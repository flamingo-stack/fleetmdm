CLI tool that queries a Fleet TUF (The Update Framework) repository to display version information for Fleet components across platforms and channels.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | func | Entry point; sets up the CLI app with the `channel-version` subcommand |
| `componentFileMap` | var | Maps component names → platform → expected filename in TUF targets |
| `channelVersionCommand` | func | Defines the `channel-version` CLI command with flags for URL, channel, components, and output format |
| `getComponents` | func | Fetches and parses `targets.json` from TUF, returning component→OS→sha512 and sha512→version maps |
| `validVersion` | func | Loosely validates a version string where all dot-separated parts are numeric |

## Flags (`channel-version`)

| Flag | Env Var | Default | Description |
|------|---------|---------|-------------|
| `--url` | `URL` | `https://updates.fleetdm.com` | TUF repository base URL |
| `--channel` | `TUF_STATUS_CHANNEL` | `stable` | Release channel to query |
| `--components` | `TUF_STATUS_COMPONENTS` | all six components | Components to include |
| `--format` | `TUF_STATUS_FORMAT` | `json` | Output format: `json` or `markdown` |

## Usage Example

```bash
# JSON output for the stable channel (default)
tuf-status channel-version

# Markdown table for the edge channel, orbit and osqueryd only
tuf-status channel-version \
  --channel edge \
  --components orbit \
  --components osqueryd \
  --format markdown

# Point at a custom TUF mirror
tuf-status channel-version \
  --url https://my-tuf-mirror.example.com \
  --format json
```

**Example JSON output:**

```json
{
  "orbit": {
    "linux": "1.23.0",
    "macos": "1.23.0",
    "windows": "1.23.0"
  },
  "osqueryd": {
    "linux": "5.12.1",
    "macos": "5.12.1"
  }
}
```

The tool resolves versions by matching each component's sha512 hash back to versioned targets in `targets.json`, selecting the version with the most dot-separated parts when duplicates exist. The `macos-app` platform key is normalized to `macos` in all output.
