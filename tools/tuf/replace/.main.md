A cross-platform `sed`-like utility that performs regex find-and-replace on a file in-place, created to avoid behavioral differences between GNU `sed` (Linux) and BSD `sed` (macOS).

## Key Components

| Component | Description |
|-----------|-------------|
| `main()` | Reads a file, applies a regex substitution, and writes the result back to the same file |
| Newline handling | Converts literal `\n` suffix in the replacement string to an actual newline character |
| File permission preservation | Uses `os.Stat` to retain the original file's mode/permissions after writing |

## Usage Example

```bash
# Replace a version string in a file
go run main.go config.yaml "version: .*" "version: 2.0.0"

# Replace a pattern with a trailing newline
go run main.go README.md "old-text" "new-text\n"
```

**Arguments:**
1. `inputPath` — path to the file to modify
2. `expression` — Go-compatible regular expression to match
3. `replace` — replacement string (supports Go regex back-references like `$1`; trailing `\n` is converted to a real newline)

## Notes

- Panics on any I/O or regex error — intended for use in controlled build/script environments
- The replacement string supports Go's [`regexp.ReplaceAllString`](https://pkg.go.dev/regexp#Regexp.ReplaceAllString) syntax for capture group references (e.g., `${1}`)
