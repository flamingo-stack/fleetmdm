Downloads TUF (The Update Framework) release artifacts from GitHub Actions workflows, supporting orbit, Fleet Desktop, and osqueryd executables across multiple platforms.

## Key Components

| Component | Description |
|---|---|
| `main()` | Entry point; registers three subcommands via `urfave/cli` |
| `orbitCommand()` | Downloads orbit binaries from the `goreleaser-orbit.yaml` workflow |
| `desktopCommand()` | Downloads Fleet Desktop binaries from the `generate-desktop-targets.yml` workflow |
| `osquerydCommand()` | Downloads osqueryd binaries from the `generate-osqueryd-targets.yml` workflow |
| `downloadComponents()` | Core logic: locates a workflow run by git tag/branch, waits for all platform artifacts, then downloads each |
| `downloadAndExtractZip()` | Fetches a zip artifact via authenticated HTTP and extracts it to a destination path |
| `extractZipFile()` | Safely extracts a single zip entry, skipping symlinks and path-traversal entries |

**Supported platforms per command:** `macos`, `linux`, `linux-arm64`, `windows`, `windows-arm64`

## Usage Example

```bash
# Download orbit binaries for a release tag
download-artifacts orbit \
  --git-tag orbit-v1.23.0 \
  --output-directory ./artifacts/orbit \
  --github-username myuser \
  --github-api-token ghp_xxxx \
  --retry

# Download Fleet Desktop binaries
download-artifacts desktop \
  --git-tag fleet-v4.50.0 \
  --output-directory ./artifacts/desktop \
  --github-username myuser \
  --github-api-token ghp_xxxx

# Download osqueryd binaries
download-artifacts osqueryd \
  --git-branch main \
  --output-directory ./artifacts/osqueryd \
  --github-username myuser \
  --github-api-token ghp_xxxx \
  --retry
```

All flags can alternatively be set via environment variables (e.g., `DOWNLOAD_ARTIFACTS_GITHUB_API_TOKEN`). When `--retry` is set, the tool polls GitHub every 60 seconds until the workflow run and all five platform artifacts are available.
