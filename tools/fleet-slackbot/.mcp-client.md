MCP client wrapper that connects to a Model Context Protocol server via SSE transport, discovers available tools, and routes tool calls to either remote MCP endpoints or locally registered handlers.

## Key Components

| Export / Member | Description |
|---|---|
| `McpClient` | Main class managing MCP server lifecycle and tool dispatch |
| `constructor({ url, authToken })` | Initializes client with server URL and optional Bearer token |
| `addLocalTool(definition, handler)` | Registers a local tool (handled in-process, never forwarded to MCP server) |
| `connect()` | Establishes SSE connection and discovers remote tools; idempotent and auto-reconnects |
| `getAnthropicTools()` | Returns merged remote + local tool definitions formatted for the Anthropic API |
| `callTool(name, args)` | Dispatches a tool call, with local-first routing, auto-reconnect on failure, and result truncation |
| `disconnect()` | Gracefully closes the MCP connection |
| `MAX_TOOL_RESULT_CHARS` | Internal constant (`20000`) capping tool output to protect Claude's context window |

## Usage Example

```javascript
const McpClient = require("./mcp-client");

const mcp = new McpClient({
  url: "https://my-mcp-server.example.com/sse",
  authToken: process.env.MCP_AUTH_TOKEN,
});

// Register a local tool (handled in-process)
mcp.addLocalTool(
  {
    name: "get_current_time",
    description: "Returns the current UTC time",
    input_schema: { type: "object", properties: {} },
  },
  async (_args) => new Date().toISOString()
);

// Connect and discover remote tools
await mcp.connect();

// Get all tools formatted for Anthropic
const tools = mcp.getAnthropicTools();

// Call a remote tool
const result = await mcp.callTool("list_hosts", { platform: "darwin" });
console.log(result);

await mcp.disconnect();
```

## Notes

- **Local tools take priority** over remote tools when names collide — checked before any network call.
- **Auto-reconnect** triggers on both pre-call disconnection detection and mid-call transport failures (one retry).
- Results exceeding `20000` characters are truncated with a descriptive suffix prompting narrower queries.
