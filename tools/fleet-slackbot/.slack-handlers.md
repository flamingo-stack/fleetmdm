Processes Slack events and routes user requests through an AI agent loop (Claude) that reads Fleet GitOps configuration, proposes YAML changes, and creates GitHub pull requests — or returns informational answers — all within a Slack thread.

## Key Components

### `validateGitopsPath(normalizedPath)`
Guards against path traversal and out-of-scope file paths. Accepts only `default.yml`, `fleets/`, and `lib/` paths. Returns `null` if valid, or an error string if not.

### `ActivityLog` (class)
Tracks tool calls made during an agent loop invocation and formats them into a Slack-ready bullet list for display in the status message.

| Method | Description |
|---|---|
| `addToolCall(toolName, args)` | Appends a tool call entry |
| `format()` | Returns a formatted mrkdwn string, or `null` if no entries |

### `handleRequest(opts)`
Core async handler shared by all Slack entry points. Orchestrates the full request lifecycle:
1. Adds an hourglass reaction to acknowledge the message
2. Posts a live status message updated during processing
3. Fetches the repo file tree and builds a sandboxed user message (prompt injection mitigations applied)
4. Runs the Claude agent loop with tool call tracking
5. On **informational** responses: posts the answer directly to the thread
6. On **config changes**: validates paths and YAML, creates a branch, commits, opens a draft PR, and posts a formatted summary
7. Sanitizes errors before surfacing them to Slack

### `getThreadContext(client, channelId, threadTs)`
Fetches the last 10 messages from a Slack thread and formats them as `role: text` pairs for inclusion as conversation context.

### `registerHandlers(app, config, github, claude)`
Registers Slack Bolt event listeners (mentions and DMs) on the provided app instance. Uses a `processingMessages` Set to deduplicate concurrent or edit-triggered events.

## Usage Example

```javascript
const { registerHandlers } = require("./slack-handlers");

// Inside your app bootstrap
registerHandlers(app, config, githubClient, claudeClient);
```

```javascript
// handleRequest is also callable directly for testing
await handleRequest({
  userText: "Add macOS 14 to the supported fleet",
  userId: "U12345",
  channelId: "C99999",
  threadTs: "1700000000.000100",
  messageTs: "1700000000.000100",
  threadContext: "",
  client: slackClient,
  config,
  github: githubClient,
  claude: claudeClient,
  logPrefix: "[test]",
});
```
