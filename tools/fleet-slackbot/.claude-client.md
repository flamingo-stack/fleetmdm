Orchestrates agentic conversations with Claude (Anthropic) by managing a streaming message loop, executing MCP tool calls, and parsing structured responses for GitOps PR workflows.

## Key Components

### `ClaudeClient` Class

**Constructor options:**
- `apiKey` — Anthropic API key
- `model` — Claude model identifier
- `mcpClient` — MCP client instance providing tool definitions and execution
- `maxToolCalls` — Per-response tool call budget (default: `100`, overridable via `MAX_TOOL_CALLS` env var)

**Core methods:**

| Method | Description |
|---|---|
| `runAgentLoop(userMessage, options)` | Main agentic loop: sends messages, executes MCP tools, and iterates until Claude returns a final text response |
| `_streamMessage(messages, tools, onText, options)` | Low-level streaming API call; fires `onText` with partial chunks |
| `proposeRevisions(commentBody, currentFiles, prTitle, options)` | High-level method for applying PR comment revision requests |
| `proposeCiFix(errorLog, currentFiles, prTitle)` | High-level method for generating CI validation error fixes |
| `_parseResponse(responseText)` | Parses Claude's output into `{ type: "info", text }` or `{ type: "changes", summary, prTitle, prBody, changes }` |

**Stop reason handling in `runAgentLoop`:**
- `end_turn` — Returns final text response
- `pause_turn` — Server-side tool limit hit; continues loop
- `tool_use` — Executes MCP tools up to budget, then re-prompts

## Usage Example

```javascript
const ClaudeClient = require('./claude-client');

const claude = new ClaudeClient({
  apiKey: process.env.ANTHROPIC_API_KEY,
  model: 'claude-opus-4-5',
  mcpClient: myMcpClient,
  maxToolCalls: 50,
});

// Propose file revisions from a PR comment
const result = await claude.proposeRevisions(
  'Please add memory limits to all deployments',
  { 'gitops/app.yaml': currentYaml },
  'feat: update fleet policies',
  {
    onToolCall: (name, args) => console.log(`Tool: ${name}`, args),
    onText: (chunk) => process.stdout.write(chunk),
  }
);

if (result.type === 'changes') {
  console.log(result.prTitle, result.changes);
} else {
  console.log(result.text);
}
```

> **Security note:** Both `_buildRevisionMessage` and `_buildCiFixMessage` wrap user-provided content in explicit prompt-injection guards, labeling it as untrusted input to prevent instruction hijacking.
