Loads and validates all application configuration from environment variables, exiting immediately if any required variable is missing.

## Key Components

- **`config`** — Structured configuration object with six namespaced sections:
  - `slack` — Bot and app tokens for the Slack integration
  - `github` — Token, repo, base branch, GitOps path, and bot username
  - `anthropic` — API key, model selection, and max tool call limit
  - `webhook` — Webhook secret and HTTP port
  - `ci` — CI check name and auto-fix toggle
  - `mcp` — Fleet MCP server URL and auth token
- **Required variable validation** — Iterates a list of required env vars and calls `process.exit(1)` with a descriptive error if any are absent

## Environment Variables

| Variable | Default | Required |
|---|---|---|
| `SLACK_BOT_TOKEN` | — | ✅ |
| `SLACK_APP_TOKEN` | — | ✅ |
| `GITHUB_TOKEN` | — | ✅ |
| `GITHUB_BOT_USERNAME` | — | ✅ |
| `ANTHROPIC_API_KEY` | — | ✅ |
| `GITHUB_WEBHOOK_SECRET` | — | ✅ |
| `FLEET_MCP_AUTH_TOKEN` | — | ✅ |
| `GITHUB_REPO` | `fleetdm/fleet` | ❌ |
| `GITHUB_BASE_BRANCH` | `main` | ❌ |
| `GITOPS_BASE_PATH` | `it-and-security` | ❌ |
| `ANTHROPIC_MODEL` | `claude-opus-4-6` | ❌ |
| `MAX_TOOL_CALLS` | `100` | ❌ |
| `PORT` | `3000` | ❌ |
| `GITOPS_CI_CHECK_NAME` | `fleet-gitops` | ❌ |
| `CI_AUTO_FIX` | `true` | ❌ |
| `FLEET_MCP_URL` | `http://localhost:8181/sse` | ❌ |

## Usage Example

```javascript
const config = require("./config");

// Access nested config sections
console.log(config.github.repo);       // "fleetdm/fleet"
console.log(config.anthropic.model);   // "claude-opus-4-6"
console.log(config.webhook.port);      // 3000
```
