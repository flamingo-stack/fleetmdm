A thin wrapper around `@octokit/rest` that exposes high-level GitHub operations needed for GitOps workflows — branch management, atomic multi-file commits, pull request interactions, and CI job log retrieval.

## Key Components

### `GitHubClient` class

**Constructor options:**

| Option | Default | Description |
|---|---|---|
| `token` | — | GitHub personal access token |
| `repo` | — | `"owner/repo"` string |
| `baseBranch` | `"main"` | Branch to branch from / merge into |
| `gitopsBasePath` | `"it-and-security"` | Subtree scanned for GitOps files |

**Methods:**

| Method | Description |
|---|---|
| `getFileContent(filePath)` | Fetches a file from `baseBranch`; returns `null` if missing |
| `getFileContentFromRef(filePath, ref)` | Fetches a file at an arbitrary ref/SHA |
| `getRepoTreePaths()` | Returns all blob paths under `gitopsBasePath` via Git tree API |
| `createBranch(branchName)` | Creates a branch from the current `baseBranch` HEAD |
| `commitChanges(branchName, changes, message)` | Atomically commits multiple file changes using the Git Data API |
| `createPullRequest(branchName, title, body, opts)` | Opens a PR from `branchName` into `baseBranch` |
| `getPullRequest(pullNumber)` | Returns normalized PR metadata |
| `getPullRequestFiles(pullNumber)` | Lists all files changed in a PR (paginated) |
| `addPullRequestComment(pullNumber, body)` | Posts an issue comment on a PR |
| `addIssueCommentReaction(commentId, reaction)` | Adds an emoji reaction to an issue comment |
| `addReviewCommentReaction(commentId, reaction)` | Adds an emoji reaction to a review comment |
| `getCommit(sha)` | Returns normalized commit metadata |
| `getFailedJobLogs(headSha, checkName)` | Finds and downloads logs for a named failed CI job |

## Usage Example

```javascript
const GitHubClient = require("./github-client");

const client = new GitHubClient({
  token: process.env.GITHUB_TOKEN,
  repo: "flamingo-stack/fleetmdm",
  baseBranch: "main",
  gitopsBasePath: "it-and-security",
});

// Read an existing policy file
const content = await client.getFileContent("it-and-security/policies/antivirus.yml");

// Create a branch and commit changes atomically
await client.createBranch("feat/update-policy");
await client.commitChanges(
  "feat/update-policy",
  [{ path: "it-and-security/policies/antivirus.yml", content: updatedYaml }],
  "chore: update antivirus policy"
);

// Open a pull request
const { url, number } = await client.createPullRequest(
  "feat/update-policy",
  "Update antivirus policy",
  "Automated policy update via Mingo AI."
);
```
