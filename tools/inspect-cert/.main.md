A CLI tool for inspecting and validating Apple APNs (Push Notification Service) certificates used in Fleet MDM configurations.

## Key Components

| Function | Description |
|---|---|
| `main()` | Parses CLI flags and dispatches to `inspect` or `validate` |
| `inspect(certFile)` | Decodes a PEM certificate and pretty-prints its parsed `x509.Certificate` struct |
| `validate(certFile, keyFile)` | Loads the APNs cert/key pair and tests client-auth TLS against Apple's sandbox endpoint |

**Flags:**

| Flag | Required | Description |
|---|---|---|
| `-cert` | Yes | Path to the PEM certificate file |
| `-key` | No | Path to the private key file (required for `-validate`) |
| `-validate` | No | Run validation against Apple sandbox |

## Usage Example

```bash
# Inspect a certificate (print parsed fields)
go run main.go -cert apns.pem

# Validate cert + key against Apple's sandbox APNs endpoint
go run main.go -cert apns.pem -key apns.key -validate
```

The `inspect` mode decodes the PEM block, parses it as an X.509 certificate, and dumps all fields using `spew`. The `validate` mode uses `config.MDMConfig` to load the APNs credentials, then calls `certificate.ValidateClientAuthTLSConnection` with a 10-second timeout against `https://api.sandbox.push.apple.com`.
