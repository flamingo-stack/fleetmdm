Node.js launcher script that automatically downloads, installs, and executes the platform-appropriate `fleetctl` binary when invoked via npm/npx.

## Key Components

| Component | Description |
|---|---|
| `strippedVersion` | Normalizes the package version by removing numeric suffixes (e.g., `v4.0.0-1` → `v4.0.0`) for correct release artifact resolution |
| `platform` | Detects the current OS and architecture to select the appropriate binary target (`windows_amd64`, `linux_arm64`, `macos`, etc.) |
| `install()` | Downloads the versioned `fleetctl` tarball from the FleetDM GitHub releases and extracts the binary to a versioned install directory |
| `run()` | Entry point — checks for an existing binary, installs if missing, then spawns `fleetctl` with all forwarded CLI arguments |

## Usage Example

This script runs automatically when the npm package is invoked. No direct usage is required by consumers:

```bash
# Install globally and run
npm install -g fleetctl
fleetctl --help

# Or via npx
npx fleetctl --help
```

The binary is cached at `install/<version>/fleetctl` (or `fleetctl.exe` on Windows). On subsequent runs, the download is skipped if the versioned binary already exists.

**Permission error handling:** If installed with elevated privileges (`sudo` / Run as Administrator), the script provides a clear, platform-specific error message instructing the user to re-run with appropriate permissions rather than showing a cryptic OS error.
