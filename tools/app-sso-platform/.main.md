A macOS-only CLI tool for testing the `app_sso_platform` osquery table implementation directly from the command line, without requiring a full osquery agent.

## Key Components

- **`main()`** — Entry point that parses two required CLI arguments (`extensionIdentifier` and `realm`), constructs an osquery `QueryContext` with equality constraints, invokes the `app_sso_platform.Generate` function, and prints the resulting rows.

## Build Constraints

- **`//go:build darwin`** — Compiles only on macOS, matching the platform requirement of the SSO Platform extension API.
- **`//go:debug x509negativeserial=1`** — Enables handling of certificates with negative serial numbers, required for some enterprise Kerberos/MSFT environments.

## Usage Example

```bash
# Query the SSO Platform extension for Microsoft Company Portal
go run ./tools/app-sso-platform \
  com.microsoft.CompanyPortalMac.ssoextension \
  KERBEROS.MICROSOFTONLINE.COM
```

```go
// Arguments map to osquery equality constraints:
// os.Args[1] → extension_identifier = "com.microsoft.CompanyPortalMac.ssoextension"
// os.Args[2] → realm               = "KERBEROS.MICROSOFTONLINE.COM"
```

**Output:** Prints the raw `[]map[string]string` rows returned by `app_sso_platform.Generate`, e.g.:

```text
[map[extension_identifier:com.microsoft.CompanyPortalMac.ssoextension realm:KERBEROS.MICROSOFTONLINE.COM username:jdoe ...]]
```

If fewer than 3 arguments are provided, the tool prints usage and exits with code `1`. Any error from `Generate` causes a panic.
