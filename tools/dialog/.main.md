A test utility for validating Linux dialog backends (`zenity` and `kdialog`) by exercising the `dialog.Dialog` interface through an entry prompt followed by an info display.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | `func` | Entry point; parses the `--dialog` flag, instantiates the chosen backend, and runs a sequential entry → info dialog flow |
| `--dialog` | CLI flag | Selects the dialog backend: `zenity` (default) or `kdialog` |

**Dependencies:**
- `github.com/fleetdm/fleet/v4/orbit/pkg/dialog` — shared `Dialog` interface and option types
- `github.com/fleetdm/fleet/v4/orbit/pkg/zenity` — GTK-based dialog backend
- `github.com/fleetdm/fleet/v4/orbit/pkg/kdialog` — KDE-based dialog backend

## Usage Example

```bash
# Run with the default zenity backend
go run main.go

# Run with the kdialog backend (KDE environments)
go run main.go --dialog kdialog
```

```go
// Dialog flow executed at runtime:

// 1. Prompt user for masked text input (10s timeout)
output, err := prompt.ShowEntry(dialog.EntryOptions{
    Title:    "Zenity Test Entry Title",
    Text:     "Zenity Test Entry Text",
    HideText: true,
    TimeOut:  10 * time.Second,
})

// 2. Display the captured input back to the user (10s timeout)
err = prompt.ShowInfo(dialog.InfoOptions{
    Title:   "Zenity Test Info Title",
    Text:    "Result: " + string(output),
    TimeOut: 10 * time.Second,
})
```

> **Note:** This is a manual testing tool, not production code. Both dialogs use a 10-second timeout; panics on any error to surface failures immediately during testing.
