Automates CIS benchmark policy testing against macOS VMs by orchestrating `tart`, `fleetctl`, and Fleet's team/MDM infrastructure to validate policy compliance across multiple macOS versions.

## Key Components

### Constants & Configuration

- **`VERSION_MAP`** – Maps macOS major versions (`13`–`26`) to tart VM images and CIS directory names
- **`SSH_BREAKING_CIS_IDS`** – Per-OS set of CIS IDs that disable SSH during testing; these are routed to manual verification
- **`PASSWORD_POLICY_CIS_IDS`** – Per-OS set of CIS IDs that enforce password policies incompatible with the VM's default `admin` credentials
- **`NON_AUTOMATABLE_CIS_IDS`** – Per-OS dict of CIS IDs that cannot be reliably automated (VM limitations, missing artifacts, state conflicts), with explanatory comments

### Data Classes

| Class | Purpose |
|---|---|
| `Policy` | Parsed CIS policy with `cis_id`, query, resolution, and MDM flag |
| `TestPlan` | Execution plan for one policy: type (`PASS_FAIL`, `PROFILE`, `MANUAL`, etc.), scripts, and profiles |
| `TestResult` | Outcome record (`PASS`, `FAIL`, `SKIP`, `ERROR`) with details |
| `FleetTeam` | Fleet team metadata including enrollment secret and enrolled host |

### Core Functions

- **`read_fleetctl_config(context)`** – Reads Fleet URL and API token from `~/.fleet/config`
- **`parse_policies(yaml_path)`** – Parses multi-document YAML policy files, filtering for `CIS -` prefixed policies with a `cis_id`
- **`filter_policies(...)`** – Filters parsed policies by explicit CIS ID list or name substring
- **`cis_id_sort_key(cis_id)`** – Produces a sortable numeric key from dotted CIS IDs (e.g., `"2.3.3.4"` → `[2, 3, 3, 4]`)
- **`_discover_profiles(cis_id, policy_cis_id, profiles_dir)`** – Resolves `.mobileconfig` profile paths for a given CIS ID, including enable/disable and multi-part variants

## Usage Example

```bash
pip3 install pyyaml

python3 cis-test-runner.py \
  --macos-version 14 \
  --all \
  --fleet-url https://fleet.example.com \
  --fleet-token YOUR_API_TOKEN
```

```python
# Parse and filter policies programmatically
from pathlib import Path
policies = parse_policies(Path("macos-14/cis-policy.yml"))
filtered = filter_policies(policies, cis_ids=["2.3.3.4", "5.2.2"])
```

> **Note:** CIS section numbers are not stable across benchmark versions or OS releases. Verify `SSH_BREAKING_CIS_IDS` and `PASSWORD_POLICY_CIS_IDS` mappings against the target benchmark document when updating to a new macOS version.
