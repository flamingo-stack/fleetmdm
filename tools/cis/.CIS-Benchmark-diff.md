Compares two CIS Benchmark PDF files and generates a unified diff of their recommendation sections, useful for identifying changes between benchmark versions (e.g., Windows 10 vs. Windows 11).

## Key Components

| Function | Description |
|---|---|
| `extract_recommendations_fitz()` | Opens a PDF with PyMuPDF, captures text between `"Recommendations ..."` and `"Appendix: Summary Table ..."`, and cleans pagination artifacts |
| `correct_word_wrapping()` | Rejoins lines that were split mid-sentence during PDF extraction, using numbered item patterns as delimiters |
| `is_start_of_new_item()` | Regex helper detecting CIS numbering patterns (e.g., `1`, `1.1`, `100.7.32`) |
| `remove_trailing_whitespace()` | Strips trailing spaces from every line of extracted text |
| `create_custom_diff()` | Produces a unified diff with `file1:` / `file2:` prefixes instead of `+`/`-`, with no context lines (`n=0`) |
| `main()` | Orchestrates extraction, writes `cleaned.txt`, and outputs a timestamped `cis_benchmarks_diff.txt` |

## Usage Example

```bash
# Install dependency
pip3 install PyMuPDF

# Run the diff
python3 CIS-Benchmark-diff.py CIS_Win10_Benchmark.pdf CIS_Win11_Benchmark.pdf
```

**Output files:**

| File | Contents |
|---|---|
| `cleaned.txt` | Extracted recommendation text from both PDFs |
| `cis_benchmarks_diff.txt` | Timestamped diff showing additions/removals between benchmarks |

## Notes

- Extraction relies on the exact phrases `"Recommendations ..."` and `"Appendix: Summary Table ..."` being present in the PDF — custom benchmarks with different section headings will require updating `start_phrase`/`end_phrase` in `main()`.
