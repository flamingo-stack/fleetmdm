A manual testing utility for verifying TLS connections to a Redis server by creating a connection pool with TLS configuration and executing a Redis command.

## Key Components

| Element | Description |
|---|---|
| `addrFlag` | Redis server address including port |
| `certFlag` | Path to client TLS certificate file |
| `keyFlag` | Path to client TLS key file |
| `cacertFlag` | Path to CA certificate file |
| `serverFlag` | Server name for TLS certificate verification |
| `skipVerifyFlag` | Boolean flag to skip TLS certificate verification |
| `main()` | Creates a TLS-enabled Redis pool, executes a Redis command, and logs the result |

## Usage Example

```bash
# Start a TLS-enabled Redis server first, then run:
go run ./tools/redis-tests/tlsconnect.go \
  -addr localhost:7379 \
  -cacert ./tests/tls/ca.crt \
  -cert ./tests/tls/redis.crt \
  -key ./tests/tls/redis.key \
  PING

# Run with TLS verification skipped
go run ./tools/redis-tests/tlsconnect.go \
  -addr localhost:7379 \
  -cacert ./tests/tls/ca.crt \
  -cert ./tests/tls/redis.crt \
  -key ./tests/tls/redis.key \
  -skip \
  PING

# Execute a custom Redis command
go run ./tools/redis-tests/tlsconnect.go \
  -addr localhost:7379 \
  -cacert ./tests/tls/ca.crt \
  SET mykey myvalue
```

If no Redis command is provided, `PING` is used by default. The result and any errors are logged to stdout.

## Setting Up a TLS Redis Server

```bash
# Build Redis with TLS support
make BUILD_TLS=yes

# Generate test certificates
./utils/gen-test-certs.sh

# Start Redis with TLS on port 7379
./src/redis-server \
  --tls-port 7379 --port 0 \
  --tls-ca-cert-file ./tests/tls/ca.crt \
  --tls-cert-file ./tests/tls/redis.crt \
  --tls-key-file ./tests/tls/redis.key
```
