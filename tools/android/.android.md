A CLI tool for interacting with the Android Management API, providing administrative operations for managing Android enterprises, devices, policies, and applications within a Fleet MDM context.

## Key Components

**Commands**

| Command | Description |
|---|---|
| `enterprises.delete` | Delete an enterprise by ID |
| `enterprises.list` | List all enterprises in the project |
| `enterprises.webTokens.create` | Generate a managed Play Store web token |
| `applications.get` | Fetch details for a specific application |
| `policies.list` / `policies.delete` | List or delete enterprise policies |
| `devices.list` / `devices.delete` | List or delete enrolled devices |
| `devices.issueCommand.RELINQUISH_OWNERSHIP` | Relinquish device ownership |

**Required Environment Variable**

- `FLEET_DEV_ANDROID_GOOGLE_SERVICE_CREDENTIALS` — JSON service account credentials; `project_id` is extracted automatically.

## Usage Example

```bash
# List all enterprises
go run android.go \
  -command=enterprises.list

# List devices for an enterprise
go run android.go \
  -command=devices.list \
  -enterprise_id=LC04xxxxxxx

# Delete a specific device
go run android.go \
  -command=devices.delete \
  -enterprise_id=LC04xxxxxxx \
  -device_id=DEVICE_ID

# Get application details (app package name passed as positional arg)
go run android.go \
  -command=applications.get \
  -enterprise_id=LC04xxxxxxx \
  com.example.app

# Create a managed Play Store web token
go run android.go \
  -command=enterprises.webTokens.create \
  -enterprise_id=LC04xxxxxxx
```

> **Note:** The `enterprises/` prefix in `--enterprise_id` is automatically stripped if present. Output for list/get commands is pretty-printed JSON.
