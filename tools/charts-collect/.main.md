Fetches live Fleet API data and writes uptime and CVE chart snapshots into a MySQL database. Designed to run hourly via cron, it maintains host bitmaps in a slowly-changing dimension (SCD) table.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `main` | func | Entry point; parses flags/env vars, opens DB connection, runs both collectors |
| `apiClient` | struct | Thin Fleet API wrapper with bearer-token auth |
| `collectUptime` | func | Fetches online hosts, OR-merges into current-hour SCD bucket (`dataset='uptime'`) |
| `collectCVE` | func | Fetches per-host CVEs, inverts into per-CVE host bitmaps, calls `reconcileSnapshot` |
| `reconcileSnapshot` | func | Mirrors server-side SCD logic: closes stale rows, upserts new/changed bitmaps |
| `dsnFromEnv` | func | Assembles a MySQL DSN from `FLEET_MYSQL_*` env vars when `--mysql-dsn` is absent |
| `scdOpenSentinel` | var | `9999-12-31` end-of-time marker for open SCD rows; must match DB default |

## Usage Example

```bash
# Run with explicit flags
go run ./tools/charts-collect \
  --fleet-url https://dogfood.fleetdm.com \
  --fleet-token <token> \
  --mysql-dsn "fleet:fleet@tcp(localhost:3306)/fleet"

# Run using environment variables (e.g. Render fromService)
export FLEET_URL=https://dogfood.fleetdm.com
export FLEET_TOKEN=<token>
export FLEET_MYSQL_ADDRESS=db.internal:3306
export FLEET_MYSQL_DATABASE=fleet
export FLEET_MYSQL_USERNAME=fleet
export FLEET_MYSQL_PASSWORD=secret
go run ./tools/charts-collect
```

## Environment Variables

| Variable | Purpose |
|---|---|
| `FLEET_URL` | Fleet server base URL |
| `FLEET_TOKEN` | Fleet API bearer token |
| `MYSQL_DSN` | Full MySQL DSN (overrides individual vars below) |
| `FLEET_MYSQL_ADDRESS` | `host:port` for MySQL |
| `FLEET_MYSQL_DATABASE` | Database name |
| `FLEET_MYSQL_USERNAME` | MySQL username |
| `FLEET_MYSQL_PASSWORD` | MySQL password |

## SCD Write Semantics

- **Uptime**: accumulates an OR-merged bitmap per 1-hour bucket; re-runs within the same hour extend the existing row via `ON DUPLICATE KEY UPDATE`.
- **CVE**: per-CVE bitmaps are reconciled each run — unchanged rows are left open, changed bitmaps close the prior row at the hour boundary and open a new one.
