Entrypoint for a diagnostic utility that identifies and prints the root disk partition using LVM (Logical Volume Manager) discovery.

## Key Components

| Symbol | Description |
|--------|-------------|
| `main()` | Entry point that calls `lvm.FindRootDisk()` and prints the result to stdout |

## Usage Example

```bash
# Build and run directly
go run main.go

# Expected output
Root Partition: /dev/sda1
```

## Dependencies

- [`lvm.FindRootDisk()`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/lvm) — discovers the disk device backing the root (`/`) filesystem partition

## Notes

- Panics on error, making this suitable as a debugging or diagnostic tool rather than a production service
- Output is written to stdout via `fmt.Println`
