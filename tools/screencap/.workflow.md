Defines the data types, persistence helpers, and browser-side JavaScript for recording and replaying UI interaction workflows used by the `screencap` tool.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `actionKind` | Enum-style string constant for interaction types: `click`, `hover`, `radio`, `checkbox`, `tab`, `toggle` |
| `recordedAction` | Single captured interaction with a kind, CSS selector, and optional text |
| `workflowStep` | One screenshot step: URL path, scroll position, optional modal state, and a slice of actions |
| `workflow` | Named, ordered sequence of `workflowStep` entries serialized to/from JSON |

### Functions

| Function | Description |
|----------|-------------|
| `workflowsDir()` | Resolves the storage directory; defaults to `tools/screencap/workflows/` relative to this source file, overrideable via `workflowsDirOverride` |
| `workflowPath(name)` | Returns the validated absolute `.json` path for a named workflow; rejects traversal characters |
| `saveWorkflow(w)` | Marshals a `workflow` to indented JSON and writes it to disk |
| `loadWorkflow(name)` | Reads and unmarshals a workflow by name, wrapping errors with context |
| `listWorkflows()` | Returns the base names of all `.json` files in the workflows directory |

### JavaScript Constants

| Constant | Description |
|----------|-------------|
| `recorderJS` | Injected into the browser page; listens for `click` and `mouseover` events, builds stable CSS selectors, classifies interaction kinds, and appends actions to `window.__screencapActions` |
| `drainActionsJS` | Drains and returns the accumulated `window.__screencapActions` buffer, then clears it |

## Usage Example

```go
// Save a recorded workflow
w := &workflow{
    Name: "add-host",
    Steps: []workflowStep{
        {
            Name:    "Open Hosts page",
            Path:    "/hosts",
            Actions: []recordedAction{
                {Kind: actionClick, Selector: "#add-host-btn", Text: "Add host"},
            },
        },
    },
}
if err := saveWorkflow(w); err != nil {
    log.Fatal(err)
}

// Load it back for replay
loaded, err := loadWorkflow("add-host")
if err != nil {
    log.Fatal(err)
}

// List all available workflows
names, err := listWorkflows()
// names → ["add-host", "enroll-device", ...]
```
