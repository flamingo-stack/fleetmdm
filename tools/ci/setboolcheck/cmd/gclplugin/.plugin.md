Provides the golangci-lint module plugin entry point for the `setboolcheck` custom linter, registering it with the golangci-lint plugin system.

## Key Components

- **`init()`** — Registers the plugin under the name `"setboolcheck"` with the golangci-lint plugin module registry on package load.
- **`New`** — Constructor function satisfying the `register.LinterPlugin` factory signature; returns a `plugin` instance.
- **`plugin`** — Private struct implementing the `register.LinterPlugin` interface with two methods:
  - `BuildAnalyzers()` — Returns the `setboolcheck.Analyzer` for use by golangci-lint.
  - `GetLoadMode()` — Returns `register.LoadModeTypesInfo`, enabling full type information during analysis.

## Usage Example

This file is not imported directly. It is loaded by golangci-lint as an external module plugin. Reference it in your `.golangci.yml`:

```yaml
linters-settings:
  custom:
    setboolcheck:
      path: ./tools/ci/gclplugin
      description: Checks for direct boolean assignments that should use a setter.
      original-url: github.com/flamingo-stack/fleetmdm
```

Then enable the linter:

```yaml
linters:
  enable:
    - setboolcheck
```

Build the plugin shared object before running:

```bash
go build -buildmode=plugin -o setboolcheck.so ./tools/ci/gclplugin
```

## Notes

- The `New` function accepts `any` (unused configuration) to match the golangci-lint plugin factory interface.
- `LoadModeTypesInfo` is required because `setboolcheck` performs type-aware analysis.
