A static analysis pass that detects `map[T]bool` variables used as sets and suggests replacing them with the more memory-efficient `map[T]struct{}`.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Analyzer` | `*analysis.Analyzer` | The exported analyzer entry point, registered as `"setboolcheck"` |
| `varInfo` | `struct` | Tracks per-variable state: declaration position, assignment presence, all-true heuristic, taint, and skip flags |
| `run` | `func` | Three-phase analysis driver: declaration collection → assignment scanning → reporting |
| `registerParams` | `func` | Marks function parameters as `skip` to avoid false positives on caller-controlled maps |
| `registerVarDecl` | `func` | Handles `var x map[T]bool` and `var x = make(map[T]bool)` declarations |
| `registerShortVarDecl` | `func` | Handles `:=` short declarations |
| `classifyInit` | `func` | Classifies an initializer as safe (`make`, composite literal) or tainting (function call, variable copy) |
| `checkAssignment` | `func` | Inspects indexed writes (`m[k] = v`) and full reassignments |
| `taintEscapedInAssign` | `func` | Taints maps aliased via RHS assignment |
| `taintEscapedInCall` | `func` | Taints maps passed as function arguments |
| `isBoolMap` | `func` | Type predicate: reports whether a type's underlying type is `map[T]bool` |
| `isBuiltinTrue` | `func` | Guards against shadowed `true` identifiers by checking `types.Universe` |

## Usage Example

Register the analyzer with your analysis driver or `multichecker`:

```go
package main

import (
    "golang.org/x/tools/go/analysis/multichecker"
    "github.com/flamingo-stack/fleetmdm/tools/linters/setboolcheck"
)

func main() {
    multichecker.Main(setboolcheck.Analyzer)
}
```

The analyzer flags code like:

```go
// flagged: every write uses literal true
seen := make(map[string]bool)
seen["foo"] = true

// not flagged: mixed bool values
flags := map[string]bool{"enabled": true, "debug": false}
```
