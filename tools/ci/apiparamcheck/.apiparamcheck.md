A Go static analysis tool that flags struct tag names containing deprecated Fleet API terminology (`team`/`teams` and context-dependent `query`/`queries`), enforcing consistent API parameter naming across `json`, `url`, and `query` struct tags.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Analyzer` | `*analysis.Analyzer` | Entry point; registers the analyzer under the name `apiparamcheck` with the `go/analysis` framework |
| `run` | `func` | Traverses all struct types in the AST, reads tag values, and calls `violationMessage` for each checked tag key |
| `violationMessage` | `func(name string) string` | Returns a diagnostic message if the tag name contains a forbidden token; empty string if allowed |
| `splitTokens` | `func(name string) []string` | Splits snake_case and kebab-case names into token slices, then delegates camelCase splitting |
| `splitCamel` | `func(s string) []string` | Splits a camelCase/PascalCase segment into parts, keeping uppercase runs (e.g. `ID`) together |

**Escape hatch:** A `renameto:"new_name"` struct tag on a field opts it out of the check, allowing legacy names to be grandfathered during migrations.

## Usage Example

```go
// Install and run against a package:
// go install github.com/flamingo-stack/fleetmdm/tools/apiparamcheck/cmd/apiparamcheck@latest
// apiparamcheck ./...

// Flagged — "team" token in json tag:
type ListRequest struct {
    TeamID int `json:"team_id"` // flagged: uses deprecated "team"/"teams"
}

// Flagged — "query" as part of a larger url tag name:
type SearchRequest struct {
    Filter string `url:"saved_query_name"` // flagged: use "report"/"reports"
}

// Allowed — bare "query" is fine (SQL context):
type SQLRequest struct {
    Query string `json:"query"` // ok
}

// Opted out via renameto tag:
type LegacyRequest struct {
    TeamID int `json:"team_id" renameto:"fleet_id"` // skipped during migration
}
```
