Provides the golangci-lint module plugin entry point that registers the `apiparamcheck` analyzer as a linter plugin for use in CI pipelines.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `init()` | Function | Registers the plugin under the name `"apiparamcheck"` with the golangci-lint plugin registry |
| `New` | Constructor | Factory function matching the `register.Plugin` signature; returns a `plugin` instance |
| `plugin` | Struct | Implements `register.LinterPlugin`; wires `apiparamcheck.Analyzer` into the golangci-lint framework |
| `BuildAnalyzers()` | Method | Returns the single `apiparamcheck.Analyzer` for golangci-lint to run |
| `GetLoadMode()` | Method | Declares `LoadModeSyntax` as the required Go package load mode |

## Usage Example

```go
// In .golangci.yml, reference the compiled plugin:
// linters-settings:
//   custom:
//     apiparamcheck:
//       path: ./tools/ci/gclplugin/gclplugin.so
//       description: Checks API parameter usage
//       original-url: github.com/flamingo-stack/fleetmdm

// The init() function auto-registers on import; no manual wiring needed.
import _ "github.com/flamingo-stack/fleetmdm/tools/ci/gclplugin"
```

## Notes

- The `New` function accepts `any` to satisfy the generic plugin factory signature but ignores the argument — no configuration is passed to this analyzer.
- `LoadModeSyntax` means only syntactic AST information is loaded, keeping CI analysis fast.
- The underlying analyzer logic lives in [`apiparamcheck`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/ci/apiparamcheck).
