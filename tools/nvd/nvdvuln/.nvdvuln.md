A CLI tool for testing and validating NVD (National Vulnerability Database) vulnerability processing against Fleet software inventory, supporting both single-software lookups and live Fleet instance comparisons.

## Key Components

| Component | Description |
|---|---|
| `main()` | Entry point; parses flags, orchestrates CPE/CVE translation, and reports results |
| `vulnDBSync()` | Syncs the local NVD vulnerability database using `nvd.Sync` |
| `getSoftwareFromURL()` | Fetches software inventory from a live Fleet instance via API, filtering out `deb_packages` and `rpm_packages` |
| `softwareIterator` | In-memory `fleet.SoftwareIterator` implementation used to feed software into the mock datastore |
| `getSoftwareName()` | Helper that resolves a software ID to a `name:version` string |
| `printf()` | Timestamped print wrapper (UTC, ISO 8601) |

## CLI Flags

| Flag | Description |
|---|---|
| `--sync` | Sync the NVD database before processing |
| `--db_dir` | Local path for vulnerability databases (default: `/tmp/vulndbs`) |
| `--debug` | Enables debug logging and CPU/memory profiling to `cpu_and_mem.dat` |
| `--software_name/version/source/bundle_identifier` | Define a single software entry to test |
| `--software_from_url` + `--software_from_api_token` | Pull software from a Fleet instance and compare CVE results |

## Usage Example

```bash
# Sync the NVD database
go run nvdvuln.go --sync --db_dir /tmp/vulndbs

# Test a single macOS app
go run nvdvuln.go \
  --db_dir /tmp/vulndbs \
  --software_name "Google Chrome" \
  --software_version "124.0.6367.60" \
  --software_source apps \
  --software_bundle_identifier com.google.Chrome

# Compare CVEs against a live Fleet instance
go run nvdvuln.go \
  --db_dir /tmp/vulndbs \
  --software_from_url https://fleet.example.com \
  --software_from_api_token your_api_token
```
