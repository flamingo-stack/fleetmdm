Parses OpenVEX JSON files and converts their vulnerability statements into formatted Markdown output, designed to generate human-readable CVE documentation from a directory of `.vex.json` files.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OpenVEXDocument` | struct | Top-level VEX document with context, author, and statements |
| `Statement` | struct | Individual VEX statement including vulnerability, status, products, justification, and timestamp |
| `Vulnerability` | struct | Holds the CVE name (e.g. `CVE-2024-1234`) |
| `Product` | struct | Holds a product identifier string |
| `parseOpenVEX` | func | Reads and unmarshals a `.vex.json` file into an `OpenVEXDocument` |
| `generateMarkdown` | func | Converts a parsed VEX document into a Markdown-formatted string, sorted by timestamp (newest first) |
| `outputMarkdown` | func | Combines parsing and rendering, printing the result to stdout |
| `main` | func | Globs all `*.vex.json` files in the given directory and processes each one |

## Usage Example

```bash
# Generate Markdown for all VEX files in a directory
go run vex-parser.go /path/to/vex-files/
```

```go
// Parsing a single file programmatically
vex, err := parseOpenVEX("CVE-2024-1234.vex.json")
if err != nil {
    log.Fatal(err)
}

md, err := generateMarkdown(vex)
if err != nil {
    log.Fatal(err)
}
fmt.Print(md)
```

**Example output:**

```text
### [CVE-2024-1234](https://nvd.nist.gov/vuln/detail/CVE-2024-1234)
- **Author:** security@example.com
- **Status:** `not_affected`
- **Status notes:** Vulnerable code path is not reachable.
- **Products:** `pkg:golang/example.com/myapp@1.0.0`
- **Justification:** `vulnerable_code_not_in_execute_path`
- **Timestamp:** 2024-01-15 10:30:00
```

> **Note:** All statements in a single `.vex.json` file must reference the same CVE. Mixed-CVE files will return an error.
