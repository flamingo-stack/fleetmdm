A load-testing utility that hammers Fleet device API endpoints with random UUID tokens to trigger and measure rate limiting behavior.

## Key Components

- **`main()`** — Entry point that accepts two CLI flags and runs the test loop:
  - `-fleet_url` — Base URL of the Fleet server (required)
  - `-fleet_desktop_token` — Optional valid Fleet Desktop token; injected every 500th request to test legitimate token pass-through

## Behavior

- Creates an HTTP client with TLS verification disabled (test-only)
- Cycles through three device endpoints using random UUIDs as device tokens:
  - `GET /api/latest/fleet/device/{token}/desktop`
  - `GET /api/latest/fleet/device/{token}/transparency`
  - `POST /api/latest/fleet/device/{token}/refetch`
- Adds a spoofed `X-Forwarded-For: 127.0.0.1` header on every request
- Logs each request's method, path, and HTTP status
- Stops and reports elapsed time when a `429 Too Many Requests` response is received
- Sleeps 10 ms between requests

## Usage Example

```bash
# Basic run — hammers with random tokens until rate limited
go run main.go -fleet_url https://fleet.example.com:8080

# Include a valid token (injected every 500th request)
go run main.go \
  -fleet_url https://fleet.example.com:8080 \
  -fleet_desktop_token "your-valid-desktop-token"
```
