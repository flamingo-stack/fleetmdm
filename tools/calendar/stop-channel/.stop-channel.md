A CLI utility to stop a Google Calendar push notification channel for a specific user by calling the Calendar API's `channels.stop` endpoint.

## Key Components

- **`main()`** — Parses CLI flags (`--users`, `--channel-id`, `--resource-id`), builds a JWT-authenticated Google Calendar client using service account impersonation, and calls `Channels.Stop()`.
- **`withRetry()`** — Wraps any API call with exponential backoff (up to 60 minutes), retrying only on rate-limit errors and treating all other errors as permanent.
- **`isRateLimited()`** — Inspects a `googleapi.Error` to determine if the failure is due to quota/rate limiting (`429` or `403` with specific rate limit messages).

## Environment Variables

| Variable | Description |
|---|---|
| `FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL` | Google service account email |
| `FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY` | PEM private key (supports `\n` escaped newlines) |

## Usage Example

```bash
export FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL="service@project.iam.gserviceaccount.com"
export FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n..."

go run stop-channel.go \
  --users john@example.com \
  --channel-id 55ebefd7-4271-4295-a80a-97f4dcb01d93 \
  --resource-id Io5ygBoEZ-FmQus7ziNrS_Jjcz4
```

> **Note:** Only a single user email is accepted. Passing a comma-separated list of more than one address will cause the command to exit with an error.
