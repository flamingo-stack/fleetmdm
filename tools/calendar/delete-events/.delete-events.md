Bulk-deletes Google Calendar events matching a specific title (`💻🚫 Scheduled maintenance`) from the primary calendars of one or more specified users, using service account impersonation with exponential-backoff retry logic.

## Key Components

| Symbol | Description |
|---|---|
| `main()` | Parses `--users` flag, spawns one goroutine per user to list and delete matching events concurrently |
| `withRetry()` | Wraps any Google API call with exponential backoff (up to 60 minutes) — retries on rate-limit errors, fails fast on all others |
| `isRateLimited()` | Inspects a `googleapi.Error` for HTTP 429 or calendar-specific 403 quota messages |
| `serviceEmail` / `privateKey` | JWT service account credentials read from `FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL` and `FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY` |
| `eventTitle` | Constant string used as the Google Calendar query filter and exact-match guard before deletion |

## Usage Example

```bash
# Set required environment variables
export FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL="svc@project.iam.gserviceaccount.com"
export FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n..."

# Run against one or more users
go run delete-events.go --users john@example.com,jane@example.com
```

The tool pages through up to 1,000 events at a time, skipping any events created *after* the run started (to avoid deleting freshly-created entries), and logs progress every 10 deletions per user. All users are processed in parallel; the process exits only after every goroutine completes.

## Notes

- Requires the `calendar.events` and `calendar.settings.readonly` OAuth2 scopes.
- The private key value supports `\n` as a literal escape sequence (automatically replaced with real newlines).
