Bulk-reschedules Google Calendar maintenance events for multiple users by updating all future occurrences of a specific event title to a new date/time using service account impersonation.

## Key Components

| Symbol | Description |
|--------|-------------|
| `main()` | Parses `--users` and `--datetime` flags, then spawns one goroutine per user to list and update matching calendar events in parallel |
| `withRetry()` | Wraps any Google API call with exponential backoff (up to 60 min) — retries only on rate-limit errors, treats all others as permanent failures |
| `isRateLimited()` | Detects Google API quota/rate-limit responses via `googleapi.Error` HTTP status codes and message strings |
| `serviceEmail` / `privateKey` | Service account credentials read from `FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL` and `FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY` env vars |
| `eventTitle` | Constant `"💻🚫 Scheduled maintenance"` — the only event summary targeted for rescheduling |

## Usage Example

```bash
# Set required credentials
export FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL="service@project.iam.gserviceaccount.com"
export FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n..."

# Move maintenance events to a new time for multiple users
go run move-events.go \
  --users john@example.com,jane@example.com \
  --datetime 2024-04-01T10:00:00Z
```

**Behavior notes:**
- Only events **after** the new target datetime are moved (past events are skipped)
- Events created **after** the script starts are skipped to avoid moving newly created events
- Each event is rescheduled to a **30-minute** window starting at `--datetime`
- Progress is logged every 10 events per user
