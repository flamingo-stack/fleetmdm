Retrieves and summarizes scheduled maintenance calendar events from the primary Google Calendar of one or more specified users, using service account impersonation with retry logic for rate limiting.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `serviceEmail` / `privateKey` | `var` | Google service account credentials loaded from `FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL` and `FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY` environment variables |
| `eventTitle` | `const` | Hardcoded event title filter: `"💻🚫 Scheduled maintenance"` |
| `regexMachineName` | `var` | Regex to extract the machine hostname from the event description body |
| `main()` | `func` | Accepts `--users` flag, fans out goroutines per user, prints per-event rows, then prints a summary of totals, counts by date, and duplicate machine entries |
| `withRetry()` | `func` | Wraps a Calendar API call with exponential backoff (up to 60 minutes) retrying only on rate-limit errors |
| `isRateLimited()` | `func` | Detects HTTP 429 or quota-related HTTP 403 responses from the Google API |

## Usage Example

```bash
# Set credentials
export FLEET_TEST_GOOGLE_CALENDAR_SERVICE_EMAIL="svc@project.iam.gserviceaccount.com"
export FLEET_TEST_GOOGLE_CALENDAR_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n..."

# Run against one or more users
go run get-events.go --users john@example.com,jane@example.com
```

**Sample output:**

```text
2024-03-15T09:00:00Z created_at:2024-03-14T08:00:00Z user:john@example.com machine:Johns-MacBook-Pro
2024-03-15T09:00:00Z created_at:2024-03-14T08:00:00Z user:jane@example.com machine:NOT_FOUND

Summary:
User: john@example.com, Total: 1
User: john@example.com, Date: 2024-03-15, Count: 1
User: jane@example.com, Total: 1
```

## Notes

- Events are queried from the `primary` calendar, ordered by `startTime`, paginated in batches of 1,000.
- A machine is flagged as a duplicate if more than one matching event references the same hostname.
