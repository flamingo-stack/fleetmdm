A command-line test utility for the `open` package that launches the system's default browser at a specified URL.

## Key Components

- **`main()`** — Parses the `-url` flag and invokes `open.Browser()` to open the given URL in the default browser. Prints an error message if the URL is missing or if the browser fails to open.

## Usage Example

```bash
# Open a URL in the default browser
go run main.go -url https://example.com

# Missing flag produces a usage hint
go run main.go
# Output: Please provide a URL to open using the -url flag
```

## Flags

| Flag | Type | Description |
|------|------|-------------|
| `-url` | `string` | The URL to open in the default browser (required) |
