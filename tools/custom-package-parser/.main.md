A CLI utility that extracts and displays metadata from software installer packages, supporting both local file paths and remote URLs as input sources.

## Key Components

- **`main`** — Entry point that parses `-url` and `-path` flags, routing to the appropriate processing function. Supports single files, directories of packages, and remote URLs.
- **`output`** — Formats and prints installer metadata (name, bundle identifier, package IDs, version) to stdout.
- **`processPackageFromUrl`** — Downloads a remote installer via HTTP (with a size limit enforced by `MaxSoftwareInstallerSize`) and extracts its metadata.
- **`processPackageFromLocal`** — Opens a local installer file and extracts its metadata.

## Usage Example

```bash
# Extract metadata from a remote package
go run main.go -url https://example.com/installer.pkg

# Extract metadata from a local file
go run main.go -path /tmp/installer.pkg

# Extract metadata from all packages in a directory
go run main.go -path /tmp/packages/
```

**Sample output:**

```text
- Name: 'Google Chrome'
- Bundle Identifier: 'com.google.Chrome'
- Package IDs: 'com.google.Chrome.pkg'
- Version: 120.0.6099.109
```

> `-url` and `-path` are mutually exclusive. When a directory is provided via `-path`, hidden files (prefixed with `.`) and subdirectories are skipped automatically.
