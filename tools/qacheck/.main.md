CLI tool that scans a GitHub Projects v2 board for issues/PRs in the "✔️Awaiting QA" column and reports any that have an unchecked test-plan confirmation checklist item.

## Key Components

| Symbol | Description |
|---|---|
| `Item` | GraphQL-mapped struct representing a project item (Issue or PR) with field values |
| `main()` | Entry point; parses flags, authenticates via `GITHUB_TOKEN`, fetches and filters items |
| `fetchProjectID()` | Queries the GitHub GraphQL API to resolve a project number to its node ID |
| `fetchItems()` | Fetches up to `limit` project items from a ProjectV2 node |
| `inAwaitingQA()` | Checks whether an item's single-select field matches the `awaitingQAColumn` value |
| `hasUncheckedTestPlanLine()` | Returns `true` if the body contains an unchecked `- [ ]` confirmation line but no checked variant |
| `getBody/Title/Number/URL()` | Helper accessors that return the correct field depending on whether the item is an Issue or PR |

## Usage Example

```bash
export GITHUB_TOKEN=ghp_yourTokenHere

go run main.go \
  -org your-github-org \
  -project 42 \
  -limit 200
```

**Sample output:**

```text
Found 2 items in "✔️Awaiting QA" with UNCHECKED test-plan confirmation:

❌ #1234 – Fix login redirect bug
   https://github.com/your-org/your-repo/issues/1234

❌ #1287 – Update user profile API
   https://github.com/your-org/your-repo/pull/1287
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `-org` | *(required)* | GitHub organization login |
| `-project` | *(required)* | Project board number |
| `-limit` | `100` | Max items to scan (no pagination) |

## Notes

- Requires a `GITHUB_TOKEN` environment variable with `read:org` and `project` scopes.
- Pagination is intentionally omitted; increase `-limit` if your board exceeds the default.
- An item is only flagged if the unchecked line is **present** — missing checklist items are ignored.
