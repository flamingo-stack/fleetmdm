Entry point for the `migration-cleanup` CLI tool, which detects and fixes Fleet database migration renumbering by analyzing git history and generating corrective SQL statements.

## Key Components

- **`main()`** – Bootstraps the Cobra CLI, wires up config management, and dispatches to `run()`.
- **`options`** – Struct holding all CLI flags: git checkout path, branch, output file, run mode (`--dry-run` / `--apply`), and MySQL/TLS connection settings.
- **`newRootCmd()`** – Defines the `migration-cleanup` Cobra command and registers all flags.
- **`run()`** – Core orchestration: validates flags, resolves the git branch, finds rename commits, extracts version ID remappings, connects to MySQL (if needed), generates SQL, and either writes output, dry-runs, or applies the fix.
- **`git()`** – Thin wrapper around `exec.Command("git", ...)` scoped to a checkout directory.
- **`resolveBranch()`** – Resolves a branch name as a local ref or `origin/<branch>`.
- **`getMergeBase()`** – Finds the common ancestor between `main` and the target branch.
- **`findRenameCommits()`** – Uses `git log -M --diff-filter=R` to locate commits that renamed migration files.
- **`extractRenames()`** – Parses `git diff-tree` output to build `migrationRename` structs with old/new version IDs.
- **`exitError`** – Custom error type carrying an exit code and optional message for controlled `os.Exit` behavior.
- **`hideUnneededFleetConfigFlags()`** – Suppresses non-MySQL Fleet config flags from the help output.

## Usage Example

```bash
# Generate corrective SQL to stdout
migration-cleanup \
  --checkout /path/to/fleet \
  --branch my-feature-branch \
  --db-host localhost \
  --db-name fleet

# Dry-run: connect to MySQL, simulate, verify
migration-cleanup \
  --checkout /path/to/fleet \
  --branch my-feature-branch \
  --db-host localhost \
  --db-name fleet \
  --db-user fleet \
  --dry-run

# Apply the fix in a transaction
migration-cleanup \
  --checkout /path/to/fleet \
  --branch my-feature-branch \
  --db-host localhost \
  --db-name fleet \
  --db-user fleet \
  --apply \
  --output fix.sql
```
