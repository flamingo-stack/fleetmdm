Entry point for **dibble**, Fleet's test data seeder CLI tool. Delegates argument parsing and execution to the `command` package, then handles top-level error reporting and process exit codes.

## Key Components

| Symbol | Description |
|---|---|
| `main()` | Passes `os.Args[1:]` to `command.Execute`, suppresses duplicate stderr output for seeder-specific errors (`ErrSeederFailed`), and exits with code `1` on failure |

## Usage Example

```bash
# Interactive wizard (no arguments)
dibble

# Seed only users
dibble users

# Seed all test data
dibble all
```

```go
// Error handling behaviour in main():
// - command.ErrSeederFailed → already reported by the seeder; exit silently
// - any other error (config, network, etc.) → printed to stderr as "dibble: <err>"
if !errors.Is(err, command.ErrSeederFailed) {
    fmt.Fprintln(os.Stderr, "dibble:", err)
}
os.Exit(1)
```
