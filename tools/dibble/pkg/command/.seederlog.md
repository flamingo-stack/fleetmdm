A minimal adapter that bridges the package-level `printf` helper to the `seed.Logger` interface, avoiding a circular import between the `command` and `seed` packages.

## Key Components

- **`seederLogger`** — Zero-value struct implementing the `seed.Logger` interface
- **`Printf(format string, a ...any)`** — Delegates all calls directly to the package-level `printf` helper

## Usage Example

```go
// Pass seederLogger to any seed function expecting a seed.Logger
seeder := seed.NewSeeder(seederLogger{})
seeder.Run(ctx)
```

## Notes

- Stateless by design — `seederLogger` carries no fields and can be instantiated with `seederLogger{}`
- Keeps the `seed` package decoupled from the `command` package by depending only on an interface, not a concrete import
