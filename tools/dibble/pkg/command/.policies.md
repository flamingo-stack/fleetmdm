Defines the `policies` subcommand for the `dibble` CLI tool, which seeds global Fleet policies and per-team policies against a running Fleet instance.

## Key Components

- **`newPoliciesCmd()`** — Constructs and returns a `*cobra.Command` for the `policies` subcommand. Reads the `--count` flag, resolves the active theme and existing teams, then delegates to `seed.Policies()` to create the policy records. Prints a summary and surfaces any errors.
- **`listExistingTeams(c *Client)`** — Helper that fetches the current team list from the Fleet API (`/api/latest/fleet/fleets`) and returns them as `[]seed.Team`. Used by this subcommand (and potentially others) so per-team seeding works even when the `teams` subcommand has not been run in the same session.

## Usage Example

```bash
# Seed 5 global policies (default) plus 2 per existing team
dibble policies

# Seed 20 global policies plus 2 per existing team
dibble policies --count 20
```

```go
// Registering the subcommand in the root command
rootCmd.AddCommand(newPoliciesCmd())
```

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--count` | `5` | Number of global policies to seed; 2 additional policies are created per existing team |

## Notes

- Requires a valid Viper config (checked via `requireConfig()`) and a reachable Fleet instance.
- Fetches up to 500 teams/fleets per page from the Fleet API.
- Results are printed via `res.Summary()`; non-fatal errors are collected and reported at the end through `reportErrors`.
