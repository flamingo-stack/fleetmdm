Thin HTTP client wrapper for the Fleet API, providing Bearer token authentication, JSON serialization, dry-run support, and multipart file uploads.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Client` | Core struct holding base URL, auth token, HTTP client, and `dryRun`/`verbose` flags |
| `newClientFromViper()` | Constructs a `Client` from Viper config keys (`fleet-url`, API token, `--insecure`, etc.) |
| `AlreadyExistsError` | Sentinel error for HTTP 409/422-with-"already exists" responses; allows seeders to treat conflicts as idempotent |
| `Client.do()` | Internal dispatcher: builds request, sets auth/content-type headers, reads and decodes JSON response |
| `Client.Get/Post/Patch/Delete` | Typed convenience wrappers around `do()` |
| `Client.PostMultipart()` | Uploads mixed form fields and named files (scripts, profiles, installers) using `seed.MultipartFile` |

## Usage Example

```go
// Client is constructed from Viper config — set flags or env vars before calling:
// viper.Set("fleet-url", "https://fleet.example.com")
// viper.Set("api-token", "fleettoken123")

client, err := newClientFromViper()
if err != nil {
    log.Fatal(err)
}

// JSON GET
var result map[string]any
if err := client.Get("/api/v1/fleet/hosts", &result); err != nil {
    log.Fatal(err)
}

// JSON POST
if err := client.Post("/api/v1/fleet/labels", map[string]string{"name": "arm64"}, nil); err != nil {
    var ae *AlreadyExistsError
    if errors.As(err, &ae) {
        log.Println("label already exists, skipping")
    }
}

// Multipart upload
err = client.PostMultipart(
    "/api/v1/fleet/scripts",
    map[string]string{"team_id": "1"},
    []seed.MultipartFile{{FieldName: "script", Filename: "setup.sh", Content: scriptBytes}},
    nil,
)
```

## Notes

- `--insecure` disables TLS verification for self-signed dev certificates, mirroring `fleetctl` behaviour.
- Dry-run mode (`--dry-run`) prints the method/path without issuing any real HTTP requests.
