Registers the `labels` CLI subcommand for seeding dynamic, query-based labels into a Fleet instance using the `dibble` seed utility.

## Key Components

- **`newLabelsCmd()`** — Constructs and returns a `*cobra.Command` that wires together config validation, client initialization, theme resolution, and label seeding via `seed.Labels`.

## Usage Example

```bash
# Seed the default 5 dynamic labels
dibble labels

# Seed a custom number of labels
dibble labels --count 10
```

```go
// Registered in the root command
rootCmd.AddCommand(newLabelsCmd())
```

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--count` | `5` | Number of dynamic labels to seed |

## Notes

- Requires a valid configuration (enforced by `requireConfig()`) and a connected Fleet client before seeding begins.
- Delegates seeding logic entirely to [`seed.Labels`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/dibble/pkg/seed/labels.go), passing the active client, logger, theme, and count.
- Outputs a human-readable summary and surfaces any seeding errors via `reportErrors`.
