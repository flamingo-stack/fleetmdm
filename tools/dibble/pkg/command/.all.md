Orchestrates the `dibble all` command, which seeds every Fleet entity type in dependency order using sensible defaults. Also exposes `runAll` for reuse by the interactive wizard's "everything" preset.

## Key Components

| Symbol | Description |
|---|---|
| `allCounts` | Configuration struct holding per-entity counts and DSN overrides for MySQL-backed seeders (activities, IDP, CAs) |
| `defaultAllCounts()` | Returns pre-configured defaults (5 users, 3 teams, 5 policies, etc.) with MySQL DSN pointing to `localhost:3306` |
| `runAll()` | Core execution function; runs all seeders in dependency order, collects errors, and reports elapsed time |
| `newAllCmd()` | Builds the `cobra.Command` for `dibble all` with flag overrides for counts and DSNs |

## Usage Example

```bash
# Run with all defaults
dibble all

# Override specific counts
dibble all --users 10 --teams 5

# Enable MySQL-backed seeders (skipped by default)
dibble all \
  --activity-batches 3 \
  --activity-dsn "fleet:secret@tcp(db.internal:3306)/fleet" \
  --idp-user-count 20 \
  --cas 4
```

```go
// Reuse runAll from the wizard preset
counts := defaultAllCounts()
counts.Users = 10
counts.EnrollSecrets = false
if err := runAll(client, theme, counts); err != nil {
    return err
}
```

## Notes

- Seeders run in dependency order: **teams → users → enroll secrets → labels → policies → reports → scripts → profiles → software → CAs → activities → IDP**
- MySQL-backed seeders (`activities`, `IDP`, `CAs`) are **skipped by default** (count = 0) since they require a DSN rather than just an API token
- All errors are collected and surfaced after the full run; a partial failure exits non-zero without aborting remaining seeders
