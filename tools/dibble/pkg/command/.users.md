Defines the `users` CLI subcommand for the `dibble` seeding tool, which seeds Fleet with themed, role-rotating user accounts.

## Key Components

- **`newUsersCmd()`** — Constructs and returns a Cobra command (`dibble users`) that reads config, builds a Fleet client, resolves the active theme, and delegates seeding to `seed.Users()`.
- **`--count` flag** — Integer flag (default `5`) controlling how many users are seeded.
- **`ErrSeederFailed`** — Sentinel error returned when one or more seeder operations fail; signals a non-zero exit to `main.go` without duplicating error output.
- **`reportErrors(errs []error)`** — Iterates over collected errors, writes each to stderr via `warnf`, and returns `ErrSeederFailed` if any exist.

## Usage Example

```bash
# Seed 5 users (default)
dibble users

# Seed 20 users
dibble users --count 20
```

```go
// Wired into the root command in root.go
rootCmd.AddCommand(newUsersCmd())
```

The command requires a valid config (enforced by `requireConfig()`) and an active theme (resolved by `currentTheme()`). Results are summarised via `res.Summary()`, and any per-user errors are surfaced through `reportErrors` before the process exits non-zero.
