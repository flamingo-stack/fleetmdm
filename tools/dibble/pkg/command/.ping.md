Implements the `ping` CLI subcommand, which verifies connectivity to the Fleet API by fetching and displaying version information.

## Key Components

- **`newPingCmd()`** — Constructs and returns a `*cobra.Command` for the `ping` subcommand. On execution, it validates the local config, initializes a Fleet API client, calls `GET /api/latest/fleet/version`, and prints the server's version, branch, and build details on success.

## Usage Example

```bash
# Run the ping command to verify Fleet API connectivity
dibble ping

# Example output:
# Fleet 4.52.0 (branch main, build abc1234) — connection OK 🌱
```

```go
// Registration in root command (typical pattern)
rootCmd.AddCommand(newPingCmd())
```

## Notes

- Requires a valid configuration to be present; calls `requireConfig()` before attempting any network request.
- Uses `newClientFromViper()` to build the HTTP client from the current Viper-backed configuration.
- The response struct maps the JSON fields `version`, `branch`, and `build` returned by the Fleet version endpoint.
