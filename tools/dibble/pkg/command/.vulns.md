Defines the `vulns` subcommand for the `dibble` CLI tool, which seeds software inventory rows directly into the Fleet MySQL database to exercise the vulnerability scanner.

## Key Components

- **`newVulnsCmd()`** — Constructs and returns a `*cobra.Command` that accepts platform-specific row counts (`--macos`, `--ubuntu`, `--windows`) and a MySQL DSN, then delegates to `seed.Vulns` to perform the inserts.

## Flags

| Flag | Default | Description |
|---|---|---|
| `--dsn` | `fleet:insecure@tcp(localhost:3306)/fleet` | MySQL connection string |
| `--macos` | `0` | Number of macOS software rows to insert |
| `--ubuntu` | `0` | Number of Ubuntu software rows to insert |
| `--windows` | `0` | Number of Windows software rows to insert |

## Usage Example

```bash
# Seed 500 macOS and 250 Windows software rows into the local dev database
dibble vulns --macos 500 --windows 250

# Target a non-default MySQL instance
dibble vulns --dsn "fleet:secret@tcp(db.internal:3306)/fleet" --ubuntu 1000
```

> **Note:** This command writes only to the `software` table. Host associations (`host_software`, `software_cpe`) are **not** created, so vulnerabilities will not surface against any host until those rows are populated via real ingest or a complementary seeder. For end-to-end vulnerable-host scenarios, use `osquery-perf` or the legacy `seed_vuln_data` tool instead.
