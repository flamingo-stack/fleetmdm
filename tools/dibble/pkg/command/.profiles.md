Registers the `profiles` CLI subcommand, which seeds MDM configuration profiles (Apple `.mobileconfig` and Windows `.xml`) into a Fleet instance using the `seed.Profiles` function.

## Key Components

| Symbol | Description |
|---|---|
| `newProfilesCmd()` | Constructs and returns the `profiles` `*cobra.Command` |
| `--count` flag | Integer flag controlling how many global profiles to seed (default: `4`); each team additionally receives 2 profiles |

## Usage Example

```bash
# Seed the default 4 global profiles (plus 2 per team)
dibble seed profiles

# Seed 10 global profiles (plus 2 per team)
dibble seed profiles --count 10
```

```go
// Registering the subcommand under a parent seed command
parentCmd.AddCommand(newProfilesCmd())
```

## Notes

- Calls `requireConfig()` and `newClientFromViper()` before executing — a valid Dibble config file must be present.
- Uses `listExistingTeams` to discover all current Fleet teams; each team receives an additional 2 profiles on top of the global count.
- Results are summarised via `res.Summary()` and any seeding errors are surfaced through `reportErrors`.
