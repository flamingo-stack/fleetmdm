Implements the `dibble hosts` subcommand, which automates the process of selecting a Fleet team, fetching its enroll secret, and launching `osquery-perf` to simulate hosts against that team.

## Key Components

| Symbol | Description |
|---|---|
| `newHostsCmd()` | Constructs the `cobra.Command` for `dibble hosts`, wiring flags and the interactive pick → secret fetch → run flow |
| `pickedTeam` | Struct representing the resolved team selection; `ID == 0` means global/no-team scope |
| `pickHostsTeam()` | Resolves the target team via `--team-name`, `--team-id`, or an interactive `survey.Select` radio prompt |
| `fetchEnrollSecret()` | Retrieves the first enroll secret from the Fleet API for a specific team or the global scope |
| `findFleetRepoRoot()` | Walks up the directory tree from `cwd` to locate the Fleet repo root containing `cmd/osquery-perf/agent.go` |
| `buildOsqueryPerfCmd()` | Assembles the `go run` argument slice and a human-readable display string for the osquery-perf invocation |
| `runOsqueryPerf()` | Executes osquery-perf with stdin/stdout/stderr passthrough, forwarding `SIGINT`/`SIGTERM` to the child process |
| `maybeRunOsqueryPerf()` | Wraps `runOsqueryPerf` with an interactive confirm prompt; falls back to print-only in non-TTY environments |

## Usage Example

```go
// Typical interactive usage (interactive team picker + confirm prompt):
// dibble hosts

// Skip the picker and run immediately against a named team:
// dibble hosts --team-name "Workstations" --run

// Global scope, print command only (no run):
// dibble hosts --team-id 0 --print-only

// Spin up 5 simulated hosts against team ID 3:
// dibble hosts --team-id 3 --host-count 5 --run
```

**Flag summary:**

| Flag | Default | Description |
|---|---|---|
| `--team-id` | `-1` | Team ID to enroll into; `-1` triggers interactive pick, `0` = global |
| `--team-name` | `""` | Team name (overrides `--team-id`) |
| `--host-count` | `1` | Number of simulated hosts passed to osquery-perf |
| `--run` | `false` | Skip confirm prompt and run immediately |
| `--print-only` | `false` | Skip confirm prompt and print command only |
