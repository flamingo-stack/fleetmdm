Registers a `teams` CLI subcommand for seeding Fleet team (aka fleet) records into a Fleet instance using the `dibble` seeder toolchain.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `newTeamsCmd` | `func() *cobra.Command` | Constructs and returns the `teams` Cobra command with its `--count` flag |
| `--count` | `int` flag | Number of teams to seed; defaults to `3` |

## Usage Example

```bash
# Seed the default 3 teams
dibble seed teams

# Seed a custom number of teams
dibble seed teams --count 10

# Alias also works
dibble seed fleets --count 5
```

```go
// Wiring the command into a parent Cobra command
rootCmd.AddCommand(newTeamsCmd())
```

The command requires a valid configuration (via `requireConfig`) and an active Fleet client (via `newClientFromViper`). It delegates seeding to [`seed.Teams`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/dibble/pkg/seed/teams.go), passing the client, a logger, the resolved theme, and the requested count. After seeding, it prints a human-readable summary and surfaces any errors through `reportErrors`.
