Provides lightweight, package-level logging helpers for the `command` package, routing formatted output to stdout and stderr with consistent prefixes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `stdoutish` | `io.Writer` | Package-level stdout writer; swappable for test capture |
| `stderrish` | `io.Writer` | Package-level stderr writer; swappable for test capture |
| `printf` | `func` | Writes a formatted line to stdout, prefixed with the tapir snout glyph from `themes` |
| `warnf` | `func` | Writes a formatted warning line to stderr, prefixed with `dibble:` |

## Usage Example

```go
// Normal informational output (stdout, tapir snout prefix)
printf("deploying %s to %d hosts", "policy.yaml", 42)
// → 🦛 deploying policy.yaml to 42 hosts

// Warning/error output (stderr, "dibble:" prefix)
warnf("could not reach host %s: %v", "fleet-01", err)
// → dibble: could not reach host fleet-01: <error>

// Swapping writers in tests
func TestOutput(t *testing.T) {
    var buf bytes.Buffer
    stdoutish = &buf
    defer func() { stdoutish = os.Stdout }()

    printf("hello %s", "world")
    assert.Contains(t, buf.String(), "hello world")
}
```

## Notes

- Both writers are unexported package-level variables, making them testable without exposing them to callers outside the package.
- `printf` appends a `\n` newline automatically; callers should not include one in the format string.
