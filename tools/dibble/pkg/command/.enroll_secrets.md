Seeds per-team enroll secrets in Fleet MDM using the `dibble` CLI tool, registering a unique enrollment credential for every existing team.

## Key Components

- **`newEnrollSecretsCmd()`** — Constructs and returns a `*cobra.Command` for the `enroll-secrets` subcommand (alias: `enrollsecrets`). Validates config, initializes a Fleet API client, lists all teams, and delegates seeding to `seed.EnrollSecrets`.

## Usage Example

```bash
# Seed enroll secrets for all teams
dibble enroll-secrets

# Using the alias
dibble enrollsecrets
```

```go
// Registering the command in a parent command
rootCmd.AddCommand(newEnrollSecretsCmd())
```

## Notes

- Requires a valid Dibble configuration (validated via `requireConfig()`).
- Only seeds **per-team** enroll secrets — the global enroll secret is intentionally left unchanged.
- Seeded secrets appear in the Fleet UI under **Settings → [team] → Add hosts → Show enroll secret**.
- These are enrollment credentials for `fleetd` agents joining a team, **not** Fleet secret variables used in profiles or scripts.
- Results and any errors are reported via `res.Summary()` and `reportErrors`.
