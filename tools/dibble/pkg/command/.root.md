Defines the root Cobra command, configuration wiring, and entry point for the `dibble` CLI tool used to seed test data into a Fleet server.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Execute(args []string) error` | Entry point called by `main.go`; routes no-argument invocations to the interactive wizard, otherwise delegates to Cobra |
| `newRootCmd() *cobra.Command` | Builds the root command, registers all persistent flags, binds Viper for env/config-file resolution, and registers all subcommands |
| `shouldRunWizard(args []string) bool` | Detects flag-only or empty invocations to trigger the interactive wizard |
| `initConfig()` | Cobra `OnInitialize` hook; loads `~/.dibble.yaml` or the path from `--config` |
| `requireConfig() error` | Validates that `fleet-url` and `api-token` are present before any subcommand executes |
| `currentTheme() (themes.Theme, error)` | Resolves the active theme and expands the `"auto"` suffix to a stable per-process random hex string |
| `autoSuffix() string` | Generates (and caches) a 4-character cryptographically random hex suffix for the lifetime of the process |
| `newVersionCmd()` | Prints build-time version, commit, and date |

**Configuration precedence** (highest → lowest): CLI flag → environment variable (`FLEET_URL`, `FLEET_API_TOKEN`, `DIBBLE_*`) → `~/.dibble.yaml` → built-in defaults.

## Usage Example

```go
// cmd/dibble/main.go
package main

import (
    "fmt"
    "os"

    "github.com/fleetdm/fleet/v4/tools/dibble/pkg/command"
)

func main() {
    if err := command.Execute(os.Args[1:]); err != nil {
        fmt.Fprintf(os.Stderr, "dibble: %v\n", err)
        os.Exit(1)
    }
}
```

```bash
# Interactive wizard (no args)
dibble

# Seed all resources, skip TLS verification
dibble all --fleet-url https://localhost:8080 --api-token $TOKEN --insecure

# Auto-suffix every generated name to avoid collisions
dibble teams --fleet-url https://fleet.example.com --api-token $TOKEN --suffix auto

# Dry-run to preview actions without calling the API
dibble policies --dry-run
```
