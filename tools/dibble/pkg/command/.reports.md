Defines the `reports` CLI subcommand for the `dibble` seeding tool, which creates fake saved reports (formerly called "queries") in a Fleet MDM instance for testing and development purposes.

## Key Components

- **`newReportsCmd()`** — Constructs and returns a `*cobra.Command` that seeds saved reports. Reads configuration via Viper, initializes a Fleet API client, resolves the current theme, and delegates to `seed.Reports()` to perform the actual seeding across global scope and all existing teams.

## Usage Example

```bash
# Seed the default 5 global reports (plus 1 per team)
dibble reports

# Seed a custom number of global reports
dibble reports --count 10

# Also accessible via the 'queries' alias
dibble queries --count 3
```

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--count` | `5` | Number of global reports to seed; additionally seeds 1 report per existing team |

## Notes

- Requires a valid Dibble config to be present (enforced by `requireConfig()`).
- Reuses shared helpers: `newClientFromViper()`, `currentTheme()`, and `listExistingTeams()`.
- Errors from individual seed operations are collected and surfaced via `reportErrors()` rather than halting early.
