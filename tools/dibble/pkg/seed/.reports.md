Seeds Fleet MDM reports (saved SQL queries with execution intervals) for both global and team-scoped contexts via the Fleet API.

## Key Components

### `Reports(c Client, log Logger, theme themes.Theme, teams []Team, count int) Result`

Main seeding function that creates two categories of reports:

- **Global reports** — creates `count` reports cycling through 5 example SQL queries, 3 intervals (`0`, `60`, `3600` seconds), and alternating `observer_can_run` permissions
- **Team-scoped reports** — creates one additional report per team with `interval: 0` and a team-scoped `team_id`

Names are derived from the theme's policy name pool (reused since they read naturally as query names). Duplicate reports are silently skipped via `IsAlreadyExists` detection.

## Key Data

| Field | Values |
|---|---|
| `interval` | `0` (never), `60s`, `3600s` — cycles via `i % 3` |
| `logging` | `"snapshot"` (global reports only) |
| `observer_can_run` | alternates `true`/`false` per index |
| `platform` | cycles through `seededPlatforms` |

## Usage Example

```go
result := seed.Reports(client, logger, theme, teams, 10)
fmt.Printf("created=%d skipped=%d errors=%d\n",
    result.Created, result.Skipped, len(result.Errors))
```

This creates 10 global reports plus one report per entry in `teams`, posting each to `/api/latest/fleet/reports`.
