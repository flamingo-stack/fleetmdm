Generates and assigns a random per-team enroll secret to each Fleet team via the Fleet API, enabling fleetd agents to join their designated team.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `EnrollSecrets` | Function | Iterates over provided teams and PATCHes a freshly generated enroll secret to each one via `/api/latest/fleet/fleets/{id}/secrets` |
| `randomEnrollSecret` | Function | Produces a `dibble-` prefixed 16-byte cryptographically random hex string; falls back to a static placeholder if `crypto/rand` fails |

## Usage Example

```go
teams := []seed.Team{
    {ID: 1, Name: "workstations"},
    {ID: 2, Name: "servers"},
}

result := seed.EnrollSecrets(client, logger, teams)
fmt.Printf("created=%d skipped=%d errors=%d\n",
    result.Created, result.Skipped, len(result.Errors))
```

## Notes

- **Global enroll secret is intentionally untouched** — modifying it would invalidate already-enrolled hosts; rotate it deliberately outside this seeder.
- **Secrets are never logged** — only the team name and ID appear in log output to avoid credential leaks in shell history or log aggregators.
- Seeded secrets are visible in the Fleet UI under **Settings → [team] → Add hosts → Show enroll secret**.
- This seeds *enroll secrets* (agent join credentials), not *Fleet secret variables* (profile/script template substitutions), which are a separate concern.
