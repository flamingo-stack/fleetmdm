Defines the shared foundation for all entity-seeding operations in the `dibble` tool, providing core interfaces, types, and utilities used by both CLI subcommands and the interactive wizard.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Client` | Interface | HTTP client abstraction with `Get`, `Post`, `Patch`, `Delete`, and `PostMultipart` methods; designed for test faking |
| `MultipartFile` | Struct | Represents a single file part in a multipart upload, carrying field name, filename, and raw content |
| `AlreadyExistsError` | Interface | Sentinel error type for server-side conflict responses; seeders treat this as a soft success |
| `IsAlreadyExists` | Function | Duck-typed helper that checks whether any `error` value represents a conflict without importing concrete types |
| `Result` | Struct | Aggregates per-entity seeding outcomes: created count, skipped count, and any accumulated errors |
| `Result.Summary()` | Method | Formats a `Result` into a single human-readable status line |
| `Logger` | Interface | Minimal `Printf`-style writer that decouples seeders from the main package's output handling |

## Usage Example

```go
// Implement Client with a real HTTP client or a test fake.
var client seed.Client = myHTTPClient{}

// Run a seeder and inspect results.
result := seed.Result{Entity: "teams"}

err := client.Post("/api/v1/fleet/teams", payload, &out)
if seed.IsAlreadyExists(err) {
    result.Skipped++
} else if err != nil {
    result.Errors = append(result.Errors, err)
} else {
    result.Created++
}

fmt.Println(result.Summary())
// Output: teams: 1 created, 0 skipped
```

## Notes

- All seeder implementations live in sibling files within this package; `seed.go` intentionally contains no seeding logic itself.
- `IsAlreadyExists` uses `errors.As` for interface matching, keeping the package free of dependencies on the concrete HTTP client.
