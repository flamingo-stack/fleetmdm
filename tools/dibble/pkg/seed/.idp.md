Seeds Fleet MDM IDP linkage tables (`mdm_idp_accounts`, `host_mdm_idp_accounts`, `scim_users`, `host_scim_user`) directly via MySQL, bypassing the public API to simulate MDM enrollment and SCIM sync flows.

## Key Components

| Symbol | Description |
|---|---|
| `IDPOptions` | Configuration struct: MySQL DSN, user count, host count |
| `IDP()` | Main entry point; fetches users/hosts via Fleet API, writes IDP/SCIM rows via MySQL |
| `upsertIDPAccount()` | Creates or reuses a `mdm_idp_accounts` row keyed by email, returning its UUID |
| `upsertSCIMUser()` | Creates or reuses a `scim_users` row keyed by `user_name` (email), returning its numeric ID |
| `assignHostToIDPAccount()` | `INSERT IGNORE` into `host_mdm_idp_accounts` (keyed by `host_uuid`) |
| `assignHostToSCIMUser()` | `INSERT IGNORE` into `host_scim_user` (keyed by `host_id`) |
| `fetchUsersForIDP()` | Fetches most-recently-created Fleet users via the Fleet REST API |
| `fetchHostsForIDP()` | Fetches enrolled hosts via the Fleet REST API |
| `splitFullName()` | Splits a display name into SCIM `given_name` / `family_name` fields |

## Usage Example

```go
result := seed.IDP(ctx, fleetClient, logger, seed.IDPOptions{
    DSN:       "fleet:fleet@tcp(localhost:3306)/fleet",
    UserCount: 5,  // seed 5 most-recently-created users
    HostCount: 10, // assign 10 hosts round-robin to those users
})
if len(result.Errors) > 0 {
    log.Printf("IDP seed errors: %v", result.Errors)
}
log.Printf("created=%d skipped=%d", result.Created, result.Skipped)
```

**Round-robin assignment**: host `i` receives `seeded_user[i % len(users)]`, so `HostCount` can safely exceed `UserCount`. Both the MDM account UUID and SCIM user ID for each user are paired before assignment, keeping the two linkage tables aligned. All writes are idempotent via `INSERT IGNORE` and email/`user_name` uniqueness checks.

> **Note**: Requires `dibble users` and osquery-perf enrollment to run first so Fleet has users and hosts to reference.
