Seeds Fleet MDM with global and per-team policies, rotating across platform targets (darwin, windows, linux, and combinations) to exercise all cross-platform UI code paths.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `seededPlatforms` | `[]string` | Rotation of platform values: `""` (all), `"darwin"`, `"windows"`, `"linux"`, `"darwin,windows,linux"` |
| `dummyPolicyQuery` | `const string` | A no-op SQL query (`SELECT 1 WHERE 1=1;`) that always returns compliant without alarming on a dev instance |
| `Policies` | `func` | Creates `count` global policies and 2 per-team policies via the Fleet API |

## Usage Example

```go
teams := []seed.Team{{ID: 1, Name: "Engineering"}, {ID: 2, Name: "IT"}}

result := seed.Policies(client, logger, themes.Star, teams, 10)

fmt.Printf("Created: %d, Skipped: %d, Errors: %d\n",
    result.Created, result.Skipped, len(result.Errors))
```

This creates:
- **10 global policies** — posted to `/api/latest/fleet/policies`
- **4 per-team policies** — 2 per team, posted to `/api/latest/fleet/fleets/{id}/policies`

Platform assignment cycles through `seededPlatforms` using `i % len(seededPlatforms)`, ensuring coverage of every platform filter in the Fleet UI. Duplicate policies are silently skipped via `IsAlreadyExists` detection.
