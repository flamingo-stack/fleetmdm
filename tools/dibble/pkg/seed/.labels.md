Seeds dynamic (query-based) Fleet labels via the Fleet API, cycling through a predefined set of osquery queries to populate each label.

## Key Components

- **`Labels(c Client, log Logger, theme themes.Theme, count int) Result`** — Main seeding function. Creates `count` labels using themed names and rotating query templates. Skips already-existing labels and collects errors without halting.

### Label Query Pool

Rotates through five osquery queries covering:

| Query | Purpose |
|---|---|
| `SELECT 1 WHERE 1=0` | Always-false (empty label) |
| `SELECT 1 FROM osquery_info` | All hosts running osquery |
| `platform = 'darwin'` | macOS hosts |
| `platform = 'windows'` | Windows hosts |
| `platform IN ('ubuntu','rhel','centos','debian')` | Linux hosts |

## Usage Example

```go
result := seed.Labels(client, logger, themes.Default, 10)
fmt.Printf("Created: %d, Skipped: %d, Errors: %d\n",
    result.Created, result.Skipped, len(result.Errors))
```

## Notes

- Only **dynamic (query-based)** labels are seeded. Manual labels require live host identifiers not available in synthetic data — use [`osquery-perf`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/osquery-perf) for those.
- Query assignment is round-robin via `i % len(labelQueries)`.
- Duplicate label names are silently skipped (`IsAlreadyExists` check).
