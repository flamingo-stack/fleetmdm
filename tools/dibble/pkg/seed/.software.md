Seeds Fleet MDM with custom software installers and Fleet-maintained apps by uploading embedded fixture files and calling the Fleet software API endpoints.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `installerFiles` | `embed.FS` | Embedded filesystem containing bundled installer fixtures from `data/installers/` |
| `extensionInstallers` | `map[string][]string` | Curated list of fixture filenames grouped by file extension (`.pkg`, `.deb`, `.msi`, `.exe`, `.rpm`, `.tar.gz`, `.ipa`) |
| `extensionScripts` | `map[string]struct` | Per-extension install/uninstall script overrides; required by Fleet's validator for `.tar.gz` and `.exe` uploads |
| `SoftwareOptions` | `struct` | Configuration for both seeders — `TeamID` (0 = global) and `MaintainedAppCount` |
| `SoftwareCustom` | `func` | Uploads all curated fixtures via `POST /api/latest/fleet/software/package` |
| `SoftwareMaintained` | `func` | Discovers and adds Fleet-maintained apps via the `fleet_maintained_apps` API |
| `isAlreadyAdded` | `func` | Detects Fleet's non-standard "already added/associated" error to safely skip duplicates |

## Usage Example

```go
client := NewFleetClient("https://fleet.example.com", apiToken)
logger := NewStdLogger()

opts := seed.SoftwareOptions{
    TeamID:             42,   // scope to team 42; use 0 for global
    MaintainedAppCount: 3,    // seed the first 3 Fleet-maintained apps
}

// Upload custom installers (.pkg, .deb, .msi, .exe, .rpm, .tar.gz, .ipa)
result := seed.SoftwareCustom(client, logger, opts)
fmt.Printf("created=%d skipped=%d errors=%d\n",
    result.Created, result.Skipped, len(result.Errors))

// Add Fleet-maintained apps from the server catalog
result = seed.SoftwareMaintained(client, logger, opts)
fmt.Printf("created=%d skipped=%d errors=%d\n",
    result.Created, result.Skipped, len(result.Errors))
```

> **Note:** Both functions are idempotent — already-existing packages and previously-added maintained apps are counted as `Skipped` rather than treated as errors.
