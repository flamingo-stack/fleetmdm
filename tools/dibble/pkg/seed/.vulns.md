Seeds the Fleet `software` table with plausible software inventory rows from embedded CSVs, enabling the background vulnerability scanner to process realistic data without requiring live hosts.

## Key Components

| Symbol | Description |
|---|---|
| `VulnsOptions` | Config struct — MySQL DSN, per-platform row counts (MacOS/Ubuntu/Windows), and batch size |
| `Vulns()` | Entry point; opens MySQL, iterates platforms, and delegates to `insertSoftware` |
| `mysqlDSN()` | Parses and re-formats a DSN safely, preserving existing query params while enabling `ParseTime` and optionally `MultiStatements` |
| `readCSV()` | Opens an embedded CSV from `vulnCSVs` (go:embed), strips the header, and returns data rows |
| `softwareChecksum()` | Computes an MD5 checksum matching `fleet.Software.ComputeRawChecksum` to satisfy the `idx_software_checksum` unique index |
| `insertSoftware()` | Batched `INSERT IGNORE` writer; pins execution to a single connection to scope `SET FOREIGN_KEY_CHECKS=0` safely |
| `csvField()` | Safe positional CSV field accessor with empty-string fallback for short rows |

## Usage Example

```go
result := seed.Vulns(ctx, logger, seed.VulnsOptions{
    DSN:      "fleet:password@tcp(localhost:3306)/fleet",
    MacOS:    200,
    Ubuntu:   150,
    Windows:  100,
    BatchSiz: 500,
})
if len(result.Errors) > 0 {
    log.Printf("seed errors: %v", result.Errors)
}
log.Printf("inserted %d software rows", result.Created)
```

**Scope note:** Only the `software` table is written. No `host_software` or `software_cpe` rows are created, so CVEs will not surface from these rows until Fleet's real ingest path wires up CPE associations.
