Provides the activity seeder for Fleet MDM, writing synthetic activity rows directly to MySQL (`activity_past` and `activity_host_past`) for UI/QA purposes without triggering webhooks or service-layer side effects.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ActivitiesOptions` | struct | Configuration for the seeder: DSN, actor identity, host ID, batch count, and category filter |
| `ActivityCategories` | `[]string` | Ordered list of valid category names used by CLI subcommands |
| `activityTemplatesByCategory` | `map[string][]fleet.ActivityDetails` | Maps each category to its zero-value activity templates; covers all `fleet.ActivityType*` structs |
| `fakePrefix` | `const` | `"*"` — prepended to all generated string values so seeded rows are visually distinct in the UI |
| `stringExample()` | func | Returns a deterministic, prefixed example string for a struct field based on its JSON tag or Go name |
| `setExampleFields()` | func | Reflects over an activity struct and fills every zero-value field with deterministic fake data |

### Supported Categories

`all`, `settings`, `profiles`, `scripts`, `software`, `hosts`, `users`, `teams`, `policies`, `queries`, `labels`, `certificates`

## Usage Example

```go
opts := seed.ActivitiesOptions{
    DSN:        "fleet:fleet@tcp(127.0.0.1:3306)/fleet",
    ActorID:    1,
    ActorName:  "Seed User",
    ActorEmail: "seed@example.com",
    HostID:     42,
    Batches:    1,
    Category:   seed.CategorySoftware, // or "all"
}

if err := seed.Activities(context.Background(), opts); err != nil {
    log.Fatal(err)
}
```

Seeded rows are non-idempotent — each call appends new rows. Generated string fields are prefixed with `*` plus a per-run tag (e.g., `*run-abc123 Example name`) so they are immediately identifiable in the Fleet UI.
