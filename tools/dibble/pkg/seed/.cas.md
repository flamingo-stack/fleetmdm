Seed utility that inserts fake Certificate Authority rows directly into MySQL, bypassing Fleet's service layer to avoid requiring live SCEP/DigiCert/NDES/EST endpoints during development or review seeding runs.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `CAOptions` | struct | Configuration for DSN connection string and batch count |
| `caRow` | struct | Mirror of the `certificate_authorities` table schema; encrypted blob fields default to NULL |
| `CAs` | func | Entry point — connects to MySQL, inserts one NDES row, then iterates `Count` batches of all other CA types |
| `caTemplates` | var | Slice of builder functions, one per non-NDES type: `custom_scep_proxy`, `custom_est_proxy`, `digicert`, `hydrant`, `smallstep` |
| `ndesRow` | func | Builds the single special-cased NDES row (name is fixed to `"NDES"` by Fleet's unique index) |
| `insertCA` | func | Executes the `INSERT INTO certificate_authorities` statement |
| `isDuplicateCAError` | func | Detects `idx_ca_type_name` / `Duplicate entry` MySQL errors so re-runs count as `Skipped` instead of `Errored` |

## Usage Example

```go
result := seed.CAs(ctx, logger, seed.CAOptions{
    DSN:   "fleet:fleet@tcp(localhost:3306)/fleet",
    Count: 3, // inserts 1 NDES + (3 × 5) non-NDES = 16 rows
})
fmt.Printf("created=%d skipped=%d errors=%d\n",
    result.Created, result.Skipped, len(result.Errors))
```

## Behavior Notes

- **Encrypted columns** (`api_token_encrypted`, `password_encrypted`, etc.) are left `NULL` — seeded CAs appear in the UI but cannot issue real certificates
- **Names** are prefixed with `*` (e.g. `*839201_digicert_1`) making them visually distinct and technically invalid through the normal service-layer name validator (`^\w+$`)
- **NDES** is inserted once per program run; duplicate-key collisions on `idx_ca_type_name` are silently skipped on subsequent runs
- **Run tag** is derived from `time.Now().UnixNano() % 1_000_000` to ensure uniqueness across runs without collisions
