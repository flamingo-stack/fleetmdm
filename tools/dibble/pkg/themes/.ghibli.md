Registers the **Studio Ghibli** theme for the Fleet MDM demo data generator, populating test environments with characters, teams, and policies from Studio Ghibli films.

## Key Components

- **`init()`** — Automatically registers the `ghibli` theme on package load via `Register()`.
- **`Theme`** — Struct populated with Ghibli-themed fixture data including users, teams, policies, software, labels, and scripts.

## Usage Example

```go
// The theme self-registers via init(); reference it by name:
theme, ok := themes.Get("ghibli")
if ok {
    fmt.Println(theme.Display) // "Studio Ghibli"
    fmt.Println(theme.Domain)  // "spiritedaway.test"
}
```

## Notes

- The test domain is `spiritedaway.test` — safe for local/sandbox environments only.
- Theme registration is side-effect driven; import the `themes` package to activate it.
