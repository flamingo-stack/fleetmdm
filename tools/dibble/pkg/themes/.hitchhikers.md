Registers the **Hitchhiker's Guide to the Galaxy** theme as a built-in demo dataset for the Fleet MDM themes package.

## Key Components

- **`init()`** — Calls `Register()` on package load to add the `hitchhikers` theme to the global theme registry.
- **`Theme` struct fields populated:**
  - `Name` / `Display` — Machine key `"hitchhikers"` and human-readable display name.
  - `Domain` — `magrathea.test`
  - `Users` — 8 fictional characters (Arthur Dent, Ford Prefect, Zaphod Beeblebrox, etc.)
  - `Teams` — 5 teams (e.g., `"Heart of Gold"`, `"Vogon Constructor Fleet"`)
  - `Policies` — 5 MDM policies with humorous but structurally realistic descriptions.
  - `Software` — 4 software entries (e.g., `"Babel Fish"`, `"Eddie the Shipboard Computer"`)
  - `Labels` — 4 host labels (e.g., `"knows-where-towel-is"`, `"froody-cats"`)
  - `Scripts` — 3 scripts for shell/PowerShell, mixing `.sh` and `.ps1`.

## Usage Example

The theme is auto-registered via `init()` and can be retrieved by name:

```go
import "github.com/flamingo-stack/fleetmdm/themes"

t, ok := themes.Get("hitchhikers")
if ok {
    fmt.Println(t.Display) // "Hitchhiker's Guide to the Galaxy"
    fmt.Println(t.Domain)  // "magrathea.test"
    for _, u := range t.Users {
        fmt.Println(u.First, u.Last) // "Arthur Dent", "Ford Prefect", ...
    }
}
```

## Notes

- No logic beyond data declaration — all behavior is driven by the shared `Register` / `Get` functions defined elsewhere in the `themes` package.
- Scripts reference `$HOME` in prose descriptions; the actual path expansion is handled at script execution time, not here.
- See [`themes/`](https://github.com/flamingo-stack/fleetmdm/blob/main/themes) for sibling theme files and the `Register` implementation.
