Provides the core theme registry and helper utilities for `dibble`'s seeded data generation, defining the data structures and deterministic lookup functions that map `(theme, kind, index)` tuples to character names, emails, teams, and other Fleet UI entities.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Person` | A single character with `First`, `Last`, and `Handle` fields |
| `Named` | A generic name/description pair for policies, software, scripts, and labels |
| `Theme` | The top-level container holding all character data for one media property, including an optional `Suffix` for collision-free re-seeding |

### Registry Functions

| Function | Description |
|----------|-------------|
| `Register(t Theme)` | Called from each theme's `init()` to add it to the global registry |
| `All() []Theme` | Returns all registered themes sorted by name |
| `Names() []string` | Returns all theme names plus the synthetic `"mix"` entry |
| `Get(name string)` | Looks up a theme by name; returns `Mix()` for `"mix"` or `""` |
| `Mix() Theme` | Combines all registered themes into one merged theme for maximum variety |

### Data Access Helpers

| Function | Description |
|----------|-------------|
| `Email(t, i)` | Returns a deterministic, collision-safe email for the i-th user |
| `FullName(t, i)` | Returns the i-th user's display name |
| `TeamName(t, i)` | Returns the i-th team name with numeric wrap suffix |
| `Pick(t, kind, i)` | Returns the i-th `Named` item from a `"policy"`, `"software"`, `"label"`, or `"script"` pool |

## Usage Example

```go
// Register a theme (called automatically via init in each theme file)
themes.Register(themes.Theme{
    Name:    "hitchhiker",
    Display: "The Hitchhiker's Guide",
    Domain:  "megadodo.com",
    Users: []themes.Person{
        {First: "Arthur", Last: "Dent", Handle: "adent"},
        {First: "Ford",   Last: "Prefect"},
    },
    Teams:    []string{"Heart of Gold", "Magrathea"},
    Policies: []themes.Named{{Name: "Don't Panic", Desc: "Verify towel presence"}},
})

// Retrieve and use a theme
t, err := themes.Get("hitchhiker")
if err != nil {
    log.Fatal(err)
}

fmt.Println(themes.Email(t, 0))      // adent@megadodo.com
fmt.Println(themes.FullName(t, 1))   // Ford Prefect
fmt.Println(themes.TeamName(t, 0))   // Heart of Gold
fmt.Println(themes.Pick(t, "policy", 0).Name) // Don't Panic

// Use the mix theme for cross-theme seeding
mix := themes.Mix()
fmt.Println(themes.Email(mix, 42))
```
