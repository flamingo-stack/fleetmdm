Registers the "Parks and Recreation" themed test fixture, populating the Flamingo/FleetMDM theme registry with fictional Pawnee government characters, teams, policies, and software entries for use in demos and testing.

## Key Components

- **`init()`** — Auto-executes on package import, calling `Register()` with a fully populated `Theme` struct scoped to the `parksrec` identifier.

## Theme Data

| Field | Values |
|---|---|
| **Domain** | `pawneeparks.test` |
| **Users** | Leslie Knope, Ron Swanson, Tom Haverford, April Ludgate, Andy Dwyer, Ben Wyatt, Donna Meagle, Jerry Gergich |
| **Teams** | Pawnee Parks Department, Eagleton, Snakehole Lounge Staff, Entertainment 720, Mouse Rat, Pawnee Goddesses |
| **Policies** | Breakfast food only check, No Eagleton software, Treat Yo Self readiness, Ron's privacy posture |
| **Software** | Pawnee Government Portal, Rent-a-Swag, DJ Roomba |
| **Labels** | `loves-breakfast`, `hates-eagleton`, `mouse-rat-fan`, `literally-treat-yo-self` |
| **Scripts** | `build-pit-park.sh`, `deploy-li_l-sebastian.sh` |

## Usage Example

```go
import _ "github.com/flamingo-stack/fleetmdm/themes"

// The parksrec theme is automatically registered on import.
// Retrieve it by name elsewhere in your test or demo setup:
theme, ok := themes.Get("parksrec")
if ok {
    fmt.Println(theme.Display) // "Parks and Recreation"
    fmt.Println(theme.Domain)  // "pawneeparks.test"
}
```
