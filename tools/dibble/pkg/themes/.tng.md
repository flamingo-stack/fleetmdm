Registers the "Star Trek: The Next Generation" theme with the Flamingo Fleet MDM theme registry, providing TNG-flavored test fixture data for development and demonstration environments.

## Key Components

- **`init()`** — Calls `Register()` on package load to add the `tng` theme to the global theme registry.
- **`Theme` struct** — Populated with TNG-specific fixture data:
  - **`Name`** / **`Display`** — Theme identifier (`"tng"`) and human-readable label.
  - **`Domain`** — Test domain (`ussenterprise.test`).
  - **`Users`** — Eight crew members (Picard, Riker, Data, Worf, Geordi, Troi, Beverly Crusher, Wesley Crusher).
  - **`Teams`** — Six factions (USS Enterprise, Klingon Empire, Borg Collective, etc.).
  - **`Policies`** — Four sample MDM policies with TNG-themed names and descriptions.
  - **`Software`** — Three software entries (Holodeck Programs, LCARS Console, Tricorder firmware).
  - **`Labels`** — Four device labels (`engage-ready`, `tea-earl-grey-hot`, etc.).
  - **`Scripts`** — Two shell scripts (`raise-shields.sh`, `engage-warp.sh`).

## Usage Example

The theme is auto-registered via `init()`. To activate it, import the themes package:

```go
import _ "github.com/flamingo-stack/fleetmdm/themes"
```

Then select the theme by name at runtime:

```go
theme, ok := themes.Get("tng")
if ok {
    fmt.Println(theme.Display) // "Star Trek: The Next Generation"
    fmt.Println(theme.Domain)  // "ussenterprise.test"
}
```

## Notes

- No exports; all registration happens as a side effect of the `init()` function.
- Intended purely for development/demo seeding — the `ussenterprise.test` domain is not a real endpoint.
- See [`themes/`](https://github.com/flamingo-stack/fleetmdm/blob/main/themes) for sibling themes and the `Register`/`Get` API.
