Registers a Brandon Sanderson's Cosmere-themed dataset with the `themes` package, providing fictional users, teams, policies, software, labels, and scripts drawn from the Cosmere universe for use in demo or test environments.

## Key Components

- **`init()`** — Calls `Register()` on package load to add the `"cosmere"` theme to the global theme registry.
- **`Theme`** — Struct populated with Cosmere-flavored sample data across six categories:
  - **`Users`** — Ten characters (Kaladin, Shallan, Vin, Hoid, etc.) with first name, last name, and username.
  - **`Teams`** — Seven factions (Bridge Four, Knights Radiant, Mistborn, etc.).
  - **`Policies`** — Four named compliance-style policies with Cosmere-themed descriptions.
  - **`Software`** — Three named tools (Stormlight Manager, Allomantic Burn Console, Shardplate Diagnostics).
  - **`Labels`** — Four classification tags (e.g., `windrunner-eligible`, `mistborn-active`).
  - **`Scripts`** — Two named scripts with descriptions.

## Usage Example

The theme is registered automatically via `init()`. To use it, import the package and retrieve the theme by name:

```go
import _ "github.com/flamingo-stack/fleetmdm/themes"

theme, ok := themes.Get("cosmere")
if ok {
    fmt.Println(theme.Display) // "Brandon Sanderson's Cosmere"
    for _, u := range theme.Users {
        fmt.Println(u.Username) // kaladin, shallan, dalinar, ...
    }
}
```

> This theme is intended for demo, staging, or test environments using `cosmere.test` as its domain. No production data is included.
