Registers the "The Good Place" theme for the Fleet MDM demo data generator, providing a themed set of fictional users, teams, policies, software, labels, and scripts based on the TV show.

## Key Components

- **`init()`** — Calls `Register()` on startup to add the `goodplace` theme to the available themes registry.
- **`Theme`** — Struct populated with themed demo data:
  - **`Users`** — Seven `Person` entries (Eleanor, Chidi, Tahani, Jason, Michael, Janet, Doug)
  - **`Teams`** — Five teams across The Good Place, Bad Place, Medium Place, and key locations
  - **`Policies`** — Four MDM policies with show-appropriate names and descriptions
  - **`Software`** — Three software entries referencing key characters
  - **`Labels`** — Four device labels (`good-place-resident`, `bad-place-architect`, etc.)
  - **`Scripts`** — Two scripts for ethical scoring and Janet summoning

## Usage Example

```go
// Theme is auto-registered via init(); retrieve it by name:
theme, ok := themes.Get("goodplace")
if !ok {
    log.Fatal("theme not found")
}

fmt.Println(theme.Display) // "The Good Place"
fmt.Println(theme.Domain)  // "thegoodplace.test"

for _, user := range theme.Users {
    fmt.Printf("%s %s (%s)\n", user.First, user.Last, user.Username)
}
// Eleanor Shellstrop (eleanor)
// Chidi Anagonye (chidi)
// ...
```

## Notes

- The `Domain` field (`thegoodplace.test`) is used as the test MDM enrollment domain for this theme.
- This theme is one of several available; see the [`themes`](https://github.com/flamingo-stack/fleetmdm/blob/main/themes) package for the full registry and `Register`/`Get` APIs.
