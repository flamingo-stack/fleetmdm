Registers the **Sailor Moon** theme for the Fleet MDM demo data system, providing a set of fictional users, teams, policies, software entries, labels, and scripts styled after the Sailor Moon universe.

## Key Components

- **`init()`** — Calls `Register()` on startup to add the `sailor_moon` theme to the global theme registry.
- **`Theme`** — Struct populated with Sailor Moon–themed demo data:
  - **`Users`** — Nine characters (Usagi, Ami, Rei, Makoto, Minako, Mamoru, Chibiusa, Luna, Artemis) as `Person` entries with first name, last name, and username.
  - **`Teams`** — Six factions: Inner Senshi, Outer Senshi, Dark Kingdom, Black Moon Clan, Death Busters, Moon Kingdom.
  - **`Policies`** — Three MDM policies with thematic names (e.g., "No youma in inventory").
  - **`Software`** — Three software entries (e.g., "Luna-P Chat", "Disguise Pen").
  - **`Labels`** — Four device labels (e.g., `moon-prism-active`, `talking-cat-detected`).
  - **`Scripts`** — Two scripts (`transform.sh`, `summon-tuxedo-mask.ps1`).

## Usage Example

The theme is self-registering via `init()`. Import the package to activate it:

```go
import _ "github.com/flamingo-stack/fleetmdm/themes"
```

Once registered, reference it by name:

```go
theme, ok := themes.Get("sailor_moon")
if ok {
    fmt.Println(theme.Domain) // "moonkingdom.test"
}
```

## Notes

- The domain `moonkingdom.test` is a non-resolvable test domain, safe for demo environments.
- Follows the same registration pattern as all other themes in the package — no special wiring required.
