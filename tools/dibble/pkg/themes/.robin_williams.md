Registers the `robin_williams` theme, a test data fixture that seeds a Fleet MDM environment with fictional users, teams, policies, software, labels, and scripts themed around Robin Williams film and TV characters.

## Key Components

- **`init()`** — Calls `Register()` on startup with a fully populated `Theme` struct using the domain `naunau.test`

## Theme Contents

| Field | Entries |
|---|---|
| `Users` | Genie, Mrs. Doubtfire, John Keating, Sean Maguire, Peter Banning, Alan Parrish, Patch Adams, Adrian Cronauer, Mork |
| `Teams` | Cave of Wonders, Welton Academy, Jumanji Survivors, Hillside Hospital, Saigon Radio AFRS, Mount Hope |
| `Policies` | Carpe Diem reminder, No phenomenal cosmic power…, Nanu nanu greeting required |
| `Software` | Lamp Polish Pro, Jumanji Board Sim, Patch.MD Clinic Suite |
| `Labels` | `oh-captain-my-captain`, `second-star-to-the-right`, `good-morning-vietnam`, `shazbot` |
| `Scripts` | `rub-the-lamp.sh`, `goooooood-morning.sh` |

## Usage Example

```go
// Themes self-register via init(); import the package to activate.
import _ "github.com/flamingo-stack/fleetmdm/path/to/themes"

// Retrieve the registered theme by name
theme := themes.Get("robin_williams")
fmt.Println(theme.Domain) // naunau.test
```

## Notes

- This theme is intended for development and testing environments only — the domain `naunau.test` is non-routable
- Follows the same `Theme` struct and `Register` pattern as all other themes in this package; see [`themes` package source](https://github.com/flamingo-stack/fleetmdm/blob/main/themes) for the full registry
