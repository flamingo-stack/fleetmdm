Registers the "Dragon Ball Z" themed dataset for use in Fleet MDM demo and testing environments.

## Key Components

- **`init()`** — Automatically registers the `dbz` theme via `Register()` at package load time, populating it with Dragon Ball Z–flavored fixture data.

## Theme Data

| Field | Contents |
|---|---|
| `Name` / `Domain` | `dbz` / `capsulecorp.test` |
| `Users` | 8 characters (Goku, Vegeta, Piccolo, Gohan, Krillin, Bulma, Trunks, Tien) |
| `Teams` | 6 factions (Z Fighters, Capsule Corp, Frieza Force, etc.) |
| `Policies` | 4 entries (power level thresholds, Senzu bean inventory, etc.) |
| `Software` | 3 entries (Scouter Firmware, Dragon Radar, Hyperbolic Time Chamber) |
| `Labels` | `super-saiyan`, `namekian`, `earthling`, `androids-allowed` |
| `Scripts` | 2 scripts (`charge-kamehameha.sh`, `open-capsule.ps1`) |

## Usage Example

The theme is self-registering; simply import the `themes` package to make `dbz` available:

```go
import _ "github.com/flamingo-stack/fleetmdm/themes"

theme, _ := themes.Get("dbz")
fmt.Println(theme.Domain) // capsulecorp.test
```

## Notes

- All data is fictional and intended solely for demos, seeding, and testing.
- Follows the same `Theme` struct contract as other themes in this package (e.g., `Register` / `Get` pattern).
- See the full themes package at [`themes/`](https://github.com/flamingo-stack/fleetmdm/blob/main/themes).
