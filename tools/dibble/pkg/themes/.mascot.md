Defines mascot constants for the Flamingo themes package, including the tapir ASCII/Braille art used in the wizard banner and README header, and a bullet character for progress lines.

## Key Components

| Constant | Type | Description |
|---|---|---|
| `TapirSnout` | `string` | Inline bullet character (`>·)~`) used on progress lines |
| `TapirSmall` | `string` | Braille-block tapir art for the wizard banner |
| `TapirLarge` | `string` | Braille-block tapir art for the README header |
| `tapirArt` | `string` (unexported) | Shared backing art; `TapirSmall` and `TapirLarge` both alias this so they can diverge later without a breaking change |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/internal/themes"
)

func main() {
    // Print wizard banner
    fmt.Println(themes.TapirSmall)

    // Use bullet on a progress line
    fmt.Printf("%s Installing packages...\n", themes.TapirSnout)
    // Output: >·)~ Installing packages...
}
```

> **Note:** `TapirSmall` and `TapirLarge` intentionally share the same art today. They are kept as distinct exported names so future callers can swap one variant for a different size without churn.
