Registers a Lord of the Rings-themed dataset for use in Fleet MDM's demo/testing theme system, populating it with characters, teams, policies, software, labels, and scripts from Middle-earth lore.

## Key Components

- **`init()`** — Calls `Register()` on package load with a fully configured `Theme` struct using the `"lotr"` key and domain `middleearth.test`.

## Theme Data

| Field | Examples |
|---|---|
| `Users` | Frodo Baggins, Gandalf the Grey, Aragorn Elessar (9 members of the Fellowship) |
| `Teams` | The Fellowship, Rohan, Gondor, Mordor, and more |
| `Policies` | "You shall not pass" (Balrog firewall rule), "No One Ring in registry" |
| `Software` | Palantír Viewer, Sting Sensor, Mithril Patch Manager |
| `Labels` | `ring-bearer`, `speaks-elvish`, `knows-the-old-songs` |
| `Scripts` | `cast-into-mount-doom.sh`, `summon-eagles.ps1` |

## Usage Example

```go
// The theme is auto-registered via init(); retrieve it by name:
theme, ok := themes.Get("lotr")
if ok {
    fmt.Println(theme.Display) // "The Lord of the Rings"
    fmt.Println(theme.Domain)  // "middleearth.test"
}
```

The `init()` function runs automatically when the `themes` package is imported, making this theme available globally without explicit setup. To activate it, ensure the package is blank-imported alongside other registered themes:

```go
import _ "github.com/flamingo-stack/fleetmdm/path/to/themes/lotr"
```

> **Note:** This is a seed/demo theme — `middleearth.test` is a non-routable test domain safe for local development and CI environments.
