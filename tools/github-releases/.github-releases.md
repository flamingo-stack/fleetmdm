Fetches and formats Fleet release versions from the GitHub API, supporting output of the latest minor releases or all versions as CPE strings.

## Key Components

- **`main()`** — Entry point that parses CLI flags, queries the GitHub Releases API for `fleetdm/fleet`, normalizes version strings (stripping `fleet-`, `Fleet `, `orbit-` prefixes), sorts results in descending semver order, and prints the output.
- **`runLastMinorReleases()`** — Filters a sorted version list to return only the highest-patch release per minor version, up to `n` minor versions.

### CLI Flags

| Flag | Type | Description |
|---|---|---|
| `--last-minor-releases` | `int` | Return the latest patch for each of the N most recent minor versions |
| `--separator` | `string` | Output delimiter (default: space) |
| `--all-cpes` | `bool` | Fetch all releases and format as CPE 2.3 strings |

## Usage Example

```bash
# Get the latest patch release for the 3 most recent minor versions
go run github-releases.go --last-minor-releases=3

# Output: v4.60.1 v4.59.3 v4.58.2

# Get all releases formatted as CPE strings, newline-separated
go run github-releases.go --all-cpes --separator="\n"

# Output:
# cpe:2.3:a:fleetdm:fleet:v4.60.1:*:*:*:*:*:*:*
# cpe:2.3:a:fleetdm:fleet:v4.59.3:*:*:*:*:*:*:*
# ...
```

> **Note:** `--last-minor-releases` and `--all-cpes` are mutually exclusive; exactly one must be set. The `--all-cpes` mode paginates all GitHub releases (100 per page) with a 500ms delay between pages to avoid rate limiting.
