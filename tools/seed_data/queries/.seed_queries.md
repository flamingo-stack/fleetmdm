Bulk-seeds the Fleet MySQL database with 1,000,000 test query records using batched inserts for performance testing or development data population.

## Key Components

| Element | Description |
|---|---|
| `batchSize` | Number of records per insert batch (1,000) |
| `totalRecords` | Total records to insert (1,000,000) |
| `main()` | Connects to MySQL, disables FK checks, runs batched inserts, re-enables FK checks |

## Usage Example

```bash
# Ensure the Fleet MySQL container is running, then:
cd tools/seed_queries  # or wherever this file lives
go run seed_queries.go
```

The script inserts records into the `queries` table with the following fixed values per row:

```go
// Each record follows this shape:
(saved=0, name="query_<N>", description="", query="SELECT * FROM processes;",
 author_id=1, observer_can_run=0, team_id=nil, platform="",
 min_osquery_version="", schedule_interval=0, automations_enabled=0,
 logging_type="snapshot", discard_data=0)
```

## Notes

- **Connection**: Targets `fleet:insecure@localhost:3306/fleet` — matches the default [Docker Compose credentials](https://github.com/flamingo-stack/fleetmdm/blob/main/docker-compose.yml).
- **Performance**: Foreign key checks are disabled (`SET FOREIGN_KEY_CHECKS=0`) during insertion and re-enabled on completion.
- **Progress**: Prints `Inserted batch N/1000` to stdout for each of the 1,000 batches.
- **Driver**: Uses [`go-sql-driver/mysql`](https://github.com/go-sql-driver/mysql) via the standard `database/sql` interface.

> ⚠️ This is a development/testing utility. Do not run against a production database — credentials are hardcoded and insecure.
