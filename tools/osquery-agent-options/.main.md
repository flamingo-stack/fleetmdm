Code generation tool that downloads the appropriate `osqueryd` binary for the current OS, queries its available flags and options, and writes a Go source file containing typed structs for osquery agent configuration.

## Key Components

| Symbol | Description |
|---|---|
| `osqueryVersion` | Pinned osquery version (`5.23.0`) targeted for code generation |
| `structTpl` | Go `text/template` that renders `osqueryOptions` and `osqueryCommandLineFlags` structs with proper JSON tags |
| `templateData` | Input data passed to `structTpl`: version string, options map, and flags map |
| `main()` | Orchestrates download, flag extraction via `osqueryd --help` and `osquery_flags` SQL query, and file output |
| `downloadOsqueryd()` | Downloads the platform-appropriate `osqueryd` binary (macOS app bundle via tar.gz, Linux single binary) from Fleet's TUF mirror |
| `camelCaseOptionName()` | Converts `snake_case` flag names to `CamelCase` for Go struct field names |
| `extractTarGz()` | Safely unpacks a `.tar.gz` archive with zip-slip protection |
| `sanitizeArchivePath()` | Guards against path traversal (G305) when extracting archive entries |

## Usage Example

This tool is invoked via `go generate` from the `server/fleet/` package. To regenerate structs for a new osquery version:

1. Update `osqueryVersion` in this file:

```go
osqueryVersion = "5.24.0"
```

2. Run generation from the correct directory:

```bash
cd server/fleet/
go generate
```

The generator will:
- Download `osqueryd` for the current OS (macOS or Linux only)
- Execute `osqueryd --help` to identify configuration-eligible options
- Query `osquery_flags` via `osqueryd -S --json` to resolve each flag's data type
- Skip OS-specific flags already defined in `OsqueryCommandLineFlagsLinux`, `OsqueryCommandLineFlagsWindows`, `OsqueryCommandLineFlagsMacOS`, and `OsqueryCommandLineFlagsHidden`
- Write the resulting structs to the output file path supplied as `os.Args[1]`

> **Note:** Generation must run on macOS or Linux. Windows is not supported as a build host for this tool.
