A CLI test tool for validating AWS IAM authentication against an RDS MySQL instance. It establishes a database connection using IAM token-based auth and runs a basic connectivity check.

## Key Components

- **`main()`** — Parses CLI flags, builds a `MysqlConfig` with IAM auth settings, connects to RDS via `mysql.NewDB`, and exits with a non-zero code on failure.
- **`testConnection(db)`** — Executes `SELECT VERSION()` to verify the connection is live and logs the MySQL version.

### Flags

| Flag | Default | Description |
|---|---|---|
| `-endpoint` | *(required)* | RDS hostname (no port) |
| `-port` | `3306` | Database port |
| `-user` | `fleet_iam_user` | IAM-authenticated username |
| `-db` | `fleet` | Database name |
| `-region` | | AWS region |
| `-assume-role` | | STS role ARN to assume |
| `-external-id` | | STS external ID |

## Usage Example

```bash
go run iam_auth.go \
  -endpoint my-cluster.cluster-abc123.us-east-1.rds.amazonaws.com \
  -region us-east-1 \
  -user fleet_iam_user \
  -db fleet \
  -assume-role arn:aws:iam::123456789012:role/FleetRDSRole \
  -external-id my-external-id
```

Expected output on success:

```text
Connecting to RDS at my-cluster...:3306 with IAM auth for user fleet_iam_user
Using assume role: arn:aws:iam::...
📋 Testing connection with IAM token...
  Database version: 8.0.32
✅ Connection successful!
```
