CLI tool that builds and packages the Fleet Desktop application for macOS, producing a signed, optionally notarized `.app` bundle compressed into a `desktop.app.tar.gz` archive.

## Key Components

| Symbol | Description |
|--------|-------------|
| `createApp` | Initializes the CLI application with `--version` and `--verbose` flags, and registers the `macos` subcommand |
| `macos()` | Defines the `macos` CLI subcommand with `--authority` (codesign identity) and `--notarize` flags |
| `createMacOSApp` | Core build function: compiles amd64 + arm64 binaries, creates a universal fat binary via `lipo`, writes `Info.plist`, optionally codesigns and notarizes, then tars the `.app` bundle |
| `compressDir` | Walks a directory and writes all contents into a `.tar.gz` archive |
| `exitErrHandler` | CLI error handler that prints to stderr and exits with code 1 |

## Usage Example

```bash
# Build unsigned macOS app
FLEET_DESKTOP_VERSION=1.2.3 go run ./tools/desktop/desktop.go macos

# Build with codesigning
FLEET_DESKTOP_APPLE_AUTHORITY="Developer ID Application: Fleet" \
FLEET_DESKTOP_VERSION=1.2.3 \
go run ./tools/desktop/desktop.go macos --authority "Developer ID Application: Fleet"

# Build with codesigning and notarization
FLEET_DESKTOP_APPLE_AUTHORITY="Developer ID Application: Fleet" \
FLEET_DESKTOP_VERSION=1.2.3 \
AC_USERNAME="appleid@example.com" \
AC_PASSWORD="app-specific-password" \
go run ./tools/desktop/desktop.go macos --notarize
```

> **Note:** Must be run on macOS. Requires `go`, `codesign` (for signing), and Apple notarization credentials (`AC_USERNAME`, `AC_PASSWORD`) when `--notarize` is set. Set `DISABLE_DIRTY_CHECK=1` to skip the dirty build check during development.
