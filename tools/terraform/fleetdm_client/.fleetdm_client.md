A Go HTTP client for interacting with the FleetDM API, focused exclusively on team (formerly "fleet") management operations.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Team` | Represents a FleetDM team with ID, name, description, agent options, scripts, and enrollment secrets |
| `TeamCreate` | Request payload for creating or updating a team |
| `TeamGetResponse` | Single-team API response wrapper |
| `TeamQueryResponse` | Multi-team API response wrapper (used for list/search) |
| `FleetDMClient` | HTTP client embedding `*http.Client` with base URL and API key |

### Methods

| Method | Description |
|--------|-------------|
| `NewFleetDMClient(url, apiKey)` | Constructor; ensures trailing slash on base URL |
| `do(req, query)` | Internal method; injects `Authorization` and `Accept` headers, resolves URL |
| `TeamNameToID(name)` | Searches teams by name, returns matching team ID |
| `CreateTeam(name, description)` | POSTs a new team, returns created team |
| `GetTeam(id)` | Fetches a single team by ID |
| `UpdateTeam(id, name, description)` | PATCHes team name and/or description |
| `UpdateAgentOptions(id, ao)` | POSTs JSON agent options to a team; validates JSON before sending |
| `DeleteTeam(id)` | Deletes a team by ID |

## Usage Example

```go
package main

import (
    "fmt"
    fleetdm "github.com/flamingo-stack/fleetmdm"
)

func main() {
    client := fleetdm.NewFleetDMClient("https://fleet.example.com", "your-api-key")

    // Create a new team
    team, err := client.CreateTeam("Engineering", "Engineering devices")
    if err != nil {
        panic(err)
    }
    fmt.Printf("Created team ID: %d\n", team.Team.ID)

    // Look up a team ID by name
    id, err := client.TeamNameToID("Engineering")
    if err != nil {
        panic(err)
    }

    // Update agent options with valid JSON
    agentOptions := `{"config":{"options":{"logger_plugin":"tls"}}}`
    _, err = client.UpdateAgentOptions(id, agentOptions)
    if err != nil {
        panic(err)
    }

    // Clean up
    err = client.DeleteTeam(id)
}
```

> **Note:** `UpdateAgentOptions` validates the provided string is well-formed JSON before making the API call, returning an error early if it is not.
