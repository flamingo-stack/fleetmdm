Terraform provider entry point for the FleetDM API. It implements the Terraform Plugin Framework provider interfaces, handles configuration via HCL attributes or environment variables, and wires up the shared API client for all resources and data sources.

## Key Components

| Symbol | Description |
|---|---|
| `FleetDMProvider` | Core provider struct implementing `provider.Provider` and `provider.ProviderWithFunctions` |
| `FleetDMProviderModel` | HCL schema model with `url` and `apikey` attributes |
| `Configure()` | Resolves credentials from config or env vars (`FLEETDM_URL`, `FLEETDM_APIKEY`), constructs `FleetDMClient`, and injects it into resource/data source context |
| `Resources()` | Registers `NewTeamsResource` as the available managed resource |
| `New(version)` | Factory function returning a provider constructor — used as the Terraform plugin entry point |

## Usage Example

**HCL provider configuration:**

```hcl
provider "fleetdm" {
  url    = "https://fleet.example.com"
  apikey = var.fleetdm_api_key
}
```

**Environment variable configuration (no HCL block required):**

```bash
export FLEETDM_URL="https://fleet.example.com"
export FLEETDM_APIKEY="your-api-key"
```

**Registering the provider in `main.go`:**

```go
import "terraform-provider-fleetdm/internal/provider"

providerserver.Serve(ctx, provider.New("1.0.0"), opts)
```

Credentials are resolved with config block values taking precedence over environment variables. Both `url` and `apikey` are required; missing either produces a Terraform diagnostic error that surfaces clearly during `terraform plan` or `terraform apply`.
