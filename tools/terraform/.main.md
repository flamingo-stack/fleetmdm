Entrypoint for the FleetDM Terraform provider binary. It initializes and serves the provider using the Terraform Plugin Framework, with optional debug mode support.

## Key Components

- **`version`** — Build-time variable injected by goreleaser; defaults to `"dev"` during local development.
- **`-debug` flag** — Boolean CLI flag enabling debugger attachment (e.g., via [Delve](https://github.com/go-delve/delve)).
- **`providerserver.ServeOpts`** — Configures the provider address (`fleetdm.com/tf/fleetdm`) and debug mode.
- **`provider.New(version)`** — Constructs the provider instance, passing the current version string.
- **`go:generate` directives** — Automate Terraform file formatting and plugin docs generation via `tfplugindocs`.

## Usage Example

**Run the provider normally (via Terraform):**
```bash
go build -o terraform-provider-fleetdm
```

**Run with debugger support:**
```bash
./terraform-provider-fleetdm -debug
```

**Regenerate docs and format examples:**
```bash
go generate ./...
```

**Override version at build time (goreleaser):**
```bash
go build -ldflags="-X main.version=1.2.3" -o terraform-provider-fleetdm
```

## Notes

- The provider address `fleetdm.com/tf/fleetdm` must match the `source` block in your Terraform configuration when using a local/dev override.
- For debugging, pair the `-debug` flag output with a `~/.terraformrc` [dev override](https://developer.hashicorp.com/terraform/cli/config/config-file#development-overrides-for-provider-developers).
