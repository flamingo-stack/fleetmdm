Terraform configuration file that provisions a FleetDM team resource using the FleetDM Terraform provider, including default osquery agent options.

## Key Components

- **`terraform` block** — Declares the `fleetdm` provider from `fleetdm.com/tf/fleetdm`
- **`provider "fleetdm"`** — Configures the FleetDM instance URL; API key is supplied via the `FLEETDM_APIKEY` environment variable
- **`locals.raw_agent_options`** — Defines default osquery agent configuration including TLS logging, distributed query settings, host decorators, and command-line flags
- **`fleetdm_teams.hello_world`** — Creates a FleetDM team named `my_first_team` with the encoded agent options applied

## Usage Example

```bash
# Authenticate via environment variable
export FLEETDM_APIKEY="your-api-key-here"

# Initialize and apply the configuration
terraform init
terraform plan
terraform apply
```

To customize the team or agent options, edit the `locals` block or the `fleetdm_teams` resource before applying:

```plaintext
resource "fleetdm_teams" "hello_world" {
  name          = "my_custom_team"
  description   = "Custom team description"
  agent_options = local.default_agent_options
}
```

> **Note:** The `distributed_interval` is set to `15` seconds and `logger_tls_period` to `10` seconds by default. Adjust these in `raw_agent_options` to match your environment's requirements.
