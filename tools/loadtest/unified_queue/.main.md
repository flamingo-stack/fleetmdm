A load-testing / stress tool that enqueues software installs and script executions across macOS and Windows hosts in a Fleet MDM instance, rate-limited to one host every 300 ms.

## Key Components

| Symbol | Description |
|---|---|
| `printf` | Timestamped log helper (UTC ISO-8601 prefix) |
| `main` | Entry point — parses flags, fetches hosts/software/scripts, then dispatches actions |
| `smallHost` | Internal struct holding `ID`, `Hostname`, and `Platform` for a host |

**CLI Flags**

| Flag | Description |
|---|---|
| `--fleet_url` | Fleet server URL (with protocol and port) |
| `--api_token` | API authentication token |
| `--debug` | Enable client debug logging |

**Per-platform action pattern**

| Platform | Scripts queued | Installs queued |
|---|---|---|
| `darwin` | 2 (`.sh`) | 1 (App Store / pkg) |
| `windows` | 1 (`.ps1`) | 2 (`.exe` / `.msi`) |

## Usage Example

```bash
go run main.go \
  --fleet_url https://fleet.example.com \
  --api_token your-api-token \
  --debug
```

**Notes**
- Linux hosts are fetched but intentionally skipped during dispatch.
- Hosts are shuffled randomly before processing to avoid ordering bias.
- Progress is logged every 500 hosts.
