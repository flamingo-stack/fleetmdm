Brief description: A load-testing utility that creates multiple Fleet teams, applies MDM configuration profiles (Apple and Windows), declaration profiles, and shell scripts to each team — optionally injecting secret variables into profile and script contents.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `main()` | Function | Entry point; parses CLI flags, creates teams, applies profiles and scripts |
| `addSecretVariable()` | Function | Injects a `$FLEET_SECRET_<name>` placeholder (or `"test"`) into profile contents via `fmt.Sprintf` formatting |
| `createRandomScripts()` | Function | Generates `n` shell script payloads per team, optionally embedding a secret variable reference |
| `createRandomDeclarations()` | Function | *(defined elsewhere)* Creates 13 randomized Apple declaration profiles |
| `printfAndPrompt()` | Function | Prints a timestamped message and blocks on stdin input before proceeding |
| `printf()` | Function | Prints a UTC-timestamped message to stdout |

**CLI Flags**

| Flag | Description |
|---|---|
| `--fleet_url` | Fleet server URL (required) |
| `--api_token` | API authentication token (required) |
| `--team_count` | Number of teams to create |
| `--cleanup_teams` | Delete all `"Team *"` teams and exit |
| `--secret_variable` | Secret variable name to inject into profiles/scripts |

## Usage Example

```bash
# Create 5 teams with profiles and scripts using a secret variable
go run . \
  --fleet_url=https://fleet.example.com \
  --api_token=your_token_here \
  --team_count=5 \
  --secret_variable=MY_SECRET

# Clean up teams from a previous run
go run . \
  --fleet_url=https://fleet.example.com \
  --api_token=your_token_here \
  --cleanup_teams
```
