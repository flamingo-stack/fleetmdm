A load-testing / seeding utility that connects to a Fleet server via its REST API, retrieves all enrolled hosts, and bulk-applies platform-specific manual labels to stress-test the `labels` and `label_membership` database tables.

## Key Components

| Symbol | Description |
|---|---|
| `main()` | Entry point; parses CLI flags, initializes the Fleet API client, fetches hosts, and applies manual labels per platform |
| `batchHostnames()` | Splits a hostname slice into chunks of 500 to avoid oversized API payloads |
| `printf()` | Timestamped log helper (UTC, RFC 3339 format) wrapping `fmt.Printf` |

## CLI Flags

| Flag | Required | Description |
|---|---|---|
| `-fleet_url` | ✅ | Full URL of the Fleet server (protocol + port) |
| `-api_token` | ✅ | API authentication token |
| `-debug` | ❌ | Enables client-level debug logging |

## Label Strategy

- **Linux** — 1 manual label applied to 80% of hosts
- **macOS** — 4 manual labels applied to all hosts
- **Windows** — 5 manual labels applied to all hosts

Each label is applied in batches of 500 hostnames via `ApplyLabels`.
