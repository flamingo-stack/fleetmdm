Defines the `issues` CLI subcommand, allowing users to query and browse GitHub issues through an interactive TUI interface.

## Key Components

- **`issuesCmd`** — Cobra command registered under `issues`, accepts an optional `--search`/`-s` flag using GitHub search syntax and delegates rendering to `tui.RunTUI`.
- **`init()`** — Registers the `-s`/`--search` string flag on `issuesCmd` at startup.

## Usage Example

```bash
# List all issues
gm issues

# Search issues using GitHub search syntax
gm issues --search "is:open label:bug"
gm issues -s "author:octocat is:closed"
```

```go
// Internal dispatch — tui.RunTUI is called with IssuesCommand and the search string
tui.RunTUI(tui.IssuesCommand, 0, 0, search)
```

> **Note:** The `search` argument is passed directly to the TUI layer as a GitHub search query string. Refer to [GitHub's search syntax](https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests) for supported filters (`is:open`, `label:`, `author:`, etc.).
