Implements the `bugs` CLI subcommand for fetching and analyzing open GitHub bug issues from the `fleetdm/fleet` repository, calculating the average number of days bugs remain open.

## Key Components

- **`BugIssue`** — Struct representing a GitHub issue with fields for number, title, creation date, milestone, and labels
- **`ProductGroup()`** — Method on `BugIssue` that returns the product group label (`#g-software`, `#g-orchestration`, `#g-mdm`, `#g-security-compliance`) or `"orphan"` if none match
- **`bugsCmd`** — Root Cobra command grouping bug-related subcommands
- **`bugsAverageOpenCmd`** — Cobra subcommand (`average-open-days`) that fetches open bugs and computes average open time, equivalent to the `averageNumberOfDaysBugsAreOpenFor` KPI from the Fleet website scripts
- **`fetchOpenBugs(limit int)`** — Calls `gh issue list` via `ghapi.RunCommandAndReturnOutput` and unmarshals the JSON response into `[]BugIssue`

## Usage Example

```bash
# Human-readable output
gm bugs average-open-days

# JSON output
gm bugs average-open-days --format json

# TSV with verbose bug list
gm bugs average-open-days --format tsv --verbose

# Exclude specific milestone bugs (simulate release going GA)
gm bugs average-open-days --without-milestone 4.80.1 --without-milestone 4.81.0

# Increase fetch limit
gm bugs average-open-days --limit 2000
```

**JSON output shape:**

```json
{
  "totalBugs": 142,
  "averageNumberOfDaysBugsAreOpenFor": 38,
  "averageDaysExact": 37.84
}
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--verbose` / `-v` | `false` | Print per-bug breakdown table |
| `--format` / `-f` | human-readable | `json`, `tsv`, or default |
| `--limit` / `-l` | `1000` | Max bugs to fetch via `gh` CLI |
| `--without-milestone` | `[]` | Exclude bugs assigned to given milestones |

> **Note:** Requires the GitHub CLI (`gh`) to be authenticated and available in `$PATH`. Returns an error if the result count equals the limit, indicating pagination was hit.
