A CLI subcommand that finds GitHub issues created since a specified date that had a given label at any point in their history (not just currently).

## Key Components

- **`issuesWithHistoricalLabelCmd`** — Cobra command registered as `issues-with-historical-label [label]`. Calls `ghapi.GetIssuesCreatedSinceWithLabel` and outputs results in a tab-aligned table via `tabwriter`.
- **`init()`** — Registers CLI flags on the command.

### Flags

| Flag | Short | Default | Description |
|---|---|---|---|
| `--since` | `-s` | _(required)_ | Oldest issue creation date (`YYYY-MM-DD`) |
| `--verbose` | `-v` | `false` | Stream progress to stderr |
| `--concurrency` | `-c` | `10` | Parallel workers for per-issue requests |
| `--repo` | `-r` | `fleetdm/fleet` | Target repository (`owner/repo`) |
| `--older-than` | | `0` | Only fetch issues with ID below this value (resume after rate limiting) |

### Output Columns

`Number`, `Title`, `State`, `Created at`, `Now?` — the last column indicates whether the issue **currently** holds the label (✔️ / ❌).

## Usage Example

```bash
# Find all issues created since 2024-01-01 that ever had the "bug" label
go run . issues-with-historical-label bug --since 2024-01-01

# Verbose mode with 20 workers, scoped to a fork
go run . issues-with-historical-label "needs-review" \
  --since 2023-06-01 \
  --verbose \
  --concurrency 20 \
  --repo flamingo-stack/fleetmdm

# Resume after a rate-limit cutoff at issue #8500
go run . issues-with-historical-label bug \
  --since 2024-01-01 \
  --older-than 8500
```
