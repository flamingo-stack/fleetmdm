Defines three Cobra CLI subcommands for fetching GitHub project issues: `project`, `estimated`, and `sprint`.

## Key Components

| Command | Description |
|---|---|
| `projectCmd` | Fetches all issues from a GitHub project by ID or alias |
| `estimatedCmd` | Fetches estimated issues from the drafting project, filtered by project label |
| `sprintCmd` | Fetches issues in the current (or previous) sprint for a project |

**Shared flags registered in `init()`:**

- `--limit` / `-l` — Maximum items to fetch (defaults: `300` for `project`/`sprint`, `500` for `estimated`)
- `--previous` / `-p` — (`sprintCmd` only) Show the previous sprint instead of the current one

## Usage Example

```bash
# Fetch up to 300 issues from a project
gm project my-project-alias

# Fetch estimated issues with a custom limit
gm estimated PVT_abc123 --limit 100

# Fetch current sprint issues
gm sprint my-project-alias

# Fetch previous sprint issues
gm sprint my-project-alias --previous
```

Each command resolves the project identifier via `ghapi.ResolveProjectID`, then delegates rendering to `tui.RunTUI` with the appropriate command type (`ProjectCommand`, `EstimatedCommand`, or `SprintCommand`). The `sprintCmd` passes `"previous"` as the search parameter when the `-p` flag is set, triggering prior-iteration filtering in the TUI layer.
