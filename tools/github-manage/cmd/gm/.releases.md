Defines CLI commands for managing release planning in the Fleet GitHub project, providing tools to sync issue estimates and calculate effort forecasts for milestones.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `releasesCmd` | `*cobra.Command` | Root `releases` subcommand grouping all release utilities |
| `releasesSyncEstimatesCmd` | `*cobra.Command` | Syncs estimate values from source projects or aggregates sub-issue estimates into the Releases project (ID: 87) |
| `releasesForecastCmd` | `*cobra.Command` | Calculates a low/high effort forecast for a milestone using t-shirt size labels (XXS–XL) |

## Usage Example

```bash
# Sync estimates for all issues on the Releases project
gm releases sync-estimates

# Sync estimates for a specific milestone, skipping already-estimated issues
gm releases sync-estimates --milestone "Fleet 4.77.0"

# Sync a single issue, overwriting any existing estimate
gm releases sync-estimates --issue 12345 --overwrite

# Forecast effort range for a milestone using t-shirt sizes
gm releases forecast --milestone "Fleet 4.86.0"
```

**T-shirt size → point range mapping used by `forecast`:**

| Size | Low | High |
|------|-----|------|
| XXS  | 1   | 3    |
| XS   | 3   | 8    |
| S    | 8   | 25   |
| M    | 25  | 50   |
| L    | 50  | 75   |
| XL   | 75  | 100  |

`sync-estimates` resolves estimates in priority order: (1) direct estimate from a known source project via `ghapi.GetEstimateForIssueAcrossProjects`, then (2) a summed aggregate from sub-issues via `ghapi.SumEstimatesFromSubIssues`. Use `--overwrite` to update issues that already carry an estimate.
