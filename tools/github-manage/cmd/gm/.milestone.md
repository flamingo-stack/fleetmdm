Provides milestone-related CLI commands for fetching, filtering, and reporting GitHub issues grouped by project status within a given milestone.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `milestoneCmd` | `*cobra.Command` | Parent command (`milestone`) grouping all milestone subcommands |
| `milestoneReportCmd` | `*cobra.Command` | Subcommand (`milestone report <name>`) that generates a per-issue project-status table with a summary section |
| `milestoneViewCmd` | `*cobra.Command` | Subcommand (`milestone view`) that opens an interactive TUI for issues in a milestone |
| `milestoneFormat` | `string` flag | Output format: `tsv` (default) or `md`/`markdown` |
| `milestoneStripEmojis` | `bool` flag | Strip emoji characters from all output text |
| `milestoneSummarySort` | `string` flag | Sort summary rows by `count` (default) or `name` |
| `milestoneIncludeClosed` | `bool` flag | Include closed milestones when listing available milestones |
| `milestoneIgnoreProject` | `string` flag | Comma-separated project name substrings to exclude from the report |
| `milestoneFilterLabels` | `string` flag | Comma-separated labels; only issues carrying **all** specified labels are included |
| `milestoneOutfile` | `string` flag | Optional file path to write the report in addition to stdout |

## Usage Example

```bash
# TSV report for an open milestone, written to a file
gm milestone report "v1.2.0" -o report.tsv

# Markdown report, excluding a project and filtering by label
gm milestone report "v1.2.0" \
  --format md \
  --ignore-project "Backlog" \
  --filter-labels "bug,platform" \
  --strip-emojis

# View aligned TSV columns after saving
cat report.tsv | column -ts $'\t'

# List available milestones (including closed) when a name isn't found
gm milestone report "nonexistent" --include-closed

# Interactive TUI view for a milestone
gm milestone view "v1.2.0"
```
