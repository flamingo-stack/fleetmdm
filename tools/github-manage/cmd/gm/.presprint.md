Implements the `pre-sprint` CLI command group for generating pre-sprint bug metrics reports from GitHub project drafting boards, filtering items by team label and outputting story point summaries.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `preSprintCmd` | `*cobra.Command` | Parent command (`gm pre-sprint`) grouping all pre-sprint utilities |
| `preSprintReportCmd` | `*cobra.Command` | Subcommand (`gm pre-sprint report`) that fetches drafting project items and computes per-team bug metrics |
| `preSprintLimit` | `int` flag | `--limit` / `-l`: max items to fetch from the drafting project (default `1000`) |
| `preSprintFormat` | `string` flag | `--format`: output format, either `out` (human-readable) or `csv` |

### Computed Metrics (per team)
- Unestimated bug count
- Total story points of estimated bugs
- Story points of priority bugs (`P0`/`P1`/`P2`)
- Story points of customer-reported bugs (`customer-*` label prefix)
- Overlap story points (bugs that are both priority and customer-reported)

## Usage Example

```bash
# Human-readable report for a single team
gm pre-sprint report mdm

# CSV report for multiple teams (comma-separated aliases)
gm pre-sprint report mdm,sec,orch --format csv

# Increase item fetch limit
gm pre-sprint report soft --limit 2000
```

```text
Pre-sprint report for mdm
Total number of unestimated bugs: 3
Total story points of estimated bugs: 21
Total story points of priority bugs: 13
Total story points of customer reported bugs: 8
Total overlap of priority and customer bugs: 5
```

## Notes

- Team identifiers are resolved via `ghapi.ResolveProjectID` and must have a drafting label mapping (`mdm`, `soft`, `orch`, `sec`).
- Status filtering uses the drafting project's `"ready to estimate"` and `"estimated"` field values, resolved dynamically via `ghapi.FindFieldValueByName`.
- Helper logic (`StatusMatches`, `HasLabel`, `HasLabelPrefix`, `HasAnyLabel`) lives in [`pkg/util`](https://github.com/flamingo-stack/fleetmdm/blob/main/gm/pkg/util).
