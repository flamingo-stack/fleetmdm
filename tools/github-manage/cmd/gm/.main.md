Entry point for the `gm` (GitHub Manage) CLI tool, initializing the logger and registering all subcommands via [Cobra](https://github.com/spf13/cobra).

## Key Components

| Component | Description |
|---|---|
| `rootCmd` | The root Cobra command (`gm`) with persistent pre-run logging of command path, args, and changed flags |
| `PersistentPreRun` | Logs the full command invocation (path, args, and explicitly set flags) before any subcommand executes |
| `test` command | Development utility that calls `ghapi.GetIssues` against a hardcoded issue number for ad-hoc testing |

### Registered Subcommands

| Command | Variable |
|---|---|
| Issues | `issuesCmd` |
| Issues with historical labels | `issuesWithHistoricalLabelCmd` |
| Project | `projectCmd` |
| Estimated | `estimatedCmd` |
| Sprint | `sprintCmd` |
| Milestone | `milestoneCmd` |
| Releases | `releasesCmd` |
| Pre-sprint | `preSprintCmd` |
| Bugs | `bugsCmd` |

## Usage Example

```bash
# Run the CLI (displays help)
gm

# Execute a subcommand
gm sprint

# Run the development test command
gm test
```

```go
// Logger and root command are initialized in main(); subcommands
// are defined in sibling files and registered here:
rootCmd.AddCommand(sprintCmd)
```

## Notes

- The `test` command targets issue `#31541` and is intended for local development only — remove or gate it behind a build flag before production use.
- See [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) for the full project source.
