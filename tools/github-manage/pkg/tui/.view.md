Renders the TUI model's various view states as formatted strings, including issue tables, detail panels, loading indicators, workflow selection, and filter input screens.

## Key Components

| Function | Description |
|---|---|
| `generateIssueContent` | Builds a formatted Markdown string for a single `ghapi.Issue`, including metadata, labels, assignees, milestone, and body |
| `RenderLoading` | Returns a spinner + contextual loading message based on the active `commandType` |
| `RenderWorkflowRunning` | Renders a windowed task list with status icons and overall progress bar during workflow execution |
| `RenderWorkflowComplete` | Renders the final task summary with success/error counts after a workflow finishes |
| `RenderIssueTable` | Renders the paginated, filterable issue list with cursor, selection state, estimate sum, and scroll indicators |
| `RenderIssueDetail` | Renders a single issue's detail viewport with navigation hints |
| `RenderFilterInput` | Renders the filter input prompt with a live 10-item preview of matching issues |
| `RenderWorkflowSelection` | Renders the workflow picker with cursor, selection radio buttons, and a wrapped description |
| `selectedWorkflowDescription` | Returns a human-readable description string for each `WorkflowType` |

## Usage Example

```go
// All render functions are called methods on model inside the bubbletea View() hook:
func (m model) View() string {
    switch m.state {
    case StateLoading:
        return m.RenderLoading()
    case StateIssueTable:
        return m.RenderIssueTable()
    case StateIssueDetail:
        return m.RenderIssueDetail()
    case StateFilterInput:
        return m.RenderFilterInput()
    case StateWorkflowSelection:
        return m.RenderWorkflowSelection()
    case StateWorkflowRunning:
        return m.RenderWorkflowRunning()
    case StateWorkflowComplete:
        return m.RenderWorkflowComplete()
    }
    return ""
}
```
