Handles all keyboard input routing for the TUI, dispatching key events to the appropriate handler based on the current `workflowState`.

## Key Components

### `HandleHotkeys(msg tea.Msg) (tea.Model, tea.Cmd)`

The central input dispatcher for the Bubble Tea model. Branches on `m.workflowState` to apply context-sensitive key bindings:

| State | Key Bindings |
|---|---|
| `Loading` / `WorkflowRunning` | `q`, `ctrl+c` → quit |
| `WorkflowComplete` | `q`, `ctrl+c`, `enter`, `esc`, `space` → quit |
| `NormalMode` | Full navigation, selection, filtering, and workflow initiation |
| `IssueDetail` | Scrollable viewport navigation; `esc` returns to list |
| `FilterInput` | Live incremental filter editing; `enter`/`esc` commits or clears |
| `WorkflowSelection` | Cursor navigation over workflow types; `enter` advances to next input stage |
| `LabelInput` / `ProjectInput` | Single-line text entry; `enter` triggers workflow execution |

**`NormalMode` hotkeys:**

| Key | Action |
|---|---|
| `/` | Enter filter mode |
| `j`/`k`, `↓`/`↑` | Move cursor |
| `pgdn`/`pgup`, `ctrl+f`/`ctrl+b` | Page navigation |
| `home`/`end`, `ctrl+a`/`ctrl+e` | Jump to first/last issue |
| `enter`, `x`, `space` | Toggle selection |
| `s` | Toggle selection of related issues (fetches via `ghapi.GetRelatedIssueNumbers`) |
| `l` / `h` | Select all visible / clear all |
| `o` | Open issue detail view (rendered via glamour) |
| `w` | Open workflow selection (requires at least one selected issue) |
| `q`, `ctrl+c` | Quit |

## Usage Example

```go
// Wired into the Bubble Tea Update loop:
func (m *model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    return m.HandleHotkeys(msg)
}
```
