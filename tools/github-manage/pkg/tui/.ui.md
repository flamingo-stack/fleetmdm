Provides the terminal user interface (TUI) for the FleetMDM GitHub management CLI, implementing a Bubble Tea-based interactive issue browser with multi-select, filtering, detail views, and bulk workflow execution.

## Key Components

| Export / Symbol | Description |
|---|---|
| `RunTUI` | Entry point that initializes and runs the Bubble Tea program for a given command type |
| `CommandType` | Enum distinguishing issue views: `IssuesCommand`, `ProjectCommand`, `EstimatedCommand`, `SprintCommand`, `MilestoneCommand` |
| `WorkflowState` | Enum tracking TUI state machine: `Loading`, `NormalMode`, `IssueDetail`, `FilterInput`, `WorkflowSelection`, `LabelInput`, `ProjectInput`, `WorkflowRunning`, `WorkflowComplete` |
| `WorkflowType` | Enum for bulk operations: label management, sprint kickoff, milestone close, demo summary, sprint moves |
| `model` | Core Bubble Tea model holding issue list, selection state, viewport, filter input, workflow tasks, and progress tracking |
| `initializeModel` | Constructs a base model with spinner, progress bar, glamour renderer, and viewport defaults |
| `fetchIssues` / `fetchProjectItems` / `fetchSprintItems` / etc. | `tea.Cmd` factories that call `ghapi` functions and return `issuesLoadedMsg` |
| `WorkflowTask` | Tracks per-task status (`Pending`, `InProgress`, `Success`, `Error`) and progress for bulk operations |

## Usage Example

```go
// Launch the TUI for current sprint issues
tui.RunTUI(tui.SprintCommand, projectID, 50, "")

// Launch for previous sprint
tui.RunTUI(tui.SprintCommand, projectID, 50, "previous")

// Launch for a specific milestone
tui.RunTUI(tui.MilestoneCommand, 0, 100, "Q3-2025")

// Launch with a GitHub search query
tui.RunTUI(tui.IssuesCommand, 0, 0, "is:open label:bug")
```
