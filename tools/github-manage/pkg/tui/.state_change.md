Handles TUI model state transitions by dispatching incoming Bubble Tea messages to update workflow state, task progress, and async operation status.

## Key Components

### `HandleStateChange(msg tea.Msg) (tea.Model, tea.Cmd)`

Central message dispatcher for the TUI model. Handles the following message types:

| Message Type | Behavior |
|---|---|
| `issuesLoadedMsg` | Populates issue list, resets to `NormalMode`, applies filters |
| `spinner.TickMsg` | Advances the loading spinner animation |
| `progress.FrameMsg` | Updates the overall progress bar frame |
| `tea.WindowSizeMsg` | Resizes the detail viewport on terminal resize |
| `startAsyncWorkflowMsg` | Initializes `AsyncManager` goroutine and status channel |
| `actionStatusMsg` | Updates individual task status from legacy action messages |
| `asyncStatusMsg` | Handles status updates from `AsyncManager`; transitions to `WorkflowComplete` on finish or error |
| `taskUpdateMsg` | Updates per-task progress; triggers next bulk label task with 50ms delay for serialization |
| `workflowExitMsg` | Sets exit message and quits the program |
| `workflowCompleteMsg` | Marks workflow done, optionally records error message |
| `workflowResultMsg` | Legacy handler that maps to `WorkflowComplete` state |

## Usage Example

```go
// HandleStateChange is called automatically by the Bubble Tea runtime via model.Update().
// It is typically wired in as the model's Update method:

func (m model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    return m.HandleStateChange(msg)
}

// When AsyncManager emits a status, listenForAsyncStatus wraps it as asyncStatusMsg:
func (m *model) listenForAsyncStatus() tea.Cmd {
    return func() tea.Msg {
        status := <-m.statusChan
        return asyncStatusMsg{status: status}
    }
}
```

## Notes

- `processTaskMsg` is retained for backwards compatibility but is a no-op; sequential processing is delegated to `ghapi.AsyncManager`.
- Overall progress is recomputed from scratch on each `asyncStatusMsg` and `taskUpdateMsg` to stay consistent with actual task completion counts.
