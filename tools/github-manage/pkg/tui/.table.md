Provides string formatting and truncation utilities for rendering GitHub issue data in a terminal UI table.

## Key Components

| Function | Description |
|---|---|
| `truncTitle` | Truncates issue titles to 50 characters, appending `...` if exceeded |
| `truncLables` | Formats a slice of `ghapi.Label` into a 35-character padded string, prioritizing known labels and appending `...+n` for overflow |
| `truncEstimate` | Formats a numeric estimate into a 9-character padded string, substituting `-` for zero |
| `truncType` | Formats an issue type string into a 10-character padded/truncated string, substituting `-` for empty |

## Usage Example

```go
title := truncTitle("This is a very long issue title that exceeds the fifty character limit")
// Output: "This is a very long issue title that exceeds the..."

labels := []ghapi.Label{
    {Name: "bug"},
    {Name: "story"},
    {Name: "#g-mdm"},
}
labelStr := truncLables(labels)
// Output: "bug, story, #g-mdm             " (padded to 35 chars)

est := truncEstimate(0)
// Output: "-        " (padded to 9 chars)

typename := truncType("enhancement")
// Output: "enhancement" (trimmed to 10 chars)
```

## Label Priority Order

`truncLables` applies the following priority before fitting within the 30-character display budget:

1. `story`, `bug`, `:release`, `:product`
2. `#g-mdm`, `#g-orchestration`, `#g-software`
3. All remaining labels (appended after priority labels)
