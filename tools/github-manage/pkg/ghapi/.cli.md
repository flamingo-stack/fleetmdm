Provides a utility for executing shell commands via bash and capturing their combined stdout/stderr output as a byte slice.

## Key Components

- **`RunCommandAndReturnOutput(command string) ([]byte, error)`** — Executes a bash command string, captures combined stdout and stderr, logs debug/error output via the internal logger, and returns the result.

## Usage Example

```go
output, err := ghapi.RunCommandAndReturnOutput("git status --short")
if err != nil {
    log.Fatalf("command failed: %v", err)
}
fmt.Println(string(output))
```

> **Note:** Both stdout and stderr are merged into the returned byte slice. On failure, the combined output is logged at error level before returning `nil, err`.
