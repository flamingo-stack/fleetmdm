Provides GitHub milestone and project integration utilities for querying issues, project statuses, and milestone metadata via the `gh` CLI and GitHub GraphQL API.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GetIssuesByMilestone` | func | Returns issue numbers for a milestone (open + closed) |
| `GetIssuesByMilestoneWithTitles` | func | Returns `MilestoneIssue` records (number, title, labels, assignees) for a milestone |
| `GetIssueProjects` | func | Returns project ID→title map for a single issue via GraphQL |
| `GetProjectsForIssues` | func | Aggregates the union of projects across multiple issues with optional progress callback |
| `GetIssueProjectStatuses` | func | Returns per-project `ProjectStatus` (presence + Status field value) for an issue |
| `GetMilestoneOpenIssueCount` | func | Returns open issue count for a milestone using GraphQL search |
| `ListRepoMilestones` | func | Lists repo milestones (open or all), paginated, sorted open-first |
| `MilestoneIssue` | struct | Issue record: number, title, labels, assignees |
| `ProjectInfo` | struct | Project descriptor: ID and title |
| `ProjectStatus` | struct | Project membership status: `Present` bool + `Status` string |
| `RepoMilestone` | struct | REST API milestone: number, title, state |

## Usage Example

```go
// List open issues in a milestone with titles
issues, err := ghapi.GetIssuesByMilestoneWithTitles("v1.2.0", 500)
if err != nil {
    log.Fatal(err)
}

// Gather projects across those issues, printing progress
nums := make([]int, len(issues))
for i, iss := range issues {
    nums[i] = iss.Number
}
projects, err := ghapi.GetProjectsForIssues(nums, func(current, total, issueNum int) {
    fmt.Printf("[%d/%d] scanning issue #%d\n", current, total, issueNum)
})

// Check status of issue #42 across specific projects
statuses, err := ghapi.GetIssueProjectStatuses(42, []int{projects[0].ID})
if ps, ok := statuses[projects[0].ID]; ok && ps.Present {
    fmt.Println("Status:", ps.Status)
}

// Count open issues in a milestone
count, err := ghapi.GetMilestoneOpenIssueCount("v1.2.0")
fmt.Printf("Open issues: %d\n", count)
```

> **Note:** All functions rely on the `gh` CLI being authenticated. `GetIssueProjectStatuses` and `GetMilestoneOpenIssueCount` include automatic retry with exponential backoff on GitHub rate limit responses (up to 5 attempts, capped at 30s delay).
