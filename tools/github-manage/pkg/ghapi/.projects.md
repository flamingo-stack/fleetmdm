Provides GitHub Projects v2 management utilities for FleetDM's internal tooling, including project item retrieval, field lookups, sprint filtering, and GraphQL mutation helpers via the `gh` CLI.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Aliases` | `map[string]int` | Human-friendly shortnames (e.g., `"mdm"`, `"sec"`) mapped to numeric GitHub project IDs |
| `ProjectLabels` | `map[int]string` | Maps project IDs to their label filter strings |
| `ResolveProjectID` | func | Resolves an alias or numeric string to a project ID |
| `GetProjectItems` / `GetProjectItemsWithTotal` | func | Fetches all items from a project via `gh project item-list` |
| `GetCurrentSprintItems` / `GetCurrentSprintItemsWithTotal` | func | Filters project items to those in the active sprint iteration |
| `GetPreviousSprintItems` / `GetPreviousSprintItemsWithTotal` | func | Filters project items to those in the immediately preceding sprint |
| `GetProjectFields` / `LoadProjectFields` | func | Retrieves and caches project field definitions |
| `LookupProjectFieldName` | func | Case-insensitive field lookup by name |
| `FindFieldValueByName` | func | Partial-match search for a field option value |
| `SetProjectItemFieldValue` | func | Updates a project item field (number, single-select, or iteration) via GraphQL mutation |
| `ParseJSONtoProjectItems` | func | Deserializes `gh` CLI JSON output into `[]ProjectItem` |

## Usage Example

```go
// Resolve a project alias to its numeric ID
projectID, err := ghapi.ResolveProjectID("mdm")
if err != nil {
    log.Fatal(err)
}

// Fetch all items in the current sprint (up to 500)
items, total, err := ghapi.GetCurrentSprintItemsWithTotal(projectID, 500)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Sprint items: %d / %d total\n", len(items), total)

// Update a single-select field on an item
err = ghapi.SetProjectItemFieldValue(
    "PVTI_abc123",  // item node ID
    projectID,
    "Status",
    "In Progress",
)
```

## Notes

- All `gh` CLI commands target the `fleetdm` org owner; adjust the `--owner` flag if needed.
- Sprint filtering relies on the project having a field named `"sprint"` (case-insensitive). Projects without this field return an empty slice rather than an error.
- Field definitions are cached in `MapProjectFieldNameToField` to avoid redundant API calls within a single process run.
- Source: [`ghapi/projects.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/ghapi/projects.go)
