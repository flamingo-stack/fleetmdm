Parses, fetches, and manages GitHub issues via the `gh` CLI, providing label operations, milestone assignment, project membership, status/sprint field updates, and timeline-based label history queries.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `ParseJSONtoIssues` | func | Unmarshals raw JSON bytes into a `[]Issue` slice |
| `GetIssues` | func | Lists issues with an optional `gh issue list -S` search filter |
| `GetIssuesByMilestoneLimited` | func | Returns up to N milestone issues; the extra-fetch trick surfaces whether more exist |
| `AddLabelToIssue` / `RemoveLabelFromIssue` | func | Thin wrappers around `gh issue edit --add-label / --remove-label` |
| `CloseIssue` | func | Closes an issue via `gh issue close` |
| `SetMilestoneToIssue` | func | Assigns a milestone string to an issue |
| `AddIssueToProject` / `RemoveIssueFromProject` | func | Adds/removes a project item; removal resolves the internal item ID first |
| `SyncEstimateField` | func | Copies the `Estimate` project field value from a source project to a target project |
| `SetCurrentSprint` | func | Sets the `sprint` project field to `@current` |
| `SetIssueStatus` | func | Sets the `Status` project field to an arbitrary string |
| `IssueEvent` | struct | Single timeline event (event type, label, timestamp) |
| `GetIssueTimeline` | func | Fetches paginated timeline events for one issue via the REST API |
| `IssueHadLabel` | func | Returns `true` if a label was ever applied (even if since removed) |
| `GetIssuesCreatedSinceWithLabel` | func | Pages through all issues newer than a date and concurrently checks each for historical label presence |

## Usage Example

```go
// Fetch issues on a milestone, cap at 50
issues, exceeded, err := ghapi.GetIssuesByMilestoneLimited("v1.2.0", 50)
if err != nil {
    log.Fatal(err)
}
if exceeded {
    log.Println("warning: more than 50 issues exist on this milestone")
}

// Label, milestone, and project operations
_ = ghapi.AddLabelToIssue(42, "bug")
_ = ghapi.SetMilestoneToIssue(42, "v1.3.0")
_ = ghapi.AddIssueToProject(42, 7)
_ = ghapi.SetIssueStatus(42, 7, "In Progress")

// Check whether issue #99 ever carried the "breaking change" label
had, err := ghapi.IssueHadLabel("org/repo", 99, "breaking change", false)
```

## Notes

- All commands delegate to the `gh` CLI through `RunCommandAndReturnOutput`; a working, authenticated `gh` installation is required.
- `GetIssuesCreatedSinceWithLabel` uses a bounded goroutine pool (semaphore + `sync.WaitGroup`) controlled by the `concurrency` parameter to parallelise timeline fetches while avoiding rate-limit exhaustion.
- The file is part of the `ghapi` package at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
