Defines view types and display templates for GitHub project items, and provides functions to retrieve estimated tickets from GitHub Projects filtered by project label.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `ViewType` | Type | String alias representing a view category (`issue_list`, `issue_detail`, `project_detail`) |
| `View` | Struct | Holds a view's type, title, and optional search filters |
| `NewView` | Function | Constructor for `View` with variadic filters |
| `GetMDMTicketsEstimated` | Function | Convenience wrapper that fetches estimated tickets for the MDM project (ID 58) |
| `GetEstimatedTicketsForProject` | Function | Fetches estimated tickets for any project ID up to a fetch limit |
| `GetEstimatedTicketsForProjectWithTotal` | Function | Same as above but also returns the unfiltered total item count, enabling callers to detect pagination gaps |
| `MDM_LABEL` | Constant | GitHub label string `#g-mdm` used to identify MDM-related issues |

## Usage Example

```go
// Fetch estimated MDM tickets (project 58, limit 500)
items, err := GetMDMTicketsEstimated()
if err != nil {
    log.Fatal(err)
}

// Fetch with pagination awareness
items, total, err := GetEstimatedTicketsForProjectWithTotal(58, 100)
if err != nil {
    log.Fatal(err)
}
if total > 100 {
    log.Printf("warning: %d total items, only first 100 fetched", total)
}

// Build a custom issue list view
v := NewView(ISSUE_LIST, "Open MDM Issues", "label:"+MDM_LABEL, "is:open")
fmt.Println(v.Title, v.Filters)
```

## Notes

- `GetEstimatedTicketsForProjectWithTotal` resolves the drafting project via the `Aliases["draft"]` map and matches items by both the project-specific label (from `ProjectLabels`) and a Status field value of `"estimated"`.
- If no label mapping exists for the given `projectID`, the function returns an error listing available project IDs.
