Provides GitHub user data retrieval with an in-memory cache, parsing GitHub API JSON responses into `User` structs via the `gh` CLI.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `username_mapping` | `map[string]string` | In-memory cache mapping login handles to full names |
| `ParseJSONtoUser` | `func` | Unmarshals raw JSON bytes into a `User` struct |
| `GetUserName` | `func` | Fetches a GitHub user by login, with cache-first lookup |

## Usage Example

```go
// Fetch a user by their GitHub login handle
user, err := ghapi.GetUserName("octocat")
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Login: %s, Name: %s\n", user.Login, user.Name)

// Subsequent calls for the same login are served from cache
cachedUser, _ := ghapi.GetUserName("octocat") // No API call made
```

## Behavior Notes

- **Cache-first:** `GetUserName` checks `username_mapping` before invoking the GitHub CLI, avoiding redundant API calls within a process lifetime.
- **CLI dependency:** Executes `gh api /users/<login>` via `RunCommandAndReturnOutput`; requires the `gh` CLI to be authenticated and available on `$PATH`.
- **No persistence:** The cache is reset on each process start (`init()` reinitializes the map).
