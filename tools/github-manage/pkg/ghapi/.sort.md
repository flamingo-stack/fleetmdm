Provides stable multi-criteria sorting for GitHub issues, ordering them by priority label, customer/prospect presence, issue type, and issue number for display purposes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SortIssuesForDisplay` | `func` | Public entry point; sorts a `[]Issue` slice in-place using four-level precedence |
| `priorityRank` | `func` | Returns `0–3` based on `P0`/`P1`/`P2` labels (or `3` if none present) |
| `custProspectRank` | `func` | Returns `0` if any label starts with `customer-` or `prospect-`, else `1` |
| `typeRank` | `func` | Returns `0–3` mapped to `story`, `bug`, `~sub-task`, or other |
| `hasAnyLabelPrefix` | `func` | Case-insensitive prefix check across all labels on an issue |
| `labelNamesLower` | `func` | Builds a lowercase label-name set for O(1) lookup |

## Sorting Precedence

```text
1. Priority    P0 → P1 → P2 → (none)
2. Affiliation customer-* / prospect-* labels first
3. Type        story → bug → ~sub-task → other
4. Number      descending (newest first as tiebreaker)
```

## Usage Example

```go
issues := []ghapi.Issue{
    {Number: 101, Labels: []ghapi.Label{{Name: "P1"}, {Name: "bug"}}},
    {Number: 205, Labels: []ghapi.Label{{Name: "P0"}, {Name: "customer-acme"}}},
    {Number: 88,  Labels: []ghapi.Label{{Name: "story"}}},
}

ghapi.SortIssuesForDisplay(issues)

// Result order:
// 1. #205  — P0, customer-acme
// 2. #101  — P1, bug
// 3. #88   — no priority, story
```

`sort.SliceStable` preserves the original relative order of equal-ranked issues, making repeated sorts predictable.
