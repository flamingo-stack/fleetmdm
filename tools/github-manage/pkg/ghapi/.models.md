Data models and type definitions for the `ghapi` package, representing GitHub API entities such as issues, labels, milestones, project items, and users.

## Key Components

| Type | Description |
|---|---|
| `Author` | GitHub user with login, name, ID, and bot flag |
| `Label` | Issue label with ID, name, description, and color |
| `Milestone` | Project milestone with number, title, description, and due date |
| `Issue` | Full issue representation including assignees, labels, milestone, and custom fields (estimate, status) |
| `Sprint` | Iteration/sprint metadata with duration, ID, start date, and title |
| `ProjectDetails` | GitHub Project (v2) metadata including owner, visibility, and item/field counts |
| `ProjectItem` | A single item within a GitHub Project with sprint, status, size, and estimate |
| `ProjectField` | A custom project field with optional dropdown options |
| `User` | Full GitHub REST API user object |

### Methods

- **`Issue.HasLabel(labelName string) bool`** — Case-insensitive check for a label on an issue.

### Functions

- **`ConvertItemsToIssues(items []ProjectItem) []Issue`** — Maps `ProjectItem` slice to `Issue` slice, deriving `Typename` from label names (`"story"` → `Feature`, `"bug"` → `Bug`, `"~sub-task"` → `Task`).

## Usage Example

```go
items := []ghapi.ProjectItem{
    {
        ID: "PI_123",
        Content: ghapi.ProjectItemContent{
            Number: 42,
            Title:  "Fix login bug",
            Body:   "Users cannot log in.",
        },
        Labels:    []string{"bug"},
        Assignees: []string{"alice"},
        Status:    "In Progress",
        Estimate:  3,
    },
}

issues := ghapi.ConvertItemsToIssues(items)
// issues[0].Typename == "Bug"

if issues[0].HasLabel("bug") {
    fmt.Println("Tagged as bug")
}
```
