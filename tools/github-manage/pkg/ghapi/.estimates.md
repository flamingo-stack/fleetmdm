Provides GitHub Projects estimate lookup, aggregation, and sprint membership utilities for issues across multiple project boards.

## Key Components

| Function | Description |
|---|---|
| `DefaultEstimateSourceProjects()` | Returns the default project IDs to scan for estimates (draft, mdm, g-software, g-orchestration, g-security-compliance) |
| `GetEstimateFromProject()` | Fetches a numeric estimate for a single issue from a specific project |
| `GetEstimateForIssueAcrossProjects()` | Scans multiple projects in order, returning the first non-zero estimate found |
| `GetEstimateFromAnyProject()` | Returns the first positive estimate respecting preferred project order, backed by GraphQL cache |
| `SumEstimatesFromSubIssues()` | Sums estimates of all direct child issues across provided projects |
| `SetEstimateInProject()` | Writes an estimate value to the `Estimate` field for an issue in a project |
| `IsIssueInProject()` | Checks whether an issue belongs to a given project |
| `IssueInSprint()` | Checks whether an issue has a matching sprint title across a set of projects |
| `GetIssueNumbersForSprint()` | Lists all issue numbers in a project matching a given sprint title |
| `GetIssueNumbersForSprintAcrossProjects()` | Union of issue numbers matching a sprint across multiple projects |
| `getIssueEstimatesAcrossProjects()` | Internal — single GraphQL call fetching all project estimates for an issue, with RW-mutex cache |

## Usage Example

```go
// Get estimate for issue #42, preferring known source projects
projects := DefaultEstimateSourceProjects()
estimate, fromProject, err := GetEstimateFromAnyProject(42, projects)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Issue #42 estimate: %d (from project %d)\n", estimate, fromProject)

// Sum child issue estimates
total, err := SumEstimatesFromSubIssues(42, projects)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Sub-issue total: %d\n", total)

// Find all issues in a sprint across projects
issueSet, err := GetIssueNumbersForSprintAcrossProjects(projects, "Sprint 14", 500)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Sprint 14 has %d issues\n", len(issueSet))

// Write an estimate back to a specific project
if err := SetEstimateInProject(42, Aliases["mdm"], 5); err != nil {
    log.Fatal(err)
}
```

## Notes

- `getIssueEstimatesAcrossProjects` uses an in-process `sync.RWMutex`-protected cache keyed by issue number to avoid redundant GraphQL calls within a single run.
- `GetEstimateForIssueAcrossProjects` falls back to per-project serial lookups if the GraphQL call fails.
- `SetEstimateInProject` is a no-op for estimates ≤ 0 to avoid writing blank/invalid values.
