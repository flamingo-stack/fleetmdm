A simple file-based logging package that initializes three leveled loggers (`INFO`, `ERROR`, `DEBUG`) writing to a `dgm.log` file in the current working directory.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `InfoLogger` | `*log.Logger` | Global logger for informational messages |
| `ErrorLogger` | `*log.Logger` | Global logger for error messages |
| `DebugLogger` | `*log.Logger` | Global logger for debug messages |
| `Init()` | `func` | Creates/opens `dgm.log` and wires up all three loggers |
| `SetOutput()` | `func` | Redirects all loggers to a custom `io.Writer` (useful for tests) |
| `Info/Infof` | `func` | Log at INFO level (plain and formatted) |
| `Error/Errorf` | `func` | Log at ERROR level (plain and formatted) |
| `Debug/Debugf` | `func` | Log at DEBUG level (plain and formatted) |

Each logger writes with a level prefix plus date, time, and short filename (e.g., `INFO: 2024/01/15 10:30:00 main.go:42`).

## Usage Example

```go
package main

import "github.com/flamingo-stack/fleetmdm/logger"

func main() {
    if err := logger.Init(); err != nil {
        log.Fatal("failed to initialize logger:", err)
    }

    logger.Info("application started")
    logger.Infof("listening on port %d", 8080)
    logger.Debug("loaded config:", cfg)
    logger.Errorf("database connection failed: %v", err)
}
```

**Redirecting output in tests:**

```go
func TestSomething(t *testing.T) {
    logger.Init()
    logger.SetOutput(io.Discard) // suppress log output during tests

    // ... test logic
}
```

> **Note:** All log/print calls are nil-safe — if `Init()` has not been called, log calls are silently skipped.
