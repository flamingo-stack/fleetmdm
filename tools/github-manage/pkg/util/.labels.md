Utility functions for matching labels in string slices, supporting case-insensitive and prefix-based lookups.

## Key Components

| Function | Description |
|---|---|
| `HasLabel` | Checks if a label slice contains an exact match (case-insensitive, whitespace-trimmed) |
| `HasAnyLabel` | Returns true if any of the provided target labels are found in the slice |
| `HasLabelPrefix` | Checks if any label in the slice starts with the given prefix (case-insensitive) |

## Usage Example

```go
labels := []string{"os:macos", "team: platform", "Priority-High"}

// Exact match (case-insensitive, trimmed)
util.HasLabel(labels, "priority-high")      // true
util.HasLabel(labels, "os:windows")         // false

// Match any of several labels
util.HasAnyLabel(labels, "os:windows", "os:macos") // true

// Prefix match
util.HasLabelPrefix(labels, "os:")          // true
util.HasLabelPrefix(labels, "team:")        // true
util.HasLabelPrefix(labels, "env:")         // false
```

## Notes

- All comparisons normalize input via `strings.ToLower` and `strings.TrimSpace`, making matching robust against inconsistent casing or whitespace in label data (e.g., from Fleet MDM API responses).
