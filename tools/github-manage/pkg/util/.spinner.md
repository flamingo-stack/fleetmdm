Provides a terminal spinner utility that displays an animated inline progress indicator while a long-running operation completes.

## Key Components

- **`StartSpinner(msg string) func()`** — Launches a goroutine that cycles through `|`, `/`, `-`, `\` characters at 100ms intervals, prefixed with the provided message. Returns a stop function that, when called, closes the done channel and prints a final `"... done."` line.

## Usage Example

```go
package main

import (
    "time"
    "github.com/flamingo-stack/fleetmdm/util"
)

func main() {
    stop := util.StartSpinner("Enrolling device")
    // perform long-running work
    time.Sleep(3 * time.Second)
    stop() // prints: "Enrolling device... done."
}
```

> **Note:** Call the returned stop function exactly once. Calling it multiple times will panic due to double-closing the channel.

## Behavior

| State | Output |
|---|---|
| Running | `\rEnrolling device \|` (updates in place) |
| Stopped | `\rEnrolling device... done.\n` |
