Provides a case-insensitive, whitespace-tolerant helper for comparing a status string against one or more candidate values.

## Key Components

- **`StatusMatches(status string, names ...string) bool`** — Returns `true` if `status` matches any value in `names`, after trimming surrounding whitespace and normalizing both sides to lowercase.

## Usage Example

```go
StatusMatches("  Active ", "active", "enabled") // true
StatusMatches("PENDING", "active", "enabled")   // false
StatusMatches("Online", "online")               // true
```
