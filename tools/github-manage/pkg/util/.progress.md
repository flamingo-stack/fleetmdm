Provides an inline terminal progress bar that writes to stderr, keeping stdout clean for report output.

## Key Components

### `ProgressBar` struct
Holds rendering state: label, total step count, bar width, start time, and a terminal-detection flag (`enabled`).

| Field | Purpose |
|---|---|
| `label` | Prefix text shown before the bar |
| `total` | Total number of steps |
| `width` | Character width of the filled/empty bar (default: 30) |
| `enabled` | Auto-disabled when stderr is not a TTY |

### Functions

| Symbol | Description |
|---|---|
| `NewProgressBar(label, total)` | Constructs a `ProgressBar`; auto-detects TTY via `go-isatty` (supports Cygwin) |
| `Update(current, detail)` | Redraws the bar in-place using `\r\033[K`; clamps `current` to `[0, total]`; appends optional detail string and ETA |
| `Done()` | Prints a final newline so the next log line starts cleanly |
| `eta(current)` | Private; computes remaining time from average duration per completed step, rounded to the nearest second |

## Usage Example

```go
items := fetchAllIssues()
bar := util.NewProgressBar("Fetching issues", len(items))

for i, issue := range items {
    bar.Update(i+1, fmt.Sprintf("#%d", issue.Number))
    processIssue(issue)
}

bar.Done()
```

**Example output in a terminal:**
```text
Fetching issues [██████████████░░░░░░░░░░░░░░░░] 14/30 (47%) #46029 ETA 8s
```

## Behaviour Notes

- **No-op when not a TTY** — silently skips all rendering if stderr is redirected or piped, preventing garbage characters in logs or files
- **nil-safe** — `Update` and `Done` both guard against a nil receiver
- **ETA suppressed** at step 0 and the final step to avoid misleading output
