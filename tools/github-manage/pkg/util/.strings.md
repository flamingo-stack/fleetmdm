Utility functions for Unicode-aware string manipulation, including emoji stripping, sort normalization, title truncation, and shell escaping.

## Key Components

| Function | Description |
|---|---|
| `StripEmojis(s string) string` | Removes emoji characters (ranges `0x1F300–0x1FAFF`, `0x2600–0x27BF`) and zero-width joiners/variation selectors, returning trimmed plain text |
| `PlainForSort(s string) string` | Lowercases and strips emojis to produce a normalized key suitable for consistent sorting |
| `TruncateTitle(s string, maxRunes int) string` | Rune-aware truncation that appends `"..."` when the string exceeds `maxRunes` |
| `EscapeSingleQuotes(s string) string` | Escapes single quotes using the `'\''` shell idiom for safe inclusion in single-quoted shell strings |
| `SafeRuneLen(s string) int` | Returns the rune count of a string via `utf8.RuneCountInString` |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/util"
)

func main() {
    raw := "🚀 Fleet Status 🛡️"

    // Strip emojis for display
    plain := util.StripEmojis(raw)
    fmt.Println(plain) // "Fleet Status"

    // Normalize for sorting
    sortKey := util.PlainForSort(raw)
    fmt.Println(sortKey) // "fleet status"

    // Truncate long titles
    title := util.TruncateTitle("My Very Long Device Name", 10)
    fmt.Println(title) // "My Very Lo..."

    // Escape for shell usage
    query := util.EscapeSingleQuotes("it's a device")
    fmt.Println(query) // "it'\''s a device"

    // Rune-safe length
    fmt.Println(util.SafeRuneLen("héllo")) // 5
}
```

## Notes

- `StripEmojis` handles zero-width joiners (`U+200D`, `U+200C`, `U+200B`) and variation selector `U+FE0F`, which are commonly embedded invisibly within emoji sequences.
- `TruncateTitle` iterates over rune boundaries (not byte offsets), making it safe for multi-byte UTF-8 strings.
- `EscapeSingleQuotes` uses the POSIX-standard `'\''` escape sequence — suitable for shell command construction but **not** for SQL escaping.
