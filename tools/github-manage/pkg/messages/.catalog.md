Provides a centralized catalog of human-friendly UI messages for loading states and limit warnings used across CLI output.

## Key Components

### `LoadingMessage(key string, projectID int, hint string) string`
Returns a contextual loading message based on a string key. Accepts an optional `projectID` (integer) and `hint` (string) for message interpolation.

| Key | Output |
|---|---|
| `"issues"` | `Fetching Issues...` |
| `"project"` | `Fetching Project Items (ID: <id>)...` |
| `"estimated"` | `Fetching Estimated Tickets (Project: <id>)...` |
| `"sprint"` | `Fetching Sprint Items (Project: <id>)...` |
| `"milestone"` | `Fetching Milestone Issues (<hint>)...` |
| _(default)_ | `Fetching...` |

### `LimitExceeded(missing, limit, total int) string`
Returns a formatted warning banner when fetched results are truncated by a CLI `--limit` flag.

## Usage Example

```go
// Loading messages
fmt.Println(messages.LoadingMessage("issues", 0, ""))
// Output: Fetching Issues...

fmt.Println(messages.LoadingMessage("project", 42, ""))
// Output: Fetching Project Items (ID: 42)...

fmt.Println(messages.LoadingMessage("milestone", 0, "v1.2.0"))
// Output: Fetching Milestone Issues (v1.2.0)...

// Limit exceeded warning
fmt.Println(messages.LimitExceeded(50, 100, 150))
// Output: ⚠ 50 items not shown (limit=100, total=150). Increase --limit to include all issues.
```

## Notes

- Pass `0` for `projectID` and `""` for `hint` when those fields are not relevant to the selected key.
- Unrecognized keys fall back to `"Fetching..."` — no panic or error is returned.
