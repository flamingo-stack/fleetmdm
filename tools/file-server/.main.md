A minimal HTTP file server used exclusively for testing purposes, serving static files from a specified directory on a given port.

## Key Components

- **`main()`** — Entrypoint that wires up an `http.FileServer` backed by a local directory and starts listening for connections.

## CLI Arguments

| Position | Description |
|---|---|
| `os.Args[1]` | Port number to listen on (e.g., `8080`) |
| `os.Args[2]` | Directory path to serve files from (e.g., `./static`) |

## Usage Example

```bash
# Serve files from ./testdata on port 8080
go run main.go 8080 ./testdata
```

```go
// Equivalent behavior in code:
fs := http.FileServer(http.FS(os.DirFS("./testdata")))
http.Handle("/", fs)
http.ListenAndServe("0.0.0.0:8080", nil)
```

## Notes

- Binds to `0.0.0.0` (all interfaces), not just localhost.
- The `gosec` linter warning (`G114`) is explicitly suppressed — this server is **not** intended for production use.
- Panics on startup failure (e.g., port already in use).
