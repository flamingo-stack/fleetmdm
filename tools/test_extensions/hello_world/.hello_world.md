A minimal osquery extension that registers a custom `hello_world` table, demonstrating how to connect an extension manager server to osqueryd via a UNIX domain socket.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `socket` | flag | Path to the osqueryd extensions UNIX domain socket |
| `timeout` | flag | Seconds to wait for autoloaded extensions (default: 3) |
| `interval` | flag | Seconds between connectivity/ping checks (default: 3) |
| `extensionName` | string | Registered extension identifier (`test_extensions.hello_world`) |
| `tableName` | string | Virtual table exposed to osquery (`hello_world`) |
| `main()` | func | Parses flags, connects to osqueryd with retry logic, registers the table plugin, and starts the server |

## Key Behaviors

- **Retry logic:** Uses `backoff.WithMaxRetries` to attempt connection every 200ms for up to 5 seconds (25 retries) before fatal exit.
- **Table schema:** Exposes a single text column `hello` that always returns the static value `world`.
- **Verbose flag:** Declared but intentionally unused (`_`) — required because osqueryd injects `--verbose` when launching extensions in verbose mode.

## Usage Example

```bash
# Build the extension
go build -o hello_world hello_world.go

# Run osqueryd and load the extension via socket
osqueryd --extensions_socket /tmp/osquery.sock &

# Start the extension, pointing to the socket
./hello_world --socket /tmp/osquery.sock --timeout 5 --interval 3
```

Once running, query the virtual table from osqueryi:

```sql
SELECT * FROM hello_world;
-- Returns: hello = "world"
```
