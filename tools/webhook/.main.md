A minimal HTTP server that receives JSON payloads, pretty-prints them to stdout via the standard logger, and returns HTTP 200. Intended for testing and local webhook inspection.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | `func` | Entry point — registers a single catch-all HTTP handler and starts listening on the port supplied as the first CLI argument (`os.Args[1]`) |

**Request handler behaviour:**

1. Reads the full request body with `io.ReadAll`
2. Unmarshals the body as generic JSON (`interface{}`)
3. Re-marshals with `json.MarshalIndent` for human-readable output
4. Logs the indented JSON via `log.Printf`
5. Responds with `HTTP 200 OK`

## Usage Example

```bash
# Start the server on port 8080
go run main.go 8080
```

```bash
# Send a test JSON payload
curl -X POST http://localhost:8080/ \
  -H "Content-Type: application/json" \
  -d '{"event":"mdm.enrollment","device":"ABC123"}'
```

Expected log output:

```text
2024/01/15 12:00:00 {
  "device": "ABC123",
  "event": "mdm.enrollment"
}
```

> **Note:** The `//nolint:gosec` comment on `ListenAndServe` acknowledges that binding to `0.0.0.0` is intentional for testing. Do not use this server in production — it has no authentication, TLS, or input size limits.
