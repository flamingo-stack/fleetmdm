HTTP middleware that enforces Bearer token authentication on incoming requests, using constant-time comparison to prevent timing attacks.

## Key Components

### `bearerAuthMiddleware(token string, next http.Handler) http.Handler`

Wraps an `http.Handler` with Bearer token validation. Requests missing or presenting an incorrect `Authorization` header receive a `401 Unauthorized` response immediately. Valid requests are passed through to `next`.

- **Timing safety:** Uses `crypto/subtle.ConstantTimeCompare` to avoid leaking token information through response timing differences.
- **Expected format:** `Authorization: Bearer <token>`

## Usage Example

```go
mux := http.NewServeMux()
mux.HandleFunc("/api/devices", handleDevices)

token := os.Getenv("API_TOKEN")
protected := bearerAuthMiddleware(token, mux)

http.ListenAndServe(":8080", protected)
```

Requests without a valid token:

```bash
# Rejected — 401 Unauthorized
curl http://localhost:8080/api/devices

# Accepted
curl -H "Authorization: Bearer mysecrettoken" http://localhost:8080/api/devices
```

## Notes

- The entire handler chain is protected when `bearerAuthMiddleware` wraps the root mux. Wrap individual routes instead if only a subset of endpoints require authentication.
- Token value should be sourced from an environment variable or secrets manager — never hardcoded.
