Manages the osquery/Fleet table schema lifecycle: embedding a vendored snapshot at build time, refreshing it periodically from the canonical Fleet monorepo URL, and exposing typed query helpers used by MCP tool handlers.

## Key Components

### Types

| Type | Purpose |
|------|---------|
| `SchemaTable` | Source-of-truth struct for an osquery/Fleet table (name, platforms, columns, etc.) |
| `Column` | A single column definition with type, description, and optional flags |
| `schemaSource` | Metadata describing where the in-memory schema was loaded from (`"live"` vs `"embed"`) |

### Functions

| Function | Purpose |
|----------|---------|
| `StartSchemaRefresh(interval)` | Spawns a background goroutine to refresh the schema periodically; respects `FLEET_MCP_SCHEMA_REFRESH_DISABLE` and `FLEET_MCP_SCHEMA_REFRESH_INTERVAL` env vars |
| `RefreshSchemaNow()` | One-shot fetch from `canonicalSchemaURL`; retains previous schema on failure |
| `GetOsquerySchema(platform)` | Returns a curated security-ops subset of tables filtered by platform |
| `GetOsquerySchemaForTables(names)` | Returns full canonical schema for a specific list of table names (case-insensitive) |
| `IsTableSupportedOnPlatform(table, platform)` | Returns `true` if a table supports the given platform, or if the table is unknown |
| `SchemaSource()` | Atomic read of current schema provenance metadata |

## Usage Example

```go
// Start background refresh (24h default, overridable via env)
StartSchemaRefresh(0)

// Get curated tables for macOS
tables, err := GetOsquerySchema("darwin")

// Look up specific tables by name
tables, err := GetOsquerySchemaForTables([]string{"processes", "listening_ports"})

// Check platform compatibility before building a live query
if IsTableSupportedOnPlatform("bitlocker_info", "windows") {
    // safe to query
}

// Inspect where the schema data came from
src := SchemaSource()
fmt.Printf("origin=%s fetched_at=%v\n", src.Origin, src.FetchedAt)
```

Platform tokens are normalized, so `"macos"`, `"darwin"`, `"chrome"`, and `"chromeos"` are all valid inputs alongside `"windows"`, `"linux"`, and `"all"`.

The embedded fallback (`osquery_fleet_schema.json`) is regenerated via:

```bash
go generate ./tools/fleet-mcp/...
```
