MCP server initialization and configuration entry point for the Fleet MCP integration.

## Key Components

- **`fleetMCPInstructions`** — Server-level system prompt injected into the MCP `initialize` response, enforcing a schema-first SQL workflow to prevent silent zero-row query bugs caused by incorrect column type assumptions.
- **`SetupMCPServer(config *Config, fleetClient *FleetClient) *server.MCPServer`** — Constructs and configures the MCP server instance, registers all tool domains, and kicks off background osquery schema refresh.
- **`defaultEndpointsPerPage`** — Package-level constant (`50`) controlling default pagination for endpoint listings.

## Usage Example

```go
config := &Config{ /* loaded from env/flags */ }
fleetClient := NewFleetClient(config)

mcpServer := SetupMCPServer(config, fleetClient)
// mcpServer is ready to serve MCP protocol requests
```

## Tool Registration

Tools are registered by domain via dedicated files:

| Call | Domain |
|---|---|
| `registerHostTools` | Host inventory & management |
| `registerQueryTools` | Live and saved osquery queries |
| `registerPolicyTools` | Fleet policy management |

## Schema Refresh

`StartSchemaRefresh(0)` is called during setup to begin background polling of the canonical osquery schema from `fleetdm/fleet`. The embedded snapshot is loaded synchronously at `init()`, making the refresh purely a freshness optimization.
