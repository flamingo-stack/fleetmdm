Middleware function that restricts HTTP routing to only the two MCP protocol paths (`/sse` and `/message`), returning a plain-text 404 for all other requests.

## Key Components

- **`mcpRouteGuard(next http.Handler) http.Handler`** — HTTP middleware that wraps a handler and enforces MCP-only path access. Strips trailing slashes before matching, passes `/sse` and `/message` through to `next`, and responds with `404 text/plain` for all other paths.

## Usage Example

```go
mux := http.NewServeMux()
mux.Handle("/sse", sseHandler)
mux.Handle("/message", messageHandler)

http.ListenAndServe(":8080", mcpRouteGuard(mux))
```

## Notes

- Trailing slashes are normalised via `strings.TrimRight` before path matching, so `/sse/` and `/sse` are treated identically.
- The 404 response body (`fleet-mcp: use an MCP client to connect`) is intentionally human-readable to guide anyone who hits the server directly in a browser.
- This guard sits **before** auth middleware and the SSE server to suppress noisy log entries from web crawlers and health-check probes on unexpected paths.
