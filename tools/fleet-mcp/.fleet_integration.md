Provides the Fleet MDM API client implementation, handling authentication, TLS configuration, host/query/policy management, and live query execution against Fleet endpoints.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `FleetClient` | struct | Core HTTP client wrapping Fleet API calls with auth and TLS config |
| `NewFleetClient` | func | Constructor with TLS skip-verify (localhost only) and custom CA support |
| `GetEndpoints` | func | Paginated host listing with label population |
| `Endpoint` | struct | Fleet host representation (hostname, platform, team, labels, etc.) |
| `HostWithPolicies` | struct | Host enriched with per-host policy compliance results |
| `Policy` / `Query` / `Label` / `Team` | structs | Core Fleet resource models |
| `LiveQueryResult` | struct | Unified response for multi-host live query execution |
| `CreateQueryRequest` | struct | Payload for saved query creation, with optional team scoping |
| `normalizePlatform` | func | Canonicalizes platform strings (`"mac"` → `"darwin"`, etc.) |
| `teamFanOutConcurrency` | const | Caps concurrent per-team API calls at 8 to avoid overwhelming Fleet |
| `tempQueryNamePrefix` | const | Prefix (`fleet-mcp-temp-`) for transient saved queries created by live query runs |

## Usage Example

```go
// Create a client with a custom CA cert
client := NewFleetClient(
    "https://fleet.example.com",
    "your-api-key",
    false,
    "/etc/ssl/fleet-ca.pem",
)

// Create a client for local dev with TLS verification skipped
devClient := NewFleetClient(
    "https://localhost:8080",
    "your-api-key",
    true,
    "",
)

// Fetch all endpoints (500 per page)
hosts, err := client.GetEndpoints(context.Background(), 500)
if err != nil {
    log.Fatal(err)
}

for _, h := range hosts {
    fmt.Printf("%s (%s) — team: %s\n", h.DisplayName, h.Platform, h.TeamName)
}
```

> **Security note:** `tlsSkipVerify=true` is hard-gated to loopback URLs (`localhost`, `127.0.0.1`, `::1`) at startup. Passing a remote URL with skip-verify set will cause a fatal exit.
