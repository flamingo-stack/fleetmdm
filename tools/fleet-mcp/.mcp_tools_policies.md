Registers five read-only MCP tools for querying Fleet policy compliance and CVE vulnerability data, attaching them to an MCP server instance via a Fleet API client.

## Key Components

| Function | Tool Name | Description |
|---|---|---|
| `registerPolicyTools` | — | Entry point; registers all five tools onto the MCP server |
| `registerGetPolicies` | `get_policies` | Returns all Fleet policies with pass/fail host counts |
| `registerGetPolicyCompliance` | `get_policy_compliance` | Returns pass/fail counts for a specific policy, optionally scoped to a fleet/team |
| `registerGetPolicyHosts` | `get_policy_hosts` | Lists hosts passing or failing a policy with multi-dimensional filtering |
| `registerGetVulnerabilityImpact` | `get_vulnerability_impact` | Returns aggregate count of hosts impacted by a CVE |
| `registerGetVulnerabilityHosts` | `get_vulnerability_hosts` | Lists specific hosts affected by a CVE with filtering |

All tools are annotated as read-only, idempotent, and non-destructive.

## Usage Example

```go
// Wire up all policy and vulnerability tools during server initialization
func main() {
    s := server.NewMCPServer("fleet-mcp", "1.0.0")
    fleetClient := NewFleetClient(cfg)

    registerPolicyTools(s, fleetClient)
    // Tools now available: get_policies, get_policy_compliance,
    // get_policy_hosts, get_vulnerability_impact, get_vulnerability_hosts
}
```

**Example AI tool call — list failing Linux hosts for policy 42 in the Workstations fleet:**

```json
{
  "tool": "get_policy_hosts",
  "arguments": {
    "policy_id": "42",
    "response": "failing",
    "fleet": "💻 Workstations",
    "platform": "linux",
    "per_page": "100"
  }
}
```

**Example AI tool call — find hosts affected by a CVE:**

```json
{
  "tool": "get_vulnerability_hosts",
  "arguments": {
    "cve_id": "CVE-2022-40898",
    "status": "online"
  }
}
```
