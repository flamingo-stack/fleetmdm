Bootstraps a Fleet instance with a predefined set of standard saved queries (reports) for common cross-platform device visibility scenarios.

## Key Components

### `SeedFleet(config *Config, client *FleetClient)`
The sole exported function. Accepts an already-initialized `Config` and `FleetClient`, then iterates over a hardcoded slice of query definitions and calls `client.CreateSavedQuery` for each. Results are logged via `logrus`; individual failures are non-fatal and do not halt the remaining seeds.

**Built-in standard queries:**

| Name | Platform |
|---|---|
| Standard: MacOS Admin Users | `darwin` |
| Standard: Windows Missing Updates | `windows` |
| Standard: Linux Running Containers | `linux` |
| Standard: Universal OS Version | *(all)* |

All queries are created as **Global** (no team association), making them suitable as demo/baseline data.

## Usage Example

```go
// Called internally when the -seed flag is passed to fleet-mcp
cfg, err := LoadConfig()
if err != nil {
    log.Fatal(err)
}

client, err := NewFleetClient(cfg)
if err != nil {
    log.Fatal(err)
}

SeedFleet(cfg, client)
// Output:
// INFO created "Standard: MacOS Admin Users"
// INFO created "Standard: Windows Missing Updates"
// INFO created "Standard: Linux Running Containers"
// INFO created "Standard: Universal OS Version"
// INFO seeding complete: 4/4 queries created
```

> **Note:** This is a one-time bootstrap operation. Running it multiple times against the same Fleet instance will attempt to create duplicate queries. Invoke via the `-seed` flag on the `fleet-mcp` binary.
