Registers read-only MCP tools for querying Fleet host/endpoint inventory data, exposing six tools for listing, filtering, and inspecting enrolled devices.

## Key Components

| Function | MCP Tool | Description |
|---|---|---|
| `registerHostTools` | — | Entry point; registers all host-domain tools on the MCP server |
| `registerGetEndpoints` | `get_endpoints` | Lists hosts with composable server-side filters (fleet, platform, status, query, label, policy) |
| `registerGetHost` | `get_host` | Fetches full details for one host by `host_id` or fuzzy `identifier`, with collision detection |
| `registerGetTotalSystemCount` | `get_total_system_count` | Returns total enrolled device count |
| `registerGetAggregatePlatforms` | `get_aggregate_platforms` | Returns per-platform (macOS/Windows/Linux) device counts |
| `registerGetFleets` | `get_fleets` | Lists all Fleet teams/fleets with IDs and names |
| `registerGetLabels` | `get_labels` | Lists all Fleet labels |

All tools are annotated as read-only, idempotent, and non-destructive so MCP clients skip destructive-action review gates.

## Usage Example

```go
// Wire up all host tools during server initialization
func main() {
    s := server.NewMCPServer("fleet-mcp", "1.0.0")
    fleetClient := NewFleetClient(cfg)

    registerHostTools(s, fleetClient)
    // ...register other tool groups
}
```

```go
// get_endpoints — filter by fleet + policy failure
{
  "fleet":            "💻 Workstations",
  "policy_id":        "42",
  "policy_response":  "failing",
  "per_page":         "25"
}

// get_host — fuzzy match; returns candidate list on collision
{
  "identifier": "Dhruv"
}

// get_host — unambiguous lookup
{
  "host_id": "1309"
}
```
