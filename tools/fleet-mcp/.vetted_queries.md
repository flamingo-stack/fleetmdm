Stores the complete vetted osquery policy query library for CIS Benchmark compliance checks, providing pre-verified, production-safe SQL queries for macOS, Linux, and Windows platforms sourced verbatim from upstream CIS policy repositories.

## Key Components

- **`VettedQuery` struct** — Schema for each policy query, containing name, description, platform, category, CIS level, CIS safeguard reference, and the osquery SQL
- **`vettedQueryLibrary`** — Package-level slice of all vetted queries grouped by OS platform (darwin, linux, windows)

### Query Sources (verbatim)

| Platform | Source |
|---|---|
| macOS (darwin) | `karmine05/fleet_policies` — CIS-8.1/macOS26 |
| Linux | `karmine05/fleet_policies` — CIS-8.1/ubuntu24 |
| Windows L1/L2/BL | `karmine05/fleet_policies` — CIS-8.1/win11/intune |

### CIS Categories Covered

| Platform | Example Controls |
|---|---|
| macOS | SIP, SSV, FileVault, Safari settings, sudo timeout, root account, NFS/HTTP server |
| Linux | SSH `MaxAuthTries`, `LoginGraceTime`, and additional hardening checks |
| Windows | Intune-based L1, L2, and Bitlocker (BL) policy enforcement |

## Usage Example

```go
// Iterate all vetted queries for a given platform
for _, q := range vettedQueryLibrary {
    if q.Platform == "darwin" && q.Level == "L1" {
        fmt.Printf("[%s] %s\n", q.CISRef, q.Name)
        // Submit q.SQL to Fleet for policy creation
    }
}

// Filter by CIS reference
for _, q := range vettedQueryLibrary {
    if q.CISRef == "CIS5.1.2" {
        fmt.Println(q.SQL)
    }
}
```

> **Important:** Do not add queries to `vettedQueryLibrary` unless sourced verbatim from the upstream policy YAML files listed in the source header. All queries are production-safe and CIS-8.1 verified.
