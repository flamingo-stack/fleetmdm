Per-IP token-bucket rate limiter for the SSE transport, throttling requests by client IP address and rejecting excess traffic with HTTP 429.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `ipRateLimiter` | struct | Core throttle; holds a `sync.Mutex`-protected map of IP → `*visitor`, plus the configured `rps` and `burst` |
| `visitor` | struct | Per-IP state: a `*rate.Limiter` and a `lastSeen` timestamp used for TTL eviction |
| `newIPRateLimiter` | func | Constructor — creates the limiter and starts the background `sweepLoop` goroutine |
| `getLimiter` | method | Returns (or creates) the `*rate.Limiter` for a given IP string, updating `lastSeen` |
| `sweepLoop` | method | Background goroutine that evicts stale visitor entries every `visitorSweepInterval` (1 min) to prevent unbounded map growth |
| `Middleware` | method | `http.Handler` wrapper that calls `Allow()` and returns `429 Too Many Requests` with `Retry-After: 1` when the bucket is empty |
| `clientIP` | func | Extracts the real client IP; honors `X-Forwarded-For` only when `r.RemoteAddr` resolves to a trusted proxy (loopback/private/link-local) |
| `isTrustedProxy` | func | Reports whether a `net.IP` is loopback, private, or link-local — the proxy trust boundary |

**Default limits** (constants):

| Constant | Value | Purpose |
|----------|-------|---------|
| `defaultPerIPRatePerSec` | 20 | Token refill rate per IP per second |
| `defaultPerIPBurst` | 60 | Initial bucket depth (allows short bursts) |
| `visitorTTL` | 10 min | Idle time before a visitor entry is evicted |
| `visitorSweepInterval` | 1 min | How often the sweep runs |

## Usage Example

```go
// Construct the limiter (starts background sweeper automatically).
rl := newIPRateLimiter(defaultPerIPRatePerSec, defaultPerIPBurst)

// Wrap any http.Handler — e.g. an SSE endpoint.
mux := http.NewServeMux()
mux.Handle("/sse", rl.Middleware(sseHandler))

http.ListenAndServe(":8080", mux)
```

Clients that exceed 20 req/s (after a burst of 60) receive:

```text
HTTP/1.1 429 Too Many Requests
Retry-After: 1

rate limit exceeded
```

> **Proxy trust model:** `X-Forwarded-For` is only read when the TCP peer is a private/loopback address. Direct connections from public IPs always use `r.RemoteAddr`, preventing rate-limit bypass via a spoofed XFF header.
