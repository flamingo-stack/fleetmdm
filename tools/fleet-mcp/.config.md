Loads and resolves server configuration from environment variables (with `.env` file fallback), supporting secure secret injection via file-path references.

## Key Components

| Symbol | Description |
|---|---|
| `Config` | Struct holding all runtime configuration fields (port, Fleet URL/key, TLS options, MCP auth token) |
| `LoadConfig()` | Reads environment variables (or `.env` file) and returns a populated `*Config` |
| `resolveSecret(key)` | Resolves a secret from `KEY_FILE` (preferred) or direct `KEY` env var, with whitespace trimming and fallback logging |
| `getEnv(key, default)` | Returns an env var value or a default string if unset |

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `PORT` | `8080` | Server listen port |
| `FLEET_BASE_URL` | `https://localhost:8080` | Fleet instance base URL |
| `FLEET_API_KEY` / `FLEET_API_KEY_FILE` | — | Fleet API credentials |
| `FLEET_TLS_SKIP_VERIFY` | `false` | Skip TLS verification (dev only) |
| `FLEET_CA_FILE` | — | Path to PEM CA cert for self-signed Fleet |
| `MCP_AUTH_TOKEN` / `MCP_AUTH_TOKEN_FILE` | — | Bearer token for incoming MCP requests |
| `LOG_LEVEL` | `info` | Logrus log level |

## Usage Example

```go
// Load config at startup
cfg := LoadConfig()

// Access values directly
server := &http.Server{
    Addr:    ":" + cfg.Port,
}

// Recommended: inject secrets via file to avoid exposure in process listings
// MCP_AUTH_TOKEN_FILE=/run/secrets/mcp_token
// FLEET_API_KEY_FILE=/run/secrets/fleet_api_key
```

> **Security note:** The `*_FILE` form keeps secrets out of shell history, process listings, and `claude_desktop_config.json`. When both `KEY` and `KEY_FILE` are set for the same secret, `KEY_FILE` wins and a warning is logged.
