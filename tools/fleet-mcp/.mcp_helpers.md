Utility helpers for parsing and validating MCP tool request arguments, providing consistent input handling across Fleet MCP tool handlers.

## Key Components

| Function/Var | Description |
|---|---|
| `getOptionalString` | Extracts an optional string argument from an MCP request's arguments map |
| `parseCSVArg` | Splits a comma-separated string argument into a trimmed, non-empty string slice |
| `jsonResult` | Marshals a value to indented JSON and wraps it in an MCP text result |
| `parsePerPageArg` | Reads and clamps the `per_page` argument; enforces the 200-item cap (`defaultPerPageMax`) |
| `validateCVEID` | Validates a CVE identifier against the canonical `CVE-YYYY-NNNN` pattern |
| `parsePositiveUintString` | Parses and validates a numeric string as a positive `uint64` |
| `parseCSVUintArg` | Parses a comma-separated list of positive unsigned integers from an MCP argument |
| `buildLiveQuerySpecFromRequest` | Assembles a `LiveQueryTargetSpec` from all targeting arguments in an MCP request |

## Usage Example

```go
// Extract a simple string argument
fleet := getOptionalString(req, "fleet")

// Parse a comma-separated list of host names
hostnames := parseCSVArg(req, "hostnames")
// "web-01, web-02, , web-03" → ["web-01", "web-02", "web-03"]

// Parse and clamp pagination (default 50, hard cap 200)
perPage := parsePerPageArg(req, 50)

// Validate a CVE ID before sending to Fleet API
if err := validateCVEID("CVE-2026-31431"); err != nil {
    return mcp.NewToolResultError(err.Error()), nil
}

// Parse a CSV list of uint IDs
hostIDs, err := parseCSVUintArg(req, "host_ids")
// "1,2,3" → []uint{1, 2, 3}

// Build a full live query target spec from a request
spec, err := buildLiveQuerySpecFromRequest(req)
if err != nil {
    return mcp.NewToolResultError(err.Error()), nil
}

// Serialize a result to JSON for the MCP client
return jsonResult(map[string]any{"hosts": hosts, "total": len(hosts)})
```
