Registers and handles MCP (Model Context Protocol) tools for Fleet query operations, including listing saved queries, creating new ones, accessing vetted CIS-8.1 policy queries, and managing live query workflows with schema validation.

## Key Components

| Function | Description |
|---|---|
| `registerQueryTools` | Entry point that registers all query-related MCP tools onto the server |
| `registerGetQueries` | Read-only tool to list all saved queries in Fleet |
| `registerCreateSavedQuery` | Creates a new saved query with platform SQL validation and optional team scoping |
| `registerGetVettedQueries` | Returns a curated library of CIS-8.1 policy queries filtered by platform |
| `registerPrepareLiveQuery` | Step 1 of live query workflow — resolves target hosts and returns schema context |

**Supporting utilities used:** `buildLiveQuerySpecFromRequest`, `ValidateSQLForPlatforms`, `GetVettedQueries`, `GetOsquerySchema`, `inferPlatformFromTargets`, `fleetClient.resolveTeamNames`

## Usage Example

```go
// Wire up all query tools during server initialization
fleetClient := NewFleetClient(cfg)
mcpServer := server.NewMCPServer()

registerQueryTools(mcpServer, fleetClient)
```

Typical AI-driven call sequence for a live query:

1. Call `get_osquery_schema` with a target platform to verify column types
2. Call `prepare_live_query` with fleet/platform/status filters to confirm host scope
3. Call `run_live_query` with the same filter arguments to execute

For saved query creation, the tool enforces a pre-flight `ValidateSQLForPlatforms` check and resolves team names to IDs before persisting — preventing silent zero-row queries caused by incorrect column type assumptions.
