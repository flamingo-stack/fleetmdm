Generates a MySQL schema dump for Fleet's test database by running migrations and exporting the result via `mysqldump`.

## Key Components

- **`getTestAddress()`** — Resolves the MySQL test host/port, defaulting to `localhost:3307` or reading from the `FLEET_MYSQL_TEST_PORT` environment variable.
- **`panicif(err)`** — Minimal error handler that panics on non-nil errors.
- **`main()`** — Orchestrates the full schema generation pipeline:
  1. Creates a fresh `schemadb` database via raw SQL.
  2. Runs Fleet's standard table migrations using the `mysql.New` datastore client.
  3. Normalizes timestamps in `app_config_json` and `migration_status_tables` to a fixed date (`2020-01-01`) to prevent noisy diffs.
  4. Dumps the schema using `mysqldump` via `docker compose exec`, then writes the output to the provided file path.

## Usage Example

```bash
# Run from the repo root; requires the mysql_test Docker container to be running
go run schema_generator.go ./path/to/schema.sql
```

```go
// Environment override for non-default MySQL port
export FLEET_MYSQL_TEST_PORT=3308
go run schema_generator.go ./schema_dump.sql
```

## Notes

- Requires `docker` and `docker compose` available in `$PATH`, with the `mysql_test` service running.
- The `--set-gtid-purged=OFF` flag ensures the dump is portable across MySQL server instances (previously the default before MySQL 9.5).
- Credentials are hardcoded test-only values (`root`/`toor`) and are not suitable for production use.
- Source: [`schema_generator.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/schema_generator.go)
