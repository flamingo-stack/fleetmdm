A CLI tool for creating and restoring named database snapshots, storing compressed SQL dumps in `~/.fleet/snapshots/` with an interactive terminal UI for selection.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Snapshot` | Represents a named snapshot with `Name`, `Date`, and `Path` fields |
| `Command` | Integer enum (`CMD_SNAPSHOT`, `CMD_RESTORE`) identifying the requested operation |

### Functions

| Function | Description |
|----------|-------------|
| `main()` | Entry point; parses CLI args (`s`/`snap`/`snapshot` or `r`/`restore`), resolves repo root, and dispatches to `snapshot()` or `restore()` |
| `snapshot(homedir)` | Prompts for a name, optionally overwrites an existing snapshot, and runs `./tools/backup_db/backup.sh` to write `db.sql.gz` |
| `restore(homedir)` | Reads `~/.fleet/snapshots/`, presents an interactive list sorted by date, and runs `./tools/backup_db/restore.sh` with the chosen path |
| `getRepoRoot()` | Resolves the repo root relative to the running binary's location, following symlinks |

## Usage Example

```bash
# Create a snapshot (interactive name prompt)
./snapshot s

# Restore a snapshot (interactive selection list)
./snapshot r
```

```go
// Snapshots are stored as:
// ~/.fleet/snapshots/<name>/db.sql.gz
//
// After each operation, the chosen name is persisted to:
// ~/.fleet/snapshots/last_snapshot

snapshot := Snapshot{
    Name: "pre-migration",
    Date: time.Now(),
    Path: "/home/user/.fleet/snapshots/pre-migration/db.sql.gz",
}
fmt.Println(snapshot.DateStr()) // "Jan 02, 2006 03:04:05 PM"
```

> **Note:** This tool must be run from within the repository; it changes the working directory to the repo root (where the `Makefile` resides) before executing shell scripts under `./tools/backup_db/`.
