Entry point for `fdm`, a developer CLI tool that wraps `make` commands for Fleet Device Management, providing a friendlier interface for invoking Makefile targets with structured option parsing.

## Key Components

| Function | Description |
|---|---|
| `main()` | Resolves repo root, parses CLI arguments, and dispatches to the appropriate Makefile target |
| `splitArgs()` | Parses raw CLI args into named options (`--key=value`, `--key value`, `--flag`) and passthrough make args (after `--`) |
| `transformToMakeVars()` | Converts kebab-case option keys to uppercase snake_case Makefile variables (e.g., `--dry-run` → `DRY_RUN=true`) |
| `callMake()` | Executes `make <target> [VARS...] [args...]` inheriting the parent process's stdin/stdout/stderr |
| `getRepoRoot()` | Resolves the repo root by walking up one directory from the binary's real path (symlinks resolved) |

## Usage Example

```bash
# Show help
fdm help

# Run a target with options
fdm deploy --env=production --dry-run

# Pass options to make directly (after --)
fdm build -- -j4 VERBOSE=1

# Positional arguments become arg1, arg2, ...
fdm lint mypackage
```

```go
// Internally, `fdm deploy --env=production` becomes:
exec.Command("make", "deploy", "ENV=production", "TOOL_CMD=fdm")
```

## Notes

- The binary must live one directory below the repo root (i.e., `<repo>/bin/fdm`) so `getRepoRoot()` resolves correctly.
- Defaults to the `help` target when no command is provided.
- All option keys are normalized: kebab-case → `UPPER_SNAKE_CASE` Makefile variables.
