Cluster-aware Redis stress tool entry point that parses subcommands and dispatches to the appropriate load-testing mode.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `usage` | `const string` | Help text printed to stderr/stdout when no valid command is provided |
| `main` | `func` | Entry point; routes CLI arguments to `runWrite` or `runRace` |

## Usage Example

```bash
# Steady SET-only load
redis-stress write -addr=redis:6379 -rate=1000

# Tight SET→GET race detection
redis-stress race -addr=redis:6379 -workers=10

# Legacy flag-first invocation (backward-compatible, defaults to write mode)
redis-stress -addr=redis:6379 -wait=10m

# Per-command help
redis-stress write -h
redis-stress race -h
```

## Routing Logic

```text
os.Args[1] starts with '-'  →  runWrite  (backward-compat shim)
"write"                     →  runWrite(os.Args[2:])
"race"                      →  runRace(os.Args[2:])
"help"                      →  print usage
anything else               →  error + exit 2
```

## Notes

- **Backward compatibility** — legacy invocations that pass flags directly (no subcommand) are silently forwarded to `write` mode, keeping existing scripts functional.
- `runWrite` and `runRace` are defined in sibling files within the same `main` package.
