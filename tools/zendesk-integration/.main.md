Tests Zendesk ticket creation via the Fleet worker processor by simulating a configured integration triggered by a new CVE, related CPEs, or a failing policy.

## Key Components

- **`main()`** — Entry point that parses CLI flags, validates inputs, constructs a mock datastore, and invokes the Zendesk worker.
- **`mock.Store`** — In-memory mock implementing `HostsByCVEFunc`, `AppConfigFunc`, and `TeamLiteFunc` to simulate Fleet datastore responses without a live server.
- **`worker.Zendesk`** — Fleet worker that handles ticket creation logic, wired with a real `externalsvc.NewZendeskClient`.
- **`argsJSON`** — Dynamically built JSON payload passed to `zendesk.Run()`, encoding either a vulnerability or failing-policy event.

## CLI Flags

| Flag | Description |
|---|---|
| `-zendesk-url` | Zendesk instance URL (required) |
| `-zendesk-email` | Zendesk account email (required) |
| `-zendesk-group-id` | Zendesk group ID (required) |
| `-fleet-url` | Fleet server URL (default: `https://localhost:8080`) |
| `-cve` | CVE identifier to create a ticket for |
| `-epss-probability` | EPSS probability score |
| `-cvss-score` | CVSS score |
| `-cisa-known-exploit` | Flag if CISA reported a known exploit |
| `-hosts-count` | Number of simulated affected hosts |
| `-failing-policy-id` | Failing policy ID (mutually exclusive with `-cve`) |
| `-failing-policy-team-id` | Team ID for the failing policy |
| `-premium` | Simulate a premium Fleet license |

**Environment variable:** `ZENDESK_TOKEN` must be set with a valid Zendesk API token.

## Usage Example

```bash
# Create a ticket for a CVE
export ZENDESK_TOKEN=your_api_token

go run main.go \
  -zendesk-url https://yourorg.zendesk.com \
  -zendesk-email admin@yourorg.com \
  -zendesk-group-id 12345 \
  -cve CVE-2021-44228 \
  -epss-probability 0.97 \
  -cvss-score 10.0 \
  -cisa-known-exploit \
  -hosts-count 3 \
  -premium

# Create a ticket for a failing policy
go run main.go \
  -zendesk-url https://yourorg.zendesk.com \
  -zendesk-email admin@yourorg.com \
  -zendesk-group-id 12345 \
  -failing-policy-id 7 \
  -failing-policy-team-id 2 \
  -hosts-count 5
```
