A CLI tool for seeding vulnerability test data into a Fleet MySQL database by creating hosts (macOS, Windows, Ubuntu) and populating them with software inventory from CSV files.

## Key Components

| Component | Description |
|---|---|
| `readCSVFile(filePath)` | Parses a CSV file into a slice of `fleet.Software` structs, skipping the header row |
| `createOrGetHost(ctx, ds, identifier, base)` | Idempotently creates or retrieves a host by identifier (UUID/hostname) |
| `main()` | Entry point; parses flags, connects to MySQL, and orchestrates host/software seeding |

**CLI Flags**

| Flag | Description |
|---|---|
| `-ubuntu N` | Number of Ubuntu hosts to create |
| `-macos N` | Number of macOS hosts to create |
| `-windows N` | Number of Windows hosts to create |
| `-linux-kernels N` | Linux kernel packages to add per Ubuntu host |

**CSV Data Sources** (relative to repo root)

```text
tools/software/vulnerabilities/software-macos.csv
tools/software/vulnerabilities/software-win.csv
tools/software/vulnerabilities/software-ubuntu.csv
```

## Usage Example

```bash
# Seed 2 macOS hosts, 1 Windows host, and 3 Ubuntu hosts with 2 kernel packages each
go run seed_vuln_data.go \
  -macos 2 \
  -windows 1 \
  -ubuntu 3 \
  -linux-kernels 2
```

The tool connects to `fleet:insecure@localhost:3306/fleet` by default. To target a different instance, edit the top-level `mysql*` variables or extend the flags before running.

> **Note:** This is a development/testing utility — not intended for production use. Source: [`seed_vuln_data.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/seed_vuln_data.go)
