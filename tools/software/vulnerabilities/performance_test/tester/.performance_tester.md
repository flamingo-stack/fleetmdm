A CLI tool for benchmarking Fleet MySQL datastore methods, measuring execution time across configurable iterations and reporting min/max/average/percentile statistics.

## Key Components

### Types

- **`TestFunction`** — Function signature `func(context.Context, *mysql.Datastore) error` representing a testable datastore method
- **`PerformanceResult`** — Holds aggregate stats for a test run: total/average/min/max time, success/failure counts, and per-iteration durations

### Functions

- **`runPerformanceTest`** — Executes a named test function N times, collecting per-iteration durations and computing aggregate stats
- **`printResults`** — Formats and prints a results table; with `-details`, also outputs P50/P90/P99 percentiles
- **`getTestFunctionNames`** — Returns a sorted list of registered test function names
- **`main`** — Entry point; parses CLI flags, connects to MySQL, runs selected test functions, and prints results

### Registered Test Functions

| Name | Datastore Method |
|---|---|
| `UpdateVulnerabilityHostCounts` | `ds.UpdateVulnerabilityHostCounts(ctx, 1)` |

## Usage Example

```bash
# Run default test with 10 iterations
go run performance_tester.go -iterations=10

# Run with detailed percentile output
go run performance_tester.go -funcs=UpdateVulnerabilityHostCounts -iterations=20 -details

# Verbose per-iteration timing
go run performance_tester.go -funcs=UpdateVulnerabilityHostCounts -verbose

# List all available test functions
go run performance_tester.go -list
```

**CLI Flags**

| Flag | Default | Description |
|---|---|---|
| `-funcs` | `UpdateVulnerabilityHostCounts` | Comma-separated list of functions to benchmark |
| `-iterations` | `5` | Iterations per function |
| `-verbose` | `false` | Print timing per iteration |
| `-details` | `false` | Include P50/P90/P99 percentiles |
| `-list` | `false` | List available functions and exit |

> **Note:** Requires a running MySQL instance at `localhost:3306` with credentials `fleet/insecure` and database `fleet`. Pre-seed test data before running.
