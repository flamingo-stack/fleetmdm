Generates high-volume test data for Fleet MDM's vulnerability pipeline by seeding MySQL with realistic hosts, software, and CVE records at scale.

## Key Components

| Function | Description |
|---|---|
| `retryOnDeadlock` | Retries a DB operation up to `maxRetries` times with exponential backoff + jitter on MySQL deadlock (error 1213) |
| `timeStep` | Wraps an operation with timing output; supports a `verbose` flag for start/completion messages |
| `batchCreateHosts` | Bulk-inserts hosts in batches of 100 using raw SQL, then fetches their IDs and populates `host_display_names` |
| `batchUpdateHostOS` | Iterates hosts in batches of 100, calling `UpdateHostOperatingSystem` with deadlock retry |
| `batchInstallSoftware` | Inserts software records via `ON DUPLICATE KEY UPDATE`, then randomly assigns 20–80% of the software catalog to each host via `host_software` |
| `createTestTeam` | Creates a named Fleet team via the datastore |
| `generateVulnerableSoftware` | Produces a slice of `fleet.Software` structs with CVE-style naming patterns for use in seeding |

**Package-level vars:** MySQL connection defaults (`mysqlAddr`, `mysqlUser`, `mysqlPass`, `mysqlDB`) and `cvePatterns` — a set of CVE year-format strings used to generate realistic vulnerability names.

## Usage Example

```go
// Typical seeder invocation pattern (inferred from flags and helpers)
hosts, err := batchCreateHosts(ctx, ds, 10000, teams, verbose)
if err != nil {
    log.Fatal(err)
}

software := generateVulnerableSoftware(500)

err = timeStep("install software", verbose, func() error {
    return batchInstallSoftware(ctx, ds, hosts, software, verbose)
})
if err != nil {
    log.Fatal(err)
}
```

> **Note:** This tool writes directly to the Fleet MySQL schema and is intended for local or staging environments only. The MySQL defaults (`fleet`/`insecure`) match Fleet's standard dev setup.
