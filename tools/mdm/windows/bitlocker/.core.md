CLI entry point for managing BitLocker encryption on the Windows `C:` drive. Provides encrypt, decrypt, and status operations via command-line flags, delegating to a WMI-backed volume abstraction layer.

## Key Components

| Function | Description |
|---|---|
| `BitlockerEncryptionNumericalPassword(password)` | Connects to `C:`, prepares the volume, adds a numerical recovery password protector, enables TPM protection, then starts XTS-AES-256 encryption (data-only mode) |
| `BitlockerDecryption()` | Connects to `C:` and initiates full decryption |
| `GetBitlockerStatus()` | Returns an `*EncryptionStatus` struct containing protection state, conversion state, encryption flags, wiping progress, and completion percentages |
| `main()` | Parses `--encrypt`, `--decrypt`, and `--status` flags and dispatches to the appropriate function |

## Usage Example

```bash
# Check current BitLocker status (default behaviour)
.\bitlocker.exe -status

# Encrypt the drive with a numerical recovery password
.\bitlocker.exe -encrypt

# Decrypt the drive
.\bitlocker.exe -decrypt
```

```go
// Programmatic usage
status, err := GetBitlockerStatus()
if err != nil {
    log.Fatal(err)
}
fmt.Println(status.ProtectionStatusDesc)   // e.g. "Protection On"
fmt.Println(status.EncryptionPercentage)   // e.g. 42
```

> **Note:** The numerical password must conform to the format defined by the [`GetKeyProtectorNumericalPassword`](https://learn.microsoft.com/en-us/windows/win32/secprov/getkeyprotectornumericalpassword-win32-encryptablevolume) Win32 API — seven groups of six digits separated by hyphens (e.g. `527230-472395-606199-107525-536789-168927-479336-471856`). This binary targets Windows only and requires administrator privileges and a TPM-equipped device.
