Provides BitLocker volume encryption management for Windows, wrapping the `Win32_EncryptableVolume` WMI interface via COM/OLE to enable encryption, decryption, key protection, and Active Directory recovery key backup.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Volume` | struct | Represents an open encryptable volume with WMI COM handles |
| `Connect` | func | Opens a WMI connection to a drive letter's encryptable volume |
| `BackupToAD` | func | Backs up BitLocker recovery keys to Active Directory |
| `Encrypt` | method | Encrypts a volume using the specified method and flags |
| `Decrypt` | method | Decrypts a volume |
| `Prepare` | method | Prepares a volume for BitLocker before adding key protectors |
| `ProtectWithNumericalPassword` | method | Adds a recovery password protector (auto-generated if blank) |
| `ProtectWithPassphrase` | method | Adds a passphrase key protector |
| `ProtectWithTPM` | method | Adds a TPM key protector |
| `EncryptionMethod` | type | Enum of supported algorithms (`XtsAES256`, `AES128`, etc.) |
| `EncryptionFlag` | type | Bitfield flags controlling encryption behavior |
| `EncryptionStatus` | struct | Holds human-readable encryption/conversion/wiping status |

## Usage Example

```go
// Connect to the C: drive
vol, err := Connect("c:")
if err != nil {
    log.Fatal(err)
}
defer vol.Close()

// Prepare the volume (must be done before adding protectors)
if err := vol.Prepare(VolumeTypeDefault, EncryptionTypeSoftware); err != nil {
    log.Fatal(err)
}

// Add a TPM protector
if err := vol.ProtectWithTPM(nil); err != nil {
    log.Fatal(err)
}

// Add an auto-generated recovery password
if err := vol.ProtectWithNumericalPassword(""); err != nil {
    log.Fatal(err)
}

// Encrypt with XTS-AES-256, data-only mode
if err := vol.Encrypt(XtsAES256, EncryptDataOnly); err != nil {
    log.Fatal(err)
}

// Back up recovery keys to Active Directory
if err := BackupToAD(); err != nil {
    log.Fatal(err)
}
```

> **Note:** This file targets Windows only and requires COM/WMI access. Derived from the [Google Glazier project](https://github.com/google/glazier). Source: [`bitlocker.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/bitlocker.go).
