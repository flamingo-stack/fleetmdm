A Windows-only CLI utility that enrolls a Windows host into an MDM (Mobile Device Management) server using the native `mdmregistration.dll` Windows API via the MS-MDE protocol.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `checkForAdmin` | `func() bool` | Verifies the process is running with Administrator privileges by attempting to open a physical drive |
| `localUTF16toString` | `func(unsafe.Pointer) (string, error)` | Converts a Windows UTF-16 pointer to a Go string using a fixed-size buffer |
| `getEnrollmentInfo` | `func() (uint32, string, error)` | Calls `IsDeviceRegisteredWithManagement` to check current MDM enrollment status and return the enrolled UPN |
| `enrollHostToMDM` | `func(string, string) (bool, error)` | Calls `RegisterDeviceWithManagement` to enroll the host with the given MDM discovery endpoint and UPN |
| `main` | `func()` | CLI entry point; parses flags, validates admin rights, checks existing enrollment, then performs enrollment |

**Windows API bindings:**

| Proc | DLL | Purpose |
|------|-----|---------|
| `IsDeviceRegisteredWithManagement` | `mdmregistration.dll` | Query current MDM enrollment state |
| `RegisterDeviceWithManagement` | `mdmregistration.dll` | Enroll device with MDM server |

## Usage Example

```bash
# Enroll a Windows host into an MDM server
mdmenroll.exe \
  -discovery-url https://mdmwindows.com/EnrollmentServer/Discovery.svc \
  -upn-email demo@mdmwindows.com
```

**Exit conditions:**

- Exits `1` if arguments are missing, admin rights are absent, enrollment info cannot be retrieved, or the host is already enrolled
- Prints success message and exits `0` on successful enrollment

> **Note:** Must be compiled for Windows only (`//go:build windows`) and run as Administrator. The OS MDM stack auto-generates the required CSR; no certificate input is needed.
