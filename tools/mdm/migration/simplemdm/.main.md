A webhook server that listens for Fleet MDM events and triggers device unenrollment via the SimpleMDM API.

## Key Components

| Component | Description |
|---|---|
| `simpleClient` | HTTP client wrapper for the SimpleMDM API, authenticated via Basic Auth |
| `unenroll(deviceID uint)` | Sends a `POST` request to the SimpleMDM unenroll endpoint for a given device ID |
| `main()` | Starts the HTTP webhook server, registers a catch-all handler, and blocks on OS signals for graceful shutdown |
| `DELAY` | Configurable 10-second sleep to simulate slow webhook response processing |

## CLI Flags

| Flag | Required | Description |
|---|---|---|
| `--api-token` | ✅ | SimpleMDM API token for Basic Auth |
| `--device-id` | ✅ | Numeric device ID to unenroll on webhook trigger |

## Usage Example

```bash
# Start the webhook server
go run main.go --api-token="your-simplemdm-token" --device-id="12345"

# Override default port (4648)
SERVER_PORT=":8080" go run main.go --api-token="your-token" --device-id="12345"
```

Once running, any HTTP request to the server triggers a 10-second delay followed by a SimpleMDM unenroll call for the configured device ID.

## Notes

- The server listens on `:4648` by default; override with the `SERVER_PORT` environment variable
- Graceful shutdown is handled via `SIGINT`/`SIGTERM`
- The handler currently uses a hardcoded `--device-id` flag; TODOs in the code indicate planned support for parsing the Fleet webhook payload to extract `hardware_serial` and resolve the device ID dynamically via the SimpleMDM list devices API
