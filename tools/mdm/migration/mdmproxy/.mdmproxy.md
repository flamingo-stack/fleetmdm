A reverse proxy that routes MDM device requests between an existing MDM server (e.g., MicroMDM) and a Fleet MDM server, enabling gradual device migration by UDID allowlist or percentage-based hash routing.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `mdmProxy` | struct | Core proxy state: target URLs, reverse proxy instances, migration config, and a `sync.RWMutex` for concurrent access |
| `handleProxy` | method | Main request router — dispatches SCEP, API, repo, and `/mdm` traffic to the appropriate backend |
| `handleUpdatePercentage` | method | Bearer-token-protected endpoint (`/admin/percentage`) to update the migration percentage at runtime |
| `handleUpdateMigrateUDIDs` | method | Bearer-token-protected endpoint (`/admin/udids`) to replace the explicit UDID allowlist at runtime |
| `isUDIDMigrated` | method | Returns `true` if a UDID is in the explicit set or falls within the percentage bucket |
| `udidIncludedByPercentage` | func | FNV-32a hashes a UDID, takes `% 100`, and compares against the configured percentage |
| `udidFromRequestBody` | func | Parses a plist-encoded MDM request body to extract the device UDID |
| `makeExistingProxy` | func | Builds a `httputil.ReverseProxy` for the legacy server with custom TLS `ServerName` |
| `makeFleetProxy` | func | Builds a `httputil.ReverseProxy` for Fleet, optionally logging response bodies in debug mode |
| `processUDIDs` | func | Reads a whitespace-delimited stream of UDIDs into a `map[string]struct{}` |

## Usage Example

```bash
# Start the proxy, migrating 10% of devices plus two specific UDIDs
./mdmproxy \
  --existing-url https://mdm.example.com \
  --existing-hostname mdm.example.com \
  --fleet-url https://fleet.example.com \
  --migrate-percentage 10 \
  --migrate-udids "AABBCCDD-1234-... EEFFGGHH-5678-..." \
  --auth-token supersecret \
  --server-address :8080

# Check migration status for a specific UDID (dry-run, exits immediately)
./mdmproxy --existing-url ... --fleet-url ... \
  --check "AABBCCDD-1234-5678-ABCD-1234567890AB"

# Update the migration percentage at runtime
curl -X POST http://localhost:8080/admin/percentage \
  -H "Authorization: Bearer supersecret" \
  -d "25"

# Replace the explicit UDID list at runtime
curl -X POST http://localhost:8080/admin/udids \
  -H "Authorization: Bearer supersecret" \
  -d $'UDID-1\nUDID-2\nUDID-3'
```

**Routing logic summary:**
- SCEP / `/v1*` / `/push*` / `/repo*` → always existing server
- `/mdm*` → Fleet if UDID is migrated, otherwise existing server
- All other paths → `403 Forbidden`
- `/healthz` → health check for load balancers
