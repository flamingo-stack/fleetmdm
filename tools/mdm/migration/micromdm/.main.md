A webhook server that listens for device unenrollment requests and forwards them to a MicroMDM instance by sending a `RemoveProfile` MDM command.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `main` | `func` | Starts the HTTP server and registers the root handler that processes unenrollment webhooks |
| `microMDMClient` | `struct` | HTTP client wrapper for the MicroMDM API, holding the base URL and API token |
| `newMicroMDMClient` | `func` | Constructor for `microMDMClient` |
| `doWithRequest` | `method` | Executes an HTTP request and returns the response body, erroring on non-2xx status codes |
| `do` | `method` | Marshals an optional payload and issues an authenticated HTTP request using Basic Auth |
| `unmanageDevice` | `method` | Sends a `RemoveProfile` command to MicroMDM to unenroll a device by UUID |

## Usage Example

```bash
# Start the webhook server
go run main.go \
  --api-token "your-micromdm-token" \
  --url "https://mdm.example.com" \
  --port 4648
```

When a device is to be unenrolled, POST a JSON payload to the server:

```bash
curl -X POST http://localhost:4648/ \
  -H "Content-Type: application/json" \
  -d '{"host": {"uuid": "device-uuid-here"}}'
```

The server extracts the `host.uuid` field from the payload and calls `unmanageDevice`, which issues a `RemoveProfile` command against the MicroMDM `/v1/commands` endpoint using Basic Auth (`micromdm:<api-token>`).

## CLI Flags

| Flag | Required | Default | Description |
|---|---|---|---|
| `--api-token` | ✅ | — | MicroMDM API token |
| `--url` | ✅ | — | MicroMDM base URL |
| `--port` | ❌ | `4648` | Local server listen port |
