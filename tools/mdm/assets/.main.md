CLI tool for managing Fleet MDM configuration assets stored in MySQL — supports importing, exporting, and rolling over Apple MDM CA certificates via three subcommands.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main()` | function | Entry point; dispatches to `import`, `export`, or `rollover-ca-cert` subcommands |
| `setupSharedFlags()` | function | Registers shared CLI flags (`-key`, `-dir`, `-db-*`) across all subcommands |
| `setupDS()` | function | Initializes and returns a `*mysql.Datastore` connected to the Fleet MySQL instance |
| `validNames` | `map[fleet.MDMAssetName]struct{}` | Allowlist of valid MDM asset names for import/export operations |
| `exportCmd` | `*flag.FlagSet` | Subcommand to retrieve encrypted assets from DB and write to disk |
| `importCmd` | `*flag.FlagSet` | Subcommand to write a named asset value into the DB |
| `rolloverCmd` | `*flag.FlagSet` | Subcommand to extend an existing Apple MDM CA certificate's validity period |

## Usage Example

```bash
# Export all MDM assets to /tmp/mdm-assets
go run main.go export \
  -key "your-32-byte-encryption-key" \
  -dir /tmp/mdm-assets \
  -db-user fleet \
  -db-password insecure \
  -db-address localhost:3306 \
  -db-name fleet

# Import a single asset
go run main.go import \
  -key "your-32-byte-encryption-key" \
  -name apns_cert \
  -value "$(cat /path/to/apns.crt)" \
  -db-address localhost:3306

# Extend the Apple MDM CA certificate by 5 years
go run main.go rollover-ca-cert \
  -key "your-32-byte-encryption-key" \
  -extend-years 5 \
  -db-address localhost:3306
```

> **Note:** The `-key` flag is truncated to 32 bytes automatically to satisfy the AES-256 requirement. The `rollover-ca-cert` subcommand reuses the existing CA identity (Subject, SubjectKeyId, RSA key) and only updates the serial number and `NotAfter` field, preserving trust for previously-issued client certificates.
