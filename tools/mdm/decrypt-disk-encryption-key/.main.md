Decrypts a base64-encoded CMS-encrypted disk encryption key (e.g., BitLocker or FileVault recovery keys) using a provided X509 certificate and private key pair.

## Key Components

| Element | Description |
|---|---|
| `main()` | Entry point; parses CLI flags, loads the X509 cert via `MDMConfig.MicrosoftWSTEP()`, and calls `mdm.DecryptBase64CMS` |
| `-cert` flag | Path to the X509 certificate file (SCEP for macOS, WSTEP for Windows) |
| `-key` flag | Path to the X509 private key file |
| `-value-to-decrypt` flag | Base64-encoded encrypted value to decrypt |

## Usage Example

```bash
go run ./tools/mdm/decrypt-disk-encryption-key/main.go \
  -cert path/to/file.crt \
  -key path/to/file.key \
  -value-to-decrypt base64-encoded-value
```

On success, the decrypted key is printed to stdout:

```text
Decrypted value: <plaintext-recovery-key>
```

Errors (missing flags, cert load failures, decryption failures) are logged as structured JSON to stderr.

> **Note:** The tool uses `MDMConfig.MicrosoftWSTEP()` internally for certificate loading regardless of the host platform. The underlying certificate format is identical for both SCEP (macOS) and WSTEP (Windows) use cases — the distinction does not affect decryption behavior.
