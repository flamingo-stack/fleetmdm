Simulates Apple DEP enrollment on a virtual machine by inserting MDM-related database records and enqueuing setup experience items for a specified host in Fleet.

## Key Components

- **`main()`** — Entry point that orchestrates the full simulation:
  - Parses CLI flags (`--mysql`, `--server-private-key`, `--host-uuid`)
  - Connects directly to the Fleet MySQL database via `sqlx`
  - Validates the target host belongs to a team
  - Inserts MDM enrollment records (`nano_devices`, `nano_enrollments`, `host_mdm`, etc.)
  - Upserts verified profile rows into `host_mdm_apple_profiles` for each team-scoped configuration profile
  - Calls `mds.EnqueueSetupExperienceItems()` via the Fleet datastore to trigger the setup experience flow

## Usage Example

```bash
go run main.go \
  --server-private-key <fleet_private_key> \
  --host-uuid <host_serial_or_uuid> \
  --mysql localhost:3306
```

**Prerequisites:**
- A running Fleet MySQL instance (defaults to `localhost:3306`, database `fleet`, user `fleet`, password `insecure`)
- The target host must already exist in the `hosts` table and be assigned to a team
- At least one MDM configuration profile must exist for that team in `mdm_apple_configuration_profiles`

> **Note:** The private key is truncated to 32 bytes if longer, as required by AES-256 encryption used for MDM assets.
