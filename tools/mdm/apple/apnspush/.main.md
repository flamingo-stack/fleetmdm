Sends APNs push notifications to Apple MDM-enrolled devices identified by UUID, bypassing the need for the host to exist in Fleet's database.

## Key Components

| Component | Description |
|-----------|-------------|
| `mysqlAddr` flag | MySQL connection address (default: `localhost:3306`) |
| `serverPrivateKey` flag | Fleet server private key used to decrypt MDM assets from the database |
| `mysql.New` | Initializes a Fleet MySQL datastore connection with MDM decryption support |
| `NewMDMAppleMDMStorage` | Creates the Apple MDM-specific storage layer for push certificates/tokens |
| `buford.NewPushProviderFactory` | Builds the APNs HTTP/2 push provider using the device's stored certificate |
| `nanomdm_pushsvc.New` / `pusher.Push` | Sends the actual APNs push notification to one or more host UUIDs |

## Usage Example

```bash
go run ./tools/mdm/apple/apnspush/main.go \
  -mysql localhost:3306 \
  -server-private-key <your-32-byte-key> \
  HOST_UUID1 HOST_UUID2
```

**Notes:**
- The `serverPrivateKey` is automatically truncated to 32 bytes if longer (AES-256 requirement)
- The default MySQL connection uses the Fleet development credentials (`fleet`/`insecure` on the `fleet` database)
- Target hosts do **not** need to exist in Fleet, but must have been previously enrolled in Fleet MDM
- Push results are printed as indented JSON to stdout
