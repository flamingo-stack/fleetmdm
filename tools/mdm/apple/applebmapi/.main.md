A CLI debugging tool that authenticates against Apple Business Manager (ABM) via the Apple DEP API, retrieving account details, enrollment profiles, device details, or account-driven enrollment service discovery.

## Key Components

| Flag | Description |
|------|-------------|
| `-mysql` | MySQL address (default `localhost:3306`) |
| `-key` | Fleet server private key for decrypting MDM assets |
| `-org-name` | ABM organization name associated with the token |
| `-profile-uuid` | UUID of an Apple enrollment profile to retrieve |
| `-serial-number` | Device serial number to fetch device details |
| `-command` | Supported named command (e.g., `adue` for account-driven enrollment discovery) |

**Dispatch logic** — exactly one of `-profile-uuid`, `-serial-number`, or `-command` may be provided. Defaults to `AccountDetail` if none are given.

**Key setup steps:**
1. Connects to a Fleet MySQL database to load DEP storage (MDM assets).
2. Builds a `godep.Client` using the retrieved storage and a standard HTTP client.
3. Calls the appropriate ABM API endpoint and pretty-prints the JSON response.

## Usage Example

```bash
# Get ABM account details for an org
go run main.go \
  -key "your32bytefleetprivatekey12345" \
  -org-name "MyOrg"

# Retrieve a specific enrollment profile
go run main.go \
  -key "your32bytefleetprivatekey12345" \
  -org-name "MyOrg" \
  -profile-uuid "abc-123-def"

# Get device details by serial number
go run main.go \
  -key "your32bytefleetprivatekey12345" \
  -org-name "MyOrg" \
  -serial-number "C02XG0JJJGH5"

# Fetch account-driven enrollment service discovery
go run main.go \
  -key "your32bytefleetprivatekey12345" \
  -org-name "MyOrg" \
  -command adue
```

> **Note:** Private keys longer than 32 bytes are automatically truncated to satisfy the AES-256 requirement. The MySQL connection defaults assume a local Fleet dev environment (`fleet`/`insecure`).
