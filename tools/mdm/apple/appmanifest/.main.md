Generates an XML app manifest (plist) for a `.pkg` file, intended for use with Apple MDM package distribution.

## Key Components

- **`main()`** — Entry point that parses CLI flags, opens the specified `.pkg` file, and prints the generated plist XML to stdout.
- **`--pkg-file`** — Path to the local `.pkg` file to process.
- **`--pkg-url`** — URL where the package will be hosted/served (embedded in the manifest).
- **`appmanifest.NewPlist`** — Constructs the XML manifest from the package file and its distribution URL.

## Usage Example

```bash
go run main.go \
  --pkg-file ./MyApp.pkg \
  --pkg-url https://example.com/packages/MyApp.pkg
```

This outputs an XML plist to stdout that can be served alongside the `.pkg` for Apple MDM-managed installs. Redirect to a file as needed:

```bash
go run main.go \
  --pkg-file ./MyApp.pkg \
  --pkg-url https://example.com/packages/MyApp.pkg \
  > MyApp.plist
```

Both flags are required; omitting either causes a fatal error and exits.
