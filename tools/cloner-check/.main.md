Verifies that each struct stored in the `cached_mysql` in-memory cache properly implements the `fleet.Cloner` interface by comparing generated field listings against tracked snapshot files.

## Key Components

**`cacheableItems`** — Registry of all cacheable `fleet.Cloner` structs that must be tracked (e.g., `AppConfig`, `Pack`, `Query`, `TeamConfig`).

**`checkCacheableItems()`** — Reads each struct's snapshot from `tools/cloner-check/generated_files/`, generates a fresh field listing via reflection, and diffs them. Returns `false` if any mismatch is found.

**`updateCacheableItems()`** — Regenerates and overwrites the snapshot files with the current struct definitions. Used after verifying that a custom `Clone` implementation is correct.

**`generateFieldsList()` / `generateStructFieldsList()`** — Recursively traverses a struct's fields via `reflect`, printing each field's package path, name, and type. Follows pointers, slices, arrays, and map key/value types into nested structs.

**`getUnderlyingStructType()`** — Unwraps pointers, slices, arrays, and maps to resolve the underlying struct type(s). Returns up to two types to handle map keys and values separately.

## Usage Example

```bash
# Check mode (default) — used in CI to detect untracked struct changes
go run ./tools/cloner-check/main.go [--check]
# or
make check-go-cloner

# Update mode — regenerate snapshots after verifying Clone implementation
go run ./tools/cloner-check/main.go --update
# or
make update-go-cloner
```

> **Adding a new cacheable struct?** Append it to `cacheableItems` in [`tools/cloner-check/main.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/cloner-check/main.go), implement `Clone()` on the struct, then run `--update` to generate its snapshot file.
