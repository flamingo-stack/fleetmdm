Provides a CLI flag definition for specifying a local WiX installation directory, used as an alternative to the Docker Hub-based WiX toolchain during Fleet agent packaging.

## Key Components

- **`LocalWixDirFlag`** — Returns a `*cli.StringFlag` configured with the `--local-wix-dir` flag name, binding its value to the provided `dest` string pointer.

## Usage Example

```go
var localWixDir string

app := &cli.App{
    Flags: []cli.Flag{
        LocalWixDirFlag(&localWixDir),
    },
    Action: func(c *cli.Context) error {
        // localWixDir is populated after flag parsing
        fmt.Println("WiX dir:", localWixDir)
        return nil
    },
}
```
