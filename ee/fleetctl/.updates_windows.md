Windows-specific stub for the `updates` CLI command that disables update management functionality, returning an error when invoked due to incompatibilities between the Windows and Unix permission models.

## Key Components

- **`UpdatesCommand() *cli.Command`** — Returns a `cli.Command` stub named `updates` that immediately errors in its `Before` hook, preventing execution on Windows. The command is still registered (for CLI consistency) but always fails with a descriptive message directing users to a Linux environment.

## Usage Example

```go
// Registered automatically via build tags on Windows builds.
// Attempting to run will yield:
//   Error: Update management is not supported on Windows. Please use a Linux environment to continue.

app := &cli.App{
    Commands: []*cli.Command{
        UpdatesCommand(),
    },
}
```

> **Build tag:** This file is compiled only on Windows (`//go:build windows`). The Linux/macOS equivalent in the same package provides full update management functionality.

## Notes

- The `Before` hook approach ensures the error surfaces before any subcommand logic runs, giving a clean user-facing message.
- Recommended workflow: manage Fleet client updates from a Linux host, then distribute the resulting artifacts to Windows endpoints.
- See the full implementation at [`ee/fleetctl/updates_windows.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/fleetctl/updates_windows.go).
