Manages TUF (The Update Framework) compliant update repository operations for Fleet's client update system, providing CLI subcommands to initialize, add artifacts, timestamp, and rotate signing keys in a secure update repository.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `UpdatesCommand()` | `*cli.Command` | Root CLI command exposing all `updates` subcommands |
| `updatesInitFunc` | `func` | Initializes a new TUF repository with keys for all four roles |
| `updatesAddFunc` | `func` | Adds a signed artifact to the repository with version/platform/tag routing |
| `updatesTimestampFunc` | `func` | Refreshes and signs the timestamp manifest |
| `updatesRotateFunc` | `func` | Rotates signing keys for a given TUF role with rollback support |
| `updatesRootsFunc` | `func` | Prints the raw `root.json` metadata |
| `passHandler` | `passphraseHandler` | Handles encrypted key passphrase prompts |

**Key expiration durations (configurable at build time):**

| Variable | Default |
|----------|---------|
| `keyExpirationDuration` | `87600h` (~10 years) |
| `targetsExpirationDuration` | `26280h` (~3 years) |
| `snapshotExpirationDuration` | `26280h` (~3 years) |
| `timestampExpirationDuration` | `336h` (14 days) |

## Usage Example

```bash
# Initialize a new TUF repository
fleetctl updates init --path /path/to/repo

# Add a new artifact
fleetctl updates add \
  --path /path/to/repo \
  --target ./osqueryd \
  --name osqueryd \
  --platform linux \
  --version 5.10.2 \
  --tag stable

# Refresh the timestamp signature (run periodically before expiry)
fleetctl updates timestamp --path /path/to/repo

# Rotate the timestamp signing key
fleetctl updates rotate --path /path/to/repo timestamp
```

> **Note:** This file is Darwin/Linux only (`//go:build darwin || linux`) and requires a valid Fleet EE subscription. Key rotation includes automatic rollback on failure.
