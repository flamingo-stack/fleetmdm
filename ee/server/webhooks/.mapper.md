Constructs enriched webhook payloads for vulnerability notifications by extending the base Fleet webhook mapper with additional CVE metadata fields.

## Key Components

- **`Mapper`** — Embeds `fleetwebhooks.Mapper` to inherit base payload construction behavior.
- **`NewMapper()`** — Constructor returning a `fleetwebhooks.VulnMapper` interface backed by `Mapper`.
- **`GetPayload()`** — Overrides the base mapper to append EPSS probability, CVSS score, CISA known exploit status, and CVE published date to the outgoing webhook payload.

## Usage Example

```go
mapper := webhooks.NewMapper()

payload := mapper.GetPayload(
    hostBaseURL,
    hosts,
    "CVE-2024-12345",
    fleet.CVEMeta{
        EPSSProbability:  0.94,
        CVSSScore:        floatPtr(9.8),
        CISAKnownExploit: boolPtr(true),
        Published:        &publishedTime,
    },
)
// payload now includes enriched fields:
// payload.EPSSProbability, payload.CVSSScore,
// payload.CISAKnownExploit, payload.CVEPublished
```

## Notes

- Delegates core payload assembly to the embedded `fleetwebhooks.Mapper.GetPayload()`, then mutates the result to attach enriched metadata.
- Enrichment fields (`EPSSProbability`, `CVSSScore`, `CISAKnownExploit`, `CVEPublished`) are sourced directly from `fleet.CVEMeta`, providing downstream webhook consumers with richer vulnerability context beyond what the base mapper supplies.
