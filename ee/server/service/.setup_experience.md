Manages the Fleet MDM setup experience lifecycle, including software installation ordering, script execution, and policy-gated install gating during macOS device enrollment.

## Key Components

- **`setupExperienceGatingPolicyTimeout`** – 30-minute constant bounding how long a policy-gated setup item waits before failing open.
- **`SetSetupExperienceSoftware`** – Authorizes and persists the list of software titles for a given platform/team, with a guard against `macos_manual_agent_install` conflicts.
- **`ListSetupExperienceSoftware`** – Returns a paginated list of software titles configured for the setup experience.
- **`GetSetupExperienceScript`** – Retrieves the setup experience script for a team, optionally including its raw content.
- **`SetSetupExperienceScript`** – Validates, stores, and enforces `.sh`-only file type rules for setup experience scripts; blocks when `macos_manual_agent_install` is enabled.
- **`DeleteSetupExperienceScript`** – Removes the setup experience script for a team.
- **`SetupExperienceNextStep`** – Orchestrates step-by-step install sequencing: processes one software item at a time (alphabetically by display name), handles policy-gated items, and ensures scripts only run after all software completes.

## Usage Example

```go
// Enqueue software for a team's macOS setup experience
err := svc.SetSetupExperienceSoftware(ctx, "darwin", teamID, []uint{101, 202, 303})

// Advance the setup experience for a newly enrolled host
shouldContinue, err := svc.SetupExperienceNextStep(ctx, host)

// Upload a setup script
err = svc.SetSetupExperienceScript(ctx, &teamID, "setup.sh", scriptReader)

// Retrieve the script with its content
script, content, err := svc.GetSetupExperienceScript(ctx, &teamID, true)
```

## Notes

- Software installs are sequenced **one at a time** in alphabetical display-name order; scripts run only after all software finishes.
- Un-gated installs are prioritized over policy-gated ones to avoid blocking during policy evaluation.
- Android devices bypass this step-by-step flow entirely (see [Fleet #33761](https://github.com/fleetdm/fleet/issues/33761)).
