Proxies SCEP certificate requests to upstream CA servers (NDES, Smallstep, or custom SCEP proxy), handling identifier parsing, challenge validation, and multi-platform support (Apple, Windows, Android MDM profiles).

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `scepProxyService` | struct | Core service implementing `scepserver.ServiceWithIdentifier`; holds datastore, logger, and timeout |
| `NewSCEPProxyService` | func | Constructor; defaults timeout to 30s |
| `GetCACaps` | method | Pass-through to upstream SCEP server for capability discovery |
| `GetCACert` | method | Pass-through to upstream SCEP server for CA certificate retrieval |
| `PKIOperation` | method | Proxies the SCEP PKI operation; enforces challenge validation before forwarding |
| `validateIdentifier` | method | Parses the comma-separated identifier (`hostUUID,profileUUID,caName,challenge`), validates the CA, and returns the resolved SCEP URL |
| `scepCertificateRequest` | interface | Abstracts certificate request state across Apple, Windows, and Android platforms |
| `hostMDMCertificateProfileAdapter` | struct | Adapts `fleet.HostMDMCertificateProfile` to `scepCertificateRequest` |
| `certificateTemplateForHostAdapter` | struct | Adapts `fleet.CertificateTemplateForHost` (Android) to `scepCertificateRequest` |
| `decodeHTMLResponse` | func | Decodes HTTP response bodies with UTF-16 LE / UTF-8 detection (for NDES compatibility) |
| `looksLikeUTF16LE` | func | Heuristic BOM, HTML pattern, and null-byte percentage check for UTF-16 LE detection |
| `challengeRegex` | var | Regex to extract the NDES enrollment challenge password from HTML responses |

**Key constants:**

| Constant | Value | Purpose |
|----------|-------|---------|
| `NDESChallengeInvalidAfter` | 57 min | NDES challenge expiry window |
| `SmallstepChallengeInvalidAfter` | 4 min | Smallstep challenge expiry window |
| `MessageSCEPProxyNotConfigured` | string | Standard error message when proxy is unconfigured |

## Usage Example

```go
import (
    "log/slog"
    "time"
    "github.com/fleetdm/fleet/v4/server/mdm/nanomdm/mdm/scep"
    "github.com/fleetdm/fleet/v4/server/ptr"
)

// Create the SCEP proxy service with a 30s timeout
svc := scep.NewSCEPProxyService(
    datastoreImpl,
    slog.Default(),
    ptr.Duration(30 * time.Second),
)

// Retrieve CA capabilities for a given identifier
// identifier format: "hostUUID,profileUUID,caName,fleetChallenge"
caps, err := svc.GetCACaps(ctx, "host-uuid,a1b2c3,NDES")

// Forward a PKI operation (challenge is validated internally)
response, err := svc.PKIOperation(ctx, csrBytes, "host-uuid,a1b2c3,NDES,challengeToken")
```
