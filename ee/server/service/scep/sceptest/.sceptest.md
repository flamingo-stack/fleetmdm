Provides test helpers for SCEP proxy testing, including a test SCEP server, an NDES admin page emulator, and a dynamic challenge server — all backed by embedded test certificates and canned HTML responses.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NewTestSCEPServer` | `func(t *testing.T) *httptest.Server` | Spins up a real SCEP server backed by embedded CA certs written to a temp directory |
| `NewTestNDESAdminServer` | `func(t *testing.T, responseTemplate string, _ int) *httptest.Server` | Emulates a Windows NDES admin page, serving UTF-16–encoded HTML from one of three canned templates |
| `NewTestDynamicChallengeServer` | `func(t *testing.T) *httptest.Server` | Returns a server that always responds with `"dynamic challenge"` |
| `UTF16FromString` | `func(s string) ([]uint16, error)` | Converts a UTF-8 string to UTF-16 with a NUL terminator; returns `syscall.EINVAL` if the input contains a NUL byte |
| `noopDepot` | `struct` | Wraps `depot.Depot` with a no-op `Put` to suppress cert storage during tests |

**Embedded assets** (via `//go:embed`):
- `testdata/testca/ca.key` / `ca.pem` — test CA credentials
- `testdata/mscep_admin_cache_full.html`
- `testdata/mscep_admin_insufficient_permissions.html`
- `testdata/mscep_admin_password.html`

## Usage Example

```go
func TestSCEPProxy(t *testing.T) {
    // Start a SCEP server backed by embedded test CA
    scepServer := sceptest.NewTestSCEPServer(t)

    // Emulate an NDES admin page returning a cached challenge password
    ndesServer := sceptest.NewTestNDESAdminServer(t, "mscep_admin_password", 0)

    // Emulate a dynamic challenge endpoint
    challengeServer := sceptest.NewTestDynamicChallengeServer(t)

    _ = scepServer.URL      // e.g. "http://127.0.0.1:PORT/scep"
    _ = ndesServer.URL      // serves UTF-16 HTML
    _ = challengeServer.URL // always returns "dynamic challenge"

    // All servers are closed automatically via t.Cleanup
}
```

> **Note:** This package imports `testing` and is strictly for test code. Never import it from production binaries.
