Defines custom error types for the premium service layer, providing structured HTTP-aware errors for not-found resources, invalid IDP tokens, and invalid CSR requests.

## Key Components

- **`notFoundError`** — Wraps `fleet.ErrorWithUUID`; returns `"not found"` and implements `IsNotFound() bool` to signal HTTP 404 responses to the handler layer.
- **`InvalidIDPTokenError`** — Signals an invalid Identity Provider token; returns HTTP 403 Forbidden via `StatusCode()`.
- **`InvalidCSRError`** — Signals an invalid Certificate Signing Request; returns HTTP 400 Bad Request via `StatusCode()`.

## Usage Example

```go
// Returning a not-found error from a service method
func (svc *Service) GetResource(ctx context.Context, id uint) (*fleet.Resource, error) {
    resource, err := svc.ds.Resource(ctx, id)
    if err != nil {
        return nil, &notFoundError{}
    }
    return resource, nil
}

// Returning an IDP token error (handler maps StatusCode() → HTTP 403)
func (svc *Service) ValidateIDPResponse(token string) error {
    if !isValid(token) {
        return InvalidIDPTokenError{}
    }
    return nil
}

// Returning a CSR error (handler maps StatusCode() → HTTP 400)
func (svc *Service) ProcessCSR(csr []byte) error {
    if !validCSR(csr) {
        return InvalidCSRError{}
    }
    return nil
}
```

HTTP status mapping is driven by the `StatusCode() int` method (for `InvalidIDPTokenError` and `InvalidCSRError`) and the `IsNotFound() bool` method (for `notFoundError`), which the Fleet HTTP handler layer reads to set the appropriate response code.
