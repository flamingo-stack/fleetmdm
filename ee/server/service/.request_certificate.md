Handles certificate requests from Fleet devices by proxying CSR submissions to EST-compatible Certificate Authorities (Hydrant or custom EST proxy), with optional IdP token validation to verify the requesting user's identity.

## Key Components

### `RequestCertificate`
The primary service method that orchestrates the full certificate issuance flow:
- Validates authorization (supports HTTP Message Signature auth for device-level calls)
- Fetches and validates the CA configuration (Hydrant or custom EST proxy)
- Parses the submitted CSR
- Optionally introspects an IdP OAuth token and cross-validates it against CSR user info
- Forwards the CSR to the EST service and returns the certificate as PKCS7 or PEM

### `pkcs7EnvelopeToPEM`
Converts a base64-encoded PKCS7 envelope (RFC 7030 `simpleenroll` response) into a single PEM `CERTIFICATE` block. Rejects envelopes containing anything other than exactly one certificate.

### `introspectIDPToken`
POSTs a token introspection request to an OAuth2 endpoint, decodes the response, and returns an `oauthIntrospectionResponse` indicating whether the token is active and which username it belongs to.

### `parseCSR`
Decodes a PEM-encoded CSR string (handling escaped newlines) and parses it into an `*x509.CertificateRequest`.

### `extractCSRUserInfo`
Extracts the single email address and UPN (User Principal Name) from a CSR for IdP cross-validation.

### `extractCSRUPN`
Manually walks the raw ASN.1 SAN extension to locate the Microsoft UPN OID (`1.3.6.1.4.1.311.20.2.3`) in the `otherName` field, since the Go standard library does not expose this.

## Usage Example

```go
cert, err := svc.RequestCertificate(ctx, fleet.RequestCertificatePayload{
    ID:                  42,
    CSR:                 "-----BEGIN CERTIFICATE REQUEST-----\n...\n-----END CERTIFICATE REQUEST-----\n",
    ReturnPEMCertificate: true,
    // Optional IdP validation
    IDPClientID:  ptr("my-client-id"),
    IDPToken:     ptr("eyJ..."),
    IDPOauthURL:  ptr("https://idp.example.com/oauth2/introspect"),
})
if err != nil {
    // handle InvalidCSRError, InvalidIDPTokenError, fleet.BadRequestError, etc.
}
fmt.Println(*cert) // PEM-encoded certificate
```
