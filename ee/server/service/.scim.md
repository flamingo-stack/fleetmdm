Retrieves SCIM (System for Cross-domain Identity Management) details for the Fleet service, including the last SCIM request metadata.

## Key Components

- **`ScimDetails(ctx context.Context) (fleet.ScimDetails, error)`** — Authorizes the caller for read access on `ScimUser` resources, then fetches the most recent SCIM request from the datastore and returns it wrapped in a `fleet.ScimDetails` struct.

## Usage Example

```go
details, err := svc.ScimDetails(ctx)
if err != nil {
    // handle authorization or datastore error
}
fmt.Println(details.LastRequest)
```

## Notes

- Authorization is enforced via `svc.authz.Authorize` using `fleet.ActionRead` on a `fleet.ScimUser` resource; unauthorized callers receive an error before any datastore access.
- Errors from the datastore are wrapped with context using `ctxerr.Wrap` for improved traceability in logs and error chains.
- Source: [`scim.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/scim.go)
