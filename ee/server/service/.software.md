Wraps the base `Service` implementation for software-related operations, enabling premium-tier features such as CVE score inclusion in the Flamingo FleetMDM service layer.

## Key Components

- **`ListSoftware`** – Delegates to the base `Service.ListSoftware` with conditional CVE score enrichment. CVE scores (`IncludeCVEScores`) are enabled when CVSS thresholds are set, known exploits are filtered, or `WithoutVulnerabilityDetails` is `false`. This guard avoids unnecessary memory overhead when vulnerability details aren't needed.
- **`SoftwareByID`** – Delegates to the base `Service.SoftwareByID`, always passing `true` to enable CVE score inclusion in the premium tier.

## Usage Example

```go
// List software with CVE scoring enabled via CVSS filter
software, pagination, err := svc.ListSoftware(ctx, fleet.SoftwareListOptions{
    MinimumCVSS: 7.0,
    ListOptions: fleet.ListOptions{Page: 0, PerPage: 25},
})

// List software suppressing vulnerability details for performance
software, pagination, err := svc.ListSoftware(ctx, fleet.SoftwareListOptions{
    WithoutVulnerabilityDetails: true,
    ListOptions: fleet.ListOptions{Page: 0, PerPage: 100},
})

// Fetch a single software entry with CVE scores (always included in premium)
sw, err := svc.SoftwareByID(ctx, 42, &teamID, false)
```

## Notes

- This file is part of the **premium service layer**, overriding base service methods to inject enterprise-only behavior.
- CVE score enrichment is intentionally opt-in for list operations to prevent memory bloat at scale; `SoftwareByID` always includes scores since it returns a single record.
