Handles in-house (iOS/iPadOS) app management within the Fleet MDM service layer, including updating installer metadata, generating OTA manifest plists, serving installer packages, and validating install tokens.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `updateInHouseAppInstaller` | Method | Updates an existing in-house app installer — validates labels, diffs the uploaded file, persists changes, clears pending installs, and logs an activity event |
| `GetInHouseAppManifest` | Method | Returns a signed Apple OTA plist manifest (`application/xml`) for wireless iOS app distribution; supports CloudFront signed URLs |
| `GetInHouseAppPackage` | Method | Streams the raw `.ipa` binary after validating the one-time install token |
| `validateInHouseAppInstallToken` | Method | Validates UUID-length token against the database and checks title-ID ownership; collapses all failure modes into a generic permission error |
| `inHouseTeamIDPtr` | Helper | Converts a stored `uint` team ID (0 = no team) to a nullable `*uint` |
| `inHouseAppInstallTokenLength` | Constant | Expected token length (`36`, UUID format) |

## Usage Example

```go
// Generate an OTA manifest for a device to download an in-house app.
// The token is a UUID issued per-host install request.
manifestBytes, err := svc.GetInHouseAppManifest(ctx, titleID, token)
if err != nil {
    return err
}
// Serve with Content-Type: application/xml to trigger iOS OTA installation.
w.Header().Set("Content-Type", "application/xml")
w.Write(manifestBytes)

// Update installer metadata (e.g. self-service flag, new .ipa file).
payload := &fleet.UpdateSoftwareInstallerPayload{
    TeamID:      ptr.Uint(42),
    TitleID:     titleID,
    SelfService: ptr.Bool(true),
}
updated, err := svc.updateInHouseAppInstaller(ctx, payload, vc, teamName, software)
```

## Notes

- Authorization is skipped on manifest/package endpoints; security is enforced exclusively through `validateInHouseAppInstallToken`.
- `GetInHouseAppManifest` XML-escapes the download URL (required for CloudFront signed URLs that contain `&` characters) using `mobileconfig.XMLEscapeString`.
- After a successful installer update, all pending installs for that installer are cleared via `RemovePendingInHouseAppInstalls`.
