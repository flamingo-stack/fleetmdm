Handles Apple VPP (Volume Purchase Program) app management for Fleet MDM, including token lifecycle management, app metadata resolution, storefront anchor logic, and batch app association across Apple platforms (macOS, iOS, iPadOS).

## Key Components

### Types

- **`vppTokenInfo`** — Bundles an encoded VPP token secret with its associated storefront country code
- **`vppAddAnchor`** — Describes which token/storefront to use when adding an app and whether the app row should be re-anchored to a new country

### Functions & Methods

| Name | Description |
|------|-------------|
| `resolveAddAnchor` | Implements the first-add / subsequent-add / re-anchor decision tree for VPP app metadata fetching |
| `ensureVPPTokenCountry` | Lazy-backfills `country_code` on legacy tokens that predate the column; bounded by a 5-second deadline |
| `getVPPToken` | Returns only the base64-encoded token secret; lightweight path for install operations |
| `getVPPTokenInfo` | Returns both secret and country code; used by add/refresh paths that need storefront context |
| `BatchAssociateVPPApps` | Associates a batch of VPP apps with a team, expanding apps without explicit platforms across all Apple platforms |

### Constants & Variables

- **`ensureVPPTokenCountryDeadline`** — 5-second timeout cap for Apple `/client/config` calls during country backfill
- **`testSetEmptyPrivateKey`** — Package-level flag for overriding environment variables in tests
- **`isAdamID`** — Compiled regexp validating that an App Store ID consists only of digits

## Usage Example

```go
// Resolve which storefront token to use when adding an app
anchor, err := svc.resolveAddAnchor(ctx, "123456789", fleet.MacOSPlatform, vppTokenInfo{
    Secret:  base64EncodedToken,
    Country: "US",
})
if err != nil {
    return err
}
// anchor.fetchSecret and anchor.anchorCountry are now set

// Get token info (with country) for add/refresh paths
info, err := svc.getVPPTokenInfo(ctx, &teamID)

// Get token secret only for install paths (no Apple call)
secret, err := svc.getVPPToken(ctx, &teamID)

// Batch-associate apps, auto-expanding to all Apple platforms
responses, warnings, err := svc.BatchAssociateVPPApps(ctx, "Engineering", []fleet.VPPBatchPayload{
    {AppStoreID: "497799835", SelfService: true},
}, false)
```

## Notes

- Apps without an explicit `Platform` are automatically expanded to macOS, iOS, and iPadOS entries; unsupported platforms are pruned after metadata fetch
- Country anchoring prevents metadata inconsistency when the same Adam ID is added across teams in different storefronts
- Install paths intentionally avoid synchronous Apple calls to prevent blocking when Apple is unreachable
