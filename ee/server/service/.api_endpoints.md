Lists Fleet API endpoints with authorization enforcement, exposing a single service method that checks read permissions before returning all available API endpoint definitions.

## Key Components

- **`ListAPIEndpoints(ctx context.Context) ([]fleet.APIEndpoint, error)`** — Authorizes the caller against the `fleet.APIEndpoint` resource with `ActionRead`, then delegates to `apiendpoints.GetAPIEndpoints()` to retrieve the full endpoint list.

## Usage Example

```go
endpoints, err := svc.ListAPIEndpoints(ctx)
if err != nil {
    // handle authorization or retrieval error
}
for _, ep := range endpoints {
    fmt.Println(ep.Path, ep.Method)
}
```

## Notes

- Authorization is enforced via `svc.authz.Authorize` before any data is returned; unauthenticated or unauthorized callers receive a wrapped `ctxerr` error.
- The actual endpoint registry lives in the `apiendpoints` package (`github.com/flamingo-stack/fleetmdm/blob/main/server/api_endpoints`); this service layer adds only the authz gate.
