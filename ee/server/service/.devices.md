Handles device-level service operations for Fleet-managed hosts, including policy listing, MDM migration webhooks, conditional access bypass, desktop summary aggregation, disk encryption escrow, software icon retrieval, and setup experience status.

## Key Components

| Function | Description |
|---|---|
| `ListDevicePolicies` | Returns all policies associated with a given host |
| `TriggerMigrateMDMDevice` | Sends a webhook to trigger macOS MDM migration to Fleet (Fleet Premium) |
| `BypassConditionalAccess` | Marks a device as bypassing conditional access and logs the activity |
| `GetFleetDesktopSummary` | Aggregates desktop summary data including failing policies, MDM migration status, self-service software, and org config |
| `TriggerLinuxDiskEncryptionEscrow` | Queues a LUKS disk encryption key escrow for eligible Linux hosts |
| `validateReadyForLinuxEscrow` | Validates that a Linux host meets all prerequisites before escrow |
| `GetDeviceSoftwareIconsTitleIcon` | Retrieves software title icon bytes from storage or VPP metadata |
| `GetDeviceSetupExperienceStatus` | Returns the current setup experience status for a device-authenticated host |
| `getHostSetupExperienceStatus` | Internal helper that resolves setup experience results and advances to the next step |

## Usage Example

```go
// Get Fleet Desktop summary for a host authenticated via device token
summary, err := svc.GetFleetDesktopSummary(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Failing policies:", *summary.FailingPolicies)
fmt.Println("Needs MDM migration:", summary.Notifications.NeedsMDMMigration)

// Trigger macOS MDM migration webhook
if err := svc.TriggerMigrateMDMDevice(ctx, host); err != nil {
    log.Fatal(err)
}

// Queue Linux disk encryption escrow
if err := svc.TriggerLinuxDiskEncryptionEscrow(ctx, host); err != nil {
    log.Fatal(err)
}
```

## Notes

- `TriggerMigrateMDMDevice` is Fleet Premium only and enforces deduplication via `RefetchCriticalQueriesUntil`.
- `BypassConditionalAccess` skips user authentication; it is device-token authenticated.
- `GetFleetDesktopSummary` skips authorization and relies on the host context injected by middleware.
