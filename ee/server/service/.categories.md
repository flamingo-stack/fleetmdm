Implements CRUD service methods for software categories used in Fleet's self-service software catalog, including authorization checks, activity logging, and input validation.

## Key Components

| Function | Description |
|---|---|
| `ListSoftwareCategories` | Lists categories for a given team with read authorization and team existence validation |
| `ListSelfServiceSoftwareCategoriesForHost` | Lists categories scoped to a host's team, used for self-service software display |
| `NewSoftwareCategory` | Creates a new category with write authorization, validation, and activity logging |
| `UpdateSoftwareCategory` | Updates an existing category's name with team-scoped authorization and activity logging |
| `DeleteSoftwareCategory` | Deletes a category by ID with team-scoped authorization and activity logging |
| `removeDuplicateOrMissingCategories` | Deduplicates a name slice and resolves names to valid IDs via the datastore |
| `teamNameForActivity` | Resolves a team ID to its name for use in activity log entries |
| `trimAndValidateCategories` | Trims whitespace and validates a slice of category name strings |

## Usage Example

```go
// Create a new software category for a team
teamID := uint(42)
category, err := svc.NewSoftwareCategory(ctx, &teamID, "Security Tools")
if err != nil {
    // handle error
}

// List categories for a team
categories, err := svc.ListSoftwareCategories(ctx, &teamID)
if err != nil {
    // handle error
}

// Update a category name
updated, err := svc.UpdateSoftwareCategory(ctx, category.ID, "Security & Compliance")
if err != nil {
    // handle error
}

// Delete a category
err = svc.DeleteSoftwareCategory(ctx, category.ID)
```

> **Note:** All mutating operations (`New`, `Update`, `Delete`) require write authorization scoped to the category's `TeamID` and emit activity log entries for audit tracking.
