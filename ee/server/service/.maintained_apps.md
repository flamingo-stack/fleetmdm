Handles Fleet Maintained Apps (FMA) operations — adding, listing, and retrieving pre-curated software packages managed by Fleet, including installer download, hash validation, and storage.

## Key Components

- **`AddFleetMaintainedApp`** — Authorizes, validates labels and embedded secrets, downloads the installer from the app's URL, verifies its SHA256 hash, builds an upload payload, stores the installer in S3, creates a database record, and emits activity events (including an automatic install policy event if applicable).
- **`ListFleetMaintainedApps`** — Returns a paginated list of available Fleet Maintained Apps, applying team-scoped or global authorization depending on whether a `teamID` is provided.
- **`GetFleetMaintainedApp`** — Retrieves a single Fleet Maintained App by ID, hydrating it from its manifest before returning.
- **`noCheckHash`** — Sentinel constant (`"no_check"`) inherited from Homebrew conventions; skips SHA256 verification when set on an app.

## Usage Example

```go
// Add a Fleet Maintained App to a team
titleID, err := svc.AddFleetMaintainedApp(
    ctx,
    ptr.Uint(42),       // teamID
    7,                  // appID
    "",                 // installScript (uses default from manifest)
    "",                 // preInstallQuery
    "",                 // postInstallScript
    "",                 // uninstallScript (uses default from manifest)
    false,              // selfService
    true,               // automaticInstall
    nil, nil, nil,      // label filters
)

// List available maintained apps for a team
apps, meta, err := svc.ListFleetMaintainedApps(ctx, ptr.Uint(42), fleet.MaintainedAppListOptions{})

// Get a single maintained app with hydrated manifest data
app, err := svc.GetFleetMaintainedApp(ctx, 7, ptr.Uint(42))
```

## Notes

- If `installScript` or `uninstallScript` differ from the manifest defaults, `FleetMaintainedAppID` is set to `nil` on the installer record to indicate a customized (non-stock) app.
- Version is extracted from the installer binary when the manifest version is `"latest"`.
