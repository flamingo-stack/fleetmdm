Implements an EST (Enrollment over Secure Transport) client service that communicates with an EST CA server to validate URLs and retrieve certificates via HTTP.

## Key Components

- **`Service`** — Core struct holding an HTTP client, logger, and timeout configuration
- **`NewService(opts ...Opt) fleet.ESTService`** — Constructor that applies functional options and returns a configured service implementing `fleet.ESTService`
- **`WithTimeout(t time.Duration) Opt`** — Functional option to set the HTTP client timeout (default: 20s)
- **`WithLogger(logger *slog.Logger) Opt`** — Functional option to set the structured logger
- **`ValidateESTURL(ctx, estCA) error`** — Validates an EST CA endpoint by calling `/cacerts` and checking for a non-empty `application/pkcs7-mime` response
- **`GetCertificate(ctx, estCA, csr) (*fleet.ESTCertificate, error)`** — Submits a PKCS#10 CSR to `/simpleenroll` using Basic Auth and returns the issued certificate bytes

## Usage Example

```go
import "github.com/fleetdm/fleet/v4/ee/server/integrations/est"

svc := est.NewService(
    est.WithTimeout(30 * time.Second),
    est.WithLogger(slog.Default()),
)

ca := fleet.ESTProxyCA{
    URL:      "https://est.example.com/.well-known/est",
    Username: "user",
    Password: "secret",
}

// Validate the EST CA endpoint
if err := svc.ValidateESTURL(ctx, ca); err != nil {
    log.Fatal(err)
}

// Enroll a certificate using a PEM-encoded CSR
cert, err := svc.GetCertificate(ctx, ca, csrPEM)
if err != nil {
    log.Fatal(err)
}
// cert.Certificate contains the DER-encoded PKCS#7 response
```

## Notes

- The service performs compile-time interface compliance via `var _ fleet.ESTService = (*Service)(nil)`
- Error response bodies are truncated to 1,000 bytes in logs to prevent accidental certificate data exposure
- URL validation checks content type and body presence but does not authenticate credentials against the EST server
