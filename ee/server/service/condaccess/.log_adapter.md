Adapts Go's structured `slog.Logger` to the SAML library's `logger.Interface`, bridging structured logging with the SAML package's expected logger contract within the `condaccess` package.

## Key Components

- **`slogAdapter`** — Struct holding a `context.Context` and `*slog.Logger`, implementing the SAML `logger.Interface`
- **Print variants** (`Print`, `Printf`, `Println`) — Forward messages to `slog.InfoContext`
- **Fatal variants** (`Fatal`, `Fatalf`, `Fatalln`) — Forward messages to `slog.ErrorContext` (without `os.Exit`, unlike standard `log.Fatal`)
- **Panic variants** (`Panic`, `Panicf`, `Panicln`) — Log via `slog.ErrorContext` then call `panic` with the formatted message

## Usage Example

```go
adapter := &slogAdapter{
    ctx:    ctx,
    logger: slog.Default(),
}

// Pass to a SAML component expecting logger.Interface
samlProvider.SetLogger(adapter)

// Internally, SAML log calls route through slog:
adapter.Printf("authenticating user %s", userID) // → slog InfoContext
adapter.Fatalf("config error: %v", err)           // → slog ErrorContext
```

> **Note:** `Fatal*` methods log at error level but do **not** terminate the process, differing from `log.Fatal` semantics. `Panic*` methods both log and call `panic`.
