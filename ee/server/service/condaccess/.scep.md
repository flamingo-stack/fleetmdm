Implements a SCEP (Simple Certificate Enrollment Protocol) service for Fleet's conditional access MDM feature, handling certificate issuance for device enrollment without supporting certificate renewal.

## Key Components

- **`RateLimitError`** — Custom error type that maps to HTTP 429 responses, implementing the `kithttp` `StatusCoder` interface.
- **`RegisterSCEP`** — Initializes assets, wires up the CSR signer with challenge middleware, and mounts the SCEP HTTP handler at `/api/fleet/conditional_access/scep`.
- **`challengeMiddleware`** — Middleware that validates the SCEP `ChallengePassword` against a Fleet enrollment secret; always required (no renewal path).
- **`service`** — Core SCEP service implementing `scepserver.Service`, backed by a datastore, CSR signer, and logger.
  - `GetCACaps` — Advertises `SHA-256`, `AES`, and `POSTPKIOperation` capabilities. Explicitly omits `Renewal`.
  - `GetCACert` — Returns the conditional access CA certificate from Fleet's MDM asset store.
  - `PKIOperation` — Parses SCEP PKI messages, decrypts the envelope, signs the CSR, and returns a success or failure response.
- **`NewSCEPService`** — Constructor for the `service` type.
- **`caKeyPair`** — Helper that retrieves the conditional access CA certificate/key pair from Fleet's asset store.

## Usage Example

```go
err := condaccess.RegisterSCEP(
    ctx,
    mux,
    scepStorage,       // scepdepot.Depot
    ds,                // fleet.Datastore
    logger,            // *slog.Logger
    &fleetConfig,      // *config.FleetConfig
)
if err != nil {
    log.Fatalf("registering conditional access SCEP: %v", err)
}
```

> **Key distinction from host identity SCEP:** Renewal is intentionally unsupported. Clients must always present a valid `ChallengePassword` (enrollment secret) to obtain a certificate. Certificates are valid for up to 398 days (`scepValidityDays`), matching Apple's maximum.
