Handles the Okta conditional access SAML Identity Provider (IdP) service, including HTTP endpoint registration, metadata serving, SSO request processing, and device health verification.

## Key Components

- **`RegisterIdP`** — Registers the `/api/fleet/conditional_access/idp/metadata` and `/api/fleet/conditional_access/idp/sso` HTTP handlers with rate limiting, logging, and OpenTelemetry middleware.
- **`idpService`** — Core service struct holding the datastore, logger, certificate serial format, and metadata cache.
- **`metadataCache`** — Thread-safe in-memory cache for SAML IdP metadata XML responses with a 1-minute TTL to protect against DDoS-driven database overload.
- **`serveMetadata`** — Serves SAML IdP metadata (XML) for Okta to consume, with cache-first response logic.
- **`serveSSO`** — Handles SAML `AuthnRequest` from Okta; extracts and validates the client certificate serial from the `X-Client-Cert-Serial` header, resolves the host, and delegates to the SAML library.
- **`statusInterceptingWriter`** — Wraps `http.ResponseWriter` to intercept HTTP 400 responses from the SAML library and redirect users to the certificate error page instead.
- **`responseRecorder`** — Captures HTTP responses in memory for caching before forwarding to the actual client.
- **`handleInternalServerError`** — Centralized 500-error handler ensuring consistent logging and OpenTelemetry error recording.
- **`parseSerialNumber`** — Parses certificate serial numbers from hex or decimal string format to `uint64`.
- **`notFoundError`** — Implements `fleet.NotFoundError` for IdP-specific not-found conditions.

## Usage Example

```go
// Register the IdP endpoints on startup
err := condaccess.RegisterIdP(
    mux,
    datastore,
    slog.Default(),
    &fleetConfig,
    limitStore,
)
if err != nil {
    log.Fatalf("failed to register IdP: %v", err)
}
```

Clients behind a load balancer must forward the `X-Client-Cert-Serial` header (hex or decimal based on `ConditionalAccess.CertSerialFormat`). Missing or unrecognized serials redirect to `https://fleetdm.com/okta-conditional-access-error`.
