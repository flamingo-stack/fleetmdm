Initializes and persists the PKI assets required for the Conditional Access feature, generating self-signed CA and IdP certificates if they are not already stored in the database.

## Key Components

### `initAssets(ctx, ds)`

Checks the datastore for the four required MDM config assets and creates any that are missing:

| Asset | Purpose |
|---|---|
| `MDMAssetConditionalAccessCACert` | SCEP CA certificate |
| `MDMAssetConditionalAccessCAKey` | SCEP CA private key |
| `MDMAssetConditionalAccessIDPCert` | SAML IdP signing certificate |
| `MDMAssetConditionalAccessIDPKey` | SAML IdP private key |

Both certificate pairs are generated as 10-year self-signed CAs (Common Name: `"Fleet conditional access CA"` / `"Fleet conditional access IdP"`, Organization: `"Local certificate authority"`, Country: `"US"`). Assets are PEM-encoded and stored encrypted via `ds.InsertMDMConfigAssets`. Duplicate-key errors are silently ignored to handle concurrent initialization safely.

## Usage Example

```go
// Called during server startup to ensure conditional access PKI assets exist
if err := initAssets(ctx, ds); err != nil {
    log.Fatalf("failed to initialize conditional access assets: %v", err)
}
```

> **Note:** `initAssets` is idempotent — re-running it when all four assets already exist is a no-op. Partial states (e.g., CA cert present but key missing) are handled gracefully: only the missing pair is regenerated.
