MySQL-backed SCEP certificate depot implementation for Fleet's conditional access feature, handling CA retrieval, serial number allocation, and certificate storage with host validation and rate limiting.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ConditionalAccessSCEPDepot` | struct | Implements `depot.Depot` interface backed by MySQL and Fleet datastore |
| `NewConditionalAccessSCEPDepot` | func | Constructor that validates DB connectivity and returns a configured depot |
| `CA` | method | Retrieves the CA certificate and RSA private key from Fleet MDM assets |
| `Serial` | method | Allocates a new auto-incremented serial number via `conditional_access_scep_serials` table |
| `HasCN` | method | Always returns `false` — renewal is not supported for conditional access |
| `Put` | method | Validates and stores a certificate, enforcing host lookup and optional rate limiting |
| `extractUUIDFromCert` | func (internal) | Parses the `urn:device:apple:uuid:<uuid>` SAN URI from a certificate |

## Usage Example

```go
depot, err := depot.NewConditionalAccessSCEPDepot(db, ds, logger, cfg)
if err != nil {
    log.Fatal(err)
}

// Retrieve CA credentials
certs, privateKey, err := depot.CA(nil)

// Allocate a serial number
serial, err := depot.Serial()

// Store a certificate (requires valid SAN URI with device UUID)
err = depot.Put("device-cn", cert)
```

## Certificate Flow Notes

- **SAN URI format required:** `urn:device:apple:uuid:<uuid>` must be present in the certificate's URI SANs
- **Host validation:** The UUID is resolved to a Fleet host via `HostByIdentifier` before storage; unknown hosts are rejected
- **Rate limiting:** Controlled by `Osquery.EnrollCooldown`; uses `backoff.Permanent` to prevent retries on cooldown violations
- **No immediate revocation:** Old certificates are intentionally left valid during rotation to support offline clients and network delays
