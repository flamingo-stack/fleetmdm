Provides Enterprise Edition (EE) overrides for vulnerability-related service methods, extending the base service with EE-specific sort columns and CVSS score enforcement.

## Key Components

### Variables

- **`eeValidVulnSortColumns`** — Defines the full set of valid sort columns available in EE tier: `cve`, `hosts_count`, `created_at`, `cvss_score`, `epss_probability`, `cve_published`.

### Methods

- **`ListVulnerabilities`** — Wraps the base `ListVulnerabilities` call, injecting the EE-extended sort columns and setting `IsEE = true` on the options before delegating.
- **`Vulnerability`** — Wraps the base `Vulnerability` call, forcing `useCVSScores` to `true` regardless of the caller-supplied value, ensuring CVSS scores are always included in EE.

## Usage Example

```go
// EE service automatically applies extended sort options and CVSS enforcement
vulns, pagination, err := eeSvc.ListVulnerabilities(ctx, fleet.VulnListOptions{
    ListOptions: fleet.ListOptions{
        OrderKey: "cvss_score",
        PerPage:  25,
    },
    TeamID: &teamID,
})

// CVSS scores always enabled in EE regardless of useCVSScores argument
vuln, known, err := eeSvc.Vulnerability(ctx, "CVE-2024-1234", &teamID, false)
// useCVSScores is coerced to true internally
```
