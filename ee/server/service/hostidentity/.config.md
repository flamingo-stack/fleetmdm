Initializes and persists the Host Identity CA certificate and private key assets required for SCEP-based host identity in Fleet MDM. On first run, it generates a self-signed 10-year CA cert/key pair and stores them encrypted in the datastore.

## Key Components

- **`initAssets(ds fleet.Datastore) error`** — Checks the datastore for existing `MDMAssetHostIdentityCACert` and `MDMAssetHostIdentityCAKey` assets. If either is missing, generates a new CA cert/key pair using `depot.NewCACertKey` and inserts both as encrypted `MDMConfigAsset` records.

## Usage Example

```go
// Called during server initialization to ensure host identity CA assets exist
if err := initAssets(datastore); err != nil {
    log.Fatalf("failed to initialize host identity assets: %v", err)
}
```

## CA Certificate Properties

The generated CA is configured with the following defaults via `depot.NewCACert`:

| Property | Value |
|---|---|
| Validity | 10 years |
| Common Name | `Fleet Host Identity CA` |
| Organization | `Local Certificate Authority` |
| Country | `US` |

## Notes

- **Idempotent**: If both assets already exist in the datastore, the function is a no-op.
- **Not found tolerance**: A `fleet.IsNotFound` error on the initial asset lookup is treated as a first-run condition, not a failure.
- Assets are PEM-encoded via `certificate.EncodeCertPEM` / `certificate.EncodePrivateKeyPEM` before storage.
