Implements the SCEP (Simple Certificate Enrollment Protocol) service for Fleet host identity enrollment, providing certificate issuance and renewal via HTTP for `fleetd` agents.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `RegisterSCEP` | `func` | Registers the SCEP HTTP handler at `/api/fleet/orbit/host_identity/scep`, wiring together storage, signing middleware, and OpenTelemetry instrumentation |
| `NewSCEPService` | `func` | Constructs a `scepserver.Service` implementation backed by a datastore, CSR signer chain, and logger |
| `service` | `struct` | Core SCEP service implementing `GetCACaps`, `GetCACert`, `PKIOperation`, and `GetNextCACert` |
| `challengeMiddleware` | `func` | CSR signer middleware that validates `ChallengePassword` against Fleet enrollment secrets; skips check for renewal requests |
| `renewalMiddleware` | `func` | CSR signer middleware that authenticates certificate renewal via ECDSA proof-of-possession, then propagates the existing `host_id` to the new certificate |
| `RateLimitError` | `struct` | Sentinel error that produces HTTP 429 responses when the signer returns a `backoff.PermanentError` |
| `getCertValidityDays` | `func` | Returns certificate validity in days, overridable via `FLEET_DEV_HOST_IDENTITY_CERT_VALIDITY_DAYS` for dev/test scenarios |
| `hasRenewalExtension` | `func` | Checks whether a CSR contains the Fleet renewal OID extension |

## Usage Example

```go
// Wire up the SCEP endpoint during server initialization
err := hostidentity.RegisterSCEP(
    mux,
    scepDepot,      // scepdepot.Depot — certificate storage backend
    datastore,      // fleet.Datastore — enrollment secret + cert lookup
    slogLogger,     // *slog.Logger
    &fleetConfig,   // *config.FleetConfig
)
if err != nil {
    log.Fatalf("registering host identity SCEP: %v", err)
}

// Renewal requests embed a Fleet OID extension; the middleware chain handles
// proof-of-possession automatically before forwarding to the base signer.
```

### Middleware chain (innermost → outermost)

```text
base depot signer
  └── challengeMiddleware   (validates enrollment secret on initial enroll)
        └── renewalMiddleware (verifies ECDSA signature on renewal)
```

> **Note:** The SCEP error handler does not forward errors to APM/Sentry. Monitor `PKIOperation` errors via structured logs (`component=http-host-id-scep`).
