Implements a MySQL-backed SCEP certificate depot (`HostIdentitySCEPDepot`) for managing host identity certificates in Fleet MDM, including CA key retrieval, serial number allocation, and certificate storage with revocation and rate-limiting support.

## Key Components

- **`HostIdentitySCEPDepot`** — Core struct implementing the `depot.Depot` interface, backed by a MySQL database and Fleet datastore.
- **`NewHostIdentitySCEPDepot`** — Constructor that validates the DB connection and initializes the depot.
- **`CA`** — Retrieves the host identity CA certificate and RSA private key from Fleet MDM assets.
- **`Serial`** — Allocates a new auto-incremented serial number via the `host_identity_scep_serials` table.
- **`HasCN`** — Stub for common name existence checks (reserved for future renewal logic).
- **`Put`** — Stores a certificate, extracting the ECDSA public key, applying enroll cooldown rate limiting, revoking any existing certs for the host, and inserting the new certificate record.

import (

## Notes

- The `Put` method enforces an enroll cooldown (configured via `Osquery.EnrollCooldown`) to prevent certificate flooding from the same host identifier.
- Existing certificates for a host are revoked on each `Put` call. As noted in the code, a shared challenge may allow a bad actor to revoke a legitimate host's cert if they possess both the challenge and the common name.
