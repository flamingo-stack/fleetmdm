Handles the full lifecycle of software installer management in the Fleet MDM service, including uploading, validating, storing, and managing software packages across teams and platforms (macOS, Windows, iOS/iPadOS).

## Key Components

### Main Functions

- **`UploadSoftwareInstaller`** — Orchestrates the end-to-end upload flow: authorization, label validation, metadata extraction, script normalization, storage, and activity logging.
- **`ValidateSoftwareLabels`** — Validates label include/exclude sets against existing Fleet labels, enforcing mutual exclusivity of label scopes.
- **`preProcessUninstallScript`** — Substitutes `$PACKAGE_ID`/`$UPGRADE_CODE` template variables in uninstall scripts based on package extension and extracted package identifiers.

### Constants

- **`softwareInstallerTokenMaxLength`** — Maximum token length (36, UUID length) for software installer tokens.

## Usage Example

```go
// Upload a new software installer
payload := &fleet.UploadSoftwareInstallerPayload{
    TeamID:          &teamID,
    Filename:        "MyApp.pkg",
    InstallScript:   installScriptContent,
    UninstallScript: uninstallScriptContent,
    AutomaticInstall: true,
    LabelsIncludeAny: []string{"macOS devices"},
}

installer, err := svc.UploadSoftwareInstaller(ctx, payload)
if err != nil {
    // handle error
}

// Validate labels independently
validatedLabels, err := ValidateSoftwareLabels(
    ctx, svc, &teamID,
    []string{"macOS"}, // includeAny
    nil,               // excludeAny
    nil,               // includeAll
)
```

## Notes

- Script content is normalized to Unix line endings (`\n`) before storage to prevent shebang execution failures.
- Script packages (`.sh`, `.ps1`) have uninstall/post-install scripts and pre-install queries cleared automatically.
- iOS (`.ipa`) installers follow a separate metadata and response path via `GetInHouseAppMetadataByTeamAndTitleID`.
- Automatic install policies require a detectable package type (e.g., `.msi`, `.pkg` with bundle ID); `.exe`, `.tar.gz`, and script packages are rejected.
