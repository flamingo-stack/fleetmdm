Core MDM service logic for Apple MDM operations including device management, FileVault, DEP enrollment, and configuration profile management.

## Key Components

### Device Management
- `MDMAppleDeviceLock` — Sends a remote lock command to a specified host
- `MDMAppleEraseDevice` — Sends a remote erase (wipe) command to a specified host
- `MDMListHostConfigurationProfiles` — Lists MDM configuration profiles assigned to a host

### FileVault / Escrow
- `MDMAppleEnableFileVaultAndEscrow` — Creates and stores the FileVault mobileconfig profile using the CA certificate
- `MDMAppleDisableFileVaultAndEscrow` — Removes the FileVault configuration profile by team and identifier

### Setup Configuration
- `UpdateMDMAppleSetup` — Entry point for updating MDM Apple setup options (end-user auth, managed local accounts, manual agent install, etc.)
- `updateAppConfigMDMAppleSetup` — Applies setup changes to the global app config
- `updateMacOSSetupEnableEndUserAuth` — Queues a profile update job and logs an activity when end-user auth is toggled
- `updateMacOSSetupEnableManagedLocalAccount` — Logs an activity when managed local account setting is toggled

### Legacy / Deprecated
- `GetAppleBM` — Deprecated. Returns Apple Business Manager token metadata for the first ABM token. Use `GET /abm_tokens` instead.

## Usage Example

```go
// Lock a device remotely
err := svc.MDMAppleDeviceLock(ctx, hostID)

// Enable FileVault for a team
err := svc.MDMAppleEnableFileVaultAndEscrow(ctx, &teamID)

// Update global MDM Apple setup
err := svc.UpdateMDMAppleSetup(ctx, fleet.MDMAppleSetupPayload{
    EnableEndUserAuthentication: fleet.BoolPtr(true),
    EnableReleaseDeviceManually: fleet.BoolPtr(false),
})
```

> **Note:** `GetAppleBM` is deprecated. For multi-token environments, use the `GET /abm_tokens` API endpoint. See [mdm.go](https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/mdm.go) for full implementation details.
