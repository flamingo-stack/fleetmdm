Handles the macOS/Apple MDM setup experience status for Orbit-enrolled hosts, determining device readiness for release after DEP enrollment by aggregating bootstrap package, configuration profile, account configuration, and software install statuses.

## Key Components

| Function | Description |
|----------|-------------|
| `GetOrbitSetupExperienceStatus` | Main handler that collects all setup experience step statuses and conditionally triggers device release via `DeviceConfigured` MDM command |
| `recordCanceledSetupExperienceSoftwareActivities` | Marks cancelled software installs as failed and emits audit activity events for both software packages and VPP apps |
| `isDeviceReleasedManually` | Reads the `EnableReleaseDeviceManually` MDM flag from either global `AppConfig` or team-level config |
| `isDeviceReadyForRelease` | Pure function that inspects a `SetupExperienceStatusPayload` and returns `false` if any step (bootstrap package, account configuration, profiles, software) is still pending |

## Usage Example

```go
// Called by Orbit agent during the macOS Setup Assistant flow
payload, err := svc.GetOrbitSetupExperienceStatus(
    ctx,
    orbitNodeKey,
    forceRelease,         // true = skip readiness check and release immediately
    resetFailedSetupSteps, // true = re-enqueue cancelled steps after a failed software install
)
if err != nil {
    return err
}

// Orbit uses the payload to render progress in the Setup Experience UI
fmt.Println(payload.BootstrapPackage.Status)
fmt.Println(payload.ConfigurationProfiles)
fmt.Println(payload.Software)
```

## Notes

- **Windows/Linux** hosts return only `Software` status; MDM-specific steps (bootstrap package, profiles, account configuration) are macOS-only.
- **DDM/Declaration profiles** and **user-scoped profiles** are explicitly excluded from the readiness check — declarations cannot be processed while a device awaits release, and user-scoped profiles are deferred until after user account creation.
- The `forceRelease` flag logs a warning and bypasses `isDeviceReadyForRelease`, intended for operator-initiated overrides.
- Device release is triggered by enqueuing an MDM `DeviceConfigured` command via `mdmAppleCommander`.
