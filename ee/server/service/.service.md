Defines the enterprise edition (EE) `Service` struct and its constructor, wrapping the base Fleet service with premium features including MDM, SSO, DEP, software management, and certificate services.

## Key Components

### `Service` struct
Embeds `fleet.Service` and extends it with enterprise-only dependencies:

| Field | Purpose |
|---|---|
| `ds` | Datastore access |
| `authz` | Authorization enforcement |
| `depStorage` / `depService` | Apple DEP enrollment |
| `mdmAppleCommander` | MDM command issuer |
| `ssoSessionStore` | SSO session management |
| `profileMatcher` | MDM profile assignment |
| `softwareInstallStore` | Software installer storage |
| `bootstrapPackageStore` | MDM bootstrap packages |
| `digiCertService` / `scepConfigService` / `estService` | Certificate services |
| `androidModule` | Android MDM service |
| `distributedLock` / `keyValueStore` | Distributed coordination |

### `NewService`
Constructor that initializes the EE service, creates an `authz.Authorizer`, wires all dependencies, and registers enterprise method overrides via `SetEnterpriseOverrides`.

## Usage Example

```go
eeSvc, err := service.NewService(
    baseSvc,
    ds,
    logger,
    fleetConfig,
    mailService,
    clock.C,
    depStorage,
    mdmAppleCommander,
    ssoStore,
    profileMatcher,
    softwareInstallStore,
    bootstrapPackageStore,
    softwareTitleIconStore,
    distributedLock,
    keyValueStore,
    scepConfigService,
    digiCertService,
    androidService,
    estService,
)
if err != nil {
    log.Fatal(err)
}
```

> **Note:** Enterprise overrides (e.g., `HostFeatures`, `MDMAppleSyncDEPProfiles`, `SetupExperienceNextStep`) are registered automatically during construction and take precedence over the base service implementations.
