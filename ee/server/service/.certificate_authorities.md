Service layer for managing Certificate Authority (CA) integrations in Fleet MDM, handling CRUD operations and validation for multiple CA types including DigiCert, Hydrant, NDES SCEP, custom SCEP/EST proxies, and Smallstep.

## Key Components

- **`GetCertificateAuthority`** — Retrieves a single CA by ID with read authorization check.
- **`ListCertificateAuthorities`** — Returns a summary list of all configured CAs.
- **`NewCertificateAuthority`** — Creates a new CA entry after validating the payload and dispatching type-specific validation; records an activity log entry on success.
- **`validatePayload`** — Ensures exactly one CA type is specified and that the server private key is configured.
- **`validateDigicert`** / **`validateHydrant`** / **`validateEST`** / **`validateNDESSCEPProxy`** / **`validateCustomSCEPProxy`** / **`validateSmallstepSCEPProxy`** — Per-provider validation helpers covering URL format, required credentials, and Fleet variable allowlists.
- **`validateCAName`** — Enforces alphanumeric naming rules, blocks reserved name `"NDES"`, and limits length to 255 characters.
- **`validateDigicertCACN`** / **`validateDigicertSeatID`** / **`validateDigicertUserPrincipalNames`** — Field-level validators for DigiCert-specific fields, allowing only approved Fleet template variables (`FLEET_VAR_HOST_END_USER_EMAIL_IDP`, `FLEET_VAR_HOST_HARDWARE_SERIAL`, `FLEET_VAR_HOST_PLATFORM`).

## Usage Example

```go
// Create a new DigiCert CA
ca, err := svc.NewCertificateAuthority(ctx, fleet.CertificateAuthorityPayload{
    DigiCert: &fleet.DigiCertCA{
        Name:                         "prod_digicert",
        URL:                          "https://one.digicert.com",
        APIToken:                     "your-api-token",
        ProfileID:                    "your-profile-guid",
        CertificateCommonName:        "$FLEET_VAR_HOST_HARDWARE_SERIAL",
        CertificateSeatID:            "$FLEET_VAR_HOST_END_USER_EMAIL_IDP",
        CertificateUserPrincipalNames: []string{},
    },
})

// List all configured CAs
summaries, err := svc.ListCertificateAuthorities(ctx)
```

## Notes

- All methods enforce authorization via `svc.authz.Authorize` before any datastore access.
- Conflict errors on creation surface user-friendly messages identifying the duplicate name and CA type.
- CA names must match `^\w+$` (letters, digits, underscores only) and cannot exceed 255 characters.
