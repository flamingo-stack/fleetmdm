Implements the SCIM 2.0 `UserHandler` for Fleet MDM, providing CRUD operations and attribute mapping for user provisioning via the SCIM protocol (RFC 7643/7644).

## Key Components

- **`UserHandler`** — Core struct implementing `scim.ResourceHandler`, backed by a Fleet datastore, activity logger, and structured logger.
- **`NewUserHandler`** — Constructor returning a `scim.ResourceHandler` for dependency injection.
- **`Create`** — Creates a SCIM user, with special handling for reactivating previously deactivated users.
- **`Get`** — Retrieves a single SCIM user by ID.
- **`createUserFromAttributes`** — Parses and validates SCIM resource attributes into a `fleet.ScimUser`, including emails and enterprise extension attributes (e.g., `department`).
- **`createUserResource`** — Converts a `fleet.ScimUser` back into a `scim.Resource` for SCIM responses, including group memberships and enterprise extension attributes.
- **`getExtensionEnterpriseUserAttributes`** — Extracts `urn:ietf:params:scim:schemas:extension:enterprise:2.0:User` attributes (currently `department`).
- **Attribute helpers** — Generic utilities (`getRequiredResource`, `getOptionalResource`, `getComplexResource`, `getComplexResourceSlice`) for safe, typed extraction from `scim.ResourceAttributes`.

## Usage Example

```go
handler := scim.NewUserHandler(ds, newActivity, logger)

// Register with your SCIM router
resourceTypes := []scim.ResourceType{
    {
        Name:        "User",
        Endpoint:    "/Users",
        Description: optional.NewString("User accounts"),
        Schema:      schema.CoreUserSchema(),
        Handler:     handler,
    },
}
```

## Notes

- `familyName` and `givenName` are **required** — empty values return `ScimErrorInvalidValue`.
- `userName` uniqueness is enforced; duplicate creates return `ScimErrorUniqueness` unless the existing user is deactivated and the incoming request sets `active=true`.
- Email values are normalized via `normalizeEmail` per RFC 5321.
- SCIM IDs are string-encoded `uint` values internally (see `extractUserIDFromValue` / `scimUserID`).
