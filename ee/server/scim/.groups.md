This file implements the SCIM `GroupHandler`, providing full CRUD and Patch operations for managing SCIM groups (used by identity providers like Microsoft Entra ID) within the Fleet MDM datastore.

## Key Components

- **`GroupHandler`** — Struct implementing `scim.ResourceHandler` for group resources, backed by `fleet.Datastore` and a structured logger.
- **`NewGroupHandler`** — Constructor returning a `scim.ResourceHandler` interface.
- **`Create`** — Creates a new SCIM group, enforcing `displayName` uniqueness (Entra ID compliance).
- **`Get`** — Fetches a single group by its SCIM ID (format: `group-<uint>`).
- **`GetAll`** — Lists groups with pagination, optional `displayName` filter, and `excludedAttributes` support.
- **`Replace`** — Fully replaces a group's attributes while validating `displayName` uniqueness.
- **`Delete`** — Removes a group by SCIM ID.
- **`Patch`** — Applies partial updates (`add`, `replace`, `remove`) to `displayName`, `externalId`, and `members`.
- **`createGroupFromAttributes`** — Maps raw SCIM attributes to a `fleet.ScimGroup` struct, parsing member user IDs.
- **`createGroupResource`** — Converts a `fleet.ScimGroup` to a `scim.Resource` response object.
- **`areMembersExcluded`** — Checks the `excludedAttributes` query parameter to skip member hydration.

## Usage Example

```go
ds := myFleetDatastore()
logger := slog.Default()

handler := scim.NewGroupHandler(ds, logger)

// Register with the SCIM server
resourceTypes := []scim.ResourceType{
    {
        Name:        "Group",
        Endpoint:    "/Groups",
        Description: optional.NewString("Group resource"),
        Schema:      schema.CoreEnterpriseGroup(),
        Handler:     handler,
    },
}
```

## Notes

- Group SCIM IDs use the prefix format `group-<uint>` to ensure uniqueness across all resource types.
- `displayName` uniqueness is enforced beyond the SCIM spec to satisfy Microsoft Entra ID requirements.
- Pagination follows RFC 7644 (1-indexed `startIndex`), capped at `maxResults`.
