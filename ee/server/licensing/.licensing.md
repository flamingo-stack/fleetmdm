Handles parsing, validation, and loading of Fleet license keys using ECDSA-signed JWTs embedded with license metadata such as tier, device count, and expiration.

## Key Components

- **`loadPublicKey()`** — Decodes and parses the embedded `pubkey.pem` ECDSA public key used to verify license JWT signatures.
- **`LoadLicense(licenseKey string)`** — Entry point for license loading. Returns a free-tier `LicenseInfo` for empty keys; otherwise parses, validates, and returns the full license. Gracefully handles expired tokens by allowing validation to continue.
- **`licenseClaims`** — JWT claims struct extending `jwt.StandardClaims` with Fleet-specific fields: `Tier`, `Devices`, `Note`, and `AllowDisableTelemetry`.
- **`validate(token *jwt.Token)`** — Enforces algorithm (`ES256`), issuer (`Fleet Device Management Inc.`), and required claims before returning a `fleet.LicenseInfo`.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/ee/server/licensing"

// Load and validate a license key at startup
license, err := licensing.LoadLicense(os.Getenv("FLEET_LICENSE_KEY"))
if err != nil {
    log.Fatalf("invalid license: %v", err)
}

// license.Tier == "free" if no key provided
// license.Tier == "premium" if a valid key is present
fmt.Printf("Tier: %s, Devices: %d, Expires: %s\n",
    license.Tier,
    license.DeviceCount,
    license.Expiration.Format(time.RFC3339),
)
```

## Notes

- The public key is embedded at compile time via `//go:embed pubkey.pem`; no runtime file access is needed.
- Expired tokens are **not** rejected — expiry is noted in `LicenseInfo.Expiration` but does not block startup.
- `ForceUpgrade()` is called post-validation to convert legacy `basic` tier values to `premium` for backwards compatibility.
