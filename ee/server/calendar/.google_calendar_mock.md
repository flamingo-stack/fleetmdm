In-memory mock implementation of the Google Calendar API for testing, simulating real API behavior with configurable latency and thread-safe state management.

## Key Components

### Types

- **`GoogleCalendarMockAPI`** — Mock struct implementing the Google Calendar API interface with an `slog` logger
- **`channel`** — Internal struct storing `channelID` and `resourceID` for watch channel tracking

### Package-Level State

| Variable | Description |
|---|---|
| `mockEvents` | Thread-safe map of event ID → `*calendar.Event` |
| `mockChannels` | Slice of active watch channels |
| `mu` | `sync.Mutex` guarding shared state |
| `id` | Auto-incrementing event ID counter |
| `latency` | Simulated API delay (`200ms`) |

### API Methods

| Method | Behavior |
|---|---|
| `Configure` | Initializes the logger; accepts but ignores credentials |
| `GetSetting` | Returns `America/Chicago` for `timezone`; errors on others |
| `CreateEvent` | Assigns incremental ID, stores in `mockEvents` |
| `UpdateEvent` | Overwrites existing event in `mockEvents` |
| `GetEvent` | Returns event or `404` `googleapi.Error` if missing |
| `ListEvents` | Returns empty `calendar.Events` |
| `DeleteEvent` | Removes event from `mockEvents` |
| `Watch` | Registers a channel with a UUID `resourceID` |
| `Stop` | Removes matching channel or returns error |

### Test Helpers

- **`ListGoogleMockEvents()`** — Returns the raw events map
- **`ClearMockEvents()`** — Resets events map (thread-safe)
- **`MockChannelsCount()`** — Returns active channel count
- **`ClearMockChannels()`** — Resets channels slice (thread-safe)
- **`SetMockEventsToNow()`** — Shifts all event start/end times to the current time (30-minute window)

## Usage Example

```go
// In a test file
func TestCalendarIntegration(t *testing.T) {
    ClearMockEvents()
    ClearMockChannels()

    api := &GoogleCalendarMockAPI{}
    _ = api.Configure(context.Background(), "", "", "user@example.com", "")

    event, _ := api.CreateEvent(&calendar.Event{
        Summary: "Scheduled Maintenance",
        Start:   &calendar.EventDateTime{DateTime: time.Now().Format(time.RFC3339)},
        End:     &calendar.EventDateTime{DateTime: time.Now().Add(time.Hour).Format(time.RFC3339)},
    })

    fetched, _ := api.GetEvent(event.Id, "")
    fmt.Println(fetched.Summary) // "Scheduled Maintenance"

    // Shift all events to now for time-sensitive tests
    SetMockEventsToNow()
    
    // Cleanup
    ClearMockEvents()
}
```

> **Note:** All methods simulate a `200ms` network latency via `time.Sleep`. Use `ClearMockEvents()` and `ClearMockChannels()` in `TestMain` or `t.Cleanup` to prevent state leakage between tests.
