Provides a Google Calendar integration for Fleet MDM, implementing the `UserCalendar` interface to manage maintenance window events via the Google Calendar API, including event creation, updates, deletion, and push notification webhooks.

## Key Components

- **`GoogleCalendar`** – High-level struct implementing `UserCalendar`; handles timezone management, event scheduling (9–17h window, 30-min slots), and retry logic.
- **`GoogleCalendarAPI`** – Low-level interface abstracting Calendar API operations: `Configure`, `GetSetting`, `ListEvents`, `CreateEvent`, `UpdateEvent`, `GetEvent`, `DeleteEvent`, `Watch`, `Stop`.
- **`GoogleCalendarLowLevelAPI`** – Production implementation of `GoogleCalendarAPI` using JWT service-account impersonation and exponential backoff (up to 10 min).
- **`GoogleCalendarConfig`** – Configuration struct wiring together context, Fleet integration credentials, logger, server URL, and an optional custom API implementation.
- **`eventDetails`** – JSON-serializable struct storing event ID, ETag, webhook channel/resource IDs, and body tag for roundtrip state tracking.
- **`NewGoogleCalendar`** – Constructor that selects the API implementation: production, load-test (`GoogleCalendarLoadAPI`), or in-memory mock (`GoogleCalendarMockAPI`) based on `client_email`.
- **`adjustEmail`** – Strips plus-addressing (e.g. `john+test@example.com` → `john@example.com`) when `FLEET_GOOGLE_CALENDAR_PLUS_ADDRESSING=1`, enabling load-testing against a single account.

## Usage Example

```go
cfg := &calendar.GoogleCalendarConfig{
    Context: ctx,
    IntegrationConfig: &fleet.GoogleCalendarIntegration{
        ApiKey: fleet.GoogleCalendarAPIKey{
            Values: map[string]string{
                fleet.GoogleCalendarEmail:      "svc@project.iam.gserviceaccount.com",
                fleet.GoogleCalendarPrivateKey: "-----BEGIN RSA PRIVATE KEY-----\n...",
            },
        },
    },
    Logger:    slog.Default(),
    ServerURL: "https://fleet.example.com",
}

gc := calendar.NewGoogleCalendar(cfg)

// Impersonate a user and schedule a maintenance event
if err := gc.Configure("user@example.com"); err != nil {
    log.Fatal(err)
}
```

**Testing with mock:**

```go
cfg.IntegrationConfig.ApiKey.Values[fleet.GoogleCalendarEmail] = calendar.MockEmail
gc := calendar.NewGoogleCalendar(cfg) // uses GoogleCalendarMockAPI
```
