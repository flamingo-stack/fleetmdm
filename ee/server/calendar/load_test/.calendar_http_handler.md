A test-only HTTP server that simulates a Google Calendar API backend using SQLite, intended for integration testing of Fleet's calendar event scheduling features.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Configure(dbPath string)` | Initializes the SQLite database and returns an `http.Handler` wired with all calendar routes |
| `Close()` | Closes the SQLite database connection |
| `getSetting` | `GET /settings` — returns a deterministic timezone for a given email |
| `getEvent` | `GET /events?id=` — fetches a single calendar event by ID |
| `getEvents` | `GET /events/list` — lists events for an email within a time range |
| `addEvent` | `POST /events/add?email=` — inserts a new event, returns it with assigned ID and ETag |
| `deleteEvent` | `DELETE /events/delete?id=` — removes an event by ID |
| `getTimezone` | Derives a consistent timezone from an email address via FNV-32a hash |
| `computeETag` | Generates an MD5-based ETag from event fields |
| `parseDateTime` | Parses RFC3339 date-time strings, respecting optional timezone overrides |
| `initializeSchema` | Creates the `events` SQLite table if it does not exist |

## Usage Example

```go
handler, err := calendartest.Configure("/tmp/test-calendar.db")
if err != nil {
    log.Fatal(err)
}
defer calendartest.Close()

server := httptest.NewServer(handler)
defer server.Close()

// Create an event
resp, err := http.Post(
    server.URL+"/events/add?email=user@example.com",
    "application/json",
    strings.NewReader(`{"summary":"OS Update","start":{"dateTime":"2024-01-15T09:00:00-05:00"},"end":{"dateTime":"2024-01-15T10:00:00-05:00"}}`),
)

// List events in a window
resp, err = http.Get(server.URL + "/events/list?email=user@example.com&timemin=2024-01-15T00:00:00Z&timemax=2024-01-16T00:00:00Z")
```

> **Note:** This package (`calendartest`) is excluded from production builds. It does not support all-day events. Timezones are assigned deterministically by hashing the user's email address against a fixed list of 10 zones.
