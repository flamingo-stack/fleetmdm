A mock/stub implementation of the Google Calendar API interface designed for load testing, routing all calendar operations through a configurable HTTP backend instead of the real Google Calendar service.

## Key Components

### `GoogleCalendarLoadAPI` struct

A load-testing client with the following fields:

| Field | Description |
|---|---|
| `Logger` | Structured logger (`slog.Logger`) |
| `baseUrl` | Base URL of the mock backend (passed as `privateKey` in `Configure`) |
| `userToImpersonate` | Email address appended as `?email=` query param |
| `ctx` | Request context |
| `client` | HTTP client (`fleethttp.NewClient()`) |
| `serverURL` | Fleet server URL |

### Methods

| Method | HTTP | Endpoint | Notes |
|---|---|---|---|
| `Configure` | — | — | Initializes the client; `privateKey` is repurposed as `baseUrl` |
| `GetSetting` | `GET` | `/settings` | Fetches a named calendar setting |
| `CreateEvent` | `POST` | `/events/add` | Expects `201 Created` |
| `UpdateEvent` | — | — | **Not implemented** — always returns an error |
| `GetEvent` | `GET` | `/events` | Returns `googleapi.Error{404}` on not found |
| `ListEvents` | `GET` | `/events/list` | Filters by `timemin`/`timemax` |
| `DeleteEvent` | `DELETE` | `/events/delete` | Returns `googleapi.Error{410}` on `410 Gone` |
| `Watch` | — | — | Stub; always returns `"resourceID"` |
| `Stop` | — | — | Stub; always returns `nil` |

## Usage Example

```go
api := &calendar.GoogleCalendarLoadAPI{}
err := api.Configure(
    ctx,
    "",                              // clientEmail (unused)
    "http://localhost:8080",         // privateKey repurposed as baseUrl
    "user@example.com",              // userToImpersonate
    "https://fleet.example.com",     // serverURL
)
if err != nil {
    log.Fatal(err)
}

events, err := api.ListEvents("2024-01-01T00:00:00Z", "2024-01-31T23:59:59Z")
```

> **Note:** `UpdateEvent` and `Watch`/`Stop` are stubs. Wire your load-test backend to the endpoints under `baseUrl` to simulate real calendar responses.
