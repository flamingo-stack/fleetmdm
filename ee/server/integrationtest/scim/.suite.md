Provides test suite setup for SCIM integration tests, initializing a MySQL-backed Fleet service with premium licensing and SCIM enabled.

## Key Components

- **`Suite`** — Embeds `integrationtest.BaseSuite`, inheriting shared test infrastructure (datastore, server, users, config).
- **`SetUpSuite`** — Bootstraps the full test environment including MySQL datastore, Fleet service, HTTP test server, and an authenticated admin token.

## Usage Example

```go
func TestSCIMIntegration(t *testing.T) {
    s := scim.SetUpSuite(t, "TestSCIMIntegration")
    // s.Server, s.DS, s.Token are ready to use
    _ = s.Token
}
```

> **Note:** `t.Parallel()` is invoked internally when MySQL datastore options are processed — no need to call it manually in your test.

## Configuration Details

| Option | Value |
|---|---|
| License Tier | `fleet.TierPremium` |
| SCIM Enabled | `true` |
| Logger | `slog` text handler → `os.Stdout` |
