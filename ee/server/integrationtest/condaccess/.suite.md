Defines the test suite setup for conditional access integration tests, initializing a full Fleet server stack with MySQL, Redis, Premium licensing, and a SCEP depot for conditional access.

## Key Components

- **`Suite`** — Embeds `integrationtest.BaseSuite`, inheriting standard test helpers (token management, HTTP client, etc.)
- **`SetUpSuite`** — Convenience wrapper that calls `SetUpSuiteWithConfig` with no config overrides
- **`SetUpSuiteWithConfig`** — Full suite initializer; accepts an optional `configModifier` func to mutate `FleetConfig` before server startup

## Usage Example

```go
func TestMyConditionalAccess(t *testing.T) {
    s := condaccess.SetUpSuite(t, "TestMyConditionalAccess")

    // Use s.BaseSuite helpers
    resp := s.DoRaw("GET", "/api/v1/fleet/mdm/microsoft/enroll", nil, http.StatusOK)
    defer resp.Body.Close()
}

// With custom config overrides:
func TestWithConfig(t *testing.T) {
    s := condaccess.SetUpSuiteWithConfig(t, "TestWithConfig", func(cfg *config.FleetConfig) {
        cfg.MDM.MicrosoftWSTEPIdentityCert = "/path/to/cert"
    })
    _ = s
}
```

## Notes

- Requires a running MySQL instance; `t.Parallel()` is invoked internally during datastore setup
- Redis is provisioned via `redistest.SetupRedis` (non-cluster, non-TLS mode)
- `ConditionalAccess.SCEPStorage` is wired to a `NewConditionalAccessSCEPDepot` backed by the MySQL datastore
- Admin token is auto-fetched and stored in `s.BaseSuite.Token` for immediate use in tests
