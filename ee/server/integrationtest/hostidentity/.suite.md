Test suite setup file for the `hostidentity` integration test package, providing helpers to initialize a full Fleet server stack with host identity (SCEP-based) support for non-Windows platforms.

## Key Components

- **`enrollOrbitResponse`** — Response struct for orbit enrollment API calls, capturing the node key and any error.
- **`orbitConfigRequest`** / **`osqueryConfigRequest`** — Request structs used when hitting orbit and osquery config endpoints in tests.
- **`Suite`** — Embeds `integrationtest.BaseSuite`, inheriting shared test server state (datastore, Fleet config, users, server).
- **`SetUpSuite`** — Convenience wrapper around `SetUpSuiteWithConfig` with no config overrides.
- **`SetUpSuiteWithConfig`** — Full suite initializer: spins up MySQL + Redis, creates a Fleet service with a Premium license, initializes the SCEP depot for host identity, and starts a test HTTP server with optional config mutations.

## Usage Example

```go
func TestMyHostIdentityFlow(t *testing.T) {
    s := hostidentity.SetUpSuite(t, "TestMyHostIdentityFlow", true)
    // s.Server, s.DS, s.Users, s.Token are ready to use

    // With config overrides:
    s2 := hostidentity.SetUpSuiteWithConfig(t, "TestCustomConfig", false,
        func(cfg *config.FleetConfig) {
            cfg.MDM.AppleSCEPSignerValidityDays = 365
        },
    )
    _ = s2
}
```

## Notes

- **Build constraint**: excluded on Windows (`//go:build !windows`) because the TPM simulator requires CGO, which breaks linting on that platform.
- The suite always uses a **Premium license tier**, making it suitable for testing enterprise-only host identity features.
- `SetUpServerURL` is called automatically to configure the datastore with the test server's URL, so enrolled hosts resolve correctly.
