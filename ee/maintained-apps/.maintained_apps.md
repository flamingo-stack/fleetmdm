Defines core types and utilities for the Fleet Maintained Apps (FMA) system, which manages app metadata ingestion, manifest structures, and script references across multiple platforms.

## Key Components

### Types

- **`Ingester`** — Function type for platform-specific app metadata ingestion. Accepts a context, logger, inputs path, and optional slug filter; returns a slice of `FMAManifestApp` entries.
- **`FMAManifestApp`** — Core manifest entry representing a single app version, including installer URL, install/uninstall scripts, SHA256 checksum, platform queries, and categories.
- **`FMAManifestFile`** — Wraps versioned app manifests with a shared script `Refs` map (script hash → script content).
- **`FMAListFileApp`** / **`FMAListFile`** — Lightweight catalog structures used for listing available maintained apps.
- **`FMAQueries`** — SQL query pair used to detect if an app exists and whether it is patched.

### Methods on `FMAManifestApp`

| Method | Description |
|---|---|
| `Platform()` | Extracts the platform segment from a `slug` (format: `appname/platform`) |
| `SlugAppName()` | Extracts the app name segment from a slug |
| `IsEmpty()` | Returns `true` if all serializable fields are zero values |

### Functions

- **`GetScriptRef(script string) string`** — Generates an 8-character SHA-256 hex prefix used as a deterministic short reference key for install/uninstall scripts.

### Constants

- **`OutputPath`** — Canonical output directory: `ee/maintained-apps/outputs`

## Usage Example

```go
ref := maintained_apps.GetScriptRef(installScriptContent)
// ref == "a1b2c3d4" (first 8 chars of SHA-256)

app := &maintained_apps.FMAManifestApp{
    Slug:    "google-chrome/darwin",
    Version: "124.0.0",
}

fmt.Println(app.Platform())    // "darwin"
fmt.Println(app.SlugAppName()) // "google-chrome"
fmt.Println(app.IsEmpty())     // false
```
