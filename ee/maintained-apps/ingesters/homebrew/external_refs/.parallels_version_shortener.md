Transforms a Homebrew-formatted Parallels Desktop version string into the shorter format that matches osquery's `bundle_short_version` field.

## Key Components

- **`ParallelsVersionShortener(app *maintained_apps.FMAManifestApp) (*maintained_apps.FMAManifestApp, error)`** — Strips the build number suffix (everything after the `-`) from a Homebrew version string, leaving only the semantic version segment.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "26.1.2-57293",
}

result, err := ParallelsVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(result.Version) // "26.1.2"
```

Returns an error if the version string is empty or cannot be parsed.

## Version Format Reference

| Source | Format | Example |
|--------|--------|---------|
| Homebrew | `MAJOR.MINOR.PATCH-BUILD` | `26.1.2-57293` |
| osquery `bundle_short_version` | `MAJOR.MINOR.PATCH` | `26.1.2` |
| osquery `bundle_version` | `BUILD` | `57293` |
