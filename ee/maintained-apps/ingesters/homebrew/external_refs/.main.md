Entrypoint for the `externalrefs` package that registers and applies per-app manifest enrichment functions for Fleet's macOS Maintained Apps (FMA) pipeline.

## Key Components

- **`Funcs`** — Registry mapping app slugs (e.g., `"google-chrome/darwin"`) to ordered slices of transformer functions. Each transformer accepts and returns an `*FMAManifestApp`, allowing multiple enrichers to chain on a single app entry.
- **`ChromePKGInstaller`** / **`OnePasswordPKGInstaller`** / **`SlackPKGInstaller`** / **`ZoomPKGInstaller`** / **`LogiTunePKGInstaller`** / **`WhatsAppInstallerURL`** — Inline PKG installer overrides that replace Homebrew's default DMG URL with a vendor-supplied PKG URL and set `SHA256` to `"no_check"` (since the binary differs from Homebrew's artifact).
- **`EnrichManifest(app *FMAManifestApp)`** — Iterates the enrichers registered for `app.Slug`, applies them in order, and prints to stdout on error without halting the pipeline.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Slug:             "google-chrome/darwin",
    UniqueIdentifier: "com.google.Chrome",
    InstallerURL:     "https://homebrew-default-dmg.example.com/GoogleChrome.dmg",
    SHA256:           "abc123...",
}

// Apply all registered enrichers for this slug
externalrefs.EnrichManifest(app)

// app.InstallerURL is now the official PKG URL
// app.SHA256 is now "no_check"
fmt.Println(app.InstallerURL)
// https://dl.google.com/dl/chrome/mac/universal/stable/gcem/GoogleChrome.pkg
```

> Additional transformer functions (version shorteners, version transformers, etc.) referenced in `Funcs` — such as `MicrosoftVersionFromReleaseNotes`, `BraveVersionTransformer`, and `WarpDirectInstaller` — are implemented in sibling files within the `externalrefs` package.
