Strips the git commit hash suffix from GitHub Desktop version strings to align Homebrew-reported versions with what osquery returns.

## Key Components

- **`GitHubDesktopVersionShortener`** — Transformer function that accepts an `*FMAManifestApp`, splits the version string on `-`, and retains only the semantic version prefix (e.g., `"3.5.4-9dfb8d8d"` → `"3.5.4"`). Returns an error if no valid prefix is found.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "3.5.4-9dfb8d8d",
}

result, err := externalrefs.GitHubDesktopVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(result.Version) // "3.5.4"
```

## Notes

- Part of the `externalrefs` package, which houses version-normalization transformers for Fleet Maintained Apps (FMA).
- The transformation is necessary because Homebrew appends a short commit hash (`-<hash>`) to GitHub Desktop versions, while osquery reports only the bare semantic version — without normalization, version comparisons between the two sources would fail.
- Returns the original `app` pointer (mutated in-place) alongside any error, consistent with the transformer interface pattern used across the package.
