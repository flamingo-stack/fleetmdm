Strips the build/revision suffix from 8x8 Work app version strings by truncating everything after the first `-` character (e.g., `"8.28.2-3"` → `"8.28.2"`).

## Key Components

- **`EightXEightWorkVersionShortener`** — Transform function that accepts an `FMAManifestApp` pointer, shortens its `Version` field, and returns the modified app. If no `-` is present, the version is left unchanged.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "8.28.2-3",
}

shortened, err := externalrefs.EightXEightWorkVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(shortened.Version) // "8.28.2"
```

## Notes

- Operates **in-place** on the passed pointer; the returned `*FMAManifestApp` is the same object.
- Only the **first** `-` delimiter is used as the split boundary — version segments like `8.28.2-3-patch` would still yield `8.28.2`.
- The error return is reserved for future use; the function currently always returns `nil`.
