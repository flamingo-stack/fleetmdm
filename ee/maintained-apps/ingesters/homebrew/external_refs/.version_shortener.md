Provides version string transformation utilities for Fleet Maintained App (FMA) manifests, normalizing Homebrew version strings to match what macOS reports as `bundle_short_version`, preventing false "Update available" detection in patch policies.

## Key Components

### `makeVersionShortener(keepSegments int)`
Factory function returning a manifest enricher that truncates dot-separated version strings to the first `keepSegments` segments. Returns an error if the app version is empty.

### Standalone Transformers
- **`SublimeVersionTransformer`** — Prepends `"Build "` (e.g. `"4200"` → `"Build 4200"`)
- **`MySQLWorkbenchVersionTransformer`** — Appends `".CE"` (e.g. `"8.0.46"` → `"8.0.46.CE"`)
- **`LensVersionTransformer`** — Appends `"-latest"` (e.g. `"2026.3.251250"` → `"2026.3.251250-latest"`)
- **`SonosVersionTransformer`** — Replaces `-` with `.` (e.g. `"90.0-77070"` → `"90.0.77070"`)
- **`PdVersionTransformer`** — Replaces `-` with `.` (e.g. `"0.56-3"` → `"0.56.3"`)

## Usage Example

```go
// Using a pre-built shortener
app := &maintained_apps.FMAManifestApp{
    Slug:    "opera",
    Version: "129.0.5823.28",
}
transformed, err := OperaVersionShortener(app)
// transformed.Version == "129.0"

// Using a standalone transformer
app := &maintained_apps.FMAManifestApp{
    Slug:    "sublime-text",
    Version: "4200",
}
transformed, err := SublimeVersionTransformer(app)
// transformed.Version == "Build 4200"

// Creating a custom shortener
threeSegment := makeVersionShortener(3)
app.Version = "1.2.3.4.5"
transformed, err := threeSegment(app)
// transformed.Version == "1.2.3"
```
