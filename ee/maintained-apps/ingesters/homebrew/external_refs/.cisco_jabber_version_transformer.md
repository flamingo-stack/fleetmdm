Transforms the version field of a Cisco Jabber `FMAManifestApp` manifest entry to match the version string reported by osquery, overriding the build number returned by Homebrew.

## Key Components

- **`CiscoJabberVersionTransformer`** — Accepts a pointer to `FMAManifestApp` and sets `app.Version` to `"15.2.1"`, resolving the mismatch between Homebrew's build number format (e.g., `"20251027035315"`) and the human-readable version string osquery reports (e.g., `"15.2.1"`). Returns the modified app and a `nil` error.

## Usage Example

```go
package externalrefs

import (
    maintained_apps "github.com/fleetdm/fleet/v4/ee/maintained-apps"
)

app := &maintained_apps.FMAManifestApp{
    Version: "20251027035315", // raw Homebrew build number
}

transformed, err := CiscoJabberVersionTransformer(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(transformed.Version) // Output: 15.2.1
```

## Notes

- This transformer exists because Homebrew reports a build number for Cisco Jabber rather than the semantic app version, which would cause version mismatches when Fleet compares installed app versions against the maintained-apps manifest.
- The hardcoded version `"15.2.1"` must be manually updated whenever the canonical Cisco Jabber version changes.
- See related transformer pattern in the [`externalrefs`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/maintained-apps/apps/externalrefs) package for other apps that require similar overrides.
