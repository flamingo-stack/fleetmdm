Provides a custom installer override for the Warp terminal app, replacing the Homebrew-sourced URL with a direct CDN download link and normalizing the version string format.

## Key Components

- **`WarpDirectInstaller`** — Mutates an `FMAManifestApp` manifest entry for Warp by:
  - Constructing a direct CDN installer URL (`https://releases.warp.dev/stable/v<version>/Warp.dmg`) to bypass the Homebrew endpoint's `User-Agent` requirement.
  - Setting `SHA256` to `"no_check"` since the CDN URL is the same binary as the Homebrew redirect target.
  - Stripping the `.stable_` segment from the version string to match the version reported by the installed app bundle (e.g., `0.2026.02.25.08.24.stable_01` → `0.2026.02.25.08.24.01`).

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version:      "0.2026.02.25.08.24.stable_01",
    InstallerURL: "https://formulae.brew.sh/...",
}

patched, err := externalrefs.WarpDirectInstaller(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(patched.InstallerURL)
// https://releases.warp.dev/stable/v0.2026.02.25.08.24.stable_01/Warp.dmg

fmt.Println(patched.Version)
// 0.2026.02.25.08.24.01
```

## Notes

- The `SHA256` field is set to `"no_check"` rather than a computed hash, relying on the CDN URL being the same artifact that Homebrew serves.
- This function is part of the `externalrefs` package, which handles app-specific manifest overrides for Fleet's maintained-apps pipeline.
