Parses and shortens Omnissa Horizon Client version strings from their full Homebrew format into a simplified semantic version.

## Key Components

- **`OmnissaHorizonVersionShortener`** — Takes an `FMAManifestApp` and extracts the middle segment of a hyphen-delimited version string (e.g., `XXXX-0.00.0-XXXXXXXXXXX` → `0.00.0`). Returns an error if the version string does not contain exactly three hyphen-separated parts.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "2406-8.13.0-23149143",
}

shortened, err := externalrefs.OmnissaHorizonVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(shortened.Version) // Output: 8.13.0
```

## Notes

- Mutates the `Version` field of the passed `app` directly.
- Expects exactly three dash-separated segments; any other format returns an error without modifying the version.
- Part of the `externalrefs` package used during Fleet Maintained Apps manifest processing.
