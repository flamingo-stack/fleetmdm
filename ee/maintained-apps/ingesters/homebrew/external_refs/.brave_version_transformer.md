Transforms Brave Browser version strings from Homebrew's format into the standard four-part release version format used by Fleet's maintained apps manifest.

## Key Components

### `BraveVersionTransformer`

```text
func BraveVersionTransformer(app *maintained_apps.FMAManifestApp) (*maintained_apps.FMAManifestApp, error)
```

Accepts an `FMAManifestApp` and rewrites its `Version` field by applying two transformations:

1. **Strips the trailing `.0`** — Homebrew versions end with `.0` (e.g., `1.79.123.0` → `1.79.123`).
2. **Prepends a derived major version** — Adds 58 to the second segment and prepends it as the new first segment (e.g., `1.79.123` → `137.1.79.123`).

Returns an error if the input version doesn't match the expected `X.Y.Z.0` format.

## Version Format

```text
Input  (Homebrew): 1.79.123.0
Output (Fleet):    137.1.79.123
                   ↑
                   second segment (79) + 58
```

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "1.79.123.0",
}

transformed, err := externalrefs.BraveVersionTransformer(app)
if err != nil {
    log.Fatalf("version transform failed: %v", err)
}

fmt.Println(transformed.Version) // Output: 137.1.79.123
```

## Notes

- Errors are returned (not panicked) for all malformed inputs.
- The `+58` offset is a fixed constant that aligns Homebrew's internal versioning with Brave's public release numbering scheme.
