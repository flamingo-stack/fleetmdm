Resolves a Homebrew-formatted Microsoft Office version string to its short version equivalent by looking up the build number in cached macOS Office release notes.

## Key Components

- **`MicrosoftVersionFromReleaseNotes(app)`** — Primary exported function. Accepts an `FMAManifestApp` and rewrites its `Version` field from Homebrew format (e.g., `16.95.25032931`) to the short release-notes format (e.g., `16.95.3`).
- **`releaseNotesCache`** — Package-level cache of `macoffice.ReleaseNotes`, populated once per process lifetime via `sync.Once`.
- **`cacheOnce`** — `sync.Once` guard ensuring release notes are fetched only once; reset on fetch error to allow retry.

## Version Resolution Logic

1. Split the Homebrew version string into `version` (major.minor) and `build` segments.
2. On first call, fetch and cache release notes via `macoffice.GetReleaseNotes`.
3. Scan release notes for an entry whose short version prefix and build number match.
4. **Exact match found:** set `app.Version` to the short version (e.g., `16.95.3`).
5. **No match found:** fall back to the base version without the build suffix (e.g., `16.95`) to prevent false "update available" alerts when release notes lag behind a newly published build.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "16.95.25032931",
}

updated, err := externalrefs.MicrosoftVersionFromReleaseNotes(app)
if err != nil {
    log.Fatalf("version resolution failed: %v", err)
}

fmt.Println(updated.Version) // "16.95.3" if found, "16.95" as fallback
```
