Transforms a WhatsApp app manifest version string by stripping the leading `2.` prefix, normalizing the Homebrew-sourced version to a shorter format used in Fleet Maintained App references.

## Key Components

- **`WhatsAppVersionShortener(app *maintained_apps.FMAManifestApp) (*maintained_apps.FMAManifestApp, error)`** — Accepts an `FMAManifestApp` manifest, validates the version begins with `2.`, strips that prefix, and returns the modified manifest. Returns an error if the version does not match the expected format.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "2.24.10.78",
}

shortened, err := externalrefs.WhatsAppVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(shortened.Version) // Output: 24.10.78
```

## Notes

- Only versions beginning with `"2."` are accepted; any other prefix causes an error.
- The function mutates the `Version` field of the passed `app` pointer in place and also returns it.
