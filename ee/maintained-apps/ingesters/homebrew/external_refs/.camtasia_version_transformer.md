Normalizes Camtasia version strings from Homebrew cask metadata to match the year-prefixed format that osquery reports (e.g., `26.0.2` → `2026.0.2`).

## Key Components

- **`yearPrefixedCamtasiaVersion`** — Compiled regex that detects whether a version string already begins with a 4-digit year prefix (`20XX.`), preventing double-prefixing.
- **`CamtasiaVersionTransformer`** — Transform function conforming to the `FMAManifestApp` transformer signature. Prepends `"20"` to the version only when the string is not already year-prefixed; returns the app unchanged otherwise.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "26.1.0", // Homebrew short-form version
}

transformed, err := externalrefs.CamtasiaVersionTransformer(app)
if err != nil {
    log.Fatal(err)
}
fmt.Println(transformed.Version) // "2026.1.0"

// Already year-prefixed versions are passed through unchanged
app2 := &maintained_apps.FMAManifestApp{
    Version: "2026.1.0",
}
transformed2, _ := externalrefs.CamtasiaVersionTransformer(app2)
fmt.Println(transformed2.Version) // "2026.1.0"
```

## Notes

- This transformer handles a discrepancy between Homebrew cask metadata (historically short year `26.x.x`) and osquery's `bundle_short_version` reporting (full year `2026.x.x`). Newer Homebrew cask entries may already use the full year format, so the guard regex ensures idempotent behavior.
