Transforms a Google Drive app manifest version string by truncating it to a two-part version number (e.g., `100.1.3456` → `100.1`), ensuring compatibility with Fleet's maintained apps version tracking.

## Key Components

- **`GoogleDriveVersionShortener`** — Accepts an `FMAManifestApp` pointer, checks if the Homebrew-sourced version contains more than one dot, and if so, trims it to only the first two segments joined by a dot. Returns the modified manifest unchanged if the version already has two or fewer parts.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "100.1.3456",
}

shortened, err := GoogleDriveVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(shortened.Version) // Output: "100.1"
```

## Notes

- Only the `Version` field is mutated; all other `FMAManifestApp` fields pass through unmodified.
- Versions with zero or one dot (e.g., `100` or `100.1`) are returned as-is.
- Introduced to address a version mismatch between Homebrew's three-part Google Drive versions and Fleet's expected format. See the upstream tracking issue for context: [#40751](https://github.com/flamingo-stack/fleetmdm/issues/40751).
