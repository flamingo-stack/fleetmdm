Generates install and uninstall shell scripts for macOS applications from Homebrew cask definitions, handling DMG/ZIP extraction, app copying, PKG installation, and artifact cleanup.

## Key Components

### Functions

- **`installScriptForApp(app, cask)`** — Builds a shell install script for a given app by orchestrating extraction, app/pkg copying, binary symlinks, and quit/relaunch lifecycle hooks.
- **`uninstallScriptForApp(cask)`** — Builds a shell uninstall script by processing cask artifacts (apps, binaries, uninstall/zap directives) in priority order.
- **`processUninstallArtifact(u, sb)`** — Handles individual uninstall directives: launchctl removal, app quit, signals, scripts, pkgutil, delete, rmdir, and trash.
- **`sortUninstall(artifacts)`** — Sorts uninstall artifacts by Homebrew's defined priority order (launchctl → quit → signal → ... → rmdir).
- **`shellSingleQuote(s)`** — POSIX-safe single-quoting for shell tokens, escaping embedded apostrophes.
- **`uninstallArtifactOrder(artifact)`** — Returns a priority integer for a given uninstall artifact type.

### Types

- **`scriptBuilder`** — Accumulates shell variables, helper functions, and statements into a complete script string.

### Priority Constants

Mirrors [Homebrew's uninstall directive ordering](https://github.com/Homebrew/brew/blob/e1ff668957dd8a66304c0290dfa66083e6c7444e/Library/Homebrew/cask/artifact/abstract_uninstall.rb#L18-L30): `PriorityEarlyScript` through `PriorityRmdir`.

## Usage Example

```go
cask := &brewCask{ /* parsed from Homebrew formula */ }
app := inputApp{
    Token:            "my-app",
    UniqueIdentifier: "com.example.myapp",
    InstallerFormat:  "dmg",
}

installScript, err := installScriptForApp(app, cask)
if err != nil {
    log.Fatal(err)
}
fmt.Println(installScript)

uninstallScript := uninstallScriptForApp(cask)
fmt.Println(uninstallScript)
```
