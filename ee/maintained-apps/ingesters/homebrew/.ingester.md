This file implements the Homebrew cask ingestion pipeline for Fleet's maintained app (FMA) system, fetching app metadata from the Homebrew formulae API or local cask JSON files and generating install/uninstall scripts with patch policy queries.

## Key Components

- **`IngestApps`** — Entry point that reads JSON input files from a directory, filters by slug, and orchestrates ingestion of each app
- **`brewIngester`** — HTTP client wrapper holding the base Homebrew API URL, logger, and HTTP client
- **`ingestOne`** — Core logic that validates cask fields, builds the `FMAManifestApp` struct, resolves install/uninstall scripts, and generates patch policy queries
- **`fetchCask`** — Resolves a `brewCask` from either a local file (`cask_path`) or the Homebrew formulae API (`https://formulae.brew.sh/api/cask/<token>.json`)
- **`inputApp`** — Struct representing a per-app JSON config file (name, token, bundle ID, slug, script paths, etc.)
- **`brewCask`** — Struct mapping the Homebrew API cask schema (token, version, SHA256, artifacts, URL)
- **`brewArtifact`** — Union-style struct representing Homebrew artifact stanzas (`app`, `pkg`, `zap`, `uninstall`, `binary`)

Special-case handling exists for `docker-desktop` (ignores `.app.back` paths) and `sonos` (compares `bundle_version` instead of `bundle_short_version`).

## Usage Example

```go
import (
    "context"
    "log/slog"

    "github.com/fleetdm/fleet/v4/ee/maintained-apps/ingesters/homebrew"
)

apps, err := homebrew.IngestApps(
    context.Background(),
    slog.Default(),
    "./inputs/homebrew",  // directory of per-app JSON input files
    "",                   // slugFilter: empty = ingest all apps
)
if err != nil {
    log.Fatal(err)
}

for _, app := range apps {
    fmt.Printf("Ingested: %s v%s\n", app.Name, app.Version)
}
```

Each JSON input file in `inputsPath` must include `token`, `unique_identifier`, and `name`. Optionally, `cask_path` can point to a local cask JSON file to bypass the Homebrew API.
