Transforms 1Password version strings from the 4-part winget manifest format (e.g., `8.11.18.36`) to the 3-part format registered by the MSI installer in Windows Programs (e.g., `8.11.18`), ensuring version matching with osquery discovery.

## Key Components

- **`OnePasswordVersionShortener(app *maintained_apps.FMAManifestApp) (*maintained_apps.FMAManifestApp, error)`** — Strips the 4th segment from a dot-separated version string. Returns an error if the version does not contain exactly 4 parts.

## Usage Example

```go
app := &maintained_apps.FMAManifestApp{
    Version: "8.11.18.36",
}

shortened, err := OnePasswordVersionShortener(app)
if err != nil {
    log.Fatal(err)
}

fmt.Println(shortened.Version) // "8.11.18"
```

## Notes

- Expects strictly 4-part versions (`X.Y.Z.W`); any other format returns an error.
- Modifies `app.Version` in place on the passed pointer, but also returns the updated struct for convenience.
- Part of the `externalrefs` package within Fleet's maintained-apps pipeline.
