Provides a registry and pipeline for applying enrichment functions to Fleet Maintained App (FMA) manifests, keyed by app slug.

## Key Components

- **`Funcs`** — A `map[string][]func(...)` registry that maps app slugs (e.g., `"1password/windows"`) to ordered slices of enricher functions. Each enricher accepts and returns a `*maintained_apps.FMAManifestApp`.
- **`EnrichManifest`** — Looks up registered enrichers by `app.Slug` and runs them sequentially. Errors are printed but do not halt the pipeline; the mutated `app` pointer is passed through each step.

## Usage Example

```go
// Register a new enricher for a slug
externalrefs.Funcs["myapp/windows"] = []func(*maintained_apps.FMAManifestApp) (*maintained_apps.FMAManifestApp, error){
    myCustomEnricher,
}

// Apply all enrichers to a manifest app
app := &maintained_apps.FMAManifestApp{
    Slug:             "myapp/windows",
    UniqueIdentifier: "myapp-windows-1.0",
}
externalrefs.EnrichManifest(app)
```

## Notes

- Enrichers run in slice order — earlier entries in `Funcs[slug]` execute first.
- If an enricher returns an error, the error is logged via `fmt.Printf` and the pipeline continues with the returned (possibly nil or partial) `app`.
- To add support for a new app, append its slug and enricher function(s) to the `Funcs` map.
