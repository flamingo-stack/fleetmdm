Jest configuration file for the FleetMDM project, enabling TypeScript + ESM support with a custom jsdom environment and Chrome extension globals.

## Key Components

- **`clearMocks`** — Automatically resets mock state before each test to prevent test pollution
- **`collectCoverage` / `coverageDirectory`** — Enables V8-based code coverage output to the `coverage/` directory
- **`preset` + `transform`** — Uses `ts-jest` with ESM mode (`useESM: true`) to handle `.ts`, `.tsx`, `.mjs`, and `.jsx` files
- **`moduleNameMapper`** — Strips `.js` extensions from relative imports, resolving TypeScript's ESM import requirements
- **`testEnvironment`** — Points to a custom `jsdomwithfetch.ts` environment that extends jsdom with `fetch` support
- **`setupFilesAfterEnv`** — Loads `jest.setup.ts` after the test framework is installed (e.g., for global matchers or test utilities)
- **`globals.chrome`** — Stubs the `chrome` extension API (`runtime`, `privacy`, `idle`, `system.storage`) since neither Jest nor jsdom provide it natively

## Usage Example

```bash
# Run all tests with coverage
npx jest

# Run a specific test file
npx jest src/myFeature.test.ts

# Watch mode during development
npx jest --watch
```

```javascript
// Example test file compatible with this config
import { myFunction } from "./myModule"; // .js extension omitted — handled by moduleNameMapper

describe("myFunction", () => {
  it("returns expected value", async () => {
    const result = await myFunction();
    expect(result).toBe("expected");
  });
});
```
