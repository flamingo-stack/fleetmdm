Configures Mock Service Worker (MSW) request handlers for testing, intercepting WebAssembly file requests and serving the actual `wa-sqlite-async.wasm` binary from `node_modules`.

## Key Components

- **`handlers`** — Array of MSW REST handlers exported for use in test setups.
- **`.wasm` GET handler** — Intercepts any GET request matching `/wa-sqlite-async\.wasm$/` and reads the binary file from disk, returning it with the correct `application/wasm` content type.

## Usage Example

```typescript
// In your test setup (e.g., setupTests.ts or msw server config)
import { setupServer } from "msw/node";
import { handlers } from "./handlers";

const server = setupServer(...handlers);

beforeAll(() => server.listen());
afterEach(() => server.resetHandlers());
afterAll(() => server.close());
```

The handler resolves the `.wasm` file path relative to its own `__dirname`, using `fileURLToPath` for ESM compatibility. This avoids network fetches for the WebAssembly binary during tests that depend on `wa-sqlite`.
