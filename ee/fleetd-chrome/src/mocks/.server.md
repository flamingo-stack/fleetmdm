Sets up a Mock Service Worker (MSW) Node.js server for intercepting and mocking HTTP requests during testing.

## Key Components

- **`server`** — A configured MSW server instance created by spreading all handlers from the `handlers` module into `setupServer`.

## Usage Example

```typescript
import { server } from "./server";

// Start the server before all tests
beforeAll(() => server.listen());

// Reset handlers after each test to avoid state leakage
afterEach(() => server.resetHandlers());

// Stop the server after all tests complete
afterAll(() => server.close());
```

## Notes

- Relies on `./handlers` to define the actual request interception logic. Add or modify mock endpoints there.
- Intended for Node.js test environments (e.g., Jest, Vitest) — use the `msw/browser` variant for browser-side mocking.
- See the full handlers definition at [`handlers.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/handlers.ts) (adjust path as needed).
