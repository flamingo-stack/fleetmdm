Provides disk/storage information by querying the Chrome system storage API and returning details about all connected storage units.

## Key Components

- **`TableDiskInfo`** — Extends `Table` to expose storage unit metadata as a queryable virtual table named `disk_info`.
- **`columns`** — Defines four fields: `capacity`, `id`, `name`, and `type`.
- **`generate()`** — Async method that calls `chrome.system.storage.getInfo()` and maps each `StorageUnitInfo` entry into a row.

## Usage Example

```typescript
import TableDiskInfo from "./disk_info";

const table = new TableDiskInfo();
const result = await table.generate();

// result.data example:
// [
//   { capacity: 500107862016, id: "0", name: "Samsung SSD 860", type: "fixed" },
//   { capacity: 128849018880, id: "1", name: "USB Drive",        type: "removable" }
// ]
```

## Notes

- Requires the `storage` permission declared in the Chrome extension manifest (`"permissions": ["system.storage"]`).
- The `type` field reflects the Chrome-defined storage category (e.g., `"fixed"`, `"removable"`, `"unknown"`).
- `capacity` is reported in bytes.
