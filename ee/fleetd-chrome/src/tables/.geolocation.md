Provides a virtual osquery-style table that fetches the current device's geolocation data based on its public IP address using the [ipapi.co](https://ipapi.co) API.

## Key Components

- **`TableGeolocation`** — Extends `Table` base class; exposes a `geolocation` virtual table with four columns: `ip`, `city`, `country`, and `region`.
- **`generate()`** — Async method that calls `https://ipapi.co/json` and maps the response to a single-row result set.

## Usage Example

```typescript
import TableGeolocation from "./geolocation";

const table = new TableGeolocation();
const result = await table.generate();

console.log(result.data);
// [{ ip: "203.0.113.1", city: "Austin", country: "United States", region: "Texas" }]
```

## Notes

- The table always returns a **single row** representing the host's current public IP geolocation.
- `country` maps to `country_name` from the ipapi.co response (full country name, not ISO code).
- No API key is required for basic usage, but ipapi.co enforces rate limits on unauthenticated requests (1,000 requests/day).
- Network availability is required at query time; no caching or offline fallback is implemented.
