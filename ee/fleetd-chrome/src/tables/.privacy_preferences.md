Exposes Chrome browser privacy settings as a virtual osquery table by querying the `chrome.privacy` API and returning all preference values in a single row.

## Key Components

**`TablePrivacyPreferences`** — Extends `Table` to implement the `privacy_preferences` virtual table.

- **`name`** — Table identifier: `"privacy_preferences"`
- **`propertyAPIs`** — Maps column names to their corresponding `chrome.privacy` API references across three namespaces:
  - `network` — `networkPredictionEnabled`, `webRTCIPHandlingPolicy`
  - `services` — `autofillAddressEnabled`, `autofillCreditCardEnabled`, `passwordSavingEnabled`, `safeBrowsingEnabled`, `spellingServiceEnabled`, `translationServiceEnabled`, and others
  - `websites` — `adMeasurementEnabled`, `doNotTrackEnabled`, `fledgeEnabled`, `hyperlinkAuditingEnabled`, `thirdPartyCookiesAllowed`, `topicsEnabled`, and others
- **`columns`** — Dynamically derived from `propertyAPIs` keys
- **`generate()`** — Queries all privacy APIs in parallel, returning a single-row result where boolean values are serialized as `"1"` / `"0"`, `webRTCIPHandlingPolicy` is returned as its raw string enum, and unavailable APIs resolve to `""` or `"data unavailable"` with a warning entry

## Usage Example

```typescript
const table = new TablePrivacyPreferences();
const { data, warnings } = await table.generate();

// data is a single-row object, e.g.:
// [{
//   safe_browsing_enabled: "1",
//   do_not_track_enabled: "0",
//   web_rtc_ip_handling_policy: "default",
//   spelling_service_enabled: "data unavailable",
//   ...
// }]

if (warnings.length > 0) {
  console.warn("Privacy API warnings:", warnings);
}
```

## Notes

- Several properties (e.g., `adMeasurementEnabled`, `fledgeEnabled`, `topicsEnabled`) are not yet typed in `@types/chrome` and require `@ts-ignore`
- `autofill_enabled` is deprecated in favor of `autofill_address_enabled` and `autofill_credit_card_enabled`
- `privacy_sandbox_enabled` is also deprecated
