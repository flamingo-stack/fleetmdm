Provides a virtual `users` table that surfaces the current Chrome profile's identity information via the Chrome Identity API.

## Key Components

- **`TableUsers`** — Extends `Table` to expose a single-row `users` table with columns `uid`, `username`, and `email`.
- **`generate()`** — Asynchronously fetches the authenticated Chrome profile via `chrome.identity.getProfileUserInfo` and returns a normalized row mapping `id` → `uid` and `email` → both `email` and `username`.

## Usage Example

```typescript
import TableUsers from "./users";

const table = new TableUsers();
const result = await table.generate();
// result.data => [{ uid: "google-id-123", email: "user@example.com", username: "user@example.com" }]
```

## Notes

- Requires the `identity` permission declared in the extension's `manifest.json`.
- `username` is derived from `email` since Chrome Identity does not expose a separate display name.
- Inherits query/filtering behavior from the base [`Table`](https://github.com/flamingo-stack/fleetmdm/blob/main/Table.ts) class.
