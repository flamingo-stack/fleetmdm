Returns static metadata about the osquery runtime environment, tailored for the Fleet Chrome extension context.

## Key Components

- **`TableOsqueryInfo`** — Extends `Table` to implement the `osquery_info` virtual table
- **`name`** — Table identifier: `"osquery_info"`
- **`columns`** — Exposes `version`, `build_platform`, `build_distro`, and `extensions`
- **`generate()`** — Returns a single-row result with Chrome extension metadata

## Usage Example

```typescript
import TableOsqueryInfo from "./osquery_info";

const table = new TableOsqueryInfo();
const result = await table.generate();

// result.data[0]:
// {
//   version: "fleetd-chrome-1.2.3",
//   build_platform: "chrome",
//   build_distro: "chrome",
//   extensions: "inactive"
// }
```

## Notes

- `version` is dynamically sourced from [`chrome.runtime.getManifest().version`](https://developer.chrome.com/docs/extensions/reference/runtime/#method-getManifest), prefixed with `fleetd-chrome-`
- `build_platform` and `build_distro` are hardcoded to `"chrome"` since this table only runs in the Chrome extension environment
- `extensions` is always `"inactive"` — matching osquery convention for environments where extensions are not applicable
