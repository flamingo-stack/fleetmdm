Provides a virtual `system_state` table that queries the Chrome extension idle API to report the current user idle state on ChromeOS devices.

## Key Components

- **`TableSystemState`** — Extends `Table` to expose a single-column `system_state` virtual table with the column `idle_state`.
- **`generate()`** — Async method that:
  - Guards against non-ChromeOS environments where `chrome.idle.getAutoLockDelay` is unavailable, returning a descriptive warning instead of data.
  - Retrieves the device's auto-lock delay via `chrome.idle.getAutoLockDelay`.
  - Computes an idle detection threshold as 20% of the auto-lock delay, falling back to 30 seconds if no delay is configured.
  - Queries `chrome.idle.queryState` and returns one of `"active"`, `"idle"`, or `"locked"`.

## Usage Example

```typescript
import TableSystemState from "./system_state";

const table = new TableSystemState();

// Query the system idle state
const result = await table.generate();

if (result.warnings?.length) {
  console.warn(result.warnings[0].error_message);
  // "chrome.idle.getAutoLockDelay API is only available on ChromeOS..."
} else {
  const { idle_state } = result.data[0];
  console.log(idle_state); // "active" | "idle" | "locked"
}
```

## Notes

- `chrome.idle.getAutoLockDelay` is a **ChromeOS-only** API; the table gracefully degrades on other platforms by returning an empty dataset with a structured warning.
- The idle threshold defaults to **30 seconds** when the device has no auto-lock configured (`autoLockDelay === 0`).
- Two `@ts-ignore` comments suppress stale TypeScript typings for the Chrome idle API.
