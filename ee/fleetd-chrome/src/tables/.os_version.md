Provides OS version information for Chrome/ChromeOS devices by querying browser APIs and formatting the result as an osquery-compatible `os_version` table row.

## Key Components

**`TableOSVersion`** extends `Table` with the following members:

| Member | Description |
|--------|-------------|
| `name` | Table identifier: `"os_version"` |
| `columns` | Exposes `name`, `platform`, `platform_like`, `version`, `major`, `minor`, `build`, `patch`, `arch`, `codename` |
| `getName(platform)` | Normalizes platform string (`"Chrome OS"` → `"ChromeOS"`) |
| `getCodename(platformVersion)` | Formats codename as `"ChromeOS <version>"` |
| `generate()` | Async method that collects OS/browser version data and returns a table row with any warnings |

### Data Collection Strategy

- **Version & platform info** — fetched via `navigator.userAgentData.getHighEntropyValues()` (experimental API); parses `MAJOR.MINOR.BUILD.PATCH` segments per [Chromium versioning](https://www.chromium.org/developers/version-numbers/).
- **Architecture** — fetched via `chrome.runtime.getPlatformInfo()`.
- **`platform` / `platform_like`** — hardcoded to `"chrome"` to ensure Fleet always identifies this as a Chrome device, even during local development on non-ChromeOS machines.
- **Warnings** — any API failure is caught and reported per-column rather than failing the entire table.

## Usage Example

```typescript
import TableOSVersion from "./os_version";

const table = new TableOSVersion();
const result = await table.generate();

console.log(result.data[0]);
// {
//   name: "ChromeOS",
//   platform: "chrome",
//   platform_like: "chrome",
//   version: "114.0.5735.90",
//   major: "114", minor: "0", build: "5735", patch: "90",
//   codename: "ChromeOS 13.3",
//   arch: "x86_64"
// }

if (result.warnings.length > 0) {
  console.warn("Partial data:", result.warnings);
}
```
