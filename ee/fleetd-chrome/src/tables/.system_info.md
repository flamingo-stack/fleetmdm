Implements the `system_info` osquery-compatible table for Chrome OS extensions, collecting hardware and system identity data from Chrome Enterprise APIs.

## Key Components

**`TableSystemInfo`** extends `Table` and exposes the following columns:

| Column | Source |
|---|---|
| `uuid` | `chrome.instanceID.getID()` |
| `hostname` | `chrome.enterprise.deviceAttributes.getDeviceHostname()` |
| `computer_name` | Derived via `getComputerName()` |
| `hardware_serial` | `chrome.enterprise.deviceAttributes.getDeviceSerialNumber()` |
| `hardware_vendor` | `chrome.enterprise.hardwarePlatform.getHardwarePlatformInfo()` |
| `hardware_model` | `chrome.enterprise.hardwarePlatform.getHardwarePlatformInfo()` |
| `cpu_brand` | `chrome.system.cpu.getInfo()` |
| `cpu_type` | `chrome.system.cpu.getInfo()` |
| `physical_memory` | `chrome.system.memory.getInfo()` |

**`getComputerName(hostname, hwSerial)`** — Returns a human-readable device name, preferring `hostname`, falling back to `"Chromebook <serial>"`, then `"Chromebook"`.

**`generate()`** — Async method that collects all system data. Each field is fetched independently; failures push a per-column warning rather than aborting the entire query. In development mode (non-enterprise installs), stubbed or UUID-based values are used.

## Usage Example

```typescript
const table = new TableSystemInfo();
const result = await table.generate();

console.log(result.data[0]);
// {
//   uuid: "abc123...",
//   hostname: "corp-device-01",
//   computer_name: "corp-device-01",
//   hardware_serial: "CX123ABC",
//   hardware_vendor: "Google",
//   hardware_model: "Chromebook Pro",
//   cpu_brand: "Intel Core i5",
//   cpu_type: "x86_64",
//   physical_memory: "8589934592"
// }

console.log(result.warnings);
// [{ column: "hardware_vendor", error_message: "Not allowed" }]
```

> **Note:** `hardware_vendor` and `hardware_model` require the [`EnterpriseHardwarePlatformAPIEnabled`](https://chromeenterprise.google/policies/?policy=EnterpriseHardwarePlatformAPIEnabled) Chrome policy to be enabled. Missing it produces a warning but does not fail the table.
