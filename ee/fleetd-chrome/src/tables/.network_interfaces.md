Implements a virtual osquery-style table that retrieves the device's network interface details (MAC address, IPv4, and IPv6) using the Chrome Enterprise `networkingAttributes` API.

## Key Components

- **`TableNetworkInterfaces`** — Extends `Table` to expose a `network_interfaces` virtual table with three columns: `mac`, `ipv4`, and `ipv6`.
- **`generate()`** — Async method that calls `chrome.enterprise.networkingAttributes.getNetworkDetails()` and maps the result into a single-row data payload. Returns a structured warning if the `chrome.enterprise` API is unavailable.

## Usage Example

```typescript
import TableNetworkInterfaces from "./network_interfaces";

const table = new TableNetworkInterfaces();
const result = await table.generate();

if (result.warnings) {
  console.warn(result.warnings[0].error_message);
} else {
  const [iface] = result.data;
  console.log(`MAC: ${iface.mac}, IPv4: ${iface.ipv4}, IPv6: ${iface.ipv6}`);
}
```

## Notes

- Requires the `chrome.enterprise` API, which is only available in managed Chrome environments (e.g., ChromeOS devices enrolled via Google Admin).
- A `@ts-expect-error` suppression is used because `@types/chrome` does not yet include the Promise-based `getNetworkDetails` signature.
- When the API is unavailable, `generate()` returns an empty `data` array and a warning on the `mac` column rather than throwing, keeping the table safe for use in non-enterprise contexts.
