Service Worker script for [Mock Service Worker (MSW) v1.3.5](https://github.com/mswjs/msw) that intercepts and mocks network requests in the browser during development and testing. It should **not** be served in production.

## Key Components

| Function/Handler | Description |
|---|---|
| `install` / `activate` | Standard SW lifecycle — skips waiting and claims clients immediately |
| `message` handler | Processes control messages: `KEEPALIVE_REQUEST`, `INTEGRITY_CHECK_REQUEST`, `MOCK_ACTIVATE`, `MOCK_DEACTIVATE`, `CLIENT_CLOSED` |
| `fetch` handler | Intercepts outgoing requests, bypasses SSE/navigation/DevTools requests, routes to `handleRequest` |
| `handleRequest` | Resolves the main client, fetches a mock or real response, sends response metadata back via `RESPONSE` message |
| `resolveMainClient` | Finds the top-level window client that registered the worker |
| `getResponse` | Decides whether to passthrough or mock based on client state and request headers |
| `sendToClient` | Bidirectional messaging to the page using `MessageChannel` |
| `respondWithMock` | Constructs a `Response` from mock data, respecting a configurable delay |

## Usage Example

This file is auto-generated and managed by MSW. Place it at your app's public root and register it via the MSW browser setup:

```javascript
// src/mocks/browser.js
import { setupWorker } from 'msw'
import { handlers } from './handlers'

export const worker = setupWorker(...handlers)

// src/index.js (dev only)
if (process.env.NODE_ENV === 'development') {
  const { worker } = await import('./mocks/browser')
  await worker.start({
    serviceWorker: {
      url: '/mockServiceWorker.js', // must match public path
    },
  })
}
```

> **Note:** Do not modify this file manually. Regenerate it via `npx msw init public/` when upgrading MSW. Never deploy to production — gate it behind a `NODE_ENV` check as shown above.
