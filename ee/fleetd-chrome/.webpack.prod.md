Production webpack configuration that merges with the common configuration and sets the build mode to `production`.

## Key Components

- **`merge`** – Imported from `webpack-merge` to combine base and environment-specific configurations
- **`common`** – Shared webpack configuration imported from [`webpack.common.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/webpack.common.js)
- **Default export** – Merged configuration object with `mode: "production"` applied

## Usage Example

```bash
# Build using this production config
webpack --config webpack.prod.js
```

```javascript
// webpack.prod.js in context
import { merge } from "webpack-merge";
import * as common from "./webpack.common.js";

export default merge(common, {
  mode: "production", // Enables minification, tree-shaking, and other optimizations
});
```

## Notes

- Setting `mode: "production"` automatically enables optimizations such as minification, scope hoisting, and tree-shaking via webpack's built-in defaults
- All shared configuration (entry points, loaders, plugins, etc.) is inherited from `webpack.common.js`
- Pair with a [`webpack.dev.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/webpack.dev.js) for a complete multi-environment build setup
