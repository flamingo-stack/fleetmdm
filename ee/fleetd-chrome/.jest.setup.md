Sets up the global Jest test environment by configuring MSW (Mock Service Worker) request interception and making `jest` available as a global variable.

## Key Components

- **`server`** — MSW server instance imported from the local mock definitions, used to intercept and simulate API requests during tests.
- **`beforeAll`** — Starts the MSW server and assigns `jest` to `global.jest` before any test suite runs.
- **`afterEach`** — Resets any custom request handlers added during individual tests to prevent cross-test contamination.
- **`afterAll`** — Shuts down the MSW server after the full test suite completes.

## Usage Example

This file is referenced in your Jest config (e.g. `jest.config.ts`) via `setupFilesAfterFramework`:

```typescript
// jest.config.ts
export default {
  setupFilesAfterFramework: ["./jest.setup.ts"],
};
```

With the setup in place, tests can rely on mocked network requests without additional boilerplate:

```typescript
// example.test.ts
import { http, HttpResponse } from "msw";
import { server } from "./src/mocks/server.js";

test("handles custom response", async () => {
  server.use(
    http.get("/api/devices", () =>
      HttpResponse.json({ devices: [] })
    )
  );

  const res = await fetch("/api/devices");
  const data = await res.json();
  expect(data.devices).toHaveLength(0);
});
```

> **Note:** The `global.jest = jest` assignment works around a known issue where `jest` is not automatically available as a global in ESM-based test environments. The `@ts-ignore` suppresses the unexplained TypeScript error on that line.
