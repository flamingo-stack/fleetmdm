Development-mode Webpack configuration that extends the shared base config with development-specific settings.

## Key Components

- **`merge`** — Combines the common Webpack config with development overrides using `webpack-merge`
- **`mode: "development"`** — Enables Webpack's built-in development optimizations (readable output, faster builds)
- **`devtool: "inline-source-map"`** — Embeds source maps directly into output bundles for easier in-browser debugging

## Usage Example

```javascript
// Build with this config directly
// package.json
{
  "scripts": {
    "dev": "webpack --config webpack.dev.js",
    "watch": "webpack --watch --config webpack.dev.js"
  }
}
```

> **Note:** `inline-source-map` is convenient for development but increases bundle size significantly — use a different `devtool` (e.g., `source-map`) for production builds defined in `webpack.common.js`.
