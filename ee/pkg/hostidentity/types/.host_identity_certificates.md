Defines core types and utilities for host identity certificate management, including ECDSA public key serialization/deserialization and a custom ASN.1 renewal extension OID used in Fleet's MDM certificate lifecycle.

## Key Components

- **`RenewalExtensionOID`** — Custom ASN.1 OID (`1.3.6.1.4.1.63991.1.1`) for the certificate renewal extension, using Fleet's IANA private enterprise number (63991).
- **`RenewalData`** — JSON-serializable struct carrying the hex-encoded serial number and base64-encoded ECDSA signature of the previous certificate during renewal.
- **`HostIdentityCertificate`** — DB-mapped struct representing a host identity certificate with serial number, common name, host association, validity period, and raw public key bytes.
- **`UnmarshalPublicKey()`** — Deserializes the raw uncompressed EC point (`0x04 || X || Y`) stored in `PublicKeyRaw` back into an `*ecdsa.PublicKey`, auto-detecting P-256 or P-384 by key length.
- **`guessCurve()`** — Internal helper that infers the elliptic curve from raw key byte length (65 bytes → P-256, 97 bytes → P-384).
- **`CreateECDSAPublicKeyRaw()`** — Serializes an `*ecdsa.PublicKey` to the uncompressed point format (`0x04 || X || Y`) with proper zero-padding for P-256 and P-384.

## Usage Example

```go
// Serialize a public key for storage
pubKeyRaw, err := types.CreateECDSAPublicKeyRaw(ecKey.Public().(*ecdsa.PublicKey))
if err != nil {
    return err
}

cert := &types.HostIdentityCertificate{
    SerialNumber:  12345,
    CommonName:    "host-abc",
    PublicKeyRaw:  pubKeyRaw,
    NotValidAfter: time.Now().Add(365 * 24 * time.Hour),
}

// Later, recover the public key for signature verification
pubKey, err := cert.UnmarshalPublicKey()
if err != nil {
    return err
}
_ = ecdsa.Verify(pubKey, digest, r, s)
```
