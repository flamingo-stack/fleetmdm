CLI tool for generating JWT-based Fleet MDM license keys, signed with ES256 using a private key and passphrase.

## Key Components

- **`generate(argv)`** — Core function that reads the private key and passphrase from disk, constructs a JWT payload with license metadata, and prints the signed token to stdout.
- **`coerceDate(str)`** — Validates and converts a date string to a Unix millisecond timestamp; throws on invalid input.
- **`yargs` CLI** — Exposes a single `generate` command with required options for key path, expiration, customer, and device count.

### JWT Payload Fields

| Field | Description |
|-------|-------------|
| `iss` | Issuer (`Fleet Device Management Inc.`) |
| `exp` | Expiration (Unix seconds) |
| `sub` | Customer name |
| `devices` | Licensed device count |
| `tier` | License tier (default: `premium`) |
| `note` | Optional note |
| `notel` | Allow disabling telemetry |

## Usage Example

```bash
node tools/license/license.js generate \
  --private-key ./keys/private.pem \
  --key-passphrase ./keys/passphrase.txt \
  --expiration "2026-01-01" \
  --customer "Acme Corp" \
  --devices 500 \
  --tier premium \
  --note "Annual contract" \
  --allow-disable-telemetry
```

This outputs a signed JWT string to stdout that can be provided to Fleet as a license key.

> **Note:** `--expiration` accepts any string parseable by `Date.parse()` (e.g., `"2026-01-01"`, `"January 1, 2026"`). Invalid dates throw immediately.
