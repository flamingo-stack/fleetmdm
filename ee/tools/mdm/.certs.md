Processes Apple MDM push certificate signing requests by combining a vendor certificate, vendor private key, and customer CSR into a signed request payload suitable for submission to Apple's identity portal.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `signResult` | struct | JSON output containing extracted `email`, `org`, and the encoded push certificate `request` |
| `main` | func | Entry point; reads inputs from environment variables and writes JSON result to stdout |
| `processRequest` | func | Orchestrates cert loading, CSR decoding, subject extraction, and request creation |
| `createPushCertificateRequest` | func | Builds the `mdmcertutil.PushCertificateRequest` with signed CSR, cert chain, and signature |
| `getEmailOrg` | func | Extracts email (OID `1.2.840.113549.1.9.1`) and organization (OID `2.5.4.10`) from CSR subjects |
| `signPushCSR` | func | Signs raw CSR bytes with RSA-PKCS1v15 + SHA-256 using the vendor private key |
| `loadKey` | func | Decodes and decrypts a password-protected PEM RSA private key |
| `decodeVendorCert` / `decodeCSR` | func | Parse PEM-encoded X.509 certificate and certificate request respectively |
| `wwdrIntermediaryCert` / `appleRootCert` | const | Hardcoded Apple WWDR G3 and Apple Root CA certificates included in the chain |

**Environment variables required:**

| Variable | Purpose |
|----------|---------|
| `VENDOR_CERT_PEM` | MDM vendor certificate (PEM) |
| `VENDOR_KEY_PEM` | Encrypted RSA private key (PEM) |
| `VENDOR_KEY_PASSPHRASE` | Passphrase to decrypt the vendor key |
| `CSR_BASE64` | Customer CSR encoded as standard base64 |

## Usage Example

```bash
export VENDOR_CERT_PEM="$(cat vendor.pem)"
export VENDOR_KEY_PEM="$(cat vendor-key.pem)"
export VENDOR_KEY_PASSPHRASE="mysecretpassphrase"
export CSR_BASE64="$(base64 -w0 customer.csr)"

go run certs.go
# Output:
# {"email":"admin@example.com","org":"Example Corp","request":"<encoded_push_cert_request>"}
```

The JSON output's `request` field is the payload to submit to `identity.apple.com` to obtain an APNs MDM push certificate. See [Apple's MDM push notification documentation](https://developer.apple.com/documentation/devicemanagement/implementing_device_management/setting_up_push_notifications_for_your_mdm_customers) for details on the expected CSR format.
