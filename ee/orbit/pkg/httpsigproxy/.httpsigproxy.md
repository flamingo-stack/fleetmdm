A TLS reverse proxy that intercepts local HTTP traffic and adds HTTP signatures before forwarding requests to a remote Fleet server. Used by the Fleet orbit agent to enable mTLS-free authenticated communication via the `httpsig-go` library.

## Key Components

- **`Proxy`** — Core struct holding the TLS listener, HTTP server, parsed local URL (`127.0.0.1:<port>`), and the path to the written certificate file.
- **`NewProxy()`** — Constructs and configures the proxy: writes the bundled TLS cert to disk, binds a TLS listener on an available loopback port, and wires up the reverse proxy handler.
- **`Proxy.Serve()`** — Starts accepting connections on the TLS listener.
- **`Proxy.Close()`** — Gracefully shuts down the server with a 10-second timeout.
- **`newProxyHandler()`** — Builds an `httputil.ReverseProxy` targeting the Fleet server URL, configured with optional custom root CA or insecure TLS skip.
- **`signingRoundTripper`** — `http.RoundTripper` wrapper that calls `signer.Sign(req)` on every outbound request and strips the `X-Forwarded-For` header before forwarding.
- **`serverCert` / `serverKey`** — Embedded self-signed ECC P-256 cert/key valid for `127.0.0.1` and `::1`. Intentionally compromised (loopback-only, security is provided by the signature layer).

## Usage Example

```go
signer, _ := httpsig.NewSigner(/* ... */)

proxy, err := httpsig.NewProxy(
    "/var/lib/orbit/httpsig",    // proxy working directory
    "https://fleet.example.com", // upstream Fleet server
    "/etc/fleet/rootCA.pem",     // custom root CA (or "" for system)
    false,                       // insecure skip verify
    signer,
)
if err != nil {
    log.Fatal(err)
}
defer proxy.Close()

// Redirect orbit HTTP clients to the proxy instead of Fleet directly
// proxy.ParsedURL == "https://127.0.0.1:<port>"
// proxy.CertificatePath == "/var/lib/orbit/httpsig/proxy.crt"

go proxy.Serve()
```

> **Note:** The embedded certificate is intentionally left in source — all connections are loopback-only (`127.0.0.1`). Security relies on the HTTP signature layer, not the TLS certificate confidentiality.
