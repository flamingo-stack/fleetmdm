This file implements TPM 2.0 (Trusted Platform Module) hardware-backed key management for Fleet's secure hardware (`securehw`) package, providing key creation, loading, and signing operations via the TPM device.

## Key Components

- **`tpm2SecureHW`** — Struct implementing the `SecureHW` interface using a TPM 2.0 device. Manages device transport, logging, and key file path.
- **`tpm2Key`** — Struct implementing the `Key` interface, wrapping a loaded TPM key handle for signing operations.
- **`httpSigner`** — Wraps `crypto.Signer` with an `ECCAlgorithm` identifier for HTTP signature use.
- **`NewTestSecureHW`** — Constructor for injecting a TPM simulator transport, intended for integration tests only.
- **`CreateKey()`** — Creates a new ECC child key under a transient RSA-2048 parent key, persists it as a keyfile, and returns the loaded key handle.
- **`LoadKey()`** — Reads an existing TPM keyfile, recreates the deterministic parent key, and loads the child key into the TPM.
- **`createParentKey()`** — Deterministically creates a transient RSA-2048 Storage Root Key used as the parent for child ECC keys.
- **`selectBestECCCurve()`** — Probes the TPM for P-384 support; falls back to P-256 if unavailable.
- **`saveTPMKeyFile()` / `loadTPMKeyFile()`** — Serializes/deserializes TPM key blobs to/from disk using the `go-tpm-keyfiles` format.
- **`Close()`** — Safely closes the TPM transport, tolerating already-closed errors.
- **`flushHandle()`** — Flushes a TPM transient object handle, logging but not surfacing errors.

## Usage Example

```go
// Production usage (platform-specific constructors wrap this):
hw, err := securehw.NewTPMSecureHW(metadataDir, logger)
if err != nil {
    log.Fatal(err)
}
defer hw.Close()

// Create a new key (first run):
key, err := hw.CreateKey()
if err != nil {
    log.Fatal(err)
}

// Or load an existing key (subsequent runs):
key, err = hw.LoadKey()
if err != nil {
    log.Fatal(err)
}

// Get an HTTP signer for Fleet's httpsig protocol:
httpSigner, err := key.HTTPSigner()
if err != nil {
    log.Fatal(err)
}
algo := httpSigner.ECCAlgorithm() // ECCAlgorithmP256 or ECCAlgorithmP384

// Testing with a TPM simulator:
hw, err = securehw.NewTestSecureHW(simulatorTransport, metadataDir, logger)
```

## Notes

- The parent key is created deterministically via `CreatePrimary` with a fixed template, so child keys can be re-loaded across restarts without persisting the parent handle.
- Key files are stored at `<metadataDir>/constant.FleetHTTPSignatureTPMKeyFileName` with `0600` permissions.
- ECC curve selection (P-384 preferred, P-256 fallback) is detected at runtime by attempting a test `CreatePrimary` on the TPM.
