Defines the core interfaces and error types for hardware-based cryptographic operations, abstracting TPM (Trusted Platform Module) functionality behind a clean Go interface layer.

## Key Components

### Interfaces

- **`SecureHW`** — Top-level interface for hardware cryptographic operations. Supports key creation, key loading from persisted blobs, and resource cleanup.
- **`Key`** — Represents a hardware-resident key. Exposes standard (`crypto.Signer`) and HTTP-specific signing, public key retrieval, and cleanup.
- **`HTTPSigner`** — Extends `crypto.Signer` with `ECCAlgorithm()` for RFC 9421-compatible HTTP signatures using fixed-width `r||s` format.

### Types

| Type | Description |
|------|-------------|
| `ECCAlgorithm` | Integer enum for ECC curve selection (`ECCAlgorithmP256`, `ECCAlgorithmP384`) |
| `ErrKeyNotFound` | Returned when a key blob cannot be loaded from storage |
| `ErrSecureHWUnavailable` | Returned when TPM hardware is inaccessible |

### Constructor

- **`New(metadataDir string, logger zerolog.Logger) (SecureHW, error)`** — Creates a new `SecureHW` instance, delegating to the platform-specific `newSecureHW` implementation. Attaches a `"securehw"` component label to the logger.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/securehw"

hw, err := securehw.New("/var/lib/agent/tpm", logger)
if err != nil {
    var unavail securehw.ErrSecureHWUnavailable
    if errors.As(err, &unavail) {
        log.Fatal("TPM not present:", unavail)
    }
}
defer hw.Close()

key, err := hw.CreateKey() // prefers P-384, falls back to P-256
if err != nil {
    log.Fatal(err)
}
defer key.Close()

signer, err := key.Signer()
if err != nil {
    log.Fatal(err)
}
// signer implements crypto.Signer — pass to tls.Config, x509 CSR, etc.
```
