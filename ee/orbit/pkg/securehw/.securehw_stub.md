Stub implementation of the `SecureHW` factory function for non-Linux platforms, returning an unsupported error at construction time.

## Key Components

- **`newSecureHW(string, zerolog.Logger) (SecureHW, error)`** — Build-constrained constructor that always returns `nil, errors.New("not implemented")` on any OS other than Linux.

## Usage Example

This file is selected automatically by the Go build system on non-Linux targets. No direct invocation is needed — calling `newSecureHW` on Windows or macOS will surface the error:

```go
hw, err := newSecureHW("/dev/tpm0", logger)
if err != nil {
    // err.Error() == "not implemented" on non-Linux platforms
    log.Warn().Err(err).Msg("secure hardware unavailable on this platform")
}
```

The `//go:build !linux` constraint ensures the Linux-specific TPM/secure-hardware implementation (in a sibling file) takes precedence when compiling for Linux, while this stub satisfies the interface on all other platforms without pulling in Linux-only syscalls or libraries.
