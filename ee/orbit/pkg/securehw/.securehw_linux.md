Linux-specific implementation of the `SecureHW` interface that initializes a TPM 2.0 hardware security module by opening the kernel resource manager device at `/dev/tpmrm0`.

## Key Components

- **`tpm20DevicePath`** — Constant defining the Linux TPM 2.0 resource manager device path (`/dev/tpmrm0`).
- **`newSecureHW(metadataDir string, logger zerolog.Logger) (SecureHW, error)`** — Constructor that opens the TPM 2.0 device via `linuxtpm.Open` and returns a configured `tpm2SecureHW` instance. Returns `ErrSecureHWUnavailable` if the device cannot be opened.

## Usage Example

```go
logger := zerolog.New(os.Stdout)
hw, err := newSecureHW("/var/lib/fleet/metadata", logger)
if err != nil {
    var unavailable ErrSecureHWUnavailable
    if errors.As(err, &unavailable) {
        // TPM not present or inaccessible on this host
        log.Warn().Msg(unavailable.Message)
    }
    return err
}
defer hw.Close()
```

## Notes

- Build-constrained to Linux via `//go:build linux`.
- Uses the **kernel TPM resource manager** (`/dev/tpmrm0`) rather than the raw device (`/dev/tpm0`), enabling safe concurrent access by multiple processes without requiring `tpm2-abrmd` in userspace.
- The TPM key file path is resolved as `metadataDir/constant.FleetHTTPSignatureTPMKeyFileName` and stored on the returned struct for subsequent key operations.
