Manages host identity credentials by provisioning and renewing SCEP-issued client certificates backed by secure hardware (TPM/SecureEnclave) private keys.

## Key Components

- **`Credentials`** — Struct holding the SCEP-issued `*x509.Certificate`, the `securehw.Key` private key handle, the certificate file path, and a reference to the `SecureHW` device. Call `Close()` when done to release hardware resources.

- **`Setup()`** — Primary entrypoint. Initializes or loads the secure hardware key, fetches or loads the SCEP client certificate, validates that the certificate's public key matches the hardware key, and starts a background goroutine that triggers `restartFunc` when the certificate approaches expiration (180-day threshold with randomized jitter to prevent thundering herd).

- **`RenewCertificate()`** — Performs certificate renewal with proof-of-possession. Backs up the existing TPM key, creates a new hardware key, signs the existing certificate's serial number with the old key to prove ownership, then fetches a new certificate via SCEP with a custom renewal extension. Restores the backup on failure.

- **`certNeedsRenewal()`** — Returns `true` if the certificate expires within the provided `renewalThreshold` duration.

- **`loadSCEPClientCert()` / `saveSCEPClientCert()`** — PEM-encode/decode the client certificate to/from `metadataDir`.

- **`fetchCertWithRenewal()`** — Builds a SCEP client with a `pkix.Extension` carrying `types.RenewalData` (serial number + old-key signature) and fetches the renewed certificate.

## Usage Example

```go
creds, err := hostidentity.Setup(
    ctx,
    "/var/lib/orbit",       // metadataDir
    "https://fleet.example.com/mdm/scep", // scepURL
    "my-scep-challenge",
    "device-hostname",
    rootCAPEM,
    false,                  // insecure
    logger,
    func(reason string) {
        log.Printf("Restarting orbit: %s", reason)
        os.Exit(0) // orbit supervisor will restart
    },
)
if err != nil {
    log.Fatal(err)
}
defer creds.Close()

// Use creds.Certificate and creds.SecureHWKey for mTLS or HTTP signing.
signer, _ := creds.SecureHWKey.Signer()
```
