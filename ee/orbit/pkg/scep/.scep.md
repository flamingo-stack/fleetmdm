SCEP client implementation for fetching X.509 certificates via the Simple Certificate Enrollment Protocol, supporting ECC signing keys with RSA envelope decryption.

## Key Components

- **`SigningKey`** — Interface requiring a `Signer() (crypto.Signer, error)` method; allows pluggable private key backends (e.g., ECC hardware keys).
- **`Client`** — Core struct holding SCEP server URL, common name, challenge password, signing key, timeout, logger, and optional TLS/root CA config.
- **`Option`** — Functional option type for configuring a `Client`; available options:
  - `WithSigningKey` — sets the private key signer
  - `WithURL` — sets the SCEP server URL
  - `WithCommonName` — sets the certificate CN
  - `WithChallenge` — sets the SCEP challenge password
  - `WithTimeout` — sets the request timeout (default: 30s)
  - `WithRootCA` — sets a custom root CA for TLS verification
  - `WithLogger` — sets a `zerolog.Logger`
  - `WithExtraExtensions` — adds custom `pkix.Extension` entries to the CSR
  - `Insecure` — disables TLS verification (test use only)
- **`NewClient(opts ...Option) (*Client, error)`** — Validates required fields (`scepURL`, `commonName`, `signingKey`) and returns a configured client.
- **`(*Client).FetchCert(ctx context.Context) (*x509.Certificate, error)`** — Executes the full SCEP enrollment flow: fetches CA cert, generates a CSR signed with the ECC key, wraps it in an ephemeral RSA self-signed cert for SCEP envelope encryption/decryption, sends `PKCSReq`, and returns the issued certificate.
- **`zerologSlogHandler`** — Internal `slog.Handler` adapter that bridges `*slog.Logger` (required by the SCEP library) to a `zerolog.Logger`.
- **`PublicKeysEqual(a, b crypto.PublicKey) (bool, error)`** — Compares two public keys by marshalling both to DER (PKIX) and byte-comparing.

## Usage Example

```go
key := myECCSigningKey{} // implements SigningKey

client, err := scep.NewClient(
    scep.WithURL("https://scep.example.com/scep"),
    scep.WithCommonName("device-001"),
    scep.WithChallenge("s3cr3t"),
    scep.WithSigningKey(key),
    scep.WithLogger(zerolog.New(os.Stderr)),
)
if err != nil {
    log.Fatal(err)
}

cert, err := client.FetchCert(context.Background())
if err != nil {
    log.Fatal(err)
}

fmt.Println("Issued cert CN:", cert.Subject.CommonName)
```

> **Note:** ECC keys are used for CSR signing, but an ephemeral 2048-bit RSA key is generated internally per request to handle SCEP envelope encryption and decryption, which the SCEP protocol requires RSA for.
