Entry point for starting the Sails.js application without the Sails CLI, enabling standard Node.js process invocation for production deployments.

## Key Components

- **`process.chdir(__dirname)`** — Normalizes the working directory to the project root so relative paths resolve correctly regardless of where the process is launched from
- **`sails` / `rc` imports** — Loads the local Sails.js instance and the `rc` utility for parsing `.sailsrc` configuration files
- **`sails.lift(rc('sails'))`** — Bootstraps and starts the Sails.js HTTP server with resolved configuration

## Usage Example

```bash
# Standard start
node app.js

# Via npm script
npm start

# With environment and port overrides
NODE_ENV=production node app.js --port=80 --verbose

# Using a process manager
forever start app.js
```

```javascript
// Ensure local sails is installed before running
// package.json should include sails as a dependency:
// "dependencies": { "sails": "^1.x.x" }

// Then run:
// node app.js
```

> **Note:** Requires a local Sails.js installation (`./node_modules/sails`). If the dependency is missing, run `npm install` in the project root. See the full source at [`app.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/app.js).
