Renders the dashboard "Welcome" page for authenticated users by mapping the route to its corresponding view template.

## Key Components

- **friendlyName** – `'View welcome page'`
- **exits.success** – Routes to `pages/dashboard/welcome` view template on successful execution
- **fn** – Async handler that returns an empty object (no data passed to the view)

## Usage Example

```javascript
// Typically wired up in config/routes.js
'GET /dashboard/welcome': { action: 'view-welcome' }
```
