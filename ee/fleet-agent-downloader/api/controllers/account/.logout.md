Handles user logout by clearing session data, optionally terminating Okta SSO sessions, and broadcasting session changes across open tabs.

## Key Components

- **`delete this.req.session.userId`** – Removes the user identifier from the active session
- **Okta SSO support** – Calls `req.logOut()` when `sails.config.custom.oktaClientSecret` is configured
- **`sails.helpers.broadcastSessionChange`** – Notifies other open browser tabs of the session change via WebSockets
- **`redirect` exit** – Redirects browser clients to `/login` after logout; JSON clients receive a success response

## Usage Example

```javascript
// Called via a route, e.g. POST /logout
// sails.config.routes:
'POST /logout': { action: 'logout' }
```

```javascript
// Client-side fetch (JSON client — no redirect)
await fetch('/logout', {
  method: 'POST',
  headers: { 'Accept': 'application/json' }
});

// Browser form submit (triggers redirect to /login)
<form action="/logout" method="POST">
  <button type="submit">Log out</button>
</form>
```

## Notes

- This action is a **no-op** if the user is already logged out — no error is thrown
- Session garbage collection timing depends on the configured [Sails session store TTL](https://sailsjs.com/docs/reference/configuration/sails-config-session)
