Streams a Fleet MSI installer file to the client as a downloadable attachment from configured cloud storage.

## Key Components

- **`fn`**: Initiates a file download stream using `sails.startDownload` with the configured installer file descriptor and S3-compatible bucket, sets the response content type to `application/x-ms-installer`, and triggers a browser download prompt with the filename `Fleet-installer.msi`.

## Configuration Dependencies

| Config Key | Purpose |
|---|---|
| `sails.config.custom.uploadedInstallerFileDescriptor` | File descriptor referencing the stored MSI |
| `sails.config.uploads.bucket` | S3-compatible bucket containing the installer |

## Usage Example

```javascript
// Invoke from a route handler or controller action
await sails.helpers.downloadFleetInstaller.with({});

// Typical route mapping in config/routes.js
'GET /download-fleet-installer': { action: 'download-fleet-installer' }
```

## Notes

- Returns a **stream reference** (`outputType: 'ref'`) rather than a serialized value — the raw download stream is piped directly to the HTTP response.
- The response headers force a file download (`Content-Disposition: attachment`) named `Fleet-installer.msi`, regardless of the stored filename.
- Requires the Sails.js `skipper` or equivalent upload/download adapter to be configured.
