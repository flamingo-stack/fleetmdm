A Sails.js hook that integrates Okta OIDC-based Single Sign-On (SSO) as a replacement for the built-in authentication mechanism, configuring Express middleware, route overrides, and session-aware request helpers.

## Key Components

### Hook Lifecycle

- **`defaults`** — Sets the default `userModelIdentity` to `'user'`
- **`initialize(cb)`** — Conditionally activates Okta SSO when `oktaClientSecret` is present; validates required config, rewires HTTP middleware order, and creates the `ExpressOIDC` instance
- **`routes.before['/*']`** — Intercepts every non-asset request to extend `req` with Okta-aware auth helpers

### OIDC Middleware (`oktaSSOMiddleware`)

Wraps `ExpressOIDC` from `@okta/oidc-middleware` and guards against Sails.js disabling sessions for static assets (which would cause a 500 error). Skips Okta processing when `req.session` is undefined.

### `_extendReq(req)`

Patches the request object with three methods:

| Method | Description |
|---|---|
| `req.logout()` / `req.logOut()` | Clears the Passport session |
| `req.isAuthenticated()` | Returns `true` if a valid, non-expired Okta token exists |
| `req.isUnauthenticated()` | Inverse of `isAuthenticated()` |

## Usage Example

```javascript
// config/custom.js
module.exports.custom = {
  oktaOrgUrl: 'https://your-org.okta.com/oauth2/default',
  oktaClientId: 'YOUR_CLIENT_ID',
  oktaClientSecret: 'YOUR_CLIENT_SECRET',
  baseUrl: 'https://your-app.com',
};
```

Okta routes registered automatically:

```text
GET  /login                          → Okta login
GET  /authorization-code/callback    → OAuth callback → /entrance/signup-okta-user-or-redirect
GET  /okta/logout                    → Okta logout
GET  /logout                         → Post-logout redirect
```

> **Note:** This hook depends on the Sails.js `orm` hook and will refuse to initialize without it.
