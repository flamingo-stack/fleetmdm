Defines the `User` model for the application, representing an authenticated user with support for email verification, password reset, billing integration, and role-based access control.

## Key Components

| Attribute | Type | Description |
|---|---|---|
| `emailAddress` | `string` | Unique, validated email (max 200 chars) |
| `emailStatus` | `string` | Confirmation state: `unconfirmed`, `change-requested`, or `confirmed` |
| `emailChangeCandidate` | `string` | Pending new email address awaiting confirmation |
| `password` | `string` | Bcrypt-hashed password (`protect: true`) |
| `fullName` | `string` | Display name (max 120 chars) |
| `isSuperAdmin` | `boolean` | Elevated permissions flag |
| `passwordResetToken` / `passwordResetTokenExpiresAt` | `string` / `number` | Single-use token for password recovery with expiry timestamp |
| `emailProofToken` / `emailProofTokenExpiresAt` | `string` / `number` | Token for email verification flows with expiry timestamp |
| `stripeCustomerId` | `string` | Linked Stripe customer ID (`protect: true`) |
| `hasBillingCard` | `boolean` | Whether a default payment method is attached in Stripe |
| `billingCardBrand/Last4/ExpMonth/ExpYear` | `string` | PCI-compliant card metadata sourced from Stripe |
| `tosAcceptedByIp` | `string` | IPv4 address that accepted Terms of Service (KYC compliance) |
| `lastSeenAt` | `number` | Epoch ms timestamp of last authenticated backend interaction |

## Usage Example

```javascript
// Create a new unconfirmed user (e.g. during signup flow)
const newUser = await User.create({
  emailAddress: 'mary.sue@example.com',
  emailStatus: 'unconfirmed',
  password: await sails.helpers.passwords.hashPassword('hunter2'),
  fullName: 'Mary Sue',
  isSuperAdmin: false,
}).fetch();

// Promote to super admin
await User.updateOne({ id: userId }).set({ isSuperAdmin: true });

// Record ToS acceptance
await User.updateOne({ id: userId }).set({
  tosAcceptedByIp: req.ip,
  lastSeenAt: Date.now(),
});
```

> **Security note:** `password` and `stripeCustomerId` are marked `protect: true` — Sails.js will automatically exclude these fields from JSON serialization in API responses.
