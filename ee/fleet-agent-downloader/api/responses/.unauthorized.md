Handles unauthorized access responses by content-negotiating between a 401 JSON response or a session-clearing redirect to the login page.

## Key Components

- **`unauthorized()`** — Custom Sails.js response function that checks `req.wantsJSON` to determine the appropriate response type

## Behavior

| Request Type | Response |
|---|---|
| JSON (API client) | `401 Unauthorized` with no body |
| Browser | Clears `userId` from session, redirects to `/login` |

## Usage Example

```javascript
// In a controller action
return res.unauthorized();

// With actions2 exits
exits: {
  badCombo: {
    description: 'That email address and password combination is not recognized.',
    responseType: 'unauthorized'
  }
}
```
