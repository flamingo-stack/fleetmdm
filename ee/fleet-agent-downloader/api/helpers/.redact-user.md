Synchronous helper that strips all `protect`-flagged attributes from a User record in-place, preparing it for safe publication (e.g., API responses).

## Key Components

- **`fn({ user })`** — Iterates over `User.attributes` and deletes any attribute where `protect: true` is set, mutating the object directly.

## Usage Example

```javascript
// In a Sails.js action or helper
const safeUser = await User.findOne({ id: req.params.id });

sails.helpers.redactUser(safeUser);

// safeUser no longer contains protected fields (e.g., password, passwordResetToken)
res.json(safeUser);
```

> **Note:** This helper is `sync: true` and mutates the `user` object in-place — it does not return a new copy. Ensure you do not need the original protected values before calling it.

## Notes

- Relies on Sails.js model attribute definitions (`User.attributes`) with `protect: true` to determine which fields to remove.
- Any attribute on the `User` model marked `protect: true` will be deleted — no hardcoded field names, so the redaction list stays in sync with the model automatically.
