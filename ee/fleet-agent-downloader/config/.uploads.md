Configures Sails.js file upload settings (`sails.config.uploads`), defining where and how uploaded files are stored. Defaults to local disk via the built-in `skipper-disk` adapter for development use.

## Key Components

- **`module.exports.uploads`** — Exports the uploads configuration object for Sails.js
- **`bucket`** *(commented out)* — S3 bucket name for storing software installers
- **`region`** *(commented out)* — AWS region for the S3 bucket
- **`secret`** *(commented out)* — Secret key for S3 bucket access

## Usage Example

```javascript
// config/uploads.js — enable S3 storage by uncommenting and populating:
module.exports.uploads = {
  bucket: 'my-fleet-installers',
  region: 'us-east-1',
  secret: 'your-s3-secret-key',
};
```

## Notes

- By default, this file leaves all options commented out, relying on Sails.js's built-in local disk storage (`skipper-disk`) — suitable for development.
- For production deployments (e.g., S3, Azure, GridFS), configure the appropriate values in [`config/env/production.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/env/production.js) rather than modifying this file directly.
- Full options reference: [sailsjs.com/config/uploads](https://sailsjs.com/config/uploads)
