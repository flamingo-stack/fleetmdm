Sails.js security configuration module that enables CSRF protection and provides commented-out CORS settings for the FleetMDM application.

## Key Components

- **`csrf`** — Enabled (`true`) to protect all state-changing routes from Cross-Site Request Forgery attacks
- **`cors`** *(commented out)* — Optional CORS configuration supporting `allRoutes`, `allowOrigins`, and `allowCredentials` options

## Usage Example

```javascript
// config/security.js — enable CORS alongside CSRF
module.exports.security = {
  cors: {
    allRoutes: false,
    allowOrigins: 'https://trustedsite.net',
    allowCredentials: false,
  },
  csrf: true
};
```

> **Note:** CSRF protection is active by default. Clients must include a valid CSRF token with all non-GET requests. See the [Sails.js CSRF docs](https://sailsjs.com/docs/concepts/security/csrf) for token delivery patterns.
