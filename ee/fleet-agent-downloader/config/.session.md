Sails.js session configuration file that defines session management settings, including the session secret used to sign and encrypt user cookies.

## Key Components

- **`secret`** – A string used to sign session cookies. Defaults to a placeholder value (`DUMMY_SECRET_REPLACED_IN_PROD`) that must be overridden in production via `config/env/production.js` to avoid invalidating user sessions.
- **`isSessionDisabled`** *(commented out)* – An optional function hook that skips session processing for specific requests (e.g., static assets like images or stylesheets) to improve performance.

## Usage Example

```javascript
// config/session.js
module.exports.session = {
  // Override in production via environment variable
  secret: process.env.SESSION_SECRET || 'DUMMY_SECRET_REPLACED_IN_PROD',

  // Optionally skip sessions for static asset requests
  isSessionDisabled: function (req) {
    return !!req.path.match(req._sails.LOOKS_LIKE_ASSET_RX);
  },
};
```

> ⚠️ **Security Note:** The `secret` value in this file is a placeholder. Always set a strong, unique secret in production using an environment variable or secrets manager. Changing the secret in production will invalidate all existing user sessions.
