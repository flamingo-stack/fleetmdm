Configures Sails.js datastore connections, defining where the application reads and writes data via built-in model methods like `.find()` and `.create()`.

## Key Components

- **`datastores.default`** — The default datastore configuration used by all models unless overridden. Ships with no adapter set, falling back to the built-in `sails-disk` (local filesystem) adapter for development convenience.

## Usage Example

**Switch to MySQL in development:**

```javascript
// config/datastores.js
default: {
  adapter: 'sails-mysql',
  url: 'mysql://user:password@host:3306/mydb',
}
```

**Switch to PostgreSQL:**

```javascript
default: {
  adapter: 'sails-postgresql',
  url: 'postgresql://user:password@host:5432/mydb',
}
```

> **Note:** The default `sails-disk` adapter is not suitable for production. Production datastore settings should be configured in [`config/env/production.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/env/production.js).

## Notes

- To swap adapters, install the package (e.g. `npm install sails-mysql --save`) and set `adapter` + `url` in the `default` block.
- Additional named datastores can be added alongside `default` for models that require isolated database connections.
- See the [SailsJS datastore docs](https://sailsjs.com/config/datastores) and [available adapters](https://sailsjs.com/plugins/databases) for the full list of supported databases.
