Sails.js logging configuration file that sets the minimum log level and transport settings for the application using Winston under the hood.

## Key Components

- **`module.exports.log`** — Sails.js log configuration object accepting a `level` property to control log output verbosity.

## Usage Example

```javascript
// config/log.js
module.exports.log = {
  level: 'info' // Options: silly | verbose | info | debug | warn | error | silent
};
```

## Log Level Precedence

Levels are ordered from lowest to highest verbosity:

```text
silly → verbose → info → debug → warn → error
```

Set `level: 'silent'` to suppress all log output entirely.

## Notes

- Built on [Winston](https://github.com/winstonjs/winston), enabling custom transports and adapters.
- The `level` key is commented out by default — Sails applies its own default when omitted.
- See the [Sails logging docs](https://sailsjs.com/docs/concepts/logging) for advanced transport configuration.
