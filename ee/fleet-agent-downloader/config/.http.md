Configures the underlying HTTP server settings for the Sails.js application, including middleware pipeline ordering and request body parsing.

## Key Components

- **`module.exports.http`** — Main HTTP configuration object consumed by Sails.js
- **`middleware`** — Container for HTTP middleware definitions and execution order
- **`order`** *(commented out)* — Array defining middleware execution sequence (cookieParser → session → bodyParser → compress → poweredBy → router → www → favicon)
- **`bodyParser`** *(commented out)* — Custom multipart request handler using `skipper`

## Usage Example

Uncomment and customize middleware order or body parser as needed:

```javascript
// config/http.js
module.exports.http = {
  middleware: {
    order: [
      'cookieParser',
      'session',
      'bodyParser',
      'compress',
      'poweredBy',
      'router',
      'www',
      'favicon',
    ],

    bodyParser: (function _configureBodyParser() {
      var skipper = require('skipper');
      return skipper({ strict: true });
    })(),
  },
};
```

## Notes

- Middleware only applies to HTTP requests — **not** WebSocket requests
- The default Sails.js middleware stack is used unless explicitly overridden
- For production-specific HTTP settings, see `config/env/production.js`
- Full configuration reference: https://sailsjs.com/config/http
