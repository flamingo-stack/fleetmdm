Global Sails.js ORM configuration file that sets project-wide default settings for all models, including schema enforcement, migration strategy, base attributes, encryption keys, and cascade behavior.

## Key Components

| Setting | Value | Description |
|---|---|---|
| `schema` | `true` | Rejects unrecognized/undefined attributes on write operations |
| `migrate` | `'alter'` | Auto-rebuilds schema on lift (forced to `'safe'` in production) |
| `attributes` | `createdAt`, `updatedAt`, `id` | Auto-managed timestamp and primary key fields on every model |
| `dataEncryptionKeys` | `default: '...'` | DEK used for at-rest encryption on attributes marked `encrypt: true` |
| `cascadeOnDestroy` | `true` | Automatically cleans up orphaned association records on delete |

## Usage Example

These settings apply automatically to every model in the project. Individual models can override them at the top level:

```javascript
// api/models/Device.js — override migrate per-model
module.exports = {
  migrate: 'safe',       // overrides global 'alter' for this model
  schema: true,          // inherits global default (explicit here for clarity)

  attributes: {
    // id, createdAt, updatedAt are injected automatically from global config
    hostname: { type: 'string', required: true },
    secret:   { type: 'string', encrypt: true }, // uses the default DEK
  }
};
```

> **Security note:** The `dataEncryptionKeys.default` value shown is a development placeholder. In production, rotate this key and manage it as a sensitive credential — never commit production keys to source control. See [`config/env/production.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/env/production.js) for production overrides.
