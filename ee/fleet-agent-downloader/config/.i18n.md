Configures internationalization (i18n) settings for the Sails.js application, defining supported locales and translation behavior.

## Key Components

- **`locales`** — Array of supported language codes: English (`en`), Spanish (`es`), French (`fr`), and German (`de`)
- **`defaultLocale`** *(commented out)* — Fallback locale for non-browser clients that don't send an `Accept-Language` header; defaults to `en`
- **`localesDirectory`** *(commented out)* — Path to translation files directory, defaults to `config/locales`

## Usage Example

```javascript
// Enable a default locale and custom locales directory
module.exports.i18n = {
  locales: ['en', 'es', 'fr', 'de'],
  defaultLocale: 'en',
  localesDirectory: 'config/locales'
};
```

Translation strings are stored as JSON files in the locales directory (e.g., `config/locales/en.json`), and Sails automatically selects the appropriate locale based on the incoming `Accept-Language` request header.

## Notes

- Adding a new locale requires both adding the code to the `locales` array and creating a corresponding translation file in the locales directory
- For full configuration options, see the [Sails.js i18n docs](https://sailsjs.com/config/i-18-n)
- Source: [`config/i18n.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/i18n.js)
