Defines the application's route mappings for a Sails.js web application, connecting HTTP endpoints to their corresponding controller actions.

## Key Components

| Route | Method | Target |
|-------|--------|--------|
| `/` | `GET` | `dashboard/view-welcome` |
| `/logout` | `GET` | Redirects → `/api/v1/account/logout` |
| `/api/v1/account/logout` | any | `account/logout` |
| `/entrance/signup-okta-user-or-redirect` | `GET` | `entrance/signup-okta-user-or-redirect` |
| `/download` | `GET` | `download-fleet-installer` |

## Route Groups

- **Webpages** — `GET /` renders the welcome/dashboard view
- **Misc Redirects** — `/logout` is aliased to the API endpoint for convenience
- **API Endpoints** — `/api/v1/*` routes map to actions consumed by the `Cloud.*()` Parasails library or `<ajax-form>` components
- **Downloads** — `/download` triggers the Fleet installer download action

## Usage Example

```javascript
// Extending routes — add a new page and API endpoint
module.exports.routes = {
  // Existing routes...
  'GET /':   { action: 'dashboard/view-welcome' },

  // New page route
  'GET /devices': { action: 'dashboard/view-devices' },

  // New API endpoint (callable via Cloud.createDevice() in Parasails)
  'POST /api/v1/devices/create': { action: 'devices/create-device' },
};
```

> **Note:** Routes prefixed with `/api/v1/` are intended to be called via the [Parasails](https://github.com/mikermcneil/parasails) `Cloud.*()` methods on the frontend.
