Defines Sails.js policy mappings that control access to application routes by running middleware functions before actions execute.

## Key Components

- **`'*': 'is-logged-in'`** — Global policy requiring authentication for all routes by default
- **`'entrance/*': true`** — Bypasses authentication for all entrance routes (e.g., login, signup)
- **`'account/logout': true`** — Bypasses authentication for the logout action

## Usage Example

```javascript
// Extend with custom policies for specific controllers
module.exports.policies = {
  '*': 'is-logged-in',

  // Public routes
  'entrance/*': true,
  'account/logout': true,

  // Admin-only routes
  'admin/*': 'is-admin',

  // API routes with token auth
  'api/*': 'is-api-token-valid',
};
```

## Notes

- Policies run **before** controller actions, making them ideal for authentication and authorization checks
- Setting a policy to `true` grants open access with no restrictions
- Setting a policy to `false` denies all access unconditionally
- Custom policies (e.g., `is-logged-in`) are defined in `api/policies/`

For more details, see the [Sails.js policies documentation](https://sailsjs.com/docs/concepts/policies) or explore the full config in the [repository](https://github.com/flamingo-stack/fleetmdm/blob/main/config/policies.js).
