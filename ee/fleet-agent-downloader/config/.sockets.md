WebSocket server configuration for the Sails.js application, defining realtime communication settings including transport protocols, connection lifecycle hooks, and session cookie options.

## Key Components

- **`transports`** — (commented out) Restricts allowed socket protocols; must match client-side `io.sails.transports` to function correctly
- **`beforeConnect`** — (commented out) Hook executed before each new socket handshake; can accept or reject incoming connections
- **`afterDisconnect`** — (commented out) Hook executed after a socket disconnects; useful for cleanup logic
- **`grant3rdPartyCookie`** — (commented out) Enables a `GET /__getcookie` route to set an HTTP-only session cookie for cross-origin scenarios

## Usage Example

```javascript
// config/sockets.js — enabling WebSocket-only transport with connection hooks
module.exports.sockets = {

  transports: ['websocket'],

  beforeConnect: function(handshake, proceed) {
    // Reject unauthenticated connections
    if (!handshake.headers.authorization) {
      return proceed(undefined, false);
    }
    return proceed(undefined, true);
  },

  afterDisconnect: function(session, socket, done) {
    // Clean up session data on disconnect
    sails.log.info('Socket disconnected:', socket.id);
    return done();
  },

};
```

> **Note:** If you change `transports` here, you **must** update `io.sails.transports` in your client-side code to match. Mismatched transport arrays will silently break socket connectivity. See the [Sails.js sockets config docs](https://sailsjs.com/config/sockets) for all available options.
