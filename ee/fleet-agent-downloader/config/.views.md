Sails.js view engine configuration file that sets rendering options for server-sent views, including the default layout template path.

## Key Components

| Option | Value | Description |
|--------|-------|-------------|
| `layout` | `'layouts/layout'` | Default layout file used to wrap all views |
| `extension` *(commented out)* | `'ejs'` | File extension for view templates |

## Usage Example

```javascript
// In a Sails.js action, render a view using the configured layout:
module.exports = {
  friendlyName: 'Homepage',
  fn: async function (inputs, exits) {
    // Renders views/homepage.ejs wrapped in views/layouts/layout.ejs
    return exits.success();
  }
};
```

To disable the global layout for a specific view:

```javascript
return res.view('standalone-page', { layout: false });
```

To override with a different layout:

```javascript
return res.view('admin/dashboard', { layout: 'layouts/admin-layout' });
```

## Notes

- Layouts are only supported with the built-in **EJS** view engine
- The `extension` option is commented out, defaulting to `ejs`
- Set `layout: false` to disable layouts entirely across the app
- Full reference: [sailsjs.com/config/views](https://sailsjs.com/config/views)
