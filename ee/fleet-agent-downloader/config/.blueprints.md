Sails.js Blueprint API configuration file that disables automatic route exposure for the application.

## Key Components

| Option | Value | Description |
|--------|-------|-------------|
| `rest` | `false` | Disables auto-generated RESTful routes for models |
| `shortcuts` | `false` | Disables CRUD shortcut routes via GET requests |

## Usage Example

```javascript
// config/blueprints.js
module.exports.blueprints = {
  rest: false,      // No auto: GET /model, POST /model, etc.
  shortcuts: false, // No auto: GET /model/create, GET /model/destroy, etc.
};
```

With both options disabled, all routes must be explicitly defined — a common security practice for production applications, preventing unintended data exposure through auto-generated endpoints.

> **Reference:** [Sails.js Blueprint API Docs](https://sailsjs.com/docs/reference/blueprint-api)
