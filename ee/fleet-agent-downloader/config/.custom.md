Defines one-off application settings for the Sails.js app via `sails.config.custom`, covering URLs, token lifetimes, email, and billing configuration.

## Key Components

| Setting | Value | Purpose |
|---|---|---|
| `baseUrl` | `http://localhost:1337` | Base URL for building dynamic links (emails, webhooks, uploads) |
| `platformCopyrightYear` | `2024` | Copyright year displayed throughout the app |
| `passwordResetTokenTTL` | 24 hours | Expiry for password reset tokens |
| `emailProofTokenTTL` | 24 hours | Expiry for email verification tokens |
| `rememberMeCookieMaxAge` | 30 days | Session cookie lifespan when "Remember Me" is checked |
| `fromEmailAddress` | `noreply@example.com` | Sender address for all outgoing automated emails |
| `internalEmailAddress` | `support+development@example.com` | Recipient for support messages; also used as GDPR data protection officer contact |
| `verifyEmailAddresses` | `false` | Toggle email ownership verification on signup/email change |

## Commented-Out Integrations

- **Sendgrid** (`sendgridSecret`) — enable for automated email delivery
- **Stripe** (`stripePublishableKey`, `stripeSecret`) — enable for billing/payment features

## Usage Example

```javascript
// Access custom config anywhere in your Sails app
sails.config.custom.baseUrl;
// → 'http://localhost:1337'

// Example: building a password reset link in a helper or action
const resetUrl = `${sails.config.custom.baseUrl}/reset-password?token=${token}`;

// Example: sending an email using the configured sender
await sails.helpers.sendTemplateEmail.with({
  to: user.emailAddress,
  from: sails.config.custom.fromEmailAddress,
  fromName: sails.config.custom.fromName,
  subject: 'Reset your password',
  template: 'email-reset-password',
});
```
