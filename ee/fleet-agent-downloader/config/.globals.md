Configures which global variables Sails.js automatically exposes throughout the application at startup.

## Key Components

| Option | Value | Description |
|--------|-------|-------------|
| `_` | `@sailshq/lodash` | Exposes Lodash as the global `_` variable |
| `async` | `false` | Disables the legacy `async` npm package as a global |
| `models` | `true` | Exposes all Sails models as global variables |
| `sails` | `true` | Exposes the Sails app instance as the global `sails` object |

## Usage Example

Once configured, globals are available anywhere in the app without `require`:

```javascript
// Access Lodash globally
const result = _.map([1, 2, 3], (n) => n * 2);

// Access a model globally (e.g., User model)
const users = await User.find({ active: true });

// Access the Sails instance globally
sails.log.info('App running in', sails.config.environment);
```

> **Note:** The `async: false` setting has no impact on native `async/await` syntax — use `await` freely throughout the codebase.
