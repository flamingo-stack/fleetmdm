Grunt task configuration for automatically injecting `<script>` and `<link>` tags into HTML and EJS view files during asset pipeline processing.

## Key Components

Eight named task targets organized into two groups:

**JavaScript targets** — inject `<script>` tags between `<!--SCRIPTS-->` / `<!--SCRIPTS END-->` delimiters:

| Target | Source Files |
|---|---|
| `devJs` | Individual JS files from `pipeline.jsFilesToInject` |
| `devJsBuild` | Same as `devJs` (with optional `relative` path support) |
| `prodJs` | `.tmp/public/min/production.min.js` |
| `prodJsBuild` | `.tmp/public/dist/*.js` |

**Stylesheet targets** — inject `<link rel="stylesheet">` tags between `<!--STYLES-->` / `<!--STYLES END-->` delimiters:

| Target | Source Files |
|---|---|
| `devStyles` | Individual CSS files from `pipeline.cssFilesToInject` |
| `devStylesBuild` | Same as `devStyles` (with optional `relative` path support) |
| `prodStyles` | `.tmp/public/min/production.min.css` |
| `prodStylesBuild` | `.tmp/public/dist/*.css` |

All targets apply to `.tmp/public/**/*.html`, `views/**/*.html`, and `views/**/*.ejs`.

## Usage Example

Add the delimiter comments to your HTML/EJS templates, then the linker fills them in at build time:

```html
<!-- In views/layout.ejs -->
<!--STYLES-->
<!-- stylesheet <link> tags are injected here -->
<!--STYLES END-->

<!--SCRIPTS-->
<!-- script <script> tags are injected here -->
<!--SCRIPTS END-->
```

```bash
# Development (individual files)
grunt sails-linker:devStyles
grunt sails-linker:devJs

# Production (minified bundle)
grunt sails-linker:prodStyles
grunt sails-linker:prodJs
```

> **PhoneGap/CDN builds:** Uncomment `relative: true` in the `devJsBuild`, `prodJsBuild`, `devStylesBuild`, or `prodStylesBuild` targets to use relative asset paths. Note this may break custom font URLs.
