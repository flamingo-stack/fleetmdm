Configures the `grunt-contrib-clean` task to remove generated files and directories during development and production build workflows.

## Key Components

- **`dev`** — Cleans the `.tmp/public/` directory used during development
- **`build`** — Removes the entire `www/` output directory before a fresh build
- **`afterBuildProd`** — Cleans up intermediate production build artifacts (concat, min, hash, js, styles, templates, dependencies) from `www/` after production compilation

## Usage Example

```javascript
// This config is automatically loaded by Sails' Grunt pipeline.
// Invoke specific targets via Grunt CLI:

// Clean dev temp files
grunt.task.run('clean:dev');

// Clean full build output
grunt.task.run('clean:build');

// Remove intermediate files after production build
grunt.task.run('clean:afterBuildProd');
```

To use a custom version of this plugin, install it manually:

```bash
npm install grunt-contrib-clean --save-dev --save-exact
```

Then load it explicitly in the file by uncommenting:

```javascript
grunt.loadNpmTasks('grunt-contrib-clean');
```

## Notes

- This plugin is pre-loaded by the Sails default asset pipeline — no manual `loadNpmTasks` call is needed unless replacing the built-in version.
- Deleting this file entirely removes the clean task from the pipeline.
