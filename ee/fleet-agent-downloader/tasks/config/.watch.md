Configures the Grunt `watch` task to monitor asset files and trigger sync/link tasks automatically when changes are detected.

## Key Components

- **`watch.assets.files`** — Glob patterns defining which files to monitor: everything under `assets/**/*` and `tasks/pipeline.js`, excluding `node_modules`
- **`watch.assets.tasks`** — Ordered list of Grunt tasks triggered on file change: `syncAssets` then `linkAssets`

## Usage Example

```javascript
// This config runs automatically as part of the Sails.js default asset pipeline.
// To trigger manually via CLI:
// $ grunt watch

// To swap in grunt-contrib-watch as a local dependency instead:
// 1. Install the plugin:
// $ npm install grunt-contrib-watch --save-dev --save-exact

// 2. Load it explicitly inside this file:
grunt.loadNpmTasks('grunt-contrib-watch');
```

## Notes

- This task is part of the default Sails.js asset pipeline and is loaded automatically — no manual `loadNpmTasks` call is needed unless replacing it with a custom version.
- Removing this file disables live asset watching entirely.
