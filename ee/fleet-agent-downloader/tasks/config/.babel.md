Configures the Grunt Babel transpilation task for the Sails.js asset pipeline, converting ES6+ JavaScript to broader browser-compatible code during the build process.

## Key Components

- **`babel.dist`** — Main Grunt task configuration targeting `.tmp/public/js/**/*.js` for transpilation
- **`presets`** — Uses `babel-preset-env` from `sails-hook-grunt` to determine transpilation targets
- **`files`** — Expands and transpiles all JS files under `.tmp/public/js/`, writing output back to the same directory

## Usage Example

This task runs automatically as part of the default Sails asset pipeline. To use a custom `grunt-babel` version instead:

```bash
npm install grunt-babel --save-dev --save-exact
```

Then uncomment the manual loader in the config file:

```javascript
// Load Grunt plugin from the node_modules/ folder.
grunt.loadNpmTasks('grunt-babel');
```

To trigger the task manually:

```bash
grunt babel
```

## Notes

- Output is written **in-place** back to `.tmp/public`, overwriting the original JS files with transpiled versions
- The task is auto-loaded via `sails-hook-grunt` — no manual `loadNpmTasks` call is needed unless swapping to a custom plugin
- Remove this file entirely to opt out of Babel transpilation in the pipeline
