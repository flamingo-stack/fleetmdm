Configures the Grunt `concat` task to merge JavaScript and CSS asset files into single monolithic files as an intermediate build step before minification.

## Key Components

- **`js` target** — Concatenates all JS files listed in `pipeline.jsFilesToInject` into `.tmp/public/concat/production.js`
- **`css` target** — Concatenates all CSS files listed in `pipeline.cssFilesToInject` into `.tmp/public/concat/production.css`
- **`../pipeline`** — Source of truth for which files are included; edit that file to add/remove assets

## Usage Example

```javascript
// tasks/pipeline.js — control which files get concatenated
var jsFilesToInject = [
  'js/dependencies/**/*.js',
  'js/**/*.js'
];

var cssFilesToInject = [
  'styles/**/*.css'
];
```

```bash
# Run the concat task directly
grunt concat

# Or via the full build pipeline (concat → uglify/cssmin)
grunt build
```

## Notes

- Output files are written to `.tmp/public/concat/` and consumed by downstream tasks (`uglify`, `cssmin`)
- The plugin (`grunt-contrib-concat`) is pre-loaded by Sails; no manual `loadNpmTasks` call is needed unless you swap it for a custom version
- To use a custom concat plugin, install it locally and uncomment `grunt.loadNpmTasks('grunt-contrib-concat')` inside this file
