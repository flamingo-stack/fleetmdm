Configures the Grunt `cssmin` task for minifying concatenated CSS assets in the Sails.js production build pipeline.

## Key Components

- **`cssmin` task config** — Reads the concatenated `production.css` from `.tmp/public/concat/` and outputs a minified `production.min.css` to `.tmp/public/min/`.

## Usage Example

```javascript
// This task runs automatically as part of the Sails asset pipeline.
// To trigger manually:
grunt cssmin

// Input:  .tmp/public/concat/production.css
// Output: .tmp/public/min/production.min.css
```

To use a custom version of the plugin, install it and load it manually:

```bash
npm install grunt-contrib-cssmin --save-dev --save-exact
```

```javascript
// In cssmin.js, uncomment:
grunt.loadNpmTasks('grunt-contrib-cssmin');
```

## Notes

- Runs **after** the `concat` task, which assembles styles from `assets/styles/` (including any LESS-compiled output from `importer.less`).
- The plugin is pre-loaded by Sails' default pipeline — no manual `loadNpmTasks` call is needed unless replacing it with a custom version.
- Remove this file entirely to opt out of CSS minification in production builds.
