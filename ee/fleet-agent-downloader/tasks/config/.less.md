Grunt task configuration that compiles LESS files into CSS stylesheets as part of the Sails.js asset pipeline.

## Key Components

- **`less.dev`** — Task target that processes `assets/styles/importer.less` and outputs compiled CSS to `.tmp/public/styles/`

## Configuration Details

| Option | Value |
|--------|-------|
| Source directory | `assets/styles/` |
| Entry file | `importer.less` |
| Output directory | `.tmp/public/styles/` |
| Output extension | `.css` |

## Usage Example

```javascript
// This task is auto-loaded by the Sails.js pipeline.
// To use a custom version, install the plugin manually:
```

```bash
npm install grunt-contrib-less --save-dev --save-exact
```

Then uncomment the manual loader in the file:

```javascript
// grunt.loadNpmTasks('grunt-contrib-less');
```

The `importer.less` entry point pattern lets you control the order of LESS imports in a single file, keeping compilation predictable. Remove this file entirely to opt out of LESS compilation for the project.
