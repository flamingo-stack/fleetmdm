Configures the Grunt `sync` task to mirror assets from the `assets/` directory to `.tmp/public/` during development, excluding CoffeeScript and Less source files.

## Key Components

- **`sync.dev`** — Grunt task configuration that copies all files matching `**/*.!(coffee|less)` from `./assets` to `.tmp/public`, overwriting any existing content.

## Usage Example

```javascript
// Registered automatically in Sails' default asset pipeline.
// To use a custom version, install the plugin manually:
// npm install grunt-sync --save-dev --save-exact

// Then load it explicitly in your Gruntfile:
grunt.loadNpmTasks('grunt-sync');
```

The `!(coffee|less)` glob negation ensures raw source files (`.coffee`, `.less`) are excluded — only their compiled outputs are served. This task runs as part of the default Sails development pipeline and can be removed or replaced by deleting/modifying this file.

> **Note:** The `grunt-sync` plugin is pre-loaded by Sails' default pipeline. Manual loading is only needed if you replace it with a custom version.

For more details, see the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/config/sync.js) or the source at [`tasks/config/sync.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/config/sync.js).
