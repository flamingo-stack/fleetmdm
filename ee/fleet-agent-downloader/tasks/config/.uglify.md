Configures the Grunt UglifyES task to minify concatenated client-side JavaScript for production builds within the Sails.js asset pipeline.

## Key Components

- **`dist` target** — Takes `.tmp/public/concat/production.js` as input and outputs the minified file to `.tmp/public/min/production.min.js`
- **`mangle.reserved`** — Prevents renaming critical global identifiers (`AsyncFunction`, `SailsSocket`, `Promise`, `File`, `FileList`, `FormData`, `Location`, `RttcRefPlaceholder`)
- **`keep_fnames`** — Preserves function names in both `mangle` and `compress` stages to avoid runtime errors in code that relies on `Function.name`

## Usage Example

This task runs automatically as part of the Sails.js production build pipeline. To invoke it directly:

```bash
grunt uglify
```

To swap in the standard `grunt-contrib-uglify` plugin instead of UglifyES:

```bash
npm install grunt-contrib-uglify --save-dev --save-exact
```

Then uncomment the loader in this file:

```javascript
grunt.loadNpmTasks('grunt-contrib-uglify');
```

## Notes

- This file is part of the default Sails.js asset pipeline and is auto-loaded — no manual `loadNpmTasks` call is needed for UglifyES.
- Removing this file disables JS minification entirely for production builds.
- The reserved name list should be extended if your app introduces additional global constructors or browser APIs that must not be mangled.
