Grunt task configuration for copying static assets between directories during development and production builds.

## Key Components

- **`dev`** — Copies all non-CoffeeScript/Less files from `./assets` to `.tmp/public` during development
- **`build`** — Copies all compiled assets from `.tmp/public` to the `www` output directory for production
- **`beforeLinkBuildProd`** — Copies hashed assets from `.tmp/public/hash` to `.tmp/public/dist` before production linking

## Usage Example

```javascript
// tasks/config/copy.js is auto-loaded by Sails' default Grunt pipeline.
// To use a custom version, install the plugin manually:
// npm install grunt-contrib-copy --save-dev --save-exact

// Then load it explicitly in your Gruntfile:
grunt.loadNpmTasks('grunt-contrib-copy');
```

The task runs as part of the standard Sails.js asset pipeline — no manual invocation is needed for typical use.

## Notes

- Excludes `.coffee` and `.less` source files from the `dev` copy using a glob negation pattern (`**/*.!(coffee|less)`)
- The `build` target is used in production to finalize the `www` directory
- The plugin is pre-loaded by Sails; only override with `grunt.loadNpmTasks` if swapping to a custom version
