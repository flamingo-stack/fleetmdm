Configures the `grunt-hash` Grunt task to implement cache-busting for minified CSS and JavaScript assets by appending SHA1-based content hashes to filenames.

## Key Components

- **`hash` Grunt config** — Registers the `hash` task with options for JS and CSS targets
- **`hashFunction`** — Custom SHA1 hash generator using Node's `crypto` module; throws a descriptive error if `source` or `encoding` are falsy
- **`js` target** — Processes `.tmp/public/min/*.js` → `.tmp/public/hash/`
- **`css` target** — Processes `.tmp/public/min/*.css` → `.tmp/public/hash/`

## Options

| Option | Value | Description |
|--------|-------|-------------|
| `hashLength` | `8` | Length of the appended hash suffix |
| `flatten` | `false` | Preserves directory structure in output |
| `mapping` / `srcBasePath` / `destBasePath` | `''` | Left empty for default path handling |

## Usage Example

This task runs automatically as part of the Sails.js production asset pipeline. To use a custom version instead:

```bash
npm install grunt-hash --save-dev --save-exact
```

Then manually load the plugin in this file:

```javascript
// Uncomment to load a custom grunt-hash version
grunt.loadNpmTasks('grunt-hash');
```

The hash task should be registered in your Grunt pipeline after minification:

```javascript
// In your Gruntfile or register task config
grunt.registerTask('prod', ['uglify', 'cssmin', 'hash']);
```
