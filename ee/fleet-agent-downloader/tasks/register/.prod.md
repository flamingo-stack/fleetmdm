Defines the Grunt task pipeline executed when the Sails.js application runs in a production environment (`NODE_ENV=production`), optimizing assets for performance.

## Key Components

- **`prod` task** — Registered Grunt task that chains the following pipeline steps in order:
  - `polyfill:prod` — Transpiles modern JavaScript for broader browser compatibility
  - `compileAssets` — Compiles raw assets (LESS, JSX, etc.)
  - `babel` — Runs Babel transpilation on compiled assets
  - `concat` — Concatenates asset files
  - `uglify` — Minifies JavaScript
  - `cssmin` — Minifies CSS
  - `sails-linker:prodJs` — Injects minified JS script tags into HTML templates
  - `sails-linker:prodStyles` — Injects minified CSS link tags into HTML templates

## Usage Example

```bash
# Triggered automatically when lifting Sails in production
NODE_ENV=production node app.js

# Or run the Grunt task directly
grunt prod
```

## Notes

- Transpilation steps (`polyfill:prod` and `babel`) can be removed if targeting modern environments only, though this is not recommended
- This task replaces the `default` Grunt task in production; for development equivalents see `tasks/register/default.js`
