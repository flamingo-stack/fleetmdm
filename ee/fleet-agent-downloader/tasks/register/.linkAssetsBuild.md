Registers a Grunt task named `linkAssetsBuild` that runs the Sails.js asset linker for JavaScript and CSS during build-time compilation.

## Key Components

- **`linkAssetsBuild`** — Composite Grunt task that sequentially executes:
  - `sails-linker:devJsBuild` — Injects compiled JS asset tags into HTML/view templates
  - `sails-linker:devStylesBuild` — Injects compiled CSS asset tags into HTML/view templates

## Usage Example

```javascript
// Invoke from Grunt CLI
// grunt linkAssetsBuild

// Or register as a dependency in another task
grunt.registerTask('build', [
  'compileAssets',
  'linkAssetsBuild', // Links built JS/CSS into templates
]);
```

## Notes

- This task is the **build variant** of the asset linking workflow, intended for compiled/minified assets rather than raw source files.
- Pair with `linkAssets` (dev) for the uncompiled development equivalent.
- Follows the standard [Sails.js task anatomy](https://sailsjs.com/anatomy/tasks/register/link-assets-build.js).
- Defined in [`tasks/register/linkAssetsBuild.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/linkAssetsBuild.js)
