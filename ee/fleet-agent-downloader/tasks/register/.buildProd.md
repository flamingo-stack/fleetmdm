Registers the `buildProd` Grunt task, which defines the full production asset pipeline executed when running `sails www` in a production environment (`NODE_ENV=production`).

## Key Components

- **`buildProd` task** — Ordered sequence of Grunt sub-tasks for optimized production builds

| Step | Task | Purpose |
|------|------|---------|
| 1 | `polyfill:prod` | Transpile modern JS for broader browser support |
| 2 | `compileAssets` | Compile raw assets (LESS, JST, etc.) |
| 3 | `babel` | Additional ES6+ transpilation |
| 4 | `concat` | Concatenate JS/CSS files |
| 5 | `uglify` | Minify JavaScript |
| 6 | `cssmin` | Minify CSS |
| 7 | `hash` | Cache-busting via content hashing |
| 8 | `copy:beforeLinkBuildProd` | Prep files for prettier post-hash URLs |
| 9 | `linkAssetsBuildProd` | Inject hashed asset links into views |
| 10 | `clean:build` | Remove intermediate build artifacts |
| 11 | `copy:build` | Copy final assets to output directory |
| 12 | `clean:afterBuildProd` | Final cleanup of temporary files |

## Usage Example

```bash
# Trigger buildProd automatically via Sails CLI
NODE_ENV=production sails www
```

```javascript
// Or invoke directly within a Gruntfile context
grunt.task.run('buildProd');
```

> **Note:** Removing `polyfill:prod` or `babel` from the task list will skip transpilation — not recommended for production environments targeting broad browser compatibility.
