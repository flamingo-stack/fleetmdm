Registers the `syncAssets` Grunt task, which compiles LESS files and syncs static assets during development.

## Key Components

- **`syncAssets`** — Composite Grunt task that runs two subtasks in sequence:
  - `less:dev` — Compiles LESS stylesheets for the development environment
  - `sync:dev` — Syncs static assets to the build/public directory

## Usage Example

```javascript
// Invoked via Grunt CLI during development
// grunt syncAssets

// Or referenced in another Grunt task chain
grunt.registerTask('default', ['syncAssets', 'watch']);
```

## Notes

- Defined as part of the Sails.js asset pipeline convention
- Intended for development use only; production builds typically use a separate pipeline
- For full configuration details, see the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/register/sync-assets.js) or the source at [`tasks/register/syncAssets.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/syncAssets.js)
