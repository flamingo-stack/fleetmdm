Registers a Grunt task that links production-built JavaScript and CSS assets into HTML templates using the `sails-linker` plugin.

## Key Components

- **`linkAssetsBuildProd`** — Grunt task that runs two sub-tasks sequentially:
  - `sails-linker:prodJsBuild` — Injects production JS build references
  - `sails-linker:prodStylesBuild` — Injects production CSS build references

## Usage Example

```javascript
// Loaded automatically by Grunt in a Sails.js project.
// To run manually:
grunt.task.run('linkAssetsBuildProd');

// Or from the CLI:
// grunt linkAssetsBuildProd
```

## Notes

- Intended for **production builds** only — use `linkAssets` or `linkAssetsBuild` tasks for development workflows.
- Relies on `sails-linker` configuration defined elsewhere in the Grunt pipeline (typically `tasks/config/sails-linker.js`).
- Part of the standard [Sails.js asset pipeline](https://sailsjs.com/anatomy/tasks/register/link-assets-build-prod.js).
