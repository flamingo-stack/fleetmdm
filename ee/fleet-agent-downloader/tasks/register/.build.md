Registers the `build` Grunt task, which compiles and prepares frontend assets for production output when running `sails www` or `grunt build`.

## Key Components

- **`build` task** — A Grunt task sequence that orchestrates the full asset build pipeline

**Task sequence:**
1. `compileAssets` — Compiles raw source assets (CSS, JS, etc.)
2. `linkAssetsBuild` — Injects asset links into layout files
3. `clean:build` — Removes stale files from the build directory
4. `copy:build` — Copies compiled assets to the output directory

> **Optional steps** (commented out): `polyfill:dev` and `babel` can be uncommented to enable transpilation for broader browser compatibility during development.

## Usage Example

```bash
# Trigger via Sails CLI
sails www

# Or directly via Grunt
grunt build
```

```javascript
// tasks/register/build.js is auto-loaded by Grunt; no manual require needed.
// To enable transpilation, uncomment in the task array:
grunt.registerTask('build', [
  'polyfill:dev',   // uncomment for polyfills
  'compileAssets',
  'babel',          // uncomment for Babel transpilation
  'linkAssetsBuild',
  'clean:build',
  'copy:build'
]);
```
