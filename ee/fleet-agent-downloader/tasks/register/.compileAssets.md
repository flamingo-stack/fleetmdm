Registers a Grunt task named `compileAssets` that orchestrates the asset compilation pipeline for development builds by chaining three sub-tasks in sequence.

## Key Components

- **`compileAssets` task** — Composite Grunt task that runs `clean:dev`, `less:dev`, and `copy:dev` in order

## Task Sequence

| Step | Task | Purpose |
|------|------|---------|
| 1 | `clean:dev` | Removes previously compiled assets from the dev output directory |
| 2 | `less:dev` | Compiles LESS stylesheets into CSS |
| 3 | `copy:dev` | Copies static assets to the dev output directory |

## Usage Example

```bash
# Run via Grunt CLI directly
grunt compileAssets
```

```javascript
// Referenced in a parent Grunt task (e.g., default or syncAssets)
grunt.registerTask('default', [
  'compileAssets',
  'linkAssets',
]);
```

## Notes

- This task is part of the standard [Sails.js](https://sailsjs.com) Grunt asset pipeline
- Typically invoked automatically during `sails lift` or `grunt default` rather than called directly
- For full pipeline details, see the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/register/compile-assets.js) or browse the task source at [`tasks/register/compileAssets.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/compileAssets.js)
