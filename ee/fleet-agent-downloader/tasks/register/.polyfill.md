Registers two Grunt tasks that inject the Babel polyfill into the asset pipeline for production and development environments.

## Key Components

- **`polyfill:prod`** — Prepends the Babel polyfill to the top of the JS concatenation list (`concat.js.src`) used in production builds.
- **`polyfill:dev`** — Adds the Babel polyfill to the file copy task and ensures it is linked first in the `sails-linker` dev script injection, serving it from `.tmp/public/polyfill/`.

## Usage Example

```javascript
// Registered automatically by Sails/Grunt pipeline.
// Invoked within your Gruntfile task sequences, e.g.:

grunt.registerTask('build', [
  'polyfill:prod',
  'concat',
  // ...other tasks
]);

grunt.registerTask('compileAssets', [
  'polyfill:dev',
  'copy:dev',
  'sails-linker:devJs',
  // ...other tasks
]);
```

## Notes

- Relies on `sails-hook-grunt` to resolve the path to `babel-polyfill`. Ensure `sails-hook-grunt` is installed as a dependency.
- In dev mode, the polyfill is copied to `.tmp/public/polyfill/polyfill.min.js` and prepended to every glob pattern configured under `sails-linker.devJs.files`, guaranteeing it loads before application scripts.
