Registers the default Grunt task sequence executed when running `grunt` or starting Sails in development mode via `sails lift`.

## Key Components

- **`default` task** — Grunt task chain that compiles assets, links them, and starts the file watcher for live reloading during development.

## Task Sequence

| Step | Task | Description |
|------|------|-------------|
| 1 | `compileAssets` | Compiles LESS, copies static assets, etc. |
| 2 | `linkAssets` | Injects asset references into layout files |
| 3 | `watch` | Watches for file changes and re-runs tasks |

> **Optional:** Uncomment `polyfill:dev` or `babel` (before/after `compileAssets`) to enable JS transpilation for broader browser compatibility during development.

## Usage Example

```bash
# Triggered automatically on sails lift (development)
sails lift

# Or run directly via Grunt
grunt
```
