Registers a Grunt task that links JavaScript and CSS assets during development using the `sails-linker` plugin.

## Key Components

- **`linkAssets`** — Grunt task that runs two sub-tasks sequentially:
  - `sails-linker:devJs` — Injects development JavaScript files into HTML templates
  - `sails-linker:devStyles` — Injects development CSS stylesheets into HTML templates

## Usage Example

```javascript
// Invoked automatically by Grunt during development builds.
// Can also be run manually via CLI:
// grunt linkAssets
```

## Notes

- Part of the Sails.js asset pipeline in `tasks/register/`
- Relies on `sails-linker` configuration defined in `tasks/config/sails-linker.js`
- Typically called as part of the broader `default` or `compileAssets` task chain

For more details, see the [Sails.js documentation](https://sailsjs.com/anatomy/tasks/register/link-assets.js) or browse the source at [`tasks/register/linkAssets.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/linkAssets.js).
