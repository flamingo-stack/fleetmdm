Grunt build system entry point for the Sails.js application. It bootstraps the Grunt task runner by loading task configurations and registrations from the `tasks/` directory.

## Key Components

- **`loadGruntTasks`** — Utility from `sails-hook-grunt` that auto-discovers and loads all Grunt task configs from `tasks/config/` and task registrations from `tasks/register/`

## Usage Example

```bash
# Run default Grunt tasks
grunt

# Tasks are also triggered automatically on
sails lift
```

> ⚠️ This file should not be modified directly. Customize build behavior in the `tasks/` directory instead.

For more details, see the [Sails.js Gruntfile anatomy](https://sailsjs.com/anatomy/Gruntfile.js) or browse the tasks directory in the [repository](https://github.com/flamingo-stack/fleetmdm/blob/main/Gruntfile.js).
