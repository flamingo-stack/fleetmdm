Configures the auto-generated browser SDK ("Cloud") by registering client-side method definitions that map to server-side routes and actions.

## Key Components

**`Cloud.setup()`** — Initializes the SDK with a `methods` map containing three endpoint definitions:

| Method | Verb | URL |
|--------|------|-----|
| `logout` | `GET` | `/api/v1/account/logout` |
| `signupOktaUserOrRedirect` | `GET` | `/entrance/signup-okta-user-or-redirect` |
| `downloadFleetInstaller` | `GET` | `/download-fleet-installer` |

## Usage Example

Once initialized, these methods are callable directly from browser-side JavaScript:

```javascript
// Log the current user out
await Cloud.logout();

// Redirect or sign up via Okta SSO
await Cloud.signupOktaUserOrRedirect();

// Trigger a Fleet installer download
await Cloud.downloadFleetInstaller();
```
