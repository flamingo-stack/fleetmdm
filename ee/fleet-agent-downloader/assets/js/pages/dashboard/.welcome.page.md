Registers the `welcome` page component using the Parasails framework, providing the scaffolding for the Fleet MDM welcome/onboarding screen.

## Key Components

- **`data`** — Reactive state object for the welcome page (currently empty, ready for extension)
- **`beforeMount`** — Lifecycle hook executed before the component is mounted to the DOM
- **`mounted`** — Async lifecycle hook executed after the component is mounted
- **`methods`** — Container for page-specific event handlers and actions (currently empty)

## Usage Example

```javascript
// Extend the welcome page with data and methods
parasails.registerPage('welcome', {
  data: {
    currentStep: 1,
    userName: ''
  },

  mounted: async function() {
    this.userName = await fetchCurrentUser();
  },

  methods: {
    nextStep() {
      this.currentStep += 1;
    }
  }
});
```

## Notes

- This file is a minimal scaffold — all sections (`data`, lifecycle hooks, `methods`) are intentionally empty and ready for feature implementation.
- Follows the standard Parasails page registration pattern used throughout the Fleet MDM frontend.
- The `mounted` hook is `async`, supporting `await`-based data fetching on page load.
