Parasails page component for the **edit password** form, handling client-side validation and form submission for updating a user's account password.

## Key Components

- **`formData`** — Holds password field values (`password`, `confirmPassword`)
- **`formRules`** — Enforces `required` on both fields and `sameAs: 'password'` to ensure confirmation matches
- **`formErrors`** — Tracks client-side validation errors per field
- **`cloudError`** — Captures server-side error responses
- **`syncing`** — Loading/submission state flag
- **`submittedForm()`** — Redirects to `/account` on successful password update, keeping the spinner active during navigation

## Usage Example

```javascript
// Form submission flow
submittedForm: async function() {
  this.syncing = true;       // Keep spinner active during redirect
  window.location = '/account';  // Navigate to account page on success
}
```

```javascript
// Validation rules ensure passwords match before submission
formRules: {
  password: { required: true },
  confirmPassword: { required: true, sameAs: 'password' },
}
```

## Notes

- Uses the [parasails](https://github.com/mikermcneil/parasails) framework for Vue-based page registration
- Client-side validation runs before any server call; `formErrors` prevents submission if rules fail
- The `syncing` flag intentionally stays `true` after form submission to avoid a flash of the idle UI during page navigation
