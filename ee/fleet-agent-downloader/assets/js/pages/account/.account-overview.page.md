Registers the `account-overview` parasails page, managing billing card state and modal interactions for the account overview UI.

## Key Components

**Data Properties**
- `isBillingEnabled` — set to `true` when a Stripe publishable key is present
- `hasBillingCard` — derived flag indicating whether the user has a saved billing card
- `modal` — controls which modal is currently visible (`'update-billing-card'` | `'remove-billing-card'` | `''`)
- `formData`, `formRules`, `formErrors`, `cloudError`, `syncing` — shared `<ajax-form>` state

**Lifecycle Hooks**
- `beforeMount` — merges `window.SAILS_LOCALS`, sets `isBillingEnabled`, and derives `me.hasBillingCard` from card metadata fields

**Methods**

| Method | Description |
|---|---|
| `clickUpdateBillingCardButton` | Opens the update billing card modal and initializes form state |
| `handleSubmittingUpdateBillingCard` | Calls `Cloud.updateBillingCard` with the new payment source |
| `submittedUpdateBillingCard` | Updates local `me` object with new card data and closes the modal |
| `clickRemoveCardButton` | Opens the remove billing card modal |
| `submittedRemoveCardForm` | Clears all billing card fields from `me` and closes the modal |
| `closeModal` | Dismisses the active modal and resets all form state |
| `_resetForms` | Clears form data/rules/errors and forces a re-render |

## Usage Example

```javascript
// Triggered when the user clicks "Update Card"
this.clickUpdateBillingCardButton();
// → opens modal: 'update-billing-card'

// After Stripe tokenizes the card and the form submits:
await this.handleSubmittingUpdateBillingCard({ newPaymentSource: stripeTokenPayload });

// On success callback:
await this.submittedUpdateBillingCard();
// → me.hasBillingCard === true, modal dismissed
```
