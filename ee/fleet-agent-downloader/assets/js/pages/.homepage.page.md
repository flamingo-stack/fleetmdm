Registers the `homepage` parasails page component, handling hero section layout and scroll interaction.

## Key Components

| Method | Description |
|---|---|
| `mounted` | Lifecycle hook that initializes hero height on page load |
| `clickHeroButton` | Animates page scroll to the "get started" section |
| `_setHeroHeight` | Private method that sets hero min-height (500px–1000px) minus the page header height |

## Usage Example

```javascript
// clickHeroButton triggers a smooth scroll to the scroll-destination element
clickHeroButton: async function() {
  $('html, body').animate({
    scrollTop: this.$find('[purpose="scroll-destination"]').offset().top
  }, 500);
},

// _setHeroHeight clamps viewport height between 500-1000px and subtracts header
_setHeroHeight: function() {
  var heightToSet = Math.max(Math.min($(window).height(), 1000), 500);
  this.$find('[purpose="full-page-hero"]')
    .css('min-height', heightToSet - $('[purpose="page-header"]').outerHeight() + 'px');
}
```

## Notes

- Hero height is clamped between `500px` and `1000px`, with the page header height subtracted to prevent overflow.
- Scroll animation duration is fixed at `500ms`.
- The `_setHeroHeight` private method is called once on `mounted`; it does **not** re-run on window resize.
