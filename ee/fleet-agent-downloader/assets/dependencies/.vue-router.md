Vue Router v2.7.0 is a client-side routing library for Vue.js applications, providing navigation management, route matching, and URL handling via hash or history modes.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `VueRouter` | Class | Main router instance with `push`, `replace`, `go`, `back`, `forward`, and `resolve` methods |
| `router-view` | Component | Functional component that renders the matched route component at the correct depth |
| `router-link` | Component | Navigation component with active class management and event handling |
| `createRoute` | Function | Builds a frozen route object from a record and location |
| `resolveQuery` | Function | Parses and merges query strings |
| `stringifyQuery` | Function | Serializes a query object to a URL string |
| `isSameRoute` | Function | Deep equality check between two route objects |

## Usage Example

```javascript
import Vue from 'vue'
import VueRouter from './vue-router.js'

Vue.use(VueRouter)

const router = new VueRouter({
  mode: 'history',
  routes: [
    { path: '/', component: Home },
    { path: '/about', component: About, props: true }
  ],
  linkActiveClass: 'active'
})

new Vue({ router, render: h => h(App) }).$mount('#app')
```

```vue
<template>
  <!-- Renders the matched route component -->
  <router-view />

  <!-- Navigation link with active class support -->
  <router-link to="/about" exact>About</router-link>
</template>
```

## Notes

- Distributed as a UMD bundle (CommonJS, AMD, and global script tag compatible)
- `router-link` automatically guards navigation for modifier keys, right-clicks, and `target="_blank"` anchors
- Route objects are frozen (`Object.freeze`) to prevent mutation
- `router-view` supports nested routes via depth tracking and `keep-alive` compatibility
