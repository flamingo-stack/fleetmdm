Client-side Socket.IO library bundled with the Sails.js WebSocket client (`sails.io.js`), enabling real-time bidirectional communication between browser clients and a Sails.js server.

## Key Components

- **Socket.IO Client (v2.0.3)** — Minified bundle providing the core WebSocket/polling transport layer
- **`io(url, options)`** — Factory function that creates or retrieves a cached socket manager and returns a namespaced socket
- **`io.Manager`** — Manages the underlying connection, reconnection logic, and multiplexing
- **`io.Socket`** — Represents a connection to a specific namespace on the server
- **URL Parser** — Normalizes connection URLs, inferring protocol, host, and port from `window.location` if not provided
- **Socket.IO Parser** — Encodes/decodes packets including binary events (`BINARY_EVENT`, `BINARY_ACK`) and standard events
- **Debug Utility** — Namespaced logging via `socket.io-client` debug channel

## Usage Example

```javascript
// Basic connection (auto-detects current host)
var socket = io();

// Connect to a specific server
var socket = io('https://example.com');

// Connect with options
var socket = io('https://example.com', {
  forceNew: true,
  query: { token: 'abc123' }
});

// Listen for events
socket.on('connect', function() {
  console.log('Connected:', socket.id);
});

socket.on('message', function(data) {
  console.log('Received:', data);
});

// Emit an event
socket.emit('chat', { text: 'Hello' });
```

## Notes

- Supports both AMD (`require.js`) and CommonJS module formats, falling back to a global `io` variable
- For AMD usage, replace this file with the standalone build from [balderdashy/sails.io.js](https://github.com/balderdashy/sails.io.js)
