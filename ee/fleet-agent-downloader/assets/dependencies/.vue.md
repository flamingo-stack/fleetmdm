A modified build of Vue.js v2.5.17 bundled for use within the Sails.js/Fleet MDM frontend, with a custom runtime check that suppresses development-mode warnings in production and staging environments by reading `SAILS_LOCALS._environment`.

## Key Components

### Environment Detection
- **`IS_VUE_RUNNING_IN_PRODUCTION_OR_STAGING_OR_ON_ERR_PAGE`** — Runtime flag that reads `global.SAILS_LOCALS._environment` to determine whether Vue should enable dev tooling and production tips. Defaults to `true` (production mode) if `SAILS_LOCALS` is absent (e.g., on error pages).

### Core Utility Functions
- **`isPrimitive(value)`** — Returns `true` for strings, numbers, symbols, and booleans
- **`isPlainObject(obj)`** — Strict `[object Object]` type check
- **`looseEqual(a, b)`** — Deep equality check for plain objects and arrays
- **`makeMap(str, expectsLowerCase)`** — Creates a fast lookup function from a comma-separated string
- **`cached(fn)`** — Memoizes a pure function using a null-prototype cache object
- **`camelize / hyphenate / capitalize`** — Cached string transformation utilities
- **`once(fn)`** — Returns a wrapper that ensures `fn` is called at most once
- **`extend(to, _from)`** — Shallow-copies properties from one object to another

### Configuration Object (`config`)
Controls Vue runtime behavior; key properties driven by the environment flag:
- **`productionTip`** — Disabled in production/staging
- **`devtools`** — Disabled in production/staging
- **`silent`**, **`errorHandler`**, **`warnHandler`**, **`ignoredElements`**, **`keyCodes`**

### Constants
- **`LIFECYCLE_HOOKS`** — Ordered array of all Vue 2 lifecycle hook names
- **`ASSET_TYPES`** — `['component', 'directive', 'filter']`

## Usage Example

This file is loaded as a browser global (UMD build). No direct instantiation is needed — standard Vue 2 usage applies:

```javascript
// Reads SAILS_LOCALS automatically at load time
// Dev warnings are silenced on production/staging pages

new Vue({
  el: '#app',
  data: { message: 'Hello from Fleet MDM' },
  mounted() {
    // devtools and productionTip are disabled when
    // SAILS_LOCALS._environment === 'production' or 'staging'
    console.log('Vue environment flag:', window.SAILS_LOCALS?._environment);
  }
});
```
