Bootstrap v4.1.3 bundled distribution file that packages the full Bootstrap JavaScript library (including jQuery dependency) as a single UMD-compatible bundle for use in browsers and Node.js environments.

## Key Components

| Component | Description |
|-----------|-------------|
| `Util` | Core utility helpers — transition detection, UID generation, selector resolution, type checking |
| `Alert` | Dismissible alert component with fade animation support |
| `Button` | Button state toggling (active/disabled) |
| `Carousel` | Slideshow/image carousel with touch and keyboard support |
| `Collapse` | Accordion/collapsible content panels |
| `Dropdown` | Dropdown menus with Popper.js positioning |
| `Modal` | Dialog/modal overlays with backdrop |
| `Scrollspy` | Automatic navigation highlighting based on scroll position |
| `Tab` | Tabbed navigation panels |
| `Tooltip` | Hover tooltips via Popper.js |
| `Popover` | Extended tooltip with title and content |

## Usage Example

```javascript
// Via jQuery (browser global)
$('#myAlert').alert('close');
$('#myModal').modal('show');
$('[data-toggle="tooltip"]').tooltip({ placement: 'top' });

// Via data attributes (no JS required)
// <button data-dismiss="alert">Close</button>
// <button data-toggle="modal" data-target="#myModal">Open</button>

// Via module (CommonJS)
const bootstrap = require('./bootstrap-4.bundle.js');
```

## Notes

- **jQuery required** — this bundle expects jQuery to be available globally as `window.jQuery` or passed via CommonJS/AMD
- Supports UMD: works as a browser global (`window.bootstrap`), CommonJS (`require()`), or AMD (`define()`)
- The `.bundle` variant includes Popper.js; the non-bundle variant does not
- Source: [Bootstrap v4.1.3](https://getbootstrap.com/) — MIT licensed
