A patched fork of Lodash 3.10.1 (`@sailshq/lodash` v3.10.2) bundled for use in Sails.js projects, incorporating a hotfix for [lodash#2768](https://github.com/lodash/lodash/issues/2768) to correctly detect async functions, generator functions, and Proxy objects.

## Key Components

- **Version**: `3.10.2` — based on Lodash 3.10.1 with patches by [@mikermcneil](https://github.com/mikermcneil)
- **Wrapper Flags**: Bitmask constants (`BIND_FLAG`, `CURRY_FLAG`, `ARY_FLAG`, etc.) controlling function composition behavior
- **Type Tags**: `Object#toString` tag constants for type detection (including patched `asyncTag`, `genTag`, `proxyTag`)
- **Cloneable/Typed Array Maps**: Lookup tables (`cloneableTags`, `typedArrayTags`) used by `_.clone` and typed array utilities
- **Regex Patterns**: Pre-compiled regexes for HTML escaping, template delimiters, property path parsing, word splitting, and latin-1 deburring
- **Environment Detection**: CommonJS (`freeExports`, `freeModule`), Node.js (`freeGlobal`), and browser (`freeWindow`, `freeSelf`) globals resolved at load time
- **Character Maps**: `htmlEscapes`/`htmlUnescapes`, `deburredLetters`, `regexpEscapes`, `stringEscapes`

## Usage Example

```javascript
var _ = require('@sailshq/lodash');

// Deep clone an object
var copy = _.clone({ a: 1, b: [2, 3] }, true);

// Curry a function
var add = _.curry(function(a, b) { return a + b; });
var addFive = add(5);
console.log(addFive(3)); // 8

// Safe property access
var user = { profile: { name: 'Alice' } };
console.log(_.get(user, 'profile.name')); // 'Alice'
console.log(_.get(user, 'profile.age', 0)); // 0

// Template rendering
var compiled = _.template('Hello, <%= name %>!');
console.log(compiled({ name: 'World' })); // 'Hello, World!'
```
