A high-level AJAX library (part of `parasails`) that provides a clean, promise-based interface for making HTTP and WebSocket requests to Sails.js API endpoints. It supports serial/named argument styles, error negotiation, CSRF protection, and file uploads.

## Key Components

- **`Cloud.setup(options)`** — Initializes the SDK with endpoint method definitions, API base URL, and usage options. Must be called before using any endpoint methods.
- **`Cloud[methodName]()`** — Dynamically generated endpoint methods created during `setup()`. Each supports `.with()`, `.exec()`, `.switch()`, `.protocol()`, and `.headers()` chaining.
- **`_representsOneOrMoreFiles(that)`** — Private utility that checks if a value is a `File`, `FileList`, or array of `File` instances (used to trigger `multipart/form-data` uploads).
- **`_verifyErrorNegotiationRule(rule)`** — Private utility that validates error intercept rules (exit name strings or HTTP status code integers).

## Usage Example

```javascript
// Step 1: Register endpoints once on page load
Cloud.setup({
  apiBaseUrl: 'https://example.com',
  methods: {
    findOneUser:  'GET  /api/v1/users/:id',
    createUser:   'POST /api/v1/users',
    doSomething:  'PUT  /api/v1/projects/:id/do',
  }
});

// Step 2a: Call with serial args (positional)
var user = await Cloud.findOneUser(3);

// Step 2b: Call with named args
var user = await Cloud.findOneUser.with({ id: 3 });

// Step 2c: Negotiate specific errors
Cloud.createUser.with({ email: 'foo@example.com' })
  .switch({
    error: (err) => console.error(err),
    emailAlreadyInUse: () => alert('Try a different email'),
    success: (newUser) => console.log(newUser),
  });

// Step 2d: Force WebSocket transport
Cloud.doSomething.with({ id: 8 })
  .protocol('io.socket')
  .exec((err, result) => { /* ... */ });

// Step 2e: Custom request headers
Cloud.doSomething.with({ id: 8 })
  .headers({ 'X-Auth': 'my-token' })
  .exec((err, result) => { /* ... */ });
```

## Notes

- CSRF tokens are sent automatically via `x-csrf-token` if `SAILS_LOCALS._csrf` is defined.
- File/`FileList` arguments are automatically serialized as `multipart/form-data`.
- The method names `on`, `off`, and `setup` are reserved and cannot be used as endpoint names.
