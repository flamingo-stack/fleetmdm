A lightweight UMD wrapper (v0.9.3) around Vue.js and Lodash that provides structured patterns for multi-page applications, with optional integration for jQuery, bowser, and VueRouter.

## Key Components

- **`parasails._cache`** — Global module registry for storing pages, components, utilities, and constants
- **`_ensureGlobalCache()`** — Initializes the module cache on first access
- **`_exportOnGlobalCache(moduleName, moduleDefinition)`** — Registers a named module, throwing on duplicate names
- **`_exposeBonusMethods(def, entityNoun)`** — Injects helper methods (`$get`, `$find`, `$focus`, `forceRender`) into Vue component/page definitions; jQuery-powered when available
- **`_wrapMethodsAndVerifyNoArrowFunctions(def, entityNoun)`** — Validates top-level definition keys against an allowlist, providing "Did you mean?" suggestions for common typos (e.g. `beforeMounted` → `beforeMount`, `state` → `data`)

## Usage Example

```javascript
// Register a page script
parasails.registerPage('home', {
  data: {
    greeting: 'Hello'
  },
  mounted: function() {
    console.log('Page mounted');
  },
  methods: {
    handleClick: async function() {
      // use $find (requires jQuery)
      var $btn = this.$find('[data-action="submit"]');
      $btn.prop('disabled', true);
    }
  }
});

// Register a reusable component
parasails.registerComponent('my-modal', {
  props: ['isOpen'],
  template: '<div v-if="isOpen"><slot/></div>',
  methods: {
    focusInput: function() {
      this.$focus('[name="email"]');
    }
  }
});

// Register a utility
parasails.registerUtility('formatDate', function(ts) {
  return new Date(ts).toLocaleDateString();
});
```

## Notes

- Arrow functions in Vue lifecycle hooks/methods are detected and rejected to prevent `this` binding issues
- Top-level definition keys are strictly validated; unrecognized keys (e.g. `events`, `functions`, `state`) throw descriptive errors with correction suggestions
- jQuery dependency is optional — `$get`, `$find`, and `$focus` throw descriptive errors if jQuery was not loaded before parasails
