Minified distribution of jQuery v3.2.1, the widely-used JavaScript DOM manipulation and utility library.

## Key Components

- **Core jQuery object** (`r` / `$`) — chainable DOM selection and manipulation via `r.fn` prototype
- **Sizzle CSS selector engine** — advanced CSS3 selector parsing, filtering, and matching with cross-browser support
- **`r.extend` / `r.fn.extend`** — deep/shallow object merging and plugin extension mechanism
- **Utility functions** — `r.each`, `r.map`, `r.grep`, `r.merge`, `r.proxy`, `r.type`, `r.isPlainObject`, `r.camelCase`, `r.globalEval`
- **UMD wrapper** — supports CommonJS (`module.exports`), AMD, and global browser environments

## Usage Example

```javascript
// Browser (global)
<script src="jquery.min.js"></script>
<script>
  $(document).ready(function () {
    $(".btn").on("click", function () {
      $(this).toggleClass("active");
    });
  });
</script>

// CommonJS / Node.js (requires jsdom window)
const { JSDOM } = require("jsdom");
const { window } = new JSDOM("");
const $ = require("./jquery.min.js")(window);
```
