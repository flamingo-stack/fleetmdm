Utility functions for the Fleet server package, providing cryptographic helpers, random text generation, URL security, template loading, and general-purpose data manipulation.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GenerateRandomEmail` | func | Creates a unique email by inserting random text before the `@` symbol |
| `GenerateRandomPwd` | func | Generates a 14-char base64 random password with a numeric suffix and `!` to meet Fleet password requirements |
| `GenerateRandomText` | func | Returns a standard base64-encoded random string of `keySize` bytes |
| `GenerateRandomURLSafeText` | func | Returns a URL-safe base64-encoded random string of `keySize` bytes |
| `DecodePrivateKeyPEM` | func | Decodes a PEM-encoded RSA private key (PKCS1) |
| `GetTemplate` | func | Loads and parses an embedded HTML template from the binary asset store |
| `Base64DecodePaddingAgnostic` | func | Decodes base64 strings tolerant of missing padding characters |
| `RemoveDuplicatesFromSlice` | func | Generic deduplication for any `comparable` slice type |
| `PostJSONWithTimeout` | var | Deprecated alias → `platform/http.PostJSONWithTimeout` |
| `MaskSecretURLParams` | var | Deprecated alias → `platform/http.MaskSecretURLParams` |
| `MaskURLError` | var | Deprecated alias → `platform/http.MaskURLError` |
| `NeverTimestamp` | const | Sentinel timestamp (`2000-01-01 00:00:00`) indicating an event has never occurred |

## Usage Example

```go
// Generate a unique test email
email, err := server.GenerateRandomEmail("admin@example.com")
// email => "admin+aBcDeFgHiJ@example.com"

// Generate a compliant random password
pwd, err := server.GenerateRandomPwd()
// pwd => "c2VjcmV0dGV4dA==42!"

// Decode a base64 string regardless of padding
decoded, err := server.Base64DecodePaddingAgnostic("c2VjcmV0")

// Remove duplicates from a slice
ids := server.RemoveDuplicatesFromSlice([]int{1, 2, 2, 3, 1})
// ids => [1, 2, 3]

// Decode a PEM-encoded RSA private key
key, err := server.DecodePrivateKeyPEM(pemBytes)

// Load an embedded HTML template
tmpl, err := server.GetTemplate("templates/email.html", "email")
```

> **Note:** `PostJSONWithTimeout`, `MaskSecretURLParams`, and `MaskURLError` are deprecated. Use their equivalents in [`server/platform/http`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/platform/http) directly.
