## Fleet template variable parsing and substitution utilities

This file implements utilities for detecting, extracting, deduplicating, and replacing Fleet template variables (e.g., `$FLEET_VAR_HOST_UUID` or `${FLEET_VAR_HOST_UUID}`) embedded in configuration content such as MDM profiles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ProfileDataVariableRegex` | `*regexp.Regexp` | Public regex matching DigiCert-specific `<data>` section variables that may cause Apple profile validation issues |
| `Find` | `func` | Extracts unique variable names (without `FLEET_VAR_` prefix) from a string; returns `nil` if none found |
| `FindKeepDuplicates` | `func` | Like `Find` but preserves duplicate occurrences; results sorted by name length (descending) to avoid partial-match substitution errors |
| `Dedupe` | `func` | Removes duplicate strings while preserving first-occurrence order |
| `Replace` | `func` | Substitutes both braced and non-braced forms of a named variable with a concrete value |
| `Contains` | `func` | Returns `true` if a string contains any Fleet variable |
| `ContainsBytes` | `func` | Byte-slice variant of `Contains` |

## Usage Example

```go
content := "Device: $FLEET_VAR_HOST_UUID, Email: ${FLEET_VAR_HOST_EMAIL}"

// Check for variables
if variables.Contains(content) {
    // Extract unique variable names
    vars := variables.Find(content)
    // vars == []string{"HOST_UUID", "HOST_EMAIL"}

    // Substitute values
    content = variables.Replace(content, "HOST_UUID", "abc-123")
    content = variables.Replace(content, "HOST_EMAIL", "user@example.com")
    // content == "Device: abc-123, Email: user@example.com"
}

// Preserve duplicates for frequency analysis
dupes := variables.FindKeepDuplicates("$FLEET_VAR_FOO and $FLEET_VAR_FOO")
// dupes == []string{"FOO", "FOO"}
```

## Notes

- The internal `fleetVariableRegex` supports both `$FLEET_VAR_NAME` and `${FLEET_VAR_NAME}` syntax via named capture groups.
- `FindKeepDuplicates` sorts results by descending length to prevent shorter variable names from being substituted within longer ones during sequential replacement.
