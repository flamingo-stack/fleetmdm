Parses Microsoft Office for Mac release notes HTML pages to extract version information, release dates, and CVE security updates for each product.

## Key Components

**Exported**
- `GetReleaseNotes(includeInvalid bool) (ReleaseNotes, error)` — Fetches and parses both the primary and archived Microsoft release notes pages, returning combined results
- `VersionPattern` — Compiled regex matching version strings like `Version 16.69.1 (Build 23011802)`
- `BuildNumberPattern` — Compiled regex extracting build numbers from version strings
- `IdToType` — Maps HTML element IDs (e.g. `"outlook"`) to `ProductType` constants
- `nameToType` — Maps lowercase product name strings to `ProductType` constants

**Internal**
- `parseReleaseHTML(reader io.Reader) ([]ReleaseNote, error)` — Core HTML tokenizer loop that extracts dates (`<h2>`), versions (`<em>`), and CVEs (`<a>`) using stateful parsing
- `parseRelDate(raw string) (time.Time, bool)` — Parses release date strings across multiple layouts
- `parseVulnLink(token html.Token) (string, bool)` — Extracts a CVE identifier from an anchor tag's `href` attribute

## Usage Example

```go
// Fetch only valid release notes (has version + security updates)
notes, err := macoffice.GetReleaseNotes(false)
if err != nil {
    log.Fatal(err)
}

for _, note := range notes {
    fmt.Printf("Release: %s, Version: %s\n", note.Date.Format("2006-01-02"), note.Version)
    for product, cves := range note.SecurityUpdates {
        fmt.Printf("  Product %v CVEs: %v\n", product, cves)
    }
}

// Include incomplete entries (e.g. for parser tests)
allNotes, err := macoffice.GetReleaseNotes(true)
```

## Notes

- Handles two HTML layouts for security updates: `<h3>`-delimited list sections and `<table>`-based formats found in older release pages
