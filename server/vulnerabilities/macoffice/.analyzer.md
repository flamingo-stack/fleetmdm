Detects and persists CVE vulnerabilities in Mac Office applications by comparing installed software versions against release notes stored on disk.

## Key Components

| Function | Description |
|---|---|
| `Analyze` | Entry point; loads release notes, iterates all installed software, and reconciles detected vs. stored vulnerabilities |
| `getLatestReleaseNotes` | Reads the most recent Mac Office release notes JSON file from the vulnerability path |
| `collectVulnerabilities` | Compares a single software version against release notes to produce a list of applicable CVEs |
| `getStoredVulnerabilities` | Fetches previously persisted vulnerabilities for a given software ID from the datastore |
| `updateVulnsInDB` | Computes the delta between detected and existing vulnerabilities, then inserts/deletes accordingly |

## Usage Example

```go
import "github.com/fleetdm/fleet/v4/server/vulnerabilities/macoffice"

// Run vulnerability analysis for all installed Mac Office apps.
// vulnPath must contain a valid Mac Office release notes JSON file.
newVulns, err := macoffice.Analyze(ctx, ds, "/path/to/vuln/data", true)
if err != nil {
    log.Fatal(err)
}

for _, v := range newVulns {
    fmt.Printf("New CVE %s found for software ID %d\n", v.CVE, v.SoftwareID)
}
```

## Notes

- Release notes are sorted descending by date; processing stops early once a release older than the installed version is reached.
- `Analyze` guards against a fully invalid/corrupted feed — if no release note entry passes `Valid()`, it returns an error rather than incorrectly marking all existing vulnerabilities as remediated.
- Only software sourced from `"apps"` and matched by `OfficeProductFromBundleId` is evaluated.
- Duplicate CVEs within a detection pass are de-duplicated via a keyed map before insertion.
