Parses, stores, and serializes Microsoft Office for Mac release notes with security vulnerability metadata for use in Fleet's vulnerability processing pipeline.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ProductType` | `int` enum | Identifies Office products (`WholeSuite`, `Outlook`, `Excel`, `PowerPoint`, `Word`, `OneNote`) |
| `SecurityUpdate` | struct | Maps a `ProductType` to a CVE/vulnerability string |
| `ReleaseNote` | struct | Holds release date, version string (e.g. `16.69 (Build 23010700)`), and associated `SecurityUpdate` slice |
| `ReleaseNotes` | `[]ReleaseNote` | Collection type with `Serialize` for JSON persistence |
| `OfficeProductFromBundleId` | func | Maps a macOS bundle ID (e.g. `com.microsoft.excel`) to a `ProductType` |

### `ReleaseNote` Methods

| Method | Description |
|---|---|
| `Valid()` | Returns `true` when both `Version` and `SecurityUpdates` are non-empty |
| `CmpVersion(otherVer)` | RPM-style version comparison (`-1`, `0`, `1`) against a given version string |
| `CollectVulnerabilities(product)` | Returns deduplicated CVEs patched for a given `ProductType`, including `WholeSuite` patches |
| `BuildNumber()` | Extracts the build number (e.g. `23010700`) from the version string |
| `ShortVersionFormat()` | Extracts the short version (e.g. `16.69`) from the version string |

## Usage Example

```go
note := macoffice.ReleaseNote{
    Date:    time.Now(),
    Version: "16.69 (Build 23010700)",
}
note.AddSecurityUpdate(macoffice.Excel, "CVE-2023-12345")
note.AddSecurityUpdate(macoffice.WholeSuite, "CVE-2023-99999")

if note.Valid() {
    product, ok := macoffice.OfficeProductFromBundleId("com.microsoft.excel")
    if ok {
        vulns := note.CollectVulnerabilities(product)
        // vulns: ["CVE-2023-12345", "CVE-2023-99999"]
    }
    fmt.Println(note.ShortVersionFormat()) // "16.69"
    fmt.Println(note.BuildNumber())        // "23010700"
}

notes := macoffice.ReleaseNotes{note}
notes.Serialize(time.Now(), "/tmp/vuln-data")
```
