Shared test helpers for vulnerability scanning integration tests, providing source-agnostic fixtures and assertions that work across OVAL, OSV, and goval-dictionary scanner backends.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Scanner` | Abstraction over a vulnerability scanning backend with `Setup` and `Analyze` hooks |
| `SoftwareFixture` | Represents a single software entry (name, version, release, arch) in a JSON fixture |
| `ExpectedVuln` | Maps a software package to its expected CVEs |
| `VulnFixture` | Top-level fixture container; exposes `AllCVEs()` and `Software()` helpers |

### Functions

| Function | Description |
|----------|-------------|
| `LoadFixture` | Loads a `VulnFixture` from a bzip2-compressed JSON file |
| `LoadSoftwareFromFixture` | Creates a DB host and populates it from a `VulnFixture` |
| `RunAndAssert` | End-to-end helper: loads fixture → runs scanner → asserts per-package CVE matches |
| `ExtractBzip2` | Decompresses a bzip2 file from `src` to `dst` |
| `LoadSoftware` | Creates a host from a `<platform>-software.json` fixture file |
| `ExtractSoftwareAndCVEFixtures` | Extracts both software and CVE bzip2 archives into a working directory |
| `WithTestFixture` | Orchestrates full fixture lifecycle: extract → load → update OS versions → callback → cleanup |
| `AssertVulns` | Loads expected CVEs from a CSV and asserts they match stored DB vulnerabilities |

## Usage Example

```go
func TestMyScanner(t *testing.T) {
    ds := mysql.CreateTestMySQLDS(t)

    scanner := vulntest.Scanner{
        Name:   "oval",
        Source: fleet.MSRCSource,
        Setup:  func(t *testing.T, vulnPath string, ver fleet.OSVersion) { /* load definitions */ },
        Analyze: func(ctx context.Context, ds fleet.Datastore, ver fleet.OSVersion, vulnPath string) ([]fleet.SoftwareVulnerability, error) {
            return myScanner.Scan(ctx, ds, ver, vulnPath)
        },
    }

    ver := fleet.OSVersion{Platform: "rhel", Name: "Red Hat Enterprise Linux 8.0.0"}
    vulntest.RunAndAssert(t, ds, scanner, ver, "rhel8", "testdata/rhel8.json.bz2", t.TempDir())
}
```

Fixture files live under [`vulntest/testdata/`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/vulnerabilities/vulntest/testdata) and are bzip2-compressed JSON or CSV.
