Provides pre-built `Scanner` implementations for OVAL and goval-dictionary vulnerability analyzers used in Fleet vulnerability integration tests.

## Key Components

### `OVALScanner(defDir string) Scanner`
Returns a `Scanner` configured for RHEL package vulnerability detection using the OVAL analyzer. Extracts a bzip2-compressed OVAL definition fixture from `testdata/<defDir>` into the test's vulnerability path, then delegates analysis to `oval.Analyze`.

### `GovalDictionaryScanner(kernelEntries map[string][]string) Scanner`
Returns a `Scanner` configured for RHEL kernel vulnerability detection using the goval-dictionary analyzer. Instead of unpacking a large (~90MB) production SQLite database, it programmatically builds a minimal in-memory SQLite database from the provided `kernelEntries` map — where each key is a fixed kernel version string (`epoch:version-release`, e.g. `"0:5.14.0-611.8.1.el9_7"`) and each value is a list of associated CVE IDs. This exercises the full `Analyze → Eval → Rpmvercmp` production code path while keeping fixtures small and self-contained.

## Usage Example

```go
// OVAL scanner for RHEL 9 package vulnerabilities
scanner := OVALScanner("rhel/2026")

// goval-dictionary scanner with targeted kernel CVE entries
scanner := GovalDictionaryScanner(map[string][]string{
    "0:5.14.0-503.40.1.el9_5": {"CVE-2024-1234", "CVE-2024-5678"},
    "0:5.14.0-611.8.1.el9_7":  {"CVE-2025-9999"},
})

// Scanners are passed into the vulntest harness
RunScannerTest(t, scanner, osVersion, hosts)
```
