Provides filesystem access for reading and deleting vulnerability metadata files (MSRC bulletins, Windows/Mac Office release notes) from a local directory.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `FSAPI` | Interface | Contract for listing and deleting metadata files by category |
| `FSClient` | Struct | Concrete implementation backed by a local directory path |
| `NewFSClient` | Constructor | Creates an `FSClient` rooted at the given directory |
| `Delete` | Method | Removes a metadata file from the configured directory |
| `MSRCBulletins` | Method | Lists all MSRC security bulletin files |
| `WinOfficeBulletin` | Method | Lists all Windows Office bulletin files |
| `MacOfficeReleaseNotes` | Method | Lists all macOS Office release note files |
| `list` | Private Method | Shared walker — filters by filename prefix and constructs typed metadata entries |

## Usage Example

```go
// Initialize a client pointed at a local metadata directory
client := io.NewFSClient("/var/cache/vuln-metadata")

// List all MSRC security bulletins
bulletins, err := client.MSRCBulletins()
if err != nil {
    log.Fatal(err)
}

for _, b := range bulletins {
    fmt.Println(b.filename)

    // Delete a bulletin after processing
    if err := client.Delete(b); err != nil {
        log.Printf("failed to delete %s: %v", b.filename, err)
    }
}
```

## Notes

- All listing methods share the internal `list` walker, which uses `filepath.WalkDir` and filters entries by filename prefix.
- Each category has a dedicated prefix constant (`mSRCFilePrefix`, `winOfficePrefix`, `macOfficeReleaseNotesPrefix`) and a constructor function for producing typed `MetadataFileName` values.
- `FSAPI` allows mocking in tests — pass the interface rather than the concrete `FSClient` where testability is needed.
