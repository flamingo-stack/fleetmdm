GitHub release asset client for fetching MSRC bulletins, Windows Office bulletins, and Mac Office release notes from the `fleetdm/nvd` GitHub repository.

## Key Components

- **`ReleaseLister`** — Interface wrapping `github.Repositories.ListReleases`, enabling testable GitHub API interactions.
- **`GitHubAPI`** — Interface defining the contract for downloading files and listing metadata bulletins/release notes.
- **`GitHubClient`** — Concrete implementation holding an HTTP client, a `ReleaseLister`, and a working directory for downloads.
- **`NewGitHubClient`** — Constructor returning a configured `GitHubClient`.
- **`Download`** — Downloads a file from a URL into `workDir`, returning the local file path.
- **`MSRCBulletins`** — Returns a map of `MetadataFileName` → download URL for all MSRC bulletin assets.
- **`WinOfficeBulletin`** — Returns the most recent Windows Office bulletin asset.
- **`MacOfficeReleaseNotes`** — Returns the single Mac Office release notes asset.
- **`list`** — Internal helper that paginates the latest release, filters assets by prefix, and builds the result map using a provided `MetadataFileName` constructor.

## Usage Example

```go
httpClient := &http.Client{Timeout: 10 * time.Second}
ghRepos := github.NewClient(nil).Repositories
client := NewGitHubClient(httpClient, ghRepos, "/tmp/nvd-metadata")

// Download MSRC bulletins
bulletins, err := client.MSRCBulletins(context.Background())
if err != nil {
    log.Fatal(err)
}
for meta, downloadURL := range bulletins {
    localPath, err := client.Download(downloadURL)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Saved %s to %s\n", meta, localPath)
}

// Fetch the latest Windows Office bulletin
meta, dlURL, err := client.WinOfficeBulletin(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Latest Win Office bulletin: %s → %s\n", meta, dlURL)
```
