Provides an abstraction over metadata asset filenames (MSRC bulletins, Windows Office, and Mac Office release notes) to encode and extract product name and date information from structured file name conventions.

## Key Components

### `MetadataFileName`
A struct wrapping a prefixed filename string, providing methods to parse and compare encoded metadata.

| Method | Description |
|--------|-------------|
| `Before(other)` | Compares two `MetadataFileName` instances by their embedded date |
| `ProductName()` | Extracts and returns the human-readable product name |
| `String()` | Returns the raw filename string |

### Constructors
| Function | Description |
|----------|-------------|
| `NewMSRCMetadata(filename)` | Parses an MSRC bulletin filename (prefix: `fleet_msrc_`) |
| `NewMacOfficeRelNotesMetadata(filename)` | Parses a Mac Office release notes filename |
| `NewWinOfficeMetadata(filename)` | Parses a Windows Office bulletin filename |

### Filename Generators
| Function | Description |
|----------|-------------|
| `MSRCFileName(productName, date)` | Generates a canonical MSRC filename |
| `MacOfficeRelNotesFileName(date)` | Generates a canonical Mac Office release notes filename |
| `WinOfficeFileName(date)` | Generates a canonical Windows Office bulletin filename |

## Usage Example

```go
// Generate a filename for a given product and date
date := time.Date(2024, 6, 15, 0, 0, 0, 0, time.UTC)
filename := MSRCFileName("Windows 10", date)
// => "fleet_msrc_Windows_10-2024_06_15.json"

// Parse and inspect the filename
meta, err := NewMSRCMetadata(filename)
if err != nil {
    log.Fatal(err)
}

fmt.Println(meta.ProductName()) // => "Windows 10"
fmt.Println(meta.String())      // => "fleet_msrc_Windows_10-2024_06_15.json"

// Compare two metadata files by date
older := MSRCFileName("Windows 10", time.Date(2024, 1, 1, 0, 0, 0, 0, time.UTC))
newer := MSRCFileName("Windows 10", date)

oldMeta, _ := NewMSRCMetadata(older)
newMeta, _ := NewMSRCMetadata(newer)

fmt.Println(oldMeta.Before(newMeta)) // => true
```
