Handles synchronization of Microsoft Security Response Center (MSRC) security bulletins between GitHub and the local filesystem, downloading new or updated bulletins and removing outdated ones based on installed operating systems.

## Key Components

- **`bulletinsDelta`** — Computes the diff between local and remote bulletins. Returns two slices: files to download and files to delete, filtered to match the OS products currently installed.
- **`SyncFromGithub`** — Public entry point that initializes GitHub and filesystem clients, then delegates to `sync`.
- **`sync`** — Internal orchestration function that fetches remote bulletin metadata, compares with local state via `bulletinsDelta`, then performs downloads and deletions.

## Usage Example

```go
// Sync MSRC bulletins for specific operating systems
ctx := context.Background()
dstDir := "/var/fleet/msrc"

operatingSystems := []fleet.OperatingSystem{
    {Name: "Windows 10", Version: "21H2"},
    {Name: "Windows Server 2019"},
}

err := msrc.SyncFromGithub(ctx, dstDir, operatingSystems)
if err != nil {
    log.Fatalf("bulletin sync failed: %v", err)
}

// Pass nil to sync bulletins for all available OS products
err = msrc.SyncFromGithub(ctx, dstDir, nil)
```

> **Note:** When `os` is `nil`, all remote bulletins are downloaded regardless of installed products. When `os` is an empty slice (`len == 0`), all remote bulletins are queued for download and nothing is deleted.
