Provides an HTTP client for downloading Microsoft Security Response Center (MSRC) security feed data in CVRF XML format.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `MSRCAPI` | Interface | Defines the contract for interacting with MSRC resources |
| `MSRCClient` | Struct | HTTP client wrapper for downloading MSRC security feeds |
| `NewMSRCClient` | Constructor | Creates a new `MSRCClient` with a given HTTP client, working directory, and base URL |
| `GetFeed` | Method | Downloads the MSRC security feed XML for a given month and year |
| `FeedNotFound` | Error | Sentinel error returned when a requested feed does not exist |
| `MSRCMinYear` | Constant | Minimum supported year (`2020`) due to upstream data inconsistencies |
| `MSRCBaseURL` | Constant | Default MSRC API base URL (`https://api.msrc.microsoft.com`) |

## Usage Example

```go
client := &http.Client{}
msrcClient := msrc.NewMSRCClient(client, "/tmp/msrc-feeds", msrc.MSRCBaseURL)

path, err := msrcClient.GetFeed(time.September, 2024)
if err != nil {
    if errors.Is(err, msrc.FeedNotFound) {
        log.Println("feed not available yet")
        return
    }
    log.Fatal(err)
}

fmt.Printf("Feed downloaded to: %s\n", path) // e.g. /tmp/msrc-feeds/2024-Sep.xml
```

## Notes

- Downloaded feeds are stored as `YYYY-Mon.xml` files (e.g. `2024-Sep.xml`) in the configured `workDir`
- Requests prior to January 2020 are rejected due to inconsistent `Supersedes` field definitions in older MSRC data
- Future dates are rejected at call time before any HTTP request is made
- Source: [`msrc_api.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/msrc_api.go)
