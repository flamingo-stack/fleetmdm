Parses and matches Microsoft Windows product names from MSRC vulnerability bulletins against Fleet-managed operating system records for CVE applicability checks.

## Key Components

| Symbol | Description |
|---|---|
| `Product` | String type representing a full MS product name (name + arch + version) |
| `Products` | Map of product ID → `Product` used for bulk OS matching |
| `ErrNoMatch` | Sentinel error returned when no product matches the host OS |
| `GetMatchForOS` | Finds the best-matching product ID for a given `fleet.OperatingSystem`, preferring display version matches over build number fallbacks |
| `NewProductFromFullName` | Normalizes MSRC bulletin product names by appending version strings for products that omit them (e.g., "Windows Server 2022" → appends `"21H2"`) |
| `NewProductFromOS` | Constructs a `Product` from a `fleet.OperatingSystem` in `"<name> for <arch>"` format |
| `Product.Arch()` | Extracts architecture string (`"32-bit"`, `"64-bit"`, `"arm64"`, `"itanium"`, or `"all"`) |
| `Product.Name()` | Extracts the base Windows product name (e.g., `"Windows 10"`, `"Windows Server 2022"`) |
| `Product.HasDisplayVersion()` | Returns `true` if the product string contains `"version"` or `"edition"` keywords |
| `Product.IsServerCore()` | Returns `true` if the product indicates a Server Core installation |
| `Product.Matches()` | Commutative arch-aware equality check between two products |

## Usage Example

```go
products := parsed.Products{
    "cpe:123": parsed.NewProductFromFullName("Windows 11 Version 22H2 for x64-based Systems"),
    "cpe:456": parsed.NewProductFromFullName("Windows Server 2022"),
}

os := fleet.OperatingSystem{
    Name:             "Microsoft Windows 11 Pro",
    Arch:             "x86_64",
    DisplayVersion:   "22H2",
    InstallationType: "Client",
}

matchID, err := products.GetMatchForOS(ctx, os)
if errors.Is(err, parsed.ErrNoMatch) {
    // no applicable CVE product found for this host
}
// matchID == "cpe:123"
```
