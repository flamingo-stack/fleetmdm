Defines the `SecurityBulletin` data structure and supporting types for parsing and analyzing Windows security update bulletins, including vulnerability tracking and KB update supersession logic.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `SecurityBulletin` | Top-level bulletin container holding products, vulnerabilities, and vendor fixes |
| `Vulnerability` | A CVE entry with affected product IDs and remediating KB fixes |
| `VendorFix` | A KB update entry with fixed builds, target products, and optional supersession reference |
| `weightedUnionFind` | Internal data structure for efficiently determining KB update chain connectivity |

### Functions & Methods

| Name | Description |
|------|-------------|
| `NewSecurityBulletin(pName)` | Creates an initialized `SecurityBulletin` for a given product name |
| `UnmarshalBulletin(fPath)` | Reads and deserializes a bulletin from a JSON file on disk |
| `(*SecurityBulletin).Merge(other)` | Merges another bulletin's products, vulnerabilities, and fixes in-place (no overwrite) |
| `(*SecurityBulletin).KBIDsConnected(p, q)` | Returns `true` if two KB IDs are linked via supersession chains |
| `(*SecurityBulletin).UnmarshalJSON(data)` | Custom JSON unmarshaler with backward-compatible support for the legacy misspelled `"Vulnerabities"` key |
| `NewVulnerability(epoch)` | Creates an initialized `Vulnerability` with a published date |
| `NewVendorFix(fixedBuilds...)` | Creates an initialized `VendorFix` with a copy of the provided build strings |
| `(*VendorFix).AddFixedBuild(build)` | Appends a build string if not already present |

## Usage Example

```go
// Load a bulletin from a cached JSON file
bulletin, err := parsed.UnmarshalBulletin("/var/cache/bulletins/windows10.json")
if err != nil {
    log.Fatal(err)
}

// Merge a second bulletin into the first
err = bulletin.Merge(otherBulletin)
if err != nil {
    log.Fatal(err) // e.g. mismatched ProductName
}

// Check if a host's installed KB is part of the same
// cumulative update chain as the required KB
if bulletin.KBIDsConnected(5031539, 5028185) {
    fmt.Println("Update is covered by a superseding KB")
}
```

## Notes

- `KBIDsConnected` uses a lazily initialized weighted union-find forest (`vfForest`) built from `VendorFix.Supersedes` references, enabling O(α(n)) connectivity queries across cumulative update chains.
- `UnmarshalJSON` handles both `"Vulnerabilities"` and the legacy typo `"Vulnerabities"` for backward compatibility with previously cached bulletin files.
