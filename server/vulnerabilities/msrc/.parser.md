Parses Microsoft Security Response Center (MSRC) XML feed files into structured `SecurityBulletin` maps, filtering for Windows-specific vulnerabilities and vendor fixes.

## Key Components

| Function | Description |
|---|---|
| `ParseFeed(fPath string)` | Entry point — opens an MSRC feed file by path and returns a map of product name → `SecurityBulletin` |
| `mapToSecurityBulletins(rXML)` | Transforms parsed XML into bulletins, linking CVEs to vendor fixes (KBIDs) and Windows product IDs |
| `parseXML(reader)` | Streaming XML decoder that extracts Windows `ProductBranch` entries and `Vulnerability` elements with vendor fixes |

## Usage Example

```go
bulletins, err := msrc.ParseFeed("/path/to/msrc-feed.xml")
if err != nil {
    log.Fatal(err)
}

for productName, bulletin := range bulletins {
    fmt.Printf("Product: %s\n", productName)
    fmt.Printf("  Vulnerabilities: %d\n", len(bulletin.Vulnerabilities))
    fmt.Printf("  Vendor Fixes:    %d\n", len(bulletin.VendorFixes))
}
```

## Notes

- Only **vendor fix** remediations are processed; other remediation types are skipped.
- Remediation descriptions are expected to be numeric KBID values — non-numeric or negative values return an error.
- The parser is streaming (token-by-token) to handle large MSRC XML feeds efficiently.
- Non-Windows products and unrecognized product names are silently skipped during bulletin construction.
- Supercedence (KBID that a fix replaces) is optional and stored as a `*uint`.
