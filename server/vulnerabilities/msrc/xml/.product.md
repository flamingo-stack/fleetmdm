Defines XML structures for parsing Microsoft product data from CSAF/CVRF documents, with a utility method for filtering Windows OS products.

## Key Components

- **`ProductBranch`** — Recursive struct representing a product tree branch (type, name, nested branches, and full product names), mapped to the `prod` XML namespace per [CSAF/CVRF v1.2](http://docs.oasis-open.org/csaf/csaf-cvrf/v1.2/cs01/csaf-cvrf-v1.2-cs01.html#_Toc493508797)
- **`Product`** — Struct representing a full product name entry with a `ProductID` attribute and character data for the name
- **`WinProducts()`** — BFS traversal of the `ProductBranch` tree that returns only Windows OS products from `"Windows"` or `"ESU"` (Extended Security Update) family branches, filtering out non-OS entries like Remote Desktop client

## Usage Example

```go
// Parse a ProductBranch from XML, then extract Windows products
branch := ProductBranch{
    Type: "Product Family",
    Name: "Windows",
    Products: []Product{
        {ProductID: "10001", FullName: "Windows 10 Version 22H2"},
        {ProductID: "10002", FullName: "Remote Desktop client for Windows Desktop"},
    },
}

winProducts := branch.WinProducts()
for _, p := range winProducts {
    fmt.Printf("ID: %s, Name: %s\n", p.ProductID, p.FullName)
}
// Output:
// ID: 10001, Name: Windows 10 Version 22H2
```

## Notes

- `WinProducts()` uses a **breadth-first queue** to traverse arbitrarily deep branch trees
- Only products whose `FullName` has the prefix `"Windows"` are included, guarding against non-OS products nested within Windows/ESU branches
- ESU branch support ensures Extended Security Update products (e.g. older Windows Server versions) are included
