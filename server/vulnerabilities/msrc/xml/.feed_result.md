Groups vulnerability feed data by bundling Windows vulnerabilities and their associated products into a single result structure.

## Key Components

### `FeedResult`
A struct that aggregates vulnerability feed output with two fields:

| Field | Type | Description |
|---|---|---|
| `WinVulnerabilities` | `[]Vulnerability` | Slice of Windows vulnerability entries |
| `WinProducts` | `map[string]Product` | Map of product identifiers to their `Product` details |

## Usage Example

```go
result := xml.FeedResult{
    WinVulnerabilities: []xml.Vulnerability{
        {CVE: "CVE-2024-1234"},
    },
    WinProducts: map[string]xml.Product{
        "windows-11": {Name: "Windows 11", Version: "23H2"},
    },
}

for _, vuln := range result.WinVulnerabilities {
    product := result.WinProducts[vuln.ProductID]
    fmt.Printf("CVE %s affects %s\n", vuln.CVE, product.Name)
}
```

## Notes

- `WinProducts` uses a string key (typically a product ID or name) for O(1) lookups when correlating vulnerabilities to products.
- Both fields are exported, making `FeedResult` suitable for cross-package use after XML feed parsing.
