Analyzes Windows OS vulnerabilities against Microsoft Security Response Center (MSRC) security bulletins, computing which CVEs affect a given operating system based on kernel version and product matching.

## Key Components

| Symbol | Description |
|---|---|
| `Analyze` | Main entry point — loads the MSRC bulletin, matches the OS to affected products, computes new/resolved vulnerabilities, and persists deltas to the datastore |
| `isOSVulnerable` | Checks whether a specific OS kernel version is below the fixed build for a given CVE; returns the resolved-in version string if vulnerable |
| `isProductVersionMismatch` | Compares the first three version segments (e.g. `10.0.22000`) to prevent false positives across different Windows releases |
| `loadBulletin` | Resolves and deserializes the most recent MSRC bulletin file from disk for the given OS |
| `getBuildNumber` | Parses a dotted version string (`10.0.22000.194`) into its build number integer and segment slice |
| `vulnBatchSize` | Batch size constant (`500`) used when inserting/deleting vulnerability records |

## Usage Example

```go
vulns, err := msrc.Analyze(
    ctx,
    datastore,
    fleet.OperatingSystem{
        ID:            42,
        KernelVersion: "10.0.22000.194",
    },
    "/var/fleet/vulns",
    true,  // collectVulns: return newly inserted findings
    logger,
)
if err != nil {
    log.Fatal(err)
}

for _, v := range vulns {
    fmt.Printf("CVE: %s, resolved in: %s\n", v.CVE, *v.ResolvedInVersion)
}
```

> **Note:** `Analyze` returns an error (and skips all deletions) if the loaded bulletin contains zero vulnerabilities, guarding against accidental mass-remediation caused by a corrupted feed file.
