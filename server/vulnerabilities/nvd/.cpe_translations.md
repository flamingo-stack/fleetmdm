Handles loading, downloading, and applying CPE (Common Platform Enumeration) translation rules that map software entries to NVD CPE Dictionary identifiers when standard matching logic fails.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `LoadCPETranslations` | func | Public wrapper to load CPE translations from a JSON file path |
| `DownloadCPETranslationsFromGithub` | func | Downloads `cpe_translations.json` from the latest `fleetdm/nvd` GitHub release; skips if already up-to-date |
| `CPETranslations` | type | Slice of `CPETranslationItem`; implements `Translate` to find the first matching translation for a given software entry |
| `CPETranslationSoftware` | struct | Match criteria (name, bundle identifier, source); supports exact strings and `/regex/` patterns |
| `CPETranslation` | struct | Filter output containing `product`, `vendor`, `target_sw`, `sw_edition`, `part`, and a `Skip` flag to suppress vulnerability reporting |
| `regexpCache` | struct | Non-concurrent cache for compiled `regexp.Regexp` instances, keyed by pattern string |

## Usage Example

```go
// Load translations from disk
translations, err := nvd.LoadCPETranslations("/path/to/cpe_translations.json")
if err != nil {
    log.Fatal(err)
}

// Translate a software entry into CPE filter criteria
reCache := newRegexpCache()
software := &fleet.Software{
    Name:             "1Password 7 - Password Manager",
    BundleIdentifier: "com.1password.1password",
    Source:           "apps",
}

filter, matched, err := translations.Translate(reCache, software)
if err != nil {
    log.Fatal(err)
}
if matched {
    if filter.Skip {
        // No CVEs will be reported for this software
        return
    }
    fmt.Printf("vendor=%v product=%v\n", filter.Vendor, filter.Product)
    // vendor=[agilebits] product=[1password]
}
```

The `cpe_translations.json` format supports regex patterns (enclosed in `/`) for flexible name matching:

```json
[
  {
    "software": { "bundle_identifier": ["/^com\\.1password\\./"] },
    "filter":   { "vendor": ["agilebits"], "product": ["1password"] }
  }
]
```
