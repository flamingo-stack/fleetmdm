Provides NVD (National Vulnerability Database) CPE matching utilities for normalizing and sanitizing Fleet software metadata into formats suitable for vulnerability lookups.

## Key Components

| Function/Variable | Description |
|---|---|
| `sanitizeSoftwareName` | Strips architecture strings, language codes, version numbers, vendor info, bundle identifiers, and `.app` suffixes from a software name; lowercases the result |
| `productVariations` | Generates a deduplicated set of product name variants (with/without vendor parts, space-stripped, underscore-joined) for CPE matching; handles VSCode extension IDs |
| `vendorVariations` | Generates a deduplicated set of vendor name variants from `Vendor` and `BundleIdentifier` fields, filtering out common stop words; handles VSCode extension IDs |
| `sanitizeMatch` | Prepares a string for SQLite FTS5 queries by replacing non-alphanumeric characters with spaces and quoting each token to prevent `AND`/`OR`/`NOT` operator interpretation |
| `sanitizeVersion` | Normalizes version strings to dot-separated format (e.g., `"5.11.1 (8356)"` → `"5.11.1.8356"`) |
| `targetSW` | Maps a Fleet software source (e.g., `apps`, `programs`, `chrome_extensions`) to its NVD CPE target software string |
| `stopWords` | Set of common words filtered from vendor names (e.g., `Inc`, `Corporation`, `Software`) |
| `langCodes` | Set of BCP 47 locale codes removed from software names during sanitization |

## Usage Example

```go
sw := &fleet.Software{
    Name:             "Zoom (64-bit) - Video Conferencing",
    Vendor:           "Zoom Video Communications, Inc.",
    BundleIdentifier: "us.zoom.xos",
    Source:           "apps",
    Version:          "5.11.1 (8356)",
}

name    := sanitizeSoftwareName(sw)       // "zoom"
target  := targetSW(sw)                   // "macos"
version := sanitizeVersion(sw.Version)    // "5.11.1.8356"
products := productVariations(sw)         // ["zoom", "zoom", ...]
vendors  := vendorVariations(sw)          // ["zoom", "video", "communications", ...]

query := sanitizeMatch("Zoom.app")        // `"Zoom"` (FTS5-safe tokens)
```
