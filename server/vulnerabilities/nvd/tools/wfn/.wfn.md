Parses and represents CPE (Common Platform Enumeration) names using the Well-Formed Name (WFN) data model, supporting both URI binding (`cpe:/`) and formatted string binding (`cpe:2.3:`) formats.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Attributes` | struct | WFN data model with fields: `Part`, `Vendor`, `Product`, `Version`, `Update`, `Edition`, `SWEdition`, `TargetSW`, `TargetHW`, `Other`, `Language` |
| `Parse` | func | Auto-detects and parses a CPE string from URI or formatted string binding |
| `NewAttributesWithAny` | func | Creates `Attributes` with all fields set to `Any` (`""`) |
| `NewAttributesWithNA` | func | Creates `Attributes` with all fields set to `NA` (`"-"`) |
| `WFNize` | func | Sanitizes a raw string into a CPE23-NAME compliant `avstring` value |
| `Any` / `NA` | const | Logical values representing wildcard (`""`) and not-applicable (`"-"`) |
| `KnownParts` | var | Maps CPE part codes (`"a"`, `"o"`, `"h"`) to human-readable names |

## Usage Example

```go
// Parse a CPE formatted string
attr, err := wfn.Parse("cpe:2.3:a:vendor:product:1.0:*:*:*:*:*:*:*")
if err != nil {
    log.Fatal(err)
}
fmt.Println(attr.Vendor)  // "vendor"
fmt.Println(attr.Version) // "1.0"

// Parse a CPE URI binding
attr, err = wfn.Parse("cpe:/a:vendor:product:1.0")

// Create attributes initialized to NA
attr = wfn.NewAttributesWithNA()
attr.Vendor = "acme"
attr.Product = "my app"

// Sanitize a raw string for use in a WFN
safe, err := wfn.WFNize("My Product 2.0!")
fmt.Println(safe) // "My_Product_2.0!"

// Print WFN representation
fmt.Println(attr.String())
// wfn:[part=NA,vendor="acme",product=NA,...,language=NA]
```
