Implements CPE (Common Platform Enumeration) WFN (Well-Formed Name) attribute matching and set-relation comparison per the Name Matching Specification v2.3, determining whether two CPE names are disjoint, equal, a subset, or a superset of each other.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Relation` | `type int` | Enum of four set relations: `Disjoint`, `Subset`, `Equal`, `Superset` |
| `Comparison` | `struct` | Per-attribute relation results across all 11 CPE WFN fields |
| `Compare` | `func` | Full attribute-by-attribute comparison of two `*Attributes`, returns `Comparison` |
| `Match` | `func` | Fast boolean check — returns `false` if any attribute pair is disjoint |
| `CompareAttr` | `func` | Single attribute-value relation per the spec's truth table |
| `HasWildcard` | `func` | Detects unquoted `*` or `?` wildcards in an attribute string |

`Comparison` exposes four predicate methods — `IsDisjoint()`, `IsEqual()`, `IsSubset()`, `IsSuperset()` — plus a `Relation()` summary method.

## Usage Example

```go
src, _ := wfn.Parse("cpe:2.3:a:vendor:product:1.*:*:*:*:*:*:*:*")
tgt, _ := wfn.Parse("cpe:2.3:a:vendor:product:1.2:*:*:*:*:*:*:*")

// Full comparison
cmp, err := wfn.Compare(src, tgt)
if err != nil {
    log.Fatal(err)
}
fmt.Println(cmp.Relation())   // SUPERSET
fmt.Println(cmp.IsDisjoint()) // false

// Fast boolean match (e.g. vulnerability scanning)
if wfn.Match(src, tgt) {
    fmt.Println("target is covered by source")
}

// Single attribute comparison
rel, err := wfn.CompareAttr("1.*", "1.2")
fmt.Println(rel) // SUPERSET
```

**Wildcard semantics:** `*` matches any sequence of characters; `?` matches exactly one character. Wildcards are only valid on the source side — a target attribute containing an unquoted wildcard causes `CompareAttr` to return an error.
