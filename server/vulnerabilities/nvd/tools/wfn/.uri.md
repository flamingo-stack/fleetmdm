Provides conversion between Well-Formed Name (WFN) attributes and the CPE URI binding format (CPE 2.2 style), handling encoding, decoding, and special character transformations.

## Key Components

| Function | Description |
|---|---|
| `BindToURI()` | Serializes `Attributes` to a CPE URI string, percent-encoding special characters and packing edition sub-components |
| `UnbindURI()` | Parses a CPE URI string into an `Attributes` struct, decoding percent-encoded values and unpacking edition fields |
| `bindValueURI()` | Encodes a single WFN attribute value to URI form (`NA` → `-`, `Any` → `""`, specials → `%xx`) |
| `unbindValueURIAtTill()` | Decodes a URI segment up to a delimiter, reversing percent-encoding back to WFN escaped form |
| `pctEncode()` | Maps a single byte to its percent-encoded URI representation |
| `pack()` | Packs edition sub-fields (`Edition`, `SWEdition`, `TargetSW`, `TargetHW`, `Other`) into the `~`-delimited CPE 2.3 compatibility format |

## Usage Example

```go
// Bind WFN attributes to a CPE URI
attr := &wfn.Attributes{
    Part:     "a",
    Vendor:   "microsoft",
    Product:  "internet_explorer",
    Version:  "8\\.0\\.6001",
    Update:   "beta",
    Edition:  "",
    Language: "en",
}
uri := attr.BindToURI()
// => "cpe:/a:microsoft:internet_explorer:8.0.6001:beta::en"

// Parse a CPE URI back into WFN attributes
parsed, err := wfn.UnbindURI("cpe:/a:microsoft:internet_explorer:8.0.6001:beta::en")
if err != nil {
    log.Fatal(err)
}
fmt.Println(parsed.Vendor)  // "microsoft"
fmt.Println(parsed.Product) // "internet_explorer"
```
