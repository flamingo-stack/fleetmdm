Defines the `Matcher` interface and composable matcher types for matching WFN (Well-Formed Name) CPE attributes against collections of `Attributes` structs.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Matcher` | Interface | Core interface with `Match()` and `Config()` methods for attribute matching |
| `MatchAll` | Function | Returns a `Matcher` that passes only when **all** child matchers return results |
| `MatchAny` | Function | Returns a `Matcher` that passes when **any** child matcher returns results |
| `DontMatch` | Function | Wraps a `Matcher` and inverts its results (logical NOT) |
| `MatchOnlyVersion` | Method | Checks if the `Version` field of two `Attributes` structs match |
| `MatchWithoutVersion` | Method | Checks all `Attributes` fields except `Version` for equality |
| `multiMatcher` | Struct | Internal implementation for `MatchAll`/`MatchAny`; thread-safe via `sync.Mutex` |
| `notMatcher` | Struct | Internal implementation for `DontMatch`; returns attributes not matched by the wrapped matcher |

## Usage Example

```go
// Build individual attribute matchers
attrA := &wfn.Attributes{Vendor: wfn.Any, Product: "chrome", Part: "a"}
attrB := &wfn.Attributes{Vendor: "google", Product: wfn.Any, Part: "a"}

// Compose matchers: match attrs satisfying both conditions
combined := wfn.MatchAll(attrA, attrB)

candidates := []*wfn.Attributes{
    {Vendor: "google", Product: "chrome", Part: "a", Version: "120.0"},
}

matches := combined.Match(candidates, true)
// matches contains attrs satisfying all sub-matchers

// Invert: find attrs that do NOT match attrA
excluded := wfn.DontMatch(attrA)
nonMatches := excluded.Match(candidates, false)
```

> **Note:** `multiMatcher.Match` is thread-safe and applies an app-part (`Part == "a"`) guard at depth zero to prevent false positives when multiple non-app attributes are matched simultaneously.
