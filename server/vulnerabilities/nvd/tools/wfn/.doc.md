Package `wfn` provides representation, bindings, and matching for Well-Formed CPE (Common Platform Enumeration) names, implementing the NIST specifications [NISTIR 7695](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir7695.pdf) and [NISTIR 7696](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir7696.pdf).

## Key Components

This is a package declaration file (`doc.go`) with no exported symbols of its own. It serves as the canonical documentation entry point for the `wfn` package, which provides:

- **WFN Representation** — structured data types for Well-Formed CPE name attributes
- **Bindings** — serialization/deserialization between WFN and CPE URI/formatted string bindings
- **Matching** — CPE name comparison and matching logic per NIST standards

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/third_party/wfn"

// Parse a CPE formatted string binding
attr, err := wfn.Parse("cpe:2.3:a:vendor:product:1.0:*:*:*:*:*:*:*")
if err != nil {
    log.Fatal(err)
}

// Access individual WFN attributes
fmt.Println(attr.Vendor)  // "vendor"
fmt.Println(attr.Version) // "1.0"

// Match two CPE names
match := wfn.Match(attr1, attr2)
```

## Standards Compliance

| Standard | Description |
|---|---|
| NISTIR 7695 | CPE Naming Specification (WFN representation) |
| NISTIR 7696 | CPE Name Matching Specification |
