Handles serialization and deserialization of Well-Formed Name (WFN) attributes to and from CPE Formatted String Binding (FSB), including escape/unescape logic for special characters.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `BindToFmtString` | Method (`Attributes`) | Serializes all 11 WFN attribute fields into a colon-delimited FSB string with the standard prefix |
| `UnbindFmtString` | Function | Parses an FSB string back into an `Attributes` struct, returning an error on malformed input |
| `StripSlashes` | Function | Removes backslash escaping from punctuation characters (`.`, `_`, `-`) in an attribute value |
| `bindValueFS` | Function (internal) | Maps `Any`/`NA` constants to `*`/`-` and strips slashes for regular values |
| `unbindValueFSAt` | Function (internal) | Reads a single attribute value from the FSB string at a given byte offset |
| `addSlashesAt` | Function (internal) | Re-escapes special characters (wildcards, punctuation) when parsing FSB fragments back to WFN |

## Usage Example

```go
// Bind WFN attributes to a formatted string
attr := wfn.Attributes{
    Part:    "a",
    Vendor:  "example_vendor",
    Product: "my_product",
    Version: "1.0",
}
fsb := attr.BindToFmtString()
// Result: "cpe:2.3:a:example_vendor:my_product:1.0:*:*:*:*:*:*:*"

// Parse a formatted string back into WFN attributes
parsed, err := wfn.UnbindFmtString("cpe:2.3:a:example_vendor:my_product:1.0:*:*:*:*:*:*:*")
if err != nil {
    log.Fatal(err)
}
fmt.Println(parsed.Vendor) // "example_vendor"

// Strip escape slashes from a value
clean := wfn.StripSlashes(`example\.vendor`)
fmt.Println(clean) // "examplevendor"
```
