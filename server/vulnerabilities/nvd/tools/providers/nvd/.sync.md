Provides NVD (National Vulnerability Database) data feed synchronization, orchestrating multiple `Syncer` implementations to sync remote feeds to a local directory while aggregating errors.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Syncer` | Interface | Abstract contract for feed synchronizers; requires a `Sync(ctx, src, localdir)` method |
| `SyncError` | Type (`[]string`) | Aggregates multiple sync errors into a single formatted error message |
| `Sync` | Struct | Orchestrates synchronization across multiple feeds using a shared source config and local directory |
| `Sync.Do` | Method | Executes all registered `Syncer` feeds, creating the local directory if needed and collecting errors |

## Usage Example

```go
// Configure and run synchronization for multiple NVD feeds
s := nvd.Sync{
    Feeds: []nvd.Syncer{
        &nvd.HTTPSyncer{}, // example feed implementation
    },
    Source:   nvd.NewSourceConfig(),
    LocalDir: "/var/cache/nvd",
}

if err := s.Do(context.Background()); err != nil {
    // SyncError reports all individual failures together
    fmt.Println(err) // "2 synchronisation errors:\n\t..."
}
```

**Partial failure handling:** `Do` does not short-circuit on a single feed failure — all feeds are attempted, and all errors are collected into a `SyncError` returned at the end.

**Default source config:** If `Source` is `nil`, `Do` automatically calls `NewSourceConfig()` to apply defaults, so explicit source configuration is optional.
