HTTP helper utilities for the NVD (National Vulnerability Database) sync client, providing request construction and response validation with configurable User-Agent support.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `userAgent` | `var` | Package-level User-Agent string, defaults to `"nvdsync-" + Version` |
| `httpNewRequestContext` | `func` | Creates an `*http.Request` with context and the configured User-Agent header |
| `httpResponseNotOK` | `func` | Returns an error if the HTTP response status is not `200 OK`, including up to 4KB of the response body |
| `SetUserAgent` | `func` | Validates and sets a custom User-Agent string (ASCII-only) |
| `UserAgent` | `func` | Returns the currently configured User-Agent string |

## Usage Example

```go
// Set a custom User-Agent before making requests
if err := nvd.SetUserAgent("my-scanner/1.0"); err != nil {
    log.Fatal(err) // returns error for non-ASCII characters
}

// Current User-Agent in use
fmt.Println(nvd.UserAgent()) // "my-scanner/1.0"

// Internal usage: create a context-aware request
req, err := httpNewRequestContext(ctx, http.MethodGet, "https://nvd.nist.gov/feeds/json/cve/1.1/nvdcve-1.1-recent.json.gz")
if err != nil {
    return err
}

resp, err := http.DefaultClient.Do(req)
if err != nil {
    return err
}
defer resp.Body.Close()

// Validate response status
if err := httpResponseNotOK(resp); err != nil {
    return err // includes URL, status code, and response body snippet
}
```

## Notes

- `httpNewRequestContext` and `httpResponseNotOK` are unexported; they are internal helpers used by the NVD sync client.
- `SetUserAgent` enforces ASCII-only values to prevent malformed HTTP headers.
- Response body reads in `httpResponseNotOK` are capped at **4KB** to avoid unbounded memory consumption on error responses.
