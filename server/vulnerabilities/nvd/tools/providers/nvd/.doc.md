Package `nvd` (datafeed) provides NVD data feed synchronization for nvdsync, designed to interface with the [NVD vulnerability data feeds](https://nvd.nist.gov/vuln/data-feeds).

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Version` | `const string` | Declares the current version of the `nvdsync/datasync` module (`"1.0"`) |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/nvd"

func main() {
    fmt.Println("nvdsync/datasync version:", nvd.Version)
}
```
