Provides synchronization logic for NVD (National Vulnerability Database) CVE data feeds, handling downloading, verification, and local caching of CVE feed files in multiple formats and compressions.

## Key Components

- **`CVE`** — Integer type representing a CVE feed variant (XML/JSON, gzip/zip combinations across versions 1.0–2.0)
- **`SupportedCVE`** — Map of feed name strings to `CVE` constants, used for flag parsing
- **`cveFile`** — Internal struct pairing a `CVE` feed type with its `.meta` and data filenames
- **`metaFile`** — Struct representing NVD `.meta` file content (last modified date, sizes, SHA256 hash)

### Key Methods

| Method | Description |
|---|---|
| `CVE.Sync()` | Syncs all feed files for a CVE type to a local directory |
| `CVE.String()` | Returns the canonical feed name (e.g., `cve-1.0.json.gz`) |
| `CVE.Help()` | Returns CLI flag help text listing all supported feeds |
| `cveFile.Sync()` | Downloads and atomically replaces a single feed file if outdated |
| `cveFile.needsUpdate()` | Compares remote `.meta` against local copy by date, size, and SHA256 |
| `cveFile.downloadAndVerify()` | Downloads a feed file to a temp path and validates size + hash |
| `metaFile.Equal()` | Compares two meta files field-by-field |
| `metaFile.WriteFile()` | Atomically writes a meta file to disk with `.bak` fallback |

## Usage Example

```go
// Select the JSON 1.1 gzip feed
feed := nvd.SupportedCVE["cve-1.1.json.gz"]

// Sync all yearly + recent + modified files to a local directory
src := nvd.SourceConfig{
    Scheme:      "https",
    Host:        "nvd.nist.gov",
    CVEFeedPath: "/feeds/json/cve/{{.Version}}/",
}

if err := feed.Sync(ctx, src, "/var/lib/nvd"); err != nil {
    log.Fatalf("CVE sync failed: %v", err)
}
```

Feed files are written atomically using `.bak` intermediates, and updates are skipped when the local file's size and SHA256 already match the remote `.meta`.
