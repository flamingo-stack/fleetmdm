Provides CPE (Common Platform Enumeration) data feed synchronization for NVD vulnerability management, supporting XML 2.2 and 2.3 formats in both gzip and zip compression.

## Key Components

- **`CPE`** — Integer type representing a CPE feed variant; implements `flag.Value` (`Set`) and `fmt.Stringer` (`String`) interfaces for CLI flag integration.
- **`SupportedCPE`** — Map of feed name strings to `CPE` constants, covering all four supported format/compression combinations.
- **`CPE.Sync`** — Downloads and persists a CPE feed to a local directory, using ETags to avoid redundant downloads.
- **`cpeFile`** — Internal struct managing per-feed filenames and sync logic.
- **`cpeFile.needsUpdate`** — Issues an HTTP `HEAD` request and compares the remote ETag against a locally cached value to determine if a download is needed.
- **`cpeFile.download`** — Performs the actual HTTP `GET`, streams the response to a temp file, and returns the ETag and temp path.

## Usage Example

```go
// Select a CPE feed and sync it to a local directory
feed := nvd.SupportedCPE["cpe-2.3.xml.gz"]

src := nvd.SourceConfig{
    Scheme:      "https",
    Host:        "nvd.nist.gov",
    CPEFeedPath: "/feeds/xml/cpe/dictionary/",
}

err := feed.Sync(context.Background(), src, "/var/cache/nvd")
if err != nil {
    log.Fatalf("CPE sync failed: %v", err)
}

// Use as a CLI flag
var cpeFeed nvd.CPE
flag.Var(&cpeFeed, "cpe-feed", cpeFeed.Help())
```

The sync process is idempotent: it checks the remote ETag first and skips the download if the local copy is current. On update, the existing data file is backed up before replacement to guard against partial writes.
