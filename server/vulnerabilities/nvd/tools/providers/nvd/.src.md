Defines and manages the NVD (National Vulnerability Database) data feed source configuration, supporting both environment variable and command-line flag initialization.

## Key Components

- **`SourceConfig`** — Struct holding NVD feed connection parameters (scheme, host, CVE/CPE feed paths), with struct tags for env var names and defaults.
- **`NewSourceConfig()`** — Constructor that populates `SourceConfig` fields using reflection: reads from environment variables (via `envconfig` tags) and falls back to `default` tag values.
- **`AddFlags()`** — Registers `SourceConfig` fields as `flag.FlagSet` command-line flags, allowing runtime override of any source setting.

## Usage Example

```go
// Initialize from environment variables (with defaults as fallback)
src := nvd.NewSourceConfig()

// Optionally register CLI flags for override
src.AddFlags(flag.CommandLine)
flag.Parse()

// Use the config values
fmt.Println(src.Scheme)      // "https" (or $NVDSYNC_SCHEME)
fmt.Println(src.Host)        // "nvd.nist.gov" (or $NVDSYNC_HOST)
fmt.Println(src.CVEFeedPath) // "/feeds/{{.Encoding}}/cve/{{.Version}}/" (or $NVDSYNC_CVE_FEED_PATH)
fmt.Println(src.CPEFeedPath) // "/feeds/xml/cpe/dictionary/" (or $NVDSYNC_CPE_FEED_PATH)
```

**Environment variable precedence:** env var → `default` tag → (no flag fallback unless `AddFlags` + `flag.Parse()` is used).

| Config Field | Env Var | Default |
|---|---|---|
| `Scheme` | `NVDSYNC_SCHEME` | `https` |
| `Host` | `NVDSYNC_HOST` | `nvd.nist.gov` |
| `CVEFeedPath` | `NVDSYNC_CVE_FEED_PATH` | `/feeds/{{.Encoding}}/cve/{{.Version}}/` |
| `CPEFeedPath` | `NVDSYNC_CPE_FEED_PATH` | `/feeds/xml/cpe/dictionary/` |
