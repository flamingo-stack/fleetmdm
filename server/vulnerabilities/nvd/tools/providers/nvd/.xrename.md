Cross-device file rename utility that falls back to copy-then-delete when `os.Rename` fails due to a `LinkError` (e.g., source and destination are on different filesystems/devices).

## Key Components

### `xRename(oldpath, newpath string) error`

Attempts an atomic `os.Rename` first. If a `*os.LinkError` is returned, it falls back to:
1. Opening the source file and verifying it is a regular file
2. Creating the destination file with matching permissions
3. Copying contents via `io.Copy`
4. Removing the original with `os.Remove`

Returns an error if any step fails, including if the source is not a regular file (symlinks, directories, etc. are rejected).

## Usage Example

```go
// Move a temp download into its final location,
// transparently handling cross-device moves.
err := xRename("/tmp/nvd-data-download.json", "/var/lib/nvd/data.json")
if err != nil {
    log.Fatalf("failed to move NVD data file: %v", err)
}
```

## Notes

- The fallback is **not atomic**: a crash between the copy and the `os.Remove` will leave the source file intact (safe, but may leave a stale temp file).
- Only regular files are supported in the fallback path; non-regular files (directories, symlinks, devices) return an explicit error.
