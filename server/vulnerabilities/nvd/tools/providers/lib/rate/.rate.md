Provides a simple token-bucket rate limiter that blocks callers until a token is available, supporting configurable burst capacity and steady-state throughput.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Limiter` | Interface | Single-method interface exposing `Allow()`, which blocks until the caller may proceed |
| `BurstyLimiter` | Constructor | Creates a `Limiter` that allows bursts up to `requestsPerPeriod` and refills tokens at a steady rate of `period / requestsPerPeriod` |
| `limiter` | Struct | Internal implementation backed by a buffered channel acting as the token bucket |

## Usage Example

```go
import (
    "time"
    "github.com/flamingo-stack/fleetmdm/rate"
)

// Allow up to 10 requests per second, with burst capacity of 10
limiter := rate.BurstyLimiter(time.Second, 10)

for _, req := range requests {
    limiter.Allow() // blocks if burst capacity is exhausted
    go process(req)
}
```

## Behavior Notes

- **Burst capacity**: The channel buffer size equals `requestsPerPeriod`, so up to that many requests can proceed immediately if tokens have accumulated.
- **Steady-state rate**: A background goroutine ticks every `period / requestsPerPeriod` and adds one token per tick, ensuring a smooth long-term rate.
- **Blocking**: `Allow()` blocks the caller until a token is available — there is no non-blocking or timeout variant.
- **No cleanup**: The internal ticker goroutine runs indefinitely; the `Limiter` has no `Close()` method, so it is intended for long-lived use.
