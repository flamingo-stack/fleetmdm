Provides debug utilities for HTTP request tracing and error-handling behavior in the NVD client package, controlled entirely through environment variables.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `debug` | `var` (struct) | Package-level struct holding all debug flags and request counter |
| `getBool` | `func` | Reads a boolean environment variable |
| `getUint` | `func` | Reads a uint64 environment variable with a default fallback |
| `obfuscateHeaders` | `func` | Clones request headers, masking sensitive auth headers before logging |
| `traceRequestStart` | `func` | Assigns a request ID and optionally dumps the request to stderr |
| `traceRequestEnd` | `func` | Optionally dumps the HTTP response to stderr |
| `StopOrContinue` | `func` | Controls concurrent download failure behavior — stop or log-and-continue |

## Environment Variables

| Variable | Effect |
|---|---|
| `NVD_TRACE_REQUESTS` | Print HTTP requests/responses to stderr |
| `NVD_TRACE_REQUEST_BODIES` | Also print request/response bodies |
| `NVD_CONTINUE_DOWNLOADING` | Keep processing remaining requests after a failure |
| `NVD_FAIL_REQUEST` | Fail the nth HTTP request (for testing) |

## Usage Example

```go
// Enable request tracing before running
os.Setenv("NVD_TRACE_REQUESTS", "true")
os.Setenv("NVD_TRACE_REQUEST_BODIES", "true")

// In an errgroup for concurrent downloads:
g.Go(func() error {
    resp, err := http.Get(url)
    if err != nil {
        // Returns nil and logs if NVD_CONTINUE_DOWNLOADING=true,
        // otherwise propagates the error to cancel the group.
        return StopOrContinue(err)
    }
    defer resp.Body.Close()
    // process resp...
    return nil
})
```
