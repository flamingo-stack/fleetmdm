HTTP client wrapper providing a `Client` interface and utilities for making context-aware GET requests with tracing and debug support.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Client` | Interface | Abstraction over `*http.Client` exposing `Do` and `Get` |
| `Default()` | Function | Returns `http.DefaultClient` as a `Client` |
| `Get()` | Function | Builds a context-aware GET request with custom headers, traces it, and executes via `Client.Do` |
| `Err` | Struct | Structured HTTP error carrying status code, status text, and response body |

## Usage Example

```go
package main

import (
    "context"
    "net/http"

    "github.com/flamingo-stack/fleetmdm/pkg/client"
)

func main() {
    c := client.Default()

    headers := http.Header{
        "Authorization": []string{"Bearer my-token"},
    }

    resp, err := client.Get(context.Background(), c, "https://example.com/api/devices", headers)
    if err != nil {
        if httpErr, ok := err.(*client.Err); ok {
            // Structured HTTP error with Code, Status, Body
            _ = httpErr.Code
        }
        panic(err)
    }
    defer resp.Body.Close()
}
```

## Notes

- **Debug injection**: `Get` checks an internal `debug.failRequestNum` against the request trace ID; matching requests return a synthetic `503` error, useful for fault-injection testing.
- **Tracing hooks**: `traceRequestStart` / `traceRequestEnd` wrap every request for observability (defined elsewhere in the package).
- **Custom clients**: Accept any `Client` implementation in `Get`, making it easy to inject mocks or custom transports in tests.
