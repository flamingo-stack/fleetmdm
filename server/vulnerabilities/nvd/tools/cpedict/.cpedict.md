Parses and decodes CPE (Common Platform Enumeration) Dictionary XML files conforming to the CPE Dictionary specification 2.3, supporting NVD vulnerability feed data structures.

## Key Components

| Type / Function | Description |
|---|---|
| `TextType` | Multi-language text map (`lang → value`); implements `xml.Unmarshaler` |
| `NamePattern` | Wraps `wfn.Attributes` to represent a CPE name; implements `xml.UnmarshalerAttr` |
| `Reference` | URL and description for supplemental CPE metadata |
| `DeprecatedInfo` | Name and type for a deprecating CPE entry |
| `Deprecation` | Deprecation date and list of `DeprecatedInfo` entries |
| `CPE23Item` | CPE 2.3-specific data (name, optional deprecation) for a dictionary entry |
| `CPEItem` | Full dictionary entry including titles, notes, references, and CPE 2.3 data |
| `Generator` | Dictionary file metadata (tool name, version, schema, timestamp) |
| `CPEList` | Root structure containing `Generator` metadata and all `CPEItem` entries |
| `Decode` | Reads an `io.Reader` and returns a decoded `*CPEList` |

## Usage Example

```go
package main

import (
    "fmt"
    "os"

    "github.com/flamingo-stack/fleetmdm/server/vulnerabilities/nvd/tools/cpedict"
)

func main() {
    f, err := os.Open("official-cpe-dictionary_v2.3.xml")
    if err != nil {
        panic(err)
    }
    defer f.Close()

    list, err := cpedict.Decode(f)
    if err != nil {
        panic(err)
    }

    fmt.Printf("Generated by: %s %s\n", list.Generator.ProductName, list.Generator.ProductVersion)
    fmt.Printf("Total entries: %d\n", len(list.Items))

    for _, item := range list.Items[:5] {
        fmt.Printf("CPE: %s | Deprecated: %v\n", item.CPE23.Name, item.Deprecated)
        fmt.Printf("  Title (en): %s\n", item.Title["en"])
    }
}
```

> **Note:** This is a partial implementation — `PlatformType`, `CheckFactRefType`, and `ProvenanceRecord` are not yet implemented, as NVD feed parsing does not require them.
