A thread-safe, size-bounded CVE lookup cache that maps CPE (Common Platform Enumeration) attribute sets to matching vulnerability entries from an NVD feed dictionary, with LRU-style eviction and single-flight deduplication for concurrent requests.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Index` | `map[string][]Vuln` | Maps CPE product names to vulnerability entries for fast pre-filtering |
| `NewIndex` | func | Builds an `Index` from a `Dictionary`, keying entries by product name |
| `MatchResult` | struct | Pairs a matched `Vuln` with the specific `[]*wfn.Attributes` CPEs that triggered it |
| `Cache` | struct | Core cache with configurable max size, `RequireVersion` flag, hit tracking, and eviction queue |
| `NewCache` | func | Constructs a `Cache` with a given `Dictionary` |
| `Cache.SetMaxSize` | method | Chainable setter; `0` = unlimited, `-1` = caching disabled |
| `Cache.SetRequireVersion` | method | Chainable setter; skips matches where CPE `Version == ANY` when `true` |
| `Cache.Get` | method | Returns `[]MatchResult` for a CPE set, populating cache on miss with single-flight dedup |
| `Cache.HitRatio` | method | Returns cache hit percentage over all lookups |
| `cacheKey` | func | Deterministic, order-independent string key from a CPE attribute slice |

## Usage Example

```go
// Load NVD feed and build cache
dict, err := cvefeed.LoadJSONDictionary("nvdcve-1.1-2024.json")
if err != nil {
    log.Fatal(err)
}

cache := cvefeed.NewCache(dict).
    SetMaxSize(100 * 1024 * 1024). // 100 MB cap
    SetRequireVersion(true)

// Optionally attach an Index for faster product-scoped lookups
cache.Idx = cvefeed.NewIndex(dict)

// Query for a set of CPE attributes
cpes := []*wfn.Attributes{
    {Part: "a", Vendor: "apache", Product: "log4j", Version: "2.14.1"},
}

matches := cache.Get(cpes)
for _, m := range matches {
    fmt.Printf("CVE: %s, matched %d CPEs\n", m.CVE.ID(), len(m.CPEs))
}

fmt.Printf("Cache hit ratio: %.1f%%\n", cache.HitRatio())
```

> **Concurrency note:** Concurrent requests for the same cache key are deduplicated — only the first goroutine computes the result; others block on a `ready` channel until it completes.
