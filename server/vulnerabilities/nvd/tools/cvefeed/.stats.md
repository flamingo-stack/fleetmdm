Provides NVD CVE feed statistics gathering and reporting, tracking CVE counts, matching rules, and the prevalence of AND-operator configurations across CPE types.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Stats` | struct | Holds aggregated statistics: total CVEs, rules, AND-rules, and per-pattern AND operator counts |
| `NewStats()` | func | Constructor — returns a zeroed `*Stats` with an initialized `operatorANDs` map |
| `Reset()` | method | Clears all counters and reinitializes the map |
| `Gather(dict Dictionary)` | method | Iterates a `Dictionary` of NVD vulnerabilities, flattening each configuration node into a canonical rule string and accumulating stats |
| `ReportOperatorAND()` | method | Prints AND-operator usage as percentages, sorted by frequency |
| `stack` | struct | Thread-safe LIFO string stack used internally during rule traversal |
| `flattenRule(...)` | func | Recursively flattens an NVD configuration node tree into a human-readable rule string (e.g., `(a AND o)`) |
| `percentage(...)` | func | Helper that computes `(partial / total) * 100` |

## Usage Example

```go
// Load a NVD JSON feed into a Dictionary (e.g. via cvefeed.LoadJSONDictionary)
dict, err := cvefeed.LoadJSONDictionary("nvdcve-1.1-2023.json")
if err != nil {
    log.Fatal(err)
}

// Gather stats from the loaded feed
stats := cvefeed.NewStats()
stats.Gather(dict)

// Print AND-operator rule breakdown
stats.ReportOperatorAND()
// Output example:
// Total rules with AND operator: 12.34%
// 45.67%: (a AND o)
// 32.10%: (h AND o)

// Reset and reuse for another feed
stats.Reset()
stats.Gather(anotherDict)
```

## Notes

- `flattenRule` encodes CPE part types (`a` = application, `h` = hardware, `o` = operating system) into the rule string, making AND-rule patterns human-readable and groupable.
- The internal `stack` is mutex-guarded for safe use during recursive traversal.
