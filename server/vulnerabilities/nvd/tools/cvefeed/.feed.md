Parses NVD (National Vulnerability Database) CVE JSON feed data, with automatic detection and decompression of gzip and bzip2 formats.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ParseJSON` | func | Parses an NVD CVE JSON feed from an `io.Reader`, returning a slice of `Vuln` items |
| `getFeed` | func (internal) | Decodes the raw JSON into the `NVDCVEFeedJSON10` schema struct |
| `setupReader` | func (internal) | Inspects the first 2 bytes of the stream to auto-detect gzip, bzip2, or plain text encoding |

## Usage Example

```go
// Open a local NVD feed file (plain JSON, gzip, or bzip2)
f, err := os.Open("nvdcve-1.1-2024.json.gz")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

vulns, err := cvefeed.ParseJSON(f)
if err != nil {
    log.Fatal(err)
}

for _, v := range vulns {
    fmt.Println(v.ID())
}
```

## Notes

- Supports three input formats detected automatically via magic bytes: plain JSON, gzip (`0x1f 0x8b`), and bzip2 (`BZ`).
- Only CVE items with non-nil `Configurations` are included in the returned slice — bare CVE entries without affected product data are skipped.
- Source: [`feed.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/vulnerabilities/nvd/tools/cvefeed/feed.go)
