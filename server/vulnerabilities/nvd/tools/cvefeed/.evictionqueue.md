A min-heap priority queue used internally by the CVE feed LRU cache to track and evict the least-recently-used entries based on access time.

## Key Components

| Type/Function | Description |
|---|---|
| `evictionData` | Holds a cache key, its heap index, and last access timestamp |
| `evictionQueue` | Wrapper around `evictionHeap` exposing LRU queue operations |
| `evictionQueue.pop()` | Removes and returns the key with the oldest access time |
| `evictionQueue.push(key)` | Adds a new key with `time.Now()` as its access time; returns its heap index |
| `evictionQueue.touch(index)` | Updates the access time of an existing entry and re-heapifies; returns the new index |
| `evictionHeap` | Slice of `*evictionData` implementing `heap.Interface`; ordered by `access` ascending (oldest first) |

## Usage Example

```go
eq := &evictionQueue{}

// Add entries to the queue
idxA := eq.push("CVE-2021-44228")
idxB := eq.push("CVE-2022-0001")

// Mark an entry as recently accessed (prevents early eviction)
idxA = eq.touch(idxA)

// Evict the least-recently-used key
victim := eq.pop() // returns "CVE-2022-0001" (older access time)
fmt.Println("Evicting:", victim)
```

## Notes

- `evictionHeap` is a min-heap ordered by `access` time, so `pop()` always returns the **oldest** accessed key — standard LRU behaviour.
- `Swap` keeps `index` fields in sync with actual heap positions, which is required for `touch` to locate items in O(log n) via `heap.Fix`.
