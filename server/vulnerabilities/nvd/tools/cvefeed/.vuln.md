Defines the core `Vuln` interface and vulnerability composition utilities for the CVE feed package, enabling attribute matching and override behavior between vulnerability entries.

## Key Components

- **`Vuln` interface** — Core vulnerability contract extending `wfn.Matcher` with methods for ID, CVEs, CWEs, and CVSS v2/v3 scores and vectors.
- **`OverrideVuln(v, override Vuln) Vuln`** — Combines two `Vuln` instances so that the result matches attributes only when `v` matches **and** `override` does **not** match. Identity methods (e.g., `ID()`) are inherited from `v`.
- **`overriden`** (private) — Wraps a `Vuln` with a custom `wfn.Matcher`, delegating `Match` and `Config` to the composed matcher.
- **`andMatcher`** (private) — Chains two `wfn.Matcher` instances, passing the output of the first as input to the second (logical AND via sequential filtering).

## Usage Example

```go
// Suppress a known false-positive CVE entry by overriding it with
// a more specific vulnerability definition.
base := loadVuln("CVE-2021-1234")       // Vuln
falsePositive := loadVuln("CVE-2021-1234-fp") // Vuln

// resultVuln matches only when base matches AND falsePositive does NOT match
resultVuln := cvefeed.OverrideVuln(base, falsePositive)

matched := resultVuln.Match(candidateAttrs, true)
if len(matched) > 0 {
    fmt.Println("Vulnerability confirmed:", resultVuln.ID())
    fmt.Printf("CVSS v3 Score: %.1f (%s)\n",
        resultVuln.CVSSv3BaseScore(),
        resultVuln.CVSSv3Vector(),
    )
}
```

## Notes

- `OverrideVuln` is useful for excluding known false positives or suppressing overly broad CVE matches in NVD feed processing.
