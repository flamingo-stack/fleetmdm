Provides a `Dictionary` type for loading and managing CVE vulnerability data from NVD JSON feed files, with support for concurrent file loading and dictionary merging.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Dictionary` | `map[string]Vuln` | Maps CVE IDs to their vulnerability entries |
| `Override` | Method | Amends a `Dictionary` with entries from a second dictionary `d2`, updating only matching keys |
| `LoadJSONDictionary` | Function | Parses and combines multiple NVD JSON feed files into a single `Dictionary` |
| `LoadFeed` | Function | Generic concurrent loader; accepts a custom `loadFunc` and file paths, returning a merged `Dictionary` |
| `loadJSONFile` | Function (internal) | Opens a single NVD JSON file and delegates parsing to `ParseJSON` |

## Usage Example

```go
// Load one or more NVD JSON feed files into a dictionary
dict, err := cvefeed.LoadJSONDictionary(
    "/feeds/nvdcve-1.1-2023.json",
    "/feeds/nvdcve-1.1-2024.json",
)
if err != nil {
    log.Printf("partial load error: %v", err)
}

// Override entries with a custom/amended feed
customDict, _ := cvefeed.LoadJSONDictionary("/feeds/custom-overrides.json")
dict.Override(customDict)

// Look up a specific CVE
if vuln, ok := dict["CVE-2024-1234"]; ok {
    fmt.Println(vuln.ID())
}

// Use a custom loader function
dict, err = cvefeed.LoadFeed(myCustomLoader, "/feeds/custom.json")
```

## Notes

- `LoadFeed` processes files **concurrently** using goroutines and a `sync.WaitGroup`; partial results are returned alongside any file-load errors.
- `Override` only updates keys that **already exist** in the base dictionary — it does not add new entries from `d2`.
