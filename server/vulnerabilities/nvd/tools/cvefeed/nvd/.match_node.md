Builds a `wfn.Matcher` from an NVD CVE feed configuration node, recursively composing CPE match rules using logical AND/OR operators with optional negation.

## Key Components

### `nodeMatcher(id string, node *schema.NVDCVEFeedJSON10DefNode) (wfn.Matcher, error)`

Recursively constructs a matcher tree from an NVD CVE feed node:

- Iterates `CPEMatch` entries, converting each to a matcher via `cpeMatcher`
- Recursively processes child nodes via `nodeMatcher`
- Combines all matchers using `wfn.MatchAny` (OR) or `wfn.MatchAll` (AND) based on `node.Operator`
- Wraps the result in `wfn.DontMatch` if `node.Negate` is `true`
- Defaults to OR with a warning if the operator is unrecognized
- Returns an error if `node` is nil or produces no matchers

## Usage Example

```go
node := &schema.NVDCVEFeedJSON10DefNode{
    Operator: "AND",
    Negate:   false,
    CPEMatch: []*schema.NVDCVEFeedJSON10DefCPEMatch{
        {Vulnerable: true, Cpe23Uri: "cpe:2.3:a:vendor:product:1.0:*:*:*:*:*:*:*"},
    },
    Children: []*schema.NVDCVEFeedJSON10DefNode{
        {
            Operator: "OR",
            CPEMatch: []*schema.NVDCVEFeedJSON10DefCPEMatch{
                {Vulnerable: true, Cpe23Uri: "cpe:2.3:o:vendor:os:*:*:*:*:*:*:*:*"},
            },
        },
    },
}

matcher, err := nodeMatcher("CVE-2021-12345", node)
if err != nil {
    log.Fatal(err)
}

// Use matcher to test a WFN attribute set
matched, _ := matcher.Match(attrs, requirements)
```

## Notes

- Part of the NVD vulnerability feed processing pipeline in [`server/vulnerabilities/nvd`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/vulnerabilities/nvd)
- Depends on `cpeMatcher` (defined separately) for leaf-level CPE matching
- Unknown operators fall through to OR and emit a warning via `flog`
