Auto-generated Go structs representing the NVD (National Vulnerability Database) CVE JSON feed 1.0 schema, used for deserializing CVE data from NIST's NVD feed.

## Key Components

| Type | Description |
|------|-------------|
| `NVDCVEFeedJSON10` | Root feed object containing all CVE items |
| `NVDCVEFeedJSON10DefCVEItem` | Individual CVE entry with metadata, impact, and configurations |
| `CVEJSON40` | Core CVE data (affects, description, references, problem type) |
| `CVSSV20` / `CVSSV30` | CVSS scoring structs for v2.0 and v3.0 severity metrics |
| `NVDCVEFeedJSON10DefImpact` | Wraps both CVSS v2 and v3 base metric scores |
| `NVDCVEFeedJSON10DefConfigurations` | CPE-based applicability configuration nodes |
| `NVDCVEFeedJSON10DefCPEMatch` | CPE match entry with version range constraints |
| `TimeLayout` | Constant (`"2006-01-02T15:04Z"`) for parsing NVD timestamps |

## Usage Example

```go
import (
    "encoding/json"
    "os"
    "time"
    "github.com/flamingo-stack/fleetmdm/path/to/schema"
)

func loadNVDFeed(path string) (*schema.NVDCVEFeedJSON10, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, err
    }

    var feed schema.NVDCVEFeedJSON10
    if err := json.Unmarshal(data, &feed); err != nil {
        return nil, err
    }

    for _, item := range feed.CVEItems {
        published, _ := time.Parse(schema.TimeLayout, item.PublishedDate)
        score := item.Impact.BaseMetricV3.CVSSV3.BaseScore
        _ = published
        _ = score
    }

    return &feed, nil
}
```

> **Source schemas:** [CVE JSON 4.0](https://csrc.nist.gov/schema/nvd/feed/1.0/CVE_JSON_4.0_min.schema), [CVSS v2.0](https://csrc.nist.gov/schema/nvd/feed/1.0/cvss-v2.0.json), [CVSS v3.0](https://csrc.nist.gov/schema/nvd/feed/1.0/cvss-v3.0.json), [NVD Feed](https://csrc.nist.gov/schema/nvd/feed/1.0/nvd_cve_feed_json_1.0.schema)
