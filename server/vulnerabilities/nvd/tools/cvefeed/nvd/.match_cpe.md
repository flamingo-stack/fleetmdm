Provides CPE (Common Platform Enumeration) matching logic for NVD vulnerability data, wrapping NVD CPE match entries and implementing the `wfn.Matcher` interface to evaluate whether software attributes match vulnerability criteria including version ranges.

## Key Components

### `cpeMatch` struct
Wraps `wfn.Attributes` with additional NVD-specific fields:
- `vulnerable` — whether the CPE match represents a vulnerable configuration
- `versionStartIncluding/Excluding`, `versionEndIncluding/Excluding` — version range bounds
- `hasVersionRanges` — pre-computed flag indicating any version range is set

### `cpeMatcher(id, nvdMatch)`
Factory function that parses an `NVDCVEFeedJSON10DefCPEMatch` into a `cpeMatch`. Attempts CPE 2.3 URI first, falls back to CPE 2.2.

### `Match(attrs, requireVersion)`
Public entry point implementing `wfn.Matcher`. Iterates over candidate attributes, calling both `match` (direct CPE comparison) and `matchTargetSW` (OS-level match via application target software).

### `matchTargetSW(attr)`
Extracts an OS CPE from an application CPE's `TargetSW` field and checks if it matches the stored CPE match criteria (part, product, and no version constraints).

### `match(attr, requireVersion)`
Core matching logic:
1. Optionally enforces that a version is present
2. Checks all attributes except version via `MatchWithoutVersion`
3. Compares exact version or evaluates version range bounds using `SmartVerCmp`

## Usage Example

```go
matcher, err := cpeMatcher("CVE-2023-1234", nvdCPEMatch)
if err != nil {
    log.Fatal(err)
}

candidates := []*wfn.Attributes{softwareAttr}
matched := matcher.Match(candidates, true /* requireVersion */)
for _, m := range matched {
    fmt.Printf("Vulnerable match: %+v\n", m)
}
```
