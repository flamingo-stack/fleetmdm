Implements the `cvefeed.Vuln` interface for NVD CVE feed entries, providing structured access to vulnerability metadata including CVE IDs, CWEs, and CVSS scoring data, with WFN-based configuration matching.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Vuln` | struct | Wraps an NVD CVE feed item and embeds a `wfn.Matcher` for CPE-based applicability matching |
| `ToVuln` | func | Converts a raw `NVDCVEFeedJSON10DefCVEItem` into a `Vuln`, building a `MatchAny` matcher from its configuration nodes |
| `ID()` | method | Returns the CVE identifier string (e.g. `CVE-2021-44228`) |
| `CVEs()` | method | Extracts all CVE references from the item's ID and reference data using regex |
| `CWEs()` | method | Returns English-language CWE identifiers from the problem type data |
| `CVSSv2BaseScore()` / `CVSSv2Vector()` | methods | Returns CVSS v2 score and vector string |
| `CVSSv3BaseScore()` / `CVSSv3Vector()` | methods | Returns CVSS v3 score and vector string |
| `Schema()` | method | Exposes the underlying raw `NVDCVEFeedJSON10DefCVEItem` |
| `cveRegex` | var | Compiled regex matching CVE identifiers (`CVE-YYYY-NNNNN+`) |

## Usage Example

```go
// Convert a raw NVD feed item to a Vuln
vuln := nvd.ToVuln(cveItem)

// Access CVE metadata
fmt.Println(vuln.ID())              // "CVE-2021-44228"
fmt.Println(vuln.CVEs())            // ["CVE-2021-44228"]
fmt.Println(vuln.CWEs())            // ["CWE-502"]
fmt.Println(vuln.CVSSv3BaseScore()) // 10.0
fmt.Println(vuln.CVSSv3Vector())    // "CVSS:3.1/AV:N/..."

// Use embedded WFN matcher to check if a CPE is affected
attrs, _ := wfn.Parse("cpe:2.3:a:vendor:product:1.0:*:*:*:*:*:*:*")
matched := vuln.Match(attrs, false)
```
