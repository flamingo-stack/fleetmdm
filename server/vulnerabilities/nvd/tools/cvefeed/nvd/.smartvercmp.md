Smart version string comparison utility for the NVD package, providing convention-aware ordering of software version strings like `"16.3.2"` vs `"3.7.0"` or `"95SE"` vs `"98SP1"`.

## Key Components

| Symbol | Description |
|---|---|
| `SmartVerCmp(v1, v2 string) int` | Primary comparison function; returns `-1`, `0`, or `1` |
| `parseVerParts(v string) (int, int, int)` | Tokenizes a version segment into numeric length, comparison boundary, and skip index |
| `lpad(s string, n int) string` | Zero-pads a string for numeric alignment during comparison |

## Usage Example

```go
// Compare semantic version strings
result := nvd.SmartVerCmp("16.3.2", "3.7.0")
// result == 1 → "16.3.2" is newer

result = nvd.SmartVerCmp("98SP1", "95SE")
// result == 1 → "98SP1" is newer

result = nvd.SmartVerCmp("2.0.1", "2.0.1")
// result == 0 → equal

// Typical use: sorting a slice of version strings
sort.Slice(versions, func(i, j int) bool {
    return nvd.SmartVerCmp(versions[i], versions[j]) < 0
})
```

## Notes

- Assumes both inputs follow the **same versioning convention** — cross-convention comparisons (e.g., `"2000"` vs `"11.7"`) produce unreliable results.
- Numeric segments are left-zero-padded before string comparison, enabling correct lexicographic ordering of unequal-length number runs.
- Punctuation characters (`.`, `-`, `_`, etc.) act as segment separators; the longer remaining string wins when all compared segments are equal.
