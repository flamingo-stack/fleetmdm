Defines the `CPEMatchingRule` and `CPEMatchingRuleSpec` types used to override or suppress false-positive CVE matches produced by inaccurate NVD CPE data.

## Key Components

- **`CPEMatchingRuleSpec`** — Specifies a single CPE match criteria: `Vendor`, `Product`, `TargetSW`, and a [SemVer constraint](https://pkg.go.dev/github.com/Masterminds/semver@v1.5.0#hdr-Checking_Version_Constraints) for version range filtering.
- **`CPEMatchingRule`** — Composite rule associating one or more `CPESpecs` with a set of target `CVEs`. Supports three matching modes:
  - `CPESpecs` — Match by CPE attributes + version constraint.
  - `IgnoreAll` — Unconditionally suppresses all CPE matches for the targeted CVEs.
  - `IgnoreIf` — Custom predicate function; when set, `CPESpecs` are skipped entirely.
- **`CPEMatches(cpeMeta *wfn.Attributes) bool`** — Evaluates whether a given CPE matches the rule by checking attributes and the SemVer constraint against the CPE's version.
- **`Validate() error`** — Validates the rule at instantiation time, ensuring CPE parts are non-empty/non-wildcard, the SemVer constraint is parseable, and at least one CVE is specified.

## Usage Example

```go
rule := CPEMatchingRule{
    CPESpecs: []CPEMatchingRuleSpec{
        {
            Vendor:           "apple",
            Product:          "icloud",
            TargetSW:         "windows",
            SemVerConstraint: "<= 7.0.0",
        },
    },
    CVEs: map[string]struct{}{
        "CVE-2017-13797": {},
    },
}

if err := rule.Validate(); err != nil {
    log.Fatalf("invalid rule: %v", err)
}

if rule.CPEMatches(cpeMeta) {
    // CPE is within the affected version range; vulnerability applies
}
```
