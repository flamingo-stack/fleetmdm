Defines the `IndexedCPEItem` struct and associated methods for constructing CPE (Common Platform Enumeration) formatted strings used in NVD vulnerability matching.

## Key Components

- **`IndexedCPEItem`** — Struct representing a CPE entry from the local NVD database, storing CPE attributes (`Part`, `Product`, `Vendor`, `SWEdition`, `TargetSW`, `Deprecated`, `Weight`) mapped to DB columns.
- **`FmtStr(s *fleet.Software) string`** — Builds a WFN-formatted CPE string from the indexed item and a `fleet.Software` instance. Handles special cases for Python (`update = N/A`) and Citrix Workspace LTSR editions. Returns an empty string if `Vendor` or `Product` resolves to a wildcard (`ANY`).
- **`parseUpdateFromVersion(originalVersion string) (version, update string)`** — Splits version strings containing pre-release suffixes (e.g., `3.12.0b4`, `3.13.0rc1`) into a base version and an `update` field (normalized to `alpha`, `beta`, or `rc`).
- **`isCitrixWorkspaceLTSR(version string) bool`** — Checks whether a Citrix Workspace version matches a known LTSR (Long Term Service Release) version from the `citrixLTSRVersions` list.

## Usage Example

```go
item := &IndexedCPEItem{
    Vendor:  "python",
    Product: "python",
    Part:    "a",
}

sw := &fleet.Software{
    Version: "3.12.0b4",
    Name:    "Python",
}

cpeStr := item.FmtStr(sw)
// cpe:2.3:a:python:python:3.12.0:beta4:*:*:*:*:*:*
```

> **Note:** `citrixLTSRVersions` is a manually maintained list. The comment in the source flags this for future automation. See [indexed_cpe_item.go](https://github.com/flamingo-stack/fleetmdm/blob/main/server/vulnerabilities/nvd/indexed_cpe_item.go) for the full implementation.
