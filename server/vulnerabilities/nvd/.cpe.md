Handles CPE (Common Platform Enumeration) database management and software-to-CPE matching for NVD vulnerability scanning, including GitHub release downloads, search query generation, and deprecation resolution.

## Key Components

### Functions

- **`GetGithubNVDAsset`** — Fetches the first matching release asset from the last 10 releases of `github.com/fleetdm/nvd` using a predicate function.
- **`DownloadCPEDBFromGithub`** — Downloads and extracts the CPE SQLite database to a local path; skips if already up-to-date. Handles zero-byte stale files as absent.
- **`cpeSearchQueries`** — Returns prioritized SQL search queries (vendor+product → product-only → full-text → bundle ID) to progressively match software to CPE entries.
- **`cpeItemMatchesSoftware`** — Validates that a CPE candidate's vendor/product tokens appear in the software's name, vendor, and bundle identifier.
- **`cpeVendorMatchesSoftware`** — Word-boundary vendor match used as a tiebreaker between multiple CPE candidates.
- **`cpeTargetSWMatchesSoftware`** — Scores (0–3) how well a CPE's `target_sw`/vendor fields align with the software's ecosystem source (npm, deb, rpm, etc.).
- **`resolveDeprecatedCPE`** — Follows the CPE deprecation chain in the database to return a non-deprecated replacement CPE string.

### Types

- **`cpeSearchQuery`** — Holds a SQL statement and its arguments for a single CPE lookup attempt.

### Constants

- `owner`, `repo`, `cpeDBFilename` — GitHub release source coordinates (`fleetdm/nvd`, `cpe.sqlite`).
- `cpeSelectColumns`, `cpeOrderBy` — Shared SQL fragments for CPE result queries.

## Usage Example

```go
// Download the CPE database to a local directory
err := DownloadCPEDBFromGithub("/var/fleet/vuln", "")
if err != nil {
    log.Fatal(err)
}

// Find the best CPE match for a software item
queries := cpeSearchQueries(software)
for _, q := range queries {
    rows, err := db.Queryx(q.stm, q.args...)
    // process rows, score with cpeTargetSWMatchesSoftware / cpeItemMatchesSoftware ...
}

// Resolve a deprecated CPE to its replacement
replacement, err := resolveDeprecatedCPE(db, candidates, software)
```
