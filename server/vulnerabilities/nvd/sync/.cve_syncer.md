Syncs CVE data from the NVD 2.0 API and stores it locally in the legacy NVD 1.1 JSON format for compatibility with Fleet's vulnerability tooling.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CVE` | struct | Core syncer that manages NVD CVE downloads and local storage |
| `CVEOption` | type | Functional option for configuring a `CVE` syncer |
| `NewCVE` | func | Constructor; requires a `dbDir` path, accepts optional `CVEOption` funcs |
| `WithLogger` | func | Option to set a `*slog.Logger` (default: discard) |
| `WithDebug` | func | Option to enable debug output to stderr |
| `Do` | method | Entry point; runs initial sync or incremental update based on local state |

**Internal methods:**

- `initSync` — Full download of all CVEs; removes legacy feed files first
- `update` — Incremental sync using the stored `last_mod_start_date.txt` timestamp
- `updateYearFile` — Merges NVD API 2.0 CVEs into a per-year legacy JSON file
- `updateVulnCheckYearFile` — Same as above but merges VulnCheck-enriched CVE configurations (with in-memory caching via `cachedCVEFeeds`)
- `writeLastModStartDateFile` — Persists the sync cursor timestamp to disk

## Usage Example

```go
syncer, err := nvdsync.NewCVE(
    "/var/fleet/nvd",
    nvdsync.WithLogger(slog.Default()),
    nvdsync.WithDebug(false),
)
if err != nil {
    log.Fatal(err)
}

if err := syncer.Do(context.Background()); err != nil {
    log.Fatal(err)
}
```

## Notes

- Uses NVD API 2.0 via [`pandatix/nvdapi`](https://github.com/pandatix/nvdapi) but persists data in **NVD 1.1 legacy format** for compatibility with [`facebookincubator/nvdtools`](https://github.com/facebookincubator/nvdtools).
- Respects NVD's recommended **6-second delay** between requests; retries up to 10 times with a 30-second back-off.
- Sync state is tracked via `last_mod_start_date.txt` in `dbDir`.
