Utility functions for the `nvdsync` package providing file compression helpers used during NVD (National Vulnerability Database) sync operations.

## Key Components

| Function | Visibility | Description |
|---|---|---|
| `CompressFile` | Exported | Reads a file, compresses it with gzip, writes to a new filename, and removes the original |
| `zipFiles` | Internal | Bundles multiple source files into a single ZIP archive using Deflate compression |

## Usage Example

```go
// Compress a single JSON file to gzip format
err := nvdsync.CompressFile("nvd-data.json", "nvd-data.json.gz")
if err != nil {
    log.Fatalf("compression failed: %v", err)
}

// Bundle multiple files into a zip archive (internal use)
// zipFiles([]string{"cve-2023.json", "cve-2024.json"}, "cves.zip")
```

## Notes

- `CompressFile` is a destructive operation — the original file at `fileName` is deleted after successful compression.
- `zipFiles` preserves the full source path as the entry name within the archive (`header.Name = source`), not just the basename.
- Both functions use `defer` for cleanup but callers should note that `defer` inside loops (in `zipFiles`) defers until function return, not loop iteration — file handles accumulate for large source slices.
- Compression level for `zipFiles` uses `zip.Deflate` for broad compatibility with standard unzip tools.
