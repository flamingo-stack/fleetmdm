Parses NVD CVE feed files and maps discovered CVEs to software and operating system CPEs stored in the Fleet datastore, handling feed downloads, CPE hydration, vulnerability matching, and stale-record cleanup.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `GenerateCVEFeeds` | func | Downloads CVE data from the NVD 2.0 API and supplements it with Vulncheck CPE data |
| `DownloadCVEFeed` | func | Downloads legacy NVD CVE feed from GitHub releases or a custom prefix URL |
| `GetGitHubCVEAssetPath` | func | Resolves the latest `cve-*` tagged GitHub release download URL |
| `TranslateCPEToCVE` | func | Core pipeline: loads feed files, matches CPEs to CVEs, inserts/deletes vulnerabilities |
| `GetMacOSCPEs` | func | Converts darwin OS records into WFN-attributed CPE structs for both `macos` and `mac_os_x` NVD variants |
| `checkCVEs` | func | Loads a single NVD JSON feed file, groups by vendor, and runs CPE matching |
| `softwareCPEWithNVDMeta` | struct | Wraps `fleet.SoftwareCPE` with parsed WFN attributes |
| `osCPEWithNVDMeta` | struct | Wraps `fleet.OperatingSystem` with parsed WFN attributes |
| `itemWithNVDMeta` | interface | Common interface for software and OS CPE types |

## Usage Example

```go
// Download CVE feeds to local directory
err := nvd.DownloadCVEFeed("/var/fleet/vulns", "", false, logger)
if err != nil {
    log.Fatal(err)
}

// Match CPEs in the Fleet database against the downloaded NVD feeds
newVulns, err := nvd.TranslateCPEToCVE(
    ctx,
    datastore,
    "/var/fleet/vulns",
    logger,
    true,          // collectVulns: return newly found vulnerabilities
    time.Now(),    // startTime: used to determine stale record cutoff
)
if err != nil {
    log.Fatal(err)
}
for _, v := range newVulns {
    fmt.Printf("New vulnerability: %s on software %d\n", v.CVE, v.SoftwareID)
}
```

> **Note:** `TranslateCPEToCVE` guards against corrupted/empty feed artifacts — if the feed produces zero matches despite non-empty CPE inputs, stale-record deletes are skipped to preserve existing `software_cve` rows until the next healthy sync.
