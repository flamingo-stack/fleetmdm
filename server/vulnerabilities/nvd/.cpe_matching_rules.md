Defines CPE matching rules used to suppress false positive vulnerability detections during NVD (National Vulnerability Database) scanning, providing a curated list of known NVD data bugs and inaccurate CVE-to-CPE mappings.

## Key Components

- **`CPEMatchingRules`** — Type alias for a slice of `CPEMatchingRule`, representing the full ruleset
- **`GetKnownNVDBugRules()`** — Returns the hardcoded list of suppression rules for known NVD data quality issues
- **`CPEMatchingRule`** — Individual rule with optional `IgnoreAll` flag, `IgnoreIf` predicate, `CPESpecs` constraints, and targeted `CVEs`
- **`CPEMatchingRuleSpec`** — Spec defining vendor, product, target OS, and semver constraint for a match condition

## Usage Example

```go
rules, err := nvd.GetKnownNVDBugRules()
if err != nil {
    log.Fatal(err)
}

// Check if a CPE/CVE pair should be suppressed
for _, rule := range rules {
    if _, ok := rule.CVEs["CVE-2020-10146"]; ok {
        if rule.IgnoreAll {
            fmt.Println("CVE suppressed entirely")
        }
        if rule.IgnoreIf != nil && rule.IgnoreIf(cpeMeta) {
            fmt.Println("CVE suppressed for this CPE context")
        }
    }
}
```
