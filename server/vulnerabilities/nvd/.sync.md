Handles downloading, parsing, and loading vulnerability metadata from NVD, EPSS, and CISA data feeds into the Fleet datastore.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SyncOptions` | struct | Configuration for feed URLs and local vulnerability data path |
| `Sync` | func | Orchestrates downloading of all vulnerability data sources (CPE DB, CVE feed, EPSS, CISA) |
| `DownloadEPSSFeed` | func | Downloads the EPSS scores CSV from `epss.cyentia.com` |
| `DownloadCISAKnownExploitsFeed` | func | Downloads the CISA Known Exploited Vulnerabilities JSON catalog |
| `CVEMetaFromNVDFeedFiles` | func | Parses NVD JSON feed files into a `CVEMeta` map (CVSS scores, descriptions, publish dates) |
| `CVEMetaFromEPSSFeedFiles` | func | Parses the EPSS CSV file and merges probability scores into a `CVEMeta` map |
| `CVEMetaFromCISAFeedFiles` | func | Parses the CISA catalog and sets `CISAKnownExploit` flags on the `CVEMeta` map |
| `CVEMetaFromFiles` | func | Aggregates all three feed parsers into a single `map[string]fleet.CVEMeta` |
| `LoadCVEMeta` | func | Premium-only: loads all CVE metadata from local files and persists to the Fleet datastore |

## Usage Example

```go
// Sync all feeds to local disk
err := nvd.Sync(ctx, nvd.SyncOptions{
    VulnPath:             "/var/fleet/vulns",
    CPEDBURL:             "https://...",
    CPETranslationsURL:   "https://...",
    CVEFeedPrefixURL:     "https://...",
    CISAKnownExploitsURL: "https://...",
}, logger)

// Load metadata from synced files into the datastore (requires Premium license)
err = nvd.LoadCVEMeta(ctx, logger, "/var/fleet/vulns", datastore)
```

> **Note:** `LoadCVEMeta` is gated behind a Premium license check and will no-op silently on Community tier instances.
