Handles synchronization of OVAL vulnerability database files from GitHub for supported OS platforms, downloading and decompressing SQLite archives used by the goval-dictionary vulnerability scanner.

## Key Components

| Function | Description |
|---|---|
| `Refresh` | Entry point that determines which platforms need database downloads and triggers sync |
| `Sync` | Orchestrates downloads for a list of platforms using the GitHub CVE asset path |
| `downloadDatabase` | Downloads and extracts a single platform's `.sqlite3.xz` archive to the destination directory |
| `downloadDecompressed` | Returns a closure wrapping `download.DownloadAndExtract` for a given HTTP client |
| `whatToDownload` | Filters `fleet.OSVersions` to only platforms supported by goval-dictionary |

## Usage Example

```go
versions := &fleet.OSVersions{
    OSVersions: []fleet.OSVersion{
        {Platform: "ubuntu", Name: "Ubuntu 22.04"},
        {Platform: "rhel",   Name: "Red Hat 9"},
    },
}

downloaded, err := goval_dictionary.Refresh(
    ctx,
    versions,
    "/var/fleet/vulnerabilities",
    slog.Default(),
)
if err != nil {
    log.Fatal(err)
}

for _, p := range downloaded {
    fmt.Println("Synced:", p)
}
```

## Notes

- Only platforms where `oval.Platform.IsGovalDictionarySupported()` returns `true` are downloaded.
- Database files are fetched from the GitHub CVE asset path resolved by `nvd.GetGitHubCVEAssetPath()` as `.sqlite3.xz` compressed archives.
- Filenames in the destination directory are determined by `platform.ToGovalDictionaryFilename()`.
