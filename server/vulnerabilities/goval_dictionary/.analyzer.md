Provides vulnerability analysis for hosts using goval-dictionary SQLite databases, scanning software packages against OVAL definitions and managing insert/delete operations for detected vulnerabilities.

## Key Components

- **`Analyze`** — Main entry point that iterates over hosts matching a given OS version in batches, evaluates software against the goval-dictionary database, computes vulnerability deltas, and persists inserts/deletes to the datastore.
- **`LoadDb`** — Opens and validates the latest goval-dictionary SQLite file for a given platform, rejecting empty databases to prevent false "all-patched" states from corrupted feeds.
- **`ErrUnsupportedPlatform`** — Sentinel error returned when the target platform has no goval-dictionary support.
- **`hostsBatchSize` / `vulnBatchSize`** — Batch size constants (500 each) controlling pagination of host queries and bulk vulnerability operations.

## Usage Example

```go
vulns, err := goval_dictionary.Analyze(
    ctx,
    datastore,
    fleet.OSVersion{Platform: "rhel", Name: "Red Hat Enterprise Linux 9"},
    "/var/fleet/vuln",
    true,
    logger,
)
if errors.Is(err, goval_dictionary.ErrUnsupportedPlatform) {
    // platform has no goval-dictionary support; skip gracefully
}

// LoadDb can also be used independently to inspect a platform's DB
db, err := goval_dictionary.LoadDb(platform, "/var/fleet/vuln")
if err != nil {
    log.Fatal(err)
}
defer db.Close()
```

## Notes

- For kernel-only platforms (e.g., RHEL), only kernel packages are scanned via goval-dictionary; non-kernel packages are handled by standard OVAL processing.
- Deduplication sets (`toInsertSet`, `toDeleteSet`) prevent redundant datastore operations when the same vulnerable software appears across multiple hosts.
