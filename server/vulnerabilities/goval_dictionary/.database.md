Wraps a SQLite-backed OVAL dictionary database for querying RPM package vulnerabilities by name and architecture, returning matched CVEs for installed software.

## Key Components

- **`NewDB(db *sql.DB, platform oval.Platform) *Database`** — Constructor that initializes a `Database` instance with a SQLite connection and target platform.
- **`Database`** — Core struct holding the SQLite connection and associated OVAL platform identifier.
- **`Verfiy() error`** — Validates the database is queryable by running a limit-1 probe against the joined package/CVE schema.
- **`Eval(ctx, software, logger) []fleet.SoftwareVulnerability`** — Iterates installed software, queries for matching vulnerable package entries by name and architecture, compares RPM versions using `utils.Rpmvercmp`, and returns all software items whose current version is older than the fixed version listed in the advisory.
- **`Close() error`** — Releases the underlying SQLite connection pool.

## Usage Example

```go
sqlDB, err := sql.Open("sqlite3", "/path/to/oval.db")
if err != nil {
    log.Fatal(err)
}

db := goval_dictionary.NewDB(sqlDB, oval.Ubuntu2004)

if err := db.Verfiy(); err != nil {
    log.Fatalf("database verification failed: %v", err)
}

installedSoftware := []fleet.Software{
    {ID: 1, Name: "openssl", Version: "1.1.1", Release: "k", Arch: "x86_64"},
}

vulns := db.Eval(ctx, installedSoftware, logger)
for _, v := range vulns {
    fmt.Printf("CVE: %s, resolved in: %s\n", v.CVE, *v.ResolvedInVersion)
}

db.Close()
```

## Notes

- Version comparison strips the epoch prefix (e.g., `1:1.1.1k`) before calling `Rpmvercmp`.
- Errors during row scanning are logged and skipped rather than halting evaluation, maximizing vulnerability coverage per scan.
