Transforms raw OVAL XML input types into parsed, domain-specific structs used for vulnerability evaluation. Handles both RHEL (RPM-based) and Ubuntu (DPKG-based) OVAL definition formats.

## Key Components

| Function | Description |
|---|---|
| `extractId` | Strips the OVAL namespace prefix from an ID string, returning only the trailing numeric portion |
| `mapDefinition` | Converts a `DefinitionXML` to a `Definition`; errors if no vulnerabilities are present |
| `mapCriteria` | Recursively maps `CriteriaXML` (including nested criteria) to a `Criteria` struct |
| `mapPackageInfoTestObject` | Resolves a package test object name, supporting both inline values and variable references |
| `mapRpmVerifyFileTest` | Maps `RpmVerifyFileTestXML` → `RpmVerifyFileTest` with match/operator fields |
| `mapRpmInfoTest` | Maps `RpmInfoTestXML` → `RpmInfoTest` |
| `mapRpmVerifyFileObject` | Extracts a file path from `RpmVerifyFileObjectXML`; rejects unsupported fields |
| `mapRpmVerifyFileState` | Maps `RpmVerifyFileStateXML` → `ObjectInfoState`; errors on unsupported attributes |
| `mapRpmInfoState` | Maps `RpmInfoStateXML` → `ObjectInfoState` with full RPM metadata support |
| `mapDpkgInfoTest` | Maps `DpkgInfoTestXML` → `DpkgInfoTest` |
| `mapDpkgInfoState` | Maps `DpkgInfoStateXML` → `ObjectStateEvrString`; only EVR-based state is supported |
| `mapUnixUnameTest` / `mapUnameState` | Maps uname test/state for OS release checks |
| `mapVariableTest` / `mapVariableState` | Maps variable test/state XML types |

## Usage Example

```go
// Parse a definition from XML input
def, err := mapDefinition(xmlDefinition)
if err != nil {
    log.Fatal(err) // e.g., "definition contains no vulnerabilities"
}

// Resolve a package test object (inline or variable-referenced name)
names, err := mapPackageInfoTestObject(testObj, variablesMap)
if err != nil {
    log.Fatalf("variable resolution failed: %v", err)
}

// Map an RPM info state for version comparison
state, err := mapRpmInfoState(rpmStateXML)
if err != nil {
    log.Fatalf("unsupported state: %v", err)
}
```

> **Note:** `mapDpkgInfoState` only supports EVR-based state definitions. Ubuntu OVAL definitions currently use exclusively EVR strings for package version comparisons.
