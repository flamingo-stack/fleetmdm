Parses OVAL (Open Vulnerability and Assessment Language) XML definition files for Ubuntu and RHEL platforms, transforming raw XML input into structured JSON output for vulnerability assessment.

## Key Components

- **`parseDefinitions(platform, inputFile, outputFile)`** — Entry point that reads an OVAL XML file, dispatches to the platform-specific processor, and writes the JSON result to disk.
- **`processRhelDef(r)`** / **`processUbuntuDef(r)`** — Platform-specific pipelines: parse XML → map to structured result → marshal to JSON.
- **`parseRhelXML(reader)`** — Streaming XML decoder for RHEL OVAL data; extracts definitions, RPM info tests/objects/states, RPM verify file tests, and constant variables.
- **`parseUbuntuXML(reader)`** — Streaming XML decoder for Ubuntu OVAL data; extracts definitions, dpkg info tests/objects/states, uname tests/states, and variable tests/objects/states.
- **`mapToRhelResult(xmlResult)`** — Assembles parsed RHEL XML entities into a typed `oval_parsed.RhelResult`, resolving cross-references between tests, objects, and states by ID.
- **`mapToUbuntuResult(xmlResult)`** — Assembles parsed Ubuntu XML entities into a typed `oval_parsed.UbuntuResult`, resolving dpkg, uname, and variable test relationships.

## Usage Example

```go
// Parse an Ubuntu OVAL XML file and write the result as JSON
err := parseDefinitions(
    Platform("ubuntu_22"),
    "/path/to/com.ubuntu.jammy.oval.xml",
    "/path/to/output/ubuntu_22.json",
)
if err != nil {
    log.Fatalf("failed to parse OVAL definitions: %v", err)
}

// Or use the lower-level Ubuntu processor directly
f, _ := os.Open("com.ubuntu.focal.oval.xml")
defer f.Close()
payload, err := processUbuntuDef(f)
// payload is JSON-encoded oval_parsed.UbuntuResult
```

Both parsers use a **streaming token-based XML decoder** to avoid loading the full OVAL document into memory, making them suitable for large vendor-supplied vulnerability feeds.
