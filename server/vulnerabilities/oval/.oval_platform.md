Defines the `Platform` type for OVAL vulnerability scanning, providing utilities to construct, validate, and generate filenames for platform-specific OVAL and goval-dictionary artifacts based on host OS information.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Platform` | type | String type representing a normalized platform identifier (e.g., `ubuntu_2004`, `rhel_07`) |
| `OvalFilePrefix` | const | File prefix `"fleet_oval"` used when saving OVAL artifacts |
| `GovalDictionaryFilePrefix` | const | File prefix `"fleet_goval_dictionary"` for goval-dictionary artifacts |
| `SupportedSoftwareSources` | var | Package sources eligible for vulnerability scanning (`deb_packages`, `rpm_packages`) |
| `SupportedGovalPlatforms` | var | Platforms with full goval-dictionary support (Amazon Linux, RHEL variants) |
| `GovalKernelOnlyPlatforms` | var | RHEL platforms where goval-dictionary is restricted to kernel-only scanning |
| `NewPlatform` | func | Constructs a normalized `Platform` from a host platform string and OS version string |
| `ToFilename` | method | Generates a dated OVAL artifact filename for a platform |
| `ToGovalDictionaryFilename` | method | Generates the goval-dictionary SQLite filename for a platform |
| `ToGovalDatabaseFilename` | method | Generates the raw SQLite filename used by goval-dictionary fetch workflows |
| `IsSupported` | method | Returns whether the platform has OVAL vulnerability definitions |
| `IsGovalDictionarySupported` | method | Returns whether the platform supports goval-dictionary scanning |
| `IsGovalDictionaryKernelOnly` | method | Returns true for RHEL platforms where goval-dictionary covers only kernel CVEs |
| `IsUbuntu` | method | Returns true if the platform targets Ubuntu |
| `IsRedHat` | method | Returns true if the platform targets RHEL or Amazon Linux |

## Usage Example

```go
// Construct a platform from host info
p := oval.NewPlatform("ubuntu", "Ubuntu 20.4.0")
// p == "ubuntu_2004"

// Check support
if p.IsSupported() {
    filename := p.ToFilename(time.Now(), "json")
    // filename == "fleet_oval_ubuntu_2004-2024_01_15.json"
}

// Goval-dictionary workflow
rhel := oval.NewPlatform("rhel", "CentOS Linux 7.9.2009")
// rhel == "rhel_07"

if rhel.IsGovalDictionarySupported() {
    dbFile := rhel.ToGovalDatabaseFilename()
    // dbFile == "rhel_07.sqlite3"
}

if rhel.IsGovalDictionaryKernelOnly() {
    // Use goval-dictionary only for kernel CVEs;
    // fall back to standard OVAL for all other packages.
}
```
