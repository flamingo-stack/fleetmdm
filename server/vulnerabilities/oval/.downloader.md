Handles fetching and downloading OVAL (Open Vulnerability and Assessment Language) definition files for vulnerability scanning, using a metadata-driven approach to locate platform-specific definitions.

## Key Components

| Component | Description |
|---|---|
| `OvalSources` | Type alias for `map[Platform]string` mapping platforms to their OVAL definition URLs |
| `getOvalSources()` | Fetches and parses the `oval_sources.json` metadata file using an injectable getter function |
| `downloadDefinitions()` | Downloads OVAL definitions for a specific platform to a temp file using an injectable downloader function |

## Usage Example

```go
// Fetch the sources metadata
sources, err := getOvalSources(func(name string) (io.ReadCloser, error) {
    return http.Get("https://nvd.example.com/" + name)
})
if err != nil {
    log.Fatal(err)
}

// Download definitions for a specific platform
dstPath, err := downloadDefinitions(
    sources,
    PlatformUbuntu20,
    func(url, dst string) error {
        return downloadFile(url, dst)
    },
)
if err != nil {
    log.Fatal(err)
}
// dstPath is a temp file path, e.g. /tmp/ubuntu20_2024-01-15.xml
```

## Notes

- Both functions accept injectable function parameters (`getter`, `downloader`), making them easy to test and swap transport implementations.
- Downloaded definitions are written to `os.TempDir()` with a timestamped filename via `platform.ToFilename()`.
