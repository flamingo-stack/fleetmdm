Orchestrates OVAL-based vulnerability scanning for hosts, loading platform-specific OVAL definitions, evaluating installed software against CVEs, and syncing new/patched vulnerabilities to the datastore.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `ErrUnsupportedPlatform` | `var` | Sentinel error returned when the host OS has no OVAL support |
| `hostsBatchSize` | `const` | Number of hosts processed per iteration (500) |
| `vulnBatchSize` | `const` | Number of vulnerabilities processed per batch delete (500) |
| `Analyze` | `func` | Main entry point: evaluates all hosts for a given OS version against OVAL definitions, then inserts/deletes vulnerabilities accordingly |
| `loadDef` | `func` | Loads and deserializes the latest OVAL definition JSON file for a platform; errors if the file is empty to prevent mass false-patching |

## Usage Example

```go
ctx := context.Background()

vulns, err := oval.Analyze(
    ctx,
    ds,                         // fleet.Datastore
    fleet.OSVersion{
        Platform: "ubuntu",
        Name:     "Ubuntu 22.04",
    },
    "/var/fleet/vuln-data",     // path to OVAL definition files
    true,                       // collect and return new vulns
)
if err != nil {
    if errors.Is(err, oval.ErrUnsupportedPlatform) {
        log.Println("skipping: platform not supported")
        return
    }
    log.Fatal(err)
}

for _, v := range vulns {
    fmt.Printf("New vuln: software=%d CVE=%s\n", v.SoftwareID, v.CVE)
}
```

## Notes

- Supports **Ubuntu** (`UbuntuOVALSource`) and **RHEL/RedHat** (`RHELOVALSource`) platforms.
- Deduplicates insert/delete operations via `toInsertSet`/`toDeleteSet` maps to handle the many-to-many host↔software relationship.
- Known false-positive CVEs are filtered out via `GetKnownOVALBugRules` before any datastore writes.
- `loadDef` guards against corrupted/empty feeds that would otherwise delete all existing vulnerabilities.
