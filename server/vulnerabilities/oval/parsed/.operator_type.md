Defines the `OperatorType` used to evaluate boolean logic in OVAL (Open Vulnerability and Assessment Language) criteria, encoding the `OperatorEnumeration` as an integer type with support for negation and multi-value evaluation.

## Key Components

| Symbol | Description |
|---|---|
| `OperatorType` | Integer type representing OVAL logical operators (`And`, `One`, `Or`, `Xor`) and their negations (`NotAnd`, `NotOne`, `NotOr`, `NotXor`) |
| `NewOperatorType(val string)` | Parses a string from an OVAL XML document into an `OperatorType`; defaults to `And` for unrecognized values |
| `Negate(neg string)` | Returns the logical negation of the operator when `neg == "true"` (e.g., `And` → `NotAnd`) |
| `Eval(vals ...bool)` | Evaluates a variadic list of booleans using the operator's truth table; returns the operator's identity value on empty input |
| `identity()` | Returns the logical identity element for each operator (e.g., `true` for `And`, `false` for `Or`) |
| `String()` | Returns the uppercase OVAL string representation of the operator |

## Usage Example

```go
// Parse operator from OVAL XML attribute
op := oval_parsed.NewOperatorType("OR")

// Evaluate multiple boolean results
result := op.Eval(false, false, true) // true

// Negate the operator (e.g., from a "negate" XML attribute)
negated := op.Negate("true") // NotOr
result2 := negated.Eval(false, false, true) // false

// Default identity on empty input
op2 := oval_parsed.NewOperatorType("AND")
result3 := op2.Eval() // true (identity for AND)
```
