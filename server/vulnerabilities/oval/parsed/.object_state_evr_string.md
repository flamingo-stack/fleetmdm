Defines the `ObjectStateEvrString` type for encoding and evaluating OVAL EVR (Epoch:Version-Release) string comparisons used in Debian package state assertions.

## Key Components

- **`ObjectStateEvrString`** — A string type encoding an OVAL operation and EVR value in the format `op|evr`
- **`NewObjectStateEvrString(op, evr string)`** — Constructor that packs an operation type and EVR string into the encoded format
- **`unpack()`** — Internal method that splits the encoded string back into an `OperationType` and EVR value
- **`Eval(ver string, cmp func(string, string) int, ignoreEpoch bool)`** — Evaluates the state against a provided version string using a caller-supplied comparator function; supports `ignoreEpoch` to strip epoch prefixes for RHEL-based distros

## Usage Example

```go
// Create a state asserting version must be less than "2:1.0-1"
state := NewObjectStateEvrString("less than", "2:1.0-1")

// Evaluate against an installed package version
result, err := state.Eval("1.0-1", myEvrComparator, true) // ignoreEpoch=true for RHEL
if err != nil {
    log.Fatal(err)
}
fmt.Println(result) // true if installed version satisfies the condition
```

Supported operations: `LessThan`, `Equals`, `NotEqual`, `GreaterThan`, `GreaterThanOrEqual`, `LessThanOrEqual`. Returns an error for unrecognized operation types.

> **Note:** Epoch handling for RHEL-based distros is partially implemented. See the upstream tracking issue for details.
