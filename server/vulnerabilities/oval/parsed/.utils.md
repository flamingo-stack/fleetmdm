Maps Fedora Linux version strings to their approximate Red Hat Enterprise Linux (RHEL) equivalents for use with RHEL OVAL definitions.

## Key Components

### `ReplaceFedoraOSVersion(version string) string`

Accepts an OS version string and, if it contains `"Fedora"`, maps it to the closest RHEL version using regex-based rules. Non-Fedora strings are returned unchanged. If no rule matches, defaults to `"Red Hat Enterprise Linux 9.0.0"`.

**Fedora → RHEL mapping:**

| Fedora Versions | RHEL Equivalent |
|---|---|
| 12–18 | RHEL 6.0.0 |
| 19–27 | RHEL 7.0.0 |
| 28–33 | RHEL 8.0.0 |
| 34–40 | RHEL 9.0.0 |

> **Note:** This is an approximation. There is no strict 1:1 mapping between Fedora and RHEL versions (e.g., RHEL 6 is based on both Fedora 12 and 13).

## Usage Example

```go
// Fedora string mapped to RHEL equivalent
result := ReplaceFedoraOSVersion("Fedora Linux 36.0.0")
// => "Red Hat Enterprise Linux 9.0.0"

// Non-Fedora strings are returned as-is
result = ReplaceFedoraOSVersion("Ubuntu 22.04")
// => "Ubuntu 22.04"

// Unrecognized Fedora versions default to RHEL 9
result = ReplaceFedoraOSVersion("Fedora Linux 99.0.0")
// => "Red Hat Enterprise Linux 9.0.0"
```
