Parses OVAL vulnerability data for Ubuntu hosts, evaluating package and kernel tests to identify software vulnerabilities.

## Key Components

### `UbuntuResult` struct
Holds parsed OVAL data: a list of vulnerability definitions, a map of dpkg package tests, and a map of uname (kernel) tests.

### `NewUbuntuResult() *UbuntuResult`
Constructor that initializes an empty `UbuntuResult` with allocated maps for package and uname tests.

### `AddDefinition`, `AddPackageTest`, `AddUnameTest`
Builder methods for populating a `UbuntuResult` with parsed OVAL definitions and test entries.

### `Eval(ver fleet.OSVersion, software []fleet.Software) ([]fleet.SoftwareVulnerability, error)`
Evaluates all dpkg package tests against the host's installed software, then checks each OVAL definition. Returns a list of `SoftwareVulnerability` entries for any CVEs matched. OS version tests are intentionally skipped for Ubuntu.

### `EvalKernel(software []fleet.Software) ([]fleet.SoftwareVulnerability, error)`
Evaluates kernel image packages using uname tests. Matches installed `linux-image-*` packages against OVAL uname tests via regex, then resolves CVEs through matching definitions.

## Usage Example

```go
result := oval_parsed.NewUbuntuResult()

result.AddDefinition(def)
result.AddPackageTest(1, dpkgTest)
result.AddUnameTest(2, unameTest)

// Evaluate installed packages for CVEs
vulns, err := result.Eval(osVersion, installedSoftware)
if err != nil {
    log.Fatal(err)
}

// Evaluate kernel packages separately
kernelVulns, err := result.EvalKernel(installedSoftware)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Kernel packages are matched using the regex pattern `^linux-image-(\d+\.\d+\.\d+-\d+)-\w+`.
- OS version (`UnameTests`) is evaluated only in `EvalKernel`; `Eval` explicitly skips OS-level test evaluation for Ubuntu hosts.
