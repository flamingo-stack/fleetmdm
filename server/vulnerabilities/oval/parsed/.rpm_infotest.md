Evaluates OVAL RPM info tests against a host's installed software packages to determine vulnerability matches.

## Key Components

### `RpmInfoTest` struct
Represents an OVAL `rpminfo_test` element with the following fields:

| Field | Type | Description |
|---|---|---|
| `Objects` | `[]string` | Package names defined by the OVAL Object |
| `States` | `[]ObjectInfoState` | State conditions to evaluate against matched packages |
| `StateOperator` | `OperatorType` | Logical operator (`AND`/`OR`) applied across state results |
| `ObjectMatch` | `ObjectMatchType` | Match cardinality rule for objects (e.g., `all`, `at least one`) |
| `StateMatch` | `StateMatchType` | Match cardinality rule for states |

### `Eval(packages []fleet.Software) ([]fleet.Software, error)`
Public entry point. Returns matching `fleet.Software` entries when both object and state match criteria are satisfied; returns `nil` otherwise.

### `matches(software []fleet.Software) (int, int, []fleet.Software, error)`
Internal method that iterates packages against defined objects and states. Returns:
- `nObjects` — count of installed packages matching any OVAL object
- `nStates` — count of those packages also satisfying all state conditions
- `[]fleet.Software` — packages matching both object and state criteria

## Usage Example

```go
test := &RpmInfoTest{
    Objects:       []string{"openssl"},
    States:        []ObjectInfoState{versionState},
    StateOperator: OperatorAND,
    ObjectMatch:   ObjectMatchAtLeastOne,
    StateMatch:    StateMatchAtLeastOne,
}

matches, err := test.Eval(installedPackages)
if err != nil {
    log.Fatal(err)
}
if matches != nil {
    fmt.Printf("Vulnerable packages: %v\n", matches)
}
```
