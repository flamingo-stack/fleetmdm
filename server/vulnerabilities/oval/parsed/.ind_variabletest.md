Defines the `VariableTest` struct used to represent a parsed OVAL variable test, grouping the objects, states, and matching configuration for test evaluation.

## Key Components

### `VariableTest`

| Field | Type | Description |
|---|---|---|
| `Objects` | `[]string` | List of object IDs referenced by the test |
| `States` | `[]ObjectStateEvrString` | List of EVR string states to evaluate against |
| `StateOperator` | `OperatorType` | Logical operator applied across multiple states |
| `ObjectMatch` | `ObjectMatchType` | Controls how object matches are combined |
| `StateMatch` | `StateMatchType` | Controls how state matches are combined |

## Usage Example

```go
test := oval_parsed.VariableTest{
    Objects: []string{"obj:1", "obj:2"},
    States: []oval_parsed.ObjectStateEvrString{
        {Value: "1.2.3-4.el7"},
    },
    StateOperator: oval_parsed.OperatorAnd,
    ObjectMatch:   oval_parsed.MatchAll,
    StateMatch:    oval_parsed.MatchAtLeastOne,
}
```

## Notes

- Mirrors the OVAL XML `<variable_test>` element after parsing
- Works alongside sibling test structs (e.g., `RpmInfoTest`) within the `oval_parsed` package
- Source: [`ind_variabletest.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/ind_variabletest.go)
