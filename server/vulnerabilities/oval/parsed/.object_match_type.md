Encodes and evaluates OVAL `ExistenceEnumeration` values, determining whether a set of object matches satisfies a given existence condition during OVAL test assertions.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ObjectMatchType` | `int` | Typed integer representing an existence condition |
| `AllExist` | `const` | All objects in the set must match |
| `AnyExist` | `const` | Zero or more objects may match (always true) |
| `AtLeastOneExists` | `const` | At least one object must match (default) |
| `NoneExist` | `const` | No objects may match |
| `OnlyOneExists` | `const` | Exactly one object must match |
| `NewObjectMatchType` | `func` | Parses an OVAL `ExistenceEnumeration` string into an `ObjectMatchType` |
| `Eval` | `method` | Evaluates whether `matches` out of `total` satisfies the condition |

## Usage Example

```go
// Parse from an OVAL XML attribute value
matchType := oval_parsed.NewObjectMatchType("at_least_one_exists")

// Evaluate: 2 matching objects found out of 5 total
if matchType.Eval(2, 5) {
    fmt.Println("Condition satisfied")
}

// Unknown strings fall back to AtLeastOneExists
defaultType := oval_parsed.NewObjectMatchType("unknown_value")
fmt.Println(defaultType == oval_parsed.AtLeastOneExists) // true
```

## Reference

Implements the OVAL [`ExistenceEnumeration`](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/oval-common-schema.html#ExistenceEnumeration) specification from OVAL 5.10.1.
