Brief struct defining state configuration for Unix `uname` system information evaluation in the OVAL (Open Vulnerability and Assessment Language) parsing layer.

## Key Components

- **`UnixUnameState`** — Struct holding state criteria for evaluating Unix `uname` data against OVAL definitions
  - `States []ObjectStateString` — Collection of state string matchers to compare against `uname` attributes
  - `StateMatch StateMatchType` — Determines how multiple states are combined (e.g., `AND`/`OR` logic)

## Usage Example

```go
state := oval_parsed.UnixUnameState{
    States: []oval_parsed.ObjectStateString{
        {Value: "Linux", Operation: "equals"},
        {Value: "5.15", Operation: "pattern match"},
    },
    StateMatch: oval_parsed.StateMatchAll,
}
```

## Notes

- Part of the `oval_parsed` package, which models OVAL content for vulnerability assessment
- Pairs with corresponding `UnixUnameObject` and `UnixUnameTest` types to form a complete OVAL test definition
- `StateMatchType` controls evaluation logic when multiple `States` entries are present — all must match, any must match, etc.
