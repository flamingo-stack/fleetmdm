Defines the `UnixUnameTest` type and its evaluation logic for comparing kernel version strings against OVAL uname test states.

## Key Components

- **`UnixUnameTest`** — Struct holding a slice of `ObjectStateString` states used to match kernel versions in OVAL definitions.
- **`Eval(version string) (bool, error)`** — Evaluates a kernel version string against all states. Returns `true` only if the version satisfies every state. Supports two operations:
  - `LessThan` — Uses RPM version comparison (`utils.Rpmvercmp`) to check the version is strictly less than the state value.
  - `PatternMatch` — Compiles the state value as a regex and checks it matches the version string.

## Usage Example

```go
test := UnixUnameTest{
    States: []ObjectStateString{
        {Operation: "less than", Value: "5.15.0-78"},
        {Operation: "pattern match", Value: `^5\.\d+`},
    },
}

match, err := test.Eval("5.4.0-77")
if err != nil {
    log.Fatal(err)
}
fmt.Println(match) // true — version is less than threshold and matches pattern
```

## Notes

- Currently scoped to **Ubuntu** kernel version evaluation within the OVAL vulnerability pipeline.
- All states must pass for `Eval` to return `true` (logical AND across states).
- Unsupported operations return a descriptive error rather than silently passing or failing.
