Defines `ObjectStateString`, a string type that encodes an OVAL comparison operation and value pair for evaluating string-based state conditions.

## Key Components

- **`ObjectStateString`** — A string type encoding `op|value` pairs used in OVAL state evaluation
- **`NewObjectStateString(op, val string)`** — Constructor that encodes an operation and value into the `op|value` format
- **`unpack()`** — Internal helper that splits the encoded string into an `OperationType` and raw value
- **`Eval(other string)`** — Evaluates an input string against the encoded value using the encoded operation; supports `Equals`, `NotEqual`, `CaseInsensitiveEquals`, `CaseInsensitiveNotEqual`, and `PatternMatch`

## Usage Example

```go
// Create a state that checks for an exact match
state := oval_parsed.NewObjectStateString("equals", "Ubuntu")
match, err := state.Eval("Ubuntu")
// match == true, err == nil

// Create a state using a regex pattern
patternState := oval_parsed.NewObjectStateString("pattern match", `^Ubuntu.*`)
match, err = patternState.Eval("Ubuntu 22.04")
// match == true, err == nil

// Case-insensitive comparison
ciState := oval_parsed.NewObjectStateString("case insensitive equals", "ubuntu")
match, err = ciState.Eval("UBUNTU")
// match == true, err == nil
```
