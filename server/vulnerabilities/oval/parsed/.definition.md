Defines the core `Definition` and `Criteria` types for evaluating OVAL (Open Vulnerability and Assessment Language) logic trees, determining whether a host is vulnerable based on OS and software package test results.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Criteria` | struct | A node in a logic tree; holds an operator, leaf test IDs (`Criteriums`), and child `Criterias` |
| `Definition` | struct | Top-level container pairing a `Criteria` tree with a list of vulnerability identifiers |
| `Definition.Eval` | method | Evaluates the criteria tree against OS and package test results, returning `true` if the host is affected |
| `Definition.CollectTestIds` | method | BFS traversal that collects every test ID referenced across the criteria tree |
| `Definition.CveVulnerabilities` | method | Filters `Vulnerabilities` to return only CVE-prefixed entries |
| `evalCriteria` | func (internal) | Recursive engine that resolves leaf test results and applies the operator up the tree |
| `findMatchingSoftware` | func | Returns software IDs matching a `Criteria` tree, dispatching to AND/OR helpers |
| `intersect` / `unionAll` | funcs | Set operations on `[]uint` slices, used by the software-matching helpers |

## Usage Example

```go
def := oval_parsed.Definition{
    Criteria: &oval_parsed.Criteria{
        Operator:   oval_parsed.And,
        Criteriums: []int{101, 102},
    },
    Vulnerabilities: []string{"CVE-2024-1234", "USN-advisory-001"},
}

// Evaluate against test results
osTstResults  := map[int]bool{101: true}
pkgTstResults := map[int][]fleet.Software{102: {{Name: "openssl", Version: "1.0.2"}}}

if def.Eval(osTstResults, pkgTstResults) {
    cves := def.CveVulnerabilities() // ["CVE-2024-1234"]
    fmt.Println("Host is affected by:", cves)
}

// Collect all test IDs referenced by this definition
ids := def.CollectTestIds() // [101, 102]
```
