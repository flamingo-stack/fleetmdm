Parses and evaluates OVAL definitions for RHEL-based Linux distributions, matching installed RPM packages against known CVE vulnerabilities.

## Key Components

### `RhelResult`
Struct holding parsed OVAL data:
- `Definitions` — list of OVAL vulnerability definitions
- `RpmInfoTests` — map of RPM package test definitions (keyed by test ID)
- `RpmVerifyFileTests` — map of OS-level file/version verification tests (keyed by test ID)

### `NewRhelResult() *RhelResult`
Constructor that initializes an empty `RhelResult` with pre-allocated maps for both test types.

### `Eval(ver fleet.OSVersion, software []fleet.Software) ([]fleet.SoftwareVulnerability, error)`
Core evaluation method that:
1. Evaluates all `RpmInfoTests` against the provided software inventory
2. Evaluates all `RpmVerifyFileTests` against the OS version
3. Iterates definitions, collecting CVE matches where both OS and package conditions are satisfied
4. Returns a slice of `fleet.SoftwareVulnerability` entries linking software IDs to CVEs

### `EvalKernel(software []fleet.Software) ([]fleet.SoftwareVulnerability, error)`
No-op stub — kernel/uname evaluation is not applicable for RHEL-based distros; always returns `nil, nil`.

## Usage Example

```go
result := oval_parsed.NewRhelResult()
// result.Definitions and test maps are populated by the OVAL parser

osVersion := fleet.OSVersion{Name: "Red Hat Enterprise Linux", Version: "8.7"}
software := []fleet.Software{
    {ID: 1, Name: "openssl", Version: "1.1.1k"},
}

vulns, err := result.Eval(osVersion, software)
if err != nil {
    log.Fatal(err)
}
for _, v := range vulns {
    fmt.Printf("SoftwareID %d is vulnerable to %s\n", v.SoftwareID, v.CVE)
}
```
