Defines the `DataType` enum for the `oval_parsed` package, encoding OVAL's `SimpleDatatypeEnumeration` values as integers for efficient handling of OVAL definition data types.

## Key Components

- **`DataType`** — Integer enum representing all OVAL simple data types.
- **`NewDataType(val string) DataType`** — Parses a string from an OVAL definition into a `DataType` constant. Defaults to `String` for unrecognized values.
- **`(dt DataType) String() string`** — Converts a `DataType` back to its canonical OVAL string representation. Defaults to `"string"` for unknown values.

### Supported Data Types

| Constant | OVAL String |
|---|---|
| `Binary` | `"binary"` |
| `Boolean` | `"boolean"` |
| `EvrString` | `"evr_string"` |
| `FilesetRevision` | `"fileset_revision"` |
| `Float` | `"float"` |
| `IosVersion` | `"ios_version"` |
| `Int` | `"int"` |
| `Ipv4Address` | `"ipv4_address"` |
| `Ipv6Address` | `"ipv6_address"` |
| `String` | `"string"` |
| `Version` | `"version"` |

## Usage Example

```go
// Parse a data type from an OVAL XML attribute
dt := oval_parsed.NewDataType("ipv4_address")
fmt.Println(dt)         // Output: ipv4_address
fmt.Println(dt == oval_parsed.Ipv4Address) // Output: true

// Unknown values fall back to String
unknown := oval_parsed.NewDataType("custom_type")
fmt.Println(unknown)    // Output: string
```
