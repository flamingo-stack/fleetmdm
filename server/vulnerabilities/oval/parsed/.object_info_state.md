Represents an OVAL object info state used to evaluate software packages and OS versions against defined vulnerability criteria.

## Key Components

| Component | Description |
|---|---|
| `ObjectInfoState` | Struct holding OVAL state fields (Name, Arch, Release, Version, EVR, etc.) and a logical `Operator` |
| `EvalSoftware` | Evaluates a `fleet.Software` instance against the state, returning match result |
| `EvalOSVersion` | Evaluates a `fleet.OSVersion` against the state, with platform normalization for RHEL, CentOS, and Amazon Linux |

## Usage Example

```go
state := ObjectInfoState{
    Version: &ObjectStateSimpleValue{Value: "3.1.0"},
    Release: &ObjectStateSimpleValue{Value: "1.el8"},
    Operator: OperatorAnd,
}

sw := fleet.Software{
    Name:    "openssl",
    Version: "3.1.0",
    Release: "1.el8",
}

match, err := state.EvalSoftware(sw)
if err != nil {
    log.Fatal(err)
}
fmt.Println(match) // true

osVer := fleet.OSVersion{Platform: "rhel", Name: "Red Hat Enterprise Linux 8.6"}
match, err = state.EvalOSVersion(osVer)
```

## Notes

- **EVR evaluation** constructs `version-release` strings and uses `utils.Rpmvercmp` for RPM-style comparison; epoch is currently excluded (see [fleet#6236](https://github.com/flamingo-stack/fleetmdm/issues/6236))
- **SignatureKeyId** always evaluates to `true` — signature verification is not implemented; this allows RHEL OVAL definitions to apply to CentOS
- **Platform normalization** in `EvalOSVersion` maps Amazon Linux 2 to RHEL 7 (`7.0.0`) and normalizes CentOS/RHEL release file names to `redhat-release`
- Returns `errors.New("invalid empty state")` when no state fields are populated
