Defines the `OperationType` enum for encoding OVAL (Open Vulnerability and Assessment Language) comparison operations as typed integers, mapping between string representations and integer constants.

## Key Components

- **`OperationType`** — Integer type representing an OVAL `OperationEnumeration` value
- **Constants** — 13 operation types: `Equals`, `NotEqual`, `CaseInsensitiveEquals`, `CaseInsensitiveNotEqual`, `GreaterThan`, `LessThan`, `GreaterThanOrEqual`, `LessThanOrEqual`, `BitwiseAnd`, `BitwiseOr`, `PatternMatch`, `SubsetOf`, `SupersetOf`
- **`NewOperationType(val string) OperationType`** — Parses an OVAL operation string into its corresponding `OperationType` constant; defaults to `Equals` for unrecognized values
- **`(op OperationType) String() string`** — Implements the `Stringer` interface, converting an `OperationType` back to its OVAL string representation

## Usage Example

```go
// Parse an operation string from an OVAL definition
op := oval_parsed.NewOperationType("greater than or equal")
fmt.Println(op) // Output: greater than or equal

// Use in a comparison context
switch op {
case oval_parsed.GreaterThanOrEqual:
    // handle >= comparison
case oval_parsed.PatternMatch:
    // handle regex pattern matching
}

// Round-trip: int → string
op2 := oval_parsed.BitwiseAnd
fmt.Println(op2.String()) // Output: bitwise and

// Unknown value defaults to Equals
op3 := oval_parsed.NewOperationType("unknown")
fmt.Println(op3 == oval_parsed.Equals) // Output: true
```

## Notes

- Follows the [OVAL 5.10.1 `OperationEnumeration` spec](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/oval-common-schema.html#OperationEnumeration)
- Unrecognized strings silently default to `Equals` — validate inputs upstream if strict parsing is required
