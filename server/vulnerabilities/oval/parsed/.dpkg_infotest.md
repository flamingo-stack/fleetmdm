Brief description: Implements OVAL dpkg info test evaluation for Linux package vulnerability scanning, comparing a host's installed Debian packages against OVAL-defined object and state criteria.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `DpkgInfoTest` | struct | Encapsulates an OVAL dpkg info test with object/state matching configuration |
| `Eval` | method | Evaluates the test against a host's installed packages, returning matched software |
| `matches` | method | Internal helper counting object/state matches and collecting matching software |

**`DpkgInfoTest` fields:**

| Field | Type | Description |
|---|---|---|
| `Objects` | `[]string` | Package names defined by the OVAL Object set |
| `States` | `[]ObjectStateEvrString` | EVR string states to evaluate versions against |
| `StateOperator` | `OperatorType` | Logical operator (`AND`/`OR`) combining state results |
| `ObjectMatch` | `ObjectMatchType` | Match qualifier for how many objects must exist on the system |
| `StateMatch` | `StateMatchType` | Match qualifier for how many objects must satisfy state conditions |

## Usage Example

```go
test := &DpkgInfoTest{
    Objects: []string{"openssl", "libssl1.1"},
    States: []ObjectStateEvrString{
        {Operation: LessThan, Value: "1.1.1n-0+deb11u3"},
    },
    StateOperator: OperatorAND,
    ObjectMatch:   AtLeastOneObject,
    StateMatch:    AtLeastOneState,
}

installedPackages := host.Software // []fleet.Software

matched, err := test.Eval(installedPackages)
if err != nil {
    log.Fatal(err)
}
if matched != nil {
    // Host is vulnerable; matched contains the affected packages
}
```
