Defines the `Result` interface for evaluating OVAL (Open Vulnerability and Assessment Language) definitions against system software to detect vulnerabilities.

## Key Components

### `Result` Interface

| Method | Description |
|--------|-------------|
| `Eval(fleet.OSVersion, []fleet.Software)` | Evaluates an OVAL definition against an OS version and installed software list, returning discovered vulnerabilities |
| `EvalKernel([]fleet.Software)` | Evaluates an OVAL definition against installed kernel-image software; currently Ubuntu-only |

## Usage Example

```go
var result oval_parsed.Result = // concrete implementation

// Evaluate software vulnerabilities for an OS version
vulns, err := result.Eval(osVersion, installedSoftware)
if err != nil {
    log.Fatal(err)
}

// Evaluate kernel-specific vulnerabilities (Ubuntu)
kernelVulns, err := result.EvalKernel(kernelSoftware)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Both methods return `[]fleet.SoftwareVulnerability` and an error
- `EvalKernel` is a specialized path for kernel image packages, currently scoped to Ubuntu distributions
- Concrete implementations of this interface are expected to contain parsed OVAL definition data used during evaluation
