Encodes and evaluates OVAL definition state comparisons for simple value types, supporting boolean, integer, float, EVR string, and plain string data types against various comparison operators.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ObjectStateSimpleValue` | `string` type | Encoded state value in the format `dtype\|op\|val` |
| `NewObjectStateSimpleValue` | Constructor | Creates an encoded `ObjectStateSimpleValue` from data type, operation, and value strings |
| `Eval` | Method | Evaluates a candidate value against the encoded state, returning a boolean result |
| `complexTypes` | `var` | List of unsupported complex `DataType` values (e.g., `Version`, `Ipv4Address`, `IosVersion`) |

## Usage Example

```go
// Create a state that checks if an integer value is greater than 5
state := NewObjectStateSimpleValue("int", "greater than", "5")

// Evaluate against a candidate value
match, err := state.Eval("10")
if err != nil {
    log.Fatal(err)
}
fmt.Println(match) // true

// EVR string comparison (uses RPM version comparison logic)
evrState := NewObjectStateSimpleValue("evr_string", "less than", "1:2.0.0-1.el8")
match, err = evrState.Eval("1:1.9.0-1.el8")
fmt.Println(match) // true

// Complex types (e.g., ipv4_address) are not supported
unsupported := NewObjectStateSimpleValue("ipv4_address", "equals", "192.168.1.1")
_, err = unsupported.Eval("192.168.1.1")
// err: type "ipv4_address" not supported
```

## Notes

- Complex types (`Version`, `Binary`, `FilesetRevision`, `IosVersion`, `Ipv4Address`, `Ipv6Address`) return an error — use dedicated handlers for these.
- EVR string evaluation delegates to `ObjectStateEvrString.Eval` with `utils.Rpmvercmp`.
- String comparison delegates to `ObjectStateString.Eval` for pattern/regex support.
- Follows the [OVAL 5.10.1 EntityStateAnySimpleType](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/oval-definitions-schema.html#EntityStateAnySimpleType) specification.
