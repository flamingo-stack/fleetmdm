Evaluates RPM verify file tests used in OVAL definitions to assert OS version conditions against installed RHEL-based systems.

## Key Components

### `RpmVerifyFileTest` struct

Represents an `<rpmverifyfile_test>` OVAL element with the following fields:

| Field | Type | Description |
|---|---|---|
| `FilePath` | `string` | Path of the RPM-installed file being tested |
| `State` | `ObjectInfoState` | The state assertion to evaluate |
| `StateOperator` | `OperatorType` | Logical operator applied across states |
| `ObjectMatch` | `ObjectMatchType` | Match strategy for the object |
| `StateMatch` | `StateMatchType` | Match strategy for the state result |

### `Eval(ver fleet.OSVersion) (bool, error)`

Evaluates whether the given OS version satisfies the test's state. Internally:

1. Delegates version comparison to `State.EvalOSVersion`
2. Converts the boolean result into a count (`nState` = `1` or `0`)
3. Passes a fixed object count of `1` to `StateMatch.Eval`, since each test targets exactly one `(object, state)` pair

## Usage Example

```go
test := RpmVerifyFileTest{
    FilePath: "/etc/redhat-release",
    State: ObjectInfoState{
        // state fields populated from OVAL definition
    },
    StateMatch: StateMatchType("at least one"),
}

osVer := fleet.OSVersion{Name: "Red Hat Enterprise Linux 9.0"}

matched, err := test.Eval(osVer)
if err != nil {
    log.Fatal(err)
}
fmt.Println("OS version matches:", matched)
```

## Notes

- Although `<rpmverifyfile_test>` can target any RPM-installed file, in RHEL OVAL definitions it is primarily used for OS version assertions
- The fixed object count of `1` reflects that each test covers a single object/state pair
