Defines XML deserialization types for the OVAL `rpmverifyfile_test` element, used to parse RPM package file verification tests in Linux (RHEL-based) OVAL definitions.

## Key Components

| Type | Description |
|---|---|
| `RpmVerifyFileTestXML` | Primary exported struct representing an `rpmverifyfile_test` element with check logic, object reference, and state references |
| `rpmVerifyFileTestObjectXML` | Internal struct holding the `object_ref` attribute linking to the test's target object |
| `rpmVerifyFileTestStateXML` | Internal struct holding a `state_ref` attribute for each associated state element |

## Usage Example

```go
import (
    oval_input "github.com/flamingo-stack/fleetmdm/path/to/oval_input"
    "encoding/xml"
)

data := []byte(`
<rpmverifyfile_test
    id="oval:test:1"
    check_existence="at_least_one_exists"
    check="all"
    state_operator="AND">
    <object object_ref="oval:obj:1"/>
    <state state_ref="oval:ste:1"/>
</rpmverifyfile_test>`)

var test oval_input.RpmVerifyFileTestXML
if err := xml.Unmarshal(data, &test); err != nil {
    log.Fatal(err)
}

fmt.Println(test.Id)            // oval:test:1
fmt.Println(test.Check)         // all
fmt.Println(test.Object.Id)     // oval:obj:1
fmt.Println(test.States[0].Id)  // oval:ste:1
```
