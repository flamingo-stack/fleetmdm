Represents the XML structure for an OVAL variable state element, used to define expected variable values in OVAL definitions.

## Key Components

- **`VariableStateXML`** — Struct mapping to the OVAL `variable_state` XML element, containing:
  - `Id` — The state's unique identifier (XML attribute)
  - `Value` — The expected value, typed as `SimpleTypeXML` (XML element)

## Usage Example

```go
state := oval_input.VariableStateXML{
    Id:    "oval:org.example:ste:1",
    Value: oval_input.SimpleTypeXML{/* ... */},
}
```
