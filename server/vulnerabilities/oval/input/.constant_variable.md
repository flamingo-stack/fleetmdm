Defines the `ConstantVariableXML` struct for parsing OVAL constant variable elements from XML definitions, mapping to the [OVAL 5.10.1 schema specification](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/oval-definitions-schema.html#constant_variable).

## Key Components

- **`ConstantVariableXML`** — Struct representing an OVAL `constant_variable` element with the following fields:
  - `Id` — The unique variable identifier (XML attribute `id`)
  - `DataType` — The data type of the variable values (XML attribute `datatype`)
  - `Values` — One or more constant values (XML element `value`)

## Usage Example

```go
import (
    "encoding/xml"
    oval_input "github.com/flamingo-stack/fleetmdm/path/to/oval_input"
)

data := `<constant_variable id="oval:example:var:1" datatype="string">
    <value>expected_value</value>
</constant_variable>`

var v oval_input.ConstantVariableXML
if err := xml.Unmarshal([]byte(data), &v); err != nil {
    log.Fatal(err)
}

fmt.Println(v.Id)       // oval:example:var:1
fmt.Println(v.DataType) // string
fmt.Println(v.Values)   // [expected_value]
```

## Notes

- This struct is typically embedded within larger OVAL definition XML documents and unmarshalled as part of a broader OVAL variables collection.
- Multiple `<value>` child elements are supported via the `Values []string` slice.
