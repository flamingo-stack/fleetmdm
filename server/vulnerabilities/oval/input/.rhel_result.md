Defines the `RhelResultXML` struct, which aggregates all parsed tokens extracted from an OVAL (Open Vulnerability and Assessment Language) file targeting RHEL distributions.

## Key Components

### `RhelResultXML`

A container struct that groups the various XML elements produced during OVAL file parsing for RHEL distros:

| Field | Type | Description |
|---|---|---|
| `Definitions` | `[]DefinitionXML` | OVAL vulnerability/compliance definitions |
| `RpmVerifyFileTests` | `[]RpmVerifyFileTestXML` | Tests for verifying RPM-managed files |
| `RpmInfoTests` | `[]RpmInfoTestXML` | Tests targeting RPM package metadata |
| `RpmInfoTestStates` | `[]RpmInfoStateXML` | Expected states for RPM info tests |
| `RpmInfoTestObjects` | `[]PackageInfoTestObjectXML` | Objects referenced by RPM info tests |
| `RpmVerifyFileObjects` | `[]RpmVerifyFileObjectXML` | Objects for RPM file verification tests |
| `RpmVerifyFileStates` | `[]RpmVerifyFileStateXML` | Expected states for RPM file verification |
| `Variables` | `map[string]ConstantVariableXML` | Named constant variables used across definitions |

## Usage Example

```go
result := oval_input.RhelResultXML{
    Definitions:        parsedDefinitions,
    RpmInfoTests:       parsedRpmInfoTests,
    RpmInfoTestStates:  parsedRpmInfoStates,
    RpmInfoTestObjects: parsedRpmInfoObjects,
    Variables:          parsedVariables,
}

for _, def := range result.Definitions {
    // process each OVAL definition
}
```
