Defines XML-serialization types for OVAL variable test elements, mapping to the [OVAL 5.10.1 independent definitions schema](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/independent-definitions-schema.html#variable_test).

## Key Components

| Type | Description |
|---|---|
| `variableObjectXML` | Internal struct representing a variable object reference (`object_ref`) |
| `variableStateXML` | Internal struct representing a variable state reference (`state_ref` attribute) |
| `VariableTestXML` | Exported struct representing a full OVAL variable test, including its ID, object, and associated states |

## Usage Example

```go
data := `<variable_test id="oval:test:1">
    <object object_ref="oval:obj:1"/>
    <state state_ref="oval:ste:1"/>
</variable_test>`

var test oval_input.VariableTestXML
if err := xml.Unmarshal([]byte(data), &test); err != nil {
    log.Fatal(err)
}

fmt.Println(test.Id)              // oval:test:1
fmt.Println(test.Object.Id)       // oval:obj:1
fmt.Println(test.States[0].Id)    // oval:ste:1
```

## Notes

- `variableObjectXML` and `variableStateXML` are unexported; only `VariableTestXML` is intended for use outside the `oval_input` package.
- A single test may reference multiple states via the `States` slice.
