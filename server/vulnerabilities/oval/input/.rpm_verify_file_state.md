Defines the XML deserialization structure for an OVAL `rpmverifyfile_state` element, used to represent the expected state of RPM-managed files during Linux security compliance checks.

## Key Components

### `RpmVerifyFileStateXML`

Struct mapping to the OVAL `rpmverifyfile_state` element per the [Linux Definitions Schema v5.10.1](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/linux-definitions-schema.html#rpmverifyfile_state). Key fields include:

| Field | XML Tag | Description |
|---|---|---|
| `Id` | `id` (attr) | Unique state identifier |
| `Name`, `Epoch`, `Version`, `Arch` | element | RPM package metadata matchers |
| `Filepath`, `ExtendedName` | element | File path and NEVRA-extended name |
| `SizeDiffers` … `CapabilitiesDiffer` | element | RPM verify difference flags |
| `ConfigurationFile`, `GhostFile`, `LicenseFile`, `ReadmeFile` | element | RPM file classification flags |
| `Operator` | `operator` (attr) | Logical operator for combining state criteria |

All value fields use `*SimpleTypeXML`, supporting OVAL's typed comparison operations (e.g., pattern match, equals).

## Usage Example

```go
import "encoding/xml"

data := []byte(`
<rpmverifyfile_state id="oval:example:ste:1" operator="AND">
    <filepath operation="equals">/etc/passwd</filepath>
    <size_differs operation="equals">not different</size_differs>
</rpmverifyfile_state>`)

var state oval_input.RpmVerifyFileStateXML
if err := xml.Unmarshal(data, &state); err != nil {
    log.Fatal(err)
}

fmt.Println(state.Id)       // oval:example:ste:1
fmt.Println(*state.Operator) // AND
```

## Notes

- The `ReadmeFile` XML tag contains a trailing tab character (`"readme_file\t"`) — this appears to be a source-level typo and may cause silent deserialization mismatches.
- Part of the `oval_input` package within the Fleet MDM OVAL evaluation pipeline.
