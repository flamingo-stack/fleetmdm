Defines XML-serializable structs for parsing UNIX `uname` test objects from OVAL definition files.

## Key Components

| Type | Description |
|---|---|
| `unixUnameTestStateXML` | Internal struct representing a state reference within a uname test, mapped to the `state_ref` XML attribute |
| `UnixUnameTestXML` | Exported struct representing a UNIX uname test element, containing an `id` attribute and a slice of associated state references |

## Usage Example

```go
import "encoding/xml"

data := `<uname_test id="oval:test:uname:1">
    <state state_ref="oval:state:uname:1"/>
</uname_test>`

var test oval_input.UnixUnameTestXML
xml.Unmarshal([]byte(data), &test)

fmt.Println(test.Id)           // oval:test:uname:1
fmt.Println(test.States[0].Id) // oval:state:uname:1
```
