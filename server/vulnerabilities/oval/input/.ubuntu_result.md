Aggregates parsed tokens from an Ubuntu-targeted OVAL (Open Vulnerability and Assessment Language) file into a single structured result type.

## Key Components

### `UbuntuResultXML`

A struct that groups all parsed OVAL XML tokens for Ubuntu distributions into categorized slices and maps:

| Field | Type | Description |
|---|---|---|
| `Definitions` | `[]DefinitionXML` | OVAL vulnerability/compliance definitions |
| `DpkgInfoTests` | `[]DpkgInfoTestXML` | Debian package test elements |
| `DpkgInfoStates` | `[]DpkgInfoStateXML` | Desired state conditions for dpkg checks |
| `DpkgInfoObjects` | `[]PackageInfoTestObjectXML` | Package objects referenced by tests |
| `UnameTests` | `[]UnixUnameTestXML` | Unix `uname` system info tests |
| `UnameStates` | `[]UnixUnameStateXML` | State conditions for `uname` checks |
| `VariableTests` | `[]VariableTestXML` | Variable-based OVAL tests |
| `VariableObjects` | `map[int]VariableObjectXML` | Variable objects keyed by integer ID |
| `VariableStates` | `[]VariableStateXML` | State conditions for variable tests |
| `Variables` | `map[string]ConstantVariableXML` | Constant variables keyed by string ID |

## Usage Example

```go
result := oval_input.UbuntuResultXML{}

// Populate after parsing an Ubuntu OVAL XML file
result.Definitions = parsedDefinitions
result.DpkgInfoTests = parsedDpkgTests
result.DpkgInfoStates = parsedDpkgStates
result.Variables = map[string]oval_input.ConstantVariableXML{
    "oval:com.ubuntu.focal:var:1": parsedConstVar,
}

// Iterate over definitions for vulnerability evaluation
for _, def := range result.Definitions {
    fmt.Println(def.ID)
}
```

## Notes

- Used as the central output container after parsing Ubuntu-specific OVAL XML feeds
- `VariableObjects` and `Variables` use maps rather than slices to support direct lookup by ID during evaluation
