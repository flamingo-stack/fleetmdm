Defines XML-deserialization structures for OVAL `rpmverifyfile_object` and its associated behaviors, used when parsing Linux OVAL definition files.

## Key Components

### `rpmVerifyFileBehaviors`
Unexported struct mapping the `<behaviors>` XML element attributes that control which RPM file verification checks to skip (e.g., `nomd5`, `nosize`, `nouser`). Corresponds to the OVAL [`RpmVerifyFileBehaviors`](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/linux-definitions-schema.html#RpmVerifyFileBehaviors) type.

| Field | XML Attribute | Purpose |
|---|---|---|
| `NoLinkTo` | `nolinkto` | Skip symlink target check |
| `NoMd5` | `nomd5` | Skip MD5 checksum check |
| `NoSize` | `nosize` | Skip file size check |
| `NoUser` | `nouser` | Skip owner user check |
| `NoGroup` | `nogroup` | Skip owner group check |
| `NoMtime` | `nomtime` | Skip modification time check |
| `NoMode` | `nomode` | Skip file mode/permissions check |
| `NoRev` | `nordev` | Skip device node check |
| `NoConfigFiles` | `noconfigfiles` | Skip config file checks |
| `NoGhostFiles` | `noghostfiles` | Skip ghost file checks |

### `RpmVerifyFileObjectXML`
Exported struct representing a full `<rpmverifyfile_object>` XML element, including its ID, optional behaviors, and package/file filter fields (`name`, `epoch`, `version`, `release`, `arch`, `filepath`), each typed as `SimpleTypeXML`.

## Usage Example

```go
var obj oval_input.RpmVerifyFileObjectXML
if err := xml.Unmarshal(data, &obj); err != nil {
    log.Fatal(err)
}
fmt.Println(obj.Id, obj.FilePath)
```
