Defines XML binding structs for parsing OVAL `rpminfo_test` elements used in Linux RPM package vulnerability assessments.

## Key Components

| Type | Description |
|---|---|
| `RpmInfoTestXML` | Primary exported struct representing an OVAL `rpminfo_test` element with check attributes and associated object/state references |
| `rpmInfoTestObjectXML` | Unexported struct capturing the `object_ref` attribute linking a test to its RPM info object |
| `rpmInfoTestStateXML` | Unexported struct capturing the `state_ref` attribute linking a test to one or more OVAL states |

### `RpmInfoTestXML` Fields

| Field | XML Attribute | Description |
|---|---|---|
| `Id` | `id` | Unique OVAL test identifier |
| `CheckExistence` | `check_existence` | Defines how object existence is evaluated |
| `Check` | `check` | Defines how collected items are evaluated against states |
| `StateOperator` | `state_operator` | Logical operator (`AND`/`OR`) applied across multiple states |
| `Object` | `object` | Reference to the associated RPM info object |
| `States` | `state` | Slice of state references evaluated against the object |

## Usage Example

```go
import "encoding/xml"

data := []byte(`
<rpminfo_test id="oval:com.example:tst:1"
              check_existence="at_least_one_exists"
              check="all"
              state_operator="AND">
    <object object_ref="oval:com.example:obj:1"/>
    <state state_ref="oval:com.example:ste:1"/>
</rpminfo_test>`)

var test oval_input.RpmInfoTestXML
xml.Unmarshal(data, &test)

fmt.Println(test.Id)            // oval:com.example:tst:1
fmt.Println(test.Check)         // all
fmt.Println(test.Object.Id)     // oval:com.example:obj:1
fmt.Println(test.States[0].Id)  // oval:com.example:ste:1
```
