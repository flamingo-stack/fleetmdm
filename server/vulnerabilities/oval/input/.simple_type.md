Defines the `SimpleTypeXML` struct used to deserialize simple OVAL type elements from XML input.

## Key Components

- **`SimpleTypeXML`** — Struct representing a simple OVAL type element with three XML-mapped fields:
  - `Datatype` — maps to the `datatype` XML attribute
  - `Value` — maps to the element's character data (inner text)
  - `Op` — maps to the `operation` XML attribute

## Usage Example

```go
import "encoding/xml"

data := `<oval_element datatype="string" operation="equals">example_value</oval_element>`

var simple oval_input.SimpleTypeXML
xml.Unmarshal([]byte(data), &simple)

fmt.Println(simple.Datatype) // "string"
fmt.Println(simple.Value)    // "example_value"
fmt.Println(simple.Op)       // "equals"
```

## Notes

- Typically embedded within larger OVAL definition structs to represent typed, comparable values
- The `Op` field drives comparison logic (e.g., `equals`, `greater than`, `pattern match`) when evaluating OVAL checks
