Defines the `PackageInfoTestObjectXML` struct used to represent OVAL package info test objects for both `dpkginfo_object` and `rpminfo_object` definitions in Linux OVAL schemas.

## Key Components

- **`PackageInfoTestObjectXML`** — Struct mapping to OVAL package info test object XML elements, supporting both Debian (`dpkginfo_object`) and RPM (`rpminfo_object`) package types. Note: the `behaviors` child element is not used when testing installed RPM packages.
  - `Id` — The object's XML attribute identifier
  - `Name` — The package name, represented as an `ObjectNameXML`

## Usage Example

```go
obj := oval_input.PackageInfoTestObjectXML{
    Id:   "oval:com.example:obj:1",
    Name: oval_input.ObjectNameXML{Value: "openssl"},
}
```
