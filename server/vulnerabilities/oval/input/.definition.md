Defines XML-deserialization types for OVAL definition structures, mapping OVAL definition schema elements to Go structs for parsing vulnerability definitions.

## Key Components

| Type | Description |
|------|-------------|
| `CriterionXML` | Leaf-level test reference with optional negation (`test_ref`, `negate` attributes) |
| `CriteriaXML` | Recursive criteria tree node supporting logical operators (`AND`/`OR`) and nested criteria/criterion elements |
| `ReferenceXML` | Vulnerability reference identifier (e.g., CVE ID via `ref_id`) |
| `DefinitionXML` | Top-level OVAL definition containing an ID, vulnerability references, and a root criteria tree |

## Usage Example

```go
import (
    "encoding/xml"
    oval_input "github.com/flamingo-stack/fleetmdm/..."
)

data := []byte(`
<definition id="oval:com.example:def:1">
  <metadata>
    <reference ref_id="CVE-2024-1234"/>
  </metadata>
  <criteria operator="AND">
    <criterion test_ref="oval:com.example:tst:1" negate="false"/>
  </criteria>
</definition>`)

var def oval_input.DefinitionXML
if err := xml.Unmarshal(data, &def); err != nil {
    log.Fatal(err)
}

fmt.Println(def.Id)                          // oval:com.example:def:1
fmt.Println(def.Vulnerabilities[0].Id)       // CVE-2024-1234
fmt.Println(def.Criteria.Operator)           // AND
fmt.Println(def.Criteria.Criteriums[0].TestId) // oval:com.example:tst:1
```

## Notes

- Fully conforms to the [OVAL Definitions Schema v5.10.1](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/oval-definitions-schema.html)
- `CriteriaXML` is self-referential, supporting arbitrarily deep nested criteria trees
