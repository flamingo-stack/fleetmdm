Represents the XML structure for a UNIX `uname` state element as defined in the OVAL 5.10.1 schema, used to capture operating system release information for compliance evaluation.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `UnixUnameStateXML` | struct | Maps the OVAL `uname_state` XML element for UNIX systems |
| `Id` | `string` | The state's unique identifier, parsed from the `id` XML attribute |
| `OSRelease` | `*SimpleTypeXML` | Optional OS release string (e.g., kernel version), parsed from the `os_release` XML element |

## Usage Example

```go
import "encoding/xml"

data := `<uname_state id="oval:example:ste:1">
    <os_release operation="equals">5.15.0-generic</os_release>
</uname_state>`

var state oval_input.UnixUnameStateXML
if err := xml.Unmarshal([]byte(data), &state); err != nil {
    log.Fatal(err)
}

fmt.Println(state.Id)               // oval:example:ste:1
fmt.Println(state.OSRelease.Value)  // 5.15.0-generic
```
