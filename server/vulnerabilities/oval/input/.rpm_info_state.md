Defines the `RpmInfoStateXML` struct for deserializing OVAL `rpminfo_state` XML elements from Linux definition schema documents.

## Key Components

### `RpmInfoStateXML`
XML-mapped struct representing an [OVAL `rpminfo_state`](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/linux-definitions-schema.html#rpminfo_state) element, used to describe expected RPM package state conditions during vulnerability assessment.

| Field | XML Mapping | Description |
|---|---|---|
| `Id` | `id` (attr) | Unique state identifier |
| `Name` | `name` | Package name condition |
| `Arch` | `arch` | Architecture condition |
| `Epoch` | `epoch` | Package epoch condition (optional) |
| `Release` | `release` | Package release condition (optional) |
| `Version` | `version` | Package version condition (optional) |
| `Evr` | `evr` | Epoch-version-release combined condition |
| `SignatureKeyId` | `signature_keyid` | GPG signing key ID condition |
| `ExtendedName` | `extended_name` | Extended package name condition |
| `Filepath` | `filepath` | File path condition |
| `Operator` | `operator` (attr) | Logical operator (`AND`/`OR`) for combining conditions |

All fields except `Id` and `Operator` use `*SimpleTypeXML`, which carries both the value and comparison operation.

## Usage Example

```go
import "encoding/xml"

data := []byte(`
  <rpminfo_state id="oval:example:ste:1" operator="AND">
    <name operation="equals">openssl</name>
    <evr datatype="evr_string" operation="less than">0:1.1.1-8.el8</evr>
  </rpminfo_state>
`)

var state oval_input.RpmInfoStateXML
if err := xml.Unmarshal(data, &state); err != nil {
    log.Fatal(err)
}

fmt.Println(state.Id)           // oval:example:ste:1
fmt.Println(state.Name.Value)   // openssl
```
