Represents the XML structure for an OVAL object name element, supporting both direct character data values and variable references.

## Key Components

### `ObjectNameXML`

A struct that maps to an OVAL object `<name>` XML element with the following fields:

| Field | XML Mapping | Description |
|---|---|---|
| `VarRef` | `var_ref` attribute | References an OVAL variable by ID |
| `VarCheck` | `var_check` attribute | Defines how variable values are checked (e.g., `all`, `at least one`) |
| `Value` | character data | The literal string value of the name element |

## Usage Example

```go
import "encoding/xml"

type ObjectXML struct {
    Name ObjectNameXML `xml:"name"`
}

data := `<name var_ref="oval:org.example:var:1" var_check="all">fallback</name>`

var obj ObjectXML
if err := xml.Unmarshal([]byte(data), &obj); err != nil {
    log.Fatal(err)
}

fmt.Println(obj.Name.VarRef)   // oval:org.example:var:1
fmt.Println(obj.Name.VarCheck) // all
fmt.Println(obj.Name.Value)    // fallback
```

## Notes

- `VarRef` and `VarCheck` are optional attributes; when omitted, `Value` holds the static name string used for object matching.
- This struct is typically embedded within larger OVAL object definitions during XML unmarshalling of OVAL content feeds.
