Defines XML unmarshaling structures for OVAL `dpkginfo_test` elements, used to parse Debian package information tests from OVAL security content feeds.

## Key Components

| Type | Description |
|------|-------------|
| `DpkgInfoTestXML` | Primary struct representing a `dpkginfo_test` element with test ID, check logic, and references |
| `dpkgInfoTestObjectXML` | Internal struct holding the `object_ref` attribute linking to a `dpkginfo_object` |
| `dpkgInfoTestStateXML` | Internal struct holding the `state_ref` attribute linking to a `dpkginfo_state` |

### `DpkgInfoTestXML` Fields

| Field | XML Attribute | Description |
|-------|--------------|-------------|
| `Id` | `id` | Unique test identifier |
| `CheckExistence` | `check_existence` | Controls whether object must exist (e.g., `at_least_one_exists`) |
| `Check` | `check` | Comparison operator applied to collected items (e.g., `all`) |
| `StateOperator` | `state_operator` | Logical operator joining multiple states (e.g., `AND`) |
| `Object` | `object` | Reference to the associated `dpkginfo_object` |
| `States` | `state` | Slice of state references evaluated against collected data |

## Usage Example

```go
import (
    "encoding/xml"
    oval_input "github.com/flamingo-stack/fleetmdm/..."
)

data := []byte(`
<dpkginfo_test id="oval:com.example:tst:1"
    check_existence="at_least_one_exists"
    check="all"
    state_operator="AND">
    <object object_ref="oval:com.example:obj:1"/>
    <state state_ref="oval:com.example:ste:1"/>
</dpkginfo_test>`)

var test oval_input.DpkgInfoTestXML
if err := xml.Unmarshal(data, &test); err != nil {
    log.Fatal(err)
}

fmt.Println(test.Id)             // oval:com.example:tst:1
fmt.Println(test.CheckExistence) // at_least_one_exists
fmt.Println(test.Object.Id)      // oval:com.example:obj:1
fmt.Println(test.States[0].Id)   // oval:com.example:ste:1
```
