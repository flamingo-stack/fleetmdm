Defines the XML deserialization structure for OVAL `dpkginfo_state` elements, representing the expected state of Debian package information used in vulnerability assessments.

## Key Components

### `DpkgInfoStateXML`
XML-mapped struct corresponding to the [OVAL 5.10.1 `dpkginfo_state`](https://oval.mitre.org/language/version5.10.1/ovaldefinition/documentation/linux-definitions-schema.html#dpkginfo_state) schema definition.

| Field | XML Attribute/Element | Description |
|---|---|---|
| `Id` | `id` (attr) | Unique state identifier |
| `Name` | `name` | Package name to match |
| `Arch` | `arch` | Target architecture |
| `Epoch` | `epoch` | Package epoch (optional) |
| `Release` | `release` | Package release version (optional) |
| `Version` | `version` | Package version (optional) |
| `Evr` | `evr` | Epoch-Version-Release combined string |

All package fields use `*SimpleTypeXML`, allowing comparison operations (e.g., `equals`, `less than`) defined on the OVAL simple type.

## Usage Example

```go
// Typical usage via XML unmarshalling from an OVAL definitions file
var state oval_input.DpkgInfoStateXML
if err := xml.Unmarshal(data, &state); err != nil {
    log.Fatal(err)
}

// Access parsed fields
fmt.Println(state.Id)          // e.g., "oval:com.example:ste:1"
fmt.Println(state.Name.Value)  // e.g., "openssl"
fmt.Println(state.Evr.Value)   // e.g., "0:1.1.1f-1ubuntu2"
```
