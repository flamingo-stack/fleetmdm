Represents an OVAL variable object XML element used for referencing OVAL variables in compliance definitions.

## Key Components

- **`VariableObjectXML`** — Struct mapping to an OVAL `variable_object` element with two fields:
  - `Id` — the object's unique identifier (XML attribute `id`)
  - `RefID` — a reference to an OVAL variable via the `var_ref` child element

## Usage Example

```go
obj := oval_input.VariableObjectXML{
    Id:    "oval:org.example:obj:1",
    RefID: "oval:org.example:var:1",
}
```
