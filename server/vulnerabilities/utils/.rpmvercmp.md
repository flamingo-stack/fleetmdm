RPM version comparison utility implementing the `rpmvercmp` algorithm for comparing EVR (Epoch:Version-Release) strings used in RPM package management.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Rpmvercmp` | Function | Top-level EVR comparison entry point; returns `-1`, `0`, or `1` |
| `rpmCmp` | Function | Core rpmvercmp algorithm; segments and compares version/release strings |
| `nextSeg` | Function | Extracts the next maximal alphanumeric segment from a version string |
| `segment` | Struct | Holds a parsed version segment (numeric value, letter string, and consumed offset) |
| `segment.compare` | Method | Compares two segments with tilde-modifier and numeric-vs-alpha precedence rules |
| `Release` | Function | Extracts the release component (after `-`) from an EVR string |
| `version` | Function | Extracts the version component (between epoch `:` and release `-`) |
| `epoch` | Function | Extracts the numeric epoch (before `:`) defaulting to `0` if absent |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/pkg/utils"
)

func main() {
    // Compare two EVR strings
    fmt.Println(utils.Rpmvercmp("1:2.3.4-5", "1:2.3.4-6"))  // -1 (older release)
    fmt.Println(utils.Rpmvercmp("2:1.0-1",   "1:9.9-99"))   //  1 (higher epoch wins)
    fmt.Println(utils.Rpmvercmp("1.2.3-4",   "1.2.3-4"))    //  0 (equal)

    // Tilde pre-release handling
    fmt.Println(utils.Rpmvercmp("1.0~beta1", "1.0"))         // -1 (tilde lowers precedence)

    // Extract EVR components individually
    fmt.Println(utils.Release("1:2.3.4-5.el9")) // "5.el9"
}
```

## Algorithm Notes

- **Epoch** — numeric prefix before `:`, defaults to `0`; compared first
- **Version/Release** — split into maximal alpha or numeric segments; separators (`.`, `_`, etc.) are ignored
- **Segment ordering** — numeric > alpha; numbers compared by value; letters compared lexicographically
- **Tilde (`~`)** — treated as a pre-release modifier that sorts *lower* than the preceding segment, enabling pre-release version strings (e.g., `1.0~beta < 1.0`)
