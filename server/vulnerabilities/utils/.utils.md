Provides generic utility functions for vulnerability management operations, including filtering, diffing, batch processing, and file resolution used across Fleet's vulnerability pipeline.

## Key Components

| Function | Description |
|---|---|
| `RecentVulns[T]` | Filters a vulnerability slice to only those whose CVE is present in a metadata list; returns filtered vulns and a CVE→metadata map |
| `BatchProcess[T]` | Iterates a map of vulnerabilities and calls a datastore function in configurable batch sizes |
| `VulnsDelta[T]` | Compares found vs. existing vulnerabilities and returns two slices: records to insert and records to delete |
| `ProductIDsIntersect` | Returns `true` if two product ID sets share at least one common element |
| `LatestFile` | Resolves a file path in a directory, falling back to the most recently modified file sharing the same prefix and extension |

All generic functions are constrained to `fleet.Vulnerability`, which requires `GetCVE()` and `Key()` methods.

## Usage Example

```go
// Filter vulnerabilities to only recent CVEs
recentVulns, meta := utils.RecentVulns(allVulns, cveMeta)

// Compute insert/delete delta against existing DB records
toInsert, toDelete := utils.VulnsDelta(recentVulns, existingVulns)

// Persist inserts in batches of 500
err := utils.BatchProcess(toInsertMap, datastoreUpsertFn, 500)

// Resolve the latest NVD feed file in a directory
path, err := utils.LatestFile("nvd-2024.json", "/var/fleet/vulndb")
if err != nil {
    log.Fatal(err)
}

// Check if two product ID sets overlap
intersects := utils.ProductIDsIntersect(productSetA, productSetB)
```
