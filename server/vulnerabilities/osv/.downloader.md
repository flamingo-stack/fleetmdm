Downloads and verifies OSV (Open Source Vulnerability) artifacts from the FleetDM vulnerabilities GitHub repository, with checksum validation and sync result tracking.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `AssetInfo` | struct | Metadata for a GitHub release asset (name, ID, SHA256 digest) |
| `ReleaseInfo` | struct | GitHub release metadata with a map of asset name → `AssetInfo` |
| `SyncResult` | struct | Outcome summary with `Downloaded`, `Skipped`, `NotInRelease`, and `Failed` version lists |
| `getLatestRelease` | func | Calls the GitHub API to fetch the latest release and filters for OSV assets (excludes delta files) |
| `downloadOSVArtifact` | func | Downloads a single release asset by ID, following redirect URLs when needed |
| `computeFileSHA256` | func | Computes a `sha256:<hex>` digest string for a local file |
| `SyncOSV` | func | Public entry point; syncs OSV artifacts for given Ubuntu versions to a destination directory |
| `syncOSVWithDownloader` | func | Internal implementation accepting injected `downloadFunc` and `filenameFn` for testability |

## Usage Example

```go
ctx := context.Background()

// Fetch latest release metadata
release, err := getLatestRelease(ctx)
if err != nil {
    log.Fatal(err)
}

// Sync OSV artifacts for specific Ubuntu versions
result, err := SyncOSV(
    ctx,
    "/var/lib/fleet/osv",
    []string{"20.04", "22.04"},
    time.Now(),
    release,
)
if err != nil {
    log.Printf("sync error: %v", err)
}

log.Printf("downloaded: %v", result.Downloaded)
log.Printf("skipped (cached): %v", result.Skipped)
log.Printf("not in release: %v", result.NotInRelease)
log.Printf("failed: %v", result.Failed)
```

> Files are skipped if a local copy already exists and its SHA256 digest matches the release asset's digest. Failed downloads are cleaned up from disk automatically.
