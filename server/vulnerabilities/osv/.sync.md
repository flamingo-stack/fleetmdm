Manages synchronization of OSV (Open Source Vulnerabilities) artifact files for Ubuntu and RHEL platforms, handling download, cleanup, and version detection of vulnerability data files.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OSVFilePrefix` | const | Filename prefix for Ubuntu OSV artifacts (`osv-ubuntu-`) |
| `OSVRHELFilePrefix` | const | Filename prefix for RHEL OSV artifacts (`osv-rhel-`) |
| `Refresh` | func | Syncs Ubuntu OSV artifacts for OS versions present in the fleet inventory |
| `RefreshRHEL` | func | Syncs RHEL OSV artifacts for OS versions present in the fleet inventory |
| `RefreshAll` | func | Downloads all Ubuntu and RHEL OSV artifacts from the latest release (no inventory filtering) |
| `versionsFromRelease` | func | Extracts Ubuntu and RHEL version strings from release asset names |
| `removeOldOSVArtifacts` | func | Deletes stale Ubuntu OSV files that don't match today's date |
| `removeOldRHELOSVArtifacts` | func | Deletes stale RHEL OSV files that don't match today's date |
| `getNeededUbuntuVersions` | func | Extracts unique Ubuntu version codes (e.g., `"2204"`) from fleet OS inventory |
| `getNeededRHELVersions` | func | Extracts unique RHEL major versions from fleet OS inventory, excluding Fedora |

## Usage Example

```go
// Sync Ubuntu OSV artifacts for hosts in the fleet
downloaded, err := osv.Refresh(ctx, osVersions, "/var/fleet/vuln", time.Now())
if err != nil {
    log.Printf("OSV sync error: %v", err)
}

// Sync RHEL OSV artifacts
downloaded, err = osv.RefreshRHEL(ctx, osVersions, "/var/fleet/vuln", time.Now())

// Pre-seed a vulnerability directory without DB access (e.g. fleetctl)
downloaded, err = osv.RefreshAll(ctx, "/var/fleet/vuln")
```

## Artifact Naming

Files follow a date-stamped format. Outdated files (non-matching date) are automatically removed for successfully synced versions:

```text
osv-ubuntu-2204-2026-03-30.json.gz
osv-rhel-9-2026-04-08.json.gz
```

> **Note:** `RefreshAll` does not delete older artifacts — cleanup remains the responsibility of the server's vulnerability cron job.
