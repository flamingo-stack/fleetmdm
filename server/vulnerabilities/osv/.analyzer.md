Orchestrates OSV (Open Source Vulnerability) analysis for Ubuntu hosts by loading vulnerability artifacts, matching installed software against known CVEs, and synchronizing vulnerability records in the Fleet datastore.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ErrUnsupportedPlatform` | `var` | Sentinel error returned for non-Ubuntu/RHEL platforms |
| `IsPlatformSupported` | `func` | Reports whether a platform string (`"ubuntu"` or `"rhel"`) is supported |
| `OSVArtifact` | `struct` | Deserialized OSV feed file containing per-package vulnerability maps |
| `OSVVulnerability` | `struct` | Single CVE record with introduced/fixed version range and explicit version list |
| `Analyze` | `func` | Public entry point — loads the artifact for a given `OSVersion` and runs `analyzeOSV` |
| `analyzeOSV` | `func` | Core loop: batches software, matches, diffs against existing DB records, inserts/deletes |
| `matchSoftwareToOSV` | `func` | Maps `fleet.Software` entries to `OSVVulnerability` records; handles kernel package name normalization |
| `loadOSVArtifact` | `func` | Opens, gunzips, and JSON-decodes a date-stamped `.json.gz` artifact file; rejects empty feeds |
| `findLatestOSVArtifactForVersion` | `func` | Filesystem fallback — scans `vulnPath` for the most recently modified non-delta artifact |
| `extractUbuntuVersion` | `func` | Converts human version strings (e.g. `"22.04.8 LTS"`) to compact keys (`"2204"`) |
| `kernelVersionMatches` | `func` | Prefix-aware comparison between osquery kernel versions and OSV version strings |

## Usage Example

```go
vulns, err := osv.Analyze(
    ctx,
    ds,
    fleet.OSVersion{Platform: "ubuntu", Version: "22.04.3 LTS"},
    "/var/fleet/vulnerabilities",
    true,  // collectVulns — return newly inserted records
    logger,
    time.Now().UTC(),
)
if errors.Is(err, osv.ErrUnsupportedPlatform) {
    log.Println("skipping unsupported platform")
}
```

Artifact files are expected at `<vulnPath>/osv-ubuntu-<NNNN>-<YYYY-MM-DD>.json.gz`. If the date-specific file is absent, `loadOSVArtifact` falls back to the most recently modified matching file in the directory.
