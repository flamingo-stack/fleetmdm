Fetches and parses Microsoft 365 Apps security update data from the Microsoft Learn documentation page, converting it into structured bulletin files for vulnerability tracking.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SecurityUpdatesURL` | `const` | URL for the Microsoft Learn Office security updates page |
| `VersionBranch` | `struct` | Represents an Office version branch with YYMM version and build numbers |
| `SecurityRelease` | `struct` | A single security update release containing date, version branches, and CVEs |
| `ScrapeSecurityUpdates` | `func` | Fetches the security updates page and returns parsed releases |
| `BuildBulletinFile` | `func` | Converts scraped releases into a structured `BulletinFile` |
| `FetchBulletin` | `func` | Convenience wrapper combining scrape and build into a single call |

## Usage Example

```go
import (
    "context"
    "net/http"
    "time"
)

client := &http.Client{Timeout: 30 * time.Second}
ctx := context.Background()

// Fetch and parse the full bulletin in one step
bulletin, err := winoffice.FetchBulletin(ctx, client)
if err != nil {
    log.Fatalf("failed to fetch bulletin: %v", err)
}

// Inspect version branches and their resolved builds
for version, vb := range bulletin.Versions {
    for _, update := range vb.SecurityUpdates {
        fmt.Printf("Version %s: %s resolved in %s\n",
            version, update.CVE, update.ResolvedInVersion)
    }
}
```

## Parsing Logic

The scraper requests the page as `text/markdown` and processes it line-by-line using three regex patterns:

- **Date headers** (`## March 10, 2026`) — mark the start of a new `SecurityRelease`
- **Version lines** (`Current Channel: Version 2602 (Build 19725.20172)`) — populate `VersionBranch` entries; "Retail" channel entries are skipped
- **CVE references** (`[CVE-2026-XXXX]`) — collected per release

Deprecated version branches (present in older releases but absent from the latest) receive upgrade path entries pointing to the oldest newer version that contains a fix for each CVE.
