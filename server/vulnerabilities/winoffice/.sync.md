Synchronizes the local Windows Office vulnerability bulletin with the latest version published on GitHub, downloading updates and removing outdated files as needed.

## Key Components

- **`SyncFromGithub(ctx, dstDir)`** — Entry point that initializes GitHub and filesystem clients, then triggers bulletin synchronization to the specified destination directory.
- **`syncBulletin(ctx, fsClient, ghClient)`** — Core sync logic: compares the remote bulletin timestamp against local copies, downloads the latest if outdated, and deletes stale local files.

## Usage Example

```go
ctx := context.Background()

if err := winoffice.SyncFromGithub(ctx, "/var/fleet/vulnerabilities"); err != nil {
    log.Fatalf("failed to sync Windows Office bulletin: %v", err)
}
```

## Sync Behavior

| Condition | Action |
|---|---|
| No remote bulletin published | No-op |
| No local bulletin exists | Download remote |
| Local bulletin is older than remote | Download remote, delete stale files |
| Local bulletin is current | No download, clean up any older duplicates |
