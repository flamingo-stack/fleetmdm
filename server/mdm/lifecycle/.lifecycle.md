Manages MDM host lifecycle actions for Apple (macOS/iOS/iPadOS) and Windows platforms, orchestrating enrollment, reset, turn-off, and deletion workflows.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `HostLifecycle` | struct | Core manager that executes lifecycle actions against a datastore |
| `HostAction` | type | String enum for supported lifecycle actions |
| `HostOptions` | struct | Input parameters for lifecycle actions (UUID, platform, host info, etc.) |
| `NewActivityFunc` | type alias | Function signature for creating fleet activity records |
| `New()` | constructor | Creates a `HostLifecycle` instance with datastore, logger, and activity function |
| `Do()` | method | Dispatches a lifecycle action to the appropriate platform handler |

### Supported Actions

| Constant | Value | Description |
|----------|-------|-------------|
| `HostActionTurnOn` | `"turn-on"` | Tasks after a host enrolls into MDM |
| `HostActionTurnOff` | `"turn-off"` | Tasks after a host unenrolls from MDM |
| `HostActionReset` | `"reset"` | Resets MDM-related enrollment data |
| `HostActionDelete` | `"delete"` | Cleans up MDM data when a host is deleted from Fleet |

## Usage Example

```go
lifecycle := mdmlifecycle.New(ds, logger, newActivityFn)

// Handle a new Apple device enrollment
err := lifecycle.Do(ctx, mdmlifecycle.HostOptions{
    Action:   mdmlifecycle.HostActionTurnOn,
    Platform: "darwin",
    UUID:     "ABC-123-UUID",
    EnrollReference: "ref-token",
    HasSetupExperienceItems: true,
})

// Reset enrollment for a Windows device
err = lifecycle.Do(ctx, mdmlifecycle.HostOptions{
    Action:   mdmlifecycle.HostActionReset,
    Platform: "windows",
    UUID:     "WIN-DEVICE-UUID",
})
```
