Provides helper functions for loading, parsing, and decrypting Apple MDM cryptographic assets (CA, APNS, ABM) stored in the Fleet datastore.

## Key Components

| Function/Type | Description |
|---|---|
| `CAKeyPair` | Loads the Apple MDM CA certificate and private key as a `*tls.Certificate` |
| `CACertsAndKeyForDecryption` | Returns the CA private key plus all historical CA certificates (including rolled-over ones) whose public key matches, enabling CMS decryption across CA rotations |
| `CADecryptRetriever` | Interface extending `fleet.MDMAssetRetriever` with `GetAllMDMConfigAssetsByNameIncludingDeleted` for historical cert lookup |
| `APNSKeyPair` | Loads the APNS certificate/key pair and returns the cert's MD5 checksum |
| `KeyPair` | Generic loader for any named cert/key asset pair from the datastore |
| `KeyPairWithMD5` | Like `KeyPair` but also returns the certificate's MD5 checksum |
| `X509Cert` | Loads and parses a single PEM-encoded certificate from the datastore |
| `APNSTopic` | Extracts the MDM push topic string from the stored APNS certificate |
| `ABMToken` | Loads ABM (Apple Business Manager) assets and decrypts the OAuth1 token for a given org |
| `DecryptRawABMToken` | Decrypts a raw ABM token using an RSA private key and certificate |

## Usage Example

```go
// Load CA keypair for MDM operations
caCert, err := assets.CAKeyPair(ctx, ds)
if err != nil {
    log.Fatal(err)
}

// Get all historical CA certs + key for CMS decryption after CA rollover
certs, privKey, err := assets.CACertsAndKeyForDecryption(ctx, ds)
if err != nil {
    log.Fatal(err)
}

// Retrieve and decrypt ABM OAuth token for a specific org
token, err := assets.ABMToken(ctx, ds, "MyOrg")
if err != nil {
    log.Fatal(err)
}
fmt.Println(token.ConsumerKey)

// Get APNS push topic
topic, err := assets.APNSTopic(ctx, ds)
// topic => "com.apple.mgmt.External.xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```
