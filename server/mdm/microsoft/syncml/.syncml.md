Defines XML namespace constants, SOAP/SyncML error codes, MS-MDM status codes, and MS-MDE2 protocol configuration values used throughout the Windows MDM enrollment and device management implementation.

## Key Components

### XML Namespace Constants
- `DiscoverNS`, `PolicyNS`, `EnrollWSTrust`, `EnrollNSS`, `EnrollNSA` — WS-Trust and SOAP envelope namespace URIs for MS-MDE2 enrollment messages
- `ActionNsDiscovery`, `ActionNsPolicy`, `ActionNsEnroll` — SOAP action URIs for discovery, policy, and enrollment responses
- `EnrollReqTypePKCS10`, `EnrollReqTypePKCS7` — binary security token type identifiers

### SOAP Fault Codes (`SoapError*`)
Error constants for enrollment failures: `SoapErrorMessageFormat`, `SoapErrorAuthentication`, `SoapErrorAuthorization`, `SoapErrorCertificateRequest`, `SoapErrorEnrollmentServer`, `SoapErrorInternalServiceFault`, `SoapErrorInvalidSecurity`

### OMA-DM Status Codes (`CmdStatus*`)
Full set of MS-MDM response codes (`200`–`516`), including `CmdStatusOK`, `CmdStatusNotFound`, `CmdStatusCommandFailed`, `CmdStatusAtomicFailed`, and rollback variants.

### DM Session Alert Codes (`CmdAlert*`)
OMA-DM alert type constants for session management: `CmdAlertServerInitiatedManagement` (`1200`), `CmdAlertClientInitiatedManagement` (`1201`), `CmdAlertSessionAbort`, `CmdAlertGeneric`, etc.

### Provisioning & DMClient Configuration
- `DocProvisioningAppProviderID = "Fleet"` — server identifier written into provisioning documents
- `DMClientPollIntervalLocURI` — LocURI for tuning Windows MDM poll cadence via the DMClient CSP
- `WstepCertRenewalPeriodInDays`, `PolicyCertValidityPeriodInSecs`, `PolicyMinKeyLength` — certificate policy parameters
- `SyncMLContentType`, `SoapContentType` — HTTP `Content-Type` headers for MDM and SOAP responses
- `SupportedEnrollmentVersions` — slice of supported MS-MDE2 protocol versions (`4.0`–`7.0`)

## Usage Example

```go
// Setting Content-Type for an MDM response
w.Header().Set("Content-Type", syncml.SyncMLContentType)

// Checking a command status code
if statusCode == syncml.CmdStatusNotFound {
    // handle missing node
}

// Building a LocURI for the DMClient poll interval
locURI := syncml.DMClientPollIntervalLocURI
// ./Device/Vendor/MSFT/DMClient/Provider/Fleet/Poll/IntervalForFirstSetOfRetries

// Referencing the enrollment provider ID
providerID := syncml.DocProvisioningAppProviderID // "Fleet"
```
