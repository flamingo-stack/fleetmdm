Parses and compares ADMX (Administrative Template File) policy payloads used in Microsoft MDM configurations, handling XML unmarshalling, case normalization, and structural equality checks.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IsADMX` | Function | Detects whether a string is a valid ADMX policy payload |
| `Equal` | Function | Compares two ADMX policy strings for semantic equality |
| `unmarshal` | Function (internal) | Wraps raw policy text in an XML root tag, unescapes CDATA, and normalizes to lowercase before decoding |
| `admxPolicy` | Struct (internal) | Holds `<enabled/>`, `<disabled/>`, and `<data>` elements |
| `admxPolicyItem` | Struct (internal) | Represents a single `<data id="..." value="..."/>` element |

## Usage Example

```go
payload := `<![CDATA[
  <enabled/>
  <data id="Publishing_Server_URL_Prompt" value="http://someuri"/>
  <data id="Global_Publishing_Refresh_Options" value="1"/>
]]>`

// Check if the string is an ADMX policy
if admx.IsADMX(payload) {
    fmt.Println("Valid ADMX policy detected")
}

// Compare two policy payloads for semantic equality
a := `<enabled/><data id="foo" value="bar"/>`
b := `<Enabled/><data id="FOO" value="bar"/>`

equal, err := admx.Equal(a, b)
if err != nil {
    log.Fatal(err)
}
fmt.Println(equal) // true — comparison is case-insensitive
```

## Notes

- Element names are **case-insensitive** (`<enabled/>` and `<Enabled/>` are treated as equivalent) via lowercase normalization before parsing.
- When a policy is `<disabled/>`, `<data>` elements are ignored during equality checks.
- `<data>` items are sorted by `id` before comparison, making equality order-independent.
