Parses and compares Windows WLAN XML profiles as used in Microsoft MDM, handling XML escaping, SSID normalization, and profile equality checks.

## Key Components

| Export | Description |
|---|---|
| `IsWLANXML(text string) bool` | Detects whether a string is a valid WLAN XML profile |
| `Equal(a, b string) (bool, error)` | Compares two WLAN XML profile strings for semantic equality |
| `WlanXmlProfile` | Top-level struct mapping to a `<WLANProfile>` XML element |
| `WlanXmlProfileSSIDConfig` | Holds SSID list, optional SSID prefix, and broadcast flag |
| `WlanXmlProfileSSID` | Individual SSID with `Hex` and `Name` fields; normalizes hex to uppercase |
| `GenerateWLANXMLProfileForTests(...)` | Produces a valid, escaped WLAN XML profile string for use in tests |

**Notable behavior:**

- **Double-unwrapping:** Profiles arrive XML-escaped inside an outer XML envelope; `unmarshal` strips the outer layer before parsing the inner `<WLANProfile>`.
- **SSID normalization:** When only a `Name` is present, the hex encoding is derived automatically and uppercased to match Windows behavior.
- **Lenient equality:** Profile comparison intentionally ignores security fields (e.g., WPA2 vs WPA3) because Windows may silently upgrade those when connecting. Only `Name`, `NonBroadcast`, `SSIDPrefix`, and the sorted SSID list are compared.

## Usage Example

```go
a := `&lt;WLANProfile ...&gt;...&lt;/WLANProfile&gt;`
b := `&lt;WLANProfile ...&gt;...&lt;/WLANProfile&gt;`

if wlanxml.IsWLANXML(a) {
    equal, err := wlanxml.Equal(a, b)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println("profiles match:", equal)
}

// In tests, generate a well-formed profile:
profile, err := wlanxml.GenerateWLANXMLProfileForTests("CorpWiFi", wlanxml.WlanXmlProfileSSIDConfig{
    SSID:         []wlanxml.WlanXmlProfileSSID{{Name: "CorpWiFi"}},
    NonBroadcast: false,
})
```
