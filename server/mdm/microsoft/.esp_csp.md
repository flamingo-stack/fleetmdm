Defines constants and helper functions for generating Windows Enrollment Status Page (ESP) error messages in the Microsoft MDM CSP implementation.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ESPTimeoutSeconds` | `const int` | Default ESP timeout value (10800 seconds / 3 hours) |
| `ESPSoftwareFailureErrorText` | `const string` | Error message shown when a critical software install fails and blocks setup |
| `ESPTimeoutErrorText` | `const string` | Error message shown when the 3-hour ESP timeout expires |
| `ESPSoftwareFailureContinuableErrorText` | `func` | Returns a user-facing error message listing failed installs when the user is allowed to continue past the failure |
| `joinFailedNames` | `func` | Formats a slice of software names into a human-readable list, capping at 3 names before summarizing the remainder |

## Usage Example

```go
// Single failure: hard block
fmt.Println(ESPSoftwareFailureErrorText)
// → "Critical software failed to install. Reset your device..."

// Continuable failures: list up to 3 names, summarize the rest
msg := ESPSoftwareFailureContinuableErrorText([]string{"Slack", "Zoom", "Chrome", "VS Code"})
// → "Slack, Zoom, Chrome, and 1 more failed to install. Reset your device to try again..."

// No names collected (defensive case)
msg = ESPSoftwareFailureContinuableErrorText([]string{})
// → "Some software failed to install. Reset your device..."
```

## Notes

- `joinFailedNames` is unexported and handles Oxford-comma formatting: `"A"`, `"A and B"`, `"A, B, and C"`, or `"A, B, C, and N more"`.
- The 3-name cap (`espMaxFailedNamesShown`) guards against overflowing the small ESP display area.
