Processes Windows MDM configuration profiles by finding and replacing Fleet variables with their resolved values before deployment to a host.

## Key Components

**`PreprocessWindowsProfileContentsForDeployment`** — Public entry point that wraps the internal preprocessing function, replacing Fleet variables in a profile string for a specific host.

**`MicrosoftProfileProcessingError`** — Sentinel error type for profile-level variable substitution failures. Signals that a single profile should be marked as failed without aborting the broader deployment flow.

**`ProfilePreprocessDependencies`** — Shared context injected once per deployment batch: datastore, logger, app config, SCEP CA configs, managed certificate payload accumulator, NDES config, and challenge-fetching callbacks.

**`ProfilePreprocessParams`** — Per-profile parameters: `HostUUID` and `ProfileUUID`.

**`preprocessWindowsProfileContents`** — Core logic. Scans the profile for Fleet variable tokens, then resolves each one via XML-safe replacement:

| Variable | Resolved Value |
|---|---|
| `$FLEET_VAR_HOST_UUID` | Host UUID |
| `$FLEET_VAR_HOST_PLATFORM` | `"windows"` |
| `$FLEET_VAR_HOST_HARDWARE_SERIAL` | Host hardware serial (DB lookup) |
| `$FLEET_VAR_HOST_END_USER_EMAIL_IDP` | IdP email (DB lookup) |
| `$FLEET_VAR_SCEP_WINDOWS_CERTIFICATE_ID` | Profile UUID |
| `$FLEET_VAR_CUSTOM_SCEP_CHALLENGE_<CA>` | Custom SCEP challenge token |
| `$FLEET_VAR_CUSTOM_SCEP_PROXY_URL_<CA>` | Custom SCEP proxy URL |
| `$FLEET_VAR_NDES_SCEP_CHALLENGE` | One-time NDES OTP (live fetch) |
| `$FLEET_VAR_NDES_SCEP_PROXY_URL` | Fleet SCEP proxy URL |

## Usage Example

```go
result, err := microsoft_mdm.PreprocessWindowsProfileContentsForDeployment(
    microsoft_mdm.ProfilePreprocessDependencies{
        Context:   ctx,
        Logger:    logger,
        DataStore: ds,
        AppConfig: appCfg,
        ManagedCertificatePayloads: &managedCerts,
    },
    microsoft_mdm.ProfilePreprocessParams{
        HostUUID:    "abc-123",
        ProfileUUID: "prof-456",
    },
    profileXMLContents,
)
if err != nil {
    // handle per-profile failure
}
```
