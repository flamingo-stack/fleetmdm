Computes install and remove deltas for Windows MDM profile reconciliation, determining which profiles need to be pushed to or withdrawn from each host based on desired state, label applicability, content changes, and secret updates.

## Key Components

| Export | Description |
|--------|-------------|
| `ComputeWindowsReconcileDeltas` | Diffs desired vs. current profile state per host, returning `toInstall` and `toRemove` slices of `MDMWindowsProfilePayload` |
| `DesiredWindowsProfileUUIDsByHost` | Returns a map of host UUID → desired profile UUIDs, used to guard LocURIs shared between a remove target and a still-applicable profile |
| `isTerminalRemoveStatus` (unexported) | Reports whether a remove row's status (`verifying`/`verified`) should block flipping it back to an install |

## Usage Example

```go
toInstall, toRemove := microsoft_mdm.ComputeWindowsReconcileDeltas(
    hosts,
    hostLabels,
    currentByHost,
    profilesByTeam,
    profilesWithBrokenLabels,
)

// Queue installs
for _, p := range toInstall {
    _ = enqueueProfileInstall(ctx, p)
}

// Queue removals, protecting shared LocURIs
desiredByHost := microsoft_mdm.DesiredWindowsProfileUUIDsByHost(
    hosts,
    hostLabels,
    profilesByTeam,
)
for _, p := range toRemove {
    protectedUUIDs := desiredByHost[p.HostUUID]
    _ = enqueueProfileRemove(ctx, p, protectedUUIDs)
}
```

An install is queued when the profile is new, its checksum changed, secret variables were updated after the current row's timestamp, or its current operation is a non-terminal remove. A remove is queued when the profile is no longer desired, is not already mid-removal, and does not carry a broken label reference.
