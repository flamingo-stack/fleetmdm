Parses ASN.1-encoded Certificate Signing Requests (CSRs) from Windows MDM-enrolled devices, working around non-standard characters (`!` and `0x00`) in the CommonName field that the standard `crypto/x509` package rejects.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `ParseCertificateRequestFromWindowsDevice` | Function | Entry point — unmarshals raw ASN.1 bytes into a `*x509.CertificateRequest`, tolerating Windows-specific invalid PrintableString characters |
| `isPrintable` | Function | Patched version of the stdlib ASN.1 `isPrintable` — additionally allows `'!'` and `0x00` bytes found in Windows device certificate CommonName fields |
| `certificateRequest` | Struct | Internal ASN.1 representation of a full CSR (`TBSCertificateRequest` + signature algorithm + signature value) |
| `tbsCertificateRequest` | Struct | The to-be-signed portion of the CSR (version, subject, public key, raw attributes) |
| `signatureAlgorithmDetails` | Var | Lookup table mapping OIDs → `x509.SignatureAlgorithm`, hash, and public-key algorithm for all supported algorithms |
| `fieldParameters` | Struct | Parsed representation of ASN.1 struct field tag strings (explicit/implicit, optional, default values, etc.) |

## Usage Example

```go
import microsoft_mdm "github.com/flamingo-stack/fleetmdm/server/mdm/microsoft"

// raw is the DER-encoded CSR bytes received during Windows MDM enrollment
func handleEnrollment(raw []byte) error {
    csr, err := microsoft_mdm.ParseCertificateRequestFromWindowsDevice(raw)
    if err != nil {
        return fmt.Errorf("parsing Windows MDM CSR: %w", err)
    }

    // CommonName may contain '!' or 0x00 bytes — this parser handles them
    fmt.Println("Device CN:", csr.Subject.CommonName)
    return nil
}
```

## Notes

- This is a **fork of the Go stdlib** `x509.ParseCertificateRequest`, modified only in `isPrintable`. All other parsing logic mirrors the standard library.
- Windows devices produce CNs such as `F717C0F0-5F68-4AC3-A341-01B254!4219DFB0A902F747A9C4FD43C8CE36CE`, which the unpatched parser rejects.
- See upstream reference: [`encoding/asn1/asn1.go#L433`](https://github.com/golang/go/blob/e126572f/src/encoding/asn1/asn1.go#L433)
