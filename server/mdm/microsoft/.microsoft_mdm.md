Defines constants, URL resolvers, and utilities for Fleet's Windows MDM (MS-MDE2) HTTP endpoints and device enrollment operations.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `MDMPath` | `/api/mdm/microsoft` | Base path for all Windows MDM endpoints |
| `MDE2DiscoveryPath` | `…/discovery` | MS-MDE2 IDiscoveryService endpoint |
| `MDE2AuthPath` | `…/auth` | Security Token Service endpoint |
| `MDE2PolicyPath` | `…/policy` | X.509 Certificate Enrollment Policy (MS-XCEP) |
| `MDE2EnrollPath` | `…/enroll` | WS-Trust enrollment (MS-WSTEP) |
| `MDE2ManagementPath` | `…/management` | Device management endpoint |
| `MDE2TOSPath` | `…/tos` | Terms of Service content |
| `MSEnrollEntryPoint` | `/EnrollmentServer/Discovery.svc` | MS-MDE user-driven enrollment entry |
| `MSManageEntryPoint` | `/ManagementServer/MDM.svc` | MS-MDE management entry |

**Device States:** `MDMDeviceStateNotEnrolled`, `MDMDeviceStateEnrolled`, `MDMDeviceStateManaged`

### Functions

- **`ResolveWindowsMDMDiscovery/Policy/Enroll/Management(serverURL)`** — Resolves full URLs for each MDM endpoint by combining a base server URL with the corresponding path.
- **`Encrypt(rawValue, cert)`** — PKCS7-encrypts a string using an X.509 certificate, returning a base64-encoded result.
- **`IsValidUPN(userID)`** — Validates a User Principal Name (UPN) format (e.g., `user@domain.com`) using a regex per the [Windows UPN naming spec](https://learn.microsoft.com/en-us/windows/win32/ad/naming-properties#upn-format).

## Usage Example

```go
// Resolve the enrollment URL
enrollURL, err := microsoft_mdm.ResolveWindowsMDMEnroll("https://mdm.example.com")
if err != nil {
    log.Fatal(err)
}

// Validate a UPN before enrollment
if !microsoft_mdm.IsValidUPN("user@example.com") {
    log.Fatal("invalid UPN")
}

// Encrypt a value using a device certificate
encrypted, err := microsoft_mdm.Encrypt("sensitive-token", deviceCert)
if err != nil {
    log.Fatal(err)
}
```
