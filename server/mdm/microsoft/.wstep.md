Implements the MS-WSTEP certificate management layer for Windows MDM (MS-MDE2 protocol), handling CSR signing, STS/EUA JWT token issuance and validation, and Azure AD token claim extraction.

## Key Components

### Interfaces

- **`CertManager`** — Core interface for MDM certificate operations: CSR signing, identity fingerprint, STS/EUA token management
- **`CertStore`** — Storage interface for WSTEP certificate persistence (implemented by `fleet.Datastore`)

### Types

| Type | Description |
|---|---|
| `manager` | Concrete `CertManager` implementation holding identity cert, private key, and cert store |
| `STSClaims` | JWT claims struct for STS auth tokens (contains UPN) |
| `EUATokenClaims` | Validated result of a parsed EUA token (UPN + DeviceID) |
| `AzureData` | Parsed claims from an Azure AD JWT token |

### Key Functions

- **`NewCertManager`** — Constructs a `CertManager` from PEM-encoded cert and private key
- **`SignClientCSR`** — Signs a client CSR using the identity keypair; stores the cert and returns DER bytes + SHA1 fingerprint
- **`NewSTSAuthToken`** — Issues a short-lived RS256 JWT (10 min) with a UPN claim for STS authentication
- **`NewEUAToken`** — Issues a 1-hour RS256 JWT containing UPN and device ID for end-user authentication passthrough
- **`GetSTSAuthTokenUPNClaim`** — Validates an STS JWT and extracts the UPN claim
- **`GetEUATokenClaims`** — Validates an EUA JWT and returns `EUATokenClaims`
- **`GetAzureAuthTokenClaims`** — Validates an Azure AD JWT via JWKS and extracts tenant/user claims

## Usage Example

```go
certManager, err := microsoft_mdm.NewCertManager(store, certPEM, privKeyPEM)
if err != nil {
    log.Fatal(err)
}

// Sign a client CSR during MDM enrollment
derBytes, fingerprint, err := certManager.SignClientCSR(ctx, deviceID, clientCSR)

// Issue an STS token for a user
stsToken, err := certManager.NewSTSAuthToken("user@example.com")

// Issue an EUA token to avoid double-prompting
euaToken, err := certManager.NewEUAToken("user@example.com", deviceID)

// Validate and extract EUA claims later
claims, err := certManager.GetEUATokenClaims(euaToken)
fmt.Println(claims.UPN, claims.DeviceID)
```
