Core MDM utility package providing cryptographic operations, profile platform detection, and reserved profile name management for Apple, Windows, and Android device management.

## Key Components

### Constants
- `MaxAppleProfileRetries` / `MaxWindowsProfileRetries` — Retry limits for profile installation commands (3 and 1 respectively)
- Reserved profile name constants (`FleetdConfigProfileName`, `FleetFileVaultProfileName`, `FleetWindowsOSUpdatesProfileName`, etc.)

### Functions

| Function | Description |
|---|---|
| `DecryptBase64CMS` | Decrypts a base64-encoded PKCS7 payload using a single certificate and private key |
| `DecryptBase64CMSWithCerts` | Tries multiple certificates with one key — handles CA certificate rollovers where serial numbers change but the private key remains the same |
| `GetRawProfilePlatform` | Detects profile platform (`"darwin"`, `"windows"`, `"android"`, or `""`) by inspecting raw bytes |
| `DetermineJSONConfigType` | Classifies a JSON profile as Apple DDM (uppercase keys) or Android (lowercase keys) |
| `GuessProfileExtension` | Returns `"xml"`, `"json"`, or `""` based on profile content prefix |
| `EncryptAndEncode` | AES-GCM encrypts plaintext with a symmetric key, returns base64-encoded ciphertext with prepended nonce |
| `DecodeAndDecrypt` | Reverses `EncryptAndEncode` — base64 decodes then AES-GCM decrypts |
| `FleetReservedProfileNames` | Returns a set of all Fleet-reserved profile display names |
| `ListFleetReservedWindowsProfileNames` / `ListFleetReservedMacOSProfileNames` / `ListFleetReservedMacOSDeclarationNames` | Per-platform slices of reserved names |

## Usage Example

```go
// Detect platform from raw profile bytes
platform := mdm.GetRawProfilePlatform(profileBytes)
// returns "darwin", "windows", "android", or ""

// Decrypt a PKCS7-encrypted value after a CA rollover
decrypted, err := mdm.DecryptBase64CMSWithCerts(
    base64Payload,
    privateKey,
    []*x509.Certificate{currentCert, previousCert},
)

// AES-GCM symmetric encryption round-trip
ciphertext, _ := mdm.EncryptAndEncode("secret-value", symmetricKey)
plaintext, _  := mdm.DecodeAndDecrypt(ciphertext, symmetricKey)

// Guard against reserved profile name collisions
reserved := mdm.FleetReservedProfileNames()
if _, ok := reserved[profileName]; ok {
    return errors.New("profile name is reserved by Fleet")
}
```
