Handles downloading Fleet maintained app installers from remote URLs, including filename extraction from HTTP responses.

## Key Components

- **`InstallerTimeout`** — Constant defining a 15-minute timeout for installer download operations.
- **`DownloadInstaller`** — Validates the installer URL, performs an HTTP GET request, and returns the installer content as a `*fleet.TempFileReader` along with the resolved filename.
- **`FilenameFromResponse`** — Extracts the installer filename from an HTTP response, first attempting the `Content-Disposition` header (with a fallback for non-RFC-compliant values), then falling back to the URL path basename.

## Usage Example

```go
ctx, cancel := context.WithTimeout(context.Background(), maintained_apps.InstallerTimeout)
defer cancel()

client := &http.Client{}
reader, filename, err := maintained_apps.DownloadInstaller(ctx, "https://example.com/app.pkg", client)
if err != nil {
    // handle fleet.InvalidArgumentError or wrapped context errors
}
defer reader.Close()

fmt.Println("Downloaded:", filename)
```

## Notes

- Returns a `fleet.NewInvalidArgumentError` for invalid URLs, 404 responses, or status codes ≥ 400.
- `FilenameFromResponse` handles non-RFC-compliant `Content-Disposition` headers via a string split fallback, and ultimately falls back to `path.Base` on the request URL path if no header is present.
