Handles synchronization of Fleet Maintained Apps (FMA) metadata by fetching app manifests from remote CDN endpoints and persisting them to the Fleet datastore.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `AppsList` | struct | Versioned list of app listings fetched from `/apps.json` |
| `appListing` | struct | Individual app entry with name, slug, platform, and unique identifier |
| `FMAInstallerCache` | interface | Optional cache interface for retrieving previously fetched installer metadata by version |
| `SyncAppsList` | func | Fetches the latest apps list and upserts it into the datastore |
| `FetchAppsList` | func | Downloads and parses `/apps.json`; validates schema version (must be `2`) |
| `Hydrate` | func | Enriches a bare `MaintainedApp` record with installer details from its per-app manifest, with optional version-pinned cache lookup |
| `fetchManifestFile` | func | Fetches a manifest path from the primary CDN, falling back to the GitHub raw fallback on failure |
| `resolveBaseURLs` | func | Returns primary/fallback base URLs, respecting `FLEET_DEV_MAINTAINED_APPS_BASE_URL` and `FLEET_DEV_MAINTAINED_APPS_FALLBACK_BASE_URL` overrides |
| `upsertMaintainedApps` | func | Upserts each app into the datastore and removes apps no longer present upstream |

## Usage Example

```go
// Sync the full apps list into the database (e.g., on a cron schedule)
if err := maintained_apps.SyncAppsList(ctx, ds); err != nil {
    log.Errorf("syncing maintained apps: %v", err)
}

// Hydrate a skeleton app record with the latest installer metadata
app := &fleet.MaintainedApp{ID: 42, Name: "1Password", Slug: "1password"}
hydrated, err := maintained_apps.Hydrate(ctx, app, "", nil, nil)
if err != nil {
    log.Errorf("hydrating app: %v", err)
}

// Hydrate a specific version using a local cache (avoids remote fetch)
hydrated, err = maintained_apps.Hydrate(ctx, app, "8.10.36", teamID, installerCache)
```

> **Dev overrides:** Set `FLEET_DEV_MAINTAINED_APPS_BASE_URL` or `FLEET_DEV_MAINTAINED_APPS_FALLBACK_BASE_URL` to redirect manifest fetches to a local or staging server during development.
