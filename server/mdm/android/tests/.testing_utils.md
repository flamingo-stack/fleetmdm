Shared test infrastructure for Android MDM integration tests, providing a reusable test suite with a live HTTP server, MySQL datastore, and mock Android Management API client.

## Key Components

- **`AndroidDSWithMock`** — Composite datastore embedding `mysql.Datastore` and `ds_mock.Store`, with explicit method routing to resolve embedding ambiguity between the real MySQL store and the mock store.
- **`WithServer`** — Embeddable `testify/suite` struct that wires together the full Android service stack: MySQL datastore, mock Android API client, `httptest.Server`, and a mock Fleet service. Intended to be embedded in integration test suites.
- **`mockService`** — Minimal `fleet.Service` mock that satisfies session/auth lookups and activity recording for HTTP middleware.
- **`runServerForTests`** — Spins up a `gorilla/mux` router with the Android service routes, auth middleware, and error encoding, wrapped in an `httptest.Server` with automatic `t.Cleanup` teardown.
- **`CreateNamedMySQLDS`** — Skips the test if `MYSQL_TEST` env var is absent; otherwise creates a named MySQL datastore via `mysqltest`.
- **`noopNewActivity`** — Drop-in no-op for activity creation in tests that don't assert on activity records.

## Usage Example

```go
type MyAndroidSuite struct {
    tests.WithServer
}

func (s *MyAndroidSuite) SetupSuite() {
    s.WithServer.SetupSuite(s.T(), "android_test_db")
}

func (s *MyAndroidSuite) TearDownSuite() {
    s.WithServer.TearDownSuite()
}

func (s *MyAndroidSuite) TestEnrollment() {
    resp, err := http.Post(
        s.Server.URL+"/api/v1/fleet/android/enroll",
        "application/json",
        strings.NewReader(`{"token":"abc"}`),
    )
    s.Require().NoError(err)
    s.Equal(http.StatusOK, resp.StatusCode)
}

func TestAndroidSuite(t *testing.T) {
    suite.Run(t, new(MyAndroidSuite))
}
```

> **Note:** MySQL integration tests require the `MYSQL_TEST` environment variable to be set; tests are skipped automatically otherwise.
