HTTP test helpers for making authenticated JSON requests against a test Fleet server instance.

## Key Components

- **`DoJSON`** – Sends an HTTP request and unmarshals the JSON response body directly into a target struct; also checks for Fleet-level errors via the `fleet.Errorer` interface.
- **`Do`** – Marshals `params` to JSON, sends the request, and returns the raw `*http.Response` with automatic body cleanup registered via `T().Cleanup`.
- **`DoRaw`** – Sends pre-serialized bytes with a Bearer token authorization header derived from `ts.Token`.
- **`DoRawWithHeaders`** – Lowest-level helper; builds a `fleethttp` client (disabling redirect following for 3xx expected codes) and delegates to `httptest.DoHTTPReq`.
- **`decodeJSON`** – Internal adapter wrapping `json.UnmarshalRead` to satisfy the decoder function signature expected by `httptest.DoHTTPReq`.

## Usage Example

```go
// Inside a test suite that embeds WithServer:
func (ts *MyTestSuite) TestCreateUser() {
    var resp createUserResponse
    ts.DoJSON(
        "POST", "/api/v1/fleet/users",
        createUserRequest{Name: "alice"},
        http.StatusOK,
        &resp,
    )
    require.Equal(ts.T(), "alice", resp.User.Name)
}

// Send raw bytes with custom headers (e.g. unauthenticated request):
rawResp := ts.DoRawWithHeaders(
    "GET", "/api/v1/fleet/config",
    nil, http.StatusUnauthorized,
    map[string]string{"X-Custom-Header": "value"},
)
```
