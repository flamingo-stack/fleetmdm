Defines Android Mobile Device Management (MDM) Pub/Sub types for handling Google Cloud Pub/Sub notifications and device state changes.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `NotificationType` | String type representing categories of Pub/Sub notifications |
| `DeviceState` | String type representing the lifecycle state of an Android device |
| `PubSubMessage` | Struct representing an incoming Pub/Sub message payload |

### `NotificationType` Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `PubSubTest` | `"test"` | Test/ping notification |
| `PubSubEnrollment` | `"ENROLLMENT"` | Device enrollment event |
| `PubSubStatusReport` | `"STATUS_REPORT"` | Device status report update |
| `PubSubCommand` | `"COMMAND"` | MDM command notification |
| `PubSubUsageLogs` | `"USAGE_LOGS"` | Device usage log event |

### `DeviceState` Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `DeviceStateDeleted` | `"DELETED"` | Device has been removed/unenrolled |

### `PubSubMessage`

| Field | Type | Description |
|-------|------|-------------|
| `Attributes` | `map[string]string` | Key-value metadata about the notification (e.g., notification type) |
| `Data` | `string` | Base64-encoded message payload |

## Usage Example

```go
// Parse incoming Pub/Sub notification
msg := android.PubSubMessage{
    Attributes: map[string]string{
        "notificationType": string(android.PubSubEnrollment),
    },
    Data: "base64encodedpayload==",
}

// Route based on notification type
switch android.NotificationType(msg.Attributes["notificationType"]) {
case android.PubSubEnrollment:
    // handle device enrollment
case android.PubSubStatusReport:
    // handle status update
case android.PubSubCommand:
    // handle command response
}
```

For full context, see [`pubsub.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/mdm/mdm_android/pubsub.go) in the repository.
