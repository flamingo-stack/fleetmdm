Defines the Android MDM datastore interface and its associated MySQL table declarations for enterprise and device management.

## Key Components

### `MySQLTables() []string`
Returns the list of MySQL table names used by the Android package (`android_enterprises`, `android_devices`). Used to scope unit test setup to only the relevant tables.

### `Datastore` Interface
Abstracts all database operations for Android MDM functionality:

| Method | Description |
|---|---|
| `CreateEnterprise` | Creates a new Android enterprise record linked to a user |
| `GetEnterpriseByID` | Retrieves enterprise details by primary key |
| `GetEnterpriseBySignupToken` | Looks up an enterprise using its signup token |
| `GetEnterprise` | Fetches the single active enterprise record |
| `UpdateEnterprise` | Updates enterprise details |
| `DeleteAllEnterprises` | Removes all enterprise records |
| `DeleteOtherEnterprises` | Removes all enterprises except the specified ID |
| `CreateDeviceTx` | Creates a device record within an existing transaction |
| `UpdateDeviceTx` | Updates a device record within an existing transaction |

The `*Tx` methods accept a `sqlx.ExtContext` to participate in caller-managed transactions.

## Usage Example

```go
// Implement the interface for MySQL
type mysqlAndroidStore struct {
    db *sqlx.DB
}

func (s *mysqlAndroidStore) CreateEnterprise(ctx context.Context, userID uint) (uint, error) {
    var id uint
    err := s.db.QueryRowContext(ctx,
        `INSERT INTO android_enterprises (user_id) VALUES (?)`, userID,
    ).Scan(&id)
    return id, err
}

// Inject into service layer
func NewAndroidService(ds android.Datastore) *AndroidService {
    return &AndroidService{ds: ds}
}
```
