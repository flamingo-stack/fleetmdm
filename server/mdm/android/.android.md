Defines core Android MDM data structures and constants for managing Android Enterprise devices, policies, and commands within the Fleet MDM platform.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Enterprise` | Represents an Android Enterprise binding with ID and authorization helpers |
| `EnterpriseDetails` | Extended enterprise info including signup credentials and Pub/Sub topic |
| `EnrollmentToken` | Enrollment token, URL, and QR code for device onboarding |
| `Device` | Android device record linked to a Fleet host with policy sync state |
| `AgentManagedConfiguration` | Configuration pushed to the Fleet agent on managed Android devices |
| `MDMAndroidPolicyRequest` | Audit record of AMAPI policy/device patch requests |
| `MDMAndroidCommand` | Lifecycle record for AMAPI commands (Lock, Wipe, Reset Password) |

### Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `DefaultAndroidPolicyID` | `1` | Default policy ID assigned to Android devices |
| `AppStatusAvailable` | `"AVAILABLE"` | App availability status string |
| `MDMAndroidCommandTypeLock` | `"LOCK"` | AMAPI lock command type |
| `MDMAndroidCommandTypeWipe` | `"WIPE"` | AMAPI wipe command type |
| `MDMAndroidCommandTypeResetPassword` | `"RESET_PASSWORD"` | AMAPI password reset command type |
| `MDMAndroidCommandStatusPending` | `"pending"` | Command issued, awaiting device ack |
| `MDMAndroidCommandStatusAcknowledged` | `"acknowledged"` | Device successfully executed command |
| `MDMAndroidCommandStatusError` | `"error"` | AMAPI returned a non-empty error code |

### `Enterprise` Methods

- **`Name() string`** — Returns the fully-qualified AMAPI resource name (`enterprises/<id>`)
- **`IsValid() bool`** — Returns `true` if `EnterpriseID` is non-empty
- **`AuthzType() string`** — Returns `"android_enterprise"` for authorization checks

## Usage Example

```go
// Check enterprise validity before issuing a command
ent := android.Enterprise{ID: 1, EnterpriseID: "LC04ab1234"}
if !ent.IsValid() {
    return fmt.Errorf("enterprise not configured")
}

// Build a command record after calling IssueCommand
cmd := android.MDMAndroidCommand{
    CommandUUID:   uuid.New().String(),
    HostUUID:      host.UUID,
    OperationName: op.Name,
    CommandType:   string(android.MDMAndroidCommandTypeLock),
    Status:        string(android.MDMAndroidCommandStatusPending),
    CreatedAt:     time.Now(),
    UpdatedAt:     time.Now(),
}
```
