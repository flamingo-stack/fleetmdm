A mock package file that uses Go's `go:generate` directive to auto-generate a mock implementation of the `androidmgmt.Client` interface.

## Key Components

- **`go:generate` directive** — Triggers code generation via `mockimpl/impl.go`, producing `client.go` with a mock struct (`*Client`) that satisfies the `androidmgmt.Client` interface.

## Usage Example

```go
// Run from this package directory to regenerate the mock:
// go generate ./...

// Use the generated mock in tests:
import "github.com/flamingo-stack/fleetmdm/mock/androidmgmt"

client := &mock.Client{}
client.On("SomeMethod").Return(nil)
```

## Notes

- The generated output file is `client.go` in the same package directory.
- Re-run `go generate` after any changes to the `androidmgmt.Client` interface to keep the mock in sync.
- Source: [`android.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/android.go)
