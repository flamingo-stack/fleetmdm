Initializes common mock function implementations for the Android MDM client used in testing scenarios.

## Key Components

- **`InitCommonMocks()`** — Sets up default no-op or stub implementations on a `*Client` mock for the following function fields:
  - `EnterpriseDeleteFunc` — returns `nil` error
  - `SignupURLsCreateFunc` — returns an empty `SignupDetails`
  - `EnterprisesCreateFunc` — returns a hardcoded enterprise response with `"enterprises/name"` and `"fleetServerSecret"`
  - `EnterprisesPoliciesPatchFunc` — returns an empty `Policy`
  - `EnterprisesListFunc` — returns a single enterprise named `"enterprises/test-enterprise-id"`
  - `SetAuthenticationSecretFunc` — returns `nil` error

## Usage Example

```go
client := &mock.Client{}
client.InitCommonMocks()

// Override only the behavior you need for a specific test
client.EnterprisesCreateFunc = func(ctx context.Context, req androidmgmt.EnterprisesCreateRequest) (androidmgmt.EnterprisesCreateResponse, error) {
    return androidmgmt.EnterprisesCreateResponse{}, errors.New("create failed")
}
```

Call `InitCommonMocks()` in test setup to get a fully functional mock baseline, then override individual `Func` fields to simulate specific conditions without needing to implement every method from scratch.
