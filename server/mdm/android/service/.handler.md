Registers HTTP routes for the Android Enterprise MDM service, mapping API endpoints to their handler functions using both authenticated and unauthenticated endpointers.

## Key Components

- **`GetRoutes`** – Returns a `HandlerRoutesFunc` that attaches all Android Enterprise API routes to a given `mux.Router`.
- **`attachFleetAPIRoutes`** – Core routing setup; registers user-authenticated and unauthenticated endpoints separately.
- **`apiVersions`** – Returns the supported API versions (`["v1"]`).
- **`pubSubPushPath`** – Constant defining the Pub/Sub push endpoint path (`/api/v1/fleet/android_enterprise/pubsub`).

### Registered Endpoints

| Method | Path | Auth | Handler |
|---|---|---|---|
| `GET` | `/api/_version_/fleet/android_enterprise/signup_url` | User | `enterpriseSignupEndpoint` |
| `GET` | `/api/_version_/fleet/android_enterprise` | User | `getEnterpriseEndpoint` |
| `DELETE` | `/api/_version_/fleet/android_enterprise` | User | `deleteEnterpriseEndpoint` |
| `GET` | `/api/_version_/fleet/android_enterprise/signup_sse` | User | `enterpriseSSE` |
| `GET` | `/api/_version_/fleet/android_enterprise/connect/{token}` | None | `enterpriseSignupCallbackEndpoint` |
| `GET` | `/api/_version_/fleet/android_enterprise/enrollment_token` | None | `enrollmentTokenEndpoint` |
| `POST` | `/api/v1/fleet/android_enterprise/pubsub` | None | `pubSubPushEndpoint` |

## Usage Example

```go
routes := service.GetRoutes(fleetSvc, androidSvc)

// Register routes on an existing mux.Router
routes(router, kithttp.ServerOptions{})
```

The Pub/Sub push endpoint enforces a 10 MiB request body size limit to guard against oversized payloads from Google Cloud Pub/Sub.
