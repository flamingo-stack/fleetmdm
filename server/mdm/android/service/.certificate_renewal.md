Identifies Android certificate templates approaching expiration and marks them for renewal in batch processing.

## Key Components

### `RenewCertificateTemplates`
The sole exported function in this file. It orchestrates the certificate renewal workflow in three steps:
1. Fetches up to 1,000 Android certificate templates due for renewal via `ds.GetAndroidCertificateTemplatesForRenewal`
2. Marks the retrieved templates for renewal via `ds.SetAndroidCertificateTemplatesForRenewal`
3. Logs the count of templates updated

## Usage Example

```go
err := service.RenewCertificateTemplates(ctx, ds, logger)
if err != nil {
    log.Fatal("certificate renewal failed", err)
}
```

## Notes

- **Batch size** is hardcoded to `1000`; only templates expiring on or before `time.Now()` are selected.
- Returns `nil` early (no-op) when no templates are due for renewal, avoiding an unnecessary write call.
- Errors are wrapped with context using `ctxerr.Wrap` for structured error tracing.
- Intended to be called periodically (e.g., by a cron/scheduler) as part of the Fleet MDM service layer.

## Related Interfaces (Fleet Datastore)

| Method | Description |
|---|---|
| `GetAndroidCertificateTemplatesForRenewal` | Queries templates expiring at or before the given time, up to `batchSize` |
| `SetAndroidCertificateTemplatesForRenewal` | Updates the status of the provided templates to trigger renewal |
