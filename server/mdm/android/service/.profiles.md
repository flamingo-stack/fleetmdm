Handles Android MDM profile reconciliation for Fleet devices, including batched profile delivery, certificate-gated withholding, failure tracking, and cursor-based pagination against the Android Management API (AMAPI).

## Key Components

### Functions

| Function | Description |
|---|---|
| `ReconcileProfiles` | Entry point for the profile reconciliation cron job; delegates to `ReconcileProfilesWithClient` with a nil client. |
| `ReconcileProfilesWithClient` | Full reconciliation flow with optional injectable AMAPI client. Reads/writes a pagination cursor in the datastore and drives the `profileReconciler`. |
| `getClientAuthenticationSecret` | Retrieves the Android Fleet server secret from MDM config assets. |

### Types

| Type | Description |
|---|---|
| `profileReconciler` | Internal struct encapsulating datastore, enterprise, AMAPI client, agent config, and logger. Tracks `lastHostUUID` for cursor advancement. |

### `profileReconciler` Methods

| Method | Description |
|---|---|
| `ReconcileProfiles` | Fetches profiles to install/remove, resolves certificate dependencies, dispatches per-host work, and bulk-upserts results. |
| `sendHostProfiles` | Merges ordered profile payloads for a single host, withholds profiles pending certificate verification, enforces a `maxRequestFailures=3` circuit-breaker, and returns bulk upsert payloads. |

## Usage Example

```go
// Invoked by a background cron/worker
err := service.ReconcileProfiles(
    ctx,
    ds,            // fleet.Datastore
    logger,        // *slog.Logger
    licenseKey,    // string
    agentConfig,   // config.AndroidAgentConfig
    500,           // batchSize (0 = unlimited)
)
if err != nil {
    log.Fatal(err)
}

// In tests, inject a mock AMAPI client
err = service.ReconcileProfilesWithClient(ctx, ds, logger, licenseKey, mockClient, agentConfig, 100)
```

## Notes

- Reconciliation is cursor-driven: on a full batch (`hostCount >= batchSize`), the cursor advances to `lastHostUUID` so the next tick continues from where it left off.
- Profiles referencing ONC certificates not yet in `verified` state are **withheld** (kept `pending`) rather than sent.
- After `maxRequestFailures` (3) consecutive Google API errors across all profiles for a host, all profiles are marked `failed` with a descriptive detail message.
