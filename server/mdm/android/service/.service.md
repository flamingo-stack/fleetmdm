This file implements the Android Enterprise MDM service layer for Fleet, handling enterprise signup, callback processing, policy management, and device enrollment/communication via the Android Management API.

## Key Components

| Component | Description |
|---|---|
| `Service` | Core struct holding logger, authorizer, datastores, API client, and configuration |
| `NewService` | Constructor that initializes the service with a proxy or Google API client based on env vars |
| `NewServiceWithClient` | Constructor accepting a pre-built client (useful for testing) |
| `EnterpriseSignup` | Initiates the Android Enterprise signup flow, validates server config, and returns a signup URL |
| `EnterpriseSignupCallback` | Handles the Google OAuth callback, creates the enterprise, and configures PubSub |
| `SignupSSESuccess` / `DefaultSignupSSEInterval` | Constants for Server-Sent Events during signup completion |

## Usage Example

```go
// Initialize the Android MDM service
svc, err := service.NewService(
    ctx,
    logger,
    androidDatastore,
    licenseKey,
    serverPrivateKey,
    fleetDatastore,
    newActivityFunc,
    androidAgentConfig,
)
if err != nil {
    log.Fatal(err)
}

// Trigger enterprise signup (requires authenticated context)
signupDetails, err := svc.EnterpriseSignup(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Signup URL:", signupDetails.Url)

// The callback is handled automatically at:
// POST /api/v1/fleet/android_enterprise/connect/:token?enterpriseToken=...
```

## Notes

- Set `FLEET_DEV_ANDROID_GOOGLE_CLIENT=1` to use the direct Google API client instead of the Fleet proxy client.
- Localhost server URLs are blocked during signup unless `AllowLocalhostServerURL` is set (test use only).
- The embedded `enterpriseCallback.html` is served as the post-signup landing page via `HijackRender`.
