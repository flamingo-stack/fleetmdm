Direct client for Google's Android Management API, intended for development and debugging purposes. It implements the `Client` interface and handles enterprise lifecycle, device management, policy patching, PubSub setup, and enrollment token creation via live Google API calls.

## Key Components

- **`GoogleClient`** — Struct wrapping the `androidmanagement.Service` client with credentials and project configuration. Enabled via `FLEET_DEV_ANDROID_GOOGLE_CLIENT=1` and `FLEET_DEV_ANDROID_GOOGLE_SERVICE_CREDENTIALS` env vars.
- **`NewGoogleClient`** — Constructor that parses service account credentials JSON, initializes the Android Management API service, and returns `nil` if credentials are absent or invalid.
- **`SignupURLsCreate`** — Creates a signup URL for Android enterprise enrollment.
- **`EnterprisesCreate`** — Creates a Google Android enterprise and wires up a new PubSub topic/subscription for device notifications.
- **`createPubSub`** — Internal helper that provisions a PubSub topic and push subscription, including IAM policy grants for `android-cloud-policy@system.gserviceaccount.com`.
- **`generatePolicyFieldMask`** / **`policyFieldMask`** — Reflects over `androidmanagement.Policy` fields to build a field mask that excludes `applications`, ensuring app updates go through a separate patch path.
- **`EnterprisesPoliciesPatch`** — Patches a named policy with optional field mask control (`ExcludeApps` or `OnlyUpdateApps`).
- **`EnterprisesDevicesPatch/Get/Delete/IssueCommand/ListPartial`** — CRUD and command operations on managed devices.
- **`EnterprisesEnrollmentTokensCreate`** — Creates enrollment tokens for device provisioning.
- **`EnterpriseDelete`** — Deletes an enterprise and cleans up its associated PubSub topic and subscription.

## Usage Example

```go
client := androidmgmt.NewGoogleClient(ctx, logger, os.Getenv)
if client == nil {
    log.Fatal("Google client not configured; check env vars")
}

details, err := client.SignupURLsCreate(ctx, "", "https://fleet.example.com/android/callback")
if err != nil {
    log.Fatal(err)
}
fmt.Println("Signup URL:", details.Url)
```

> **Note:** This client is for dev/debug use only. See [`google_client.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/android/androidmgmt/google_client.go) for the full implementation.
