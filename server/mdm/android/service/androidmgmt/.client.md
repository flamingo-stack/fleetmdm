Android Management API client interface definition for interacting with Google's Android Management API (AMAPI), providing enterprise enrollment, device management, and policy operations.

## Key Components

### `Client` Interface
The primary interface exposing all AMAPI operations:

| Method | Description |
|--------|-------------|
| `SignupURLsCreate` | Generates an enterprise signup URL |
| `EnterprisesCreate` | Creates an enterprise with PubSub topic/subscription |
| `EnterprisesPoliciesPatch` | Creates or updates a device policy |
| `EnterprisesDevicesPatch` | Updates a device record |
| `EnterprisesDevicesGet` | Retrieves a device by resource name |
| `EnterprisesDevicesDelete` | Removes an enrolled device |
| `EnterprisesDevicesIssueCommand` | Issues commands (LOCK, WIPE, etc.) to a device |
| `EnterprisesDevicesListPartial` | Paginates device list (100 per page) |
| `EnterprisesEnrollmentTokensCreate` | Creates an enrollment token |
| `EnterpriseDelete` | Permanently deletes an enterprise and all associated data |
| `EnterprisesList` | Lists all accessible enterprises |
| `EnterprisesPoliciesModifyPolicyApplications` | Adds or updates apps in a policy |
| `EnterprisesPoliciesRemovePolicyApplications` | Removes apps from a policy |
| `EnterprisesWebAppsCreate` | Creates a web app within an enterprise |
| `SetAuthenticationSecret` | Sets the authentication secret |

### Supporting Types

- **`EnterprisesCreateRequest`** — Bundles enterprise creation parameters including `EnterpriseToken`, `SignupURLName`, `PubSubPushURL`, and `ServerURL`.
- **`EnterprisesCreateResponse`** — Returns `EnterpriseName`, `FleetServerSecret`, and `TopicName` after successful enterprise creation.

### Helper Functions

- **`IsNotModifiedError(err)`** — Returns `true` if the AMAPI error is an HTTP 304 Not Modified response.
- **`IsBadRequestError(err)`** — Returns `true` if the AMAPI error is an HTTP 400 Bad Request response.

## Usage Example

```go
var client androidmgmt.Client

// Create enterprise signup URL
details, err := client.SignupURLsCreate(ctx, "https://fleet.example.com", "https://fleet.example.com/callback")
if err != nil {
    log.Fatal(err)
}

// Complete enterprise creation
resp, err := client.EnterprisesCreate(ctx, androidmgmt.EnterprisesCreateRequest{
    EnterpriseToken: details.EnterpriseToken,
    SignupURLName:   details.SignupURLName,
    PubSubPushURL:   "https://fleet.example.com/pubsub",
    ServerURL:       "https://fleet.example.com",
})
if err != nil {
    if androidmgmt.IsBadRequestError(err) {
        log.Println("invalid request parameters")
    }
    log.Fatal(err)
}

// Issue a lock command to a device
op, err := client.EnterprisesDevicesIssueCommand(ctx, "enterprises/LC00r8aycu/devices/abc123",
    &androidmanagement.Command{Type: "LOCK"},
)
```
