Routes Google Android Management API calls through the Fleet proxy at `fleetdm.com`, handling authentication, enterprise lifecycle, device management, and policy operations on behalf of Fleet server instances.

## Key Components

### `ProxyClient` struct
The primary client that wraps `androidmanagement.Service` and routes all API calls through the Fleet proxy endpoint (`https://fleetdm.com/api/android/` by default, overridable via `FLEET_DEV_ANDROID_PROXY_ENDPOINT`).

| Field | Purpose |
|---|---|
| `mgmt` | Google Android Management API service pointed at the proxy |
| `licenseKey` | Fleet license key sent during enterprise creation |
| `proxyEndpoint` | Base URL of the proxy server |
| `fleetServerSecret` | Bearer token used for authenticated proxy calls |

### Key Methods

| Method | Description |
|---|---|
| `NewProxyClient` | Constructs the client; redacts `Authorization` headers in logs |
| `SetAuthenticationSecret` | Sets the bearer token for authenticated requests |
| `SignupURLsCreate` | Creates enrollment signup URLs (unauthenticated); returns `ConflictError` on duplicates |
| `EnterprisesCreate` | Custom POST (not a direct Google API mirror) that includes `licenseKey` and `pubSubPushURL` |
| `EnterprisesPoliciesPatch` | Patches a policy with optional field masks (`ExcludeApps`, `OnlyUpdateApps`) |
| `EnterprisesDevices*` | Get, patch, delete, list (paginated), and issue commands to devices |
| `EnterprisesEnrollmentTokensCreate` | Creates enrollment tokens for device onboarding |
| `EnterprisesList` | Lists enterprises filtered by Fleet instance; converts proxy 403s to `googleapi.Error` |

### `PoliciesPatchOpts`
Controls `UpdateMask` behavior when patching policies — `OnlyUpdateApps` restricts updates to the application list; `ExcludeApps` uses the full field mask excluding applications.

## Usage Example

```go
client := NewProxyClient(ctx, logger, "my-license-key", os.Getenv)

_ = client.SetAuthenticationSecret("fleet-server-secret")

// Create an enterprise
resp, err := client.EnterprisesCreate(ctx, EnterprisesCreateRequest{
    ServerURL:       "https://fleet.example.com",
    EnterpriseToken: "token123",
    SignupURLName:   "signupUrls/abc",
    PubSubPushURL:   "https://fleet.example.com/pubsub",
    EnabledNotificationTypes: []string{"ENROLLMENT", "STATUS_REPORT"},
})

// Patch a policy (apps only)
policy, err := client.EnterprisesPoliciesPatch(ctx, "enterprises/123/policies/default",
    &androidmanagement.Policy{...},
    PoliciesPatchOpts{OnlyUpdateApps: true},
)
```
