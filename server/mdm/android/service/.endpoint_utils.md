Provides endpoint wiring utilities for the Android MDM service, including request decoding, response encoding, and endpoint factory functions for authenticated and unauthenticated routes.

## Key Components

- **`encodeResponse`** – Writes JSON responses using `go-json-experiment` with 2-space indentation, delegating to the shared `eu.EncodeCommonResponse` helper.
- **`makeDecoder`** – Returns a `kithttp.DecodeRequestFunc` that unmarshals the request body via `json.UnmarshalRead`, with an optional request body size limit.
- **`handlerFunc`** – Type alias for Android service handler signatures: `func(ctx, request, android.Service) fleet.Errorer`.
- **`androidEndpointer`** – Implements `eu.Endpointer[handlerFunc]`, bridging the generic `CommonEndpointer` framework to the `android.Service` interface.
- **`newUserAuthenticatedEndpointer`** – Constructs a `CommonEndpointer` that enforces user authentication via `auth.AuthenticatedUser` and appends the route template middleware.
- **`newNoAuthEndpointer`** – Constructs a `CommonEndpointer` that allows unauthenticated requests via `auth.UnauthenticatedRequest`.

## Usage Example

```go
// Authenticated endpoints
ep := newUserAuthenticatedEndpointer(fleetSvc, androidSvc, serverOpts, router, "v1")
ep.GET("/api/{version}/fleet/android/devices", listDevicesHandler, listDevicesRequest{})

// Unauthenticated endpoints (e.g., push notification callbacks)
noAuthEp := newNoAuthEndpointer(fleetSvc, androidSvc, serverOpts, router, "v1")
noAuthEp.POST("/api/{version}/fleet/android/push", pushHandler, pushRequest{})
```

## Notes

- The full-slice expression `opts[:len(opts):len(opts)]` in `newUserAuthenticatedEndpointer` prevents unintended mutation of the caller's `opts` backing array before appending `ServerBefore`.
- `androidEndpointer` satisfies the `eu.Endpointer[handlerFunc]` interface, verified at compile time via the blank identifier assertion.
