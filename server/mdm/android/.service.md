Defines the `Service` interface and core HTTP response types for the Android MDM package, providing the contract for enterprise lifecycle management, device enrollment, and policy operations via the Android Management API (AMAPI).

## Key Components

### `Service` Interface

The primary interface defining all Android MDM operations:

| Method Group | Methods |
|---|---|
| Enterprise lifecycle | `EnterpriseSignup`, `EnterpriseSignupCallback`, `GetEnterprise`, `DeleteEnterprise`, `EnterpriseSignupSSE`, `VerifyExistingEnterpriseIfAny` |
| Device enrollment | `CreateEnrollmentToken`, `ProcessPubSubPush`, `UnenrollAndroidHost` |
| Device commands | `LockAndroidHost`, `ClearAndroidPasscode`, `WipeAndroidHost` |
| Policy & app management | `AddAppsToAndroidPolicy`, `RemoveAppsFromAndroidPolicy`, `SetAppsForAndroidPolicy`, `AddFleetAgentToAndroidPolicy`, `BuildAndSendFleetAgentConfig`, `EnableAppReportsOnDefaultPolicy`, `MigrateToPerDevicePolicy`, `PatchDevice`, `PatchPolicy` |
| Web apps | `CreateAndroidWebApp`, `EnterprisesApplications` |

### Response Types

- **`DefaultResponse`** — Base response embedding an `error` field; implements `Error() error` and `StatusCode() int` (go-kit `StatusCoder` interface, preserving custom HTTP status codes from Fleet errors)
- **`GetEnterpriseResponse`** — Wraps `android_enterprise_id` with `DefaultResponse`
- **`EnterpriseSignupResponse`** — Wraps the signup redirect URL with `DefaultResponse`
- **`EnrollmentTokenResponse`** — Embeds `*EnrollmentToken` with `DefaultResponse`

## Usage Example

```go
// Implement the Service interface
type androidService struct { /* ... */ }

func (s *androidService) LockAndroidHost(ctx context.Context, hostID uint) error {
    // Issues AMAPI LOCK command, persists to mdm_android_commands
    return s.issueCommand(ctx, hostID, "LOCK")
}

// Use DefaultResponse's StatusCode for go-kit transport
resp := DefaultResponse{Err: fleet.NewError(http.StatusConflict, "already locked")}
fmt.Println(resp.StatusCode()) // 409
```
