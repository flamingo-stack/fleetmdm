Parses Android ONC (Open Network Configuration) JSON blobs to extract `ClientCertKeyPairAlias` values from WiFi, Ethernet, and VPN network configurations.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `oncConfig` | struct | Top-level ONC document with a list of network configurations |
| `oncNetworkConfiguration` | struct | Single network entry supporting WiFi, Ethernet, and VPN connection types |
| `oncEAPWrapper` | struct | Intermediate wrapper for WiFi/Ethernet that nests cert fields under an `EAP` sub-object |
| `oncCertKeyHolder` | struct | Holds `ClientCertType` and `ClientCertKeyPairAlias` fields per the ONC spec |
| `extractAlias` | func | Returns the alias string only when `ClientCertType == "KeyPairAlias"`; empty string otherwise |
| `ExtractCertAliasesFromONC` | func | Parses a raw ONC JSON blob and returns all valid cert key-pair aliases |
| `ExtractCertAliasesFromProfileJSON` | func | Parses a full Android profile JSON and delegates to `ExtractCertAliasesFromONC` if an `openNetworkConfiguration` field is present |

## Usage Example

```go
// Extract aliases directly from an ONC blob
oncJSON := json.RawMessage(`{
  "NetworkConfigurations": [{
    "WiFi": {
      "EAP": {
        "ClientCertType": "KeyPairAlias",
        "ClientCertKeyPairAlias": "my-wifi-cert"
      }
    }
  }]
}`)

aliases, err := android.ExtractCertAliasesFromONC(oncJSON)
// aliases => ["my-wifi-cert"]

// Or extract from a raw Android profile payload
profileJSON := json.RawMessage(`{
  "openNetworkConfiguration": { ... }
}`)

aliases, err = android.ExtractCertAliasesFromProfileJSON(profileJSON)
```

> **Note:** Only aliases where `ClientCertType` is exactly `"KeyPairAlias"` are returned. All other `ClientCertType` values are silently skipped per the ONC spec.
