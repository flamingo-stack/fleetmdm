Implements the platform-neutral core of MDM profile/declaration reconciliation by providing a shared dispatcher and label-gate handlers that determine whether a given entity (profile or DDM declaration) applies to a specific host.

## Key Components

| Export | Signature | Description |
|---|---|---|
| `EntityAppliesToHost` | `(e MDMLabeledEntity, hostEffectiveTeamID uint, hostLabelUpdatedAt time.Time, hostLabels map[uint]struct{}) bool` | Top-level dispatcher: enforces team scope, then delegates to include/exclude handlers |
| `HandlerIncludeAll` | `(labels []MDMProfileLabelRef, hostLabels map[uint]struct{}) bool` | Returns `true` only if the host is a member of **every** non-broken include label |
| `HandlerIncludeAny` | `(labels []MDMProfileLabelRef, hostLabels map[uint]struct{}) bool` | Returns `true` if the host is a member of **at least one** valid include label |
| `HandlerExcludeAny` | `(labels []MDMProfileLabelRef, hostLabelUpdatedAt time.Time, hostLabels map[uint]struct{}) bool` | Returns `true` (exclude the host) if any exclude label matches, is broken, or is a dynamic label created after the host's last label scan |

## Usage Example

```go
// Determine whether a profile should be installed on a host.
hostLabels := map[uint]struct{}{42: {}, 99: {}}
applies := reconcile.EntityAppliesToHost(
    profile,                // fleet.MDMLabeledEntity
    host.TeamID,            // normalized: nil -> 0
    host.LabelUpdatedAt,    // time of last label scan
    hostLabels,
)
if applies {
    // enqueue profile installation
}
```

## Broken-label & Timing Safety Rules

- **Include-all:** any `nil` `LabelID` (broken label) returns `false` — the entity is withheld.
- **Include-any:** broken labels are skipped; the entity is withheld only if no valid label matches.
- **Exclude-any:** broken labels or dynamic labels created *after* `hostLabelUpdatedAt` cause the entity to be withheld (can't confirm exclusion is safe). Manual and host-vital labels bypass the timing check.
