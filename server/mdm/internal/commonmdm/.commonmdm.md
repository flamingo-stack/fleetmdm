Provides a URL resolution utility for MDM (Mobile Device Management) server endpoints, combining a base server URL with a relative path.

## Key Components

- **`ResolveURL(serverURL, relPath string, cleanQuery bool) (string, error)`** — Parses a base server URL, appends a relative path using `path.Join`, and optionally strips the query string. Returns the resolved URL string or an error if parsing fails.

## Usage Example

```go
// Resolve a relative MDM endpoint path against a Fleet server URL
resolved, err := commonmdm.ResolveURL("https://fleet.example.com/mdm?token=abc", "/enroll", true)
if err != nil {
    log.Fatal(err)
}
// resolved => "https://fleet.example.com/mdm/enroll"

// Preserve the existing query string
resolved, err = commonmdm.ResolveURL("https://fleet.example.com?token=abc", "/api/v1/mdm", false)
// resolved => "https://fleet.example.com/api/v1/mdm?token=abc"
```

## Notes

- Uses `path.Join` (not `filepath.Join`) to ensure forward-slash semantics appropriate for URLs.
- When `cleanQuery` is `true`, any existing query parameters on the server URL are dropped from the result.
- Parsing errors from a malformed `serverURL` are propagated directly to the caller.
