Orchestrates Apple MDM commands for Fleet-managed devices, handling profile installation/removal, device lock/unlock/erase, enterprise application installation, and push notification delivery to enrolled hosts.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `MDMAppleCommander` | struct | Core commander decoupled from `fleet.Service`; holds MDM storage and push notifier |
| `NewMDMAppleCommander` | func | Constructor accepting `MDMAppleStore` and `nanomdm_push.Pusher` |
| `InstallProfile` | method | Signs, base64-encodes, and enqueues an `InstallProfile` MDM command |
| `SignAndEncodeInstallProfile` | method | Signs a mobileconfig payload and returns a raw plist XML string |
| `RemoveProfile` | method | Enqueues a `RemoveProfile` command by profile identifier |
| `DeviceLock` | method | Enqueues a `DeviceLock` command with a generated 6-digit PIN; handles concurrent-lock race conditions |
| `EnableLostMode` / `DisableLostMode` | methods | Toggle Lost Mode on supervised Apple devices |
| `EraseDevice` | method | Enqueues an `EraseDevice` (wipe) command with a random 6-digit PIN |
| `InstallEnterpriseApplication` | method | Enqueues install via a remote manifest URL |
| `InstallEnterpriseApplicationWithEmbeddedManifest` | method | Enqueues install with an inline `appmanifest.Manifest` |
| `AccountConfiguration` | method | Sends `AccountConfiguration` command supporting SSO and/or admin account setup |
| `commandPayload` | struct | Generic plist-serializable wrapper for any MDM command |
| `SSOAccountConfig` / `AdminAccountConfig` | structs | Typed config for `AccountConfiguration` payloads |

## Usage Example

```go
storage := // fleet.MDMAppleStore implementation
pusher  := // nanomdm_push.Pusher implementation

commander := apple_mdm.NewMDMAppleCommander(storage, pusher)

// Install a configuration profile on two hosts
profile := mobileconfig.Mobileconfig(profileBytes)
err := commander.InstallProfile(ctx, []string{"host-uuid-1", "host-uuid-2"}, profile, cmdUUID, "My Profile")

// Lock a device and retrieve the unlock PIN
pin, err := commander.DeviceLock(ctx, host, cmdUUID)

// Wipe a device
err = commander.EraseDevice(ctx, host, cmdUUID)
```

## Notes

- Authentication and permission checks are intentionally **not** handled here — callers are responsible.
- `DeviceLock` is race-condition-safe: if a concurrent request already enqueued a lock, it returns the existing PIN rather than creating a duplicate.
- All commands are serialized as Apple plist XML before being stored and pushed via `enqueueAndNotify`.
