Provides utilities for creating and encoding Apple MDM app manifest files using SHA256 checksums instead of MD5, for use with `InstallApplication` MDM commands.

## Key Components

- **`Manifest`** — Type alias of `appmanifest.Manifest`; adds a `Plist()` method that encodes the manifest to an indented plist byte slice.
- **`New(file, url)`** — Reads an `io.Reader`, computes its SHA256 hash, and returns a `*Manifest`.
- **`NewFromSha(sha, url)`** — Constructs a `*Manifest` directly from a precomputed SHA256 digest and a download URL.
- **`NewPlist(file, url)`** — Convenience wrapper that calls `New` then `Plist()`, returning the encoded plist in one step.

## Usage Example

```go
// Build a manifest plist from a file reader and a CDN URL
f, err := os.Open("MyApp.pkg")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

plistBytes, err := appmanifest.NewPlist(f, "https://cdn.example.com/MyApp.pkg")
if err != nil {
    log.Fatal(err)
}

// plistBytes is ready to send in an MDM InstallApplication command
fmt.Println(string(plistBytes))

// Or build incrementally when the SHA256 is already known
manifest := appmanifest.NewFromSha(knownSHA256Bytes, "https://cdn.example.com/MyApp.pkg")
plistBytes, err = manifest.Plist()
```

## Notes

- Intentionally overrides the upstream `micromdm/mdm/appmanifest` package's MD5-based hashing with SHA256 (`crypto/sha256`), improving security for package integrity verification.
- The asset `Kind` is always `"software-package"` and `SHA256Size` is set to `sha256.Size` (32 bytes).
