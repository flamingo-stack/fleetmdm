Handles reconciliation logic for Apple MDM profile and declaration delivery, computing install/remove deltas and executing them against enrolled hosts.

## Key Components

### Constants
- `HoursToWaitForUserEnrollmentAfterDeviceEnrollment` — Grace period (2 hours) before failing user-scoped profile delivery when no user channel enrollment exists.

### Functions

| Function | Description |
|---|---|
| `EntityAppliesToHost` | Top-level dispatcher; applies Apple platform gate then delegates to the shared `reconcile` package for team/label filtering. |
| `IsEligiblePlatform` | Returns `true` for `darwin`, `ios`, and `ipados` platforms. |
| `ComputeReconcileDeltas` | Diffs desired vs. current profile state per host, returning `toInstall` and `toRemove` slices. |
| `IsBrokenProfile` | Checks whether a profile references a deleted label (skips removal for legacy parity). |
| `IsBrokenDeclaration` | DDM equivalent of `IsBrokenProfile`. |
| `ComputeDeclarationDeltas` | DDM equivalent of `ComputeReconcileDeltas`; returns changed host UUIDs and declaration rows to write. |
| `ExecuteReconcileBatch` | Runs the post-listing pipeline: resolves user enrollments, intersects install/remove sets, prefetches CA-classified profiles, and enqueues MDM commands. |

## Usage Example

```go
// Compute which profiles need to be installed or removed
toInstall, toRemove := apple_mdm.ComputeReconcileDeltas(
    hosts,
    hostLabels,
    currentByHost,
    profilesByTeam,
    profilesWithBrokenLabels,
)

// Execute the reconcile batch (cron path — discard returned command UUIDs)
_, err := apple_mdm.ExecuteReconcileBatch(
    ctx,
    ds,
    commander,
    redisKV,
    logger,
    appConfig,
    certProfilesLimit,
    toInstall,
    toRemove,
)
```

> **Note:** Pass `redisKeyValue = nil` in per-host enrollment paths to bypass the "host being set up" Redis check and force immediate profile installation.
