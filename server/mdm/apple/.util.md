Utility functions for Apple MDM operations, providing cryptographic primitives, error classification helpers, and enrollment URL construction used across the MDM subsystem.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `newPrivateKey` | func | Generates a 2048-bit RSA private key (Apple-required size) |
| `EncodeCertRequestPEM` | func | PEM-encodes an x509 certificate signing request |
| `GenerateRandomPin` | func | Generates a cryptographically random N-digit PIN using SHA-256 |
| `FmtErrorChain` | func | Formats an MDM v1 error chain into a human-readable string |
| `IsRecoveryLockPasswordMismatchError` | func | Detects recovery lock password mismatch errors in an error chain |
| `IsProfileNotFoundError` | func | Detects "profile not found" errors, indicating desired removal state |
| `IsAppAlreadyInstalledError` | func | Detects app-already-installed errors for BYOD enrollment flows |
| `FmtDDMError` | func | Formats a DDM (Declarative Device Management) error message |
| `EnrollURL` | func | Constructs a full MDM enrollment URL with a token query parameter |
| `IsLessThanVersion` | func | Semver comparison returning true if `current` is less than `target` |
| `GenerateManagedAccountPassword` | func | Generates a random password in recovery lock format (e.g. `5ADZ-HTZ8-LJJ4-B2F8-JWH3-YPBT`) |
| `GenerateSaltedSHA512PBKDF2Hash` | func | Produces a plist-encoded SALTED-SHA512-PBKDF2 password hash for `AutoSetupAdminAccountItem` |

## Usage Example

```go
// Generate a 6-digit PIN for an MDM operation
pin, err := apple_mdm.GenerateRandomPin(6)
if err != nil {
    log.Fatal(err)
}
// pin => "047382"

// Build the enrollment URL for a token
enrollURL, err := apple_mdm.EnrollURL("my-token", appConfig)
// enrollURL => "https://example.com/mdm/enroll?token=my-token"

// Classify an MDM command error response
if apple_mdm.IsProfileNotFoundError(errChain) {
    // Profile already absent — treat as success
}

// Generate a managed account password and its PBKDF2 hash
password := apple_mdm.GenerateManagedAccountPassword()
// password => "5ADZ-HTZ8-LJJ4-B2F8-JWH3-YPBT"

hashPlist, err := apple_mdm.GenerateSaltedSHA512PBKDF2Hash(password)
// hashPlist is a plist-encoded SALTED-SHA512-PBKDF2 blob for AccountConfiguration
```

## Notes

- RSA key size is fixed at **2048 bits** — Apple rejects CSRs with any other size.
- `IsAppAlreadyInstalledError` uses both a known error code (`MCMDMErrorDomain 12042`) and a substring fallback on the description, as Apple's numeric codes have shifted across iOS versions.
- `GenerateSaltedSHA512PBKDF2Hash` uses 32-byte salt, 128-byte derived key, and 40,000 PBKDF2 iterations as required by Apple's `passwordHash` specification.
