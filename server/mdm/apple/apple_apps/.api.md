HTTP client and configuration layer for fetching Apple App Store metadata via Apple's VPP (Volume Purchase Program) enterprise catalog API, with support for region-aware storefronts, bearer token authentication, and automatic retry/rate-limit handling.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Metadata` | struct | Top-level App Store app record returned by the metadata API |
| `Attributes` | struct | App name, per-platform data, and supported device families |
| `PlatformData` | struct | Bundle ID, version info, and artwork for a specific platform |
| `Config` | struct | Holds a region-aware base URL factory and an authenticator function |
| `GetMetadata` | func | Fetches metadata for a list of Adam IDs from a given storefront region |
| `ToVPPApps` | func | Converts a `Metadata` record into a map of `fleet.VPPApp` by platform |
| `Configure` | func | Builds a `Config` from a bearer token or license-key-based authenticator |
| `StubbedConfig` | func | Returns a no-auth `Config` for testing/dev use |
| `TestConfigWithBaseURLForRegion` | func | Test-only constructor for custom region-aware base URL injection |

## Usage Example

```go
// Production setup using Fleet license key authentication
config := apple_apps.Configure(ctx, dataStore, "your-license-key", "")

adamIDs := []string{"497799835", "409183694"}
metadata, err := apple_apps.GetMetadata(adamIDs, "us", vppToken, config)
if err != nil {
    log.Fatal(err)
}

for id, meta := range metadata {
    apps := apple_apps.ToVPPApps(meta)
    for platform, app := range apps {
        fmt.Printf("ID=%s platform=%s bundle=%s version=%s\n",
            id, platform, app.BundleIdentifier, app.LatestVersion)
    }
}

// Direct bearer token (bypasses Fleet proxy)
config = apple_apps.Configure(ctx, dataStore, "", "my-bearer-token")
```

> **Region handling:** Pass a lowercase [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) country code (e.g. `"us"`, `"de"`) matching the VPP token's storefront. An empty string falls back to `"us"`.
