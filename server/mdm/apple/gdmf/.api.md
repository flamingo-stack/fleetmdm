HTTP client and data structures for querying the Apple Software Lookup Service (GDMF) at `https://gdmf.apple.com/v2/pmv` to retrieve OS update asset metadata for macOS and iOS devices.

## Key Components

- **`Asset`** — Metadata for a single OS release (version, build, posting/expiration dates, supported devices).
- **`AssetSets`** — Groups `Asset` slices by platform (`iOS`, `macOS`).
- **`AssetMetadata`** — Top-level response struct containing public and internal `AssetSets`.
- **`IsSupportedMacOSVersion`** — Checks if a macOS version string exists in the asset metadata; respects the `excludeNonPublicAssetSets` flag for DEP enrollment contexts.
- **`IsSupportedIOSVersion`** — Same check for iOS, with optional filtering by device prefix (e.g. `"iPhone"`, `"iPad"`).
- **`GetLatestOSVersion`** — Resolves the latest public OS version for a given MDM device by matching `Product` or `SoftwareUpdateDeviceID` against supported devices.
- **`GetAssetMetadata`** — Fetches and decodes the GDMF JSON payload via an Apple Root CA-pinned TLS client with retry logic.
- **`doWithRetry`** — Wraps HTTP requests with up to 3 retries using constant backoff, including `Retry-After` header handling for HTTP 429 responses.

## Usage Example

```go
// Fetch current asset metadata
metadata, err := gdmf.GetAssetMetadata()
if err != nil {
    log.Fatal(err)
}

// Check if a macOS version is publicly available
supported := metadata.IsSupportedMacOSVersion("14.6.1", true)

// Check if an iOS version is available for iPad devices
supported = metadata.IsSupportedIOSVersion("17.6", "iPad", true)

// Get the latest OS version for a specific MDM device
asset, err := gdmf.GetLatestOSVersion(fleet.MDMAppleMachineInfo{
    Product:               "iPhone14,3",
    SoftwareUpdateDeviceID: "iPhone14,3",
})
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Latest version: %s (%s)\n", asset.ProductVersion, asset.Build)
```

> The base URL can be overridden in dev mode via the `FLEET_DEV_GDMF_URL` environment variable.
