Parses and verifies Apple MDM device information from the `x-apple-aspen-deviceinfo` HTTP header, which carries PKCS7-signed device metadata during DEP enrollment flows.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `DeviceInfoHeader` | `const` | The `x-apple-aspen-deviceinfo` header name constant |
| `ParseDeviceinfo` | `func` | Decodes a base64 string from the device-info header and returns `*fleet.MDMAppleMachineInfo` |
| `ParseMachineInfoFromPKCS7` | `func` | Parses raw PKCS7 bytes into `*fleet.MDMAppleMachineInfo`, with optional signature verification |
| `verifyPKCS7SHA1RSA` | `func` | Manually performs SHA1WithRSA verification (deprecated in Go 1.18) and optionally walks the cert chain to Apple's Root CA |
| `VerifyFromAppleIphoneDeviceCA` | `func` | Verifies that a given `*x509.Certificate` was signed by Apple's iPhone Device CA; supports SHA1 and SHA256 |
| `appleIphoneDeviceCACert` | `var` | Embedded Apple iPhone Device CA certificate (DER-encoded, loaded via `//go:embed`) |

## Usage Example

```go
// Parse and verify a device-info header value from an enrollment request
headerVal := r.Header.Get(apple_mdm.DeviceInfoHeader)

// verify=true checks the signature against Apple's Root CA
machineInfo, err := apple_mdm.ParseDeviceinfo(headerVal, true)
if err != nil {
    log.Printf("failed to parse device info: %v", err)
    return
}

log.Printf("serial: %s, UDID: %s", machineInfo.SerialNumber, machineInfo.UDID)

// Separately verify a client certificate was issued by Apple's iPhone Device CA
if err := apple_mdm.VerifyFromAppleIphoneDeviceCA(clientCert); err != nil {
    log.Printf("certificate not from Apple iPhone Device CA: %v", err)
}
```

> **Security note:** The `x-apple-aspen-deviceinfo` header is signed by Apple PKI but should **not** be used for device attestation or security-sensitive decisions. See the [architecture notes](https://github.com/korylprince/dep-webview-oidc/blob/2dd846a54fed04c16dd227b8c6c31665b4d0ebd8/docs/Architecture.md#x-apple-aspen-deviceinfo-header) for details. Certificate validity windows are intentionally not checked because Apple's signing cert is expired by design.
