Handles Apple Business Manager (ABM) token metadata retrieval by querying the DEP API and populating token fields such as organization name, Apple ID, and renewal date.

## Key Components

### Functions

- **`SetABMTokenMetadata`** — Decrypts a stored ABM token by organization name, then delegates to `SetDecryptedABMTokenMetadata` to fetch and populate metadata.
- **`SetDecryptedABMTokenMetadata`** — Core logic: builds a DEP client, calls the Apple `/account` endpoint, and sets `OrganizationName`, `AppleID`, and `RenewAt` on the provided `*fleet.ABMToken`. Does **not** persist changes to the database.

### Constants

- **`UnsavedABMTokenOrgName`** (`"new_abm_token"`) — Placeholder org name used when processing a newly uploaded or migrated token that has not yet been saved to the datastore.

## Usage Example

```go
err := apple_mdm.SetABMTokenMetadata(
    ctx,
    abmToken,       // *fleet.ABMToken to populate
    depStorage,     // storage.AllDEPStorage
    ds,             // fleet.Datastore
    logger,         // *slog.Logger
    false,          // renewal — set true when replacing an existing token
)
if err != nil {
    // Handle invalid cert/token (400) or other DEP API errors
}

// Fields now populated (not yet saved):
fmt.Println(abmToken.OrganizationName) // e.g. "Acme Corp"
fmt.Println(abmToken.AppleID)          // e.g. "admin@acme.com"
fmt.Println(abmToken.RenewAt)          // token expiry (UTC)
```

## Notes

- When `renewal` is `true`, the new decrypted token is injected into the context so the DEP client uses it rather than the stored one.
- A `401 Unauthorized` from Apple's DEP API is surfaced as a `fleet.BadRequestError` with a human-readable remediation message.
- Falls back to `FacilitatorID` if `AdminID` is absent (compatibility with older Apple DEP API versions).
