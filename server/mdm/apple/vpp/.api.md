This file implements the Apple VPP (Volume Purchase Program) API client for Fleet MDM, providing functions to manage app licenses — including fetching VPP configuration, associating/disassociating assets, and registering VPP users.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Asset` | struct | Represents a purchasable product in the Apple store with license count |
| `ErrorResponse` | struct | Apple VPP API error payload; implements the `error` interface |
| `IsMaxDevicesPerUserError` | func | Detects Apple's per-user device cap error (code 9622 or message substring) |
| `ClientConfig` | struct | Subset of Apple's `/client/config` response (location name + country code) |
| `GetConfig` | func | Fetches and validates a VPP token; retries up to 3 times with backoff |
| `AssociateAssetsRequest` | struct | Request body for assigning app licenses to devices or users |
| `AssociateAssets` | func | Associates VPP app licenses with serial numbers or client user IDs |
| `DisassociateAssetsRequest` | type alias | Same shape as `AssociateAssetsRequest`; used for license release |
| `DisassociateAssets` | func | Releases previously reserved licenses back to the VPP location |
| `RegisterUserResponse` | struct | Apple v1 synchronous register-user response with full user record |
| `RegisterUser` | func | Registers a VPP user via Apple's legacy v1 endpoint for immediate confirmation |

## Usage Example

```go
// Validate and fetch VPP token config
cfg, err := vpp.GetConfig(ctx, vppToken)
if err != nil {
    log.Fatal(err)
}
fmt.Println(cfg.LocationName, cfg.CountryCode) // e.g. "Acme Corp" "us"

// Associate an app license to a device
eventID, err := vpp.AssociateAssets(ctx, vppToken, &vpp.AssociateAssetsRequest{
    Assets:        []vpp.Asset{{AdamID: "12345678", PricingParam: "STDQ"}},
    SerialNumbers: []string{"C02XL0TAJHD5"},
})
if err != nil {
    if vpp.IsMaxDevicesPerUserError(err) {
        log.Println("device cap reached for this user")
    }
    log.Fatal(err)
}

// Release the license if install does not proceed
_, err = vpp.DisassociateAssets(vppToken, &vpp.DisassociateAssetsRequest{
    Assets:        []vpp.Asset{{AdamID: "12345678", PricingParam: "STDQ"}},
    SerialNumbers: []string{"C02XL0TAJHD5"},
})
```

> **Note:** `AssociateAssetsRequest.Validate()` enforces Apple's contract that `SerialNumbers` and `ClientUserIds` are mutually exclusive — passing both returns an error.
