Orchestrates metadata refresh for VPP (Volume Purchase Program) apps stored in Fleet, updating `LatestVersion`, `Name`, and `IconURL` fields by querying Apple's storefront API through available VPP tokens.

## Key Components

- **`RefreshVersions(ctx, ds, vppAppsConfig)`** — Top-level function that drives the full refresh lifecycle: token selection, Apple API calls, and datastore updates.

### Internal Types

| Type | Purpose |
|---|---|
| `appKey` | Composite key of `(adamID, platform)` for per-row token picking |
| `ownedResult` | Cached result of `GetAssets` per token (owned set or error) |
| `pick` | Selected token for a given `appKey` |
| `bundle` | Groups `appKey` entries sharing a token to batch Apple API calls |

## Token Selection Strategy

1. **Anchored country preferred** — Each `(adamID, platform)` row has a stored `CountryCode`; tokens matching it are tried first.
2. **Fallback with re-anchor** — If no anchored-country token owns the app, any other token that owns it is used and the row's country is updated (`UpdateVPPAppCountryCode`) to avoid repeated fallbacks.
3. **Error-safe skipping** — If an anchored-country token errors, the row is skipped entirely to prevent incorrect re-anchoring.

## Usage Example

```go
err := vpp.RefreshVersions(ctx, ds, vppAppsConfig)
if err != nil {
    log.Errorf("VPP version refresh failed: %v", err)
}
```

Called periodically (e.g., via a cron job) to keep VPP app metadata current. Errors from individual storefronts are collected and joined, so a single flaky Apple storefront does not block updates from healthy ones.
