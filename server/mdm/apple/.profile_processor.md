Orchestrates preprocessing and concurrent enqueueing of Apple MDM configuration profiles, including Fleet variable substitution and certificate authority integration for install and remove operations.

## Key Components

### `EnqueueResult`
Struct capturing the outcome of profile enqueue operations:
- `FailedCmdUUIDs` — maps failed command UUIDs to their errors
- `SucceededCmdUUIDs` — list of successfully enqueued command UUIDs

### `ProcessAndEnqueueProfiles`
Main entry point that:
1. Fetches profile contents if not provided
2. Loads grouped certificate authorities
3. Calls `preprocessProfileContents` to substitute Fleet variables per-host
4. Identifies profiles containing secret variables
5. Concurrently dispatches install/remove MDM commands via goroutines, collecting results

### `preprocessProfileContents`
Iterates install targets and replaces `$FLEET_VAR_*` placeholders in profile XML with host-specific values. Supports:
- **NDES SCEP** — challenge and proxy URL variables
- **DigiCert** — password and data variables
- **Custom SCEP** — challenge and proxy URL variables
- **Smallstep SCEP** — challenge and proxy URL variables
- **Host identity** — UUID, hardware serial, platform, IDP email/username/groups/department

## Usage Example

```go
result, err := apple_mdm.ProcessAndEnqueueProfiles(
    ctx,
    ds,
    logger,
    appConfig,
    commander,
    installTargets,
    removeTargets,
    hostProfilesToInstallMap,
    userEnrollmentsToHostUUIDsMap,
    nil, // profileContents fetched automatically
)
if err != nil {
    log.Fatal(err)
}

for cmdUUID, cmdErr := range result.FailedCmdUUIDs {
    log.Printf("failed: %s — %v", cmdUUID, cmdErr)
}
log.Printf("succeeded: %d commands", len(result.SucceededCmdUUIDs))
```
