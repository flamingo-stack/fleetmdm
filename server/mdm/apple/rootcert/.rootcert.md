Embeds and exposes Apple's Root CA certificate as a parsed `*x509.Certificate` for use in certificate chain validation workflows.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `AppleRootCA` | `*x509.Certificate` | Package-level parsed Apple Root CA certificate, embedded at compile time |
| `NewAppleCert` | `func([]byte) *x509.Certificate` | Parses a DER-encoded certificate; panics on invalid input |
| `appleRootCert` | `[]byte` | Embedded binary of `AppleIncRootCertificate.cer` (sourced from `apple.com/appleca`) |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/ee/mdm/apple/rootcert"

// Use the pre-parsed Apple Root CA directly
roots := x509.NewCertPool()
roots.AddCert(rootcert.AppleRootCA)

opts := x509.VerifyOptions{
    Roots: roots,
}
if _, err := deviceCert.Verify(opts); err != nil {
    return fmt.Errorf("certificate chain validation failed: %w", err)
}

// Or parse a custom DER-encoded certificate
customCert := rootcert.NewAppleCert(rawDERBytes)
```

## Notes

- `NewAppleCert` **panics** on parse failure — intended for initialization-time use only (package-level vars, `init()`). Do not call with untrusted or user-supplied bytes at runtime.
- The embedded `.cer` file is compiled into the binary via `//go:embed`, eliminating runtime file I/O or external fetches.
- Source certificate: [`AppleIncRootCertificate.cer`](https://www.apple.com/appleca/AppleIncRootCertificate.cer)
