Provides utilities and service types for Apple MDM (Mobile Device Management) operations, including DEP enrollment profile management, URL resolution, SCEP handling, and integration with Apple Business Manager (ABM).

## Key Components

### Constants

| Constant | Description |
|---|---|
| `SCEPPath` | HTTP path for the SCEP service (`/mdm/apple/scep`) |
| `MDMPath` | HTTP path for the core MDM service (`/mdm/apple/mdm`) |
| `EnrollPath` | HTTP path serving mobile enrollment profiles |
| `DEPSyncLimit` | Max devices synced per DEP cycle (200) |
| `FleetPayloadIdentifier` | MDM enrollment profile payload identifier |
| `DeclarationTypeSoftwareUpdate` | DDM software update declaration type |

### `DEPService`

Core service struct encapsulating DEP (Device Enrollment Program) operations. Not authentication-aware — callers must enforce authorization.

| Method | Description |
|---|---|
| `GetDefaultProfile()` | Returns a default supervised, non-removable `godep.Profile` |
| `CreateDefaultAutomaticProfile(ctx)` | Persists the default DEP enrollment profile to the datastore |
| `RegisterProfileWithAppleDEPServer(...)` | Registers enrollment profile with Apple DEP API across all relevant ABM tokens |
| `ValidateSetupAssistant(...)` | Validates a setup assistant profile via Apple's `DefineProfile` API |

### URL Resolvers

```go
ResolveAppleMDMURL(serverURL string) (string, error)
ResolveAppleEnrollMDMURL(serverURL string) (string, error)
ResolveAppleSCEPURL(serverURL string) (string, error)
ResolveAppleACMEDirectoryURL(serverURL, acmeIdent string) (string, error)
```

## Usage Example

```go
depService := &DEPService{
    ds:         datastore,
    depStorage: depStorage,
    logger:     logger,
}

// Register DEP enrollment profile for a team
profileUUID, modTime, err := depService.RegisterProfileWithAppleDEPServer(
    ctx,
    team,
    setupAssistant,
    "My ABM Org",
)
if err != nil {
    return err
}

// Resolve SCEP URL for enrollment profile generation
scepURL, err := ResolveAppleSCEPURL("https://fleet.example.com")
```

> **Note:** `DEPService` performs no authentication. Ensure callers enforce proper authorization before invoking methods.
