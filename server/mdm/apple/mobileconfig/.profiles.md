Defines Apple `.mobileconfig` plist XML templates used by Fleet MDM to configure the fleetd agent, install CA root certificates, and initiate OTA (over-the-air) enrollment on Apple devices.

## Key Components

| Export | Type | Description |
|---|---|---|
| `FleetdProfileOptions` | struct | Template data for fleetd agent configuration (enroll secret, server URL, payload metadata) |
| `FleetdProfileTemplate` | `*template.Template` | Generates a `.mobileconfig` profile that sets orbit's `EnrollSecret` and `FleetURL`; delivered to hosts during DEP enrollment |
| `FleetCARootTemplateOptions` | struct | Template data for CA root certificate installation (certificate PEM, payload name/identifier) |
| `FleetCARootTemplate` | `*template.Template` | Generates a `com.apple.security.root` profile to install a Fleet CA certificate on managed devices |
| `OTAMobileConfigTemplate` | `*template.Template` | Generates an OTA `Profile Service` plist that collects device attributes (UDID, version, product, serial) during enrollment |
| `funcMap` | `map[string]any` | Template helper registering `XMLEscapeString` as the `xml` function for safe XML interpolation |

## Usage Example

```go
import (
    "bytes"
    "github.com/flamingo-stack/fleetmdm/mobileconfig"
)

// Generate a fleetd agent configuration profile
var buf bytes.Buffer
err := mobileconfig.FleetdProfileTemplate.Execute(&buf, mobileconfig.FleetdProfileOptions{
    PayloadType:  "com.fleetdm.orbit",
    PayloadName:  "Fleetd Configuration",
    EnrollSecret: "s3cr3t",
    ServerURL:    "https://fleet.example.com",
})

// Generate a CA root certificate profile
var caBuf bytes.Buffer
err = mobileconfig.FleetCARootTemplate.Execute(&caBuf, mobileconfig.FleetCARootTemplateOptions{
    PayloadName:       "Fleet CA",
    PayloadIdentifier: "com.fleetdm.fleet.ca",
    Certificate:       base64EncodedPEM,
})
```

> **Note:** All templates use `missingkey=error`, so every field in the options struct must be populated before execution. String values interpolated into XML contexts should pass through the `xml` template function to prevent injection.
