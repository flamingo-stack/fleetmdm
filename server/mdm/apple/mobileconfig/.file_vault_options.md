Parses and validates Apple FileVault (FDE) configuration profiles to detect restricted `FDEFileVaultOptions` payloads managed exclusively by Fleet.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `FDEFileVaultOptionsProfileContent` | struct | Top-level plist profile wrapper holding a slice of payload entries |
| `FDEFileVaultOptionsPayload` | struct | Individual payload entry with `PayloadType` and optional `DestroyFVKeyOnStandby` flag |
| `ContainsFDEFileVaultOptionsPayload` | func | Unmarshals a raw plist and returns `true` if any payload matches Fleet's custom settings type with a `DestroyFVKeyOnStandby` field set |

## Usage Example

```go
raw, _ := os.ReadFile("profile.mobileconfig")

found, err := mobileconfig.ContainsFDEFileVaultOptionsPayload(raw)
if err != nil {
    log.Fatalf("failed to parse profile: %v", err)
}

if found {
    // Reject upload — Fleet manages FileVault exclusively
    return errors.New("profile contains restricted FDEFileVaultOptions payload")
}
```

## Notes

- Returns `false, nil` for empty input, avoiding unnecessary parse overhead.
- Detection is intentionally strict: a payload must **both** match `FleetCustomSettingsPayloadType` **and** have `DestroyFVKeyOnStandby` non-nil.
- Aligned with Apple's [FDEFileVaultOptions device management spec](https://developer.apple.com/documentation/devicemanagement/fdefilevaultoptions).
