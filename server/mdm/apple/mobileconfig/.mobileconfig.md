Parses and validates Apple MDM configuration profiles (`.mobileconfig` files) represented as XML plist byte slices, providing utilities for payload inspection, screening, and Fleet-specific identifier management.

## Key Components

### Types

- **`Mobileconfig`** (`[]byte`) — Core type representing a raw `.mobileconfig` XML plist profile
- **`Parsed`** — Struct holding top-level profile metadata: `PayloadIdentifier`, `PayloadDisplayName`, `PayloadType`, `PayloadScope`
- **`payloadSummary`** — Internal struct for per-payload-item metadata (`Type`, `Identifier`, `Name`)

### Constants

Fleet-managed payload identifiers and types (e.g. `FleetFileVaultPayloadIdentifier`, `ACMEPayloadType`, `SCEPPayloadType`, `FleetdConfigPayloadIdentifier`)

### Functions & Methods

| Name | Description |
|---|---|
| `FleetPayloadIdentifiers()` | Returns map of payload identifiers managed by Fleet |
| `FleetPayloadTypes()` | Returns map of payload types handled by Fleet |
| `mc.IsSignedProfile()` | Returns `true` if the profile is PKCS7-signed (not XML) |
| `mc.ParseConfigProfile()` | Parses and validates the top-level profile structure |
| `mc.HasPayloadType(t)` | Reports whether any payload content item matches the given type |
| `mc.ScreenPayloads(allowCustomFileVault)` | Validates no reserved Fleet payload types/identifiers are present |
| `XMLEscapeString(s)` | XML-escapes a plain text string |

### Errors

`ErrEmptyPayloadContent`, `ErrEncryptedPayloadContent`, `ErrInvalidPayloadType`

## Usage Example

```go
mc := mobileconfig.Mobileconfig(profileBytes)

// Check if signed
if mc.IsSignedProfile() {
    log.Fatal("signed profiles are not supported")
}

// Parse and validate profile metadata
parsed, err := mc.ParseConfigProfile()
if err != nil {
    log.Fatal(err)
}
fmt.Println(parsed.PayloadIdentifier, parsed.PayloadScope)

// Screen for reserved Fleet payload types
if err := mc.ScreenPayloads(false); err != nil {
    log.Fatal(err)
}

// Check for a specific payload type
hasSCEP, err := mc.HasPayloadType(mobileconfig.SCEPPayloadType)
```
