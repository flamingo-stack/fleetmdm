Handles Apple MDM certificate operations including APNs CSR generation, SCEP CA certificate creation, and DEP key pair management for Fleet MDM enrollment workflows.

## Key Components

| Export | Type | Description |
|---|---|---|
| `GenerateAPNSCSRKey` | func | Generates a new RSA private key and APNs CSR together |
| `GenerateAPNSCSR` | func | Generates an APNs CSR from an existing `crypto.PrivateKey` |
| `NewPrivateKey` | func | Public wrapper to generate a new RSA private key |
| `GetSignedAPNSCSR` | func | Posts unsigned CSR to fleetdm.com API; signed cert delivered via email |
| `GetSignedAPNSCSRNoEmail` | func | Posts unsigned CSR to fleetdm.com API; returns signed CSR bytes directly |
| `NewSCEPCACertKey` | func | Creates a self-signed CA certificate and key for SCEP |
| `NewDEPKeyPairPEM` | func | Generates a PEM-encoded RSA keypair for Apple DEP token download |
| `FleetWebsiteError` | struct | Error type for non-200 responses from the fleetdm.com API |

## Usage Example

```go
// Generate APNs CSR with a new key
csr, key, err := apple_mdm.GenerateAPNSCSRKey("admin@example.com", "Example Corp")
if err != nil {
    log.Fatal(err)
}

// Submit CSR to fleetdm.com and receive signed cert via email
client := &http.Client{}
if err := apple_mdm.GetSignedAPNSCSR(client, csr); err != nil {
    log.Fatal(err)
}

// Or retrieve the signed CSR bytes directly (no email delivery)
signedCSR, err := apple_mdm.GetSignedAPNSCSRNoEmail(client, csr)
if err != nil {
    log.Fatal(err)
}

// Generate a SCEP CA certificate
cert, key, err := apple_mdm.NewSCEPCACertKey()

// Generate a DEP keypair for Apple token download
pubPEM, privPEM, err := apple_mdm.NewDEPKeyPairPEM()
_ = key // suppress unused variable warning
```

> **Note:** The `TEST_FLEETDM_API_URL` environment variable overrides the default `https://fleetdm.com` endpoint for testing purposes.
