Defines the challenge password validation interface and middleware for SCEP enrollment in the MDM server.

## Key Components

- **`Validator`** — Interface requiring `HasChallenge(pw string) (bool, error)` to validate a challenge password
- **`Store`** — Extends `Validator` with `SCEPChallenge() (string, error)` for generating new challenge passwords; acts as a dynamic cache
- **`Middleware`** — Wraps a `CSRSignerContext` with challenge validation logic; rejects signing requests with invalid challenge passwords

## Usage Example

```go
// Implement a custom Store
type myStore struct{}

func (s *myStore) SCEPChallenge() (string, error) {
    return "generated-password", nil
}

func (s *myStore) HasChallenge(pw string) (bool, error) {
    return pw == "generated-password", nil
}

// Wrap a CSR signer with challenge validation middleware
store := &myStore{}
signer := challenge.Middleware(store, nextSigner)

// The middleware validates ChallengePassword before delegating to nextSigner
cert, err := signer(ctx, csrReqMessage)
if err != nil {
    // "invalid challenge" if HasChallenge returns false
}
```

## Notes

- `Middleware` currently validates all SCEP message types; a TODO notes restricting validation to `PKCSReq` messages only
- A failed `HasChallenge` check returns an `"invalid challenge"` error without calling the downstream signer
