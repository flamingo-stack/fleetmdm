Provides a BoltDB-backed store for managing one-time SCEP challenge passwords used in SCEP (Simple Certificate Enrollment Protocol) enrollment flows.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Depot` | struct | Wraps a `*bolt.DB` instance to provide SCEP challenge storage |
| `NewBoltDepot` | func | Initializes a `Depot`, creating the `scep_challenges` bucket if absent |
| `SCEPChallenge` | method | Generates a cryptographically random 24-byte base64 challenge, persists it, and returns it |
| `HasChallenge` | method | Looks up a challenge by value; deletes it on match (one-time use) and returns whether it was found |

## Usage Example

```go
db, err := bolt.Open("scep.db", 0600, nil)
if err != nil {
    log.Fatal(err)
}
defer db.Close()

depot, err := challengestore.NewBoltDepot(db)
if err != nil {
    log.Fatal(err)
}

// Generate a challenge to issue to an enrolling device
challenge, err := depot.SCEPChallenge()
if err != nil {
    log.Fatal(err)
}
fmt.Println("Issued challenge:", challenge)

// Later, validate the challenge submitted by the device
valid, err := depot.HasChallenge(challenge)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Challenge valid:", valid) // true (consumed on first check)

valid, err = depot.HasChallenge(challenge)
fmt.Println("Challenge valid:", valid) // false (already deleted)
```

## Notes

- Challenges are **single-use**: `HasChallenge` deletes the entry on a successful match within the same write transaction, preventing replay attacks.
- Randomness is sourced from `crypto/rand`, making challenges cryptographically unpredictable.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
