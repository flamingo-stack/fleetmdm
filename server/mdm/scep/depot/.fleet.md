Provides utilities for generating RSA private keys and self-signed CA certificates used in SCEP (Simple Certificate Enrollment Protocol) workflows.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `NewCACertKey` | func | Generates an RSA key pair and produces a self-signed CA certificate from a provided `CACert` configuration |
| `NewSCEPCACertKey` | func | Convenience wrapper that creates a SCEP-ready CA cert with a 10-year validity, CN `"Fleet"`, and country `"US"` |
| `newPrivateKey` | func (internal) | Generates a 2048-bit RSA private key using `crypto/rand` |
| `rsaKeySize` | const | Fixed at `2048` — Apple rejects CSRs with any other key size |

## Usage Example

```go
// Generate a ready-to-use SCEP CA certificate and private key
cert, key, err := depot.NewSCEPCACertKey()
if err != nil {
    log.Fatal(err)
}

// Or supply a custom CACert configuration
caCert := depot.NewCACert(
    depot.WithYears(5),
    depot.WithCommonName("My MDM CA"),
    depot.WithCountry("CA"),
)
cert, key, err = depot.NewCACertKey(caCert)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- All randomness uses `crypto/rand` — cryptographically secure by default.
- The 2048-bit key size is enforced to maintain compatibility with Apple MDM/SCEP requirements; do not change `rsaKeySize`.
