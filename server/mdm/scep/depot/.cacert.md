Self-signed CA certificate builder for SCEP (Simple Certificate Enrollment Protocol) PKI operations, providing a functional options pattern to configure and generate X.509 CA certificates.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `CACert` | struct | Holds CA certificate configuration (CN, Org, OU, Country, validity, key usage) |
| `NewCACert` | func | Constructor with sensible defaults (`scep-ca` org, 10-year validity, cert/CRL sign usage) |
| `CACertOption` | type | Functional option type for configuring a `CACert` |
| `WithOrganization` | option | Sets the Organization field |
| `WithOrganizationalUnit` | option | Sets the OrganizationalUnit field |
| `WithCommonName` | option | Sets the CommonName field |
| `WithCountry` | option | Sets the Country field |
| `WithYears` | option | Sets certificate validity duration |
| `WithKeyUsage` | option | Overrides default X.509 key usage flags |
| `SelfSign` | method | Builds an RFC 5280-compliant CA template and self-signs it, returning raw DER bytes |

## Usage Example

```go
import (
    "crypto/rand"
    "crypto/rsa"
)

// Generate a key pair
privKey, _ := rsa.GenerateKey(rand.Reader, 2048)

// Build and self-sign the CA certificate
ca := depot.NewCACert(
    depot.WithCommonName("My SCEP CA"),
    depot.WithOrganization("Acme Corp"),
    depot.WithCountry("US"),
    depot.WithYears(5),
)

derBytes, err := ca.SelfSign(rand.Reader, privKey.Public(), privKey)
if err != nil {
    log.Fatal(err)
}

cert, err := x509.ParseCertificate(derBytes)
```

> **Note:** `NotBefore` is set 600 nanoseconds in the past to account for clock skew in distributed clusters. The CA is constrained to a path length of `0`, disallowing intermediate CAs.
