A BoltDB-backed SCEP certificate depot that stores CA certificates, private keys, and issued certificates in a single embedded database bucket.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Depot` | struct | Wraps `*bolt.DB` with a serial-number mutex; implements the `depot.Depot` interface |
| `NewBoltDepot` | func | Initializes the BoltDB instance and ensures the `scep_certificates` bucket exists |
| `CA` | method | Retrieves the CA certificate chain and private key from the store |
| `Put` | method | Persists a leaf certificate keyed by `<cn>.<serial>` |
| `Serial` | method | Returns the current serial number and atomically increments it |
| `HasCN` | method | Checks whether a certificate with the given Common Name already exists in the store |
| `CreateOrLoadKey` | method | Loads an existing RSA private key or generates and stores a new one |
| `CreateOrLoadCA` | method | Loads an existing self-signed CA certificate or creates and stores a new one |

## Usage Example

```go
boltDB, err := bolt.Open("scep.db", 0600, nil)
if err != nil {
    log.Fatal(err)
}
defer boltDB.Close()

depot, err := bolt.NewBoltDepot(boltDB)
if err != nil {
    log.Fatal(err)
}

// Create or load the CA key (2048-bit RSA)
key, err := depot.CreateOrLoadKey(2048)
if err != nil {
    log.Fatal(err)
}

// Create or load a self-signed CA certificate valid for 10 years
caCert, err := depot.CreateOrLoadCA(key, 10, "Acme Corp", "US")
if err != nil {
    log.Fatal(err)
}

// Store an issued certificate
serial, _ := depot.Serial()
_ = depot.Put("device.example.com", caCert)
```

## Notes

- All bucket reads that return persistent references use `bucketGetCopy` to avoid invalid memory access after the BoltDB transaction closes (BoltDB `mmap` memory is volatile outside transactions).
- Serial number increments are protected by `serialMu` (`sync.RWMutex`) to prevent race conditions under concurrent SCEP enrollment requests.
- `HasCN` and revocation (`revokeOldCertificate`) are partially stubbed — `allowTime` and revocation logic are marked `TODO`.
