A filesystem-backed certificate depot implementing storage and management of X.509 certificates, serial numbers, and an OpenSSL-compatible CA database (`index.txt`).

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `fileDepot` | struct | Core depot holding the directory path and mutexes for serial/DB writes |
| `NewFileDepot` | func | Constructor; initializes `index.txt` in the given directory |
| `CA` | method | Loads the CA certificate (`ca.pem`) and private key (`ca.key`) |
| `Put` | method | Persists a certificate as a PEM file and records it in `index.txt` |
| `Serial` | method | Returns the current serial number (hex) and auto-increments it |
| `HasCN` | method | Checks `index.txt` for an existing valid cert with the same DN; optionally revokes it |
| `writeDB` | method | Appends an OpenSSL-format entry to `index.txt` |
| `loadKey` | func | Parses PKCS#1 or PKCS#8 RSA private keys from PEM (supports encrypted blocks) |
| `loadCert` | func | Decodes a PEM-encoded X.509 certificate |
| `pemCert` | func | DER → PEM encoder for certificate bytes |

## Usage Example

```go
// Create a new depot rooted at /etc/scep/ca
depot, err := file.NewFileDepot("/etc/scep/ca")
if err != nil {
    log.Fatal(err)
}

// Load the CA certificate and key
certs, key, err := depot.CA([]byte("passphrase"))
if err != nil {
    log.Fatal(err)
}

// Check whether a CN already exists before issuing
ok, err := depot.HasCN("device.example.com", 14, incomingCert, true)
if err != nil {
    log.Fatal(err) // DN already exists and is not renewable
}

// Allocate the next serial number
serial, err := depot.Serial()
if err != nil {
    log.Fatal(err)
}

// Store the newly issued certificate
if err := depot.Put("device.example.com", issuedCert); err != nil {
    log.Fatal(err)
}
```

## File Layout

```text
<dirPath>/
  ca.pem        ← CA certificate
  ca.key        ← CA private key (optionally encrypted)
  serial        ← hex serial counter
  index.txt     ← OpenSSL-format CA database
  <cn>.<serial>.pem  ← issued certificate files
```
