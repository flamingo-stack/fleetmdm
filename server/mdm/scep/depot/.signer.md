Signs x509 certificates from SCEP CSR requests and stores them in a `Depot`, supporting configurable validity, renewal windows, and signature algorithms.

## Key Components

### `Signer` struct
Core type holding depot reference and signing configuration: CA password, renewal window (`allowRenewalDays`), certificate lifetime (`validityDays`), server attribute inclusion, and signature algorithm override.

### `NewSigner(depot Depot, opts ...Option) *Signer`
Constructor with defaults: 14-day renewal window, 365-day validity, and signature algorithm inherited from the CSR.

### Options
Functional options to customize `Signer` behavior:

| Option | Description |
|---|---|
| `WithCAPass(pass string)` | Password for an encrypted CA private key |
| `WithAllowRenewalDays(r int)` | Days before expiry within which renewal is permitted |
| `WithValidityDays(v int)` | Lifetime in days for newly issued certificates |
| `WithSignatureAlgorithm(a)` | Override CSR-derived signature algorithm |
| `WithSeverAttrs()` | Add server auth EKU and data/key encipherment key usages |

### `SignCSR(m *scep.CSRReqMessage) (*x509.Certificate, error)`
SCEP-aware wrapper that delegates to `Signx509CSR`.

### `Signx509CSR(csr *x509.CertificateRequest) (*x509.Certificate, error)`
Core signing logic: generates a subject key ID, fetches a serial number from the depot, builds the certificate template, signs using the depot CA, then checks for an existing certificate with the same CN — revoking it if within the renewal window — before storing the new certificate.

## Usage Example

```go
depot, _ := fileDepot.NewFileDepot("/path/to/ca")

signer := NewSigner(depot,
    WithCAPass("secret"),
    WithValidityDays(180),
    WithAllowRenewalDays(30),
    WithSignatureAlgorithm(x509.SHA256WithRSA),
)

// From a raw x509 CSR
cert, err := signer.Signx509CSR(csrRequest)

// From a SCEP message
cert, err = signer.SignCSR(scepMessage)
```
