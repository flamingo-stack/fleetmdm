Defines the `Depot` interface, a repository abstraction for managing X.509 certificates and their lifecycle within a PKI/SCEP context.

## Key Components

| Element | Description |
|---|---|
| `Depot` | Core interface for certificate storage and retrieval operations |
| `CA()` | Retrieves the CA certificate chain and private key, unlocked with a passphrase |
| `Put()` | Stores a signed certificate by name |
| `Serial()` | Returns the next available serial number for certificate issuance |
| `HasCN()` | Checks if a Common Name exists, optionally revoking the old certificate |

## Notes

- `HasCN`'s `allowTime` parameter defines a grace window (in days) for overlapping certificates
- Setting `revokeOldCertificate` to `true` in `HasCN` enables automatic rotation during re-enrollment
- Implementations can back this interface with files, databases, or HSMs
