Extends Go's standard `crypto/x509` package to support the `challengePassword` attribute in Certificate Signing Requests (CSRs), enabling SCEP (Simple Certificate Enrollment Protocol) compatibility.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `CertificateRequest` | struct | Wraps `x509.CertificateRequest` with an optional `ChallengePassword` field |
| `CreateCertificateRequest` | func | Creates a CSR, falling back to stdlib if no challenge password is set |
| `ParseChallengePassword` | func | Extracts the `challengePassword` attribute from a DER-encoded CSR |
| `addChallenge` | func (internal) | Injects the challenge attribute into an existing CSR and re-signs it |
| `signingParamsForPublicKey` | func (internal) | Resolves hash function and signature algorithm for RSA, ECDSA, and RSA-PSS keys |
| `rsaPSSParameters` | func (internal) | Builds ASN.1 PSS parameters for RSA-PSS signature algorithms |

## Usage Example

```go
// Generate a CSR with a challengePassword attribute
template := &x509util.CertificateRequest{
    CertificateRequest: x509.CertificateRequest{
        Subject: pkix.Name{
            CommonName: "device.example.com",
        },
        SignatureAlgorithm: x509.SHA256WithRSA,
    },
    ChallengePassword: "scep-secret",
}

csrDER, err := x509util.CreateCertificateRequest(rand.Reader, template, privateKey)
if err != nil {
    log.Fatal(err)
}

// Later, extract the challenge from a received CSR
password, err := x509util.ParseChallengePassword(csrDER)
if err != nil {
    log.Fatal(err)
}
fmt.Println(password) // "scep-secret"
```

## Notes

- If `ChallengePassword` is empty, `CreateCertificateRequest` delegates directly to `x509.CreateCertificateRequest` with no overhead.
- Supports RSA, RSA-PSS, DSA, and ECDSA (P-224, P-256, P-384, P-521) key types.
- Derived from Go standard library internals to work around the missing challenge password support tracked in [golang/go#15995](https://github.com/golang/go/issues/15995).
