Entry point for a standalone SCEP (Simple Certificate Enrollment Protocol) server that handles certificate issuance, renewal, and CA management for MDM deployments.

## Key Components

| Function | Description |
|---|---|
| `main()` | Initializes the file depot, SCEP service, HTTP handler, and starts the server |
| `caMain()` | Subcommand handler for CA initialization (`scepserver ca --init`) |
| `createKey()` | Generates an RSA private key and writes it as an encrypted PEM file to the depot |
| `createCertificateAuthority()` | Creates and self-signs a CA certificate, saving it to the depot |
| `pemCert()` | Encodes DER certificate bytes to PEM format |
| `envString()` / `envBool()` | Helper functions to read configuration from environment variables with defaults |
| `setByUser()` | Detects whether a flag was explicitly set via CLI or environment variable |

**Key flags / environment variables:**

| Flag | Env Var | Default | Purpose |
|---|---|---|---|
| `-http-addr` | `SCEP_HTTP_ADDR` | `:8080` | HTTP listen address |
| `-depot` | `SCEP_FILE_DEPOT` | `depot` | Path to CA cert/key storage |
| `-capass` | `SCEP_CA_PASS` | `""` | CA private key password |
| `-challenge` | `SCEP_CHALLENGE_PASSWORD` | `""` | SCEP challenge password |
| `-csrverifierexec` | `SCEP_CSR_VERIFIER_EXEC` | `""` | External CSR verification executable |
| `-allowrenew` | `SCEP_CERT_RENEW` | `14` | Days before expiry to allow renewal |
| `-crtvalid` | `SCEP_CERT_VALID` | `365` | Client certificate validity in days |

## Usage Example

```bash
# Initialize a new CA
scepserver ca --init \
  --depot ./depot \
  --common_name "My SCEP CA" \
  --organization "Acme Corp" \
  --country US \
  --keySize 4096 \
  --years 10 \
  --key-password secret

# Start the SCEP server
scepserver \
  --depot ./depot \
  --capass secret \
  --challenge enrollSecret \
  --port 8080 \
  --log-json \
  --debug
```

The server exposes a single HTTP route `POST/GET /scep` and shuts down gracefully on `SIGINT`.
