Provides certificate management utilities for SCEP (Simple Certificate Enrollment Protocol), including self-signed certificate generation, PEM encoding, and file-based certificate persistence.

## Key Components

| Function | Description |
|---|---|
| `pemCert(derBytes []byte)` | Encodes raw DER certificate bytes into a PEM-formatted block |
| `loadOrSign(path, priv, csr)` | Loads an existing certificate from disk or generates and persists a new self-signed one |
| `selfSign(priv, csr)` | Creates a self-signed X.509 certificate valid for 1 hour using the provided RSA key and CSR |
| `loadPEMCertFromFile(path)` | Reads and parses a PEM-encoded certificate from a file path |

## Usage Example

```go
// Generate or load an existing SCEP signer certificate
privKey, _ := rsa.GenerateKey(rand.Reader, 2048)

csr := &x509.CertificateRequest{
    Subject: pkix.Name{
        Organization: []string{"Flamingo MDM"},
    },
}

// Loads from disk if exists, otherwise self-signs and saves
cert, err := loadOrSign("/etc/scep/signer.pem", privKey, csr)
if err != nil {
    log.Fatal(err)
}

// Encode an existing DER certificate to PEM
pemBytes := pemCert(cert.Raw)
```

## Notes

- `selfSign` generates a certificate with a 128-bit random serial number and a **1-hour validity window** — suitable for short-lived SCEP operations
- `loadOrSign` uses `O_EXCL` to atomically create the file, preventing race conditions on first write
- Certificate key usage is set to `KeyEncipherment | DigitalSignature` with `ExtKeyUsageServerAuth`
