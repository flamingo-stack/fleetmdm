Handles creation and loading of X.509 Certificate Signing Requests (CSRs) for SCEP (Simple Certificate Enrollment Protocol) MDM enrollment, persisting them as PEM-encoded files.

## Key Components

- **`csrOptions`** — Struct holding CSR field values (`cn`, `org`, `country`, `ou`, `locality`, `province`, `dnsName`, `challenge`) and the RSA private key used to sign the request.
- **`loadOrMakeCSR`** — Creates a new CSR file at the given path if it doesn't exist, or loads an existing one. Supports an optional SCEP challenge password via `x509util.CertificateRequest`.
- **`loadCSRfromFile`** — Reads and parses a PEM-encoded CSR from disk, validating block type and headers.
- **`subjOrNil`** — Helper that converts an empty string to `nil` (omitting the field from the PKIX subject) or wraps a non-empty string in a slice.

## Usage Example

```go
key, _ := rsa.GenerateKey(rand.Reader, 2048)

opts := &csrOptions{
    cn:        "fleet-device",
    org:       "Flamingo MSP",
    country:   "US",
    dnsName:   "device.example.com",
    challenge: "mysecret",
    key:       key,
}

csr, err := loadOrMakeCSR("/etc/mdm/device.csr", opts)
if err != nil {
    log.Fatal(err)
}

fmt.Println("CSR Subject:", csr.Subject.CommonName)
```

> **Note:** `loadOrMakeCSR` uses `O_EXCL` to atomically create the file, ensuring concurrent calls safely fall back to loading the existing CSR rather than overwriting it.
