Provides RSA private key generation and persistence utilities, handling creation, storage, and loading of PEM-encoded RSA keys from disk.

## Key Components

| Function | Description |
|---|---|
| `newRSAKey(bits int)` | Generates a new RSA private key using `crypto/rand` with the specified bit size |
| `loadOrMakeKey(path, rsaBits)` | Loads an existing key from disk if present, otherwise generates and persists a new one |
| `loadKeyFromFile(path)` | Reads and parses a PKCS#1 PEM-encoded RSA private key from a file path |

**Constant:**
- `rsaPrivateKeyPEMBlockType` — PEM block type identifier (`"RSA PRIVATE KEY"`)

## Usage Example

```go
// Generate and persist a 2048-bit RSA key (or load if already exists)
privKey, err := loadOrMakeKey("/etc/fleet/server.key", 2048)
if err != nil {
    log.Fatalf("failed to load or create key: %v", err)
}

// Load an existing key directly
privKey, err := loadKeyFromFile("/etc/fleet/server.key")
if err != nil {
    log.Fatalf("failed to load key: %v", err)
}
```

## Notes

- `loadOrMakeKey` uses `O_EXCL` to atomically detect whether the file exists, preventing race conditions on first creation.
- Keys are serialized using PKCS#1 (`x509.MarshalPKCS1PrivateKey`) and written as PEM blocks.
- `loadKeyFromFile` validates the PEM block type before parsing, returning explicit errors for malformed or mismatched files.
