A command-line SCEP (Simple Certificate Enrollment Protocol) client that handles certificate enrollment, renewal, and CA certificate retrieval against a SCEP server (e.g., NDES).

## Key Components

- **`runCfg`** — Configuration struct holding all runtime parameters: paths, certificate subject fields, server URL, CA selector, and logging options.
- **`run(cfg runCfg) error`** — Core enrollment logic: initializes the SCEP client, loads or generates a key/CSR, fetches CA certs, sends a `PKCSReq` or `RenewalReq`, polls on `PENDING`, decrypts the response envelope, and writes the issued certificate to disk.
- **`logCerts`** — Logs count, RDN subject, and SHA-256 fingerprint for each CA certificate returned by the server.
- **`validateFingerprint`** — Normalizes and validates a SHA-256 fingerprint string (accepts space-, colon-, or plain hex formats) and verifies its length.
- **`validateFlags`** — Validates required CLI flags and enforces mutual exclusivity between `ca-fingerprint` and `key-encipherment-selector`.
- **`main`** — Parses CLI flags, selects a CA certificate selector (fingerprint, key encipherment, or no-op), assembles `runCfg`, and calls `run`.

## Usage Example

```bash
# Initial enrollment
scepclient \
  -server-url https://ndes.example.com/certsrv/mscep/mscep.dll \
  -private-key /etc/mdm/client.key \
  -certificate /etc/mdm/client.pem \
  -cn "device-hostname" \
  -organization "Acme Corp" \
  -country US \
  -challenge "enrollment-secret" \
  -ca-fingerprint "e3:b0:c4:42:98:fc:1c:14:9a:fb:f4:c8:99:6f:b9:24:27:ae:41:e4:64:9b:93:4c:a4:95:99:1b:78:52:b8:55"

# Renewal (runs automatically when a cert already exists at -certificate path)
scepclient \
  -server-url https://ndes.example.com/certsrv/mscep/mscep.dll \
  -private-key /etc/mdm/client.key \
  -certificate /etc/mdm/client.pem \
  -key-encipherment-selector \
  -debug
```

> **CA selector flags are mutually exclusive** — use either `-ca-fingerprint` or `-key-encipherment-selector`, not both.
