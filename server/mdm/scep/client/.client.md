Provides the SCEP client constructor and configuration options for connecting to a SCEP (Simple Certificate Enrollment Protocol) server.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Client` | Interface | Extends `scepserver.Service` with a `Supports(capacity string) bool` method for capability checking |
| `Option` | Type | Functional option type for configuring `clientOpts` |
| `WithRootCA` | Function | Sets a custom root CA certificate file for TLS verification |
| `Insecure` | Function | Disables server certificate verification (test use only) |
| `WithTimeout` | Function | Sets a timeout duration for SCEP requests |
| `New` | Function | Constructs and returns a configured `Client` with logging middleware applied to GET and POST endpoints |

## Usage Example

```go
timeout := 30 * time.Second

client, err := scepclient.New(
    "https://scep.example.com/scep",
    slog.Default(),
    scepclient.WithRootCA("/path/to/ca.pem"),
    scepclient.WithTimeout(&timeout),
)
if err != nil {
    log.Fatal(err)
}

if client.Supports("renewal") {
    // proceed with renewal flow
}
```

> **Note:** `Insecure()` bypasses TLS certificate validation and should never be used in production — it exists solely for testing environments.
