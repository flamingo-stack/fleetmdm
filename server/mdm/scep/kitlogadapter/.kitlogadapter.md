Provides a thin adapter that wraps `*slog.Logger` to implement the `go-kit/kitlog.Logger` interface, bridging third-party libraries (go-kit/kit, smallstep/scep, etc.) that require a `kitlog.Logger` with the standard `log/slog` backend.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Logger` | `struct` | Wraps `*slog.Logger`; implements `kitlog.Logger` |
| `NewLogger` | `func` | Constructs a `Logger` from an existing `*slog.Logger` |
| `Log` | `method` | Implements `kitlog.Logger`; maps key-value pairs to `slog` attributes and level |
| `With` | `method` | Returns a new `Logger` with persistent key-value context |
| `levelToSlog` | `func` (internal) | Converts kitlog level strings (`"debug"`, `"info"`, `"warn"`, `"error"`) to `slog.Level` |

**Special key handling in `Log`:**

| Key | Behaviour |
|---|---|
| `level` | Sets log level via `levelToSlog` |
| `msg` | Used as the slog message string |
| `ts` | Skipped — slog manages timestamps automatically |
| all others | Passed as `slog.Attr` values |

## Usage Example

```go
import (
    "log/slog"
    "os"

    "github.com/flamingo-stack/fleetmdm/kitlogadapter"
)

// Create a standard slog logger
slogLogger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

// Wrap it for use with go-kit or smallstep/scep
kitLogger := kitlogadapter.NewLogger(slogLogger)

// Use directly as a kitlog.Logger
kitLogger.Log("level", "info", "msg", "server started", "port", 8080)

// Add persistent fields (e.g. per-component context)
componentLogger := kitLogger.With("component", "mdm-scep")
componentLogger.Log("level", "debug", "msg", "processing request")
```
