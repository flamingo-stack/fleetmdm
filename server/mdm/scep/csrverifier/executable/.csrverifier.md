Validates Certificate Signing Requests (CSRs) by delegating to an external executable, passing the raw CSR bytes via stdin and interpreting the exit code as the verification result.

## Key Components

- **`New(path string, logger *slog.Logger)`** — Constructor that validates the given path exists, is not a directory, and has at least one execute permission bit set before returning an `ExecutableCSRVerifier`.
- **`ExecutableCSRVerifier`** — Struct holding the executable path and a structured logger.
- **`Verify(data []byte) (bool, error)`** — Runs the executable, writes raw CSR bytes to its stdin, and returns `true` if the process exits with code `0`. Non-zero exits are logged and masked as `(false, nil)`.

## Usage Example

```go
import (
    executablecsrverifier "github.com/flamingo-stack/fleetmdm/ee/mdm/scep/csrverifier/executable"
    "log/slog"
    "os"
)

logger := slog.New(slog.NewTextHandler(os.Stderr, nil))

verifier, err := executablecsrverifier.New("/usr/local/bin/verify-csr", logger)
if err != nil {
    log.Fatal(err) // path missing, is a directory, or not executable
}

csrBytes := []byte("...raw CSR data...")
valid, err := verifier.Verify(csrBytes)
if err != nil {
    log.Fatal(err)
}
if !valid {
    log.Println("CSR rejected by external verifier")
}
```

> **Note:** Errors returned by the external process are intentionally masked — `Verify` returns `(false, nil)` on a non-zero exit. Only fatal setup errors (stdin pipe failures) propagate as non-nil errors.
