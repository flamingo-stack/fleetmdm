Defines the `CSRVerifier` interface and middleware for verifying decrypted CSR payloads within the SCEP server pipeline before signing.

## Key Components

- **`CSRVerifier`** — Interface with a single `Verify(data []byte) (bool, error)` method; implementations inspect the raw decrypted CSR bytes and return whether it passes validation.
- **`Middleware`** — Wraps a `scepserver.CSRSignerContext` with a verification step; returns a `CSRSignerContextFunc` that calls `verifier.Verify` on `m.RawDecrypted` before delegating to the next signer.

## Usage Example

```go
// Implement CSRVerifier
type MyVerifier struct{}

func (v *MyVerifier) Verify(data []byte) (bool, error) {
    // Custom validation logic on raw decrypted CSR bytes
    if len(data) == 0 {
        return false, nil
    }
    return true, nil
}

// Wrap an existing CSRSignerContext with verification middleware
verifier := &MyVerifier{}
signerWithVerification := csrverifier.Middleware(verifier, existingSigner)

// signerWithVerification can now be used as a scepserver.CSRSignerContextFunc
cert, err := signerWithVerification(ctx, csrReqMessage)
if err != nil {
    // Handles both verifier errors and "CSR verify failed"
    log.Fatal(err)
}
```

## Behavior

If `Verify` returns `false, nil`, the middleware short-circuits with `errors.New("CSR verify failed")` and the downstream signer is never called. If `Verify` returns an error, that error is propagated directly.
