Defines the core SCEP server service interface and its default implementation, handling CA capabilities, certificate retrieval, and PKI operations for MDM certificate enrollment workflows.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Service` | Interface | Core SCEP operations: `GetCACaps`, `GetCACert`, `PKIOperation`, `GetNextCACert` |
| `ServiceWithIdentifier` | Interface | Extends `Service` with a polymorphic `identifier` string parameter for Fleet-specific routing (e.g., NDES vs. custom SCEP proxy) |
| `service` | Struct | Concrete implementation holding the certificate/key pair, optional RA CA chain, a `CSRSignerContext`, and a debug logger |
| `DefaultCACaps` | Constant | Default CA capability string advertising `Renewal`, `SHA-1`, `SHA-256`, `AES`, `DES3`, `SCEPStandard`, `POSTPKIOperation` |
| `NewService` | Function | Constructor accepting a certificate, RSA private key, signer, and variadic `ServiceOption` functions |
| `WithLogger` | Option | Configures a `slog.Logger` on the service (defaults to discard) |
| `WithAddlCA` | Option | Appends an intermediate/RA CA certificate to the response chain for `GetCACert` |

## Usage Example

```go
// Load CA certificate and key (simplified)
crt, _ := loadCertificate("ca.crt")
key, _ := loadPrivateKey("ca.key")

// Build service with optional extra CA and logger
svc, err := scepserver.NewService(
    crt,
    key,
    mySigner, // implements CSRSignerContext
    scepserver.WithLogger(slog.Default()),
    scepserver.WithAddlCA(intermediateCert),
)
if err != nil {
    log.Fatal(err)
}

// Respond to a SCEP client PKIOperation request
responseBytes, err := svc.PKIOperation(ctx, incomingMsgBytes)
```

> **Note:** `ServiceWithIdentifier` is a Fleet-specific extension. The `identifier` parameter is a comma-separated string used for ad hoc validation in SCEP proxy scenarios. See the type-level `FIXME` comment in the [source](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/scep/server/service.go) for details.
