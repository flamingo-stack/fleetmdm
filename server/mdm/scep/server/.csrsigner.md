Defines the CSR signing interfaces, adapters, and middleware used by the SCEP server to handle certificate signing requests from CA/RA operations.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `CSRSignerContext` | Interface | Context-aware CSR signer; `SignCSRContext` returns a signed `*x509.Certificate` |
| `CSRSignerContextFunc` | Func adapter | Implements `CSRSignerContext` for inline/anonymous signing functions |
| `CSRSigner` | Interface | Non-context CSR signer; `SignCSR` returns a signed `*x509.Certificate` |
| `CSRSignerFunc` | Func adapter | Implements `CSRSigner` for inline/anonymous signing functions |
| `NopCSRSigner` | Factory | Returns a no-op signer that always returns `nil, nil` — useful for testing |
| `StaticChallengeMiddleware` | Middleware | Validates SCEP challenge password via constant-time compare before delegating to `next` |
| `SignCSRAdapter` | Adapter | Lifts a context-free `CSRSigner` into the `CSRSignerContext` interface |

## Usage Example

```go
// Wrap a basic signer with static challenge validation
var mySigner CSRSigner = CSRSignerFunc(func(m *scep.CSRReqMessage) (*x509.Certificate, error) {
    // sign the CSR with your CA
    return myCA.Sign(m.CSR)
})

// Adapt to context-aware interface, then add challenge middleware
adapted := SignCSRAdapter(mySigner)
protected := StaticChallengeMiddleware("s3cr3t-challenge", adapted)

// Use in the SCEP server
cert, err := protected.SignCSRContext(ctx, csrReqMsg)
if err != nil {
    log.Fatal("signing failed:", err)
}
```

## Notes

- `StaticChallengeMiddleware` uses `crypto/subtle.ConstantTimeCompare` to prevent timing attacks when validating the SCEP challenge password.
- `SignCSRAdapter` enables gradual migration: legacy `CSRSigner` implementations can be used anywhere a `CSRSignerContext` is required without rewriting the signing logic.
