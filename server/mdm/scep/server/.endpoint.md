Defines SCEP protocol endpoints for both client and server sides, handling operations like `GetCACaps`, `GetCACert`, `PKIOperation`, and `GetNextCACert` using the go-kit endpoint pattern.

## Key Components

- **`Endpoints`** — Holds `GetEndpoint` and `PostEndpoint` go-kit endpoints, with thread-safe caching of server CA capabilities.
- **`SCEPRequest` / `SCEPRequestWithIdentifier`** — Request types carrying the SCEP operation name and optional message payload or identifier.
- **`SCEPResponse`** — Response type carrying raw DER data, CA cert count, and any business error.
- **`MakeServerEndpoints`** / **`MakeServerEndpointsWithIdentifier`** — Wire a `Service` or `ServiceWithIdentifier` into an `Endpoints` struct for server-side use.
- **`MakeClientEndpoints`** — Constructs an HTTP client-backed `Endpoints` targeting a remote SCEP server URL, with optional TLS, root CA, insecure skip, and timeout configuration via `ClientOption` functional options.
- **`MakeSCEPEndpoint`** / **`MakeSCEPEndpointWithIdentifier`** — Low-level go-kit endpoint factories that dispatch on `req.Operation`.
- **`EndpointLoggingMiddleware`** — go-kit middleware that logs operation name, duration, and error using `slog`.

## Usage Example

```go
// Server-side
svc := NewSCEPService(...)
endpoints := scepserver.MakeServerEndpoints(svc)

// Client-side with custom root CA and timeout
timeout := 30 * time.Second
endpoints, err := scepserver.MakeClientEndpoints(
    "https://scep.example.com/scep",
    scepserver.WithClientRootCA("/etc/ssl/scep-ca.pem"),
    scepserver.WithClientTimeout(&timeout),
)
if err != nil {
    log.Fatal(err)
}

caps, err := endpoints.GetCACaps(ctx)
cert, num, err := endpoints.GetCACert(ctx, "")
data, err := endpoints.PKIOperation(ctx, pkiMsg)
```
