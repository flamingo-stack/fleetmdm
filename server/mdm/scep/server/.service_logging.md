Middleware wrapper that adds structured logging to the SCEP service using Go's `slog` package, recording execution time and errors for each operation.

## Key Components

- **`loggingService`** — Decorator struct embedding `Service` that intercepts all SCEP service calls to emit timing and error logs.
- **`NewLoggingService`** — Constructor that wraps any `Service` implementation with logging middleware.
- **`GetCACaps`** — Logs CA capabilities requests with duration and error.
- **`GetCACert`** — Logs CA certificate retrieval with the request message, duration, and error.
- **`PKIOperation`** — Logs PKI operations (enrollment, renewal) with duration and error.

## Usage Example

```go
import (
    "log/slog"
    "os"
)

logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

var coreSvc scepserver.Service = scepserver.NewService(depot, opts...)

// Wrap with logging middleware
svc := scepserver.NewLoggingService(logger, coreSvc)

// All calls now emit structured logs:
// {"level":"INFO","msg":"PKIOperation","err":null,"took":"3.2ms"}
caps, err := svc.GetCACaps(ctx)
```

Each method uses a deferred closure to capture the final `err` value and elapsed time after the underlying service call completes, ensuring accurate logging even when errors occur.

## Notes

- Logs are emitted at `INFO` level via `InfoContext`, preserving the request context for trace propagation.
- This follows the [decorator/middleware pattern](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/scepserver/service_logging.go); stack additional wrappers (e.g., metrics, tracing) by composing them in the same way.
