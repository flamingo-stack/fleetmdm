HTTP transport layer for the SCEP (Simple Certificate Enrollment Protocol) server, handling request routing, encoding, and decoding for SCEP operations over HTTP.

## Key Components

### HTTP Handler Factories

- **`MakeHTTPHandler`** — Creates a basic router handling `GET`/`POST` SCEP requests without path-based identifiers.
- **`MakeHTTPHandlerWithIdentifier`** — Creates a router supporting URL path identifiers (e.g., `/scep/{identifier}`), including a Windows SCEP client compatibility route at `{identifier}/pkiclient.exe`.

### Request Encoding/Decoding

- **`EncodeSCEPRequest`** — Client-side encoder; serializes a `SCEPRequest` into an HTTP request. For `GET`/`PKIOperation`, base64-encodes the message body; for `POST`, sends it as `application/octet-stream`.
- **`decodeSCEPRequest`** / **`decodeSCEPRequestWithIdentifier`** — Server-side decoders; parse the `operation` query parameter and message body from incoming requests.
- **`message`** — Extracts the raw payload from a request. For `GET`/`PKIOperation`, reads from the raw query string (bypassing `+`→space HTML-form decoding per RFC 3986; see [`#45291`](https://github.com/flamingo-stack/fleetmdm/issues)).

### Response Encoding/Decoding

- **`encodeSCEPResponse`** — Writes a `SCEPResponse` to the HTTP response writer, setting appropriate `Content-Type` headers per SCEP operation.
- **`DecodeSCEPResponse`** — Client-side decoder for HTTP responses from a SCEP server.

### Error Types

- **`BadRequestError`** — Returns HTTP `400`; implements `kithttp.StatusCoder`.
- **`TimeoutError`** — Returns HTTP `408`; implements `kithttp.StatusCoder`.

## Usage Example

```go
// Server setup
endpoints := MakeServerEndpoints(svc)
handler := MakeHTTPHandlerWithIdentifier(endpoints, "/mdm/scep/", logger)
http.ListenAndServe(":8080", handler)

// Client-side request encoding
req, _ := http.NewRequest("GET", "https://example.com/scep", nil)
EncodeSCEPRequest(ctx, req, SCEPRequest{
    Operation: "PKIOperation",
    Message:   pkiMessageBytes,
})
```
