Provides cryptographic utility functions for generating Subject Key Identifiers (SKI) and parsing PEM-encoded private keys.

## Key Components

- **`GenerateSubjectKeyID(pub crypto.PublicKey) ([]byte, error)`** — Generates a 160-bit Subject Key Identifier by SHA-256 hashing the public key bytes, following RFC 7093 §2. Supports RSA and ECDSA public keys.

- **`ParsePrivateKey(privKeyPEM []byte, keyName string) (crypto.PrivateKey, error)`** — Decodes a PEM-encoded private key, attempting PKCS#1, PKCS#8, and EC formats in order. Supports RSA, ECDSA, and Ed25519 key types. The `keyName` parameter is used only for error messages.

## Usage Example

```go
import "cryptoutil"

// Generate a Subject Key Identifier from an RSA public key
ski, err := cryptoutil.GenerateSubjectKeyID(rsaCert.PublicKey)
if err != nil {
    log.Fatalf("failed to generate SKI: %v", err)
}

// Parse a PEM private key from an environment variable or file
pemBytes := []byte(os.Getenv("TLS_PRIVATE_KEY"))
privKey, err := cryptoutil.ParsePrivateKey(pemBytes, "TLS_PRIVATE_KEY")
if err != nil {
    log.Fatalf("failed to parse private key: %v", err)
}
```

## Notes

- `GenerateSubjectKeyID` returns only the **leftmost 20 bytes** (160 bits) of the SHA-256 hash per RFC 7093.
- `ParsePrivateKey` mirrors the logic from Go's standard library [`crypto/tls`](https://cs.opensource.google/go/go/+/release-branch.go1.23:src/crypto/tls/tls.go;l=355-372), supporting all three common PEM private key formats without requiring the caller to know the format upfront.
