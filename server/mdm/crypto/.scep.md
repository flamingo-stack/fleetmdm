Implements SCEP (Simple Certificate Enrollment Protocol) certificate verification for MDM device authentication, validating client certificates against the Fleet CA certificate stored in the MDM asset database.

## Key Components

| Component | Description |
|-----------|-------------|
| `SCEPVerifier` | Struct implementing `mdm.CertVerifier` that verifies SCEP-issued client certificates |
| `NewSCEPVerifier` | Constructor accepting a `fleet.MDMAssetRetriever` for CA cert retrieval |
| `Verify` | Validates a client `x509.Certificate` against the Fleet CA, relaxing key usage constraints when the CA cert carries non-standard extended key usages |
| `hasOtherKeyUsages` | Helper that checks whether a certificate has extended key usages beyond a specified one |

## Usage Example

```go
// Initialize verifier with a datastore that implements MDMAssetRetriever
verifier := mdmcrypto.NewSCEPVerifier(ds)

// Verify a client certificate from an MDM request
if err := verifier.Verify(ctx, clientCert); err != nil {
    log.Printf("SCEP certificate verification failed: %v", err)
}
```

## Notes

- The verifier loads the CA certificate dynamically from the asset store on each call, reflecting live configuration changes.
- Key usage enforcement is automatically relaxed to `ExtKeyUsageAny` when the CA certificate contains non-`ClientAuth` extended key usages. This accommodates customer-provided certificates used in touchless MDM migrations.
- Implements the `mdm.CertVerifier` interface, verified at compile time via the blank identifier assignment `var _ mdm.CertVerifier = (*SCEPVerifier)(nil)`.
