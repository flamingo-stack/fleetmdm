Signs an MDM enrollment profile using a CA key pair retrieved from the datastore.

## Key Components

- **`Sign(ctx, profile, ds)`** — Retrieves the CA certificate/key pair via `assets.CAKeyPair`, then signs the raw profile bytes using `profileutil.Sign`. Returns the signed profile or a wrapped error.

## Usage Example

```go
signedProfile, err := mdmcrypto.Sign(ctx, rawProfile, ds)
if err != nil {
    return fmt.Errorf("signing enrollment profile: %w", err)
}
// signedProfile is ready to be delivered to enrolling devices
```

## Notes

- Signing is delegated to [`micromdm/profileutil`](https://github.com/micromdm/micromdm), which produces a CMS/PKCS#7 signed payload.
- The CA key pair is fetched dynamically from the datastore on each call via [`assets.CAKeyPair`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/assets/assets.go), so no in-memory key material needs to be passed by the caller.
