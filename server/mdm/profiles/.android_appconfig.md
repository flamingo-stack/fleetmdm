Handles substitution of `$FLEET_VAR_*` tokens in Android managed app configuration JSON, resolving host-scoped variables (UUID, serial, platform, IdP fields) and returning JSON-safe substituted bytes.

## Key Components

- **`ErrUnresolvableAndroidAppConfigVar`** — Sentinel error for unresolvable Fleet variable references.
- **`UnresolvableAndroidAppConfigVarError`** — Structured error carrying the unresolved variable name and a user-facing detail message; implements `Is()` for `errors.Is` compatibility.
- **`AndroidAppConfigSubstitutionHost`** — Lightweight struct carrying host context (`UUID`, `HardwareSerial`, `Platform`) needed for variable resolution.
- **`SubstituteFleetVarsInAndroidAppConfig`** — Primary entry point; scans config for `$FLEET_VAR_*` tokens, resolves each against the host and datastore, and returns substituted bytes.
- **`replaceJSONSafe`** — Replaces a variable token with a JSON-escaped value via `variables.Replace`.
- **`jsonEscapeString`** — Uses `json.Marshal` to escape special characters for safe embedding inside JSON string literals.

## Usage Example

```go
host := profiles.AndroidAppConfigSubstitutionHost{
    UUID:           "abc-123",
    HardwareSerial: "SN123456",
    Platform:       "android",
}

substituted, err := profiles.SubstituteFleetVarsInAndroidAppConfig(ctx, ds, rawConfig, host)
if err != nil {
    if errors.Is(err, profiles.ErrUnresolvableAndroidAppConfigVar) {
        var varErr *profiles.UnresolvableAndroidAppConfigVarError
        errors.As(err, &varErr)
        log.Printf("unresolved variable: %s — %s", varErr.FleetVar, varErr.Detail)
    }
    return err
}
// substituted contains the resolved JSON config ready for deployment
```
