Handles replacement of Fleet-defined template variables (e.g., `$FLEET_VAR_CUSTOM_SCEP_CHALLENGE_*`, `$FLEET_VAR_HOST_END_USER_EMAIL_IDP`) within MDM profile XML contents across platforms (Apple/Windows).

## Key Components

| Function | Description |
|---|---|
| `ReplaceCustomSCEPChallengeVariable` | Substitutes the SCEP challenge value for a named CA into profile XML |
| `ReplaceCustomSCEPProxyURLVariable` | Generates a new SCEP challenge, builds the proxy URL, injects it into profile XML, and returns a `MDMManagedCertificate` record |
| `ReplaceHostEndUserIDPVariables` | Top-level dispatcher that resolves and replaces IDP user variables in a profile |
| `ResolveHostEndUserIDPValue` | Resolves the raw string value for a given IDP fleet variable (`IdpUserName`, local part, groups, department, full name) |
| `ReplaceExactFleetPrefixVariableInXML` | Compiles a regex for `$FLEET_VAR_<PREFIX><SUFFIX>` / `${FLEET_VAR_<PREFIX><SUFFIX>}` and replaces with XML-escaped text |
| `ReplaceFleetVariableInXML` | Replaces matches of a pre-compiled regexp with an XML-escaped replacement string |
| `IsCustomSCEPConfigured` | Validates Premium license and CA existence before allowing SCEP variable substitution |
| `BuildNDESSCEPProxyURL` | Constructs an NDES SCEP proxy URL for a host/profile pair |
| `ReplaceNDESSCEPProxyURLVariable` | Convenience wrapper that builds and injects the NDES SCEP proxy URL into profile XML |
| `HydrateHost` | Resolves a partially-populated `fleet.Host` (UUID only) to a full record via the datastore |

## Usage Example

```go
// Replace a custom SCEP challenge variable in an Apple/Windows MDM profile
updated, replaced, err := profiles.ReplaceCustomSCEPChallengeVariable(
    ctx,
    logger,
    "$FLEET_VAR_CUSTOM_SCEP_CHALLENGE_MyCA",
    customSCEPCAs,      // map[string]*fleet.CustomSCEPProxyCA
    rawProfileContents,
)
if err != nil {
    return err
}

// Replace host IDP email variable
updated, replaced, err = profiles.ReplaceHostEndUserIDPVariables(
    ctx, ds,
    string(fleet.FleetVarHostEndUserIDPUsername),
    rawProfileContents,
    hostUUID,
    hostIDCache,
    func(msg string) error { return fmt.Errorf(msg) },
)

// Build and inject NDES SCEP proxy URL
updated = profiles.ReplaceNDESSCEPProxyURLVariable(
    appConfig.MDMUrl(), hostUUID, profileUUID, rawProfileContents,
)
```
