Parses a storage backend name and DSN string to instantiate and return the appropriate `AllDEPStorage` implementation for NanoDEP.

## Key Components

- **`Storage(storageName, dsn string) (storage.AllDEPStorage, error)`** — Factory function that resolves a storage backend by name. Supports `"file"` (defaults DSN to `"db"` if empty) and `"mysql"`. Returns an error for unknown backend names.

## Usage Example

```go
// File-based storage with default path
store, err := parse.Storage("file", "")

// File-based storage with custom path
store, err := parse.Storage("file", "/var/lib/nanodep/db")

// MySQL storage
store, err := parse.Storage("mysql", "user:pass@tcp(localhost:3306)/nanodep")
if err != nil {
    log.Fatal(err)
}
```

## Supported Backends

| Name | DSN Default | Implementation |
|------|-------------|----------------|
| `file` | `"db"` | `storage/file` |
| `mysql` | *(required)* | `storage/mysql` |

> Unknown backend names return `fmt.Errorf("unknown storage: %q", storageName)`.
