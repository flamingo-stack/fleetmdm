Synchronizes devices from the Apple DEP service by managing fetch/sync cursor operations with configurable run modes (once or continuous).

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Syncer` | struct | Core struct managing DEP device fetch/sync lifecycle |
| `CursorStorage` | interface | Persistent storage for DEP cursor state (`RetrieveCursor`, `StoreCursor`) |
| `DeviceResponseCallback` | type | Hook invoked after each fetch or sync operation completes |
| `NewSyncer` | func | Constructor accepting a `godep.Client`, DEP name, storage, and variadic options |
| `Run` | method | Starts the fetch/sync loop; handles cursor exhaustion, expiry, and context cancellation |
| `WithLogger` | option | Sets a custom logger |
| `WithDuration` | option | Enables continuous mode with a tick interval |
| `WithSyncNow` | option | Channel to trigger an immediate sync mid-wait |
| `WithLimit` | option | Caps devices returned per fetch/sync call |
| `WithCallback` | option | Registers a `DeviceResponseCallback` |

## Usage Example

```go
package main

import (
    "context"
    "log"
    "time"

    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/godep"
    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/sync"
)

func main() {
    client := godep.NewClient(/* transport */)
    store  := myCursorStorage{} // implements CursorStorage

    syncNow := make(chan struct{})

    syncer := sync.NewSyncer(
        client,
        "my-dep-name",
        store,
        sync.WithDuration(5*time.Minute),   // continuous mode
        sync.WithSyncNow(syncNow),           // allow on-demand triggers
        sync.WithLimit(100),
        sync.WithCallback(func(ctx context.Context, isFetch bool, resp *godep.DeviceResponse) error {
            log.Printf("devices received: %d (fetch=%v)", len(resp.Devices), isFetch)
            return nil
        }),
    )

    if err := syncer.Run(context.Background()); err != nil {
        log.Fatal(err)
    }
}
```

**Run modes:**

- **Run once** — omit `WithDuration` (or pass `0`); `Run` returns after one full fetch→sync cycle.
- **Continuous** — provide a non-zero `WithDuration`; `Run` loops indefinitely, waiting between cycles or unblocking early via the `syncNow` channel or context cancellation.
