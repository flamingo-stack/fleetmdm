A no-operation logger implementation that satisfies the `Logger` interface without producing any output, useful for testing or disabling logging.

## Key Components

- **`nopLogger`** — Private struct implementing the `Logger` interface with all methods as no-ops
- **`Info`** — Accepts variadic arguments and discards them
- **`Debug`** — Accepts variadic arguments and discards them
- **`With`** — Accepts variadic context arguments and returns the same `nopLogger` instance
- **`NopLogger`** — Exported package-level singleton instance of `nopLogger`

## Usage Example

```go
// Use NopLogger to silence logging in tests or optional logger fields
logger := log.NopLogger

logger.Info("this message is discarded")
logger.Debug("this too")

// With returns the same nop logger — safe for chaining
contextLogger := logger.With("key", "value")
contextLogger.Info("still discarded")
```

## Notes

- `nopLogger` is a zero-allocation singleton; all method calls are no-ops and return immediately
- The `With` method returns the receiver itself, maintaining interface compatibility without allocating a new logger
- This package embeds (not imports) the logger interface from [`jessepeterson/go-log`](https://github.com/jessepeterson/go-log) — see the [source](https://github.com/flamingo-stack/fleetmdm/blob/main/pkg/log/nop.go) for the full context
