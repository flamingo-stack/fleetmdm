Defines the core `Logger` interface for structured, leveled, and nestable logging used throughout the FleetMDM codebase.

## Key Components

### `Logger` Interface
The primary interface all loggers must implement:

| Method | Description |
|--------|-------------|
| `Info(...interface{})` | Logs a message at the info level |
| `Debug(...interface{})` | Logs a message at the debug level |
| `With(...interface{}) Logger` | Returns a new nested logger with additional context key-value pairs |

## Usage Example

```go
// Implement the Logger interface
type myLogger struct{ /* ... */ }

func (l *myLogger) Info(args ...interface{})          { /* ... */ }
func (l *myLogger) Debug(args ...interface{})         { /* ... */ }
func (l *myLogger) With(args ...interface{}) Logger   { /* ... */ }

// Add context and log
logger := newMyLogger()
childLogger := logger.With("component", "enrollment", "host_id", 42)
childLogger.Info("host enrolled successfully")
childLogger.Debug("enrollment payload received")
```

## Notes

- This package is **embedded** (not imported) from [`jessepeterson/go-log`](https://github.com/jessepeterson/go-log)
- Use `With` to propagate contextual fields (e.g. request IDs, host identifiers) into sub-loggers rather than repeating them on every call
