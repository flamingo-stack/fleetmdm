Adapts Go's standard library `log.Logger` to the NanoDEP `log.Logger` interface, enabling structured key-value logging with info/debug levels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Logger` | struct | Wraps `*log.Logger` with context state and debug toggle |
| `New` | func | Constructs a `Logger` from an existing `*log.Logger` and debug flag |
| `Info` | method | Logs at `level=info` with accumulated context |
| `Debug` | method | Logs at `level=debug` only when `logDebug` is `true` |
| `With` | method | Returns a new `Logger` with additional key-value context appended |

## Usage Example

```go
import (
    stdlog "log"
    "os"

    "github.com/flamingo-stack/fleetmdm/server/mdm/nanodep/log/stdlogfmt"
)

base := stdlog.New(os.Stderr, "", stdlog.LstdFlags)

// Create logger with debug enabled
logger := stdlogfmt.New(base, true)

// Add persistent context fields
logger = logger.With("component", "dep-sync", "org", "acme").(*stdlogfmt.Logger)

// Structured output: level=info component=dep-sync org=acme msg=started
logger.Info("msg", "started")

// Only emits when logDebug=true
logger.Debug("msg", "fetching devices", "count", 42)
```

## Notes

- Output format is space-separated `key=value` pairs (e.g., `level=info component=dep msg=ok`)
- Odd-length argument lists append a trailing `UNKNOWN=<value>` field rather than panicking
- `With` copies context by reference — context slices are not deep-copied, so append-safe patterns are used via variadic accumulation
- Satisfies the [`log.Logger`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/nanodep/log/log.go) interface from the NanoDEP package
