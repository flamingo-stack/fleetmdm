Provides context-aware logging by associating key-value generator functions with a `context.Context` and applying them to a logger at call time.

## Key Components

- **`CtxKVFunc`** — Function type `func(context.Context) []interface{}` that extracts key-value pairs from a context for log enrichment.
- **`AddFunc(ctx, f)`** — Attaches a `CtxKVFunc` to the context; multiple functions can be chained. Thread-safe via `sync.RWMutex`.
- **`Logger(ctx, logger)`** — Executes all registered `CtxKVFunc` functions and returns a new `log.Logger` enriched with the accumulated key-value pairs.
- **`SimpleStringFunc(logKey, ctxKey)`** — Convenience factory that returns a `CtxKVFunc` emitting a single `logKey`/value pair when a string is found under `ctxKey` on the context.

## Usage Example

```go
// Define a context key for a request ID
type ctxKeyRequestID struct{}

// Register a logging function at request ingress
ctx = ctxlog.AddFunc(ctx, ctxlog.SimpleStringFunc("request_id", ctxKeyRequestID{}))

// Store the value somewhere in the call chain
ctx = context.WithValue(ctx, ctxKeyRequestID{}, "abc-123")

// Enrich the logger before writing a log entry
enriched := ctxlog.Logger(ctx, baseLogger)
enriched.Log("msg", "processing request")
// Output includes: request_id=abc-123 msg="processing request"
```

## Notes

- `AddFunc` is safe to call with a `nil` context; it returns the context unchanged.
- The internal `funcs` slice is protected by `sync.RWMutex`, making concurrent reads (via `Logger`) and writes (via `AddFunc`) safe.
- Functions should be lightweight—`Logger` invokes every registered `CtxKVFunc` on each call.
