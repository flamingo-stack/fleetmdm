Implements a MicroMDM-compatible webhook client that posts DEP (Device Enrollment Program) sync and fetch events as JSON payloads to a configured URL.

## Key Components

| Name | Type | Description |
|---|---|---|
| `Event` | struct | Top-level webhook payload matching the MicroMDM webhook schema, containing topic, event ID, timestamp, and device response data |
| `DeviceResponseEvent` | struct | Nested payload holding the DEP profile name and the raw `godep.DeviceResponse` from a sync or fetch operation |
| `Webhook` | struct | HTTP client wrapper holding the target URL and an `*http.Client` |
| `NewWebhook` | func | Constructor that initializes a `Webhook` with the given URL and `http.DefaultClient` |
| `CallWebhook` | method | Builds the event payload, marshals it to JSON, and POSTs it to the configured URL |

## Usage Example

```go
wh := NewWebhook("https://example.com/mdm/webhook")

resp := &godep.DeviceResponse{ /* ... */ }

if err := wh.CallWebhook(ctx, "my-dep-server", true, resp); err != nil {
    log.Fatalf("webhook call failed: %v", err)
}
```

`isFetch = true` sets the topic to `dep.FetchDevices`; `false` uses `dep.SyncDevices`, mirroring the MicroMDM webhook convention documented at [micromdm/micromdm](https://github.com/micromdm/micromdm/blob/main/docs/user-guide/api-and-webhooks.md).

## Notes

- Returns an error if the response status is anything other than `200 OK`.
- Passes the provided `context.Context` through to the HTTP request, enabling timeout and cancellation propagation.
- Source: [`webhook.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/webhook.go)
