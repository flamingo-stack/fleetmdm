Entry point for the `depsync` CLI tool that continuously synchronizes Apple DEP (Device Enrollment Program) device data by running one or more named DEP syncers in parallel.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `version` | `var` | Build-time version string, overridden via `-ldflags -X` |
| `defaultDuration` | `const` | Default interval between DEP syncs (30 minutes) |
| `main` | `func` | Parses CLI flags, initializes storage/webhook/syncers, and manages the sync lifecycle |

**CLI Flags:**

| Flag | Default | Description |
|------|---------|-------------|
| `-version` | `false` | Print build version and exit |
| `-duration` | `1800` | Seconds between syncs; `0` = single run |
| `-limit` | `0` | Max devices per fetch/sync call |
| `-debug` | `false` | Enable debug logging |
| `-debug-assigner` | `false` | Extra assigner debug logging |
| `-storage` | `"file"` | Storage backend type |
| `-storage-dsn` | `""` | Storage connection string |
| `-webhook-url` | `""` | Optional URL for device event callbacks |

**Signal Handling:**
- `SIGHUP` — triggers an immediate sync across all running syncers
- `SIGINT` / `SIGTERM` — cancels the root context, gracefully stopping all syncers

## Usage Example

```bash
# Run a continuous sync every 10 minutes for two DEP tokens
./depsync -duration 600 -storage file -storage-dsn ./data org1 org2

# Trigger an immediate sync without waiting for the interval
kill -HUP <pid>

# Single one-shot sync with webhook notifications
./depsync -duration 0 -webhook-url https://hooks.example.com/dep org1
```
