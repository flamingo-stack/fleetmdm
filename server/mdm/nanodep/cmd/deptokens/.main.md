CLI tool for generating RSA keypairs and decrypting Apple DEP token files used in MDM enrollment workflows.

## Key Components

| Function | Description |
|---|---|
| `main` | Entry point; routes to keypair generation or token decryption based on flags |
| `generateKeyPair` | Creates a self-signed RSA certificate/key pair and writes them to disk |
| `decryptTokens` | Reads and decrypts an Apple DEP `.p7m` token file using a local cert/key pair |
| `encodeEncryptedKeyPEM` | Serializes an RSA private key to PEM, optionally encrypting with 3DES |
| `decodeEncryptedKeyPEM` | Parses a PEM private key from bytes, optionally decrypting with a password |

## CLI Flags

| Flag | Default | Description |
|---|---|---|
| `-cert` | `cert.pem` | Path to certificate file |
| `-key` | `cert.key` | Path to private key file |
| `-password` | `""` | Password for encrypting/decrypting the private key |
| `-token` | `""` | Path to DEP token file (triggers decrypt mode) |
| `-f` | `false` | Force overwrite existing keypair |
| `-version` | `false` | Print binary version |

## Usage Example

```bash
# Generate a new keypair (clear-text key)
./deptokens -cert cert.pem -key cert.key

# Generate a new keypair with encrypted private key
./deptokens -cert cert.pem -key cert.key -password mysecret

# Force overwrite an existing keypair
./deptokens -cert cert.pem -key cert.key -password mysecret -f

# Decrypt a DEP token file and print JSON to stdout
./deptokens -cert cert.pem -key cert.key -password mysecret -token tokens.p7m
```

## Notes

- When no `-token` flag is provided, the tool runs in **keypair generation mode**.
- When `-token` is provided, the tool runs in **token decryption mode**, outputting the decrypted JSON to stdout.
- Omitting `-password` during generation prints a warning; the private key is stored in clear text.
