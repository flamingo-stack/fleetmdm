Entry point for the `depserver` HTTP server, which proxies and manages Apple Device Enrollment Program (DEP) tokens, configurations, and PKI operations via a REST API.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | func | Parses flags, initializes storage and HTTP routes, starts the server |
| `newTraceID` | func | Generates a random 8-byte hex string for HTTP request tracing |
| `DelHeaderMiddleware` | func | Middleware that strips a named header (e.g., `Authorization`) before passing the request downstream |
| `handleStrippedAPI` | closure | Registers a handler with prefix-stripping and Basic Auth applied |
| `endpointProxy` | const | Route prefix (`/proxy/`) for proxying requests to Apple DEP |
| `endpointTokenPKI` | const | Route prefix (`/v1/tokenpki/`) for certificate/token PKI operations |

## CLI Flags

| Flag | Default | Description |
|------|---------|-------------|
| `-debug` | `false` | Enable debug logging |
| `-listen` | `:9001` | HTTP listen address |
| `-api` | _(required)_ | API key for Basic Auth |
| `-storage` | `file` | Storage backend type |
| `-storage-dsn` | `""` | Storage data source name |
| `-version` | `false` | Print version and exit |

## Usage Example

```bash
# Start the server with a file-based storage backend
depserver -api "supersecretkey" -listen ":9001" -storage file -storage-dsn "/var/lib/depserver"

# Enable debug logging
depserver -api "supersecretkey" -debug

# Print version
depserver -version
```

```go
// DelHeaderMiddleware usage — strip Authorization before proxying
handler = DelHeaderMiddleware(handler, "Authorization")

// newTraceID — attach a random trace ID per request
id := newTraceID() // e.g. "a3f2c1b4e5d60789"
```

All API endpoints require HTTP Basic Auth with username `depserver` and the configured `-api` key.
