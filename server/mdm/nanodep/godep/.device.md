Go client implementation for Apple Device Enrollment Program (DEP) device management, providing methods to fetch, sync, and retrieve device details via the Apple DEP API.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Device` | Maps to Apple DEP API `Device` structure with serial number, model, profile status, and assignment metadata |
| `DeviceResponse` | Paginated response containing a device list, cursor, and `more_to_follow` flag |
| `DeviceRequestOption` | Functional option type for configuring fetch/sync requests |

### Client Methods

| Method | Description |
|--------|-------------|
| `FetchDevices` | Retrieves the full device list for a DEP server via `POST /server/devices` |
| `SyncDevices` | Gets incremental device updates via `POST /devices/sync` |
| `GetDeviceDetails` | Fetches details for a single device by serial number via `POST /devices` |

### Option Constructors

| Function | Description |
|----------|-------------|
| `WithCursor(cursor string)` | Includes a pagination cursor in the request |
| `WithLimit(limit int)` | Sets the device count per page (default: 100, max: 1000) |

### Cursor Error Helpers

| Function | Description |
|----------|-------------|
| `IsCursorExhausted` | Returns `true` if the cursor has been fully consumed |
| `IsCursorInvalid` | Returns `true` if the cursor value is invalid |
| `IsCursorExpired` | Returns `true` if the cursor is older than 7 days |

## Usage Example

```go
// Initial fetch — no cursor needed
resp, err := client.FetchDevices(ctx, "my-dep-server", WithLimit(500))
if err != nil {
    log.Fatal(err)
}

// Paginate using the returned cursor
for resp.MoreToFollow {
    resp, err = client.FetchDevices(ctx, "my-dep-server",
        WithCursor(resp.Cursor),
        WithLimit(500),
    )
    if err != nil {
        if IsCursorExpired(err) {
            // Restart from scratch — cursor is older than 7 days
        }
        log.Fatal(err)
    }
}

// Sync incremental changes using the last cursor
syncResp, err := client.SyncDevices(ctx, "my-dep-server", WithCursor(resp.Cursor))

// Fetch a single device by serial number
device, err := client.GetDeviceDetails(ctx, "my-dep-server", "C02XJ0AAJGH7")
```
