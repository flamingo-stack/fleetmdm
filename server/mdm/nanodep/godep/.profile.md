Apple DEP profile management for the `godep` package, providing structs and client methods to define, assign, and retrieve DEP enrollment profiles via the Apple Device Enrollment Program API.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `Profile` | Maps to the Apple DEP API `Profile` structure — holds enrollment configuration including MDM URL, supervision settings, setup skip items, and device lists |
| `ProfileResponse` | Maps to Apple's `AssignProfileResponse` — returns the profile UUID and a map of device serial numbers to assignment status strings |

### Client Methods

| Method | HTTP | Endpoint | Description |
|--------|------|----------|-------------|
| `AssignProfile` | `PUT` | `/profile/devices` | Assigns a DEP profile UUID to one or more device serial numbers |
| `DefineProfile` | `POST` | `/profile` | Creates/defines a new DEP profile on Apple's servers |
| `GetProfile` | `GET` | `/profile?profile_uuid=...` | Retrieves raw profile details for a given profile UUID |

## Usage Example

```go
client := godep.NewClient(/* config */)
ctx := context.Background()

// Define a new DEP profile
profile := &godep.Profile{
    ProfileName:     "Corporate MDM",
    URL:             "https://mdm.example.com/enroll",
    IsSupervised:    true,
    IsMandatory:     true,
    IsMDMRemovable:  false,
    SkipSetupItems:  []string{"AppleID", "Siri"},
}
defineResp, err := client.DefineProfile(ctx, "myDEPName", profile)
if err != nil {
    log.Fatal(err)
}

// Assign the profile to devices by serial number
assignResp, err := client.AssignProfile(
    ctx,
    "myDEPName",
    defineResp.ProfileUUID,
    "SERIAL001", "SERIAL002",
)

// Retrieve raw profile details
raw, err := client.GetProfile(ctx, "myDEPName", defineResp.ProfileUUID)
```

> **Note:** `AssignProfile` uses `HTTP PUT` instead of the modern `HTTP POST` for compatibility with the DEP simulator (`depsim`). `AwaitDeviceConfigured` is intentionally omitted from stored profiles — it is always forced to `true` when registering with Apple.
