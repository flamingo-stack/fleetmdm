Implements Apple DEP Account-Driven Enrollment API interactions, providing methods to fetch and assign MDM service discovery URLs for account-driven device enrollment.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `AccountDrivenEnrollmentProfileResponse` | Response struct containing the MDM service discovery URL and last updated timestamp |

### Methods

| Method | Description |
|--------|-------------|
| `FetchAccountDrivenEnrollmentServiceDiscovery` | Fetches the MDM service discovery URL and last updated time via `GET /account-driven-enrollment/profile` |
| `AssignAccountDrivenEnrollmentServiceDiscovery` | Assigns an MDM service discovery URL via `POST /account-driven-enrollment/profile` |

### Error Helpers

| Function | Description |
|----------|-------------|
| `IsServiceDiscoveryNotFound` | Returns `true` when Apple returns `404 NOT_FOUND` (service discovery URL not found) |
| `IsServiceDiscoveryNotSupported` | Returns `true` when Apple returns `400 ORG_NOT_SUPPORTED` (organization not eligible for account-driven enrollment) |

## Usage Example

```go
client := godep.NewClient(...)

// Fetch the current service discovery profile
profile, err := client.FetchAccountDrivenEnrollmentServiceDiscovery(ctx, "org-name")
if err != nil {
    if godep.IsServiceDiscoveryNotFound(err) {
        // No profile assigned yet
    }
    if godep.IsServiceDiscoveryNotSupported(err) {
        // Org not eligible for account-driven enrollment
    }
    return err
}
fmt.Println(profile.MDMServiceDiscoveryURL, profile.LastUpdatedTimestamp)

// Assign a new service discovery URL
err = client.AssignAccountDrivenEnrollmentServiceDiscovery(ctx, "org-name", "https://mdm.example.com/.well-known/mdm-enrollment")
```
