HTTP client implementation for communicating with Apple's Device Enrollment Program (DEP) APIs, handling authentication, session management, and JSON serialization/deserialization.

## Key Components

- **`HTTPError`** — Structured error type capturing the HTTP response body, status string, and status code from failed DEP API requests.
- **`NewHTTPError(r *http.Response)`** — Constructs an `HTTPError` by reading the full response body.
- **`httpErrorContains` / `authErrorContains`** — Helper functions for inspecting error types and matching body content and status codes.
- **`ClientStorage`** — Interface combining `AuthTokensRetriever` and `ConfigRetriever` from the NanoDEP client package, providing the credentials and config needed to connect to the DEP API.
- **`Client`** — Core struct wrapping the NanoDEP-authenticated HTTP client with optional post-request hook support.
- **`WithAfterHook`** — Functional option that registers a callback invoked after every request (success or failure), useful for logging or error transformation.
- **`NewClient`** — Constructor that wraps the provided `*http.Client` with NanoDEP's transport layer for transparent auth and session handling.
- **`do`** — Internal method that marshals input to JSON, builds the authenticated request, executes it, handles HTTP errors, and unmarshals the response body.

## Usage Example

```go
store := myClientStorage // implements ClientStorage

// Optional: log or transform errors after every request
hook := func(ctx context.Context, err error) error {
    if err != nil {
        log.Printf("DEP request error: %v", err)
    }
    return err
}

client := godep.NewClient(store, nil, godep.WithAfterHook(hook))

// The client is now ready to make authenticated DEP API calls
// via higher-level methods that call client.doWithAfterHook internally.
```
