Provides utilities for generating and encoding RSA keypairs and X.509 certificates within the `tokenpki` package, supporting self-signed certificate creation and PEM serialization/deserialization.

## Key Components

| Function | Description |
|---|---|
| `SelfSignedRSAKeypair` | Generates a 2048-bit RSA key and self-signed X.509 cert with configurable CN and validity period |
| `PEMRSAPrivateKey` | Encodes an `*rsa.PrivateKey` to PKCS#1 PEM format |
| `RSAKeyFromPEM` | Decodes a PEM-encoded RSA private key back to `*rsa.PrivateKey` |
| `PEMCertificate` | Encodes raw DER certificate bytes to PEM format |
| `CertificateFromPEM` | Decodes a PEM certificate to `*x509.Certificate` |

## Usage Example

```go
// Generate a self-signed cert valid for 365 days
key, cert, err := tokenpki.SelfSignedRSAKeypair("my-service.example.com", 365)
if err != nil {
    log.Fatal(err)
}

// Serialize for storage or transport
pemKey := tokenpki.PEMRSAPrivateKey(key)
pemCert := tokenpki.PEMCertificate(cert.Raw)

// Reload from PEM
restoredKey, err := tokenpki.RSAKeyFromPEM(pemKey)
restoredCert, err := tokenpki.CertificateFromPEM(pemCert)
```

> **Note:** `SelfSignedRSAKeypair` backdates `NotBefore` by 10 minutes to account for clock skew. The certificate uses `KeyEncipherment` and `DigitalSignature` key usages, making it suitable for TLS and token-signing scenarios.
