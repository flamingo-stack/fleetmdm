HTTP handlers and middleware utilities for the NanoDEP MDM server, providing request body management, authentication, versioning, and trace logging.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ReadAllAndReplaceBody` | Function | Reads the full request body and replaces it with a reusable buffer |
| `BasicAuthMiddleware` | Middleware | Enforces HTTP Basic Auth with constant-time comparison to prevent timing attacks |
| `VersionHandler` | Handler | Returns a JSON version response |
| `TraceLoggingMiddleware` | Middleware | Injects a trace ID into request context and logs incoming HTTP request metadata |

## Usage Example

```go
mux := http.NewServeMux()

// Protect a handler with Basic Auth
protected := BasicAuthMiddleware(mux, "admin", "secret", "NanoDEP")

// Add trace logging around the protected handler
logged := TraceLoggingMiddleware(protected, logger, func() string {
    return uuid.New().String()
})

// Expose a version endpoint
mux.Handle("/version", VersionHandler("1.2.3"))

http.ListenAndServe(":8080", logged)
```

```go
// Read and reuse a request body in a handler
body, err := ReadAllAndReplaceBody(r)
if err != nil {
    http.Error(w, "failed to read body", http.StatusBadRequest)
    return
}
// r.Body is still readable by downstream handlers
```

## Notes

- `BasicAuthMiddleware` uses `crypto/subtle.ConstantTimeCompare` to prevent timing-based credential enumeration.
- `TraceLoggingMiddleware` logs `addr`, `method`, `path`, `agent`, and optionally `x_forwarded_for`, storing the trace ID in context for downstream use via `ctxlog`.
