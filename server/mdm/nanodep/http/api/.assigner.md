HTTP handlers for managing DEP (Device Enrollment Program) assigner profile UUIDs, supporting both retrieval and storage operations via the NanoDEP API.

## Key Components

| Component | Type | Description |
|---|---|---|
| `RetrieveAssignerProfileHandler` | `http.HandlerFunc` | Returns the assigner profile UUID for a given DEP name |
| `StoreAssignerProfileHandler` | `http.HandlerFunc` | Saves an assigner profile UUID for a given DEP name |
| `AssignerProfileStorer` | Interface | Defines `StoreAssignerProfile(ctx, name, profileUUID)` contract |

## Usage Example

```go
mux := http.NewServeMux()

// Strip the route prefix so the remaining path is treated as the DEP name
mux.Handle("/v1/assigner/", http.StripPrefix("/v1/assigner",
    api.RetrieveAssignerProfileHandler(store, logger),
))

mux.Handle("/v1/assigner/", http.StripPrefix("/v1/assigner",
    api.StoreAssignerProfileHandler(store, logger),
))
```

**Retrieve profile:**
```bash
GET /v1/assigner/my-dep-name
# Response: {"profile_uuid":"abc-123"}
```

**Store profile:**
```bash
PUT /v1/assigner/my-dep-name?profile_uuid=abc-123
# Response: {"profile_uuid":"abc-123"}
```

## Notes

- The **entire URL path** after prefix stripping is treated as the DEP name — prefix stripping via `http.StripPrefix` is required before mounting these handlers.
- Both handlers return `400 Bad Request` if the DEP name (path) or `profile_uuid` query parameter is missing.
- Errors are surfaced directly in the JSON response body, as these endpoints target API consumers rather than end users.
