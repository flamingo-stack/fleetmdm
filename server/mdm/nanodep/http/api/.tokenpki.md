HTTP handlers for the Apple DEP (Device Enrollment Program) Token PKI exchange flow, enabling certificate generation and encrypted token decryption for ABM/ASM/BE portal integration.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `TokenPKIRetriever` | Interface | Retrieves stored PEM certificate and private key by DEP name |
| `TokenPKIStorer` | Interface | Persists a PEM certificate and private key by DEP name |
| `GetCertTokenPKIHandler` | `http.HandlerFunc` | Generates a self-signed RSA keypair, stores it, and returns the PEM certificate |
| `DecryptTokenPKIHandler` | `http.HandlerFunc` | Decrypts an Apple-provided `.p7m` token file and stores the resulting OAuth1 tokens |

**Constants:**
- `defaultCN` — certificate Common Name (`"depserver"`)
- `defaultDays` — certificate validity period (`1` day)

## Usage Example

```go
mux := http.NewServeMux()

// Strip the route prefix so r.URL.Path equals the DEP name
mux.Handle("/cert/", http.StripPrefix("/cert",
    api.GetCertTokenPKIHandler(myStore, logger),
))

// POST the Apple-encrypted .p7m file to this endpoint
mux.Handle("/decrypt/", http.StripPrefix("/decrypt",
    api.DecryptTokenPKIHandler(myStore, myTokenStore, logger),
))
```

**Flow:**
1. `GET /cert/{dep-name}` — generates a fresh RSA keypair, persists it, returns `depserver.pem` for upload to the ABM portal.
2. `POST /decrypt/{dep-name}` — accepts the encrypted `.p7m` token returned by Apple, decrypts it with the stored keypair, validates the OAuth1 tokens, persists them, and echoes them as JSON.

> The full `r.URL.Path` is used as the DEP name, so the route prefix **must** be stripped before delegating to either handler (e.g. via `http.StripPrefix`).
