HTTP handlers for managing Apple DEP (Device Enrollment Program) OAuth1 authentication tokens via the NanoDEP API.

## Key Components

| Component | Type | Description |
|---|---|---|
| `AuthTokensStorer` | Interface | Defines `StoreAuthTokens` for persisting OAuth1 tokens by DEP name |
| `RetrieveAuthTokensHandler` | `http.HandlerFunc` | Returns OAuth1 tokens for a given DEP name as JSON |
| `StoreAuthTokensHandler` | `http.HandlerFunc` | Accepts and persists OAuth1 tokens from a JSON request body |

## Usage Example

```go
mux := http.NewServeMux()

// Strip the route prefix so the remaining path is treated as the DEP name
mux.Handle("/v1/tokens/", http.StripPrefix("/v1/tokens",
    api.RetrieveAuthTokensHandler(tokenStore, logger),
))

mux.Handle("/v1/tokens/", http.StripPrefix("/v1/tokens",
    api.StoreAuthTokensHandler(tokenStore, logger),
))
```

## Notes

- The **full URL path** (after prefix stripping) is used as the DEP name — callers must strip the route prefix with `http.StripPrefix` before mounting these handlers.
- `StoreAuthTokensHandler` validates tokens via `tokens.Valid()` before persisting, returning `400 Bad Request` for invalid payloads.
- Both handlers use `ctxlog` for context-aware structured logging and return JSON-encoded errors via `jsonError` for API-friendly error responses.
- `RetrieveAuthTokensHandler` depends on `client.AuthTokensRetriever` (defined in the NanoDEP client package); `StoreAuthTokensHandler` uses the locally defined `AuthTokensStorer` interface.
