HTTP error response utility for the NanoDEP API package, providing a standardized JSON error writer for HTTP handlers.

## Key Components

- **`jsonError(w http.ResponseWriter, err error)`** — Internal helper that serializes a Go `error` to a JSON `{"error": "..."}` response body, sets the `Content-Type` header to `application/json`, and responds with HTTP `500 Internal Server Error`.

## Usage Example

```go
func myHandler(w http.ResponseWriter, r *http.Request) {
    data, err := doSomething()
    if err != nil {
        jsonError(w, err)
        return
    }
    // handle success...
}
```

## Notes

- `jsonError` is unexported (lowercase), so it is only available within the `api` package.
- The response body format is always `{"error": "<message>"}`.
- Encode errors are explicitly discarded (`_ =`) since the response is already committed at that point.
