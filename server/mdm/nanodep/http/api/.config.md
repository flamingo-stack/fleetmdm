Provides HTTP handler functions for retrieving and storing Apple DEP (Device Enrollment Program) server configuration via a NanoDEP API.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `RetrieveConfigHandler` | `func` | HTTP handler that fetches DEP server config for a named DEP instance |
| `ConfigStorer` | `interface` | Defines the `StoreConfig` method for persisting DEP configuration |
| `StoreConfigHandler` | `func` | HTTP handler that decodes and persists DEP server config for a named DEP instance |

## Usage Example

```go
mux := http.NewServeMux()

// Strip the route prefix so the remaining path becomes the DEP name
mux.Handle("/dep/config/", http.StripPrefix("/dep/config",
    api.RetrieveConfigHandler(configStore, logger),
))

mux.Handle("/dep/config/store/", http.StripPrefix("/dep/config/store",
    api.StoreConfigHandler(configStore, logger),
))
```

**Request / Response flow:**

```text
GET  /dep/config/my-org   → returns JSON-encoded client.Config for "my-org"
POST /dep/config/store/my-org  → decodes JSON body into client.Config,
                                 persists it, returns stored config as JSON
```

## Notes

- The full URL path (after prefix stripping) is used as the **DEP name** — an empty path returns `400 Bad Request`.
- Both handlers surface Go errors directly in JSON responses, as they target internal API consumers.
- `ConfigStorer` is a narrow write-only interface; read access is handled by `client.ConfigRetriever` from the NanoDEP client package.
