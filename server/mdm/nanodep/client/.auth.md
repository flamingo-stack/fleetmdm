Handles Apple DEP (Device Enrollment Program) OAuth1 authentication, including token validation, authorization header signing, and session token retrieval from the DEP `/session` endpoint.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `AuthError` | struct | Encapsulates HTTP error responses from the `/session` endpoint, including body, status text, and status code |
| `OAuth1Tokens` | struct | Holds the four OAuth1 credentials (consumer key/secret, access token/secret) plus token expiry |
| `OAuth1Tokens.Valid()` | method | Sanity-checks that all four credential fields are non-empty |
| `NewAuthError` | func | Constructs an `AuthError` by reading the response body; caller must ensure `Body` is closed |
| `SetAuthorizationHeader` | func | Signs an `*http.Request` with HMAC-SHA1 OAuth1 credentials per Apple's DEP spec |
| `DoAuth` | func | Orchestrates a full DEP auth round-trip: signs the request, executes it, and returns the `auth_session_token` |
| `ErrEmptyAuthSessionToken` | error | Sentinel returned when the session response is valid JSON but contains an empty token |

## Usage Example

```go
tokens := &client.OAuth1Tokens{
    ConsumerKey:    "my-consumer-key",
    ConsumerSecret: "my-consumer-secret",
    AccessToken:    "my-access-token",
    AccessSecret:   "my-access-secret",
}

if !tokens.Valid() {
    log.Fatal("invalid DEP OAuth1 tokens")
}

req, err := http.NewRequest(http.MethodGet, "https://mdmenrollment.apple.com/session", nil)
if err != nil {
    log.Fatal(err)
}

sessionToken, err := client.DoAuth(http.DefaultClient, req, tokens)
if errors.Is(err, client.ErrEmptyAuthSessionToken) {
    log.Fatal("DEP returned empty session token")
}
if err != nil {
    log.Fatal(err)
}

fmt.Println("Session token:", sessionToken)
```

## Notes

- HMAC-SHA1 is hardcoded as the signature method — required by Apple's DEP API.
- `Content-Type` defaults to `application/json;charset=UTF8` when unset, satisfying the `depsim` simulator requirement.
- See the full implementation at [`https://github.com/flamingo-stack/fleetmdm/blob/main/auth.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/auth.go).
