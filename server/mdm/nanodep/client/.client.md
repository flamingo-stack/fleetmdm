HTTP primitives and configuration management for communicating with the Apple DEP (Device Enrollment Program) MDM enrollment APIs.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DefaultBaseURL` | Constant | Default Apple MDM enrollment endpoint (`https://mdmenrollment.apple.com/`) |
| `Doer` | Interface | Abstraction over `http.Client` for executing HTTP requests |
| `Config` | Struct | DEP name configuration holding the `BaseURL` |
| `ConfigRetriever` | Interface | Retrieves a `Config` by DEP name |
| `DefaultConfigRetreiver` | Struct | Wraps a `ConfigRetriever`, falling back to `DefaultBaseURL` if config is empty |
| `RetrieveAndResolveURL` | Function | Resolves a full DEP request URL from a name, store, and relative path |
| `NewRequestWithContext` | Function | Builds an `*http.Request` for a DEP endpoint, attaching the DEP name to the context |
| `NewClient` | Function | Returns a copy of an `*http.Client` with a custom `RoundTripper` set |

## Usage Example

```go
// Implement ConfigRetriever for your storage backend
type myStore struct{}

func (s *myStore) RetrieveConfig(ctx context.Context, name string) (*client.Config, error) {
    // Return nil to fall back to DefaultBaseURL
    return nil, nil
}

store := &myStore{}

// Build a DEP HTTP request for the "account" endpoint
req, err := client.NewRequestWithContext(
    context.Background(),
    "my-dep-name",
    store,
    http.MethodGet,
    "account",
    nil,
)
if err != nil {
    log.Fatal(err)
}

// Attach a custom transport (e.g., OAuth token injection)
httpClient := client.NewClient(http.DefaultClient, myTransport)
resp, err := httpClient.Do(req)
```

## Notes

- `DefaultConfigRetreiver` wraps any `ConfigRetriever` and ensures a non-empty `BaseURL` is always returned, making it safe to use without explicit base URL configuration.
- The DEP name is stored in the request context via `WithName` for downstream middleware (e.g., authentication handlers) to retrieve.
