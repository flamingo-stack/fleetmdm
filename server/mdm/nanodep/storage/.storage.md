Defines the unified storage interface for the NanoDEP MDM integration, aggregating all required storage capabilities into a single interface.

## Key Components

### `ErrNotFound`
Sentinel error returned when a requested resource does not exist in storage.

### `AllDEPStorage` Interface
Composite interface combining all storage operations required by NanoDEP. It embeds:

| Embedded Interface | Source Package | Purpose |
|---|---|---|
| `client.AuthTokensRetriever` | `nanodep/client` | Retrieve DEP auth tokens |
| `client.ConfigRetriever` | `nanodep/client` | Retrieve DEP client config |
| `sync.AssignerProfileRetriever` | `nanodep/sync` | Retrieve assigner profile for sync |
| `sync.CursorStorage` | `nanodep/sync` | Read/write sync cursor state |
| `api.AuthTokensStorer` | `nanodep/http/api` | Store DEP auth tokens |
| `api.ConfigStorer` | `nanodep/http/api` | Store DEP client config |
| `api.TokenPKIStorer` | `nanodep/http/api` | Store token PKI data |
| `api.TokenPKIRetriever` | `nanodep/http/api` | Retrieve token PKI data |
| `api.AssignerProfileStorer` | `nanodep/http/api` | Store assigner profile |

> **Note:** Renamed from `AllStorage` to `AllDEPStorage` to prevent naming conflicts with the `nanomdm` `AllStorage` interface, which caused resolution issues in the mock implementation tooling.

## Usage Example

```go
// Implement AllDEPStorage to back the NanoDEP stack
type MyDEPStore struct{}

// Satisfies all embedded interfaces
var _ storage.AllDEPStorage = (*MyDEPStore)(nil)

func NewDEPServer(store storage.AllDEPStorage) {
    // Pass to sync, client, and API handlers
}

// Handle missing resources
result, err := store.RetrieveConfig(ctx, name)
if errors.Is(err, storage.ErrNotFound) {
    // handle missing config
}
```
