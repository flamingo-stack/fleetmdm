Filesystem-based storage backend for Apple DEP (Device Enrollment Program) services, implementing the `storage.AllDEPStorage` interface by persisting OAuth tokens, configuration, profiles, cursors, and PKI data as files on disk.

## Key Components

- **`FileStorage`** — Core struct holding the root directory path for all DEP-related files
- **`New(path string)`** — Constructor that creates (or validates) the storage directory and returns a `FileStorage` instance
- **`RetrieveAuthTokens` / `StoreAuthTokens`** — Read/write OAuth1 tokens as JSON (`.tokens.json`)
- **`RetrieveConfig` / `StoreConfig`** — Read/write DEP client config as JSON (`.config.json`); returns empty config if not found
- **`RetrieveAssignerProfile` / `StoreAssignerProfile`** — Read/write assigner profile UUID as plain text (`.profile.txt`), returning file modification time
- **`RetrieveCursor` / `StoreCursor`** — Read/write DEP sync cursor as plain text (`.cursor.txt`)
- **`StoreTokenPKI` / `RetrieveTokenPKI`** — Read/write PEM-encoded certificate and private key files (`.tokenpki.cert.txt` / `.tokenpki.key.txt`)

## Usage Example

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/storage/file"
    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/client"
)

func main() {
    store, err := file.New("/var/lib/nanodep")
    if err != nil {
        log.Fatal(err)
    }

    ctx := context.Background()

    // Store OAuth tokens for a DEP enrollment
    tokens := &client.OAuth1Tokens{
        ConsumerKey:       "key",
        ConsumerSecret:    "secret",
        AccessToken:       "token",
        AccessSecret:      "tokensecret",
    }
    if err := store.StoreAuthTokens(ctx, "my-dep-name", tokens); err != nil {
        log.Fatal(err)
    }

    // Retrieve them later
    retrieved, err := store.RetrieveAuthTokens(ctx, "my-dep-name")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(retrieved.ConsumerKey)
}
```

## Notes

- Missing files return empty/zero values (not errors) for config, profiles, and cursors, enabling safe first-run defaults.
- `storage.ErrNotFound` is returned for missing tokens and PKI data, signaling callers to re-enroll or re-generate credentials.
