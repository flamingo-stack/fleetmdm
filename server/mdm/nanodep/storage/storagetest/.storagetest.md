Provides a reusable test suite for validating `storage.AllDEPStorage` implementations, covering store/retrieve operations for PKI tokens, auth tokens, DEP config, assigner profiles, and cursors.

## Key Components

- **`Run`** — Entry point that executes the full battery of subtests against a `storage.AllDEPStorage` instance provided by a factory function. Subtests include:
  - `empty` — verifies correct zero-value behavior on uninitialized storage
  - `basic` — full store/retrieve round-trip for all storage fields
  - `multiple-names` — validates namespace isolation between two DEP enrollment names
- **`checkTokens`** — Helper that asserts field-by-field equality of two `OAuth1Tokens`, with a 1-second tolerance on expiry timestamps
- **`checkErr`** — Thin `t.Fatal` wrapper for unexpected errors
- **`generatePKI`** — Generates a self-signed RSA keypair and returns PEM-encoded cert and key for use in PKI tests

## Usage Example

```go
package mystorage_test

import (
    "testing"

    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/storage/storagetest"
    "github.com/fleetdm/fleet/v4/server/mdm/nanodep/storage"
)

func TestMyStorage(t *testing.T) {
    storagetest.Run(t, func(t *testing.T) storage.AllDEPStorage {
        // Return a fresh instance of your implementation for each test.
        return NewMyStorage(t)
    })
}
```

The factory function is called once per subtest, ensuring each test case receives a clean storage instance. Tests cover `ErrNotFound` semantics on empty stores, idempotent overwrites, modification time updates, and cursor ordering.
