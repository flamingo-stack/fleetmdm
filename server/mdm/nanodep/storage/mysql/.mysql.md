MySQL-backed storage implementation for NanoDEP (Apple Device Enrollment Program) data, providing CRUD operations for DEP OAuth tokens, configurations, assigner profiles, sync cursors, and PKI certificates.

## Key Components

### Types & Constructor

- **`MySQLStorage`** — Core struct wrapping `*sql.DB`, implements `storage.AllDEPStorage`
- **`Option`** — Functional option type for configuring the storage
- **`New(opts ...Option)`** — Constructor; opens/validates the DB connection
- **`Schema`** — Embedded SQL schema from `schema.sql` via `//go:embed`

### Configuration Options

| Option | Description |
|--------|-------------|
| `WithDSN(dsn string)` | Sets the MySQL data source name |
| `WithDriver(driver string)` | Overrides the default `"mysql"` driver |
| `WithDB(db *sql.DB)` | Injects an existing `*sql.DB` (ignores `WithDriver`) |

### Storage Methods

| Method | Description |
|--------|-------------|
| `RetrieveAuthTokens` / `StoreAuthTokens` | DEP OAuth1 token management |
| `RetrieveConfig` / `StoreConfig` | DEP base URL config |
| `RetrieveAssignerProfile` / `StoreAssignerProfile` | Profile UUID + timestamp |
| `RetrieveCursor` / `StoreCursor` | DEP fetch/sync cursor + timestamp |
| `RetrieveTokenPKI` / `StoreTokenPKI` | PEM certificate and private key |

All writes use `INSERT ... ON DUPLICATE KEY UPDATE` for upsert semantics against the `nano_dep_names` table.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/server/mdm/nanodep/storage/mysql"

// Using DSN
store, err := mysql.New(
    mysql.WithDSN("user:pass@tcp(localhost:3306)/fleet"),
)

// Using an existing *sql.DB
store, err := mysql.New(
    mysql.WithDB(existingDB),
)
if err != nil {
    log.Fatal(err)
}

// Store DEP OAuth tokens
err = store.StoreAuthTokens(ctx, "my-dep-server", &client.OAuth1Tokens{
    ConsumerKey:    "key",
    ConsumerSecret: "secret",
    AccessToken:    "token",
    AccessSecret:   "tokenSecret",
})

// Retrieve DEP sync cursor
cursor, modTime, err := store.RetrieveCursor(ctx, "my-dep-server")
```
