Implements a reverse proxy for routing HTTP requests to Apple DEP (Device Enrollment Program) APIs, handling dynamic endpoint resolution, DEP name extraction from URL paths, and authentication error management.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `New` | func | Creates an `httputil.ReverseProxy` wired with a NanoDEP transport, director, and error handler |
| `newDirector` | func | Builds a reverse proxy director that resolves the target DEP base URL from config, with an in-memory URL cache |
| `newErrorHandler` | func | Returns a proxy error handler that logs and surfaces `client.AuthError` details to the caller |
| `ProxyDEPNameHandler` | func | HTTP handler that extracts the DEP name from the first path segment, strips it, and injects it into the request context |
| `CutIncl` | func | Like `strings.Cut`, but keeps the separator at the start of the `after` string |
| `newCopiedRequest` | func | Shallow-copies an `*http.Request` including a deep copy of `*url.URL` to avoid mutating the original |

## Usage Example

```go
// Create a NanoDEP transport (handles auth/session)
transport := client.NewTransport(httpClient, tokenStore, depName, nil)

// Build the reverse proxy
proxy := proxy.New(transport, configStore, logger)

// Wrap with DEP name extraction (strip your route prefix first)
mux := http.NewServeMux()
mux.Handle("/dep/", http.StripPrefix("/dep", proxy.ProxyDEPNameHandler(proxy, logger)))

// Incoming: GET /dep/myOrg/devices
// → DEP name "myOrg" placed in context
// → Request forwarded to <BaseURL>/devices
```

> **URL Cache Note:** The director caches parsed base URLs per DEP name in memory. Config changes (e.g. a new `BaseURL`) won't take effect until the process restarts. DEP names containing `/` or `%2F` are not supported by `ProxyDEPNameHandler`.
