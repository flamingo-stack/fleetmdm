Provides cryptographic test helper utilities for generating ECDSA keys, attestation certificates, and ACME CSR payloads used in MDM attestation testing.

## Key Components

| Function | Description |
|---|---|
| `GenerateTestKey()` | Generates an ECDSA P-256 key pair, returns the private key |
| `GenerateTestAttestationCA()` | Creates a self-signed CA certificate for attestation testing |
| `BuildAttestationLeafCert()` | Issues a leaf certificate signed by the test CA, embedding Apple serial and nonce OID extensions |
| `BuildAppleDeviceAttestationPayload()` | Assembles a CBOR-encoded Apple device attestation object (format: `"apple"`) and returns it base64 URL-encoded in a JSON-compatible struct |
| `GenerateCSRDER()` | Generates a P-256 key and a DER-encoded CSR, returning it base64 URL-encoded per RFC 7.4 |

## Usage Example

```go
// Generate a test attestation chain and payload
ca, caKey, err := testhelpers.GenerateTestAttestationCA()
if err != nil {
    log.Fatal(err)
}

leaf, err := testhelpers.BuildAttestationLeafCert(ca, caKey, "C02XG0XJJGH5", "some-token-nonce")
if err != nil {
    log.Fatal(err)
}

payload, err := testhelpers.BuildAppleDeviceAttestationPayload(leaf, ca)
if err != nil {
    log.Fatal(err)
}

// Generate a CSR for ACME order submission
encodedCSR, privKey, err := testhelpers.GenerateCSRDER("device.example.com")
if err != nil {
    log.Fatal(err)
}
_ = privKey // retain for signing JWS requests
```

## Notes

- `BuildAppleDeviceAttestationPayload` expects the leaf certificate as the **first** argument, followed by any intermediates or the CA.
- All certificates use a ±1 hour validity window suitable only for short-lived tests.
