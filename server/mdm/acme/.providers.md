Defines the dependency injection interfaces for the ACME bounded context, establishing the minimal contracts needed for Redis access, CSR signing, and data provisioning without coupling to Fleet-internal types.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `RedisPool` | Interface | Minimal Redis pool abstraction; structurally compatible with `fleet.RedisPool` |
| `CSRSigner` | Interface | Signs x509 certificate requests during ACME order finalization |
| `CSRSignerFunc` | Adapter | Function-to-interface adapter implementing `CSRSigner` |
| `DataProviders` | Interface | Aggregates all external dependencies required by the ACME bounded context |

## Usage Example

```go
// Implement DataProviders for your environment
type myProviders struct{}

func (p *myProviders) ServerURL(ctx context.Context) (string, error) {
    return "https://mdm.example.com", nil
}

func (p *myProviders) CSRSigner(ctx context.Context) (acme.CSRSigner, error) {
    // Wrap a plain function using the adapter
    return acme.CSRSignerFunc(func(ctx context.Context, csr *x509.CertificateRequest) (*x509.Certificate, error) {
        return myCA.Sign(csr)
    }), nil
}

// RedisPool is satisfied implicitly by fleet.RedisPool
var _ acme.RedisPool = (*fleet.RedisPool)(nil)
```

## Notes

- `DataProviders` methods are intentionally narrowed — only the four operations ACME requires are exposed, preventing accidental dependencies on broader Fleet internals.
- `CSRSignerFunc` follows the standard Go adapter pattern (e.g., `http.HandlerFunc`), enabling lightweight inline signers in tests without a full struct implementation.
