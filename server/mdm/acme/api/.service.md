Defines the top-level `Service` interface for the ACME service module, serving as the public API entry point that composes all sub-service interfaces.

## Key Components

- **`Service`** — Composite interface that embeds:
  - `DirectoryNonceService`
  - `AccountService`
  - `EnrollmentService`
  - `AuthorizationService`
  - `ChallengeService`
  - `NoncesStore()` — Returns the underlying `*redis_nonces_store.RedisNoncesStore` instance

## Usage Example

```go
// Obtain a Service via Bootstrap (defined elsewhere in the module)
svc := acme.Bootstrap(cfg)

// Use any embedded sub-service method directly
account, err := svc.GetAccount(ctx, accountID)

// Access the nonces store directly if needed
store := svc.NoncesStore()
```

## Notes

- External packages should depend on this `api` package rather than internal sub-packages.
- The `Service` interface is returned by `Bootstrap`, which wires up all dependencies.
- Direct use of `NoncesStore()` should be limited to infrastructure-level code; prefer the higher-level methods for business logic.
