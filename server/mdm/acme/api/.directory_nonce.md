Defines the `DirectoryNonceService` interface for managing ACME directory nonces and retrieving directory information in the MDM ACME API layer.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DirectoryNonceService` | `interface` | Service contract for nonce lifecycle and directory lookup |
| `NewNonce` | `method` | Creates a new nonce for a given ACME identifier |
| `GetDirectory` | `method` | Retrieves the ACME directory associated with an identifier |

## Usage Example

```go
type myDirectoryNonceService struct{}

func (s *myDirectoryNonceService) NewNonce(ctx context.Context, identifier string) error {
    // generate and store a new nonce
    return nil
}

func (s *myDirectoryNonceService) GetDirectory(ctx context.Context, identifier string) (*types.Directory, error) {
    // fetch directory by identifier
    return &types.Directory{}, nil
}

var svc api.DirectoryNonceService = &myDirectoryNonceService{}

// Create a nonce for an ACME account identifier
if err := svc.NewNonce(ctx, "account-123"); err != nil {
    log.Fatal(err)
}

// Retrieve the ACME directory
dir, err := svc.GetDirectory(ctx, "account-123")
```

## Notes

- `identifier` typically corresponds to an ACME account or domain identifier
- Returns `*types.Directory` from the internal `acme/internal/types` package — callers should not mutate the returned pointer
- Both methods accept a `context.Context` for deadline and cancellation propagation
