Defines the `EnrollmentService` interface for managing ACME enrollment records in the `acme_enrollments` database table.

## Key Components

- **`EnrollmentService`** — Interface with a single method for creating ACME enrollment records.
- **`NewACMEEnrollment`** — Creates a new enrollment row keyed by `hostIdentifier` and returns the generated `path_identifier`.

## Usage Example

```go
var svc api.EnrollmentService // inject your implementation

pathID, err := svc.NewACMEEnrollment(ctx, "device-host-001")
if err != nil {
    log.Fatalf("enrollment failed: %v", err)
}
fmt.Println("Path identifier:", pathID)
```

## Notes

- Implementations are expected to persist records to the `acme_enrollments` table.
- The returned `path_identifier` uniquely identifies the enrollment and is typically used in subsequent ACME certificate provisioning flows.
