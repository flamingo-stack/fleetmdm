Defines the `ChallengeService` interface for validating ACME protocol challenges during MDM enrollment.

## Key Components

- **`ChallengeService`** — Interface with a single method for challenge validation
- **`ValidateChallenge`** — Validates an ACME challenge given an enrollment context, account, challenge ID, and payload; returns a `ChallengeResponse` or an error

## Usage Example

```go
type myChallengeService struct{}

func (s *myChallengeService) ValidateChallenge(
    ctx context.Context,
    enrollment *types.Enrollment,
    account *types.Account,
    challengeID uint,
    payload string,
) (*types.ChallengeResponse, error) {
    // validate the challenge payload against the enrollment
    return &types.ChallengeResponse{}, nil
}

var _ api.ChallengeService = (*myChallengeService)(nil)
```

## Notes

- Implementations must satisfy all ACME challenge validation requirements for the MDM enrollment flow
- The interface is defined in the `api` package under `server/mdm/acme/internal`, keeping it internal to the ACME subsystem
- See [`challenge.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/acme/internal/api/challenge.go) for the full source
