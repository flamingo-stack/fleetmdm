Defines the `AuthorizationService` interface for handling ACME protocol authorization lookups, distinct from standard authentication.

## Key Components

- **`AuthorizationService`** — Interface with a single method for retrieving ACME authorization objects by ID, scoped to a specific enrollment and account.
  - `GetAuthorization(ctx, enrollment, account, authorizationID)` — Returns an `AuthorizationResponse` for the given authorization ID within the context of an enrollment and account.

## Usage Example

```go
type myAuthService struct{}

func (s *myAuthService) GetAuthorization(
    ctx context.Context,
    enrollment *types.Enrollment,
    account *types.Account,
    authorizationID uint,
) (*types.AuthorizationResponse, error) {
    // Fetch and return the ACME authorization object
    return &types.AuthorizationResponse{}, nil
}

var _ api.AuthorizationService = (*myAuthService)(nil)
```

## Notes

- This interface is part of the ACME (Automated Certificate Management Environment) protocol implementation within the Fleet MDM stack.
- "Authorization" here refers to the ACME protocol concept — a server-side object representing a domain owner's right to obtain a certificate — **not** user access control.
- See the full implementation at [`server/mdm/acme/internal/`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/acme/internal/).
