Defines the `AccountService` interface for the ACME protocol implementation, providing methods for account management and certificate order lifecycle operations.

## Key Components

### `AccountService` Interface

| Method | Description |
|--------|-------------|
| `CreateAccount` | Creates a new ACME account or returns an existing one when `onlyReturnExisting` is `true` |
| `AuthenticateMessageFromAccount` | Validates a JWS-signed request from an established account |
| `AuthenticateNewAccountMessage` | Validates a JWS-signed request for new account creation |
| `CreateOrder` | Initiates a new certificate order for an enrolled account |
| `FinalizeOrder` | Submits a CSR to finalize an active certificate order |
| `GetOrder` | Retrieves the current state of a specific order |
| `ListAccountOrders` | Returns all order URLs associated with an account |
| `GetCertificate` | Fetches the issued certificate chain for a completed order |

## Usage Example

```go
// Inject AccountService into a handler
type OrderHandler struct {
    accounts AccountService
}

func (h *OrderHandler) HandleFinalize(ctx context.Context, enrollment *types.Enrollment, account *types.Account, orderID uint, csr string) {
    order, err := h.accounts.FinalizeOrder(ctx, enrollment, account, orderID, csr)
    if err != nil {
        // handle error
        return
    }
    // order.Status reflects the updated order state
}
```

## Notes

- All methods accept a `context.Context` for timeout and cancellation propagation.
- JWS authentication methods operate on `*api_http.JWSRequestContainer`, aligning with the ACME RFC 8555 request format.
- This interface is implemented by the ACME server and should be satisfied by any mock in tests.
