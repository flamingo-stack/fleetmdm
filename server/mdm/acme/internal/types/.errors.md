Defines the `ACMEError` type and constructor functions for all ACME protocol errors used in Fleet's MDM certificate management, following RFC 8555 problem document conventions.

## Key Components

**`ACMEError` struct** — Implements the RFC 7807 problem document format with `type`, `title`, `detail`, and `instance` JSON fields plus an HTTP `StatusCode`. Satisfies the `error` interface via `Error()`.

**`ShouldReturnNonce() bool`** — Returns `false` for `enrollmentNotFound` and `serverInternal` errors; `true` for all others, controlling nonce inclusion in ACME responses.

**Error constructors** — Each returns a configured `*ACMEError`. Errors are split into two namespaces:
- **RFC 8555 standard** (`urn:ietf:params:acme:error:`): `AccountDoesNotExistError`, `BadNonceError`, `BadCSRError`, `BadPublicKeyError`, `BadSignatureAlgorithmError`, `RejectedIdentifierError`, `UnsupportedIdentifierError`, `UnauthorizedError`, `MalformedError`, `OrderNotReadyError`, `InternalServerError`, `BadAttestationStatementError`
- **Fleet custom** (`https://fleetdm.com/acme/error/`): `EnrollmentNotFoundError`, `AccountRevokedError`, `TooManyAccountsError`, `TooManyOrdersError`, `OrderDoesNotExistError`, `OrderNotFinalizedError`, `AuthorizationDoesNotExistError`, `ChallengeDoesNotExistError`, `CertificateDoesNotExistError`, `InvalidChallengeStatusError`

## Usage Example

```go
// Return a standard RFC error
if nonce != expectedNonce {
    return nil, types.BadNonceError("nonce has already been used")
}

// Return a Fleet custom error
enrollment, err := db.GetEnrollment(id)
if err != nil {
    return nil, types.EnrollmentNotFoundError("enrollment ID not registered")
}

// Check if a nonce should be included in the error response
acmeErr := types.BadNonceError("invalid nonce")
if acmeErr.ShouldReturnNonce() {
    // attach fresh nonce to response header
}

// ACMEError satisfies the error interface
fmt.Println(acmeErr.Error())
// urn:ietf:params:acme:error:badNonce: The client sent an unacceptable anti-replay nonce: invalid nonce
```
