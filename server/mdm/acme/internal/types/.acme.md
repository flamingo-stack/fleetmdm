Defines the core ACME (Automated Certificate Management Environment) types, constants, and datastore interface used for device attestation and certificate lifecycle management within the FleetMDM ACME service module.

## Key Components

### Status Constants
- `OrderStatus*` — Order lifecycle states: `pending`, `ready`, `valid`, `invalid`
- `AuthorizationStatus*` / `ChallengeStatus*` — Corresponding states for authorizations and challenges

### Core Types
| Type | Description |
|---|---|
| `Directory` | ACME directory resource with endpoint URLs and metadata |
| `Enrollment` | Device enrollment record with validity/revocation tracking |
| `Account` | ACME account linked to an enrollment, identified by JWK thumbprint |
| `Order` | Certificate order with CSR, identifiers, and finalization state |
| `Authorization` / `Challenge` | ACME authorization and `device-attest-01` challenge records |
| `Identifier` | ACME identifier (type `permanent-identifier`) representing a host serial |
| `AttestationObject` | WebAuthn attestation object (CBOR-encoded) |
| `AppleDeviceAttestationStatement` | Apple anonymous attestation x5c certificate chain |

### Key Methods
- `Enrollment.IsValid()` — Returns `false` if revoked or past `NotValidAfter`
- `Order.IsReadyToFinalize()` — Validates order is in `ready` state before CSR submission
- `Order.IsCertificateReady()` — Validates order is finalized and `valid` before cert retrieval
- `Order.ValidateOrderCreation()` — Enforces a single `permanent-identifier` matching the enrollment's host identifier; rejects `notBefore`/`notAfter`
- `Challenge.ValidatedAt()` — Returns validation timestamp only when status is `valid`

### Interfaces
- `Datastore` — Full CRUD interface for enrollments, accounts, orders, authorizations, challenges, and certificates
- `AccountAuthenticatedRequest` — Implemented by request types that require enrollment/account injection post-authentication

## Usage Example

```go
order := acmetypes.Order{
    Identifiers: []acmetypes.Identifier{
        {Type: acmetypes.IdentifierTypePermanentIdentifier, Value: "ABC123"},
    },
}

enrollment := &acmetypes.Enrollment{HostIdentifier: "ABC123"}

if err := order.ValidateOrderCreation(enrollment); err != nil {
    // handle validation error
}

if err := order.IsReadyToFinalize(); err != nil {
    // handle not-ready error
}
```
