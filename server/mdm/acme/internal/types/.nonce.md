Generates cryptographically secure nonces for ACME protocol (RFC 8555) replay protection, providing both raw and base64url-encoded formats.

## Key Components

| Symbol | Description |
|---|---|
| `nonceRawByteSize` | Constant defining nonce size as 16 bytes (128 bits) per RFC 8555 |
| `CreateRawNonce()` | Returns a 128-bit random nonce as a raw byte string using `crypto/rand` |
| `CreateNonceEncodedForHeader()` | Returns a base64url-encoded nonce suitable for the `Replay-Nonce` HTTP header per RFC 7515 |

## Usage Example

```go
// Generate a raw nonce (e.g., for internal storage/tracking)
rawNonce := types.CreateRawNonce()

// Generate an encoded nonce for the Replay-Nonce response header
headerNonce := types.CreateNonceEncodedForHeader()
w.Header().Set("Replay-Nonce", headerNonce)
```

## Notes

- Uses `crypto/rand` for cryptographically secure randomness; `rand.Read` always fills the full slice and never returns an error.
- `CreateNonceEncodedForHeader` uses `base64.RawURLEncoding` (no padding), which is required by [RFC 7515 §2](https://datatracker.ietf.org/doc/html/rfc7515#section-2) for JOSE/ACME header values.
- See the full implementation at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/nonce.go).
