Handles ACME protocol account and order lifecycle operations, including account creation, order management, CSR validation, certificate signing, and certificate retrieval for Fleet MDM's ACME implementation.

## Key Components

| Function | Description |
|---|---|
| `CreateAccount` | Creates or retrieves an existing ACME account tied to a JWK and enrollment ID |
| `CreateOrder` | Initiates a new certificate order with a pending authorization and device attestation challenge |
| `createOrderResponse` | Internal helper that constructs a fully-populated `OrderResponse` with resolved URLs |
| `FinalizeOrder` | Validates authorizations/challenges, parses and signs a DER-encoded CSR, and marks the order valid |
| `parseDERCSR` | Decodes a base64url-encoded DER CSR and parses it into an `x509.CertificateRequest` |
| `GetOrder` | Fetches a single order by ID and returns its response representation |
| `ListAccountOrders` | Returns a list of order URLs for a given account |
| `GetCertificate` | Retrieves the signed leaf certificate PEM concatenated with the CA root PEM |

## Usage Example

```go
// Create an ACME account
acctResp, err := svc.CreateAccount(ctx, "/acme/v1", enrollmentID, jwk, false)
if err != nil {
    log.Fatal(err)
}
fmt.Println(acctResp.Location) // https://fleet.example.com/acme/v1/accounts/42

// Create an order for a device identifier
orderResp, err := svc.CreateOrder(ctx, enrollment, acctResp.CreatedAccount, partialOrder)
if err != nil {
    log.Fatal(err)
}
fmt.Println(orderResp.Status) // "pending"

// Finalize the order with a base64url-encoded DER CSR
finalResp, err := svc.FinalizeOrder(ctx, enrollment, account, orderResp.ID, csrBase64URL)
if err != nil {
    log.Fatal(err)
}

// Retrieve the full PEM chain (leaf + root)
certPEM, err := svc.GetCertificate(ctx, account.ID, finalResp.ID)
```

> **Note:** Only ECDSA CSRs are supported, matching the Apple MDM protocol requirement. The CSR subject is overwritten to `CN=Fleet Identity, OU=fleet` before signing.
