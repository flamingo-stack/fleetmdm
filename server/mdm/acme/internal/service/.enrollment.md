Handles ACME enrollment for DEP (Device Enrollment Program) devices, bypassing standard authorization checks since authentication is established via DEP device identity.

## Key Components

- **`NewACMEEnrollment`** — Creates a new ACME enrollment for a host using its identifier. Marks the authorization context as checked (no authz check required) and delegates enrollment creation to the underlying store.

## Usage Example

```go
enrollmentToken, err := svc.NewACMEEnrollment(ctx, "device-hardware-uuid-or-serial")
if err != nil {
    return fmt.Errorf("failed to enroll device: %w", err)
}
// enrollmentToken returned from the store for further ACME provisioning
```

## Notes

- Authorization is intentionally skipped (`skipauth`) — the caller is already authenticated through DEP device identity, not Fleet's standard user/token auth.
- The actual enrollment record is created via `s.store.NewEnrollment`, keeping business logic separate from storage.
