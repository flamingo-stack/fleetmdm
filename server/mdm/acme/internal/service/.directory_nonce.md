Implements two ACME service methods for nonce generation and directory retrieval, both authenticated via ACME enrollment identifier validation.

## Key Components

| Function | Description |
|----------|-------------|
| `NewNonce` | Validates the ACME enrollment identifier and delegates nonce generation to the response renderer |
| `GetDirectory` | Validates the ACME enrollment identifier, then builds and returns the ACME directory object containing endpoint URLs for `new_nonce`, `new_account`, and `new_order` |

## Usage Example

```go
svc := &Service{}

// Retrieve the ACME directory for an enrolled device
dir, err := svc.GetDirectory(ctx, "device-enrollment-identifier")
if err != nil {
    log.Fatal(err)
}
fmt.Println(dir.NewNonce)   // e.g. "https://acme.example.com/abc123/new_nonce"
fmt.Println(dir.NewAccount) // e.g. "https://acme.example.com/abc123/new_account"
fmt.Println(dir.NewOrder)   // e.g. "https://acme.example.com/abc123/new_order"

// Request a new nonce (actual nonce value is embedded in the HTTP response)
if err := svc.NewNonce(ctx, "device-enrollment-identifier"); err != nil {
    log.Fatal(err)
}
```

## Notes

- Both methods require a valid ACME enrollment `identifier`; unauthenticated calls return an error immediately.
- `NewNonce` performs no direct nonce generation — the nonce value is written during HTTP response rendering.
- `GetDirectory` constructs per-identifier URLs by combining the base ACME URL with each endpoint suffix via `getACMEURLWithBaseURL`.
