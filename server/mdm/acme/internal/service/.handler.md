Registers and wires up all RFC 8555 (ACME) HTTP endpoints for the MDM ACME service, mapping routes to their corresponding handler functions via go-kit's transport layer.

## Key Components

| Symbol | Description |
|--------|-------------|
| `GetRoutes` | Returns a `HandlerRoutesFunc` that registers all ACME routes on a `mux.Router` |
| `attachFleetAPIRoutes` | Internal helper that binds each ACME path to its endpoint function; appends the ACME error encoder and auth-skip middleware |
| `skipStandardFleetAuth` | Middleware that marks Fleet's standard authorization as satisfied, preventing `Forbidden` errors on JWS-authenticated endpoints |
| `getNewNonceEndpoint` | Handles `HEAD`/`GET`/`POST /new_nonce` — issues a fresh replay-protection nonce |
| `getDirectoryEndpoint` | Handles `GET`/`POST /directory` — returns the ACME directory object |
| `createAccountEndpoint` | Handles `POST /new_account` — authenticates a JWS message and creates or retrieves an ACME account |
| `createOrderEndpoint` | Handles `POST /new_order` — creates a new certificate order |
| `getOrderEndpoint` | Handles `POST-as-GET /orders/{order_id}` — retrieves order status |
| `listOrdersEndpoint` | Handles `POST-as-GET /accounts/{account_id}/orders` — lists all orders for an account |
| `getCertificateEndpoint` | Handles `POST-as-GET /orders/{order_id}/certificate` — downloads the issued certificate |
| `getAuthorizationEndpoint` | Handles `POST /authorizations/{authorization_id}` — retrieves authorization details |
| `getChallengeEndpoint` | Handles `POST /challenges/{challenge_id}` — validates an attestation challenge |
| `finalizeOrderEndpoint` | Handles `POST /orders/{order_id}/finalize` — submits a CSR to finalize the order |

## Usage Example

```go
import (
    "github.com/fleetdm/fleet/v4/server/mdm/acme/service"
    "github.com/go-kit/kit/endpoint"
)

// Wire ACME routes into the Fleet router
routesFunc := service.GetRoutes(acmeSvc, authMiddleware)
routesFunc(router, serverOptions)
```

All endpoints follow the [RFC 8555](https://datatracker.ietf.org/doc/html/rfc8555/) ACME protocol, supporting both standard POST requests and POST-as-GET requests where the spec requires it. Each handler authenticates the incoming JWS payload via `svc.AuthenticateMessageFromAccount` (or `AuthenticateNewAccountMessage` for new accounts) before dispatching to the underlying service method.
