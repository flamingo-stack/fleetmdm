Implements the ACME bounded context service, wiring together a datastore, Redis-backed nonces store, and data providers to fulfill the `api.Service` interface for MDM ACME operations.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Service` | struct | Core service holding the datastore, Redis nonces store, data providers, logger, and an optional test CA pool |
| `ServiceOption` | type | Functional option type for configuring a `Service` at construction time |
| `NewService` | func | Constructor that initialises the `RedisNoncesStore` and applies any provided `ServiceOption` functions |
| `NoncesStore` | method | Returns the underlying `RedisNoncesStore` (used by transport/middleware layers) |
| `getACMEBaseURL` | method | Resolves the ACME server base URL via the injected `DataProviders` |
| `getACMEURL` | method | Builds a full ACME endpoint URL from a path identifier and optional suffix segments |
| `getACMEURLWithBaseURL` | method | Lower-level URL builder that accepts an explicit base URL instead of fetching it |

## Usage Example

```go
svc := service.NewService(
    store,
    redisPool,
    providers,
    logger,
    // optional: override Apple root CA for tests
    func(s *service.Service) {
        s.TestAppleRootCAs = testCertPool
    },
)

// Access the nonces store (e.g., for ACME replay-nonce middleware)
nonces := svc.NoncesStore()
```

## Notes

- `tracer` is an OpenTelemetry tracer scoped to this package; it is a no-op when OTEL is not configured.
- The compile-time assertion `var _ api.Service = (*Service)(nil)` guarantees `Service` satisfies the `api.Service` interface.
- `TestAppleRootCAs` should only be set in test code to override the hardcoded Apple Enterprise Attestation Root CA.
