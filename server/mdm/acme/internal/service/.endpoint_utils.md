Provides HTTP request decoding, response encoding, and endpoint wiring utilities for the ACME service layer, bridging go-kit transport primitives with Fleet's platform endpointer infrastructure.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `encodeResponse` | func | Encodes responses as indented JSON using the platform's common response encoder with ACME-specific error handling |
| `acmeErrorEncoder` | func | Writes ACME-protocol-compliant error responses (`application/problem+json`) with safe internal error masking |
| `acmeDomainErrorEncoder` | func | Adapter bridging the platform's `JsonError` encoder signature to `acmeErrorEncoder` |
| `makeDecoder` | func | Constructs a `kithttp.DecodeRequestFunc` with JSON body decoding and custom URL tag support |
| `parseCustomTags` | func | Handles `http_method` and `http_path` struct field tags to inject request metadata during decoding |
| `bodyDecoder` | interface | Allows request types to implement custom body decoding with access to TLS peer certificates and query params |
| `decodeBody` | func | Invokes `bodyDecoder.DecodeBody`, passing TLS peer certificates from the request when available |
| `handlerFunc` | type | Handler signature for ACME endpoints: `(ctx, request, svc) → Errorer` |
| `endpointer` | struct | Wraps `api.Service`, implementing `eu.Endpointer[handlerFunc]` for the platform's generic endpoint dispatch |
| `newEndpointerWithNoAuth` | func | Constructs a `CommonEndpointer` wired with the ACME decoder, encoder, and service — without enforcing authentication middleware on individual handlers |

## Usage Example

```go
// Wire ACME endpoints onto a mux router
ep := newEndpointerWithNoAuth(svc, authMiddleware, serverOpts, router, "v1")

// Register a handler that uses bodyDecoder for TLS-authenticated requests
type myRequest struct {
    Method string `url:"http_method"`
    Path   string `url:"http_path"`
}

func (r *myRequest) DecodeBody(
    ctx context.Context,
    body io.Reader,
    query url.Values,
    certs []*x509.Certificate,
) error {
    // custom decoding with optional mTLS cert inspection
    return json.NewDecoder(body).Decode(r)
}
```
