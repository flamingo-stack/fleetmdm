Implements the ACME protocol's authorization retrieval, fetching an authorization object and its associated challenges to build a structured `AuthorizationResponse`.

## Key Components

- **`GetAuthorization`** — Retrieves an ACME authorization by ID for a given account, resolves its challenges, constructs per-challenge and authorization URLs, and returns a populated `AuthorizationResponse`.

## Usage Example

```go
authzResp, err := svc.GetAuthorization(ctx, enrollment, account, authorizationID)
if err != nil {
    // handle types.MalformedError or store/URL construction errors
}

for _, challenge := range authzResp.Challenges {
    fmt.Printf("Challenge type: %s, status: %s, URL: %s\n",
        challenge.ChallengeType, challenge.Status, challenge.URL)
}
```

## Notes

- Validates that `authorizationID` is non-zero; returns a `types.MalformedError` otherwise.
- Builds fully-qualified URLs for both the authorization itself and each of its challenges using the ACME base URL and the enrollment's `PathIdentifier`.
- Authorization expiry is sourced from `enrollment.NotValidAfter`, not from the authorization record itself.
- This file handles **ACME protocol authorization** (a step in certificate issuance), not service-level authentication.
