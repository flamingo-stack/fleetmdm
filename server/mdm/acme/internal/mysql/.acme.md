MySQL datastore implementation for the ACME service module, providing database connectivity with primary/replica routing and OpenTelemetry tracing support.

## Key Components

- **`Datastore`** — Struct holding primary/replica `*sqlx.DB` connections and a structured logger.
- **`NewDatastore`** — Constructor that initializes the `Datastore` from a `platform_mysql.DBConnections` bundle.
- **`reader(ctx)`** — Returns the replica connection by default; falls back to primary when `ctxdb.IsPrimaryRequired` is set on the context.
- **`writer(ctx)`** — Always returns the primary connection for write operations.
- **`tracer`** — Package-level OpenTelemetry tracer (no-op when OTEL is not configured).

## Usage Example

```go
import (
    acmemysql "github.com/fleetdm/fleet/v4/server/mdm/acme/internal/mysql"
    platform_mysql "github.com/fleetdm/fleet/v4/server/platform/mysql"
    "log/slog"
)

conns := &platform_mysql.DBConnections{
    Primary: primaryDB,
    Replica: replicaDB,
}

ds := acmemysql.NewDatastore(conns, slog.Default())
```

> The `reader` method automatically promotes reads to the primary when `ctxdb.IsPrimaryRequired` is set on the context — useful for read-after-write consistency.
