Provides MySQL datastore implementation for retrieving ACME enrollment records by path identifier.

## Key Components

- **`GetACMEEnrollment(ctx, pathIdentifier)`** — Queries the `acme_enrollments` table for a single enrollment matching the given `pathIdentifier`. Returns a `*types.Enrollment` or a wrapped `types.EnrollmentNotFoundError` if no record exists.

## Usage Example

```go
enrollment, err := ds.GetACMEEnrollment(ctx, "/enroll/abc123")
if err != nil {
    // Handle types.EnrollmentNotFoundError or other DB errors
    log.Fatal(err)
}
fmt.Println(enrollment.HostIdentifier, enrollment.NotValidAfter)
```

## Notes

- Uses the read replica (`ds.reader(ctx)`) for the query.
- Wraps `sql.ErrNoRows` into a domain-specific `types.EnrollmentNotFoundError` for cleaner error handling upstream.
- Instrumented with OpenTelemetry tracing via `tracer.Start`.
