Handles MySQL datastore operations for ACME protocol authorizations, providing lookup by authorization ID (with account ownership verification) and bulk retrieval by order ID.

## Key Components

| Function | Description |
|---|---|
| `GetAuthorizationByID` | Fetches a single ACME authorization, validating both `accountID` and `authorizationID` are non-zero and confirming account ownership via a JOIN across `acme_authorizations`, `acme_orders`, and `acme_accounts`. Returns `AuthorizationDoesNotExistError` on no match. |
| `GetAuthorizationsByOrderID` | Retrieves all ACME authorizations associated with a given order ID from the primary DB writer. |

## Usage Example

```go
// Fetch a specific authorization for an account
authz, err := ds.GetAuthorizationByID(ctx, accountID, authorizationID)
if err != nil {
    // handle types.MalformedError or types.AuthorizationDoesNotExistError
}

// Fetch all authorizations for an order
authzList, err := ds.GetAuthorizationsByOrderID(ctx, orderID)
if err != nil {
    // handle error
}
```

## Notes

- `GetAuthorizationByID` uses the **reader** replica; `GetAuthorizationsByOrderID` uses the **primary** connection.
- Input validation (`accountID == 0`, `authorizationID == 0`) returns `types.MalformedError` before hitting the DB.
- This file implements the **ACME protocol authorization** concept — not standard Fleet authentication.
