MySQL datastore implementation for ACME protocol account and order management, providing CRUD operations for accounts, orders, authorizations, and challenges with concurrent access protection and per-enrollment/account limits.

## Key Components

| Function | Description |
|---|---|
| `CreateAccount` | Creates or returns an existing ACME account, enforcing a max of 3 accounts per enrollment with row-level locking and JWK thumbprint deduplication |
| `GetAccountByID` | Fetches a non-revoked account by enrollment and account ID |
| `CreateOrder` | Atomically creates an order, authorization, and challenge within a transaction, enforcing a max of 3 orders per account |
| `FinalizeOrder` | Marks an order as valid with its CSR and issued certificate serial |
| `GetOrderByID` | Retrieves an order and its associated authorizations by account and order ID |
| `GetCertificatePEMByOrderID` | Returns the PEM-encoded certificate linked to a finalized, non-revoked order |
| `ListAccountOrderIDs` | Lists all non-invalid order IDs for a given account |

**Constants:**
- `maxAccountsPerEnrollment = 3`
- `maxOrdersPerAccount = 3`

## Usage Example

```go
ds := &Datastore{ /* ... */ }

// Create or retrieve an existing account
account, created, err := ds.CreateAccount(ctx, &types.Account{
    ACMEEnrollmentID: 42,
    JSONWebKey:       jwk,
}, false)

// Create an order with its authorization and challenge
order, err := ds.CreateOrder(ctx, &types.Order{
    ACMEAccountID: account.ID,
    Identifiers:   []types.Identifier{{Type: "dns", Value: "example.com"}},
    Status:        types.OrderStatusPending,
}, &types.Authorization{Status: "pending"}, &types.Challenge{
    ChallengeType: "device-attest-01",
    Token:         "sometoken",
    Status:        "pending",
})

// Finalize once CSR and certificate are available
err = ds.FinalizeOrder(ctx, order.ID, csrPEM, certSerial)
```

## Notes

- All multi-step writes use `WithRetryTxx` for transactional safety and retry on deadlock.
- `CreateAccount` uses `SELECT ... FOR UPDATE` to serialize concurrent account creation per enrollment.
- `GetAccountByID` and read operations use a reader replica via `ds.reader(ctx)`.
