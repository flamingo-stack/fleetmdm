Shared test utilities for the ACME service module, providing database setup helpers and test data insertion functions for integration tests.

## Key Components

### Types

- **`TestDB`** — Holds a `*sqlx.DB` connection and a `*slog.Logger` for use within tests.

### Functions

- **`SetupTestDB(t, testNamePrefix)`** — Creates an isolated MySQL test database with the Fleet schema loaded. Registers cleanup to close the connection when the test ends.
- **`(tdb *TestDB) Conns()`** — Returns a `*common_mysql.DBConnections` struct wiring both primary and replica to the same test DB.
- **`(tdb *TestDB) TruncateTables(t)`** — Clears all ACME-related tables (`acme_enrollments`, `acme_accounts`, `acme_orders`, `acme_authorizations`, `acme_challenges`, `identity_certificates`, `identity_serials`).
- **`(tdb *TestDB) InsertACMEEnrollment(t, enrollment)`** — Inserts an `types.Enrollment` record, auto-generating `PathIdentifier` and `HostIdentifier` via UUID if empty, and populating the struct's `ID` field from the last insert ID.

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    tdb := testutils.SetupTestDB(t, "my_feature")
    tdb.TruncateTables(t)

    enrollment := &types.Enrollment{
        NotValidAfter: time.Now().Add(24 * time.Hour),
    }
    tdb.InsertACMEEnrollment(t, enrollment)
    // enrollment.ID, PathIdentifier, and HostIdentifier are now populated

    store := mypackage.NewDatastore(tdb.Conns(), tdb.Logger)
    // run assertions...
}
```

## Notes

- All helpers call `t.Helper()` for clean failure attribution in test output.
- The logger uses `slog.DiscardHandler`, suppressing log noise during tests.
