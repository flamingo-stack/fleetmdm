Serves as the public entry point for the ACME service module, wiring together the datastore, service layer, and HTTP route handler for use in the Fleet MDM server.

## Key Components

- **`New`** – Initializes the ACME module by constructing a MySQL datastore and service instance, then returns the composed `api.Service` and a deferred route registration function that accepts auth middleware.
- **`WithTestAppleRootCAs`** – A `ServiceOption` that injects a custom `x509.CertPool` for overriding Apple root CAs in test environments.
- **`ServiceOption`** – Re-exported type alias from `service.ServiceOption`, allowing callers to pass functional options without importing the internal package directly.

## Usage Example

```go
import (
    "github.com/fleetdm/fleet/v4/server/mdm/acme/bootstrap"
)

svc, routesFn := bootstrap.New(
    dbConns,
    redisPool,
    providers,
    logger,
)

// Register routes with auth middleware
handlerRoutes := routesFn(authMiddleware)

// In tests: override Apple root CAs
svc, routesFn := bootstrap.New(
    dbConns,
    redisPool,
    providers,
    logger,
    bootstrap.WithTestAppleRootCAs(testCertPool),
)
```

## Notes

- The internal `mysql` and `service` packages are not exposed directly; all wiring is handled here.
- `routesFn` defers route binding until auth middleware is available, keeping initialization and request handling concerns separate.
