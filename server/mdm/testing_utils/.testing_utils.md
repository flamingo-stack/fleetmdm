Shared testing utilities for MDM Apple-related test infrastructure, providing reusable helpers for certificate templates and mock HTTP servers used across Fleet MDM test suites.

## Key Components

- **`TestingT`** — Interface abstracting `*testing.T`, exposing only `Errorf`, `FailNow`, `Cleanup`, and `Setenv`. Keeps the `testing` package out of the production import graph while remaining compatible with standard test types.
- **`NewTestMDMAppleCertTemplate()`** — Returns a pre-configured `*x509.Certificate` template for Apple MDM testing, including a UID OID matching Apple's management profile format (`com.apple.mgmt.Example`).
- **`StartNewAppleGDMFTestServer(t TestingT)`** — Spins up an `httptest.Server` serving canned GDMF JSON from `testdata/gdmf.json`, overrides the `FLEET_DEV_GDMF_URL` dev-mode variable to point at it, and auto-closes the server via `t.Cleanup`.

## Usage Example

```go
func TestSomeMDMFeature(t *testing.T) {
    // Start a local GDMF mock server; cleaned up automatically
    testing_utils.StartNewAppleGDMFTestServer(t)

    // Get a ready-to-sign Apple MDM cert template
    tmpl := testing_utils.NewTestMDMAppleCertTemplate()

    // Sign tmpl with a test CA key, then use the cert in your test...
}
```

## Notes

- `StartNewAppleGDMFTestServer` resolves the `testdata/gdmf.json` path at runtime using `runtime.Caller(0)`, so it works regardless of the caller's working directory.
- Both helpers accept `TestingT` rather than `*testing.T`, making them usable in sub-packages or table-driven test helpers that receive a narrower interface.
