Implements the `storage.PushCertStore` interface for `MultiAllStorage`, delegating APNs push certificate operations across all configured storage backends simultaneously.

## Key Components

### Methods

| Method | Description |
|--------|-------------|
| `IsPushCertStale` | Checks whether the stored push certificate is stale by comparing against a provided token, executed across all backends |
| `RetrievePushCert` | Fetches the TLS push certificate and its associated stale token from storage backends |
| `StorePushCert` | Persists a new APNs push certificate (PEM-encoded cert and key) to all backends |

### Internal Type

- **`retrievePushCertReturns`** — helper struct used to bundle the `*tls.Certificate` and `staleToken` return values when passing results through the generic `execStores` callback

## Usage Example

```go
// StorePushCert fans out the PEM cert/key write to all configured backends
err := multiStorage.StorePushCert(ctx, pemCert, pemKey)
if err != nil {
    log.Fatal("failed to store push cert:", err)
}

// RetrievePushCert fetches the certificate from the primary backend
cert, staleToken, err := multiStorage.RetrievePushCert(ctx, "com.apple.mgmt.example")
if err != nil {
    log.Fatal("failed to retrieve push cert:", err)
}

// IsPushCertStale validates freshness against a known token
stale, err := multiStorage.IsPushCertStale(ctx, "com.apple.mgmt.example", staleToken)
if stale {
    // Refresh the push certificate
}
```

## Notes

- All three methods delegate to `execStores`, ensuring writes and reads are fanned out to every registered `AllStorage` backend
- `retrievePushCertReturns` is cast via type assertion (`val.(*retrievePushCertReturns)`) after `execStores` returns, following the multi-storage pattern used throughout the `allmulti` package
