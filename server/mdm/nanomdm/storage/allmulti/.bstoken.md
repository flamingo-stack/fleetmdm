Implements Bootstrap Token storage operations for the `MultiAllStorage` type, delegating `StoreBootstrapToken` and `RetrieveBootstrapToken` calls across all configured storage backends.

## Key Components

- **`StoreBootstrapToken`** – Writes a bootstrap token to all storage backends via `execStores`, returning the first error encountered.
- **`RetrieveBootstrapToken`** – Reads a bootstrap token from the storage backends via `execStores` and returns the result cast to `*mdm.BootstrapToken`.

## Usage Example

```go
ms := &MultiAllStorage{ /* configured backends */ }
req := &mdm.Request{Context: ctx}

// Store a bootstrap token
setMsg := &mdm.SetBootstrapToken{ /* token data */ }
if err := ms.StoreBootstrapToken(req, setMsg); err != nil {
    log.Fatal(err)
}

// Retrieve a bootstrap token
getMsg := &mdm.GetBootstrapToken{}
token, err := ms.RetrieveBootstrapToken(req, getMsg)
if err != nil {
    log.Fatal(err)
}
fmt.Println(token)
```

## Notes

- Both methods delegate to `execStores`, which fans out the operation across all registered `storage.AllStorage` backends.
- `RetrieveBootstrapToken` performs an unchecked type assertion (`val.(*mdm.BootstrapToken)`); ensure all backends return a compatible type to avoid panics.
