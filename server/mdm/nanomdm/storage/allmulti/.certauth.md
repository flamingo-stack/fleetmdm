Implements certificate authentication storage operations for `MultiAllStorage` by delegating each method to all underlying stores via `execStores`.

## Key Components

| Method | Description |
|---|---|
| `HasCertHash` | Checks if a certificate hash exists across all stores |
| `EnrollmentHasCertHash` | Checks if a certificate hash is associated with an enrollment |
| `IsCertHashAssociated` | Verifies whether a cert hash is linked to an MDM request |
| `AssociateCertHash` | Associates a cert hash with an MDM request, including expiry time |
| `EnrollmentFromHash` | Retrieves an enrollment ID from a certificate hash |

## Usage Example

```go
ms := &MultiAllStorage{ /* configured stores */ }

req := &mdm.Request{Context: ctx}
hash := "abc123..."

// Check if cert hash is known
exists, err := ms.HasCertHash(req, hash)

// Associate a cert hash with expiry
expiry := time.Now().Add(365 * 24 * time.Hour)
err = ms.AssociateCertHash(req, hash, expiry)

// Retrieve enrollment ID from hash
enrollmentID, err := ms.EnrollmentFromHash(ctx, hash)
```

All methods fan out to every registered `AllStorage` backend via `execStores`, ensuring cert auth state is consistent across all stores. See the full implementation at [`certauth.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/nanomdm/storage/allmulti/certauth.go).
