Dispatches MDM storage operations to multiple `AllStorage` backends concurrently, returning results from the primary store and logging errors from secondary stores.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `MultiAllStorage` | struct | Fan-out dispatcher holding a logger and a slice of `AllStorage` backends |
| `New` | constructor | Creates a `MultiAllStorage`; panics if no stores are provided |
| `execStores` | internal | Runs an operation against all stores concurrently via goroutines; returns the first store's result/error |
| `returnCollector` | internal struct | Captures per-store results and errors from concurrent goroutine execution |

### Implemented Storage Methods

- `StoreAuthenticate` — persists MDM Authenticate messages
- `StoreTokenUpdate` — persists MDM TokenUpdate messages
- `RetrieveTokenUpdateTally` — retrieves token update count from the primary store
- `StoreUserAuthenticate` — persists MDM UserAuthenticate messages
- `Disable` — marks a device as disabled
- `ExpandEmbeddedSecrets` — expands secrets within a document string
- `BulkDeleteHostUserCommandsWithoutResults` — bulk deletes MDM commands lacking results

> **Note:** `ExpandHostSecrets` and `SetRecoveryLockFailed` are stubs that return no-op results.

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/server/mdm/nanomdm/storage/allmulti"
    "github.com/micromdm/nanolib/log/stdlogfmt"
)

logger := stdlogfmt.New()

multi := allmulti.New(logger, primaryStore, replicaStore)

// All writes fan out to both stores concurrently.
// Errors from replicaStore are logged; errors from primaryStore are returned.
err := multi.StoreAuthenticate(req, authMsg)
```

## Concurrency Behavior

Each call to `execStores` spawns one goroutine per registered store. Store `0` (the first store passed to `New`) is authoritative — its return value and error are propagated to the caller. Errors from all other stores are logged via `ctxlog` at `Info` level and discarded from the return path.
