Implements MDM command queue operations for `MultiAllStorage`, delegating each queue action across all configured storage backends via `execStores`.

## Key Components

| Function | Description |
|---|---|
| `StoreCommandReport` | Persists a command result/report from an MDM device across all storage backends |
| `RetrieveNextCommand` | Fetches the next pending command for a device, optionally skipping `NotNow` responses |
| `ClearQueue` | Removes all pending commands from a device's queue across all backends |
| `EnqueueCommand` | Adds a new MDM command to the queue for one or more device IDs |

## Usage Example

```go
ms := &MultiAllStorage{ /* configured backends */ }

// Enqueue a command for multiple devices
errs, err := ms.EnqueueCommand(ctx, []string{"device-1", "device-2"}, cmd)
if err != nil {
    log.Fatal(err)
}

// Retrieve next command for a device
req := &mdm.Request{Context: ctx}
next, err := ms.RetrieveNextCommand(req, true) // skipNotNow=true

// Store the result after execution
err = ms.StoreCommandReport(req, &mdm.CommandResults{ /* ... */ })

// Clear the queue if needed
err = ms.ClearQueue(req)
```

## Notes

- All operations fan out to every registered storage backend via `execStores`; if any backend fails, the error is returned
- `RetrieveNextCommand` and `EnqueueCommand` return values from the **primary** backend (first result via `execStores`)
