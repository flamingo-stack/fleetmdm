Defines the core storage interfaces for MDM enrollments, commands, push notifications, and certificate authentication within the NanoMDM service layer.

## Key Components

| Interface | Purpose |
|---|---|
| `CheckinStore` | Stores MDM check-in lifecycle events (Authenticate, TokenUpdate, Disable) |
| `CommandAndReportResultsStore` | Manages the MDM command queue — storing reports, retrieving next commands, bulk-deleting |
| `BootstrapTokenStore` | Escrows and retrieves Bootstrap Tokens |
| `SecretStore` | Expands fleet/host-scoped secrets and tracks recovery lock failures |
| `ServiceStore` | Composite interface combining all core service stores |
| `PushStore` | Retrieves APNs push data by enrollment ID |
| `PushCertStore` | Manages APNs push certificates with staleness detection |
| `CommandEnqueuer` | Enqueues MDM commands to one or more device IDs |
| `CertAuthStore` | Associates and validates cert hashes to enrollments |
| `CertAuthRetriever` | Looks up an enrollment ID from a certificate hash |
| `StoreMigrator` | Streams check-in data (Authenticate + TokenUpdate) for migration |
| `TokenUpdateTallyStore` | Retrieves the count of TokenUpdate messages for a given ID |

## Usage Example

```go
// Implement ServiceStore to back the MDM service
type MyStore struct{}

func (s *MyStore) StoreAuthenticate(r *mdm.Request, msg *mdm.Authenticate) error { ... }
func (s *MyStore) StoreTokenUpdate(r *mdm.Request, msg *mdm.TokenUpdate) error { ... }
func (s *MyStore) Disable(r *mdm.Request) error { ... }
func (s *MyStore) StoreCommandReport(r *mdm.Request, report *mdm.CommandResults) error { ... }
func (s *MyStore) RetrieveNextCommand(r *mdm.Request, skipNotNow bool) (*mdm.CommandWithSubtype, error) { ... }
// ... implement remaining ServiceStore methods

var _ storage.ServiceStore = (*MyStore)(nil) // compile-time check
```

## Notes

- `ServiceStore` is the primary aggregate interface — most service implementations depend on it.
- `RetrievePushInfo` silently skips unknown or unenrolled IDs; callers must check for missing keys in the returned map.
- `StoreMigrator` requires ordered delivery: device `Authenticate` → device `TokenUpdate` → user `TokenUpdate`.
