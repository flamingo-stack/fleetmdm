Aggregates all NanoMDM storage interfaces into a single composite interface, allowing implementations to satisfy the complete storage contract in one type.

## Key Components

### `AllStorage` Interface
A composite interface that embeds all required NanoMDM storage sub-interfaces:

| Interface | Purpose |
|---|---|
| `ServiceStore` | Core MDM service data storage |
| `PushStore` | Push notification token/endpoint storage |
| `PushCertStore` | APNs push certificate storage |
| `CommandEnqueuer` | MDM command queue management |
| `CertAuthStore` | Certificate-based authentication storage |
| `CertAuthRetriever` | Certificate authentication data retrieval |
| `StoreMigrator` | Storage schema migration support |
| `TokenUpdateTallyStore` | Token update event tracking |

## Usage Example

```go
// Implement AllStorage to satisfy the full NanoMDM storage contract
type MyStorage struct {
    db *sql.DB
}

// Ensure MyStorage satisfies AllStorage at compile time
var _ storage.AllStorage = (*MyStorage)(nil)

// Pass to NanoMDM server as a unified storage backend
func NewServer(store storage.AllStorage) *nanomdm.Server {
    return nanomdm.New(store)
}
```

## Notes

- Implementing `AllStorage` ensures a single backend satisfies every storage dependency NanoMDM requires
- Compile-time interface checks (`var _ AllStorage = (*MyImpl)(nil)`) are recommended to catch missing method implementations early
- See individual sub-interface files in the [`storage`](https://github.com/flamingo-stack/fleetmdm/blob/main/storage) package for method-level contracts
