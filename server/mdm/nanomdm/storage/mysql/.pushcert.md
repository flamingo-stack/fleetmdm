Manages APNs push certificate storage and retrieval for the NanoMDM MySQL backend, handling certificate persistence, staleness tracking, and TLS key pair reconstruction.

## Key Components

| Function | Description |
|---|---|
| `RetrievePushCert` | Fetches PEM cert/key from `nano_push_certs` by topic, reconstructs a `tls.Certificate`, and returns the current stale token |
| `IsPushCertStale` | Compares a provided stale token against the DB value to determine if the cached cert is outdated |
| `StorePushCert` | Upserts a PEM cert/key pair, deriving the APNs topic automatically; increments `stale_token` on update |

## Usage Example

```go
// Store a new push certificate
err := storage.StorePushCert(ctx, pemCertBytes, pemKeyBytes)

// Retrieve the push certificate for a topic
cert, staleToken, err := storage.RetrievePushCert(ctx, "com.apple.mgmt.External.abc123")

// Check if a previously cached token is stale
isStale, err := storage.IsPushCertStale(ctx, "com.apple.mgmt.External.abc123", staleToken)
if isStale {
    // refresh cached certificate
}
```

## Notes

- The `stale_token` column is an integer incremented on every `UPDATE`, enabling cache invalidation without timestamp comparison.
- Topic extraction is handled by `cryptoutil.TopicFromPEMCert`, so callers only need to provide the raw PEM bytes.
- Uses MySQL `ON DUPLICATE KEY UPDATE` to safely handle both insert and update in a single query.
