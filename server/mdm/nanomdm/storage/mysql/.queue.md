Manages the MDM command queue in MySQL, handling enqueuing, retrieval, deletion, and reporting of MDM commands for device enrollments.

## Key Components

| Function/Method | Description |
|---|---|
| `enqueue` | Inserts a command into `nano_commands` and batches enrollment queue entries into `nano_enrollment_queue`, respecting MySQL's 65535 placeholder limit |
| `EnqueueCommand` | Public wrapper around `enqueue` with deadlock-safe retry logic via `WithRetryTxx` |
| `deleteCommand` | Removes a queued command and its results using a row-level lock (`FOR UPDATE`) to prevent race conditions across concurrent device responses |
| `StoreCommandReport` | Persists a device's command result; handles `Idle`, `NotNow` (tally tracking), and terminal statuses; deletes the command if removal mode (`rm`) is enabled |
| `RetrieveNextCommand` | Fetches the highest-priority active queued command for a device; uses a direct UUID string literal for macOS (performance optimization) and a prepared statement for iOS/user enrollments |
| `ClearQueue` | Marks all unprocessed/`NotNow` commands inactive for a device and its user-channel enrollments |
| `BulkDeleteHostUserCommandsWithoutResults` | Bulk-removes unresulted queued commands by command UUID and host/user ID batches (10,000 per batch) |

## Usage Example

```go
// Enqueue a command to multiple devices
commandErrors, err := storage.EnqueueCommand(ctx, []string{"device-uuid-1", "device-uuid-2"}, cmd)

// Retrieve the next command for a device (skip NotNow entries)
next, err := storage.RetrieveNextCommand(mdmRequest, true)

// Store a device's command result
err = storage.StoreCommandReport(mdmRequest, &mdm.CommandResults{
    CommandUUID: "cmd-uuid",
    Status:      "Acknowledged",
    Raw:         rawXML,
})

// Clear the queue for a device channel
err = storage.ClearQueue(mdmRequest)

// Clean up commands with no results when a profile is removed
err = storage.BulkDeleteHostUserCommandsWithoutResults(ctx, map[string][]string{
    "cmd-uuid": {"device-uuid-1", "device-uuid-2"},
})
```

> **Note:** `RetrieveNextCommand` uses an ANTIJOIN (`NOT EXISTS`) optimization on `nano_command_results` and short-circuits UUID validation to avoid prepared statements for macOS devices.
