Retrieves APNs push notification info for enrolled MDM devices from MySQL, returning a map of enrollment IDs to push payloads.

## Key Components

### `RetrievePushInfo(ctx, ids) (map[string]*mdm.Push, error)`

Queries the `nano_enrollments` table for push notification data (`topic`, `push_magic`, `token_hex`) matching the provided enrollment IDs. Returns fewer results than requested if some IDs are not found — callers must reconcile the difference.

- Validates that at least one ID is provided
- Builds a parameterized `IN (?, ?, ...)` clause dynamically to prevent SQL injection
- Converts the hex-encoded `token_hex` column to a binary token via `push.SetTokenString`

## Usage Example

```go
store, _ := mysql.New(db)

pushInfos, err := store.RetrievePushInfo(ctx, []string{
    "device-enrollment-id-1",
    "device-enrollment-id-2",
})
if err != nil {
    log.Fatal(err)
}

for id, push := range pushInfos {
    fmt.Printf("Device %s → topic: %s, magic: %s\n", id, push.Topic, push.PushMagic)
}
```

## Notes

- Returns `error` if `ids` is empty
- Missing enrollment IDs are silently omitted from the result map — callers should check `len(pushInfos)` against `len(ids)`
- `rows.Err()` is propagated to catch any iteration-level errors
