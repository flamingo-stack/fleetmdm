Handles certificate authentication associations for MDM enrollments, providing MySQL-backed storage operations for managing certificate hash-to-enrollment ID mappings in the `nano_cert_auth_associations` table.

## Key Components

| Function | Description |
|---|---|
| `queryRowContextRowExists` | Helper that executes a `COUNT(*)` query and returns a boolean indicating row existence |
| `EnrollmentHasCertHash` | Checks if an enrollment ID has any certificate hash association |
| `HasCertHash` | Checks if a specific certificate hash exists in the store |
| `IsCertHashAssociated` | Verifies that a certificate hash is associated with a specific enrollment ID |
| `AssociateCertHash` | Upserts a certificate hash association for an enrollment, including expiry time |
| `EnrollmentFromHash` | Retrieves the enrollment ID associated with a given certificate hash |

> **Note:** All hash comparisons use lowercase normalization via `strings.ToLower` before storage and lookup.

## Usage Example

```go
storage := &MySQLStorage{db: db}

// Associate a certificate hash with an enrollment
err := storage.AssociateCertHash(req, "abc123def456...", certExpiry)
if err != nil {
    log.Fatal(err)
}

// Verify the association exists
associated, err := storage.IsCertHashAssociated(req, "abc123def456...")
if err != nil {
    log.Fatal(err)
}

// Look up an enrollment ID from a hash
enrollmentID, err := storage.EnrollmentFromHash(ctx, "abc123def456...")
```
