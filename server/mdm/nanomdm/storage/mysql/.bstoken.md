Handles persistent storage and retrieval of MDM Bootstrap Tokens in the MySQL backend for NanoMDM.

## Key Components

- **`StoreBootstrapToken`** — Upserts the base64-encoded bootstrap token for a device in the `nano_devices` table, recording a timestamp and updating the device's last-seen time.
- **`RetrieveBootstrapToken`** — Fetches the stored base64 bootstrap token for a device, deserializes it into an `mdm.BootstrapToken`, and updates last-seen on success.

## Usage Example

```go
// Store a bootstrap token received from a SetBootstrapToken MDM command
err := storage.StoreBootstrapToken(mdmRequest, setBootstrapTokenMsg)
if err != nil {
    log.Fatalf("failed to store bootstrap token: %v", err)
}

// Retrieve the bootstrap token for a GetBootstrapToken MDM command
token, err := storage.RetrieveBootstrapToken(mdmRequest, getBootstrapTokenMsg)
if err != nil {
    log.Fatalf("failed to retrieve bootstrap token: %v", err)
}
```

## Notes

- Uses `nullEmptyString` to store a SQL `NULL` when the token is an empty string, avoiding blank token records.
- `RetrieveBootstrapToken` returns `nil, nil` when no token exists (`tokenB64.Valid == false`), signaling absence without an error.
- Both operations call `updateLastSeen` to keep device activity timestamps current.
