Provides asynchronous, batched "last seen" tracking for host identifiers, buffering IDs in memory and flushing them to a callback either when a capacity threshold is reached or on a periodic timer interval.

## Key Components

### `asyncLastSeen`
Coordinates buffered host-seen tracking with two flush strategies:
- **`newAsyncLastSeen(flushInterval, flushCap, fn)`** — constructs an instance with a flush interval, capacity cap, and a callback `fn` to process batched IDs.
- **`markHostSeen(ctx, id)`** — adds a host ID to the buffer; immediately flushes and invokes `fn` if the capacity cap is reached.
- **`runFlushLoop(ctx)`** — runs a ticker-based background loop that flushes accumulated IDs on each interval tick, resetting the ticker after each non-empty flush.

### `seenSet[T cmp.Ordered]`
A generic, mutex-protected set for deduplicating ordered identifiers:
- **`add(id, capacity)`** — inserts an ID and returns a sorted, cleared batch if capacity is reached.
- **`getAndClear()`** — atomically retrieves and clears all stored IDs, returning them sorted.
- **`getAndClearLocked()`** — internal variant for use when the mutex is already held.

> IDs are sorted before returning to help prevent deadlocks in downstream batch SQL operations.

## Usage Example

```go
flush := func(ctx context.Context, ids []string) {
    // e.g., bulk UPDATE hosts SET last_seen = NOW() WHERE id IN (ids...)
}

tracker := newAsyncLastSeen(30*time.Second, 500, flush)

// In a goroutine, run the periodic flush loop
go tracker.runFlushLoop(ctx)

// On each host check-in
tracker.markHostSeen(ctx, "host-uuid-123")
```
