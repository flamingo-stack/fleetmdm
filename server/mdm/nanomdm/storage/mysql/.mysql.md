MySQL-backed storage layer for NanoMDM, handling device enrollment, authentication, token updates, and last-seen tracking.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MySQLStorage` | struct | Core storage type wrapping a `*sql.DB` connection with optional async last-seen tracking |
| `Schema` | `string` | Embedded SQL schema loaded from `schema.sql` at compile time |
| `ErrNoCert` | `error` | Sentinel error for MDM requests missing a certificate |
| `New` | func | Constructor accepting functional options; opens/validates the DB connection and starts the async flush goroutine |
| `Option` | type | Functional option for configuring `MySQLStorage` |

**Available options:** `WithDB`, `WithDSN`, `WithDriver`, `WithLogger`, `WithReaderFunc`, `WithDeleteCommands`, `WithAsyncLastSeen`

**Key methods:**

| Method | Description |
|--------|-------------|
| `StoreAuthenticate` | Upserts device identity cert; preserves bootstrap token during SCEP renewal |
| `StoreTokenUpdate` | Upserts enrollment record with push topic, push magic, and token; tracks hardware attestation |
| `StoreUserAuthenticate` | Stores user-channel authenticate or digest response; triggers last-seen update |
| `Disable` | Marks all enrollments for a device as disabled on CheckOut |
| `RetrieveTokenUpdateTally` | Returns the cumulative token update count for an enrollment |
| `updateLastSeenBatch` | Bulk-updates `last_seen_at` via `sqlx.In`; used by the async flush loop |

## Usage Example

```go
store, err := mysql.New(
    mysql.WithDSN("user:pass@tcp(localhost:3306)/fleet"),
    mysql.WithLogger(slog.Default()),
    mysql.WithAsyncLastSeen(1000, 2*time.Second),
)
if err != nil {
    log.Fatal(err)
}

// Disable async last-seen updates (e.g. in tests)
// os.Setenv("FLEET_DISABLE_ASYNC_NANO_LAST_SEEN", "1")
```

> **Note:** Set `FLEET_DISABLE_ASYNC_NANO_LAST_SEEN=1` to skip the background flush goroutine, useful in test environments.
