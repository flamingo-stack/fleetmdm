Manages persistence of MDM Bootstrap Tokens to the filesystem, providing store and retrieve operations for the `FileStorage` backend.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `StoreBootstrapToken` | Method | Writes a bootstrap token to disk, or removes the file if the token payload is empty |
| `RetrieveBootstrapToken` | Method | Reads a bootstrap token from disk; returns `nil, nil` if no token has been escrowed yet |

## Usage Example

```go
// Store a bootstrap token received from an MDM SetBootstrapToken message
err := storage.StoreBootstrapToken(request, setBootstrapTokenMsg)
if err != nil {
    log.Fatalf("failed to store bootstrap token: %v", err)
}

// Retrieve a previously escrowed bootstrap token
token, err := storage.RetrieveBootstrapToken(request, getBootstrapTokenMsg)
if err != nil {
    log.Fatalf("failed to retrieve bootstrap token: %v", err)
}
if token == nil {
    log.Println("no bootstrap token escrowed yet")
}
```

## Behavior Notes

- **Store:** If `BootstrapToken` bytes are non-empty, the token is written to `BootstrapTokenFile`. If the payload is empty, the existing file is deleted; a missing file (`os.ErrNotExist`) is treated as a no-op.
- **Retrieve:** A missing file is silently ignored — `nil, nil` is returned rather than an error, distinguishing "not yet escrowed" from a genuine I/O failure.
