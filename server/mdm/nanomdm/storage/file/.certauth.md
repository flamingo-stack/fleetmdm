File-based certificate hash storage and association management for MDM enrollment authentication.

## Key Components

| Function | Description |
|---|---|
| `EnrollmentHasCertHash` | Checks if a cert hash file exists for a given enrollment ID |
| `HasCertHash` | Scans the global associations file to verify a hash exists anywhere |
| `IsCertHashAssociated` | Verifies a specific hash is linked to a specific enrollment ID |
| `AssociateCertHash` | Appends a new `enrollmentID,hash` entry to the associations file and writes the hash to the enrollment directory |
| `EnrollmentFromHash` | Looks up an enrollment ID by scanning the associations file for a matching hash |

## Usage Example

```go
// Associate a certificate hash with an enrollment
err := storage.AssociateCertHash(req, "abc123hash", time.Now())

// Verify the hash is globally known
exists, err := storage.HasCertHash(req, "abc123hash")

// Verify hash belongs to a specific enrollment
associated, err := storage.IsCertHashAssociated(req, "abc123hash")

// Reverse lookup: find enrollment ID from hash
enrollmentID, err := storage.EnrollmentFromHash(ctx, "abc123hash")
```

## Notes

- The global associations file (`CertAuthAssociationsFilename`) stores `enrollmentID,hash` pairs, one per line, and is **append-only**
- Per-enrollment cert hash is stored in `CertAuthFilename` within the enrollment directory
- Hash lookups use `strings.Contains`, so the associations file format must ensure hashes don't appear as substrings of other fields
- `EnrollmentFromHash` returns an empty string (not an error) when no match is found
