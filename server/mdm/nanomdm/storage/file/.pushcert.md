Provides filesystem-based storage for APNs push notification certificates used in NanoMDM, handling read, write, and staleness checks for PEM-encoded cert/key pairs.

## Key Components

### `PushCertFileStorage`
Standalone struct for managing a single push certificate pair on disk.

| Field | Description |
|---|---|
| `certFilepath` | Path to the `.pem` certificate file |
| `keyFilepath` | Path to the `.key` private key file |
| `allowStore` | Gate that must be `true` to permit writes |

**Methods:**
- `NewPushCertFileStorage(certPath, keyPath string)` — constructor for direct use
- `RetrievePushCert` — reads cert and key from disk, validates topic match, returns `*tls.Certificate` and a stale token
- `IsPushCertStale` — compares a provided stale token against the cert file's modification time
- `StorePushCert` — writes PEM cert (`0644`) and key (`0600`) to disk; fails unless `allowStore` is set
- `getPushCertStaleToken` — returns the file's `ModTime` string as the staleness token

### `FileStorage` pass-through methods
`RetrievePushCert`, `IsPushCertStale`, and `StorePushCert` on `FileStorage` delegate to a dynamically constructed `PushCertFileStorage`, deriving file paths from the topic name (e.g., `<base>/<topic>.pem`).

## Usage Example

```go
// Standalone usage
store := file.NewPushCertFileStorage("/etc/mdm/push.pem", "/etc/mdm/push.key")

cert, staleToken, err := store.RetrievePushCert(ctx, "com.apple.mgmt.example")
if err != nil {
    log.Fatal(err)
}

stale, err := store.IsPushCertStale(ctx, "com.apple.mgmt.example", cachedToken)
if err != nil || stale {
    // refresh the cert
}

// Write new cert/key pair
err = store.StorePushCert(ctx, pemCertBytes, pemKeyBytes)
```

> **Note:** `StorePushCert` on `PushCertFileStorage` requires `allowStore: true`. When called via `FileStorage.StorePushCert`, this flag is set automatically.
