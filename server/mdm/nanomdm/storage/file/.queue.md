Filesystem-backed MDM command queue implementation for managing command lifecycle (enqueue, dispatch, result storage) across device enrollments using subdirectories as queue states.

## Key Components

### `queue` struct
Internal type representing a named subdirectory queue tied to an enrollment. Supports four states via constants:

| Constant | Value | Purpose |
|---|---|---|
| `subQueue` | `Queue` | Active pending commands |
| `subNotNow` | `QueueNotNow` | Deferred commands (device responded `NotNow`) |
| `subDone` | `QueueDone` | Completed commands with results |
| `subInactive` | `QueueInactive` | Cleared/deactivated commands |

### `queue` Methods
- **`enqueue(uuid, raw)`** — Writes a `.plist` command file into the queue directory
- **`exists(uuid)`** — Checks if a command file exists in this queue
- **`move(uuid, dest)`** — Atomically moves a command between queue subdirectories
- **`getNext()`** — Returns the first decoded `.plist` command found in the queue
- **`writeResults / removeResults`** — Manages `.result.plist` sidecar files

### `FileStorage` Methods (public API)
- **`EnqueueCommand`** — Writes a command to the active queue for one or more enrollment IDs; returns per-ID errors
- **`StoreCommandReport`** — Routes command results: moves to `QueueDone` on success or `QueueNotNow` on deferral
- **`RetrieveNextCommand`** — Fetches the next pending command, optionally skipping `NotNow`-deferred items
- **`ClearQueue`** — Moves all pending/deferred commands to `QueueInactive` for a device and its sub-enrollments

## Usage Example

```go
// Enqueue a command for two devices
idErrs, err := storage.EnqueueCommand(ctx, []string{"device-1", "device-2"}, &mdm.CommandWithSubtype{
    Command: mdm.Command{CommandUUID: "abc-123"},
    Raw:     plistBytes,
})

// Retrieve the next command for a device
cmd, err := storage.RetrieveNextCommand(request, false) // false = include NotNow queue

// Store the device's response
err = storage.StoreCommandReport(request, &mdm.CommandResults{
    CommandUUID: "abc-123",
    Status:      "Acknowledged",
    Raw:         resultBytes,
})
```
