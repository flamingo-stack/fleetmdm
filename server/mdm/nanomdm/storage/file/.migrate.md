Provides migration support for the `FileStorage` backend by retrieving stored MDM check-in messages (Authenticate and TokenUpdate) and streaming them over a channel for processing during enrollment migration.

## Key Components

### `sendCheckinMessage(e *enrollment, filename string, c chan<- interface{})`
Reads a check-in message file from an enrollment directory, decodes it using `mdm.DecodeCheckin`, and sends the result (or any error) to the provided channel.

### `(*FileStorage) RetrieveMigrationCheckins(_ context.Context, c chan<- interface{}) error`
Iterates over all enrollment directories in the storage path in two passes — first for device-channel enrollments (those with an `Authenticate` file), then for user-channel enrollments (those without one). For each valid enrollment it streams the `Authenticate` message (device-channel only), followed by the `TokenUpdate` message.

## Usage Example

```go
store, err := file.New("/var/lib/mdm/enrollments")
if err != nil {
    log.Fatal(err)
}

ch := make(chan interface{})

go func() {
    if err := store.RetrieveMigrationCheckins(context.Background(), ch); err != nil {
        log.Printf("migration error: %v", err)
    }
    close(ch)
}()

for msg := range ch {
    switch v := msg.(type) {
    case error:
        log.Printf("enrollment error: %v", v)
    default:
        // process decoded MDM check-in message
        log.Printf("received check-in: %T", v)
    }
}
```

## Notes

- Enrollments missing both `Authenticate` and `TokenUpdate` files are skipped as invalid.
- User-channel enrollments (no `Authenticate` file) only emit a `TokenUpdate` message.
- A `TODO` exists to synthesize stored `UnlockToken` data into `TokenUpdate` messages, as unlock tokens are currently saved out-of-band.
