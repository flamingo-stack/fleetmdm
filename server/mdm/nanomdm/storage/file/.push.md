Retrieves APNs push notification data for enrolled MDM devices by reading stored token update files from the filesystem.

## Key Components

### `RetrievePushInfo`
```text
func (s *FileStorage) RetrievePushInfo(_ context.Context, ids []string) (map[string]*mdm.Push, error)
```
Iterates over a list of enrollment IDs, reads each device's `TokenUpdate` file, decodes the checkin message, and returns a map of enrollment ID to `*mdm.Push`. Enrollments with missing token files are silently skipped (treated as incomplete or non-existent).

## Usage Example

```go
storage := &FileStorage{ /* ... */ }

pushInfos, err := storage.RetrievePushInfo(ctx, []string{"device-id-1", "device-id-2"})
if err != nil {
    log.Fatal(err)
}

for id, push := range pushInfos {
    fmt.Printf("Device %s push token: %s\n", id, push.PushMagic)
}
```

## Behavior Notes

| Condition | Behavior |
|---|---|
| `TokenUpdate` file missing | Enrollment skipped silently |
| File read error (other) | Returns `nil, err` |
| File content not a `*mdm.TokenUpdate` | Returns type assertion error |
| Valid token | Added to result map |
