Shared CLI utilities for configuring and initializing NanoMDM storage backends from command-line flags, supporting `file` and `mysql` backends with optional multi-storage aggregation.

## Key Components

- **`StringAccumulator`** — A `flag.Value` implementation that accumulates repeated flag values into a string slice.
- **`Storage`** — Holds parsed CLI flags (`-storage`, `-dsn`, `-options`) used to configure one or more storage backends.
- **`Storage.Parse()`** — Validates flag counts, instantiates each named backend, and returns either a single `AllStorage` or an `allmulti` aggregate when multiple backends are specified. Defaults to `file` storage at path `db` if no flags are provided.
- **`fileStorageConfig()`** — Initializes a `file.FileStorage`; rejects any options since the file backend supports none.
- **`mysqlStorageConfig()`** — Initializes a `mysql.MySQLStorage`, wiring in a bridged `slog.Logger` and parsing comma-separated `key=value` options (currently supports `delete=1` to enable command deletion).
- **`nanoLibSlogHandler`** — An `slog.Handler` adapter that bridges a `nanolib/log.Logger` to the `*slog.Logger` interface required by the MySQL storage backend.

## Usage Example

```go
s := cli.NewStorage()

// Register flags (typically via flag.Var)
flag.Var(&s.Storage, "storage", "storage backend (file|mysql)")
flag.Var(&s.DSN, "dsn", "data source name")
flag.Var(&s.Options, "storage-options", "backend options")
flag.Parse()

store, err := s.Parse(logger)
if err != nil {
    log.Fatal(err)
}
// store implements storage.AllStorage and is ready for use
```

For MySQL with command deletion enabled:

```bash
-storage mysql -dsn "user:pass@tcp(localhost)/nanomdm" -storage-options "delete=1"
```

Multiple backends are automatically wrapped in an `allmulti` store for fan-out writes:

```bash
-storage file -dsn ./db -storage mysql -dsn "user:pass@tcp(localhost)/nanomdm"
```
