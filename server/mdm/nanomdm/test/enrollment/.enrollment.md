Provides MDM enrollment emulation for testing, handling device check-in flows including Authenticate, TokenUpdate, and Bootstrap Token operations against an MDM server.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Enrollment` | struct | Core type emulating an MDM device enrollment with identity, push info, and transport |
| `Transport` | interface | Defines HTTP check-in and report/fetch operations |
| `ErrAlreadyEnrolled` | error | Sentinel error for duplicate enrollment attempts |
| `NewRandomDeviceEnrollment` | func | Creates a randomly-identified device enrollment |
| `NewFromCheckins` | func | Loads enrollment state from saved Authenticate/TokenUpdate plist files |
| `ReplaceIdentityRandom` | func | Replaces the enrollment's certificate/key pair with a new random one |
| `DoEnroll` | method | Sends Authenticate + TokenUpdate check-ins to fully enroll a device |
| `DoEscrowBootstrapToken` | method | Sends a `SetBootstrapToken` check-in to the MDM server |
| `DoGetBootstrapToken` | method | Retrieves a `GetBootstrapToken` response from the MDM server |
| `DoReportAndFetch` | method | Sends command results and retrieves the next pending command |

## Usage Example

```go
// Create a new random device enrollment
enroll, err := enrollment.NewRandomDeviceEnrollment(
    httpClient,
    "com.apple.mgmt.push.topic",
    "https://mdm.example.com/mdm",
    "https://mdm.example.com/checkin",
)
if err != nil {
    log.Fatal(err)
}

// Perform full enrollment (Authenticate + TokenUpdate)
if err := enroll.DoEnroll(ctx); err != nil {
    log.Fatalf("enrollment failed: %v", err)
}

// Send an empty report and fetch the next command
resp, err := enroll.DoReportAndFetch(ctx, strings.NewReader(""))
if err != nil {
    log.Fatal(err)
}
defer resp.Body.Close()
```

## Notes

- Enrollment is safe for concurrent use; check-in operations are protected by a mutex.
- Identity is a self-signed RSA keypair generated via `test.SimpleSelfSignedRSAKeypair`.
- Push tokens are regenerated on every `DoTokenUpdate` call to simulate APNs behavior.
