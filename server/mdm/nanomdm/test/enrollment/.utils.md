Provides HTTP error handling utilities for the enrollment package, including a structured error type and response validation helper.

## Key Components

- **`HTTPError`** — Struct capturing HTTP error details: raw body bytes, status string, and status code.
- **`NewHTTPError(response, body)`** — Constructor for `HTTPError`; safely handles a nil `*http.Response`.
- **`(*HTTPError).Error()`** — Implements the `error` interface, formatting a human-readable message from status and body.
- **`HTTPErrors(r)`** — Inspects an `*http.Response` and returns a non-nil error for any non-200 status, reading up to `Limit10KiB` (10 KiB) of the response body.
- **`Limit10KiB`** — Constant (`10 * 1024`) capping how much of a non-200 body is read.

## Usage Example

```go
resp, err := http.Get("https://example.com/enroll")
if err != nil {
    log.Fatal(err)
}
defer resp.Body.Close()

if err := enrollment.HTTPErrors(resp); err != nil {
    var httpErr *enrollment.HTTPError
    if errors.As(err, &httpErr) {
        fmt.Printf("status %d: %s\n", httpErr.StatusCode, httpErr.Body)
    }
    log.Fatal(err)
}
// proceed with 200 response...
```

## Notes

- The caller remains responsible for closing the response body; `HTTPErrors` does not close it.
- Passing a `nil` response to `HTTPErrors` returns an explicit `"nil response"` error rather than panicking.
