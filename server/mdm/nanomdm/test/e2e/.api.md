Provides an HTTP-based API client for enqueuing MDM commands during end-to-end tests, wrapping raw command dispatch against a NanoMDM-compatible endpoint.

## Key Components

- **`Doer` interface** — Abstracts HTTP execution (`Do(*http.Request) (*http.Response, error)`), allowing test doubles or custom transports to be injected.
- **`api` struct** — Holds a `Doer` instance and implements MDM command dispatch logic.
- **`RawCommandEnqueue`** — Serializes an `mdm.Command` to plist, constructs a POST request to `enqueueURL` with a comma-separated list of device IDs, optionally sets the `nopush=1` query parameter, and returns any HTTP-level errors.

## Usage Example

```go
client := &api{doer: http.DefaultClient}

cmd := &mdm.Command{
    CommandUUID: "some-uuid",
    Command: mdm.CommandPayload{
        RequestType: "DeviceLock",
    },
}

err := client.RawCommandEnqueue(ctx, []string{"device-id-1", "device-id-2"}, cmd, false)
if err != nil {
    log.Fatal(err)
}
```

> **Note:** `enqueueURL` must have a trailing slash (e.g., `https://mdm.example.com/enqueue/`); the function returns an error immediately if the slash is missing.

## Notes

- Intended for use in the `e2e` test package only — not for production MDM dispatch.
- Error handling delegates to `enrollment.HTTPErrors`, which interprets non-2xx responses from the NanoMDM server.
