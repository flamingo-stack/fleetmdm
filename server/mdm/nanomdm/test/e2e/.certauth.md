End-to-end tests for NanoMDM certificate-based authentication, verifying that device identity certificates are correctly associated and validated during MDM enrollment flows.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `certAuth` | func | Tests standard cert auth flow: blocks pre-auth messages, allows post-auth messages, and rejects spoofed device identities |
| `certAuthRetro` | func | Tests retroactive cert association mode, which permits messages before `Authenticate` but still rejects cert reuse/spoofing |
| `expectErr` | func | Helper that asserts an error matches an expected value using `errors.Is` |
| `setupEnrollment` | func | Creates a random device enrollment and generates parsed `Authenticate` and `TokenUpdate` MDM messages |

## Usage Example

```go
func TestCertAuth(t *testing.T) {
    ctx := context.Background()

    // Provide a storage backend implementing CertAuthStore
    store := inmem.New()

    // Standard cert auth — Authenticate must precede other messages
    certAuth(t, ctx, store)

    // Retroactive mode — association happens on first message received
    certAuthRetro(t, ctx, store)
}
```

## Test Scenarios Covered

1. **Pre-auth rejection** — `TokenUpdate` before `Authenticate` returns `ErrNoCertAssoc`
2. **Successful auth** — `Authenticate` associates the cert hash; subsequent `TokenUpdate` succeeds
3. **Spoofed identity** — replacing the device certificate after association returns `ErrNoCertAssoc`
4. **Retroactive mode** — first `TokenUpdate` (no prior `Authenticate`) succeeds and establishes the association
5. **Cert reuse detection** — swapping the cert in retroactive mode returns `ErrNoCertReuse`
