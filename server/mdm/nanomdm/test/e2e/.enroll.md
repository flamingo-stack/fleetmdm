Provides a reusable E2E test helper for enrolling MDM devices and validating their push notification data against a storage backend.

## Key Components

- **`enrollDevice` interface** — Composite interface requiring `IDer`, `DoEnroll(context.Context) error`, and `GetPush() *mdm.Push`; represents any device capable of participating in MDM enrollment
- **`enroll` func** — Test helper that orchestrates device enrollment, retrieves push info from the store, and asserts the stored push data matches the device's expected push payload

## Usage Example

```go
func TestMyDeviceEnrollment(t *testing.T) {
    ctx := context.Background()
    store := setupTestPushStore(t)

    device := &MyTestDevice{id: "device-001"}

    // Enroll the device and verify push info is persisted correctly
    enroll(t, ctx, device, store)
}
```

## Notes

- Uses `reflect.DeepEqual` for push info comparison — the device's `GetPush()` return value must exactly match what is stored
- Calls `t.Fatal` on enrollment or storage retrieval errors, stopping the test immediately
- Validates exactly **one** push record is returned for the enrolled device ID
