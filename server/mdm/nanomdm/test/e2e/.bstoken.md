Provides end-to-end test helpers for verifying MDM Bootstrap Token escrow and retrieval behavior on newly enrolled devices.

## Key Components

### `bstokenDevice` Interface
Combines `IDer` with two MDM operations:
- `DoGetBootstrapToken` – retrieves the stored bootstrap token for a device
- `DoEscrowBootstrapToken` – stores a bootstrap token for a device

### `bstoken(t, ctx, d)`
Core test function that validates the full bootstrap token lifecycle:
1. Asserts a freshly enrolled device returns `nil` (no error, no token)
2. Escrows a known token payload (`"hello world"`)
3. Re-fetches and base64-decodes the token
4. Verifies the decoded value matches the original input

## Usage Example

```go
func TestBootstrapToken(t *testing.T) {
    ctx := context.Background()

    // d must implement bstokenDevice and represent a fresh enrollment
    d := newMockDevice(t)

    bstoken(t, ctx, d)
}
```

## Notes

- The `d` argument **must** represent a newly enrolled device with no previously escrowed token; the test explicitly fails if a non-nil token exists before escrow.
- The stored token is expected to be base64-encoded by the server; `bstoken` decodes it before comparison.
