Validates that the `TokenUpdate` tally mechanism increments correctly by checking an initial count, triggering a `TokenUpdate`, and confirming the count increases by one.

## Key Components

### `tokenTallyDevice` Interface
Combines `DoTokenUpdate(context.Context) error` with `IDer`, representing any device capable of performing a token update and providing an identifier.

### `tally` Function
```text
func tally(t *testing.T, ctx context.Context, d tokenTallyDevice, store storage.TokenUpdateTallyStore, initial int)
```
E2E test helper that:
1. Retrieves the current tally from the store and asserts it matches `initial`
2. Calls `DoTokenUpdate` on the device
3. Re-retrieves the tally and asserts it equals `initial + 1`

## Usage Example

```go
func TestMyDeviceTally(t *testing.T) {
    ctx := context.Background()
    device := newTestDevice(t, ctx)   // implements tokenTallyDevice
    store := newTestStore(t)          // implements storage.TokenUpdateTallyStore

    // Assert tally starts at 0 and increments to 1 after a TokenUpdate
    tally(t, ctx, device, store, 0)
}
```

## Notes

- The `initial` parameter allows tests to call `tally` sequentially, passing the updated count as the new baseline for subsequent calls.
- Failures in store retrieval or `DoTokenUpdate` call `t.Fatal()`, immediately halting the test.
- Defined under the `e2e` package; intended for use within end-to-end test suites only.
