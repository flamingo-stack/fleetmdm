Provides the core end-to-end test harness for NanoMDM, wiring together an in-memory HTTP server, a fake client, and a sequence of sub-tests that exercise enrollment, certificate auth, push info, tally, Bootstrap Token, and command queue behavior against a given storage backend.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `setupNanoMDM` | func | Builds an `http.ServeMux` with MDM check-in/command and raw command enqueue handlers, including MDM signature verification and certificate auth middleware. |
| `TestE2E` | func | Orchestrates the full end-to-end test suite: creates a logger, spins up the handler mux, creates a fake device via check-in plists, and runs ordered sub-tests. |
| `NanoMDMAPI` | interface | Minimal API surface for enqueuing raw MDM commands to one or more device IDs. |
| `IDer` | interface | Single-method helper interface for types that can return a string identifier. |
| `serverURL` / `enqueueURL` | const | HTTP path constants for the MDM and API enqueue endpoints (`/mdm` and `/api/enq/`). |

## Usage Example

```go
// Typically called from a storage-backend-specific test:
func TestMyBackend(t *testing.T) {
    store := mybackend.New(/* ... */)
    ctx   := context.Background()
    e2e.TestE2E(t, ctx, store)
}
```

The sub-tests run in order and cover:

| Sub-test | What it validates |
|---|---|
| `certauth` / `certauth-retro` | Certificate authentication flows |
| `invalid-pushinfo` | No global error for unknown enrollment IDs |
| `enroll` | Full device enrollment |
| `tally` / `tally-after-reenroll` | Per-device command tally resets on re-enroll |
| `bstoken` / `bstoken-after-reenroll` | Bootstrap Token lifecycle |
| `queue` | Command queue dispatch and retrieval |
