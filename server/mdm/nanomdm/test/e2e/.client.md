Provides a lightweight HTTP client adapter for E2E testing that routes requests directly to an `http.Handler` instead of making real network calls.

## Key Components

- **`HandlerClient`** — Struct that wraps an `http.Handler` and implements an HTTP client interface.
- **`NewHandlerClient`** — Constructor that accepts an `http.Handler` and returns a `*HandlerClient`.
- **`Do`** — Executes an HTTP request by passing it to the handler via `httptest.NewRecorder`, returning the recorded response.

## Usage Example

```go
mux := http.NewServeMux()
mux.HandleFunc("/health", func(w http.ResponseWriter, r *http.Request) {
    w.WriteHeader(http.StatusOK)
})

client := NewHandlerClient(mux)

req, _ := http.NewRequest(http.MethodGet, "/health", nil)
resp, err := client.Do(req)
if err != nil {
    log.Fatal(err)
}
fmt.Println(resp.StatusCode) // 200
```

## Notes

- No real TCP connections are made — useful for fast, isolated E2E tests.
- The `Do` method signature is compatible with `*http.Client`-style interfaces, making it easy to swap in place of a real client.
- Internally uses `httptest.NewRecorder` to capture handler responses.
