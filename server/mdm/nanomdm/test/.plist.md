Provides a test helper that encodes a Go value into an XML Property List (plist) format and returns it as an `io.Reader`.

## Key Components

- **`PlistReader(v interface{}) (io.Reader, error)`** — Encodes any Go value to a tab-indented XML plist using the `micromdm/plist` encoder, returning a readable buffer.

## Usage Example

```go
type DeviceInfo struct {
    UDID string
    Name string
}

device := DeviceInfo{UDID: "abc-123", Name: "Test Device"}

reader, err := test.PlistReader(device)
if err != nil {
    t.Fatal(err)
}

req := httptest.NewRequest(http.MethodPost, "/enroll", reader)
```

## Notes

- Intended for use in test packages only (package `test`)
- Output is tab-indented XML plist for readability in test assertions
- Source: [`https://github.com/flamingo-stack/fleetmdm/blob/main/plist.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/plist.go)
