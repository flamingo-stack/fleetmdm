Provides test utilities for MDM-related cryptographic operations and a no-op MDM service implementation used in unit tests.

## Key Components

### Functions

- **`GenerateRandomCertificateSerialNumber()`** — Generates a cryptographically random 128-bit certificate serial number as a `*big.Int`.
- **`SimpleSelfSignedRSAKeypair(cn string, days int)`** — Creates a 2048-bit RSA private key and a self-signed X.509 certificate with the given Common Name and validity period (in days).

### Types

- **`NopService`** — A no-op implementation of the NanoMDM service interface. All methods accept valid MDM request types and return zero values with no errors, useful as a stub in tests that don't require real MDM behavior.

## Usage Example

```go
// Generate a self-signed cert for testing
key, cert, err := test.SimpleSelfSignedRSAKeypair("test.example.com", 365)
if err != nil {
    t.Fatal(err)
}

// Use NopService as a stub MDM service
svc := &test.NopService{}
err = svc.Authenticate(mdmRequest, authenticateMsg)
// err == nil, no side effects
```

## Notes

- All functions live in the `test` package and are intended for use in test files only.
- `SimpleSelfSignedRSAKeypair` sets both `KeyUsageKeyEncipherment` and `KeyUsageDigitalSignature`, with `ExtKeyUsageServerAuth` and a DNS SAN matching the provided `cn`.
- `NopService` satisfies the full NanoMDM service interface, covering `Authenticate`, `TokenUpdate`, `CheckOut`, `UserAuthenticate`, `SetBootstrapToken`, `GetBootstrapToken`, `DeclarativeManagement`, `GetToken`, and `CommandAndReportResults`.
