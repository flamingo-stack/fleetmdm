Implements the Apple MDM protocol transport layer, handling HTTP communication for MDM check-in and command fetch/report operations, including optional CMS detached message signing.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Transport` | struct | Core MDM transport encapsulating HTTP client, URLs, identity, and signing config |
| `IdentityProvider` | func type | Callback that returns the device's `x509.Certificate` and `crypto.PrivateKey` |
| `Doer` | interface | Abstraction over `*http.Client` for executing HTTP requests |
| `WithClient` | option | Sets a custom HTTP client |
| `WithIdentityProvider` | option | Sets the certificate/key provider for signing |
| `WithMDMURLs` | option | Configures `serverURL` and optional `checkInURL` |
| `WithSignMessage` | option | Enables CMS detached signature header on requests |
| `SignMessage` | method | Generates a Base64-encoded PKCS7 detached signature |
| `DoCheckIn` | method | Sends a check-in request (`application/x-apple-aspen-mdm-checkin`) |
| `DoReportResultsAndFetchNext` | method | Sends a report-results-and-fetch-next request to `serverURL` |

## Usage Example

```go
transport := protocol.NewTransport(
    protocol.WithMDMURLs("https://mdm.example.com/server", "https://mdm.example.com/checkin"),
    protocol.WithIdentityProvider(func(ctx context.Context) (*x509.Certificate, crypto.PrivateKey, error) {
        return myCert, myKey, nil
    }),
    protocol.WithSignMessage(),
    protocol.WithClient(&http.Client{Timeout: 10 * time.Second}),
)

// Send a check-in message
resp, err := transport.DoCheckIn(ctx, bytes.NewReader(plistPayload))
if err != nil {
    log.Fatal(err)
}
defer resp.Body.Close()

// Report results and fetch next command
resp, err = transport.DoReportResultsAndFetchNext(ctx, bytes.NewReader(resultPayload))
```

When `WithSignMessage` is enabled, the request body is buffered, signed via PKCS7, and attached as the `Mdm-Signature` header before the request is dispatched.
