Implements a MicroMDM-compatible webhook service that forwards MDM lifecycle events (check-in, commands, token updates, etc.) to a configured HTTP endpoint.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MicroWebhook` | struct | Core service holding the webhook URL, HTTP client, and optional tally store |
| `New` | constructor | Creates a `MicroWebhook` instance with `http.DefaultClient` |
| `Authenticate` | method | Posts `mdm.Authenticate` check-in events |
| `TokenUpdate` | method | Posts `mdm.TokenUpdate` events; optionally enriches with a tally count from `TokenUpdateTallyStore` |
| `CheckOut` | method | Posts `mdm.CheckOut` events |
| `UserAuthenticate` | method | Posts `mdm.UserAuthenticate` events |
| `SetBootstrapToken` | method | Posts `mdm.SetBootstrapToken` events |
| `GetBootstrapToken` | method | Posts `mdm.GetBootstrapToken` events |
| `CommandAndReportResults` | method | Posts `mdm.Connect` acknowledge events for MDM command results |
| `DeclarativeManagement` | method | Posts `mdm.DeclarativeManagement` events |
| `GetToken` | method | Posts `mdm.GetToken` events |

Each handler builds a typed `Event` struct (with topic, timestamp, and either a `CheckinEvent` or `AcknowledgeEvent` payload) and delegates to `postWebhookEvent`.

## Usage Example

```go
import "github.com/fleetdm/fleet/v4/server/mdm/nanomdm/push/microwebhook"

// Initialize with a target webhook URL and an optional tally store.
webhook := microwebhook.New(
    "https://example.com/mdm-webhook",
    myTokenUpdateTallyStore, // pass nil to skip tally enrichment
)

// Register as an MDM checkin/command handler in your NanoMDM service.
svc := nanomdm.New(storage, nanomdm.WithCheckinAndCommandService(webhook))
```

> **Note:** `TokenUpdate` is the only handler that queries the `TokenUpdateTallyStore`; all other handlers ignore it. Pass `nil` if tally tracking is not needed.
