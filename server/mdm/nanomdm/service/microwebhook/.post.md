Handles HTTP POST delivery of webhook events by serializing an `Event` to indented JSON and sending it to a target URL.

## Key Components

- **`postWebhookEvent`** — Internal function that marshals an `Event` struct to JSON and POSTs it to the specified URL using the provided `http.Client`. Returns an error if marshaling fails, the request cannot be created/sent, or the response status is not `200 OK`.

## Usage Example

```go
client := &http.Client{Timeout: 10 * time.Second}
event := &Event{
    // populate event fields
}

err := postWebhookEvent(ctx, client, "https://example.com/webhook", event)
if err != nil {
    log.Printf("webhook delivery failed: %v", err)
}
```

## Notes

- Uses `json.MarshalIndent` for human-readable payloads (tab-indented).
- Sets `Content-Type: application/json; charset=utf-8` on the request.
- Treats any non-`200` HTTP response as an error, including `2xx` variants like `201` or `204`.
- Accepts a `context.Context` for cancellation and timeout propagation.
