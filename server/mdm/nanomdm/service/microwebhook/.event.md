Defines the core event types for the `microwebhook` package, representing MDM webhook payloads dispatched when devices acknowledge commands or perform check-ins.

## Key Components

| Type | Description |
|---|---|
| `Event` | Top-level webhook envelope containing a topic, unique event ID, timestamp, and an optional typed event payload |
| `AcknowledgeEvent` | Payload for MDM command acknowledgement events; includes device UDID, enrollment ID, command status, command UUID, URL params, and raw payload bytes |
| `CheckinEvent` | Payload for MDM check-in events (e.g., `TokenUpdate`, `Authenticate`); includes device identifiers, URL params, raw payload, and a tally counter to distinguish initial enrollment from subsequent token updates |

## Usage Example

```go
package main

import (
    "encoding/json"
    "fmt"
    microwebhook "github.com/flamingo-stack/fleetmdm/ee/mdm/maintainedapps/microwebhook"
    "time"
)

func handleWebhook(data []byte) {
    var event microwebhook.Event
    if err := json.Unmarshal(data, &event); err != nil {
        panic(err)
    }

    fmt.Printf("Topic: %s, EventID: %s, At: %s\n",
        event.Topic, event.EventID, event.CreatedAt.Format(time.RFC3339))

    if event.AcknowledgeEvent != nil {
        fmt.Printf("Command %s status: %s for device %s\n",
            event.AcknowledgeEvent.CommandUUID,
            event.AcknowledgeEvent.Status,
            event.AcknowledgeEvent.UDID,
        )
    }

    if event.CheckinEvent != nil && event.CheckinEvent.TokenUpdateTally != nil {
        fmt.Printf("TokenUpdate #%d for enrollment %s\n",
            *event.CheckinEvent.TokenUpdateTally,
            event.CheckinEvent.EnrollmentID,
        )
    }
}
```

## Notes

- `Event` uses a union-style design — only one of `AcknowledgeEvent` or `CheckinEvent` will be non-nil per event, selected by the `Topic` field.
- `TokenUpdateTally` in `CheckinEvent` allows consumers to differentiate the **initial enrollment** (`tally == 1`) from subsequent token refreshes.
- `RawPayload` is available on both event types for consumers needing access to the original MDM XML payload.
