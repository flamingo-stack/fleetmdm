A NanoMDM service middleware that intercepts and dumps raw MDM request and response payloads to a file handle for debugging and inspection purposes.

## Key Components

### `Dumper` struct
Service middleware wrapping a `CheckinAndCommandService`. Flags control which response types are dumped:
- `cmd` — command responses
- `bst` — bootstrap tokens
- `usr` — user authentication responses
- `dm` — declarative management responses

### `New(next, file)`
Constructs a `Dumper` with all dump flags enabled by default.

### Implemented MDM Handlers
Each method writes the raw request payload to the file, delegates to the next service, then conditionally writes response data:

| Method | Dumps Request | Dumps Response |
|---|---|---|
| `Authenticate` | ✅ | — |
| `TokenUpdate` | ✅ | — |
| `CheckOut` | ✅ | — |
| `UserAuthenticate` | ✅ | ✅ (if `usr`) |
| `SetBootstrapToken` | ✅ | — |
| `GetBootstrapToken` | ✅ | ✅ base64 string (if `bst`) |
| `GetToken` | ✅ | ✅ base64-encoded token data |
| `CommandAndReportResults` | ✅ | ✅ on error (if `cmd`) |
| `DeclarativeManagement` | ✅ + body | ✅ on error (if `dm`) |

## Usage Example

```go
import (
    "os"
    "github.com/flamingo-stack/fleetmdm/server/mdm/nanomdm/service/dump"
)

// Wrap an existing MDM service to dump payloads to stdout
dumper := dump.New(myCheckinService, os.Stdout)

// Or write to a log file
f, _ := os.OpenFile("mdm-dump.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
dumper := dump.New(myCheckinService, f)

// Pass dumper wherever a CheckinAndCommandService is expected
server.SetCheckinAndCommandService(dumper)
```

> **Note:** `Dumper` is intended for development/debugging. Avoid using it in production as raw MDM payloads may contain sensitive device credentials and tokens.
