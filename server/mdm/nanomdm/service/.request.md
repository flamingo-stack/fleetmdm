Provides HTTP-level adapters for dispatching MDM check-in messages and command result reports to their respective service handlers.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `HTTPStatusError` | struct | Wraps an error with an HTTP status code for transport-layer error signaling |
| `NewHTTPStatusError` | func | Constructor for `HTTPStatusError` |
| `IsNotFound` | func | Returns `true` if an error is `sql.ErrNoRows` or `os.ErrNotExist` |
| `CheckinRequest` | func | Decodes a raw MDM check-in body and dispatches to the appropriate `Checkin` service method |
| `CommandAndReportResultsRequest` | func | Decodes a raw MDM command result body and delegates to `CommandAndReportResults` service |

## Usage Example

```go
// Handling a check-in request in an HTTP handler
func (h *MDMHandler) ServeCheckin(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)

    resp, err := service.CheckinRequest(h.checkinSvc, mdmReq, body)
    if err != nil {
        var httpErr *service.HTTPStatusError
        if errors.As(err, &httpErr) {
            http.Error(w, httpErr.Error(), httpErr.Status)
            return
        }
        http.Error(w, err.Error(), http.StatusInternalServerError)
        return
    }
    w.Write(resp)
}

// Handling a command report request
resp, err := service.CommandAndReportResultsRequest(cmdSvc, mdmReq, body)
if err != nil {
    log.Printf("command report failed: %v", err)
}
```

## Notes

- `CheckinRequest` handles all Apple MDM check-in message types: `Authenticate`, `TokenUpdate`, `CheckOut`, `UserAuthenticate`, `SetBootstrapToken`, `GetBootstrapToken`, `DeclarativeManagement`, and `GetToken`.
- For `GetBootstrapToken`, a missing token returns an empty byte slice per Apple's MDM specification rather than an error.
- `HTTPStatusError` implements `Unwrap()`, making it compatible with `errors.Is` / `errors.As` unwrapping chains.
