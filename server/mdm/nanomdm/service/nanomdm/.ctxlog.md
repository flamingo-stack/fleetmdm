Provides context-based logging utilities for MDM request metadata by storing and retrieving enrollment identifiers and types within a Go context.

## Key Components

| Symbol | Description |
|---|---|
| `ctxKeyID` | Unexported struct key for storing the MDM request ID in context |
| `ctxKeyType` | Unexported struct key for storing the MDM enrollment type in context |
| `newContextWithValues` | Creates a derived context populated with the ID and enrollment type from an `mdm.Request` |
| `ctxKVs` | Extracts stored values from context and returns them as a flat key-value slice for structured logging |

## Usage Example

```go
// Attach MDM request metadata to context
enrichedCtx := newContextWithValues(ctx, mdmRequest)

// Retrieve key-value pairs for structured logging
kvs := ctxKVs(enrichedCtx)
logger.Info("processing request", kvs...)
// Output: processing request id=<device-id> type=<enroll-type>
```

## Notes

- Both context keys use empty unexported structs to avoid collisions with keys from other packages.
- `ctxKVs` performs safe type assertions and silently omits any value not present in the context, making it safe to call on any context.
- The returned slice from `ctxKVs` is variadic-compatible and intended for use with structured loggers (e.g., `log.Info(msg, kvs...)`).
