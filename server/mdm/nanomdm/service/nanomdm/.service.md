Core NanoMDM service implementation that dispatches MDM check-in messages and command lifecycle operations to the configured storage backend.

## Key Components

### `Service` struct
The central service struct holding references to storage, logger, and optional handlers:
- `store` — `storage.ServiceStore` for persistence operations
- `dm` — Declarative Management handler
- `ua` — UserAuthenticate handler
- `gt` — GetToken handler
- `ps` — ProfileService for signing/encoding configuration profiles

### Constructor & Options
- **`New(store, ...Option) *Service`** — creates a new Service instance with functional options
- **`WithLogger`**, **`WithDeclarativeManagement`**, **`WithProfileService`**, **`WithUserAuthenticate`**, **`WithGetToken`** — option setters

### Check-in Message Handlers
| Method | Description |
|---|---|
| `Authenticate` | Stores enrollment, clears command queue, disables until TokenUpdate |
| `TokenUpdate` | Stores token update for device/user channel |
| `CheckOut` | Disables the enrollment |
| `UserAuthenticate` | Delegates to configured `ua` handler |
| `SetBootstrapToken` / `GetBootstrapToken` | Bootstrap token persistence |
| `DeclarativeManagement` | Delegates to configured `dm` handler |
| `GetToken` | Delegates to configured `gt` handler |

### `CommandAndReportResults`
Stores incoming command results, then retrieves the next queued command. Handles:
- Not-found command UUIDs gracefully (migration edge case)
- Primary DB enforcement when host is not idle
- Secret expansion via `ExpandEmbeddedSecrets` and `ExpandHostSecrets`
- Special handling for `SetRecoveryLock` and `ClearPasscode` command types
- Profile signing/encoding for `CommandSubtypeProfileWithSecrets`

### `normalize`
Internal function that generates `EnrollID` structs from device/user channel identifiers, appending user channel ID after `:` for user enrollments.

## Usage Example

```go
store := myStorageBackend.New()

svc := nanomdm.New(
    store,
    nanomdm.WithLogger(myLogger),
    nanomdm.WithDeclarativeManagement(dmHandler),
    nanomdm.WithGetToken(gtHandler),
)
```
