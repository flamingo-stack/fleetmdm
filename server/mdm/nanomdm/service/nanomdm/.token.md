Implements token handling for MDM `GetToken` check-in messages, providing both a static token responder and a multiplexer for routing requests by service type.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `StaticToken` | struct | Holds a fixed token byte slice and always returns it on `GetToken` calls |
| `NewStaticToken` | func | Constructor for `StaticToken` |
| `TokenMux` | struct | Thread-safe multiplexer that routes `GetToken` requests to registered handlers by `TokenServiceType` |
| `NewTokenMux` | func | Constructor for `TokenMux` |
| `TokenMux.Handle` | method | Registers a `service.GetToken` handler for a given service type string |
| `TokenMux.GetToken` | method | Dispatches an incoming `GetToken` request to the matching registered handler |

## Usage Example

```go
// Static token – always returns the same bytes
st := nanomdm.NewStaticToken([]byte("my-static-token"))
resp, err := st.GetToken(req, getTokenMsg)

// Multiplexer – route by TokenServiceType
mux := nanomdm.NewTokenMux()
mux.Handle("com.example.service", myHandler)

resp, err := mux.GetToken(req, getTokenMsg)
// Routes to myHandler when getTokenMsg.TokenServiceType == "com.example.service"
// Returns an error if no handler is registered for the type
```

## Notes

- `TokenMux.Handle` panics on empty service type, nil handler, or duplicate registration — register all handlers at startup before serving requests.
- `TokenMux` uses `sync.RWMutex` for concurrent read safety during dispatch.
- See [Apple's `GetTokenRequest` documentation](https://developer.apple.com/documentation/devicemanagement/gettokenrequest) for valid `TokenServiceType` values.
