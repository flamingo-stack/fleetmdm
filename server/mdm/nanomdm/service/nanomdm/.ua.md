Handles Apple MDM `UserAuthenticate` check-in messages, implementing optional support for the two-step "zero-length" digest challenge protocol defined in Apple's Device Management specification.

## Key Components

- **`UAService`** — Core struct that processes `UserAuthenticate` check-in messages, with configurable behavior for accepting or rejecting user enrollment
- **`NewUAService`** — Constructor accepting a `UserAuthenticateStore` and a boolean flag to enable the empty digest challenge flow
- **`UserAuthenticate`** — Service method handling both steps of the two-message protocol; returns a 410 Gone response by default to decline user management

## Behavior

| Condition | Response |
|---|---|
| `sendEmptyDigestChallenge = false`, first message | 410 Gone (user management declined) |
| `sendEmptyDigestChallenge = true`, first message | Empty `DigestChallenge` XML plist |
| Second message (non-empty `DigestResponse`) | Empty 200 response (enrollment proceeds) |

## Usage Example

```go
// Reject all user authentication (default behavior)
uaService := nanomdm.NewUAService(store, false)

// Enable two-step zero-length digest challenge protocol
uaService := nanomdm.NewUAService(store, true)

// Register as part of a multi-service handler
multi := service.NewMultiService(enrollService, uaService)
```
