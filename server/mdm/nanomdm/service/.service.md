Core service interface definitions for the NanoMDM Apple MDM protocol implementation, declaring the contracts for check-in handling, command processing, declarative management, and profile signing.

## Key Components

| Interface | Purpose |
|---|---|
| `Checkin` | Handles Apple MDM check-in messages: `Authenticate`, `TokenUpdate`, `CheckOut`, `SetBootstrapToken`, `GetBootstrapToken` |
| `CommandAndReportResults` | Processes device command results and returns the next queued command |
| `CheckinAndCommandService` | Composite interface combining `Checkin` and `CommandAndReportResults` — the primary MDM service contract |
| `DeclarativeManagement` | Handles the Apple Declarative Management protocol (DDM) via MDM v1 |
| `UserAuthenticate` | Processes `UserAuthenticate` check-in messages for user-channel MDM |
| `GetToken` | Handles `GetToken` check-in messages per Apple's [Device Management docs](https://developer.apple.com/documentation/devicemanagement/get_token) |
| `ProfileService` | Fleet-specific interface for signing and encoding installation profiles |
