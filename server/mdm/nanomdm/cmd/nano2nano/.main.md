CLI tool that migrates MDM check-in records (Authenticate and TokenUpdate messages) from a local storage backend to a remote NanoMDM server via HTTP PUT requests.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | func | Parses flags, initializes storage, streams check-in messages from the backend, and forwards them to the migration endpoint |
| `logsFromEnrollment` | func | Builds a structured log key-value slice from an MDM enrollment, including device/user channel IDs and enrollment type |
| `httpPut` | func | Sends raw MDM check-in bytes to the migration URL using HTTP Basic Auth; returns an error on non-200 responses |
| `version` | var | Build-time version string, overridden via `-ldflags -X` |

## CLI Flags

| Flag | Description |
|------|-------------|
| `-storage` | Storage backend name |
| `-storage-dsn` | Data source name / connection string |
| `-storage-options` | Additional backend options |
| `-url` | Target NanoMDM migration endpoint URL |
| `-key` | NanoMDM API key (used as Basic Auth password) |
| `-debug` | Enable debug logging |
| `-version` | Print version and exit |

## Usage Example

```bash
# Migrate check-ins from a local file-based backend to a remote NanoMDM instance
./naномdm-migrate \
  -storage file \
  -storage-dsn /var/db/mdm \
  -url https://mdm.example.com/migrate \
  -key supersecretapikey

# Dry run: read and log check-ins without forwarding to a server
./nanomdm-migrate \
  -storage file \
  -storage-dsn /var/db/mdm \
  -debug
```

> If either `-url` or `-key` is omitted, the tool logs all check-ins locally without sending any HTTP requests, making it safe for inspection runs.
