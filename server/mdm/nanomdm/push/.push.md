Defines the core interfaces and types for sending MDM APNs (Apple Push Notification service) push notifications to enrolled devices.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Response` | struct | Holds the push notification result with an ID string and any error |
| `Pusher` | interface | High-level interface that sends APNs notifications to enrollments identified by string IDs |
| `PushProvider` | interface | Low-level interface that sends raw APNs push notifications using `mdm.Push` tokens |
| `PushProviderFactory` | interface | Factory that creates a `PushProvider` from a TLS certificate/keypair |

## Usage Example

```go
// Implement a PushProviderFactory
type MyFactory struct{}

func (f *MyFactory) NewPushProvider(cert *tls.Certificate) (push.PushProvider, error) {
    return &MyPushProvider{cert: cert}, nil
}

// Use a Pusher to notify enrolled devices by enrollment ID
func notifyDevices(ctx context.Context, pusher push.Pusher, enrollmentIDs []string) {
    results, err := pusher.Push(ctx, enrollmentIDs)
    if err != nil {
        log.Fatal(err)
    }
    for id, resp := range results {
        if resp.Err != nil {
            log.Printf("push failed for %s: %v", id, resp.Err)
        }
    }
}

// Use a PushProvider directly with raw mdm.Push tokens
func notifyRaw(ctx context.Context, provider push.PushProvider, pushes []*mdm.Push) {
    results, err := provider.Push(ctx, pushes)
    if err != nil {
        log.Fatal(err)
    }
    for token, resp := range results {
        log.Printf("token %s: id=%s, err=%v", token, resp.Id, resp.Err)
    }
}
```

> **Note:** `Pusher` operates on enrollment ID strings (higher-level), while `PushProvider` operates on raw `mdm.Push` token structs (lower-level). Use `PushProviderFactory` to instantiate providers per APNs certificate.
