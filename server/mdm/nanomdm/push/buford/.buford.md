Adapts the [buford APNs push library](https://github.com/RobotsAndPencils/buford) to the `PushProvider` and `PushProviderFactory` interfaces for sending MDM APNs push notifications.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `NewPushProviderFactory` | Constructor | Creates a `bufordFactory` with configurable options |
| `bufordFactory` | Struct | Implements `PushProviderFactory`; spawns `bufordPushProvider` instances |
| `bufordPushProvider` | Struct | Implements `PushProvider`; wraps a buford `Service` to send APNs pushes |
| `WithWorkers` | Option | Sets the number of goroutines for concurrent push delivery (default: 5) |
| `WithExpiration` | Option | Sets the APNs notification expiration duration |
| `WithNewClient` | Option | Injects a custom HTTP client constructor per provider |
| `NewClient` | Type | Callback signature for building an `*http.Client` from a TLS certificate |

## Usage Example

```go
// Create a factory with custom options
factory := buford.NewPushProviderFactory(
    buford.WithWorkers(10),
    buford.WithExpiration(24 * time.Hour),
)

// Create a push provider from a TLS certificate
cert, _ := tls.LoadX509KeyPair("cert.pem", "key.pem")
provider, err := factory.NewPushProvider(&cert)
if err != nil {
    log.Fatal(err)
}

// Send push notifications
responses, err := provider.Push(context.Background(), []*mdm.Push{
    {Token: deviceToken, PushMagic: "some-magic-value"},
})
```

## Behavior Notes

- **Single push** (`len == 1`): uses `pushSingle` directly, bypassing queue overhead.
- **Multiple pushes**: uses a buford `Queue` with up to `workers` goroutines for concurrent delivery.
- Push payload format: `{"mdm":"<PushMagic>"}` per the MDM protocol specification.
