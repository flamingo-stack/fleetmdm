Sends APNs (Apple Push Notification service) push notifications to MDM-enrolled devices, supporting both serial and concurrent delivery modes.

## Key Components

- **`Provider`** — Core struct holding the HTTP client, expiration duration, worker count, and APNs base URL
- **`Doer`** — Interface abstracting `*http.Client` for testability
- **`JSONPushError`** — Structured error type for APNs JSON error responses, including reason and timestamp
- **`Provider.Push`** — Entry point; routes to serial (single device) or concurrent (multiple devices) delivery
- **`Provider.pushSerial`** — Sends pushes sequentially; used for single-device requests
- **`Provider.pushConcurrent`** — Fan-out worker pool for parallel APNs delivery; worker count capped to push count
- **`Provider.do`** — Executes a single HTTP/2 POST to APNs, handles `GoAway` errors and non-200 responses

## APNs Endpoint Constants

| Constant | URL |
|---|---|
| `Development` | `https://api.development.push.apple.com` |
| `Development2197` | `https://api.development.push.apple.com:2197` |
| `Production` | `https://api.push.apple.com` |
| `Production2197` | `https://api.push.apple.com:2197` |

## Usage Example

```go
provider := &Provider{
    client:     &http.Client{},
    expiration: 24 * time.Hour,
    workers:    10,
    baseURL:    Production,
}

pushInfos := []*mdm.Push{
    {Token: deviceToken, PushMagic: "abc123"},
}

responses, err := provider.Push(ctx, pushInfos)
if err != nil {
    log.Fatal(err)
}

for token, resp := range responses {
    if resp.Err != nil {
        log.Printf("push failed for %s: %v", token, resp.Err)
        continue
    }
    log.Printf("push sent for %s, apns-id: %s", token, resp.Id)
}
```
