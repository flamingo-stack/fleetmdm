Apple APNs HTTP/2 push notification provider factory for MDM, implementing the `PushProvider` and `PushProviderFactory` interfaces via mTLS-authenticated HTTP/2 clients.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `NewClient` | `func` type | Callback signature for constructing an HTTP client from a TLS certificate |
| `ClientWithCert` | `func` | Configures mTLS on an HTTP client and forces HTTP/2 transport |
| `Factory` | `struct` | Instantiates `PushProvider` instances with shared configuration |
| `NewFactory` | `func` | Constructor for `Factory` with functional options |
| `WithNewClient` | `Option` | Overrides the default HTTP client constructor |
| `WithExpiration` | `Option` | Sets the APNs push notification expiration duration |
| `WithWorkers` | `Option` | Sets the number of worker goroutines (default: 5, minimum: 1) |
| `Factory.NewPushProvider` | method | Creates a `Provider` using the given TLS certificate |

## Usage Example

```go
import (
    "time"
    "github.com/flamingo-stack/fleetmdm/server/mdm/nanomdm/push/nanopush"
)

// Create a factory with custom options
factory := nanopush.NewFactory(
    nanopush.WithExpiration(24 * time.Hour),
    nanopush.WithWorkers(10),
)

// Create a provider from a TLS certificate
cert, _ := tls.LoadX509KeyPair("cert.pem", "key.pem")
provider, err := factory.NewPushProvider(&cert)
if err != nil {
    log.Fatal(err)
}

// Use a custom HTTP client (e.g. with proxy or timeout)
customFactory := nanopush.NewFactory(
    nanopush.WithNewClient(func(cert *tls.Certificate) (*http.Client, error) {
        client := &http.Client{Timeout: 10 * time.Second}
        return nanopush.ClientWithCert(client, cert)
    }),
)
```

## Notes

- `ClientWithCert` defaults to a clone of `http.DefaultClient` if `nil` is passed, and enforces TLS 1.2 minimum.
- HTTP/2 is always configured on the transport via `http2.ConfigureTransport`.
- `NewPushProvider` defaults to the APNs `Production` endpoint.
