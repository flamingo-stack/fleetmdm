HTTP middleware utilities and request helpers for MDM server HTTP handling, including authentication, version reporting, and trace-aware request logging.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ReadAllAndReplaceBody` | Function | Reads `r.Body` fully and resets it so it can be read again downstream |
| `BasicAuthMiddleware` | Middleware | Wraps a handler with HTTP Basic Auth using constant-time comparison to prevent timing attacks |
| `VersionHandler` | Handler | Returns a static JSON `{"version":"..."}` response |
| `GetTraceID` | Function | Retrieves a trace ID string from a `context.Context` |
| `TraceLoggingMiddleware` | Middleware | Injects a trace ID into the request context and logs method, path, remote addr, user agent, and `X-Forwarded-For` |

## Usage Example

```go
mux := http.NewServeMux()

// Version endpoint
mux.Handle("/version", fleethttp.VersionHandler("1.2.3"))

// Protected handler with Basic Auth
protected := fleethttp.BasicAuthMiddleware(mux, "admin", "secret", "Fleet")

// Trace ID + request logging
logger := log.NewNopLogger()
traced := fleethttp.TraceLoggingMiddleware(
    protected,
    logger,
    func(r *http.Request) string {
        return r.Header.Get("X-Request-ID")
    },
)

http.ListenAndServe(":8080", traced)

// Read and re-use request body in a handler
body, err := fleethttp.ReadAllAndReplaceBody(r)
if err != nil {
    http.Error(w, "failed to read body", http.StatusBadRequest)
    return
}
// r.Body is still readable by downstream handlers
```

## Notes

- `BasicAuthMiddleware` uses `crypto/subtle.ConstantTimeCompare` to prevent timing-based credential enumeration.
- `TraceLoggingMiddleware` gracefully falls back to the raw `RemoteAddr` if `net.SplitHostPort` fails (e.g., Unix sockets).
- The trace ID is stored under the unexported `ctxKeyTraceID{}` key; use `GetTraceID(ctx)` to retrieve it safely.
