A reverse proxy implementation for Apple MDM clients that forwards authenticated requests to a backend destination, with support for custom header injection and MDM signature forwarding.

## Key Components

| Component | Description |
|---|---|
| `HeaderFunc` | Function type that extracts a string value from a request context, used to dynamically set proxy headers |
| `Option` | Functional options pattern for configuring the proxy |
| `WithLogger` | Sets a logger for proxy error reporting |
| `WithHeaderFunc` | Registers a `HeaderFunc` to inject a custom header on forwarded requests |
| `WithForwardMDMSignature` | Enables forwarding of the `MDM-Signature` header (disabled by default due to ~2KB overhead) |
| `New` | Constructs and returns a configured `httputil.ReverseProxy` |

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/authproxy"
)

// Extract enrollment ID from context and forward it as a header
enrollmentIDFunc := func(ctx context.Context) string {
    id, _ := ctx.Value(enrollmentIDKey).(string)
    return id
}

proxy, err := authproxy.New(
    "https://backend.internal",
    authproxy.WithLogger(logger),
    authproxy.WithHeaderFunc("X-Enrollment-ID", enrollmentIDFunc),
    authproxy.WithForwardMDMSignature(), // opt-in: adds ~2KB per request
)
if err != nil {
    log.Fatal(err)
}

http.Handle("/mdm", proxy)
```

## Notes

- Authentication is **not** handled within this package — it relies on upstream middleware to validate requests and populate context values before the proxy is reached.
- The `MDM-Signature` header is stripped by default; use `WithForwardMDMSignature()` only when the backend requires it.
- Proxy errors return `502 Bad Gateway`, consistent with the standard `httputil` behavior.
