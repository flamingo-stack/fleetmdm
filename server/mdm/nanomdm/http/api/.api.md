HTTP API handlers for the NanoMDM management plane, providing push notification dispatch, MDM command enqueueing, and push certificate storage over JSON REST endpoints.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `enrolledAPIResult` | struct | Per-enrollment result carrying push/command outcomes |
| `enrolledAPIResults` | type | `map[string]*enrolledAPIResult` keyed by enrollment ID |
| `apiResult` | struct | Top-level JSON response for push and enqueue operations |
| `PushHandler` | func | HTTP handler that sends APNs push notifications to one or more enrollment IDs |
| `RawCommandEnqueueHandler` | func | HTTP handler that decodes a plist command body, enqueues it, and optionally pushes |
| `StorePushCertHandler` | func | HTTP handler that reads a PEM cert+key body and persists it to `PushCertStore` |
| `readPEMCertAndKey` | func | Internal helper that splits a combined PEM blob into separate cert and key bytes |

## Usage Example

```go
mux := http.NewServeMux()

// Strip /v1/push/ prefix so the remaining path becomes the enrollment ID(s)
mux.Handle("/v1/push/",
    http.StripPrefix("/v1/push/",
        api.PushHandler(pusher, logger),
    ),
)

// Enqueue a raw plist command; append ?nopush to skip APNs notification
mux.Handle("/v1/commands/",
    http.StripPrefix("/v1/commands/",
        api.RawCommandEnqueueHandler(store, pusher, logger),
    ),
)

// Upload push certificate: cat push.pem push.key | curl -T - .../v1/pushcert
mux.Handle("/v1/pushcert",
    api.StorePushCertHandler(certStore, logger),
)
```

Enrollment IDs are comma-separated in the URL path (e.g. `/v1/push/id1,id2`). Response codes follow HTTP 200 / 207 / 500 semantics based on full, partial, or total failure across the supplied IDs.
