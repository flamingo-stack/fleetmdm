Provides HTTP middleware chain for extracting, verifying, and associating MDM enrollment identity certificates with request contexts in the NanoMDM server.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `CertExtractPEMHeaderMiddleware` | `func` | Extracts a certificate from a URL-encoded PEM value in a named request header (e.g., Nginx `$ssl_client_escaped_cert`) |
| `CertExtractTLSMiddleware` | `func` | Extracts the first TLS peer certificate from the request's mutual-TLS handshake |
| `CertExtractMdmSignatureMiddleware` | `func` | Verifies the Apple `Mdm-Signature` header and extracts the signing certificate |
| `MdmSignatureVerifier` | `interface` | Contract for verifying an Apple `Mdm-Signature` header and returning its certificate |
| `MdmSignatureVerifierFunc` | `type` | Function adapter implementing `MdmSignatureVerifier` |
| `GetCert` | `func` | Retrieves the stored `*x509.Certificate` from a context |
| `CertVerifier` | `interface` | Contract for validating a certificate against custom logic |
| `CertVerifyMiddleware` | `func` | Runs `CertVerifier.Verify` and rejects with HTTP 400 on failure (intentionally avoids 401 to prevent MDM unenrollment) |
| `CertWithEnrollmentIDMiddleware` | `func` | Hashes the context certificate, looks it up in storage, and injects the enrollment ID into the context |
| `GetEnrollmentID` | `func` | Retrieves the enrollment ID string from a context |
| `SigLogOption` | `type` | Functional option for configuring signature-header logging behavior |

## Usage Example

```go
// Build the middleware chain for an MDM endpoint.
// 1. Extract cert from TLS, or fall back to a proxy header.
// 2. Verify the cert is enrolled.
// 3. Associate the enrollment ID for downstream handlers.

var verifier mdm.CertVerifier = myVerifierImpl{}
var store storage.CertAuthRetriever = myStore

handler := mdm.CertWithEnrollmentIDMiddleware(
    myMDMHandler,
    cryptoutil.HashCert,  // HashFn
    store,
    true, // enforce: reject requests without a valid enrollment
    logger,
)

handler = mdm.CertVerifyMiddleware(handler, verifier, logger)

// Prefer TLS mutual auth; proxy-header extraction wraps it when needed.
handler = mdm.CertExtractTLSMiddleware(handler, logger)

http.Handle("/mdm/check-in", handler)

// Inside a downstream handler, read the resolved values:
cert := mdm.GetCert(r.Context())
enrollmentID := mdm.GetEnrollmentID(r.Context())
```

> **Note:** `CertVerifyMiddleware` and `CertWithEnrollmentIDMiddleware` both respond with HTTP `400 Bad Request` (not `401`) on auth failures to avoid triggering inadvertent MDM unenrollments on Apple devices.
