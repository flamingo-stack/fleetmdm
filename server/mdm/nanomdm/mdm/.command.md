Defines core MDM command structures and decoders for parsing Apple MDM command payloads and their results from XML plist format.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CommandResults` | struct | Represents a device's response to an MDM command, including status, error chain, and raw plist bytes |
| `Command` | struct | Generic MDM command containing UUID, request type, and raw plist bytes |
| `CommandWithSubtype` | struct | Extends `Command` with a subtype and name field |
| `ErrorChain` | struct | Represents client-side errors returned during command execution |
| `CommandSubtype` | type | String enum for command subtypes (`None`, `ProfileWithSecrets`) |
| `DecodeCommandResults` | func | Unmarshals raw XML plist bytes into a `CommandResults` struct |
| `DecodeCommand` | func | Unmarshals raw XML plist bytes into a `Command` struct |
| `ErrInvalidCommandResult` | error | Returned when decoded results have an empty `Status` field |
| `ErrInvalidCommand` | error | Returned when decoded command is missing `CommandUUID` or `RequestType` |

## Usage Example

```go
// Decode an incoming command result from a device
results, err := mdm.DecodeCommandResults(rawPlistBytes)
if err != nil {
    if errors.Is(err, mdm.ErrInvalidCommandResult) {
        // handle missing status
    }
    log.Fatal(err)
}
fmt.Println(results.Status, results.CommandUUID)

// Decode an outgoing command payload
cmd, err := mdm.DecodeCommand(rawCommandBytes)
if err != nil {
    if errors.Is(err, mdm.ErrInvalidCommand) {
        // handle missing UUID or request type
    }
    log.Fatal(err)
}
fmt.Println(cmd.Command.RequestType)
```
