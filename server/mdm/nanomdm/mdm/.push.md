Defines core APNs push notification data types for MDM enrollments, including hex-encoded token handling.

## Key Components

- **`hexData`** — Byte slice type with a `String()` method that returns hex-encoded output via `hex.EncodeToString`.
- **`Push`** — Struct holding the three fields required to send an APNs push to an MDM enrollment:
  - `PushMagic` — Magic string required by the APNs MDM protocol.
  - `Token` — Device push token stored as `hexData`.
  - `Topic` — APNs topic (typically the MDM certificate's UID).
- **`SetTokenString(token string)`** — Decodes a hex-encoded token string into `Push.Token`, returning any decode error.

## Usage Example

```go
p := &mdm.Push{
    PushMagic: "com.apple.mgmt.External.abc123",
    Topic:     "com.example.mdm",
}

// Decode and store a hex-encoded device push token
err := p.SetTokenString("a1b2c3d4e5f6...")
if err != nil {
    log.Fatalf("invalid token: %v", err)
}

// Access the token as a hex string
fmt.Println(p.Token.String()) // "a1b2c3d4e5f6..."
```

## Notes

- `SetTokenString` is the preferred way to populate `Token` from external sources (e.g., database or API responses) where tokens are stored as hex strings.
- The `hexData` type ensures tokens are always serialized as hex, avoiding accidental binary output.
