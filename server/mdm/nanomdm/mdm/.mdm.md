Provides core MDM protocol types for representing Apple MDM enrollment data, enrollment identifiers, and client requests.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Enrollment` | struct | Enrollment-related data (UDID, UserID, EnrollmentID, etc.) sent with MDM requests |
| `TokenUpdateEnrollment` | struct | Extends `Enrollment` with `AwaitingConfiguration` flag for token update flows |
| `EnrollID` | struct | Derived enrollment identifiers (type, ID, parent ID) used as MDM client keys throughout the system |
| `Request` | struct | Represents an MDM client request, including certificate, context, params, and authorization |
| `Enrollment.Identifier()` | method | Returns the preferred unique device identifier (UDID if available, otherwise `EnrollmentID`) |
| `EnrollID.Validate()` | method | Validates that an `EnrollID` is non-nil, non-empty, and has a valid type |
| `Request.Clone()` | method | Returns a shallow copy of a `Request` |

## Usage Example

```go
// Build an enrollment and get its identifier
e := mdm.Enrollment{
    UDID:         "ABC123",
    EnrollmentID: "fallback-id",
}
id := e.Identifier() // returns "ABC123"

// Validate an EnrollID before use
eid := &mdm.EnrollID{
    Type: mdm.Device,
    ID:   "device-uuid-123",
}
if err := eid.Validate(); err != nil {
    log.Fatal(err)
}

// Construct and clone an MDM request
req := &mdm.Request{
    EnrollID:    eid,
    Certificate: cert,
    Context:     ctx,
    Params:      map[string]string{"key": "value"},
}
reqCopy := req.Clone()
```

## Notes

- `EnrollID` fields serve as primary keys for database storage, logging, and certificate associations — their format must remain consistent across a device's enrollment lifetime.
- `Authorization` on `Request` is only populated for User (Device) enrollment types.
