Handles Apple MDM check-in message parsing, providing structs and decoding logic for all supported MDM check-in message types (Authenticate, TokenUpdate, CheckOut, etc.).

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ErrUnrecognizedMessageType` | `error` | Sentinel error returned when an unknown `MessageType` is encountered |
| `Authenticate` | `struct` | Represents an `Authenticate` check-in request with device identity fields |
| `TokenUpdate` | `struct` | Represents a `TokenUpdate` check-in request including push and unlock token data |
| `CheckOut` | `struct` | Represents a `CheckOut` check-in request signaling device unenrollment |
| `UserAuthenticate` | `struct` | Represents a `UserAuthenticate` check-in request for user-channel MDM |
| `SetBootstrapToken` / `GetBootstrapToken` | `struct` | Represent bootstrap token exchange check-in messages |
| `DeclarativeManagement` | `struct` | Represents a `DeclarativeManagement` check-in request with endpoint and payload data |
| `GetToken` | `struct` | Represents a `GetToken` check-in request; includes `Validate()` for field checks |
| `DecodeCheckin` | `func` | Decodes a raw plist byte slice into the appropriate check-in message struct |
| `b64Data` | `type` | `[]byte` alias with a `String()` method returning base64-encoded output |

## Usage Example

```go
// Decode an incoming MDM check-in HTTP request body
func handleCheckin(body []byte) error {
    msg, err := mdm.DecodeCheckin(body)
    if err != nil {
        if errors.Is(err, mdm.ErrUnrecognizedMessageType) {
            return fmt.Errorf("unsupported message type: %w", err)
        }
        return err
    }

    switch m := msg.(type) {
    case *mdm.Authenticate:
        fmt.Printf("Device authenticating: %s (serial: %s)\n", m.DeviceName, m.SerialNumber)
    case *mdm.TokenUpdate:
        fmt.Printf("Token update from UDID: %s\n", m.UDID)
    case *mdm.CheckOut:
        fmt.Printf("Device checked out: %s\n", m.UDID)
    case *mdm.GetToken:
        if err := m.Validate(); err != nil {
            return fmt.Errorf("invalid GetToken: %w", err)
        }
    }
    return nil
}
```

## Notes

- All message structs preserve the original plist bytes in a `Raw []byte` field (tagged `plist:"-"`) for auditing or re-processing.
- Decoding is a two-pass process: first reads only `MessageType`, then decodes the full struct via `checkinUnmarshaller`.
