BER structure depth validator that walks BER-encoded TLV data without allocating output buffers, returning `ErrBERTooDeep` if nesting exceeds a configurable limit.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `MaxBERDepth` | `const` | Default maximum nesting depth (64) for BER structures |
| `ErrBERTooDeep` | `var` | Sentinel error returned when nesting exceeds `maxDepth` |
| `berFrame` | `struct` | Internal stack frame tracking open constructed-tag containers (definite or indefinite length) |
| `ValidateBERDepth` | `func` | Streams over BER TLV headers, enforcing a caller-supplied depth cap |

## Usage Example

```go
import "your/package/cryptoutil"

func parseSafely(raw []byte) error {
    // Guard against deeply nested BER before handing off to pkcs7.Parse
    if err := cryptoutil.ValidateBERDepth(raw, cryptoutil.MaxBERDepth); err != nil {
        return fmt.Errorf("rejecting payload: %w", err)
    }
    return pkcs7.Parse(raw)
}
```

## Behaviour Notes

- **Intentionally lenient on malformed input** — truncated lengths, oversized values, and invalid indefinite-length primitives all return `nil`, letting the downstream parser (e.g. `pkcs7.Parse`) surface a more precise error.
- **Zero allocation** — uses a pre-allocated slice stack; no output buffers are built.
- **Indefinite-length support** — correctly detects the two-byte end-of-contents marker (`0x00 0x00`) required by BER (but not DER).
- **Multi-byte tags** — high-tag-number form (`0x1F` low bits) is consumed and skipped without depth impact.
