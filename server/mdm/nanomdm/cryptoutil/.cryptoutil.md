Provides crypto utility helpers for Apple MDM certificate operations, including APNs topic extraction, MDM signature verification, and PEM certificate encoding/decoding.

## Key Components

| Function | Description |
|---|---|
| `TopicFromCert` | Extracts the APNs Topic (UID OID `com.apple.mgmt.*`) from an `*x509.Certificate` |
| `TopicFromPEMCert` | Convenience wrapper — decodes a PEM cert then calls `TopicFromCert` |
| `VerifyMdmSignature` | Validates an Apple MDM `Mdm-Signature` header (base64 PKCS#7) against the request body; returns the signing certificate |
| `PEMCertificate` | Encodes raw DER bytes into a PEM `CERTIFICATE` block |
| `DecodePEMCertificate` | Decodes a PEM `CERTIFICATE` block into an `*x509.Certificate` |

## Usage Example

```go
// Extract APNs topic from a PEM certificate
topic, err := cryptoutil.TopicFromPEMCert(pemBytes)
if err != nil {
    log.Fatal(err)
}
// topic == "com.apple.mgmt.External.abc123"

// Verify an inbound MDM request signature
cert, err := cryptoutil.VerifyMdmSignature(r.Header.Get("Mdm-Signature"), body)
if err != nil {
    http.Error(w, "invalid signature", http.StatusUnauthorized)
    return
}
log.Printf("signed by: %s", cert.Subject.CommonName)

// Round-trip a DER certificate through PEM
pemBlock := cryptoutil.PEMCertificate(derBytes)
decoded, err := cryptoutil.DecodePEMCertificate(pemBlock)
```

## Notes

- `VerifyMdmSignature` enforces a 10 KB cap on the decoded signature and validates BER nesting depth before parsing to guard against malformed inputs.
- The UID OID (`0.9.2342.19200300.100.1.1`) follows [RFC 4519 §2.39](https://tools.ietf.org/html/rfc4519#section-2.39); only values prefixed with `com.apple.mgmt` are accepted as valid APNs topics.
