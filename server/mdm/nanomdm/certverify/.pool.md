Provides a PEM-based X.509 certificate verifier that validates certificates against a trusted root CA pool with optional extended key usage constraints.

## Key Components

- **`PoolVerifier`** — Struct wrapping `x509.VerifyOptions` configured with a root CA pool and key usage policies.
- **`NewPoolVerifier(rootsPEM []byte, keyUsages ...x509.ExtKeyUsage)`** — Constructor that parses a PEM-encoded root CA bundle and returns a configured `PoolVerifier`. Returns an error if the PEM data is empty or unparseable.
- **`Verify(_ context.Context, cert *x509.Certificate) error`** — Validates a given certificate against the configured root pool and key usages. Returns an error if the certificate is `nil` or fails chain verification.

## Usage Example

```go
import (
    "crypto/x509"
    "context"
    "os"

    "github.com/flamingo-stack/fleetmdm/server/mdm/certverify"
)

rootPEM, err := os.ReadFile("root-ca.pem")
if err != nil {
    log.Fatal(err)
}

verifier, err := certverify.NewPoolVerifier(rootPEM, x509.ExtKeyUsageClientAuth)
if err != nil {
    log.Fatal(err)
}

// Validate an incoming MDM client certificate
if err := verifier.Verify(context.Background(), clientCert); err != nil {
    log.Printf("certificate verification failed: %v", err)
}
```

> **Note:** `keyUsages` is variadic — pass no values to skip extended key usage enforcement, or pass one or more `x509.ExtKeyUsage` constants (e.g., `ExtKeyUsageClientAuth`) to restrict accepted certificates.
