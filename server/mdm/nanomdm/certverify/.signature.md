Verifies X.509 certificate signatures against a trusted CA certificate, providing a lightweight verifier that checks only the cryptographic signature without full chain validation.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SignatureVerifier` | struct | Holds a CA certificate used to verify certificate signatures |
| `NewSignatureVerifier` | func | Constructs a `SignatureVerifier` from a PEM-encoded root CA |
| `Verify` | method | Checks that a given certificate was signed by the configured CA |

## Usage Example

```go
rootPEM, err := os.ReadFile("ca.pem")
if err != nil {
    log.Fatal(err)
}

verifier, err := certverify.NewSignatureVerifier(rootPEM)
if err != nil {
    log.Fatal(err)
}

cert, _ := cryptoutil.DecodePEMCertificate(deviceCertPEM)
if err := verifier.Verify(context.Background(), cert); err != nil {
    log.Printf("certificate signature invalid: %v", err)
}
```

## Notes

- Performs **signature-only** verification via [`x509.Certificate.CheckSignatureFrom`](https://pkg.go.dev/crypto/x509#Certificate.CheckSignatureFrom) — does not validate expiry, revocation, or the full certificate chain.
- Returns an error immediately if either the CA PEM fails to decode or the provided certificate is `nil`.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
