HTTP request and response types for the chart data endpoint within the chart bounded context.

## Key Components

| Type | Kind | Description |
|------|------|-------------|
| `GetChartDataRequest` | struct | Bound HTTP request carrying all chart query parameters |
| `GetChartDataResponse` | struct | HTTP response wrapping `api.Response` with an optional error |
| `Error()` | method | Implements the Fleet error-carrier interface on `GetChartDataResponse` |

### `GetChartDataRequest` Fields

| Field | Wire Name | Notes |
|-------|-----------|-------|
| `Metric` | `metric` (URL path) | The chart metric to retrieve |
| `Days` | `days` | Optional time window in days |
| `Resolution` | `resolution` | Optional data resolution |
| `TZOffset` | `tz_offset` | Optional timezone offset |
| `TeamID` | `fleet_id` | Pointer — `nil` means auto-scope to viewer; `0` means no-team hosts |
| `LabelIDs` | `label_ids` | Comma-separated label filter |
| `Platforms` | `platforms` | Comma-separated platform filter |
| `IncludeHostIDs` | `include_host_ids` | Comma-separated host allowlist |
| `ExcludeHostIDs` | `exclude_host_ids` | Comma-separated host denylist |

> **Note:** `TeamID` uses the wire name `fleet_id` (not `team_id`) to reflect the teams → fleets rename, while the Go field name preserves codebase consistency.

## Usage Example

```go
// Decoded automatically by the Fleet HTTP transport layer.
req := http.GetChartDataRequest{
    Metric:   "os_versions",
    Days:     30,
    TeamID:   nil, // auto-scope to the authenticated viewer
    Platforms: "darwin,windows",
}

resp := http.GetChartDataResponse{
    Response: apiResp,
}
if err := resp.Error(); err != nil {
    log.Printf("chart endpoint error: %v", err)
}
```
