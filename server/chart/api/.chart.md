Defines the core API types and interfaces for Fleet's chart/analytics subsystem, including dataset collection strategies, storage contracts, and HTTP request/response structures.

## Key Components

### Types & Interfaces

| Name | Kind | Description |
|------|------|-------------|
| `SampleStrategy` | `string` alias | Controls how bitmap samples combine within and across time buckets (`accumulate` or `snapshot`) |
| `Dataset` | Interface | Contract for a chartable metric — provides name, resolution, strategy, visualization, and a `Collect` method |
| `DatasetStore` | Interface | Narrow storage interface injected into `Dataset.Collect`; decouples dataset logic from the underlying datastore |
| `Host` | Struct | Minimal host representation used for OPA authorization checks; JSON tags are load-bearing for rego policy evaluation |
| `DataPoint` | Struct | A single `(timestamp, value)` pair in a chart series |
| `Response` | Struct | Full API response envelope including metric metadata and the `[]DataPoint` series |
| `RequestOpts` | Struct | Parsed query parameters: days, resolution, timezone offset, team/label/platform filters |
| `Filters` | Struct | Applied filter snapshot embedded in `Response` for client-side introspection |

### `SampleStrategy` Values

| Constant | Semantics |
|----------|-----------|
| `SampleStrategyAccumulate` | OR-merge across all samples in a bucket; best for "ever seen during window" metrics like uptime |
| `SampleStrategySnapshot` | Last write wins per bucket; unchanged state keeps the row open; best for point-in-time state like CVE inventory |

## Usage Example

```go
// Implement a custom Dataset
type MyDataset struct{}

func (d *MyDataset) Name() string                    { return "my_metric" }
func (d *MyDataset) DefaultResolutionHours() int     { return 4 }
func (d *MyDataset) SampleStrategy() api.SampleStrategy { return api.SampleStrategySnapshot }
func (d *MyDataset) DefaultVisualization() string    { return "line" }

func (d *MyDataset) Collect(
    ctx context.Context,
    store api.DatasetStore,
    now time.Time,
    disabledFleetIDs []uint,
) error {
    hostIDs, err := store.FindOnlineHostIDs(ctx, now, disabledFleetIDs)
    if err != nil {
        return err
    }

    bm := roaring.New()
    for _, id := range hostIDs {
        bm.Add(uint32(id))
    }

    return store.RecordBucketData(
        ctx,
        d.Name(),
        now.Truncate(time.Hour),
        time.Hour,
        d.SampleStrategy(),
        map[string]*roaring.Bitmap{"all": bm},
    )
}
```

> **Authorization note:** `Host.TeamID` and its `json:"team_id"` tag are required by the OPA rego policy. Removing or renaming the tag silently breaks team-scoped authorization without a compile-time error.
