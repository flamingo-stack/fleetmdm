Brief description of the file's purpose: Defines the public API contracts for the chart bounded context, exposing the `Service` interface and supporting types for dataset management, data collection, and cleanup operations.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Service` | Interface | Composite service interface returned by the chart module's bootstrap; covers data retrieval, dataset registration, collection, cleanup, and scrubbing |
| `CollectScopeFn` | Type | Function signature used to filter per-dataset collection by skipping datasets or restricting to specific fleet IDs |
| `ViewerProvider` | Interface | Authorization seam that resolves the authenticated viewer's team scope without importing server/fleet packages directly |

### `Service` Methods

| Method | Description |
|---|---|
| `GetChartData` | Returns time-series data for a named metric |
| `RegisterDataset` | Registers a `Dataset` for future collection runs |
| `CollectDatasets` | Runs `Collect` on all registered datasets, filtered by an optional `CollectScopeFn` |
| `CleanupData` | Deletes chart rows older than `days` days |
| `ScrubDatasetGlobal` | Idempotently removes all collected rows for a dataset (global admin disable) |
| `ScrubDatasetFleet` | Idempotently clears fleet-specific bits from dataset rows (per-fleet admin disable) |

## Usage Example

```go
// Retrieve chart data for a specific metric
resp, err := svc.GetChartData(ctx, "host_online_rate", api.RequestOpts{})
if err != nil {
    return err
}

// Register a custom dataset
svc.RegisterDataset(myDataset)

// Collect with fleet-aware scoping
err = svc.CollectDatasets(ctx, time.Now(), func(name string) (skip bool, disabledFleetIDs []uint) {
    if name == "disabled_metric" {
        return true, nil // skip entirely
    }
    return false, []uint{42, 99} // collect, but exclude fleets 42 and 99
})

// Scrub a dataset disabled globally by an admin
err = svc.ScrubDatasetGlobal(ctx, "host_vulnerability_score")

// Scrub a dataset disabled for specific fleets
err = svc.ScrubDatasetFleet(ctx, "host_vulnerability_score", []uint{1, 2, 3})
```

## Notes

- `CollectScopeFn` may be `nil`; the service treats `nil` as `(false, nil)` for every dataset — i.e., collect all datasets with no fleet restrictions.
- Both `ScrubDataset*` methods are **idempotent**; retrying on partial completion converges to the same final state.
- `ViewerProvider` is the explicit boundary that keeps the chart context free of direct `server` or `fleet` package imports, ensuring the context fails closed (returns an error) when no viewer is present rather than leaking data.
