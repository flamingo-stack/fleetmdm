Defines the built-in `api.Dataset` implementations for the Fleet chart system, providing uptime and CVE tracking datasets that collect host telemetry into time-bucketed bitmaps.

## Key Components

| Type | Description |
|------|-------------|
| `UptimeDataset` | Tracks which hosts were online per hour using an accumulate strategy; stores all active host IDs under a single `""` key as a roaring bitmap |
| `CVEDataset` | Snapshots hosts affected by tracked critical CVEs per hour; maps each CVE string to a bitmap of affected host IDs |

### Dataset Properties

| Dataset | Name | Resolution | Strategy | Visualization |
|---------|------|------------|----------|---------------|
| `UptimeDataset` | `"uptime"` | 3 hours | `Accumulate` | `"checkerboard"` |
| `CVEDataset` | `"cve"` | 3 hours | `Snapshot` | `"line"` |

## Usage Example

```go
// Register and collect uptime data
var store api.DatasetStore // injected dependency

uptime := &chart.UptimeDataset{}
if err := uptime.Collect(ctx, store, time.Now(), disabledFleetIDs); err != nil {
    log.Error(err)
}

// Register and collect CVE data
cve := &chart.CVEDataset{}
if err := cve.Collect(ctx, store, time.Now(), disabledFleetIDs); err != nil {
    log.Error(err)
}
```

## Notes

- `UptimeDataset` uses `SampleStrategyAccumulate` — buckets merge across collections within the same hour window.
- `CVEDataset` uses `SampleStrategySnapshot` — calling `RecordBucketData` with an empty bitmap closes rows for CVEs no longer tracked, preventing stale data.
- Both datasets exclude hosts belonging to `disabledFleetIDs` fleets.
- Full CVE tracking is limited to currently charted CVEs pending bitmap compression improvements.
