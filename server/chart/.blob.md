Bitmap blob utilities for the `chart` package, providing storage-form and op-form conversions for host-set bitmaps persisted in `host_scd_data.host_bitmap`.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `EncodingDense` / `EncodingRoaring` | `uint8` constants | Discriminate the on-disk `encoding_type` column value (`0` = raw bit-array, `1` = portable RoaringBitmap) |
| `Blob` | struct | Storage form: `Bytes` (serialized payload) + `Encoding` (column value). Used only at the DB I/O boundary |
| `NewBitmap` | func | Builds a `*roaring.Bitmap` from a `[]uint` host-ID list; skips IDs of `0` and those exceeding `uint32` range |
| `BitmapToBlob` | func | Serializes a bitmap to storage form (`EncodingRoaring`); nil/empty bitmaps produce `Blob{Bytes: nil}` |
| `HostIDsToBlob` | func | Convenience composition of `NewBitmap` + `BitmapToBlob` for the host-ID-list → DB path |
| `DecodeBitmap` | func | Converts storage form to op form (`*roaring.Bitmap`); dispatches on `Blob.Encoding`, walking dense blobs byte-by-byte |
| `BitmapToHostIDs` | func | Converts a `*roaring.Bitmap` back to a sorted `[]uint` for Fleet API boundaries |
| `BlobPopcount` | func | Returns bitmap cardinality; `nil` → `0` |
| `BlobAND` / `BlobOR` / `BlobANDNOT` | funcs | Set operations (intersection, union, difference) on op-form bitmaps; all handle `nil` operands safely |
| `hostIDsToDenseBlob` | func (internal) | Legacy dense encoder retained for test fixtures; not used in production writes |

## Usage Example

```go
// --- Storage write path ---
ids := []uint{1, 5, 42, 999}
blob := chart.HostIDsToBlob(ids)           // Blob{Bytes: [...], Encoding: EncodingRoaring}
// blob.Bytes and blob.Encoding go into INSERT/UPDATE

// --- Storage read path ---
rb, err := chart.DecodeBitmap(blob)         // handles both EncodingDense and EncodingRoaring
if err != nil {
    log.Fatal(err)
}

// --- Set operations (op form) ---
added   := chart.NewBitmap([]uint{10, 11})
removed := chart.NewBitmap([]uint{5})

union    := chart.BlobOR(rb, added)
filtered := chart.BlobANDNOT(union, removed)

fmt.Println(chart.BlobPopcount(filtered))   // cardinality
fmt.Println(chart.BitmapToHostIDs(filtered)) // []uint — sorted

// --- Serialize result back to storage form ---
outBlob := chart.BitmapToBlob(filtered)
```

> **Encoding boundary rule:** `DecodeBitmap` and `BitmapToBlob` are the only functions that are encoding-aware. All callers above that layer work exclusively with `*roaring.Bitmap` (op form).
