HTTP route handler for the chart service, registering API endpoints and processing chart data requests.

## Key Components

- **`GetRoutes`** — Returns a `HandlerRoutesFunc` that registers chart routes on a `mux.Router` with the provided auth middleware.
- **`attachFleetAPIRoutes`** — Registers versioned (`v1`, `2022-04`) chart API routes via an endpointer abstraction.
- **`getChartDataEndpoint`** — Handler function that extracts request parameters, applies a default 7-day window when `Days` is zero, and delegates to `svc.GetChartData`.

## Usage Example

```go
svc := chart.NewService(ds)
authMiddleware := makeAuthMiddleware(tokenStore)

routes := service.GetRoutes(svc, authMiddleware)

// Register chart routes on an existing mux.Router
routes(router, serverOptions)

// Resulting route:
// GET /api/v1/fleet/charts/{metric}
// GET /api/2022-04/fleet/charts/{metric}
```

## Request Parameters

The handler maps `GetChartDataRequest` fields to `api.RequestOpts`:

| Field | Default | Description |
|---|---|---|
| `Days` | `7` | Rolling time window |
| `Resolution` | — | Data point granularity |
| `TZOffset` | — | Timezone offset in minutes |
| `TeamID` | — | Filter by team |
| `LabelIDs` | — | Comma-separated label IDs |
| `Platforms` | — | Comma-separated platform names |
| `IncludeHostIDs` | — | Comma-separated host IDs to include |
| `ExcludeHostIDs` | — | Comma-separated host IDs to exclude |
