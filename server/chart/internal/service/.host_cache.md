Implements a TTL-based, concurrent-safe bitmap cache for host filter results, collapsing duplicate in-flight fetches via singleflight and sweeping expired entries on each write.

## Key Components

| Symbol | Description |
|---|---|
| `hostFilterCache` | Core cache struct holding TTL, a pluggable clock, singleflight group, and the entry map |
| `hostFilterCacheEntry` | Single cached value: a `*roaring.Bitmap` and its expiry timestamp |
| `hostBitmapFetcher` | Callback signature callers provide to recompute a bitmap on cache miss |
| `newHostFilterCache` | Constructor; accepts a TTL duration and wires up `time.Now` as the default clock |
| `Get` | Reads from cache on hit; on miss/expiry collapses concurrent fetches via `singleflight.Do`, then writes and sweeps expired keys |
| `hashHostFilter` | Produces a deterministic, nil-aware cache key from a `*types.HostFilter`, sorting all slice fields before encoding |
| `hostFilterCacheTTL` | Package-level constant set to 60 s, kept under the 10-minute chart collection cadence |

## Usage Example

```go
cache := newHostFilterCache(hostFilterCacheTTL)

filter := &types.HostFilter{
    TeamIDs:   []uint{1, 2},
    Platforms: []string{"darwin", "linux"},
}

bitmap, err := cache.Get(ctx, filter, func(ctx context.Context) (*roaring.Bitmap, error) {
    // Fetch fresh host IDs from the database.
    return db.QueryHostBitmap(ctx, filter)
})
if err != nil {
    return err
}

// bitmap is shared — use functional Roaring operations, not in-place mutations.
result := roaring.And(bitmap, teamMask)
```

> **Thread safety note:** The returned `*roaring.Bitmap` is shared across all callers that hit the same cache entry. Use non-mutating Roaring operations (`roaring.And`, `roaring.Or`, `roaring.AndNot`) rather than their in-place receiver variants.
