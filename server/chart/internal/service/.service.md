Service implementation for the chart bounded context, providing dataset registration, data collection, authorization-aware chart data retrieval, and data lifecycle management (cleanup and scrubbing).

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Service` | struct | Core service wiring together authorization, datastore, viewer scope, registered datasets, and a host-filter cache |
| `NewService` | func | Constructor; initializes the dataset map and host-filter cache with default TTL |
| `RegisterDataset` | func | Registers a named `api.Dataset` implementation for collection and querying |
| `CollectDatasets` | func | Iterates registered datasets, applies an optional scope function (skip/disable), and calls each dataset's `Collect`; errors are logged and non-fatal |
| `GetChartData` | func | Authorization-gated entry point: resolves viewer scope, validates request options, resolves a bitmap host filter (with caching), fetches SCD data, and returns an `api.Response` |
| `CleanupData` | func | Delegates SCD row cleanup beyond a retention window to the datastore |
| `ScrubDatasetGlobal` | func | Deletes all rows for a dataset in bounded batches |
| `ScrubDatasetFleet` | func | Resolves hosts for given fleet IDs and applies a roaring-bitmap scrub mask |
| `effectiveTeamIDs` | func | Computes SQL-time team scope from the viewer's global/team status and any explicit `team_id` filter |
| `computeBucketRange` | func | Produces `(startDate, endDate)` UTC bounds aligned to the client's timezone and bucket size |
| `formatResolution` | func | Converts a `time.Duration` bucket size to a human-readable resolution string |

## Usage Example

```go
svc := service.NewService(authz, store, viewerProvider, logger)

// Register a dataset before serving requests
svc.RegisterDataset(myDataset)

// Collect all datasets (e.g., from a scheduled job)
err := svc.CollectDatasets(ctx, time.Now(), nil)

// Serve a chart API request
teamID := uint(42)
resp, err := svc.GetChartData(ctx, "os_versions", api.RequestOpts{
    TeamID:          &teamID,
    Days:            7,
    Resolution:      24, // daily
    TZOffsetMinutes: -300,
})
```

## Authorization Model

`GetChartData` uses two distinct authz paths:

- **Explicit `team_id`** → `ActionRead` on `Host{TeamID: ...}` — policy rejects cross-team access automatically.
- **No `team_id`** → `ActionList` on `Host{}` — global users see all data; team users are scoped to their accessible teams via `effectiveTeamIDs`.

## Notes

- Host-filter results are cached (via `hostFilterCache`) to avoid redundant bitmap queries across concurrent requests.
- `scrubBatchSize` (5 000 rows) bounds per-statement lock duration during scrub operations.
- `CollectDatasets` is fail-open per dataset — one failing dataset does not block others.
