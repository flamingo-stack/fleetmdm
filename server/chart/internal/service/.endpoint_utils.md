Provides HTTP endpoint wiring utilities for the chart service, including request decoding, response encoding, and endpoint registration with versioning support.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `encodeResponse` | `func` | Encodes handler responses as indented JSON using Fleet's common encoding pattern |
| `makeDecoder` | `func` | Constructs a `kithttp.DecodeRequestFunc` with optional body size limiting via `eu.MakeDecoder` |
| `handlerFunc` | `type` | Function signature for chart service endpoint handlers returning a `platform_http.Errorer` |
| `chartEndpointer` | `struct` | Implements `eu.Endpointer[handlerFunc]` by binding `api.Service` to typed handler dispatch |
| `newChartEndpointer` | `func` | Factory that wires a `chartEndpointer` into a `eu.CommonEndpointer`, attaching auth middleware, server options, router, and version prefixes |

## Usage Example

```go
// Register chart service endpoints on a versioned router
endpointer := newChartEndpointer(
    svc,
    authMiddleware,
    kithttp.ServerOptions{},
    router,
    "v1",
)

// Attach an individual endpoint
endpointer.Handle(
    "/api/{version}/fleet/charts",
    http.MethodGet,
    listChartsRequest{},
    listChartsEndpoint,
)
```

## Notes

- `chartEndpointer` satisfies `eu.Endpointer[handlerFunc]` enforced via a compile-time blank identifier assertion.
- Error handling is delegated to Fleet's common encoder (`eu.EncodeCommonResponse`); no chart-specific error encoder is needed.
- `makeDecoder` passes `nil` for URL, query, and extra decode hooks — extend these if path or query parameter decoding is required.
