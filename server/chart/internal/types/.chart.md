Defines the core internal types and datastore interface for the chart bounded context, establishing the contract between the service layer and data persistence for SCD (Slowly Changing Dimension) host metric queries.

## Key Components

### `HostFilter`
A struct for narrowing SCD queries to specific hosts. Key semantics for `TeamIDs`:
- `nil` — no team filter (all hosts)
- `[]uint{}` — empty team scope, returns no results
- `[]uint{0}` — hosts with no team assignment (`team_id IS NULL`)
- Other values — `team_id IN (list)`, with `0` mixed in adding a `NULL` clause

### `Datastore` Interface
The internal datastore contract with the following methods:

| Method | Purpose |
|---|---|
| `FindOnlineHostIDs` | Returns IDs of currently online hosts using Fleet's standard online predicate (excludes iOS/iPadOS/Android MDM-only devices) |
| `AffectedHostIDsByCVE` | Returns host IDs grouped by CVE identifier |
| `TrackedCriticalCVEs` | Returns curated critical CVEs (CVSS ≥ 9.0) for configured software titles and OS vulnerabilities |
| `RecordBucketData` | Writes entity bitmaps for a given bucket using a specified sample strategy |
| `GetSCDData` | Returns per-bucket distinct-host counts over a date range, applying `Accumulate` or `Snapshot` aggregation |
| `GetHostIDsForFilter` | Resolves a `HostFilter` to a list of matching host IDs |
| `CleanupSCDData` | Deletes closed SCD rows older than the retention cutoff |
| `DeleteAllForDataset` | Batch-deletes all SCD rows for a dataset (used when a dataset is disabled) |
| `HostIDsInFleets` | Returns host IDs belonging to specified fleet team IDs |
| `ApplyScrubMaskToDataset` | Applies a bitmap AND-NOT mask to scrub host data from a dataset in paginated batches |

## Usage Example

```go
// Build a filter for hosts on teams 1 and 2, excluding MDM-only devices
filter := &types.HostFilter{
    TeamIDs:   []uint{1, 2},
    Platforms: []string{"darwin", "windows"},
}

hostIDs, err := ds.GetHostIDsForFilter(ctx, filter)
if err != nil {
    return err
}

mask := chart.NewBitmap(hostIDs)

points, err := ds.GetSCDData(
    ctx,
    "uptime",
    startDate, endDate,
    24*time.Hour,
    api.SampleStrategySnapshot,
    mask,
    nil, // all entities
)
```
