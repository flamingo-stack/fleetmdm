Shared test utilities for the `chart` bounded context, providing a `TestDB` helper that wraps a MySQL test database with convenience methods for seeding and inspecting `host_scd_data` rows.

## Key Components

### `TestDB`
A struct holding a `*sqlx.DB` connection and a `*slog.Logger` (discard handler) for use in tests.

### Functions

| Name | Description |
|---|---|
| `SetupTestDB` | Creates an isolated MySQL test DB with the Fleet schema. Skips the test when `MYSQL_TEST` is not set. |
| `DenseBlob` | Builds a legacy dense-encoded `chart.Blob` for seeding pre-migration fixtures. |

### `TestDB` Methods

| Method | Description |
|---|---|
| `Conns()` | Returns `DBConnections` (primary = replica = test DB) for datastore construction. |
| `TruncateTables()` | Clears all tables used by the chart bounded context between tests. |
| `InsertSCDRow()` | Inserts a minimal `host_scd_data` row with an empty bitmap blob. |
| `InsertSCDRowWithBlob()` | Inserts a row with a caller-supplied `chart.Blob`; returns the auto-assigned `id`. |
| `InsertSCDRowWithHostIDs()` | Convenience wrapper that roaring-encodes host IDs before inserting. |
| `SCDBlob()` | Fetches the raw `host_bitmap` + `encoding_type` for a given row `id`. |
| `SCDHostIDs()` | Decodes and returns the host ID slice for a given row `id`. |
| `CountSCDRows()` | Returns the total row count in `host_scd_data`. |

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    tdb := testutils.SetupTestDB(t, "my_feature")
    tdb.TruncateTables(t)

    now := time.Now().UTC()
    id := tdb.InsertSCDRowWithHostIDs(t, "my_dataset", "entity-1",
        []uint{1, 2, 3}, now, now.Add(24*time.Hour))

    ids := tdb.SCDHostIDs(t, id)
    // ids == []uint{1, 2, 3}

    assert.Equal(t, 1, tdb.CountSCDRows(t))
}
```
