Implements the Slowly Changing Dimension (SCD) data layer for the `host_scd_data` MySQL table, providing time-bucketed bitmap storage and retrieval for host tracking datasets using two strategies: accumulate (OR-merge within a bucket) and snapshot (close/reopen rows on state change).

## Key Components

### Constants & Sentinels

| Name | Type | Purpose |
|------|------|---------|
| `scdOpenSentinel` | `time.Time` | End-of-time marker (`9999-12-31`) for currently-open rows |
| `scdUpsertBatch` | `const int` | Max rows per INSERT statement (200) |
| `scdCleanupBatch` | `var int` | Max rows per DELETE in cleanup (1000, shrinkable in tests) |
| `scdScrubWriteByteBudget` | `const int` | Max CASE/WHEN UPDATE payload size (2 MB) |
| `scdScrubWriteBatchCap` | `var int` | Max rows per scrub UPDATE (1000, shrinkable in tests) |

### Methods

- **`RecordBucketData`** — Dispatcher that routes to `recordAccumulate` or `recordSnapshot` based on `api.SampleStrategy`.
- **`recordAccumulate`** — OR-merges incoming bitmaps into in-bucket rows using `INSERT ... ON DUPLICATE KEY UPDATE`. Reads from the writer to avoid stale-read merge loss.
- **`recordSnapshot`** — Reconciles open rows against incoming state: closes stale/disappeared rows, upserts changed/new rows. Uses reader for the open-row fetch (idempotent on stale read).
- **`GetSCDData`** — Walks time buckets across `[startDate, endDate]`, aggregates bitmaps per bucket, AND-applies a filter mask, and returns labeled data points (partially shown).

## Usage Example

```go
// Record accumulate-strategy data for a new 1-hour bucket
err := ds.RecordBucketData(
    ctx,
    "uptime",
    time.Now().UTC().Truncate(time.Hour),
    time.Hour,
    api.SampleStrategyAccumulate,
    map[string]*roaring.Bitmap{
        "entity-1": roaring.BitmapOf(1, 2, 3),
    },
)

// Record snapshot-strategy data (closes stale rows automatically)
err = ds.RecordBucketData(
    ctx,
    "cve_hosts",
    bucketStart,
    0, // snapshot ignores bucketSize
    api.SampleStrategySnapshot,
    entityBitmaps,
)
```
