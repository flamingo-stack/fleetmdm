MySQL datastore implementation for the chart bounded context, providing host filtering and CVE vulnerability queries against Fleet's primary/replica database connections.

## Key Components

### `Datastore`
The core struct wrapping `sqlx.DB` primary/replica connections and a structured logger. Implements `types.Datastore` at compile time.

```go
type Datastore struct {
    primary *sqlx.DB
    replica *sqlx.DB
    logger  *slog.Logger
}
```

### Constructor

- **`NewDatastore(conns, logger)`** — Initializes the datastore from a `platform_mysql.DBConnections` pair.

### Key Methods

| Method | Description |
|---|---|
| `GetHostIDsForFilter(ctx, hostFilter)` | Returns host IDs matching a `HostFilter` predicate |
| `FindOnlineHostIDs(ctx, now, disabledFleetIDs)` | Returns IDs of hosts seen within their check-in interval + 60s buffer |
| `TrackedCriticalCVEs(ctx)` | Returns deduplicated CVE IDs with CVSS ≥ 9.0 for tracked software and OS vulnerabilities |
| `AffectedHostIDsByCVE(ctx, disabledFleetIDs, cves)` | Returns host IDs grouped by CVE from both software and OS vulnerability joins |

### Internal Helpers

- **`streamCVEStrings`** — Streams single-column CVE ID results into a deduplication map.
- **`streamCVEHostPairs`** — Streams `(cve, host_id)` pairs into a `map[string][]uint`, avoiding full result-set materialization on large fleets.
- **`buildHostFilterClauses`** — Translates a `HostFilter` into SQL `WHERE` clauses (partial, truncated in source).

### Constants & Config

- **`onlineIntervalBufferSeconds = 60`** — Grace period mirroring `fleet.OnlineIntervalBuffer`, deliberately duplicated to avoid cross-bounded-context imports.
- **`trackedCVESoftwareMatchers`** — Curated list of browser, Office, Adobe, and Linux kernel software patterns used to scope critical CVE tracking.

## Usage Example

```go
conns, _ := platform_mysql.Open(cfg)
logger := slog.Default()

ds := mysql.NewDatastore(conns, logger)

// Find all online hosts, excluding disabled fleets
onlineIDs, err := ds.FindOnlineHostIDs(ctx, time.Now(), disabledFleetIDs)

// Get critical CVEs across tracked software
cves, err := ds.TrackedCriticalCVEs(ctx)

// Map CVEs to affected host IDs
affected, err := ds.AffectedHostIDsByCVE(ctx, disabledFleetIDs, cves)
```
