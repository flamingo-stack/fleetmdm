Public entry point for the `chart` bounded context, wiring together internal components (datastore, service, routes) and exposing them for use in `serve.go`.

## Key Components

| Export | Type | Description |
|---|---|---|
| `New` | Function | Constructs and returns the chart service and its HTTP route handler factory |
| `TrackedCriticalCVEs` | Function | Lightweight helper to fetch tracked CVE IDs without building the full context |

## Usage Example

```go
// In serve.go — wiring up the chart bounded context
chartSvc, chartRoutesFn := bootstrap.New(
    dbConns,
    authorizer,
    viewerProvider,
    logger,
)

// Register HTTP routes with auth middleware
handlerRoutes := chartRoutesFn(authMiddleware)

// Standalone CVE lookup for backfill tooling
cves, err := bootstrap.TrackedCriticalCVEs(ctx, db, logger)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Tracked CVEs:", cves)
```

## Notes

- `New` composes `mysql.NewDatastore` → `service.NewService` → `service.GetRoutes` internally; callers receive only the public `api.Service` interface and a route factory.
- `TrackedCriticalCVEs` accepts a raw `*sqlx.DB` and mirrors it as both primary and replica, making it suitable for CLI tools (e.g. `charts-backfill`) that do not go through the full platform connection pool setup.
- Route registration is deferred via the returned `func(authMiddleware) eu.HandlerRoutesFunc`, allowing the caller to inject auth middleware at startup time.
