Defines configuration types and interfaces for the activity bounded context's webhook integration.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `ActivitiesWebhookSettings` | struct | Holds webhook configuration — enable flag and destination URL |
| `AppConfigProvider` | interface | Abstracts access to app-level config, scoped to activity webhook needs |

### `AppConfigProvider` Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `GetActivitiesWebhookConfig` | `(ctx context.Context) (*ActivitiesWebhookSettings, error)` | Retrieves webhook settings for the activity context |

## Usage Example

```go
// Implement AppConfigProvider in your config service
type MyConfigService struct{}

func (s *MyConfigService) GetActivitiesWebhookConfig(ctx context.Context) (*activity.ActivitiesWebhookSettings, error) {
    return &activity.ActivitiesWebhookSettings{
        Enable:         true,
        DestinationURL: "https://hooks.example.com/fleet-activities",
    }, nil
}

// Consume the provider in an activity handler
func NewActivityHandler(cfg activity.AppConfigProvider) *ActivityHandler {
    return &ActivityHandler{config: cfg}
}

func (h *ActivityHandler) Dispatch(ctx context.Context) error {
    settings, err := h.config.GetActivitiesWebhookConfig(ctx)
    if err != nil {
        return err
    }
    if settings.Enable {
        // forward activity to settings.DestinationURL
    }
    return nil
}
```

## Notes

- `AppConfigProvider` is an interface so implementations can be swapped or mocked in tests without coupling to a concrete config store.
