Defines internal interfaces and types for the activity bounded context, providing contracts for the datastore layer, pagination options, and activity behavior classification.

## Key Components

### Interfaces
- **`AutomatableActivity`** — Implemented by activities triggered by automation (cron jobs, webhooks, policy automation)
- **`ActivityHosts`** — Implemented by activities associated with specific host IDs
- **`ActivityHostOnly`** — Marks an activity as host-scoped only
- **`ActivityActivator`** — Implemented by activities that should trigger the next upcoming activity in a queue
- **`Datastore`** — Primary datastore contract for persisting, querying, and cleaning up activity records

### Types
- **`ListOptions`** — Extends `api.ListOptions` with internal fields (`IncludeMetadata`, `MatchingUserIDs`) set by the service layer; implements a pagination interface with cursor and metadata support

### Constants & Variables
- **`ActivityAutomationAuthor`** — Actor name (`"Fleet"`) used when recording automated activity
- **`ActivityWebhookContextKey`** — Context key enforcing that webhook processing occurs before datastore writes

## Usage Example

```go
// Implementing the Datastore interface
type MyDatastore struct{}

func (d *MyDatastore) NewActivity(
    ctx context.Context,
    user *api.User,
    activity api.ActivityDetails,
    details []byte,
    createdAt time.Time,
) error {
    // Enforce webhook was processed before storing
    if ctx.Value(types.ActivityWebhookContextKey) == nil {
        return errors.New("webhook context key not set")
    }
    // persist activity...
    return nil
}

// Building list options with pagination metadata
opts := types.ListOptions{
    ListOptions:     api.ListOptions{Page: 0, PerPage: 25},
    IncludeMetadata: true,
    MatchingUserIDs: []uint{42, 99},
}
```

## Notes

- The `ActivityWebhookContextKey` acts as a compile-time guardrail: callers must go through the service layer (which sets the key) rather than calling the datastore directly.
- `CleanupExpiredActivities` preserves host-linked activity rows; only unlinked activities are subject to expiry.
