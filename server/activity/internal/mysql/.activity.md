MySQL datastore implementation for the activity bounded context, providing CRUD and query operations on `activity_past` and `activity_host_past` tables with OpenTelemetry tracing on every method.

## Key Components

| Symbol | Description |
|---|---|
| `Datastore` | Struct holding primary/replica `sqlx.DB` connections and a structured logger |
| `NewDatastore` | Constructor accepting `platform_mysql.DBConnections` and `*slog.Logger` |
| `ListActivities` | Paginated, filterable query over org-wide activities (excluding host-only rows) |
| `MarkActivitiesAsStreamed` | Bulk `UPDATE` to set `streamed = true` for a slice of activity IDs |
| `ListHostPastActivities` | Paginated past-activity query scoped to a single host via `activity_host_past` join |
| `CleanupExpiredActivities` | Deletes up to `maxCount` orphaned activities older than `expiryWindowDays` |
| `CleanupHostActivities` | Removes `activity_host_past` rows for a set of deleted host IDs |
| `fetchActivityDetails` | Private helper that fetches JSON details in a separate query to avoid MySQL sort-buffer pressure |

## Usage Example

```go
import (
    activitymysql "github.com/fleetdm/fleet/v4/server/activity/internal/mysql"
    "github.com/fleetdm/fleet/v4/server/activity/internal/types"
    platform_mysql "github.com/fleetdm/fleet/v4/server/platform/mysql"
    "log/slog"
)

conns := &platform_mysql.DBConnections{
    Primary: primaryDB,
    Replica: replicaDB,
}
ds := activitymysql.NewDatastore(conns, slog.Default())

activities, meta, err := ds.ListActivities(ctx, types.ListOptions{
    Page:            0,
    PerPage:         25,
    IncludeMetadata: true,
    ActivityType:    "installed_software",
    MatchQuery:      "alice",
})

// Mark selected activities as streamed
err = ds.MarkActivitiesAsStreamed(ctx, []uint{1, 2, 3})

// Periodic cleanup: remove up to 500 activities older than 30 days
err = ds.CleanupExpiredActivities(ctx, 500, 30)
```

## Notes

- **Read/write split** — mutations use `ds.primary`; reads use `ds.reader(ctx)` (replica).
- **JSON details are fetched separately** — `fetchActivityDetails` avoids MySQL sort-buffer exhaustion caused by large `details` JSON columns appearing in `ORDER BY` queries.
- **OTEL tracing** — every exported method opens a span via the package-level `tracer`; tracing is a no-op when OTEL is not configured.
