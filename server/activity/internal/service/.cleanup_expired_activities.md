Delegates cleanup of expired, host-unlinked activity records to the datastore layer, wrapping any errors with context information.

## Key Components

- **`CleanupExpiredActivities(ctx, maxCount, expiryWindowDays)`** — Service method that removes up to `maxCount` activity records older than `expiryWindowDays` days that have no associated host. Wraps datastore errors using `ctxerr.Wrap` for richer context propagation.

## Usage Example

```go
svc := service.New(store, ...)

// Remove up to 1000 activities older than 90 days with no host link
if err := svc.CleanupExpiredActivities(ctx, 1000, 90); err != nil {
    log.Errorf("failed to clean up expired activities: %v", err)
}
```

## Notes

- The actual deletion logic lives in the datastore (`s.store.CleanupExpiredActivities`); this method is a thin service-layer wrapper.
- Only activities **not linked to any host** are eligible for cleanup.
- Both `maxCount` and `expiryWindowDays` allow callers to tune the cleanup scope without code changes.
