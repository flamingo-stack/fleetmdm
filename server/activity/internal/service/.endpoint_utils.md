Provides HTTP endpoint utilities for the Activity service, including request decoding, response encoding, pagination parsing, and endpoint wiring for authenticated routes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `encodeResponse` | func | Encodes handler responses as indented JSON |
| `makeDecoder` | func | Builds a `kithttp.DecodeRequestFunc` with JSON body decoding and custom tag support |
| `parseCustomTags` | func | Resolves the `list_options` URL tag by parsing query parameters into `api.ListOptions` |
| `listOptionsFromRequest` | func | Extracts pagination, ordering, and filtering parameters from an HTTP request |
| `handlerFunc` | type | Handler signature for Activity service endpoints |
| `endpointer` | struct | Implements `eu.Endpointer[handlerFunc]`, bridging generic endpoint wiring to `api.Service` |
| `newUserAuthenticatedEndpointer` | func | Constructs a `CommonEndpointer` with auth middleware and route-template injection |
| `defaultPerPage` / `maxPerPage` | const | Pagination defaults (20 per page, 10 000 max) |

## Usage Example

```go
// Wire authenticated Activity endpoints onto a Gorilla Mux router.
ep := newUserAuthenticatedEndpointer(
    svc,           // api.Service implementation
    authMiddleware,
    serverOpts,
    router,
    "v1",
)

// Register a route using the endpointer.
ep.POST(
    "/api/{version}/fleet/activities",
    makeCreateActivityEndpoint,
    createActivityRequest{},
)
```

**Pagination query parameters** accepted by `listOptionsFromRequest`:

| Parameter | Notes |
|-----------|-------|
| `page` | Zero-based page index |
| `per_page` | 1–10 000; defaults to 20 when `page` is set |
| `order_key` | Column to sort by |
| `order_direction` | `asc` (default) or `desc` |
| `after` | Cursor-based offset |
| `activity_type`, `query`, `start_created_at`, `end_created_at` | Filtering fields |
