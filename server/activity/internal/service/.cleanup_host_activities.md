Delegates host activity cleanup to the data store layer, removing `activity_host_past` rows for specified host IDs.

## Key Components

- **`CleanupHostActivities(ctx, hostIDs []uint) error`** — Service method that wraps the store-layer cleanup call, removing past activity records for the provided host IDs and wrapping any errors with context using `ctxerr`.

## Usage Example

```go
svc := fleet.NewService(store, ...)

hostIDs := []uint{1, 2, 3}
if err := svc.CleanupHostActivities(ctx, hostIDs); err != nil {
    log.Fatalf("failed to clean up host activities: %v", err)
}
```

## Notes

- This is a thin service wrapper; the actual deletion logic lives in the store implementation (`s.store.CleanupHostActivities`).
- Errors are wrapped with [`ctxerr.Wrap`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/contexts/ctxerr) to preserve request context in error traces.
- Passing an empty `hostIDs` slice delegates to the store as-is; no-op behavior depends on the store implementation.
