Registers and handles HTTP routes for the Fleet activity API, wiring user-authenticated endpoints for listing global and host-specific past activities.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `GetRoutes` | Function | Returns a `HandlerRoutesFunc` that mounts activity routes onto a `mux.Router` |
| `attachFleetAPIRoutes` | Function | Registers `GET /activities` and `GET /hosts/{id}/activities` under user-authenticated middleware |
| `RegisterTracingTiers` | Function | Classifies both activity endpoints as `TierStandard` (≈2% trace sampling) in the tracing registry |
| `listActivitiesEndpoint` | Function | Handles `GET /api/_version_/fleet/activities` — calls `svc.ListActivities` and returns paginated results |
| `listHostPastActivitiesEndpoint` | Function | Handles `GET /api/_version_/fleet/hosts/{id}/activities` — calls `svc.ListHostPastActivities` for a specific host |
| `apiVersions` | Function | Returns the supported API version strings: `["v1", "latest"]` |

## Usage Example

```go
// Register routes on startup
routes := service.GetRoutes(activitySvc, authMiddleware)
routes(router, serverOptions)

// Register tracing tiers alongside route registration
service.RegisterTracingTiers(tracingRegistry)
```

## Route Summary

| Method | Path | Handler |
|--------|------|---------|
| `GET` | `/api/_version_/fleet/activities` | `listActivitiesEndpoint` |
| `GET` | `/api/_version_/fleet/hosts/{id}/activities` | `listHostPastActivitiesEndpoint` |

Both routes require user authentication and are sampled at the standard tracing tier. The `_version_` placeholder resolves to `v1` or `latest` at runtime.
