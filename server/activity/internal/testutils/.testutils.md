Shared test utilities for the activity bounded context, providing database setup and helper methods for inserting and managing test fixtures.

## Key Components

### Types

- **`TestDB`** — Holds a `*sqlx.DB` connection and a `*slog.Logger` for use across tests.

### Functions

| Function | Description |
|---|---|
| `SetupTestDB` | Creates an isolated MySQL test database with the Fleet schema loaded; registers cleanup on `t.Cleanup`. |
| `TestDB.Conns` | Returns `DBConnections` (primary + replica pointing to the same DB) for datastore construction. |
| `TestDB.TruncateTables` | Clears `activity_host_past`, `activity_past`, `hosts`, and `users` between test runs. |
| `TestDB.InsertUser` | Inserts a user row and returns the generated ID. |
| `TestDB.InsertActivity` | Inserts an activity with `time.Now()` as the timestamp; pass `nil` for `userID` for a system activity. |
| `TestDB.InsertActivityWithTime` | Same as `InsertActivity` but accepts an explicit `createdAt` timestamp. |
| `TestDB.InsertHost` | Inserts a host row (optionally scoped to a team) and returns its ID. |
| `TestDB.InsertHostActivity` | Links a host and an activity in the `activity_host_past` join table. |

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    tdb := testutils.SetupTestDB(t, "my_feature")
    tdb.TruncateTables(t)

    userID := tdb.InsertUser(t, "Alice", "alice@example.com")
    hostID := tdb.InsertHost(t, "mac-01", nil)
    activityID := tdb.InsertActivity(t, &userID, "installed_software", map[string]any{
        "software_name": "Fleet Agent",
    })
    tdb.InsertHostActivity(t, hostID, activityID)

    store := mypackage.NewDatastore(tdb.Conns())
    // ... assertions
}
```
