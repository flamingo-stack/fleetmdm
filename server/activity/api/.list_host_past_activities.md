Lists past activities for a specific host, providing paginated activity history retrieval through a service interface.

## Key Components

- **`ListHostPastActivitiesService`** — Interface defining the contract for retrieving historical activities associated with a host
- **`ListHostPastActivities`** — Method that accepts a host ID, pagination options, and returns a slice of `Activity` pointers along with `PaginationMetadata` and any error

## Usage Example

```go
var svc ListHostPastActivitiesService

activities, meta, err := svc.ListHostPastActivities(ctx, hostID, ListOptions{
    Page:    0,
    PerPage: 20,
})
if err != nil {
    log.Fatal(err)
}

for _, a := range activities {
    fmt.Println(a)
}

fmt.Printf("Page %d of %d\n", meta.Page, meta.TotalPages)
```

## Notes

- Part of the `api` package within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository
- Returns paginated results via `ListOptions` and `PaginationMetadata`, consistent with other list-style service interfaces in this package
- Consumers must implement or inject a concrete type satisfying `ListHostPastActivitiesService` to use this interface
