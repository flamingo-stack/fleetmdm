Defines the composite `Service` interface for the activity bounded context, aggregating all activity-related operation interfaces into a single type returned by Bootstrap.

## Key Components

| Interface | Description |
|-----------|-------------|
| `Service` | Composite interface embedding all activity sub-interfaces |
| `ListActivitiesService` | Lists activities |
| `ListHostPastActivitiesService` | Lists past activities for a specific host |
| `StreamActivitiesService` | Streams activity data |
| `NewActivityService` | Creates new activities |
| `CleanupExpiredActivitiesService` | Removes expired activities |
| `CleanupHostActivitiesService` | Removes activities for a specific host |

## Usage Example

```go
// Bootstrap returns an api.Service; consumers depend on the interface,
// not a concrete implementation.
func Bootstrap(deps Dependencies) api.Service {
    return &serviceImpl{deps: deps}
}

// Downstream caller accepts the composite interface.
func NewHandler(svc api.Service) *Handler {
    return &Handler{svc: svc}
}
```

## Notes

- This file defines only the composite interface; sub-interfaces are declared in their own files within the `api` package.
- Consumers should depend on the narrowest sub-interface they need (e.g. `ListActivitiesService`) rather than the full `Service`, following the interface segregation principle.
- The `api` package is the **public boundary** for the activity context — external packages must not import internal implementation packages directly.
