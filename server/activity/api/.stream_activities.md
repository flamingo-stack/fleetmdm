Defines the core interfaces for streaming Fleet audit activities to JSON-based logging destinations.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `JSONLogger` | Interface | Abstracts any logger capable of writing batched JSON entries to an output destination |
| `JSONLogger.Write` | Method | Accepts a context and a slice of raw JSON messages, returning any write errors |
| `StreamActivitiesService` | Interface | Defines the contract for streaming unprocessed audit activities to a logger |
| `StreamActivitiesService.StreamActivities` | Method | Streams pending (unstreamed) activities using a system-level context and a `JSONLogger` |

## Usage Example

```go
// Implement a custom JSONLogger that writes to stdout
type StdoutLogger struct{}

func (l *StdoutLogger) Write(ctx context.Context, logs []json.RawMessage) error {
    for _, entry := range logs {
        fmt.Println(string(entry))
    }
    return nil
}

// Use StreamActivitiesService to flush pending audit logs
func flushAuditLogs(svc api.StreamActivitiesService) error {
    // systemCtx must carry system-level authorization, not a user session
    systemCtx := context.Background()
    logger := &StdoutLogger{}

    return svc.StreamActivities(systemCtx, logger)
}
```

## Notes

- `StreamActivities` expects a **system-level context** (no user authorization attached) to ensure audit streaming runs with elevated, non-user-scoped permissions.
- `JSONLogger.Write` receives `[]json.RawMessage`, allowing callers to pass pre-serialized JSON blobs without additional marshalling overhead.
- Both interfaces are defined in the `api` package of [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/api/stream_activities.go).
