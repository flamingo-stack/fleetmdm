Defines HTTP request and response types for the activities bounded context, used exclusively by the activities endpoint handler.

## Key Components

| Type | Kind | Description |
|------|------|-------------|
| `ListActivitiesRequest` | struct | Request type for listing all activities; decodes `list_options` from URL parameters |
| `ListActivitiesResponse` | struct | Response type for listing all activities; includes pagination metadata and activity slice |
| `ListHostPastActivitiesRequest` | struct | Request type for listing past activities for a specific host; requires `HostID` and `list_options` from URL |
| `ListHostPastActivitiesResponse` | struct | Response type for listing host past activities; includes pagination metadata and activity slice |

Both response types implement the `platform_http.Errorer` interface via an `Error() error` method, enabling consistent error propagation through the HTTP layer.

## Usage Example

```go
// Decoding a list activities request from an HTTP handler
req := ListActivitiesRequest{}
// ListOptions populated from URL query params via `url` struct tags

// Building a list activities response
resp := ListActivitiesResponse{
    Meta: &api.PaginationMetadata{
        HasNextResults:     true,
        HasPreviousResults: false,
    },
    Activities: []*api.Activity{
        {ID: 1, Type: "user_login"},
    },
}

// Checking for errors (platform_http.Errorer interface)
if err := resp.Error(); err != nil {
    // handle error
}

// Host-scoped past activities
hostReq := ListHostPastActivitiesRequest{
    HostID: 42,
    // ListOptions from URL params
}
```
