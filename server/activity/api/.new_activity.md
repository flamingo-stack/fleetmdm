Records activity events in the Fleet MDM system, providing interfaces for creating and associating activity records with users or automated processes.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `User` | struct | Represents the actor for an activity (ID, Name, Email, Deleted) |
| `ActivityDetails` | interface | Implemented by activity detail types; requires `ActivityName() string` |
| `NewActivityService` | interface | Service contract for creating activity records and triggering webhooks |

## Usage Example

```go
// Implement ActivityDetails for a custom event
type DeviceEnrolledActivity struct {
    DeviceID string
}

func (d DeviceEnrolledActivity) ActivityName() string {
    return "device_enrolled"
}

// Record an activity for a specific user
func recordEnrollment(svc api.NewActivityService, user *api.User, deviceID string) error {
    activity := DeviceEnrolledActivity{DeviceID: deviceID}
    return svc.NewActivity(context.Background(), user, activity)
}

// Record an automation-initiated activity (no user)
func recordAutomatedTask(svc api.NewActivityService, deviceID string) error {
    activity := DeviceEnrolledActivity{DeviceID: deviceID}
    return svc.NewActivity(context.Background(), nil, activity)
}
```

## Notes

- `user` can be `nil` when the activity is triggered by automation rather than a human actor
- Implementations of `NewActivityService` are expected to fire configured webhooks alongside persisting the record
