Defines the `CleanupExpiredActivitiesService` interface for removing stale, unlinked activity records from the Fleet MDM system.

## Key Components

- **`CleanupExpiredActivitiesService`** — Interface with a single method for purging expired activity records.
- **`CleanupExpiredActivities`** — Deletes up to `maxCount` activity records older than `expiryWindowDays` days, scoped exclusively to activities **not linked to any host**. Host-associated activities are retained and handled separately during host activity processing.

## Usage Example

```go
type myService struct{}

func (s *myService) CleanupExpiredActivities(ctx context.Context, maxCount int, expiryWindowDays int) error {
    // Delete up to 1000 unlinked activities older than 90 days
    return deleteActivities(ctx, maxCount, expiryWindowDays)
}

var _ api.CleanupExpiredActivitiesService = (*myService)(nil)
```

## Notes

- Host-linked activities are **explicitly excluded** from cleanup; they follow the host activity lifecycle.
- Callers control both the batch size (`maxCount`) and retention window (`expiryWindowDays`), making the cleanup policy configurable at the call site rather than hardcoded in the interface.
