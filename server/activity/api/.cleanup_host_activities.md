Defines the `CleanupHostActivitiesService` interface for removing `activity_host_past` records when hosts are deleted from Fleet.

## Key Components

- **`CleanupHostActivitiesService`** — Interface with a single method for cleaning up host activity history.
- **`CleanupHostActivities(ctx, hostIDs)`** — Removes `activity_host_past` rows associated with the provided host IDs.

## Usage Example

```go
var svc CleanupHostActivitiesService

hostIDs := []uint{42, 99, 101}
if err := svc.CleanupHostActivities(ctx, hostIDs); err != nil {
    log.Errorf("failed to clean up host activities: %v", err)
}
```

## Notes

- Intended to be called as part of host deletion workflows to prevent orphaned activity records.
- Implementors should handle empty `hostIDs` slices gracefully (no-op).
