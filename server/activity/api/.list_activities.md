Defines the core data types and service interface for querying the Fleet audit activity log.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `ListActivitiesService` | Interface | Service contract with a single `ListActivities` method for fetching paginated activity records |
| `Activity` | Struct | Audit log entry capturing actor metadata, event type, timestamp, and arbitrary JSON details |
| `ListOptions` | Struct | Query options for pagination, sorting, filtering by type/date range, match query, and streamed status |
| `PaginationMetadata` | Struct | Cursor-aware pagination result indicating whether next/previous pages exist |
| `OrderDirection` | Type | Typed string constant (`asc` / `desc`) for sort direction |

## Usage Example

```go
// Implement the service interface
type myActivityService struct{}

func (s *myActivityService) ListActivities(
    ctx context.Context,
    opt api.ListOptions,
) ([]*api.Activity, *api.PaginationMetadata, error) {
    // query your database using opt.Page, opt.PerPage, opt.ActivityType, etc.
    activities := []*api.Activity{
        {
            UUID:          "abc-123",
            Type:          "user_login",
            FleetInitiated: false,
        },
    }
    meta := &api.PaginationMetadata{
        HasNextResults:     false,
        HasPreviousResults: false,
    }
    return activities, meta, nil
}

// Call the service with filtering and pagination
opts := api.ListOptions{
    Page:           1,
    PerPage:        25,
    OrderKey:       "created_at",
    OrderDirection: api.OrderDescending,
    ActivityType:   "user_login",
    StartCreatedAt: "2024-01-01T00:00:00Z",
}

activities, meta, err := svc.ListActivities(ctx, opts)
```

> **Note:** `ListOptions` fields are populated by the service layer from HTTP query parameters. The `Activity.Streamed` field and `PaginationMetadata.TotalResults` are intentionally excluded from JSON serialization to preserve legacy API behavior.
