Defines the `DataProviders` interface and `UpcomingActivityActivator` contract for the activity bounded context, combining external dependency interfaces into a single ACL adapter target.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `UpcomingActivityActivator` | Interface | Triggers the next queued activity for a host after a completed execution |
| `DataProviders` | Interface | Aggregate interface composing all external dependencies required by the activity package |

### `UpcomingActivityActivator`

```go
ActivateNextUpcomingActivity(ctx context.Context, hostID uint, fromCompletedExecID string) error
```

Called when an activity implements `ActivityActivator`. Advances the queue by activating the next pending activity for the given host, keyed from the just-completed execution ID.

### `DataProviders`

Composes:
- `UserProvider`
- `HostProvider`
- `AppConfigProvider`
- `UpcomingActivityActivator`

The ACL (Anti-Corruption Layer) adapter is expected to implement this single interface, keeping the activity bounded context decoupled from infrastructure concerns.

## Usage Example

```go
// ACL adapter satisfying DataProviders
type activityACL struct { /* ... */ }

func (a *activityACL) ActivateNextUpcomingActivity(
    ctx context.Context,
    hostID uint,
    fromCompletedExecID string,
) error {
    // delegate to underlying service/repository
    return a.svc.ActivateNext(ctx, hostID, fromCompletedExecID)
}

// Inject into activity service
func NewService(deps activity.DataProviders) *Service {
    return &Service{deps: deps}
}
```
