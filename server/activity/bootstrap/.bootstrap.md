Public entry point for the activity bounded context, wiring together internal components (datastore, service, and routing) for use by the application's server setup.

## Key Components

- **`New`** — Constructs the activity bounded context by instantiating the MySQL datastore and service layer, then returns the assembled `api.Service` and a route-registration function that accepts auth middleware.
- **`RegisterTracingTiers`** — Delegates to the internal service to register activity routes with the tracing registry for trace sampling classification.

## Usage Example

```go
activitySvc, activityRoutesFn := bootstrap.New(
    dbConns,
    authorizer,
    dataProviders,
    logger,
)

// Register routes with auth middleware
routesFunc := activityRoutesFn(authMiddleware)

// Register tracing tiers for sampling
bootstrap.RegisterTracingTiers(tracingRegistry)
```

## Notes

- Depends on `platform/mysql.DBConnections` for database access, `platform/authz.Authorizer` for authorization, and `activity.DataProviders` for external data dependencies.
- Internal packages (`mysql`, `service`) are not exposed directly — all wiring is encapsulated within `New`, keeping the bounded context's internals private.
- The returned route function is deferred (accepts `endpoint.Middleware`) to allow auth middleware to be applied at server startup time.
