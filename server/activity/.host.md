Defines the minimal host data model and provider interface used by the activity authorization layer.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Host` | struct | Lightweight host representation containing `ID` and `TeamID` fields; JSON tags are required by the OPA policy engine (`server/authz/policy.rego`) for team-scoped authorization checks |
| `Host.AuthzType()` | method | Returns `"host"` to satisfy the authorization object interface |
| `HostProvider` | interface | Contract for fetching minimal host data; consumed by the activity context to resolve hosts before performing authorization |
| `HostProvider.GetHostLite()` | method | Fetches the minimal `Host` struct by ID; returns a `NotFoundError` if the host does not exist |

## Usage Example

```go
// Implement HostProvider in a service layer
type myStore struct{}

func (s *myStore) GetHostLite(ctx context.Context, hostID uint) (*activity.Host, error) {
    // fetch from DB, return minimal fields only
    return &activity.Host{ID: hostID, TeamID: nil}, nil
}

// Use in an authorization check
var provider activity.HostProvider = &myStore{}

host, err := provider.GetHostLite(ctx, 42)
if err != nil {
    // handle NotFoundError or other errors
}

fmt.Println(host.AuthzType()) // "host"
fmt.Println(host.TeamID)      // nil if host is not team-scoped
```

## Notes

- `TeamID` is a pointer to `*uint` to distinguish between a global host (`nil`) and a team-assigned host (non-nil).
- The `//nolint apiparamcheck` directive suppresses API param linting because the field is internal and the JSON tag exists exclusively for the OPA policy engine, not for user-facing API responses.
