Implements a Redis-backed error store that deduplicates, persists, and exposes fleet errors via an HTTP endpoint. Errors are hashed by cause type, message, and stack trace to collapse identical occurrences into a single entry.

## Key Components

| Symbol | Description |
|---|---|
| `Handler` | Core struct managing Redis pool, TTL, and the async error channel |
| `NewHandler` | Creates and starts a `Handler`; negative TTL disables storage |
| `Handler.Store` | Non-blocking error submission; drops after a 2-second timeout |
| `Handler.Retrieve` | Scans Redis for `error:*:json` keys; optionally flushes on read |
| `Handler.ServeHTTP` | HTTP endpoint returning stored errors as JSON; accepts `?flush=true` |
| `hashError` | SHA-256 deduplication key derived from cause type, message, and stack trace |
| `maybeReplaceSocketAddr` | Normalizes IPv4/IPv6 socket addresses in request-timeout error messages |

## Usage Example

```go
// Initialize the handler with a 24-hour TTL
handler := errorstore.NewHandler(ctx, redisPool, logger, 24*time.Hour)

// Store an error (non-blocking, fires in a goroutine)
handler.Store(err)

// Expose the HTTP endpoint (e.g. on an internal mux)
mux.Handle("/debug/errors", handler)

// Retrieve errors programmatically (destructive read)
storedErrors, err := handler.Retrieve(true /* flush */)
if err != nil {
    log.Fatal(err)
}
for _, se := range storedErrors {
    fmt.Println(se)
}
```

**Deduplication:** Each unique `(cause type + message + stack trace)` combination maps to one Redis key pair — `error:{hash}:json` (serialized error) and `error:{hash}:count` (occurrence counter). For request-timeout errors, socket addresses in the message are normalized before hashing to prevent spurious duplicates.
