Provides AES-256-GCM authenticated encryption and decryption utilities for the Fleet crypto package.

## Key Components

| Function | Description |
|---|---|
| `EncryptAESGCM(plainText []byte, key string) ([]byte, error)` | Encrypts plaintext using AES-256-GCM. Returns `[nonce \|\| ciphertext]`. Key must be exactly 32 bytes. |
| `DecryptAESGCM(encrypted []byte, key string) ([]byte, error)` | Decrypts ciphertext produced by `EncryptAESGCM`. Key must match the original 32-byte encryption key. |

**Output format:** The encrypted payload prepends the randomly generated nonce to the ciphertext, so no separate nonce storage is required.

## Usage Example

```go
package main

import (
    "fmt"
    "crypto/rand"

    "github.com/flamingo-stack/fleetmdm/pkg/crypto"
)

func main() {
    // Key must be exactly 32 bytes for AES-256
    key := "12345678901234567890123456789012"

    plaintext := []byte("sensitive fleet data")

    // Encrypt
    encrypted, err := crypto.EncryptAESGCM(plaintext, key)
    if err != nil {
        panic(err)
    }

    // Decrypt
    decrypted, err := crypto.DecryptAESGCM(encrypted, key)
    if err != nil {
        panic(err)
    }

    fmt.Println(string(decrypted)) // "sensitive fleet data"
}
```

## Notes

- Key validation is strict — passing a key that is not exactly 32 bytes returns an error immediately.
- A fresh nonce is generated via `crypto/rand` on every `EncryptAESGCM` call, ensuring ciphertext uniqueness.
- GCM provides authenticated encryption; `DecryptAESGCM` will error if the ciphertext has been tampered with.
- Malformed ciphertext shorter than `nonceSize + 1` is rejected before any decryption attempt.
