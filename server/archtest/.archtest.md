Architecture test utility for validating Go package dependency constraints within the Fleet MDM project. It traverses import graphs using BFS and reports forbidden dependency chains.

## Key Components

| Export | Type | Description |
|---|---|---|
| `PackageTest` | struct | Core test harness that holds configuration for dependency checking |
| `ModuleName` | const | Root module path `github.com/fleetdm/fleet/v4` |
| `NewPackageTest` | func | Constructs a `PackageTest` for one or more package paths |
| `TestingT` | interface | Subset of `*testing.T` required by the harness |
| `packageDependency` | struct | Internal BFS node representing a single import with parent linkage for chain reporting |

### `PackageTest` Methods

| Method | Description |
|---|---|
| `OnlyInclude(regex)` | Filters traversal to packages matching a regexp (speeds up large graphs) |
| `IgnoreRecursively(pkgs...)` | Excludes packages and their entire transitive subtrees from analysis |
| `IgnoreDeps(pkgs...)` | Allows specific packages in results but still traverses their imports |
| `IgnoreXTests(pkgs...)` | Skips external (`_test`) imports for the given packages |
| `WithTests()` | Includes test imports only for the root packages under test |
| `WithTestsRecursively()` | Includes test imports across the full dependency tree |
| `ShouldNotDependOn(pkgs...)` | Registers forbidden dependency targets |
| `Check()` | Executes the BFS traversal and calls `t.Errorf` for each violation |

## Usage Example

```go
func TestNoDatabaseInAPI(t *testing.T) {
    archtest.NewPackageTest(t, "github.com/fleetdm/fleet/v4/server/service/...").
        IgnoreRecursively("github.com/fleetdm/fleet/v4/server/mock/...").
        IgnoreDeps("github.com/fleetdm/fleet/v4/server/contexts/...").
        WithTests().
        ShouldNotDependOn("github.com/fleetdm/fleet/v4/server/datastore/...").
        Check()
}
```

Violations are reported with the full import chain, tab-indented, showing exactly how the forbidden dependency is reached.
