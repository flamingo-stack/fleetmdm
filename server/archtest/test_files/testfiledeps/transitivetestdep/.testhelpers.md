Brief utility package used to test transitive dependency behavior in Go module test configurations, specifically for validating `WithTests` vs `WithTestsRecursively` scenarios.

## Key Components

- **`TransitiveTestHelper()`** — A no-op function serving as a marker/anchor that test code can import to verify transitive test dependency resolution works correctly.

## Usage Example

```go
import transitivetestdep "github.com/flamingo-stack/fleetmdm/path/to/transitivetestdep"

func TestTransitiveDependency(t *testing.T) {
    transitivetestdep.TransitiveTestHelper()
    // Confirms this package is reachable via transitive test imports
}
```

## Notes

- This package is **test-only** — it should only be imported by test files of packages that are themselves transitive dependencies.
- It contains no logic; its value is purely structural, enabling import graph validation in build/test tooling.
