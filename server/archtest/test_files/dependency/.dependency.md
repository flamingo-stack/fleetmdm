Defines a simple dependency package that exposes a constant and a method, demonstrating a transitive dependency relationship for use in architecture tests.

## Key Components

- **`Item`** (`string` constant) — Exported constant with the value `"depend on me"`, intended to be referenced by dependent packages.
- **`SomeMethod()`** — Prints the value of `transative.NowYouDependOnMe` to stdout, pulling in the `transative` package as a transitive dependency.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/server/archtest/test_files/dependency"

// Access the exported constant
fmt.Println(dependency.Item) // Output: depend on me

// Invoke the method (triggers transitive dependency on the transative package)
dependency.SomeMethod()
```

## Notes

- This package is located under `archtest/test_files/`, indicating it is a fixture used by architecture/dependency graph tests rather than production code.
- The import of `transative` makes any consumer of `dependency` indirectly dependent on `transative` — this is likely the behavior being validated by the surrounding test suite.
