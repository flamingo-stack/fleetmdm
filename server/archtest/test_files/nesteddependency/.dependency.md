Defines a package that exports a constant and a method demonstrating a nested/transitive dependency chain for use in architecture tests.

## Key Components

- **`Item`** (`string` const) — Exportable constant (`"depend on me"`) intended to be imported by packages under test.
- **`SomeMethod()`** — Prints the value of `transative.NowYouDependOnMe`, establishing a transitive dependency from any caller through this package to the `transative` package.

## Usage Example

```go
import nesteddependency "github.com/flamingo-stack/fleetmdm/server/archtest/test_files/nested_dependency"

// Access the exported constant
fmt.Println(nesteddependency.Item) // "depend on me"

// Invoke method that triggers the transitive dependency
nesteddependency.SomeMethod() // prints transative.NowYouDependOnMe
```

## Dependency Chain

```text
caller → nesteddependency → transative
```

This package is a fixture used by `archtest` to verify that dependency analysis correctly identifies indirect (transitive) relationships between packages.
