Initializes a package-level side effect by printing a value from the `nesteddependency` package during program startup.

## Key Components

- **`init()`** — Automatically executed on package import; prints `nesteddependency.Item` to stdout using `fmt.Println`.

## Usage Example

```go
// Importing the dep package triggers the init() function automatically.
import _ "github.com/flamingo-stack/fleetmdm/server/archtest/test_files/dep"

// Output on import:
// <value of nesteddependency.Item>
```

> **Note:** This file is part of the `archtest` test infrastructure. It exists to model nested dependency chains for architecture/import graph testing — not for production use.
