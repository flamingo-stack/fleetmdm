Provides a test package used to verify architecture and dependency constraints, exposing a single function that accepts a `crypto.Decrypter` and prints a value from an internal test dependency.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `What` | Function | Accepts a `crypto.Decrypter` parameter (unused) and prints `dependency.Item` to stdout |

## Usage Example

```go
package main

import (
    "crypto/rsa"
    "github.com/flamingo-stack/fleetmdm/server/archtest/test_files/testpackage"
)

func main() {
    var d *rsa.PrivateKey // implements crypto.Decrypter
    testpackage.What(d)
}
```

## Notes

- This file is part of the `archtest` test fixture infrastructure; it is **not intended for production use**.
- The `crypto.Decrypter` import is annotated with `// for test`, signalling it exists solely to exercise import graph analysis in architecture tests.
