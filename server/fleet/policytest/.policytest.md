Provides reusable test helper functions for validating `fleet.FailingPolicySet` implementations, covering both basic CRUD operations and large-scale host management scenarios.

## Key Components

| Function | Description |
|---|---|
| `RunFailingBasic` | Comprehensive test suite covering add, list, remove, and edge-case operations on policy sets and their associated hosts |
| `RunFailing1000hosts` | Stress test that validates correct behavior when adding, listing, and removing 1,000 hosts from a single policy set |

## Usage Example

```go
package mystore_test

import (
    "testing"

    "github.com/fleetdm/fleet/v4/server/service/policytest"
)

func TestMyFailingPolicySetBasic(t *testing.T) {
    store := newMyFailingPolicyStore(t) // implements fleet.FailingPolicySet
    policytest.RunFailingBasic(t, store)
}

func TestMyFailingPolicySet1000Hosts(t *testing.T) {
    store := newMyFailingPolicyStore(t)
    policytest.RunFailing1000hosts(t, store)
}
```

Both functions accept any type implementing the `fleet.FailingPolicySet` interface (`AddHost`, `ListHosts`, `RemoveHosts`, `ListSets`, `RemoveSet`), making them portable across different storage backend implementations (e.g., Redis, in-memory).
