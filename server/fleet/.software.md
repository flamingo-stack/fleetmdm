Provides core data structures, constants, and helper methods for representing software inventory items tracked across managed devices in Fleet MDM.

## Key Components

- **`Software`** — Primary struct representing an installed software item, including fields for name, version, source, bundle identifier, extension info, CPE, vulnerabilities, and platform-specific identifiers (`ApplicationID`, `UpgradeCode`)
- **`SoftwareLite`** — Lightweight struct exposing minimal software fields (`ID`, `Name`, `Version`)
- **`VulnerableSoftware`** — Struct for software entries with associated vulnerability data and host counts
- **`SoftwareVersion`** — Abstraction over the `software` table supporting software title APIs, including CVE list and host count
- **`SoftwareTitleSummary`** — Lightweight struct for processing incoming software with name and source
- **`ToUniqueStr()`** — Builds a null-separated unique string key from software fields for deduplication
- **`ComputeRawChecksum()`** — Computes an MD5 checksum (DB optimization only, not security) matching the `softwareChecksumComputedColumn` SQL expression
- **`MarshalJSON()` / `UnmarshalJSON()`** — Custom JSON serialization handling `last_opened_at` field edge cases and backwards-compatible `browser` field population
- **Length constants** — `SoftwareNameMaxLength`, `SoftwareVersionMaxLength`, etc., kept in sync with DB column definitions

## Usage Example

```go
sw := fleet.Software{
    Name:    "curl",
    Version: "7.88.1",
    Source:  "deb_packages",
    Vendor:  "Debian",
    Arch:    "x86_64",
}

// Generate unique string for deduplication
uniqueKey := sw.ToUniqueStr()

// Compute checksum for DB lookup
checksum, err := sw.ComputeRawChecksum()
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Key: %s, Checksum: %x\n", uniqueKey, checksum)
```
