Defines the `Installer` struct representing a Fleet agent installer stored in an S3 bucket.

## Key Components

### `Installer`
A struct that describes an agent installer package with the following fields:

| Field | Type | Description |
|---|---|---|
| `EnrollSecret` | `string` | Secret used to enroll the device into Fleet |
| `Kind` | `string` | Installer type/platform (e.g., `pkg`, `msi`, `deb`) |
| `Desktop` | `bool` | Whether the installer includes the Fleet Desktop component |
| `Content` | `io.ReadSeeker` | Readable and seekable stream of the installer binary from S3 |

## Usage Example

```go
import (
    "os"
    fleet "github.com/flamingo-stack/fleetmdm"
)

f, _ := os.Open("fleet-agent.pkg")

installer := fleet.Installer{
    EnrollSecret: "abc123secret",
    Kind:         "pkg",
    Desktop:      true,
    Content:      f,
}
```

## Notes

- `Content` uses `io.ReadSeeker` (rather than `io.Reader`) to support retry logic and range requests against S3 objects without re-fetching.
- The `Kind` field typically corresponds to the OS package format and drives download/execution logic downstream.
