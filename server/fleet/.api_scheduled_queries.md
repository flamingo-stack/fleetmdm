Defines HTTP request and response types for managing scheduled queries within packs in the Fleet MDM API.

## Key Components

### Request Types
- **`GetScheduledQueriesInPackRequest`** — Fetches all scheduled queries for a given pack ID, with pagination via `ListOptions`
- **`ScheduleQueryRequest`** — Creates a new scheduled query, binding a query to a pack with configurable execution options (`Interval`, `Snapshot`, `Removed`, `Platform`, `Version`, `Shard`)
- **`GetScheduledQueryRequest`** — Retrieves a single scheduled query by ID
- **`ModifyScheduledQueryRequest`** — Updates a scheduled query; embeds `ScheduledQueryPayload` for field reuse
- **`DeleteScheduledQueryRequest`** — Removes a scheduled query by ID

### Response Types
- **`ScheduledQueryResponse`** — Wraps `ScheduledQuery` for use in collection and single-item responses
- **`GetScheduledQueriesInPackResponse`** — Returns a slice of `ScheduledQueryResponse` under the `scheduled` JSON key
- **`ScheduleQueryResponse`**, **`GetScheduledQueryResponse`**, **`ModifyScheduledQueryResponse`**, **`DeleteScheduledQueryResponse`** — Standard envelope responses with an optional `Err` field; each implements the `Error() error` interface

## Usage Example

```go
// Schedule a query against a pack
req := fleet.ScheduleQueryRequest{
    PackID:   42,
    QueryID:  7,
    Interval: 3600,
    Snapshot: ptr.Bool(true),
    Platform: ptr.String("linux"),
}

// List all scheduled queries in a pack
listReq := fleet.GetScheduledQueriesInPackRequest{
    ID: 42,
    ListOptions: fleet.ListOptions{Page: 0, PerPage: 20},
}
```

## Notes

- `QueryID` carries a `renameto:"report_id"` tag, indicating it may be serialised under a different field name in certain transport layers.
- All response types satisfy a common error-carrier interface via `Error() error`, enabling uniform error handling across Fleet API handlers.
