EST CA types and service interface for interacting with an Enrollment over Secure Transport (EST) Certificate Authority, providing certificate retrieval and URL validation capabilities.

## Key Components

- **`ESTCertificate`** — Struct holding a raw certificate payload (`[]byte`) returned from the EST CA.
- **`ESTService`** — Interface defining two EST CA operations:
  - `ValidateESTURL` — Confirms the EST proxy CA's `/cacerts` endpoint is reachable (does not validate credentials).
  - `GetCertificate` — Submits a base64-encoded PKCS#10 CSR (PEM without headers/newlines) and returns a base64-encoded PKCS#7 certificate.

## Usage Example

```go
// Validate the EST server is reachable before enrolling
proxyCA := fleet.ESTProxyCA{ /* ... */ }

if err := estSvc.ValidateESTURL(ctx, proxyCA); err != nil {
    log.Fatalf("EST URL unreachable: %v", err)
}

// Submit a CSR and retrieve the signed certificate
// csr must be base64-encoded PKCS#10 (no PEM header/footer/newlines)
csr := "MIICpDCCAYwCAQAw..."

cert, err := estSvc.GetCertificate(ctx, proxyCA, csr)
if err != nil {
    log.Fatalf("failed to get certificate: %v", err)
}

// cert.Certificate contains the base64-encoded PKCS#7 response
fmt.Printf("certificate bytes: %d\n", len(cert.Certificate))
```

## Notes

- The CSR format passed to `GetCertificate` must match the template configured on the EST server; mismatches will be rejected server-side.
- `ValidateESTURL` is intended as a pre-flight check and explicitly does **not** verify credentials — use it only to confirm network reachability.
