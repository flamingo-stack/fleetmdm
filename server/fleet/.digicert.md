Defines the core types and service interface for DigiCert certificate authority integration within the Fleet package.

## Key Components

### Types

- **`DigiCertCertificate`** — Represents a retrieved DigiCert certificate, containing PFX-encoded certificate data, password, validity window (`NotValidBefore`/`NotValidAfter`), and serial number.

### Interfaces

- **`DigiCertService`** — Contract for DigiCert CA operations:
  - `VerifyProfileID` — Validates that a given `DigiCertCA` configuration has a valid, accessible profile ID.
  - `GetCertificate` — Retrieves a certificate from DigiCert using the provided CA configuration, returning a `DigiCertCertificate`.

## Usage Example

```go
// Implementing the DigiCertService interface
type myDigiCertClient struct{}

func (c *myDigiCertClient) VerifyProfileID(ctx context.Context, config fleet.DigiCertCA) error {
    // validate profile exists in DigiCert API
    return nil
}

func (c *myDigiCertClient) GetCertificate(ctx context.Context, config fleet.DigiCertCA) (*fleet.DigiCertCertificate, error) {
    return &fleet.DigiCertCertificate{
        PfxData:        []byte{...},
        Password:       "secret",
        NotValidBefore: time.Now(),
        NotValidAfter:  time.Now().Add(365 * 24 * time.Hour),
        SerialNumber:   "ABC123",
    }, nil
}
```

## Notes

- Certificate data is returned as PFX (PKCS#12) binary via `PfxData`, suitable for direct use in MDM profile provisioning.
- `DigiCertCA` (referenced but defined elsewhere) holds the CA-specific configuration passed into both service methods.
