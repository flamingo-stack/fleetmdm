Provides OpenFrame multitenancy configuration helpers for Fleet, managing tenant-scoping modes, team ID resolution, and startup validation via environment variables.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `IsOpenframeMode()` | func | Returns `true` when `FLEET_OPENFRAME_MODE=1`; gates host-assignment logic |
| `IsOpenframeMultitenancy()` | func | Master switch for shared-database multitenancy (`FLEET_OPENFRAME_MULTI_TENANCY_ENABLED`) |
| `IsOpenframeSharedMode()` | func | `true` when multitenancy is on but no process-level tenant pin is configured (one Fleet serves many tenants) |
| `OpenframeTenantUUID()` | func | Returns the stable UUID tenant pin from `FLEET_OPENFRAME_TENANT_UUID` |
| `OpenframeTeamID(ctx)` | func | Resolves the active tenant team ID in precedence order: context value → UUID-resolved pin → env fallback |
| `SetOpenframeTeamID(teamID)` | func | Atomically pins the process to a Fleet team ID at startup after UUID resolution |
| `NewOpenframeTeamContext(ctx, teamID)` | func | Injects a per-request tenant team ID into a context (used by middleware and tests) |
| `ValidateOpenframeMultitenancy()` | func | Validates multitenancy env vars at startup; rejects malformed pins |
| `openframePinnedTeamID` | `atomic.Uint64` | Process-level team pin set once at startup via `SetOpenframeTeamID` |

## Usage Example

```go
// Startup: validate config, resolve UUID → team ID, then pin the process
if err := fleet.ValidateOpenframeMultitenancy(); err != nil {
    log.Fatal(err)
}
fleet.SetOpenframeTeamID(resolvedTeamID) // called after EnsureOpenframeTeamID

// Per-request middleware (shared mode): pin team from X-Tenant-Id header
ctx = fleet.NewOpenframeTeamContext(r.Context(), tenantTeamID)

// Datastore call: resolve active tenant team
if teamID, ok := fleet.OpenframeTeamID(ctx); ok {
    // scope query to teamID
}

// Feature gate (host-assignment paths)
if fleet.IsOpenframeMode() {
    // apply hosts_include_any logic
}
```

**Environment variables:**

| Variable | Purpose |
|---|---|
| `FLEET_OPENFRAME_MODE` | Enables host-assignment feature (`1` to enable) |
| `FLEET_OPENFRAME_MULTI_TENANCY_ENABLED` | Master multitenancy switch (`true`/`1`) |
| `FLEET_OPENFRAME_TENANT_UUID` | Pins process to a single tenant by UUID |
| `FLEET_OPENFRAME_TEAM_ID` | Pins process to a Fleet team ID (integer fallback) |
