Provides common timestamp struct types used across Fleet domain entities to track creation and modification times.

## Key Components

| Type | Description |
|---|---|
| `CreateTimestamp` | Embeddable struct with a `CreatedAt` field for tracking entity creation time |
| `UpdateTimestamp` | Embeddable struct with an `UpdatedAt` field for tracking last modification time |
| `UpdateCreateTimestamps` | Composite struct embedding both `CreateTimestamp` and `UpdateTimestamp` |

All fields include `json`, `db`, and `csv` struct tags for serialization support across HTTP responses, database queries, and CSV exports.

## Usage Example

```go
// Embed UpdateCreateTimestamps into a domain entity
type Host struct {
    ID       uint   `json:"id" db:"id"`
    Hostname string `json:"hostname" db:"hostname"`
    UpdateCreateTimestamps
}

// Timestamps are populated automatically by the database layer
host := Host{
    ID:       1,
    Hostname: "my-macbook",
    UpdateCreateTimestamps: fleet.UpdateCreateTimestamps{
        CreateTimestamp: fleet.CreateTimestamp{CreatedAt: time.Now()},
        UpdateTimestamp: fleet.UpdateTimestamp{UpdatedAt: time.Now()},
    },
}

// JSON serialization includes timestamp fields automatically
// {"id":1,"hostname":"my-macbook","created_at":"...","updated_at":"..."}
```
