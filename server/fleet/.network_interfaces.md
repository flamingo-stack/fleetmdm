Defines the `NetworkInterface` struct representing a host's network interface, including addressing, traffic statistics, and metadata, as part of the Fleet domain model.

## Key Components

### `NetworkInterface`

A struct that maps to a database record capturing the full state of a network interface on a managed host.

| Field | Type | Description |
|---|---|---|
| `HostID` | `uint` | Foreign key linking the interface to its host (one-to-many) |
| `Interface` | `string` | Interface name (e.g., `eth0`, `en0`) |
| `IPAddress` | `string` | Assigned IP address (`db:"ip_address"`) |
| `Mask` | `string` | Subnet mask |
| `Broadcast` | `string` | Broadcast address |
| `PointToPoint` | `string` | Point-to-point peer address |
| `MAC` | `string` | Hardware MAC address |
| `Type` | `int` | Interface type identifier |
| `MTU` | `int` | Maximum Transmission Unit |
| `Metric` | `int` | Routing metric |
| `IPackets` / `OPackets` | `int64` | Inbound/outbound packet counts |
| `IBytes` / `OBytes` | `int64` | Inbound/outbound byte counts |
| `IErrors` / `OErrors` | `int64` | Inbound/outbound error counts |
| `LastChange` | `int64` | Timestamp of the last interface state change |

Embeds `UpdateCreateTimestamps` for automatic created/updated time tracking.

## Usage Example

```go
iface := fleet.NetworkInterface{
    HostID:    42,
    Interface: "eth0",
    IPAddress: "192.168.1.10",
    Mask:      "255.255.255.0",
    Broadcast: "192.168.1.255",
    MAC:       "00:1A:2B:3C:4D:5E",
    MTU:       1500,
    IPackets:  100000,
    OPackets:  95000,
}
```
