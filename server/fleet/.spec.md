Defines shared file-include primitives for GitOps YAML configurations, providing `path`/`paths` field support across Fleet spec types.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `BaseItem` | `struct` | Embeddable struct exposing `path` and `paths` JSON fields for referencing external files |
| `SupportsFileInclude` | `interface` | Contract for types that support external file references via `path`/`paths` |
| `GetBaseItem()` | method | Returns the current `BaseItem`; promoted to embedding types automatically |
| `SetBaseItem()` | method | Sets the `BaseItem` value; promoted to embedding types automatically |

## Usage Example

```go
// Embed BaseItem to satisfy SupportsFileInclude automatically
type PolicySpec struct {
    BaseItem
    Name string `json:"name"`
}

// Both methods are available via promotion
var p PolicySpec
p.SetBaseItem(fleet.BaseItem{
    Path: fleet.StringPtr("/policies/no-bitlocker.yml"),
})

item := p.GetBaseItem()
fmt.Println(*item.Path) // /policies/no-bitlocker.yml

// Use the interface for generic GitOps processing
func applyFileRef(s fleet.SupportsFileInclude, path string) {
    s.SetBaseItem(fleet.BaseItem{Path: &path})
}
```

## Notes

- Embed `BaseItem` directly into any spec struct to satisfy `SupportsFileInclude` with zero boilerplate — Go method promotion handles both interface methods automatically.
- `Path` and `Paths` are pointers to distinguish between an unset field and an empty string during GitOps YAML parsing.
