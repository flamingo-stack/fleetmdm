Defines Fleet user role specification types used for managing role-based access control (RBAC) assignments across global and team-level scopes.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `UserRolesKind` | `const` | Resource kind identifier (`"user_roles"`) for role spec documents |
| `UsersRoleSpec` | `struct` | Top-level container mapping usernames to their individual role specs |
| `UserRoleSpec` | `struct` | Defines a single user's global role and team-level role assignments |
| `TeamRoleSpec` | `struct` | Represents a role assignment within a specific named team |

## Usage Example

```go
spec := fleet.UsersRoleSpec{
    Roles: map[string]*fleet.UserRoleSpec{
        "alice@example.com": {
            GlobalRole: ptr("admin"),
            Teams:      []fleet.TeamRoleSpec{},
        },
        "bob@example.com": {
            GlobalRole: nil,
            Teams: []fleet.TeamRoleSpec{
                {Name: "engineering", Role: "maintainer"},
                {Name: "security",    Role: "observer"},
            },
        },
    },
}
```

## Notes

- `GlobalRole` is a pointer to `string`, allowing `nil` to represent no global role assignment.
- The `renameto` struct tags on `Teams` → `"fleets"` and `TeamRoleSpec.Name` → `"fleet"` indicate a renaming convention used during serialization or migration between Fleet and an earlier "fleet" naming scheme.
