Defines the `APIEndpoint` type used to represent and manage API endpoints with attached authorization permissions in the Fleet MDM system.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `APIEndpoint` | struct | Represents an API endpoint with method, path, display name, and deprecation status |
| `AuthzType()` | method | Implements `authz.AuthzTyper`; returns `"api_endpoint"` |
| `NewAPIEndpointFromTpl()` | func | Constructs an `APIEndpoint` from a mux route template or `/_version_/` placeholder path |
| `normalize()` | method | Uppercases the method and replaces dynamic path segments with numbered placeholders |
| `Fingerprint()` | method | Returns a unique string identifier in the form `\|METHOD\|normalized-path\|` |
| `validate()` | method | Validates that `DisplayName`, `Method`, and `Path` are non-empty and that the method is a recognized HTTP verb |
| `UnmarshalJSON()` | method | Custom JSON unmarshaler that normalizes and validates the endpoint after deserialization |

## Usage Example

```go
// Create an endpoint from a gorilla/mux route template
ep := fleet.NewAPIEndpointFromTpl("GET", "/api/_version_/fleet/hosts/{id}")
fmt.Println(ep.Path)           // /api/v1/fleet/hosts/{id}
fmt.Println(ep.NormalizedPath) // /api/v1/fleet/hosts/:placeholder_1
fmt.Println(ep.Fingerprint())  // |GET|/api/v1/fleet/hosts/:placeholder_1|

// Deserialize from JSON (normalizes and validates automatically)
data := []byte(`{
  "method": "post",
  "path": "/api/v1/fleet/labels",
  "display_name": "Create Label"
}`)
var endpoint fleet.APIEndpoint
if err := json.Unmarshal(data, &endpoint); err != nil {
    log.Fatal(err)
}
fmt.Println(endpoint.Method) // POST (uppercased by normalize)
```

## Notes

- Dynamic path segments in both `:param` (Echo/chi) and `{param}` (gorilla/mux) styles are normalized to numbered placeholders (`:placeholder_1`, `:placeholder_2`, …) for consistent fingerprinting.
- The gorilla/mux version segment pattern (e.g. `/{fleetversion:(?:v1|2022-04|latest)}/`) is collapsed to `/v1/` during construction.
- Valid HTTP methods are limited to `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`.
