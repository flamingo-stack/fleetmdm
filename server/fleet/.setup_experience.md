Defines types and logic for tracking the macOS (and cross-platform) Setup Experience workflow, representing the status of software installs, VPP app installs, and script executions during device enrollment.

## Key Components

### Status Type
- **`SetupExperienceStatusResultStatus`** — String enum (`pending`, `running`, `success`, `failure`, `cancelled`) with `IsValid()` and `IsTerminalStatus()` helpers.

### Core Struct
- **`SetupExperienceStatusResult`** — Represents a single setup step (software installer, VPP app, or script) for a host. Includes:
  - `IsValid() error` — Validates that exactly one underlying step type is set and policy-gating constraints are respected.
  - `VPPAppID()` — Returns the VPP app identifier or an error if not a VPP row.
  - `IsForScript()`, `IsForSoftware()`, `IsForSoftwarePackage()`, `IsForVPPApp()` — Step type predicates.
  - `ForMyDevicePage(token)` — Rewrites the icon URL to use a device-token-based endpoint.

### Result Converters
- **`SetupExperienceVPPInstallResult`** — Maps MDM command status → `SetupExperienceStatusResultStatus`.
- **`SetupExperienceSoftwareInstallResult`** — Maps `SoftwareInstallerStatus` → setup experience status.
- **`SetupExperienceScriptResult`** — Maps script exit code → setup experience status.

### Payloads
- **`SetupExperienceStatusPayload`** — Sent to Orbit; contains script, software, bootstrap package, profiles, account config, and org branding.
- **`DeviceSetupExperienceStatusPayload`** — Device-facing payload with software and script results.

### Utilities
- **`IsSetupExperienceSupported(platform)`** — Returns `true` for `darwin`, `ios`, `ipados`, `windows`, `android`, and Linux.
- **`HostUUIDForSetupExperience(host)`** — Returns the canonical host identifier for setup experience records; uses `OsqueryHostID` on Windows/Linux to avoid hardware UUID collisions.
- **`SetupExperienceCount`** — Aggregate counts of installers, scripts, and VPP apps.

## Usage Example

```go
result := &SetupExperienceStatusResult{
    ID:                  1,
    HostUUID:            "abc-123",
    Name:                "Install Slack",
    Status:              SetupExperienceStatusPending,
    SoftwareInstallerID: uintPtr(42),
}

if err := result.IsValid(); err != nil {
    log.Fatalf("invalid result: %v", err)
}

if result.IsForSoftwarePackage() {
    log.Println("Step type: software installer")
}

if result.Status.IsTerminalStatus() {
    log.Println("Step has completed")
}

hostID, err := HostUUIDForSetupExperience(host)
if err != nil {
    log.Fatalf("cannot determine host ID: %v", err)
}
```
