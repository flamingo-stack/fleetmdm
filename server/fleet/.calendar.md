Defines core calendar integration types, interfaces, and webhook functionality for Fleet's automated device compliance scheduling system.

## Key Components

### Constants
- `CalendarBodyStaticHeader` — Static header text used in calendar event bodies
- `CalendarEventConflictText` — Text appended when a scheduling conflict occurs
- `CalendarDefaultDescription` / `CalendarDefaultResolution` — Default event body content with HTML-formatted remediation steps

### Types & Interfaces

| Name | Description |
|---|---|
| `DayEndedError` | Sentinel error returned when no time slots remain on a given day |
| `CalendarGenBodyFn` | Callback signature for generating event body content dynamically |
| `UserCalendar` | Interface for interacting with a user's calendar (create, update, delete events) |
| `Lock` | Interface for distributed locking (set, release, get, set operations) |
| `CalendarCreateEventOpts` | Options passed when creating a calendar event (UUID, channel, resource IDs) |
| `CalendarGetAndUpdateEventOpts` | Options for retrieving/updating events (e.g., timezone updates) |
| `CalendarWebhookPayload` | JSON payload structure for calendar webhook notifications |

### Functions

- **`FireCalendarWebhook`** — POSTs a `CalendarWebhookPayload` to a configured webhook URL, including host details and failing policy data. Masks secret URL params in errors.

## Usage Example

```go
err := fleet.FireCalendarWebhook(
    "https://example.com/webhook",
    hostID,
    "ABC123XYZ",
    "Alice's MacBook",
    failingPolicies,
    "",
    logger,
)
if err != nil {
    log.Printf("webhook failed: %v", err)
}
```
