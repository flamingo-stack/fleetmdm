Defines core email-related types, interfaces, and utilities for Fleet's email system, including mail sending abstractions and password reset request handling.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `ErrPasswordResetNotConfigured` | `error` | Sentinel error returned when SMTP/SES is not configured for password resets |
| `Mailer` | `interface` | Implemented by email campaign types that can serialize themselves to an email body via `Message() ([]byte, error)` |
| `Email` | `struct` | Represents an outbound email with subject, recipients, server URL, SMTP settings, and a `Mailer` payload |
| `MailService` | `interface` | Abstracts the email sending backend; requires `SendEmail` and `CanSendEmail` implementations |
| `PasswordResetRequest` | `struct` | Maps to the password reset requests database table, holding user ID, expiry time, and token |
| `IsLooseEmail` | `func` | Validates that a string loosely resembles an email address using a permissive regex |

## Usage Example

```go
// Check if a string is a valid-looking email before processing
email := "user@example.com"
if !fleet.IsLooseEmail(email) {
    return errors.New("invalid email address")
}

// Implement Mailer to create a custom email campaign
type WelcomeMailer struct {
    UserName string
}

func (w WelcomeMailer) Message() ([]byte, error) {
    return []byte("Welcome, " + w.UserName + "!"), nil
}

// Build and send an email via a MailService implementation
msg := fleet.Email{
    Subject:      "Welcome to Fleet",
    To:           []string{email},
    ServerURL:    "https://fleet.example.com",
    SMTPSettings: smtpSettings,
    Mailer:       WelcomeMailer{UserName: "Alice"},
}

if err := mailSvc.SendEmail(ctx, msg); err != nil {
    // handle ErrPasswordResetNotConfigured or transport errors
}
```

## Notes

- `IsLooseEmail` uses a permissive regex (`^[^\s@]+@[^\s@\.]+\..+$`) — it intentionally rejects spaces and requires a dot in the domain, but does not enforce RFC 5321 fully.
- Prefer checking `CanSendEmail` before calling `SendEmail` to avoid the `ErrPasswordResetNotConfigured` sentinel at runtime.
