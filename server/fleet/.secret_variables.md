Defines the `SecretVariable` domain model and validation logic for named secret variables used in Fleet configuration.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SecretVariable` | struct | Core model holding a secret's name, value, and last-updated timestamp |
| `SecretVariableIdentifier` | struct | Lightweight read-only view of a secret (ID + name + timestamp, no value) |
| `AuthzType()` | method | Returns `"secret_variable"` for authorization policy enforcement |
| `ValidateSecretVariableName()` | func | Validates a secret name against length and format constraints |
| `secretVariableFormat` | `*regexp.Regexp` | Compiled regex restricting names to `[A-Z0-9_]+` |

## Validation Rules

`ValidateSecretVariableName` enforces three constraints:

- **Non-empty** — name must not be blank
- **Max length** — must not exceed 255 characters
- **Format** — must match `^[A-Z0-9_]+$` (uppercase letters, digits, and underscores only)

Violations return a typed `InvalidArgumentError`.

## Usage Example

```go
// Validate before storing
name := "DATABASE_PASSWORD"
if err := fleet.ValidateSecretVariableName(name); err != nil {
    log.Fatalf("invalid secret variable name: %v", err)
}

secret := fleet.SecretVariable{
    Name:  name,
    Value: "s3cr3t!",
}

// Authorization type used by policy engine
fmt.Println(secret.AuthzType()) // "secret_variable"

// Use SecretVariableIdentifier when listing secrets without exposing values
var identifiers []fleet.SecretVariableIdentifier
// identifiers contain ID, Name, UpdatedAt — but not Value
```
