Defines session and SSO-related types and utilities for Fleet's authentication layer, including SAML attribute parsing and JIT (Just-In-Time) role provisioning from SSO responses.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Auth` | Interface | Extracts user identity and attributes from a validated SAML response |
| `SAMLAttribute` / `SAMLAttributeValue` | Structs | Hold custom SAML assertion attribute names and typed values |
| `Session` | Struct | Represents an active user session with access tracking and API-only flag |
| `SessionSSOSettings` | Struct | Exposes SSO configuration (IDP name, image URL, enabled flag) to pre-auth clients |
| `SSOSession` | Struct | Transient token and redirect URL produced during SSO handshake |
| `SSORolesInfo` | Struct | Parsed global and team roles extracted from SAML attributes |
| `TeamRole` | Struct | Maps a Fleet team ID to a user role string |
| `RolesFromSSOAttributes` | Function | Parses `FLEET_JIT_USER_ROLE_*` SAML attributes into `SSORolesInfo`, returns coerced attribute names and any error |
| `parseRole` | Function (internal) | Validates a single role value from a SAML attribute value list; coerces empty/whitespace to `null` |

## Usage Example

```go
// After validating a SAML response, extract roles for JIT provisioning
attrs := authResponse.AssertionAttributes()

rolesInfo, coerced, err := fleet.RolesFromSSOAttributes(attrs)
if err != nil {
    return fmt.Errorf("invalid SSO role attributes: %w", err)
}

if len(coerced) > 0 {
    log.Printf("coerced empty SSO attributes to null: %v", coerced)
}

if rolesInfo.IsSet() {
    if rolesInfo.Global != nil {
        // Apply global role, e.g. "admin", "observer"
        applyGlobalRole(user, *rolesInfo.Global)
    }
    for _, tr := range rolesInfo.Teams {
        applyTeamRole(user, tr.ID, tr.Role)
    }
}
```

**Supported SAML attribute names:**

```text
FLEET_JIT_USER_ROLE_GLOBAL           → global role
FLEET_JIT_USER_ROLE_TEAM_<ID>        → team role (v1)
FLEET_JIT_USER_ROLE_FLEET_<ID>       → team role (v2)
```

Valid role values: `admin`, `maintainer`, `observer`, `observer_plus`, `technician`, `null` (ignored).
