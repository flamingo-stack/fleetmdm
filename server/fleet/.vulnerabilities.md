Defines core vulnerability data structures and interfaces for tracking CVEs across software and operating systems in the Fleet MDM platform.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `CVE` | struct | Full CVE record with double-pointer fields for tier-aware nullability (omitted in free tier, nullable in premium) |
| `CVEMeta` | struct | Lightweight CVE metadata including CVSS score, EPSS probability, CISA known exploit flag, and description |
| `SoftwareCPE` | struct | Maps a software entry to its Common Platform Enumeration (CPE) identifier |
| `SoftwareVulnerability` | struct | Associates a CVE with a specific software ID; maps to the `software_cve` table |
| `OSVulnerability` | struct | Associates a CVE with an OS ID and source; maps to the `os_vulnerabilities` table |
| `Vulnerability` | interface | Generic constraint over `SoftwareVulnerability` and `OSVulnerability`, requiring `GetCVE()`, `Affected()`, and `Key()` |
| `VulnerabilitySource` | `int` (iota enum) | Enumeration of data sources (NVD, Ubuntu OVAL, RHEL OVAL, MSRC, etc.) |
| `VulnerabilityWithMetadata` | struct | Extends `CVE` with host count and source metadata for list views |
| `OSVulnerabilitiesWithCount` | struct | Pairs a CVE slice with a total count for paginated OS vulnerability responses |
| `VulnListOptions` | struct | Query parameters for vulnerability list endpoints, including team filtering and exploit flag |

## Usage Example

```go
// Build a software vulnerability and use its Key as a deduplication discriminator
sv := fleet.SoftwareVulnerability{
    SoftwareID:        42,
    CVE:               "CVE-2024-1234",
    ResolvedInVersion: ptr("1.2.3"),
}
fmt.Println(sv.Key())    // "software:42:CVE-2024-1234"
fmt.Println(sv.String()) // "{42,CVE-2024-1234}"

// Build an OS vulnerability from the Ubuntu OVAL source
ov := fleet.OSVulnerability{
    OSID:   7,
    CVE:    "CVE-2024-5678",
    Source: fleet.UbuntuOVALSource,
}
fmt.Println(ov.Key()) // "os:7:CVE-2024-5678:"

// Validate sort column before executing a query
opts := fleet.VulnListOptions{
    ValidSortColumns: []string{"cvss_score", "epss_probability", "created_at"},
    ListOptions:      fleet.ListOptions{OrderKey: "cvss_score"},
}
fmt.Println(opts.HasValidSortColumn()) // true
```

## Double-Pointer Fields

Fields like `CVSSScore **float64` on the `CVE` struct encode three distinct states:

| Value | Meaning |
|-------|---------|
| `nil` (outer pointer) | Field omitted — free tier, not serialized |
| `*nil` (inner pointer is `nil`) | Premium tier, no data available |
| `**value` | Premium tier, value present |
