Defines core data structures and conversion utilities for scheduled queries — osquery queries that run on a configurable schedule within Fleet packs.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `ScheduledQuery` | Struct | Full scheduled query entity with osquery config fields (interval, snapshot, platform, shard, denylist) and aggregated execution stats |
| `ScheduledQueryList` | Type | Slice of `*ScheduledQuery` with `Clone()` support |
| `AggregatedStats` | Struct | P50/P95 percentile stats for system/user CPU time and total executions |
| `ScheduledQueryPayload` | Struct | Partial payload for create/update API requests |
| `ScheduledQueryStats` | Struct | Per-host execution stats sourced from osquery (memory, executions, wall time, etc.) |
| `ScheduledQuery.Clone()` / `Copy()` | Methods | Deep copy with safe pointer duplication |
| `ScheduledQueryStats.TeamID()` | Method | Extracts team ID from `team-{id}` pack name convention |
| `ScheduledQueryFromQuery()` | Function | Converts a `Query` to a `ScheduledQuery`, mapping `Logging` mode to snapshot/removed booleans |
| `ScheduledQueryToQueryPayloadForNewQuery()` | Function | Builds a `QueryPayload` for creating a new query from a scheduled query |
| `ScheduledQueryPayloadToQueryPayloadForModifyQuery()` | Function | Maps a `ScheduledQueryPayload` to `QueryPayload` for updates; requires both `Snapshot` and `Removed` to change logging mode |

## Usage Example

```go
// Convert a Query into a ScheduledQuery
sq := fleet.ScheduledQueryFromQuery(&fleet.Query{
    ID:       42,
    Name:     "running_processes",
    Query:    "SELECT * FROM processes;",
    Interval: 3600,
    Logging:  "differential",
})

// Deep copy for safe mutation
clone := sq.Copy()
clone.Interval = 7200

// Resolve team ID from pack name
stats := &fleet.ScheduledQueryStats{PackName: "team-7"}
teamID, err := stats.TeamID() // returns pointer to 7
```

> **Note:** To change a scheduled query's logging mode via `ScheduledQueryPayload`, both `Snapshot` and `Removed` fields must be set together; setting only one has no effect on the logging behavior.
