Defines the core label domain types, constants, and validation logic for Fleet's label system, supporting dynamic (query-based), manual (host-list-based), and host-vitals label membership types.

## Key Components

### Types & Structs
- **`Label`** — Core label entity with ID, name, query, platform, membership type, and multi-tenancy fields
- **`LabelSpec`** — Serializable label specification used for bulk import/export operations
- **`LabelSummary`** / **`LabelWithTeamName`** — Lightweight projections of `Label` for list views
- **`LabelPayload`** / **`ModifyLabelPayload`** — API request payloads for creating and updating labels
- **`HostVitalCriteria`** — Recursive criteria tree (AND/OR) for host-vitals label evaluation
- **`LabelQueryExecution`** — Tracks per-host query execution results for dynamic labels
- **`HostsSlice`** — Custom JSON type that deserializes host identifiers as either strings or integers
- **`LabelIdent`** — Minimal ID+Name pair for label references

### Enums
- **`LabelType`** — `regular` or `builtin`; controls mutability
- **`LabelMembershipType`** — `dynamic`, `manual`, or `host_vitals`; determines how hosts are assigned
- **`HostVitalOperator`** — Comparison operators (`=`, `!=`, `>`, `<`, `LIKE`) for vitals criteria

### Functions
- **`ValidateLabelMembershipFields(spec)`** — Validates that label fields are consistent with their declared membership type; returns field-level errors
- **`ReservedLabelNames()`** — Returns the set of built-in label names that cannot be user-modified
- **`DetectMissingLabels(validMap, candidates)`** — Identifies label names that are referenced but do not exist

## Usage Example

```go
spec := &fleet.LabelSpec{
    Name:                "macOS Devices",
    Query:               "SELECT 1 FROM os_version WHERE platform = 'darwin';",
    LabelMembershipType: fleet.LabelMembershipTypeDynamic,
    Platform:            "darwin",
}

if err := fleet.ValidateLabelMembershipFields(spec); err != nil {
    log.Fatalf("invalid label spec: %v", err)
}

reserved := fleet.ReservedLabelNames()
if _, ok := reserved[spec.Name]; ok {
    log.Fatal("cannot use a reserved label name")
}

missing := fleet.DetectMissingLabels(
    map[string]uint{"macOS Devices": 42},
    []string{"macOS Devices", "Unknown Label"},
)
// missing == ["Unknown Label"]
```
