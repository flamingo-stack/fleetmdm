Defines shared metadata types used across Fleet's domain model for API object identification and paginated response handling.

## Key Components

| Type | Description |
|------|-------------|
| `ObjectMetadata` | Carries API version and kind fields for Fleet objects, following Kubernetes-style object identification |
| `PaginationMetadata` | Tracks pagination state for list responses, including next/previous page availability and optional total result count |

### `PaginationMetadata` Notes

- `TotalResults` is intentionally excluded from JSON serialization (`json:"-"`) as it is not always populated — callers should verify whether a non-zero value is expected for their specific endpoint.

## Usage Example

```go
// Attaching object metadata to a Fleet resource
obj := struct {
    fleet.ObjectMetadata
    Name string `json:"name"`
}{
    ObjectMetadata: fleet.ObjectMetadata{
        ApiVersion: "v1",
        Kind:       "Host",
    },
    Name: "my-host",
}

// Using pagination metadata in a list response
resp := struct {
    Hosts      []fleet.Host            `json:"hosts"`
    Meta       fleet.PaginationMetadata `json:"meta"`
}{
    Meta: fleet.PaginationMetadata{
        HasNextResults:     true,
        HasPreviousResults: false,
        TotalResults:       42, // populated internally, not serialized to JSON
    },
}
```
