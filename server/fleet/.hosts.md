Defines the core host data types, status constants, and list filtering options used throughout the Fleet MDM platform for managing and querying enrolled devices.

## Key Components

### Types & Constants

- **`HostStatus`** — String type with values `StatusOnline`, `StatusOffline`, `StatusMIA`, `StatusMissing`, `StatusNew`; includes `NewDuration` (24h) and `MIADuration` (30 days) thresholds
- **`MDMEnrollStatus`** — Enrollment state enum: `manual`, `automatic`, `pending`, `unenrolled`, `enrolled`, `personal`
- **`OSSettingsStatus`** — Configuration profile aggregate status: `verified`, `verifying`, `pending`, `failed`
- **`MDMBootstrapPackageStatus`** — Bootstrap package installation state: `installed`, `failed`, `pending`

### Functions

- **`IsPlaceholderHardwareSerial(serial string) bool`** — Detects junk/OEM serial numbers (empty, known placeholder strings, or single-repeated-character serials) that cannot uniquely identify a device
- **`(s HostStatus) IsValid() bool`** — Validates a `HostStatus` value
- **`(s OSSettingsStatus) IsValid() bool`** — Validates an `OSSettingsStatus` value
- **`(s MDMBootstrapPackageStatus) IsValid() bool`** — Validates a `MDMBootstrapPackageStatus` value

### `HostListOptions`

Rich filter struct used across multiple endpoints (`GET /hosts`, `GET /hosts/count`, `GET /labels/{id}/hosts`, `POST /hosts/delete`, etc.) supporting filters for:
- Status, team, policy response, software version/title, OS version
- MDM enrollment, bootstrap package, OS settings, disk encryption
- Vulnerability (CVE), low disk space, batch script execution, DEP profile

## Usage Example

```go
opts := fleet.HostListOptions{
    StatusFilter: fleet.StatusOnline,
    TeamFilter:   ptr.Uint(3),
    OSSettingsFilter: fleet.OSSettingsFailed,
    LowDiskSpaceFilter: ptr.Int(10),
}

// Detect placeholder serials before linking hosts
serial := "To Be Filled By O.E.M."
if fleet.IsPlaceholderHardwareSerial(serial) {
    // Fall back to UUID or other unique identifier
}
```
