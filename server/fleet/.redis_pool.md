Defines the `RedisPool` interface and `RedisMode` type, providing a unified abstraction over standalone Redis and Redis Cluster connection pools.

## Key Components

- **`RedisPool`** — Interface abstracting both `redigo`'s `Pool` (standalone) and `redisc`'s `Cluster`. Exposes four methods:
  - `Get() redis.Conn` — Returns a connection; must be closed after use.
  - `Close() error` — Closes the pool.
  - `Stats() map[string]redis.PoolStats` — Returns per-server pool statistics.
  - `Mode() RedisMode` — Reports the current Redis deployment mode.

- **`RedisMode`** — A `byte` enum indicating the Redis topology, with two constants:
  - `RedisStandalone` — Single-node Redis.
  - `RedisCluster` — Redis Cluster mode.

- **`RedisMode.String()`** — Returns a human-readable label (`"standalone"`, `"cluster"`, or `"unknown"`).

## Usage Example

```go
func connectAndPing(pool fleet.RedisPool) error {
    conn := pool.Get()
    defer conn.Close()

    _, err := conn.Do("PING")
    if err != nil {
        return fmt.Errorf("redis ping failed: %w", err)
    }

    fmt.Printf("Connected in %s mode\n", pool.Mode()) // e.g. "standalone"

    for addr, stats := range pool.Stats() {
        fmt.Printf("Server %s — active: %d, idle: %d\n",
            addr, stats.ActiveCount, stats.IdleCount)
    }
    return nil
}
```

## Notes

- Always call `Close()` on connections returned by `Get()` (use `defer`).
- Consumers should program against `RedisPool` rather than concrete types to remain topology-agnostic.
