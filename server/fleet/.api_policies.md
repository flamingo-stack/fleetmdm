Defines request and response types for the Fleet MDM policy API, covering CRUD operations for both global and team-scoped policies.

## Key Components

### Global Policy Types
| Type | Purpose |
|------|---------|
| `GlobalPolicyRequest` / `GlobalPolicyResponse` | Create a global policy |
| `ListGlobalPoliciesRequest` / `ListGlobalPoliciesResponse` | List all global policies |
| `GetPolicyByIDRequest` / `GetPolicyByIDResponse` | Fetch a single global policy |
| `CountGlobalPoliciesRequest` / `CountGlobalPoliciesResponse` | Count global policies |
| `DeleteGlobalPoliciesRequest` / `DeleteGlobalPoliciesResponse` | Bulk-delete global policies |
| `ModifyGlobalPolicyRequest` / `ModifyGlobalPolicyResponse` | Update a global policy |

### Team Policy Types
| Type | Purpose |
|------|---------|
| `TeamPolicyRequest` / `TeamPolicyResponse` | Create a team-scoped policy |
| `ListTeamPoliciesRequest` / `ListTeamPoliciesResponse` | List team policies (with optional inherited policies) |
| `CountTeamPoliciesRequest` / `CountTeamPoliciesResponse` | Count team and inherited policies |
| `GetTeamPolicyByIDRequest` / `GetTeamPolicyByIDResponse` | Fetch a single team policy |
| `DeleteTeamPoliciesRequest` / `DeleteTeamPoliciesResponse` | Bulk-delete team policies |
| `ModifyTeamPolicyRequest` / `ModifyTeamPolicyResponse` | Update a team policy |

### Utility Types
- **`ResetAutomationRequest`** — Resets policy automation for specified teams and policies
- **`ApplyPolicySpecsRequest`** — Batch-applies policy specs declaratively
- **`AutofillPoliciesRequest`** — AI-assisted autofill of policy description/resolution from SQL

All response types implement `Error() error`, making them compatible with Fleet's standard transport error handling.

Notable premium fields (`critical`, label filters, `continuous_automations_enabled`) are tagged `premium:"true"` and enforced at the licensing layer. Team policies extend global ones with automation extras like `CalendarEventsEnabled`, `ScriptID`, `SoftwareTitleID`, and `ConditionalAccessEnabled`.

## Usage Example

```go
// Create a team policy
req := fleet.TeamPolicyRequest{
    TeamID:      42,
    Name:        "Disk Encryption Required",
    Query:       "SELECT 1 FROM disk_encryption WHERE encrypted = 1;",
    Description: "Ensures disk encryption is enabled.",
    Resolution:  "Enable FileVault or BitLocker.",
    Platform:    "darwin",
    Critical:    true,
}

// List team policies including inherited global ones
listReq := fleet.ListTeamPoliciesRequest{
    TeamID:         42,
    MergeInherited: true,
    Opts:           fleet.ListOptions{PerPage: 20},
}

// Bulk delete
deleteReq := fleet.DeleteTeamPoliciesRequest{
    TeamID: 42,
    IDs:    []uint{1, 2, 3},
}
```
