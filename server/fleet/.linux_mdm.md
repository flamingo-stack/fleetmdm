Defines the `MDMLinuxDiskEncryptionSummary` struct used to represent aggregated disk encryption status counts for Linux devices managed via MDM.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MDMLinuxDiskEncryptionSummary` | `struct` | Holds counts of Linux devices grouped by disk encryption state |

### `MDMLinuxDiskEncryptionSummary` Fields

| Field | Type | JSON Key | Description |
|-------|------|----------|-------------|
| `Verified` | `uint` | `verified` | Devices with confirmed disk encryption |
| `ActionRequired` | `uint` | `action_required` | Devices requiring user or admin action |
| `Failed` | `uint` | `failed` | Devices where encryption enforcement failed |

## Usage Example

```go
summary := fleet.MDMLinuxDiskEncryptionSummary{
    Verified:       42,
    ActionRequired: 5,
    Failed:         1,
}

data, err := json.Marshal(summary)
if err != nil {
    log.Fatal(err)
}
// Output: {"verified":42,"action_required":5,"failed":1}
```

## Notes

- All fields use `uint` to prevent negative counts
- Typically populated by aggregating per-device encryption states across a fleet
- Mirrors the summary pattern used for macOS/Windows disk encryption (`MDMDiskEncryptionSummary`)
