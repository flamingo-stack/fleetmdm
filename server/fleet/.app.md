Defines the core application configuration types and structures for the Fleet MDM platform, including SMTP, SSO, MDM, and conditional access settings used across API request/response serialization.

## Key Components

- **`AppConfig`** — Top-level application configuration struct implementing `AuthzType()` for authorization
- **`SSOSettings` / `SSOProviderSettings`** — SSO/SAML configuration including IdP metadata, JIT provisioning, and SSO server URL overrides
- **`ConditionalAccessSettings`** — Microsoft Entra and Okta conditional access settings with `OktaConfigured()` and `BypassEnabled()` helpers
- **`SMTPSettings`** — Full SMTP configuration including auth methods, TLS, and server settings
- **`MDM`** — Comprehensive MDM settings covering Apple Business Manager, macOS/iOS/iPadOS/Windows update policies, disk encryption, and hardware attestation
- **`MDMAppleABMAssignmentInfo`** — Maps ABM organization names to team assignments for macOS, iOS, iPadOS, and BYOD
- **`MDMAppleVolumePurchasingProgramInfo`** — Associates VPP token locations with Fleet team assignments
- **`VulnerabilitySettings`** — Configures the local vulnerability database path

## Usage Example

```go
cfg := fleet.AppConfig{}

// Check if SSO is configured
if cfg.SSOSettings.EnableSSO && !cfg.SSOSettings.SSOProviderSettings.IsEmpty() {
    fmt.Println("SSO enabled with IdP:", cfg.SSOSettings.IDPName)
}

// Check Okta conditional access
if cfg.ConditionalAccess.OktaConfigured() {
    fmt.Println("Okta conditional access is fully configured")
}

// Check bypass setting
if cfg.ConditionalAccess.BypassEnabled() {
    fmt.Println("Conditional access bypass is active")
}
```

## Notes

- Several fields use `optjson.Bool` / `optjson.Slice` to support partial PATCH updates without overwriting unset fields
- `AppleBMEnabledAndConfigured` and `EnabledAndConfigured` are read-only server-set fields; they cannot be modified via the API
- `DeprecatedAppleBMDefaultTeam` is retained only for API backward compatibility; use `AppleBusinessManager` instead
