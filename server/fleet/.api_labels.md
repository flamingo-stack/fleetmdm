Request and response type definitions for the Fleet label management API, covering CRUD operations, spec management, and host-label associations.

## Key Components

| Type | Description |
|---|---|
| `CreateLabelRequest/Response` | Create a new label via `LabelPayload` |
| `ModifyLabelRequest/Response` | Update a label by ID; response includes team name |
| `GetLabelRequest/Response` | Fetch a single label by ID |
| `ListLabelsRequest/Response` | List labels with pagination, optional team filter, and host counts |
| `GetLabelsSummaryRequest/Response` | Lightweight label summary, optionally scoped to a team |
| `ListHostsInLabelRequest` | List hosts belonging to a label, with host-specific list options |
| `DeleteLabelRequest/Response` | Delete a label by name |
| `DeleteLabelByIDRequest/Response` | Delete a label by numeric ID |
| `ApplyLabelSpecsRequest/Response` | Bulk-apply label specs, with optional team scope and move list |
| `GetLabelSpecsRequest/Response` | Retrieve all label specs, optionally scoped to a team |
| `GetLabelSpecResponse` | Retrieve a single label spec |
| `RemoveLabelsFromHostRequest/Response` | Disassociate named labels from a specific host |
| `LabelResponse` | Label with `display_text`, `count`, and optional `host_ids` |
| `LabelWithTeamNameResponse` | Extends `LabelWithTeamName` with the same display fields |

All response types implement `Error() error` to satisfy the Fleet transport error interface.

## Usage Example

```go
// List labels for a specific team, including host counts
teamID := "42"
includeHostCounts := true
req := fleet.ListLabelsRequest{
    ListOptions: fleet.ListOptions{Page: 0, PerPage: 20},
    TeamID:            &teamID,
    IncludeHostCounts: &includeHostCounts,
}

// Apply bulk label specs scoped to a team
fleetID := uint(42)
applyReq := fleet.ApplyLabelSpecsRequest{
    Specs: []*fleet.LabelSpec{
        {Name: "linux-servers", Query: "SELECT 1 FROM os_version WHERE platform = 'linux'"},
    },
    TeamID:      &fleetID,
    NamesToMove: []string{"old-label"},
}

// Remove labels from a host
removeReq := fleet.RemoveLabelsFromHostRequest{
    ID:     123,
    Labels: []string{"linux-servers", "production"},
}
```
