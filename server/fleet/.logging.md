Defines the `JSONLogger` interface for writing JSON log entries to configurable output destinations within the Fleet package.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `JSONLogger` | `interface` | Contract for JSON log writers |
| `JSONLogger.Write` | `method` | Writes a batch of raw JSON log entries to the target destination |

## Usage Example

```go
// Implement JSONLogger for a custom destination
type FileLogger struct {
    file *os.File
}

func (f *FileLogger) Write(ctx context.Context, logs []json.RawMessage) error {
    for _, entry := range logs {
        if _, err := f.file.Write(append(entry, '\n')); err != nil {
            return err
        }
    }
    return nil
}

// Use the interface
var logger fleet.JSONLogger = &FileLogger{file: logFile}
err := logger.Write(ctx, []json.RawMessage{[]byte(`{"level":"info","msg":"hello"}`)})
```

## Notes

- Accepts `[]json.RawMessage` allowing pre-serialized JSON to be forwarded without re-encoding overhead.
- The `context.Context` parameter enables cancellation and deadline propagation for slow or remote log destinations.
- Designed for use with pluggable backends (file, HTTP, cloud logging services, etc.).
