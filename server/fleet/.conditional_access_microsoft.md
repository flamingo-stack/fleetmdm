Defines data structures for Microsoft Conditional Access integration within the Fleet MDM platform, mapping Entra (Azure AD) tenant configuration and per-host compliance state.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ConditionalAccessMicrosoftIntegration` | struct | Tenant-level Entra integration config: tenant ID, proxy secret, and setup completion flag |
| `AuthzType()` | method | Implements `authz.AuthzTyper`; returns the authorization type string `"conditional_access_microsoft"` |
| `HostConditionalAccessStatus` | struct | Per-host Entra compliance record: device ID, UPN, MDM enrollment state, policy compliance state, and display metadata |

## Field Notes

**`ConditionalAccessMicrosoftIntegration`**
- `ProxyServerSecret` — authenticates Fleet's Cloud proxy against the Entra tenant
- `SetupDone` — set to `true` only after admin consent and tenant provisioning are complete

**`HostConditionalAccessStatus`**
- `Managed` / `Compliant` — pointer booleans used to detect drift; Fleet compares these cached values against current state before pushing updates to Entra
- `DeviceID` / `UserPrincipalName` — populated via a Fleet detail query on the host
- Embeds `UpdateCreateTimestamps` for automatic `created_at` / `updated_at` tracking

## Usage Example

```go
integration := &fleet.ConditionalAccessMicrosoftIntegration{
    TenantID:          "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    ProxyServerSecret: "super-secret",
    SetupDone:         true,
}
fmt.Println(integration.AuthzType()) // "conditional_access_microsoft"

managed := true
compliant := false
status := &fleet.HostConditionalAccessStatus{
    HostID:            42,
    DeviceID:          "entra-device-id",
    UserPrincipalName: "user@example.com",
    Managed:           &managed,
    Compliant:         &compliant,
    DisplayName:       "DESKTOP-ABC123",
    OSVersion:         "macOS 14.4.1",
}
```
