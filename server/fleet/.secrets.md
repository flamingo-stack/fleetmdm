Defines secret-related constants, types, and error formatting for Fleet's server-side and host-scoped secret injection system used during MDM command delivery.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `ServerSecretPrefix` | `"FLEET_SECRET_"` | Prefix for user-configurable server secrets looked up by name |
| `HostSecretPrefix` | `"FLEET_HOST_SECRET_"` | Internal prefix for per-host secrets resolved by enrollment ID at command delivery time |
| `HostSecretRecoveryLockPassword` | `"RECOVERY_LOCK_PASSWORD"` | Host secret type for macOS recovery lock passwords |
| `HostSecretRecoveryLockPendingPassword` | `"RECOVERY_LOCK_PENDING_PASSWORD"` | Host secret type for pending passwords during rotation |
| `HostSecretMDMUnlockToken` | `"MDM_UNLOCK_TOKEN"` | Host secret type for MDM unlock tokens (Apple ClearPasscode commands) |

### Types

- **`MissingSecretsError`** — Error type carrying a slice of missing secret names. Formats a human-readable message quoting each missing variable using the `FLEET_SECRET_` prefix convention.

## Usage Example

```go
// Return an error when required secrets are absent
missing := []string{"DB_PASSWORD", "API_KEY"}
err := fleet.MissingSecretsError{MissingSecrets: missing}
fmt.Println(err.Error())
// Output: Couldn't add. Secret variables "FLEET_SECRET_DB_PASSWORD", "FLEET_SECRET_API_KEY" missing from database

// Check host secret type before MDM command delivery
if secretType == fleet.HostSecretRecoveryLockPassword {
    // resolve encrypted password from host_recovery_key_passwords
}
```

## Notes

- `HostSecretPrefix` and host secret type constants are **Fleet-internal only** — not user-facing or user-configurable.
- Host secrets are resolved at MDM **command delivery time** by enrollment ID, not by name.
