Defines the `QueryResultStore` interface for transmitting distributed query results between osqueryd clients and the Fleet server via a pub/sub system.

## Key Components

### Interface: `QueryResultStore`

| Method | Description |
|--------|-------------|
| `WriteResult(result DistributedQueryResult) error` | Publishes a query result submitted by an osqueryd client |
| `ReadChannel(ctx context.Context, query DistributedQueryCampaign) (<-chan interface{}, error)` | Returns a read-only channel streaming `DistributedQueryResult` or `error` values |
| `HealthCheck() error` | Validates the store is operational; returns `nil` on success |

## Usage Example

```go
// Writing a result (osqueryd client side)
err := store.WriteResult(DistributedQueryResult{
    QueryID: 42,
    Rows:    []map[string]string{{"pid": "1234", "name": "fleet"}},
})

// Reading results (campaign consumer side)
ch, err := store.ReadChannel(ctx, campaign)
if err != nil {
    log.Fatal(err)
}
for msg := range ch {
    switch v := msg.(type) {
    case DistributedQueryResult:
        fmt.Println("result:", v)
    case error:
        fmt.Println("stream error:", v)
    }
}

// Health check
if err := store.HealthCheck(); err != nil {
    log.Printf("query result store unhealthy: %v", err)
}
```

## Notes

- Implementations live in the `pubsub` package
- `ReadChannel` callers must handle both `DistributedQueryResult` and `error` channel values via type assertion
- The channel is closed when `ctx` is cancelled or the campaign ends
