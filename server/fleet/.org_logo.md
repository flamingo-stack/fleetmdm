Handles validation, content-type detection, and storage interface definitions for organization logo uploads, supporting PNG, JPEG, WebP, and SVG formats with security-focused SVG sanitization.

## Key Components

### Constants & Types
- `OrgLogoMaxFileSize` — Maximum upload size (100KB)
- `OrgLogoMode` — Enum (`light`, `dark`, `all`) controlling which theme a logo applies to
- `OrgLogoStore` — Interface for logo persistence (`Put`, `Get`, `Delete`, `Exists`)

### Format Detection
- `ContentTypeForOrgLogo(b []byte) string` — Identifies image format from magic bytes (PNG/JPEG/WebP) or SVG heuristic; returns the HTTP `Content-Type` or `""` for unsupported formats
- `hasWebPMagic(b []byte) bool` — Checks RIFF/WEBP container headers
- `looksLikeSVG(b []byte) bool` — Scans first 512 bytes for `<svg` tag (BOM/whitespace tolerant)

### Validation
- `ValidateOrgLogoBytes(b []byte) error` — Canonical validator enforcing size limit, format support, and SVG safety; used by both HTTP upload handlers and GitOps pre-flight checks
- `validateSVG(b []byte) error` — Strict XML-based SVG sanitizer blocking XXE, billion-laughs, SMIL animations, `on*` event handlers, `javascript:` hrefs, and `DOCTYPE` declarations
- `isSafeSVGURL(raw string) bool` — Allowlists fragment, relative, and `http(s)://` URLs; rejects protocol-relative and `javascript:` schemes

## Usage Example

```go
// Validate bytes before storing a logo
data, _ := io.ReadAll(uploadedFile)
if err := fleet.ValidateOrgLogoBytes(data); err != nil {
    http.Error(w, err.Error(), http.StatusBadRequest)
    return
}

// Detect content type for HTTP response headers
ct := fleet.ContentTypeForOrgLogo(data)
w.Header().Set("Content-Type", ct)

// Store using OrgLogoStore implementation
if err := store.Put(ctx, fleet.OrgLogoModeLight, bytes.NewReader(data)); err != nil {
    log.Fatal(err)
}

// Resolve modes for OrgLogoModeAll
modes := fleet.OrgLogoModeAll.Modes() // → [light, dark]
```
