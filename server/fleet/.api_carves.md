Request and response types for the Fleet file carving API, covering listing, retrieving, and managing osquery file carve sessions and their data blocks.

## Key Components

| Type | Description |
|---|---|
| `ListCarvesRequest` / `ListCarvesResponse` | List all carve sessions with filtering via `CarveListOptions` |
| `GetCarveRequest` / `GetCarveResponse` | Retrieve metadata for a single carve by ID |
| `GetCarveBlockRequest` / `GetCarveBlockResponse` | Fetch a specific block of carve data by carve ID and block ID |
| `CarveBeginRequest` / `CarveBeginResponse` | Initiate a new file carve session from an osquery host node |
| `CarveBlockRequest` / `CarveBlockResponse` | Submit a data block for an in-progress carve session |

All response types implement an `Error() error` method for consistent API error handling.

## Usage Example

```go
// Begin a file carve from an osquery host
beginReq := fleet.CarveBeginRequest{
    NodeKey:    "abc123nodekey",
    BlockCount: 10,
    BlockSize:  512000,
    CarveSize:  5120000,
    CarveId:    "carve-uuid-001",
    RequestId:  "req-uuid-001",
}

// Receive a subsequent data block for the carve session
blockReq := fleet.CarveBlockRequest{
    SessionId: "session-uuid-001",
    BlockId:   0,
    RequestId: "req-uuid-001",
    Data:      []byte{...},
}

// Retrieve stored carve metadata
getReq := fleet.GetCarveRequest{ID: 42}

// Retrieve a specific block of stored carve data
blockGetReq := fleet.GetCarveBlockRequest{ID: 42, BlockId: 3}
```

## Notes

- `CarveBeginRequest` implements `HostNodeKey() string` to satisfy host authentication interfaces using the node's key.
- Block data in `GetCarveBlockResponse` is returned as raw `[]byte`, suitable for reassembly of the carved file.
- See: [`api_carves.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/api_carves.go)
