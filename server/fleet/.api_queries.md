Request and response structs for all Fleet query-related API operations, including CRUD operations, bulk actions, spec management, and query report retrieval.

## Key Components

| Type | Description |
|------|-------------|
| `GetQueryRequest` / `GetQueryResponse` | Fetch a single query by ID |
| `ListQueriesRequest` / `ListQueriesResponse` | List queries with filtering, pagination, and platform targeting |
| `GetQueryReportRequest` / `GetQueryReportResponse` | Retrieve host-level query result rows for a given query |
| `CreateQueryRequest` / `CreateQueryResponse` | Create a new query from a `QueryPayload` |
| `ModifyQueryRequest` / `ModifyQueryResponse` | Update an existing query by ID |
| `DeleteQueryRequest` / `DeleteQueryResponse` | Delete a query by name and optional team |
| `DeleteQueryByIDRequest` / `DeleteQueryByIDResponse` | Delete a single query by numeric ID |
| `DeleteQueriesRequest` / `DeleteQueriesResponse` | Bulk-delete multiple queries by ID list |
| `ApplyQuerySpecsRequest` / `ApplyQuerySpecsResponse` | Apply declarative query specs (GitOps-style) |
| `GetQuerySpecsRequest` / `GetQuerySpecsResponse` | Retrieve all query specs for a team |
| `GetQuerySpecRequest` / `GetQuerySpecResponse` | Retrieve a single query spec by name |

## Usage Example

```go
// List queries for a specific team, merging inherited global queries
req := fleet.ListQueriesRequest{
    TeamID:         42,
    MergeInherited: true,
    Platform:       "darwin",
    ListOptions:    fleet.ListOptions{Page: 0, PerPage: 20},
}

// Bulk delete stale queries
del := fleet.DeleteQueriesRequest{
    IDs: []uint{1, 5, 9},
}

// Apply query specs declaratively
apply := fleet.ApplyQuerySpecsRequest{
    Specs: []*fleet.QuerySpec{
        {Name: "os-version", Query: "SELECT * FROM os_version;"},
    },
}
```

## Notes

- All response types implement `Error() error` for uniform error handling across the API transport layer.
- `TeamID` set to `0` is treated as the global (cross-team) scope throughout list and delete operations.
- `GetQueryResponse`, `CreateQueryResponse`, and `ModifyQueryResponse` each carry both a `Query` and a `Report` field — a transitional pattern pending cleanup in Fleet 5.
- The `renameto` struct tag is used to alias JSON field names (e.g., `fleet_id`, `report_id`) without renaming the underlying Go fields.
