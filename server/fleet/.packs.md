Defines core data structures and logic for osquery query packs, including pack creation, validation, deep copying, and authorization metadata extraction.

## Key Components

### Types
- **`Pack`** — Primary struct representing an osquery query pack, supporting three types: `global`, `team-$ID`, and user-created (nil type)
- **`PackListOptions`** — Extends `ListOptions` with a flag to include system-managed packs in list results
- **`PackPayload`** — Request payload struct for creating or updating packs
- **`PackSpec`** — Declarative spec representation used for import/export workflows
- **`PackSpecTargets`** — Target labels and teams within a `PackSpec`
- **`PackSpecQuery`** — Individual scheduled query definition within a `PackSpec`
- **`PackStats`** — Aggregated runtime statistics for a pack and its scheduled queries

### Constants
- **`MaxScheduledQueryInterval`** — Maximum allowed osquery schedule interval: `604800` seconds (7 days)
- **`PackKind`** — String constant `"pack"` used for resource kind identification

### Methods on `Pack`
- **`Clone() / Copy()`** — Produces a deep copy of a `Pack`, safely duplicating all slice fields
- **`ExtraAuthz()`** — Implements `authz.ExtraAuthzer`; returns `pack_team_id` and `is_global_pack` for authorization checks
- **`Verify()`** — Validates that the pack name is non-empty
- **`EditablePackType()`** — Returns `true` only for user-created packs (nil or empty `Type`)
- **`AuthzType()`** — Returns `"pack"` for authorization framework integration

### Methods on `PackPayload` / `PackSpec`
- **`PackPayload.Verify()`** — Validates name when provided
- **`PackSpec.Verify()`** — Validates name and ensures all query intervals are within `[1, 604800]`

## Usage Example

```go
// Create and validate a new pack payload
payload := &fleet.PackPayload{
    Name:     ptr.String("Weekly Audit"),
    Platform: ptr.String("linux"),
    Disabled: ptr.Bool(false),
    HostIDs:  &[]uint{1, 2, 3},
}
if err := payload.Verify(); err != nil {
    log.Fatal(err)
}

// Deep copy an existing pack
original := &fleet.Pack{Name: "My Pack", TeamIDs: []uint{10, 20}}
copied := original.Copy()

// Check pack authorization metadata
authz, err := original.ExtraAuthz()
// authz["is_global_pack"] == false
// authz["pack_team_id"]   == nil (user-created pack)

// Validate a pack spec with scheduled queries
spec := &fleet.PackSpec{
    Name: "Compliance",
    Queries: []fleet.PackSpecQuery{
        {QueryName: "open_sockets", Interval: 3600},
    },
}
if err := spec.Verify(); err != nil {
    log.Fatal(err) // fires if interval < 1 or > 604800
}
```
