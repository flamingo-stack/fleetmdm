Defines the core data structures and types for certificate template management in Fleet MDM, including request/response models, status tracking, and host-specific delivery representations.

## Key Components

| Type/Function | Description |
|---|---|
| `CertificateRequestSpec` | Input spec for creating a certificate template, mapping name, team, CA, and subject fields |
| `CertificateTemplate` | Core domain model representing a certificate template with authorization support |
| `CertificateTemplate.AuthzType()` | Returns `"certificate_template"` for Fleet's authorization system |
| `CertificateTemplateResponseSummary` | Flattened DB-mapped summary response with CA name resolved |
| `CertificateTemplateResponse` | Extends summary with CA type and team ID (team ID excluded from JSON) |
| `CertificateTemplateResponseForHost` | Host-specific response including delivery status, UUID, and SCEP/Fleet challenge fields |
| `CertificateTemplateStatus` | String enum: `pending`, `delivering`, `delivered`, `failed`, `verified` |
| `CertificateActivityStatus` | String enum for install activity outcomes: `installed`, `failed_install` |
| `CertificateTemplateStatusToMDMDeliveryStatus()` | Maps certificate template status to `MDMDeliveryStatus` for the `GetHost` endpoint |
| `HostCertificateTemplateForDelivery` | Represents a single template queued for host delivery with its operation type |
| `HostCertificateTemplatesForDelivery` | Aggregates delivery results, separating newly-transitioning IDs from all templates |

## Usage Example

```go
// Convert a certificate template status for the GetHost MDM profile response
status := CertificateTemplateVerified
mdmStatus := CertificateTemplateStatusToMDMDeliveryStatus(status)
// mdmStatus == MDMDeliveryVerified

// Check delivery batch results
result := HostCertificateTemplatesForDelivery{
    DeliveringTemplateIDs: []uint{42, 43},
    Templates: []HostCertificateTemplateForDelivery{
        {
            CertificateTemplateID: 42,
            Status:                CertificateTemplateDelivering,
            OperationType:         MDMOperationTypeInstall,
            UUID:                  "abc-123",
        },
    },
}

// Authorize a certificate template
tmpl := &CertificateTemplate{Name: "corp-wifi"}
authType := tmpl.AuthzType() // "certificate_template"
```

## Notes

- `SCEPChallenge` and `FleetChallenge` in `CertificateTemplateResponseForHost` are pointers to support nullable challenge strings; the encrypted form (`SCEPChallengeEncrypted`) is intentionally excluded from JSON output.
- The `renameto` struct tag on `Team`/`TeamID` fields indicates Fleet's internal team alias mapping.
- All in-progress statuses (`pending`, `delivering`, `delivered`) collapse to `MDMDeliveryPending` in the MDM delivery status conversion.
