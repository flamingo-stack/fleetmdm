Defines the core types, constants, and registry for Fleet's cron scheduling system, including schedule names, run statistics, and ad-hoc trigger management.

## Key Components

### Types
- **`CronScheduleName`** — Typed string for identifying named cron jobs (30+ constants defined, e.g. `CronVulnerabilities`, `CronMDMAppleProfileManager`, `CronCalendar`)
- **`CronSchedule`** — Interface requiring `Trigger()`, `Name()`, and `Start()` methods
- **`CronSchedules`** — Registry holding all active schedules; implements `CronSchedulesService`
- **`CronStats`** — DB-mapped struct recording run metadata (instance, timestamps, status, errors)
- **`CronStatsType`** — `"scheduled"` or `"triggered"`
- **`CronStatsStatus`** — `"pending"`, `"expired"`, `"completed"`, `"canceled"`, or `"queued"`
- **`CronScheduleErrors`** — `map[string]error` with custom JSON marshaling (converts errors to strings)

### Errors
- **`triggerConflictError`** — Returned when a schedule is already running; maps to HTTP 409
- **`triggerNotFoundError`** — Returned for unknown schedule names; maps to HTTP 404

## Usage Example

```go
// Initialize the schedule registry
schedules := fleet.NewCronSchedules()

// Register and start a schedule
err := schedules.StartCronSchedule(func() (fleet.CronSchedule, error) {
    return myVulnerabilitiesSchedule, nil
})

// Ad-hoc trigger by name
err = schedules.TriggerCronSchedule(ctx, string(fleet.CronVulnerabilities))
if err != nil {
    // Handle triggerConflictError (409) or triggerNotFoundError (404)
}

// List all registered schedule names
names := schedules.ScheduleNames() // sorted slice of strings
```
