Defines types and validation logic for managing external service integrations (Jira, Zendesk, Google Calendar) at both the global and team level within the Fleet MDM platform.

## Key Components

### Types

| Type | Description |
|---|---|
| `TeamIntegrations` | Aggregates Jira, Zendesk, and Google Calendar integrations for a specific team |
| `TeamJiraIntegration` | Team-scoped Jira config (URL, project key, failing policy toggle) |
| `TeamZendeskIntegration` | Team-scoped Zendesk config (URL, group ID, failing policy toggle) |
| `TeamGoogleCalendarIntegration` | Google Calendar config with webhook URL and enable flag |
| `JiraIntegration` | Global Jira config including API token and vulnerability alerting |
| `ZendeskIntegration` | Global Zendesk config including API token and vulnerability alerting |
| `IntegrationTestError` | Sentinel error type for failed external service connectivity tests |

### Functions

| Function | Description |
|---|---|
| `TeamIntegrations.Copy()` | Returns a deep copy of all team integrations |
| `TeamIntegrations.MatchWithIntegrations()` | Maps team integrations to global integrations, propagating team-level settings |
| `TeamIntegrations.Validate()` | Checks team integrations for duplicates |
| `IndexJiraIntegrations()` | Indexes global Jira integrations by `URL+ProjectKey` for O(1) lookup |
| `IndexZendeskIntegrations()` | Indexes global Zendesk integrations by `URL+GroupID` for O(1) lookup |
| `ValidateJiraIntegrations()` | Validates new Jira integrations, tests connectivity, and returns deleted entries |
| `ValidateZendeskIntegrations()` | Validates new Zendesk integrations, tests connectivity, and returns deleted entries |

## Usage Example

```go
// Index existing global integrations before updating AppConfig
indexed, err := fleet.IndexJiraIntegrations(appConfig.Integrations.Jira)
if err != nil {
    return err
}

// Validate incoming changes; test connectivity for new/modified entries
deleted, err := fleet.ValidateJiraIntegrations(ctx, indexed, newJiraIntgs)
if err != nil {
    var testErr fleet.IntegrationTestError
    if errors.As(err, &testErr) {
        // Return HTTP 422 for connectivity failures
    }
    return err
}

// Match team-level integrations against validated global integrations
teamIntgs := fleet.TeamIntegrations{
    Jira: []*fleet.TeamJiraIntegration{
        {URL: "https://jira.example.com", ProjectKey: "OPS", EnableFailingPolicies: true},
    },
}
if err := teamIntgs.Validate(); err != nil {
    return err
}
matched, err := teamIntgs.MatchWithIntegrations(appConfig.Integrations)
```
