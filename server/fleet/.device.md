Defines data structures used by Fleet Desktop to display host status information and manage MDM migration workflows.

## Key Components

| Type | Description |
|------|-------------|
| `DesktopSummary` | Top-level summary returned to Fleet Desktop clients; controls menu visibility and self-service availability |
| `DesktopNotifications` | Server-pushed flags triggering client-side actions (MDM migration, profile renewal) |
| `DesktopConfig` | Subset of `AppConfig` containing org branding and MDM settings relevant to the Desktop agent |
| `DesktopMDMConfig` | Holds macOS migration mode configuration for the Desktop agent |
| `DesktopOrgInfo` | Organization branding fields (name, logo URLs, contact URL) surfaced in the Desktop UI |
| `MigrateMDMDeviceWebhookPayload` | Webhook body sent when a device triggers an MDM migration event |

> **Note:** `OrgLogoURL` and `OrgLogoURLLightBackground` on `DesktopOrgInfo` are deprecated in favour of `OrgLogoURLDarkMode` and `OrgLogoURLLightMode`.

## Usage Example

```go
// Constructing a DesktopSummary to return from the Fleet server
failingCount := uint(3)
selfService := true

summary := fleet.DesktopSummary{
    FailingPolicies: &failingCount,
    SelfService:     &selfService,
    Notifications: fleet.DesktopNotifications{
        NeedsMDMMigration: true,
    },
    Config: fleet.DesktopConfig{
        OrgInfo: fleet.DesktopOrgInfo{
            OrgName:             "Acme Corp",
            OrgLogoURLDarkMode:  "https://example.com/logo-dark.png",
            OrgLogoURLLightMode: "https://example.com/logo-light.png",
            ContactURL:          "https://example.com/support",
        },
    },
}

// Webhook payload emitted on MDM migration
payload := fleet.MigrateMDMDeviceWebhookPayload{
    Timestamp: time.Now(),
    Host: struct {
        ID             uint   `json:"id"`
        UUID           string `json:"uuid"`
        HardwareSerial string `json:"hardware_serial"`
    }{
        ID:             42,
        UUID:           "abc-123",
        HardwareSerial: "C02XY1234567",
    },
}
```
