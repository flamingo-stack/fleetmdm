Defines request/response types for the Fleet target search and count API, enabling lookup and enumeration of hosts, labels, and teams.

## Key Components

| Type | Description |
|---|---|
| `SearchTargetsRequest` | Request payload for free-text target search with optional saved query ID and already-selected host exclusions |
| `LabelSearchResult` | Wraps `*Label` with display text and host count for search results |
| `TeamSearchResult` | Wraps `*Team` with display text and match count; includes custom JSON marshal/unmarshal to flatten `TeamConfig` |
| `TargetsData` | Aggregated search results container holding matched hosts, labels, and teams |
| `SearchTargetsResponse` | Full search response including targets and online/offline/missing-in-action host counts |
| `CountTargetsRequest` | Request payload for counting hosts within a given target selection |
| `CountTargetsResponse` | Count-only response with online/offline breakdown and error field |

## Usage Example

```go
// Build a search request excluding already-selected hosts
req := fleet.SearchTargetsRequest{
    MatchQuery: "production",
    QueryID:    ptr.Uint(42),
    Selected: fleet.HostTargets{
        HostIDs:  []uint{1, 2, 3},
        LabelIDs: []uint{10},
    },
}

// Parse a search response
var resp fleet.SearchTargetsResponse
if err := json.Unmarshal(data, &resp); err != nil {
    log.Fatal(err)
}
fmt.Printf("Online: %d, Offline: %d\n", resp.TargetsOnline, resp.TargetsOffline)

// Count targets for a selection
countReq := fleet.CountTargetsRequest{
    Selected: fleet.HostTargets{TeamIDs: []uint{5}},
    QueryID:  ptr.Uint(42),
}
```

## Notes

- `TeamSearchResult.MarshalJSON` flattens `TeamConfig` into the JSON output and converts `[]Host` to lightweight `HostResponse` slices via `HostResponsesForHostsCheap`.
- The `Teams` field in `TargetsData` uses the `renameto:"fleets"` struct tag, indicating a transport-layer rename used by the Fleet API transport layer.
- Both response types implement an `Error() error` method, satisfying a common Fleet API response interface for error propagation.
