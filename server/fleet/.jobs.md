Defines the `Job` struct and `JobState` type representing asynchronous background jobs managed by the Fleet worker package.

## Key Components

- **`JobState`** — String type with three possible states: `queued`, `success`, and `failure`
- **`Job`** — Core struct representing a persisted async job with fields for tracking lifecycle, retry count, scheduling, and error details

## Usage Example

```go
job := fleet.Job{
    Name:      "send_email",
    Args:      &json.RawMessage(`{"to": "user@example.com"}`),
    State:     fleet.JobStateQueued,
    NotBefore: time.Now().Add(5 * time.Minute),
}

// Check job outcome
switch job.State {
case fleet.JobStateQueued:
    fmt.Println("Job pending")
case fleet.JobStateSuccess:
    fmt.Println("Job completed")
case fleet.JobStateFailure:
    fmt.Printf("Job failed: %s (retries: %d)\n", job.Error, job.Retries)
}
```

## State Transitions

```text
Queued ───► Success
  │
  └────────► Failure
```

Jobs start in `queued`, execute at or after `NotBefore`, and transition to either `success` or `failure`. The `Retries` field tracks how many execution attempts occurred, and `Error` captures the failure reason.

| Field | Purpose |
|---|---|
| `NotBefore` | Delays execution until a specific time |
| `Retries` | Counts execution attempts |
| `Args` | Raw JSON payload passed to the job handler |
| `Error` | Stores failure message when state is `failure` |
