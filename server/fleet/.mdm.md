Defines core MDM (Mobile Device Management) types, constants, and utilities for the Fleet platform, supporting Apple, Microsoft, Windows, and Android device management workflows.

## Key Components

### Constants & Prefixes
- `MDMPlatformApple` / `MDMPlatformMicrosoft` — platform identifiers
- Profile UUID prefixes: `MDMAppleDeclarationUUIDPrefix`, `MDMAppleProfileUUIDPrefix`, `MDMWindowsProfileUUIDPrefix`, `MDMAndroidProfileUUIDPrefix`
- `MDMProfileProcessingKeyPrefix` / `MDMProfileProcessingTTL` — Redis-based processing state tracking
- `OneTimeChallengeTTL` — 1-hour TTL for SCEP challenges

### `FleetVarName` Type
A typed string representing Fleet variable names (without the `FLEET_VAR_` prefix), with helper methods:
- `WithPrefix()` — returns `$FLEET_VAR_<NAME>`
- `WithBraces()` — returns `${FLEET_VAR_<NAME>}`

### Fleet Variable Constants
Host variables: `FleetVarHostHardwareSerial`, `FleetVarHostUUID`, `FleetVarHostPlatform`, `FleetVarHostEndUserIDPUsername`, etc.

CA/certificate variables: `FleetVarNDESSCEPChallenge`, `FleetVarCertificateRenewalID`, `FleetVarDigiCertDataPrefix`, `FleetVarCustomSCEPChallengePrefix`, etc.

### Helper Functions
- `HasCAVariables(fleetVars []string) bool` — checks if any variable names correspond to certificate authority variables

### Compiled Regexps
Pre-compiled patterns for each Fleet variable (both `$FLEET_VAR_X` and `${FLEET_VAR_X}` forms), e.g., `FleetVarHostHardwareSerialRegexp`, `FleetVarRenewalIDRegexp` (matches both deprecated `SCEP_RENEWAL_ID` and current `CERTIFICATE_RENEWAL_ID`).

### Structs
- `AppleMDM` — APNs certificate metadata
- `AppleBM` / `ABMToken` — Apple Business Manager token with per-platform default team assignments (macOS, iOS, iPadOS, BYOD)
- `ABMTokenTeam` — team name/ID pair for ABM responses
- `AppleCSR` — APNs/SCEP certificate signing request data
- `ABMTermsUpdater` — minimal interface for handling ABM Terms of Service expiry

## Usage Example

```go
// Check if a variable name is a CA variable
vars := []string{"NDES_SCEP_CHALLENGE", "HOST_UUID"}
if fleet.HasCAVariables(vars) {
    // fetch SCEP challenge before profile installation
}

// Use FleetVarName helpers for template substitution
varName := fleet.FleetVarHostHardwareSerial
profileTemplate := strings.ReplaceAll(template, varName.WithBraces(), hostSerial)
// "${FLEET_VAR_HOST_HARDWARE_SERIAL}" → actual serial

// Match variables in profile content
if fleet.FleetVarNDESSCEPChallengeRegexp.MatchString(profileContent) {
    // profile requires NDES SCEP challenge replacement
}
```
