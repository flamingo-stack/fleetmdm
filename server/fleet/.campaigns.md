Defines the core data types for Fleet's distributed query (live query) campaign lifecycle, including campaign state, targets, and results.

## Key Components

| Type | Description |
|------|-------------|
| `DistributedQueryStatus` | Enum (`QueryWaiting`, `QueryRunning`, `QueryComplete`) representing campaign lifecycle state |
| `DistributedQueryCampaign` | Core campaign metadata: ID, associated query, status, and owning user |
| `DistributedQueryCampaignTarget` | Maps a campaign to one or more hosts/labels (one-to-many) |
| `DistributedQueryResult` | Per-host query result streamed via WebSocket to browser or `fleetctl`; kept minimal for Redis pubsub efficiency |
| `ResultHostData` | Lightweight host identity embedded in each result (ID, hostname, display name) |
| `QueryResult` | Raw rows and optional error for a single host, used in batch result aggregation |
| `QueryCampaignResult` | Aggregated results for a full campaign, grouped by query ID |

## Usage Example

```go
// Create a new campaign
campaign := fleet.DistributedQueryCampaign{
    QueryID: 42,
    Status:  fleet.QueryWaiting,
    UserID:  7,
}

// Transition status as the campaign progresses
campaign.Status = fleet.QueryRunning

// Handle a streamed result from a host
result := fleet.DistributedQueryResult{
    DistributedQueryCampaignID: campaign.ID,
    Host: fleet.ResultHostData{
        ID:          101,
        Hostname:    "macbook-pro.local",
        DisplayName: "Alice's MacBook Pro",
    },
    Rows: []map[string]string{
        {"pid": "1234", "name": "osqueryd"},
    },
}

// Check for per-host query errors
if result.Error != nil {
    log.Printf("host %s reported error: %s", result.Host.Hostname, *result.Error)
}
```

## Notes

- `DistributedQueryResult` is intentionally kept small — it is serialized to Redis and broadcast over WebSockets, so avoid adding large fields.
- The `QueryID` field uses the `renameto:"report_id"` tag, indicating an alias used in certain API or storage contexts.
- `QueryCampaignResult.Err` is excluded from JSON serialization (`json:"-"`) and is used only for internal error propagation.
