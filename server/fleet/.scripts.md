Manages Fleet's script execution domain types, including saved scripts, host script requests, results, and validation logic for script contents and shebang directives.

## Key Components

- **`Script`** — Represents a saved script (`.sh`, `.ps1`, `.py`) with metadata; `ValidateNewScript()` enforces extension rules and shebang compatibility
- **`HostScriptDetail`** — Aggregates script metadata and its most recent execution result for a given host
- **`HostScriptExecution`** — Single execution record with status derived from exit code (`pending`, `ran`, `error`)
- **`HostScriptRequestPayload`** — Incoming request payload for running a script; `ValidateParams()` enforces mutual exclusivity of `script_id`, `script_contents`, and `script_name`; `Priority()` elevates setup experience scripts
- **`HostScriptResultPayload`** — Inbound result payload submitted by the host agent
- **`HostScriptResult`** — Full execution result record with exit code, output, timeout, and soft-delete support for removed hosts
- **`setLastExecution()`** — Updates `HostScriptDetail.LastExecution` to the most recent execution by timestamp, then by row ID as a tiebreaker

## Usage Example

```go
// Validate and create a new saved script
s := &fleet.Script{
    Name:           "remediate.sh",
    ScriptContents: "#!/bin/sh\necho 'hello'",
}
if err := s.ValidateNewScript(); err != nil {
    log.Fatal(err)
}

// Build a HostScriptDetail with its last known execution
detail := fleet.NewHostScriptDetail(
    hostID, scriptID, "remediate.sh",
    &executionID, &executedAt, &exitCode, &hsrID,
)
fmt.Println(detail.LastExecution.Status) // "ran", "error", or "pending"

// Validate a run request
payload := fleet.HostScriptRequestPayload{
    HostID:         42,
    ScriptContents: "#!/bin/sh\nuname -a",
}
if err := payload.ValidateParams(30 * time.Second); err != nil {
    log.Fatal(err)
}
```
