Defines core types, interfaces, and sentinel errors for Apple MDM management in Fleet, including enrollment profiles, configuration profiles, device representations, and command issuer contracts.

## Key Components

### Interfaces
- **`MDMAppleCommandIssuer`** — Contract for issuing MDM commands to Apple devices (install/remove profiles, device lock, erase, recovery lock, passcode management)

### Sentinel Errors
- **`ErrRecoveryLockRotationPending`** / **`ErrRecoveryLockNotEligible`** — Guard recovery lock rotation state
- **`ErrManagedLocalAccountRotationPending`** / **`ErrManagedLocalAccountNotEligible`** — Guard managed local account rotation state

### Core Types
- **`MDMAppleEnrollmentProfile`** — Represents automatic or manual Apple MDM enrollment profiles; implements `AuthzType()`
- **`MDMAppleConfigProfile`** — Configuration profile with team scoping, label associations (`LabelsIncludeAll/Any`, `LabelsExcludeAny`), and MD5 checksum
- **`MDMAppleDevice`** / **`MDMAppleDEPDevice`** — MDM-enrolled and DEP-provisioned device representations
- **`MDMAppleInstaller`** — Enterprise application installer package with URL token auth
- **`MDMAppleCommandTimeoutError`** — Returns HTTP 504 on MDM command timeout
- **`MDMProfilesUpdates`** — Flags which profile types changed during batch processing

### Constants
- `ADUEEnrollmentChallengeExpiration` — 1-hour ADUE enrollment challenge TTL
- `MDMAppleStatus*` — Well-known MDM status strings (`Acknowledged`, `Error`, `Idle`, etc.)
- `PayloadScope` — `User` or `System` profile scoping

## Usage Example

```go
// Check eligibility before rotating recovery lock
err := rotateRecoveryLock(ctx, host, cmdUUID)
if errors.Is(err, fleet.ErrRecoveryLockNotEligible) {
    log.Info("host not eligible for rotation, skipping")
    return nil
}
if errors.Is(err, fleet.ErrRecoveryLockRotationPending) {
    log.Info("rotation already in progress")
    return nil
}

// Issue an MDM command via the command issuer
err = issuer.DeviceLock(ctx, host, uuid)
```
