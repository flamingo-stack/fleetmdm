Brief description of the software installer types, interfaces, and data structures used in Fleet's software package management system.

## Key Components

- **`SoftwareInstallerStore`** — Interface for storing/retrieving installer files (local filesystem or S3), with `Get`, `Put`, `Exists`, `Cleanup`, and `Sign` methods
- **`SoftwareInstallDetails`** — Contains all runtime details needed to execute an installation on a host: scripts, conditions, execution ID, and CDN URL
- **`SoftwareInstaller`** — Full metadata model for a software package, including platform, version, scripts, labels, categories, and Fleet-maintained app linkage
- **`SoftwarePackageResponse`** — Lightweight response type for batch/GitOps software apply operations, including icon and hash fields
- **`SoftwareTitleIdentifier`** — Identifies a software title by bundle identifier + source for batch-set deletion matching
- **`DeletedSoftwarePackage`** — Describes a package removed during a batch-set operation
- **`VPPAppResponse`** — Response type for App Store (VPP) apps applied via batch/GitOps
- **`SoftwareInstallerURL`** — CDN download details (URL + filename) embedded in install details

## Usage Example

```go
// Retrieve installer details for a host
details := fleet.SoftwareInstallDetails{
    ExecutionID:         "exec-123",
    InstallerID:         42,
    PreInstallCondition: "SELECT 1 FROM apps WHERE name = 'MyApp'",
    InstallScript:       "#!/bin/bash\ninstaller -pkg myapp.pkg -target /",
    PostInstallScript:   "echo 'done'",
    SelfService:         false,
    SoftwareInstallerURL: &fleet.SoftwareInstallerURL{
        URL:      "https://cdn.example.com/myapp.pkg",
        Filename: "myapp.pkg",
    },
}

// Check if installer exists in the store
exists, err := store.Exists(ctx, "sha256-abc123")

// Generate a signed download URL
signedURL, err := store.Sign(ctx, "sha256-abc123", fleet.SoftwareInstallerSignedURLExpiry)
```

## Notes

- `SoftwareInstallerSignedURLExpiry` is set to **6 hours**
- `SoftwareInstaller.Platform` supports `"darwin"`, `"windows"`, and `"linux"`
- Label scoping (`LabelsIncludeAny`, `LabelsExcludeAny`, `LabelsIncludeAll`) controls which hosts see a given installer
