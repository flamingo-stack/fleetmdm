Defines the core XML/SOAP types and validation logic for the Microsoft MDM (MS-MDE2) enrollment protocol, implementing the SOAP envelope structures and request validation used in Windows device management.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `SoapRequest` | Incoming SOAP envelope from Windows MDM client, with header/body parsing |
| `SoapResponse` | Outgoing SOAP envelope response to MDM client |
| `RequestHeader` / `ResponseHeader` | SOAP header structures for MDM messages |
| `BodyRequest` / `BodyResponse` | SOAP body wrappers containing MDM-specific message payloads |

### Validation Methods on `SoapRequest`

- `IsValidDiscoveryMsg()` — Validates MS-MDE2 Discovery request fields and supported enrollment versions
- `IsValidGetPolicyMsg()` — Validates GetPolicies request structure
- `IsValidRequestSecurityTokenMsg()` — Validates enrollment token request, including device ID, OS version, and PKCS type
- `isValidHeader()` / `isValidBody()` — Internal guards ensuring SOAP envelope well-formedness
- `GetHeaderBinarySecurityToken()` — Extracts and validates the `BinarySecurityToken` from the security header
- `GetRequestSecurityTokenMessage()` — Returns the `RequestSecurityToken` body element

### Constants

- `WINDOWS_SCEP_LOC_URI_PART` — OMA-DM URI path for SCEP certificate installation
- `WindowsMDMAuthNoncePrefix` — Prefix for MDM authentication nonces
- Message type iota: `MDEDiscovery`, `MDEPolicy`, `MDEEnrollment`, `MDEFault`, `MSMDM`

## Usage Example

```go
var req fleet.SoapRequest
if err := xml.Unmarshal(rawBody, &req); err != nil {
    return err
}

// Validate a Discovery request
if err := req.IsValidDiscoveryMsg(); err != nil {
    return fmt.Errorf("bad discovery request: %w", err)
}

// Extract security token for enrollment
token, err := req.GetHeaderBinarySecurityToken()
if err != nil {
    return err
}
```
