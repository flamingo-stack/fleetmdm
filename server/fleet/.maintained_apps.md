Defines the `MaintainedApp` domain type and supporting types for Fleet's library of centrally managed, auto-updated applications across macOS and Windows platforms.

## Key Components

### Types

- **`MaintainedApp`** — Core struct representing a Fleet-maintained app entry, including metadata (name, slug, version, platform), installer details (URL, SHA256, scripts), and categorization fields. Internal fields (`SHA256`, `UniqueIdentifier`, `AutomaticInstallQuery`, `PatchQuery`) are excluded from JSON serialization.
- **`MaintainedAppListOptions`** — Extends `ListOptions` with `Platform` (filter by `"darwin"` or `"windows"`) and `AvailableOnly` (hide apps already added to a team) filters.
- **`NoMaintainedAppsInDatabaseError`** — Sentinel error returned when the maintained apps list has not been populated; responds with HTTP 404.

### Methods on `MaintainedApp`

- **`Source()`** — Returns `"programs"` for Windows, `"apps"` for all other platforms.
- **`BundleIdentifier()`** — Returns the app's `UniqueIdentifier` on non-Windows platforms; empty string on Windows.
- **`AuthzType()`** — Returns `"maintained_app"` for authorization policy enforcement.

### Methods on `NoMaintainedAppsInDatabaseError`

- **`Error()`** — Human-readable error message with remediation hint (`fleetctl trigger`).
- **`StatusCode()`** — Returns `http.StatusNotFound` (404) for go-kit HTTP transport.
- **`Is()`** — Enables `errors.Is` matching by message comparison.

## Usage Example

```go
app := &fleet.MaintainedApp{
    Name:             "Google Chrome",
    Slug:             "google-chrome",
    Platform:         "darwin",
    UniqueIdentifier: "com.google.Chrome",
}

fmt.Println(app.Source())            // "apps"
fmt.Println(app.BundleIdentifier())  // "com.google.Chrome"
fmt.Println(app.AuthzType())         // "maintained_app"

opts := fleet.MaintainedAppListOptions{
    Platform:      "darwin",
    AvailableOnly: true,
}
```
