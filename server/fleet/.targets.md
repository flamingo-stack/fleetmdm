Defines the core targeting types and logic for Fleet live query campaigns, including host selection by individual host, label, or team.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `TargetSearchResults` | struct | Aggregates search results across hosts, labels, and teams |
| `TargetMetrics` | struct | Host online/offline status counters for a target set |
| `HostTargets` | struct | Campaign target specification using host, label, and team IDs with OR/AND selection semantics |
| `TargetType` | `int` enum | Discriminates between `TargetLabel`, `TargetHost`, and `TargetTeam` |
| `ParseTargetType` | func | Parses a string (`"label"`, `"host"`, `"team"`) into a `TargetType` |
| `Target` | struct | A single resolved target with its type, ID, and display text |

## Usage Example

```go
// Build a campaign target set
targets := fleet.HostTargets{
    HostIDs:  []uint{42},
    LabelIDs: []uint{7, 12},
    TeamIDs:  []uint{3},
}

// Parse and serialize a TargetType
tt, err := fleet.ParseTargetType("label")
if err != nil {
    log.Fatal(err)
}
fmt.Println(tt.String()) // "label"

// Inspect metrics for a resolved target set
metrics := fleet.TargetMetrics{
    TotalHosts:   100,
    OnlineHosts:  80,
    OfflineHosts: 15,
    MissingInActionHosts: 5,
    NewHosts: 3,
}
fmt.Printf("Online: %d / %d\n", metrics.OnlineHosts, metrics.TotalHosts)
```

## Selection Semantics for `HostTargets`

- **`HostIDs`** — always included, regardless of label or team filters
- **`LabelIDs`** — builtin labels are OR'd; custom labels are OR'd; the two groups are AND'd together. The "All hosts" builtin label overrides all other filters
- **`TeamIDs`** — OR'd among themselves; AND'd with any provided label selection

## Notes

- `TargetType` implements `json.Marshaler` / `json.Unmarshaler`, serializing as a human-readable string (`"host"`, `"label"`, `"team"`)
- `Target.AuthzType()` returns `"target"` for authorization middleware integration
