Defines the core activity types and supporting interfaces used throughout the Fleet MDM platform's activity/audit log system, mapping domain events (policy changes, user actions, host management) to structured, serializable types.

## Key Components

### Interfaces & Type Aliases
- **`ActivityWriteService`** — Combines `NewActivityService` and `CleanupHostActivitiesService` for write-side activity operations
- **`Activity`** / **`ActivityDetails`** — Aliases to canonical types from `server/activity/api`
- **`NewActivityFunc`** — Function signature: `func(ctx, *User, ActivityDetails) error`

### Upcoming Activity Types
- **`UpcomingActivity`** — Augmented activity for pending host actions (embeds `Activity`)
- **`UpcomingActivityMeta`** — DB-mapped metadata including `ExecutionID`, `ActivatedAt`, `WellKnownAction`
- **`WellKnownActionType`** — Enum for `Lock`, `Unlock`, `Wipe`, `None`

### Activity Type Structs (selected)
Each implements `ActivityDetails` via `ActivityName() string`:

| Type | Activity Name |
|---|---|
| `ActivityTypeCreatedPolicy` | `created_policy` |
| `ActivityTypeDeletedHost` | `deleted_host` |
| `ActivityTypeMDMEnrolled` | _(truncated)_ |
| `ActivityTypeTransferredHostsToTeam` | `transferred_hosts` |
| `ActivityTypeUserLoggedIn` | `user_logged_in` |
| `ActivityTypeChangedUserGlobalRole` | `changed_user_global_role` |

### Automation Detection
- `ActivityTypeDeletedUser.WasFromAutomation()` — returns `true` when triggered by SCIM
- `ActivityTypeDeletedHost.WasFromAutomation()` — returns `true` for `DeletedHostTriggeredByExpiration`

## Usage Example

```go
// Log a policy creation activity
activity := fleet.ActivityTypeCreatedPolicy{
    ID:       42,
    Name:     "Require FileVault",
    TeamID:   ptr.Int64(7),
    TeamName: ptr.String("Engineering"),
}

if err := svc.NewActivity(ctx, authUser, activity); err != nil {
    return err
}

// Check if a host deletion was automated
deleted := fleet.ActivityTypeDeletedHost{
    HostID:      101,
    TriggeredBy: fleet.DeletedHostTriggeredByExpiration,
}
fmt.Println(deleted.WasFromAutomation()) // true
```
