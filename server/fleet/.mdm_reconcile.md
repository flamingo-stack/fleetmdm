Platform-neutral types and interfaces for the batched MDM profile reconciliation system, defining how profile label applicability is computed in memory across platforms.

## Key Components

### Types & Constants

| Name | Kind | Description |
|------|------|-------------|
| `MDMProfileIncludeMode` | `int` type | Enum controlling how include-labels gate profile applicability to a host |
| `MDMProfileIncludeNone` | constant | No include labels; applicability determined by team, platform, and exclude labels only |
| `MDMProfileIncludeAll` | constant | Host must be a member of **every** non-broken include label |
| `MDMProfileIncludeAny` | constant | Host must be a member of **at least one** include label |
| `MDMProfileLabelRef` | struct | Single label reference attached to a profile; `nil` `LabelID` indicates a deleted ("broken") label |
| `MDMLabeledEntity` | interface | Minimal view of any label-gated MDM entity (profile or declaration) required by the reconciler |

### Functions

| Name | Description |
|------|-------------|
| `anyMDMLabelBroken` | Reports whether any label in a slice has a `nil` `LabelID`, signaling a broken label assignment |

## Usage Example

```go
// Implement MDMLabeledEntity for a platform-specific profile type
type MyProfile struct {
    TeamID        uint
    IncludeMode   fleet.MDMProfileIncludeMode
    IncludeLabels []fleet.MDMProfileLabelRef
    ExcludeLabels []fleet.MDMProfileLabelRef
}

func (p *MyProfile) GetTeamID() uint                              { return p.TeamID }
func (p *MyProfile) GetIncludeMode() fleet.MDMProfileIncludeMode  { return p.IncludeMode }
func (p *MyProfile) GetIncludeLabels() []fleet.MDMProfileLabelRef { return p.IncludeLabels }
func (p *MyProfile) GetExcludeLabels() []fleet.MDMProfileLabelRef { return p.ExcludeLabels }
func (p *MyProfile) HasBrokenLabel() bool {
    return anyMDMLabelBroken(p.IncludeLabels) || anyMDMLabelBroken(p.ExcludeLabels)
}
```

## Notes

- Exclude labels always use **"exclude any"** semantics regardless of include mode.
- `LabelMembershipType` on `MDMProfileLabelRef` distinguishes dynamic, manual, and host-vitals labels, which affects timing checks for dynamic labels created after a host's last `label_updated_at`.
- The matching logic lives in `server/mdm/reconcile` to keep applicability rules consistent across Apple and Windows platforms.
