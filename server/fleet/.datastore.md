Central data access layer interface for the Fleet MDM platform, defining the `Datastore` interface and related sub-interfaces that all persistence implementations must satisfy.

## Key Components

| Interface / Type | Description |
|---|---|
| `Datastore` | Master interface combining all Fleet DAL sub-interfaces (users, queries, campaigns, packs, hosts, MDM, etc.) |
| `CarveStore` | File carving operations: create, retrieve, block management, and cleanup of carve sessions |
| `CarveBySessionIder` | Minimal interface for session-based carve lookup |
| `InstallerStore` | Blob storage interface for pre-built Fleet osquery installers (Fleet Sandbox use) |
| `CleanupExcessQueryResultRowsOptions` | Configuration struct for batched query result row cleanup |

### Notable `Datastore` Sub-Sections

- **UserStore** — CRUD for users, email confirmation, admin-safe deletion
- **QueryStore** — Query lifecycle, scheduling, live query stats, aggregated perf percentiles
- **CampaignStore** — Distributed query campaign management and cleanup
- **OpenFrame extensions** — `AddQueryHosts`, `RemoveQueryHosts`, `ReplaceQueryHosts`, `ListQueryHosts` for host-targeted query assignments

## Usage Example

```go
// Inject Datastore into a service
type Service struct {
    ds fleet.Datastore
}

func (s *Service) GetUser(ctx context.Context, id uint) (*fleet.User, error) {
    return s.ds.UserByID(ctx, id)
}

// Carve cleanup (called from cron)
func (s *Service) RunCarveCleanup(ctx context.Context) error {
    expired, err := s.ds.CleanupCarves(ctx, time.Now())
    if err != nil {
        return err
    }
    log.Printf("Expired %d carves", expired)
    return nil
}

// OpenFrame: assign hosts to a query
_, err := ds.ReplaceQueryHosts(ctx, queryID, []uint{1, 2, 3})
```

## Notes

- `InstallerStore` is scoped to Fleet Sandbox; see [Fleet server config docs](https://fleetdm.com/docs/configuration/fleet-server-configuration#packaging).
- The `Datastore` interface embeds `health.Checker`, `GetsAppConfig`, and `AccessesMDMConfigAssets` for cross-cutting concerns.
