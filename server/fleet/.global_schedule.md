Defines the payload structure for representing the global schedule in Fleet, wrapping a collection of scheduled queries.

## Key Components

- **`GlobalSchedulePayload`** — Top-level response/request payload struct containing a list of globally scheduled queries.
  - `GlobalSchedule []*ScheduledQuery` — Slice of pointers to `ScheduledQuery` objects, serialized as `"global_schedule"` in JSON.

## Usage Example

```go
payload := fleet.GlobalSchedulePayload{
    GlobalSchedule: []*fleet.ScheduledQuery{
        {
            Name:     "Weekly Disk Usage",
            Query:    "SELECT * FROM disk_info;",
            Interval: 604800,
        },
    },
}

data, err := json.Marshal(payload)
if err != nil {
    log.Fatal(err)
}
fmt.Println(string(data))
// Output: {"global_schedule":[{"name":"Weekly Disk Usage",...}]}
```

## Notes

- This struct acts purely as an envelope; all scheduling logic and fields are defined in `ScheduledQuery`.
- Typically used in API responses for endpoints that return or accept the global query schedule.
