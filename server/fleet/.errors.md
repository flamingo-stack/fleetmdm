Defines the core error types, sentinel errors, and error interfaces used throughout the Fleet server package, mapping domain-specific failures to appropriate HTTP status codes.

## Key Components

### Sentinel Errors
| Variable | Description |
|---|---|
| `ErrNoContext` | Context key not set |
| `ErrMissingLicense` | Fleet Premium license required |
| `ErrMDMNotConfigured` | MDM not configured |
| `ErrWindowsMDMNotConfigured` | Windows MDM not configured |
| `ErrAndroidMDMNotConfigured` | Android MDM not configured |

### Interfaces
- **`ErrWithStatusCode`** — errors that map to a specific HTTP status code via `StatusCode() int`
- **Type aliases** for `ErrWithInternal`, `ErrWithLogFields`, `ErrWithRetryAfter`, `ErrWithIsClientError`, `ErrorUUIDer`, `ErrorWithUUID` — re-exported from `platform/errors` and `platform/http`

### Error Types
| Type | HTTP Status | Notes |
|---|---|---|
| `InvalidArgumentError` | 422 | Validation failures; supports multiple field errors |
| `PermissionError` | — | Authenticated but unauthorized access |
| `OTAForbiddenError` | 403 | Surfaces error message in iOS/iPadOS OTA enrollment dialogs |
| `licenseError` | 402 | Missing Fleet Premium license |
| `MDMNotConfiguredError` | 400 | MDM not set up |
| `WindowsMDMNotConfiguredError` | 400 | Windows MDM not set up |
| `AndroidMDMNotConfiguredError` | 400 | Android MDM not set up |
| `GatewayError` | 502/504 | Upstream gateway failures |

## Usage Example

```go
// Validation error with multiple fields
err := fleet.NewInvalidArgumentError("email", "must be a valid email address")
err.Append("name", "cannot be empty")
if err.HasErrors() {
    return err
}

// License-gated feature
if !license.IsPremium() {
    return fleet.NewLicenseErrorWithCause("SSO configuration")
}

// Custom HTTP status on invalid argument
return fleet.NewInvalidArgumentError("token", "expired").WithStatus(http.StatusUnauthorized)

// MDM guard
if !config.MDMConfigured() {
    return fleet.ErrMDMNotConfigured
}
```
