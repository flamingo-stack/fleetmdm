Android MDM profile types, validation logic, and policy field utilities for Fleet's Android device management integration.

## Key Components

### Types

- **`MDMAndroidConfigProfile`** – Represents an Android MDM configuration profile in Fleet, including UUID, team association, raw JSON payload, and label selectors.
- **`MDMAndroidProfilePayload`** – Tracks the delivery status and operation metadata for a profile applied to a specific host.
- **`HostMDMAndroidProfile`** – Represents the MDM profile status for an individual Android host; converts to the generic `HostMDMProfile` via `ToHostMDMProfile()`.
- **`AndroidPolicyRequestPayload`** – Wraps an `androidmanagement.Policy` with metadata mapping policy settings to their originating profile UUIDs.

### Variables

- **`AndroidForbiddenJSONKeys`** – Deny-list of top-level JSON keys (e.g., `applications`, `encryptionPolicy`) that are blocked from user-provided profiles, with human-readable error messages.
- **`AndroidPremiumOnlyJSONKeys`** – Keys restricted to Fleet Premium licenses (e.g., `systemUpdate`).
- **`FleetVarsSupportedInAndroidAppConfig`** – Allow-list of `FleetVarName` values permitted inside Android managed app configuration JSON.

### Functions

- **`ValidateUserProvided(isPremium bool) error`** – Validates a user-uploaded Android config profile: checks for empty JSON, reserved profile names, forbidden/premium-only keys, unknown policy fields, and structural type errors.
- **`IsAndroidPolicyFieldValid(fieldName string) bool`** – Thread-safe, lazily-initialized lookup that validates a JSON key against the `androidmanagement.Policy` struct's JSON tags.
- **`ValidateAndroidAppConfiguration(config json.RawMessage) error`** – Validates Android app configuration JSON, enforcing allowed top-level keys (`managedConfiguration`, `workProfileWidgets`), valid widget values, and supported Fleet variables.

## Usage Example

```go
profile := &fleet.MDMAndroidConfigProfile{
    Name:    "corporate-policy",
    RawJSON: []byte(`{"screenCaptureDisabled": true}`),
}

if err := profile.ValidateUserProvided(isPremium); err != nil {
    log.Fatalf("invalid profile: %v", err)
}

// Validate a managed app configuration
appConfig := json.RawMessage(`{"managedConfiguration": {"key": "value"}}`)
if err := fleet.ValidateAndroidAppConfiguration(appConfig); err != nil {
    log.Fatalf("invalid app config: %v", err)
}

// Check if a policy field is valid
if fleet.IsAndroidPolicyFieldValid("screenCaptureDisabled") {
    fmt.Println("field is a known Android policy key")
}
```
