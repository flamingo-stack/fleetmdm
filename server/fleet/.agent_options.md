Defines the `AgentOptions` structure and validation logic for Fleet's osquery agent configuration, including platform overrides, command-line flags, extensions, and orbit-specific settings.

## Key Components

### Types
- **`AgentOptions`** – Top-level struct representing the full agent options payload, including base config, platform overrides, CLI flags, extensions, update channels, and orbit options.
- **`OrbitAgentOptions`** – Orbit-specific settings, currently supporting `DebugLoggingOnEnrollDuration`.
- **`AgentOptionsOverrides`** – Holds per-platform config overrides keyed by platform name.
- **`osqueryAgentOptions`** – Internal struct representing valid osquery configuration keys (options, schedule, packs, YARA, decorators, etc.).
- **`OsqueryCommandLineFlagsLinux`** – OS-specific CLI flags for Linux audit/BPF subsystems.

### Functions
- **`ForPlatform(platform string)`** – Returns the platform-specific config override if available, falling back to the base config.
- **`ValidateJSONAgentOptions(...)`** – Full validation of a raw JSON agent options payload: checks field types, enforces limits, validates extensions and update channels, and rejects unsupported CLI flags.
- **`SuggestAgentOptionsCorrection(err error)`** – Enriches unknown-field errors with a human-readable suggestion pointing to the correct key path.
- **`checkEmptyFields(...)`** – Ensures no fields within a JSON object are `null` or empty strings.
- **`validateJSONAgentOptionsExtensions(...)`** – Validates extension definitions, including label existence checks and premium license enforcement.

### Constants
- `maxAgentScriptExecutionTimeout` – Hard cap of `18000` seconds for script execution.
- `MaxOrbitDebugLoggingOnEnrollDurationSeconds` / `MaxOrbitDebugLoggingOnEnrollDuration` – Max 24-hour orbit debug logging window.

## Usage Example

```go
rawJSON := json.RawMessage(`{
  "config": {"options": {"logger_plugin": "tls"}},
  "script_execution_timeout": 300
}`)

if err := fleet.ValidateJSONAgentOptions(ctx, ds, rawJSON, isPremium, teamID); err != nil {
    log.Fatalf("invalid agent options: %v", err)
}

var opts fleet.AgentOptions
json.Unmarshal(rawJSON, &opts)
platformConfig := opts.ForPlatform("darwin")
```
