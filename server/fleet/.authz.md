Defines the authorization action constants used throughout the Fleet package to represent the set of permitted operations on entities.

## Key Components

### Action Constants

| Constant | Value | Description |
|---|---|---|
| `ActionRead` | `"read"` | Read a single entity |
| `ActionList` | `"list"` | List entities |
| `ActionWrite` | `"write"` | Create, update, or delete an entity |
| `ActionWriteHostLabel` | `"write_host_label"` | Write labels on hosts |
| `ActionCreate` | `"create"` | Create entities with permissions distinct from standard writes (e.g. global labels) |
| `ActionCancelHostActivity` | `"cancel_host_activity"` | Cancel an upcoming host activity |
| `ActionTransferHost` | `"transfer_host"` | Transfer a host between teams; permitted for technicians without requiring `ActionWrite` |
| `ActionResend` | `"resend"` | Resend an entity (e.g. configuration profiles) to a single host |
| `ActionReadSecrets` | `"read_secrets"` | Read sensitive credentials such as CA private keys or API tokens |
| `ActionWriteRole` | `"write_role"` | Modify a user's global roles and team assignments |
| `ActionChangePassword` | `"change_password"` | Change an existing user's password |
| `ActionRun` | `"run"` | Run a live query |
| `ActionRunNew` | `"run_new"` | Run a new (unsaved) live query |
| `ActionSelectiveRead` | `"selective_read"` | Targeted read access for roles with limited permissions |
| `ActionSelectiveList` | `"selective_list"` | Targeted list access for roles with limited permissions |

## Usage Example

```go
// Authorize a read action on a host entity
if err := svc.authz.Authorize(ctx, host, fleet.ActionRead); err != nil {
    return nil, err
}

// Authorize a host transfer (permitted for technicians)
if err := svc.authz.Authorize(ctx, host, fleet.ActionTransferHost); err != nil {
    return nil, err
}

// Authorize reading sensitive secrets (e.g. CA private key)
if err := svc.authz.Authorize(ctx, caConfig, fleet.ActionReadSecrets); err != nil {
    return nil, err
}
```

> **Note:** `ActionSelectiveRead` and `ActionSelectiveList` exist to grant targeted access to roles that are otherwise restricted from broad read or list operations.
