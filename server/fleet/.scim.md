Defines the core SCIM (System for Cross-domain Identity Management) data types and structures used for provisioning users and groups in Fleet's database layer.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `SCIMMaxFieldLength` | Constant | Default maximum length (255) for SCIM field validation |
| `SCIMValidationError` | Struct | Error type returned when a SCIM field fails validation |
| `ScimUser` | Struct | Represents a SCIM-provisioned user record with profile fields, emails, and group memberships |
| `ScimUserGroup` | Struct | Lightweight group reference attached to a `ScimUser` |
| `ScimUserEmail` | Struct | An email address associated with a SCIM user, supporting primary/type metadata |
| `ScimGroup` | Struct | Represents a SCIM group with optional member user IDs |
| `ScimListOptions` | Struct | Pagination options (1-based `StartIndex`, `PerPage`) for SCIM list endpoints |
| `ScimUsersListOptions` | Struct | Extends `ScimListOptions` with user-specific filters (`UserNameFilter`, `EmailTypeFilter`, `EmailValueFilter`) |
| `ScimGroupsListOptions` | Struct | Extends `ScimListOptions` with `DisplayNameFilter` and an `ExcludeUsers` flag |
| `ScimLastRequest` | Struct | Audit record of the most recent SCIM provisioning request status and timestamp |
| `ScimDetails` | Struct | API-level wrapper exposing `ScimLastRequest` as JSON |

### Notable Methods

- **`ScimUser.DisplayName()`** — Returns a composed display name from `GivenName` and `FamilyName`, gracefully handling `nil` values.
- **`ScimUser.AuthzType()`** — Returns `"scim_user"` for Fleet's authorization framework.
- **`ScimUserEmail.GenerateComparisonKey()`** — Produces a stable `email:type:primary` string for deduplication and diffing of email records.

## Usage Example

```go
user := &fleet.ScimUser{
    UserName:   "jane.doe@example.com",
    GivenName:  fleet.StringPtr("Jane"),
    FamilyName: fleet.StringPtr("Doe"),
    Active:     fleet.BoolPtr(true),
    Emails: []fleet.ScimUserEmail{
        {
            Email:   "jane.doe@example.com",
            Primary: fleet.BoolPtr(true),
            Type:    fleet.StringPtr("work"),
        },
    },
}

fmt.Println(user.DisplayName())    // "Jane Doe"
fmt.Println(user.AuthzType())      // "scim_user"

email := user.Emails[0]
fmt.Println(email.GenerateComparisonKey()) // "jane.doe@example.com:work:true"

opts := fleet.ScimUsersListOptions{
    ScimListOptions:  fleet.ScimListOptions{StartIndex: 1, PerPage: 50},
    UserNameFilter:   fleet.StringPtr("jane.doe@example.com"),
}
```
