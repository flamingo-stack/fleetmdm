Defines the `ACMEWriteService` interface for ACME enrollment write operations within the Fleet package.

## Key Components

- **`ACMEWriteService`** — Interface exposing the subset of ACME service functionality required by the legacy service layer for write operations.
  - **`NewACMEEnrollment(ctx, hostIdentifier)`** — Creates a new enrollment record in the `acme_enrollments` table for the given host UUID and returns the generated `path_identifier`.

## Usage Example

```go
var svc fleet.ACMEWriteService = // inject concrete implementation

pathID, err := svc.NewACMEEnrollment(ctx, "host-uuid-1234")
if err != nil {
    log.Fatalf("failed to create ACME enrollment: %v", err)
}
fmt.Println("Enrollment path identifier:", pathID)
```

## Notes

- This interface is intentionally narrow — it exposes only write operations, keeping the legacy service layer decoupled from the full ACME module.
- The returned `path_identifier` is used downstream to identify the enrollment record uniquely.
