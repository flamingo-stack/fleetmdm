Defines the core data structures and helper methods for managing calendar events within the Fleet MDM platform, including event persistence, webhook status tracking, and host-policy associations.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `CalendarEvent` | Core event entity with UUID, email, time range, raw JSON data, and optional timezone |
| `CalendarEventDetails` | Extends `CalendarEvent` with `TeamID` and `HostID` for database join queries |
| `HostCalendarEvent` | Join record linking a host to a calendar event with a webhook delivery status |
| `CalendarWebhookStatus` | Integer enum tracking webhook lifecycle (`None`, `Pending`, `Sent`, `Error`, `Retry`) |
| `HostPolicyMembershipData` | Flat projection used to query which hosts/emails are failing policies |

### Methods on `CalendarEvent`

| Method | Description |
|--------|-------------|
| `GetBodyTag()` | Extracts the `body_tag` field from the raw JSON `Data` blob; returns `""` on failure |
| `SaveDataItems(keysAndValues ...string)` | Merges key-value pairs into the JSON `Data` blob; requires an even number of arguments |

## Usage Example

```go
// Create a calendar event and persist arbitrary metadata
event := &fleet.CalendarEvent{
    Email:     "user@example.com",
    StartTime: time.Now(),
    EndTime:   time.Now().Add(time.Hour),
}

// Merge multiple keys in a single call
if err := event.SaveDataItems(
    "body_tag", "maintenance-window-2024",
    "reason",   "patch-tuesday",
); err != nil {
    log.Fatal(err)
}

// Retrieve a specific field from the stored blob
tag := event.GetBodyTag() // "maintenance-window-2024"

// Check webhook delivery state
hce := &fleet.HostCalendarEvent{
    HostID:          42,
    CalendarEventID: event.ID,
    WebhookStatus:   fleet.CalendarWebhookStatusPending,
}
```
