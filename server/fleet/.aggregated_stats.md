Defines the `AggregatedStatsType` string type and its associated constants for categorizing aggregated statistics within the Fleet data model.

## Key Components

- **`AggregatedStatsType`** — A named `string` type used to represent the category of an aggregated statistic.
- **`AggregatedStatsTypeScheduledQuery`** — A constant of value `"scheduled_query"` identifying aggregated stats that belong to scheduled queries.

## Usage Example

```go
var statsType fleet.AggregatedStatsType = fleet.AggregatedStatsTypeScheduledQuery

switch statsType {
case fleet.AggregatedStatsTypeScheduledQuery:
    fmt.Println("Processing scheduled query stats")
}
```
