Defines the `NudgeConfig` struct and constructor for generating [Nudge](https://github.com/macadmins/nudge/wiki) macOS update enforcement configurations from Fleet's `AppleOSUpdateSettings`.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `NudgeConfig` | struct | Top-level Nudge JSON config with OS requirements, UI, and UX settings |
| `nudgeOSVersionRequirements` | struct | Minimum OS version and installation deadline |
| `nudgeUserInterface` | struct | Simple mode toggle, deferral count visibility, and localized button/header text |
| `nudgeUserExperience` | struct | Refresh cycle intervals (in seconds) for each urgency phase |
| `nudgeAboutUpdateURLs` | struct | Localized "About Update" URL per language |
| `nudgeUpdateElements` | struct | Localized UI strings (action button, main header) per language |
| `NewNudgeConfig` | func | Constructs a `*NudgeConfig` from `AppleOSUpdateSettings`; parses the deadline and applies opinionated refresh cycle defaults |

## Usage Example

```go
settings := AppleOSUpdateSettings{
    Deadline:       optjson.SetString("2024-09-01"),
    MinimumVersion: optjson.SetString("14.6.1"),
}

cfg, err := NewNudgeConfig(settings)
if err != nil {
    log.Fatal(err)
}

// cfg.OSVersionRequirements[0].RequiredInstallationDate
// → 2024-09-01T20:00:00Z (noon PST / 20:00 UTC)
```

## Refresh Cycle Defaults

| Phase | Interval |
|---|---|
| Initial | 86400 s (24 h) |
| Approaching (≤72 h to deadline) | 86400 s (24 h) |
| Imminent (≤24 h to deadline) | 7200 s (2 h) |
| Elapsed (past deadline) | 3600 s (1 h) |

## Notes

- Deadlines are normalized to **20:00 UTC** (noon PST, DST-unadjusted) for compatibility with older `fleetd` versions that cannot handle local-time deadlines. See [fleet#23320](https://github.com/fleetdm/fleet/pull/23320).
- macOS 14+ uses DDM for deadline enforcement; Nudge config is retained for legacy `fleetd` compatibility.
- Source: [`nudge.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/nudge.go)
