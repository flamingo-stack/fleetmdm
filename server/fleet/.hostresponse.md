Response structs and constructor functions for converting `Host` and `HostDetail` models into API/CSV-ready representations with computed fields like online status, display text, and geolocation.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `HostResponse` | Embeds `*Host` and adds computed fields: `Status`, `DisplayText`, `DisplayName`, `Labels`, `Geolocation`, and CSV-specific aliases (`FleetID`, `FleetName`, `CSVDeviceMapping`) |
| `HostDetailResponse` | Embeds `HostDetail` and adds the same computed display/status fields for detailed host views |

### Functions

| Function | Description |
|----------|-------------|
| `HostResponseForHost` | Builds a full `HostResponse` including geolocation lookup via `svc.LookupGeoIP` |
| `HostResponseForHostCheap` | Builds a `HostResponse` without geolocation (cheaper, no external call) |
| `HostResponsesForHostsCheap` | Batch variant of `HostResponseForHostCheap` for a slice of `Host` values |

## Usage Example

```go
// With geolocation (more expensive - requires service/context)
hr := fleet.HostResponseForHost(ctx, svc, host)

// Without geolocation (preferred for list endpoints)
hr := fleet.HostResponseForHostCheap(host)

// Batch conversion for list responses
hrs := fleet.HostResponsesForHostsCheap(hosts)
```

## Notes

- `FleetID` and `FleetName` are CSV-only alias fields tagged `json:"-"`, intended as a temporary workaround pending a Fleet 5 cleanup.
- `HostResponseForHostCheap` sets `Status` via `host.Status(time.Now())` and `DisplayText` from `host.Hostname` — avoiding any I/O or service calls, making it safe for high-volume list endpoints.
