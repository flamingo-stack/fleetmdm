Utility functions for Fleet package operations including license banner display, JSON decoding, string preprocessing, and semantic version comparison.

## Key Components

| Function | Description |
|---|---|
| `WriteExpiredLicenseBanner` | Writes a bold red warning banner when a Fleet Premium license is near expiry |
| `WriteAppleBMTermsExpiredBanner` | Writes a warning banner when Apple Business Manager terms need re-acceptance |
| `JSONStrictDecode` | Strict JSON unmarshaling that rejects unknown fields and trailing bytes |
| `Preprocess` | Trims whitespace and normalizes Unicode characters (NFC form) |
| `CompareVersions` | Semantic version comparison returning `-1`, `0`, or `+1`; treats invalid versions as less than valid ones |
| `IsAtLeastVersion` | Returns `true` if `currentVersion` meets or exceeds `minimumVersion` |
| `VersionToSemverVersion` | Converts a version string to a `*semver.Version`, stripping macOS Rapid Security Response suffixes (e.g., `13.3.1 (a)` → `13.3.1`) |

## Usage Example

```go
// Strict JSON decoding
var cfg MyConfig
if err := fleet.JSONStrictDecode(r, &cfg); err != nil {
    log.Fatal(err)
}

// Version comparison
if fleet.IsAtLeastVersion("14.1 (a)", "13.6") {
    fmt.Println("Host is on a supported OS version")
}

result := fleet.CompareVersions("13.3.1 (a)", "13.3.2")
// result == -1

// Unicode-safe string preprocessing
normalized := fleet.Preprocess("  héllo wörld  ")

// Write license warning to stderr
fleet.WriteExpiredLicenseBanner(os.Stderr)
```
