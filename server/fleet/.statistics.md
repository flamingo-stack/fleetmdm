Defines the data structures and constants for Fleet's anonymous usage statistics telemetry payload, used to periodically report deployment metrics back to Fleet.

## Key Components

### `StatisticsPayload`
The primary struct serialized as JSON and transmitted as the telemetry payload. Key field groups include:

- **Instance metadata** — `AnonymousIdentifier`, `FleetVersion`, `LicenseTier`, `Organization`
- **Host counts** — enrolled hosts, ABM-pending hosts, hosts by OS/orbit/osquery version, Fleet Desktop, non-responding hosts
- **Feature flags** — MDM (macOS/Windows), software inventory, vulnerability detection, live query, AI features, GitOps mode, conditional access
- **Software metrics** — versions, titles, CPEs, CVEs, installed paths
- **Policy violation tracking** — weekly actual vs. possible violation day aggregates
- **Integration status** — Google Calendar maintenance windows, Okta/Entra conditional access, GitOps exceptions
- **Fleet-maintained apps** — slugs in use on macOS and Windows (`omitempty`)

### Supporting Structs

| Struct | Purpose |
|---|---|
| `HostsCountByOrbitVersion` | Host count grouped by orbit agent version |
| `HostsCountByOsqueryVersion` | Host count grouped by osquery version |
| `HostsCountByOSVersion` | Host count grouped by OS version string |

### `StatisticsFrequency`
```go
const StatisticsFrequency = time.Hour * 1
```
Controls how often statistics are collected and transmitted (every 1 hour).

## Usage Example

```go
payload := fleet.StatisticsPayload{
    AnonymousIdentifier:      "abc123",
    FleetVersion:             "4.50.0",
    LicenseTier:              "premium",
    NumHostsEnrolled:         1200,
    SoftwareInventoryEnabled: true,
    MDMMacOsEnabled:          true,
    HostsEnrolledByOperatingSystem: map[string][]fleet.HostsCountByOSVersion{
        "macOS": {{Version: "14.4", NumEnrolled: 800}},
    },
    HostsEnrolledByOrbitVersion: []fleet.HostsCountByOrbitVersion{
        {OrbitVersion: "1.22.0", NumHosts: 1200},
    },
}

data, err := json.Marshal(payload)
```
