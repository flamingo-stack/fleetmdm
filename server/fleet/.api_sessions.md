Defines request and response types for user authentication session management, specifically for login and logout API endpoints.

## Key Components

| Type | Description |
|------|-------------|
| `LoginRequest` | Payload for authenticating a user via email/password |
| `LoginResponse` | Response returned after successful login, including user info and session token |
| `LogoutResponse` | Response returned after a logout operation |

### `LoginRequest` Fields

- **`Email`** / **`Password`** — Standard credentials for authentication
- **`SupportsEmailVerification`** — Controls MFA email flow behavior. When `false` or omitted, users requiring email-based MFA (Fleet MFA) will receive a login error rather than triggering an MFA email. This is important for CLI/API contexts where a browser-redirect MFA flow is not appropriate.

### `LoginResponse` Fields

- **`User`** — Authenticated user object
- **`AvailableTeams`** — List of teams the user has access to (serialized as `available_fleets`)
- **`Token`** — Session/API token for subsequent authenticated requests
- **`TokenExpiresAt`** — Optional token expiration timestamp

Both `LoginResponse` and `LogoutResponse` implement an `Error() error` method to satisfy response error-handling interfaces.

## Usage Example

```go
req := fleet.LoginRequest{
    Email:                     "admin@example.com",
    Password:                  "s3cr3t",
    SupportsEmailVerification: false,
}

// After decoding the API response:
var resp fleet.LoginResponse
// resp.Token contains the session token for subsequent requests
// resp.AvailableTeams lists teams accessible to the authenticated user
if err := resp.Error(); err != nil {
    log.Fatalf("login failed: %v", err)
}
```
