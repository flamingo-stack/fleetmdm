Defines the core data structures, constants, and utility functions for Fleet team management, including team roles, configurations, payloads, and JSON serialization logic.

## Key Components

### Constants
- **Role constants**: `RoleAdmin`, `RoleMaintainer`, `RoleObserver`, `RoleObserverPlus`, `RoleGitOps`, `RoleTechnician`
- **Reserved names**: `TeamNameNoTeam`, `TeamNameAllTeams`, `ReservedNameAllTeams`, `ReservedNameNoTeam`
- **Display names**: `DisplayNameNoTeam` (`"Unassigned"`), `DisplayNameAllTeams` (`"All fleets"`)

### Functions
- **`IsReservedTeamName(name string) bool`** — Case-insensitive check (NFC-normalized) against all reserved/display team names

### Core Types
- **`Team`** — Primary team entity with DB fields, JOINed counts, users, hosts, and secrets; implements custom `MarshalJSON`/`UnmarshalJSON`
- **`TeamLite`** — Lightweight team subset containing only columns from the `teams` table (no JOIN-derived fields)
- **`TeamConfig`** — Full team configuration including agent options, MDM, webhooks, integrations, features, scripts, and software
- **`TeamConfigLite`** — Config subset available directly from the `teams.config` JSON column
- **`TeamPayload`** — Request payload for team creation/modification (pointer fields enable partial updates)
- **`TeamPayloadMDM`** — MDM-specific payload using `optjson.Bool` to distinguish omitted vs. explicitly-set fields
- **`TeamPayloadFeatures`** / **`HistoricalDataPayload`** — Partial-PATCH feature settings for the REST endpoint
- **`DefaultTeam`** — Limited team info returned for team ID `0` (no-team context)

## Usage Example

```go
// Check if a name is reserved before creating a team
if fleet.IsReservedTeamName("No Team") {
    return errors.New("cannot use a reserved team name")
}

// Build a modify-team payload (only set fields are applied)
payload := fleet.TeamPayload{
    Name:        ptr.String("Engineering"),
    Description: ptr.String("Engineering team"),
    MDM: &fleet.TeamPayloadMDM{
        EnableDiskEncryption: optjson.SetBool(true),
    },
}

// Convert full Team to lightweight form for list responses
teamLite := team.ToTeamLite()
```

> **Note:** `Team` implements `sql.Scanner`/`driver.Valuer` via `TeamConfig` for database serialization, and custom JSON marshal/unmarshal to inline `TeamConfig` fields while avoiding sqlx scanning conflicts.
