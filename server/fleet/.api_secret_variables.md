Defines HTTP request/response types for the secret variables API, covering create (batch and single), list, and delete operations.

## Key Components

| Type | Description |
|------|-------------|
| `CreateSecretVariablesRequest` | Batch create payload with `dry_run` support and a slice of `SecretVariable` |
| `CreateSecretVariablesResponse` | Response for batch create; surfaces errors via `Error()` |
| `CreateSecretVariableRequest` | Single secret variable payload with `name` and `value` |
| `CreateSecretVariableResponse` | Returns the created variable's `ID` and `Name` |
| `ListSecretVariablesRequest` | Wraps `ListOptions` for paginated listing |
| `ListSecretVariablesResponse` | Returns identifiers, pagination metadata, and count |
| `DeleteSecretVariableRequest` | Identifies the target variable by `ID` via URL param |
| `DeleteSecretVariableResponse` | Surfaces delete errors via `Error()` |

All response types implement the `Error() error` method for consistent error propagation across the transport layer.

## Usage Example

```go
// Batch create with dry run
req := fleet.CreateSecretVariablesRequest{
    DryRun: true,
    SecretVariables: []fleet.SecretVariable{
        {Name: "API_KEY", Value: "abc123"},
    },
}

// Single create
createReq := fleet.CreateSecretVariableRequest{
    Name:  "DB_PASSWORD",
    Value: "s3cr3t",
}

// List with pagination
listReq := fleet.ListSecretVariablesRequest{
    ListOptions: fleet.ListOptions{Page: 0, PerPage: 20},
}

// Delete by ID
deleteReq := fleet.DeleteSecretVariableRequest{ID: 42}
```
