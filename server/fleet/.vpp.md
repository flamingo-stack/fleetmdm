Handles VPP (Volume Purchase Program) app management types and validation logic for Apple MDM integration, defining data structures for App Store apps, install tracking, client user lifecycle management, and configuration validation.

## Key Components

### Core Types

| Type | Description |
|------|-------------|
| `VPPAppID` | Identifies a VPP app by Adam ID and platform |
| `VPPAppTeam` | Extends `VPPAppID` with team-scoped metadata (labels, self-service, auto-install policy) |
| `VPPApp` | Full VPP app record including bundle identifier, icon URL, and version |
| `VPPAppStoreApp` | Lightweight representation for the software title endpoint |
| `VPPAppStatusSummary` | Aggregated install status counts (installed/pending/failed) |
| `VPPClientUser` | Maps a VPP token to a Managed Apple ID and Fleet-generated `clientUserId` |

### Install Tracking

| Type | Description |
|------|-------------|
| `HostVPPSoftwareInstall` | Full install attempt record with command UUID, status, and retry count |
| `HostVPPSoftwareInstallLite` | Minimal install record for lightweight lookups |
| `HostAndroidVPPSoftwareInstall` | Android-specific install record for setup experience |

### Constants & Enums

- `VPPClientUserStatus` — `pending`, `registered`, `retired`
- `DefaultVPPInstallVerifyTimeout` — 10 minutes
- `DefaultVPPVerifyRequestDelay` — 5 seconds

### Validation

- `FleetVarsSupportedInAppleAppConfig` — allowlist of Fleet variables permitted in iOS/iPadOS managed app configuration plists
- `ValidateAppleAppConfiguration(config []byte) error` — validates that a managed app configuration plist has a `<dict>` root element and only uses supported Fleet variable tokens

## Usage Example

```go
// Identify a VPP app
appID := fleet.VPPAppID{
    AdamID:   "361285480",
    Platform: fleet.IOSPlatform,
}

// Check platform string representation
fmt.Println(appID.String()) // "361285480_ios"

// Validate an iOS managed app configuration plist
config := []byte(`<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" ...>
<plist version="1.0">
  <dict>
    <key>UserEmail</key>
    <string>$FLEET_VAR_HOST_END_USER_EMAIL_IDP</string>
  </dict>
</plist>`)

if err := fleet.ValidateAppleAppConfiguration(config); err != nil {
    log.Fatalf("invalid app configuration: %v", err)
}
```
