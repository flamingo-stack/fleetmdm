Defines authorization types and constants for Fleet's Okta-based conditional access IdP (Identity Provider) integration, including resource identifiers used in MDM profile delivery and certificate management.

## Key Components

### Types

- **`ConditionalAccessIDPAssets`** — Empty struct implementing `authz.AuthzTyper`; represents the authorization resource for downloading Okta IdP assets (signing certificates, Apple profiles). Returns `"conditional_access_idp_assets"` from `AuthzType()`.
- **`OktaCACleanupTarget`** — Holds the host ID and macOS short username needed to target the keychain-cleanup script after a successful Okta CA profile installation acknowledgment.

### Constants

- **`ConditionalAccessOktaProfileIdentifier`** — `"com.fleetdm.conditional-access-okta"`: The `PayloadIdentifier` of the `.mobileconfig` profile for Okta conditional access. Also stored in `host_mdm_apple_profiles.profile_identifier` and used to detect when an `InstallProfile` acknowledgment belongs to the Okta CA profile.
- **`ConditionalAccessOktaCertificateCN`** — `"Fleet conditional access for Okta"`: The Subject Common Name of the SCEP certificate issued for Okta conditional access, used by the duplicate-certificate cleanup script to locate matching keychain entries.

## Usage Example

```go
// Authorization check for Okta IdP assets
resource := &fleet.ConditionalAccessIDPAssets{}
authzType := resource.AuthzType() // "conditional_access_idp_assets"

// Detect Okta CA profile acknowledgment
if profile.ProfileIdentifier == fleet.ConditionalAccessOktaProfileIdentifier {
    target := fleet.OktaCACleanupTarget{
        HostID:        host.ID,
        UserShortName: host.PrimaryUsername,
    }
    runKeychainCleanup(target)
}

// Match SCEP certificate by CN during cleanup
if cert.Subject.CommonName == fleet.ConditionalAccessOktaCertificateCN {
    removeFromKeychain(cert)
}
```
