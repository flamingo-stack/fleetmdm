Defines data models and helper functions for managing host TLS/X.509 certificates in Fleet, supporting ingestion from both osquery and Apple MDM sources.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `HostCertificateSource` | type | Enum distinguishing `system` vs `user` certificate ownership |
| `HostCertificateOrigin` | type | Internal enum scoping deletion semantics: `osquery` or `mdm` |
| `HostCertificateRecord` | struct | Database model for a host certificate row, including validity window, subject/issuer DN fields, and soft-delete timestamp |
| `HostCertificatePayload` | struct | JSON-serialisable API response model for certificate data |
| `HostCertificateNameDetails` | struct | Nested payload for subject/issuer distinguished name fields |
| `MDMAppleCertificateListResponse` | struct | Plist model for the Apple MDM `CertificateList` command response |
| `MDMAppleCertificateListItem` | struct | Single DER-encoded certificate entry from an MDM response, with a `Parse` method |
| `MDMAppleErrorChainItem` | struct | Plist model for MDM error chain entries |
| `NewHostCertificateRecord` | func | Constructs a `HostCertificateRecord` from a host ID and a parsed `*x509.Certificate`, computing its SHA-1 fingerprint |
| `(*HostCertificateRecord).ToPayload` | method | Converts a database record into a `HostCertificatePayload` for API responses |
| `ExtractDetailsFromOsqueryDistinguishedName` | func | Dispatches DN parsing to platform-specific parsers (`windows`, `darwin`/`macos`) |

## Usage Example

```go
// Parse a DER-encoded certificate and create a Fleet record
cert, err := x509.ParseCertificate(derBytes)
if err != nil {
    return err
}
record := fleet.NewHostCertificateRecord(hostID, cert)
record.Origin = fleet.HostCertificateOriginMDM

// Convert to API payload
payload := record.ToPayload()
// payload.Subject.CommonName, payload.Serial, etc. are now populated

// Parse an Apple MDM CertificateList item directly
item := fleet.MDMAppleCertificateListItem{Data: derBytes}
record, err = item.Parse(hostID)

// Extract subject details from an osquery-formatted DN
details, err := fleet.ExtractDetailsFromOsqueryDistinguishedName(
    "darwin",
    "/C=US/O=Fleet Device Management Inc./CN=FleetDM",
)
```

## Notes

- SHA-1 is used intentionally for compatibility with the osquery `certificates` table schema (suppressed via `nolint:gosec`).
- `Origin` scopes soft-delete semantics: an osquery sync will not remove MDM-only certificates and vice versa.
- Several fields (`KeyStrength`, `KeyUsage`, `CommonName` methodology) have open TODOs to align behaviour with osquery's OpenSSL-based computation.
