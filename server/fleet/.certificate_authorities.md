Defines core types, constants, and payload structures for managing Certificate Authorities (CAs) in Fleet MDM, including DigiCert, NDES SCEP Proxy, Custom SCEP, Hydrant, EST Proxy, and Smallstep integrations.

## Key Components

### Type Constants

- **`CAConfigAssetType`** — Legacy CA asset type identifiers (`ndes`, `digicert`, `custom_scep_proxy`, `smallstep`)
- **`CAType`** — Current CA type identifiers (`ndes_scep_proxy`, `digicert`, `custom_scep_proxy`, `hydrant`, `custom_est_proxy`, `smallstep`)

### Core Structs

| Struct | Purpose |
|---|---|
| `CertificateAuthority` | Full CA record with all provider fields and DB mappings |
| `CertificateAuthoritySummary` | Lightweight CA listing (ID, Name, Type) |
| `CertificateAuthorityPayload` | Union payload for creating any CA type |
| `CertificateAuthorityUpdatePayload` | Union payload for updating any CA type |
| `CAConfigAsset` | Raw DB asset row (name, value, type) |

### CA-Specific Structs

- **`DigiCertCA`** — API token, profile ID, UPN, seat ID fields; includes `Equals` and `Preprocess`
- **`NDESSCEPProxyCA`** — NDES SCEP with admin URL and credentials
- **`CustomSCEPProxyCA`** — Custom SCEP with challenge secret; includes `Equals`
- **`HydrantCA`** — OAuth2-style CA with client ID/secret; includes `Equals`, `NeedToVerify`
- **`ESTProxyCA`** — EST (Enrollment over Secure Transport) with username/password; includes `NeedToVerify`
- **`SmallstepSCEPProxyCA`** — Smallstep with challenge URL

### Key Functions

- **`ListCATypesWithRenewalSupport()`** — Returns CA types Fleet can auto-renew certificates for
- **`ListCATypesWithRenewalIDSupport()`** — Returns CA types requiring renewal ID embedding in profiles
- **`CAConfigAssetType.SupportsRenewalID()`** — Boolean check for renewal ID support
- **`CertificateAuthorityUpdatePayload.ValidatePayload()`** — Enforces exactly one CA type per update request and requires a private key
- **`CAConfigAssetType.Scan()`** — SQL `NULL`-safe scanner; maps `NULL` to empty string sentinel

### Interface

- **`SCEPConfigService`** — Defines validation and challenge-fetching operations for NDES and Smallstep SCEP proxies

## Usage Example

```go
// Check renewal support before triggering renewal
caType := CAConfigAssetType("ndes")
if caType.SupportsRenewalID() {
    // embed renewal ID into the MDM profile
}

// Validate an update request
payload := &CertificateAuthorityUpdatePayload{
    DigiCertCAUpdatePayload: &DigiCertCAUpdatePayload{
        APIToken: ptr("new-token"),
        URL:      ptr("https://certcentral.digicert.com"),
    },
}
if err := payload.ValidatePayload(privateKey, "update CA: "); err != nil {
    // returns BadRequestError if no CA or multiple CAs specified,
    // or if private key is missing
}

// Compare two DigiCert configs to detect changes
existing := &DigiCertCA{Name: "prod", APIToken: "tok1", ProfileID: "p1"}
incoming := &DigiCertCA{Name: "prod", APIToken: "tok2", ProfileID: "p1"}
if !existing.Equals(incoming) {
    // re-verify and update
}
```
