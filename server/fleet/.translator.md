Defines translation payload types for converting string-based identifiers (email, label, team, host) to their corresponding numeric IDs within the Fleet package.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `TranslatorTypeUserEmail` | `"user"` | Identifies a user email translation |
| `TranslatorTypeLabel` | `"label"` | Identifies a label translation |
| `TranslatorTypeTeam` | `"team"` | Identifies a team translation |
| `TranslatorTypeHost` | `"host"` | Identifies a host translation |

### Types

- **`TranslatePayload`** — Top-level request body carrying a translator type and its associated payload.
- **`StringIdentifierToIDPayload`** — Holds the human-readable `Identifier` string and the resolved numeric `ID`.

## Usage Example

```go
payload := fleet.TranslatePayload{
    Type: fleet.TranslatorTypeUserEmail,
    Payload: fleet.StringIdentifierToIDPayload{
        Identifier: "alice@example.com",
        ID:         0, // populated by the translation service
    },
}

data, err := json.Marshal(payload)
if err != nil {
    log.Fatal(err)
}
// POST data to the translation endpoint;
// the response will include the resolved numeric ID.
```

## Notes

- The `Type` field drives which resolver handles the translation (user, label, team, or host).
- `ID` is typically zero on input and populated by the server after resolving the `Identifier`.
