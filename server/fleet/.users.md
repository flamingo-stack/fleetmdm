Defines the core `User` domain model and related types for Fleet's user management system, including authentication, role assignment, team membership, and payload validation.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `User` | struct | Primary user model with authentication fields, SSO/MFA flags, global role, and team memberships |
| `UserSummary` | struct | Lightweight projection of `User` for list endpoints |
| `UserPayload` | struct | Request payload for create/modify operations |
| `UserTeam` | struct | Associates a `Team` with the role a user holds within it |
| `UserSettings` | struct | Per-user UI preferences (e.g. hidden host columns); implements `sql.Scanner` |
| `OptionalAPIEndpoints` | struct | Three-state JSON-nullable field for PATCH semantics (absent / null / array) |
| `APIEndpointRef` | struct | HTTP method + path pair describing a single API endpoint |
| `UserListOptions` | struct | Extends `ListOptions` with an optional `TeamID` filter |
| `ErrLastGlobalAdmin` | var | Sentinel error returned when an operation would remove the last global admin |
| `(p *UserPayload) VerifyAdminCreate` | method | Validates admin-initiated user creation payloads |
| `(p *UserPayload) VerifyInviteCreate` | method | Validates invite-flow user creation payloads |
| `(p *UserPayload) VerifyModify` | method | Validates user update payloads; enforces password requirements for self-edits |
| `(p UserPayload) User` | method | Constructs a `User` from a validated payload, hashing the password |
| `(u *User) IsGlobalObserver` | method | Returns `true` if the user holds the Observer or Observer+ global role |
| `(u *User) TeamMembership` | method | Returns a `map[uint]bool` of team IDs matching a predicate |
| `(u *User) IsAdminForcedPasswordReset` | method | Returns `true` when a non-SSO user has a forced password reset pending |

## Usage Example

```go
// Build and validate a new user from an admin-create request
payload := fleet.UserPayload{
    Name:       fleet.StringPtr("Alice Smith"),
    Email:      fleet.StringPtr("alice@example.com"),
    Password:   fleet.StringPtr("Str0ng!Pass"),
    GlobalRole: fleet.StringPtr(fleet.RoleAdmin),
}

if err := payload.VerifyAdminCreate(); err != nil {
    log.Fatal(err)
}

user, err := payload.User(server.DefaultKeySize, bcrypt.DefaultCost)
if err != nil {
    log.Fatal(err)
}

// Check team membership for maintainer role
maintainerTeams := user.TeamMembership(func(t fleet.UserTeam) bool {
    return t.Role == fleet.RoleMaintainer
})
```
