Defines request/response types for Fleet's script execution API endpoints, covering both synchronous and asynchronous script runs, saved script management, and batch execution operations.

## Key Components

| Type | Purpose |
|------|---------|
| `RunScriptRequest` / `RunScriptResponse` | Async script execution on a host; returns `202 Accepted` with an `execution_id` |
| `RunScriptSyncRequest` / `RunScriptSyncResponse` | Synchronous script execution; returns `408` on host timeout, `200` on success |
| `GetScriptResultRequest` / `GetScriptResultResponse` | Retrieve output, exit code, and metadata for a completed script run |
| `CreateScriptRequest` | Multipart file upload decoder for saving a new script; parses `fleet_id` and `script` form fields |
| `UpdateScriptRequest` | Multipart decoder for replacing an existing saved script by `script_id` |
| `DeleteScriptRequest` / `DeleteScriptResponse` | Remove a saved script; returns `204 No Content` |
| `ListScriptsRequest` / `ListScriptsResponse` | Paginated listing of saved scripts, optionally filtered by team |
| `GetScriptRequest` / `GetScriptResponse` | Fetch or download a saved script (supports `alt` query param) |
| `GetHostScriptDetailsRequest` / `GetHostScriptDetailsResponse` | Paginated script details for a specific host |
| `BatchSetScriptsRequest` / `BatchSetScriptsResponse` | Atomic replacement of all scripts for a team; supports `dry_run` validation |
| `BatchScriptExecutionStatusResponse` / `BatchScriptExecutionListResponse` | Status, listing, summary, host results, and cancellation for batch executions |

## Usage Example

```go
// Async run
req := fleet.RunScriptRequest{
    HostID:         42,
    ScriptContents: "echo hello",
}

// Sync run — check for host timeout
var syncResp fleet.RunScriptSyncResponse
if syncResp.HostTimeout {
    // HTTP 408 returned to caller
}

// Retrieve results
resultReq := fleet.GetScriptResultRequest{ExecutionID: "abc-123"}

// Batch set (dry run validation)
batchReq := fleet.BatchSetScriptsRequest{
    DryRun:  true,
    Scripts: []fleet.ScriptPayload{{...}},
}
```
