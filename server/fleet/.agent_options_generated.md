Auto-generated Go struct definitions mapping osquery 5.23.0 agent configuration flags to their JSON representations for use within the Fleet package.

## Key Components

### `osqueryOptions`
A struct representing the subset of osquery flags configurable as **agent options** (delivered via Fleet's remote configuration). Covers audit settings, AWS integrations, buffering, distributed query behavior, event handling, logging, scheduling, and more. Embeds four OS-specific structs:
- `OsqueryCommandLineFlagsLinux`
- `OsqueryCommandLineFlagsWindows`
- `OsqueryCommandLineFlagsMacOS`
- `OsqueryCommandLineFlagsHidden`

### `osqueryCommandLineFlags`
A broader struct capturing **all** osquery command-line flags, including ones not remotely configurable (e.g., `ConfigPath`, `DatabasePath`, `EnrollSecretPath`, `Daemonize`, `CarverBlockSize`). Used for validation and documentation purposes.

## Usage Example

These structs are consumed internally by Fleet's agent options validation pipeline. Direct instantiation is uncommon, but a typical use looks like:

```go
opts := fleet.osqueryOptions{
    DistributedInterval:     30,
    ScheduleSplayPercent:    10,
    LoggerTlsCompress:       true,
    DisableDistributed:      false,
}
```

To regenerate this file after an osquery version bump:

```bash
# Update osqueryVersion in tools/osquery-agent-options/main.go, then:
cd server/fleet/
go generate
```
