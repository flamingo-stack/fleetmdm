Defines the core data structures and validation logic for Fleet queries, including the `Query` and `QueryPayload` types used to create, modify, and schedule osquery queries on managed devices.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Query` | struct | Full query model with scheduling, logging, label scoping, and aggregated stats |
| `QueryPayload` | struct | Pointer-field payload for creating/modifying queries; supports partial updates |
| `TargetedQuery` | struct | Query with explicit `HostTargets` for live query execution |
| `LiveQueryStats` | struct | Per-host execution metrics (memory, CPU time, wall time, output size) |
| `QueryPayload.Verify()` | method | Validates name, SQL, logging type, platforms, and label scope exclusivity |
| `Query.Verify()` | method | Same validation used when applying queries via spec files |
| `Query.Clone()` / `Copy()` | methods | Deep-copy implementation including all pointer and slice fields |
| `Query.GetSnapshot()` / `GetRemoved()` | methods | Translate `Logging` string to osquery schedule booleans |
| `Query.ToQueryContent()` | method | Converts a `Query` into a `QueryContent` for schedule configuration |
| `Query.TeamIDStr()` | method | Returns team ID as a string (empty string when nil) |

**Logging constants:** `LoggingSnapshot`, `LoggingDifferential`, `LoggingDifferentialIgnoreRemovals`

## Usage Example

```go
// Build and validate a new scheduled query payload
payload := fleet.QueryPayload{
    Name:               ptr.String("disk-usage"),
    Query:              ptr.String("SELECT * FROM disk_info;"),
    Interval:           ptr.Uint(3600),
    Platform:           ptr.String("linux,darwin"),
    Logging:            ptr.String(fleet.LoggingSnapshot),
    AutomationsEnabled: ptr.Bool(true),
    DiscardData:        ptr.Bool(false),
    LabelsIncludeAny:   []string{"production-servers"},
}

if err := payload.Verify(); err != nil {
    log.Fatalf("invalid query payload: %v", err)
}

// Deep-copy an existing query
cloned, err := existingQuery.Clone()

// Convert to schedule-ready content
content := existingQuery.ToQueryContent()
```

> **OpenFrame extension:** `Query` includes a `HostsIncludeAny []HostIdent` field for direct host targeting, documented in [`openframe/docs/architecture-host-assignments.md`](https://github.com/flamingo-stack/fleetmdm/blob/main/openframe/docs/architecture-host-assignments.md).
