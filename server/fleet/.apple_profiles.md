Provides utility types and functions for managing Apple MDM profile installation and removal operations across host enrollments.

## Key Components

### Types

- **`CmdTarget`** — Represents a batched MDM command target, grouping a command UUID, profile identifier/name, and a list of enrollment IDs that will receive the same command.
- **`HostProfileUUID`** — Composite key pairing a host UUID with a profile UUID, used as a map key for profile lookup operations.

### Functions

- **`FindProfilesWithSecrets`** — Scans a set of install targets and their raw mobileconfig contents to identify which profiles contain server secret prefix variables. Returns a set of profile UUIDs that contain secrets.
- **`MarkProfilesFailed`** — Marks all host profiles in a `CmdTarget` as `MDMDeliveryFailed` with a given detail string, then bulk-upserts the updated records via the datastore. Handles user-channel enrollments by resolving enrollment IDs back to host UUIDs.
- **`GetHostProfileToInstallByEnrollmentID`** — Looks up a host profile payload by enrollment ID and profile UUID. Falls back to a user enrollment → host UUID mapping for user-channel MDM enrollments.

## Usage Example

```go
// Look up a profile for a specific enrollment
profile, ok := fleet.GetHostProfileToInstallByEnrollmentID(
    hostProfilesToInstallMap,
    userEnrollmentsToHostUUIDsMap,
    "enrollment-abc-123",
    "profile-uuid-xyz",
)
if !ok {
    log.Println("profile not found")
}

// Identify profiles containing secrets before sending commands
profilesWithSecrets, err := fleet.FindProfilesWithSecrets(
    ctx, logger, installTargets, profileContents,
)
```
