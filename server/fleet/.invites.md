Defines the data structures for managing user invitations in the Fleet platform, including payload validation and invite representation.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `InvitePayload` | struct | Request body for creating or updating a user invite |
| `Invite` | struct | Represents a persisted invitation record with metadata |
| `AuthzType()` | method | Returns `"invite"` for authorization policy enforcement |

## Fields of Note

- **`GlobalRole`** — Uses `null.String` to distinguish between "no role set" and an empty string, supporting nullable DB values.
- **`Teams`** — A slice of `UserTeam` enabling team-scoped invites; tagged with `renameto:"fleets"` for legacy compatibility.
- **`Token`** — Excluded from JSON serialization (`json:"-"`) to prevent exposure in API responses.
- **`SSOEnabled` / `MFAEnabled`** — Boolean flags controlling authentication method for the invited user.

## Usage Example

```go
// Build an invite payload
email := "newuser@example.com"
name := "Jane Doe"
role := null.StringFrom("admin")

payload := fleet.InvitePayload{
    Email:      &email,
    Name:       &name,
    GlobalRole: role,
    SSOEnabled: boolPtr(false),
    MFAEnabled: boolPtr(true),
    Teams:      []fleet.UserTeam{},
}

// Check the authz type of an existing invite
invite := fleet.Invite{Email: "newuser@example.com"}
fmt.Println(invite.AuthzType()) // Output: invite
```
