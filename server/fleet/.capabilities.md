Defines the capability negotiation system used by Fleet components (server, Orbit, Fleet Desktop) to advertise and discover supported features via HTTP headers.

## Key Components

**Types**
- `Capability` — string type representing a named feature flag
- `CapabilityMap` — thread-safe set of capabilities (`map[Capability]struct{}`)

**Methods on `CapabilityMap`**
- `PopulateFromString(s string)` — parses a comma-separated capability list into the map
- `String() string` — serializes the map back to a comma-separated string
- `Has(capability Capability) bool` — checks if a specific capability is present
- `Copy(from CapabilityMap)` — merges capabilities from another map

**Capability Constructors**
- `GetServerOrbitCapabilities()` — returns capabilities advertised by the server to Orbit clients
- `GetServerDeviceCapabilities()` — returns capabilities advertised to device clients (conditionally includes `CapabilityErrorReporting` via `FLEET_ENABLE_POST_CLIENT_DEBUG_ERRORS=1`)
- `GetOrbitClientCapabilities()` — returns capabilities advertised by the Orbit client, varying by OS (macOS excludes `CapabilityEndUserAuth`; Windows adds `CapabilityWindowsMDMSync`)

**Defined Capabilities**

| Constant | Value | Description |
|---|---|---|
| `CapabilityOrbitEndpoints` | `orbit_endpoints` | Orbit-specific API endpoints |
| `CapabilityTokenRotation` | `token_rotation` | Periodic device token rotation |
| `CapabilityErrorReporting` | `error_reporting` | Client debug error posting |
| `CapabilityEndUserEmail` | `end_user_email` | End-user email from Orbit |
| `CapabilityEscrowBuddy` | `escrow_buddy` | FileVault key rotation |
| `CapabilityLinuxDiskEncryptionEscrow` | `linux_disk_encryption_escrow` | LUKS passphrase escrow |
| `CapabilitySetupExperience` | `setup_experience` | macOS ADE enrollment flow |
| `CapabilityWebSetupExperience` | `web_setup_experience` | Linux/Windows setup experience |
| `CapabilityMacOSWebSetupExperience` | `macos_web_setup_experience` | macOS web-based setup UI |
| `CapabilityEndUserAuth` | `end_user_auth` | SSO enrollment authentication |
| `CapabilityWindowsMDMSync` | `windows_mdm_sync` | On-demand OMA-DM session trigger |

**Constants**
- `CapabilitiesHeader = "X-Fleet-Capabilities"` — HTTP header name used for capability exchange

## Usage Example

```go
// Server advertising capabilities to an Orbit client
caps := fleet.GetServerOrbitCapabilities()
w.Header().Set(fleet.CapabilitiesHeader, caps.String())
// → "orbit_endpoints,token_rotation,escrow_buddy,..."

// Orbit client reading server capabilities from a response
var serverCaps fleet.CapabilityMap
serverCaps.PopulateFromString(resp.Header.Get(fleet.CapabilitiesHeader))

if serverCaps.Has(fleet.CapabilitySetupExperience) {
    // Enable setup experience flow
}

// Orbit client advertising its own capabilities
clientCaps := fleet.GetOrbitClientCapabilities()
req.Header.Set(fleet.CapabilitiesHeader, clientCaps.String())
```
