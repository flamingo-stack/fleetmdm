Core service interface definitions for the Fleet MDM platform, defining the primary `Service` interface and supporting interfaces that compose the full set of Fleet operations including osquery management, user administration, host management, MDM, SSO, and enterprise feature overrides.

## Key Components

| Component | Description |
|---|---|
| `Service` | Primary interface composing all Fleet service capabilities |
| `OsqueryService` | Osquery agent enrollment, authentication, query distribution, and log submission |
| `EnterpriseOverrides` | Struct of function fields allowing enterprise implementations to override specific service behaviors |
| `UserLookupService` | Minimal interface for user lookup operations |
| `HostLookupService` | Minimal interface for basic host information retrieval |
| `LookupService` | Composite of `UserLookupService` and `HostLookupService` |
| `ActivityLookupService` | Extends `LookupService` with activity webhook settings and host activity management |

## Key Interface Methods (Service)

- **Osquery:** `EnrollOsquery`, `AuthenticateHost`, `GetDistributedQueries`, `SubmitDistributedQueryResults`
- **Orbit/Fleet Desktop:** `EnrollOrbit`, `AuthenticateOrbitHost`, `GetOrbitConfig`, `GetFleetDesktopSummary`
- **Users:** `CreateUser`, `ModifyUser`, `DeleteUser`, `ChangePassword`, `ResetPassword`
- **Sessions/SSO:** `InitiateSSO`, `InitiateMDMSSO`, `InitSSOCallback`
- **Enterprise:** `SetEnterpriseOverrides`

## Usage Example

```go
// Implementing a minimal service that satisfies LookupService
type myLookup struct{}

func (m *myLookup) ListUsers(ctx context.Context, opt fleet.UserListOptions) ([]*fleet.User, error) {
    // return users from datastore
}

func (m *myLookup) UsersByIDs(ctx context.Context, ids []uint) ([]*fleet.UserSummary, error) {
    // return user summaries
}

func (m *myLookup) GetHostLite(ctx context.Context, id uint) (*fleet.Host, error) {
    // return basic host info
}

// Registering enterprise overrides
svc.SetEnterpriseOverrides(fleet.EnterpriseOverrides{
    MDMAppleSyncDEPProfiles: func(ctx context.Context) error {
        return eeSvc.SyncDEPProfiles(ctx)
    },
})
```
