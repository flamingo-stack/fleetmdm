Shell variable parsing and expansion utilities for Fleet server configuration, providing prefix-based variable scanning, conditional expansion, and shell-syntax variable detection.

## Key Components

| Function/Constant | Description |
|---|---|
| `ServerVarPrefix` | Constant `"FLEET_VAR_"` — prefix for Fleet server-scoped environment variables |
| `ContainsPrefixVars(text, prefix)` | Scans text for `$VAR`/`${VAR}` references matching a given prefix; returns variable names with prefix stripped |
| `ContainsVar(text, variableName)` | Returns `true` if text references a specific named shell variable |
| `MaybeExpand(s, mapping)` | Conditionally expands `$VAR`/`${VAR}` references; the mapper controls whether each variable is replaced or left unchanged |
| `getShellName(s)` | Internal parser that extracts a shell variable name and its byte width from a string |
| `isAlphaNum` / `isShellSpecialVar` | Byte-level character classification helpers used by the parser |

## Usage Example

```go
// Find all FLEET_VAR_ references in a query string
vars := fleet.ContainsPrefixVars("SELECT $FLEET_VAR_ORG_ID, $OTHER_VAR", fleet.ServerVarPrefix)
// vars == ["ORG_ID"]

// Check if a specific variable is referenced
found := fleet.ContainsVar("WHERE id = $device_id", "device_id")
// found == true

// Conditionally expand only known variables, leave others untouched
resolved := fleet.MaybeExpand("$FLEET_VAR_ORG_ID/$UNKNOWN", func(name string, start, end int) (string, bool) {
    if val, ok := knownVars[name]; ok {
        return val, true
    }
    return "", false // leaves $UNKNOWN as-is
})
```

## Notes

- `MaybeExpand` differs from `os.Expand` in two ways: invalid syntax (e.g. bare `$`) is preserved rather than consumed, and the mapper can opt out of replacement per-variable.
- All parsing operates on raw bytes since shell variable syntax (`$`, `{`, `}`) is pure ASCII.
