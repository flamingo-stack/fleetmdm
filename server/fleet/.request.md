Declares and centralizes all HTTP request body size limits used across Fleet's endpoint handlers, preventing oversized payloads from reaching application logic.

## Key Components

| Constant | Limit | Purpose |
|---|---|---|
| `MaxSpecSize` | 25 MiB | Spec file upload payloads |
| `MaxFleetdErrorReportSize` | 5 MiB | Fleetd agent error reports |
| `MaxScriptSize` | 1.5 MiB | Single script body (≈1 MiB content + Base64 overhead) |
| `MaxBatchScriptSize` | 25 MiB | Batch script upload payloads |
| `MaxProfileSize` | 1.5 MiB | Single MDM profile (≈1 MiB content + Base64 overhead) |
| `MaxBatchProfileSize` | 25 MiB | Batch profile upload payloads |
| `MaxEULASize` | 25 MiB | EULA document uploads |
| `MaxSoftwareBatchSize` | 25 MiB | Batch software (installers + scripts + queries) |
| `MaxMDMCommandSize` | 2 MiB | MDM command payloads |
| `MaxMultiScriptQuerySize` | 5 MiB | Payloads combining multiple scripts and SQL queries |
| `MaxMicrosoftMDMSize` | 2 MiB | Microsoft MDM request bodies |
| `MaxSSOCallbackSize` | 256 KiB | Unauthenticated SSO callback (regular + MDM); bounds pre-auth attack surface |
| `MaxAppleMDMRequestBodySize` | 16 MiB − 1 byte | Apple MDM check-in and command results; aligned to `MEDIUMTEXT` column max |
| `DefaultMaxOsqueryLogWriteSize` | 10 MiB | `/api/osquery/log` in legacy body-auth mode; operator-overridable |
| `DefaultMaxOsqueryDistributedWriteSize` | 5 MiB | `/api/osquery/distributed/write` in legacy body-auth mode |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/fleet"

// Apply a size limit middleware to an endpoint
http.Handle("/api/v1/fleet/scripts", limitBody(fleet.MaxScriptSize, scriptHandler))

// Override the osquery log write limit from config
logWriteLimit := fleet.DefaultMaxOsqueryLogWriteSize
if cfg.Osquery.MaxLogWriteBodySize > 0 {
    logWriteLimit = cfg.Osquery.MaxLogWriteBodySize
}
```

> **Note:** `MaxSoftwareInstallerSize` is intentionally excluded from this file — it lives in the `installersize` context package to avoid circular imports and because it is referenced outside of request handling.
