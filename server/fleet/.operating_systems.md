Defines the `OperatingSystem` struct and associated methods for representing and querying OS metadata across platforms (macOS, Windows, Linux).

## Key Components

- **`OperatingSystem`** — Core struct representing a uniquely identified OS by name, version, architecture, kernel version, platform, and Windows-specific fields (`DisplayVersion`, `InstallationType`).
- **`IsWindows() bool`** — Returns `true` if the OS platform is `"windows"` (case-insensitive).
- **`RequiresNudge() (bool, error)`** — Returns `true` for macOS (`darwin`) versions below 14, where Nudge is required to prompt users for updates. macOS 14+ has a built-in update notification mechanism.

## Usage Example

```go
os := fleet.OperatingSystem{
    Name:     "macOS",
    Version:  "13.3.7 (a)",
    Platform: "darwin",
}

if os.IsWindows() {
    fmt.Println("Windows OS detected")
}

needsNudge, err := os.RequiresNudge()
if err != nil {
    log.Fatal(err)
}
if needsNudge {
    fmt.Println("Nudge required for this macOS version")
}
```

> **Note:** `RequiresNudge` strips Rapid Security Response suffixes (e.g. `13.3.7 (a)`) before parsing the version via `VersionToSemverVersion`.
