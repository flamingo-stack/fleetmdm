Defines core database types and interfaces for Fleet's datastore layer, providing lock introspection and a read-only database abstraction.

## Key Components

### `DBLock`
Struct representing a MySQL InnoDB transaction lock conflict, as returned by `datastore.DBLocks`. Captures both the waiting and blocking transaction/thread/query details for deadlock diagnostics.

| Field | Type | Description |
|---|---|---|
| `WaitingTrxID` | `string` | Transaction ID of the waiting transaction |
| `WaitingThread` | `uint64` | Thread ID of the waiting connection |
| `WaitingQuery` | `*string` | SQL query text of the waiting transaction (optional) |
| `BlockingTrxID` | `string` | Transaction ID of the blocking transaction |
| `BlockingThread` | `uint64` | Thread ID of the blocking connection |
| `BlockingQuery` | `*string` | SQL query text of the blocking transaction (optional) |

### `DBReader`
Interface for read-only database access, composing `sqlx.QueryerContext` and `sqlx.PreparerContext` with additional lifecycle methods.

| Method | Description |
|---|---|
| `Close() error` | Releases the underlying connection |
| `Rebind(string) string` | Adapts a query string to the driver's placeholder syntax |

## Usage Example

```go
// Inject a read replica as DBReader
func NewService(reader fleet.DBReader) {
    rows, err := reader.QueryContext(ctx, "SELECT id FROM hosts WHERE platform = ?", "darwin")
    if err != nil {
        log.Fatal(err)
    }
    defer rows.Close()
}

// Inspect active lock conflicts
var locks []fleet.DBLock
err := ds.DBLocks(ctx, &locks)
for _, l := range locks {
    fmt.Printf("TrxID %s blocked by %s\n", l.WaitingTrxID, l.BlockingTrxID)
}
```
