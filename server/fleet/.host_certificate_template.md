Defines data structures and constants for managing certificate templates assigned to Android hosts in Fleet MDM, including status tracking, retry logic, and profile mapping.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `AndroidCertificateTemplateProfileID` | `"fleet-host-certificate-template"` | Sentinel profile UUID used by the front-end to identify certificate template profiles |
| `ONCProfileWithheldDetailPrefix` | `"Waiting for certificate"` | Detail prefix for Android ONC profiles blocked pending certificate installation |
| `MaxCertificateInstallRetries` | `3` | Maximum automatic retries after initial certificate install failure; manual resend sets `retry_count` to this value for a single forced attempt |

### Types

- **`HostCertificateTemplate`** — Primary record linking a host (`host_uuid`) to a certificate template, carrying status, operation type, validity window, serial, and retry count.
- **`CertificateTemplateForHost`** — Lightweight query projection used when fetching pending certificate work for a host, including CA metadata.
- **`CertificateStatusUpdate`** — Payload for updating a host certificate's delivery status, detail, operation type, validity window, and serial after an MDM callback.
- **`HostCertificateTemplateForRenewal`** — Minimal record identifying certificates due for renewal, keyed by host UUID, template ID, and expiry time.

### Methods

- **`HostCertificateTemplate.ToHostMDMProfile()`** — Converts a `HostCertificateTemplate` to a `HostMDMProfile` for use in MDM API responses, hardcoding `platform` as `"android"` and `ProfileUUID` as `AndroidCertificateTemplateProfileID`.

## Usage Example

```go
hct := &fleet.HostCertificateTemplate{
    HostUUID:              "abc-123",
    Name:                  "Corp Wi-Fi Cert",
    CertificateTemplateID: 7,
    Status:                fleet.CertificateTemplateStatusPending,
    OperationType:         fleet.MDMOperationTypeInstall,
    RetryCount:            0,
}

// Map to MDM API profile shape
profile := hct.ToHostMDMProfile()
// profile.ProfileUUID == "fleet-host-certificate-template"
// profile.Platform    == "android"

// Trigger a manual resend with no automatic retries
hct.RetryCount = fleet.MaxCertificateInstallRetries
```
