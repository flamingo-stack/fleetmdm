OPA-based authorization engine that compiles and evaluates Rego policies to enforce access control across Fleet service methods.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Authorizer` | Core struct holding a compiled OPA `PreparedEvalQuery` used for policy evaluation |
| `NewAuthorizer()` | Compiles the embedded `policy.rego` file and returns a ready-to-use `Authorizer` |
| `Must()` | Convenience constructor that panics on error instead of returning it |
| `Authorize()` | Evaluates subject/object/action triples against the Rego policy; marks the auth context as checked |
| `SkipAuthorization()` | Marks the auth context as checked without performing any policy evaluation |
| `IsAuthenticatedWith()` | Checks whether the request was authenticated via a specific method |
| `ExtraAuthzer` | Interface for types that contribute additional key/value pairs to policy input |
| `jsonToInterface()` | Serializes any value to `map[string]interface{}` for OPA input, with support for `AuthzTyper` and `ExtraAuthzer` |
| `UserFromContext()` | Retrieves the current `fleet.User` from the viewer context |
| `AuthorizerAdapter` | Adapts `Authorizer` to the `platform_authz.Authorizer` interface with stronger typing |

## Usage Example

```go
// Create and use the authorizer
auth, err := authz.NewAuthorizer()
if err != nil {
    log.Fatal(err)
}

// Check authorization for an action
err = auth.Authorize(ctx, hostObject, fleet.ActionRead)
if err != nil {
    // Returns a Forbidden error if the policy disallows the request
    return err
}

// Skip authorization where not applicable
// skipauth: listing public metadata requires no access control
auth.SkipAuthorization(ctx)

// Wrap with platform adapter for typed interface
adapter := authz.NewAuthorizerAdapter(auth)
err = adapter.Authorize(ctx, typedObject, platform_authz.ActionWrite)
```

Policy rules are defined in the co-located [`policy.rego`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/authz/policy.rego) file and embedded at compile time via `//go:embed`.
