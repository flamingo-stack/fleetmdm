Implements a simple stdout log writer that prints JSON log messages directly to standard output.

## Key Components

- **`stdoutLogWriter`** — struct implementing the log writer interface for stdout output
- **`NewStdoutLogWriter()`** — constructor returning a new `stdoutLogWriter` instance
- **`Write(ctx, logs)`** — iterates over a slice of `json.RawMessage` and prints each entry to stdout, one per line

## Usage Example

```go
writer, err := logging.NewStdoutLogWriter()
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"level":"info","msg":"service started"}`),
    json.RawMessage(`{"level":"error","msg":"something failed"}`),
}

if err := writer.Write(context.Background(), logs); err != nil {
    log.Fatal(err)
}
// Output:
// {"level":"info","msg":"service started"}
// {"level":"error","msg":"something failed"}
```

## Notes

- No configuration or external dependencies required — output goes directly to `os.Stdout` via `fmt.Printf`
- The `context.Context` parameter is accepted but unused, keeping the signature consistent with other log writer implementations
- Raw JSON messages are printed as-is with no transformation or formatting
