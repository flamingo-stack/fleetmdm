Writes Fleet log data to an AWS Kinesis Data Stream, handling batching, size limits, and exponential backoff retries.

## Key Components

### `KinesisAPI` Interface
Abstracts the AWS Kinesis client methods used (`PutRecords`, `DescribeStream`), enabling testing with mock implementations.

### `kinesisLogWriter` Struct
Core writer holding the Kinesis client, target stream name, logger, and a random source for partition key generation.

### `NewKinesisLogWriter`
Constructs and validates a `kinesisLogWriter`. Supports static credentials, a custom endpoint URL, and STS assume-role authentication. Validates the target stream is in `ACTIVE` status before returning.

### `Write`
Accepts a batch of `json.RawMessage` log entries, appends newlines for NDJSON formatting, assigns random partition keys (0–255) for shard balancing, enforces Kinesis limits (500 records/batch, 1 MB/record, 5 MB/batch), and flushes intermediate batches as needed. Logs exceeding 1 MB are dropped with a warning.

### `putRecords`
Sends a batch to Kinesis with exponential backoff (up to 8 retries). Handles both API-level errors and per-record failures by collecting failed records and retrying them individually.

## Usage Example

```go
writer, err := logging.NewKinesisLogWriter(
    "us-east-1",
    "",                      // endpointURL (empty = AWS default)
    "ACCESS_KEY_ID",
    "SECRET_ACCESS_KEY",
    "",                      // stsAssumeRoleArn
    "",                      // stsExternalID
    "my-fleet-log-stream",
    slog.Default(),
)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"host":"server1","event":"login"}`),
    json.RawMessage(`{"host":"server2","event":"logout"}`),
}

if err := writer.Write(ctx, logs); err != nil {
    log.Printf("failed to write logs: %v", err)
}
```
