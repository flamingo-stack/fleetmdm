Implements a Kafka REST Proxy producer for publishing Fleet log records to a Kafka topic via HTTP, used as a logging backend within the Fleet server.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `KafkaRESTParams` | struct | Configuration parameters: proxy host, topic name, content type, and timeout |
| `kafkaRESTProducer` | struct | Internal producer holding the HTTP client, publish URL, check URL, and content type |
| `kafkaRecords` / `kafkaValue` | structs | JSON envelope wrapping raw log messages into Kafka's REST Proxy record format |
| `NewKafkaRESTWriter` | func | Constructs a `kafkaRESTProducer`, validates topic availability via `checkTopic()` |
| `Write` | method | Batches `[]json.RawMessage` logs into a Kafka records payload and POSTs to the proxy |
| `checkTopic` | method | GETs the topic endpoint on startup to confirm the topic is reachable |
| `post` | method | Issues a POST request with `Content-Type` and Unix nanosecond `TimeStamp` headers |
| `checkResponse` | func | Validates HTTP 200 OK; returns error with body on non-200 responses |

## Usage Example

```go
params := &logging.KafkaRESTParams{
    KafkaProxyHost:        "http://kafka-rest-proxy:8082",
    KafkaTopic:            "fleet-logs",
    KafkaContentTypeValue: "application/vnd.kafka.json.v2+json",
    KafkaTimeout:          10,
}

writer, err := logging.NewKafkaRESTWriter(params)
if err != nil {
    log.Fatalf("failed to initialize Kafka writer: %v", err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"host":"device-1","event":"enrolled"}`),
    json.RawMessage(`{"host":"device-2","event":"policy_failed"}`),
}

if err := writer.Write(ctx, logs); err != nil {
    log.Printf("failed to publish logs: %v", err)
}
```

> **Note:** `NewKafkaRESTWriter` performs an immediate topic reachability check. If the Kafka REST Proxy or the topic is unavailable at startup, initialization will fail with a descriptive error.
