Factory entry point for the `logging` package — `NewJSONLogger` constructs a `fleet.JSONLogger` by dispatching to the appropriate backend writer based on the configured plugin name.

## Key Components

### Configuration Structs

| Struct | Plugin Key | Notable Fields |
|---|---|---|
| `FilesystemConfig` | `filesystem` | `LogFile`, rotation/compression options |
| `WebhookConfig` | `webhook` | `URL` |
| `FirehoseConfig` | `firehose` | `StreamName`, AWS credentials, STS role |
| `KinesisConfig` | `kinesis` | `StreamName`, AWS credentials, STS role |
| `LambdaConfig` | `lambda` | `Function`, AWS credentials, STS role |
| `PubSubConfig` | `pubsub` | `Project`, `Topic`, `AddAttributes` |
| `KafkaRESTConfig` | `kafkarest` | `ProxyHost`, `Topic`, `Timeout` |
| `NatsConfig` | `nats` | `Server`, `Subject`, TLS/auth files, JetStream |

### `Config`

Top-level configuration struct that holds the active `Plugin` name and all plugin-specific sub-configs.

### `NewJSONLogger`

```go
func NewJSONLogger(ctx context.Context, name string, config Config, logger *slog.Logger) (fleet.JSONLogger, error)
```

Dispatches on `config.Plugin` to instantiate and return the correct `fleet.JSONLogger` backend. An empty plugin string falls back to `"filesystem"` for backwards compatibility.

**Supported plugin values:** `filesystem`, `webhook`, `firehose`, `kinesis`, `lambda`, `pubsub`, `stdout`, `kafkarest`, `nats`.

## Usage Example

```go
cfg := logging.Config{
    Plugin: "filesystem",
    Filesystem: logging.FilesystemConfig{
        LogFile:           "/var/log/fleet/osquery.log",
        EnableLogRotation: true,
        MaxSize:           100, // MB
        MaxBackups:        5,
    },
}

jsonLogger, err := logging.NewJSONLogger(ctx, "osquery-result", cfg, slogLogger)
if err != nil {
    log.Fatal(err)
}
```

To switch backends, change `Plugin` to `"kinesis"` (or any supported key) and populate the corresponding config struct — no other code changes required.
