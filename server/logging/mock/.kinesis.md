Mock implementation of the AWS Kinesis client interface for use in unit tests, providing controllable `PutRecords` and `DescribeStream` method stubs with invocation tracking.

## Key Components

| Component | Description |
|---|---|
| `KinesisMock` | Struct implementing the Kinesis client interface with injectable function fields and invocation flags |
| `PutRecordsFunc` | Function type matching the `PutRecords` AWS SDK signature |
| `DescribeStreamFunc` | Function type matching the `DescribeStream` AWS SDK signature |
| `PutRecordsFuncInvoked` | Boolean flag set to `true` when `PutRecords` is called |
| `DescribeStreamFuncInvoked` | Boolean flag set to `true` when `DescribeStream` is called |

## Usage Example

```go
mock := &mock.KinesisMock{
    PutRecordsFunc: func(ctx context.Context, input *kinesis.PutRecordsInput, optFns ...func(*kinesis.Options)) (*kinesis.PutRecordsOutput, error) {
        return &kinesis.PutRecordsOutput{}, nil
    },
    DescribeStreamFunc: func(ctx context.Context, input *kinesis.DescribeStreamInput, optFns ...func(*kinesis.Options)) (*kinesis.DescribeStreamOutput, error) {
        return &kinesis.DescribeStreamOutput{}, nil
    },
}

// Inject mock into service under test
svc := NewMyService(mock)
svc.DoSomething(context.Background())

// Assert methods were called
if !mock.PutRecordsFuncInvoked {
    t.Error("expected PutRecords to be called")
}
```

> **Note:** Both `PutRecordsFunc` and `DescribeStreamFunc` must be set before calling the corresponding methods, otherwise the mock will panic on a nil function call.
