Mock implementation of the AWS Lambda client interface for use in unit tests, enabling controlled simulation of Lambda `Invoke` calls without real AWS infrastructure.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `LambdaMock` | `struct` | Testify-backed mock that satisfies the Lambda client interface |
| `Invoke` | `method` | Intercepts Lambda invocation calls and returns pre-configured test responses |

## Usage Example

```go
func TestMyLambdaCaller(t *testing.T) {
    mockLambda := new(mock.LambdaMock)

    expectedOutput := &lambda.InvokeOutput{
        StatusCode: aws.Int32(200),
    }

    mockLambda.On("Invoke", mock.AnythingOfType("*lambda.InvokeInput")).
        Return(expectedOutput, nil)

    // Pass mockLambda to the component under test
    result, err := myFunction(context.Background(), mockLambda)

    assert.NoError(t, err)
    mockLambda.AssertExpectations(t)
}
```

> **Note:** When the mock returns `nil` as the first argument, `Invoke` safely returns `(nil, err)` to avoid a nil-pointer panic during type assertion.
