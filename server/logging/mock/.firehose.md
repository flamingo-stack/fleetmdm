A mock implementation of the AWS Kinesis Firehose client interface for use in unit tests, tracking invocations of `PutRecordBatch` and `DescribeDeliveryStream`.

## Key Components

- **`PutRecordBatchFunc`** — Function type matching the `PutRecordBatch` AWS SDK signature.
- **`DescribeDeliveryStreamFunc`** — Function type matching the `DescribeDeliveryStream` AWS SDK signature.
- **`FirehoseMock`** — Struct implementing the Firehose client interface. Holds configurable function fields and boolean invocation flags (`PutRecordBatchFuncInvoked`, `DescribeDeliveryStreamFuncInvoked`) to assert calls were made during tests.

## Usage Example

```go
mock := &mock.FirehoseMock{
    PutRecordBatchFunc: func(
        ctx context.Context,
        input *firehose.PutRecordBatchInput,
        optFns ...func(*firehose.Options),
    ) (*firehose.PutRecordBatchOutput, error) {
        return &firehose.PutRecordBatchOutput{}, nil
    },
    DescribeDeliveryStreamFunc: func(
        ctx context.Context,
        input *firehose.DescribeDeliveryStreamInput,
        optFns ...func(*firehose.Options),
    ) (*firehose.DescribeDeliveryStreamOutput, error) {
        return &firehose.DescribeDeliveryStreamOutput{}, nil
    },
}

// Inject mock into the service under test
svc := NewMyService(mock)
svc.DoSomething(ctx)

// Assert interactions
if !mock.PutRecordBatchFuncInvoked {
    t.Error("expected PutRecordBatch to be called")
}
```

## Notes

- Both methods delegate entirely to their configurable function fields, so tests can inject custom behavior or errors without subclassing.
- Set a function field to `nil` intentionally to cause a panic if an unexpected method is called, making unintended invocations immediately visible.
