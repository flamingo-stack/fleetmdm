Provides filesystem-based log writing for Fleet, supporting both simple buffered writes and rotation-enabled logging via `lumberjack`, with optional `SIGHUP`-triggered log rotation and compression.

## Key Components

- **`filesystemLogWriter`** — Top-level log writer wrapping either a `rawLogWriter` or a `lumberjack.Logger`.
- **`NewFilesystemLogWriter`** — Constructor that validates file permissions, then returns either a raw buffered writer or a rotation-capable writer based on `enableRotation`. When rotation is enabled, a goroutine listens for `SIGHUP` to trigger `lumberjack.Rotate()`.
- **`Write`** — Writes a batch of `json.RawMessage` log entries to the file, appending a newline after each, and flushes if the underlying writer supports it.
- **`rawLogWriter`** — Mutex-protected `bufio.Writer` over an `*os.File`. Automatically recreates the file if it no longer exists (e.g., after external deletion), making it resilient to log rotation without `lumberjack`.
- **`flusher` interface** — Internal interface checked on the writer to trigger a flush after each write batch.

## Usage Example

```go
import (
    "context"
    "log/slog"
    "github.com/flamingo-stack/fleetmdm/server/logging"
)

ctx := context.Background()
appLogger := slog.Default()

writer, err := logging.NewFilesystemLogWriter(
    ctx,
    "/var/log/fleet/osquery.log",
    appLogger,
    true,  // enableRotation
    true,  // enableCompression
    100,   // maxSize in MB
    30,    // maxAge in days
    5,     // maxBackups
)
if err != nil {
    log.Fatal(err)
}

// Write a batch of JSON log entries
err = writer.Write(ctx, []json.RawMessage{
    json.RawMessage(`{"level":"info","msg":"host connected"}`),
})
```

> **Rotation:** Send `SIGHUP` to the Fleet process (`kill -HUP <pid>`) to trigger log rotation when `enableRotation` is `true`.
