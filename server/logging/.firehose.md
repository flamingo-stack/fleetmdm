Implements an AWS Kinesis Firehose log writer that batches and delivers JSON log records to a Firehose delivery stream, with retry logic and batch size enforcement.

## Key Components

- **`FirehoseAPI`** — Interface wrapping the AWS Firehose client methods used (`PutRecordBatch`, `DescribeDeliveryStream`), enabling testing via mocks.
- **`firehoseLogWriter`** — Core struct holding the Firehose client, stream name, and logger.
- **`NewFirehoseLogWriter`** — Constructor that configures AWS credentials (static or default chain), optional STS assume-role, endpoint override, and validates the target stream is active.
- **`Write`** — Accepts a slice of raw JSON logs, appends newlines, enforces per-record (1 MB) and per-batch (4 MB, 500 records) limits, and flushes batches to Firehose.
- **`putRecordBatch`** — Internal method handling `PutRecordBatch` calls with exponential backoff (up to 8 retries) for `ServiceUnavailableException` and partial-failure record retries.

## Usage Example

```go
import "log/slog"

logger := slog.Default()

writer, err := logging.NewFirehoseLogWriter(
    "us-east-1",          // region
    "",                   // endpointURL (optional)
    "",                   // AWS access key ID (uses default chain if empty)
    "",                   // AWS secret key
    "",                   // STS assume role ARN (optional)
    "",                   // STS external ID (optional)
    "my-delivery-stream", // Firehose stream name
    logger,
)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"host":"web01","event":"login"}`),
    json.RawMessage(`{"host":"web02","event":"logout"}`),
}

if err := writer.Write(ctx, logs); err != nil {
    log.Printf("failed to write logs: %v", err)
}
```

## Notes

- Records exceeding 1 MB are dropped with an info log (consistent with osquery's Firehose plugin behavior).
- Batches are flushed automatically when approaching the 500-record or 4 MB Firehose limits.
