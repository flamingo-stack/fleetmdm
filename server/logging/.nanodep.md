Adapter that bridges the nanodep logging interface to Go's standard `slog.Logger`, enabling NanoDEP MDM components to emit structured log output via Fleet's logging infrastructure.

## Key Components

- **`NanoDEPLogger`** — Struct implementing the `nanodep_log.Logger` interface, wrapping a `*slog.Logger` and a `context.Context`
- **`NewNanoDEPLogger`** — Constructor that initialises the adapter with a context and slog logger
- **`Info`** — Delegates to `slog.Logger.InfoContext` with key-value pairs
- **`Debug`** — Delegates to `slog.Logger.DebugContext` with key-value pairs
- **`With`** — Returns a new `NanoDEPLogger` with additional structured fields attached, satisfying the `nanodep_log.Logger` interface

## Usage Example

```go
import (
    "context"
    "log/slog"
    "os"

    "github.com/flamingo-stack/fleetmdm/server/mdm/nanodep/logging"
)

ctx := context.Background()
base := slog.New(slog.NewJSONHandler(os.Stdout, nil))

depLogger := logging.NewNanoDEPLogger(ctx, base)

// Log at info level
depLogger.Info("msg", "key", "value")

// Log at debug level
depLogger.Debug("msg", "attempt", 1)

// Attach persistent fields
scoped := depLogger.With("component", "dep-syncer", "profile", "default")
scoped.Info("msg", "status", "syncing")
```

## Notes

- Context is stored on the struct and propagated to every log call via `InfoContext`/`DebugContext`, enabling context-aware log enrichment (e.g. request tracing).
- `With` preserves the parent context while creating a child logger with additional fields, keeping the nanodep interface contract intact.
