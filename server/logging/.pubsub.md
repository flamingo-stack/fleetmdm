Implements a Google Cloud Pub/Sub log writer for Fleet's logging infrastructure, enabling asynchronous batch publishing of JSON log messages to a GCP Pub/Sub topic with optional message attribute extraction.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `pubSubLogWriter` | struct | Core writer holding the Pub/Sub topic handle, logger, and attribute configuration |
| `PubSubAttributes` | struct | JSON-mapped structure for extracting `name`, `unixTime`, and `decorations` from log messages into Pub/Sub message attributes |
| `NewPubSubLogWriter` | func | Constructor that initializes a GCP Pub/Sub client and returns a configured `pubSubLogWriter` |
| `estimateAttributeSize` | func | Helper that approximates byte size of a `map[string]string` to guard against the 10 MB Pub/Sub publish limit |
| `Write` | func | Publishes a batch of `json.RawMessage` logs asynchronously, waiting for all results before returning |

## Usage Example

```go
import "log/slog"

logger := slog.Default()

writer, err := logging.NewPubSubLogWriter(
    ctx,
    "my-gcp-project",
    "fleet-osquery-logs",
    true,  // extract name/timestamp/decorations as Pub/Sub attributes
    logger,
)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"name":"osquery_result","unixTime":1700000000,"decorations":{"host_uuid":"abc-123"}}`),
}

if err := writer.Write(ctx, logs); err != nil {
    log.Printf("publish error: %v", err)
}
```

## Notes

- Messages exceeding the **10 MB Pub/Sub limit** (data + attribute sizes) are **silently dropped** with an info log rather than returning an error.
- Publishing is batched: all messages are enqueued via `topic.Publish` before blocking on results, leveraging Pub/Sub client-side batching.
- When `addAttributes` is `true`, `decorations` key-value pairs from the log JSON are promoted to top-level Pub/Sub message attributes, enabling server-side filtering.
