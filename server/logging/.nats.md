NATS log writer implementation that publishes structured log messages to a NATS server, supporting both core NATS and JetStream delivery modes, subject routing via static or template-based patterns, and optional payload compression.

## Key Components

| Component | Description |
|---|---|
| `natsLogWriter` | Main writer struct connecting to NATS with configurable compression, JetStream, routing, and timeout |
| `NewNatsLogWriter` | Constructor accepting server, subject, auth (creds/nkey/TLS), compression, and JetStream options |
| `natsPublisher` | Interface abstracting core NATS (`natsClientPublisher`) and JetStream (`natsStreamPublisher`) delivery |
| `natsRouter` | Interface abstracting constant (`natsConstantRouter`) and template (`natsTemplateRouter`) subject routing |
| `natsTemplateRouter` | Evaluates `{expr}` placeholders in subject templates against log JSON fields using the `expr-lang` compiler |
| `natsTemplatePatcher` | AST patcher that rewrites member access (`log.field`) into `get(log, "field")` calls for safe JSON traversal |
| `compress` | Compresses log payloads using `gzip`, `snappy`, or `zstd` before publish |

## Usage Example

```go
import "log/slog"

writer, err := logging.NewNatsLogWriter(
    ctx,
    "nats://localhost:4222",     // server
    "logs.{log.platform}.{log.hostname}", // template subject
    "/etc/nats/creds",           // credFile
    "",                          // nkeyFile
    "", "", "",                  // TLS files
    "zstd",                      // compression
    true,                        // jetstream
    5*time.Second,               // timeout
    slog.Default(),
)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"platform":"linux","hostname":"host1","msg":"boot complete"}`),
}

if err := writer.Write(ctx, logs); err != nil {
    log.Fatal(err)
}
```

Subject templates use `{expr}` syntax — e.g., `logs.{log.platform}` resolves `platform` from each log's JSON before publishing. Supported compression values: `gzip`, `snappy`, `zstd`.
