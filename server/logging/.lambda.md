AWS Lambda log writer that invokes a Lambda function for each log entry, with payload size enforcement and optional STS assume-role support.

## Key Components

- **`LambdaAPI`** — Interface wrapping `lambda.Invoke`, enabling mock injection for testing.
- **`lambdaLogWriter`** — Core struct holding the Lambda client, function name, and a structured logger.
- **`NewLambdaLogWriter`** — Constructor that builds AWS config (static credentials or default chain), optionally configures STS assume-role, creates the Lambda client, and validates the target function via a dry-run invocation.
- **`validateFunction`** — Performs a `DryRun` invocation to confirm the function exists and is reachable before accepting writes.
- **`Write`** — Iterates over a slice of raw JSON log messages, skips any exceeding the 6 MB Lambda synchronous payload limit, and invokes the Lambda function once per log entry.

## Usage Example

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

writer, err := logging.NewLambdaLogWriter(
    "us-east-1",          // region
    "AKIAIOSFODNN7EXAMPLE", // AWS access key ID (or "" for default chain)
    "wJalrXUtnFEMI...",   // AWS secret (or "")
    "",                   // STS assume-role ARN (optional)
    "",                   // STS external ID (optional)
    "my-log-processor",   // Lambda function name
    logger,
)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"host":"web-01","event":"login","user":"alice"}`),
}

if err := writer.Write(context.Background(), logs); err != nil {
    log.Printf("write failed: %v", err)
}
```

> **Note:** Log entries exceeding 6 MB are silently dropped with an `INFO`-level log showing the first 100 bytes. This matches the behavior of other Fleet logging plugins. See [lambda.go](https://github.com/flamingo-stack/fleetmdm/blob/main/server/logging/lambda.go) for full implementation details.
