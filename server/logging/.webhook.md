Implements a webhook-based log writer that batches and forwards log entries to a configured HTTP endpoint via JSON POST requests.

## Key Components

- **`webhookLogWriter`** — Struct holding the target webhook URL and a structured logger (`slog.Logger`).
- **`NewWebhookLogWriter(webhookURL, logger)`** — Constructor that validates the URL and returns a configured `webhookLogWriter` instance.
- **`webhookPayload`** — JSON-serializable envelope containing a server-side `timestamp` and a `details` array of raw log messages.
- **`Write(ctx, logs)`** — Wraps the provided log messages in a `webhookPayload` and dispatches them via `server.PostJSONWithTimeout`. Errors are logged (with URL and error masking) but not propagated to the caller.

## Usage Example

```go
import (
    "context"
    "encoding/json"
    "log/slog"

    "github.com/flamingo-stack/fleetmdm/server/logging"
)

logger := slog.Default()

writer, err := logging.NewWebhookLogWriter("https://hooks.example.com/fleet-logs", logger)
if err != nil {
    log.Fatal(err)
}

logs := []json.RawMessage{
    json.RawMessage(`{"host_id":42,"event":"policy_failed"}`),
}

if err := writer.Write(context.Background(), logs); err != nil {
    log.Fatal(err)
}
```

## Notes

- Secret query parameters in the webhook URL are masked via `server.MaskSecretURLParams` before appearing in logs.
- HTTP errors are sanitized with `server.MaskURLError` to avoid leaking sensitive URL data.
- `Write` always returns `nil`; delivery failures are surfaced only through the logger.
