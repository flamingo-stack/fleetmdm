Provides utilities for retrieving and parsing SAML Identity Provider (IdP) metadata from either a remote URL or a raw XML string, returning a structured `saml.EntityDescriptor`.

## Key Components

| Export | Description |
|--------|-------------|
| `GetMetadata(config)` | Entry point that resolves IdP metadata from `SSOProviderSettings` — fetches from URL if set, otherwise parses inline XML |
| `getMetadata(metadataURL)` | Internal helper that performs an HTTP GET against the metadata URL with a 5-second timeout |
| `ParseMetadata(xmlMetadata)` | Unmarshals raw XML bytes into a `saml.EntityDescriptor` |

## Usage Example

```go
// Fetch metadata from a remote URL
settings := &fleet.SSOProviderSettings{
    IDPName:     "Okta",
    MetadataURL: "https://idp.example.com/saml/metadata",
}
entity, err := sso.GetMetadata(settings)
if err != nil {
    log.Fatalf("failed to get IdP metadata: %v", err)
}

// Or parse inline XML metadata
settings := &fleet.SSOProviderSettings{
    IDPName:  "AzureAD",
    Metadata: `<EntityDescriptor ...>...</EntityDescriptor>`,
}
entity, err := sso.GetMetadata(settings)

// Parse raw XML bytes directly
entity, err := sso.ParseMetadata([]byte(rawXML))
```

## Notes

- `GetMetadata` returns an error if **both** `MetadataURL` and `Metadata` are empty.
- Remote fetches use `fleethttp.NewClient` with a hardcoded **5-second timeout**.
- The HTTP response must return `200 OK`; any other status yields an error including the status text.
