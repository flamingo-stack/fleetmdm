Provides WebSocket connection helpers for Fleet's backend-to-frontend communication using SockJS, including typed JSON messaging and authentication token handling.

## Key Components

| Export | Description |
|--------|-------------|
| `JSONMessage` | Wrapper struct for typed WebSocket messages with `Type` and `Data` fields |
| `Conn` | Wraps `sockjs.Session` with Fleet-specific read/write methods |
| `Conn.WriteJSON` | Marshals a `JSONMessage` and sends it over the connection |
| `Conn.WriteJSONMessage` | Convenience method to send typed data without constructing `JSONMessage` manually |
| `Conn.WriteJSONError` | Sends an error message with type `"error"` |
| `Conn.ReadJSONMessage` | Reads and unmarshals an incoming message; `Data` is always `*json.RawMessage` |
| `Conn.ReadAuthToken` | Reads the first message expecting type `"auth"` and extracts the Fleet auth token |

## Usage Example

```go
// Wrap a SockJS session
conn := &websocket.Conn{Session: session}

// Read the auth token sent by the frontend on connect
tok, err := conn.ReadAuthToken()
if err != nil {
    conn.WriteJSONError("authentication failed")
    return
}

// Send a typed message back to the client
err = conn.WriteJSONMessage("status", map[string]string{
    "state": "authenticated",
})

// Read subsequent messages with type-based dispatch
msg, err := conn.ReadJSONMessage()
if err == nil && msg.Type == "foo" {
    var foo fooData
    json.Unmarshal(*(msg.Data.(*json.RawMessage)), &foo)
}
```

## Notes

- `ReadJSONMessage` always stores `Data` as `*json.RawMessage`, enabling safe unchecked type assertions before a second `json.Unmarshal` call for the concrete type.
- Authentication is expected as the **first message** on a new connection before any other traffic.
