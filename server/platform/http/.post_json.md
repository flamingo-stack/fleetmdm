Provides a helper for marshaling a value as JSON and sending it via HTTP POST, with built-in timeout, error masking, and status-code-aware error handling.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `errWithStatus` | struct | Error type that carries an HTTP status code alongside the error message |
| `errWithStatus.Error()` | method | Implements the `error` interface |
| `errWithStatus.StatusCode()` | method | Implements the `StatusCoder` interface for custom status code propagation |
| `PostJSONWithTimeout` | function | Marshals `v` to JSON and POSTs it to `url` using a 30-second timeout |

## Usage Example

```go
package main

import (
    "context"
    "log/slog"
    "os"

    fleethttp "github.com/flamingo-stack/fleetmdm/pkg/http"
)

func main() {
    logger := slog.New(slog.NewTextHandler(os.Stdout, nil))
    ctx := context.Background()

    payload := map[string]string{
        "event": "device_enrolled",
        "host":  "mac-pro-01",
    }

    err := fleethttp.PostJSONWithTimeout(ctx, "https://api.example.com/webhook", payload, logger)
    if err != nil {
        // Optionally inspect the HTTP status code
        type statusCoder interface{ StatusCode() int }
        if sc, ok := err.(statusCoder); ok {
            slog.Error("request failed", "status", sc.StatusCode())
        }
    }
}
```

## Notes

- Response bodies on non-2xx replies are read up to **512 bytes** and logged at `DEBUG` level before returning an `errWithStatus`.
- Secret URL parameters are automatically masked in both error messages and log output via `MaskSecretURLParams` / `MaskURLError`, preventing credential leakage.
- The underlying HTTP client is created via `fleethttp.NewClient`, inheriting Fleet's default transport settings with a 30-second timeout override.
