Defines HTTP request size constraints for the Fleet MDM HTTP package, controlling maximum body and multipart form sizes.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `MaxRequestBodySize` | `var int64` | Maximum allowed HTTP request body size (default: 1 MiB). Configurable at startup/serve time. |
| `MaxMultipartFormSize` | `const int64` | Maximum in-memory size for multipart form data parsing (1 MiB). Data exceeding this limit is written to temporary disk files. |

## Usage Example

```go
import fleethttp "github.com/flamingo-stack/fleetmdm/pkg/http"

// Override the default max request body size at server startup
fleethttp.MaxRequestBodySize = 10 * units.MiB

// Use the multipart form size constant when parsing form data
err := r.ParseMultipartForm(fleethttp.MaxMultipartFormSize)
```

## Notes

- `MaxRequestBodySize` is intentionally a `var` (not `const`) to allow runtime configuration during server initialization.
- `MaxMultipartFormSize` governs only the **in-memory** portion of multipart parsing — files and fields exceeding 1 MiB are spilled to temporary disk files automatically by Go's `multipart` package.
