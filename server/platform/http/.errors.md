Defines HTTP-layer error types and interfaces used throughout the Fleet server to communicate structured error information between service layers, HTTP handlers, and clients.

## Key Components

### Interfaces

| Interface | Purpose |
|---|---|
| `ErrWithInternal` | Errors with a loggable-only internal message |
| `ErrWithLogFields` | Errors carrying additional structured log fields |
| `ErrorUUIDer` | Errors with a UUID for request tracking |
| `ErrWithRetryAfter` | Errors that set an HTTP `Retry-After` header |
| `ForeignKeyError` | Errors from DB foreign key constraint violations |
| `AlreadyExistsError` | Errors when a resource already exists |

### Embeddable Types

- **`ErrorWithUUID`** — Embed in error structs to get lazy, concurrency-safe UUID generation via `sync.Once`.

### Concrete Error Types

| Type | HTTP Status | Description |
|---|---|---|
| `BadRequestError` | 400 | Invalid request with optional internal cause |
| `PayloadTooLargeError` | 413 | Request body exceeds configured size limit |
| `UserMessageError` | 422 (default) | Wraps any error with a user-friendly message |
| `AuthFailedError` | 401 | Authentication failure |
| `AuthRequiredError` | 401 | Authentication not provided |
| `AuthHeaderRequiredError` | 401 | Missing `Authorization` header |
| `ErrPasswordResetRequired` | 401 | Password reset must be completed |
| `CheckMissing` | — | Authorization check was skipped in service layer |
| `Error` | — | Generic error with a code and message |

### Helper Functions

- **`NewUserMessageError(err, statusCode)`** — Wraps an error with a user-friendly message and custom status code.
- **`IsJSONUnknownFieldError(err)`** — Detects strict JSON unknown-field errors by message pattern.
- **`GetJSONUnknownField(err)`** — Extracts the field name from a JSON unknown-field error.
- **`IsForeignKey(err)`** — Checks if an error is a foreign key constraint violation.

## Usage Example

```go
// Return a bad request error with a loggable internal cause
if err := validateInput(req); err != nil {
    return &BadRequestError{
        Message:     "invalid host identifier",
        InternalErr: err,
    }
}

// Wrap a service error with a friendly message and custom status
if err := svc.CreateTeam(ctx, team); err != nil {
    return NewUserMessageError(err, http.StatusConflict)
}

// Create an auth failure with an internal-only reason
return NewAuthFailedError("token expired for user " + userID)
```
