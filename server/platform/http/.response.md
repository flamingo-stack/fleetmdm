Defines shared HTTP response types for bounded contexts within the Fleet MDM service layer.

## Key Components

### `Errorer` Interface

An interface implemented by HTTP response types that may carry errors. It exposes a single method:

```go
Error() error
```

## Usage Example

Implement `Errorer` on a response struct to allow transport-layer error handling to inspect whether a response carries a domain error:

```go
type createDeviceResponse struct {
    Device *fleet.Device `json:"device,omitempty"`
    Err    error         `json:"error,omitempty"`
}

func (r createDeviceResponse) Error() error {
    return r.Err
}
```

Transport handlers can then use a type assertion to check for errors before encoding the response:

```go
if e, ok := response.(http.Errorer); ok && e.Error() != nil {
    encodeError(ctx, e.Error(), w)
    return
}
```

## Notes

- This pattern follows the [Go kit](https://gokit.io/) transport design, separating domain errors from HTTP status codes.
- All response structs in bounded contexts that may return errors should implement this interface to ensure consistent error propagation at the transport layer.
