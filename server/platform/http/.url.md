Provides utilities for redacting sensitive information from URLs before logging or returning errors.

## Key Components

- **`MaskSecretURLParams(rawURL string) string`** — Parses a raw URL string and replaces the values of any query parameters whose names contain `secret`, `token`, `key`, or `password` with `"MASKED"`. Returns the URL unchanged if it cannot be parsed.

- **`MaskURLError(e error) error`** — Unwraps a `*url.Error` (e.g., from failed HTTP requests) and applies `MaskSecretURLParams` to its embedded URL field. Returns the original error unmodified if it is not a `*url.Error`.

## Usage Example

```go
// Mask sensitive query parameters in a URL string
raw := "https://api.example.com/auth?api_key=supersecret&user=alice"
safe := http.MaskSecretURLParams(raw)
// safe: "https://api.example.com/auth?api_key=MASKED&user=alice"

// Mask a url.Error returned by a failed HTTP request
_, err := http.Get("https://api.example.com/data?token=abc123")
if err != nil {
    safeErr := http.MaskURLError(err)
    log.Println(safeErr) // token value replaced with MASKED
}
```

## Notes

- Parameter name matching is **case-insensitive** and uses substring matching (e.g., `mySecretKey` would be masked).
- Uses `url.URL.Redacted()` as the final step, which additionally masks any credentials embedded in the URL's userinfo (`user:password@host`).
- Safe to call with non-URL strings — unparseable input is returned as-is.
