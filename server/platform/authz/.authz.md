Provides a minimal, dependency-free authorization interface layer for bounded contexts, enabling authorization checks without coupling to legacy Fleet packages.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Action` | `type string` | Typed constant representing an authorization action (`read`, `list`) |
| `Authorizer` | `interface` | Core interface for performing authorization checks against a context-bound user |
| `AuthzTyper` | `interface` | Implemented by domain subjects to declare their authorization type string |
| `Forbidden` | `interface` | Marker interface for errors that represent a forbidden/denied authorization result |
| `IsForbidden` | `func` | Unwraps an error chain to detect any `Forbidden` authorization error |

## Usage Example

```go
// 1. Implement AuthzTyper on a domain subject
type Device struct{ ID string }
func (d *Device) AuthzType() string { return "device" }

// 2. Perform an authorization check
func GetDevice(ctx context.Context, az authz.Authorizer, id string) (*Device, error) {
    d := &Device{ID: id}
    if err := az.Authorize(ctx, d, authz.ActionRead); err != nil {
        return nil, err
    }
    return d, nil
}

// 3. Inspect the error type at the call site
if authz.IsForbidden(err) {
    // return HTTP 403
}
```

## Notes

- **No Fleet dependencies** — safe to import from any bounded context without introducing circular imports.
- `IsForbidden` uses `errors.As`, so it correctly unwraps sentinel errors returned by middleware or decorators.
- New `Action` constants should be added here as bounded contexts require them (e.g., `ActionWrite`, `ActionDelete`).
