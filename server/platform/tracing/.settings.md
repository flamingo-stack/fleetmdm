Defines the `Settings` struct for runtime-tunable distributed trace head-sampling configuration, backed by the `trace_sampler_settings` singleton database row and polled periodically by each Fleet replica.

## Key Components

### `Settings` struct

| Field | Type | Description |
|---|---|---|
| `HighVolumeRatio` | `float64` | Sampling ratio applied to high-volume trace paths |
| `StandardRatio` | `float64` | Sampling ratio applied to standard trace paths |
| `ForceFull` | `bool` | When `true`, overrides ratios and forces 100% sampling |
| `UpdatedAt` | `time.Time` | Timestamp of last update; zero-valued on PATCH responses via `omitzero` |

## Usage Example

```go
// Read current settings from the database singleton row
settings := tracing.Settings{
    HighVolumeRatio: 0.05,  // sample 5% of high-volume spans
    StandardRatio:   0.25,  // sample 25% of standard spans
    ForceFull:       false,
    UpdatedAt:       time.Now(),
}

// PATCH handler zeroes UpdatedAt before echoing back to caller;
// omitzero ensures the field is omitted from JSON output when zero.
settings.UpdatedAt = time.Time{}
out, _ := json.Marshal(settings) // "updated_at" key absent
```

## Notes

- Settings are **hot-reloadable** — Fleet replicas poll the DB row so support teams can adjust sampling ratios without a service restart.
- The `omitzero` tag on `UpdatedAt` is a non-standard extension (e.g. `encoding/json/v2` / `segmentio/encoding`); confirm your JSON library supports it.
