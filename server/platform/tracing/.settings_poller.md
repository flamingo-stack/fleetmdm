Runs a background polling loop that periodically reads trace sampler settings from the datastore and applies them to a `RouteTierSampler` when values change.

## Key Components

- **`settingsPollInterval`** – Poll cadence constant (60s), aligned with feature-flag style runtime config conventions.
- **`pollTracer`** – OTel tracer used to instrument each poll iteration; falls back to a no-op when OTEL is unconfigured.
- **`settingsReader`** – Minimal interface exposing only `GetTraceSamplerSettings`, keeping the poller decoupled from the full datastore and easy to test.
- **`StartSettingsPoller`** – Blocking function that performs an immediate read on startup, then ticks every 60s. Calls `sampler.Apply` only when `HighVolumeRatio`, `StandardRatio`, or `ForceFull` actually change. Exits cleanly when `ctx` is cancelled.

## Usage Example

```go
ctx, cancel := context.WithCancel(context.Background())
defer cancel()

sampler := tracing.NewRouteTierSampler()
logger := slog.Default()

go tracing.StartSettingsPoller(ctx, sampler, datastoreImpl, logger)
```

> The first read is synchronous before the ticker starts, so the sampler reflects persisted settings immediately at startup rather than waiting a full 60s interval. If the initial read fails, compile-time defaults are preserved and the next tick retries automatically.

## Notes

- `settingsReader` accepts any type implementing `GetTraceSamplerSettings`; pass a mock in tests to avoid a real datastore.
- Each poll iteration creates its own OTel span with `trace.WithNewRoot()`, keeping poll traces independent of the caller's trace context.
