Provides a thread-safe registry that maps HTTP route span names to sampling tiers, enabling per-route trace sampling decisions within Fleet's distributed tracing infrastructure.

## Key Components

### Types

- **`Tier`** — Integer enum classifying spans for sampling. Four values in ascending priority:
  - `TierAlways` (default/catch-all, 100% sampled)
  - `TierHighVolume` (aggressively downsampled, ~0.1%)
  - `TierStandard` (moderately downsampled, ~2%)
  - `TierNever` (unconditionally dropped, e.g. liveness probes)

### `Registry`

A concurrent-safe map of normalized route keys to `Tier` values.

| Method | Description |
|---|---|
| `NewRegistry()` | Returns a new empty registry |
| `Register(method, path, tier)` | Classifies a route; overwrites on re-registration |
| `Lookup(spanName)` | Returns the `Tier` and presence bool for a span name |

### Normalization

Two compiled regexes applied in `normalizeSpanName` before every read and write:

- **`versionTemplatePattern`** — Replaces `{fleetversion:...}` with `_version_`
- **`muxParamRegexPattern`** — Strips regex constraints, e.g. `{id:[0-9]+}` → `{id}`

This keeps registrations decoupled from gorilla/mux template internals and ensures lookups match regardless of which form was used at registration time.

## Usage Example

```go
reg := tracing.NewRegistry()

// Register high-volume osquery routes at startup
reg.Register("POST", "/api/_version_/osquery/distributed/read", tracing.TierHighVolume)
reg.Register("POST", "/api/_version_/osquery/distributed/write", tracing.TierHighVolume)

// Drop liveness probes unconditionally
reg.Register("GET", "/healthz", tracing.TierNever)

// Sampler queries per span
tier, found := reg.Lookup("POST /api/v1/osquery/distributed/read")
// tier == TierHighVolume, found == true
```

Routes not registered return `(TierAlways, false)`, ensuring unregistered load-bearing flows are sampled at 100% by safe default.
