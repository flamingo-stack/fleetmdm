Implements a two-tier, atomically-updatable OpenTelemetry trace sampler that routes spans to different sampling rates based on a route's registered tier.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `DefaultHighVolumeRatio` | `const` | Default 0.1% sample rate for high-traffic routes |
| `DefaultStandardRatio` | `const` | Default 2% sample rate for standard routes |
| `RouteTierSampler` | `struct` | Implements `sdktrace.Sampler`; holds an `atomic.Pointer` to live state and a `*Registry` for tier lookups |
| `samplerState` | `struct` | Immutable snapshot of all four inner samplers plus the `forceFull` flag; swapped atomically on settings change |
| `NewRouteTierSampler` | `func` | Constructs a sampler seeded with default ratios and `forceFull=false` |
| `Apply` | `method` | Atomically replaces sampler state; clamps out-of-range ratios to `[0, 1]` |
| `ShouldSample` | `method` | Routes each span to the correct inner sampler based on tier; `TierNever` wins over `forceFull` |
| `Description` | `method` | Returns a diagnostic string consumed by the OTel SDK for logging |
| `samplerRatio` | `func` | Parses the ratio back from a `TraceIDRatioBased` sampler's description string |

## Usage Example

```go
reg := tracing.NewRegistry()
reg.Register("/api/v1/hosts", tracing.TierHighVolume)
reg.Register("/api/v1/config", tracing.TierStandard)

sampler := tracing.NewRouteTierSampler(reg)

// Later: SettingsPoller calls this after reading DB row
sampler.Apply(0.005, 0.05, false)

// Wire into the OTel SDK
tp := sdktrace.NewTracerProvider(
    sdktrace.WithSampler(sampler),
)
```

**Tier precedence (highest → lowest):**

```text
TierNever → always drop (liveness probes)
forceFull=true → always sample
TierHighVolume → highVolume ratio sampler
TierStandard → standard ratio sampler
TierAlways / unregistered → always sample
```

## Notes

- State swaps are lock-free via `atomic.Pointer[samplerState]`; `ShouldSample` never blocks on settings updates.
- `samplerRatio` parses the OTel SDK's description string (`TraceIDRatioBased{0.001}`) as the SDK does not expose the ratio field directly; it is used only for `Description()` output.
