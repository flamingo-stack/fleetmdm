Generic batch processing utility for slicing a payload slice into fixed-size chunks and executing a provided function on each chunk sequentially.

## Key Components

### `BatchProcessSimple[T any]`

A generic function that iterates over a slice in batches, calling `executeBatch` for each chunk. Stops and returns early on the first error. Gracefully handles edge cases: empty payloads, non-positive batch sizes, and nil callbacks all return `nil` immediately.

| Parameter | Type | Description |
|---|---|---|
| `payloads` | `[]T` | The full slice to process |
| `batchSize` | `int` | Maximum number of items per batch |
| `executeBatch` | `func([]T) error` | Callback invoked with each batch slice |

## Usage Example

```go
ids := []int{1, 2, 3, 4, 5, 6, 7}

err := mysql.BatchProcessSimple(ids, 3, func(batch []int) error {
    // e.g. bulk insert batch into DB
    return db.InsertIDs(batch)
})
if err != nil {
    log.Fatal(err)
}
// Executes 3 batches: [1,2,3], [4,5,6], [7]
```

## Notes

- The last batch will be smaller than `batchSize` when `len(payloads)` is not evenly divisible.
- Batches are processed **sequentially** — there is no parallelism.
- Returns the **first error** encountered; remaining batches are skipped.
