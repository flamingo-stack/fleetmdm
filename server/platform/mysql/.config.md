Defines lightweight local copies of MySQL connection and logging configuration structs for the `mysql` package, intentionally avoiding heavy upstream dependencies like the AWS SDK or Viper.

## Key Components

| Type | Description |
|------|-------------|
| `MysqlConfig` | Holds all MySQL connection parameters including credentials, TLS settings, and connection pool tuning |
| `LoggingConfig` | Holds tracing configuration for query logging |

### `MysqlConfig` Fields

| Field | Purpose |
|-------|---------|
| `Protocol` / `Address` | Network protocol and host:port |
| `Username` / `Password` / `PasswordPath` | Auth credentials (direct or file-based) |
| `Database` | Target database name |
| `TLSCert` / `TLSKey` / `TLSCA` / `TLSServerName` / `TLSConfig` | Mutual TLS configuration |
| `MaxOpenConns` / `MaxIdleConns` / `ConnMaxLifetime` | Connection pool tuning |
| `SQLMode` | MySQL `sql_mode` override |
| `Region` | AWS region for IAM-based auth |

### `LoggingConfig` Fields

| Field | Purpose |
|-------|---------|
| `TracingEnabled` | Enables query tracing |
| `TracingType` | Tracing backend identifier |

## Usage Example

```go
cfg := mysql.MysqlConfig{
    Protocol:        "tcp",
    Address:         "localhost:3306",
    Username:        "fleet",
    Password:        "secret",
    Database:        "fleet",
    MaxOpenConns:    50,
    MaxIdleConns:    10,
    ConnMaxLifetime: 300,
}

logCfg := mysql.LoggingConfig{
    TracingEnabled: true,
    TracingType:    "elasticapm",
}
```

> **Note:** These structs are intentional local copies of `server/config.MysqlConfig` and `server/config.LoggingConfig`. If fields are added upstream, they must be manually mirrored here. See the full server config at [`server/config/config.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/config/config.go).
