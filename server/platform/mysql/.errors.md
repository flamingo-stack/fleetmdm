Defines MySQL-specific error types and utilities for the Fleet datastore layer, including a `NotFoundError` struct and read-only error detection.

## Key Components

- **`NotFoundError`** — Struct implementing `platform_errors.NotFoundError` for missing datastore resources, with optional ID, FleetID, name, or message context
- **`NotFound(kind string)`** — Constructor returning a new `*NotFoundError` for the given resource type
- **`WithID` / `WithFleetID` / `WithName` / `WithMessage`** — Builder methods to attach lookup context to a `NotFoundError`
- **`IsNotFound() / IsClientError()`** — Interface satisfaction methods marking the error as a client-facing not-found error
- **`Is(other error)`** — Makes `errors.Is(err, sql.ErrNoRows)` return `true` for `*NotFoundError` without explicit wrapping
- **`IsReadOnlyError(err error)`** — Detects MySQL read-only errors (codes 1290, 1792, 1836), useful for handling Aurora failover scenarios

## Usage Example

```go
// Constructing a not-found error
err := mysql.NotFound("host").WithID(42)
fmt.Println(err) // "host 42 was not found in the datastore"

// Check compatibility with sql.ErrNoRows
errors.Is(err, sql.ErrNoRows) // true

// Detecting read-only MySQL state (e.g., after Aurora failover)
if mysql.IsReadOnlyError(err) {
    log.Warn("MySQL is in read-only mode, retrying against primary...")
}

// Using name-based lookup failure
err = mysql.NotFound("policy").WithName("CIS Benchmark")
fmt.Println(err) // "policy CIS Benchmark was not found in the datastore"
```

## Notes

- Read-only error constants (`erReadOnlyTransaction`, `erOptionPreventsStatement`, `erReadOnlyMode`) are defined locally as they are absent from the `mysqlerr` package
- `IsReadOnlyError` unwraps context errors via `ctxerr.Cause` before inspecting the underlying `*mysql.MySQLError`
