Provides shared test utilities for MySQL-backed datastore tests, including database setup, schema loading, table truncation, and test configuration helpers.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TestUsername` / `TestPassword` | `const` | Default MySQL test credentials (`root`/`toor`) |
| `TestAddress` | `var` | Primary MySQL test server address (env: `FLEET_MYSQL_TEST_PORT`, default `localhost:3307`) |
| `TestReplicaAddress` | `var` | Replica MySQL test server address (env: `FLEET_MYSQL_REPLICA_TEST_PORT`, default `localhost:3310`) |
| `DatastoreTestOptions` | `struct` | Configures test datastore creation (dummy/real replica, replication function, unique name) |
| `TruncateTables` | `func` | Truncates specified tables (or all non-seeded tables) with FK checks disabled |
| `LoadDefaultSchema` | `func` | Loads the default `schema.sql` into the test database |
| `LoadSchema` | `func` | Loads a schema from a given path via `docker compose exec mysql_test` |
| `MysqlTestConfig` | `func` | Returns a `MysqlConfig` for a named test database |
| `ProcessOptions` | `func` | Validates env vars, derives a clean test name, enables parallelism, skips if MySQL not enabled |

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    testName, opts := testing_utils.ProcessOptions(t, &testing_utils.DatastoreTestOptions{
        DummyReplica: true,
    })

    testing_utils.LoadDefaultSchema(t, testName, opts)

    db, err := sqlx.Open("mysql", /* dsn */)
    require.NoError(t, err)

    // Run test logic...

    testing_utils.TruncateTables(t, db, logger, nonEmptyTables)
}
```

> **Environment Variables:**
> - `MYSQL_TEST` — must be set to enable MySQL tests
> - `MYSQL_REPLICA_TEST` — must be set to enable replica tests
> - `DISABLE_TRUNCATE_TABLES` — skip truncation for manual inspection
> - `FLEET_MYSQL_TEST_PORT` / `FLEET_MYSQL_REPLICA_TEST_PORT` — override default ports
