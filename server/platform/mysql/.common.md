Provides shared MySQL database connection utilities, transaction helpers, and configuration types used across the Fleet MySQL datastore layer.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ConnectorFactory` | `type` | Function type for creating custom `driver.Connector` implementations (e.g., AWS IAM auth) |
| `TestSQLMode` | `const` | ANSI + MySQL 8 strict SQL mode string for test environments |
| `DBOptions` | `struct` | Connection configuration including retry attempts, tracing, interceptors, and optional `ConnectorFactory` |
| `DBConnections` | `struct` | Holds primary/replica `*sqlx.DB` connections and shared options for multi-datastore reuse |
| `DBReadTx` | `interface` | Minimal read-only transaction interface exposing `QueryerContext`, `PreparerContext`, and `Rebind` |
| `NewDB` | `func` | Creates and validates a `*sqlx.DB` with retry logic, OTel metric registration, and optional custom connectors |
| `generateMysqlConnectionString` | `func` | Builds a MySQL DSN with opinionated defaults (UTF-8, UTC, IAM cleartext support) |
| `WithTxx` | `func` | Executes a function within a read-write transaction with automatic rollback and fatal error detection |
| `WithReadOnlyTxx` | `func` | Executes a function within a `REPEATABLE READ`, read-only transaction |
| `GetDefaultNonZeroTime` | `func` | Returns `2000-01-01 UTC` as a safe non-zero MySQL timestamp default |

## Usage Example

```go
// Create a new database connection with retry and OTel tracing
db, err := mysql.NewDB(&mysql.MysqlConfig{
    Username: "fleet",
    Password: "secret",
    Address:  "localhost:3306",
    Database: "fleet",
    Protocol: "tcp",
}, &mysql.DBOptions{
    MaxAttempts: 5,
    Logger:      slog.Default(),
    TracingConfig: &mysql.LoggingConfig{
        TracingEnabled: true,
        TracingType:    "otel",
    },
}, "otel/mysql")

// Execute a read-write transaction
err = mysql.WithTxx(ctx, db, func(tx sqlx.ExtContext) error {
    _, err := tx.ExecContext(ctx, "INSERT INTO hosts (hostname) VALUES (?)", "my-host")
    return err
}, slog.Default())

// Execute a read-only transaction
err = mysql.WithReadOnlyTxx(ctx, db, func(tx mysql.DBReadTx) error {
    return tx.QueryRowxContext(ctx, "SELECT id FROM hosts LIMIT 1").Scan(&id)
}, slog.Default())
```

## Notes

- `ConnectorFactory` enables AWS RDS IAM authentication without coupling this package to AWS SDKs.
- `WithTxx` calls `TriggerFatalError` on read-only errors to surface replica-routing misconfigurations.
- DSN generation automatically sets `tls=rdsmysql` when using IAM (no password + region present).
