Rate limiting middleware for Fleet's HTTP endpoints, providing both quota-based and IP-ban-based request throttling using the GCRA algorithm.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Middleware` | struct | Quota-based rate limiter backed by a `throttled.GCRAStore` |
| `NewMiddleware` | func | Initializes `Middleware` with a required store (panics on nil) |
| `Middleware.Limit` | method | Returns an `endpoint.Middleware` enforcing a named `RateQuota` |
| `ErrorMiddleware` | struct | IP-based rate limiter that only penalizes failed requests |
| `NewErrorMiddleware` | func | Initializes `ErrorMiddleware` with a required `IPBanner` |
| `ErrorMiddleware.Limit` | method | Returns an `endpoint.Middleware` that bans IPs with excessive errors |
| `IPBanner` | interface | Abstraction for checking/updating IP ban state |
| `Error` | interface | Extends `error` with `Result() throttled.RateLimitResult` |
| `rateLimitError` | struct | Internal error type returning HTTP 429 with retry timing |

## Usage Example

```go
// Quota-based middleware (e.g. Redis-backed GCRA)
store, _ := redigostore.New(pool, "ratelimit:", 0)
rl := ratelimit.NewMiddleware(store)

quota := throttled.RateQuota{
    MaxRate:  throttled.PerMin(60),
    MaxBurst: 5,
}

limitedEndpoint := rl.Limit("login", quota)(myEndpoint)

// Error/IP-ban middleware
errMiddleware := ratelimit.NewErrorMiddleware(myIPBanner)
protectedEndpoint := errMiddleware.Limit(logger)(myEndpoint)
```

## Notes

- Both middlewares call `authz_ctx.SetChecked()` on error/ban paths to prevent downstream HTTP 500 responses from unchecked authorization state.
- `ErrorMiddleware` groups requests with no resolvable public IP into a single shared bucket.
- `rateLimitError` implements `StatusCode() int` (→ 429) and `RetryAfter() int` for HTTP response header population.
