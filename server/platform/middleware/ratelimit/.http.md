HTTP-level rate limiting middleware using GCRA (Generic Cell Rate Algorithm) with real client IP detection for accurate per-client throttling behind proxies.

## Key Components

| Component | Description |
|---|---|
| `clientIPVaryBy` | Implements `throttled.VaryBy` to key rate limits by real client IP, falling back to `RemoteAddr` if extraction fails |
| `DefaultHTTPRateQuota()` | Returns a default quota of 10 req/min with a burst of 9 |
| `NewHTTPRateLimiter()` | Constructs a `throttled.HTTPRateLimiter` wired to a GCRA store and IP strategy |

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/server/ratelimit"
    "github.com/throttled/throttled/v2/store/memstore"
)

// Create an in-memory GCRA store
store, err := memstore.New(65536)
if err != nil {
    log.Fatal(err)
}

// Build an IP strategy from trusted proxy config
ipStrategy, err := endpointer.NewClientIPStrategy(trustedProxies)
if err != nil {
    log.Fatal(err)
}

// Use default quota (10 req/min, burst 9) or define a custom one
quota := ratelimit.DefaultHTTPRateQuota()

// Create the rate limiter
limiter, err := ratelimit.NewHTTPRateLimiter(store, quota, ipStrategy)
if err != nil {
    log.Fatal(err)
}

// Wrap your HTTP handler
http.Handle("/api/", limiter.RateLimit(myHandler))
```

## Notes

- Uses the [`realclientip-go`](https://github.com/realclientip/realclientip-go) library to correctly resolve client IPs behind load balancers or reverse proxies, preventing all traffic from being attributed to a single proxy IP.
- The `ipStrategy` should be configured via `trusted_proxies` server settings to match your deployment topology.
- For custom quotas, use `throttled.PerSec`, `throttled.PerMin`, or `throttled.PerHour` alongside `throttled.RateQuota`.
