Implements a Go-kit endpoint middleware that enforces authorization checks were performed during request handling, acting as a safety net for missed authorization logic.

## Key Components

- **`Middleware`** — Struct representing the authzcheck middleware instance.
- **`NewMiddleware()`** — Constructor returning a new `*Middleware`.
- **`AuthzCheck()`** — Returns a `endpoint.Middleware` that wraps each endpoint to verify an authorization check occurred.

## Behavior

The middleware injects an `AuthorizationContext` into every request context. After the wrapped endpoint returns, it inspects the context to determine if an authorization check was performed:

- **Auth-specific errors** (`AuthFailedError`, `AuthRequiredError`, `AuthHeaderRequiredError`, `ErrPasswordResetRequired`) are passed through as-is to preserve correct logging.
- **No auth check performed** — If `authzctx.Checked()` returns `false`, the middleware returns a `CheckMissingWithResponse` error, indicating an authorization bug in the handler.
- **Normal flow** — If the check was performed, the original response and error are returned unchanged.

## Usage Example

```go
mw := authzcheck.NewMiddleware()

myEndpoint := mw.AuthzCheck()(func(ctx context.Context, req interface{}) (interface{}, error) {
    // Handler must call an authorization check or the middleware
    // will return an authorization error.
    if err := svc.Authorize(ctx, req); err != nil {
        return nil, err
    }
    return handleRequest(ctx, req)
})
```

> **Note:** This middleware validates that *some* authorization check was made, not that the *correct* check was made. Handlers are still responsible for performing the appropriate policy checks.
