A `slog.Handler` implementation that captures log records in memory for use in unit tests, enabling assertion-based log verification without parsing serialized output.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `TestHandler` | `struct` | Thread-safe `slog.Handler` that stores `slog.Record` entries in a shared slice |
| `NewTestHandler` | `func` | Constructs a new `TestHandler` with initialized mutex and record slice |
| `Handle` | `method` | Clones and appends each incoming record, prepending any pre-set attributes |
| `WithAttrs` | `method` | Returns a derived handler with additional attributes merged via `slices.Concat` |
| `WithGroup` | `method` | Returns a derived handler carrying a group name (shared record destination) |
| `Records` | `method` | Returns a safe clone of all captured records |
| `LastRecord` | `method` | Returns a pointer to the most recent record, or `nil` |
| `Clear` | `method` | Resets the shared record slice to `nil` |
| `RecordAttrs` | `func` | Helper that flattens a record's attributes into a `map[string]any` |

## Usage Example

```go
func TestMyLogger(t *testing.T) {
    handler := testutils.NewTestHandler()
    logger := slog.New(handler)

    logger.Info("user created", "id", 42, "role", "admin")

    last := handler.LastRecord()
    if last == nil {
        t.Fatal("expected a log record")
    }

    if last.Message != "user created" {
        t.Errorf("unexpected message: %s", last.Message)
    }

    attrs := testutils.RecordAttrs(last)
    if attrs["id"] != int64(42) {
        t.Errorf("unexpected id attr: %v", attrs["id"])
    }

    // Clear between sub-tests
    handler.Clear()

    logger.WithGroup("request").
        With("trace_id", "abc123").
        Warn("slow query")

    if len(handler.Records()) != 1 {
        t.Errorf("expected 1 record, got %d", len(handler.Records()))
    }
}
```

> **Thread safety:** `mu` and `records` are pointer fields shared across `WithAttrs`/`WithGroup` derivations, so all child handlers write to the same record slice — mirroring how production handlers share an `io.Writer` while maintaining independent attribute chains.
