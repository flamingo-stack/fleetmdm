A `slog.Handler` wrapper that filters log records based on a `log_topic` attribute, suppressing records whose topic is disabled via `TopicEnabled`.

## Key Components

- **`TopicFilterHandler`** — Wraps any `slog.Handler` and intercepts records containing a `log_topic` attribute, dropping them if the topic is disabled.
- **`NewTopicFilterHandler(base slog.Handler)`** — Constructs a `TopicFilterHandler` wrapping the provided base handler.
- **`Handle`** — Extracts `log_topic` from the record's attributes (overriding any topic set on the handler itself), then calls `TopicEnabled` before delegating to the base handler.
- **`WithAttrs`** — Returns a new `TopicFilterHandler`; if the attributes include `log_topic`, that value is captured on the new handler instance.
- **`WithGroup`** — Propagates group scoping to the base handler while preserving the current topic.

## Usage Example

```go
// Wrap an existing slog handler with topic filtering
baseHandler := slog.NewJSONHandler(os.Stdout, nil)
topicHandler := logging.NewTopicFilterHandler(baseHandler)
logger := slog.New(topicHandler)

// Records with a disabled log_topic are silently dropped
logger.Info("syncing devices", "log_topic", "mdm_sync", "count", 42)

// Topic can also be attached via WithAttrs for a scoped logger
mdmLogger := logger.With("log_topic", "mdm_sync")
mdmLogger.Info("this is filtered if mdm_sync is disabled")
```

The `log_topic` attribute on the record always takes precedence over one set via `WithAttrs`, allowing per-call topic overrides within a scoped logger.
