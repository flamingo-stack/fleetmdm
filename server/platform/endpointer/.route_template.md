Provides utilities for capturing and retrieving the `gorilla/mux` route template from a request context, primarily used for request telemetry and routing metadata.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `RouteTemplateRequestFunc` | `func` | Middleware-style function that extracts the matched mux route template from an incoming request and stores it in the context |
| `RouteTemplateFromContext` | `func` | Retrieves the previously stored route template string from a context |
| `WithRouteTemplate` | `func` | Injects a route template directly into a context; intended for test environments |
| `routeTemplateKey` | `contextKeyRouteTemplate` | Unexported, typed context key to avoid collisions |

## Usage Example

```go
// In a go-kit transport layer, register as a ServerRequestFunc:
kithttp.NewServer(
    endpoint,
    decodeRequest,
    encodeResponse,
    kithttp.ServerBefore(endpointer.RouteTemplateRequestFunc),
)

// Later, in a middleware or handler, read the template:
func myMiddleware(ctx context.Context) {
    tpl, ok := endpointer.RouteTemplateFromContext(ctx)
    if ok {
        // e.g. "GET /api/v1/hosts/{id}" — use for metrics labeling
        metrics.RecordRequest(tpl)
    }
}

// In tests, simulate a matched route without a real mux router:
func TestHandler(t *testing.T) {
    ctx := endpointer.WithRouteTemplate(context.Background(), "/api/v1/hosts/{id}")
    tpl, ok := endpointer.RouteTemplateFromContext(ctx)
    // tpl == "/api/v1/hosts/{id}", ok == true
}
```

## Notes

- `RouteTemplateRequestFunc` is a no-op if no route is matched or the route has no path template, making it safe to use unconditionally.
- The typed `contextKeyRouteTemplate` key prevents accidental collisions with other string-keyed context values.
