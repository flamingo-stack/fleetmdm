Provides client IP extraction strategies configurable via `trusted_proxies` settings, wrapping the `realclientip-go` library to support multiple proxy trust models.

## Key Components

### `NewClientIPStrategy(trustedProxies string) (realclientip.Strategy, error)`
Factory function that returns a `realclientip.Strategy` based on the `trusted_proxies` configuration value:

| Config Value | Behavior |
|---|---|
| `""` (empty) | Legacy mode — trusts `True-Client-IP`, `X-Real-IP`, leftmost `X-Forwarded-For` |
| `"none"` | Uses only `RemoteAddr`, ignores all headers |
| `"header:<name>"` | Trusts a single named IP header, falls back to `RemoteAddr` |
| `"2"` (integer) | Trusts `X-Forwarded-For` with N rightmost proxy hops |
| `"10.0.0.0/8,..."` | Trusts `X-Forwarded-For` from specific IP/CIDR ranges |

### `legacyStrategy`
Internal struct implementing `realclientip.Strategy` for backwards-compatible behavior. Delegates to the existing `extractIP` function via a minimal `http.Request`.

## Usage Example

```go
// Direct connection — no proxy headers trusted
strategy, err := NewClientIPStrategy("none")

// Single trusted header (e.g., set by a load balancer)
strategy, err := NewClientIPStrategy("header:True-Client-IP")

// Trust X-Forwarded-For with 2 proxy hops
strategy, err := NewClientIPStrategy("2")

// Trust X-Forwarded-For from specific proxy ranges
strategy, err := NewClientIPStrategy("10.0.0.0/8,192.168.0.0/16")

if err != nil {
    log.Fatal(err)
}

clientIP := strategy.ClientIP(r.Header, r.RemoteAddr)
```

> **Deprecation Note:** The empty string (`""`) legacy mode is retained for backwards compatibility only. Use `"none"` for servers directly exposed to the internet.
