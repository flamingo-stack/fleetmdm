Streaming JSON key aliasing and rewriting for handling deprecated field name migrations in JSON requests and responses.

## Key Components

### Types

- **`AliasConflictError`** — Error returned when both the deprecated (`OldKey`) and replacement (`NewKey`) field names appear in the same JSON object scope.
- **`AliasRule`** — Defines a key-rename pair (`OldKey` → `NewKey`). The optional `Inline` flag controls response-encoding duplication behavior for nested containers.
- **`JSONKeyRewriteReader`** — An `io.Reader` that wraps a JSON source, rewrites `NewKey` names to `OldKey` on the fly, tracks deprecated key usage, and detects alias conflicts.

### Functions

- **`NewJSONKeyRewriteReader(src io.Reader, rules []AliasRule)`** — Constructs a `JSONKeyRewriteReader`, processes the full source stream into an internal buffer, and returns an error-aware reader.
- **`UsedDeprecatedKeys() []string`** — Returns the list of deprecated (`OldKey`) names encountered during processing.
- **`RewriteDeprecatedKeys(data []byte, rules []AliasRule)`** — Standalone function that rewrites `NewKey` → `OldKey` in a raw JSON byte slice, also returning a map of deprecated keys used.
- **`RewriteOldToNewKeys(data []byte, rules []AliasRule)`** — Reverse of `RewriteDeprecatedKeys`; rewrites `OldKey` → `NewKey` for forward-compatible response payloads.

## Usage Example

```go
rules := []AliasRule{
    {OldKey: "team_id", NewKey: "fleet_id"},
}

// Rewrite incoming request body so both "fleet_id" and "team_id" deserialize correctly.
reader := NewJSONKeyRewriteReader(req.Body, rules)

var payload MyStruct
if err := json.NewDecoder(reader).Decode(&payload); err != nil {
    // handle decode error
}

// Check for deprecated field usage to emit warnings.
for _, key := range reader.UsedDeprecatedKeys() {
    log.Warnf("Deprecated field %q used in request", key)
}

// Rewrite a stored payload back to new key names for response.
newBody, err := RewriteOldToNewKeys(storedJSON, rules)
```

## Notes

- The `software` subtree (keyed by `softwareScopeKey`) is explicitly excluded from key rewriting to avoid collisions with unrelated fields that share names with rename targets (see [#44970](https://github.com/flamingo-stack/fleetmdm/issues/44970)).
- Token-level processing is delegated to [`github.com/go-json-experiment/json/jsontext`](https://pkg.go.dev/github.com/go-json-experiment/json/jsontext), ensuring correct handling of unicode, escape sequences, and whitespace.
