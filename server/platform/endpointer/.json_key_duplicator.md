Token-level JSON processor that duplicates object keys under both their legacy and renamed names to maintain backward compatibility during API key migrations.

## Key Components

### `DuplicateJSONKeysOpts`
Configuration struct with a `Compact` flag to disable default two-space indented output.

### `DuplicateJSONKeys(data []byte, rules []AliasRule, opts ...DuplicateJSONKeysOpts) []byte`
Public entry point. Accepts marshaled JSON and a slice of `AliasRule` values. For each rule mapping `OldKey → NewKey`, both key names appear in the output with their respective values.

### `duplicateJSONKeys(data []byte, rules []AliasRule, compact bool) []byte`
Recursive core implementation. Uses `jsontext.Decoder`/`Encoder` for token-level streaming. Maintains a `scopes` stack to defer duplicate emission until each object's closing `}`, allowing natural occurrences of new keys to suppress duplication.

### `startsWithContainer(v []byte) bool`
Helper that reports whether a raw JSON value is an object `{}` or array `[]` rather than a scalar, used to determine whether inline recursive processing applies.

## Usage Example

```go
rules := []AliasRule{
    {OldKey: "team_id", NewKey: "fleet_id"},
    {OldKey: "abm_tokens", NewKey: "abm_fleet_tokens", Inline: true},
}

input := []byte(`{"team_id": 42, "abm_tokens": {"macos_team": 1}}`)
output := DuplicateJSONKeys(input, rules)
// output contains both "team_id": 42 and "fleet_id": 42,
// plus both "abm_tokens" and "abm_fleet_tokens" subtrees.

// Compact output
output = DuplicateJSONKeys(input, rules, DuplicateJSONKeysOpts{Compact: true})
```

## Key Behaviors

| Scenario | Behavior |
|---|---|
| Renamed leaf | Both old and new keys appear as siblings with identical values |
| Renamed container (default) | Old subtree retains old names; new subtree gets all-new names via `RewriteOldToNewKeys` |
| Renamed container (`Inline: true`) | Old subtree is recursively re-processed so nested renames also appear under the old name |
| New key already present | Duplication skipped to prevent duplicate keys |
| Parse error | Original `data` returned unchanged |
