Handles HTTP transport-layer error encoding for the Fleet MDM API, mapping Go domain errors to appropriate JSON responses and HTTP status codes.

## Key Components

- **`ErrBadRoute`** — Sentinel error for mux/routing failures.
- **`DomainErrorEncoder`** — Function type allowing services to inject custom error handling before falling back to generic logic.
- **`JsonError`** — JSON response struct with `message`, `code`, `errors`, and `uuid` fields.
- **`baseError`** — Helper that wraps an error string into the `[]map[string]string` format expected by frontend clients.
- **`EncodeError`** — Core function that classifies errors by type and writes the correct HTTP status code and JSON body.

### Error Type Dispatch

| Error Interface / Type | HTTP Status |
|---|---|
| `validationErrorInterface` | `422` (or custom via `Status()`) |
| `permissionErrorInterface` | `403` |
| `NotFoundErrorInterface` | `404` |
| `ExistsErrorInterface` / `conflictErrorInterface` | `409` |
| `badRequestErrorInterface` | `400` |
| `*mysql.MySQLError` (1062) | `409`, otherwise `422` |
| `*net.OpError` (TCP timeout) | `408` |
| `context.Canceled` | `499` |
| `kithttp.StatusCoder` | Dynamic |
| Default | `500` |

## Usage Example

```go
func MakeHandler(svc MyService, domainEncoder endpointer.DomainErrorEncoder) http.Handler {
    return kithttp.NewServer(
        makeMyEndpoint(svc),
        decodeRequest,
        encodeResponse,
        kithttp.ServerErrorEncoder(func(ctx context.Context, err error, w http.ResponseWriter) {
            endpointer.EncodeError(ctx, err, w, domainEncoder)
        }),
    )
}
```
