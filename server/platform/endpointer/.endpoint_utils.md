Utility functions for HTTP endpoint handling in the Fleet MDM server, providing request decoding, IP extraction, struct field reflection, and alias rule management for the `endpointer` package.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `ParseTag` | func | Parses `url`/`query` struct tags into name, optional flag, and error |
| `allFields` | func | Returns all struct fields including embedded struct fields via reflection |
| `ExtractAliasRules` | func | Builds `[]AliasRule` from `renameto` struct tags; results cached by type |
| `BadRequestErr` | func | Wraps errors as `BadRequestError`, preserving timeout errors as-is |
| `UintFromRequest` | func | Extracts a `uint64` from mux route variables |
| `IntFromRequest` | func | Extracts an `int64` from mux route variables |
| `StringFromRequest` | func | Extracts a URL-unescaped string from mux route variables |
| `DecodeURLTagValue` | func | Decodes URL path parameters into struct fields by kind (int, uint, string) |
| `DecodeQueryTagValue` | func | Decodes query string parameters into struct fields, with deprecation warning support via `renameto` tags |
| `DomainQueryFieldDecoder` | type | Hook function for custom query parameter decoding |
| `extractIP` | func | Extracts client IP from request, preferring `True-Client-IP` → `X-Real-IP` → `X-Forwarded-For` |
| `HandlerRoutesFunc` | type | Alias for route registration callbacks |

## Usage Example

```go
// Decoding URL and query parameters from a tagged request struct
type listDevicesRequest struct {
    TeamID   uint   `url:"team_id"`
    Page     uint   `query:"page"`
    Platform string `query:"platform,optional"`
    // Deprecated: use "platform" instead
    OS string `query:"os" json:"os" renameto:"platform"`
}

func decodeListDevicesRequest(_ context.Context, r *http.Request) (interface{}, error) {
    var req listDevicesRequest
    for _, fp := range allFields(reflect.ValueOf(&req)) {
        if urlTag, ok := fp.Sf.Tag.Lookup("url"); ok {
            name, optional, _ := ParseTag(urlTag)
            if err := DecodeURLTagValue(r, fp.V, name, optional); err != nil {
                return nil, err
            }
        }
        if err := DecodeQueryTagValue(r, fp, nil, r.Context()); err != nil {
            return nil, err
        }
    }
    return req, nil
}

// Extracting alias rules for JSON body renaming
rules := ExtractAliasRules(&listDevicesRequest{})
// rules[0] == AliasRule{OldKey: "os", NewKey: "platform"}
```

## Notes

- `aliasRulesCache` uses `sync.Map` to ensure the reflection walk over struct types happens only once per type, safe for concurrent use.
- `DecodeQueryTagValue` enforces mutual exclusivity between deprecated (`query` tag) and new (`renameto` tag) parameter names, returning a `BadRequestError` if both are supplied.
- IP extraction follows CDN/proxy header precedence: `True-Client-IP` > `X-Real-IP` > `X-Forwarded-For` > `RemoteAddr`.
