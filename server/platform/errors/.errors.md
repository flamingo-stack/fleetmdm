Provides lightweight, transport-agnostic error classification primitives shared across the codebase, enabling low-level packages (datastores, context helpers) to classify errors without importing HTTP or other higher-level dependencies.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Cause` | Function | Traverses the error chain and returns the root (unwrapped) error |
| `ErrWithIsClientError` | Interface | Implemented by errors that distinguish client errors from server errors |
| `NotFoundError` | Interface | Implemented by errors representing a missing resource |
| `IsNotFound` | Function | Checks if any error in the chain satisfies `NotFoundError` |

## Usage Example

```go
package main

import (
    "fmt"
    flterrors "github.com/flamingo-stack/fleetmdm/server/fleet/errors"
)

// Implement NotFoundError
type deviceNotFound struct{ id string }

func (e *deviceNotFound) Error() string    { return "device not found: " + e.id }
func (e *deviceNotFound) IsNotFound() bool { return true }

func main() {
    err := fmt.Errorf("lookup failed: %w", &deviceNotFound{id: "abc-123"})

    // Unwrap to root cause
    root := flterrors.Cause(err)
    fmt.Println(root) // device not found: abc-123

    // Check for not-found anywhere in the chain
    if flterrors.IsNotFound(err) {
        fmt.Println("resource missing — return 404")
    }
}
```

## Notes

- **No transport dependencies** — safe to import from datastores, context helpers, or any low-level package.
- `ErrWithIsClientError` follows a convention where errors are assumed to be **server errors by default**; only errors explicitly implementing `IsClientError() bool` can declare themselves client errors.
- `IsNotFound` uses `errors.As`, so it correctly traverses wrapped error chains.
