Redis-backed store implementing the `ThrottledStore` type for rate limiting operations, providing atomic get-with-timestamp, conditional set, and compare-and-swap primitives against a Redis pool.

## Key Components

### `ThrottledStore`
Struct holding a `fleet.RedisPool` and a `KeyPrefix` string applied to all keys before Redis operations.

### Methods

| Method | Description |
|--------|-------------|
| `GetWithTime(key string)` | Atomically retrieves a key's value and the current Redis server time via a Lua script. Returns `(int64, time.Time, error)`; value is `-1` if the key does not exist. |
| `SetIfNotExistsWithTTL(key string, value int64, ttl time.Duration)` | Sets a key only if it does not already exist (`SET ... NX EX`). Returns `true` if the key was created, `false` if it already existed. Enforces a minimum TTL of 1 second. |
| `CompareAndSwapWithTTL(key string, old, isNew int64, ttl time.Duration)` | Atomically swaps a key's value from `old` to `isNew` only if the current value matches `old`, then resets the TTL. Returns `false` silently if the key is missing. Enforces a minimum TTL of 1 second. |

### Lua Scripts
- `getWithTimeScript` — Uses `redis.call('TIME')` + `GET` in a single atomic round-trip.
- `compareAndSwapWithTTLScript` — Performs a `GET`→compare→`SET EX` sequence atomically.

## Usage Example

```go
store := &ThrottledStore{
    Pool:      redisPool,
    KeyPrefix: "ratelimit:",
}

// Check current count and server timestamp
count, ts, err := store.GetWithTime("user:42")

// Initialize a counter if absent (first request in window)
created, err := store.SetIfNotExistsWithTTL("user:42", 1, time.Minute)

// Atomically increment counter with sliding TTL
swapped, err := store.CompareAndSwapWithTTL("user:42", count, count+1, time.Minute)
```
