Generates and caches AWS IAM authentication tokens for ElastiCache Redis connections using AWS Signature Version 4 presigned URLs.

## Key Components

| Symbol | Description |
|--------|-------------|
| `awsIAMAuthTokenGenerator` | Struct holding AWS credentials, signer, and token manager for ElastiCache auth |
| `newAWSIAMAuthTokenGenerator` | Constructor that loads AWS config (with optional role assumption) and initializes the token manager |
| `generateAuthToken` | Public entry point; returns a cached token or refreshes it via the token manager |
| `generateNewToken` | Builds a presigned `GET` request against the cluster endpoint, signs it with SigV4, and strips the `https://` prefix to produce the raw auth token |
| `emptySHA256` | Constant SHA-256 hash of an empty body, required by SigV4 for GET requests |

## Usage Example

```go
gen, err := newAWSIAMAuthTokenGenerator(
    "my-cluster",          // ElastiCache cluster name
    "fleet-user",          // IAM username
    "us-east-1",           // AWS region
    "arn:aws:iam::123:role/MyRole", // optional assume-role ARN
    "",                    // optional STS external ID
)
if err != nil {
    log.Fatal(err)
}

token, err := gen.generateAuthToken(context.Background())
if err != nil {
    log.Fatal(err)
}
// Use token as the Redis password
```

Tokens are presigned for **15 minutes** (`X-Amz-Expires=900`). The underlying `aws_common.IAMAuthTokenManager` handles proactive refresh so callers always receive a valid token without managing expiry themselves.
