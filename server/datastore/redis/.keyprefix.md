Implements a Redis connection wrapper that automatically prepends a key prefix to all Redis commands, enabling multi-tenant key isolation without requiring callers to manually manage key namespacing.

## Key Components

### `prefixedConn` struct
A `redis.Conn` wrapper that intercepts `Do`/`Send` calls and applies prefix logic before forwarding to the inner connection. Implements `ConnWithTimeout`, `Bind`, and `ReadOnly` interfaces for compatibility with `redisc` cluster connections.

### `newPrefixedConn(inner redis.Conn, prefix string) redis.Conn`
Constructor that returns the inner connection unchanged if prefix is empty, `inner` is nil, or the connection is already wrapped.

### `unwrapConn(c redis.Conn) (redis.Conn, string)`
Extracts the inner connection and prefix from a `prefixedConn`, or returns the connection as-is with an empty prefix.

### `prefixArgs(cmd string, args []interface{}, prefix string) []interface{}`
Core routing logic. Applies one of three policies per command:
- **`noPrefixCmds`** — no-op (admin/server/connection commands)
- **`specialCmds`** — custom `prefixRule` function for commands with keys not at `args[0]`
- **Default** — prefixes `args[0]` only

### Prefix rule functions
| Function | Applied to |
|---|---|
| `allArgs` | `DEL`, `MGET`, `SUBSCRIBE`, `EXISTS`, ... |
| `twoKeys` | `RENAME`, `COPY`, `LMOVE`, ... |
| `evalArgs` | `EVAL`, `EVALSHA`, `FCALL` (respects `numKeys`) |
| `scanArgs` | `SCAN` (prefixes `MATCH` pattern value) |
| `blockingKeysArgs` | `BLPOP`, `BRPOP`, `BZPOPMIN`, `BZPOPMAX` |
| `sortArgs` | `SORT` (prefixes source key and optional `STORE` destination) |
| `bitopArgs` | `BITOP` (skips the operation argument) |
| `objectArgs` | `OBJECT` (prefixes key for `ENCODING`/`IDLETIME`/`FREQ`/`REFCOUNT`) |
| `pubsubArgs` | `PUBSUB` (prefixes channels for `NUMSUB`/`CHANNELS`/`SHARD*`) |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/server/datastore/redis"

// Wrap an existing connection with a tenant prefix
inner := pool.Get()
conn := newPrefixedConn(inner, "tenant:acme:")

// Keys are prefixed automatically
conn.Do("SET", "session:123", data)    // → SET tenant:acme:session:123 data
conn.Do("DEL", "a", "b")              // → DEL tenant:acme:a tenant:acme:b
conn.Do("EVAL", script, 2, "k1", "k2") // → prefixes k1 and k2 only
conn.Do("PING")                        // → PING (no prefix applied)

// Unwrap when needed (e.g. before passing to redisc.RetryConn)
inner, prefix := unwrapConn(conn)
```
