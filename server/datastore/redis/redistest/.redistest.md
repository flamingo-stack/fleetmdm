Provides test helpers for setting up Redis connections in unit and integration tests, including a no-op Redis implementation and utilities for managing real Redis pools with automatic key cleanup.

## Key Components

- **`NopRedis()`** — Returns a no-op `fleet.RedisPool` implementation (`nopRedis`/`nopConn`) that silently discards all operations, useful for tests that don't require actual Redis connectivity.
- **`SetupRedis()`** — Convenience wrapper around `SetupRedisWithConfig` using default pool configuration.
- **`SetupRedisWithConfig()`** — Creates and validates a real Redis connection pool for tests. Handles standalone and cluster modes, skips automatically when `REDIS_TEST` env var is absent, and registers `tb.Cleanup` to delete test keys and close the pool.
- **`cleanup()`** — Internal helper that scans and deletes all Redis keys matching a given prefix, preventing key collisions across concurrent test packages.

## Usage Example

```go
func TestSomethingWithRedis(t *testing.T) {
    // Uses a real Redis instance; skipped if REDIS_TEST is unset
    pool := redistest.SetupRedis(t, "mytest:", false, false, false)

    conn := pool.Get()
    defer conn.Close()
    _, err := conn.Do("SET", "mytest:key", "value")
    require.NoError(t, err)
}

func TestSomethingWithoutRedis(t *testing.T) {
    // No real Redis needed; all ops are no-ops
    pool := redistest.NopRedis()
    conn := pool.Get()
    defer conn.Close()
}
```

## Environment Variables

| Variable | Effect |
|---|---|
| `REDIS_TEST` | Must be set to enable Redis-backed tests; tests are skipped otherwise |
| `REDIS_TEST_SKIP_CLUSTER` | Skips cluster tests on macOS when set |
