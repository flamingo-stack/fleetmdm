Redis-backed IP banning implementation that tracks consecutive request failures per IP and temporarily bans IPs that exceed a configurable failure threshold within a sliding time window.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `IPBanner` | struct | Core banning engine holding Redis pool, key prefix, and threshold/window/ban configuration |
| `NewIPBanner` | constructor | Creates an `IPBanner` with the given Redis pool and banning parameters |
| `CheckBanned` | method | Returns `true` if the given IP currently has an active ban key in Redis |
| `RunRequest` | method | Executes the Lua script to increment failure counter or reset it on success |
| `SetNullIfEmptyIP` | func | Normalizes empty IP strings to `"null"` to avoid empty Redis keys |
| `updateCountScript` | const | Atomic Lua script that manages counter/ban keys in a single round-trip |
| `SetIPBannerTestValues` / `UnsetIPBannerTestValues` | funcs | Thread-safe test helpers to override banning parameters at runtime |

### Redis Key Layout

```text
{keyPrefix}{ip}::count   — consecutive failure counter (expires after window)
{keyPrefix}{ip}::banned  — ban sentinel key (expires after ban duration)
```

Keys are wrapped in `{}` for Redis Cluster hash-slot locality.

## Usage Example

```go
banner := redis.NewIPBanner(
    redisPool,
    "fleet:ipban:",
    10,               // allow up to 10 consecutive failures
    time.Minute,      // within a 1-minute window
    15*time.Minute,   // ban for 15 minutes on breach
)

// Before handling a request:
banned, err := banner.CheckBanned(clientIP)
if err != nil {
    log.Error(err)
} else if banned {
    http.Error(w, "Too many failures", http.StatusTooManyRequests)
    return
}

// After handling a request, record the outcome:
if err := banner.RunRequest(clientIP, requestSucceeded); err != nil {
    log.Error(err)
}
```

> The Lua `updateCountScript` ensures the counter increment, expiry, and ban-key writes are atomic, so no race conditions occur under concurrent load.
