Implements a no-op fallback store (`commonFailingStore`) that returns errors for all storage operations, used as a safe default when neither S3 nor the local filesystem store can be initialized.

## Key Components

### `commonFailingStore`

A struct implementing the `CommonStore` interface with a single `Entity` string field used to identify the store type in error messages.

| Method | Behavior |
|--------|----------|
| `Get` | Returns `nil, 0, error` |
| `Put` | Returns `error` |
| `Exists` | Returns `false, error` |
| `Cleanup` | Returns `0, nil` (silent no-op) |
| `Sign` | Returns `"", error` |

> **Note:** `Cleanup` is the only method that does **not** return an error — it silently succeeds to avoid disrupting background cleanup routines when storage is unconfigured.

## Usage Example

```go
// Instantiated automatically when storage backend configuration fails
store := commonFailingStore{Entity: "software installer"}

_, _, err := store.Get(ctx, "some-icon-id")
// err: "software installer store not properly configured"

_, err = store.Sign(ctx, "some-icon-id", 5*time.Minute)
// err: "software installer store not properly configured"

// Cleanup silently succeeds
removed, err := store.Cleanup(ctx, usedIDs, time.Now())
// removed: 0, err: nil
```
