A failing stub implementation of the software title icon store, used for testing scenarios where datastore operations are expected to fail.

## Key Components

- **`FailingSoftwareTitleIconStore`** — Struct embedding `commonFailingStore`, providing a pre-configured store that returns errors for all software title icon operations.
- **`NewFailingSoftwareTitleIconStore()`** — Constructor that initializes the store with the entity label `"software title icon"`.

## Usage Example

```go
store := failing.NewFailingSoftwareTitleIconStore()

// Any operation on this store will return a standardized failure error
// identified by the "software title icon" entity label.
err := store.SomeOperation()
// err != nil — expected failure behavior for testing
```

## Notes

- Part of the `failing` package, which provides stub stores designed to simulate datastore failures in tests.
- Behavior is delegated entirely to `commonFailingStore`, which handles error generation consistently across all failing store types.
- See the full package at [`server/mock/failing/`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mock/failing/) for related failing store implementations.
