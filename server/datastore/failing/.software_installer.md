Provides a failing stub implementation of a software installer store, used for testing scenarios where store operations are expected to fail.

## Key Components

- **`FailingSoftwareInstallerStore`** — Struct embedding `*commonFailingStore`, inheriting its error-returning behavior for all store operations.
- **`NewFailingSoftwareInstallerStore()`** — Constructor that initializes the store with the entity name `"software installer"`.

## Usage Example

```go
store := failing.NewFailingSoftwareInstallerStore()

// All store operations will return a predictable failure,
// useful for testing error-handling paths.
err := store.SomeOperation()
// err != nil — operation fails as expected
```

## Notes

- Part of the `failing` package, which provides test-double stores that always return errors.
- The entity label `"software installer"` is used in error messages produced by `commonFailingStore` to aid in test diagnostics.
- See the full package at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/software_installer.go).
