Filesystem-backed store for software title icons, providing atomic write, SHA-256 integrity verification, and orphan cleanup operations.

## Key Components

### Types

- **`SoftwareTitleIconStore`** — Primary struct holding the root directory path; implements the `fleet.SoftwareTitleIconStore` interface.
- **`iconNotFoundError`** — Sentinel error implementing `fleet.NotFoundError`; returned when a requested icon does not exist on disk.

### Functions & Methods

| Symbol | Description |
|---|---|
| `NewSoftwareTitleIconStore(rootDir string)` | Initializes the store; creates the `software-title-icons/` subdirectory under `rootDir` if absent. |
| `Get(ctx, iconID)` | Returns a `ReadCloser` and file size for the icon. Returns `iconNotFoundError` if missing. **Caller must close the reader.** |
| `Put(ctx, iconID, content)` | Atomically writes icon content: streams to a temp file, calls `Sync()`, then `Rename()` into the final path. Crash-safe. |
| `Exists(ctx, iconID)` | Checks presence and integrity. Computes SHA-256 of the file and compares against `iconID`; returns `false` for empty or hash-mismatched files. |
| `Cleanup(ctx, usedIconIDs, removeCreatedBefore)` | Removes orphaned icon files not in `usedIconIDs` and older than `removeCreatedBefore`. Returns count of deleted files. |
| `Sign(ctx, _, _)` | Not supported; always returns an error. |
| `pathForIcon(iconID)` | Internal helper returning the full filesystem path for a given icon ID. |

## Usage Example

```go
store, err := filesystem.NewSoftwareTitleIconStore("/var/fleet/data")
if err != nil {
    log.Fatal(err)
}

// Store an icon
f, _ := os.Open("icon.png")
defer f.Close()
if err := store.Put(ctx, iconID, f); err != nil {
    log.Fatal(err)
}

// Retrieve an icon
rc, size, err := store.Get(ctx, iconID)
if err != nil {
    log.Fatal(err)
}
defer rc.Close()
// use rc and size...

// Remove orphaned icons older than 7 days
deleted, err := store.Cleanup(ctx, activeIconIDs, time.Now().Add(-7*24*time.Hour))
```
