Filesystem-based storage implementation for software installer binaries, providing CRUD operations backed by the local filesystem under a `software-installers/` subdirectory.

## Key Components

### `SoftwareInstallerStore`
The primary struct managing local filesystem storage for installer files, rooted at a configurable directory.

### Functions & Methods

| Name | Description |
|---|---|
| `NewSoftwareInstallerStore(rootDir string)` | Creates a new store, ensuring the `software-installers/` directory exists |
| `Get(ctx, installerID)` | Retrieves an installer as a `ReadCloser` along with its file size |
| `Put(ctx, installerID, content)` | Writes installer content to disk |
| `Exists(ctx, installerID)` | Checks whether an installer file exists without opening it |
| `Cleanup(ctx, usedInstallerIDs, removeCreatedBefore)` | Removes unused installer files older than the specified time, returning the count deleted |
| `Sign(ctx, _, _)` | Always returns an error — URL signing is unsupported for filesystem storage |

### `installerNotFoundError`
Implements `fleet.NotFoundError` for missing installer files, enabling callers to distinguish "not found" from other I/O errors.

## Usage Example

```go
store, err := filesystem.NewSoftwareInstallerStore("/var/fleet/installers")
if err != nil {
    log.Fatal(err)
}

// Store an installer
f, _ := os.Open("my-app.pkg")
defer f.Close()
err = store.Put(ctx, "installer-abc123", f)

// Retrieve it later
rc, size, err := store.Get(ctx, "installer-abc123")
defer rc.Close()

// Remove stale unused installers
removed, err := store.Cleanup(ctx, []string{"installer-abc123"}, time.Now().Add(-24*time.Hour))
```

> **Note:** The caller is responsible for closing the `ReadCloser` returned by `Get`. `Sign` is intentionally unsupported — use an S3-backed store when presigned URL generation is required.
