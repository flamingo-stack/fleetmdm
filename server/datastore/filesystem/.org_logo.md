Filesystem-backed store for organization logo images, providing CRUD operations keyed by `fleet.OrgLogoMode` within a dedicated `org-logos/` subdirectory.

## Key Components

| Symbol | Description |
|--------|-------------|
| `OrgLogoStore` | Main struct holding the root directory path for logo storage |
| `NewOrgLogoStore` | Constructor that initializes the `org-logos/` directory, creating it if absent |
| `Get` | Opens and returns a logo file as an `io.ReadCloser` with its byte size; returns `orgLogoNotFoundError` if absent |
| `Put` | Creates or overwrites a logo file by streaming from an `io.ReadSeeker` |
| `Delete` | Removes a logo file; silently succeeds if the file does not exist |
| `Exists` | Reports whether a logo file is present without opening it |
| `orgLogoNotFoundError` | Sentinel error implementing `fleet.NotFoundError` for missing logos |

## Usage Example

```go
store, err := filesystem.NewOrgLogoStore("/var/fleet/uploads")
if err != nil {
    log.Fatal(err)
}

// Store a logo
f, _ := os.Open("logo.png")
defer f.Close()
if err := store.Put(ctx, fleet.OrgLogoModeDark, f); err != nil {
    log.Fatal(err)
}

// Retrieve a logo
rc, size, err := store.Get(ctx, fleet.OrgLogoModeDark)
if err != nil {
    log.Fatal(err)
}
defer rc.Close()
fmt.Printf("logo size: %d bytes\n", size)

// Check existence before serving
if ok, _ := store.Exists(ctx, fleet.OrgLogoModeLight); !ok {
    // fall back to default
}

// Remove a logo
_ = store.Delete(ctx, fleet.OrgLogoModeDark)
```

## Notes

- Logo files are stored flat under `<rootDir>/org-logos/<mode>` with no extension; the `mode` value acts as the filename.
- The directory is created with permissions `0755` on first use.
- All errors are wrapped with context via `ctxerr.Wrap` for consistent tracing through Fleet's error pipeline.
