Manages S3-backed storage for organization logos, providing CRUD operations scoped to a `fleet.OrgLogoMode` key under a dedicated `org-logos` prefix within the software-installers bucket.

## Key Components

- **`OrgLogoStore`** — Wraps `commonFileStore` to provide logo-specific S3 operations.
- **`NewOrgLogoStore(cfg)`** — Initializes the store using the software-installers S3 config, mounting files under the `org-logos` prefix.
- **`Put(ctx, mode, content)`** — Uploads logo bytes for the given display mode.
- **`Get(ctx, mode)`** — Retrieves the logo stream and its size for a given mode.
- **`Exists(ctx, mode)`** — Checks whether a logo exists for the given mode.
- **`Delete(ctx, mode)`** — Removes the logo object; silently ignores `NoSuchKey`/`NotFound` errors.

## Usage Example

```go
cfg := config.S3Config{ /* populated from app config */ }

store, err := s3.NewOrgLogoStore(cfg)
if err != nil {
    log.Fatal(err)
}

// Upload a logo
f, _ := os.Open("logo.png")
defer f.Close()
err = store.Put(ctx, fleet.OrgLogoModeLight, f)

// Check existence
exists, err := store.Exists(ctx, fleet.OrgLogoModeLight)

// Download a logo
rc, size, err := store.Get(ctx, fleet.OrgLogoModeLight)
defer rc.Close()

// Remove a logo (no-op if missing)
err = store.Delete(ctx, fleet.OrgLogoModeDark)
```

## Notes

- Reuses the software-installers S3 bucket; logos are isolated by the `org-logos` path prefix.
- `Delete` treats missing objects as a success to allow idempotent cleanup.
- See [`s3/software_title_icon.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/datastore/s3/software_title_icon.go) for the analogous pattern this store follows.
