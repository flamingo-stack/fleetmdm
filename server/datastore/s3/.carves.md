Implements AWS S3-backed file carving storage for Fleet MDM, handling multipart upload lifecycle management and block-level data retrieval for osquery file carves.

## Key Components

- **`CarveStore`** — Main struct embedding `*s3store` and a metadata database (`fleet.CarveStore`) for hybrid S3 + DB storage.
- **`NewCarveStore`** — Constructor that initializes the S3 client from config and wraps a metadata DB.
- **`NewCarve`** — Initiates an S3 multipart upload session; records metadata (including errors) to the database.
- **`NewBlock`** — Uploads a single data block as an S3 multipart part; auto-completes the multipart upload when the final block arrives.
- **`GetBlock`** — Retrieves a specific block via HTTP range request; marks the carve expired if the S3 object no longer exists.
- **`CleanupCarves`** — Compares the 1,000 oldest non-expired DB carves against live S3 keys; marks absent, fully-uploaded carves as expired.
- **`listCompletedParts`** — Paginates through S3 `ListParts` to collect all `CompletedPart` entries for finalizing a multipart upload.
- **`generateS3Key`** — Builds a chronologically sortable S3 key using a `year/month/day/hour` prefix.

## Usage Example

```go
import (
    "github.com/fleetdm/fleet/v4/server/config"
    s3store "github.com/fleetdm/fleet/v4/server/datastore/s3"
)

// Initialize the carve store
store, err := s3store.NewCarveStore(config.S3Config{
    Bucket:    "my-carves-bucket",
    Prefix:    "carves/",
    Region:    "us-east-1",
}, metadataDB)
if err != nil {
    log.Fatal(err)
}

// Start a new carve session
carve, err := store.NewCarve(ctx, &fleet.CarveMetadata{
    HostId:     42,
    BlockCount: 5,
    BlockSize:  512 * 1024,
    Name:       "carve_abc123",
})

// Upload blocks as they arrive
err = store.NewBlock(ctx, carve, 0, blockData)

// Retrieve a block by ID
data, err := store.GetBlock(ctx, carve, 0)
```

> **Note:** S3 lifecycle policies should handle physical deletion; `CleanupCarves` only marks metadata as expired in the database.
