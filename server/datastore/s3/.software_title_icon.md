Provides an S3-backed store for managing software title icon files, reusing the software installers S3 configuration.

## Key Components

- **`SoftwareTitleIconStore`** — Struct embedding `*commonFileStore` to provide S3 file storage operations scoped to software title icons.
- **`NewSoftwareTitleIconStore`** — Constructor that initializes the store using the software installers S3 config (`SoftwareInstallersToInternalCfg()`), with a fixed path prefix of `"software-title-icons"`.

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/server/config"
    s3store "github.com/flamingo-stack/fleetmdm/server/s3"
)

cfg := config.S3Config{
    // populated from app configuration
}

store, err := s3store.NewSoftwareTitleIconStore(cfg)
if err != nil {
    log.Fatal(err)
}

// Use store to read/write software title icon files
```

## Notes

- Shares S3 bucket and credentials with the software installers store via `SoftwareInstallersToInternalCfg()`.
- All icon files are namespaced under the `software-title-icons/` path prefix within the configured bucket.
- File operations (upload, download, delete) are inherited from `commonFileStore`.
