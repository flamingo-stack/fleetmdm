Provides S3-backed storage for macOS bootstrap packages, wrapping a shared `commonFileStore` with a dedicated path prefix and file label.

## Key Components

- **`BootstrapPackageStore`** — Struct embedding `*commonFileStore` to inherit S3 file operations scoped to bootstrap packages.
- **`bootstrapPackagePrefix`** — Internal constant (`"bootstrap-packages"`) used as the S3 path prefix for all stored bootstrap packages.
- **`NewBootstrapPackageStore`** — Constructor that initializes the store using the S3 software installers config (via `SoftwareInstallersToInternalCfg()`), sharing the same S3 bucket configuration.

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/server/config"
    s3store "github.com/flamingo-stack/fleetmdm/server/mdm/apple/s3"
)

s3Cfg := config.S3Config{
    // Populate software installer S3 settings
    SoftwareInstallersBucket:   "my-fleet-bucket",
    SoftwareInstallersRegion:   "us-east-1",
    SoftwareInstallersAccessKeyID: "AKIAIOSFODNN7EXAMPLE",
}

store, err := s3store.NewBootstrapPackageStore(s3Cfg)
if err != nil {
    log.Fatalf("failed to create bootstrap package store: %v", err)
}

// store is ready to use for Put/Get/Delete operations on bootstrap packages
```

## Notes

- Reuses the **software installers S3 configuration** rather than a separate bucket, simplifying operational setup.
- All objects are stored under the `bootstrap-packages/` prefix, keeping them isolated from other file types in the same bucket.
- File operations (upload, download, delete) are inherited from `commonFileStore` and not redefined here.
