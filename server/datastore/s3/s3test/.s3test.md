Test helper package for spinning up ephemeral S3-backed stores (software installers, bootstrap packages, software title icons) against a local MinIO endpoint for integration testing.

## Key Components

| Symbol | Description |
|---|---|
| `SetupSoftwareInstallerStore` | Creates a `*s3.SoftwareInstallerStore` backed by a local test bucket; registers `tb.Cleanup` to drop the bucket after the test. |
| `SetupBootstrapPackageStore` | Creates a `*s3.BootstrapPackageStore` with the same lifecycle semantics. |
| `SetupSoftwareTitleIconStore` | Creates a `*s3.SoftwareTitleIconStore` with the same lifecycle semantics. |
| `setupStore[T testStore]` | Generic constructor shared by all three public helpers; builds the `config.S3Config`, creates the bucket, and wires cleanup. |
| `testStore` | Minimal interface (`CreateTestBucket`, `CleanupTestBucket`) required by `setupStore`. |
| `checkEnv` | Skips the test via `tb.Skip` unless the `S3_STORAGE_TEST` environment variable is set. |
| `getTestEndpoint` | Resolves the MinIO endpoint from `FLEET_S3_PORT`; defaults to `http://localhost:9000`. |

## Usage Example

```go
func TestUploadInstaller(t *testing.T) {
    store := s3test.SetupSoftwareInstallerStore(t, "test-installers", "prefix/")

    err := store.Put(context.Background(), "my-app.pkg", bytes.NewReader(data))
    require.NoError(t, err)
    // bucket is automatically deleted when the test finishes
}
```

## Environment Variables

| Variable | Purpose | Default |
|---|---|---|
| `S3_STORAGE_TEST` | Must be set (any value) to enable S3 tests; absent → `t.Skip`. | *(unset)* |
| `FLEET_S3_PORT` | Overrides the MinIO port. | `9000` |
