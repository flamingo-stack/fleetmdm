S3-backed store for managing software installer file objects, providing upload, download, and retrieval operations scoped to the `software-installers` path prefix.

## Key Components

- **`SoftwareInstallerStore`** — Thin wrapper around `commonFileStore` that scopes all S3 operations to the `software-installers/` prefix with a `"software installer"` label for error messaging.
- **`NewSoftwareInstallerStore`** — Production constructor; initializes an S3 connection using `config.S3Config`, delegating to `newS3Store` via `SoftwareInstallersToInternalCfg()`.
- **`NewTestSoftwareInstallerStore`** — Test constructor; bypasses full S3 initialization, wiring a stub `s3store` with a fixed `"test-bucket"` and optional CloudFront settings from config.

## Usage Example

```go
// Production initialization
cfg := config.S3Config{
    Bucket:    "my-fleet-bucket",
    Region:    "us-east-1",
    AccessKeyID: "AKIAIOSFODNN7EXAMPLE",
    SecretAccessKey: "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
}

store, err := s3.NewSoftwareInstallerStore(cfg)
if err != nil {
    log.Fatalf("failed to create installer store: %v", err)
}

// Test initialization
testStore, err := s3.NewTestSoftwareInstallerStore(cfg)
if err != nil {
    log.Fatalf("failed to create test installer store: %v", err)
}
```

## Notes

- CloudFront signing is supported for CDN-accelerated downloads; configure via `SoftwareInstallersCloudFrontURL` and related fields in `S3Config`.
- GCS (Google Cloud Storage) compatibility is auto-detected from `EndpointURL` via `isGCS()`.
- All file operations inherit from `commonFileStore`, keeping installer-specific logic minimal.
