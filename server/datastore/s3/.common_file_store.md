Implements shared S3/GCS file store operations (Get, Put, Exists, Sign, Cleanup) used by `SoftwareInstallerStore` and `BootstrapPackageStore` to manage files under configurable path prefixes within a single bucket.

## Key Components

| Symbol | Description |
|---|---|
| `commonFileStore` | Struct embedding `*s3store` with a `pathPrefix` and `fileLabel` for scoped file operations |
| `Get` | Downloads a file by ID; returns a `ReadCloser` and content length; maps S3 not-found errors to `installerNotFoundError` |
| `Put` | Uploads content using the S3 multipart manager; selects CRC32C checksum when targeting GCS |
| `Exists` | Performs a `HeadObject` check; returns `false` (not an error) when the object is absent |
| `Cleanup` | Lists up to 1000 objects, removes keys absent from `usedFileIDs` and older than a cutoff, with up to 10 parallel deletes |
| `Sign` | Generates a time-limited CloudFront signed URL for a given file ID |
| `keyForFile` | Builds the full S3 key as `<prefix>/<pathPrefix>/<fileID>` |
| `isGCS` | Helper that detects a Google Cloud Storage endpoint by URL |

## Usage Example

```go
store := &commonFileStore{
    s3store:    baseStore,          // configured *s3store
    pathPrefix: "software-installers",
    fileLabel:  "software installer",
}

// Upload
if err := store.Put(ctx, "abc123", fileReader); err != nil {
    log.Fatal(err)
}

// Download
rc, size, err := store.Get(ctx, "abc123")
if err != nil {
    log.Fatal(err)
}
defer rc.Close()

// Check existence
exists, err := store.Exists(ctx, "abc123")

// Signed CloudFront URL (requires cloudFrontConfig)
url, err := store.Sign(ctx, "abc123", 15*time.Minute)

// Remove orphaned files older than 24 hours
n, err := store.Cleanup(ctx, activeIDs, time.Now().Add(-24*time.Hour))
```
