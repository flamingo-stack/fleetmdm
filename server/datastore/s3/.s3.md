Initializes and configures an S3-compatible object store client, with built-in support for AWS S3, S3-compatible endpoints, and Google Cloud Storage (GCS) via both HMAC and IAM bearer token authentication.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `s3store` | struct | Core store holding the S3 client, bucket, prefix, CloudFront config, and a GCS flag |
| `newS3Store` | func | Constructs an `s3store` from a `config.S3ConfigInternal`; handles region auto-detection, STS assume-role, GCS compatibility workarounds, and credential selection |
| `installerNotFoundError` | struct | Implements `fleet.NotFoundError`; returned when a requested installer object is absent |
| `useGCSBearerAuth` | func | Replaces the AWS SigV4 middleware with a GCS OAuth2 bearer token middleware |
| `gcsBearerTokenAuth` | func | Middleware that fetches a Google access token and injects it as an `Authorization: Bearer` header |
| `ignoreSigningHeaders` | func | Strips specified headers before SigV4 signing and restores them after, preventing GCS signature mismatches on mutated headers (e.g., `Accept-Encoding`) |
| `disableTrailingChecksumForGCS` | func | Uses reflection to disable trailing checksums on `PutObject`/`UploadPart` operations, which GCS does not support |
| `CreateTestBucket` | method | Creates an S3 bucket; idempotent — ignores already-exists errors. **Testing only.** |
| `CleanupTestBucket` | method | Empties and deletes the store's bucket. **Testing only.** |

## Usage Example

```go
cfg := config.S3ConfigInternal{
    Bucket:          "my-fleet-bucket",
    Region:          "us-west-2",
    AccessKeyID:     "AKIAIOSFODNN7EXAMPLE",
    SecretAccessKey:  "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
    Prefix:          "installers/",
    ForceS3PathStyle: false,
}

store, err := newS3Store(cfg)
if err != nil {
    log.Fatalf("failed to init S3 store: %v", err)
}

// GCS IAM auth example
gcsCfg := config.S3ConfigInternal{
    Bucket:      "my-gcs-bucket",
    EndpointURL: "https://storage.googleapis.com",
    GCSIAMAuth:  true,
}

gcsStore, err := newS3Store(gcsCfg)
if err != nil {
    log.Fatalf("failed to init GCS store: %v", err)
}
```

> **GCS compatibility:** When `EndpointURL` contains `storage.googleapis.com`, the store automatically applies three workarounds — header-ignore signing, trailing-checksum disabling, and (optionally) OAuth2 bearer auth — to compensate for GCS deviations from the AWS S3 API. See [upstream issue #1816](https://github.com/aws/aws-sdk-go-v2/issues/1816).
