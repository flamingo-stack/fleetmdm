Manages a Redis-backed cursor for the batched Android MDM profile reconciliation cron job, enabling paginated processing across ticks.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `androidReconCursorKey` | `const` | Redis key (`mdm:android:recon_cursor`) storing the `host_uuid` cursor |
| `GetMDMAndroidReconcileCursor` | `func` | Retrieves the current reconciliation cursor; returns `""` if unset |
| `SetMDMAndroidReconcileCursor` | `func` | Persists the cursor; an empty string signals a full pass has completed |

## Usage Example

```go
// Advance the reconciler one tick
cursor, err := datastore.GetMDMAndroidReconcileCursor(ctx)
if err != nil {
    return err
}

nextCursor, err := reconcileBatch(ctx, cursor)
if err != nil {
    return err
}

// Persist progress; pass "" when the full sweep is complete
if err := datastore.SetMDMAndroidReconcileCursor(ctx, nextCursor); err != nil {
    return err
}
```

## Behaviour Notes

- **Missing key** (`ErrNil`) returns `""` — the cron restarts from the beginning, which is safe because the desired-state diff is recomputed every tick.
- **Key loss** (Redis flush, fresh deployment) is harmless; reconciliation simply re-converges from the start of the host list.
- Connections are drawn from the shared pool via `redis.ConfigureDoer` and closed immediately after each operation.
