Defines the JSON wire format envelope used to cache `fleet.Host` objects in Redis, handling the four fields tagged `json:"-"` on `fleet.Host` that must survive cache round-trips for authentication to function correctly.

## Key Components

### `hostCacheEnvelope` (struct)
Embeds `fleet.Host` and shadows its four `json:"-"` fields with explicitly tagged outer fields:

| Field | Type | Purpose |
|---|---|---|
| `OsqueryHostID` | `*string` | Required for osquery host lookup |
| `NodeKey` | `*string` | Required for node key auth |
| `OrbitNodeKey` | `*string` | Required for Orbit node key auth |
| `HasHostIdentityCert` | `*bool` | Gates `httpsig` check in `AuthenticateHost` |

### `envelopeFromHost(h *fleet.Host) *hostCacheEnvelope`
Constructs a marshal-ready envelope from a host pointer, lifting the four shadow fields out of the embedded struct.

### `(e *hostCacheEnvelope) toHost() *fleet.Host`
Reconstructs a complete `*fleet.Host` from the envelope, writing the shadow fields back into their natural positions on the embedded struct.

## Usage Example

```go
// Writing to cache
envelope := envelopeFromHost(host)
data, err := json.Marshal(envelope)

// Reading from cache
var env hostCacheEnvelope
if err := json.Unmarshal(data, &env); err != nil {
    return nil, err
}
host := env.toHost() // auth-safe: all four fields restored
```

## Important Notes

- **Auth safety:** A cached host with `HasHostIdentityCert == nil` would silently skip the `httpsig` check for the full cache TTL — the shadow field pattern prevents this regression.
- **Single envelope, two callers:** Serves both `LoadHostByNodeKey` and `LoadHostByOrbitNodeKey`; unpopulated pointer fields are omitted via `omitempty`.
- **Drift detection:** `TestPBT_HostCacheEnvelopeRoundTrip` asserts full-struct equivalence after marshal/unmarshal. When a new `json:"-"` auth field is added to `fleet.Host`, a matching shadow field must be added here.
