Manages a Redis-backed cursor for the Apple MDM Declaration Device Management (DDM) reconciliation process, tracking pagination state independently from profile reconciliation.

## Key Components

- **`appleDeclarationReconCursorKey`** — Redis key (`mdm:apple:declaration_recon_cursor`) storing the `host_uuid` cursor position for the batched DDM reconciler
- **`GetMDMAppleDeclarationReconcileCursor`** — Retrieves the current cursor value; returns an empty string when no cursor is set (Redis `ErrNil`)
- **`SetMDMAppleDeclarationReconcileCursor`** — Persists an updated cursor value to Redis after each reconciliation batch

## Usage Example

```go
// Advance through hosts in batches using the stored cursor
cursor, err := ds.GetMDMAppleDeclarationReconcileCursor(ctx)
if err != nil {
    return err
}

hosts, nextCursor := fetchNextBatch(cursor)
processDeclarations(hosts)

if err := ds.SetMDMAppleDeclarationReconcileCursor(ctx, nextCursor); err != nil {
    return err
}
```

## Notes

- The declaration cursor is intentionally separate from the MDM profile reconcile cursor, allowing the two reconciliation passes to advance at independent rates
- A missing key (fresh state or after reset) returns `""` rather than an error, so callers can treat an empty cursor as "start from beginning"
- Both methods acquire a connection from the shared Redis pool via `redis.ConfigureDoer` and close it in a `defer`
