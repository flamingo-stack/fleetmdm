Manages Redis persistence for the Apple MDM profile reconciliation cursor, enabling the batched reconciliation cron to bound per-tick work using a `host_uuid` cursor.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `appleReconCursorKey` | `const` | Redis key (`mdm:apple:recon_cursor`) storing the cursor value |
| `GetMDMAppleReconcileCursor` | `func` | Retrieves the current cursor; returns `""` if unset |
| `SetMDMAppleReconcileCursor` | `func` | Persists a cursor value; empty string signals a completed full pass |

## Usage Example

```go
// Retrieve the current cursor before processing a batch
cursor, err := datastore.GetMDMAppleReconcileCursor(ctx)
if err != nil {
    return err
}
// cursor == "" means start from the beginning

// ... process a batch of hosts starting after cursor ...

// Persist the last processed host_uuid for the next tick
if err := datastore.SetMDMAppleReconcileCursor(ctx, lastHostUUID); err != nil {
    return err
}

// Signal a full pass is complete by resetting the cursor
if err := datastore.SetMDMAppleReconcileCursor(ctx, ""); err != nil {
    return err
}
```

## Behavior Notes

- A missing Redis key (`ErrNil`) is treated as `""` — the cron safely restarts from the beginning
- Key loss (Redis flush, fresh deployment) is harmless; desired-state diffs are recomputed each tick, so reprocessing converges naturally
- Both methods acquire a connection from the pool via `redis.ConfigureDoer` and close it via `defer`
