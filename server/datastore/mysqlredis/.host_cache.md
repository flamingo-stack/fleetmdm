Implements a Redis-backed host cache layer for the Fleet MDM datastore, providing two-level (positive + negative) caching for host lookups by `node_key` and `orbit_node_key`, with TTL jitter, singleflight deduplication, and safe write-ordering for concurrent invalidation.

## Key Components

### Constants & Configuration
- `hostCacheKeyPrefix` — versioned Redis key namespace (`fleet:hostcache:v1`), enabling bulk purge on schema changes
- `hostCacheNegativeTTL` — 5-second TTL for "not found" entries to absorb retry storms without masking enrollment races
- `hostCacheTTLJitterFraction` — ±10% TTL spread to prevent synchronized cache stampedes

### Types
- `hostCacheLookup` — tri-state enum: `Miss`, `Hit`, `Negative`
- `cacheFamily` — strategy struct encapsulating key constructors and host field accessors for osquery vs. orbit paths; extend here to add new agent families

### Predefined Families
- `osqueryCacheFamily` — handles `node_key`-based lookups (`LoadHostByNodeKey`)
- `orbitCacheFamily` — handles `orbit_node_key`-based lookups (`LoadHostByOrbitNodeKey`)

### Core Methods
| Method | Purpose |
|---|---|
| `jitteredHostCacheTTL()` | Returns base TTL ± random jitter |
| `hostCacheGetFamily()` | Positive → negative cache read; degrades gracefully on Redis/JSON errors |
| `hostCachePutFamily()` | Writes primary key then index key (order is correctness-critical) |
| `hostCachePutNotFoundFamily()` | Writes per-key negative entry with short TTL |

## Usage Example

```go
// Read from cache (osquery family)
host, lookup := d.hostCacheGetByNodeKey(ctx, nodeKey)
switch lookup {
case hostCacheLookupHit:
    return host, nil
case hostCacheLookupNegative:
    return nil, fleet.ErrNotFound
case hostCacheLookupMiss:
    // fall through to database
}

// Populate cache after DB read
d.hostCachePutByNodeKey(ctx, host)

// Record negative result after DB miss
d.hostCachePutNotFoundByNodeKey(ctx, nodeKey)
```

> **Ops tip:** Purge all host-cache entries with:
> ```bash
> redis-cli --scan --pattern 'fleet:hostcache:v1:*' | xargs redis-cli DEL
> ```
> Bump the version suffix in `hostCacheKeyPrefix` on any cached-payload schema change; old keys TTL out automatically.
