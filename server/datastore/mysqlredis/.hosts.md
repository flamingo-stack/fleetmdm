Manages enrolled host ID synchronization between MySQL and a Redis set to enforce host enrollment limits.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `enrolledHostsSetKey` | `const` | Redis key (`enrolled_hosts:host_ids`) for the host ID set |
| `redisSetMembersBatchSize` | `var` | Batch size (10,000) for Redis `SADD`/`SREM` operations |
| `SyncEnrolledHostIDs` | method | Reconciles DB and Redis host counts; replaces the Redis set when they diverge |
| `addHosts` | func | Batch-adds host IDs to the Redis set via `SADD` |
| `removeHosts` | func | Batch-removes host IDs from the Redis set via `SREM` |
| `checkCanAddHost` | method | Returns `true` if the current Redis set size is below the configured limit |
| `CanEnrollNewHost` | method | Public gate — skips the Redis check when no limit is configured |
| `NewHost` | method | Wraps DB insert; adds the new host to Redis and invalidates its cache entry |
| `EnrollOsquery` | method | Wraps osquery enrollment; updates Redis and invalidates the stale cache snapshot |
| `DeleteHost` / `DeleteHosts` | methods | Wrap DB deletes; remove IDs from Redis and invalidate cache entries |
| `CleanupExpiredHosts` / `CleanupIncomingHosts` | methods | Wrap DB cleanup operations; batch-remove IDs from Redis and invalidate cache |

## Usage Example

```go
// Periodically called by a cron job to keep Redis in sync with the DB
if err := datastore.SyncEnrolledHostIDs(ctx); err != nil {
    log.Fatalf("sync failed: %v", err)
}

// Check enrollment eligibility before admitting a new host
ok, err := datastore.CanEnrollNewHost(ctx)
if err != nil {
    log.Fatalf("eligibility check failed: %v", err)
}
if !ok {
    log.Println("host limit reached, enrollment denied")
}

// Normal host creation — Redis tracking and cache invalidation are handled automatically
newHost, err := datastore.NewHost(ctx, &fleet.Host{NodeKey: ptr.String("abc123")})
```

## Notes

- When `enforceHostLimit <= 0`, `SyncEnrolledHostIDs` deletes the Redis key entirely to reclaim memory.
- All Redis mutations are batched in chunks of `redisSetMembersBatchSize` (10,000) to avoid oversized commands.
- Redis errors during `addHosts`/`removeHosts` are logged (via `logging.WithErr`) but do not fail the primary DB operation; `SyncEnrolledHostIDs` will self-heal on its next scheduled run.
