Provides an in-memory caching layer over a MySQL-backed `fleet.Datastore`, intercepting reads and writes for frequently accessed entities (app config, packs, scheduled queries, team settings, MDM assets, etc.) to reduce database load.

## Key Components

### `cloneCache`
Wraps `go-cache` with deep-clone semantics via the `fleet.Cloner` interface. Items are cloned on both `Get` and `Set` to prevent callers from mutating cached state. Respects `ctxdb.IsCachedMysqlBypassed` to allow explicit cache bypasses per request context.

### `cachedMysql`
Embeds `fleet.Datastore` and overrides specific methods to serve cached responses. Each cached entity has:
- A unique string key pattern (e.g., `"AppConfig:%s"`, `"Packs:host:%d"`)
- A configurable expiration duration (defaulting to 1s–15min depending on staleness sensitivity)

### `Option` Functions
Functional options for customizing per-entity TTLs at construction time:

| Option | Default TTL |
|---|---|
| `WithAppConfigExpiration` | 1 second |
| `WithPacksExpiration` | 1 minute |
| `WithScheduledQueriesExpiration` | 1 minute |
| `WithTeamAgentOptionsExpiration` | 1 minute |
| `WithTeamMDMConfigExpiration` | 1 minute |
| `WithMDMConfigAssetExpiration` | 15 minutes |
| `WithFMANamesByIdentifierExpiration` | 5 minutes |

### `New`
Constructs a `cachedMysql` wrapping an existing `fleet.Datastore` with a background cleanup interval of 10 minutes.

### OpenFrame Multi-Tenancy Key Scoping
`openframeAppConfigKey` keys the app config cache by team ID (extracted from context) so that a shared process never serves one tenant's config to another.

## Usage Example

```go
import cached "github.com/fleetdm/fleet/v4/server/datastore/cached_mysql"

// Wrap an existing datastore with caching defaults
ds := cached.New(rawDatastore)

// Customize TTLs for high-frequency reads
ds := cached.New(rawDatastore,
    cached.WithAppConfigExpiration(500*time.Millisecond),
    cached.WithTeamAgentOptionsExpiration(30*time.Second),
    cached.WithMDMConfigAssetExpiration(10*time.Minute),
)

// Bypass cache for a specific request (e.g., during writes)
ctx = ctxdb.BypassCachedMysql(ctx)
ac, err := ds.AppConfig(ctx) // reads directly from MySQL
```

> **Adding a new cached item:** Follow the five-step checklist in the file header — define a key/TTL constant, add an expiration field and `WithXXX` option, implement `fleet.Cloner`, register in `cloner-check/main.go`, then add datastore methods and tests.
