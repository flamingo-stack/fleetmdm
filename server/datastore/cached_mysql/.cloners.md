Defines `fleet.Cloner` implementations for types stored in the `cached_mysql` layer, enabling safe deep-copy semantics when reading cached values.

## Key Components

| Type | Underlying Type | Clone Behavior |
|---|---|---|
| `packsList` | `[]*fleet.Pack` | Deep-copies each `*fleet.Pack` via `Pack.Copy()` |
| `rawJSONMessage` | `json.RawMessage` | Byte-for-byte copy of the raw JSON buffer |
| `integer` | `int` | Value type; returns itself (no allocation needed) |
| `fmaNameMap` | `map[string]string` | Shallow key-value copy via `maps.Copy`; safe because both key and value are strings |

`fmaNameMap` specifically maps a software `unique_identifier` to its canonical FMA (Fleet-managed app) display name, used during osquery software ingestion to override reported names.

## Usage Example

```go
// packsList — deep clone a slice of packs pulled from cache
var cached packsList = fetchFromCache()
cloned, err := cached.Clone()
if err != nil {
    return err
}
packs := cloned.(packsList)

// fmaNameMap — clone the FMA name override map
var nameMap fmaNameMap = map[string]string{
    "com.example.app": "Example App",
}
clonedMap, err := nameMap.Clone()
if err != nil {
    return err
}

// rawJSONMessage — clone an opaque JSON blob
raw := rawJSONMessage(`{"key":"value"}`)
clonedRaw, err := raw.Clone()
```

All `Clone()` methods handle `nil` receivers gracefully, returning a typed `nil` without error.
