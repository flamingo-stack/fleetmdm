MySQL datastore implementation for persisting and retrieving distributed tracing sampler configuration from a singleton database row.

## Key Components

- **`traceSamplerSettingsID`** — Constant (`1`) identifying the singleton row in `trace_sampler_settings`.
- **`GetTraceSamplerSettings`** — Reads `high_volume_ratio`, `standard_ratio`, `force_full`, and `updated_at` from the database using the read replica.
- **`SetTraceSamplerSettings`** — Updates all three mutable fields on the singleton row via the writer connection, enforcing that exactly one row is affected (seeded by migration).

## Usage Example

```go
// Retrieve current sampler settings
settings, err := ds.GetTraceSamplerSettings(ctx)
if err != nil {
    // handles sql.ErrNoRows as a notFound error
    return err
}

// Update sampler settings
err = ds.SetTraceSamplerSettings(ctx, &tracing.Settings{
    HighVolumeRatio: 0.1,
    StandardRatio:   1.0,
    ForceFull:       false,
})
if err != nil {
    return err
}
```

> **Note:** The `trace_sampler_settings` table holds exactly one row (id = `1`), seeded by a database migration. `SetTraceSamplerSettings` returns an error if the update does not affect exactly one row, protecting against a broken invariant.
