MySQL-backed implementation of the `android.Datastore` interface, providing read/write database access with primary/replica routing for Android MDM data.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `AndroidDatastore` | struct | Core datastore holding logger, primary DB, and replica DB reader |
| `NewAndroidDatastore` | func | Constructor returning an `android.Datastore` backed by MySQL |
| `reader` | method | Returns replica or primary DB based on `ctxdb.RequirePrimary` context flag |
| `Writer` | method | Always returns the primary `*sqlx.DB` for write operations |
| `WithRetryTxx` | method | Executes a transactional function with automatic retry on the primary |
| `WithTxx` | method | Executes a transactional function without retry on the primary |

## Usage Example

```go
import (
    "log/slog"

    androidmysql "github.com/flamingo-stack/fleetmdm/server/mdm/android/mysql"
    "github.com/jmoiron/sqlx"
)

// Initialize primary and replica DB connections
primary, _ := sqlx.Open("mysql", primaryDSN)
replica, _ := sqlx.Open("mysql", replicaDSN)

logger := slog.Default()

// Create the Android datastore
ds := androidmysql.NewAndroidDatastore(logger, primary, replica)

// Use within a retryable transaction
err := ds.WithRetryTxx(ctx, func(tx *sqlx.Tx) error {
    // perform write operations
    return nil
})
```

## Read Routing

Reads are automatically routed to the replica unless the context signals that the primary is required:

```go
// Force primary for read-after-write consistency
ctx = ctxdb.RequirePrimary(ctx, true)
// ds.reader(ctx) now returns primary
```
