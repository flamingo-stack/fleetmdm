MySQL datastore implementation for resolving and counting hosts that match live query targets (host IDs, label IDs, and team IDs), with OpenFrame multitenancy fencing to restrict results to the pinned team.

## Key Components

| Symbol | Description |
|---|---|
| `CountHostsInTargets` | Aggregates host status metrics (total, MIA, offline, online, new) for a set of targets at a given timestamp |
| `HostIDsInTargets` | Returns a deduplicated, ordered slice of host IDs matching the given target set |
| `targetSQLCondAndArgs` | Builds the reusable SQL `WHERE` condition and argument list for host target resolution (explicit IDs, builtin labels, platform labels, and team membership) |

## OpenFrame Multitenancy Fencing

Both `CountHostsInTargets` and `HostIDsInTargets` inject an additional `AND hosts.team_id = ?` clause when `fleet.OpenframeTeamID(ctx)` is present. This ensures a live query cannot count or distribute to another tenant's hosts on a shared MySQL database, complementing the Redis key-prefix isolation already applied at the execution layer.

## Usage Example

```go
// Count hosts across a mixed target set
metrics, err := ds.CountHostsInTargets(ctx, filter, fleet.HostTargets{
    LabelIDs: []uint{3, 7},
    TeamIDs:  []uint{1},
}, time.Now())
if err != nil {
    return err
}
fmt.Printf("online=%d offline=%d mia=%d\n", metrics.Online, metrics.Offline, metrics.MIA)

// Resolve concrete host IDs for campaign distribution
hostIDs, err := ds.HostIDsInTargets(ctx, filter, fleet.HostTargets{
    HostIDs:  []uint{42, 43},
    LabelIDs: []uint{5},
})
if err != nil {
    return err
}
```
