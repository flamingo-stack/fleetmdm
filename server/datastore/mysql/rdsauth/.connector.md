AWS IAM authentication connector for RDS MySQL connections, implementing `driver.Connector` with automatic token caching and refresh via the `aws-sdk-go-v2` RDS auth package.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `iamAuthTokenGenerator` | struct | Generates and caches AWS IAM auth tokens for a specific RDS endpoint |
| `newIAMAuthTokenGenerator` | func | Initialises the token generator with AWS credentials, region, and optional role assumption |
| `getAuthToken` | method | Returns a cached or freshly generated IAM auth token |
| `Connector` | struct | Implements `driver.Connector`; injects the IAM token as the MySQL password on each connection |
| `NewConnectorFactory` | func | Returns a factory closure compatible with `common_mysql.NewDB`, decoupling AWS dependencies |

## Usage Example

```go
import (
    "database/sql"
    "github.com/flamingo-stack/fleetmdm/server/rdsauth"
    "github.com/flamingo-stack/fleetmdm/server/config"
)

conf := &config.MysqlConfig{
    Username:         "fleetdm",
    Region:           "us-east-1",
    StsAssumeRoleArn: "arn:aws:iam::123456789012:role/FleetRDSRole",
    StsExternalID:    "optional-external-id",
}

// Build the factory once; share it across connection pool setup.
factory, err := rdsauth.NewConnectorFactory(conf, "mydb.cluster.us-east-1.rds.amazonaws.com", "3306")
if err != nil {
    log.Fatal(err)
}

// Pass factory into common_mysql.NewDB (or use directly).
connector, err := factory(dsn, slogLogger)
if err != nil {
    log.Fatal(err)
}

db := sql.OpenDB(connector)
```

## Notes

- TLS is pre-configured via the blank import of `rdsmysql/v2`, which registers AWS RDS CA certificates automatically.
- Token caching is delegated to `aws_common.IAMAuthTokenManager`; tokens are reused until expiry, avoiding per-connection STS calls.
- If `dbEndpoint` already contains a port (`:`) it is used as-is; otherwise `dbPort` is appended.
