Provides MySQL datastore implementations for MDM (Mobile Device Management) command querying, listing, and configuration profile management across Apple, Windows, and Android platforms.

## Key Components

- **`GetMDMCommandPlatform`** — Resolves the platform (`darwin`, `windows`, `android`) for a given MDM command UUID by querying platform-specific tables.
- **`getMDMCommandsSubqueries`** — Returns optimized Apple and Windows SQL sub-statements used in paginated command listing, bypassing slow views to avoid full-table materializations.
- **`getCombinedMDMCommandsQuery`** — Builds a legacy `UNION ALL` query used for single-command lookups via `getMDMCommand`.
- **`ListMDMCommands`** — Lists MDM commands across all hosts with per-branch pagination (Apple + Windows) to avoid O(total) scans at scale. Applies team filters, request type filters, and cursor/page-based pagination.
- **`listMDMCommandsByHostIdentifier`** — Optimized host-scoped command lookup using a `UNION` of indexed subqueries (hostname, UUID, hardware_serial) rather than disjunctive `OR` conditions that degrade to full table scans.
- **`mdmCommandsOrderAllowlist`** / **`mdmConfigProfilesAllowedOrderKeys`** — Closed allowlists for safe SQL `ORDER BY` key injection.

## Usage Example

```go
commands, _, meta, err := ds.ListMDMCommands(ctx, teamFilter, &fleet.MDMCommandListOptions{
    ListOptions: fleet.ListOptions{
        PerPage:         25,
        Page:            0,
        OrderKey:        "updated_at",
        OrderDirection:  fleet.OrderDescending,
        IncludeMetadata: true,
    },
    Filters: fleet.MDMCommandFilters{
        RequestType: "InstallProfile",
    },
})
if err != nil {
    return err
}
for _, cmd := range commands {
    fmt.Printf("%s: %s (%s)\n", cmd.Hostname, cmd.CommandUUID, cmd.Status)
}
```

## Notes

- The Apple branch queries `nano_enrollment_queue` and `nano_commands` directly, bypassing the `nano_view_queue` VIEW which forces a full sort regardless of `LIMIT`.
- Per-branch inner `LIMIT` is inflated to `page * per_page + per_page` for page-based pagination so the outer `UNION ALL` can slice correctly without materializing the full result set.
- See [source](https://github.com/flamingo-stack/fleetmdm/blob/main/server/datastore/mysql/mdm.go) for full implementation.
