Provides MySQL datastore implementations for querying, listing, and enriching CVE vulnerability data with host counts, OS versions, and software associations.

## Key Components

- **`Vulnerability`** – Fetches a single CVE with optional metadata (CVSS score, EPSS probability, CISA exploit status) and host count, supporting both EE (with scores) and free-tier query paths.
- **`OSVersionsByCVE`** – Returns vulnerable OS versions affected by a CVE, deduplicating across architectures and mapping resolved-in versions.
- **`SoftwareByCVE`** – Returns vulnerable software titles associated with a CVE, filtered by team scope.
- **`ListVulnerabilities`** – Paginates a full vulnerability list using `buildListVulnerabilitiesSQL`, applying filters and sort order.
- **`buildListVulnerabilitiesSQL`** – Constructs a two-stage SQL query: an inner paginated query against `vulnerability_host_counts` and an outer enrichment join for CVE metadata. Optimized to avoid full-table scans via index-range scans on scope filters.
- **`vulnerabilitiesAllowedOrderKeys`** / **`vulnerabilitiesOuterOrderKeys`** – Allowlists controlling which columns clients may sort by in inner and outer query scopes respectively.

## Usage Example

```go
// Fetch a single vulnerability (EE path with CVE scores)
vuln, err := ds.Vulnerability(ctx, "CVE-2024-12345", nil, true)

// List vulnerabilities for a specific team, sorted by CVSS score
opts := fleet.VulnListOptions{
    TeamID:      &teamID,
    KnownExploit: false,
    ListOptions: fleet.ListOptions{
        OrderKey:  "cvss_score",
        OrderDirection: fleet.OrderDescending,
        PerPage:   25,
        Page:      0,
    },
}
vulns, meta, err := ds.ListVulnerabilities(ctx, opts)

// Get OS versions affected by a CVE
osVersions, updatedAt, err := ds.OSVersionsByCVE(ctx, "CVE-2024-12345", &teamID)

// Get software affected by a CVE (global scope)
software, updatedAt, err := ds.SoftwareByCVE(ctx, "CVE-2024-12345", nil)
```
