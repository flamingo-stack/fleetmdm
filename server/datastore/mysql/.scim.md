SCIM user and group data persistence layer for Fleet MDM, implementing CRUD operations and lookup queries against MySQL-backed `scim_users`, `scim_user_emails`, `scim_user_groups`, and related tables.

## Key Components

| Function | Description |
|---|---|
| `CreateScimUser` | Inserts a new SCIM user with emails and optionally associates them with an MDM IdP host |
| `ScimUserByID` | Fetches a SCIM user by primary key, including emails and groups |
| `ScimUserByUserName` | Fetches a SCIM user by `user_name` field |
| `ScimUserByUserNameOrEmail` | Multi-strategy lookup: tries `user_name`, then email-as-username, then email join; returns `nil` (no error) when multiple users share an email |
| `ScimUserByHostID` | Retrieves the SCIM user associated with a given host ID |
| `ReplaceScimUser` | Full replacement update; detects username/department/name changes and triggers profile resend |
| `DeleteScimUser` | Deletes a SCIM user and triggers profile resend for affected hosts |
| `insertEmails` | Batch-inserts `scim_user_emails` rows for a user |
| `getScimUserLiteByHostID` | Internal helper that fetches core user fields only (no emails/groups) for a host |

**Constants:**
- `SCIMMaxStatusLength` — maximum length for status fields (31)
- `SCIMDefaultResourcesPerPage` — default pagination size (100)

## Usage Example

```go
// Create a new SCIM user
id, err := ds.CreateScimUser(ctx, &fleet.ScimUser{
    UserName:   "jane.doe@example.com",
    GivenName:  ptr("Jane"),
    FamilyName: ptr("Doe"),
    Active:     true,
    Emails: []fleet.ScimUserEmail{
        {Email: "jane.doe@example.com", Primary: ptr(true)},
    },
})

// Lookup by username or fallback to email
user, err := ds.ScimUserByUserNameOrEmail(ctx, "jane.doe", "jane.doe@example.com")

```
