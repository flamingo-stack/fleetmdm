Provides MySQL datastore methods for batched Windows MDM profile reconciliation, including host enumeration, profile loading with label assignments, and current profile state retrieval within a consistent read snapshot.

## Key Components

### Functions

| Function | Description |
|---|---|
| `listWindowsMDMHostsForReconcileBatchTransaction` | Fetches up to `batchSize` Windows MDM-enrolled hosts with UUID greater than `afterHostUUID`, ordered ascending — used for cursor-based batch iteration |
| `GetWindowsMDMHostForReconcile` | Returns reconcile info for a single eligible Windows MDM host by UUID; returns `(nil, nil)` if not found or ineligible |
| `ListWindowsProfilesForReconcileByTeam` | Public wrapper that loads Windows configuration profiles scoped to a specific team ID |
| `listWindowsProfilesForReconcileTransaction` | Core profile loader; when `teamID` is `nil` returns all profiles (snapshot path), otherwise scopes to one team (per-host enrollment path). Attaches label assignments and computes include/exclude modes |
| `BulkGetHostMDMWindowsProfilesByUUIDs` | Public wrapper to retrieve current `host_mdm_windows_profiles` rows grouped by host UUID |
| `bulkGetHostMDMWindowsProfilesByUUIDsTransaction` | Executes a single `IN`-clause query to load current profile state for a bounded set of host UUIDs |
| `GetWindowsProfileReconcileSnapshot` | Loads all four reconciler inputs (host window, profiles, label memberships, current profile rows) inside a single repeatable-read transaction for snapshot consistency |

### Key Types Used

- `fleet.WindowsHostReconcileInfo` — host fields needed by the reconciler (`id`, `uuid`, `team_id`, `label_updated_at`)
- `fleet.WindowsProfileForReconcile` — profile with checksum, label refs, and include/exclude mode
- `fleet.MDMWindowsProfilePayload` — current `host_mdm_windows_profiles` row
- `fleet.MDMProfileIncludeMode` — enum distinguishing `IncludeAny`, `IncludeAll`, and `IncludeNone` semantics

## Usage Example

```go
// Load a single host for an immediate reconcile trigger
host, err := ds.GetWindowsMDMHostForReconcile(ctx, "device-uuid-1234")
if err != nil {
    return err
}
if host == nil {
    // Host not enrolled or not eligible
    return nil
}

// Load profiles scoped to the host's team
profiles, err := ds.ListWindowsProfilesForReconcileByTeam(ctx, host.TeamID)

// Fetch current profile state for a batch of hosts
current, err := ds.BulkGetHostMDMWindowsProfilesByUUIDs(ctx, []string{"uuid-1", "uuid-2"})
```

> **Label mode safety:** If a profile's include label rows disagree on `require_all`, the include set is dropped and `IncludeMode` is set to `IncludeNone`; exclude labels are preserved. This prevents guessing at intent when data integrity constraints are unexpectedly violated.
