Provides MySQL datastore implementations for host management in the Fleet MDM platform, including CRUD operations, query statistics, host listing/filtering, and batch processing for host-related data.

## Key Components

### Core Functions
- **`NewHost`** – Creates a new host record with associated seen time and display name entries
- **`SerialUpdateHost`** – Queues host updates through a write channel for serialized processing
- **`SaveHostPackStats`** / **`saveHostPackStatsDB`** – Persists osquery pack/scheduled query execution statistics, handling both global/team packs and legacy 2017-style user packs
- **`loadHostPackStatsDB`** – Loads pack execution statistics for a given host, returning zero values for unexecuted queries

### Configuration Variables
- **`hostIssuesInsertBatchSize`** / **`hostIssuesUpdateFailingPoliciesBatchSize`** / **`hostsDeleteBatchSize`** – Configurable batch sizes for bulk operations (adjustable for testing)

### Constants & Allowlists
- **`hostAllowedOrderKeys`** – Allowlist of safe sort columns for host listing (intentionally excludes sensitive fields like `node_key` and encryption keys to prevent binary search extraction attacks)
- **`batchScriptHostAllowedOrderKeys`** – Restricted sort key allowlist for the `ListBatchScriptHosts` endpoint
- **`hostSearchColumns`** / **`wildCardableHostSearchColumns`** – Column sets used for full-text host search

## Usage Example

```go
// Create a new host
host, err := ds.NewHost(ctx, &fleet.Host{
    Hostname:    "my-device.local",
    UUID:        "abc-123",
    Platform:    "darwin",
    NodeKey:     ptr.String("secret-key"),
})

// Save osquery pack statistics
err = ds.SaveHostPackStats(ctx, teamID, host.ID, []fleet.PackStats{
    {
        PackName: "Global",
        QueryStats: []fleet.ScheduledQueryStats{
            {ScheduledQueryName: "system_info", Executions: 42},
        },
    },
})
```
