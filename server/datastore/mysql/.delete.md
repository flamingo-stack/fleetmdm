Provides generic MySQL delete helper methods for removing entities from database tables by ID, name, or a batch of IDs.

## Key Components

| Function | Description |
|---|---|
| `deleteEntity` | Deletes a single row by `id`; returns a `notFound` error if no row was affected |
| `deleteEntityByName` | Deletes a single row by `name`; handles foreign key constraint violations and `notFound` errors |
| `deleteEntities` | Batch-deletes multiple rows by a slice of `id` values using `sqlx.In`; returns the count of deleted rows |

## Usage Example

```go
// Delete a single entity by ID
err := ds.deleteEntity(ctx, packEntity, 42)
if err != nil {
    // handles notFound or query errors
}

// Delete a single entity by name
err = ds.deleteEntityByName(ctx, labelEntity, "my-label")
if err != nil {
    // handles foreignKey, notFound, or query errors
}

// Batch delete entities by ID slice
deleted, err := ds.deleteEntities(ctx, hostEntity, []uint{1, 2, 3})
if err != nil {
    // handles query build or execution errors
}
fmt.Printf("Deleted %d records\n", deleted)
```

## Error Handling

- **`notFound`** — returned when `RowsAffected() != 1` for single-row operations
- **`foreignKey`** — returned by `deleteEntityByName` when a MySQL foreign key constraint is violated
- All errors are wrapped with context via `ctxerr.Wrap`/`ctxerr.Wrapf` for traceability
