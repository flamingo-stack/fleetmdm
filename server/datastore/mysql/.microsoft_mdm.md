Provides MySQL datastore implementations for Windows MDM enrollment management, command queuing, and host configuration state within the Fleet MDM platform.

## Key Components

### Enrollment Lookup Functions
- **`MDMWindowsGetEnrolledDeviceWithDeviceID`** — Fetches the most recent Windows MDM enrollment record by device ID
- **`MDMWindowsGetEnrolledDeviceWithHostUUID`** — Retrieves enrollment by host UUID (writer-backed to avoid replica lag)
- **`MDMWindowsGetUnlinkedEnrolledDeviceWithDeviceName`** — Fallback lookup by computer name for enrollments not yet linked to a host UUID (BYOD/setup-experience use case)
- **`WindowsHostLiteByHardwareSerial`** — Looks up a Windows host by hardware serial; returns `NotFound` if multiple hosts share the same serial

### Command & Poll Schedule Management
- **`MDMWindowsEnqueuePollScheduleCommand`** — Atomically enqueues a DMClient poll-schedule Replace command and records the intended relaxed state in a single transaction
- **`setMDMWindowsEnrollmentPollScheduleRelaxedDB`** — Internal helper that updates the `poll_schedule_relaxed` flag within a caller-supplied transaction
- **`SetMDMWindowsEnrollmentFleetdSyncCapable`** — Persists the `CapabilityWindowsMDMSync` flag from orbit config check-ins to gate poll relaxation

### Host Configuration State
- **`GetMDMWindowsHostConfigState`** — Returns `awaiting_configuration`, `has_pending_commands`, and `fleetd_sync_capable` from the most recent enrollment row; optimized for high-frequency orbit polling via a denormalized flag
- **`HasWindowsSetupExperienceItemsForTeam`** — Checks whether any active Windows setup-experience software installers are configured for a given team
- **`isWindowsHostConnectedToFleetMDM`** — Internal helper verifying a host has an active enrolled Windows MDM session

## Usage Example

```go
// Fetch enrollment state for the orbit config hot path
state, err := ds.GetMDMWindowsHostConfigState(ctx, hostUUID)
if err != nil {
    return err
}
if state.HasPendingCommands {
    // Signal device to check in immediately
}

// Atomically enqueue poll schedule command and record intended state
err = ds.MDMWindowsEnqueuePollScheduleCommand(ctx, deviceID, enrollmentID, cmd, relaxed)
```
