MySQL datastore implementation for managing Fleet application configuration and enrollment secrets, with OpenFrame multitenancy extensions that scope all reads and writes to the current process's tenant team.

## Key Components

| Function | Description |
|---|---|
| `NewAppConfig` | Creates and persists a new app config with installation defaults applied |
| `AppConfig` / `appConfigDB` | Reads app config JSON, routing by tenant team ID when multitenancy is active |
| `AppConfigUrls` | Reads only the URL-related subset of app config |
| `SaveAppConfig` | Persists app config JSON; uses team-scoped `INSERT ... ON DUPLICATE KEY UPDATE` under multitenancy |
| `VerifyEnrollSecret` | Validates an enrollment secret, restricting to the current tenant's secrets in multitenancy mode |
| `IsEnrollSecretAvailable` | Checks whether a secret string is available for use by a given team |
| `ApplyEnrollSecrets` | Replaces the full set of enrollment secrets for a team, preserving original `created_at` timestamps |
| `GetEnrollSecrets` | Retrieves enrollment secrets scoped to a team (or global), pinned to tenant in multitenancy mode |
| `InsertOrReplaceMDMConfigAsset` | Upserts an MDM config asset, replacing only when the value differs |
| `SetAndroidEnabledAndConfigured` | Toggles the Android MDM enabled/configured flag in app config |
| `GetCurrentTime` | Returns the current time from the database (falls back to server time on error) |

## Usage Example

```go
// Read app config for the current tenant context
cfg, err := ds.AppConfig(ctx)
if err != nil {
    return err
}

// Mutate and persist
cfg.MDM.AndroidEnabledAndConfigured = true
if err := ds.SaveAppConfig(ctx, cfg); err != nil {
    return err
}

// Apply enrollment secrets for a team, preserving timestamps
secrets := []*fleet.EnrollSecret{
    {Secret: "abc123"},
}
if err := ds.ApplyEnrollSecrets(ctx, &teamID, secrets); err != nil {
    return err
}

// Verify a secret during agent enrollment
enrollSecret, err := ds.VerifyEnrollSecret(ctx, "abc123")
```

## Multitenancy Notes

All queries are annotated with `OPENFRAME(mysql-multitenancy)` blocks. When `fleet.OpenframeTeamID(ctx)` returns a team ID, reads and writes are scoped to `app_config_json.id = teamID` and `enroll_secrets.team_id = teamID`, preventing cross-tenant data access on a shared database. When no team is pinned, the upstream Fleet behavior is preserved.
