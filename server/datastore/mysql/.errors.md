Defines MySQL-specific error types and helper functions for the Fleet MDM datastore layer, covering duplicate entries, foreign key violations, access denial, bad connections, and partial batch results.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `notFound` | func | Returns a `NotFoundError` for a given resource kind |
| `existsError` | struct | Error for duplicate/already-existing resources, optionally scoped to a team |
| `alreadyExists` | func | Constructs an `existsError` with optional team context via `WithTeamID`/`WithTeamName` |
| `IsDuplicate` | func | Reports whether an error wraps MySQL error `ER_DUP_ENTRY` |
| `foreignKeyError` | struct | Error for operations that violate a MySQL foreign key constraint |
| `foreignKey` | func | Constructs a `foreignKeyError` for a resource and constraint name |
| `isMySQLForeignKey` | func | Reports whether an error wraps MySQL error `ER_ROW_IS_REFERENCED_2` |
| `accessDeniedError` | struct | Error for MySQL access-denied conditions; returns HTTP 422 by default |
| `isMySQLAccessDenied` | func | Detects `ER_SPECIFIC_ACCESS_DENIED_ERROR` or `ER_TABLEACCESS_DENIED_ERROR` |
| `isBadConnection` | func | Detects transient connection errors that justify retrying on a new connection |
| `ErrPartialResult` | var | Sentinel error for batch operations that complete with incomplete results |

## Usage Example

```go
// Check for a duplicate before inserting
err := ds.CreateUser(ctx, user)
if IsDuplicate(err) {
    return alreadyExists("User", user.Email).WithTeamID(teamID)
}

// Detect a bad connection and retry
if isBadConnection(err) {
    conn, _ = pool.NewConn()
    err = retryOperation(conn)
}

// Signal partial batch completion
func processBatch(items []Item) error {
    if someItemsFailed {
        return ErrPartialResult
    }
    return nil
}
```

## Notes

- All error detection functions unwrap context errors via `ctxerr.Cause` before inspecting the underlying `*mysql.MySQLError`.
- `existsError` implements `IsExists()`, `IsClientError()`, and `Resource()` to integrate with Fleet's error-classification middleware.
- `isBadConnection` covers both standard library connection sentinels and syscall-level network errors (`ECONNRESET`, `EPIPE`, `ETIMEDOUT`, etc.).
