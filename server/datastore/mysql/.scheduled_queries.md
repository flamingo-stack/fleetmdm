MySQL datastore implementation for CRUD operations and stats management on scheduled queries within query packs.

## Key Components

| Function | Description |
|---|---|
| `ListScheduledQueriesInPackWithStats` | Lists all scheduled queries in a pack with aggregated performance stats (p50/p95 percentiles, execution counts) |
| `ListScheduledQueriesInPack` | Lists all scheduled queries in a pack without stats |
| `NewScheduledQuery` | Inserts a new scheduled query, resolving query name from the given `QueryID` |
| `SaveScheduledQuery` | Updates an existing scheduled query's configuration |
| `DeleteScheduledQuery` | Deletes a scheduled query and its associated stats in a transaction |
| `ScheduledQuery` | Fetches a single scheduled query by ID |
| `ScheduledQueryIDsByName` | Batch-resolves scheduled query IDs from `(pack_name, query_name)` pairs, with configurable batch size |
| `AsyncBatchSaveHostsScheduledQueryStats` | Upserts per-host scheduled query execution stats in batches, sorted by host ID for optimal MySQL locking |
| `scheduledQueriesAllowedOrderKeys` | Allowlist of sortable columns (including JSON-extracted aggregated stats fields) for cursor-based pagination |

## Usage Example

```go
// List scheduled queries in a pack with performance stats
queries, err := ds.ListScheduledQueriesInPackWithStats(ctx, packID, fleet.ListOptions{
    PerPage: 25,
    OrderKey: "user_time_p50",
})

// Create a new scheduled query
sq, err := ds.NewScheduledQuery(ctx, &fleet.ScheduledQuery{
    PackID:   1,
    QueryID:  42,
    Name:     "My Query",
    Interval: 3600,
    Snapshot: ptr.Bool(true),
})

// Batch-resolve IDs for (pack, query) name pairs
ids, err := ds.ScheduledQueryIDsByName(ctx, 500,
    [2]string{"Global", "os_version"},
    [2]string{"team-1", "disk_usage"},
)
```

> **Note:** `AsyncBatchSaveHostsScheduledQueryStats` differentiates between "new" pack names (`Global`, `team-*`) and legacy 2017-style user packs, routing stats to different upsert paths accordingly.
