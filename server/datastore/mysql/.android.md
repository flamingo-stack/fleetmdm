MySQL datastore layer for Android device enrollment and management, providing CRUD operations for Android hosts and devices within the Fleet MDM system.

## Key Components

- **`truncateRunes`** — Utility that safely truncates a string to a maximum rune count, aligning with MySQL `utf8mb4 VARCHAR(N)` column constraints.
- **`NewAndroidHost`** — Inserts or updates a `hosts` row for a newly enrolling Android device, deduplicating against orbit-enrolled hosts that share the same UUID, and initializing MDM info, label membership, device record, and disk space.
- **`UpdateAndroidHost`** — Updates an existing Android host's hardware, OS, and MDM metadata; syncs `android_devices.team_id`; optionally refreshes MDM enrollment state on re-enroll.
- **`UpdateTeamIDOnAndroidDevices`** — Bulk-updates `android_devices.team_id` for a list of host UUIDs.
- **`GetAndroidDeviceLastTeamID`** — (partial) Retrieves the last known `team_id` for an Android device by its `enterpriseSpecificID`.
- **`setTimesToNonZero`** — Helper that replaces zero-value timestamps on an `AndroidHost` with a MySQL-safe default to avoid storage errors.

## Usage Example

```go
// Enroll a new Android host
host := &fleet.AndroidHost{
    Host:   &fleet.Host{NodeKey: "android/abc123", Platform: "android"},
    Device: &android.Device{EnterpriseSpecificID: "abc123"},
}
created, err := ds.NewAndroidHost(ctx, host, true /* companyOwned */)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("enrolled host ID: %d\n", created.Host.ID)

// Update an existing host after a check-in
err = ds.UpdateAndroidHost(ctx, host, false /* fromEnroll */, true)

// Move devices to a new team
err = ds.UpdateTeamIDOnAndroidDevices(ctx, []string{"uuid-1", "uuid-2"}, ptr.Uint(42))
```
