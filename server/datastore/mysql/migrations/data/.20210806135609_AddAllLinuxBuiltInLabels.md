Database migration that adds a built-in "All Linux" label targeting Ubuntu and CentOS distributions via an idempotent `INSERT IGNORE` statement.

## Key Components

- **`Up_20210806135609`** — Inserts a built-in label named `"All Linux"` into the `labels` table. Uses `INSERT IGNORE` for idempotency. The label targets Linux hosts by querying `osquery_info` for Ubuntu (`build_platform`) or CentOS (`build_distro`) identifiers.
- **`Down_20210806135609`** — No-op rollback; the label is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Label Details

| Field | Value |
|---|---|
| `name` | `All Linux` |
| `description` | `All Linux distributions` |
| `platform` | *(empty — cross-platform)* |
| `label_type` | `fleet.LabelTypeBuiltIn` |
| `query` | `SELECT 1 FROM osquery_info WHERE build_platform LIKE '%ubuntu%' OR build_distro LIKE '%centos%'` |

## Usage Example

This migration runs automatically via the Fleet migration runner. No manual invocation is required. To apply it manually during development:

```bash
fleet prepare db --config /etc/fleet/fleet.yml
```

To reference the label type constant used here:

```go
import "github.com/fleetdm/fleet/v4/server/fleet"

labelType := fleet.LabelTypeBuiltIn
```

---

> **Note:** The `Down` function is intentionally a no-op. Removing built-in labels on rollback could break existing label-based policies and queries that depend on `"All Linux"`.
