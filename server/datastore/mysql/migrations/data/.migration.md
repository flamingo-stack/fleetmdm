Initializes and exposes a Goose database migration client configured for MySQL, used to manage migration state tracking for the Fleet data layer.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MigrationClient` | `*goose.Goose` | Pre-configured Goose migration client targeting the `migration_status_data` table with MySQL dialect |

## Usage Example

```go
package data

import (
    "database/sql"
    "github.com/flamingo-stack/fleetmdm/server/datastore/mysql/migrations/data"
)

func applyMigrations(db *sql.DB) error {
    // Run all pending data migrations
    return data.MigrationClient.Up(db, ".")
}

func migrationStatus(db *sql.DB) error {
    // Check current migration state
    return data.MigrationClient.Status(db, ".")
}
```

## Notes

- Uses the `migration_status_data` table to track applied migrations, keeping data migrations distinct from schema migrations
- Backed by `goose.MySqlDialect{}`, so it expects a MySQL-compatible connection
- Follows the same pattern as Fleet's schema migration client; parallel clients allow independent versioning of schema vs. data migrations
