Database migration that renames team-associated schedule packs by prepending `"Team: "` to the team name, derived by joining the `packs` and `teams` tables on the embedded team ID in `pack_type`.

## Key Components

| Function | Description |
|---|---|
| `Up_20210819120215` | Renames all packs with a `pack_type` of `team-<id>` to `Team: <team_name>` using a correlated subquery |
| `Down_20210819120215` | No-op rollback; the rename is not reversed |

## Migration Details

- **Direction:** Up-only (down is a no-op)
- **Idempotent:** Yes — re-running produces the same result
- **Target table:** `packs`
- **Filter:** Rows where `pack_type LIKE 'team-%'`
- **Transform:** Extracts the numeric team ID from `pack_type` via `SUBSTRING_INDEX`, looks up the matching team name, and sets `name = CONCAT('Team: ', <team_name>)`

## SQL Executed

```sql
UPDATE packs
SET name = CONCAT('Team: ', (
    SELECT name FROM teams
    WHERE id = (CAST(SUBSTRING_INDEX(pack_type, '-', -1) AS UNSIGNED))
))
WHERE pack_type LIKE 'team-%';
```

> **Note:** `Down_20210819120215` is intentionally empty. If a rollback is required, a separate migration to restore the previous naming convention must be written manually.
