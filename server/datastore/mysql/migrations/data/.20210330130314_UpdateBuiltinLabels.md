Database migration that clears platform restrictions from built-in labels and adds a Red Hat Enterprise Linux label to the Fleet MDM system.

## Key Components

- **`Up_20210330130314`** — Applies two changes:
  - Clears the `platform` field for all built-in labels, preventing hosts that change OS (while retaining the same hardware UUID) from appearing in multiple platform labels simultaneously
  - Inserts a new `"Red Hat Linux"` built-in label targeting hosts where `os_version.name` matches `%red hat%`
- **`Down_20210330130314`** — No-op rollback (migration is designed to be idempotent)
- **`init()`** — Registers the migration with `MigrationClient`

## Behavior Notes

- The `UPDATE` is safe to re-run; setting `platform = ''` on already-empty rows has no effect
- The Red Hat label insert uses `INSERT IGNORE`, making it safe against duplicate runs
- The label uses `LabelMembershipTypeDynamic`, so membership is evaluated continuously via the query rather than statically assigned

## Usage Example

This migration runs automatically via the Fleet migration framework at startup:

```go
// Registered automatically via init()
MigrationClient.AddMigration(Up_20210330130314, Down_20210330130314)

// Equivalent manual SQL applied by Up_20210330130314:
// UPDATE labels SET platform = '' WHERE label_type = <BuiltIn>
// INSERT IGNORE INTO labels (name, ...) VALUES ('Red Hat Linux', ...)
```
