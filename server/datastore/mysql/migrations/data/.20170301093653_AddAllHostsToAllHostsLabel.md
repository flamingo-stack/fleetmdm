Database migration that ensures all existing hosts are enrolled in the built-in "All Hosts" label by backfilling missing `label_membership` records.

## Key Components

- **`Up_20170301093653(tx *sql.Tx) error`** — Inserts any host not already present in the `label_membership` table for the `All Hosts` built-in label. Uses `INSERT IGNORE` to make the operation idempotent (safe to run multiple times).
- **`Down_20170301093653(tx *sql.Tx) error`** — No-op; this migration is intentionally irreversible.
- **`init()`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically by the Fleet migration runner. No manual invocation is required.

```go
// Registered automatically via init()
MigrationClient.AddMigration(Up_20170301093653, Down_20170301093653)
```

The core SQL executed during `Up`:

```sql
INSERT IGNORE INTO label_membership (host_id, label_id)
SELECT
    id AS host_id,
    (SELECT id FROM labels WHERE name = 'All Hosts' AND label_type = ?)
FROM hosts;
```

## Notes

- **Idempotent**: `INSERT IGNORE` silently skips rows that already satisfy the unique constraint on `(host_id, label_id)`, making repeated runs safe.
- **Non-reversible**: The `Down` function is a no-op because removing hosts from `All Hosts` would require knowing which memberships existed prior to the migration.
- Depends on `fleet.LabelTypeBuiltIn` to identify the correct label row.
