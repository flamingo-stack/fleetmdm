Database migration that fixes the built-in "CentOS Linux" label query to correctly detect CentOS 6 hosts where osquery misreports the platform.

## Key Components

- **`Up_20170314151620`** — Updates the `CentOS Linux` built-in label's query to match both `platform = 'centos'` and `name like '%centos%'`, and clears the platform filter. This ensures CentOS 6 hosts are correctly identified regardless of how osquery reports their platform.
- **`Down_20170314151620`** — No-op; this migration is not reversible.

## Usage Example

```go
// Migration is registered automatically via init()
// and applied by the MigrationClient during server startup.

// Effective SQL executed during Up:
UPDATE labels
SET query = 'select 1 from os_version where platform = ''centos'' or name like ''%centos%''',
    platform = ''
WHERE name = 'CentOS Linux' AND label_type = <BuiltIn>;
```

## Notes

- The migration is **idempotent** — safe to run multiple times without side effects.
- Only affects labels where `label_type = fleet.LabelTypeBuiltIn`, preventing unintended changes to user-defined labels.
- Clearing `platform` removes the strict platform filter, allowing the query itself to determine membership.
