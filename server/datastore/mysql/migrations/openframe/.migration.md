Provides the OpenFrame-specific database migration client and idempotent DDL helper utilities for managing schema changes independently from the upstream Fleet migration pipeline.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MigrationClient` | `*goose.Goose` | Goose migration client scoped to the `migration_status_openframe` tracking table, isolating OpenFrame schema versions from upstream Fleet migrations |
| `indexExists` | `func` | Queries `information_schema.STATISTICS` to check whether a named index exists on a given table |
| `columnExists` | `func` | Queries `information_schema.COLUMNS` to check whether a named column exists on a given table |

## Usage Example

```go
// Register MigrationClient with your goose migration files
err := openframe.MigrationClient.Up(db, migrationsDir)

// Use helpers inside a migration transaction for idempotent DDL
func Up_20240101000000(tx *sql.Tx) error {
    exists, err := columnExists(tx, "hosts", "openframe_tag")
    if err != nil {
        return err
    }
    if !exists {
        _, err = tx.Exec(`ALTER TABLE hosts ADD COLUMN openframe_tag VARCHAR(255)`)
    }
    return err
}

func Up_20240102000000(tx *sql.Tx) error {
    exists, err := indexExists(tx, "hosts", "idx_hosts_openframe_tag")
    if err != nil {
        return err
    }
    if !exists {
        _, err = tx.Exec(`CREATE INDEX idx_hosts_openframe_tag ON hosts (openframe_tag)`)
    }
    return err
}
```

## Notes

- `MigrationClient` uses a **separate tracking table** (`migration_status_openframe`) to prevent version conflicts when rebasing onto newer upstream Fleet releases.
- `indexExists` and `columnExists` are unexported helpers that compensate for MySQL's lack of `IF [NOT] EXISTS` support in `CREATE/DROP INDEX` and `ADD COLUMN` DDL statements.
