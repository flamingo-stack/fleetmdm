Database migration that adds `primary_ip` and `primary_mac` columns to the `hosts` table, along with a fulltext index for searching by IP and MAC address.

## Key Components

- **`Up20200311140000`** — Idempotent migration that adds two columns and a fulltext index to the `hosts` table:
  - `primary_ip` — IPv4/IPv6 address (`varchar(45)`, utf8mb4)
  - `primary_mac` — MAC address (`varchar(17)`, utf8mb4)
  - `host_ip_mac_search` — Fulltext index across both columns for efficient search
- **`Down20200311140000`** — No-op rollback (columns are not dropped)
- **`columnsExists`** — Guard check ensuring idempotent execution; skips the `ALTER TABLE` if both columns already exist

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up20200311140000, Down20200311140000)
}

// Run all pending migrations
err := MigrationClient.Up(db)
```

To apply manually using the Fleet migration tooling:

```bash
fleet prepare db --config /etc/fleet/fleet.yml
```

## Notes

- The `varchar(45)` length for `primary_ip` accommodates full IPv6 addresses (max 39 chars) with headroom.
- `varchar(17)` for `primary_mac` fits standard MAC notation (`AA:BB:CC:DD:EE:FF`).
- The down migration is intentionally a no-op — dropping columns risks data loss and is left to manual intervention.
