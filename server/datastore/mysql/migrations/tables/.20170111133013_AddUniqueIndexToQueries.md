Adds a unique index on the `name` column of the `queries` table, ensuring no two queries share the same name.

## Key Components

- **`Up_20170111133013`** — Idempotently adds a `UNIQUE` constraint (`constraint_query_name_unique`) on `queries.name`. Uses `constraintExists` to skip execution if the constraint is already present.
- **`Down_20170111133013`** — Drops the unique index from `queries.name`, reverting the migration.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration client at startup.
// To run manually via sql.Tx:
err := Up_20170111133013(tx)
if err != nil {
    log.Fatal(err)
}

// To roll back:
err = Down_20170111133013(tx)
```

> This migration is **idempotent** — running `Up` multiple times is safe because it checks for the constraint before applying it.
