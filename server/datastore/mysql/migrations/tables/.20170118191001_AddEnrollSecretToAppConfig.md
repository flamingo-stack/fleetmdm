Database migration that adds the `osquery_enroll_secret` column to the `app_configs` table, enabling enrollment secret configuration at the application level.

## Key Components

- **`Up_20170118191001`** — Adds a `VARCHAR(255) NOT NULL DEFAULT ''` column named `osquery_enroll_secret` to `app_configs`. The migration is idempotent; it checks for column existence before executing the `ALTER TABLE` statement.
- **`Down_20170118191001`** — Rolls back the migration by dropping the `osquery_enroll_secret` column from `app_configs`.
- **`init`** — Registers both migration functions with `MigrationClient` on package load.

## Usage Example

This migration is applied automatically via the migration client. To run it manually in tests or tooling:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

// Apply migration
if err := Up_20170118191001(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)

tx.Commit()

// Rollback migration

if err := Down_20170118191001(tx); err != nil {
```

> The `Up` function is safe to re-run — it uses `columnExists` to skip the `ALTER TABLE` if the column already exists, preventing duplicate column errors in environments where migrations may be applied more than once.
