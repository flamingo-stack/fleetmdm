Database migration that creates the `scheduled_query_stats` table, which stores performance and execution metrics for scheduled queries on a per-host basis.

## Key Components

- **`Up_20210506095025`** — Creates the `scheduled_query_stats` table using `CREATE TABLE IF NOT EXISTS` (idempotent). Defines a composite primary key on `(host_id, scheduled_query_id)` with cascading foreign keys to `hosts` and `scheduled_queries`.
- **`Down_20210506095025`** — No-op rollback; the table is not dropped on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Table Schema

| Column | Type | Description |
|---|---|---|
| `host_id` | `int unsigned` | Reference to the host |
| `scheduled_query_id` | `int unsigned` | Reference to the scheduled query |
| `average_memory` | `int` | Average memory used per execution |
| `denylisted` | `tinyint(1)` | Whether the query is denylisted |
| `executions` | `int` | Total execution count |
| `schedule_interval` | `int` | Query schedule interval |
| `last_executed` | `timestamp` | Last execution timestamp |
| `output_size` | `int` | Size of query output |
| `system_time` | `int` | CPU system time consumed |
| `user_time` | `int` | CPU user time consumed |
| `wall_time` | `int` | Wall-clock time consumed |
