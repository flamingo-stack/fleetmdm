Idempotent database migration that adds three interval/period configuration columns to the `hosts` table.

## Key Components

- **`Up_20170331111922`** — Adds `distributed_interval`, `logger_tls_period`, and `config_tls_refresh` columns (all `int DEFAULT 0`) to the `hosts` table. Skips execution if columns already exist, making it safe to re-run.
- **`Down_20170331111922`** — Reverses the migration by dropping all three added columns.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Column Reference

| Column | Type | Default | Purpose |
|---|---|---|---|
| `distributed_interval` | `int` | `0` | Interval for distributed query polling |
| `logger_tls_period` | `int` | `0` | TLS logger flush period |
| `config_tls_refresh` | `int` | `0` | TLS config refresh interval |

## Usage Example

```go
// Migration is auto-registered via init() and executed by the migration client.
// To apply manually during testing:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20170331111922(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

> **Note:** The `Up` function is idempotent — it checks for column existence via `columnsExists` before executing the `ALTER TABLE`, preventing errors on repeated runs.
