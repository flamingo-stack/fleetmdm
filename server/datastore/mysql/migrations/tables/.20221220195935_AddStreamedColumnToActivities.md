Database migration that adds a `streamed` boolean column and corresponding index to the `activities` table.

## Key Components

- **`Up_20221220195935`** — Idempotent migration that adds a `TINYINT(1)` column `streamed` (defaulting to `FALSE`) and creates an index `activities_streamed_idx` on the `activities` table. Guards against duplicate execution using `columnExists` and `indexExistsTx` checks.
- **`Down_20221220195935`** — No-op rollback function (column and index are not removed on downgrade).
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the migration client. To run it manually in context:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20221220195935(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

After applying, the `activities` table gains:

```text
Column : streamed  TINYINT(1) NOT NULL DEFAULT FALSE
Index  : activities_streamed_idx ON activities (streamed)
```

## Notes

- The migration is **idempotent** — safe to run multiple times without error.
- The `Down` function is intentionally empty; data loss from dropping the column was deemed acceptable to skip.
