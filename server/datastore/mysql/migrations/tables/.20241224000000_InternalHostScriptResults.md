Database migration that adds an `is_internal` boolean column to the `host_script_results` table, enabling scripts to execute even when scripting is globally disabled.

## Key Components

- **`Up_20241224000000`** — Idempotent migration that adds `is_internal BOOLEAN DEFAULT FALSE` to `host_script_results` if the column does not already exist
- **`Down_20241224000000`** — No-op rollback (column removal is not performed)
- **`init`** — Registers the migration with `MigrationClient`

## Usage Example

This migration runs automatically via the migration client. To apply manually:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20241224000000(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}

tx.Commit()
```

## Notes

- The migration is **idempotent** — safe to run multiple times; `columnExists` guards against duplicate `ALTER TABLE` errors
- The `is_internal` flag distinguishes system-level scripts (which bypass the global scripts-disabled setting) from user-initiated scripts
- Rollback is intentionally a no-op; reversing this migration requires a manual schema change
