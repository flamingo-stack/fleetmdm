Database migration that creates the `software_host_counts` table, which tracks how many hosts have each software item installed.

## Key Components

- **`Up_20220208144830`** — Creates the `software_host_counts` table (idempotent via `CREATE TABLE IF NOT EXISTS`) with the following schema:
  - `software_id` — Foreign key reference to software entries (unsigned `bigint`, primary key)
  - `hosts_count` — Number of hosts with the software installed (unsigned `int`)
  - `created_at` / `updated_at` — Standard audit timestamps
  - Two composite indexes optimizing queries by host count and last-updated time

- **`Down_20220208144830`** — No-op rollback; table removal is not implemented
