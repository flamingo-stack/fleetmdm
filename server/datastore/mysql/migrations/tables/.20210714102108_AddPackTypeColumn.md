Database migration that adds a `pack_type` column to the `packs` table, enabling categorization of packs by type.

## Key Components

- **`Up_20210714102108`** — Idempotent migration that adds a nullable `varchar(255)` `pack_type` column to the `packs` table. Uses `columnExists` to skip if the column is already present.
- **`Down_20210714102108`** — No-op rollback; the column is left in place on downgrade.

// Applied automatically by the migration client at startup.

## Notes

- The migration is **idempotent**: safe to run multiple times without error.
- `pack_type` defaults to `NULL`, so existing rows are unaffected.
- Rollback is intentionally a no-op — dropping the column on downgrade is not implemented.
