Database migration that creates the `host_certificate_templates` table, linking hosts to certificate templates with challenge/status tracking.

## Key Components

- **`Up_20251121124239`** — Creates the `host_certificate_templates` table using `CREATE TABLE IF NOT EXISTS` (idempotent). Columns include:
  - `id` — Auto-incrementing primary key
  - `host_uuid` — 36-character UUID identifying the host
  - `certificate_template_id` — Foreign reference to a certificate template
  - `fleet_challenge` — 32-character challenge string used during certificate issuance
  - `status` — Current state of the certificate request (up to 20 chars)
  - `created_at` / `updated_at` — Automatic timestamps

- **`Down_20251121124239`** — No-op rollback (table drop is not implemented)
