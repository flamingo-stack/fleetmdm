Database migration that creates the `password_reset_requests` table, which stores tokens used for user password reset flows.

## Key Components

- **`Up_20161118212641`** — Creates the `password_reset_requests` table with the following columns:
  - `id` — Auto-incrementing primary key
  - `expires_at` — Token expiration timestamp
  - `created_at` / `updated_at` — Audit timestamps with automatic defaults
  - `user_id` — Foreign reference to the owning user
  - `token` — The password reset token string (up to 1024 chars)
  - Uses `InnoDB` engine with `utf8mb4_unicode_ci` collation; idempotent via `CREATE TABLE IF NOT EXISTS`

- **`Down_20161118212641`** — Drops the `password_reset_requests` table if it exists

- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

This migration is automatically discovered and executed by the migration client on startup:

```go
// Registered via init() — no manual invocation required.
// The migration runner applies Up/Down based on schema version state.
MigrationClient.AddMigration(Up_20161118212641, Down_20161118212641)
```

