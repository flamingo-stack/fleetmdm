Database migration that adds a `"w"` prefix to existing Windows MDM configuration profile UUIDs in both the profiles table and the host-profile mapping table.

## Key Components

| Function | Description |
|---|---|
| `Up_20240129162819` | Idempotent migration that prepends `"w"` to any `profile_uuid` not already starting with `"w"` across two tables |
| `Down_20240129162819` | No-op rollback (migration is not reversible) |

**Tables affected:**
- `mdm_windows_configuration_profiles` — updates `profile_uuid` and preserves `updated_at`
- `host_mdm_windows_profiles` — updates the corresponding host mapping `profile_uuid`

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
MigrationClient.AddMigration(Up_20240129162819, Down_20240129162819)
```

The underlying SQL is idempotent — safe to re-run:

```sql
-- Only updates rows that haven't been prefixed yet
UPDATE mdm_windows_configuration_profiles
SET profile_uuid = CONCAT("w", profile_uuid)
WHERE profile_uuid NOT LIKE "w%";
```

## Notes

- **Idempotent:** The `WHERE profile_uuid NOT LIKE "w%"` guard prevents double-prefixing on repeated runs.
- **`updated_at` preservation:** The profiles table sets `updated_at = mwcp.updated_at` to avoid triggering timestamp changes on existing rows.
- **No rollback:** `Down_` is a no-op; stripping the prefix retroactively is not implemented.
