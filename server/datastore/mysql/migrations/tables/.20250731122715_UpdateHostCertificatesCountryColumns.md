Database migration that expands the `subject_country` and `issuer_country` columns in the `host_certificates` table from `varchar(2)` to `varchar(32)` to support longer country name values.

## Key Components

- **`Up_20250731122715`** — Alters both `subject_country` and `issuer_country` columns to `varchar(32)` with `utf8mb4_unicode_ci` collation. Uses `columnExists` checks to make the migration idempotent.
- **`Down_20250731122715`** — No-op rollback; the column widening is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. No manual invocation is needed.

```go
// Applied automatically during Fleet database migrations:
// fleet prepare db --config /etc/fleet/fleet.yml

// The migration expands two columns in host_certificates:
//   subject_country  varchar(2)  →  varchar(32)
//   issuer_country   varchar(2)  →  varchar(32)
```

## Notes

- The migration is **idempotent** — each `ALTER TABLE` is guarded by a `columnExists` check, so re-running it is safe.
- The rollback (`Down`) is intentionally empty; shrinking `varchar(32)` back to `varchar(2)` could truncate existing data.
