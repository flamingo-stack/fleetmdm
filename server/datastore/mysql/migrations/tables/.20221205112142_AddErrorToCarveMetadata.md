Database migration that adds an optional `error` TEXT column to the `carve_metadata` table for storing carve operation error messages.

## Key Components

- **`Up_20221205112142`** — Idempotent upgrade migration; checks for column existence before executing `ALTER TABLE` to avoid duplicate column errors.
- **`Down_20221205112142`** — No-op rollback; the column addition is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration runner at startup.
// Manually invoking the up migration within a transaction:
err := Up_20221205112142(tx)
if err != nil {
    log.Fatal("migration failed:", err)
}
```

## Notes

- The migration is **idempotent** — safe to run multiple times; `columnExists` guards against adding a duplicate column.
- The `error` column is defined as `TEXT` (nullable), allowing `NULL` when no error occurred during a carve operation.
- The down migration is intentionally a no-op; destructive rollbacks (dropping columns) are avoided to prevent data loss.
