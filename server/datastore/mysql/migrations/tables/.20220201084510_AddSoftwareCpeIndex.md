Database migration that adds an index on the `cpe` column of the `software_cpe` table to improve CPE lookup performance.

## Key Components

- **`Up_20220201084510`** — Creates the `software_cpe_cpe_idx` index on `software_cpe(cpe)`. The migration is idempotent; it checks for the index's existence before attempting creation.
- **`Down_20220201084510`** — No-op rollback; the index is left in place on downgrade.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Applied automatically during fleet database migrations
// Equivalent SQL:
// CREATE INDEX software_cpe_cpe_idx ON software_cpe(cpe);
```

> **Note:** The idempotency check via `indexExistsTx` ensures this migration is safe to re-run without error if the index already exists.
