Database migration that optimizes indexing on the `software_titles_host_counts` table by replacing an outdated index with a new covering index that includes the `global_stats` column.

## Key Components

- **`Up_20260316120005`** — Drops the legacy index `idx_software_titles_host_counts_team_counts_title` (if present) and creates `idx_software_titles_host_counts_team_global_hosts`, covering `(team_id, global_stats, hosts_count, software_title_id)` to optimize filtered queries on software title host counts.
- **`Down_20260316120005`** — No-op rollback; the migration is considered forward-only.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the Fleet migration framework:

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

Or programmatically through the migration client:

```go
// Registered automatically via init()
```
