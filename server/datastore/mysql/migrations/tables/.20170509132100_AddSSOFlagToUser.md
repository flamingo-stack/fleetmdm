Adds a database migration that introduces the `sso_enabled` column to the `users` table, enabling Single Sign-On (SSO) support per user.

## Key Components

- **`Up_20170509132100`** — Idempotent migration that adds a `sso_enabled` (`TINYINT NOT NULL DEFAULT FALSE`) column to the `users` table after the `position` column. Skips execution if the column already exists.
- **`Down_20170509132100`** — Rolls back the migration by dropping the `sso_enabled` column from the `users` table.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the migration client. To run it manually in context:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

// Apply migration
if err := Up_20170509132100(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()

// Rollback migration
tx, _ = db.Begin()
if err := Down_20170509132100(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The `Up` migration is **idempotent** — safe to run multiple times without error.
- Default value is `FALSE`, meaning SSO is disabled for all existing users after migration.
