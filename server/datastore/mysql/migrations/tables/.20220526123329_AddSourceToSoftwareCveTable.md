Idempotent database migration that adds a `source` column to the `software_cve` table.

## Key Components

- **`Up_20220518124708`** — Adds an integer `source` column (default `0`) to `software_cve` if it does not already exist. Uses `columnExists` to ensure the migration is safe to re-run.
- **`Down_20220518124708`** — No-op rollback; the column addition is not reversed.
- **`init`** — Registers the migration pair with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration client at startup.
// To run manually via the migration runner:
MigrationClient.AddMigration(Up_20220518124708, Down_20220518124708)
```

After this migration runs, the `software_cve` table gains:

```text
`source` INT DEFAULT '0'
```

## Notes

- The migration is **idempotent**: it checks for the column's existence before executing `ALTER TABLE`, so re-running it on an already-migrated schema is safe.
- The rollback (`Down`) is intentionally a no-op; dropping the column must be handled manually if needed.
