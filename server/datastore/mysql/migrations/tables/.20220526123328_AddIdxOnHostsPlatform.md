Database migration that adds an index on the `platform` column of the `hosts` table to improve query performance for platform-based host filtering.

## Key Components

- **`Up_20220510110838`** — Creates the `hosts_platform_idx` index on `hosts(platform)` if it does not already exist. The migration is idempotent, using `indexExistsTx` to skip creation if the index is already present.
- **`Down_20220510110838`** — No-op rollback; the index is not dropped on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration runner at startup.
// To run manually via goose or the Fleet migration client:
// MigrationClient.AddMigration(Up_20220510110838, Down_20220510110838)

// The resulting index:
// CREATE INDEX hosts_platform_idx ON hosts (platform);

// Idempotency check prevents errors on re-runs:
if !indexExistsTx(tx, "hosts", "hosts_platform_idx") {
    tx.Exec("CREATE INDEX hosts_platform_idx ON hosts (platform);")
}
```
