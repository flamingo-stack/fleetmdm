## Key Components

- **`Up_20231206142340`** — Idempotent migration that adds `fleet_enroll_ref` (`VARCHAR(36)`, `utf8mb4_unicode_ci`, `NOT NULL DEFAULT ''`) to `host_mdm` if the column does not already exist.
- **`Down_20231206142340`** — No-op rollback; the column is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go

// To run manually using goose or a compatible client:
MigrationClient.AddMigration(Up_20231206142340, Down_20231206142340)
```

The `columnExists` guard makes re-running the migration safe in environments where the column may have been added out-of-band.
