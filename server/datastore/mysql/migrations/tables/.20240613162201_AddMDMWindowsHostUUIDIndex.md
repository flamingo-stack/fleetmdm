Adds a database index on the `host_uuid` column of the `mdm_windows_enrollments` table to improve query performance for Windows MDM enrollment lookups.

## Key Components

- **`Up_20240613162201`** — Idempotent migration that adds `idx_mdm_windows_enrollments_host_uuid` on `mdm_windows_enrollments.host_uuid` if it does not already exist.
- **`Down_20240613162201`** — No-op rollback; the index is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the Fleet migration runner. To apply or roll back manually:

```go
// Apply
err := Up_20240613162201(tx)

// Rollback (no-op)
err := Down_20240613162201(tx)
```
