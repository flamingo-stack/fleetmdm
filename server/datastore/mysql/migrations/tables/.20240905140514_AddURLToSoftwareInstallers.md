Database migration that adds a `url` column to the `software_installers` table, intended to store source URLs for software uploaded via GitOps batch operations.

## Key Components

- **`Up_20240905140514`** — Idempotent migration that adds a `VARCHAR(255)` `url` column (utf8mb4_unicode_ci, NOT NULL, DEFAULT `''`) to `software_installers` if it doesn't already exist.
- **`Down_20240905140514`** — No-op rollback; the column is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. The `columnExists` guard makes it safe to re-run:

```go
// Applied automatically on fleet server startup.
// Manually trigger via the migration client:
MigrationClient.AddMigration(Up_20240905140514, Down_20240905140514)
```

After migration, the `url` field is available on software installers:

```go
// url is populated only for GitOps batch-uploaded software
INSERT INTO software_installers (url, ...) VALUES ('https://example.com/app.pkg', ...)
```

## Notes

- The migration is **idempotent** — safe to run multiple times due to the `columnExists` check.
- The `url` column is only populated for software uploaded in batch via **GitOps**; manually uploaded installers leave this field as an empty string.
- Rollback (`Down`) is intentionally a no-op; dropping the column is not performed.
