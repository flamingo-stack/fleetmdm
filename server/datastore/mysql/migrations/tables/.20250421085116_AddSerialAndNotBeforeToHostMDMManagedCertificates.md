  - `not_valid_before` — `datetime(6)` (nullable), stores certificate validity start timestamp

## Notes

- The migration is idempotent — if both columns already exist, it exits early without error.
- `serial` uses `utf8mb4` charset to support international certificate fields.
- `not_valid_before` uses microsecond precision (`datetime(6)`) for accurate certificate lifecycle tracking.
- The down migration is intentionally a no-op; destructive rollbacks are not automated.
