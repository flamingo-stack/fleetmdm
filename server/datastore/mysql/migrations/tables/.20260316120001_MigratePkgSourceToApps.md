Database migration that updates the `source` field of `software_titles` records from `'pkg_packages'` to `'apps'` for entries that have a non-empty `bundle_identifier`.

## Key Components

- **`Up_20260316120001`** — Executes an `UPDATE` on the `software_titles` table, remapping `source = 'pkg_packages'` → `source = 'apps'` where `bundle_identifier != ''`. The operation is idempotent and safe to re-run.
- **`Down_20260316120001`** — No-op rollback; the migration is intentionally irreversible.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the Fleet migration runner. To run it manually during development:

```bash
# Apply all pending migrations (includes this one)
fleet prepare db --config /path/to/config.yml

# Or using the migration client directly in tests
tx, _ := db.Begin()
err := Up_20260316120001(tx)
```

## Notes

- Only PKG-sourced titles **with** a `bundle_identifier` are migrated; those without one (bare `.pkg` installers with no bundle) are left unchanged.
- The downward migration is a no-op — restoring `'pkg_packages'` would require knowing which rows were originally migrated, which is not tracked.
