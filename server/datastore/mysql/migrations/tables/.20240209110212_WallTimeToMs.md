Database migration that converts `wall_time` values in the `scheduled_query_stats` table from seconds to milliseconds by multiplying existing values by 1000.

## Key Components

- **`Up_20240209110212`** — Applies the migration; multiplies all `wall_time` column values by `1000` to convert from seconds to milliseconds.
- **`Down_20240209110212`** — No-op rollback; the conversion is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration is registered automatically via init() and run by the migration client.
// To apply manually within a transaction:
tx, _ := db.Begin()
if err := Up_20240209110212(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

> **Note:** This migration is idempotent in intent but not mathematically reversible — running `Up` twice will multiply values by `1000` a second time. Ensure the migration is applied exactly once via the `MigrationClient`.
