Database migration that adds patch policy support columns to the `policies` table, including a `type` discriminator and a foreign-keyed `patch_software_title_id` reference.

## Key Components

- **`Up_20260316120010`** — Idempotent forward migration that adds:
  - `type` — `ENUM('dynamic', 'patch')`, defaults to `'dynamic'`
  - `patch_software_title_id` — nullable `INT UNSIGNED` foreign key referencing `software_titles(id)` with `ON DELETE CASCADE`
  - `fk_patch_software_title_id` — foreign key constraint
  - `idx_team_id_patch_software_title_id` — unique index on `(team_id, patch_software_title_id)` to enforce one patch policy per software title per team
- **`Down_20260316120010`** — No-op rollback (columns are left in place)
