Adds a database migration that creates a unique composite index on the `scripts` table to enforce unique script names within a team.

## Key Components

- **`Up_20231009094542`** — Idempotent migration that adds a `UNIQUE KEY` index `idx_scripts_team_name` on `(team_id, name)` columns of the `scripts` table, preventing duplicate script names per team. Skips execution if the index already exists.
- **`Down_20231009094542`** — No-op rollback; the index is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. To apply manually during development:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20231009094542(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The migration is **idempotent** — safe to run multiple times; uses `indexExistsTx` to check for the index before attempting creation.
- The `DOWN` migration is intentionally a no-op, meaning the index is retained if the migration is rolled back.
