Database migration that creates the `fleet_library_apps` table and adds a `fleet_library_app_id` foreign key column to `software_installers`, linking software installers to Fleet's curated app library.

## Key Components

- **`Up_20241003145349`** — Creates the `fleet_library_apps` table and conditionally adds `fleet_library_app_id` to `software_installers`
- **`Down_20241003145349`** — No-op rollback (destructive rollback omitted by design)

### `fleet_library_apps` Table Schema

| Column | Type | Description |
|---|---|---|
| `token` | `varchar(255)` | Homebrew `full_token` (unique; used to deduplicate version updates) |
| `platform` | `varchar(255)` | Target OS platform |
| `installer_url` | `varchar(255)` | Download URL for the installer binary |
| `sha256` | `varchar(64)` | SHA-256 hash of the installer binary for S3 keying and integrity validation |
| `bundle_identifier` | `varchar(255)` | Links the app to a row in `software_titles` |
| `install_script_content_id` | `int unsigned` | FK → `script_contents.id` (CASCADE delete) |
| `uninstall_script_content_id` | `int unsigned` | FK → `script_contents.id` (CASCADE delete) |

### `software_installers` Alteration

Adds `fleet_library_app_id` (nullable FK → `fleet_library_apps.id`, `SET NULL` on delete) to track which Fleet Library entry sourced a given installer. The column addition is guarded by `columnExists` to make the migration idempotent.
