Database migration that adds an `enable_analytics` column to the `app_configs` table, defaulting to disabled for existing installations.

## Key Components

- **`Up_20210622160235`** — Idempotent migration that adds `enable_analytics` (`tinyint(1) NOT NULL DEFAULT 0`) to `app_configs` if the column does not already exist. Existing installations default to `0` (off); new installs have this enabled during setup.
- **`Down_20210622160235`** — No-op rollback (column removal is not performed).
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. No manual invocation is needed.

```go
// Registered automatically on package import via init()
MigrationClient.AddMigration(Up_20210622160235, Down_20210622160235)
```

To run manually in a test or tooling context:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20210622160235(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)

```

## Notes

- The migration is **idempotent** — safe to run multiple times; `columnExists` guards against duplicate `ALTER TABLE` errors.
- Analytics are **off by default** for existing installations and must be explicitly enabled during the setup flow for new installs.
