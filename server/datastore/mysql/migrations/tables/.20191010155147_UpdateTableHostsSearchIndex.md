Database migration that updates the `hosts_search` fulltext index on the `hosts` table to include the `uuid` column alongside `host_name`, enabling host search by UUID.

## Key Components

- **`Up20191010155147`** — Idempotent migration that drops the existing `hosts_search` fulltext index (if present) and recreates it covering both `host_name` and `uuid` columns.
- **`Down20191010155147`** — Reverts the index to its original definition, covering only `host_name`.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migrations are registered automatically via init() and run by the migration client.
// To apply manually in tests or tooling:

db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up20191010155147(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()

// To roll back:
tx, _ = db.Begin()
if err := Down20191010155147(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The `Up` migration is **idempotent** — it checks for index existence before dropping or creating, making it safe to re-run.
- The `Down` migration is **not idempotent** — it will error if `hosts_search` does not exist when rolled back.
- Uses `indexExistsTx` (a shared helper) to inspect index presence within the active transaction.
