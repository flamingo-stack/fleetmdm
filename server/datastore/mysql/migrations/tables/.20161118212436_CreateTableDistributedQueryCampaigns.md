Database migration that creates the `distributed_query_campaigns` table, which tracks live/distributed osquery campaign executions linked to queries and users.

## Key Components

| Export | Description |
|--------|-------------|
| `Up_20161118212436` | Creates the `distributed_query_campaigns` table with soft-delete support |
| `Down_20161118212436` | Drops the `distributed_query_campaigns` table |

### Table Schema: `distributed_query_campaigns`

| Column | Type | Description |
|--------|------|-------------|
| `id` | `INT UNSIGNED` | Auto-increment primary key |
| `created_at` | `TIMESTAMP` | Record creation time |
| `updated_at` | `TIMESTAMP` | Last update time (auto-updated) |
| `deleted_at` | `TIMESTAMP` | Soft-delete timestamp |
| `deleted` | `TINYINT(1)` | Soft-delete flag |
| `query_id` | `INT UNSIGNED` | FK reference to a query |
| `status` | `INT` | Campaign execution status |
| `user_id` | `INT UNSIGNED` | FK reference to initiating user |
