Adds a database migration that creates a composite index on the `policy_membership_history` table to optimize GROUP BY query performance.

## Key Components

- **`Up_20211116184029`** — Creates the `policy_membership_history_groupby_idx` composite index on `(host_id, policy_id, id)` if it does not already exist. Uses `indexExistsTx` for idempotent execution.
- **`Down_20211116184029`** — No-op rollback; the index is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration runs automatically via MigrationClient on startup.
// The index is created only if absent, making re-runs safe:
if !indexExistsTx(tx, "policy_membership_history", "policy_membership_history_groupby_idx") {
    tx.Exec("CREATE INDEX policy_membership_history_groupby_idx ON policy_membership_history (host_id, policy_id, id)")
}
```

The resulting index supports efficient lookups and aggregations such as:

```sql
SELECT host_id, policy_id, MAX(id)
FROM policy_membership_history
GROUP BY host_id, policy_id;
```

## Notes

- **Idempotent** — Safe to run multiple times; skips creation if the index already exists.
- **Down migration is a no-op** — Dropping the index on rollback is not implemented; manual cleanup is required if removal is needed.
