Database migration that creates the `label_query_executions` table, which tracks whether a host matches a given label query.

## Key Components

- **`Up_20161118212549`** — Creates the `label_query_executions` table with the following columns:
  - `id` — Auto-incrementing primary key
  - `created_at` / `updated_at` — Automatic timestamps
  - `matches` — Boolean flag indicating if the host matches the label query (defaults to `false`)
  - `label_id` — Foreign reference to the associated label
  - `host_id` — Foreign reference to the associated host
  - Unique composite index `idx_lqe_label_host` on `(label_id, host_id)` to enforce one record per label-host pair
- **`Down_20161118212549`** — Drops the `label_query_executions` table if it exists
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

This migration is automatically registered and executed by the migration client:

```go
// Registered automatically via init()
MigrationClient.AddMigration(Up_20161118212549, Down_20161118212549)

// Apply migration
err := Up_20161118212549(tx)

// Roll back migration
err := Down_20161118212549(tx)
```

> The `Up` migration uses `CREATE TABLE IF NOT EXISTS`, making it safe to re-run without causing errors.
