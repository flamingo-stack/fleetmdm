Database migration that adds a `global_stats` column to the `software_titles_host_counts` table and updates the primary key to support distinguishing between global statistics and team-specific host counts.

## Key Components

- **`Up_20240730215453`** — Idempotent migration that:
  1. Adds `global_stats` (`tinyint unsigned`, default `0`) to `software_titles_host_counts`
  2. Drops and recreates the primary key as `(software_title_id, team_id, global_stats)`
  3. Marks existing `team_id = 0` rows as global stats (`global_stats = 1`)
  4. Inserts "no team" rows (`team_id = 0, global_stats = 0`) derived by subtracting team-specific counts from global totals
- **`Down_20240730215453`** — No-op rollback (intentionally empty)
- **Idempotency guard** — Checks `INFORMATION_SCHEMA.STATISTICS` before running to safely skip already-migrated databases

## Data Model Change

```text
Before: PRIMARY KEY (software_title_id, team_id)
After:  PRIMARY KEY (software_title_id, team_id, global_stats)

global_stats = 1 → aggregate count across all teams
global_stats = 0 → scoped count (specific team or "no team")
```
