Database migration that creates a built-in Fleet label for Fedora Linux hosts, inserting it into the `labels` table with idempotent behavior.

## Key Components

- **`Up_20241002104105`** — Inserts the `BuiltinLabelFedoraLinux` label using `INSERT IGNORE` for idempotency. Uses a hard-coded timestamp (`2024-09-27`) to keep `schema.sql` stable. Returns a descriptive error if a duplicate label name exists via `ER_DUP_ENTRY`.
- **`Down_20241002104105`** — No-op rollback; the migration is not reversible.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Label Details

| Field | Value |
|---|---|
| Name | `fleet.BuiltinLabelFedoraLinux` |
| Description | `All Fedora hosts` |
| Query | `select 1 from os_version where name = 'Fedora Linux';` |
| Platform | `rhel` |
| Label Type | `fleet.LabelTypeBuiltIn` |
| Membership Type | `fleet.LabelMembershipTypeDynamic` |

## Usage Example

This migration runs automatically via the Fleet migration client. To apply manually:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20241002104105(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

**Error handling:** If a user-created label already shares the name defined by `fleet.BuiltinLabelFedoraLinux`, the migration returns an actionable error prompting the operator to rename it before re-running.
