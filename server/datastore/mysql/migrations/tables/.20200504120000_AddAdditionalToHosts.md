Database migration that adds optional JSON columns for additional host data and application configuration queries.

## Key Components

- **`Up_20200504120000`** — Applies the migration by conditionally adding two nullable JSON columns:
  - `additional` on the `hosts` table
  - `additional_queries` on the `app_configs` table
- **`Down_20200504120000`** — No-op rollback (columns are not removed)
- **`init`** — Registers both migration functions with `MigrationClient`

## Behavior Notes

- **Idempotent** — Uses `columnExists` checks before each `ALTER TABLE`, making it safe to run multiple times without errors.
- **Down migration is a no-op** — Rolling back does not drop the columns; data is preserved.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Run all pending migrations (including this one)
if err := MigrationClient.Up(db, ""); err != nil {
    log.Fatal(err)
}
```

To apply only this migration manually:

```go
tx, _ := db.Begin()
if err := Up_20200504120000(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```
