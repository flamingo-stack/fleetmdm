Database migration that creates the `software_title_team_pins` table, enabling teams to pin specific software title versions for controlled deployment management.

## Key Components

- **`Up_20260617172853`** — Creates the `software_title_team_pins` table with a composite primary key on `(team_id, title_id)`, storing a pinned version string per team/title pair. Includes a cascading foreign key to `software_titles(id)` and an auto-updating `updated_at` timestamp. Migration is idempotent via `CREATE TABLE IF NOT EXISTS`.
- **`Down_20260617172853`** — No-op rollback (table is not dropped on downgrade).
- **`init`** — Registers both migration functions with `MigrationClient`.
