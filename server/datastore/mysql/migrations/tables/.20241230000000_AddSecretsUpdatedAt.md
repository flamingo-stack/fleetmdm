Database migration that adds a `secrets_updated_at` column to Apple MDM profile and declaration tables, enabling detection of secret variable changes even when profile content remains unchanged.

## Key Components

- **`Up_20241230000000`** — Idempotent migration adding `secrets_updated_at DATETIME(6) NULL` to four tables and a computed `token` column to `mdm_apple_declarations`
- **`Down_20241230000000`** — No-op rollback (columns are not dropped)
- **`init`** — Registers the migration with `MigrationClient`

### Tables Modified

| Table | Changes |
|---|---|
| `mdm_apple_configuration_profiles` | Adds `secrets_updated_at DATETIME(6)`, modifies `created_at` / `uploaded_at` |
| `host_mdm_apple_profiles` | Adds `secrets_updated_at DATETIME(6)` |
| `mdm_apple_declarations` | Adds `secrets_updated_at DATETIME(6)`, modifies timestamps, adds computed `token BINARY(16)` |
| `host_mdm_apple_declarations` | Adds `secrets_updated_at DATETIME(6)` |

### Design Notes

- Uses `DATETIME` instead of `TIMESTAMP` to avoid the Y2K38 (year 2038) overflow issue
- `columnExists` guards make every `ALTER` idempotent — safe to re-run
- The `token` column on `mdm_apple_declarations` is a stored generated column: `MD5(CONCAT(raw_json, IFNULL(secrets_updated_at, '')))`, used to detect when a declaration must be re-applied to a host

## Usage Example

```go
// Migration is registered automatically via init().
// To apply manually in tests or tooling:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20241230000000(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```
