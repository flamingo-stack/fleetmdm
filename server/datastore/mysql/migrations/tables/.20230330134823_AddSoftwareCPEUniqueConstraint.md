| Function | Description |

| `Down_20230330134823` | No-op rollback (constraint removal not implemented) |
| `_20230329161600_remove_duplicates` | Deletes duplicate `software_cpe` rows, keeping the highest `id` per `software_id` |
| `_20230329161600_add_unq_constraint` | Adds `UNIQUE` constraint on `software_id` using `ALGORITHM=INPLACE, LOCK=NONE` for online DDL |

## Notes

- **Idempotent**: The `Up` function safely re-runs — duplicate removal is a no-op if no duplicates exist, and `constraintExists` guards against re-adding the constraint.
- **Online DDL**: Uses `ALGORITHM=INPLACE, LOCK=NONE` to minimize table locking in production MySQL environments.
- **Down migration**: Returns `nil` without reversing the constraint — dropping the constraint on rollback is not implemented.
