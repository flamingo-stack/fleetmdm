Database migration that corrects the bundle identifier for the SAP Privileges installer, changing it from the incorrect `corp.sap.privileges.pkg` to the correct `corp.sap.privileges` in the `software_titles` table.

## Key Components

- **`Up_20250926123048`** — Forward migration that idempotently fixes Privileges app bundle identifiers and reassigns any affected software installers to the correct title record
- **`Down_20250926123048`** — No-op rollback (migration is considered a data correction, not reversible)

## Migration Logic

```text
1. Query software_titles for both bundle IDs
   ├── If neither exists → exit (nothing to fix)
   ├── If correct ID missing → INSERT new title row
   └── Continue
2. Find software_installers linked to the incorrect title
3. Re-point each installer to the correct title
4. Delete the incorrect software_title row
```

## Usage Example

```go
// Applied automatically via MigrationClient at startup
// Manual invocation example (for testing):
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20250926123048(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- **Idempotent** — safe to run multiple times; checks for existing correct state before making changes
- Handles the edge case where osquery has not yet indexed the Privileges app (inserts the correct title row using `INSERT IGNORE`)
- The `Down` migration is intentionally a no-op; deleted rows are not restored
