Database migration that removes the foreign key constraint `certificate_templates_ibfk_1` from the `certificate_templates` table. The migration is idempotent and has no rollback operation.

## Key Components

- **`Up_20251203170808`** — Checks for the existence of `certificate_templates_ibfk_1` before attempting to drop it, preventing errors on repeated runs.
- **`Down_20251203170808`** — No-op rollback; the constraint is not restored on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient` at package load time.

## Usage Example

```go
// Applied automatically by the migration client on schema upgrade.
// To run manually within a transaction:
tx, _ := db.Begin()
if err := Up_20251203170808(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

> **Note:** The `Down` migration is intentionally empty. Restoring the foreign key after removal must be handled manually if required.
