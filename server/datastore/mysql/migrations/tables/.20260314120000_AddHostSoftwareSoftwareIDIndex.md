Adds a database migration (version `20260314120000`) that creates a secondary index on the `software_id` column of the `host_software` table to optimize join and filter query performance.

## Key Components

- **`Up_20260314120000`** — Idempotently adds the index `idx_host_software_software_id` on `host_software.software_id` using `indexExistsTx` to skip creation if it already exists.
- **`Down_20260314120000`** — No-op rollback; the index is left in place on downgrade.
- **`init`** — Registers the migration with `MigrationClient`.

## Usage Example

This migration runs automatically via the Fleet migration framework. To apply manually:

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

The underlying SQL executed during `Up`:

```sql
ALTER TABLE host_software ADD INDEX idx_host_software_software_id (software_id);
```

## Notes

- The migration is **idempotent** — safe to re-run; if the index already exists, the `ALTER TABLE` is skipped.
- The down migration is intentionally a no-op to avoid data loss risks from dropping an index that may have existed prior to this migration.
