Database migration that adds an `orbit_node_key` column to the `hosts` table, enabling Orbit-based node authentication in FleetMDM.

## Key Components

| Function | Description |
|---|---|
| `Up_20220908181826` | Adds `orbit_node_key` column and unique index to `hosts` table |
| `Down_20220908181826` | No-op rollback (column removal not implemented) |

## Behavior

- **Idempotent** — checks for column and index existence before applying changes, safe to run multiple times
- Adds `orbit_node_key` as `VARCHAR(255)` with `utf8mb4_bin` collation (case-sensitive), defaulting to `NULL`
- Creates a unique index `idx_host_unique_orbitnodekey` to enforce one-to-one Orbit node key per host
