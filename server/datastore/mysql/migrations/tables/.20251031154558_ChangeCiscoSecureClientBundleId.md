Database migration that corrects the bundle identifier for Cisco Secure Client software titles, replacing the incorrect `com.cisco.pkg.anyconnect.vpn` (pkg-ref) with the proper `com.cisco.secureclient.gui` identifier.

## Key Components

- **`Up_20251031154558`** — Idempotent migration that:
  1. Queries `software_titles` for both the incorrect and correct Cisco bundle identifiers
  2. Inserts the correct `com.cisco.secureclient.gui` title if it hasn't been indexed by osquery yet
  3. Reassigns any `software_installers` (`.pkg` extension) pointing to the incorrect title to the correct one
  4. Deletes the incorrect `com.cisco.pkg.anyconnect.vpn` title entry
- **`Down_20251031154558`** — No-op rollback; the migration is considered non-reversible

## Usage Example

This migration runs automatically via the `MigrationClient` on database upgrade. No manual invocation is required.

```go
// Registered automatically on package init
func init() {
    MigrationClient.AddMigration(Up_20251031154558, Down_20251031154558)
}
```

To run manually during development:

```bash
fleet prepare db --dev
```

## Notes

- This is intentionally idempotent — safe to run multiple times with no side effects
- Mirrors the pattern established in `20250926123048_ChangePrivilegesInstallerBundleId.go`, which fixed the same class of bug for a different installer
- Only affects `.pkg` software installers; other formats are not modified
- If neither bundle identifier exists in the database, the migration exits early with no changes
