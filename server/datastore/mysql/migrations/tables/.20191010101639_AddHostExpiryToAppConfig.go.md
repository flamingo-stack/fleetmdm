Adds `host_expiry_enabled` and `host_expiry_window` columns to the `app_configs` table, enabling configuration of automatic host expiry behavior in Fleet MDM.

## Key Components

- **`Up20191010101639`** — Idempotent migration that adds two columns to `app_configs`:
  - `host_expiry_enabled` (`TINYINT(1)`, default `FALSE`) — toggles host expiry on/off
  - `host_expiry_window` (`INT`, default `0`) — defines the expiry window duration
- **`Down20191010101639`** — Rolls back the migration by dropping both columns
- **`init`** — Registers both migration functions with `MigrationClient`
