Database migration that adds `enrollment_status`, `created_at`, and `updated_at` columns to the `host_mdm` table, with `enrollment_status` as a virtual generated column derived from existing MDM enrollment fields.

## Key Components

- **`Up_20241022140321`** — Idempotent migration that alters `host_mdm` to add:
  - `enrollment_status` — Virtual `ENUM` column (`'On (manual)'`, `'On (automatic)'`, `'Pending'`, `'Off'`) computed from `is_server`, `enrolled`, and `installed_from_dep`
  - `created_at` — Timestamp with microsecond precision, defaulting to insert time
  - `updated_at` — Timestamp with microsecond precision, auto-updated on row change
- **`Down_20241022140321`** — No-op rollback (columns are not dropped)
- **Idempotency guard** — Uses `columnsExists` to skip the `ALTER TABLE` if all three columns are already present

## Enrollment Status Logic

| `is_server` | `enrolled` | `installed_from_dep` | Result |
|---|---|---|---|
| `1` | any | any | `NULL` |
| `0` | `1` | `0` | `On (manual)` |
| `0` | `1` | `1` | `On (automatic)` |
| `0` | `0` | `1` | `Pending` |
| `0` | `0` | `0` | `Off` |
