Database migration that creates the `host_batteries` table for storing battery information associated with managed hosts.

## Key Components

- **`Up_20220627104817`** — Creates the `host_batteries` table with an auto-increment primary key, supporting multiple batteries per host. Defines a unique constraint on `(host_id, serial_number)` to prevent duplicate battery records.
- **`Down_20220627104817`** — No-op rollback; table removal is not implemented.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- Migration is **idempotent** via `CREATE TABLE IF NOT EXISTS`.
- Uses `InnoDB` engine with `utf8mb4_unicode_ci` collation.
- The unique index `idx_host_batteries_host_id_serial_number` enforces one record per battery serial number per host.
