Database migration that creates the `host_emails` table, associating email addresses with hosts along with their source and timestamps.

## Key Components

- **`Up_20211221110132`** — Creates the `host_emails` table if it does not already exist (idempotent). Defines the following columns:
  - `id` — Auto-incrementing primary key
  - `host_id` — Foreign reference to a host record
  - `email` — Email address (up to 255 characters)
  - `source` — Origin of the email entry (up to 255 characters)
  - `created_at` / `updated_at` — Automatic timestamps
  - Indexes on `(host_id, email)` and `email` for query performance

- **`Down_20211221110132`** — No-op rollback; table is not dropped on downgrade.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20211221110132, Down_20211221110132)
}

// Apply the migration manually (handled by the migration runner)
err := Up_20211221110132(tx)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Uses `CREATE TABLE IF NOT EXISTS` making the `Up` migration safe to re-run.
- Table uses `InnoDB` engine with `utf8mb4_unicode_ci` collation for full Unicode support.
- The `Down` migration is intentionally a no-op to avoid accidental data loss during rollback.
