Database migration that adds a `fim_interval` column to the `app_configs` table, enabling configuration of the File Integrity Monitoring (FIM) polling interval.

## Key Components

| Function | Description |
|---|---|
| `Up20170519105648` | Idempotently adds `fim_interval` (INT, NOT NULL, default `300`) to `app_configs` after the `enable_sso` column |
| `Down20170519105648` | Drops the `fim_interval` column from `app_configs`, reverting the migration |

## Migration Details

- **Table:** `app_configs`
- **Column:** `fim_interval` (`INT NOT NULL DEFAULT 300`)
- **Default value:** `300` seconds (5 minutes)
- **Idempotent:** Yes — uses `columnExists()` guard in `Up` to prevent re-adding the column if it already exists

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically at package init
MigrationClient.AddMigration(Up20170519105648, Down20170519105648)

// Apply migration
err := Up20170519105648(tx)

// Rollback migration

```
