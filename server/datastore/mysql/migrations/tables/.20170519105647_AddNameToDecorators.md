Database migration that adds a `name` column (VARCHAR 128, UTF-8) to the `decorators` table.

## Key Components

- **`Up_20170519105647`** — Idempotently adds a `name` column after `built_in` in the `decorators` table; skips execution if the column already exists.
- **`Down_20170519105647`** — Removes the `name` column from `decorators`, reversing the migration.
- **`init`** — Registers both migration functions with `MigrationClient`.
