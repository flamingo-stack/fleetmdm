Database migration that updates macOS PKG uninstall scripts for software installers, replacing the existing default script with a new embedded version while preserving package ID configurations.

## Key Components

- **`Up_20241002104104`** — Migrates existing macOS PKG uninstall scripts in `software_installers` to a new script template embedded from `data/uninstall_pkg.sh`, using regex to detect and preserve package IDs from the old format
- **`Down_20241002104104`** — No-op rollback; migration is considered non-reversible
- **`newScript`** — Embedded shell script loaded from `data/uninstall_pkg.sh` via `//go:embed`
- **`insertScriptContents`** — Helper that upserts script content into `script_contents` using MD5 checksum deduplication, returning the row ID

## Migration Logic

```text
1. Find all darwin/pkg software_installers with uninstall_script_content_id
2. For each, fetch the current script from script_contents
3. Match against regex for the known default uninstall script
4. If matched, extract package IDs and inject into new script template
5. Upsert new script content (deduped by MD5 checksum)
6. Update software_installers.uninstall_script_content_id to new row ID
```

## Usage Example

```go
// Applied automatically via MigrationClient during fleet db migrations
// Registered in init():
MigrationClient.AddMigration(Up_20241002104104, Down_20241002104104)

// Manual invocation (within a transaction):
if err := Up_20241002104104(tx); err != nil {
    log.Fatalf("migration failed: %v", err)
}
```

> This migration is **idempotent**: only scripts matching the exact previous default template are updated. Custom or already-migrated scripts are left unchanged.
