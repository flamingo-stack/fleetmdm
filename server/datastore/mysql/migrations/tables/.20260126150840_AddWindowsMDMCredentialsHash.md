Adds two columns to the `mdm_windows_enrollments` table to support credential tracking for Windows MDM enrollments.

## Key Components

- **`Up_20260126150840`** — Idempotent migration that adds `credentials_hash` (`BINARY(16)`) and `credentials_acknowledged` (`BOOLEAN NOT NULL DEFAULT FALSE`) columns to `mdm_windows_enrollments` if they don't already exist.
- **`Down_20260126150840`** — No-op rollback; columns are not removed on downgrade.

## Usage Example

This migration runs automatically via the `MigrationClient` on startup. To apply manually:

```bash
fleet db migrate
```

To verify the columns were added:

```sql
SHOW COLUMNS FROM mdm_windows_enrollments LIKE 'credentials_%';
```
