Database migration that renames the `browser` column to `extension_for` in the `software` and `software_titles` tables.

## Key Components

- **`Up_20251015103600`** — Idempotent upgrade migration; checks for column existence before renaming `browser` → `extension_for` in both `software` and `software_titles` tables.
- **`Down_20251015103600`** — No-op rollback; the rename is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration client on startup.
// Manual invocation (e.g. in tests):
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20251015103600(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- Migration is **idempotent**: uses `columnExists` to skip the `ALTER TABLE` if `browser` has already been renamed, making it safe to re-run.
- The rollback (`Down`) is intentionally empty — reversing a column rename would require a separate migration or manual intervention.
