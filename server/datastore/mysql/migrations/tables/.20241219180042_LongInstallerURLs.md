Database migration that lengthens the `url` column in the `software_installers` table from its previous size to `VARCHAR(4095)` to support longer installer URLs uploaded via GitOps batch operations.

## Key Components

- **`Up_20241219180042`** — Idempotent upgrade migration; checks if the `url` column exists before altering it to `VARCHAR(4095)` with `utf8mb4_unicode_ci` collation and a default empty string
- **`Down_20241219180042`** — No-op rollback; the column length increase is not reversed
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

This migration is applied automatically by the Fleet migration runner. To apply manually:

```go
// Applied via the migration client registered in init()
MigrationClient.AddMigration(Up_20241219180042, Down_20241219180042)
```

```bash
# Run all pending migrations
fleetctl prepare db --config /etc/fleet/fleet.yml
```

## Notes

- The migration is **idempotent** — it first checks for column existence via `columnExists()` before attempting the `ALTER TABLE`, making it safe to re-run
- The `url` column is intended exclusively for software installers uploaded in batch through GitOps workflows
- The rollback (`Down`) is intentionally empty; shortening a `VARCHAR` column risks data truncation and is left as a manual operation if needed
