Database migration that corrects mismatched `software_titles` associations for both `software_installers` and `software` records, ensuring each entry references a title with the matching `source` field.

## Key Components

| Symbol | Description |
|---|---|
| `Up_20260316120002` | Migration entry point — finds and remaps mismatched software title links in two passes |
| `Down_20260316120002` | No-op rollback (migration is considered irreversible data correction) |
| `getOrInsertTitleID` | Finds an existing `software_titles` row by `bundle_identifier` + `source`, or inserts a new one |
| `badInstaller` | Internal struct mapping installer rows with wrong title sources |
| `badSoftware` | Internal struct mapping software rows whose `source` diverges from their linked title's `source` |

## Migration Logic

The migration runs two idempotent fix passes:

1. **Installer pass** — targets `software_installers` rows on the `darwin` platform whose linked `software_titles` row has a non-`apps` source but carries a non-empty `bundle_identifier`. Each is repointed to the correct (or newly created) `apps`-sourced title.

2. **Software pass** — targets `software` rows where `software.source != software_titles.source` and a `bundle_identifier` exists. Each is repointed to a title matching the software's own source value.

## Usage Example

This file is auto-registered via `init()` and executed by the migration runner:

// Registered automatically on package import
