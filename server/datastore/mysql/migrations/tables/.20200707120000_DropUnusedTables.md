Database migration that removes unused legacy tables from the schema, including decorator, YARA, file integrity monitoring, and options tables.

## Key Components

| Function | Description |
|---|---|
| `Up_20200707120000` | Drops 7 legacy tables using idempotent `DROP TABLE IF EXISTS` statements |
| `Down_20200707120000` | No-op rollback — table restoration is not implemented |

**Tables Dropped:**

- `decorators`
- `yara_file_paths`
- `yara_signature_paths`
- `yara_signatures`
- `file_integrity_monitoring_files`
- `file_integrity_monitorings`
- `options`

## Usage Example

This migration runs automatically via the `MigrationClient` registered in `init()`. To apply manually:

```bash
# Apply the migration
fleet prepare db --migrations-dir ./server/datastore/mysql/migrations/tables

# Verify tables are removed
mysql -u fleet -p fleet -e "SHOW TABLES LIKE 'decorators';"
```

## Notes

- **Idempotent**: Uses `DROP TABLE IF EXISTS` — safe to run multiple times without errors.
- **Irreversible**: The `Down` function is a no-op; dropped tables and their data cannot be restored via rollback. Ensure backups exist before applying.
- Registered automatically via `init()` into the shared `MigrationClient`.
