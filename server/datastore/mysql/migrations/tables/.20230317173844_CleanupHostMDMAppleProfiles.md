Database migration that removes failed MDM profile removal records containing a specific `MDMClientError (89)` error from the `host_mdm_apple_profiles` table.

## Key Components

- **`Up_20230317173844`** — Deletes rows from `host_mdm_apple_profiles` where `operation_type = 'remove'`, `status = 'failed'`, and `detail` contains `MDMClientError (89)`. The migration is idempotent and safe to re-run.
- **`Down_20230317173844`** — No-op; the cleanup is non-reversible by design.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the migration client. To run it manually in a transaction:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20230317173844(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- Targets a known Apple MDM error code (`89`) that indicates a profile was already removed on the device, making the `failed` status a false negative that should be cleaned up.
- The `Down` migration is intentionally a no-op — deleted records are not restored on rollback.
