Database migration that adds the `LockEndUserInfo` field to MDM MacOS setup configuration for both global app config and per-team configs, setting it to mirror the existing `EnableEndUserAuthentication` value.

## Key Components

- **`Up_20260316120006(tx *sql.Tx) error`** — Applies the migration by updating `LockEndUserInfo` in app config and all team configs, deriving its value from the existing `EnableEndUserAuthentication` flag.
- **`Down_20260316120006(tx *sql.Tx) error`** — No-op rollback; the migration is additive and idempotent.
- **`init()`** — Registers the migration with `MigrationClient`.

## Behavior

The migration is idempotent (JSON config updates only, no DDL changes):

1. **App config** — Calls `updateAppConfigJSON` to set `MDM.MacOSSetup.LockEndUserInfo` equal to the current value of `MDM.MacOSSetup.EnableEndUserAuthentication`.
2. **Team configs** — Queries all non-null team configs, unmarshals each into `fleet.TeamConfig`, applies the same `LockEndUserInfo` derivation, and writes the updated JSON back to the `teams` table.

## Usage Example

This migration runs automatically via the Fleet migration client. To apply manually during development:

```go
// Registered automatically via init()
MigrationClient.AddMigration(Up_20260316120006, Down_20260316120006)

// Called internally by the migration runner:
if err := Up_20260316120006(tx); err != nil {
    return fmt.Errorf("migration 20260316120006 failed: %w", err)
}
```
