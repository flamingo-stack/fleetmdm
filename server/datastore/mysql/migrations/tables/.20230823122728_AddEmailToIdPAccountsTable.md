Idempotent database migration that adds an `email` column to the `mdm_idp_accounts` table.

## Key Components

- **`Up_20230823122728`** — Adds a `varchar(255)` `email` column with `utf8mb4_unicode_ci` collation and a default empty string. Guards against duplicate execution using `columnExists`.
- **`Down_20230823122728`** — No-op rollback; the column addition is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- Migration is **idempotent**: checks for the `email` column's existence before attempting `ALTER TABLE`, making it safe to re-run without error.
- The rollback (`Down`) is intentionally empty — dropping the column on rollback was deemed unnecessary for this migration.
- Targets the `mdm_idp_accounts` table used for Identity Provider (IdP) account tracking in the MDM subsystem.
