Database migration that removes duplicate indexes identified by `pt-duplicate-key-checker` across six Fleet database tables to improve query performance and reduce storage overhead.

## Key Components

- **`Up_20241122171434`** — Idempotent migration that drops or replaces redundant indexes on six tables. Uses `indexExistsTx` guards before each `ALTER TABLE` to ensure safe re-execution.
- **`Down_20241122171434`** — No-op rollback; dropped indexes are not recreated since their removal is non-destructive.
- **`init`** — Registers both migration functions with `MigrationClient`.

### Indexes Removed

| Table | Index Dropped | Reason |
|---|---|---|
| `app_config_json` | `id` | Duplicate of `PRIMARY KEY` |
| `host_users` | `idx_uid_username` | Duplicate of `PRIMARY KEY` |
| `migration_status_tables` | `id` | Duplicate of `PRIMARY KEY` |
| `policy_membership` | `idx_policy_membership_policy_id` | Left-prefix of `PRIMARY KEY` |
| `software_cve` | `software_cve_software_id` | Left-prefix of `unq_software_id_cve` |
| `software` | `software_listing_idx` | Rebuilt without trailing `id` column (clustered index suffix) |

## Usage Example

```go
// Migration runs automatically via MigrationClient on schema upgrade.
// To apply manually within a transaction:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20241122171434(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

> **Note:** Each `ALTER TABLE` is guarded by `indexExistsTx`, making this migration safe to run multiple times without error.
