Database migration that initializes the `WindowsEntraTenantIDs` field in the MDM section of Fleet's app configuration JSON.

## Key Components

- **`Up_20260205184907`** — Applies the migration by updating the app config JSON to set `MDM.WindowsEntraTenantIDs` to an empty slice using `optjson.SetSlice`. The operation is idempotent and safe to re-run.
- **`Down_20260205184907`** — No-op rollback; the JSON-only change requires no explicit reversal.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is automatically applied by the Fleet migration runner. No direct invocation is needed, but the affected config field can be used as follows:

```go
// After migration, WindowsEntraTenantIDs is available in AppConfig
config.MDM.WindowsEntraTenantIDs = optjson.SetSlice([]string{
    "tenant-id-1",
    "tenant-id-2",
})
```
