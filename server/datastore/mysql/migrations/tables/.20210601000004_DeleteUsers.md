Database migration that removes disabled users and drops the `enabled` column from the `users` table.

## Key Components

- **`Up_20210601000004`** — Idempotent up migration that checks for the `enabled` column, deletes all users where `enabled = false`, then drops the column entirely.
- **`Down_20210601000004`** — No-op rollback; the data deletion is irreversible.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Behavior Notes

- **Idempotency**: The migration checks `columnExists(tx, "users", "enabled")` before executing, making it safe to run multiple times without error.
- **Data loss warning**: Deleted rows are not recoverable via rollback — `Down` is intentionally empty.

## Usage Example

This migration is auto-registered and executed by the migration client. No direct invocation is needed:

```go
// Triggered automatically during schema migration
if err := MigrationClient.Up(db, ""); err != nil {
    log.Fatal("migration failed:", err)
}
```

To apply manually against a transaction:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20210601000004(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```
