Adds a composite database index on the `host_certificates` table to optimize MDM certificate sweep queries that filter on `origin` and `deleted_at`.

## Key Components

- **`Up_20260527215817`** — Idempotent migration that creates the `idx_host_certs_origin_deleted` index on `(origin, deleted_at)`. Skips execution if the index already exists. InnoDB automatically appends the primary key (`id`) to secondary indexes, satisfying `ORDER BY id LIMIT` clauses without a filesort.
- **`Down_20260527215817`** — No-op rollback; the index is considered safe to leave in place.

## Usage Example

This migration runs automatically via the `MigrationClient` on startup. To apply or roll back manually:

```go
// Apply
fleet db migrate

// Verify index creation
SHOW INDEX FROM host_certificates WHERE Key_name = 'idx_host_certs_origin_deleted';
```

The index supports the unenrolled-host MDM certificate sweep query pattern:

```sql
SELECT * FROM host_certificates
WHERE origin = ? AND deleted_at IS NOT NULL
ORDER BY id
LIMIT ?;
```
