Database migration that adds a `self_service` boolean column to the `software_installers` and `host_software_installs` tables, defaulting to `false`.

## Key Components

- **`Up_20240521143024`** — Idempotent migration that adds `self_service bool NOT NULL DEFAULT false` to both `software_installers` and `host_software_installs` tables. Uses `columnExists` guards to prevent errors on re-runs.
- **`Down_20240521143024`** — No-op rollback; columns are left in place on downgrade.
- **`init`** — Registers the migration with `MigrationClient`.

## Usage Example

This migration runs automatically via the Fleet migration client. To apply manually:

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

To verify the column was added:

```sql
SHOW COLUMNS FROM software_installers LIKE 'self_service';
SHOW COLUMNS FROM host_software_installs LIKE 'self_service';
```

## Notes

- Migration is **idempotent** — safe to run multiple times without side effects.
- The `self_service` flag enables end-user initiated software installs without admin intervention.
- Rollback is intentionally a no-op; remove columns manually if a true rollback is needed.
