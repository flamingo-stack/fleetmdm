Database migration that adds the `PreserveHostActivitiesOnReenrollment` setting to the `AppConfig` JSON, with smart defaulting based on whether the installation is new or upgraded.

## Key Components

- **`Up_20260522195224`** — Applies the migration. Counts existing users to determine the default value: `true` for upgraded installations (preserving prior behavior) and `false` for fresh installs. Updates `AppConfig.ActivityExpirySettings.PreserveHostActivitiesOnReenrollment` via `updateAppConfigJSON`.
- **`Down_20260522195224`** — No-op rollback; the JSON config change requires no explicit reversal.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Behavior

The migration is idempotent — it only performs `UPDATE`/JSON config modifications, making it safely re-runnable without side effects.

| Installation Type | `preserve` Value | Rationale |
|---|---|---|
| Upgraded (users exist) | `true` | Maintains backward compatibility |
| Fresh install | `false` | Clean default behavior |

## Usage Example

This migration runs automatically via the Fleet migration client. No manual invocation is required.

```go
// Migration registered in init()
MigrationClient.AddMigration(Up_20260522195224, Down_20260522195224)

// Internal logic (simplified)
preserve := usersCount > 0
config.ActivityExpirySettings.PreserveHostActivitiesOnReenrollment = preserve
```
