Database migration that adds a `bundle_identifier` column to the `software_titles` table, backfills existing data from the `software` table, deduplicates rows sharing the same bundle identifier, and enforces uniqueness via an index.

## Key Components

| Function | Description |
|---|---|
| `Up_20240709124958` | Applies the migration: adds column, backfills data, deduplicates rows, and adds unique index |
| `Down_20240709124958` | No-op rollback (migration is not reversible) |

## Migration Steps

The `Up` function executes the following operations in order:

1. **Column addition** — Adds `bundle_identifier VARCHAR(255)` to `software_titles` (skipped if already present via `columnExists` guard)
2. **Backfill** — Copies non-empty `bundle_identifier` values from `software` rows into their linked `software_titles` rows
3. **Installer deduplication** — Reassigns `software_installers.title_id` to the lowest `software_titles.id` sharing the same `bundle_identifier`, resolving FK conflicts before row deletion
4. **Row deduplication** — Deletes duplicate `software_titles` rows (keeping the smallest `id`) only when not referenced by any installer
5. **Orphan fix** — Updates `software` rows with a `NULL` `title_id` by matching on `bundle_identifier`
6. **Unique index** — Adds `idx_software_titles_bundle_identifier` as an idempotent, guarded step
