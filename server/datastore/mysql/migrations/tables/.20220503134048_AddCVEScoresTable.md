Database migration that creates the `cve_scores` table for storing CVE vulnerability scoring data including CVSS scores, EPSS probabilities, and CISA exploit status.

## Key Components

- **`Up_20220503134048`** — Creates the `cve_scores` table with the following columns:
  - `cve` (`varchar(20)`) — Primary key, CVE identifier (e.g., `CVE-2022-12345`)
  - `cvss_score` (`double`) — CVSS severity score
  - `epss_probability` (`double`) — Exploit Prediction Scoring System probability
  - `cisa_known_exploit` (`boolean`) — Whether CISA has flagged this CVE as a known exploited vulnerability
- **`Down_20220503134048`** — No-op rollback (table is left in place)

## Notes

- Migration is **idempotent** via `CREATE TABLE IF NOT EXISTS`, safe to re-run
- Uses `InnoDB` engine with `utf8mb4_unicode_ci` collation
- Registered automatically via `init()` with `MigrationClient`
