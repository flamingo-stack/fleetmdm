Database migration that adds a `public_ip` column to the `hosts` table, storing public IP addresses for managed hosts.

## Key Components

- **`Up_20220316155700`** — Idempotent migration that adds a `public_ip` column (`varchar(45)`, `utf8mb4_unicode_ci`, `NOT NULL DEFAULT ''`) to the `hosts` table. Skips execution if the column already exists.
- **`Down_20220316155700`** — No-op rollback; the column is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

```go
// Applied automatically by the migration runner at startup.

```

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

The `columnExists` guard ensures safe re-runs:

```go
if !columnExists(tx, "hosts", "public_ip") {
    // ALTER TABLE only executes if the column is absent
}
```

## Notes

- Column supports both IPv4 and IPv6 addresses (max 45 characters covers full IPv6 notation).
- The empty-string default (`DEFAULT ''`) avoids `NULL` handling in downstream queries.
- Rollback is intentionally a no-op; dropping the column would require a separate, explicit migration.
