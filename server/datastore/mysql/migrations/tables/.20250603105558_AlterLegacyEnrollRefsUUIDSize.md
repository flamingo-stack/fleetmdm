Database migration that expands the `host_uuid` column size to `VARCHAR(255)` across three MDM enrollment reference tables, ensuring consistent UTF-8 encoding for UUID storage.

## Key Components

| Function | Description |
|---|---|
| `Up_20250603105558` | Alters `host_uuid` to `VARCHAR(255)` with `utf8mb4_unicode_ci` collation in three tables |
| `Down_20250603105558` | No-op rollback (column resize is not destructive) |

**Affected Tables:**
- `legacy_host_mdm_enroll_refs`
- `legacy_host_mdm_idp_accounts`
- `host_mdm_idp_accounts`

## Behavior Notes

- **Idempotent:** Each `ALTER TABLE` is guarded by a `columnExists` check before execution, making it safe to re-run.
- **No rollback:** Downsizing a `VARCHAR` column risks data truncation, so `Down_20250603105558` is intentionally a no-op.
- **Collation:** Columns are set to `utf8mb4_unicode_ci`, which correctly handles the full Unicode range needed for UUIDs and internationalized identifiers.

This migration runs automatically via the `MigrationClient` registered in `init()`:
