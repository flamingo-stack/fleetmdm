Database migration that adds a `label_membership_type` column to the `labels` table and sets the "All Hosts" built-in label to use manual membership.

## Key Components

- **`Up20200407120000`** — Idempotent up migration that:
  1. Adds `label_membership_type` (`int unsigned`, default `0`) to `labels` if it does not already exist
  2. Sets `label_membership_type = 1` (manual) for the "All Hosts" built-in label (`label_type = 1`)
- **`Down20200407120000`** — No-op rollback; the column is left in place on downgrade
- **`init`** — Registers both migration functions with `MigrationClient`

## Membership Type Values

| Value | Meaning |
|-------|---------|
| `0` | Dynamic (query-based membership) |
| `1` | Manual (membership managed explicitly) |

## Usage Example

This migration is applied automatically by the Fleet migration runner. To run it manually during development:

```go
// Migrations are registered via init() and executed by the client
if err := MigrationClient.Up(db, ""); err != nil {
    log.Fatal(err)
}
```

To roll back (no-op in this case):

```go
if err := MigrationClient.Down(db, ""); err != nil {
    log.Fatal(err)
}
```

## Notes

- The up migration is **idempotent** — safe to run multiple times; `columnExists` guards the `ALTER TABLE` statement
