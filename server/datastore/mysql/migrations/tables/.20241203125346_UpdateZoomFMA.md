Database migration that removes the existing Zoom fleet-maintained app (FMA) entry from `fleet_library_apps` and clears its scheduled cron run, forcing a fresh pull of the updated Zoom FMA on next server start.

## Key Components

- **`Up_20241203125346`** — Applies the migration by:
  1. Deleting the `zoom` entry for the `darwin` platform from `fleet_library_apps`
  2. Removing scheduled cron stats for `maintained_apps` from `cron_stats`, triggering a re-run on next startup
- **`Down_20241203125346`** — No-op rollback; the migration is intentionally non-reversible
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

This migration runs automatically via Fleet's migration framework on server startup:

```go
// Registered automatically via init()
MigrationClient.AddMigration(Up_20241203125346, Down_20241203125346)

// Up migration deletes stale Zoom FMA entry
tx.Exec(`DELETE FROM fleet_library_apps WHERE token = 'zoom' AND platform = 'darwin'`)

// Forces maintained_apps cron to re-fetch updated Zoom FMA
tx.Exec(`DELETE FROM cron_stats WHERE name = ? AND stats_type = ?`,
    fleet.CronMaintainedApps, fleet.CronStatsTypeScheduled)
```

> **Note:** This is an idempotent migration — re-running it on a database where the Zoom entry has already been removed is safe and produces no errors.
