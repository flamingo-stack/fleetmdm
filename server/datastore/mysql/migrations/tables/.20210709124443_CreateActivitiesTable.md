Database migration that creates the `activities` table for tracking user actions and audit events within the Fleet MDM platform.

## Key Components

- **`Up_20210709124443`** — Creates the `activities` table if it does not already exist (idempotent). Defines columns for tracking user identity, activity type, and a flexible JSON `details` payload. Includes a nullable foreign key (`user_id`) referencing the `users` table with `ON DELETE SET NULL` to preserve activity records when users are removed.
- **`Down_20210709124443`** — No-op rollback; the table is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

| Column          | Type                  | Notes                                      |
