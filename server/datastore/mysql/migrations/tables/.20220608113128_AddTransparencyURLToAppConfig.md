Database migration that adds `TransparencyURL` support to the Fleet Desktop section of the app configuration JSON, with a pre-flight validation check.

## Key Components

- **`Up_20220608113128`** — Applies the migration by calling `updateAppConfigJSON` to validate that no existing `transparency_url` value is already set in `FleetDesktop`; errors if an unexpected value is found.
- **`Down_20220608113128`** — No-op rollback; the migration is considered idempotent and does not require cleanup.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration is auto-registered via init() and executed by the migration client.
// The Up function validates the current app_config_json before proceeding:

err := updateAppConfigJSON(tx, func(config *fleet.AppConfig) error {
    if config.FleetDesktop.TransparencyURL != "" {
        return errors.New("unexpected transparency_url value in app_config_json")
    }
    return nil
})
```

## Notes

- The migration is **idempotent by design** — it validates state rather than destructively altering schema, making it safe to re-run.
- `TransparencyURL` is expected to be empty at migration time; a non-empty value indicates a data conflict and causes the migration to fail explicitly.
- The `Down` function is intentionally a no-op since no schema changes are made that need reversing.
