## Key Components

- **`Up_20240625093543`** — Idempotent migration that adds a nullable `VARCHAR(255)` `filename` column (utf8mb4_unicode_ci collation) with a unique index (`idx_teams_filename`) to the `teams` table. Skips execution if the column already exists.
- **`Down_20240625093543`** — No-op rollback; the migration is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go

// To apply manually during development:
MigrationClient.AddMigration(Up_20240625093543, Down_20240625093543)
```

The migration uses the shared `columnExists` helper to guard against duplicate `ALTER TABLE` errors, making it safe to re-run.
