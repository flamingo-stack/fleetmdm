Database migration that creates the `public_keys` table for storing cryptographic public keys indexed by their hash.

## Key Components

- **`Up_20170131232841`** — Creates the `public_keys` table (idempotent via `CREATE TABLE IF NOT EXISTS`) with a 64-character hash primary key and a `text` field for the key material.
- **`Down_20170131232841`** — Drops the `public_keys` table if it exists, reversing the migration.
- **`init()`** — Registers both migration functions with `MigrationClient` at package load time.

## Schema

| Column | Type       | Constraints              |
|--------|------------|--------------------------|
| `hash` | `char(64)` | `NOT NULL`, Primary Key  |
| `key`  | `text`     | `NOT NULL`               |

Engine: `InnoDB`, Charset: `utf8`

## Usage Example

```go
// Migrations are registered automatically via init().
// To apply programmatically using the migration client:
err := MigrationClient.Up(db)
if err != nil {
    log.Fatal("migration failed:", err)
}

// To roll back:
err = MigrationClient.Down(db)
```

## Notes

- The migration is **idempotent** — safe to run multiple times without error.
- The `hash` column (64 chars) is sized for SHA-256 hex digests.
- Part of the Fleet MDM migration chain; see other files in the `tables` package for related migrations.
