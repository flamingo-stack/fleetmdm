## Notes

- **Idempotent**: Uses [`columnExists`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/datastore/mysql/migrations/tables) guard, making it safe to re-run.

- Default value of `0` means errors are **not** ignored unless explicitly set.
