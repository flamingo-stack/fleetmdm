Database migration that creates the `licenses` table, establishing the schema for storing license keys and tokens with revocation tracking.

## Key Components

| Component | Description |
|-----------|-------------|
| `Up_20170127014618` | Creates the `licenses` table if it does not already exist (idempotent) |
| `Down_20170127014618` | Drops the `licenses` table if it exists (rollback) |

### Table Schema — `licenses`

| Column | Type | Notes |
|--------|------|-------|
| `id` | `int(10)` | Auto-increment primary key |
| `updated_at` | `timestamp` | Auto-updated on row modification |
| `revoked` | `tinyint(1) unsigned` | Boolean revocation flag, defaults to `FALSE` |
| `key` | `text` | License key value (required) |
| `token` | `text` | Optional token associated with the license |
