Database migration that creates the `network_interfaces` table, storing network interface metadata (MAC address, IP, traffic statistics, MTU, etc.) per host with CASCADE delete and fulltext IP search support.

## Key Components

| Export | Description |
|--------|-------------|
| `Up_20161128234849` | Creates the `network_interfaces` table if it does not exist |
| `Down_20161128234849` | Drops the `network_interfaces` table if it exists |
| `init()` | Registers both migration functions with `MigrationClient` |

### Table Schema — `network_interfaces`

| Column | Type | Notes |
|--------|------|-------|
| `id` | `INT UNSIGNED` | Auto-increment primary key |
| `host_id` | `INT UNSIGNED` | FK → `hosts(id)` with `ON DELETE CASCADE` |
| `mac` | `VARCHAR(255)` | MAC address |
| `ip_address` | `VARCHAR(255)` | Fulltext-indexed |
| `broadcast` | `VARCHAR(255)` | Broadcast address |
| `interface` | `VARCHAR(255)` | Interface name |
| `ibytes` / `obytes` | `BIGINT` | Bytes in/out |
| `ipackets` / `opackets` | `BIGINT` | Packets in/out |
| `ierrors` / `oerrors` | `BIGINT` | Errors in/out |
| `mask` | `VARCHAR(255)` | Subnet mask |
| `metric` / `mtu` / `type` | `INT` | Interface properties |
| `last_change` | `BIGINT` | Timestamp of last change |

**Indexes:**
- `PRIMARY KEY (id)`
- `UNIQUE (ip_address, host_id, interface)`
- `FULLTEXT KEY ip_address_search (ip_address)`
- `FOREIGN KEY (host_id)` → `hosts(id)` ON DELETE CASCADE
