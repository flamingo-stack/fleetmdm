Adds a database migration that creates an index on the `cve` column of the `operating_system_vulnerabilities` table to improve CVE-based query performance.

## Key Components

- **`Up_20250224184002`** — Idempotently adds the index `idx_os_vulnerabilities_cve` on `operating_system_vulnerabilities.cve` if it does not already exist.
- **`Down_20250224184002`** — No-op rollback; the index is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the Fleet migration client. To apply manually:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20250224184002(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

> The migration is idempotent — re-running it when `idx_os_vulnerabilities_cve` already exists is safe and produces no changes.
