Database migration that creates the `statistics` table, used for tracking anonymous usage/telemetry identifiers.

## Key Components

- **`Up_20210719153709`** — Creates the `statistics` table with `id`, `created_at`, `updated_at`, and `anonymous_identifier` columns. The migration is idempotent (`CREATE TABLE IF NOT EXISTS`).
- **`Down_20210719153709`** — No-op rollback; the table is not dropped on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Table Schema

| Column | Type | Notes |
|---|---|---|
| `id` | `int(10) unsigned` | Auto-increment primary key |
| `created_at` | `timestamp` | Defaults to current timestamp |
| `updated_at` | `timestamp` | Auto-updates on row change |
| `anonymous_identifier` | `varchar(255)` | Required; stores anonymous telemetry ID |

## Usage Example

```go
// Migration is registered automatically via init().
// To apply manually using the migration client:
if err := MigrationClient.Up(db); err != nil {
    log.Fatal("migration failed:", err)
}
```

> **Note:** The down migration is intentionally empty — dropping the `statistics` table on rollback was not implemented. Ensure data retention requirements are considered before running rollbacks in production.
