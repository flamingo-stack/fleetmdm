Database migration that consolidates Fleet's scheduled query packs (global and team-based) into the unified `queries` table, then cleans up obsolete pack structures.

## Key Components

| Function | Description |
|---|---|
| `Up_20230721161508` | Migration entry point — orchestrates all migration steps in order |
| `Down_20230721161508` | Rollback function (stub/no-op for this migration) |
| `_20230719152138_migrate_global_packs` | Copies scheduled queries from `global` packs into `queries` with `automations_enabled = true` |
| `_20230719152138_migrate_team_packs` | Copies scheduled queries from `team-{id}` packs into `queries` with team ownership set |
| `_20230719152138_migrate_non_scheduled` | Duplicates non-scheduled global queries as team queries for admin/maintainer authors |
| `_20230719152138_clean_up` | Truncates stats tables and removes migrated packs and their scheduled queries |
| `_20230719152138_QueryName` | Generates a unique query name from name, scheduled query ID, and timestamp |

## Internal Type

`_20230719152138_Query` is a migration-local snapshot of `fleet.Query`, ensuring the migration remains correct even if the production type changes later.

## Logging Type Resolution

Logging type is derived from the `snapshot` and `removed` fields:

```text
snapshot = true              → "snapshot"
snapshot != true, removed = true  → "differential"
snapshot != true, removed = false → "differential_ignore_removals"
```

