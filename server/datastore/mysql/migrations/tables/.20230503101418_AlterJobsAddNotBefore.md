## Key Components

- **`Up_20230503101418`** — Idempotently adds a `not_before TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP` column to the `jobs` table. Uses `columnExists` to skip execution if the column is already present.
- **`Down_20230503101418`** — No-op rollback; the column addition is considered non-destructive to reverse automatically.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- The migration is **idempotent** — safe to run multiple times without error.
- `not_before` defaults to `CURRENT_TIMESTAMP`, meaning existing jobs become immediately eligible unless updated explicitly.
- The down migration is intentionally empty; restoring the previous schema requires a separate manual step if needed.
