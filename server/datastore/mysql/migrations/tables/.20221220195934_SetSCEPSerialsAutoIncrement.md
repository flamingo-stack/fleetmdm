Database migration that sets the `scep_serials` table's `AUTO_INCREMENT` value to `2`, reserving serial `1` for the Certificate Authority (CA).

## Key Components

- **`Up_20221220195934`** — Idempotent migration that checks if `scep_serials` is empty before altering `AUTO_INCREMENT`. If rows already exist, it skips the change to avoid disrupting existing serial assignments.
- **`Down_20221220195934`** — No-op rollback; the increment change is considered safe to leave in place.

## Behavior Details

- Skips the `ALTER TABLE` if `scep_serials` already contains rows (idempotency guard).
- Sets `AUTO_INCREMENT = 2` so that serial `1` is implicitly reserved for the CA certificate, aligning with standard SCEP/PKI conventions.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
func init() {
    MigrationClient.AddMigration(Up_20221220195934, Down_20221220195934)
}
```

To apply manually during development:

```bash
fleet db migrate
```

## Notes

- **Idempotent**: Safe to run multiple times — existing data is never modified.
- Serial `1` is intentionally skipped per Fleet issue [#8167](https://github.com/fleetdm/fleet/issues/8167), which documents the CA serial reservation requirement.
