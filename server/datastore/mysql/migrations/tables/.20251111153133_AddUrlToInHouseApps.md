Database migration that adds a `url` column to the `in_house_apps` table.

## Key Components

- **`Up_20251111153133`** — Adds a `url` VARCHAR(4095) column (UTF8MB4, non-null, default empty string) to `in_house_apps`. The migration is idempotent, using `columnExists` to skip the `ALTER TABLE` if the column already exists.
- **`Down_20251111153133`** — No-op rollback; the column addition is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the `MigrationClient` during Fleet's database migration lifecycle:

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

To manually inspect the resulting schema change:

```sql
DESCRIBE in_house_apps;
-- url | varchar(4095) | NO | | | 
```

## Notes

- Column length of `4095` characters accommodates long URLs within MySQL's row size limits while using the 4-byte `utf8mb4` character set.
- The idempotency check (`columnExists`) makes this safe to re-run against databases where the column may already exist from a prior partial migration.
- The down migration is intentionally a no-op — dropping the column would risk data loss.
