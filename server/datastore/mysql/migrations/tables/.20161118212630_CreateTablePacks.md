Database migration that creates the `packs` table, which stores query pack definitions for organizing and scheduling osquery packs in Fleet MDM.

## Key Components

- **`Up_20161118212630`** — Creates the `packs` table with soft-delete support (`deleted`, `deleted_at`), scheduling controls (`disabled`), and a unique constraint on `name`.
- **`Down_20161118212630`** — Drops the `packs` table if it exists.
- **`init`** — Registers both migration functions with `MigrationClient`.

### Table Schema: `packs`

| Column | Type | Notes |
|---|---|---|
| `id` | `int unsigned` | Auto-increment primary key |
| `created_at` | `timestamp` | Defaults to `CURRENT_TIMESTAMP` |
| `updated_at` | `timestamp` | Auto-updates on row change |
| `deleted_at` | `timestamp` | Soft-delete timestamp |
| `deleted` | `tinyint(1)` | Soft-delete flag |
| `disabled` | `tinyint(1)` | Disables pack scheduling |
| `name` | `varchar(255)` | Required; unique |
| `description` | `varchar(255)` | Optional |
| `platform` | `varchar(255)` | Target platform filter |
| `created_by` | `int unsigned` | FK reference to creator |
