Database migration that adds `created_at` and `updated_at` timestamp columns to the `network_interfaces` table, with idempotent up migration support.

## Key Components

- **`Up_20170223094154`** — Adds `created_at` and `updated_at` columns (both `TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP`) only if they do not already exist, making the migration safe to re-run.
- **`Down_20170223094154`** — Drops both timestamp columns, reverting the migration.
- **`init()`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migrations run automatically via MigrationClient.
// To apply manually within a transaction:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20170223094154(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()

// To roll back:
tx, _ = db.Begin()
if err := Down_20170223094154(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The up migration uses `columnsExists` to check for existing columns before altering the table, preventing errors on repeated execution.
- Both columns default to `CURRENT_TIMESTAMP` and update automatically on row modification.
