Database migration that adds Identity Provider (IdP) / SSO-related columns to the `app_configs` table.

## Key Components

- **`Up_20170502143928`** — Idempotent migration that adds seven SSO/IdP columns to `app_configs` using `columnsExists` to guard against duplicate execution.
- **`Down_20170502143928`** — Rolls back the migration by dropping all seven added columns.
- **`init()`** — Registers both migration functions with `MigrationClient`.

### Columns Added

| Column | Type | Description |
|---|---|---|
| `entity_id` | `VARCHAR(255)` | SAML entity identifier |
| `issuer_uri` | `VARCHAR(255)` | IdP issuer URI |
| `idp_image_url` | `VARCHAR(512)` | IdP logo/image URL |
| `metadata` | `TEXT` | Raw SAML metadata XML |
| `metadata_url` | `VARCHAR(512)` | URL to fetch SAML metadata |
| `idp_name` | `VARCHAR(255)` | Human-readable IdP name |
| `enable_sso` | `TINYINT(1)` | SSO feature flag (boolean) |

All string columns use `utf8mb4` / `utf8mb4_general_ci` collation.
