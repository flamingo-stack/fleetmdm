Database migration that initializes the `WindowsEntraClientIDs` field in the MDM app configuration to an empty array, ensuring consistent JSON serialization for upgraded Fleet installations.

## Key Components

- **`Up_20260529120000`** — Applies the migration by updating the app config JSON to set `MDM.WindowsEntraClientIDs` to an empty slice (`[]`) instead of `null`, preventing GitOps diff instability
- **`Down_20260529120000`** — No-op rollback; the JSON-only change does not require reversal
- **`init`** — Registers both migration functions with `MigrationClient`

## Behavior Notes

- **Idempotent** — Safe to re-run; uses `UPDATE`/JSON config mutation only, no schema changes
- **Mirrors** `windows_entra_tenant_ids` behavior established in migration `20260205184907`
- Ensures `GET /config` returns `[]` (not `null`) for `windows_entra_client_ids` on upgraded installs

## Usage Example

This migration runs automatically via the Fleet migration framework. It is not called directly, but the core update logic is equivalent to:

```go
config.MDM.WindowsEntraClientIDs = optjson.SetSlice([]string{})
```

To apply all pending migrations:

```bash
fleet prepare db --config /etc/fleet/fleet.yml
```
