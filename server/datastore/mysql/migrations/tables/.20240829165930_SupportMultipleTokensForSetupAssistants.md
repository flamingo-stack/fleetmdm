Database migration that adds multi-ABM token support to Apple MDM Setup Assistants, enabling profile UUIDs to be tracked per team and per ABM token.

## Key Components

- **`Up_20240829165930`** — Applies the migration with three main changes:
  1. Alters `mdm_apple_default_setup_assistants` to add an `abm_token_id` column and replaces the existing unique index with a composite `(global_or_team_id, abm_token_id)` unique constraint
  2. Creates the new `mdm_apple_setup_assistant_profiles` table linking custom setup assistants to ABM tokens with their corresponding `profile_uuid`
  3. Migrates existing `profile_uuid` data from `mdm_apple_setup_assistants` into the new table and drops the old `profile_uuid` column

- **`Down_20240829165930`** — No-op rollback (returns nil)

All schema changes are idempotent via `columnExists`, `indexExistsTx`, and `constraintExists` guards before executing DDL.
