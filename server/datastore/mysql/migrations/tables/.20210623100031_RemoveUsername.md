Database migration that removes the `username` column from the `users` table, first backfilling the `name` column with any existing username values where `name` is empty or null.

## Key Components

| Function | Description |
|---|---|
| `Up_20210623100031` | Migrates forward: copies `username` → `name` (where blank), then drops `username` |
| `Down_20210623100031` | No-op rollback (column removal is not reversed) |

## Usage Example

```go
// Registered automatically via init(); no direct invocation needed.
// The migration client runs this as part of the ordered migration chain.
MigrationClient.AddMigration(Up_20210623100031, Down_20210623100031)
```

## Notes

- **Idempotent**: Checks for column existence via `columnExists(tx, "users", "username")` before executing, making it safe to run multiple times.
- **Data preservation**: Ensures no user display names are lost by copying `username` into `name` only when `name` is `NULL` or `''`.
- **Irreversible**: The `Down` migration is a no-op — the dropped column and its data are not restored on rollback.
