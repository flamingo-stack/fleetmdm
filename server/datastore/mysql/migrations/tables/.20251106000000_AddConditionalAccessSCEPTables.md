Database migration that creates two tables supporting Conditional Access SCEP (Simple Certificate Enrollment Protocol) certificate management.

## Key Components

- **`Up_20251106000000`** — Creates `conditional_access_scep_serials` and `conditional_access_scep_certificates` tables. The migration is idempotent (`CREATE TABLE IF NOT EXISTS`). Serial number `1` is reserved for system use via `AUTO_INCREMENT=2`.
- **`Down_20251106000000`** — No-op rollback; tables are left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Schema Overview

**`conditional_access_scep_serials`**
| Column | Type | Notes |
|---|---|---|
| `serial` | `bigint unsigned` | Auto-increment PK, starts at 2 |
| `created_at` | `DATETIME(6)` | Defaults to `NOW(6)` |

**`conditional_access_scep_certificates`**
| Column | Type | Notes |
|---|---|---|
| `serial` | `bigint unsigned` | PK, FK → `conditional_access_scep_serials.serial` |
| `host_id` | `int unsigned` | Indexed |
| `name` | `varchar(64)` | Certificate name |
| `not_valid_before` / `not_valid_after` | `datetime` | Validity window |
| `certificate_pem` | `text` | Enforced to start with `-----BEGIN CERTIFICATE-----` via CHECK constraint |
| `revoked` | `tinyint(1)` | Defaults to `0` |
