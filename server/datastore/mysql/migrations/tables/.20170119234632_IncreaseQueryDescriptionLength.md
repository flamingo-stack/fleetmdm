Database migration that increases the `description` column in the `queries` table from `VARCHAR(255)` to `TEXT`, allowing longer query descriptions.

## Key Components

- **`Up_20170119234632`** — Idempotently alters the `queries.description` column to `TEXT NOT NULL`, only executing if the column exists
- **`Down_20170119234632`** — Reverts the column back to `VARCHAR(255) NOT NULL`
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

```go
// Applied automatically by the migration client at startup.
// Manual execution via sql.Tx:
err := Up_20170119234632(tx)
if err != nil {
    log.Fatal(err)
}

// To roll back:
err = Down_20170119234632(tx)
```

> **Note:** The `Up` migration is idempotent — it checks for column existence via `columnExists` before executing, making it safe to run multiple times without error.
