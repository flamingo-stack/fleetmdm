Database migration that creates the `app_configs` table, which stores a single global application configuration record including organization details and SMTP email settings.

## Key Components

- **`Up_20161118193812`** — Creates the `app_configs` table if it doesn't exist and inserts a default row using `INSERT IGNORE`, ensuring exactly one configuration record always exists.
- **`Down_20161118193812`** — Drops the `app_configs` table if it exists, reverting the migration.
- **`init`** — Registers both migration functions with `MigrationClient` at package load time.

## Table Schema

The `app_configs` table is a singleton (always one row, `id` defaults to `1`) with the following column groups:

| Group | Columns |
|---|---|
| Organization | `org_name`, `org_logo_url`, `kolide_server_url` |
| SMTP connection | `smtp_server`, `smtp_port`, `smtp_sender_address`, `smtp_domain` |
| SMTP auth | `smtp_authentication_type`, `smtp_authentication_method`, `smtp_user_name`, `smtp_password` |
| SMTP flags | `smtp_configured`, `smtp_enabled`, `smtp_enable_ssl_tls`, `smtp_verify_ssl_certs`, `smtp_enable_start_tls` |

## Notes

- The migration is **idempotent**: `CREATE TABLE IF NOT EXISTS` and `INSERT IGNORE` prevent errors on re-runs.
- Default SMTP port is `587`; SSL/TLS and certificate verification are enabled by default.
