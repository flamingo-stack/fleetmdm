Database migration that adds a `config` JSON column to the `teams` table and migrates existing `agent_options` data into it.

## Key Components

- **`Up_20220309133956`** — Idempotent up migration that:
  1. Adds a `config JSON` column to `teams` if it doesn't already exist
  2. Migrates existing `agent_options` values into `config` using `JSON_SET`
  3. Drops the `agent_options` column if it still exists
- **`Down_20220309133956`** — No-op rollback (data migration is not reversed)

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
MigrationClient.AddMigration(Up_20220309133956, Down_20220309133956)
```

The up migration consolidates `agent_options` into a broader `config` JSON object:

```sql
-- Resulting config structure after migration
UPDATE teams SET config = JSON_SET('{}', '$.agent_options', agent_options);
```

> **Note:** The migration is idempotent — `columnExists` guards both the `ADD COLUMN` and `DROP COLUMN` steps, making it safe to re-run.
