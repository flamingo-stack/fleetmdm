Database migration that adds an index on the `hostname` column of the `hosts` table to improve query performance for hostname-based lookups.

## Key Components

- **`Up_20251215163721`** — Idempotently adds `idx_hosts_hostname` index on `hosts.hostname`; checks for existence before applying to avoid duplicate index errors
- **`Down_20251215163721`** — No-op rollback; index removal is omitted
- **`init`** — Registers the migration with `MigrationClient`

## Usage Example

```bash
# Apply migration via Fleet's migration runner
fleet prepare db --config /etc/fleet/fleet.yml
```

```go
// Migration runs automatically on startup; manual invocation example:
tx, _ := db.Begin()
if err := Up_20251215163721(tx); err != nil {
    tx.Rollback()
}
tx.Commit()
```

## Notes

- **Idempotent** — Safe to run multiple times; `indexExistsTx` guards against re-creating an existing index
- **Rollback** — `Down_20251215163721` is intentionally a no-op; dropping the index would require a separate decision given potential performance impact on downgrade
- Migration timestamp: `20251215163721` (December 15, 2025)
