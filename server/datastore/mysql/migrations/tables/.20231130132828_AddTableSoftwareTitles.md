Database migration that creates the `software_titles` table, grouping software by name and source for deduplication and title-level reporting.

## Key Components

| Symbol | Description |
|---|---|
| `Up_20231130132828` | Creates the `software_titles` table if it does not already exist (idempotent) |
| `Down_20231130132828` | No-op rollback; the table is left in place on downgrade |

## Table Schema

```text
software_titles
├── id     INT UNSIGNED  AUTO_INCREMENT  PRIMARY KEY
├── name   VARCHAR(255)  NOT NULL
└── source VARCHAR(64)   NOT NULL
         UNIQUE (name, source)
```

- **Engine:** InnoDB
- **Charset:** `utf8mb4` / `utf8mb4_unicode_ci`
- The unique index `idx_software_titles_name_source` prevents duplicate `(name, source)` pairs.
