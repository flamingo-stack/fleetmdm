Database migration that converts the legacy boolean `admin` column on `users` and `invites` tables into a `global_role` string field, mapping admins to `'admin'` and non-admins to `'maintainer'`.

## Key Components

- **`Up_20210601000003`** — Idempotent up migration that:
  - Promotes users/invites where `admin = TRUE` to `global_role = 'admin'`
  - Demotes users/invites where `admin = FALSE` to `global_role = 'maintainer'`
  - Drops the legacy `admin` boolean column from both tables
  - Guards each block with `columnExists` to allow safe re-runs
- **`Down_20210601000003`** — No-op rollback; the migration is intentionally irreversible

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20210601000003, Down_20210601000003)
}
```

The idempotency check prevents double-execution:

```go
// Only runs if the legacy column still exists
if columnExists(tx, "users", "admin") {
    // migrate and drop column
}
```

## Notes

- **Idempotent**: Safe to run multiple times — skips if `admin` column is already absent
- **One-way**: `Down_20210601000003` is a no-op; the `admin` column is not restored on rollback
- **Scope**: Affects both `users` and `invites` tables independently
