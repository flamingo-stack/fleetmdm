Adds database indexes to optimize APNS (Apple Push Notification Service) MDM enrollment queue and command result lookup performance.

## Key Components

- **`Up_20260210151544`** — Idempotent migration that creates two indexes:
  - `idx_neq_filter` on `nano_enrollment_queue(active, priority, created_at)` — optimizes filtering active enrollments by priority and creation time
  - `idx_ncr_lookup` on `nano_command_results(id, command_uuid, status)` — optimizes MDM command result lookups
- **`Down_20260210151544`** — No-op rollback; indexes are left in place on downgrade
- **`init()`** — Registers the migration with `MigrationClient` at package load time

## Usage Example

This migration runs automatically via the Fleet migration runner. To apply manually:

```go
// Applied by the migration framework on startup
// Equivalent SQL executed by Up_20260210151544:

CREATE INDEX idx_neq_filter ON nano_enrollment_queue (
    active,
    priority,
    created_at
);

CREATE INDEX idx_ncr_lookup ON nano_command_results (id, command_uuid, status);
```

Both steps are **idempotent** — if the index already exists (checked via `indexExistsTx`), the step is skipped without error, making re-runs safe.
