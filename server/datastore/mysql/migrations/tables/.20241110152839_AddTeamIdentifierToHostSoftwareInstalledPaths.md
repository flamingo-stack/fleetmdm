|---|---|

## Behavior

- **Idempotent:** The migration checks for column existence before executing `ALTER TABLE`, so re-running it on an already-migrated schema is safe.
- **Default value:** New column defaults to `''` (empty string), preserving existing rows without disruption.
- **Charset:** Uses `utf8mb4` / `utf8mb4_unicode_ci` to support full Unicode team identifier strings.
