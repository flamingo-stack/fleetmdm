Database migration that adds `smallstep` as a supported certificate authority type to the `host_mdm_managed_certificates` and `certificate_authorities` tables, and introduces a `challenge_url` column for Smallstep-specific configuration.

## Key Components

- **`Up_20250923120000`** — Applies the migration with three idempotent operations:
  - Extends the `type` ENUM on `host_mdm_managed_certificates` to include `'smallstep'`
  - Extends the `type` ENUM on `certificate_authorities` to include `'smallstep'`
  - Adds a nullable `challenge_url TEXT` column to `certificate_authorities` (after `password_encrypted`), used for Smallstep SCEP challenge URL configuration
- **`Down_20250923120000`** — No-op rollback; ENUM and column removals are omitted to avoid data loss

## Usage Example

This migration is registered automatically via `init()` and executed by the Fleet migration runner:

```go
// Registered automatically on package import
MigrationClient.AddMigration(Up_20250923120000, Down_20250923120000)
```

To apply manually during development:

```bash
fleetctl prepare db --config /path/to/fleet.yml
```

## Notes

- All three schema changes are **idempotent** — guarded by `columnExists()` checks, so re-running is safe
- Smallstep reuses the existing `username` and `password_encrypted` columns shared with NDES; `challenge_url` is the only new Smallstep-specific field
- The `Down` function is intentionally empty — reverting ENUMs with existing data requires manual intervention
