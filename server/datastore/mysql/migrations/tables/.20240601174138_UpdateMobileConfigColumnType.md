Database migration that alters the `mobileconfig` column type in the `mdm_apple_configuration_profiles` table from its previous type to `MEDIUMBLOB NOT NULL`, supporting larger MDM configuration profile payloads.

## Key Components

- **`Up_20240601174138`** — Idempotent upgrade migration; checks for column existence before executing `ALTER TABLE ... MODIFY COLUMN mobileconfig MEDIUMBLOB NOT NULL`.
- **`Down_20240601174138`** — No-op rollback; the column type change is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration runs automatically via MigrationClient on startup.
// Manually invoking the Up function against a transaction:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20240601174138(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The migration is **idempotent**: if the `mobileconfig` column does not exist (e.g., already renamed or dropped), the `ALTER` is skipped entirely.
- `MEDIUMBLOB` supports up to **16 MB**, replacing a smaller type to accommodate large Apple MDM configuration profiles.
- The `Down` function is intentionally empty — reverting a column type change risks data loss and is left as a manual operation if needed.
