Database migration that adds an `is_server` column to the `host_mdm` table, enabling Fleet to distinguish between server and non-server hosts in MDM enrollment records.

## Key Components

| Function | Description |
|---|---|
| `Up_20221104144401` | Adds `is_server TINYINT(1) NULL` column to `host_mdm` if it does not already exist |
| `Down_20221104144401` | No-op rollback (column removal not implemented) |

The migration is **idempotent** — it uses `columnExists` to check for the column before executing the `ALTER TABLE` statement, making it safe to run multiple times.

## Usage Example

This migration is registered automatically via `init()` and executed by the Fleet migration runner:

```go
// Registered automatically on package import
MigrationClient.AddMigration(Up_20221104144401, Down_20221104144401)

// Resulting schema change
ALTER TABLE host_mdm ADD COLUMN is_server TINYINT(1) NULL;
```

## Notes

- The column is nullable (`NULL`), so existing rows are unaffected after migration.
- Rollback (`Down_*`) is intentionally a no-op; column removal must be handled manually if needed.
