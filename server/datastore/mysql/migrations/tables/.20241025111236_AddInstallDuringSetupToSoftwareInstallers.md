Database migration that adds the `install_during_setup` boolean column to both `software_installers` and `vpp_apps_teams` tables, enabling software to be flagged for installation during device setup workflows.

## Key Components

- **`Up_20241025111236`** — Idempotent `ALTER TABLE` migration that adds `install_during_setup BOOL NOT NULL DEFAULT false` to `software_installers` and `vpp_apps_teams`. Uses `columnExists` guard to skip if column is already present.
- **`Down_20241025111236`** — No-op rollback; column removal is not performed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the `MigrationClient` on application startup. No manual invocation is needed. The column can then be used as:

```go
// Query software installers flagged for setup-time installation
rows, err := db.Query(`
    SELECT id, name
    FROM software_installers
    WHERE install_during_setup = true
      AND team_id = ?
`, teamID)
```

## Notes

- Migration is **idempotent** — safe to re-run; `columnExists` checks prevent duplicate `ALTER TABLE` errors.
- Both `software_installers` and `vpp_apps_teams` receive the column in a single migration for consistency.
- The `Down` function is intentionally empty; destructive rollbacks (dropping columns) are avoided to prevent data loss.
