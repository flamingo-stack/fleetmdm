Database migration that adds an index on the `mdm_device_id` column of the `mdm_windows_enrollments` table to improve query performance for Windows MDM enrollment lookups.

## Key Components

- **`Up_20240312103753`** — Idempotently adds `idx_mdm_windows_enrollments_mdm_device_id` index on `mdm_windows_enrollments.mdm_device_id` if it does not already exist.
- **`Down_20240312103753`** — No-op rollback; the index is not dropped on downgrade.
- **`init`** — Registers the migration with `MigrationClient`.

## Notes

- The migration is **idempotent**: it checks for the index via `indexExistsTx` before attempting `ALTER TABLE`, making it safe to run multiple times.
- The `Down` function is intentionally a no-op — dropping the index on rollback was deemed unnecessary, which is a common pattern for performance-only schema changes.
