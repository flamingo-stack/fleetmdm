Adds a `fleet_initiated` boolean column to the `activities` table via an idempotent schema migration.

## Key Components

- **`Up_20250219090511`** – Adds `fleet_initiated tinyint(1) NOT NULL DEFAULT '0'` to the `activities` table. Checks for column existence before altering, making it safe to run multiple times.
- **`Down_20250219090511`** – No-op rollback; the column is left in place on downgrade.
- **`init`** – Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the `MigrationClient` during database initialization. No manual invocation is needed.

```go

// To run manually in tests or tooling:

if err := Up_20250219090511(tx); err != nil {
```

## Notes

- The migration is **idempotent**: if `fleet_initiated` already exists on `activities`, the `ALTER TABLE` is skipped.
- `Down_20250219090511` is intentionally a no-op — destructive rollbacks (dropping columns) are avoided to prevent data loss.
