## Key Components

- **`Up_20210802135933`** — Creates the `software_cve` table with a foreign key reference to `software_cpe(id)`, a unique constraint on `(cpe_id, cve)` pairs, and `AUTO_INCREMENT` primary key. The migration is idempotent via `CREATE TABLE IF NOT EXISTS`.
