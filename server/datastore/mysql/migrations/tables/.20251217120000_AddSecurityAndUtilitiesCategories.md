## Usage Example

```go
// Migration is auto-registered via init(); run via MigrationClient
err := MigrationClient.Up(db)

// To rollback:

```

> **Note:** The `Up` migration is idempotent — re-running it against a database that already contains these categories is safe and produces no error.
