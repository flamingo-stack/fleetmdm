Database migration that creates the `mdm_apple_configuration_profiles` table for storing Apple MDM configuration profiles associated with Fleet teams.

## Key Components

- **`Up_20230206163608`** — Creates the `mdm_apple_configuration_profiles` table using `CREATE TABLE IF NOT EXISTS` (idempotent). Defines columns for profile identity, team association, name, and raw mobileconfig payload.
- **`Down_20230206163608`** — No-op rollback; table is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Table Schema

| Column | Type | Notes |
|---|---|---|
| `profile_id` | `INT UNSIGNED` | Auto-increment primary key |
| `team_id` | `INT UNSIGNED` | `0` = no team (global profile) |
| `identifier` | `VARCHAR(255)` | Apple profile bundle identifier |
| `name` | `VARCHAR(255)` | Human-readable profile name |
| `mobileconfig` | `BLOB` | Raw `.mobileconfig` file contents |
| `created_at` | `TIMESTAMP` | Set on insert |
| `updated_at` | `TIMESTAMP` | Auto-updated on row change |

**Unique constraints:** `(team_id, identifier)` and `(team_id, name)` prevent duplicate profiles within a team.
