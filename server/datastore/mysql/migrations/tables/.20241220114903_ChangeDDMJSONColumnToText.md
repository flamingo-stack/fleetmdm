Database migration that converts the `raw_json` column in `mdm_apple_declarations` from a JSON type to `MEDIUMTEXT` (16MB max), accommodating larger DDM (Declarative Device Management) profiles.

## Key Components

- **`Up_20241220114903`** — Idempotent upgrade migration; checks for column existence before altering `mdm_apple_declarations.raw_json` to `MEDIUMTEXT COLLATE utf8mb4_unicode_ci NOT NULL`
- **`Down_20241220114903`** — No-op rollback; column type reversal is not implemented
- **`init`** — Registers both migration functions with `MigrationClient`

## Behavior Notes

- Uses `columnExists` guard to make the `UP` migration safe to run multiple times
- `MEDIUMTEXT` supports up to **16MB**, replacing the prior `JSON` column limit to handle large DDM configuration profiles
- Rollback is intentionally a no-op — reverting `MEDIUMTEXT` back to `JSON` would risk data loss if oversized values were written

## Usage Example

This migration runs automatically via the Fleet migration runner. To apply manually:

```bash
fleetctl prepare db --config /etc/fleet/fleet.yml
```

To inspect the resulting schema:

```sql
SHOW COLUMNS FROM mdm_apple_declarations WHERE Field = 'raw_json';
-- Expected: MEDIUMTEXT, utf8mb4_unicode_ci, NOT NULL
```
