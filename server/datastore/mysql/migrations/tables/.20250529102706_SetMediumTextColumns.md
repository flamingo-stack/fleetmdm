Database schema migration that converts `query` and `description` columns in the `queries` and `labels` tables from their existing text types to `MEDIUMTEXT`.

## Key Components

- **`Up_20250529102706`** — Idempotent upgrade migration that alters two tables:
  - `queries.query` and `queries.description` → `MEDIUMTEXT NOT NULL`
  - `labels.query` → `MEDIUMTEXT NOT NULL`
  - Uses `columnsExists` / `columnExists` guards to ensure safe re-execution
- **`Down_20250529102706`** — No-op rollback; the column type change is not reversed

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client during database upgrades:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20250529102706, Down_20250529102706)
}

// Applying the migration manually (for testing)
err := Up_20250529102706(tx)
if err != nil {
    log.Fatalf("migration failed: %v", err)
}
```

## Notes

- `MEDIUMTEXT` supports up to ~16 MB per field, accommodating large SQL query strings that may exceed standard `TEXT` limits (~64 KB)
- The migration is **idempotent** — column existence is checked before each `ALTER TABLE`, preventing errors on repeated runs
- The down migration is intentionally empty; reverting to a smaller text type could cause data loss if existing rows exceed the original column capacity
