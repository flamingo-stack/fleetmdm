Database migration that adds a generated boolean column `is_scheduled` and a composite index on the `queries` table to optimize scheduled automation lookups.

## Key Components

- **`Up_20241002104106`** — Applies the migration idempotently:
  - Adds `is_scheduled` as a `STORED` generated column derived from `schedule_interval > 0`
  - Creates index `idx_queries_schedule_automations` on `(is_scheduled, automations_enabled)`
- **`Down_20241002104106`** — No-op rollback (generated columns and indexes are left in place)

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20241002104106, Down_20241002104106)
}

// The generated column eliminates redundant computation at query time:
// SELECT * FROM queries WHERE is_scheduled = true AND automations_enabled = true
// Uses: idx_queries_schedule_automations
```

## Notes

- Both `columnExists` and `indexExistsTx` guards make the migration safe to re-run
- The `DOWN` migration is intentionally a no-op — dropping a stored generated column used by an index requires careful ordering; callers should handle rollback manually if needed
