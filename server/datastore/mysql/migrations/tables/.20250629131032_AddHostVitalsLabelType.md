Database migration that adds a nullable `criteria` JSON column to the `labels` table to support host vitals label types.

## Key Components

- **`Up_20250629131032`** — Idempotent migration that adds the `criteria` column (`json DEFAULT NULL`) to the `labels` table. Uses `columnExists` to guard against re-applying the migration.
- **`Down_20250629131032`** — No-op rollback; the column addition is considered non-destructive to reverse automatically.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the `MigrationClient` during Fleet database schema upgrades. No manual invocation is required.

```go
// Migration is registered on package init and run by the migration runner:
MigrationClient.AddMigration(Up_20250629131032, Down_20250629131032)

// The Up function guards against duplicate column creation:
if !columnExists(tx, "labels", "criteria") {
    tx.Exec("ALTER TABLE `labels` ADD COLUMN `criteria` json DEFAULT NULL;")
}
```

The `criteria` column stores structured JSON conditions used to evaluate host vitals labels, enabling dynamic label membership based on host health metrics.
