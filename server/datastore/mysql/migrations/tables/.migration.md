Provides core migration utilities for the Fleet MDM database schema, including step execution, progress tracking, and schema introspection helpers used across all table migration files.

## Key Components

| Export / Function | Description |
|---|---|
| `MigrationClient` | Global `goose` migration client targeting the `migration_status_tables` table using MySQL dialect |
| `migrationStep` | Function type `func(tx *sql.Tx) error` representing a single transactional migration step |
| `basicMigrationStep` | Wraps a raw SQL statement into a `migrationStep` |
| `basicMigrationStepWithArgs` | Same as above but accepts parameterized arguments |
| `incrementalMigrationStep` | Wraps a long-running batch operation with periodic progress reporting (every 5 seconds) to stderr |
| `withSteps` | Executes an ordered slice of `migrationStep` functions within a transaction, logging step numbers |
| `fkExists` | Checks whether a named foreign key constraint exists on a table |
| `constraintExists` | Checks whether any named constraint exists on a table |
| `columnExists` / `columnsExists` | Checks for the existence of one or more columns in a table |
| `tableExists` | Checks whether a table exists in the current database schema |
| `indexExists` / `indexExistsTx` | Checks for a named index on a table (via `sqlx.DB` or `*sql.Tx`) |
| `updateAppConfigJSON` | Reads, modifies via callback, and writes back the JSON app configuration stored in `app_config_json` |

## Usage Example

```go
// Compose a migration using multiple steps
func Up_20240101120000(tx *sql.Tx) error {
    return withSteps([]migrationStep{
        basicMigrationStep(
            `ALTER TABLE hosts ADD COLUMN os_version VARCHAR(255)`,
            "add os_version column",
        ),
        incrementalMigrationStep(
            func(tx *sql.Tx) (uint64, error) {
                var n uint64
                return n, tx.QueryRow(`SELECT COUNT(*) FROM hosts`).Scan(&n)
            },
            func(tx *sql.Tx, inc incrementCountFn) error {
                rows, _ := tx.Query(`SELECT id FROM hosts`)
                for rows.Next() {
                    // backfill logic...
                    inc()
                }
                return rows.Err()
            },
        ),
    }, tx)
}

// Safely modify app config during migration
updateAppConfigJSON(tx, func(cfg *fleet.AppConfig) error {
    cfg.ServerSettings.EnableAnalytics = false
    return nil
})
```

> **Note:** `incrementalMigrationStep` uses an atomic counter and a background goroutine to print progress percentages to `os.Stderr` every 5 seconds — both can be overridden in tests via `outputTo` and `progressInterval`.
