Database migration that adds a `last_enroll_time` timestamp column to the `hosts` table, initializing it with each host's `created_at` value.

## Key Components

- **`Up_20201208121729`** — Idempotent migration that adds `last_enroll_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP` to `hosts` if the column does not already exist, then backfills it from `created_at`.
- **`Down_20201208121729`** — No-op rollback; the column is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration runner at startup.
// To run manually via goose or the Fleet migration CLI:
// fleet prepare db --config fleet.yml
```

```sql
-- Resulting schema change
ALTER TABLE `hosts`
  ADD COLUMN `last_enroll_time` TIMESTAMP DEFAULT CURRENT_TIMESTAMP;

UPDATE hosts SET last_enroll_time = created_at;
```

## Notes

- The migration is **idempotent**: `columnExists` guards against re-applying the `ALTER TABLE` if the column already exists.
- The backfill (`UPDATE hosts SET last_enroll_time = created_at`) ensures historical hosts reflect a meaningful enrollment time rather than the migration run time.
- The down migration is intentionally empty — dropping the column on rollback could cause data loss and was deemed unnecessary.
