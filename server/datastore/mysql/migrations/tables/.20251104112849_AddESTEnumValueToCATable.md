Database migration that adds `custom_est_proxy` to the `type` ENUM column in the `certificate_authorities` table, enabling EST (Enrollment over Secure Transport) certificate authority support.

## Key Components

- **`Up_20251104112849`** — Idempotent migration that alters `certificate_authorities.type` to include `custom_est_proxy` alongside existing values: `digicert`, `ndes_scep_proxy`, `custom_scep_proxy`, `hydrant`, `smallstep`
- **`Down_20251104112849`** — No-op rollback (ENUM modifications are not reversed)
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

## Notes

- **EST** (Enrollment over Secure Transport, RFC 7030) is a certificate enrollment protocol; `custom_est_proxy` allows Fleet to support custom EST-based certificate authorities
- The column uses `utf8mb4_unicode_ci` collation, consistent with Fleet's MySQL charset standards
- The `Down` migration is intentionally empty — reverting an ENUM modification requires careful data validation and is left as a manual operation
