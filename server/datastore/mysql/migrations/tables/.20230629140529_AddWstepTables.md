Database migration that creates the WSTEP (Windows Simple Certificate Enrollment Protocol) tables required for MDM certificate management.

## Key Components

- **`Up_20230629140529`** — Creates three tables supporting WSTEP certificate lifecycle management:
  - `wstep_serials` — Auto-incrementing serial number registry; `AUTO_INCREMENT` starts at `2`, reserving serial `1` for the CA certificate
  - `wstep_certificates` — Stores issued certificates with PEM data, validity window, and revocation status; references `wstep_serials` via foreign key
  - `wstep_cert_auth_associations` — Maps device identifiers (`id`) to certificate SHA-256 fingerprints for authentication lookups
- **`Down_20230629140529`** — No-op rollback; tables are left in place on downgrade
- **`init()`** — Registers both migration functions with `MigrationClient`

## Schema Notes

| Table | Primary Key | Notable Columns |
|---|---|---|
| `wstep_serials` | `serial` (auto-increment) | `created_at` |
| `wstep_certificates` | `serial` (FK → `wstep_serials`) | `certificate_pem`, `revoked`, validity range |
| `wstep_cert_auth_associations` | `(id, sha256)` composite | Device-to-cert binding |

All text tables use `utf8mb4_unicode_ci` collation for full Unicode support.

## Usage Example

```go
// Migrations are registered automatically via init().
// To apply programmatically using the migration client:
if err := MigrationClient.Up(db); err != nil {
    log.Fatalf("migration failed: %v", err)
}
```

Migration is idempotent — `CREATE TABLE IF NOT EXISTS` guards allow safe re-runs.
