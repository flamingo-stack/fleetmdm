Adds a `self_service` boolean column to the `vpp_apps_teams` table via an idempotent database migration.

## Key Components

- **`Up_20240815000001`** — Applies the migration by adding a `self_service bool NOT NULL DEFAULT false` column to `vpp_apps_teams`, guarded by a `columnExists` check to ensure safe re-execution.
- **`Down_20240815000001`** — No-op rollback; the column addition is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration is auto-registered via init() and executed by the migration runner.
// To apply manually during development:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20240815000001(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- **Idempotent**: Wrapping the `ALTER TABLE` in a `columnExists` guard makes this safe to run multiple times without error.
- The rollback (`Down`) is intentionally left as a no-op — dropping the column on rollback would risk data loss and was omitted by design.
