Database migration that creates the `org_logo` table for storing organization logo binary data, keyed by display mode.

## Key Components

- **`Up_20260527215818`** — Creates the `org_logo` table with `IF NOT EXISTS` (idempotent). Stores logo binary blobs indexed by `mode` (e.g., `"light"`, `"dark"`).
- **`Down_20260527215818`** — No-op rollback; the table is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.
