Database migration that adds the `refetch_requested` column to the `hosts` table, enabling on-demand host detail refresh requests.

## Key Components

- **`Up_20210513115729`** — Idempotent migration that adds a `refetch_requested TINYINT(1) NOT NULL DEFAULT 0` column to the `hosts` table. Uses `columnExists` guard to safely re-run without error.
- **`Down_20210513115729`** — No-op rollback; column removal is not implemented.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Applied automatically by MigrationClient at startup
MigrationClient.AddMigration(Up_20210513115729, Down_20210513115729)
```

To trigger a host detail refetch, set the flag in application code:

```go
db.Exec("UPDATE hosts SET refetch_requested = 1 WHERE id = ?", hostID)
```
