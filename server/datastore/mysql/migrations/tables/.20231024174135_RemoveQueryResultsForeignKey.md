Database migration that removes foreign key constraints referencing the `queries` table from the `query_results` table.

## Key Components

- **`Up_20231024174135`** — Idempotent migration that discovers and drops all foreign key constraints on `query_results` that reference the `queries` table. Uses `constraintsForTable` to locate relevant constraints and `fkExists` to verify each before attempting removal.
- **`Down_20231024174135`** — No-op rollback; the foreign key removal is intentionally irreversible via this migration.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. To apply manually during development:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20231024174135(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}

tx.Commit()
```

## Notes

- The migration is **idempotent** — safe to run multiple times. The `fkExists` check prevents errors if the constraint has already been dropped.
- The down migration is intentionally empty; re-creating the original foreign key definition would require knowing the exact original constraint, which is not preserved.
