## Key Components

- **`Up_20250311132525`** — Idempotent migration that adds a nullable `author_id` column (`int unsigned`) to `labels` with a foreign key referencing `users.id` (cascades to `NULL` on user deletion), then creates an index on the column. Both steps are guarded by existence checks to prevent duplicate-column or duplicate-index errors.
- **`Down_20250311132525`** — No-op rollback; the column is left in place on downgrade.
