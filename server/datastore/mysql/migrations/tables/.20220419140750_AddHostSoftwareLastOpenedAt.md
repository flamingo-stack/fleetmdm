Adds a nullable `last_opened_at` timestamp column to the `host_software` table via an idempotent schema migration.

## Key Components

- **`Up_20220419140750`** — Checks for column existence before adding `last_opened_at timestamp NULL` to `host_software`, ensuring safe re-execution.
- **`Down_20220419140750`** — No-op rollback; column removal is not implemented.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration is auto-registered via init().
// Run all pending migrations using the MigrationClient:
if err := MigrationClient.Up(db); err != nil {
    log.Fatal(err)
}
```

## Notes

- The migration is **idempotent**: it calls `columnExists` before altering the table, so running it multiple times is safe.
- The rollback (`Down`) is intentionally empty — dropping the column is left as a manual operation to avoid data loss.
