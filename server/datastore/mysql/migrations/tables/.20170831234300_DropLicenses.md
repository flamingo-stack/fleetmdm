Database migration that drops the `licenses` table, with a rollback that restores it by replaying migration `Up_20170127014618`.

## Key Components

- **`Up_20170831234300`** — Idempotently drops the `licenses` table using `DROP TABLE IF EXISTS`.
- **`Down_20170831234300`** — Reverts the migration by delegating to `Up_20170127014618`, which recreates the original `licenses` table schema.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Applied automatically by the migration runner
MigrationClient.AddMigration(Up_20170831234300, Down_20170831234300)
```

To run manually during development:

```bash
# Apply migration
fleet db prepare --dev

# Roll back
fleet db rollback
```

> The `Up` function is safe to run multiple times — `DROP TABLE IF EXISTS` ensures no error if the table is already absent.
