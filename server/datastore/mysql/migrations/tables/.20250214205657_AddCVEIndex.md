Database migration that adds an index on the `cve` column of the `software_cve` table to improve CVE-based query performance.

## Key Components

- **`Up_20250214205657`** — Idempotently adds the index `idx_software_cve_cve` on `software_cve.cve` if it does not already exist.
- **`Down_20250214205657`** — No-op rollback; the index is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Migration is registered automatically via init().
// To apply manually using the migration client:
err := MigrationClient.Up(db, "20250214205657")
if err != nil {
    log.Fatalf("migration failed: %v", err)
}
```

## Notes

- The migration is **idempotent**: it checks for the index via `indexExistsTx` before executing the `ALTER TABLE`, making it safe to run multiple times.
- The rollback (`Down`) is intentionally a no-op — dropping the index on rollback was deemed unnecessary.
