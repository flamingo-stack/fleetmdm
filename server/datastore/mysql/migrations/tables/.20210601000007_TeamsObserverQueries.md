Database migration that adds the `observer_can_run` column to the `queries` table, enabling observer-role query execution controls.

## Key Components

- **`Up_20210601000007`** — Idempotent migration that adds `observer_can_run` (`TINYINT(1) NOT NULL DEFAULT FALSE`) to the `queries` table if it does not already exist.
- **`Down_20210601000007`** — No-op rollback; the column is left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration runs automatically via the migration client. To apply it manually during development:

```go
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20210601000007(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

After the migration, the `queries` table includes:

```text
observer_can_run  TINYINT(1)  NOT NULL  DEFAULT 0
```

Set `observer_can_run = 1` on a query row to allow Fleet observers to execute it without elevated privileges.

## Notes

- The migration is **idempotent** — safe to run multiple times; `columnExists` guards against duplicate `ALTER TABLE` errors.
