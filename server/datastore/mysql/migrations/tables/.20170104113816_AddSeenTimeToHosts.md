Database migration that adds a `seen_time` timestamp column to the `hosts` table, enabling tracking of when a host was last observed.

## Key Components

| Function | Description |
|---|---|
| `Up_20170104113816` | Adds `seen_time` (nullable `timestamp`, default `NULL`) to `hosts`; idempotent via `columnExists` check |
| `Down_20170104113816` | Removes the `seen_time` column from `hosts` |

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Applied automatically during schema migration
MigrationClient.AddMigration(Up_20170104113816, Down_20170104113816)
```

To apply or roll back manually using the migration client:

```go
// Migrate up
err := MigrationClient.Up(db)

// Migrate down
err := MigrationClient.Down(db)
```

**Resulting schema change:**

```sql
-- Up
ALTER TABLE `hosts`
  ADD COLUMN `seen_time` timestamp NULL DEFAULT NULL;

-- Down
ALTER TABLE `hosts`
  DROP COLUMN `seen_time`;
```

> The `Up` migration is idempotent — it checks for the column's existence before altering the table, making it safe to run multiple times.
