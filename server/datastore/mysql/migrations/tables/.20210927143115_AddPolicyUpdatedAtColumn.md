Database migration that adds a `policy_updated_at` timestamp column to the `hosts` table and truncates the `policy_membership_history` table.

- **`Down_20210927143115`** — No-op rollback; the migration is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- The `Up` function is **idempotent**: it checks for column existence via `columnExists` before altering the `hosts` table, making it safe to run multiple times.
- `policy_membership_history` is **always truncated** on `Up`, so any existing history data is lost when this migration runs.
- The default timestamp (`2000-01-01 00:00:00`) signals that no policy evaluation has occurred for pre-existing hosts.
