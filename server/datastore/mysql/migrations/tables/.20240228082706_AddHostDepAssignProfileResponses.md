Database migration that adds DEP (Device Enrollment Program) profile assignment response tracking columns to the `host_dep_assignments` table.

## Key Components

- **`Up_20240228082706`** — Idempotent migration that alters `host_dep_assignments` with four new fields and a composite index. Falls back to index-only creation if columns already exist.
- **`Down_20240228082706`** — No-op rollback (destructive changes are not reversed).

### Added Columns

| Column | Type | Description |
|---|---|---|
| `profile_uuid` | `VARCHAR(37)` | UUID of the enrollment profile assigned to the host (references `mdm_apple_setup_assistants`) |
| `assign_profile_response` | `VARCHAR(15)` | DEP profile assignment response (`SUCCESS`, `NOT_ACCESSIBLE`, `FAILED`) |
| `response_updated_at` | `TIMESTAMP` | Timestamp of the most recent assignment response |
| `retry_job_id` | `INT UNSIGNED` | Job ID for retrying a failed DEP profile assignment (defaults to `0`) |

### Added Index

- **`idx_hdep_response`** — Composite index on `(assign_profile_response, response_updated_at)` to support efficient querying by response status and recency.
