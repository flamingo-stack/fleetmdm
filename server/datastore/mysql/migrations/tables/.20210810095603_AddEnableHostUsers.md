Database migration that adds the `enable_host_users` boolean column to the `app_config` table, controlling whether host user data collection is enabled.

## Key Components

- **`Up_20210810095603`** — Idempotent migration that adds `enable_host_users BOOL DEFAULT TRUE` to `app_configs` if the column does not already exist.
- **`Down_20210810095603`** — No-op rollback; the column is not removed on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration client at startup.
// To run manually against a transaction:
db, _ := sql.Open("mysql", dsn)
tx, _ := db.Begin()

if err := Up_20210810095603(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The migration is **idempotent**: `columnExists` guards the `ALTER TABLE` statement, making it safe to re-run without error.
- `enable_host_users` defaults to `TRUE`, preserving existing behaviour for all current deployments when the column is first added.
- The down migration is intentionally a no-op — dropping the column on rollback is omitted to avoid data loss.
