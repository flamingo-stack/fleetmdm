Adds a database migration that introduces an `encoding_type` column to the `host_scd_data` table, enabling discrimination between legacy dense bitmap and new roaring bitmap formats.

## Key Components

- **`Up_20260518194422`** — Adds `encoding_type TINYINT NOT NULL DEFAULT 0` to `host_scd_data` using `ALGORITHM=INSTANT` (MySQL 8.0+ metadata-only change). Existing rows read back as `0` (dense bitmap); new writes set `1` (roaring bitmap). Idempotent via a `columnExists` guard.
- **`Down_20260518194422`** — No-op rollback; the column addition is considered safe to leave in place.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Encoding Type Values

| Value | Format |
|---|---|
| `0` | Legacy dense bitmap (default for pre-migration rows) |
| `1` | Roaring bitmap (set explicitly on new writes) |
