Database migration that creates and seeds the `default_team_config_json` table, which stores a singleton default configuration for teams, mirroring the `app_config_json` structure.

## Key Components

- **`Up_20250828120836`** — Creates the `default_team_config_json` table with a constraint enforcing a single row (`id = 1`), then seeds it with a minimal valid `TeamConfig` JSON structure using `INSERT IGNORE` for idempotency.
- **`Down_20250828120836`** — No-op rollback; the migration is intended to be permanent.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Table Schema

```sql
CREATE TABLE IF NOT EXISTS default_team_config_json (
    id          int(10) unsigned NOT NULL UNIQUE DEFAULT 1,
    json_value  JSON NOT NULL,
    created_at  timestamp(6) DEFAULT CURRENT_TIMESTAMP(6),
    updated_at  timestamp(6) DEFAULT CURRENT_TIMESTAMP(6) ON UPDATE CURRENT_TIMESTAMP(6),
    PRIMARY KEY (id),
    CONSTRAINT default_team_config_id CHECK (id = 1)
)
```

## Default Seed Structure

The inserted JSON covers the following top-level keys with safe defaults:

| Key | Notable Defaults |
|---|---|
| `webhook_settings` | Failing policies webhook disabled, host status webhook `nil` |
| `features` | Host users, software inventory, and OS details enabled |
| `host_expiry_settings` | Expiry disabled |
| `integrations` | Jira, Zendesk, Google Calendar all `nil` |
| `mdm` | Disk encryption off, no update deadlines, end-user auth disabled |
| `agent_options`, `scripts`, `software` | All `nil` |
