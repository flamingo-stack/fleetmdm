Database migration that removes foreign key constraints `fk_lm_host_id` and `fk_lm_label_id` from the `label_membership` table.

## Key Components

- **`Up_20210920155130`** — Idempotent up migration that conditionally drops two foreign keys from `label_membership` using `fkExists` checks before attempting removal.
- **`Down_20210920155130`** — No-op down migration; the foreign key removal is intentionally irreversible.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- The migration is **idempotent** — safe to run multiple times. Each foreign key is only dropped if it currently exists, preventing errors on re-execution.
- The empty `Down` function means this migration cannot be automatically rolled back. Restoring the foreign keys requires a new migration.
