Database migration that removes the `smtp_enabled` column from the `app_configs` table, with rollback support to restore it.

## Key Components

| Function | Description |
|---|---|
| `Up_20170110202752` | Drops `smtp_enabled` column from `app_configs` if it exists (idempotent) |
| `Down_20170110202752` | Restores `smtp_enabled` as a `TINYINT(1) NOT NULL DEFAULT FALSE` column |

## Usage Example

```go
// Applied automatically by MigrationClient during schema upgrades.
// Manual invocation via the migration runner:

Up_20170110202752(tx)   // Remove smtp_enabled
Down_20170110202752(tx) // Restore smtp_enabled
```

> **Idempotent:** The `Up` migration checks for column existence before attempting the `DROP`, making it safe to run multiple times without error.
