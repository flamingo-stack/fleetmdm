Database migration that creates the `aggregated_stats` table for storing aggregated statistical data as JSON blobs, indexed by ID, type, and update timestamp.

## Key Components

- **`Up_20211013133707`** — Creates the `aggregated_stats` table with a composite primary key `(id, type)`, a `json_value` JSON column, and an index on `updated_at`. Uses `CREATE TABLE IF NOT EXISTS` for idempotency.
- **`Down_20211013133707`** — No-op rollback; table is left in place on downgrade.
- **`init`** — Registers the migration pair with `MigrationClient`.

## Table Schema

| Column | Type | Notes |
|---|---|---|
| `id` | `INT UNSIGNED` | Part of composite PK |
| `type` | `VARCHAR(255)` | Part of composite PK |
| `json_value` | `JSON` | Aggregated stats payload |
| `created_at` | `TIMESTAMP` | Defaults to current time |
| `updated_at` | `TIMESTAMP` | Auto-updates on row change |

## Notes

- Engine: `InnoDB`, charset: `utf8mb4` with `utf8mb4_unicode_ci` collation.
- The `idx_aggregated_stats_updated_at` index supports efficient queries filtering or sorting by staleness.
- The empty `Down_` function means this migration is intentionally irreversible — dropping the table must be handled manually if needed.
