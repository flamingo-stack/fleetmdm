Database migration that adds a `host_only` boolean column to the `activities` table, with an idempotent up migration that checks for column existence before altering the schema.

## Key Components

| Function | Description |
|---|---|
| `Up_20250811155036` | Adds `host_only BOOLEAN NOT NULL DEFAULT false` column to `activities` if it doesn't already exist |
| `Down_20250811155036` | No-op rollback (column removal not implemented) |
| `init` | Registers the migration with `MigrationClient` |

## Usage Example

This migration is applied automatically via the `MigrationClient` when running database migrations:

```go
// Migration is self-registering via init()
// Idempotent check prevents duplicate column errors
if !columnExists(tx, "activities", "host_only") {
    stmt := `ALTER TABLE activities ADD COLUMN host_only BOOLEAN NOT NULL DEFAULT false`
    tx.Exec(stmt)
}
```

## Notes

- **Idempotent**: Safe to run multiple times; `columnExists` guard prevents errors if the column already exists
- **Non-reversible**: `Down` is a no-op — rollback does not drop the column
- Migration timestamp: `20250811155036`
