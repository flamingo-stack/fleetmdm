## Key Components

- **`Up_20230915101341`** — Idempotent migration that adds a `client_error` column (`varchar(255)`, `utf8mb4_unicode_ci`, `NOT NULL DEFAULT ''`) to `host_disk_encryption_keys` if it does not already exist.
- **`Down_20230915101341`** — No-op rollback function; the column addition is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Notes

- The `Down` migration is intentionally a no-op; dropping the column must be handled manually if needed.
