Database migration that adds support for "No team" policies in Fleet MDM, enabling policies to target hosts that belong to no team (`hosts.team_id = NULL`).

## Key Components

- **`Up_20240905200001`** — Applies the migration with three changes:
  - Drops the foreign key constraint from `policies` → `teams` to allow `team_id = 0` as a valid "No team" sentinel value
  - Modifies `policy_stats` to support NULL `inherited_team_id` (global domain) and `inherited_team_id = 0` (No team domain), and adds a generated column `inherited_team_id_char` for unique constraint enforcement
  - Migrates existing rows where `inherited_team_id = 0` to `NULL` (freeing `0` to represent "No team")
- **`Down_20240905200001`** — No-op rollback

## Team ID Semantics After Migration

| Value | Meaning |
|---|---|
| `policies.team_id = NULL` | Global policy (all teams) |
| `policies.team_id > 0` | Team-specific policy |
| `policies.team_id = 0` | "No team" policy |

| `inherited_team_id` | `inherited_team_id_char` | Meaning |
|---|---|---|
| `NULL` | `'global'` | Global policy stats |
| `<TEAM_ID>` | `'<TEAM_ID>'` | Per-team stats |
| `0` | `'0'` | "No team" domain stats |
