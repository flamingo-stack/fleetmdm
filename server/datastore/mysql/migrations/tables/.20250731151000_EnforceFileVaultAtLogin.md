Database migration that enforces FileVault at login by setting `DeferForceAtUserLoginMaxBypassAttempts` to `0` on existing FileVault MDM configuration profiles, and archives affected host records to a legacy table for debugging purposes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `enforceFileVaultAtLogin` | `func([]byte) ([]byte, error)` | Unmarshals a mobileconfig plist, sets `DeferForceAtUserLoginMaxBypassAttempts = 0` on any `com.apple.MCX.FileVault2` payload, and returns the re-marshalled plist |
| `Up_20250723111413` | `func(*sql.Tx) error` | Migration up: creates `legacy_host_filevault_profiles`, copies current FileVault host records into it, then patches all matching `mdm_apple_configuration_profiles` rows |
| `Down_20250723111413` | `func(*sql.Tx) error` | No-op rollback (intentionally empty) |

## Migration Behaviour

```text
1. CREATE TABLE legacy_host_filevault_profiles  (if not exists)
2. INSERT INTO legacy ... SELECT FROM host_mdm_apple_profiles
   WHERE profile_identifier = 'com.fleetdm.fleet.mdm.filevault'
3. SELECT profile_id, mobileconfig FROM mdm_apple_configuration_profiles
   WHERE identifier = 'com.fleetdm.fleet.mdm.filevault'
4. For each profile → enforceFileVaultAtLogin() → UPDATE mobileconfig
```

## Usage Example

```go
// enforceFileVaultAtLogin can be unit-tested independently of the DB migration.
original, _ := os.ReadFile("filevault.mobileconfig")

updated, err := enforceFileVaultAtLogin(original)
if err != nil {
    log.Fatalf("patch failed: %v", err)
}

// updated is a valid plist with DeferForceAtUserLoginMaxBypassAttempts = 0
// on every com.apple.MCX.FileVault2 payload found in the profile.
os.WriteFile("filevault_patched.mobileconfig", updated, 0644)
```

> **Note:** The migration is idempotent — `CREATE TABLE IF NOT EXISTS` and `INSERT IGNORE` prevent duplicate work on re-runs. The `legacy_host_filevault_profiles` table is retained for post-migration debugging and is not automatically dropped.
