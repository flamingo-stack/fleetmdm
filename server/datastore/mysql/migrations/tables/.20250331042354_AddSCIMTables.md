Database migration (timestamp `20250331042354`) that creates five SCIM (System for Cross-domain Identity Management) tables for user provisioning and group management.

## Key Components

### Functions

- **`Up_20250331042354`** — Creates the following InnoDB tables (idempotent via `CREATE TABLE IF NOT EXISTS`):
  - `scim_users` — Core SCIM user records with external ID, name fields, and active status
  - `host_scim_user` — Many-to-many join table linking Fleet hosts to SCIM users
  - `scim_user_emails` — User email addresses with type and primary flag; uses `BIGINT` PK due to frequent clear/repopulate cycles
  - `scim_groups` — SCIM groups with unique `display_name` (required by Entra ID)
  - `scim_user_group` — Many-to-many join table linking SCIM users to groups
- **`Down_20250331042354`** — No-op rollback (tables are left in place)

### Schema Notes

- All tables use `utf8mb4_unicode_ci` with `ENGINE=InnoDB`
- Foreign keys on join tables cascade deletes from `scim_users` and `scim_groups`
- `scim_users.user_name` has a unique index; `external_id` is indexed for lookup performance
- `scim_groups.display_name` is unique to satisfy Entra ID requirements
