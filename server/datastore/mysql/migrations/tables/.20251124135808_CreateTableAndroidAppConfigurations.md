### Table Schema

| Column | Type | Notes |
|---|---|---|
| `id` | `INT UNSIGNED` | Auto-increment primary key |
| `application_id` | `VARCHAR(255)` | Android app identifier |
| `team_id` | `INT UNSIGNED NULL` | FK → `teams(id)`, cascade delete |
