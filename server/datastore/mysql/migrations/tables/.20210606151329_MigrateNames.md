Database migration that renames the `kolide_server_url` column to `server_url` in the `app_configs` table as part of a rebranding from Kolide to Fleet.

## Key Components

- **`Up_20210606151329`** — Idempotent up migration that checks for the existence of `kolide_server_url` before renaming it to `server_url` (`varchar(255) NOT NULL DEFAULT ''`). Safe to run multiple times.
- **`Down_20210606151329`** — No-op rollback; the rename is not reversed.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

This migration is applied automatically via the Fleet migration runner. No direct invocation is needed, but the logic follows this pattern:

```go
// Applied by the migration framework
if columnExists(tx, "app_configs", "kolide_server_url") {
    _, err := tx.Exec(`
        ALTER TABLE app_configs
        CHANGE kolide_server_url server_url varchar(255) NOT NULL DEFAULT ''
    `)
}
```

The idempotency guard (`columnExists`) ensures the `ALTER TABLE` is skipped if the column has already been renamed, preventing errors on repeated runs.
