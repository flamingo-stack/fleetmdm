Provides a simple, package-level logger for the `tables` package with separate `Info` and `Warn` log levels writing to `stdout` and `stderr` respectively.

## Key Components

| Component | Description |
|-----------|-------------|
| `Logger` | Struct holding two `*log.Logger` instances: `Info` (stdout) and `Warn` (stderr) |
| `NewLogger()` | Constructor that initializes both loggers with time-prefixed formatting |
| `logger` | Package-level singleton `*Logger` instance available throughout the `tables` package |

## Logger Configuration

| Field | Destination | Prefix | Flags |
|-------|------------|--------|-------|
| `Info` | `os.Stdout` | `INFO: ` | `log.Ltime` |
| `Warn` | `os.Stderr` | `WARNING: ` | `log.Ltime` |

## Usage Example

```go
// Using the package-level singleton
logger.Info.Println("Table sync started")
logger.Warn.Printf("Missing column: %s", columnName)

// Creating a standalone logger instance
l := NewLogger()
l.Info.Println("Custom logger initialized")
l.Warn.Println("Something looks off")
```

**Example output:**

```text
INFO:     15:04:05 Table sync started
WARNING:  15:04:05 Missing column: device_id
```
