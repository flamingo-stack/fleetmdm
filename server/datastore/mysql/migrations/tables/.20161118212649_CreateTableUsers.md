Database migration that creates the `users` table, establishing the core user authentication and profile schema for the Fleet MDM platform.

## Key Components

| Function | Description |
|---|---|
| `Up_20161118212649` | Creates the `users` table if it does not already exist (idempotent) |
| `Down_20161118212649` | Drops the `users` table if it exists (rollback) |

### Table Schema

The `users` table includes the following columns:

| Column | Type | Description |
|---|---|---|
| `id` | `int unsigned` | Auto-increment primary key |
| `created_at` / `updated_at` / `deleted_at` | `timestamp` | Lifecycle timestamps |
| `deleted` | `tinyint(1)` | Soft-delete flag |
| `username` | `varchar(255)` | Unique login username |
| `password` | `varbinary(255)` | Hashed password (binary-safe) |
| `salt` | `varchar(255)` | Password salt |
| `name` / `email` | `varchar(255)` | Display name and unique email |
| `admin` / `enabled` | `tinyint(1)` | Role and account status flags |
| `admin_forced_password_reset` | `tinyint(1)` | Forces reset on next login |
| `gravatar_url` / `position` | `varchar(255)` | Optional profile metadata |

## Notes

- Uses `InnoDB` engine with `utf8mb4_unicode_ci` collation for full Unicode and emoji support.
- Unique indexes are enforced on both `username` and `email`.
- Soft-delete pattern supported via `deleted` + `deleted_at` columns.
