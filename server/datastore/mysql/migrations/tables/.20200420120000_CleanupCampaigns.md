Database migration that removes the `distributed_query_executions` table as part of a campaign cleanup operation.

## Key Components

- **`Up20200420120000`** — Drops the `distributed_query_executions` table if it exists (idempotent).
- **`Down20200420120000`** — No-op rollback; the table is not recreated on downgrade.

## Usage Example

```go
// Migration is registered automatically via init()
// and executed by the migration client in sequence.
MigrationClient.AddMigration(Up20200420120000, Down20200420120000)
```

> **Note:** This migration is intentionally idempotent — using `DROP TABLE IF EXISTS` ensures it is safe to run multiple times without error.
