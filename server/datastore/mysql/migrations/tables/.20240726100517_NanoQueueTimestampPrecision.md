Database migration that upgrades timestamp columns in MDM-related tables to microsecond precision (`TIMESTAMP(6)`).

## Key Components

| Function | Description |
|---|---|
| `Up_20240726100517` | Alters `created_at` and `updated_at` columns in `nano_commands` and `nano_enrollment_queue` to `TIMESTAMP(6)` |
| `Down_20240726100517` | No-op rollback (precision downgrade intentionally skipped) |

The migration is **idempotent** — it checks for column existence via `columnExists` before executing each `ALTER TABLE`, making it safe to run multiple times.

## Affected Tables

- **`nano_commands`** — MDM command tracking table
- **`nano_enrollment_queue`** — MDM device enrollment queue

Both tables have `created_at` and `updated_at` upgraded from `TIMESTAMP` (1-second precision) to `TIMESTAMP(6)` (microsecond precision), preserving `DEFAULT CURRENT_TIMESTAMP(6)` and `ON UPDATE CURRENT_TIMESTAMP(6)` behaviors.

## Usage Example

This migration runs automatically via the migration client at startup:

```go
// Registered automatically in init()
MigrationClient.AddMigration(Up_20240726100517, Down_20240726100517)

// Equivalent SQL applied per table:
// ALTER TABLE nano_commands
//   MODIFY COLUMN created_at TIMESTAMP(6) NULL DEFAULT CURRENT_TIMESTAMP(6),
//   MODIFY COLUMN updated_at TIMESTAMP(6) NULL DEFAULT CURRENT_TIMESTAMP(6)
//     ON UPDATE CURRENT_TIMESTAMP(6);
```
