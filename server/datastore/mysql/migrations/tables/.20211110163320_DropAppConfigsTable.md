Database migration that drops the legacy `app_configs` table from the schema.

## Key Components

- **`Up_20211110163320`** — Executes `DROP TABLE IF EXISTS app_configs` idempotently, safely removing the table if it exists without erroring on a missing table.
- **`Down_20211110163320`** — No-op rollback; the table structure is not restored on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient` at package load time.

## Usage Example

```go
// Applied automatically by the migration client during schema upgrades.
// To run manually within a transaction:
tx, _ := db.Begin()
if err := Up_20211110163320(tx); err != nil {
    tx.Rollback()
    log.Fatal(err)
}
tx.Commit()
```

## Notes

- The migration is **idempotent** — repeated execution is safe due to the `IF EXISTS` clause.
- The **down migration is intentionally empty**; restoring `app_configs` is not supported, implying its data and structure were migrated elsewhere prior to this drop.
