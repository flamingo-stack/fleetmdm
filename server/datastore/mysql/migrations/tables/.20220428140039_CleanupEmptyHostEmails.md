Database migration that removes host email records with empty string values from the `host_emails` table.

## Key Components

- **`Up_20220428140039`** — Deletes all rows from `host_emails` where `email` is an empty string. The operation is idempotent and safe to run multiple times.
- **`Down_20220428140039`** — No-op rollback; deleted rows are not restored.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Usage Example

```go
// Applied automatically by the migration runner at startup.
// To manually invoke during testing:
_, err := tx.Exec(`DELETE FROM host_emails WHERE email = ''`)
if err != nil {
    return errors.Wrap(err, "delete empty host emails")
}
```

## Notes

- **Destructive & irreversible** — the down migration is a no-op, so deleted rows cannot be recovered via rollback.
- **Idempotent** — re-running the migration on a clean table is safe.
- Part of the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) schema migration suite under the `tables` package.
