Database migration that adds a nullable `team_id` foreign key column to the `labels` table, enabling team-scoped label support in FleetMDM.

## Key Components

- **`Up_20251207050413`** — Idempotent migration that adds a `team_id INT UNSIGNED NULL` column to `labels` with a foreign key reference to `teams.id`. Uses `columnExists` guard to safely re-run without error.
- **`Down_20251207050413`** — No-op rollback; the column is intentionally left in place on downgrade.
- **`init`** — Registers both migration functions with `MigrationClient`.

## Design Notes

- **No `ON DELETE CASCADE`** — Intentional. Label membership cleanup must be handled explicitly when a label is deleted, since the membership table has no back-reference foreign key to `labels`.
- **Idempotency** — The `columnExists` check ensures the migration is safe to run multiple times without failing.
