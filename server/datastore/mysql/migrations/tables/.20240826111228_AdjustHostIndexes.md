Database migration that adjusts indexes on the `hosts` table by removing legacy search indexes and adding a new UUID index.

## Key Components

- **`Up_20240826111228`** — Applies the migration idempotently:
  - Drops `host_ip_mac_search` index if it exists
  - Drops `hosts_search` index if it exists
  - Adds `idx_hosts_uuid` index on the `uuid` column if it does not already exist
- **`Down_20240826111228`** — No-op rollback (returns `nil`)
- **`init`** — Registers both migration functions with `MigrationClient`

## Usage Example

This migration is automatically registered and executed by the migration runner. No direct invocation is required.

```go
// Migration is registered via init() and run by the migration client:
MigrationClient.AddMigration(Up_20240826111228, Down_20240826111228)

// To run all pending migrations:
if err := MigrationClient.Up(db); err != nil {
    log.Fatal(err)
}
```

## Notes

- The migration is **idempotent** — safe to run multiple times. Each DDL operation is guarded by `indexExistsTx` checks before execution.
- The rollback (`Down`) intentionally does not restore the dropped indexes; manual intervention would be required to reverse this migration.
