Adds a composite index on the `nano_enrollment_queue` table to optimize MDM enrollment queue processing, tracking the [nanomdm schema migration 00009](https://github.com/micromdm/nanomdm/blob/main/storage/mysql/schema.00009.sql).

## Key Components

| Function | Description |
|---|---|
| `Up_20230807100822` | Adds a composite index on `(priority DESC, created_at)` to `nano_enrollment_queue`. Idempotent — skips if the index already exists. |
| `Down_20230807100822` | No-op rollback; index removal is not implemented. |

## Usage Example

This migration runs automatically via the `MigrationClient` on database startup. To apply or roll back manually:

```bash
# Apply migration
fleetctl prepare db --config /etc/fleet/fleet.yml

# Or using goose directly
goose -dir ./db/migrations mysql "$DATABASE_URL" up-to 20230807100822
```

The index improves queue processing performance by allowing efficient priority-ordered scans:

```sql
-- Query pattern this index optimizes
SELECT * FROM nano_enrollment_queue
ORDER BY priority DESC, created_at
LIMIT 100;
```

> **Note:** The down migration is intentionally a no-op. Dropping this index in a rollback scenario is considered safe to skip, as the table remains functional without it.
