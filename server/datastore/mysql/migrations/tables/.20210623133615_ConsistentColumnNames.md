Database migration that standardizes column naming conventions in the `hosts` table by renaming several columns to follow consistent `snake_case` patterns.

## Key Components

- **`Up_20210623133615`** — Renames five `hosts` table columns for naming consistency. The migration is idempotent, checking for the existence of `host_name` before executing. Column renames:

| Old Name | New Name |
|---|---|
| `host_name` | `hostname` |
| `physical_memory` | `memory` |
| `detail_update_time` | `detail_updated_at` |
| `label_update_time` | `label_updated_at` |
| `last_enroll_time` | `last_enrolled_at` |

- **`Down_20210623133615`** — No-op rollback; the downward migration is not implemented.

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20210623133615, Down_20210623133615)
}

// The idempotency guard prevents re-execution if columns are already renamed
if columnExists(tx, "hosts", "host_name") {
    // ALTER TABLE runs only when old column names are still present
}
```

> **Note:** The down migration is a no-op. Rolling back this migration will not restore the original column names.
