Database migration file that adds local MFA (Multi-Factor Authentication) support by introducing `mfa_enabled` columns and a `verification_tokens` table.

## Key Components

- **`Up_20241203130032`** — Applies the migration with three idempotent operations:
  - Adds `mfa_enabled BOOLEAN NOT NULL DEFAULT FALSE` to the `users` table
  - Adds `mfa_enabled BOOLEAN NOT NULL DEFAULT FALSE` to the `invites` table
  - Creates the `verification_tokens` table linking tokens to users via a cascading foreign key
- **`Down_20241203130032`** — No-op rollback (schema changes are not reversed)
- **`init`** — Registers both functions with `MigrationClient`

## Schema Changes

```sql
-- Added to users and invites tables
mfa_enabled BOOLEAN NOT NULL DEFAULT FALSE

-- New table
CREATE TABLE verification_tokens (
  id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  user_id     INT UNSIGNED NOT NULL,
  token       VARCHAR(255) UNIQUE NOT NULL,  -- utf8mb4_unicode_ci
  created_at  TIMESTAMP(6) DEFAULT CURRENT_TIMESTAMP(6),
  FOREIGN KEY (user_id) REFERENCES users(id) ON UPDATE CASCADE ON DELETE CASCADE
)
```
