Defines deprecated type definitions previously used at global scope in the `tables` package, preserved for backward compatibility without active usage in current application logic.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `decorator` | Represents an osquery decorator query with optional name, type, interval, and built-in flag |
| `decorators` | Groups decorator queries into `load`, `always`, and `interval` categories |
| `option` | Represents a configurable osquery option with typed value and read-only protection |
| `optionValue` | Wrapper implementing `driver.Valuer`, `sql.Scanner`, and JSON interfaces for flexible option storage |
| `optionType` | Enum (`int`) for option value types: `string`, `int`, `bool` |
| `decoratorType` | Enum (`int`) for decorator execution timing: `load`, `always`, `interval` |

### Key Methods

- **`optionType.MarshalJSON` / `UnmarshalJSON`** — Serializes/deserializes option types as human-readable strings (`"string"`, `"int"`, `"bool"`)
- **`optionValue.Value`** — Satisfies `driver.Valuer`; marshals value to JSON for DB storage
- **`optionValue.Scan`** — Satisfies `sql.Scanner`; unmarshals JSON from DB, converting `float64` → `int`
- **`decoratorType.MarshalJSON` / `UnmarshalJSON`** — Converts decorator types to/from `"load"`, `"always"`, `"interval"` strings
- **`option.GetValue`** — Returns the underlying `interface{}` value from the wrapped `optionValue`

## Usage Example

```go
// Unmarshal an option from JSON
data := []byte(`{"id":1,"name":"aws_meta","type":"string","value":"us-east-1","read_only":false}`)
var opt option
if err := json.Unmarshal(data, &opt); err != nil {
    log.Fatal(err)
}
fmt.Println(opt.GetValue()) // "us-east-1"

// Unmarshal a decorator from JSON
decData := []byte(`{"id":2,"name":"os_version","type":"always","query":"SELECT * FROM os_version;"}`)
var dec decorator
if err := json.Unmarshal(decData, &dec); err != nil {
    log.Fatal(err)
}
fmt.Println(dec.Type.String()) // "always"
```

## Notes

- These types are **deprecated** and no longer required at global scope; they remain to avoid migration breakage.
- `optionValue.Scan` explicitly coerces `float64` to `int` since JSON numbers unmarshal as `float64` by default.
