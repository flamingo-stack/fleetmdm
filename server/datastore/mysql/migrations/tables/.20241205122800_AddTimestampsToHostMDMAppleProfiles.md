Adds `created_at` and `updated_at` timestamp columns to the `host_mdm_apple_profiles` table via an idempotent database migration.

## Key Components

| Function | Description |
|---|---|
| `Up_20241205122800` | Adds microsecond-precision timestamp columns to `host_mdm_apple_profiles` if they don't already exist |
| `Down_20241205122800` | No-op rollback (columns are not removed on downgrade) |

## Usage Example

```go
// Migration is auto-registered via init()
// and executed by the MigrationClient automatically.

// The Up migration performs an idempotency check before altering the table:
if !columnsExists(tx, "host_mdm_apple_profiles", "created_at", "updated_at") {
    tx.Exec(`ALTER TABLE host_mdm_apple_profiles
        ADD COLUMN created_at TIMESTAMP(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6),
        ADD COLUMN updated_at TIMESTAMP(6) NOT NULL DEFAULT CURRENT_TIMESTAMP(6)
            ON UPDATE CURRENT_TIMESTAMP(6)`)
}
```

## Notes

- **Idempotent**: Uses `columnsExists` guard — safe to run multiple times without error.
- **Precision**: Columns use `TIMESTAMP(6)` for microsecond resolution.
- `updated_at` auto-updates on row modification via `ON UPDATE CURRENT_TIMESTAMP(6)`.
- Rollback is intentionally a no-op; column removal must be handled manually if needed.
