Database migration that removes `gigs_disk_space_available` and `percent_disk_space_available` columns from the `hosts` table (timestamp: 2022-11-09).

## Key Components

- **`Down_20221109100749`** — No-op rollback; columns are not restored.

## Notes

- **Idempotent**: Checks column existence before attempting `ALTER TABLE`, so re-running is safe.
- **No rollback**: The `Down` function is a no-op — dropped columns are not recreated on rollback. Coordinate with application deployments accordingly.
- **MySQL compatibility**: By omitting `ALGORITHM` and `LOCK` hints, MySQL 5.7 defaults to `INPLACE` and MySQL 8.0.12+ uses `INSTANT`, minimising table lock duration.
