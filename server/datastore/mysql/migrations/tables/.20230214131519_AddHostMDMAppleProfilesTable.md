Database migration that creates tables for tracking MDM Apple configuration profile delivery status and operation types per host.

## Key Components

- **`Up_20230214131519`** — Creates three tables:
  - `mdm_apple_delivery_status` — Enum-style lookup table seeded with `failed`, `applied`, `pending`
  - `mdm_apple_operation_types` — Enum-style lookup table seeded with `install`, `remove`
  - `host_mdm_apple_profiles` — Tracks per-host MDM profile state, with foreign keys referencing both lookup tables
- **`Down_20230214131519`** — No-op rollback (returns `nil`)

## Schema Details

The `host_mdm_apple_profiles` table:

| Column | Type | Notes |
|---|---|---|
| `profile_id` | `int UNSIGNED` | Part of composite PK |
| `profile_identifier` | `varchar(255)` | MDM profile bundle ID |
| `host_uuid` | `varchar(255)` | Part of composite PK |
| `status` | `varchar(20)` | FK → `mdm_apple_delivery_status` |
| `operation_type` | `varchar(20)` | FK → `mdm_apple_operation_types` |
| `detail` | `text` | Error/status detail |
| `command_uuid` | `varchar(127)` | MDM command correlation ID |
