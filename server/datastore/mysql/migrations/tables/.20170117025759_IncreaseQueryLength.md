Database migration that expands the `query` column type from `VARCHAR(255)` to `TEXT` across the `decorators`, `queries`, and `labels` tables.

## Key Components

| Function | Description |
|---|---|
| `Up_20170117025759` | Idempotent migration that alters `query` columns to `TEXT NOT NULL` on all three tables |
| `Down_20170117025759` | Reverts `query` columns back to `VARCHAR(255) NOT NULL` |
| `init` | Registers both migration functions with `MigrationClient` |

## Behavior Notes

- **Up migration is idempotent** — uses `columnExists()` checks before executing each `ALTER TABLE`, making it safe to run multiple times.
- **Down migration is not idempotent** — executes `ALTER TABLE` directly without existence checks; data truncation may occur if any stored query exceeds 255 characters.
- Affects three tables: `decorators`, `queries`, and `labels`.

## Usage Example

Migrations are registered automatically via `init()` and executed by the migration runner:

```go
// Applied automatically by the migration client
// Manual execution (up)
err := Up_20170117025759(tx)

// Manual rollback (down)
err := Down_20170117025759(tx)
```
