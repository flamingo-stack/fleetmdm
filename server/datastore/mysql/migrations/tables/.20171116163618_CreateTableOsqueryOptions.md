Database migration file that creates the `osquery_options` table and migrates existing osquery configuration data (options, FIM paths, decorators) into a unified JSON column.

## Key Components

- **`Up_20171116163618`** — Creates the `osquery_options` table and either migrates existing options from legacy tables or inserts a default configuration with TLS logging and distributed query settings.
- **`Down_20171116163618`** — Drops the `osquery_options` table.
- **`migrateOptions`** — Consolidates data from three legacy tables (`options`, `file_integrity_monitorings`/`file_integrity_monitoring_files`, `decorators`) into a single JSON blob stored in the new table.

## Table Schema

```sql
CREATE TABLE IF NOT EXISTS `osquery_options` (
  `id`                  INT(10) UNSIGNED NOT NULL AUTO_INCREMENT,
  `override_type`       INT(1) NOT NULL,
  `override_identifier` VARCHAR(255) NOT NULL DEFAULT '',
  `options`             JSON NOT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## Usage Example

The migration is registered automatically via `init()` and executed by the migration client:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20171116163618, Down_20171116163618)
}

// Apply migration
err := Up_20171116163618(tx)

// Roll back migration
err := Down_20171116163618(tx)
```

The default JSON configuration inserted when no prior options exist includes:

```json
{
  "options": {
    "logger_plugin": "tls",
    "pack_delimiter": "/",
    "logger_tls_period": 10,
    "distributed_plugin": "tls",
    "disable_distributed": false,
    "logger_tls_endpoint": "/api/v1/osquery/log",
    "distributed_interval": 10,
    "distributed_tls_max_attempts": 3
  },
  "decorators": {
    "load": [
      "SELECT uuid AS host_uuid FROM system_info;",
      "SELECT hostname AS hostname FROM system_info;"
    ]
  }
}
```
