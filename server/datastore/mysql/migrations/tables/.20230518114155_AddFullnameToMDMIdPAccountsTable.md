Database migration that modifies the `mdm_idp_accounts` table by removing legacy password-hashing columns (`salt`, `entropy`, `iterations`) and adding a `fullname` column for storing IdP account display names.

## Key Components

- **`Up_20230518114155`** — Idempotent upgrade migration that:
  - Drops `salt`, `entropy`, and `iterations` columns if they exist
  - Adds `fullname` as a `varchar(256)` column with `utf8mb4_unicode_ci` collation if not already present
- **`Down_20230518114155`** — No-op rollback (structural column removal is not reversed)

## Usage Example

This migration is registered automatically via `init()` and executed by the migration client during schema upgrades:

```go
// Registered automatically on package import
func init() {
    MigrationClient.AddMigration(Up_20230518114155, Down_20230518114155)
}

// Migration is idempotent — safe to re-run if partially applied
err := Up_20230518114155(tx)
if err != nil {
    log.Fatalf("migration failed: %v", err)
}
```

The migration uses `columnExists` checks before each DDL statement, making it safe to apply multiple times without error.
