Provides MySQL datastore methods for Apple MDM profile reconciliation, implementing batch and single-host queries to load enrolled Apple device information and configuration profiles for the MDM reconciler.

## Key Components

### Functions

- **`listAppleMDMHostsForReconcileBatchTransaction`** — Paginated query returning up to `batchSize` Apple MDM-enrolled hosts (darwin/ios/ipados) with host UUID > `afterHostUUID`, joined with `nano_enrollments` and `nano_devices` for reconcile state.

- **`GetAppleMDMHostForReconcile`** — Single-host lookup by UUID returning `AppleHostReconcileInfo`, or `(nil, nil)` if the host is not enrolled or not an Apple platform.

- **`ListAppleProfilesForReconcileByTeam`** — Public method loading Apple configuration profiles scoped to a specific team ID; used by the per-enrollment reconcile path.

- **`listAppleProfilesForReconcileTransaction`** — Core profile loader. When `teamID` is `nil`, returns all profiles (batch mode); when set, filters to that team only. Loads label assignments (include/exclude/require_all) and resolves per-profile `IncludeMode` (`Any`, `All`, or drops mixed-mode include sets).

- **`BulkGetHostMDMAppleProfilesByUUIDs`** — Returns current `host_mdm_apple_profiles` rows grouped by host UUID, chunked at 5,000 UUIDs per query.

- **`bulkGetHostMDMAppleProfilesByUUIDsTransaction`** — Internal implementation of the above, accepts an explicit transaction/reader.

## Usage Example

```go
// Batch reconcile: iterate pages of enrolled hosts
var afterUUID string
for {
    hosts, err := ds.listAppleMDMHostsForReconcileBatchTransaction(ctx, tx, afterUUID, 500)
    if err != nil || len(hosts) == 0 {
        break
    }
    afterUUID = hosts[len(hosts)-1].UUID
}

// Per-enrollment reconcile: load profiles for a host's team
profiles, err := ds.ListAppleProfilesForReconcileByTeam(ctx, host.TeamID)

// Fetch current profile status for a batch of hosts
uuids := []string{"uuid-1", "uuid-2"}
profileMap, err := ds.BulkGetHostMDMAppleProfilesByUUIDs(ctx, uuids)
```

## Notes

- Team `0` represents the "no team" global scope; hosts with a real team do **not** inherit team `0` profiles.
- Mixed `require_all` values on include labels for the same profile drop the include set entirely and log an error.
- Label rows with a `NULL` `label_id` (broken labels) are preserved so callers can apply broken-label semantics consistently.
