Manages MySQL-backed software inventory for Fleet MDM hosts, handling CRUD operations for host software records, installed paths, upgrade codes, and software title associations.

## Key Components

### Types
- `softwareSummary` — DB row struct for software metadata (ID, checksum, name, title, bundle identifier, upgrade code, source)
- `oldAndNewUpgradeCodePtrs` — holds old/new upgrade code pointers for diff operations

### Primary Functions

| Function | Description |
|---|---|
| `UpdateHostSoftware` | Applies software inventory changes for a host with OTEL tracing |
| `UpdateHostSoftwareInstalledPaths` | Syncs `host_software_installed_paths` table with osquery-reported paths |
| `hostSoftwareInstalledPathsDelta` | Computes insert/delete delta between reported and stored installed paths |
| `nothingChanged` | Deduplicates incoming software and checks if inventory has changed |
| `macOSTopLevelApplicationTitleIDs` | Returns title IDs for top-level macOS `/Applications/` apps on a host |
| `deleteHostSoftwareInstalledPaths` | Bulk-deletes installed path rows by ID |
| `insertHostSoftwareInstalledPaths` | Batch-inserts installed path rows (batch size: 500) |

### Tunable Batch Variables

```go
countHostSoftwareBatchSize      = 100000 // aggregation count batching
softwareInsertBatchSize         = 1000   // main software insert batch
softwareInventoryInsertBatchSize = 100   // pre-insert inventory entries
cleanupBatchSize                = 1000   // orphan cleanup deletes per batch
cleanupMaxIterations            = 100    // max cleanup batches per cron run
```

## Usage Example

```go
// Update software inventory for a host
result, err := ds.UpdateHostSoftware(ctx, hostID, softwareList)
if err != nil {
    return err
}

// Sync installed paths from osquery results
err = ds.UpdateHostSoftwareInstalledPaths(ctx, hostID, reportedPaths, result)
if err != nil {
    return err
}

// Get top-level macOS app title IDs for a host
titleIDs, err := ds.macOSTopLevelApplicationTitleIDs(ctx, hostID)
```
