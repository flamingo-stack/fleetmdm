MySQL datastore implementation for managing Certificate Authority (CA) records, handling encrypted secret fields (API tokens, passwords, challenges, client secrets) and batch operations.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `certificateAuthorityWithEncryptedSecrets` | struct | Internal DB scan target that extends `fleet.CertificateAuthority` with raw encrypted byte fields |
| `GetCertificateAuthorityByID` | method | Fetches a single CA by ID; optionally decrypts secrets or masks them |
| `GetAllCertificateAuthorities` | method | Fetches all CAs with optional secret decryption/masking |
| `ListCertificateAuthorities` | method | Returns lightweight `CertificateAuthoritySummary` records (id, name, type only) |
| `GetGroupedCertificateAuthorities` | method | Returns all CAs grouped by type via `fleet.GroupCertificateAuthoritiesByType` |
| `NewCertificateAuthority` | method | Inserts a new CA, encrypting secrets before storage |
| `BatchApplyCertificateAuthorities` | method | Atomically upserts and deletes CAs within a retried transaction |
| `postprocessRetrievedCertificateAuthority` | function | Decrypts or masks sensitive fields and unmarshals JSON UPN array after a DB read |
| `batchUpsertCertificateAuthorities` | function | Builds and executes a multi-row `INSERT … ON DUPLICATE KEY UPDATE` |
| `batchDeleteCertificateAuthorities` | function | Deletes CAs by `(name, type)` pairs; returns a friendly conflict error on FK violations |
| `sqlGenerateArgsForInsertCertificateAuthority` | function | Encrypts secrets and marshals UPNs, returning ordered args and a placeholder string |

## Usage Example

```go
// Fetch a CA with secrets decrypted
ca, err := ds.GetCertificateAuthorityByID(ctx, 42, true)
if err != nil {
    log.Fatal(err)
}
fmt.Println(*ca.APIToken) // plaintext

// Create a new CA
newCA := &fleet.CertificateAuthority{
    Type:     "SCEP",
    Name:     "Corp SCEP",
    URL:      "https://scep.example.com",
    APIToken: ptr.String("secret-token"),
}
created, err := ds.NewCertificateAuthority(ctx, newCA)

// Batch apply (add/update/delete) within a transaction
err = ds.BatchApplyCertificateAuthorities(ctx, fleet.CertificateAuthoritiesBatchOperations{
    Add:    []*fleet.CertificateAuthority{newCA},
    Delete: []*fleet.CertificateAuthority{oldCA},
})
```

## Notes

- Secrets (`APIToken`, `Password`, `Challenge`, `ClientSecret`) are **never stored in plaintext**; they are encrypted with `ds.serverPrivateKey` using the shared `encrypt`/`decrypt` helpers.
- When `includeSecrets` is `false`, secret fields are replaced with `fleet.MaskedPassword` instead of being decrypted.
- `CertificateUserPrincipalNames` is stored as a JSON blob and unmarshalled on retrieval.
- Duplicate name conflicts on insert return `fleet.ConflictError` keyed to the `idx_ca_type_name` unique index.
