Manages Fleet label database operations including applying label specs, membership tracking, and team-scoped label access control in MySQL.

## Key Components

- **`ApplyLabelSpecs`** – Delegates to `ApplyLabelSpecsWithAuthor` with no author override; entry point for spec-driven label upserts.
- **`ApplyLabelSpecsWithAuthor`** – Core upsert logic: inserts/updates label records, cleans up memberships on platform changes, and resolves manual label membership by hostname, serial, UUID, or host ID across batched queries.
- **`SetAsideLabels`** – Renames conflicting labels by appending `__team_{id}` suffix before applying new specs; enforces write-role checks (admin/maintainer/technician/gitops) at both global and team scope.
- **`checkHostIdentifiersInTeam`** – Validates that host identifiers belong to the expected team before inserting manual label memberships.
- **`labelsAllowedOrderKeys`** – Allowlist mapping API sort keys (e.g. `name`, `host_count`, `team_id`) to SQL column expressions for safe `ORDER BY` construction.

## Usage Example

```go
// Upsert labels from a GitOps spec file
specs := []*fleet.LabelSpec{
    {
        Name:                "macOS Ventura",
        Platform:            "darwin",
        LabelType:           fleet.LabelTypeDynamic,
        LabelMembershipType: fleet.LabelMembershipTypeDynamic,
        Query:               "SELECT 1 FROM os_version WHERE major = 13;",
    },
    {
        Name:                "Staging Servers",
        LabelMembershipType: fleet.LabelMembershipTypeManual,
        TeamID:              &teamID,
        Hosts:               []string{"host-1", "AA:BB:CC:DD:EE:FF", "uuid-xyz"},
    },
}

authorID := uint(42)
if err := ds.ApplyLabelSpecsWithAuthor(ctx, specs, &authorID); err != nil {
    log.Fatal(err)
}

// Rename conflicting labels before applying new ones for a team
err := ds.SetAsideLabels(ctx, &teamID, []string{"Old Label"}, currentUser)
```

## Notes

- Manual label membership resolves hosts by **hostname, hardware serial, UUID, or integer ID**; identifiers are batched to avoid MySQL parameter limits.
- Platform changes on existing labels **purge all memberships**, allowing Fleet's query executor to rebuild from scratch.
- `SetAsideLabels` enforces a strict permission model: team-scoped users may only set aside labels they authored on other teams; global roles bypass this restriction.
