Provides MySQL datastore operations for managing custom display names associated with software titles on a per-team basis.

## Key Components

| Function | Description |
|---|---|
| `updateSoftwareTitleDisplayName` | Upserts a display name for a given software title and team into `software_title_display_names` |
| `getDisplayNamesByTeamAndTitleIds` | Bulk-fetches display names for multiple title IDs under a team, using batched queries (32,000 IDs per batch) |
| `getSoftwareTitleDisplayName` | Fetches a single display name for a specific team/title combination |

## Usage Example

```go
// Upsert a display name within a transaction
err := updateSoftwareTitleDisplayName(ctx, tx, &teamID, titleID, "Custom App Name")

// Bulk fetch display names for a team
nameMap, err := ds.getDisplayNamesByTeamAndTitleIds(ctx, teamID, []uint{1, 2, 3})
if err != nil {
    // handle error
}
for titleID, name := range nameMap {
    fmt.Printf("Title %d: %s\n", titleID, name)
}

// Fetch a single display name
name, err := ds.getSoftwareTitleDisplayName(ctx, teamID, titleID)
```

## Notes

- `updateSoftwareTitleDisplayName` treats a `nil` `teamID` as team `0` (global scope).
- `getDisplayNamesByTeamAndTitleIds` batches queries at **32,000 IDs** to stay under MySQL's 65,535 prepared statement placeholder limit.
- `getSoftwareTitleDisplayName` returns a typed `notFound` error when no row exists, suitable for upstream 404 handling.
