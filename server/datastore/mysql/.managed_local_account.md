MySQL datastore implementation for managing MDM-controlled local account passwords on enrolled hosts, including encrypted storage, status tracking, and rotation lifecycle management.

## Key Components

| Function | Description |
|---|---|
| `SaveHostManagedLocalAccount` | Upserts an encrypted local account password and associated MDM command UUID for a host |
| `GetHostManagedLocalAccountPassword` | Retrieves and decrypts the current local account password for a host |
| `GetHostManagedLocalAccountStatus` | Returns delivery status, password availability, and rotation state |
| `SetHostManagedLocalAccountStatus` | Updates the MDM delivery status for a host's managed local account |
| `GetManagedLocalAccountUUID` / `SetManagedLocalAccountUUID` | Read/write the macOS local account UUID |
| `GetManagedLocalAccountByCommandUUID` / `GetManagedLocalAccountByPendingCommandUUID` | Look up the host associated with an MDM command UUID (active or pending rotation) |
| `MarkManagedLocalAccountPasswordViewed` | Sets a 65-minute auto-rotation deadline on first password view |
| `InitiateManagedLocalAccountRotation` | Stages a pending password rotation with eligibility guards and typed error returns |

## Usage Example

```go
// Save a new managed local account password after MDM command enqueue
err := ds.SaveHostManagedLocalAccount(ctx, hostUUID, plaintextPassword, commandUUID)

// Retrieve the decrypted password for display
account, err := ds.GetHostManagedLocalAccountPassword(ctx, hostUUID)
if err != nil {
    // handle notFound or decryption error
}
fmt.Println(account.Password)

// Check rotation/delivery status before surfacing to UI
status, err := ds.GetHostManagedLocalAccountStatus(ctx, hostUUID)
if status.PendingRotation {
    // rotation in flight, suppress password display
}

// Stage a rotation (returns ErrManagedLocalAccountRotationPending if one is already in flight)
err = ds.InitiateManagedLocalAccountRotation(ctx, hostUUID, newPassword, newCmdUUID)
```

## Notes

- All passwords are AES-encrypted at rest using `ds.serverPrivateKey` via the shared `encrypt`/`decrypt` helpers.
- `MarkManagedLocalAccountPasswordViewed` uses a conditional `UPDATE` (guards on `auto_rotate_at IS NULL`) to avoid extending an already-running rotation timer.
- `InitiateManagedLocalAccountRotation` returns typed errors (`ErrManagedLocalAccountRotationPending`, `ErrManagedLocalAccountNotEligible`) so callers (API handlers vs. cron) can react appropriately.
- Column interpolation in `lookupManagedLocalAccountHost` is safe because callers pass fixed identifiers, never user input.
