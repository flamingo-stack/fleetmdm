MySQL datastore implementation for managing software title icons, providing CRUD operations and cleanup utilities for icons associated with software installers, VPP apps, and in-house apps across teams.

## Key Components

| Function | Description |
|---|---|
| `CreateOrUpdateSoftwareTitleIcon` | Upserts an icon record for a given team and software title |
| `GetSoftwareTitleIcon` | Retrieves a single icon by team ID and title ID |
| `GetTeamIdsForIconStorageId` | Returns all team IDs referencing a given storage object |
| `GetSoftwareIconsByTeamAndTitleIds` | Batch-fetches icons for multiple title IDs within a team |
| `DeleteSoftwareTitleIcon` | Removes a specific icon record; returns not-found error if absent |
| `DeleteIconsAssociatedWithTitlesWithoutInstallers` | Cleans up orphaned icons for titles with no active installer, VPP app, or in-house app |
| `CleanupUnusedSoftwareTitleIcons` | Removes files from the icon object store that are no longer referenced in the DB |
| `ActivityDetailsForSoftwareTitleIcon` | Fetches rich activity metadata (labels, team info, installer details) for audit logging |

## Usage Example

```go
// Upsert an icon after uploading to object storage
icon, err := ds.CreateOrUpdateSoftwareTitleIcon(ctx, &fleet.UploadSoftwareTitleIconPayload{
    TeamID:    42,
    TitleID:   7,
    StorageID: "icons/abc123.png",
    Filename:  "chrome.png",
})

// Retrieve an icon for a specific team + title
icon, err := ds.GetSoftwareTitleIcon(ctx, 42, 7)

// Batch lookup icons for a list of title IDs
iconsMap, err := ds.GetSoftwareIconsByTeamAndTitleIds(ctx, 42, []uint{7, 8, 9})

// Periodic cleanup: remove DB rows for orphaned icons, then purge object store
err = ds.DeleteIconsAssociatedWithTitlesWithoutInstallers(ctx, teamID)
err = ds.CleanupUnusedSoftwareTitleIcons(ctx, iconStore, time.Now().Add(-24*time.Hour))
```

> **Note:** `CleanupUnusedSoftwareTitleIcons` intentionally reads storage IDs from the writer connection to avoid replica lag causing accidental deletion of recently uploaded icons.
