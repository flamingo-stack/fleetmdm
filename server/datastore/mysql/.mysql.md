MySQL datastore implementation for Fleet's primary persistence layer, providing connection management, read/write routing, statement caching, and migration support for both primary and replica MySQL databases.

## Key Components

| Component | Description |
|---|---|
| `Datastore` | Core struct implementing `fleet.Datastore` backed by MySQL with primary/replica support |
| `New()` | Creates a new MySQL datastore with options |
| `NewDatastore()` | Creates a datastore from pre-existing `DBConnections` (for shared connections) |
| `NewDBConnections()` | Establishes primary and optional replica DB connections with IAM auth support |
| `reader()` / `writer()` | Context-aware DB routing; forces primary when `ctxdb.RequirePrimary` is set |
| `loadOrPrepareStmt()` | Thread-safe prepared statement cache against the replica connection |
| `withRetryTxx()` / `withTx()` / `withReadTx()` | Transaction helpers for write, retry, and read-only operations |
| `writeChanLoop()` | Background goroutine processing async write operations via `writeCh` channel |
| `NewSCEPDepot()` | Returns a SCEP certificate depot using the primary DB |
| `NewHostIdentitySCEPDepot()` / `NewConditionalAccessSCEPDepot()` | EE SCEP depot constructors for host identity and conditional access |

## Usage Example

```go
import (
    "github.com/WatchBeam/clock"
    "github.com/fleetdm/fleet/v4/server/config"
    "github.com/fleetdm/fleet/v4/server/datastore/mysql"
)

cfg := config.MysqlConfig{
    Address:  "localhost:3306",
    Database: "fleet",
    Username: "fleet",
    Password: "secret",
}

// Simple initialization
ds, err := mysql.New(cfg, clock.C, mysql.WithLogger(logger))
if err != nil {
    log.Fatal(err)
}

// Shared connections across datastores
conns, err := mysql.NewDBConnections(cfg,
    mysql.WithReplica(replicaCfg),
    mysql.WithPrivateKey(privateKey),
)
if err != nil {
    log.Fatal(err)
}
ds, err := mysql.NewDatastore(conns, cfg, clock.C)
```

> **Note:** Prepared statements consume MySQL server resources per connection. Monitor `max_prepared_stmt_count` when adding new cached statements. See [issue #15476](https://github.com/fleetdm/fleet/issues/15476).
