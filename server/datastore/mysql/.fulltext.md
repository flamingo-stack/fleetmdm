Provides utility functions for transforming and validating search queries before passing them to MySQL's Full-Text Search (FTS) engine.

## Key Components

| Function | Description |
|---|---|
| `queryMinLength(query string) bool` | Returns `true` if the longest term in the query meets the minimum length threshold (≥ 3 characters) required to avoid MySQL's short-word filtering |
| `countLongestTerm(query string) int` | Splits a query on spaces and returns the character length of the longest individual term |
| `transformQuery(query string) string` | Sanitizes a query for MySQL FTS by stripping special operator characters (`-`, `+`, `@`) and appending a wildcard suffix (`*`) |
| `transformQueryWithSuffix(query, suffix string) string` | Core transformation logic — replaces FTS operator symbols with spaces and appends a configurable suffix |

The package-level `mysqlFTSSymbolRegexp` regexp (`[-+@]+`) matches one or more consecutive MySQL FTS operator characters that would otherwise be interpreted as boolean search operators.

## Usage Example

```go
// Validate query meets minimum length before executing FTS search
query := "web server"
if !queryMinLength(query) {
    // skip FTS, fall back to LIKE or return empty result
}

// Sanitize and prepare query for MATCH ... AGAINST
ftsQuery := transformQuery(query)
// ftsQuery == "web server*"

// With a custom suffix
ftsQuery = transformQueryWithSuffix("web+server", "")
// ftsQuery == "web server"
```

> **Note:** `queryMinLength` is marked for removal in [issue #2627](https://github.com/flamingo-stack/fleetmdm/issues/2627). The threshold of 3 reflects the default MySQL `ft_min_word_len` of 4 used in Fleet deployments.
