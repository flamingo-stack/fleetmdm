MySQL datastore implementation for managing distributed query campaigns, including CRUD operations, target management, and cleanup routines for completed campaigns.

## Key Components

| Function | Description |
|---|---|
| `NewDistributedQueryCampaign` | Inserts a new distributed query campaign record |
| `DistributedQueryCampaign` | Fetches a single campaign by ID |
| `SaveDistributedQueryCampaign` | Updates an existing campaign's status, query, and user |
| `DistributedQueryCampaignsForQuery` | Returns all campaigns associated with a query ID |
| `DistributedQueryCampaignTargetIDs` | Returns host, label, and team target IDs for a campaign |
| `NewDistributedQueryCampaignTarget` | Inserts a new campaign target record |
| `GetCompletedCampaigns` | Filters a list of campaign IDs to those with `QueryComplete` status |
| `CleanupDistributedQueryCampaigns` | Expires stale waiting/running campaigns past their time limits |
| `CleanupCompletedCampaignTargets` | Batch-deletes target rows for old completed campaigns |

**Cleanup constants:**

| Constant | Value | Purpose |
|---|---|---|
| `campaignTargetsCleanupBatchSize` | `10,000` | Rows deleted per batch |
| `campaignTargetsCleanupMinPerRun` | `50,000` | Minimum targets deleted per run |
| `campaignTargetsCleanupPercentPerRun` | `10%` | Fraction of eligible targets to process |
| `campaignTargetsCleanupBatchSleep` | `100ms` | Pause between batches |

## Usage Example

```go
// Create a new campaign
camp, err := ds.NewDistributedQueryCampaign(ctx, &fleet.DistributedQueryCampaign{
    QueryID: 42,
    Status:  fleet.QueryWaiting,
    UserID:  1,
})

// Expire stale campaigns
expired, err := ds.CleanupDistributedQueryCampaigns(ctx, time.Now())

// Clean up targets for campaigns completed over 7 days ago
deleted, err := ds.CleanupCompletedCampaignTargets(ctx, time.Now().Add(-7*24*time.Hour))
```

## Notes

- `CleanupCompletedCampaignTargets` caps deletion at 10% of eligible rows (min 50k) per run and sleeps 100ms between batches to reduce database load.
- `GetCompletedCampaigns` batches input IDs in groups of 65,534 to respect MySQL's placeholder limit.
- Waiting campaigns expire after **1 minute**; running campaigns expire after **24 hours**.
