MySQL datastore implementation for managing host disk encryption keys, including escrow lifecycle operations, LUKS support, and key archival for both macOS and Windows/BitLocker environments.

## Key Components

| Function | Description |
|---|---|
| `SetOrUpdateHostDiskEncryptionKey` | Upserts a host's disk encryption key with optional decryptability flag; archives changed keys |
| `SaveLUKSData` | Stores LUKS passphrase, salt, and key slot for Linux disk encryption |
| `DeleteLUKSData` | Removes a LUKS key entry by host ID and key slot |
| `archiveHostDiskEncryptionKey` | Writes a previous key to the archive table when the incoming key differs |
| `GetHostDiskEncryptionKey` | Fetches the current encryption key record for a host |
| `GetHostArchivedDiskEncryptionKey` | Retrieves the most recent archived key, falling back to hardware serial lookup |
| `GetUnverifiedDiskEncryptionKeys` | Returns keys with `decryptable IS NULL` (macOS only; Windows keys are always decryptable) |
| `SetHostsDiskEncryptionKeyStatus` | Bulk-updates decryptability status for a list of hosts |
| `QueueEscrow` / `ClearPendingEscrow` / `IsHostPendingEscrow` | Manages escrow request lifecycle via `reset_requested` flag |
| `ReportEscrowError` | Records a client-side escrow error without overwriting an existing key |
| `AssertHasNoEncryptionKeyStored` | Guards against re-escrowing when a key already exists |

## Usage Example

```go
// Store or update a macOS FileVault key
archived, err := ds.SetOrUpdateHostDiskEncryptionKey(ctx, host, base64Key, "", &decryptable)

// Store a Linux LUKS passphrase
archived, err := ds.SaveLUKSData(ctx, host, base64Passphrase, base64Salt, keySlot)

// Queue escrow and later clear it
_ = ds.QueueEscrow(ctx, host.ID)
pending := ds.IsHostPendingEscrow(ctx, host.ID) // true
_ = ds.ClearPendingEscrow(ctx, host.ID)

// Bulk-mark keys verified after server-side decryption attempt
err = ds.SetHostsDiskEncryptionKeyStatus(ctx, hostIDs, true, threshold)

// Fetch the current key for a host
key, err := ds.GetHostDiskEncryptionKey(ctx, host.ID)
```
