Provides MySQL datastore operations for querying, listing, and managing software titles in Fleet MDM, including support for team-scoped filtering, installer metadata, VPP apps, and optimized pagination.

## Key Components

- **`SoftwareTitleByID`** — Fetches a single software title with version details, auto-update schedules, and icon/display name, scoped to a team or global context.
- **`SoftwareTitleNameForHostFilter`** — Lightweight lookup returning only the name and display name of a title for use in host list filters, intentionally bypassing team-scoped inventory auth.
- **`UpdateSoftwareTitleName`** — Updates the name of a software title (restricted to titles with a bundle identifier).
- **`ListSoftwareTitles`** — Lists software titles with filtering, sorting, and pagination. Validates options and routes to an optimized fast-path query when possible.
- **`softwareTitleWithInstallerFields`** — Internal struct extending `SoftwareTitleListResult` with scanned installer, VPP, and in-house app columns for post-processing.
- **`canUseOptimizedListTitlesQuery`** — Determines whether the fast-path `listSoftwareTitlesOptimized` can be used based on active filters and sort order.
- **`softwareTitlesAllowedOrderKeys`** — Allowlist mapping API sort keys to SQL column expressions.

## Usage Example

```go
// Fetch a single software title scoped to a team
teamID := uint(42)
title, err := ds.SoftwareTitleByID(ctx, titleID, &teamID, tmFilter)

// List software titles with pagination
titles, count, meta, err := ds.ListSoftwareTitles(ctx, fleet.SoftwareTitleListOptions{
    ListOptions: fleet.ListOptions{
        OrderKey:       "hosts_count",
        OrderDirection: fleet.OrderDescending,
        Page:           0,
        PerPage:        20,
    },
    TeamID:         &teamID,
    VulnerableOnly: false,
}, tmFilter)

// Lightweight name lookup for host filters
name, displayName, err := ds.SoftwareTitleNameForHostFilter(ctx, titleID)
```
