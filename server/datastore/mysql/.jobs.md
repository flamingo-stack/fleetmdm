MySQL-backed implementation of the `fleet.Job` queue persistence layer, providing CRUD operations and queue management for background worker jobs.

## Key Components

| Function | Description |
|---|---|
| `NewJob` | Inserts a new job record, using `NOW()` as `not_before` if unset |
| `GetQueuedJobs` | Fetches up to `maxNumJobs` queued jobs ready to run by `not_before` |
| `GetFilteredQueuedJobs` | Like `GetQueuedJobs` but optionally filters by job name using `IN` |
| `UpdateJob` | Updates job state, retries, error, and `not_before` by ID |
| `CleanupWorkerJobs` | Deletes old failed/completed jobs older than configurable durations |
| `HasQueuedJobWithArgs` | Deduplication check — queries primary to avoid replica lag |
| `GetJob` | Fetches a single job by ID |

## Usage Example

```go
// Enqueue a new job
job, err := ds.NewJob(ctx, &fleet.Job{
    Name:  "send_email",
    Args:  json.RawMessage(`{"to":"user@example.com"}`),
    State: fleet.JobStateQueued,
})

// Deduplicate before enqueuing
exists, err := ds.HasQueuedJobWithArgs(ctx, "send_email", args)
if !exists {
    ds.NewJob(ctx, job)
}

// Fetch up to 10 ready jobs
jobs, err := ds.GetQueuedJobs(ctx, 10, time.Now().UTC())

// Fetch only specific job types
jobs, err := ds.GetFilteredQueuedJobs(ctx, 10, time.Now().UTC(), []string{"send_email"})

// Mark job as failed, schedule retry
job.State = fleet.JobStateFailure
job.Retries++
ds.UpdateJob(ctx, job.ID, job)

// Prune old records
n, err := ds.CleanupWorkerJobs(ctx, 7*24*time.Hour, 24*time.Hour)
```

## Notes

- Jobs are ordered by `updated_at ASC` to process oldest-first.
- `CleanupWorkerJobs` leverages the `not_before` index rather than `created_at`/`updated_at` for performance.
- `HasQueuedJobWithArgs` forces a primary DB read via `ctxdb.RequirePrimary` to prevent stale replica reads during rapid user interactions.
