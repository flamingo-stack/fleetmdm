MySQL datastore implementation for querying, inserting, and deleting OS-level CVE vulnerability records, with support for CVSS metadata, team filtering, and pagination.

## Key Components

| Function | Description |
|---|---|
| `ListOSVulnerabilitiesByOS` | Fetches all CVEs linked to a specific OS ID from `operating_system_vulnerabilities` |
| `ListVulnsByOsNameAndVersion` | Queries vulnerabilities by OS name/version with optional CVSS metadata, team scoping, and result limiting |
| `listVulnsWithoutCVSS` | Internal helper for lightweight vulnerability queries without CVSS enrichment |
| `InsertOSVulnerabilities` | Batch upserts OS vulnerabilities using `BatchProcessSimple` |
| `InsertOSVulnerability` | Single-record upsert returning whether the row was newly inserted |
| `DeleteOSVulnerabilities` | Bulk deletes specific `(operating_system_id, cve)` pairs |
| `DeleteOutOfDateOSVulnerabilities` | Removes stale vulnerability records older than a given timestamp for a specific source |
| `DeleteOrphanedOSVulnerabilities` | Cleans up vulnerability records whose OS has no associated hosts |
| `ListKernelsByOS` | Retrieves kernel software entries with CVEs and host counts for a given OS version |

## Usage Example

```go
// Fetch all CVEs for a specific OS ID
vulns, err := ds.ListOSVulnerabilitiesByOS(ctx, 42)

// Query vulnerabilities by OS name/version with CVSS data and team scoping
teamID := uint(7)
maxVulns := 50
result, err := ds.ListVulnsByOsNameAndVersion(ctx, "Ubuntu", "22.04", true, &teamID, &maxVulns)
fmt.Println(result.Count, len(result.Vulnerabilities))

// Batch insert new OS vulnerabilities
affected, err := ds.InsertOSVulnerabilities(ctx, vulnSlice, fleet.NVDVulnerabilitySource)

// Remove stale entries older than 24 hours
err = ds.DeleteOutOfDateOSVulnerabilities(ctx, fleet.NVDVulnerabilitySource, time.Now().Add(-24*time.Hour))

// Clean up orphaned records
err = ds.DeleteOrphanedOSVulnerabilities(ctx)
```

> **Note:** `ListVulnsByOsNameAndVersion` unions results from both `operating_system_vulnerabilities` (direct OS matches) and `operating_system_version_vulnerabilities` (Linux kernel-level aggregations), with team filtering applied only to the latter table.
