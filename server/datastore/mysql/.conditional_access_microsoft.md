MySQL datastore implementation for Microsoft Conditional Access (Entra ID) compliance partner integration, managing both the global integration configuration and per-host compliance status records.

## Key Components

| Function | Description |
|---|---|
| `ConditionalAccessMicrosoftCreateIntegration` | Replaces the existing global Microsoft compliance integration with new tenant ID and proxy secret |
| `ConditionalAccessMicrosoftMarkSetupDone` | Marks the global integration's setup as complete |
| `ConditionalAccessMicrosoftGet` | Retrieves the current global Microsoft compliance integration |
| `ConditionalAccessMicrosoftDelete` | Deletes the global integration and all associated host compliance statuses |
| `LoadHostConditionalAccessStatus` | Fetches a host's compliance status, joined with display name and OS version |
| `CreateHostConditionalAccessStatus` | Upserts a host's Entra device ID and UPN, resetting compliance fields on change |
| `SetHostConditionalAccessStatus` | Updates `managed` and `compliant` flags for a specific host |
| `extractWindowsBuildVersion` | Parses the build version (e.g., `10.0.26100.32230`) from a Windows `os_version` string |

## Usage Example

```go
// Create or replace the global Microsoft Conditional Access integration
err := ds.ConditionalAccessMicrosoftCreateIntegration(ctx, "tenant-uuid", "proxy-secret")

// Mark setup as complete after OAuth flow
err = ds.ConditionalAccessMicrosoftMarkSetupDone(ctx)

// Retrieve the integration
integration, err := ds.ConditionalAccessMicrosoftGet(ctx)
// integration.TenantID, integration.SetupDone

// Register a host's Entra identity
err = ds.CreateHostConditionalAccessStatus(ctx, hostID, "entra-device-id", "user@example.com")

// Update compliance result from the proxy
err = ds.SetHostConditionalAccessStatus(ctx, hostID, true /* managed */, true /* compliant */)

// Load full status for display
status, err := ds.LoadHostConditionalAccessStatus(ctx, hostID)
// status.OSVersion is normalized (macOS prefix stripped, Windows reduced to build number)
```

## Notes

- Only **one global integration** is supported at a time; `CreateIntegration` always deletes the existing row first.
- `LoadHostConditionalAccessStatus` strips the `"macOS "` prefix and reduces Windows OS strings to their build number (e.g., `10.0.19045.6456`) for display consistency.
- `CreateHostConditionalAccessStatus` is a read-before-write no-op when the device ID and UPN are unchanged, reducing unnecessary write load.
