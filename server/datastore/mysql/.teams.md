Provides MySQL datastore operations for Fleet team management, including CRUD operations, team lookups, and cascading deletions with multi-tenancy support.

## Key Components

| Function | Description |
|---|---|
| `NewTeam` | Creates a new team with NFC-normalized name, saves enroll secrets, and initializes default software categories |
| `TeamWithExtras` | Fetches a team by ID with full extras (users, host count, secrets, features) |
| `TeamLite` | Returns a lightweight team representation without extras |
| `teamDB` | Core team lookup with OpenFrame multi-tenancy scoping — enforces tenant isolation by rejecting foreign team IDs |
| `DeleteTeam` | Cascading team deletion: clears MDM profiles, labels, policies, and related reference tables |
| `TeamByName` | Looks up a team by NFC-normalized name with extras |
| `TeamByFilename` | Looks up a team by its YAML filename |
| `TeamConflictsWithName` | Checks for name conflicts excluding a specific team ID |
| `enqueueWindowsDeleteCommandsForTeam` | Pre-deletion step that copies Windows MDM profile data before cascade removes definitions |

### Internal Helpers

- `saveTeamSecretsDB` — Persists enroll secrets for a team
- `loadUsersForTeamDB` — Loads team member list with roles
- `loadHostCountForTeamDB` — Counts hosts assigned to a team
- `loadFeaturesForTeamDB` — Loads feature flags from team config
- `loadExtrasForTeamDB` — Orchestrates all extra-data loaders

### Reference Tables

- `teamRefs` — Tables cleared on team deletion (MDM profiles, software configs, etc.)
- `teamLabelsRefs` — Label-related tables requiring pre-deletion cleanup due to `ON DELETE RESTRICT` constraints

## Usage Example

```go
// Create a new team
team, err := ds.NewTeam(ctx, &fleet.Team{
    Name:        "Engineering",
    Description: "Engineering team",
})

// Fetch full team details
team, err := ds.TeamWithExtras(ctx, teamID)

// Lightweight lookup (no extras)
lite, err := ds.TeamLite(ctx, teamID)

// Lookup by name or filename
team, err := ds.TeamByName(ctx, "Engineering")
team, err := ds.TeamByFilename(ctx, "engineering.yml")

// Delete team and all associated data
err := ds.DeleteTeam(ctx, teamID)
```

> **OpenFrame note:** `teamDB` enforces tenant isolation via `fleet.OpenframeTeamID(ctx)` — reads for a team ID that doesn't match the pinned tenant return `NotFound`.
