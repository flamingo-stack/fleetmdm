Handles MySQL persistence for host certificate records, including bulk upserts, MDM managed certificate lifecycle tracking, and pagination-aware listing.

## Key Components

| Export | Description |
|--------|-------------|
| `ListHostCertificates` | Returns paginated certificate records for a given host ID |
| `UpdateHostCertificates` | Upserts incoming certs, reconciles sources, and backfills `host_mdm_managed_certificates` rows |
| `hostCertificateAllowedOrderKeys` | Allowlist preventing arbitrary column injection in ORDER BY clauses |
| `hmmcBackfillGrace` | 4-hour grace window distinguishing in-flight renewals from stuck MDM rows (see issue #44111) |
| `isVerifiedStatus` | Helper that safely dereferences an `MDMDeliveryStatus` pointer and checks for `Verified` |

## Usage Example

```go
// List certificates for a host (paginated)
certs, meta, err := ds.ListHostCertificates(ctx, hostID, fleet.ListOptions{
    Page:    0,
    PerPage: 100,
    OrderKey: "not_valid_after",
})

// Ingest certificates reported by osquery
err = ds.UpdateHostCertificates(ctx, hostID, hostUUID, certs, fleet.HostCertificateOriginOsquery)
```

## Reconciliation Logic

`UpdateHostCertificates` performs a multi-step reconciliation on every call:

1. **Normalize** — SHA1 sums are uppercased for consistent keying
2. **Diff** — Incoming certs are compared against existing DB rows by SHA1 and validity dates; only changed or new records are inserted
3. **Source sync** — Per-cert `(source, username)` tuples are diffed and re-written when they diverge
4. **MDM backfill** — For each `host_mdm_managed_certificates` row without validity dates (stuck past `hmmcBackfillGrace`), the full incoming pool is searched for a matching `fleet-<profile_uuid>` renewal marker
5. **Non-proxied insert** — ACME/non-proxied SCEP flows that never create an `hmmc` row at issuance are seeded here by matching installed profile UUIDs against cert Subject fields

> **Security:** `hostCertificateAllowedOrderKeys` is an explicit allowlist used in all list queries to prevent SQL injection via sort parameters.
