Provides bulk host-to-label membership lookups for MDM profile reconcilers, returning a map of which label IDs each host belongs to from a given set of host and label IDs.

## Key Components

- **`BulkGetHostLabelMemberships`** — Public method on `Datastore`; delegates to the transaction-aware variant using the context reader.
- **`bulkGetHostLabelMembershipsTransaction`** — Internal implementation that accepts any `DBReadTx`, chunking host IDs (5,000/batch) and label IDs (1,000/batch) to avoid exceeding MySQL's prepared-statement parameter limit.
- **`membershipRow`** — Internal struct mapping `host_id` and `label_id` columns from `label_membership`.

## Usage Example

```go
hostIDs := []uint{1, 2, 3, 42}
labelIDs := []uint{10, 20, 30}

memberships, err := ds.BulkGetHostLabelMemberships(ctx, hostIDs, labelIDs)
if err != nil {
    return err
}

// Check if host 42 is a member of label 20
if labels, ok := memberships[42]; ok {
    if _, member := labels[20]; member {
        fmt.Println("host 42 belongs to label 20")
    }
}
```

The return type `map[uint]map[uint]struct{}` maps each host ID to a set of its matching label IDs. Both inputs may be empty — an empty (non-nil) map is returned in that case.

## Notes

- Chunked queries keep total SQL placeholders well under MySQL limits (max ~65,535 parameters per statement).
- Platform-neutral: designed to be reused by Apple, Windows, and Linux MDM reconcilers as they migrate to in-memory reconciliation.
