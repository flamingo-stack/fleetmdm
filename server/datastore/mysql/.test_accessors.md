Test-only accessor shims that expose internal `Datastore` fields and helpers to `mysqltest` package utilities without modifying production code paths.

## Key Components

| Export | Kind | Description |
|---|---|---|
| `CheckAndModifyMysqlConfig` | Function | Wraps the internal `checkAndModifyConfig` validator for use in test setup |
| `TestPrimaryDB` | Method | Returns the primary `*sqlx.DB` connection |
| `TestReplica` | Method | Returns the current replica `fleet.DBReader` |
| `TestSetReplica` | Method | Overrides the replica with a custom `fleet.DBReader` |
| `TestSetReadReplicaConfig` | Method | Overrides the read-replica MySQL config |
| `TestLogger` | Method | Returns the datastore's `*slog.Logger` |
| `TestWriter` | Method | Returns the writer `*sqlx.DB` for a given context |
| `TestReader` | Method | Returns the reader `fleet.DBReader` for a given context |
| `TestEncrypt` | Method | Encrypts bytes using the datastore's server private key |

## Usage Example

```go
// Typical usage inside a mysqltest helper
func setupTestDB(t *testing.T) *mysql.Datastore {
    ds := createDatastore(t)

    // Inspect internal connections
    db := ds.TestPrimaryDB()
    _ = db.Ping()

    // Swap replica for a test double
    ds.TestSetReplica(db)

    // Verify encryption round-trip
    cipher, err := ds.TestEncrypt([]byte("secret"))
    require.NoError(t, err)
    _ = cipher

    return ds
}
```

> **⚠️ Warning:** All exports in this file are **test-only**. They are intentionally not guarded by build tags but carry explicit `// It must not be used from production code.` doc comments. Do not call these from any non-test code path.
