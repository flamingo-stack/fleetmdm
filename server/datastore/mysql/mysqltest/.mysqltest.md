Provides test infrastructure for MySQL-backed Fleet datastore tests, including database setup, dummy/real replica configuration, ABM/MDM fixtures, and activity service helpers.

## Key Components

### Database Setup
- **`connectMySQL`** — Creates a `mysql.Datastore` test client, wiring in mock clock, SQL mode, and optional replica configuration.
- **`setupDummyReplica`** — Spawns a goroutine that replicates changed tables on demand (lock-step via `opts.RunReplication()`), dropping foreign keys and mirroring rows from primary to a suffixed replica DB.
- **`setupRealReplica`** — Configures a real MySQL binary log replica via `CHANGE REPLICATION SOURCE TO`, targeting the `mysql_replica_test` Docker container.

### Config Helpers
- **`fromCommonMysqlConfig`** / **`toCommonMysqlConfig`** — Translate between `common_mysql.MysqlConfig` and `config.MysqlConfig`, keeping test setup decoupled from production config structs.

### Package-level State
- **`databasesToReplicate`** / **`mu`** — Global mutex-protected string tracking which test databases the real replica should follow, accumulated across parallel test runs.

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    opts := &testing_utils.DatastoreTestOptions{
        DummyReplica: true,
    }
    ds := connectMySQL(t, t.Name(), opts)
    defer ds.Close()

    // Force replication of specific tables mid-test
    opts.RunReplication("hosts", "software")

    // Now query replica...
}
```

## Notes

- Import only from test files; this package transitively imports `"testing"`, which must not reach production binaries.
- Set `FLEET_INTEGRATION_TESTS_DISABLE_LOG=1` to suppress datastore log output during test runs.
- Real replica tests require the `mysql_replica_test` Docker Compose service to be running.
