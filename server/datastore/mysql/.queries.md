Provides MySQL datastore implementations for Fleet query CRUD operations, including bulk upsert via `ApplyQueries`, single-record operations (`NewQuery`, `QueryByName`), label association management, and query result cleanup — with OpenFrame multi-tenancy team-pinning hooks throughout.

## Key Components

| Function | Description |
|---|---|
| `ApplyQueries` | Bulk upserts queries (in batches of 50) and discards stale query results; pins queries to the OpenFrame tenant team when active |
| `applyQueriesInTx` | Transactional batch upsert with ID back-population and label association updates |
| `NewQuery` | Inserts a single new query; validates, sets timestamps, pins to tenant team, and saves label associations |
| `QueryByName` | Fetches a query by `{name, team_id}`, scoping to the tenant team in OpenFrame mode |
| `updateQueryLabelsInTx` | Replaces `LabelsIncludeAny`/`LabelsIncludeAll` associations within a transaction, resolving label names to IDs |
| `deleteMultipleQueryResults` | Bulk-deletes rows from `query_results` for given query IDs |
| `queryAllowedOrderKeys` | Allowlist preventing arbitrary column sorting in `ListQueries` (security boundary) |

## Usage Example

```go
// Apply a set of queries via GitOps
err := ds.ApplyQueries(ctx, authorID, []*fleet.Query{
    {
        Name:               "running_processes",
        Query:              "SELECT * FROM processes;",
        Interval:           300,
        AutomationsEnabled: true,
        Logging:            "snapshot",
    },
}, queriesToDiscardResults)

// Create a single new query
q, err := ds.NewQuery(ctx, &fleet.Query{
    Name:            "disk_info",
    Query:           "SELECT * FROM disk_info;",
    ObserverCanRun:  true,
    Platform:        "linux",
})

// Look up a query by name within a team
q, err := ds.QueryByName(ctx, &teamID, "disk_info")
```

> **OpenFrame multi-tenancy:** All write operations automatically pin queries to the process's tenant team (via `fleet.OpenframeTeamID(ctx)`) when the context carries a team binding, preventing cross-tenant data leakage on shared databases.
