Provides MySQL datastore logic for enqueuing and managing setup experience items during host enrollment, handling platform-specific enrollment guards, software installer selection, and VPP app assignment.

## Key Components

### Functions

- **`EnqueueSetupExperienceItems`** — Public entry point to enqueue setup experience items for a newly enrolling host.
- **`ResetSetupExperienceItemsAfterFailure`** — Re-enqueues setup experience items, preserving previously successful steps.
- **`enqueueSetupExperienceItems`** — Core private implementation shared by both public functions. Handles:
  - Platform normalization (`hostPlatform`, `hostPlatformLike`, fleet platform-like)
  - 24-hour enrollment age guard to skip re-enqueuing on fleetd upgrades
  - Windows re-enrollment detection via `mdm_windows_enrollments` (ESP state + recency window)
  - Clearing prior `setup_experience_status_results`
  - Building combined SQL for software installers and VPP apps

### Constants

- **`windowsFreshEnrollmentWindow`** (`5 * time.Minute`) — Grace window for detecting a genuine Windows re-enrollment when `last_enrolled_at` appears stale.

### Platform Handling

| Host Platform | Platform-Like | Fleet Platform-Like |
|---|---|---|
| `darwin` | `darwin` | `darwin` |
| `windows` | `windows` | `windows` |
| `ubuntu` | `debian` | `linux` |
| `arch` | `arch` (fallback) | `linux` |
| `ios` | `ios` (fallback) | `ios` |

Software installer inclusion is gated by fleet platform:

- **Software installers**: all platforms except `ios`/`ipados`
- **VPP apps**: `darwin`, `ios`, `ipados` only

## Usage Example

```go
// Enqueue setup experience items for a newly enrolled macOS host
enqueued, err := ds.EnqueueSetupExperienceItems(
    ctx,
    "darwin",   // hostPlatform
    "darwin",   // hostPlatformLike
    "abc-uuid", // hostUUID
    42,         // teamID
)
if err != nil {
    log.Fatal(err)
}

// Re-enqueue after a failed run (keeps successful steps)
enqueued, err = ds.ResetSetupExperienceItemsAfterFailure(
    ctx,
    "windows",
    "windows",
    "abc-uuid",
    42,
)
```
