Manages MySQL database operations for storing, retrieving, and cleaning up scheduled query result rows in the Fleet MDM datastore.

## Key Components

| Function | Description |
|---|---|
| `OverwriteQueryResultRows` | Atomically replaces all result rows for a host/query pair; rejects payloads exceeding 1,000 rows |
| `QueryResultRows` | Fetches all result rows for a query with team-based host filtering and host metadata join |
| `QueryResultRowsForHost` | Fetches result rows scoped to a specific query and host (includes null-data rows) |
| `ResultCountForQuery` | Counts non-null result rows for a given query across all hosts |
| `ResultCountForQueryAndHost` | Counts non-null result rows for a specific query/host pair |
| `CleanupDiscardedQueryResults` | Removes rows belonging to queries marked with `discard_data = true` |
| `CleanupExpiredQueryResults` | Batched TTL deletion of rows older than a given timestamp (up to 1,000 per call) |
| `CleanupExcessQueryResultRows` | Prunes rows exceeding the per-query cap using windowed ranking; returns per-query counts for Redis counter sync |
| `ListHostReports` | Paginated query report listing for a host with filtering, sorting, and cursor-based pagination |

## Usage Example

```go
// Overwrite result rows for a host/query (called on each osquery report)
rowsAdded, err := ds.OverwriteQueryResultRows(ctx, rows, maxQueryReportRows)

// Fetch all results for a query, filtered by team membership
results, err := ds.QueryResultRows(ctx, queryID, teamFilter)

// Count results for a specific query
count, err := ds.ResultCountForQuery(ctx, queryID)

// Run TTL cleanup (called from cron)
deleted, err := ds.CleanupExpiredQueryResults(ctx, time.Now().Add(-30*24*time.Hour))

// Run excess-row cleanup and get per-query counts for Redis sync
queryCounts, err := ds.CleanupExcessQueryResultRows(ctx, maxQueryReportRows)
```

## Notes

- `OverwriteQueryResultRows` runs inside a retryable transaction; deletes before inserting to avoid duplicates.
- `CleanupExcessQueryResultRows` batches both the cutoff lookup and deletion to avoid large binlogs and MySQL's 65,535-placeholder limit.
- `CleanupExpiredQueryResults` is an OpenFrame extension (`query-results-ttl`) — see [`openframe/docs/query-results-ttl-cleanup.md`](https://github.com/flamingo-stack/fleetmdm/blob/main/openframe/docs/query-results-ttl-cleanup.md).
- `ListHostReports` uses `hostReportAllowedOrderKeys` to restrict sort columns and supports cursor-based pagination.
