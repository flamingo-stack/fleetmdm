Handles Fleet telemetry statistics collection and reporting from the MySQL datastore, determining whether statistics should be sent based on a configurable frequency and assembling a comprehensive payload of instance metrics.

## Key Components

- **`ShouldSendStatistics`** — Core method that checks if the reporting interval has elapsed, generates an anonymous identifier on first run, and builds a `fleet.StatisticsPayload` covering hosts, software, policies, MDM state, and feature flags.
- **`RecordStatisticsSent`** — Updates the `statistics` table timestamp after a successful telemetry send.
- **`CleanupStatistics`** — Resets weekly policy violation day counters via `InitializePolicyViolationDays`.
- **`GetTableRowCounts`** / **`getTableRowCountsViaInformationSchema`** — Returns estimated row counts for all tables using MySQL's `information_schema`.
- **`fleetMaintainedAppsInUseDB`** — Queries which Fleet-maintained app slugs are actively in use, grouped by platform (`darwin` / `windows`).
- **`statistics`** (struct) — Minimal DB model holding the anonymous identifier and timestamps.

## Usage Example

```go
payload, shouldSend, err := ds.ShouldSendStatistics(ctx, 24*time.Hour, fleetConfig)
if err != nil {
    log.Fatal(err)
}
if shouldSend {
    if err := sendTelemetry(payload); err != nil {
        log.Error(err)
    }
    if err := ds.RecordStatisticsSent(ctx); err != nil {
        log.Error(err)
    }
}

// Weekly cleanup (called by cron)
if err := ds.CleanupStatistics(ctx); err != nil {
    log.Error(err)
}
```

The anonymous identifier is generated once and persisted; subsequent calls compare `updated_at` against the provided `frequency` to avoid duplicate submissions.
