MySQL datastore implementation for CRUD and query operations on certificate templates, including team-scoped lookups, batch upserts, and host-specific certificate status retrieval with SCEP challenge decryption.

## Key Components

| Function | Description |
|---|---|
| `GetCertificateTemplateById` | Fetches a single certificate template by ID |
| `GetCertificateTemplatesByIdsAndTeam` | Fetches multiple templates filtered by IDs and team |
| `GetCertificateTemplateByTeamIDAndName` | Looks up a template by team and name |
| `GetCertificateTemplateByIdForHost` | Returns template with host-specific status and decrypted SCEP challenge (only when status is `delivered`) |
| `GetCertificateTemplatesByTeamID` | Paginated listing of templates for a team |
| `CreateCertificateTemplate` | Inserts a new certificate template |
| `DeleteCertificateTemplate` | Deletes a template by ID |
| `BatchUpsertCertificateTemplates` | Upserts multiple templates; returns IDs of modified teams |
| `BatchDeleteCertificateTemplates` | Deletes multiple templates by ID |
| `subjectAlternativeNameForStorage` | Helper that converts blank SAN strings to SQL `NULL` |
| `certificateTemplateAllowedOrderKeys` | Allowlist preventing arbitrary column injection in `ORDER BY` |

## Usage Example

```go
// Create a new certificate template
tmpl, err := ds.CreateCertificateTemplate(ctx, &fleet.CertificateTemplate{
    Name:                   "wifi-cert",
    TeamID:                 42,
    CertificateAuthorityID: 1,
    SubjectName:            "CN=WiFi",
    SubjectAlternativeName: "dns:wifi.example.com",
})

// List templates for a team with pagination
templates, meta, err := ds.GetCertificateTemplatesByTeamID(ctx, 42, fleet.ListOptions{
    Page:            0,
    PerPage:         25,
    IncludeMetadata: true,
})

// Get template with host-specific SCEP challenge
hostTmpl, err := ds.GetCertificateTemplateByIdForHost(ctx, tmpl.ID, "host-uuid-123")
if hostTmpl.Status == fleet.CertificateTemplateDelivered {
    // hostTmpl.SCEPChallenge is populated with the decrypted challenge
}
```
