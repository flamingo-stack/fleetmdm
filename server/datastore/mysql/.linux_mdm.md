Provides MySQL datastore methods for querying and summarizing Linux MDM disk encryption status across hosts.

## Key Components

### Methods

- **`GetLinuxDiskEncryptionSummary`** — Queries the `hosts` and `host_disk_encryption_keys` tables to return a `fleet.MDMLinuxDiskEncryptionSummary` with counts of hosts grouped by encryption status (`verified`, `action_required`, `failed`). Supports optional team filtering via `teamID`.

### Helper Functions

- **`sqlCaseLinuxOSSettingsStatus`** — Returns a SQL `CASE` expression mapping `host_disk_encryption_keys` column values to `fleet.OSSettings*` status constants (`Verified`, `Failed`, `Pending`).
- **`sqlCaseLinuxDiskEncryptionStatus`** — Returns a SQL `CASE` expression mapping the same columns to `fleet.DiskEncryption*` status constants (`Verified`, `Failed`, `ActionRequired`).

### Status Logic (shared across all three)

| Condition | Status |
|---|---|
| `base64_encrypted` is set and `client_error` is empty | Verified |
| `client_error` is non-empty | Failed |
| `base64_encrypted` is NULL or empty with no error | Pending / ActionRequired |

## Usage Example

```go
summary, err := ds.GetLinuxDiskEncryptionSummary(ctx, &teamID)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Verified: %d, Action Required: %d, Failed: %d",
    summary.Verified,
    summary.ActionRequired,
    summary.Failed,
)
```

The helper SQL functions are intended for reuse in broader host-listing queries that need to join OS settings or disk encryption status inline:

```go
query := fmt.Sprintf(`SELECT h.id, %s AS disk_status FROM hosts h
    LEFT JOIN host_disk_encryption_keys hdek ON h.id = hdek.host_id`,
    sqlCaseLinuxDiskEncryptionStatus(),
)
```
