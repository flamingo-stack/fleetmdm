MySQL-backed NanoMDM storage layer that wraps `nanomdm_mysql.MySQLStorage` with Fleet-specific overrides for push certificate management, device lifecycle commands (lock, unlock, wipe), and MDM asset handling.

## Key Components

| Component | Description |
|---|---|
| `NanoMDMStorage` | Struct embedding `*nanomdm_mysql.MySQLStorage` with Fleet datastore, db, and logger |
| `lockConflictError` | Sentinel error type signalling a duplicate pending lock command |
| `pushCertStalenessCheck` | In-memory cache struct tracking push cert hash and last-updated timestamp |
| `NewMDMAppleMDMStorage` | Production constructor wiring Fleet's primary DB into NanoMDM storage |
| `NewTestMDMAppleMDMStorage` | Test constructor accepting configurable async last-seen capacity/interval |
| `RetrievePushCert` | Loads APNS key pair from assets, updates in-memory staleness cache |
| `IsPushCertStale` | Compares stale token to cached hash; re-fetches if cache is older than 5 minutes |
| `StorePushCert` | Disabled — returns error directing callers to use `fleet.Datastore` |
| `GetPendingLockCommand` | Queries for an unacknowledged `DeviceLock` command and its unlock PIN |
| `EnqueueDeviceLockCommand` | Enqueues `DeviceLock` with conflict guard via `SELECT FOR UPDATE` |
| `EnqueueDeviceUnlockCommand` | Enqueues `DeviceUnlock` and upserts `host_mdm_actions` |
| `EnqueueDeviceWipeCommand` | Enqueues `EraseDevice` and upserts `host_mdm_actions` |
| `ExpandEmbeddedSecrets` | Delegates embedded secret expansion to the Fleet datastore |
| `ExpandHostSecrets` | Delegates host-scoped secret expansion to the Fleet datastore |

## Usage Example

```go
// Production setup
storage, err := ds.NewMDMAppleMDMStorage()
if err != nil {
    log.Fatal(err)
}

// Enqueue a device lock with PIN
cmd := &mdm.Command{CommandUUID: "uuid-123"}
err = storage.EnqueueDeviceLockCommand(ctx, host, cmd, "123456")
if isConflict(err) {
    // Handle duplicate lock gracefully
    fmt.Println("lock already pending for host")
}

// Check push cert freshness
stale, err := storage.IsPushCertStale(ctx, "com.apple.topic", currentToken)
if stale {
    cert, token, _ := storage.RetrievePushCert(ctx, "com.apple.topic")
    _ = cert // use refreshed cert
}

// Test setup with custom async flush interval
testStorage, err := ds.NewTestMDMAppleMDMStorage(100, 1*time.Second)
```
