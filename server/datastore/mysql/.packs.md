MySQL datastore implementation for Fleet pack (query pack) CRUD operations, including spec-based apply/get, target management (labels, hosts, teams), and scheduled query association.

## Key Components

| Function | Description |
|---|---|
| `ApplyPackSpecs` | Upserts multiple packs from specs within a retried transaction |
| `applyPackSpecDB` | Core spec apply logic: upserts pack, rebuilds scheduled queries and targets |
| `GetPackSpecs` | Retrieves all non-team packs with their targets and scheduled queries |
| `GetPackSpec` | Retrieves a single pack spec by name |
| `PackByName` | Looks up a pack by name, returning the full pack with targets |
| `NewPack` | Inserts a new pack and sets its targets |
| `SavePack` | Updates an existing pack's metadata and replaces targets |
| `replacePackTargetsDB` | Deletes and re-inserts all pack targets (labels, hosts, teams) |
| `loadPackTargetsDB` | Populates a pack's target ID slices and display metadata |
| `packsAllowedOrderKeys` | Allowlist for safe ORDER BY column names |

## Usage Example

```go
// Apply pack specs (e.g., from a YAML fleet spec file)
specs := []*fleet.PackSpec{
    {
        Name:        "security-pack",
        Description: "Security monitoring queries",
        Platform:    "linux",
        Disabled:    false,
        Queries: []fleet.PackSpecQuery{
            {QueryName: "open_sockets", Interval: 60},
        },
        Targets: fleet.PackSpecTargets{
            Labels: []string{"production"},
            Teams:  []string{"ops"},
        },
    },
}
if err := ds.ApplyPackSpecs(ctx, specs); err != nil {
    log.Fatal(err)
}

// Retrieve a single pack spec by name
spec, err := ds.GetPackSpec(ctx, "security-pack")
if err != nil {
    log.Fatal(err)
}

// Look up a pack by name with full target info
pack, exists, err := ds.PackByName(ctx, "security-pack")
if err != nil || !exists {
    log.Fatal(err)
}
fmt.Printf("Pack targets: %d hosts, %d labels\n", len(pack.HostIDs), len(pack.LabelIDs))
```

> **Note:** `applyPackSpecDB`, `replacePackTargetsDB`, and `loadPackTargetsDB` are internal helpers and not exported. All mutating operations use `withRetryTxx` for deadlock-safe transactions.
