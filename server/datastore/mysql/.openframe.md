MySQL datastore helpers for OpenFrame's shared-database row-level multitenancy. Each per-tenant Fleet process is pinned to a single team via `FLEET_OPENFRAME_TEAM_ID`; these functions scope by-ID operations to that team to prevent cross-tenant data access or mutation.

## Key Components

| Function | Description |
|---|---|
| `filterHostIDsByTeam` | Filters a slice of host IDs to only those belonging to the pinned team |
| `filterPolicyIDsByTeam` | Filters policy IDs to the pinned team's scope |
| `filterQueryIDsByTeam` | Filters query IDs to the pinned team's scope |
| `openframeForeignTeam` | Returns `true` if a caller-supplied team ID differs from the pinned team |
| `openframeScopePolicyHosts` | Verifies policy ownership then filters host IDs for write operations |
| `openframeScopeQueryHosts` | Query analog of `openframeScopePolicyHosts` |
| `EnsureOpenframeTeamID` | Resolves a tenant UUID to a Fleet `team_id`, creating the team (with a seeded enroll secret) if absent |
| `AcquireOpenframeMigrationLock` | Acquires a session-scoped MySQL named lock to serialize concurrent `fleet prepare db` runs across replicas |

## Usage Example

```go
// Resolve (or create) the Fleet team for this tenant at process startup.
teamID, err := ds.EnsureOpenframeTeamID(ctx, os.Getenv("FLEET_OPENFRAME_TENANT_UUID"))
if err != nil {
    log.Fatal(err)
}

// Serialize schema migrations across replicas on the shared DB.
release, err := ds.AcquireOpenframeMigrationLock(ctx, 5*time.Minute)
if err != nil {
    log.Fatal(err)
}
defer release()
runMigrations()

// Fence a host-policy assignment to the calling process's pinned team.
safeHostIDs, err := ds.openframeScopePolicyHosts(ctx, policyID, requestedHostIDs)
if err != nil {
    return err // NotFound if policy belongs to another tenant
}
```

> **Note:** All filter helpers query the primary writer to avoid read-after-write races on lagging replicas.
