MySQL datastore implementation for managing CA (Certificate Authority) configuration assets, providing encrypted CRUD operations against the `ca_config_assets` table.

## Key Components

| Function | Description |
|---|---|
| `GetAllCAConfigAssetsByType` | Fetches all CA config assets of a given type, returning a name-keyed map with decrypted values |
| `SaveCAConfigAssets` | Public entry point for bulk upsert of CA config assets using the write connection |
| `saveCAConfigAssets` | Internal upsert implementation; accepts an `sqlx.ExtContext` for transaction support |
| `GetCAConfigAsset` | Retrieves a single CA config asset by name and type, with decrypted value |
| `DeleteCAConfigAssets` | Removes one or more CA config assets by name using an `IN` clause |

**Encryption:** All asset values are transparently encrypted on write (`encrypt`) and decrypted on read (`decrypt`) using `ds.serverPrivateKey`.

## Usage Example

```go
// Save assets
assets := []fleet.CAConfigAsset{
    {Name: "root-ca-cert", Type: fleet.CAConfigAssetTypeCert, Value: []byte("-----BEGIN CERTIFICATE-----...")},
}
if err := ds.SaveCAConfigAssets(ctx, assets); err != nil {
    return err
}

// Retrieve all assets of a type
assetMap, err := ds.GetAllCAConfigAssetsByType(ctx, fleet.CAConfigAssetTypeCert)
if err != nil {
    return err
}
cert := assetMap["root-ca-cert"]

// Retrieve a single asset
asset, err := ds.GetCAConfigAsset(ctx, "root-ca-cert", fleet.CAConfigAssetTypeCert)

// Delete assets
err = ds.DeleteCAConfigAssets(ctx, []string{"root-ca-cert"})
```

## Notes

- Upserts use `ON DUPLICATE KEY UPDATE`, keyed on `name`.
- `notFound` errors are returned when no rows match, enabling callers to distinguish missing vs. failed lookups.
