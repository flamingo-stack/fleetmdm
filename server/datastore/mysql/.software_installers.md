Provides MySQL datastore operations for managing software installer lifecycle in Fleet MDM, including install scheduling, detail retrieval, and installer record creation with deduplication and label/script content management.

## Key Components

- **`ListPendingSoftwareInstalls`** / **`ListReadyToExecuteSoftwareInstalls`** — Returns execution IDs for upcoming software installs on a host, optionally filtered to only activated (ready-to-run) entries.
- **`GetSoftwareInstallDetails`** — Fetches full install details (scripts, pre-install query, self-service flag) for a given execution ID, expanding embedded secrets and setting retry limits for setup-experience installs.
- **`MatchOrCreateSoftwareInstaller`** — Idempotently creates or matches a software installer record, handling IPA (in-house app) branching, content-hash deduplication for script packages, script content ID resolution, and team-scoped uniqueness enforcement.
- **`checkVPPAppExistsForTitleIdentifier`** — Checks whether a VPP app matching a given bundle identifier and platform already exists for a team.
- **`listUpcomingSoftwareInstalls`** (internal) — Shared query backing the two list functions, ordering results by activation state, priority, and creation time.

## Usage Example

```go
// List installs ready to execute on a host
execIDs, err := ds.ListReadyToExecuteSoftwareInstalls(ctx, hostID)

// Fetch details for a specific execution
details, err := ds.GetSoftwareInstallDetails(ctx, execIDs[0])
fmt.Println(details.InstallScript, details.MaxRetries)

// Create or match an installer record
installerID, titleID, err := ds.MatchOrCreateSoftwareInstaller(ctx, &fleet.UploadSoftwareInstallerPayload{
    TeamID:          &teamID,
    Title:           "My App",
    Extension:       "pkg",
    StorageID:       "sha256:abc123",
    InstallScript:   "#!/bin/sh\ninstaller ...",
    UninstallScript: "#!/bin/sh\nrm ...",
    ValidatedLabels: &fleet.LabelIdentsWithScope{},
})
```

> **Note:** `setupExperienceSoftwareInstallsRetries` (value `2`) caps retry attempts at 3 total (1 initial + 2 retries) for installs triggered during device setup experience.
