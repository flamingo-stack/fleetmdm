MySQL datastore implementation for Apple MDM configuration profile management, handling CRUD operations, scope conflict validation, DEP device enrollment, and host MDM command queuing.

## Key Components

### Profile Management
- `NewMDMAppleConfigProfile` — Creates a new Apple MDM config profile with label associations, variable bindings, and duplicate detection
- `ListMDMAppleConfigProfiles` — Lists config profiles for a given team
- `VerifyAppleConfigProfileScopesDoNotConflict` — Validates that profiles with the same identifier don't have conflicting `PayloadScope` values across teams
- `verifyAppleConfigProfileScopesDoNotConflictDB` — Internal DB-level scope conflict checker with backward-compatibility logic for pre-User Channel profiles

### Error Formatting
- `formatErrorDuplicateConfigProfile` — Maps MySQL duplicate key errors to structured `existsError` types for config profiles
- `formatErrorDuplicateDeclaration` — Same for Apple DDM declarations

### Host MDM State
- `isAppleHostConnectedToFleetMDM` — Checks if a host is actively enrolled in Fleet MDM via nano enrollment records

### Constants & Variables
- `addHostMDMCommandsBatchSize` — Configurable batch size (default `10000`) for bulk MDM command insertion

## Usage Example

```go
// Create a new Apple MDM config profile
profile, err := ds.NewMDMAppleConfigProfile(ctx, fleet.MDMAppleConfigProfile{
    Name:         "Wi-Fi Settings",
    Identifier:   "com.example.wifi",
    Scope:        fleet.PayloadScopeSystem,
    Mobileconfig: mobileconfigBytes,
    TeamID:       &teamID,
}, []fleet.FleetVarName{})

// Validate no scope conflicts before batch upload
err = ds.VerifyAppleConfigProfileScopesDoNotConflict(ctx, profiles)
if err != nil {
    // Returns fleet.BadRequestError with a learn-more URL
}

// Check host MDM enrollment status
connected, err := isAppleHostConnectedToFleetMDM(ctx, db, host)
```
