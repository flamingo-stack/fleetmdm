Defines functional options for configuring a MySQL datastore connection, using the Option pattern to allow flexible, composable database setup.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DBOption` | Type | Function type `func(o *common_mysql.DBOptions) error` used to pass optional config to a DB connection |
| `Logger` | `DBOption` | Attaches an `slog.Logger` to the datastore |
| `WithInterceptor` | `DBOption` | Adds a `sqlmw.Interceptor` for SQL middleware hooks |
| `Replica` | `DBOption` | Configures a MySQL read replica using `*config.MysqlConfig` |
| `LimitAttempts` | `DBOption` | Sets max connection retry attempts (default: `15`) |
| `TracingEnabled` | `DBOption` | Enables tracing via a `*config.LoggingConfig` |
| `WithFleetConfig` | `DBOption` | Applies Fleet-wide config values (e.g. `MinLastOpenedAtDiff`, `PrivateKey`) |
| `SQLMode` | `DBOption` | Sets a custom MySQL `sql_mode` string |

## Usage Example

```go
db, err := mysql.New(
    cfg,
    mysql.Logger(slog.Default()),
    mysql.LimitAttempts(10),
    mysql.Replica(&config.MysqlConfig{
        Address:  "replica.db.internal:3306",
        Database: "fleet",
    }),
    mysql.WithFleetConfig(&fleetConfig),
    mysql.SQLMode("STRICT_TRANS_TABLES"),
)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- `defaultMaxAttempts` is `15`; override with `LimitAttempts`
- `defaultMinLastOpenedAtDiff` is `1 hour`; overridden via `WithFleetConfig` from `FleetConfig.Osquery.MinSoftwareLastOpenedAtDiff`
- All options are composable and applied variadic-style to `common_mysql.DBOptions`
