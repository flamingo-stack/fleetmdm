SCEP-based host identity certificate data access layer, providing MySQL queries for retrieving and updating host identity and MDM SCEP certificates.

## Key Components

| Function | Description |
|---|---|
| `GetHostIdentityCertBySerialNumber` | Fetches a non-expired, non-revoked host identity certificate by serial number |
| `UpdateHostIdentityCertHostIDBySerial` | Associates a host ID with an existing certificate record via serial number |
| `GetHostIdentityCertByName` | Retrieves a valid host identity certificate by its name field |
| `GetMDMSCEPCertBySerial` | Resolves an MDM SCEP certificate serial to a device UUID via NanoMDM's cert-auth association table |

## Usage Example

```go
// Retrieve a host identity certificate by serial number
cert, err := ds.GetHostIdentityCertBySerialNumber(ctx, 12345678)
if err != nil {
    // handles notFound or DB errors
}

// Associate a host with a certificate
err = ds.UpdateHostIdentityCertHostIDBySerial(ctx, 12345678, hostID)

// Resolve an MDM SCEP certificate serial to a device UUID
deviceUUID, err := ds.GetMDMSCEPCertBySerial(ctx, 98765432)
```

## Notes

- All queries filter on `not_valid_after > NOW()` and `revoked = 0`, ensuring only active certificates are returned.
- `GetMDMSCEPCertBySerial` performs a two-step lookup: serial → PEM → SHA-256 hash → `nano_cert_auth_associations`, mirroring NanoMDM's `HashCert` logic (DER-encoded `cert.Raw`, not the PEM string).
- `UpdateHostIdentityCertHostIDBySerial` uses `WithRetryTxx` for transactional safety with automatic retries.
- Core host identity business logic lives in `ee/server/service/hostidentity`.
