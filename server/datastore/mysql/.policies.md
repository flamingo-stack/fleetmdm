Provides MySQL datastore implementations for Fleet policy management, including CRUD operations for global/team policies, host-policy assignments, label scoping, and policy membership lifecycle management.

## Key Components

| Function / Type | Description |
|---|---|
| `NewGlobalPolicy` | Creates a global (or OpenFrame tenant-scoped) policy, redirecting to team policy on multi-tenant deployments |
| `newGlobalPolicy` | Internal helper that inserts the policy row, sets label scopes, and returns the hydrated policy |
| `updatePolicyLabelsTx` | Replaces all `policy_labels` rows for a policy across four scopes: `include_any`, `include_all`, `exclude_any`, `exclude_all` |
| `AddPolicyHosts` / `RemovePolicyHosts` / `ReplacePolicyHosts` | Manage the `policy_hosts` assignment table with multi-tenant host filtering |
| `ListPolicyHosts` | Paginates over hosts assigned to a policy with allowlisted sort keys |
| `policyAllowedOrderKeys` | Allowlist of safe `ORDER BY` columns for `ListTeamPolicies`, preventing information-disclosure via arbitrary column injection |
| `policyMembershipDeleteBatchSize` | Configurable batch size (default 500) for bulk `policy_membership` cleanup; overridable in tests |
| `policyCleanupArgs` | Struct carrying arguments for the `cleanupPolicy` helper |

## Usage Example

```go
// Create a global policy (auto-redirected to team scope in OpenFrame)
policy, err := ds.NewGlobalPolicy(ctx, &authorID, fleet.PolicyPayload{
    Name:        "Disk Encryption Enabled",
    Query:       "SELECT 1 FROM disk_encryption WHERE encrypted = 1;",
    Description: "Ensures FileVault/BitLocker is active",
    Platform:    "darwin",
    Critical:    true,
})

// Assign specific hosts to a policy
added, err := ds.AddPolicyHosts(ctx, policy.ID, []uint{42, 99, 137})

// List hosts assigned to a policy with pagination
hosts, meta, err := ds.ListPolicyHosts(ctx, policy.ID, fleet.ListOptions{
    PerPage:         25,
    IncludeMetadata: true,
    OrderKey:        "hostname",
})
```

## Notes

- All order-key parameters are validated against `policyAllowedOrderKeys` / `policyHostsAllowedOrderKeys` allowlists to prevent SQL injection via sort columns.
- OpenFrame multi-tenancy hooks (`openframeScopePolicyHosts`, `OpenframeTeamID`) silently filter out cross-tenant resources; they are no-ops when the process is not pinned to a team.
- Policy names are NFC-normalised before insert to ensure Unicode equivalence across clients.
