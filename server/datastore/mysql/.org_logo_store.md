MySQL-backed implementation of the `fleet.OrgLogoStore` interface, providing CRUD operations for organization logos stored in the `org_logo` database table.

## Key Components

- **`orgLogoStore`** — Struct wrapping a `*Datastore` reference that implements `fleet.OrgLogoStore`.
- **`NewOrgLogoStore`** — Constructor method on `*Datastore` that returns an `OrgLogoStore` instance.
- **`Put`** — Upserts a logo binary for a given `OrgLogoMode` using `INSERT ... ON DUPLICATE KEY UPDATE`.
- **`Get`** — Retrieves logo binary data by mode, returning an `io.ReadCloser`, byte length, and a `notFound` error if absent.
- **`Delete`** — Removes a logo record by mode from the `org_logo` table.
- **`Exists`** — Checks whether a logo record exists for a given mode without fetching the binary data.

## Usage Example

```go
// Initialize via the Datastore
store := ds.NewOrgLogoStore()

// Store a logo
f, _ := os.Open("logo.png")
defer f.Close()
err := store.Put(ctx, fleet.OrgLogoModeLight, f)

// Check existence before retrieval
exists, err := store.Exists(ctx, fleet.OrgLogoModeLight)
if exists {
    rc, size, err := store.Get(ctx, fleet.OrgLogoModeLight)
    defer rc.Close()
    // stream logo data (size bytes)
}

// Remove a logo
err = store.Delete(ctx, fleet.OrgLogoModeDark)
```

> Reads use the replica reader (`ds.reader`) while writes use the primary writer (`ds.writer`), following the datastore's read/write separation pattern.
