MySQL datastore methods for managing the relationship between hosts and certificate templates, supporting MDM certificate lifecycle operations (install, remove, retry) for Android and other platforms.

## Key Components

| Function | Description |
|---|---|
| `ListAndroidHostUUIDsWithDeliverableCertificateTemplates` | Returns paginated host UUIDs that have pending certificate templates not yet delivered |
| `ListCertificateTemplatesForHosts` | Fetches all certificate templates for given hosts, including removal entries from previous team assignments |
| `GetCertificateTemplateForHost` | Retrieves a single certificate template record for a specific host and template ID |
| `GetHostCertificateTemplateRecord` | Fetches the raw `host_certificate_templates` row without requiring the parent template to exist (used for orphaned record updates) |
| `GetCertificateTemplateStatusesByNameForHosts` | Batch-queries install-only certificate statuses keyed by `host_uuid → template_name → status` |
| `RetryHostCertificateTemplate` | Resets a failed certificate to pending, increments `retry_count`, deletes stale challenges, and clears cert fields |
| `BulkInsertHostCertificateTemplates` | Batch-inserts multiple `host_certificate_templates` rows in a single statement |
| `DeleteHostCertificateTemplates` | Deletes records by `(host_uuid, certificate_template_id)` tuple pairs |

## Usage Example

```go
// Find Android hosts needing certificate delivery
uuids, err := ds.ListAndroidHostUUIDsWithDeliverableCertificateTemplates(ctx, 0, 100)

// Load all relevant templates (install + pending removals)
templates, err := ds.ListCertificateTemplatesForHosts(ctx, uuids)

// Bulk-enqueue install records
err = ds.BulkInsertHostCertificateTemplates(ctx, hostCertTemplates)

// Retry a failed certificate install
err = ds.RetryHostCertificateTemplate(ctx, hostUUID, templateID, "SCEP error: timeout")

// Check per-host template statuses by name
statuses, err := ds.GetCertificateTemplateStatusesByNameForHosts(ctx, uuids)
// statuses["host-uuid"]["My SCEP Template"] == fleet.CertificateTemplatePending
```

## Notes

- Team membership is resolved via `hosts.team_id = certificate_templates.team_id` with a fallback for `team_id = 0` (no team).
- `ListCertificateTemplatesForHosts` uses a `UNION` to include removal entries that may reference templates from a prior team after a host transfer.
- `GetCertificateTemplateStatusesByNameForHosts` excludes `pending-remove` rows to ensure deterministic name-to-status mapping.
- `RetryHostCertificateTemplate` runs inside a transaction, deleting associated challenge rows before resetting the record.
