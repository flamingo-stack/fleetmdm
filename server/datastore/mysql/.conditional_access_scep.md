MySQL datastore implementation for managing Conditional Access SCEP (Simple Certificate Enrollment Protocol) certificates, providing certificate lookup, rate limiting support, and automatic revocation of superseded certificates.

## Key Components

| Function | Description |
|---|---|
| `GetConditionalAccessCertHostIDBySerialNumber` | Looks up a host ID by certificate serial number, filtering for valid (non-revoked, non-expired) certificates |
| `GetConditionalAccessCertCreatedAtByHostID` | Retrieves the creation timestamp of the most recent certificate for a given host, used for rate limiting |
| `RevokeOldConditionalAccessCerts` | Batch-revokes superseded certificates while respecting a grace period to prevent authentication failures during rotation |

## Usage Example

```go
// Authenticate a device by certificate serial number
hostID, err := ds.GetConditionalAccessCertHostIDBySerialNumber(ctx, serialNumber)
if err != nil {
    // handle notFound or other errors
}

// Check if the host recently received a certificate (rate limiting)
createdAt, err := ds.GetConditionalAccessCertCreatedAtByHostID(ctx, hostID)
if err != nil {
    // handle notFound or other errors
}
if time.Since(*createdAt) < minRenewInterval {
    // reject renewal request
}

// Periodically clean up superseded certificates with a 5-minute grace period
gracePeriod := 5 * time.Minute
revoked, err := ds.RevokeOldConditionalAccessCerts(ctx, gracePeriod)
if err != nil {
    // handle error
}
log.Printf("Revoked %d old certificates", revoked)
```

## Notes

- All reads use `ds.reader(ctx)` for replica-friendly query routing; writes use `ds.writer(ctx)`.
- `RevokeOldConditionalAccessCerts` uses a self-join UPDATE strategy: it identifies the highest serial per host that predates the grace period, then revokes all older serials for that host.
- A `notFound` error is returned when no rows match, allowing callers to distinguish missing records from database errors.
