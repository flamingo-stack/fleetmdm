MySQL-backed SCEP (Simple Certificate Enrollment Protocol) certificate depot implementation, providing CA key retrieval, serial number allocation, and certificate storage for Fleet MDM's device enrollment workflow.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SCEPDepot` | struct | MySQL-backed depot implementing `depot.Depot`; holds a `*sql.DB` and `fleet.Datastore` |
| `newSCEPDepot` | func | Constructor that pings the database and returns a validated `*SCEPDepot` |
| `CA` | method | Fetches the CA certificate and RSA private key from the asset store |
| `Serial` | method | Inserts a row into `identity_serials` and returns the auto-increment ID as a `*big.Int` |
| `HasCN` | method | Checks `identity_certificates` for the existence of a certificate by Common Name |
| `Put` | method | Persists a DER-encoded certificate as PEM into `identity_certificates` |

## Usage Example

```go
db, err := sql.Open("mysql", dsn)
if err != nil {
    log.Fatal(err)
}

depot, err := mysql.newSCEPDepot(db, datastore)
if err != nil {
    log.Fatal(err)
}

// Retrieve the CA keypair for signing
certs, privateKey, err := depot.CA(nil)

// Allocate a unique serial number for a new certificate
serial, err := depot.Serial()

// Check if a device certificate already exists
exists, err := depot.HasCN("device-cn", 0, nil, false)

// Store a newly issued certificate
err = depot.Put("device-cn", issuedCert)
```

## Notes

- `HasCN` has two unimplemented parameters (`allowTime`, `revokeOldCertificate`) marked with TODOs for future renewal/revocation logic.
- `CA` lacks a context parameter due to upstream `nano` interface constraints; it uses `context.Background()` internally.
- If `crt.Subject.CommonName` is empty in `Put`, the certificate is stored under its SHA-256 hex fingerprint.
