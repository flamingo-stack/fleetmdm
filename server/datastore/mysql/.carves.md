MySQL datastore implementation for osquery file carving operations, providing CRUD operations for carve metadata and block data storage.

## Key Components

| Function/Method | Description |
|---|---|
| `upsertCarveDB` | Internal helper that inserts a new carve metadata record into `carve_metadata` |
| `NewCarve` | Creates a new carve session, returning the metadata with the assigned database ID |
| `UpdateCarve` / `updateCarveDB` | Updates mutable carve fields: `max_block`, `expired`, and `error` |
| `CleanupCarves` | Expires carves older than 24 hours in batches of 50,000, deleting their block data |
| `Carve` | Retrieves carve metadata by numeric ID |
| `CarveBySessionId` | Retrieves carve metadata by osquery session ID string |
| `CarveByName` | Retrieves carve metadata by carve name |
| `ListCarves` | Lists carves with optional filtering (excluding expired) and sorting via `carvesAllowedOrderKeys` |
| `NewBlock` | Inserts a carve data block and updates `max_block` on the parent metadata if needed |
| `GetBlock` | Fetches raw block data by metadata ID and block ID |

## Usage Example

```go
// Create a new carve session
meta, err := ds.NewCarve(ctx, &fleet.CarveMetadata{
    HostId:     42,
    CreatedAt:  time.Now(),
    Name:       "carve_2024_01_01",
    BlockCount: 10,
    BlockSize:  1024 * 1024,
    CarveSize:  10 * 1024 * 1024,
    CarveId:    "abc123",
    RequestId:  "req-456",
    SessionId:  "sess-789",
})

// Store an incoming block
err = ds.NewBlock(ctx, meta, 0, blockData)

// Retrieve a block for reassembly
data, err := ds.GetBlock(ctx, meta, 0)

// Expire stale carves
count, err := ds.CleanupCarves(ctx, time.Now())
```

## Notes

- Only `max_block`, `expired`, and `error` are updatable after creation.
- `CleanupCarves` runs inside a retryable transaction and processes up to 50,000 carves per call.
- The `carvesAllowedOrderKeys` allowlist prevents SQL injection in list ordering.
