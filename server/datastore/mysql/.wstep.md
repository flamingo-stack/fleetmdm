Implements MySQL datastore operations for MS-WSTEP certificate management as part of the MS-MDE2 (Microsoft Mobile Device Enrollment) protocol. Satisfies the `microsoft_mdm.CertStore` interface.

## Key Components

| Function | Description |
|---|---|
| `WSTEPStoreCertificate` | Persists an x509 certificate to `wstep_certificates`, using SHA-256 hash as name fallback when `CommonName` is empty |
| `WSTEPNewSerial` | Allocates a monotonically increasing serial number via auto-increment insert into `wstep_serials` |
| `WSTEPAssociateCertHash` | Upserts a device UUID ↔ certificate SHA-256 hash mapping in `wstep_cert_auth_associations` |

## Usage Example

```go
// Store a new device certificate
err := ds.WSTEPStoreCertificate(ctx, "device-hostname", cert)
if err != nil {
    return fmt.Errorf("storing wstep cert: %w", err)
}

// Allocate a serial number for certificate signing
serial, err := ds.WSTEPNewSerial(ctx)
if err != nil {
    return fmt.Errorf("allocating serial: %w", err)
}

// Link the device UUID to its certificate fingerprint
err = ds.WSTEPAssociateCertHash(ctx, deviceUUID, certHash)
if err != nil {
    return fmt.Errorf("associating cert hash: %w", err)
}
```

## Notes

- Serial numbers must fit within `int64`; certificates with oversized serials are rejected.
- `WSTEPAssociateCertHash` uppercases the hash before storage and uses `ON DUPLICATE KEY UPDATE` for idempotent upserts.
- The `CertStore` interface conformance is enforced at compile time via the blank identifier assertion: `var _ microsoft_mdm.CertStore = (*Datastore)(nil)`.
