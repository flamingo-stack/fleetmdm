Manages CRUD operations and secure expansion of secret variables stored in MySQL, including AES encryption/decryption, usage-checking before deletion, and embedded-secret substitution in scripts and MDM profiles.

## Key Components

| Function | Description |
|---|---|
| `UpsertSecretVariables` | Bulk insert/update secret variables, comparing decrypted values to avoid spurious `updated_at` changes |
| `CreateSecretVariable` | Insert a single secret variable, returning its new ID; rejects duplicates |
| `GetSecretVariables` | Fetch and decrypt named secret variables by name |
| `ListSecretVariables` | Paginated listing of secret identifiers (ID, name, updated_at) with Unicode-safe search; intentionally excludes the `value` column from sort options to prevent information disclosure |
| `DeleteSecretVariable` | Transactionally checks all consuming entities (scripts, Apple profiles, Apple declarations, Windows profiles) before deleting; returns `SecretUsedError` if referenced |
| `ExpandEmbeddedSecrets` | Replaces `$FLEET_SECRET_<name>` placeholders in a document string with their decrypted values |
| `expandEmbeddedSecrets` | Internal helper returning expanded document plus the resolved `[]fleet.SecretVariable` slice |
| `secretVariableAllowedOrderKeys` | Allowlist restricting sortable columns to `name`, `id`, and `updated_at`; `value` is excluded for security |

## Usage Example

```go
// Upsert secrets
err := ds.UpsertSecretVariables(ctx, []fleet.SecretVariable{
    {Name: "DB_PASSWORD", Value: "s3cr3t"},
    {Name: "API_TOKEN",   Value: "tok_abc123"},
})

// Fetch and decrypt by name
secrets, err := ds.GetSecretVariables(ctx, []string{"DB_PASSWORD"})
fmt.Println(secrets[0].Value) // "s3cr3t"

// Expand placeholders inside a script body
expanded, err := ds.ExpandEmbeddedSecrets(ctx,
    "echo $FLEET_SECRET_DB_PASSWORD")

// Delete (fails with SecretUsedError if referenced by any profile/script)
name, err := ds.DeleteSecretVariable(ctx, 42)
```

> **Security note:** Values are AES-encrypted with a server private key before persistence. The `value` column is never returned by `ListSecretVariables` and is excluded from allowed sort keys to prevent timing-based information disclosure.
