Provides utility functions for creating pointers from primitive and common Go types, useful for working with APIs and structs that require pointer fields.

## Key Components

| Function | Description |
|---|---|
| `String(x string) *string` | Returns a pointer to a string value *(deprecated)* |
| `Int(x int) *int` | Returns a pointer to an int value *(deprecated)* |
| `Uint(x uint) *uint` | Returns a pointer to a uint value *(deprecated)* |
| `UintOrNilIfZero(x uint) *uint` | Returns `nil` if zero, otherwise a pointer to the uint |
| `Bool(x bool) *bool` | Returns a pointer to a bool value *(deprecated)* |
| `BoolPtr(x bool) **bool` | Returns a double pointer to a bool *(deprecated)* |
| `StringPtr(x string) **string` | Returns a double pointer to a string *(deprecated)* |
| `Time(x time.Time) *time.Time` | Returns a pointer to a `time.Time` value *(deprecated)* |
| `Float64(x float64) *float64` | Returns a pointer to a float64 *(deprecated)* |
| `Int64(x int64) *int64` | Returns a pointer to an int64 *(deprecated)* |
| `Duration(x time.Duration) *time.Duration` | Returns a pointer to a `time.Duration` *(deprecated)* |
| `RawMessage(x json.RawMessage) *json.RawMessage` | Returns a pointer to a `json.RawMessage` *(deprecated)* |
| `Equal[T comparable](a, b *T) bool` | Returns `true` if both pointers are nil or point to equal values |
| `ValOrZero[T any](x *T) T` | Returns the dereferenced value or the zero value if nil |

> **Note:** Most pointer-creation helpers are deprecated in favor of Go's built-in `new` keyword.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/ptr"

// Create simple pointers (prefer `new` for new code)
s := ptr.String("hello")       // *string
b := ptr.Bool(true)            // *bool
n := ptr.Int(42)               // *int

// Safely handle optional uint — returns nil instead of pointer to zero
teamID := ptr.UintOrNilIfZero(0)   // nil
teamID  = ptr.UintOrNilIfZero(7)   // *uint(7)

// Compare two nullable values
a, b := ptr.Int(1), ptr.Int(1)
ptr.Equal(a, b) // true

// Safely dereference a potentially nil pointer
var maybeStr *string
val := ptr.ValOrZero(maybeStr) // returns ""
```
