Provides build-time version metadata for the Fleet application, exposing version details set via `ldflags` at compile time.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Info` | struct | Holds version fields: `Version`, `Branch`, `Revision`, `GoVersion`, `BuildDate`, `BuildUser` |
| `Version()` | func | Returns the populated `Info` struct |
| `Print()` | func | Prints a short `<appName> version <version>` summary to stdout |
| `PrintFull()` | func | Prints all version fields to stdout in a tabbed format |
| `Handler()` | func | Returns an `http.Handler` that serves version info as indented JSON |

## Usage Example

**Set values at build time:**

```bash
go build -ldflags "\
  -X github.com/fleetdm/fleet/v4/server/version.version=1.2.3 \
  -X github.com/fleetdm/fleet/v4/server/version.branch=main \
  -X github.com/fleetdm/fleet/v4/server/version.buildDate=2024-01-15 \
  -X github.com/fleetdm/fleet/v4/server/version.appName=fleet"
```

**Access version info in code:**

```go
import "github.com/flamingo-stack/fleetmdm/server/version"

// Retrieve structured info
info := version.Version()
fmt.Println(info.Version) // "1.2.3"

// Print short summary
version.Print() // fleet version 1.2.3

// Print full details
version.PrintFull()

// Register HTTP endpoint
mux.Handle("/version", version.Handler())
```

**HTTP response from `Handler()`:**

```json
{
  "version": "1.2.3",
  "branch": "main",
  "revision": "abc1234",
  "go_version": "go1.22.0",
  "build_date": "2024-01-15",
  "build_user": "ci-bot"
}
```

> All package-level variables default to `"unknown"` if not set via `ldflags`. `GoVersion` defaults to the runtime value from `runtime.Version()`.
