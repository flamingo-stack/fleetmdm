Shell word-splitting utility based on `/bin/sh` rules, supporting backslash-escapes, single-quoted, and double-quoted strings.

## Key Components

**Errors**
| Error | Description |
|---|---|
| `UnterminatedSingleQuoteError` | Input ends inside a single-quoted string |
| `UnterminatedDoubleQuoteError` | Input ends inside a double-quoted string |
| `UnterminatedEscapeError` | Input ends on a backslash escape |

**Functions**
- `Split(input string) ([]string, error)` — Public entry point. Tokenizes a shell-style string into words, skipping whitespace (`space`, `\n`, `\t`) and handling all three quoting mechanisms.
- `splitWord(input string, buf *bytes.Buffer) (string, string, error)` — Internal state machine that parses a single word from the input, advancing through `raw`, `escape`, `single`, and `double` labeled goto-states.

## Usage Example

```go
package main

import (
    "fmt"
    "shellquote"
)

func main() {
    words, err := shellquote.Split(`echo "hello world" 'it'\''s fine' foo\ bar`)
    if err != nil {
        panic(err)
    }
    fmt.Println(words)
    // Output: [echo hello world it's fine foo bar]

    // Error case: unterminated quote
    _, err = shellquote.Split(`echo "unterminated`)
    if err == shellquote.UnterminatedDoubleQuoteError {
        fmt.Println("caught unterminated double quote")
    }
}
```

## Notes

- Does **not** support `$"..."` quoting, brace/shell/pathname expansion.
- Inside double quotes, only `$`, `` ` ``, `"`, `\n`, and `\` are treated as escape sequences — matching bash behavior.
- Backslash-escaped newlines are silently elided from output in both raw and double-quoted contexts.
