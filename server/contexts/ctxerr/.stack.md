Captures and formats a Go program's call stack as a slice of human-readable strings, used internally by the `ctxerr` package for error context enrichment.

## Key Components

- **`stack`** — A type alias over `[]uintptr` that holds raw program counters for a captured stack trace.
- **`newStack(skip int) stack`** — Captures up to 10 stack frames at call time. The `skip` parameter controls how many innermost frames to omit (e.g., skip=0 includes `newStack` itself).
- **`stack.List() []string`** — Resolves raw program counters into formatted strings using `runtime.CallersFrames`, returning entries in the form `package.Function (file.go:line)`.
- **`stackTracer`** — Internal interface satisfied by `stack`, enabling polymorphic stack access elsewhere in the package.

## Usage Example

```go
// Capture a stack trace, skipping 1 frame (the immediate caller)
s := newStack(1)

// Format and print each frame
for _, frame := range s.List() {
    fmt.Println(frame)
}

// Example output:
// github.com/org/repo/pkg.SomeFunction (myfile.go:42)
// github.com/org/repo/pkg.CallerFunction (other.go:17)
// main.main (main.go:10)
```

> `maxDepth` is set to `10`, limiting stack capture depth to keep error payloads lean.

## Notes

- `runtime.Callers` is called with `skip+2` to account for `newStack` and `runtime.Callers` itself, ensuring the captured trace starts at the true call site.
- Only the base filename (via `filepath.Base`) is included in each frame string, not the full path, keeping output readable.
