Provides context-aware error wrapping, stack trace capture, and multi-backend telemetry reporting (OpenTelemetry, Elastic APM, Sentry) for Fleet server errors.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FleetError` | struct | Core error type carrying message, stack trace, cause, and JSON metadata |
| `New` / `NewWithData` | func | Create new errors with optional metadata |
| `Wrap` / `Wrapf` / `WrapWithData` | func | Wrap existing errors with additional context |
| `Errorf` | func | Create formatted errors |
| `Handle` | func | Top-level error handler: stores, deduplicates, and reports to telemetry backends |
| `MarshalJSON` | func | Serialize full error chain to JSON in chronological order |
| `Cause` / `FleetCause` | func | Traverse error chain to root or root-most `FleetError` |
| `Handler` | interface | Backend for storing and retrieving deduplicated errors |
| `NewContext` / `FromContext` | func | Attach/retrieve a `Handler` via `context.Context` |
| `StoredError` | struct | Redis deserialization target: error chain + occurrence count |

## Usage Example

```go
// At the point of failure (e.g., a service layer):
func fetchUser(ctx context.Context, id int) (*User, error) {
    user, err := db.GetUser(id)
    if err != nil {
        return nil, ctxerr.Wrap(ctx, err, "fetching user")
    }
    return user, nil
}

// At the top of the call stack (e.g., HTTP handler):
func handler(ctx context.Context, w http.ResponseWriter, r *http.Request) {
    user, err := fetchUser(ctx, 42)
    if err != nil {
        ctxerr.Handle(ctx, err) // stores, deduplicates, and reports to APM/Sentry
        http.Error(w, "internal error", http.StatusInternalServerError)
        return
    }
    // ...
}

// Serialize the error chain for debugging:
raw, _ := ctxerr.MarshalJSON(err)
fmt.Println(string(raw))
```

## Notes

- Stack traces are captured at the earliest `New`/`Wrap` call and not duplicated on subsequent wraps.
- `Handle` distinguishes client errors (4xx) from server errors (5xx) per [OTEL semantic conventions](https://opentelemetry.io/docs/specs/semconv/http/http-spans/) — only server errors set span status to `Error` and are forwarded to APM/Sentry.
- Metadata set via `setMetadata` includes a timestamp and any diagnostic context registered by `ErrorContextProvider` implementations.
