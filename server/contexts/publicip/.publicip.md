Provides context-based storage and retrieval of a client's public IP address using Go's `context` package.

## Key Components

- **`NewContext(ctx, ip)`** — Stores a remote IP address string into a new child context using a private key to avoid collisions.
- **`FromContext(ctx)`** — Extracts the remote IP address from a context; returns an empty string if not present or type assertion fails.

## Usage Example

```go
// Store the IP in context (e.g., in HTTP middleware)
ctx := publicip.NewContext(r.Context(), "203.0.113.42")

// Retrieve the IP downstream
ip := publicip.FromContext(ctx)
if ip == "" {
    // IP was not set in context
}
fmt.Println("Client IP:", ip)
```
