Provides context markers for propagating osquery HTTP pre-authentication state and debug logging flags through the Go request context, enabling downstream handlers to skip redundant node-key extraction and apply consistent debug logging.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `NewPreAuthedContext` | `func` | Marks a context as pre-authenticated by the HTTP-level osquery middleware |
| `IsPreAuthed` | `func` | Reports whether the current context was marked as pre-authenticated |
| `NewDebugContext` | `func` | Marks a context as belonging to a host with debug logging enabled |
| `IsDebug` | `func` | Reports whether the request context has debug logging enabled |
| `preAuthedMarker` | `struct` | Unexported sentinel value stored in context for pre-auth detection |
| `debugMarker` | `struct` | Unexported sentinel value stored in context for debug flag detection |

## Usage Example

```go
// In the HTTP pre-auth middleware — mark the context after validating
// the Authorization: NodeKey header.
func OsqueryPreAuthMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        nodeKey := r.Header.Get("Authorization")
        host, debug, err := authenticateHost(nodeKey)
        if err != nil {
            http.Error(w, "unauthorized", http.StatusUnauthorized)
            return
        }

        ctx := osqueryauth.NewPreAuthedContext(r.Context())
        if debug {
            ctx = osqueryauth.NewDebugContext(ctx)
        }

        next.ServeHTTP(w, r.WithContext(ctx))
    })
}

// In a downstream endpoint handler — skip body-level node-key extraction
// when pre-auth has already been performed.
func handleOsqueryLog(ctx context.Context, req logRequest) error {
    if !osqueryauth.IsPreAuthed(ctx) {
        if err := validateNodeKey(req.NodeKey); err != nil {
            return ErrUnauthorized
        }
    }

    if osqueryauth.IsDebug(ctx) {
        log.Debug().Msgf("osquery log payload: %+v", req)
    }

    return processLog(req)
}
```
