Manages the current user context for request-scoped authentication and authorization, providing helpers to read user identity, session state, and access control within a Go `context.Context`.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Viewer` | struct | Holds the current `*fleet.User` and `*fleet.Session` for a request |
| `NewContext` | func | Stores a `Viewer` into a `context.Context` |
| `FromContext` | func | Retrieves a `Viewer` from a `context.Context` |
| `NewSystemContext` | func | Creates a context with synthetic admin (`"Fleet"`) privileges for internal operations |
| `Viewer.IsLoggedIn` | method | Returns `true` if a non-zero session ID is present |
| `Viewer.CanPerformActions` | method | Returns `true` if logged in and not in a forced password-reset state |
| `Viewer.CanPerformPasswordReset` | method | Returns `true` if logged in and an admin-forced password reset is pending |
| `Viewer.GetDiagnosticContext` | method | Implements `ctxerr.ErrorContextProvider` with login/SSO status |
| `Viewer.GetTelemetryContext` | method | Implements `ctxerr.ErrorContextProvider` with masked user email |
| `maskEmail` | func (internal) | Anonymizes email for telemetry: `"john@example.com"` → `"j***@example.com"` |

## Usage Example

```go
// Attach the current viewer to a request context
v := viewer.Viewer{User: currentUser, Session: currentSession}
ctx = viewer.NewContext(ctx, v)

// Retrieve and inspect the viewer downstream
v, ok := viewer.FromContext(ctx)
if !ok || !v.CanPerformActions() {
    return fleet.ErrNoContext
}
fmt.Println("Request by:", v.Email())

// Use system-level privileges for a cron job
sysCtx := viewer.NewSystemContext(context.Background())
```

## Notes

- The context key is an unexported typed `int` (`key`) to prevent collisions with other packages.
- `NewSystemContext` creates a synthetic `"Fleet"` admin user; use it only for cron jobs and internal service calls that bypass user authorization.
- `GetTelemetryContext` masks emails (first character + `***@domain`) before any external reporting.
