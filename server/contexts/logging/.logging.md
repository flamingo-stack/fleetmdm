Provides request-scoped structured logging utilities for propagating log context (user, errors, timing, extras) through Go `context.Context` values.

## Key Components

| Export | Type | Description |
|---|---|---|
| `UserEmailer` | Interface | Supplies a user's email string for log output |
| `WithUserEmailer` / `UserEmailerFromContext` | Functions | Store/retrieve a `UserEmailer` on the context |
| `LoggingContext` | Struct | Thread-safe container for request log state: start time, errors, extras, user skip flag, and forced log level |
| `NewContext` / `FromContext` | Functions | Attach/retrieve a `*LoggingContext` on a `context.Context` |
| `WithStartTime` | Function | Stamps the current time as the request start on the logging context |
| `WithErr` | Function | Appends one or more errors to the logging context |
| `WithExtras` | Function | Appends arbitrary key-value pairs to the log output |
| `WithLevel` | Function | Forces a specific `slog.Level` for the request (still upgrades to `Error` if errors are present) |
| `WithNoUser` | Function | Suppresses user logging for the request |
| `LoggingContext.Log` | Method | Emits the structured log record via `*slog.Logger`, resolving level, user, method, URI, duration, extras, and error details |

## Usage Example

```go
// Middleware: attach a fresh LoggingContext at the start of each request
func loggingMiddleware(next http.Handler, logger *slog.Logger) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        ctx := logging.NewContext(r.Context(), &logging.LoggingContext{})
        ctx = logging.WithStartTime(ctx)

        // After authenticating the user:
        ctx = logging.WithUserEmailer(ctx, authenticatedUser)

        next.ServeHTTP(w, r.WithContext(ctx))

        // At the end of the request, flush the log:
        if logCtx, ok := logging.FromContext(ctx); ok {
            logCtx.Log(ctx, logger)
        }
    })
}

// Inside a handler or service layer:
ctx = logging.WithExtras(ctx, "fleet_id", 42, "action", "enroll")
ctx = logging.WithErr(ctx, fmt.Errorf("policy check failed"))
```

**Level resolution order:** explicit server errors → `ForceLevel` (if set) → `slog.LevelDebug`. Client errors (implementing `IsClientError()`) do **not** escalate the level to `Error`.
