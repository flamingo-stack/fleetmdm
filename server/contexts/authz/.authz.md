Defines the authorization context used to track whether a request has undergone an authorization check, and which authentication method was used.

## Key Components

- **`AuthorizationContext`** — Thread-safe struct tracking authorization check state (`checked`) and the authentication method (`authnMethod`) for a request.
- **`AuthenticationMethod`** — Integer enum identifying the authentication mechanism used (e.g., user token, host token, device certificate).
- **`NewContext`** / **`FromContext`** — Helpers to store and retrieve an `AuthorizationContext` from a `context.Context`.
- **Authentication Methods:**
  - `AuthnUserToken` — User API token; supports granular authorization.
  - `AuthnHostToken` — osquery host token; no granular authorization.
  - `AuthnDeviceToken` — Orbit identifier; limited device-only access.
  - `AuthnOrbitToken` — Orbit host token; no granular authorization.
  - `AuthnDeviceCertificate` — Client certificate for iOS/iPadOS devices.
  - `AuthnHTTPMessageSignature` — HTTP Message Signature via SCEP identity cert.
  - `AuthnDeviceURL` — UUID in URL; no granular authorization.

## Usage Example

```go
// Attach an authorization context to a request context
authCtx := &authz.AuthorizationContext{}
authCtx.SetAuthnMethod(authz.AuthnUserToken)
ctx := authz.NewContext(ctx, authCtx)

// In middleware or service layer: mark authorization as checked
if ac, ok := authz.FromContext(ctx); ok {
    ac.SetChecked()
}

// Verify the request was authorized before returning results
if ac, ok := authz.FromContext(ctx); !ok || !ac.Checked() {
    return nil, errors.New("authorization check not performed")
}
```
