Provides context-based storage and retrieval of the current osquery host, along with diagnostic and telemetry attribute extraction for error reporting.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `NewContext` | Function | Stores a `*fleet.Host` in a context using a private typed key |
| `FromContext` | Function | Retrieves a `*fleet.Host` from context with an existence check |
| `HostAttributeProvider` | Struct | Wraps `*fleet.Host` to implement `ctxerr.ErrorContextProvider` |
| `GetDiagnosticContext` | Method | Returns host `platform` and `osquery_version` for error diagnostics |
| `GetTelemetryContext` | Method | Returns `host.hostname` and `host.id` for telemetry reporting |

## Usage Example

```go
// Store host in context
ctx = host.NewContext(ctx, &fleet.Host{
    Hostname:       "acme-macbook.local",
    Platform:       "darwin",
    OsqueryVersion: "5.10.2",
    ID:             42,
})

// Retrieve host from context
h, ok := host.FromContext(ctx)
if ok {
    fmt.Println(h.Hostname) // "acme-macbook.local"
}

// Attach to error context provider for enriched error reporting
provider := &host.HostAttributeProvider{Host: h}

diag := provider.GetDiagnosticContext()
// map[host:map[platform:darwin osquery_version:5.10.2]]

telemetry := provider.GetTelemetryContext()
// map[host.hostname:acme-macbook.local host.id:42]
```

## Notes

- The context key is a private typed `int` constant (`hostKey`), preventing collisions with other packages storing values in context.
- Both `GetDiagnosticContext` and `GetTelemetryContext` safely return `nil` when `Host` is `nil`, avoiding nil-pointer panics in error handling paths.
