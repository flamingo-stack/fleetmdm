Provides context-aware storage and retrieval of the maximum software installer size limit, along with human-readable byte formatting utilities.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `MaxSoftwareInstallerSize` | `const int64` | Default maximum installer size (10 GiB) |
| `Human` | `func` | Formats a byte count into the shortest human-readable string (SI or binary units) |
| `NewContext` | `func` | Stores a custom max installer size into a `context.Context` |
| `FromContext` | `func` | Retrieves the max installer size from a context, falling back to `MaxSoftwareInstallerSize` |

## Usage Example

```go
// Store a custom limit in context (e.g., 5 GiB)
ctx := installersize.NewContext(context.Background(), 5*units.GiB)

// Retrieve the limit later
maxSize := installersize.FromContext(ctx)
fmt.Println(installersize.Human(maxSize)) // "5 GiB"

// Context without a stored value returns the default 10 GiB
defaultSize := installersize.FromContext(context.Background())
fmt.Println(installersize.Human(defaultSize)) // "10 GiB"
```

## Notes

- `Human` picks the shorter of SI (`GB`) and binary (`GiB`) representations, minimising display length.
- `FromContext` is safe to call on any context — missing values transparently fall back to `MaxSoftwareInstallerSize`.
- The unexported `key{}` struct prevents context key collisions with other packages.
