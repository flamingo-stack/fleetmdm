Provides a typed context key for storing and retrieving client certificate serial numbers during mTLS authentication flows for device endpoints.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `key` | `int` type alias | Unexported type used as a context key to prevent collisions |
| `certSerialKey` | `key` constant | Package-level singleton key for context storage |
| `NewContext` | Function | Stores a `uint64` certificate serial number into the given context |
| `FromContext` | Function | Retrieves the certificate serial number from a context with presence check |

## Usage Example

```go
// Store a cert serial in context (e.g., in an mTLS middleware)
ctx := certserial.NewContext(r.Context(), 123456789)

// Retrieve it downstream (e.g., in a handler or service layer)
serial, ok := certserial.FromContext(ctx)
if !ok {
    // No cert serial present — handle unauthenticated case
    http.Error(w, "missing client certificate", http.StatusUnauthorized)
    return
}

log.Printf("Authenticated device with cert serial: %d", serial)
```

## Notes

- The unexported `key` type ensures the context key cannot collide with keys from other packages, following Go's recommended context key pattern.
- `FromContext` uses a type assertion safe form `.(uint64)` returning `(value, ok)`, so callers must always check the boolean before using the serial.
- Designed for use in HTTP middleware that extracts cert serial numbers from headers (e.g., `X-SSL-Client-Serial`) set by a TLS-terminating proxy.
