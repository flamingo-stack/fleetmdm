Provides context helpers for storing and retrieving Apple Business Manager (ABM) OAuth1 tokens within a Go `context.Context`.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `abmKey` | `key` (unexported) | Typed context key to avoid collisions with other context values |
| `NewContext` | `func` | Stores a decrypted `OAuth1Tokens` value into the provided context |
| `FromContext` | `func` | Retrieves the `OAuth1Tokens` from a context, returning a boolean indicating presence |

## Usage Example

```go
// Store ABM tokens in context
tokens := &depclient.OAuth1Tokens{ /* ... */ }
ctx = apple_bm.NewContext(ctx, tokens)

// Retrieve ABM tokens from context
tok, ok := apple_bm.FromContext(ctx)
if !ok {
    // token not present in context
}
```

## Notes

- Uses a private typed `key` (`type key int`) to prevent accidental key collisions with other packages storing values in the same context.
- Follows the standard Go `NewContext` / `FromContext` convention for context-scoped values.
- Sourced from [`apple_bm.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/apple_bm.go) in the `flamingo-stack/fleetmdm` repository.
