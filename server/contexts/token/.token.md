Authentication token management for Fleet session tokens, providing utilities to extract, store, and retrieve Bearer tokens from HTTP requests and Go contexts.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Token` | `type` | Concrete string type representing Fleet session tokens |
| `FromHTTPRequest` | `func` | Extracts a Bearer token from an HTTP `Authorization` header |
| `NewContext` | `func` | Stores a token in a `context.Context` |
| `FromContext` | `func` | Retrieves a token from a `context.Context` |
| `parseHeaderLimited` | `func` (internal) | Safely splits an auth header into exactly two parts |

## Usage Example

```go
// Extract token from an incoming HTTP request
token := token.FromHTTPRequest(r)

// Store it in the request context for downstream handlers
ctx := token.NewContext(r.Context(), token)

// Retrieve it later in a handler or middleware
if tok, ok := token.FromContext(ctx); ok {
    fmt.Println("Token:", tok)
}
```

## Notes

- **Case-insensitive prefix**: The `Bearer` scheme prefix is matched case-insensitively (`BEARER`, `bearer`, etc.), while the token value itself preserves its original casing.
- **Strict header parsing**: `parseHeaderLimited` rejects headers with more than two space-delimited parts, preventing malformed or malicious `Authorization` headers from causing unexpected behaviour.
- **No-op on empty token**: `NewContext` returns the original context unchanged if the token is an empty string, avoiding polluting the context with blank values.
