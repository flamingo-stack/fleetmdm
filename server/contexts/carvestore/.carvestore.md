Context helper for injecting and retrieving a `fleet.CarveBySessionIder` store into/from a Go `context.Context`, enabling carve session access across request boundaries.

## Key Components

| Symbol | Description |
|--------|-------------|
| `carveStoreKey` | Unexported typed key used to safely namespace the value within a context |
| `NewContext` | Stores a `fleet.CarveBySessionIder` implementation into the provided context |
| `FromContext` | Retrieves the `fleet.CarveBySessionIder` from the context; returns `nil` if not set |

## Usage Example

```go
// Store the carve service in context (e.g., in middleware)
ctx = carvestore.NewContext(ctx, myCarveService)

// Retrieve the carve service later (e.g., in a handler)
svc := carvestore.FromContext(ctx)
if svc == nil {
    // handle missing carve store
}

session, err := svc.CarveBySessionId(ctx, sessionID)
```

## Notes

- Uses a private typed `key` type to avoid collisions with other packages storing values in the same context.
- `FromContext` performs a safe type assertion and returns `nil` on failure rather than panicking.
- Follows the standard Go context value pattern recommended for request-scoped dependencies.
