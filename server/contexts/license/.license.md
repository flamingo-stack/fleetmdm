Provides a context-based API for storing and retrieving license information, enabling license-aware behavior throughout the application without explicit parameter passing.

## Key Components

### Interface

- **`LicenseChecker`** — Defines the contract for license introspection. Implemented by `fleet.LicenseInfo` and exposes:
  - `IsPremium() bool` — Whether the license grants premium access
  - `IsAllowDisableTelemetry() bool` — Whether telemetry can be disabled
  - `GetTier() string` — Returns the tier string (e.g., `"free"`, `"premium"`, `"trial"`)
  - `GetOrganization() string` — Name of the licensed organization
  - `GetDeviceCount() int` — Number of licensed devices

### Functions

- **`NewContext(ctx, lic)`** — Stores a `LicenseChecker` in the given context
- **`FromContext(ctx)`** — Retrieves the `LicenseChecker` from context, returns `(LicenseChecker, bool)`
- **`IsPremium(ctx)`** — Convenience wrapper; returns `false` if no license is present
- **`IsAllowDisableTelemetry(ctx)`** — Convenience wrapper; returns `false` if no license is present

## Usage Example

```go
// Store a license in context (typically at request/startup time)
ctx := license.NewContext(context.Background(), myLicenseInfo)

// Check premium status anywhere downstream
if license.IsPremium(ctx) {
    // enable premium features
}

// Retrieve the full checker for richer inspection
if lic, ok := license.FromContext(ctx); ok {
    fmt.Println("Org:", lic.GetOrganization())
    fmt.Println("Tier:", lic.GetTier())
    fmt.Println("Devices:", lic.GetDeviceCount())
}

// Check telemetry opt-out eligibility
if license.IsAllowDisableTelemetry(ctx) {
    // respect telemetry disable setting
}
```
