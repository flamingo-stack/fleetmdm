Provides a client method for saving secret variables to the Fleet MDM API via an authenticated PUT request.

## Key Components

- **`SaveSecretVariables(secretVariables []fleet.SecretVariable, dryRun bool) error`** — Sends a PUT request to `/api/latest/fleet/spec/secret_variables` to create or update secret variables. Supports a `dryRun` mode to validate the operation without persisting changes.

## Usage Example

```go
client, _ := service.NewClient(...)

secrets := []fleet.SecretVariable{
    {Name: "DB_PASSWORD", Value: "s3cr3t"},
    {Name: "API_KEY", Value: "abc123"},
}

// Dry run to validate before saving
if err := client.SaveSecretVariables(secrets, true); err != nil {
    log.Fatalf("dry run failed: %v", err)
}

// Persist the secret variables
if err := client.SaveSecretVariables(secrets, false); err != nil {
    log.Fatalf("failed to save secrets: %v", err)
}
```

## Notes

- Requires an authenticated client; the request is dispatched via `authenticatedRequest`.
- Uses `fleet.CreateSecretVariablesRequest` as the request body and `fleet.CreateSecretVariablesResponse` for the response.
