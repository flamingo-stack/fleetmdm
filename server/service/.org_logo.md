Handles the HTTP endpoints and service logic for managing organization logos in Fleet MDM, including upload, deletion, and retrieval with support for light/dark mode variants.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `putOrgLogoEndpoint` | func | Handles `PUT /api/v1/fleet/logo` — parses multipart form upload and delegates to `UploadOrgLogo` |
| `deleteOrgLogoEndpoint` | func | Handles `DELETE /api/v1/fleet/logo` — removes stored logo blob and clears AppConfig URLs |
| `getOrgLogoEndpoint` | func | Handles `GET /api/latest/fleet/logo` — fetches and streams the raw logo bytes |
| `svc.UploadOrgLogo` | method | Validates, stores, and records activity for a logo upload; rolls back on partial failure |
| `svc.DeleteOrgLogo` | method | Clears AppConfig URL fields and deletes blobs for one or both modes atomically |
| `svc.GetOrgLogo` | method | Retrieves logo bytes, re-validates content, and enforces size limits on read |
| `getOrgLogoResponse.HijackRender` | method | Writes raw bytes directly with correct `Content-Type`, `Cache-Control`, and SVG-specific CSP headers |
| `parseLogoModeQuery` | func | Parses `mode` query param for PUT/DELETE; defaults to `OrgLogoModeAll` when omitted |
| `orgLogoServingURL` | func | Builds a cache-busted URL persisted in AppConfig after upload |
| `getOrgLogoURL` / `clearOrgLogoURL` | funcs | Read/zero both new and deprecated `OrgInfo` URL fields for a given mode |

## Usage Example

```go
// Upload a logo for both light and dark modes
f, _ := os.Open("logo.svg")
defer f.Close()
err := svc.UploadOrgLogo(ctx, fleet.OrgLogoModeAll, f)

// Retrieve the light-mode logo bytes
body, size, err := svc.GetOrgLogo(ctx, fleet.OrgLogoModeLight)

// Delete only the dark-mode logo
err = svc.DeleteOrgLogo(ctx, fleet.OrgLogoModeDark)
```

> **Mode values:** `light`, `dark`, or `all`. The GET endpoint rejects `all` — it only serves a single stored file per request.

> **Security:** SVG responses include a restrictive CSP (`default-src 'none'`) and `X-Content-Type-Options: nosniff` to prevent XSS via direct URL access.
