Client methods for interacting with Fleet's host management API endpoints, providing operations to retrieve, identify, and transfer hosts between teams.

## Key Components

| Function | Description |
|---|---|
| `GetHosts(query string)` | Retrieves a list of all hosts, optionally filtered by a query string |
| `GetHost(id uint)` | Fetches detailed information for a single host by numeric ID |
| `HostByIdentifier(identifier string)` | Looks up a host by UUID, osquery host ID, hostname, or node key |
| `TransferHosts(...)` | Moves hosts to a team, either by explicit host list or by filter (label/status/search) |
| `GetHostsReport(columns ...string)` | Returns a CSV-formatted report of all hosts with optional column selection |
| `translateTransferHostsToIDs(...)` | Internal helper that resolves host, label, and team string identifiers to numeric IDs via the `/api/latest/fleet/translate` endpoint |
| `encodeTranslatedPayload(...)` | Builds a `fleet.TranslatePayload` struct from a translator type and identifier string |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Get all hosts matching a query
hosts, err := client.GetHosts("platform=darwin")

// Look up a host by hostname
host, err := client.HostByIdentifier("macbook-pro.local")

// Transfer specific hosts to a team
err = client.TransferHosts(
    []string{"host-uuid-1", "host-uuid-2"},
    "",    // label
    "",    // status
    "",    // searchQuery
    "Engineering",
)

// Transfer all hosts matching a label and status
err = client.TransferHosts(nil, "macOS", "online", "", "Engineering")

// Fetch a CSV report with specific columns
records, err := client.GetHostsReport("hostname", "platform", "os_version")
// records[0] = ["hostname", "platform", "os_version"]
// records[1..] = per-host values
```

## Notes

- `TransferHosts` dispatches to either `/hosts/transfer` (explicit IDs) or `/hosts/transfer/filter` (label/status/search filter) depending on whether host identifiers are provided.
- All methods require an authenticated client; requests use `authenticatedRequest` or `AuthenticatedDo` internally.
