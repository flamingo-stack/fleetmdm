Handles software inventory endpoints for listing, retrieving, and counting software across Fleet-managed devices, with support for team-based access control and CVE vulnerability filtering.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `listSoftwareEndpoint` | func (deprecated) | Legacy endpoint returning software list without count metadata |
| `listSoftwareVersionsEndpoint` | func | Current endpoint returning paginated software list with total count |
| `ListSoftware` | method | Authorizes and fetches software inventory with optional team and CVE filters |
| `getSoftwareEndpoint` | func | Retrieves a single software record by ID |
| `SoftwareByID` | method | Fetches software with team-scoped auth; returns a metadata stub if user lacks host access |
| `SoftwareLiteByID` | method | Fetches lightweight software record without host-count data |
| `countSoftwareEndpoint` | func (deprecated) | Standalone count endpoint, retained for backwards compatibility |
| `CountSoftware` | method | Returns total software count; restricts CVSS/exploit filters to premium licenses |

## Usage Example

```go
// List software for a specific team (premium: include CVSS filters)
opts := fleet.SoftwareListOptions{
    TeamID:       ptr.Uint(42),
    MinimumCVSS:  7.0,
    KnownExploit: true,
}
softwares, meta, err := svc.ListSoftware(ctx, opts)

// Fetch a single software version by ID, scoped to a team
teamID := uint(42)
sw, err := svc.SoftwareByID(ctx, 1337, &teamID, false)

// Count software matching filters
count, err := svc.CountSoftware(ctx, opts)
```

## Notes

- `listSoftwareEndpoint` and `countSoftwareEndpoint` are **deprecated**; prefer `listSoftwareVersionsEndpoint` which bundles pagination metadata and count in one response.
- CVSS score and known-exploit filters (`MinimumCVSS`, `MaximumCVSS`, `KnownExploit`) are **premium-only**; non-premium callers receive `fleet.ErrMissingLicense`.
- `SoftwareByID` relaxes access restrictions for basic metadata: if a user cannot see any hosts with the software, a stub `{ID, Name}` is returned instead of a permission error.
