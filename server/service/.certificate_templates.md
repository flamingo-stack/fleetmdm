Provides validation and variable-expansion utilities for MDM certificate templates, ensuring Fleet variables, subject names, and SANs are well-formed before delivery to managed hosts.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `fleetVarsSupportedInCertificateTemplates` | `var` | Allowlist of `FleetVarName` values valid inside certificate subject names and SANs (`HostUUID`, `HostHardwareSerial`, `HostEndUserIDPUsername`) |
| `subjectAlternativeNameAllowedKeys` | `var` | Set of accepted SAN key tokens: `DNS`, `EMAIL`, `UPN`, `IP`, `URI` |
| `validateCertificateTemplateFleetVariables` | `func` | Checks that every `$FLEET_VAR_*` reference in a subject name string is on the supported allowlist |
| `validateCertificateTemplateSubjectAlternativeName` | `func` | Validates SAN string format (length, `KEY=value` shape, key allowlist); returns a typed `*fleet.InvalidArgumentError` (HTTP 422) on failure |
| `replaceCertificateVariables` | `func (Service)` | Expands `$FLEET_VAR_*` tokens in a string with live host values; uses an optional memo to avoid redundant DB calls for the end-user IDP lookup |
| `expandCertVar` | `func (Service)` | Thin wrapper around `replaceCertificateVariables` that persists a `CertificateStatusFailed` record and clears SCEP/Fleet challenges on expansion failure |

## Usage Example

```go
// Validate SAN format before persisting a new certificate template
if err := validateCertificateTemplateSubjectAlternativeName(
    "DNS=$FLEET_VAR_HOST_UUID,UPN=user@example.com",
    "MyCorpWiFi",
); err != nil {
    return err // returns fleet.InvalidArgumentError with field "subject_alternative_name"
}

// Expand Fleet variables when building the per-host payload
var endUsersMemo []fleet.HostEndUser
expanded, ok, err := svc.expandCertVar(
    ctx,
    certificate,          // *fleet.CertificateTemplateResponseForHost
    certificate.SubjectName,
    "Could not replace certificate variables",
    host,
    &endUsersMemo,        // reuse for subsequent SAN expansion on same host
)
if !ok {
    return certificate, err // status already written to DB as failed
}
```

## Notes

- SAN validation is intentionally **format-only**; value semantics (e.g., valid IP format) are enforced by the Android MDM agent after variable expansion.
- Pass the same `*[]fleet.HostEndUser` memo pointer across successive `expandCertVar` / `replaceCertificateVariables` calls for the same host to avoid duplicate datastore round-trips.
