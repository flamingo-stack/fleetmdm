Handles CRUD operations and validation for certificate templates in the Fleet MDM service layer, including creation, listing, and host-scoped retrieval with Fleet variable expansion.

## Key Components

### Validation Functions
- **`validateCertificateTemplateName`** — Enforces name rules: non-empty, max 255 chars, alphanumeric/spaces/dashes/underscores only
- **`validateCertificateTemplateSubjectName`** — Ensures subject name is non-empty
- `certificateTemplateNameRegex` — Compiled regex: `^[a-zA-Z0-9 \-_]+$`

### Service Methods
| Method | Description |
|--------|-------------|
| `CreateCertificateTemplate` | Creates a new cert template (Premium only, `custom_scep_proxy` CA required), seeds pending records for existing Android hosts, emits activity |
| `ListCertificateTemplates` | Paginated list of templates scoped to a team; fixed sort by `id` ascending |
| `GetDeviceCertificateTemplate` | Node-key authenticated; expands `$FLEET_VAR_*` variables in `subject_name` and `subject_alternative_name` for the requesting host; on-demand challenge creation for delivered status |
| `GetCertificateTemplate` | Admin-facing lookup by ID *(truncated in source)* |

### Request/Response Types
- `createCertificateTemplateRequest` / `createCertificateTemplateResponse`
- `listCertificateTemplatesRequest` / `listCertificateTemplatesResponse`
- `getDeviceCertificateTemplateRequest` / `getDeviceCertificateTemplateResponse`
- `getCertificateTemplateRequest` / `getCertificateTemplateResponse`

## Usage Example

```go
// Create a certificate template (Premium license required)
template, err := svc.CreateCertificateTemplate(
    ctx,
    "My Corp Cert",          // name
    42,                      // teamID
    7,                       // certificateAuthorityID (must be custom_scep_proxy)
    "CN=$FLEET_VAR_HOST_END_USER_IDP_USERNAME",
    "email:$FLEET_VAR_HOST_END_USER_IDP_USERNAME",
)

// List templates for a team
templates, meta, err := svc.ListCertificateTemplates(ctx, 42, fleet.ListOptions{PerPage: 20})
```
