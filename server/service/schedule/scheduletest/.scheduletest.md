Provides no-op and mock implementations of the `schedule` package's `Locker` and `CronStatsStore` interfaces for use in cron schedule tests.

## Key Components

| Type | Description |
|------|-------------|
| `NopLocker` | No-op `Locker` that always returns `(true, nil)` on lock and `nil` on unlock |
| `NopStatsStore` | No-op `CronStatsStore` that returns empty results for all operations |
| `MockLock` | In-memory `Locker` with owner/expiration logic, call counters (`LockCount`, `UnlockCount`), and optional signaling channels |
| `MockStatsStore` | In-memory `CronStatsStore` backed by a `map[int]fleet.CronStats` with optional signaling channels |

### Constructor Functions

- **`SetupMockLocker(name, owner, expiresAt)`** — returns a `*MockLock` pre-configured with the given lock name, owner, and expiration time.
- **`SetUpMockStatsStore(_, initialStats...)`** — returns a `*MockStatsStore` pre-seeded with the provided `fleet.CronStats` entries.

### Channel Signaling (`AddChannels`)

Both `MockLock` and `MockStatsStore` expose an `AddChannels(t, names...)` method that initialises named `chan struct{}` fields for synchronising test goroutines.

| Type | Valid Channel Names |
|------|-------------------|
| `MockLock` | `"locked"`, `"unlocked"` |
| `MockStatsStore` | `"GetStatsCalled"`, `"InsertStatsCalled"`, `"UpdateStatsCalled"` |

## Usage Example

```go
func TestMySchedule(t *testing.T) {
    // No-op implementations for simple tests
    locker := scheduletest.NopLocker{}
    store  := scheduletest.NopStatsStore{}

    // Full mock with expiration and signaling
    lock := scheduletest.SetupMockLocker("my-job", "instance-1", time.Now().Add(time.Minute))
    lock.AddChannels(t, "locked", "unlocked")

    statsStore := scheduletest.SetUpMockStatsStore("my-job")
    statsStore.AddChannels(t, "InsertStatsCalled")

    // Block until a lock is acquired
    go runSchedule(lock, statsStore)
    <-lock.Locked

    _ = locker
    _ = store
}
```

> **Note:** This package imports `testing` and must only be used from test files (`_test.go`) to avoid pulling the `testing` package into production binaries.
