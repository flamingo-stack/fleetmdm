Periodic job scheduler that runs a list of named jobs serially at configurable intervals, with distributed locking, cron statistics tracking, and support for both scheduled and externally-triggered execution.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `Schedule` | struct | Core scheduler holding jobs, interval config, locker, stats store, and trigger channels |
| `Job` / `JobFn` | struct / type | Named job wrapper around a `func(context.Context) error` |
| `Locker` | interface | Distributed lock interface (`Lock`/`Unlock`) to prevent concurrent runs across instances |
| `CronStatsStore` | interface | Persistence layer for cron run statistics (`GetLatestCronStats`, `InsertCronStats`, `UpdateCronStats`, `ClaimCronStats`) |
| `ReloadInterval` | type | Callback function to dynamically reload the schedule interval at runtime |
| `New()` | func | Constructs a `Schedule` with required fields and applies functional options |
| `Start()` | method | Launches the scheduler goroutine; must be called after all jobs are added |

### Functional Options

| Option | Purpose |
|--------|---------|
| `WithJob` | Appends a named job to the execution list |
| `WithLogger` | Attaches a `*slog.Logger` |
| `WithConfigReloadInterval` | Sets dynamic interval reloading |
| `WithAltLockID` | Overrides the lock name (default: schedule name) |
| `WithRunOnce` | Stops after the first successful completion |
| `WithDefaultPrevRunCreatedAt` | Controls initial wait before first run |
| `WithTriggerPollInterval` | Enables DB polling for cross-server trigger requests |

## Usage Example

```go
sched := schedule.New(
    ctx,
    "cleanup",
    instanceID,
    1*time.Hour,
    locker,
    statsStore,
    schedule.WithLogger(logger),
    schedule.WithJob("delete-expired-tokens", func(ctx context.Context) error {
        return ds.DeleteExpiredTokens(ctx)
    }),
    schedule.WithJob("vacuum-old-records", func(ctx context.Context) error {
        return ds.VacuumOldRecords(ctx)
    }),
    schedule.WithConfigReloadInterval(5*time.Minute, func(ctx context.Context) (time.Duration, error) {
        return ds.GetScheduleInterval(ctx, "cleanup")
    }),
)
sched.Start()
```
