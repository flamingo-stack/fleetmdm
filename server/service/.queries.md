Handles CRUD operations and reporting for Fleet osquery queries, including listing, creating, modifying, deleting, and retrieving query report results with authorization checks and activity logging.

## Key Components

| Function | Description |
|---|---|
| `GetQuery` | Fetches a single query by ID with auth check |
| `ListQueries` | Lists queries with filtering by team, platform, and schedule; supports pagination and inherited queries |
| `GetQueryReportResults` | Returns stored query result rows for a given query, respecting team visibility and discard settings |
| `QueryReportIsClipped` | Checks whether a query's report has hit the configured row cap |
| `NewQuery` | Creates a new saved query; enforces premium license for label targeting and logs activity |
| `ModifyQuery` | Updates an existing query's fields after authorization; validates label targeting and logging mode |

## Usage Example

```go
// Create a new scheduled query
payload := fleet.QueryPayload{
    Name:               ptr.String("Active Users"),
    Query:              ptr.String("SELECT * FROM logged_in_users;"),
    Interval:           ptr.Uint(3600),
    AutomationsEnabled: ptr.Bool(true),
    Logging:            ptr.String(fleet.LoggingSnapshot),
    Platform:           ptr.String("darwin"),
}
query, err := svc.NewQuery(ctx, payload)

// List queries for a specific team, filtered by platform
queries, count, inheritedCount, meta, err := svc.ListQueries(
    ctx,
    fleet.ListOptions{PerPage: 20, Page: 0},
    ptr.Uint(42),   // teamID
    nil,            // scheduled filter
    true,           // mergeInherited
    ptr.String("macos"),
)

// Get query report results
results, clipped, err := svc.GetQueryReportResults(ctx, queryID, nil)
if clipped {
    log.Println("Report exceeded row cap; results are truncated")
}
```

## Notes

- Platform filter `"macos"` is automatically translated to `"darwin"` for datastore compatibility.
- Label-based query targeting (`LabelsIncludeAny`, `LabelsIncludeAll`) requires a Fleet Premium license.
- `NewQuery` and `ModifyQuery` emit `ActivityTypeCreatedSavedQuery` / `ActivityTypeEditedSavedQuery` entries; global queries use `teamID = -1`.
- `GetQueryReportResults` returns `nil` (no error) when `DiscardData` is enabled on the query.
