Provides HTTP client methods for managing Fleet teams, including CRUD operations, spec application, and batch configuration of MDM profiles, scripts, software installers, and App Store apps.

## Key Components

| Function | Description |
|---|---|
| `ListTeams` | Retrieves all teams, optionally filtered by a query string |
| `CreateTeam` | Creates a new team from a `fleet.TeamPayload` |
| `GetTeam` | Fetches a single team by ID |
| `DeleteTeam` | Deletes a team by ID |
| `ApplyTeams` | Batch-applies team specs (with deprecated key rewriting and dry-run support) |
| `PatchFleet` | Partially updates a team's configuration |
| `ApplyTeamProfiles` | Batch-applies MDM profiles to a named team |
| `ApplyTeamScripts` | Batch-applies scripts to a named team |
| `ApplyTeamSoftwareInstallers` | Batch-applies software installers to a named team |
| `ApplyTeamAppStoreAppsAssociation` | Associates VPP/App Store apps with a named team |
| `ApplyNoTeamAppStoreAppsAssociation` | Associates VPP/App Store apps with no team |
| `matchAppStoreAppCustomIcons` | Internal helper that hydrates VPP responses with local icon metadata from the request |

## Usage Example

```go
// List all teams
teams, err := client.ListTeams("")
if err != nil {
    log.Fatal(err)
}

// Create a team
team, err := client.CreateTeam(fleet.TeamPayload{
    Name: ptr.String("Engineering"),
})

// Apply team specs with dry-run
teamIDs, err := client.ApplyTeams(specs, fleet.ApplyTeamSpecOptions{
    ApplySpecOptions: fleet.ApplySpecOptions{DryRun: true},
})

// Batch-apply MDM profiles to a team
err = client.ApplyTeamProfiles("Engineering", profiles, fleet.ApplyTeamSpecOptions{})

// Apply scripts to a team
scripts, err := client.ApplyTeamScripts("Engineering", scriptPayloads, fleet.ApplySpecOptions{})
```
