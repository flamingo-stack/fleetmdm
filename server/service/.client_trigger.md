Provides a Fleet API client method for triggering ad-hoc cron schedule runs, along with a helper for extracting error messages from server responses.

## Key Components

- **`TriggerCronSchedule(name string) error`** — Sends a `POST` to `/api/latest/fleet/trigger` with the schedule name as a query parameter. Handles `409 Conflict` (returns `conflictErr`) and `404 Not Found` (returns `*notFoundErr`) distinctly, falling back to `ParseResponse` for other status codes.
- **`extractServerErrMsg(verb, path string, res *http.Response) (string, error)`** — Decodes a `serverError` JSON body from a response, returning the first error's reason if available, or the top-level message otherwise.

## Usage Example

```go
client, _ := service.NewClient(fleetURL, token, nil)

err := client.TriggerCronSchedule("vulnerabilities")
if err != nil {
    var conflict conflictErr
    if errors.As(err, &conflict) {
        fmt.Println("schedule already running:", conflict.Msg)
        return
    }
    var notFound *notFoundErr
    if errors.As(err, &notFound) {
        fmt.Println("schedule not found:", notFound.Msg)
        return
    }
    log.Fatal(err)
}
fmt.Println("cron schedule triggered successfully")
```

## Error Handling

| Status Code | Returned Error |
|---|---|
| `409 Conflict` | `conflictErr` (value type) |
| `404 Not Found` | `*notFoundErr` (pointer type) |
| Other | Parsed via `ParseResponse` |
