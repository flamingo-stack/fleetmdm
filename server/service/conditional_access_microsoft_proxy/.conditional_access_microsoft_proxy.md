HTTP client package for communicating with Microsoft Entra via Fleet's MS proxy service, enabling conditional access compliance management for enrolled devices.

## Key Components

### `Proxy` struct
The main client type holding the proxy URI, API key, origin getter function, and an underlying `*http.Client`.

### Constructor
- **`New(uri, apiKey string, originGetter func() (string, error)) (*Proxy, error)`** — Creates a validated `Proxy` instance using `fleethttp.NewClient()`.

### Methods

| Method | Description |
|---|---|
| `Create(ctx, tenantID)` | Registers a new Microsoft compliance partner integration, returns tenant ID and secret. |
| `Get(ctx, tenantID, secret)` | Retrieves integration settings including consent URL and setup status. |
| `Delete(ctx, tenantID, secret)` | Deprovisions the tenant on Microsoft and removes the proxy integration. Returns `notFoundError` (implements `IsNotFound()`) if missing. |
| `SetComplianceStatus(...)` | Pushes device inventory and compliance state to Entra; returns a `MessageID` for async polling. |
| `GetMessageStatus(ctx, tenantID, secret, messageID)` | Polls the async result of a `SetComplianceStatus` operation. |

### Constants
- **`MessageStatusCompleted`** — Sentinel value `"Completed"` indicating a successfully applied compliance operation.

### Internal helpers
- `post`, `get`, `delete` — Internal HTTP wrappers handling marshaling, header injection, and error mapping.
- `setHeaders` — Injects `MS-API-Key` and `Origin` headers on every outbound request.
- `notFoundError` — Implements `IsNotFound()` and `IsClientError()` for Fleet's error-type conventions.

## Usage Example

```go
proxy, err := conditional_access_microsoft_proxy.New(
    "https://ms-proxy.fleet.example.com",
    "my-api-key",
    func() (string, error) { return "https://fleet.myorg.com", nil },
)
if err != nil {
    log.Fatal(err)
}

// Create integration
resp, err := proxy.Create(ctx, "my-entra-tenant-id")

// Push compliance status
statusResp, err := proxy.SetComplianceStatus(
    ctx,
    resp.TenantID, resp.Secret,
    "device-uuid", "user@corp.com",
    true, "MyMacBook", "macOS", "14.4",
    true, time.Now(),
)

// Poll async result
msg, err := proxy.GetMessageStatus(ctx, resp.TenantID, resp.Secret, statusResp.MessageID)
if msg.Status == conditional_access_microsoft_proxy.MessageStatusCompleted {
    // Compliance applied
}
```
