Implements HTTP endpoint handlers and service-layer stubs for managing self-service software categories in Fleet MDM. All service methods return `fleet.ErrMissingLicense`, indicating these features require a paid license tier.

## Key Components

| Symbol | Description |
|--------|-------------|
| `ListSoftwareCategories` | Lists software categories scoped to a team (license-gated) |
| `ListSelfServiceSoftwareCategoriesForHost` | Lists categories for a device via token authentication (license-gated) |
| `NewSoftwareCategory` | Creates a new software category for a team (license-gated) |
| `UpdateSoftwareCategory` | Renames an existing software category by ID (license-gated) |
| `DeleteSoftwareCategory` | Deletes a software category by ID; returns HTTP 204 (license-gated) |

The device-scoped endpoint (`getDeviceSelfServiceCategoriesEndpoint`) extracts the host from context via `hostctx.FromContext`, enabling token-authenticated device requests without explicit user auth.

## Usage Example

```go
// All methods follow the same pattern — they skip authorization
// and return ErrMissingLicense in the open-source build.

categories, err := svc.ListSoftwareCategories(ctx, teamID)
if err != nil {
    // err == fleet.ErrMissingLicense on non-premium builds
    log.Printf("categories unavailable: %v", err)
}

// Creating a category (premium only)
category, err := svc.NewSoftwareCategory(ctx, teamID, "Productivity")

// Updating a category by ID
updated, err := svc.UpdateSoftwareCategory(ctx, categoryID, "Security Tools")

// Deleting a category — endpoint returns 204 No Content
err = svc.DeleteSoftwareCategory(ctx, categoryID)

// Device token-authenticated listing
// Host is resolved from context; no user auth required
categories, err = svc.ListSelfServiceSoftwareCategoriesForHost(ctx, host)
```

> **Note:** Premium implementations of these interfaces live in the Fleet EE layer. The stubs here satisfy the `fleet.Service` interface for open-source deployments.
