Implements CRUD operations for Fleet's global query schedule, providing HTTP endpoint handlers and service methods to list, create, modify, and delete globally scheduled osquery queries.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `GetGlobalScheduledQueries` | Service method | Lists all global scheduled queries by fetching queries with no team ID |
| `GlobalScheduleQuery` | Service method | Creates a new globally scheduled query from an existing query |
| `ModifyGlobalScheduledQueries` | Service method | Updates an existing scheduled query by ID |
| `DeleteGlobalScheduledQueries` | Service method | Deletes a globally scheduled query by ID |
| `getGlobalScheduleEndpoint` | HTTP handler | `GET` endpoint for listing the global schedule |
| `globalScheduleQueryEndpoint` | HTTP handler | `POST` endpoint for scheduling a query globally |
| `modifyGlobalScheduleEndpoint` | HTTP handler | `PATCH` endpoint for modifying a scheduled query |
| `deleteGlobalScheduleEndpoint` | HTTP handler | `DELETE` endpoint for removing a scheduled query |

## Usage Example

```go
// List all globally scheduled queries
queries, err := svc.GetGlobalScheduledQueries(ctx, fleet.ListOptions{
    Page:    0,
    PerPage: 20,
})

// Schedule an existing global query
scheduled, err := svc.GlobalScheduleQuery(ctx, &fleet.ScheduledQuery{
    QueryID:  42,
    Interval: 3600,
    Snapshot: ptr.Bool(true),
    Removed:  ptr.Bool(false),
    Platform: ptr.String("linux"),
    Shard:    ptr.Uint(50),
})

// Modify a scheduled query's interval
updated, err := svc.ModifyGlobalScheduledQueries(ctx, scheduled.ID, fleet.ScheduledQueryPayload{
    Interval: ptr.Uint(7200),
})

// Remove a scheduled query
err = svc.DeleteGlobalScheduledQueries(ctx, scheduled.ID)
```

> **Note:** `GlobalScheduleQuery` enforces that the source query must not belong to a team (`TeamID == nil`). Attempting to schedule a team query globally returns an error.
