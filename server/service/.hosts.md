Provides core host management service logic for the Fleet MDM platform, including listing, streaming, filtering, and geo-locating hosts with support for MDM enrollment state.

## Key Components

- **`hostDetailResponseForHost`** – Builds a `HostDetailResponse`, resolving ADE enrollment status for iOS/iPadOS devices and attaching geolocation data (MDM-sourced for ADE devices, MaxMind GeoIP otherwise).
- **`GetHostLocationData`** – Retrieves stored latitude/longitude coordinates for a host from the datastore.
- **`listHostsRequest` / `listHostsResponse`** – Request/response types for the list hosts endpoint, supporting optional filters for software, MDM solution, and Munki issues.
- **`streamHostsResponse`** – Implements `HijackRender` to stream hosts as a JSON array incrementally, flushing each host to the HTTP response writer as it is yielded from the iterator.
- **`listHostsEndpoint`** – Resolves filter metadata (software title, MDM solution, Munki issue) and creates a streaming iterator pipeline that transforms `fleet.Host` into `fleet.HostResponse`, optionally populating host labels.

## Usage Example

```go
// Listing hosts with a software version filter via the service layer
opts := fleet.HostListOptions{
    SoftwareVersionIDFilter: ptr.Uint(42),
    TeamFilter:              ptr.Uint(1),
    PopulateLabels:          true,
}

iterator, err := svc.StreamHosts(ctx, opts)
if err != nil {
    return err
}

for host, err := range iterator {
    if err != nil {
        return err
    }
    resp := fleet.HostResponseForHost(ctx, svc, host)
    fmt.Println(resp.Hostname, resp.Status)
}
```

## Notes

- The streaming response (`streamHostsResponse`) writes JSON incrementally rather than buffering the full host list, making it suitable for large fleets.
- ADE-enrolled iOS/iPadOS devices require an active MDM configuration and a Premium license to retrieve geolocation data.
