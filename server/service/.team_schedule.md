Implements CRUD operations for managing scheduled queries within Fleet team schedules, mapping legacy scheduled query concepts to the underlying query model.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `GetTeamScheduledQueries` | Method | Lists all scheduled queries for a given team, converting `Query` records to `ScheduledQuery` format |
| `TeamScheduleQuery` | Method | Adds a global query to a team schedule by copying it with a timestamped name and associating it with the team |
| `ModifyTeamScheduledQueries` | Method | Updates a scheduled query's configuration (interval, snapshot, shard, etc.) via the underlying query model |
| `DeleteTeamScheduledQueries` | Method | Removes a scheduled query from a team by deleting it by ID |
| `nameForCopiedQuery` | Function | Generates a unique name for copied queries using the format `"Copy of <name> (<unix_ts>)"` |
| `nullIntToPtrUint` | Helper | Converts a nullable `null.Int` to a `*uint` pointer |
| `uintValueOrZero` | Helper | Safely dereferences a `*uint`, returning `0` for nil |

## Usage Example

```go
// List all scheduled queries for team 42
queries, err := svc.GetTeamScheduledQueries(ctx, 42, fleet.ListOptions{})

// Add a global query (ID=7) to team 42's schedule
scheduled, err := svc.TeamScheduleQuery(ctx, 42, &fleet.ScheduledQuery{
    QueryID:  7,
    Interval: 3600,
    Snapshot: ptr.Bool(true),
})

// Modify an existing scheduled query
updated, err := svc.ModifyTeamScheduledQueries(ctx, 42, scheduledQueryID, fleet.ScheduledQueryPayload{
    Interval: ptr.Uint(7200),
})

// Remove a scheduled query from the team
err = svc.DeleteTeamScheduledQueries(ctx, 42, scheduledQueryID)
```

> **Note:** `teamID` is accepted but not used in `ModifyTeamScheduledQueries` and `DeleteTeamScheduledQueries` due to a mismatch between the legacy API representation and the internal query model. Operations act directly on the query by ID.
