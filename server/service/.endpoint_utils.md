Provides factory functions and utilities for constructing typed HTTP endpoint handlers in the Fleet service layer, including request decoding, authentication middleware wiring, and capability header management.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `makeDecoder` | func | Builds a `kithttp.DecodeRequestFunc` by delegating to the platform endpointer with Fleet-specific tag parsers and body decoders |
| `fleetQueryDecoder` | func | Custom query-param decoder that converts `order_direction` / `inherited_order_direction` strings to `fleet.OrderDirection` int values |
| `bodyDecoder` | interface | Implemented by request types that need full control over body decoding (receives raw reader, URL values, and TLS peer certs) |
| `fleetEndpointer` | struct | Implements `eu.Endpointer[handlerFunc]`; bridges the generic endpointer framework to `fleet.Service` |
| `parseCustomTags` | func | Resolves custom URL tag values (`list_options`, `user_options`, `host_options`, etc.) into typed option structs |
| `newUserAuthenticatedEndpointer` | func | Returns a `CommonEndpointer` that enforces authenticated-user + API-only middleware |
| `newNoAuthEndpointer` | func | Returns a `CommonEndpointer` for unauthenticated routes |
| `newOrbitNoAuthEndpointer` | func | Returns a `CommonEndpointer` for unauthenticated Orbit routes, injecting capabilities context |
| `newDeviceAuthenticatedEndpointer` | func | Returns a `CommonEndpointer` for device-auth routes; adds cert-serial extraction and device capability headers |
| `newHostAuthenticatedEndpointer` | func | Returns a `CommonEndpointer` for osquery host-authenticated routes |
| `newOrbitAuthenticatedEndpointer` | func | Returns a `CommonEndpointer` for Orbit-authenticated routes with capability headers |
| `androidAuthenticatedEndpointer` | func | Returns a `CommonEndpointer` for Android MDM routes using Orbit node-key auth |
| `capabilitiesResponseFunc` | func | `kithttp.ServerAfter` option that writes a `fleet.CapabilitiesHeader` to the response |
| `capabilitiesContextFunc` | func | `kithttp.ServerBefore` option that injects the capabilities map into the request context |
| `badRequest` / `badRequestf` | func | Convenience helpers that wrap a message in `fleet.BadRequestError` |

## Usage Example

```go
// Create a versioned, user-authenticated endpoint group
ue := newUserAuthenticatedEndpointer(svc, kitOpts, router, "v1")

// Register a handler — decoder, auth middleware, and response encoding
// are all handled automatically by the endpointer
ue.GET("/api/{version}/fleet/hosts/{id}", getHostEndpoint, getHostRequest{})

// For unauthenticated routes (e.g. login)
ne := newNoAuthEndpointer(svc, kitOpts, router, "v1")
ne.POST("/api/{version}/fleet/login", loginEndpoint, loginRequest{})

// For Orbit-authenticated routes with capability negotiation
oe := newOrbitAuthenticatedEndpointer(svc, logger, kitOpts, router, "v1")
oe.POST("/api/{version}/fleet/orbit/config", orbitConfigEndpoint, orbitConfigRequest{})
```
