Provides Fleet API client methods for managing Android certificate templates, including retrieval, creation/update, and deletion operations.

## Key Components

| Function | Description |
|---|---|
| `GetCertificateTemplates(teamID string)` | Fetches all certificate templates for a given team via `GET /api/latest/fleet/certificates` |
| `ApplyCertificateSpecs(specs []*fleet.CertificateRequestSpec)` | Creates or updates certificate templates via `POST /api/latest/fleet/spec/certificates` |
| `DeleteCertificateTemplates(certificateTemplateIDs []uint, teamID uint)` | Removes certificate templates by ID via `DELETE /api/latest/fleet/spec/certificates` |

## Usage Example

```go
client := service.NewClient(...)

// List certificate templates for a team
templates, err := client.GetCertificateTemplates("42")
if err != nil {
    log.Fatal(err)
}

// Apply (create/update) certificate specs
specs := []*fleet.CertificateRequestSpec{
    {Name: "corp-wifi-cert", /* ... */},
}
if err := client.ApplyCertificateSpecs(specs); err != nil {
    log.Fatal(err)
}

// Delete certificate templates
if err := client.DeleteCertificateTemplates([]uint{1, 2, 3}, 42); err != nil {
    log.Fatal(err)
}
```

## Notes

- All methods require an authenticated `Client` instance; authentication is handled internally via `authenticatedRequest` / `authenticatedRequestWithQuery`.
- `GetCertificateTemplates` filters results server-side using the `fleet_id` query parameter.
