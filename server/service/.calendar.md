Handles incoming Google Calendar webhook notifications for Fleet MDM calendar events, providing the HTTP endpoint and request decoding logic.

## Key Components

| Component | Description |
|---|---|
| `calendarWebhookRequest` | Request struct holding the event UUID and Google-specific webhook headers |
| `calendarWebhookRequest.DecodeRequest` | Custom request decoder extracting `event_uuid` from the URL path and Google channel metadata from headers |
| `calendarWebhookResponse` | Response struct implementing `fleet.Errorer` |
| `calendarWebhookEndpoint` | Endpoint handler delegating to `fleet.Service.CalendarWebhook` |
| `Service.CalendarWebhook` | Service-level implementation; skips authorization and returns `fleet.ErrMissingLicense` (feature requires a valid license) |

## Usage Example

The endpoint receives `POST` requests from Google Calendar's push notification channel:

```go
// Google sends webhook notifications to this route:
// POST /api/v1/fleet/calendar/webhook/{event_uuid}
//
// With headers:
//   X-Goog-Channel-Id:       <channelID>
//   X-Goog-Resource-State:   <sync|exists|not_exists>

err := svc.CalendarWebhook(ctx, eventUUID, channelID, resourceState)
if err != nil {
    // Returns fleet.ErrMissingLicense on non-premium deployments
}
```

## Notes

- Authorization is explicitly skipped (`SkipAuthorization`) because the endpoint is externally triggered by Google and the license check serves as the only gate.
- On free/unlicensed Fleet instances, all calls return `fleet.ErrMissingLicense`; actual webhook processing logic lives in premium service implementations.
