This file implements the Fleet API client for Go, providing HTTP request construction, authentication, MDM configuration checks, and profile management utilities used by the `fleetctl` CLI and other Go consumers.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Client` | struct | Primary API client wrapping `baseClient` with token auth, custom headers, and I/O writers |
| `ClientOption` | type | Functional option pattern for configuring a `Client` at construction time |
| `NewClient` | func | Constructor accepting address, TLS options, and variadic `ClientOption` values |
| `EnableClientDebug` | `ClientOption` | Injects a `logRoundTripper` that logs request/response details to stderr |
| `SetClientOutputWriter` / `SetClientErrorWriter` | `ClientOption` | Override default stdout/stderr writers |
| `WithCustomHeaders` | `ClientOption` | Attaches custom HTTP headers to every request |
| `logRoundTripper` | struct | `http.RoundTripper` decorator that logs method, URL, status, timing, and body |
| `AuthenticatedDo` | method | Executes a request with a `Bearer` token authorization header |
| `CheckAnyMDMEnabled` / `CheckAppleMDMEnabled` / `CheckPremiumMDMEnabled` | methods | Pre-flight MDM configuration validations against app config |
| `getProfilesContents` | func | Reads macOS/Windows/Android MDM profile files from disk and returns batch payloads |

## Usage Example

```go
client, err := service.NewClient(
    "https://fleet.example.com",
    false,
    "",
    "",
    service.SetClientOutputWriter(os.Stdout),
    service.WithCustomHeaders(map[string]string{"X-Custom": "value"}),
)
if err != nil {
    log.Fatal(err)
}

client.SetToken("your-api-token")

// Run a pre-flight MDM check
if err := client.CheckAppleMDMEnabled(); err != nil {
    log.Fatalf("Apple MDM not configured: %v", err)
}

// Make an authenticated request
resp, err := client.AuthenticatedDo("GET", "/api/v1/fleet/hosts", "", nil)
```
