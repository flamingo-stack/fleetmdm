Core implementation file that defines the `Service` struct — the central type implementing the `fleet.Service` interface — along with its constructor and supporting types.

## Key Components

### `Service` struct
The primary service implementation holding all dependencies:
- **Data layer**: `ds` (datastore), `carveStore`, `resultStore`, `liveQueryStore`, `keyValueStore`, `orgLogoStore`
- **MDM**: Apple (`depStorage`, `mdmStorage`, `mdmAppleCommander`), Microsoft (`wstepCertManager`, `scepConfigService`), Android (`androidSvc`)
- **Infrastructure**: `mailService`, `ssoSessionStore`, `authz`, `geoIP`, `clock`, `logger`
- **Async/scheduling**: `task`, `cronSchedulesService`, `failingPolicySet`, `enrollHostLimiter`

### `ConditionalAccessMicrosoftProxy` interface
Defines interactions with the Microsoft Conditional Access compliance proxy: `Create`, `Get`, `Delete`, `SetComplianceStatus`, `GetMessageStatus`.

### `OsqueryLogger`
Holds osqueryd's `Status` and `Result` JSON loggers.

### `validationMiddleware`
Wraps `Service` to apply input validation before dispatching to service methods.

## Key Functions

| Function | Description |
|---|---|
| `NewService(...)` | Constructs and returns a `fleet.Service` wrapped in `validationMiddleware` |
| `SetActivityService(...)` | Post-construction injection of the activity write service |
| `SetACMEService(...)` | Post-construction injection of the ACME write service |
| `SetEnterpriseOverrides(...)` | Injects enterprise feature overrides |
| `LookupGeoIP(...)` | Delegates GeoIP lookup to the underlying `geoIP` provider |

## Usage Example

```go
svc, err := service.NewService(
    ctx,
    ds,
    task,
    resultStore,
    logger,
    osqueryLogger,
    cfg,
    mailService,
    clock.C,
    ssoStore,
    liveQueryStore,
    carveStore,
    failingPolicySet,
    geoIP,
    enrollHostLimiter,
    depStorage,
    mdmStorage,
    mdmPushService,
    cronSchedulesService,
    wstepCertManager,
    scepConfigService,
    digiCertService,
    conditionalAccessProxy,
    keyValueStore,
    androidSvc,
    orgLogoStore,
)
if err != nil {
    log.Fatal(err)
}

// Inject post-construction dependencies
svc.(*service.Service).SetActivityService(activitySvc)
svc.(*service.Service).SetACMEService(acmeSvc)
```
