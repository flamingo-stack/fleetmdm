Real-time WebSocket/SockJS handler for streaming distributed query campaign results to connected clients.

## Key Components

### `makeStreamDistributedQueryCampaignResultsHandler`

Factory function returning an `http.Handler` builder. Handles:

- **Origin validation** — optionally allows unsafe origins via `config.WebsocketsAllowUnsafeOrigin`
- **Version path expansion** — parses regex-based version placeholders (e.g., `{fleetversion:(?:v1|v2)}`) into literal path prefixes required by SockJS
- **SockJS session lifecycle** — authenticates the WebSocket connection, reads the `select_campaign` message, and delegates to `svc.StreamCampaignResults`

### `reVersion`

Compiled regex `\{fleetversion:\(\?:([^\}\)]+)\)\}` — extracts pipe-delimited API version alternatives from route path templates.

### WebSocket Handshake Protocol

Each session follows a strict message sequence:

1. Client sends a bearer auth token
2. Server validates via `auth.AuthViewer` and builds a viewer context
3. Client sends a `select_campaign` JSON message with `campaign_id`
4. Server streams results via `svc.StreamCampaignResults`

## Usage Example

```go
handler := makeStreamDistributedQueryCampaignResultsHandler(
    cfg,
    svc,
    logger,
)

// Register the handler with the router using a versioned path template
http.Handle(
    "/api/{fleetversion:(?:v1|latest)}/fleet/results/",
    handler("/api/{fleetversion:(?:v1|latest)}/fleet/results/"),
)
```

> The returned function must be called with the versioned path template string. It panics if the path does not contain a valid `{fleetversion:...}` placeholder.
