Brief description: Provides shared calendar utilities for Fleet MDM's cron and service packages, handling calendar event body generation, policy-based descriptions, and distributed locking constants for Google Calendar integration.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `LockKeyPrefix` / `ReservedLockKeyPrefix` / `RecentUpdateKeyPrefix` / `QueueKey` | Constants | Redis key prefixes for distributed locking and event queue management |
| `DistributedLockExpireMs` / `ReserveLockExpireMs` | Constants | Lock TTLs (20 min and 40 min) for Redis-based distributed locks |
| `RecentCalendarUpdateDuration` | Variable | Deduplication window (default 10s) to suppress redundant Google Calendar callbacks |
| `Config` | Struct | Combined calendar configuration embedding `CalendarConfig`, `GoogleCalendarIntegration`, and `ServerURL` |
| `PolicyLiteWithMeta` | Struct | Thread-safe wrapper around `fleet.PolicyLite` with a SHA-256 `Tag` for event body change detection |
| `CreateUserCalendarFromConfig` | Function | Instantiates a `fleet.UserCalendar` (Google Calendar) from a `Config` |
| `GenerateCalendarEventBody` | Function | Builds the HTML calendar event body string and returns a content tag for change detection |

## Usage Example

```go
cfg := &calendar.Config{
    CalendarConfig:             serverConfig.Calendar,
    GoogleCalendarIntegration:  integration,
    ServerURL:                  "https://fleet.example.com",
}

// Create a Google Calendar client
userCal := calendar.CreateUserCalendarFromConfig(ctx, cfg, logger)

// Generate an event body for a non-compliant host
policyMap := &sync.Map{}
body, tag := calendar.GenerateCalendarEventBody(
    ctx,
    datastore,
    "Acme Corp",
    hostPolicyData,
    policyMap,
    false, // no scheduling conflict
    logger,
)

// tag is a SHA-256 hash of the policy description+resolution,
// or "default" when using fallback text — use it to skip
// redundant Google Calendar API updates.
if tag != calendar.DefaultEventBodyTag {
    // policy-specific body was generated
}
```

## Notes

- `RecentCalendarUpdateDuration` is intentionally a `var` (not `const`) so unit tests can override it.
- `PolicyLiteWithMeta.Tag` is lazily computed on first access and protected by an embedded `sync.Mutex` to avoid redundant SHA-256 hashing under concurrent load.
