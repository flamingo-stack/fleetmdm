Implements the SCEP (Simple Certificate Enrollment Protocol) service used during MDM device enrollment to issue certificates signed by the Fleet CA.

## Key Components

| Symbol | Description |
|--------|-------------|
| `service` | Internal struct implementing `scepserver.Service`; holds a CSR signer, debug logger, and MDM asset retriever |
| `NewSCEPService` | Constructor — wires up the service with a `fleet.MDMAssetRetriever`, a `CSRSignerContext`, and a `slog.Logger` |
| `GetCACaps` | Returns the static capability string advertised to SCEP clients (SHA-256, AES, DES3, etc.) |
| `GetCACert` | Fetches the CA leaf certificate from the asset store and returns its DER-encoded bytes |
| `PKIOperation` | Core enrollment handler — parses the PKCS#7 message, decrypts the PKI envelope, signs the CSR, and returns a SCEP `CertRep` |
| `GetNextCACert` | Stub; returns `"not implemented"` |

## Usage Example

```go
import (
    scepservice "github.com/flamingo-stack/fleetmdm/server/service"
    scepserver  "github.com/flamingo-stack/fleetmdm/server/mdm/scep/server"
)

// Wire up the SCEP service during server initialization.
signer := scepserver.SomeCSRSigner(...)    // implements CSRSignerContext
svc    := scepservice.NewSCEPService(ds, signer, logger)

// svc satisfies scepserver.Service and can be mounted on the SCEP HTTP handler.
handler := scepserver.MakeHTTPHandler(svc, logger)
```

## Notes

- **BER depth guard** — `PKIOperation` calls `cryptoutil.ValidateBERDepth` before parsing to mitigate deeply-nested BER bomb payloads.
- **RSA-only CA key** — the service asserts the CA private key is `*rsa.PrivateKey`; non-RSA keys return an error.
- On CSR signing failure the service replies with a SCEP `BadRequest` `CertRep` rather than a raw error, keeping the protocol exchange well-formed for clients.
