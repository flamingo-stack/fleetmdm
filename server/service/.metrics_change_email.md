Metrics middleware wrapper for the `ChangeUserEmail` service method, recording request count and latency instrumentation via labeled dimensions.

## Key Components

- **`ChangeUserEmail`** — Wraps the underlying `Service.ChangeUserEmail` call, tracking:
  - `requestCount`: incremented on each invocation with method/error labels
  - `requestLatency`: records elapsed seconds via a deferred `time.Since` observation
  - Label set uses `"CommitEmailChange"` as the method name

## Usage Example

```go
// The metricsMiddleware is typically composed during service initialization
svc = newMetricsMiddleware(
    prometheusRequestCount,
    prometheusRequestLatency,
    svc,
)

// Calling ChangeUserEmail transparently records metrics
newEmail, err := svc.ChangeUserEmail(ctx, token)
```

## Notes

- The label key `"CommitEmailChange"` differs from the method name `ChangeUserEmail` — this is intentional and aligns with the underlying operation name tracked across the metrics pipeline
- Error presence is captured as a string boolean (`"true"`/`"false"`) in the `"error"` label dimension
- Follows the standard `metricsMiddleware` decorator pattern used throughout the service layer; see sibling files for consistent conventions
