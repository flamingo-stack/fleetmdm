This file defines the HTTP handler setup and routing for the Fleet server, including middleware configuration, Prometheus metrics instrumentation, rate limiting, and MDM service initialization.

## Key Components

- **`MakeHandler`** — Constructs the main HTTP router with middleware stack (tracing, gzip, client IP extraction, auth), attaches all Fleet API routes, and wires feature routes.
- **`PrometheusMetricsHandler`** — Wraps an `http.Handler` with Prometheus counters and histograms for request count, duration, request size, and response size.
- **`addMetrics`** — Walks the Gorilla mux router and decorates every registered route with `PrometheusMetricsHandler`.
- **`attachFleetAPIRoutes`** — Registers all versioned Fleet API routes across user-authenticated, device-authenticated, and unauthenticated endpoint groups.
- **`checkLicenseExpiration`** — Middleware that sets the `X-Fleet-License` response header when a premium license is expired.
- **`ExtraHandlerOption`** / `WithLoginRateLimit` / `WithMdmSsoRateLimit` / `WithSsoRateLimit` / `WithHTTPSigVerifier` — Functional options for configuring rate limits and HTTP signature verification on the handler.
- **`setCarveStoreInRequestContext`** — `go-kit` request function that injects the carve store into each request context.

## Usage Example

```go
handler := service.MakeHandler(
    svc,
    fleetConfig,
    logger,
    limitStore,
    redisPool,
    carveStore,
    featureRoutes,
    service.WithLoginRateLimit(throttled.PerMin(10)),
    service.WithSsoRateLimit(throttled.PerMin(5)),
)

http.ListenAndServe(":8080", handler)
```

## Notes

- Supports both OpenTelemetry (`otmiddleware`) and Elastic APM (`apmgorilla`) tracing, selected via `config.Logging.TracingEnabled` and `config.OTELEnabled()`.
- Client IP resolution respects `config.Server.TrustedProxies` for proxy-aware deployments.
- Rate limit constants (`deviceIPAllowedConsecutiveFailingRequestsCount`, etc.) are exported as package-level `const` values to enable reuse in tests.
