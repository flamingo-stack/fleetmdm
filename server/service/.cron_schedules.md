Exposes an API service method to manually trigger an ad-hoc execution of a named cron schedule, with authorization enforcement.

## Key Components

- **`TriggerCronSchedule(ctx context.Context, name string) error`** — Authorizes the caller against the `fleet.CronSchedules` resource (requiring `ActionWrite`), then delegates to the underlying `cronSchedulesService` to trigger the named schedule.

## Usage Example

```go
// Trigger a specific cron schedule by name
err := svc.TriggerCronSchedule(ctx, "vulnerabilities")
if err != nil {
    log.Fatalf("failed to trigger cron schedule: %v", err)
}
```

## Notes

- Authorization is checked before execution; unauthorized callers receive an error immediately.
- The actual scheduling logic is handled by the injected `cronSchedulesService` dependency, keeping this layer thin.
