Provides base64 encoding utilities for Fleet script payloads, enabling WAF bypass by allowing script fields in HTTP request bodies to be transmitted as base64-encoded strings.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ScriptsEncodedHeader` | `const` | HTTP header `X-Fleet-Scripts-Encoded` used to signal base64-encoded script fields |
| `decodeBase64Script` | `func` | Decodes a base64-encoded script string; passes through empty strings unchanged |
| `isScriptsEncoded` | `func` | Checks if an `*http.Request` carries the encoding header set to `"base64"` |

## Usage Example

```go
func handleScriptRequest(r *http.Request) (string, error) {
    rawScript := r.FormValue("script")

    if isScriptsEncoded(r) {
        decoded, err := decodeBase64Script(rawScript)
        if err != nil {
            return "", fmt.Errorf("decoding script payload: %w", err)
        }
        return decoded, nil
    }

    return rawScript, nil
}
```

On the client side, encode the script before sending:

```go
encoded := base64.StdEncoding.EncodeToString([]byte(scriptContent))
req.Header.Set(ScriptsEncodedHeader, "base64")
req.Body = strings.NewReader(`{"script": "` + encoded + `"}`)
```

## Notes

- The header value must be exactly `"base64"` (case-sensitive) for `isScriptsEncoded` to return `true`
- `decodeBase64Script` treats empty input as a no-op, so unset optional script fields do not require special handling by callers
- This pattern is intended for WAF environments where raw shell or PowerShell syntax in request bodies triggers security rules
