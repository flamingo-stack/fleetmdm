Provides backward-compatible type aliases, variable aliases, and helper function wrappers that re-export types and utilities from the `github.com/fleetdm/fleet/v4/client` package into the `service` package.

## Key Components

### Type Aliases
| Alias | Source |
|---|---|
| `baseClient` / `HTTPClient` / `BodyHandler` / `FileResponse` | `client.BaseClient`, `client.HTTPClient`, etc. |
| `SetupAlreadyErr` / `NotFoundErr` / `ConflictErr` / `StatusCodeErr` | Corresponding `client.*` error types |
| `setupAlreadyErr` / `notSetupErr` / `conflictErr` | Internal unexported aliases for error types |

### Error Variable Aliases
- `ErrUnauthenticated`, `ErrPasswordResetRequired`, `ErrMissingLicense`, `ErrEndUserAuthRequired` — re-exported sentinel errors from the `client` package.

### Functions
- `IsNotFoundErr(err error) bool` — public wrapper around `client.IsNotFoundErr`
- `isNotFoundErr(err error) bool` — unexported variant
- `extractServerErrorText(body io.Reader) string` — delegates to `client.ExtractServerErrorText`
- `extractServerErrorNameReason` / `extractServerErrorNameReasons` — parse structured error name/reason pairs from a response body

### Local Types
- `serverError` — JSON struct used internally for parsing Fleet API error responses (`message` + `errors[]` with `name`/`reason` fields)

## Usage Example

```go
// Check for a not-found error returned by the Fleet server
resp, err := svc.GetHost(ctx, hostID)
if isNotFoundErr(err) {
    return nil, nil // host not found, treat as empty
}

// Parse a raw error body from an HTTP response
errText := extractServerErrorText(resp.Body)

// Use the sentinel error directly
if errors.Is(err, ErrUnauthenticated) {
    return nil, ErrUnauthenticated
}
```
