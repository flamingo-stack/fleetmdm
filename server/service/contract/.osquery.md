Defines the request/response contract types for enrolling an osquery agent with the Fleet MDM server.

## Key Components

| Type | Description |
|------|-------------|
| `EnrollOsqueryAgentRequest` | Enrollment payload containing the secret, host identifier, and host details |
| `EnrollOsqueryAgentResponse` | Enrollment response returning a node key or error |
| `Error()` | Implements the `contract.Response` interface by exposing the response error |

### Fields

**`EnrollOsqueryAgentRequest`**
- `EnrollSecret` — shared secret used to authenticate the enrollment request
- `HostIdentifier` — unique identifier for the enrolling host
- `HostDetails` — nested map of host metadata (e.g., platform, OS info) passed during enrollment

**`EnrollOsqueryAgentResponse`**
- `NodeKey` — issued node key used for subsequent osquery API calls
- `Err` — enrollment error, if any

## Usage Example

```go
req := contract.EnrollOsqueryAgentRequest{
    EnrollSecret:   "super-secret-enroll-key",
    HostIdentifier: "my-macbook-pro.local",
    HostDetails: map[string]map[string]string{
        "os_version": {
            "platform": "darwin",
            "version":  "14.4.1",
        },
    },
}

resp := contract.EnrollOsqueryAgentResponse{
    NodeKey: "abc123nodekey",
}

if err := resp.Error(); err != nil {
    log.Fatalf("enrollment failed: %v", err)
}
```
