Defines the SCIM (System for Cross-domain Identity Management) response contract for the Fleet MDM integration, wrapping Fleet's `ScimDetails` with an error field.

## Key Components

- **`ScimDetailsResponse`** — Response struct embedding `fleet.ScimDetails` alongside an unexported JSON error field, used as the transport envelope for SCIM detail responses.
- **`Error() error`** — Implements the `errorer` interface, exposing any error that occurred during SCIM detail retrieval.

## Usage Example

```go
resp := contract.ScimDetailsResponse{
    ScimDetails: fleet.ScimDetails{
        // populated SCIM fields
    },
    Err: nil,
}

if err := resp.Error(); err != nil {
    // handle transport-level error
}
```

## Notes

- The `Err` field is tagged `json:"-"` so it is never serialized in API responses; errors are surfaced programmatically via the `Error()` method.
- Follows the standard Fleet endpoint response pattern where each response type implements the `errorer` interface for consistent middleware-level error handling.
