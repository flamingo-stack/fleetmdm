Metrics middleware wrapper for the `ModifyLabel` service method, instrumenting it with request count and latency observability using labeled Prometheus-style metrics.

## Key Components

- **`metricsMiddleware.ModifyLabel`** — Wraps the underlying `Service.ModifyLabel` call, recording two metrics on every invocation:
  - `requestCount` — incremented with method name and error status labels
  - `requestLatency` — records elapsed time in seconds via `Observe`

## Usage Example

```go
// metricsMiddleware is typically constructed and layered over the base service
svc = newMetricsMiddleware(svc, requestCount, requestLatency)

// ModifyLabel is called transparently; metrics are recorded automatically
label, teamIDs, err := svc.ModifyLabel(ctx, labelID, fleet.ModifyLabelPayload{
    Name: fleet.StringPtr("updated-label"),
})
```

## Metric Labels

| Label    | Value                          |
|----------|-------------------------------|
| `method` | `"ModifyLabel"`               |
| `error`  | `"true"` or `"false"`         |

## Notes

- Instrumentation uses a deferred closure to capture the final error value after the wrapped call returns, ensuring the `error` label accurately reflects success or failure.
- Follows the same middleware pattern used across other service methods in the `service` package. See related files at [`https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/).
