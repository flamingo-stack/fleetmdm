Service layer for managing script execution on Fleet-managed hosts, handling both asynchronous and synchronous run modes, result retrieval, and saved script management.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `runScriptEndpoint` | func | HTTP endpoint handler for async script execution |
| `runScriptSyncEndpoint` | func | HTTP endpoint handler for sync script execution with configurable wait timeout |
| `RunHostScript` | method | Core service method that validates, queues, and optionally polls for script execution results |
| `GetScriptIDByName` | method | Resolves a script name to its numeric ID within a team scope |
| `GetScriptResult` | method | Retrieves execution result for a given execution ID |
| `getScriptResultEndpoint` | func | HTTP endpoint handler for fetching script results |
| `setUpGetScriptResultResponse` | func | Builds a `GetScriptResultResponse` from a raw `HostScriptResult` |
| `maxPendingScripts` | const | Cap of 1000 queued scripts per host |
| `testRunScriptWaitForResult` | var | Test-only override for the sync wait timeout |

## Usage Example

```go
// Async execution — fire and forget
result, err := svc.RunHostScript(ctx, &fleet.HostScriptRequestPayload{
    HostID:         42,
    ScriptContents: "#!/bin/sh\necho hello",
}, 0) // waitForResult=0 → async
if err != nil {
    log.Fatal(err)
}
fmt.Println("Queued execution:", result.ExecutionID)

// Synchronous execution — wait up to MaxServerWaitTime
result, err = svc.RunHostScript(ctx, &fleet.HostScriptRequestPayload{
    HostID:   42,
    ScriptID: &savedScriptID,
}, scripts.MaxServerWaitTime)
if errors.Is(err, context.DeadlineExceeded) {
    fmt.Println("Host did not respond in time:", result.ExecutionID)
} else if err == nil {
    fmt.Println("Exit code:", *result.ExitCode)
}

// Look up result later
scriptResult, err := svc.GetScriptResult(ctx, result.ExecutionID)
```

## Notes

- Scripts are globally disabled when `AppConfig.ServerSettings.ScriptsDisabled` is `true`.
- Hosts enrolled via plain osquery (no `OrbitNodeKey`) cannot run scripts.
- Sync mode polls at an increasing interval (1 s → 5 s) until a result arrives or the context deadline is exceeded; on timeout the execution ID is still returned so callers can poll later.
- Team-scoped saved scripts require a Premium license.
