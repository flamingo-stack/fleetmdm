Handles the execution of live queries against Fleet-managed hosts, providing both single-query and multi-query endpoints that fan out distributed query campaigns and collect results within a configurable deadline.

## Key Components

| Symbol | Description |
|--------|-------------|
| `runLiveQueryEndpoint` | Endpoint handler for running multiple queries against multiple hosts simultaneously |
| `runOneLiveQueryEndpoint` | Endpoint handler for running a single query by ID against specified hosts |
| `runLiveQueryOnHostEndpoint` | Endpoint handler targeting a host by string identifier with a raw SQL query |
| `runLiveQueryOnHostByIDEndpoint` | Endpoint handler targeting a host by numeric ID with a raw SQL query |
| `runLiveQuery` | Core helper that invokes `RunLiveQueryDeadline` and enforces authorization checks on results |
| `RunLiveQueryDeadline` | Service method that fans out campaigns per query ID using goroutines, collects results via a channel, and respects a configurable timeout |
| `runLiveQueryOnHost` | Shared logic for host-targeted ad-hoc queries; short-circuits if host is offline |
| `FLEET_LIVE_QUERY_REST_PERIOD` | Environment variable controlling the live query timeout (default: `25s`) |

## Usage Example

```go
// Run a saved query against a set of hosts
results, respondedCount, err := svc.RunLiveQueryDeadline(
    ctx,
    []uint{42},        // query IDs
    "",                // raw SQL (empty when using saved query IDs)
    []uint{1, 2, 3},  // host IDs
    25*time.Second,
)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Responded: %d/%d hosts\n", respondedCount, 3)
for _, r := range results {
    fmt.Printf("Query %d: %d rows from %d hosts\n", r.QueryID, len(r.Results), respondedCount)
}

// Run an ad-hoc raw SQL query (query ID 0 signals raw SQL mode)
results, _, err = svc.RunLiveQueryDeadline(
    ctx,
    []uint{0},
    "SELECT * FROM os_version;",
    []uint{7},
    25*time.Second,
)
```

> **Note:** The live query timeout can be tuned via the `FLEET_LIVE_QUERY_REST_PERIOD` environment variable (e.g., `FLEET_LIVE_QUERY_REST_PERIOD=30s`). Set it below your load balancer's request timeout to avoid proxy-level failures.
