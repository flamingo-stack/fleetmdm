This file implements the service layer for Fleet MDM's Setup Experience feature, providing HTTP endpoint handlers and service methods for managing setup experience software titles and scripts during device enrollment.

## Key Components

### Request/Response Types
- `putSetupExperienceSoftwareRequest` / `putSetupExperienceSoftwareResponse` — Set software titles for setup experience
- `getSetupExperienceSoftwareRequest` / `getSetupExperienceSoftwareResponse` — List software titles with pagination
- `getSetupExperienceScriptRequest` / `getSetupExperienceScriptResponse` — Retrieve setup script (with optional download)
- `setSetupExperienceScriptRequest` / `setSetupExperienceScriptResponse` — Upload script via multipart form
- `deleteSetupExperienceScriptRequest` / `deleteSetupExperienceScriptResponse` — Remove setup script

### Service Methods (Free Tier Stubs)
All core service methods (`SetSetupExperienceSoftware`, `ListSetupExperienceSoftware`, `GetSetupExperienceScript`, `SetSetupExperienceScript`, `DeleteSetupExperienceScript`, `SetupExperienceNextStep`) return `fleet.ErrMissingLicense` — these are license-gated and implemented in the premium tier.

### Business Logic
- `isAllSetupExperienceSoftwareRequired` — Checks per-host (macOS/Windows) whether all setup experience software must be installed, consulting team or global app config
- `maybeCancelPendingSetupExperienceSteps` — Cancels pending setup experience steps when required software fails; includes Windows MDM enrollment state gating to avoid false cancellations during OOBE vs. post-OOBE enrollment

## Usage Example

```go
// Checking if all setup experience software is required for a host
required, err := svc.IsAllSetupExperienceSoftwareRequired(ctx, host)
if err != nil {
    return err
}

// Canceling pending steps if required software failed
err = svc.MaybeCancelPendingSetupExperienceSteps(ctx, host)
if err != nil {
    return err
}
```

> **Note:** The endpoint handlers (`putSetupExperienceSoftware`, `getSetupExperienceSoftware`, script CRUD) are free-tier stubs. Full functionality requires a Fleet Premium license.
