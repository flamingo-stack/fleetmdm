Handles vulnerability listing, lookup, and CVE validation within the Fleet service layer, including authorization checks and NVD details link generation.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `cveNotFoundError` | struct | Custom error for unknown CVEs; satisfies `fleet.NotFoundError` |
| `cveRegex` | var | Regex validating CVE format (`CVE-YYYY-NNNN+`, case-insensitive) |
| `freeValidVulnSortColumns` | var | Allowed sort columns for vulnerability list queries |
| `listVulnerabilitiesEndpoint` | func | HTTP endpoint handler for listing vulnerabilities with count and pagination |
| `getVulnerabilityEndpoint` | func | HTTP endpoint handler for a single CVE, returning OS versions and software |
| `Service.ListVulnerabilities` | method | Authorizes, validates, and fetches paginated vulnerability list from datastore |
| `Service.CountVulnerabilities` | method | Returns total count of vulnerabilities matching the given options |
| `Service.Vulnerability` | method | Fetches a single CVE; distinguishes unknown CVE vs. known-but-unmatched (204) |
| `Service.ListOSVersionsByCVE` | method | Returns OS versions affected by a CVE, scoped to optional team |
| `Service.ListSoftwareByCVE` | method | Returns software affected by a CVE, scoped to optional team |
| `Service.IsCVEKnownToFleet` | method | Checks whether a CVE exists in Fleet's vulnerability sources |

## Usage Example

```go
// List vulnerabilities for a team
vulns, meta, err := svc.ListVulnerabilities(ctx, fleet.VulnListOptions{
    TeamID: &teamID,
    ListOptions: fleet.ListOptions{
        OrderKey: "hosts_count",
        Page:     0,
        PerPage:  20,
    },
})

// Fetch a single CVE with OS and software breakdown
vuln, known, err := svc.Vulnerability(ctx, "CVE-2023-12345", nil, false)
if err != nil {
    // cveNotFoundError returned if CVE is unknown to Fleet
}

osList, _, err := svc.ListOSVersionsByCVE(ctx, "CVE-2023-12345", nil)
swList, _, err := svc.ListSoftwareByCVE(ctx, "CVE-2023-12345", nil)
```

> **Note:** `ListVulnerabilities` enforces `fleet.ErrMissingLicense` when `KnownExploit` filtering is requested without an EE license. The `Vulnerability` method returns `(nil, true, nil)` with HTTP 204 when a CVE is known to Fleet but matches no host software or OS versions.
