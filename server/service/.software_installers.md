Handles HTTP request decoding, encoding, and service-layer stubs for uploading and updating software installers in the Fleet MDM platform.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `uploadSoftwareInstallerRequest` | struct | Multipart form request for uploading a new software installer (file, scripts, labels, team, etc.) |
| `updateSoftwareInstallerRequest` | struct | Multipart form request for updating an existing installer by title ID; all fields optional |
| `uploadSoftwareInstallerResponse` | struct | JSON response wrapper returning a `SoftwareInstaller` or error |
| `DecodeRequest` (upload) | method | Parses multipart form for new installer uploads; validates file size and required fields |
| `DecodeRequest` (update) | method | Parses multipart form for installer updates; every field including the file is optional |
| `updateSoftwareInstallerEndpoint` | func | Transport-layer handler that maps the decoded request to `svc.UpdateSoftwareInstaller` |
| `Service.UpdateSoftwareInstaller` | method | Service stub that returns `fleet.ErrMissingLicense` (requires Fleet Premium) |

## Usage Example

```go
// Registering the update endpoint (simplified)
endpointer.NewEndpoint(
    updateSoftwareInstallerEndpoint,
    updateSoftwareInstallerRequest{},  // DecodeRequest called automatically
    encodeResponse,
    http.MethodPatch,
    "/api/v1/fleet/software/titles/{id}/package",
)

// Service call (Premium only)
installer, err := svc.UpdateSoftwareInstaller(ctx, &fleet.UpdateSoftwareInstallerPayload{
    TitleID:         42,
    TeamID:          ptr.Uint(1),
    InstallScript:   ptr.String("#!/bin/sh\ninstall.sh"),
    SelfService:     ptr.Bool(true),
    LabelsIncludeAny: []string{"macOS", "Laptops"},
})
// Returns fleet.ErrMissingLicense on Fleet Free
```

## Notes

- **File size** is capped by `installersize.FromContext`; exceeding it returns a human-readable `BadRequestError`.
- **Base64-encoded scripts** are supported (WAF bypass) when the `scripts_encoded` multipart field is set; all script fields are decoded transparently.
- Labels (`labels_include_any`, `labels_exclude_any`, `labels_include_all`) and `categories` use a three-way presence check: absent → `nil`, empty string → `[]string{}`, values → slice.
- `UpdateSoftwareInstaller` is a **license-gated stub**; the real implementation lives in the Fleet Premium service layer.
