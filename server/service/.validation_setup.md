Provides input validation logic for Fleet app configuration setup, specifically validating the server URL during new app config creation.

## Key Components

- **`validationMiddleware.NewAppConfig`** — Middleware handler that validates the `AppConfig` payload before delegating to the underlying service. Checks for a missing or invalid `server_url` and returns an `InvalidArgumentError` if validation fails.
- **`ValidateServerURL`** — Exported helper that validates a URL string by enforcing an `http://` or `https://` scheme and requiring a non-empty host.

## Usage Example

```go
// Validate a server URL directly
err := service.ValidateServerURL("https://fleet.example.com")
if err != nil {
    log.Fatalf("invalid server URL: %v", err)
}

// Invalid: missing scheme
err = service.ValidateServerURL("fleet.example.com")
// returns error: fleet.InvalidServerURLMsg

// Invalid: missing host
err = service.ValidateServerURL("https://")
// returns error: fleet.InvalidServerURLMsg
```

## Notes

- `ValidateServerURL` is intentionally minimal — a `TODO` comment marks it for more robust validation in future iterations.
- URL cleanup via `cleanupURL` (defined elsewhere) is applied before validation within `NewAppConfig`.
- Validation errors are wrapped with `ctxerr.Wrap` to preserve context-aware error propagation.
