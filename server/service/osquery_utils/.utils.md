Provides a string normalization utility for handling empty values returned by osquery queries where numeric values are expected.

## Key Components

### `EmptyToZero(val string) string`
Converts an empty string to `"0"`, leaving all other values unchanged. This prevents errors in downstream string-to-integer conversion functions (e.g., `strconv.Atoi`) that return an error when given an empty string.

## Usage Example

```go
import osquery_utils "github.com/flamingo-stack/fleetmdm/pkg/osquery_utils"

// Safely convert an osquery result field to an integer
raw := osquery_utils.EmptyToZero(row["port"]) // "" → "0"
port, err := strconv.Atoi(raw)               // no error on blank fields
```
