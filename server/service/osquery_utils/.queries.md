Provides SQL query definitions, ingestion logic, and platform-specific data collection for osquery detail queries used to populate Fleet host metadata (OS version, network interfaces, hardware info, MDM status, etc.).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DetailQuery` | struct | Core type defining a named osquery query with optional platform filters, discovery queries, and result ingestion callbacks |
| `hostDetailQueries` | `map[string]DetailQuery` | Static map of all built-in detail queries run against enrolled hosts |
| `invalidHardwareSerialRegexp` | `*regexp.Regexp` | Filters out invalid/placeholder hardware serial numbers |
| `networkInterfaceQuery` | `const string` | Parameterized SQL for resolving a host's primary IP and MAC via default route lookup |
| `linuxGigsAllDiskSpaceSubQueryConditions` | `const string` | SQL `WHERE` clause fragment filtering Linux disk mounts to physical storage only |

### `DetailQuery` Fields

| Field | Purpose |
|-------|---------|
| `Query` / `QueryFunc` | Static or dynamic SQL to execute |
| `Discovery` | Guard query; skips main query if empty result |
| `Platforms` | Restrict execution to specific OS platforms |
| `IngestFunc` | Updates `fleet.Host` fields from query rows |
| `DirectIngestFunc` | Persists results directly via `fleet.Datastore` |
| `DirectTaskIngestFunc` | Async variant of `DirectIngestFunc` using `async.Task` |
| `SoftwareOverrideMatch` / `SoftwareProcessResults` | Hooks for merging/overriding software inventory results |

### Notable Built-in Queries

- **`network_interface_unix/windows/chrome`** – resolves primary IP/MAC per platform
- **`os_version` / `os_version_windows`** – populates `host.OSVersion`, `host.Platform`, `host.Build`
- **`osquery_flags`** – captures polling intervals for online-status calculation

## Usage Example

```go
q := hostDetailQueries["os_version"]

if q.RunsForPlatform("darwin") {
    result, _ := db.Query(q.Query)
    _ = q.IngestFunc(ctx, logger, host, rows)
}
```
