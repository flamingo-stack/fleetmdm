A build-ignored code generator that produces a Markdown reference document listing all hardcoded Fleet "host vitals" detail queries (name, description, platforms, discovery SQL, and query SQL), sorted alphabetically and written to a file path provided as a CLI argument.

## Key Components

- **`main()`** — Entry point that orchestrates the full generation pipeline:
  - Calls `osquery_utils.GetDetailQueries` with a fully-featured `FleetConfig` (vulnerabilities, MDM, software inventory, host users, and Microsoft Conditional Access enabled) to retrieve all detail queries.
  - Sorts queries alphabetically by name for deterministic output.
  - Iterates over each query and writes Markdown sections covering description, platform targets, optional discovery SQL, and the query SQL (or a `<dynamically generated>` placeholder for `QueryFunc`-based queries).
  - Appends footnotes and Flamingo nav metadata tags.
  - Writes the final Markdown string to the file path passed as `os.Args[1]`.

## Usage Example

This file uses the `//go:build ignore` tag, so it is run directly with `go run` rather than compiled into any binary:

```bash
go run gen_queries_doc.go ../docs/host-vitals.md
```

The output file is a fully-formed Markdown document beginning with:

```text
<!-- DO NOT EDIT. This document is automatically generated. -->
# Understanding host vitals
...
## <query_name>
- Description: ...
- Platforms: darwin, linux, windows
- Query:
```sql
SELECT ...
```
```

> **Note:** Do not edit the generated output file manually — re-run this generator to regenerate it. The output path must be supplied as the first positional argument (`os.Args[1]`); omitting it will cause a runtime panic.
