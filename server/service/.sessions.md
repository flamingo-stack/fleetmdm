Handles user session management for the Fleet service layer, including login/logout, SSO initiation, MFA flows, and session lifecycle operations.

## Key Components

| Function/Method | Description |
|---|---|
| `GetInfoAboutSession` | Retrieves session metadata by ID with authorization check |
| `DeleteSession` | Destroys a session by ID after authorization |
| `Login` | Authenticates a user with email/password; handles MFA and SSO guards |
| `CompleteMFA` | Second-step MFA completion via token exchange |
| `Logout` / `DestroySession` | Terminates the current viewer session |
| `makeSession` | Creates a new session record in the datastore |
| `GetSessionDuration` | Returns the configured session TTL |
| `setSSOCookie` | Sets the `__Host-FLEETSSOSESSIONID` secure cookie for SSO flows |
| `initiateSSORequest` / `initiateSSOResponse` | Request/response types for starting an SSO redirect |

**Sentinel errors:**

- `sendingMFAEmail` — returned when MFA email dispatch is triggered
- `mfaNotSupportedForClient` — returned when a client cannot handle MFA verification

## Usage Example

```go
// Standard password login
user, session, err := svc.Login(ctx, "user@example.com", "password", true)
if errors.Is(err, sendingMFAEmail) {
    // Prompt user to check email for magic link
}

// Complete MFA second step
session, user, err := svc.CompleteMFA(ctx, mfaToken)

// Get session info
session, err := svc.GetInfoAboutSession(ctx, sessionID)

// Logout current user
err := svc.Logout(ctx)
```

## Notes

- Login failures are artificially delayed (~1 second) to mitigate timing attacks.
- Premium-only roles are blocked on Fleet Free during login.
- SSO users cannot authenticate via password; MFA is only triggered for non-SSO users.
- Token expiration is computed from `config.Session.Duration` if set.
