Provides Linux-specific MDM service implementations for disk encryption status reporting and profile summary aggregation.

## Key Components

### `LinuxHostDiskEncryptionStatus`
Returns the disk encryption status for a Linux host by inspecting its LUKS encryption key record. Returns one of three statuses:
- `ActionRequired` – no key found or key is empty
- `Failed` – key has a client error
- `Verified` – key exists with no errors

### `GetMDMLinuxProfilesSummary`
Returns an `MDMProfilesSummary` for Linux hosts scoped to an optional team. Since Linux has no configuration profiles, this only reports on disk encryption counts (`Verified`, `Pending`/`ActionRequired`, `Failed`). Returns an empty summary if disk encryption is not enabled.

## Usage Example

```go
// Check disk encryption status for a Linux host
status, err := svc.LinuxHostDiskEncryptionStatus(ctx, host)
if err != nil {
    // handle error
}
fmt.Println(*status.Status) // e.g., "verified", "action_required", or "failed"

// Get MDM profiles summary for a team
teamID := uint(42)
summary, err := svc.GetMDMLinuxProfilesSummary(ctx, &teamID)
if err != nil {
    // handle error
}
fmt.Printf("Verified: %d, Pending: %d, Failed: %d\n",
    summary.Verified, summary.Pending, summary.Failed)
```

## Notes

- `LinuxHostDiskEncryptionStatus` short-circuits early if the host does not support LUKS (`host.IsLUKSSupported() == false`), returning an empty struct.
- `GetMDMLinuxProfilesSummary` enforces authorization via `svc.authz.Authorize` before any data access.
