Provides debug-oriented HTTP client methods for accessing Fleet server diagnostic endpoints, including profiling, migration status, error logs, and database internals.

## Key Components

| Function | Description |
|---|---|
| `getRawBody` | Internal helper that performs an authenticated GET and returns the raw response body |
| `DebugPprof` | Fetches Go pprof profiling data from `/debug/pprof/{name}` |
| `DebugMigrations` | Retrieves database migration status from `/debug/migrations` |
| `DebugErrors` | Streams the `/debug/errors` response to an `io.Writer`, with optional flush |
| `DebugDBLocks` | Returns current database lock information from `/debug/db/locks` |
| `DebugInnoDBStatus` | Returns InnoDB engine status from `/debug/db/innodb-status` |
| `DebugProcessList` | Returns the active database process list from `/debug/db/process-list` |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Fetch heap profile
heapData, err := client.DebugPprof("heap")
if err != nil {
    log.Fatal(err)
}

// Check migration status
migrationStatus, err := client.DebugMigrations()
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Migrations applied: %v\n", migrationStatus)

// Stream errors to stdout, flushing after read
if err := client.DebugErrors(os.Stdout, true); err != nil {
    log.Fatal(err)
}

// Retrieve DB lock info
locks, err := client.DebugDBLocks()
if err != nil {
    log.Fatal(err)
}
fmt.Println(string(locks))
```

## Notes

- All methods require an authenticated `Client` instance; requests are made via `AuthenticatedDo` or `authenticatedRequest`.
- `DebugErrors` uses `io.Copy` for streaming to avoid loading large payloads entirely into memory.
