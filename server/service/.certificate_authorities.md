Defines HTTP endpoint handlers and service-layer stubs for managing Certificate Authorities (CAs) in Fleet MDM, covering CRUD operations, certificate requests, batch apply, and spec retrieval.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `listCertificateAuthoritiesEndpoint` | endpoint | Lists all CAs; delegates to `svc.ListCertificateAuthorities` |
| `getCertificateAuthorityEndpoint` | endpoint | Retrieves a single CA by ID |
| `createCertificateAuthorityEndpoint` | endpoint | Creates a new CA from a `CertificateAuthorityPayload` |
| `deleteCertificateAuthorityEndpoint` | endpoint | Deletes a CA by ID; returns HTTP 204 No Content |
| `updateCertificateAuthorityEndpoint` | endpoint | Updates an existing CA by ID |
| `requestCertificateEndpoint` | endpoint | Requests a certificate from a CA |
| `batchApplyCertificateAuthoritiesEndpoint` | endpoint | Batch-applies grouped CAs via GitOps with dry-run and skip-deletes support |
| `getCertificateAuthoritiesSpecEndpoint` | endpoint | Returns grouped CA spec, optionally including secrets |
| `(svc *Service) BatchApplyCertificateAuthorities` | method | Only fully implemented method; performs authorization and returns `ErrMissingLicense` if CAs are present |
| `(svc *Service) GetGroupedCertificateAuthorities` | method | Authorizes read/read-secrets then fetches from datastore |

> **Note:** All individual CA operations (`List`, `Get`, `New`, `Delete`, `Update`, `RequestCertificate`) skip authorization and return `fleet.ErrMissingLicense`, indicating these are premium/licensed features stubbed in the OSS tier.

## Usage Example

```go
// Batch apply CAs via GitOps (the only non-stub path in OSS)
err := svc.BatchApplyCertificateAuthorities(ctx, fleet.GroupedCertificateAuthorities{
    DigiCert: []fleet.DigiCertCA{{Name: "my-ca"}},
}, fleet.BatchApplyCertificateAuthoritiesOpts{
    DryRun:      true,
    ViaGitOps:   true,
    SkipDeletes: false,
})
// Returns fleet.ErrMissingLicense if any CAs are provided (requires Fleet Premium)

// Get grouped CA spec (reads from datastore in OSS)
grouped, err := svc.GetGroupedCertificateAuthorities(ctx, false)
```
