Provides test-helper types, constants, and an in-memory `FailingPolicySet` implementation for the Fleet service package — intentionally avoids importing the `testing` package so these types can coexist in the production binary.

## Key Components

### Constants

| Constant | Value |
|---|---|
| `TestAdminUserEmail` | `admin1@example.com` |
| `TestMaintainerUserEmail` | `user1@example.com` |
| `TestObserverUserEmail` | `user2@example.com` |

### Types

- **`TestNewScheduleFunc`** — Function signature for tests that start a cron schedule against a real datastore.
- **`HostIdentity`** — Groups SCEP storage and HTTP message signature options for host identity testing.
- **`ConditionalAccess`** — Groups SCEP storage options for conditional access testing.
- **`TestServerOpts`** — Primary configuration struct for spinning up a test Fleet service/server. Covers logging, licensing, MDM, DEP, SCEP, Redis, async tasks, feature flags, Android, ACME certs, and more.
- **`memFailingPolicySet`** — Thread-safe, in-memory implementation of `fleet.FailingPolicySet` backed by a `map[uint][]fleet.PolicySetHost`.

### Functions & Methods

- **`NewMemFailingPolicySet()`** — Constructs a new in-memory `FailingPolicySet`.
- **`AddHost(policyID, host)`** — Appends a host to a policy set.
- **`ListHosts(policyID)`** — Returns a copy of all hosts in a policy set.
- **`RemoveHosts(policyID, hosts)`** — Removes specific hosts from a policy set.
- **`RemoveSet(policyID)`** — Deletes an entire policy set.
- **`ListSets()`** — Returns all policy set IDs.

## Usage Example

```go
// Create an in-memory failing policy set for tests
fps := service.NewMemFailingPolicySet()

_ = fps.AddHost(42, fleet.PolicySetHost{ID: 1})
hosts, _ := fps.ListHosts(42)

// Configure a test server with the in-memory set
opts := &service.TestServerOpts{
    FailingPolicySet: fps,
    License:          &fleet.LicenseInfo{Tier: fleet.TierPremium},
    APNSTopic:        "com.apple.mgmt.example",
}
```

> **Note:** Types requiring `*testing.T` live in [`server/service/svctest`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/svctest), which is only imported from test code.
