HTTP middleware for pre-authenticating osquery requests via the `Authorization: NodeKey <token>` header, before the request body is read. Provides two middleware factories for standard osquery endpoints and the carve/block streaming endpoint.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `osqueryHeaderPreAuth` | `func` | Middleware that authenticates all osquery requests from the `Authorization` header; rejects with 401 if the header is absent, malformed, or the token is invalid |
| `osqueryCarveBlockHeaderPreAuth` | `func` | Specialized variant for `/api/osquery/carve/block`; authenticates via header but allows the downstream streaming parser to continue running for carve ownership verification |
| `extractNodeKeyFromHeader` | `func` | Parses the `Authorization: NodeKey <token>` header; returns `""` on any malformed input |
| `osqueryPreAuthRejections` | `metric.Int64Counter` | OTEL counter tracking rejections by `http.route` and `reason` (`missing` or `invalid_token`) |
| `osqueryHeaderAuthScheme` | `const` | Canonical scheme string `"NodeKey"` expected in the `Authorization` header |

**Rejection reasons:**

| Constant | Value | Meaning |
|---|---|---|
| `preAuthRejectMissing` | `"missing"` | Header absent or wrong scheme |
| `preAuthRejectInvalidToken` | `"invalid_token"` | Scheme matched but token failed validation |

## Usage Example

```go
// Register pre-auth middleware only when body-auth fallback is disabled.
// Guarded by the osquery.allow_body_auth_fallback flag (default: true).
if !cfg.Osquery.AllowBodyAuthFallback {
    r.Use(osqueryHeaderPreAuth(svc, logger))
    r.With(osqueryCarveBlockHeaderPreAuth(svc, logger)).
        Post("/api/osquery/carve/block", carveBlockHandler)
}
```

> **Note:** Both middlewares also call `openframePinHostTeam` to enforce multi-tenant team isolation in OpenFrame shared-mode deployments before passing the request downstream.
