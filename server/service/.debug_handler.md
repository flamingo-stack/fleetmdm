Provides HTTP handlers for Fleet's debug endpoints, requiring admin authentication via bearer token for access to profiling, database diagnostics, and trace sampler configuration.

## Key Components

- **`debugAuthenticationMiddleware`** — HTTP middleware that validates bearer tokens and enforces admin-only (`GlobalRole == RoleAdmin`) access to all debug routes.
- **`jsonHandler`** — Helper that wraps a context-aware generator function, serializes the result as indented JSON, and logs errors via `slog`.
- **`MakeDebugHandler`** — Constructs and returns the debug router with all registered endpoints, applying `debugAuthenticationMiddleware` globally.

## Registered Endpoints

| Route | Handler |
|---|---|
| `/debug/pprof/*` | Go runtime profiling via `net/http/pprof` |
| `/debug/errors` | Error store handler |
| `/debug/migrations` | DB migration status |
| `/debug/db/locks` | Active DB locks |
| `/debug/db/innodb-status` | InnoDB engine status |
| `/debug/db/process-list` | Active DB process list |
| `GET /debug/trace_sampler` | Retrieve trace sampler settings |
| `PATCH /debug/trace_sampler` | Update trace sampler settings |

## Usage Example

```go
debugHandler := MakeDebugHandler(svc, fleetConfig, logger, errorHandler, datastore)

// Mount alongside the main API router
mainMux.Handle("/debug/", debugHandler)
```

All requests must include a valid admin bearer token:

```bash
curl -H "Authorization: Bearer <admin-token>" \
  https://fleet.example.com/debug/db/locks
```

> **Note:** All debug routes are admin-only. Non-admin authenticated users receive `403 Forbidden`; unauthenticated requests receive `401 Unauthorized`.
