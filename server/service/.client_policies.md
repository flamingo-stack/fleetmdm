Client policy management methods for interacting with the Fleet API, providing CRUD operations for global and team-scoped policies.

## Key Components

| Function | Description |
|---|---|
| `CreateGlobalPolicy` | Creates a new global policy with name, query, description, resolution, and platform |
| `ApplyPolicies` | Bulk-applies a list of `PolicySpec` definitions to the Fleet instance |
| `GetPolicies` | Retrieves all policies; scoped to a team if `teamID` is provided, otherwise returns global policies |
| `DeletePolicies` | Deletes one or more policies by ID; scoped to a team or global depending on `teamID` |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Create a global policy
err := client.CreateGlobalPolicy(
    "Firewall Enabled",
    "SELECT * FROM iptables LIMIT 1;",
    "Ensure firewall is active",
    "Enable the firewall via system settings",
    "linux",
)

// Apply policy specs in bulk
specs := []*fleet.PolicySpec{
    {Name: "Disk Encrypted", Query: "SELECT 1 FROM disk_encryption;"},
}
err = client.ApplyPolicies(specs)

// Get policies for a specific team
teamID := uint(42)
policies, err := client.GetPolicies(&teamID)

// Get global policies
globalPolicies, err := client.GetPolicies(nil)

// Delete policies from a team
err = client.DeletePolicies(&teamID, []uint{1, 2, 3})
```

## Notes

- `GetPolicies` and `DeletePolicies` are team-aware: pass `nil` for `teamID` to target global policies, or a valid `*uint` to scope to a specific team.
- Both methods reuse global response types (`ListGlobalPoliciesResponse`, `DeleteGlobalPoliciesResponse`) which are structurally compatible with their team-scoped counterparts.
