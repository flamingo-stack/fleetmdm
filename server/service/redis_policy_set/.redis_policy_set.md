Redis-backed implementation of `fleet.FailingPolicySet`, storing hosts that fail fleet policies using Redis sets with cursor-based scanning to avoid blocking operations.

## Key Components

| Symbol | Description |
|---|---|
| `redisFailingPolicySet` | Core struct holding a `fleet.RedisPool` and optional test key prefix |
| `NewFailing(pool)` | Constructor for production use |
| `NewFailingTest(t, pool)` | Constructor for tests; namespaces keys by test name to avoid conflicts |
| `ListSets()` | Returns all policy IDs tracked via `SMEMBERS` on the set-of-sets key |
| `AddHost(policyID, host)` | Adds a host entry to a policy's set, then registers the policy in the set-of-sets |
| `ListHosts(policyID)` | Returns all hosts in a policy set using cursor-based `SSCAN` |
| `RemoveHosts(policyID, hosts)` | Removes specific hosts from a policy set via `SREM` |
| `RemoveSet(policyID)` | Removes a policy from the set-of-sets, then deletes the policy set key |

**Redis Key Schema:**

| Key | Pattern |
|---|---|
| Policy set | `policies:failing:<policyID>` |
| Set-of-sets | `policies:failing_sets` |

Host entries are stored as `"<hostID>,<hostname>"` strings.

## Usage Example

```go
pool := redis.NewPool(redisConfig)

// Production
ps := redis_policy_set.NewFailing(pool)

// Add a failing host to policy 42
err := ps.AddHost(42, fleet.PolicySetHost{ID: 7, Hostname: "laptop-01"})

// List all hosts failing policy 42
hosts, err := ps.ListHosts(42)

// List all policies with failures
policyIDs, err := ps.ListSets()

// Remove specific hosts from policy 42
err = ps.RemoveHosts(42, hosts)

// Remove the entire policy set
err = ps.RemoveSet(42)

// Testing
ps = redis_policy_set.NewFailingTest(t, pool)
```

> **Note:** `AddHost` and `RemoveSet` use separate connections per operation intentionally — this supports Redis Cluster mode where the policy set key and set-of-sets key may reside on different nodes.
