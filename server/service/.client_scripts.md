Provides Fleet MDM client methods for executing scripts on hosts and managing saved/setup experience scripts via the Fleet API.

## Key Components

| Function | Description |
|---|---|
| `RunHostScriptSync` | Executes a script on a host and polls until completion, returning the full result |
| `RunHostScriptAsync` | Submits a script execution request and returns immediately with the execution ID |
| `runHostScript` | Internal helper that POSTs the script payload and handles HTTP error responses |
| `pollForResult` | Polls `GET /api/latest/fleet/scripts/results/{id}` every 5 seconds until `ExitCode` is non-nil |
| `ApplyNoTeamScripts` | Batch-applies a list of scripts to hosts in no team |
| `uploadMacOSSetupScript` | Uploads a setup experience script via multipart form POST |
| `deleteMacOSSetupScript` | Deletes the setup experience script for a given team |
| `ListScripts` | Returns all saved scripts matching a query |
| `GetScriptContents` | Fetches the raw bytes of a saved script by ID |
| `GetSetupExperienceScript` | Retrieves the setup experience script for a given team |

## Usage Example

```go
// Run a script synchronously and wait for result
result, err := client.RunHostScriptSync(
    hostID,
    []byte("#!/bin/sh\necho hello"),
    "greet.sh",
    0, // teamID (0 = no team)
)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Exit code: %d, Output: %s\n", *result.ExitCode, result.Output)

// Run asynchronously and retrieve execution ID
pending, err := client.RunHostScriptAsync(hostID, scriptBytes, "deploy.sh", teamID)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Execution ID:", pending.ExecutionID)

// List saved scripts for a team
scripts, err := client.ListScripts("team_id=1")
```

## Notes

- `pollForResult` uses a fixed `pollWaitTime` of 5 seconds between retries and exits when `ExitCode` is non-nil.
- `runHostScript` translates HTTP error codes (`403`, `504`, `402`) into descriptive Fleet-specific error messages.
- Setup experience script endpoints (`/api/latest/fleet/setup_experience/script`) require Apple MDM to be enabled.
