Handles the creation of distributed query campaigns for live querying against targeted Fleet hosts, supporting targeting by IDs or by human-readable identifiers (hostnames, labels, UUIDs).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NewDistributedQueryCampaign` | Service method | Creates a campaign from a raw SQL query or saved query ID, targeting hosts/labels/teams by numeric ID |
| `NewDistributedQueryCampaignByIdentifiers` | Service method | Creates a campaign by resolving human-readable host identifiers and label names to IDs, then delegates to `NewDistributedQueryCampaign` |
| `createDistributedQueryCampaignEndpoint` | HTTP handler | REST endpoint handler for `/api/.../queries/run` |
| `createDistributedQueryCampaignByIdentifierEndpoint` | HTTP handler | REST endpoint handler for identifier-based targeting |

## Usage Example

```go
// Create a campaign targeting specific hosts and a label by ID
campaign, err := svc.NewDistributedQueryCampaign(
    ctx,
    "SELECT * FROM os_version;",
    nil, // no saved query ID
    fleet.HostTargets{
        HostIDs:  []uint{1, 2, 3},
        LabelIDs: []uint{5},
        TeamIDs:  []uint{},
    },
)

// Create a campaign using human-readable identifiers
campaign, err := svc.NewDistributedQueryCampaignByIdentifiers(
    ctx,
    "SELECT * FROM uptime;",
    nil,
    []string{"hostname-1", "abc123-uuid"}, // hostnames or UUIDs
    []string{"macOS hosts"},               // label names
)
```

## Notes

- Requires an active viewer context; returns `fleet.ErrNoContext` if absent.
- Ad-hoc queries (no `queryID`) trigger authorization via `fleet.ActionRunNew` and are persisted as unsaved queries before the campaign is created.
- Returns a `BadRequestError` if the resolved target set contains zero hosts.
- Campaign metrics (total host count) are recorded post-creation for the activity feed.
