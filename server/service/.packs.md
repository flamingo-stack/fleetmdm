Service layer implementation for Fleet osquery pack management, providing CRUD operations (get, create, modify, list, delete) and spec application for query packs with authorization enforcement and activity logging.

## Key Components

| Component | Description |
|---|---|
| `packResponse` | Response DTO extending `fleet.Pack` with query count, total host count, and target IDs |
| `userIsGitOpsOnly` | Helper that checks if the current user holds exclusively the GitOps role |
| `packResponseForPack` | Builds a `packResponse` by fetching scheduled queries and host target metrics |
| `GetPack` | Retrieves a single pack by ID (requires read authorization) |
| `NewPack` | Creates a new pack from a `PackPayload`, validates input, and logs activity |
| `ModifyPack` | Updates an existing pack; respects `EditablePackType()` constraints |
| `ListPacks` | Lists all non-system packs with pagination options |
| `DeletePack` | Deletes a pack by name, guarding against system/team pack deletion |
| `DeletePackByID` | Deletes a pack by numeric ID with the same guard logic |

## Usage Example

```go
// Create a new pack
payload := fleet.PackPayload{
    Name:        ptr.String("Compliance Pack"),
    Description: ptr.String("Daily compliance checks"),
    Platform:    ptr.String("linux"),
    HostIDs:     &[]uint{1, 2, 3},
}
pack, err := svc.NewPack(ctx, payload)

// Retrieve a pack with full response details
pack, err := svc.GetPack(ctx, packID)

// Modify an existing pack
updated, err := svc.ModifyPack(ctx, packID, fleet.PackPayload{
    Disabled: ptr.Bool(true),
})

// Delete by name or ID
err = svc.DeletePack(ctx, "Compliance Pack")
err = svc.DeletePackByID(ctx, packID)

// List all user-defined packs
packs, err := svc.ListPacks(ctx, fleet.PackListOptions{
    ListOptions:        fleet.ListOptions{Page: 0, PerPage: 20},
    IncludeSystemPacks: false,
})
```

> **Note:** All mutations enforce `fleet.ActionWrite` authorization and emit an activity record. GitOps-only users are permitted to write packs even though they cannot read host targets, handled gracefully in `packResponseForPack`.
