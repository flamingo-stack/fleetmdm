Provides Fleet MDM client methods for managing software inventory, installers, icons, and VPP apps across hosts and teams.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ListSoftwareVersions` | Method | Lists software versions installed on hosts |
| `ListSoftwareTitles` | Method | Lists software titles with filter query support |
| `GetSetupExperienceSoftware` | Method | Fetches software available during device setup experience |
| `GetSoftwareTitleByID` | Method | Retrieves a single software title by ID, optionally scoped to a team |
| `GetSoftwareTitleIcon` | Method | Downloads the icon bytes for a software title |
| `ApplyNoTeamSoftwareInstallers` | Method | Batch-applies software installers to the no-team scope |
| `applySoftwareInstallers` | Method | Internal polling loop for async batch installer processing |
| `UploadIcon` / `UpdateIcon` / `DeleteIcon` | Methods | Manage software title icons via multipart PUT/DELETE |
| `ErrIconBytesMissing` | Error | Sentinel for missing server-side icon bytes (HTTP 409) |
| `InstallSoftware` | Method | Triggers on-demand installation on a specific host |
| `GetFleetMaintainedApp` / `ListFleetMaintainedApps` | Methods | Fetch Fleet-maintained app catalog entries |
| `ListSelfServiceCategories` / `DeleteSelfServiceCategory` | Methods | Manage self-service software categories per team |
| `matchPackageIcons` | Function | Internal helper to hydrate batch responses with local icon metadata |

## Usage Example

```go
client := service.NewClient(...)

// List all software titles for a team
titles, err := client.ListSoftwareTitles("fleet_id=1&per_page=50")

// Batch-apply software installers
packages, deleted, categories, err := client.ApplyNoTeamSoftwareInstallers(
    []fleet.SoftwareInstallerPayload{{URL: "https://example.com/app.pkg"}},
    fleet.ApplySpecOptions{DryRun: false},
)

// Upload an icon
f, _ := os.Open("icon.png")
err = client.UploadIcon(1, 42, "icon.png", f)

// Trigger install on a host
err = client.InstallSoftware(hostID, softwareTitleID)
```

> **Note:** `applySoftwareInstallers` polls the batch endpoint every second until the job reaches `Completed` or `Failed` status. Callers should ensure appropriate timeouts at a higher level.
