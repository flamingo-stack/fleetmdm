Utility functions for validating and loading labels and hosts before associating them with Fleet entities such as policies or queries.

## Key Components

| Function | Description |
|---|---|
| `loadLabelsFromNames` | Fetches labels from the datastore by name using a team-scoped filter, returning an error if any label is not found |
| `verifyHostsToAssociate` | OpenFrame fork-only helper that deduplicates host IDs and validates all specified hosts exist before association |
| `verifyLabelsToAssociate` | Deduplicates label names, enforces authentication, scopes to global labels for no-team entities, and delegates to `loadLabelsFromNames` for existence validation |

## Usage Example

```go
// Validate labels before associating with a policy
err := verifyLabelsToAssociate(ctx, ds, policy.TeamID, []string{"macOS", "production"}, currentUser)
if err != nil {
    return err
}

// Validate hosts before associating with a query (OpenFrame fork)
err = verifyHostsToAssociate(ctx, ds, []uint{1, 2, 3})
if err != nil {
    return err
}

// Load labels directly with a team filter
labelsMap, err := loadLabelsFromNames(ctx, ds, []string{"macOS"}, fleet.TeamFilter{User: user, TeamID: ptr.Uint(1)})
if err != nil {
    return err
}
```

## Notes

- `verifyHostsToAssociate` is an **OpenFrame-only addition** (see [`openframe/docs/architecture-host-assignments.md`](https://github.com/flamingo-stack/fleetmdm/blob/main/openframe/docs/architecture-host-assignments.md)), not present in upstream Fleet.
- No-team/all-teams entities (`entityTeamID == nil`) are automatically scoped to global labels only (`TeamID = 0`).
- Both verify functions silently no-op when given empty slices, making them safe to call unconditionally.
