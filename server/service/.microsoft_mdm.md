Handles the Microsoft MDM (Mobile Device Management) enrollment and management protocol implementation, providing SOAP/SyncML message parsing, response generation, and enrollment workflow orchestration for Windows devices.

## Key Components

### Request/Response Containers

| Type | Purpose |
|------|---------|
| `SoapRequestContainer` | Decodes incoming SOAP XML enrollment requests |
| `SoapResponseContainer` | Marshals and renders SOAP XML responses |
| `SyncMLReqMsgContainer` | Decodes SyncML management protocol messages |
| `SyncMLResponseMsgContainer` | Marshals and renders SyncML responses |
| `MDMWebContainer` | Handles HTML web enrollment container requests |
| `MDMAuthContainer` | Handles MDM authentication responses |

### Response Builders

- **`NewDiscoverResponse`** — Constructs the MS-MDE2 discovery response with auth policy and enrollment URLs
- **`NewGetPoliciesResponse`** — Builds the MS-XCEP certificate policy response with key length, validity, and renewal periods
- **`NewRequestSecurityTokenResponseCollection`** — Generates the WS-Trust security token response containing the provisioned MDM certificate

### Utilities

- **`getUtcTime(minutes int)`** — Returns a UTC timestamp offset by the given number of minutes, formatted for MDM protocol use
- `devDetailSMBIOSSerialNumberURI` — OMA-DM LocURI constant for fetching the device SMBIOS serial number

## Usage Example

```go
// Build a discovery response for the enrollment endpoint
discoverResp, err := NewDiscoverResponse(
    "Federated",
    "https://fleet.example.com/api/mdm/microsoft/discovery",
    "https://fleet.example.com/api/mdm/microsoft/enroll",
)
if err != nil {
    return err
}

// Build a certificate policies response
policiesResp, err := NewGetPoliciesResponse("2048", "31536000", "2592000")
if err != nil {
    return err
}

// Render a SOAP response
container := SoapResponseContainer{Data: &soapResp}
container.HijackRender(ctx, w)
```
