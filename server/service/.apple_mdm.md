Provides Apple MDM service layer functionality for Fleet, handling configuration profiles, MDM commands, declarative device management (DDM), and Apple-specific enrollment flows.

## Key Components

### Request/Response Types
- `getMDMAppleCommandResultsRequest/Response` — Retrieves results for a specific MDM command by UUID
- `listMDMAppleCommandsRequest/Response` — Lists MDM Apple commands with pagination/filtering
- `newMDMAppleConfigProfileRequest/Response` — Uploads a new Apple configuration profile via multipart form

### Service Methods
- `GetMDMAppleCommandResults` — Fetches command results with team-based authorization checks
- `ListMDMAppleCommands` — Lists MDM commands, filtering out teams the viewer lacks access to
- `NewMDMAppleConfigProfile` — Creates a new `.mobileconfig`, `.json`, or `.xml` configuration profile for a team

### Constants & Variables
- `SameProfileNameUploadErrorMsg` — User-facing error for duplicate profile `PayloadDisplayName`
- `fleetVarsSupportedInAppleConfigProfiles` — Fleet variables valid in Apple config profiles (e.g., NDES SCEP, host identity fields)
- `fleetVarsSupportedInDDMDeclarations` — Fleet variables valid in Apple DDM declarations

## Usage Example

```go
// Upload a new Apple configuration profile
profileID, err := svc.NewMDMAppleConfigProfile(
    ctx,
    teamID,         // uint: 0 = no team
    profileData,    // []byte: raw .mobileconfig / .json / .xml content
    nil,            // labels
    fleet.LabelsIncludeAll,
    nil,
)

// Retrieve MDM command results
results, err := svc.GetMDMAppleCommandResults(ctx, "command-uuid-here")

// List recent MDM commands with pagination
commands, err := svc.ListMDMAppleCommands(ctx, &fleet.MDMCommandListOptions{
    ListOptions: fleet.ListOptions{PerPage: 50},
})
```

## Notes
- Authorization is enforced per-team; observers can view commands but not modify them
- Profile uploads use multipart form decoding; the `fleet_id` field targets a specific team
