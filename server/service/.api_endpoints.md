Defines the HTTP endpoint handler and service method for listing API endpoints in the Fleet MDM service layer.

## Key Components

- **`listAPIEndpointsRequest`** — Empty request struct for the list API endpoints route.
- **`listAPIEndpointsResponse`** — Response struct containing a slice of `fleet.APIEndpoint` and an error field, with JSON serialization support.
- **`listAPIEndpointsEndpoint`** — Transport-layer handler that wires the HTTP request to the service method and returns the response.
- **`Service.ListAPIEndpoints`** — Service implementation that skips authorization and returns `fleet.ErrMissingLicense`, indicating this is a **premium-only feature** unavailable in the open-source build.

## Usage Example

```go
// Calling the service method directly (e.g., in a licensed implementation)
endpoints, err := svc.ListAPIEndpoints(ctx)
if err != nil {
    // Returns fleet.ErrMissingLicense on non-premium builds
    log.Fatal(err)
}
for _, ep := range endpoints {
    fmt.Println(ep)
}
```

## Notes

- The `listAPIEndpointsEndpoint` function follows Fleet's standard endpoint pattern, accepting a generic `request any` and returning a `fleet.Errorer`.
- Authorization is explicitly skipped via `svc.authz.SkipAuthorization(ctx)` — the license check serves as the access gate instead.
- A premium implementation would override `ListAPIEndpoints` and return actual endpoint data.
