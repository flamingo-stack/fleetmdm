Service layer implementation for Fleet's legacy 2017 packs scheduled query API, providing CRUD operations for queries associated with query packs.

## Key Components

| Function | Description |
|---|---|
| `GetScheduledQueriesInPack` | Lists all scheduled queries within a pack, including execution stats |
| `ScheduleQuery` | Creates a new scheduled query entry in a pack with interval validation |
| `GetScheduledQuery` | Retrieves a single scheduled query by ID |
| `ModifyScheduledQuery` | Updates fields on an existing scheduled query |
| `DeleteScheduledQuery` | Removes a scheduled query from a pack |
| `unauthorizedScheduleQuery` | Internal helper that handles name auto-generation and datastore write |
| `unauthorizedModifyScheduledQuery` | Internal helper that applies partial payload updates to a scheduled query |
| `findNextNameForQuery` | Recursively appends `-1` suffixes to a query name until it is unique within the pack |

All operations authorize against `fleet.Pack` (read or write), mirroring pack-level permissions.

## Usage Example

```go
// Schedule a query in a pack
scheduled, err := svc.ScheduleQuery(ctx, &fleet.ScheduledQuery{
    PackID:   42,
    QueryID:  7,
    Interval: 3600,        // seconds; must be 1–MaxScheduledQueryInterval
    Snapshot: boolPtr(true),
    Platform: strPtr("linux"),
})

// List all scheduled queries in the pack
queries, err := svc.GetScheduledQueriesInPack(ctx, packID, fleet.ListOptions{})

// Modify an existing scheduled query
updated, err := svc.ModifyScheduledQuery(ctx, scheduledQueryID, fleet.ScheduledQueryPayload{
    Interval: uintPtr(7200),
})

// Remove a scheduled query
err = svc.DeleteScheduledQuery(ctx, scheduledQueryID)
```

> **Note:** This file supports Fleet's legacy 2017 packs functionality. Scheduled queries inherit pack-level authorization — any principal with pack read/write access can manage scheduled queries within that pack.
