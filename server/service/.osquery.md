Handles osquery agent authentication, enrollment, and client configuration for Fleet MDM. It manages host identity verification, node key generation, and host detail ingestion during the osquery enrollment lifecycle.

## Key Components

| Function/Method | Description |
|---|---|
| `AuthenticateHost` | Validates a host's node key, verifies host identity certificates via HTTP signatures, and records last-seen timestamps |
| `EnrollOsquery` | Enrolls a new osquery agent: verifies enroll secret, checks host limits, generates node keys, and ingests initial host details |
| `enrollAgentEndpoint` | HTTP endpoint handler that wraps `EnrollOsquery` for the transport layer |
| `getHostIdentifier` | Resolves the host identifier based on the configured strategy (`provided`, `instance`, `uuid`, `hostname`) |
| `serialUpdateHost` | Background goroutine that persists host updates asynchronously with a 30-second timeout |
| `debugEnabledForHost` | Checks whether debug logging is enabled for a specific host ID via app config |
| `newOsqueryError` / `newOsqueryErrorWithInvalidNode` | Constructs typed osquery errors, with the invalid-node variant signaling re-enrollment |

## Usage Example

```go
// Authenticate an existing host by node key
host, debugEnabled, err := svc.AuthenticateHost(ctx, nodeKey)
if err != nil {
    // handle authentication failure (e.g., invalid node key triggers re-enrollment)
}

// Enroll a new osquery agent
nodeKey, err := svc.EnrollOsquery(ctx, enrollSecret, hostIdentifier, hostDetails)
if err != nil {
    // handle enrollment failure
}
```

## Notes

- **OpenFrame shared-mode** (`mysql-multitenancy`): enrollment enforces a team-scoped context when `OPENFRAME_SHARED_MODE` is active — enroll secrets without a team ID are rejected.
- Host detail ingestion (`os_version`, `osquery_info`, `system_info`) occurs at enrollment time; persistence is either immediate or deferred via `DeferredSaveHost`.
- Identity certificate validation uses HTTP message signatures (`httpsig`) to prevent spoofing.
