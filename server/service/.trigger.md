Handles HTTP endpoint logic for manually triggering a named cron schedule in the Fleet service.

## Key Components

- **`triggerRequest`** — Request struct with an optional `name` query parameter identifying the cron schedule to trigger.
- **`triggerResponse`** — Response struct that surfaces any service-layer error as a JSON `error` field.
- **`triggerEndpoint`** — Handler function that authenticates the caller via `svc.AuthenticatedUser`, then invokes `svc.TriggerCronSchedule` with the provided schedule name.

## Usage Example

```go
// Registered as a Fleet endpoint, called with an authenticated HTTP request:
// GET /api/v1/fleet/trigger?name=my_cron_job

resp, err := triggerEndpoint(ctx, &triggerRequest{Name: "my_cron_job"}, svc)
if err != nil {
    log.Fatal(err)
}
if trigResp, ok := resp.(triggerResponse); ok && trigResp.Err != nil {
    log.Printf("trigger failed: %v", trigResp.Err)
}
```

## Notes

- Authentication is enforced before the trigger is executed; unauthenticated requests return an error in the response body rather than a hard error return.
- The `name` query parameter is optional at the struct level, but downstream behavior in `TriggerCronSchedule` determines whether a missing name is acceptable.
