Provides OpenTelemetry HTTP instrumentation helpers for wrapping Fleet HTTP handlers with distributed tracing spans.

## Key Components

| Function | Description |
|---|---|
| `WrapHandler` | Wraps an HTTP handler with OTEL tracing using a fixed route string |
| `WrapHandlerDynamic` | Wraps an HTTP handler with OTEL tracing using the request's actual URL path |

Both functions are no-ops when `cfg.OTELEnabled()` returns `false`, returning the original handler unchanged.

## Usage Example

```go
// Fixed route — span named "GET /healthz"
http.Handle("/healthz", otel.WrapHandler(healthzHandler, "/healthz", cfg))

// Dynamic route — span named using actual request path, e.g. "GET /assets/app.js"
http.Handle("/assets/", otel.WrapHandlerDynamic(assetsHandler, cfg))
```

## Span Naming

Spans follow the `"{METHOD} {route}"` convention:

- `WrapHandler` → `"GET /healthz"` (fixed at wrap time)
- `WrapHandlerDynamic` → `"GET /assets/app.js"` (resolved per request from `r.URL.Path`)

## Notes

- Uses [`otelhttp`](https://pkg.go.dev/go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp) from the OpenTelemetry Go contrib library
- `WrapHandlerDynamic` creates a new instrumented handler per request, which is necessary to capture the dynamic path in the span name
- Fleet config controls OTEL activation via `cfg.OTELEnabled()`; see [`config.FleetConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/config/config.go)
