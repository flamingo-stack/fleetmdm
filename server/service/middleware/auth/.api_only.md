Implements an endpoint middleware that enforces access control for API-only users with configured endpoint restrictions, ensuring they can only access explicitly permitted routes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `RouteTemplateRequestFunc` | `var` | Re-exported alias of the platform `eu.RouteTemplateRequestFunc` for capturing mux route templates into context |
| `APIOnlyEndpointCheck` | `func` | Public middleware constructor wiring the catalog check against `apiendpoints.IsInCatalog` |
| `apiOnlyEndpointCheck` | `func` | Testable inner implementation accepting an injectable `isInCatalog` predicate |
| `permissionDenied` | `func` | Helper that marks the authz context as checked and returns a 403 `PermissionError` |

## Behavior

The middleware is a no-op for:
- Non-API-only users
- Requests with no `Viewer` in context
- API-only users with **no** endpoint restrictions (granted full route access)

For API-only users **with** restrictions, two ordered checks apply:

1. The resolved route fingerprint must exist in the API endpoint catalog → 403 if absent
2. The fingerprint must match one of the user's allowed endpoints → 403 if not found

## Usage Example

```go
// Wire the middleware inside AuthenticatedUser, and register
// RouteTemplateRequestFunc as a ServerBefore option on the transport.
import (
    "github.com/flamingo-stack/fleetmdm/server/authz/auth"
    kithttp "github.com/go-kit/kit/transport/http"
)

server := kithttp.NewServer(
    auth.APIOnlyEndpointCheck(myEndpoint),
    decodeRequest,
    encodeResponse,
    kithttp.ServerBefore(auth.RouteTemplateRequestFunc),
)
```

> **Note:** `APIOnlyEndpointCheck` must be composed **inside** `AuthenticatedUser` so a `Viewer` is already present in context when this middleware executes.
