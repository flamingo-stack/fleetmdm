Provides HTTP middleware for enriching request contexts with authentication, viewer identity, and logging metadata for Fleet service handlers.

## Key Components

- **`SetRequestsContexts`** — Returns a `kithttp.RequestFunc` that extracts a bearer token from the incoming request, resolves it to an authenticated viewer via `AuthViewer`, and injects the viewer, error context provider, user emailer, logging context, and start time into the request context.
- **`SetRequestsContextMiddleware`** — Standard `http.Handler` middleware wrapper that calls `kithttp.PopulateRequestContext` followed by `SetRequestsContexts`, passing the enriched context to the next handler.

## Usage Example

```go
// As a go-kit RequestFunc (transport layer)
httpHandler := kithttp.NewServer(
    endpoint,
    decodeRequest,
    encodeResponse,
    kithttp.ServerBefore(auth.SetRequestsContexts(svc)),
)

// As a standard net/http middleware
mux := http.NewServeMux()
mux.Handle("/api/", myHandler)

http.ListenAndServe(":8080", auth.SetRequestsContextMiddleware(svc, mux))
```

## Context Values Injected

| Context Key | Value |
|---|---|
| `token` | Raw bearer token string |
| `viewer` | Authenticated `fleet.Viewer` (if token valid) |
| `ctxerr` provider | Viewer for error enrichment |
| `logging` user emailer | Viewer email for audit logs |
| `logging` context | Fresh `LoggingContext` struct |
| `logging` start time | Request start timestamp |
