Middleware package that provides endpoint middleware functions to verify that platform-specific MDM solutions (Apple, Windows, Android) are properly configured before a request reaches its handler.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Middleware` | struct | Wraps a `fleet.Service` instance to provide MDM verification middleware |
| `NewMDMConfigMiddleware` | constructor | Creates a new `Middleware` instance |
| `VerifyAppleMDM()` | method | Blocks all requests if Apple MDM is not configured |
| `VerifyAppleMDMOnMacOSHosts()` | method | Conditionally verifies Apple MDM only when the requesting host is an Apple platform |
| `VerifyWindowsMDM()` | method | Blocks all requests if Windows MDM is not configured |
| `VerifyAndroidMDM()` | method | Blocks all requests if Android MDM is not configured |
| `VerifyAnyMDM()` | method | Blocks all requests if no MDM solution is configured |

## Usage Example

```go
// Initialize the middleware with a fleet service
mdmMiddleware := mdmconfigured.NewMDMConfigMiddleware(svc)

// Wrap an endpoint to require Apple MDM configuration
appleEndpoint := mdmMiddleware.VerifyAppleMDM()(myAppleEndpoint)

// Use conditional Apple MDM check for endpoints shared with Linux hosts
sharedEndpoint := mdmMiddleware.VerifyAppleMDMOnMacOSHosts()(mySharedEndpoint)

// Require Windows MDM configuration
windowsEndpoint := mdmMiddleware.VerifyWindowsMDM()(myWindowsEndpoint)

// Require at least one MDM to be configured
anyMDMEndpoint := mdmMiddleware.VerifyAnyMDM()(myGenericEndpoint)
```

## Notes

- `VerifyAppleMDMOnMacOSHosts` is intended for endpoints shared between Apple and Linux hosts. It reads the host from the request context and only enforces the Apple MDM check for Apple platforms, avoiding unnecessary failures for Linux clients.
- All middleware methods follow the standard `go-kit` `endpoint.Middleware` pattern, making them composable with other middleware.
