Foundational package constants for external service communication, defining retry behavior and backoff timing for REST API interactions.

## Key Components

| Constant | Value | Purpose |
|---|---|---|
| `maxRetries` | `5` | Maximum number of retry attempts |
| `retryBackoff` | `300ms` | Base delay between retry attempts |
| `maxWaitForRetryAfter` | `10s` | Maximum wait time when honoring `Retry-After` headers |

## Usage Example

These constants are package-internal and consumed by retry logic within `externalsvc`:

```go
// Internal usage pattern (within the externalsvc package)
for attempt := 0; attempt < maxRetries; attempt++ {
    resp, err := client.Do(req)
    if err == nil {
        return resp, nil
    }
    time.Sleep(retryBackoff)
}
```

## Notes

- All constants are unexported, scoping retry policy to the `externalsvc` package internals.
- `maxWaitForRetryAfter` caps respect for server-side `Retry-After` response headers, preventing indefinite blocking on rate-limited APIs.
