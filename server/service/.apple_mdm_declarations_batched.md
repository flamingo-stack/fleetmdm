Implements cursor-based batched reconciliation of Apple Declarative Device Management (DDM) declarations across managed hosts, processing up to 5,000 hosts per cron tick.

## Key Components

- **`reconcileAppleDeclarationsBatchSize`** — Configurable batch limit (default `5000`) controlling how many hosts are processed per tick, tunable independently from profile reconciliation.
- **`ReconcileAppleDeclarationsBatched`** — Main entry point that orchestrates the full reconciliation pass: loads a host snapshot, computes declaration deltas, persists changes, and dispatches `DeclarativeManagement` MDM commands to affected hosts.

## Usage Example

```go
err := service.ReconcileAppleDeclarationsBatched(
    ctx,
    datastore,
    mdmCommander,
    slogLogger,
)
if err != nil {
    log.Fatalf("declaration reconcile failed: %v", err)
}
```

## How It Works

1. **Guard** — Exits early if MDM is not enabled/configured.
2. **Cursor read** — Fetches the current pagination cursor from the datastore; resets to `""` on failure.
3. **Snapshot load** — Calls `GetAppleDeclarationReconcileSnapshot` to retrieve hosts, all declarations, host label memberships, and current declaration state in a single round-trip.
4. **Cursor advance** — On a full batch (`len(hosts) >= batchSize`), the cursor advances to the last host UUID; on a partial batch the cursor resets, signaling a completed pass. Advancement is deferred and skipped if the tick errors.
5. **Delta computation** — Groups declarations by team, flags broken-label declarations, then delegates to `apple_mdm.ComputeDeclarationDeltas` (shared with profile reconciliation) to produce the minimal set of row changes.
6. **Persist** — Bulk-upserts changed `host_mdm_apple_declarations` rows.
7. **Resync** — Fetches and clears any hosts that requested a forced resync, merging and deduplicating them into the changed-host set.
8. **Command dispatch** — Issues a single `DeclarativeManagement` MDM command covering all changed host UUIDs.
