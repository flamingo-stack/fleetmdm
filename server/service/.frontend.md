Handles serving the Fleet MDM frontend application, including the React SPA, static assets, and the OTA (Over-The-Air) BYOD device enrollment flow with optional IdP SSO authentication.

## Key Components

| Function | Description |
|---|---|
| `ServeFrontend` | Returns an `http.Handler` that renders the React SPA template with URL prefix, server type, and CSP nonce |
| `ServeEndUserEnrollOTA` | Handles the `/enroll` BYOD enrollment flow for iOS/Android devices, including IdP SSO redirect and cookie-based auth state |
| `ServeStaticAssets` | Serves gzip-compressed static JS/CSS assets from embedded bindata with browser security headers |
| `renderEnrollPage` | Renders the `enroll-ota.html` template with enrollment URL, MDM config flags, and error messaging |
| `generateEnrollOTAURL` | Builds the OTA enrollment profile URL (`/api/v1/fleet/enrollment_profiles/ota`) with the enroll secret as a query param |
| `initiateOTAEnrollSSO` | Triggers MDM SSO via `fleet.Service.InitiateMDMSSO`, sets a session cookie, and redirects to the IdP |
| `newBinaryFileSystem` | Creates an `assetfs.AssetFS` backed by embedded `bindata` assets at a given prefix |

## Usage Example

```go
// Serve the React frontend SPA
mux.Handle("/", ServeFrontend("/", false, logger, true))

// Serve BYOD OTA enrollment page (handles SSO redirect if IdP auth is required)
mux.Handle("/enroll", ServeEndUserEnrollOTA(svc, "/", ds, logger, true))

// Serve static assets with gzip compression and CSP headers
mux.Handle("/assets/", ServeStaticAssets("/assets/", true))
```

## Notes

- POST requests to the frontend root are rejected with `405 Method Not Allowed` to prevent misconfigured osquery agents from submitting data to the wrong endpoint (see [Fleet issue #16182](https://github.com/fleetdm/fleet/issues/16182)).
- The BYOD cookie (`BYODIdpCookieName`) is cleared after a successful fully-managed enrollment to avoid stale auth state.
- Static assets are only gzip-compressed for `text/javascript` and `text/css` content types; other types fall through uncompressed.
