Implements a distributed lock and key-value/set operations for Fleet using Redis, preventing multiple Fleet server instances from concurrently accessing shared resources.

## Key Components

- **`NewLock(pool fleet.RedisPool) fleet.Lock`** — Constructor that returns a `fleet.Lock` implementation backed by Redis.
- **`SetIfNotExist`** — Acquires a lock via Redis `SET NX PX`, returning `true` if the key was set. Defaults to a 60-second expiry if `expireMs` is `0`.
- **`ReleaseLock`** — Atomically releases a lock using a Lua script, only deleting the key when the stored value matches the caller's value (prevents accidental release by another holder).
- **`AddToSet` / `RemoveFromSet` / `GetSet`** — Manage Redis sets via `SADD`, `SREM`, and `SMEMBERS`.
- **`Get`** — Retrieves a string value; returns `nil` if the key does not exist.
- **`GetAndDelete`** — Atomically reads and removes a key using sequential `GET` + `DEL` (note: consolidatable into `GETDEL` on Redis ≥ 6.2.0).

## Usage Example

```go
pool := redis.NewPool(redisAddr)
lock := redis_lock.NewLock(pool)

// Acquire a distributed lock for 30 seconds
acquired, err := lock.SetIfNotExist(ctx, "my-job-lock", "server-1", 30_000)
if err != nil || !acquired {
    // Another instance holds the lock
    return
}
defer lock.ReleaseLock(ctx, "my-job-lock", "server-1")

// Track active workers in a Redis set
_ = lock.AddToSet(ctx, "active-workers", "server-1")
defer lock.RemoveFromSet(ctx, "active-workers", "server-1")

members, _ := lock.GetSet(ctx, "active-workers")
fmt.Println("Active workers:", members)
```
