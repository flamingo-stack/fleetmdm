Handles bulk application of user role specifications in the Fleet MDM service layer, mapping email addresses to global and team-level roles with admin safeguards.

## Key Components

- **`applyUserRoleSpecsEndpoint`** — Transport-layer handler that delegates to `ApplyUserRolesSpecs` and wraps errors in the response struct.
- **`ApplyUserRolesSpecs`** — Core service method that authorizes the request, resolves users by email, validates team names, and persists updated role assignments via `SaveUsers`.
- **`checkAtLeastOneAdmin`** — Guard that prevents admin downgrade if no other global admin exists, returning `ErrNoOneAdminNeeded` when the last admin would be removed.

## Usage Example

```go
spec := fleet.UsersRoleSpec{
    Roles: map[string]*fleet.UserRoleSpec{
        "alice@example.com": {
            GlobalRole: fleet.RoleAdminPtr(),
        },
        "bob@example.com": {
            GlobalRole: nil,
            Teams: []fleet.UserTeam{
                {Team: fleet.Team{Name: "engineering"}, Role: fleet.RoleMaintainer},
            },
        },
    },
}

err := svc.ApplyUserRolesSpecs(ctx, spec)
if err != nil {
    // Handle fleet.ErrNoOneAdminNeeded or fleet.BadRequestError (unknown team)
    log.Fatal(err)
}
```

## Notes

- Requires `fleet.ActionWrite` on `fleet.User`; unauthorized callers receive an auth error immediately.
- Team names in the spec must already exist; unknown names return a `BadRequestError`.
- All user updates are batched into a single `SaveUsers` call for atomicity.
