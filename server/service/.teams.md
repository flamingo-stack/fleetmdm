This file implements the HTTP endpoint handlers and service-layer stubs for Fleet team management operations in the free/unlicensed tier.

## Key Components

| Component | Description |
|---|---|
| `listTeamsEndpoint` / `ListTeams` | Lists all teams; returns `ErrMissingLicense` in free tier |
| `getTeamEndpoint` / `GetTeam` | Retrieves a single team by ID; special handling for team ID `0` (default team) |
| `createTeamEndpoint` / `NewTeam` | Creates a new team via `TeamPayload` |
| `modifyTeamEndpoint` / `ModifyTeam` | Updates team settings; strips `UpdateNewHosts` from iOS/iPadOS MDM updates |
| `deleteTeamEndpoint` / `DeleteTeam` | Deletes a team by ID |
| `applyTeamSpecsEndpoint` / `ApplyTeamSpecs` | Bulk-applies team specs with force/dry-run support and Unicode name normalization |
| `modifyTeamAgentOptionsEndpoint` / `ModifyTeamAgentOptions` | Updates raw agent options JSON for a team |
| `listTeamUsersEndpoint` / `ListTeamUsers` | Lists users belonging to a team |
| `defaultTeamResponse` | Reduced response struct for team ID `0`, exposing only webhooks and integrations |

> **Note:** All service-layer methods (`ListTeams`, `GetTeam`, `NewTeam`, etc.) return `fleet.ErrMissingLicense` — full implementations require a Fleet Premium license.

## Usage Example

```go
// Apply team specs with dry-run validation
req := &applyTeamSpecsRequest{
    Force:  false,
    DryRun: true,
    Specs: []*fleet.TeamSpec{
        {Name: "Engineering"},
        {Name: "Sales"},
    },
}

idsByName, err := svc.ApplyTeamSpecs(ctx, req.Specs, fleet.ApplyTeamSpecOptions{
    ApplySpecOptions: fleet.ApplySpecOptions{
        DryRun: true,
    },
})
// Returns ErrMissingLicense on free tier

// Modify team agent options (raw JSON)
team, err := svc.ModifyTeamAgentOptions(ctx, teamID, json.RawMessage(`{"config":{}}`), fleet.ApplySpecOptions{})
```
