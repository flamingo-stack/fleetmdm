A Redis-backed string key/value store providing basic `SET`, `GET`, `MGET`, and `DEL` operations with TTL-based expiration support.

## Key Components

| Export | Type | Description |
|---|---|---|
| `RedisKeyValue` | struct | Core store wrapping a `fleet.RedisPool` with an internal key prefix (`key_value_`) to avoid namespace collisions |
| `New` | constructor | Creates a new `RedisKeyValue` instance from a `fleet.RedisPool` |
| `Set` | method | Creates or overwrites a key/value pair with a required expiration duration |
| `Get` | method | Retrieves a single value; returns `(nil, nil)` when the key does not exist |
| `MGet` | method | Batch-retrieves multiple keys in one Redis `MGET` call; returns a `map[string]*string` with `nil` values for missing keys |
| `Delete` | method | Removes a key via Redis `DEL`; no-ops on empty key |

## Usage Example

```go
import (
    "context"
    "time"

    redistore "github.com/fleetdm/fleet/v4/server/datastore/redis_key_value"
)

pool := getRedisPool() // fleet.RedisPool
store := redistore.New(pool)
ctx := context.Background()

// Set a key with a 10-minute TTL
err := store.Set(ctx, "session:abc123", "user@example.com", 10*time.Minute)

// Retrieve a single key
val, err := store.Get(ctx, "session:abc123")
if val != nil {
    fmt.Println(*val) // "user@example.com"
}

// Batch-retrieve multiple keys
results, err := store.MGet(ctx, []string{"session:abc123", "session:xyz"})
// results["session:xyz"] == nil if not found

// Delete a key
err = store.Delete(ctx, "session:abc123")
```

## Notes

- All keys are internally namespaced under the `key_value_` prefix to prevent collisions with other Redis domains (e.g. live queries, calendar locks).
- Expiration is set in milliseconds via the `PX` option on `SET`; there is no `Update` without TTL — every write requires an expiration.
- A `testPrefix` field is available on the struct for test isolation, though it is not exposed via `New`.
