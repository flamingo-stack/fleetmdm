Registers trace sampling tiers for Fleet service routes, classifying API endpoints into `TierHighVolume` or `TierStandard` buckets so the `platform/tracing` sampler can apply appropriate sampling ratios without baking route knowledge into the tracing package itself.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `RegisterTracingTiers` | Function | Populates a `*tracing.Registry` with per-route tier assignments for all routes owned by the legacy flat service handler |

### Tier Classifications

| Tier | Routes | Default Sample Rate |
|---|---|---|
| `TierHighVolume` | Hot agent endpoints: osquery config/distributed/log, Orbit config/token/ping, device ping/desktop | 0.1% |
| `TierStandard` | Admin/read endpoints: hosts, labels, policies, software, users, config, UI per-page-load calls | 2% |
| `TierAlways` (fallback) | Unregistered routes: cron jobs, enroll, SCEP, MDM checkin, GitOps batch, etc. | 100% |

## Usage Example

```go
// Called once during server startup (e.g. in the serve command).
func startServer() {
    registry := tracing.NewRegistry()

    // Register tiers from this package and any bounded contexts
    // that have migrated out of the flat service handler.
    service.RegisterTracingTiers(registry)
    activity.RegisterTracingTiers(registry)

    tracer := tracing.NewSampler(registry, tracing.SamplerConfig{
        HighVolumeRatio: 0.001, // 0.1%
        StandardRatio:   0.02,  // 2%
    })
    _ = tracer
}
```

## Notes

- Path segments use `_version_` as the placeholder for the gorilla/mux `fleetversion` segment; the sampler normalises incoming span names to this form before lookup.
- Alternate path forms (e.g. `/api/v1/osquery/...`) are registered alongside their versioned equivalents.
- Bounded contexts that have migrated out of this package own their own `RegisterTracingTiers` function; this function covers only the legacy flat handler.
