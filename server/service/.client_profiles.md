Provides Fleet MDM client methods for managing Apple and cross-platform MDM configuration profiles, including CRUD operations and enrollment profile retrieval.

## Key Components

| Function | Description |
|---|---|
| `DeleteProfile(profileID uint)` | Deletes an Apple MDM config profile by ID (deprecated endpoint) |
| `ListProfiles(teamID *uint)` | Lists Apple MDM config profiles, optionally filtered by team |
| `ListConfigurationProfiles(teamID *uint)` | Lists cross-platform MDM config profiles via the unified endpoint |
| `GetProfileContents(profileID string)` | Fetches the raw byte contents of a saved MDM profile |
| `AddProfile(teamID uint, configurationProfile []byte)` | Uploads a new Apple MDM config profile via multipart form POST |
| `GetConfigProfilesSummary(teamID *uint)` | Returns a summary of MDM profile statuses for a team |
| `GetAppleMDMEnrollmentProfile(teamID uint)` | Retrieves the Apple DEP setup assistant profile for a team |

> **Note:** `DeleteProfile`, `ListProfiles`, and `AddProfile` use deprecated Apple-specific endpoints (`/api/latest/fleet/mdm/apple/profiles`). Migration to newer endpoints is pending.

## Usage Example

```go
// List cross-platform configuration profiles for a team
teamID := uint(42)
profiles, err := client.ListConfigurationProfiles(&teamID)
if err != nil {
    log.Fatal(err)
}
for _, p := range profiles {
    fmt.Println(p.Name)
}

// Upload a new Apple MDM profile
profileData, _ := os.ReadFile("com.example.mobileconfig")
profileID, err := client.AddProfile(teamID, profileData)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Created profile ID: %d\n", profileID)

// Fetch raw profile contents
contents, err := client.GetProfileContents("profile-uuid-here")
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Profile XML: %s\n", contents)
```
