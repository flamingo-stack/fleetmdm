Validates and tracks Certificate Authority (CA) variable presence within MDM profiles, ensuring all required Fleet variables for DigiCert, NDES, Custom SCEP, and Smallstep CAs are correctly paired and present.

## Key Components

| Type/Function | Description |
|---|---|
| `DigiCertVarsFound` | Tracks DigiCert CA `DATA` and `PASSWORD` variable pairs; validates 1:1 mapping per CA name |
| `NDESVarsFound` | Tracks NDES SCEP variables: URL, challenge, and renewal ID presence |
| `CustomSCEPVarsFound` | Tracks custom SCEP proxy URL, challenge, and renewal ID variables per CA name |
| `SmallstepVarsFound` | Tracks Smallstep SCEP URL, challenge, and renewal ID variables per CA name |
| `validateProfileCertificateAuthorityVariables` | Core validation function that scans profile contents for Fleet variables and delegates to per-CA validators |

Each CA struct implements a consistent interface:
- `Ok() bool` — all required variables are present and paired
- `Found() bool` — at least one variable was encountered
- `RenewalOnly() bool` — only a renewal ID was found (no URL/challenge)
- `ErrorMessage() string` — human-readable description of the validation failure
- `Set*()` methods — register variable occurrences, returning updated state and a duplicate flag

## Usage Example

```go
err := validateProfileCertificateAuthorityVariables(
    profileContents,
    licenseInfo,
    groupedCAs,
    additionalDigiCertValidation,
    additionalCustomSCEPValidation,
    additionalNDESValidation,
    additionalSmallstepValidation,
)
if err != nil {
    // Handle missing license, unknown CA, or mismatched variable pairs
}

// Check DigiCert pairing directly
var d *DigiCertVarsFound
d, _ = d.SetData("MyCorp")
d, _ = d.SetPassword("MyCorp")
if !d.Ok() {
    fmt.Println(d.ErrorMessage())
}
```
