Thread-safe manager for storing and retrieving OpenFrame authentication tokens using a read/write mutex.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `OpenFrameAuthorizationManager` | struct | Holds the current auth token with an `sync.RWMutex` for concurrent access |
| `NewOpenFrameAuthorizationManager` | func | Creates an empty manager with no initial token |
| `NewOpenFrameAuthorizationManagerWithToken` | func | Creates a manager pre-loaded with a token |
| `UpdateToken` | method | Writes a new token (exclusive lock) |
| `GetToken` | method | Reads the current token (shared lock) |

## Usage Example

```go
// Create without a token, then set one later
mgr := openframe.NewOpenFrameAuthorizationManager()
mgr.UpdateToken("eyJhbGciOiJSUzI1NiJ9...")

// Create with an initial token (e.g. loaded from config)
mgr := openframe.NewOpenFrameAuthorizationManagerWithToken(cfg.OpenFrameToken)

// Read the token when making an API call
token := mgr.GetToken()
req.Header.Set("Authorization", "Bearer "+token)

// Rotate the token on refresh (safe to call from any goroutine)
go func() {
    newToken := refreshOpenFrameToken()
    mgr.UpdateToken(newToken)
}()
```

## Notes

- `UpdateToken` acquires a full write lock; `GetToken` uses a read lock, so multiple goroutines can read concurrently without blocking each other.
- The zero value (`&OpenFrameAuthorizationManager{}`) is valid and returns an empty string from `GetToken` until a token is set.
