Periodically refreshes the OpenFrame authentication token by polling the token extractor on a 5-second cron schedule and propagating changes to the authorization manager.

## Key Components

| Symbol | Description |
|--------|-------------|
| `OpenframeTokenRefresher` | Core struct holding references to the token extractor, authorization manager, and the underlying cron scheduler |
| `NewOpenframeTokenRefresher` | Constructor that wires up dependencies and initializes a second-precision cron instance |
| `Start()` | Registers the `*/5 * * * * *` cron job and starts the scheduler; returns an error if job registration fails |
| `Stop()` | Gracefully halts the cron scheduler and blocks until any in-flight refresh completes |
| `refreshToken()` | Internal tick handler — extracts the current token, skips update if unchanged, and calls `UpdateToken` on change |
| `openframeTokenRefreshErrorLogInterval` | Constant (`100`) that throttles extraction error logs to every 100 consecutive failures |

## Usage Example

```go
extractor := openframe.NewOpenframeTokenExtractor(/* ... */)
authManager := openframe.NewOpenFrameAuthorizationManager(/* ... */)

refresher := openframe.NewOpenframeTokenRefresher(extractor, authManager)

if err := refresher.Start(); err != nil {
    log.Fatal().Err(err).Msg("failed to start token refresher")
}
defer refresher.Stop()
```

## Behavior Notes

- **Throttled error logging** — extraction errors are only logged on the 1st, 101st, 201st… failure, preventing log floods during extended outages.
- **No-op on stale token** — `UpdateToken` is skipped when the extracted value matches the cached token, avoiding unnecessary state churn.
- **Graceful shutdown** — `Stop()` waits on the context returned by `cron.Stop()`, ensuring in-progress refresh calls finish cleanly before the process exits.
