Reads and decrypts an authentication token from an encrypted file on disk, using `OpenframeEncryptionService` to produce a plaintext token string.

## Key Components

| Symbol | Description |
|---|---|
| `OpenframeTokenExtractor` | Struct that holds a reference to the encryption service, the token file path, and a read-error counter for throttled logging |
| `NewOpenframeTokenExtractor` | Constructor that initializes the extractor with a given encryption service and file path |
| `ExtractToken` | Reads the encrypted token file, decrypts its contents, and returns the plaintext token; errors are throttled via `openframeTokenRefreshErrorLogInterval` |

## Usage Example

```go
encSvc := NewOpenframeEncryptionService(secret)
extractor := NewOpenframeTokenExtractor(encSvc, "/var/run/openframe/token.enc")

token, err := extractor.ExtractToken()
if err != nil {
    log.Fatal().Err(err).Msg("failed to extract token")
}

// token is now the decrypted plaintext credential
```

## Notes

- Read errors are only logged on the first occurrence and then every `openframeTokenRefreshErrorLogInterval` attempts, preventing log spam in degraded environments.
- The error counter resets to `0` on a successful file read, so logging resumes immediately after a recovery.
