Provides AES-256-GCM authenticated decryption for the OpenFrame integration, decoding Base64-encoded ciphertext and returning plaintext bytes.

## Key Components

### `OpenframeEncryptionService`
Struct holding the AES encryption key and a rolling error counter used to throttle repeated decrypt failure logs.

### `NewOpenframeEncryptionService(encryptionKey string) *OpenframeEncryptionService`
Constructor that initializes the service with the provided AES key.

### `Decrypt(data string) ([]byte, error)`
Decodes a Base64 string, constructs an AES-GCM cipher, extracts the nonce prefix, and authenticates + decrypts the ciphertext. Error logging is rate-limited by `openframeTokenRefreshErrorLogInterval` to avoid log flooding on sustained failures. The error counter resets to `0` on each successful decryption.

## Usage Example

```go
svc := openframe.NewOpenframeEncryptionService("your-32-byte-aes-key-here!!!!!")

plaintext, err := svc.Decrypt(encryptedBase64String)
if err != nil {
    log.Fatal().Err(err).Msg("decryption failed")
}

fmt.Println(string(plaintext))
```

## Notes

- The AES key must be exactly **16, 24, or 32 bytes** for AES-128, AES-192, or AES-256 respectively.
- Encrypted input is expected as `base64(nonce || ciphertext)` where the nonce length is determined by `gcm.NonceSize()` (typically 12 bytes).
- Only `Decrypt` is implemented; encryption is handled externally (e.g., by the OpenFrame backend).
