Handles retrieval of a Fleet policy by its ID, including authorization checks and population of related data such as team automations and software icon URLs.

## Key Components

- **`getPolicyByIDEndpoint`** — HTTP handler that extracts the policy ID from the request and delegates to the service layer, returning a typed response.
- **`Service.GetPolicyByID`** — Core service method that fetches a policy, enforces team-scoped authorization, and enriches the policy with automation settings and software icon URLs.

## Usage Example

```go
policy, err := svc.GetPolicyByID(ctx, 42)
if err != nil {
    // handle unauthorized access or not-found errors
}
fmt.Println(policy.Name)
```

## Authorization Flow

1. Fetch the raw policy from the datastore to determine team ownership.
2. Call `authz.Authorize` with `ActionRead` — team-scoped users are denied access to policies outside their teams.
3. Enrich the policy with team automations (`populateAutomationsForTeamPolicy`) and software icon URLs (`populateSoftwareIconURLs`).
