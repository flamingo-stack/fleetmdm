Manages CRUD operations and automation workflows for global (non-team-scoped) Fleet policies, including creation, listing, counting, deletion, modification, and automation reset logic.

## Key Components

| Function | Description |
|---|---|
| `globalPolicyEndpoint` | HTTP handler for creating a new global policy |
| `NewGlobalPolicy` | Creates a global policy with authorization, label validation, and license checks |
| `ListGlobalPolicies` | Returns all global policies with pagination support |
| `CountGlobalPolicies` | Returns a count of global policies matching an optional query string |
| `DeleteGlobalPolicies` | Deletes policies by ID and removes them from webhook configurations |
| `ModifyGlobalPolicy` | Updates an existing global policy via shared `modifyPolicy` helper |
| `ResetAutomation` | Resets automation iteration counters for specified policies and teams |
| `removeGlobalPoliciesFromWebhookConfig` | Cleans deleted policy IDs from the failing policies webhook config |
| `automationPolicies` | Builds a set of policy IDs that have automation (webhook/Jira/Zendesk) enabled |

## Usage Example

```go
// Create a new global policy
policy, err := svc.NewGlobalPolicy(ctx, fleet.PolicyPayload{
    Name:        "Require FileVault",
    Query:       "SELECT 1 FROM filevault_status WHERE enabled = 1;",
    Description: "Ensures FileVault is enabled on macOS devices",
    Platform:    "darwin",
    Critical:    true,
})

// List global policies
policies, err := svc.ListGlobalPolicies(ctx, fleet.ListOptions{
    Page:    0,
    PerPage: 20,
})

// Delete global policies and clean up webhook references
deletedIDs, err := svc.DeleteGlobalPolicies(ctx, []uint{1, 2, 3})

// Reset automation for specific policies
err = svc.ResetAutomation(ctx, []uint{teamID}, []uint{policyID})
```

## Notes

- Label-based policy filtering (`LabelsIncludeAny`, `LabelsExcludeAll`, etc.) requires a premium license.
- OpenFrame multitenancy patch allows deletion of team-owned policies when a per-request tenant pin matches.
- Activity log entries are created for policy creation and deletion (global team ID is represented as `-1`).
