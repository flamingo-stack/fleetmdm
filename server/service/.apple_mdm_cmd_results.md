Handles processing of Apple MDM command results, specifically for `InstalledApplicationList` and `DeviceLocation` MDM commands returned from managed Apple devices.

## Key Components

### `InstalledApplicationListResult` (interface)
Extends `fleet.MDMCommandResults` with methods to retrieve available apps (`AvailableApps()`) and host platform (`HostPlatform()`).

### `NewInstalledApplicationListResult`
Constructor that unmarshals a raw MDM response into an `InstalledApplicationListResult`, mapping the host platform (`ios`, `ipados`, `darwin`) to the appropriate software source type.

### `NewInstalledApplicationListResultsHandler`
Returns a `fleet.MDMCommandResultsHandler` closure that processes VPP and in-house app install verification results. Responsibilities include:
- Matching installed apps against pending VPP and in-house installs by bundle ID
- Marking installs as verified or failed based on app presence and timeout
- Handling the Xcode special case (requires `managedonly=false` listing)
- Queuing a retry verification job if apps are not yet visible
- Triggering host refetch or re-issuing `InstalledApplicationList` on success
- Creating audit activities for terminal install states

### `DeviceLocationResult` (interface)
Extends `fleet.MDMCommandResults` with `HostID()`, `Latitude()`, and `Longitude()` accessors for device location data.

### `NewDeviceLocationResult`
Parses a raw MDM `DeviceLocation` command response plist into a `DeviceLocationResult`.

## Usage Example

```go
handler := NewInstalledApplicationListResultsHandler(
    ds, commander, logger,
    5*time.Minute, 30*time.Second,
    newActivityFn,
)

result, err := NewInstalledApplicationListResult(ctx, rawBytes, cmdUUID, hostUUID, "darwin")
if err != nil {
    log.Fatal(err)
}

if err := handler(ctx, result); err != nil {
    log.Fatal(err)
}
```
