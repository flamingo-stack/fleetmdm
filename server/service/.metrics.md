Wraps a `fleet.Service` implementation with instrumentation middleware that tracks request count and latency metrics using go-kit's metrics primitives.

## Key Components

- **`metricsMiddleware`** — Struct that embeds `fleet.Service` and holds two metric collectors: a `Counter` for request counts and a `Histogram` for request latency.
- **`NewMetricsService`** — Constructor that accepts an existing `fleet.Service` and two go-kit metric instruments, returning a new `fleet.Service` with metrics instrumentation applied.

## Usage Example

```go
import (
    "github.com/go-kit/kit/metrics/prometheus"
    stdprometheus "github.com/prometheus/client_golang/prometheus"
)

requestCount := prometheus.NewCounterFrom(stdprometheus.CounterOpts{
    Namespace: "fleet",
    Name:      "request_count",
    Help:      "Number of requests received.",
}, []string{"method"})

requestLatency := prometheus.NewSummaryFrom(stdprometheus.SummaryOpts{
    Namespace: "fleet",
    Name:      "request_latency_microseconds",
    Help:      "Total duration of requests in microseconds.",
}, []string{"method"})

var svc fleet.Service = NewMetricsService(baseSvc, requestCount, requestLatency)
```

> **Note:** `metricsMiddleware` embeds `fleet.Service` directly, so only methods explicitly overridden in the middleware will record metrics. All other methods delegate transparently to the wrapped service.
