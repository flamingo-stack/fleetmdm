Client-side methods for managing Fleet application configuration, enroll secrets, versioning, and organization logo assets via the Fleet REST API.

## Key Components

| Function | Description |
|---|---|
| `ApplyAppConfig` | PATCHes the Fleet instance application config, rewriting legacy key aliases before sending |
| `ApplyNoTeamProfiles` | POSTs a batch of MDM profiles for hosts not assigned to any team |
| `GetAppConfig` | GETs the current enriched application config from the server |
| `GetEnrollSecretSpec` | GETs the stored enroll secrets spec |
| `ApplyEnrollSecretSpec` | POSTs new enroll secrets |
| `Version` | GETs Fleet server version info |
| `planAndStripOrgLogos` | Plans logo upload actions from a GitOps YAML payload; strips `path` keys before the PATCH so the follow-up PUT is the sole writer |
| `doGitOpsOrgLogos` | Executes upload actions planned by `planAndStripOrgLogos` after a successful AppConfig PATCH |
| `validateOrgLogoFile` | Reads and validates a logo file against Fleet's size/format constraints before uploading |
| `UploadOrgLogo` | PUTs a logo file as `multipart/form-data` to `/api/latest/fleet/logo` for a given mode (light/dark) |
| `DeleteOrgLogo` | DELETEs the stored org logo for a given mode; idempotent |
| `GetOrgLogoContent` | GETs the raw logo bytes and `Content-Type` for a given mode; returns a `notFoundErr` on 404 |

## Usage Example

```go
// Apply updated app config
payload := map[string]interface{}{
    "org_info": map[string]interface{}{
        "org_name": "Acme Corp",
    },
}
if err := client.ApplyAppConfig(payload, fleet.ApplySpecOptions{}); err != nil {
    log.Fatal(err)
}

// Upload a light-mode org logo
if err := client.UploadOrgLogo(fleet.OrgLogoModeLight, "/path/to/logo.png"); err != nil {
    log.Fatal(err)
}

// Fetch current config
cfg, err := client.GetAppConfig()
if err != nil {
    log.Fatal(err)
}
fmt.Println(cfg.OrgInfo.OrgName)
```

> **GitOps note:** `planAndStripOrgLogos` + `doGitOpsOrgLogos` are used together in GitOps workflows — logo upload actions are planned before the PATCH and executed only after it succeeds, ensuring the logo store is never mutated on a failed config apply.
