Translates human-readable identifiers (emails, label names, team names, host identifiers) into their corresponding Fleet entity IDs via a service endpoint.

## Key Components

| Component | Description |
|-----------|-------------|
| `translatorRequest` / `translatorResponse` | HTTP request/response structs wrapping a list of `fleet.TranslatePayload` items |
| `translatorEndpoint` | HTTP handler that delegates to `svc.Translate` |
| `translateFunc` | Function type signature for all translation helpers |
| `translateEmailToUserID` | Resolves a user email to a `User.ID` |
| `translateLabelToID` | Resolves a label name to a `Label.ID` (respects team filter from context) |
| `translateTeamToID` | Resolves a team name to a `Team.ID` |
| `translateHostToID` | Resolves a host identifier to a `Host.ID` |
| `Service.Translate` | Core service method; authorizes each payload by type and applies the matching translate function |

## Authorization Behavior

Each `TranslatePayload.Type` triggers a separate authorization check (`ActionRead`) against the corresponding Fleet resource. Unknown types return a `BadRequest` error and skip authorization entirely. An empty payload list also skips authorization and returns a `BadRequest`.

## Usage Example

```go
payloads := []fleet.TranslatePayload{
    {
        Type: fleet.TranslatorTypeUserEmail,
        Payload: fleet.StringIdentifierToIDPayload{
            Identifier: "alice@example.com",
        },
    },
    {
        Type: fleet.TranslatorTypeHost,
        Payload: fleet.StringIdentifierToIDPayload{
            Identifier: "my-macbook-pro",
        },
    },
}

resolved, err := svc.Translate(ctx, payloads)
if err != nil {
    log.Fatal(err)
}

for _, p := range resolved {
    fmt.Printf("Type: %s, ID: %d\n", p.Type, p.Payload.ID)
}
// Type: user_email, ID: 42
// Type: host,       ID: 107
```
