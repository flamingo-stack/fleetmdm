Provides test-only mock and no-op implementations of key service interfaces used by the `svctest` package.

## Key Components

| Type | Interface Implemented | Behavior |
|---|---|---|
| `mockMailService` | `fleet.MailService` | Configurable no-op mailer; delegates to a swappable `SendEmailFn` func and records invocation via `Invoked` |
| `nopEnrollHostLimiter` | `fleet.EnrollHostLimiter` | Always permits enrollment; `CanEnrollNewHost` returns `true, nil` and `SyncEnrolledHostIDs` is a no-op |
| `acmeCSRSigner` | `acme.CSRSigner` | Adapts a `depot.Signer` to the ACME CSR signing interface by delegating to `depot.Signer.Signx509CSR` |

## Usage Example

```go
// Wire up a mockMailService in a test
svc, _ := svctest.RunServerForTestsWithDS(t, ds, func(c *config.FleetConfig) {
    // override the mailer after service creation
})

mailer := &mockMailService{
    SendEmailFn: func(e fleet.Email) error {
        // assert on e.Subject, e.Recipients, etc.
        return nil
    },
}

// Verify the mailer was called
mailer.SendEmail(ctx, someEmail)
if !mailer.Invoked {
    t.Fatal("expected SendEmail to be called")
}

// Use nopEnrollHostLimiter when enrollment limits are irrelevant
var limiter fleet.EnrollHostLimiter = nopEnrollHostLimiter{}
ok, err := limiter.CanEnrollNewHost(ctx)
// ok == true, err == nil

// Adapt a depot.Signer for ACME CSR signing
signer := &acmeCSRSigner{signer: depotSigner}
cert, err := signer.SignCSR(ctx, csr)
```

## Notes

- `mockMailService.CanSendEmail` returns `true` only when `SMTPConfigured` is set on the provided settings, mirroring real SMTP gate logic.
- All three types are internal to the `svctest` package and are not exported; they are wired into the test service by [`RunServerForTestsWithDS`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/testhelpers.go).
