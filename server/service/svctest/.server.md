Provides test server bootstrapping utilities for Fleet MDM integration tests, spinning up a full HTTP test server backed by a real or mock datastore with all service modules wired together.

## Key Components

### Functions

- **`RunServerForTestsWithDS`** — Primary entry point that creates a `TestService` from a datastore and config, then delegates to `RunServerForTestsWithServiceWithDS`. Supports optional cached MySQL wrapper via `EnableCachedDS`.

- **`RunServerForTestsWithServiceWithDS`** — Core setup function that assembles the full HTTP stack including:
  - User seeding (unless `SkipCreateTestUsers` is set)
  - Activity bounded context (real when `DBConns` is provided, stub otherwise)
  - Apple MDM protocol services (check-in, DDM, SCEP proxy)
  - ACME certificate service
  - Host identity SCEP + HTTP message signature verification
  - Conditional access SCEP/IdP endpoints
  - SCIM provisioning endpoints
  - Redis rate limiting (falls back to in-memory store)
  - Debug and OTA enrollment handlers
  - API endpoint catalog validation via `apiendpoints.Validate`

- **`opts0FeatureRoutes`** — Helper that safely extracts `FeatureRoutes` from the first `TestServerOpts` entry.

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    ds := mysql.CreateNamedMySQLDS(t)

    users, server := svctest.RunServerForTestsWithDS(t, ds)
    defer server.Close()

    adminToken := getTestAdminToken(users)
    resp, err := http.Get(server.URL + "/api/latest/fleet/hosts")
    require.NoError(t, err)
    // assert on resp...
}
```

With custom options:

```go
users, server := svctest.RunServerForTestsWithDS(t, ds, &service.TestServerOpts{
    EnableCachedDS:      true,
    MDMStorage:          mdmStorage,
    SCEPStorage:         scepStorage,
    MDMPusher:           mockPusher,
    License:             &fleet.LicenseInfo{Tier: fleet.TierPremium},
})
```
