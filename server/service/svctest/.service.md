Provides a `NewTestService` helper that constructs a fully wired `fleet.Service` instance backed by a test datastore, suitable for use in Go unit and integration tests.

## Key Components

### `NewTestService`
The primary exported function. Accepts a `testing.T`, a `fleet.Datastore`, a `FleetConfig`, and optional `TestServerOpts`. Returns a `fleet.Service` and a `context.Context` pre-loaded with license information.

### `newTestServiceWithConfig` (internal)
Builds and wires all service dependencies, including:
- **Logging** — filesystem log writer via `logging.NewFilesystemLogWriter`
- **Clock** — pluggable via `opts.Clock`, defaults to `clock.C`
- **MDM** — Apple MDM storage/pusher, Windows WSTEP cert manager, Android service
- **SSO** — Redis-backed `sso.SessionStore` when a Redis pool is provided
- **Error store** — `errorstore.Handler` with Redis, injected into context via `ctxerr`
- **Cron schedules** — started from `opts.StartCronSchedules` callbacks
- **EE service** — wraps the base service with `eeservice.NewService` when the license tier is Premium
- **Mock overrides** — activity service and ACME service are replaced with no-op mocks by default; real implementations are substituted when `DBConns` is supplied by `RunServerForTestsWithServiceWithDS`

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    ds := new(fleet_mock.Store)
    cfg := config.TestConfig()

    svc, ctx := svctest.NewTestService(t, ds, cfg)

    result, err := svc.ListHosts(ctx, fleet.HostListOptions{})
    require.NoError(t, err)
    require.Empty(t, result)
}
```

To use a Premium license or a Redis pool:

```go
svc, ctx := svctest.NewTestService(t, ds, cfg, &service.TestServerOpts{
    License: &fleet.LicenseInfo{Tier: fleet.TierPremium},
    Pool:    redisPool,
})
```
