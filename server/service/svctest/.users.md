Test helper utilities for seeding standard Fleet users and obtaining authentication tokens in integration tests.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `testUsers` | `var` | Predefined set of admin, maintainer, and observer users seeded into the test database |
| `createTestUsers` | `func` | Seeds `testUsers` into a `fleet.Datastore` and returns them keyed by email |
| `GetToken` | `func` | POSTs to `/api/latest/fleet/login` and returns the auth token for a given email/password |

## Usage Example

```go
// Seed users and retrieve an auth token in an integration test
func TestSomething(t *testing.T) {
    ds := setupTestDatastore(t)
    users := createTestUsers(t, ds)

    // Confirm the admin user was created
    admin := users[service.TestAdminUserEmail]
    require.Equal(t, fleet.RoleAdmin, *admin.GlobalRole)

    // Obtain an auth token for the maintainer user
    token := GetToken(t, service.TestMaintainerUserEmail, test.GoodPassword, "http://localhost:8080")
    require.NotEmpty(t, token)
}
```

## Notes

- **Test-only package** — imports `testing`, so it must never be referenced from production code.
- `testUsers` must stay in sync with the internal service test copy that defines the same set of users.
- `createTestUsers` iterates keys in sorted order to avoid non-deterministic user IDs caused by random map iteration.
- `GetToken` fails the test immediately (`require`) on HTTP or JSON errors, and asserts a `200 OK` response status.
