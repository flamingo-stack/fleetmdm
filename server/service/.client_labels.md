Provides Fleet client methods for managing label specifications, supporting create/update, retrieval, and deletion operations against the Fleet API.

## Key Components

| Function | Description |
|---|---|
| `ApplyLabels` | Upserts a list of `LabelSpec` objects; accepts an optional `teamID` for team-scoped labels and a `moves` slice for label name migrations |
| `GetLabel` | Fetches a single `LabelSpec` by name via URL-escaped path parameter |
| `GetLabels` | Retrieves all `LabelSpec` entries for a given team ID |
| `DeleteLabel` | Removes a label by its URL-escaped name |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Apply (upsert) labels globally
specs := []*fleet.LabelSpec{
    {Name: "linux-servers", Query: "SELECT 1 FROM os_version WHERE platform = 'linux'"},
}
if err := client.ApplyLabels(specs, nil, nil); err != nil {
    log.Fatal(err)
}

// Apply labels scoped to a specific team
teamID := uint(42)
if err := client.ApplyLabels(specs, &teamID, nil); err != nil {
    log.Fatal(err)
}

// Retrieve a single label
spec, err := client.GetLabel("linux-servers")

// List all labels for a team
labels, err := client.GetLabels(42)

// Delete a label
if err := client.DeleteLabel("linux-servers"); err != nil {
    log.Fatal(err)
}
```

## Notes

- `ApplyLabels` routes to `/api/latest/fleet/spec/labels` with a `fleet_id` query parameter when `teamID` is non-nil; otherwise uses an unauthenticated-query variant without the parameter.
- Label names are URL-escaped via `url.PathEscape` in both `GetLabel` and `DeleteLabel`, making names with special characters or spaces safe for path segments.
