Handles the SCIM (System for Cross-domain Identity Management) details endpoint, returning configuration/status information or a license error if the feature is unavailable.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `getScimDetailsEndpoint` | Function | HTTP handler adapter that calls `ScimDetails` and wraps the result in a `ScimDetailsResponse` |
| `(*Service).ScimDetails` | Method | Service-layer implementation; skips authorization and returns `ErrMissingLicense` for unlicensed instances |

## Usage Example

```go
// Registering the endpoint (typical pattern)
e := makeEndpoint(getScimDetailsEndpoint)

// Calling the service method directly
details, err := svc.ScimDetails(ctx)
if errors.Is(err, fleet.ErrMissingLicense) {
    // SCIM is a licensed feature; handle accordingly
}
```

## Notes

- **Authorization**: Authorization is explicitly skipped via `SkipAuthorization` because the only response path is a license gate — no sensitive data is returned.
- **License gate**: The base (unlicensed) implementation always returns `fleet.ErrMissingLicense`. A licensed override in a higher-tier build would replace this method to return real SCIM details.
- **Response contract**: The endpoint uses `contract.ScimDetailsResponse`, keeping transport-layer concerns separate from the service layer.
