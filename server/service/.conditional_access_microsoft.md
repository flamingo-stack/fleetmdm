Service layer implementation for managing Microsoft Conditional Access (Entra ID) integrations in Fleet MDM, handling creation, confirmation, deletion, and retrieval of tenant integrations via a proxy server.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ConditionalAccessMicrosoftCreateIntegration` | Method | Creates a new Microsoft Entra tenant integration, registering it with the proxy and datastore, then returns the admin consent URL |
| `ConditionalAccessMicrosoftConfirm` | Method | Polls the proxy to check if the admin consent flow is complete and marks setup as done in the datastore |
| `ConditionalAccessMicrosoftDelete` | Method | Removes the integration from both the proxy and datastore, logging a warning if the proxy returns not-found |
| `ConditionalAccessMicrosoftGet` | Method | Reads the current integration record; returns `nil` if not configured or not found |
| `conditionalAccessMicrosoftCreateEndpoint` | Function | HTTP endpoint handler wiring `CreateIntegration` to the Fleet transport layer |
| `conditionalAccessMicrosoftConfirmEndpoint` | Function | HTTP endpoint handler wiring `Confirm` to the Fleet transport layer |
| `conditionalAccessMicrosoftDeleteEndpoint` | Function | HTTP endpoint handler wiring `Delete` to the Fleet transport layer |

## Usage Example

```go
// Create integration for an Entra tenant
consentURL, err := svc.ConditionalAccessMicrosoftCreateIntegration(ctx, "your-tenant-id")
if err != nil {
    log.Fatal(err)
}
// Redirect admin to consentURL to grant Fleet access

// Poll until the admin completes the consent flow
done, setupErr, err := svc.ConditionalAccessMicrosoftConfirm(ctx)
if err != nil {
    log.Fatal(err)
}
if done {
    fmt.Println("Integration setup complete")
} else if setupErr != "" {
    fmt.Printf("Setup error: %s\n", setupErr)
}

// Remove the integration when no longer needed
if err := svc.ConditionalAccessMicrosoftDelete(ctx); err != nil {
    log.Fatal(err)
}
```

All methods enforce authorization via `svc.authz` and require `MicrosoftCompliancePartner` to be configured; `Create`/`Confirm`/`Delete` require `ActionWrite` on `ConditionalAccessMicrosoftIntegration`, while `Get` requires `ActionRead` on `AppConfig`.
