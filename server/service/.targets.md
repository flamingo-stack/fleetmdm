Handles target search and host counting for Fleet query targeting, providing endpoints and service methods to search hosts, labels, and teams, then aggregate host metrics (online/offline/missing).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `searchTargetsEndpoint` | func | HTTP endpoint handler that searches targets and returns results with host metrics |
| `countTargetsEndpoint` | func | HTTP endpoint handler that returns only host count metrics for selected targets |
| `Service.SearchTargets` | method | Searches hosts, labels, and teams by query string with authorization and team filtering |
| `Service.CountHostsInTargets` | method | Counts hosts matching selected targets, broken down by online/offline/missing status |

## Usage Example

```go
// Search targets matching a query string
results, err := svc.SearchTargets(ctx, "web-server", &queryID, fleet.HostTargets{
    HostIDs:  []uint{1, 2},
    LabelIDs: []uint{10},
    TeamIDs:  []uint{3},
})
if err != nil {
    log.Fatal(err)
}

for _, host := range results.Hosts {
    fmt.Println(host.Hostname)
}

// Count hosts in selected targets
metrics, err := svc.CountHostsInTargets(ctx, &queryID, fleet.HostTargets{
    TeamIDs: []uint{3},
})
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Total: %d, Online: %d, Offline: %d\n",
    metrics.TotalHosts, metrics.OnlineHosts, metrics.OfflineHosts)
```

> **Note:** Both methods enforce authorization via `svc.authz` and apply `TeamFilter` scoping based on the viewer's user context. When a `queryID` is provided, observer permissions are derived from the query's `ObserverCanRun` flag.
