Generates and serves conditional access IdP assets for Apple devices, including the signing certificate (PEM) and a pre-populated Apple configuration profile (`.mobileconfig`) for Okta-based SCEP enrollment.

## Key Components

| Symbol | Description |
|---|---|
| `conditionalAccessAppleProfileTemplate` | XML plist template for the Apple MDM configuration profile, embedding SCEP, CA trust, mTLS identity preference, and Chrome cert auto-selection |
| `generateDeterministicUUID` | Produces stable UUID v5 values per server URL + component name, scoped to Fleet's conditional access namespace |
| `appleProfileTemplateData` | Struct holding all template variables: CA cert, SCEP URL, challenge, CN, mTLS URL, and per-payload UUIDs |
| `ConditionalAccessGetIdPSigningCert` | Service method that authorizes the caller, validates the private key config, and returns the IdP signing cert as PEM from `mdm_config_assets` |
| `ConditionalAccessGetIdPAppleProfile` | Service method that authorizes the caller, validates the private key config, and returns the rendered `.mobileconfig` profile |
| `HijackRender` (both responses) | Custom HTTP writers that set correct `Content-Type` / `Content-Disposition` headers before streaming the binary/PEM payload |

## Usage Example

```go
// Fetch the IdP signing certificate (requires fleet.ActionRead on ConditionalAccessIDPAssets)
certPEM, err := svc.ConditionalAccessGetIdPSigningCert(ctx)
if err != nil {
    // handle: private key not configured, asset missing, auth failure, etc.
}

// Fetch the Apple .mobileconfig profile
profileData, err := svc.ConditionalAccessGetIdPAppleProfile(ctx)
if err != nil {
    // handle error
}

// UUIDs embedded in the profile are deterministic per server URL:
uuid := generateDeterministicUUID("https://fleet.example.com", "scep-payload")
```

Both endpoints stream their responses directly via `HijackRender`, bypassing the standard JSON envelope — clients should validate received payload length against the `Content-Length` header.
