Service layer implementation for software title management, handling listing, retrieval, and update operations for software inventory within Fleet MDM.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ListSoftwareTitles` | Method | Lists software titles with pagination, filtering, and license-gated options (CVSS scoring, team scoping) |
| `SoftwareTitleByID` | Method | Retrieves a single software title by ID, enriching the response with installer metadata, VPP app data, and in-house app info (Premium only) |
| `SoftwareTitleNameForHostFilter` | Method | Returns minimal title name/displayName for host filtering without team-scoped inventory auth |
| `UpdateSoftwareName` | Method | Updates the display name of a software title (restricted to titles with a bundle identifier) |
| `UpdateSoftwareTitleAutoUpdateConfig` | Method | Updates auto-update configuration for a software title scoped to a team |

## Usage Example

```go
// List software titles with filtering options
titles, count, meta, err := svc.ListSoftwareTitles(ctx, fleet.SoftwareTitleListOptions{
    ListOptions: fleet.ListOptions{PerPage: 20},
    TeamID:      ptr.Uint(42),
})

// Get a specific software title (Premium: includes installer/VPP/in-house app metadata)
title, err := svc.SoftwareTitleByID(ctx, titleID, ptr.Uint(42))

// Rename a software title (bundle ID required)
err := svc.UpdateSoftwareName(ctx, titleID, "My Custom App Name")

// Update auto-update config for a title
err := svc.UpdateSoftwareTitleAutoUpdateConfig(ctx, titleID, ptr.Uint(42), fleet.SoftwareAutoUpdateConfig{
    AutoUpdate: true,
})
```

## Notes

- **License gating**: Team-scoped queries and CVSS-based filtering (`MaximumCVSS`, `MinimumCVSS`, `KnownExploit`) require a Premium license.
- `InstallDuringSetup` is stripped from list responses but retained in single-title responses.
- iOS/iPadOS VPP and in-house app configurations (plist) are JSON-marshalled as strings before being returned.
- Cursor-based pagination is disabled for software titles; only offset-based pagination is supported.
