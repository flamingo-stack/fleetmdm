Provides Fleet MDM client methods for managing users via the Fleet API, including creation, listing, role assignment, deletion, and session introspection.

## Key Components

| Function | Description |
|---|---|
| `CreateAPIOnlyUser` | Creates an API-only user with a name, global role, and team assignments; returns the API token |
| `CreateUser` | Creates a user bypassing the invitation flow using a `fleet.UserPayload`; returns a token for API-only users |
| `ListUsers` | Retrieves all users from the Fleet instance |
| `ApplyUsersRoleSecretSpec` | Bulk-applies global and team role assignments from a `fleet.UsersRoleSpec` |
| `userIdFromEmail` | Internal helper that resolves a user's numeric ID from their email address via the translate endpoint |
| `DeleteUser` | Deletes a user by email (resolves to ID internally before deletion) |
| `Me` | Returns the `fleet.User` associated with the currently authenticated session |

## Usage Example

```go
client, _ := service.NewClient(serverURL, true, "", "")

// Create an API-only user with observer role
role := "observer"
token, err := client.CreateAPIOnlyUser("ci-bot", &role, []fleet.UserTeam{})
if err != nil {
    log.Fatal(err)
}
fmt.Println("API token:", *token)

// List all users
users, err := client.ListUsers()
if err != nil {
    log.Fatal(err)
}
for _, u := range users {
    fmt.Println(u.Email)
}

// Delete a user by email
if err := client.DeleteUser("old-user@example.com"); err != nil {
    log.Fatal(err)
}

// Get the current authenticated user
me, err := client.Me()
if err != nil {
    log.Fatal(err)
}
fmt.Println("Logged in as:", me.Email)
```

## Notes

- All methods use `authenticatedRequest`, requiring a valid session token on the `Client`.
- `DeleteUser` performs a two-step operation: email → ID translation, then deletion.
- The API token is only returned on user creation for API-only users; it is `nil` for standard users.
