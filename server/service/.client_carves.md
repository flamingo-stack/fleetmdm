Provides HTTP client methods for interacting with Fleet's file carving API, enabling listing, retrieval, and streaming download of osquery file carve sessions.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `ListCarves` | Method | Returns all carve sessions; supports filtering expired carves via `CarveListOptions` |
| `GetCarve` | Method | Fetches metadata for a single carve by numeric ID |
| `getCarveBlock` | Method (private) | Retrieves a single data block from a carve by carve ID and block ID |
| `carveReader` | Struct | Implements `io.Reader` for streaming carve data block-by-block |
| `newCarveReader` | Constructor | Initializes a `carveReader` with carve metadata and an authenticated client |
| `DownloadCarve` | Method | Returns an `io.Reader` that streams the full carve content by sequentially fetching blocks |

## Usage Example

```go
client, _ := service.NewClient(...)

// List all active carves
carves, err := client.ListCarves(fleet.CarveListOptions{Expired: false})
if err != nil {
    log.Fatal(err)
}

// Get metadata for a specific carve
meta, err := client.GetCarve(42)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Carve size: %d bytes\n", meta.CarveSize)

// Stream carve data to a file
reader, err := client.DownloadCarve(42)
if err != nil {
    log.Fatal(err)
}
outFile, _ := os.Create("carve_42.tar")
defer outFile.Close()
io.Copy(outFile, reader)
```

## Notes

- `carveReader.Read` lazily fetches blocks from the API only when the internal buffer is exhausted, minimising memory usage for large carves.
- All methods use `AuthenticatedDo` and expect a valid Fleet session token on the client.
