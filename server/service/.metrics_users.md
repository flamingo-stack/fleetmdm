Metrics instrumentation middleware for user-related service methods, wrapping each operation with request count and latency tracking using labeled Prometheus-style metrics.

## Key Components

| Method | Description |
|---|---|
| `CreateUserFromInvite` | Tracks user creation via invite |
| `ModifyUser` | Tracks user modification by ID |
| `User` | Tracks single user lookup |
| `ListUsers` | Tracks user list retrieval |
| `AuthenticatedUser` | Tracks authenticated user context lookup |
| `ChangePassword` | Tracks password change operations |
| `ResetPassword` | Tracks password reset via token |
| `RequestPasswordReset` | Tracks password reset email requests |

Each method follows the same pattern:
- Defers a closure capturing `time.Now()` at call start
- Records `requestCount` and `requestLatency` with `method` and `error` label values
- Delegates to the underlying `mw.Service` implementation

## Usage Example

```go
// metricsMiddleware wraps a fleet.Service implementation
var svc fleet.Service = newBaseService(ds)

svc = metricsMiddleware{
    Service:        svc,
    requestCount:   kitprometheus.NewCounterFrom(stdprometheus.CounterOpts{
        Name: "request_count",
    }, []string{"method", "error"}),
    requestLatency: kitprometheus.NewSummaryFrom(stdprometheus.SummaryOpts{
        Name: "request_latency_seconds",
    }, []string{"method", "error"}),
}

// All user operations are now instrumented automatically
user, err := svc.User(ctx, userID)
```
