HTTP service layer for Apple VPP (Volume Purchase Program) token and App Store app management, providing endpoint handlers and stub service implementations that return `fleet.ErrMissingLicense` for all operations (indicating these features require a Fleet premium license).

## Key Components

### App Store App Endpoints

| Function | Method | Description |
|---|---|---|
| `getAppStoreAppsEndpoint` | `GET` | Lists available App Store apps for a team |
| `addAppStoreAppEndpoint` | `POST` | Adds an App Store app to a team via VPP |
| `updateAppStoreAppEndpoint` | `PATCH` | Updates app settings including labels, self-service, and auto-update config |

### VPP Token Endpoints

| Function | Method | Description |
|---|---|---|
| `uploadVPPTokenEndpoint` | `POST /vpp_tokens` | Uploads a new VPP token via multipart form |
| `patchVPPTokenRenewEndpoint` | `PATCH /vpp_tokens/:id/renew` | Renews an existing VPP token by ID |
| `patchVPPTokensTeams*` | `PATCH /vpp_tokens/:id/teams` | Associates a VPP token with teams |

### Request/Response Structs

- `addAppStoreAppRequest` — includes label targeting (`LabelsIncludeAny`, `LabelsExcludeAny`, `LabelsIncludeAll`), platform, self-service flag, auto-install, categories, and raw JSON configuration
- `updateAppStoreAppRequest` — supports display name, auto-update window (start/end time), and all label fields
- `uploadVPPTokenRequest` / `patchVPPTokenRenewRequest` — implement custom `DecodeRequest` for multipart file parsing

## Usage Example

```go
// All service methods return ErrMissingLicense in the base (non-premium) implementation.
// Premium implementation overrides these stubs.

apps, err := svc.GetAppStoreApps(ctx, &teamID)
if errors.Is(err, fleet.ErrMissingLicense) {
    // Feature requires Fleet premium license
}

// Upload a VPP token (multipart/form-data with "token" field)
tok, err := svc.UploadVPPToken(ctx, tokenFileReader)

// Add an App Store app to a team
titleID, name, err := svc.AddAppStoreApp(ctx, &teamID, fleet.VPPAppTeam{
    VPPAppID:    fleet.VPPAppID{AdamID: "123456789", Platform: fleet.MacOSPlatform},
    SelfService: true,
})
```

> **Note:** All methods in this file are license-gated stubs. The actual implementations reside in the Fleet premium service layer and override these via interface composition.
