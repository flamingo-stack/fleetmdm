Handles HTTP endpoints and service methods for managing software title icons, including fetching, uploading, validating, and deleting PNG icons associated with software titles in Fleet MDM.

## Key Components

### Request/Response Types
- **`getSoftwareTitleIconsRequest`** / **`getSoftwareTitleIconsResponse`** — GET endpoint structs; response supports `HijackRender` to stream raw PNG bytes directly to the HTTP response
- **`getSoftwareTitleIconsRedirectResponse`** — Issues a `302` redirect to a VPP app icon URL when the icon is externally hosted
- **`putSoftwareTitleIconRequest`** / **`putSoftwareTitleIconResponse`** — PUT endpoint structs; implements custom `DecodeRequest` for multipart form parsing
- **`deleteSoftwareTitleIconRequest`** / **`deleteSoftwareTitleIconResponse`** — DELETE endpoint structs

### Endpoint Handlers
- **`getSoftwareTitleIconsEndpoint`** — Retrieves an icon; redirects to external URL for VPP apps or streams stored PNG data
- **`putSoftwareTitleIconEndpoint`** — Accepts a new icon via multipart upload or an existing storage reference (`hash_sha256` + `filename`)
- **`deleteSoftwareTitleIconEndpoint`** — Removes an icon for a given title and team

### Service Methods
- **`GetSoftwareTitleIcon`**, **`UploadSoftwareTitleIcon`**, **`DeleteSoftwareTitleIcon`** — Base service stubs that return `fleet.ErrMissingLicense`; overridden in licensed builds

### Validation
- **`ValidateIcon(file io.ReadSeeker) error`** — Validates an uploaded PNG: max 100 KB, dimensions 120×120 to 1024×1024, must be square

## Usage Example

```go
// Validate an icon before uploading
f, _ := os.Open("icon.png")
defer f.Close()

if err := service.ValidateIcon(f); err != nil {
    log.Fatalf("invalid icon: %v", err)
}
```

> **Note:** All three service methods return `fleet.ErrMissingLicense` in the open-source build. Licensed implementations override these methods to provide full functionality.
