Handles Fleet application configuration management, including reading, modifying, and validating global AppConfig settings. It manages obfuscation of sensitive fields, role-based field visibility, and serialization of the composite config response.

## Key Components

- **`appConfigResponse`** — Composite response struct combining `fleet.AppConfig` with runtime fields (license, logging, update intervals, vulnerabilities, partnerships)
- **`getAppConfigEndpoint`** — Returns the current app config, filtering fields by role (global admin, team admin) and applying license-gated features
- **`modifyAppConfigEndpoint`** — Handles PATCH requests to update app config with support for `force`, `dry_run`, and `overwrite` query params
- **`AppConfigObfuscated`** — Service method that fetches, normalizes logo URL fields, absolutizes relative URLs, and obfuscates sensitive values before returning
- **`AppConfigUrls`** — Returns a minimal URL-only subset of AppConfig, skipping authorization
- **`SandboxEnabled`** — Reports whether the server was started with sandbox mode enabled
- **`applyAndValidateConditionalAccessOktaFields`** — Validates and merges Okta conditional access settings during config modification

## Usage Example

```go
// Fetch obfuscated app config (used internally by endpoint handlers)
ac, err := svc.AppConfigObfuscated(ctx)
if err != nil {
    return nil, err
}

// Modify app config via raw JSON payload
updated, err := svc.ModifyAppConfig(ctx, rawJSON, fleet.ApplySpecOptions{
    Force:  false,
    DryRun: true,
})
if err != nil {
    return nil, err
}

// Fetch minimal URL config without authorization (e.g., device enrollment flows)
urls, err := svc.AppConfigUrls(ctx)
```

## Notes

- SMTP and SSO settings are only visible to global admins and team admins
- Agent options are restricted to global admins only
- `TransparencyURL` and `AlternativeBrowserHost` require a Fleet Premium license
- Logo URL normalization (`NormalizeLogoFields`, `AbsolutizeLogoURLs`) occurs at read time; persisted values remain in their original form
