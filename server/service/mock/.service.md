Mock service package entry point that defines `go:generate` directives for auto-generating mock implementations of core Fleet service interfaces.

## Key Components

| Directive | Generated File | Mocked Interface |
|---|---|---|
| `TLSService` | `service_osquery.go` | `fleet.OsqueryService` |
| `APNSPushProviderFactory` | `service_pusher_factory.go` | `push.PushProviderFactory` |
| `APNSPushProvider` | `service_push_provider.go` | `push.PushProvider` |

## Usage Example

Run the code generators from the package directory:

```bash
go generate ./server/mock/...
```

This regenerates all three mock files using the `mockimpl` tool, which introspects the target interfaces and produces concrete stub structs.

Consume a generated mock in tests:

```go
import "github.com/fleetdm/fleet/v4/server/mock"

svc := &mock.TLSService{}
svc.EnrollAgentFunc = func(ctx context.Context, nodeKey string) (string, error) {
    return "test-node-key", nil
}
```

## Notes

- Generated files should not be edited manually — changes will be overwritten on the next `go generate` run.
- The `mockimpl` generator at `../../mock/mockimpl/impl.go` reads receiver signatures and interface paths to produce function-field-based mocks compatible with Fleet's testing patterns.
- Source: [`server/mock/service.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mock/service.go)
