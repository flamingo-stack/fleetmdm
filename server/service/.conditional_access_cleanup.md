Handles post-enrollment cleanup of orphaned Okta conditional access SCEP certificates on macOS hosts by scheduling a shell script after a successful MDM `InstallProfile` command.

## Key Components

- **`deleteDuplicateOktaSCEPScript`** — Embedded bash script (sourced from `embedded_scripts/delete-duplicate-scep-certificates.sh`) that removes duplicate SCEP certificates from the per-user keychain.
- **`validMacOSShortNameRE`** — Compiled regex that validates macOS short usernames (1–31 chars, alphanumeric + `_`, `.`, `-`) before interpolating them into a shell command.
- **`buildOktaCACleanupScript(username string) (string, bool)`** — Composes the final script by prepending positional arguments (auto-confirm flag, target username, certificate CN) to the embedded script. Returns `false` if the username fails validation.
- **`shellSingleQuote(s string) string`** — POSIX-safe single-quote wrapper using the `'foo'"'"'bar'` escape idiom to prevent shell injection.
- **`maybeRunOktaCACleanupScript(ctx, hostUUID, commandUUID string) error`** — Entry point called after a successful `InstallProfile` MDM ack. Looks up the cleanup target via the datastore, validates the username, and enqueues an async host script execution request. Silently no-ops when the command does not relate to the Okta CA profile.

## Usage Example

```go
// Called inside the InstallProfile MDM acknowledgement handler:
if err := svc.maybeRunOktaCACleanupScript(ctx, host.UUID, commandUUID); err != nil {
    level.Error(svc.logger).Log("msg", "Okta CA cleanup script enqueue failed", "err", err)
    // err is logged but must not fail the ack path
}
```

## Notes

- The embedded script must stay byte-identical to `docs/solutions/macos/scripts/delete-duplicate-scep-certificates.sh`; an `embed_sync` test enforces this.
- Username validation is intentionally strict — any malformed value from `nano_users` is silently skipped rather than dispatched.
