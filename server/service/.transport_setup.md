Decodes incoming HTTP request bodies for the Fleet MDM setup endpoint by parsing JSON payloads into a `setupRequest` struct.

## Key Components

- **`decodeSetupRequest`** — Transport-layer decoder that reads and unmarshals the JSON body of an HTTP request into a `setupRequest` value, returning an error if decoding fails.

## Usage Example

```go
// Typically wired into a Go kit (or similar) HTTP handler:
handler := httptransport.NewServer(
    setupEndpoint,
    decodeSetupRequest,
    encodeResponse,
)
```

> **Note:** This function follows the `go-kit/kit/transport/http` decoder signature (`func(context.Context, *http.Request) (interface{}, error)`), making it compatible with standard Go kit transport wiring.
