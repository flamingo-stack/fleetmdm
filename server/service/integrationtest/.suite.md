Provides shared test suite infrastructure for Fleet integration tests, including base suite setup, authentication helpers, and service/datastore initialization utilities.

## Key Components

### `BaseSuite`
A reusable test suite struct embedding common dependencies:
- `DS` — MySQL datastore instance
- `Server` — in-process HTTP test server
- `Users` / `Token` — pre-configured test users and session token
- `cachedAdminToken` — rate-limit-aware cached admin token

### Methods
- **`GetTestAdminToken`** — Returns a cached admin token to avoid triggering login rate limits; clears `cachedAdminToken` manually if re-authentication is needed
- **`GetTestToken`** — Authenticates a user by email/password against the test server and returns a session token

### Setup Helpers
- **`SetUpServerURL`** — Persists the test server's URL into the app config, ensuring services resolve callbacks correctly
- **`SetUpMySQLAndService`** — Creates a MySQL datastore, seeds the `All Hosts` label, configures `AppConfig`, and returns a Fleet service with context
- **`SetUpMySQLAndRedisAndService`** — Extends `SetUpMySQLAndService` with a Redis pool for tests requiring caching or pub/sub

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    ds, fleetCfg, fleetSvc, ctx := integrationtest.SetUpMySQLAndService(
        t, "my_feature_test",
    )
    _ = fleetCfg
    _ = ctx

    // Use ds and fleetSvc in your test
    hosts, err := ds.ListHosts(ctx, fleet.TeamFilter{}, fleet.HostListOptions{})
    require.NoError(t, err)
    _ = hosts
}

// With Redis
func TestMyCachedFeature(t *testing.T) {
    ds, redisPool, _, _, ctx := integrationtest.SetUpMySQLAndRedisAndService(
        t, "my_cached_feature_test",
    )
    _ = redisPool
    _ = ctx
}
```
