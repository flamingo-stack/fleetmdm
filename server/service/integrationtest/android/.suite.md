Provides the test suite setup for Android MDM integration tests, wiring together a MySQL datastore, Redis, Fleet service, and a mock Android proxy client into a runnable test server.

## Key Components

- **`Suite`** — Embeds `integrationtest.BaseSuite` and exposes an `AndroidProxy` mock client for asserting Android MDM interactions.
- **`SetUpSuite`** — Bootstraps the full integration test environment including:
  - MySQL + Redis via `integrationtest.SetUpMySQLAndRedisAndService`
  - A mock `android_mock.Client` with common mocks pre-initialized
  - An `android_service.Service` configured with a test private key and agent package metadata
  - A test HTTP server with Android feature routes registered via `android_service.GetRoutes`
  - An admin token stored on the suite for authenticated requests

## Usage Example

```go
package android_test

import (
    "testing"

    androidtest "github.com/fleetdm/fleet/v4/server/mdm/android/integrationtest"
)

type MyAndroidSuite struct {
    *androidtest.Suite
}

func TestMyAndroidFeature(t *testing.T) {
    s := androidtest.SetUpSuite(t, "TestMyAndroidFeature")

    // Use s.AndroidProxy to configure or assert mock behavior
    s.AndroidProxy.OnSomeCall = func(...) { ... }

    // Make authenticated HTTP requests using s.Server and s.Token
    resp := s.DoRawRequest(t, "GET", "/api/v1/fleet/android/...", nil, s.Token)
    // assert response...
}
```

## Notes

- `AllowLocalhostServerURL` is set to `true` on the Android service to permit test server URLs.
- The suite runs with a `TierFree` license by default; override `TestServerOpts` if premium-tier features are needed.
