HTTP helper methods for the `integrationtest` package that provide a layered API for making authenticated HTTP requests and decoding JSON responses in test suites.

## Key Components

- **`DoJSON`** — Makes an HTTP request and unmarshals the JSON response body into `v`; also checks for `fleet.Errorer` interface to surface API-level errors.
- **`Do`** — Marshals `params` to JSON, delegates to `DoRaw`, and registers a cleanup to close the response body.
- **`DoRaw`** — Wraps `DoRawWithHeaders` with a default `Authorization: Bearer <token>` header using `s.Token`.
- **`DoRawWithHeaders`** — Core request executor; builds a `fleethttp` client (disabling redirects for 3xx expectations) and delegates to `httptest.DoHTTPReq`.
- **`decodeJSON`** — Thin adapter satisfying the decoder interface expected by `httptest.DoHTTPReq`, backed by `json.UnmarshalRead`.

## Usage Example

```go
// Make an authenticated POST and decode the response
var result fleet.SomeResponse
s.DoJSON(t, "POST", "/api/v1/fleet/some-endpoint", fleet.SomeRequest{
    Field: "value",
}, http.StatusOK, &result)

// Make a raw request with custom headers
resp := s.DoRawWithHeaders(t, "GET", "/api/v1/fleet/resource", nil,
    http.StatusOK,
    map[string]string{
        "Authorization": "Bearer custom-token",
        "X-Custom-Header": "value",
    },
)

// Test a redirect without following it
resp := s.DoRaw(t, "GET", "/api/v1/fleet/redirect", nil, http.StatusTemporaryRedirect)
location := resp.Header.Get("Location")
```

## Notes

- All methods are defined on `*BaseSuite`, making them available across any suite that embeds it.
- Redirect-following is automatically disabled when `expectedStatusCode` is in the `300–399` range.
- Response body cleanup is registered via `t.Cleanup` in `Do`, preventing resource leaks across tests.
