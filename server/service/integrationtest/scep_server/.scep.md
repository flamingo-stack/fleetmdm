Provides a self-contained SCEP (Simple Certificate Enrollment Protocol) test server for use in Go integration tests, embedding a test CA and issuing certificates in-memory without disk I/O.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `StartTestSCEPServer` | `func(t *testing.T) *httptest.Server` | Spins up a fully functional SCEP HTTP test server backed by an embedded test CA |
| `noopCertDepot` | `struct` | Wraps a `scepdepot.Depot` and silently discards `Put` calls to avoid writing issued certs to disk |
| `newInMemorySigner` | `func` | Returns a `CSRSignerContextFunc` that signs CSRs directly against the test CA in memory, with atomic serial number generation for concurrent safety |
| `caCert`, `caKey`, `caPem` | `[]byte` | Embedded test CA credentials loaded at compile time from `testdata/` |

## Usage Example

```go
func TestMyMDMFeature(t *testing.T) {
    scepServer := scep_server.StartTestSCEPServer(t)
    // scepServer.URL → e.g. "http://127.0.0.1:PORT"
    // Point your Fleet/MDM client at scepServer.URL + "/scep"
    _ = scepServer.URL
}
```

The test server:
- Writes the embedded CA files to a `t.TempDir()` (auto-cleaned after the test)
- Registers a `/scep` route via `gorilla/mux`
- Issues 1-year client-auth certificates signed by the test CA
- Skips SCEP challenge validation, making enrollment frictionless in tests
- Is safe for concurrent certificate requests due to the `atomic.Int64` serial counter

## Notes

- The embedded `testdata/ca.*` files must exist at compile time; they are not generated at runtime.
- `noopCertDepot` prevents issued certificates from accumulating on disk during test runs.
- The server is automatically shut down via `t.Cleanup` when the test completes.
