Handles asynchronous recording and collection of policy query execution results for Fleet hosts, using Redis as an intermediate buffer before persisting data to the datastore.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `policyPassHostIDsKey` | constant | Redis key for the set of active host IDs with pending policy results |
| `policyPassHostKey` | constant | Redis key template for a host's policy result list |
| `policyPassReportedKey` | constant | Redis key template storing the last-reported timestamp per host |
| `maxRedisPolicyResultsPerHost` | variable | Cap on policy results stored per host in Redis (default: 1000) |
| `RecordPolicyQueryExecutions` | method | Buffers host policy results into Redis; falls back to direct datastore write if async is disabled |
| `collectPolicyQueryExecutions` | method | Collector that drains Redis buffers and batch-inserts policy membership results into the datastore |
| `GetHostPolicyReportedAt` | method | Returns the most recent policy-reported timestamp, preferring the Redis value over the host's stored value |

## Usage Example

```go
// Recording policy results asynchronously
results := map[uint]*bool{
    42: ptr.Bool(true),   // policy 42 passed
    17: ptr.Bool(false),  // policy 17 failed
    99: nil,              // policy 99 had no result
}
err := task.RecordPolicyQueryExecutions(ctx, host, results, time.Now(), false, []uint{42})

// Retrieving the most recent reported-at time for a host
reportedAt := task.GetHostPolicyReportedAt(ctx, host)

// The collector runs on a schedule via the task runner and calls:
// task.collectPolicyQueryExecutions(ctx, ds, pool, stats)
```

## Notes

- Policy results are encoded as `policy_id=1` (pass), `policy_id=-1` (fail), or `policy_id=0` (null) in Redis lists.
- Redis keys carry a TTL of at least 1 week (or 10× the collect interval) to handle deleted hosts and ensure the collector can process data before expiry.
- In Redis Cluster mode, the active host ID set (`policyPassHostIDsKey`) may reside on a different node than host-specific keys, so it is updated outside the Lua script.
