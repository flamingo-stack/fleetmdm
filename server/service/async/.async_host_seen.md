Manages async tracking of host "last seen" timestamps, supporting both synchronous (in-memory) and asynchronous (Redis-backed) modes for recording and flushing host activity.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `RecordHostLastSeen` | method | Records a host ID as seen; stores in Redis SET (async) or in-memory set (sync) |
| `FlushHostsLastSeen` | method | Flushes in-memory seen hosts to MySQL; no-op when async mode is enabled |
| `collectHostsLastSeen` | method | Collector cron handler; batches Redis-stored host IDs and marks them seen in MySQL |
| `loadSeenHostsIDs` | method | Atomically moves the recorded Redis SET to a processing SET via Lua script, then scans and returns all IDs |
| `seenHostSet` | struct | Thread-safe in-memory set of host IDs using a `sync.Mutex`-protected map |
| `addHostID` | method | Adds a host ID to the in-memory set |
| `getAndClearHostIDs` | method | Atomically drains and returns all host IDs from the in-memory set |

### Redis Keys

| Key | Purpose |
|---|---|
| `{host_seen:host_ids}` | Pending host ID SET |
| `{host_seen:host_ids}:processing` | In-flight host ID SET during collection |

## Usage Example

```go
// Async mode — record host activity (stored in Redis)
if err := task.RecordHostLastSeen(ctx, hostID); err != nil {
    log.Error(err)
}

// Sync mode — flush in-memory seen hosts to the datastore
if err := task.FlushHostsLastSeen(ctx, time.Now()); err != nil {
    log.Error(err)
}
```

> **TTL policy:** The Redis SET TTL is the greater of 1 week or `10 × CollectInterval`, preventing stale data accumulation if async collection is paused.
