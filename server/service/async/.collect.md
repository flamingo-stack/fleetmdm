Implements a periodic background collector that acquires a distributed Redis lock before executing a handler function, tracking execution statistics across runs.

## Key Components

- **`collector`** — Core struct holding configuration (name, Redis pool, datastore, intervals) and mutable stats protected by a `sync.RWMutex`.
- **`collectorHandlerFunc`** — Function signature `func(context.Context, fleet.Datastore, fleet.RedisPool, *collectorExecStats) error` that collectors implement to perform their actual work.
- **`collectorStats`** — Cumulative statistics (exec/skip/failure counts, min/max/last values for duration, keys, items, inserts, updates, deletes, Redis commands).
- **`collectorExecStats`** — Per-run stats populated by the handler and rolled into `collectorStats` after each execution.
- **`Start(ctx)`** — Blocking loop that sleeps for `nextRunAfter()` then calls `exec`. Exits when context is cancelled.
- **`exec(ctx)`** — Acquires a Redis `SET NX EX` lock; skips the run (recording a skip) if the lock is unavailable, executes the handler with a deadline equal to `lockTimeout` if acquired.
- **`nextRunAfter()`** — Returns `execInterval` ± a random jitter up to `jitterPct`% to spread load across distributed instances.
- **`ReadStats()`** — Thread-safe snapshot of current `collectorStats`.

## Usage Example

```go
c := &collector{
    name:         "policy_results",
    pool:         redisPool,
    ds:           datastore,
    execInterval: 30 * time.Second,
    jitterPct:    10,
    lockTimeout:  25 * time.Second,
    handler: func(ctx context.Context, ds fleet.Datastore, pool fleet.RedisPool, stats *collectorExecStats) error {
        // flush buffered data from Redis into the datastore
        stats.Items = 42
        stats.Inserts = 10
        return nil
    },
    errHandler: func(name string, err error) {
        log.Printf("collector %s error: %v", name, err)
    },
}

go c.Start(ctx)

// Later, inspect stats
s := c.ReadStats()
fmt.Printf("executions=%d failures=%d lastDuration=%s\n",
    s.ExecCount, s.FailuresCount, s.LastExecDuration)
```
