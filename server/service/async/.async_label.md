Handles asynchronous recording and collection of label query execution results for Fleet hosts, buffering label membership changes in Redis before bulk-flushing them to MySQL.

## Key Components

| Symbol | Description |
|--------|-------------|
| `RecordLabelQueryExecutions` | Buffers label membership changes (inserts/deletes) into Redis sorted sets per host, with TTL management and active host ID tracking |
| `collectLabelQueryExecutions` | Collector that drains Redis sorted sets and bulk-writes label membership changes to the datastore in configurable batches |
| `GetHostLabelReportedAt` | Returns the most recent label report timestamp for a host, preferring the Redis-cached value over the DB value |
| `labelMembershipHostKey` | Per-host Redis sorted set key storing pending label changes (`score: +1` = insert, `-1` = delete) |
| `labelMembershipReportedKey` | Per-host Redis key storing the Unix timestamp of the last label report |
| `labelMembershipActiveHostIDsKey` | Global Redis set tracking host IDs with pending label membership changes |

## Usage Example

```go
// Record label results asynchronously during host check-in
results := map[uint]*bool{
    42: ptr.Bool(true),  // host is a member of label 42
    17: ptr.Bool(false), // host is not a member of label 17
}
err := task.RecordLabelQueryExecutions(ctx, host, results, time.Now(), false)

// Retrieve the most recent label report time for a host
// (may return a Redis-cached value newer than what's in MySQL)
reportedAt := task.GetHostLabelReportedAt(ctx, host)
```

The collector (`collectLabelQueryExecutions`) runs on a schedule, popping changes from Redis via `ZPOPMIN` and flushing them to MySQL using `AsyncBatchInsertLabelMembership` and `AsyncBatchDeleteLabelMembership`. OpenTelemetry tracing is emitted when enabled.
