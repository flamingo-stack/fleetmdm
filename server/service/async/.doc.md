Provides package-level documentation for the `async` package, which handles asynchronous service task processing using a Redis-backed buffering pattern to prevent thundering herd problems in high-host-count deployments.

## Key Components

This file contains only the package declaration and documentation comment. The core implementation is distributed across other files in the `async` package, which collectively provide:

- **Redis hot path buffering** – Temporary storage for high-frequency write operations
- **Background MySQL flushing** – Periodic, controlled draining of buffered data to persistent storage
- **Thundering herd mitigation** – Decouples write load from the persistent database layer

## Usage Example

```go
// The async package is used internally by FleetMDM services to offload
// high-frequency writes (e.g., host check-ins, live query results) away
// from MySQL on the hot path.

import "github.com/flamingo-stack/fleetmdm/server/service/async"

// Implementations in this package follow the pattern of:
// 1. Writing incoming data to Redis immediately
// 2. Running a background collector that periodically flushes Redis → MySQL
collector := async.NewCollector(redisPool, mysqlDB, flushInterval)
collector.Run(ctx)
```
