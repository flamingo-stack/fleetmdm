Metrics middleware implementation for session-related service methods, wrapping each operation with Prometheus-style request count and latency instrumentation.

## Key Components

| Method | Description |
|---|---|
| `Login` | Authenticates a user and records metrics for the login operation |
| `GetSessionDuration` | Passthrough proxy returning the configured session duration (no metrics) |
| `Logout` | Ends the current session and records metrics |
| `DestroySession` | Destroys the current context session and records metrics |
| `GetInfoAboutSessionsForUser` | Retrieves all sessions for a user ID and records metrics |
| `DeleteSessionsForUser` | Removes all sessions for a user ID and records metrics |
| `GetInfoAboutSession` | Fetches details for a single session by ID and records metrics |
| `DeleteSession` | Removes a single session by ID and records metrics |

Each instrumented method uses a `defer` closure to capture:
- **`requestCount`** — incremented by 1 per call, labelled with `method` and `error` status
- **`requestLatency`** — observed duration in seconds from call start to return

## Usage Example

```go
// metricsMiddleware wraps an existing fleet.Service implementation
svc := metricsMiddleware{
    Service:        baseService,
    requestCount:   kitprometheus.NewCounterFrom(...),
    requestLatency: kitprometheus.NewSummaryFrom(...),
}

// Login is automatically instrumented
user, session, err := svc.Login(ctx, "user@example.com", "password", true)

// GetSessionDuration is a passthrough — no metrics recorded
duration := svc.GetSessionDuration(ctx)

// Destroy all sessions for a user — metrics recorded on completion
err = svc.DeleteSessionsForUser(ctx, userID)
```

## Notes

- `GetSessionDuration` is the only method **not** instrumented — it delegates directly to the underlying service.
- Label values use `fmt.Sprint(err != nil)` to produce `"true"` / `"false"` error tags on all metrics.
