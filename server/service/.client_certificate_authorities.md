Provides HTTP client methods for managing Certificate Authorities (CAs) in Fleet MDM, including fetching, applying, and listing CA configurations via the Fleet API.

## Key Components

| Function | Description |
|---|---|
| `GetCertificateAuthoritiesSpec` | Fetches grouped CA specs from the server; optionally includes secrets via query param |
| `ApplyCertificateAuthoritiesSpec` | Applies (batch upserts) CA specs with support for dry-run and skip-deletes options |
| `GetCertificateAuthorities` | Lists all CA summaries from the server |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Fetch CAs (with secrets)
spec, err := client.GetCertificateAuthoritiesSpec(true)

// Apply CA specs with dry-run
err = client.ApplyCertificateAuthoritiesSpec(
    groupedCAs,
    fleet.ApplySpecOptions{DryRun: true},
    fleet.BatchApplyCertificateAuthoritiesOpts{SkipDeletes: false},
)

// List all CA summaries
cas, err := client.GetCertificateAuthorities()
```

## API Endpoints

| Method | Endpoint | Used By |
|---|---|---|
| `GET` | `/api/latest/fleet/spec/certificate_authorities` | `GetCertificateAuthoritiesSpec` |
| `POST` | `/api/latest/fleet/spec/certificate_authorities` | `ApplyCertificateAuthoritiesSpec` |
| `GET` | `/api/latest/fleet/certificate_authorities` | `GetCertificateAuthorities` |
