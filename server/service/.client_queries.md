Client query methods for interacting with the Fleet API's query/report spec endpoints, supporting create, read, and delete operations.

## Key Components

| Function | Description |
|---|---|
| `ApplyQueries` | Upserts a list of query specs via `POST /api/latest/fleet/spec/reports` |
| `GetQuerySpec` | Fetches a single query spec by team ID and name via `GET /api/latest/fleet/spec/reports/{name}` |
| `GetQueries` | Lists all queries, optionally filtered by team ID or name via `GET /api/latest/fleet/reports` |
| `DeleteQuery` | Deletes a single query by name via `DELETE /api/latest/fleet/reports/{name}` |
| `DeleteQueries` | Bulk-deletes queries by ID list via `POST /api/latest/fleet/reports/delete` |

## Usage Example

```go
client, _ := service.NewClient(...)

// Upsert queries
specs := []*fleet.QuerySpec{{Name: "os_info", Query: "SELECT * FROM os_version;"}}
err := client.ApplyQueries(specs)

// Retrieve a single query spec scoped to a team
teamID := uint(1)
spec, err := client.GetQuerySpec(&teamID, "os_info")

// List all queries for a team
queries, err := client.GetQueries(&teamID, nil)

// Delete a single query by name
err = client.DeleteQuery("os_info")

// Bulk delete by IDs
err = client.DeleteQueries([]uint{1, 2, 3})
```

## Notes

- All methods use `authenticatedRequest` or `authenticatedRequestWithQuery`, requiring a valid session.
- Query names and paths are safely encoded via `url.PathEscape` to handle special characters.
- `GetQuerySpec` and `GetQueries` accept an optional `teamID` pointer; passing `nil` targets the global (no-team) scope.
