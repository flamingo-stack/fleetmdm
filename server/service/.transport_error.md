Defines Fleet-specific HTTP error types and encoding logic for translating `MailError` and `OsqueryError` into structured JSON responses.

## Key Components

- **`FleetErrorEncoder`** — Custom error encoder that handles `MailError` and `OsqueryError` types, writing appropriate HTTP status codes and JSON bodies. Returns `true` if the error was handled, `false` otherwise.
- **`MailError`** — Simple error type for mail operation failures, serialized as a `500 Internal Server Error` with a named error field.
- **`OsqueryError`** — Error type for osquery agent responses. Supports `node_invalid` signaling (401), custom status codes, and UUID tracking via `platform_http.ErrorWithUUID`. Implements `IsClientError()` to distinguish 4xx from 5xx scenarios.
- **`NewOsqueryError`** — Constructor for `OsqueryError` with message and `nodeInvalid` flag.
- **`encodeError` / `fleetErrorEncoder`** — Internal adapter functions that wrap `endpointer.EncodeError` with `FleetErrorEncoder` for use in HTTP handlers and `kithttp.ErrorEncoder` contexts.

## Usage Example

```go
// Return an osquery node_invalid error from a handler
func (svc *Service) AuthenticateHost(ctx context.Context, nodeKey string) (*fleet.Host, error) {
    host, err := svc.ds.AuthenticateHost(ctx, nodeKey)
    if err != nil {
        return nil, NewOsqueryError("invalid node key", true)
    }
    return host, nil
}

// Encode errors directly in a handler
func myHandler(ctx context.Context, w http.ResponseWriter, err error) {
    encodeError(ctx, err, w)
}
```
