Provides health check endpoints for the Fleet result store and live query subsystems, used to verify service availability and configuration status.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `statusResponse` | struct | Shared response type implementing `fleet.Errorer` for status endpoints |
| `statusResultStoreEndpoint` | func | HTTP endpoint handler delegating to `StatusResultStore` |
| `StatusResultStore` | method | Authorizes the caller then runs a health check against the result store |
| `statusLiveQueryEndpoint` | func | HTTP endpoint handler delegating to `StatusLiveQuery` |
| `StatusLiveQuery` | method | Authorizes the caller, checks if live queries are disabled, then delegates to `StatusResultStore` |

## Usage Example

```go
// Check result store health directly via the service
if err := svc.StatusResultStore(ctx); err != nil {
    log.Fatalf("result store unhealthy: %v", err)
}

// Check live query status (also validates admin config + result store)
if err := svc.StatusLiveQuery(ctx); err != nil {
    // Returns fleet.PermissionError if live query is disabled by admin,
    // or a wrapped error if app config or result store health check fails.
    log.Printf("live query unavailable: %v", err)
}
```

Both methods require the caller to hold `fleet.ActionRead` on `fleet.AppConfig`. `StatusLiveQuery` additionally returns a `fleet.PermissionError` when `ServerSettings.LiveQueryDisabled` is `true` in the app config.
