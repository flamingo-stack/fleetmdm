Handles device-facing API endpoints for Fleet, including device authentication, host detail retrieval, Fleet Desktop summaries, and ping capabilities.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `devicePingEndpoint` | Handler | Unauthenticated ping endpoint that returns server capabilities header |
| `getFleetDesktopEndpoint` | Handler | Returns desktop summary data for Fleet Desktop client |
| `getDeviceHostEndpoint` | Handler | Returns full host details for the authenticated device |
| `AuthenticateDevice` | Method | Validates a device auth token (1hr TTL) and returns the associated host |
| `AuthenticateDeviceByCertificate` | Method | Validates iOS/iPadOS devices via SCEP certificate serial + host UUID |
| `GetHostDEPAssignment` | Method | Returns DEP assignment status for a host |
| `GetFleetDesktopSummary` | Method | Stub returning `ErrMissingLicense` (license-gated feature) |

## Usage Example

```go
// Authenticate a device by token
host, debugEnabled, err := svc.AuthenticateDevice(ctx, "device-auth-token-here")
if err != nil {
    // handle auth failure
}

// Fetch device host details (called internally via getDeviceHostEndpoint)
opts := fleet.HostDetailOptions{
    IncludeCVEScores: false,
    IncludePolicies:  false,
    ExcludeSoftware:  false,
}
hostDetails, err := svc.GetHost(ctx, host.ID, opts)

// Check DEP assignment for MDM-enrolled host
depAssignment, err := svc.GetHostDEPAssignment(ctx, host)
if err == nil && depAssignment.IsDEPAssignedToFleet() {
    // host is DEP-assigned to Fleet
}
```

## Notes

- iOS/iPadOS devices **must** use certificate-based auth (`AuthenticateDeviceByCertificate`); token auth is rejected for these platforms.
- `getDeviceHostEndpoint` scrubs sensitive fields (serial, UUID, MAC, labels, hostname) from responses for iOS/iPadOS devices.
- Org logo URLs and license info are included in the device host response to support the Fleet Desktop frontend.
- Software inventory and conditional access flags are resolved at the team level when applicable, falling back to global config.
