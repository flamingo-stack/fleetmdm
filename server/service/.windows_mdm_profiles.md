Handles creation, validation, and management of Windows MDM configuration profiles, including Fleet variable substitution, label scoping, OS update conflict detection, and NDES/SCEP certificate validation.

## Key Components

### `NewMDMWindowsConfigProfile`
Creates a new Windows MDM config profile with full validation pipeline:
- Authorization check (team-scoped)
- Windows MDM enabled verification
- Premium license enforcement for teams and label scoping
- Profile XML validation via `ValidateUserProvided()`
- Label include/exclude overlap detection
- Embedded secrets and Fleet variable validation
- OS update conflict detection
- Activity logging on success

### `handleWindowsProfileSoftwareUpdate`
Guards OS update profile creation by ensuring a premium license exists and that Windows OS updates aren't already configured via team/app settings.

### `isWindowsOSUpdatesConfigured`
Reads team or global app config to determine if Windows OS update settings are already active.

### `validateWindowsProfileFleetVariables`
Validates that all `$FLEET_VAR_*` tokens in a profile are on the supported allowlist (`fleetVarsSupportedInWindowsProfiles`) or are known custom SCEP prefix variables. Requires premium license when any variables are present.

### `additionalNDESValidationForWindowsProfiles`
Parses SyncML XML to enforce placement rules: `$FLEET_VAR_NDES_SCEP_CHALLENGE` must only appear in `Challenge` fields and `$FLEET_VAR_NDES_SCEP_PROXY_URL` only in `ServerURL` fields — preventing variable exfiltration via misplaced substitution.

### `collectAllSyncMLItems`
Flattens `SyncMLCmd` items from top-level and nested Atomic block commands (Replace, Add, Exec) into a single slice for uniform iteration.

### Helper Utilities
- `containsFleetVar` / `isFleetVar` — substring/exact match for Fleet variable tokens in both `$FLEET_VAR_` and `${FLEET_VAR_}` forms
- `subjectNameHasRenewalIDMarker` — checks SubjectName fields for renewal ID variables (supports legacy `SCEP_RENEWAL_ID` alias)

## Usage Example

```go
profile, err := svc.NewMDMWindowsConfigProfile(
    ctx,
    teamID,
    "MyWindowsPolicy",
    syncMLBytes,
    []string{"LabA"},           // labelsInclude
    fleet.LabelsIncludeAll,     // membership mode
    []string{"LabB"},           // labelsExcludeAny
)
if err != nil {
    // handle fleet.BadRequestError, fleet.ErrMissingLicense, etc.
}
```

The function returns a `*fleet.MDMWindowsConfigProfile` on success and records a `ActivityTypeCreatedWindowsProfile` audit event.
