Handles the initial Fleet instance setup by sending admin credentials, organization info, and server URL to the setup endpoint, returning an authentication token on success.

## Key Components

### `Setup(email, name, password, org string) (string, error)`
Performs a one-time Fleet instance initialization via `POST /api/v1/setup`. Constructs a `setupRequest` payload containing:
- **Admin user** — email, display name, and password (`fleet.UserPayload`)
- **Organization info** — org name (`fleet.OrgInfo`)
- **Server URL** — derived from the client's configured address

Returns the auth token string on success, or an error on failure.

**Notable behavior:**
- Returns a `setupAlreadyErr{}` sentinel error if the endpoint responds with `404`, indicating setup was previously completed and the route is no longer served.
- Decodes the response into a `setupResponse` struct and surfaces any server-side error from `responseBody.Err`.

## Usage Example

```go
client, err := service.NewClient("https://fleet.example.com", true, "", "")
if err != nil {
    log.Fatal(err)
}

token, err := client.Setup("admin@example.com", "Admin User", "s3cur3pass!", "Acme Corp")
if err != nil {
    if errors.As(err, &service.SetupAlreadyErr{}) {
        log.Println("Fleet is already set up")
    } else {
        log.Fatalf("setup failed: %v", err)
    }
}

fmt.Println("Auth token:", token)
```

## Notes

- This endpoint is only available on a freshly provisioned Fleet instance; subsequent calls will receive a `404`.
- The client address (`c.addr`) is automatically included as the `ServerURL` in the setup payload.
