Provides a client-side method for searching Fleet hosts and labels by query string and target identifiers via the Fleet API.

## Key Components

- **`SearchTargets(query string, hostIDs, labelIDs []uint)`** — Sends an authenticated `POST` request to `/api/latest/fleet/targets`, returning matched hosts and labels as a `*fleet.TargetSearchResults`.

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

results, err := client.SearchTargets("web-servers", []uint{1, 2}, []uint{5})
if err != nil {
    log.Fatal(err)
}

for _, host := range results.Hosts {
    fmt.Println(host.Hostname)
}

for _, label := range results.Labels {
    fmt.Println(label.Name)
}
```

## Notes

- Team ID filtering is not yet implemented (noted via `TODO` in source).
- Response hosts and labels are unwrapped from their API envelope types into plain `*fleet.Host` and `*fleet.Label` slices before being returned.
