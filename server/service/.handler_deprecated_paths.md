Defines the `deprecatedPathAliases` registry that maps legacy API URL paths to their current canonical equivalents, enabling backward-compatible routing without duplicating handler logic.

## Key Components

### `deprecatedPathAliases`

A package-level `[]eu.DeprecatedPathAlias` slice consumed by the router to register alias routes. Each entry specifies:

| Field | Description |
|---|---|
| `Method` | HTTP verb (`GET`, `POST`, `PATCH`, `DELETE`) |
| `PrimaryPath` | The current canonical API path |
| `DeprecatedPaths` | One or more legacy paths that forward to the primary handler |

The aliases are grouped into six migration categories:

| Category | Old Prefix | New Prefix |
|---|---|---|
| Fleet CRUD & secrets | `/fleet/teams/` | `/fleet/fleets/` |
| Policies | `/fleet/team/{id}/` or `/fleet/teams/{id}/` | `/fleet/fleets/{id}/` |
| Query CRUD & specs | `/fleet/queries/` | `/fleet/reports/` |
| Host queries | `/fleet/hosts/{id}/queries/` | `/fleet/hosts/{id}/reports/` |
| Live query execution | `/fleet/queries/run*` | `/fleet/reports/run*` |
| ABM/VPP tokens | `abm_tokens` / `teams` suffix | `ab_tokens` / `fleets` suffix |

## Usage Example

```go
// The router consumes deprecatedPathAliases at startup to register
// each deprecated path as an alias for its primary handler.
func attachRoutes(r *eu.Endpointer) {
    for _, alias := range deprecatedPathAliases {
        r.RegisterDeprecatedAlias(alias)
    }
}
```

> **Note:** Path parameters (e.g., `{id:[0-9]+}`) are preserved verbatim across alias and primary paths — the router must treat them as equivalent captures.
