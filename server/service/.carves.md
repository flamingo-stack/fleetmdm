Handles osquery file carve operations including listing carves, retrieving carve metadata and blocks, initiating new carves, and securely receiving carve block data from osquery agents.

## Key Components

### Endpoint Handlers
- `listCarvesEndpoint` / `ListCarves` — Lists all carves with filtering options, requires `ActionRead` authorization
- `getCarveEndpoint` / `GetCarve` — Retrieves carve metadata by ID
- `getCarveBlockEndpoint` / `GetBlock` — Fetches a specific block from a carve, validates block availability and expiry

### Carve Initiation
- `CarveBegin` — Initiates a new file carve session from an osquery host; validates size constraints (`maxCarveSize` = 8GB, `maxBlockSize` = 256MB), generates a UUID session ID, and persists metadata via `carveStore`

### Streaming Block Receiver
- `decodeCarveBlockRequest.DecodeRequest` — Custom streaming JSON parser for the `/api/v1/osquery/carve/block` endpoint. Parses the request body field-by-field to extract `block_id`, `session_id`, and `request_id` **before** reading the potentially large `data` field, preventing DoS attacks on this unauthenticated endpoint. Authentication is performed mid-parse via `carveStore.CarveBySessionId` and `requestID` validation.

## Usage Example

```go
// Begin a carve session (called by osquery host)
carve, err := svc.CarveBegin(ctx, fleet.CarveBeginPayload{
    BlockCount: 10,
    BlockSize:  1024 * 1024, // 1MB blocks
    CarveSize:  9 * 1024 * 1024,
    CarveId:    "carve-abc123",
    RequestId:  "req-xyz",
})

// Retrieve a specific block (admin API)
data, err := svc.GetBlock(ctx, carve.ID, 0)

// List all carves
carves, err := svc.ListCarves(ctx, fleet.CarveListOptions{})
```

## Security Notes

The block endpoint uses field-by-field JSON parsing to authenticate via `session_id`/`request_id` before decoding the raw `data` payload, preventing large-payload DoS attacks. An optional `Authorization: NodeKey` header provides an additional pre-auth gate.
