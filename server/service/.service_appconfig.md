Handles Fleet application configuration service operations, including app config initialization, SMTP email testing, license retrieval, and runtime configuration exposure for logging, vulnerabilities, and email backends.

## Key Components

| Function | Description |
|---|---|
| `NewAppConfig` | Creates initial app configuration and generates a default enroll secret |
| `sendTestEmail` | Sends a test SMTP email to the current viewer's address |
| `cleanupURL` | Trims whitespace and trailing slashes from URLs |
| `License` | Returns current license info, with managed-cloud detection via Microsoft Compliance Partner settings |
| `SetupRequired` | Reports whether initial setup is needed (no users exist) |
| `UpdateIntervalConfig` | Returns osquery detail/policy update intervals from server config |
| `VulnerabilitiesConfig` | Returns full vulnerability scanning configuration |
| `LoggingConfig` | Builds logging plugin config for status, result, and audit log targets across supported backends |
| `EmailConfig` | Returns server-side email backend config (SES only; SMTP is API-configured) |
| `PartnershipsConfig` | Returns partnership feature flags (currently Primo only) |

## Usage Example

```go
// Initialize app config on first run
cfg := fleet.AppConfig{
    ServerSettings: fleet.ServerSettings{ServerURL: "https://fleet.example.com"},
}
newCfg, err := svc.NewAppConfig(ctx, cfg)

// Check if Fleet needs initial setup
required, err := svc.SetupRequired(ctx)
if required {
    // redirect to setup flow
}

// Retrieve logging plugin configuration
logging, err := svc.LoggingConfig(ctx)
// logging.Status.Plugin will be "filesystem", "kinesis", "pubsub", etc.

// Retrieve license details (supports device token auth)
lic, err := svc.License(ctx)
if lic.ManagedCloud {
    // instance is cloud-managed
}
```

## Supported Logging Backends

`LoggingConfig` maps the configured plugin name to a typed struct for each of `filesystem`, `webhook`, `kinesis`, `firehose`, `lambda`, `pubsub`, `stdout`, `kafkarest`, and `nats`. An unrecognized plugin returns a wrapped context error.
