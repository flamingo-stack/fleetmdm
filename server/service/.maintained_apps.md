Handles HTTP endpoints and service-layer stubs for Fleet's maintained apps feature, providing add, list, and get operations that return license errors in the open-source tier.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `addFleetMaintainedAppRequest` | struct | Request body for `POST /software/fleet_maintained_apps`; supports `team_id`/`fleet_id` aliasing and optional base64-encoded script fields |
| `addFleetMaintainedAppRequest.DecodeRequest` | method | Custom decoder that normalizes `fleet_id`→`team_id`, emits a deprecation warning for `team_id`, and decodes base64 scripts when `X-Fleet-Scripts-Encoded: base64` is present |
| `addFleetMaintainedAppEndpoint` | func | Endpoint handler that calls `svc.AddFleetMaintainedApp` with an installer timeout guard and maps `DeadlineExceeded` to a gateway-timeout error |
| `Service.AddFleetMaintainedApp` | method | OSS stub — skips auth and returns `fleet.ErrMissingLicense` |
| `listFleetMaintainedAppsRequest` | struct | Query-param request for `GET /software/fleet_maintained_apps`; supports pagination, platform filter, and `available` (hide-added-apps) flag |
| `listFleetMaintainedAppsEndpoint` | func | Endpoint handler that builds `MaintainedAppListOptions` and returns apps with pagination metadata |
| `Service.ListFleetMaintainedApps` | method | OSS stub — skips auth and returns `fleet.ErrMissingLicense` |
| `getFleetMaintainedApp` | func | Endpoint handler for fetching a single maintained app by ID |
| `Service.GetFleetMaintainedApp` | method | OSS stub — skips auth and returns `fleet.ErrMissingLicense` |

## Usage Example

```go
// Add a maintained app (premium tier overrides the stub below)
titleID, err := svc.AddFleetMaintainedApp(
    ctx,
    &teamID,          // *uint — target team
    42,               // fleet_maintained_app_id
    installScript,
    preInstallQuery,
    postInstallScript,
    uninstallScript,
    true,             // self_service
    false,            // automatic_install
    []string{"label-a"},
    []string{},
    []string{},
)

// List maintained apps with filters
apps, meta, err := svc.ListFleetMaintainedApps(ctx, &teamID, fleet.MaintainedAppListOptions{
    ListOptions:   fleet.ListOptions{Page: 0, PerPage: 20},
    Platform:      "darwin",
    AvailableOnly: true,
})
```

> **Note:** All three `Service` methods (`AddFleetMaintainedApp`, `ListFleetMaintainedApps`, `GetFleetMaintainedApp`) are OSS stubs that always return `fleet.ErrMissingLicense`. Premium implementations are registered separately and override these at startup.
