Handles MDM (Mobile Device Management) service endpoints for Apple MDM configuration, APNS certificate signing requests, and EULA management within the Fleet service layer.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `GetAppleMDM` | Method | Retrieves Apple MDM configuration including APNS cert details (CN, issuer, expiry, serial) |
| `GetAppleBM` | Method | Stub for Apple Business Manager — returns `ErrMissingLicense` |
| `RequestMDMAppleCSR` | Method | Generates SCEP CA cert/key pair and APNs CSR, submits to fleetdm.com for signing |
| `VerifyMDMAppleConfigured` | Method | Checks app config to confirm Apple MDM is enabled and configured |
| `MDMCreateEULA` | Method | Stub for EULA upload — returns `ErrMissingLicense` |
| `MDMGetEULABytes` | Method | Stub for EULA download by token — returns `ErrMissingLicense` |
| `getMDMEULAResponse` | Struct | Response with `HijackRender` to stream PDF bytes with correct `Content-Type` headers |
| `createMDMEULARequest` | Struct | Custom multipart decoder with size validation against `fleet.MaxEULASize` |

## Usage Example

```go
// Get Apple MDM APNS certificate info
appleMDM, err := svc.GetAppleMDM(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("APNS CN: %s, Renews: %s\n", appleMDM.CommonName, appleMDM.RenewDate)

// Request a signed APNs CSR from fleetdm.com
csr, err := svc.RequestMDMAppleCSR(ctx, "admin@corp.example.com", "Corp Inc")
if err != nil {
    log.Fatal(err)
}
// Returns PEM-encoded APNs key, SCEP cert, and SCEP key
fmt.Printf("APNs Key PEM: %s\n", csr.APNsKey)

// Verify MDM is configured before proceeding
if err := svc.VerifyMDMAppleConfigured(ctx); err != nil {
    // fleet.ErrMDMNotConfigured if not set up
    log.Fatal(err)
}
```

## Notes

- `GetAppleBM` and EULA methods (`MDMCreateEULA`, `MDMGetEULABytes`) are license-gated stubs returning `fleet.ErrMissingLicense`
- `RequestMDMAppleCSR` contacts `fleetdm.com` for CSR signing; invalid email domains return a specific `invalidEmailDomain` error
- EULA uploads are capped at `fleet.MaxEULASize` and support a `dry_run` query parameter for validation-only mode
