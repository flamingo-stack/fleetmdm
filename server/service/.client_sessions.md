Provides HTTP client methods for managing Fleet authentication sessions, including email/password login, SSO settings retrieval, and logout operations.

## Key Components

| Function | Description |
|---|---|
| `Login(email, password string)` | Authenticates against the Fleet API and returns a bearer token on success |
| `SSOSettings()` | Fetches SSO configuration from the Fleet instance; unauthenticated endpoint |
| `Logout()` | Terminates the current authenticated session |

## Usage Example

```go
client, _ := service.NewClient(fleetURL, true, "", "")

// Email/password login
token, err := client.Login("admin@example.com", "supersecret")
if err != nil {
    log.Fatal(err)
}

// Retrieve SSO settings before authentication
ssoSettings, err := client.SSOSettings()
if err != nil {
    log.Fatal(err)
}
fmt.Println("SSO enabled:", ssoSettings.IDPName)

// Logout when done
if err := client.Logout(); err != nil {
    log.Fatal(err)
}
```

## Notes

- `Login` returns a `notSetupErr` when the Fleet instance has not yet been configured (`404` response).
- `SSOSettings` is unauthenticated and safe to call prior to login, useful for detecting whether SSO is configured before presenting a login UI.
- `Logout` uses `authenticatedRequest`, so a valid session token must be set on the client before calling it.
