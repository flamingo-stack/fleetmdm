Provides HTTP endpoint handlers and service-layer logic for Fleet user management operations, including creating standard users, API-only users, and users from invites, with authorization, license, and MFA validation.

## Key Components

### Endpoints

| Endpoint | Function | Description |
|---|---|---|
| `createUserEndpoint` | `POST /users` | Creates a standard user with optional session token for API-only users |
| `createAPIOnlyUserEndpoint` | `POST /api-only-users` | Creates an API-only user with auto-generated email/password |
| `modifyAPIOnlyUserEndpoint` | `PATCH /api-only-users/:id` | Updates an API-only user's name, role, teams, or endpoint restrictions |
| `createUserFromInviteEndpoint` | `POST /invites` | Creates a user from an existing invite |

### Service Methods

- **`CreateUser(ctx, UserPayload)`** — Core user creation with RBAC authz, license checks, team validation, MFA preconditions, and API endpoint ref validation.
- **`ModifyAPIOnlyUser(ctx, userID, UserPayload)`** — Patches an API-only user; prevents self-modification.
- **`validateAPIEndpointRefs(ctx, refs)`** — Validates that API endpoint references exist, are not duplicated, and meet cardinality constraints.

### Key Types

- `createUserRequest` / `createUserResponse` — Request/response wrapper for standard user creation; returns `Token` only for non-SSO API-only users.
- `createAPIOnlyUserRequest` — Accepts `name`, `global_role`, `fleets`, and `api_endpoints`.
- `modifyAPIOnlyUserRequest` — Patch payload; uses `fleet.OptionalAPIEndpoints` for null/absent distinction.

## Usage Example

```go
// Create an API-only user programmatically
user, token, err := svc.CreateUser(ctx, fleet.UserPayload{
    Name:                     ptr.String("CI Bot"),
    Email:                    ptr.String("ci-bot@example.com"),
    Password:                 ptr.String("s3cr3t!"),
    APIOnly:                  ptr.Bool(true),
    AdminForcedPasswordReset: ptr.Bool(false),
    GlobalRole:               ptr.String(fleet.RoleObserver),
})
// token is non-nil for API-only, non-SSO users
```

> **Note:** API endpoint scoping (`APIEndpoints`) requires a Fleet Premium license. Passing an explicit empty array `[]` is invalid — send `null` to grant full access.
