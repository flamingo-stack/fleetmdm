Endpoint middleware for authenticating Fleet hosts, devices, and Orbit agents before requests reach service handlers.

## Key Components

| Function | Description |
|---|---|
| `authenticatedDevice` | Validates device auth tokens or mTLS cert serials; supports Fleet Desktop (token), iOS/iPadOS (cert or UUID URL) |
| `authenticatedHost` | Validates osquery `node_key`; short-circuits if HTTP pre-auth (`osqueryHeaderPreAuth`) already populated the host context |
| `authenticatedOrbitHost` | Validates Orbit node keys using a caller-supplied key extractor function |
| `extractCertSerialFromHeader` | Parses `X-Client-Cert-Serial` header set by load balancer for mTLS device auth |
| `instrumentHostLogger` | Attaches `host_id`, `ip_addr`, and `x_for_ip_addr` to the request's context logger |
| `getDeviceAuthToken` | Extracts device auth token from request via `deviceAuthToken()` interface |
| `getNodeKey` | Extracts osquery node key from request via `HostNodeKey()` / `hostNodeKey()` interfaces |
| `getOrbitNodeKey` | Extracts Orbit node key from request via `OrbitHostNodeKey()` interface |
| `authHeaderValue` | Returns a context extractor that strips a prefix from the `Authorization` header value |
| `logJSON` | Marshals a value to JSON and emits a debug-level structured log entry |

## Usage Example

```go
// Wrap an endpoint with device authentication
e = authenticatedDevice(svc, logger, e)

// Wrap an endpoint with osquery host authentication
e = authenticatedHost(svc, logger, e)

// Wrap an endpoint with Orbit authentication using the Authorization header
e = authenticatedOrbitHost(svc, logger, e, authHeaderValue("OrbitNodeKey "))
```

## Authentication Flow

Each middleware follows the same pattern:

1. Extract credentials from the request (token, node key, or cert serial)
2. Call the appropriate `fleet.Service` authentication method
3. Attach the resolved `*fleet.Host` to the request context via `hostctx`
4. Pin the host to its team for multitenancy isolation (`openframePinHostTeam`)
5. Set the `AuthenticationMethod` on the authz context
6. Invoke the next endpoint handler

> **OpenFrame multitenancy note:** All three middleware functions call `openframePinHostTeam` to enforce team-scoped database access in shared-mode deployments.
