Provides Fleet client methods for managing query packs via the Fleet REST API, supporting apply-spec workflows and CRUD operations.

## Key Components

| Function | Method | Endpoint |
|---|---|---|
| `ApplyPacks` | `POST` | `/api/latest/fleet/spec/packs` |
| `GetPackSpec` | `GET` | `/api/latest/fleet/spec/packs/:name` |
| `GetPacksSpecs` | `GET` | `/api/latest/fleet/spec/packs` |
| `ListPacks` | `GET` | `/api/latest/fleet/packs` |
| `DeletePack` | `DELETE` | `/api/latest/fleet/packs/:name` |

All methods use `authenticatedRequest` internally. Pack names in path parameters are safely encoded via `url.PathEscape`.

## Usage Example

```go
client, _ := service.NewClient(baseURL, true, "", "")

// Upsert packs from spec definitions
err := client.ApplyPacks([]*fleet.PackSpec{
    {Name: "osquery-starter", Targets: fleet.PackSpecTargets{}},
})

// Retrieve a single pack spec by name
spec, err := client.GetPackSpec("osquery-starter")

// List all pack specs (apply-spec format)
specs, err := client.GetPacksSpecs()

// List all packs (full Pack structs)
packs, err := client.ListPacks()
for _, p := range packs {
    fmt.Println(p.Name)
}

// Remove a pack by name
err = client.DeletePack("osquery-starter")
```

## Notes

- `ApplyPacks` performs an **upsert** — it creates or updates packs matching the provided specs.
- `ListPacks` returns `[]*fleet.Pack` (full structs), while `GetPacksSpecs` / `GetPackSpec` return the lighter `fleet.PackSpec` format used in GitOps-style workflows.
