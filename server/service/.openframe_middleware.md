Per-request tenant isolation middleware for Fleet's shared multi-tenant (OpenFrame) deployment mode, pinning control-plane requests to a team derived from the `X-Tenant-Id` gateway header and agent requests to their authenticated host's team.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `WithOpenframeTenant` | `func` | HTTP middleware entry point; no-ops outside shared mode, otherwise delegates to `openframeTenantHandler` |
| `openframeTenantHandler` | `func` | Core handler: validates the `X-Tenant-Id` header UUID, resolves (and caches) it to a Fleet team ID via `EnsureOpenframeTeamID`, then injects the team into the request context |
| `openframeTenantExemptPath` | `func` | Returns `true` for agent/device/MDM-enrollment paths (`/osquery/`, `/fleet/orbit/`, `/fleet/device/`, `/api/mdm/`, `/fleet/ota_enrollment`) that derive their tenant from the authenticated principal instead of the header |
| `openframePinHostTeam` | `func` | Scopes an authenticated host's context to its own team in shared mode; fails closed if the host has no team |
| `openframeTeamEnsurer` | `interface` | Datastore contract: `EnsureOpenframeTeamID(ctx, tenantUUID) (uint, error)` |

## Usage Example

```go
// Wire the middleware at server startup (shared mode only).
handler := service.WithOpenframeTenant(ds, slogLogger, fleetAPIHandler)
http.ListenAndServe(":8080", handler)

// Inside an agent-authenticated handler, pin the host's team:
ctx, err := service.openframePinHostTeam(r.Context(), authenticatedHost)
if err != nil {
    // host has no team — fail closed in shared mode
    return err
}
// ctx now carries the team ID for all downstream datastore queries
```

**Fail-closed behaviour:**

- Requests to control-plane paths without a valid `X-Tenant-Id` UUID are rejected with `AuthRequiredError`.
- Authenticated hosts without a team assignment are rejected with `AuthFailedError`.
- Resolved UUID → team ID mappings are cached in a `sync.Map` (a tenant's team ID never changes), avoiding repeated datastore round-trips.
