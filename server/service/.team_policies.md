Manages CRUD operations and automations for Fleet team-scoped policies, including label filtering, software installation, VPP app integration, script execution, and activity logging.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `teamPolicyEndpoint` | func | HTTP handler that creates a new team policy via `NewTeamPolicy` |
| `NewTeamPolicy` | method | Creates a team policy with authorization, license checks, label validation, and activity logging |
| `ListTeamPolicies` | method | Lists team-scoped and optionally inherited global policies with pagination |
| `populateAutomationsForTeamPolicy` | method | Orchestrates population of install software, run script, and patch software automations on a policy |
| `populatePolicyInstallSoftware` | method | Resolves software installer or VPP app metadata onto a policy's `InstallSoftware` field |
| `populatePolicyRunScript` | method | Resolves script metadata onto a policy's `RunScript` field |
| `populatePolicyPatchSoftware` | method | Resolves patch software installer metadata onto a policy's `PatchSoftware` field |
| `populateSoftwareIconURLs` | method | Batch-resolves software icon URLs for all policies in a list, supporting custom uploads and VPP apps |
| `newTeamPolicyPayloadToPolicyPayload` | method | Converts a `NewTeamPolicyPayload` to a `PolicyPayload`, resolving installer/VPP IDs |
| `getPolicySoftwareTitleIconURL` | func | Builds the icon URL for a given team and software title ID |

## Usage Example

```go
// Create a new team policy with software installation automation
policy, err := svc.NewTeamPolicy(ctx, teamID, fleet.NewTeamPolicyPayload{
    Name:        "Ensure Zoom is installed",
    Query:       "SELECT 1 FROM apps WHERE name = 'zoom.us';",
    Description: "Verifies Zoom is present on all team hosts",
    Resolution:  "Install Zoom via self-service",
    Platform:    "darwin",
    Critical:    false,
    SoftwareTitleID: ptr.Uint(42),
})
if err != nil {
    log.Fatal(err)
}

// List team policies (with inherited global policies merged)
teamPolicies, inheritedPolicies, err := svc.ListTeamPolicies(
    ctx,
    teamID,
    fleet.ListOptions{PerPage: 20},
    fleet.ListOptions{PerPage: 20},
    true,  // mergeInherited
    "",    // no automation filter
)
```

> **Note:** Label-based filtering (`LabelsIncludeAny`, `LabelsExcludeAll`, etc.) requires a Fleet Premium license. Attempting to use these fields on a free tier returns `fleet.ErrMissingLicense`.
