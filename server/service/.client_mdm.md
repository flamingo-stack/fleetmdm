Provides MDM (Mobile Device Management) client methods for interacting with Fleet's MDM API endpoints, supporting Apple and Windows MDM operations including bootstrap packages, setup assistants, and command execution.

## Key Components

- **`GetAppleMDM`** / **`GetAppleBM`** — Retrieves Apple MDM APNs and Apple Business Manager info
- **`GetVPPTokens`** / **`CountABMTokens`** — Fetches VPP token list and ABM token count
- **`RequestAppleCSR`** / **`RequestAppleABM`** — Requests signed CSR and ABM public key from Fleet server
- **`GetBootstrapPackageMetadata`** / **`DeleteBootstrapPackage`** / **`UploadBootstrapPackage`** — Full CRUD lifecycle for macOS bootstrap packages
- **`UploadBootstrapPackageIfNeeded`** — Idempotent upload using SHA-256 checksum comparison to skip unnecessary uploads
- **`ValidateBootstrapPackageFromURL`** — Downloads, validates signature, and checksums a remote `.pkg` file
- **`validateMacOSSetupAssistant`** / **`uploadMacOSSetupAssistant`** / **`deleteMacOSSetupAssistant`** — Manages macOS DEP enrollment profiles
- **`MDMListCommands`** / **`MDMGetCommandResults`** — Lists and retrieves results for MDM commands
- **`RunMDMCommand`** — Dispatches raw MDM commands to Apple (darwin) or Windows hosts, base64-encoding the payload
- **`prepareWindowsMDMCommand`** — Validates and injects a random UUID `CmdID` into Windows MDM XML commands

## Usage Example

```go
// Upload a bootstrap package only if the checksum has changed
pkg := &fleet.MDMAppleBootstrapPackage{
    Name:   "setup.pkg",
    Bytes:  pkgBytes,
    Sha256: checksum,
}
if err := client.UploadBootstrapPackageIfNeeded(pkg, teamID, false); err != nil {
    log.Fatal(err)
}

// Run a raw MDM command on a macOS host
result, err := client.RunMDMCommand(
    []string{"host-uuid-1234"},
    rawCommandXML,
    "darwin",
)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Command UUID:", result.CommandUUID)
```
