Mock implementation of the `fleet.LiveQueryStore` interface for use in unit tests, enabling controlled simulation of live query operations without a real backing store.

## Key Components

- **`MockLiveQuery`** — Core mock struct embedding `mock.Mock` (testify) and `fleet.LiveQueryStore`, with optional function overrides for result-count methods
- **`New(t *testing.T)`** — Constructor that allocates and registers the mock with the test runner
- **Override fields** — `GetQueryResultsCountsOverride`, `IncrQueryResultsCountsOverride`, `SetQueryResultsCountOverride`, `DeleteQueryResultsCountOverride` allow injecting custom logic without full testify call setup

## Mocked Methods

| Method | Description |
|---|---|
| `RunQuery` | Simulates starting a live query against a set of hosts |
| `StopQuery` | Simulates stopping a named query |
| `QueriesForHost` | Returns queries pending for a given host |
| `QueryCompletedByHost` | Marks a query as completed by a specific host |
| `CleanupInactiveQueries` | Removes inactive campaign queries |
| `LoadActiveQueryNames` | Lists currently active query names |
| `GetQueryResultsCounts` | Returns result counts per query ID (supports override) |
| `IncrQueryResultsCounts` | Increments result counts (supports override) |
| `SetQueryResultsCount` | Sets a specific count (supports override) |
| `DeleteQueryResultsCount` | Deletes a count entry (supports override, no-ops by default) |

## Usage Example

```go
func TestMyService(t *testing.T) {
    lq := live_query_mock.New(t)

    // Standard testify mock expectation
    lq.On("RunQuery", "query-1", "SELECT * FROM osquery_info", []uint{1, 2}).
        Return(nil)

    // Or use an override for result counts
    lq.GetQueryResultsCountsOverride = func(queryIDs []uint) (map[uint]int, error) {
        return map[uint]int{42: 5}, nil
    }

    svc := NewService(lq)
    err := svc.Run()
    require.NoError(t, err)

    lq.AssertExpectations(t)
}
```

> **Note:** `DeleteQueryResultsCount` always returns `nil` when the override is not set — no testify expectation is required for it.
