Redis-backed implementation of the `live_query` package that stores, retrieves, and manages live query targeting data using Redis bitfields, with an in-memory cache layer to reduce Redis round-trips on host check-ins.

## Key Components

### Types

- **`redisLiveQuery`** — Main struct wrapping a Redis connection pool, an in-memory cache (`memCache`), cache TTL, and a structured logger.
- **`memCache`** — Thread-safe in-memory cache holding SQL strings keyed by campaign ID and the list of active query names, with an expiration timestamp.

### Constructor

- **`NewRedisLiveQuery(pool, logger, memCacheExp)`** — Creates a new `redisLiveQuery` instance backed by the provided Redis pool.

### Core Interface Methods

| Method | Description |
|---|---|
| `RunQuery(name, sql, hostIDs)` | Stores the query SQL, host bitfield, and registers the campaign ID in the active set. |
| `StopQuery(name)` | Deletes the SQL and bitfield keys, removes the campaign ID from the active set. |
| `QueriesForHost(hostID)` | Returns all active queries targeting a given host, using pipelined `GETBIT` calls. |
| `QueryCompletedByHost(name, hostID)` | Clears the host's bit in the targeting bitfield via a Lua script (only if the key still exists). |
| `LoadActiveQueryNames()` | Returns the set of active campaign IDs, serving from cache when still valid. |

### Internal Helpers

- **`generateKeys(name)`** — Produces `livequery:{name}` and `sql:livequery:{name}` keys with Redis Cluster hash tags.
- **`extractTargetKeyName(key)`** — Strips prefix and hash-tag braces to recover the campaign ID.
- **`mapBitfield(hostIDs)`** — Converts a sorted slice of host IDs into a binary bitfield (defined elsewhere in the package).
- **`loadCache()`** — Refreshes the in-memory SQL cache and active query list from Redis, expiring stale campaign entries.
- **`collectBatchQueriesForHost(...)`** — Pipelines `GETBIT` commands per cluster slot and resolves matching SQL from cache.

## Usage Example

```go
import (
    livequery "github.com/fleetdm/fleet/v4/server/live_query"
    "log/slog"
    "time"
)

pool := getRedisPool() // fleet.RedisPool

lq := livequery.NewRedisLiveQuery(pool, slog.Default(), 10*time.Second)

// Start a live query targeting hosts 1, 3, and 7
err := lq.RunQuery("42", "SELECT * FROM osquery_info;", []uint{1, 3, 7})

// On host check-in, fetch applicable queries
queries, err := lq.QueriesForHost(3)
// queries["42"] == "SELECT * FROM osquery_info;"

// Mark host as done with the query
err = lq.QueryCompletedByHost("42", 3)

// Stop the query and clean up Redis keys
err = lq.StopQuery("42")
```

## Redis Key Layout

```text
livequery:{<campaignID>}        # bitfield of targeted host IDs (expires in 7 days)
sql:livequery:{<campaignID>}    # SQL string for the query      (expires in 7 days)
livequery:active                # Redis SET of all active campaign IDs
```

> **Note:** Hash tags (`{campaignID}`) ensure the bitfield and SQL keys for the same campaign always land on the same Redis Cluster node. The `livequery:active` set is a known hot key in cluster mode.
