Anti-corruption layer adapter that bridges the ACME bounded context to Fleet's legacy `Datastore`, implementing the narrow `acme.DataProviders` interface using Fleet datastore methods.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `FleetDatastoreAdapter` | struct | Wraps `fleet.Datastore` and `acme.CSRSigner` to satisfy `acme.DataProviders` |
| `NewFleetDatastoreAdapter` | constructor | Instantiates the adapter with a datastore and signer |
| `ServerURL` | method | Retrieves the MDM server URL from app config |
| `GetCACertificatePEM` | method | Fetches the CA certificate PEM from MDM config assets |
| `CSRSigner` | method | Returns the injected `acme.CSRSigner` |
| `IsDEPEnrolled` | method | Checks DEP enrollment status for a device serial number |

## Usage Example

```go
import (
    "github.com/fleetdm/fleet/v4/server/mdm/acmeacl"
)

// Wire up the adapter at the composition root — the only place
// that should import both fleet and acme types.
adapter := acmeacl.NewFleetDatastoreAdapter(ds, csrSigner)

// Pass the adapter wherever acme.DataProviders is required.
acmeService := acme.NewService(adapter)
```

## Notes

- **Package boundary**: `acmeacl` is the sole permitted import site for both `fleet` and `acme` types — all cross-context translation is isolated here.
- **Interface compliance**: The compile-time assertion `var _ acme.DataProviders = (*FleetDatastoreAdapter)(nil)` ensures the adapter stays in sync with the interface.
- **Narrow interface**: Only the methods the ACME context actually needs are exposed, keeping the ACME bounded context decoupled from the full `fleet.Datastore` surface area.
