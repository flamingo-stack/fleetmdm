Provides utilities for retrieving secrets from AWS Secrets Manager, with built-in retry logic, exponential backoff, and optional STS assume-role authentication.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `SecretsManagerClient` | Interface | Abstraction over the AWS SDK client for dependency injection and testing |
| `retrieveSecretWithRetry` | Function (internal) | Fetches a secret by ARN with up to 3 attempts and exponential backoff with jitter |
| `RetrieveSecretsManagerSecret` | Function | Public entry point for secret retrieval with STS assume-role support |
| `RetrieveSecretsManagerSecretWithOptions` | Function | Extended variant accepting custom `aws_config.LoadOptions` (e.g. LocalStack in tests) |

## Retry Behaviour

`retrieveSecretWithRetry` retries on transient errors (network issues, throttling) but returns immediately — without retrying — on:

- `ResourceNotFoundException` — secret ARN not found
- `InvalidRequestException` — access denied
- `InvalidParameterException` — malformed ARN

Backoff formula: `base * 2^(attempt-1)` ± 50% jitter, starting at 500 ms.

## Usage Example

```go
ctx := context.Background()

secret, err := config.RetrieveSecretsManagerSecret(
    ctx,
    "arn:aws:secretsmanager:us-east-1:123456789012:secret:my-secret",
    "us-east-1",
    "arn:aws:iam::123456789012:role/MyRole", // assumeRoleArn (empty string to skip)
    "my-external-id",                        // externalID (empty string to skip)
)
if err != nil {
    log.Fatalf("failed to retrieve secret: %v", err)
}
```

For tests using LocalStack, pass custom load options via `RetrieveSecretsManagerSecretWithOptions`:

```go
secret, err := config.RetrieveSecretsManagerSecretWithOptions(
    ctx, secretArn, "us-east-1", "", "",
    aws_config.WithEndpointResolverWithOptions(localstackResolver),
)
```
