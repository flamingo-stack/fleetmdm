Manages all Fleet server configuration structures, defaults, and validation logic. It defines typed config structs for every subsystem (MySQL, Redis, server, auth, osquery, logging, MDM, etc.) and wires them together via Viper/Cobra for environment variable and YAML file binding.

## Key Components

| Export | Description |
|---|---|
| `FleetConfig` | Root config struct aggregating all subsystem configs |
| `MysqlConfig` | MySQL connection settings including TLS, connection pooling, and AWS STS |
| `RedisConfig` | Redis connection settings with cluster, TLS, key-prefix namespacing, and host-cache flags |
| `ServerConfig` | HTTP server settings: TLS profiles, H2C, URL prefix, private key, installer size limits |
| `AuthConfig` | Bcrypt cost, SSO session validity, HTTP message signature enforcement |
| `OsqueryConfig` | Node key size, host identifier, log plugins, async processing, jitter |
| `ConfigManager` | Interface implemented by `viperConfigManager` — loads config from env/YAML and binds Cobra flags |
| `DefaultHTTPServer` | Builds a pre-tuned `*http.Server` with optional H2C (HTTP/2 cleartext) support |
| `Validate` / `ValidatePrivateKeyLength` / `ValidateURLPrefix` / `NormalizeURLPrefix` | Startup validation helpers on `ServerConfig` |

## Usage Example

```go
// Bind flags and load config in a Cobra command
func runServe(cmd *cobra.Command, args []string) {
    manager := config.NewManager(cmd)
    cfg := manager.Config()

    // Access subsystem configs
    fmt.Println(cfg.Mysql.Address)   // e.g. "localhost:3306"
    fmt.Println(cfg.Redis.KeyPrefix) // e.g. "tenant-42"
    fmt.Println(cfg.Server.TLS)      // true/false

    // Validate server config early
    cfg.Server.Validate(func(err error, msg string) {
        log.Fatalf("%s: %v", msg, err)
    })
    cfg.Server.NormalizeURLPrefix()
    cfg.Server.ValidateURLPrefix(func(err error, msg string) {
        log.Fatalf("%s: %v", msg, err)
    })

    // Build HTTP server
    srv := cfg.Server.DefaultHTTPServer(ctx, myHandler)
    log.Fatal(srv.ListenAndServe())
}
```

## Environment Variables

All settings are prefixed with `FLEET_`, e.g.:

```bash
FLEET_MYSQL_ADDRESS=db:3306
FLEET_REDIS_KEY_PREFIX=tenant-42
FLEET_SERVER_TLS=true
FLEET_SERVER_PRIVATE_KEY=supersecretkey32bytes00000000000
```
