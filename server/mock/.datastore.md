Provides the entry point for mock datastore generation and defines a minimal `Store` implementation used in tests.

## Key Components

- **`Store`** — Embeds the generated `DataStore` and satisfies the `fleet.Datastore` interface. Used as a test double throughout the Fleet server test suite.
- **`go:generate` directives** — Drive code generation for multiple mock interfaces via `mockimpl/impl.go`, producing mocks for:
  - `fleet.Datastore` → `datastore_mock.go`
  - `fleet.InstallerStore` → `datastore_installers.go`
  - `nanodep/storage.AllDEPStorage` → `nanodep/storage.go`
  - `fleet.MDMAppleStore` → `mdm/datastore_mdm_mock.go`
  - `depot.Depot` / `fleet.SCEPConfigService` → `scep/`
  - `fleet.DigiCertService` → `digicert/digicert.go`
  - `fleet.MDMBootstrapPackageStore` / `fleet.SoftwareInstallerStore` → MDM/software sub-packages
- **Stub methods** — `EnrollOrbit`, `LoadHostByOrbitNodeKey`, `GetCurrentTime`, `Drop`, `MigrateTables`, `MigrateData`, `MigrateOpenframe`, `MigrationStatus`, and `Name` all return zero values, allowing tests to compile without a real database.

## Usage Example

```go
// Instantiate the mock store in a test
store := &mock.Store{}

// Override only the methods your test needs
store.DataStore.ListHostsFn = func(ctx context.Context, filter fleet.TeamFilter, opt fleet.HostListOptions) ([]*fleet.Host, error) {
    return []*fleet.Host{{ID: 1, Hostname: "test-host"}}, nil
}

svc := NewService(store)
hosts, err := svc.ListHosts(ctx, filter, opt)
```

Run code generation with:

```bash
go generate ./server/mock/...
```
