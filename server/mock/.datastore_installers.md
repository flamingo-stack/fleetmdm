Auto-generated mock implementation of the `fleet.InstallerStore` interface, used for testing installer storage operations without a real backend.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `InstallerStore` | struct | Thread-safe mock implementing `fleet.InstallerStore` |
| `GetFunc` | type | Function signature for retrieving an installer as a readable stream |
| `PutFunc` | type | Function signature for storing an installer, returning its URL/path |
| `ExistsFunc` | type | Function signature for checking if an installer exists |
| `*FuncInvoked` | fields | Boolean flags tracking whether each method was called |

Each method acquires a mutex lock before setting its `*FuncInvoked` flag, ensuring safe concurrent access in parallel tests.

## Usage Example

```go
store := &mock.InstallerStore{
    GetFunc: func(ctx context.Context, installer fleet.Installer) (io.ReadCloser, int64, error) {
        return io.NopCloser(strings.NewReader("binary")), 6, nil
    },
    PutFunc: func(ctx context.Context, installer fleet.Installer) (string, error) {
        return "https://example.com/installer.pkg", nil
    },
    ExistsFunc: func(ctx context.Context, installer fleet.Installer) (bool, error) {
        return true, nil
    },
}

// Exercise the store
_, _, _ = store.Get(ctx, installer)

// Assert the method was called
if !store.GetFuncInvoked {
    t.Error("expected Get to be called")
}
```
