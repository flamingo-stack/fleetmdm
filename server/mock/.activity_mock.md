Thread-safe mock implementation of `fleet.ActivityWriteService` for unit tests, providing configurable callbacks and optional delegation to real activity service behavior.

## Key Components

| Symbol | Description |
|---|---|
| `NewActivityFunc` | Callback type for intercepting activity creation calls |
| `NoopNewActivityFunc` | No-op default — returns `nil` without side effects |
| `MockActivityService` | Core struct implementing `fleet.ActivityWriteService` |
| `Delegate` | Optional real service to call before the mock function (e.g. for webhook testing) |
| `NewActivityFuncInvoked` / `CleanupHostActivitiesFuncInvoked` | Boolean flags for asserting method calls in tests |

## Usage Example

```go
// Basic no-op mock (ignore all activity calls)
svc := &mock.MockActivityService{}

// Capture and inspect activity calls
var captured activity_api.ActivityDetails
svc := &mock.MockActivityService{
    NewActivityFunc: func(ctx context.Context, user *activity_api.User, activity activity_api.ActivityDetails) error {
        captured = activity
        return nil
    },
}

// Use delegate for real behavior (e.g. webhooks) while still capturing
svc := &mock.MockActivityService{
    Delegate: realActivityService,
    NewActivityFunc: func(ctx context.Context, user *activity_api.User, activity activity_api.ActivityDetails) error {
        // assert or log after real behavior runs
        return nil
    },
}

// Assert the method was called
assert.True(t, svc.NewActivityFuncInvoked)
```

## Notes

- All invocation flags are set under a `sync.Mutex`, making the mock safe for concurrent test scenarios.
- If `NewActivityFunc` is `nil`, `NoopNewActivityFunc` is used automatically — no nil-check needed in tests.
