A mock error type implementing the `fleet.NotFoundError` and `fleet.AlreadyExistsError` interfaces for use in tests.

## Key Components

- **`Error`** — Struct with a `Message` string field used as the error message.
- **`Error()`** — Returns the error message string, satisfying the standard `error` interface.
- **`IsNotFound()`** — Always returns `true`, implementing `fleet.NotFoundError`.
- **`IsExists()`** — Always returns `true`, implementing `fleet.AlreadyExistsError`.

## Usage Example

```go
err := &mock.Error{Message: "device not found"}

// Use as a standard error
fmt.Println(err.Error()) // "device not found"

// Check fleet-specific error types
if notFound, ok := err.(fleet.NotFoundError); ok {
    fmt.Println(notFound.IsNotFound()) // true
}

if exists, ok := err.(fleet.AlreadyExistsError); ok {
    fmt.Println(exists.IsExists()) // true
}
```
