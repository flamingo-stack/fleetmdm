Generates mock implementation stubs for a given Go interface, producing a complete `mock` package with a struct, function-type fields, invocation tracking, and mutex-guarded method implementations.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `findInterface` | func | Resolves an interface name (e.g. `io.Reader` or `net/http.ResponseWriter`) to its import path and identifier |
| `typeSpec` | func | Locates the `*ast.TypeSpec` for a named type within a package's source files |
| `funcs` | func | Returns the full set of `Func` descriptors required to implement an interface, recursing into embedded interfaces |
| `genStubs` | func | Renders mutex-guarded method stubs from `Func` descriptors using the `stub` template |
| `genStr` | func | Generates the mock struct definition with `*Func` fields, `*FuncInvoked` booleans, and a `sync.Mutex` |
| `Pkg` | struct | Wraps `build.Package` and `token.FileSet`; provides `fullType` and `params` helpers for AST traversal |
| `Method` / `Func` / `Param` | structs | Data models fed into Go `text/template` rendering |
| `validReceiver` | func | Validates a receiver expression by attempting to parse it as a Go source fragment |
| `main` | func | CLI entry point; wires parsing → deduplication → code generation → `goimports` → stdout or file output |

## Usage Example

```bash
# Generate mock for io.ReadWriter to stdout
impl 'f *File' io.ReadWriter

# Write mock to a file
impl -o mock/readwriter.go 'rw *ReadWriter' io.ReadWriter

# Fully qualified path
impl 's *Store' net/http.Handler
```

```go
// Generated output structure (mock/mock.go):
// Automatically generated by mockimpl. DO NOT EDIT!

package mock

import "io"

var _ io.Reader = (*Reader)(nil)

type ReadFunc func(p []byte) (n int, err error)

type Reader struct {
    ReadFunc        ReadFunc
    ReadFuncInvoked bool

    mu sync.Mutex
}

func (f *Reader) Read(p []byte) (n int, err error) {
    f.mu.Lock()
    f.ReadFuncInvoked = true
    f.mu.Unlock()
    return f.ReadFunc(p)
}
```

## CLI Flags

| Flag | Default | Description |
|---|---|---|
| `-o` | `""` (stdout) | Output file path |
| `recv` | _(positional)_ | Receiver expression, e.g. `'s *Store'` |
| `iface` | _(positional)_ | Interface to implement, e.g. `io.Reader` |

> **Note:** Wrap the receiver in single quotes to prevent shell glob expansion.
