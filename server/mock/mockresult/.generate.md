Provides the `go:generate` directive for auto-generating a mock implementation of the `fleet.QueryResultStore` interface.

## Key Components

- **`go:generate` directive** — Invokes `mockimpl/impl.go` to scaffold a mock struct (`QueryResultStore`) that satisfies the `fleet.QueryResultStore` interface, writing output to `datastore_query_results.go`.

## Usage Example

Run from the package directory (or via `go generate ./...` from the repo root):

```go
//go:generate go run ../mockimpl/impl.go -o datastore_query_results.go "s *QueryResultStore" "fleet.QueryResultStore"
```

To regenerate the mock:

```bash
cd mock
go generate ./...
```

The generated file `datastore_query_results.go` will contain a `QueryResultStore` struct with receiver `s` implementing all methods defined in `fleet.QueryResultStore`, suitable for use in unit tests.

## Notes

- The output file `datastore_query_results.go` is **auto-generated** — do not edit it manually; re-run `go generate` instead.
- Source lives at [`mock/generate.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/mock/generate.go).
