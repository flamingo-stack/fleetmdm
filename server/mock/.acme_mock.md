Mock implementation of the `fleet.ACMEWriteService` interface for use in unit tests, avoiding real MySQL or network dependencies.

## Key Components

- **`MockACMEService`** — Struct implementing `fleet.ACMEWriteService` with injectable function fields and invocation tracking.
  - `NewACMEEnrollmentFunc` — Replaceable function field; set this in tests to control return values.
  - `NewACMEEnrollmentFuncInvoked` — Boolean flag set to `true` whenever `NewACMEEnrollment` is called, enabling call verification.
- **`NewACMEEnrollment`** — Delegates to `NewACMEEnrollmentFunc` if set; returns `("", nil)` as a safe default otherwise.

## Usage Example

```go
func TestACMEEnrollment(t *testing.T) {
    svc := &mock.MockACMEService{
        NewACMEEnrollmentFunc: func(ctx context.Context, hostIdentifier string) (string, error) {
            return "enrollment-token-abc123", nil
        },
    }

    token, err := svc.NewACMEEnrollment(context.Background(), "host-001")

    assert.NoError(t, err)
    assert.Equal(t, "enrollment-token-abc123", token)
    assert.True(t, svc.NewACMEEnrollmentFuncInvoked)
}
```

## Notes

- The compile-time assertion `var _ fleet.ACMEWriteService = (*MockACMEService)(nil)` ensures interface compliance is caught at build time, not at runtime.
- To simulate errors, set `NewACMEEnrollmentFunc` to return a non-nil error.
