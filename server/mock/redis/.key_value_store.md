Mock implementation of the `fleet.KeyValueStore` interface, auto-generated by `mockimpl` for use in tests.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KeyValueStore` | struct | Mock store implementing `fleet.KeyValueStore` |
| `SetFunc` | type | Function signature for the `Set` operation |
| `GetFunc` | type | Function signature for the `Get` operation |
| `SetFuncInvoked` | bool | Tracks whether `Set` was called during a test |
| `GetFuncInvoked` | bool | Tracks whether `Get` was called during a test |

## Usage Example

```go
func TestMyService(t *testing.T) {
    stored := make(map[string]string)

    mockKV := &mock.KeyValueStore{
        SetFunc: func(ctx context.Context, key, value string, ttl time.Duration) error {
            stored[key] = value
            return nil
        },
        GetFunc: func(ctx context.Context, key string) (*string, error) {
            v, ok := stored[key]
            if !ok {
                return nil, nil
            }
            return &v, nil
        },
    }

    svc := NewMyService(mockKV)
    svc.DoSomething(context.Background())

    assert.True(t, mockKV.SetFuncInvoked, "expected Set to be called")
    assert.True(t, mockKV.GetFuncInvoked, "expected Get to be called")
}
```

## Notes

- Both `SetFuncInvoked` and `GetFuncInvoked` flags are set under a mutex, making invocation tracking safe for concurrent tests.
- Panics if `SetFunc` or `GetFunc` is nil when the corresponding method is called — assign both before use.
