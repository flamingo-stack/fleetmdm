Auto-generated mock implementation of the `depot.Depot` interface for use in tests, tracking invocation state for each method via boolean flags.

## Key Components

### Type Aliases

| Type | Signature |
|---|---|
| `CAFunc` | `func(pass []byte) ([]*x509.Certificate, *rsa.PrivateKey, error)` |
| `PutFunc` | `func(name string, crt *x509.Certificate) error` |
| `SerialFunc` | `func() (*big.Int, error)` |
| `HasCNFunc` | `func(cn string, allowTime int, cert *x509.Certificate, revokeOldCertificate bool) (bool, error)` |

### `Depot` Struct

A thread-safe mock that satisfies `depot.Depot`. Each method delegates to its corresponding `*Func` field and sets the matching `*FuncInvoked` boolean flag under a mutex lock.

| Method | Description |
|---|---|
| `CA(pass []byte)` | Retrieves CA certificates and private key |
| `Put(name string, crt *x509.Certificate)` | Stores a certificate by name |
| `Serial()` | Returns the next serial number |
| `HasCN(cn string, ...)` | Checks if a common name exists, optionally revoking old certificates |

## Usage Example

```go
mockDepot := &mock.Depot{
    CAFunc: func(pass []byte) ([]*x509.Certificate, *rsa.PrivateKey, error) {
        return testCerts, testKey, nil
    },
    SerialFunc: func() (*big.Int, error) {
        return big.NewInt(42), nil
    },
}

certs, key, err := mockDepot.CA([]byte("password"))

if !mockDepot.CAFuncInvoked {
    t.Error("expected CA to be called")
}
```
