Central mock registry for Fleet service interfaces. It registers code generation directives for mock implementations and provides composite types that embed the generated mock stores.

## Key Components

| Symbol | Description |
|--------|-------------|
| `//go:generate` directives | Three directives that invoke `mockimpl/impl.go` to auto-generate mocks for `fleet.Service`, `fleet.KeyValueStore`, and `fleet.AdvancedKeyValueStore` |
| `var _ fleet.Service` | Compile-time interface compliance check ensuring `svcmock.Service` satisfies `fleet.Service` |
| `KVStore` | Embeds `kvmock.KeyValueStore` — a mock for the basic key-value store interface |
| `AdvancedKVStore` | Embeds `akvmock.AdvancedKeyValueStore` — a mock for the advanced key-value store interface |

## Usage Example

```go
// Use KVStore in a test
store := &mock.KVStore{}
store.GetFunc = func(ctx context.Context, key string) ([]byte, error) {
    return []byte("value"), nil
}

// Use AdvancedKVStore in a test
advStore := &mock.AdvancedKVStore{}
advStore.CompareAndSwapFunc = func(ctx context.Context, key string, oldVal, newVal []byte) (bool, error) {
    return true, nil
}
```

## Regenerating Mocks

Run the following from the `server/mock` directory to regenerate all mock implementations:

```bash
go generate ./...
```

This produces:
- `service/service_mock.go` — full `fleet.Service` mock
- `redis/key_value_store.go` — `fleet.KeyValueStore` mock
- `redis_advanced/advanced_key_value_store.go` — `fleet.AdvancedKeyValueStore` mock
