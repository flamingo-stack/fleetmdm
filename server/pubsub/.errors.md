Defines the error types and interfaces for the `pubsub` package, providing structured error handling for pub/sub channel operations.

## Key Components

- **`Error` interface** — Extends the standard `error` interface with a `NoSubscriber() bool` method to identify subscriber-related failures.
- **`noSubscriberError` struct** — Concrete error type returned when a channel operation fails due to no active subscribers. Implements both `Error()` and `NoSubscriber()`.

## Usage Example

```go
func handlePubSubError(err error) {
    if psErr, ok := err.(pubsub.Error); ok {
        if psErr.NoSubscriber() {
            log.Printf("no subscribers available: %v", psErr)
            // handle gracefully, e.g. skip publishing
            return
        }
    }
    // handle other errors
    log.Fatalf("unexpected error: %v", err)
}
```

## Notes

- `noSubscriberError` is unexported; callers should use the `pubsub.Error` interface for type assertions rather than the concrete struct.
- `NoSubscriber()` always returns `true` for `noSubscriberError`, making it safe to use as a discriminator in error handling logic.
