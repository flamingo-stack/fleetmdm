Provides `Up` and `UpByOne` migration methods for advancing a database schema forward using the goose migration client.

## Key Components

| Function | Description |
|----------|-------------|
| `Client.Up` | Runs all pending migrations from the current version to the latest available |
| `Client.UpByOne` | Advances the database schema by exactly one migration step |

## Usage Example

```go
client := goose.NewClient()
db, _ := sql.Open("postgres", dsn)

// Apply all pending migrations
if err := client.Up(db, "./migrations"); err != nil {
    log.Fatal(err)
}

// Apply only the next single migration
if err := client.UpByOne(db, "./migrations"); err != nil {
    if err == goose.ErrNoNextVersion {
        log.Println("already at latest version")
    }
    log.Fatal(err)
}
```

## Behavior Notes

- **`Up`** loops continuously, applying each pending migration in order until `ErrNoNextVersion` is returned — at which point it exits cleanly with `nil`
- **`UpByOne`** applies exactly one migration then returns; propagates `ErrNoNextVersion` to the caller rather than swallowing it, allowing callers to detect an already-current database
- Both methods use `collectMigrations` with `minVersion`/`maxVersion` bounds and delegate execution to `runMigration` with the `migrateUp` direction
