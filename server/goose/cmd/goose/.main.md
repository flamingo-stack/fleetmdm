CLI entry point for the `goose` database migration tool, parsing flags and arguments to connect to a database and execute migration commands.

## Key Components

| Component | Description |
|-----------|-------------|
| `main()` | Parses CLI arguments, opens a database connection, and dispatches to `goose.Run()` |
| `usage()` | Prints help text including supported options and commands |
| `dir` flag | `-dir` option specifying the directory containing migration files (default: `.`) |
| Supported drivers | `postgres`, `mysql`, `sqlite3` |

## Usage Example

```bash
# Run all pending migrations (PostgreSQL)
goose -dir ./migrations postgres "user=postgres dbname=mydb sslmode=disable" up

# Roll back the latest migration (MySQL)
goose mysql "user:password@/dbname" down

# Check migration status (SQLite)
goose sqlite3 ./foo.db status

# Create a new blank migration file
goose create add_users_table sql
```

## Supported Commands

| Command | Description |
|---------|-------------|
| `up` | Migrate to the most recent version |
| `down` | Roll back one version |
| `redo` | Re-run the latest migration |
| `status` | Show migration status for the current DB |
| `version` | Print the current database schema version |
| `create` | Generate a blank migration template |

> **Note:** The `create` command does not require a database connection and can be run with only a migration name argument.
