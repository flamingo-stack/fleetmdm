Provides a high-level entry point for generating new blank migration files using the `goose` migration framework.

## Key Components

- **`Create(db *sql.DB, dir, name, migrationType string) error`** — Creates a new blank migration file in the specified directory. Delegates file generation to `CreateMigration` using the current UTC time as the migration timestamp, then prints the resulting file paths to stdout.

## Usage Example

```go
import (
    "database/sql"
    _ "github.com/lib/pq"
    "github.com/flamingo-stack/fleetmdm/goose"
)

db, _ := sql.Open("postgres", "postgres://localhost/mydb")

err := goose.Create(db, "./migrations", "add_users_table", "sql")
if err != nil {
    log.Fatal(err)
}
// Output: Created sql migration files at [./migrations/20240101120000_add_users_table.sql]
```

## Notes

- The `db` parameter is accepted but not used directly by `Create`; it is present for interface consistency with other `goose` functions.
- The migration timestamp is derived from `time.Now().UTC()`, ensuring consistent, timezone-independent file naming.
- Supported values for `migrationType` are typically `"sql"` or `"go"`, as defined by `CreateMigration`.
