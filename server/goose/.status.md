Provides migration status reporting by querying the database for applied migration timestamps and displaying a formatted status table for all discovered migrations.

## Key Components

- **`Client.Status`** — Collects all migrations from the given directory, ensures the version table exists, then prints a formatted status table to stdout.
- **`printMigrationStatus`** — Queries `goose_db_version` for a specific migration version and prints whether it was applied (with timestamp) or is still pending.

## Usage Example

```go
client := goose.NewClient()
db, _ := sql.Open("postgres", "postgres://localhost/mydb")

if err := client.Status(db, "./migrations"); err != nil {
    log.Fatal(err)
}
// Output:
//     Applied At                  Migration
//     =======================================
//     Mon Jan  2 15:04:05 2006    -- 001_create_users.sql
//     Pending                     -- 002_add_index.sql
```

## Notes

- Requires the `goose_db_version` table to exist; calls `GetDBVersion` to initialize it on a pristine database if needed.
- Migration records are ordered by `tstamp DESC` with `LIMIT 1` to reflect the most recent application state.
- Timestamps are formatted using `time.ANSIC`; unapplied migrations display `"Pending"`.
