Rolls back the most recently applied database migration by one version step.

## Key Components

- **`Down(db *sql.DB, dir string) error`** — Method on `Client` that retrieves the current schema version, collects available migrations from `dir`, resolves the active migration, and executes a single downward rollback via `runMigration`.

## Usage Example

```go
client := goose.NewClient()

if err := client.Down(db, "./migrations"); err != nil {
    log.Fatalf("rollback failed: %v", err)
}
```

## Notes

- Only rolls back **one migration** at a time. Call repeatedly or use a `DownTo` variant to roll back multiple steps.
- Returns an error if no migration matching the current database version is found in `dir`.
- Delegates the actual SQL execution to `runMigration` with the `migrateDown` direction flag.
