Provides shared utility functions for the `goose` package, supporting file creation from Go templates.

## Key Components

- **`writeTemplateToFile`** — Creates a file at the given path, executes a `text/template.Template` with the provided data, and writes the result to disk. Returns the file name on success or an error.

## Usage Example

```go
tmpl := template.Must(template.New("migration").Parse("-- Migration: {{.Name}}\n"))
data := struct{ Name string }{"create_users"}

filePath, err := writeTemplateToFile("/migrations/001_create_users.sql", tmpl, data)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Written to:", filePath)
```

## Notes

- The file is created (or overwritten) using `os.Create`.
- The underlying file handle is closed via `defer` after template execution.
- This is an internal helper; it is not exported outside the package.
