Reports the current database migration version by querying the database and printing the result to stdout.

## Key Components

- **`Version(db *sql.DB, dir string) error`** — Client method that retrieves and prints the current schema version using `GetDBVersion`, returning any error encountered.

## Usage Example

```go
client := goose.NewClient()
if err := client.Version(db, "./migrations"); err != nil {
    log.Fatal(err)
}
// Output: goose: dbversion 42
```

> **Note:** The `dir` parameter is accepted but unused in the current implementation.
