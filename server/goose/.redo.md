Re-applies the most recently run migration by rolling it back and re-running it, along with the next available migration.

## Key Components

- **`Redo(db *sql.DB, dir string) error`** — Client method that performs a two-step redo operation: rolls back the current migration version, then re-applies it followed by the next migration in sequence.

## Behavior

1. Fetches the current schema version from the database via `GetDBVersion`
2. Collects all available migrations from `dir`
3. Resolves the `current` migration and the `previous` (next in sequence) migration relative to the current version
4. Runs both migrations upward using `migrateUp`

## Usage Example

```go
client := goose.NewClient()
db, _ := sql.Open("postgres", "postgres://localhost/mydb")

if err := client.Redo(db, "./migrations"); err != nil {
    log.Fatalf("redo failed: %v", err)
}
```

## Notes

- Intended for development workflows where a migration needs to be quickly re-applied after a code change.
- Calls `migrations.Next` with the **current** version — the naming convention here means "next after current" rather than a strictly prior version; review the `Next` implementation when debugging unexpected behavior.
