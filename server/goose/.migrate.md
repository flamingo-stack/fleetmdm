Core migration management logic for the `goose` database migration library, providing version tracking, migration collection, sorting, and database version table management.

## Key Components

### Types & Errors

| Symbol | Description |
|--------|-------------|
| `ErrNoCurrentVersion` | Returned when no migration matches the current DB version |
| `ErrNoNextVersion` | Returned when no migration exists beyond the current version |
| `Migrations` | Sortable slice of `*Migration` with helper methods |
| `globalGoose` | Package-level `*Client` singleton (PostgreSQL dialect, `goose_db_version` table) |

### `Migrations` Methods

- **`Current(current int64)`** — finds the migration matching the given version
- **`Next(current int64)`** — finds the first migration with a version greater than `current`
- **`Last()`** — returns the highest-version migration
- **`Len/Swap/Less`** — implements `sort.Interface`; panics on duplicate versions

### Client Methods

- **`AddMigration(up, down)`** — registers a Go migration using `runtime.Caller` to capture the source filename and extract the numeric version
- **`collectMigrations(dirpath, current, target)`** — scans a directory for `.sql` files and merges registered Go migrations, filtered by version range
- **`GetDBVersion(db)`** — queries the version table for the current applied version; initializes the table if missing; safely returns `0` on an empty table (race-safe fix)
- **`createVersionTable(db)`** — creates the version tracking table and seeds it with version `0` in a single transaction

### Package-Level Function

- **`AddMigration(up, down)`** — legacy wrapper that registers migrations against `globalGoose` (caller frame preserved manually)

## Usage Example

```go
// Register a Go migration (called from a versioned migration file)
goose.AddMigration(
    func(tx *sql.Tx) error {
        _, err := tx.Exec(`CREATE TABLE users (id SERIAL PRIMARY KEY)`)
        return err
    },
    func(tx *sql.Tx) error {
        _, err := tx.Exec(`DROP TABLE users`)
        return err
    },
)

// Get the current database version
db, _ := sql.Open("postgres", dsn)
version, err := client.GetDBVersion(db)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Current DB version: %d\n", version)
```

> **OpenFrame note:** `GetDBVersion` returns `0` instead of panicking when the version table exists but is empty, guarding against race conditions on fresh database initialization.
