Defines the core migration data structures and lifecycle functions for executing, creating, and finalizing database migrations in both SQL and Go formats.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MigrationRecord` | struct | Represents a persisted migration record with version, timestamp, and direction |
| `Migration` | struct | Holds migration metadata including version, source path, and Up/Down transaction functions |
| `NumericComponent` | func | Parses the numeric version prefix from a migration filename (e.g., `20060102_name.sql`) |
| `CreateMigration` | func | Scaffolds new migration files from templates into a target directory |
| `(*Client).runMigration` | method | Dispatches execution to either SQL or Go migration runners based on file extension |
| `(*Client).FinalizeMigration` | method | Inserts the version record and commits the transaction |
| `parseNameAndDate` | func | Extracts a human-readable name and formatted date from a Go migration filename |

## Usage Example

```go
// Parse the version from a migration filename
version, err := goose.NumericComponent("20231015_add_users_table.sql")
if err != nil {
    log.Fatal(err)
}
fmt.Println(version) // 20231015

// Scaffold a new SQL migration
paths, err := goose.CreateMigration("add_devices_table", "sql", "./db/migrations", time.Now())
if err != nil {
    log.Fatal(err)
}
fmt.Println(paths) // [./db/migrations/20231015120000_add_devices_table.sql]

// Scaffold a new Go migration (also generates a _test.go file)
paths, err = goose.CreateMigration("add_index", "go", "./db/migrations", time.Now())
fmt.Println(paths) // [.../add_index.go, .../add_index_test.go]
```

## Notes

- Migration filenames must follow the pattern `YYYYMMDDHHMMSS_description.{sql,go}`.
- Go migrations are wrapped in a `*sql.Tx` and rolled back automatically on failure.
- Date parsing intentionally truncates to 8 digits (`YYYYMMDD`) to tolerate out-of-range seconds in older migration filenames.
