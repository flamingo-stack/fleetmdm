Orchestrates automation dispatch for failing Fleet MDM policies, routing each failing policy to the appropriate automation backend (webhook, Jira, or Zendesk) based on global, team, or "no team" configuration.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `FailingPolicyAutomationType` | `type` | String enum for supported automation backends |
| `FailingPolicyWebhook` / `FailingPolicyJira` / `FailingPolicyZendesk` | `const` | Supported automation type values |
| `FailingPolicyAutomationConfig` | `struct` | Holds resolved automation config (type, policy IDs, webhook URL, batch size) |
| `TriggerFailingPoliciesAutomation` | `func` | Main entry point; iterates failing policy sets and dispatches via `sendFunc` |
| `buildFailingPolicyAutomationConfig` | `func` | Resolves active automation type and constructs a `FailingPolicyAutomationConfig` |
| `makeTeamConfigCache` | `func` | Returns a memoized loader for per-team automation configs |
| `makeDefaultTeamConfigCache` | `func` | Returns a memoized loader for the "No Team" default config |
| `getActiveAutomation` | `func` | Determines which automation (if any) is currently enabled |

## Usage Example

```go
err := policies.TriggerFailingPoliciesAutomation(
    ctx,
    ds,
    logger,
    failingPoliciesSet,
    func(policy *fleet.Policy, cfg policies.FailingPolicyAutomationConfig) error {
        switch cfg.AutomationType {
        case policies.FailingPolicyWebhook:
            return sendWebhook(policy, cfg.WebhookURL, cfg.HostBatchSize)
        case policies.FailingPolicyJira:
            return createJiraTicket(policy)
        case policies.FailingPolicyZendesk:
            return createZendeskTicket(policy)
        }
        return nil
    },
)
```

## Routing Logic

Scope is determined by `policy.TeamID`:

- **`nil`** → global automation config from `AppConfig`
- **`0`** → "No Team" default config via `makeDefaultTeamConfigCache`
- **any other value** → per-team config via `makeTeamConfigCache`

Policies not present in the resolved config's `PolicyIDs` map are skipped and removed from the failing set. Deleted policies (`sql.ErrNoRows`) are silently pruned from the set.
