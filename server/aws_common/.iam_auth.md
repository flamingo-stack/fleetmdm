Provides thread-safe AWS IAM authentication token management with automatic caching and refresh, plus AWS configuration loading with optional assume-role support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IAMAuthTokenManager` | Struct | Manages IAM auth tokens with RW-mutex-protected caching |
| `IAMTokenCache` | Struct | Holds a cached token and its generation timestamp |
| `TokenGenerator` | Type | Function signature for service-specific token generators (RDS, ElastiCache, etc.) |
| `NewIAMAuthTokenManager` | Constructor | Creates a new `IAMAuthTokenManager` with a provided token generator |
| `GetToken` | Method | Returns a valid cached token or generates a new one; uses double-checked locking |
| `LoadAWSConfig` | Function | Loads AWS SDK config for a region, optionally configuring an assume-role provider |

**Token refresh:** Tokens are cached for 10 minutes plus up to 30 seconds of random jitter (well within the 15-minute AWS token validity window).

## Usage Example

```go
// Define a service-specific token generator (e.g., RDS IAM auth)
rdsTokenGen := func(ctx context.Context) (string, error) {
    return rdsauth.BuildAuthToken(ctx, dbEndpoint, region, dbUser, cfg.Credentials)
}

// Create a token manager
manager := aws_common.NewIAMAuthTokenManager(rdsTokenGen)

// Load AWS config (with optional assume role)
cfg, err := aws_common.LoadAWSConfig(ctx, "us-east-1", "arn:aws:iam::123456789:role/MyRole", "externalID")
if err != nil {
    log.Fatal(err)
}

// Retrieve a token (served from cache if still valid)
token, err := manager.GetToken(ctx)
if err != nil {
    log.Fatal(err)
}
```

> **Concurrency:** `GetToken` uses a read lock for cache hits and upgrades to a write lock only on cache miss, with a double-check to prevent redundant token generation under concurrent load.
