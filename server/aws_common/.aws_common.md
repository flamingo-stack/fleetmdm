Shared utility for configuring AWS credential providers using the STS AssumeRole flow, used by Fleet's AWS-backed services (Kinesis, Firehose, SES, Lambda, S3).

## Key Components

### `ConfigureAssumeRoleProvider`

```text
func ConfigureAssumeRoleProvider(
    conf aws.Config,
    opts []func(*aws_config.LoadOptions) error,
    stsAssumeRoleARN string,
    stsExternalID string,
) (aws.Config, error)
```

Wraps an existing `aws.Config` with an STS [AssumeRole](https://docs.aws.amazon.com/STS/latest/APIReference/API_AssumeRole.html) credentials provider. Key behaviours:

- Creates an STS client from the provided base config.
- Optionally attaches an `ExternalID` (used for cross-account trust policies).
- Appends `WithCredentialsProvider` to `opts`, **overriding** any previously set credentials provider.
- Calls `LoadDefaultConfig` to produce a fully resolved `aws.Config`.

## Usage Example

```go
import (
    aws_config "github.com/aws/aws-sdk-go-v2/config"
    aws_common "github.com/fleetdm/fleet/v4/server/aws_common"
)

// Load a base config (e.g. from environment / instance profile)
baseConf, err := aws_config.LoadDefaultConfig(context.Background(),
    aws_config.WithRegion("us-east-1"),
)
if err != nil {
    log.Fatal(err)
}

// Assume a cross-account role before creating service clients
conf, err := aws_common.ConfigureAssumeRoleProvider(
    baseConf,
    []func(*aws_config.LoadOptions) error{
        aws_config.WithRegion("us-east-1"),
    },
    "arn:aws:iam::123456789012:role/FleetRole",
    "optional-external-id",
)
if err != nil {
    log.Fatal(err)
}

// Use conf with any AWS service client (S3, Kinesis, etc.)
s3Client := s3.NewFromConfig(conf)
```

> **Note:** Any `WithCredentialsProvider` option passed in `opts` will be replaced by the AssumeRole provider. Pass the external ID as an empty string (`""`) to skip setting it.
