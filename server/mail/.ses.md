Amazon SES email sender implementation for Fleet, providing SMTP-free email delivery via the AWS SES SDK v2.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `sesSender` | struct | Core sender holding the SES client, source ARN, and optional sender domain |
| `fleetSESSender` | interface | Thin wrapper around `ses.Client.SendRawEmail` to allow test mocking |
| `NewSESSender` | func | Constructor that wires AWS config, optional static credentials, STS assume-role, and endpoint override |
| `SendEmail` | method | Builds the raw MIME message and dispatches it via SES |
| `CanSendEmail` | method | Returns `true` when the SES client is initialised |
| `getFromSES` | func | Derives the `From:` header — uses `senderDomain` when set, otherwise extracts the host from `fleet.Email.ServerURL` |
| `sendMail` | method | Calls `SendRawEmail` with destinations, raw message bytes, and the source ARN for both `FromArn` and `SourceArn` |

## Usage Example

```go
sender, err := mail.NewSESSender(
    "us-east-1",          // region
    "",                   // endpointURL (empty = AWS default)
    "AKIAIOSFODNN7EXAMPLE", // access key ID
    "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY", // secret
    "",                   // stsAssumeRoleArn
    "",                   // stsExternalID
    "arn:aws:ses:us-east-1:123456789012:identity/example.com", // sourceArn
    "example.com",        // senderDomain
)
if err != nil {
    log.Fatal(err)
}

err = sender.SendEmail(ctx, fleet.Email{
    To:        []string{"user@example.com"},
    Subject:   "Welcome",
    ServerURL: "https://fleet.example.com",
})
```

> **Credential resolution:** When `id` and `secret` are empty, the sender falls back to the standard AWS credential chain (`AWS_PROFILE`, instance metadata, etc.). Set `stsAssumeRoleArn` to cross-account roles without static keys.
