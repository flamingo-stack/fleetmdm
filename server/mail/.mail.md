Implements Fleet's email delivery service, supporting both SMTP and AWS SES backends with configurable authentication methods, TLS settings, and connection timeouts.

## Key Components

- **`NewService`** — Factory that returns either an SES sender or the default SMTP `mailService` based on `FleetConfig.Email.EmailBackend`.
- **`mailService`** — Core SMTP implementation satisfying `fleet.MailService`; handles `SendEmail`, `CanSendEmail`, and the internal `sendMail` pipeline.
- **`smtpAuth`** — Resolves the correct `smtp.Auth` strategy (CRAM-MD5, PLAIN, or LOGIN) from SMTP settings.
- **`LoginAuth` / `loginauth`** — Custom `smtp.Auth` implementation for the LOGIN mechanism, rejecting unencrypted non-localhost connections.
- **`dialTimeout`** — Establishes a TCP or TLS connection with a 28-second dial timeout and a minimum 30-second error delay to mitigate port-scan timing attacks.
- **`getMessageBody`** — Assembles raw MIME email bytes (headers + HTML body) from a `fleet.Email`.
- **`Test`** — Sends a one-off test email through any `fleet.MailService` that also implements the internal `sender` interface.
- **`SMTPTestMailer`** — Renders the `smtp_setup.html` template into a test email body for SMTP configuration validation.
- **`ErrSTARTTLSWithoutSSLTLS`** — Sentinel error surfaced when STARTTLS fails due to an incompatible SSL/TLS + cert-verification configuration.

## Usage Example

```go
// Create the mail service from Fleet config
svc, err := mail.NewService(cfg)
if err != nil {
    log.Fatal(err)
}

// Send a test email to validate SMTP settings
testEmail := fleet.Email{
    Subject: "SMTP Test",
    To:      []string{"admin@example.com"},
    Mailer:  &mail.SMTPTestMailer{BaseURL: "https://fleet.example.com"},
    SMTPSettings: fleet.SMTPSettings{
        SMTPConfigured:    true,
        SMTPServer:        "smtp.example.com",
        SMTPPort:          mail.PortTLS,
        SMTPSenderAddress: "fleet@example.com",
        SMTPEnableStartTLS: true,
        SMTPVerifySSLCerts: true,
    },
}

if err := mail.Test(svc, testEmail); err != nil {
    log.Printf("SMTP test failed: %v", err)
}
```
