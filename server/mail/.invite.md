Builds HTML email messages for Fleet user invitations by rendering a pre-defined template with invite-specific context data.

## Key Components

- **`InviteMailer`** — Struct holding invitation context for template rendering, including:
  - `*fleet.Invite` — Embedded invite model (token, email, etc.)
  - `BaseURL` / `AssetURL` — Safe template URLs for links and static assets
  - `InvitedBy` — Display name of the inviting user
  - `OrgName` — Organization name for personalization
  - `CurrentYear` — Auto-populated year for email footer copyright

- **`Message() ([]byte, error)`** — Renders the `invite_token.html` template with the mailer's context and returns the resulting HTML as a byte slice.

## Usage Example

```go
mailer := &mail.InviteMailer{
    Invite:    invite,
    BaseURL:   template.URL("https://fleet.example.com"),
    AssetURL:  template.URL("https://assets.example.com"),
    InvitedBy: "Alice",
    OrgName:   "Acme Corp",
}

body, err := mailer.Message()
if err != nil {
    log.Fatal(err)
}

// body contains the rendered HTML email ready for delivery
```

The template is loaded from `server/mail/templates/invite_token.html` via `server.GetTemplate`. `CurrentYear` is automatically set at render time and does not need to be provided by the caller.
