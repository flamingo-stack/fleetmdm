Renders the MFA (Multi-Factor Authentication) email by binding user and token data into an HTML template.

## Key Components

### `MFAMailer` struct
| Field | Type | Description |
|---|---|---|
| `FullName` | `string` | Recipient's display name |
| `Token` | `string` | MFA authentication token |
| `BaseURL` | `template.URL` | Application base URL for links |
| `AssetURL` | `template.URL` | CDN/asset base URL for email images |
| `CurrentYear` | `int` | Auto-populated for copyright footer |
| `TTLInMinutes` | `float64` | Token expiry, truncated to whole minutes |

### `Message() ([]byte, error)`
Populates `CurrentYear` and `TTLInMinutes` at render time, loads `server/mail/templates/mfa.html`, executes the template with the mailer's fields, and returns the rendered HTML as a byte slice.

## Usage Example

```go
mailer := &mail.MFAMailer{
    FullName: "Jane Smith",
    Token:    "abc123token",
    BaseURL:  "https://fleet.example.com",
    AssetURL: "https://assets.example.com",
}

body, err := mailer.Message()
if err != nil {
    log.Fatal(err)
}

// Pass body to your mail-sending layer
err = smtp.SendMail(addr, auth, from, []string{to}, body)
```

> **Note:** `TTLInMinutes` is derived from `fleet.MFALinkTTL`, truncated to whole minutes via `Truncate(time.Minute)`, ensuring the displayed expiry is never overstated to the user.
