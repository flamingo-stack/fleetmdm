Defines email mailer types for user account actions, rendering HTML email templates for password resets and email change confirmations.

## Key Components

### `ChangeEmailMailer`
Mailer struct for email change confirmation messages.

| Field | Type | Description |
|---|---|---|
| `BaseURL` | `template.URL` | Base URL for Fleet endpoints |
| `AssetURL` | `template.URL` | URL for image asset loading |
| `Token` | `string` | Email change confirmation token |
| `CurrentYear` | `int` | Auto-populated year for copyright footer |

**`Message() ([]byte, error)`** — Renders `change_email_confirmation.html` and returns the email body as bytes.

---

### `PasswordResetMailer`
Mailer struct for password reset emails.

| Field | Type | Description |
|---|---|---|
| `BaseURL` | `template.URL` | Base URL for Fleet endpoints |
| `AssetURL` | `template.URL` | URL for image asset loading |
| `Token` | `string` | Password reset token |
| `CurrentYear` | `int` | Auto-populated year for copyright footer |

**`Message() ([]byte, error)`** — Renders `password_reset.html` and returns the email body as bytes.

---

## Usage Example

```go
mailer := &mail.PasswordResetMailer{
    BaseURL:  template.URL("https://fleet.example.com"),
    AssetURL: template.URL("https://assets.example.com"),
    Token:    "abc123resettoken",
}

body, err := mailer.Message()
if err != nil {
    log.Fatal(err)
}

// Send body via SMTP or mail service
```

Both mailers auto-set `CurrentYear` at render time via `time.Now().Year()`, ensuring copyright footers stay current without manual updates.
