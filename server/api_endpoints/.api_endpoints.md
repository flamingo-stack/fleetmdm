Provides a catalog of known API endpoints loaded from an embedded YAML file, with utilities to query and validate route registration against a Gorilla Mux router.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `FeatureRouteFunc` | Type | Callback signature for registering feature module routes onto a `*mux.Router` |
| `GetAPIEndpoints()` | Function | Returns a safe copy of the embedded `[]fleet.APIEndpoint` catalog |
| `IsInCatalog()` | Function | Reports whether a given endpoint fingerprint exists in the catalog set |
| `Validate()` | Function | Walks a live router (plus optional feature routers) and returns an error listing any catalog endpoints that are not registered |
| `loadAPIEndpoints()` | Function (internal) | Unmarshals `api_endpoints.yml` and panics on duplicate fingerprints |
| `init()` | Function | Bootstraps the package-level `apiEndpoints` slice and `apiEndpointsSet` map at startup |

## Usage Example

```go
// Check a single endpoint fingerprint
fp := fleet.NewAPIEndpointFromTpl("GET", "/api/v1/fleet/hosts").Fingerprint()
if apiendpoints.IsInCatalog(fp) {
    fmt.Println("endpoint is in catalog")
}

// Validate all catalog entries against a running mux router,
// including routes registered by feature modules.
err := apiendpoints.Validate(mainRouter, featureA.Routes, featureB.Routes)
if err != nil {
    log.Fatalf("route catalog mismatch: %v", err)
}

// Iterate the full catalog (e.g., for documentation generation)
for _, e := range apiendpoints.GetAPIEndpoints() {
    fmt.Printf("%s %s\n", e.Method, e.Path)
}
```

## Notes

- The YAML catalog (`api_endpoints.yml`) is embedded at compile time via `//go:embed`; duplicate entries cause a startup `panic`.
- `Validate` spins up a **throwaway** `*mux.Router` for each `FeatureRouteFunc`, so feature routes never need to be pre-registered on the main router to be validated.
- Source: [`api_endpoints.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/api_endpoints.go)
