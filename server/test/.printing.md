Provides a helper utility for pretty-printing any Go value as formatted JSON output to stdout, useful during testing and debugging.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `PrettyPrintJSON` | Function | Marshals any value to indented JSON and prints it with a label prefix |

## Usage Example

```go
type Device struct {
    ID       string `json:"id"`
    Hostname string `json:"hostname"`
}

device := Device{ID: "abc123", Hostname: "mac-pro-01"}
PrettyPrintJSON("device", device)

// Output:
// device: {
//   "id": "abc123",
//   "hostname": "mac-pro-01"
// }
```

## Notes

- Lives in the `test` package — intended for use in test helpers and debug utilities only
- Prints a user-readable error message if marshalling fails rather than panicking
- The `prefix` parameter acts as a label, making it easy to distinguish multiple debug outputs in test logs
