Provides test helper functions for constructing authenticated `context.Context` values used in unit and integration tests.

## Key Components

| Function | Description |
|---|---|
| `UserContext` | Wraps a context with a `fleet.User` as the authenticated viewer |
| `HostContext` | Wraps a context with a `fleet.Host` using device-token authentication |

## Usage Example

```go
// Simulate a user-authenticated request
user := &fleet.User{ID: 1, Email: "admin@example.com"}
ctx := test.UserContext(context.Background(), user)

// Simulate a device-token authenticated host request
host := &fleet.Host{ID: 42, Hostname: "my-device"}
ctx := test.HostContext(context.Background(), host)
```

## Notes

- `UserContext` delegates to `viewer.NewContext`, populating the standard viewer context used across Fleet service layers.
- `HostContext` sets up both the authz context and the host context, then explicitly marks the authentication method as `AuthnDeviceToken`, mirroring real device-authenticated request flows.
- These helpers are intended for use in the `test` package only and should not be used in production code.
