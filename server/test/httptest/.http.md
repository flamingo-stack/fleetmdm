Provides a test helper for making HTTP requests in Go test suites, asserting expected status codes and surfacing Fleet-specific JSON error details on failure.

## Key Components

### `DoHTTPReq`

Executes an HTTP request within a test context and validates the response status code. On mismatch, it attempts to decode the response body as a Fleet `endpointer.JsonError` to produce a more descriptive failure message.

**Parameters:**

| Parameter | Description |
|---|---|
| `t` | Testing context |
| `client` | HTTP client to use for the request |
| `jsonDecoder` | Function to decode JSON response body |
| `verb` | HTTP method (`GET`, `POST`, etc.) |
| `rawBytes` | Request body bytes |
| `urlPath` | Full URL for the request |
| `headers` | Key-value map of request headers |
| `expectedStatusCode` | HTTP status code the test asserts |
| `queryParams` | Optional variadic key-value pairs appended as query parameters |

## Usage Example

```go
resp := httptest.DoHTTPReq(
    t,
    http.DefaultClient,
    json.NewDecoder,
    "POST",
    []byte(`{"name":"test"}`),
    "http://localhost:8080/api/v1/fleet/hosts",
    map[string]string{
        "Authorization": "Bearer token123",
        "Content-Type":  "application/json",
    },
    http.StatusOK,
    "per_page", "10",
    "page", "0",
)
defer resp.Body.Close()
```

> **Note:** `queryParams` must be supplied as sequential key-value pairs (even count). Passing an odd number of params immediately fails the test via `require.Fail`.
