Provides test helper utilities for enrolling Fleet hosts via the Orbit enrollment flow in integration and unit tests.

## Key Components

### `SetOrbitEnrollment`

```go
func SetOrbitEnrollment(t *testing.T, h *fleet.Host, ds fleet.Datastore) string
```

Enrolls a `fleet.Host` into Orbit using the datastore and returns the generated Orbit node key. It performs two operations:

1. Calls `ds.EnrollOrbit` with the host's hardware UUID, serial number, and team ID, using a randomly generated UUID as the node key.
2. Calls `ds.SetOrUpdateHostOrbitInfo` to simulate an Orbit agent check-in with version `1.22.0`, a desktop version of `42`, and device-mapping enabled.

## Usage Example

```go
func TestMyFeature(t *testing.T) {
    ds := mysql.CreateNamedMysqlDatastore(t)
    host := test.NewHost(t, ds, "hostname", "192.168.1.1", "nodekey", "uuid", time.Now())

    orbitKey := test.SetOrbitEnrollment(t, host, ds)
    // orbitKey can now be used in API calls that require an enrolled Orbit host
    _ = orbitKey
}
```

## Notes

- Intended **only for test packages** (`package test`); not for production use.
- Calls `require.NoError` on both datastore operations, so any failure immediately fails the test.
- The enrolled host is set with a hardcoded Orbit version (`1.22.0`) and desktop version (`42`) — adjust if your test requires specific version assertions.
