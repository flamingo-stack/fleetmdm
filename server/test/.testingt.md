A lightweight test helper that suppresses log output during testing by wrapping `testing.T` and silencing `Logf` calls.

## Key Components

- **`quiet` struct** — Embeds `*testing.T`, inheriting all standard test methods while overriding logging behavior.
- **`Quiet(t *testing.T) *quiet`** — Constructor that wraps a `*testing.T` instance to mute `Logf` output.
- **`Logf`** — Overridden method that discards all formatted log messages (no-op).

## Usage Example

```go
func TestSomething(t *testing.T) {
    // Wrap t to suppress verbose Logf output from noisy dependencies
    qt := test.Quiet(t)

    // Pass qt wherever a *testing.T is accepted
    result := someNoisyFunction(qt)

    if result != expected {
        t.Errorf("unexpected result: %v", result)
    }
}
```

> **Note:** Only `Logf` is silenced. All other `testing.T` methods (e.g., `Errorf`, `Fatalf`, `Run`) behave normally since they are inherited via embedding. Use the original `t` for assertions and failures to ensure test failures are still reported correctly.
