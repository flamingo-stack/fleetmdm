Test helper utilities for creating Fleet datastore objects in integration and unit tests.

## Key Components

| Function | Description |
|---|---|
| `NewQuery` | Creates a saved/unsaved query without a schedule |
| `NewQueryWithSchedule` | Creates a query with interval and automations settings |
| `NewPack` | Creates a query pack via `ApplyPackSpecs` |
| `NewCampaign` | Creates a distributed query campaign with a given status and timestamp |
| `AddHostToCampaign` | Adds a host target to an existing campaign |
| `AddLabelToCampaign` | Adds a label target to an existing campaign |
| `AddAllHostsLabel` | Seeds the built-in "All Hosts" label (manual membership) |
| `AddBuiltinLabels` | Seeds all built-in platform labels (macOS, Ubuntu, Windows, iOS, Android, etc.) |
| `NewHost` | Creates a host with optional functional options (`WithComputerName`, `WithPlatform`, `WithOSVersion`, `WithTeamID`) |
| `NewUser` | Creates a user with either Observer or Admin global role |
| `NewScheduledQuery` | Creates a scheduled query bound to a pack |
| `NewHostOption` | Functional option type for configuring `NewHost` |

## Usage Example

```go
// Create a host with custom options
host := test.NewHost(t, ds, "web-01", "10.0.0.1", "nodekey", "uuid-abc", time.Now(),
    test.WithPlatform("ubuntu"),
    test.WithTeamID(42),
)

// Create a query with an automated schedule
query := test.NewQueryWithSchedule(t, ds, nil, "disk_info", "SELECT * FROM disk;", authorID, true, 60, true)

// Create a campaign and associate the host
campaign := test.NewCampaign(t, ds, query.ID, fleet.QueryRunning, time.Now())
test.AddHostToCampaign(t, ds, campaign.ID, host.ID)

// Seed all built-in labels
test.AddBuiltinLabels(t, ds)

// Create an admin user
user := test.NewUser(t, ds, "Alice", "alice@example.com", true)
```

> **Note:** All functions call `require.NoError` internally and reload created objects from the datastore so returned structs include server-generated fields (IDs, timestamps).
