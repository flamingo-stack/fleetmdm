Provides a set of pre-defined `fleet.User` test fixtures and password constants for use across Fleet server test suites, covering all global and team-scoped roles.

## Key Components

**Password Constants**
- `GoodPassword` / `GoodPassword2` — valid password strings for authentication-related tests

**Global Role Users**
| Variable | ID | Role |
|---|---|---|
| `UserNoRoles` | 1 | None |
| `UserAdmin` | 2 | Admin |
| `UserMaintainer` | 3 | Maintainer |
| `UserObserver` | 4 | Observer |
| `UserObserverPlus` | 12 | ObserverPlus |
| `UserGitOps` | 15 | GitOps |
| `UserTechnician` | 18 | Technician |

**Team-Scoped Users**

Each role (Admin, Maintainer, Observer, ObserverPlus, GitOps, Technician) has fixtures for Team 1 and Team 2 independently. `UserTeamObserverTeam1TeamAdminTeam2` (ID 11) covers a multi-team, mixed-role scenario.

## Usage Example

```go
package myfeature_test

import (
    "testing"
    "github.com/flamingo-stack/fleetmdm/server/test"
)

func TestPolicyAccess(t *testing.T) {
    // Use a pre-built admin fixture
    user := test.UserAdmin

    // Use a team-scoped maintainer for Team 1
    teamUser := test.UserTeamMaintainerTeam1

    // Use a valid password in auth tests
    password := test.GoodPassword

    _ = user
    _ = teamUser
    _ = password
}
```

> **Note:** These are shared, pointer-based fixtures. Avoid mutating them in tests; copy the struct if modifications are needed to prevent cross-test contamination.
