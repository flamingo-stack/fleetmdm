Test helper utilities for creating and resolving host activity requests (script execution, software install/uninstall, VPP app install, and in-house app install) against a Fleet datastore.

## Key Components

| Function | Description |
|---|---|
| `CreateHostScriptUpcomingActivity` | Creates a script execution request for a host; returns the execution ID |
| `SetHostScriptResult` | Records the result of a queued script execution |
| `CreateHostSoftwareInstallUpcomingActivity` | Creates a software installer and queues an install request; returns the execution ID |
| `SetHostSoftwareInstallResult` | Records the result of a queued software install |
| `CreateHostSoftwareUninstallUpcomingActivity` | Creates a software installer and queues an uninstall request; returns the execution ID |
| `SetHostSoftwareUninstallResult` | Records the result of a queued software uninstall |
| `CreateHostVPPAppInstallUpcomingActivity` | Creates a VPP app and queues an install request; returns execution ID and Adam ID |
| `SetHostVPPAppInstallResult` | Stores the MDM command report and fires the activity callback for a VPP install |
| `CreateHostInHouseAppInstallUpcomingActivity` | Creates an in-house `.ipa` app and queues an install request; returns execution ID |
| `SetHostInHouseAppInstallResult` | Stores the MDM command report and fires the activity callback for an in-house install |

## Usage Example

```go
// Script activity round-trip
execID := test.CreateHostScriptUpcomingActivity(t, ds, host)
test.SetHostScriptResult(t, ds, host, execID, 0)

// Software install round-trip
execID = test.CreateHostSoftwareInstallUpcomingActivity(t, ds, host, user)
test.SetHostSoftwareInstallResult(t, ds, host, execID, 0)

// VPP app install round-trip (requires a VPP token created first)
// test.CreateInsertGlobalVPPToken(t, ds)
execID, adamID := test.CreateHostVPPAppInstallUpcomingActivity(t, ds, host)
test.SetHostVPPAppInstallResult(t, ds, nanods, host, execID, adamID, "Acknowledged", newActivityFn)
```

> **Note:** VPP app helpers require a VPP token to be present. Call `test.CreateInsertGlobalVPPToken(t, ds)` before using `CreateHostVPPAppInstallUpcomingActivity`.
