Provides test assertion helpers for comparing structs and slices while selectively ignoring specific fields (e.g., IDs, timestamps, host counts) using `go-cmp` options alongside `testify`.

## Key Components

| Export | Description |
|---|---|
| `TestingT` | Interface extending `assert.TestingT` with a `Helper()` method |
| `ElementsMatchSkipID` | Asserts slice equality, ignoring any field with a name ending in `"ID"` |
| `ElementsMatchSkipIDAndHostCount` | Asserts slice equality, ignoring `ID`, `HostCount`, and `TitleID` fields |
| `ElementsMatchSkipTimestampsID` | Asserts slice equality, ignoring `ID` and all timestamp fields |
| `EqualSkipTimestampsID` | Asserts struct equality, ignoring `ID` and all timestamp fields |
| `ElementsMatchWithOptions` | Core helper that wraps `assert.ElementsMatch` with custom `cmp.Options` |
| `QueryElementsMatch` | Asserts slice equality for query objects, ignoring author/pack/metadata fields |
| `QueriesMatch` | Asserts single query struct equality, ignoring the same query metadata fields |

Internal helpers (`isEmpty`, `isList`, `diffLists`, `formatListDiff`) support order-independent list diffing with configurable comparison options.

## Usage Example

```go
func TestPoliciesInserted(t *testing.T) {
    expected := []fleet.Policy{
        {Name: "Policy A", Query: "SELECT 1"},
        {Name: "Policy B", Query: "SELECT 2"},
    }
    actual := insertPolicies(t, ds, expected)

    // IDs assigned by DB are ignored in comparison
    ElementsMatchSkipID(t, expected, actual)
}

func TestAfterDBInsertion(t *testing.T) {
    original := fleet.Label{Name: "Servers", Query: "SELECT 1"}
    inserted := insertLabel(t, ds, original)

    // ID, CreatedAt, UpdatedAt all ignored
    EqualSkipTimestampsID(t, original, inserted)
}

func TestQueriesRoundTrip(t *testing.T) {
    a := fleet.Query{Name: "q1", Description: "desc"}
    b := fleet.Query{Name: "q1", Description: "desc", AuthorName: "alice"}

    // AuthorName, AuthorID, Packs, Saved etc. are ignored
    QueriesMatch(t, a, b)
}
```
