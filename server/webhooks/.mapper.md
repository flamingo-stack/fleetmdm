Maps vulnerability data and affected hosts into webhook payloads for third-party integrations.

## Key Components

| Component | Type | Description |
|---|---|---|
| `VulnMapper` | Interface | Contract for transforming vulnerability data into webhook payloads |
| `WebhookPayload` | Struct | Outbound payload containing CVE details and affected hosts |
| `hostPayloadPart` | Struct | Compact host representation embedded in the payload |
| `Mapper` | Struct | Default `VulnMapper` implementation |
| `NewMapper()` | Constructor | Returns a new `Mapper` as a `VulnMapper` interface |
| `GetPayload()` | Method | Builds a `WebhookPayload` from a CVE, metadata, and affected hosts |

**Note:** `WebhookPayload` includes premium-only fields (`EPSSProbability`, `CVSSScore`, `CISAKnownExploit`, `CVEPublished`) that are omitted in the base implementation but available for enrichment by premium mappers.

## Usage Example

```go
hostBaseURL, _ := url.Parse("https://fleet.example.com")

hosts := []fleet.HostVulnerabilitySummary{
    {ID: 42, Hostname: "laptop-01", DisplayName: "Alice's Laptop"},
}

mapper := webhooks.NewMapper()
payload := mapper.GetPayload(hostBaseURL, hosts, "CVE-2024-1234", fleet.CVEMeta{})

// payload.CVE  => "CVE-2024-1234"
// payload.Link => "https://nvd.nist.gov/vuln/detail/CVE-2024-1234"
// payload.Hosts[0].URL => "https://fleet.example.com/hosts/42"
```
