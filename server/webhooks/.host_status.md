Triggers host status webhooks for both global and team-level Fleet configurations when the percentage of unseen hosts exceeds a configured threshold.

## Key Components

| Function | Description |
|---|---|
| `TriggerHostStatusWebhook` | Entry point; fans out to global and team webhook triggers, collecting all errors |
| `triggerGlobalHostStatusWebhook` | Checks app config and fires the global host status webhook if enabled |
| `triggerTeamHostStatusWebhook` | Iterates all teams and fires per-team webhooks for those with the feature enabled |
| `processWebhook` | Core logic — queries unseen host stats, computes the unseen percentage, and POSTs a JSON payload if the threshold is breached |

## Usage Example

```go
err := webhooks.TriggerHostStatusWebhook(ctx, ds, logger)
if err != nil {
    logger.ErrorContext(ctx, "host status webhook failed", "error", err)
}
```

**Webhook payload structure:**

```json
{
  "text": "More than 25.00% of your hosts have not checked into Fleet for more than 7 days...",
  "data": {
    "unseen_hosts": 50,
    "total_hosts": 200,
    "days_unseen": 7,
    "host_ids": [1, 2, 3],
    "team_id": 4
  }
}
```

> `team_id` / `fleet_id` are only included in the payload when processing a team-scoped webhook.

## Behavior Notes

- Global and team webhooks run independently; a failure in one does not block the other.
- Within team processing, a single team failure is collected via `multierror` and execution continues for remaining teams.
- The webhook fires only when `percentUnseen >= settings.HostPercentage`; no-ops otherwise.
