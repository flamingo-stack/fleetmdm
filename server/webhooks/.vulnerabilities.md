Handles triggering webhook notifications for newly discovered vulnerabilities, grouping CVEs by affected hosts and dispatching batched HTTP POST payloads to a configured destination URL.

## Key Components

- **`TriggerVulnerabilitiesWebhook`** – Entry point that checks if the vulnerability webhook is enabled, groups vulnerabilities by CVE, retrieves affected hosts from the datastore, and sends batched payloads respecting the configured `HostBatchSize`.
- **`sendVulnerabilityHostBatch`** – Constructs a timestamped JSON payload and POSTs it to the target URL via `server.PostJSONWithTimeout`.
- **`VulnArgs`** – Input struct (defined elsewhere) carrying the app config, vulnerability list, metadata map, and timestamp.
- **`VulnMapper`** – Interface (defined elsewhere) used to transform host/CVE data into a `WebhookPayload`.

## Usage Example

```go
err := webhooks.TriggerVulnerabilitiesWebhook(
    ctx,
    datastore,
    logger,
    webhooks.VulnArgs{
        AppConfig:      appConfig,
        Vulnerablities: recentVulns,
        Meta:           vulnMeta,
        Time:           time.Now(),
    },
    myVulnMapper,
)
if err != nil {
    log.Fatalf("vulnerability webhook failed: %v", err)
}
```

Batching is controlled by `AppConfig.WebhookSettings.VulnerabilitiesWebhook.HostBatchSize`. When set to `0`, all affected hosts for a CVE are sent in a single request. The webhook is a no-op if `VulnerabilitiesWebhook.Enable` is `false`.
