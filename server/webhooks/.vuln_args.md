Defines the `VulnArgs` struct used as input data for vulnerability-related webhook payloads.

## Key Components

- **`VulnArgs`** — Struct bundling all data needed to construct and dispatch a vulnerability webhook event:
  - `Vulnerabilities` — Slice of `fleet.SoftwareVulnerability` entries to be reported
  - `Meta` — Map of CVE identifiers to `fleet.CVEMeta` metadata (severity, descriptions, etc.)
  - `AppConfig` — Pointer to the Fleet application configuration
  - `Time` — Timestamp associated with the vulnerability event

## Usage Example

```go
args := webhooks.VulnArgs{
    Vulnerablities: []fleet.SoftwareVulnerability{vuln1, vuln2},
    Meta: map[string]fleet.CVEMeta{
        "CVE-2024-1234": {CVSSScore: 9.8},
    },
    AppConfig: appCfg,
    Time:      time.Now(),
}
```
