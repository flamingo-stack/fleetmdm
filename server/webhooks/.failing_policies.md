Sends batched HTTP POST webhook notifications for Fleet policies that have failing hosts, marshalling structured payloads with support for deprecated JSON field aliasing.

## Key Components

- **`SendFailingPoliciesBatchedPOSTs`** — Main entry point. Retrieves failing hosts from a `FailingPolicySet`, sorts them by ID, splits them into configurable batches, and POSTs each batch as JSON to the configured webhook URL. Hosts are removed from the set after a successful send.
- **`failingPoliciesPayload`** — JSON payload struct containing a timestamp, the `fleet.Policy`, and a slice of `failingHost` entries.
- **`failingHost`** — Slim host representation included in the webhook payload: host ID, hostname, display name, and a direct Fleet UI URL.
- **`makeFailingHost`** — Constructs a `failingHost` from a `fleet.PolicySetHost`, building the host's Fleet UI deep-link URL by joining the server base URL with the host ID path.

## Usage Example

```go
webhookURL, _ := url.Parse("https://hooks.example.com/fleet-alerts")
serverURL, _ := url.Parse("https://fleet.example.com")

err := webhooks.SendFailingPoliciesBatchedPOSTs(
    ctx,
    policy,           // *fleet.Policy
    failingPoliciesSet, // fleet.FailingPolicySet
    100,              // hostBatchSize (0 = single batch)
    serverURL,
    webhookURL,
    time.Now(),
    logger,
)
if err != nil {
    log.Fatalf("webhook send failed: %v", err)
}
```

Setting `hostBatchSize` to `0` sends all failing hosts in a single request. Each successful batch POST removes those hosts from the `FailingPolicySet`, so partial progress is preserved if a later batch fails. Secret URL parameters are masked in logs and error messages via `server.MaskSecretURLParams`.
