Worker job implementation for verifying VPP (Volume Purchase Program) app installations on Apple devices via MDM commands.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `AppleSoftware` | struct | Worker implementing the `apple_software` job; holds a datastore, MDM commander, and logger |
| `AppleSoftware.Run` | method | Dispatches incoming job payloads to the appropriate task handler |
| `verifyVPPInstalls` | method | Sends an `InstalledApplicationList` MDM command and replaces verification UUIDs in the datastore for both VPP and in-house apps |
| `QueueVPPInstallVerificationJob` | func | Public entry point to enqueue a delayed VPP verification job |
| `appleSoftwareArgs` | struct | JSON-serialisable job payload carrying task name, host UUID, verification command UUID, and the managed-only flag |

## Usage Example

```go
// Queue a VPP verification job to run after a 30-second delay
err := worker.QueueVPPInstallVerificationJob(
    ctx,
    datastore,
    logger,
    30*time.Second,
    "device-uuid-abc123",          // host UUID
    "cmd-uuid-xyz789",             // verification command UUID from prior MDM command
    false,                         // false = restrict to managed apps only
)
if err != nil {
    log.Fatal(err)
}
```

When the job is picked up by the worker queue, `Run` unmarshals the payload, calls `verifyVPPInstalls`, which:

1. Generates a new command UUID via `fleet.VerifySoftwareInstallCommandUUID()`
2. Sends an `InstalledApplicationList` MDM command to the host
3. Replaces the old verification UUID with the new one in both the VPP and in-house app install records

## Notes

- The `DisableManagedOnlyApps` flag inverts the `managedAppsOnly` parameter sent to MDM; leaving it `false` (default) restricts the list command to managed apps.
- Only one task type (`verify_vpp_installs`) is currently defined; unknown tasks return a wrapped error.
