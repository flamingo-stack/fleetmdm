Manages background job processing for macOS DEP (Device Enrollment Program) Setup Assistant profile assignments, handling profile changes, deletions, team transfers, and cooldown retries within the Fleet MDM worker system.

## Key Components

### `MacosSetupAssistant` struct
The primary job processor registered under the `macos_setup_assistant` job name. Requires:
- `Datastore` — Fleet data access layer
- `Log` — structured logger
- `DEPService` — Apple MDM DEP service for profile management
- `DEPClient` — Apple Business Manager (ABM) API client

### `MacosSetupAssistantTask` (string type)
Enum-like constants identifying which subtask to execute:

| Task | Description |
|---|---|
| `MacosSetupAssistantProfileChanged` | Assign updated custom profile to team's DEP hosts |
| `MacosSetupAssistantProfileDeleted` | Reassign default profile when custom is removed |
| `MacosSetupAssistantTeamDeleted` | Move hosts to no-team profile on team deletion |
| `MacosSetupAssistantHostsTransferred` | Assign correct profile after host team transfer |
| `MacosSetupAssistantHostsCooldown` | Retry assignments previously skipped due to cooldown |
| `MacosSetupAssistantUpdateAllProfiles` | Queue per-team profile update jobs |
| `MacosSetupAssistantUpdateProfile` | Refresh a single team's default profile UUID |

### `Run(ctx, argsJSON)`
Entry point for the worker; dispatches to the appropriate handler based on `args.Task`. Returns `nil` immediately if `DEPService` is unset (MDM disabled).

## Usage Example

```go
// Queue a profile-changed job when a setup assistant profile is updated
_, err := QueueMacosSetupAssistantJob(
    ctx,
    datastore,
    logger,
    MacosSetupAssistantProfileChanged,
    &teamID,
)

// Register the processor with the worker
w.AddJob(macosSetupAssistantJobName, &MacosSetupAssistant{
    Datastore:  ds,
    Log:        logger,
    DEPService: depService,
    DEPClient:  depClient,
})
```

> **Cooldown handling:** Serial numbers on DEP assignment cooldown are skipped and re-queued via the `dep_cooldown` integrations cron job. The `MacosSetupAssistantHostsCooldown` task forces assignment regardless of cooldown status.
