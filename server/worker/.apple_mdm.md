Handles Apple MDM post-enrollment workflows, including DEP and manual enrollment task dispatch, profile installation, bootstrap package delivery, and device release coordination.

## Key Components

### Types & Constants

- `appleMDMJobName` — registered job name (`"apple_mdm"`)
- `AppleMDMTask` — string type for task identifiers
- `AppleMDMPostDEPEnrollmentTask` — post-DEP enrollment task
- `AppleMDMPostManualEnrollmentTask` — post-manual enrollment task
- `AppleMDMPostDEPReleaseDeviceTask` — post-DEP device release task (legacy for macOS; active for iOS/iPadOS)

### Structs

- **`AppleMDM`** — job processor with dependencies: `Datastore`, `Log`, `Commander`, `BootstrapPackageStore`, `VPPInstaller`, `NewActivityFn`
- **`appleMDMArgs`** — JSON-deserialized job payload carrying `Task`, `HostUUID`, `TeamID`, `EnrollReference`, `Platform`, release timing fields, and migration flags

### Methods

- **`Name()`** — returns `"apple_mdm"` for job registration
- **`Run(ctx, argsJSON)`** — entry point; validates MDM is configured, unmarshals args, dispatches to task handler
- **`runPostDEPEnrollment(ctx, args)`** — orchestrates fleetd install, bootstrap package, profile installation, SSO/managed-admin account configuration, and device release for DEP-enrolled hosts
- **`runPostManualEnrollment(ctx, args)`** — installs profiles and fleetd (macOS) or setup-experience VPP apps (iOS/iPadOS) for manually enrolled hosts

### Helpers

- `isMacOS(platform)` — returns `true` for `""` or `"darwin"` platform strings (backward-compatible)

## Usage Example

```go
// Enqueue a post-DEP enrollment job
payload, _ := json.Marshal(appleMDMArgs{
    Task:     AppleMDMPostDEPEnrollmentTask,
    HostUUID: "abc-123",
    TeamID:   ptr.Uint(7),
    Platform: "darwin",
})

err := worker.QueueAppleMDMJob(ctx, ds, logger, AppleMDMPostDEPEnrollmentTask, "abc-123", 7, ...)
```
