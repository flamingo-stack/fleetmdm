This file implements the `SoftwareWorker`, a background job worker that manages Android app availability and setup experience tasks via the Android Management API (AMAPI) for Fleet MDM.

## Key Components

### `SoftwareWorker` struct
The main worker struct holding dependencies: a `fleet.Datastore`, an `android.Service` module, a logger, and a configurable batch size for Android API calls.

### Task Constants
Defines the set of supported async job tasks:

| Task | Description |
|---|---|
| `makeAndroidAppAvailableTask` | Push a new/updated app to enrolled Android hosts |
| `makeAndroidAppUnavailableTask` | Remove an app from Android host policies |
| `runAndroidSetupExperienceTask` | Run setup experience flow on enrollment |
| `bulkSetAndroidAppsAvailableForHostTask` | Bulk-apply apps to a single host |
| `bulkSetAndroidAppsAvailableForHostsTask` | Bulk-apply apps across multiple hosts |

### `Run(ctx, argsJSON)`
Entry point for the job queue. Deserializes `softwareWorkerArgs` JSON and dispatches to the appropriate handler method.

### `makeAndroidAppAvailable`
Called when an app is added or updated. Fetches in-scope hosts, optionally applies per-host variable substitution for `$FLEET_VAR_HOST_*` tokens, then calls `AddAppsToAndroidPolicy` in batches with a stagger interval to avoid AMAPI rate limits.

### `makeAndroidAppAvailablePerHost`
Handles per-host config substitution when app configuration contains host-specific Fleet variables (e.g., device serial). Fetches host details, substitutes variables, and applies the policy individually per host.

### `makeAndroidAppUnavailable`
Removes an app from Android MDM policies for the specified host-to-policy mapping.

### `ensureHostSpecificPolicyIsApplied`
Ensures a host has its own named policy (not the shared default), configuring status reporting settings and sending the Fleet agent config.

## Usage Example

```go
worker := &SoftwareWorker{
    Datastore:        ds,
    AndroidModule:    androidSvc,
    Log:              logger,
    AndroidBatchSize: 100,
}

args, _ := json.Marshal(softwareWorkerArgs{
    Task:           makeAndroidAppAvailableTask,
    ApplicationID:  "com.example.app",
    AppTeamID:      42,
    EnterpriseName: "enterprises/xyz",
})

err := worker.Run(ctx, args)
```
