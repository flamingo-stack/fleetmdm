Handles asynchronous Zendesk ticket creation for Fleet's vulnerability and failing policy integrations, implementing a background worker job that generates templated tickets via the Zendesk API.

## Key Components

- **`Zendesk`** — Main job processor struct holding Fleet URL, datastore, logger, a client factory function, and a thread-safe cache of `ZendeskClient` instances keyed by integration type and team ID.
- **`ZendeskClient`** — Interface requiring `CreateZendeskTicket` and `ZendeskConfigMatches` methods, abstracting the Zendesk API client.
- **`zendeskArgs`** — Job payload struct supporting two integration types: `Vulnerability` and `FailingPolicy`.
- **`zendeskTemplates`** — Package-level Markdown-formatted Go templates for ticket summaries and descriptions (vuln and failing policy variants).
- **`getClient()`** — Retrieves or creates a cached `ZendeskClient` for the appropriate integration config (global or team-scoped), returning `nil` if no integration is enabled.
- **`Run()`** — Entry point for the worker job; dispatches to `runVuln` or `runFailingPolicy` based on args.
- **`runVuln()`** — Fetches affected hosts by CVE or software IDs, renders templates, and creates a Zendesk ticket.
- **`runFailingPolicy()`** — Renders failing policy templates and creates a Zendesk ticket.
- **`createTemplatedTicket()`** — Executes summary/description templates and calls the Zendesk API.
- **`QueueZendeskVulnJobs()`** — Groups recent vulnerabilities by CVE and enqueues worker jobs with enriched CVE metadata.

## Usage Example

```go
// Register the Zendesk worker
zendeskWorker := &worker.Zendesk{
    FleetURL:  "https://fleet.example.com",
    Datastore: ds,
    Log:       logger,
    NewClientFunc: func(opts *externalsvc.ZendeskOptions) (worker.ZendeskClient, error) {
        return externalsvc.NewZendeskClient(opts)
    },
}
workerPool.AddJob(zendeskWorker)

// Queue vulnerability jobs from the vulnerability processing pipeline
err := worker.QueueZendeskVulnJobs(ctx, ds, logger, recentVulns, cveMeta)
if err != nil {
    log.Fatal(err)
}
```
