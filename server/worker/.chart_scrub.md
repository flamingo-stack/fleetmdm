Defines two background worker jobs for scrubbing Chart dataset rows from `host_scd_data`: a global scrub that deletes all rows for a dataset, and a per-fleet scrub that clears bits only for hosts in specified fleets.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `ChartScrubDatasetGlobalJobName` | `const` | Stable job name `"chart_scrub_dataset_global"` persisted in the jobs table |
| `ChartScrubDatasetFleetJobName` | `const` | Stable job name `"chart_scrub_dataset_fleet"` persisted in the jobs table |
| `ChartScrubGlobalArgs` | `struct` | JSON payload for the global job; contains `Dataset` string |
| `ChartScrubFleetArgs` | `struct` | JSON payload for the fleet job; contains `Dataset` string and `FleetIDs []uint` |
| `ChartScrubGlobal` | `struct` | Worker that calls `ChartService.ScrubDatasetGlobal` to delete all `host_scd_data` rows for a dataset |
| `ChartScrubFleet` | `struct` | Worker that calls `ChartService.ScrubDatasetFleet` to clear bits for hosts in listed fleets |

Both workers implement the `Name() string` and `Run(ctx, json.RawMessage) error` interface expected by the job queue.

> ⚠️ The job name constants are persisted in the database — renaming them is a breaking change.

## Usage Example

```go
// Register workers with the job runner
globalScrub := &worker.ChartScrubGlobal{
    ChartService: chartSvc,
    Log:          logger,
}
fleetScrub := &worker.ChartScrubFleet{
    ChartService: chartSvc,
    Log:          logger,
}

jobRunner.Register(globalScrub)
jobRunner.Register(fleetScrub)

// Enqueue a global scrub job
globalArgs, _ := json.Marshal(worker.ChartScrubGlobalArgs{Dataset: "vulnerabilities"})
jobQueue.Enqueue(ctx, worker.ChartScrubDatasetGlobalJobName, globalArgs)

// Enqueue a per-fleet scrub job
fleetArgs, _ := json.Marshal(worker.ChartScrubFleetArgs{
    Dataset:  "vulnerabilities",
    FleetIDs: []uint{12, 34},
})
jobQueue.Enqueue(ctx, worker.ChartScrubDatasetFleetJobName, fleetArgs)
```
