Runtime dev-mode flag and environment-variable override registry for test isolation, allowing controlled activation of developer features and per-variable overrides without affecting production behavior.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `IsEnabled` | `var bool` | Process-level dev-mode flag; set once at startup via flags, treated as read-only afterward |
| `enabledViaOverride` | `var bool` | Internal flag set automatically when `SetOverride` is called; enables dev-mode within test contexts |
| `Env` | `func(name string) string` | Safe env-var accessor; returns `""` when dev-mode is inactive, checks overrides before `os.Getenv` |
| `SetOverride` | `func(name, value string, cleanup ...testingTB)` | Sets a named override and optionally registers automatic cleanup via `t.Cleanup` |
| `ClearOverride` | `func(name string)` | Removes a single named override |
| `ClearAllOverrides` | `func()` | Resets all overrides and disables `enabledViaOverride` |
| `testingTB` | `interface` | Local subset of `*testing.T`; keeps the `testing` package out of the production import graph |

## Usage Example

### Production startup

```go
// main.go — set once, never written again
dev_mode.IsEnabled = flagDevMode
```

### Reading a dev-mode variable

```go
dsn := dev_mode.Env("FLEET_DEV_DB_DSN")
if dsn == "" {
    dsn = productionDSN // dev-mode inactive; use production value
}
```

### Test isolation with automatic cleanup

```go
func TestFeatureFlag(t *testing.T) {
    // Override is registered and automatically cleared via t.Cleanup.
    dev_mode.SetOverride("FLEET_DEV_FEATURE_X", "true", t)

    got := dev_mode.Env("FLEET_DEV_FEATURE_X")
    assert.Equal(t, "true", got)
} // override cleared here
```

> **Note:** `SetOverride` calls `t.Setenv("FLEET_DEV_OVERRIDE_SET", "1")` to trigger any parallel-test safety checks in the test suite. All reads and writes to the override map are protected by `sync.RWMutex`.
