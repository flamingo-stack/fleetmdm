Sails.js custom generator that scaffolds a complete landing page under the `views/pages/imagine/` directory, creating a controller action, EJS view, LESS stylesheet, and page script in one command.

## Key Components

- **`before(scope, exits)`** — Validates and normalizes the CLI argument (path sanitization, kebab-case enforcement, prefix checks), then computes all output paths (`newActionRelPath`, `newViewRelPath`, `newStylesheetRelPath`, `newPageScriptRelPath`) and configures the upstream `sails-generate` action generator.
- **`after(scope, done)`** — Prints a post-generation summary listing all created files and step-by-step manual follow-up instructions (route registration, LESS import, server restart).
- **`targets`** — Defines two file generation targets:
  - `./:newActionRelPath` — Generates a Sails actions2 controller stub with testimonials logic.
  - `./:newViewRelPath` — Generates an EJS/Vue template with lorem ipsum hero, feature sections, and placeholder images.

## Usage Example

```bash
# From the root of your Sails project
sails generate landing-page osquery-management
```

This produces:

```text
api/controllers/imagine/view-osquery-management.js
views/pages/imagine/osquery-management.ejs
assets/styles/pages/imagine/osquery-management.less
assets/js/pages/imagine/osquery-management.page.js
```

After generation, follow the three manual steps logged to the console:

1. Add the route to `website/config/routes.js` under the "Imagine" section
2. Import the new stylesheet in `assets/styles/importer.less`
3. Re-lift the server to pick up the new controller
