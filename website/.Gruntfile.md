Grunt build system entry point for the Sails.js application. Loads and registers all Grunt task configurations and registrations from the `tasks/` directory when `grunt` is run or when `sails lift` is executed.

## Key Components

- **`loadGruntTasks`** — Imported from `sails-hook-grunt`, scans `tasks/config/` and `tasks/register/` to auto-load all task definitions and registrations into Grunt.

## Usage Example

```bash
# Run Grunt directly
grunt

# Or implicitly via Sails (grunt hook must be enabled)
sails lift
```

```javascript
// This file is auto-invoked by the Grunt CLI or Sails hook.
// Customize build behavior by editing files in tasks/:
//   tasks/config/   — individual task configurations (e.g., less, uglify)
//   tasks/register/ — task pipelines (e.g., default, build, compileAssets)
```

> **Note:** This file should not be edited directly. Modify `tasks/config/` or `tasks/register/` to customize the build pipeline. See the [Sails.js Gruntfile docs](https://sailsjs.com/anatomy/Gruntfile.js) for more detail.
