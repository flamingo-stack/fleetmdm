A bundled, minified WebSocket client library combining **socket.io-client v2.0.3** with the **sails.io.js** wrapper, enabling real-time bidirectional communication between browsers and Sails.js servers.

## Key Components

| Component | Description |
|---|---|
| `io(url, opts)` | Main factory function — creates or reuses a socket connection |
| `io.managers` | Cache of active `Manager` instances, keyed by server URL |
| `io.Manager` | Manages the underlying WebSocket transport and reconnection logic |
| `io.Socket` | Namespace-level socket with `emit`/`on` event API |
| `io.protocol` | Socket.IO protocol version (v4) |
| URL parser | Normalizes URLs, infers protocol/port, generates stable connection IDs |
| Packet encoder/decoder | Handles `CONNECT`, `DISCONNECT`, `EVENT`, `ACK`, `ERROR`, `BINARY_EVENT`, `BINARY_ACK` packet types |

## Usage Example

```javascript
// Connect to the Sails.js server
var socket = io('https://your-sails-server.com');

// Listen for events from the server
socket.on('connect', function() {
  console.log('Connected with socket ID:', socket.id);
});

// Subscribe to a custom event
socket.on('message', function(data) {
  console.log('Received:', data);
});

// Emit an event to the server
socket.emit('chatMessage', { text: 'Hello from client!' });

// Force a new connection (bypass cache / multiplex)
var freshSocket = io('https://your-sails-server.com', {
  forceNew: true
});

// Connect to a specific namespace
var adminSocket = io('https://your-sails-server.com/admin');
```

## Notes

- **AMD / RequireJS users**: Replace this file with the standalone build from [balderdashy/sails.io.js](https://github.com/balderdashy/sails.io.js) and load socket.io-client separately.
- Connections are **multiplexed by default** — multiple calls to `io()` with the same host reuse the same underlying `Manager`.
- Set `multiplex: false` or `forceNew: true` in options to force a dedicated connection.
- Source: [`sails.io.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/assets/js/sails.io.js)
