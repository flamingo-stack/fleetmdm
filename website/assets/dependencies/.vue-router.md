Vue Router v2.7.0 bundled library that provides client-side routing for Vue.js applications, supporting hash-based and HTML5 history navigation with named routes, nested views, and navigation guards.

## Key Components

| Export / Symbol | Type | Description |
|---|---|---|
| `VueRouter` | Class | Main router instance installed as a Vue plugin |
| `router-view` | Component | Functional component that renders the matched route component |
| `router-link` | Component | Navigation component that renders as `<a>` tags with active-class support |
| `createRoute` | Function | Builds an immutable frozen route object from a record and location |
| `resolveQuery` | Function | Parses and merges URL query strings |
| `stringifyQuery` | Function | Serializes a query object back to a URL string |
| `isSameRoute` | Function | Deep-compares two route objects for equality |
| `isIncludedRoute` | Function | Checks if one route is a subset of another (used for active-class logic) |
| `guardEvent` | Function | Filters click events to prevent navigation on modified/right clicks |

## Usage Example

```javascript
import Vue from 'vue'
import VueRouter from './vue-router.js'

Vue.use(VueRouter)

const router = new VueRouter({
  mode: 'history',
  routes: [
    {
      path: '/dashboard',
      name: 'dashboard',
      component: Dashboard,
      props: true          // passes route.params as component props
    },
    {
      path: '/user/:id',
      component: UserProfile,
      props: route => ({ userId: route.params.id })
    }
  ],
  linkActiveClass: 'is-active',
  linkExactActiveClass: 'is-exact-active'
})

new Vue({ router }).$mount('#app')
```

```vue
<template>
  <nav>
    <router-link to="/dashboard" exact>Dashboard</router-link>
    <router-link :to="{ name: 'dashboard' }" tag="button">Go</router-link>
  </nav>
  <router-view name="default" />
</template>
```

> **Note:** This is the vendored UMD build of vue-router@2.7.0. For active projects, prefer installing via npm: `npm install vue-router@2` and importing from `node_modules`.
