A patched fork of Lodash 3.10.1 (versioned as 3.10.2) maintained by the Sailsh team (`@sailshq/lodash`), with a hotfix applied for [lodash issue #2768](https://github.com/lodash/lodash/issues/2768) to correctly identify async functions, generator functions, and proxies.

## Key Components

| Component | Description |
|---|---|
| **Version constants** | `VERSION = '3.10.2'`, wrapper bitmask flags (`BIND_FLAG`, `CURRY_FLAG`, etc.) |
| **Type tags** | `Object#toString` result strings for all built-in types including patched `asyncTag`, `genTag`, `proxyTag` |
| **`cloneableTags`** | Lookup map controlling which types `_.clone` supports |
| **`typedArrayTags`** | Lookup map for typed array detection |
| **`deburredLetters`** | Latin-1 supplementary → ASCII character map used by `_.deburr` |
| **`htmlEscapes`/`htmlUnescapes`** | HTML entity encode/decode maps used by `_.escape`/`_.unescape` |
| **Regex constants** | Pre-compiled patterns for template delimiters, property paths, word splitting, and unicode handling |
| **Environment detection** | CommonJS (`freeExports`, `freeModule`), browser (`freeWindow`), Node.js (`freeGlobal`) globals |

## Usage Example

```javascript
var _ = require('@sailshq/lodash');

// Deep clone an object
var original = { user: 'Alice', scores: [1, 2, 3] };
var copy = _.cloneDeep(original);

// Utility functions
_.isFunction(async function() {}); // true (patched async support)
_.deburr('Ångström');              // 'Angstrom'
_.escape('<script>');              // '&lt;script&gt;'
_.trunc('Hello, World!', 8);      // 'Hello...'

// Functional helpers
var doubled = _.map([1, 2, 3], function(n) { return n * 2; });
```

## Notes

- **Patch:** Adds `asyncTag`, `genTag`, and `proxyTag` recognition so `_.isFunction` correctly handles async/generator functions and proxies in modern runtimes.
- **Source:** [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — vendored from `@sailshq/lodash` (MIT license).
- Prefer the upstream [`lodash` v4+](https://lodash.com) for new projects; this fork is maintained for Sails.js compatibility.
