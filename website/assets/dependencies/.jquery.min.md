Minified distribution of jQuery v3.2.1, the widely-used JavaScript DOM manipulation and utility library. This file provides the complete jQuery API for browser environments and CommonJS/Node.js module systems.

## Key Components

| Export | Description |
|---|---|
| `$` / `jQuery` | Core selector function returning jQuery object instances |
| `$.fn` | jQuery prototype — chainable DOM methods (`each`, `map`, `eq`, `first`, `last`, `slice`) |
| `$.extend` | Deep/shallow object merging utility |
| `Sizzle` | Embedded CSS selector engine with cross-browser normalization |
| Utility methods | `$.type`, `$.isFunction`, `$.isPlainObject`, `$.camelCase`, `$.globalEval`, `$.grep`, `$.map`, `$.proxy`, `$.merge` |

## Usage Example

```javascript
// Browser (script tag)
// <script src="jquery.min.js"></script>

// CommonJS / Node.js (requires jsdom window)
const { JSDOM } = require('jsdom');
const { window } = new JSDOM('<!DOCTYPE html>');
const $ = require('./jquery.min.js')(window);

// DOM selection and manipulation
$('#my-element').addClass('active').text('Hello');

// Iteration
$.each(['a', 'b', 'c'], function(index, value) {
  console.log(index, value);
});

// Object extension
const merged = $.extend({}, { a: 1 }, { b: 2 }); // { a: 1, b: 2 }

// Type checking
$.isPlainObject({});    // true
$.isFunction(() => {}); // true
```
