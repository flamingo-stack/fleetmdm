Web Worker bootstrap file for the Ace editor's XML language worker. It sets up a CommonJS-compatible module system (`require`/`define`/`exports`) inside a Web Worker context, where the standard browser globals are unavailable, and includes foundational Ace utility modules.

## Key Components

| Export / Function | Description |
|---|---|
| `window.require(parentId, id)` | AMD/CommonJS-style module loader; resolves relative paths, caches initialized modules, and falls back to `importScripts()` for unknown modules |
| `window.define(id, deps, factory)` | AMD `define` implementation with CommonJS compatibility shim (`require`, `exports`, `module` injected automatically) |
| `window.normalizeModule(parentId, moduleName)` | Resolves relative (`./`, `../`) and plugin (`!`) module paths |
| `window.initBaseUrls(topLevelNamespaces)` | Seeds the top-level namespace map used to resolve module IDs to script paths |
| `window.initSender()` | Creates an event `Sender` instance that bridges worker↔main thread via `postMessage` |
| `window.onmessage` | Message dispatcher: handles `init` (bootstraps the worker class), `command` (calls methods on the main worker object), and `event` (forwards to `Sender`) |
| `ace/lib/oop` | OOP helpers: `inherits`, `mixin`, `implement` |
| `ace/lib/deep_copy` | Recursive deep-copy utility |
| `ace/lib/lang` | String/array utilities: `escapeHTML`, `escapeRegExp`, `deferredCall`, `delayedCall`, etc. |
| `ace/apply_delta` | Document delta validation and application logic |

## Usage Example

This file is loaded automatically by the Ace editor when it spawns an XML syntax/validation worker. You do not import it directly — Ace references it via worker path configuration:

```javascript
ace.config.setModuleUrl(
  "ace/mode/xml_worker",
  "/path/to/worker-xml.js"
);

const editor = ace.edit("editor");
editor.session.setMode("ace/mode/xml");
// Ace internally posts an `init` message to the worker:
// { init: true, module: "ace/mode/xml_worker",
//   classname: "Worker", tlns: { ... } }
```

Inside the worker, commands are dispatched like:

```javascript
// Main thread → worker
worker.postMessage({ command: "setValue", args: ["<root/>"] });

// Worker → main thread (via Sender)
sender.emit("annotate", [{ row: 0, column: 0, text: "Error", type: "error" }]);
```

> **Note:** This file uses `importScripts()` for dynamic module loading and must be served as a dedicated Web Worker script, not bundled as a standard ES module.
