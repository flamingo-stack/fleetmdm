Ace editor module providing XML syntax highlighting rules and editor behaviors for the `mode-xml` language mode.

## Key Components

### `XmlHighlightRules`
Tokenizer rule set extending `TextHighlightRules` that defines syntax highlighting for XML documents. Covers the following token states:

| State | Purpose |
|---|---|
| `start` | Entry point; dispatches to sub-states |
| `processing_instruction` | `<?...?>` declarations |
| `doctype` | `<!DOCTYPE ...>` blocks |
| `int_subset` | Internal DTD subset `[...]` |
| `cdata` | `<![CDATA[...]]>` sections |
| `comment` | `<!-- ... -->` blocks |
| `reference` / `attr_reference` | Entity references (`&amp;`, `&#x...;`) |
| `tag` / `attributes` / `attribute_value` | Element tags and their attributes |

**`embedTagRules(HighlightRules, prefix, tag)`** — Mixes in a foreign highlight ruleset (e.g., CSS, JavaScript) for a specific embedded tag (e.g., `<style>`, `<script>`), wiring open/close tag transitions correctly.

### `XmlBehaviour`
Editor behavior handlers extending `Behaviour`:

- **`string_dquotes` insertion** — Auto-pairs `"` and `'` when the cursor is positioned after an attribute-equals token; skips closing if already present.
- **`string_dquotes` deletion** — Removes the matching closing quote when the opening quote is deleted.
- **`autoclosing` insertion** — Automatically inserts a closing tag (`</tagName>`) when `>` is typed to close an opening tag, skipping void/self-closing elements.

## Usage Example

```javascript
// Used internally by Ace's XML mode
var XmlHighlightRules = require("ace/mode/xml_highlight_rules").XmlHighlightRules;

// Extend for a custom XML dialect
var MyRules = function () {
    XmlHighlightRules.call(this);
    // Add custom token rules...
    this.normalizeRules();
};
oop.inherits(MyRules, XmlHighlightRules);

// Embed another language ruleset (e.g., for <script> tags)
xmlRules.embedTagRules(JavaScriptHighlightRules, "js-", "script");
```
