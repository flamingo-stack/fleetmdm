Minified build of **Highlight.js v10.7.3** — a client-side syntax highlighting library that parses and renders code blocks with language-specific token classification and HTML span wrapping.

## Key Components

| Export / Symbol | Description |
|---|---|
| `hljs` | Global namespace object exposing all public API methods |
| `l` (HTMLRenderer) | Walks a token tree and emits `<span class="...">` HTML |
| `o` / `c` (TokenTree) | Builds and traverses a tree of highlighted tokens |
| `T` (compileLanguage) | Compiles a language grammar definition into an executable matcher |
| `P` (VuePlugin) | Vue 2 component + plugin (`<highlightjs>`) for framework integration |
| `D` (mergeHTMLPlugin) | `after:highlightElement` hook that merges existing DOM markup into highlighted output |
| `_` (MODES) | Frozen object of reusable grammar primitives (strings, numbers, comments, regexes, etc.) |
| `j` (compileKeywords) | Converts keyword definitions into scored lookup maps |
| `hljs.highlight` | Highlight a code string given an explicit language |
| `hljs.highlightAuto` | Auto-detect language and highlight |
| `hljs.highlightElement` | Highlight a DOM element in place |
| `hljs.registerLanguage` | Register a language grammar module |

## Usage Example

**Vanilla JS:**

```javascript
// Highlight a specific language
const result = hljs.highlight('javascript', 'const x = 42;');
document.querySelector('pre > code').innerHTML = result.value;

// Auto-detect and highlight all code blocks on page load
document.addEventListener('DOMContentLoaded', () => {
  hljs.highlightAll();
});
```

**Vue 2 Plugin:**

```javascript
import Vue from 'vue';
const { VuePlugin } = hljs.initHighlightingOnLoad();
Vue.use(VuePlugin);
// Then in templates: <highlightjs language="python" :code="snippet" />
```

**Registering a language grammar:**

```javascript
hljs.registerLanguage('mylang', (hljs) => ({
  name: 'MyLang',
  keywords: 'if else for while return',
  contains: [hljs.C_LINE_COMMENT_MODE, hljs.QUOTE_STRING_MODE]
}));
```
