Minified bundle of **DocSearch** v3.6.1 by Algolia — a drop-in JavaScript widget that adds AI-powered documentation search to any web page by connecting to an Algolia index.

## Key Components

| Export / Symbol | Description |
|---|---|
| `docsearch` | Primary UMD export; initializes and mounts the search widget |
| Preact runtime (`g`, `S`, `B`, `q`, `D`) | Embedded Preact v10 virtual DOM used to render the search UI |
| `w` (`Component`) | Base Preact component class with `setState` / `forceUpdate` |
| `B` / `V` (`render`) | Mounts/patches the Preact VDOM tree into a real DOM container |
| `N` / `x` | DOM property/attribute diffing and CSS style patching |
| `T` / `R` | Synthetic event delegation handlers |
| `U` | Component unmount and ref cleanup |

## Usage Example

```javascript
// CDN usage (UMD bundle)
// <script src="docsearch.min.js"></script>

docsearch({
  appId: 'YOUR_APP_ID',
  apiKey: 'YOUR_SEARCH_API_KEY',
  indexName: 'YOUR_INDEX_NAME',
  container: '#docsearch',          // CSS selector or DOM element
  debug: false,                     // keep modal open for styling
});
```

```bash
# Or install via npm
npm install @docsearch/js
```

```javascript
// ES module usage
import docsearch from '@docsearch/js';

docsearch({
  appId: 'YOUR_APP_ID',
  apiKey: 'YOUR_SEARCH_API_KEY',
  indexName: 'YOUR_INDEX_NAME',
  container: '#docsearch',
});
```
