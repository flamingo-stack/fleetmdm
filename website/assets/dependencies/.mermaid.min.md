Minified bundle of the [Mermaid](https://mermaid.js.org/) diagram-as-code library, providing a parser, lexer, and renderer for generating diagrams from text definitions in JavaScript environments.

## Key Components

- **Parser (`R`)** — LALR(1) parser with a full grammar table for class diagram syntax, handling `CLASS_DIAGRAM` directives, relation statements, annotations, CSS class assignments, and click events
- **Lexer (`F`)** — Tokenizer that processes diagram source text into tokens (`MEMBER`, `RELATION`, `ANNOTATION_START`, etc.) with support for lexer states (`INITIAL`, `STRUCT`)
- **`performAction`** — Semantic action handler that builds the diagram AST by calling methods like `addClass`, `addRelation`, `addMembers`, `setClickEvent`, and `setLink`
- **Directive support** — Handles `%%{ ... }%%` front-matter directives for configuring diagram-level settings

## Usage Example

```javascript
// Mermaid exposes itself as a UMD module
import mermaid from './mermaid.min.js';

// Initialize with configuration
mermaid.initialize({
  startOnLoad: true,
  theme: 'default',
  securityLevel: 'loose',
});

// Render a class diagram programmatically
const { svg } = await mermaid.render('diagram-id', `
  classDiagram
    Animal <|-- Duck
    Animal <|-- Fish
    Animal : +int age
    Animal : +String gender
    Animal: +isMammal()
    Duck: +String beakColor
    Duck: +quack()
`);

document.getElementById('output').innerHTML = svg;
```
