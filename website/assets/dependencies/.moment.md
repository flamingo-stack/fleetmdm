Moment.js (v2.20.1) is a comprehensive JavaScript date/time parsing, manipulation, validation, and formatting library that works in both browser and Node.js environments via UMD module definition.

## Key Components

| Component | Description |
|---|---|
| `Moment` | Core prototype class representing a wrapped date instance |
| `Locale` | Locale configuration class for internationalization support |
| `hooks` | Main entry point (the `moment()` function) with plugin support |
| `createUTC` | Creates a UTC-based moment instance |
| `isValid` | Validates a moment object against parsing flags |
| `createInvalid` | Creates an explicitly invalid moment instance |
| `deprecate` / `deprecateSimple` | Deprecation warning utilities with handler support |
| `copyConfig` | Deep-clones moment configuration between instances |
| `mergeConfigs` | Merges parent/child locale configs without mutation |
| `defaultCalendar` | Default calendar format strings (Today, Tomorrow, etc.) |
| `defaultLongDateFormat` | Named date format tokens (`LT`, `LL`, `LLLL`, etc.) |

## Usage Example

```javascript
// CommonJS
const moment = require('moment');

// Parse and format
const now = moment();
console.log(now.format('MMMM D, YYYY h:mm A')); // "January 1, 2024 9:30 AM"

// UTC creation
const utc = moment.utc('2024-01-01T12:00:00Z');
console.log(utc.isValid()); // true

// Validation
const invalid = moment('not-a-date', 'YYYY-MM-DD', true); // strict mode
console.log(invalid.isValid()); // false

// Relative calendar display
const yesterday = moment().subtract(1, 'days');
console.log(yesterday.calendar()); // "Yesterday at 9:30 AM"

// Plugin / locale extension
moment.updateLocale('en', {
  calendar: {
    sameDay: '[Today at] LT',
    lastDay: '[Yesterday at] LT',
  }
});
```

## Notes

- Suppress deprecation warnings via `moment.suppressDeprecationWarnings = true`
- Custom deprecation handling: `moment.deprecationHandler = (name, msg) => {}`
- Plugins can register additional moment properties via `moment.momentProperties`
