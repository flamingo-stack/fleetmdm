A lightweight UMD wrapper (v0.9.3) around Vue.js and Lodash that provides opinionated structure for multi-page applications, with optional integration from jQuery, VueRouter, and bowser.

## Key Components

| Export / Function | Description |
|---|---|
| `parasails` | Main module export; manages global component/page registry via `_cache` |
| `_ensureGlobalCache()` | Initializes the internal module registry |
| `_exportOnGlobalCache(name, def)` | Registers a named module definition, throwing on duplicate names |
| `_exposeBonusMethods(def, noun)` | Injects `forceRender`, `$get`, `$find`, and `$focus` helper methods into a component/page definition |
| `_wrapMethodsAndVerifyNoArrowFunctions(def, noun)` | Validates top-level definition keys against an allowlist and suggests corrections for common typos (e.g. `beforeMounted` → `beforeMount`) |

## Usage Example

```javascript
// Register a page script (typical Sails.js / parasails setup)
parasails.registerPage('home', {
  data: function () {
    return {
      greeting: 'Hello, world!'
    };
  },
  mounted: async function () {
    // Access jQuery-powered helpers (requires $ on page)
    this.$focus('[name="emailAddress"]');
  },
  methods: {
    clickButton: async function () {
      var response = await Cloud.sendMessage.with({ text: this.greeting });
      console.log(response);
    }
  }
});

// Register a reusable component
parasails.registerComponent('my-widget', {
  props: ['label'],
  template: '<button>{{ label }}</button>',
  methods: {
    highlight: function () {
      this.$get().addClass('active');
    }
  }
});
```

## Notes

- **jQuery optional**: `$get`, `$find`, and `$focus` are no-ops (throw descriptive errors) when jQuery is absent at registration time.
- **Key validation**: Misspelled lifecycle hooks (e.g. `beforeDestroyed`, `state`, `functions`) produce actionable error messages rather than silently failing.
- **UMD build**: Works with CommonJS, AMD, and browser globals — no bundler required.
