Minified build of Chart.js v2.9.4, a flexible JavaScript charting library for rendering interactive charts on HTML5 Canvas elements. This file includes bundled color conversion utilities and optional Moment.js integration for time-based axes.

## Key Components

| Component | Description |
|---|---|
| `Chart` | Main constructor — creates and manages chart instances |
| Color conversion module | Supports RGB, HSL, HSV, HWB, CMYK, HEX, LAB, LCH, and CSS keyword color spaces |
| Chart types | `bar`, `line`, `pie`, `doughnut`, `radar`, `polarArea`, `bubble`, `scatter` |
| Scales | Linear, logarithmic, category, time (requires Moment.js) |
| Plugins API | Lifecycle hooks for custom rendering and behavior |
| Tooltip & Legend | Built-in interactive UI components |

## Usage Example

```javascript
// Basic bar chart
const ctx = document.getElementById('myChart').getContext('2d');

const myChart = new Chart(ctx, {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 'Apr'],
    datasets: [{
      label: 'Monthly Revenue',
      data: [1200, 1900, 3000, 2500],
      backgroundColor: 'rgba(54, 162, 235, 0.5)',
      borderColor: 'rgba(54, 162, 235, 1)',
      borderWidth: 1
    }]
  },
  options: {
    responsive: true,
    scales: {
      yAxes: [{ ticks: { beginAtZero: true } }]
    }
  }
});

// Update data dynamically
myChart.data.datasets[0].data = [1500, 2200, 2800, 3100];
myChart.update();

// Destroy instance when done
myChart.destroy();
```

## Notes

- **Version:** 2.9.4 (released 2020) — consider upgrading to Chart.js v4.x for new projects
- **Moment.js:** Optional peer dependency; required only for `time` scale type
- **Module formats:** Supports CommonJS (`require`), AMD (`define`), and global (`window.Chart`)
- **Source & docs:** [chartjs.org](https://www.chartjs.org) | [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm/blob/main/chart.min.js)
