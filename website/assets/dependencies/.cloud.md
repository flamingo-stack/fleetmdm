A high-level AJAX library (part of `parasails`) that provides a declarative, promise-based SDK for making HTTP and WebSocket requests to Sails.js backend endpoints. Supports serial/named argument styles, error negotiation, custom headers, CSRF protection, and file uploads.

## Key Components

- **`Cloud.setup(options)`** — Initializes the SDK with endpoint definitions, API base URL, and default options. Must be called before any endpoint methods are used.
- **`Cloud.<methodName>()`** — Auto-generated methods for each declared endpoint, supporting both serial args and `.with({...})` named-argument style.
- **`.exec(callback)`** — Executes the request with a Node.js-style callback.
- **`.switch({...})`** — Negotiates errors by exit name or HTTP status code.
- **`.protocol(name|instance)`** — Selects transport (`'jQuery'`, `'io.socket'`, or an actual instance).
- **`.headers({...})`** — Attaches custom HTTP headers to the request.
- **`_representsOneOrMoreFiles(that)`** *(private)* — Detects `File`, `FileList`, or wrapped file arrays for multipart handling.
- **`_verifyErrorNegotiationRule(rule)`** *(private)* — Validates `.intercept()`/`.tolerate()` negotiation rules.

## Usage Example

```javascript
// Step 1: Initialize once on page load
Cloud.setup({
  apiBaseUrl: 'https://example.com',
  methods: {
    doSomething: 'PUT /api/v1/projects/:id',
    signup:      'POST /api/v1/users/signup'
  }
});

// Step 2: Call endpoint methods
var result = await Cloud.doSomething(8);

// With named arguments
var result = await Cloud.doSomething.with({ id: 8, foo: ['bar', 'baz'] });

// Negotiate errors by exit name or status code
Cloud.signup.with({ email: 'user@example.com', password: 'secret' })
.switch({
  error:                        (err) => console.error(err),
  emailAddressAlreadyInUse:     ()    => alert('Email taken'),
  success:                      ()    => window.location = '/dashboard'
});

// Use WebSockets
Cloud.doSomething.with({ id: 8 })
.protocol('io.socket')
.exec((err, result) => { if (err) { return; } console.log(result); });

// Custom headers
Cloud.doSomething.with({ id: 8 })
.headers({ 'X-Auth': 'token123' })
.exec((err, result) => { /* ... */ });
```
