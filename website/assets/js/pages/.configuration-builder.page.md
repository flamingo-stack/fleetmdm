Parasails page component for a multi-step MDM configuration profile builder that guides users through platform selection, payload configuration, and profile download.

## Key Components

### Data Properties

| Property | Description |
|---|---|
| `selectedPlatform` | Currently selected platform (`windows`, `android`, etc.) |
| `step` | Current wizard step (`platform-select` or `configuration-builder`) |
| `selectedPayloads` | Array of user-selected MDM payloads |
| `autoSelectedPayloads` | Payloads automatically added as dependencies |
| `selectedPayloadSettings` | Form data keyed by payload slug |
| `configurationBuilderFormData` | Aggregated form values for profile generation |
| `downloadProfileFormData` | Profile name/description for the download modal |

### Payload Schema

Each payload entry follows this structure:

```javascript
{
  name: 'Require device password',
  uniqueSlug: 'macos-enable-force-pin',
  tooltip: 'Require a password to unlock the device',
  category: 'Device lock',
  payload: 'Passcode',
  payloadType: 'com.apple.mobiledevice.passwordpolicy',
  formInput: {
    type: 'boolean', // or 'number' with minValue/maxValue/unitLabel
  },
  formOutput: {
    settingFormat: 'boolean', // or 'integer'
    settingKey: 'forcePIN',
  },
}
```

## Usage Example

```javascript
// Accessing selected payloads grouped by category
this.selectedPayloadsGroupedByCategory['Device lock']
// => [{ name: 'Require device password', uniqueSlug: '...', ... }]

// Checking current wizard step
if (this.step === 'platform-select') {
  // Show platform picker UI
}

// Triggering download modal
this.modal = 'download-profile';
```

## Notes

- macOS and iOS payload definitions are currently **commented out** in favor of Windows and Android support
- The page uses `parasails` (Sails.js + Vue.js integration)
- Form validation is handled via `platformSelectFormRules` and `downloadProfileFormRules`
- Source: [`configuration-builder.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/configuration-builder.page.js)
