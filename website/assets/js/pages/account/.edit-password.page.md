Parasails page component for the **edit password** form, handling client-side validation, form submission, and post-success navigation for password changes.

## Key Components

| Member | Type | Description |
|---|---|---|
| `syncing` | `data` | Loading/submitting state flag |
| `formData` | `data` | Holds `password` and `confirmPassword` field values |
| `formErrors` | `data` | Tracks client-side validation errors per field |
| `formRules` | `data` | Validation rules: `password` required; `confirmPassword` required and must match `password` |
| `cloudError` | `data` | Stores server-side error messages |
| `submittedForm` | `method` | Handles successful form submission; redirects to `/account` |

## Usage Example

```javascript
// Registered automatically by parasails on the 'edit-password' page.
// The form template binds to formData and formRules:

// formRules enforce:
// - password: must be present
// - confirmPassword: must be present AND equal to password
formRules: {
  password: { required: true },
  confirmPassword: { required: true, sameAs: 'password' },
}

// On successful submission, syncing stays true during navigation:
submittedForm: async function() {
  this.syncing = true;
  this.goto('/account'); // Redirects user to account page
}
```

## Notes

- `syncing` is intentionally left `true` after submission to keep the loading spinner visible during page navigation, preventing double-submits.
- Server errors are surfaced via `cloudError` for display in the template.
