Registers the `okta-conditional-access-error` parasails page component, which handles rendering the error state when Okta conditional access checks fail during authentication.

## Key Components

| Member | Type | Description |
|---|---|---|
| `data` | Object | Reactive state for the error page |
| `beforeMount` | Lifecycle hook | Pre-mount initialization logic |
| `mounted` | Lifecycle hook (async) | Post-mount setup, supports async operations |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Registered automatically by parasails; rendered when Okta conditional
// access denies a user session. Typically reached via a server-side redirect.
parasails.registerPage('okta-conditional-access-error', {
  data: {
    errorMessage: ''
  },
  mounted: async function () {
    // e.g. parse query params to display a specific denial reason
    this.errorMessage = new URLSearchParams(window.location.search).get('reason');
  },
  methods: {
    // e.g. redirect user back to login
    handleRetry() {
      window.location.href = '/login';
    }
  }
});
```

## Notes

- Part of the Okta SSO integration in [Fleet MDM](https://github.com/flamingo-stack/fleetmdm).
- The page is a stub — `data`, `beforeMount`, `mounted`, and `methods` are empty placeholders awaiting implementation.
- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout the Fleet frontend.
