Registers the `windows-mdm` parasails page component, providing the lifecycle hooks and interaction logic for the Windows MDM (Mobile Device Management) enrollment and configuration UI.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the Windows MDM page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook | Async setup logic executed after the component mounts |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Registered automatically by parasails; referenced via the page name
parasails.registerPage('windows-mdm', {
  data: {
    // e.g. enrollmentUrl: '', mdmStatus: null
  },
  beforeMount: function () {
    // pre-mount setup, e.g. read server-provided bootstrap data
  },
  mounted: async function () {
    // async init, e.g. fetch MDM enrollment status
  },
  methods: {
    // e.g. handleEnroll(), copyEnrollmentLink()
  }
});
```

## Notes

- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout this codebase.
- The page name `windows-mdm` must match the corresponding server-rendered view that invokes this page script.
- See the full implementation in [`windows-mdm.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/assets/js/pages/windows-mdm.page.js).
