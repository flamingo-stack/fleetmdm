Parasails page component for the "Replace Jamf" marketing/landing page, managing modal state for embedded video overlays.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `modal` | `data` | Tracks the currently open modal by name; empty string when none is open |
| `clickOpenVideoModal` | `method` | Opens a named modal by setting `this.modal` to the provided `modalName` |
| `closeModal` | `method` | Dismisses the active modal by setting `this.modal` to `undefined` |

## Usage Example

```javascript
// Open a specific video modal from a template button
this.clickOpenVideoModal('demo-video');

// Close the currently open modal
this.closeModal();
```

In the page template, conditionally render a modal based on the `modal` data property:

```vue
<div v-if="modal === 'demo-video'" class="modal-overlay">
  <!-- Video embed content -->
  <button @click="closeModal()">Close</button>
</div>
```
