Registers the `apple-mdm` parasails page, managing modal state for the Apple MDM configuration UI.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `modal` | `data` | Tracks the currently open modal by name; empty string by default |
| `clickOpenVideoModal` | `method` | Opens a modal by setting `modal` to the provided `modalName` |
| `closeModal` | `method` | Dismisses the active modal by setting `modal` to `undefined` |

## Usage Example

```javascript
// Open a specific modal (e.g. triggered by a UI button)
this.clickOpenVideoModal('demo-video');

// Close the currently active modal
this.closeModal();
```

## Notes

- `beforeMount` and `mounted` lifecycle hooks are defined but currently empty — reserved for future initialization logic.
- Modal visibility in the template is driven by comparing `this.modal` to a named value (e.g. `v-if="modal === 'demo-video'"`).
