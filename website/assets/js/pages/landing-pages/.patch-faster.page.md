Registers the `patch-faster` parasails page, which handles the "Patch Faster" demo request form, including validation, analytics tracking, and form submission.

## Key Components

**Data Properties**
- `syncing` — Boolean flag indicating an in-flight form submission
- `formData` / `formErrors` — Form field values and validation error state
- `cloudError` / `cloudSuccess` — Server response state
- `demoFormRules` — Validation rules requiring `emailAddress` (email format), `firstName`, `lastName`, `organization`, and `numberOfHosts`

**Methods**
- `handleSubmittingDemoForm(argins)` — Async handler that submits the demo form, fires LinkedIn and Google Ads conversion events, triggers Qualified CRM enrichment, and redirects to a calendar/event URL on success

## Usage Example

```javascript
// Form submission triggers handleSubmittingDemoForm with collected field values
await this.handleSubmittingDemoForm({
  emailAddress: 'jane@acme.com',
  firstName: 'Jane',
  lastName: 'Doe',
  organization: 'Acme Corp',
  numberOfHosts: 500,
  // primaryBuyingSituation injected automatically as 'it-misc'
});
// On success: redirects to report.eventUrl (e.g., a calendar booking page)
```
