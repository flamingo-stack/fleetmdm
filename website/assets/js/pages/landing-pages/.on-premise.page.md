A minimal Parasails page component registration for the `on-premise-page` route, defining the standard Vue-based lifecycle hooks and data structure.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive page-level state |
| `beforeMount` | Lifecycle Hook | Synchronous setup logic before DOM mount |
| `mounted` | Lifecycle Hook | Async initialization after DOM mount |
| `methods` | Object | Page-specific event handlers and utility functions |

## Usage Example

```javascript
// Extending this page registration pattern:
parasails.registerPage('on-premise-page', {
  data: {
    contactFormVisible: false,
    selectedPlan: null,
  },
  beforeMount: function () {
    // Runs synchronously before the component mounts
  },
  mounted: async function () {
    // Fetch data or initialize third-party libs
    await this.loadPricingData();
  },
  methods: {
    loadPricingData: async function () {
      // e.g. call a Sails endpoint
    },
    toggleContactForm: function () {
      this.contactFormVisible = !this.contactFormVisible;
    },
  },
});
```

## Notes

- Registered via `parasails.registerPage`, the Sails.js + Vue.js micro-framework used across FleetMDM's front end.
- The page name `'on-premise-page'` must match the `id` attribute on the corresponding EJS template's `<div>`.
- All method calls within `mounted` should be awaited to prevent race conditions during page initialization.
