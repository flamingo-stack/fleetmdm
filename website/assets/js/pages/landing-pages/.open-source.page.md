Parasails page component registration for the Open Source page, defining the standard Vue-based lifecycle structure with data, lifecycle hooks, and methods placeholders.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the open source page |
| `beforeMount` | Lifecycle hook | Logic executed before the component mounts |
| `mounted` | Lifecycle hook (async) | Async logic executed after the component mounts |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Extending the page with actual data and methods
parasails.registerPage('open-source-page', {
  data: {
    contributors: [],
    repoStats: {}
  },
  beforeMount: function() {
    // Pre-mount setup
  },
  mounted: async function() {
    this.repoStats = await fetch('/api/v1/repo-stats').then(r => r.json());
  },
  methods: {
    handleContribute() {
      window.open('https://github.com/flamingo-stack/fleetmdm', '_blank');
    }
  }
});
```

## Notes

- Registered via `parasails.registerPage`, which integrates with the Sails.js + Vue.js frontend convention used across this codebase.
- The `mounted` hook is declared `async`, allowing `await`-based data fetching on page load.
