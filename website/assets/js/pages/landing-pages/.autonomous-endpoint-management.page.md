Parasails page controller for the **Autonomous Endpoint Management** marketing/landing page, handling animated ticker cycling and video modal state.

## Key Components

| Member | Type | Description |
|---|---|---|
| `modal` | data | Tracks the currently open modal by name (`''` when closed) |
| `animateTicker` | method | Cycles visibility through ticker option elements every 1200ms with a CSS-driven exit animation |
| `clickOpenVideoModal` | method | Sets `modal` to the given name, opening the corresponding video modal |
| `closeModal` | method | Clears `modal`, closing any open modal |

## Usage Example

```javascript
// Open a video modal from a template button
clickOpenVideoModal('demo-video');

// Close the modal (e.g., from a dismiss button or overlay click)
closeModal();
```

```javascript
// Ticker animation targets DOM elements with purpose="ticker-option"
// Elements cycle: current → animating-out (1000ms CSS transition) → removed
// Next element gains "visible" class; wraps around at end of list
animateTicker(); // Called automatically on mounted()
```

## Ticker DOM Contract

The `animateTicker` method expects elements structured as:

```html
<span purpose="ticker-option">MDM</span>
<span purpose="ticker-option">Patching</span>
<span purpose="ticker-option">Compliance</span>
```

CSS should handle transitions on `.visible` and `.animating-out` classes. The exit animation timeout (1000ms) must remain less than the interval (1200ms) to avoid overlap.
