Registers the `reset-trial` parasails page, handling form submission and state management for resetting a Fleet trial account via email address.

## Key Components

**Data Properties**

| Property | Description |
|---|---|
| `formData` | Holds email address input collected from the form |
| `formErrors` | Tracks client-side validation errors per field |
| `formRules` | Enforces `emailAddress` as a required field |
| `syncing` | Loading/submission state flag |
| `cloudError` | Stores server-side error messages |
| `cloudSuccess` | Indicates a successful form submission |

**Methods**

- `submittedForm()` — Called on successful form submission; sets `syncing` to `false` and `cloudSuccess` to `true`
- `clickClearFormFields()` — Resets the form by clearing `cloudSuccess`, `formErrors`, and `formData`, then forces a re-render

## Usage Example

```javascript
// Triggered automatically by parasails when the page loads.
// The form collects an email address and submits it to reset a trial.

// On success, the success state is shown:
this.cloudSuccess = true;

// User can reset the form back to initial state:
await this.clickClearFormFields();
// → formData: {}, formErrors: {}, cloudSuccess: false
```
