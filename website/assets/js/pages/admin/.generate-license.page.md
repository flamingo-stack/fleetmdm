A Parasails page component that provides a form interface for generating Fleet MDM license keys, including validation, submission, and clipboard copy functionality.

## Key Components

**Data Properties**
- `formData` — Holds user inputs: `numberOfHosts`, `organization`, `expiresAt`, and optional `partnerName`
- `formRules` — Enforces required fields for `numberOfHosts`, `organization`, and `expiresAt`
- `generatedLicenseKey` — Stores the license key returned from the server
- `showResult` — Toggles display of the generated key result panel

**Lifecycle Hooks**
- `beforeMount` — Pre-populates `expiresAt` with a date one year from today using `moment.js`

**Methods**
- `handleSubmittingForm` — Converts the expiry date to a Unix timestamp and calls `Cloud.buildLicenseKey` with form values
- `submittedQuoteForm` — Disables syncing state and shows the result panel
- `clickCopyLicenseKey` — Copies the generated license key to the clipboard with a fade-in notification
- `clickClearFormFields` — Resets all form state and re-renders the component

## Usage Example

```javascript
// The page is registered and auto-mounted by Parasails on the matching route.
// Cloud.buildLicenseKey is called internally with the following payload:
await Cloud.buildLicenseKey.with({
  numberOfHosts: 500,
  organization: 'Acme Corp',
  expiresAt: 1780000000000, // Unix ms timestamp
  partnerName: 'Flamingo',  // optional
});

// After submission, the generated key can be copied via the UI button,
// which writes to the clipboard:
navigator.clipboard.writeText(this.generatedLicenseKey);
```

> **Note:** The form reset in `clickClearFormFields` repopulates `formData.validTo` instead of `formData.expiresAt`, which may be an unintentional field name mismatch with the form rules expecting `expiresAt`.
