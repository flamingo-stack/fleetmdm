Registers the `email-templates` parasails page component, providing the scaffold for managing email template configuration within the Fleet MDM admin interface.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the email templates page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook (async) | Runs after the component is mounted; supports async operations |
| `methods` | Object | Page-specific action handlers |

## Usage Example

```javascript
// Extend this scaffold to add email template state and logic
parasails.registerPage('email-templates', {
  data: {
    emailTemplates: [],
    selectedTemplate: null,
  },

  beforeMount: function() {
    // Pre-mount setup (e.g., initialize defaults)
  },

  mounted: async function() {
    // Fetch templates on load
    this.emailTemplates = await Cloud.getEmailTemplates();
  },

  methods: {
    selectTemplate: function(template) {
      this.selectedTemplate = template;
    },
  }
});
```

## Notes

- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout the Fleet MDM frontend.
- The `mounted` hook is `async`, allowing direct use of `await` for API calls on page load.
