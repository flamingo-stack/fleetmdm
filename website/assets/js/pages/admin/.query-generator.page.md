Registers the `query-generator` parasails page, which handles natural language to SQL query generation via a WebSocket-backed form, displaying platform-specific osquery results for macOS, Windows, Linux, and ChromeOS.

## Key Components

**Data State**
- `formData` / `formRules` — Captures and validates the `naturalLanguageQuestion` input (required)
- `generatedQueries` — Stores per-platform SQL queries and caveats (`macOSQuery`, `windowsQuery`, `linuxQuery`, `chromeOSQuery`, and matching `*Caveats` fields)
- `selectedTab` — Tracks the active platform tab (`macos`, `windows`, `linux`, `chromeos`)
- `syncing` / `cloudError` / `showGeneratedQuery` — UI loading, error, and visibility state

**Methods**

| Method | Description |
|---|---|
| `handleSubmittingForm` | Sends a socket GET request to `/api/v1/query-generator/get-llm-generated-sql` and registers socket event listeners |
| `clickResetQueryGenerator` | Clears all query results and resets the form input |
| `_onQueryResultsReturned` | Handles the `queryGenerated` socket event; populates queries, selects the first available platform tab, and tears down the listener |
| `_onQueryGenerationError` | Handles socket `error` events; sets `cloudError` and tears down the listener |
| `_setupCopyButtonEventListener` | Binds click handlers to `[purpose="copy-button"]` elements to copy visible code block content to the clipboard |

## Usage Example

```javascript
// Form submission triggers a socket request; results are received via socket event
handleSubmittingForm: async function() {
  this.syncing = true;
  io.socket.get('/api/v1/query-generator/get-llm-generated-sql', {
    naturalLanguageQuestion: this.formData.naturalLanguageQuestion
  }, () => {});
  io.socket.on('queryGenerated', this._onQueryResultsReturned);
  io.socket.on('error', this._onQueryGenerationError);
}

// On success, generatedQueries is populated and the first available tab is auto-selected
// e.g. { macOSQuery: 'SELECT ...', windowsQuery: null, ... }
```

> **Note:** Socket listeners are explicitly torn down with `io.socket.off(...)` after each response to prevent duplicate handlers across multiple submissions.
