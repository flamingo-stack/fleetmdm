Registers the `email-preview` parasails page component, providing a preview interface for rendered email templates with a default responsive preview mode.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `preview` | `data` | Controls the preview mode; defaults to `'Responsive'` |
| `beforeMount` | `lifecycle` | Merges `SAILS_LOCALS` server-side data into the component |
| `mounted` | `lifecycle` | Async hook reserved for post-mount initialization |
| `methods` | `object` | Placeholder for page-specific interaction handlers |

## Usage Example

```javascript
// SAILS_LOCALS is injected server-side and merged into component data at mount time:
// { emailTemplateName: 'welcome', subject: 'Welcome aboard!' }

parasails.registerPage('email-preview', {
  data: {
    preview: 'Responsive', // Could be toggled to 'Mobile' or 'Desktop'
  },
  beforeMount: function() {
    _.extend(this, SAILS_LOCALS); // Pulls in server-rendered template data
  },
});
```

## Notes

- Relies on [`parasails`](https://github.com/mikermcneil/parasails) for Vue-based page registration
- `SAILS_LOCALS` must be set by the Sails.js backend view before this page renders
- The `methods` and `mounted` blocks are scaffolded but unpopulated — extension points for future interactivity
