A Parasails page component registration for the `fast-track` route, defining the standard Vue/Parasails lifecycle structure with data, lifecycle hooks, and methods.

## Key Components

| Section | Description |
|---|---|
| `data` | Reactive state properties for the fast-track page |
| `beforeMount` | Synchronous lifecycle hook executed before DOM mounting |
| `mounted` | Async lifecycle hook executed after DOM is ready |
| `methods` | Page-specific action handlers and utilities |

## Usage Example

```javascript
// Extending this page with data and methods
parasails.registerPage('fast-track', {
  data: {
    isLoading: false,
    trackItems: [],
  },

  beforeMount: function() {
    // Synchronous setup before render
  },

  mounted: async function() {
    // Async data fetching after mount
    this.isLoading = true;
    this.trackItems = await Cloud.getFastTrackItems();
    this.isLoading = false;
  },

  methods: {
    handleSubmit: async function() {
      await Cloud.submitFastTrack();
    }
  }
});
```

## Notes

- Follows the standard [Parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout the Fleet MDM frontend
- The `mounted` hook is `async`, allowing `await` for Cloud API calls
- Source: [`fast-track.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/fast-track.page.js)
