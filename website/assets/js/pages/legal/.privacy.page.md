Registers the `privacy` page component using the parasails framework, providing the scaffolding for the Privacy Policy page with empty lifecycle hooks and method stubs.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the privacy page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook | Async hook that runs after the component is mounted |
| `methods` | Object | Container for page-specific interaction handlers |

## Usage Example

```javascript
// Extending the privacy page with custom behavior
parasails.registerPage('privacy', {
  data: {
    lastUpdated: '2024-01-01',
  },

  beforeMount: function () {
    // Pre-mount setup, e.g. setting page metadata
  },

  mounted: async function () {
    // Async operations after render, e.g. fetching policy version
    const response = await fetch('/api/v1/policy-version');
    this.lastUpdated = await response.json();
  },

  methods: {
    handleAccept() {
      // Handle user accepting privacy policy
    },
  },
});
```

## Notes

- Registered under the page key `'privacy'`, matching the route that renders this page.
- All sections (`data`, `beforeMount`, `mounted`, `methods`) are stubbed — logic is expected to be added as privacy policy display requirements evolve.
- See the full Fleet MDM source at [`privacy.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/privacy.page.js).
