Registers the `integrations` parasails page component, providing the lifecycle hooks and interaction logic for the Fleet MDM integrations page.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the integrations page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook | Async initialization logic executed after mount |
| `methods` | Object | Event handlers and page interaction methods |

## Usage Example

```javascript
// Registered automatically by parasails; no manual instantiation needed.
// Extend with custom state and methods as required:

parasails.registerPage('integrations', {
  data: {
    integrationsList: [],
    isLoading: false,
  },
  mounted: async function () {
    this.integrationsList = await Cloud.getIntegrations();
  },
  methods: {
    handleConnect: async function (integrationId) {
      await Cloud.connectIntegration({ id: integrationId });
    },
  },
});
```

## Notes

- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout this codebase.
- The `mounted` hook is `async`, supporting `await`-based API calls on page load.
- See the full implementation at [`integrations.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/integrations.page.js).
