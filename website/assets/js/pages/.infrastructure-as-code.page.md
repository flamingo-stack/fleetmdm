Registers the `fleet-gitops` parasails page component for the Infrastructure as Code (GitOps) marketing or feature page in the Fleet MDM web application.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the GitOps page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook | Async setup logic executed after the component mounts |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Registered automatically by parasails at page load
// Targets the DOM element with id="fleet-gitops"
parasails.registerPage('fleet-gitops', {
  data: {
    // reactive page state
  },
  beforeMount: function() {
    // pre-mount setup
  },
  mounted: async function() {
    // async data fetching or initialization
  },
  methods: {
    // event handlers and page actions
  }
});
```

## Notes

- Follows the standard parasails page registration pattern used across Fleet MDM's frontend
- The `mounted` lifecycle hook is `async`, suggesting potential API calls or deferred initialization on page load
- View the source at [`views/pages/infrastructure-as-code.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/views/pages/infrastructure-as-code.page.js)
