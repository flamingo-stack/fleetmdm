Parasails page component that handles the Vanta authorization OAuth flow, managing the connection between Fleet and the Vanta security compliance platform.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the authorization page |
| `beforeMount` | Lifecycle Hook | Pre-mount initialization logic |
| `mounted` | Lifecycle Hook | Async post-mount setup (e.g., token exchange, redirect handling) |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Registered automatically by parasails on pages matching 'vanta-authorization'
parasails.registerPage('vanta-authorization', {
  data: {
    // OAuth state, error messages, etc.
  },
  mounted: async function() {
    // Handles Vanta OAuth callback parameters (e.g., authorization code)
  },
  methods: {
    // Handlers for user interactions during the authorization flow
  }
});
```

## Notes

- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout Fleet
- The `mounted` lifecycle hook is `async`, indicating it likely performs an API call to complete the OAuth handshake with Vanta
- Source: [`vanta-authorization.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/vanta-authorization.page.js)
