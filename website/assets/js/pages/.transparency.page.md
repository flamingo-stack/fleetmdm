Registers the `transparency` page with parasails, handling platform detection and video modal interactions for the Fleet transparency page.

## Key Components

**Data Properties**
- `showSecureframeBanner` — Controls visibility of the Secureframe banner
- `modal` — Tracks the currently open modal by name
- `isDesktopUser` — Boolean flag for desktop vs. mobile detection
- `guessedPlatformName` — Human-readable platform label (defaults to `'computer'`)

**Lifecycle Hooks**
- `mounted` — Detects the user's platform via `bowser` and `navigator.maxTouchPoints`, setting `isDesktopUser` and `guessedPlatformName` accordingly

**Methods**
- `clickOpenVideoModal(modalName)` — Opens a named video modal by setting `this.modal`
- `closeModal()` — Dismisses the active modal by resetting `this.modal` to `undefined`

## Usage Example

```javascript
// Open a video modal from a template action
this.clickOpenVideoModal('demo-video');

// Close the active modal
this.closeModal();

// Platform detection result after mount
console.log(this.isDesktopUser);       // false (on iPhone)
console.log(this.guessedPlatformName); // 'iPhone'
```

## Platform Detection Logic

| Condition | `isDesktopUser` | `guessedPlatformName` |
|---|---|---|
| iOS (non-iPad) | `false` | `'iPhone'` |
| iPad / Mac with touch | `false` | `'iPad'` |
| Android | `false` | `'Android device'` |
| Default | `true` | `'computer'` |
