Parasails page controller for the Fleet MDM new license purchase flow, handling quote generation, pricing display, Stripe checkout, and billing form submission.

## Key Components

**Data State**
- `newLicenseFormData` — per-platform host counts (macOS, Windows, Linux, iOS, Android, other)
- `formErrors` / `formData` — client-side validation tracking and form field values
- `billingFormRules` / `checkoutFormRules` — validation rule sets for each form step
- `showBillingForm`, `showQuotedPrice`, `showSuccessMessage` — multi-step UI visibility flags

**Lifecycle Hooks**
- `beforeMount` — clears any existing URL hash
- `mounted` — adds required billing fields (`organization`, `firstName`, `lastName`) when user signed up via "Try Fleet Sandbox"

**Methods**

| Method | Purpose |
|---|---|
| `handleSubmittingQuoteForm` | Validates host totals > 0, calls `Cloud.createQuote` |
| `submittedQuoteForm` | Displays quoted price; shows billing form if hosts < 700 |
| `handleSubmittingCheckoutForm` | Calls `Cloud.getStripeCheckoutSessionUrl`, redirects to Stripe |
| `submittedPaymentForm` | Shows success state, focuses the submit button |
| `clickGoToDashboard` | Navigates to `/customers/dashboard?order-complete` |
| `clickScheduleDemo` | Redirects to Calendly with pre-filled email and name |
| `clickResetForm` | Resets quote form state and re-focuses the macOS hosts input |
| `clickClearOneFormError` | Removes a single field error from `formErrors` |

## Usage Example

```javascript
// Quote flow: user enters host counts → quote generated → price displayed
// If numberOfHosts < 700: billing form shown (self-serve Stripe checkout)
// If numberOfHosts >= 700: "Schedule Demo" path via Calendly

// Cloud API calls used internally:
await Cloud.createQuote.with({ macosHosts: 50, windowsHosts: 20, linuxHosts: 10, ... });
await Cloud.getStripeCheckoutSessionUrl.with({ quoteId: quote.id });
```
