Registers the `dashboard` parasails page component, managing user profile editing, password changes, and license key interactions via modal-driven forms.

## Key Components

| Member | Type | Description |
|---|---|---|
| `syncing` | data | Loading/async state flag |
| `formData` | data | Reactive form field values |
| `formErrors` | data | Client-side validation error map |
| `formRules` | data | Validation rules applied per modal |
| `cloudError` | data | Server-side error message |
| `modal` | data | Currently active modal identifier |
| `clickEditButton` | method | Opens the update-profile modal, pre-populating fields from `this.me` |
| `clickChangePassword` | method | Opens the update-password modal with password strength rules |
| `clickCopyLicenseKey` | method | Copies the Fleet license key to the clipboard with a fade notification |
| `clickExpandLicenseKey` | method | Toggles full license key visibility |
| `closeModal` | method | Dismisses the active modal and resets all form state |
| `submittedUpdateProfileForm` | method | Merges updated profile fields into `this.me` and closes the modal |
| `submittedUpdatePasswordForm` | method | Handles post-password-change teardown |
| `_resetForms` | method | Private helper that clears all form state and forces a re-render |

## Usage Example

```javascript
// Triggered by an "Edit Profile" button in the dashboard template
this.clickEditButton();
// → opens modal 'update-profile' with current user fields pre-filled

// Password validation rule enforced by clickChangePassword:
// Must be 12–48 chars, contain at least one digit and one special character
const isValid = value.match(/^(?=.*\d)(?=.*[^A-Za-z0-9]).{12,48}$/);

// After profile form submission, me is updated in-place:
Object.assign(this.me, _.pick(this.formData, ['firstName', 'lastName', 'organization', 'emailAddress']));
```

> **Note:** Password validation requires a minimum length of 12 characters with at least one digit and one non-alphanumeric character. The `_resetForms` helper calls `this.forceRender()` to ensure Vue reactivity is consistent after clearing state.
