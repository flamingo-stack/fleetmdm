Registers the `faq` parasails page component, providing the lifecycle hooks and interaction layer for the FAQ page.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the FAQ page |
| `beforeMount` | Lifecycle hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle hook (async) | Runs after the component is mounted to the DOM |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Extending this page with state and behavior
parasails.registerPage('faq', {
  data: {
    openQuestion: null,
  },
  beforeMount: function() {
    // Pre-mount setup, e.g. parse URL hash to expand a specific question
  },
  mounted: async function() {
    // Fetch dynamic FAQ content or initialize third-party widgets
  },
  methods: {
    toggleQuestion(id) {
      this.openQuestion = this.openQuestion === id ? null : id;
    }
  }
});
```

## Notes

- Registered via `parasails.registerPage`, which is the standard Fleet/Sails.js frontend page registration pattern used throughout this repository.
- The `mounted` hook is `async`, allowing `await`-based data fetching or initialization on page load.
- All three sections (`data`, lifecycle hooks, `methods`) are currently stubbed — see the full implementation at [`assets/js/pages/faq.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/assets/js/pages/faq.page.js).
