Page controller for the Fleet MDM app library view, managing platform filtering and scroll-aware UI behavior for browsing available applications.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `selectedPlatform` | `data` | Currently active platform filter; defaults to `'macos'`, switches to `'windows'` on Windows browsers |
| `clickSelectPlatform` | method | Updates the active platform filter and scrolls the page to the filter bar when switching platforms mid-scroll |
| `handleScrollingPlatformFilters` | method | Scroll event handler that toggles the `header-hidden` CSS class on the platform filter bar to compensate for the hidden site header |

## Usage Example

```javascript
// Platform filter button interaction (called from template)
this.clickSelectPlatform('windows');
// → scrolls to y:350 if user is past that point, then sets selectedPlatform = 'windows'

// Scroll handler — wired automatically on mount
window.addEventListener('scroll', this.handleScrollingPlatformFilters);

// The handler toggles a CSS class on the filter bar element:
// <div purpose="platform-filters" class="header-hidden"> ← added when scrolled far down
// <div purpose="platform-filters">                       ← restored when scrolling back up
```

## Behavior Notes

- **Auto-platform detection:** Uses `bowser.windows` on mount to default Windows users to the `windows` filter instead of `macos`
- **Scroll threshold:** `header-hidden` is added when `scrollTop` exceeds both `scrollDistance` and `1.5× window height`; removed when the user scrolls back up more than 60px
- **Scroll-to-filter:** Switching platforms while scrolled past y:370 smoothly repositions the viewport to y:350 to keep filters in view
