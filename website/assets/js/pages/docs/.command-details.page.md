Registers the `command-details` parasails page, which handles syntax highlighting and clipboard copy functionality for command detail code blocks.

## Key Components

- **`mounted`** — Initializes `highlight.js` on all `<pre><code>` elements and binds click handlers to copy buttons
- **Copy button handler** — Extracts visible code text from the nearest codeblock, copies it to the clipboard via `navigator.clipboard.writeText`, and briefly applies a `copied` CSS class for visual feedback

## Usage Example

```javascript
// Triggered automatically when the command-details page mounts.
// Copy buttons must use the following DOM structure:

// <div purpose="codeblock">
//   <pre><code>osquery SELECT ...</code></pre>
//   <button purpose="copy-button">Copy</button>
// </div>

// On click, the button receives the "copied" class for 2 seconds,
// then the code content is written to the clipboard.
$('[purpose="copy-button"]').on('click', async function() {
  let code = $(this).closest('[purpose="codeblock"]').find('pre:visible code').text();
  if (code) {
    $(this).addClass('copied');
    await setTimeout(() => { $(this).removeClass('copied'); }, 2000);
    navigator.clipboard.writeText(code);
  }
});
```

## Notes

- Requires `window.hljs` (highlight.js) to be available globally at mount time
- The copy handler targets only **visible** `<code>` blocks (`pre:visible`) to support tabbed or toggled code displays
- Source: [`command-details.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/command-details.page.js)
