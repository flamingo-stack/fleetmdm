Parasails page component for the Script Library page, managing platform filtering (Apple, Windows, Linux) and scroll-based UI behavior for the platform filter navigation.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `selectedPlatform` | data | Active platform filter; defaults to `'apple'`, auto-set to `'windows'` on Windows browsers |
| `modal` | data | Controls which modal is currently open |
| `clickSelectPlatform` | method | Sets the active platform and smoothly scrolls to the top of the page |
| `handleScrollingPlatformFilters` | method | Shows/hides the sticky platform filter bar based on scroll direction and position |
| `clickOpenTableOfContents` | method | Opens the table-of-contents modal |
| `closeModal` | method | Closes any open modal and triggers a force re-render |

## Usage Example

```javascript
// Platform is auto-selected on mount based on browser OS detection
// and URL hash (e.g., navigating to /script-library#linux)

// Programmatically switch platform filter
this.clickSelectPlatform('windows');
// → sets selectedPlatform = 'windows', scrolls to top

// Open table of contents modal
this.clickOpenTableOfContents();
// → sets modal = 'table-of-contents'

// Close any open modal
await this.closeModal();
// → clears modal, forces re-render
```

## Scroll Behavior

The platform filter bar hides when the user scrolls **down past 1.5× the viewport height**, and reappears when the user scrolls **up by more than 60px**, mimicking a smart sticky header pattern.
