Registers the `policy-library` parasails page, managing platform filter selection and scroll-aware UI behavior for the Fleet MDM policy library.

## Key Components

**Data**
- `selectedPlatform` — Tracks the active platform filter; defaults to `'macos'`, auto-switches to `'windows'` on Windows browsers via Bowser detection.

**Lifecycle Hooks**
- `mounted` — Detects the user's OS, sets the initial platform, and attaches a scroll event listener for sticky filter positioning.

**Methods**

| Method | Description |
|---|---|
| `clickSelectPlatform(platform)` | Updates the active platform filter; scrolls the page to `y: 370` if the user has scrolled past that point. |
| `handleScrollingPlatformFilters()` | Adds/removes the `header-hidden` class on the `div[purpose="platform-filters"]` element based on scroll direction and position. |

## Usage Example

```javascript
// Platform filter button (template)
clickSelectPlatform('windows');
// → Sets selectedPlatform to 'windows'
// → Smooth-scrolls to y:370 if currently scrolled below that threshold

// Scroll behavior
// Scrolling down past 1.5× viewport height → adds 'header-hidden' to filters
// Scrolling up more than 60px → removes 'header-hidden', reveals filters
```

## Notes

- Relies on the [Bowser](https://github.com/lancedikson/bowser) library (`bowser.windows`) for OS detection at mount time.
- The `div[purpose="platform-filters"]` element must exist in the page template for scroll-based class toggling to apply.
- Source: [`policy-library.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/policy-library.page.js)
