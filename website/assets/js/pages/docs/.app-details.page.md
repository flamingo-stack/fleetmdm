Registers the `app-details` parasails page, handling syntax highlighting for SQL-like code blocks and clipboard copy functionality for code examples on the app details view.

## Key Components

- **`mounted`** — Async lifecycle hook that drives two main behaviors:
  - **Syntax highlighting** — Iterates over all `<pre><code>` blocks, applying `hljs` highlights to shell blocks (`.ps`/`.sh`) directly, and manually wrapping table names (`programs`, `apps`) and column names (`bundle_short_version`, `bundle_identifier`, `version`, `name`) in `hljs-attr` and `hljs-string` spans before running `hljs.highlightElement()`
  - **Copy button** — Binds a click handler to `[purpose="copy-button"]` elements that copies sibling `<code>` text to the clipboard and toggles a `copied` CSS class for 2 seconds

## Usage Example

```javascript
// The page is auto-registered via parasails and activated when the
// matching DOM page is loaded. No manual instantiation is required.

parasails.registerPage('app-details', {
  data: { /* page-level reactive data */ },
  beforeMount: function() { /* pre-render setup */ },
  mounted: async function() {
    // Highlights all code blocks and wires copy buttons automatically
  },
  methods: { /* custom page methods */ }
});
```

```html
<!-- Copy button markup expected by the mounted handler -->
<div>
  <button purpose="copy-button">Copy</button>
  <pre><code class="sh">SELECT name FROM apps;</code></pre>
</div>
```

## Notes

- Relies on globally available `window.hljs` (highlight.js) and `_` (Lodash)
- Table/column keyword highlighting uses regex replacement on raw `innerHTML`; order matters — table names are highlighted before column names
- Source: [`app-details.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/app-details.page.js)
