Parasails page controller for the report details view, handling SQL syntax highlighting and copy-to-clipboard functionality for code blocks.

## Key Components

**Data Properties**
- `contributors` — Array for report contributor data (initialized empty)
- `selectedTab` — Active tab state, defaults to `'sql'`

**Lifecycle Hooks**
- `beforeMount` — Reserved for pre-render setup
- `mounted` — Primary initialization logic; processes syntax highlighting and wires up copy buttons

**Syntax Highlighting Logic** (`mounted`)
- Receives `columnNamesForSyntaxHighlighting` and `tableNamesForSyntaxHighlighting` from server-side page data
- Sorts keyword arrays by descending length to match longer tokens first, preventing partial replacements
- Wraps table names in `<span class="hljs-attr">` and column names in `<span class="hljs-string">` before delegating to `window.hljs.highlightElement()`
- Shell/PowerShell blocks (`.ps`, `.sh`) skip custom highlighting and go directly to highlight.js
- Applies `has-linebreaks` or `no-linebreaks` CSS class based on block content

**Copy Button Handler**
- Targets `[purpose="copy-button"]` elements
- Reads visible `<pre><code>` text from the nearest `[purpose="codeblock"]` ancestor
- Adds `.copied` class for 2 seconds as visual feedback, then writes to `navigator.clipboard`

## Usage Example

```javascript
// Server passes keyword arrays to the page via Parasails page data:
// columnNamesForSyntaxHighlighting: ['device_id', 'platform']
// tableNamesForSyntaxHighlighting: ['osquery_info', 'system_info']

// HTML structure expected by the copy handler:
// <div purpose="codeblock">
//   <pre><code class="sql">SELECT device_id FROM osquery_info</code></pre>
//   <button purpose="copy-button">Copy</button>
// </div>
```
