Registers the `script-details` parasails page, handling syntax highlighting and clipboard copy functionality for script code blocks on the script detail view.

## Key Components

- **`mounted`** — Initializes highlight.js on all `pre code` elements and binds a click handler to copy buttons
- **Copy button handler** — Extracts visible code text from the nearest code block, briefly applies a `copied` CSS class (for 2 seconds), then writes the content to the clipboard via `navigator.clipboard.writeText`

## Usage Example

```javascript
// Copy button triggers this flow on click:
$('[purpose="copy-button"]').on('click', async function() {
  let code = $(this)
    .closest('[purpose="codeblock"]')
    .find('pre:visible code')
    .text();

  if (code) {
    $(this).addClass('copied');         // visual feedback
    await setTimeout(() => {
      $(this).removeClass('copied');    // reset after 2s
    }, 2000);
    navigator.clipboard.writeText(code); // write to clipboard
  }
});
```

The page expects HTML elements with `purpose="copy-button"` and `purpose="codeblock"` attributes to wire up copy interactions, and uses `window.hljs` (highlight.js) for syntax highlighting on mount.
