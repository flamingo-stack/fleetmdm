Parasails page component for the MDM Commands documentation page, handling platform filtering (Apple, Windows, Linux) and scroll-aware UI behavior.

## Key Components

### Data Properties
| Property | Default | Description |
|---|---|---|
| `selectedPlatform` | `'apple'` | Currently active platform filter |
| `modal` | `undefined` | Controls active modal overlay |

### Methods

- **`clickSelectPlatform(platform)`** — Sets the active platform filter and smoothly scrolls the user back to the top of the page
- **`handleScrollingPlatformFilters()`** — Hides/shows the sticky platform filter bar based on scroll direction and position (hides after scrolling down past 1.5× viewport height; reveals after scrolling up 60px)
- **`clickOpenTableOfContents()`** — Opens the table of contents modal
- **`closeModal()`** — Clears the active modal and forces a re-render

### Lifecycle Hooks

- **`mounted`** — Detects Windows via Bowser, resolves `#linux` / `#apple` / `#windows` URL hash to set the initial platform, then attaches the scroll listener

## Usage Example

```javascript
// Platform filter selection (called from template)
this.clickSelectPlatform('windows');

// URL hash navigation — load page with a pre-selected platform
// https://example.com/mdm-commands#linux
// → sets selectedPlatform to 'linux' on mount

// Open the table of contents modal
this.clickOpenTableOfContents();
// modal === 'table-of-contents'

// Close the active modal
await this.closeModal();
// modal === ''
```
