Parasails page controller for the Fleet MDM documentation viewer, handling navigation structure, syntax highlighting, search, scroll behavior, and clipboard copy for heading links.

## Key Components

| Member | Type | Description |
|---|---|---|
| `data.pagesBySectionSlug` | Object | Pages grouped by URL section slug for sidebar navigation |
| `data.navSectionsByDocsSectionSlug` | Object | Pages further grouped by `docNavCategory` for collapsible nav sections |
| `data.subtopics` | Array | H2 headings extracted from the current page for "on this page" navigation |
| `computed.currentLocation` | String | Reactive `window.location.href` for active subtopic highlighting |
| `beforeMount` | Lifecycle | Builds breadcrumbs, sorts/groups pages, attaches scroll listener |
| `mounted` | Lifecycle | Handles hash scrolling, extracts subtopics, runs `hljs` syntax highlighting, wires heading clipboard-copy |
| `clickSwagRequestCTA` | Method | Fires Google Analytics + LinkedIn conversion events, then navigates to Typeform |
| `isCurrentSection` | Method | Returns `true` when a nav section matches the current page URL segment |
| `findPagesByUrl` | Method | Looks up the page array for a given section URL slug |
| `getActiveSubtopicClass` | Method | Returns `'active'` when a subtopic hash matches the current URL hash |
| `getTitleFromUrl` | Method | Converts a URL slug to a human-readable title (handles `fleet`, `rest`, `api` casing) |
| `toggleDocsNav` | Method | Toggles mobile docs nav visibility |
| `delayInput` | Method | Debounce helper for the search input |
| `handleScrollingInDocumentation` | Method | Manages right sidebar, swag CTA, and back-to-top button visibility on scroll |

## Usage Example

```javascript
// Registered automatically by parasails; accessed via the page's HTML template.

// Find all pages under a section (e.g., /docs/deploy/*)
let deployPages = this.findPagesByUrl('/docs/deploy');

// Check if a nav link is the active section
let active = this.isCurrentSection({ url: '/docs/configuration' }); // true/false

// Convert a URL slug to a display title
let title = this.getTitleFromUrl('/docs/rest-api'); // "REST API"

// Debounce the search input handler
this.delayInput(this.setSearchString, 300)();
```

## Notes

- Pages are filtered to `/docs` URLs only and sorted by `pageOrderInSectionPath`; FAQ pages are always moved to the end of their section.
- The four top-level docs sections (`get-started`, `deploy`, `configuration`, `rest-api`) are explicitly re-ordered via the `DOCS_SLUGS` constant in `beforeMount`.
- Syntax highlighting uses the globally loaded `hljs` (highlight.js) library and applies custom class tweaks for `function` keywords and `require` calls.
