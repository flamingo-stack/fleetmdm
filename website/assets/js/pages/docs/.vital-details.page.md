Page controller for the Fleet vitals detail view, managing platform filtering, SQL syntax highlighting, and scroll-aware UI behavior for individual vital (osquery table) pages.

## Key Components

| Member | Type | Description |
|---|---|---|
| `selectedPlatform` | data | Active platform filter (`apple`, `linux`, `windows`, `chrome`); defaults to `apple` |
| `selectedTab` | data | Active content tab; defaults to `sql` |
| `modal` | data | Currently open modal identifier |
| `contributors` | data | List of page contributors |
| `clickSelectPlatform` | method | Switches platform filter or redirects to the first vital available on the target platform |
| `handleScrollingPlatformFilters` | method | Adds/removes `header-hidden` class on platform filters based on scroll position |
| `clickOpenTableOfContents` | method | Opens the table-of-contents modal |
| `closeModal` | method | Closes any open modal and forces a re-render |

## Usage Example

```javascript
// Platform selection with redirect fallback
clickSelectPlatform('windows');
// If the current vital is not available on Windows,
// navigates to: /vitals/<first-windows-vital-slug>#windows

// Platform filter is also restored from URL hash on mount:
// /vitals/some-table#linux → selectedPlatform = 'linux'
// Falls back to 'windows' if bowser.windows is detected
```

## Behavior Notes

- **Syntax highlighting** — On mount, iterates all `pre code` blocks, injects `<span class="hljs-attr">` for table names and `<span class="hljs-string">` for column names before delegating to `highlight.js`. Keywords are sorted longest-first to prevent partial matches.
- **Copy button** — Clicking `[purpose="copy-button"]` copies visible code text to the clipboard and briefly adds a `copied` CSS class (removed after 2 seconds).
- **Scroll behavior** — Platform filters gain the `header-hidden` class when the user scrolls down past 1.5× the viewport height, and lose it when scrolling back up more than 60px.
