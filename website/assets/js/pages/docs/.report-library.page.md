Registers the `report-library` parasails page, managing platform selection state and scroll-aware positioning of platform filter UI elements.

## Key Components

**Data**
- `selectedPlatform` — Active platform filter, defaults to `'macos'`; auto-set to `'windows'` if the user's browser is detected as Windows via `bowser`

**Methods**
- `clickSelectPlatform(platform)` — Updates the selected platform and scrolls to `y=300` if the user is scrolled past that point
- `handleScrollingPlatformFilters()` — Adds/removes `header-hidden` class on `div[purpose="platform-filters"]` based on scroll direction and position, keeping filters visible when scrolling up

**Lifecycle Hooks**
- `mounted` — Detects Windows OS, attaches the scroll listener, and runs an initial filter position check

## Usage Example

```javascript
// Platform selection triggered from template
this.clickSelectPlatform('windows');

// Scroll handler is registered automatically on mount and
// targets the following DOM element:
// <div purpose="platform-filters"> ... </div>

// CSS class toggled by scroll behavior:
// .header-hidden { /* shifts filters up when header is out of view */ }
```

## Notes

- Scroll threshold for hiding filters is `windowHeight * 1.5` (downward) and `lastScrollTop - 60` (upward hysteresis)
- The `bowser` library must be available globally for OS detection
- Source: [`report-library.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/report-library.page.js)
