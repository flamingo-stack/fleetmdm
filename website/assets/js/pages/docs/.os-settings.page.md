Parasails page component for the OS Settings page, managing platform filter selection (Apple, Windows, Linux) and scroll-aware UI behavior.

## Key Components

| Member | Type | Description |
|---|---|---|
| `selectedPlatform` | data | Active platform filter; defaults to `'apple'`, auto-switches to `'windows'` on Windows browsers |
| `modal` | data | Tracks which modal is currently open |
| `clickSelectPlatform` | method | Sets the active platform filter tab |
| `handleScrollingPlatformFilters` | method | Shows/hides the sticky platform filter bar based on scroll direction and position |
| `clickOpenTableOfContents` | method | Opens the table-of-contents modal |
| `closeModal` | method | Closes any open modal and forces a re-render |

## Lifecycle Behavior

- **`mounted`**: Detects Windows OS via `bowser.windows` to set the default platform, reads `window.location.hash` (`#apple`, `#windows`, `#linux`) to deep-link to a specific tab, then wires up the scroll listener for the sticky filter bar.

## Usage Example

```javascript
// Platform is selected programmatically or via URL hash:
// Navigate to /os-settings#linux → selectedPlatform = 'linux'

// Template interaction (calls clickSelectPlatform):
// <button @click="clickSelectPlatform('windows')">Windows</button>

// Scroll behavior hides/shows div[purpose="platform-filters"]:
// Scrolling down past 1.5× viewport height → adds 'header-hidden' class
// Scrolling up more than 60px → removes 'header-hidden' class
```

## Notes

- Requires the `bowser` browser-detection library for OS sniffing.
- The scroll handler uses `scrollDistance` and `lastScrollTop` for hysteresis (avoids flickering on small scroll jitter).
