Registers the `osquery-table-details` parasails page, handling platform filtering, table navigation, and syntax highlighting for osquery table detail views.

## Key Components

| Component | Description |
|---|---|
| `filteredTables` | Computed property filtering `allTables` by the selected platform |
| `numberOfTablesDisplayed` | Computed count of currently filtered tables |
| `beforeMount` | Reads URL hash to set initial platform filter; binds scroll handler |
| `mounted` | Sorts tables alphabetically, applies custom keyword/column name syntax highlighting via `hljs` |
| `clickFilterByPlatform` | Updates `selectedPlatform` for the sidebar table list |
| `clickSelectPlatform` | Switches platform and redirects to a valid table if the current one is unavailable on the new platform |
| `clickOpenTablesNav` | Opens the table-of-contents modal and scrolls to the active table link |
| `handleScrollingPlatformFilters` | Shows/hides the sticky platform filter bar based on scroll direction |
| `closeModal` | Clears the active modal and forces a re-render |

## Usage Example

```javascript
// Platform filter is set from URL hash on load
// e.g. /tables/users#linux → selectedPlatform = 'linux'

// Programmatically switch platforms
this.clickSelectPlatform('windows');
// If current table doesn't support Windows, redirects to:
// /tables/appcompat_shims#windows

// Filter the sidebar table list independently
this.clickFilterByPlatform('chrome');
// filteredTables returns only tables with platforms.includes('chrome')

// Open the table-of-contents modal
this.clickOpenTablesNav();
// Opens 'table-of-contents' modal and scrolls to the active link
```

## Notes

- Platform `'apple'` maps to `'darwin'` internally for platform-array lookups.
- Syntax highlighting wraps table name matches in `hljs-attr` spans and column name matches in `hljs-string` spans before calling `hljs.highlightElement`.
- Single-line SQL examples get `purpose="line-break"` attributes on `SELECT`, `WHERE`, `FROM`, and `JOIN` keywords for readable formatting.
