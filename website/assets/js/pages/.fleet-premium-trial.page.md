Parasails page component for the Fleet Premium trial page, handling post-activation UX including license key display and navigation flow.

## Key Components

- **`closeModalAndRedirect`** — Navigates the user back after closing the trial modal. Uses the [Navigation API](https://developer.mozilla.org/en-US/docs/Web/API/Navigation_API) (`window.navigation`) to go back in history, with a fallback to the home route (`/`). Guards against redirecting back to `/login` by checking the first navigation entry's URL.
- **`clickCopyLicenseKey`** — Copies `this.trialLicenseKey` to the clipboard via `navigator.clipboard.writeText`. Temporarily adds a `copied` CSS class to the copy button for 2 seconds to provide visual feedback.

## Usage Example

```javascript
// Triggered when user clicks the copy button on the trial license key UI
clickCopyLicenseKey: async function() {
  $('[purpose="command-copy-button"]').addClass('copied');
  await setTimeout(() => {
    $('[purpose="command-copy-button"]').removeClass('copied');
  }, 2000);
  navigator.clipboard.writeText(this.trialLicenseKey);
}

// Triggered when user closes the trial modal
closeModalAndRedirect: function() {
  // Goes back if navigation history exists and didn't originate from /login
  if (window.navigation && window.navigation.canGoBack) {
    window.navigation.back();
  } else {
    this.goto('/'); // Fallback to home
  }
}
```

## Notes

- `trialLicenseKey` is expected to be set in `data` or passed as a page prop from the server before mount.
- The login URL check covers both local (`localhost:2024`) and production (`fleetdm.com`) environments.
