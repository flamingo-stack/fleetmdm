Registers the `basic-handbook` parasails page component, handling navigation, emoji filtering, search integration, and sidebar behavior for Fleet's handbook documentation pages.

## Key Components

### Data Properties

| Property | Description |
|---|---|
| `isHandbookLandingPage` | Whether the current URL is `/handbook` |
| `showHandbookNav` | Controls handbook navigation visibility |
| `breadcrumbs` | URL segments parsed for breadcrumb display |
| `subtopics` | H2/H3 headings extracted for sidebar nav |
| `handbookIndexLinks` | Sorted page links for the landing page index |
| `relatedPages` | Pages in the same handbook folder for sidebar |
| `hideEmojisOnPage` | Strips emojis on Windows devices |
| `regexToMatchEmoji` | Unicode regex matching emojis (excludes 🥚🐣🐥🦆🦢) |

### Lifecycle Hooks

- **`beforeMount`** — Detects landing page, parses URL into breadcrumbs
- **`mounted`** — Initializes Algolia DocSearch, handles URL hash scrolling, builds handbook index links and subtopics, injects responsibility links, sets ordered list counters

### Methods

| Method | Description |
|---|---|
| `_isCurrentSection(section, location)` | Checks if a sidebar section matches the current hash |
| `_getTitleFromUrl(url)` | Converts a URL slug to a human-readable title |
| `handleScrollingInHandbook()` | Manages back-to-top button and sidebar CTA visibility on scroll |
| `_removeEmojiFromThisPage()` | Replaces/removes emoji in `#body-content` HTML for Windows |
| `clickScrollToTop()` | Smoothly scrolls the page to the top |

## Usage Example

```javascript
// Algolia DocSearch is enabled only when algoliaPublicKey is configured:
// sails.config.custom.algoliaPublicKey = 'your-key';

// Hash-based deep linking is handled automatically:
// /handbook/company/communications#create-an-api-only-user
// scrolls to the matching heading with a 90px header offset.

// Emoji filtering activates automatically on Windows (via bowser.js):
if (bowser.windows) {
  this.hideEmojisOnPage = true;
  this._removeEmojiFromThisPage();
}
```

## Notes

- Algolia search targets the `fleetdm` index filtered to `section:handbook`
- Handbook index links exclude `/handbook/company/open-positions` and `/handbook/company/legal`
- The "Company" page is always sorted first in the handbook index
