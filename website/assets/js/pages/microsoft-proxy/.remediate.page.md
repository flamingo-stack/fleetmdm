Registers the `remediate` parasails page, which detects whether the current user is on a Windows operating system and exposes that state to the view.

## Key Components

- **`isWindowsUser`** *(Boolean)* — Reactive data flag, initialized to `false`, set to `true` if the browser's OS is detected as Windows.
- **`mounted`** — Async lifecycle hook that checks `bowser.windows` and updates `isWindowsUser` accordingly.

## Usage Example

```javascript
// The page auto-detects the OS on mount.
// In the view template, conditionally render Windows-specific remediation steps:

// Example usage in a linked template:
// <div v-if="isWindowsUser">
//   Follow Windows remediation steps...
// </div>
// <div v-else>
//   Follow macOS/Linux remediation steps...
// </div>
```

> **Dependency:** Relies on [`bowser`](https://github.com/lancedikson/bowser) for browser/OS detection. Ensure `bowser` is available globally before this page mounts.
