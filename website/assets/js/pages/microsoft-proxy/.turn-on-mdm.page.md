Page controller for the "Turn on MDM" flow, registering a parasails page component with standard lifecycle hooks and interaction methods.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the MDM activation page |
| `beforeMount` | Lifecycle hook | Synchronous setup logic before the component mounts |
| `mounted` | Lifecycle hook | Async initialization logic after the component mounts |
| `methods` | Object | User interaction handlers for the MDM onboarding flow |

## Usage Example

```javascript
// Registered automatically by parasails on pages matching 'turn-on-mdm'
parasails.registerPage('turn-on-mdm', {
  data: {
    isLoading: false,
    mdmEnabled: false,
  },
  mounted: async function () {
    // Fetch MDM status or prerequisites on page load
    this.mdmEnabled = await Cloud.getMdmStatus();
  },
  methods: {
    handleEnableMdm: async function () {
      this.isLoading = true;
      await Cloud.enableMdm();
      this.isLoading = false;
    }
  }
});
```

## Notes

- Follows the standard parasails page registration pattern used throughout Fleet MDM's frontend.
- The `mounted` hook is `async`, allowing direct `await` calls for API requests on load.
- Source: [`turn-on-mdm.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/turn-on-mdm.page.js)
