A Parasails page component that handles the expired sandbox state in the Fleet MDM web application, displayed when a user's sandbox environment has expired.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the page (currently empty) |
| `beforeMount` | Lifecycle Hook | Pre-mount initialization logic |
| `mounted` | Lifecycle Hook | Async post-mount initialization |
| `methods` | Object | Page-specific action handlers (currently empty) |

## Usage Example

```javascript
// Registered automatically by Parasails; paired with a server-rendered view.
// Extend data, lifecycle hooks, or methods as needed:

parasails.registerPage('sandbox-expired', {
  data: {
    supportEmail: 'support@example.com',
  },
  mounted: async function () {
    // e.g. log expiry event or fetch renewal options
  },
  methods: {
    clickRenew: async function () {
      await Cloud.requestSandboxRenewal();
    },
  },
});
```

## Notes

- Registered under the page key `'sandbox-expired'`; the corresponding server view must set `pageName` to this value for Parasails to activate the component.
- All sections (`data`, `beforeMount`, `mounted`, `methods`) are scaffolded but contain no logic yet — safe to extend without side effects.
