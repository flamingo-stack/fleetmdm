Registers the `waitlist` parasails page component, providing the lifecycle hooks and interaction logic for the waitlist landing page.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the waitlist page |
| `beforeMount` | Lifecycle Hook | Runs synchronously before the component is mounted |
| `mounted` | Lifecycle Hook | Async setup logic executed after the component mounts |
| `methods` | Object | Interaction handlers and helper functions for the page |

## Usage Example

```javascript
// parasails automatically binds this page to the matching view.
// Extend the data, lifecycle hooks, or methods as needed:

parasails.registerPage('waitlist', {
  data: {
    emailAddress: '',
    submitted: false,
  },

  beforeMount: function () {
    // Pre-mount setup (e.g. reading URL params)
  },

  mounted: async function () {
    // Async initialization (e.g. fetching initial data)
  },

  methods: {
    submitWaitlist: async function () {
      await Cloud.joinWaitlist({ emailAddress: this.emailAddress });
      this.submitted = true;
    },
  },
});
```

## Notes

- This file follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used throughout FleetMDM's frontend.
- The component is automatically activated when the browser loads the corresponding `waitlist` view.
