Handles the browser history and form submission logic for redirecting users into a Fleet Sandbox instance, ensuring clean navigation behavior when users return to the main site.

## Key Components

- **`syncing`** — Loading state flag for the page
- **`mounted`** — Core lifecycle hook that performs two actions:
  - Replaces the current browser history entry with `/` so the back button returns users to the homepage instead of the sandbox teleporter page
  - Binds `onpageshow` to catch cached page restores (e.g., Safari back-navigation) and redirect to `/`
  - Immediately submits the `demologin` form to authenticate the user into their Sandbox instance

## Usage Example

```javascript
// This page is not invoked directly — it is rendered server-side
// by the Fleet Sandbox view action, which pre-populates the
// 'demologin' form with credentials before this lifecycle runs.

// Flow:
// 1. Server renders page with hidden 'demologin' form
// 2. mounted() fires → history entry replaced with '/'
// 3. 'demologin' form auto-submits → user lands in Sandbox
// 4. If user hits back → they reach fleetdm.com homepage (not this page)
```

## Notes

- The `onpageshow` / `event.persisted` check is specifically needed for Safari's back-forward cache (bfcache), which can restore a fully cached version of this page without re-running `mounted`
- Refer to the server-side view action for full context on why auto-form-submission is used here
