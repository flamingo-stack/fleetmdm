Homepage page controller for Fleet MDM's marketing landing page, managing modal state, newsletter form submission, MDM comparison table interactions, and animated text ticker.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `modal` | data | Tracks the currently open modal (e.g., `'unsubscribed'`, video modals) |
| `selectedCategory` | data | Active category tab, defaults to `'mdm'` |
| `comparisonModeForIt` | data | Currently selected MDM vendor for comparison table, defaults to `'jamf'` |
| `comparisonModeFriendlyNames` | data | Display name map for 14 supported MDM/security vendors |
| `animationDelayInMs` | data | Ticker animation interval in milliseconds (`1200`) |
| `formRules` | data | Validation rules — requires a valid email address |
| `animateBottomTicker` | method | Cycles visible CTA ticker items using jQuery class toggling on an interval |
| `clickOpenVideoModal` | method | Sets `modal` to the given modal name to open a video overlay |
| `clickSwitchComparisonTableColumn` | method | Updates `comparisonModeForIt` and re-initializes Bootstrap tooltips |
| `closeModal` | method | Clears the active modal |
| `submittedNewsletterForm` | method | Shows a 10-second success banner and resets form data |

## Usage Example

```javascript
// Switching the MDM comparison table to display Intune
this.clickSwitchComparisonTableColumn('intune');

// Opening a video modal by name
this.clickOpenVideoModal('demo-video');

// Newsletter form success callback (wired to parasails form submit)
await this.submittedNewsletterForm();
// → cloudSuccess = true for 10 seconds, then resets to false
```

## Notes

- Registered via [`parasails.registerPage`](https://github.com/flamingo-stack/fleetmdm/blob/main/assets/js/pages/homepage.page.js) — requires the parasails Vue-based framework
- `beforeMount` detects `#unsubscribed` in the URL hash and auto-opens the unsubscribed modal, then clears the hash
- Tooltips use Bootstrap's `data-toggle="tooltip"` and are re-initialized after comparison table column switches to handle dynamically rendered content
