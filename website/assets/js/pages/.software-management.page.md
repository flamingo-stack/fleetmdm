Page controller for the Fleet MDM software management marketing/feature page, handling carousel animations and feature tab switching.

## Key Components

**Data Properties**
- `modal` — tracks the currently open video modal (undefined when closed)
- `visibleFeature` — controls which feature section is visible; defaults to `'mitigate-cves-automatically'`

**Lifecycle Hooks**
- `mounted` — initializes the Bootstrap hero carousel with a 5-second interval and synchronizes custom carousel indicator styles on slide transitions

**Methods**
- `clickSwitchFeature(feature)` — updates `visibleFeature` to show the selected feature tab
- `clickOpenVideoModal(modalName)` — opens a named video modal
- `closeModal()` — dismisses the active modal

## Usage Example

```javascript
// Switch the visible feature panel (called from template button clicks)
this.clickSwitchFeature('patch-os-automatically');

// Open a named video modal
this.clickOpenVideoModal('software-demo-video');

// Close the active modal
this.closeModal();
```

## Notes

- Registered via `parasails.registerPage` — part of the [Sails.js](https://sailsjs.com) + parasails frontend pattern used throughout this repo
- Carousel indicator state is managed manually via jQuery because Bootstrap's built-in indicator sync is bypassed by the custom `ol[purpose="carousel-indicators"]` markup
