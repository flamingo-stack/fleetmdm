Registers the `pricing` page component using Parasails, managing tooltip behavior and modal state for the Fleet MDM pricing page.

## Key Components

**Data Properties**
- `modal` — Tracks the currently open modal (empty string when none)
- `selectedFeature` — Holds the feature object selected for tooltip display
- `showExpandedTable` — Boolean flag to toggle the expanded pricing comparison table

**Lifecycle Hooks**
- `mounted` — Initializes Bootstrap tooltips on desktop (hover-triggered, scoped to `#pricing`)

**Methods**
- `clickOpenMobileTooltip(feature)` — Sets `selectedFeature` and opens the `mobileTooltip` modal for touch/mobile users
- `closeModal()` — Resets `selectedFeature` to `undefined` and closes any open modal

## Usage Example

```javascript
// Opening a mobile tooltip for a specific pricing feature
this.clickOpenMobileTooltip({ name: 'MDM Enrollment', description: 'Enroll devices automatically.' });
// → this.selectedFeature = { name: 'MDM Enrollment', ... }
// → this.modal = 'mobileTooltip'

// Closing the modal
this.closeModal();
// → this.selectedFeature = undefined
// → this.modal = ''
```

> **Note:** Desktop users see hover-based tooltips via Bootstrap's `.tooltip()` initialization in `mounted`. Mobile users interact through the `mobileTooltip` modal instead, since hover events are unavailable on touch devices.
