Registers the `gitops-workshop` parasails page component, providing the lifecycle hooks and interaction layer for the GitOps Workshop landing or content page.

## Key Components

| Member | Type | Description |
|---|---|---|
| `data` | Object | Reactive state for the page |
| `beforeMount` | Lifecycle hook | Pre-mount initialization logic |
| `mounted` | Lifecycle hook (async) | Post-mount setup, supports async operations |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Registered automatically by parasails at page load
// when the matching DOM element is present.
parasails.registerPage('gitops-workshop', {
  data: {
    workshopStep: 1,
  },
  mounted: async function () {
    // Fetch workshop content or validate session
  },
  methods: {
    handleStepChange: function (step) {
      this.workshopStep = step;
    },
  },
});
```

## Notes

- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used across this codebase.
- All lifecycle hooks and methods are currently stubbed (`//…`) — implementation details live in the corresponding view template or are pending development.
- Source: [`gitops-workshop.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/gitops-workshop.page.js)
