Page controller for the Linux Management marketing/feature page, handling video modal display state.

## Key Components

| Member | Type | Description |
|---|---|---|
| `modal` | data | Tracks the currently open modal name; empty string by default |
| `clickOpenVideoModal` | method | Sets `modal` to the provided `modalName` string to open a video modal |
| `closeModal` | method | Resets `modal` to `undefined`, closing any open modal |

## Usage Example

```javascript
// Open a specific video modal
this.clickOpenVideoModal('intro-video');

// Close the active modal
this.closeModal();
```

## Notes

- Registered via `parasails.registerPage` as the `'linux-management'` page
- `beforeMount` and `mounted` lifecycle hooks are defined but currently empty
- Modal state is typically bound in the template to conditionally render a video overlay
