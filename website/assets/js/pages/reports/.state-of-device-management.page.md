Registers the `state-of-device-management` parasails page, providing all static chart data (pie and bar charts) used to render survey results for the "State of Device Management" report page.

## Key Components

- **`pieCharts`** — Dataset definitions for Chart.js pie charts covering MDM deployment topics:
  - `cloudMDM` — Cloud vs. self-managed MDM split
  - `mdmCharges` — Per-device vs. per-user billing models
  - `mdmInvolvement`, `mdmDeploymentTime`, `mdmVisibility` — Deployment and visibility metrics
  - `mdmLaptopsAndServers`, `mdmInventory`, `mdmIncidentResponse`, `mdmRealtimeVisibility` — Operational capability metrics
  - `mdmComplianceEnforcement`, `mdmWorkflowAutomation`, `mdmSelfService` — Feature adoption metrics

- **`barCharts`** — Grouped bar chart data organized by report section:
  - `demographics` — Respondent gender, age, country, company size, role, industry, and remote work percentage
  - `partOne` — Device fleet metrics: total devices, enrollment rates, OS currency, platform coverage
  - `partTwo` — Device management strategy priorities and top challenges
  - `partThree` — MDM investment triggers

## Usage Example

```javascript
// Each pie chart entry maps to a Chart.js canvas element
// Example: rendering the cloudMDM pie chart
const chart = this.pieCharts.cloudMDM;
// chart.elementID  → 'cloud-mdm-chart'
// chart.data.labels → ['Cloud solution', 'Self-managed']
// chart.data.datasets[0].data → [57.6, 42.4]

// Bar chart entries are flat arrays consumed by a template loop
// Example: rendering demographics age bars
this.barCharts.demographics.age.forEach(({ label, percent, color }) => {
  // render a bar with given label, width (percent), and color
});
```

Each chart entry supplies `elementID`, `legendPosition` (optional), `labels`, `data`, and `backgroundColor` arrays — consumed directly by Chart.js or a wrapper component in the page template.
