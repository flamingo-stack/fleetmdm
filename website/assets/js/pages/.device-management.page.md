Registers the `device-management-page` parasails page component, providing the scaffold for device management UI logic within the FleetMDM interface.

## Key Components

| Section | Description |
|---|---|
| `data` | Reactive state for the device management page |
| `beforeMount` | Pre-mount lifecycle hook for initialization logic |
| `mounted` | Post-mount lifecycle hook for DOM-dependent setup |
| `methods` | Page-specific action handlers and business logic |

## Usage Example

```javascript
// Registered automatically by parasails; referenced via the page's HTML data attribute
// <div id="device-management-page" ...>

parasails.registerPage('device-management-page', {
  data: {
    devices: [],
    isLoading: false,
  },
  mounted: function() {
    this.loadDevices();
  },
  methods: {
    loadDevices: async function() {
      this.isLoading = true;
      this.devices = await Cloud.getDevices();
      this.isLoading = false;
    }
  }
});
```
