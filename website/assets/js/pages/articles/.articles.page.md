Registers the `articles` Parasails page component, handling category-based filtering and display logic for Fleet's blog and content library pages.

## Key Components

**Data Properties**
| Property | Description |
|---|---|
| `selectedArticles` | Array of articles currently displayed |
| `filter` | Active filter state (default: `'all'`) |
| `isArticlesLandingPage` | Flag for landing page vs. category page |
| `articleCategory` | Display name for the current category |
| `categoryDescription` | Subtitle text shown on category pages |

**Lifecycle Hooks**
- `beforeMount` — Maps URL `category` slugs (e.g. `'securing'`, `'guides'`, `'releases'`) to human-readable `articleCategory` labels and `categoryDescription` strings
- `mounted` — Conditionally initializes Algolia DocSearch for `Blog`, `News`, `Guides`, and `Releases` categories, scoped to the `articles` facet filter

**Methods**
- `clickGotoStart()` — Navigates to `/register`

## Usage Example

```javascript
// Category slug mapping examples:
// URL: /articles/category/engineering
// → articleCategory: 'Engineering'
// → categoryDescription: 'Read about engineering at Fleet and beyond.'

// URL: /articles/category/securing
// → articleCategory: 'Security'
// → categoryDescription: 'Learn more about how we secure Fleet.'

// Algolia search is only initialized when:
// 1. The category is Blog, News, Guides, or Releases
// 2. sails.config.custom.algoliaPublicKey is defined
```

## Notes

- Algolia search is silently disabled if `algoliaPublicKey` is not configured — no error is thrown
- The `report` category sets `categoryDescription` to an empty string intentionally
- Supported categories: `success-stories`, `securing`, `releases`, `engineering`, `guides`, `announcements`, `podcasts`, `report`, `whitepapers`, `webinars`, `articles`
