Registers the `basic-webinar` parasails page, handling webinar registration form submission and sidebar scroll behavior for webinar landing pages.

## Key Components

**Data**
- `formData` — Captures `emailAddress`, `firstName`, `lastName`, and `webinarName` for registration
- `formRules` — Validates email format and required fields
- `formDataToPrefillForLoggedInUsers` — Pre-populates form fields from authenticated user session
- `syncing`, `cloudError`, `cloudSuccess` — Tracks async submission state
- `scrollDistance` — Tracks scroll position for sidebar behavior

**Lifecycle Hooks**
- `beforeMount` — Pre-fills form data from `this.me` if user is logged in
- `mounted` — Sets `webinarName` from page meta and attaches scroll event listener

**Methods**
- `submittedDownloadForm` — Handles form submission; fires Qualified and Google Analytics events, then redirects to `/watch`
- `handleScrollingInArticle` — Toggles `header-hidden` class on the right sidebar based on scroll direction and position

## Usage Example

```javascript
// The page auto-prefills for logged-in users and redirects after registration
// Qualified integration (if available)
qualified('saveFormData', {
  email: 'user@example.com',
  name: 'Jane Doe',
});
qualified('showFormExperience', 'experience-1772126772950');

// Google Analytics event (if available)
gtag('event', 'fleet_website__webinar_registration');

// After submission, user is redirected to:
// /[current-page-url]/watch
```
