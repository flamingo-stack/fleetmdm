Registers a Parasails page component for whitepaper download landing pages, handling form submission, user prefill, and sidebar scroll behavior.

## Key Components

**Data Properties**
- `formData` — Collects `emailAddress`, `firstName`, `lastName`, and `whitepaperName` for the download form
- `formRules` — Validates email format and required fields
- `formDataToPrefillForLoggedInUsers` — Stores prefill values for authenticated users
- `syncing / cloudError / cloudSuccess` — Tracks async form state
- `scrollDistance` — Tracks scroll position for sidebar behavior

**Lifecycle Hooks**
- `beforeMount` — Prefills form fields from `this.me` if the user is logged in
- `mounted` — Sets `whitepaperName` from page meta and attaches the scroll event listener

**Methods**
- `submittedDownloadForm` — Fires analytics events (`gtag`, `qualified`), triggers the PDF download via a synthetic anchor click, and sets `cloudSuccess`
- `handleScrollingInArticle` — Adds/removes `header-hidden` on the right sidebar element based on scroll direction and position

## Usage Example

```javascript
// Triggered after the download form is submitted successfully
// The parent EJS/Vue template calls this via the ajax form's `@submitted` handler:

// <ajax-form :syncing.sync="syncing" :cloud-error.sync="cloudError"
//   action="/api/v1/whitepaper/download" @submitted="submittedDownloadForm">

// PDF is auto-downloaded and qualified/gtag integrations fire:
await this.submittedDownloadForm();
// => Downloads /pdfs/<whitepaperFilename>, fires analytics, sets cloudSuccess = true
```

**Scroll behavior** — The right sidebar gains `header-hidden` when scrolling down past 1.5× the viewport height, and loses it when scrolling back up by 60px or more.
