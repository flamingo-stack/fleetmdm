Parasails page controller for the `basic-article` page, handling article rendering enhancements including subtopic navigation, syntax highlighting, clipboard link copying, and Algolia DocSearch integration.

## Key Components

**Data Properties**
- `articleHasSubtitle` / `articleSubtitle` — detects and stores an H2 immediately following an H1 as a subtitle
- `subtopics` — array of `{ title, url }` objects built from `h2.markdown-heading` elements, used to populate the right sidebar navigation
- `lastScrollTop` / `scrollDistance` — scroll position tracking for sidebar behavior
- `isIpadOS` — flags iPadOS devices to conditionally show/hide embedded PDFs

**Lifecycle Hooks**
- `beforeMount` — placeholder, no logic
- `mounted` — orchestrates all page initialization: iPad detection, subtopic extraction, subtitle detection, ordered list counter reset, heading clipboard handlers, syntax highlighting, scroll listener, and DocSearch initialization

**Methods**
- `clickCopyRssLink(articleCategory)` — copies the RSS feed URL for the given category to the clipboard; falls back to `window.open` if the Clipboard API is unavailable
- `clickGotoStart()` — navigates to `/register`
- `handleScrollingInArticle()` — adds/removes `header-hidden` class on the right sidebar based on scroll direction and position, creating a hide-on-scroll-down, show-on-scroll-up effect

## Usage Example

```javascript
// Subtopics are auto-extracted from rendered H2 headings in [purpose="article-content"]
// Result shape:
[
  { title: 'Installation', url: '#installation' },
  { title: 'Configuration', url: '#configuration' },
]

// RSS copy button usage (called from template)
this.clickCopyRssLink('deploy');
// Copies: https://fleetdm.com/rss/deploy

// Algolia DocSearch is initialized only when algoliaPublicKey is configured,
// targeting both desktop (#docsearch-query) and mobile (#mobile-docsearch) containers
```

## Notes

- Syntax highlighting is applied via `window.hljs.highlightElement` on all `pre code` blocks
- Heading anchor clicks copy the heading's permalink to the clipboard, with a 5-second `copied` CSS class for visual feedback
- DocSearch is scoped to `facetFilters: ['section:articles']`
