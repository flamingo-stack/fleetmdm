Parasails page component for the Fleet MDM basic comparison page, handling navigation subtopics extraction, mobile-responsive comparison table setup, and scroll-aware sidebar behavior.

## Key Components

**Data Properties**
- `subtopics` — Array of `{ title, url }` objects extracted from `h2.markdown-heading` elements for right-sidebar navigation
- `lastScrollTop` / `scrollDistance` — Scroll position trackers for directional scroll detection
- `tableHeadersForMobileComparisonTable` — Column header strings used to add `data-label` attributes for CSS-driven mobile table layout

**Lifecycle Hooks**
- `beforeMount` — Reserved, currently empty
- `mounted` — Orchestrates subtopic extraction, mobile table labeling, and scroll listener registration

**Methods**
- `handleScrollingInArticle()` — Scroll handler that adds/removes `header-hidden` class on `div[purpose="right-sidebar"]` based on scroll direction and position threshold (`> 1.5x window height` to hide, `> 60px upward` to restore)

## Usage Example

```javascript
// Registered automatically via parasails; no manual instantiation needed.
// The page activates when the DOM contains purpose="article-content".

// Mobile table data-label output (enables CSS :before pseudo-element labels):
// <td data-label="Fleet">✓</td>

// Subtopics array shape:
// [{ title: "Feature X", url: "#feature-x" }, ...]

// Sidebar class toggling:
// div[purpose="right-sidebar"].header-hidden { ... } /* sticky scroll-up reveal */
```

## Notes

- The mobile comparison table relies on `data-label` attributes paired with CSS `td::before { content: attr(data-label) }` for column headers on small screens
- The scroll threshold (`windowHeight * 1.5`) prevents the sidebar from hiding prematurely on short pages
