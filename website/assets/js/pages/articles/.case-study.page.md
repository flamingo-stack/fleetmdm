Registers the `case-study` page component using the Parasails framework, providing the standard Vue-compatible lifecycle structure for the Fleet MDM case study page.

## Key Components

| Member | Type | Description |
|---|---|---|
| `data` | Object | Reactive state properties for the case study page |
| `beforeMount` | Lifecycle Hook | Synchronous setup logic executed before DOM mounting |
| `mounted` | Lifecycle Hook | Async initialization logic executed after DOM mounting |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Extend the page with data and methods
parasails.registerPage('case-study', {
  data: {
    caseStudy: null,
    isLoading: true,
  },

  beforeMount: function() {
    // Pre-mount setup, e.g. seed data from server-rendered vars
    this.caseStudy = window.SAILS_LOCALS.caseStudy;
  },

  mounted: async function() {
    // Async initialization, e.g. fetch additional content
    this.isLoading = false;
  },

  methods: {
    handleCtaClick: function() {
      // Handle user interactions on the case study page
    }
  }
});
```
