Registers the `download` parasails page, handling clipboard-based code copying functionality for code blocks on the download page.

## Key Components

- **`mounted`** — Initializes copy-to-clipboard behavior on `[purpose="copy-button"]` elements. Detects `navigator.clipboard` availability and either wires up click handlers or removes copy buttons gracefully.
- **`beforeMount`** — Lifecycle hook placeholder for pre-mount setup.
- **`methods`** — Placeholder for page-specific method definitions.

## Usage Example

```javascript
// Copy button interaction flow (handled automatically on mount):
// 1. User clicks [purpose="copy-button"] inside a [purpose="codeblock"]
// 2. The nearest <code> element's text is read
// 3. Text is written to clipboard via navigator.clipboard.writeText()
// 4. The "copied" class is added to the button (e.g. shows a checkmark icon)
// 5. After 2 seconds, the "copied" class is removed

// Expected HTML structure:
// <div purpose="codeblock">
//   <button purpose="copy-button"></button>
//   <code>npm install -g fleetctl</code>
// </div>
```

## Behavior Notes

- **Clipboard API check** — If `navigator.clipboard.writeText` is unavailable (e.g., non-HTTPS context or older browsers), copy buttons are removed from the DOM entirely rather than silently failing.
- **Visual feedback** — The `copied` CSS class toggles for 2 seconds to provide user feedback, typically rendering a checkmark icon swap.
- **No custom data or methods** — This page relies entirely on DOM event delegation with no reactive state.
