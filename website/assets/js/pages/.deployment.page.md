Registers the `deployment` parasails page component, initializing a Bootstrap carousel on mount for the deployment page UI.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state for the deployment page |
| `beforeMount` | Lifecycle hook | Pre-mount initialization logic |
| `mounted` | Lifecycle hook | Initializes the `#carousel` element with a 30-second interval |
| `methods` | Object | Page-specific interaction handlers |

## Usage Example

```javascript
// Carousel is auto-initialized on page load via the mounted hook.
// The #carousel element must exist in the deployment page template:

// <div id="carousel" class="carousel slide" data-ride="carousel">
//   ...slides...
// </div>

// To extend the page, add state or methods:
parasails.registerPage('deployment', {
  data: {
    activeSlide: 0,
  },
  mounted: async function() {
    $('#carousel').carousel({ interval: 30000 });
  },
  methods: {
    goToSlide(index) {
      $('#carousel').carousel(index);
    }
  }
});
```

## Notes

- Requires [parasails](https://github.com/mikermcneil/parasails) and jQuery (`$`) to be available globally.
- The carousel interval is set to **30,000 ms (30 seconds)**.
- Source: [`deployment.page.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/deployment.page.js)
