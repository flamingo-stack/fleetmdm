Handles client-side logic for the Fleet login/signup page, managing form state, validation, and post-authentication redirects using the `parasails` framework.

## Key Components

**Data Properties**
- `formToDisplay` — toggles between `'login'` and `'signup'` views
- `syncing` — loading/submission state flag
- `cloudError` — stores server-side error messages
- `signupFormRules` — validation rules including password complexity (min 12 chars, requires digit + special character)
- `loginFormRules` — email and password required validation
- `pageToRedirectToAfterFormSubmission` — destination after successful auth (defaults to `'/try'`)

**Lifecycle Hooks**
- `beforeMount` — parses URL hash fragments to set initial form view and post-login redirect destination

| Hash | Effect |
|---|---|
| `#register` | Shows signup form |
| `#purchaseLicense` | Redirects to `/new-license` |
| `#contact` | Redirects to `/contact?sendMessage` |
| `#tryfleet` | Redirects to `/try-fleet` |

**Methods**
- `switchForm(form)` — toggles between login and signup forms
- `submittedSignupForm()` — fires Google Analytics and LinkedIn conversion events, then redirects
- `submittedLoginForm()` — sets syncing state and redirects
- `clickGoBack()` — uses browser navigation API with fallback to `'/'`

## Usage Example

```javascript
// The page auto-registers with parasails; URL hash controls initial state:

// Show signup form on load:
// /login#register

// Redirect to license page after login:
// /login#purchaseLicense

// Clear a specific field error while typing:
this.typeClearOneFormError('emailAddress');

// Programmatically switch between forms:
this.switchForm('signup');
```
