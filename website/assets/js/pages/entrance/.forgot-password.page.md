Registers the `forgot-password` parasails page, handling form state, validation, and submission for the password reset request flow.

## Key Components

| Property/Method | Description |
|---|---|
| `syncing` | Loading/syncing state flag for the page |
| `formData` | Stores email address input from the user |
| `formErrors` | Tracks client-side validation errors per field |
| `formRules` | Defines validation rules — `emailAddress` is required and must be a valid email |
| `cloudError` | Holds server-side error messages returned after submission |
| `cloudSuccess` | Boolean flag set to `true` on successful form submission |
| `submittedForm()` | Async handler called on successful form submit; sets `cloudSuccess` to display a confirmation message |

## Usage Example

```javascript
// The page is registered globally via parasails and automatically
// bound to the matching HTML view for the 'forgot-password' route.

// Typical form submission flow:
// 1. User enters email address — validated against formRules
// 2. On submit, the form POSTs to the server (handled by parasails/Cloud SDK)
// 3. On success, submittedForm() is called:

submittedForm: async function() {
  this.cloudSuccess = true; // Triggers success message in the template
}
```

## Notes

- Validation enforces a required, properly formatted email address before any server call is made.
- `cloudError` surfaces server-side errors (e.g., unrecognized email) directly in the UI.
- The success state (`cloudSuccess`) replaces the form with a confirmation message, preventing duplicate submissions.
