Parasails page controller for the Fleet MDM partners page, managing partner registration and deal registration form modals with validation logic.

## Key Components

### Data State

| Property | Description |
|---|---|
| `isSafariThirteen` / `isIosThirteen` | Browser detection flags for Safari 13 logo carousel animation fix |
| `partnerFormData` | Partner registration form model (defaults to `reseller` type) |
| `partnerFormRules` | Validation rules for partner registration fields |
| `dealRegistrationFormData` | Deal registration form model with `platforms` and `useCase` multi-select objects |
| `dealRegistrationFormRules` | Validation rules including custom multi-checkbox validators for `platforms` and `useCase` |
| `modal` | Currently open modal identifier (`'partner'`, `'deal-registration'`, or `undefined`) |

### Methods

| Method | Description |
|---|---|
| `clickOpenModal(modalName)` | Opens a modal by name |
| `clickOpenPartnerModal(partnerType)` | Opens partner modal pre-set to a specific partner type |
| `clickSelectCustomCheckbox()` | Forces Vue re-render after checkbox interaction |
| `handleSubmittingPartnerForm(argins)` | Validates reseller/integrations-specific required fields then submits via `Cloud.deliverPartnerRegistrationSubmission` |
| `closeModal()` | Resets all form state and closes the active modal |
| `submittedDealForm()` / `submittedPartnerForm()` | Sets `cloudSuccess` flag on successful submission |

## Usage Example

```javascript
// Auto-opens deal registration modal when navigating to /partners#deals
// mounted hook handles this automatically

// Programmatically open the partner modal pre-set to "integrations" type
this.clickOpenPartnerModal('integrations');

// Custom multi-checkbox validation used in dealRegistrationFormRules
custom: (platforms) => {
  return _.keysIn(platforms).length > 0 && _.contains(_.values(platforms), true);
}
```
