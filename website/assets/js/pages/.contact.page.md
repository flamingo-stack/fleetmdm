Registers the `contact` page component using Parasails, managing multiple contact form variants (talk-to-us, general contact, job application, and GitOps workshop request) with form validation, user pre-filling, and analytics tracking.

## Key Components

### Data Properties

| Property | Description |
|---|---|
| `formToDisplay` | Controls which form is currently visible (`talk-to-us`, `contact`, `apply`, `gitops-workshop-request`) |
| `primaryBuyingSituation` | Tracks the user's buying intent for pre-filling and analytics segmentation |
| `formData` | Shared object holding current form field values |
| `formErrors` | Tracks client-side validation errors per field |
| `*FormRules` | Validation rule sets for each form (`talkToUsFormRules`, `contactFormRules`, `applicationFormRules`, `workshopRequestFormRules`) |
| `cloudSuccess` / `cloudError` | Submission result state |

### Lifecycle Hooks

- **`beforeMount`** — Determines which form to show based on `formToShow`, URL hash (`#message`, `#apply`, `#gitops`), session-based `primaryBuyingSituation`, and logged-in user data from `this.me`

### Methods

| Method | Description |
|---|---|
| `submittedContactForm` | Fires `gtag`, LinkedIn, and Qualified conversion events; sets `cloudSuccess` |
| `handleSubmittingTalkToUsForm` | Submits to `Cloud.deliverTalkToUsFormSubmission`, fires ICP-conditional analytics, redirects via `report.eventUrl` |
| `submittedApplicationForm` | Sets `cloudSuccess` on successful job application submission |
| `submittedWorkshopRequestForm` | Fires conversion tracking for workshop requests; sets `cloudSuccess` |
| `clickSwitchForms` | Resets `formData`, `formErrors`, and `cloudError` then switches the active form |
| `clickSelectCustomCheckbox` | Forces a Vue re-render after custom checkbox interaction |

## Usage Example

```javascript
// The page is auto-initialized by Parasails when the `contact` page loads.
// To switch forms programmatically within the page:
this.clickSwitchForms('apply');

// Form submission is handled via Parasails cloud actions:
await Cloud.deliverTalkToUsFormSubmission.with({
  emailAddress: 'user@example.com',
  firstName: 'Jane',
  lastName: 'Doe',
  organization: 'Acme Corp',
  primaryBuyingSituation: 'mdm',
  numberOfHosts: 500,
});
```
