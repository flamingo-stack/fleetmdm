Parasails page component for the Fleet MDM customers page, managing testimonial video modals, hero carousel initialization, and paginated case study display.

## Key Components

| Component | Description |
|---|---|
| `data.modal` | Tracks the currently open video modal ID |
| `data.quotesWithVideoLinks` | Filtered list of testimonials that include YouTube video URLs |
| `data.pageOfCaseStudiesVisible` | Pagination counter for progressively revealing case studies |
| `beforeMount` | Processes `testimonialsWithVideoLinks`, building `quotesWithVideoLinks` with kebab-cased modal IDs and embed IDs |
| `mounted` | Initializes the Bootstrap `#heroCarousel` with a 15-second interval |

## Methods

| Method | Description |
|---|---|
| `clickOpenVideoModal(modalName)` | Sets the active modal using a kebab-cased version of the author name |
| `clickGotoCaseStudyLink(url, event)` | Navigates to a case study URL; opens in a new tab if Ctrl/Cmd is held |
| `clickShowMoreCaseStudies()` | Increments `pageOfCaseStudiesVisible` to reveal the next page of case studies |
| `closeModal()` | Clears the active modal state |

## Usage Example

```javascript
// Opening a video modal programmatically
this.clickOpenVideoModal('Jane Doe');
// this.modal === 'jane-doe'

// Navigating to a case study
this.clickGotoCaseStudyLink('https://fleetmdm.com/customers/acme', event);

// Revealing additional case studies
this.clickShowMoreCaseStudies();
// this.pageOfCaseStudiesVisible increments by 1
```
