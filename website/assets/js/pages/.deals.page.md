Registers the `deals` parasails page, managing a partner deal registration form with validation, submission state, and success/error handling.

## Key Components

| Member | Type | Description |
|---|---|---|
| `formData` | Data | Collects submitter and customer contact details, deal size, close date, and preferred hosting |
| `formErrors` | Data | Tracks client-side validation errors per field |
| `formRules` | Data | Validation rules for all required fields including email format checks |
| `syncing` / `cloudError` / `showSuccessMessage` | Data | Loading, error, and success UI states |
| `submittedForm` | Method | Handles successful form submission by showing the success message |
| `clickResetForm` | Method | Resets all form state and forces a re-render |
| `clickChoosePreferredHosting` | Method | Sets the `preferredHosting` field and re-renders |
| `typeClearOneFormError` | Method | Clears a single field's validation error as the user types |

## Usage Example

```javascript
// Triggered after successful form submission via parasails form helper
submittedForm: async function() {
  this.syncing = false;
  this.showSuccessMessage = true;
},

// Reset the form to allow a new submission
clickResetForm: async function() {
  this.showSuccessMessage = false;
  this.cloudError = '';
  this.formErrors = {};
  this.formData = {};
  await this.forceRender();
},

// Set hosting preference from a button/toggle selection
clickChoosePreferredHosting: async function(value) {
  this.formData.preferredHosting = value;
  await this.forceRender();
},
```

## Validated Fields

Both the **submitter** (partner) and **customer** (end-org) require first name, last name, email (with format check), and organization. The form also requires `expectedDealSize` and `expectedCloseDate` before submission is allowed.
