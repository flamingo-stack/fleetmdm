Parasails page component for the `fleetctl-preview` route, managing platform-specific install commands and clipboard copy interactions for the FleetDM CLI preview setup flow.

## Key Components

**Data Properties**
- `selectedPlatform` — Active platform tab (`macos`, `linux`, `windows`, `npm`)
- `installCommands` — Map of platform-specific `fleetctl` install commands
- `fleetctlPreviewTerminalCommand` — Map of platform-specific `fleetctl preview` run commands
- `me` — Current user object, used to conditionally render authenticated vs. unauthenticated UI

**Methods**
- `clickCopyInstallCommand(platform)` — Copies the install command for the given platform to the clipboard; briefly toggles a `copied` CSS class on the button for visual feedback
- `clickCopyTerminalCommand(platform)` — Copies the `fleetctl preview` run command for the given platform; appends `--license-key` if a valid trial license key is present

## Usage Example

```javascript
// Triggered when a user clicks the install copy button for macOS
await this.clickCopyInstallCommand('macos');
// Copies: curl -sSL https://fleetdm.com/resources/install-fleetctl.sh | bash

// Triggered when a user clicks the terminal command copy button for Windows
await this.clickCopyTerminalCommand('windows');
// Copies: %USERPROFILE%\.fleetctl\fleetctl preview
// If trialLicenseKey is set and not expired:
// Copies: %USERPROFILE%\.fleetctl\fleetctl preview --license-key <key>
```

## Notes

- Clipboard writes use the [`navigator.clipboard.writeText`](https://caniuse.com/mdn-api_clipboard_writetext) API
- Button feedback uses a 2-second `copied` class toggle via jQuery selectors scoped to `purpose` attributes
- License key is only appended when `trialLicenseKey` is truthy **and** `userHasExpiredTrialLicense` is falsy
