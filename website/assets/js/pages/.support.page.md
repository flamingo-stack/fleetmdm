Registers the `support` page component using the parasails framework, defining the standard Vue-compatible page lifecycle and structure for the Fleet MDM support page.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `data` | Object | Reactive state properties for the support page |
| `beforeMount` | Lifecycle Hook | Logic executed before the component is mounted to the DOM |
| `mounted` | Lifecycle Hook | Async logic executed after the component is mounted |
| `methods` | Object | Event handlers and helper functions for the support page |

## Usage Example

```javascript
// parasails page registration pattern
parasails.registerPage('support', {
  data: {
    // reactive state
  },
  beforeMount: function() {
    // pre-mount setup
  },
  mounted: async function() {
    // async post-mount logic (e.g., fetch support data)
  },
  methods: {
    // page-specific methods
  }
});
```

## Notes

- This is a scaffold/shell implementation — all sections (`data`, lifecycle hooks, `methods`) are currently stubbed with placeholder comments (`//…`)
- Follows the standard [parasails](https://github.com/mikermcneil/parasails) page registration pattern used across Fleet MDM's frontend
- The page is identified by the string `'support'`, which must match the corresponding view template
