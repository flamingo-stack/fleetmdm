## Usage Example

```javascript
// Authenticate a user
const result = await Cloud.login({
  emailAddress: 'admin@example.com',
  password: 'hunter2',
  rememberMe: true
});

// Issue a command to an Android device
await Cloud.issueCommandOnAndroidDevice({
  androidEnterpriseId: 'ent_abc123',
  deviceId: 'dev_xyz789',
  issueCommand: 'LOCK',
  type: 'LOCK'
});

// Get an LLM-generated osquery SQL query
const { sql } = await Cloud.getLlmGeneratedSql({
  naturalLanguageQuestion: 'Which macOS hosts have FileVault disabled?'
});
```
