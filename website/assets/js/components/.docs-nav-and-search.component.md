A Vue/Parasails component that renders a documentation navigation bar with section links and an Algolia-powered search box.

## Key Components

**Props**
- `searchFilter` — Restricts Algolia search to a specific section index (e.g., `docs`, `software`, `tables`, `policies`, `vitals`, `controls`, `queries`, `handbook`)
- `algoliaPublicKey` — Public API key used to initialize the Algolia DocSearch widget; search UI is hidden if not provided
- `currentSection` — Highlights the active nav link by matching against section identifiers

**Navigation Links**

Renders seven top-level doc section links:

| Label | Href |
|---|---|
| Get started | `/docs` |
| Controls | `/mdm-commands` |
| Vitals | `/vitals` |
| Reports | `/reports` |
| Policies | `/policies` |
| Software | `/software-catalog` |
| Data tables | `/tables` |

**Lifecycle — `mounted`**

Validates `searchFilter` against allowed section names and initializes the Algolia `docsearch` widget targeting `#docsearch-query` with the `fleetdm` index.

## Usage Example

```javascript
// Registering in a Parasails page and passing props
<docs-nav-and-search
  algolia-public-key="YOUR_ALGOLIA_PUBLIC_KEY"
  current-section="docs"
  search-filter="docs"
/>
```

```javascript
// Valid searchFilter values
const searchIndexesThatExist = [
  'docs', 'software', 'queries', 'vitals',
  'policies', 'tables', 'handbook', 'controls'
];
```

> **Note:** If `algoliaPublicKey` is not passed, the search input is hidden entirely. If an invalid `searchFilter` is provided, the component throws an error at mount time.
