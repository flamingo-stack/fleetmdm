A styled span component used in Fleet documentation to render role-based access type badges with optional hyperlinks to relevant role documentation.

## Key Components

**Props**
- `type` *(required)* — The role label displayed inside the bubble (e.g., `"Admin"`, `"Observer+"`)

**Computed Data**
- `rawType` — Normalized lowercase version of `type`, used as a CSS class (e.g., `"observer-plus"` for `"observer+"`)
- `roleLink` — Auto-resolved URL to the role's documentation anchor. Supported roles:

| Type | Link Target |
|---|---|
| `admin` | `/guides/role-based-access#admin` |
| `maintainer` | `/guides/role-based-access#maintainer` |
| `observer` | `/guides/role-based-access#observer` |
| `observer+` | `/guides/role-based-access#observer2` |
| `technician` | `/guides/role-based-access#technician` |
| `gitops` | `/guides/role-based-access#gitops` |

**Behavior**
- If `type` maps to a known role, the bubble renders as a clickable `<a>` tag linking to the role docs
- Unknown types render as a plain `<span>` with the type applied as a CSS class
- Throws an error at `beforeMount` if `type` is not provided

## Usage Example

```html
<!-- Renders a linked role badge -->
<bubble type="Admin"></bubble>

<!-- Renders a linked Observer+ badge -->
<bubble type="Observer+"></bubble>

<!-- Renders an unlinked custom badge -->
<bubble type="Beta"></bubble>
```
