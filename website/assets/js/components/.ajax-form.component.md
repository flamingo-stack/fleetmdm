A Vue component registered via `parasails` that wraps a standard HTML form with AJAX submission behavior, client-side validation, and two-way prop binding for syncing state with parent components.

## Key Components

| Export / Method | Description |
|---|---|
| `ajaxForm` | Parasails component registration name |
| `submit()` / `keydownMetaEnter()` | Public form submission triggers (native submit + ⌘+Enter) |
| `_submit()` | Internal submission handler — prevents double-posting, runs parsing/validation, emits results |
| `handleParsing` prop | Custom parsing function alternative to `formData` + `formRules` |
| `handleSubmitting` prop | Custom async submission function alternative to `action` |

### Props

| Prop | Description |
|---|---|
| `action` | Name of a `Cloud.*` method (camelCase) to call on submit |
| `formData` | Plain object passed verbatim as request argins |
| `formRules` | Client-side validation rules (`required`, `isEmail`, `minLength`, etc.) |
| `syncing` | Two-way bound loading state |
| `cloudError` | Two-way bound server error |
| `formErrors` | Two-way bound field-level validation errors |

### Events

| Event | When |
|---|---|
| `submitted` | Server responds with 2xx |
| `rejected` | Server responds with non-2xx |
| `update:syncing` | Sync loading state |
| `update:cloudError` | Sync server error |
| `update:formErrors` | Sync field errors |

## Usage Example

```vue
<ajax-form
  :action="'login'"
  :form-data.sync="formData"
  :form-rules="formRules"
  :form-errors.sync="formErrors"
  :syncing.sync="syncing"
  :cloud-error.sync="cloudError"
  @submitted="handleSuccess"
  @rejected="handleRejection"
>
  <input v-model="formData.email" focus-first />
  <input v-model="formData.password" type="password" />
  <button type="submit" :disabled="syncing">Log in</button>
</ajax-form>
```

**With custom parsing and submission:**

```vue
<ajax-form
  :handle-submitting="handleSubmittingLogin"
  :handle-parsing="handleParsingLogin"
  :syncing.sync="syncing"
  :cloud-error.sync="cloudError"
  @submitted="handleSuccess"
>
  <!-- form fields -->
</ajax-form>
```
