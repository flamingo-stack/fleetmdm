A self-updating Vue/parasails component that formats JavaScript timestamps into human-readable strings using moment.js, automatically refreshing every minute.

## Key Components

**Props**
| Prop | Description |
|---|---|
| `at` | Required. Epoch millisecond timestamp to display |
| `format` | Display format: `'timeago'` (default), `'calendar'`, or `'billing'` |
| `short` | Omits time-of-day in timeago format (limited applicability) |
| `alwaysShowYear` | Forces year inclusion in timeago output |

**Format Modes**

- **`timeago`** — Smart relative display: "X minutes ago" within 24h, then expands to `Month DD [at] h:mma` within 31 days, `Month DD` within the year, or `Month DD, YYYY` beyond
- **`calendar`** — Static `MM-DD-YYYY` format, set once on mount
- **`billing`** — Expanded `MMM DD, YYYY` with no time-of-day, auto-refreshing

**Lifecycle Behavior**
- Sets up a `setInterval` every 60 seconds for `timeago` and `billing` formats
- Clears the interval on `beforeDestroy` to prevent memory leaks
- Watches the `at` prop for programmatic changes after mount

## Usage Example

```javascript
// Basic timeago (default)
`<js-timestamp :at="item.createdAt"></js-timestamp>`

// Calendar format (static MM-DD-YYYY)
`<js-timestamp :at="item.createdAt" format="calendar"></js-timestamp>`

// Billing format (e.g. "Dec 13, 2022")
`<js-timestamp :at="invoice.date" format="billing"></js-timestamp>`

// Timeago, always showing year
`<js-timestamp :at="item.createdAt" alwaysShowYear="true"></js-timestamp>`
```

> **Dependencies:** Requires [`moment.js`](https://momentjs.com/) and the [`parasails`](https://github.com/mikermcneil/parasails) component framework.
