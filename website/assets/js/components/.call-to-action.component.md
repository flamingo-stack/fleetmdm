A reusable Vue/Parasails component that renders a customizable call-to-action (CTA) section with support for a primary button, an optional secondary button, and a fallback default CTA linking to `/contact`.

## Key Components

### Props

| Prop | Required | Description |
|---|---|---|
| `type` | Optional | Set to `"custom"` to enable custom CTA mode; omit for default landing page CTA |
| `title` | Required (custom) | Heading text for the CTA |
| `text` | Required (custom) | Body text for the CTA |
| `primaryButtonText` | Required (custom) | Label for the primary button |
| `primaryButtonHref` | Required (custom) | URL for the primary button |
| `secondaryButtonText` | Optional | Label for the secondary button (requires `secondaryButtonHref`) |
| `secondaryButtonHref` | Optional | URL for the secondary button (requires `secondaryButtonText`) |

### Behavior

- **Default mode** (`type` omitted): Renders a static "Get a demo" link to `/contact`.
- **Custom mode** (`type="custom"`): Validates all required props on mount and throws descriptive errors for missing values. Props are copied into local data on `mounted` and are **not reactive** — watchers throw errors if any prop changes after initialization.

## Usage Example

**Default CTA:**

```javascript
// Renders the built-in "Get a demo" button
<call-to-action></call-to-action>
```

**Custom CTA with two buttons:**

```javascript
<call-to-action
  type="custom"
  title="Secure laptops & servers"
  text="Get up and running with Fleet in minutes."
  primary-button-text="Get started"
  primary-button-href="/get-started"
  secondary-button-text="Read the docs"
  secondary-button-href="https://fleetdm.com/docs"
></call-to-action>
```

> **Note:** All props are set once at mount time. Dynamically changing any prop at runtime will throw an error.
