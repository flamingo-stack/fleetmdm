A parasails/Vue component that renders a table of team rituals (recurring tasks), displaying each ritual's name, start date, frequency, DRI, and description — with optional linked descriptions via `moreInfoUrl`.

## Key Components

| Member | Type | Description |
|--------|------|-------------|
| `rituals` | Prop (Array) | Array of ritual objects to display in the table |
| `ritual.task` | Field | Name of the recurring task |
| `ritual.startedOn` | Field | Date the ritual was initiated |
| `ritual.frequency` | Field | How often the ritual occurs |
| `ritual.dri` | Field | Directly Responsible Individual for the ritual |
| `ritual.description` | Field | Description, rendered as a plain string or hyperlink depending on `moreInfoUrl` |
| `ritual.moreInfoUrl` | Field (optional) | When present, wraps the description in an anchor tag |

## Usage Example

```javascript
// Register and use in a parasails page or parent component
parasails.registerPage('my-page', {
  data: function() {
    return {
      rituals: [
        {
          task: 'Weekly Sync',
          startedOn: '2024-01-01',
          frequency: 'Weekly',
          dri: 'Jane Smith',
          description: 'Team standup and planning',
          moreInfoUrl: 'https://example.com/weekly-sync'
        },
        {
          task: 'Monthly Review',
          startedOn: '2024-01-15',
          frequency: 'Monthly',
          dri: 'John Doe',
          description: 'Review metrics and OKRs'
          // No moreInfoUrl — renders as plain text
        }
      ]
    };
  }
});
```

```html
<!-- In your page template -->
<rituals :rituals="rituals"></rituals>
```

## Notes

- Conditionally renders the description cell using `v-if`/`v-else` — plain text when no `moreInfoUrl` is provided, a hyperlink when one exists.
- Includes a reference link to a video walkthrough for adding new rituals.
- Lifecycle hooks (`beforeMount`, `mounted`, `beforeDestroy`) are stubbed and available for extension.
