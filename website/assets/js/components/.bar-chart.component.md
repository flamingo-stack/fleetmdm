A Vue/parasails component that renders data visualizations as either stacked or divided horizontal bar charts.

## Key Components

### Props

| Prop | Required | Description |
|------|----------|-------------|
| `type` | Yes | Chart layout: `'stacked'` or `'divided'` |
| `chartData` | Yes | Array of `{ label, percent, color }` objects |
| `title` | Yes | Chart heading text |
| `subtitle` | No | Optional subtitle below the title |
| `maxRange` | Divided only | Upper bound of the scale |
| `minRange` | Divided only | Lower bound of the scale |
| `incrementScaleBy` | No | Custom scale step; auto-selected if omitted |

### Chart Types

- **`stacked`** — All values are rendered as segments on a single bar, proportional to `percent`.
- **`divided`** — Each data item renders its own bar scaled between `minRange` and `maxRange`, with an auto-generated percentage axis.

### Scale Auto-Detection

When `incrementScaleBy` is not provided, the step is chosen from the range:

| Range | Step |
|-------|------|
| ≥ 50  | 10   |
| ≥ 20  | 5    |
| > 10  | 2    |
| ≤ 10  | 1    |

## Usage Example

```vue
<!-- Stacked bar chart -->
<bar-chart
  type="stacked"
  title="OS Distribution"
  subtitle="All enrolled devices"
  :chart-data="[
    { label: 'macOS', percent: 60, color: '#6e57f8' },
    { label: 'Windows', percent: 30, color: '#1f77b4' },
    { label: 'Linux', percent: 10, color: '#ff7f0e' }
  ]"
/>

<!-- Divided bar chart with explicit range -->
<bar-chart
  type="divided"
  title="Patch Compliance"
  :chart-data="complianceData"
  min-range="0"
  max-range="100"
  :increment-scale-by="20"
/>
```

> **Note:** All props are immutable after mount. Watchers will throw an error if any prop changes at runtime. The `divided` type requires both `minRange` and `maxRange`.
