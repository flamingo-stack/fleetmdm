A Vue.js modal dialog component that integrates Bootstrap's modal system with Vue's transition lifecycle, providing animated open/close behavior with custom event handling.

## Key Components

| Element | Description |
|---|---|
| `hideCloseButton` prop | Removes the default `×` dismiss button when set |
| `close` event | Emitted when the closing process begins |
| `opened` event | Emitted when the entry animation fully completes |
| `_bsModalIsAnimatingOut` | Spinlock flag preventing duplicate Bootstrap `hide` calls |
| `leave(el, done)` | Vue transition hook that coordinates Bootstrap and Vue teardown sequencing |

## Behavior Notes

- Uses `backdrop: 'static'` — clicking outside the modal does **not** close it; only the `×` button or a programmatic `$emit('close')` does
- Auto-focuses the first `[focus-first]` element after open animation completes (skipped on mobile via `bowser`)
- No `beforeDestroy` hook is intentional — timing conflicts with the `leave()` transition would cause unpredictable behavior

## Usage Example

```javascript
// In a parent component template:
// Toggle visibility with a boolean flag (e.g., `showMyModal`)

// Show the modal:
this.showMyModal = true;

// In your parent template:
// <modal v-if="showMyModal" @close="showMyModal = false" @opened="focusInput">
//   <h1>Modal Title</h1>
//   <input focus-first type="text" />
// </modal>

// Hide close button variant:
// <modal v-if="showMyModal" hide-close-button @close="showMyModal = false">
//   <p>No X button shown</p>
// </modal>
```

> **Caution:** Avoid adding Vue lifecycle callbacks (`beforeMount`, `beforeDestroy`, etc.) to this component. The interplay between Vue transitions and Bootstrap modal animations is fragile and well-tested as-is — modifications may produce difficult-to-debug rendering issues.
