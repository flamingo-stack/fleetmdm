A Vue/Parasails component that renders the Fleet "cloud city" illustration with a multi-layer parallax scrolling effect, automatically falling back to a static image on mobile devices or when hardware acceleration is unavailable.

## Key Components

### Props

| Prop | Type | Description |
|---|---|---|
| `noBackground` | Boolean | Removes the background styling from the wrapper element |

### Data Properties

| Property | Description |
|---|---|
| `parallaxCityElement` | jQuery reference to the parallax container `div` |
| `parallaxLayers` | Array of layer objects containing element refs and scroll amounts |
| `enableAnimation` | Toggles parallax animation vs. static fallback rendering |

### Methods

| Method | Description |
|---|---|
| `_setupParallaxAnimation()` | Initializes layer positions, calculates element bounds, and attaches scroll/resize listeners |
| `scrollParallaxLayers()` | Computes scroll percentage and applies `translate3D` transforms to each layer |
| `_throttleParallaxScroll()` | Scroll event handler that throttles animation updates to ~100ms intervals |
| `_isHardwareAccelerationEnabledOnChromiumBrowsers()` | Detects GPU vendor via WebGL to determine if hardware acceleration is active |
| `_isHardwareAccelerationEnabledOnFirefox()` | Compares hardware vs. software canvas renders to detect acceleration on Firefox |
| `_getElementPositions()` | Recalculates element height and page offsets (called on resize) |

### Template Layers (scroll amounts in px)

```text
background-cloud-2 (4) → background-cloud-1 (6) → small-island-2 (16)
→ small-island-1 (12) → large-island (24) → foreground-cloud-2 (32)
→ foreground-cloud-1 (40)
```

## Usage Example

```javascript
// Basic usage in a parent template
<parallax-city></parallax-city>

// Without background styling
<parallax-city :no-background="true"></parallax-city>
```

Parallax animation activates only after 25% of the element has scrolled into the viewport, with movement capped at each layer's defined `scroll-amount` maximum.
