A Parasails Vue component that displays Fleet's open job positions as a linked list, or a fallback message when no positions are available.

## Key Components

| Element | Description |
|---|---|
| `openPositions` | Required prop — array of position objects with `url` and `jobTitle` fields |
| `v-if / v-else` | Conditionally renders the positions list or a "no openings" message |
| Position list | Renders each position as an `<a>` link using `v-for` |
| Tip blockquotes | Contextual callouts with info icons for both the hiring and no-openings states |

## Usage Example

```javascript
// Register and use the component with a positions array passed as a prop
parasails.registerPage('careers', {
  data: {
    openPositions: [
      { jobTitle: 'Senior Engineer', url: '/jobs/senior-engineer' },
      { jobTitle: 'Product Designer', url: '/jobs/product-designer' },
    ]
  }
});
```

```html
<!-- In your page template -->
<open-positions :open-positions="openPositions"></open-positions>
```

**When positions exist**, renders a `<ul>` of linked job titles with a "Join us!" callout linking to the handbook.

**When empty**, renders a tip blockquote prompting visitors to send a LinkedIn profile via `/contact#message`.
