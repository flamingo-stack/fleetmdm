A Parasails UI component that renders a styled anchor element with an animated SVG arrow, supporting customizable colors for both the arrow and button text.

## Key Components

| Property | Type | Description |
|---|---|---|
| `buttonType` | prop | Reserved for future button style variants (primary/secondary) |
| `arrowColor` | prop | Custom stroke color for the SVG arrow (defaults to `#009A7D`) |
| `textColor` | prop | Custom font color for button text (defaults to `#192147`) |

**Internal State:**
- `strokeColor` — resolved arrow color, falls back to brand teal if `arrowColor` is not provided
- `fontColor` — resolved text color, falls back to dark navy if `textColor` is not provided

## Usage Example

```javascript
// Basic usage with default colors
<animated-arrow-button>Learn More</animated-arrow-button>

// With custom arrow and text colors (e.g., for dark backgrounds)
<animated-arrow-button arrow-color="#FFFFFF" text-color="#FFFFFF">
  Get Started
</animated-arrow-button>

// Registering the component (already handled in the source file)
parasails.registerComponent('animatedArrowButton', { /* ... */ });
```

> **Note:** The `buttonType` prop and primary style variant are stubbed out for future use. Currently, all buttons render as `secondary` type regardless of the `buttonType` value passed.

The component renders as an `<a>` tag with `no-icon` and `text-decoration: none`, containing a named slot for button text and an inline SVG arrow composed of a line and chevron path.
