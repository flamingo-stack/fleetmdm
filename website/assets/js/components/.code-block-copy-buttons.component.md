A Parasails UI component that automatically injects copy-to-clipboard buttons into all `<pre><code>` blocks on a page when mounted.

## Key Components

- **`mounted`** — Lifecycle hook that checks for `navigator.clipboard` API availability, then prepends a `<button>` element to each `<pre><code>` block and wires up click handlers
- **Copy handler** — Reads the nearest `<code>` element's text content, writes it to the clipboard, and toggles a `copied` CSS class for 2 seconds (used to swap the icon to a checkmark)
- **Guard clause** — Skips initialization entirely if `navigator.clipboard.writeText` is unavailable (e.g., non-HTTPS contexts or older browsers)

## Usage Example

Register the component on any page via Parasails, then place it once in a layout or view. It self-initializes on mount with no configuration needed.

```html
<!-- Place once in your layout or view template -->
<code-block-copy-buttons></code-block-copy-buttons>
```

```javascript
// The component registers globally via parasails — no import needed in templates
// Ensure parasails is loaded before this file:
parasails.registerComponent('code-block-copy-buttons', { /* ... */ });
```

**Expected DOM structure targeted:**

```html
<pre class="has-copy-button">
  <button type="button" purpose="code-block-copy-button" aria-label="Copy code"></button>
  <code>npm install fleet</code>
</pre>
```

**Notes:**

- Only runs in secure contexts where `navigator.clipboard` is available
- Uses `.not('.has-copy-button')` to prevent duplicate buttons on re-mount
- The `copied` class styling (checkmark icon swap) must be defined in the consuming page's CSS
