A reusable Vue/parasails button component that displays a loading spinner while an async operation is in progress.

## Key Components

- **Props**
  - `syncing` — Boolean that toggles the loading state; when `true`, hides button text and shows a spinner
- **Events**
  - `click` — Emitted when the button is clicked
- **Slots**
  - `default` — Button label text (fallback: `"Submit"`)
  - `syncing-state` — Custom loading indicator (fallback: `<div class="loading-spinner">`)

## Usage Example

```javascript
// Basic usage with a syncing state bound to a parent data property
```

```html
<ajax-button :syncing="isSaving" @click="handleSave">
  Save Changes
</ajax-button>

<!-- Custom loading state via slot -->
<ajax-button :syncing="isLoading" @click="fetchData">
  <template #default>Load Data</template>
  <template #syncing-state>
    <span>Loading…</span>
  </template>
</ajax-button>
```

The button renders with the CSS classes `btn ajax-button`, and appends `syncing` to its class list when `syncing` is `true`. The `type="submit"` attribute makes it compatible with form submissions.
