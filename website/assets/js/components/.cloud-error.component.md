A reusable Parasails/Vue component that renders a styled error message for cloud/API request failures, with optional margin control via a prop.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `withoutMargins` | Prop (`Boolean`) | When `true`, removes default margins from the error paragraph via `m-0` CSS class |
| `beWithoutMargins` | Internal state | Resolved boolean copy of the `withoutMargins` prop, set during `beforeMount` |
| Default slot | Slot | Custom error message content; falls back to a generic error string with a `/contact` support link |

**Validation:** Throws at mount time if `withoutMargins` is provided but is not strictly a boolean. Prop changes after mount are not supported and will throw.

## Usage Example

```javascript
// Basic usage — displays the default error message
// <cloud-error></cloud-error>

// Custom error message via default slot
// <cloud-error>Unable to reach the server. Please try again.</cloud-error>

// Suppress margins (e.g., inside a tight layout)
// <cloud-error :without-margins="true">Sync failed.</cloud-error>
```

Rendered output (default message):
```text
An error occured while processing your request. Please check your
information and try again, or contact support if the error persists.
```

> **Note:** The `withoutMargins` prop is static — it is read once at mount. Dynamically changing it after render will throw a runtime error. Pass the final value before the component mounts.
