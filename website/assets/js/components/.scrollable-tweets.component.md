A Vue/parasails component that renders a horizontally scrollable row of testimonial/tweet cards with pagination controls, expandable quotes, and YouTube video modal support.

## Key Components

**Props**
- `testimonials` — Required array of testimonial objects from `sails.config.builtStaticContent.testimonials`

**Data**
- `quotesToDisplay` — Processed testimonials array with overflow/expand state
- `quotesWithVideoLinks` — Subset of testimonials containing YouTube video URLs
- `tweetsDiv` / `tweetCards` — DOM references for scroll calculations
- `showPreviousPageButton` / `showNextPageButton` — Pagination visibility flags
- `numberOfTweetsPerPage` / `pageWidth` — Calculated layout dimensions
- `modal` — Controls which YouTube video modal is open

**Methods**

| Method | Description |
|---|---|
| `calculateHowManyFullTweetsCanBeDisplayed` | Measures card widths and computes how many fit per viewport |
| `clickNextPage` / `clickPreviousPage` | Scrolls the container by one page width |
| `updatePageIndicators` | Shows/hides prev/next buttons based on scroll position |
| `clickOpenVideoModal(name)` | Opens the YouTube embed modal for a testimonial |
| `closeModal` | Clears the active modal |
| `checkQuoteOverflow` | Detects truncated quotes and sets expand/overflow flags |

## Usage Example

```html
<scrollable-tweets :testimonials="testimonials"></scrollable-tweets>
```

```javascript
// Testimonial object shape expected in the array:
{
  quote: 'This product is amazing.',
  quoteLinkUrl: 'https://twitter.com/...',
  quoteImageFilename: 'logo-acme.png',
  imageHeight: 32,
  quoteAuthorName: 'Jane Doe',
  quoteAuthorJobTitle: 'CTO at Acme',
  quoteAuthorProfileImageFilename: 'jane-doe.jpg',
  youtubeVideoUrl: 'https://youtu.be/abc123', // optional
  videoIdForEmbed: 'abc123',                  // optional
}
```

> **Note:** The `testimonials` prop is required and must be an array. The component throws descriptive errors in `beforeMount` if the prop is missing or the wrong type. Window `resize` and `wheel` listeners are registered on mount and cleaned up in `beforeDestroy`.
