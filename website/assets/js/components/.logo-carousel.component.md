A parasails Vue component that renders an infinitely scrolling row of customer logos, with optional browser-specific CSS animation handling for Safari 13 and iOS 13.

## Key Components

| Name | Type | Description |
|---|---|---|
| `logoCarousel` | Component | Main parasails component registration |
| `displayBottomRow` | Prop | Boolean-like prop to show/hide a second reverse-scrolling row of logos |
| `bottomRowVisible` | Data | Derived boolean controlling bottom row visibility |
| `isSafariThirteen` | Data | Detects Safari 13 via `bowser` to apply fallback CSS animation class |
| `isIosThirteen` | Data | Detects iOS Safari 13 via `bowser` to apply iOS-specific animation class |

**Animation classes applied conditionally:**
- `ios-13-scroll-animation` — iOS Safari 13
- `safari-13-scroll-animation` — Desktop Safari 13
- Default CSS animation — all other browsers

The top row duplicates the logo set twice (for seamless looping) and scrolls left. The bottom row, when visible, uses `flex-row-reverse` to scroll in the opposite direction.

## Usage Example

```javascript
// Register and use in a parasails page or layout template:
parasails.registerComponent('logoCarousel', { /* defined in file */ });
```

```html
<!-- Basic usage - top row only -->
<logo-carousel></logo-carousel>

<!-- With bottom reverse-scrolling row enabled -->
<logo-carousel display-bottom-row="true"></logo-carousel>
```

**Dependencies:**
- [`parasails`](https://github.com/mikermcneil/parasails) — component registration
- [`bowser`](https://github.com/lancedikson/bowser) — browser/version detection
- `lodash` (`_`) — `_.startsWith` for version string matching
