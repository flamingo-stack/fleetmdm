A reusable Vue component (registered via `parasails`) that renders a dynamic list of input fields, supporting add/remove operations and multiple input types including text, select dropdowns, checkboxes, and team selectors.

## Key Components

### Props
| Prop | Description |
|---|---|
| `value` | Two-way binding array (v-model) |
| `addButtonText` | Custom label for the "Add another" button |
| `inputType` | Input mode: `select`, `teamSelect`, `nameAndHostCountSelect`, `checkboxes`, or any HTML input type |
| `selectOptions` | Array of option objects (required for select/checkbox modes) |
| `cloudError` | Highlights invalid fields based on server error response |
| `placeholder` | Optional placeholder text for text inputs |

### Slot: `item-field`
Exposes `item`, `doSet`, `allItems`, and `idx` for custom field templates. The first element with `role="focusable"` or `focus-first` is auto-focused on add/remove.

### Events
- `input` — Emitted whenever field values change

### Key Methods
| Method | Description |
|---|---|
| `inputDefaultItemField` | Handles standard text/select input changes |
| `inputTeamSelectItemField` | Handles team select with "All teams" support |
| `inputCheckboxItemField` | Handles checkbox toggle changes |
| `clickAddItem` | Appends a new `undefined` entry |
| `clickRemoveItem` | Removes item at given index |
| `clickResetSingleItem` | Resets the single remaining item to `undefined` |

## Usage Example

```javascript
// Basic text multifield
<multifield v-model="emails" placeholder="Enter email" />

// Select dropdown multifield
<multifield
  v-model="selectedPlatforms"
  input-type="select"
  :select-options="[
    { name: 'macOS', value: 'darwin' },
    { name: 'Windows', value: 'windows' }
  ]"
/>

// Team selector with "All teams" shortcut
<multifield
  v-model="teamIds"
  input-type="teamSelect"
  :select-options="teams"
/>

// Custom slot template
<multifield v-model="items">
  <template #item-field="{ item, doSet, idx }">
    <input :value="item" @input="doSet($event.target.value)" role="focusable" />
  </template>
</multifield>
```
