Sails.js blueprint API configuration that disables automatic route generation for the application.

## Key Components

| Option | Value | Description |
|--------|-------|-------------|
| `rest` | `false` | Disables auto-generated RESTful routes for models |
| `shortcuts` | `false` | Disables CRUD shortcut routes on GET requests |

## Usage Example

```javascript
// config/blueprints.js
module.exports.blueprints = {
  rest: false,      // No auto-generated GET /model, POST /model, etc.
  shortcuts: false, // No auto-generated GET /model/create, /model/find, etc.
};
```

With both options disabled, all application routes must be explicitly defined — improving security and ensuring no unintended endpoints are exposed. The commented-out `actions` option, if enabled, would additionally auto-expose implicit routes for every controller action.

> **Reference:** [Sails.js Blueprint API Docs](https://sailsjs.com/docs/reference/blueprint-api)
