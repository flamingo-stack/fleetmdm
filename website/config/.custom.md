Sails.js custom configuration file for the FleetDM website application, defining application-wide settings for URLs, authentication tokens, email, billing, and repository governance automation.

## Key Components

| Setting | Description |
|---|---|
| `baseUrl` | Development base URL (`http://localhost:2024`) used for building dynamic links in emails and webhooks |
| `passwordResetTokenTTL` / `emailProofTokenTTL` | Token expiry durations (24 hours each) |
| `rememberMeCookieMaxAge` | "Remember Me" session cookie lifetime (30 days) |
| `fromEmailAddress` / `fromName` | Sender identity for outgoing automated emails |
| `internalEmailAddress` | Support/GDPR data protection officer contact address |
| `verifyEmailAddresses` | Boolean flag to require email ownership verification on signup |
| `RX_PROTOCOL_AND_COMMON_SUBDOMAINS` | Regex for sanitizing LinkedIn URLs before CRM record creation |
| `githubRepoDRIByPath` | Path-to-GitHub-username map defining Directly Responsible Individuals (DRIs) for PR review requests across the `fleetdm/fleet` repository |

## Usage Example

```javascript
// Access custom config values within a Sails.js action or helper
module.exports = {
  fn: async function () {
    // Build a password reset link using baseUrl
    const resetLink = `${sails.config.custom.baseUrl}/reset-password?token=${token}`;

    // Check token expiry against TTL
    const tokenAge = Date.now() - tokenCreatedAt;
    if (tokenAge > sails.config.custom.passwordResetTokenTTL) {
      throw { expired: true };
    }

    // Send email from configured sender
    await sails.helpers.sendTemplateEmail({
      to: userEmail,
      from: sails.config.custom.fromEmailAddress,
      fromName: sails.config.custom.fromName,
      templateData: { resetLink }
    });
  }
};
```

## Notes

- Sendgrid (`sendgridSecret`), Stripe (`stripePublishableKey`, `stripeSecret`), and AI/CRM integration keys are stubbed out and commented — configure these per environment via `config/local.js` or environment variables before enabling billing or email features.
- The `githubRepoDRIByPath` map is consumed by the GitHub webhook controller ([`receive-from-github.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/website/api/controllers/webhooks/receive-from-github.js)) to automatically request PR approvals from the appropriate DRI.
