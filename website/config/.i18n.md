Sails.js internationalization (i18n) configuration that defines supported locales and translation settings for the application.

## Key Components

| Setting | Value | Description |
|---|---|---|
| `locales` | `['en', 'es', 'fr', 'de']` | Supported language codes (English, Spanish, French, German) |
| `defaultLocale` | `'en'` *(commented out)* | Fallback locale for non-browser clients |
| `localesDirectory` | `'config/locales'` *(commented out)* | Path to translation files, relative to app root |

## Usage Example

To activate optional settings, uncomment the relevant lines:

```javascript
module.exports.i18n = {
  locales: ['en', 'es', 'fr', 'de'],

  // Set default locale for non-browser clients (e.g. cURL)
  defaultLocale: 'en',

  // Custom path for locale/translation files
  localesDirectory: 'config/locales'
};
```

Translation files should be placed in `config/locales/` (or your configured `localesDirectory`) as JSON files named after each locale code (e.g. `en.json`, `es.json`).

> **Note:** The `defaultLocale` setting is overridden automatically for browser requests that include an `Accept-Language` header. It primarily affects non-browser clients.
