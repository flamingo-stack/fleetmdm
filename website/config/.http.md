Configures the HTTP server settings for the Sails.js application, including middleware order and custom request body parsing behavior.

## Key Components

- **`middleware.order`** – Defines the execution sequence of middleware layers for every HTTP request
- **`bodyParser`** – Custom Skipper-based body parser with a 10MB limit and structured error handling for 4xx/5xx scenarios
- **`middlewareErrorHandler`** – Catches static asset errors from `serve-static`, returning `416` (Range Not Satisfiable) or `412` (Precondition Failed) as appropriate

## Middleware Order

```text
cookieParser → session → bodyParser → compress → poweredBy → router → www → favicon → middlewareErrorHandler
```

## Usage Example

```javascript
// config/http.js is loaded automatically by Sails.js.
// To extend middleware, add a custom function to the middleware object:

module.exports.http = {
  middleware: {
    order: [
      'cookieParser',
      'session',
      'myCustomMiddleware', // add custom entries here
      'bodyParser',
      'router',
      'www',
      'favicon',
      'middlewareErrorHandler'
    ],
    myCustomMiddleware: function(req, res, next) {
      // custom logic
      return next();
    }
  }
};
```

## Error Handling Reference

| Condition | HTTP Status |
|---|---|
| Client request error (4xx body parse) | `400` |
| Request to static asset on parse error | `403` |
| Client never finishes streaming (`EUNFNTEX`) | `408` |
| Unexpected server error | `500` |
| Range Not Satisfiable | `416` |
| Precondition Failed | `412` |
