Sails.js view engine configuration that sets the default layout template for server-rendered views.

## Key Components

- **`module.exports.views`** — Sails.js view configuration object
- **`layout`** — Specifies the default layout file (`views/layouts/layout.ejs`) used to wrap all server-rendered views

## Usage Example

```javascript
// In a Sails.js action, res.view() automatically applies the configured layout:
module.exports = {
  friendlyName: 'Homepage',
  fn: async function (inputs, exits) {
    // Renders views/homepage.ejs wrapped in views/layouts/layout.ejs
    return exits.success(await this.res.view('homepage', {
      pageTitle: 'Welcome'
    }));
  }
};

// To disable the layout for a specific view:
return exits.success(await this.res.view('homepage', { layout: false }));
```

## Notes

- The `layout` path is relative to the `views/` directory and omits the file extension
- Layouts are only supported with the built-in **EJS** templating engine
- To disable layouts globally, set `layout: false`
- The `extension` option (commented out) defaults to `ejs` if not explicitly set
