Sails.js log configuration file that sets the minimum log level and transport settings for the application using Winston under the hood.

## Key Components

- **`module.exports.log`** — Exports the log configuration object consumed by `sails.config.log`
- **`level`** *(commented out)* — Controls the minimum log level captured by `sails.log.*()`

## Log Level Precedence

Levels are ordered from lowest to highest:

```text
silly → verbose → info → debug → warn → error
```

Set to `"silent"` to suppress all output.

## Usage Example

```javascript
// config/log.js
module.exports.log = {
  level: 'warn' // Only capture warn and error in production
};
```

```javascript
// Elsewhere in your app
sails.log.info('Server started');  // suppressed at 'warn' level
sails.log.warn('Low memory');      // captured
sails.log.error('DB unreachable'); // captured
```

> **Note:** The default `level` is commented out in this file, meaning Sails falls back to its built-in default (`info`). Uncomment and set `level` to override.

For custom transports (e.g., file logging, external services), refer to the [Sails logging docs](https://sailsjs.com/docs/concepts/logging) or the [Winston documentation](https://github.com/winstonjs/winston).
