Sails.js WebSocket server configuration file that defines realtime communication settings for the application.

## Key Components

| Setting | Status | Description |
|---|---|---|
| `transports` | Commented out | Defines allowed socket protocols (e.g., `websocket`) |
| `beforeConnect` | Commented out | Hook executed before each new socket connection is accepted |
| `afterDisconnect` | Commented out | Hook executed after each socket disconnects |
| `grant3rdPartyCookie` | Commented out | Enables `GET /__getcookie` route for HTTP-only session cookies |

## Usage Example

Uncomment and configure settings as needed:

```javascript
module.exports.sockets = {
  // Restrict to WebSocket only (no long-polling fallback)
  transports: ['websocket'],

  // Validate connections before allowing them
  beforeConnect: function(handshake, proceed) {
    // Allow connection (pass `false` to reject)
    return proceed(undefined, true);
  },

  // Cleanup logic on disconnect
  afterDisconnect: function(session, socket, done) {
    return done();
  },

  // Enable cross-domain cookie support
  grant3rdPartyCookie: true,
};
```

> **Note:** If you change `transports`, you must update `io.sails.transports` in your client-side code to match. Mismatched transport arrays will break socket connectivity. See the [Sails.js sockets config docs](https://sailsjs.com/config/sockets) for all available options.
