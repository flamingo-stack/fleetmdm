Configures the Sails.js datastore connections, defining where the application reads and writes data. By default, uses the built-in `sails-disk` adapter for local development storage.

## Key Components

- **`datastores.default`** — The primary datastore configuration used by all models unless overridden. Ships with no adapter specified, falling back to `sails-disk` for development convenience.

## Usage Example

Switch from the default `sails-disk` to a production-ready database by installing an adapter and providing a connection URL:

```javascript
// config/datastores.js
module.exports.datastores = {
  default: {
    adapter: 'sails-mysql',
    url: 'mysql://user:password@host:3306/fleetmdm_dev',
  },
};
```

For PostgreSQL:

```javascript
module.exports.datastores = {
  default: {
    adapter: 'sails-postgresql',
    url: 'postgresql://user:password@host:5432/fleetmdm_dev',
  },
};
```

> **Note:** The default `sails-disk` adapter is for development only and is not suitable for production. Production database configuration should be defined in [`config/env/production.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/env/production.js). See the [Sails.js datastores documentation](https://sailsjs.com/config/datastores) for the full list of supported adapters.
