Sails.js route configuration file that maps all HTTP GET endpoints for the Fleet website to their corresponding controller actions and view-level locals (meta tags, layout flags, section identifiers).

## Key Components

| Route Group | Path Prefix | Description |
|---|---|---|
| Marketing pages | `/`, `/pricing`, `/logos`, `/contact` | Core website pages |
| Content library | `/articles`, `/guides`, `/releases`, `/securing`, `/announcements`, `/podcasts`, `/engineering` | Article/blog content routes |
| Documentation | `/docs/?*`, `/tables/:tableName` | Docs viewer and osquery table details |
| Device management | `/reports/:slug`, `/vitals/:slug`, `/policies/:slug`, `/scripts/:slug`, `/mdm-commands/:slug` | Dynamic detail pages for device management resources |
| Customer portal | `/customers/*`, `/login`, `/new-license` | License management and authentication |
| Admin tools | `/admin/email-preview`, `/admin/generate-license`, `/admin/reset-trial`, `/admin/sandbox-waitlist` | Internal admin utilities |
| Integrations | `/connect-vanta`, `/vanta-authorization` | Third-party Vanta integration |
| Platform pages | `/device-management`, `/visibility-and-reporting`, `/software-management` | Feature marketing pages |

### Route Local Variables

Each route passes view-specific locals:
- `pageTitleForMeta` / `pageDescriptionForMeta` — SEO meta tags
- `currentSection` — Active nav section (`platform`, `documentation`, `pricing`, `more`, `customers`)
- `hideHeaderLinks` / `hideFooterLinks` — Layout control flags
- `skipAssets` — Asset pipeline bypass for content routes

## Usage Example

```javascript
// Adding a new route in routes.js
'GET /my-feature': {
  action: 'view-my-feature',
  locals: {
    currentSection: 'platform',
    pageTitleForMeta: 'My Feature',
    pageDescriptionForMeta: 'Description for SEO.',
    hideFooterLinks: false,
  }
},

// Dynamic slug route pattern
'GET /my-feature/:slug': {
  action: 'docs/view-my-feature-details',
  locals: {
    currentSection: 'documentation',
    // Meta title set in view action
  }
},
```
