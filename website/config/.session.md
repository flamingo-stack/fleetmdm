Configures Sails.js session management, including the session secret used to sign and encrypt user session cookies.

## Key Components

- **`secret`** — A string used to sign session cookies. Set to a placeholder value (`DUMMY_SECRET_REPLACED_IN_PROD`) that must be overridden via environment-specific config (e.g., `config/env/production.js`) before deploying to production.
- **`isSessionDisabled`** *(commented out)* — An optional function to skip session handling for specific requests, such as static asset routes, to improve performance.

## Usage Example

Override the secret in production via `config/env/production.js`:

```javascript
// config/env/production.js
module.exports = {
  session: {
    secret: process.env.SESSION_SECRET, // Set via environment variable
    isSessionDisabled: function (req) {
      return !!req.path.match(req._sails.LOOKS_LIKE_ASSET_RX);
    },
  },
};
```

## Notes

- **Never commit a real secret** to version control. Use environment variables or a secrets manager in production.
- Changing the `secret` in production will invalidate all existing user sessions, forcing re-authentication.
- See the [Sails.js session docs](https://sailsjs.com/config/session) for the full list of available options.
