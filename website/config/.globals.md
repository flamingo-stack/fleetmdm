Configures which global variables Sails.js automatically exposes throughout the application at startup.

## Key Components

| Option | Value | Description |
|--------|-------|-------------|
| `_` | `@sailshq/lodash` | Exposes Lodash as a global `_` variable |
| `async` | `false` | Disables the legacy `async` npm package as a global |
| `models` | `true` | Exposes all app models as global variables |
| `sails` | `true` | Exposes the Sails app instance as a global `sails` variable |

## Usage Example

Once configured, these globals are accessible anywhere in the application without explicit imports:

```javascript
// Access Lodash globally
const filtered = _.filter(users, { active: true });

// Access a model globally (e.g., User model)
const user = await User.findOne({ id: userId });

// Access the Sails instance globally
sails.log.info('App running in', sails.config.environment);
```

## Notes

- The legacy `async` npm package is disabled (`false`) since this app favors native `async/await` syntax instead
- Full configuration reference: [sailsjs.com/config/globals](https://sailsjs.com/config/globals)
- Source: [`config/globals.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/globals.js)
