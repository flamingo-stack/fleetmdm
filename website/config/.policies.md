Defines Sails.js policy mappings that control access to application routes by associating each route pattern with an authentication or authorization policy.

## Key Components

### Global Policy
- `'*': 'is-logged-in'` — All routes require authentication by default

### Restricted Access Policies
- `'admin/*': 'is-super-admin'` — Admin routes require super-admin privileges
- `'query-generator/*': 'has-query-generator-access'` — Query generator requires specific access grant
- `'microsoft-proxy/*': 'is-cloud-customer'` — Microsoft proxy routes restricted to cloud customers

### Public Routes (`true`)
Routes that bypass the default `is-logged-in` policy, including:
- **Authentication flows** — `entrance/*`, `account/logout`
- **Public pages** — `docs/*`, `handbook/*`, `articles/*`, `legal/*`, marketing and landing pages
- **Webhooks** — `webhooks/*`
- **Third-party integrations** — `vpp-proxy/*`, `android-proxy/*`, Vanta and Microsoft redirect endpoints
- **Lead/form submissions** — `deliver-contact-form-message`, `deliver-talk-to-us-form-submission`, `deliver-deal-registration-submission`, etc.
- **Public API endpoints** — `get-human-interpretation-from-osquery-sql`, `get-est-device-certificate`, `get-llm-generated-configuration-profile`

## Usage Example

```javascript
// config/policies.js — Sails.js loads this automatically.
// To protect a new route, add it under a named policy:
module.exports.policies = {
  '*': 'is-logged-in',        // default: must be authenticated
  'admin/*': 'is-super-admin', // admin routes: must be super admin

  // Bypass authentication for a public endpoint:
  'view-my-public-page': true,
};
```
