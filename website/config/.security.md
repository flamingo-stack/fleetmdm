Sails.js security configuration module that enables CSRF protection and exposes commented-out CORS settings for the FleetMDM application.

## Key Components

- **`csrf`** — Set to `true`, enabling Cross-Site Request Forgery protection globally across all routes
- **`cors`** *(commented out)* — Disabled by default; configuration block available to allow cross-origin requests if needed

## Usage Example

```javascript
// config/security.js — modify CORS settings when integrating external clients
module.exports.security = {
  cors: {
    allRoutes: false,
    allowOrigins: ['https://trustedsite.net'],
    allowCredentials: false,
  },
  csrf: true
};
```

> **Note:** CORS is intentionally disabled by default. Enable only for trusted origins to avoid exposing the API to unauthorized cross-origin requests.
