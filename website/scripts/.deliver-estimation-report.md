Sails.js action that aggregates GitHub project story point totals across all columns and delivers a formatted estimation report to a configured Slack webhook.

## Key Components

- **GitHub REST API integration** — fetches classic GitHub Projects and their columns/cards using a personal access token
- **GitHub Projects v2 (beta) support** — uses a GraphQL query to fetch next-gen projects, normalizing them into a shape compatible with the REST API response
- **Story point extraction** — reads numeric labels (e.g., `1`, `2`, `3`, `5`) from issues and sums them per column per project
- **Concurrent processing** — uses `sails.helpers.flow.simultaneouslyForEach` to parallelize fetches across projects, columns, and cards
- **Slack delivery** — posts the aggregated `estimationReport` object to a Slack incoming webhook URL

## Usage Example

This action is invoked as a Sails.js machine, typically on a schedule:

```javascript
// In a scheduled job or script runner
await sails.helpers.actions.deliverEstimationReport();
```

**Required configuration** in `config/custom.js`:

```javascript
module.exports.custom = {
  // GitHub personal access token with `read:org` and `repo` scopes
  githubAccessToken: 'ghp_xxxxxxxxxxxxxx',

  // Slack incoming webhook URL for the target channel
  slackWebhookUrlForGithubEstimates: 'https://hooks.slack.com/services/T.../B.../xxx',
};
```

**Output shape posted to Slack:**

```text
New estimation report:
{
  'Sprint Board': { 'In Progress': 13, 'Done': 21, 'Backlog': 8 },
  'Roadmap': { 'Planned': 34, 'In Review': 5 }
}
```

> **Note:** Story points are read from GitHub issue labels where the label name is a finite number (e.g., `3`). Cards with no numeric label contribute `0` points. Cards with more than one numeric label throw an error.
