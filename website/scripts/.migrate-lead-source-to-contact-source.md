One-time Sails.js shell script that migrates legacy `LeadSource` field values to the custom `Contact_source__c` field for Salesforce Contact records where the contact source is not yet populated.

## Key Components

- **Salesforce authentication** — Connects via `jsforce` using credentials from `sails.config.custom`
- **`POSSIBLE_CONTACT_SOURCES`** — Allowlist of lead source values eligible for migration (`Dripify`, `Website - Contact forms`, `Website - Sign up`, etc.)
- **SOQL query** — Fetches Contacts where `Contact_source__c` is `NULL` and `LeadSource` matches the allowlist
- **Bulk update** — Uses `sails.helpers.flow.simultaneouslyForEach` to concurrently update each contact's `Contact_source__c` with its existing `LeadSource` value

## Usage Example

```bash
# Run via Sails shell script runner
sails run migrate-lead-source-to-contact-source
```

```javascript
// Requires these config values to be set before running:
sails.config.custom.salesforceIntegrationUsername // Salesforce login username
sails.config.custom.salesforceIntegrationPasskey  // Salesforce login password + security token
```

## Notes

- This is a **one-time migration script** — contacts already having `Contact_source__c` set are excluded by the `WHERE Contact_source__c = NULL` clause
- A commented-out query targeting a specific test contact (`McNeil, Mike`) is included for scoped testing before a full run
- The `//eslint-disable-line camelcase` comment suppresses linting for the Salesforce custom field naming convention (`Contact_source__c`)
