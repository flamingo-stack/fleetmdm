A Sails.js shell script that delivers automated nurture emails to MDM-focused users based on their psychological buying stage and time elapsed since stage entry.

## Key Components

- **Stage 3 ("Intrigued")** — Sends `email-nurture-stage-three` to users who have been at stage 3 for at least **1 day** and have not yet received a stage 3 nurture email.
- **Stage 4 ("Has use case")** — Email sending is currently **disabled** (commented out) to avoid interfering with sales rep lead flow; however, users are still marked as having been processed via `stageFourNurtureEmailSentAt`.
- **Stage 5 ("Personally confident")** — Sends `email-nurture-stage-five` to users who have been at stage 5 for at least **6 weeks** and have not yet received a stage 5 nurture email.
- **User filtering** — Only targets users with `primaryBuyingSituation: 'mdm'` created after July 22, 2024 and at least 1 hour old.
- **Batch update** — After sending, updates all emailed users' `stageXNurtureEmailSentAt` timestamps in a single `User.update()` call.

## Usage Example

```bash
# Run as a Sails shell script
sails run deliver-nurture-emails
```

```javascript
// Email config keys required in sails.config.custom
{
  activityCaptureEmailForNutureEmails: 'capture@example.com',
  contactEmailForNutureEmails: 'outreach@example.com',
  contactNameForNurtureEmails: 'Jane from Acme',
}
```

## Notes

- The stage 4 email is intentionally commented out pending a Salesforce-based opt-out mechanism for per-contact nurture suppression.
- All emails use the `layout-nurture-email` layout and are BCC'd to the activity capture address for CRM tracking.
- Guard flags (`stageXNurtureEmailSentAt === 0`) ensure each nurture email is sent **at most once** per stage per user.
