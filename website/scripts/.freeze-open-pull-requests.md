Sails.js script that bulk-freezes open pull requests on the FleetDM repository by requesting changes on PRs whose authors are not pre-approved DRIs, with support for dry-run mode. **Currently disabled** — the active `fn` throws immediately; the original implementation is preserved in commented-out code.

## Key Components

| Element | Description |
|---|---|
| `dry` input | Boolean flag enabling dry-run mode (no actual API calls); defaults to `false` |
| `limit` input | Max number of open PRs to examine; defaults to `100` |
| `fn` | Throws `Error('Not currently in use.')` — script is intentionally inert |
| Commented implementation | Fetches open PRs via GitHub REST API, calls `getIsPrPreapproved` helper per PR, posts `REQUEST_CHANGES` review to non-pre-approved PRs |

## Usage Example

```bash
# Dry run (preview which PRs would be frozen)
sails_custom__githubAccessToken=YOUR_TOKEN_HERE sails run scripts/freeze-open-pull-requests.js --dry

# Live run (freeze up to 100 PRs)
sails_custom__githubAccessToken=YOUR_TOKEN_HERE sails run scripts/freeze-open-pull-requests.js --limit=100
```

## Notes

- Requires `sails.config.custom.githubAccessToken` (passed via environment variable)
- Pre-approval is determined by `sails.helpers.githubAutomations.getIsPrPreapproved` — PRs touching files where the author is the designated DRI are skipped
- Freeze message instructs maintainers they can dismiss the review manually in emergencies
- For historical context on why this was disabled, see the referenced [PR #5628 comment](https://github.com/fleetdm/fleet/pull/5628#issuecomment-1196175485)
