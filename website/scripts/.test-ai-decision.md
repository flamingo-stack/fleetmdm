Sails.js shell script that tests AI-powered content classification by filtering a list of social media posts using a decision function.

## Key Components

- **`posts`** — Sample dataset of three tweet objects, each with `id`, `author`, and `tweet` fields
- **`ƒ.simultaneouslyForEach`** — Runs AI classification concurrently across all posts
- **`ƒ.decide`** — AI decision helper that classifies each post against labeled criteria
- **`topPosts`** — Accumulated array of posts classified as "Top post"

## Usage Example

```bash
sails run test-ai-decision
```

```javascript
// Classification labels passed to ƒ.decide:
{
  'Top post': 'A social media post that is both (a) VERY interesting and (b) in reasonably good taste',
  'n/a': 'Anything else',
}

// Returns filtered posts where classification === 'Top post'
// e.g. [ { id: 1, author: 'mikermcneil', tweet: 'I fed this one stray cat...' } ]
```

## Notes

- Posts are classified **simultaneously** (not sequentially) for performance
- The `ƒ.decide` call sends each post object as context to the AI model, which returns one of the defined label strings
- Useful as a quick sanity check for the `ƒ.decide` helper behavior and prompt tuning
