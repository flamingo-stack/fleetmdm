Processes the Fleet standard query library YAML, using AI to generate PowerShell equivalents for Windows-targeted osquery SQL queries, then writes an updated YAML file.

## Key Components

- **`fn`** — Main async function that orchestrates reading, transforming, and writing the query library
- **Query filtering** — Skips non-`query` kind entries, non-Windows queries, and queries already having a `powershell` field
- **AI prompt** — Calls `sails.helpers.ai.prompt` with the `o3-mini-2025-01-31` model to convert osquery SQL into PowerShell scripts
- **Batch processing** — Chunks queries into groups of 5, processing each batch with `simultaneouslyForEach` for parallel AI calls
- **Output** — Writes results to `docs/new.queries.yml` in the repository root

## Usage Example

```javascript
// Run via Sails machine runner (e.g., sails run or custom script)
await sails.helpers.scripts.getPowershellCommandsAndRegenerateQueriesYaml();
```

## Notes

- Reads from `docs/01-Using-Fleet/standard-query-library/standard-query-library.yml` relative to the top-level repo path
- Queries already containing a `powershell` field are skipped to avoid redundant AI calls
- ⚠️ Output YAML (`docs/new.queries.yml`) does **not** preserve the original query order (noted as a `TODO` in the source)
- Requires the `yaml` npm package and configured `sails.helpers.ai.prompt`
