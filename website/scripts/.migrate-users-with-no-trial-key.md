One-time migration script that identifies qualifying users without a Fleet Premium trial license key, generates 30-day trial keys for them, and notifies them via email.

## Key Components

- **`dry` input** — Boolean flag to simulate the migration without writing to the database or sending emails
- **`idsOfUsersWithSubscriptions`** — Pre-fetched list of users with active paid subscriptions, used to skip already-paying customers
- **`User.stream()`** — Streams filtered users who have progressed past the "is-it-any-good" questionnaire step, excluding unsubscribed and non-interested users
- **`createLicenseKey` helper** — Generates a Fleet Premium trial key scoped to 10 hosts, expiring 30 days from execution
- **`User.updateOne()`** — Persists the new trial key and expiration timestamp to the user record
- **`sendTemplateEmail` helper** — Sends the `email-fleet-premium-trial` template to notify the user of their new trial

## Usage Example

```bash
# Dry run — no DB changes or emails sent
sails run migrate-users-with-no-trial-key --dry

# Live run — generates keys and sends emails
sails run migrate-users-with-no-trial-key
```

```javascript
// Filters applied to User.stream():
{
  lastSubmittedGetStartedQuestionnaireStep: { in: ['is-it-any-good', 'what-did-you-think', ...] },
  psychologicalStage: { '!=': '2 - Aware' },       // Skip opted-out users
  stageThreeNurtureEmailSentAt: { '!=': 1 },        // Skip unsubscribed users
}
```

> **Note:** Trial keys are valid for **30 days** and allow up to **10 hosts**. Users with an existing paid `Subscription` record are skipped regardless of other filters.
