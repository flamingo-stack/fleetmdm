A Sails.js shell script that tests AI-powered content weighting by scoring sample posts against defined topic categories.

## Key Components

- **`fn`** — Async function that runs the weight test against a hardcoded set of sample posts
- **`ƒ.simultaneouslyForEach`** — Parallel iteration over posts, returning enriched objects with scores
- **`ƒ.weigh`** — AI scoring utility that evaluates each post against multiple topic criteria
- **`scoresByTopic`** — Output field added to each post containing scores per topic label

## Usage Example

Run via the Sails CLI:

```bash
sails run test-ai-weights
```

Expected output shape:

```javascript
[
  {
    id: 1,
    author: 'mikermcneil',
    tweet: 'I fed this one stray cat...',
    scoresByTopic: {
      'related to cats': 0.95,
      'related to javascript': 0.02,
      'A social media post that is both (a) VERY interesting...': 0.78
    }
  },
  // ...
]
```

## Notes

- Sample posts cover three distinct topics: cats, JavaScript frameworks, and a mixed-content baseline
- Topics tested include relevance scoring and a compound quality filter ("interesting + good taste")
- The `ƒ` namespace suggests a custom helper/utility layer wrapping AI inference calls
- This is a development/debugging utility; not intended for production use
