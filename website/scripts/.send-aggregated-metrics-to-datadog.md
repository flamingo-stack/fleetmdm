Aggregates Fleet instance usage statistics from the past week and sends them as structured metrics to Datadog, filtering out development/test instances and combining data across Fleet Premium organizations and released Fleet versions.

## Key Components

- **Data Filtering** — Excludes sandbox, loadtest, development, and empty organization entries from raw `HistoricalUsageSnapshot` records
- **Premium Org Metrics** — Groups latest reports by organization and emits `usage_statistics.num_hosts_enrolled_by_org` gauge metrics per org with Fleet version tags
- **OS Version Metrics** — Merges `hostsEnrolledByOperatingSystem` arrays across all instances and emits `usage_statistics_v2.host_count_by_os_version` per OS/version pair
- **Osquery Version Metrics** — Aggregates `hostsEnrolledByOsqueryVersion` and emits `usage_statistics_v2.host_count_by_osquery_version`
- **Orbit Version Metrics** — Aggregates `hostsEnrolledByOrbitVersion` and emits `usage_statistics_v2.host_count_by_orbit_version`
- **Stored Error Metrics** — Combines `storedErrors` by location across instances and emits both `usage_statistics_v2.stored_errors_counts` and `usage_statistics_v2.stored_errors_statistics`

## Usage Example

```bash
# Run as a Sails shell script
sails run send-metrics-to-datadog
```

```javascript
// Datadog metric payload shape (type 3 = gauge)
{
  metric: 'usage_statistics_v2.host_count_by_os_version',
  type: 3,
  points: [{ timestamp: 1700000000, value: 142 }],
  resources: [{ name: 'macOS', type: 'os_type' }],
  tags: ['os_version_name:14.1.0'],
}
```

> Only Fleet instances reporting versions prefixed with `4.` are included in aggregated version-level metrics. Premium org host counts are computed before this filter to capture all paying customers regardless of version.
