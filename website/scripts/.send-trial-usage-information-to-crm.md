Reports recent usage statistics for Render trial instances to a CRM (Salesforce), querying active and recently expired trials and syncing user engagement data.

## Key Components

- **`reportAllHistoricalData`** *(input, boolean)* — When `true`, reports all historical Render trial records regardless of status. When omitted/`false`, limits scope to active trials and those expired within the last 24 hours.
- **`RenderProofOfValue`** — Model queried to retrieve Render trial instance records.
- **`HistoricalUsageSnapshot`** — Model queried for the most recent usage statistics per trial (searched by both `Render-trial-<slug>` and `<slug>` prefixes).
- **`updateOrCreateContactAndAccount`** — Salesforce helper invoked to sync trial usage details (status, user count, enrolled hosts, trial start/end dates) to the CRM.

## Usage Example

```bash
# Report only active and recently expired trials (default behavior)
sails run send-trial-usage-information-to-crm

# Report all historical Render trial data (run once on initial setup)
sails run send-trial-usage-information-to-crm --reportAllHistoricalData
```

## Behavior Notes

- **Skips** trial instances with no reported `HistoricalUsageSnapshot` records.
- **Skips** trials where the associated `User` record no longer exists (e.g., deleted accounts).
- **Skips** trials associated with `@fleetdm.com` email addresses to exclude internal users.
- All trials are processed concurrently via `sails.helpers.flow.simultaneouslyForEach`.
- CRM update errors are tolerated (logged as warnings) so one failure does not block the rest.
