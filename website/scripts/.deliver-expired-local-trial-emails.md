Sends expiration notification emails to FleetMDM.com users whose Fleet Premium local trial licenses expired within the past 24 hours, designed to be run as a daily scheduled script.

## Key Components

- **`fn`** — Main async function that queries recently expired trial users and dispatches notification emails
- **`usersWithRecentlyExpiredLocalTrials`** — Users filtered by `fleetPremiumTrialType: 'local trial'` and a license expiry timestamp within the last 24-hour window
- **`sendTemplateEmail`** — Sails helper used to deliver the `email-fleet-premium-local-trial-ended` template via the `layout-nurture-email` layout
- **`fleetPremiumTrialEmailSentAt`** — Guard field checked before sending to prevent duplicate emails; updated after successful dispatch

## Usage Example

```bash
# Run manually via Sails CLI
sails run deliver-expired-local-trial-emails

# Typical cron schedule (daily at 8am UTC)
0 8 * * * cd /app && sails run deliver-expired-local-trial-emails
```

## Behavior Notes

- Only sends to users where `fleetPremiumTrialEmailSentAt` is falsy, ensuring idempotency across retries
- Email send errors are tolerated with a `sails.log.warn` rather than halting the loop, allowing remaining users to be processed
- After a successful send, `fleetPremiumTrialEmailSentAt` is stamped on the user record via `User.updateOne`
