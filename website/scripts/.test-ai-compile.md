Sails.js shell script that tests the AI compilation system by generating code for three different goals using `ƒ.compile` and `sails.helpers.ai.compile`.

## Key Components

- **`fn`** — Async function that sequentially invokes the AI compiler with three distinct goal prompts and logs the generated output

## Goals Tested

| Goal | Description | Compile Target |
|------|-------------|----------------|
| `goal1` | Fibonacci sequence array | `helper` type |
| `goal2` | Signup form handler | default type |
| `goal3` | Fleet webhook handler with policy-fail email alerts | default type (via `sails.helpers.ai.compile`) |

## Usage Example

```bash
# Run from the Sails.js project root
sails run test-ai-compile
```

```javascript
// The script exercises two equivalent calling conventions:
await ƒ.compile(goal, 'helper');        // Shorthand global with explicit type
await ƒ.compile(goal);                   // Shorthand global, default type
await sails.helpers.ai.compile(goal);    // Full helper path, default type
```

## Notes

- Requires a running Sails.js environment with the `ai.compile` helper registered
- `ƒ.compile` is a Flamingo-specific global shorthand for `sails.helpers.ai.compile`
- `goal3` demonstrates a realistic MSP use case: mapping a Fleet-reported hostname to a user email via the Fleet API and sending an alert — reflecting [Flamingo's Fleet MDM integration](https://github.com/flamingo-stack/fleetmdm/blob/main/scripts/test-ai-compile.js)
