Sails.js shell script that deletes `HistoricalUsageSnapshot` database records older than 60 days, keeping usage statistics storage manageable.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `friendlyName` | `string` | Human-readable script name |
| `description` | `string` | Brief explanation of the script's behavior |
| `fn` | `async function` | Main execution logic |

### Core Logic

- Calculates a Unix timestamp for 60 days ago using `Date.now()`
- Executes a raw `DELETE` SQL query against the `historicalusagesnapshot` table
- Logs the number of deleted records via `queryResult.rowCount`

## Usage Example

Run directly via the Sails CLI:

```bash
sails run cleanup-old-usage-statistics
```

To automate, invoke on a schedule (e.g., via cron):

```bash
# Run daily at midnight
0 0 * * * cd /path/to/app && sails run cleanup-old-usage-statistics
```

## Notes

- Retention window is hardcoded to **60 days**; adjust the multiplier in `sixtyDaysAgoAt` to change the cutoff
- Uses `sails.sendNativeQuery` for direct SQL execution — ensure the database user has `DELETE` privileges on `historicalusagesnapshot`
- No dry-run mode; deletions are immediate and irreversible
