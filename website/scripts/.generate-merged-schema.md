Merges the base osquery schema with Fleet-specific table overrides and writes the combined result to a single JSON output file.

## Key Components

- **`fn`** – Async function that orchestrates schema merging and file output
- **`sails.helpers.getExtendedOsquerySchema()`** – Helper that fetches and merges the osquery base schema with Fleet's overrides from `/schema/tables/`
- **`sails.helpers.fs.writeJson`** – Writes the merged schema to `/schema/osquery_fleet_schema.json`, overwriting any existing file

## Usage Example

Run this as a Sails script from the project root:

```bash
sails run generate-merged-schema
```

The merged schema is saved to:

```text
/schema/osquery_fleet_schema.json
```

## Output

On success, logs a confirmation message with the resolved output path:

```text
osquery schema successfully merged with Fleet's overrides. The merged schema has been saved at /path/to/schema/osquery_fleet_schema.json
```

## Notes

- The output file is always **overwritten** (`force: true`) if it already exists
- Source overrides are read from `/schema/tables/` and merged via the `getExtendedOsquerySchema` helper
- The resolved output path is relative to the top-level repository root, not the Sails app directory
