A Sails.js shell script that migrates legacy `primaryBuyingSituation` user record values to their updated equivalents, with optional dry-run support.

## Key Components

- **`dry` input** — Boolean flag; when `true`, counts affected records without writing to the database
- **Migration mappings** — Four legacy values are remapped:

| Old Value | New Value | Notes |
|---|---|---|
| `mdm` | `it-major-mdm` | Defaults to `it-major-mdm`; upgrades to `it-gap-filler-mdm` if user previously selected Linux MDM in the get-started questionnaire |
| `eo-it` | `it-misc` | Flat remap |
| `eo-security` | `security-misc` | Flat remap |
| `vm` | `security-vm` | Flat remap |

- **`User.stream()`** — Streams matching records in batches to avoid loading all users into memory at once
- **Questionnaire check** — Inspects `getStartedQuestionnaireAnswers['what-do-you-manage-mdm'].mdmUseCase` to distinguish Linux MDM users during the `mdm` migration

## Usage Example

```bash
# Dry run — logs how many records would be updated, no DB changes
sails run migrate-old-primary-buying-situation-values --dry

# Live run — applies all updates
sails run migrate-old-primary-buying-situation-values
```
