Generates a bug and pull request report by querying the GitHub API for open/closed bugs and PRs in the `fleetdm/fleet` repository, computing age metrics, and summarizing activity over configurable time windows.

## Key Components

- **Open bug fetching** — Paginates through all open issues labeled `bug`, tracks age in days, flags bugs ≥32 days old, bugs opened in the past 7 days, and customer-reported bugs (labels containing `customer-`)
- **Closed bug fetching** — Retrieves the last 300 closed `bug` issues and filters for those closed within the past 7 days
- **Closed PR analysis** — Fetches the last 300 closed PRs, filters merged PRs from the past three weeks, then computes commit-to-merge time by fetching each PR's commit history
- **Open PR analysis** — Paginates through all open PRs to separate contributor PRs from internal ones, computing how long each has been open
- **Metrics arrays** — Populates `daysSinceBugsWereOpened`, `daysSinceUnprioritizedBugsWereOpened`, `commitToMergeTimesInDays`, `daysSincePullRequestsWereOpened`, and `daysSinceContributorPullRequestsWereOpened` for downstream averaging

## Usage Example

```bash
# Provide your GitHub personal access token at runtime
sails_custom__githubAccessToken=YOUR_PERSONAL_ACCESS_TOKEN sails run get-bug-and-pr-report
```

```javascript
// Or configure it in website/config/local.js
module.exports = {
  custom: {
    githubAccessToken: 'YOUR_PERSONAL_ACCESS_TOKEN',
  },
};
```

## Configuration Requirements

| Setting | Description |
|---|---|
| `sails.config.custom.githubAccessToken` | GitHub personal access token with `repo` read scope — required |

> **Note:** The script queries `fleetdm/fleet` directly via the GitHub REST API. All four data-fetching operations run simultaneously via `sails.helpers.flow.simultaneously`. Pagination stops automatically when fewer results than requested are returned (open bugs/PRs) or after 3 pages (closed bugs/PRs).
