A Sails.js custom script that introspects all configured routes and regenerates the browser-side Cloud SDK configuration file (`cloud.setup.js`) and a companion JSON file used in automated tests.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `friendlyName` | `string` | Display name: `"Rebuild Cloud SDK"` |
| `description` | `string` | Human-readable summary of the script's purpose |
| `fn` | `async function` | Main entry point — scans routes, builds endpoint maps, writes output files |

### Internal Logic

- **`endpointsByMethodName`** — Collects standard API endpoints (verb, URL, optional args, optional WebSocket protocol)
- **`extraEndpointsOnlyForTestsByMethodName`** — Collects view-serving routes excluded from the browser SDK but included in the test JSON
- **Route filtering** — Skips array targets (uses last sub-target), string redirects, targets without an `action`, and view-serving actions
- **Method naming** — Derived via `_.camelCase()` on the bare action name (last segment after `/`)
- **Actions2 support** — Reads `def.inputs` or `def.args` to populate positional argument lists
- **WebSocket detection** — Sets `protocol: 'io.socket'` when `target.isSocket` is truthy

### Output Files

| File | Purpose |
|------|---------|
| `assets/js/cloud.setup.js` | Browser SDK configuration consumed by `Cloud.setup()` |
| `test/private/CLOUD_SDK_METHODS.json` | Merged endpoint map for automated tests (written only if `test/` exists) |

## Usage Example

Run from the project root using the Sails CLI:

```bash
sails run rebuild-cloud-sdk
```

Or invoke programmatically within a Sails lift context:

```javascript
await sails.runBootstrap(async () => {
  await sails.runHelper('rebuild-cloud-sdk');
});
```

The generated `cloud.setup.js` will contain an entry like:

```javascript
Cloud.setup({
  methods: {
    "login": { "verb": "POST", "url": "/api/v1/entrance/login", "args": ["emailAddress", "password"] },
    "logout": { "verb": "DELETE", "url": "/api/v1/account/logout", "args": [] }
  }
});
```

> Re-run this script whenever routes or actions2 inputs change to keep the browser SDK in sync with the server.
