Generates HTML partials and metadata from Fleet repo source files (Markdown docs, YAML queries/policies), baking the processed content into `sails.config.builtStaticContent` for use across the Sails application.

## Key Components

### Inputs
- **`dry`** (`boolean`) — When `true`, skips writing to `.sailsrc` and skips HTML file generation
- **`githubAccessToken`** (`string`) — Optional GitHub token for authenticating API requests to fetch contributor profiles and validate usernames

### Primary Tasks (run simultaneously)

| Task | Source File | Output |
|---|---|---|
| Query library parsing | `docs/queries.yml` | `builtStaticContent.queries` |
| Policy library parsing | `docs/01-Using-Fleet/standard-query-library/standard-query-library.yml` | `builtStaticContent.policies` (policies only, queries filtered out) |

### Query Processing Pipeline

1. **YAML parsing** — Reads and parses multi-document YAML using the `yaml` package
2. **Slug generation** — Creates URL-safe slugs via `_.kebabCase(query.name)`
3. **Line number tracking** — Locates each query's line in the YAML file for direct-edit linking
4. **Platform suffix stripping** — Removes `(macOS)`, `(Windows)`, `(Linux)`, etc. from display names
5. **Tag normalization** — Splits comma-separated tags, trims whitespace, lowercases, deduplicates
6. **Contributor validation & enrichment** — Validates GitHub usernames against the GitHub Users API (when token provided), then attaches `name`, `handle`, `avatarUrl`, and `htmlUrl` per contributor

### Validation Errors Thrown

- Duplicate query slugs
- Invalid `discovery` field format or placement
- Malformed `tags` (non-string)
- Invalid GitHub usernames in `contributors`

## Usage Example

```bash
# Dry run (no files written)
sails run build-static-content --dry

# With GitHub token for contributor enrichment
sails run build-static-content --githubAccessToken=ghp_yourTokenHere
```

```javascript
// Accessing built content after compilation
sails.config.builtStaticContent.queries       // Enriched query objects
sails.config.builtStaticContent.queryLibraryYmlRepoPath  // Relative repo path
```

> **Note:** Without a GitHub token, contributor profiles use placeholder data (kitten avatars, username as display name). The script logs a warning and skips GitHub API validation.
