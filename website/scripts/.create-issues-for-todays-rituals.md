Sails.js script that automatically creates GitHub issues for scheduled rituals based on their configured frequency and start date.

## Key Components

- **`dry`** input — Boolean flag to preview issue creation without making API calls
- **Frequency parsing** — Converts ritual frequencies (`Daily`, `Weekly`, `Biweekly`, `Triweekly`, `Monthly`, `Quarterly`, `Annually`) into milliseconds for scheduling calculations
- **Timing logic** — Compares each ritual's cycle against the current UTC date to determine if an issue is due within the current run window
- **Monthly/Annual special cases** — Handles edge cases like short months (e.g., a ritual started on Jan 31 triggers on Feb 28/29) and exact anniversary matching
- **GitHub Issues API** — Posts to `https://api.github.com/repos/{owner}/{repo}/issues` with title, body, labels, and assignee

## Usage Example

```bash
# Standard run — creates issues for rituals due today
sails run create-issues-for-todays-rituals

# Dry run — logs what would be created without hitting the GitHub API
sails run create-issues-for-todays-rituals --dry
```

```javascript
// Ritual config shape expected in sails.config.builtStaticContent.rituals
{
  task: 'Weekly sync',
  frequency: 'Weekly',          // Daily | Weekly | Biweekly | Triweekly | Monthly | Quarterly | Annually
  startedOn: '2024-01-15',
  dri: 'github-username',
  description: 'Team sync meeting',
  moreInfoUrl: 'https://example.com',
  autoIssue: {
    repo: 'fleet',
    labels: ['ritual', ':culture'],
    issueDescription: 'Optional override body text'
  }
}
```

## Prerequisites

- `sails.config.custom.githubAccessToken` must be set
- `sails run build-static-content` must be run before this script to populate `sails.config.builtStaticContent.rituals`
