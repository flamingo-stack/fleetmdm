Provisions and manages a pool of Fleet Premium trial instances on Render, creating database records, Redis services, MySQL services, and associated infrastructure for eligible users signing up at fleetdm.com.

## Key Components

- **`RenderProofOfValue` model** — Database model tracking instance lifecycle (statuses: `record created`, `provisioning`, `ready for assignment`)
- **Pool size management** — Calculates how many new instances to provision based on `renderInstancePoolSize` config vs. existing ready/in-progress records
- **Slug generation** — Uses `gpt-5-nano` to generate unique two-word hyphenated slugs (e.g., `bumbling-bumblesaur`) with `E_UNIQUE` retry logic
- **Render API integration** — Sequentially creates per-instance:
  - Render **Project** (via `POST /v1/projects`)
  - **Redis** service (`starter` plan, `allkeys-lru` eviction policy)
  - **MySQL** service (auto-generated root/user passwords)
- **Error isolation** — Errors are stored in `errorReportById` per instance, preventing one failure from halting the full pool provisioning loop

## Required Config Values

| Config Key | Description |
|---|---|
| `renderOwnerId` | Render account owner ID |
| `renderApiToken` | Render API bearer token |
| `renderInstancePoolSize` | Target number of ready instances |
| `renderInstanceSesSecretId` | AWS SES secret ID for email |
| `renderInstanceSesSecretKey` | AWS SES secret key for email |

## Usage Example

```bash
# Run via Sails shell script runner
sails run manage-fleet-premium-trial-instances
```

```javascript
// Triggered automatically; pool size controlled via config
sails.config.custom.renderInstancePoolSize = 5; // Maintain 5 ready instances
```
