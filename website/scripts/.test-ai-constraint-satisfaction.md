A Sails.js shell script that tests AI-driven constraint satisfaction by rearranging a wedding seating chart according to specified rules and modifications.

## Key Components

- **`seatingChart`** — Sample data object representing three named tables (`elevenTop1`, `elevenTop2`, `tenTop4`) populated with married-couple guest pairs
- **`ƒ.satisfy()`** — AI constraint satisfaction call that accepts current state, constraint rules, and requested modifications, returning a recomputed result

## Usage Example

```bash
sails run test-ai-constraint-satisfaction
```

```javascript
// ƒ.satisfy(currentState, constraints, modifications)
let newSeatingChart = await ƒ.satisfy(seatingChart, [
  'People with the same last name are married and should sit together.',
  'No table can have fewer than 8 people seated at it.'
], [
  'Add another, special 2-person table for the bride and groom, Ally and Andrew Peterson, and move them to it'
]);
```

The function takes three arguments:

| Argument | Type | Description |
|---|---|---|
| `seatingChart` | Object | Current state to be optimized |
| Constraints | Array | Rules that must be satisfied |
| Modifications | Array | Explicit changes to apply |

## Notes

- Relies on the global `ƒ.satisfy()` helper provided by the Flamingo/OpenFrame AI layer
- `description` is intentionally left empty — this is a developer test/scratch script
- The `seatingChart` object is truncated (`//…etc`) indicating it serves as a minimal reproducible example
