Converts a Markdown article from the Fleet repo's `articles/` folder into an HTML email partial (`.ejs` file) for the Fleet newsletter, handling cleanup of unsupported elements and resolution of relative links.

## Key Components

- **`articleFilename`** *(input)* — The Markdown filename to convert; the `.md` extension is optional and will be appended automatically if omitted.
- **Sanitization** — Strips `<meta>` tags and removes `<iframe>` elements with a logged warning before conversion.
- **`sails.helpers.strings.toHtmlEmail`** — Converts the sanitized Markdown string to HTML.
- **Relative link resolution** — Rewrites `./` and `../` href values to absolute `https://fleetdm.com/` URLs, preserving anchor hashes.
- **Output** — Saves the rendered HTML as an `.ejs` partial to `views/emails/newsletter/email-article-<filename>.ejs`, replacing any previously generated file.

## Usage Example

```javascript
// Run via Sails machine runner (e.g., from a script or shell command)
await sails.helpers.scripts.generateHtmlEmailFromArticle.with({
  articleFilename: 'fleet-4-osquery-management'
  // .md extension is optional; will be appended automatically
});

// Output file will be written to:
// website/views/emails/newsletter/email-article-fleet-4-osquery-management.ejs
```

## Notes

- The script resolves the top-level repo path one directory above `sails.config.appPath`, assuming the standard Fleet monorepo layout.
- Dots in the article filename are replaced with hyphens in the output filename to avoid extension ambiguity.
- Relative link conversion lowercases path segments and strips leading numeric prefixes (e.g., `01-intro` → `intro`) to match fleetdm.com URL conventions. See [fleet#706](https://github.com/flamingo-stack/fleetmdm/issues/706) for background.
