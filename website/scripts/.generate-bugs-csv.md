Generates a categorized CSV report of open bug issues from the `fleetdm/fleet` GitHub repository, grouped by `bug-*` label with counts and average open time in days.

## Key Components

- **GitHub API pagination** — Iterates through all pages of open issues labeled `bug` using `sails.helpers.flow.until`
- **Bug category grouping** — Filters issues by labels prefixed with `bug-` and groups them into a categorized object
- **CSV generation** — Produces a three-column CSV: `Bug category`, `Number of open issues`, `Average open time` (in days)
- **Auth guard** — Throws early if `sails.config.custom.githubAccessToken` is not configured

## Usage Example

```bash
# Set your GitHub token and run the script via Sails
sails_custom__githubAccessToken=YOUR_PERSONAL_ACCESS_TOKEN sails run generate-bugs-csv
```

```javascript
// Or configure the token in website/config/local.js
module.exports = {
  custom: {
    githubAccessToken: 'YOUR_PERSONAL_ACCESS_TOKEN',
  },
};
// Then run:
// sails run generate-bugs-csv
```

The script logs a CSV to the console in the format:

```text
Bug category,Number of open issues,Average open time
bug-critical,12,14
bug-unreported,5,30
```

> **Note:** Requires a valid GitHub personal access token with `repo` read access. Configure it via `sails.config.custom.githubAccessToken` before running.
