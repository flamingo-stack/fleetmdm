A Sails.js shell script that tests the `ƒ.improvePrompt` AI utility by submitting a classification prompt against sample tweet data and logging results at varying invocation counts.

## Key Components

- **`prompt1`** — A structured classification prompt containing three sample tweets and two decision choices, asking an AI model to identify socially interesting content
- **`ƒ.improvePrompt`** — External AI utility being tested; called three times with the same prompt (intended to test behavior across multiple invocations)

## Usage Example

```bash
sails run test-ai-improve-prompt
```

Running the script produces console output from three sequential calls to `ƒ.improvePrompt`:

```javascript
// Internal prompt structure (abbreviated)
let prompt1 = (
  'Given some data and a set of possible choices, decide which choice most accurately classifies the data. Data: ```\n' +
  JSON.stringify([{ id: 1, author: 'mikermcneil', tweet: '...' }, ...]) +
  '```\n\nChoices:\n' +
  ' • A social media post that is both (a) VERY interesting and (b) in reasonably good taste\n' +
  ' • Anything else\n'
);

sails.log(await ƒ.improvePrompt(prompt1));    // Call 1
sails.log(await ƒ.improvePrompt(prompt1), 2); // Call 2 (second arg logged separately)
sails.log(await ƒ.improvePrompt(prompt1), 5); // Call 3 (second arg logged separately)
```

> **Note:** The numeric arguments (`2`, `5`) in calls 2 and 3 are passed as additional arguments to `sails.log`, not to `ƒ.improvePrompt` itself — likely a bug in the test script.
