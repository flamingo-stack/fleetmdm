Defines the `CertificateSigningRequest` Sails.js ORM model, representing database records for certificate signing requests submitted by organizations.

## Key Components

| Attribute | Type | Description |
|---|---|---|
| `organization` | `string` (required) | The organization that requested a signed certificate |
| `emailAddress` | `string` (required, email) | The email address of the user who submitted the request |

## Usage Example

```javascript
// Create a new certificate signing request record
await CertificateSigningRequest.create({
  organization: 'Acme Corp',
  emailAddress: 'admin@acmecorp.com',
});

// Find all requests for a specific organization
const requests = await CertificateSigningRequest.find({
  organization: 'Acme Corp',
});
```

## Notes

- The `emailAddress` field is validated using Sails.js built-in `isEmail` validator
- No associations (embeds or associations sections are empty)
- Follows standard [Sails.js model conventions](https://sailsjs.com/docs/concepts/models-and-orm/models)
