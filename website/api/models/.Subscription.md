Sails.js model definition for storing Fleet Premium subscription data, including billing details, host limits, pricing, and Stripe integration.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `nextBillingAt` | `number` | JS timestamp of the next billing date |
| `numberOfHosts` | `number` | Host count the subscription covers |
| `subscriptionPrice` | `number` | Price of the Fleet Premium subscription |
| `stripeSubscriptionId` | `string` | Stripe identifier for the subscription |
| `fleetLicenseKey` | `string` | Fleet Premium license key (optional) |

### Associations

| Association | Model | Description |
|---|---|---|
| `user` | `User` | The user who owns this subscription |

## Usage Example

```javascript
// Create a new subscription record
await Subscription.create({
  nextBillingAt: Date.now() + (30 * 24 * 60 * 60 * 1000), // 30 days from now
  numberOfHosts: 100,
  subscriptionPrice: 499,
  stripeSubscriptionId: 'sub_1ABC123xyz',
  fleetLicenseKey: '1234 1234 1234 1234 1234',
  user: userId,
});

// Find a subscription by Stripe ID
const subscription = await Subscription.findOne({
  stripeSubscriptionId: 'sub_1ABC123xyz'
}).populate('user');
```

## Notes

- `fleetLicenseKey` is the only optional attribute; all others are required.
- `nextBillingAt` uses a JavaScript Unix timestamp (milliseconds).
