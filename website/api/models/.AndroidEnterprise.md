Sails.js ORM model definition for persisting Android Enterprise enrollment data, linking Fleet MDM server instances to their corresponding Google Android Enterprise configurations.

## Key Components

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `fleetServerUrl` | `string` | URL of the Fleet server; unique, required |
| `fleetLicenseKey` | `string` | License key for the associated Fleet server |
| `fleetServerSecret` | `string` | Randomly generated secret for authenticating proxy endpoint requests post-setup |
| `androidEnterpriseId` | `string` | Google's unique ID for the Android enterprise; unique, required |
| `pubsubTopicName` | `string` | Pub/Sub topic name created for this enterprise (retained for cleanup on deletion) |
| `pubsubSubscriptionName` | `string` | Pub/Sub subscription name associated with the topic (retained for cleanup on deletion) |

## Usage Example

```javascript
// Create a new Android Enterprise record
await AndroidEnterprise.create({
  fleetServerUrl: 'https://fleet.example.com',
  fleetLicenseKey: 'fleet-license-abc123',
  fleetServerSecret: 'randomly-generated-secret',
  androidEnterpriseId: 'LC04xxxxxx',
  pubsubTopicName: 'projects/my-project/topics/android-enterprise-topic',
  pubsubSubscriptionName: 'projects/my-project/subscriptions/android-enterprise-sub',
});

// Look up an enterprise by Fleet server URL
const enterprise = await AndroidEnterprise.findOne({
  fleetServerUrl: 'https://fleet.example.com'
});
```

## Notes

- `pubsubTopicName` and `pubsubSubscriptionName` are stored solely to support cleanup when an Android Enterprise is deleted.
- `fleetServerUrl` and `androidEnterpriseId` are both marked `unique`, enforcing one enterprise record per Fleet server and one record per Google enterprise ID.
