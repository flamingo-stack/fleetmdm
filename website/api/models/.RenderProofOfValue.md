Sails.js model definition for managing Fleet MDM "Proof of Value" instances provisioned on Render.com, tracking their lifecycle from creation through expiration.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `status` | `string` | Lifecycle state — one of `record created`, `provisioning`, `ready for assignment`, `in use`, `expired` |
| `slug` | `string` | Unique human-readable identifier for the Render instance (e.g. `bumbling-bulbasaur`) |
| `instanceUrl` | `string` | Full public URL of the provisioned Fleet instance |
| `renderProjectId` | `string` | Render.com project ID |
| `renderMySqlServiceId` | `string` | Render MySQL service ID |
| `renderRedisServiceId` | `string` | Render Redis service ID |
| `renderFleetServiceId` | `string` | Render Fleet service ID |
| `renderTrialEndsAt` | `number` | JS timestamp for when the Render instance will be deleted |

### Associations

| Association | Model | Description |
|---|---|---|
| `user` | `User` | Optional — assigned user (instances may exist in a pool without a user) |

## Usage Example

```javascript
// Create a new POV record in the provisioning pool
const pov = await RenderProofOfValue.create({
  slug: 'bumbling-bulbasaur',
  status: 'record created',
}).fetch();

// Assign a provisioned instance to a user
await RenderProofOfValue.updateOne({ slug: 'bumbling-bulbasaur' }).set({
  status: 'in use',
  user: userId,
  instanceUrl: 'https://bumbling-bulbasaur.onrender.com',
});

// Find all instances ready for assignment
const available = await RenderProofOfValue.find({ status: 'ready for assignment' });
```

## Notes

- Instances are pre-provisioned into a **pool** before user assignment — the `user` association is intentionally optional to support this pattern.
- The `slug` field is **unique** and **required**, serving as the primary human-readable key.
- `renderTrialEndsAt` should be monitored to trigger cleanup of expired instances.
