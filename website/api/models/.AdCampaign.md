Defines the `AdCampaign` Sails.js ORM model, representing a LinkedIn advertising campaign record tied to a specific audience persona.

## Key Components

| Attribute | Type | Description |
|-----------|------|-------------|
| `persona` | `string` | Audience persona identifier (e.g., `elf.it-major-mdm`); constrained via `isIn` allowlist |
| `name` | `string` | Human-readable campaign name, typically including persona and timestamp |
| `linkedinCampaignUrn` | `string` | LinkedIn sponsored campaign URN (e.g., `urn:li:sponsoredCampaign:379399199`) |
| `isLatest` | `boolean` | Flags whether this is the active/current campaign for the given persona |
| `linkedinCompanyIds` | `json` | Array of LinkedIn company IDs targeted by this campaign; defaults to `[]` |

## Usage Example

```javascript
// Create a new ad campaign record
await AdCampaign.create({
  persona: 'elf.it-major-mdm',
  name: 'elf.it-major-mdm - 2024-02-24 @ 6:11pm',
  linkedinCampaignUrn: 'urn:li:sponsoredCampaign:379399199',
  isLatest: true,
  linkedinCompanyIds: [8482494, 28328],
});

// Find the latest campaign for a given persona
const latestCampaign = await AdCampaign.findOne({
  persona: 'elf.it-major-mdm',
  isLatest: true,
});
```

## Notes

- Only `elf.it-major-mdm` is currently active in the `persona` allowlist; other persona values are commented out and reserved for future use.
- No associations are defined on this model.
