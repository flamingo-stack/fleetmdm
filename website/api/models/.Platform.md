Sails.js ORM model definition for storing singleton platform-level configuration used to manage GitHub PR merge freeze bypass state.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `currentUnfrozenGitHubPrNumbers` | `json` | **Required.** Array of PR numbers permitted to bypass MergeFreeze in the `fleetdm/fleet` GitHub repository. |

## Usage Example

```javascript
// Fetch the current platform record
const platform = await Platform.findOne();

// Check if a specific PR can bypass MergeFreeze
const prNumber = 13638;
const canBypass = platform.currentUnfrozenGitHubPrNumbers.includes(prNumber);

// Update the list of unfrozen PRs
await Platform.updateOne({ id: platform.id }).set({
  currentUnfrozenGitHubPrNumbers: [13638, 13447, 13673],
});
```

## Notes

- This model is intended as a **singleton** — only one record should exist at a time.
- No associations or embedded records are defined; all state is stored in the single `json` attribute.
- Follows standard [Sails.js model conventions](https://sailsjs.com/docs/concepts/models-and-orm/models).
