A Sails.js ORM model definition that captures anonymized telemetry snapshots of Fleet MDM deployment usage metrics for historical tracking and analytics.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `anonymousIdentifier` | `string` | Hashed identifier for the Fleet deployment |
| `fleetVersion` | `string` | Fleet version string (e.g. `x.x.x`) |
| `licenseTier` | `string` | License level (e.g. `free`) |
| `numHostsEnrolled` | `number` | Total enrolled hosts (integer, min 0) |
| `hostsEnrolledByOperatingSystem` | `json` | Host counts grouped by OS |
| `hostsEnrolledByOrbitVersion` | `json` | Host counts grouped by Orbit version |
| `hostsEnrolledByOsqueryVersion` | `json` | Host counts grouped by Osquery version |
| `storedErrors` | `json` | Stored error records |
| `numHostsNotResponding` | `number` | Hosts that haven't submitted distributed query results in the last 2-hour window |
| `fleetMaintainedAppsMacOS` / `fleetMaintainedAppsWindows` | `json` | Fleet-managed app inventories per platform |
| `gitOpsModeEnabled` / `gitOpsModeExceptions` | `boolean` / `json` | GitOps configuration state |

Feature flags and counters also tracked: MDM (macOS/Windows), AI features, maintenance windows, conditional access (Okta/Entra), live query, host expiry, software CVEs/CPEs, and Fleet Desktop enrollment.

## Usage Example

```javascript
// Create a new snapshot record
await HistoricalUsageSnapshot.create({
  anonymousIdentifier: '9pnzNmrES3mQG66UQtd29cYTiX2+fZ4CYxDvh495720=',
  fleetVersion: '4.50.0',
  licenseTier: 'premium',
  numHostsEnrolled: 1200,
  numUsers: 45,
  numTeams: 6,
  numPolicies: 30,
  numLabels: 12,
  softwareInventoryEnabled: true,
  vulnDetectionEnabled: true,
  systemUsersEnabled: false,
  hostsStatusWebHookEnabled: true,
  numWeeklyActiveUsers: 18,
  numWeeklyPolicyViolationDaysActual: 3,
  numWeeklyPolicyViolationDaysPossible: 7,
  hostsEnrolledByOperatingSystem: { darwin: 800, windows: 300, linux: 100 },
  hostsEnrolledByOrbitVersion: { '1.22.0': 950 },
  hostsEnrolledByOsqueryVersion: { '5.11.0': 1200 },
  storedErrors: [],
  numHostsNotResponding: 4,
  organization: 'acme-corp',
  // ... additional required fields
});

// Query recent snapshots for an org
const snapshots = await HistoricalUsageSnapshot.find({ organization: 'acme-corp' })
  .sort('createdAt DESC')
  .limit(10);
```

## Notes

- All fields are **required** with no optional attributes
- `numHostsEnrolled` enforces integer validation via a custom validator
- No explicit associations (embeds/associations sections are empty)
