Sails.js model representing a Vanta customer connection, storing authentication credentials and configuration needed to sync Fleet device data with the Vanta compliance platform.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `emailAddress` | `string` | Contact email for the connection creator; validated as email format |
| `vantaSourceId` | `string` | Unique identifier for this connection within Vanta |
| `fleetInstanceUrl` | `string` | Full URL of the connected Fleet instance (unique per connection) |
| `fleetApiKey` | `string` | Admin-level API-only token for authenticating Fleet requests |
| `vantaAuthToken` | `string` | OAuth token authorizing data pushes to Vanta on behalf of the customer |
| `vantaAuthTokenExpiresAt` | `number` | JS timestamp indicating when `vantaAuthToken` expires |
| `vantaRefreshToken` | `string` | Token used to obtain new `vantaAuthToken` values |
| `isConnectedToVanta` | `boolean` | Connection status flag; defaults to `false`; when `true`, data sync is active |

## Usage Example

```javascript
// Create a new Vanta connection record
const connection = await VantaConnection.create({
  emailAddress: 'admin@example.com',
  vantaSourceId: 'vanta-src-abc123',
  fleetInstanceUrl: 'https://fleet.example.com',
  fleetApiKey: 'fleetApiKeyToken',
}).fetch();

// Mark connection as authorized after OAuth flow completes
await VantaConnection.updateOne({ vantaSourceId: 'vanta-src-abc123' })
  .set({
    vantaAuthToken: 'newAuthToken',
    vantaAuthTokenExpiresAt: Date.now() + 3600000,
    vantaRefreshToken: 'refreshToken',
    isConnectedToVanta: true,
  });

// Find all active connections for the data sync script
const activeConnections = await VantaConnection.find({
  isConnectedToVanta: true,
});
```

## Notes

- `fleetApiKey` must belong to an **API-only user** with **admin privileges** on the Fleet instance.
- Only connections with `isConnectedToVanta: true` are included in the `send-data-to-vanta` sync script.
- Both `fleetInstanceUrl` and `vantaSourceId` are enforced as unique across records.
