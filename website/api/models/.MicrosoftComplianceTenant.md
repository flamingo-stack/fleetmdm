Sails.js model definition for storing and managing Microsoft compliance tenant records, linking Fleet instances to Microsoft Entra tenants for device compliance partner integration.

## Key Components

| Attribute | Type | Description |
|---|---|---|
| `fleetServerSecret` | `string` | API token for authenticating requests from the Fleet server |
| `entraTenantId` | `string` | Unique Microsoft Entra tenant identifier (required) |
| `fleetInstanceUrl` | `string` | URL of the connected Fleet instance (required, unique) |
| `setupCompleted` | `boolean` | Tracks whether the compliance partner app has been fully provisioned |
| `lastHeartbeatAt` | `string` | Epoch MS timestamp of the last received heartbeat |
| `adminConsented` | `boolean` | Indicates if an Intune admin has granted consent for Fleet as a compliance partner |
| `stateTokenForAdminConsent` | `string` | Token used to validate admin consent webhook requests |
| `setupError` | `string` | Last Microsoft API error encountered during setup |

## Usage Example

```javascript
// Create a new compliance tenant record
await MicrosoftComplianceTenant.create({
  entraTenantId: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  fleetInstanceUrl: 'https://fleet.example.com',
  stateTokenForAdminConsent: 'generated-state-token',
});

// Mark setup as complete after provisioning
await MicrosoftComplianceTenant.updateOne({ entraTenantId: tenantId })
  .set({ setupCompleted: true, adminConsented: true });

// Update heartbeat timestamp
await MicrosoftComplianceTenant.updateOne({ entraTenantId: tenantId })
  .set({ lastHeartbeatAt: String(Date.now()) });
```

## Notes

- `entraTenantId` and `fleetInstanceUrl` are both **unique** and **required**, enforcing one-to-one Fleet–Entra tenant mappings.
- `adminConsented` is used **only during initial setup** and is not relevant post-provisioning.
- `setupError` captures the last Microsoft API error, useful for debugging failed provisioning flows.
