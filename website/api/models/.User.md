Sails.js ORM model defining the `User` entity for the FleetDM web application, including authentication, billing, email verification, and onboarding questionnaire attributes.

## Key Components

| Attribute | Type | Description |
|---|---|---|
| `emailAddress` | `string` | Unique, validated user email (max 200 chars) |
| `emailStatus` | `string` | Email confirmation state: `unconfirmed`, `change-requested`, or `confirmed` |
| `emailChangeCandidate` | `string` | Pending new email address awaiting confirmation |
| `password` | `string` | Bcrypt-hashed password (`protect: true` — excluded from responses) |
| `firstName` / `lastName` | `string` | Required name fields (max 120 chars) |
| `isSuperAdmin` | `boolean` | Grants elevated permissions |
| `passwordResetToken` | `string` | Single-use token for password recovery |
| `emailProofToken` | `string` | Token for email verification flows |
| `stripeCustomerId` | `string` | Linked Stripe customer ID (`protect: true`) |
| `hasBillingCard` | `boolean` | Whether a default payment method is attached in Stripe |
| `billingCard*` | `string` | PCI-safe card metadata (brand, last4, expMonth, expYear) from Stripe |
| `fleetSandboxURL` | `string` | Provisioned Fleet sandbox instance URL (legacy, pre-Oct 2023) |
| `primaryBuyingSituation` | `string` | Onboarding segmentation value (e.g. `mdm`, `security-vm`) |
| `psychologicalStage` | `string` | Sales funnel stage (`1 - Unaware` through `6 - Has team buy-in`) |
| `getStartedQuestionnaireAnswers` | `json` | Free-form answers from the onboarding questionnaire |
| `fleetPremiumTrialLicenseKey` | `string` | Generated Fleet Premium trial license key |
| `canUseQueryGenerator` | `boolean` | Feature flag for query generator page access |

## Usage Example

```javascript
// Create a new user record via Sails.js model
const newUser = await User.create({
  emailAddress: 'mary.sue@example.com',
  password: await sails.helpers.passwords.hashPassword('supersecret'),
  firstName: 'Mary',
  lastName: 'Sue',
  emailStatus: 'unconfirmed',
  primaryBuyingSituation: 'it-major-mdm',
  psychologicalStage: '2 - Aware',
}).fetch();

// Query a confirmed user by email
const user = await User.findOne({
  emailAddress: 'mary.sue@example.com',
  emailStatus: 'confirmed',
});
```
