Sails.js ORM model definition for managing newsletter email subscriptions, tracking subscription preferences per email address.

## Key Components

| Attribute | Type | Description |
|---|---|---|
| `emailAddress` | `string` | Unique, validated email address (required, max 200 chars) |
| `isUnsubscribedFromAll` | `boolean` | Global unsubscribe flag for all current and future newsletters |
| `isSubscribedToReleases` | `boolean` | Opt-in for release posts and security update emails |

## Usage Example

```javascript
// Create a new subscription
await NewsletterSubscription.create({
  emailAddress: 'user@example.com',
  isSubscribedToReleases: true,
});

// Unsubscribe a user from all newsletters
await NewsletterSubscription.updateOne({ emailAddress: 'user@example.com' })
  .set({ isUnsubscribedFromAll: true });

// Find active release subscribers
const releaseSubscribers = await NewsletterSubscription.find({
  isSubscribedToReleases: true,
  isUnsubscribedFromAll: false,
});
```

## Notes

- `emailAddress` is enforced as unique at the database level — duplicate subscriptions are rejected automatically.
- Several category-specific subscription flags (product, engineering, security, guides, announcements, deployment, podcast) are commented out, indicating planned but not yet active segmentation.
- The model has no explicit associations or embed definitions; it operates as a standalone collection.
