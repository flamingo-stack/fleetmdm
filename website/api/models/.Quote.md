Sails.js model definition for storing Fleet Premium license quotes generated by users, capturing the host count, quoted price, and associated organization at the time of quote creation.

## Key Components

### Attributes

| Attribute | Type | Description |
|---|---|---|
| `organization` | `string` | Organization name entered by the user at quote time (max 120 chars) |
| `numberOfHosts` | `number` | Number of hosts the user wants to license *(required)* |
| `quotedPrice` | `number` | Fleet Premium license price quoted to the user *(required)* |

### Associations

| Association | Model | Description |
|---|---|---|
| `user` | `User` | The user who generated the quote *(required)* |

## Usage Example

```javascript
// Create a new quote record
const quote = await Quote.create({
  organization: 'Acme Corp',
  numberOfHosts: 500,
  quotedPrice: 4999.00,
  user: req.me.id,
}).fetch();

// Find all quotes for a specific user
const userQuotes = await Quote.find({ user: req.me.id })
  .sort('createdAt DESC');

// Find quotes by organization
const orgQuotes = await Quote.find({ organization: 'Acme Corp' })
  .populate('user');
```

## Notes

- `organization` is stored independently from the user's current organization, preserving the org name **at the time the quote was generated**
- All quote records require both a `user` association and `numberOfHosts`/`quotedPrice` values
- See the [Sails.js model docs](https://sailsjs.com/docs/concepts/models-and-orm/models) for ORM usage patterns
