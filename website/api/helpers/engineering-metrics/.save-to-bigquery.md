Sails.js helper that inserts a single data record into a specified Google BigQuery table within the `github_metrics` dataset using a GCP service account for authentication.

## Key Components

| Element | Description |
|---|---|
| `data` | The record object to insert into BigQuery (required) |
| `gcpServiceAccountKey` | GCP service account credentials object, used for project ID and auth (required) |
| `tableId` | Target table name within the `github_metrics` dataset (required) |
| `fn` | Async function that authenticates with BigQuery and calls `table.insert()` |

**Error handling** covers three specific BigQuery failure cases:
- `PartialFailureError` — one or more rows failed to insert
- `404` — table or dataset not found
- `403` — insufficient service account permissions

Known `tableId` values with named error messages: `issue_qa_ready`, `issue_release_ready`, `issue_status_change`.

## Usage Example

```javascript
await sails.helpers.saveToBigquery.with({
  data: {
    issue_number: 42,
    repo: 'flamingo-stack/fleetmdm',
    status: 'qa_ready',
    timestamp: new Date().toISOString()
  },
  gcpServiceAccountKey: {
    project_id: 'my-gcp-project',
    client_email: 'sa@my-gcp-project.iam.gserviceaccount.com',
    private_key: '-----BEGIN PRIVATE KEY-----\n...'
  },
  tableId: 'issue_qa_ready'
});
```

> **Note:** The target dataset is hardcoded as `github_metrics`. Ensure the table exists in that dataset before calling this helper, or a `404` error will be thrown.
