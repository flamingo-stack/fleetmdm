Sails.js helper that merges the raw osquery table schema from the osquery/osquery-site GitHub repository with Fleet's local YAML overrides, returning an extended, Fleet-enriched schema for documentation generation.

## Key Components

- **`includeLastModifiedAtValue`** (input, boolean) — When `true`, fetches the last commit timestamp from the GitHub API for osquery schema files and uses `git log` for local Fleet YAML overrides.
- **`githubAccessToken`** (input, string) — Optional GitHub personal access token for authenticated API requests to avoid rate limiting.
- **`rawOsqueryTables`** — Fetched from `osquery/osquery-site` at the version specified by `sails.config.custom.versionOfOsquerySchemaToUseWhenGeneratingDocumentation`.
- **`fleetOverridesForTables`** — Parsed from `.yml` files in `/schema/tables/` relative to the repo root. Each file must have a `name` property.
- **`expandedTables`** (output array) — The merged result. For each osquery table, Fleet overrides (platforms, description, examples, columns, notes, etc.) are applied if a matching YAML file exists; otherwise the raw table is used with Fleet-specific URL generation.

### Merge Behavior

- Tables **without** a Fleet override get a generated `fleetRepoUrl` linking to GitHub's new-file UI with a sample YAML template, and their URL is rewritten to `https://fleetdm.com/tables/<name>`.
- Tables **with** a Fleet override have individual fields (`platforms`, `description`, `examples`, `columns`, `notes`) selectively overridden; invalid types throw descriptive errors.
- Tables ending in `_events` are automatically set to `evented: true`.
- The last example from the osquery schema array is used when no override example exists, wrapped in a Markdown code fence.

## Usage Example

```javascript
// Called internally by Fleet's documentation build pipeline (Sails.js helper)
let extendedTables = await sails.helpers.getExtendedOsquerySchema.with({
  includeLastModifiedAtValue: true,
  githubAccessToken: process.env.GITHUB_TOKEN,
});

// extendedTables is an array of merged table objects, e.g.:
// [{ name: 'users', description: '...', url: 'https://fleetdm.com/tables/users', ... }]
```

> **Prerequisite:** `sails.config.custom.versionOfOsquerySchemaToUseWhenGeneratingDocumentation` must be set (e.g., `'5.8.1'`) before invoking this helper.
