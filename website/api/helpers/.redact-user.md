Synchronous Sails.js helper that destructively removes protected attributes from a User record before it is sent to a client.

## Key Components

- **`friendlyName`** – `'Redact user'`
- **`sync`** – `true` (runs synchronously, no `await` needed)
- **`inputs.user`** – A reference to a mutable User record object
- **`fn`** – Iterates over `User.attributes` and deletes any attribute marked with `protect: true`

## Usage Example

```javascript
// Redact sensitive fields before sending user data to the client
let user = await User.findOne({ id: req.session.userId });

sails.helpers.redactUser(user);

return res.json(user); // Protected attributes (e.g. password hash) are removed
```

## Notes

- This helper **mutates the object in place** — it does not return a copy.
- Any attribute defined in the `User` model with `protect: true` (e.g. `password`, `passwordResetToken`) will be stripped.
- Because `readOnly: false` is set on the `user` input, the helper is permitted to modify the passed-in reference directly.
