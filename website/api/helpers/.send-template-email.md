Sends transactional emails using EJS templates via SendGrid, with built-in development safety that logs emails to the console instead of sending them when the recipient address ends in `@example.com` or the environment is `test`.

## Key Components

### Inputs

| Input | Type | Description |
|---|---|---|
| `template` | `string` | Relative path to an EJS template under `views/emails/` (no extension) |
| `templateData` | `object` | Key/value data passed as locals to the EJS template |
| `to` | `string` | Recipient email address |
| `toName` | `string` | Recipient display name |
| `subject` | `string` | Email subject line |
| `from` / `fromName` | `string` | Sender override (defaults to app config) |
| `replyTo` | `object` | Reply-to address and name |
| `layout` | `string\|false` | Layout override relative to `views/layouts/`; defaults to `layout-email` |
| `ensureAck` | `boolean` | Await delivery confirmation before returning; defaults to `false` (fire-and-forget) |
| `bcc` | `string[]` | BCC recipients |
| `attachments` | `array` | Base64-encoded file attachments |

### Exit

- **`success`** — Returns `{ loggedInsteadOfSending: boolean }` indicating whether the email was actually sent or only logged.

### Key Behaviors

- **Template validation** — Warns if the template filename doesn't start with `email-`; throws if prefixed with `views/` or `emails/`
- **Safe development mode** — Skips real delivery for `@example.com` addresses or `test` environment; logs full email body to console instead
- **Subject prefix** — Prepends `[FROM STAGING]` or `[FROM LOCALHOST]` in non-production environments
- **Async delivery** — Runs SendGrid delivery in the background by default unless `ensureAck: true`

## Usage Example

```javascript
await sails.helpers.sendTemplateEmail.with({
  template: 'email-reset-password',
  templateData: {
    fullName: 'Nola Thacker',
    resetLink: 'https://example.com/reset?token=abc123',
  },
  to: 'nola.thacker@example.com',
  toName: 'Nola Thacker',
  subject: 'Reset your password',
  ensureAck: true,
});
```

> **Note:** Requires `sails.config.custom.sendgridSecret` to be set in [`config/custom.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/config/custom.js) for real delivery. Sign up at [sendgrid.com](https://sendgrid.com) to obtain credentials.
