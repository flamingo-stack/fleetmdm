Provisions a new Fleet Sandbox instance by calling the cloud provisioner API, polling the instance health endpoint, and returning connection details to the caller.

## Key Components

**Inputs**

| Input | Type | Description |
|---|---|---|
| `firstName` | string | User's first name, passed to the Fleet instance |
| `lastName` | string | User's last name, passed to the Fleet instance |
| `emailAddress` | string | User's email address, passed to the Fleet instance |

**Exits**

| Exit | Description |
|---|---|
| `success` | Returns `fleetSandboxDemoKey`, `fleetSandboxExpiresAt`, and `fleetSandboxURL` |
| `requestToProvisionerTimedOut` | Fires when the POST to `sandbox.fleetdm.com/new` exceeds 10 seconds |

**Core Logic**

- Computes a 5-day expiration timestamp and generates a UUID demo key via `sails.helpers.strings.uuid()`
- POSTs to `https://sandbox.fleetdm.com/new` with user details, the demo key as the password field, and the expiration as an ISO 8601 string; authenticated via `sails.config.custom.cloudProvisionerSecret`
- Polls the provisioned instance's `/healthz` endpoint (10 s budget, 5 s per request timeout) until a successful response is received

## Usage Example

```javascript
let sandboxDetails = await sails.helpers.provisionNewFleetSandboxInstance.with({
  firstName: 'Jane',
  lastName:  'Doe',
  emailAddress: 'jane.doe@example.com',
});
// sandboxDetails => {
//   fleetSandboxDemoKey:   'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
//   fleetSandboxExpiresAt: 1700000000000,
//   fleetSandboxURL:       'https://abc123.sandbox.fleetdm.com',
// }
```

## Notes

- Throws a hard `500`-style error if the provisioner returns a non-200 response or omits the `URL` field in its response body
- The demo key is intentionally used in place of the user's real password; users always authenticate via their `fleetdm.com` account rather than directly against the sandbox
