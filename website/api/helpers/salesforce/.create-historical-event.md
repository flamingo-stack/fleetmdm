Creates a historical event record in Salesforce linked to a specific contact and account, supporting "Intent signal" and "Website page view" event types.

## Key Components

**Inputs**

| Input | Type | Required | Description |
|---|---|---|---|
| `salesforceAccountId` | string | ✅ | Salesforce account ID to associate with the event |
| `salesforceContactId` | string | ✅ | Salesforce contact ID to associate with the event |
| `eventType` | string | ✅ | Either `"Intent signal"` or `"Website page view"` |
| `fleetWebsitePageUrl` | string | Conditional | Required when `eventType` is `"Website page view"` |
| `intentSignal` | string | Conditional | Required when `eventType` is `"Intent signal"` |
| `eventContent` | string | — | Content associated with the event |
| `eventContentUrl` | string | — | URL of the related content |
| `linkedinUrl` | string | — | LinkedIn profile URL (protocol/subdomain normalized) |
| `relatedCampaign` | string | — | Associated campaign name |

**Exits**

- `success` — Returns `{ salesforceHistoricalEventId: string }`

**Behavior Notes**

- No-ops (returns `undefined`) in non-production environments
- Normalizes `linkedinUrl` by stripping protocol and common subdomains
- Authenticates via `jsforce` to `fleetdm.my.salesforce.com` using `salesforceIntegrationUsername` and `salesforceIntegrationPasskey`
- Creates records on the `fleet_website_page_views__c` Salesforce custom object

## Usage Example

```javascript
let result = await sails.helpers.salesforce.createHistoricalEvent({
  salesforceAccountId: '001XXXXXXXXXXXX',
  salesforceContactId: '003XXXXXXXXXXXX',
  eventType: 'Intent signal',
  intentSignal: 'Stared the fleetdm/fleet repo on GitHub',
  relatedCampaign: 'Q1 GitHub Outreach',
});

// result => { salesforceHistoricalEventId: '...' }
```

## Configuration Requirements

The following must be set in `sails.config.custom` for production use:

```text
salesforceIntegrationUsername
salesforceIntegrationPasskey
RX_PROTOCOL_AND_COMMON_SUBDOMAINS
```
