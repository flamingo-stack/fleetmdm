Creates a Salesforce "Campaign Member" record by linking a contact to a campaign using the jsforce library. Only executes in production environments.

## Key Components

- **`salesforceContactId`** *(required)* — The Salesforce Contact ID to associate with the campaign
- **`salesforceCampaignId`** *(required)* — The Salesforce Campaign ID to add the contact to
- **`couldNotCreateCampaignMember`** exit — Triggered when the campaign record cannot be matched in Salesforce

## Behavior Notes

- **No-ops outside production** — Logs a verbose message and returns early in non-production environments
- **Authentication** — Connects to `fleetdm.my.salesforce.com` using credentials from `sails.config.custom.salesforceIntegrationUsername` and `sails.config.custom.salesforceIntegrationPasskey`
- **No return value** — The helper resolves with `undefined` on success

## Usage Example

```javascript
await sails.helpers.salesforce.createCampaignMember({
  salesforceContactId: '0035g00000AbCdEFAZ',
  salesforceCampaignId: '7015g00000XyZwVAAZ',
});
```

## Required Configuration

| Config Key | Description |
|---|---|
| `sails.config.custom.salesforceIntegrationUsername` | Salesforce login username |
| `sails.config.custom.salesforceIntegrationPasskey` | Salesforce login password/token |
| `sails.config.environment` | Must be `'production'` to execute |
