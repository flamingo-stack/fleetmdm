Creates a Salesforce Lead record representing an action Fleet needs to take for a contact, triggered by user behavior signals or explicit requests.

## Key Components

**Inputs**
- `salesforceAccountId` *(required)* — ID of the related Salesforce Account
- `salesforceContactId` *(required)* — ID of the related Salesforce Contact
- `leadDescription` — Description of the lead (e.g. contact form message, swag request)
- `leadSource` *(required)* — One of: `Website - Contact forms`, `Website - Sign up`, `Website - Waitlist`, `Website - swag request`
- `primaryBuyingSituation` — One of: `eo-it`, `eo-security`, `mdm`, `vm`
- `numberOfHosts` — Number of hosts associated with the lead

**Core Logic**

1. **Salesforce authentication** — Connects via `jsforce` using credentials from `sails.config.custom`
2. **Record retrieval** — Fetches both the Contact and Account records from Salesforce
3. **Round-robin assignment** — If the Account is owned by the integration admin (`0054x00000735wDAAQ`) and is not the unenriched-contacts account, reassigns ownership to the next AE in the round-robin queue by sorting on `AE_Account_Assignment_round_robin__c`
4. **Lead creation** — Creates a `Lead` sobject combining input data with fields from the retrieved Contact and Account records

## Usage Example

```javascript
await sails.helpers.salesforce.createLead({
  salesforceAccountId: '0014x000025JC8DAAW',
  salesforceContactId: '0034x000006abcDEF',
  leadDescription: 'Interested in MDM for 500 devices',
  leadSource: 'Website - Contact forms',
  primaryBuyingSituation: 'mdm',
  numberOfHosts: 500,
});
```
