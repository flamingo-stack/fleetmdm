Orchestrates a two-step Salesforce integration by first upserting a Contact and Account record, then creating a Lead record using the returned IDs.

## Key Components

- **`updateOrCreateContactAndAccount`** — Calls the `salesforce.updateOrCreateContactAndAccount` helper to upsert the Contact and Account, returning their Salesforce record IDs.
- **`createLead`** — Calls the `salesforce.createLead` helper using the IDs from the previous step to associate the Lead with the correct records.
- **Environment guard** — Skips all Salesforce calls when `sails.config.environment` is not `'production'`, logging a skip message instead.

## Inputs

| Input | Type | Required | Description |
|---|---|---|---|
| `emailAddress` | string | No | Used to find an existing contact |
| `linkedinUrl` | string | No | Alternative lookup key |
| `firstName` | string | Yes | Contact first name |
| `lastName` | string | Yes | Contact last name |
| `organization` | string | No | Account/company name |
| `primaryBuyingSituation` | string | No | Buying context |
| `psychologicalStage` | string | No | Stage 1–6 enum |
| `psychologicalStageChangeReason` | string | No | Reason for stage change |
| `leadDescription` | string | No | Free-text lead context |
| `contactSource` | string | Yes | Enum of acquisition channels |
| `numberOfHosts` | number | No | Host count for the lead |

## Usage Example

```javascript
await sails.helpers.salesforce.updateOrCreateContactAndAccountAndCreateLead.with({
  emailAddress: 'jane@example.com',
  firstName: 'Jane',
  lastName: 'Doe',
  organization: 'Acme Corp',
  contactSource: 'Website - Contact forms - Demo',
  leadDescription: 'Requested a product demo via contact form.',
  numberOfHosts: 500,
  psychologicalStage: '3 - Intrigued',
  psychologicalStageChangeReason: 'Website - Organic start flow',
});
```

> **Note:** Returns no value on success. In non-production environments the helper exits early without making any Salesforce API calls.
