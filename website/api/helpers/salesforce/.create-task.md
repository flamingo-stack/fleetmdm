Creates a Salesforce task for a given account — currently a stub that throws "Not yet implemented."

## Key Components

| Element | Description |
|---|---|
| `salesforceAccountId` | Required string; used to resolve the task's owner from the linked Salesforce account |
| `dueDate` | Optional `YYYY-MM-DD` string; defaults to current date if omitted |
| `fn` | Async handler — logs inputs and throws; commented-out `jsforce` integration is scaffolded but inactive |

## Usage Example

```javascript
await sails.helpers.createTask({
  salesforceAccountId: '001Dn000003GhABIA0',
  dueDate: '2025-08-01',
});
```
