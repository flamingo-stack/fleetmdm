Upserts Salesforce Contact and Account records given person and enrichment data, handling login, field mapping, marketing attribution parsing, and psychological stage tracking.

## Key Components

- **`emailAddress` / `linkedinUrl`**: Lookup keys for finding existing records (at least one required)
- **`contactValuesToSet`**: Dictionary built from inputs, maps to Salesforce field API names (e.g., `Primary_buying_situation__c`, `Trial_status__c`)
- **`accountValuesToSet`**: Dictionary for account-level host counts (macOS, Windows, Linux, iOS, Android)
- **`attributionDetails`**: Parsed from `marketingAttributionCookie`; classifies traffic as Digital, Event, or Organic and maps UTM medium codes to human-readable channel names
- **`psychologicalStage`**: Tracks buyer journey stage (1–6) with a change reason for CRM updates
- **`trialInstanceUsageDetails`**: Syncs trial status, dates, user count, and enrolled host count to Contact fields
- **`formBasedContactSources`**: List of web/event sources that trigger `Most_recent_campaign_member_status__c = 'Registered'`

## Usage Example

```javascript
await sails.helpers.salesforce.updateOrCreateContactAndAccount.with({
  emailAddress: 'jane@example.com',
  firstName: 'Jane',
  lastName: 'Doe',
  jobTitle: 'IT Director',
  organization: 'Acme Corp',
  primaryBuyingSituation: 'Security',
  psychologicalStage: '3 - Intrigued',
  psychologicalStageChangeReason: 'Website - Organic start flow',
  contactSource: 'Website - Contact forms - Demo',
  intentSignal: 'Subscribed to the Fleet newsletter',
  marketingAttributionCookie: {
    medium: 'cpc',
    campaign: 'fleet-q1-paid',
    gclid: 'abc123',
    initialUrl: 'https://fleetdm.com/demo',
    referrer: 'https://www.google.com'
  },
  trialInstanceUsageDetails: {
    status: 'active',
    lastUpdatedOn: '2024-06-01',
    trialStartedOn: '2024-05-15',
    trialEndsOn: '2024-06-15',
    numUsers: 5,
    numHostsEnrolled: 120,
  }
});
// Returns: { salesforceAccountId, salesforceContactId, mostRecentCampaign }
```

> **Note:** This helper is a no-op outside `production` environment — it returns `undefined` values and skips all Salesforce API calls. Requires `salesforceIntegrationUsername`, `salesforceIntegrationPasskey`, and `iqSecret` in `sails.config.custom`.
