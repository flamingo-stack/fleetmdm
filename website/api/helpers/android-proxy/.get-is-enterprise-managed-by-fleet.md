Checks whether a given Android Enterprise ID is managed by Fleet's Enterprise Management Google project by querying the Google Android Management API and searching the returned enterprise list.

## Key Components

**Inputs**
- `androidEnterpriseId` *(string, required)* — The Android Enterprise ID to verify against Fleet's managed enterprise list.

**Exits**
- `success` — Returns a `boolean` (`true` if the enterprise is managed by Fleet, `false` otherwise).

**Core Logic**
- Authenticates with Google APIs using a service account (email + private key from Sails config).
- Paginates through all enterprises in the configured Google project using `androidmanagement.enterprises.list`.
- Uses `_.find` to match the provided enterprise ID against the full enterprise list (supports both `enterprises/{id}` and bare ID formats).

**Required Sails Config**
| Config Key | Purpose |
|---|---|
| `androidEnterpriseServiceAccountEmailAddress` | Google service account email |
| `androidEnterpriseServiceAccountPrivateKey` | Google service account private key |
| `androidEnterpriseProjectId` | Google Cloud project ID |

## Usage Example

```javascript
// Call from within a Sails action or helper
let isManagedByFleet = await sails.helpers.getIsEnterpriseManagedByFleet
  .with({ androidEnterpriseId: 'LC04xxxxxxx' });

if (isManagedByFleet) {
  // Proceed with Fleet-managed enterprise operations
} else {
  // Handle unrecognized enterprise
}
```
