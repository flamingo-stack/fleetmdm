Converts a GitHub-flavored Markdown string into an HTML string with inline styles optimized for Fleet newsletter email rendering.

## Key Components

- **`mdString` input** — Required Markdown string to compile
- **`customRenderer`** — A `marked.Renderer` instance overriding default output for the following elements, each with hardcoded inline CSS styles:
  - `code` / `codespan` — Styled code blocks and inline code
  - `blockquote` — Blockquote wrapper
  - `heading` — H1–H4 with weight/size variants
  - `hr` — Horizontal rule with border styling
  - `list` / `listitem` — Ordered and unordered lists
  - `paragraph` — Body text paragraphs
  - `strong` / `em` — Bold and italic spans
  - `link` — Anchor tags with external link handling and Fleet domain detection
  - `image` — Images with asset path rewriting from `../website/assets` to `https://fleetdm.com`
- **Exits:** `success` (HTML string) and `unsafeMarkdown` (unsafe content detected)

## Usage Example

```javascript
const toHtmlEmail = require('./to-html-email');

toHtmlEmail.fn(
  { mdString: '# Hello\n\nThis is a **newsletter** update.' },
  {
    success: (htmlString) => console.log(htmlString),
    error: (err) => console.error(err),
    unsafeMarkdown: () => console.warn('Unsafe markdown detected'),
  }
);
```

## Notes

- Uses [`marked`](https://github.com/chjj/marked) with GFM and table support enabled
- The `link` renderer includes Fleet domain detection logic (`fleetdm.com`) to handle internal vs. external links, though the internal href-rewriting block is currently a no-op (the inner arrow function is never invoked)
- Image `src` paths beginning with `../website/assets` are rewritten to absolute `https://fleetdm.com` URLs
