Converts a string to sentence case using best-effort heuristics, with special handling for known acronyms and proper nouns.

## Key Components

- **`KNOWN_ACRONYMS`** — List of uppercase acronyms (e.g., `JSON`, `API`, `REST`) that are preserved in uppercase regardless of position.
- **`KNOWN_PROPER_NOUNS`** — List of proper nouns (e.g., `Fleet`) that are always capitalized regardless of position.
- **`fn`** — Core transformation: splits on whitespace, hyphens, and underscores; capitalizes the first word; lowercases all others (except acronyms/proper nouns).

## Usage Example

```javascript
const toSentenceCase = require('./to-sentence-case');

toSentenceCase.fn({ text: 'the-Weird Catfood' });
// => 'The weird catfood'

toSentenceCase.fn({ text: 'fleet-REST-api overview' });
// => 'Fleet REST API overview'

toSentenceCase.fn({ text: 'deploying_fleet_via_cli' });
// => 'Deploying Fleet via CLI'
```

## Notes

- Runs **synchronously** (`sync: true`).
- Leading numeric-only tokens are stripped before capitalization to avoid unexpected results (e.g., `123-some-title` → `Some title`).
- To extend behavior, add entries to `KNOWN_ACRONYMS` or `KNOWN_PROPER_NOUNS` inside the function.
