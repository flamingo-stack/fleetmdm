Converts a GitHub-flavored Markdown string into an HTML string using the `marked` library, with custom renderers for headings, code blocks, blockquotes, checkboxes, and tables.

## Key Components

**Inputs**
- `mdString` — Required Markdown string to compile
- `allowHtml` — Whether to permit HTML tags in input (default: `true`); triggers `unsafeMarkdown` exit if `false` and HTML is detected
- `addIdsToHeadings` — Whether to add `id` attributes and anchor links to heading tags (default: `true`)

**Custom Renderers**
- **`heading`** — Adds `id`, anchor link, and optional zero-width-space line breaks for long underscore-delimited identifiers; deduplicates heading IDs on the same page
- **`code`** — Handles `mermaid` blocks (no `<pre>` wrapper), normalizes `js` → `javascript`, `sh`/`bash` → `bash`, escapes all output, and falls back to `nohighlight`
- **`blockquote`** — Wraps content in a styled tip callout with an info icon
- **`listitem`** — Renders checkbox list items as disabled `<input type="checkbox">` elements
- **`table`** — Wraps tables in a Bootstrap-compatible `table-responsive` container

**Exits**
- `success` — Returns the compiled HTML string
- `unsafeMarkdown` — Fires when HTML tags are found and `allowHtml` is `false`

## Usage Example

```javascript
const toHtml = require('./to-html');

toHtml.fn(
  {
    mdString: '# Hello\n\nSome **bold** text.\n\n```js\nconsole.log("hi");\n```',
    allowHtml: true,
    addIdsToHeadings: true,
  },
  {
    success: (html) => console.log(html),
    unsafeMarkdown: () => console.warn('HTML tags detected in input'),
    error: (err) => console.error(err),
  }
);
```
