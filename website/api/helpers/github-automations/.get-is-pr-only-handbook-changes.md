Checks each file changed in a GitHub pull request and returns a boolean indicating whether all modifications are confined to the `handbook/` directory.

## Key Components

- **`prNumber`** *(input)*: The GitHub pull request number to evaluate (required)
- **`isHandbookOnlyPR`** *(output)*: Boolean — `true` if every changed file path begins with `handbook/`, `false` otherwise
- **GitHub Files API**: Fetches up to 100 changed files via [`GET /repos/{owner}/{repo}/pulls/{prNumber}/files`](https://docs.github.com/en/rest/reference/pulls#list-pull-requests-files)

## Behavior Notes

- Returns `false` immediately if the PR contains no changed files
- Uses `_.all()` with a regex (`/^handbook\//`) to validate every changed path
- Requires `sails.config.custom.githubAccessToken` to be set; asserts at runtime if missing
- Hardcoded to the `fleetdm/fleet` repository

## Usage Example

```javascript
let isHandbookOnly = await sails.helpers.getIsPrOnlyHandbookChanges.with({
  prNumber: 382,
});

if (isHandbookOnly) {
  // Apply handbook-only label or skip CI steps
}
```
