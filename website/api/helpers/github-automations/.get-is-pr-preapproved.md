Determines whether a pull request is pre-approved by checking if all changed file paths have designated maintainers configured in the Sails application's path-based maintainer map.

## Key Components

- **`repo`** — Target repository (`fleet` or `confidential`)
- **`prNumber`** — GitHub PR number to evaluate
- **`githubUserToCheck`** — Optional GitHub username; if omitted, returns `true` if any maintainer covers all changed paths
- **`isGithubUserMaintainerOrDoesntMatter`** — Allows wildcard (`*`) maintainer entries to match when the user is a confirmed maintainer
- **`MAINTAINERS_BY_PATH`** — Path-to-maintainer map sourced from `sails.config.custom`, supporting exact path matches and ancestral path traversal

## Usage Example

```javascript
let isPreapproved = await sails.helpers.githubAutomations.getIsPrPreapproved.with({
  repo: 'fleet',
  prNumber: 382,
  githubUserToCheck: 'mikermcneil',
  isGithubUserMaintainerOrDoesntMatter: true,
});

if (isPreapproved) {
  // Proceed with auto-merge or approval workflow
}
```

## How It Works

1. Fetches the list of changed files from the GitHub Pulls API (up to 100 files)
2. For each changed path, checks the `MAINTAINERS_BY_PATH` config for an exact match
3. If no exact match, walks up the directory tree checking each ancestral path
4. Supports wildcard (`*`) entries for maintainers, honoring them only when `isGithubUserMaintainerOrDoesntMatter` is `true`
5. Returns `true` only if **all** changed paths are covered and the file count is under the 100-file API page limit

> **Note:** Requires `sails.config.custom.githubRepoMaintainersByPath`, `confidentialGithubRepoMaintainersByPath`, `fleetMdmGitopsGithubRepoMaintainersByPath`, and `githubAccessToken` to be configured.
