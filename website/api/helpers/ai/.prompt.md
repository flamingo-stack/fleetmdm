A Sails.js helper that provides a unified interface for prompting large language models (LLMs), supporting both OpenAI and Anthropic APIs with optional JSON response parsing.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `prompt` | `string` (required) | The user prompt to send to the LLM |
| `baseModel` | `string` | Model identifier; defaults to `gpt-3.5-turbo` |
| `expectJson` | `boolean` | When `true`, instructs the model to return valid JSON and parses the response |
| `systemPrompt` | `string` | Optional system-level context injected before the user prompt |
| `jsonExpectationFailed` | exit | Triggered when `expectJson: true` but the model returns invalid JSON |

**Supported model families:**
- **OpenAI** — `gpt-4o`, `gpt-4.1-*`, `o1-preview`, `o3-*`, `o4-mini-*`
- **Anthropic** — `claude-sonnet-*`, `claude-opus-*`

Model routing is determined automatically: any `baseModel` starting with `claude-` is sent to the Anthropic API; all others go to OpenAI.

**Required config:**
- `sails.config.custom.openAiSecret` — for OpenAI models
- `sails.config.custom.anthropicSecret` — for Anthropic models

## Usage Example

```javascript
// Basic prompt
let answer = await sails.helpers.prompt.with({
  prompt: 'Who is running macOS 15?',
  baseModel: 'gpt-4o',
});

// JSON response with retry on parse failure
let metadata = await sails.helpers.prompt
  .with({
    prompt: 'Extract name, OS, and version from this device record as JSON.',
    baseModel: 'gpt-4o',
    expectJson: true,
    systemPrompt: 'Here is the device data as JSON: ```[…]```',
  })
  .retry('jsonExpectationFailed');

// Using an Anthropic model
let summary = await sails.helpers.prompt.with({
  prompt: 'Summarize the following incident report.',
  baseModel: 'claude-opus-4-6-20260218',
  systemPrompt: 'You are an IT operations assistant.',
});
```

> **Note:** Some OpenAI reasoning models (`o1-preview`, `o3-mini-2025-01-31`) do not support system prompts. Passing `systemPrompt` with these models logs a warning and ignores the input.
