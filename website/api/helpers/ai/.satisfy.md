Modifies JSON data to satisfy a set of natural-language constraints, optionally applying ordered changes while keeping all constraints intact throughout.

## Key Components

| Element | Description |
|---|---|
| `data` | Required JSON input to be evaluated and modified |
| `constraints` | Required array of natural-language constraint strings the data must satisfy |
| `changes` | Optional ordered list of changes to apply while preserving all constraints |
| `fn` | Builds a structured prompt and delegates to `sails.helpers.ai.prompt` using `o4-mini-2025-04-16` |

## Behavior Notes

- Constraints are rendered as a bullet list in the prompt
- Changes are rendered as an ordered (indexed) list appended after constraints
- Uses `expectJson: true` so the LLM response is parsed back to a JSON object
- Retries automatically on `jsonExpectationFailed`
- The returned data is a deep clone from the LLM — the original `data` input is never mutated

## Usage Example

```javascript
const result = await sails.helpers.satisfy.with({
  data: {
    tables: [
      { id: 1, seats: ['Alice Smith', 'Bob Smith', null, null] },
      { id: 2, seats: ['Jane Doe', null, null, null] }
    ]
  },
  constraints: [
    'Every table must have no more than 2 empty seats.',
    'Couples with the same last name should sit together at the same table.'
  ],
  changes: [
    'Add Carol and Dave Jones to the seating chart'
  ]
});
// result => modified tables JSON satisfying all constraints
```
