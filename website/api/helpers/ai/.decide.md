Classifies arbitrary JSON data into one of a set of predefined labeled choices using an LLM prompt, returning the matching choice key.

## Key Components

- **`data`** (input) — Any JSON value to be classified
- **`choices`** (input) — A dictionary mapping choice keys (returned strings) to predicate phrases (natural-language descriptions). Must include a catch-all option (e.g. `"Anything else"`)
- **`success`** (exit) — Returns the key string of the chosen option
- **`fn`** — Builds a structured prompt, calls `sails.helpers.ai.prompt` using `o4-mini-2025-04-16`, matches the LLM response back to a choice key, and retries on failure via `sails.helpers.flow.build().retry()`

## Usage Example

```javascript
let result = await sails.helpers.ai.decide.with({
  data: { text: 'This product changed my life!', likes: 9200 },
  choices: {
    'Top post': 'A social media post with high engagement and positive sentiment',
    'Spam':     'A post that appears to be promotional or low-quality',
    'n/a':      'Anything else',
  },
});

// result => 'Top post'
```

## Notes

- The `choices` dictionary **must include a catch-all** predicate (e.g. `'Anything else'`) to prevent errors when no other choice matches
- LLM responses that don't exactly match a predicate value throw an `Error` with a detailed diagnostic message; the `.retry()` wrapper automatically retries transient failures
- Marked `sideEffects: 'cacheable'`, making it safe for caching identical input/choice combinations
- Intended for use cases like sentiment analysis, content moderation, or featured-post ranking
