Scores arbitrary JSON data along multiple named dimensions using an AI language model, returning a 0–1 float per dimension suitable for building recommendation indexes or ranked search features.

## Key Components

| Element | Description |
|---|---|
| `data` | Any JSON-serializable input to be scored |
| `dimensions` | Array of string labels defining the scoring axes (e.g. `'formal'`, `'wool fabric'`) |
| `weights` (output) | Plain object mapping each dimension name to a `0`–`1` score |
| `sails.helpers.ai.prompt` | Underlying LLM call using `o4-mini-2025-04-16`; retries on JSON parse failures |
| `sails.helpers.flow.build` | Wraps the async LLM call with a top-level retry guard |

**Validation:** After the LLM responds, the helper confirms the returned object is a non-array plain object whose keys cover every requested dimension — throwing a descriptive `Error` if the shape mismatches.

## Usage Example

```javascript
// Score a clothing product for recommendation indexing
let scores = await sails.helpers.weigh.with({
  data: {
    name: 'Merino Wool Blazer',
    material: '100% wool',
    occasion: 'business formal',
  },
  dimensions: [
    'night on the town',
    'formal',
    'polyester fabric',
    'wool fabric',
  ],
});

// scores =>
// {
//   'night on the town': 0.3,
//   'formal':            0.9,
//   'polyester fabric':  0.0,
//   'wool fabric':       1.0,
// }
```

> **Note:** A TODO in the source flags that decimal precision rounding (`toFixed`-style) is not yet enforced in code — the prompt asks the model to limit to one decimal place, but callers should not rely on this guarantee until it is hardened.
