Iteratively refines a given prompt to be more effective for LLM consumption, running it through an AI model one or more times.

## Key Components

- **`prompt`** *(string, required)* — The original prompt to be improved
- **`cycles`** *(number, default: `1`)* — Number of improvement iterations to run
- **`fn`** — Core logic that wraps each cycle in a retryable flow, calling `sails.helpers.ai.prompt` with `o4-mini-2025-04-16` as the base model

## Usage Example

```javascript
// Single improvement cycle (default)
let betterPrompt = await sails.helpers.improvePrompt.with({
  prompt: 'Who is running macOS 15?'
});

// Multiple refinement cycles
let betterPrompt = await sails.helpers.improvePrompt.with({
  prompt: 'Who is running macOS 15?',
  cycles: 3
});
```

## Notes

- Marked as `cacheable` — identical inputs will return cached results, avoiding redundant AI calls
- Each cycle feeds the previous cycle's output back as input, progressively refining the prompt
- Each AI call is wrapped in `sails.helpers.flow.build(...).retry()` for resilience against transient failures
- The improver instructs the model to respond with only the raw prompt text, no surrounding explanation
