A Sails.js machine (actions2-compatible) that uses an AI prompt to auto-generate boilerplate code for Sails actions or helpers based on a plain-English specification.

## Key Components

- **`humanSpecification`** *(required, string)* — Plain-English description of what the action or helper should do.
- **`purpose`** *(string, `'action'` | `'helper'`, default: `'action'`)* — Determines whether to generate a Sails action (actions2) or a helper.
- **`fn`** — Calls `ƒ.prompt.with()` using the `o4-mini-2025-04-16` model to generate raw JavaScript code matching the specification and Sails v1+ conventions.

## Usage Example

```javascript
// Generate a Sails action
const code = await sails.helpers.compile.with({
  humanSpecification: 'Sign up: Handle a signup form by creating a user in the database and set the `.userId` key in the session.',
  purpose: 'action',
});

// Generate a Sails helper
const helperCode = await sails.helpers.compile.with({
  humanSpecification: 'Send a welcome email to a user given their email address and name.',
  purpose: 'helper',
});
```

## Prompt Conventions Enforced

The AI prompt instructs the model to follow these Sails-specific rules:

- Use `fn: ({ foo, bar }) => { ... }` destructuring instead of a separate `inputs` argument
- Use `.intercept()` / `.tolerate()` for error handling; never `.catch()`
- Use `req.session.userId` for session access
- Use `sails.helpers.http` for outgoing HTTP (never `fetch`)
- Never define a separate exit for 5xx errors — throw instead
- Omit the `exits` argument from `fn`
