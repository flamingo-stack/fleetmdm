Generates a signed JWT license key for Fleet Device Management, encoding host count, organization, expiration, and optional partner details using ES256 asymmetric signing.

## Key Components

| Input | Type | Description |
|---|---|---|
| `numberOfHosts` | `number` | Maximum number of licensed devices |
| `organization` | `string` | Subscriber organization name (`sub` claim) |
| `expiresAt` | `number` | JS timestamp (ms) for license expiration |
| `partnerName` | `string` | *(Optional)* Reseller partner name |

**Output:** A signed JWT string (`ES256`)

**JWT Claims Generated:**

| Claim | Value |
|---|---|
| `iss` | `Fleet Device Management Inc.` |
| `exp` | `expiresAt` converted to Unix seconds |
| `sub` | `organization` |
| `devices` | `numberOfHosts` |
| `tier` | `premium` |
| `partner` | `partnerName` *(omitted if undefined)* |

**Dependencies:** [`jsonwebtoken`](https://www.npmjs.com/package/jsonwebtoken)

**Config Required:**
- `sails.config.custom.licenseKeyGeneratorPrivateKey`
- `sails.config.custom.licenseKeyGeneratorPassphrase`

## Usage Example

```javascript
let licenseToken = await sails.helpers.createLicenseKey({
  numberOfHosts: 500,
  organization: 'Acme Corp',
  expiresAt: Date.now() + (365 * 24 * 60 * 60 * 1000), // 1 year from now
  partnerName: 'Flamingo MSP',                           // optional
});

// licenseToken → signed ES256 JWT string
```

> **Security note:** Signing requires a private key + passphrase configured in Sails. Never expose these values in client-side code or version control.
