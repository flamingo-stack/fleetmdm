A Sails.js policy middleware that restricts route access to authenticated super-admin users only.

## Key Components

- **`module.exports`** — Async middleware function `(req, res, proceed)` following the Sails.js policy pattern

## Behavior

The policy enforces two sequential checks:

1. **Authentication check** — If `req.me` is absent (unauthenticated request):
   - JSON/API requests receive a `401 Unauthorized` response
   - Browser requests are redirected to `/customers/login?admin`

2. **Super-admin check** — If `req.me.isSuperAdmin` is falsy, responds with `403 Forbidden`

3. **Proceed** — If both checks pass, calls `proceed()` to allow the request through

## Usage Example

Apply this policy to controller actions in `config/policies.js`:

```javascript
// config/policies.js
module.exports.policies = {
  // Protect a specific action
  'admin/DashboardController': {
    '*': 'is-super-admin',
  },

  // Or protect individual actions
  'UserController': {
    delete: 'is-super-admin',
    impersonate: 'is-super-admin',
  },
};
```

## Notes

- Depends on `req.me` being populated by the app's custom hook (`api/hooks/custom/index.js`)
- Uses `req.wantsJSON` to differentiate between API and browser clients, providing appropriate responses for each
- See the full implementation at [`api/policies/is-super-admin.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/api/policies/is-super-admin.js)
- Sails.js policy docs: [sailsjs.com/docs/concepts/policies](https://sailsjs.com/docs/concepts/policies)
