A Sails.js policy middleware that restricts route access to authenticated users only by checking for the presence of `req.me` on the request object.

## Key Components

- **`req.me` check** – Determines authentication state; set by the app's custom hook (`api/hooks/custom/index.js`) during session resolution
- **`proceed()`** – Passes control to the next policy or action when the user is authenticated
- **`res.unauthorized()`** – Rejects the request with a `401` response when no authenticated user is found

## Usage Example

```javascript
// config/policies.js
module.exports.policies = {

  // Protect all actions in UserController
  UserController: {
    '*': 'is-logged-in',
  },

  // Protect a specific action in DashboardController
  DashboardController: {
    index: 'is-logged-in',
  },

};
```

## Notes

- This policy relies on `req.me` being populated upstream by the custom hook — it does not perform authentication itself
- Pair with role-based policies (e.g. `is-super-admin`) for finer-grained access control
- Unauthenticated requests receive a `401 Unauthorized` response via `res.unauthorized()`
