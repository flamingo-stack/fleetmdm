Sails.js helper that processes "Talk to Us" form submissions, validates the submitter's email domain, enriches contact data, and routes users to the appropriate Calendly booking link based on company size and sales territory.

## Key Components

**Inputs**
- `emailAddress` — Validated email (required, isEmail)
- `firstName`, `lastName` — Submitter name fields (required)
- `organization` — Company name provided by the user (required; overridden by enrichment data)
- `numberOfHosts` — Self-reported host count used for ICP qualification (required)
- `primaryBuyingSituation` — Use-case enum (`it-major-mdm`, `it-gap-filler-mdm`, `it-misc`, `security-misc`, `security-vm`)

**Exits**
- `invalidEmailDomain` — Thrown when the submitter's domain is on the configured denylist
- `success` — Returns `{ icp: boolean, eventUrl: string }`

**Core Logic**
1. **Domain denylist check** — Rejects banned email domains early
2. **Parallel enrichment + LLM location guess** — Calls `sails.helpers.iq.getEnriched` and `sails.helpers.ai.prompt` simultaneously via `flow.simultaneously`
3. **ICP routing** — Users with ≥700 hosts (self-reported or from enrichment) are flagged as ICP and routed to a territory-specific Calendly link via `salesforce.getTerritoryUserId`
4. **Non-ICP routing** — Users below the threshold go to a generic onboarding Calendly link
5. **CRM update** — `salesforce.updateOrCreateContactAndAccount` is fired asynchronously (fire-and-forget) in both branches

## Usage Example

```javascript
// Called from a Sails.js controller action
const result = await sails.helpers.deliverTalkToUsFormSubmission.with({
  emailAddress: 'jane@acmecorp.com',
  firstName: 'Jane',
  lastName: 'Smith',
  organization: 'Acme Corp',
  numberOfHosts: '1200',
  primaryBuyingSituation: 'it-major-mdm',
});

// result.icp === true  → territory-specific Calendly URL
// result.icp === false → generic onboarding Calendly URL
console.log(result.eventUrl);
```

**Territory → Calendly URL mapping**

| Region | Salesforce User ID |
|---|---|
| New York City | `005UG000006YYDVYA4` |
| Washington DC | `0054x0000086sOlAAI` |
| Los Angeles | `005UG000008y0wbYAA` |
| San Francisco | `0054x0000086wsGAAQ` |
| Stockholm | `005UG000009NnSfYAK` |

> Unknown territory IDs fall back to the Washington DC Calendly link with a logged warning.
