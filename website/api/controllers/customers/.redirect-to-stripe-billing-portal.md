Handles creation of a Stripe billing portal session for Fleet Premium subscribers and redirects them to manage their subscription.

## Key Components

**Exits**
- `redirect` — Redirects the user to their Stripe customer billing portal session URL
- `noSubscription` — Redirects to `/customers/new-license` if no active Fleet Premium subscription is found

**Function Logic**
- Initializes the Stripe SDK using `sails.config.custom.stripeSecret`
- Looks up the current user's subscription via the `Subscription` model
- Creates a Stripe billing portal session tied to `this.req.me.stripeCustomerId`
- Sets the portal return URL to `/customers/dashboard`

## Usage Example

This action is invoked as a Sails.js route handler and is protected by the `is-logged-in` policy. No direct invocation is required — wire it to a route in `config/routes.js`:

```javascript
// config/routes.js
'GET /customers/billing-portal': {
  action: 'redirect-to-stripe-billing-portal',
  middleware: ['is-logged-in']
}
```

When a logged-in user hits this route:
1. Their subscription record is fetched from the database
2. If no subscription exists, they are redirected to `/customers/new-license`
3. If found, a Stripe billing portal session is created and they are redirected to the Stripe-hosted portal URL

## Notes

- Requires `sails.config.custom.stripeSecret` and `sails.config.custom.baseUrl` to be configured
- The `stripeCustomerId` must be stored on the user record (`this.req.me.stripeCustomerId`)
