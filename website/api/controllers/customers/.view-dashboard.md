Sails.js action that handles rendering the customer dashboard page, including subscription status checks via Stripe before displaying the view.

## Key Components

- **`thisSubscription`** – Looks up the current user's subscription record; redirects to `/customers/new-license` if none exists
- **`stripeSubscriptionDetails`** – Retrieves live subscription data from Stripe to check renewal intent (`cancel_at_period_end`)
- **Subscription status flags** – Computes and returns four boolean states:
  - `subscriptionHasBeenRecentlyRenewed` – Subscription is over a year old and renewed within the last 30 days
  - `subscriptionExpiresSoon` – Next billing date is within 30 days and subscription will renew
  - `subscriptionIsExpired` – Next billing date has already passed
  - `willSubscriptionRenew` – Whether Stripe will auto-renew at period end

## Exits

| Exit | Behavior |
|---|---|
| `success` | Renders `pages/customers/dashboard` with subscription data |
| `redirect` | Sends user to `/customers/new-license` if no subscription found |

## Usage Example

```javascript
// Accessed via the route mapped to this action, e.g. GET /dashboard
// Returns view data including:
{
  stripePublishableKey: 'pk_live_...',  // undefined if billing disabled
  thisSubscription: { /* Subscription record */ },
  subscriptionExpiresSoon: false,
  subscriptionHasBeenRecentlyRenewed: true,
  willSubscriptionRenew: true,
  subscriptionIsExpired: false,
}
```

## Notes

- Stripe is initialized per-request using `sails.config.custom.stripeSecret`
- `stripePublishableKey` is omitted from the view if `enableBillingFeatures` is `false`
