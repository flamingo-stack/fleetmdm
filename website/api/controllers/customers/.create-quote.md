A Sails.js helper action that generates a Fleet Premium License quote based on host counts across operating systems, persists it to the database, and triggers background CRM sync via Salesforce.

## Key Components

- **Inputs** — Six optional numeric inputs (`macosHosts`, `windowsHosts`, `linuxHosts`, `iosHosts`, `androidHosts`, `otherHosts`), each defaulting to `0`
- **Pricing logic** — Sums all host counts and applies a flat rate of `$7.00 × hosts × 12` (annual billing)
- **`Quote.create()`** — Persists the quote record with host count, price, organization, and user ID
- **`updateOrCreateContactAndAccount`** — Salesforce helper that upserts a CRM contact/account with a detailed description and marketing attribution cookie
- **`createHistoricalEvent`** — Logs an intent signal event in Salesforce tied to the contact and account
- **Background task** — CRM operations run via `sails.helpers.flow.build()` so failures are non-blocking; errors are logged as warnings

## Usage Example

```javascript
// Called as a Sails action (e.g., via a POST route)
const quote = await sails.helpers.createQuote.with({
  macosHosts: 50,
  windowsHosts: 30,
  linuxHosts: 20,
  iosHosts: 10,
  androidHosts: 5,
  otherHosts: 2,
});

// Returns the created Quote record:
// {
//   numberOfHosts: 117,
//   quotedPrice: 9828.00,   // 7.00 * 117 * 12
//   organization: 'acme',
//   user: 42
// }
```

> **Note:** CRM sync (`Salesforce` helpers) runs asynchronously in the background. A failure there will only emit a `sails.log.warn` and will not affect the returned quote.
