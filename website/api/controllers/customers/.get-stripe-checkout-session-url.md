Creates a Stripe checkout session for a new Fleet Premium subscription and returns the session URL, handling Stripe customer creation if one does not yet exist for the user.

## Key Components

- **`quoteId`** (input) — Required numeric ID of a `Quote` record that determines the subscription price and host count
- **Stripe customer provisioning** — Automatically creates a Stripe Customer via `sails.helpers.stripe.saveBillingInfo` if the current user lacks a `stripeCustomerId`, then persists it to the `User` record
- **`stripe.checkout.sessions.create`** — Builds a subscription-mode checkout session with billing address collection, promotion code support, and tax ID collection
- **Return value** — The Stripe-hosted checkout session URL, consumed by the `<ajax-form>` on `/customers/new-license`

## Usage Example

```javascript
// Called from a controller or route handler
const checkoutUrl = await sails.helpers.getStripeCheckoutSessionUrl.with({
  quoteId: 42
});

// Redirect or return the URL to the client
return res.json({ url: checkoutUrl });
```

## Configuration Dependencies

| Config Key | Purpose |
|---|---|
| `sails.config.custom.stripeSecret` | Stripe secret API key |
| `sails.config.custom.stripePublishableKey` | Enables billing features when set |
| `sails.config.custom.stripeSubscriptionPriceId` | Stripe price ID for Fleet Premium |
| `sails.config.custom.baseUrl` | Base URL for the post-checkout `success_url` redirect |

> **Note:** Billing features are gated by `sails.config.custom.enableBillingFeatures`. If either Stripe key is missing, the helper throws immediately before any Stripe API calls are made.
