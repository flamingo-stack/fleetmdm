Renders the "Download" page by validating and exposing platform-specific `fleetctl` download URLs from static build configuration.

## Key Components

- **`friendlyName`** – Human-readable action label: `'View download'`
- **`exits.success`** – Renders the `pages/download` view template with resolved download URLs
- **`exits.badConfig`** – Thrown when `builtStaticContent.fleetctlDownloadUrls` is missing or malformed
- **`fn`** – Validates `sails.config.builtStaticContent.fleetctlDownloadUrls` and returns three platform download URLs to the view

## Usage Example

```javascript
// Sails.js route configuration (config/routes.js)
'GET /download': { action: 'view-download' }

// Expected sails.config.builtStaticContent shape:
{
  fleetctlDownloadUrls: {
    macOs: 'https://example.com/fleetctl-macos.zip',
    windows: 'https://example.com/fleetctl-windows.exe',
    windowsArm: 'https://example.com/fleetctl-windows-arm.exe',
  }
}

// View template receives:
{
  macOsDownloadUrl: '...',
  windowsDownloadUrl: '...',
  windowsArmDownloadUrl: '...',
}
```

## Error Handling

Throws `badConfig` (HTTP 500-class response) if:
- `sails.config.builtStaticContent` or `fleetctlDownloadUrls` is not an object
- Any of `macOs`, `windows`, or `windowsArm` keys are not strings
