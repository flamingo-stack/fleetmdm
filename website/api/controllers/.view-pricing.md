Sails.js page action that renders the Pricing page by organizing pricing table features from static content into categorized groups.

## Key Components

**Exits**
- `success` — Renders the `pages/pricing` view template with pricing data
- `badConfig` — Thrown when `sails.config.builtStaticContent.pricingTable` is missing or malformed

**Core Logic (`fn`)**
- Validates `sails.config.builtStaticContent.pricingTable` exists and is an array
- Iterates over five predefined categories and filters matching features from static content
- Returns a structured `pricingTable` array passed to the view

**Pricing Categories**
```text
Device management | Deployment | Configuration | Integrations | Support
```

## Usage Example

```javascript
// Resulting pricingTable shape passed to the view:
[
  {
    categoryName: 'Device management',
    features: [
      {
        name: 'MDM enrollment',
        pricingTableCategories: ['Device management'],
        // ...other feature fields
      }
    ]
  },
  {
    categoryName: 'Deployment',
    features: [ /* ... */ ]
  },
  // ...remaining categories
]
```

## Notes

- Feature data is sourced from `sails.config.builtStaticContent.pricingTable`, which is built at startup from static content files
- Features are assigned to categories via their `pricingTableCategories` array — a single feature can appear in multiple categories
- The category order is hardcoded; features within each category preserve their source order
