Handles the "Legal Terms" page route by locating and serving the Fleet subscription terms markdown content from the site's static content configuration.

## Key Components

- **`friendlyName`** – `'View terms'`
- **`description`** – Identifies this as the "Legal terms" page handler
- **`exits.success`** – Renders `pages/legal/terms` view template
- **`exits.badConfig`** – Returns a `badConfig` response if static content is misconfigured
- **`fn`** – Async handler that validates `builtStaticContent` config, locates the `📜 Fleet subscription terms` markdown page, and returns it alongside Node's `path` module for use in the view

## Usage Example

```javascript
// Accessed automatically via Sails.js routing.
// The action validates config and resolves the correct markdown page:

let thisPage = _.find(
  sails.config.builtStaticContent.markdownPages,
  { title: '📜 Fleet subscription terms' }
);

// Returns to view:
return {
  path: require('path'),
  thisPage, // markdown page object used by pages/legal/terms template
};
```

## Error Handling

| Condition | Behavior |
|---|---|
| `builtStaticContent` is missing or malformed | Throws `badConfig` exit |
| Markdown page titled `📜 Fleet subscription terms` not found | Throws a descriptive `Error` |
