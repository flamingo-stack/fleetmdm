Renders the Privacy Policy page by locating and serving the Fleet privacy policy markdown content from the site's static content configuration.

## Key Components

- **`friendlyName`** – Human-readable label: `'View privacy'`
- **`description`** – Serves the `pages/legal/privacy` view template
- **`exits.success`** – Renders `pages/legal/privacy` view on success
- **`exits.badConfig`** – Returns a `badConfig` response if static content is misconfigured
- **`fn`** – Async handler that validates `builtStaticContent` config, finds the `📜 Fleet privacy policy` markdown page, and returns it alongside the Node.js `path` module

## Usage Example

```javascript
// Sails.js automatically routes this action. The fn resolves like:
const result = await sails.helpers.callAction('view-privacy');

// On success, the view receives:
// {
//   path: require('path'),
//   thisPage: { title: '📜 Fleet privacy policy', ... }
// }

// Throws badConfig if builtStaticContent is missing or malformed:
// throw { badConfig: 'builtStaticContent.markdownPages' }

// Throws a standard Error if the markdown page entry is not found:
// throw new Error('When a user visited the /legal/privacy page...')
```

## Configuration Dependency

This action requires `sails.config.builtStaticContent` to be properly populated at boot time with:

| Field | Type | Description |
|---|---|---|
| `markdownPages` | `Array` | All compiled markdown pages |
| `compiledPagePartialsAppPath` | `String` | Path to compiled partials |

The markdown file must include an entry with `title: '📜 Fleet privacy policy'` or the action will throw a runtime error.
