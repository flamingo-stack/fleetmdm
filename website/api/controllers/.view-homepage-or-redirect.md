Sails.js action that handles homepage routing — displaying the public landing page for guests or redirecting authenticated users to the internal welcome page.

## Key Components

| Element | Description |
|---|---|
| `success` exit | Returns `200` and renders `pages/homepage` for unauthenticated guests |
| `redirect` exit | Redirects logged-in users to the internal welcome page |
| `badConfig` exit | Fires when `builtStaticContent.testimonials` is missing or malformed |
| `testimonialsForScrollableTweets` | Filtered and ordered testimonial array passed to the `<scrollable-tweets>` component |

## Behavior

1. **Config guard** — throws `badConfig` if `sails.config.builtStaticContent.testimonials` is not a valid array.
2. **Testimonial filtering** — when `compiledPagePartialsAppPath` is set (i.e., the build-static-content script has run), testimonials are filtered to the `Device management` product category and sorted against a hardcoded author order.
3. **Fallback** — if static content has not been built, a placeholder testimonial injected by the custom hook is used as-is.

## Usage Example

```javascript
// Registered automatically by Sails via the filesystem convention.
// Accessible at the route mapped in config/routes.js, e.g.:
'GET /': { action: 'view-homepage-or-redirect' }

// The action returns this locals object to the view on success:
{
  testimonialsForScrollableTweets: [
    { quoteAuthorName: 'Bart Reardon', productCategories: ['Device management'], ... },
    // ...sorted per testimonialOrderForThisPage
  ]
}
```
