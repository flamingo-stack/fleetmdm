Sends a partner registration form submission via email, handling both reseller and integrations partner types with input validation, spam protection, and email domain filtering.

## Key Components

| Element | Description |
|---|---|
| `websiteUrl` input | Honeypot field — silently discards bot submissions when populated |
| `partnerType` validation | Conditional required fields differ by type (`reseller` vs `integrations`) |
| `invalidEmailDomain` exit | Rejects submissions from domains listed in `bannedEmailDomainsForWebsiteSubmissions` |
| `dealRegistrationContactEmailAddress` | Reseller submissions route to this address; integrations fall back to `fromEmailAddress` |
| `email-partner-registration` | Email template used for all partner registration notifications |

## Usage Example

```javascript
await sails.helpers.deliverPartnerRegistrationSubmission.with({
  submittersFirstName: 'Jane',
  submittersLastName: 'Doe',
  submittersEmailAddress: 'jane@example.com',
  submittersOrganization: 'Acme Corp',
  partnerType: 'reseller',
  partnerWebsite: 'https://acme.example.com',
  partnerCountry: 'US',
  notes: 'Interested in MDM reselling.',
  numberOfHosts: '500-1000',
  servicesOffered: {
    mdm: true,
    itServices: true,
    securityServices: false,
  },
});
```

## Conditional Logic by Partner Type

- **`reseller`** — requires `numberOfHosts` and `servicesOffered`; routes email to `dealRegistrationContactEmailAddress`
- **`integrations`** — requires `servicesCategory`; routes email to the default `fromEmailAddress`

> **Config dependency:** `sails.config.custom.dealRegistrationContactEmailAddress` must be set or the helper throws a descriptive error at runtime.
