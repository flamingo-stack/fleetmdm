Saves a user's progress through the Fleet "Get Started" onboarding questionnaire, updating psychological stage, primary buying situation, and accumulated answers in the database and session.

## Key Components

- **`currentStep`** — Validated enum input representing the current questionnaire step (18 possible steps from `start` to `thanks-for-checking-out-fleet`)
- **`formData`** — Arbitrary form data payload for the current step
- **Psychological stage tracking** — Maps user responses to progressive engagement stages (`2 - Aware` through `6 - Has team buy-in`)
- **Primary buying situation mapping** — Normalizes legacy values (`eo-it`, `eo-security`, `vm`, `mdm`) to new canonical identifiers (`it-misc`, `security-misc`, `security-vm`, `it-major-mdm`)
- **Fleet Premium trial key generation** — Automatically generates a 30-day trial license key (10 hosts) when the user completes a buying-situation-specific step, if one hasn't been issued yet

## Usage Example

```javascript
// Called from the frontend at each questionnaire step
await sendAction('/api/v1/account/save-questionnaire-progress', {
  currentStep: 'what-are-you-using-fleet-for',
  formData: { primaryBuyingSituation: 'security-vm' }
});

// Later step using accumulated answers
await sendAction('/api/v1/account/save-questionnaire-progress', {
  currentStep: 'how-many-hosts',
  formData: { numberOfHosts: '100-300' }
});
// Returns: all accumulated questionnaire answers so far
```

## Psychological Stage Transitions

| Step | Condition | Stage |
|---|---|---|
| `what-are-you-using-fleet-for` | Any answer | `2 - Aware` |
| `have-you-ever-used-fleet` | `yes-deployed` | `6 - Has team buy-in` |
| `have-you-ever-used-fleet` | `yes-recently-deployed` | `5 - Personally confident` |
| Buying situation steps | Has use case | `4 - Has use case` |
| `how-many-hosts` | Previously deployed | `6 - Has team buy-in` |
| `what-did-you-think` | `let-me-think-about-it` | `2 - Aware` |
