Sails.js page action that handles data preparation for the Customers page, including curated testimonials and paginated case study links.

## Key Components

- **`exits.success`** — Renders the `pages/customers` view template on successful execution
- **Testimonial filtering** — Excludes specific authors and sorts the remaining testimonials by a predefined display order
- **`testimonialsWithVideoLinks`** — Subset of filtered testimonials that include a `youtubeVideoUrl`
- **Case study collection** — Filters `markdownPages` for URLs under `/case-study/` that carry both `useBasicArticleTemplate` and `cardTitleForCustomersPage` meta tags
- **Pagination logic** — Targets an initial display of 12 case study cards (accounting for non-linked case studies), then chunks the remainder into groups of 12

## Usage Example

```javascript
// Registered automatically by Sails.js at the route defined in config/routes.js
// Example route binding:
'GET /customers': { action: 'view-customers' }

// The action returns the following locals to the view:
{
  testimonials,            // Filtered + sorted testimonial objects
  testimonialsWithVideoLinks, // Testimonials that have a YouTube URL
  caseStudiesToCreateLinksFor, // Remaining case studies after initial block
  initalCaseStudyLinksToShow,  // First block of up to 12 case study cards
  blocksOfCaseStudies,    // Array of 12-item arrays for subsequent pages
  numberOfPagesOfCaseStudies   // Total page count including the initial block
}
```

## Notes

- Requires `sails.config.builtStaticContent.testimonials` and `sails.config.builtStaticContent.markdownPages` to be populated at boot time; throws `badConfig` if either is missing
- Duplicate authors (e.g. `'Nico Waisman'` vs `'nico waisman'`) are handled via the exclusion list to avoid showing the same person twice
