Handles the server-side action for rendering the Deals page, returning an empty response object that triggers the associated view template.

## Key Components

- **`friendlyName`** – Human-readable label: `'View deals'`
- **`exits.success.viewTemplatePath`** – Maps successful responses to the `pages/deals` view template
- **`fn`** – Async action function that returns an empty object, delegating all rendering to the view layer

## Usage Example

```javascript
// Typically wired up in config/routes.js
'GET /deals': { action: 'view-deals' }
```

When a user navigates to the deals route, this action fires, returns `{}`, and Sails.js renders the `pages/deals` template with no additional data passed from the controller.
