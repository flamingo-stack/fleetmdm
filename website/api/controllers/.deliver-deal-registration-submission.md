Sends an email with the contents of a deal registration form submission to a configured contact address, with spam protection via honeypot field and email domain denylisting.

## Key Components

**Inputs**

| Input | Type | Description |
|---|---|---|
| `submittersFirstName/LastName` | string | Partner submitter identity |
| `submittersEmailAddress` | email string | Validated submitter email |
| `submittersOrganization` | string | Partner organization name |
| `submitterIsExistingPartner` | string | Existing partner flag |
| `customersOrganization/Name/EmailAddress` | string/email | End-customer details |
| `dealStage` | string | Current stage of the deal |
| `expectedClose` | string | Anticipated close date |
| `numberOfHosts` | string | Host count for the deal |
| `platforms` | object | Target platforms (Apple, Windows, Linux, Other) |
| `useCase` | object | Use cases (MDM, Security/compliance) |
| `notes` | string | Optional notes, defaults to `'N/A'` |
| `websiteUrl` | string | Honeypot field — submission silently discarded if filled |

**Exits**

- `success` — Email delivered successfully
- `invalidEmailDomain` — Submitter email domain is on the denylist (`badRequest`)

**Core Logic**

- Honeypot check: silently returns if `websiteUrl` is populated
- Domain denylist check against `sails.config.custom.bannedEmailDomainsForWebsiteSubmissions`
- Formats `platforms` and `useCase` objects into human-readable HTML strings
- Sends formatted data via `sails.helpers.sendTemplateEmail` using the `email-deal-registration` template

## Usage Example

```javascript
await sails.helpers.deliverDealRegistrationSubmission.with({
  submittersFirstName: 'Jane',
  submittersLastName: 'Doe',
  submittersEmailAddress: 'jane@partnerco.com',
  submittersOrganization: 'Partner Co',
  submitterIsExistingPartner: 'yes',
  customersOrganization: 'Acme Corp',
  customersName: 'John Smith',
  customersEmailAddress: 'john@acme.com',
  dealStage: 'Qualified',
  expectedClose: '2025-Q3',
  numberOfHosts: '500',
  platforms: { apple: true, windows: true, linux: false, other: false },
  useCase: { mdm: true, security: false },
  notes: 'Replacing existing MDM solution.',
});
```

> **Config required:** `sails.config.custom.dealRegistrationContactEmailAddress` must be set or the helper will throw an error.
