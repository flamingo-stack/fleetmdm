Renders the "Turn on MDM" page for the Microsoft proxy MDM enrollment flow.

## Key Components

- **`friendlyName`** – Human-readable label: `'View turn on mdm'`
- **`exits.success`** – Routes to the `pages/microsoft-proxy/turn-on-mdm` view template
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Registered as a Sails.js action and mapped to a route, e.g.:
// config/routes.js
'GET /microsoft-proxy/turn-on-mdm': { action: 'microsoft-proxy/view-turn-on-mdm' }
```

When a `GET` request hits the route, the action resolves the `success` exit and renders the `turn-on-mdm` view with no additional data passed to the template.

## Notes

- This is a minimal display-only action with no input validation or data fetching
- Part of the Microsoft MDM proxy flow — likely shown during Windows device enrollment
- View template path: `pages/microsoft-proxy/turn-on-mdm`
