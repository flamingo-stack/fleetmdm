Retrieves the result of a compliance status update for a Microsoft compliance tenant by querying the Microsoft device data sync API and returning the message status.

## Key Components

**Inputs**
- `entraTenantId` — Microsoft Entra tenant ID used to identify the compliance tenant
- `fleetServerSecret` — Secret key to authenticate the Fleet instance
- `messageId` — The GUID of the compliance data upload message to look up

**Exits**
- `success` — Returns a compliance status result object
- `tenantNotFound` — Returned when no matching `MicrosoftComplianceTenant` record exists (responds as `unauthorized`)

**Response Shape**

```javascript
{
  message_id: "<messageId>",
  status: "Completed" | "Failed" | ...,
  detail: "<ErrorDetail>" // only present when status === "Failed"
}
```

## Usage Example

```javascript
const result = await sails.helpers.getOneComplianceStatusResult.with({
  entraTenantId: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  fleetServerSecret: 'fleet-secret-value',
  messageId: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx'
});

if (result.status === 'Failed') {
  sails.log.warn('Compliance update failed:', result.detail);
}
```

## Notes

- Uses `sails.helpers.microsoftProxy.getAccessTokenAndApiUrls` to resolve per-tenant API credentials
- Calls the Microsoft device data sync API at `DataUploadMessages(guid'...')?api-version=1.2`
- Requests for the `dogfood.fleetdm.com` Fleet instance emit additional diagnostic logs
- Errors from the HTTP request or JSON parsing are thrown as `Error` objects with full inspection output
