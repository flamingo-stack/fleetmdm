Handles the Microsoft Entra admin consent redirect callback for the Fleet conditional access compliance integration, processing consent outcomes and completing new tenant provisioning when consent is granted.

## Key Components

**Inputs**
- `tenant` — Entra tenant ID of the Microsoft Compliance Partner tenant
- `state` — Authentication token used to validate the request against a stored `MicrosoftComplianceTenant` record
- `error` / `error_description` — Present only when an Entra admin denied or failed to grant consent

**Exits**
- `success` / `redirect` — Redirects back to the Fleet instance's conditional access settings page
- `adminDidNotConsent` — Admin explicitly denied permissions
- `noMatchingTenant` — No `MicrosoftComplianceTenant` record matched the provided `state`
- `badRequest` — Missing required `tenant` or `state` values

**Core Logic Flow**
1. **Consent denied** — If `error` or `error_description` is present, finds the tenant record by `state`, saves a `setupError`, and redirects back to the Fleet UI
2. **Tenant lookup** — Matches both `entraTenantId` and `stateTokenForAdminConsent` to locate the correct record
3. **Token retrieval** — Calls `sails.helpers.microsoftProxy.getAccessTokenAndApiUrls` to obtain Manage API and Graph API access tokens
4. **Tenant provisioning** — Sends a `PUT` to `PartnerTenants` to mark the tenant as provisioned
5. **Policy creation** — Sends a `POST` to `PartnerCompliancePolicies` to create a macOS Fleet compliance policy (tolerates `409` by fetching the existing policy)
6. **Group lookup** — Queries Microsoft Graph API for the `Fleet conditional access` Entra ID group to associate with the policy

## Usage Example

```javascript
// This action is invoked automatically by Microsoft as an OAuth redirect callback.
// Example redirect URL Microsoft sends after admin consent:
// GET /microsoft/redirect?tenant=<entra-tenant-id>&state=<state-token>
//
// On consent denial:
// GET /microsoft/redirect?state=<state-token>&error=access_denied&error_description=...
//
// Configured as a Sails.js action in routes, e.g.:
'GET /microsoft/redirect': { action: 'microsoft/receive-redirect-from-microsoft' }
```
