Creates a new Microsoft compliance partner tenant record for a Fleet instance, associating a Fleet server secret with a provided Entra tenant ID.

## Key Components

**Inputs**
- `entraTenantId` *(string, required)* — The Microsoft Entra tenant ID to register.

**Exits**
- `success` — Returns the generated `fleet_server_secret` and `entra_tenant_id`.
- `connectionAlreadyExists` *(409)* — A completed tenant record already exists for the requesting Fleet instance URL.
- `missingOriginHeader` *(400)* — The incoming request lacks an `Origin` header.

**Core Logic**
1. Validates the `Origin` header is present (used as `fleetInstanceUrl`).
2. Checks for an existing `MicrosoftComplianceTenant` record matching the requesting Fleet instance's URL.
   - If found and setup is **incomplete**, deletes the stale record and proceeds.
   - If found and setup is **complete**, throws `connectionAlreadyExists`.
3. Creates a new tenant record with a randomly generated 30-character `fleetServerSecret` and `setupCompleted: false`.
4. Returns the secret and tenant ID to the Fleet instance.

## Usage Example

```javascript
// POST request from a Fleet instance with the Origin header set
const response = await fetch('https://fleetdm.example.com/create-compliance-partner-tenant', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Origin': 'https://my-fleet-instance.example.com',
  },
  body: JSON.stringify({ entraTenantId: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx' }),
});

// Success response
// {
//   fleet_server_secret: "abc123...xyz",
//   entra_tenant_id: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
// }
```
