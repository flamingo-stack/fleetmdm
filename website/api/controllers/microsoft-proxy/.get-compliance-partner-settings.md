Retrieves compliance partner settings for a Microsoft Entra tenant, including setup status and a freshly generated admin consent URL.

## Key Components

**Inputs**
- `entraTenantId` *(string, required)* — The Microsoft Entra tenant ID to look up
- `fleetServerSecret` *(string, required)* — Secret used to authenticate the tenant record lookup

**Exits**
- `success` — Returns setup and admin consent status for the matched tenant
- `notFound` — Returned when no matching tenant record exists

**Core Logic**
1. Looks up the `MicrosoftComplianceTenant` record by `entraTenantId` + `fleetServerSecret`
2. Generates a random URL-friendly state token (30 chars) and persists it to the tenant record
3. Builds a Microsoft admin consent URL using the tenant ID, compliance partner client ID, state token, and redirect URI
4. Returns tenant status fields alongside the freshly built consent URL

**Response Shape**

| Field | Source |
|---|---|
| `entra_tenant_id` | Input `entraTenantId` |
| `setup_done` | `setupCompleted` on DB record |
| `admin_consented` | `adminConsented` on DB record |
| `admin_consent_url` | Dynamically built consent URL |
| `setup_error` | `setupError` on DB record |

## Usage Example

```javascript
// Called as a Sails action, e.g. via POST /api/v1/microsoft-compliance-partner/settings
const result = await sails.helpers.getCompliancePartnerSettings({
  entraTenantId: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  fleetServerSecret: 'your-fleet-server-secret',
});

console.log(result.admin_consent_url);
// https://login.microsoftonline.com/<tenantId>/adminconsent?client_id=...&state=...&redirect_uri=...
```
