Displays the "Remediate" page for the Microsoft Proxy section by rendering the corresponding view template.

## Key Components

- **`friendlyName`** – Human-readable name: `'View remediate'`
- **`exits.success`** – Renders the view at `pages/microsoft-proxy/remediate`
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Registered as a Sails.js action and mapped to a route, e.g.:
// config/routes.js
'GET /microsoft-proxy/remediate': { action: 'microsoft-proxy/view-remediate' }
```

When the route is hit, the action resolves via the `success` exit and renders the `pages/microsoft-proxy/remediate` view template with no additional data passed from the controller.

## Notes

- Follows the standard [Sails.js actions2](https://sailsjs.com/documentation/concepts/actions-and-controllers) convention
- No inputs or authentication logic are defined at this layer — those concerns are handled upstream via policies or the view template itself
