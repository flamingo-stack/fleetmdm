Handles the FAQ page route by rendering the `pages/faq` view template with no additional data.

## Key Components

- **friendlyName** – `'View faq'`
- **exits.success** – Renders the `pages/faq` view template on success
- **fn** – Async handler that returns an empty object, delegating all display logic to the view template

## Usage Example

```javascript
// Registered as a Sails.js action, typically bound in config/routes.js:
'GET /faq': { action: 'view-faq' }
```
