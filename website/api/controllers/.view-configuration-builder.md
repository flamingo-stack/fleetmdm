Handles routing for the Configuration Builder page, returning the corresponding view template upon a successful request.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `friendlyName` | `string` | Human-readable name: `'View configuration builder'` |
| `description` | `string` | Brief description of the action's purpose |
| `exits.success` | `object` | Maps successful responses to `pages/configuration-builder` view template |
| `fn` | `async function` | Action handler — returns an empty object to render the view |

## Usage Example

This is a Sails.js action wired to a route. When the route is matched, Sails invokes `fn` and renders the configured view template.

```javascript
// config/routes.js
module.exports.routes = {
  'GET /configuration-builder': { action: 'view-configuration-builder' }
};
```

The action itself requires no inputs and performs no data fetching — it simply signals a successful exit, delegating all rendering to the `pages/configuration-builder` view template.

```javascript
// Resulting behavior of fn()
fn: async function () {
  return {}; // Triggers `success` exit → renders pages/configuration-builder
}
```

## Notes

- No inputs are defined; the page renders statically with no server-side data dependencies.
- To pass data to the view (e.g., config options), extend the returned object and add corresponding `locals` in the view template.
