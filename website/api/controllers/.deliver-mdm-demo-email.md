Sends an MDM demo video email to a specified address using a predefined email template. Triggered by form submissions on the `/device-management` page.

## Key Components

- **`emailAddress`** *(input)*: Required string — the recipient's email address for the MDM demo video link
- **`fn`**: Invokes `sails.helpers.sendTemplateEmail` with the `email-mdm-video` template, using configured `fromEmailAddress` and `fromName` Sails globals
- **Error handling**: Intercepts send failures and re-throws a descriptive `Error` including the recipient address and original stack trace

## Usage Example

```javascript
await sails.helpers.deliverMdmDemoEmail.with({
  emailAddress: 'user@example.com',
});
```

## Notes

- Relies on `sails.config.custom.fromEmailAddress` and `sails.config.custom.fromName` being set in your Sails configuration
- The email body is defined in the `email-mdm-video` template — no dynamic `templateData` is passed
- Source: [`deliver-mdm-demo-email.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/deliver-mdm-demo-email.js)
