Sails.js action that renders the `fleetctl preview` page, handling Fleet Premium trial license key generation and validation for authenticated users.

## Key Components

- **`start` input** — Boolean flag; when `true`, hides "next steps" buttons on the rendered page (defaults to `false`)
- **Trial license detection** — Checks `req.me.fleetPremiumTrialLicenseKey` to determine if the logged-in user already has a trial license
- **Expiry check** — Compares `fleetPremiumTrialLicenseKeyExpiresAt` against `Date.now()` to flag expired licenses
- **Auto-provisioning** — Calls `sails.helpers.createLicenseKey` to generate a 30-day, 10-host trial license for authenticated users who lack one, then persists it to the `User` record
- **View exits** — Returns view data including `hideNextStepsButtons`, `trialLicenseKey`, `userHasTrialLicense`, and `userHasExpiredTrialLicense`

## Usage Example

```javascript
// GET /fleetctl-preview (standard page load)
// Renders page with "next steps" buttons visible
// → hideNextStepsButtons: false

// GET /fleetctl-preview?start=true
// Renders page with "next steps" buttons hidden
// → hideNextStepsButtons: true

// For authenticated users without a trial key, a license is auto-generated:
let trialLicenseKeyForThisUser = await sails.helpers.createLicenseKey.with({
  numberOfHosts: 10,
  organization: 'Fleet Premium trial',
  expiresAt: Date.now() + (1000 * 60 * 60 * 24 * 30), // 30 days
});
```

## Notes

- Unauthenticated users (`req.me` is falsy) receive the page with no trial license data
- Trial licenses are scoped to **10 hosts** and expire **30 days** from generation
