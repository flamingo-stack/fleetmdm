Handles the server-side action for rendering the Deployment page, returning an empty response object that triggers the associated view template.

## Key Components

- **`friendlyName`** – Human-readable label: `'View deployment'`
- **`exits.success`** – Maps to the view template at `pages/deployment`
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view layer

## Usage Example

```javascript
// Sails.js routes.js
'GET /deployment': { action: 'view-deployment' }
```

When a `GET` request hits `/deployment`, Sails invokes this action and renders `pages/deployment` with no additional data passed to the view.

## Notes

- No inputs or authorization logic are defined — add guards here if the page requires authentication
- To pass data to the view template, return a populated object from `fn`:

```javascript
fn: async function () {
  return { deployments: await Deployment.find() };
}
```
