Sails.js action that renders the Fleet MDM Transparency page, with logic to conditionally display a swag form and a Secureframe banner based on request context.

## Key Components

- **`showSwagForm`** – Boolean flag controlling swag form visibility; defaults to `false` and is set to `true` only when Cloudflare headers confirm the visitor is located within the contiguous United States (`cf-ipcountry === 'US'` and `cf-iplongitude > -125`)
- **`showSecureframeBanner`** – Boolean derived from the `utm_content` query parameter; renders a Secureframe-specific banner when `utm_content=secureframe`
- **Cloudflare header warning** – In `production`, logs a warning via `sails.log.warn` if the expected `cf-ipcountry` or `cf-iplongitude` headers are absent

## Usage Example

```javascript
// Navigating to the transparency page with Secureframe banner
// GET /transparency?utm_content=secureframe

// Expected view locals returned:
{
  showSecureframeBanner: true,  // utm_content matches 'secureframe'
  showSwagForm: false           // visitor not in contiguous US
}

// For a US-based visitor (contiguous US, e.g. longitude -95):
// Cloudflare headers: cf-ipcountry: 'US', cf-iplongitude: '-95'
{
  showSecureframeBanner: false,
  showSwagForm: true            // US + longitude > -125
}
```

## Notes

- Renders the view template at `pages/transparency`
- Swag form gating accounts for shipping cost constraints; Hawaii and Alaska are excluded since their longitudes fall outside the `> -125` threshold
- Cloudflare header checks are skipped in non-production environments to avoid false warnings during local development
