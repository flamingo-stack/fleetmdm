Handles unsubscribing a user from all newsletter emails by marking the associated `NewsletterSubscription` record as inactive.

## Key Components

- **`emailAddress`** *(input)*: Required string identifying the newsletter subscription to deactivate.
- **`fn`**: Async handler that sets `isUnsubscribedFromAll: true` on the matching `NewsletterSubscription` record, logs a warning if no record is found, and redirects the user to `/#unsubscribed`.

## Usage Example

```javascript
await sails.helpers.unsubscribeFromAllNewsletters({
  emailAddress: 'user@example.com'
});
```

## Behavior Notes

- If no `NewsletterSubscription` record matches the provided email, a warning is logged via `sails.log.warn` but the request still resolves successfully (no error is thrown).
- On success or graceful miss, the user is redirected to `/#unsubscribed`.
