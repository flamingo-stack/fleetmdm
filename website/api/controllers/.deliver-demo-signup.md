Sends a Slack notification to an internal channel when a user signs up for a Fleet live Q&A/demo session.

## Key Components

- **`emailAddress`** *(input)*: Required string — the email address of the user who signed up for the demo session.
- **`success`** *(exit)*: Returned when the Slack message is delivered successfully.
- **`fn`**: Core logic that posts a formatted message to the configured Slack webhook, including the signup email and a reminder to invite the user to the next demo session. Throws an error if `slackWebhookUrlForContactForm` is not configured.

## Usage Example

```javascript
await sails.helpers.deliverDemoSignup.with({
  emailAddress: 'hermione@hogwarts.edu'
});
```

## Configuration

Requires `sails.config.custom.slackWebhookUrlForContactForm` to be set. If missing, an error is thrown with the undelivered message content for manual recovery.

```javascript
// config/custom.js
module.exports.custom = {
  slackWebhookUrlForContactForm: 'https://hooks.slack.com/services/...'
};
```
