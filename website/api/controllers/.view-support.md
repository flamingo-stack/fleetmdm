Handles the HTTP GET request for the "Support" page, returning an empty data object that triggers rendering of the `pages/support` view template.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `friendlyName` | `string` | Human-readable action label: `'View support'` |
| `description` | `string` | Brief action description |
| `exits.success` | `object` | Maps successful response to `pages/support` view template |
| `fn` | `async function` | Action handler — returns an empty object to render the view |

## Usage Example

This is a Sails.js action wired to a route in `config/routes.js`:

```javascript
// config/routes.js
'GET /support': { action: 'view-support' }
```

When a user navigates to `/support`, the action executes and the `pages/support` template is rendered with no additional data passed to the view:

```javascript
fn: async function () {
  // No dynamic data needed — returns empty object to trigger success exit
  return {};
}
```

## Notes

- This is a static display action with no inputs or dynamic data fetching.
- To pass data to the view (e.g., support contact info or FAQs), add properties to the returned object:

```javascript
return {
  supportEmail: 'help@example.com',
  faqs: await SupportFaq.find()
};
```
