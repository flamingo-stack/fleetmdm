Sails.js page action that renders the **Software Management** marketing page, filtering and ordering testimonials for display in the scrollable tweets component.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `friendlyName` | `string` | Human-readable action label |
| `exits.success` | `object` | Renders `pages/software-management` view template |
| `exits.badConfig` | `object` | Returns a `badConfig` error if static content is misconfigured |
| `fn` | `async function` | Main action handler — validates config, filters, and sorts testimonials |

## Behavior

- **Config guard** — Throws `badConfig` if `sails.config.builtStaticContent.testimonials` is not a valid array.
- **Testimonial filtering** — When static content has been compiled, filters testimonials to those tagged with the `"Software management"` product category and present in the curated author list.
- **Custom ordering** — Sorts the filtered testimonials by a hardcoded author name order (13 authors defined).
- **Fallback** — If `compiledPagePartialsAppPath` is absent (i.e. `build-static-content` was never run), a placeholder testimonial injected by the custom hook is passed through unmodified.

## Usage Example

```javascript
// Registered automatically by Sails.js via its actions2 convention.
// Typically mapped in config/routes.js:
'GET /software-management': { action: 'view-software-management' }
```

The action returns `testimonialsForScrollableTweets` to the view:

```javascript
// pages/software-management.ejs (view layer)
<scrollable-tweets :testimonials="<%= JSON.stringify(testimonialsForScrollableTweets) %>">
</scrollable-tweets>
```
