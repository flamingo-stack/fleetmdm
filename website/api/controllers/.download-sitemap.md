Generates and returns a `sitemap.xml` file as an XML string, aggregating URLs from hand-coded pages, dynamic content (queries, policies, markdown pages, app library, scripts, MDM commands), and static content config.

## Key Components

- **`HAND_CODED_HTML_PAGES`** — Hardcoded list of static routes (home, pricing, landing pages, category pages, etc.) included directly in the sitemap
- **Dynamic query/policy pages** — Pulls `built-in` vitals, `query` types, and `policy` types from `sails.config.builtStaticContent.queries` and `.policies`, generating `/vitals/*`, `/reports/*`, and `/policies/*` URLs
- **Markdown pages** — Iterates `builtStaticContent.markdownPages` and includes `<lastmod>` timestamps from `pageInfo.lastModifiedAt`
- **App library/scripts/MDM commands** — Generates `/software-catalog/*`, `/scripts/*`, and `/mdm-commands/*` URLs from respective content arrays
- **Staging guard** — Throws an error if `sails.config.environment === 'staging'` to prevent search engine indexing accidents
- **`badConfig` exit** — Validates required `builtStaticContent` arrays before proceeding

## Usage Example

```javascript
// Invoked automatically via Sails.js routing (e.g. GET /sitemap.xml)
// Configured in config/routes.js:
'GET /sitemap.xml': { action: 'download-sitemap' }

// The action returns an XML string with Content-Type: text/xml
// Example output:
// <?xml version="1.0" encoding="UTF-8"?>
// <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
//   <url><loc>https://example.com/</loc></url>
//   <url><loc>https://example.com/pricing</loc></url>
//   <url>
//     <loc>https://example.com/docs/configuration</loc>
//     <lastmod>2024-01-15T00:00:00.000Z</lastmod>
//   </url>
//   ...
// </urlset>
```

> **Note:** XML-escaping is applied to all URLs via `_.escape()` to prevent malformed XML from special characters in slugs or base URLs. See [source](https://github.com/flamingo-stack/fleetmdm/blob/main/api/controllers/download-sitemap.js).
