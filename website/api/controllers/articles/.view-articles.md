Sails.js page action that fetches, filters, and sorts markdown-based articles by category, then passes the results to the articles view template.

## Key Components

| Export | Type | Description |
|---|---|---|
| `friendlyName` | `string` | Human-readable action name: `'View articles'` |
| `inputs.category` | `string` | Optional URL category filter, defaults to `''` |
| `exits.success` | `object` | Renders `pages/articles/articles` view template |
| `exits.badConfig` | `object` | Fires if `builtStaticContent` is misconfigured |
| `fn` | `async function` | Core action handler — filters, sorts, and returns article data |

## Logic Overview

- Extracts `category` from `req.path` (e.g., `/guides`, `/releases`)
- If category is `articles`, returns all markdown pages **excluding** `/guides`, `/whitepapers`, and `/webinars`
- Otherwise, filters pages whose URL starts with `/<category>`
- Sorts results by `meta.publishedOn` in descending order
- Sets `pageTitleForMeta`, `pageDescriptionForMeta`, and `currentSection` via a `switch` based on category

**Supported categories:** `articles`, `guides`, `releases`, `deploy`, `success-stories`, `securing`, `engineering`, `announcements`, `podcasts`, `whitepapers`, `webinars`

## Usage Example

```javascript
// This action is typically mapped in config/routes.js
'GET /articles': { action: 'view-articles' },
'GET /guides':   { action: 'view-articles' },

// The action reads category from req.path automatically.
// View receives:
// {
//   articles: [...],       // filtered + sorted markdown pages
//   category: 'guides',
//   pageTitleForMeta: 'Guides',
//   currentSection: 'documentation',
//   algoliaPublicKey: '...',
// }
```
