Displays the "Basic Webinar" page by resolving a webinar slug against pre-built static markdown content and returning the matched page data to the view template.

## Key Components

- **`slug`** (input) — Required string identifying which webinar to display; matched against `/webinars/{slug}` in `builtStaticContent.markdownPages`
- **`success`** exit — Renders `pages/articles/basic-webinar` with page data
- **`badConfig`** exit — Thrown when `sails.config.builtStaticContent.markdownPages` is missing or malformed
- **`notFound`** exit — Thrown when no markdown page matches the provided slug
- **`fn`** — Core handler that looks up the webinar page, extracts meta title/description, and returns view locals

## Usage Example

```javascript
// Invoked automatically by Sails.js router — example route binding in config/routes.js
'GET /webinars/:slug': { action: 'view-basic-webinar' }

// The action resolves the slug and returns these locals to the view template:
// {
//   pageTitleForMeta:       'Intro to Fleet MDM',
//   pageDescriptionForMeta: 'Learn the basics of Fleet MDM in this webinar.',
//   path:                   require('path'),
//   thisPage:               { url: '/webinars/intro-to-fleet-mdm', meta: { ... }, html: '...' }
// }
```

## Notes

- Requires `sails.config.builtStaticContent.markdownPages` to be populated at boot time (typically via a Sails hook that compiles markdown)
- Meta fields (`articleTitle`, `description`) are optional; if absent, the corresponding view locals will be `undefined`
