Displays a case study page by resolving a URL suffix to a matching markdown page from static content, with URL normalization, redirect handling, and support for an alternate basic article template via page-level meta configuration.

## Key Components

- **`pageUrlSuffix`** (input) — Relative path string used to look up the case study page (e.g., `case-study/foo`)
- **`success`** exit — Renders `pages/articles/case-study` EJS template
- **`useBasicArticleTemplate`** exit — Renders `pages/articles/basic-article` EJS template when the page's meta includes `useBasicArticleTemplate: true`
- **`badConfig`** exit — Thrown when `builtStaticContent` is not properly initialized
- **`notFound`** exit — Thrown when no matching markdown page can be found
- **`redirect`** exit — Thrown when a normalized URL variant matches, redirecting to the canonical URL

## Usage Example

```javascript
// Sails.js route configuration (config/routes.js)
'GET /customers/case-study/*': {
  action: 'view-case-study',
  pageUrlSuffix: 'case-study/'
}
```

```javascript
// Example markdown page meta (frontmatter) for basic article rendering
/*
---
articleTitle: "How Acme Corp Saved 40% on IT Costs"
description: "A deep dive into Acme Corp's journey with Fleet MDM."
useBasicArticleTemplate: true
---
*/
```

**URL normalization behavior:**

| Incoming URL | Normalized URL | Result |
|---|---|---|
| `/Customers/Case-Study/Foo` | `/customers/case-study/foo` | 301 redirect |
| `/customers/case-study//foo` | `/customers/case-study/foo` | 301 redirect |
| `/customers/case-study/foo` | — | Renders page |
| `/customers/case-study/missing` | — | 404 not found |

## Notes

- Requires `sails.config.builtStaticContent.markdownPages` to be compiled before this action runs
- The `currentSection` is hardcoded to `'customers'` for header navigation highlighting
