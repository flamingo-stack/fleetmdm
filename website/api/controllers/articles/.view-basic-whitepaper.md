Displays a whitepaper article page by resolving a URL slug against pre-built static markdown content and returning the matched page data to the view template.

## Key Components

- **`slug`** (input) — Required string identifying the whitepaper, mapped to `/whitepapers/{slug}` in the static content index
- **`success`** exit — Renders `pages/articles/basic-whitepaper` with the resolved page data
- **`badConfig`** exit — Thrown when `sails.config.builtStaticContent.markdownPages` is missing or malformed
- **`notFound`** exit — Thrown when no markdown page matches the provided slug

## Usage Example

```javascript
// Triggered via a route like:
// GET /whitepapers/:slug → view-basic-whitepaper

// Example request:
// GET /whitepapers/fleet-security-guide

// On success, the view receives:
{
  pageTitleForMeta: 'Fleet Security Guide',       // from thisPage.meta.articleTitle
  pageDescriptionForMeta: 'An overview of...',    // from thisPage.meta.description
  path: require('path'),                           // Node.js path module for template use
  thisPage: { url, meta, html, ... }              // Full matched markdown page object
}
```

## Notes

- Content is sourced from `sails.config.builtStaticContent.markdownPages`, which must be populated at build time
- Slug matching uses `encodeURIComponent` to safely construct the lookup URL
- Meta fields (`pageTitleForMeta`, `pageDescriptionForMeta`) are only set if present in the page's frontmatter — no fallback defaults are applied
