Sails.js action that renders a static markdown-based comparison page by looking up a URL slug in pre-built static content.

## Key Components

- **`slug`** (required input) — URL segment used to locate the matching comparison page (e.g., `/compare/<slug>`)
- **`badConfig` exit** — thrown when `sails.config.builtStaticContent.markdownPages` is missing or malformed
- **`notFound` exit** — thrown when no markdown page matches the provided slug
- **`success` exit** — renders `pages/articles/basic-comparison` with resolved page data

## Usage Example

```javascript
// Called via Sails routing, e.g. config/routes.js
'GET /compare/:slug': { action: 'view-basic-comparison' }

// The action resolves the slug, finds the matching page, and returns:
{
  pageTitleForMeta: 'Fleet vs. Competitor',
  pageDescriptionForMeta: 'A detailed comparison...',
  path: require('path'),
  thisPage: { url: '/compare/fleet-vs-x', meta: { ... }, ... }
}
```

## Notes

- Relies on `sails.config.builtStaticContent.markdownPages` being populated at build time (e.g., via a bootstrap or build script)
- Uses `encodeURIComponent(slug)` when matching URLs, so special characters in slugs are handled safely
- `pageTitleForMeta` and `pageDescriptionForMeta` are conditionally set from `thisPage.meta` — both are `undefined` if the corresponding meta fields are absent
