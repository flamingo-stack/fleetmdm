Handles routing and view rendering for individual blog article pages, resolving markdown content by URL path and preparing metadata for display.

## Key Components

- **`urlWildcardSuffix`** — Captures the dynamic URL segment after the base route to identify the requested article
- **URL normalization** — Lowercases, deduplicates slashes, and strips leading/trailing slashes from malformed URLs, issuing a `redirect` to the canonical URL when a match is found
- **`categoryFriendlyNamesByCategorySlug`** — Maps URL path segments (e.g. `guides`, `releases`) to human-readable category labels
- **Meta tag resolution** — Derives `pageTitleForMeta` and `pageDescriptionForMeta` from article frontmatter, falling back to `articleTitle + authorFullName` when no explicit description is provided

## Exits

| Exit | Behavior |
|---|---|
| `success` | Renders `pages/articles/basic-article` view |
| `badConfig` | Fires when `builtStaticContent` is misconfigured |
| `notFound` | 404 when no matching markdown page exists |
| `redirect` | 301 to canonical URL when a normalized match is found |

## Usage Example

```javascript
// Registered in config/routes.js as a wildcard route:
'GET /guides/*': { action: 'view-basic-article' }

// A request to /guides/deploying-fleet-on-render resolves
// the matching markdownPage and renders the article view with:
{
  thisPage,              // matched markdown page object
  markdownPages,         // all available pages (for nav/related)
  pageTitleForMeta,      // from meta.articleTitle
  pageDescriptionForMeta,// from meta.description or auto-generated
  pageImageForMeta,      // from meta.articleImageUrl
  categoryFriendlyName,  // e.g. "Guides"
  algoliaPublicKey,      // for client-side search
}
```

## Notes

- Requires `sails.config.builtStaticContent.markdownPages` and `compiledPagePartialsAppPath` to be populated at build time; throws `badConfig` if either is missing
