Generates and delivers a signed Apple MDM Certificate Signing Request (CSR) by invoking the `mdm-gen-cert` binary and returning or emailing the result to the requesting user.

## Key Components

### Inputs
| Parameter | Type | Required | Description |
|---|---|---|---|
| `unsignedCsrData` | `string` | ✅ | Base64-encoded CSR from Fleet server or `fleetctl` |
| `deliveryMethod` | `string` | ❌ | `'email'` (default) or `'json'` |

### Exits
| Exit | Description |
|---|---|
| `success` | Returns signed CSR object `{ csr: string }` |
| `invalidEmailDomain` | Email domain is on the configured denylist |
| `csrMissingRequiredValue` | CSR is missing `email`, `org`, or `request` fields |
| `badRequest` | Invalid input or unrecognized delivery method |

### Core Flow
1. Validates presence of `.tools/mdm-gen-cert` binary and required config values (`mdmVendorCertPem`, `mdmVendorKeyPem`, `mdmVendorKeyPassphrase`)
2. Executes `mdm-gen-cert` via `sails.helpers.process.executeCommand` with vendor credentials passed as environment variables
3. Parses JSON output and validates `email`, `org`, and `request` fields
4. Checks email validity and domain against `bannedEmailDomainsForCSRSigning`
5. Persists a `CertificateSigningRequest` record to the database
6. Delivers the signed CSR via email (as `apple-apns-csr.txt` attachment) or JSON response
7. Posts a Slack notification on success

## Usage Example

```javascript
// Deliver via email (default)
await sails.helpers.deliverAppleCsr.with({
  unsignedCsrData: '<base64-encoded-csr>',
  deliveryMethod: 'email',
});

// Deliver as JSON response
const result = await sails.helpers.deliverAppleCsr.with({
  unsignedCsrData: '<base64-encoded-csr>',
  deliveryMethod: 'json',
});
// result => { csr: '<base64-encoded-signed-csr>' }
```

## Required Configuration

```javascript
// config/custom.js
mdmVendorCertPem: '...',
mdmVendorKeyPem: '...',
mdmVendorKeyPassphrase: '...',
bannedEmailDomainsForCSRSigning: ['gmail.com', 'yahoo.com'],
slackWebhookUrlForMDMSignups: 'https://hooks.slack.com/...',
```

> **Note:** The `mdm-gen-cert` binary must exist at `.tools/mdm-gen-cert` relative to the app root. See the [repository](https://github.com/flamingo-stack/fleetmdm) for setup instructions.
