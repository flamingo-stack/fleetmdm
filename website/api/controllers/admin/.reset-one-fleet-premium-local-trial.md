Resets a Fleet Premium local trial for a user by generating a new 30-day license key and updating their account record.

## Key Components

**Inputs**
- `emailAddress` *(string, required)* — The email address of the user whose trial will be reset

**Exits**
- `success` — Trial was successfully reset
- `userNotFound` — No user found for the provided email address
- `trialTypeUnsupported` — User has a Render trial (not eligible for reset via this action)

**Core Logic**
- Looks up the user by email address
- Guards against Render-type trials (only local trials are supported)
- Generates a new license key via `sails.helpers.createLicenseKey` for 10 hosts, scoped to the user's organization, expiring 30 days from now
- Updates `fleetPremiumTrialLicenseKey` and `fleetPremiumTrialLicenseKeyExpiresAt` on the user record

## Usage Example

```javascript
// Invoke from a controller or shell script
await sails.helpers.resetOneFleetPremiumLocalTrial.with({
  emailAddress: 'user@example.com',
});
```

> **Note:** This action only supports users with a local trial (`fleetPremiumTrialType !== 'render trial'`). Attempting to reset a Render trial will throw `trialTypeUnsupported`.
