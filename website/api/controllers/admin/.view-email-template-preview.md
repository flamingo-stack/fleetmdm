A Sails.js controller action that renders previews of email templates for admin inspection, supporting both a full previewer UI and raw HTML output modes.

## Key Components

- **`template`** (input) — Path identifier for the email template, matching the convention used by `sendTemplateEmail()`
- **`raw`** (input) — Boolean flag; when `true`, returns raw compiled HTML instead of the previewer page
- **`success` exit** — Renders the `pages/admin/email-preview` view with preview UI context
- **`sendRawHtmlInstead` exit** — Returns raw HTML string (HTTP 200), used by iframes to avoid style bleed
- **`switch` block** — Maps each supported template name to its layout and fake data fixture
- **`sails.renderView()`** — Compiles the EJS/HTML template with injected fake data and utilities (`url`, `util`, `_`, `moment`)

## Supported Templates

| Template | Layout |
|---|---|
| `email-reset-password`, `email-verify-account`, `email-verify-new-email` | `layout-email` |
| `email-nurture-stage-three/four/five` | `layout-nurture-email` |
| `email-deal-registration`, `email-partner-registration` | `layout-email` |
| `internal/email-contact-form` | *(none)* |
| *(default)* | `layout-email-newsletter` |

## Usage Example

```bash
# View the full previewer UI
GET /admin/email-template-preview/email-reset-password

# Get raw HTML only (suitable for iframes)
GET /admin/email-template-preview/email-reset-password?raw=true
```

```javascript
// Example iframe usage in the previewer page
<iframe src="/admin/email-template-preview/email-reset-password?raw=true" />
```

> **Note:** When adding a new email template, add a corresponding `case` in the `switch` statement with appropriate fake data — otherwise rendering will fail. See [`view-email-template-preview.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/api/controllers/admin/view-email-template-preview.js) for the full list of supported templates.
