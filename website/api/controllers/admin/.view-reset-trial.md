Renders the admin "Reset trial" page by returning an empty response object that maps to the `pages/admin/reset-trial` view template.

## Key Components

- **`friendlyName`** – Human-readable label: `'View reset trial'`
- **`exits.success`** – Maps the successful response to the `pages/admin/reset-trial` view template
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view layer

## Usage Example

```javascript
// Registered as a Sails.js action, typically mapped in config/routes.js
'GET /admin/reset-trial': { action: 'admin/view-reset-trial' }
```

When a `GET` request hits the route, the action resolves via the `success` exit and renders `pages/admin/reset-trial` with no additional data passed to the view.
