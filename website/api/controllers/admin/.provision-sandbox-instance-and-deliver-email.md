Provisions a Fleet Sandbox instance for a waitlisted user and sends a notification email once the instance is ready.

## Key Components

- **Input:** `userId` *(number, required)* — Database ID of the user on the Fleet Sandbox waitlist
- **Exit:** `success` — User successfully removed from the waitlist after provisioning
- **Core logic (`fn`):**
  - Validates the user is still on the waitlist before proceeding
  - Calls `fleetSandboxCloudProvisioner.provisionNewFleetSandboxInstance` to provision the sandbox
  - Updates the user record with `fleetSandboxURL`, `fleetSandboxExpiresAt`, `fleetSandboxDemoKey`, and sets `inSandboxWaitlist: false`
  - Sends a confirmation email using the `email-sandbox-ready-approved` template

## Usage Example

```javascript
// Invoked as a Sails helper/action, typically from a background job or scheduled task
await sails.helpers.provisionSandboxInstanceAndDeliverEmail.with({
  userId: 42
});
```

## Error Handling

Throws a descriptive `Error` in two scenarios:
- The user is no longer on the waitlist (guard against duplicate processing)
- The cloud provisioner fails (error is intercepted and re-thrown with context)

## Notes

- Uses the `email-sandbox-ready-approved` Sails template for the notification email
- Sender details are pulled from `sails.config.custom` (`fromEmailAddress`, `fromName`)
- Designed to be idempotent-safe via the `inSandboxWaitlist` guard check
