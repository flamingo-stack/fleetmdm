Renders the "Generate License" admin page for creating Fleet Premium licenses, with pre-flight validation of required license key generator configuration.

## Key Components

- **`friendlyName`** – Human-readable action label: `'View generate license'`
- **`exits.success`** – Renders the view at `pages/admin/generate-license`
- **`fn`** – Async handler that validates two required Sails config values before serving the page:
  - `sails.config.custom.licenseKeyGeneratorPrivateKey`
  - `sails.config.custom.licenseKeyGeneratorPassphrase`

## Usage Example

This is a Sails.js page action wired to an admin route. Ensure the required config values are set before navigating to the page:

```javascript
// config/custom.js
module.exports.custom = {
  licenseKeyGeneratorPrivateKey: process.env.LICENSE_KEY_GENERATOR_PRIVATE_KEY,
  licenseKeyGeneratorPassphrase: process.env.LICENSE_KEY_GENERATOR_PASSPHRASE,
};
```

If either value is missing, the action throws an `Error` before rendering:

```text
Missing config variable: The license key generator private key missing
(sails.config.custom.licenseKeyGeneratorPrivateKey)!
To use this tool, a license key generator private key is required.
```

On success, returns an empty object `{}` and delegates rendering to the `pages/admin/generate-license` view template.

## Notes

- Access should be restricted to admin users via Sails policies on the route binding this action.
- Both `licenseKeyGeneratorPrivateKey` and `licenseKeyGeneratorPassphrase` should be sourced from environment variables and never hard-coded.
