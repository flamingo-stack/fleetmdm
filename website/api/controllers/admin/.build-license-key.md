Delegates to the `createLicenseKey` helper to build and return a Fleet Premium license key string for a given organization and host count.

## Key Components

**Inputs**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `numberOfHosts` | `number` | ✅ | Number of hosts the license covers |
| `organization` | `string` | ✅ | Name of the licensed organization |
| `expiresAt` | `number` | ✅ | JS timestamp for license expiration |
| `partnerName` | `string` | ❌ | Reseller partner name (optional) |

**Exits**

- `success` — Returns the generated license key as a `string`

## Usage Example

```javascript
// Invoke via Sails machine runner
let licenseKey = await sails.helpers.buildLicenseKey.with({
  numberOfHosts: 500,
  organization: 'Acme Corp',
  expiresAt: new Date('2026-01-01').getTime(),
  partnerName: 'Flamingo MSP', // optional
});

console.log(licenseKey); // → Fleet Premium license key string
```

## Notes

- `expiresAt` expects a **JavaScript timestamp** (milliseconds since epoch) — use `Date.getTime()` or `Date.now()`
- `partnerName` is optional; omit it for direct (non-reseller) licenses
- Internally delegates to [`sails.helpers.createLicenseKey`](https://github.com/flamingo-stack/fleetmdm/blob/main/api/helpers/create-license-key.js)
