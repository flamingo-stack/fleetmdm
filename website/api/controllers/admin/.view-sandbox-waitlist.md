Renders the admin "Sandbox Waitlist" page by fetching all users who are currently queued for a sandbox instance, sorted by signup date (oldest first).

## Key Components

- **`fn`** — Async action function that queries the `User` model for records where `inSandboxWaitlist` is `true`, sorted ascending by `createdAt`
- **`exits.success`** — Renders the view template at `pages/admin/sandbox-waitlist` with the fetched user list

## Usage Example

This is a Sails.js page action bound to a route in your app's router. Example route binding:

```javascript
// config/routes.js
'GET /admin/sandbox-waitlist': { action: 'view-sandbox-waitlist' }
```

The view template receives the following locals:

```javascript
// pages/admin/sandbox-waitlist.ejs (available locals)
usersWaitingForSandboxInstance // Array of User records, sorted by createdAt ASC
```

Example template usage:

```javascript
// Iterating over waitlisted users in the view
usersWaitingForSandboxInstance.forEach(user => {
  console.log(user.emailAddress, user.createdAt);
});
```

## Notes

- Access should be restricted to admin users via a policy (e.g., `isLoggedIn`, `isSuperAdmin`) configured in `config/policies.js`
