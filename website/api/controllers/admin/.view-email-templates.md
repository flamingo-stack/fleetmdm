Displays the admin "Email templates" page by scanning the filesystem for available email templates and returning their relative paths to the view.

## Key Components

- **`templatePaths`** — Top-level email templates discovered under `views/emails/` (depth: 1, no dirs/symlinks)
- **`markdownEmailPaths`** — Newsletter markdown email templates discovered under `views/emails/newsletter/` (depth: 99, recursive)
- **`exits.success.viewTemplatePath`** — Renders `pages/admin/email-templates`

## Usage Example

```javascript
// Called automatically by Sails.js router; no direct invocation needed.
// Returns an object passed as locals to the view:
{
  templatePaths: ['layout-email', 'welcome'],
  markdownEmailPaths: ['newsletter/march-update', 'newsletter/product-announcement']
}
```

Path processing strips the `views/emails/` prefix and file extension from each discovered path, producing clean relative slugs suitable for template rendering or linking.

## Notes

- Uses `sails.helpers.fs.ls` for filesystem traversal
- Symlinks and directories are excluded from both scans
- Extension stripping is done via `path.extname` + `String.split`, returning the bare template slug
