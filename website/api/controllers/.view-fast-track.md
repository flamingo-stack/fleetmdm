Renders the "Fast Track" page by returning an empty response object that triggers the `pages/fast-track` view template.

## Key Components

- **friendlyName** – `'View fast track'`
- **description** – `'Display "Fast track" page.'`
- **exits.success** – Maps to the `pages/fast-track` view template
- **fn** – Async handler that returns an empty object to render the view

## Usage Example

```javascript
// Invoked automatically by Sails.js routing
// Example route binding in config/routes.js:
'GET /fast-track': { action: 'view-fast-track' }
```

## Notes

This is a minimal Sails.js action with no inputs or data processing — it simply responds with an empty object, delegating all rendering to the `pages/fast-track` view template.
