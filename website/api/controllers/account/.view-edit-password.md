Renders the "Edit password" page for the current user's account, returning an empty response object to the associated view template.

## Key Components

- **`friendlyName`** – Human-readable label: `'View edit password'`
- **`exits.success`** – Directs to the view template at `pages/account/edit-password`
- **`fn`** – Async handler that returns an empty object `{}` to the view

## Usage Example

```javascript
// Registered as a Sails.js action and mapped to a route, e.g. in config/routes.js:
'GET /account/password': 'account/view-edit-password'
```

The action requires no inputs and passes no additional data to the view, relying solely on session context (e.g. the logged-in user) for rendering.
