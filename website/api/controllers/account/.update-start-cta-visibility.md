Manages the visibility state of the "start" call-to-action (CTA) banner by toggling a session-based timestamp that controls when the CTA should be shown or hidden.

## Key Components

- **`fn`** — Core action handler that reads and writes `req.session.expandCtaAt`:
  - If `expandCtaAt` is already set (CTA is collapsed), resets it to `0` to expand the CTA immediately.
  - If `expandCtaAt` is not set (CTA is visible), sets it to 24 hours from now to collapse the CTA.

## Behavior

| Session State | Action Taken |
|---|---|
| `expandCtaAt` is set (truthy) | Resets to `0` — CTA expands |
| `expandCtaAt` is not set (falsy) | Sets to `now + 24h` — CTA collapses |

## Usage Example

```javascript
// Called via a route action (e.g., POST /api/v1/update-start-cta-visibility)
// Session is managed automatically by Sails.js

// First call — collapses CTA for 24 hours:
// req.session.expandCtaAt = Date.now() + 86400000

// Second call — expands CTA immediately:
// req.session.expandCtaAt = 0
```

## Notes

- Throws an explicit error if the session object is missing to catch configuration or middleware issues early.
- No inputs or exits are defined; the action relies entirely on session state.
- Part of the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) web application's UI state management layer.
