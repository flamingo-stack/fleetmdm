Updates the Stripe payment source for the authenticated user and syncs the card metadata to the local database, supporting both adding/updating and removing a card.

## Key Components

- **`stripeToken`** – Single-use Stripe Checkout token identifying the payment source; omit or pass `""` to remove the card
- **`billingCardLast4 / Brand / ExpMonth / ExpYear`** – Card display metadata returned by Stripe; all omitted when removing a card
- **`sails.helpers.stripe.saveBillingInfo`** – Helper that upserts the payment source on the Stripe customer record (5 s timeout with retry)
- **`User.updateOne`** – Persists the Stripe customer ID and masked card details (last 4 digits only) to the database; clears all fields when the token is absent

## Usage Example

```javascript
// Add or update a billing card
await sails.helpers.updateBillingCard.with({
  stripeToken: 'tok_199k3qEXw14QdSnRwmsK99MH',
  billingCardLast4: '4242',
  billingCardBrand: 'visa',
  billingCardExpMonth: '08',
  billingCardExpYear: '2023',
});

// Remove a billing card (omit token)
await sails.helpers.updateBillingCard.with({});
```

## Notes

- Only the **last 4 digits** of the card number are stored — never the full PAN — keeping the implementation outside PCI DSS scope
- The `stripeCustomerId` returned by the Stripe helper is written back to the user record, covering the case where a Stripe customer entry is created for the first time
- `hasBillingCard` is set to `false` and all card fields are cleared atomically when no token is provided
