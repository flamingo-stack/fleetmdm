Handles routing logic for the Fleet Premium trial page, redirecting users based on their subscription status, trial state, and trial type, or generating a new trial license key for first-time visitors.

## Key Components

### Exits

| Exit | Type | Description |
|------|------|-------------|
| `success` | View | Renders the `fleet-premium-trial` page with trial data |
| `redirectToLiveFleetInstance` | Redirect | Sends user to their active Render-hosted trial instance |
| `redirectToCustomerDashboard` | Redirect | Sends existing subscribers to `/customers/dashboard` |

### Core Logic (`fn`)

1. **Existing subscription check** — Queries `Subscription` model; redirects paying customers to the customer dashboard
2. **Trial key validation** — Checks `fleetPremiumTrialLicenseKey` on the user record and evaluates expiry against `Date.now()`
3. **Render trial redirect** — If the user has an active `render trial` type, fetches the `RenderProofOfValue` record and redirects to `instanceUrl`
4. **License key generation** — For users without a trial key, calls `sails.helpers.createLicenseKey` (10 hosts, 30-day expiry) and persists it to the `User` record

## Usage Example

```javascript
// Sails.js route binding (config/routes.js)
'GET /try-fleet': 'view-fleet-premium-trial-or-redirect',

// Data returned to the view on success:
{
  trialIsExpired: false,
  trialType: 'render trial',       // or 'license key', etc.
  trialLicenseKey: 'eyJ...',
}
```
