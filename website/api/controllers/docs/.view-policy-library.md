Sails.js page action that fetches and categorizes built-in policy library content by platform, then renders the Policy Library documentation page.

## Key Components

**Exits**
- `success` — Renders `pages/docs/policy-library` with filtered policy data
- `badConfig` — Thrown when `sails.config.builtStaticContent.policies` is missing or malformed

**Platform Filters**
Policies are filtered from `builtStaticContent.policies` (kind: `'policy'`) into four platform buckets by splitting the `platform` field on `', '`:

| Variable | Platform Token |
|---|---|
| `macOsPolicies` | `darwin` |
| `windowsPolicies` | `windows` |
| `linuxPolicies` | `linux` |
| `chromePolicies` | `chrome` |

**View Locals Returned**
- `macOsPolicies`, `windowsPolicies`, `linuxPolicies`, `chromePolicies` — filtered policy arrays
- `algoliaPublicKey` — passed through from `sails.config.custom` for client-side search

## Usage Example

```javascript
// Invoked automatically by Sails router — no direct call needed.
// Ensure builtStaticContent is populated before startup, e.g.:
sails.config.builtStaticContent = {
  policies: [
    { kind: 'policy', platform: 'darwin, windows', name: 'Disk Encryption' },
    { kind: 'policy', platform: 'linux',            name: 'SSH Config'      },
  ]
};

// GET /docs/policy-library
// Returns: { macOsPolicies, windowsPolicies, linuxPolicies, chromePolicies, algoliaPublicKey }
```
