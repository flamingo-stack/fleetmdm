Displays the policy details page for a single policy in Fleet's standard policy library, resolved by its unique slug.

## Key Components

- **`slug`** (input): Required string identifying the policy (e.g., `'get-macos-disk-free-space-percentage'`)
- **`fn`**: Looks up the policy from `builtStaticContent.policies`, resolves associated osquery table metadata for syntax highlighting, and returns view data
- **Syntax highlighting logic**: Intersects query words with known osquery table names to extract `columnNamesForSyntaxHighlighting` and `tableNamesForSyntaxHighlighting`
- **Exits**: `success` → renders `pages/docs/policy-details`, `notFound` → 404, `badConfig` → config error

## Usage Example

```javascript
// Triggered via route, e.g. GET /policies/:slug
// Example: GET /policies/get-macos-disk-free-space-percentage

// The action resolves the policy and returns to the view:
{
  policy,                         // Full policy object from builtStaticContent
  queryLibraryYmlRepoPath,        // GitHub path to the policy library YAML
  pageTitleForMeta,               // e.g. "Require FileVault | Policy details"
  pageDescriptionForMeta,         // Policy description or generic fallback
  columnNamesForSyntaxHighlighting, // Column names from referenced osquery tables
  tableNamesForSyntaxHighlighting,  // osquery table names used in the query
  algoliaPublicKey,               // For search integration
}
```

## Notes

- Requires `sails.config.builtStaticContent.policies` and `policyLibraryYmlRepoPath` to be set at build time; throws `badConfig` if either is missing
- Table metadata is sourced from `builtStaticContent.markdownPages` filtered by `/tables/` URL prefix
