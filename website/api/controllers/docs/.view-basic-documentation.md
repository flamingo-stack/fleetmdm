Sails.js action that handles routing and rendering for the Fleet documentation section, serving both the `/docs` landing page and individual documentation pages from pre-built static markdown content.

## Key Components

- **`urlWildcardSuffix`** — Captures the URL path segment after `/docs/` to identify the requested page
- **`pageUrlSuffix` input** — The relative doc path (e.g., `using-fleet/supported-browsers`), defaults to empty string for the landing page
- **URL normalization** — Redirects malformed URLs (wrong casing, duplicate/trailing slashes) to their canonical form
- **Geo-based swag form** — Uses Cloudflare headers (`cf-ipcountry`, `cf-iplongitude`) to show a swag form only to contiguous US visitors
- **`builtStaticContent` guard** — Validates required static content config before proceeding, throws `badConfig` if missing

## Exits

| Exit | Behavior |
|---|---|
| `success` | Renders `pages/docs/basic-documentation` view |
| `badConfig` | Static content config is missing or malformed |
| `notFound` | No matching doc page found after URL normalization |
| `redirect` | Canonical URL found after case/slash correction |

## Usage Example

```javascript
// Registered in config/routes.js as a wildcard route:
'GET /docs/*': { action: 'view-basic-documentation' }

// Accessing /docs/using-fleet/supported-browsers resolves:
// thisPage = { url: '/docs/using-fleet/supported-browsers', title: '...', meta: { description: '...' } }

// Accessing /docs/Using-Fleet/Supported-Browsers triggers:
// → redirect to /docs/using-fleet/supported-browsers

// Accessing /docs renders:
// → the landing page (SECTION_URL_PREFIX with no suffix)
```
