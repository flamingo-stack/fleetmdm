Renders the "Script details" page by looking up a script from the built static content library using its unique slug.

## Key Components

**Inputs**
- `slug` *(string, required)* — Unique identifier for the script (e.g., `'macos-uninstall-fleetd'`)

**Exits**
- `success` — Renders `pages/docs/script-details` with script data
- `notFound` — Returns a 404 response if the slug doesn't match any script
- `badConfig` — Returns a config error if `builtStaticContent.scripts` is missing or malformed

**fn**
Core handler that validates static content config, locates the matching script by slug, and returns view locals including SEO metadata and the Algolia public key.

## Usage Example

```javascript
// Triggered via a route like: GET /controls/scripts/:slug
// Example request: GET /controls/scripts/macos-uninstall-fleetd

// On success, the view receives:
{
  thisScript: {
    slug: 'macos-uninstall-fleetd',
    name: 'Uninstall Fleetd',
    description: 'Removes the fleetd agent from macOS.',
    // ...other script fields
  },
  pageTitleForMeta: 'Uninstall Fleetd | Fleet controls library',
  pageDescriptionForMeta: 'Removes the fleetd agent from macOS.',
  algoliaPublicKey: 'your-algolia-key',
}
```

## Notes

- Falls back to a generic `pageDescriptionForMeta` if the script has no `description` field
- Depends on `sails.config.builtStaticContent.scripts` being populated at build time
