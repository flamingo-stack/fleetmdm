Renders the "App details" page for a specific application in Fleet's maintained software catalog, looking up the app by its identifier and returning its data to the view template.

## Key Components

- **`appIdentifier`** (input) — Required string identifier for the app (e.g., `'1password'`) used to look up the entry in the app library
- **`success`** exit — Renders `pages/docs/app-details` with the matched app's data
- **`badConfig`** exit — Thrown when `sails.config.builtStaticContent.appLibrary` is missing or malformed
- **`notFound`** exit — Thrown when no app matching `appIdentifier` exists in the catalog

## Usage Example

```javascript
// Triggered by a route like: GET /software/:appIdentifier
// Sails.js resolves inputs from route params automatically

await sails.helpers.http.get('/software/1password');
// → Renders pages/docs/app-details with:
// {
//   thisApp: { identifier: '1password', name: '1Password', ... },
//   pageTitleForMeta: '1Password | Fleet software catalog',
//   algoliaPublicKey: '...'
// }
```

## Notes

- Requires `sails.config.builtStaticContent.appLibrary` to be populated at build time; throws `badConfig` if absent
- Page title is auto-generated as `{app.name} | Fleet software catalog`; a `pageDescriptionForMeta` field is stubbed out for future use
- `algoliaPublicKey` is passed to the view to support client-side search functionality
