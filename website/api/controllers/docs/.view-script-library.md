Renders the Script Library page by reading pre-built static content and organizing scripts by platform.

## Key Components

- **`fn`** — Async handler that validates static content config, filters scripts by platform, and returns categorized data to the view template
- **`exits.success`** — Renders `pages/docs/script-library` view template
- **`exits.badConfig`** — Throws if `builtStaticContent.scripts` is missing or malformed

## Logic Flow

1. Validates that `sails.config.builtStaticContent.scripts` is a populated array
2. Filters the scripts array into three platform-specific subsets:
   - `macOsScripts` — scripts where `platform === 'macos'`
   - `windowsScripts` — scripts where `platform === 'windows'`
   - `linuxScripts` — scripts where `platform === 'linux'`
3. Passes platform groups and the Algolia public key to the view

## Usage Example

```javascript
// Called automatically by Sails.js router — example route binding:
// config/routes.js
'GET /docs/scripts': { action: 'view-script-library' }

// Data passed to the view template:
{
  macOsScripts: [{ name: 'rotate-password', platform: 'macos', ... }],
  windowsScripts: [{ name: 'disable-bitlocker', platform: 'windows', ... }],
  linuxScripts: [{ name: 'check-updates', platform: 'linux', ... }],
  algoliaPublicKey: 'abc123...'
}
```

## Dependencies

| Dependency | Source |
|---|---|
| `builtStaticContent.scripts` | Pre-built static content config (`sails.config`) |
| `algoliaPublicKey` | Custom Sails config (`sails.config.custom`) |
| `lodash` (`_`) | Sails.js global — used for `_.isObject`, `_.isArray`, `_.filter` |
