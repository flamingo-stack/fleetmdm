Renders the osquery table details page by looking up a specific table by slug from pre-built static content and returning it alongside metadata for SEO and navigation.

## Key Components

**Inputs**
- `tableName` — URL slug of the osquery table to display (e.g., `account_policy_data`)

**Exits**
- `success` — Renders `pages/docs/osquery-table-details` with table data
- `badConfig` — Thrown when `builtStaticContent` is missing or misconfigured
- `notFound` — Thrown when no matching table page is found for the given slug

**Returned View Locals**
| Key | Description |
|---|---|
| `tableToDisplay` | The matched markdown page object for the requested table |
| `allTables` | All pages under the `/tables/` URL prefix, used for navigation |
| `pageTitleForMeta` | SEO-optimized `<title>` string |
| `pageDescriptionForMeta` | SEO meta description |
| `algoliaPublicKey` | Public key for Algolia search integration |
| `path` | Node.js `path` module, passed to the view layer |

## Usage Example

```javascript
// Triggered via routing, e.g.:
// GET /tables/account_policy_data
// -> calls view-osquery-table-details with { tableName: 'account_policy_data' }

// The action resolves the table from builtStaticContent:
let tableToDisplay = _.find(
  sails.config.builtStaticContent.markdownPages,
  { url: '/tables/' + tableName }
);

// If not found, a 404 is returned automatically via the `notFound` exit.
```

## Notes

- Table pages are expected to be pre-compiled into `sails.config.builtStaticContent.markdownPages` at build time.
- The URL convention for table pages is `/tables/<tableName>`.
