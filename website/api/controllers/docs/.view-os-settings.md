Renders the OS settings documentation page, returning the Algolia public key for client-side search functionality.

## Key Components

- **`exits.success`** — Renders the `pages/docs/os-settings` view template
- **`fn`** — Async handler that returns configuration data to the view

## Usage Example

```javascript
// Sails.js route mapping (config/routes.js)
'GET /docs/os-settings': { action: 'view-os-settings' }
```

## Notes

- Passes `algoliaPublicKey` from `sails.config.custom` to enable Algolia-powered search on the docs page
- No inputs or authentication required; purely a view-rendering action
