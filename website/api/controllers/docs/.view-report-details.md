Displays the report details page for a specific query in Fleet's standard query library, identified by a unique slug. Handles legacy redirects for policies that previously lived at `/queries/*` URLs.

## Key Components

**Inputs**
- `slug` *(string, required)* — Unique identifier for the query (e.g., `get-macos-disk-free-space-percentage`)

**Exits**
- `success` — Renders `pages/docs/report-details` with report data
- `notFound` — No matching query or policy found for the slug
- `badConfig` — Required static content config (`builtStaticContent.queries`, `.policies`, `.queryLibraryYmlRepoPath`) is missing
- `redirectToPolicy` — Slug matches a policy; redirects to `/policies/:slug`

**Core Logic**
1. Validates that `builtStaticContent` is properly configured
2. Looks up the report by slug in `builtStaticContent.queries`
3. Falls back to `builtStaticContent.policies` for legacy URL redirection
4. Cross-references osquery table documentation to extract `columnNamesForSyntaxHighlighting` and `tableNamesForSyntaxHighlighting` for syntax highlighting in the UI
5. Builds meta title/description with safe fallbacks

## Usage Example

```javascript
// Route: GET /reports/:slug
// Example: GET /reports/get-macos-disk-free-space-percentage

// View receives:
{
  report,                          // Full query object from the library
  reportLibraryYmlRepoPath,        // Repo path to the YAML source file
  pageTitleForMeta,                // e.g. "Get macOS disk free space | Report details"
  pageDescriptionForMeta,          // Report description or generic fallback
  columnNamesForSyntaxHighlighting, // osquery column names used in the query
  tableNamesForSyntaxHighlighting,  // osquery table names used in the query
  algoliaPublicKey,                // For search integration
}
```
