Displays the "Command details" page for a specific MDM command by looking up a command from the built static content using a URL slug.

## Key Components

**Inputs**
- `slug` *(string, required)* — Unique identifier for the MDM command (e.g., `macos-uninstall-fleetd`)

**Exits**
- `success` — Renders `pages/docs/command-details` with command data
- `notFound` — Returns a 404 when no matching command is found
- `badConfig` — Returns a config error if `builtStaticContent.mdmCommands` is missing or malformed

**fn**
Core handler that:
1. Validates `sails.config.builtStaticContent.mdmCommands` exists and is an array
2. Finds the matching command by `slug`
3. Builds meta title/description strings
4. Returns the command object, meta tags, and Algolia public key to the view

## Usage Example

```javascript
// Triggered via a route like:
// GET /controls/:slug
// e.g. GET /controls/macos-uninstall-fleetd

// Returns to the view:
{
  thisCommand: {
    slug: 'macos-uninstall-fleetd',
    name: 'Uninstall Fleetd',
    description: 'Removes the Fleetd agent from a macOS device.',
    // ...other command fields
  },
  pageTitleForMeta: ' Uninstall Fleetd command | Fleet controls library',
  pageDescriptionForMeta: 'Removes the Fleetd agent from a macOS device.',
  algoliaPublicKey: 'your-algolia-key',
}
```

## Notes

- Command data is sourced from `sails.config.builtStaticContent.mdmCommands`, populated at build time
- The `slug` must exactly match a command entry; unmatched slugs throw `notFound`
- Source: [`view-command-details.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/view-command-details.js)
