Handles the server-side action for rendering the Partners page, returning an empty response object that triggers the `pages/partners` view template.

## Key Components

- **friendlyName** – `'View partners'`
- **description** – `'Display "Partners" page.'`
- **exits.success.viewTemplatePath** – Points to `pages/partners` template
- **fn** – Async action function; returns an empty object to render the view with no additional data

## Usage Example

```javascript
// Registered as a Sails.js action, typically mapped in config/routes.js
'GET /partners': { action: 'view-partners' }
```

When a `GET` request hits `/partners`, Sails invokes this action, which returns `{}` and renders the `pages/partners` view template.
