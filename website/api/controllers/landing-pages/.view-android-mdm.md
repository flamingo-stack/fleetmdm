Renders the Android MDM landing page by supplying device-management testimonials to the view template.

## Key Components

**Exits**
- `success` — Renders `pages/landing-pages/android-mdm` with testimonial data
- `badConfig` — Returned when `builtStaticContent` is missing or malformed

**fn (async)**
- Validates that `sails.config.builtStaticContent.testimonials` is a properly configured array
- Clones the global testimonials list and filters to entries tagged with `'Device management'`
- Passes the filtered array as `testimonialsForScrollableTweets` to the `<scrollable-tweets>` component in the view

## Usage Example

```javascript
// Registered automatically by Sails.js via the actions2 convention.
// Called when a user navigates to the Android MDM landing page route.

// Example filtered testimonial shape passed to the view:
{
  testimonialsForScrollableTweets: [
    {
      text: "Fleet transformed our Android fleet management.",
      productCategories: ["Device management"],
      // ...other testimonial fields
    }
  ]
}
```

## Notes

- Throws `badConfig` if `sails.config.builtStaticContent` is not an object, `testimonials` is not an array, or `compiledPagePartialsAppPath` is missing — preventing the page from rendering with broken data
- Filtering uses `_.contains` (Lodash/Underscore), so `productCategories` must be an array on each testimonial object
