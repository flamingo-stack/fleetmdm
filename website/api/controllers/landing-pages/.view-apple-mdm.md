Renders the Apple MDM landing page, preparing and ordering testimonials filtered by the "Device management" product category for display in the scrollable tweets component.

## Key Components

- **`exits.success`** — Renders the `pages/landing-pages/apple-mdm` view template
- **`exits.badConfig`** — Thrown when `builtStaticContent.testimonials` or `compiledPagePartialsAppPath` are missing or malformed
- **`fn`** — Main action handler that filters and sorts testimonials before passing them to the view

## Behavior

1. **Config validation** — Guards against missing `sails.config.builtStaticContent` shape; throws `badConfig` if invalid
2. **Filtering** — Retains only testimonials tagged with `"Device management"` from the global built static content
3. **Ordering** — Sorts filtered testimonials against a fixed author name list; unrecognized authors are pushed to the end

## Usage Example

```javascript
// Registered automatically by Sails as a page action.
// Accessible via the route mapped to this action, e.g.:
// 'GET /apple-mdm': { action: 'view-apple-mdm' }

// The view receives:
// - testimonialsForScrollableTweets: Testimonial[]
```
