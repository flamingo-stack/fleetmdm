Renders the Windows MDM landing page by loading and sorting device management testimonials for the scrollable tweets component.

## Key Components

- **`exits.success`** — Renders the `pages/landing-pages/windows-mdm` view template
- **`exits.badConfig`** — Throws a `badConfig` response if `builtStaticContent` is misconfigured
- **`fn`** — Async handler that validates config, filters testimonials by the `Device management` product category, and sorts them by a predefined author order

## Testimonial Ordering

The page enforces a specific display order for testimonials using a named author list:

```text
Justin LaBo → Wes Whetstone → Erik Gomez → Mike Meyer → Nick Fohs →
Kenny Botelho → Thomas Lübker → Chayce O'Neal → Luis Madrigal →
Dan Jackson → Bart Reardon → Eric Tan
```

Authors not in the list are pushed to the end of the array.

## Usage Example

This is a Sails.js action invoked automatically via routing. The returned data is passed to the view template:

```javascript
// Returned to the view template
return {
  testimonialsForScrollableTweets // filtered + sorted testimonial array
};
```

The view template at `pages/landing-pages/windows-mdm` consumes `testimonialsForScrollableTweets` to populate the `<scrollable-tweets>` component.

## Config Dependency

Requires `sails.config.builtStaticContent` to be a valid object containing:
- `testimonials` — an array of testimonial objects with `productCategories` and `quoteAuthorName` fields
- `compiledPagePartialsAppPath` — a non-empty string path
