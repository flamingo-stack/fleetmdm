Renders the "Replace Jamf" landing page by returning an empty response object that triggers the corresponding view template.

## Key Components

- **`friendlyName`** – Human-readable label: `'View replace jamf'`
- **`exits.success`** – Maps to view template `pages/landing-pages/replace-jamf`
- **`fn`** – Async handler that returns an empty object to render the view

## Usage Example

```javascript
// Registered as a Sails.js action and resolved via router, e.g.:
// config/routes.js
'/replace-jamf': { action: 'view-replace-jamf' }
```

## Notes

This is a lightweight Sails.js page action with no inputs or data processing. It serves purely as a route handler that delegates rendering to the `pages/landing-pages/replace-jamf` view template. For source, see [`view-replace-jamf.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/view-replace-jamf.js).
