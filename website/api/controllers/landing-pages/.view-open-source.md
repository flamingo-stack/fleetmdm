Renders the "Open Source" landing page by validating static content config and preparing a curated, ordered list of testimonials for display.

## Key Components

- **`exits.success`** — Renders `pages/landing-pages/open-source` view template
- **`exits.badConfig`** — Thrown when `builtStaticContent.testimonials` or `compiledPagePartialsAppPath` is missing or malformed
- **`testimonialOrderForThisPage`** — Ordered array of author names that surfaces open source, transparency, and community-focused testimonials first
- **`testimonialsForScrollableTweets`** — Sorted clone of the global testimonials array passed to the `<scrollable-tweets>` component

## Usage Example

```javascript
// Sails.js routes.js
'GET /open-source': { action: 'view-open-source' }
```

```javascript
// Required sails.config shape
sails.config.builtStaticContent = {
  testimonials: [
    { quoteAuthorName: 'Mike Arpaia', quoteText: '...' },
    // ...
  ],
  compiledPagePartialsAppPath: '/path/to/partials'
};
```

The action clones the global testimonials array to avoid mutation, then sorts it so named community voices appear first. Any author not in `testimonialOrderForThisPage` is pushed to the end. The sorted array is returned to the view as `testimonialsForScrollableTweets`.

## Notes

- Throws `badConfig` if `builtStaticContent` is not an object, `testimonials` is not an array, or `compiledPagePartialsAppPath` is absent — preventing the page from rendering with broken data.
