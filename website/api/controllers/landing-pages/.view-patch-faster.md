Renders the "Patch Faster" landing page by returning an empty data object and delegating display to the `pages/landing-pages/patch-faster` view template.

## Key Components

| Property | Value |
|---|---|
| `friendlyName` | `View patch faster` |
| `exits.success.viewTemplatePath` | `pages/landing-pages/patch-faster` |
| `exits.badConfig` | Handles misconfiguration via `badConfig` response type |

## Usage Example

```javascript
// Sails.js routes.js
'GET /patch-faster': { action: 'view-patch-faster' }
```
