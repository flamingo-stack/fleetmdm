Renders the "Connect Vanta" page by returning the corresponding view template with no additional data or inputs required.

## Key Components

- **`friendlyName`** – Human-readable identifier: `'View connect vanta'`
- **`exits.success`** – Maps to the view template at `pages/connect-vanta`
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Registered as a Sails.js action and invoked via routing, e.g. in config/routes.js:
'GET /connect-vanta': { action: 'view-connect-vanta' }
```

> **Note:** This is a minimal pass-through action. No inputs are defined and no data is passed to the view. Any dynamic content should be handled within the `pages/connect-vanta` template or a future extension of the `fn` body.
