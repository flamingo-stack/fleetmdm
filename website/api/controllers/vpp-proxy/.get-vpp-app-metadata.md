Proxies authenticated requests from Fleet instances to the Apple App Store API, fetching VPP (Volume Purchase Program) app metadata for specified store regions and app IDs.

## Key Components

**Inputs**
| Parameter | Type | Description |
|---|---|---|
| `storeRegion` | string | Apple App Store region for the proxied request (required) |
| `platform` | string | Platform the app(s) run on |
| `additionalPlatforms` | string | Comma-separated list of additional platforms |
| `ids` | string | Comma-separated list of App Store app IDs |
| `extend` | object | Additional attributes to include in the API response |

**Exits**
| Exit | Response | Description |
|---|---|---|
| `missingAuthHeader` | 401 | No `Authorization` Bearer header provided |
| `invalidFleetServerSecret` | 401 | JWT verification failed against `vppProxyAuthenticationPublicKey` |
| `missingVppToken` | 400 | No `vpp-token` header included |
| `appleApiReturnedForbiddenResponse` | 403 | Apple API rejected the request |
| `appleApiReturnedServerError` | 500 | Apple API returned a server error |

**Authentication Flow**
1. Validates the `Authorization: Bearer <JWT>` header using ES256 and `vppProxyAuthenticationPublicKey`
2. Reads the VPP token from the `vpp-token` request header
3. Generates a short-lived (60s) ES256 JWT signed with `vppProxyTokenPrivateKey` for the Apple API request

## Usage Example

```javascript
// Fleet server calls this endpoint with:
// Headers:
//   Authorization: Bearer <fleet-server-jwt>
//   vpp-token: <vpp-session-token>

// GET /get-vpp-app-metadata?storeRegion=us&ids=123456,789012&platform=ios
```

## Required Sails Config

```javascript
// config/custom.js
module.exports.custom = {
  vppProxyAuthenticationPublicKey: '...', // ES256 public key
  vppProxyTokenPrivateKey: '...',         // ES256 private key
  vppProxyTokenKeyId: '...',              // Apple API key ID
  vppProxyTokenTeamId: '...',             // Apple team ID
};
```
