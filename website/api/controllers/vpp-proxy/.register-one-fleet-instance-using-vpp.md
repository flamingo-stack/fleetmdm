Registers a Fleet instance for VPP (Volume Purchase Program) proxy usage by validating credentials and generating a signed authentication secret.

## Key Components

**Inputs**
- `fleetServerUrl` *(string, required)* — The URL of the Fleet server instance
- `fleetLicenseKey` *(string, required)* — A JWT license key to authenticate the Fleet instance

**Exits**
- `success` — Returns a `fleetServerSecret` JWT for authenticating future VPP proxy requests
- `couldNotVerifyLicense` — License key JWT verification failed (`401 Unauthorized`)
- `invalidFleetServerUrl` — Provided URL is malformed (`400 Bad Request`)

**Core Logic (`fn`)**
1. Verifies `fleetLicenseKey` as a valid ES256 JWT against the configured public key
2. Validates `fleetServerUrl` is a parseable URL
3. Generates a new ES256-signed `fleetServerSecret` JWT with a 1-year expiry, issued by `'Fleet VPP proxy'`

## Usage Example

```javascript
const result = await sails.helpers.registerOneFleetInstanceUsingVpp({
  fleetServerUrl: 'https://fleet.example.com',
  fleetLicenseKey: 'eyJhbGciOiJFUzI1NiJ9...',
});

console.log(result.fleetServerSecret);
// eyJhbGciOiJFUzI1NiJ9... (1-year ES256 JWT for VPP proxy auth)
```

## Configuration Dependencies

Requires the following Sails config values to be set:

| Config Key | Purpose |
|---|---|
| `sails.config.custom.licenseKeyGeneratorPublicKey` | Verifies incoming Fleet license JWTs |
| `sails.config.custom.vppProxyAuthenticationPrivateKey` | Signs the generated `fleetServerSecret` |
| `sails.config.custom.vppProxyAuthenticationPassphrase` | Passphrase for the private key |
