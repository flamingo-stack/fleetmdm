Sails.js page action that renders the "Device management" marketing page, filtering and ordering testimonials for display in a scrollable tweets component.

## Key Components

- **`exits.success`** — Renders the `pages/device-management` view template
- **`exits.badConfig`** — Throws when `builtStaticContent.testimonials` is missing or malformed
- **`testimonialsForScrollableTweets`** — Filtered and ordered subset of testimonials tagged with the `"Device management"` product category
- **`testimonialOrderForThisPage`** — Hardcoded display order by author name (17 entries)

## Behavior

1. Validates that `sails.config.builtStaticContent.testimonials` exists and is an array
2. If static content has been compiled (`compiledPagePartialsAppPath` is set), filters testimonials to only those in the `"Device management"` category and matching the curated author list, then sorts them into the specified order
3. If static content has **not** been built, passes through a placeholder testimonial injected by the custom hook
4. Returns the testimonial array to the view

## Usage Example

```javascript
// Accessed via Sails.js routing — no direct invocation needed.
// Typical route binding in config/routes.js:
'GET /device-management': { action: 'view-device-management' }
```
