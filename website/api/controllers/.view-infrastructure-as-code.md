Handles the server-side logic for rendering the Fleet infrastructure-as-code marketing page, fetching and deduplicating testimonial data for display.

## Key Components

- **`friendlyName`** – Human-readable action label: `'View infrastructure-as-code'`
- **`exits.success`** – Renders the `pages/infrastructure-as-code` view template
- **`exits.badConfig`** – Returns a `badConfig` response if required static content is misconfigured
- **`fn`** – Async handler that validates config, clones testimonials, deduplicates by author name (when static content is compiled), and returns data to the view

## Usage Example

```javascript
// Sails.js automatically maps this action to a route.
// Example route config in config/routes.js:
'GET /infrastructure-as-code': { action: 'view-infrastructure-as-code' }

// The action returns the following locals to the view template:
{
  testimonialsForScrollableTweets: [
    { quoteAuthorName: 'Jane Doe', quote: '...' },
    // Deduplicated by lowercased author name when static content is built
  ]
}
```

## Notes

- Requires `sails.config.builtStaticContent.testimonials` to be a valid array; throws `badConfig` otherwise
- Deduplication via `_.uniq` on `quoteAuthorName.toLowerCase()` only runs when `compiledPagePartialsAppPath` is set, allowing a placeholder testimonial to display in development environments without a full static content build
