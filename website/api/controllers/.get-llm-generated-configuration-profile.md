Uses an LLM (OpenAI `o3-mini`) to generate device configuration profiles from natural language instructions, supporting macOS `.mobileconfig`, Apple DDM, and Windows CSP XML formats.

## Key Components

**Inputs**
- `profileType` — Profile format: `mobileconfig`, `csp`, or `ddm`
- `naturalLanguageInstructions` — Plain-language description of the desired device settings

**Exits**
- `success` — Returns the generated profile, filename, and a list of enforced settings
- `couldNotGenerateProfile` (`badRequest`) — Thrown when the LLM cannot produce a valid profile from the provided instructions

**Core Logic (`fn`)**
- Builds a type-specific prompt describing the target platform and format
- Calls `sails.helpers.ai.prompt` using the `o3-mini-2025-01-31` base model
- Parses the JSON response and validates presence of required fields (`configurationProfile`, `profileFilename`, `settingsEnforced`)
- Returns `profile`, `profileFilename`, and `items` (enforced settings array) on success

## Usage Example

```javascript
let result = await sails.helpers.ai.getLlmGeneratedConfigurationProfile.with({
  profileType: 'mobileconfig',
  naturalLanguageInstructions: 'Disable Bluetooth and require FileVault on login'
});

// result.profile        → raw XML profile string
// result.profileFilename → suggested filename (e.g. "disable-bluetooth.mobileconfig")
// result.items          → [{ name: 'Bluetooth', value: 'Disabled' }, ...]
```

## Response Shape

```json
{
  "profile": "<xml>...</xml>",
  "profileFilename": "disable-bluetooth.mobileconfig",
  "items": [
    { "name": "Bluetooth", "value": "Disabled" }
  ]
}
```
