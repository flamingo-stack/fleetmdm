Handles the route for displaying the "Sandbox expired" page when a Fleet sandbox trial session has ended.

## Key Components

- **`friendlyName`** – `'View sandbox expired'`
- **`exits.success`** – Renders the view template at `pages/try-fleet/sandbox-expired`
- **`fn`** – Async action function; returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Registered as a Sails.js action, typically bound in config/routes.js
'GET /try-fleet/sandbox-expired': { action: 'view-sandbox-expired' }
```

When a user navigates to the sandbox-expired route, the action responds with the corresponding view template and no additional data.
