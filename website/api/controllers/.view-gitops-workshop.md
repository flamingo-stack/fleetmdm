Renders the GitOps Workshop page by fetching and formatting upcoming GitOps events from the Eventbrite API, including venue details, formatted times, and timezone information.

## Key Components

- **`fn`** — Async action handler that:
  - Queries the Eventbrite API for live, current/future events filtered by `gitops`
  - Formats event start/end times using `Intl.DateTimeFormat` with abbreviated timezone strings
  - Fetches venue details per event (city + address) when a `venue_id` is present
  - Falls back gracefully on API errors (empty event list or `TBA` address)
  - Sorts all collected events by start timestamp before passing to the view

- **`futureGitopsWorkshops`** — Array of event objects passed to the view template, each containing:
  - `eventbriteLink` — Direct URL to the Eventbrite event page
  - `eventTime` — Human-readable string (e.g., `Feb 3 from 1 to 3pm PST`)
  - `startsAt` — Unix timestamp used for sorting
  - `workshopCity` — City name from venue, or event name as fallback
  - `workshopAddress` — Venue name, or `TBA` if unavailable

- **Exit:** `success` → renders `pages/gitops-workshop`

## Usage Example

```javascript
// Sails.js route binding (config/routes.js)
'GET /gitops-workshop': { action: 'view-gitops-workshop' }
```

```javascript
// Required Sails config values (config/custom.js)
module.exports.custom = {
  eventbriteOrgId: 'YOUR_ORG_ID',
  eventbriteApiToken: 'YOUR_BEARER_TOKEN',
};
```

The view at `pages/gitops-workshop` receives `futureGitopsWorkshops` as a local variable, ready for iteration. If the Eventbrite API is unreachable, the page renders with an empty workshops list rather than throwing an error.
