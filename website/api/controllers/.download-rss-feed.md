Generates and returns an RSS 2.0 XML feed for a specified category of Fleet blog articles, pulling content from pre-built static markdown pages.

## Key Components

- **`categoryName`** (input) — Required string; must be one of: `success-stories`, `securing`, `releases`, `engineering`, `guides`, `announcements`, `deploy`, `podcasts`, `report`, `articles`
- **`badConfig`** (exit) — Thrown when `sails.config.builtStaticContent` or its `markdownPages` array is missing/malformed
- **`success`** (exit) — Returns the fully constructed RSS XML string
- **`fn`** — Core logic that builds channel metadata, filters `markdownPages` by category, sorts by publish date, and appends `<item>` elements for each article

## Usage Example

```javascript
// Called via Sails.js machine invocation (e.g., from a route action)
const rssFeedXml = await sails.helpers.downloadRssFeed.with({
  categoryName: 'releases'
});

// Or as an HTTP GET request routed to this action:
// GET /rss/releases → returns text/xml RSS feed
```

## Notes

- The `articles` category is a special case — it aggregates **all** pages whose `htmlId` starts with `articles`, while other categories filter by URL prefix
- Articles are sorted ascending by `meta.publishedOn` before being added to the feed
- All string values are XML-escaped via `_.escape()` to prevent malformed output
- The response `Content-Type` is explicitly set to `text/xml`
- Feed includes standard RSS elements: `<title>`, `<description>`, `<link>`, `<atom:link>`, `<lastBuildDate>`, and a Fleet logo `<image>` block
