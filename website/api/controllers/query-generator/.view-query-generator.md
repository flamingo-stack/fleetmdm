Renders the admin Query Generator page, validating that `builtStaticContent.schemaTables` is properly configured before serving the view.

## Key Components

| Element | Description |
|---|---|
| `fn` | Async handler that validates config and returns the view |
| `success` exit | Renders `pages/admin/query-generator` template |
| `badConfig` exit | Returns a `badConfig` response if schema tables are misconfigured |

## Usage Example

```javascript
// Sails.js route mapping (config/routes.js)
'GET /admin/query-generator': { action: 'admin/view-query-generator' }

// Required config shape (config/custom.js or builtStaticContent)
sails.config.builtStaticContent = {
  schemaTables: [ /* array of schema table definitions */ ]
};
```

## Notes

- Throws `badConfig` if `sails.config.builtStaticContent` is not an object or if `schemaTables` is not an array
- No data is passed to the view — all schema data is expected to be available client-side or via a separate endpoint
- Part of the admin panel; ensure appropriate access policies are applied in `config/policies.js`
