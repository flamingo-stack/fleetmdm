Handles job application form submissions from the contact page, forwarding applicant data to a Zapier webhook and sending a confirmation email to the applicant.

## Key Components

**Inputs**

| Field | Required | Description |
|---|---|---|
| `firstName` | ✅ | Applicant's first name |
| `lastName` | ✅ | Applicant's last name |
| `emailAddress` | ✅ | Valid email address for response |
| `position` | ✅ | Job position being applied for |
| `linkedinProfileUrl` | ✅ | Applicant's LinkedIn profile URL |
| `location` | ✅ | Applicant's location |
| `message` | ✅ | Cover letter in plain text |
| `websiteUrl` | ❌ | Honeypot field — submission silently discarded if populated |

**Exits**

- `success` — Application submitted successfully
- `invalidEmailDomain` — Email domain is on the configured denylist (`badRequest`)

## Key Behaviors

- **Honeypot check** — If `websiteUrl` is filled, the helper returns silently without processing (bot protection)
- **Domain denylist** — Validates the email domain against `sails.config.custom.bannedEmailDomainsForContactFormSubmissions`
- **Emoji stripping** — Removes position emojis (🧑‍🚀 🚀 🌦️ etc.) before forwarding to Zapier
- **Zapier webhook** — Posts submission data with a 5-second timeout; tolerates `non200Response`, `requestFailed`, and `TimeoutError`
- **Confirmation email** — Sends `email-application-submitted` template to the applicant via `sails.helpers.sendTemplateEmail`

## Usage Example

```javascript
await sails.helpers.deliverApplicationSubmission.with({
  firstName: 'Jane',
  lastName: 'Doe',
  emailAddress: 'jane.doe@example.com',
  position: '🚀 Senior Engineer',
  linkedinProfileUrl: 'https://linkedin.com/in/janedoe',
  location: 'Austin, TX',
  message: 'I am excited to apply for this role...',
  // websiteUrl omitted — honeypot not triggered
});
```
