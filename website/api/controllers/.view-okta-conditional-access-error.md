Displays the Okta conditional access error page by rendering the corresponding view template.

## Key Components

- **friendlyName** – `'View okta conditional access error'`
- **description** – Describes the action as displaying the Okta conditional access error page
- **exits.success** – Renders the `pages/okta-conditional-access-error` view template
- **fn** – Async handler that returns an empty object, delegating rendering to the view template

## Usage Example

```javascript
// Typically registered as a route in config/routes.js
'GET /okta-conditional-access-error': { action: 'view-okta-conditional-access-error' }
```

This is a minimal Sails.js page action with no inputs or data processing — it simply responds with the associated view template when the route is hit.
