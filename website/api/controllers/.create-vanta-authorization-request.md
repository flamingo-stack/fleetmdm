Generates a Vanta OAuth authorization URL to connect a user's Fleet instance to their Vanta account, handling validation, deduplication, and state management for the OAuth flow.

## Key Components

**Inputs**
- `emailAddress` — User's email (required)
- `fleetInstanceUrl` — Base URL of the Fleet instance (required)
- `fleetApiKey` — API key for the Fleet instance (required)
- `redirectToExternalPageAfterAuthorization` — Optional post-auth redirect URL
- `sharedSecret` — Validates requests from the external `/api/v1/create-external-vanta-authorization-request` endpoint

**Exits**
| Exit | Status | Description |
|---|---|---|
| `connectionAlreadyExists` | 409 | Fleet URL already connected to Vanta |
| `fleetInstanceNotResponding` | 404 | Fleet HTTP request failed |
| `invalidToken` | 401 | API key unauthorized |
| `requestToFleetInstanceForbidden` | 403 | Fleet returned 403 |
| `invalidLicense` | 400 | Fleet instance is on a Free tier |
| `nonApiOnlyUser` | 400 | Token belongs to a non-API-only user |
| `insufficientPermissions` | 403 | API-only user lacks admin role |
| `missingOrInvalidSharedSecret` | 401 | Invalid shared secret for external requests |

**Core Logic Flow**
1. Validates shared secret for external endpoint requests
2. Checks for existing `VantaConnection` records to prevent duplicates
3. Verifies Fleet API key against `/api/v1/fleet/me` (must be API-only admin)
4. Confirms Fleet license tier is not `free` via `/api/v1/fleet/config`
5. Creates a `VantaConnection` record if none exists
6. Builds and returns the Vanta OAuth authorization URL

## Usage Example

```javascript
// Called internally by the Sails.js router
const authUrl = await sails.helpers.createVantaAuthorizationRequest.with({
  emailAddress: 'admin@example.com',
  fleetInstanceUrl: 'https://fleet.example.com',
  fleetApiKey: 'your-api-only-admin-token',
  redirectToExternalPageAfterAuthorization: 'https://partner.example.com/setup-complete',
});
// Returns either a Vanta OAuth URL or an internal redirect URL
```
