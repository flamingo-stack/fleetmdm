Creates a new web app for an Android Enterprise by authenticating the request, validating the enterprise, and calling the Google Android Management API.

## Key Components

**Inputs**
| Parameter | Type | Required | Description |
|---|---|---|---|
| `androidEnterpriseId` | string | ✅ | Target Android Enterprise ID |
| `title` | string | ❌ | Display name of the web app |
| `startUrl` | string | ❌ | Launch URL for the web app |
| `icons` | array | ❌ | Icon definitions for the web app |
| `displayMode` | string | ❌ | Rendering mode (e.g., fullscreen) |
| `versionCode` | string | ❌ | Version identifier |

**Exits**
- `success` — Web app created successfully
- `missingAuthHeader` — No `Authorization: Bearer` header present
- `unauthorized` — Secret mismatch or invalid token
- `notFound` — Enterprise not found or no longer managed by Fleet
- `invalidWebApp` — Google API rejected the request (400)

**Authentication Flow**
1. Extracts `Bearer` token from the `Authorization` header
2. Looks up the `AndroidEnterprise` record by ID
3. Validates the `fleetServerSecret` against the stored value
4. Confirms the enterprise is still managed by Fleet via `androidProxy.getIsEnterpriseManagedByFleet`

## Usage Example

```bash
curl -X POST https://your-fleet-server/api/v1/enterprise-webapps \
  -H "Authorization: Bearer <fleetServerSecret>" \
  -H "Content-Type: application/json" \
  -d '{
    "androidEnterpriseId": "LC04az...",
    "title": "Company Portal",
    "startUrl": "https://portal.example.com",
    "displayMode": "STANDALONE",
    "versionCode": "1"
  }'
```

**Error Handling**
- `429` from Google API → logs a `p1` warning to trigger an alert
- `400` from Google API → returns `invalidWebApp` with a `badRequest` response
- All other Google API errors → wrapped in a generic `Error`
