Sails.js action that modifies an existing policy on an Android enterprise via the Google Android Management API, acting as an authenticated proxy between a Fleet server and Google's API.

## Key Components

| Element | Description |
|---|---|
| `androidEnterpriseId` | Required input identifying the target Android enterprise |
| `policyId` | Required input identifying the policy to patch |
| `fleetServerSecret` | Extracted from `Bearer` token in the `Authorization` header for request authentication |
| `AndroidEnterprise.findOne()` | Validates enterprise existence and authenticates the caller's secret |
| `androidProxy.getIsEnterpriseManagedByFleet()` | Confirms the enterprise is still actively managed by Fleet |
| `androidmanagement.enterprises.policies.patch()` | Google API call that applies the patch using `req.body` and optional `updateMask` query param |
| `sails.helpers.flow.build()` | Wraps the Google API call for structured error interception |

**Exit conditions:**

| Exit | HTTP Status | Trigger |
|---|---|---|
| `missingAuthHeader` | 401 | No `Bearer` token present |
| `unauthorized` | 401 | Secret mismatch |
| `notFound` | 404 | Unknown enterprise or no longer managed by Fleet |
| `invalidPolicy` | 400 | Google API rejects the policy payload |
| `policyNotFound` | 404 | Google API cannot find the specified policy |

## Usage Example

```bash
# PATCH request from Fleet server to modify an Android enterprise policy
curl -X PATCH https://your-host/modify-android-policies \
  -H "Authorization: Bearer <fleetServerSecret>" \
  -H "Content-Type: application/json" \
  -d '{
    "applications": [{ "packageName": "com.example.app", "installType": "FORCE_INSTALLED" }]
  }' \
  "?androidEnterpriseId=LC0...&policyId=default&updateMask=applications"
```

> **Note:** This action forwards `req.body` directly to Google's API rather than using declared Sails inputs — an intentional exception to preserve existing policy values when only a subset of fields is being updated. This pattern is not recommended for future Android proxy endpoints.
