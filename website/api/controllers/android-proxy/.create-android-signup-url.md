Generates and returns an Android Enterprise signup URL by calling the Google Android Management API, with stale enterprise cleanup and error handling for rate limits and invalid callbacks.

## Key Components

- **`callbackUrl`** (input) — The URL Google redirects to after enterprise creation, with an `enterpriseToken` query parameter appended
- **`missingOriginHeader`** exit — Thrown when the `Origin` header is absent from the incoming request
- **`enterpriseAlreadyExists`** exit — Returns HTTP 409 when a valid, active Android Enterprise already exists for the requesting Fleet instance
- **`invalidCallbackUrl`** exit — Returns HTTP 400 when Google rejects the provided callback URL
- **Stale record cleanup** — If a local `AndroidEnterprise` record exists but the enterprise is no longer found in Google, the proxy record is destroyed and signup proceeds
- **Rate limit handling** — Logs a `p1` warning alert on HTTP 429 responses from the Android Management API

## Usage Example

```javascript
// Called via Fleet server with Origin header set
const response = await sails.helpers.flow.build(async () => {
  return await superagent
    .post('https://fleetdm-proxy/create-android-signup-url')
    .set('Origin', 'https://my-fleet-instance.example.com')
    .send({ callbackUrl: 'https://my-fleet-instance.example.com/mdm/android/callback' });
});

// Successful response shape
// { url: 'https://play.google.com/work/adminsignup?...', name: 'signupUrls/abc123' }
```

## Notes

- Requires `androidEnterpriseServiceAccountEmailAddress`, `androidEnterpriseServiceAccountPrivateKey`, and `androidEnterpriseProjectId` in `sails.config.custom`
- Uses `googleapis` npm package with service account credentials for authentication
- Google may reformat the `callbackUrl` slightly when appending the `enterpriseToken` parameter
