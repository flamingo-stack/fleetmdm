Proxies AMAPI command requests from a Fleet server to the Android Management API, authenticating the caller and forwarding explicitly declared command fields to a managed device.

## Key Components

**Inputs**

| Input | Type | Description |
|---|---|---|
| `androidEnterpriseId` | `string` | Identifies the Android enterprise |
| `deviceId` | `string` | Target device within the enterprise |
| `issueCommand` | `string` | Route action validator; must equal `'issueCommand'` |
| `type` | `string` | AMAPI command type (e.g. `LOCK`, `WIPE`, `RESET_PASSWORD`) |
| `duration` | `string` | Optional command TTL (e.g. `"315360000s"`) |
| `newPassword` | `string` | New passcode for `RESET_PASSWORD`; empty string clears the passcode |
| `resetPasswordFlags` | `string[]` | AMAPI reset-password flags |
| `wipeParams` / `*Params` | `ref` | Command-specific AMAPI parameter objects |

**Exits**

| Exit | HTTP | Trigger |
|---|---|---|
| `success` | 200 | Command issued; returns AMAPI Operation |
| `missingAuthHeader` | 401 | No `Authorization: Bearer` header |
| `unauthorized` | 401 | Secret mismatch |
| `notFound` | 404 | Unknown enterprise or enterprise no longer managed by Fleet |
| `deviceNoLongerManaged` | 404 | Google reports device unmanaged |

**Auth flow** — Extracts `Bearer` token from the `Authorization` header, looks up the `AndroidEnterprise` record, and compares `fleetServerSecret` before proceeding.

**Command body construction** — Fields are added with `!== undefined` checks (not truthiness) so Fleet can forward an empty `newPassword` (`""`) or empty `wipeParams` (`{}`) without them being silently dropped.

**Rate-limit handling** — A 429 from the Google API triggers a `p1` warning log to surface the alert, then re-throws.

## Usage Example

```bash
POST /android-enterprise/:androidEnterpriseId/devices/:deviceId:issueCommand
Authorization: Bearer <fleetServerSecret>
Content-Type: application/json

{
  "issueCommand": "issueCommand",
  "type": "LOCK",
  "duration": "3600s"
}
```

```bash
# WIPE with required empty params
{
  "issueCommand": "issueCommand",
  "type": "WIPE",
  "wipeParams": {}
}
```
