Retrieves a specific device from an Android Enterprise using the Google Android Management API, after authenticating the request against a stored Fleet server secret.

## Key Components

| Name | Type | Description |
|---|---|---|
| `androidEnterpriseId` | Input | The Android Enterprise identifier |
| `deviceId` | Input | The target device identifier |
| `missingAuthHeader` | Exit | No `Authorization` Bearer header present |
| `unauthorized` | Exit | Bearer token does not match stored secret |
| `notFound` | Exit | Enterprise not found or no longer managed by Fleet |
| `deviceNoLongerManaged` | Exit | Device is no longer managed by the enterprise |

## Usage Example

```javascript
// Called via HTTP GET with a Bearer token in the Authorization header.
// Example: GET /android-enterprise/:androidEnterpriseId/device/:deviceId

const response = await fetch(
  `https://your-fleet-server/android-enterprise/${androidEnterpriseId}/device/${deviceId}`,
  {
    headers: {
      Authorization: `Bearer ${fleetServerSecret}`,
    },
  }
);

const deviceData = await response.json();
```

## Auth Flow

1. Extracts the Bearer token from the `Authorization` header
2. Looks up the `AndroidEnterprise` record by `androidEnterpriseId`
3. Validates the token against `fleetServerSecret` stored on that record
4. Confirms the enterprise is still managed by Fleet via `androidProxy.getIsEnterpriseManagedByFleet`
5. Calls `androidmanagement.enterprises.devices.get` using a Google service account

## Error Handling

- **429 responses** from the Google API trigger a `p1` warning log for alerting
- `"Device is no longer being managed"` errors from Google are caught and mapped to the `deviceNoLongerManaged` exit
- All other Google API errors are re-thrown as standard `Error` objects
