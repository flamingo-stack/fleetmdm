Lists Android devices accessible to a given Android Enterprise by authenticating via a Bearer token and querying the Google Android Management API.

## Key Components

| Element | Description |
|---|---|
| `androidEnterpriseId` | Required string identifying the target Android enterprise |
| `pageSize` | Optional integer (default `100`) limiting devices returned per page |
| `pageToken` | Optional string for paginated requests |
| `fields` | Optional field selector for partial API responses |
| `missingAuthHeader` | Exit thrown when `Authorization: Bearer` header is absent |
| `notFound` | Exit thrown when no matching `AndroidEnterprise` record exists |
| `unauthorized` | Exit thrown when the Bearer token does not match the stored `fleetServerSecret` |

**Authentication flow:**
1. Extracts `fleetServerSecret` from the `Authorization: Bearer` header
2. Looks up the `AndroidEnterprise` record and validates the secret
3. Authenticates with Google using a service account (`androidEnterpriseServiceAccountEmailAddress` / `androidEnterpriseServiceAccountPrivateKey`)
4. Calls `enterprises.devices.list` scoped to the enterprise

Rate-limit (HTTP 429) responses from the Android Management API trigger a `p1` warning log for alerting purposes.

## Usage Example

```bash
curl -X GET /api/v1/android-devices \
  -H "Authorization: Bearer <fleetServerSecret>" \
  -H "Origin: https://your-fleet-server.example.com" \
  -d '{"androidEnterpriseId": "LC04...", "pageSize": 50}'
```

```javascript
// Example Sails action call (server-side)
const result = await sails.helpers.flow.build(async () => {
  return await getAndroidDevices({
    androidEnterpriseId: 'LC04abc123',
    pageSize: 50,
    pageToken: 'token-from-previous-page',
    fields: 'devices(name,state)',
  });
});
```
