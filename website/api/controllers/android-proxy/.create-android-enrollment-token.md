Creates an Android Enterprise enrollment token by authenticating the request against a stored enterprise record and calling the Google Android Management API.

## Key Components

- **`androidEnterpriseId`** *(required input)*: The ID of the Android Enterprise for which a token is being created.
- **Authentication**: Validates a `Bearer` token from the `Authorization` header against the stored `fleetServerSecret` on the matched `AndroidEnterprise` record.
- **Fleet-managed check**: Calls `sails.helpers.androidProxy.getIsEnterpriseManagedByFleet` to verify the enterprise is still active.
- **Token creation**: Uses the `googleapis` client with a service account to call `enterprises.enrollmentTokens.create` via the Android Management API v1.
- **Rate limit handling**: Intercepts HTTP 429 responses and emits a `p1`-tagged warning for alerting purposes.

## Exits

| Exit | Behavior |
|---|---|
| `success` | Returns the enrollment token data |
| `missingAuthHeader` | No `Bearer` token found in request |
| `unauthorized` | Secret mismatch |
| `notFound` | No matching enterprise record or enterprise no longer managed by Fleet |

## Usage Example

```bash
curl -X POST https://<android-proxy-host>/create-android-enrollment-token \
  -H "Authorization: Bearer <fleet-server-secret>" \
  -H "Content-Type: application/json" \
  -d '{"androidEnterpriseId": "LC04ax...", "duration": "3600s"}'
```

```javascript
// Called internally by Fleet when provisioning a new Android device
const token = await sails.helpers.androidProxy.createAndroidEnrollmentToken(androidEnterpriseId);
```
