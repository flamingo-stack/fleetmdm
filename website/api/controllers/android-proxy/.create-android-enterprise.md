Creates a new Android Enterprise by orchestrating Google Android Management API and Pub/Sub setup for a Fleet MDM instance, then persisting the resulting enterprise record.

## Key Components

| Input | Description |
|---|---|
| `signupUrlName` | Google signup URL name for enterprise creation |
| `enterpriseToken` | Token from the Fleet enrollment flow |
| `fleetLicenseKey` | Optional Fleet license key |
| `pubsubPushUrl` | Endpoint where Google Pub/Sub will push device notifications |
| `enterprise` | Enterprise object payload forwarded to Google |

**Exits:** `success`, `enterpriseAlreadyExists` (409), `missingOriginHeader`, `invalidEnterpriseToken`

**Core orchestration steps:**

1. Extracts `fleetServerUrl` from the `Origin` header
2. Guards against duplicate enterprise creation via `AndroidEnterprise.findOne`
3. Creates a Google Pub/Sub topic with 24-hour message retention
4. Sets IAM policy granting `android-cloud-policy@system.gserviceaccount.com` publisher rights
5. Creates a push subscription pointing to `pubsubPushUrl`
6. Calls `androidmanagement.enterprises.create` to finalize the enterprise
7. Persists the record to `AndroidEnterprise` and returns the enterprise name + a generated `fleetServerSecret`

## Usage Example

```javascript
// Called internally by a Fleet-initiated webhook/callback route
const result = await sails.helpers.createAndroidEnterprise.with({
  signupUrlName: 'signupUrls/abc123',
  enterpriseToken: 'fleet-enrollment-token',
  fleetLicenseKey: 'LIC-XXXX',
  pubsubPushUrl: 'https://fleet.example.com/mdm/android/pubsub',
  enterprise: { contactInfo: { contactEmail: 'admin@example.com' } }
});

// result.name           => 'enterprises/LC04...'
// result.fleetServerSecret => '<30-char random secret>'
```

## Error Handling

| Status | Behavior |
|---|---|
| 400 (`INVALID_ENTERPRISE_TOKEN`) | Throws `invalidEnterpriseToken` |
| 401 / 403 | Throws `invalidEnterpriseToken` with auth message |
| 429 | Logs `p1` alert, throws generic error |
| 5XX / network | Throws generic error |
