Handles modification and removal of application assignments within Android Enterprise Management API policies, acting as a secure proxy between a Fleet server and Google's Android Management API.

## Key Components

### Inputs

| Input | Type | Description |
|---|---|---|
| `androidEnterpriseId` | `string` | Required. Identifies the target Android enterprise |
| `policyId` | `string` | Required. Identifies the target policy within the enterprise |
| `googleAction` | `string` | Defaults to `modifyPolicyApplications`. Controls which API action is performed |
| `packageNames` | `string[]` | Package names to remove (used with `removePolicyApplications`) |
| `changes` | `object[]` | Application change objects (used with `modifyPolicyApplications`) |

### Exits

| Exit | Response Type | Description |
|---|---|---|
| `success` | `200` | Policy applications updated successfully |
| `missingAuthHeader` | `401` | No `Authorization: Bearer` header present |
| `unauthorized` | `401` | Fleet server secret does not match stored record |
| `notFound` | `404` | No matching Android enterprise found, or enterprise no longer managed by Fleet |
| `policyNotFound` | `404` | Specified policy does not exist on the enterprise |

### Auth Flow

Validates the `Authorization: Bearer <secret>` header against the stored `fleetServerSecret` on the matching `AndroidEnterprise` record, then confirms the enterprise is still actively managed by Fleet before proceeding.

### Google API Actions

- **`modifyPolicyApplications`** (default): Calls `enterprises.policies.modifyPolicyApplications` with a `changes` body
- **`removePolicyApplications`**: Calls `enterprises.policies.removePolicyApplications` with a `packageNames` body

## Usage Example

```javascript
// Modify policy applications
await sails.helpers.modifyEnterpriseAppPolicy({
  androidEnterpriseId: 'LC04xxxxxxx',
  policyId: 'my-policy',
  googleAction: 'modifyPolicyApplications',
  changes: [
    { packageName: 'com.example.app', installType: 'FORCE_INSTALLED' }
  ],
});

// Remove applications from a policy
await sails.helpers.modifyEnterpriseAppPolicy({
  androidEnterpriseId: 'LC04xxxxxxx',
  policyId: 'my-policy',
  googleAction: 'removePolicyApplications',
  packageNames: ['com.example.app'],
});
```

> **Note:** Rate limit (`429`) responses from the Google Android Management API trigger a `p1` warning log to surface operational alerts.
