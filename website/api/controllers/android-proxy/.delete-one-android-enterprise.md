Deletes an Android Enterprise record from both Google's Android Management API and the local proxy database, with bearer token authentication to verify the requesting Fleet server.

## Key Components

| Element | Description |
|---|---|
| `androidEnterpriseId` | Required string input identifying the enterprise to delete |
| `missingAuthHeader` | Exit thrown when no `Authorization: Bearer` header is present |
| `unauthorized` | Exit thrown when the bearer token doesn't match the stored `fleetServerSecret` |
| `notFound` | Exit thrown when no matching `AndroidEnterprise` record exists |
| Google API cleanup | Deletes the enterprise, its Pub/Sub topic, and subscription via `googleapis` |
| Database cleanup | Destroys the `AndroidEnterprise` record regardless of Google API outcome |

## Usage Example

```bash
curl -X DELETE https://your-proxy/api/v1/android-enterprise/<androidEnterpriseId> \
  -H "Authorization: Bearer <fleetServerSecret>"
```

```javascript
// Sails.js route handler invocation (internal)
await sails.helpers.flow.build(async () => {
  // Called by Fleet server with matching fleetServerSecret
  // Deletes Google enterprise, Pub/Sub topic, subscription,
  // then removes the local AndroidEnterprise DB record
});
```

## Notes

- **Auth flow:** Extracts the bearer token from the `Authorization` header and validates it against `thisAndroidEnterprise.fleetServerSecret`
- **Graceful Google cleanup:** If the enterprise is already deleted in Google, the API error is caught and swallowed — database cleanup proceeds regardless
- **Rate limit handling:** HTTP 429 responses from the Android Management API trigger a `p1` warning log to alert on-call teams
- **Pub/Sub resources:** Both the topic (`pubsubTopicName`) and subscription (`pubsubSubscriptionName`) are deleted alongside the enterprise
