Renders the Linux Management marketing page by preparing curated, ordered testimonials filtered to the "Device management" product category for display in a scrollable tweets component.

## Key Components

**Exits**
- `success` — Renders `pages/linux-management` view template with testimonial data
- `badConfig` — Thrown when `sails.config.builtStaticContent.testimonials` is missing or malformed

**Testimonial Processing**
- Validates `builtStaticContent.testimonials` exists and is an array
- Filters testimonials to only those tagged with `'Device management'` product category
- Sorts filtered testimonials by a hardcoded author order list; unrecognized authors are appended to the end
- Falls back to a placeholder testimonial (injected by the custom hook) if static content has not been compiled

**Ordered Authors**
The page uses a specific 12-author display order including Erik Gomez, Nick Fohs, Adam Pippert, and others.

## Usage Example

```javascript
// Sails.js route configuration (config/routes.js)
'GET /linux-management': { action: 'view-linux-management' }
```

```javascript
// Required shape of builtStaticContent
sails.config.builtStaticContent = {
  testimonials: [
    {
      quoteAuthorName: 'Erik Gomez',
      productCategories: ['Device management'],
      // ...other testimonial fields
    }
  ],
  compiledPagePartialsAppPath: '/path/to/partials' // omit to skip filtering/sorting
};
```

## Notes

- Filtering and sorting are skipped when `compiledPagePartialsAppPath` is absent, enabling local development without running the `build-static-content` script
