Sails.js action that renders the "Security and Control" page, filtering and ordering testimonials from static content for display in a scrollable tweets component.

## Key Components

| Element | Description |
|---|---|
| `friendlyName` | `View security and control` |
| `viewTemplatePath` | `pages/security-and-control` |
| `testimonialsForScrollableTweets` | Filtered and ordered testimonial array passed to the view |
| `testimonialOrderForThisPage` | Hardcoded author name array controlling display order |

## Behavior

- Validates that `sails.config.builtStaticContent.testimonials` exists and is an array; throws `badConfig` if not
- When static content has been compiled, filters testimonials to only those tagged under the `Software management` product category and whose author appears in the curated order list
- Sorts the filtered testimonials according to the predefined author order
- Falls back to a placeholder testimonial (injected by the custom hook) when the `build-static-content` script has not been run
- Shares the same testimonial set as the `/software-management` page

## Usage Example

```javascript
// Sails.js routes.js
'GET /security-and-control': { action: 'view-security-and-control' }
```

```javascript
// Adding a new testimonial to the order list
let testimonialOrderForThisPage = [
  'Luis Madrigal',
  // ... existing authors ...
  'New Author Name', // append here
];
```

## Notes

- Testimonials not found in `testimonialOrderForThisPage` are sorted to the end of the list
- The curated order list must match `quoteAuthorName` values exactly (case-sensitive)
