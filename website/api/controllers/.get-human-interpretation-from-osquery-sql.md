A Sails.js helper that takes an osquery SQL policy statement and uses the OpenAI GPT-4 API to generate a human-readable interpretation of the policy's security risks and expected maintenance actions.

## Key Components

- **Input:** `sql` (string, required) — an osquery SQL policy query
- **Output:** An object with two fields:
  - `risks` — description of security/stability risks if the policy fails
  - `whatWillProbablyHappenDuringMaintenance` — description of remediation actions
- **LLM Model:** GPT-4 via `https://api.openai.com/v1/chat/completions`
- **Failure Handling:** Gracefully tolerates API failures by returning a fallback message object instead of throwing, ensuring the `success` exit is always reached

## Usage Example

```javascript
// Call from within a Sails.js controller or action
let interpretation = await sails.helpers.getHumanInterpretationFromOsquerySql({
  sql: `SELECT 1 FROM os_version WHERE version >= '14.4.1';`
});

// interpretation =>
// {
//   risks: 'Using an outdated macOS version risks exposure to security vulnerabilities...',
//   whatWillProbablyHappenDuringMaintenance: 'We will update your macOS to version 14.4.1...'
// }
```

## Notes

- Requires `sails.config.custom.openAiSecret` to be configured; throws immediately if missing
- The prompt intentionally uses `whatWillHappenDuringMaintenance` (more decisive-sounding) from the LLM, then renames it to `whatWillProbablyHappenDuringMaintenance` in the returned object
- JSON parse failures from the LLM response are caught and replaced with the same fallback message, ensuring the caller always receives a consistent response shape
- Token limit is set to `256` with `temperature: 0.7` for concise, moderately creative output
