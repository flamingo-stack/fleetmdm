Handles routing and rendering for the dashboard Welcome page, returning the appropriate view template for authenticated users.

## Key Components

- **`friendlyName`** – Human-readable label: `'View welcome page'`
- **`exits.success`** – Maps to the view template at `pages/dashboard/welcome`
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Typically wired to a route in config/routes.js
'GET /dashboard/welcome': { action: 'view-welcome' }
```

The action requires no inputs and passes no data to the view — any dynamic content is handled at the template level.
