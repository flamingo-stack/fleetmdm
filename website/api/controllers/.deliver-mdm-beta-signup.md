Sends MDM beta signup form submissions to an internal Slack channel via a Zapier webhook, notifying the team when someone registers for a live Q&A.

> **Note:** This helper is marked as deprecated (`TODO: This isn't a thing anymore, we can delete it.`) and may be removed in a future update.

## Key Components

- **`fn`** — Core async function that POSTs signup data to a Zapier webhook endpoint
- **`zapierSandboxWebhookSecret`** — Required config value (`sails.config.custom.zapierSandboxWebhookSecret`) used to authenticate the webhook request

### Inputs

| Input | Type | Description |
|---|---|---|
| `emailAddress` | `string` | Submitter's email address |
| `fullName` | `string` | Submitter's full name |
| `jobTitle` | `string` | Submitter's job title |
| `numberOfHosts` | `number` | Number of hosts provided on the form |

## Usage Example

```javascript
await sails.helpers.deliverMdmBetaSignup.with({
  emailAddress: 'hermione@hogwarts.edu',
  fullName: 'Hermione Granger',
  jobTitle: 'IT Administrator',
  numberOfHosts: 150,
});
```

## Error Handling

- Throws an `Error` if `zapierSandboxWebhookSecret` is not configured.
- Non-200 responses, request failures, and timeouts (5s limit) are tolerated — a warning is logged via `sails.log.warn` rather than throwing, since Zapier may return `2xx` even on failure.
