Handles incoming GitHub webhook events and authentication redirects for the FleetMDM platform, providing automation, change visibility, and abuse monitoring across GitHub repository activity.

## Key Components

### Inputs

| Input | Type | Description |
|-------|------|-------------|
| `botSignature` | `string` | Webhook secret for request authentication |
| `action` | `string` | GitHub event action (e.g., `opened`, `ping`) |
| `sender` | `object` | GitHub user who triggered the event |
| `repository` | `object` | Repository context (optional for org-level webhooks) |
| `issue` / `pull_request` / `comment` | `object` | Event-specific payload objects |
| `projects_v2_item` | `object` | GitHub Projects v2 item data |

### Exits

- **`success`** — Event received and processed successfully
- **`unexpectedBotSignature`** — Returns `401 Unauthorized` when webhook secret validation fails

### Key Constants

- **`GITHUB_USERNAMES_OF_BOTS_AND_MAINTAINERS`** — Allowlist of bot and human maintainer usernames used for abuse monitoring, auto-label management, and `*` DRI functionality
- **`GREEN_LABEL_COLOR`** — Hex value (`C2E0C6`) identifying "done/approved" labels
- **`GITHUB_USERNAME_OF_DRI_FOR_LABELS`** — Username responsible for label management

### Required Config

```javascript
sails.config.custom.mergeFreezeAccessToken       // MergeFreeze API token
sails.config.custom.slackWebhookUrlForGithubBot  // Slack notification webhook
sails.config.custom.githubBotWebhookSecret       // Webhook HMAC secret
sails.config.custom.githubAccessToken            // GitHub API token
sails.config.custom.engMetricsGcpServiceAccountKey // GCP metrics key
```

## Usage Example

```javascript
// Sails.js route binding (config/routes.js)
'POST /webhooks/github': { action: 'webhooks/receive-from-github' }

// Example payload handled by this webhook
{
  botSignature: 'your-webhook-secret',
  action: 'opened',
  sender: { login: 'octocat' },
  repository: { name: 'fleet', owner: { login: 'fleetdm' } },
  pull_request: { number: 42, state: 'open' }
}
```

> **Note:** The webhook validates `botSignature` against `sails.config.custom.githubBotWebhookSecret` before processing any event. Missing or mismatched signatures return a `401` via the `unexpectedBotSignature` exit.
