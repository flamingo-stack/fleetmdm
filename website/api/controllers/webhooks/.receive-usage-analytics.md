Receives and stores anonymous usage analytics from production Fleet deployments, persisting the data as a `HistoricalUsageSnapshot` database record.

## Key Components

**Inputs**

| Parameter | Type | Description |
|---|---|---|
| `anonymousIdentifier` | `string` (required) | Unique anonymous ID for the Fleet deployment |
| `fleetVersion` | `string` (required) | Fleet version string (e.g. `x.x.x`) |
| `licenseTier` | `string` | `free`, `premium`, or `unknown` |
| `numHostsEnrolled` | `number` (required) | Total enrolled hosts (integer ≥ 0) |
| `numUsers` / `numTeams` / `numPolicies` / `numLabels` | `number` | Count metrics, default `0` |
| `softwareInventoryEnabled`, `vulnDetectionEnabled`, etc. | `boolean` | Feature flag states |
| `hostsEnrolledByOperatingSystem` | `object` | OS-keyed host counts |
| `hostsEnrolledByOrbitVersion` / `hostsEnrolledByOsqueryVersion` | `array` | Per-version host breakdowns |
| `storedErrors` | `array` | Captured deployment errors |
| `organization` | `string` | License-registered org name (Premium only) |
| MDM, GitOps, AI, Conditional Access flags | `boolean` | Various feature enable/disable states |
| `fleetMaintainedAppsWindows` / `fleetMaintainedAppsMacOS` | `string[]` | Managed app lists per platform |

**Exits**

- `success` — Analytics record was created successfully.

**Core Logic**

- Normalizes empty `organization` strings to `'unknown'`
- Persists all inputs to `HistoricalUsageSnapshot` via `create()`

## Usage Example

```javascript
await sails.helpers.receiveUsageAnalytics({
  anonymousIdentifier: '9pnzNmrES3mQG66UQtd29cYTiX2+fZ4CYxDvh495720=',
  fleetVersion: '4.52.0',
  licenseTier: 'premium',
  numHostsEnrolled: 1500,
  numUsers: 42,
  softwareInventoryEnabled: true,
  vulnDetectionEnabled: true,
  organization: 'Acme Corp',
  mdmMacOsEnabled: true,
  gitOpsModeEnabled: false,
});
```

> **Note:** Only triggered for production deployments — `fleetctl preview` and dev-mode instances are excluded upstream before this action is called.
