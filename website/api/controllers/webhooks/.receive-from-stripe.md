Handles incoming Stripe webhook events for Fleet MDM subscription lifecycle management, including renewal reminders, payment processing, and license key generation.

## Key Components

### Inputs

| Input | Type | Description |
|---|---|---|
| `id` | `string` | Unique Stripe event identifier |
| `type` | `string` | Stripe event type (e.g., `invoice.paid`, `invoice.upcoming`) |
| `data` | `object` | Event payload from Stripe |
| `webhookSecret` | `string` | Secret used to verify Stripe request authenticity |

### Exits

- **`success`** — Event received and processed
- **`missingStripeHeader`** — Request lacks `stripe-signature` header (returns `401 Unauthorized`)

### Handled Event Types

| Event Type | Billing Reason | Action |
|---|---|---|
| `invoice.upcoming` | `upcoming` | Sends renewal reminder email |
| `invoice.paid` | `subscription_cycle` | Generates new license key, updates subscription record, sends confirmation email |
| `invoice.paid` | `subscription_update` | Generates new license key reflecting updated seat count and price |

## Usage Example

```bash
# Example Stripe webhook payload (POST to your webhook endpoint)
POST /api/v1/webhooks/receive-from-stripe
stripe-signature: t=...,v1=...

{
  "id": "evt_1ABC123",
  "type": "invoice.paid",
  "data": {
    "object": {
      "customer": "cus_XYZ",
      "subscription": "sub_ABC",
      "billing_reason": "subscription_cycle",
      "lines": { "data": [{ "period": { "end": 1720000000 } }] }
    }
  },
  "webhookSecret": "whsec_..."
}
```

> **Configuration required:** Set `sails.config.custom.stripeSecret` and `sails.config.custom.stripeSubscriptionWebhookSecret` before deploying.

## Notes

- Events received before a `Subscription` database record exists (e.g., `invoice.created`, `checkout.session.completed`) are gracefully ignored or fall through to user-level lookups.
- Subscription ID resolution differs for `customer.subscription.updated` events — the data object itself is the subscription, so `stripeEventData.id` is used instead of `stripeEventData.subscription`.
