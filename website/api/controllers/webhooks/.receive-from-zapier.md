Sails.js webhook action that receives and routes events from Zapier, handling CRM opportunity creation, LinkedIn ABM campaign management, and placeholder URN resolution for ad campaigns.

## Key Components

**Inputs**
- `eventName` — Unique identifier for the Zap triggering the request
- `data` — Arbitrary payload from the Zap (validated per event type)
- `webhookSecret` — Shared secret used to authenticate incoming requests

**Event Handlers**

| Event Name | Description |
|---|---|
| `crm-opportunity-created` | Posts a Slack notification when a new CRM logo opportunity is created |
| `receive-new-customer-data` | Manages LinkedIn ABM campaigns — appends companies to existing campaigns or creates new ones with placeholder URNs |
| `update-placeholder-campaign-urn` | Resolves a placeholder URN in the database with the real LinkedIn campaign URN once it is created |

**Exits**
- `success` — Event received and processed
- `unrecognizedEventName` — Unknown event name; returns HTTP 200 to avoid Zapier retries
- `couldNotMatchLinkedinId` — LinkedIn company lookup failed

## Usage Example

```bash
# POST to the webhook endpoint (e.g., via Zapier HTTP action)
curl -X POST https://fleetdm.com/api/v1/receive-from-zapier \
  -H "Content-Type: application/json" \
  -d '{
    "eventName": "crm-opportunity-created",
    "webhookSecret": "your-secret",
    "data": {
      "id": "0011U000009ABCDE",
      "type": "New Logo",
      "primaryBuyingSituation": "VM",
      "accountId": "0011U000009ABCDE",
      "accountName": "Acme Corp",
      "accountRating": "Hot",
      "accountLinkedinCompanyUrl": "https://linkedin.com/company/acme"
    }
  }'
```

## Configuration Requirements

The following must be set in `sails.config.custom` before this action will function:

```javascript
module.exports.custom = {
  zapierWebhookSecret: 'your-shared-secret',
  iqSecret: 'your-iq-secret',
  slackWebhookUrlForNewlyCreatedOppts: 'https://hooks.slack.com/...',
  linkedinAbmCampaignGroupUrn: 'urn:li:sponsoredCampaignGroup:...',
};
```
