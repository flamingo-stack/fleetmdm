Renders the login page or redirects already-authenticated users to the appropriate destination based on their role.

## Key Components

**Exits**
- `success` — Renders the `pages/entrance/login` view template for unauthenticated users
- `redirect` — Redirects authenticated users away from the login page

**Function Logic (`fn`)**
- Checks `this.req.me` to determine if the user is already logged in
- Super admins (`isSuperAdmin`) are redirected to `/admin/generate-license`
- Regular authenticated users are redirected to `/try`
- Unauthenticated users proceed to the login view

## Usage Example

This is a Sails.js action wired to a route (e.g., `GET /login`). No direct invocation is needed — Sails handles dispatch automatically.

```javascript
// config/routes.js
module.exports.routes = {
  'GET /login': { action: 'entrance/view-login' },
};
```

**Request flow:**

```text
GET /login
  ├── User not logged in       → renders pages/entrance/login
  ├── User is superAdmin       → redirect /admin/generate-license
  └── User is regular member   → redirect /try
```

## Notes

- Accepts no `inputs` — the action relies entirely on session state via `this.req.me`
- Role-based redirect logic should be kept in sync with any middleware that populates `req.me`
