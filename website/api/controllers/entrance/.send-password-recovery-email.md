Sends a password recovery email to a user by generating a time-limited reset token and delivering a templated notification — silently no-ops for unrecognized addresses to prevent email enumeration.

## Key Components

| Element | Description |
|---|---|
| `emailAddress` | Required input — the email address to look up and send recovery instructions to |
| `websiteUrl` | Honeypot field — if populated, the action silently exits to block automated submissions |
| `token` | URL-friendly pseudorandom string generated via `sails.helpers.strings.random` |
| `passwordResetTokenExpiresAt` | Expiry timestamp calculated using `sails.config.custom.passwordResetTokenTTL` |
| `email-reset-password` | Template used by `sendTemplateEmail` helper to render the outbound message |

## Usage Example

```javascript
// Invoked from a controller or route handler
await sails.helpers.sendPasswordRecoveryEmail.with({
  emailAddress: 'rydahl@example.com'
});
// Always resolves successfully — no indication whether the address was found
```

## Behavior Notes

- **Enumeration protection** — returns `success` regardless of whether the email matched a user record, preventing attackers from probing valid accounts
- **Honeypot guard** — if `websiteUrl` is present in the submission, the action exits immediately without sending anything or querying the database
- **Token lifecycle** — the reset token is written to `User.passwordResetToken` alongside an expiry derived from `sails.config.custom.passwordResetTokenTTL`; the token must be validated downstream before allowing a password change
