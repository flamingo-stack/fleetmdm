Displays the "Forgot Password" page, redirecting authenticated users to the home route.

## Key Components

- **`exits.success`** — Renders the `pages/entrance/forgot-password` view template for unauthenticated users
- **`exits.redirect`** — Redirects already-logged-in users away from the page (authenticated users should use Account Settings to change their password)
- **`fn`** — Checks for an active session (`this.req.me`); throws a redirect to `/` if the user is logged in, otherwise returns an empty response to render the view

## Usage Example

```javascript
// Registered as a Sails.js action and mapped in config/routes.js
'GET /forgot-password': { action: 'view-forgot-password' }
```

When an unauthenticated user visits `/forgot-password`, the action renders the forgot-password page. Authenticated users are immediately redirected to `/`.

## Notes

- This is a Sails.js [actions2](https://sailsjs.com/documentation/concepts/actions-and-controllers) style action
- No inputs are defined — the action only inspects session state via `this.req.me`
- View template path: `pages/entrance/forgot-password`
