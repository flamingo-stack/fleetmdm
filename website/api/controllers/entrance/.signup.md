Sails.js action that handles new user account registration for fleetdm.com, including email validation, trial license generation, CRM sync, and email notifications.

## Key Components

**Inputs**
| Field | Required | Description |
|-------|----------|-------------|
| `emailAddress` | ✅ | Valid email for the new account |
| `password` | ✅ | Plain-text password (max 200 chars) |
| `firstName` | ✅ | User's first name |
| `lastName` | ✅ | User's last name |
| `organization` | ❌ | Company name; defaults to email domain |
| `signupReason` | ❌ | `'Buy a license'` or `'Try Fleet'`; defaults to `'Buy a license'` |

**Exits**
| Exit | Status | Description |
|------|--------|-------------|
| `success` | 200 | Account created |
| `invalid` | 400 | Malformed input fields |
| `emailAlreadyInUse` | 409 | Duplicate email address |
| `invalidEmailDomain` | 400 | Email domain is on the denylist |

**Core Flow**
1. Normalizes and validates the email address against existing records and a banned-domain list
2. Creates the user record with a hashed password and optional email verification token
3. Enriches user data via `sails.helpers.iq.getEnriched` to determine trial type (`'local trial'` vs `'render trial'` for orgs >700 employees or `@fleetdm.com`)
4. Generates a 30-day Fleet Premium license key and assigns a Render POV instance if eligible
5. Sends a trial welcome email based on trial type
6. Asynchronously syncs contact/account/event data to Salesforce CRM
7. Stores `userId` in session; optionally sends email verification

## Usage Example

```javascript
// POST /api/v1/entrance/signup
const response = await fetch('/api/v1/entrance/signup', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    emailAddress: 'jane@example.com',
    password: 'securepassword123',
    firstName: 'Jane',
    lastName: 'Doe',
    organization: 'Acme Corp',
    signupReason: 'Try Fleet',
  }),
});
```
