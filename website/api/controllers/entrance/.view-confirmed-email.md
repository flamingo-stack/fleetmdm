Renders the confirmed email page after a user successfully verifies their email address.

## Key Components

- **`friendlyName`** – Human-readable label: `'View confirmed email'`
- **`exits.success`** – Routes to the `pages/entrance/confirmed-email` view template
- **`fn`** – Async handler that returns an empty object, delegating all rendering to the view template

## Usage Example

```javascript
// Registered as a Sails.js action, typically mapped in config/routes.js
'GET /email/confirm/success': { action: 'entrance/view-confirmed-email' }
```

## Notes

This is a minimal Sails.js [action](https://sailsjs.com/documentation/concepts/actions-and-controllers) with no inputs or guards — it simply serves the confirmation landing page. Any conditional logic (e.g. validating a token) is expected to be handled upstream before this action is reached.
