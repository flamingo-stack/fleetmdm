Sets browser cookies required for Vanta OAuth integration and redirects the user to the Vanta authorization URL.

## Key Components

**Inputs**
| Input | Type | Description |
|---|---|---|
| `vantaSourceId` | `string` | Generated Vanta Source ID for the request |
| `state` | `string` | OAuth state parameter provided to Vanta |
| `vantaAuthorizationRequestURL` | `string` | Vanta authorization URL to redirect the user to |
| `redirectAfterSetup` | `string` | URL to redirect the user to after setup completes |

**Exits**
| Exit | Type | Description |
|---|---|---|
| `noMatchingVantaConnection` | `badRequest` | No `VantaConnection` record found for the provided `vantaSourceId` |

**Core Logic**
1. Looks up an existing `VantaConnection` record by `vantaSourceId`
2. Throws `noMatchingVantaConnection` if no record exists
3. Sets three signed cookies on the user's browser: `redirectAfterSetup`, `state`, and `vantaSourceId`
4. Redirects the user to `vantaAuthorizationRequestURL`

## Usage Example

```javascript
// Invoked as a Sails.js page action — example call via helper or router
await sails.helpers.redirectVantaAuthorizationRequest({
  vantaSourceId: 'src_abc123',
  state: 'random-oauth-state-token',
  vantaAuthorizationRequestURL: 'https://app.vanta.com/oauth/authorize?client_id=...',
  redirectAfterSetup: 'https://yourapp.com/dashboard',
});
```

> **Note:** Cookies are signed (`{ signed: true }`), so `cookieSecret` must be configured in your Sails app. These cookies are later consumed during the Vanta OAuth callback to validate the state and resume the integration setup flow.
