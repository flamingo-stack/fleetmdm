Sails.js custom hook that runs at server startup and on every matching request, handling third-party service configuration, security headers, session tracking, and marketing attribution.

## Key Components

### `initialize()`
Executes during Sails app lift:
- Validates Stripe and Sendgrid configuration, logging warnings for missing credentials
- Sets `sails.config.custom.enableBillingFeatures` based on Stripe config availability
- Configures Stripe and Sendgrid helper packs after the `organics` hook loads
- Validates `githubRepoDRIByPath` config structure
- Triggers an Algolia crawler reindex in production (only on `web.1` dyno)
- Exposes a global `ƒ` shorthand object mirroring `sails.helpers`
- Injects a placeholder testimonial in non-production environments when static content hasn't been built

### `routes.before['/*']`
Runs before every non-asset request:
- Attaches `_environment` and `me` view locals for GET/HEAD requests
- Sets security headers: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Strict-Transport-Security`, `Permissions-Policy`
- Captures ad attribution data (`utm_source`, `creative_id`, `campaign_id`) into the session
- Sets a `marketingAttribution` cookie from UTM parameters when not already present

## Usage Example

```javascript
// api/hooks/custom/index.js is auto-loaded by Sails.
// Configure required keys in config/custom.js:

module.exports.custom = {
  stripeSecret: 'sk_live_...',
  stripePublishableKey: 'pk_live_...',
  sendgridSecret: 'SG.xxx',
  internalEmailAddress: 'ops@example.com',
  fromEmailAddress: 'no-reply@example.com',
  fromName: 'My App',
  algoliaCrawlerId: 'abc123',
  algoliaCrawlerApiToken: 'Bearer ...',
  githubRepoDRIByPath: {
    'docs/': 'octocat',
  },
};
```
