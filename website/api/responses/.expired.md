Handles content negotiation for expired or invalid token responses, returning either a `498` JSON message or an HTML error page depending on the request type.

## Key Components

- **`expired()`** – Custom Sails.js response function attached to `res.expired()`. Checks `req.wantsJSON` to determine the appropriate response format.

## Behavior

| Request Type | Status | Response |
|---|---|---|
| JSON (API) | `498` | `Token Expired/Invalid` text body |
| Browser | `498` | Renders `498` view template |

## Usage Example

```javascript
// Basic usage in a controller action
return res.expired();

// With actions2 exits
exits: {
  badToken: {
    description: 'Provided token was expired, invalid, or already used up.',
    responseType: 'expired'
  }
}
```

## Notes

- Logs a verbose message via `sails.log.verbose` on each invocation, useful for debugging token-related failures.
- Requires a `498.ejs` (or equivalent) view template in your Sails.js views directory for browser-based responses.
- Source: [`api/responses/expired.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/api/responses/expired.js)
