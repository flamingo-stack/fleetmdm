A custom Sails.js response handler that returns a `500 serverError` when the application detects missing, incomplete, or invalid server configuration, with context-aware troubleshooting guidance.

## Key Components

- **`badConfig(configKeyPath)`** — The exported response function, callable as `res.badConfig()` or via actions2 exits. Accepts an optional `configKeyPath` string (e.g., `"custom.internalEmailAddress"`) representing the dot-notation key path within `sails.config`.

## Behavior

- **Validates** the `configKeyPath` argument — rejects empty strings, non-strings, or paths prefixed with `sails.config` (which are redundant).
- **Generates a context-aware explanation:**
  - No argument → generic message prompting the developer to check server logs.
  - `builtStaticContent.*` key → suggests running `sails run build-static-content`.
  - Any other key → links to [Sails.js configuration docs](https://sailsjs.com/documentation/concepts/configuration).
- **Delegates** to `res.serverError(explanation)` for the actual HTTP 500 response.

## Usage Example

```javascript
// Basic usage in a controller action
return res.badConfig();

// With a specific config key path
return res.badConfig('custom.internalEmailAddress');

// Via actions2 exits
exits: {
  badConfig: { responseType: 'badConfig' }
}
// Then in the action:
throw { badConfig: 'builtStaticContent.queries' };
```
