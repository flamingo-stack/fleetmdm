Registers two Grunt tasks that inject the Babel polyfill into the asset pipeline for production and development environments.

## Key Components

| Task | Description |
|------|-------------|
| `polyfill:prod` | Prepends the Babel polyfill to the JS concatenation list for production builds |
| `polyfill:dev` | Copies the polyfill to `.tmp/public/polyfill/` and prepends it to all `sails-linker` dev JS file globs |

## Usage Example

```javascript
// Gruntfile.js — register and invoke the polyfill tasks
require('./tasks/register/polyfill')(grunt);

// Typically chained in a build pipeline:
grunt.registerTask('build', [
  'polyfill:prod',
  'concat',
  // ...other tasks
]);

grunt.registerTask('linkAssets', [
  'polyfill:dev',
  'sails-linker:devJs',
  // ...other tasks
]);
```

## Notes

- **`polyfill:prod`** — uses `grunt.config.set` to mutate `concat.js.src`, placing the polyfill path (resolved via `sails-hook-grunt`) at index 0 so it is always bundled first.
- **`polyfill:dev`** — adds a `copy.dev.files` entry to move the polyfill into `.tmp/public/polyfill/`, then iterates every glob key in `sails-linker.devJs.files` to prepend `.tmp/public/polyfill/polyfill.min.js`, ensuring it is linked before any app scripts.
- Depends on `sails-hook-grunt` to resolve the physical path to the Babel polyfill — no manual path configuration required.
