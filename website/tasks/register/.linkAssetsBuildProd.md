Registers a Grunt task that links production-built JavaScript and CSS assets into HTML files using the `sails-linker` plugin.

## Key Components

- **`linkAssetsBuildProd`** — Grunt task that sequentially runs:
  - `sails-linker:prodJsBuild` — Injects production JS build references
  - `sails-linker:prodStylesBuild` — Injects production CSS build references

## Usage Example

```javascript
// Executed as part of the Sails.js production build pipeline
grunt.task.run('linkAssetsBuildProd');
```

This task is typically invoked automatically during the production asset pipeline. Refer to the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/register/link-assets-build-prod.js) or the [source file](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/linkAssetsBuildProd.js) for configuration details.
