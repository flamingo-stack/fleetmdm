Registers the Grunt `prod` task, which defines the asset pipeline executed when a Sails.js application runs in a production environment (`NODE_ENV=production`).

## Key Components

- **`prod` task** — Ordered Grunt task list optimized for production builds, including transpilation, concatenation, minification, and asset linking.

| Step | Task | Purpose |
|---|---|---|
| 1 | `polyfill:prod` | Injects browser polyfills (optional, remove to skip transpilation) |
| 2 | `compileAssets` | Compiles raw assets (LESS, SASS, etc.) |
| 3 | `babel` | Transpiles modern JS to ES5 (optional, remove to skip) |
| 4 | `concat` | Concatenates JS/CSS files |
| 5 | `uglify` | Minifies JavaScript |
| 6 | `cssmin` | Minifies CSS |
| 7 | `sails-linker:prodJs` | Injects `<script>` tags into HTML views |
| 8 | `sails-linker:prodStyles` | Injects `<link>` tags into HTML views |

## Usage Example

```bash
# Triggered automatically when lifting Sails in production
NODE_ENV=production node app

# Or run the Grunt task directly
grunt prod
```

To skip transpilation (not recommended), comment out `polyfill:prod` and `babel` in the task list:

```javascript
grunt.registerTask('prod', [
  // 'polyfill:prod',
  'compileAssets',
  // 'babel',
  'concat',
  'uglify',
  'cssmin',
  'sails-linker:prodJs',
  'sails-linker:prodStyles',
]);
```

## Notes

- This task replaces the `default` Grunt task in production environments.
- Removing `polyfill:prod` or `babel` may break compatibility with older browsers.
- Full Sails.js documentation: [sailsjs.com/anatomy/tasks/register/prod.js](https://sailsjs.com/anatomy/tasks/register/prod.js)
