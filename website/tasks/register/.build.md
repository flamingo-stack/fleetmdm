Registers the `build` Grunt task, which compiles and packages frontend assets for production output via `sails www` or `grunt build`.

## Key Components

- **`build` task** — Orchestrates the asset pipeline by running the following subtasks in sequence:
  - `compileAssets` — Compiles raw source assets (CSS, JS, templates)
  - `linkAssetsBuild` — Injects asset references into layout files
  - `clean:build` — Removes stale files from the build output directory
  - `copy:build` — Copies compiled assets to the `.tmp/public` build folder

## Usage Example

```bash
# Run via Sails CLI
sails www

# Or directly via Grunt
grunt build
```

To enable ES5 transpilation for broader browser compatibility, uncomment the optional subtasks in [`tasks/register/build.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/build.js):

```javascript
grunt.registerTask('build', [
  'polyfill:dev',    // ← uncomment for polyfills
  'compileAssets',
  'babel',           // ← uncomment for Babel transpilation
  'linkAssetsBuild',
  'clean:build',
  'copy:build'
]);
```

> **Note:** The `polyfill:dev` and `babel` steps are disabled by default. Enable them only if you need to support legacy browsers.
