Registers a Grunt task named `syncAssets` that compiles LESS stylesheets and syncs static assets during development.

## Key Components

- **`syncAssets` task** – A composite Grunt task that runs `less:dev` followed by `sync:dev` in sequence

## Usage Example

```javascript
// Invoked automatically by Sails.js during development (sails lift)
// Or manually via Grunt CLI:
grunt syncAssets
```

## Notes

- Part of the Sails.js asset pipeline (`tasks/register/`)
- Runs two sub-tasks in order:
  - `less:dev` – Compiles LESS files into CSS for the development environment
  - `sync:dev` – Syncs compiled assets to the `.tmp/public` directory
- Intended for **development only**; production builds use a separate pipeline (e.g., `buildProd`)

For more details, see the [Sails.js anatomy reference](https://sailsjs.com/anatomy/tasks/register/sync-assets.js) or the source file at [`tasks/register/syncAssets.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/register/syncAssets.js).
