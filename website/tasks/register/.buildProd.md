Grunt task registration for the production build pipeline, executed when running `sails www` in a production environment (`NODE_ENV=production`).

## Key Components

**`buildProd` Task** — A Grunt task sequence that compiles, optimizes, and finalizes all frontend assets for production deployment.

| Step | Task | Purpose |
|------|------|---------|
| 1 | `polyfill:prod` | Transpiles modern JS for older browsers |
| 2 | `compileAssets` | Compiles raw source assets |
| 3 | `babel` | Additional JS transpilation pass |
| 4 | `concat` | Concatenates asset files |
| 5 | `uglify` | Minifies JavaScript |
| 6 | `cssmin` | Minifies CSS |
| 7 | `hash` | Cache-busting via content hashing |
| 8 | `copy:beforeLinkBuildProd` | Prepares files for prettier post-hash URLs |
| 9 | `linkAssetsBuildProd` | Injects hashed asset references into HTML |
| 10 | `clean:build` | Removes intermediate build artifacts |
| 11 | `copy:build` | Copies final assets to output directory |
| 12 | `clean:afterBuildProd` | Final cleanup of temporary files |

## Usage Example

```bash
# Triggers buildProd instead of the default build task
NODE_ENV=production sails www
```

To skip transpilation (not recommended for production):

```javascript
// In tasks/register/buildProd.js, comment out polyfill and babel steps
grunt.registerTask('buildProd', [
  // 'polyfill:prod',
  'compileAssets',
  // 'babel',
  'concat',
  'uglify',
  'cssmin',
  'hash',
  // ...
]);
```

## Notes

- Differs from the default `build` task by adding minification (`uglify`, `cssmin`) and cache-busting (`hash`)
- Transpilation steps (`polyfill:prod`, `babel`) are optional but recommended for broad browser compatibility
- Full Sails.js reference: [sailsjs.com/anatomy/tasks/register/build-prod.js](https://sailsjs.com/anatomy/tasks/register/build-prod.js)
