Registers a Grunt task that injects compiled JavaScript and CSS asset links into HTML templates during the build process.

## Key Components

- **`linkAssetsBuild`** — Composite Grunt task that runs two `sails-linker` sub-tasks sequentially:
  - `sails-linker:devJsBuild` — Injects built JavaScript file references into templates
  - `sails-linker:devStylesBuild` — Injects built CSS stylesheet references into templates

## Usage Example

```javascript
// Run via Grunt CLI
// grunt linkAssetsBuild

// Or register as a dependency in another Grunt task
grunt.registerTask('build', [
  'compileAssets',
  'linkAssetsBuild', // injects JS + CSS links into templates
]);
```

## Notes

- This task is part of the [Sails.js](https://sailsjs.com) Grunt pipeline, typically used during development builds rather than production compilation.
- Relies on `grunt-sails-linker` being configured in the Grunt task configuration (e.g., `tasks/config/sails-linker.js`).
- Full Sails.js anatomy reference: [link-assets-build.js](https://sailsjs.com/anatomy/tasks/register/link-assets-build.js)
