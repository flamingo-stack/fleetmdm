Registers a Grunt task named `compileAssets` that orchestrates the asset compilation pipeline for development by running clean, LESS compilation, and file copy subtasks in sequence.

## Key Components

- **`compileAssets` task** — Composite Grunt task that chains three subtasks:
  - `clean:dev` — Removes previously compiled assets from the dev build directory
  - `less:dev` — Compiles LESS stylesheets into CSS
  - `copy:dev` — Copies static assets to the build output directory

## Usage Example

```javascript
// Invoked via Grunt CLI
// grunt compileAssets

// Or registered as a dependency in another Grunt task
grunt.registerTask('default', ['compileAssets', 'watch']);
```
