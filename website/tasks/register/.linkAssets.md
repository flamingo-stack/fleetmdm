Registers a Grunt task that links development JavaScript and CSS assets into HTML templates using the `sails-linker` plugin.

## Key Components

- **`linkAssets`** — Composite Grunt task that runs two sub-tasks sequentially:
  - `sails-linker:devJs` — Injects `<script>` tags for development JS files
  - `sails-linker:devStyles` — Injects `<link>` tags for development CSS files

## Usage Example

```javascript
// Invoke via Grunt CLI
// grunt linkAssets

// Or reference in another Grunt task pipeline
grunt.registerTask('default', ['linkAssets', 'watch']);
```
