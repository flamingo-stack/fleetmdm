Grunt task configuration that compiles LESS files into CSS stylesheets for the Sails.js asset pipeline.

## Key Components

- **`less.dev`** — Task target that processes `importer.less` from `assets/styles/` and outputs compiled CSS to `.tmp/public/styles/`

## Usage Example

```javascript
// tasks/config/less.js is auto-loaded by Sails.js grunt pipeline.
// To customize, modify the file glob or output path:

grunt.config.set('less', {
  dev: {
    files: [{
      expand: true,
      cwd: 'assets/styles/',
      src: ['importer.less'],   // Entry point for LESS imports
      dest: '.tmp/public/styles/',
      ext: '.css'
    }]
  }
});

// To use a custom grunt-contrib-less version, install it:
// npm install grunt-contrib-less --save-dev --save-exact
// Then load it manually:
// grunt.loadNpmTasks('grunt-contrib-less');
```

## Notes

- Only `importer.less` is compiled directly — use it as the entry point to `@import` other LESS partials from `assets/styles/`
- Output is written to `.tmp/public/styles/` (not committed to source control)
- The plugin is pre-loaded by Sails.js; manual `loadNpmTasks` is only needed when substituting a custom version
- Remove this file entirely to opt out of LESS compilation in the pipeline
