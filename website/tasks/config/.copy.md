Configures the `grunt-contrib-copy` task for copying static assets across different build stages in a Sails.js application.

## Key Components

| Target | Source | Destination | Purpose |
|---|---|---|---|
| `dev` | `./assets/**` (excludes `.coffee`, `.less`) | `.tmp/public` | Copies raw assets for development |
| `build` | `.tmp/public/**` | `www` | Copies processed assets for production build |
| `beforeLinkBuildProd` | `.tmp/public/hash/**` | `.tmp/public/dist` | Stages hashed assets before link injection |

## Usage Example

```javascript
// Grunt runs these targets as part of the asset pipeline:

// Development (watch mode)
grunt.task.run('copy:dev');

// Production build sequence
grunt.task.run('copy:build');
grunt.task.run('copy:beforeLinkBuildProd');
```

To override with a custom version of `grunt-contrib-copy`:

```bash
npm install grunt-contrib-copy --save-dev --save-exact
```

Then add to this file:

```javascript
// Load Grunt plugin from the node_modules/ folder.
grunt.loadNpmTasks('grunt-contrib-copy');
```

> **Note:** The `dev` target intentionally excludes `.coffee` and `.less` files (`**/*.!(coffee|less)`) since those are handled by their own compilation tasks before being placed in `.tmp/public`.
