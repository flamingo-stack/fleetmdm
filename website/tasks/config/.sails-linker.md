Grunt task configuration for `grunt-sails-linker` that automatically injects `<script>` and `<link>` tags into HTML and EJS view files during the asset pipeline build process.

## Key Components

Eight task targets organized into two groups (JavaScript and CSS), each with development and production variants:

| Target | Purpose |
|---|---|
| `devJs` | Injects dev JS files from pipeline into HTML/EJS views |
| `devJsBuild` | Same as `devJs`, supports optional relative path mode |
| `prodJs` | Injects minified `production.min.js` into HTML/EJS views |
| `prodJsBuild` | Injects bundled dist JS files into HTML/EJS views |
| `devStyles` | Injects dev CSS files from pipeline into HTML/EJS views |
| `devStylesBuild` | Same as `devStyles`, supports optional relative path mode |
| `prodStyles` | Injects minified `production.min.css` into HTML/EJS views |
| `prodStylesBuild` | Injects bundled dist CSS files into HTML/EJS views |

All targets use HTML comment delimiters as insertion markers:
- Scripts: `<!--SCRIPTS-->` / `<!--SCRIPTS END-->`
- Styles: `<!--STYLES-->` / `<!--STYLES END-->`

## Usage Example

Add the corresponding delimiter comments to your HTML or EJS views, and the linker will inject the appropriate tags between them:

```html
<!--STYLES-->
<!-- CSS tags injected here automatically -->
<!--STYLES END-->

<!--SCRIPTS-->
<!-- Script tags injected here automatically -->
<!--SCRIPTS END-->
```

To use a custom version of the plugin instead of the built-in one:

```bash
npm install grunt-sails-linker --save-dev --save-exact
```

Then uncomment `grunt.loadNpmTasks('grunt-sails-linker')` at the bottom of the file.

> **Note:** Uncomment `relative: true` in any build target's options when compiling assets for PhoneGap or CDN delivery.
