Configures the `grunt-contrib-concat` Grunt task to merge multiple JS and CSS source files into single monolithic output files, serving as an intermediate build step before minification.

## Key Components

- **`js` target** — Concatenates all JavaScript files listed in `pipeline.jsFilesToInject` into `.tmp/public/concat/production.js`
- **`css` target** — Concatenates all CSS files listed in `pipeline.cssFilesToInject` into `.tmp/public/concat/production.css`
- **Pipeline integration** — Source file lists are pulled from [`tasks/pipeline.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/pipeline.js), keeping asset ordering centralized

## Usage Example

```javascript
// tasks/pipeline.js — define which files get concatenated
var jsFilesToInject = [
  'js/dependencies/**/*.js',
  'js/**/*.js'
];

var cssFilesToInject = [
  'styles/**/*.css'
];
```

```bash
# Run concat task directly
grunt concat

# Or as part of the full build pipeline
grunt build
```

## Notes

- Output files land in `.tmp/public/concat/` and are **not** committed to source control
- To use a custom version of `grunt-contrib-concat`, install it via npm and call `grunt.loadNpmTasks('grunt-contrib-concat')` within this file (see commented block)
- Removing this file disables concatenation; minification tasks that depend on the output will also fail
