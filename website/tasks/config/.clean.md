Configures the `grunt-contrib-clean` Grunt task to remove generated files and directories across different build targets in a Sails.js application.

## Key Components

| Target | Paths Cleaned |
|---|---|
| `dev` | `.tmp/public/**` — clears the development temp folder |
| `build` | `www/` — removes the entire production build output |
| `afterBuildProd` | Intermediate build artifacts (`concat`, `min`, `hash`, `js`, `styles`, `templates`, `dependencies`) inside `www/` |

## Usage Example

```javascript
// This task is auto-loaded by Sails. Run via Grunt:

// Clear dev temp files
// grunt clean:dev

// Remove full production build
// grunt clean:build

// Remove intermediate artifacts after production build
// grunt clean:afterBuildProd
```

To use a custom version of the plugin, install it explicitly:

```bash
npm install grunt-contrib-clean --save-dev --save-exact
```

Then load it manually inside the module:

```javascript
grunt.loadNpmTasks('grunt-contrib-clean');
```

## Notes

- Automatically loaded as part of the Sails.js default asset pipeline — no manual setup required in most cases.
- `afterBuildProd` is typically invoked after minification and concatenation to strip intermediate artifacts, keeping only the final hashed output in `www/`.
- Deleting this file removes the clean task entirely from the pipeline.
