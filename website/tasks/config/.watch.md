Configures the Grunt `watch` task to monitor asset files and automatically trigger sync and linking tasks when changes are detected.

## Key Components

- **`watch.assets.files`** — Glob patterns defining which files to watch: everything under `assets/**/*` and `tasks/pipeline.js`, excluding `node_modules`
- **`watch.assets.tasks`** — Ordered list of Grunt tasks executed on change: `syncAssets` then `linkAssets`

## Usage Example

```javascript
// Triggered automatically by the Sails default asset pipeline.
// To run manually via Grunt CLI:
```

```bash
grunt watch
```

```javascript
// To override with grunt-contrib-watch, install the plugin first:
```

```bash
npm install grunt-contrib-watch --save-dev --save-exact
```

```javascript
// Then load it explicitly in this file:
grunt.loadNpmTasks('grunt-contrib-watch');
```

## Notes

- This task is pre-loaded by the Sails asset pipeline — no manual plugin registration is required unless swapping to a custom version
- Removing this file disables file watching entirely; the `syncAssets` and `linkAssets` tasks will only run on an explicit `grunt build`
- The `!**/node_modules/**` pattern prevents unnecessary re-triggers from dependency installs
