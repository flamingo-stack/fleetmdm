Configures the Grunt `uglify` task to minify concatenated client-side JavaScript for production builds using UglifyES.

## Key Components

- **`dist`** — Defines input/output paths: reads from `.tmp/public/concat/production.js` and writes minified output to `.tmp/public/min/production.min.js`
- **`mangle.reserved`** — Prevents renaming of critical globals: `AsyncFunction`, `SailsSocket`, `Promise`, `File`, `FileList`, `FormData`, `Location`, and `RttcRefPlaceholder`
- **`keep_fnames`** — Preserves function names in both `mangle` and `compress` passes to avoid runtime errors in code that relies on `Function.prototype.name`

## Usage Example

```bash
# Run the uglify task directly via Grunt
grunt uglify
```

```javascript
// To swap in grunt-contrib-uglify instead of the default UglifyES plugin,
// install it and load it manually in this file:
grunt.loadNpmTasks('grunt-contrib-uglify');
```

## Notes

- This task runs **after** concatenation, so [`tasks/config/concat.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/config/concat.js) must execute first.
- The plugin is auto-loaded by Sails' default asset pipeline — no explicit `loadNpmTasks` call is needed unless swapping to a custom plugin.
- To disable minification entirely, delete this file or remove `uglify` from the build pipeline task list.
