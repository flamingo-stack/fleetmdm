Configures the Grunt `sync` task to mirror files from the `assets/` directory into `.tmp/public/`, overwriting existing content during Sails.js development builds.

## Key Components

- **`sync.dev`** — Grunt task configuration that defines a file sync operation:
  - **`cwd`**: Source root set to `./assets`
  - **`src`**: Glob pattern `**/*.!(coffee|less)` — copies all files except `.coffee` and `.less` (handled by separate compilation tasks)
  - **`dest`**: Output target at `.tmp/public`

## Usage Example

This file is auto-loaded by Sails.js's default Grunt pipeline. No manual invocation is needed, but you can run it directly:

```bash
grunt sync:dev
```

To use a custom version of the underlying plugin, install and load it manually:

```bash
npm install grunt-sync --save-dev --save-exact
```

Then uncomment in the file:

```javascript
grunt.loadNpmTasks('grunt-sync');
```

## Notes

- Part of the default Sails.js asset pipeline — pre-loaded automatically
- Excludes `.coffee` and `.less` files, which are compiled separately before syncing
- Safe to delete if the sync step is not needed, or replace with a custom `grunt-sync` version
