Configures the `cssmin` Grunt task to minify concatenated CSS for production builds in a Sails.js asset pipeline.

## Key Components

- **`cssmin` task config** — Takes the concatenated `.tmp/public/concat/production.css` file and outputs a minified version to `.tmp/public/min/production.min.css`

## Usage Example

```javascript
// This task runs automatically as part of the Sails production build pipeline.
// It is typically invoked after the `concat` task completes:

// grunt cssmin
// Input:  .tmp/public/concat/production.css
// Output: .tmp/public/min/production.min.css
```

To use a custom version of the plugin, install it manually and load it in this file:

```bash
npm install grunt-contrib-cssmin --save-dev --save-exact
```

```javascript
// Then uncomment in cssmin.js:
grunt.loadNpmTasks('grunt-contrib-cssmin');
```

## Notes

- This is the **final step** in the CSS pipeline: `LESS/CSS source → concat → cssmin`
- The plugin is pre-loaded by Sails' default pipeline; no manual `loadNpmTasks` call is needed unless swapping to a custom version
- Removing this file disables CSS minification entirely for production builds

For more details, see the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/config/cssmin.js) or the source on GitHub at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/config/cssmin.js).
