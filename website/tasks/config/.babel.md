Configures the Grunt `babel` task to transpile modern JavaScript (ES6+) into browser-compatible code as part of the Sails.js asset pipeline.

## Key Components

- **`babel.dist`** — Task target that processes all `js/**/*.js` files under `.tmp/public`, transpiling them in-place using `babel-preset-env` from `sails-hook-grunt`.

## Usage Example

```javascript
// Invoked automatically by the Sails.js Grunt pipeline.
// To run manually:
grunt.task.run('babel:dist');
```

To swap in a custom `grunt-babel` installation instead of the built-in one:

```bash
npm install grunt-babel --save-dev --save-exact
```

Then uncomment in this file:

```javascript
grunt.loadNpmTasks('grunt-babel');
```

## Notes

- Source and destination are both `.tmp/public`, so files are transpiled in-place.
- The preset is sourced from `sails-hook-grunt/accessible/babel-preset-env` by default.
- This file can be deleted to remove Babel transpilation from the pipeline entirely.
- See the [Sails.js anatomy docs](https://sailsjs.com/anatomy/tasks/config/babel.js) or the source at [`tasks/config/babel.js`](https://github.com/flamingo-stack/fleetmdm/blob/main/tasks/config/babel.js) for further reference.
