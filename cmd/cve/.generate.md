This file is a CLI tool that generates and synchronizes NVD (National Vulnerability Database) CVE data feeds for Fleet's vulnerability detection, producing compressed JSON files with accompanying metadata.

## Key Components

- **`main()`** — Entry point accepting `--db_dir` and `--debug` flags; orchestrates the full sync pipeline: optional incremental download, CVE feed generation, metadata creation, and empty placeholder file creation.
- **`downloadLatestRelease()`** — Downloads the latest CVE feed archive, decompresses `.json.gz` files, and fetches the `last_mod_start_date.txt` asset with up to 3 retries.
- **`downloadLatestGitHubAsset()`** — Fetches a named asset from the latest GitHub CVE release and writes it to disk.
- **`createMetadata()`** — Produces a `.meta` file for each compressed feed containing `gzSize` and `sha256` fields.
- **`createEmptyFiles()`** — Creates gzipped placeholder JSON feeds for `modified` and `recent` NVD feed slots.
- **`fileFmt()`** — Constructs NVD feed filenames in the format `nvdcve-1.1-<suffix>.<encoding>[.<compression>]`.
- **`gunzipFileToDisk()`** — Decompresses a `.gz` file to disk with a 200MB cap to prevent decompression bombs (G110).
- **`gunzipFileAndComputeSHA256()`** / **`computeSHA256()`** — Streaming SHA-256 computation over decompressed content.

## Usage Example

```bash
# Full NVD sync (clean environment)
VULNERABILITIES_CLEAN=false go run generate.go --db_dir /tmp/vulndbs --debug

# Incremental sync (skip downloading latest release)
go run generate.go --db_dir /tmp/vulndbs
```

```go
// Outputs per year from 2002 to current year:
// nvdcve-1.1-2024.json.gz   (compressed feed)
// nvdcve-1.1-2024.meta      (gzSize + sha256)

// Empty placeholder feeds always created:
// nvdcve-1.1-modified.json.gz + .meta
// nvdcve-1.1-recent.json.gz  + .meta
```

The `VULNERABILITIES_CLEAN` env var controls whether the tool attempts an incremental download (`false`) or performs a full NVD sync from scratch (any other value).
