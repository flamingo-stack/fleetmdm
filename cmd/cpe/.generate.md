A CLI tool that fetches CPE (Common Platform Enumeration) data from the NVD API, generates a SQLite database, compresses it with gzip, and appends its SHA256 checksum to the filename.

## Key Components

| Function | Description |
|---|---|
| `main()` | Entry point; orchestrates CPE fetching, compression, and checksum generation |
| `getCPEs()` | Paginates through the NVD API to collect all CPE entries with retry logic |
| `convertToCPEItem()` | Maps `nvdapi.CPE` structs to `cpedict.CPEItem`, including WFN name parsing and deprecation handling |
| `compress()` | Gzip-compresses the SQLite database file |
| `addSHA256()` | Computes SHA256 of the compressed file and renames it to include the hash |
| `replaceLast()` | String utility that replaces the last occurrence of a substring |

## Configuration Constants

| Constant | Value | Purpose |
|---|---|---|
| `httpClientTimeout` | 3 minutes | HTTP client timeout |
| `waitTimeBetweenRequests` | 6 seconds | NVD API rate limiting delay |
| `waitTimeForRetry` | 10 seconds | Backoff delay on failed requests |
| `maxRetryAttempts` | 20 | Max retries before panic |
| `apiKeyEnvVar` | `NVD_API_KEY` | Required environment variable |

## Usage Example

```bash
# Set required API key and run
export NVD_API_KEY=your_nvd_api_key_here
go run generate.go
```

The tool outputs a file named `cpe-<sha256hash>.sqlite.gz` in the working directory. The SQLite database is generated via `nvd.GenerateCPEDB` and a sanity check ensures the fetched count matches `TotalResults` from the API before writing.

> **Note:** Requires the `NVD_API_KEY` environment variable. The NVD API enforces rate limits; the tool respects the [recommended 6-second delay](https://nvd.nist.gov/developers/api-workflows) between paginated requests.
