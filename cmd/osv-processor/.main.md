OSV vulnerability data processor that parses Open Source Vulnerability (OSV) JSON files for Ubuntu and RHEL platforms, aggregates CVE data by package and OS version, and writes gzip-compressed JSON artifacts — including optional daily delta files.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `OSVData` | struct | Root OSV schema: ID, published/modified dates, affected packages |
| `Affected` | struct | Per-package vulnerability data with version ranges and ecosystem metadata |
| `ProcessedVuln` | struct | Flattened CVE record (CVE ID, dates, introduced/fixed versions) |
| `ArtifactData` | struct | Ubuntu output artifact: schema, version, CVE map keyed by package name |
| `RHELArtifactData` | struct | RHEL output artifact: same shape as `ArtifactData` with `rhel_version` |
| `Config` | struct | Runtime configuration derived from CLI flags |
| `main()` | func | Parses flags, builds `Config`, dispatches to `run()` or `runRHEL()` |
| `run()` | func | Ubuntu pipeline: walks OSV files, filters versions, writes full + delta artifacts |

## Usage Example

```bash
# Process all Ubuntu OSV files from default path
go run . --platform ubuntu --output ./artifacts

# Process only Ubuntu 22.04 and 24.04, with delta tracking
go run . \
  --platform ubuntu \
  --input /tmp/ubuntu-osv \
  --versions "22.04,24.04" \
  --changed-files-today /tmp/changed-today.txt \
  --output ./artifacts

# Process RHEL, excluding a specific version
go run . \
  --platform rhel \
  --input /tmp/rhel-osv \
  --exclude-versions "7" \
  --output ./artifacts
```

Output files follow the naming convention:

```text
osv-ubuntu-2204-2025-01-15.json.gz          # full snapshot
osv-ubuntu-2204-delta-2025-01-15.json.gz    # daily delta
```
