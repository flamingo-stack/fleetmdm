Provides a hook for applying custom transformations, filters, and package expansion rules to OSV vulnerability data before it is emitted by the pipeline.

## Key Components

- **`transformVuln(packageName, cveID string, vuln *ProcessedVuln) ([]string, *ProcessedVuln)`** — Called once per CVE/package pair. Returns the (possibly expanded) list of packages that should receive the CVE and an optional modified copy of the vulnerability. Returning `nil, nil` drops the CVE entirely.

## Usage Example

```go
// Expand "emacs" CVEs to sibling packages, or drop/modify specific CVEs:
packages, modifiedVuln := transformVuln("emacs", "CVE-2024-39331", &vuln)
// packages → ["emacs", "emacs-common", "emacs-el"]
// modifiedVuln → nil (original vuln used as-is)
```

## Extension Patterns

| Goal | What to change |
|---|---|
| Drop a specific CVE | Uncomment the `return nil, nil` block and add the CVE ID |
| Expand a package to siblings | Add an `if packageName == "…"` block with `append` |
| Override a fixed version | Copy the struct (`modified := *vuln`), set fields, return `&modified` |

> The function is intentionally kept as a single editable file so operators can maintain local policy patches without touching core pipeline logic. See [`transforms.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/transforms.go) for the full source.
