Initializes the GeoIP provider for the Fleet server, returning either a MaxMind-backed implementation or a no-op fallback when the database is unavailable.

## Key Components

- **`initGeoIP(ctx, cfg, logger)`** — Selects and constructs the appropriate `fleet.GeoIP` implementation based on configuration. Returns `fleet.NoOpGeoIP` if no database path is configured or if the MaxMind database fails to load, logging an error instead of halting startup.

## Usage Example

```go
geoIP := initGeoIP(ctx, config, logger)

// Use the provider downstream (works regardless of whether
// MaxMind loaded successfully or fell back to no-op)
location := geoIP.Lookup("203.0.113.42")
```

## Behavior Notes

| Condition | Result |
|---|---|
| `cfg.GeoIP.DatabasePath` is empty | Returns `&fleet.NoOpGeoIP{}` silently |
| MaxMind DB fails to load | Logs error, returns `&fleet.NoOpGeoIP{}` |
| MaxMind DB loads successfully | Returns live `fleet.MaxMindGeoIP` provider |

GeoIP is treated as best-effort — failures degrade gracefully and never block server startup.
