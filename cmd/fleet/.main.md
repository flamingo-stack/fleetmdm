Entry point for the Fleet server binary, responsible for registering all subcommands, handling stdin argument injection, and initializing logging and tracing infrastructure.

## Key Components

| Symbol | Description |
|--------|-------------|
| `main()` | Bootstraps the root Cobra command, registers subcommands, handles piped stdin args, and executes the CLI |
| `createRootCmd()` | Builds the base `fleet` Cobra command with a `--config` / `-c` flag |
| `applyDevFlags(cfg)` | Fills missing config fields with local docker-compose defaults (MySQL, S3 carves, software installers) |
| `initLogger(cfg, provider)` | Constructs a `*slog.Logger` wired to JSON/debug/tracing/OTEL settings from `FleetConfig` |
| `initFatal` | Var-wrapped fatal error handler (prints + `os.Exit(1)`); overridable in tests |
| `tracer` | Package-level OpenTelemetry tracer scoped to `github.com/fleetdm/fleet/v4/cmd/fleet` |

## Usage Example

```bash
# Run the Fleet server
fleet serve --config /etc/fleet/fleet.yml

# Pipe additional arguments from stdin (e.g. secrets from a secrets manager)
echo "--mysql_password=secret" | fleet serve

# Prepare the database
fleet prepare db --config /etc/fleet/fleet.yml
```

```go
// initFatal is a var so tests can override it without calling os.Exit
var initFatal = func(err error, message string) {
    fmt.Printf("Failed to start: %s: %v\n", message, err)
    os.Exit(1)
}

// Override in tests:
initFatal = func(err error, msg string) {
    t.Fatalf("%s: %v", msg, err)
}
```
