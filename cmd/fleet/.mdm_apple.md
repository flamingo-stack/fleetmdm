Initializes and reconciles Apple MDM infrastructure components (storage backends, push services, and configuration assets) during Fleet server startup.

## Key Components

| Function | Description |
|---|---|
| `initAppleMDMStorages` | Constructs NanoMDM, DEP, and SCEP storage backends backed by the MySQL datastore |
| `initAppleMDMPushService` | Builds an APNs push service (real or no-op dev mode) using the NanoMDM storage |
| `checkMDMAssetsExist` | Queries the datastore for named MDM config assets; treats missing/partial results as "not configured" |
| `reconcileAppleMDMAPNsAndSCEPAssets` | Syncs APNs and SCEP cert/key assets from server config into the datastore on first setup |
| `reconcileAppleMDMABMAssets` | Syncs Apple Business Manager cert/key assets and inserts an initial ABM token row on first setup |

## Usage Example

```go
// Initialize storages
mdmStorage, depStorage, scepStorage := initAppleMDMStorages(ds, initFatal)

// Build push service (respects FLEET_DEV_MDM_APPLE_DISABLE_PUSH=1)
pusher := initAppleMDMPushService(mdmStorage, logger)

// Reconcile APNs/SCEP assets from environment config into DB (idempotent)
reconcileAppleMDMAPNsAndSCEPAssets(ctx, cfg, ds, logger, initFatal)

// Reconcile ABM assets and token from environment config into DB (idempotent)
reconcileAppleMDMABMAssets(ctx, cfg, ds, logger, initFatal)
```

## Notes

- All reconcile functions are **idempotent**: they skip insertion and log a warning if assets already exist in the datastore, preventing environment variables from overwriting live certificates.
- `initAppleMDMPushService` enforces TLS 1.2+ as required by Apple APNs.
- ABM token rows are inserted with a sentinel `RenewAt` of `2000-01-01` to signal the `apple_mdm_dep_profile_assigner` cron to backfill metadata.
- Set `FLEET_DEV_MDM_APPLE_DISABLE_PUSH=1` to bypass real APNs during local development.
