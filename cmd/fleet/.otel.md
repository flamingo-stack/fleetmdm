Initializes and configures OpenTelemetry (OTEL) trace, metric, and log providers for the Fleet server, wiring them to OTLP/gRPC exporters with gzip compression.

## Key Components

- **`initOTELProviders`** — Main setup function that returns fully configured `LoggerProvider`, `TracerProvider`, `MeterProvider`, and `RouteTierSampler`. Returns all `nil` when OTEL is disabled via `cfg.OTELEnabled()`.
- **Resource** — Built with `semconv` service attributes (`fleet` service name, version, `deployment.environment`). Environment variables `OTEL_SERVICE_NAME` and `OTEL_RESOURCE_ATTRIBUTES` override defaults.
- **Trace pipeline** — Uses `otlptracegrpc` with gzip compression, a `BatchSpanProcessor` (batch size capped at 256 to stay under the 4 MB gRPC limit), and a `ParentBased` sampler wrapping a `RouteTierSampler` for route-aware head sampling.
- **Metric pipeline** — Uses `otlpmetricgrpc` with a periodic reader. Includes six `sdkmetric.View` mappings that rename `otelsql` `db.sql.*` instrument names to the canonical OTel semconv `db.client.*` names expected by SigNoz.
- **Log pipeline** — Conditionally initialized when `cfg.Logging.OtelLogsEnabled` is `true`, using `otlploggrpc` with a batch processor.

## Usage Example

```go
sampler := tracing.NewRouteTierSampler(registry)
// register routes before calling initOTELProviders

logProvider, traceProvider, meterProvider, sampler := initOTELProviders(
    fleetCfg,
    traceRegistry,
    func(err error, msg string) { log.Fatalf("%s: %v", msg, err) },
)
if traceProvider != nil {
    defer traceProvider.Shutdown(ctx)
}
if meterProvider != nil {
    defer meterProvider.Shutdown(ctx)
}
if logProvider != nil {
    defer logProvider.Shutdown(ctx)
}
```

> **Note:** Route-to-tier mappings must be registered in `traceRegistry` before calling `initOTELProviders`. See [`server/service/tracing_tiers.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/service/tracing_tiers.go) for the canonical registration pattern.
