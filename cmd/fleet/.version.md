Defines the `version` CLI subcommand for the Fleet binary, printing version and build information.

## Key Components

- **`createVersionCmd(configManager config.Manager) *cobra.Command`** — Constructs and returns the `version` Cobra command with a `--full` flag for extended build metadata output.

### Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--full` | `bool` | `false` | Print full version and build info |

## Usage Example

```bash
# Print short version
fleetctl version

# Print full version with build metadata
fleetctl version --full
```

```go
// Registering the command in main
rootCmd.AddCommand(createVersionCmd(configManager))
```

## Notes

- Delegates output to `version.Print()` and `version.PrintFull()` from the [`server/version`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/version) package.
- `configManager` is accepted as a parameter for consistency with other command constructors but is not directly used in this command's logic.
