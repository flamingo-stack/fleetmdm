Implements a CLI subcommand that serializes the fully-merged Fleet server configuration to YAML and prints it to stdout.

## Key Components

- **`createConfigDumpCmd(configManager config.Manager) *cobra.Command`** — Constructs and returns the `config_dump` Cobra subcommand. Loads the active configuration via `configManager.LoadConfig()`, marshals it to YAML, and writes the result to stdout.

## Usage Example

```go
// Register the subcommand with the root Cobra command
rootCmd.AddCommand(createConfigDumpCmd(configManager))
```

```bash
# Run from the Fleet server binary to inspect the merged config
fleetctl config_dump

# Combine with CLI flags to preview their effect on the resolved config
fleetctl config_dump --mysql_address=127.0.0.1:3306
```

## Configuration Precedence

The dump reflects the final merged configuration, resolved in this order (highest to lowest priority):

1. CLI flags
2. Environment variables
3. Config file
4. Default values
