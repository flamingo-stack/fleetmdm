Initializes and configures Fleet's primary data layer, wiring together MySQL connections, the main datastore, and the carve file store (S3 or MySQL-backed).

## Key Components

| Symbol | Description |
|--------|-------------|
| `buildMySQLOpts` | Assembles `[]mysql.DBOption` from config: base logger, read replica, dev SQL interceptor, and OTEL tracing |
| `initDatastore` | Creates shared DB connections, the MySQL datastore, and the carve store; routes fatal errors through the caller-supplied `initFatal` callback |
| `evalMigrationStatus` | Inspects a `*fleet.MigrationStatus` and returns whether the server should abort startup based on migration state and runtime flags |

## Usage Example

```go
// Wire up the datastore during server startup
ds, dbConns, carveStore := initDatastore(cfg, logger, clock.C, func(err error, msg string) {
    logger.Error(msg, "err", err)
    os.Exit(1)
})

// Check migration health before serving traffic
status, err := ds.MigrationStatus(ctx)
if err != nil {
    log.Fatal(err)
}
if evalMigrationStatus(status, devMode, allowMissingMigrations) {
    os.Exit(1)
}
```

## Migration Status Behavior

| Status Code | Dev Mode | `--allow-missing-migrations` | Result |
|-------------|----------|------------------------------|--------|
| `AllMigrationsCompleted` | any | any | Boot proceeds |
| `UnknownMigrations` | `true` | — | Exit |
| `NeedsFleetv4732Fix` / `UnknownFleetv4732State` | any | `false` | Exit |
| `SomeMigrationsCompleted` | any | `false` | Exit |
| `NoMigrationsCompleted` | any | any | Always exit |

> **S3 Carve Store:** Activated when either `S3.CarvesBucket` or `S3.Bucket` is set in config; falls back to the MySQL datastore otherwise.
