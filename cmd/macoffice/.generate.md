Generates Mac Office release notes metadata in JSON format for use in Fleet's vulnerability detection pipeline.

## Key Components

- **`main()`** – Entry point that orchestrates the full generation workflow: creates the output directory, fetches release notes, and serializes them to disk.
- **`panicif(err error)`** – Minimal error helper that panics on non-nil errors.
- **`macoffice.GetReleaseNotes(false)`** – Fetches and parses Mac Office release notes from the upstream source (live fetch, not cached).
- **`relNotes.Serialize(time.Now(), outPath)`** – Writes the parsed release notes to JSON files under `macoffice_rel_notes/` in the current working directory.

## Usage Example

Run directly from the command line:

```bash
cd tools/vuln-processing  # or wherever generate.go lives
go run generate.go
```

Expected output:

```text
Downloading and parsing Mac Office rel notes...
Done.
```

Output is written to `./macoffice_rel_notes/` relative to the working directory.

## Notes

- The output directory (`macoffice_rel_notes/`) is created automatically if it does not exist (`0o755` permissions).
- Timestamps the serialized data with the current time via `time.Now()`.
- Any error at any stage causes an immediate panic — this is a one-shot CLI tool, not a long-running service.
