Entry point for the `fleetctl` CLI binary. It wires together the core application, registers the `goquery` subcommand, and defines error handling behavior.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | func | Bootstraps the CLI app, registers the goquery runner, and executes the command |
| `exitErrHandler` | func | `cli.ExitErrHandlerFunc` implementation — prints errors to stderr and exits with code 1, with OS-aware permission hints |

## Usage Example

```bash
# Build and run the fleetctl binary
go build -o fleetctl ./cmd/fleetctl
./fleetctl --help
```

```go
// exitErrHandler provides OS-specific guidance on permission errors
// darwin/linux:
//   "fix permissions on <config dir> or re-run with sudo"
// windows:
//   "fix permissions on <config dir> or re-run as administrator"
```

## Notes

- **goquery isolation**: `goquerycmd.Run` is registered here (not in the shared `fleetctl` package) to prevent the `github.com/AbGuthrie/goquery/v2` dependency and its `init()` from being linked into other binaries (e.g., the Fleet server) that import the `fleetctl` package.
- Raw args are stashed via `fleetctl.StashRawArgs` before `app.Run` for downstream inspection.
- Permission errors (`fs.ErrPermission`) produce platform-specific remediation hints covering macOS/Linux (`sudo`) and Windows (`Run as administrator`).
