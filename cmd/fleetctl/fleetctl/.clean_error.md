Strips the verbose HTTP prefix from `*client.StatusCodeErr` errors, returning a cleaner message suitable for CLI display.

## Key Components

- **`statusCodeErrPrefixRE`** — Compiled regex matching the `"VERB /path received status N "` prefix injected by `BaseClient.ParseResponse`.
- **`CleanStatusCodeErr(err error) error`** — Walks the error chain via `errors.As`; if a `*client.StatusCodeErr` is found, removes the first occurrence of the HTTP prefix from the full error message string.

## Usage Example

```go
raw := errors.New("POST /api/v1/fleet/hosts received status 403 Forbidden")
clean := fleetctl.CleanStatusCodeErr(raw)
fmt.Println(clean) // "Forbidden"
```

## Notes

- Returns `nil` if `err` is `nil`.
- Returns `err` unchanged if the chain contains no `*client.StatusCodeErr`.
- The returned error is a **new** `errors.New` value — the original chain is not preserved. Always run `errors.Is` / `errors.As` checks against the **original** error before calling this function.
