Registers and exposes the `goquery` subcommand for the `fleetctl` CLI, using a lazy-registration pattern to avoid linking the `goquery` dependency into binaries that don't need it.

## Key Components

- **`goqueryRunner`** — Package-level function variable holding the goquery implementation; `nil` by default until explicitly set.
- **`SetGoqueryRunner(runner func(*service.Client) error)`** — Registration hook called from `package main` to inject the goquery implementation before `CreateApp` runs.
- **`goqueryCommand() *cli.Command`** — Builds and returns the `fleetctl goquery` CLI command, which initializes a Fleet client and delegates to `goqueryRunner`.

## Usage Example

```go
// In package main (fleetctl binary only):
import (
    "github.com/fleetdm/fleet/v4/command/fleetctl"
    "github.com/AbGuthrie/goquery/v2"
)

func main() {
    fleetctl.SetGoqueryRunner(func(client *service.Client) error {
        return goquery.StartSession(client)
    })
    app := fleetctl.CreateApp()
    app.Run(os.Args)
}
```

If `SetGoqueryRunner` is never called (e.g., in the Fleet server binary that transitively imports `fleetctl`), invoking the subcommand returns:

```text
goquery support is not built into this binary
```

## Notes

- The pattern intentionally decouples the `github.com/AbGuthrie/goquery/v2` import from this package. Its `init()` function and dependencies are only linked into binaries that explicitly call `SetGoqueryRunner`.
- Supports standard `fleetctl` flags: `--config`, `--context`, `--yaml`, and `--debug`.
