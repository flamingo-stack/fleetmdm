Implements the `fleetctl report` (aliased as `query`) CLI command, which executes live osquery reports against targeted Fleet-managed hosts and streams results to stdout.

## Key Components

- **`queryCommand()`** — Returns a `*cli.Command` that registers the `report`/`query` subcommand with all its flags and action handler.

### Flags

| Flag | Description |
|------|-------------|
| `--hosts` | Comma-separated hostnames, UUIDs, or serial numbers |
| `--labels` | Comma-separated label names to target |
| `--query` | Inline SQL query string |
| `--report-name` / `--query-name` | Name of a saved report/query |
| `--exit` | Exit when 100% of online hosts have responded |
| `--quiet` | Suppress status/spinner output |
| `--pretty` | Pretty-print JSON results |
| `--timeout` | Max duration before auto-exit |
| `--fleet` / `--team` | Team ID scope for named reports |

### Action Flow

1. Validates that at least one of `--hosts` or `--labels` is provided.
2. Resolves a saved query by name via `client.GetQueries()` if `--report-name` is used.
3. Opens a live query stream via `client.LiveQuery()`.
4. Runs a `select` loop consuming three channels: `res.Results()`, `res.Errors()`, and a 100ms ticker for status updates, plus an optional timeout channel.

## Usage Example

```bash
# Run an inline query against specific hosts
fleetctl report --hosts web-01,web-02 --query "SELECT * FROM os_version;"

# Run a saved report against a label with pretty output and auto-exit
fleetctl report --labels "production" --report-name "disk-usage" --pretty --exit

# Run with a timeout against all hosts in a team
fleetctl report --labels "all-hosts" --query "SELECT * FROM processes;" \
  --timeout 30s --fleet 4
```
