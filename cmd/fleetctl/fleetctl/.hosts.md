Defines the `hosts` CLI command group for `fleetctl`, providing host management subcommands — currently `transfer` for moving hosts between fleets.

## Key Components

- **`hostsCommand()`** — Returns the top-level `hosts` CLI command with its subcommands registered
- **`transferCommand()`** — Returns the `transfer` subcommand that moves hosts to a specified fleet using one of several targeting strategies
- **Flag constants** — `hostsFlagName`, `labelFlagName`, `statusFlagName`, `searchQueryFlagName` define reusable flag identifiers

### Transfer Flags

| Flag | Description |
|---|---|
| `--fleet` / `--team` | Target fleet name (required; `''` = unassigned) |
| `--hosts` | Comma-separated hostnames |
| `--label` | Label name to filter hosts |
| `--status` | Status filter for hosts |
| `--search_query` | Search query to match hostnames |

## Validation Logic

The `transfer` action enforces mutual exclusivity:
- `--hosts` **cannot** be combined with `--label`, `--status`, or `--search_query`
- If `--hosts` is omitted, at least one of `--label`, `--status`, or `--search_query` is required

## Usage Example

```bash
# Transfer specific hosts by hostname
fleetctl hosts transfer --fleet "Production" --hosts "host1.example.com,host2.example.com"

# Transfer hosts matching a label
fleetctl hosts transfer --fleet "Staging" --label "macOS"

# Transfer hosts by status and search query
fleetctl hosts transfer --fleet "" --status "online" --search_query "web-server"
```
