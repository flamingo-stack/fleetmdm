Provides shared test utilities for Fleet MDM GitOps integration tests, including server setup helpers, mock data stores, and test infrastructure for premium and MDM-enabled Fleet server scenarios.

## Key Components

- **`RunServerWithMockedDS`** — Spins up a Fleet HTTP test server backed by a `mock.Store` with pre-wired DS method stubs (users, sessions, MDM assets, labels, policies, scripts, etc.). Returns the `httptest.Server` and the mock datastore for further customization.
- **`SetupFullGitOpsPremiumServer`** — Higher-level helper that configures a premium-licensed Fleet server with Apple MDM (SCEP), Android MDM, and VPP support, returning the mock store, app config pointer, and a team map for GitOps tests.
- **`ServeMDMBootstrapPackage`** — Starts a temporary HTTP server that serves a raw binary package file with correct headers for MDM bootstrap package testing.
- **`StartSoftwareInstallerServer`** — Starts an HTTP server routing requests to local software installer test fixtures, supporting edge cases like 404, oversized packages (>513 MiB), and `.pkg`/`.deb` files.
- **`getPathRelative`** — Resolves a path relative to the source file's directory using `runtime.Caller`, enabling test fixtures to be located independently of working directory.
- **`AddLabelMocks`** — (referenced) Wires label-related datastore mock functions into a `mock.Store`.

## Usage Example

```go
func TestMyGitOpsFeature(t *testing.T) {
    // Basic server with mocked datastore
    server, ds := RunServerWithMockedDS(t)

    // Override a specific mock as needed
    ds.AppConfigFunc = func(ctx context.Context) (*fleet.AppConfig, error) {
        return &fleet.AppConfig{OrgInfo: fleet.OrgInfo{OrgName: "My Org"}}, nil
    }

    // Full premium + MDM server for GitOps tests
    ds2, appCfg, teams := SetupFullGitOpsPremiumServer(t)
    _ = ds2
    _ = appCfg
    _ = teams
}
```
