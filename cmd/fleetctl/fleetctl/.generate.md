Implements the `fleetctl generate` CLI command, which generates certificates and cryptographic keys required to enable Apple MDM features in Fleet.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `generateCommand` | `func` | Root CLI command factory; registers `mdm-apple`, `mdm-ab`, and `mdm-apple-bm` subcommands |
| `generateMDMAppleCommand` | `func` | Subcommand that requests an APNs CSR from the Fleet server and writes it to disk |
| `generateMDMABCommand` | `func` | Subcommand that generates an Apple Business (AB) public key certificate for automatic macOS enrollment |
| `generateMDMAppleBMCommand` | `func` | Deprecated alias for `mdm-ab`; emits a deprecation warning when the `DeprecatedFieldTopic` log topic is enabled |
| `generateMDMABFlags` | `func` | Shared flag definitions (`--public-key`) for `mdm-ab` and `mdm-apple-bm` |
| `runGenerateMDMAB` | `func` | Shared action handler for both AB subcommands; fetches the public key and writes it to the configured path |
| `apnsCSRPath` | `const` | Default output filename for the APNs CSR (`fleet-mdm-csr.csr`) |
| `bmPublicKeyCertPath` | `const` | Default output filename for the AB public key (`fleet-apple-mdm-bm-public-key.crt`) |

## Usage Example

```bash
# Generate an APNs CSR using the default output path
fleetctl generate mdm-apple

# Generate an APNs CSR to a custom path
fleetctl generate mdm-apple --csr /tmp/my-csr.csr

# Generate an Apple Business (AB) public key
fleetctl generate mdm-ab

# Generate AB public key to a custom path
fleetctl generate mdm-ab --public-key /tmp/ab-public-key.crt

# Deprecated: same as mdm-ab (emits a deprecation warning)
fleetctl generate mdm-apple-bm
```

On success, each subcommand prints a follow-up URL pointing to the relevant Fleet settings page (e.g., `/settings/integrations/mdm/apple`) where the generated file should be uploaded to complete MDM enrollment setup.

## Notes

- Both file-writing operations use `defaultFileMode` for consistent permissions across generated artifacts.
- The `mdm-apple-bm` deprecation warning is gated behind `logging.DeprecatedFieldTopic`, allowing operators to suppress it via log configuration.
