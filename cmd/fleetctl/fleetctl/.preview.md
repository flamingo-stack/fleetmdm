Orchestrates the `fleetctl preview` command, providing a one-command sandbox deployment of Fleet server using Docker Compose. It handles dependency downloads, Docker container lifecycle, MDM certificate generation, host enrollment, and browser launch.

## Key Components

- **`previewCommand()`** — CLI entry point that downloads Fleet config, starts Docker containers (MySQL, Redis, Fleet), initializes the server, configures fleetctl context, and enrolls simulated hosts via Orbit
- **`dockerCompose`** — Abstraction over both `docker-compose` (V1) and `docker compose` (V2) CLI variants, auto-detected via `newDockerCompose()`
- **`ensureWSTEPCerts()`** — Generates or reuses a self-signed RSA certificate/key pair for Windows MDM (WSTEP) enrollment
- **`previewStopCommand()` / `previewResetCommand()`** — Subcommands to tear down or fully reset the sandbox environment
- **`waitStartup()`** — Polls the Fleet HTTPS endpoint with exponential backoff until the server is healthy
- **`downloadFromFleetRepo()`** — Fetches preview configuration files from the `fleetdm/fleet` GitHub repository (default: `main` branch, `tools/osquery/in-a-box/`)
- **`getPrivateKey()`** — Persists a randomly generated AES-256 private key to disk for MDM asset encryption across restarts

## Usage Example

```bash
# Start a Fleet sandbox (downloads latest config, spins up Docker containers)
fleetctl preview

# Use a specific Fleet version with a license key
fleetctl preview --tag v4.50.0 --license-key <YOUR_KEY>

# Start without enrolling simulated hosts
fleetctl preview --no-hosts

# Use a local config directory (development/testing)
fleetctl preview --preview-config-path ./tools/osquery/in-a-box

# Stop the running sandbox
fleetctl preview stop

# Reset the sandbox (removes all data)
fleetctl preview reset
```

After startup, the Fleet UI is available at `https://localhost:8412` with credentials `admin@example.com` / `preview1337#`. The fleetctl config is written to the `preview` context automatically.
