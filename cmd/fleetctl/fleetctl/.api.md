Provides HTTP client construction, authentication handling, and the `fleetctl api` CLI command for making authenticated requests to the Fleet API.

## Key Components

- **`unauthenticatedClientFromCLI`** — Builds an unauthenticated `service.Client` from CLI flags
- **`clientFromCLI`** — Builds an authenticated `service.Client`, validates the token, checks version compatibility, and warns on expired Apple BM terms
- **`unauthenticatedClientFromConfig`** — Constructs a `service.Client` from a `Context` config struct with optional TLS and debug settings
- **`rawHTTPClientFromConfig`** — Returns a raw `*http.Client` and parsed base URL with optional root CA, bypassing Fleet-specific TLS defaults
- **`clientConfigFromCLI`** — Reads and returns the `Context` config from the fleetctl config file for the active context
- **`apiCommand`** — CLI command (`fleetctl api`) for making raw authenticated API requests with support for custom methods, headers, and body fields
- **`parseBodyFlags`** — Parses `-F key=value` flags into either a JSON body or a multipart form body (with file upload support via `@file` and `<file` prefixes)
- **`printAuthError`** — Detects SSO configuration and prints context-appropriate authentication error guidance

## Usage Example

```bash
# GET request with query parameters
fleetctl api /hosts -F status=online

# POST with a JSON body field
fleetctl api -X POST /labels -F name=MyLabel -F query="SELECT 1"

# POST with a file upload
fleetctl api -X POST /software/packages -F package=@/tmp/app.pkg

# Use a file's contents as a field value
fleetctl api -X POST /scripts -F script_contents=</tmp/script.sh

# Add custom headers
fleetctl api -H "X-Custom-Header:value" /hosts
```

```go
// Programmatic client construction
cc := Context{Address: "https://fleet.example.com", TLSSkipVerify: false}
client, err := unauthenticatedClientFromConfig(cc, false, os.Stdout, os.Stderr)
```
