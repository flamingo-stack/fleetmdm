This file implements the `fleetctl get` command, providing CLI output formatters and data-retrieval helpers for Fleet resources (labels, hosts, queries, packs, teams, configs, and more) in YAML, JSON, or tabular formats.

## Key Components

### Output Formatters
- `printYaml` / `printSpec` — serialize a `specGeneric` envelope to YAML or JSON and write to stdout
- `defaultTable` / `borderlessTabularTable` — construct `tablewriter` instances for human-readable tabular output
- `printLabel`, `printHost`, `printHostDetail`, `printPack`, `printSecret`, `printQuerySpec`, `printConfig`, `printUserRoles`, `printTeams` — per-resource wrappers that wrap payloads in a `specGeneric` and delegate to `printSpec`

### Data Structures
- `specGeneric` — generic YAML/JSON envelope with `kind`, `apiVersion`, and `spec` fields
- `enrichedAppConfigPresenter` — custom `MarshalJSON` that merges human-readable duration strings for `UpdateInterval` and `Vulnerabilities` into the serialized app config
- `UserRoles` / `UserRole` / `TeamRole` — projection types used when exporting user-role specs

### Team Software Helpers
- `getTeamSoftwareSpec` — builds a `fleet.SoftwareSpec` for a team by querying software titles and setup-experience endpoints, resolving Fleet-Maintained App slugs, and de-duplicating in-house iOS apps
- `scopeLabelNames` — extracts bare label name strings from label-scope structs
- `setupExperienceValue` — returns an `optjson.Bool` indicating whether a title is part of the setup experience
- `isDuplicateInHouseApp` — prevents emitting the same in-house `.ipa` more than once
- `stripMismatchedLabelFields` — clears irrelevant fields from a `LabelSpec` before export so re-apply is idempotent

### CLI Flags
- `yamlFlag`, `jsonFlag`, `removeDeprecatedKeysFlag` — reusable `cli.Flag` definitions

## Usage Example

```go
// Print a label spec as YAML via the CLI context
label := &fleet.LabelSpec{Name: "production", Query: "SELECT 1"}
if err := printLabel(c, label); err != nil {
    return err
}

// Build the software spec for a team before printing
spec, err := getTeamSoftwareSpec(client, teamID)
if err != nil {
    return err
}
```
