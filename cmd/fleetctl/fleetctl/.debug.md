Provides CLI debug subcommands for the `fleetctl` tool, enabling capture of pprof profiles, runtime diagnostics, connection checks, and database debug data from a running Fleet server.

## Key Components

| Function | Description |
|---|---|
| `debugCommand()` | Root `debug` CLI command, aggregates all subcommands |
| `debugProfileCommand()` | Captures a 30-second CPU pprof profile |
| `debugHeapCommand()` | Captures heap allocation profile |
| `debugGoroutineCommand()` | Captures goroutine stack traces |
| `debugTraceCommand()` | Captures a 1-second execution trace |
| `debugCmdlineCommand()` | Retrieves the Fleet server's invocation command line |
| `debugArchiveCommand()` | Bundles all debug profiles into a `.tar.gz` archive |
| `debugConnectionCommand()` | Diagnoses Fleet server connection failures |
| `writeFile()` | Writes byte output to a named file with a confirmation message |
| `outfileNameWithExt()` | Generates timestamped output filenames |
| `joinCmdline()` | Formats null-delimited cmdline strings for display |

## Usage Example

```bash
# Capture a CPU profile
fleetctl debug profile

# Capture a heap profile to a specific file
fleetctl debug heap --outfile heap.prof

# Get the Fleet server command line
fleetctl debug cmdline

# Bundle all debug data into an archive
fleetctl debug archive --outfile fleet-debug.tar.gz

# Diagnose a connection issue to a specific address
fleetctl debug connection https://fleet.example.com

# Diagnose using a custom TLS certificate
fleetctl debug connection https://fleet.example.com --fleet-certificate /path/to/cert.pem
```

Profile output files (`.prof`) are compatible with `go tool pprof`; trace output is compatible with `go tool trace`.

> ⚠️ Archive files may contain sensitive data. Review contents before sharing.
