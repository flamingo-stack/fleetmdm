Provides Unix/Linux/macOS process termination using `SIGKILL` for the `fleetctl` package. This file is excluded from Windows builds via build constraints.

## Key Components

- **`killPID(pid int) error`** — Sends `SIGKILL` to the specified process ID using `syscall.Kill`. Returns any error encountered during the kill attempt.

## Usage Example

```go
err := killPID(12345)
if err != nil {
    log.Fatalf("failed to kill process: %v", err)
}
```

## Notes

- Applies only to non-Windows platforms (`//go:build !windows`)
- A Windows-specific counterpart is expected to implement the same `killPID` signature using Windows APIs
- `SIGKILL` is non-catchable and immediately terminates the target process
