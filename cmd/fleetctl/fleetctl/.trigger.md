Implements the `fleetctl trigger` CLI command, which triggers an ad hoc run of all jobs within a named cron schedule on the Fleet server.

## Key Components

- **`triggerCommand()`** — Builds and returns the `*cli.Command` for the `trigger` subcommand. Accepts a `--name` flag (or `NAME` env var) identifying the cron schedule to trigger. On success, prints a confirmation message; on `NotFoundErr` or `ConflictErr`, prints a formatted user-friendly error without returning a non-zero exit code.
- **`formatTriggerErrMsg(name, msg string) string`** — Normalizes error messages: when no `--name` is provided, rewrites `"invalid name"` to `"name must be specified"`, and ensures the first character of the message is uppercased.

## Usage Example

```bash
# Trigger a cron schedule by name
fleetctl trigger --name vulnerabilities

# Using an environment variable
NAME=automations fleetctl trigger
```

```go
// Programmatic equivalent via the Fleet client
client, _ := service.NewClient(addr, true, "", "")
err := client.TriggerCronSchedule("vulnerabilities")
```

**Flags:**

| Flag | Env Var | Description |
|------|---------|-------------|
| `--name` | `NAME` | Name of the cron schedule to trigger |
| `--config` | — | Path to Fleet config file |
| `--context` | — | Fleet config context to use |
| `--debug` | — | Enable debug output |
