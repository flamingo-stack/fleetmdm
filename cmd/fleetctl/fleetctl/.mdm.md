Provides CLI subcommands for executing MDM (Mobile Device Management) actions against enrolled hosts via the `fleetctl` command-line tool.

## Key Components

| Function | Description |
|----------|-------------|
| `mdmCommand()` | Root `mdm` command registering all subcommands |
| `mdmRunCommand()` | Runs a custom XML MDM command on macOS/Windows hosts |
| `mdmLockCommand()` | Locks a host remotely (macOS, Windows, Android) |
| `mdmUnlockCommand()` | Unlocks a host; returns a 6-digit PIN for macOS |
| `mdmWipeCommand()` | Wipes all content from a host |
| `mdmClearPasscodeCommand()` | Clears the passcode on iOS, iPadOS, or Android hosts |
| `hostMdmActionSetup()` | Shared helper that validates the host, builds the client, and checks MDM enrollment before any action |

## Usage Example

```bash
# Run a custom MDM command against multiple hosts
fleetctl mdm run-command \
  --hosts=hostname1,serial-number-2 \
  --payload=./command.xml

# Lock a host
fleetctl mdm lock --host=my-macbook-serial

# Unlock a host (returns PIN for macOS)
fleetctl mdm unlock --host=my-macbook-serial

# Wipe a host
fleetctl mdm wipe --host=my-macbook-serial

# Clear passcode (iOS/iPadOS/Android)
fleetctl mdm clear-passcode --host=my-ipad-serial
```

## Notes

- All commands accept hosts specified by **hostname, UUID, or serial number**.
- `run-command` validates that all targeted hosts share the same platform (macOS or Windows) before dispatching.
- `hostMdmActionSetup()` is a shared pre-flight helper used by `lock`, `unlock`, `wipe`, and `clear-passcode` — it checks MDM connectivity and permission before the action is attempted.
- Android lock uses the device PIN for user-side unlock; no Fleet unlock command is issued.
- `clear-passcode` does not update `host_mdm_actions`; completion is surfaced only via the `cleared_passcode` activity log.
