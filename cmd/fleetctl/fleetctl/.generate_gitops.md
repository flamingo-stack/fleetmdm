Generates GitOps configuration files from a live Fleet instance by querying the Fleet API and serializing the results into YAML files suitable for use with Fleet's GitOps workflow.

## Key Components

- **`generateGitopsCommand()`** — Registers the `fleetctl generate-gitops` CLI command with flags for `--dir`, `--key`, `--print`, `--force`, `--insecure`, and `--fleet`
- **`GenerateGitopsCommand`** — Main struct holding the CLI context, API client, messages, file output map, software/script lists, and app config
- **`generateGitopsClient`** — Interface abstracting all Fleet API calls needed for config export (teams, scripts, profiles, policies, queries, software, labels, etc.)
- **`createGenerateGitopsAction()`** — Factory function that wires a `generateGitopsClient` into the CLI action, allowing injection of a test client
- **`Run()`** — Orchestrates validation (auth, directory checks) and triggers the full config export pipeline
- **`yamlMarshalRenamed()`** — JSON-marshals a struct, applies `renameto` alias rules from `spec.DeprecatedGitOpsKeyMappings`, then YAML-marshals the result to ensure deprecated keys are replaced with their canonical names in output
- **`replaceAliasKeys()`** — Recursively walks a `map[string]any` tree renaming deprecated JSON keys to their current canonical equivalents
- **`jsonFieldName()`** — Reflects on a struct type to resolve the correct output key name, preferring `renameto` tags over `json` tags
- **`getValueAtKey()`** — Traverses a dot-separated key path into a nested map

## Usage Example

```bash
# Export all Fleet configuration to a directory
fleetctl generate-gitops --dir ./gitops-output

# Export a specific team's configuration
fleetctl generate-gitops --dir ./gitops-output --fleet "My Team"

# Print global config to stdout
fleetctl generate-gitops --dir . --fleet global --print

# Output a specific config value
fleetctl generate-gitops --key "org_settings.org_name"

# Overwrite an existing output directory
fleetctl generate-gitops --dir ./gitops-output --force
```
