Provides CLI subcommands for managing Fleet users, including single and bulk create/delete operations via `fleetctl`.

## Key Components

| Function | Description |
|----------|-------------|
| `userCommand()` | Root `user` CLI command with four subcommands |
| `createUserCommand()` | Creates a single user with optional SSO, MFA, API-only, and role/team assignment |
| `createBulkUsersCommand()` | Bulk-creates users from a CSV file with auto-generated passwords |
| `deleteUserCommand()` | Deletes a single user by email |
| `deleteBulkUsersCommand()` | Bulk-deletes users from a CSV file of emails |
| `generateRandomPassword()` | Generates a 20-character random password (2 digits, 2 symbols) |

## Usage Example

**Create a single user:**

```bash
fleetctl user create \
  --email admin@example.com \
  --name "Jane Doe" \
  --global-role admin
```

**Create an API-only user with team assignment:**

```bash
fleetctl user create \
  --name "CI Bot" \
  --api-only \
  --team 1:maintainer
```

**Bulk-create users from CSV:**

```bash
fleetctl user create-users --csv users.csv
```

CSV format (`Name,Email,SSO,API Only,Global Role,Teams`):

```text
Name,Email,SSO,API Only,Global Role,Teams
Alice,alice@example.com,false,false,observer,
Bob,bob@example.com,true,false,,2:maintainer
```

**Delete a single user:**

```bash
fleetctl user delete --email alice@example.com
```

**Bulk-delete users from CSV:**

```bash
fleetctl user delete-users --csv to_delete.csv
```

## Notes

- Role validation enforces mutual exclusivity: a user cannot have both a `global-role` and team assignments.
- SSO users cannot have passwords or MFA set.
- API-only users cannot use MFA.
- Non-SSO, non-API-only users are flagged for a forced password reset on first login.
