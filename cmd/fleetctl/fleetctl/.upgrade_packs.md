Provides the `upgrade-packs` CLI command for converting legacy Fleet 2017 "Packs" into portable scheduled queries compatible with the current Fleet query format.

## Key Components

- **`upgradePacksCommand()`** — Registers the `fleetctl upgrade-packs` CLI command. Validates admin role, fetches existing packs and queries, converts them, and writes the output YAML file.
- **`writeQuerySpecsToFile(filename, specs)`** — Serializes a slice of `fleet.QuerySpec` objects to a YAML file using `---` document separators.
- **`mapQueriesToPacks(packs, queries)`** — Builds a lookup map associating each `PackSpec` with its referenced `Query` objects by name.
- **`upgradePackToQueriesSpecs(packSpec, packDB, packQueries, ts)`** — Core conversion logic. For team-targeted packs, duplicates each query per team with scheduling enabled. For label- or host-targeted packs, emits a global query with scheduling disabled.
- **`testUpgradePacksTimestamp`** — Package-level variable allowing tests to inject a deterministic timestamp into generated query names.

## Usage Example

```bash
# Convert all 2017 Packs and write output to queries.yml
fleetctl upgrade-packs -o queries.yml

# Apply the converted queries to Fleet
fleetctl apply -f queries.yml
```

```go
// Internal conversion (used by tests)
var testUpgradePacksTimestamp = time.Date(2024, 1, 15, 10, 0, 0, 0, time.UTC)

specs, count := upgradePackToQueriesSpecs(packSpec, packDB, queries, testUpgradePacksTimestamp)
// specs → []*fleet.QuerySpec ready for YAML serialization
// count → number of pack queries successfully converted
```

After applying the converted queries, visit `/packs/manage` in the Fleet UI to disable the original 2017 Packs and avoid duplicate query execution.
