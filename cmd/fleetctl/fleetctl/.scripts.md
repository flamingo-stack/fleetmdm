Provides the `run-script` CLI command for executing scripts on remote Fleet-managed hosts, handling both synchronous and asynchronous execution modes with result rendering.

## Key Components

- **`runScriptCommand()`** — Builds the `fleetctl run-script` CLI command with flags for `--script-path`, `--host`, `--script-name`, `--fleet`, `--async`, and `--quiet`. Validates mutual exclusivity of script source options, resolves the target host, and dispatches sync or async execution.
- **`renderScriptResult()`** — Renders a `fleet.HostScriptResult` to stdout using an HTML template, displaying exit code, status message, and script output. Handles special exit codes (`-1` for timeout, `-2` for suppressed output, `nil` for error state) and truncation warnings at 10,000 characters.
- **`validateScriptPath()`** — Validates that a script file has an accepted extension (`.sh`, `.ps1`, or `.py`).
- **`boolToInt()`** — Helper that converts a boolean to `1`/`0`, used to count how many mutually exclusive script source flags are set.

## Usage Example

```bash
# Run a local shell script synchronously on a host
fleetctl run-script --script-path ./setup.sh --host my-hostname

# Run a saved Fleet script by name on a specific team
fleetctl run-script --script-name "patch-agent" --host abc-123-uuid --fleet 4

# Run an inline script via stdin-style args
fleetctl run-script --host my-host -- echo hello world

# Queue a script without waiting for output
fleetctl run-script --script-path ./audit.sh --host my-host --async

# Suppress status messages; print only raw script output
fleetctl run-script --script-path ./check.sh --host my-host --quiet
```

```go
// renderScriptResult is called internally after sync execution:
err := renderScriptResult(c, res)
// Outputs: Exit code: 0 (Script ran successfully.) + stdout content
```

## Notes

- Exactly one of `--script-path`, `--script-name`, or inline `-- <args>` must be provided; passing more than one returns an error.
- Sync mode displays a spinner while waiting and calls `client.RunHostScriptSync`; async mode prints the `ExecutionID` and returns immediately.
- The target host must be online (`fleet.StatusOnline`) before script execution is attempted.
