Defines the `fleetctl package` CLI command, which builds fully bootstrapped fleetd installer packages for Windows, macOS, and Linux targets.

## Key Components

- **`packageCommand()`** — Returns a `*cli.Command` that wires up the `package` subcommand with all its flags and action handler.
- **`opt` (`packaging.Options`)** — Package-level variable that collects all flag destinations and is passed to the packaging backend.
- **`disableOpenFolder`** — Package-level flag controlling whether the output folder is auto-opened after a successful build.

## Supported Flags (selected)

| Flag | Purpose |
|---|---|
| `--type` | Package format (`pkg`, `msi`, `deb`, `rpm`, `pkg.tar.zst`) |
| `--enroll-secret` / `--fleet-url` | Fleet enrollment credentials (must be paired) |
| `--fleet-certificate` | Custom TLS CA chain for the Fleet server |
| `--fleet-tls-client-certificate` / `--fleet-tls-client-key` | mTLS to Fleet (EE) |
| `--insecure` | Skip TLS verification (mutually exclusive with cert flags) |
| `--orbit-channel` / `--osqueryd-channel` / `--desktop-channel` | Update channels |
| `--disable-updates` | Bake in static binaries, no auto-update |
| `--notarize` / `--sign-identity` | macOS codesign & notarization |
| `--fleet-managed-host-identity-certificate` | TPM-backed host identity (EE, Linux only) |
| `--host-identifier` | `uuid` or `instance` enrollment identifier |

## Usage Example

```bash
fleetctl package \
  --type=deb \
  --fleet-url=https://fleet.example.com \
  --enroll-secret=s3cr3t \
  --fleet-certificate=/path/to/ca.pem \
  --orbit-channel=stable \
  --fleet-desktop \
  --enable-scripts
```

## Validation Logic

The action handler enforces several mutual-exclusion rules before delegating to the packaging backend:

- `--enroll-secret` and `--fleet-url` must be supplied together.
- `--insecure` cannot be combined with `--fleet-certificate` or `--update-tls-certificate`.
- `--fleet-tls-client-certificate` and `--fleet-tls-client-key` must both be present or both absent; the key pair is validated with `tls.LoadX509KeyPair`.
- `--fleet-managed-host-identity-certificate` is restricted to `deb`/`rpm`/`pkg.tar.zst` targets and cannot be combined with `--fleet-tls-client-certificate`.
- `--host-identifier` accepts only `uuid` or `instance`.
