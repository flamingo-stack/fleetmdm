Defines and manages CLI flag constants, constructors, and deprecation-warning helpers for the `fleetctl` command-line tool.

## Key Components

### Flag Constants
Named string constants for all standard CLI flag names (e.g., `debugFlagName`, `outfileFlagName`, `passwordFlagName`).

### Flag Constructors & Getters
Paired functions for each flag:
- `outfileFlag()` / `getOutfile()` — output file path, env: `OUTFILE`
- `debugFlag()` / `getDebug()` — HTTP debug logging, env: `DEBUG`
- `fleetCertificateFlag()` / `getFleetCertificate()` — TLS cert path, env: `FLEET_CERTIFICATE`
- `stdoutFlag()` / `getStdout()` — print to stdout, env: `STDOUT`
- `enableLogTopicsFlag()` / `getEnabledLogTopics()` — comma-separated topics to enable, env: `FLEET_ENABLE_LOG_TOPICS`
- `disableLogTopicsFlag()` / `getDisabledLogTopics()` — comma-separated topics to disable, env: `FLEET_DISABLE_LOG_TOPICS`

### Log Topic Helpers
- `withLogTopicFlags()` — injects enable/disable log topic flags into a slice of subcommands and wraps their `Before` hooks
- `applyLogTopicFlags()` — applies parsed topic flags; enables run before disables so disable wins on conflict

### Deprecation Warnings
- `logDeprecatedCommandName()` — warns when a deprecated command alias is used
- `logDeprecatedFlagName()` — warns on deprecated flag names (`--name`, `-name`, `--name=value`)
- `logDeprecatedEnvVar()` — warns when a deprecated environment variable is set

### Raw Args Helpers
- `StashRawArgs()` — saves original `os.Args` into `app.Metadata` before `app.Run`
- `rawArgs()` — retrieves stashed args, falling back to `os.Args[1:]`

### MDM Filter Flags
- `byHostIdentifier()`, `byMDMCommandRequestType()`, `withMDMCommandStatusFilter()` — filter flags for MDM command queries

## Usage Example

```go
app := &cli.App{
    Commands: withLogTopicFlags([]*cli.Command{
        {
            Name:  "query",
            Flags: []cli.Flag{outfileFlag(), debugFlag()},
            Action: func(c *cli.Context) error {
                logDeprecatedFlagName(c, "output", "outfile")
                out := getOutfile(c)
                // use out...
                return nil
            },
        },
    }),
}

StashRawArgs(app, os.Args)
app.Run(os.Args)
```
