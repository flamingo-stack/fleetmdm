Implements the `fleetctl delete` CLI command, enabling declarative batch deletion of osquery configurations (queries, packs, and labels) from a spec file.

## Key Components

- **`deleteCommand()`** — Returns a `*cli.Command` that registers the `delete` subcommand with fleetctl.
- **`-f` flag** — Required path to a YAML/JSON spec file; also readable via the `FILENAME` environment variable.
- **`spec.GroupFromBytes()`** — Parses the spec file into typed groups (queries, packs, labels).
- **`fleet.DeleteQuery / DeletePack / DeleteLabel`** — API client calls that perform the actual deletions; `service.NotFoundErr` is handled gracefully with a warning instead of a fatal error.

## Usage Example

```bash
# Delete all resources defined in a spec file
fleetctl delete -f ./osquery-configs.yml

# Using environment variable for filename
FILENAME=./osquery-configs.yml fleetctl delete
```

```go
// Registration in the fleetctl CLI
app.Commands = append(app.Commands, deleteCommand())
```

**Sample spec file (`osquery-configs.yml`):**

```yaml
apiVersion: v1
kind: query
spec:
  name: my-query
---
apiVersion: v1
kind: pack
spec:
  name: my-pack
```

Each resource is deleted individually. If a resource is not found, the command logs a warning (`[!] ... doesn't exist`) and continues rather than aborting the entire batch.
