Registers the `fleetctl apply` CLI command, which applies Fleet spec files (YAML) for one-off imports and backwards-compatible GitOps operations.

## Key Components

- **`applyCommand()`** — Returns a `*cli.Command` configured with flags, validation, and the apply action
- **Flags** — `-f` (file path), `--force`, `--dry-run`, `--policies-fleet` (team name override for policy specs)
- **Action** — Reads a `.yml`/`.yaml` file, parses it into spec groups via `spec.GroupFromBytes`, then calls `fleetClient.ApplyGroup`

## Usage Example

```bash
# Apply a spec file
fleetctl apply -f fleet-config.yml

# Dry-run validation only
fleetctl apply -f policies.yaml --dry-run

# Force apply ignoring validation errors
fleetctl apply -f config.yml --force

# Import policies into a specific fleet/team
fleetctl apply -f policies.yaml --policies-fleet "Engineering"
```

## Notes

- Only `.yml` and `.yaml` files are accepted; other extensions return an error
- `--force` and `--dry-run` are only supported for `config` and `fleet` spec types
- `--policies-fleet` (aliased as `--policies-team`, now deprecated) overrides the `fleet` key in a policies spec file
- The `baseDir` of the input file is passed to `ApplyGroup` to resolve relative paths in the spec
