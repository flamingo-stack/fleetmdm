Converts osquery pack JSON files into Fleet YAML report specifications, handling platform normalization and query metadata transformation.

## Key Components

- **`platformMapping`** — Maps osquery platform category strings (e.g., `"posix"`, `"linwin"`) to their canonical OS targets (`darwin`, `linux`, `windows`), based on the [osquery codegen reference](https://github.com/osquery/osquery/blob/b87a4b5f1567415a72acd5ecd0e9e7ab75754959/tools/codegen/genwebsitejson.py#L38).

- **`convertPlatforms(platformsIn string)`** — Parses a comma-separated platform string, maps each token via `platformMapping`, deduplicates, sorts, and returns a normalized platform string.

- **`specGroupFromPack(name string, inputPack fleet.PermissivePackContent)`** — Transforms a parsed osquery pack into a `spec.Group` containing `fleet.QuerySpec` entries. Handles polymorphic interval types (`string`, `uint`, `float64`) and nil-safe platform/version fields.

- **`convertCommand()`** — Defines the `fleetctl convert` CLI command. Reads an osquery pack JSON file, strips invalid literal newlines, converts to Fleet YAML report specs, and writes to stdout or an output file.

## Usage Example

```bash
# Convert an osquery pack JSON to Fleet YAML (stdout)
fleetctl convert -f my-pack.json

# Write converted output to a file
fleetctl convert -f my-pack.json -o my-reports.yaml
```

```go
// Programmatic platform conversion
result, err := convertPlatforms("posix,windows")
// result: "darwin,linux,windows"

// Convert a pack to spec group
specs, err := specGroupFromPack("my-pack", packContent)
for _, q := range specs.Queries {
    fmt.Println(q.Name, q.Platform)
}
```
