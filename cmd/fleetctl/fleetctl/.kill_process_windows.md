Provides a Windows-specific implementation of process termination using the `taskkill` system command.

## Key Components

- **`killPID(pid int) error`** — Terminates a process and all its child processes on Windows by invoking `taskkill /T /F /PID <pid>`. The `/T` flag kills the entire process tree; `/F` forces termination.

## Usage Example

```go
// Terminate a process and its children by PID
err := killPID(12345)
if err != nil {
    log.Fatalf("failed to kill process: %v", err)
}
```

## Notes

- Build-constrained to `windows` only; a corresponding implementation exists for other platforms.
- Uses `strconv.Itoa` to safely convert the integer PID to a string argument.
- The `//nolint:gosec` directive suppresses the `G204` linter warning for subprocess execution with a variable argument, which is intentional here.
