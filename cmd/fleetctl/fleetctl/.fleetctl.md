CLI application factory and runner for the `fleetctl` command-line tool. It wires together all subcommands, configures I/O streams, and exposes a test-friendly runner.

## Key Components

| Export | Description |
|--------|-------------|
| `CreateApp` | Builds and returns a fully configured `*cli.App` with all registered subcommands, version info, and custom I/O |
| `RunApp` | Convenience wrapper that creates the app, captures stdout to a `*bytes.Buffer`, and runs it — primarily used in tests |
| `defaultFileMode` | Package-level constant (`0o600`) for restrictive file permissions used when writing files |

### Registered Commands

`api`, `apply`, `delete`, `setup`, `login`, `logout`, `query`, `get`, `config` (set/get), `convert`, `goquery`, `user`, `debug`, `preview`, `updates`, `hosts`, `vulnerability-data-stream`, `package`, `generate`, `prepare`*, `trigger`, `mdm`, `upgrade-packs`, `run-script`, `gitops`, `generate-gitops`, `new`

> \* `prepare` intentionally returns an error directing users to the Fleet server binary.

## Usage Example

```go
// Production entrypoint — streams wired to real stdin/stdout/stderr
app := fleetctl.CreateApp(os.Stdin, os.Stdout, os.Stderr, func(c *cli.Context, err error) {
    if err != nil {
        os.Exit(1)
    }
})
if err := app.Run(os.Args); err != nil {
    log.Fatal(err)
}

// Test usage — capture output without touching real I/O
output, err := fleetctl.RunApp([]string{"get", "hosts", "--json"})
if err != nil {
    t.Fatal(err)
}
fmt.Println(output.String())
```
