Provides in-process test helpers for driving the `fleetctl` CLI app, capturing stdout/stderr and asserting on command results without spawning a subprocess.

## Key Components

| Function | Description |
|---|---|
| `RunAppForTest` | Runs the CLI with given args, asserts no error, returns captured stdout |
| `RunAppCheckErr` | Runs the CLI with given args, asserts an error containing a specific message, returns captured stdout |
| `RunWithErrWriter` | Runs the CLI with a custom `io.Writer` for stderr, returns stdout buffer and error |
| `RunAppNoChecks` | Thin alias over `fleetctl.RunApp`; returns stdout buffer and error without any assertions |
| `noopExitErrHandler` | Internal no-op exit-error handler passed to `fleetctl.CreateApp` to suppress `os.Exit` calls during tests |

## Usage Example

```go
func TestGetHosts(t *testing.T) {
    // Assert command succeeds and inspect output
    output := fleetctltest.RunAppForTest(t, []string{"get", "hosts"})
    require.Contains(t, output, "hostname")

    // Assert command fails with a specific error message
    fleetctltest.RunAppCheckErr(t, []string{"get", "hosts", "--invalid-flag"}, "flag provided but not defined")

    // Capture stderr separately
    var stderr bytes.Buffer
    stdout, err := fleetctltest.RunWithErrWriter([]string{"query", "--help"}, &stderr)
    require.NoError(t, err)
    _ = stdout.String()
}
```

> **⚠️ Test-only package:** This package imports `testing` and must only ever be imported from `_test.go` files or test binaries. Importing it from production code will pull the `testing` package into the resulting binary.
