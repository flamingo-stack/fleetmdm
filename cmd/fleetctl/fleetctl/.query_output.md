Handles rendering of distributed query results from Fleet hosts, supporting both JSON and live-updating pretty table output formats.

## Key Components

- **`outputWriter`** — Interface requiring a `WriteResult(res fleet.DistributedQueryResult) error` method, implemented by both writers below.
- **`resultOutput`** — JSON serialization struct mapping a host identifier, query rows, and optional error.
- **`jsonWriter`** — Streams each query result as a newline-delimited JSON object to any `io.Writer` (defaults to `os.Stdout`).
- **`prettyWriter`** — Accumulates all results and re-renders a live-updating terminal table on every new result using `uilive` and `tablewriter`. Columns are auto-discovered, sorted alphabetically, and prefixed with a `hostname` column. Internal Fleet columns (`host_hostname`, `host_display_name`) are stripped before display.

## Usage Example

```go
// JSON output (e.g., pipe to a file or stdout)
jw := newJsonWriter(os.Stdout)
if err := jw.WriteResult(result); err != nil {
    log.Fatal(err)
}

// Pretty terminal table (live-updating)
pw := newPrettyWriter()
for result := range resultsChan {
    if err := pw.WriteResult(result); err != nil {
        log.Fatal(err)
    }
}
```

## Notes

- `prettyWriter` re-renders the **entire table** on every call — it buffers all past results in memory, making it suitable for interactive terminal sessions but not streaming pipelines.
- `jsonWriter` is stateless and safe for concurrent use if the underlying `io.Writer` is.
