Provides reusable base test suite structs for integration tests, embedding a MySQL datastore and an HTTP test server with helper utilities for authentication.

## Key Components

- **`WithDS`** — Base suite struct that initializes a named MySQL datastore, seeds the "all hosts" label, and configures `AppConfig` with a default org name and server URL. Implements `SetupSuite`/`TearDownSuite` lifecycle hooks.
- **`WithServer`** — Embeds `WithDS` and adds an `httptest.Server` and a `Users` map for server-level integration tests.
- **`GetTestToken`** — Posts credentials to `/api/latest/fleet/login` and returns the bearer token from the response.

## Usage Example

```go
type MyIntegrationSuite struct {
    integrationtest.WithServer
}

func (s *MyIntegrationSuite) SetupSuite() {
    s.WithDS.Suite = &s.Suite
    s.WithDS.SetupSuite("my_test_db")
    // initialize s.Server ...
}

func (s *MyIntegrationSuite) TearDownSuite() {
    s.WithDS.TearDownSuite()
}

func (s *MyIntegrationSuite) TestSomething() {
    token := s.GetTestToken("admin@example.com", "password123")
    // use token in authenticated requests
}
```

## Notes

- `SetupSuite` requires a unique `dbName` per suite to avoid datastore collisions across parallel test runs.
- `GetTestToken` asserts `HTTP 200` and zero errors before returning the token, failing the test immediately on any mismatch.
