Standalone generator script that scrapes Microsoft Learn for Windows Office security update bulletins and serializes the results to disk.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | `func` | Entry point: fetches the Windows Office vulnerability bulletin via `winoffice.FetchBulletin` and writes it to `winoffice_out/` in the working directory |
| `panicif` | `func` | Minimal error-handling helper; panics on any non-nil error |

## Usage Example

This file uses the `//go:build ignore` tag, so it is excluded from normal builds. Run it directly with `go run`:

```bash
cd server/vulnerabilities/winoffice
go run generate.go
```

Output directory `winoffice_out/` is created in the working directory. Expected console output:

```text
Scraping Windows Office security updates from Microsoft Learn...
Found <N> versions
Saving Windows Office bulletin...
Done.
```

## Notes

- **Build tag `ignore`** — the file is intentionally skipped by `go build` / `go test`; it must be invoked explicitly via `go run`.
- **HTTP timeout** — the `http.Client` is configured with a 60-second timeout to handle potentially slow Microsoft Learn responses.
- Serialization delegates to `bulletin.Serialize(now, outPath)` defined in the [`winoffice`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/vulnerabilities/winoffice) package.
