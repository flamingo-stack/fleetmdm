Simulates osquery agent behavior for Fleet MDM performance testing, generating realistic host enrollment, query responses, software inventory, and MDM check-ins across macOS, Windows, Ubuntu, and RHEL platforms.

## Key Components

- **`mdmAgent`** — Struct representing a simulated MDM-enrolled host with configurable OS version, software counts, MDM check-in intervals, and profile failure probabilities.
- **`nodeKeyManager`** — Thread-safe manager for persisting and retrieving osquery node keys to/from a file, enabling agent state continuity across runs.
- **Software loaders** — Embedded data files loaded at `init()` time:
  - `loadMacOSVulnerableSoftware()` — Loads bzip2-compressed macOS CVE-affected software list.
  - `loadExtraVulnerableSoftware()` — Parses VS Code extension vulnerability records.
  - `loadSoftwareItems()` — Generic loader for Windows/Ubuntu bzip2 software lists.
  - `loadDebKernelList()` / `loadRPMKernelList()` — Loads kernel package lists for Ubuntu and RHEL (8/9/10).
  - `loadSoftwareDBRPM()` — Lazily filters RPM packages from an optional SQLite software DB.
- **`adamIDsToSoftware`** — Map of Apple VPP App Store IDs to mock `fleet.Software` entries used to simulate VPP install flows.
- **`selectSoftwareVersion()`** — Deterministic per-agent version selector that simulates realistic version distribution (99% base, 0.9% alternate, 0.1% patch variants).

## Usage Example

```go
agent := &mdmAgent{
    agentIndex:            0,
    MDMCheckInInterval:    30 * time.Second,
    model:                 "MacBookPro18,3",
    serverAddress:         "https://fleet.example.com",
    softwareVersionMap:    make(map[rune]int),
    strings:               make(map[string]string),
    mdmProfileFailureProb: 0.01,
    osVersion:             "14.5",
}

// Get a stable cached random string for a host field
serial := agent.CachedString("serial_number")

// Resolve a consistent software version for this agent
version := agent.selectSoftwareVersion("Xcode", "15.0", "14.3")

// Persist node keys across runs
mgr := &nodeKeyManager{filepath: "/tmp/nodekeys.txt"}
mgr.LoadKeys()
mgr.Add("abc123nodekey")
```
