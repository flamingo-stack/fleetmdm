Provides a thread-safe, in-memory cache for software installer metadata used during osquery performance simulation, avoiding redundant downloads when multiple agents process the same installer.

## Key Components

### `Metadata` struct
- `cache map[uint]*file.InstallerMetadata` — maps installer IDs to extracted metadata
- `mu sync.Mutex` — guards concurrent cache access
- `Stats *osquery_perf.Stats` — tracks orbit error counters

### `Get(installer, orbitClient)`
Returns cached `InstallerMetadata` for a given installer ID. On a cache miss, delegates to `populateMetadata`, stores the result, and sets `cacheMiss = true`.

### `populateMetadata(installer, orbitClient)` *(private)*
Downloads the installer to a temp directory (preferring a CDN URL if `SoftwareInstallerURL` is set, falling back to a direct Fleet download), then:
- Returns a minimal `InstallerMetadata` stub for `.dmg`/`.zip` files (unsupported by the extractor)
- Runs `file.ExtractInstallerMetadata` for all other formats (`.pkg`, `.msi`, `.deb`, etc.)

## Usage Example

```go
cache := &installer_cache.Metadata{
    Stats: perfStats,
}

meta, cacheMiss, err := cache.Get(installerDetails, orbitClient)
if err != nil {
    log.Fatal(err)
}

if cacheMiss {
    log.Printf("cache miss for installer %d: %s", installerDetails.InstallerID, meta.Name)
}
```

## Notes

- The temp directory created during download is cleaned up via `defer os.RemoveAll` regardless of outcome.
- `.dmg` and `.zip` installers (Fleet-maintained apps) bypass metadata extraction and return a name/extension-only struct.
- Error paths increment `Stats.OrbitErrors` for perf simulation observability.
