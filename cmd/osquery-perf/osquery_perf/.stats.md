Thread-safe statistics collector for the `osquery_perf` load-testing package, tracking enrollment counts, error rates, and protocol-level metrics (MDM, DDM, osquery distributed queries) across concurrent simulated agents.

## Key Components

### `Stats` struct
Holds all counters behind a `sync.Mutex`, covering:
- **Enrollment**: osquery, Orbit, MDM enrollments and sessions
- **MDM/SCEP**: session counts, SCEP request/success/error tallies
- **DDM (Declarative Device Management)**: per-phase success/error counts for tokens, declaration items, configuration, activation, and status
- **osquery protocol**: distributed read/write counts and errors, config requests/errors, result log requests/errors
- **Miscellaneous**: buffered logs, script executions, software installs, desktop errors

### Methods

| Method | Description |
|--------|-------------|
| `Increment*()` | Mutex-guarded atomic increment for each counter |
| `UpdateBufferedLogs(v int)` | Adds `v` to the buffered log count, clamped to ≥ 0 |
| `Log()` | Emits a single structured log line with all current counters and uptime |
| `RunLoop()` | Blocks indefinitely, calling `Log()` every 10 seconds |

## Usage Example

```go
s := &osquery_perf.Stats{
    StartTime: time.Now(),
}

// Start background reporting
go s.RunLoop()

// Increment counters from concurrent goroutines
s.IncrementEnrollments()
s.IncrementMDMEnrollments()
s.IncrementDistributedReads()
s.IncrementMDMSCEPRequests()
s.IncrementMDMSCEPSuccess()
s.UpdateBufferedLogs(5)

// Snapshot at any point
s.Log()
```

> `RunLoop` ticks every 10 seconds and is intended to run as a background goroutine for the duration of a load test. All `Increment*` methods are safe to call from multiple goroutines simultaneously.
