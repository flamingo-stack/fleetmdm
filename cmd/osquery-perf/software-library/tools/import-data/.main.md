CSV-to-SQLite importer for Fleet MDM software inventory data, supporting optional vendor/pattern-based filtering to exclude internal or proprietary software entries.

## Key Components

- **`SoftwareEntry`** — Struct representing a parsed software record with fields matching the `software` table schema (name, version, source, vendor, arch, etc.)
- **`Importer`** — Core struct holding the DB connection, dry-run/verbose flags, filter configuration, and running import statistics
- **`ImportStats`** — Tracks totals for processed, imported, filtered, and duplicate entries
- **`run()`** — Orchestrates validation, DB connection, and CSV import pipeline
- **`importCSV()`** — Streams CSV rows and delegates each to `importEntry()`
- **`importEntry()`** — Validates fields, applies filters, and calls `insertSoftware()`
- **`shouldImport()`** — Determines whether an entry passes configured filters (internal patterns, vendor, private IPs)
- **`isInternalDomain()`** — Detects vendor strings that match internal domain patterns (e.g., `gitlab.corp.com`)
- **`parseSoftwareFromCSV()`** — Maps CSV columns to a `SoftwareEntry` by header name

## Usage Example

```bash
# Basic import
go run main.go --input software_export.csv

# Import with custom DB path and dry-run validation
go run main.go --input software_export.csv --db ./software.db --dry-run --verbose

# Filter out internal software by pattern and vendor
go run main.go \
  --input software_export.csv \
  --filter "internal,corp-" \
  --filter-vendor "acme" \
  --verbose
```

```go
// Programmatic usage (within the same package)
err := run(
    "software_export.csv",
    "../../software.db",
    false,  // dryRun
    true,   // verbose
    "internal,corp-",
    "acme",
)
```

**Filter behavior:**
- If no `--filter` or `--filter-vendor` flags are set, all valid entries are imported
- Known public software (Chrome, Docker, Git, etc.) is preserved even when vendor matches
- Private IP addresses in the vendor field are always filtered when filtering is enabled
