A CLI tool (`generate.go`) that downloads, parses, and serializes Microsoft Security Response Center (MSRC) vulnerability bulletins, either backfilling historical data or updating existing bulletins fetched from GitHub.

## Key Components

| Function | Description |
|----------|-------------|
| `main()` | Entry point — initializes HTTP clients, directories, and orchestrates bulletin download/update/save |
| `backfill()` | Downloads and merges all MSRC feeds from `MSRCMinYear` up to the current month |
| `update()` | Downloads the current MSRC feed and merges it into existing bulletins from GitHub |
| `serialize()` | JSON-marshals a `SecurityBulletin` and writes it to the output directory |
| `windowsBulletinGracePeriod()` | Returns `true` if within the first 15 days of the current month (MSRC feeds may not yet be published) |
| `panicif()` | Convenience helper that panics on non-nil errors |

### Environment Variables

| Variable | Behavior |
|----------|----------|
| `MSRC_CLEAN` | Set to `"false"` to update existing bulletins; any other value (or unset) triggers a full backfill |

## Usage Example

```bash
# Run a full backfill (default behavior)
go run generate.go

# Update existing bulletins from GitHub
MSRC_CLEAN=false go run generate.go
```

The tool writes input feeds to `./msrc_in/` and serialized output bulletins to `./msrc_out/`. Output filenames are generated via `io.MSRCFileName(productName, date)`.

```go
// Backfill flow: fetches monthly feeds from MSRCMinYear → now,
// merging each feed into a per-product SecurityBulletin map.
bulletins, err := backfill(now.Month(), now.Year(), msrcAPI)

// Update flow: downloads existing bulletins from GitHub,
// then merges the latest MSRC feed into each one.
bulletins, err := update(now.Month(), now.Year(), eBulletins, msrcAPI, ghAPI)
```

> **Note:** If the current month's MSRC feed is unavailable and the current date is within the 15-day grace period, the missing feed is silently skipped rather than returning an error.
