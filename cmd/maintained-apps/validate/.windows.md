Provides Windows-specific implementations for application detection and script execution used in the Fleet MDM software installer validator.

## Key Components

- **`normalizeVersion(version string) string`** — Pads version strings to 4-part format (`Major.Minor.Build.Revision`) for consistent comparison.
- **`appExists(...) (bool, error)`** — Queries the Windows `programs` table via `osqueryi` to detect installed applications. Falls back to checking AppX provisioned packages via PowerShell and handles edge cases for Google Chrome (auto-update), Microsoft Office (Click-to-Run), and Sublime Text (missing registry version).
- **`codexCLIExistsFromFile(...) (bool, error)`** — Detects the portable OpenAI Codex CLI binary (which does not register in the Windows programs table) by querying the PE file version via `osqueryi` across common install paths.
- **`executeScript(cfg *Config, scriptContents string) (string, error)`** — Writes a `.ps1` script to a temp directory and executes it via `powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass` with a 10-minute timeout.
- **`postApplicationInstall`** — No-op on Windows (platform hook).
- **`preInstalled`** — Empty slice (no pre-installed app exclusions on Windows).

## Usage Example

```go
// Check if an application is installed
found, err := appExists(ctx, logger, "Google Chrome", "", "124.0.6367.60", "")
if err != nil {
    log.Fatal(err)
}
fmt.Println("Chrome installed:", found)

// Run a PowerShell install script
output, err := executeScript(cfg, `Write-Output "Installing..."`)
if err != nil {
    log.Fatal(err)
}
fmt.Println(output)
```
