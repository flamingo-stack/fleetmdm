Provides the `AppCommander` struct and its methods for managing application lifecycle operations (install, uninstall, version extraction) on macOS and Windows platforms within the Fleet MDM toolchain.

## Key Components

### `AppCommander` Struct
Central type holding app metadata and configuration:

| Field | Description |
|---|---|
| `Name`, `Slug`, `UniqueIdentifier` | App identity fields |
| `Version` | Target version (`"latest"` triggers auto-extraction) |
| `AppPath`, `InstallScript`, `UninstallScript` | Filesystem and script references |
| `cfg` | Pointer to shared `Config` |
| `appLogger` | Structured logger (`slog.Logger`) |

### Methods

- **`isFrozen()`** — Reads the app's JSON input file (resolved from the slug) and returns whether the app is marked as frozen, preventing updates.
- **`extractAppVersion()`** — If `Version` is `"latest"`, extracts the actual version from installer metadata and rewinds the temp file reader for subsequent use.
- **`uninstallPreInstalled()`** — Handles pre-installed app removal by delegating to `uninstallApp()` while monitoring filesystem changes.
- **`uninstallApp()`** — Executes the uninstall script, then verifies the app is no longer present via `appExists()`.
- **`expectToChangeFileSystem()`** — Snapshots the installation directory before and after a given operation, detects added/removed applications, and returns the changed path along with any errors.

## Usage Example

```go
ac := &AppCommander{
    Name:            "MyApp",
    Slug:            "myapp/darwin",
    UniqueIdentifier: "com.example.myapp",
    Version:         "latest",
    UninstallScript: "sudo rm -rf /Applications/MyApp.app",
    cfg:             cfg,
    appLogger:       slog.Default(),
}

frozen, err := ac.isFrozen()
if err != nil || frozen {
    return
}

// Extract real version from installer before uploading
if err := ac.extractAppVersion(installerTFR); err != nil {
    log.Fatal(err)
}

// Uninstall any pre-existing version
ac.uninstallPreInstalled(ctx)
```

## Notes

- Build-constrained to `darwin` and `windows` via `//go:build darwin || windows`.
- Slug format must be `<name>/<platform>` — e.g., `"chrome/darwin"`.
