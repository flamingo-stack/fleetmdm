This file provides macOS-specific application management logic for the Fleet orbit agent, handling post-installation steps (LaunchServices refresh, quarantine removal) and app existence verification via osquery.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `postApplicationInstall` | `func` | Runs post-install steps: forces LaunchServices refresh and removes macOS quarantine attributes |
| `QuarantineResult` | `struct` | Holds diagnostic output from quarantine check and removal commands (`xattr`, `spctl`) |
| `removeAppQuarantine` | `func` | Checks quarantine status and removes the `com.apple.quarantine` xattr via `sudo` |
| `forceLaunchServicesRefresh` | `func` | Invokes `lsregister -f` to force macOS to recognize a newly installed app |
| `normalizeVersion` | `func` | Strips common pre-release suffixes (`-latest`, `-beta`, `-alpha`, etc.) from version strings |
| `checkVersionMatch` | `func` | Multi-strategy version comparator: exact, normalized, concatenated, and prefix matching |
| `appExists` | `func` | Queries osquery `apps` table to verify an app is installed at the expected version |
| `preInstalled` | `var` | Slice of app identifiers considered pre-installed on Darwin (e.g., `"firefox/darwin"`) |

## Usage Example

```go
// Post-installation hook after copying an .app bundle
err := postApplicationInstall(ctx, logger, "/Applications/MyApp.app")
if err != nil {
    log.Printf("post-install warning: %v", err)
}

// Check if a specific app version is present
found, err := appExists(
    ctx,
    logger,
    "Firefox",              // display name
    "org.mozilla.firefox",  // bundle identifier
    "124.0.1",              // expected version
    "/Applications/Firefox.app",
)
if err != nil {
    log.Fatal(err)
}
if found {
    log.Println("App is installed at the expected version")
}
```

> **Note:** Several known apps (OneDrive, GPG Suite, Adobe DNG Converter, Ableton Live, WhatsApp, Logi Tune) have hardcoded special-case logic inside `appExists` to handle auto-update behavior or non-standard version string formats.
