This file is the entry point for the Fleet Maintained Apps (FMA) validation tool, which downloads, installs, verifies, and uninstalls maintained apps on macOS and Windows to validate their install/uninstall scripts and metadata.

## Key Components

- **`Config`** — Holds runtime configuration including temp directory, OS target, paths, environment variables, and logger.
- **`main()`** — Bootstraps the validator by reading environment variables (`LOG_LEVEL`, `GOOS`, `INSTALLATION_SEARCH_DIRECTORY`), configuring the logger, and invoking `run()`.
- **`run(cfg *Config) error`** — Core validation loop: iterates over all apps from the manifest, downloads each installer, verifies SHA256, runs install/uninstall scripts, and checks app presence via osquery.
- **`detachAllDMGs()`** — macOS-specific cleanup that force-detaches any DMG images mounted under the temp directory using `hdiutil`.
- **`getListOfApps()`** — Reads and parses `apps.json` from the outputs path into a list of `FMAListFileApp` entries.
- **`getAppJson()`** — Reads and parses an individual app's `<slug>.json` manifest file.
- **`appFromJson()`** — Converts an `FMAManifestFile` into a `fleet.MaintainedApp` struct using the first available version entry.

## Usage Example

```bash
# Run validation for macOS apps
LOG_LEVEL=debug \
GOOS=darwin \
INSTALLATION_SEARCH_DIRECTORY=/Applications \
go run ./tools/maintained-apps/validate/

# Run validation for Windows apps
GOOS=windows \
INSTALLATION_SEARCH_DIRECTORY="C:\\Program Files" \
go run ./tools/maintained-apps/validate/
```

```go
// Programmatic usage (simplified)
cfg := &Config{
    operatingSystem:             "darwin",
    installationSearchDirectory: "/Applications",
    outputsPath:                 maintained_apps.OutputPath,
    logger:                      slog.Default(),
}
if err := run(cfg); err != nil {
    log.Fatal(err)
}
```

> **Build constraint:** This file only compiles on `darwin` and `windows` (`//go:build darwin || windows`). It will not compile on Linux.
