Entry point for the Fleet maintained-apps ingestion pipeline. It reads app definitions from Homebrew and Winget input directories, validates and processes each app manifest, and writes structured JSON output files to the designated output path.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `main` | `func` | Bootstraps the ingestion pipeline; iterates over registered ingesters and processes each resulting app |
| `processOutput` | `func` | Validates categories, updates the master app list, and writes individual JSON manifest files |
| `validateCategories` | `func` | Ensures every category on an app matches the allowlist synced with `frontend/interfaces/software.ts` |
| `updateAppsListFile` | `func` | Reads `apps.json`, appends new entries (if missing), re-sorts by slug, and writes back |
| `allowedCategories` | `var` | Allowlist map of valid category strings: `Browsers`, `Communication`, `Developer tools`, `Productivity`, `Security`, `Utilities` |

## Usage Example

```bash
# Ingest all maintained apps
go run ./ee/maintained-apps/ingesters/

# Ingest a single app by slug
go run ./ee/maintained-apps/ingesters/ -slug firefox

# Enable debug logging
go run ./ee/maintained-apps/ingesters/ -slug firefox -debug
```

```go
// The two registered ingesters and their input directories:
ingesters := map[string]maintained_apps.Ingester{
    "ee/maintained-apps/inputs/homebrew": homebrew.IngestApps,
    "ee/maintained-apps/inputs/winget":   winget.IngestApps,
}
```

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `-slug` | `""` | Limit ingestion to a single app slug |
| `-debug` | `false` | Switch logger from `INFO` to `DEBUG` level |

## Notes

- Frozen apps (`app.Frozen == true`) skip overwriting an already-existing output file, preserving the previously written manifest.
- The `UniqueIdentifier` field is stripped from individual manifest files before writing to prevent leakage.
