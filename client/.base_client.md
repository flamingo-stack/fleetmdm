Provides the foundational HTTP client structure for Fleet API communication, including TLS configuration, response parsing, capability negotiation, and file download handling.

## Key Components

- **`BaseClient`** — Core struct holding the base URL, HTTP client, URL prefix, TLS settings, and server/client capability maps.
- **`NewBaseClient`** — Constructor that parses the server address, configures TLS (custom CA, insecure skip, or system pool), and initializes the HTTP client with optional request signing.
- **`ParseResponse`** — Handles HTTP status codes (404, 401, 402, 2xx), updates server capabilities, and unmarshals JSON into the destination type or delegates to a `BodyHandler`.
- **`HTTPClient`** — Interface wrapping `http.Do` to enable mock injection in tests.
- **`BodyHandler`** — Interface for custom response body handling (e.g., streaming to disk).
- **`FileResponse`** — `BodyHandler` implementation that streams a response body to a local file, resolving the filename from `Content-Disposition` and optionally reporting progress via `ProgressFunc`.
- **`SetServerCapabilities` / `SetClientCapabilitiesHeader`** — Bidirectional capability negotiation via the `Fleet-Capabilities` header.

## Usage Example

```go
cert, _ := tls.LoadX509KeyPair("client.crt", "client.key")

client, err := client.NewBaseClient(
    "https://fleet.example.com",
    false,
    "/etc/fleet/ca.pem",
    "/api",
    &cert,
    fleet.CapabilityMap{},
    nil,
)
if err != nil {
    log.Fatal(err)
}

req, _ := http.NewRequest(http.MethodGet, client.URL("/v1/hosts", "").String(), nil)
client.SetClientCapabilitiesHeader(req)

resp, err := client.DoHTTPRequest(req)
if err != nil {
    log.Fatal(err)
}
defer resp.Body.Close()

var result MyResponse
if err := client.ParseResponse("GET", "/v1/hosts", resp, &result); err != nil {
    log.Fatal(err)
}
```
