HTTP client for Fleet server communication from Orbit agents, handling enrollment, authentication, configuration fetching, and config receiver orchestration with support for OpenFrame mode.

## Key Components

| Symbol | Description |
|--------|-------------|
| `OrbitClient` | Main struct embedding `BaseClient`; manages node key, enrollment state, 401 debounce/re-enrollment, config caching, SSO window handling, and OpenFrame Bearer auth |
| `NewOrbitClient` | Constructor; wires TLS, URL prefix (OpenFrame mode), node key path, config receivers, and auth manager |
| `request` / `requestWithExternal` | Core HTTP dispatch; marshals params, injects capability and Bearer auth headers, delegates to `DoHTTPRequest` / `ParseResponse` |
| `configCache` | Mutex-protected cache with a 3-second TTL for `fleet.OrbitConfig` responses |
| `OnGetConfigErrFuncs` | Callback struct for surfacing network/5XX errors (rate-limited to 5 min) and debug-level errors from `GetConfig` |
| `RunConfigReceivers` | Fetches config once and fans out to all registered `OrbitConfigReceiver` implementations concurrently |
| `ExecuteConfigReceivers` | Ticker-driven loop (default 30 s) that calls `RunConfigReceivers` until context cancellation |
| `closeIdleConnections` | Cleans up HTTP transport idle connections every 55 minutes to avoid AWS ELB forced-close errors |
| `TriggerOrbitRestart` / `RestartTriggered` | Cancel the receiver context to signal a graceful restart |
| `unauthenticatedReenrollGracePeriod` | Package-level `var` (45 s default, overridable in tests) controlling 401 debounce before forced re-enrollment |

## Usage Example

```go
authMgr := openframe.NewOpenFrameAuthorizationManager(...)

client, err := client.NewOrbitClient(
    "/var/lib/orbit",          // rootDir
    "https://fleet.example.com",
    "",                        // rootCA
    false,                     // insecureSkipVerify
    "my-enroll-secret",
    nil,                       // fleetClientCert
    fleet.OrbitHostInfo{...},
    &client.OnGetConfigErrFuncs{
        OnNetErrFunc: func(err error) { log.Warn().Err(err).Msg("net error") },
        DebugErrFunc: func(err error) { log.Debug().Err(err).Msg("config err") },
    },
    nil,   // httpSignerWrapper
    "",    // hostIdentityCertPath
    true,  // openFrameMode
    authMgr,
)
if err != nil {
    log.Fatal().Err(err).Send()
}

client.RegisterConfigReceiver(myReceiver)
if err := client.ExecuteConfigReceivers(); err != nil {
    log.Error().Err(err).Send()
}
```
