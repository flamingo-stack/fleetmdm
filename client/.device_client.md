HTTP client for Fleet Desktop's device-specific API endpoints, handling authenticated requests with automatic token refresh on `ErrUnauthenticated` responses.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeviceClient` | struct | Extends `BaseClient` with device-scoped auth, token retry logic, and browser host overrides |
| `NewDeviceClient` | constructor | Creates a `DeviceClient` with TLS config and optional alternative browser host |
| `WithInvalidTokenRetry` | method | Registers a callback to fetch a fresh token on auth failures |
| `CheckToken` | method | Validates a device token via a `HEAD` ping, falling back to `DesktopSummary` |
| `Ping` | method | Unauthenticated server health check |
| `DesktopSummary` | method | Fetches failing policy count and alternative browser host; falls back to full policy list on 404 |
| `BrowserDeviceURL` | method | Builds the `/device/{token}` browser URL with optional host override |
| `BrowserTransparencyURL` | method | Builds the transparency redirect URL |
| `BrowserSelfServiceURL` | method | Builds the self-service browser URL |
| `BrowserPoliciesURL` | method | Builds the policies browser URL |
| `MigrateMDM` | method | Triggers MDM migration for a device |
| `ReportError` | method | Reports a `FleetdError` with up to 3 retries at 15-second intervals |

## Usage Example

```go
cert, _ := tls.LoadX509KeyPair("client.crt", "client.key")
dc, err := client.NewDeviceClient(
    "https://fleet.example.com",
    false,
    "/etc/ssl/certs/ca.pem",
    &cert,
    "", // no alternative browser host
)
if err != nil {
    log.Fatal(err)
}

// Retry with a fresh token on 401
dc.WithInvalidTokenRetry(func() string {
    return fetchNewTokenFromOrbit()
})

// Validate token and get desktop summary
summary, err := dc.DesktopSummary(deviceToken)
if err != nil {
    log.Error().Err(err).Msg("failed to get summary")
}
fmt.Printf("Failing policies: %d\n", *summary.FailingPolicies)

// Get browser URL for Fleet Desktop tray
deviceURL := dc.BrowserDeviceURL(deviceToken)
```

## Retry Behavior

The `request` method attempts up to **4 retries** on `ErrUnauthenticated`, sleeping `attempt × 1s` between attempts and invoking `invalidTokenRetryFunc` to refresh the token. Retries are skipped for unauthenticated paths (token `"-"`), when no retry hook is set, or for non-auth errors.
