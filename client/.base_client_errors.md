Defines client-side error types and utilities for handling Fleet API error responses, including sentinel errors, structured error interfaces, and response body parsing helpers.

## Key Components

### Sentinel Errors
- `ErrUnauthenticated` — invalid or missing auth token
- `ErrPasswordResetRequired` — user must reset password via Fleet UI
- `ErrMissingLicense` — missing or invalid Fleet license
- `ErrEndUserAuthRequired` — end-user authentication required (e.g., device enrollment)

### Error Types & Interfaces
| Type | Description |
|---|---|
| `SetupAlreadyError` / `SetupAlreadyErr` | Fleet instance already initialized |
| `NotSetupError` / `NotSetupErr` | Fleet instance not yet initialized |
| `NotFoundErr` / `NotFoundErrIface` | Resource not found; satisfies `sql.ErrNoRows` via `Is()` |
| `ConflictError` / `ConflictErr` | Resource conflict (e.g., duplicate) |
| `StatusCodeErr` | Wraps an HTTP status code and body text |

### Helper Functions
- `TruncateAndDetectHTML(body, maxLen)` — truncates a response body and detects HTML content
- `ExtractServerErrorText(body)` — returns the first error reason string from a JSON error body
- `ExtractServerErrorNameReason(body)` — returns the first `(name, reason)` pair from a JSON error body, with fallback for HTML/plain-text responses
- `ExtractServerErrorNameReasons(body)` — returns all `(names, reasons)` slices from a JSON error body
- `IsNotFoundErr(err)` — reports whether an error chain contains `*NotFoundErr`

## Usage Example

```go
resp, err := client.DoSomeRequest()
if err != nil {
    if errors.Is(err, client.ErrUnauthenticated) {
        log.Fatal("please log in again")
    }
    if client.IsNotFoundErr(err) {
        log.Fatal("resource does not exist")
    }
}

// Parse a non-2xx response body
name, reason := client.ExtractServerErrorNameReason(resp.Body)
fmt.Printf("error field %q: %s\n", name, reason)

// Check HTTP status
var sce *client.StatusCodeErr
if errors.As(err, &sce) && sce.StatusCode() == 429 {
    log.Println("rate limited")
}
```
