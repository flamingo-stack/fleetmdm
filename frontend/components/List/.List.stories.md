Storybook stories for the `List` component, demonstrating its various props and interaction states using `@storybook/react`.

## Key Components

| Export | Description |
|---|---|
| `Default` | Base list with data and custom row renderer |
| `WithHeading` | List with an optional heading element |
| `WithHelpText` | List with contextual help text below |
| `ClickableRows` | List with `onClickRow` handler logging to console |
| `Loading` | List in loading/skeleton state via `isLoading` |
| `CustomIdKey` | List using a non-default `idKey` prop (`customId` instead of `id`) |

## Usage Example

```typescript
// Default story — standard list with a flex row renderer
export const Default: Story = {};

// Custom ID key — when your data uses a field other than `id`
export const CustomIdKey: Story = {
  render: () => {
    interface CustomItem {
      customId: string;
      name: string;
    }

    const data: CustomItem[] = [
      { customId: "alpha", name: "Alpha" },
      { customId: "beta", name: "Beta" },
    ];

    return (
      <List<CustomItem, "customId">
        data={data}
        idKey="customId"
        renderItemRow={(item) => <span>{item.name}</span>}
      />
    );
  },
};
```

The shared `meta` config seeds all stories with a 3-item dataset and a flex-based `renderItemRow`, so individual stories only need to override the specific prop they demonstrate.
