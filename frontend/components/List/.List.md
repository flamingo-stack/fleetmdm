A generic, reusable list component that renders an array of items as an unordered list with optional click handling, loading state, and custom row rendering.

## Key Components

### `IListProps<TItem, TKey>`
| Prop | Type | Description |
|------|------|-------------|
| `data` | `TItem[]` | Array of items to render |
| `isLoading` | `boolean` | Displays a loading overlay when `true` |
| `idKey` | `TKey` | Key field used for React's `key` prop (defaults to `"id"`) |
| `renderItemRow` | `(item: TItem) => ReactElement \| false \| null \| undefined` | Custom row renderer |
| `onClickRow` | `(item: TItem) => void` | Click handler for list rows |
| `isRowClickable` | `(item: TItem) => boolean` | Per-item clickability control |
| `heading` | `JSX.Element` | Optional sticky header row |
| `helpText` | `React.ReactNode` | Helper text rendered below the list |

### `List<TItem, TKey>`
Generic functional component constrained to items that include an `id` key (or a custom key via `TKey`).

## Usage Example

```typescript
interface IDevice {
  id: number;
  name: string;
  status: "online" | "offline";
}

<List<IDevice>
  data={devices}
  isLoading={isFetching}
  renderItemRow={(device) => (
    <span>{device.name} — {device.status}</span>
  )}
  onClickRow={(device) => console.log("Selected:", device.id)}
  isRowClickable={(device) => device.status === "online"}
  helpText="Click an online device to view details."
/>
```

> **Note:** Rows gain the `list__row--clickable` CSS class when `onClickRow` is provided or `isRowClickable` returns `true` for that item, enabling pointer-style styling without additional logic.
