Test suite for the `RevealButton` component, verifying rendering of show/hide text states, caret positioning, and tooltip behavior on hover.

## Key Components

- **`describe("Reveal button")`** — Top-level test suite covering all `RevealButton` behaviors
- **Test cases:**
  - `renders show text` — Confirms label displays when `isShowing={false}`
  - `renders hide text` — Confirms label displays when `isShowing={true}`
  - `hides caret by default` — Asserts no chevron icon renders without `caretPosition`
  - `renders caret on left` — Validates `chevron-right-icon` precedes text when `caretPosition="before"`
  - `renders caret on right` — Validates `chevron-down-icon` follows text when `caretPosition="after"`
  - `renders tooltip on hover if provided` — Simulates hover and asserts tooltip content appears

## Usage Example

```typescript
// Rendering the component under test
render(
  <RevealButton
    isShowing={false}
    hideText="Advanced options"
    showText="Advanced options"
    caretPosition="before"
    tooltipContent="Customize logging type and platforms"
  />
);

// Asserting caret placement
const icon = screen.queryByTestId("chevron-right-icon");
expect(icon?.nextSibling).toHaveTextContent("Advanced options");

// Asserting tooltip on hover
const { user } = renderWithSetup(<RevealButton ... />);
await user.hover(screen.getByText("Advanced options"));
await waitFor(() => {
  expect(screen.getByText("Customize logging type and platforms")).toBeInTheDocument();
});
```

## Notes

- Uses `renderWithSetup` from `test/test-utils` for user-event interactions (hover simulation)
- Caret icons are identified via `data-testid` attributes (`chevron-right-icon`, `chevron-down-icon`)
