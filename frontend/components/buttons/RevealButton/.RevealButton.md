A toggle button component that reveals or hides content, displaying contextual text and an optional caret icon based on the current visibility state.

## Key Components

### `IRevealButtonProps`
Interface defining the component's props:
- `isShowing` — controls current toggle state (show/hide)
- `hideText` / `showText` — labels displayed based on state
- `caretPosition` — optional chevron icon placement (`"before"` or `"after"`)
- `tooltipContent` — tooltip shown on hover when enabled
- `disabledTooltipContent` — tooltip shown when button is disabled (wraps button to support hover while disabled)
- `autofocus`, `disabled`, `className`, `onClick` — standard button controls

### `RevealButton`
Default export. Renders an `inverse` variant `Button` with dynamic label and optional caret icons. When disabled with `disabledTooltipContent`, wraps the button in a `TooltipWrapper` to preserve tooltip functionality despite the disabled state.

## Usage Example

```typescript
<RevealButton
  isShowing={isExpanded}
  showText="Show details"
  hideText="Hide details"
  caretPosition="after"
  tooltipContent={<span>Toggle section visibility</span>}
  onClick={() => setIsExpanded(!isExpanded)}
/>

// Disabled with tooltip
<RevealButton
  isShowing={false}
  showText="Show advanced"
  hideText="Hide advanced"
  disabled
  disabledTooltipContent="Requires admin permissions"
  onClick={() => {}}
/>
```

## Notes

- When `caretPosition="before"`, the chevron alternates between `chevron-right` and `chevron-down` based on `isShowing`
- When `caretPosition="after"`, the chevron rotates via CSS class `reveal-button__caret--open` rather than swapping icons
