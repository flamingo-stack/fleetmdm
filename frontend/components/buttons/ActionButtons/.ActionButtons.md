Renders a structured set of primary and secondary action buttons for detail/edit pages, supporting optional icons, button variants, and GitOps mode compatibility with tooltip wrapping.

## Key Components

### `IActionButtonProps`
Configuration interface for individual action buttons:
- `type` — `"primary"` or `"secondary"` placement
- `label` — button display text
- `onClick` — click handler
- `buttonVariant` — optional `ButtonVariant` override
- `iconName` — optional icon rendered alongside the label
- `hideAction` — conditionally excludes the button from rendering
- `gitOpsModeCompatible` — wraps the button in `GitOpsModeTooltipWrapper` when enabled

### `ActionButtons`
Default export. Splits the `actions` array into primary and secondary buckets (filtering hidden actions), then renders:
- **Primary actions** — standard `Button` components
- **Secondary actions** — `Button` components (with optional variant/icon), plus a `DropdownButton` "More options" overflow menu for smaller viewports

## Usage Example

```typescript
import ActionButtons, { IActionButtonProps } from "components/ActionButtons";

const actions: IActionButtonProps[] = [
  {
    type: "primary",
    label: "Save",
    onClick: () => handleSave(),
  },
  {
    type: "secondary",
    label: "Delete",
    buttonVariant: "alert",
    iconName: "trash",
    gitOpsModeCompatible: true,
    onClick: () => handleDelete(),
  },
  {
    type: "secondary",
    label: "Export",
    buttonVariant: "text-icon",
    iconName: "export",
    onClick: () => handleExport(),
    hideAction: !canExport,
  },
];

<ActionButtons baseClass="host-details" actions={actions} />;
```

## Notes

- Hidden actions (`hideAction: true`) are filtered before rendering — safe to conditionally include in the array.
- `gitOpsModeCompatible` actions are wrapped in `GitOpsModeTooltipWrapper`, which disables the button and shows a tooltip when GitOps mode is active.
- Secondary actions also appear in a `DropdownButton` overflow menu; ensure `label` values are descriptive for that context.
