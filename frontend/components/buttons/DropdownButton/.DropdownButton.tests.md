Unit tests for the `DropdownButton` component, verifying that clicking a dropdown option triggers its associated `onClick` handler.

## Key Components

- **Test suite**: `DropdownButton - component` — covers interaction behavior of the `DropdownButton` component
- **Test case**: Asserts that selecting a dropdown option invokes the correct `onClick` callback for that specific option, not others

## Usage Example

```javascript
// Renders a DropdownButton with multiple options and verifies onClick dispatch
const optionSpy = jest.fn();
const dropdownOptions = [
  { label: "btn1", onClick: noop },
  { label: "btn2", onClick: optionSpy },
];

render(
  <DropdownButton options={dropdownOptions}>New Button</DropdownButton>
);

fireEvent.click(screen.getByText("New Button"));         // Opens dropdown
fireEvent.click(screen.getByRole("button", { name: "btn2" })); // Selects option
expect(optionSpy).toHaveBeenCalled();                    // Correct handler fired
```

## Testing Approach

- Uses `@testing-library/react` for DOM rendering and event simulation
- `jest.fn()` spy confirms the correct option's handler is called
- `lodash.noop` is used as a no-op placeholder for non-targeted options, ensuring only the intended handler fires
- Interaction flow: open dropdown via trigger text → click specific option → assert spy invocation
