Storybook stories file for the `DropdownButton` component, providing interactive documentation and visual testing scenarios within the Storybook UI.

## Key Components

- **`meta`** – Storybook `Meta` configuration defining the component title (`Components/DropdownButton`), available `variant` options (`default`, `alert`, `pill`, `link`, `text-icon`, `icon`, `inverse`, `inverse-alert`, `unstyled`, `unstyled-modal-query`), and shared default args
- **`Default`** – Base story rendering a `DropdownButton` with an `Avatar` child using the default Gravatar link and a sample options array (My account, Documentation, Sign out)
- **`Disabled`** – Extends `Default` with `disabled: true` to showcase the disabled state

## Usage Example

```typescript
import { Default, Disabled } from "./DropdownButton.stories";

// Render the default dropdown with avatar trigger
<Default />

// Render the disabled state
<Disabled />

// Sample options shape expected by DropdownButton
const options = [
  { label: "My account", onClick: () => {} },
  { label: "Sign out", onClick: () => {} },
];
```

## Notes

- Stories are located at [`components/DropdownButton/DropdownButton.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/DropdownButton/DropdownButton.stories.tsx)
- The `variant` control is exposed as a `select` dropdown in Storybook, making it easy to preview all visual variants interactively
- The `options` prop drives the dropdown menu items; each entry requires a `label` string and an `onClick` handler
