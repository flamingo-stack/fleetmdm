A reusable dropdown button component that renders a trigger button with a collapsible list of clickable options, closing automatically when the user clicks outside.

## Key Components

- **`DropdownButton`** — Class component managing open/close state, rendering the trigger button and an options list
- **`toggleDropdown`** — Toggles the dropdown open/closed on trigger button click
- **`optionClick`** — Closes the dropdown and invokes the selected option's `onClick` handler
- **`renderOptions`** — Maps each option to a `<li>` element containing an unstyled `Button`
- **Default export** — `DropdownButton` wrapped with `ClickOutside` HOC to close on external clicks

## Props

| Prop | Type | Description |
|------|------|-------------|
| `options` | `array` | **Required.** Array of `{ label, onClick, disabled }` objects |
| `children` | `node` | Trigger button content |
| `disabled` | `bool` | Disables the trigger button |
| `variant` | `string` | Button style variant |
| `size` | `string` | Button size |
| `showCaret` | `bool` | Show chevron icon (default: `true`) |
| `tabIndex` | `number` | Tab index for the trigger button |

## Usage Example

```javascript
import DropdownButton from "components/buttons/DropdownButton";

const actions = [
  { label: "Edit", onClick: () => handleEdit() },
  { label: "Delete", onClick: () => handleDelete(), disabled: false },
];

<DropdownButton
  variant="brand"
  size="medium"
  options={actions}
>
  Actions
</DropdownButton>
```
