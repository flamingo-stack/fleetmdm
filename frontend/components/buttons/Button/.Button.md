Reusable button component that renders a styled `<button>` element with support for multiple visual variants, loading states, accessibility attributes, and size options.

## Key Components

### `ButtonVariant`
Union type defining available visual styles:
- `"default"`, `"alert"`, `"inverse"`, `"inverse-alert"` — standard action buttons
- `"pill"`, `"grey-pill"`, `"oversized"` — shape/size variants
- `"link"`, `"brand-inverse-icon"`, `"text-icon"`, `"icon"` — icon and link-style buttons
- `"unstyled"`, `"unstyled-modal-query"` — minimal styling overrides

### `IButtonProps`
Full prop interface including:
- `variant` — visual style (default: `"default"`)
- `isLoading` — shows an inline `Spinner` and makes text transparent
- `iconStroke` — applies stroke-based hover styling for SVG icons
- `size` — `"small"` (half padding), `"wide"` (200px), or `"default"`
- `ariaHasPopup`, `ariaExpanded`, `ariaLabel` — ARIA accessibility attributes
- `customOnKeyDown` — overrides default Enter key handler
- `autofocus` — focuses the button on mount

### `Button` (class component)
Handles click/keyboard events, disabled state guards, ref-based autofocus, and dynamic `classnames` composition.

## Usage Example

```typescript
import Button from "components/Button";

// Default button
<Button onClick={() => console.log("clicked")}>Save</Button>

// Loading state
<Button variant="default" isLoading>Saving...</Button>

// Alert variant, small size
<Button variant="alert" size="small" onClick={handleDelete}>Delete</Button>

// Icon button with ARIA label
<Button variant="icon" ariaLabel="Close dialog" onClick={onClose}>
  <CloseIcon />
</Button>

// Link-style with custom key handler
<Button
  variant="link"
  customOnKeyDown={(e) => e.key === "Escape" && onClose()}
>
  Cancel
</Button>
```
