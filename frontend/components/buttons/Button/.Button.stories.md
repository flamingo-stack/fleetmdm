Storybook stories file for the `Button` component, defining visual variants and interactive controls for documentation and UI testing in Storybook.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DefaultVariant` | `Story` | Default button with loading state toggle |
| `AlertVariant` | `Story` | Alert/destructive button with loading state toggle |
| `InverseVariant` | `Story` | Inverse-styled button |
| `InverseAlertVariant` | `Story` | Inverse alert button |
| `PillVariant` | `Story` | Pill-shaped button |
| `LinkVariant` | `Story` | Link-styled button |
| `TextIconVariant` | `Story` | Button with trailing icon |
| `BrandInverseIconVariant` | `Story` | Brand inverse button with leading icon |
| `IconVariant` | `Story` | Icon-only button |
| `UnstyledVariant` | `Story` | Unstyled button |
| `UnstyledModalQueryVariant` | `Story` | Unstyled modal query button |
| `OversizedVariant` | `Story` | Oversized button |

### Helper Templates

- **`Template(variant, children?)`** — Base factory for non-loading variants; hides `isLoading` control.
- **`createLoadingVariant(variant)`** — Factory for variants that expose a `isLoading` boolean toggle in Storybook controls.

## Usage Example

```typescript
// Adding a new Button story variant
import { ButtonVariant } from "./Button";

// Non-loading variant
export const MyVariant = Template("my-variant");

// Variant with loading state control
export const MyLoadingVariant = createLoadingVariant("default");

// Variant with custom icon children
export const MyIconVariant = Template(
  "text-icon",
  <>
    Submit <Icon name="check" size="small" />
  </>
);
```

## Notes

- Only `default` and `alert` variants expose the `isLoading` control — other variants intentionally suppress it.
- The `disabled` control is a boolean toggle available across all stories.
- The `variant` argType control is hidden globally; each story represents a single variant.
