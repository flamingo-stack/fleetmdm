A specialized button component that renders a styled "Automations" button with a settings icon, built on top of the base `Button` component with the `inverse` variant pre-applied.

## Key Components

- **`AutomationsButton`** — Default export. A wrapper around the `Button` component that renders a settings icon alongside the label "Automations".
- **`IAutomationsButtonProps`** — Exported type that picks `onClick`, `disabled`, `className`, and `size` from `IButtonProps`.

## Usage Example

```typescript
import AutomationsButton from "components/buttons/AutomationsButton";

const MyPage = () => (
  <AutomationsButton
    onClick={() => console.log("Open automations")}
    disabled={false}
    size="medium"
  />
);
```

## Notes

- The `variant` is hardcoded to `"inverse"` and cannot be overridden.
- The base CSS class `automations-button` is always applied; additional classes can be passed via `className`.
