Storybook stories for the `TeamsDropdown` component, defining metadata and a basic usage story for visual development and testing.

## Key Components

- **`meta`** — Storybook `Meta` configuration for `TeamsDropdown`, sets the component title, wraps stories in a min-height container decorator, and provides default args (two sample teams and a no-op `onChange` handler)
- **`Basic`** — A minimal story rendering `TeamsDropdown` with the default args

## Usage Example

```typescript
// Render the Basic story in Storybook
export const Basic: Story = {};

// Override args for a custom story
export const SingleTeam: Story = {
  args: {
    currentUserTeams: [{ id: 1, name: "Engineering" }],
    onChange: (teamId) => console.log("Selected team:", teamId),
  },
};
```

## Notes

- Stories are located under **Components/TeamsDropdown** in the Storybook sidebar
- The decorator ensures dropdown menus have enough vertical space (`minHeight: 300`) to render without clipping
- `noop` from `lodash` is used as a safe default for the `onChange` callback in shared args
