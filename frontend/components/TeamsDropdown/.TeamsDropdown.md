A searchable dropdown component for selecting teams, built on `react-select-5`. Supports "All Teams" and "No Team" virtual entries, a custom chevron indicator, and two visual modes: a compact header style and a standard form field style.

## Key Components

- **`INumberDropdownOption`** — Extends `IDropdownOption` with `value: number`, matching team IDs.
- **`ITeamsDropdownProps`** — Props interface controlling team list, selection state, visibility filters, disabled state, and open/close callbacks.
- **`generateDropdownOptions`** — Pure function that maps `ITeamSummary[]` into dropdown options, conditionally filtering the "All Teams" and "No Team" sentinel entries.
- **`CustomDropdownIndicator`** — Renders a `chevron-down` icon that rotates 180° when the menu is open, with color states for focused, active, and disabled.
- **`TeamsDropdown`** — Default export; the full component with memoized options, `react-select-5` custom styles, and fallback to the first option when `selectedTeamId` doesn't match any option.

## Usage Example

```typescript
import TeamsDropdown from "components/TeamsDropdown";

// Header-style (default)
<TeamsDropdown
  currentUserTeams={teams}
  selectedTeamId={currentTeamId}
  includeAllTeams
  includeNoTeams={false}
  onChange={(teamId) => setCurrentTeamId(teamId)}
  onOpen={() => console.log("menu opened")}
  onClose={() => console.log("menu closed")}
/>

// Form field style
<TeamsDropdown
  currentUserTeams={teams}
  selectedTeamId={currentTeamId}
  isDisabled={isSubmitting}
  onChange={(teamId) => setFieldValue("teamId", teamId)}
  asFormField
/>
```
