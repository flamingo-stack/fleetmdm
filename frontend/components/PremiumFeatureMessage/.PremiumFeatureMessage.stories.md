Storybook stories file for the `PremiumFeatureMessage` component, providing a basic story configuration for visual testing and documentation in Storybook.

## Key Components

- **`meta`** – Storybook `Meta` configuration registering the component under `Components/PremiumFeatureMessage`
- **`Basic`** – Default story rendering `PremiumFeatureMessage` with no additional props

## Usage Example

```typescript
import { Basic } from "./PremiumFeatureMessage.stories";

// Render the Basic story in tests or Storybook
<Basic />
```

To add additional stories with custom props:

```typescript
export const WithCustomMessage: Story = {
  args: {
    message: "This feature requires a premium plan.",
  },
};
```
