A React component that displays an informational message indicating a feature requires a Fleet Premium subscription, with a link to learn more.

## Key Components

- **`PremiumFeatureMessage`** — Default export. A presentational component rendering a premium feature notice with an icon, descriptive text, and an external upgrade link.
- **`IPremiumFeatureMessage`** — Interface defining the optional `className` prop for custom styling overrides.
- **`baseClass`** — Base CSS class `"premium-feature-message-container"` applied to the wrapper element.

## Usage Example

```typescript
import PremiumFeatureMessage from "components/PremiumFeatureMessage";

// Basic usage
const MyFeaturePage = () => (
  <div>
    <h2>Advanced Analytics</h2>
    <PremiumFeatureMessage />
  </div>
);

// With additional custom class
const MyFeaturePage = () => (
  <PremiumFeatureMessage className="my-custom-styles" />
);
```

## Notes

- The component composes [`CustomLink`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/CustomLink) and [`Icon`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/Icon) internally; no additional configuration is needed.
- The upgrade URL is hardcoded to `https://fleetdm.com/upgrade` and opens in a new tab.
- Accepts an optional `className` prop merged via `classnames` for layout-level customization without overriding internal styles.
