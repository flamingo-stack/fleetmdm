Wraps UI elements with a tooltip explaining GitOps mode restrictions, conditionally disabling children and showing a repository-linked tooltip when GitOps mode is active.

## Key Components

- **`GitOpsModeTooltipWrapper`** — Default export. Renders children normally when GitOps mode is inactive; when active, wraps them in a `TooltipWrapper` with a contextual message and disables the children.
- **`IGitOpsModeTooltipWrapper`** — Props interface defining the wrapper's configuration.
- **`useGitOpsMode(entityType?)`** — Hook that returns `gitOpsModeEnabled` and `repoURL`, optionally scoped to a specific entity type exception.
- **`getGitOpsModeTipContent(repoURL)`** — Utility that builds the tooltip body content linking to the GitOps repository.

### Props

| Prop | Type | Description |
|---|---|---|
| `renderChildren` | `(disabled?) => ReactNode` | Render function; receives `true` when GitOps mode disables the element |
| `entityType` | `keyof IGitOpsExceptions` | Optional — if the entity is excepted from GitOps, children stay enabled |
| `position` | `ITooltipWrapper["position"]` | Tooltip position, defaults to `"top"` |
| `isInputField` | `boolean` | Adds full-width modifier for block-level form elements |
| `tipOffset` | `ITooltipWrapper["tipOffset"]` | Adjusts tooltip offset |
| `fixedPositionStrategy` | `ITooltipWrapper["fixedPositionStrategy"]` | Controls positioning strategy |

## Usage Example

```typescript
<GitOpsModeTooltipWrapper
  entityType="teams"
  isInputField
  position="top"
  renderChildren={(disabled) => (
    <input
      type="text"
      disabled={disabled}
      placeholder="Team name"
    />
  )}
/>
```

When GitOps mode is enabled and the entity is not excepted, the input is disabled and a tooltip linking to the configured repository URL is displayed.
