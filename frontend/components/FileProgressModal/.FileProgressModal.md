Renders a non-dismissible modal displaying file upload progress for software addition workflows.

## Key Components

- **`FileProgressModal`** — Default export. A locked modal (`disableClosingModal`) that wraps `FileDetails` inside a grey `Card` to show real-time upload progress.

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `graphicNames` | `ISupportedGraphicNames \| ISupportedGraphicNames[]` | `"file-pkg"` | Icon(s) displayed alongside file info |
| `fileDetails` | `IFileDetails` | — | File metadata (name, size, etc.) |
| `fileProgress` | `number` | — | Upload progress value (0–100) |

## Usage Example

```typescript
import FileProgressModal from "components/FileProgressModal";

<FileProgressModal
  fileDetails={{ name: "my-app.pkg", size: 1024000 }}
  fileProgress={42}
  graphicNames="file-pkg"
/>
```

## Notes

- The modal title is hardcoded as `"Add software"` and cannot be overridden.
- `onExit` is intentionally set to `noop` — the modal cannot be closed by the user while upload is in progress (`disableClosingModal`).
