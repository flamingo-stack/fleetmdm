A React class component that renders an Ace editor configured for YAML syntax, with form field label support and error state handling.

## Key Components

- **`YamlAce`** — Class component wrapping `react-ace`'s `AceEditor` with YAML mode, the `fleet` theme, and form field conventions.
- **`onLoadHandler`** — Registers an `Escape` key command on the editor instance so keyboard users can blur the editor and continue tabbing through the page.
- **`renderLabel`** — Renders a `<label>` that displays either an error message or the standard label text, applying error styling via `classnames`.

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `onChange` | `func` | ✅ | Called on editor content change |
| `value` | `string` | — | Controlled editor content |
| `name` | `string` | — | Editor `id` / `name` |
| `label` | `string` | — | Field label text |
| `error` | `string` | — | Error message; replaces label and applies error styles |
| `wrapperClassName` | `string` | — | Extra class on the wrapper `<div>` |
| `disabled` | `bool` | — | Sets `readOnly` and hides the gutter |

## Usage Example

```javascript
import YamlAce from "components/YamlAce";

<YamlAce
  name="config-yaml"
  label="Configuration (YAML)"
  value={yamlValue}
  onChange={(newValue) => setYamlValue(newValue)}
  error={validationError}
  wrapperClassName="my-custom-wrapper"
/>
```

## Notes

- The editor is capped between **2 and 17 lines** and stretches to `100%` width.
- Tab size is set to **2 spaces**.
