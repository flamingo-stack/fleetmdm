Storybook stories for the `YamlAce` component, showcasing a YAML-focused Ace editor in default and error states.

## Key Components

- **`meta`** — Storybook metadata registering `YamlAce` under `Components/YamlAce` with shared default args (a sample Kubernetes Pod manifest and a no-op `onChange` handler)
- **`Basic`** — Renders the editor with only the default YAML value and change handler
- **`WithError`** — Renders the editor with an inline error message (`"This is an error"`)

## Usage Example

```typescript
import YamlAce from "./YamlAce";

<YamlAce
  value={`apiVersion: v1\nkind: Pod`}
  onChange={(newValue) => console.log(newValue)}
  error="Invalid YAML syntax"
/>
```

## Notes

- The component is imported with `@ts-ignore` due to missing type declarations on the default export
- The sample YAML (`TEST_YAML`) represents a minimal Kubernetes Pod spec and serves as a realistic default for all stories
- Both stories inherit `value` and `onChange` from `meta.args`; `WithError` extends with an `error` prop
