Renders the "Add hosts" modal, orchestrating enrollment secret validation, TLS certificate fetching, and platform-specific onboarding instructions for adding hosts to a Fleet team or the global organization.

## Key Components

- **`IAddHostsModal`** – Props interface defining team context, enrollment secret, loading state, and callback handlers
- **`AddHostsModal`** – Default export; modal shell that conditionally renders a spinner, an error/empty state, or the `PlatformWrapper` with full enrollment details
- **`certificate` query** – Uses `react-query` to fetch the Fleet TLS certificate via `configAPI.loadCertificate()`; skipped in preview mode
- **`renderModalContent()`** – Internal renderer that handles three states: loading, missing enroll secret (with optional manage-secrets CTA), and the fully populated `PlatformWrapper`
- **`PlatformWrapper`** – Child component receiving the resolved certificate, enroll secret, and config for rendering platform-specific host enrollment instructions

## Usage Example

```typescript
import AddHostsModal from "pages/hosts/AddHostsModal";

<AddHostsModal
  currentTeamName="Engineering"
  enrollSecret="abc123xyz"
  isAnyTeamSelected={true}
  isLoading={false}
  onCancel={() => setShowAddHostsModal(false)}
  openEnrollSecretModal={() => setShowEnrollSecretModal(true)}
/>
```

## Notes

- When `enrollSecret` is absent, the modal surfaces a `DataError` with an inline link to open the enroll secrets manager (if `openEnrollSecretModal` is provided)
- `teamDisplayName` falls back to `"Fleet"` when no team is selected, ensuring the error message is always contextually accurate
- Certificate fetching is disabled (`enabled: !isPreviewMode`) in preview/demo environments to avoid unnecessary API calls
