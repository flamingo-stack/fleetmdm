Renders the Android MDM enrollment panel, providing a URL input field and enrollment type selection for adding Android devices to Fleet MDM.

## Key Components

- **`AndroidPanel`** – Main React component that displays Android enrollment options and generates an enrollment URL
- **`generateUrl`** – Utility function that constructs the enrollment URL from server URL, enroll secret, and enrollment type
- **`EnrollmentType`** – Union type (`"workProfile" | "fullyManaged"`) representing the two supported Android enrollment modes
- **`IAndroidPanelProps`** – Component props interface requiring an `enrollSecret` string

## Behavior

- If Android MDM is not enabled/configured, renders a prompt linking to [`PATHS.ADMIN_INTEGRATIONS_MDM_ANDROID`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/router/paths.ts) with a call to action
- When enabled, renders radio buttons for enrollment type selection and a read-only, copyable enrollment URL field

## Usage Example

```typescript
import AndroidPanel from "./AndroidPanel";

// Inside a parent enrollment flow component
<AndroidPanel enrollSecret="your-enroll-secret-here" />
```

The generated URL follows this format:

```text
# Work profile
https://<server_url>/enroll?enroll_secret=<secret>

# Fully managed
https://<server_url>/enroll?enroll_secret=<secret>&fully_managed=true
```

## Dependencies

| Dependency | Purpose |
|---|---|
| `AppContext` | Reads `config.server_settings.server_url` and `isAndroidMdmEnabledAndConfigured` |
| `Radio` | Enrollment type selection UI |
| `InputField` | Displays the generated enrollment URL with copy support |
| `CustomLink` | Link to Android MDM setup when not yet configured |
