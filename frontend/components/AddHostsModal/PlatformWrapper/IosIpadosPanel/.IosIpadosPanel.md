Renders the iOS/iPadOS MDM enrollment panel, displaying a copyable enrollment URL for end users or a prompt to enable Apple MDM if not yet configured.

## Key Components

- **`generateUrl(serverUrl, enrollSecret)`** – Constructs the enrollment URL by combining the Fleet server URL with a URL-encoded enroll secret.
- **`IosIpadosPanel`** – Main component that conditionally renders either an MDM setup prompt or a read-only, copyable enrollment link field.
- **`AppContext`** – Consumed for `config` (server settings) and `isMacMdmEnabledAndConfigured` (MDM state guard).

## Usage Example

```typescript
import IosIpadosPanel from "components/IosIpadosPanel";

<IosIpadosPanel enrollSecret="my-secret-token" />
```

**Render behavior:**

| Condition | Output |
|---|---|
| `config` is null | Returns `null` |
| Apple MDM not enabled | Link to enable Apple MDM settings |
| Apple MDM enabled | Copyable enrollment URL input field |

The generated URL follows the format:

```text
https://<server_url>/enroll?enroll_secret=<encoded_secret>
```

## Notes

- The component is display-only; the input field is `readOnly` with copy support via `enableCopy`.
- Enrollment URL is derived from `config.server_settings.server_url` at render time.
- The MDM setup redirect points to `PATHS.ADMIN_INTEGRATIONS_MDM_APPLE`.
