Renders a multi-platform tabbed enrollment UI for adding hosts to Fleet MDM, providing platform-specific installer commands, configuration files, and enrollment credentials for download.

## Key Components

- **`PlatformWrapper`** – Main component that renders a tabbed interface across 7 platform types: macOS, Windows, Linux, ChromeOS, iOS & iPadOS, Android, and Advanced
- **`platformSubNav`** – Static configuration array defining tab names and their associated package types
- **`renderPanel(packageType)`** – Dispatches to the correct platform-specific UI (ChromeOS fields, `IosIpadosPanel`, `AndroidPanel`, or installer command input)
- **`renderInstallerString(packageType)`** – Builds the `fleetctl package` CLI command string dynamically from config, enroll secret, and host type
- **`renderFleetCertificateBlock(type)`** – Renders the Fleet TLS certificate download block in either plain or tooltip-annotated form
- **`flagfileContent`** – Pre-built osquery flagfile string for plain osquery enrollment, using the server's TLS hostname
- Download handlers: **`onDownloadEnrollSecret`**, **`onDownloadFlagfile`**, **`onDownloadCertificate`** – Use `file-saver` to trigger browser file downloads

## Usage Example

```typescript
import PlatformWrapper from "components/PlatformWrapper";

<PlatformWrapper
  enrollSecret="abc123secret"
  onCancel={() => setShowModal(false)}
  certificate={pemCertificateString}
  isFetchingCertificate={false}
  fetchCertificateError={null}
  config={fleetConfig}
/>
```

## Notes

- Host type toggle (`"workstation"` | `"server"`) controls whether `--fleet-desktop` is included in the installer command
- The Advanced tab supports a "Plain osquery" reveal for manual flagfile + certificate enrollment
- ChromeOS enrollment uses a fixed extension ID (`fleeedmmihkfkeemmipgmhhjemlljidg`) with dynamic policy JSON
