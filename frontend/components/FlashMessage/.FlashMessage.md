Renders transient or persistent notification banners (success, error, warning) for the Fleet MDM UI, supporting both single and multiple simultaneous flash messages.

## Key Components

- **`FlashMessage`** — Main exported component. Accepts a single `INotification` or an array of up to 5, delegating each to `SingleFlashMessage`.
- **`SingleFlashMessage`** — Internal component that handles per-notification display logic, including auto-dismiss and page-change hiding.
- **`IFlashMessage`** — Props interface defining `notification`, `fullWidth`, `isPersistent`, `className`, `onRemoveFlash`, and `pathname`.

### Behaviors

| Behavior | Details |
|---|---|
| Auto-dismiss | Success alerts hide after 4 seconds (unless `isPersistent`) |
| Page navigation | Non-persistent alerts hide on `pathname` change |
| Batch limit | Array notifications capped at 5 displayed at once |
| Manual dismiss | Close button calls `onRemoveFlash(id)` for targeted removal |

## Usage Example

```typescript
import FlashMessage from "components/FlashMessage/FlashMessage";

// Single notification
<FlashMessage
  fullWidth={false}
  notification={{ id: "1", alertType: "success", isVisible: true, message: "Saved!" }}
  onRemoveFlash={(id) => dispatch(removeNotification(id))}
  pathname={location.pathname}
/>

// Multiple notifications
<FlashMessage
  fullWidth
  notification={[
    { id: "1", alertType: "error", isVisible: true, message: "Deploy failed." },
    { id: "2", alertType: "success", isVisible: true, message: "Policy updated." },
  ]}
  isPersistent
  onRemoveFlash={(id) => dispatch(removeNotification(id))}
  pathname={location.pathname}
/>
```
