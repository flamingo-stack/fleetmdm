Storybook stories file for the `FlashMessage` component, providing interactive documentation and visual testing configurations in Storybook.

## Key Components

- **`meta`** — Storybook metadata configuration defining component title (`Components/FlashMessage`), available controls (`fullWidth`, `isPersistent`), and default args including a sample success notification
- **`Default`** — Base story rendering `FlashMessage` with default props (full-width, persistent, visible success message)

## Usage Example

```typescript
// Extend or override the Default story for custom scenarios
import { Default } from "./FlashMessage.stories";

const ErrorStory: Story = {
  args: {
    ...Default.args,
    notification: {
      message: "Something went wrong!",
      alertType: "error",
      isVisible: true,
    },
    isPersistent: false,
  },
};
```

## Default Args

| Prop | Default Value |
|------|--------------|
| `fullWidth` | `true` |
| `isPersistent` | `true` |
| `notification.alertType` | `"success"` |
| `notification.isVisible` | `true` |
