Test suite for the `IconStatusMessage` component, verifying rendering behavior for icon display, message content, and custom prop application.

## Key Components

- **`renders with icon and message`** — Confirms the icon wrapper (`.icon-status-message__icon`), the icon element (`success-icon` test ID), and message content are all rendered when `iconName` and `iconColor` are provided.
- **`does not render icon when iconName is not provided`** — Asserts the icon container is absent and only the message content renders.
- **`applies custom className and testId when provided`** — Validates that both the default `icon-status-message` class and any additional `className` are applied to the root element, and that a custom `testId` is queryable.

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import IconStatusMessage from "./IconStatusMessage";

// Render with icon
render(
  <IconStatusMessage
    message="Operation successful"
    iconName="success"
    iconColor="core-fleet-green"
  />
);

// Render without icon
render(<IconStatusMessage message="No icon displayed" />);

// Render with custom class and testId
render(
  <IconStatusMessage
    message="Custom styled"
    className="extra-style"
    testId="status-msg"
  />
);
```

## Notes

- Uses `@testing-library/react` (`render`, `screen`) for DOM assertions.
- Icon presence is determined by querying `.icon-status-message__icon`; absence is verified with a `toBeNull()` check.
- The root element always carries the `icon-status-message` base class regardless of additional props.
