A reusable React component that displays a status message optionally accompanied by an icon, used for communicating contextual feedback or state to users.

## Key Components

- **`IconStatusMessage`** – Default export. A presentational component that renders a message with an optional leading icon.
- **`IconStatusMessageProps`** – Interface defining the component's props:
  - `message` *(required)* – The content to display, accepts any `ReactNode`
  - `iconName` *(optional)* – Icon identifier from the shared `IconNames` type
  - `iconColor` *(optional)* – Icon color token from the `Colors` design system
  - `className` *(optional)* – Additional CSS class names for the root element
  - `testId` *(optional)* – `data-testid` attribute for test targeting

## Usage Example

```typescript
import IconStatusMessage from "components/IconStatusMessage/IconStatusMessage";

// With icon
<IconStatusMessage
  iconName="success"
  iconColor="ui-fleet-black-75"
  message="Configuration saved successfully."
  testId="save-status"
/>

// Message only
<IconStatusMessage
  message={<span>No devices found matching your filters.</span>}
  className="custom-status"
/>
```

## Notes

- The icon is conditionally rendered — if `iconName` is omitted, only the message content is displayed.
- Styling is managed via BEM-style class names (`icon-status-message`, `icon-status-message__icon`, `icon-status-message__content`) composed with `classnames`.
