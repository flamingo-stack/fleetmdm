Storybook stories file for the `IconStatusMessage` component, providing an interactive playground for exploring its icon, color, and message props in the Storybook UI.

## Key Components

- **`meta`** — Storybook metadata configuration defining controls for `message`, `iconName`, `iconColor`, `className`, and `testId` props
- **`Playground`** — Default interactive story pre-configured with a success icon, green color, and rich-text message demonstrating JSX content support

## Usage Example

```typescript
// Render the Playground story directly in Storybook
import { Playground } from "./IconStatusMessage.stories";

// Or use the component standalone with equivalent props
import IconStatusMessage from ".";

<IconStatusMessage
  message={<>Your <b>system update</b> was completed successfully.</>}
  iconName="success"
  iconColor="core-fleet-green"
  testId="icon-status-playground"
/>
```

**Available `iconName` options:** `success`, `success-outline`, `error`, `error-outline`, `info`

**Available `iconColor` options:** `core-fleet-green`, `core-fleet-black`, `ui-fleet-black-75`, `status-success`, `status-error`

## Notes

- The `message` prop accepts both plain strings and JSX/React nodes, enabling rich text formatting
- All controls are exposed via Storybook's expanded controls panel for interactive testing
