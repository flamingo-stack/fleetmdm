Renders plain text with URLs automatically converted to clickable anchor links, sanitizing the HTML output to prevent XSS attacks.

## Key Components

- **`IClickableUrls`** — Interface with `text` (required) and optional `className` props
- **`urlReplacer`** — Transforms matched URL strings into `<a>` tags with `target="_blank"` and `rel="noreferrer"`; prepends `https://` if no protocol is present
- **`ClickableUrls`** — Main component that applies regex-based URL detection, sanitizes the result via DOMPurify, and renders via `dangerouslySetInnerHTML`

## Usage Example

```typescript
import ClickableUrls from "./ClickableUrls";

// Basic usage
<ClickableUrls text="Visit https://flamingo.run for more info." />

// With custom class
<ClickableUrls
  text="Check out www.openframe.ai or http://example.com"
  className="my-custom-class"
/>
```

**Supported URL formats:**
- `https://example.com`
- `http://example.com`
- `www.example.com` (protocol auto-prefixed to `https://`)

## Security Notes

- Output is passed through **DOMPurify** before rendering, stripping any malicious HTML
- The `target` attribute is explicitly allowlisted so links open in a new tab
- The `rel="noreferrer"` attribute is added to all generated links to prevent referrer leakage
