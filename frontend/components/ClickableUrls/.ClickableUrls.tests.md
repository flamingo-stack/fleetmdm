Test suite for the `ClickableUrls` React component, verifying that URLs embedded in plain text are correctly parsed and rendered as accessible anchor elements.

## Key Components

- **`describe("ClickableUrls - component")`** — Top-level test suite grouping all `ClickableUrls` tests
- **`it("renders text and icon")`** — Asserts that multiple URLs within a mixed text string are each rendered as accessible links with correct `href` and `target="_blank"` attributes

## Usage Example

```typescript
// Renders a string containing mixed prose and URLs;
// each URL should appear as a clickable anchor.
render(<ClickableUrls text={TEXT_WITH_URLS} />);

const link1 = screen.getByRole("link", { name: URL_1 });
expect(link1).toHaveAttribute("href", URL_1);
expect(link1).toHaveAttribute("target", "_blank");
```

## Test Coverage

| Scenario | Assertion |
|---|---|
| Multiple URLs in a single string | Both links are rendered and accessible by role |
| Correct `href` attribute | Each link points to its respective URL |
| Opens in new tab | Each link has `target="_blank"` |

## Notes

- Uses [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) for rendering and querying
- Queries use `getByRole("link")` to validate semantic accessibility of rendered anchors
