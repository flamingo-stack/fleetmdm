Storybook stories file for the `ListItem` component, providing visual documentation and interactive playground configurations for Storybook.

## Key Components

- **`meta`** – Storybook metadata configuration registering `ListItem` under `Components/ListItem` with default args (graphic, title, details, actions)
- **`Basic`** – Default story rendering `ListItem` with a configuration profile graphic, sample title, inline detail spans, and two action buttons

## Usage Example

```typescript
import { Basic } from "components/ListItem/ListItem.stories";

// Rendered in Storybook with default args:
// - graphic: "file-configuration-profile"
// - title: "List Item Title"
// - details: <span>Details</span> • <span>more details</span>
// - actions: <Button>button 1</Button> <Button>Button 2</Button>
```

To add a new story variant:

```typescript
export const WithoutActions: Story = {
  args: {
    actions: undefined,
  },
};
```

## Notes

- Stories rely on default args defined in `meta`, so individual stories like `Basic` require no additional configuration
- The `details` and `actions` props accept arbitrary JSX, enabling flexible compositional testing in Storybook
