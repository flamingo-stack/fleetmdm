A generic, reusable list item component that encapsulates UI layout for displaying a graphic, title, details, and actions in a consistent structure.

## Key Components

### `ISupportedGraphicNames`
A TypeScript utility type that restricts the allowed graphic names to a specific subset of `GraphicNames`, covering file-type icons (e.g., `file-sh`, `file-pdf`, `file-pkg`, `file-certificate`).

### `IListItemProps`
| Prop | Type | Description |
|------|------|-------------|
| `graphic` | `ISupportedGraphicNames` | Optional file-type graphic icon |
| `title` | `string \| JSX.Element` | Required title content |
| `details` | `React.ReactNode` | Optional detail content rendered below the title |
| `actions` | `React.ReactNode` | Optional action elements (buttons, links) rendered to the right |
| `onClick` | `() => void` | Optional click handler for the entire item |
| `className` | `string` | Optional additional CSS class |

### `ListItem` (default export)
A functional component that renders a structured `div` layout with distinct slots for a graphic, info block, and actions area.

## Usage Example

```typescript
import ListItem from "components/ListItem";

<ListItem
  graphic="file-pdf"
  title="Annual Security Report"
  details={<span>Uploaded 2024-01-15</span>}
  actions={
    <button onClick={handleDelete}>Remove</button>
  }
  onClick={() => console.log("Item clicked")}
/>
```
