A reusable UI tag component that renders an icon alongside a text label, optionally as an interactive button for keyboard-accessible click handling.

## Key Components

### `ITagProps`
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `icon` | `IconNames` | ✅ | Icon to display within the tag |
| `text` | `string` | ✅ | Label text rendered beside the icon |
| `className` | `string` | ❌ | Additional CSS class names |
| `onClick` | `() => void` | ❌ | Click handler; renders a `<button>` when provided |

### `Tag`
Default export. Conditionally renders as a `<button>` (when `onClick` is provided) or a `<div>`, ensuring keyboard accessibility for interactive tags. Applies the `tag__clickable-tag` modifier class automatically when clickable.

## Usage Example

```typescript
import Tag from "components/Tag";

// Static (non-interactive) tag
<Tag icon="label" text="macOS" />

// Clickable tag (renders as <button> for keyboard access)
<Tag
  icon="filter"
  text="Filter by platform"
  onClick={() => handleFilterClick()}
  className="my-custom-tag"
/>
```

## Notes

- When `onClick` is provided, the component renders a `<button>` element instead of a `<div>`, enabling native keyboard focus and activation (Enter/Space).
- The icon is always rendered at `"small"` size with color `"ui-fleet-black-75"`.
- Class composition uses `classnames` to merge base, custom, and state-based classes cleanly.
