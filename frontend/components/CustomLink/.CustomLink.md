A reusable anchor link component that renders styled hyperlinks with optional external link icons, multiline text handling, and variant-based styling for different UI contexts.

## Key Components

### `ICustomLinkProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `url` | `string` | — | The href target URL |
| `text` | `string` | — | Link display text |
| `newTab` | `boolean` | `false` | Opens link in a new tab with an external icon |
| `multiline` | `boolean` | `false` | Wraps the external icon with the last word to prevent orphaned icons |
| `disableKeyboardNavigation` | `boolean` | `false` | Sets `tabIndex=-1` when inside disabled UI |
| `variant` | `"default" \| "tooltip-link" \| "banner-link" \| "flash-message-link"` | `"default"` | Controls icon color and CSS class modifier |

### `CustomLink`
The default export. Renders an `<a>` tag with:
- **`getIconColor()`** — maps `variant` to a `Colors` token for the external link icon
- **`handleClick()`** — calls `e.stopPropagation()` to prevent triggering parent click handlers (e.g., table row/cell handlers)
- **Multiline mode** — splits text at the last space so the icon always stays inline with the final word

## Usage Example

```typescript
// Basic external link
<CustomLink url="https://fleetdm.com" text="Fleet Docs" newTab />

// Inside a tooltip with multiline text and keyboard nav disabled
<CustomLink
  url="https://fleetdm.com/docs"
  text="Learn more about this feature"
  variant="tooltip-link"
  newTab
  multiline
  disableKeyboardNavigation
/>

// Banner context
<CustomLink
  url="/upgrade"
  text="Upgrade your plan"
  variant="banner-link"
  className="my-banner-link"
/>
```

## Notes

- Always renders `rel="noopener noreferrer"` on `_blank` links for security.
- The external link icon is only shown when `newTab={true}`.
