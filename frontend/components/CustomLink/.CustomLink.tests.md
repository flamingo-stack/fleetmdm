Test suite for the `CustomLink` component, verifying rendering behavior for same-tab and new-tab link variants.

## Key Components

- **`CustomLink - component`** — Top-level `describe` block containing two test cases for the `CustomLink` component.
  - **`renders text, link in same tab, and no icon`** — Asserts that the component renders the link text, applies the correct `href`, opens in the same tab (no `target="_blank"`), and omits the external icon by default.
  - **`renders icon and link in new tab if newTab is set`** — Asserts that when the `newTab` prop is provided, an external link icon is rendered and the anchor element carries `target="_blank"`.

## Usage Example

```typescript
// Running the tests
// From the repository root:
// npx jest CustomLink.tests.tsx

// Example assertions exercised by these tests:
render(
  <CustomLink
    url="https://github.com/fleetdm/fleet/issues/new/choose"
    text="file an issue"
  />
);
// Same-tab: no icon, no target="_blank"

render(
  <CustomLink
    url="https://github.com/fleetdm/fleet/issues/new/choose"
    text="file an issue"
    newTab
  />
);
// New-tab: external-link-icon present, target="_blank" set
```

- Uses [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) for rendering and DOM queries.
