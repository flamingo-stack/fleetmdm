Storybook stories for the `CustomLink` component, demonstrating all supported variants, behaviors, and contextual usage patterns.

## Key Components

| Export | Description |
|--------|-------------|
| `Basic` | Default inline link with URL and text |
| `ExternalLink` | Opens in a new tab via `newTab: true` |
| `Multiline` | Wraps across lines with icon anchored to last word |
| `TooltipVariant` | Link styled for use inside `TooltipWrapper` |
| `BannerVariant` | Link styled for use inside `InfoBanner` |
| `FlashMessageVariant` | Link styled for flash/toast messages |
| `DisabledKeyboardNav` | Link with keyboard navigation disabled |

## Usage Example

```typescript
// Basic link
<CustomLink url="https://www.google.com" text="Test Link" />

// External link (opens new tab)
<CustomLink url="https://www.google.com" text="External" newTab />

// Multiline with icon anchored to last word
<CustomLink
  url="https://www.google.com"
  text="A long link that spans multiple lines"
  multiline
  newTab
/>

// Tooltip context
<CustomLink
  url="https://www.google.com"
  text="Tooltip link"
  variant="tooltip-link"
  newTab
/>

// Disable keyboard navigation (e.g. inside a disabled parent)
<CustomLink
  url="https://www.google.com"
  text="No tab focus"
  disableKeyboardNavigation
/>
```

## Supported Variants

- `tooltip-link` — styled for tooltip interiors
- `banner-link` — styled for `InfoBanner` context
- `flash-message-link` — styled for flash/toast notifications
