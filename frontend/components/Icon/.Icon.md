A generic icon wrapper component that renders any icon from the application's icon registry, applying optional color, size, and className customizations.

## Key Components

- **`IIconProps`** — Interface defining the component's props:
  - `name` — Required. Key from `IconNames` used to look up the icon in `ICON_MAP`.
  - `color` — Optional. Typed color value from the `Colors` token set.
  - `size` — Optional. Typed size value from the `IconSizes` token set.
  - `className` — Optional. Additional CSS class(es) to apply to the wrapper `<div>`.

- **`Icon`** — Default export. Looks up the icon component via `ICON_MAP[name]`, constructs a props object (omitting `undefined` values via `useMemo`), and renders it inside a `<div>` with a `data-testid` attribute for testing.

## Usage Example

```typescript
import Icon from "components/Icon";

// Basic usage
<Icon name="trash" />

// With color and size tokens
<Icon
  name="check"
  color="core-fleet-blue"
  size="medium"
  className="status-icon"
/>
```

## Notes

- Only `color` and `size` props defined as non-`undefined` are forwarded to the underlying icon component, preventing unnecessary prop pollution.
- Each rendered icon includes a `data-testid` of `"<name>-icon"` (e.g., `"trash-icon"`), enabling straightforward test queries.
- The full icon registry and available `IconNames` are defined in [`components/icons`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons).
