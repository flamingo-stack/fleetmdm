Storybook stories for the `Icon` component, providing a basic interactive example for development and testing.

## Key Components

- **`meta`** — Storybook metadata configuring the story under `Components/Icon` with a default `name` prop of `"plus"`
- **`Basic`** — A single story rendering the `Icon` component with default args

## Usage Example

```typescript
// Extend with additional stories for different icon variants
export const Delete: Story = {
  args: { name: "delete" },
};

export const Check: Story = {
  args: { name: "check" },
};
```

## Notes

- Default story renders `<Icon name="plus" />`
- Add new named exports to showcase additional icon variants in the Storybook UI
