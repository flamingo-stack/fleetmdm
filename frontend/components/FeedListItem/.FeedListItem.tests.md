Unit tests for the `FeedListItem` component, verifying rendering behavior and user interactions for details, cancellation, and date display.

## Key Components

**Test Suite:** `FeedListItem`

**Default Props:**
- `useFleetAvatar: true`
- `createdAt: new Date("2024-01-01T12:00:00Z")`

**Test Cases Covered:**
- `allowShowDetails` — renders/hides the info outline icon
- `onClickFeedItem` — called when feed content is clicked (with `allowShowDetails`)
- `createdAt` — renders a relative date string (e.g. "X days ago")
- `allowCancel` — renders/hides the close icon
- `onClickCancel` — called via `fireEvent.click` on the cancel button
- `disableCancel` — disables the cancel button when `true`

## Usage Example

```typescript
// Rendering with details and cancel enabled
render(
  <FeedListItem
    useFleetAvatar
    createdAt={new Date()}
    allowShowDetails
    allowCancel
    onClickFeedItem={() => console.log("item clicked")}
    onClickCancel={() => console.log("cancel clicked")}
  >
    Feed item content
  </FeedListItem>
);
```

## Notes

- Uses `renderWithSetup` from `test/test-utils` for tests requiring `userEvent` (pointer interactions).
- The cancel icon click uses `fireEvent.click` instead of `userEvent.click` due to hover-dependent visibility of the icon — see inline comment.
- Date rendering is validated loosely by checking for `/ago/i` text, accommodating any relative date format returned by the `dateAgo` utility.
