A reusable React component that renders a single item in an activity/event feed list, displaying an avatar, timestamp, content, and optional action buttons.

## Key Components

### `FeedListItem` (default export)
Renders a feed entry with:
- **Avatar** — supports Gravatar URLs, Fleet-branded avatars, or API-only avatars
- **Timestamp** — shows relative time (e.g., "2 hours ago") with a tooltip displaying the full international format
- **Children** — arbitrary content rendered as the item's main description
- **Action buttons** — optional info/details and cancel buttons

### `IFeedListItemProps`
| Prop | Type | Description |
|------|------|-------------|
| `children` | `ReactNode` | Main feed item content |
| `useFleetAvatar` | `boolean` | Use Fleet branded avatar |
| `createdAt` | `Date` | Timestamp for relative/absolute display |
| `gravatarURL` | `string` | Optional Gravatar image URL |
| `allowShowDetails` | `boolean` | Enables the info button and click handler |
| `allowCancel` | `boolean` | Shows the cancel/close button |
| `disableCancel` | `boolean` | Disables the cancel button |
| `isSoloItem` | `boolean` | Applies solo-item styling modifier |
| `onClickFeedItem` | `MouseEventHandler` | Callback when item is clicked |
| `onClickCancel` | `MouseEventHandler` | Callback when cancel is clicked |

## Usage Example

```typescript
import FeedListItem from "components/FeedListItem";

<FeedListItem
  useFleetAvatar={false}
  createdAt={new Date("2024-01-15T10:30:00Z")}
  gravatarURL="https://gravatar.com/avatar/abc123"
  allowShowDetails
  allowCancel
  onClickFeedItem={(e) => console.log("Item clicked", e)}
  onClickCancel={(e) => console.log("Cancelled", e)}
>
  User <strong>jane@example.com</strong> enrolled a new device.
</FeedListItem>
```
