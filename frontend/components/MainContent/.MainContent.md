Renders the main content region of the application, managing layout, className composition, and app-wide banner display with priority-ordered notification banners sourced from `AppContext`.

## Key Components

### `MainContent`
Default export. A layout wrapper component that:
- Composes CSS classes via `classnames`
- Evaluates and renders at most one priority-ordered app-wide banner
- Supports both static `ReactNode` children and a render-prop pattern via `IMainContentConfig`

### `IMainContentConfig`
Interface passed to children when the render-prop pattern is used.

| Property | Type | Description |
|---|---|---|
| `renderedBanner` | `boolean` | Whether an app-wide banner is currently displayed |

### Banner Priority Order
Only one banner renders at a time, evaluated in this order:

1. **APNs expiry** — all tiers
2. **Android Enterprise deleted** — premium only
3. **Apple Business Manager expiry** — premium only
4. **ABM Terms renewal** — premium only
5. **VPP expiry** — premium only
6. **Fleet license expiry** — premium only

## Usage Example

```typescript
// Static children
<MainContent className="my-page">
  <PageContent />
</MainContent>

// Render-prop pattern — adjust layout based on banner presence
<MainContent className="my-page">
  {({ renderedBanner }) => (
    <PageContent offsetTop={renderedBanner} />
  )}
</MainContent>
```
