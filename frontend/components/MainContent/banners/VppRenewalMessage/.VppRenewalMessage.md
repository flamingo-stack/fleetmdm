A React component that displays a warning banner when a Fleet VPP (Volume Purchasing Program) content token is expired or nearing expiration.

## Key Components

- **`VppRenewalMessage`** — Default export. Renders a yellow `InfoBanner` with a contextual message and a "Renew VPP" link based on token status.
- **`IVppRenewalMessageProps`** — Props interface with a single `expired: boolean` flag that controls the displayed message.

## Usage Example

```typescript
// Token already expired
<VppRenewalMessage expired={true} />

// Token expiring within 30 days
<VppRenewalMessage expired={false} />
```

## Behavior

| `expired` | Message shown |
|-----------|--------------|
| `true` | Token has expired; App Store apps cannot be added or installed |
| `false` | Token expires in <30 days; warns before functionality is lost |

Both states render a CTA linking to `/settings/integrations/mdm/vpp` for admin renewal.
