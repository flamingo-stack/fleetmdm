A generic, reusable list component that renders an array of items with optional heading support, designed for upload-related UI flows.

## Key Components

### `IUploadListProps<T>`
Generic interface defining the component's props:
- `keyAttribute` — optional key for React list rendering (required when `T` is not a primitive)
- `listItems` — array of items to render
- `HeadingComponent` — optional header rendered above the list
- `ListItemComponent` — required render component for each list item
- `className` — optional additional CSS class

### `UploadList<T>`
A generic functional component that maps `listItems` to `<li>` elements, each rendered via `ListItemComponent`. Conditionally renders a `HeadingComponent` header when provided.

## Usage Example

```typescript
import UploadList from "components/UploadList";

interface IFile {
  id: number;
  name: string;
}

const FileRow = ({ listItem }: { listItem: IFile }) => (
  <span style={{ flex: 1, minWidth: 0 }}>{listItem.name}</span>
);

const HeadingRow = () => <h4>Uploaded Files</h4>;

// In your component:
<UploadList<IFile>
  keyAttribute="id"
  listItems={files}
  HeadingComponent={HeadingRow}
  ListItemComponent={FileRow}
  className="my-upload-list"
/>
```

> **Note:** If `ListItemComponent` renders user-typed text (names, labels, descriptions), wrap it in `<TooltipTruncatedText />` and apply `flex: 1; min-width: 0` to its container to handle overflow correctly.
