Registers a custom ACE editor theme named "fleet" by defining an ACE module that loads and applies associated CSS styles to the editor.

## Key Components

- **`ace.define`** — Registers the `ace/theme/fleet` module with the ACE editor framework
- **`exports.isDark`** — Declares the theme as a light theme (`false`)
- **`exports.cssClass`** — Sets the CSS class identifier to `"ace-fleet"`
- **`exports.cssText`** — Loads theme styles from the co-located `theme.css` file
- **`dom.importCssString`** — Injects the CSS into the DOM under the `ace-fleet` class scope

## Usage Example

```typescript
// Apply the fleet theme to an ACE editor instance
import "./theme"; // registers ace/theme/fleet

const editor = ace.edit("editor-container");
editor.setTheme("ace/theme/fleet");
```

## Notes

- This file is part of a custom ACE editor theme and must be used alongside [`theme.css`](https://github.com/flamingo-stack/fleetmdm/blob/main/theme.css) in the same directory.
- The `/* eslint-disable */` and `// @ts-nocheck` directives suppress linting and TypeScript checks due to ACE's non-typed global `ace.define` API.
- No direct instantiation is needed — importing the file side-effectfully registers the theme with ACE's module system.
