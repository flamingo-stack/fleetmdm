Custom Ace editor mode for Fleet/osquery SQL syntax highlighting, extending the built-in SQL mode with osquery-specific table and column token recognition.

## Key Components

- **`FleetHighlightRules`** — Extends Ace's `SqlHighlightRules` with custom token mappings for:
  - `osquery-token` — osquery table names
  - `osquery-column` — osquery table column names
  - `support.function` — SQL built-in functions
  - `keyword` — SQL keywords
  - `constant.language` — boolean literals (`true`/`false`)
  - `storage.type` — SQL data types
- **`ace/mode/fleet`** — The registered Ace editor mode (`ace/mode/fleet`) that wires `FleetHighlightRules` into a complete mode with `--` line comment support.

## Usage Example

```typescript
import "path/to/mode"; // registers ace/mode/fleet and ace/mode/fleet_highlight_rules

// Use in any Ace editor instance
const editor = ace.edit("editor-container");
editor.session.setMode("ace/mode/fleet");
```

Once registered, the editor will highlight osquery table names, column names, SQL keywords, functions, data types, operators, strings, numbers, and comments using Fleet-specific CSS token classes (e.g., `.ace_osquery-token`, `.ace_osquery-column`).

## Notes

- Depends on [`utilities/osquery_tables`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/osquery_tables) for `osqueryTableNames` / `osqueryTableColumnNames`, and [`utilities/sql_tools`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/sql_tools) for `sqlKeyWords`, `sqlBuiltinFunctions`, and `sqlDataTypes`.
- Uses `ace.define` directly (not ES module exports), so the file must be imported as a side effect before referencing `"ace/mode/fleet"`.
