Storybook stories file for the `SQLEditor` component, defining default args and story variants for visual development and testing.

## Key Components

- **`meta`** – Storybook `Meta` configuration for `SQLEditor`, setting the component title (`Components/SQLEditor`) and default prop values
- **`Default`** – A single `StoryObj` export rendering `SQLEditor` with all default args applied

## Usage Example

```typescript
// Run Storybook to view this story interactively
// Default story renders SQLEditor with these props:
{
  label: "Type some SQL here...",
  value: "SELECT 1 FROM TABLE_NAME;",
  readOnly: false,
  showGutter: false,
  wrapEnabled: false,
  fontSize: 16,
}
```

## Default Args

| Prop | Default Value |
|---|---|
| `label` | `"Type some SQL here..."` |
| `value` | `"SELECT 1 FROM TABLE_NAME;"` |
| `readOnly` | `false` |
| `fontSize` | `16` |
| `showGutter` | `false` |
| `wrapEnabled` | `false` |
| `onChange` / `onLoad` / `handleSubmit` | `noop` |

## Notes

- All callback props (`onLoad`, `onChange`, `handleSubmit`) default to `noop` to safely prevent errors during isolated story rendering
- Global styles are imported via `../../index.scss` to ensure consistent theming in Storybook
