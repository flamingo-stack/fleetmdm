A SQL editor component built on `react-ace` with Fleet-specific syntax highlighting, osquery table/column autocompletion, and optional copy-to-clipboard functionality.

## Key Components

### `ISQLEditorProps`
Interface defining the editor's configuration options:
- `value` / `onChange` — controlled input pattern
- `readOnly` + `enableCopy` — renders a non-selectable editor with a copy button
- `error` / `label` / `helpText` — form field UX
- `handleSubmit` — bound to `Ctrl+Enter`
- `disabled` — disables interaction and applies visual state
- `labelActionComponent` — injects custom React node alongside the label

### `SQLEditor`
Main component rendering an `AceEditor` with:
- **Fleet custom mode/theme** (`./mode`, `./theme`)
- **Smart autocompletion** — SQL keywords, built-in functions, data types, osquery table names, and context-aware column suggestions derived from parsed table references in the current query
- **Hotfix overrides** — removes default `gotoline`/`find` shortcuts; adds `Esc` to blur editor for keyboard accessibility
- **`isReadonlyCopy` mode** — prevents text selection, removes keyboard focus from textarea, immediately blurs on focus events

## Usage Example

```typescript
import SQLEditor from "components/SQLEditor";

// Basic editable query editor
<SQLEditor
  label="Query"
  value={queryText}
  onChange={(val) => setQueryText(val)}
  handleSubmit={runQuery}
  error={queryError}
  helpText="Press Ctrl+Enter to run"
/>

// Read-only display with copy button
<SQLEditor
  value={savedQuery}
  readOnly
  enableCopy
  label="Saved Query"
  showGutter={false}
/>
```
