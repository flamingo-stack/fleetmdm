Unit test suite for the `DataSet` component, verifying rendering behavior, orientation modes, BEM modifier classes, and className merging.

## Key Components

### Test Suite: `DataSet`

| Test Case | Description |
|-----------|-------------|
| `renders title and value` | Confirms both `title` and `value` props render visible text |
| `vertical orientation (default)` | Asserts no `.data-set__horizontal` class and no colon appended to title |
| `horizontal orientation` | Verifies `.data-set__horizontal` class is applied and a colon is appended to the `<dt>` text |
| `textOnly modifier` | Checks `.data-set--text-only` BEM modifier is present when `textOnly` prop is set |
| `multiline modifier` | Checks `.data-set--multiline` BEM modifier is present when `multiline` prop is set |
| `multiline default` | Confirms `.data-set--multiline` is absent when prop is not passed |
| `custom className` | Ensures custom class merges with the base `data-set` class |

## Usage Example

```typescript
// Run the full suite
// npx jest DataSet.tests.tsx

// Example: testing horizontal orientation
render(<DataSet title="Author" value="Alice" orientation="horizontal" />);
expect(container.querySelector(".data-set__horizontal")).toBeInTheDocument();
expect(container.querySelector("dt")?.textContent).toBe("Author:");

// Example: testing BEM modifier props
render(<DataSet title="Resolve" value="Long text." multiline textOnly />);
expect(container.querySelector(".data-set--multiline")).toBeInTheDocument();
expect(container.querySelector(".data-set--text-only")).toBeInTheDocument();
```
