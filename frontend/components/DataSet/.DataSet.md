A reusable presentational component for rendering a labeled key-value pair using semantic HTML (`<dt>`/`<dd>`), supporting horizontal/vertical layouts and text-specific alignment modes.

## Key Components

### `IDataSetProps`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `React.ReactNode` | — | The label/key of the data pair |
| `value` | `React.ReactNode` | — | The displayed value |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | Layout direction |
| `textOnly` | `boolean` | `false` | Aligns by text baseline; use only when value contains text (not icons/buttons) |
| `multiline` | `boolean` | `false` | Allows value to wrap across lines instead of truncating with ellipsis |
| `className` | `string` | — | Additional CSS class override |

### `DataSet` (default export)

Renders a `<div>` wrapper containing a `<dt>` (title) and `<dd>` (value). Appends a colon after the title in horizontal orientation.

## Usage Example

```typescript
import DataSet from "./DataSet";

// Vertical (default)
<DataSet title="Status" value="Active" />

// Horizontal layout
<DataSet
  title="Assigned To"
  value="Jane Doe"
  orientation="horizontal"
/>

// Multiline prose value
<DataSet
  title="Description"
  value="This host requires manual review before deployment."
  multiline
/>

// Baseline-aligned text with tooltip
<DataSet
  title="Platform"
  value={<TooltipWrapper tipContent="macOS 14.x">macOS</TooltipWrapper>}
  textOnly
/>
```

## Notes

- `textOnly` and `multiline` are mutually exclusive in intent — `textOnly` optimizes baseline alignment for single-line text rows, while `multiline` removes truncation for prose content.
- The component does not include built-in truncation/tooltip logic; consumers are expected to wrap `value` in a tooltip-on-truncate helper when using default (single-line) mode.
