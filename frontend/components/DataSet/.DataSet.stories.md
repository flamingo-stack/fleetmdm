Storybook stories for the `DataSet` component, demonstrating its available display variants including basic, horizontal orientation, and multiline text rendering.

## Key Components

| Export | Description |
|--------|-------------|
| `Basic` | Default story with a simple title/value pair |
| `HorizontalOrientation` | Renders the component with `orientation: "horizontal"` |
| `Multiline` | Shows long-form prose that wraps instead of truncating, constrained to a 320px container |

## Usage Example

```typescript
// Basic usage
<DataSet title="Data set title" value="This is the value" />

// Horizontal layout
<DataSet
  title="Data set title"
  value="This is the value"
  orientation="horizontal"
/>

// Multiline (free-form prose, no ellipsis truncation)
<DataSet
  title="Resolve"
  value="Re-enable FileVault on the device. Open System Settings..."
  multiline
/>
```

## Notes

- The `Multiline` story wraps the component in a `320px` container to demonstrate text wrapping behavior — useful for fields like "Resolve" or "Description" that contain longer prose.
- Default args (`title` and `value`) are shared across all stories via the `meta.args` object.
