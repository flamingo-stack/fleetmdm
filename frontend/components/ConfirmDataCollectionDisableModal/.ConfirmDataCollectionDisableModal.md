A confirmation modal component that warns users before disabling historical data collection, displaying the affected datasets and an irreversible data deletion warning.

## Key Components

**`ConfirmDataCollectionDisableModal`** — Default export. A modal dialog rendered when a user attempts to disable one or more historical data collection datasets.

**`IConfirmDataCollectionDisableModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|------|------|-------------|
| `scope` | `"global" \| "fleet"` | Determines the warning heading context |
| `datasets` | `HistoricalDataConfigKey[]` | List of datasets to be disabled |
| `fleetName` | `string` (optional) | Fleet display name for fleet-scoped warnings |
| `isUpdating` | `boolean` (optional) | Disables modal content and shows loading state on confirm button |
| `onConfirm` | `() => void` | Callback fired when user confirms the action |
| `onCancel` | `() => void` | Callback fired when user cancels or exits the modal |

## Usage Example

```typescript
import ConfirmDataCollectionDisableModal from "components/ConfirmDataCollectionDisableModal";

<ConfirmDataCollectionDisableModal
  scope="fleet"
  datasets={["host_count", "labels_updated_at"]}
  fleetName="Engineering"
  isUpdating={isSaving}
  onConfirm={handleDisableConfirm}
  onCancel={() => setShowModal(false)}
/>
```

## Behavior Notes

- When `scope` is `"global"`, the heading references the entire Fleet deployment.
- When `scope` is `"fleet"`, the heading references the specific fleet by `fleetName`, falling back to `"this fleet"` if the name is not provided.
- Dataset names are rendered using the `DATASET_LABEL` map from `interfaces/charts`, displaying human-readable labels.
- The **"Save and disable"** confirm button enters a loading state while `isUpdating` is `true`, and the modal content is disabled to prevent interaction during the update.
