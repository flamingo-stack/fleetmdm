Test suite for the `ConfirmDataCollectionDisableModal` component, verifying rendering behavior, scope-based copy, and user interaction callbacks.

## Key Components

- **`renderModal`** — Helper that mounts `ConfirmDataCollectionDisableModal` with default props (`scope: "global"`, `datasets: ["uptime"]`) and accepts partial overrides; returns render utilities plus `onConfirm`/`onCancel` jest mocks.

## Test Cases

| Test | Description |
|---|---|
| `renders the dataset labels prominently` | Verifies human-readable labels ("Hosts online", "Vulnerability exposure") appear for given dataset keys |
| `uses global-scoped copy when scope is 'global'` | Confirms copy references "across this Fleet deployment" for global scope |
| `uses fleet-scoped copy referencing the fleet name when scope is 'fleet'` | Confirms the provided `fleetName` ("Engineering") appears in the modal body |
| `calls onConfirm when Save and disable is clicked` | Asserts `onConfirm` fires once on primary action button click |
| `calls onCancel when Cancel is clicked` | Asserts `onCancel` fires once on cancel button click |
