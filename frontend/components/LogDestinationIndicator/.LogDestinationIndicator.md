A React component that displays a human-readable label for a Fleet log destination type, optionally wrapped in a tooltip with contextual details about where report data is sent.

## Key Components

### `LogDestinationIndicator`
Default export. Renders a styled label for the active log destination with an optional `TooltipWrapper`.

**Props (`ILogDestinationIndicatorProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `logDestination` | `LogDestination` | The active log destination type |
| `webhookDestination` | `string?` | URL shown in the webhook tooltip |
| `filesystemDestination` | `string?` | Path shown in the filesystem tooltip |
| `excludeTooltip` | `boolean?` | Render label only, without tooltip (default: `false`) |

### `generateClassTag` (internal)
Converts a raw log destination string into a CSS-safe class tag. Returns `"indeterminate"` for empty/default cell values.

### `readableLogDestination` (internal)
Maps `LogDestination` enum values to human-readable strings (e.g., `"firehose"` → `"Amazon Kinesis Data Firehose"`).

### `tooltipText` (internal)
Returns JSX tooltip content describing where report data is sent for each destination type.

**Supported destinations:** `filesystem`, `firehose`, `kinesis`, `lambda`, `pubsub`, `kafka`, `nats`, `stdout`, `webhook`, `""` (not configured)

## Usage Example

```typescript
import LogDestinationIndicator from "components/LogDestinationIndicator/LogDestinationIndicator";

// With tooltip (default)
<LogDestinationIndicator
  logDestination="webhook"
  webhookDestination="https://my-server.example.com/logs"
/>

// Filesystem with path in tooltip
<LogDestinationIndicator
  logDestination="filesystem"
  filesystemDestination="/var/log/fleet/osquery_result"
/>

// Label only, no tooltip
<LogDestinationIndicator
  logDestination="kinesis"
  excludeTooltip
/>
```
