Storybook stories file for the `LogDestinationIndicator` component, providing interactive UI documentation and visual testing for different log destination states.

## Key Components

- **`meta`** – Storybook metadata configuration defining the component title, component reference, and default args (`logDestination: "filesystem"`)
- **`Basic`** – Default story rendering `LogDestinationIndicator` with the `filesystem` log destination

## Usage Example

```typescript
// Extend with additional stories for other log destinations
export const Firehose: Story = {
  args: {
    logDestination: "firehose",
  },
};

export const Kinesis: Story = {
  args: {
    logDestination: "kinesis",
  },
};
```

## Notes

- Default `logDestination` is set to `"filesystem"` in shared `args`, inherited by all stories
- The component lives at `Components/LogDestinationIndicator` in the Storybook hierarchy
