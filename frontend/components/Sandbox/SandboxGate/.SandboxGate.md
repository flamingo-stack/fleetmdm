Conditionally renders content based on whether the application is in sandbox mode, acting as a gate that shows a fallback component when sandbox mode is active.

## Key Components

- **`SandboxGate`** — Default export. A wrapper component that reads `isSandboxMode` from `AppContext` and either renders `children` (non-sandbox) or invokes `fallbackComponent` (sandbox mode).
- **`ISandboxGateProps`** — Interface defining:
  - `children` — Content rendered in normal (non-sandbox) mode.
  - `fallbackComponent` — Optional render function invoked in sandbox mode; defaults to `() => null`.

## Usage Example

```typescript
// Render a feature only outside sandbox mode
<SandboxGate>
  <PremiumFeature />
</SandboxGate>

// Show a sandbox-specific message instead
<SandboxGate fallbackComponent={() => <SandboxBanner />}>
  <LiveDataTable />
</SandboxGate>
```
