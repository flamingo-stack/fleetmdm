A presentational component that displays a sandbox/demo environment message with a contextual call-to-action link, either scheduling a demo via Calendly or directing users to the Fleet sales page.

## Key Components

### `ISandboxMessageProps`
| Prop | Type | Description |
|------|------|-------------|
| `variant` | `"demo" \| "sales"` | Controls which CTA link is rendered (default: `"demo"`) |
| `message` | `string` | Primary message text displayed in the sandbox banner |
| `utmSource` | `string` | UTM source parameter appended to the Calendly demo URL |
| `className` | `string` | Optional additional CSS class for the wrapper element |

### `SandboxMessage`
Default export. Renders a `<div>` containing a heading with the message and a paragraph with a `CustomLink` CTA based on the selected variant:
- **`demo`** → Links to `calendly.com/fleetdm/demo` with UTM tracking
- **`sales`** → Links to `fleetdm.com/upgrade`

## Usage Example

```typescript
// Demo variant with UTM tracking
<SandboxMessage
  variant="demo"
  message="This feature is not available in the sandbox environment."
  utmSource="sandbox-policies-page"
/>

// Sales/upgrade variant
<SandboxMessage
  variant="sales"
  message="Upgrade your plan to access advanced reporting."
  className="custom-banner"
/>
```
