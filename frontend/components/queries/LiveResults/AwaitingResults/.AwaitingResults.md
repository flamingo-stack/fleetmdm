Renders an empty state UI component displayed while waiting for query results from hosts that have not yet responded.

## Key Components

- **`AwaitingResults`** — Functional component that wraps `EmptyState` with a "Waiting for results" message and informational text indicating hosts haven't checked in yet.

## Usage Example

```typescript
import AwaitingResults from "components/AwaitingResults";

const QueryPage = ({ hasResults }: { hasResults: boolean }) => {
  if (!hasResults) {
    return <AwaitingResults />;
  }
  return <ResultsTable />;
};
```
