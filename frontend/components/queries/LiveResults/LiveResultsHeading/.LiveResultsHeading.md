Renders the heading section for a live query/policy run modal, displaying real-time host response progress, percentage stats with tooltips, and contextual action buttons based on run state.

## Key Components

- **`LiveResultsHeading`** — Main exported component displaying the page title, targeted host count, response percentage, and state-aware action buttons
- **`FinishedButtons`** — Internal component rendering "Close" and "Run again" buttons shown when the run completes
- **`StopButton`** — Internal component rendering an alert-styled "Stop" button shown while the run is in progress
- **`pluralizeHost`** — Helper using `strUtils.pluralize` to correctly pluralize "host"/"hosts"

### Props (`ILiveResultsHeadingProps`)

| Prop | Type | Description |
|------|------|-------------|
| `numHostsTargeted` | `number` | Total hosts in the run |
| `numHostsResponded` | `number` | Hosts that have responded so far |
| `numHostsRespondedResults` | `number` | Responded with results |
| `numHostsRespondedNoErrorsAndNoResults` | `number` | Responded with nothing |
| `numHostsRespondedErrors` | `number` | Responded with errors |
| `isFinished` | `boolean` | Toggles finished vs. running state |
| `resultsType` | `"report" \| "policy"` | Affects title and labels (default: `"report"`) |
| `onClickClose/RunAgain/Stop` | `MouseEventHandler` | Button callbacks |

## Usage Example

```typescript
<LiveResultsHeading
  numHostsTargeted={120}
  numHostsResponded={45}
  numHostsRespondedResults={40}
  numHostsRespondedNoErrorsAndNoResults={3}
  numHostsRespondedErrors={2}
  isFinished={false}
  resultsType="policy"
  onClickClose={handleClose}
  onClickRunAgain={handleRunAgain}
  onClickStop={handleStop}
/>
```
