Defines the table configuration for displaying scheduled queries within a Fleet pack, including column headers, cell renderers, and data transformation utilities.

## Key Components

### `generateTableHeaders(actionSelectHandler)`
Returns an array of column definitions for the pack queries table, including:
- **Selection** – Checkbox column for bulk row selection
- **Query** – Sortable query name column
- **Frequency** – Interval formatted via `secondsToDhms`
- **Platform** – Resolved platform display string
- **Logging** – Snapshot vs. differential logging type
- **Performance Impact** – Tooltip-wrapped average performance indicator
- **Actions** – Dropdown with Edit/Remove options

### `generateDataSet(queries)`
Entry point that transforms raw `IScheduledQuery[]` into enriched `IPackQueriesTableData[]` ready for table consumption.

### Internal Helpers
| Function | Purpose |
|---|---|
| `generateLoggingTypeString` | Maps `snapshot`/`removed` flags to human-readable logging labels |
| `generatePlatformTypeString` | Converts comma-separated platform values (e.g., `"darwin"`) to display names (e.g., `"macOS"`) |
| `generateVersionString` | Returns the version string or `"Any"` if undefined |
| `generateActionDropdownOptions` | Builds static Edit/Remove dropdown options |
| `enhancePackQueriesData` | Maps raw queries to `IPackQueriesTableData`, attaching computed display fields and performance stats |

## Usage Example

```typescript
import { generateTableHeaders, generateDataSet } from "./PackQueriesTableConfig";

const handleAction = (action: string, query: IScheduledQuery) => {
  if (action === "edit") { /* open edit modal */ }
  if (action === "remove") { /* confirm removal */ }
};

const columns = generateTableHeaders(handleAction);
const tableData = generateDataSet(scheduledQueries);

// Pass to TableContainer
<TableContainer columns={columns} data={tableData} />
```
