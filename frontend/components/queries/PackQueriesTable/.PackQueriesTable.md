Displays scheduled queries assigned to a pack in a searchable, sortable table with add/edit/remove actions.

## Key Components

- **`PackQueriesTable`** — Default export; renders a `TableContainer` when queries exist, or an `EmptyState` prompt when the pack is empty
- **`IPackQueriesTableProps`** — Interface defining required callbacks and data:
  - `onAddPackQuery` — Opens the add-query modal
  - `onEditPackQuery` — Opens the edit modal for a selected `IScheduledQuery`
  - `onRemovePackQueries` — Removes one or more queries by ID
  - `scheduledQueries` — Array of `IScheduledQuery` objects (or `undefined` while loading)
  - `isLoadingPackQueries` — Controls the table loading state
- **`onTableQueryChange`** — Syncs search text from `TableContainer` into local state
- **`getQueries`** — Filters `scheduledQueries` via `simpleSearch` against the current search text
- **`onActionSelection`** — Delegates row-level `"edit"` / `"remove"` actions to the appropriate callback

## Usage Example

```typescript
import PackQueriesTable from "components/PackQueriesTable";
import { IScheduledQuery } from "interfaces/scheduled_query";

const handleAdd = () => openAddQueryModal();
const handleEdit = (query: IScheduledQuery) => openEditModal(query);
const handleRemove = (ids: number[]) => removeQueriesById(ids);

<PackQueriesTable
  onAddPackQuery={handleAdd}
  onEditPackQuery={handleEdit}
  onRemovePackQueries={handleRemove}
  scheduledQueries={scheduledQueries}
  isLoadingPackQueries={isLoading}
/>
```
