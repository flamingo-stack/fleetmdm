Storybook stories for the `Textarea` component, demonstrating label and code variant configurations.

## Key Components

- **`meta`** – Storybook metadata registering `Textarea` under `Components/Textarea` with default children content
- **`ExampleWithLabelAndCodeVariant`** – Story showcasing the `code` variant with a label and multiline text including line break and carriage return handling

## Usage Example

```typescript
import Textarea from "./Textarea";

// Code variant with label
<Textarea variant="code" label="Textarea label:">
  {`const example = 'This is code styled text';\n// With line breaks preserved.`}
</Textarea>

// Default variant
<Textarea>Default textarea content</Textarea>
```

## Notes

- The `code` variant renders content in a monospace/code-styled format
- Line breaks (`\n`) and carriage returns (`\r\n`) are both preserved/normalized in the `code` variant
- Stories import `../../index.scss` for global styles
