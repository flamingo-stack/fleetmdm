A read-only display component that renders text content with consistent styling, optional labels, and support for code or default variants.

## Key Components

### `ITextareaProps`
| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | Text or content to display |
| `className` | `string` | Optional additional CSS class |
| `label` | `React.ReactNode` | Optional label rendered above content |
| `variant` | `"code" \| "default"` | `"code"` applies monospace font and 300px max height |

### `Textarea`
Default export. Wraps children in a styled `div` structure. Automatically normalizes carriage return characters (`\r`) to newlines (`\n`) to preserve line breaks consistently across platforms.

## Usage Example

```typescript
import Textarea from "components/Textarea";

// Default variant
<Textarea label="Script Output">
  Hello, world!
</Textarea>

// Code variant with max height and monospace font
<Textarea
  variant="code"
  label="Raw Script"
  className="my-custom-class"
>
  {"#!/bin/bash\r\necho 'hello'"}
</Textarea>
```

## CSS Classes

| Class | Applied To |
|-------|------------|
| `textarea-wrapper` | Outer `div` |
| `textarea__label` | Label `div` |
| `textarea` | Content `div` |
| `textarea--code` | Content `div` when `variant="code"` |

> **Note:** This is a **display-only** component — it renders content in a styled `div`, not an HTML `<textarea>` input element.
