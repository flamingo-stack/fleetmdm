A React component that renders a tooltip-wrapped label for Arch Linux's rolling release model, providing contextual information with a "Learn more" link.

## Key Components

- **`TooltipWrapperArchLinuxRolling`** — Default export; a thin wrapper around `TooltipWrapper` that displays a rolling release explanation tooltip
- **`capitalized`** *(optional, default: `false`)* — Controls whether the trigger label renders as `"Rolling"` or `"rolling"`

## Usage Example

```typescript
import TooltipWrapperArchLinuxRolling from "components/TooltipWrapperArchLinuxRolling";

// Lowercase label (default)
<TooltipWrapperArchLinuxRolling />

// Capitalized label (e.g., start of a sentence)
<TooltipWrapperArchLinuxRolling capitalized />
```

## Notes

- Tooltip content links out to `https://fleetdm.com/learn-more-about/arch-linux-rolling-release` via `CustomLink` with `variant="tooltip-link"` and `newTab`
- Delegates all tooltip rendering and positioning to the shared `TooltipWrapper` component
