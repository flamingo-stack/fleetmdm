Storybook story file for the `QueryFrequencyIndicator` component, providing interactive documentation and visual testing for frequency display states.

## Key Components

- **`meta`** — Storybook metadata configuration defining the component title, component reference, and default args (`frequency: 300`, `checked: true`)
- **`Basic`** — Default story rendering the component with the configured args

## Usage Example

```typescript
// Extend with additional stories to cover different states
export const Unchecked: Story = {
  args: {
    frequency: 300,
    checked: false,
  },
};

export const HighFrequency: Story = {
  args: {
    frequency: 3600,
    checked: true,
  },
};
```

## Notes

- Default story uses a `frequency` of `300` (seconds) with `checked: true`
- Extend stories to test edge cases such as unchecked state or varying frequency intervals
