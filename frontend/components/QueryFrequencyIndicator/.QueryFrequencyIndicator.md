Renders a visual frequency indicator for Fleet MDM queries, displaying a human-readable schedule label alongside a contextual icon that reflects both the query interval and its enabled/disabled state.

## Key Components

- **`IStatusIndicatorProps`** – Interface accepting `frequency` (seconds) and `checked` (enabled state)
- **`generateClassTag`** – Converts raw frequency values into CSS-safe class name suffixes
- **`readableQueryFrequency`** – Maps common second values (`0`, `3600`, `86400`, `604800`) to labels (`Never`, `Hourly`, `Daily`, `Weekly`), falling back to `secondsToDhms` for custom intervals
- **`frequencyIcon`** – Returns a `warning` icon when frequency is `0` and `checked`, a greyed `clock` when `0` and unchecked, or a standard `clock` for all active frequencies
- **`QueryFrequencyIndicator`** – Default export; composes the above into a styled `<div>` with BEM-style class names

## Usage Example

```typescript
import QueryFrequencyIndicator from "components/QueryFrequencyIndicator/QueryFrequencyIndicator";

// Daily query, enabled
<QueryFrequencyIndicator frequency={86400} checked={true} />

// Never runs, disabled (greyed clock)
<QueryFrequencyIndicator frequency={0} checked={false} />

// Never runs, but enabled (warning icon)
<QueryFrequencyIndicator frequency={0} checked={true} />

// Custom interval (e.g., 7200s → "2h")
<QueryFrequencyIndicator frequency={7200} checked={true} />
```

## Notes

- Frequency `0` with `checked={false}` applies an additional `grey` CSS modifier for visual de-emphasis
- Custom intervals delegate formatting to the [`secondsToDhms`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/helpers.ts) helper
