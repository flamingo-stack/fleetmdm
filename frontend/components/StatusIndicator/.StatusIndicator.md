A reusable React component that renders a styled status badge with an optional tooltip, used to display states like success, warning, error, or indeterminate across data tables and detail views.

## Key Components

### Types

- **`IIndicatorValue`** — Union type for the four supported indicator states: `"success"` | `"warning"` | `"error"` | `"indeterminate"`

### Props (`IStatusIndicatorProps`)

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Display text (auto-capitalized) |
| `indicator` | `IIndicatorValue` | ⭐ Preferred prop for controlling visual state |
| `tooltip` | `{ tooltipText: ReactNode, position?: "top" \| "bottom" }` | Optional tooltip configuration |
| `customIndicatorType` | `string` | ⚠️ Deprecated — use `indicator` instead |
| `className` | `string` | Additional CSS class names |

### Helpers

- **`generateIndicatorStateClassTag`** — Derives CSS class suffixes from the `value` string, normalizing spaces to hyphens and lowercasing. Returns `"indeterminate"` for empty cell values.

## Usage Example

```typescript
// Basic success indicator
<StatusIndicator value="online" indicator="success" />

// Warning with a bottom tooltip
<StatusIndicator
  value="degraded"
  indicator="warning"
  tooltip={{
    tooltipText: "Device has not checked in recently",
    position: "bottom",
  }}
/>

// Error state with custom class
<StatusIndicator
  value="failed"
  indicator="error"
  className="my-custom-class"
/>
```

> **Note:** Always use the `indicator` prop to control the visual state. Do not rely on `value` string matching for styling — `value` is display text only.
