Test suite for the `StatusIndicator` component, verifying text capitalization and optional tooltip behavior on hover.

## Key Components

- **`renders status as capitalized`** – Confirms the component displays status values in capitalized form (e.g., `"paused"` → `"Paused"`).
- **`renders optional tooltip on hover`** – Verifies that when a `tooltip` prop is provided, the tooltip text appears after hovering over the status label.

## Usage Example

```typescript
// Render a basic status indicator
render(<StatusIndicator value="paused" />);

// Render with an optional tooltip
renderWithSetup(
  <StatusIndicator
    value="online"
    tooltip={{ tooltipText: "Online hosts will respond to a live report." }}
  />
);
```

## Notes

- Uses `@testing-library/react` for rendering and querying the DOM.
- Uses `renderWithSetup` from the local test utilities to support user-event interactions (e.g., hover).
- `waitFor` is used to handle async tooltip rendering after hover.
