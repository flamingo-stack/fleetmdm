Storybook stories file for the `StatusIndicator` component, providing interactive UI development and documentation via Storybook.

## Key Components

- **`meta`** — Storybook metadata configuration defining the component title, component reference, and shared default args (`value`, `tooltip`)
- **`Basic`** — A single baseline story rendering `StatusIndicator` with default props

## Usage Example

```typescript
// Extend with additional stories for variant coverage
export const WithLongTooltip: Story = {
  args: {
    value: "50",
    tooltip: {
      tooltipText: "This is a longer tooltip description",
    },
  },
};

export const ZeroValue: Story = {
  args: {
    value: "0",
  },
};
```

## Default Args

| Prop | Default Value |
|---|---|
| `value` | `"100"` |
| `tooltip.tooltipText` | `"Tooltip text"` |

## Notes

- Stories are located under **Components/StatusIndicator** in the Storybook sidebar
- Default args are inherited by all stories; individual stories can override via their own `args`
