Renders platform compatibility indicators for osquery queries, displaying check/cross icons for macOS, Windows, Linux, and ChromeOS based on which platforms support the query's tables.

## Key Components

- **`IPlatformCompatibilityProps`** — accepts `compatiblePlatforms` (array of `QueryablePlatform` or `null`) and an optional `error`
- **`DISPLAY_ORDER`** — fixed rendering order: macOS → Windows → Linux → ChromeOS
- **`formatPlatformsForDisplay`** — maps internal `QueryablePlatform` keys to human-readable `DisplayPlatform` names via `PLATFORM_DISPLAY_NAMES`
- **`displayIncompatibilityText`** — renders contextual error messages distinguishing between invalid/missing tables and syntax errors
- **`PlatformCompatibility`** — default export; the main component rendering the compatibility row with tooltip and per-platform icons

## Usage Example

```typescript
import PlatformCompatibility from "components/PlatformCompatibility";

<PlatformCompatibility
  compatiblePlatforms={["darwin", "windows"]}
  error={null}
/>

// Error state (syntax error)
<PlatformCompatibility
  compatiblePlatforms={[]}
  error={new Error("syntax error")}
/>

// Null — renders nothing (query not yet parsed)
<PlatformCompatibility
  compatiblePlatforms={null}
  error={null}
/>
```

## Notes

- Returns `null` when `compatiblePlatforms` is `null` (no query parsed yet)
- ChromeOS renders with an additional tooltip noting only live reports are supported
- The "Compatible with:" label includes a non-clickable tooltip explaining that compatibility is table-based and excludes iOS/iPadOS/Android hosts
