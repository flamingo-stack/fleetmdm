Test suite for the `PlatformCompatibility` React component, verifying correct rendering of platform icons, empty states, and error states.

## Key Components

- **`renders compatible platforms`** — Verifies that `darwin` and `windows` receive the `compatible-platform` CSS class while `linux` receives `incompatible-platform` when not included in `compatiblePlatforms`.
- **`renders empty state`** — Confirms a "No platforms" message appears when `compatiblePlatforms` is an empty array.
- **`renders error state`** — Confirms a "possible syntax error" message appears when an `error` object is passed alongside a platform list.

## Usage Example

```typescript
// Run the test suite
npx jest PlatformCompatibility.tests.tsx

// Component props exercised by these tests
<PlatformCompatibility
  compatiblePlatforms={["darwin", "windows"]} // "linux" | "windows" | "darwin"
  error={null} // null | { name: string; message: string }
/>
```

## Notes

- Compatible platforms render icons with class `icon compatible-platform`; unsupported platforms render `icon incompatible-platform`
- An error object (e.g., from a failed resource lookup) triggers a syntax error hint rather than the platform list
- Tests use `@testing-library/react` — assertions rely on accessible text and DOM attribute checks
