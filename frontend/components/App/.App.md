The root application component that bootstraps Fleet's context providers, fetches global app state (current user, config, MDM token expirations), and renders the provider tree with error boundary handling.

## Key Components

### `App` (default export)
The top-level React component responsible for:
- Fetching and hydrating global context: current user, app config, enroll secrets
- Polling MDM token expiry data (ABM, APNs, VPP, Android Enterprise) for admin banners
- Wrapping the app in `TableProvider`, `QueryProvider`, `PolicyProvider`, and `NotificationProvider`
- Handling auth redirects and browser tab titles based on the current route
- Rendering HTTP error pages (403, 404, 500) via `ErrorBoundary`

### `getEarliestExpiry` (named export)
```typescript
getEarliestExpiry(records: RecordWithRenewDate[]): string
```
Utility that reduces an array of token objects to the earliest `renew_date` ISO string. Falls back to `"2000-01-01T01:00:00Z"` if no valid dates are found.

## Usage Example

```typescript
import App from "App";

// Typically mounted by the router — children are the active route component
<App location={{ pathname: "/dashboard", search: "", query: {} }}>
  <Dashboard />
</App>

// Using the named export independently
import { getEarliestExpiry } from "App";

const tokens = [
  { renew_date: "2025-06-01T00:00:00Z" },
  { renew_date: "2024-12-15T00:00:00Z" }, // earliest
];

const expiry = getEarliestExpiry(tokens);
// → "2024-12-15T00:00:00.000Z"
```

## Notes

- MDM-related queries only run when `isGlobalAdmin` is `true` and the relevant MDM integration is configured.
- Auth token removal and redirect to `/login` occur automatically on failed user fetch, except on `/device/` and `/login/reset` paths.
- Page titles are matched via prefix against `page_titles` from `router/page_titles`.
