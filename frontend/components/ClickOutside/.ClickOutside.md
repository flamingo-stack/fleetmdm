A Higher-Order Component (HOC) that detects and handles clicks outside of a wrapped component, supporting both mouse and touch events.

## Key Components

- **Default Export** — HOC factory function that accepts a `WrappedComponent` and an options object
- **Options**
  - `onOutsideClick` — Callback invoked with the component instance when an outside click is detected (defaults to `noop`)
  - `getDOMNode` — Function to retrieve the DOM node of the component instance (defaults to `noop`)
- **`handleClickOutside`** — Imported helper that creates the event handler logic for determining if a click occurred outside the target node
- **`ClickOutside` class** — Internal React class component managing event listener lifecycle

## Lifecycle Behavior

| Hook | Action |
|---|---|
| `componentDidMount` | Registers `mousedown` and `touchStart` listeners on `document` |
| `componentWillUnmount` | Removes both listeners to prevent memory leaks |

## Usage Example

```javascript
import ClickOutside from "./ClickOutside";

class MyDropdown extends React.Component {
  render() {
    return <div>Dropdown content</div>;
  }
}

const EnhancedDropdown = ClickOutside(MyDropdown, {
  onOutsideClick: (instance) => () => {
    console.log("Clicked outside!", instance);
  },
  getDOMNode: (instance) => instance.dropdownNode,
});

// Use like a normal component
<EnhancedDropdown someProps="value" />;
```

## Notes

- Uses a `ref` callback (`setInstance`) to capture the wrapped component instance, which is passed to both `onOutsideClick` and `getDOMNode`
- Event listeners are attached to `global.document` for SSR compatibility
- `touchStart` listener uses a non-standard casing — standard DOM spelling is `touchstart` (lowercase), which may cause the touch handler to not fire in some environments
