Utility for detecting and handling clicks that occur outside a specified DOM element.

## Key Components

- **`handleClickOutside(clickHandler, componentNode)`** — Returns an event handler that invokes `clickHandler` only when the click target is outside the provided `componentNode`. If the click is inside the node, it returns `false` and does nothing.

## Usage Example

```javascript
import { handleClickOutside } from './helpers';

const menuNode = document.getElementById('dropdown-menu');

const closeMenu = (evt) => {
  console.log('Clicked outside menu, closing...', evt);
};

const outsideClickHandler = handleClickOutside(closeMenu, menuNode);
document.addEventListener('click', outsideClickHandler);

// Cleanup when done
document.removeEventListener('click', outsideClickHandler);
```
