Renders a host count value alongside a "last updated" timestamp tooltip, informing users when host data was last refreshed and directing them to view all hosts for the most current count.

## Key Components

- **`ILastUpdatedHostCount`** – Interface defining optional `hostCount` (string, number, or JSX element) and `lastUpdatedAt` (string or null) props
- **`LastUpdatedHostCount`** – Default export; composes the host count display with a [`LastUpdatedText`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/LastUpdatedText) tooltip component
- **`tooltipContent`** – Inline JSX snippet explaining the staleness of host data and prompting users to click **View all hosts**

## Usage Example

```typescript
import LastUpdatedHostCount from "components/LastUpdatedHostCount";

// With a numeric count and timestamp
<LastUpdatedHostCount
  hostCount={42}
  lastUpdatedAt="2024-01-15T10:30:00Z"
/>

// With a JSX element as the count (e.g., a loading spinner or styled number)
<LastUpdatedHostCount
  hostCount={<span className="highlight">128</span>}
  lastUpdatedAt={null}
/>

// Without a timestamp (hides the LastUpdatedText component)
<LastUpdatedHostCount hostCount={10} />
```

## Notes

- If `lastUpdatedAt` is `undefined`, the `LastUpdatedText` component is not rendered at all
- Passing `null` for `lastUpdatedAt` renders `LastUpdatedText` with a null value, which the child component handles independently
- The `hostCount` prop accepts flexible types to support rendered states like spinners or styled elements
