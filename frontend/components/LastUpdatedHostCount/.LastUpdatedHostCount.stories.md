Storybook stories for the `LastUpdatedHostCount` component, defining visual variants for development and testing.

## Key Components

- **`meta`** — Storybook metadata configuring the component under `Components/LastUpdatedHostCount` with a default `hostCount` of `40`
- **`Basic`** — Renders the component with only the default `hostCount` prop (no timestamp)
- **`WithLastUpdatedAt`** — Renders the component with an additional `lastUpdatedAt` ISO timestamp (`2021-01-01T00:00:00Z`)

## Usage Example

```typescript
// Run in Storybook to preview stories
// Basic story uses default args: hostCount = 40
export const Basic: Story = {};

// WithLastUpdatedAt story adds a timestamp prop
export const WithLastUpdatedAt: Story = {
  args: {
    lastUpdatedAt: "2021-01-01T00:00:00Z",
  },
};
```

## Notes

- Stories are co-located with the component for discoverability
- The `Basic` story relies on shared `args` (`hostCount: 40`) defined in `meta`
