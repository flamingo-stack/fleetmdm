Test suite for the `LastUpdatedHostCount` component, verifying rendering of host counts, relative timestamps, "Updated never" fallback states, and tooltip behavior on hover.

## Key Components

- **`describe("Last updated host count")`** — Top-level test suite grouping all component behavior cases
- **`render` / `renderWithSetup`** — Standard RTL render and a custom setup utility that includes user-event interaction support
- **Four test cases:**
  - Host count and relative timestamp rendering (`40`, `"Updated 2 days ago"`)
  - `null` `lastUpdatedAt` renders `"Updated never"`
  - `undefined` `lastUpdatedAt` renders no updated text at all
  - Tooltip appears on hover when state is `"Updated never"`

## Usage Example

```typescript
// Run tests
npx jest LastUpdatedHostCount.tests.tsx

// Component under test (props shape inferred from tests)
<LastUpdatedHostCount hostCount={40} lastUpdatedAt={twoDaysAgo} />
<LastUpdatedHostCount lastUpdatedAt={null} />   // → "Updated never"
<LastUpdatedHostCount />                         // → no timestamp rendered
```

## Notes

- `lastUpdatedAt` accepts an ISO 8601 string, `null`, or `undefined` — each produces distinct UI behavior
- Tooltip test uses `renderWithSetup` (from [`test/test-utils`](https://github.com/flamingo-stack/fleetmdm/blob/main/test/test-utils)) to get the `user` object required for `user.hover()`
- `waitFor` is used to handle async tooltip rendering after the hover interaction
