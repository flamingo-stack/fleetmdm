Storybook stories for the `Spinner` component, defining interactive visual variants for development and design review.

## Key Components

- **`SpinnerDefault`** — Renders the Spinner with no props (default state)
- **`SpinnerSmall`** — Spinner with `small: true` prop
- **`SpinnerButton`** — Spinner with `button: true` prop for use inside buttons
- **`SpinnerWhite`** — Spinner with `white: true` for dark backgrounds
- **`SpinnerSize`** — Interactive story with a `select` control for `size` values: `"x-small"`, `"small"`, `"medium"`

## Usage Example

```typescript
import Spinner from "./Spinner";

// Default spinner
<Spinner />

// Small variant
<Spinner small />

// Button variant
<Spinner button />

// White variant (for dark backgrounds)
<Spinner white />

// Explicit size
<Spinner size="x-small" />
```

## Notes

- Stories are grouped under **Components/Spinner** in the Storybook sidebar
- The `SpinnerSize` story exposes a Storybook `select` control, allowing testers to switch between `x-small`, `small`, and `medium` sizes interactively without code changes
