A reusable loading spinner React component that renders an SVG circular animation with configurable size, padding, visibility delay, and layout options.

## Key Components

### `ISpinnerProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"x-small" \| "small" \| "medium"` | `"medium"` | Spinner size |
| `verticalPadding` | `"small" \| "medium"` | `"medium"` | Padding size (60px / 120px) |
| `includeContainer` | `boolean` | `true` | Applies background container styling |
| `centered` | `boolean` | `true` | Centers spinner within parent |
| `delay` | `number` | `250` | Ms before spinner appears; `0` = immediate |
| `variant` | `"mobile"` | `undefined` | Enables mobile-specific layout |
| `white` | `boolean` | — | White color variant |
| `button` | `boolean` | — | Button-embedded variant |

### Delay Visibility Logic
Uses `useState` + `useEffect` to defer rendering until the `delay` elapses. If the component unmounts before the timeout fires, it clears the timer and never renders — preventing a flash for fast-resolving loads.

## Usage Example

```typescript
// Standard loading state (250ms delay)
<Spinner />

// Immediate spinner for ongoing operations (e.g. pending install)
<Spinner delay={0} />

// Small, white, button-embedded spinner
<Spinner size="small" white button />

// Mobile variant without container
<Spinner variant="mobile" centered={false} />

// Custom padding and class
<Spinner verticalPadding="small" className="my-spinner" />
```
