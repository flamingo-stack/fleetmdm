Reusable table container component that wraps `DataTable` with search, pagination, sorting, and filtering controls. It supports both server-side and client-side data management patterns.

## Key Components

### Interfaces

- **`ITableQueryData`** — Query state shape passed to `onQueryChange` (pageIndex, pageSize, searchQuery, sortHeader, sortDirection)
- **`ITableContainerProps<T>`** — Full props interface for the container (50+ props covering layout, behavior, and callbacks)
- **`ITableContainerActionButtonProps`** — Extends `IActionButtonProps` with optional `disabledTooltipContent`

### Constants

- **`DEFAULT_PAGE_SIZE`** — `20` (exported)
- **`DEFAULT_PAGE_INDEX`** — `0`

### Internal State

| State | Type | Purpose |
|---|---|---|
| `searchQuery` | `string` | Current search input value |
| `sortHeader` | `string` | Active sort column ID |
| `sortDirection` | `string` | `"asc"` or `"desc"` |
| `currentPageIndex` | `number` | Active page (server-side) |
| `clientFilterCount` | `number` | Result count from client-side filtering |

### Key Behaviors

- **Controlled search** — When `searchQuery` prop is provided, internal state syncs via `useEffect`
- **Server-side pagination** — Rendered via `renderServersidePagination()` using the `Pagination` component
- **Query change notification** — `useDeepEffect` fires `onQueryChange` when search, sort, page, or `additionalQueries` change
- **Disabled button tooltip** — Action button auto-wraps in `TooltipWrapper` when `disabledTooltipContent` is set

## Usage Example

```typescript
<TableContainer
  columnConfigs={columns}
  data={hosts}
  isLoading={isFetching}
  emptyComponent={EmptyHosts}
  showMarkAllPages={false}
  isAllPagesSelected={false}
  searchable
  defaultSortHeader="hostname"
  defaultSortDirection="asc"
  pageSize={DEFAULT_PAGE_SIZE}
  totalCount={hostsCount}
  onQueryChange={({ searchQuery, sortHeader, sortDirection, pageIndex }) => {
    fetchHosts({ searchQuery, sortHeader, sortDirection, pageIndex });
  }}
  actionButton={{
    buttonText: "Add host",
    onClick: () => setShowAddModal(true),
    variant: "brand",
  }}
/>
```
