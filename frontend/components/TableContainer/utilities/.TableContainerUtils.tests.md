Test suite for the `generateResultsCountText` utility function from `TableContainerUtils`, validating correct pluralization and singular/plural count text generation across various entity types.

## Key Components

- **`generateResultsCountText`** — The function under test; accepts a plural entity type string, a count, and an optional singular override, returning a formatted count string.

## Test Coverage

| Test Case | Entity Types |
|---|---|
| Standard pluralization | `teams`, `items`, `results`, `users`, `hosts`, `labels`, `versions` |
| Irregular plurals | `policies` → `policy`, `reports` → `report` |
| Longer suffix drop | `certificates` → `certificate` |
| Custom singular override | `classes` with explicit `"class"` singular |

## Usage Example

```typescript
import { generateResultsCountText } from "./TableContainerUtils";

// Standard pluralization
generateResultsCountText("teams", 1);       // "1 team"
generateResultsCountText("teams", 5);       // "5 teams"

// Irregular plurals (auto-handled)
generateResultsCountText("policies", 1);    // "1 policy"
generateResultsCountText("policies", 3);    // "3 policies"

// Custom singular override for edge cases
generateResultsCountText("classes", 1, "class");  // "1 class"
generateResultsCountText("classes", 4, "class");  // "4 classes"
```

## Notes

- The optional third argument allows passing an explicit singular form for words where automatic de-pluralization would be ambiguous (e.g., `"classes"` → `"class"`).
