Utility for generating header checkbox props in `react-table` tables that support conditional row selection — only selectable rows (as determined by a predicate) participate in the "select all" toggle logic.

## Key Components

### `getConditionalSelectHeaderCheckboxProps`

The primary export. Computes checkbox state and behavior for a table header's "select all" checkbox, respecting a per-row selectability check.

**Parameters:**
- `headerProps` — Standard `react-table` header props providing access to rows and toggle utilities.
- `checkIfRowIsSelectable` — A predicate `(row: Row<any>) => boolean` that determines whether a given row can be selected.

**Returns** an object extending `react-table`'s `getToggleAllRowsSelectedProps()` with:
- `value` — `true` if all selectable rows are selected.
- `indeterminate` — `true` if some (but not all) rows are selected.
- `onChange` — Toggles selection: deselects all if all selectable rows are selected; otherwise selects only selectable rows.

## Usage Example

```typescript
import { getConditionalSelectHeaderCheckboxProps } from "./config_utils";

const SelectAllHeader = (headerProps) => {
  const checkboxProps = getConditionalSelectHeaderCheckboxProps({
    headerProps,
    checkIfRowIsSelectable: (row) => !row.original.isLocked,
  });

  return <input type="checkbox" {...checkboxProps} />;
};
```
