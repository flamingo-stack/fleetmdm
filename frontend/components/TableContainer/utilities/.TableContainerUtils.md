Generates human-readable result count labels with proper singular/plural inflection for table container UI components.

## Key Components

### `generateResultsCountText(name, resultsCount, singularName)`

Builds a localized count string (e.g., `"3 policies"`, `"1 policy"`, `"0 results"`).

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `name` | `string` | `"results"` | Plural form of the result noun |
| `resultsCount` | `number` | `undefined` | Number of results to display |
| `singularName` | `string` | `undefined` | Override for irregular singulars |

**Pluralization logic:**
- `0` or `undefined` → `"0 {name}"`
- `1` with `singularName` → `"1 {singularName}"`
- `1` with `-ies` suffix → strips to `-y` (e.g., `"policies"` → `"1 policy"`)
- `1` with `-s` suffix → strips trailing `s` (e.g., `"hosts"` → `"1 host"`)
- `> 1` → `"{count.toLocaleString()} {name}"`

## Usage Example

```typescript
import { generateResultsCountText } from "./TableContainerUtils";

// Regular plural (trailing "s")
generateResultsCountText("hosts", 42);      // "42 hosts"
generateResultsCountText("hosts", 1);       // "1 host"

// "-ies" plural
generateResultsCountText("policies", 3);    // "3 policies"
generateResultsCountText("policies", 1);    // "1 policy"

// Irregular plural — pass explicit singular
generateResultsCountText("children", 1, "child"); // "1 child"

// Zero / undefined
generateResultsCountText("results", 0);     // "0 results"
generateResultsCountText();                 // "0 results"
```
