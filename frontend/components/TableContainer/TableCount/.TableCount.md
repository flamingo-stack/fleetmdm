Renders a styled `<span>` displaying a formatted results count label for data tables.

## Key Components

- **`ITableCountProps`** — Interface with `name` (string, required) and `count` (number, optional)
- **`TableCount`** — Default export; functional component that delegates text formatting to `generateResultsCountText`
- **`generateResultsCountText`** — Utility imported from `TableContainerUtils` that produces the display string (e.g., `"5 hosts"`)

## Usage Example

```typescript
import TableCount from "./TableCount";

// Renders: "42 devices"
<TableCount name="devices" count={42} />

// Renders with undefined count (handled by utility)
<TableCount name="policies" />
```

## Notes

- The component applies the CSS class `table-count` to the wrapping `<span>` for styling
- Display text formatting logic is fully delegated to [`generateResultsCountText`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/utilities/TableContainerUtils.ts), keeping this component a thin presentational wrapper
- `count` is optional; the utility handles `undefined` gracefully
