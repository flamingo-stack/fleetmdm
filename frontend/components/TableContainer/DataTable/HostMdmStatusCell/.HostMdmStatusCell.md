Renders the MDM enrollment status cell for a host table row, handling platform-specific display logic, status tooltips, and DEP profile error indicators.

## Key Components

- **`HostMdmStatusCell`** — Default export; a React table cell component that accepts a `row` (typed as `IHost`) and a `cell` (typed as `MdmEnrollmentStatus`).

### Rendering Logic

| Condition | Output |
|-----------|--------|
| Chrome or Linux-like platform | `NotSupported` component |
| No status value | Empty cell placeholder (`—`) |
| Status with no tooltip | Plain display name string |
| Status with tooltip | `TooltipWrapper` around display name |
| `mdm.dep_profile_error` is set | Error icon with DEP profile tooltip + link |

## Usage Example

```typescript
import HostMdmStatusCell from "components/TableContainer/DataTable/HostMdmStatusCell";

// Used as a column renderer in a react-table column definition
const columns = [
  {
    Header: "MDM Status",
    id: "mdm_enrollment_status",
    accessor: "mdm_enrollment_status",
    Cell: HostMdmStatusCell,
  },
];
```

## Dependencies

- [`MDM_ENROLLMENT_STATUS_UI_MAP`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/mdm.ts) — Maps raw enrollment status keys to human-readable display names.
- [`MDM_STATUS_TOOLTIP`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/constants.ts) — Maps status keys to tooltip copy.
- [`isChrome` / `isLinuxLike`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/platform.ts) — Platform guards that suppress MDM status for unsupported OSes.
- `paths.HOST_DETAILS(id)` — Generates the deep-link URL to the host details page with `?show_mdm_status=true` when a DEP profile error is present.
