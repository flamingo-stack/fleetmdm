Test suite for the `HostMdmStatusCell` component, verifying that MDM enrollment status labels render correctly across different host platforms and enrollment states.

## Key Components

- **`renderCell(platform, value?)`** — Helper that creates a mock host for a given platform and renders the `HostMdmStatusCell` component with an optional `MdmEnrollmentStatus` value.
- **`HostMdmStatusCell`** — The component under test, located in the same directory.

## Usage Example

```typescript
// Render the cell for a macOS host with automatic (company-owned) enrollment
renderCell("darwin", "On (automatic)");
expect(screen.getByText("On (company-owned)")).toBeInTheDocument();

// Render the cell for a Chrome host (unsupported platform)
renderCell("chrome");
expect(screen.getByText("Not supported")).toBeInTheDocument();
```

## Test Coverage

| Platform | Input Status | Expected Display |
|---|---|---|
| `chrome` | — | `Not supported` |
| `ubuntu` | — | `Not supported` |
| `darwin` | `On (manual)` | `On (manual)` |
| `darwin` | `On (automatic)` | `On (company-owned)` |
| `ios` | `On (personal)` | `On (BYOD)` |
| `darwin` | `Pending` | `Pending` |
| `android` | `On (personal)` | `On (BYOD)` |
| `windows` | `On (manual)` | `On (manual)` |
| `windows` | `Off` | `Off` |

Key behaviors validated:
- Chrome and Linux platforms always show `Not supported` regardless of status.
- `On (automatic)` maps to the user-facing label `On (company-owned)`.
- `On (personal)` maps to `On (BYOD)` on iOS and Android.
