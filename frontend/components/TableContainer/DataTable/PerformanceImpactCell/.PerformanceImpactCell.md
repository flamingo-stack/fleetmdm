A React table cell component that renders a styled pill badge indicating the performance impact level of a schedulable query, with contextual tooltip support.

## Key Components

### `PerformanceImpactCell`
The default export. Accepts a `value` object containing an `indicator` string and an optional `isHostSpecific` boolean flag, rendering the appropriate pill badge and tooltip.

### Interfaces
- **`IPerformanceImpactCellValue`** — wraps the raw `indicator` string from table data
- **`IPerformanceImpactCellProps`** — component props: `value` and optional `isHostSpecific`

### Helpers
- **`generateClassTag`** — converts indicator strings (e.g., `"Considerable"`) to kebab-case CSS class suffixes (e.g., `"considerable"`)
- **`disableTooltip`** — suppresses the tooltip for indicators outside the known set (`Minimal`, `Considerable`, `Excessive`, `Undetermined`)

## Usage Example

```typescript
import PerformanceImpactCell from "components/TableContainer/DataTable/PerformanceImpactCell";

// Inside a react-table column definition
{
  Header: "Performance Impact",
  accessor: "performance_impact",
  Cell: ({ value }) => (
    <PerformanceImpactCell
      value={{ indicator: value?.indicator ?? "" }}
      isHostSpecific={false}
    />
  ),
}
```

The `isHostSpecific` prop adjusts the tooltip copy via `getPerformanceImpactIndicatorTooltip`, providing host-context-aware messaging when the cell is rendered in a host-scoped query table.

## Notes
- Unknown or invalid indicators fall back to `PerformanceImpactIndicatorValue.UNDETERMINED`
- The tooltip is disabled entirely for unrecognized indicator values to avoid rendering empty popovers
