Test suite for the `PerformanceImpactCell` component, verifying that the performance impact pill renders correctly and displays a tooltip with descriptive text on hover.

## Key Components

- **`PERFORMANCE_IMPACT`** — Fixture object with `indicator: "Minimal"` and `id: 3` used as test input
- **`"renders pill text and tooltip on hover"`** — Asserts the pill label is visible and that hovering reveals a tooltip matching `/little to no impact/i`

## Usage Example

```typescript
import { renderWithSetup } from "test/test-utils";
import PerformanceImpactCell from "./PerformanceImpactCell";

const { user } = renderWithSetup(
  <PerformanceImpactCell value={{ indicator: "Minimal", id: 3 }} />
);

await user.hover(screen.getByText("Minimal"));
await waitFor(() => {
  expect(screen.getByText(/little to no impact/i)).toBeInTheDocument();
});
```

## Notes

- Uses `renderWithSetup` from the shared test utilities to get a pre-configured `user` event instance (via `@testing-library/user-event`)
- `waitFor` handles async tooltip rendering that may be deferred after the hover interaction
