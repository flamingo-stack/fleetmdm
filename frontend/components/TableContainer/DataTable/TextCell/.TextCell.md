A reusable table cell component for rendering text values with support for formatting, empty state handling, and optional tooltip display.

## Key Components

### `ITextCellProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `React.ReactNode \| { timeString: string }` | — | The raw value to display |
| `formatter` | `(val: any) => React.ReactNode` | Identity fn | Optional transform applied to the value |
| `grey` | `boolean` | `false` | Renders cell text in grey |
| `italic` | `boolean` | `false` | Renders cell text in italic |
| `className` | `string` | `"w250"` | Additional CSS class |
| `emptyCellTooltipText` | `React.ReactNode` | — | Tooltip content shown on empty cells |

### Empty Cell Behavior
- Values of `null`, `undefined`, or `""` (before or after formatting) are treated as empty
- Empty cells automatically apply grey + italic styling
- If `emptyCellTooltipText` is provided, the default empty value is wrapped in a `TooltipWrapper`

## Usage Example

```typescript
// Basic usage
<TextCell value="Fleet Device Manager" />

// With a custom formatter
<TextCell
  value={1699900800}
  formatter={(val) => new Date(val * 1000).toLocaleDateString()}
  className="w150"
/>

// Empty cell with tooltip explanation
<TextCell
  value={null}
  emptyCellTooltipText="No data available for this host"
/>

// Boolean value (rendered as string)
<TextCell value={true} />
// Renders: "true"
```
