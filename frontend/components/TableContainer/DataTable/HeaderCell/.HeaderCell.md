A reusable table header cell component that renders a label with optional sort direction indicators.

## Key Components

- **`IHeaderCellProps`** — Interface defining the component's props:
  - `value` — The header label content (any `ReactNode`)
  - `isSortedDesc` — Optional sort state; `undefined` = unsorted, `true` = descending, `false` = ascending
  - `disableSortBy` — When `true`, hides the sort arrow indicators

- **`HeaderCell`** — Default export; renders a `div` with dynamic `classnames` (`ascending`/`descending`/none) and conditionally renders sort arrow spans

## Usage Example

```typescript
import HeaderCell from "./HeaderCell";

// Unsorted column (no arrow highlighted)
<HeaderCell value="Host Name" />

// Sorted ascending
<HeaderCell value="Last Seen" isSortedDesc={false} />

// Sorted descending
<HeaderCell value="Status" isSortedDesc={true} />

// Sorting disabled entirely
<HeaderCell value="Actions" disableSortBy={true} />
```

## Notes

- Sort arrows are rendered as empty `<span>` elements styled via CSS classes (`ascending-arrow`, `descending-arrow`) on the parent `.sort-arrows` container
- Active sort direction is applied as a class on the root `.header-cell` div, allowing CSS to highlight the appropriate arrow
- Typically used within a `react-table` column definition's `Header` render prop
