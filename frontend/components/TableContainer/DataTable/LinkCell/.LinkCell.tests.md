Renders a `LinkCell` component within a test environment to verify it correctly displays its text content.

## Key Components

- **`LinkCell`** — The component under test; accepts a `value` string and a `path` prop for navigation.
- **`renderWithSetup`** — Custom test utility that wraps components with required app-level providers.
- **`PATHS.MANAGE_HOSTS`** — Route constant used as the link destination.

## Usage Example

```typescript
import LinkCell from "./LinkCell";
import PATHS from "router/paths";

<LinkCell value="40 hosts" path={PATHS.MANAGE_HOSTS} />
```

## Test Coverage

| Test | Description |
|------|-------------|
| `renders text` | Confirms the `value` prop renders visibly in the DOM |

> **Note:** Full router behavior (link navigation) is not tested here, as it would require a `Router` or `MemoryRouter` wrapper at the app level.
