A reusable table cell component that renders navigable links using React Router's `Link`, supporting tooltips, truncation, and custom click handlers. Using `Link` instead of `Button` enables native browser behaviors like right-click context menus.

## Key Components

- **`LinkCell`** — Default export. Renders one of three variants based on props:
  - **Basic link** — Plain `Link` with optional `customOnClick`
  - **Tooltip link** — Wraps the link in `TooltipWrapper` when `tooltipContent` is provided
  - **Truncated tooltip link** — Uses `TooltipTruncatedTextCell` when `tooltipTruncate` is `true`, with optional `prefix`/`suffix` elements

- **`ILinkCellProps`** — Interface defining all accepted props

## Usage Example

```typescript
// Basic link cell
<LinkCell value="Acme Corp" path="/hosts/1" />

// With tooltip content
<LinkCell
  value="Acme Corp"
  path="/hosts/1"
  tooltipContent="View host details"
/>

// With truncation tooltip and prefix/suffix
<LinkCell
  value="a-very-long-hostname.example.com"
  path="/hosts/42"
  tooltipTruncate
  prefix={<span className="status-dot" />}
  suffix={<span className="badge">MDM</span>}
/>

// With custom click handler
<LinkCell
  value="Acme Corp"
  path="/hosts/1"
  customOnClick={(e) => {
    e.preventDefault();
    trackClick("host-link");
  }}
/>
```

## Notes

- `tooltipTruncate` takes precedence over `tooltipContent` in rendering order
- CSS modifier classes (`link-cell--tooltip`, `link-cell--tooltip-truncate`) are applied via `classnames` for targeted styling
