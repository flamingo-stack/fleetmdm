A reusable, feature-rich data table component built on top of `react-table` v7, supporting sorting, filtering, pagination, row selection, and export functionality.

## Key Components

### `DataTable` (default export)
The primary component accepting the following major prop groups:

- **Data & Columns** — `columns`, `data`, `filters`, `isLoading`, `getRowId`
- **Sorting** — `sortHeader`, `sortDirection`, `onSort`, `manualSortBy`
- **Pagination** — `defaultPageSize`, `defaultPageIndex`, `isClientSidePagination`, `onClientSidePaginationChange`, `renderPagination`
- **Row Selection** — `disableMultiRowSelect`, `keyboardSelectableRows`, `showMarkAllPages`, `isAllPagesSelected`, `toggleAllPagesSelected`, `defaultSelectedRows`, `persistSelectedRows`
- **Filtering** — `isClientSideFilter`, `searchQuery`, `searchQueryColumn`, `selectedDropdownFilter`
- **Actions** — `primarySelectAction`, `secondarySelectActions`, `onSelectSingleRow`, `onClickRow`, `onClearSelection`
- **Export** — `setExportRows`

### `IDataTableProps`
TypeScript interface defining all accepted props.

### Custom `filterTypes`
- `hasLength` — filters rows where the specified column has a non-empty array value.

### Custom `sortTypes`
- `boolean`, `caseInsensitive`, `dateStrings`, `hasLength`, `hostPolicyStatus`

## Usage Example

```typescript
import DataTable from "components/DataTable";

<DataTable
  columns={myColumns}
  data={myData}
  isLoading={isFetching}
  sortHeader="name"
  sortDirection="asc"
  onSort={(header, direction) => fetchSorted(header, direction)}
  disableMultiRowSelect={false}
  showMarkAllPages={false}
  isAllPagesSelected={false}
  defaultPageSize={20}
  isClientSidePagination
  onClientSidePaginationChange={(pageIndex) => setPageParam(pageIndex)}
  isClientSideFilter
  searchQuery={query}
  searchQueryColumn="name"
  setExportRows={(rows) => setExportData(rows)}
/>
```

## Notes

- Wraps [react-table v7](https://react-table-v7-docs.netlify.app/docs/api/usetable) with Fleet-specific extensions.
- Uses `useDebouncedCallback` (300ms) for client-side column filter updates.
- Set `persistSelectedRows={true}` to retain row selection across filter/pagination changes.
- Set `autoResetPage={false}` to prevent page resets when column ordering changes (e.g., after an action modifies data).
- Avoid index-only `getRowId` in server-side paginated or selectable tables to prevent ID collisions across pages.
