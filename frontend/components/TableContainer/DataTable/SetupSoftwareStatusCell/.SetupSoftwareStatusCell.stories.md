Storybook stories for the `SetupSoftwareStatusCell` component, showcasing all possible installation status states within a table cell context.

## Key Components

- **`meta`** — Storybook metadata registering the component under `Components/TableContainer/SetupSoftwareStatusCell`
- **`Pending`** — Story rendering the cell with `status: "pending"`
- **`Installing`** — Story rendering the cell with `status: "running"`
- **`Installed`** — Story rendering the cell with `status: "success"`
- **`Failure`** — Story rendering the cell with `status: "failure"`

## Usage Example

```typescript
import SetupSoftwareStatusCell from "./SetupSoftwareStatusCell";

// Render each status variant directly
<SetupSoftwareStatusCell status="pending" />
<SetupSoftwareStatusCell status="running" />
<SetupSoftwareStatusCell status="success" />
<SetupSoftwareStatusCell status="failure" />
```

## Status Values

| Story | `status` prop |
|---|---|
| `Pending` | `"pending"` |
| `Installing` | `"running"` |
| `Installed` | `"success"` |
| `Failure` | `"failure"` |
