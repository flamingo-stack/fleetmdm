Renders a status cell for setup software steps, mapping server-side `SetupStepStatus` values to user-friendly labels and corresponding icons (or a spinner for active installation).

## Key Components

- **`ISetupSoftwareStatusCell`** — Props interface accepting a single `status: SetupStepStatus` value
- **`serverToUiStatus()`** — Pure mapping function that converts server status strings to display label/icon pairs:
  - `"pending"` → "Pending" + `pending-outline` icon
  - `"running"` → "Installing" + spinner
  - `"success"` → "Installed" + `success` icon
  - `"failure"` / `"cancelled"` → "Failed" + `error` icon
- **`SetupSoftwareStatusCell`** — Default export React component rendering the icon/spinner and label

## Usage Example

```typescript
import SetupSoftwareStatusCell from "components/SetupSoftwareStatusCell";

// Inside a table or list row:
<SetupSoftwareStatusCell status="running" />
// Renders: [Spinner] Installing

<SetupSoftwareStatusCell status="success" />
// Renders: [✓ Icon] Installed

<SetupSoftwareStatusCell status="failure" />
// Renders: [✗ Icon] Failed
```

## Notes

- The `"running"` status renders a `Spinner` (x-small, no container, no delay) instead of a static icon to indicate active progress
- Unknown/unhandled status values fall through to the `"pending"` default
- Styled via BEM-style class `setup-software-status-cell`
