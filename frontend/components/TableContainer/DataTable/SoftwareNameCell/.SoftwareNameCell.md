A table cell component for displaying software names with icons, installation type indicators, and contextual tooltips across different page contexts (device user, host details, software library).

## Key Components

- **`SoftwareNameCell`** *(default export)* — Main cell component rendering a software icon, display name, and optional install-type suffix. Adapts its behavior (clickable link, fake link, or static text) based on `pageContext`, `router`, and `path` props.
- **`InstallIconWithTooltip`** *(named export)* — Renders an install-type icon with a contextual tooltip. Supports four install types: `manual`, `selfService`, `automatic`, and `automaticSelfService`.
- **`installIconMap`** — Static map from `InstallType` to icon name and tooltip factory, centralizing all install-mode display logic.
- **`getInstallIconType`** — Derives the correct `InstallType` from `isSelfService` and `automaticInstallPoliciesCount`.
- **`PageContext`** — Union type (`"deviceUser" | "hostDetails" | "hostDetailsLibrary"`) that controls rendering behavior and tooltip copy.

## Usage Example

```typescript
// Basic clickable cell with installer icon
<SoftwareNameCell
  name="zoom"
  display_name="Zoom"
  source="homebrew_packages"
  path="/software/123"
  router={router}
  pageContext="hostDetails"
  hasInstaller
  isSelfService={false}
  automaticInstallPoliciesCount={2}
/>

// Self-service + automatic policy install (combined icon)
<InstallIconWithTooltip
  isSelfService
  automaticInstallPoliciesCount={1}
  pageContext="hostDetails"
  isIosOrIpadosApp={false}
  isAndroidPlayStoreApp={false}
/>

// Static (non-navigable) cell — e.g. My Device self-service row
<SoftwareNameCell
  name="slack"
  pageContext="deviceUser"
  isSelfService
/>
```

## Rendering Logic

| `pageContext` | `router`/`path` | Installer | Output |
|---|---|---|---|
| `deviceUser` + not self-service | — | — | Fake `LinkCell` (row opens modal) |
| Any | Missing | — | Static `TooltipTruncatedTextCell` |
| Any | Present | `false` | `LinkCell` without suffix |
| Any | Present | `true` | `LinkCell` + `InstallIconWithTooltip` |
