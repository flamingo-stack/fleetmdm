Renders a table cell that automatically detects text overflow and displays a tooltip with the full content only when the text is truncated.

## Key Components

- **`TooltipTruncatedTextCell`** — Default export. A React component that wraps cell content in a `ReactTooltip`, enabling the tooltip only when the rendered text is visually truncated.
- **`ITooltipTruncatedTextCellProps`** — Interface defining component props.
- **Truncation detection** — Uses `useLayoutEffect` with `scrollWidth` vs `offsetWidth` comparison on a `ref`-attached `<span>` to determine if a tooltip should be active.
- **`prefix` / `suffix`** — Optional non-truncated content rendered before/after the main value.
- **`tooltip`** — Optional override for tooltip content; falls back to displaying `value` if omitted.

## Usage Example

```typescript
import TooltipTruncatedTextCell from "components/TooltipTruncatedTextCell";

// Basic usage — tooltip shows full text only when truncated
<TooltipTruncatedTextCell
  value="This is a very long string that may be truncated..."
/>

// Custom tooltip content with word-break and suffix
<TooltipTruncatedTextCell
  value="app.bundle.identifier.very.long"
  tooltip={<span>Full identifier: <strong>app.bundle.identifier.very.long</strong></span>}
  tooltipBreakOnWord
  suffix={<span>(3)</span>}
/>
```

## Notes

- Tooltip is **disabled by default** (`tooltipDisabled: true`) and only enabled after the layout effect confirms overflow, preventing unnecessary tooltips on short values.
- Null, undefined, or empty string values are replaced with `DEFAULT_EMPTY_CELL_VALUE`, which suppresses the tooltip via `isDefaultValue`.
- Includes a `<div className="safari-hack">` workaround to prevent triple-click selection spilling into adjacent DOM elements in Safari.
