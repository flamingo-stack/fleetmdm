Unit tests for the `PlatformCell` component, verifying correct platform icon rendering order and empty state handling.

## Key Components

- **`QUERYABLE_PLATFORMS`** — Test fixture array of all four queryable platforms: `windows`, `darwin`, `linux`, `chrome`
- **`renders platform icons in correct order`** — Asserts that icons render in the sequence: Apple → Windows → Linux → Chrome, regardless of input order
- **`renders --- when no platforms passed in`** — Asserts that an empty `platforms` array displays the `---` fallback string

## Usage Example

```typescript
// Running the tests
// From the repository root:
// npx jest PlatformCell.tests.tsx

// The component under test accepts:
<PlatformCell platforms={["windows", "darwin", "linux", "chrome"]} />

// Empty state:
<PlatformCell platforms={[]} />
```

## Notes

- Tests use `queryByTestId` to locate individual platform icons (`darwin-icon`, `windows-icon`, `linux-icon`, `chrome-icon`) and the wrapping `icons` container
- DOM sibling traversal (`firstChild`, `nextSibling`) is used to assert strict render order
- The empty-state test uses a case-insensitive regex (`/---/i`) via `getByText`
