Storybook stories file for the `PlatformCell` table component, providing visual development and testing stories for platform indicator cells.

## Key Components

- **`meta`** — Storybook metadata configuration registering `PlatformCell` under `Components/Table/PlatformCell` with default args covering all four platforms (`darwin`, `windows`, `linux`, `chrome`)
- **`Basic`** — Default story rendering `PlatformCell` with all supported platform values

## Usage Example

```typescript
// Extend with custom story variants
export const SinglePlatform: Story = {
  args: {
    platforms: ["darwin"],
  },
};

export const CrossPlatform: Story = {
  args: {
    platforms: ["windows", "linux"],
  },
};
```

## Notes

- Default args pre-populate all four supported platforms for quick visual reference
- Located at [`frontend/.../PlatformCell/PlatformCell.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/Table/PlatformCell/PlatformCell.stories.tsx)
- Relies on the `PlatformCell` component exported from the adjacent `index` file
