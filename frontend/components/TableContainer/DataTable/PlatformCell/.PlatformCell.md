Renders a table cell displaying platform icons (macOS, Windows, Linux, ChromeOS) for a given list of supported platforms, falling back to a `"---"` text cell when no platforms are provided.

## Key Components

- **`IPlatformCellProps`** — Props interface accepting a `platforms` array of `QueryablePlatform` values
- **`ICONS`** — Maps platform string keys to their corresponding `QueryablePlatform` icon identifiers
- **`DISPLAY_ORDER`** — Defines the canonical rendering order: `darwin → windows → linux → chrome`
- **`PlatformCell`** — Default export; the main cell component that maps platforms to `Icon` components

## Usage Example

```typescript
import PlatformCell from "components/TableContainer/DataTable/PlatformCell";

// Renders macOS and Windows icons
<PlatformCell platforms={["darwin", "windows"]} />

// Renders a "---" fallback for all-platform queries or empty arrays
<PlatformCell platforms={[]} />
```

## Behavior Notes

- Platforms are always rendered in the fixed `DISPLAY_ORDER` regardless of input order
- Chrome is included in the icon map and display order but is noted as unsupported for scheduled queries
- Any platform not present in `ICONS` is silently skipped (`null` returned)
- The wrapper `<span>` includes a `data-testid="icons"` attribute for test selection
