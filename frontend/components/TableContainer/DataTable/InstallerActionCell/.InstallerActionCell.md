Renders the action cell for Fleet Maintained App (FMA) installer rows in a software table, displaying either an unavailability message, an "already added" success icon with tooltip, or an "Add" button to navigate to the app's details page.

## Key Components

### `InstallerActionCell` (default export)
A table cell component with three render states:

| State | Condition | Output |
|-------|-----------|--------|
| Unavailable | `value` is `null`/`undefined` | `TextCell` with tooltip: *"Currently unavailable for this platform."* |
| Already added | `softwareTitleId` is set | Success icon wrapped in a tooltip linking to the existing software title |
| Add | `softwareTitleId` is absent | Pill `Button` labeled **Add** that navigates to the FMA details page |

### Props — `IInstallerActionCellProps`

| Prop | Type | Description |
|------|------|-------------|
| `value` | `Omit<IFleetMaintainedApp, "name" \| "version"> \| null` | FMA data for the row |
| `router` | `InjectedRouter` | React Router instance for programmatic navigation |
| `className` | `string` | Additional CSS class (defaults to `"w250"`) |
| `teamId` | `number` | Team/fleet ID appended as `fleet_id` query param |

## Usage Example

```typescript
import InstallerActionCell from "components/TableContainer/DataTable/InstallerActionCell";

<InstallerActionCell
  value={{ id: 42, software_title_id: undefined, /* ...other FMA fields */ }}
  router={router}
  teamId={3}
/>

// Already added — shows success icon with tooltip
<InstallerActionCell
  value={{ id: 42, software_title_id: 7 }}
  router={router}
  teamId={3}
/>

// Unsupported platform — shows empty/unavailable cell
<InstallerActionCell value={null} />
```
