Renders a table cell for live query host status, displaying the host's display name alongside a contextual warning or error icon tooltip when the host is offline or has a high distributed interval.

## Key Components

- **`ILiveQueryIssueCellProps`** — Interface defining the component's props:
  - `displayName`: The host's display name shown in the cell
  - `distributedInterval`: Polling interval in seconds; triggers a warning icon if ≥ 60
  - `status`: Host status string (`"online"` | `"offline"`)

- **`LiveQueryIssueCell`** — Default export; conditionally renders an inline icon with a tooltip when action is needed:
  - **No icon** — when `distributedInterval < 60` and `status === "online"`
  - **Warning icon** (`status-warning`) — host is online but slow to respond; tooltip shows expected delay in seconds
  - **Error icon** (`status-error`) — host is `"offline"`; tooltip warns the host won't respond

## Usage Example

```typescript
import LiveQueryIssueCell from "components/LiveQueryIssueCell";

// No issue icon rendered (fast online host)
<LiveQueryIssueCell
  displayName="web-server-01"
  distributedInterval={30}
  status="online"
/>

// Warning icon: slow distributed interval
<LiveQueryIssueCell
  displayName="web-server-01"
  distributedInterval={120}
  status="online"
/>

// Error icon: offline host
<LiveQueryIssueCell
  displayName="db-replica-03"
  distributedInterval={60}
  status="offline"
/>
```

## Notes

- Uses `TooltipWrapper` with `position="top"`, arrow enabled, and `underline={false}` for unobtrusive inline display
- Icon color maps directly to Fleet's design token system (`status-error`, `status-warning`)
