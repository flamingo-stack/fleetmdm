React Testing Library test suite for the `DataTable` component, verifying rendering, sorting behavior, and conditional help text display.

## Key Components

- **`DataTable` render test** — Confirms column headers and data cells render correctly from `columns` and `data` props
- **Sort header test** — Validates that changing `sortHeader` reorders columns correctly (rerenders with `address` vs `name`)
- **Sort direction test** — Verifies `sortDirection="asc"` and `sortDirection="desc"` produce correctly ordered rows
- **Help text tests** — Asserts `renderTableHelpText` renders only when rows are present, and is suppressed during loading with empty data

## Usage Example

```typescript
// Minimal DataTable render
render(
  <DataTable
    columns={[{ title: "Name", Header: "Name", accessor: "name", disableHidden: false }]}
    data={[{ name: "Test User", id: 1 }]}
    sortHeader="name"
    sortDirection="desc"
    isLoading={false}
    onSort={noop}
    showMarkAllPages={false}
    isAllPagesSelected={false}
    resultsTitle="users"
    defaultPageSize={20}
    disableMultiRowSelect={false}
  />
);

expect(screen.getByText("Name")).toBeInTheDocument();
expect(screen.getByText("Test User")).toBeInTheDocument();
```

## Test Coverage Summary

| Test Case | Assertion |
|---|---|
| Basic render | Header and cell text present in DOM |
| Sort by column | Cell order matches active `sortHeader` |
| Sort direction | `asc`/`desc` reverses row order |
| Help text hidden | Returns `null` when `data` is empty |
| Help text shown | Renders when rows exist |
