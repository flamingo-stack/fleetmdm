Unit tests for the `IssueCell` component, verifying its rendering behavior based on issue count data.

## Key Components

- **`Issue cell` suite** — Top-level `describe` block grouping all `IssueCell` rendering tests.
- **`renders --- if total issues count is 0`** — Asserts that the cell displays a `---` placeholder when both `total_issues_count` and `failing_policies_count` are `0`.

## Usage Example

```typescript
// Render IssueCell with zero issues and assert empty state placeholder
render(
  <IssueCell
    issues={{
      total_issues_count: 0,
      failing_policies_count: 0,
    }}
    rowId={1}
  />
);

expect(screen.getByText(/---/i)).toBeInTheDocument();
```

## Notes

- Uses `@testing-library/react` (`render`, `screen`) for DOM assertions.
- The `---` placeholder is matched case-insensitively via regex, making the assertion resilient to minor text casing changes.
- Additional test cases for non-zero issue counts are not yet covered and may be candidates for future expansion.
