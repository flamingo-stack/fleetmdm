A table cell component that renders host issue indicators, displaying either a muted placeholder or an `IssuesIndicator` when issues exist.

## Key Components

### `IIssueCellProps`
| Prop | Type | Description |
|------|------|-------------|
| `issues` | `object` | Contains `total_issues_count`, `failing_policies_count`, and optional `critical_vulnerabilities_count` |
| `rowId` | `number` | Unique row identifier passed to the issues indicator |

### `IssueCell`
Default export. Renders a muted dash (`DEFAULT_EMPTY_CELL_VALUE`) when `issues` is empty or `total_issues_count` is `0`; otherwise delegates to `IssuesIndicator`.

## Usage Example

```typescript
import IssueCell from "components/IssueCell";

<IssueCell
  issues={{
    total_issues_count: 3,
    critical_vulnerabilities_count: 1,
    failing_policies_count: 2,
  }}
  rowId={42}
/>
```

## Notes

- Returns a plain `<span className="text-muted">` with `DEFAULT_EMPTY_CELL_VALUE` when there are no issues — avoids rendering an empty indicator.
- `critical_vulnerabilities_count` is optional; the component passes it through to `IssuesIndicator` which handles `undefined` gracefully.
