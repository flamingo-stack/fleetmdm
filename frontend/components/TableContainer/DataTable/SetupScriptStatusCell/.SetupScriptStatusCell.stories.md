Storybook stories file for the `SetupScriptStatusCell` component, defining visual states for all possible setup script execution statuses.

## Key Components

- **`meta`** — Storybook metadata registering the component under `Components/TableContainer/SetupScriptStatusCell`
- **`Pending`** — Story rendering the cell with `status: "pending"`
- **`Running`** — Story rendering the cell with `status: "running"`
- **`Success`** — Story rendering the cell with `status: "success"`
- **`Failure`** — Story rendering the cell with `status: "failure"`

## Usage Example

```typescript
import { SetupScriptStatusCell } from "./SetupScriptStatusCell";

// Render a specific status in a table row
<SetupScriptStatusCell status="pending" />
<SetupScriptStatusCell status="running" />
<SetupScriptStatusCell status="success" />
<SetupScriptStatusCell status="failure" />
```
