A React cell component that renders the execution status of a setup script step, mapping server-side `SetupStepStatus` values to user-friendly labels and icons.

## Key Components

- **`SetupScriptStatusCell`** — Default export. Accepts a `status` prop and renders the corresponding icon and label.
- **`serverToUiStatus`** — Internal mapper that converts a `SetupStepStatus` enum value to a display label and icon name.
- **`ISetupScriptStatusCell`** — Props interface accepting a single `status: SetupStepStatus` field.

### Status Mappings

| Server Status | Label | Icon |
|---|---|---|
| `pending` | Pending | `pending-outline` |
| `running` | Running | `spinner` (animated) |
| `success` | Ran | `success` |
| `failure` / `cancelled` | Failed | `error` |

> When status is `running`, an animated `<Spinner>` replaces the static `<Icon>` component.

## Usage Example

```typescript
import SetupScriptStatusCell from "components/SetupScriptStatusCell";

// Inside a table row or list
<SetupScriptStatusCell status="running" />
<SetupScriptStatusCell status="success" />
<SetupScriptStatusCell status="failure" />
```
