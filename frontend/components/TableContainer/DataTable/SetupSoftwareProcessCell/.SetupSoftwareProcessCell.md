A React cell component that displays a software installation entry with an icon and label, used within setup/onboarding software process tables.

## Key Components

- **`SetupSoftwareProcessCell`** — Default export. Renders a small `SoftwareIcon` alongside an "Install **{name}**" label.
- **`ISetupSoftwareProcessCell`** — Props interface:
  - `name` — Display name shown in the label (falls back to `"Unknown software"`).
  - `iconName` *(optional)* — Raw software title passed to `SoftwareIcon` for icon lookup. Useful when the display `name` has been overridden (e.g. Fleet Mobile Apps without a custom `icon_url`) and won't match the known-icon registry.
  - `url` *(optional)* — Icon URL passed directly to `SoftwareIcon`; takes precedence over name-based matching.

## Usage Example

```typescript
import SetupSoftwareProcessCell from "./SetupSoftwareProcessCell";

// Basic usage with display name only
<SetupSoftwareProcessCell name="Google Chrome" />

// With a raw icon name fallback (display name differs from registry key)
<SetupSoftwareProcessCell
  name="Chrome Browser"
  iconName="Google Chrome"
  url={null}
/>

// With a custom icon URL
<SetupSoftwareProcessCell
  name="Acme Agent"
  iconName="Acme Agent"
  url="https://cdn.example.com/acme-icon.png"
/>
```

## Notes

- `iconName` defaults to `name` when omitted (`iconName ?? name ?? ""`), so passing it explicitly is only necessary when the display name diverges from the known-icon lookup key.
