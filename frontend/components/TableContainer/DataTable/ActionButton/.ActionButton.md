A reusable action button component that renders a configurable button with optional icon, tooltip, and dynamic show/hide logic — designed for use in table row actions or bulk-action toolbars.

## Key Components

### `IActionButtonProps`
| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Used to generate a scoped CSS class via `kebabCase` |
| `buttonText` | `string \| ((targetIds) => string)` | Static label or dynamic function resolving text from selected IDs |
| `onClick` | `(ids: number[]) => void` | Click handler receiving current `targetIds` |
| `targetIds` | `number[]` | IDs of selected rows/items passed to callbacks |
| `hideButton` | `boolean \| ((ids) => boolean)` | Conditionally hides the button |
| `iconSvg` | `IconNames` | Optional icon rendered left or right of label |
| `tooltipContent` | `React.ReactNode` | Wraps button in a `TooltipWrapper` when provided |
| `isDisabled` | `boolean` | Applies a disabled CSS modifier class |

### `useActionCallback`
Internal hook that memoizes the click handler via `useCallback`, preventing unnecessary re-renders.

### `ActionButton`
The default export. Returns `null` when `hideButton` resolves to `true`; otherwise renders the button, optionally wrapped in a `TooltipWrapper`.

## Usage Example

```typescript
import ActionButton from "components/action_button/ActionButton";

// Static label, no tooltip
<ActionButton
  name="delete"
  buttonText="Delete Selected"
  targetIds={selectedIds}
  onClick={(ids) => handleDelete(ids)}
  variant="alert"
  iconSvg="trash"
  iconPosition="left"
/>

// Dynamic label with tooltip and conditional hide
<ActionButton
  name="transfer"
  buttonText={(ids) => `Transfer ${ids.length} Host(s)`}
  targetIds={selectedIds}
  onClick={handleTransfer}
  hideButton={(ids) => ids.length === 0}
  tooltipContent="Select hosts to enable transfer"
/>
```
