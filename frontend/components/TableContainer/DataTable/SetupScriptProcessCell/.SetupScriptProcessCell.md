Renders a table cell displaying a setup script process entry with a shell-file icon and the script name.

## Key Components

- **`ISetupScriptProcessCell`** — Props interface requiring a `name` string for the script filename
- **`SetupScriptProcessCell`** — Default export; a React functional component combining a `Graphic` shell-file icon with a formatted "Run `<script name>`" label

## Usage Example

```typescript
import SetupScriptProcessCell from "components/SetupScriptProcessCell/SetupScriptProcessCell";

<SetupScriptProcessCell name="configure-fleet.sh" />
// Renders: 🗂 Run configure-fleet.sh

<SetupScriptProcessCell name="" />
// Renders: 🗂 Run Unknown script
```

## Notes

- Falls back to `"Unknown script"` when `name` is an empty string or falsy
- Uses the `"file-sh"` graphic variant from the shared `Graphic` component to visually signal a shell script
- BEM-style class `setup-script-process-cell` scopes all styles to this component
