A generic column filter component for React Table that renders a search input in table column headers, with special handling to suppress filtering for the `last_fetched` column.

## Key Components

- **`DefaultColumnFilter`** — Generic React Table filter component accepting `FilterProps<T>` that renders a `SearchField` with a funnel icon inside a `.filter-cell` wrapper
- **`last_fetched` exclusion** — Returns an empty fragment for the `last_fetched` column ID to avoid exposing raw date-string filtering in the UI
- **`setFilter`** — Calls React Table's column `setFilter` with the search string, or `undefined` to clear the filter entirely

## Usage Example

```typescript
import { useTable, useFilters } from "react-table";
import DefaultColumnFilter from "components/elements/filters/DefaultColumnFilter";

const columns = useMemo(
  () => [
    {
      Header: "Name",
      accessor: "name",
      Filter: DefaultColumnFilter,
    },
    {
      Header: "Last Fetched",
      accessor: "last_fetched",
      // DefaultColumnFilter will render nothing for this column
      Filter: DefaultColumnFilter,
    },
  ],
  []
);

const tableInstance = useTable({ columns, data }, useFilters);
```

## Notes

- Propagation is stopped on click (`e.stopPropagation()`) to prevent sort toggling when interacting with the filter input
- Setting an empty string converts to `undefined` to ensure React Table removes the filter predicate entirely rather than filtering on an empty value
