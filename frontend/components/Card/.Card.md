A foundational layout primitive that renders styled card containers with configurable border radius, padding, color, and optional shadow — used as the base for components like `InfoBanner`, `HostCountCard`, and `SectionCard`.

## Key Components

**`Card`** — Default export. Renders either a `<div>` or a React Router `<Link>` depending on whether a `path` prop is provided.

**`ICardProps`**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `borderRadiusSize` | `BorderRadiusSize` | `"small"` | Maps to design system border radius tokens in `_global.scss` |
| `color` | `CardColor` | `"white"` | Background color: `white`, `grey`, or `yellow` |
| `paddingSize` | `PaddingSize` | `"large"` | Maps to design system padding tokens in `padding.scss` |
| `includeShadow` | `boolean` | `false` | Adds drop shadow styling |
| `path` | `string` | — | Renders as a `<Link>` for right-click support |
| `largePadding` | `boolean` | `false` | ⚠️ Deprecated — use `paddingSize` instead |

## Usage Example

```typescript
// Basic card
<Card color="grey" borderRadiusSize="medium" paddingSize="xlarge">
  <p>Card content here</p>
</Card>

// Clickable card with shadow
<Card
  path="/hosts/details"
  includeShadow
  borderRadiusSize="large"
  paddingSize="small"
>
  <HostCountCard count={42} />
</Card>
```

## Notes

- When `path` is provided, the card renders as a React Router `<Link>` to preserve native right-click/open-in-new-tab behavior.
- `largePadding` is deprecated; migrate usages to `paddingSize="xxlarge"` or equivalent.
- Class names are composed via `classnames` and follow the BEM-style pattern `card__<modifier>`.
