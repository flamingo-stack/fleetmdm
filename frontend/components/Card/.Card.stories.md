Storybook stories for the `Card` component, providing a default story configuration with basic rendering.

## Key Components

- **`meta`** — Storybook `Meta` configuration for the `Card` component, registered under `Components/Card` with default `children` prop set to `"card content"`
- **`Default`** — A baseline `Story` that renders the `Card` using the shared `meta` args

## Usage Example

```typescript
import { Default } from "./Card.stories";

// Render the Default Card story in tests or Storybook
<Default />
```

## Notes

- Stories are colocated with the `Card` component index file (`./index`)
- Extend by adding new named exports of type `Story` to cover additional variants
