Barrel export file for the TargetLabelSelector component family, consolidating all public exports into a single entry point.

## Key Components

- **`TargetLabelSelector`** – Default export of the main label selector component
- **`DropdownTargetLabelSelector`** – Default export of the dropdown variant of the label selector
- **`ILabelConfig`** – Type defining label configuration shape
- **`ITargetLabelSelectorProps`** – Type defining props for the `TargetLabelSelector` component
- **`LabelTargetMode`** – Type representing the targeting mode for labels
- **`TargetType`** – Type representing the type of target being selected

## Usage Example

```typescript
import {
  TargetLabelSelector,
  DropdownTargetLabelSelector,
} from "components/TargetLabelSelector";

import type {
  ILabelConfig,
  ITargetLabelSelectorProps,
  LabelTargetMode,
  TargetType,
} from "components/TargetLabelSelector";
```
