Test suite for the `DropdownTargetLabelSelector` component, verifying rendering behavior across target type selections, label states, and configurable display options.

## Key Components

### Test Groups

- **Custom target rendering** — Validates the custom target selector appears when `selectedTargetType` is `"Custom"`, including dropdown presence with `customTargetOptions` and help text fallback via `customHelpText`
- **All hosts suppression** — Confirms the custom selector and label checkboxes are hidden when `selectedTargetType` is `"All hosts"`
- **Label check state** — Verifies labels render as checked/unchecked based on the `selectedLabels` map
- **Title/subtitle display** — Covers default title (`"Target"`), custom title, `suppressTitle` prop, and optional `subTitle`

## Usage Example

```typescript
// Run the test suite
npx jest DropdownTargetLabelSelector.tests.tsx

// Example props exercised in tests
<DropdownTargetLabelSelector
  selectedTargetType="Custom"
  selectedCustomTarget="labelIncludeAny"
  customTargetOptions={[{ value: "labelIncludeAny", label: "Include any" }]}
  selectedLabels={{ "label 1": true, "label 2": false }}
  labels={[
    { id: 1, name: "label 1", label_type: "regular" },
    { id: 2, name: "label 2", label_type: "regular" },
  ]}
  onSelectCustomTarget={noop}
  onSelectLabel={noop}
  onSelectTargetType={noop}
  title="Choose a target"
  subTitle="Select one of the following options"
  suppressTitle={false}
/>
```
