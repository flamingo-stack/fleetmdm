Test suite for the `TargetLabelSelector` component, validating tab rendering, mode toggles, label selection state, cross-tab disabling logic, and empty state behavior.

## Key Components

- **`LABELS`** — Fixture array of two `ILabelSummary` objects used across tests
- **`makeTab(overrides)`** — Factory that builds a partial `ILabelConfig` with safe defaults (`noop` handlers, empty `selectedLabels`)
- **`renderSelector(props)`** — Wrapper around `render` that provides fully-defaulted props for `TargetLabelSelector`, allowing per-test overrides

## Test Cases

| Test | What it verifies |
|------|-----------------|
| Include/Exclude tabs visible | Both tabs and all label checkboxes render in `Custom` target mode |
| `All hosts` target type | Tabs and checkboxes are absent when `selectedTargetType` is `"All hosts"` |
| Any/All mode toggle | `Any` and `All` radio buttons appear on the Include tab |
| `showModeToggle: false` | Mode radios are absent on the Exclude tab when the flag is off |
| `selectedLabels` state | Checked/unchecked state maps correctly from `selectedLabels` object |
| Cross-tab disabling | A label selected in Exclude is `aria-disabled="true"` on the Include tab |
| Empty state | Renders `"No labels"` heading, description text, and calls `onAddLabel` on button click |

## Usage Example

```typescript
// Run the full test suite
npx jest TargetLabelSelector.tests.tsx

// Run a single test by name
npx jest --testNamePattern="disables a label in the include tab"
```
