A React component that provides a host targeting UI, allowing users to select either "All hosts" or a "Custom" label-based target with tabbed Include/Exclude label scopes.

## Key Components

### Exported Types
- **`LabelTargetMode`** — `"any" | "all"` — controls whether matching requires any or all selected labels
- **`TargetType`** — `"All hosts" | "Custom"` — top-level targeting mode
- **`ILabelConfig`** — configuration object for a single label tab (selected labels, mode toggle, callbacks, tooltips)
- **`ITargetLabelSelectorProps`** — full props interface for the main component

### Internal Components
- **`TargetTypeChooser`** — Radio group to switch between "All hosts" and "Custom"
- **`CustomTargetTabs`** — Tabbed panel with "Include" and "Exclude" tabs; handles search, loading, and error states
- **`LabelTabContent`** — Renders search field, selected badges, checkbox list, and optional mode toggle within a tab
- **`LabelModeToggle`** — Any/All radio pair controlling `LabelTargetMode` per tab
- **`LabelCheckboxList`** — Renders checkboxes for each label; disables labels selected in the opposing tab
- **`SelectedLabelBadges`** — Dismissible badge chips for currently selected labels
- **`NoLabelsEmptyState`** — Empty state with an "Add label" CTA

## Usage Example

```typescript
import TargetLabelSelector, {
  ILabelConfig,
  TargetType,
} from "components/TargetLabelSelector";

const [targetType, setTargetType] = useState<TargetType>("All hosts");
const [includeLabels, setIncludeLabels] = useState<Record<string, boolean>>({});
const [includeMode, setIncludeMode] = useState<LabelTargetMode>("any");

const includeConfig: ILabelConfig = {
  selectedLabels: includeLabels,
  onSelectLabel: ({ name, value }) =>
    setIncludeLabels((prev) => ({ ...prev, [name]: value })),
  showModeToggle: true,
  mode: includeMode,
  onSelectMode: setIncludeMode,
};

<TargetLabelSelector
  selectedTargetType={targetType}
  onSelectTargetType={setTargetType}
  labels={labels}
  includeConfig={includeConfig}
  excludeConfig={excludeConfig}
  emptyStateDescription="Add labels to target specific hosts."
  onAddLabel={() => router.push("/labels/new")}
  isLoadingLabels={isLoading}
  isErrorLabels={isError}
/>
```

> Labels selected in the Include tab are automatically disabled in the Exclude tab (and vice versa) to prevent conflicting selections.
