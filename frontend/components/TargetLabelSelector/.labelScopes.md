Defines the `LabelScope` type and generates label-scope dropdown options for targeting hosts in policies and reports.

## Key Components

- **`LabelScope`** – Union type representing the three scoping modes: `"labelsIncludeAny"`, `"labelsIncludeAll"`, and `"labelsExcludeAny"`.
- **`getCustomTargetOptions`** – Returns an array of `IDropdownOption` items for the "Custom" target dropdown, gated by tier and entity type.

## Availability Matrix

| Option | Always shown | Premium only | Policy only |
|---|---|---|---|
| Include any | ✅ | | |
| Include all | | ✅ | |
| Exclude any | | | ✅ |

## Usage Example

```typescript
import { getCustomTargetOptions } from "./labelScopes";

// For a premium policy form
const options = getCustomTargetOptions({
  entity: "policy",
  isPremiumTier: true,
});
// Returns: [includeAny, includeAll, excludeAny]

// For a free-tier report form
const reportOptions = getCustomTargetOptions({
  entity: "report",
  isPremiumTier: false,
});
// Returns: [includeAny]
```
