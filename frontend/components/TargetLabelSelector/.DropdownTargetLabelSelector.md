A compound form component that lets users target either "All hosts" or a "Custom" subset of hosts filtered by labels, with an optional dropdown for selecting the label-matching mode (e.g., include any / include all / exclude any).

## Key Components

| Component/Interface | Description |
|---|---|
| `DropdownTargetLabelSelector` | Root export; composes `TargetChooser` and `LabelChooser` |
| `TargetChooser` | Radio group toggling between `"All hosts"` and `"Custom"` |
| `LabelChooser` | Renders a dropdown (label mode) + checkboxes for individual labels; handles loading/error/empty states |
| `IDropdownTargetLabelSelectorProps` | Full prop contract for the root component |

## Usage Example

```typescript
import DropdownTargetLabelSelector from "components/DropdownTargetLabelSelector";

const MyForm = () => {
  const [targetType, setTargetType] = useState("All hosts");
  const [customTarget, setCustomTarget] = useState("include_any");
  const [selectedLabels, setSelectedLabels] = useState<Record<string, boolean>>({});

  const handleLabelChange = ({ name, value }: { name: string; value: boolean }) => {
    setSelectedLabels((prev) => ({ ...prev, [name]: value }));
  };

  return (
    <DropdownTargetLabelSelector
      selectedTargetType={targetType}
      selectedCustomTarget={customTarget}
      customTargetOptions={[
        { label: "Include any", value: "include_any", helpText: "Hosts matching any label" },
        { label: "Exclude any", value: "exclude_any", helpText: "Hosts not matching any label" },
      ]}
      selectedLabels={selectedLabels}
      labels={myLabels}
      isLoadingLabels={isLoading}
      isErrorLabels={isError}
      onSelectTargetType={setTargetType}
      onSelectCustomTarget={setCustomTarget}
      onSelectLabel={handleLabelChange}
      title="Target"
    />
  );
};
```

## Notes

- When `selectedTargetType` is `"All hosts"`, the `LabelChooser` is hidden entirely.
- `dropdownHelpText` overrides the per-option `helpText` defined in `customTargetOptions`.
- Use `suppressTitle` to hide the field label, or `subTitle` for additional context beneath it.
- For the tabbed include + exclude UX, use the sibling `TargetLabelSelector` component instead.
