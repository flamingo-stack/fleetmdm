A React component that renders a yellow informational banner warning users that their Fleet Premium license is nearing expiration, with a link to downgrade or renew.

## Key Components

- **`LicenseExpirationBanner`** — Default export; a functional component wrapping `InfoBanner` with a fixed yellow color, expiration message, and a CTA link.
- **`InfoBanner`** — Base banner UI component used for layout and styling.
- **`CustomLink`** — Renders the "Downgrade or renew" CTA pointing to `https://fleetdm.com/learn-more-about/downgrading`, opening in a new tab.

## Usage Example

```typescript
import LicenseExpirationBanner from "components/LicenseExpirationBanner";

const AppLayout = () => (
  <div>
    <LicenseExpirationBanner />
    {/* rest of layout */}
  </div>
);
```
