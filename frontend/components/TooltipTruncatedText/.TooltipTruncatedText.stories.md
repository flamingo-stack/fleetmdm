Storybook stories file for the `TooltipTruncatedText` component, providing interactive demos for testing tooltip behavior on truncated text within configurable container widths.

## Key Components

- **`Default`** — Primary story with a resizable container controlled via a range slider (`containerWidth`: 50–900px). Demonstrates that the tooltip only appears when text is genuinely truncated.
- **`UsedInsideDataSet`** — Composite story that renders `TooltipTruncatedText` inside a `DataSet` component in horizontal orientation, verifying integration behavior.

## Usage Example

```typescript
// Default story — resize container via Storybook controls panel
export const Default: StoryObj<
  React.ComponentProps<typeof TooltipTruncatedText> & { containerWidth: number }
> = {
  args: {
    containerWidth: 200,
    value: "Resize the container to show tooltip only shows on truncation",
  },
  render: ({ containerWidth, ...args }) => (
    <div style={{ width: containerWidth, padding: "8px" }}>
      <TooltipTruncatedText {...args} />
    </div>
  ),
};

// Composite story — component inside a DataSet
export const UsedInsideDataSet: Story = {
  decorators: [
    (Story) => (
      <DataSet
        title="Example Title"
        value={<Story />}
        orientation="horizontal"
      />
    ),
  ],
};
```

> **Tip:** In the Storybook addons panel, drag the `containerWidth` range control to narrow the container and observe that the tooltip activates only when text overflow actually occurs — not unconditionally.

## Notes

- All stories are constrained to a `200px` max-width decorator by default to simulate real truncation scenarios.
