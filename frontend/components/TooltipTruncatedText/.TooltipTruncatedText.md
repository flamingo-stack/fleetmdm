A React component that renders text with a tooltip that only activates when the text is visually truncated (overflowing its container).

## Key Components

- **`TooltipTruncatedText`** — Default export. Wraps content in a `TooltipWrapper` that is disabled unless the inner text element is truncated.
- **`useCheckTruncatedElement`** — Hook (via `ref`) that detects whether the rendered text exceeds its container width.
- **`ITooltipTruncatedTextCellProps`** — Props interface defining display and tooltip behavior options.

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `React.ReactNode` | — | The text/content to display |
| `tooltip` | `React.ReactNode` | `undefined` | Custom tooltip content; falls back to `value` if omitted |
| `className` | `string` | — | Additional CSS class |
| `tooltipPosition` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | Tooltip placement |
| `isMobileView` | `boolean` | `false` | Adjusts behavior for mobile |
| `fixedPositionStrategy` | `boolean` | `false` | Use fixed positioning inside `overflow: hidden` ancestors |

## Usage Example

```typescript
import TooltipTruncatedText from "components/TooltipTruncatedText";

// Tooltip auto-shows only when the text overflows
<TooltipTruncatedText
  value="This is a very long string that may get truncated"
  className="my-cell"
  tooltipPosition="bottom"
/>

// Custom tooltip content separate from display value
<TooltipTruncatedText
  value="Hostname"
  tooltip={<span>Full hostname: <strong>host.example.com</strong></span>}
  fixedPositionStrategy  // use inside overflow:hidden containers
/>
```
