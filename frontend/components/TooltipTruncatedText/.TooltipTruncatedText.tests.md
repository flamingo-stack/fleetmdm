Unit tests for the `TooltipTruncatedText` component, verifying prop forwarding to `TooltipWrapper` and tooltip enable/disable logic driven by truncation state.

## Key Components

- **`mockedTooltipWrapper`** — Spy on props forwarded to `TooltipWrapper`; replaces internal rendering with a simple `<div>`.
- **`mockedUseCheckTruncatedElement`** — Controls the `isTruncated` boolean returned by the hook, bypassing jsdom's lack of layout computation.

## Test Cases

| Test | Asserts |
|------|---------|
| `fixedPositionStrategy=true` forwarded | Prop reaches `TooltipWrapper` when explicitly set |
| `fixedPositionStrategy` defaults to `false` | Omitting the prop sends `false` |
| Tooltip disabled when not truncated | `disableTooltip: true` when hook returns `false` |
| Tooltip enabled when truncated | `disableTooltip: false` when hook returns `true` |
| `tipContent` falls back to `value` | No `tooltip` prop → `tipContent` equals `value` |
| `tooltip` overrides `value` for `tipContent` | Explicit `tooltip` prop takes precedence |
