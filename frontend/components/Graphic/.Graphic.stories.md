Storybook stories for the `Graphic` component, providing visual documentation and interactive testing within the Storybook UI.

## Key Components

- **`meta`** — Storybook metadata configuration registering the component under `Components/Graphic` with a default `name` prop of `"empty-queries"`
- **`Basic`** — A default story rendering the `Graphic` component with the configured args

## Usage Example

```typescript
import Graphic from "./";

// Render a named graphic asset
<Graphic name="empty-queries" />
```

## Notes

- Stories are located at [`frontend/components/Graphic/Graphic.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/Graphic/Graphic.stories.tsx)
- Additional story variants can be added by extending the `Story` type with custom `args` overrides
