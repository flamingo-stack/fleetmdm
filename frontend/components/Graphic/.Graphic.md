A reusable wrapper component that renders named graphic/illustration assets by looking them up from a central `GRAPHIC_MAP` registry.

## Key Components

- **`IGraphicProps`** — Interface defining component props:
  - `name: GraphicNames` — Key used to look up the graphic from `GRAPHIC_MAP`
  - `className?: string` — Optional CSS class (supports scale workarounds, e.g., `scale-40-24`)
- **`Graphic`** — Default export; resolves the graphic component by name, wraps it in a `div` with a `data-testid` attribute for testing

## Usage Example

```typescript
import Graphic from "components/Graphic";

// Render a named graphic
<Graphic name="empty-table" />

// With custom class for scaling
<Graphic name="empty-table" className="scale-40-24" />

// The rendered output structure:
// <div class="graphic" data-testid="empty-table-graphic">
//   <EmptyTableGraphic />
// </div>
```

## Notes

- The `data-testid` attribute follows the pattern `{name}-graphic`, making it easy to target in tests
- All available graphic names are defined by the `GraphicNames` type exported from `components/graphics`
- Adding new graphics requires updating `GRAPHIC_MAP` in the graphics registry — this component requires no changes
