Navigation component for authentication flows that renders a back/close button and handles keyboard escape key navigation.

## Key Components

- **`AuthenticationNav`** — React functional component that provides navigation controls during authentication screens
- **`useEffect` (Escape key handler)** — Registers a `keydown` listener that redirects to `paths.LOGIN` when the Escape key is pressed, cleaning up on unmount
- **`onClick`** — Navigates to `previousLocation` if provided, otherwise calls `browserHistory.goBack()`

## Props

| Prop | Type | Description |
|------|------|-------------|
| `previousLocation` | `string` (optional) | Explicit path to navigate back to |
| `router` | `InjectedRouter` (optional) | Router instance used for Escape key redirect to login |

## Usage Example

```typescript
import AuthenticationNav from "components/AuthenticationNav";

// With explicit back location
<AuthenticationNav
  previousLocation="/dashboard"
  router={router}
/>

// Without previous location (falls back to browserHistory.goBack())
<AuthenticationNav router={router} />
```

## Behavior Notes

- **Escape key** → redirects to `paths.LOGIN` (requires `router` prop)
- **Close button click** → navigates to `previousLocation` if set, otherwise goes back in browser history
- Renders an inverse-variant `Button` wrapping a `close` `Icon`, styled under the `authentication-nav__back` CSS class
