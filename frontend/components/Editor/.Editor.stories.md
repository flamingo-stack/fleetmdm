Storybook stories for the `Editor` component, covering all major prop combinations including syntax modes, read-only state, copy functionality, error/help text display, and line wrapping behavior.

## Key Components

| Story | Description |
|---|---|
| `Default` | Bash shell script editor with `onChange`/`onBlur` action logging |
| `WithError` | Displays inline syntax error message |
| `WithHelpText` | Shows helper text below the editor |
| `WithTooltip` | Label with an informational tooltip |
| `ReadOnly` | Non-editable editor view |
| `WithCopyButton` | Editor with clipboard copy action enabled |
| `PowerShellMode` | Syntax highlighting set to `powershell` |
| `WrappedLines` | Long-line wrapping via `wrapEnabled` |
| `CustomMaxLines` | Constrains visible height to 3 lines |
| `LongScriptWithCopy` | Realistic multi-command script stress-testing scroll, copy, and overflow |

## Usage Example

```typescript
import Editor from "./Editor";

// Basic shell editor
<Editor
  name="my-editor"
  label="Shell Script"
  mode="sh"
  value="#!/bin/bash\necho 'Hello'"
  onChange={(value) => console.log(value)}
  onBlur={() => console.log("blurred")}
/>

// Read-only PowerShell with copy
<Editor
  name="ps-viewer"
  label="PowerShell Script"
  mode="powershell"
  value="Write-Host 'Hello'"
  readOnly
  enableCopy
/>

// Editor with validation feedback
<Editor
  name="validated-editor"
  label="Script"
  mode="sh"
  value="echo 'bad"
  error="Unclosed string literal"
  helpText="Write valid Bash syntax"
/>
```
