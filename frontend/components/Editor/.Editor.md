A generic, configurable code editor component built on AceEditor with support for syntax highlighting, copy-to-clipboard, labels, tooltips, and form field integration.

## Key Components

- **`Editor`** — Default export. Wraps `react-ace`'s `AceEditor` with additional UI elements including labels, error states, help text, and a copy button.
- **`IEditorProps`** — Interface defining all configurable props for the editor.
- **`onLoadHandler`** — Internal handler that adds an `Escape` key command to blur the editor for keyboard accessibility, then calls the optional `onLoad` prop.
- **`renderCopyButton`** — Renders a copy icon button with a temporary "Copied!" confirmation message when `enableCopy` is true.
- **`renderLabel`** — Renders the label or error message, optionally wrapped in a `TooltipWrapper`.
- **`renderHelpText`** — Renders optional help text below the editor.

## Usage Example

```typescript
import Editor from "components/Editor";

// Controlled editor with shell syntax highlighting and copy support
<Editor
  label="Run Script"
  labelTooltip="Enter your shell script here"
  mode="sh"
  value={scriptValue}
  onChange={(val) => setScriptValue(val)}
  enableCopy
  maxLines={30}
  helpText="Supports bash syntax"
/>

// Read-only editor displaying XML output
<Editor
  mode="xml"
  value={xmlOutput}
  readOnly
  isFormField={false}
  wrapEnabled
/>

// Uncontrolled editor with error state
<Editor
  label="Python Script"
  mode="python"
  defaultValue="print('hello')"
  error="Syntax error on line 3"
  onBlur={() => validateScript()}
/>
```

## Supported Modes

The component ships with pre-imported Ace modes: `sh`, `powershell`, `python`, and `xml`. Pass the mode name via the `mode` prop.
