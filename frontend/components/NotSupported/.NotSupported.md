A simple React component that renders a styled "Not supported" label for use in UI contexts where a feature or value is unavailable.

## Key Components

- **`NotSupported`** — A pre-rendered `<span>` element with the CSS class `not-supported`, exported as both a named and default export.

## Usage Example

```typescript
import NotSupported from "./NotSupported";
import { NotSupported } from "./NotSupported";

// Use directly in JSX
const FeatureCell = ({ isSupported }: { isSupported: boolean }) => (
  <td>{isSupported ? "Yes" : NotSupported}</td>
);
```

> **Note:** `NotSupported` is a static React element (not a component function), so it is used as a value rather than rendered with JSX tags (`<NotSupported />`).
