A reusable dropdown component for action menus, built on `react-select-5`, supporting multiple visual variants (default, button, brand-button, small-button) with customizable menu alignment, placement, tooltips, and disabled states.

## Key Components

### Component
- **`ActionsDropdown`** — Main export. Renders a styled select dropdown that triggers an `onChange` callback with the selected value string without persisting the selection visually.

### Sub-components
- **`CustomDropdownIndicator`** — Renders a chevron icon whose color adapts based on focus/open state and variant.
- **`CustomOption`** — Renders each dropdown option with optional `helpText` and tooltip support via `DropdownOptionTooltipWrapper`.

### Helpers
- **`getOptionBackgroundColor`** — Returns background color for focused vs. unfocused options.
- **`getLeftMenuAlign`** / **`getRightMenuAlign`** — Compute CSS `left`/`right` values from the `menuAlign` prop.

### Interface
- **`IActionsDropdownProps`** — Defines props: `options`, `placeholder`, `onChange`, `disabled`, `isSearchable`, `className`, `menuAlign`, `menuPlacement`, `variant`, `buttonLabel`.

## Usage Example

```typescript
import ActionsDropdown from "components/ActionsDropdown";

const options = [
  { label: "Edit", value: "edit" },
  { label: "Delete", value: "delete", disabled: true, tooltipContent: "No permission" },
];

<ActionsDropdown
  options={options}
  placeholder="Actions"
  onChange={(value) => console.log("Selected:", value)}
  variant="brand-button"
  buttonLabel="Actions"
  menuAlign="right"
  menuPlacement="bottom"
/>
```

## Notes

- The `brand-button` variant renders an external `Button` component in place of the native react-select control, enabling custom chevron rotation animation.
- Selected values are never persisted in the control — the placeholder always remains visible (`controlShouldRenderValue: false`, `value: null`).
- Outside-click detection is handled manually via a `mousedown` listener on `document` for the `brand-button` variant.
