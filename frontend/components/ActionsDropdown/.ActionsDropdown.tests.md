Test suite for the `ActionsDropdown` component, verifying rendering, interaction, and accessibility behaviors using React Testing Library.

## Key Components

- **`DROPDOWN_OPTIONS`** — Shared fixture with three options: `edit-query` (enabled), `show-query` (enabled), and `delete-query` (disabled)
- **`renderWithSetup`** — Custom test utility that wraps React Testing Library's `render` with `userEvent` setup

## Test Cases

| Test | Description |
|------|-------------|
| Renders placeholder and options | Clicks the trigger, asserts all options appear in the DOM |
| Disabled dropdown | Verifies `combobox` role is disabled when `disabled` prop is passed |
| `onChange` callback | Confirms the handler is called with the correct value string on option select |
| Disabled option | Checks that the `Delete` option carries `aria-disabled="true"` |
| Click-outside closes | Asserts options are removed from the DOM after clicking `document.body` |

## Usage Example

```typescript
import { renderWithSetup } from "test/test-utils";
import ActionsDropdown from "./ActionsDropdown";

const options = [
  { disabled: false, label: "Edit", value: "edit-query" },
  { disabled: true, label: "Delete", value: "delete-query" },
];

const { user } = renderWithSetup(
  <ActionsDropdown
    options={options}
    placeholder="Actions"
    onChange={(value) => console.log(value)}
  />
);

// Open dropdown and select an option
await user.click(screen.getByText("Actions"));
await user.click(screen.getByText("Edit"));
```

## Notes

- The `Edit` option appears twice in ARIA when focused — `queryAllByText` at index `[1]` accounts for this
