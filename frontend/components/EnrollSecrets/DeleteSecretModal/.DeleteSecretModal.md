A confirmation modal component for deleting an enrollment secret, warning that hosts will no longer be able to enroll using the deleted secret.

## Key Components

- **`IDeleteSecretModal`** — Props interface defining:
  - `onDeleteSecret` — Callback executed when deletion is confirmed
  - `toggleDeleteSecretModal` — Callback to close/toggle the modal
  - `isUpdatingSecret` — Boolean to display a loading state on the Delete button during the async operation
- **`DeleteSecretModal`** — Default export; renders a `Modal` with a description, an external learn-more link, and confirm/cancel action buttons

## Usage Example

```typescript
import DeleteSecretModal from "components/DeleteSecretModal";

<DeleteSecretModal
  onDeleteSecret={handleDeleteSecret}
  toggleDeleteSecretModal={() => setShowDeleteModal(false)}
  isUpdatingSecret={isLoading}
/>
```

> **Note:** Pressing `Enter` triggers `onDeleteSecret` directly via the `Modal`'s `onEnter` prop, providing keyboard accessibility for the confirmation action.

## External Reference

The modal surfaces a link to FleetDM's documentation on rotating enroll secrets:
https://fleetdm.com/learn-more-about/rotating-enroll-secrets
