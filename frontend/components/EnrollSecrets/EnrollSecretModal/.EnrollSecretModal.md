A modal component for managing host enrollment secrets, displaying existing secrets for a selected team or showing an empty state when none exist.

## Key Components

**`EnrollSecretModal`** — Default export. Renders a `Modal` wrapping either an `EnrollSecretTable` (when secrets exist) or an `EmptyState`, with controls to add, edit, and delete secrets.

**`IEnrollSecretModal`** — Props interface:

| Prop | Type | Description |
|------|------|-------------|
| `selectedTeamId` | `number` | `<=0` resolves to global/unassigned secrets |
| `primoMode` | `boolean` | Suppresses team name display when `true` |
| `onReturnToApp` | `() => void` | Handles modal close/exit |
| `teams` | `ITeam[]` | List of available teams |
| `toggleSecretEditorModal` | `() => void` | Opens the secret editor |
| `toggleDeleteSecretModal` | `() => void` | Opens the delete confirmation |
| `setSelectedSecret` | `Dispatch` | Sets the active secret for edit/delete |
| `globalSecrets` | `IEnrollSecret[]` | Secrets used when no team is selected |

## Usage Example

```typescript
<EnrollSecretModal
  selectedTeamId={0}
  primoMode={false}
  onReturnToApp={() => setShowModal(false)}
  teams={teams}
  toggleSecretEditorModal={() => setShowSecretEditor(true)}
  toggleDeleteSecretModal={() => setShowDeleteModal(true)}
  setSelectedSecret={setSelectedSecret}
  globalSecrets={globalSecrets}
/>
```

## Notes

- When `selectedTeamId <= 0`, secrets are sourced from `globalSecrets` under the label `"Unassigned"`.
- The **Add secret** button is wrapped in `GitOpsModeTooltipWrapper`, disabling it when GitOps mode is active.
