Renders a single enroll secret row with a hidden/masked secret value and optional edit/delete action buttons, used within the enrollment secrets management UI.

## Key Components

- **`EnrollSecretRow`** – Default export. Accepts an `IEnrollSecret` and optional modal toggle callbacks to conditionally render edit/delete controls.
- **`IEnrollSecretRowProps`** – Interface defining props: `secret`, `toggleSecretEditorModal`, `toggleDeleteSecretModal`, and `setSelectedSecret`.
- **`renderEditDeleteButtons`** – Internal helper that wraps pencil/trash icon buttons inside `GitOpsModeTooltipWrapper` to disable them when GitOps mode is active.
- **`InputFieldHiddenContent`** – Displays the secret value in a masked/hidden input field.

## Usage Example

```typescript
<EnrollSecretRow
  secret={enrollSecret}
  toggleSecretEditorModal={() => setShowEditorModal(true)}
  toggleDeleteSecretModal={() => setShowDeleteModal(true)}
  setSelectedSecret={setSelectedSecret}
/>
```

When `toggleSecretEditorModal` and `toggleDeleteSecretModal` are omitted, the row renders in read-only mode with no action buttons — useful for display-only contexts.

## Notes

- Edit/delete buttons are individually disabled via `GitOpsModeTooltipWrapper` when the instance is in GitOps-managed mode, preventing manual secret modification.
- `uniqueId()` from lodash is used to generate stable-unique `key` and `name` attributes at render time.
