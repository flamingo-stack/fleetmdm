Test suite for the `EnrollSecretRow` component, verifying that enrollment secret values are hidden by default and revealed when the visibility toggle icon is clicked.

## Key Components

- **`TEAM_SECRET`** – Mock fixture representing a team enrollment secret with `secret`, `created_at`, and `team_id` fields
- **`describe("Enroll secret row")`** – Test suite grouping for the `EnrollSecretRow` component
- **`it("Hides secret by default...")`** – Single test verifying the show/hide toggle behavior of the secret input field

## Behavior Tested

| Scenario | Expected |
|---|---|
| Initial render | Input field type is `password` (secret hidden) |
| After clicking eye icon | Input field type is `text` (secret visible) |

## Usage Example

```typescript
// Rendering the component under test
const { user, container } = renderWithSetup(
  <EnrollSecretRow secret={TEAM_SECRET} />
);

// Verify initial hidden state
const input = container.querySelector("input");
expect(input?.type === "password").toBeTruthy();

// Simulate toggle click
const eyeIcon = screen.getByTestId("eye-icon");
await user.click(eyeIcon);

// Verify revealed state
expect(container.querySelector("input")?.type === "text").toBeTruthy();
```

The test uses `renderWithSetup` from the shared test utilities, which provides a pre-configured `user` event instance alongside the standard RTL `container`. The eye icon is located via a `data-testid="eye-icon"` attribute on the toggle element within `EnrollSecretRow`.
