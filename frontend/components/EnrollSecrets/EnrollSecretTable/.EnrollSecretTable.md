Renders a list of enrollment secrets as a table, delegating each row to `EnrollSecretRow` with optional edit/delete controls.

## Key Components

- **`EnrollSecretTable`** – Default export. Accepts an array of `IEnrollSecret` objects and conditionally renders rows with or without action handlers.
- **`EnrollSecretRow`** – Re-exported named export from the child component module.
- **`IEnrollSecretRowProps`** – Props interface defining:
  - `secrets` – Array of enroll secrets (or `undefined` to render nothing)
  - `toggleSecretEditorModal` – Optional callback to open the editor modal
  - `toggleDeleteSecretModal` – Optional callback to open the delete confirmation modal
  - `setSelectedSecret` – Optional state setter to track the currently selected secret

## Behavior

| State | Output |
|---|---|
| `secrets` is `undefined` | Returns `null` |
| `secrets` is empty array | Renders *"No active enroll secrets."* message |
| Modal toggles provided | Renders rows with edit/delete action support |
| No modal toggles | Renders read-only rows |

## Usage Example

```typescript
import EnrollSecretTable from "./EnrollSecretTable";

// Read-only display
<EnrollSecretTable secrets={enrollSecrets} />

// With edit/delete actions
<EnrollSecretTable
  secrets={enrollSecrets}
  toggleSecretEditorModal={handleOpenEditor}
  toggleDeleteSecretModal={handleOpenDelete}
  setSelectedSecret={setSelectedSecret}
/>
```
