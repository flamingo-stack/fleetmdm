A modal component for creating or editing Fleet enrollment secrets, with built-in random secret generation and validation.

## Key Components

### `ISecretEditorModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `selectedTeam` | `number` | ID of the team to associate the secret with (`0` = Unassigned) |
| `primoMode` | `boolean` | Hides team name in description when enabled |
| `onSaveSecret` | `(newEnrollSecret: string) => void` | Callback fired with the validated secret string |
| `toggleSecretEditorModal` | `() => void` | Closes the modal |
| `selectedSecret` | `IEnrollSecret \| undefined` | Pre-populates the input when editing an existing secret |
| `isUpdatingSecret` | `boolean` | Shows a loading state on the Save button |

### `randomSecretGenerator()`
Generates a cryptographically random-like 32-character alphanumeric string used as the default value for new secrets.

### Validation
Enforces a minimum length of 32 characters, surfacing an inline field error on both input change and save attempt.

## Usage Example

```typescript
import SecretEditorModal from "components/modals/SecretEditorModal";

<SecretEditorModal
  selectedTeam={3}
  teams={teams}
  selectedSecret={undefined}           // undefined = "Add secret" mode
  isUpdatingSecret={isLoading}
  onSaveSecret={(secret) => handleSave(secret)}
  toggleSecretEditorModal={() => setShowModal(false)}
/>
```

> To edit an existing secret, pass the current `IEnrollSecret` object as `selectedSecret`. The modal title changes to **"Edit secret"** and the input is pre-populated with the existing value.
