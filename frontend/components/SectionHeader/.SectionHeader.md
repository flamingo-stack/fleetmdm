A reusable React component that renders a styled section header with an optional subtitle and right-aligned details panel.

## Key Components

### `ISectionHeaderProps`

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Required. The main heading text rendered in an `<h2>`. |
| `subTitle` | `React.ReactNode` | Optional subtitle displayed below the title. |
| `details` | `JSX.Element` | Optional content rendered on the right side of the header. |
| `wrapperCustomClass` | `string` | Optional CSS class appended to the wrapper `<div>`. |
| `alignLeftHeaderVertically` | `boolean` | Stacks title and subtitle vertically when `true`. |
| `greySubtitle` | `boolean` | Applies a grey color modifier class to the subtitle. |

### `SectionHeader` (default export)

Functional component that composes a two-column header layout: a left side with title/subtitle and an optional right side for detail elements.

## Usage Example

```typescript
import SectionHeader from "components/SectionHeader";

// Basic usage
<SectionHeader title="Device Management" />

// With subtitle and details panel
<SectionHeader
  title="Enrolled Hosts"
  subTitle="Manage all enrolled devices"
  details={<Button>Add Host</Button>}
  greySubtitle
/>

// Vertical alignment with custom wrapper class
<SectionHeader
  title="Policies"
  subTitle="3 failing"
  alignLeftHeaderVertically
  wrapperCustomClass="my-section"
/>
```
