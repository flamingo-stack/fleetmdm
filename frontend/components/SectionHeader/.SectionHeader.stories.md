Storybook stories for the `SectionHeader` component, demonstrating its visual variants with title, subtitle, and detail configurations.

## Key Components

- **`Basic`** — Default story rendering `SectionHeader` with a plain string title, subtitle, and details slot
- **`WithSubTitle`** — Variant showcasing a dynamic `LastUpdatedText` component used as the `subTitle` prop

## Usage Example

```typescript
import SectionHeader from "components/SectionHeader";
import LastUpdatedText from "components/LastUpdatedText";

// Basic usage
<SectionHeader
  title="Section header title"
  subTitle="This is a subtitle"
  details={<>These are details</>}
/>

// With dynamic subtitle
<SectionHeader
  title="Section header title"
  subTitle={
    <LastUpdatedText
      lastUpdatedAt={new Date().toISOString()}
      whatToRetrieve="operating systems"
    />
  }
/>
```

## Props (via story args)

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Primary heading text |
| `subTitle` | `string \| ReactNode` | Optional subtitle — accepts plain text or a React element |
| `details` | `ReactNode` | Optional detail content rendered alongside the header |
