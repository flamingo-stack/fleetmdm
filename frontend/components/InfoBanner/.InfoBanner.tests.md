Test suite for the `InfoBanner` component, validating rendering behavior across its key prop configurations.

## Key Components

- **`renders children content`** — Verifies that text passed as children is rendered in the DOM.
- **`renders as page-level banner`** — Confirms the `pageLevel` prop applies the `info-banner__page-banner` CSS class.
- **`renders CTA element`** — Ensures a custom call-to-action element passed via the `cta` prop is rendered.
- **`renders closable button and hides banner on click`** — Validates that the `closable` prop renders a close button and that clicking it removes the banner from the DOM.
- **`renders with icon class when icon prop is provided`** — Checks that passing an `icon` prop applies the `info-banner__icon` CSS class.

## Usage Example

```typescript
import { render, screen, fireEvent } from "@testing-library/react";
import InfoBanner from "./InfoBanner";

// Test closable behavior
render(<InfoBanner closable>Test message</InfoBanner>);
const closeButton = screen.getByRole("button");
fireEvent.click(closeButton);
expect(screen.queryByText("Test message")).not.toBeInTheDocument();

// Test page-level styling
const { container } = render(<InfoBanner pageLevel />);
expect(container.firstChild).toHaveClass("info-banner__page-banner");
```

## Notes

- Uses `@testing-library/react` for DOM queries and user interaction simulation.
- The close button visibility and banner removal are tested via `fireEvent.click`, confirming the component manages its own visibility state internally.
