Storybook stories for the `InfoBanner` component, providing an interactive playground to explore and configure all available props.

## Key Components

- **`meta`** — Storybook metadata defining component title (`Components/InfoBanner`), arg types, and controls for `color`, `borderRadius`, `pageLevel`, `closable`, and `icon`
- **`defaultChildren`** — Sample banner content with bold text and a `CustomLink` pointing to the Fleet GitHub issues page
- **`sampleCta`** — A call-to-action `CustomLink` used as the `cta` prop in the story
- **`Playground`** — The primary exported story with fully interactive Storybook controls

## Usage Example

```typescript
import { Playground } from "components/InfoBanner/InfoBanner.stories";

// Default Playground story args
const args = {
  color: "grey",           // "yellow" | "grey"
  borderRadius: "medium",  // "medium" | "xlarge"
  pageLevel: false,
  closable: true,
  icon: "info",            // "info" | "warning" | "error" | "success"
  children: <p>Banner message</p>,
  cta: <a href="#">Action</a>,
};
```

## Available Controls

| Prop | Type | Options |
|------|------|---------|
| `color` | select | `yellow`, `grey` |
| `borderRadius` | select | `medium`, `xlarge` |
| `icon` | select | `info`, `warning`, `error`, `success` |
| `pageLevel` | boolean | — |
| `closable` | boolean | — |

> **Note:** `cta` and `children` props are hidden from the Storybook controls table and must be passed directly as JSX.
