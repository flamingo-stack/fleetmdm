A dismissible, styled banner component used to display informational messages with optional icons, CTAs, and close functionality.

## Key Components

### `IInfoBannerProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | — | Banner message content |
| `color` | `"grey" \| "yellow"` | `"grey"` | Background color variant |
| `borderRadius` | `"medium" \| "xlarge"` | `undefined` (4px) | Corner radius size |
| `pageLevel` | `boolean` | — | Applies page-level banner styling |
| `cta` | `JSX.Element` | — | Action element appended to banner; mutually exclusive with `closable` |
| `closable` | `boolean` | — | Renders a close button to dismiss the banner |
| `icon` | `IconNames` | — | Icon displayed in the banner (currently unused in implementation) |

### `InfoBanner`
Default export. Wraps content in a `Card` component and manages local visibility state via `useState`. When dismissed, renders an empty fragment.

## Usage Example

```typescript
// Basic informational banner
<InfoBanner color="yellow">
  Your license expires in 7 days.
</InfoBanner>

// Dismissible page-level banner with a CTA
<InfoBanner
  pageLevel
  closable
  color="grey"
  borderRadius="medium"
  cta={<Button onClick={handleUpgrade}>Upgrade Now</Button>}
>
  Upgrade to Fleet Premium to unlock this feature.
</InfoBanner>
```

## Notes

- `cta` and `closable` are mutually exclusive by design — avoid using both simultaneously.
- The `icon` prop is wired into CSS class logic but not yet rendered; child components currently embed icons directly.
