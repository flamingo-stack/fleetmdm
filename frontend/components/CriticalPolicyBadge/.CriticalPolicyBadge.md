A small React component that renders a visual badge indicating a Fleet policy has been marked as critical, using a tooltip-wrapped policy icon.

## Key Components

- **`CriticalPolicyBadge`** — Default export. A stateless functional component that wraps a `policy` icon inside a `TooltipWrapper`, displaying the message *"This policy has been marked as critical."* on hover.

## Usage Example

```typescript
import CriticalPolicyBadge from "components/CriticalPolicyBadge";

const PolicyRow = ({ policy }) => (
  <div className="policy-row">
    <span>{policy.name}</span>
    {policy.critical && <CriticalPolicyBadge />}
  </div>
);
```

## Notes

- The tooltip is positioned above the icon (`position="top"`) with an 8px offset and a visible arrow.
- Styling is scoped via the `critical-badge` CSS class on the wrapper `<div>`.
- The component accepts no props — it is purely presentational with static content.
