A layout wrapper component that applies consistent styling to the side panel region of the application.

## Key Components

- **`SidePanelContent`** *(default export)* — A presentational wrapper `div` that merges the `side-panel-content` base class with any additional `className` provided by the consumer.

### Props (`ISidePanelContentProps`)

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `children` | `ReactNode` | ✅ | Content to render inside the side panel |
| `className` | `string` | ❌ | Additional CSS classes to merge onto the wrapper |

## Usage Example

```typescript
import SidePanelContent from "components/SidePanelContent";

const MyPage = () => (
  <SidePanelContent className="my-custom-styles">
    <h2>Panel Title</h2>
    <p>Side panel body content goes here.</p>
  </SidePanelContent>
);
```

## Notes

- Uses [`classnames`](https://github.com/JedWatson/classnames) to safely merge the `side-panel-content` base class with any consumer-supplied `className`.
- Purely presentational — no internal state or side effects.
- Intended to be composed inside a page-level layout alongside a main content area.
