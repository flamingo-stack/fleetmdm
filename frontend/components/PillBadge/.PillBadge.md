A reusable pill-shaped badge UI component that optionally wraps its content in a tooltip.

## Key Components

- **`PillBadge`** — Default export. Renders a styled pill badge with optional tooltip support via `TooltipWrapper`.

### Props (`IPillBadgeProps`)

| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | Content displayed inside the badge |
| `tipContent` | `JSX.Element \| string` | Optional tooltip content shown on hover |
| `className` | `string` | Optional additional CSS class names |

## Usage Example

```typescript
import PillBadge from "components/PillBadge";

// Basic badge
<PillBadge>Active</PillBadge>

// Badge with tooltip
<PillBadge tipContent="This device is currently online">
  Online
</PillBadge>

// Badge with custom class
<PillBadge className="status-badge" tipContent="Pending review">
  Pending
</PillBadge>
```

## Notes

- Tooltip is positioned `top` with a 12px offset and a 300ms hover delay.
- The `underline` style on the tooltip trigger is disabled by default.
- Base CSS class is `pill-badge`; the inner element uses `pill-badge__element`.
