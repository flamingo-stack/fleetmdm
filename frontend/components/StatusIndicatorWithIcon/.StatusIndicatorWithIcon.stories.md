Storybook stories file for the `StatusIndicatorWithIcon` component, providing interactive visual documentation and a baseline story with default args.

## Key Components

- **`meta`** — Storybook metadata configuration registering the component under `Components/StatusIndicatorWithIcon` with default args (`status`, `value`, `tooltip`)
- **`Basic`** — A single story rendering the component with the default args (status: `"success"`, value: `"Yes"`, tooltip text: `"Tooltip text"`)

## Usage Example

```typescript
// Extend with additional stories for other status variants
export const Error: Story = {
  args: {
    status: "error",
    value: "No",
    tooltip: {
      tooltipText: "Something went wrong",
    },
  },
};

export const Warning: Story = {
  args: {
    status: "warning",
    value: "Pending",
  },
};
```

## Notes

- The default `status` prop is `"success"` — extend stories to cover other status states (e.g., `error`, `warning`)
- The `tooltip` arg accepts a `tooltipText` property for hover context
- View and interact with stories via Storybook at the `Components/StatusIndicatorWithIcon` path
