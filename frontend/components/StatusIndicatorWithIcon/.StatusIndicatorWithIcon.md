A reusable React component that renders a status icon paired with a label, with optional tooltip support and horizontal/vertical layout modes.

## Key Components

### Types

- **`IndicatorStatus`** — Union type for valid status values: `"success"`, `"successPartial"`, `"pending"`, `"pendingPartial"`, `"error"`, `"failure"`, `"actionRequired"`

### Props (`IStatusIndicatorWithIconProps`)

| Prop | Type | Description |
|------|------|-------------|
| `status` | `IndicatorStatus` | Determines which icon to display |
| `value` | `string` | Text label rendered alongside the icon |
| `tooltip` | `{ tooltipText, position? }` | Optional tooltip configuration |
| `layout` | `"horizontal" \| "vertical"` | Icon/text layout direction (default: `"horizontal"`) |
| `className` | `string` | Additional class for the wrapper `div` |
| `valueClassName` | `string` | Additional class for the value `span` |

### Internal Mapping

`statusIconNameMapping` maps each `IndicatorStatus` to an `IconNames` value, with `"failure"` additionally receiving a muted `"ui-fleet-black-50"` color.

## Usage Example

```typescript
// Basic usage
<StatusIndicatorWithIcon status="success" value="Passing" />

// With tooltip
<StatusIndicatorWithIcon
  status="error"
  value="Failed"
  tooltip={{ tooltipText: "3 checks failed", position: "top" }}
/>

// Vertical layout with custom class
<StatusIndicatorWithIcon
  status="pending"
  value="Enrolling"
  layout="vertical"
  className="my-custom-class"
/>
```
