Storybook stories for the `Modal` component, providing interactive visual documentation and development sandbox for the modal UI.

## Key Components

- **`meta`** – Storybook metadata configuring the component title (`Components/Modal`), default args (`title`, `className`, `onExit`)
- **`Default`** – Story rendering the modal with sample children content inside a 300px container

## Usage Example

```typescript
// Extend with additional stories
export const WithActions: Story = {
  args: {
    title: "Confirm Action",
    children: <div>Are you sure you want to continue?</div>,
    onExit: () => console.log("Modal closed"),
  },
};
```

## Notes

- Uses `noop` from lodash as a no-op default for `onExit`, preventing unhandled handler errors during development
- The `Default` story wraps the modal in a `300px` height container to simulate a realistic viewport constraint
- Imports `../../index.scss` for global styles
