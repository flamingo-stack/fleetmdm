Test suite for the `Modal` component, validating its rendering behavior and the conditions under which the `onExit` callback is and is not triggered.

## Key Components

- **`clickBackground`** — Helper that simulates a full mouse-down/mouse-up click on the modal background overlay using `userEvent.pointer`.
- **Render tests** — Verifies the modal title is visible on screen.
- **`onExit` invocation tests** — Covers all cases where clicking the background overlay should or should not call `onExit`.
- **Drag-origin guard** — Ensures a drag that starts inside the modal container and ends on the background does not dismiss the modal.
- **Dirty-form guard** — Confirms `onExit` is suppressed when a text input, checkbox, or toggle inside the modal has been interacted with.
- **Window-blur guard** — Validates that a `mousedown` on the backdrop followed by the window losing focus (e.g., alt-tab) does not close the modal on the subsequent `mouseup`.
- **`disableClosingModal` prop** — Asserts that the prop fully prevents background-click dismissal.

## Usage Example

```typescript
// Running the full test suite
// jest --testPathPattern Modal.tests.tsx

// Minimal example of what the tests cover:
render(
  <Modal title="Confirm Action" onExit={handleClose} disableClosingModal={false}>
    <form>
      <input type="text" placeholder="Enter value" />
    </form>
  </Modal>
);

// After interacting with the form input, clicking the background
// will NOT call handleClose — the dirty-form guard prevents it.
fireEvent.input(screen.getByRole("textbox"), { target: { value: "hello" } });
// background click → onExit NOT called

// Without interaction, background click WILL call handleClose.
// background click → onExit called once
```
