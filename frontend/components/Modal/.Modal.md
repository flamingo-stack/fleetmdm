Accessible modal dialog component with keyboard support, close animations, and configurable width/state variants.

## Key Components

**`IModalProps`** — Interface defining all modal configuration options:
- `title` — Modal header content (string or JSX)
- `onExit` — Callback fired after close animation completes
- `onEnter` — Optional Enter key handler (avoid on forms)
- `width` — Layout width: `"medium"` (650px), `"large"` (800px), `"xlarge"` (850px), `"auto"`
- `isHidden` — Hides modal without unmounting (for stacked modals)
- `isLoading` — Adds loading state CSS target class
- `isContentDisabled` — Overlays content to block interaction while keeping close button active
- `disableClosingModal` — Removes Escape key, background click, and close button dismiss

**`Modal`** — Default export; renders a backdrop + container with:
- **Close animation** — 100ms CSS transition via `--modal-close-duration` CSS variable
- **Escape key** listener (disabled when `disableClosingModal` is true)
- **Background click-to-close** — Uses mousedown/mouseup refs to distinguish drags from clicks; suppressed if form is dirty
- **Form dirty detection** — Tracks input events and checkbox/toggle interactions to prevent accidental close

## Usage Example

```typescript
import Modal from "components/Modal/Modal";

const MyModal = ({ onClose }: { onClose: () => void }) => (
  <Modal
    title="Confirm Action"
    onExit={onClose}
    onEnter={onClose}
    width="large"
    isContentDisabled={false}
  >
    <p>Are you sure you want to proceed?</p>
    <button onClick={onClose}>Confirm</button>
  </Modal>
);
```

> **Note:** Avoid `onEnter` on modals containing forms, copy controls, or other elements where Enter has existing keyboard semantics — it will conflict with native browser behavior.
