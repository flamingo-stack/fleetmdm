Renders visual badges for software install policy types, displaying a "Patch" pill badge and/or an automatic install icon based on the active policy type set.

## Key Components

- **`SoftwareInstallPolicyBadges`** – Main component accepting a `policyType` (`SoftwareInstallPolicyTypeSet`) prop and conditionally rendering badges
- **`PATCH_TOOLTIP_CONTENT`** – Exported JSX constant with tooltip text for the patch badge
- **`renderPatchBadge`** – Renders a `PillBadge` with patch policy tooltip
- **`renderAutomaticInstallBadge`** – Renders a refresh `Icon` wrapped in a `TooltipWrapper` for dynamic/auto-install policies

## Usage Example

```typescript
import SoftwareInstallPolicyBadges from "./SoftwareInstallPolicyBadges";
import { SoftwareInstallPolicyTypeSet } from "interfaces/software";

const policyTypes: SoftwareInstallPolicyTypeSet = new Set(["patch", "dynamic"]);

// Renders both the Patch pill and the auto-install refresh icon
<SoftwareInstallPolicyBadges policyType={policyTypes} />

// Renders only the Patch badge
<SoftwareInstallPolicyBadges policyType={new Set(["patch"])} />

// Renders nothing
<SoftwareInstallPolicyBadges />
```

## Notes

- `policyType` is optional; omitting it renders nothing
- `SoftwareInstallPolicyTypeSet` is a `Set<string>` checked via `.has()` for `"patch"` and `"dynamic"` keys
