Storybook stories file for the `DeviceUserError` component, providing visual testing and documentation of device user error message states.

## Key Components

- **`meta`** – Storybook metadata config registering `DeviceUserError` under `Components/Error messages/Device user error`
- **`Basic`** – Default story rendering the component with no additional props

## Usage Example

```typescript
import { Basic } from "./DeviceUserError.stories";

// Render the basic story in tests or Storybook
<Basic />
```

> View and interact with this story in Storybook by navigating to **Components → Error messages → Device user error**.

## Notes

- The `Basic` story uses an empty config (`{}`), meaning it renders `DeviceUserError` with its default props only
- Additional stories can be added to cover error variants (e.g., permission denied, device not found) by extending the `Story` type
