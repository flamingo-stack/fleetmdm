Displays error states for the device user page, rendering contextual error messages based on the type of error encountered (authentication, setup steps, or generic).

## Key Components

### `DeviceUserError`
Default export. A React component that renders one of three error states:
- **Setup steps error** – delegates to the `DataError` component with a software setup status message
- **Authentication error** – shows device-specific or URL-specific messaging depending on whether the device is mobile
- **Generic error** – fallback "Something went wrong / Please contact your IT admin" message

### `IDeviceUserErrorProps`
| Prop | Type | Default | Description |
|---|---|---|---|
| `isMobileView` | `boolean` | `false` | Applies mobile-width CSS modifier (`<768px`) |
| `isMobileDevice` | `boolean` | `false` | Adjusts copy for iPhone/iPad/Android devices |
| `isAuthenticationError` | `boolean` | `false` | Triggers authentication-specific error UI |
| `isErrorSetupSteps` | `boolean` | `false` | Renders `DataError` for setup step failures |

## Usage Example

```typescript
// Generic error
<DeviceUserError />

// Authentication error on a mobile device
<DeviceUserError
  isAuthenticationError
  isMobileDevice
  isMobileView
/>

// Software setup step failure
<DeviceUserError isErrorSetupSteps />
```
