Unit test suite for the `DeviceUserError` React component, validating rendering behavior across default, mobile, and authentication error states.

## Key Components

- **`describe("DeviceUserError")`** — Test suite grouping four behavioral test cases for the component
- **Default render test** — Verifies the error icon, generic message, and IT admin contact text appear when no props are passed
- **Mobile view test** — Confirms the `device-user-error__mobile-view` CSS class is applied when `isMobileView` is `true`
- **Desktop authentication error test** — Checks that URL expiry messaging and a "click" instruction are shown for `isAuthenticationError` on desktop
- **Mobile authentication error test** — Validates certificate-specific error text appears when both `isAuthenticationError` and `isMobileDevice` are set

## Props Under Test

| Prop | Type | Effect |
|------|------|--------|
| `isMobileView` | `boolean` | Applies mobile layout CSS class |
| `isAuthenticationError` | `boolean` | Switches to auth-specific error messages |
| `isMobileDevice` | `boolean` | Switches auth error to certificate-focused messaging |

## Usage Example

```typescript
// Run the test suite
import { render, screen } from "@testing-library/react";
import DeviceUserError from "./DeviceUserError";

// Renders default fallback UI
render(<DeviceUserError />);
screen.getByText("Something went wrong");

// Renders mobile auth error
render(<DeviceUserError isAuthenticationError isMobileDevice />);
screen.getByText("Invalid or missing certificate");
```
