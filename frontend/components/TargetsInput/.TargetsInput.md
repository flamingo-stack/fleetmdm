A React component that provides a searchable host targeting interface with a dropdown of search results and a table of already-selected hosts.

## Key Components

### `ITargetsInputProps`
| Prop | Type | Description |
|------|------|-------------|
| `searchText` | `string` | Current search input value |
| `searchResults` | `IHost[]` | Hosts returned from search API |
| `isTargetsLoading` | `boolean` | API loading state |
| `hasFetchError` | `boolean` | Whether the search request failed |
| `targetedHosts` | `IHost[]` | Already-selected hosts |
| `searchResultsTableConfig` | `ITargestInputHostTableConfig[]` | Column config for dropdown results |
| `selectedHostsTableConifg` | `ITargestInputHostTableConfig[]` | Column config for selected hosts table |
| `disablePagination` | `boolean` | Disables client-side pagination (default: `false`) |
| `handleRowSelect` | `(value: Row<IHost>) => void` | Callback when a result row is clicked |
| `setSearchText` | `(value: string) => void` | Callback to update search input |

### Behaviours
- **Dropdown visibility** — active when `searchText` is non-empty and no fetch error, hidden on outside click (suppressed during loading to prevent premature close)
- **Deduplication** — `pullAllBy(searchResults, targetedHosts, "id")` removes already-targeted hosts from dropdown results
- **Error state** — replaces the dropdown with a `<DataError />` component when search fails

## Usage Example

```typescript
<TargetsInput
  searchText={searchText}
  searchResults={apiResults}
  isTargetsLoading={isLoading}
  hasFetchError={hasError}
  targetedHosts={selectedHosts}
  searchResultsTableConfig={resultsColumns}
  selectedHostsTableConifg={selectedColumns}
  setSearchText={setSearchText}
  handleRowSelect={(row) => addHost(row.original)}
  autofocus
  disablePagination={false}
/>
```
