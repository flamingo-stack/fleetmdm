Defines the table column configuration for displaying selected hosts in the targets input UI, used in live query and policy targeting workflows.

## Key Components

- **`ITargestInputHostTableConfig`** — Type alias for `Column<IHost>`, representing a single column definition for the hosts table.
- **`generateTableHeaders(handleRowRemove?)`** — Factory function that returns an array of react-table column configs. Accepts an optional row-removal callback; when provided, appends a delete column with a close-icon button.

### Columns Rendered

| Column | Accessor | Cell Component |
|---|---|---|
| Host | `display_name` | `LiveQueryIssueCell` (shows name + osquery health indicators) |
| Status | `status` | `StatusIndicator` |
| Private IP address | `primary_ip` | `TextCell` |
| MAC address | `primary_mac` | `TextCell` |
| OS | `os_version` | `TextCell` |
| Osquery | `osquery_version` | `TextCell` |
| _(delete)_ | — | Icon `Button` (conditional) |

## Usage Example

```typescript
import { generateTableHeaders } from "./TargetsInputHostsTableConfig";

// Read-only table (no removal)
const readOnlyColumns = generateTableHeaders();

// Table with row removal support
const editableColumns = generateTableHeaders((row) => {
  dispatch(removeTargetHost(row.original.id));
});
```

> **Note:** The `Status` column has `disableSortBy: true` and includes a known limitation — status is **not refreshed** after a host is selected as a target.
