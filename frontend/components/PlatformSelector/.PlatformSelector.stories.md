Storybook stories for the `PlatformSelector` component, defining default args and exporting a basic story for visual testing and documentation.

## Key Components

- **`meta`** – Storybook `Meta` configuration registering `PlatformSelector` under `Components/PlatformSelector` with default arg values for all platform toggle states and setters.
- **`Basic`** – A default story using the configured meta args, rendering `PlatformSelector` with macOS (`checkDarwin`) and Windows (`checkWindows`) enabled, Linux and Chrome disabled.

## Usage Example

```typescript
// Extend the Basic story with custom args
export const LinuxOnly: Story = {
  args: {
    checkDarwin: false,
    checkWindows: false,
    checkLinux: true,
    checkChrome: false,
  },
};
```

## Default Arg Values

| Prop             | Default |
|------------------|---------|
| `checkDarwin`    | `true`  |
| `checkWindows`   | `true`  |
| `checkLinux`     | `false` |
| `checkChrome`    | `false` |
| `setCheck*`      | `noop`  |

All setter props (`setCheckDarwin`, `setCheckWindows`, `setCheckLinux`, `setCheckChrome`) are initialized with Lodash's `noop` to prevent errors in the Storybook sandbox.
