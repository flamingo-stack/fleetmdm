A React component that renders a set of platform target checkboxes (macOS, Windows, Linux, ChromeOS) for policy or software configuration forms.

## Key Components

### `PlatformSelector` (named + default export)

A controlled form component accepting four boolean platform states and their setters. Optionally renders contextual help text when a software install policy is attached.

**Props (`IPlatformSelectorProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `checkDarwin` | `boolean` | macOS checkbox state |
| `checkWindows` | `boolean` | Windows checkbox state |
| `checkLinux` | `boolean` | Linux checkbox state |
| `checkChrome` | `boolean` | ChromeOS checkbox state |
| `setCheck*` | `(val: boolean) => void` | State setters for each platform |
| `disabled` | `boolean` | Disables all checkboxes (default: `false`) |
| `installSoftware` | `IPolicySoftwareToInstall` | Optional; triggers help text with a link to the software title and a tooltip explaining targeted hosts |
| `currentTeamId` | `number` | Optional; used to build the software detail link with `fleet_id` query param |
| `baseClass` | `string` | Optional parent BEM class prefix |

### `renderInstallSoftwareHelpText` (internal)

Renders a help text block with a `CustomLink` to the software title page and a `TooltipWrapper` explaining targeting behavior when `installSoftware` is provided.

## Usage Example

```typescript
const [checkDarwin, setCheckDarwin] = useState(true);
const [checkWindows, setCheckWindows] = useState(false);
const [checkLinux, setCheckLinux] = useState(false);
const [checkChrome, setCheckChrome] = useState(false);

<PlatformSelector
  baseClass="policy-form"
  checkDarwin={checkDarwin}
  checkWindows={checkWindows}
  checkLinux={checkLinux}
  checkChrome={checkChrome}
  setCheckDarwin={setCheckDarwin}
  setCheckWindows={setCheckWindows}
  setCheckLinux={setCheckLinux}
  setCheckChrome={setCheckChrome}
  installSoftware={policy.installSoftware}
  currentTeamId={3}
/>
```
