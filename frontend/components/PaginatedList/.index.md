Re-exports the `PaginatedList` component and its `IPaginatedListHandle` TypeScript interface from the barrel entry point, simplifying imports for consumers of this module.

## Key Components

- **`default`** — The `PaginatedList` component (re-exported as default)
- **`IPaginatedListHandle`** — TypeScript interface for the imperative handle exposed via `useImperativeHandle` / `forwardRef` on `PaginatedList`

## Usage Example

```typescript
// Import the component and handle type from the module root
import PaginatedList, { type IPaginatedListHandle } from "@/components/PaginatedList";
import { useRef } from "react";

function MyPage() {
  const listRef = useRef<IPaginatedListHandle>(null);

  return <PaginatedList ref={listRef} />;
}
```
