Test suite for the `PaginatedList` component, covering rendering, pagination, selection states, custom markup, dirty item tracking, and imperative handle behavior via `IPaginatedListHandle`.

## Key Components

- **`PaginatedList`** — The component under test; a generic paginated list with checkbox selection support
- **`IPaginatedListHandle`** — Imperative ref handle interface exposing `getDirtyItems()` for accessing modified items
- **`ITestItem`** — Local test fixture interface with fields: `id`, `name`, `key`, `val`, `favoriteIceCreamFlavor`, `checkMeBruh`
- **`fetchSmallPage` / `fetchLargePage`** — Helper functions simulating paginated data fetching
- **`checkPaginationIsHidden`** — Assertion helper verifying Next/Previous buttons are absent
- **`waitForLoadingToFinish`** — Async helper that waits for `.loading-overlay` to disappear

## Test Coverage

| Test Case | What It Validates |
|-----------|------------------|
| Renders with checkboxes | Items render as unchecked checkboxes |
| Custom `idKey`/`labelKey` | Supports non-default id and label properties |
| `isSelected` as property name | Checkbox state driven by item field |
| `isSelected` as function | Checkbox state driven by predicate |
| Pagination controls | Next/Previous buttons enable/disable correctly across pages |
| `renderItemRow` | Custom markup rendered alongside each row |
| `renderItemLabel` | Custom label markup replaces default text |
| `onClickRow` + dirty tracking | Toggling item calls callback and updates dirty set |
| `onChange` in custom markup | Custom row content can push updates to dirty items |
| `onUpdate` notification | Parent notified when dirty items change |

## Usage Example

```typescript
const ref = createRef<IPaginatedListHandle<MyItem>>();

<PaginatedList<MyItem>
  ref={ref}
  currentPage={0}
  data={items}
  onChangePage={setPage}
  pageSize={10}
  onClickRow={(item) => ({ ...item, selected: !item.selected })}
  onUpdate={(dirtyItems) => console.log(dirtyItems)}
  isSelected="selected"
  renderItemRow={(item, onChange) => (
    <button onClick={() => onChange({ ...item, name: "updated" })}>
      {item.name}
    </button>
  )}
/>

// Access dirty items imperatively
const dirty = ref.current?.getDirtyItems();
```
