A generic, paginated list component with optional checkbox selection, dirty-item tracking, and an imperative handle for retrieving changed items from parent components.

## Key Components

- **`IPaginatedListHandle<TItem>`** — Ref handle interface exposing `getDirtyItems()` for parent access
- **`IPaginatedListProps<TItem>`** — Full prop interface including data, pagination, selection, and rendering callbacks
- **`PaginatedListInner`** — Core generic component implementing dirty-state tracking, checkbox rendering, and custom row rendering
- **`PaginatedList`** — `forwardRef`-wrapped export, typed to preserve generics

## Usage Example

```typescript
import { useRef, useCallback, useState } from "react";
import PaginatedList, { IPaginatedListHandle } from "components/PaginatedList";

interface Device { id: number; name: string; enrolled: boolean; }

function DeviceSelector({ devices }: { devices: Device[] }) {
  const listRef = useRef<IPaginatedListHandle<Device>>(null);
  const [page, setPage] = useState(0);

  const handleSave = () => {
    const changed = listRef.current?.getDirtyItems();
    console.log("Changed devices:", changed);
  };

  return (
    <>
      <PaginatedList<Device>
        ref={listRef}
        data={devices}
        count={devices.length}
        currentPage={page}
        onChangePage={setPage}
        idKey="id"
        labelKey="name"
        useCheckBoxes
        isSelected={(item) => item.enrolled}
        onClickRow={(item) => ({ ...item, enrolled: !item.enrolled })}
        isItemDisabled={(item) => item.id === 0}
        pageSize={10}
      />
      <button onClick={handleSave}>Save</button>
    </>
  );
}
```

## Notes

- **Dirty tracking** — Modified items are stored locally by `idKey`; navigating pages preserves unsaved changes
- **`isSelected`** accepts either a key string or a predicate function
- **`renderItemRow`** receives a `onChange` callback to mark items dirty from custom row controls
- `forwardRef` cast preserves generic type inference; the TODO comment notes this can be simplified after upgrading to React 19
