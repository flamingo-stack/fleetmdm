Test suite for the `FileDetails` component, verifying file name/description rendering, file selection, delete actions, and upload progress bar behavior.

## Key Components

- **`setup`** — Helper that renders `FileDetails` with default props (`config.yaml`, edit enabled) using `renderWithSetup`, accepting prop overrides.
- **Test: renders file name and description** — Confirms `.file-details__name` and `.file-details__description` text content, and that clicking the edit button triggers `input[type='file'].click()`.
- **Test: calls onFileSelect on file change** — Fires a `change` event on the hidden file input and asserts the `onFileSelect` callback is invoked.
- **Test: delete button calls onDeleteFile** — Asserts `.file-details__delete-button` click invokes the `onDeleteFile` callback.
- **Test: progress bar hides edit/delete** — When `progress={0.5}` is passed, the progress bar is rendered and edit/delete buttons are absent.

## Usage Example

```typescript
// Running all tests
// npx jest FileDetails.tests.tsx

// Overriding props in a specific test
const { container } = setup({
  gitopsCompatible: false,
  onFileSelect: jest.fn(),
  onDeleteFile: jest.fn(),
  progress: 0.5,
});
```

## Notes

- Uses `fireEvent.change` (from `@testing-library/react`) for file input simulation, since `userEvent` does not directly support `FileList` construction.
- The edit button indirectly triggers the hidden file input via `.click()`, spied on with `jest.spyOn`.
- Progress state (`progress` prop) is mutually exclusive with edit/delete controls — both buttons should be `null` in the DOM when uploading.
