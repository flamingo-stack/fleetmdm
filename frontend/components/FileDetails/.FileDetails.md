A React component that displays file metadata (name, description, graphic/preview) with optional edit, delete, and upload progress controls, including GitOps mode awareness.

## Key Components

### `FileDetails` (default export)
The main component rendering a file's visual details row with interactive controls.

### `IFileDetailsSupportedGraphicNames`
Extended type union combining `ISupportedGraphicNames` with `"app-store"` to support VPP app icons.

### `IFileDetailsProps`
| Prop | Type | Description |
|---|---|---|
| `graphicNames` | `IFileDetailsSupportedGraphicNames \| []` | Icon graphic(s) to display |
| `fileDetails` | `IFileDetails` | Name and optional description |
| `canEdit` | `boolean` | Whether edit controls are shown |
| `customEditor` | `() => ReactNode` | Replaces default pencil edit icon |
| `customPreview` | `ReactNode` | Replaces default `<Graphic>` thumbnail |
| `onDeleteFile` | `() => void` | Shows trash icon when provided |
| `onFileSelect` | `(e) => void` | File input change handler |
| `progress` | `number` | Upload progress (0–1); hides edit/delete when active |
| `gitopsCompatible` | `boolean` | Wraps edit in GitOps tooltip (default: `true`) |
| `gitOpsModeEnabled` | `boolean` | Applies disabled styling in GitOps mode |

## Usage Example

```typescript
<FileDetails
  graphicNames="pkg"
  fileDetails={{ name: "fleet-agent.pkg", description: "macOS installer" }}
  canEdit={true}
  onFileSelect={(e) => handleFileChange(e)}
  onDeleteFile={() => handleDelete()}
  accept=".pkg"
  progress={uploadProgress} // e.g. 0.75 shows 75% progress bar
  gitopsCompatible={true}
  gitOpsModeEnabled={false}
/>
```

When `progress` is non-zero, edit/delete controls are hidden and a progress bar is rendered instead. GitOps mode disables the edit section visually while preserving tooltip interactivity.
