Test suite for the `Pagination` component, verifying rendering behavior, button states, user interactions, and conditional visibility.

## Key Components

| Test Case | Description |
|-----------|-------------|
| Render & className | Verifies "Previous"/"Next" buttons render and that both `pagination` base class and custom `className` are applied to the container |
| Disabled states | Confirms buttons are disabled when `disablePrev` and `disableNext` props are set |
| Click handlers | Validates `onPrevPage` and `onNextPage` callbacks fire exactly once on button click |
| Hidden pagination | Ensures neither button renders when `hidePagination` is `true` |

## Usage Example

```typescript
// Running the test suite
// From repo root:
// npx jest Pagination.tests.tsx

import { fireEvent, render, screen } from "@testing-library/react";
import Pagination from "./Pagination";

// Minimal render
render(
  <Pagination
    onNextPage={() => {}}
    onPrevPage={() => {}}
  />
);

// With all optional props exercised
render(
  <Pagination
    onNextPage={jest.fn()}
    onPrevPage={jest.fn()}
    className="custom-pagination"
    disablePrev
    disableNext
    hidePagination={false}
  />
);
```

## Props Under Test

| Prop | Type | Behavior Tested |
|------|------|-----------------|
| `onNextPage` | `() => void` | Called once on "Next" click |
| `onPrevPage` | `() => void` | Called once on "Previous" click |
| `className` | `string` | Appended alongside base `pagination` class |
| `disablePrev` / `disableNext` | `boolean` | Disables respective button |
| `hidePagination` | `boolean` | Removes both buttons from DOM entirely |
