Storybook stories file for the `Pagination` component, providing interactive visual documentation and development playground via Storybook.

## Key Components

- **`meta`** — Storybook metadata configuration defining the component, title path (`Components/Pagination`), and default args
- **`Template`** — Base `StoryFn` render function that passes all props to `Pagination`
- **`Default`** — Exported story instance with preset args (prev disabled, next enabled, no-op handlers)

## Usage Example

```typescript
// Run stories locally via Storybook
// Default story renders with these initial props:
{
  disableNext: false,
  disablePrev: true,
  onNextPage: noop,
  onPrevPage: noop,
  className: "pagination-story",
  hidePagination: false,
}
```

To extend with additional stories:

```typescript
export const NextDisabled = Template.bind({});
NextDisabled.args = {
  disableNext: true,
  disablePrev: false,
};

export const Hidden = Template.bind({});
Hidden.args = {
  hidePagination: true,
};
```

## Notes

- Stories are colocated with the component at [`frontend/components/Pagination/`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/Pagination)
- Imports global styles from `index.scss` to match production rendering
- Uses `noop` from lodash as safe placeholder for callback props during isolated story rendering
