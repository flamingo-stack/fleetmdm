A reusable pagination component that renders "Previous" and "Next" navigation buttons with support for disabling states and conditional visibility.

## Key Components

### `IPaginationProps`
| Prop | Type | Description |
|------|------|-------------|
| `disableNext` | `boolean` | Disables the Next button (e.g., last page or loading) |
| `disablePrev` | `boolean` | Disables the Previous button (e.g., first page or loading) |
| `onNextPage` | `() => void` | Callback fired when Next is clicked |
| `onPrevPage` | `() => void` | Callback fired when Previous is clicked |
| `className` | `string` | Optional additional CSS class |
| `hidePagination` | `boolean` | Hides the component entirely when only one page exists |

### `Pagination` (default export)
Renders two `Button` components with chevron icons. Returns `null` when `hidePagination` is `true`.

## Usage Example

```typescript
import Pagination from "components/Pagination";

const MyTable = () => {
  const [page, setPage] = React.useState(0);
  const totalPages = 5;

  return (
    <>
      {/* ...table content... */}
      <Pagination
        onNextPage={() => setPage((p) => p + 1)}
        onPrevPage={() => setPage((p) => p - 1)}
        disablePrev={page === 0}
        disableNext={page === totalPages - 1}
        hidePagination={totalPages <= 1}
      />
    </>
  );
};
```

## Notes

- `hidePagination` defaults to `false`; pass `true` to suppress rendering when the full result set fits on a single page.
- Button disabled states should reflect API metadata (e.g., `has_next_results`) or loading state to prevent navigation during data fetching.
