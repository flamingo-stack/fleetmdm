Test suite for the `HumanTimeDiffWithDateTip` and `HumanTimeDiffWithFleetLaunchCutoff` React components, validating rendering behavior, tooltip interactions, and edge case handling for time string inputs.

## Key Components

- **`HumanTimeDiffWithDateTip`** — Component under test; renders a human-readable time difference with a date tooltip on hover
- **`HumanTimeDiffWithFleetLaunchCutoff`** — Variant that filters out dates predating Fleet's launch, rendering "never" for epoch-era timestamps
- **`renderWithSetup`** — Test utility that provides a `user` event simulation object for interaction testing

## Test Cases

| Scenario | Input | Expected Output |
|---|---|---|
| Valid date hover | `"2015-12-06T10:30:00Z"` | Tooltip shows `12/6/2015` |
| Empty string | `""` | `"Unavailable"` |
| Invalid string | `"foobar"` | `"Invalid date"` |
| Pre-Fleet cutoff | `"1970-01-02T00:00:00Z"` | `"never"` |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { renderWithSetup } from "test/test-utils";
import { HumanTimeDiffWithDateTip } from "./HumanTimeDiffWithDateTip";

// Test tooltip interaction
const { user } = renderWithSetup(
  <HumanTimeDiffWithDateTip timeString="2015-12-06T10:30:00Z" />
);
await user.hover(screen.getByText(/years ago/i));
expect(screen.getByText(/12\/6\/2015/i)).toBeInTheDocument();

// Test empty/invalid inputs
render(<HumanTimeDiffWithDateTip timeString="" />);
expect(screen.getByText("Unavailable")).toBeInTheDocument();
```

> **Note:** The "years ago" assertion uses a regex match intentionally — the exact number changes over time as the test date recedes further into the past.
