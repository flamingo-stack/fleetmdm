Storybook stories file for the `HumanTimeDiffWithDateTip` component, providing visual development and testing scenarios in Storybook's component explorer.

## Key Components

- **`meta`** — Storybook metadata configuration registering the component under `Components/HumanTimeDiffWithDateTip` with a default `timeString` arg set to an ISO 8601 date string.
- **`Basic`** — A baseline story rendering the component with the default args.

## Usage Example

```typescript
// Extend with additional stories for different time values
export const RecentTime: Story = {
  args: {
    timeString: new Date(Date.now() - 60_000).toISOString(), // 1 minute ago
  },
};

export const OldTime: Story = {
  args: {
    timeString: "2000-06-15T12:30:00.000Z",
  },
};
```

## Notes

- Default `timeString` is `"2021-01-01T00:00:00.000Z"` — a fixed past date useful for snapshot/regression testing.
- The component is expected to display a human-readable relative time difference (e.g., "3 years ago") with a tooltip showing the full formatted date.
