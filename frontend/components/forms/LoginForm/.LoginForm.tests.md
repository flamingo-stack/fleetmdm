Unit tests for the `LoginForm` component, verifying rendering behavior, client-side form validation, submission logic, and keyboard navigation (tab order).

## Key Components

- **`describe("LoginForm - component")`** — Top-level test suite covering all `LoginForm` behaviors
- **`renderWithSetup`** — Custom test utility that returns a `user` event object for simulating user interactions
- **`submitSpy`** — Jest mock function used to assert form submission calls and arguments

## Test Coverage

| Test Case | What It Verifies |
|-----------|-----------------|
| Renders base error | `baseError` prop displays when provided |
| No base error | Error message absent when prop is omitted |
| Input fields | Email and Password `InputField` components render |
| Invalid email | Empty/invalid email blocks submission with error messages |
| Empty password | Missing password blocks submission with error message |
| Both fields empty | Form does not call `handleSubmit` |
| Valid submission | `handleSubmit` called with `{ email, password }` |
| Tab order | Focus moves: Email → Password → Log in → SSO button → Forgot password |

## Usage Example

```typescript
// Run all LoginForm tests
npx jest LoginForm.tests.tsx

// Run a specific test by name
npx jest LoginForm.tests.tsx -t "submits the form data when valid form data is submitted"
```

## Notes

- SSO tab-order test uses `sso_enabled: true` with `idp_name: "Test IdP"` to ensure the SSO button appears in the tab sequence
- Client-side validation is tested **before** the `submitSpy` assertion to confirm the form never reaches the submit handler on invalid input
