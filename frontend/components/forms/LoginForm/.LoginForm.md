Renders the login form UI for Fleet MDM, handling email/password authentication, SSO sign-on, client-side validation, and a "check your email" state for magic-link (passwordless) flows.

## Key Components

- **`LoginForm`** – Default export. Controlled form component accepting:
  - `handleSubmit` – async callback receiving `ILoginUserData` on valid submission
  - `isSubmitting` – drives loading state on the submit button
  - `pendingEmail` – toggles the magic-link confirmation screen
  - `ssoSettings` – optional SSO config (`idp_name`, `idp_image_url`, `sso_enabled`)
  - `handleSSOSignOn` – callback triggered by the SSO button
  - `baseError` – server-side error string rendered above the form

- **`validate()`** – Inline validation using `validatePresence` and `validateEmail` helpers; sets field-level errors in state.

- **`renderSingleSignOnButton()`** – Conditionally renders an SSO button with IdP name/image when `sso_enabled` is true.

- **Pending email view** – When `pendingEmail` is `true`, the form is replaced with a confirmation screen and a back button.

## Usage Example

```typescript
import LoginForm from "components/LoginForm";

<LoginForm
  handleSubmit={async ({ email, password }) => {
    await loginUser({ email, password });
  }}
  isSubmitting={loading}
  pendingEmail={awaitingMagicLink}
  ssoSettings={{
    sso_enabled: true,
    idp_name: "Okta",
    idp_image_url: "https://example.com/okta-logo.png",
  }}
  handleSSOSignOn={() => redirectToSSOProvider()}
  baseError={serverError}
/>
```
