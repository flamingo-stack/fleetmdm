Thin wrapper around the `validator.js` `isEmail` function that validates whether a given string is a properly formatted email address.

## Key Components

- **Default export** — A function `(email: string) => boolean` that returns `true` if the input is a valid email address, `false` otherwise.

## Usage Example

```typescript
import validEmail from "./valid_email";

validEmail("user@example.com");  // true
validEmail("not-an-email");      // false
validEmail("missing@tld");       // false
```

## Notes

- Delegates all validation logic to [`validator.js`](https://github.com/validatorjs/validator.js), which follows RFC 5322 rules.
- No custom configuration is passed; uses `isEmail` defaults.
