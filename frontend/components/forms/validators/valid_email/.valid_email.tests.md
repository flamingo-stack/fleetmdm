Unit tests for the `validEmail` utility, verifying that the email validation function correctly identifies valid and invalid email address formats.

## Key Components

- **`validEmails`** — Test fixture array containing well-formed email addresses (e.g., `"fleet@gmail.com"`)
- **`invalidEmails`** — Test fixture array containing malformed addresses missing a valid TLD or domain (e.g., `"www.thegnar.co"`, `"bill@shakespeare"`)
- **`returns true for valid emails`** — Asserts `validEmail()` returns `true` for all entries in `validEmails`
- **`returns false for invalid emails`** — Asserts `validEmail()` returns `false` for all entries in `invalidEmails`

## Usage Example

```typescript
import validEmail from "./index";

// Valid — returns true
validEmail("fleet@gmail.com"); // true

// Invalid — missing TLD
validEmail("bill@shakespeare"); // false

// Invalid — no @ symbol
validEmail("www.thegnar.co"); // false
```

## Notes

- Tests are co-located with the implementation in `./index`; see [`valid_email/index.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/valid_email/index.ts) for the validator logic
- Malformed inputs tested include bare domain-only addresses and URLs without `@`
