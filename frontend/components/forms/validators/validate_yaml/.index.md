Parses and validates YAML text using `js-yaml`, returning a structured result object indicating success or failure with error details.

## Key Components

- **`validateYaml(yamlText)`** — Main exported function. Accepts a YAML string and returns a validation result object.
- **`validYamlResponse`** — Static success object: `{ valid: true, error: null }`.
- **`invalidYamlResponse(message)`** — Helper that returns `{ valid: false, error: message }`.

### Return Shape

| Scenario | `valid` | `error` |
|---|---|---|
| Valid YAML | `true` | `null` |
| Empty/null input | `false` | `"YAML text must be present"` |
| Syntax error | `false` | `{ name, reason, line }` |
| Other error | `false` | `error.message` (string) |

## Usage Example

```javascript
import validateYaml from "./index.js";

// Valid YAML
validateYaml("key: value");
// → { valid: true, error: null }

// Invalid YAML
validateYaml("key: [unclosed");
// → { valid: false, error: { name: "Syntax Error", reason: "...", line: 0 } }

// Empty input
validateYaml("");
// → { valid: false, error: "YAML text must be present" }
```
