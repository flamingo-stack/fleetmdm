Unit tests for the `valid_hostname` utility, validating acceptance and rejection of various hostname and IP address formats.

## Key Components

- **Test suite**: `valid_hostname` — covers FQDNs, IPv4, IPv6, localhost, port combinations, and malformed inputs
- **Import**: `valid_hostname` from [`./valid_hostname`](https://github.com/flamingo-stack/fleetmdm/blob/main/valid_hostname.ts)

## Test Cases

| Input | Expected | Reason |
|---|---|---|
| `fleet.example.com` | `true` | Standard FQDN |
| `fleet.example.com:8090` | `true` | FQDN with port |
| `192.168.0.1` | `true` | IPv4 |
| `192.168.0.1:9090` | `true` | IPv4 with port |
| `2001:0db8:...:7334` | `true` | IPv6 without brackets |
| `[2001:0db8:...:7334]:8080` | `true` | IPv6 with brackets and port |
| `localhost` | `true` | Localhost |
| `localhost:3000` | `true` | Localhost with port |
| `not a valid url!` | `false` | Gibberish input |
| `example.com:` | `false` | Missing port after colon |
| `example.com:70000` | `false` | Port exceeds 65535 |
| `256.256.256.256` | `false` | Invalid IPv4 octets |
| `2001:xyz:123` | `false` | Invalid IPv6 |
| `:8080` | `false` | Missing host |
| `[2001:db8::1]` | `false` | IPv6 brackets without port |

## Usage Example

```typescript
import valid_hostname from "./valid_hostname";

valid_hostname("fleet.example.com");         // true
valid_hostname("192.168.0.1:9090");          // true
valid_hostname("[2001:db8::1]:8080");        // true
valid_hostname("example.com:70000");         // false — invalid port
valid_hostname(":8080");                     // false — missing host
```
