Validates whether a given string is a valid hostname, supporting FQDNs, IPv4, IPv6, and optional port numbers in various notations.

## Key Components

- **Default Export** — A single validation function `(addr: string): boolean` that checks hostname validity across multiple formats.

**Supported formats:**
- Plain FQDNs (with or without TLD): `example.com`, `localhost`
- IPv4 addresses: `192.168.1.1`
- IPv6 addresses: `::1`, `2001:db8::1`
- Host + port: `example.com:8080`, `192.168.1.1:443`
- Bracketed IPv6 + port: `[::1]:3000`

## Usage Example

```typescript
import validHostname from "./valid_hostname";

validHostname("example.com");        // true
validHostname("localhost");          // true
validHostname("192.168.1.1");        // true
validHostname("192.168.1.1:8080");   // true
validHostname("[::1]:3000");         // true
validHostname("not a host!");        // false
validHostname(":8080");              // false — colon must not be first char
```

## Validation Logic

1. First attempts `isFQDN` (TLD not required) and `isIP` directly on the input.
2. If both fail, splits on the **last colon** to extract a potential `host:port` pair.
3. Strips `[` `]` brackets for IPv6 notation before re-validating the host.
4. Returns `true` only if the extracted port passes `isPort` **and** the host passes `isFQDN` or `isIP`.
