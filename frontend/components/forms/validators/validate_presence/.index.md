Checks whether a value is truthy, with the additional rule that blank or whitespace-only strings are treated as `false`.

## Key Components

- **Default export** — a single arrow function `(actual: any): boolean`

## Usage Example

```typescript
import hasValue from "./index";

hasValue(0);          // false
hasValue(null);       // false
hasValue("");         // false
hasValue("   ");      // false
hasValue("hello");    // true
hasValue(42);         // true
hasValue([]);         // true
```

## Notes

- Standard falsy values (`null`, `undefined`, `0`, `false`) return `false` via the `!!actual` short-circuit.
- Strings are further checked with `.trim()`, so `"   "` (whitespace-only) returns `false` even though `!!"   "` would be `true`.
- Non-string truthy values (numbers, arrays, objects) pass through the string check and always return `true`.
