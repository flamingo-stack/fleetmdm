Tests for the `validatePresence` validator, verifying it correctly identifies truthy/non-empty values as valid and falsy/empty values as invalid.

## Key Components

- **`validInputs`** — Test fixtures covering arrays, objects, and non-empty strings
- **`invalidInputs`** — Test fixtures covering empty strings, `undefined`, `false`, and `null`
- **`validatePresence - validator`** — Jest `describe` block with two test cases

## Usage Example

```typescript
import validatePresence from "./index";

// Returns true for present values
validatePresence([1, 2, 3]);        // true
validatePresence({ hello: "world" }); // true
validatePresence("hi@thegnar.co");  // true

// Returns false for absent/empty values
validatePresence("");        // false
validatePresence(undefined); // false
validatePresence(false);     // false
validatePresence(null);      // false
```

## Test Cases

| Input | Expected |
|-------|----------|
| `[1, 2, 3]` | `true` |
| `{ hello: "world" }` | `true` |
| `"hi@thegnar.co"` | `true` |
| `""` | `false` |
| `undefined` | `false` |
| `false` | `false` |
| `null` | `false` |
