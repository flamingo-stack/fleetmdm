Validates whether a given string conforms to the standard JWT (JSON Web Token) format by testing it against a regex pattern.

## Key Components

- **`JWT_REGEX`** – Regular expression that matches the three-part, dot-separated structure of a JWT (`header.payload.signature`)
- **`default export`** – A function that accepts a JWT string and returns a boolean indicating whether it is valid

## Usage Example

```javascript
import isValidJwt from './index.js';

isValidJwt('eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJ1c2VyMSJ9.abc123'); // true
isValidJwt('not-a-jwt');   // false
isValidJwt('');            // false
```

> **Note:** This validates JWT *structure only* (three Base64URL segments separated by dots). It does **not** verify the token's signature or expiry.
