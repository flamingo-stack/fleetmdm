Lightweight deep-equality utility that wraps Lodash's `isEqual` to provide a simple, consistent comparison interface across the codebase.

## Key Components

- **Default export** — A function that accepts two values (`actual`, `expected`) and returns `true` if they are deeply equal, `false` otherwise. Delegates entirely to [`lodash.isEqual`](https://lodash.com/docs/#isEqual).

## Usage Example

```typescript
import deepEqual from "./index";

deepEqual({ a: 1, b: [2, 3] }, { a: 1, b: [2, 3] }); // true
deepEqual({ a: 1 }, { a: 2 });                         // false
deepEqual([1, 2, 3], [1, 2, 3]);                       // true
```

## Notes

- Supports deep comparison of objects, arrays, primitives, and nested structures.
- Uses Lodash's battle-tested `isEqual` under the hood — handles edge cases like `NaN`, `Date`, `RegExp`, circular references, etc.
- The `actual` / `expected` naming convention suggests this is primarily used in **test assertion helpers** or **change-detection logic**.
