Test suite for the `validateEquality` utility, verifying deep equality checks across primitive and complex data types.

## Key Components

- **`validateEquality`** — The default import under test; accepts two values of any type and returns a boolean indicating deep equality.

## Test Coverage

| Case | Expected |
|---|---|
| Identical strings | `true` |
| Equal integers / floats (`1.0` vs `1`) | `true` |
| Arrays with matching elements | `true` |
| Shallow and nested objects with matching values | `true` |
| Mismatched strings | `false` |
| Type mismatch (number vs string) | `false` |
| Arrays with different elements | `false` |
| Objects with differing values (shallow & nested) | `false` |

## Usage Example

```typescript
import validateEquality from "./index";

// Primitives
validateEquality("thegnarco", "thegnarco"); // true
validateEquality(1.0, 1);                   // true
validateEquality(1, "thegnar");             // false

// Collections
validateEquality(["thegnarco"], ["thegnarco"]);               // true
validateEquality({ hello: "world" }, { hello: "world" });     // true
validateEquality({ foo: { bar: "baz" } }, { foo: { bar: "foo" } }); // false
```
