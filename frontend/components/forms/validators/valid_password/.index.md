Validates a password string against Fleet MDM's password policy rules, returning a result object with validity status and error details.

## Key Components

- **Default export** — A validation function that accepts a password string and returns a `{ isValid, error, error_code }` result object.
- **Validation rules** enforced:
  - Minimum 12 characters (`too_short`)
  - Maximum 48 characters (`too_long`)
  - Must contain at least one letter, one number, and one symbol (`invalid_format`)

## Usage Example

```typescript
import validatePassword from "./index";

const result = validatePassword("MyP@ssw0rd123");

if (!result.isValid) {
  console.error(result.error);       // "Password must meet the criteria below"
  console.error(result.error_code);  // "too_short" | "too_long" | "invalid_format"
} else {
  console.log("Password is valid");
}
```

## Return Shape

```typescript
{
  isValid: boolean;   // true if all rules pass
  error: string;      // human-readable error message, empty string on success
  error_code: string; // machine-readable code, empty string on success
}
```

> **Note:** The symbol check uses `\W+` (non-word characters), which matches anything that is not a letter, digit, or underscore. Underscores alone will **not** satisfy the symbol requirement.
