Test suite for the `validPassword` form validator, verifying password strength rules including minimum/maximum length, and required character types (letters, numbers, symbols).

## Key Components

- **`validPassword`** — imported validator function under test, sourced from `components/forms/validators/valid_password`
- **Invalid password cases** — tests eight distinct failure scenarios, each asserting the correct `error` message and `error_code`
- **Valid password cases** — tests four passing examples confirming `{ isValid: true, error: "", error_code: "" }` is returned

## Validation Rules Covered

| Scenario | `error_code` | `error` |
|---|---|---|
| Fewer than 12 characters | `too_short` | "Password must be at least 12 characters" |
| Missing symbol, letters, or numbers | `invalid_format` | "Password must meet the criteria below" |
| Exceeds maximum length | `too_long` | "Password is over the character limit" |
| Valid (≥12 chars, has number + symbol) | `""` | `""` |

## Usage Example

```javascript
import validPassword from "components/forms/validators/valid_password";

// Invalid - too short
validPassword("abc12!");
// → { isValid: false, error: "Password must be at least 12 characters", error_code: "too_short" }

// Invalid - no symbol
validPassword("abc12456aaaa");
// → { isValid: false, error: "Password must meet the criteria below", error_code: "invalid_format" }

// Valid
validPassword("p@assw0rd123");
// → { isValid: true, error: "", error_code: "" }
```
