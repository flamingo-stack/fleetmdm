Validates SQL query strings using `node-sql-parser`, returning structured success/error responses for use in query form validation flows.

## Key Components

- **`EMPTY_QUERY_ERR`** — Exported error constant for missing/empty query text
- **`INVALID_SYNTAX_ERR`** — Exported error constant for SQL syntax failures
- **`validateQuery(queryText?)`** — Main export; accepts an optional query string and returns `{ valid: boolean, error: string | null }`

## Usage Example

```typescript
import { validateQuery, EMPTY_QUERY_ERR, INVALID_SYNTAX_ERR } from "./index";

// Empty input
validateQuery();
// → { valid: false, error: "Query text must be present" }

// Invalid SQL
validateQuery("SELECT * FORM hosts");
// → { valid: false, error: "Syntax error. Please review before saving." }

// Valid SQL
validateQuery("SELECT * FROM hosts WHERE platform = 'darwin'");
// → { valid: true, error: null }
```

## Behavior Notes

- Trims whitespace before checking for empty input
- Parses against the **SQLite** dialect via `parser.astify()`
- Any parse exception is caught and mapped to `INVALID_SYNTAX_ERR`; raw parser errors are not exposed to callers
