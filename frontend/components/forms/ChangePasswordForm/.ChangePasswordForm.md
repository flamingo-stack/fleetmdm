A React class component that renders a password change form with validation, allowing users to update their account password by providing their current password and confirming a new one.

## Key Components

- **`ChangePasswordForm`** – Class component rendering three password input fields (original, new, confirmation) with submit and cancel actions
- **`formFields`** – Array defining the three managed form fields: `old_password`, `new_password`, `new_password_confirmation`
- **`validate`** – External validation function imported from the same directory, applied via the `Form` HOC
- **`Form` HOC** – Higher-order component wrapping `ChangePasswordForm` to inject field state management and validation

## Props

| Prop | Type | Description |
|------|------|-------------|
| `fields` | `shape` | Managed field objects for each password input |
| `handleSubmit` | `func` | Form submission handler |
| `onCancel` | `func` | Callback to dismiss/cancel the form |

## Usage Example

```javascript
import ChangePasswordForm from "components/forms/ChangePasswordForm";

<ChangePasswordForm
  handleSubmit={(formData) => {
    // formData includes old_password, new_password, new_password_confirmation
    api.changePassword(formData);
  }}
  onCancel={() => setModalVisible(false)}
/>
```

> **Password requirements:** New password must be at least 12 characters, include at least 1 number (0–9), and at least 1 symbol (e.g. `&*#`).
