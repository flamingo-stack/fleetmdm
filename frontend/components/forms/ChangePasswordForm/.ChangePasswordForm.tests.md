Test suite for the `ChangePasswordForm` React component, verifying field rendering, input validation, and form submission behavior.

## Key Components

- **`renderWithSetup`** — Custom test utility that wraps `render` with user-event setup for simulating typed input and clicks
- **`ChangePasswordForm`** — The component under test, accepting `handleSubmit` and `onCancel` callback props

## Test Cases

| Test | Description |
|------|-------------|
| `has the correct fields` | Verifies presence of all three password fields and both action buttons |
| `renders password fields as HTML password fields` | Ensures all inputs use `type="password"` |
| `should trigger validation for all fields` | Confirms empty submission shows required-field errors without calling `handleSubmit` |
| `does not submit when new password is invalid` | Blocks submission when password fails strength criteria |
| `does not submit when confirm password mismatches` | Blocks submission when confirmation does not match new password |
| `calls handleSubmit with form data` | Verifies successful submission passes correct `{ old_password, new_password, new_password_confirmation }` payload |
| `calls onCancel when Cancel is clicked` | Confirms cancel button fires `onCancel` prop |

## Usage Example

```javascript
import { renderWithSetup } from "test/test-utils";
import ChangePasswordForm from "components/forms/ChangePasswordForm";

const props = {
  handleSubmit: jest.fn(),
  onCancel: jest.fn(),
};

// Render and interact with valid credentials
const { user } = renderWithSetup(<ChangePasswordForm {...props} />);
await user.type(screen.getByLabelText("Original password"), "p@ssw0rd123#");
await user.type(screen.getByLabelText("New password"), "newP@ss123!");
await user.type(screen.getByLabelText("New password confirmation"), "newP@ss123!");
await user.click(screen.getByRole("button", { name: "Change password" }));

expect(props.handleSubmit).toHaveBeenCalledWith({ ... });
```
