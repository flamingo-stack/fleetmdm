Validates the change-password form by checking field presence, password strength, and confirmation match.

## Key Components

- **Default export** — A validation function that accepts a `formData` object and returns a `{ valid, errors }` result object.

**Validation rules applied:**
| Field | Rule |
|---|---|
| `old_password` | Must be present |
| `new_password` | Must be present and pass `validPassword` strength check |
| `new_password_confirmation` | Must be present and match `new_password` |

**Dependencies:**
- [`validPassword`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/validators/valid_password.js) — Checks password strength/format
- [`validateEquality`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/validators/validate_equality.js) — Compares two values for equality
- `lodash/size` — Determines if the errors object is empty

## Usage Example

```javascript
import validate from "components/forms/validators/validate";

const formData = {
  old_password: "currentPass1!",
  new_password: "newSecurePass1!",
  new_password_confirmation: "newSecurePass1!",
};

const { valid, errors } = validate(formData);

if (!valid) {
  console.log(errors);
  // e.g. { new_password_confirmation: "New password confirmation does not match new password" }
}
```
