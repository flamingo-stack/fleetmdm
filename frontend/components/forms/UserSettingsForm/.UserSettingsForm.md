A React class component that renders a user settings form with fields for email, full name, and position, wrapped with the `Form` higher-order component for field management and validation.

## Key Components

- **`UserSettingsForm`** — Class component rendering the profile settings form
- **`renderEmailHelpText()`** — Conditionally renders a pending email change notice
- **`formFields`** — Array defining managed fields: `email`, `name`, `position`, `username`
- **`Form` HOC** — Wraps the component with field state management and the `validate` function from the sibling `validate` module

## Props

| Prop | Type | Description |
|------|------|-------------|
| `fields` | `object` | Injected by `Form` HOC; contains `email`, `name`, `position` field interfaces |
| `handleSubmit` | `func` | Form submission handler |
| `onCancel` | `func` | Cancel button callback |
| `pendingEmail` | `string` | Displays a pending email change notice when present |
| `smtpConfigured` | `bool` | Makes the email field read-only when SMTP/SES is not configured |

## Usage Example

```javascript
import UserSettingsForm from "components/forms/UserSettingsForm";

<UserSettingsForm
  handleSubmit={(formData) => updateUser(formData)}
  onCancel={() => closeModal()}
  pendingEmail="newemail@example.com"
  smtpConfigured={true}
/>
```

> **Note:** The email field is read-only when `smtpConfigured` is `false`, and displays a tooltip directing admins to **Settings > Organization settings** to configure SMTP or SES before email changes can be made.
