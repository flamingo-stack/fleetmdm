Test suite for the `UserSettingsForm` component, verifying rendering, form validation, and submission behavior using React Testing Library.

## Key Components

- **`renderWithSetup`** — Custom test utility that wraps the component with user-event setup for simulating interactions
- **`defaultProps`** — Shared mock props (`handleSubmit`, `onCancel`) reused across test cases
- **Test cases:**
  - `renders correctly` — Verifies presence of email, full name fields, and Update/Cancel buttons
  - `should pass validation checks for input fields` — Confirms empty form submission is blocked with appropriate error messages
  - `should throw validation error when invalid email is entered` — Checks email format validation
  - `calls the handleSubmit props with form data` — Asserts correct form data is passed on valid submission
  - `initializes the form with the users data` — Verifies `formData` prop pre-populates form fields

## Usage Example

```javascript
// Run all tests in this suite
jest.fn(); // mock handleSubmit and onCancel

const defaultProps = {
  handleSubmit: jest.fn(),
  onCancel: jest.fn(),
};

// Render with pre-populated user data
render(<UserSettingsForm formData={{ email: "user@example.com", name: "Jane Doe" }} {...defaultProps} />);

// Render with SMTP configured (enables email validation)
renderWithSetup(<UserSettingsForm smtpConfigured={true} {...defaultProps} />);
```

## Notes

- `smtpConfigured: true` must be passed to trigger email format validation in certain test cases
- Uses `fireEvent` for synchronous click events and `user` (userEvent) for async typed interactions
