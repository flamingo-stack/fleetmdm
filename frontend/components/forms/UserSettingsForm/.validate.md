Validates invite form fields, checking that both email and full name are present and that the email is properly formatted.

## Key Components

- **`validate(formData)`** — Default export. Accepts a `formData` object with `email` and `name` fields, returning a result object indicating validity and any field-level errors.

## Validation Rules

| Field | Rules |
|-------|-------|
| `email` | Required; must pass `validEmail` format check |
| `name` | Required |

## Usage Example

```javascript
import validate from "components/forms/InviteUserModal/validate";

const result = validate({ email: "bad-email", name: "" });
// result.valid  => false
// result.errors => { email: "bad-email is not a valid email", name: "Full name field must be completed" }

const result = validate({ email: "jane@example.com", name: "Jane Doe" });
// result.valid  => true
// result.errors => {}
```

## Return Shape

```javascript
{
  valid: Boolean,  // true when errors object is empty
  errors: {
    email?: String, // present if email is missing or malformed
    name?: String   // present if name is missing
  }
}
```
