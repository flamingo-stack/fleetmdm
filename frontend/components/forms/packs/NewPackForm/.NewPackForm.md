Form component for creating a new osquery pack, handling name/description input, target selection, and submission validation.

## Key Components

**Props (`INewPackForm`)**
| Prop | Type | Description |
|------|------|-------------|
| `handleSubmit` | `(formData: IEditPackFormData) => void` | Callback fired with form data on valid submission |
| `onFetchTargets` | `(query, targetsResponse) => boolean` | Callback for target search API calls |
| `selectedTargetsCount` | `number` | Count of currently selected targets |
| `isPremiumTier` | `boolean` | Enables premium target options in dropdown |
| `isUpdatingPack` | `boolean` | Shows loading state on submit button |

**Internal State**
- `packName` / `packDescription` — controlled input values
- `newPackFormTargets` — array of selected `ITarget` objects
- `errors` — field-level validation error map

**Validation**
- Prevents submission if `packName` is empty, setting an inline error on the name field

## Usage Example

```typescript
import NewPackForm from "components/forms/NewPackForm";

<NewPackForm
  handleSubmit={(formData) => {
    // formData: { name, description, targets }
    createPack(formData);
  }}
  onFetchTargets={(query, response) => {
    updateTargetCount(response.targets_count);
    return true;
  }}
  selectedTargetsCount={targetCount}
  isPremiumTier={currentUser.isPremium}
  isUpdatingPack={isLoading}
/>
```
