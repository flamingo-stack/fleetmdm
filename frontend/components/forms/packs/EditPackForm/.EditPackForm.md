A React form component for editing an existing osquery pack, including pack name, description, target selection, and scheduled queries management.

## Key Components

### Interfaces

- **`IEditPackForm`** — Props interface defining callbacks, state flags, and form data for the edit pack form
- **`IEditPackFormData`** — Shape of the form's submitted data: `name`, `description`, and `targets`

### Component: `EditPackForm`

Controlled form component that manages local state for pack name, description, and targets, syncing with incoming `formData` via `useDeepEffect`.

**Key behaviors:**
- Validates that `packName` is non-empty before submission
- Syncs `packFormTargets` when `formData.targets` changes (deep comparison via `useDeepEffect`)
- Delegates query management (add/edit/remove) to parent via callbacks

**Rendered sub-components:**
| Component | Purpose |
|---|---|
| `InputField` | Pack name and description inputs |
| `SelectTargetsDropdown` | Host/group target picker with premium tier support |
| `PackQueriesTable` | Displays and manages scheduled queries in the pack |

## Usage Example

```typescript
<EditPackForm
  formData={{ name: "My Pack", description: "Weekly checks", targets: [] }}
  scheduledQueries={scheduledQueries}
  isLoadingPackQueries={false}
  isUpdatingPack={false}
  targetsCount={3}
  isPremiumTier={true}
  handleSubmit={(data) => updatePack(packId, data)}
  onCancelEditPack={() => router.push("/packs")}
  onFetchTargets={(query, response) => handleTargets(query, response)}
  onAddPackQuery={() => setShowAddQueryModal(true)}
  onEditPackQuery={(query) => setSelectedQuery(query)}
  onRemovePackQueries={(ids) => removeQueries(packId, ids)}
/>
```
