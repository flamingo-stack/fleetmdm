Brief description of the file's purpose: Test suite for the `OrgDetails` registration form component, validating rendering, field validation, and form submission behavior.

## Key Components

- **`describe("OrgDetails - form")`** — Top-level test suite grouping all `OrgDetails` component tests
- **`handleSubmitSpy`** — Jest mock function injected as the `handleSubmit` prop to assert submission calls
- **`renderWithSetup`** — Custom test utility (from `test/test-utils`) that provides a `user` event instance for simulating interactions

## Test Cases

| Test | Description |
|------|-------------|
| `renders` | Asserts the organization name text input and "Next" button are present in the DOM |
| `validates presence of org_name field` | Confirms submission is blocked and an error message appears when the org name field is empty |
| `submits with the org name and a null logo when no file is selected` | Verifies `handleSubmit` is called with `{ org_name, org_logo_file: null }` when only the name is provided |

## Usage Example

```typescript
// Running the tests
// From the repo root:
// npx jest OrgDetails.tests.tsx

// Example of the shape asserted in the submit test:
handleSubmitSpy.toHaveBeenCalledWith({
  org_name: "The Gnar Co",
  org_logo_file: null,
});
```

## Notes

- The `currentPage` prop is passed as `true` in all tests, indicating this component conditionally renders based on wizard step
- `handleSubmitSpy.mockReset()` runs before each test to prevent cross-test call pollution
- Logo upload is not exercised here; `org_logo_file` defaults to `null` when no file is selected
