React form component for capturing organization name and logo during onboarding/setup flows. Manages blob URL lifecycle for logo previews and validates file uploads before accepting them.

## Key Components

### Interfaces
- **`IOrgDetailsFormData`** — Form payload shape: `org_name` (string) and optional `org_logo_file` (File)
- **`IOrgDetailsProps`** — Component props including `currentPage` (controls autofocus/submit button), `formData` (pre-populated values), and `handleSubmit` callback
- **`ICustomLogo`** — Internal state pairing a `File` with its `blob:` preview URL

### State & Refs
- `orgName` / `customLogo` / `errors` — Controlled form state
- `activePreviewUrlRef` — Tracks the live blob URL; revoked on unmount to prevent memory leaks

### Handlers
- `onOrgNameChange` — Updates name state and clears related validation error
- `onFileSelect` — Validates file via `validateOrgLogoFile`, generates a blob preview URL, revokes the previous URL if one exists
- `onDeleteFile` — Clears logo state and revokes the active blob URL
- `onSubmit` — Validates required `org_name` before invoking `handleSubmit`

## Usage Example

```typescript
import OrgDetails from "components/forms/OrgDetails";

const MySetupStep = () => {
  const handleSubmit = (data: IOrgDetailsFormData) => {
    console.log(data.org_name, data.org_logo_file);
  };

  return (
    <OrgDetails
      currentPage={true}
      formData={{ org_name: "Acme Corp" }}
      handleSubmit={handleSubmit}
      className="org-details-step"
    />
  );
};
```

> **Note:** Blob URLs created for logo previews are automatically revoked when the component unmounts or when a new file replaces the previous one, preventing memory leaks.
