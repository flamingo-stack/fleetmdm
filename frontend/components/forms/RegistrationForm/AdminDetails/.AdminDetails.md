A multi-field registration form component for capturing Fleet admin account details (name, email, password, and password confirmation) during the initial setup wizard.

## Key Components

- **`AdminDetails`** – Class component rendering a form with four `InputField` instances and a "Next" submit button
- **`formFields`** – Array `["name", "password", "password_confirmation", "email"]` passed to the `Form` HOC for field management
- **`validate`** – Imported from local `helpers` to handle field-level validation
- **`componentDidUpdate`** – Auto-focuses the first input when the wizard navigates to this page (delayed 300ms to match CSS transition)
- **`tabIndex`** – Dynamically set to `-1` when the page is not active, preventing tab navigation to off-screen fields

## Usage Example

```javascript
import AdminDetails from "components/forms/RegistrationForm/AdminDetails";

// Used as a wizard step; handleSubmit and currentPage are managed by the parent RegistrationForm
<AdminDetails
  currentPage={currentStep === 1}
  handleSubmit={this.handleAdminDetailsSubmit}
/>
```

## Notes

- Wrapped with the `Form` HOC (from `components/forms/Form`), which injects the `fields` prop and wires up form state/validation automatically
- `autoComplete="off"` and `ignore1password={false}` are set to control browser/password manager behavior explicitly
- Password help text enforces Fleet's password policy: 12–48 characters, at least 1 number and 1 symbol
