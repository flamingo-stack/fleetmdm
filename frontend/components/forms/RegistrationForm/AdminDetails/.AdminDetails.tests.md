Test suite for the `AdminDetails` registration form component, validating rendering, field validation, and form submission behavior.

## Key Components

- **`AdminDetails` component** — The form under test, sourced from `components/forms/RegistrationForm/AdminDetails`
- **`renderWithSetup`** — Custom test utility that provides a `user` event object for simulating interactions
- **`onSubmitSpy`** — Jest mock tracking `handleSubmit` calls

## Test Cases

| Test | Description |
|------|-------------|
| `renders` | Confirms all form fields (Email, Full name, Password, Confirm password) and the Next button are present |
| `validates missing fields` | Ensures all required fields show presence errors on empty submit |
| `validates the email field` | Rejects malformed email input |
| `validates the password fields match` | Rejects mismatched password/confirmation |
| `validates the password is not too long` | Enforces character limit on password |
| `validates the password field` | Enforces password complexity requirements |
| `submits the form when valid` | Confirms `handleSubmit` is called with correct payload on valid input |

## Usage Example

```javascript
// Running the test suite
// From the repo root:
// npx jest AdminDetails.tests.jsx

// Valid submission payload expected by the form:
{
  email: "hi@gnar.dog",
  name: "Gnar Dog",
  password: "password123#",
  password_confirmation: "password123#",
}
```

## Notes

- Tests use `@testing-library/react` with user-event for realistic interaction simulation
- The `currentPage` prop must be passed to enable validation on submit
- Password rules enforced: must meet complexity criteria, must match confirmation, and must not exceed the character limit
