Validation helper for the user registration/creation form, providing field-level validation for email, full name, password, and password confirmation inputs.

## Key Components

- **`validate(formData)`** — Accepts a form data object and returns a `{ valid, errors }` result object. Validates the following fields:
  - `email` — Must be present and a valid email format
  - `name` — Must be present
  - `password` — Must be present and meet password complexity rules
  - `password_confirmation` — Must be present and match `password`

## Usage Example

```javascript
import helpers from "./helpers";

const formData = {
  email: "user@example.com",
  name: "Jane Doe",
  password: "SecurePass1!",
  password_confirmation: "SecurePass1!",
};

const { valid, errors } = helpers.validate(formData);

if (!valid) {
  console.log(errors);
  // e.g. { password_confirmation: "Password confirmation does not match password" }
}
```

## Dependencies

| Dependency | Purpose |
|---|---|
| `validate_equality` | Checks that two values are identical |
| `valid_email` | Validates email format |
| `valid_password` | Enforces password complexity rules |
| `lodash/size` | Determines if the errors object is empty |
