Tests for the `ConfirmationPage` component within the registration flow, verifying that user-provided form data renders correctly and that form submission triggers the expected handler.

## Key Components

- **`renders the user information`** — Asserts that `name`, `email`, `org_name`, and `server_url` from `formData` are displayed in the DOM.
- **`submits the form`** — Simulates a click on the "Confirm" button and verifies the `handleSubmit` callback is invoked.

## Usage Example

```javascript
// Running the test suite
// Ensure Jest and @testing-library/react are installed, then:
// npx jest ConfirmationPage.tests.jsx

const formData = {
  name: "Test User",
  email: "test@example.com",
  org_name: "Fleet",
  server_url: "http://localhost:8080",
};

const handleSubmitSpy = jest.fn();

// Render and assert displayed data
render(<ConfirmationPage formData={formData} handleSubmit={handleSubmitSpy} />);
expect(screen.getByText(formData.name)).toBeInTheDocument();

// Simulate confirmation click
fireEvent.click(screen.getByText("Confirm"));
expect(handleSubmitSpy).toHaveBeenCalled();
```

## Notes

- The `currentPage` prop is required for the submit button to be active/visible in the confirmation step.
- `handleSubmit` is passed as a spy (`jest.fn()`) — no form submission side effects occur during tests.
