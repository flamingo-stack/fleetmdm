The final step in the Fleet registration wizard, displaying a summary of administrator configuration details (name, email, organization, Fleet URL) for review before submission.

## Key Components

- **`ConfirmationPage`** – Default export; a form component that renders a read-only summary table of `IRegistrationFormData` fields and a submit button
- **`importOsqueryConfig`** – Internal helper function for an osquery migration checkbox (currently disabled via `disableImport = true`)
- **`useEffect`** – Handles auto-focus on the confirm button when the page becomes active, with a 300ms delay to accommodate CSS transition animations

## Props

| Prop | Type | Description |
|------|------|-------------|
| `className` | `string` | Additional CSS class |
| `currentPage` | `boolean` | Controls focus behavior and tab accessibility |
| `formData` | `IRegistrationFormData` | Registration data to display |
| `handleSubmit` | `React.FormEventHandler` | Form submission handler |
| `isLoading` | `boolean?` | Shows loading state on the submit button |

## Usage Example

```typescript
import ConfirmationPage from "components/ConfirmationPage";

<ConfirmationPage
  className="registration-step"
  currentPage={activeStep === "confirmation"}
  formData={{
    name: "Jane Doe",
    email: "jane@example.com",
    org_name: "Acme Corp",
    server_url: "https://fleet.acme.com",
  }}
  handleSubmit={handleRegistrationSubmit}
  isLoading={isSubmitting}
/>
```

## Notes

- `tabIndex` is set to `-1` when not the active page to prevent off-screen tab navigation
