A multi-step registration wizard component that orchestrates a 4-page onboarding flow for Fleet MDM setup, accumulating form data across steps before final submission.

## Key Components

| Export/Member | Description |
|---|---|
| `RegistrationForm` | Class component managing the 4-step registration wizard |
| `onPageFormSubmit` | Merges per-page form data into state and advances to the next page |
| `onSubmitConfirmation` | Handles final form submission with all accumulated `formData` |
| `isCurrentPage` | Helper that returns `true` if the given page number matches the active page |
| `renderRegistrationForm` | Renders the correct step component based on the `page` prop |

**Page map:**

| Page | Component |
|---|---|
| 1 | `AdminDetails` |
| 2 | `OrgDetails` |
| 3 | `FleetDetails` |
| 4 | `ConfirmationPage` |

## Usage Example

```javascript
import RegistrationForm from "components/forms/RegistrationForm";

const MyRegistrationPage = () => {
  const [page, setPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);

  const handleNextPage = () => setPage((prev) => prev + 1);

  const handleSubmit = async (formData) => {
    setIsLoading(true);
    await registerFleetInstance(formData);
    setIsLoading(false);
  };

  return (
    <RegistrationForm
      page={page}
      onNextPage={handleNextPage}
      onSubmit={handleSubmit}
      isLoading={isLoading}
    />
  );
};
```

## Props

| Prop | Type | Description |
|---|---|---|
| `page` | `number` | Active wizard step (1–4) |
| `onNextPage` | `func` | Called after each page form submission |
| `onSubmit` | `func` | Called on final confirmation with full `formData` |
| `isLoading` | `bool` | Passed to `ConfirmationPage` to indicate submission in progress |

> **Note:** `server_url` is pre-populated from `window.location.origin` as the default Fleet server URL.
