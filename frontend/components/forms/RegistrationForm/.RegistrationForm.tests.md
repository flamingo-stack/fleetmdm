Test suite for the `RegistrationForm` component, verifying that the correct sub-form or page section renders based on the `page` prop.

## Key Components

- **`RegistrationForm`** — Multi-step registration form component imported from `components/forms/RegistrationForm`, accepts a `page` prop to control which step is displayed.
- **Page step assertions** — Each test renders the component with a specific `page` value and confirms the expected CSS class container is present in the DOM:
  - `page={1}` → `.user-registration__container--admin` (AdminDetails)
  - `page={2}` → `.user-registration__container--org` (OrgDetails)
  - `page={3}` → `.user-registration__container--fleet` (FleetDetails)
  - `page={4}` → `.user-registration__container--confirmation` (ConfirmationPage)

## Usage Example

```javascript
// Run the test suite
import { render } from "@testing-library/react";
import RegistrationForm from "components/forms/RegistrationForm";

// Verify a specific step renders its container
const { container } = render(<RegistrationForm page={2} />);
expect(
  container.querySelectorAll(".user-registration__container--org").length
).toEqual(1);
```

## Notes

- Uses [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) for DOM rendering.
- Tests are purely structural — they confirm the correct container element exists, not form field behavior or submission logic.
- Step headers are intentionally excluded from this component and are managed by the parent `RegistrationPage.tsx`.
