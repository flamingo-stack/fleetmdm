Test suite for the `FleetDetails` registration form component, validating rendering, field presence validation, URL format enforcement, and successful form submission with both `http` and `https` URLs.

## Key Components

- **`describe("FleetDetails - form")`** — Top-level test suite grouping all `FleetDetails` form behavior
- **`handleSubmitSpy`** — Jest mock function used to assert submission callback behavior
- **`INVALID_SERVER_URL_MESSAGE`** — Imported error constant used to verify URL format validation messages

## Test Cases

| Test | Description |
|------|-------------|
| `renders` | Verifies the "Fleet web address" textbox and "Next" button are present in the DOM |
| `validates presence` | Ensures empty submission prevents `handleSubmit` from being called and shows a required-field error |
| `validates URL format` | Confirms that URLs without `https://` or `http://` prefix (e.g. `gnar.Fleet.co`, `localhost:8080`) trigger `INVALID_SERVER_URL_MESSAGE` |
| `submits with https` | Confirms valid `https://` URL calls `handleSubmit` with the correct `server_url` payload |
| `submits with http` | Confirms valid `http://` URL (e.g. `http://localhost:8080`) also passes validation and submits correctly |

## Usage Example

```javascript
// Running the test suite
import { renderWithSetup } from "test/test-utils";
import FleetDetails from "components/forms/RegistrationForm/FleetDetails";

// Simulate user interaction with setup utilities
const { user } = renderWithSetup(
  <FleetDetails handleSubmit={handleSubmitSpy} currentPage />
);

await user.type(
  screen.getByRole("textbox", { name: "Fleet web address" }),
  "https://gnar.Fleet.co"
);
await user.click(screen.getByRole("button", { name: "Next" }));

expect(handleSubmitSpy).toHaveBeenCalledWith({
  server_url: "https://gnar.Fleet.co",
});
```
