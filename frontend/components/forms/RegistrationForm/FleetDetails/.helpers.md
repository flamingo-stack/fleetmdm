Provides form validation logic for the Fleet server URL configuration field.

## Key Components

- **`validate(formData)`** – Validates the `server_url` field from a form data object. Checks that the Fleet web address is present and conforms to a valid URL format (supporting `http` and `https` protocols, including `localhost`). Returns a result object containing a `valid` boolean and an `errors` map.

## Usage Example

```javascript
import helpers from "./helpers";

const formData = { server_url: "https://fleet.example.com" };
const { valid, errors } = helpers.validate(formData);

if (!valid) {
  console.error(errors.server_url); // e.g. "Fleet web address must be completed"
}
```

## Validation Rules

| Condition | Error Message |
|-----------|---------------|
| `server_url` is empty/missing | `"Fleet web address must be completed"` |
| `server_url` is not a valid HTTP/HTTPS URL | Value of `INVALID_SERVER_URL_MESSAGE` |

## Dependencies

- [`lodash/size`](https://lodash.com/docs/#size) – Determines if the errors object is empty
- `components/forms/validators/valid_url` – URL format validator with protocol and localhost support
- `utilities/error_messages` – Shared error message constants
