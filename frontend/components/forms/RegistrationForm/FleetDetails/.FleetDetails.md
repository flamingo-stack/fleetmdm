A registration form step component that collects the Fleet server URL, used as part of the multi-step `RegistrationForm` flow.

## Key Components

- **`FleetDetails`** — Class component rendering a single `server_url` input field and a "Next" submit button
- **`formFields`** — Declares `["server_url"]` as the managed form fields
- **`validate`** — Imported from [`helpers`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/RegistrationForm/FleetDetails/helpers.js) to handle field-level validation
- **`Form` HOC** — Wraps the component via the `Form` higher-order component, injecting `fields` and form state management
- **Auto-focus** — On `componentDidUpdate`, focuses the first input 300ms after becoming the active page to preserve CSS transition smoothness

## Usage Example

```javascript
// Used internally by RegistrationForm as a wizard step
import FleetDetails from "components/forms/RegistrationForm/FleetDetails";

<FleetDetails
  currentPage={currentStep === 0}
  handleSubmit={this.handleStepSubmit}
  className="registration-form__fleet-details"
/>
```

## Notes

- `tabIndex` is set to `-1` when the step is not active (`currentPage === false`), preventing keyboard navigation to off-screen fields
- The `server_url` help text explicitly warns users to omit `/latest` or any trailing path
- The component is exported as a wrapped `Form(FleetDetails, { fields, validate })` instance — the raw class is not exported directly
