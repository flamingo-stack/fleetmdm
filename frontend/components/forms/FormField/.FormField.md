A reusable form field wrapper component that provides consistent layout and styling for form inputs, including label rendering, error states, help text, and optional tooltip support.

## Key Components

### `IFormFieldProps`
| Prop | Type | Description |
|------|------|-------------|
| `children` | `JSX.Element` | The form input element to wrap |
| `label` | `React.ReactNode` | Field label content |
| `name` | `string` | Associates the label `htmlFor` attribute with the input |
| `error` | `string \| null` | Error message; replaces label text when present |
| `helpText` | `React.ReactNode` | Secondary descriptive text rendered below the input |
| `tooltip` | `React.ReactNode` | Tooltip content rendered via `TooltipWrapper` on the label |
| `labelTooltipPosition` | `PlacesType` | Position of the label tooltip |
| `type` | `string` | Appends a BEM modifier class (e.g., `form-field--checkbox`) |
| `disabled` | `boolean` | Applies disabled styling to the label |
| `className` | `string` | Additional CSS classes on the root element |

### Internal Renderers
- **`renderLabel()`** — Conditionally renders the label with error/disabled states and optional `TooltipWrapper`
- **`renderHelpText()`** — Renders optional help text below the child input

## Usage Example

```typescript
import FormField from "components/FormField";

// Basic usage
<FormField label="Email Address" name="email">
  <input type="email" id="email" />
</FormField>

// With error and help text
<FormField
  label="Username"
  name="username"
  error="Username is already taken"
  helpText="Must be 3–20 characters"
>
  <input type="text" id="username" />
</FormField>

// With tooltip on label
<FormField
  label="API Key"
  name="api_key"
  tooltip="Found in your account settings"
  labelTooltipPosition="right"
>
  <input type="text" id="api_key" />
</FormField>
```

> **Note:** All styles are defined in `_global.scss` using the `form-field` BEM base class, making this component a pure structural wrapper.
