Higher-order component (HOC) factory that wraps a component with form state management, field tracking, validation, and error handling.

## Key Components

- **`defaultValidate`** — Fallback validation function that always returns valid with no errors
- **`Form` (HOC)** — Class component managing form state, injected into the wrapped component via props:
  - `formData` — Tracks current field values
  - `errors` — Combines client-side validation and server-side errors
  - `onFieldChange(fieldName)` — Returns a change handler that updates a single field and clears its error
  - `onSubmit` — Runs validation before calling `handleSubmit`; sets client errors on failure
  - `getFields()` — Builds a field prop map (`error`, `name`, `onChange`, `value`) for each declared field
  - `resetField(fieldName)` — Clears a field's value and error
  - `getError(fieldName)` / `getValue(fieldName)` — Field-level state accessors

## Usage Example

```javascript
import Form from "./Form";

const fields = ["email", "password"];
const validate = ({ email, password }) => {
  if (!email) return { valid: false, errors: { email: "Required" } };
  return { valid: true, errors: {} };
};

const LoginForm = ({ fields, handleSubmit, baseError }) => (
  <form onSubmit={handleSubmit}>
    {baseError && <p>{baseError}</p>}
    <input
      name={fields.email.name}
      value={fields.email.value || ""}
      onChange={(e) => fields.email.onChange(e.target.value)}
    />
    {fields.email.error && <span>{fields.email.error}</span>}
    <button type="submit">Login</button>
  </form>
);

export default Form(LoginForm, { fields, validate });
```

## Notes

- Uses legacy lifecycle methods (`componentWillMount`, `componentWillReceiveProps`) — consider migrating to `getDerivedStateFromProps` for React 17+
- Server errors passed via `serverErrors` prop are merged with client validation errors, with server errors taking precedence on prop updates
