Test suite for the `ConfirmInviteForm` component, verifying rendering, form validation, error display, and submit behavior.

## Key Components

| Test | Description |
|------|-------------|
| `renders` | Verifies all form fields (Full name, Password, Confirm password) and Submit button are present |
| `renders the base error` | Confirms `ancestorError` prop displays an authentication error message |
| `calls the handleSubmit prop when valid` | Validates `handleSubmit` is called with correct payload on successful submission |
| `name input` | Validates "Full name must be present" error when name is empty |
| `password input` | Validates "Password must be present" error when password is empty |
| `password_confirmation input` | Validates mismatch and presence errors for the confirm password field |

## Usage Example

```typescript
// Running the test suite
// From the repo root:
// npx jest ConfirmInviteForm.tests.tsx

// Example: testing valid form submission
const { user } = renderWithSetup(
  <ConfirmInviteForm
    defaultFormData={{ name: "Test User" }}
    handleSubmit={handleSubmitSpy}
  />
);

await user.type(screen.getByLabelText("Password"), "p@ssw0rd");
await user.type(screen.getByLabelText("Confirm password"), "p@ssw0rd");
await user.click(screen.getByRole("button", { name: "Submit" }));

expect(handleSubmitSpy).toHaveBeenCalledWith({
  name: "Test User",
  password: "p@ssw0rd",
  password_confirmation: "p@ssw0rd",
});
```
