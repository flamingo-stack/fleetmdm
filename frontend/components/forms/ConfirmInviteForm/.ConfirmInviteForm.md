Form component for completing a user invite by collecting full name, password, and password confirmation with inline validation.

## Key Components

### Interfaces

- **`IConfirmInviteFormData`** — Form data shape: `name`, `password`, `password_confirmation`
- **`IConfirmInviteFormProps`** — Component props: optional `defaultFormData`, `handleSubmit` callback, and `ancestorError` for server-side errors
- **`IConfirmInviteFormErrors`** — Validation error shape mirroring form fields

### Functions

- **`validate(formData)`** — Pure validation function; checks name presence, password presence, confirmation presence, and equality between password fields
- **`ConfirmInviteForm`** — Main form component with controlled inputs and progressive error display

### Validation Behavior

- Errors are only surfaced on **submit** for new issues
- On **input change**, only previously surfaced errors are re-evaluated and updated, preventing premature error messages

## Usage Example

```typescript
import ConfirmInviteForm, {
  IConfirmInviteFormData,
} from "components/forms/ConfirmInviteForm";

const handleInviteSubmit = (data: IConfirmInviteFormData) => {
  // Call API to complete registration
  api.confirmInvite(data);
};

<ConfirmInviteForm
  defaultFormData={{ name: "Jane Doe" }}
  handleSubmit={handleInviteSubmit}
  ancestorError={serverError} // e.g. "Invite token has expired"
/>;
```

## Notes

- Password must be ≥12 characters, include at least 1 number and 1 symbol (enforced via `helpText`; enforcement is UI-guidance only at this layer)
- `autoComplete="off"` and `ignore1password={false}` are set on the form and inputs
- Submit button is disabled while any validation errors are present
