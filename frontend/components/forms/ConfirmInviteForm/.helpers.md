Provides form validation logic for user account creation or profile forms, checking required fields and password confirmation matching.

## Key Components

- **`validate(formData)`** — Validates a form data object containing `name`, `password`, and `password_confirmation` fields. Returns a `{ valid, errors }` result object.

## Validation Rules

| Field | Rule |
|---|---|
| `name` | Must be present |
| `password` | Must be present |
| `password_confirmation` | Must be present and match `password` |

## Usage Example

```javascript
import helpers from "./helpers";

const formData = {
  name: "Jane Doe",
  password: "secret123",
  password_confirmation: "secret123",
};

const { valid, errors } = helpers.validate(formData);

if (!valid) {
  console.log(errors);
  // e.g. { password_confirmation: "Password confirmation does not match password" }
}
```

## Dependencies

- [`lodash/size`](https://lodash.com/docs/#size) — Determines if the errors object is empty to derive the `valid` boolean.
- [`validateEquality`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/validators/validate_equality) — Compares `password` and `password_confirmation` for equality.
