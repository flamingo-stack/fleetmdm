Test suite for the `ResetPasswordForm` component, validating form rendering, input validation, and submission behavior.

## Key Components

- **`renderWithSetup`** – Custom test utility that provides a `user` event simulation instance alongside the rendered component
- **`submitSpy`** – Jest mock function passed as `handleSubmit` prop to assert call behavior
- **Test cases** – Seven focused scenarios covering the full validation and submission lifecycle

## Test Coverage

| Scenario | Expected Behavior |
|---|---|
| Initial render | Both password fields and submit button are present |
| Empty form submission | Shows required field errors for both inputs; blocks submit |
| Only new password filled | Shows confirmation required error; blocks submit |
| Only confirmation filled | Shows new password required error; blocks submit |
| Passwords do not match | Shows mismatch error; blocks submit |
| Invalid password format | Shows criteria error; blocks submit |
| Valid matching passwords | Calls `handleSubmit` with `new_password` and `new_password_confirmation` |

## Usage Example

```javascript
// Running the test suite
import { renderWithSetup } from "test/test-utils";
import ResetPasswordForm from "./ResetPasswordForm";

const submitSpy = jest.fn();
const { user } = renderWithSetup(
  <ResetPasswordForm handleSubmit={submitSpy} />
);

// Simulate valid submission
await user.type(screen.getByPlaceholderText("New password"), "password123!");
await user.type(screen.getByPlaceholderText("Confirm password"), "password123!");
await user.click(screen.getByRole("button", { name: "Reset password" }));

expect(submitSpy).toHaveBeenCalledWith({
  new_password: "password123!",
  new_password_confirmation: "password123!",
});
```
