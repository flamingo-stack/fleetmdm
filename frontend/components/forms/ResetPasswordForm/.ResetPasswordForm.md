A React form component for resetting a user's password, handling input validation, error display, and form submission.

## Key Components

### Interfaces
- **`IOldApiError`** — Shape of server-side errors returned by `utilities/format_error_response` (`http_status`, `base`)
- **`IFormData`** — Submitted form payload containing `new_password` and `new_password_confirmation`
- **`IResetPasswordFormProps`** — Component props: `serverErrors` and `handleSubmit` callback

### Internal Logic
- **`validate()`** — Runs three validators before submission:
  - `validatePassword` — Enforces password complexity (12–48 chars, ≥1 number, ≥1 symbol)
  - `validatePresence` — Ensures both fields are non-empty
  - `validateEquality` — Confirms passwords match
- **`onInputChange(formField)`** — Curried handler that updates `formData` state and clears errors on each keystroke
- **`onFormSubmit(evt)`** — Prevents default form submission, runs `validate()`, then calls `handleSubmit` if valid

## Usage Example

```typescript
import ResetPasswordForm, { IFormData, IOldApiError } from "components/forms/ResetPasswordForm";

const handlePasswordReset = (formData: IFormData) => {
  api.resetPassword(formData.new_password);
};

const serverErrors: IOldApiError = { http_status: 422, base: "Token expired" };

<ResetPasswordForm
  serverErrors={serverErrors}
  handleSubmit={handlePasswordReset}
/>
```

## Validation Rules

| Field | Rule |
|-------|------|
| `new_password` | Required; 12–48 chars, ≥1 number, ≥1 symbol |
| `new_password_confirmation` | Required; must match `new_password` |
