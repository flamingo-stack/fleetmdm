Validates email form data by checking for presence and proper email format, returning a validation result object.

## Key Components

- **`validate(formData)`** — Default export. Accepts a `formData` object, runs presence and format checks on the `email` field, and returns `{ valid, errors }`.

## Usage Example

```javascript
import validate from "components/forms/validators/validate";

const result = validate({ email: "user@example.com" });
// { valid: true, errors: {} }

const result = validate({ email: "" });
// { valid: false, errors: { email: "Email field must be completed" } }

const result = validate({ email: "not-an-email" });
// { valid: false, errors: { email: "Email must be a valid email address" } }
```

## Validation Rules

| Field | Rule | Error Message |
|-------|------|---------------|
| `email` | Must be present | `"Email field must be completed"` |
| `email` | Must be valid format | `"Email must be a valid email address"` |

## Dependencies

- [`validatePresence`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/validators/validate_presence.js) — Checks field is non-empty
- [`validateEmail`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/forms/validators/valid_email.js) — Checks valid email format
- `lodash/size` — Used to determine if the errors object is empty
