Unit tests for the `ForgotPasswordForm` React component, verifying rendering, validation, error display, and form submission behavior.

## Key Components

- **`renderWithSetup`** — Custom test utility that returns a `user` event instance for simulating interactions
- **Test constants** — `validEmail` (`"hi@thegnar.co"`) and `invalidEmail` (`"invalid-email"`) used across test cases
- **`handleSubmit`** — Jest mock function injected as a prop to assert call behavior

## Test Cases

| Test | Description |
|------|-------------|
| `renders correctly` | Asserts the email input and "Get instructions" button are present |
| `renders with server error prop` | Verifies `serverErrors.base` message is displayed in the UI |
| `correctly validates the email field` | Checks empty-field and invalid-format validation messages; asserts `handleSubmit` is not called |
| `submits the form data` | Types a valid email and confirms `handleSubmit` is called with `{ email: validEmail }` |

## Usage Example

```javascript
// Running the tests
// From the repo root:
npx jest ForgotPasswordForm.tests.jsx

// Core pattern used in tests
const { user } = renderWithSetup(
  <ForgotPasswordForm handleSubmit={handleSubmit} />
);

await user.type(screen.getByPlaceholderText("Email"), "hi@thegnar.co");
await user.click(screen.getByRole("button", { name: "Get instructions" }));

expect(handleSubmit).toHaveBeenCalledWith({ email: "hi@thegnar.co" });
```
