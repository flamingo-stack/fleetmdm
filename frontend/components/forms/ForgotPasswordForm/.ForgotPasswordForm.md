A React class component that renders a password reset request form, allowing users to submit their email address to receive password reset instructions.

## Key Components

- **`ForgotPasswordForm`** — Class component rendering an email input and submit button wrapped in a `<form>` element
- **`Form` HOC** — Wraps the component with form state management, binding `fields`, `handleSubmit`, and validation logic
- **`validate`** — Local validation module applied via the `Form` HOC
- **`InputFieldWithIcon`** — Styled email input field with autofocus enabled
- **`Button`** — Submit button with loading state support

## Props

| Prop | Type | Description |
|------|------|-------------|
| `baseError` | `string` | Top-level error message displayed above the form |
| `fields` | `shape` | Form field state object (requires `email`) |
| `handleSubmit` | `func` | Submit handler injected by the `Form` HOC |
| `isLoading` | `bool` | Toggles loading state on the submit button |

## Usage Example

```javascript
import ForgotPasswordForm from "components/forms/ForgotPasswordForm";

// The Form HOC handles field state and validation internally
const ForgotPasswordPage = ({ onSubmit }) => (
  <ForgotPasswordForm
    handleSubmit={onSubmit}
    isLoading={false}
    baseError="Invalid email address"
  />
);
```

## Notes

- `autoComplete="off"` and `noValidate` are set on the `<form>` element; HTML5 validation is suppressed in favor of the custom `validate` module
- The component is exported as a `Form`-enhanced version — the raw class is not exported directly
