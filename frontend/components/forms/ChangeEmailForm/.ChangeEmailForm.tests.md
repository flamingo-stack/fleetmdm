Test suite for the `ChangeEmailForm` React component, validating rendering, form validation, submission behavior, and cancel functionality.

## Key Components

- **`renderWithSetup`** — Custom test utility providing a `user` event instance for simulating interactions
- **`ChangeEmailForm`** — The component under test, expecting `handleSubmit` and `onCancel` props

## Test Cases

| Test | Description |
|------|-------------|
| Renders correctly | Asserts Password field, Submit, and Cancel buttons are present in the DOM |
| Empty password blocks submit | Clicking Submit without a password shows `"Password must be present"` and prevents `handleSubmit` from being called |
| Valid password submits form | Typing a password and clicking Submit calls `handleSubmit` with `{ password }` |
| Cancel button triggers callback | Clicking Cancel invokes the `onCancel` prop |

## Usage Example

```javascript
import { renderWithSetup } from "test/test-utils";
import ChangeEmailForm from "./ChangeEmailForm";

const props = {
  handleSubmit: jest.fn(),
  onCancel: jest.fn(),
};

// Render and interact
const { user } = renderWithSetup(<ChangeEmailForm {...props} />);
await user.type(screen.getByLabelText("Password"), "p@ssw0rd");
await user.click(screen.getByRole("button", { name: "Submit" }));

expect(props.handleSubmit).toHaveBeenCalledWith({ password: "p@ssw0rd" });
```
