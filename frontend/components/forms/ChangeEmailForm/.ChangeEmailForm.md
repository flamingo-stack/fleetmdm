A React form component that prompts users to confirm their password before updating their email address, with built-in validation via a higher-order `Form` wrapper.

## Key Components

- **`ChangeEmailForm`** — Class component rendering a password confirmation input with Submit and Cancel action buttons
- **`Form` HOC** — Wraps the component to manage field state and validation logic
- **Validation** — Ensures the password field is non-empty before allowing submission

## Usage Example

```javascript
import ChangeEmailForm from "components/forms/ChangeEmailForm";

<ChangeEmailForm
  handleSubmit={(formData) => console.log("Update email with:", formData)}
  onCancel={() => setModalVisible(false)}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `fields.password` | `formFieldInterface` | Password field state managed by the `Form` HOC |
| `handleSubmit` | `func` | Called on form submission with validated field data |
| `onCancel` | `func` | Called when the user clicks the Cancel button |
