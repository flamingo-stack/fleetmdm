Test suite for the `Dropdown` form field component, verifying rendering and user interaction behavior using React Testing Library.

## Key Components

- **`render` / `renderWithSetup`** — Standard RTL render and a custom utility that includes a configured `user` event object for simulating interactions
- **`Dropdown`** — The component under test, imported from `components/forms/fields/Dropdown`
- **Two test cases:**
  - `renders the dropdown` — Asserts the combobox role is present in the DOM
  - `selects a value from dropdown` — Simulates typing and clicking an option, then asserts the `onChange` callback is called with the correct value

## Usage Example

```javascript
// Running the tests
// From the repo root:
npx jest Dropdown.tests.jsx

// Custom renderWithSetup utility (used internally)
const { user } = renderWithSetup(<Dropdown {...props} onChange={onChangeSpy} />);
await user.type(inputNode, "users");
await user.click(screen.getByRole("option"));
expect(onChangeSpy).toHaveBeenCalledWith("users");
```

## Notes

- Uses `jest.fn()` as a spy to verify the `onChange` handler receives the selected option's `value` string (e.g., `"users"`), not the full option object.
- The `options` fixture provides two entries (`Users`, `Groups`) sufficient to validate selection logic without over-specifying the test surface.
- Relies on `renderWithSetup` from `test/test-utils` for `userEvent` v14+ setup — see [`test/test-utils`](https://github.com/flamingo-stack/fleetmdm/blob/main/test/test-utils.js) for the shared helper.
