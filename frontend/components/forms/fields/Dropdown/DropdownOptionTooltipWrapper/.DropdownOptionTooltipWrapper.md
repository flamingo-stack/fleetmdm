A React wrapper component that attaches a tooltip to dropdown option elements using `react-tooltip-5`, with configurable placement, delay, and offset.

## Key Components

### `IDropdownOptionTooltipWrapper`
Interface defining the component props:
- `children` — the dropdown option element to wrap
- `tipContent` — tooltip content (supports React nodes)
- `isDelayed?` — adds 500ms show/hide delay when `true`
- `place?` — tooltip position (`"left"` | `"right"` | `"top"` | `"bottom"`), defaults to `"left"`
- `offset?` — pixel offset from the target, defaults to `24`
- `clickable?` — whether the tooltip is interactive, defaults to `true`
- `className?` / `tooltipClass?` — custom class overrides

### `DropdownOptionTooltipWrapper`
Default export. Generates a unique ID per instance via `lodash.uniqueId()` to bind the tooltip anchor to its `ReactTooltip5` instance. Uses `positionStrategy="fixed"` (note: known rendering issue inside Modals).

## Usage Example

```typescript
import DropdownOptionTooltipWrapper from "components/DropdownOptionTooltipWrapper";

<DropdownOptionTooltipWrapper
  tipContent={<span>This action is disabled</span>}
  place="right"
  isDelayed
>
  <button disabled>Delete</button>
</DropdownOptionTooltipWrapper>
```

## Notes

- Tooltip position strategy is `"fixed"`, which may render incorrectly when used inside a Modal — see the inline `TODO` comment in the [source](https://github.com/flamingo-stack/fleetmdm/blob/main/DropdownOptionTooltipWrapper.tsx).
- Style injection is disabled (`disableStyleInjection`); ensure `react-tooltip-5` styles are imported globally.
