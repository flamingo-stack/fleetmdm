Storybook stories file for the `Dropdown` form field component, defining default metadata and a baseline story for visual testing and documentation in Storybook.

## Key Components

- **`meta`** – Storybook `Meta` configuration registering `Dropdown` under `Components/FormFields/Dropdown` with a full set of default args (options, placeholder, event handlers, etc.)
- **`authMethodOptions`** – Sample options array (`Plain`, `Cram MD5`, `Login`) used as default story data
- **`Default`** – Baseline `Story` export rendering the `Dropdown` with all default args

## Usage Example

```typescript
// Extend the Default story to create a variant
import { Default } from "./Dropdown.stories";

export const WithError: Story = {
  args: {
    ...Default.args,
    error: "Please select an authentication method",
    value: "",
  },
};

export const MultiSelect: Story = {
  args: {
    multi: true,
    placeholder: "Choose multiple...",
    options: authMethodOptions,
  },
};
```

## Default Args Reference

| Prop | Default |
|---|---|
| `clearable` | `false` |
| `searchable` | `false` |
| `disabled` | `false` |
| `multi` | `false` |
| `placeholder` | `"Choose one..."` |
| `options` | `authMethodOptions` |
