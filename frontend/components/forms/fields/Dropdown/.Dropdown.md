A reusable dropdown select component that wraps `react-select` within a `FormField`, supporting labels, validation errors, tooltips, icons, and multi-select behavior.

## Key Components

- **`Dropdown`** — Main class component that renders a styled `<Select>` inside a `<FormField>` wrapper
- **`handleChange`** — Normalizes selection output; supports single, multi, clearable, and `parseTarget` modes
- **`renderOption`** — Custom option renderer supporting per-option `tooltipContent` and `helpText`
- **`renderWithIcon`** — Renders the selected value with a prepended styled icon when `iconName` is provided
- **`renderCustomDropdownArrow`** — Replaces the default dropdown arrow with a `chevron-down` icon

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `array` | required | Array of `{ label, value }` objects |
| `value` | `string \| number \| array` | — | Must match an option's `value` field |
| `onChange` | `func` | `noop` | Called with selected value(s) |
| `parseTarget` | `bool` | `false` | Returns `{ value, name }` instead of bare value |
| `multi` | `bool` | `false` | Enables multi-select; returns comma-joined values |
| `clearable` | `bool` | `false` | Allows clearing the selection |
| `iconName` | `string` | `""` | Renders a styled icon alongside the selected value |
| `tooltip` | `string` | `""` | Tooltip shown on the label |
| `disabled` | `bool` | `false` | Disables interaction and removes keyboard focus |

## Usage Example

```javascript
import Dropdown from "components/forms/fields/Dropdown";

<Dropdown
  label="Platform"
  name="platform"
  options={[
    { label: "macOS", value: "darwin" },
    { label: "Windows", value: "windows" },
    { label: "Linux", value: "linux" },
  ]}
  value={selectedPlatform}
  onChange={(val) => setSelectedPlatform(val)}
  error={formErrors.platform}
  helpText="Select the target OS platform."
/>
```

For icon-decorated dropdowns, pass `iconName` matching an available `Icon` name. For form submission contexts requiring field identification, use `parseTarget` to receive `{ value, name }` in the `onChange` callback.
