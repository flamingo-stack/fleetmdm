Storybook stories file for the `AutoSizeInputField` component, providing interactive documentation and visual testing within the Storybook UI.

## Key Components

- **Default export (Meta)** — Registers the component under `Components/FormFields/Input/AutoSizeInputField` in the Storybook sidebar with sensible default args
- **Template** — A generic `StoryFn` wrapper that spreads all props onto `AutoSizeInputField`
- **Default** — The primary story showcasing the component with its default configuration

## Default Args

| Prop | Default Value |
|---|---|
| `autofocus` | `false` |
| `disabled` | `false` |
| `isFocused` | `false` |
| `placeholder` | `"Type here..."` |
| `maxLength` | `250` |
| `onFocus` / `onChange` / `onKeyPress` | `noop` |
| `error`, `name`, `type`, `value` | `""` |

## Usage Example

```typescript
// Extend with additional stories for specific states
export const WithError = Template.bind({});
WithError.args = {
  value: "Invalid input",
  error: "This field is required",
};

export const Disabled = Template.bind({});
Disabled.args = {
  disabled: true,
  value: "Cannot edit",
};
```
