A React textarea component that automatically sizes itself to fit its content, used for inline editable fields with keyboard and focus management.

## Key Components

**`IAutoSizeInputFieldProps`** — Interface defining component props:
- `name` / `placeholder` / `value` — Standard input attributes
- `maxLength` — Character limit for the textarea
- `hasError` / `isDisabled` / `isFocused` — State modifiers that apply CSS class variants
- `disableTabability` — Sets `tabIndex={-1}` to remove the field from tab order
- `onFocus` / `onBlur` / `onChange` / `onKeyPress` — Event callbacks

**`AutoSizeInputField`** — Default export. Renders a `<textarea>` wrapped in a `<label>` with a CSS `input-sizer` class, enabling content-driven auto-sizing via the `data-value` attribute on the label (typically paired with a CSS `::after` pseudo-element trick).

**Focus management** — A `useEffect` hook watches `isFocused` and programmatically focuses the textarea, placing the cursor at the end of the existing value.

## Usage Example

```typescript
import AutoSizeInputField from "./AutoSizeInputField";

<AutoSizeInputField
  name="tag-input"
  placeholder="Add tag..."
  value={tagValue}
  maxLength={50}
  hasError={!!validationError}
  isFocused={isActiveField}
  onChange={(val) => setTagValue(val)}
  onKeyPress={(e) => {
    if (e.key === "Enter") handleSubmit();
  }}
  onBlur={() => setIsActiveField(false)}
  disableTabability={false}
/>
```
