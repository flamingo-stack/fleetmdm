Test suite for the `InputFieldWithIcon` React component, validating rendering behavior, user interactions, accessibility attributes, and prop-driven state changes.

## Key Components

- **`describe("InputFieldWithIcon Component")`** — Top-level test suite grouping all behavioral tests
- **`mockOnChange`** — Shared Jest mock function reset before each test via `beforeEach`
- **`renderWithSetup`** — Custom test utility from `test/test-utils` used for tests requiring pointer event simulation (e.g., tooltip hover)

## Test Coverage

| Test | Behavior Verified |
|---|---|
| Label & placeholder rendering | Basic mount output |
| `onChange` on typing | Called once per character (9x for "New Value") |
| `helpText` prop | Help text rendered in DOM |
| `error` prop | Error message rendered in DOM |
| `clearButton` with value | Clear button appears; calls `onChange("")` on click |
| `clearButton` without value | Clear button not rendered |
| `tooltip` prop | Tooltip text shown on hover |
| `iconSvg` prop | Icon rendered via `data-testid` |
| `disabled` prop | Input disabled; `onChange` never called |
| `autofocus` prop | Input receives focus on mount |
| `onClick` prop | Callback fired on input click |
| `data-1p-ignore` attribute | Set `true` by default; omitted when `ignore1Password={false}` |
| `type="password"` | Correct `type` attribute and CSS class applied |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import userEvent from "@testing-library/user-event";
import InputFieldWithIcon from "./InputFieldWithIcon";

test("clears input on button click", async () => {
  const onChange = jest.fn();
  render(
    <InputFieldWithIcon
      value="existing text"
      onChange={onChange}
      label="Search"
      placeholder="Search..."
      name="search"
      clearButton
    />
  );

  await userEvent.click(screen.getByRole("button"));
  expect(onChange).toHaveBeenCalledWith("");
});
```
