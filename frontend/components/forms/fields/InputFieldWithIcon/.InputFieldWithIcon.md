A reusable form input component that renders a text field with optional icon, label, tooltip, error state, help text, and clear button.

## Key Components

**`IInputFieldWithIconProps`** — Interface defining all configurable props:
- `iconSvg` — Icon name from `ICON_MAP` rendered inside the input field
- `error` — Displays error styling and replaces the label with error text
- `tooltip` — Wraps the label in a `TooltipWrapper` when no error is present
- `clearButton` — Renders an `×` button to reset the input value to `""`
- `helpText` — Renders supplementary text below the input
- `ignore1Password` — Controls `data-1p-ignore` attribute (defaults to `true`)
- `autofocus` — Programmatically focuses the input on mount via `useRef`

**`InputFieldWithIcon`** — Default export; the main component handling:
- Autofocus via `useEffect` + `useRef`
- Memoized `onChange` handler via `useCallback`
- Dynamic CSS class composition via `classnames`

## Usage Example

```typescript
import InputFieldWithIcon from "components/InputFieldWithIcon/InputFieldWithIcon";

// Basic search input with icon and clear button
<InputFieldWithIcon
  label="Search devices"
  name="device-search"
  iconSvg="search"
  placeholder="Hostname, UUID, serial..."
  value={searchQuery}
  onChange={(val) => setSearchQuery(val)}
  clearButton
  helpText="Search across all enrolled devices."
/>

// Password field with tooltip and error state
<InputFieldWithIcon
  label="API token"
  name="api-token"
  type="password"
  tooltip="Your Fleet API token from Account Settings."
  error={formErrors.apiToken}
  value={token}
  onChange={(val) => setToken(val)}
  ignore1Password={false}
/>
```
