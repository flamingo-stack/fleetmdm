Storybook stories for the `InputFieldWithIcon` component, defining interactive documentation and visual test cases across its key prop variations.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `meta` | `Meta` | Storybook metadata config with `argTypes` for interactive controls |
| `Default` | `Story` | Base email input story |
| `PasswordInput` | `Story` | Password type input variant |
| `WithError` | `Story` | Input with inline validation error |
| `WithHelpText` | `Story` | Input with descriptive helper text |
| `Disabled` | `Story` | Disabled/read-only state |
| `WithTooltip` | `Story` | Input with tooltip hint |
| `WithClearButton` | `Story` | Input with pre-filled value and clear action |
| `CustomIcon` | `Story` | Search input with custom SVG icon |

## Usage Example

```typescript
// Render the Default story in isolation
import { Default } from "./InputFieldWithIcon.stories";

<Default.args.onChange /> // wired to Storybook action logger

// Compose a new story from existing args
export const SearchWithError: Story = {
  args: {
    ...Default.args,
    ...CustomIcon.args,
    error: "No results found",
  },
};
```

## Controlled Props (via Storybook Controls)

| Prop | Control | Options |
|------|---------|---------|
| `type` | select | `text`, `password`, `email`, `number` |
| `iconSvg` | select | `search`, `filter` |
| `disabled` | boolean | — |
| `value`, `error`, `helpText`, `tooltip` | text | — |
