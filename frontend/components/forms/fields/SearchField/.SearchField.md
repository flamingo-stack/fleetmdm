A debounced search input component that wraps `InputFieldWithIcon` with optional tooltip support, delaying `onChange` callbacks by 500ms to reduce unnecessary API calls.

## Key Components

### `ISearchFieldProps`
| Prop | Type | Description |
|------|------|-------------|
| `placeholder` | `string` | Input placeholder text |
| `defaultValue` | `string` | Initial input value (default: `""`) |
| `onChange` | `(value: string) => void` | Debounced change handler (500ms delay) |
| `onClick` | `(e: React.MouseEvent) => void` | Optional click handler |
| `clearButton` | `boolean` | Show a clear/reset button |
| `icon` | `IconNames` | Icon name (default: `"search"`) |
| `tooltip` | `React.ReactNode` | Optional tooltip content |
| `disabled` | `boolean` | Disables the input |

### `SearchField` (default export)
Maintains local input state and fires the debounced `onChange` on every keystroke, keeping the UI responsive while throttling upstream handlers.

## Usage Example

```typescript
import SearchField from "components/forms/fields/SearchField";

const HostsTable = () => {
  const handleSearch = (query: string) => {
    // Called 500ms after the user stops typing
    fetchHosts({ query });
  };

  return (
    <SearchField
      placeholder="Search hosts..."
      defaultValue=""
      onChange={handleSearch}
      clearButton
      tooltip={<span>Search by hostname or IP</span>}
    />
  );
};
```

## Notes

- The 500ms debounce is hardcoded; if your use case requires a different delay, the value must be changed in the source.
- Tooltip rendering is suppressed when `tooltip` is `undefined`/`null` via the `disableTooltip` prop on `TooltipWrapper`.
