A reusable controlled radio button component that supports tooltips, help text, and disabled states.

## Key Components

### `IRadioProps`
| Prop | Type | Description |
|------|------|-------------|
| `label` | `ReactNode` | Visible label for the radio button |
| `value` | `string` | Value emitted on selection |
| `id` | `string` | Unique element ID for label association |
| `onChange` | `(value: string) => void` | Callback with the selected value |
| `name` | `string` | Groups radio buttons for keyboard navigation |
| `checked` | `boolean` | Controlled checked state |
| `disabled` | `boolean` | Disables interaction and applies styling |
| `tooltip` | `ReactNode` | Wraps label in a `TooltipWrapper` when provided |
| `helpText` | `ReactNode` | Secondary descriptive text rendered below the label |
| `testId` | `string` | `data-testid` attribute for testing |

### `Radio`
Default export. Renders a styled radio input with optional tooltip and help text. Uses `classnames` to conditionally apply a `radio__disabled` modifier class.

## Usage Example

```typescript
import Radio from "components/Radio";

// Basic usage
<Radio
  id="opt-basic"
  name="options"
  label="Option A"
  value="a"
  checked={selected === "a"}
  onChange={(val) => setSelected(val)}
/>

// With tooltip and help text
<Radio
  id="opt-advanced"
  name="options"
  label="Option B"
  value="b"
  checked={selected === "b"}
  onChange={(val) => setSelected(val)}
  tooltip={<span>Additional context about this option</span>}
  helpText="This option enables advanced features"
  disabled={false}
  testId="radio-option-b"
/>
```
