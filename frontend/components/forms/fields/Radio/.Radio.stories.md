Storybook stories for the `Radio` component, providing visual documentation and interactive playground for the radio input field.

## Key Components

- **`meta`** – Storybook metadata configuration defining the component, title path (`Components/FormFields/Radio`), and default args
- **`Default`** – Base story rendering a checked, enabled radio button with a label

## Usage Example

```typescript
import { Radio } from "components/Radio";

<Radio
  checked={true}
  disabled={false}
  label="Selected radio"
  value="option1"
  id="radio-1"
  name="radio-group"
  onChange={(e) => console.log(e.target.value)}
/>
```

## Default Args

| Prop | Default |
|------|---------|
| `checked` | `true` |
| `disabled` | `false` |
| `label` | `"Selected radio"` |
| `value` | `""` |
| `onChange` | `noop` |
