A wrapper component built on react-select 5.4 that provides a standardized, styled dropdown with support for custom option rendering, tooltips, help text, icons, and multiple visual variants.

## Key Components

### Exports

| Export | Type | Description |
|--------|------|-------------|
| `DropdownWrapper` | Component | Main dropdown component (default export) |
| `CustomDropdownIndicator` | Component | Custom chevron indicator with focus/open state color handling |
| `generateCustomDropdownStyles` | Function | Generates `StylesConfig` for consistent styling across dropdown variants |
| `CustomOptionType` | Interface | Shape of each dropdown option |
| `IDropdownWrapper` | Interface | Props interface for the wrapper component |

### `CustomOptionType` Fields

| Field | Type | Description |
|-------|------|-------------|
| `label` | `React.ReactNode` | Display text/element |
| `value` | `string` | Unique identifier |
| `tooltipContent` | `TooltipContent?` | Optional tooltip on hover |
| `helpText` | `React.ReactNode?` | Secondary descriptive text |
| `isDisabled` | `boolean?` | Disables the option |
| `iconName` | `IconNames?` | Optional icon |

### Variants

- **`table-filter`** — Includes filter icon, 40px height
- **`button`** — Hover/active states, button-like padding, no selected-option styling

## Usage Example

```typescript
import DropdownWrapper, {
  CustomOptionType,
} from "components/forms/fields/Dropdown/DropdownWrapper";

const options: CustomOptionType[] = [
  { label: "All platforms", value: "all" },
  { label: "macOS", value: "darwin", helpText: "Apple devices" },
  { label: "Windows", value: "windows", isDisabled: true },
];

const MyFilter = () => {
  const [selected, setSelected] = useState<CustomOptionType | null>(null);

  return (
    <DropdownWrapper
      name="platform-filter"
      label="Platform"
      options={options}
      value={selected}
      onChange={(newValue) => setSelected(newValue)}
      variant="table-filter"
      placeholder="Select platform"
      helpText="Filter hosts by OS"
    />
  );
};
```

## Notes

- Replaces the legacy `Dropdown.jsx` (react-select 1.3)
- `generateCustomDropdownStyles` is exported for use in derived dropdown components requiring style consistency
- The `button` variant intentionally ignores `isFocused` for highlight styling to avoid persistent highlight after menu close (see [#45853](https://github.com/flamingo-stack/fleetmdm/issues/45853))
- `value` accepts both `PropsValue<CustomOptionType>` and raw `string` for convenience
