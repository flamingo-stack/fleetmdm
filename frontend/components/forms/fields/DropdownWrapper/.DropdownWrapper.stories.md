Storybook stories file for the `DropdownWrapper` component, providing interactive UI documentation and visual test cases across multiple dropdown states.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `meta` | `Meta<DropdownWrapper>` | Storybook metadata defining component title, argTypes, and a padding decorator for tooltip visibility |
| `Default` | `Story` | Base story with sample options including help text, tooltips, and disabled states |
| `Disabled` | `Story` | Full dropdown in a globally disabled state |
| `WithHelpText` | `Story` | Dropdown with supplementary help text rendered below |
| `WithError` | `Story` | Dropdown displaying an inline error message |
| `sampleOptions` | `CustomOptionType[]` | Shared fixture data covering all option variants |

## Usage Example

```typescript
// Run in Storybook to preview all variants
// Navigate to: Components / DropdownWrapper

// Sample options cover four CustomOptionType configurations:
const sampleOptions: CustomOptionType[] = [
  { label: "Help text only",            value: "opt1", helpText: "..." },
  { label: "Tooltip only",              value: "opt2", tooltipContent: "..." },
  { label: "Disabled only",             value: "opt3", isDisabled: true },
  { label: "All features combined",     value: "opt4",
    helpText: "...", isDisabled: true,  tooltipContent: "..." },
];
```

> The decorator wraps every story in a `150px`-padded container so tooltip overflow remains visible in the Storybook canvas.
