A reusable React component that wraps `InputField` to display sensitive/secret values with built-in show/hide toggle and copy-to-clipboard functionality.

## Key Components

- **`InputFieldHiddenContent`** — Default export. A read-only password-type input field pre-configured with `enableShowSecret` and `enableCopy` props.
- **`IInputFieldHiddenContentProps`** — Interface defining the component's props:
  - `value` *(required)* — The sensitive string to display.
  - `name` *(optional)* — Input field name attribute.
  - `className` *(optional)* — Additional CSS class(es) for the wrapper `div`.
  - `helpText` *(optional)* — Helper text displayed below the input, accepts a string or JSX element.

## Usage Example

```typescript
import InputFieldHiddenContent from "components/forms/fields/InputFieldHiddenContent";

// Display an API key with show/hide and copy controls
const ApiKeyDisplay = () => (
  <InputFieldHiddenContent
    name="api-key"
    value="sk_live_abcdefghijklmnopqrstuvwxyz123456"
    helpText="Keep this key secret. Do not share it publicly."
  />
);
```

## Notes

- The input is always `readOnly` — users cannot edit the value directly.
- The default `type="password"` masks the value until the show/hide toggle is activated via `enableShowSecret`.
- The `enableCopy` prop renders a copy button, making it straightforward to copy secrets without revealing them on screen.
- Styling is scoped under the `input-field-hidden-content` BEM base class, with the inner input wrapped in `input-field-hidden-content__secret-input`.
