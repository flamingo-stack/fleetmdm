Unit tests for the `Checkbox` component, verifying rendering, change handler behavior, and disabled state functionality.

## Key Components

- **`renders`** — Confirms the `Checkbox` component mounts without returning a null container.
- **`onChange` handler test** — Validates that clicking a checked checkbox calls `onChange` with `false`, and clicking an unchecked checkbox calls `onChange` with `true` (toggle behavior).
- **`disabled` prop test** — Ensures the checkbox input is inaccessible when the `disabled` prop is set.

## Usage Example

```typescript
// Typical Checkbox usage patterns covered by these tests

// Basic render
<Checkbox />

// Controlled with onChange handler
<Checkbox
  name="checkbox"
  value={true}
  onChange={(newValue) => console.log(newValue)} // called with false on click
/>

// Disabled state
<Checkbox name="test" value={false} disabled>
  Test checkbox
</Checkbox>
```

## Test Coverage

| Scenario | Assertion |
|---|---|
| Basic render | Container is not null |
| Click checked checkbox | `onChange` called with `false` |
| Click unchecked checkbox | `onChange` called with `true` |
| `disabled` prop | Input is disabled in the DOM |

## Notes

- Uses `@testing-library/react` (`fireEvent`, `render`, `screen`) for DOM interaction and queries.
- The `onChange` toggle tests use `rerender` to switch between checked/unchecked states within the same test, verifying both directions of the toggle.
- The disabled test queries by label text, implying `Checkbox` renders an associated `<label>` element.
