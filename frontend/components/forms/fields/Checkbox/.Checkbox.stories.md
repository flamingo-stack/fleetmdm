Storybook stories for the `Checkbox` component, defining visual documentation and interactive examples for the Fleet design system.

## Key Components

- **`meta`** – Storybook metadata registering the component under `Components/FormFields/Checkbox`
- **`Basic`** – Minimal checkbox story with a Figma design spec link for reference
- **`WithLabel`** – Checkbox story demonstrating bold label content via the `children` prop

## Usage Example

```typescript
// Render a checkbox with a label in your stories or tests
import Checkbox from ".";

<Checkbox>
  <b>Label</b>
</Checkbox>
```
