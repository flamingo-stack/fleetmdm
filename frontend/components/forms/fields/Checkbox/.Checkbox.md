A fully accessible, custom-styled checkbox component that supports indeterminate state, tooltips, keyboard navigation, and both direct and parse-target onChange patterns.

## Key Components

### Props (`ICheckboxProps`)
Union type of two variants:
- **`ICheckboxParseTargetProps`** — when `parseTarget: true`, `onChange` receives `{ name, value: boolean }`
- **`ICheckboxDirectProps`** — when `parseTarget` is false/unset, `onChange` receives a `boolean` directly

Key props:
| Prop | Type | Description |
|---|---|---|
| `value` | `boolean \| null` | Controlled checked state |
| `indeterminate` | `boolean` | Renders a mixed/partial state icon |
| `readOnly` | `boolean` | Non-editable, visually distinct |
| `disabled` | `boolean` | Greyed out, non-interactive |
| `labelTooltipContent` | `ReactNode` | Tooltip over the label text |
| `iconTooltipContent` | `ReactNode` | Tooltip over the checkbox icon |
| `enableEnterToCheck` | `boolean` | Allows Enter key to toggle (table use only) |
| `isLeftLabel` | `boolean` | Positions label to the left of the icon |

## Usage Example

```typescript
// Direct boolean onChange
<Checkbox
  name="agree_terms"
  value={agreed}
  onChange={(checked) => setAgreed(checked)}
>
  I agree to the terms
</Checkbox>

// With parseTarget for shared form handlers
<Checkbox
  name="send_alerts"
  value={formValues.send_alerts}
  parseTarget
  onChange={({ name, value }) => setFormValues({ ...formValues, [name]: value })}
  labelTooltipContent={<span>Sends email notifications</span>}
>
  Enable alerts
</Checkbox>

// Indeterminate state (e.g. select-all in a table)
<Checkbox
  name="select_all"
  value={false}
  indeterminate={someSelected}
  onChange={handleSelectAll}
  enableEnterToCheck
/>
```

> **Note:** The underlying `<input type="checkbox">` is hidden; interaction is handled via a custom `div` with full ARIA attributes (`role="checkbox"`, `aria-checked`, `aria-readonly`, `aria-disabled`) and keyboard support (Space always, Enter optionally).
