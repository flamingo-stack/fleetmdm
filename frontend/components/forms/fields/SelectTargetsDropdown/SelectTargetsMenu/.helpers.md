Provides a utility function for filtering host targets by type in the Fleet MDM targeting system.

## Key Components

- **`targetFilter(targetType)`** — Returns a filter value or predicate function based on the specified target type:
  - `"all"` → returns a static `{ name: "All Hosts" }` object
  - `"labels"` or `"teams"` → returns a predicate function that matches options by `target_type`, excluding `"All Hosts"`
  - Any other value → returns a static `{ target_type: targetType }` object

## Usage Example

```javascript
import { targetFilter } from "./helpers";

// Get filter for "all hosts"
const allFilter = targetFilter("all");
// → { name: "All Hosts" }

// Get a predicate for filtering label targets
const labelFilter = targetFilter("labels");
const options = [
  { target_type: "labels", name: "macOS Devices" },
  { target_type: "labels", name: "All Hosts" },
  { target_type: "teams", name: "Engineering" },
];
const filtered = options.filter(labelFilter);
// → [{ target_type: "labels", name: "macOS Devices" }]

// Get filter for a specific target type
const teamFilter = targetFilter("teams");
// → { target_type: "teams" }
```

## Notes

- When `targetType` is `"labels"` or `"teams"`, the returned predicate explicitly excludes `"All Hosts"` to avoid duplication with the `"all"` target type.
- The mixed return type (object vs. function) is designed to integrate with a filtering/selection API that accepts either a static matcher or a dynamic predicate.
