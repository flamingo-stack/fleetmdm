A higher-order function that wraps and returns a `SelectTargetsMenu` React component for rendering a dropdown menu of selectable Fleet MDM targets (hosts, labels, and fleets), grouped by type with detail panel support.

## Key Components

- **`SelectTargetsMenuWrapper`** — Outer factory function accepting `onMoreInfoClick`, `moreInfoTarget`, `handleBackToResults`, and `isPremiumTier` as closure parameters, returning the inner `SelectTargetsMenu` component
- **`SelectTargetsMenu`** — Inner component rendering grouped target options with focus/selection state management
- **`renderTargets(targetType)`** — Renders a labeled group of targets filtered by type (`"all"`, `"fleets"`, `"labels"`, `"hosts"`), with a "not found" fallback per group
- **`hasHostTargets()`** — Guard that checks whether any options have a non-zero `count`, showing an `EmptyState` if none exist
- **`renderTargetGroups`** — Composes all target type sections; `"fleets"` is gated behind `isPremiumTier`

## Usage Example

```javascript
import SelectTargetsMenuWrapper from "components/SelectTargetsMenu";

const SelectTargetsMenu = SelectTargetsMenuWrapper(
  (target) => setMoreInfoTarget(target),  // onMoreInfoClick
  moreInfoTarget,                          // currently shown detail target
  () => setMoreInfoTarget(null),           // handleBackToResults
  isPremiumTier                            // show fleets section
);

// Pass as menuRenderer to a react-select component
<Select
  menuRenderer={(props) => <SelectTargetsMenu {...props} />}
  options={targets}
  valueKey="id"
/>
```

## Notes

- `onSelect` on each `Option` is intentionally set to `noop` — actual selection is delegated to the `TargetOption` child component
- The right-hand `__option-details` panel always mounts, rendering `TargetDetails` for whatever `moreInfoTarget` is passed via closure
