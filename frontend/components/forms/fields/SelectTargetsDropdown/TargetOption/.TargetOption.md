A React component that renders a single selectable target option (host, label, or team) within a target selection dropdown, displaying contextual details and an add button.

## Key Components

- **`TargetOption`** — Main functional component accepting three props:
  - `target` — An `ISelectTargetsEntity` object representing a host, label, or team
  - `onSelect` — Callback fired when the add (`+`) button is clicked
  - `onMoreInfoClick` — Callback fired when the target content area is clicked (typically opens a detail panel)
- **`renderTargetDetail()`** — Internal render helper that conditionally displays:
  - Primary IP address for host targets
  - Host count for team or label targets
- **Dynamic CSS classes** — Applies `is-team`, `is-label`, or `is-host` modifier classes to the wrapper based on `target_type`

## Usage Example

```typescript
import TargetOption from "./TargetOption";

<TargetOption
  target={{
    display_text: "Engineering",
    target_type: "teams",
    count: 42,
  }}
  onSelect={(target, evt) => {
    console.log("Selected:", target.display_text);
  }}
  onMoreInfoClick={(target) => (evt) => {
    openDetailPanel(target);
  }}
/>
```

## Notes

- The component normalizes `"All Hosts"` → `"All hosts"` for display consistency
- Relies on type-guard helpers (`isTargetHost`, `isTargetLabel`, `isTargetTeam`) from the parent `helpers` module
