Test suite for the `TargetOption` component, verifying rendering behavior and user interaction callbacks for both label and host target types.

## Key Components

- **`renders a label option for label targets`** — Asserts the `.is-label` CSS class is applied and host count is displayed when a label target is provided.
- **`renders a host option for host targets`** — Asserts the `.is-host` CSS class, platform icon (`fleeticon-windows`), and primary IP are rendered for a host target.
- **`calls the onSelect prop when + icon button is clicked`** — Verifies the `onSelect` callback fires when the `.target-option__add-btn` button is clicked.
- **`calls the onMoreInfoClick prop when the item content is clicked`** — Verifies the `onMoreInfoClick` callback fires when `.target-option__target-content` is clicked.

## Usage Example

```typescript
// Running the test suite
// npx jest TargetOption.tests.tsx

render(
  <TargetOption
    onSelect={onSelectSpy}
    onMoreInfoClick={onMoreInfoClick}
    target={createMockHost({ target_type: "hosts", platform: "windows" })}
  />
);

// Assert host-specific rendering
expect(container.querySelectorAll(".is-host").length).toEqual(1);
expect(container.querySelectorAll("i.fleeticon-windows").length).toEqual(1);
```

## Notes

- Uses `createMockLabel` and `createMockHost` from the shared mock factories in `__mocks__/`.
- `onMoreInfoClick` is a **factory function** — it returns the spy rather than being the spy directly, matching the component's expected prop signature.
