Renders a platform/status-aware icon for a Fleet target entity (label or host) using the `FleetIcon` component.

## Key Components

- **`TargetIcon`** — Default export. Accepts a single `target` prop of type `ISelectTargetsEntity` and returns the appropriate `FleetIcon` based on target type and platform.
- **`iconName()`** — Internal helper that resolves the icon name string:
  - Labels → `"all-hosts"` or `"label"`
  - Linux-like hosts → `"linux"`
  - macOS hosts → `"apple"`
  - Other hosts → raw `target.platform` value
- **`targetClasses`** — Applies a status-based CSS modifier (e.g., `target-option__icon--online`) when the target is a host.

## Usage Example

```typescript
import TargetIcon from "components/target_picker/TargetIcon";
import { ISelectTargetsEntity } from "interfaces/target";

const myHost: ISelectTargetsEntity = {
  id: 1,
  platform: "darwin",
  status: "online",
  // ...other fields
};

const myLabel: ISelectTargetsEntity = {
  id: 2,
  name: "All Hosts",
  // ...other fields
};

// Renders an Apple icon with an "online" status class
<TargetIcon target={myHost} />

// Renders an "all-hosts" icon
<TargetIcon target={myLabel} />
```
