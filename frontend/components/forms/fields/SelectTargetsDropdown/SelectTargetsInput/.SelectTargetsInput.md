A multi-select input component for choosing Fleet query targets (labels, hosts, IP addresses) built on `react-select`, with UUID-keyed deduplication and debounced search input.

## Key Components

- **`SelectTargetsInput`** — Class component wrapping `react-select`'s `Select` with target-specific logic:
  - **UUID keying** — Assigns `uniqueId()` to each target on prop updates to ensure correct selection/deselection behavior (workaround for non-unique target IDs, see [#4905](https://github.com/flamingo-stack/fleetmdm/issues/4905))
  - **`filterOptions`** — Excludes already-selected targets from the dropdown options using lodash `difference`
  - **`handleInputChange`** — Debounced (trailing-edge) handler that delegates search queries to `onTargetSelectInputChange`
  - **`componentDidUpdate`** — Syncs `uuidTargets` and `uuidSelectedTargets` state when `targets` or `selectedTargets` props change

## Props

| Prop | Type | Description |
|------|------|-------------|
| `targets` | `targetInterface[]` | Available targets to display |
| `selectedTargets` | `targetInterface[]` | Currently selected targets |
| `onTargetSelect` | `func` | Called when a target is added/removed |
| `onTargetSelectInputChange` | `func` | Called (debounced) on search input change |
| `menuRenderer` | `func` | Custom dropdown menu renderer |
| `isLoading` | `bool` | Shows loading state in dropdown |

## Usage Example

```javascript
import SelectTargetsInput from "components/SelectTargetsInput";

<SelectTargetsInput
  targets={availableTargets}
  selectedTargets={selectedTargets}
  isLoading={isLoadingTargets}
  onTargetSelect={(targets) => setSelectedTargets(targets)}
  onTargetSelectInputChange={(query) => fetchTargets(query)}
  menuRenderer={(props) => <CustomMenu {...props} />}
/>
```
