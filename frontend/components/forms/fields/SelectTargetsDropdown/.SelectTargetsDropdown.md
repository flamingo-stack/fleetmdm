A React class component that renders a searchable dropdown for selecting Fleet query targets (hosts, labels, or teams), handling async target fetching, loading states, and "more info" target previews.

## Key Components

- **`SelectTargetsDropdown`** — Main class component managing target search state and rendering the composed input/menu UI
- **`fetchTargets`** — Calls `targetsAPI.DEPRECATED_loadAll` with query string, query ID, and currently selected targets; updates `targets` state and notifies parent via `onFetchTargets`
- **`onTargetSelectMoreInfo`** — Returns an event handler that sets `moreInfoTarget` state to display an expanded info panel for a given target
- **`renderLabel`** — Renders an optional label with error state and a dynamic unique host count
- **`ArrowRenderer`** / **`ClearRenderer`** — Inline render components for the dropdown chevron and clear button
- **`menuRenderer`** — Composed from the `Menu` sub-component, forwarding more-info and back-navigation callbacks

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `onSelect` | `func` | ✅ | Called when a target is selected/removed |
| `selectedTargets` | `arrayOf(targetInterface)` | — | Currently selected targets |
| `onFetchTargets` | `func` | — | Callback with query and full API response |
| `targetsCount` | `number` | — | Unique host count shown in label |
| `queryId` | `number` | — | Scopes target results to a saved query |
| `isPremiumTier` | `bool` | — | Enables premium-tier target options in the menu |
| `disabled` | `bool` | — | Disables the input |
| `error` | `string` | — | Replaces label text with an error message |

## Usage Example

```javascript
import SelectTargetsDropdown from "components/SelectTargetsDropdown";

<SelectTargetsDropdown
  label="Select targets"
  selectedTargets={selectedTargets}
  targetsCount={targetsCount}
  queryId={42}
  isPremiumTier={true}
  onSelect={(newTargets) => setSelectedTargets(newTargets)}
  onFetchTargets={(query, response) => {
    setTargetsCount(response.targets_count);
  }}
/>
```

> **Note:** `fetchTargets` internally calls `targetsAPI.DEPRECATED_loadAll` — this API method is marked for replacement. The component also uses legacy lifecycle methods (`componentWillMount`, `componentWillReceiveProps`) and should be migrated to a functional component with hooks when refactoring.
