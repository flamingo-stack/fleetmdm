A React component that renders detailed information for a selected query target — host, label, or team — within the Fleet MDM target selection UI.

## Key Components

### `TargetDetails`

The default export. Accepts a polymorphic `target` prop and delegates rendering to one of three internal renderers based on type guards.

**Props (`ITargetDetailsProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `target` | `ISelectHost \| ISelectTeam \| ISelectLabel` | The selected target to display |
| `className` | `string` | Optional additional CSS class |
| `handleBackToResults` | `() => void` | Callback for the "Back" button (defaults to `noop`) |

### Internal Renderers

| Function | Target Type | Displays |
|----------|-------------|----------|
| `renderHost` | `ISelectHost` | IP, MAC, platform (with OS icon), OS version, osquery version, memory, online/offline status |
| `renderLabel` | `ISelectLabel` | Host count, description, read-only SQL query editor |
| `renderTeam` | `ISelectTeam` | Display name, host count |

## Usage Example

```typescript
import TargetDetails from "components/TargetDetails";
import { ISelectHost } from "interfaces/target";

const myHost: ISelectHost = {
  display_text: "web-server-01",
  status: "online",
  primary_ip: "10.0.1.42",
  primary_mac: "aa:bb:cc:dd:ee:ff",
  platform: "ubuntu",
  os_version: "Ubuntu 22.04",
  osquery_version: "5.9.1",
  memory: 8589934592,
};

<TargetDetails
  target={myHost}
  handleBackToResults={() => setSelectedTarget(null)}
/>;
```
