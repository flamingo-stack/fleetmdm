Type guard utilities for narrowing `ISelectTargetsEntity` union types to their specific host, label, or team variants.

## Key Components

- **`isTargetHost`** — Returns `true` and narrows type to `ISelectHost` when `target_type === "hosts"`
- **`isTargetLabel`** — Returns `true` and narrows type to `ISelectLabel` when `target_type === "labels"`
- **`isTargetTeam`** — Returns `true` and narrows type to `ISelectTeam` when `target_type === "teams"`

## Usage Example

```typescript
import { isTargetHost, isTargetLabel, isTargetTeam } from "./helpers";

targets.forEach((target) => {
  if (isTargetHost(target)) {
    // target is ISelectHost
    console.log(target.hostname);
  } else if (isTargetLabel(target)) {
    // target is ISelectLabel
    console.log(target.label_type);
  } else if (isTargetTeam(target)) {
    // target is ISelectTeam
    console.log(target.team_id);
  }
});
```

## Notes

These guards rely on the `target_type` discriminant field and are intended for use wherever an `ISelectTargetsEntity` union needs to be safely narrowed before accessing type-specific properties.
