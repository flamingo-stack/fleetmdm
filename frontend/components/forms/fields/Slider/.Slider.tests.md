Test suite for the `Slider` component, verifying rendering in default/active states and click interaction behavior.

## Key Components

- **`renders correctly with default props`** — Asserts inactive text (`"Off"`) is visible and the switch element carries the `fleet-slider` CSS class
- **`renders active state correctly`** — Asserts active text (`"On"`) is visible and the switch carries the `fleet-slider--active` CSS class when `value={true}`
- **`calls onChange when clicked`** — Fires a click event on the switch and confirms the `onChange` callback is invoked exactly once

## Usage Example

```typescript
// Run the full test suite
npx jest Slider.tests.tsx

// Example defaultProps shape used across tests
const defaultProps = {
  onChange: jest.fn(),
  value: false,
  inactiveText: "Off",
  activeText: "On",
};

// Simulating an active slider state in a test
render(<Slider {...defaultProps} value />);
expect(screen.getByRole("switch")).toHaveClass("fleet-slider--active");
```

## Dependencies

| Dependency | Purpose |
|---|---|
| `@testing-library/react` | `render`, `fireEvent`, `screen` utilities |
| `jest` | Test runner and mock functions |
| `./Slider` | Component under test |

## Notes

- The `switch` ARIA role is expected on the root element — ensure the `Slider` component sets `role="switch"` for these tests to pass
- `onChange` mock is defined once in `defaultProps` and shared across tests; consider calling `jest.clearAllMocks()` in `beforeEach` if the call count check becomes flaky across test ordering
