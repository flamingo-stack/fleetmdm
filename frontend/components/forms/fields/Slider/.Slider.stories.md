Storybook stories for the `Slider` component, providing interactive UI development and visual testing via the `Components/FormFields/Slider` story path.

## Key Components

- **`meta`** — Storybook metadata configuration defining default args (`value`, `inactiveText`, `activeText`, `onChange`) for the `Slider` component
- **`Default`** — Baseline story rendering the `Slider` with its default props (off state, "Off"/"On" labels)

## Usage Example

```typescript
import { Default } from "./Slider.stories";

// Render the default Slider story
<Default />

// Customize args via Storybook controls
const CustomSlider: Story = {
  args: {
    value: true,
    inactiveText: "Disabled",
    activeText: "Enabled",
  },
};
```

## Notes

- Located under `Components/FormFields/Slider` in the Storybook component hierarchy
- Uses `noop` from `lodash` as a no-op `onChange` handler for static story previews
- Imports global styles from `index.scss`
- See the source at [`Slider.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/FormFields/Slider/Slider.stories.tsx)
