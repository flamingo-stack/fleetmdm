A boolean toggle slider component that renders an accessible switch control with active/inactive label states, optional tooltip support, and form field integration.

## Key Components

- **`Slider`** — Default export; a controlled toggle switch component
- **`ISliderProps`** — Interface defining the component's props
- **`FormField`** — Wrapper providing label, helpText, and error display
- **`TooltipWrapper`** — Conditionally wraps the label when `labelTooltip` is provided

## Usage Example

```typescript
import Slider from "components/forms/fields/Slider";

<Slider
  value={isEnabled}
  onChange={() => setIsEnabled(!isEnabled)}
  activeText="Enabled"
  inactiveText="Disabled"
  helpText="Toggle this feature on or off."
  labelTooltip="This setting affects all users."
  disabled={false}
  autoFocus
/>
```

## Key Behaviors

- Renders a `<button role="switch">` with `aria-checked` for accessibility
- Displays `activeText` when `value` is `true`, `inactiveText` when `false`
- `autoFocus` prop programmatically focuses the button via `useRef` on mount
- Click events are suppressed when `disabled` is `true`
- `labelTooltip` wraps the visible label in a `TooltipWrapper` and is compatible with the disabled state
- CSS classes (`--active`, `--disabled`) are dynamically applied via `classnames`
