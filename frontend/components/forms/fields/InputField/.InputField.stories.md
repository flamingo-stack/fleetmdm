Storybook stories for the `InputField` component, defining interactive visual examples for all supported variants and states.

## Key Components

| Export | Description |
|---|---|
| `meta` | Storybook metadata configuring the component under `Components/FormFields/Input` with controls for `type`, `autofocus`, `readOnly`, `disabled`, `blockAutoComplete`, `enableCopy`, `enableShowSecret`, and `labelTooltipPosition` |
| `Default` | Base story with empty value, placeholder, and action handlers |
| `WithValue` | Input pre-populated with sample text |
| `WithError` | Input displaying an inline validation error message |
| `WithHelpText` | Input with descriptive help text below |
| `WithTooltip` | Input with a label tooltip positioned to the right |
| `Password` | Input using `type="password"` |
| `ReadOnly` | Non-editable input with `readOnly: true` |
| `Disabled` | Fully disabled input state |
| `WithCopyButton` | Input with `enableCopy` to copy content to clipboard |
| `AutoFocus` | Input that focuses on mount via `autofocus: true` |
| `Textarea` | Multi-line input using `type="textarea"` |

## Usage Example

```typescript
import { Default, WithError, Password } from "./InputField.stories";

// Use story args directly in tests or compositions
const errorArgs = {
  ...WithError.args,
  error: "Custom error message",
};

// Render via Storybook play or testing-library
render(<InputField {...errorArgs} />);
```
