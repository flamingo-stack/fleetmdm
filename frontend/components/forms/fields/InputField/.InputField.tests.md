Test suite for the `InputField` React component, covering rendering, user interactions, accessibility attributes, and clipboard functionality.

## Key Components

| Test Case | What It Verifies |
|---|---|
| Label & placeholder rendering | Basic display of label and placeholder text |
| `onChange` callback | Fires once per keystroke; `parseTarget` mode returns `{ name, value }` |
| `helpText` / `error` props | Informational and error messages appear in the DOM |
| `type="textarea"` | Renders a `<textarea>` element with correct `name` attribute |
| `enableCopy` | Copy icon renders; clicking writes value to clipboard and shows "Copied!" |
| `enableShowSecret` | Eye icon toggles password input between `type="password"` and `type="text"` |
| `onBlur` / `onFocus` | Focus/blur callbacks fire the expected number of times |
| `disabled` / `readOnly` | Input is disabled in the DOM |
| `autofocus` | Input receives focus on mount |
| `blockAutoComplete` | Sets `autocomplete="new-password"` |
| `ignore1password` | Controls `data-1p-ignore` attribute (defaults to `true`) |
| `tooltip` | Tooltip text renders on label hover |
| `step` / `min` / `max` | Numeric attributes set correctly on `type="number"` inputs |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import userEvent from "@testing-library/user-event";
import InputField from "./InputField";

// Run the full suite
// npx jest InputField.tests.tsx

// Example: test a controlled input with parseTarget
render(
  <InputField
    value=""
    onChange={(payload) => console.log(payload)} // { name, value }
    label="API Key"
    name="api-key"
    parseTarget
    blockAutoComplete
    enableCopy
  />
);

await userEvent.type(screen.getByRole("textbox"), "abc");
// onChange called with { name: "api-key", value: "a" }, etc.
```
