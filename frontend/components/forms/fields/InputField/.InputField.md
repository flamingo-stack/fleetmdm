A reusable form input component supporting both `<input>` and `<textarea>` elements, with optional copy-to-clipboard, show/hide secret (password eye icon), autofocus, read-only/disabled states, validation error display, and label/tooltip/help-text integration.

## Key Components

### `InputField` (default export)
The main component rendering either a text input or textarea, wrapped in a `FormField` for label, error, help text, and tooltip support.

### `IInputFieldProps`
TypeScript interface defining all supported props:

| Prop | Type | Description |
|------|------|-------------|
| `type` | `string` | Input type (`"text"`, `"password"`, `"textarea"`, etc.) |
| `value` | `boolean \| string \| number \| null` | Controlled field value |
| `onChange` | `(value: any) => void` | Change handler; receives raw value or `{ name, value }` when `parseTarget` is `true` |
| `readOnly` / `disabled` | `boolean` | Non-editable display states |
| `enableCopy` | `boolean` | Shows a copy-to-clipboard button |
| `enableShowSecret` | `boolean` | Shows eye icon to toggle password visibility |
| `parseTarget` | `boolean` | Returns `{ name, value }` instead of raw value in `onChange` |
| `blockAutoComplete` | `boolean` | Sets `autocomplete="new-password"` to suppress browser autofill |
| `ignore1password` | `boolean` | Adds `data-1p-ignore` to skip 1Password (default: `true`) |

## Usage Example

```typescript
// Basic text input
<InputField
  label="Username"
  name="username"
  value={username}
  onChange={(val) => setUsername(val)}
  placeholder="Enter username"
  error={errors.username}
  helpText="Must be unique across the organization."
/>

// Password input with show/hide and copy
<InputField
  label="API Secret"
  name="apiSecret"
  type="password"
  value={secret}
  onChange={(val) => setSecret(val)}
  enableShowSecret
  enableCopy
  readOnly
/>

// Textarea with copy button
<InputField
  label="Config"
  name="config"
  type="textarea"
  value={configText}
  onChange={(val) => setConfigText(val)}
  enableCopy
/>

// parseTarget mode — receives { name, value }
<InputField
  name="email"
  parseTarget
  onChange={({ name, value }) => handleField(name, value)}
/>
```
