A React form component for confirming SSO-based user invitations, allowing users to verify their email and set their display name before completing account setup.

## Key Components

- **`ConfirmSSOInviteForm`** — Default export; a controlled form component managing name input state and validation
- **`IConfirmSSOInviteFormProps`** — Interface defining the component's props:
  - `defaultName` — Pre-populated name value (optional)
  - `email` — Read-only email field pre-filled from the SSO invite (optional)
  - `handleSubmit` — Callback invoked with the trimmed name string on valid submission

## Behavior

- Email field is **disabled** (read-only), displaying the SSO-provided address
- Full name field is **autofocused**, limited to 80 characters, with inline error display
- Validates that the name is non-empty on submit; clears the error as soon as valid input is detected
- Submit button is disabled while a name validation error is active

## Usage Example

```typescript
import ConfirmSSOInviteForm from "components/forms/ConfirmSSOInviteForm";

const ConfirmInvitePage = () => {
  const handleConfirm = (name: string) => {
    // Submit name to API or dispatch action
    console.log("Confirmed name:", name);
  };

  return (
    <ConfirmSSOInviteForm
      defaultName="Jane Doe"
      email="jane.doe@example.com"
      handleSubmit={handleConfirm}
    />
  );
};
```
