Test suite for the `ConfirmSSOInviteForm` component, verifying rendering, validation, and submission behavior for SSO-based user invite confirmation.

## Key Components

- **`ConfirmSSOInviteForm`** — The component under test; accepts `defaultName`, `email`, and `handleSubmit` props
- **`renderWithSetup`** — Test utility from `test/test-utils` that provides a `user` event instance for simulating interactions
- **`handleSubmitSpy`** — Jest mock tracking submission calls and arguments

## Test Cases

| Test | Description |
|------|-------------|
| Renders correctly | Email field is disabled and prefilled; name field shows `defaultName`; Submit button is present |
| Valid submission | Calls `handleSubmit` with the name value on submit |
| Empty name validation | Blocks submission and shows `"Full name must be present"` error |
| Whitespace-only name | Treated as empty (validation fails); trimmed name is passed on valid submit |

## Usage Example

```typescript
import { renderWithSetup } from "test/test-utils";
import ConfirmSSOInviteForm from "components/forms/ConfirmSSOInviteForm";

const { user } = renderWithSetup(
  <ConfirmSSOInviteForm
    defaultName="Test User"
    email="test@example.com"
    handleSubmit={jest.fn()}
  />
);

// Simulate form submission
await user.click(screen.getByRole("button", { name: "Submit" }));
```

## Notes

- The email field is **always disabled** — users cannot change it during SSO invite confirmation
- Name trimming is enforced: `"Padded Name  "` is submitted as `"Padded Name"`
