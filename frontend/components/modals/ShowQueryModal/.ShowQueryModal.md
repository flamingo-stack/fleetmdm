A read-only modal component that displays a SQL query and its optional performance impact indicator.

## Key Components

- **`ShowQueryModal`** — Default export. A modal dialog wrapping a read-only `SQLEditor` with an optional `PerformanceImpactCell` badge and a close button.
- **`IShowQueryModalProps`** — Props interface:
  - `onCancel: () => void` — Callback fired on close button click, modal exit, or Enter key press.
  - `query?: string` — The SQL query string to display (read-only).
  - `impact?: PerformanceImpactIndicator` — Optional performance impact level to render alongside the query.

## Usage Example

```typescript
import ShowQueryModal from "components/modals/ShowQueryModal";

const MyComponent = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <button onClick={() => setShowModal(true)}>View Query</button>
      {showModal && (
        <ShowQueryModal
          query="SELECT * FROM osquery_info WHERE build_platform = 'darwin';"
          impact="significant"
          onCancel={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- The `SQLEditor` is rendered in `readOnly` mode — users cannot edit the query.
- `PerformanceImpactCell` is only rendered when `impact` is provided.
- Both `onExit` and `onEnter` on the underlying `Modal` are wired to `onCancel`, so pressing Enter or clicking outside dismisses the modal.
