A modal component that displays detailed results for failed MDM enrollment profile renewal commands, showing status, timing, and remediation guidance.

## Key Components

- **`IFailedEnrollmentProfileModalProps`** — Interface requiring a `command` object (with `command_uuid`) and an `onDone` callback
- **`failedEnrollmentProfileContentBody`** — Internal render function that builds the modal body content, including a status icon, relative timestamp via `date-fns`, and a link to Fleet support
- **`FailedEnrollmentProfileModal`** — Default export; wraps `CommandResultsModal` with enrollment-profile-specific title and content

## Usage Example

```typescript
import FailedEnrollmentProfileModal from "./FailedEnrollmentProfileModal";

<FailedEnrollmentProfileModal
  command={{ command_uuid: "abc-123-def-456" }}
  onDone={() => setShowModal(false)}
/>
```

## Behavior

- Fetches and renders command results via the shared `CommandResultsModal`
- Displays the host name (falls back to `"this host"`) and a human-readable relative time (e.g., *"3 minutes ago"*) when `updated_at` is available
- Shows an appropriate status icon via `GetIconName` based on command result status
- Informs the user that an un-renewed profile will require full host re-enrollment, with a link to [fleetdm.com/support](https://fleetdm.com/support)
