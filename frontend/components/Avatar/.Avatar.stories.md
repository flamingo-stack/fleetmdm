Storybook stories for the `Avatar` component, defining visual variants for use in the Storybook UI with Figma design integration.

## Key Components

- **`Default`** – Renders the Avatar with the default size using a Gravatar URL from `DEFAULT_GRAVATAR_LINK`
- **`Small`** – Renders the Avatar at the `"small"` size variant
- **`UseFleetAvatar`** – Renders the Avatar using the Fleet-branded avatar (`useFleetAvatar: true`)

## Usage Example

```typescript
import { Default, Small, UseFleetAvatar } from "./Avatar.stories";

// Use in Storybook or for snapshot testing
<Default />
<Small />
<UseFleetAvatar />
```

## Notes

- All stories share a base `args` of `{ user: { gravatar_url: DEFAULT_GRAVATAR_LINK } }` defined in `meta`
- Linked to the [Fleet style guide Figma file](https://www.figma.com/file/qbjRu8jf01BzEfdcge1dgu/Fleet-style-guide-2022-(WIP)?node-id=210-11078) for design reference
