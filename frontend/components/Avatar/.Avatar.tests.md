Unit tests for the `Avatar` component, verifying rendering behavior for user gravatar URLs and the Fleet-branded avatar fallback.

## Key Components

- **`renders the user gravatar if provided`** — Confirms that when a `gravatar_url` is supplied via the `user` prop, an `<img>` element is rendered with the correct `src` attribute and is visible.
- **`renders the fleet avatar if useFleetAvatar is true`** — Confirms that when `useFleetAvatar` is `true`, the Fleet-branded avatar element (identified by `data-testid="fleet-avatar"`) is rendered and visible.

## Usage Example

```typescript
// Run tests with Jest / React Testing Library
import { render, screen } from "@testing-library/react";
import Avatar from "./Avatar";

// User gravatar
render(<Avatar user={{ gravatar_url: "https://example.com/avatar.png" }} />);
expect(screen.getByAltText("User avatar")).toHaveAttribute(
  "src",
  "https://example.com/avatar.png"
);

// Fleet avatar fallback
render(<Avatar useFleetAvatar user={{}} />);
expect(screen.getByTestId("fleet-avatar")).toBeVisible();
```

## Notes

- Tests rely on `@testing-library/react` queries (`getByAltText`, `getByTestId`) — ensure the `Avatar` component uses matching `alt` text and `data-testid` attributes.
