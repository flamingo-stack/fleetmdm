Renders user avatar images with four display modes: gravatar image, Fleet logo SVG, API-only icon, or a default silhouette SVG fallback.

## Key Components

- **`Avatar`** — Main exported component. Accepts a `user` object with optional `gravatar_url`, and flags to override display mode (`useFleetAvatar`, `useApiOnlyAvatar`). Handles image load/error state to trigger fallback rendering.
- **`FleetAvatar`** — SVG component rendering the Fleet logo (colorful dot grid) inside a circular border.
- **`APIOnlyAvatar`** — SVG component rendering a `</>` code icon for API-only users.
- **`DefaultAvatar`** — SVG component rendering a generic user silhouette for users without a gravatar.

## Usage Example

```typescript
import Avatar from "components/Avatar";

// Gravatar image with size modifier
<Avatar user={{ gravatar_url: "https://www.gravatar.com/avatar/..." }} size="small" />

// Fleet logo avatar
<Avatar user={{}} useFleetAvatar />

// API-only user avatar
<Avatar user={{}} useApiOnlyAvatar />

// Default silhouette (no gravatar_url provided)
<Avatar user={{}} className="my-custom-class" hasWhiteBackground />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `user` | `IAvatarUserInterface` | required | Object with optional `gravatar_url` |
| `size` | `string` | — | Appended as BEM modifier class (e.g. `avatar--small`) |
| `useFleetAvatar` | `boolean` | `false` | Renders Fleet logo SVG instead of gravatar |
| `useApiOnlyAvatar` | `boolean` | `false` | Renders API-only code icon SVG |
| `hasWhiteBackground` | `boolean` | — | Adds `has-white-background` class (ignored for API-only) |
| `className` | `string` | — | Additional CSS class |
