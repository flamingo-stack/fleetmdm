Renders a team selection header that conditionally displays either a `TeamsDropdown` component or a static team name heading based on the user's team membership and global team status.

## Key Components

- **`ITeamsHeader`** — Props interface with:
  - `isOnGlobalTeam` — whether the user belongs to the global team
  - `currentTeamId` — currently selected team ID
  - `userTeams` — array of `ITeamSummary` objects available to the user
  - `onTeamChange` — callback fired when the selected team changes
- **`TeamsHeader`** — Default export; renders one of three states:
  - `TeamsDropdown` — when the user has multiple teams or is on the global team
  - `<h1>` — when the user belongs to exactly one non-global team
  - Empty fragment — when no teams are available

## Usage Example

```typescript
import TeamsHeader from "components/TeamsHeader";

<TeamsHeader
  isOnGlobalTeam={false}
  currentTeamId={3}
  userTeams={[
    { id: 3, name: "Engineering" },
    { id: 7, name: "Security" },
  ]}
  onTeamChange={(teamId) => console.log("Selected team:", teamId)}
/>
```

## Rendering Logic

```text
userTeams.length > 1 OR isOnGlobalTeam  →  <TeamsDropdown> (with "No Teams" option)
userTeams.length === 1 AND !isOnGlobalTeam  →  <h1>{teamName}</h1>
otherwise  →  empty fragment
```
