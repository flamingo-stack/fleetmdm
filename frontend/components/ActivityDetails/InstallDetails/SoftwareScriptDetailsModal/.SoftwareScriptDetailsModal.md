A modal component for displaying script-based software installation details (e.g., `sh_packages` or `ps1_packages`), intentionally separate from `SoftwareInstallDetailsModal` to handle script-only installs with Run/Rerun terminology instead of Install/Retry.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SoftwareScriptDetailsModal` | Component (default) | Root modal; fetches and renders script install results |
| `StatusMessage` | Component | Renders install status icon + descriptive copy for admin or My Device page views |
| `ModalButtons` | Component | Renders Close or Cancel+Rerun footer buttons based on install state |
| `renderContactOption` | Function | Renders "contact your IT admin" text with optional custom URL |
| `IPackageInstallDetails` | Type | `{ host_display_name?, install_uuid? }` — props shape for install context |

## Usage Example

```typescript
import SoftwareScriptDetailsModal, {
  IPackageInstallDetails,
} from "./SoftwareScriptDetailsModal";

// Admin/host activity feed usage
<SoftwareScriptDetailsModal
  details={{ install_uuid: "abc-123", host_display_name: "Johns MacBook" }}
  onCancel={() => setShowModal(false)}
/>

// My Device page usage (enables Rerun button on failed installs)
<SoftwareScriptDetailsModal
  details={{ install_uuid: "abc-123" }}
  deviceAuthToken={token}
  hostSoftware={hostSoftware}
  contactUrl="https://support.example.com"
  onCancel={() => setShowModal(false)}
  onRerun={(id, isScriptPackage) => handleRerun(id, isScriptPackage)}
/>
```

## Behavior Notes

- Fetches results via `softwareAPI` (admin) or `deviceUserAPI` (My Device page, when `deviceAuthToken` is present)
- Displays a toggleable **Details** section with script output when available and status is not `pending_install`
- Omits current version info and post-install script output (key difference from `SoftwareInstallDetailsModal`)
- Handles 401/404 errors with `DeviceUserError` or `DataError` components accordingly
