Test suite for the `decodeBase64Utf8` helper function, verifying correct decoding of Base64-encoded UTF-8 strings including non-ASCII characters and plist XML payloads.

## Key Components

- **`decodeBase64Utf8`** — The function under test, imported from `./helpers`. Decodes Base64-encoded UTF-8 strings back to their original representation.

## Test Cases

**`decodeBase64Utf8 function`**

| Test | Input | Validates |
|------|-------|-----------|
| Non-ASCII UTF-8 | `"Günter Møller Sánchez Peña 🎉"` encoded to Base64 | Round-trip fidelity with special/emoji characters |
| Plist XML payload | Apple Property List XML encoded to Base64 | Round-trip fidelity for MDM command payloads |

## Usage Example

```typescript
import decodeBase64Utf8 from "./helpers";

// Decode a Base64 UTF-8 string with non-ASCII characters
const utf8 = "Günter Møller Sánchez Peña 🎉";
const encoded = Buffer.from(utf8, "utf-8").toString("base64");
const decoded = decodeBase64Utf8(encoded);
// decoded === "Günter Møller Sánchez Peña 🎉"

// Decode a Base64-encoded plist XML MDM command payload
const xmlPayload = Buffer.from(plistXml, "utf-8").toString("base64");
const decodedXml = decodeBase64Utf8(xmlPayload);
// decodedXml contains the original XML with "CertificateList"
```
