A modal component that displays the details and status of a software uninstall operation, supporting both host details and "My Device" page contexts.

## Key Components

### `StatusMessage`
Renders an icon-accompanied status message describing the uninstall outcome. Adapts copy based on:
- `isMyDevicePage` — shows retry prompt with optional contact link for failed uninstalls
- `status` — drives icon selection and predicate text (e.g., "failed to uninstall", "uninstalled")
- `timestamp` — displays relative time (e.g., "3 minutes ago") for non-pending statuses

### `ModalButtons`
Renders footer buttons conditionally:
- **My Device + `failed_uninstall`**: Shows "Cancel" + "Retry" buttons, invoking `onRetry` with the host software object
- **All other cases**: Shows a single "Close" button

### `SoftwareUninstallDetailsModal` (default export)
The main modal component. Fetches script execution results via `useQuery`, routing to either `deviceUserAPI.getSoftwareUninstallResult` (My Device page) or `scriptsAPI.getScriptResult` (host details page) based on presence of `deviceAuthToken`. Renders script contents and output in collapsible `Textarea` code blocks.

### Exported Types
- `ISWUninstallDetailsParentState` — shape for parent component state management
- `ISoftwareUninstallDetailsModalProps` — full props interface for the modal

## Usage Example

```typescript
<SoftwareUninstallDetailsModal
  hostDisplayName="Johns-MacBook-Pro"
  softwareName="Zoom"
  softwarePackageName="zoom.pkg"
  uninstallStatus="failed_uninstall"
  scriptExecutionId="exec-abc-123"
  onCancel={() => setShowModal(false)}
  // My Device page props (optional)
  deviceAuthToken="device-token-xyz"
  contactUrl="https://support.example.com"
  onRetry={(software) => handleRetryUninstall(software)}
  hostSoftware={hostSoftwareObject}
/>
```

> **Note:** The query is disabled when `uninstallStatus === "pending_uninstall"` to avoid unnecessary API calls and premature error states.
