Tests for the `SoftwareUninstallDetailsModal` React component, validating the rendering behavior of the `StatusMessage` and `ModalButtons` sub-components across different uninstall states and page contexts.

## Key Components

### `StatusMessage` Tests
Covers rendering logic for four uninstall states based on page context (`isMyDevicePage`):
- **`pending_uninstall`** – Shows pending icon, package name, host name, and "when it comes online" text (offline host, non-device page)
- **`failed_uninstall` (device page)** – Shows error icon, software name, retry message; suppresses host name
- **`failed_uninstall` (host details page)** – Shows error icon, host name; suppresses retry message
- **`uninstalled`** – Shows success icon, software name, host name, package name, and relative timestamp

### `ModalButtons` Tests
Validates button rendering and interaction handlers for each status:
- **`failed_uninstall` (device page)** – Renders "Retry" and "Cancel" buttons; "Retry" calls `onRetry` with host software and triggers `onCancel`; "Cancel" calls `onCancel` again
- **`pending_uninstall`** – Renders only "Close" button; no "Retry" or "Cancel"
- **`uninstalled`** – Renders only "Close" button
