Modal component that displays certificate installation failure details, including the certificate name, host, and an optional expandable error message.

## Key Components

- **`ICertificateInstallDetails`** – Exported interface describing the modal's data shape (`certificateName`, `hostDisplayName`, `status`, `detail`).
- **`ICertificateInstallDetailsModalProps`** – Internal props interface accepting `details` and an `onCancel` callback.
- **`CertificateInstallDetailsModal`** – Default export; renders a `Modal` with an error status icon, certificate/host context, and a toggleable code-formatted error detail block.

## Usage Example

```typescript
import CertificateInstallDetailsModal, {
  ICertificateInstallDetails,
} from "components/CertificateInstallDetailsModal";

const details: ICertificateInstallDetails = {
  certificateName: "corporate-root-ca",
  hostDisplayName: "MacBook-Pro-123",
  status: "failed",
  detail: "Error: certificate chain validation failed (code: -67843)",
};

<CertificateInstallDetailsModal
  details={details}
  onCancel={() => setModalVisible(false)}
/>
```

## Behavior Notes

- The error `detail` block is **hidden by default** and toggled via a `RevealButton` labeled "Details".
- If `hostDisplayName` is empty, the message falls back to the generic string `"the host"`.
- Both `onExit` and `onEnter` on the underlying `Modal` are wired to `onCancel`, so pressing **Escape** or **Enter** closes the modal.
- The detail text renders in a `code`-variant `Textarea` for monospace formatting.
