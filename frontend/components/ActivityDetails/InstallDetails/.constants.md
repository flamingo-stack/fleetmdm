Defines icon mappings and human-readable status predicates for software install/uninstall and script execution statuses used in Fleet MDM's software details UI.

## Key Components

- **`INSTALL_DETAILS_STATUS_ICONS`** — Maps `SoftwareInstallUninstallStatus` values to `IconNames` for install/uninstall status indicators.
- **`getInstallDetailsStatusPredicate`** — Returns a human-readable verb phrase for a given install/uninstall/script status string; falls back to `"is installing or will install"` if status is undefined or unrecognized.
- **`SCRIPT_DETAILS_STATUS_ICONS`** — Maps `SoftwareInstallStatus` values to `IconNames` for script execution status indicators.
- **`getScriptDetailsStatusPredicate`** — Returns a human-readable verb phrase for a given script run status string; falls back to `"is running or will run"` if status is undefined or unrecognized.

## Usage Example

```typescript
import {
  INSTALL_DETAILS_STATUS_ICONS,
  getInstallDetailsStatusPredicate,
  getScriptDetailsStatusPredicate,
} from "./constants";

// Resolve an icon for a given install status
const icon = INSTALL_DETAILS_STATUS_ICONS["failed_install"]; // "error"

// Build a sentence describing install status
const status = "failed_uninstall";
const predicate = getInstallDetailsStatusPredicate(status);
console.log(`Software ${predicate}`); // "Software failed to uninstall"

// Build a sentence describing script run status
const scriptStatus = "installed";
const scriptPredicate = getScriptDetailsStatusPredicate(scriptStatus);
console.log(`Script ${scriptPredicate}`); // "Script ran"

// Handles undefined gracefully
const fallback = getInstallDetailsStatusPredicate(undefined);
// "is installing or will install"
```
