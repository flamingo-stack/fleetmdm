Test suite for the `SoftwareIpaInstallDetailsModal` component, covering rendering behavior across all IPA software installation states including MDM command results, install success/failure, and retry interactions.

## Key Components

- **`renderModal(overrides?)`** — Helper that bootstraps a pre-wired modal with a mock backend, accepting partial prop overrides for `details`, `hostSoftware`, `deviceAuthToken`, `onRetry`, and `onCancel`
- **`getMdmCommandResultHandler`** / **`getDeviceVppCommandResultHandler`** — MSW handlers registered before each test to simulate MDM command result API responses
- **`createMockHostSoftware`** — Factory used to simulate installed/uninstalled host software state, driving `failed_install` branch logic

## Test Cases

| Scenario | Key Assertion |
|---|---|
| MDM `NotNow` result | Displays locked/Power Nap message |
| MDM `Acknowledged` pending | Shows "not been verified" + Refetch button |
| Non-MDM installed | Success icon, app name, host name |
| Manually installed (no `commandUuid`) | "is installed." with success icon |
| Empty `hostDisplayName` | Falls back to "the host" label |
| `failed_install` but app IS installed | Treats as success, no error icon |
| `failed_install`, app NOT installed | Error icon + retry guidance |
| Default footer | Single Close button triggers `onCancel` |
| `failed_install` + `deviceAuthToken` | Cancel + Retry buttons; Retry calls `onRetry(softwareId)` |

## Usage Example

```typescript
// Run all tests
npx jest SoftwareIpaInstallDetailsModal.tests.tsx

// Override specific details in a custom test
renderModal({
  details: {
    commandUuid: "my-uuid",
    fleetInstallStatus: "failed_install",
    hostDisplayName: "My Mac",
    appName: "Xcode",
  },
  hostSoftware: createMockHostSoftware({ id: 7, name: "Xcode", installed_versions: [] }),
  deviceAuthToken: "tok_abc",
  onRetry: jest.fn(),
  onCancel: jest.fn(),
});
```
