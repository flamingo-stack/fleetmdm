Renders a modal dialog displaying iOS/iPadOS `.ipa` software installation details, including MDM command status, error messages, and retry functionality for both admin and end-user (My Device) contexts.

## Key Components

### Exported Functions & Components

- **`getStatusMessage(props)`** — Derives a human-readable JSX status message based on install status, MDM acknowledgment state, actor identity, and failure reason. Handles edge cases like pre-4.57 `"pending"` status, `NotNow` MDM responses, and pre-flight Fleet failures.

- **`ModalButtons`** — Renders modal action buttons; shows a **Retry** button on the My Device page when status is `failed_install`, otherwise renders a **Close** button.

- **`SoftwareIpaInstallDetailsModal`** — Main modal component. Fetches MDM command results via `react-query`, decodes base64 payloads, reconciles inventory vs. command result state, and renders the status message, install detail toggle, and inventory versions.

### Key Types

- **`ISoftwareIpaInstallDetails`** — Data contract for the modal: install status, host/app names, command UUID, failure reason, and actor metadata.

## Usage Example

```typescript
import { SoftwareIpaInstallDetailsModal } from "./SoftwareIpaInstallDetailsModal";

<SoftwareIpaInstallDetailsModal
  details={{
    fleetInstallStatus: "failed_install",
    hostDisplayName: "iPhone-12-Pro",
    appName: "MyApp",
    commandUuid: "abc-123",
    fleetInitiated: false,
    actorFullName: "Jane Doe",
  }}
  hostSoftware={hostSoftwareRecord}
  onCancel={() => setShowModal(false)}
  onRetry={(id) => retryInstall(id)}
/>
```

## Notes

- Skips the MDM command results query when `failureReason` is set (pre-flight Fleet failures never enqueue an MDM command).
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — mirrors the VPP install details modal pattern for IPA-specific flows.
