Test suite for the `SoftwareInstallDetailsModal` component, covering status message rendering, modal button behavior, and install details section interactions with mocked API responses.

## Key Components

- **`StatusMessage` tests** — Validates rendering across install states (`pending_install`, `failed_install`, `installed`) for both device user page and host details page contexts, including contact links, timestamps, and the `canOverrideFailureWithInstalled` flag
- **`ModalButtons` tests** — Verifies correct button rendering (Retry/Cancel vs. Close) based on install status and device auth token presence, and confirms click handler invocation
- **`Install Details Section` tests** — Integration tests using `mockServer` to validate lazy-loaded script output panels (pre-install, install, post-install) that appear only after clicking the "Details" toggle

## Usage Example

```typescript
// Rendering with a mocked backend for integration tests
const renderWithServer = createCustomRenderer({ withBackendMock: true });
mockServer.use(getSoftwareInstallHandlerWithPreInstall);

const { user } = renderWithServer(
  <SoftwareInstallDetailsModal
    details={{ install_uuid: "uuid-123", host_display_name: "Test Host" }}
    hostSoftware={createMockHostSoftware({ id: 99, name: "CoolApp" })}
    onCancel={noop}
  />
);

// Details are hidden until the user expands them
const detailsBtn = await screen.findByRole("button", { name: /Details/i });
await user.click(detailsBtn);
expect(screen.getByText("Install script output:")).toBeInTheDocument();
```
