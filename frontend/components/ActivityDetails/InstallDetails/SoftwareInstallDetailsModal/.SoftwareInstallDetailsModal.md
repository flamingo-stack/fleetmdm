Renders a modal dialog displaying software installation details for a host, supporting multiple installation contexts (Fleet-managed packages, My Device page, and activity feeds).

## Key Components

### Exports

- **`SoftwareInstallDetailsModal`** – Main modal component that fetches and displays install results, inventory versions, and script outputs. Handles loading, error, and premium feature states.
- **`StatusMessage`** – Renders an icon + status copy describing the current install state (pending, installed, failed, etc.), with optional failure-override logic when host inventory reports the app as installed.
- **`ModalButtons`** – Renders footer buttons; shows a **Retry** action on the My Device page when `status === "failed_install"`, otherwise renders a **Close** button.
- **`renderContactOption`** – Utility that renders an "or contact your IT admin" phrase with an optional hyperlink.
- **`IPackageInstallDetails`** – Type for the `details` prop (`host_display_name`, `install_uuid`).

### Internal Behavior

- Queries install results via `softwareAPI` or `deviceUserAPI` (My Device page) using `react-query`.
- Conditionally overrides `failed_install`/`failed_uninstall` status with "is installed" when host inventory confirms installation.
- Shows a collapsible **Details** section (pre-install query, install script, post-install script outputs) via `RevealButton` + `Textarea`.
- Displays `InventoryVersions` based on visibility rules tied to install status and context.

## Usage Example

```typescript
<SoftwareInstallDetailsModal
  details={{
    install_uuid: "abc-123",
    host_display_name: "Johns-MacBook",
  }}
  hostSoftware={hostSoftwareData}
  onCancel={() => setShowModal(false)}
  onRetry={(id) => handleRetry(id)}
  contactUrl="https://helpdesk.example.com"
/>
```
