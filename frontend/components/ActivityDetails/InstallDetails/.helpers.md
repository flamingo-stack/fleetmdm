Safely decodes a base64-encoded UTF-8 string into a JavaScript string, handling multi-byte characters by converting through a `Uint8Array` and `TextDecoder` rather than using `atob` directly.

## Key Components

- **`decodeBase64Utf8(b64: string): string`** — Default export. Accepts a base64 string, validates input, decodes via `atob`, converts the binary string to a `Uint8Array`, and uses `TextDecoder` to produce a properly decoded UTF-8 string. Returns an empty string on invalid input or decode errors.

## Usage Example

```typescript
import decodeBase64Utf8 from "./helpers";

// Standard ASCII payload
decodeBase64Utf8("SGVsbG8gV29ybGQ="); // "Hello World"

// Multi-byte UTF-8 characters (e.g. Japanese, emoji)
decodeBase64Utf8("44GT44KT44Gr44Gh44Gv"); // "こんにちは"

// Invalid or empty input returns empty string gracefully
decodeBase64Utf8("");        // ""
decodeBase64Utf8("!!!bad"); // ""
```

## Notes

- Uses `atob` + `Uint8Array` + `TextDecoder` to correctly handle multi-byte UTF-8 — plain `atob` alone will corrupt characters outside ASCII.
- Catches and logs decode errors via `console.error` without throwing, making it safe to use in rendering pipelines.
- Returns `""` for empty, whitespace-only, or non-string inputs.
