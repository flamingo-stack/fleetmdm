Renders a user avatar image in the top navigation bar, falling back to a default Gravatar when the user's image fails to load or is unavailable.

## Key Components

- **`IAvatarUserInterface`** – Internal interface requiring an optional `gravatar_url` string for the user object.
- **`IAvatarInterface`** – Public interface accepting `className`, `size`, and `user` props.
- **`Avatar`** – Default export; a functional component managing load/error state for the avatar image.

## Usage Example

```typescript
import Avatar from "components/AvatarTopNav";

const TopNav = () => (
  <Avatar
    user={{ gravatar_url: "https://gravatar.com/avatar/abc123" }}
    size="small"
    className="top-nav-avatar"
  />
);
```

## Behavior Notes

- **Loading state**: Applies a `"default"` CSS class while the image is loading or if an error occurs, allowing a styled placeholder.
- **Error fallback**: On `onError`, `isError` is set to `true`, triggering the `"default"` class and visually falling back to the `DEFAULT_GRAVATAR_LINK` constant.
- **Size modifier**: When `size` is provided, appends a BEM-style modifier class (e.g., `avatar--small`) via `classnames`.
- **Test ID**: The `<img>` element includes `data-testid="user-avatar"` for reliable test targeting.
