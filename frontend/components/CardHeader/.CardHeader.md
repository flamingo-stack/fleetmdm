A reusable header component for use inside `Card` layouts, rendering an optional heading and subheading with BEM-style class composition.

## Key Components

### `ICardHeaderProps`
| Prop | Type | Description |
|------|------|-------------|
| `header` | `JSX.Element \| string` | Primary heading content rendered as `<h2>` |
| `subheader` | `JSX.Element \| string` | Secondary content rendered as `<p>` |
| `className` | `string` | Additional CSS classes to merge |
| `variant` | `"mobile-header"` | Applies a BEM modifier class (e.g. `card-header--mobile-header`) |

### `CardHeader`
Default export. Conditionally renders `header` and `subheader` elements only when provided.

## Usage Example

```typescript
import CardHeader from "components/CardHeader";

// Basic usage
<CardHeader
  header="Fleet Overview"
  subheader="Summary of enrolled devices"
/>

// With mobile variant and JSX content
<CardHeader
  header={<span>Custom <strong>Header</strong></span>}
  subheader="Device enrollment status"
  variant="mobile-header"
  className="my-custom-class"
/>
```

> Both `header` and `subheader` are optional — the component renders nothing for either slot if the value is falsy.
