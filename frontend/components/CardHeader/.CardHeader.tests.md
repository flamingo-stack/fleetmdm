Test suite for the `CardHeader` component, validating rendering behavior for header and subheader content across string and JSX input types.

## Key Components

- **`renders header text and subheader text when provided`** — Verifies that string props render correctly, with `header` as an `<h2>` element and `subheader` as a `<p>` element.
- **`does not render subheader when not provided`** — Confirms the subheader is absent from the DOM when the prop is omitted.
- **`renders JSX elements for header and subheader`** — Ensures JSX elements passed as `header` and `subheader` props are rendered and queryable by `data-testid`.

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import CardHeader from "./CardHeader";

// String props
render(<CardHeader header="My Title" subheader="Optional subtitle" />);
expect(screen.getByText("My Title").tagName).toBe("H2");
expect(screen.getByText("Optional subtitle").tagName).toBe("P");

// JSX props
render(
  <CardHeader
    header={<span data-testid="custom-header">Custom</span>}
    subheader={<span data-testid="custom-sub">Sub</span>}
  />
);
expect(screen.getByTestId("custom-header")).toBeInTheDocument();

// Omitted subheader
render(<CardHeader header="No Sub" />);
expect(screen.queryByText(/subheader/i)).not.toBeInTheDocument();
```

## Notes

- `header` is a required prop; `subheader` is optional.
- Both props accept `string` or `ReactNode`, enabling flexible content composition.
