Storybook stories for the `CardHeader` component, defining default metadata and a baseline `Default` story.

## Key Components

- **`meta`** — Storybook configuration object setting the component, story title (`Components/CardHeader`), and default args (`header`, `subheader`)
- **`Default`** — Baseline story rendering `CardHeader` with the default args

## Usage Example

```typescript
import { CardHeader } from "./CardHeader";

// Render with default props as shown in Storybook
<CardHeader
  header="Card header"
  subheader="This is a card subtitle"
/>
```
