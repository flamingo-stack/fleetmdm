Maps `PolicyStatus` values to their corresponding `IndicatorStatus` display parameters for use in status indicator components.

## Key Components

- **`POLICY_STATUS_TO_INDICATOR_PARAMS`** — A lookup record that maps each `PolicyStatus` (`"pass"`, `"fail"`, `"actionRequired"`) to a tuple of `[IndicatorStatus, displayLabel]` used by `StatusIndicatorWithIcon`.

## Usage Example

```typescript
import POLICY_STATUS_TO_INDICATOR_PARAMS from "./helpers";

const status: PolicyStatus = "fail";
const [indicatorStatus, label] = POLICY_STATUS_TO_INDICATOR_PARAMS[status];
// indicatorStatus → "failure"
// label           → "Fail"
```

| PolicyStatus | IndicatorStatus | Label |
|---|---|---|
| `pass` | `success` | Pass |
| `fail` | `failure` | Fail |
| `actionRequired` | `actionRequired` | Action required |
