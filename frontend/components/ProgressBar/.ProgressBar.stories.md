Storybook stories for the `ProgressBar` component, demonstrating various segment configurations, color combinations, and background customization options.

## Key Components

| Export | Description |
|--------|-------------|
| `Basic` | Two-segment bar showing 85% success (green) and 5% failure (red) |
| `MultipleSegments` | Four-segment bar with green, yellow, red, and blue portions |
| `SingleSegment` | Single segment occupying 50% of the bar |
| `CustomBackground` | Single segment with a custom light-red background color |
| `DefaultBackground` | Single segment using the component's default grey background |

## Usage Example

```typescript
import ProgressBar from "./ProgressBar";

// Basic two-tone bar
<ProgressBar
  sections={[
    { color: "#5cb85c", portion: 0.85 },
    { color: "#d9534f", portion: 0.05 },
  ]}
/>

// Custom background
<ProgressBar
  sections={[{ color: "#5cb85c", portion: 0.6 }]}
  backgroundColor="#f8d7da"
/>
```

## Notes

- `portion` values are decimals between `0` and `1` representing the filled percentage
- Segments without a `backgroundColor` prop fall back to the component's default grey
- Multiple sections are rendered sequentially left-to-right within the bar
