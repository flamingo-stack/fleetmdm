A reusable React component that renders a segmented progress bar composed of colored sections, each representing a proportional value.

## Key Components

### Interfaces

- **`IProgressBarSection`** — Defines a single segment with a `color` string and `portion` (0–1 float representing percentage).
- **`IProgressBar`** — Component props including `sections` array, optional `backgroundColor`, and optional `width` size variant.

### Component

- **`ProgressBar`** — Renders a `div[role="progressbar"]` containing one child `div` per section, sized via inline `width` percentage styles.

**Props:**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sections` | `IProgressBarSection[]` | required | Array of colored segments |
| `backgroundColor` | `string` | `COLORS["ui-fleet-black-10"]` | Track/background fill color |
| `width` | `"small" \| "large"` | `"large"` | Controls height via CSS class |

## Usage Example

```typescript
import ProgressBar, { IProgressBarSection } from "components/ProgressBar";

const sections: IProgressBarSection[] = [
  { color: "#5C8DFF", portion: 0.6 }, // 60%
  { color: "#FF6B6B", portion: 0.25 }, // 25%
];

<ProgressBar
  sections={sections}
  backgroundColor="#E8E8E8"
  width="large"
/>
```

> **Note:** Section `portion` values should sum to `≤ 1.0`. Overflow is not clamped by the component — any excess will render beyond the bar's bounds.
