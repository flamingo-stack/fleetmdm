Re-exports the `FileUploader` component and its associated `ISupportedGraphicNames` type from the local `FileUploader` module, serving as the public barrel entry point for the `FileUploader` feature.

## Key Components

- **`default`** — The `FileUploader` component (re-exported as default)
- **`ISupportedGraphicNames`** — TypeScript type defining supported graphic/icon names for the uploader

## Usage Example

```typescript
import FileUploader from "./FileUploader";
import type { ISupportedGraphicNames } from "./FileUploader";
```
