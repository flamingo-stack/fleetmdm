Storybook stories for the `FileUploader` component, defining metadata and a basic story for visual testing and development.

## Key Components

- **`meta`** — Storybook `Meta` configuration for `FileUploader`, including default args such as `graphicName`, `message`, `additionalInfo`, `accept`, `isLoading`, and `onFileUpload`.
- **`Basic`** — A minimal story that renders `FileUploader` with all default args applied.

## Usage Example

```typescript
// Render the Basic story in Storybook
import { Basic } from "./FileUploader.stories";

// Default args used by the Basic story:
// graphicName: "file-configuration-profile"
// message: "The main message"
// additionalInfo: "The additional message"
// accept: ".pdf"
// isLoading: false
// onFileUpload: () => console.log("File uploaded!")
```

To add additional stories, extend the file with new `StoryObj` exports:

```typescript
export const Loading: Story = {
  args: {
    isLoading: true,
  },
};
```

## Notes

- Accepts file type filtering via `accept` (e.g., `".pdf"`).
- The `isLoading` flag can be toggled to preview loading state.
- Located at [`components/FileUploader/FileUploader.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/FileUploader/FileUploader.stories.tsx).
