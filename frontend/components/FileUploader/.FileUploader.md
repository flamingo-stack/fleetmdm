A reusable React component that handles file upload UI, displaying either a file selection prompt with graphics and an upload button, or a file details view once a file has been selected.

## Key Components

### `ISupportedGraphicNames`
Type alias restricting accepted graphic names to a predefined set of file-type icons (e.g., `"file-sh"`, `"file-pdf"`, `"file-pkg"`, `"file-png"`, etc.).

### `IFileUploaderProps`
Interface defining all configurable props:
- **`graphicName`** – Single or array of supported graphic icons to display
- **`message`** – Instructional text shown in the upload area
- **`onFileUpload`** – Callback receiving the selected `FileList`
- **`fileDetails`** – When provided, switches the view to a file-selected state via `FileDetails`
- **`onButtonClick`** – Overrides file input triggering for custom modal flows
- **`gitopsCompatible`** / **`gitOpsModeEnabled`** – Disables the uploader when GitOps mode is active
- **`canEdit`**, **`onDeleteFile`**, **`customEditor`**, **`customPreview`** – Controls file management actions in the details view

### `FileUploader` (default export)
The main component with internal state tracking (`isFileSelected`) and a hidden `<input type="file">` element triggered programmatically.

## Usage Example

```typescript
import FileUploader from "components/FileUploader";

// Basic file upload
<FileUploader
  graphicName="file-sh"
  message="Upload a shell script"
  accept=".sh"
  onFileUpload={(files) => console.log(files)}
/>

// With file details (post-selection view) and GitOps support
<FileUploader
  graphicName={["file-configuration-profile", "file-pdf"]}
  message="Upload a configuration profile"
  accept=".mobileconfig,.pdf"
  buttonMessage="Choose File"
  fileDetails={{ name: "profile.mobileconfig", description: "MDM profile" }}
  canEdit
  onDeleteFile={() => handleDelete()}
  onFileUpload={(files) => handleUpload(files)}
  gitopsCompatible
  gitOpsModeEnabled={isGitOpsModeEnabled}
/>
```
