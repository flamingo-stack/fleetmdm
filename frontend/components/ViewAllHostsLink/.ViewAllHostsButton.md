A reusable navigation button component that routes users to the host management view, with optional filtering by platform label and configurable display modes.

## Key Components

### `IHostLinkProps` Interface
| Prop | Type | Description |
|------|------|-------------|
| `queryParams` | `QueryParams` | Additional URL query parameters |
| `platformLabelId` | `number` | Filters hosts by platform when provided |
| `condensed` | `boolean` | Shows chevron icon only, no text |
| `excludeChevron` | `boolean` | Hides the right chevron icon |
| `responsive` | `boolean` | Applies responsive text styling |
| `customText` | `string` | Overrides default "View all hosts" label |
| `rowHover` | `boolean` | Visible only on row hover/tab focus |
| `noLink` | `boolean` | Disables navigation (click handled by ancestor) |

### `ViewAllHostsButton`
Default export. Renders an inverse-styled small `Button` that pushes a constructed path onto `browserHistory`. Stops event propagation to prevent conflicts with parent row click handlers.

## Usage Example

```typescript
// Basic usage
<ViewAllHostsButton />

// Filter by platform with custom text
<ViewAllHostsButton
  platformLabelId={3}
  customText="View macOS hosts"
  queryParams={{ status: "online" }}
/>

// Condensed icon-only in a table row
<ViewAllHostsButton
  condensed
  rowHover
  platformLabelId={5}
/>

// Ancestor handles click — no internal navigation
<ViewAllHostsButton noLink customText="See all" />
```

## Path Resolution

- **With** `platformLabelId` → `PATHS.MANAGE_HOSTS_LABEL(platformLabelId)`
- **Without** → `PATHS.MANAGE_HOSTS`

Query parameters are appended via `getPathWithQueryParams`.
