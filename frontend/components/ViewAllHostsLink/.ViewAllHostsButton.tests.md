Test suite for the `ViewAllHostsButton` component, validating its rendering behavior in both default and condensed display modes.

## Key Components

- **`ViewAllHostsButton - component`** — Top-level `describe` block containing two unit tests for the button component.
- **renders View all hosts text and icon** — Verifies the default render includes the label text and a chevron-right icon.
- **hides text when set to condensed** — Confirms that passing the `condensed` prop alongside `queryParams` suppresses the visible label text.

## Usage Example

```typescript
// Run the test suite
import { render, screen } from "@testing-library/react";
import ViewAllHostsButton from "./ViewAllHostsButton";

// Default render — expects text + icon
render(<ViewAllHostsButton />);
expect(screen.getByText("View all hosts")).toBeInTheDocument();
expect(screen.getByTestId("chevron-right-icon")).toBeInTheDocument();

// Condensed render — text should be hidden
render(<ViewAllHostsButton queryParams={{ status: "online" }} condensed />);
expect(screen.queryByText("View all hosts")).toBeNull();
```

## Props Exercised

| Prop | Type | Behavior Tested |
|------|------|-----------------|
| *(none)* | — | Renders label + icon by default |
| `condensed` | `boolean` | Hides the label text |
| `queryParams` | `{ status: string }` | Passed alongside `condensed` |
