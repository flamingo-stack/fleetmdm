A React banner component that displays a warning message when the Apple Push Notification service (APNs) certificate is expired or nearing expiration, with a link to renewal instructions.

## Key Components

- **`ApplePNCertRenewalMessage`** — Default export. Renders a yellow `InfoBanner` with context-aware messaging based on certificate status.
- **`IApplePNCertRenewalMessage`** — Props type with a single `expired: boolean` flag that controls which message variant is displayed.

## Usage Example

```typescript
// Certificate already expired
<ApplePNCertRenewalMessage expired={true} />

// Certificate expiring within 30 days
<ApplePNCertRenewalMessage expired={false} />
```

**Message behavior:**
- `expired={true}` — Warns that the certificate **has expired** and end users must toggle MDM off/on after renewal.
- `expired={false}` — Warns that the certificate **expires in < 30 days** and prompts proactive renewal before MDM disruption occurs.

Both states include a "Renew APNs" link that opens [fleetdm.com/learn-more-about/renew-apns](https://fleetdm.com/learn-more-about/renew-apns) in a new tab.
