Renders a yellow informational banner prompting administrators to accept updated Apple Business Manager (ABM) terms and conditions, which are required to enable automatic MDM enrollment for macOS, iOS, and iPadOS hosts.

## Key Components

- **`AppleBMTermsMessage`** — Stateless functional component that wraps `InfoBanner` with a fixed yellow warning style and a CTA link to `business.apple.com`
- **`InfoBanner`** — Base banner component accepting `color`, `className`, and `cta` props
- **`CustomLink`** — Renders the "Go to AB" call-to-action, opening in a new tab with the `banner-link` variant

## Usage Example

```typescript
import AppleBMTermsMessage from "components/AppleBMTermsMessage";

// Render conditionally when ABM terms are pending acceptance
const MDMSettingsPage = ({ abmTermsPending }: { abmTermsPending: boolean }) => (
  <div>
    {abmTermsPending && <AppleBMTermsMessage />}
    {/* ...rest of settings */}
  </div>
);
```

## Notes

- The component takes no props and manages no state — display logic should be handled by the parent
- If multiple Apple Business Manager instances are connected, the banner should remain visible until all instances have accepted the updated terms
- The CTA currently links to `https://business.apple.com/`; a TODO comment in the source suggests a future redirect to `/settings/integrations/mdm/abm`
