A React component that renders a user-friendly SSO (Single Sign-On) error message, wrapping the base `DataError` component with MDM-specific error text.

## Key Components

- **`SSOError`** — Default export; a functional component that displays an SSO failure message with guidance to contact IT support
- **`ISSOErrorProps`** — Interface accepting an optional `className` prop for style customization
- **`baseClass`** — BEM-style base CSS class (`mdm-sso-error`) applied to the root element

## Usage Example

```typescript
import SSOError from "components/mdm/SSOError";

// Basic usage
<SSOError />

// With additional custom class
<SSOError className="my-custom-class" />
```

The rendered output merges `mdm-sso-error` with any provided `className` via `classnames`, delegating layout and error styling to the `DataError` component while injecting the SSO-specific message as a child.
