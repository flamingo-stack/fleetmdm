Renders a yellow informational banner notifying users that Android MDM has been disabled due to Android Enterprise deletion in Google Console, with a link to reconnect.

## Key Components

- **`AndroidEnterpriseDeletedMessage`** — Functional component that displays a pre-configured `InfoBanner` with a "Learn more" call-to-action link
- **`InfoBanner`** — Container component styled with `color="yellow"` for warning-level visibility
- **`CustomLink`** — Renders an external link to the Fleet documentation for reconnecting Android Enterprise, opening in a new tab

## Usage Example

```typescript
import AndroidEnterpriseDeletedMessage from "components/AndroidEnterpriseDeletedMessage";

// Conditionally render when Android Enterprise has been deleted
const AndroidSettingsPage = ({ enterpriseDeleted }: { enterpriseDeleted: boolean }) => {
  return (
    <div>
      {enterpriseDeleted && <AndroidEnterpriseDeletedMessage />}
      {/* other settings content */}
    </div>
  );
};
```

## Notes

- No props are accepted; the message and link are statically defined
- The external link points to `https://fleetdm.com/learn-more-about/deleting-android-enterprise` and opens in a new tab
- CSS scoping uses the base class `android-enterprise-deleted-message`
