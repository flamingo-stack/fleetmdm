Test suite for the `AndroidLatestVersionWithTooltip` component, verifying that hovering over "Latest" text displays a tooltip containing a correctly configured Play Store link.

## Key Components

- **`AndroidLatestVersionWithTooltip`** — The component under test, accepting an `androidPlayStoreId` prop
- **`renderWithSetup`** — Custom test utility providing a `user` event helper for interaction simulation
- **`ANDROID_PLAY_STORE_URL`** — Constant used to construct the expected Play Store href

## What's Tested

| Scenario | Assertion |
|---|---|
| Tooltip trigger | "Latest" text is present and hoverable |
| Tooltip content | Renders "See latest version on the" and "Play Store" text |
| Link href | Matches `ANDROID_PLAY_STORE_URL?id=<appId>` |
| Link target | Opens in a new tab (`target="_blank"`) |
| Link text | Displays "Play Store" |

## Usage Example

```typescript
// Running the test suite
import { renderWithSetup } from "test/test-utils";
import AndroidLatestVersionWithTooltip from "./AndroidLatestVersionWithTooltip";

const { user } = renderWithSetup(
  <AndroidLatestVersionWithTooltip androidPlayStoreId="com.example.app" />
);

// Hover to trigger tooltip visibility
user.hover(screen.getByText("Latest"));

await waitFor(() => {
  expect(screen.getByRole("link", { name: /Play Store/i }))
    .toHaveAttribute("href", "https://play.google.com/store/apps/details?id=com.example.app");
});
```
