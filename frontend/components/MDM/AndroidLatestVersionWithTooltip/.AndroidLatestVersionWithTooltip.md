Renders a "Latest" label with a tooltip for Android Play Store app versions, linking directly to the app's Play Store page using its package ID.

## Key Components

- **`AndroidLatestVersionWithTooltip`** — Default export. A React component that wraps a "Latest" text span in a `TooltipWrapper`, displaying a tooltip with a `CustomLink` pointing to the app's Play Store URL.
- **`IAndroidLatestVersionWithTooltipProps`** — Interface requiring `androidPlayStoreId` (e.g. `com.android.chrome`) used to construct the Play Store deep link via `getPathWithQueryParams` and `ANDROID_PLAY_STORE_URL`.

## Usage Example

```typescript
import AndroidLatestVersionWithTooltip from "components/AndroidLatestVersionWithTooltip";

// Renders "Latest" with a tooltip linking to Chrome's Play Store page
<AndroidLatestVersionWithTooltip androidPlayStoreId="com.android.chrome" />
```

## Notes

- The Play Store link opens in a new tab (`newTab` prop).
- Relies on `ANDROID_PLAY_STORE_URL` constant and `getPathWithQueryParams` utility to construct the full URL (e.g. `https://play.google.com/store/apps/details?id=com.android.chrome`).
- Intended for use in software version tables or app management UIs where the installed version is managed externally by the Play Store.
