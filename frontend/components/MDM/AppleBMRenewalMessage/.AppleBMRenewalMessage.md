Renders a yellow warning banner notifying Fleet administrators about Apple Business Manager (ABM) server token expiration status, with a direct link to renew the token.

## Key Components

- **`AppleBMRenewalMessage`** — Default export. A React component that displays one of two warning messages depending on whether the ABM token has already expired or is approaching expiration (within 30 days).
- **`IAppleBMRenewalMessageProps`** — Props interface with a single `expired: boolean` field controlling which message variant is displayed.

## Usage Example

```typescript
import AppleBMRenewalMessage from "components/AppleBMRenewalMessage";

// Token is expired
<AppleBMRenewalMessage expired={true} />

// Token expires within 30 days
<AppleBMRenewalMessage expired={false} />
```

## Behavior

| `expired` | Message shown |
|-----------|---------------|
| `true` | Token **has expired** — hosts won't auto-enroll |
| `false` | Token expires **within 30 days** — action recommended |

Both variants render with a yellow `InfoBanner` and include a **"Renew AB"** link pointing to `/settings/integrations/mdm/ab`.
