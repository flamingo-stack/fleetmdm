React SVG icon component that renders an iPadOS platform icon with configurable size and color props.

## Key Components

- **`IiPadOSProps`** — Interface defining component props:
  - `size: IconSizes` — Controls icon dimensions via the `ICON_SIZES` map
  - `color?: Colors` — Optional fill/stroke color from the `COLORS` palette, defaults to `"ui-fleet-black-75"`
- **`iPadOS`** — Default export; a functional component rendering a 24×24 SVG depicting an iPad device outline with the Apple logo mark

## Usage Example

```typescript
import iPadOS from "components/icons/iPadOS";

// Default size and color
<iPadOS size="medium" />

// Custom size and color
<iPadOS size="large" color="ui-fleet-blue" />
```

## Notes

- Default `size` is `"medium"`, default `color` is `"ui-fleet-black-75"`
- SVG `viewBox` is fixed at `0 0 24 24`; scaling is handled entirely by `ICON_SIZES[size]`
- Both the rect (device border) and path (Apple logo) use the same resolved color token, keeping them visually consistent
