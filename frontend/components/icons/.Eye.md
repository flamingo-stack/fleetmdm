SVG icon component that renders an eye/visibility symbol with configurable color and size props.

## Key Components

- **`IEye`** — Interface defining optional `color` and `size` props
- **`Eye`** — Default export; renders a 16×16 viewBox SVG eye icon
  - `color` — Defaults to `"ui-fleet-black-75"`, resolved via the `COLORS` map
  - `size` — Defaults to `"medium"`, resolved via the `ICON_SIZES` map

## Usage Example

```typescript
import Eye from "components/icons/Eye";

// Default appearance
<Eye />

// Custom color and size
<Eye color="ui-fleet-blue-15" size="small" />
```

## Notes

- Color and size values are constrained to the shared `Colors` and `IconSizes` token types, ensuring consistency with the design system.
- The SVG uses `fillRule="evenodd"` and `clipRule="evenodd"` to correctly render the iris cutout within the eye shape.
