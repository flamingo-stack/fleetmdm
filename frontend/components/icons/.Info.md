A React SVG icon component that renders a circular "info" (ℹ️) symbol with configurable size and color.

## Key Components

- **`IInfoProps`** — Interface accepting optional `color` (from `Colors` token) and `size` (from `IconSizes` token)
- **`Info`** — Default export; renders a 16×16 viewBox SVG with a filled info icon, defaulting to `"small"` size and `"ui-fleet-black-75"` color

## Usage Example

```typescript
import Info from "components/icons/Info";

// Default appearance
<Info />

// Custom size and color
<Info size="medium" color="core-vibrant-blue" />
```

## Notes

- Size is resolved via `ICON_SIZES[size]` — sets both `width` and `height` for uniform scaling
- Color is resolved via `COLORS[color]` — maps design token names to hex/CSS values
- The SVG path renders a circle with a dot (top) and vertical bar (center), matching standard info iconography
