Renders a sparkles/magic icon as an inline SVG, supporting customizable fill color via the shared color system.

## Key Components

- **`ISparklesProps`** — Interface accepting an optional `color` prop typed to the `Colors` token union
- **`Sparkles`** — Default export; a functional component rendering a 16×17px three-star sparkles SVG with a default fill of `"ui-fleet-black-75"`

## Usage Example

```typescript
import Sparkles from "components/icons/Sparkles";

// Default color
<Sparkles />

// Custom color from the shared color palette
<Sparkles color="core-vibrant-blue" />
```

## Notes

- Fill color is resolved through `COLORS[color]`, mapping token names to hex values from `styles/var/colors`
- The SVG is purely decorative in most contexts; consider adding `aria-hidden="true"` or an `aria-label` depending on usage
