SVG icon component that renders the Android logo using configurable size and color props from the design system.

## Key Components

- **`Android`** – Default export. A functional React component accepting `size` and `color` props to render a scalable Android SVG icon.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `IconSizes` | `"medium"` | Controls width/height via `ICON_SIZES` map |
| `color` | `Colors` | `"ui-fleet-black-75"` | Fill color resolved via `COLORS` map |

## Usage Example

```typescript
import Android from "components/icons/Android";

// Default usage
<Android size="medium" />

// Custom size and color
<Android size="large" color="core-vibrant-blue" />
```
