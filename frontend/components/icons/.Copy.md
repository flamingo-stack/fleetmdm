A React SVG icon component that renders a "copy" icon with configurable color and size.

## Key Components

- **`ICopy`** — Interface defining optional props:
  - `color` — Token from the `Colors` type (defaults to `"ui-fleet-black-75"`)
  - `size` — Token from the `IconSizes` type (defaults to `"medium"`)
- **`Copy`** — Default export; renders a 16×16 viewBox SVG copy icon using resolved values from `COLORS` and `ICON_SIZES` style maps.

## Usage Example

```typescript
import Copy from "components/icons/Copy";

// Default appearance
<Copy />

// Custom color and size
<Copy color="core-vibrant-blue" size="small" />
```

## Notes

- The SVG is drawn at a fixed `viewBox="0 0 16 16"` but scales via `ICON_SIZES[size]` for width/height.
- Stroke color is resolved from the `COLORS` map, keeping icon styling consistent with the design token system.
