A React SVG icon component that renders a filter funnel icon with configurable size and color.

## Key Components

- **`IFilterFunnelProps`** — Interface defining optional props:
  - `color` — Icon fill color, typed to `Colors` token (defaults to `"ui-fleet-black-33"`)
  - `size` — Icon dimensions, typed to `IconSizes` token (defaults to `"medium"`)

- **`FilterFunnel`** — Default export; renders a 16×16 viewBox SVG funnel shape using design system tokens from `COLORS` and `ICON_SIZES`.

## Usage Example

```typescript
import FilterFunnel from "components/icons/FilterFunnel";

// Default (medium, dark gray)
<FilterFunnel />

// Custom size and color
<FilterFunnel size="small" color="core-fleet-blue" />
```

## Notes

- SVG `viewBox` is fixed at `0 0 16 16`; actual rendered size is controlled by `ICON_SIZES[size]`.
- Color and size values are resolved through centralized style tokens (`styles/var/colors`, `styles/var/icon_sizes`), ensuring consistency with the Fleet design system.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
