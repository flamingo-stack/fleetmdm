A React SVG icon component that renders a query/search-with-checkmark icon, supporting customizable color and size props.

## Key Components

- **`IQuery`** – Interface defining optional `color` and `size` props
- **`Query`** – Default export; renders a 16×16 SVG magnifying glass with a checkmark indicator

## Usage Example

```typescript
import Query from "components/icons/Query";

// Default rendering (medium size, dark color)
<Query />

// Custom color and size
<Query color="core-vibrant-blue" size="small" />
```

## Props

| Prop | Type | Default |
|------|------|---------|
| `color` | `Colors` | `"ui-fleet-black-75"` |
| `size` | `IconSizes` | `"medium"` |

Color values are resolved via `COLORS` from [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/colors.ts) and size values via `ICON_SIZES` from [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/icon_sizes.ts).
