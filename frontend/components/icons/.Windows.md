SVG icon component that renders the Windows logo, with configurable size and color props drawn from the shared design token system.

## Key Components

- **`IWindowsProps`** — Interface defining the component's props:
  - `size` (`IconSizes`) — Controls SVG dimensions via the `ICON_SIZES` token map; defaults to `"medium"`
  - `color` (`Colors`) — Fill color resolved from the `COLORS` token map; defaults to `"ui-fleet-black-75"`
- **`Windows`** — Default export; a functional React component rendering a 16×16 viewBox Windows logo SVG

## Usage Example

```typescript
import Windows from "components/icons/Windows";

// Default size and color
<Windows size="medium" />

// Custom size and color
<Windows size="large" color="core-vibrant-blue" />
```

## Notes

- All sizing and color values are resolved through shared design tokens (`ICON_SIZES`, `COLORS`) imported from `styles/var/`, ensuring consistency across the icon system.
- The SVG uses a fixed `viewBox="0 0 16 16"` and scales via the `ICON_SIZES` token, making it safe to render at any supported size without distortion.
