A reusable SVG lightbulb icon component that renders with configurable color and size values drawn from the shared design token system.

## Key Components

- **`ILightbulbProps`** — Interface defining optional `color` (from `Colors`) and `size` (from `IconSizes`) props
- **`Lightbulb`** — Default export; a functional React component rendering a 16×16 SVG lightbulb path with defaults of `"medium"` size and `"ui-fleet-black-75"` color

## Usage Example

```typescript
import Lightbulb from "components/icons/Lightbulb";

// Default appearance
<Lightbulb />

// Custom size and color
<Lightbulb size="large" color="core-vibrant-blue" />
```

## Notes

- Size is resolved via `ICON_SIZES[size]` and applied to both `width` and `height`, ensuring a square render.
- Color is resolved via `COLORS[color]`, keeping icon fills consistent with the global design token palette.
- The SVG uses `fill="none"` on the root element with `fillRule="evenodd"` on the path, which is the standard pattern for this icon set.
