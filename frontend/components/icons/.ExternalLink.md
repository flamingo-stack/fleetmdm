An SVG icon component that renders an external link indicator with a rounded rectangle outline and a diagonal arrow.

## Key Components

- **`ExternalLink`** – Default export; a functional React component rendering an inline SVG external link icon
- **`IExternalLinkProps`** – Interface defining the component's props
  - `size: IconSizes` – Controls width/height via the `ICON_SIZES` token map (defaults to `"small"`)
  - `color: Colors` – Controls stroke color via the `COLORS` token map (defaults to `"ui-fleet-black-75"`)
- **`baseClass`** – CSS class prefix (`"external-link-icon"`) used for `:hover` styling hooks on the outline and arrow sub-elements

## Usage Example

```typescript
import ExternalLink from "components/icons/ExternalLink";

// Default size and color
<ExternalLink size="small" color="ui-fleet-black-75" />

// Custom size and color
<ExternalLink size="medium" color="core-vibrant-blue" />
```

## Notes

- The SVG uses a fixed `viewBox="0 0 10 10"` with actual dimensions driven by `ICON_SIZES[size]`
- The outline (`__outline`) and arrow (`__arrow`) sub-elements expose BEM-style classes for CSS `:hover` transitions, typically consumed by a parent `<CustomLink />` component
- No fill is applied; only `stroke` is colored, keeping the icon visually lightweight
