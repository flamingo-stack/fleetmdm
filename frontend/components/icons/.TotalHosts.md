Renders a "Total Hosts" SVG icon with a stacked-layers motif and a checkmark badge, used to represent the total host count in Fleet MDM dashboards.

## Key Components

### `ITotalHostsProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `color` | `Colors` | `"ui-fleet-black-75"` | Fill color token from the Fleet color palette |

### `TotalHosts`
Default export. A functional React component that renders a 33×33 SVG icon composed of:
- **Stacked layer shapes** — three overlapping polygon paths depicting a host/device stack
- **Circular badge** — a circle with a checkmark (`✓`) overlaid in the bottom-right corner
- Unique `clipPath` and `mask` IDs generated via `lodash.uniqueId` to prevent conflicts when multiple instances are rendered on the same page

## Usage Example

```typescript
import TotalHosts from "components/icons/TotalHosts";

// Default color
<TotalHosts />

// Custom color from Fleet palette
<TotalHosts color="core-fleet-blue" />
```

## Notes

- Colors are resolved at render time via the `COLORS` map from `styles/var/colors`, ensuring the icon respects Fleet's design token system.
- Background color is always hardcoded to `"core-fleet-white"` for the mask and badge fill, keeping contrast consistent regardless of the `color` prop.
- Safe for repeated use in lists or tables — `uniqueId` guarantees no SVG `id` collisions across instances.
