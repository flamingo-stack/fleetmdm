A React SVG component that renders a 16×16 indeterminate checkbox icon (filled square with a horizontal dash), used to represent a partially-selected state in checkbox groups.

## Key Components

- **`ICheckboxIndeterminateProps`** — Interface accepting an optional `color` prop typed to the `Colors` union
- **`CheckboxIndeterminate`** — Default export; renders an SVG with a colored rounded rectangle background and a white horizontal bar to indicate indeterminate state
- **Default color** — Falls back to `"core-fleet-green"` if no `color` prop is provided

## Usage Example

```typescript
import CheckboxIndeterminate from "components/CheckboxIndeterminate";

// Default green indeterminate state
<CheckboxIndeterminate />

// Custom color
<CheckboxIndeterminate color="core-vibrant-red" />
```

## Notes

- The outer `<rect>` applies the `checkbox-state` class, allowing CSS targeting for transitions or overrides
- Color values are resolved via the `COLORS` map from `styles/var/colors`, ensuring consistency with the design token system
- The inner white `<rect>` (`x="3" y="7" width="10" height="2"`) is the fixed-size dash and does not respond to the `color` prop
