Renders a Fleet-specific icon as an `<i>` element using CSS class-based icon fonts, with support for fixed-width and size variants.

## Key Components

- **`IFleetIconProps`** — Interface defining the component's props
- **`FleetIcon`** — Default export; renders an `<i>` tag with dynamically composed CSS class names

### Props

| Prop | Type | Description |
|---|---|---|
| `name` | `string` | Icon identifier (required); appended as `fleeticon-<name>` |
| `className` | `string` | Additional CSS classes |
| `fw` | `boolean` | Applies `fleeticon-fw` for fixed-width rendering |
| `size` | `string` | Applies `fleeticon-<size>` for sizing variants |
| `title` | `string` | Accessible tooltip/title attribute |

## Usage Example

```typescript
import FleetIcon from "./FleetIcon";

// Basic icon
<FleetIcon name="arrow-right" />

// Fixed-width with size and custom class
<FleetIcon
  name="filter"
  fw
  size="large"
  className="my-custom-icon"
  title="Filter results"
/>
```

## Notes

- Uses [`classnames`](https://github.com/JedWatson/classnames) for conditional class composition
- Base CSS class is `fleeticon`; icon variants follow the pattern `fleeticon-<name>`
- The `fw` and `size` props are additive and can be combined freely
