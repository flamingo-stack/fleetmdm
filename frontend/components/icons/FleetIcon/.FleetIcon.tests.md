Renders and validates the `FleetIcon` component using React Testing Library, ensuring icon elements mount correctly in the DOM.

## Key Components

- **Test Suite**: `FleetIcon - component` — verifies core rendering behavior of the `FleetIcon` component
- **`renders` test**: Confirms that a `FleetIcon` with `name="success-check"` mounts and produces a `.fleeticon-success-check` CSS class in the DOM

## Usage Example

```typescript
import { render } from "@testing-library/react";
import FleetIcon from "./FleetIcon";

const { container } = render(<FleetIcon name="success-check" />);
expect(container.querySelector(".fleeticon-success-check")).toBeInTheDocument();
```

## Notes

- The component applies a CSS class derived from the `name` prop, following the pattern `.fleeticon-{name}`
- Tests live alongside the component source; see [`FleetIcon.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/FleetIcon/FleetIcon.tsx) for the implementation
