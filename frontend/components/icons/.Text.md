A React component that renders a text/lines SVG icon (16×17px) representing text alignment or a text block, styled with a fixed gray fill color (`#515774`).

## Key Components

- **`Text`** *(default export)* — Stateless functional component returning a hardcoded SVG with three horizontal lines, commonly used as a "text" or "paragraph" icon in UI toolbars.

## Usage Example

```typescript
import Text from "@/components/icons/Text";

const Toolbar = () => (
  <button aria-label="Text">
    <Text />
  </button>
);
```

## Notes

- No props are accepted; size and color are hardcoded (`16×17`, `#515774`).
- To support dynamic sizing or theming, consider extending with `className` or `color` props:

```typescript
interface TextIconProps {
  color?: string;
  size?: number;
}

const Text = ({ color = "#515774", size = 16 }: TextIconProps) => (
  <svg width={size} height={size + 1} viewBox="0 0 16 17" fill="none">
    <path
      fillRule="evenodd"
      clipRule="evenodd"
      d="M0 3.5a1 1 0 0 1 1-1h14a1 1 0 1 1 0 2H1a1 1 0 0 1-1-1Zm0 10a1 1 0 0 1 1-1h8a1 1 0 1 1 0 2H1a1 1 0 0 1-1-1Zm1-6a1 1 0 0 0 0 2h14a1 1 0 1 0 0-2H1Z"
      fill={color}
    />
  </svg>
);
```
