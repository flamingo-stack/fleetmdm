A React SVG icon component that renders a right-pointing chevron arrow, with configurable color and size props.

## Key Components

- **`IChevronProps`** – Interface defining optional `color` and `size` props
- **`ChevronRight`** – Default export; renders a 16×16 SVG chevron using design system tokens

| Prop | Type | Default |
|------|------|---------|
| `color` | `Colors` | `"core-fleet-black"` |
| `size` | `IconSizes` | `"medium"` |

## Usage Example

```typescript
import ChevronRight from "components/icons/ChevronRight";

// Default usage
<ChevronRight />

// Custom color and size
<ChevronRight color="core-vibrant-red" size="small" />
```

## Notes

- Color and size values are resolved via `COLORS` and `ICON_SIZES` maps from the shared design token files ([`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/colors.ts) and [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/icon_sizes.ts)), ensuring consistency with the broader design system.
- The SVG `viewBox` is fixed at `0 0 16 16`; the rendered size scales via `ICON_SIZES[size]`.
