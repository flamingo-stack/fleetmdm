A React SVG icon component that renders a right-pointing arrow, typically used to indicate internal navigation links.

## Key Components

**Interface: `IArrowInternalLink`**
- `color` — Optional fill color using the `Colors` token system (default: `"core-fleet-green"`)
- `size` — Optional icon size using the `IconSizes` token system (default: `"medium"`)

**Component: `ArrowInternalLink`**
- Renders a 16×16 viewBox SVG arrow path
- Resolves `color` and `size` values through `COLORS` and `ICON_SIZES` maps from the design token system

## Usage Example

```typescript
import ArrowInternalLink from "components/icons/ArrowInternalLink";

// Default usage (green, medium)
<ArrowInternalLink />

// Custom color and size
<ArrowInternalLink color="ui-fleet-black-75" size="small" />
```

## Notes

- Actual rendered dimensions are controlled by `ICON_SIZES[size]`, not the `viewBox`
- Fill color is resolved via `COLORS[color]`, keeping icon styling consistent with the design token system
