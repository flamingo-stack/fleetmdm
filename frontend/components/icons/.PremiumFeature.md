A React SVG icon component that renders a purple star-in-circle badge used to indicate premium features in the Fleet MDM UI.

## Key Components

### `IPremiumFeatureProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `IconSizes` | `"medium"` | Controls the rendered dimensions via `ICON_SIZES` lookup |

### `PremiumFeature`
Default export. Renders a 17×17 viewBox SVG containing:
- A purple-filled circle (stroke `#B17FF0`, fill `#C98DEF`)
- A white star shape with a purple outline, centered within the circle
- Unique `clipPath` and `mask` IDs generated per-instance via `lodash.uniqueId` to prevent SVG ID collisions when multiple instances are rendered on the same page

## Usage Example

```typescript
import PremiumFeature from "components/icons/PremiumFeature";

// Default medium size
<PremiumFeature />

// Explicit size
<PremiumFeature size="small" />
<PremiumFeature size="large" />
```

## Notes

- Size values (`"small"`, `"medium"`, `"large"`) are resolved through `ICON_SIZES` from `styles/var/icon_sizes`, which maps size tokens to pixel values
- Unique IDs are generated at render time using `lodash.uniqueId` — safe for multiple simultaneous instances but **not** stable across re-renders (do not rely on these IDs externally)
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
