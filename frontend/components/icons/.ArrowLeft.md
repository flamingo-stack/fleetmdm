A reusable SVG icon component that renders a left-pointing arrow, with configurable color support via the shared color system.

## Key Components

- **`IArrowLeftProps`** — Interface defining the optional `color` prop, typed to the `Colors` union from the shared color variables.
- **`ArrowLeft`** — Default export; a functional React component rendering a 16×16 SVG arrow. Defaults to `"ui-fleet-black-75"` if no color is provided.

## Usage Example

```typescript
import ArrowLeft from "components/icons/ArrowLeft";

// Default color
<ArrowLeft />

// Custom color
<ArrowLeft color="ui-fleet-blue-50" />
```

## Notes

- The SVG uses `fillRule="evenodd"` and `clipRule="evenodd"` for clean path rendering.
- Color values are resolved through the `COLORS` map from [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/colors.ts), ensuring consistency with the design system.
- Fixed dimensions of `16×16` — wrap in a container or apply CSS if a different display size is needed.
