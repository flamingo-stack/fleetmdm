SVG icon component for the "Automatic Self Service" feature, rendering a circular arrows/refresh icon with configurable size and color.

## Key Components

- **`IAutomaticSelfServiceProps`** — Interface defining optional `size` and `color` props
  - `size`: `IconSizes` — defaults to `"medium"`
  - `color`: `Colors` — defaults to `"ui-fleet-black-75"`
- **`AutomaticSelfService`** — Default exported React component rendering a 16×16 SVG icon

## Usage Example

```typescript
import AutomaticSelfService from "components/icons/AutomaticSelfService";

// Default size and color
<AutomaticSelfService />

// Custom size and color
<AutomaticSelfService size="large" color="core-fleet-blue" />
```

## Notes

- Icon dimensions are resolved via `ICON_SIZES[size]` from the shared icon size tokens
- Fill color is resolved via `COLORS[color]` from the shared color tokens
- The SVG `viewBox` is fixed at `0 0 16 16`; scaling is handled entirely by the `width`/`height` attributes driven by `ICON_SIZES`
