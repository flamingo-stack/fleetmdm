A React SVG icon component that renders the CentOS logo, supporting configurable size and color via design system tokens.

## Key Components

- **`ICentosProps`** — Interface defining optional `size` (`IconSizes`) and `color` (`Colors`) props
- **`Centos`** — Default export; a functional component rendering the CentOS logo as an inline SVG with defaults of `"medium"` size and `"ui-fleet-black-75"` color

## Usage Example

```typescript
import Centos from "components/icons/Centos";

// Default size and color
<Centos />

// Custom size and color
<Centos size="large" color="ui-fleet-blue-50" />
```

## Notes

- Size values are resolved via `ICON_SIZES` from `styles/var/icon_sizes`
- Color values are resolved via `COLORS` from `styles/var/colors`
- The SVG uses a fixed `viewBox="0 0 16 16"` and `fill="none"` base, with all fill colors applied via the `color` prop
