A reusable React SVG icon component rendering a right-pointing arrow, with configurable fill color sourced from the Fleet design system color palette.

## Key Components

- **`IArrowProps`** — Interface accepting an optional `color` prop typed to the `Colors` union
- **`Arrow`** — Default export; renders a 16×16 SVG arrow icon with a fill resolved via `COLORS[color]`

## Usage Example

```typescript
import Arrow from "components/icons/Arrow";

// Default color (ui-fleet-black-75)
<Arrow />

// Custom color from the Fleet color palette
<Arrow color="core-fleet-blue" />
```

## Notes

- Defaults to `"ui-fleet-black-75"` when no `color` prop is provided
- Color values are resolved through the `COLORS` map from `styles/var/colors`, ensuring consistency with Fleet's design tokens
- SVG dimensions are fixed at 16×16 and use `fill="none"` on the root element; only the path receives the dynamic fill
