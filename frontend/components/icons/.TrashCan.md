A reusable SVG icon component that renders a trash can/delete icon, supporting customizable color and size via the shared design system tokens.

## Key Components

- **`ITrashCanProps`** — Interface defining optional `color` and `size` props
  - `color`: A `Colors` token (defaults to `"ui-fleet-black-75"`)
  - `size`: An `IconSizes` token (defaults to `"medium"`)
- **`TrashCan`** — Default export; renders a 16×16 viewBox SVG scaled via `ICON_SIZES` and colored via `COLORS`

## Usage Example

```typescript
import TrashCan from "components/icons/TrashCan";

// Default appearance
<TrashCan />

// Custom color and size
<TrashCan color="ui-error" size="small" />
```

## Notes

- Size and color values must be valid tokens from [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/icon_sizes.ts) and [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/colors.ts) respectively — arbitrary strings are not accepted.
- The SVG `viewBox` is fixed at `0 0 16 16`; only the rendered dimensions scale with the `size` token.
