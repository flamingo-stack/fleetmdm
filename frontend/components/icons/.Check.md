A reusable SVG checkmark icon component that renders a 16×16 check icon with configurable color support.

## Key Components

- **`ICheckProps`** — Interface accepting an optional `color` prop typed to the `Colors` design token union
- **`Check`** — Default export; a functional React component rendering an accessible SVG checkmark

## Usage Example

```typescript
import Check from "components/icons/Check";

// Default color (ui-fleet-black-75)
<Check />

// Custom color using design token
<Check color="status-success" />
```

## Notes

- Defaults to `"ui-fleet-black-75"` if no `color` prop is provided
- Color values are resolved via the `COLORS` map from the shared design token system (`styles/var/colors`)
- Includes `aria-label="check"` for basic accessibility
- Stroke-based rendering with `strokeWidth="2"`, `strokeLinecap="round"`, and `strokeLinejoin="round"` for a clean, consistent style
