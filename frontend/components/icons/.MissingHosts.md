SVG icon component that renders a "missing hosts" visual indicator — a map pin with an overlaid "X" badge — used to represent hosts that are absent or unavailable in the Fleet MDM interface.

## Key Components

**`IMissingHostsProps`**
- `color?: Colors` — Optional theme color token (defaults to `"ui-fleet-black-75"`) applied to the pin fill and X mark strokes.

**`MissingHosts`**
- Renders a 32×32 SVG composed of:
  - A map pin shape (filled with `color`)
  - A circular dot cutout on the pin (filled with `core-fleet-white`)
  - A circular badge (white fill, colored border) overlaid at the bottom-right
  - An "X" mark inside the badge drawn with two diagonal paths in `color`

## Usage Example

```typescript
import MissingHosts from "components/icons/MissingHosts";

// Default color
<MissingHosts />

// Custom theme color
<MissingHosts color="core-fleet-red" />
```

## Notes

- Colors are resolved from the `COLORS` map using typed `Colors` tokens, ensuring consistency with the Fleet design system.
- The white background (`core-fleet-white`) is hardcoded for the inner cutout and badge background, making this icon suited for light backgrounds.
