A React SVG icon component that renders a vertical three-dot "more options" (ellipsis) icon with configurable color support.

## Key Components

- **`IMoreProps`** — Interface accepting an optional `color` prop typed to the `Colors` union
- **`More`** — Default export; renders a 16×16 SVG with three vertically stacked dots, defaulting to `"ui-fleet-black-75"`

## Usage Example

```typescript
import More from "components/icons/More";

// Default color
<More />

// Custom color
<More color="ui-fleet-blue-15" />
```

## Notes

- Color is resolved via the `COLORS` map from `styles/var/colors`, ensuring design-token consistency across the icon system
- The SVG uses `fillRule="evenodd"` / `clipRule="evenodd"` to render the three circular dots as a single compound path
- Fixed at 16×16px; scale via a wrapping element if needed
