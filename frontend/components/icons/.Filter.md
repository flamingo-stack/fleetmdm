A React SVG icon component that renders a filter/funnel icon with three horizontal lines of decreasing width.

## Key Components

- **`IFilterProps`** — Interface accepting optional `color` (from `Colors` type) and `size` (from `IconSizes` type) props
- **`Filter`** — Default export; a functional component rendering a 16×16 viewBox SVG filter icon

## Usage Example

```typescript
import Filter from "components/icons/Filter";

// Default rendering (medium size, dark color)
<Filter />

// Custom size and color
<Filter size="large" color="ui-fleet-blue-50" />
```

## Notes

- Defaults to `"medium"` size and `"ui-fleet-black-75"` color
- Size is resolved via `ICON_SIZES` map; color via `COLORS` map from shared style variables
- SVG uses a single compound `fillRule="evenodd"` path representing three stacked horizontal bars
