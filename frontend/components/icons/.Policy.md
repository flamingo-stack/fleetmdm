A React SVG icon component that renders a policy/shield icon with configurable size and color props.

## Key Components

- **`IPolicyProps`** – Interface defining optional `size` (`IconSizes`) and `color` (`Colors`) props
- **`Policy`** – Default export; renders a 16×16 viewBox SVG shield/checkmark icon

## Usage Example

```typescript
import Policy from "components/icons/Policy";

// Default rendering (medium size, ui-fleet-black-75 color)
<Policy />

// Custom size and color
<Policy size="large" color="ui-fleet-black-50" />
```

## Notes

- Default `color`: `"ui-fleet-black-75"`
- Default `size`: `"medium"`
- Actual pixel dimensions are resolved via `ICON_SIZES[size]` from `styles/var/icon_sizes`
- Fill color is resolved via `COLORS[color]` from `styles/var/colors`
