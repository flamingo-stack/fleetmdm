A filled circular close/dismiss icon component that renders an SVG with an "X" inside a solid circle.

## Key Components

- **`CloseFilled`** — Default export. A React SVG icon component rendering a filled circle with an "X" mark.
- **`IExCircledProps`** — Interface defining optional `color` and `size` props.
  - `color` — Accepts a `Colors` token (default: `"ui-fleet-black-75"`)
  - `size` — Accepts an `IconSizes` token (default: `"medium"`)

## Usage Example

```typescript
import CloseFilled from "components/icons/CloseFilled";

// Default usage
<CloseFilled />

// Custom size and color
<CloseFilled size="large" color="ui-fleet-red" />
```

## Notes

- Dimensions are resolved via `ICON_SIZES[size]` and fill color via `COLORS[color]`, keeping the component aligned with the design system's shared tokens.
- The SVG uses `viewBox="0 0 16 16"` and `fillRule="evenodd"` to render the circle-minus-X shape as a single compound path.
