A React component that renders a calendar with a checkmark SVG icon at 16×16 pixels.

## Key Components

- **`CalendarCheck`** — Default export. A stateless functional component that returns an inline SVG calendar-check icon using a single compound `fillRule="evenodd"` path.

## Usage Example

```typescript
import CalendarCheck from "@/components/icons/CalendarCheck";

const ScheduledEventBadge = () => (
  <div className="badge">
    <CalendarCheck />
    <span>Scheduled</span>
  </div>
);
```

## Notes

- Fixed dimensions: `16x16` with `fill="none"` background and a `#515774` filled path.
- No props accepted — color and size are hardcoded. To support customization, consider extending with `className`, `color`, or `size` props.
- Suitable for use alongside scheduled task labels, due date fields, or policy compliance timestamps in the Fleet MDM UI.
