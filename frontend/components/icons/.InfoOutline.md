A React SVG icon component that renders an outlined information (ℹ️) circle icon with configurable size and color.

## Key Components

- **`IInfoOutlineProps`** — Interface defining optional props:
  - `size?: IconSizes` — Controls icon dimensions via `ICON_SIZES` map (defaults to `"medium"`)
  - `color?: Colors` — Controls fill color via `COLORS` map (defaults to `"ui-fleet-black-75"`)

- **`InfoOutline`** — Default export; a functional component rendering a 17×17 viewBox SVG with an outlined circle and info symbol (dot + vertical bar).

## Usage Example

```typescript
import InfoOutline from "components/icons/InfoOutline";

// Default size and color
<InfoOutline />

// Custom size and color
<InfoOutline size="large" color="ui-fleet-blue-50" />
```

## Notes

- SVG `viewBox` is fixed at `0 0 17 17`; actual rendered dimensions scale via `ICON_SIZES[size]`
- Color is applied as a single `fill` on the compound path, so the entire icon shares one color
