A small SVG icon component that renders a "play/run" triangle arrow, used to represent execution or run actions in the Fleet MDM UI.

## Key Components

- **`IRefresh` interface** — Props interface accepting an optional `color` parameter typed to the `Colors` token union
- **`Run` component** — Renders a 12×13 SVG play button triangle with a customizable stroke color, defaulting to `"ui-fleet-black-75"`

## Usage Example

```typescript
import Run from "components/icons/Run";

// Default color
<Run />

// Custom color
<Run color="core-fleet-blue" />
```

## Notes

- Color is applied as an SVG `stroke` (not `fill`) sourced from the `COLORS` token map
- The triangle path uses `strokeLinejoin="round"` for softer corners
- Stroke width is fixed at `2`
