A React component that renders an SVG icon representing ABM (Apple Business Manager) hosts with an issue/warning state, combining a laptop/device icon with a triangular alert badge.

## Key Components

- **`ABMIssueHosts`** — Default export. A stateless functional component that returns a fixed-size `36×24` SVG icon composed of:
  - A laptop/device outline with a hinge indicator
  - A dark triangular warning badge with a white exclamation mark

## Usage Example

```typescript
import ABMIssueHosts from "./ABMIssueHosts";

const HostStatusIndicator = () => (
  <div className="host-status">
    <ABMIssueHosts />
    <span>ABM enrollment issue detected</span>
  </div>
);
```

## Notes

- No props are accepted; dimensions and colors are hardcoded (`36×24`, fill `#515774` for the device, `#515774` for the warning triangle, `#fff` for the exclamation detail).
- Intended as a static UI indicator icon, likely used in Fleet MDM dashboards to flag hosts with Apple Business Manager enrollment problems.
