A React SVG icon component that renders the Apple logo, supporting configurable size and color via design system tokens.

## Key Components

- **`IAppleProps`** — Interface defining optional props:
  - `size` (`IconSizes`) — Controls SVG dimensions via `ICON_SIZES` tokens; defaults to `"medium"`
  - `color` (`Colors`) — Controls fill color via `COLORS` tokens; defaults to `"ui-fleet-black-75"`
- **`Apple`** — Default export; a functional component rendering a 16×16 viewBox Apple SVG icon

## Usage Example

```typescript
import Apple from "components/icons/Apple";

// Default usage
<Apple />

// Custom size and color
<Apple size="large" color="ui-fleet-black-50" />
```

## Notes

- Dimensions are resolved from the shared `ICON_SIZES` map, ensuring consistency across icon components
- Fill color is resolved from the shared `COLORS` map, keeping styling aligned with the design system
- The SVG uses `fill="none"` on the root element; color is applied only to the inner `<path>`
