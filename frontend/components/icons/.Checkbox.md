Renders a 16×16 SVG checkbox icon with a checkmark, supporting customizable fill color via the Fleet design system color tokens.

## Key Components

- **`ICheckboxProps`** — Interface accepting an optional `color` prop typed to the `Colors` union from the shared design system
- **`Checkbox`** — Default export; a functional React component that renders an inline SVG checkbox with a white checkmark path and a dynamically generated `clipPath` ID (via `lodash.uniqueId`) to avoid collisions when multiple instances are rendered

## Usage Example

```typescript
import Checkbox from "components/icons/Checkbox";

// Default green checkbox
<Checkbox />

// Custom color
<Checkbox color="core-vibrant-red" />
```

## Notes

- The `color` prop defaults to `"core-fleet-green"` and maps to a hex value via the `COLORS` lookup from `styles/var/colors`
- `uniqueId("clip-path-")` ensures each rendered instance gets a unique SVG `clipPath` ID, preventing visual artifacts when multiple checkboxes appear on the same page
- The component is purely presentational — checked/unchecked state management is expected to be handled by the parent via conditional rendering
