A React SVG icon component that renders a "pending" status indicator (three dots in a circle).

## Key Components

- **`IPendingProps`** — Interface defining optional `size` and `color` props
  - `size`: `IconSizes` — controls SVG dimensions via `ICON_SIZES` map (default: `"medium"`)
  - `color`: `Colors` — controls fill color via `COLORS` map (default: `"ui-fleet-black-50"`)
- **`Pending`** — Default export; renders a 16×16 viewBox SVG circle with three dots

## Usage Example

```typescript
import Pending from "components/icons/Pending";

// Default appearance
<Pending />

// Custom size and color
<Pending size="large" color="ui-fleet-black-75" />
```

## Notes

- Dimensions scale via the shared `ICON_SIZES` token map; the `viewBox` is fixed at `0 0 16 16`.
- Color is resolved at render time from the `COLORS` token map, keeping icon styling consistent with the design system.
