An SVG close/dismiss icon component that renders an "X" shape using two crossed lines.

## Key Components

- **`IExProps`** — Interface defining optional `color` and `size` props
- **`Close`** — Default export; a functional React component rendering a 16×16 viewBox SVG "X" icon

**Defaults:**
- `size`: `"medium"` (resolved via `ICON_SIZES`)
- `color`: `"ui-fleet-black-75"` (resolved via `COLORS`)

## Usage Example

```typescript
import Close from "components/icons/Close";

// Default size and color
<Close />

// Custom size and color
<Close size="small" color="ui-fleet-black-50" />
```

## Notes

- Size and color values are resolved from the shared `ICON_SIZES` and `COLORS` token maps defined in `styles/var/`
- The "X" is drawn as two diagonal `<path>` strokes with `strokeLinecap="round"` for softened endpoints
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
