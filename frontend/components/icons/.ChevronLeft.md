A reusable SVG icon component that renders a left-pointing chevron arrow, with configurable color and size.

## Key Components

- **`IChevronProps`** — Interface defining optional props:
  - `color?: Colors` — Icon stroke color (defaults to `"core-fleet-black"`)
  - `size?: IconSizes` — Icon dimensions (defaults to `"medium"`)
- **`ChevronLeft`** — Default export; a functional React component rendering a 16×16 SVG chevron path

## Usage Example

```typescript
import ChevronLeft from "components/icons/ChevronLeft";

// Default usage
<ChevronLeft />

// Custom color and size
<ChevronLeft color="core-vibrant-red" size="small" />
```

## Notes

- Dimensions and stroke color are resolved via the `ICON_SIZES` and `COLORS` lookup maps from the shared style tokens
- The SVG `viewBox` is fixed at `0 0 16 16`; actual rendered size scales via the `ICON_SIZES` token
- `strokeWidth` is hardcoded at `2` and uses `round` line caps/joins for a smooth appearance
