A React SVG icon component that renders the Linux (Tux) logo, supporting configurable size and color via design system tokens.

## Key Components

- **`ILinuxProps`** — Interface defining the component's props:
  - `size: IconSizes` — Controls icon dimensions using `ICON_SIZES` tokens
  - `color?: Colors` — Optional fill color using `COLORS` tokens (defaults to `"ui-fleet-black-75"`)

- **`Linux`** — Default export; a functional component rendering a 16×16 SVG viewBox Linux icon with two paths composing the Tux silhouette

## Usage Example

```typescript
import Linux from "components/icons/Linux";

// Default size and color
<Linux size="medium" />

// Custom size and color
<Linux size="large" color="ui-fleet-black-50" />
```

## Notes

- Default `size` is `"medium"`, default `color` is `"ui-fleet-black-75"`
- Dimensions are resolved via `ICON_SIZES[size]` from the shared icon size scale
- Fill color is resolved via `COLORS[color]` from the shared color palette
- SVG has `fill="none"` at the root; color is applied directly to `<path>` elements
