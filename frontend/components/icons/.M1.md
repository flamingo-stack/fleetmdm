SVG icon component rendering the "M1" glyph, used for device/chip identification within the Fleet MDM UI icon system.

## Key Components

- **`IM1Props`** – Interface accepting optional `size` (`IconSizes`) and `color` (`Colors`) props
- **`M1`** – Default export; renders a 16×16 SVG path representing the M1 label with configurable size and fill color

## Usage Example

```typescript
import M1 from "components/icons/M1";

// Default rendering (medium size, ui-fleet-black-75)
<M1 />

// Custom size and color
<M1 size="large" color="core-vibrant-blue" />
```

## Notes

- Defaults: `size = "medium"`, `color = "ui-fleet-black-75"`
- Size and color values are resolved via `ICON_SIZES` and `COLORS` maps from the shared style variables
- SVG `viewBox` is fixed at `0 0 16 16`; only the rendered dimensions scale with `ICON_SIZES[size]`
