A reusable SVG upload icon component that renders a styled upload arrow graphic with configurable color support.

## Key Components

- **`IUploadProps`** — Interface defining optional props for the component
  - `color?: Colors` — Token-based color key from the design system (defaults to `"ui-fleet-black-75"`)
- **`Upload`** — Default export; renders a 17×17 SVG upload icon using a `fillRule="evenodd"` path

## Usage Example

```typescript
import Upload from "components/icons/Upload";

// Default color
<Upload />

// Custom color using design system token
<Upload color="core-vibrant-blue-over-white" />
```

## Notes

- Color is resolved via the `COLORS` map from `styles/var/colors`, ensuring consistency with the broader design token system
- The SVG is fixed at `17×17` pixels with no built-in fill, making color the only configurable visual property
- The icon depicts an upward arrow with a horizontal base line, suitable for file upload actions or import triggers
