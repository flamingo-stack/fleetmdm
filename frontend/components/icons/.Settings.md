A React SVG icon component that renders a settings (gear) icon with configurable size and color.

## Key Components

- **`ISettingsProps`** — Interface defining optional props:
  - `color` — Icon fill color from the `Colors` type (default: `"ui-fleet-black-75"`)
  - `size` — Icon dimensions from the `IconSizes` type (default: `"medium"`)
- **`Settings`** — Default export; a functional component rendering an SVG gear/cog icon

## Usage Example

```typescript
import Settings from "components/icons/Settings";

// Default size and color
<Settings />

// Custom size and color
<Settings size="large" color="ui-fleet-blue-15" />
```

## Notes

- Size values resolve to pixel dimensions via `ICON_SIZES` from `styles/var/icon_sizes`
- Color values resolve to hex/CSS values via `COLORS` from `styles/var/colors`
- The SVG uses `fill="none"` on the root element; fill is applied only to the path
