A React SVG icon component that renders a warning/alert triangle symbol with configurable color and size.

## Key Components

- **`IWarningProps`** – Interface accepting optional `color` (`Colors`) and `size` (`IconSizes`) props
- **`Warning`** – Default export; renders a filled SVG warning triangle using design system tokens

| Prop | Type | Default |
|------|------|---------|
| `color` | `Colors` | `"status-warning"` |
| `size` | `IconSizes` | `"medium"` |

## Usage Example

```typescript
import Warning from "components/icons/Warning";

// Default warning appearance
<Warning />

// Custom color and size
<Warning color="status-error" size="large" />
```

## Notes

- Resolves pixel dimensions via `ICON_SIZES[size]` and hex/token values via `COLORS[color]` from the shared design system
- SVG `viewBox` is fixed at `0 0 16 16`; scaling is handled entirely by the `size` token
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
