A React SVG icon component that renders a filled circular checkmark (success) icon, using design system color and size tokens.

## Key Components

- **`ISuccessProps`** — Interface defining optional `color` and `size` props
  - `color`: Token from the `Colors` type (defaults to `"status-success"`)
  - `size`: Token from the `IconSizes` type (defaults to `"medium"`)
- **`Success`** — Default export; renders a 16×16 viewBox SVG circle with an embedded checkmark path, scaled via `ICON_SIZES` and colored via `COLORS`

## Usage Example

```typescript
import Success from "components/icons/Success";

// Default usage (medium size, success green)
<Success />

// Custom size and color
<Success size="large" color="status-error" />
```

## Notes

- Dimensions are driven by `ICON_SIZES[size]`, keeping the component in sync with the design system scale
- Fill color is resolved through `COLORS[color]`, ensuring only valid design tokens are accepted
- The SVG uses `fillRule="evenodd"` to correctly render the donut-style circle with an interior checkmark in a single `<path>`
