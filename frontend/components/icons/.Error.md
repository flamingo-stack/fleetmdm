A reusable SVG error icon component that renders a 16×16 circular error indicator with a configurable fill color.

## Key Components

- **`IErrorProps`** — Interface accepting an optional `color` prop typed to the `Colors` union from the shared color system.
- **`Error`** — Default export; renders an inline SVG circle with an exclamation mark path, defaulting to `"status-error"` color token.

## Usage Example

```typescript
import Error from "components/icons/Error";

// Default error color
<Error />

// Custom color via design token
<Error color="status-warning" />
```

## Notes

- Color is resolved through the `COLORS` map from `styles/var/colors`, ensuring consistency with the design system's token-based color palette.
- The SVG is purely presentational (no ARIA attributes); wrap with accessible markup when used in context-sensitive UI.
