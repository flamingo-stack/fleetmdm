SVG icon component that renders a refresh/reload symbol with configurable color and size props.

## Key Components

- **`IRefresh`** – Interface defining optional `color` and `size` props
- **`Refresh`** – Default export; renders a 16×16 viewBox SVG refresh icon
  - `color` – Token from `Colors` type; defaults to `"ui-fleet-black-75"`
  - `size` – Token from `IconSizes` type; defaults to `"medium"`

## Usage Example

```typescript
import Refresh from "components/icons/Refresh";

// Default appearance
<Refresh />

// Custom color and size
<Refresh color="ui-fleet-blue-60" size="small" />
```

## Notes

- Actual pixel dimensions are resolved via `ICON_SIZES[size]` and colors via `COLORS[color]`, keeping the component decoupled from raw values.
