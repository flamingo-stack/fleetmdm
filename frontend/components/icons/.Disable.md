A reusable SVG icon component that renders a "disabled" (circle with diagonal line) symbol.

## Key Components

- **`IDisable`** – Interface accepting an optional `color` prop typed to the `Colors` enum
- **`Disable`** – Default export; renders a 16×16 SVG circle-with-slash icon, defaulting to `"ui-fleet-black-75"`

## Usage Example

```typescript
import Disable from "components/icons/Disable";

// Default color
<Disable />

// Custom color
<Disable color="status-error" />
```

## Notes

- Color is resolved through the `COLORS` map from `styles/var/colors`, ensuring consistent token-based theming across the app
- The icon is purely decorative SVG — add `aria-label` or wrap in a semantic element if used in an interactive/accessible context
