A React SVG icon component that renders a downward-pointing chevron arrow, with configurable color and size via design system tokens.

## Key Components

- **`IChevronProps`** — Interface defining optional `color` (from `Colors` type) and `size` (from `IconSizes` type) props
- **`ChevronDown`** — Default export; renders a 16×16 SVG chevron using stroked path, defaulting to `"core-fleet-black"` color and `"medium"` size

## Usage Example

```typescript
import ChevronDown from "components/icons/ChevronDown";

// Default (black, medium)
<ChevronDown />

// Custom color and size
<ChevronDown color="core-vibrant-blue" size="small" />
```

## Notes

- Color values are resolved via the `COLORS` map from `styles/var/colors`
- Size values (width/height) are resolved via the `ICON_SIZES` map from `styles/var/icon_sizes`
- The SVG `viewBox` is fixed at `0 0 16 16`; only rendered dimensions scale with `size`
