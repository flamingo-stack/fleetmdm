SVG icon component that renders an alternative filter icon using design system color and size tokens.

## Key Components

- **`IFilterAltProps`** — Interface defining optional props:
  - `color?: Colors` — Token-based color from the design system (default: `"ui-fleet-black-75"`)
  - `size?: IconSizes` — Token-based size from the design system (default: `"medium"`)
- **`FilterAlt`** — Default export; a functional React component rendering a 16×16 viewBox SVG filter icon with two horizontal sliders.

## Usage Example

```typescript
import FilterAlt from "components/icons/FilterAlt";

// Default appearance
<FilterAlt />

// Custom size and color
<FilterAlt size="large" color="ui-fleet-blue-15" />
```

## Notes

- Size and fill are resolved via `ICON_SIZES` and `COLORS` maps, ensuring consistency with the rest of the design system.
- The SVG `viewBox` is fixed at `0 0 16 16`; the rendered dimensions scale via the `size` token.
