A React SVG icon component that renders an unchecked checkbox state with a customizable border color.

## Key Components

- **`ICheckboxUncheckedProps`** — Interface defining the optional `color` prop
- **`CheckboxUnchecked`** — Default export; renders a 16×16 SVG rectangle styled as an empty checkbox with rounded corners (`rx="3"`) and a white fill

## Usage Example

```typescript
import CheckboxUnchecked from "components/CheckboxUnchecked";

// Default color (ui-fleet-black-25)
<CheckboxUnchecked />

// Custom border color
<CheckboxUnchecked color="ui-fleet-black-50" />
```

## Notes

- The default border color is `"ui-fleet-black-25"` from the shared `COLORS` token map
- The inner `<rect>` carries the class `checkbox-unchecked-state`, allowing external CSS targeting for hover/focus state overrides
- Accepts any `Colors` value defined in `styles/var/colors` for theming consistency across the Fleet UI
