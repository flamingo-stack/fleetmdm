A React SVG icon component that renders a pencil/edit icon with configurable color and size props.

## Key Components

- **`IPencil`** — Interface defining optional `color` (`Colors`) and `size` (`IconSizes`) props
- **`Pencil`** — Default export; renders a 16×16 viewBox SVG pencil icon

## Usage Example

```typescript
import Pencil from "components/icons/Pencil";

// Default rendering (medium size, ui-fleet-black-75 color)
<Pencil />

// Custom color and size
<Pencil color="core-vibrant-blue" size="small" />
```

## Notes

- Defaults to `"ui-fleet-black-75"` color and `"medium"` size
- Color and size values are resolved via `COLORS` and `ICON_SIZES` token maps from the shared style variables
- SVG uses `fill="none"` on the root with fill applied only to the path, ensuring clean rendering
