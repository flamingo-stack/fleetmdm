A React SVG icon component that renders an outlined error/warning circle icon with a configurable color and size.

## Key Components

- **`IErrorOutlineProps`** — Interface defining optional props:
  - `color` — Token from the `Colors` type (defaults to `"status-error"`)
  - `size` — Token from the `IconSizes` type (defaults to `"medium"`)
- **`ErrorOutline`** — Default export; a functional component rendering a 16×16 viewBox SVG with a circular outline containing an exclamation indicator

## Usage Example

```typescript
import ErrorOutline from "components/icons/ErrorOutline";

// Default usage (status-error color, medium size)
<ErrorOutline />

// Custom color and size
<ErrorOutline color="ui-fleet-black-50" size="small" />
```

## Notes

- Dimensions are resolved via `ICON_SIZES[size]` and fill color via `COLORS[color]`, both sourced from shared style tokens, ensuring consistency across the icon system.
- The SVG uses `fillRule="evenodd"` to cut out the inner circle and dot, producing the outlined appearance.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
