A React SVG icon component that renders a user/person icon with configurable size and color.

## Key Components

- **`IUserProps`** — Interface defining optional `size` (`IconSizes`) and `color` (`Colors`) props
- **`User`** — Default export; renders a circular user avatar SVG with a head/body silhouette path

## Usage Example

```typescript
import User from "components/icons/User";

// Default rendering (medium size, dark color)
<User />

// Custom size and color
<User size="large" color="core-vibrant-blue" />

// Small icon with muted color
<User size="small" color="ui-fleet-black-50" />
```

## Notes

- Defaults to `size="medium"` and `color="ui-fleet-black-75"` when no props are provided
- Size values are resolved via `ICON_SIZES` map; color values via `COLORS` map from shared style variables
- The SVG uses `fill="none"` on the root with `fillRule="evenodd"` on the path, producing a clean circular avatar shape
