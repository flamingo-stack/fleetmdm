SVG icon component representing an iOS device (mobile phone outline with Apple logo).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `iOS` | `React.FC` | Default export — renders an iOS device SVG icon |
| `IiOSProps` | `interface` | Props definition for the icon component |

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `IconSizes` | `"medium"` | Controls width/height via `ICON_SIZES` map |
| `color` | `Colors` | `"ui-fleet-black-75"` | Stroke/fill color via `COLORS` map |

## Usage Example

```typescript
import iOS from "components/icons/iOS";

// Default size and color
<iOS size="medium" />

// Custom size and color
<iOS size="large" color="ui-fleet-black-50" />
```

## Notes

- Renders a 24×24 viewBox SVG depicting a mobile device frame with an Apple-style logo path
- `size` and `color` values are constrained to the shared `IconSizes` and `Colors` token systems defined in [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/icon_sizes.ts) and [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/colors.ts)
- The SVG uses a consistent `strokeWidth` of `1.5` for the device outline
