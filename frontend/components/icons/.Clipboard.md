A React functional component that renders a clipboard SVG icon at 16×16 pixels using a fixed purple (`#6A67FE`) fill color.

## Key Components

- **`Clipboard`** — Default export. A stateless React component that returns an inline SVG clipboard icon with two paths: a small top tab and the main clipboard body.

## Usage Example

```typescript
import Clipboard from "./Clipboard";

const MyComponent = () => (
  <button>
    <Clipboard />
    Copy to clipboard
  </button>
);
```

## Notes

- Fixed dimensions: `16x16` — best suited for use within icon slots, buttons, or toolbars.
- No props accepted — color and size are hardcoded. To make it customizable, consider extending with `className`, `size`, or `color` props.
- The fill color `#6A67FE` matches the Flamingo brand purple. If you need a themeable version, the fill values would need to be replaced with `currentColor`.
