A reusable SVG search icon React component that renders a magnifying glass icon with configurable size and color.

## Key Components

- **`ISearchProps`** — Interface defining optional `color` and `size` props
- **`Search`** — Default export; a functional React component rendering an SVG search/magnifying glass icon

## Usage Example

```typescript
import Search from "components/icons/Search";

// Default usage (medium size, ui-fleet-black-75 color)
<Search />

// Custom size and color
<Search size="large" color="core-vibrant-blue" />
```

## Defaults

| Prop | Default |
|------|---------|
| `size` | `"medium"` |
| `color` | `"ui-fleet-black-75"` |

The component maps `size` to pixel dimensions via `ICON_SIZES` and `color` to hex values via `COLORS`, both sourced from the shared design token files at [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/colors.ts) and [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/styles/var/icon_sizes.ts). The SVG uses a fixed `viewBox="0 0 16 16"` with `fill="none"` and renders as a single compound path using `evenodd` fill rule.
