Central icon registry for the Fleet MDM UI component library, exporting a unified `ICON_MAP` that maps string identifiers to their corresponding SVG icon components.

## Key Components

- **`ICON_MAP`** — A flat object mapping kebab-case (and some PascalCase) string keys to icon components. Covers navigation, status, OS/platform, host dashboard, and action icons.
- **`IconNames`** — A TypeScript utility type derived from `ICON_MAP` keys, providing type-safe icon name autocompletion throughout the application.

## Usage Example

```typescript
import { ICON_MAP, IconNames } from "./icons";

// Type-safe icon lookup
const iconName: IconNames = "chevron-right";
const IconComponent = ICON_MAP[iconName];

// Render by name in a component
function Icon({ name }: { name: IconNames }) {
  const Component = ICON_MAP[name];
  return <Component />;
}

// OS/platform icons support multiple aliases
const macIcon = ICON_MAP["darwin"]; // same as ICON_MAP["macOS"]
const chromeIcon = ICON_MAP["chrome"]; // same as ICON_MAP["ChromeOS"]
```

## Icon Categories

| Category | Example Keys |
|---|---|
| Navigation | `arrow`, `chevron-left`, `chevron-right` |
| Actions | `copy`, `pencil`, `trash`, `download`, `upload` |
| Status | `success`, `error`, `warning`, `pending`, `clock` |
| OS / Platform | `darwin`, `windows`, `linux`, `ios`, `ipados`, `android` |
| Host Dashboard | `low-disk-space-hosts`, `missing-hosts`, `total-hosts` |
| MDM / Policy | `policy`, `query`, `gitops-mode`, `premium-feature` |

> **Note:** Several OS icons support both lowercase and PascalCase aliases (e.g., `windows` / `Windows`, `ios` / `iOS`) for compatibility across different call sites.
