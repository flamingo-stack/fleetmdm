A React SVG icon component that renders a "Columns" layout icon, supporting configurable color and size props.

## Key Components

- **`IColumnsProps`** — Interface defining optional `color` (`Colors`) and `size` (`IconSizes`) props
- **`Columns`** — Default export; renders a 16×16 SVG columns icon with defaults of `"ui-fleet-black-75"` color and `"medium"` size

## Usage Example

```typescript
import Columns from "components/icons/Columns";

// Default appearance
<Columns />

// Custom color and size
<Columns color="core-fleet-blue" size="small" />
```

## Notes

- Color values are resolved via `COLORS` from `styles/var/colors`
- Size values are resolved via `ICON_SIZES` from `styles/var/icon_sizes`
- SVG `viewBox` is fixed at `0 0 16 16`; only rendered dimensions scale via `ICON_SIZES`
