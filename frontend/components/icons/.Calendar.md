SVG calendar icon component with configurable size and color props.

## Key Components

- **`ICalendarProps`** – Interface accepting optional `color` (from `Colors` type) and `size` (from `IconSizes` type)
- **`Calendar`** – Default export; renders a 16×16 viewBox SVG calendar icon

**Defaults:**
- `size`: `"medium"`
- `color`: `"ui-fleet-black-75"`

## Usage Example

```typescript
import Calendar from "components/icons/Calendar";

// Default appearance
<Calendar />

// Custom size and color
<Calendar size="large" color="ui-fleet-blue-dark" />
```
