A React SVG icon component that renders the GitOps Mode indicator icon used in the Fleet MDM UI.

## Key Components

- **`IGitOpsModeIconProps`** — Interface defining optional props:
  - `color?: Colors` — Theme color token for the icon fill (defaults to `"ui-fleet-black-75"`)
- **`GitOpsMode`** — Default export; a functional component rendering a fixed-size (12×13) SVG icon representing GitOps mode

## Usage Example

```typescript
import GitOpsMode from "components/icons/GitOpsMode";

// Default usage
<GitOpsMode />

// With custom color
<GitOpsMode color="core-fleet-blue" />
```

## Notes

- Icon dimensions are hardcoded at `12×13` with a `0 0 12 13` viewBox. Dynamic sizing via `IconSizes` is commented out pending a product redesign to a square aspect ratio.
- Fill color resolves through the `COLORS` map from `styles/var/colors`, enabling design token consistency across the UI.
- The SVG path encodes both the three circle nodes and the connecting line characteristic of a GitOps workflow diagram.
