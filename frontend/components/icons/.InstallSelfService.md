SVG icon component that renders an "Install Self Service" circular download arrow icon, with configurable size and color props.

## Key Components

### `IInstallSelfServiceProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `IconSizes` | `"medium"` | Controls icon dimensions via `ICON_SIZES` map |
| `color` | `keyof typeof COLORS` | `"ui-fleet-black-50"` | Fill color from the shared `COLORS` palette |

### `InstallSelfService`
Default export. Renders a 16×16 viewBox SVG of a circle with a downward-pointing arrow, using a unique `clipPath` ID (via `lodash.uniqueId`) to avoid collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import InstallSelfService from "components/icons/InstallSelfService";

// Default (medium, gray)
<InstallSelfService />

// Custom size and color
<InstallSelfService size="large" color="core-vibrant-blue" />
```

## Notes

- `clipPathId` is generated with `uniqueId("clip-path-")` on each render to prevent SVG `clipPath` ID conflicts in the DOM.
- Size values are resolved through `ICON_SIZES` — valid options are defined in [`styles/var/icon_sizes`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/icon_sizes.ts).
- Color values are resolved through the `COLORS` map in [`styles/var/colors`](https://github.com/flamingo-stack/fleetmdm/blob/main/styles/var/colors.ts).
