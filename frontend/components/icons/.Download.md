A reusable SVG icon component that renders a download arrow symbol, built with configurable color and size props.

## Key Components

- **`IDownload`** — Interface defining optional `color` and `size` props
- **`Download`** — Default export; renders a 16×16 viewBox SVG download icon

| Prop | Type | Default |
|------|------|---------|
| `color` | `Colors` | `"ui-fleet-black-75"` |
| `size` | `IconSizes` | `"medium"` |

## Usage Example

```typescript
import Download from "components/icons/Download";

// Default appearance
<Download />

// Custom color and size
<Download color="core-vibrant-blue" size="large" />
```
