A 16×16 SVG icon component representing a bidirectional transfer/swap action, rendered with a configurable fill color.

## Key Components

- **`ITransfer`** — Interface defining the optional `color` prop
- **`Transfer`** — Default export; renders a two-arrow transfer SVG icon
- **`color`** — Accepts a `Colors` token from the design system palette, defaulting to `"ui-fleet-black-75"`

## Usage Example

```typescript
import Transfer from "components/icons/Transfer";

// Default color
<Transfer />

// Custom color
<Transfer color="core-vibrant-blue" />
```

## Notes

- Icon dimensions are fixed at `16×16`
- Fill color is resolved via the `COLORS` map from `styles/var/colors`, ensuring consistency with the design token system
- Source: [`Transfer.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Transfer.tsx)
