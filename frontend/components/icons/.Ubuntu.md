SVG icon component that renders the Ubuntu operating system logo, supporting configurable size and color props.

## Key Components

- **`IUbuntuProps`** – Interface defining optional `size` (`IconSizes`) and `color` (`Colors`) props
- **`Ubuntu`** – Default export; a React functional component rendering the Ubuntu SVG icon with defaults of `"medium"` size and `"ui-fleet-black-75"` color

## Usage Example

```typescript
import Ubuntu from "components/icons/Ubuntu";

// Default size and color
<Ubuntu />

// Custom size and color
<Ubuntu size="large" color="ui-fleet-black-50" />
```

## Notes

- Size values are resolved via `ICON_SIZES` from `styles/var/icon_sizes`
- Color values are resolved via `COLORS` from `styles/var/colors`
- The SVG `viewBox` is fixed at `0 0 17 16`
