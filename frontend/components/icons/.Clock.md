A reusable SVG clock icon component that renders a filled clock shape with configurable color and size.

## Key Components

- **`IClockProps`** — Interface defining optional props:
  - `color` — Icon fill color using the `Colors` type (defaults to `"ui-fleet-black-75"`)
  - `size` — Icon dimensions using the `IconSizes` type (defaults to `"medium"`)
- **`Clock`** — Default export; a functional React component rendering a 16×16 viewBox SVG clock icon

## Usage Example

```typescript
import Clock from "components/icons/Clock";

// Default appearance
<Clock />

// Custom color and size
<Clock color="core-vibrant-blue" size="large" />
```

## Notes

- Color values are resolved via the `COLORS` map from `styles/var/colors`
- Size values (width/height in px) are resolved via `ICON_SIZES` from `styles/var/icon_sizes`
- The SVG uses `fillRule="evenodd"` and `clipRule="evenodd"` to render the clock face and hands as a single compound path
