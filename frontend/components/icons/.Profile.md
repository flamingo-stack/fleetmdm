A React component that renders a profile/document SVG icon with a gear/settings overlay, representing a user profile file.

## Key Components

- **`Profile`** – Default export; a functional React component that returns an inline SVG element
- **`clipPathIdA` / `clipPathIdB`** – Unique IDs generated via `lodash.uniqueId` to prevent SVG `clipPath` ID collisions when multiple instances are rendered on the same page

## Usage Example

```typescript
import Profile from "./Profile";

const MyComponent = () => (
  <div>
    <Profile />
  </div>
);
```

## Notes

- The SVG renders at a fixed `34×40` viewport with no dynamic props (size, color, etc.)
- Uses two nested `clipPath` definitions — one for the document outline, one for the gear/profile icon group
- Safe for concurrent rendering; `uniqueId` ensures each instance gets distinct clip path IDs, avoiding visual bleed between instances
- Located in [`Profile.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Profile.tsx)
