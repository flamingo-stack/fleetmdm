Unit tests for the `OrgLogoIcon` React component, verifying default logo rendering and custom image source handling.

## Key Components

- **`renders the Fleet Logo by default`** — Asserts that when `OrgLogoIcon` is rendered without props, the `<img>` element falls back to the bundled `fleetAvatar` asset (`fleet-avatar-24x24@2x.png`).
- **`renders the image source when it is valid`** — Asserts that when a `src` prop is provided, the `<img>` element reflects the supplied path.

## Usage Example

```javascript
import { render, screen } from "@testing-library/react";
import OrgLogoIcon from "./OrgLogoIcon";

// Default fallback
render(<OrgLogoIcon />);
screen.getByRole("img"); // renders fleet avatar

// Custom source
render(<OrgLogoIcon src="/assets/images/avatar.svg" />);
screen.getByRole("img").getAttribute("src"); // "/assets/images/avatar.svg"
```

## Notes

- Uses [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) with `getByRole("img")` for accessible, implementation-agnostic querying.
- The commented-out `component.state()` assertion is a legacy Enzyme pattern replaced by the current DOM attribute check.
