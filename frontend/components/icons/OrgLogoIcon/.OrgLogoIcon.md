Renders an organization logo image with automatic fallback to the default Fleet avatar when the provided image source is invalid or fails to load.

## Key Components

- **`OrgLogoIcon`** — Class component that displays an org logo `<img>` tag
- **`onError`** — Handler that resets `imageSrc` to the Fleet avatar fallback on load failure
- **`getDerivedStateFromProps`** — Syncs internal `imageSrc` state when the `src` prop changes externally
- **`fleetAvatar`** — Default fallback image (`fleet-avatar-24x24@2x.png`)

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `src` | `string` | Yes | URL of the organization logo |
| `className` | `string` | No | Additional CSS class(es) to apply |

> When `imageSrc` falls back to the Fleet avatar, the CSS class `default-fleet-logo` is appended automatically.

## Usage Example

```javascript
import OrgLogoIcon from "components/icons/OrgLogoIcon";

// With a custom org logo
<OrgLogoIcon src="https://example.com/my-org-logo.png" />

// With an additional class and custom logo
<OrgLogoIcon
  src="https://example.com/my-org-logo.png"
  className="header-logo"
/>

// Falls back to Fleet avatar if src is empty or image fails to load
<OrgLogoIcon src="" />
```
