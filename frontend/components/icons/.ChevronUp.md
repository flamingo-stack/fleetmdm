A React SVG icon component that renders an upward-pointing chevron arrow, with configurable color and size props.

## Key Components

- **`IChevronProps`** — Interface defining optional `color` and `size` props
- **`ChevronUp`** — Default export; renders a 16×16 SVG chevron using design token values

| Prop | Type | Default |
|------|------|---------|
| `color` | `Colors` | `"core-fleet-black"` |
| `size` | `IconSizes` | `"medium"` |

## Usage Example

```typescript
import ChevronUp from "components/icons/ChevronUp";

// Default usage
<ChevronUp />

// Custom color and size
<ChevronUp color="core-vibrant-red" size="small" />
```

## Notes

- Color and size values are resolved via `COLORS` and `ICON_SIZES` token maps from `styles/var/`, ensuring consistency with the design system.
- The SVG uses a `stroke`-based path (no fill), making it suitable for both light and dark backgrounds when paired with appropriate color tokens.
