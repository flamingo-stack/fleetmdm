A React SVG icon component that renders a 16×16 outlined circle with a checkmark, styled using the Fleet design system color tokens.

## Key Components

- **`ICheckProps`** — Interface accepting an optional `color` prop typed to the `Colors` union from the shared color system
- **`SuccessOutline`** — Default export; renders an SVG circle with an inner check path, defaulting to the `"status-success"` color token

## Usage Example

```typescript
import SuccessOutline from "components/icons/SuccessOutline";

// Default success green
<SuccessOutline />

// Override with a custom color token
<SuccessOutline color="status-warning" />
```

## Notes

- Color values are resolved at render time via the `COLORS` map, ensuring consistency with the global Fleet color palette
- Both the circle stroke and check path share the same resolved color, keeping the icon visually cohesive
- Fixed at `16×16` px — scale via a wrapping element's `transform` or `font-size` if a different size is needed
