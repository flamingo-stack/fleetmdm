SVG icon component representing hosts with low disk space, combining a server/storage device icon with a warning triangle overlay.

## Key Components

- **`ILowDiskSpaceHostsProps`** — Interface accepting an optional `color` prop of type `Colors`
- **`LowDiskSpaceHosts`** — Default export; renders a 32×32 SVG composed of:
  - A storage/server rack path (primary fill color)
  - A warning triangle (primary fill color)
  - A vertical exclamation stroke and dot (white background color for contrast)

## Usage Example

```typescript
import LowDiskSpaceHosts from "components/icons/LowDiskSpaceHosts";

// Default color (ui-fleet-black-75)
<LowDiskSpaceHosts />

// Custom color
<LowDiskSpaceHosts color="status-error" />
```

## Notes

- Defaults to `"ui-fleet-black-75"` if no `color` prop is provided
- Background/contrast elements (exclamation mark) always use `"core-fleet-white"` regardless of the `color` prop
- Color values are resolved via the `COLORS` map from `styles/var/colors`
