A React SVG icon component that renders a Linux logo (Tux penguin silhouette) inside a circle, with configurable size and color theming.

## Key Components

### `ILinuxCircledProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `IconSizes` | `"extra-large"` | Controls SVG width/height via `ICON_SIZES` map |
| `iconColor` | `Colors` | `"ui-fleet-black-75"` | Fill color for the Linux icon paths |
| `bgColor` | `Colors` | `"ui-fleet-black-10"` | Fill color for the background circle |

### `LinuxCircled`
Default-exported functional component rendering a 48×48 viewBox SVG containing:
- A circular background filled with `bgColor`
- Linux/Tux penguin icon paths filled with `iconColor`

## Usage Example

```typescript
import LinuxCircled from "components/icons/LinuxCircled";

// Default appearance (grey icon on light grey background, extra-large)
<LinuxCircled />

// Custom size and colors
<LinuxCircled
  size="medium"
  iconColor="core-fleet-blue"
  bgColor="core-vibrant-blue-over-dark"
/>

// Small icon with high-contrast colors
<LinuxCircled
  size="small"
  iconColor="ui-fleet-black-75"
  bgColor="core-fleet-white"
/>
```
