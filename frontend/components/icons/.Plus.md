A React SVG icon component that renders a 16×16 plus/add symbol with configurable color support.

## Key Components

**`IPlusProps`** — Interface defining the component's optional props:
- `color` — A `Colors` token from the design system palette; defaults to `"ui-fleet-black-75"`

**`Plus`** — Default export. Renders a rounded-stroke plus icon using two perpendicular SVG paths, resolved through the `COLORS` map.

## Usage Example

```typescript
import Plus from "components/icons/Plus";

// Default color
<Plus />

// Custom color via design token
<Plus color="status-success" />
```

## Notes

- Dimensions are fixed at `16x16` via `width`/`height` attributes and a `viewBox="0 0 16 16"`.
- The `aria-label="plus"` attribute provides basic accessibility for screen readers.
- Color is resolved at render time via the `COLORS` lookup map, ensuring consistency with the design system's token palette. Raw hex values are not accepted — only valid `Colors` tokens.
