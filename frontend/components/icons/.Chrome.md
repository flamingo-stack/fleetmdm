Renders a Chrome browser SVG icon with configurable size and color props drawn from the shared design token system.

## Key Components

- **`IChromeProps`** — Interface defining the component's props:
  - `size` (`IconSizes`) — Controls icon dimensions via `ICON_SIZES` tokens (default: `"medium"`)
  - `color` (`Colors`) — Fill color via `COLORS` tokens (default: `"ui-fleet-black-75"`)
- **`Chrome`** — Default export; a functional React component rendering a 16×16 viewBox SVG of the Chrome logo

## Usage Example

```typescript
import Chrome from "components/icons/Chrome";

// Default size and color
<Chrome size="medium" />

// Custom size and color
<Chrome size="large" color="core-vibrant-blue" />
```

## Notes

- Icon SVG is drawn at a `16×16` viewBox and scales to the resolved `ICON_SIZES[size]` pixel value
- Color is applied as a single `fill` on the path, so the icon renders as a flat monochrome shape
