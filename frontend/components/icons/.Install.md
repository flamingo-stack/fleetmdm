A reusable React SVG icon component representing a download/install action (downward arrow within a circle).

## Key Components

- **`IInstallProps`** — Interface defining optional `color` and `size` props
- **`Install`** — Default export; renders a 16×16 SVG install icon with configurable color and size
- **`clipPathId`** — Unique ID generated via `lodash.uniqueId` to prevent SVG `clipPath` collisions when multiple instances render on the same page

## Usage Example

```typescript
import Install from "components/icons/Install";

// Default rendering (medium size, ui-fleet-black-50 color)
<Install />

// Custom color and size
<Install color="core-vibrant-blue" size="small" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `color` | `Colors` | `"ui-fleet-black-50"` | Fill color from the shared color palette |
| `size` | `IconSizes` | `"medium"` | Icon dimensions from the shared size scale |

## Notes

- Dimensions are resolved from `ICON_SIZES` and colors from `COLORS` — both defined in the shared design token files under `styles/var/`
- The SVG uses two `evenodd` paths: an outer ring and an inner downward-arrow chevron shape
- Safe for multi-instance use; each render gets a unique `clipPath` ID via `uniqueId`
