A React SVG icon component rendering a circular "pending" indicator (three dots within an outlined circle) at 16×16 pixels.

## Key Components

- **`ICheckProps`** – Interface accepting an optional `color` prop of type `Colors`
- **`PendingOutline`** – Default export; renders an SVG pending/ellipsis icon with a configurable fill color, defaulting to `"ui-fleet-black-50"`

## Usage Example

```typescript
import PendingOutline from "components/icons/PendingOutline";

// Default color
<PendingOutline />

// Custom color
<PendingOutline color="ui-fleet-black-75" />
```
