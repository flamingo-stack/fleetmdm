A React functional component that renders a decorative SVG illustration used as an empty state graphic for the Teams section.

## Key Components

- **`EmptyTeams`** — Default export. A stateless component that renders a 322×150px SVG depicting a placeholder card UI with muted text rows, used when no teams exist.
- **`clipPathId` / `filterId`** — Unique IDs generated via `lodash.uniqueId` to prevent DOM conflicts when multiple instances of the SVG are rendered simultaneously.

## Usage Example

```typescript
import EmptyTeams from "./EmptyTeams";

const TeamsPage = () => (
  <div className="empty-state">
    <EmptyTeams />
    <p>No teams found. Create a team to get started.</p>
  </div>
);
```

## Notes

- The SVG uses a drop shadow filter and a circular purple background (`#F1F0FF`) for visual polish.
- Unique IDs are injected into `clipPath` and `filter` elements to avoid SVG `id` collisions in pages with multiple empty state components.
- No props are accepted; the illustration is purely static.
