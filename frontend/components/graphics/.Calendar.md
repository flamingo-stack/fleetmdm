A React functional component that renders a calendar SVG icon with a dark slate background and white calendar symbol.

## Key Components

- **`Calendar`** — Default export; a stateless React component returning an inline SVG icon (24×24px) with a rounded `#515774` background and a white calendar path.

## Usage Example

```typescript
import Calendar from "@/components/icons/Calendar";

const MyComponent = () => (
  <div>
    <Calendar />
  </div>
);
```

## Notes

- No props are accepted; size and colors are hardcoded (`24×24`, fill `#515774`, icon fill `#fff`).
- Suitable for use as a decorative or informational calendar icon in UI elements such as date pickers, event lists, or schedule views.
- To support customization, consider extending with props for `width`, `height`, and `fill`.
