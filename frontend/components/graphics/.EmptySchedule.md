A React component that renders an SVG illustration representing an empty schedule state, used as a visual placeholder when no schedule data is available.

## Key Components

- **`EmptySchedule`** — Functional React component that returns a 322×176px SVG illustration
- **Unique ID generation** — Uses `lodash.uniqueId` to generate collision-free IDs for SVG internal references (`maskId`, `clipPathId`, `filterId`), ensuring safe rendering when multiple instances exist on the same page

## Usage Example

```typescript
import EmptySchedule from "./EmptySchedule";

const SchedulePage = () => (
  <div>
    {schedules.length === 0 && (
      <div className="empty-state">
        <EmptySchedule />
        <p>No schedules found</p>
      </div>
    )}
  </div>
);
```

## Notes

- The SVG includes a drop shadow filter, a circular background, a card layout with placeholder rows, and an orange clock/schedule icon — forming a complete empty-state illustration
- Dynamic IDs via `uniqueId` prevent SVG `<mask>`, `<clipPath>`, and `<filter>` ID collisions when the component is rendered more than once in the same document
- No props are accepted; the component is purely presentational with fixed dimensions
