A React component that renders a Python file icon as an inline SVG, styled with a blue label badge displaying "py".

## Key Components

- **`FilePy`** — Default export. A functional React component that returns a 34×40px SVG representing a `.py` file icon with a document shape, folded corner, and a blue "py" badge.
- **`clipPathId`** — A `uniqueId`-generated ID (via lodash) ensuring unique `clipPath` references when multiple instances are rendered on the same page.

## Usage Example

```typescript
import FilePy from "./FilePy";

const FileList = () => (
  <div>
    <FilePy />
    <span>script.py</span>
  </div>
);
```

## Notes

- No props are accepted; the icon is purely presentational at a fixed size (`34×40`).
- The `uniqueId("clip-path-")` call prevents SVG `clipPath` ID collisions when the icon is rendered multiple times in the same DOM.
- Styled with Fleet MDM's design palette: white document body (`#fff`), dark outline (`#192147`), grey fold (`#C5C7D1`), and a blue badge (`#5CABDF`).
