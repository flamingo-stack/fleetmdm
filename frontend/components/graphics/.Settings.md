A React functional component that renders a settings gear icon as an inline SVG, featuring a dark rounded square background with a white gear/cog path.

## Key Components

- **`Settings`** (default export) — Stateless React component returning a 24×24 SVG settings icon with a `#515774` rounded rectangle background and a white gear symbol.

## Usage Example

```typescript
import Settings from "./Settings";

const Toolbar = () => (
  <button aria-label="Open settings">
    <Settings />
  </button>
);
```

## Notes

- No props are accepted; dimensions and colors are hardcoded (`24×24`, fill `#515774`, icon fill `#f9fafc`).
- Rendered as an inline SVG — inherits document flow and can be styled via CSS `width`/`height` overrides on the parent.
