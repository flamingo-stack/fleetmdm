A React SVG component that renders a "data error" illustration — a stylized graphic used to visually communicate error or empty states in the Fleet MDM UI.

## Key Components

- **`DataError`** — Default export; a functional React component returning a static inline SVG graphic (128×135px)

## Usage Example

```typescript
import DataError from "./DataError";

const ErrorState = () => (
  <div className="error-container">
    <DataError />
    <p>Something went wrong loading your data.</p>
  </div>
);
```

## Notes

- No props accepted; the component is purely presentational
- SVG uses a fixed `viewBox="0 0 128 135"` with `fill="none"` and layered `<path>` elements
- Color palette: light blue (`#D3E8F3`), white (`#FFFFFF`), and muted gray (`#C0CCCF`) — consistent with Fleet MDM's design system
- Suitable for empty states, loading failures, or inline error illustrations within dashboards or data tables
