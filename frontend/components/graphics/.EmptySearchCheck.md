A thin wrapper component that renders the empty search state specifically for the "check" context.

## Key Components

- **`EmptySearchCheck`** — Default export; a functional component that delegates to `renderEmptySearch` with the `"check"` argument.
- **`renderEmptySearch`** — Imported utility from [`EmptySearchQuestion`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/EmptySearchQuestion.tsx); handles the actual rendering logic for empty search states.

## Usage Example

```typescript
import EmptySearchCheck from "./EmptySearchCheck";

// Render empty state when a check search returns no results
const ChecksTable = ({ checks }) => (
  <div>
    {checks.length === 0 ? <EmptySearchCheck /> : <ChecksList checks={checks} />}
  </div>
);
```
