A React component that renders a stylized SVG icon representing a package file (`.pkg`), designed for use in Fleet MDM's UI.

## Key Components

- **`FilePkg`** — Default export. A functional React component that returns a 34×40px SVG depicting a document icon with a 3D isometric box/package graphic overlaid.
- **`clipPathIdA` / `clipPathIdB`** — Dynamically generated unique IDs (via `lodash.uniqueId`) for SVG clip path definitions, preventing ID collisions when multiple instances are rendered.
- **`maskId`** — Dynamically generated unique ID for the SVG mask element, ensuring safe re-use across the same page.

## Usage Example

```typescript
import FilePkg from "components/icons/FilePkg";

const FileTypeCell = () => (
  <div className="file-type-indicator">
    <FilePkg />
    <span>Package File</span>
  </div>
);
```

## Notes

- No props are accepted; the icon is purely decorative and fixed in size (`34×40`).
- Unique IDs are generated at render time using `lodash/uniqueId`, so multiple `<FilePkg />` instances on the same page will not share conflicting SVG definition IDs.
- Colors use a gold/brown palette (`#FFE400`, `#533006`, `#FBC191`) to visually represent a package, against a white document background with a dark (`#192147`) border.
