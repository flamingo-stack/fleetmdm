A React component that renders a PNG file type icon as an inline SVG, styled with a document shape, blue label band, and "PNG" text.

## Key Components

- **`FilePng`** — Default export. A functional React component that returns a 34×40px SVG icon representing a PNG file, using a unique `clipPath` ID (via `lodash.uniqueId`) to avoid conflicts when rendered multiple times on the same page.

## Usage Example

```typescript
import FilePng from "./FilePng";

const FileList = () => (
  <div>
    <FilePng />
    <span>image.png</span>
  </div>
);
```

## Notes

- The `clipPath` ID is generated at render time using `uniqueId()`, ensuring each instance has a unique DOM ID even when multiple `<FilePng />` components are rendered simultaneously.
- No props are accepted; the icon size is fixed at `34×40px`.
- Colors used: white document body (`#fff`), dark outline (`#192147`), light grey fold (`#C5C7D1`), and blue label band (`#5CABDF`).
