SVG icon component representing a `.sh` (shell script) file, rendered as a document icon with a badge label.

## Key Components

- **`FileSh`** — Default export. A functional React component that renders a styled SVG file icon resembling a shell script document with an "sh" badge in the lower-left corner.
- **`clipPathId`** — A unique ID generated via `lodash.uniqueId` to prevent `clipPath` conflicts when multiple instances of the icon are rendered on the same page.

## Usage Example

```typescript
import FileSh from "./FileSh";

const FileList = () => (
  <div>
    <FileSh />
    <span>deploy.sh</span>
  </div>
);
```

## Notes

- Renders at a fixed size of `34×40px`. Use a wrapper or CSS transform to resize.
- The icon uses a white document body with a folded corner, a grey fold fill (`#C5C7D1`), and a dark blue (`#515774`) badge containing the white "sh" label.
- No props are accepted; the component is purely presentational.
