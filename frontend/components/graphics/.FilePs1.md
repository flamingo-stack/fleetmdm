React SVG icon component that renders a PowerShell script file (`.ps1`) icon with a blue badge label.

## Key Components

- **`FilePs1`** — Default export. A functional React component that renders a styled SVG representing a `.ps1` file icon, featuring a document shape with a folded corner and a blue "PS1" badge in the lower portion.
- **`clipPathId`** — A unique ID generated via `lodash.uniqueId` to prevent `clipPath` conflicts when multiple instances of the icon are rendered on the same page.

## Usage Example

```typescript
import FilePs1 from "./FilePs1";

const FileList = () => (
  <div>
    <FilePs1 />
  </div>
);
```

The SVG renders at a fixed `34×40` viewport with no external props — size and colors are hardcoded. To control dimensions, wrap it in a sized container or extend the component to accept `width`/`height` props.

## Notes

- The icon uses a white document body (`#FFFFFF`) with a dark outline (`#192147`) and a gray fold (`#C5C7D1`).
- The blue badge (`#3375B8`) displays the white text "1", "S", and "p" characters composing the "PS1" label via individual SVG `<path>` elements.
