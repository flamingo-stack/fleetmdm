A React component that renders an SVG illustration used as an empty state graphic for software-related views.

## Key Components

- **`EmptySoftware`** — Functional React component that outputs a 100×56px SVG illustration depicting stacked, isometric box shapes in a purple/lavender color palette, typically used to indicate no software data is available.
- **`clipPathId`** — A unique ID generated via `lodash.uniqueId` to avoid SVG `clipPath` ID collisions when multiple instances render on the same page.

## Usage Example

```typescript
import EmptySoftware from "components/EmptySoftware";

const SoftwareTable = ({ items }) => {
  if (!items.length) {
    return (
      <div className="empty-state">
        <EmptySoftware />
        <p>No software found.</p>
      </div>
    );
  }
  // ...
};
```

## Notes

- No props are accepted; the component is fully self-contained.
- The `clipPathId` is scoped per render instance using `lodash/uniqueId`, preventing DOM ID conflicts in pages where the component may appear more than once.
- Intended for use alongside empty-state messaging in tables or list views within the Fleet MDM UI.
