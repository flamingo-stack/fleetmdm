SVG icon component that renders a P7M file type icon — a document graphic with a dark badge displaying "P7M" text, styled to resemble a file with a folded corner.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FileP7m` | `React.FC` | Default export; renders a 34×40px SVG file icon |

**Internal details:**
- Uses `uniqueId` from lodash to generate a unique `clipPath` ID, preventing SVG conflicts when multiple instances render on the same page
- SVG dimensions: `34px × 40px`
- Renders a white document shape with a folded top-right corner and a dark (`#515774`) badge containing the "P7M" label in white

## Usage Example

```typescript
import FileP7m from "./FileP7m";

const FileList = () => (
  <div>
    <FileP7m />
    <span>document.p7m</span>
  </div>
);
```

## Notes

- No props are accepted; the component is purely presentational
- The unique `clipPath` ID ensures safe reuse across multiple instances in the same DOM
- Related file-type icons likely follow the same pattern in the codebase
