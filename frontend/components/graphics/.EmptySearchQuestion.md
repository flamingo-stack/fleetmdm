Renders an SVG magnifying glass icon with a configurable interior symbol (exclamation, question mark, or check) used as an empty-state illustration for search results.

## Key Components

- **`renderEmptySearch(type)`** — Exported factory function that accepts `"exclamation" | "question" | "check"` and returns a full SVG magnifying glass illustration with the corresponding inner icon path rendered using `COLORS["ui-fleet-black-33"]`
- **`EmptySearchQuestion`** — Default export; a zero-prop React component that renders the magnifying glass with the `"question"` variant

## Usage Example

```typescript
// Default question mark variant
import EmptySearchQuestion from "components/EmptySearchQuestion";

const SearchResults = () => (
  <div>
    {results.length === 0 && <EmptySearchQuestion />}
  </div>
);

// Custom variant via the named export
import { renderEmptySearch } from "components/EmptySearchQuestion";

const NoResultsState = () => (
  <div>
    {renderEmptySearch("exclamation")}
    <p>No results found</p>
  </div>
);
```

## Notes

- All SVG colors are sourced from the shared `COLORS` token map (`styles/var/colors`), ensuring consistent theming across the app
- The outer magnifying glass shape is identical across all variants; only the inner path changes based on `type`
