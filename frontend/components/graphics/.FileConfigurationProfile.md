A React component that renders an SVG icon representing a configuration profile file, featuring a document shape with a gear/settings symbol overlay.

## Key Components

- **`FileConfigurationProfile`** — Default export; a functional React component that returns a styled SVG icon (34×40px) depicting a file with a configuration/gear icon

## Usage Example

```typescript
import FileConfigurationProfile from "./FileConfigurationProfile";

const MyComponent = () => (
  <div>
    <FileConfigurationProfile />
  </div>
);
```

## Notes

- Uses `uniqueId` from lodash to generate unique `clipPath` IDs (`clipPathIdA`, `clipPathIdB`), preventing DOM conflicts when multiple instances are rendered on the same page
- The SVG uses two clip paths: one for the overall document boundary and one scoping the gear icon to its inner region
- No props are accepted; the icon is fixed at `34×40` pixels with hardcoded colors (`#192147` for document borders, `#8B8FA2` for the gear, `#C5C7D1` for the folded corner)
- Intended for use in Fleet MDM UI contexts where configuration profile files need a visual representation
