A React component that renders a lock icon as an inline SVG with a rounded dark background.

## Key Components

- **`Lock`** — Default export. A stateless functional component rendering a 24×24 SVG lock icon with a `#515774` rounded rectangle background and a white lock path.

## Usage Example

```typescript
import Lock from "./Lock";

const SecurityBadge = () => (
  <div>
    <Lock />
    <span>Protected</span>
  </div>
);
```

## Notes

- No props are accepted; the icon is fixed at `24×24` with no customization API.
- To support dynamic sizing or color, consider extending with props:

```typescript
interface LockProps {
  size?: number;
  color?: string;
}

const Lock = ({ size = 24, color = "#515774" }: LockProps) => (
  <svg width={size} height={size} viewBox="0 0 24 24" fill="none">
    <rect width="24" height="24" rx="4" fill={color} />
    {/* path */}
  </svg>
);
```
