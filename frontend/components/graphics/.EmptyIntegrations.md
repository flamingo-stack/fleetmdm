Renders a decorative SVG illustration used as an empty-state placeholder when no integrations are configured.

## Key Components

- **`EmptyIntegrations`** — A React functional component that returns a static SVG graphic depicting a stylized empty list/card UI with placeholder text rows and a subtle drop shadow effect.
- **`filterId`** — A `uniqueId`-generated unique DOM ID (prefixed `filter-`) applied to the SVG `<filter>` and its `url()` reference, preventing ID collisions when the component is rendered multiple times on the same page.

## Usage Example

```typescript
import EmptyIntegrations from "./EmptyIntegrations";

const IntegrationsPage = () => (
  <div>
    <EmptyIntegrations />
    <p>No integrations found. Add one to get started.</p>
  </div>
);
```

## Notes

- No props are accepted; the SVG dimensions are fixed at `322×150`.
- The drop shadow filter uses a unique ID per render via Lodash's `uniqueId`, ensuring safe reuse across multiple instances in the same document.
- The SVG paths encode placeholder "skeleton" rows (grey bars) and a header region, visually communicating an empty list state without requiring any external assets.
