A simple React component that renders the Fleet logo as an image element using an SVG asset.

## Key Components

- **`FleetLogo`** (default export) — Stateless functional component that renders a 40×40 pixel Fleet logo image.

## Usage Example

```typescript
import FleetLogo from "components/FleetLogo/FleetLogo";

const Header = () => (
  <header>
    <FleetLogo />
  </header>
);
```

## Notes

- The SVG asset is imported from `assets/images/fleet-logo.svg` and inlined as a URL.
- The `alt` attribute is set to `"Fleet logo"` for accessibility.
- Dimensions are fixed at `40×40` pixels; override via CSS if resizing is needed.
