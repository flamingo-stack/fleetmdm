A React component that renders a decorative SVG illustration used as an empty-state placeholder for the Packs section in the Fleet MDM UI.

## Key Components

- **`EmptyPacks`** — Default export; a functional React component that returns a static SVG graphic (322×176px) depicting a table-like UI skeleton with a red circular icon, used to indicate no query packs exist.
- **Dynamic IDs** — Uses `lodash.uniqueId` to generate collision-safe IDs for `clipPath`, `mask`, and `filter` SVG elements, preventing conflicts when multiple SVG instances appear in the same DOM.

## Usage Example

```typescript
import EmptyPacks from "components/EmptyPacks";

const PacksPage = () => (
  <div>
    {packs.length === 0 && <EmptyPacks />}
  </div>
);
```

## Notes

- No props are accepted; the component is purely presentational.
- SVG internal IDs (`clipPathId`, `maskId`, `filterId`) are generated at render time via `uniqueId`, ensuring safe reuse across multiple mounts.
- The illustration includes a stylized row/table mockup with a Fleet pack icon (red circle with a package/query glyph) to visually communicate the empty state.
