Renders an empty state illustration for the Queries section using an inline SVG with dynamically generated unique IDs for filter and clip-path elements.

## Key Components

- **`EmptyQueries`** — Default export React functional component that renders a 322×176 SVG placeholder graphic
- **`uniqueId`** (lodash) — Generates collision-safe IDs for SVG `filter` and `clipPath` elements to prevent conflicts when multiple instances are rendered

## Usage Example

```typescript
import EmptyQueries from "./EmptyQueries";

const QueriesPage = () => (
  <div>
    {queries.length === 0 && <EmptyQueries />}
  </div>
);
```

## Notes

- No props are accepted; the component is purely presentational
- SVG dimensions are fixed at `322×176` with a `viewBox="0 0 322 176"`
- Uses `uniqueId` from lodash to namespace SVG filter/clipPath IDs, preventing DOM collisions if the component renders more than once on the same page
- Visual elements include a purple-tinted background circle, a card-style container with drop shadow filter, placeholder row items (checkbox outlines + gray/purple bar fills), and a header row with "Name", "Comp", and other column label paths baked into the SVG path data
