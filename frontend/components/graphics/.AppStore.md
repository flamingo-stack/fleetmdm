SVG icon component for the Apple App Store, rendering a 42×42 branded icon with a blue gradient background and white App Store logo using a unique gradient ID to avoid DOM conflicts.

## Key Components

- **`AppStore`** (default export) — Functional React component that renders the App Store SVG icon
- **`pathFillId`** — Unique ID generated via `lodash.uniqueId` to prevent `linearGradient` ID collisions when multiple instances are rendered on the same page

## Usage Example

```typescript
import AppStore from "./AppStore";

const MyComponent = () => (
  <div>
    <AppStore />
  </div>
);
```

## Notes

- Fixed dimensions: `42×42` pixels
- Gradient runs vertically from `#18bffb` (top) to `#2072f3` (bottom)
- No props accepted; non-configurable size/colors
