React SVG component that renders an illustrated empty state graphic for a hosts list, depicting a stylized computer/server setup with decorative elements.

## Key Components

**`EmptyHosts`** — A functional React component that returns a static SVG illustration (176×145px) used as a placeholder when no hosts are available in the Fleet MDM interface.

## Usage Example

```typescript
import EmptyHosts from "./EmptyHosts";

const HostsPage = ({ hosts }) => {
  if (hosts.length === 0) {
    return (
      <div className="empty-state">
        <EmptyHosts />
        <p>No hosts enrolled yet.</p>
      </div>
    );
  }
  return <HostList hosts={hosts} />;
};
```

## Notes

- Pure presentational component — no props, state, or side effects.
- Uses inline SVG paths with a palette of blues and purples (`#506E92`, `#E1E1FF`, `#C9D5F3`, `#F7F8FC`) consistent with Fleet MDM's design system.
- Contains a single `mixBlendMode: "soft-light"` inline style for a shadow/depth overlay effect.
- No external dependencies beyond React.
