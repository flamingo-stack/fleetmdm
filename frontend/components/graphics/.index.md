Barrel file that consolidates all graphic/SVG components into a single registry map for use throughout the Fleet MDM UI.

## Key Components

- **`GRAPHIC_MAP`** — A string-keyed object mapping graphic identifiers to their React components, organized into three categories:
  - **Empty state graphics** — Placeholder visuals for empty lists (queries, hosts, teams, policies, software, etc.)
  - **File type graphics** — Icons representing specific file formats (`.sh`, `.ps1`, `.py`, `.pdf`, `.pkg`, `.png`, `.p7m`, `.pem`, `.vpp`, configuration profiles, certificates)
  - **Other graphics** — Utility visuals (collecting results, data errors, calendar, lock, settings, Fleet logo)

- **`GraphicNames`** — A TypeScript union type automatically derived from the keys of `GRAPHIC_MAP`, ensuring type-safe graphic lookups.

## Usage Example

```typescript
import { GRAPHIC_MAP, GraphicNames } from "components/graphics";

// Type-safe graphic lookup
const graphicKey: GraphicNames = "empty-hosts";
const Graphic = GRAPHIC_MAP[graphicKey];

// Render in a component
const EmptyState = () => (
  <div>
    <Graphic />
    <p>No hosts found.</p>
  </div>
);

// Validate a key at compile time
function renderGraphic(name: GraphicNames) {
  const Component = GRAPHIC_MAP[name];
  return <Component />;
}
```
