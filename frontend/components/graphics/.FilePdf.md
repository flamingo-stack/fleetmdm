A React functional component that renders a PDF file icon as an inline SVG, styled with a document shape, folded corner, and a red "PDF" label badge.

## Key Components

- **`FilePdf`** — Default export. A stateless React component returning a hardcoded 34×40px SVG icon representing a PDF file.

## Usage Example

```typescript
import FilePdf from "./FilePdf";

const DocumentList = () => (
  <div>
    <FilePdf />
    <span>report.pdf</span>
  </div>
);
```

## Notes

- No props are accepted; size and colors are hardcoded in the SVG paths.
- Color palette: white document body (`#fff`), dark navy outline (`#192147`), light grey fold/shadow (`#C5C7D1`), and a red PDF badge (`#D66C7B`).
- The SVG is self-contained and renders inline — no external assets or icon libraries required.
