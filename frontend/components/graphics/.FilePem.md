SVG icon component representing a `.pem` file, used to visually indicate PEM certificate or key files in the Fleet MDM UI.

## Key Components

- **`FilePem`** — Functional React component that renders a styled SVG file icon with a dark banner labeled "PEM"
- **`clipPathId`** — Unique ID generated via `lodash.uniqueId` to prevent SVG `clipPath` collisions when multiple instances are rendered on the same page

## Usage Example

```typescript
import FilePem from "components/icons/FilePem";

const CertificateRow = () => (
  <div className="file-row">
    <FilePem />
    <span>my-certificate.pem</span>
  </div>
);
```

## Notes

- The SVG is fixed at `34×40px` and uses no external assets
- The `clipPath` unique ID pattern (`uniqueId("clip-path-")`) ensures safe reuse in lists or tables without DOM ID conflicts
- Styled with Fleet's color palette: dark navy (`#192147`), light gray (`#C5C7D1`), slate (`#515774`), and white
