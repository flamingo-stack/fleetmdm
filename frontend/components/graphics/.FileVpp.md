A React component that renders an SVG icon representing a VPP (Volume Purchase Program) file, displaying a stylized document with a dark banner and "vpp" text label.

## Key Components

- **`FileVpp`** — Default export; a functional React component that renders a 34×40px SVG file icon with a document shape, folded corner, and a dark footer badge displaying "vpp"
- **`clipPathId`** — A unique ID generated via `lodash.uniqueId` to prevent SVG `clipPath` collisions when multiple instances are rendered on the same page

## Usage Example

```typescript
import FileVpp from "components/FileVpp";

const FileList = () => (
  <div>
    <FileVpp />
    <span>App.vpp</span>
  </div>
);
```

## Notes

- No props are accepted; the icon is purely presentational with hardcoded dimensions and colors
- Uses `lodash.uniqueId` to namespace the internal `<clipPath>` `id`, making it safe to render multiple instances without DOM `id` conflicts
- Color palette: white document body (`#fff`), dark navy outline (`#192147`), medium grey corner fold (`#C5C7D1`), dark slate banner (`#515774`), white "vpp" label text
