Renders a decorative SVG illustration used to visually indicate a "collecting results" loading or empty state within the Fleet MDM UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CollectingResults` | React Functional Component | Renders a static SVG illustration with a unique `clipPath` ID |

## Usage Example

```typescript
import CollectingResults from "components/CollectingResults";

const QueryResults = () => {
  return (
    <div>
      <CollectingResults />
      <p>Waiting for hosts to report results...</p>
    </div>
  );
};
```

## Notes

- Uses `lodash.uniqueId` to generate a unique `clipPath` ID (`clip-path-N`), preventing conflicts when the component is rendered multiple times on the same page.
- The SVG is purely decorative (240×126px) and contains no interactive elements or accessibility attributes — consider adding `aria-hidden="true"` or an `aria-label` if used in a context where screen reader context matters.
- All colors use a palette of soft purples/blues (`#F1F1FD`, `#D7DAF5`, `#B0B2E7`) consistent with Fleet's design system.
