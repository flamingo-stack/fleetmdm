A React SVG icon component that renders a file certificate icon — a document with a decorative gold badge/seal overlay.

## Key Components

- **`FileCertificate`** *(default export)* — Stateless functional component returning a 34×41px SVG icon with:
  - A white document shape with a dark border and folded corner
  - A gold gradient circular badge with a brown checkmark
  - Unique IDs for the `clipPath` and `linearGradient` definitions, generated via `lodash.uniqueId` to prevent conflicts when multiple instances render on the same page

## Usage Example

```typescript
import FileCertificate from "./FileCertificate";

const MyComponent = () => (
  <div>
    <FileCertificate />
  </div>
);
```

## Notes

- **No props** — the component is not currently configurable (size, color, etc. are hardcoded).
- `uniqueId` from `lodash` ensures SVG definition IDs (`clip-path-*`, `linear-gradient-*`) are globally unique, preventing visual artifacts when the icon appears multiple times on a page.
- The gold badge uses a vertical `linearGradient` from `#FFED5B` to `#E8AD06`.
