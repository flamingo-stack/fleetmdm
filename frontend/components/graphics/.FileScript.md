A React component that renders an SVG icon representing a script file, featuring a document shape with a decorative script/pen illustration.

## Key Components

- **`FileScript`** — Default export. A functional React component that renders a 34×40px SVG icon depicting a document with a script/writing motif.

## Notable Implementation Details

- Uses `uniqueId` from `lodash` to generate unique `clipPath` IDs (`clip-path-a`, `clip-path-b`), preventing DOM conflicts when multiple instances of the icon are rendered on the same page.
- The SVG uses two clip paths: one for the overall document boundary and one for the inner script illustration area.

## Usage Example

```typescript
import FileScript from "./FileScript";

const FileListItem = () => (
  <div className="file-item">
    <FileScript />
    <span>script.sh</span>
  </div>
);
```
