A React component that renders an empty search state using an exclamation mark variant.

## Key Components

- **`EmptySearchExclamation`** (default export) — Functional component that delegates to `renderEmptySearch` with the `"exclamation"` variant string.
- **`renderEmptySearch`** — Imported utility from [`EmptySearchQuestion.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/EmptySearchQuestion.tsx) that handles the actual rendering logic for empty search states.

## Usage Example

```typescript
import EmptySearchExclamation from "./EmptySearchExclamation";

const SearchResults = ({ results }) => {
  if (results.length === 0) {
    return <EmptySearchExclamation />;
  }
  return <ResultsList results={results} />;
};
```
