Renders a decorative SVG illustration used as an empty-state graphic for the policies list view, depicting a shield/policy icon above a placeholder table row.

## Key Components

- **`EmptyPolicies`** — Default-exported React functional component that returns a static SVG element (322×176px) with dynamically generated unique IDs for its `clipPath` and `filter` definitions, preventing ID collisions when multiple instances are rendered.

## Usage Example

```typescript
import EmptyPolicies from "./EmptyPolicies";

const PoliciesPage = () => (
  <div>
    {policies.length === 0 && (
      <div className="empty-state">
        <EmptyPolicies />
        <p>No policies have been added yet.</p>
      </div>
    )}
  </div>
);
```

## Notes

- Uses `lodash.uniqueId` to generate unique `clipPath` and `filter` IDs at render time, ensuring SVG `<defs>` references remain unique across the DOM — important when the component could appear more than once on a page.
- The SVG is purely presentational with no props or interactivity; styling is baked into the SVG attributes.
