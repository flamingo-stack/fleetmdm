A React component that renders an SVG illustration used as an empty state graphic for the users list view.

## Key Components

- **`EmptyUsers`** — Functional component that returns a styled SVG (322×150px) depicting a placeholder card layout with muted text bars, a circular background, and a subtle drop shadow effect.
- **`clipPathId` / `filterId`** — Unique IDs generated via lodash `uniqueId` to prevent SVG `clipPath` and `filter` definition collisions when multiple instances render on the same page.

## Usage Example

```typescript
import EmptyUsers from "components/EmptyUsers";

const UsersPage = () => (
  <div className="empty-state">
    <EmptyUsers />
    <p>No users found.</p>
  </div>
);
```

## Notes

- No props are accepted; the component is purely presentational.
- The SVG includes a drop shadow filter (`feGaussianBlur`, `feColorMatrix`, `feBlend`) applied to the card shape, and decorative horizontal bars in varying shades to simulate placeholder text rows.
- Unique IDs are scoped at render time, making the component safe for repeated use within a single document without SVG definition conflicts.
