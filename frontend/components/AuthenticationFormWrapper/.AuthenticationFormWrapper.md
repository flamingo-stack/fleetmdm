A layout wrapper component for authentication-related pages (login, registration, etc.) that renders a consistent shell with navigation, org logo, optional breadcrumbs, and a styled card container.

## Key Components

### `AuthenticationFormWrapper`
Default export. A presentational wrapper that provides:
- **Top navigation bar** — renders the org logo icon using `OrgLogoIcon` with the Fleet avatar as its source.
- **Breadcrumbs slot** — optional node rendered above the card (used on the registration page).
- **Card** — a rounded, padded `Card` component containing an optional `CardHeader` + CTA row, followed by `children`.

### `IAuthenticationFormWrapperProps`
| Prop | Type | Description |
|---|---|---|
| `children` | `React.ReactNode` | Form content rendered inside the card |
| `header` | `string` | Optional card heading text |
| `headerCta` | `React.ReactNode` | Optional action element rendered beside the header |
| `breadcrumbs` | `React.ReactNode` | Optional breadcrumb node (registration page only) |
| `className` | `string` | Additional CSS class merged onto the wrapper `div` |

## Usage Example

```typescript
import AuthenticationFormWrapper from "components/AuthenticationFormWrapper";

const LoginPage = () => (
  <AuthenticationFormWrapper
    header="Sign in to Fleet"
    headerCta={<a href="/register">Create account</a>}
  >
    <LoginForm />
  </AuthenticationFormWrapper>
);

// With breadcrumbs (registration page)
const RegisterPage = () => (
  <AuthenticationFormWrapper
    header="Create your account"
    breadcrumbs={<Breadcrumbs steps={["Home", "Register"]} />}
  >
    <RegistrationForm />
  </AuthenticationFormWrapper>
);
```
