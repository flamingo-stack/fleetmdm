Renders a styled description paragraph for pages or sections, with optional variant-based styling for cards, tab panels, right panels, and modals.

## Key Components

### `PageDescription`
Default export component that wraps content in a `<p>` tag with CSS class handling based on the provided variant.

**Props (`IPageDescription`):**

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `React.ReactNode` | ✅ | The description content to render |
| `variant` | `"card" \| "tab-panel" \| "right-panel" \| "modal"` | ❌ | Applies section-level description styling |
| `className` | `string` | ❌ | Additional CSS classes |

**CSS Classes:**
- Base: `page-description`
- Section variant: `page-description__section-description` (applied when `variant` is one of the section variants)

## Usage Example

```typescript
// Page-level description (no variant)
<PageDescription content="Manage your organization's devices and policies." />

// Section-level description inside a card
<PageDescription
  variant="card"
  content="Configure settings for this integration."
/>

// With additional custom class
<PageDescription
  variant="modal"
  className="custom-modal-description"
  content={<span>Description with <strong>rich content</strong></span>}
/>
```
