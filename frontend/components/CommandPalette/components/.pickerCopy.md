Utility that generates a contextual fleet suffix string for picker empty-state messages based on the currently selected team.

## Key Components

- **`getFleetSuffix(currentTeam?)`** — Default export. Accepts an optional `ITeamSummary` and returns a trailing phrase string based on team context:

| Team State | Input | Output |
|---|---|---|
| Real team | `id > 0` | `" in <team name>"` |
| Unassigned | `id === 0` (`APP_CONTEXT_NO_TEAM_ID`) | `" in this fleet"` |
| All fleets | `id === -1` | `""` |
| Undefined | `undefined` | `""` |

## Usage Example

```typescript
import getFleetSuffix from "./pickerCopy";

const currentTeam = { id: 3, name: "Engineering" };
const message = `No reports found${getFleetSuffix(currentTeam)}.`;
// → "No reports found in Engineering."

const noTeam = { id: 0, name: "" };
const fallback = `No reports found${getFleetSuffix(noTeam)}.`;
// → "No reports found in this fleet."

const allFleets = `No reports found${getFleetSuffix(undefined)}.`;
// → "No reports found."
```

## Notes

- Mirrors the empty-state suffix convention used in `EmptyVulnerabilitiesTable` across the codebase.
- `APP_CONTEXT_NO_TEAM_ID` (value `0`) represents hosts not assigned to any team.
- The all-fleets context (`id === -1`) intentionally omits a suffix since scope is already global.
