Renders a text label with matched query substrings wrapped in `<mark>` elements, enabling visual search highlighting within command palette results.

## Key Components

- **`HighlightedLabel`** — Default export. A presentational component that splits `text` into matched/unmatched segments using `highlightMatches` and wraps matched portions in `<mark className="command-palette__item-label-match">` elements.
- **`IHighlightedLabelProps`** — Interface requiring `text` (the full label string) and `query` (the current search input).
- **`highlightMatches`** — Helper imported from `../helpers` that returns an array of `{ text, matched }` segments.

## Usage Example

```typescript
import HighlightedLabel from "./HighlightedLabel";

// Renders "Fleet" with "lee" highlighted in a <mark> element
<span className="result-item">
  <HighlightedLabel text="FleetMDM" query="lee" />
</span>
```

The component renders a React Fragment, so the caller is responsible for any wrapping element or additional styling. Index-based keys are intentionally used since segments are derived synchronously and their order is stable per render.

## Notes

- Matched segments: `<mark className="command-palette__item-label-match">`
- Unmatched segments: `<React.Fragment>`
- No state or side effects — purely derived from props each render.
