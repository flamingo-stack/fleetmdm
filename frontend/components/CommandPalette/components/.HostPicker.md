Renders a searchable list of Fleet hosts inside the command palette, fetching results via the hosts API and highlighting matched text.

## Key Components

### `HostPicker` (default export)
A React component that displays a `cmdk` `Command.Group` of host results. It debounces the caller-supplied search string, fetches up to 50 hosts sorted by display name, and calls `onSelect` with the selected host's ID.

### `IHostPickerProps`
| Prop | Type | Description |
|---|---|---|
| `search` | `string` | Live search string passed from the parent palette. |
| `showTeamColumn` | `boolean` | When `true`, renders the host's team name in a third column (premium-tier, non-Primo installs). |
| `onSelect` | `(hostId: number) => void` | Callback fired when a host row is chosen. |

### Internal behaviour
- **`usePickerSearch`** — handles debouncing, React Query caching, and loading state.
- **`HighlightedLabel`** — bolds the matched substring within the host display name.
- **`UprightEmoji`** — renders the team name with correct emoji orientation.
- A coloured status dot (`online` / `offline` / `missing`) is rendered via a BEM modifier class and an `aria-label`.
- No team scoping is applied to the query; the parent navigates to `/hosts/:id/details` and the host details page reads team context from the host record.

## Usage Example

```typescript
import HostPicker from "components/CommandPalette/HostPicker";
import { useNavigate } from "react-router-dom";

const CommandPalette = () => {
  const navigate = useNavigate();
  const [search, setSearch] = React.useState("");

  const handleSelectHost = (hostId: number) => {
    navigate(`/hosts/${hostId}/details`);
  };

  return (
    <HostPicker
      search={search}
      showTeamColumn={isPremiumTier}
      onSelect={handleSelectHost}
    />
  );
};
```

## Notes
- `HOST_SEARCH_LIMIT` is fixed at `50`; no pagination is exposed.
- Loading and empty states render outside the `Command.Group` to avoid empty group artifacts in `cmdk`.
