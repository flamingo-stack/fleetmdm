A command palette picker component that searches and displays Fleet policies, supporting both global and team-scoped policy lookups with badge indicators for critical, patch, and inherited policies.

## Key Components

### `PolicyPicker` (default export)
A React component rendering a `cmdk` `Command.Group` of searchable policy results.

**Props (`IPolicyPickerProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `search` | `string` | Current search query string |
| `currentTeam` | `ITeamSummary?` | Active team context; `undefined` or `APP_CONTEXT_ALL_TEAMS_ID` triggers global policy lookup |
| `isPremiumTier` | `boolean` | Enables the critical policy badge (Premium-only) |
| `onSelect` | `(policyId: number) => void` | Callback fired when a policy item is selected |

### Key Behaviors
- **Team vs. global scoping** — Uses `teamPoliciesAPI` when a specific team is active (with `mergeInherited: true` to surface global policies), falls back to `globalPoliciesAPI`
- **Debounced search** — Delegated to `usePickerSearch` hook with a limit of 50 results
- **Badge rendering** — Conditionally shows `CriticalPolicyBadge`, `PillBadge` (Patch), or `PillBadge` (Inherited) per policy
- **Loading/empty states** — Renders contextual messages during load or when no results match

## Usage Example

```typescript
import PolicyPicker from "./PolicyPicker";

<PolicyPicker
  search={inputValue}
  currentTeam={activeTeam}
  isPremiumTier={true}
  onSelect={(policyId) => {
    // Navigate to or act on the selected policy
    router.push(`/policies/${policyId}`);
  }}
/>
```
