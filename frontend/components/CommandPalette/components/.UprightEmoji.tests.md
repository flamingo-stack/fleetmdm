Test suite for the `UprightEmoji` component and its `splitEmojiSegments` utility, validating emoji grapheme segmentation logic and correct DOM rendering of upright emoji spans.

## Key Components

- **`splitEmojiSegments` tests** — Covers the text segmentation utility across edge cases including plain text, emoji prefixes, adjacent emoji coalescing, mid-string emoji, ZWJ sequences, skin tone modifiers, regional indicator flag pairs, and trailing emoji.
- **`UprightEmoji` component tests** — Validates rendering behavior: plain text renders without `<span>` elements, emoji segments are wrapped in a `<span>` with `font-style: normal`, adjacent emoji coalesce into a single span, and ZWJ sequences are preserved as one span.

## Usage Example

```typescript
import { splitEmojiSegments } from "./UprightEmoji";

// Segment a string containing emoji
splitEmojiSegments("💻 Workstations");
// → [{ text: "💻", isEmoji: true }, { text: " Workstations", isEmoji: false }]

// ZWJ sequences are treated as a single grapheme
splitEmojiSegments("👨‍💻 Engineering");
// → [{ text: "👨‍💻", isEmoji: true }, { text: " Engineering", isEmoji: false }]

// Flag emoji (regional indicator pairs) coalesce correctly
splitEmojiSegments("\u{1F1FA}\u{1F1F8} US fleet");
// → [{ text: "🇺🇸", isEmoji: true }, { text: " US fleet", isEmoji: false }]
```

## Notes

- All segmentation tests rely on Unicode grapheme cluster boundaries, ensuring multi-codepoint sequences (ZWJ, skin tone modifiers, flag pairs) are never split across segments.
- The rendering tests confirm that non-emoji text is output as raw text nodes — no unnecessary DOM wrapper elements — while emoji segments receive an inline `<span style="font-style: normal">` to prevent italicization in italic contexts.
