Renders text with emoji glyphs staying upright when the surrounding element applies `font-style: italic`, preventing browsers from applying synthetic slant to emoji characters.

## Key Components

- **`EMOJI_RUN_RE`** — Unicode regex matching emoji grapheme clusters, including ZWJ sequences (e.g. 👨‍💻), variation selectors (`\uFE0F`), and regional indicator pairs (flag emoji like 🇺🇸)
- **`IEmojiSegment`** — Interface describing a text segment with `text: string` and `isEmoji: boolean`
- **`splitEmojiSegments(text)`** — Exported pure helper that splits a string into alternating emoji/non-emoji segments; adjacent emoji runs are coalesced into a single segment
- **`UprightEmoji`** — Default export React component wrapping emoji runs in `<span style={{ fontStyle: "normal" }}>` while leaving non-emoji text unstyled

## Usage Example

```typescript
import UprightEmoji, { splitEmojiSegments } from "./UprightEmoji";

// Inside an italicized context — emoji stays upright:
const FleetName = ({ name }: { name: string }) => (
  <em>
    <UprightEmoji text="📱 My Fleet 🔐" />
  </em>
);

// Pure helper for testing or pre-processing:
splitEmojiSegments("Hello 🌍!");
// → [
//     { text: "Hello ", isEmoji: false },
//     { text: "🌍",     isEmoji: true  },
//     { text: "!",      isEmoji: false },
//   ]
```

> **Note:** Use `UprightEmoji` anywhere user-provided strings containing emoji appear inside italicized surfaces (e.g. fleet names, device labels). Without it, synthetic italic shearing distorts emoji rendering across most browsers.
