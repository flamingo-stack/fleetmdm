Test suite for the `PolicyPicker` component, verifying API routing logic, empty-state messaging, and badge rendering based on team context and policy type.

## Key Components

| Export/Symbol | Purpose |
|---|---|
| `PolicyPicker` (SUT) | The component under test — a command-palette policy picker |
| `renderPicker` | Thin wrapper around `createCustomRenderer` with backend mock enabled |
| `renderPickerInCommand` | Wraps the picker in a `cmdk` `Command` root (required for `Command.Item` rendering) |
| `policyWith` | Factory helper that builds a minimal `IPolicyStats` fixture from partial fields |
| `mockedGlobal` / `mockedTeam` | Typed Jest mocks for `globalPoliciesAPI.loadAllNew` and `teamPoliciesAPI.loadAllNew` |

## Test Coverage

| Scenario | Assertion |
|---|---|
| `currentTeam.id === -1` ("All fleets") | Only `globalPoliciesAPI.loadAllNew` is called |
| `currentTeam.id > 0` (real team) | `teamPoliciesAPI.loadAllNew` called with `{ teamId, mergeInherited: true }` |
| `currentTeam.id === 0` ("No team") | `teamPoliciesAPI.loadAllNew` called with `{ teamId: 0 }` |
| Empty results — named team | Renders `"No policies found in <TeamName>."` |
| Empty results — Unassigned | Renders `"No policies found in this fleet."` |
| Empty results — All fleets | Renders `"No policies found."` |
| Search with no results — All fleets | Renders `"No policies match \"<query\>\"."` |
| `policy.type === "patch"` | "Patch" badge is present |
| `policy.type !== "patch"` | "Patch" badge is absent |

## Usage Example

```typescript
// Running the full suite
jest --testPathPattern="PolicyPicker.tests"

// Adding a new test — use a unique `search` prop to avoid
// React Query cache collisions with prior empty-state tests
it("renders the Critical badge", async () => {
  mockedGlobal.loadAllNew.mockResolvedValue({
    policies: [policyWith({ id: 3, name: "FileVault", critical: true })],
  });

  const { findByText } = renderPickerInCommand(
    <PolicyPicker
      search="critical-unique-key"
      currentTeam={{ id: -1, name: "All fleets" }}
      onSelect={jest.fn()}
    />
  );

  expect(await findByText("Critical")).toBeInTheDocument();
});
```

> **Note:** Each test that renders policies must use a unique `search` prop value. React Query caches results by `["commandPalettePolicies", ..., "<search>"]`, so reusing a search string populated by a prior empty-state test will suppress the mocked data.
