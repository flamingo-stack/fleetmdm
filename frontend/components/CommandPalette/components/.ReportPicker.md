A command palette picker component that renders a searchable list of Fleet reports (queries), with support for team scoping, observer permissions, and inherited report badges.

## Key Components

- **`ReportPicker`** — Default export; a `Command.Group` that lists selectable reports filtered by search input and team context
- **`IReportPickerProps`** — Props interface defining `search`, `currentTeam`, `isViewerObserver`, and `onSelect`
- **`usePickerSearch`** — Custom hook handling debounced search, query caching, and data fetching via `queriesAPI.loadAll`
- **`HighlightedLabel`** — Highlights matching characters in report names against the debounced query string
- **Observer icon** — Shown (via `TooltipWrapper`) only when the current viewer is *not* an observer but the report supports observer execution
- **Inherited badge** — `PillBadge` shown when viewing a specific team and the report belongs to a different scope (e.g., global)

## Usage Example

```typescript
import ReportPicker from "./ReportPicker";

<ReportPicker
  search={inputValue}
  currentTeam={{ id: 42, name: "Engineering" }}
  isViewerObserver={false}
  onSelect={(reportId) => {
    router.push(`/queries/${reportId}`);
  }}
/>
```

## Behavior Notes

- Displays `"Looking for reports..."` while the initial fetch is in flight
- Displays `"No reports match '...'"` or `"No reports found"` (with an optional team suffix) when results are empty
- Fetches up to `50` reports per search (`REPORT_SEARCH_LIMIT`), ordered by name ascending, with inherited (global) reports merged in
- Team ID resolves to `undefined` when "All Teams" context is active, making the query global
