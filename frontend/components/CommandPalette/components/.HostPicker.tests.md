Test suite for the `HostPicker` command-palette component, verifying API call behavior, empty states, and column rendering.

## Key Components

- **`renderPicker`** — Wraps the component under test in a `cmdk` `Command` root (required context for `Command.Item` to render correctly)
- **`emptyHostsResponse` / `hostsResponseWith`** — Typed fixture helpers that construct minimal `ILoadHostsResponse` objects for mock API responses
- **`mockedHosts.loadHosts`** — Jest mock of `hostsAPI.loadHosts`, reset before each test to an empty result

## Test Coverage

| Test | Assertion |
|---|---|
| Global navigator (no team) | `teamId` key is entirely absent from `loadHosts` call args |
| Search passthrough | `globalFilter` and `sortBy: display_name asc` forwarded correctly |
| Empty state (no search) | Renders `"No hosts found."` |
| Empty state (search) | Renders `"No hosts match <query>."` |
| Status dot | Presentational span with `--online` BEM modifier exists; no status text |
| Team column (enabled) | Team name rendered when `showTeamColumn` prop is set |
| Team column (default off) | Team name suppressed without `showTeamColumn` |
| Highlight | Matched substring wrapped in `mark.command-palette__item-label-match` |

## Usage Example

```typescript
// Running the suite
npx jest HostPicker.tests.tsx

// Adding a new column test — use a unique search string to avoid
// React Query cache collisions with earlier test registrations
it("renders platform icon", async () => {
  mockedHosts.loadHosts.mockResolvedValue(hosts);
  const { findByText, container } = renderPicker(
    <HostPicker search="col-platform-test" onSelect={jest.fn()} />
  );
  await findByText("Rachel's MacBook");
  expect(container.querySelector(".platform-icon")).toBeInTheDocument();
});
```

> **Cache isolation note:** React Query's `QueryClient` persists across tests in this file. Each column test uses a unique `search` string to force a fresh `queryFn` invocation and avoid stale empty-result cache hits from earlier tests.
