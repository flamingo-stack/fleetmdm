Shared hook providing debounced search input and server-side query management for command-palette picker components, combining a 200 ms debounce with React Query caching optimized for short-lived picker UI.

## Key Components

- **`DEBOUNCE_MS`** — 200 ms debounce delay constant applied to raw search input before triggering queries
- **`IUsePickerSearchOptions<TResponse, TItem>`** — Generic options interface accepting a query key prefix, fetch function, and item selector
- **`usePickerSearch<TResponse, TItem>`** — Default export; the core hook that wires debounce state, React Query fetching, and item extraction together

### Return Values

| Property | Type | Description |
|---|---|---|
| `items` | `TItem[]` | Extracted display items from the query response |
| `isLoading` | `boolean` | React Query loading state |
| `debouncedQuery` | `string` | Resolved debounced search string (used for empty-state copy in consumers) |

## Usage Example

```typescript
const { items, isLoading, debouncedQuery } = usePickerSearch({
  search: rawInputValue,
  queryKeyPrefix: ["commandPaletteHosts", teamId],
  queryFn: (query) => hostsAPI.search({ query }),
  selectItems: (data) => data?.hosts ?? [],
});
```

## Notes

- The `queryKeyPrefix` **must be an array** — spreading a bare string would iterate its characters into the cache key
- Cache behavior is tuned for picker lifecycles: `staleTime` of 30 s and a reduced `cacheTime` of 60 s (vs. React Query's 5-minute default) to avoid accumulating stale `(team, query)` tuples across a long session
- `keepPreviousData: true` prevents flicker between keystrokes
