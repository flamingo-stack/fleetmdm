A command palette picker component that renders a searchable list of Fleet MDM teams using the `cmdk` library, highlighting matched text and marking the currently selected team.

## Key Components

- **`FleetPicker`** — Default export. Renders a `cmdk` `Command.Group` of team items with search-aware empty states.
- **`IFleetPickerProps`** — Interface defining the component's props:
  - `availableTeams` — Optional list of `ITeamSummary` objects to display.
  - `currentTeam` — The currently active team (used to apply selected styling).
  - `search` — Current search query string, passed to `HighlightedLabel` for match highlighting.
  - `onSelect` — Callback invoked with the selected team's numeric ID.
- **`HighlightedLabel`** — Sub-component that highlights the matching portion of a team name based on the search query.
- **`Command.Empty`** — Auto-renders when all items are filtered out, showing contextual copy (`"No fleets match..."` vs. `"No fleets found."`).

## Usage Example

```typescript
import FleetPicker from "components/FleetPicker";
import { ITeamSummary } from "interfaces/team";

const teams: ITeamSummary[] = [
  { id: 1, name: "Engineering" },
  { id: 2, name: "Marketing" },
];

<FleetPicker
  availableTeams={teams}
  currentTeam={teams[0]}
  search="eng"
  onSelect={(fleetId) => console.log("Selected fleet:", fleetId)}
/>
```

> **Note:** `FleetPicker` is designed to be embedded within a `cmdk` `Command` root (e.g., `CommandPalette`). The parent is expected to suppress its own `Command.Empty` when this picker is active, since `FleetPicker` owns its empty state copy.
