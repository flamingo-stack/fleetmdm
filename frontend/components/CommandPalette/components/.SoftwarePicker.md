A command palette picker component for searching and selecting software titles, supporting both inventory and library scopes with debounced search and team-aware filtering.

## Key Components

### `SoftwarePicker`
The main exported React component that renders a `cmdk` `Command.Group` of searchable software titles. Accepts the following props:

| Prop | Type | Description |
|------|------|-------------|
| `search` | `string` | Current search query string |
| `currentTeam` | `ITeamSummary?` | Active team context for scoped queries |
| `scope` | `SoftwareScope` | `"inventory"` (default) or `"library"` |
| `onSelect` | `(id: number) => void` | Callback fired when a title is selected |

### `getInstallerProps`
Internal helper that derives install-icon tooltip props from an `ISoftwareTitle`. Returns `null` when no installer (`software_package` or `app_store_app`) is attached to the title.

### `usePickerSearch`
Imported hook handling debounced API calls via `softwareAPI.getSoftwareTitles`, keyed by scope and team. Returns `items`, `isLoading`, and `debouncedQuery`.

## Usage Example

```typescript
import SoftwarePicker from "./SoftwarePicker";

<SoftwarePicker
  search={inputValue}
  currentTeam={selectedTeam}
  scope="library"
  onSelect={(softwareId) => {
    router.push(`/software/${softwareId}`);
  }}
/>
```

Each result renders a highlighted software name, an optional install-status icon, and a software type label (e.g., "macOS app"). Empty and loading states are handled inline with scoped messages like `No software in Acme's library.`
