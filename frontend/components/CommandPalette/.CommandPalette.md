Renders a keyboard-driven command palette (⌘K / Ctrl+K) for the Fleet MDM interface, enabling quick navigation, fleet switching, and contextual actions based on the current user's role and team.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CommandPalette` | `React.FC` | Main component rendering the full palette UI via `cmdk` and Radix Dialog |
| `HighlightSubscriber` | Internal component | Bridges `cmdk`'s internal store highlight state to React via `useCommandState` |
| `getUniqueItemValue` | Helper function | Generates stable, unique `cmdk` row identity strings from item id + label + keywords |
| `getUniqueSubItemValue` | Helper function | Same as above for sub-items |
| `Page` | Type alias | Union of palette page states: `"root"`, `"switch-fleet"`, `"view-host"`, `"view-software"`, etc. |

### Sub-components (rendered per page)

- **`FleetPicker`** — team/fleet switcher (⌘⇧F shortcut)
- **`HostPicker`** — host search and navigation
- **`SoftwarePicker`** — software inventory/library search
- **`ReportPicker`** — query/report navigation
- **`PolicyPicker`** — policy navigation
- **`HighlightedLabel`** — renders fuzzy-match highlights
- **`UprightEmoji`** — accessibility-safe emoji rendering

## Usage Example

The palette is a global singleton; mount it once at the app root. It self-registers keyboard listeners.

```typescript
// App.tsx
import CommandPalette from "components/CommandPalette";

const App = () => (
  <>
    <Router />
    <CommandPalette />
  </>
);
```

Keyboard shortcuts (auto-registered):

```text
⌘K / Ctrl+K       — Toggle palette open/close
⌘⇧F / Ctrl+Shift+F — Jump directly to fleet switcher (premium, multi-fleet only)
Backspace          — Return to root from any picker page (when search is empty)
Escape             — Return to root from picker page (overrides dialog close)
```

## Role-Gating Summary

Access to palette items is derived from `AppContext` permissions. Key gates:

| Capability | Required Role |
|-----------|--------------|
| `canWrite` | Global/Team Admin, Maintainer, or Technician |
| `canAddSoftware` | Global/Team Admin or Maintainer (scoped to `currentTeam`) |
| `canRunLiveReport` | `canWrite` OR Observer Plus |
| `canManagePolicyAutomations` | Global Admin or Team Admin |
| `canAccessSettings` | Global Admin only |
