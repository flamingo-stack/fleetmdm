Builds the list of command palette items for the Settings group, filtering entries based on the current user's access level (`canAccessSettings`), tier (`isPremiumTier`), and deployment mode (`isPrimoMode`).

## Key Components

### `buildSettingsItems(ctx: ICommandPaletteContext): ICommandItem[]`

The sole export. Accepts a context object and returns a flat array of `ICommandItem` entries covering:

| Group | Items |
|---|---|
| Organization settings | Info, web address, SMTP, agents, statistics, Fleet Desktop, advanced |
| Integrations | Ticket destinations, MDM, calendars†, change management†, SSO (Fleet users), SSO (end users)†, certificate authorities†, IdP†, host status webhook, conditional access† |
| Users | User management |
| Fleets | Multi-fleet management†‡ |

† Premium tier only (`isPremiumTier === true`)
‡ Hidden in Primo Mode (`isPrimoMode === false` required)

## Usage Example

```typescript
import buildSettingsItems from "components/CommandPalette/commands/settings";

const items = buildSettingsItems({
  canAccessSettings: true,   // global admin
  isPremiumTier: true,       // unlock premium-only entries
  isPrimoMode: false,        // show Fleets tab
});

// items[0] → Organization settings (with subItems)
// items[1] → Integrations (with subItems, all premium entries included)
// items[2] → Users
// items[3] → Fleets
```

If `canAccessSettings` is `false`, an empty array is returned immediately — no settings entries are exposed to non-admins.
