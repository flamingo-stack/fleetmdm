Brief description: Builds the command palette "Commands" group items array, mapping user permissions, tier, and context to actionable navigation entries for the Fleet MDM command palette.

## Key Components

**`buildCommandsItems(ctx, derived)`**
The sole export. Accepts a `ICommandPaletteContext` and `IDerivedContext`, returns a filtered `ICommandItem[]` array for the "Commands" palette group.

### Permission Gates

| Gate | Controls |
|---|---|
| `canWrite` | Add hosts, reports, policies, scripts |
| `canAddSoftware` | Software add actions (FMA, VPP, Android, custom package) |
| `canEditCustomVariable` | Add custom variable entry |
| `isTechnician` | Hides scripts/variables section |
| `isPremiumTier` | Software library, software add actions |
| `canRunLiveReport` | Live query/report commands |
| `canAccessSettings` | Settings navigation entries |

### Command Categories

- **View commands** — `view-host`, `view-software`, `view-software-library`, `view-report`, `view-policy` (open picker pages)
- **Write actions** — `add-hosts`, `add-report`, `add-policy`, software additions, `add-script`, `add-custom-variable`
- **Packs** — conditionally shown via regex on search string (`/packs|create new pack|add new pack/`)

## Usage Example

```typescript
import { buildCommandsItems } from "./commands";
import { buildDerivedContext } from "./derivations";

const derived = buildDerivedContext(ctx);
const items = buildCommandsItems(ctx, derived);

// items is ICommandItem[] — pass directly to palette renderer
items.forEach(item => {
  console.log(item.id, item.path ?? "(action)");
});
```

## Notes

- All paths are wrapped with `withTeamId(...)` to preserve active team context in URLs.
- `opensPickerPage: true` marks view-commands that open a secondary search layer rather than navigating directly.
- Software add entries require **both** `isPremiumTier && hasTeamOrUnassigned && canAddSoftware` to appear.
