Builds the list of command palette items for the **Software** section, mapping navigation paths and search keywords to software-related routes.

## Key Components

- **`buildSoftwareItems(ctx, derived)`** — Factory function that returns an array of `ICommandItem` entries for the Software group. Conditionally includes the Software Library item based on premium tier and team context.

| Item ID | Label | Condition |
|---|---|---|
| `software` | Software inventory | Always |
| `software-os` | Operating systems | Always |
| `software-vulnerabilities` | Vulnerabilities | Always |
| `software-library` | Software library | Premium + team/unassigned only |

## Usage Example

```typescript
import buildSoftwareItems from "./software";

const items = buildSoftwareItems(
  {
    isPremiumTier: true,
    withTeamId: (path) => `${path}?team_id=1`,
  },
  {
    hasTeamOrUnassigned: true,
  }
);

// Returns command items including Software Library with sub-items
// for Self-service categories
```

## Notes

- **Sub-items** — `software` nests "Software versions" and "Vulnerable software"; `software-library` nests "Self-service categories".
- **Team scoping** — All paths are wrapped with `withTeamId()` to preserve the active team filter.
- **Library gate** — `software-library` is only included when `isPremiumTier && hasTeamOrUnassigned`, as the library is unavailable in the "All fleets" context.
