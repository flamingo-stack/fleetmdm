Builds and returns the list of MDM-related command palette items, conditionally surfacing "turn on" or "edit" actions for Apple, Windows, and Android MDM based on the current user's access level and MDM configuration state.

## Key Components

### `buildMdmItems(ctx, derived): ICommandItem[]`

The sole export. Accepts a `ICommandPaletteContext` and `IDerivedContext` and returns an array of `ICommandItem` objects grouped under `"MDM"`.

**Context flags consumed:**

| Flag | Effect |
|---|---|
| `canAccessSettings` | Returns `[]` if `false` (global-admin guard) |
| `isMacMdmEnabledAndConfigured` | Toggles "Turn on" vs "Edit" Apple MDM item |
| `isPremiumTier` | Gates ABM and VPP items |
| `isAbmConfigured` | Toggles "Add" vs "Edit" Apple Business Manager item |
| `isVppEnabled` | Toggles "Add" vs "Edit" VPP item |
| `isWindowsMdmEnabledAndConfigured` | Toggles "Turn on" vs "Edit" Windows MDM + Entra enrollment item |
| `isAndroidMdmEnabledAndConfigured` | Toggles "Turn on" vs "Edit" Android MDM item |

## Usage Example

```typescript
import buildMdmItems from "./mdm";

const items = buildMdmItems(commandPaletteContext, derivedContext);
// items is an ICommandItem[] ready to be merged into the full command palette
```

## Notes

- Returns an empty array immediately when `canAccessSettings` is `false` — no MDM commands are exposed to non-admins.
- ABM and VPP items are only included on Premium tier and only when Apple MDM is already configured.
- The Windows Entra automatic enrollment item only appears once Windows MDM is active.
