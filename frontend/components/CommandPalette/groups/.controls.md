Builds the list of command palette items for the **Controls** section, applying permission and tier gates before returning navigable entries.

## Key Components

- **`buildControlsItems(ctx, derived)`** — Default export. Accepts a `ICommandPaletteContext` and `IDerivedContext`, returns a filtered `ICommandItem[]` for the Controls group.

### Gate conditions

| Condition | Effect |
|---|---|
| `!canAccessControls` | Returns empty array (admins, maintainers, technicians only) |
| `!hasTeamOrUnassigned` | Returns empty array (Controls doesn't support "All fleets") |
| `!isPremiumTier` | Excludes OS updates, Disk encryption, Certificates, Passwords, Setup experience |
| `isTechnician` | Excludes Certificates and Passwords even on Premium |

### Items produced (when all gates pass)

- **OS updates** *(Premium)* — `controls-os-updates`
- **OS settings** — `controls-os-settings`, with sub-items:
  - Disk encryption *(Premium)*
  - Configuration profiles
  - Certificates *(Premium, non-technician)*
  - Passwords *(Premium, non-technician)*
- **Setup experience** *(Premium)* — `controls-setup-experience`, with sub-items: Users, Bootstrap package, Install software, Run script, Setup Assistant
- **Scripts** — `controls-scripts`, with sub-items: Script library, Script batch progress
- **Variables** — `controls-variables`

## Usage Example

```typescript
import buildControlsItems from "./controls";

const items = buildControlsItems(
  {
    canAccessControls: true,
    isPremiumTier: true,
    isTechnician: false,
    withTeamId: (path) => `${path}?team_id=1`,
  },
  { hasTeamOrUnassigned: true }
);

// items[0] => { id: "controls-os-updates", label: "OS updates", ... }
```
