Computes and caches shared contextual values used by all command palette group builders, avoiding repeated derivation logic across individual builders.

## Key Components

### `IDerivedContext` Interface
Exposes seven pre-computed flags and chip labels:

| Field | Type | Description |
|-------|------|-------------|
| `isAbmConfigured` | `boolean` | Apple Business Manager enabled at org level |
| `isGitOpsMode` | `boolean` | GitOps mode active; disables write actions |
| `isUnassigned` | `boolean` | Current team is the "No team" sentinel (`id === 0`) |
| `hasTeamOrUnassigned` | `boolean` | A specific team or Unassigned is selected (not "All fleets") |
| `switchesFromUnassigned` | `string \| undefined` | Chip label when navigating away from Unassigned |
| `switchesFromAllFleets` | `string \| undefined` | Chip label when navigating from "All fleets" to a team-required page |
| `defaultDestination` | `string \| undefined` | Chip label for add-report / software automation commands |

### `deriveContext(ctx: ICommandPaletteContext): IDerivedContext`
Factory function called once per `buildPaletteItems` invocation. Handles three cross-cutting concerns:

- **Primo Mode** — collapses all destination chip labels to `undefined` (single-fleet perception, no context switching)
- **Free tier** — treats the implicit single fleet as `hasTeamOrUnassigned: true` so team-gated items still surface
- **Default fleet resolution** — prefers a team named `"workstations"` or `"💻 workstations"`, falling back to the lowest `id` team

## Usage Example

```typescript
import { deriveContext } from "./derivations";
import { buildControlsItems } from "./groups/controlsGroup";

const derived = deriveContext(commandPaletteContext);

// Pass derived to every group builder — logic computed once, shared everywhere
const controlItems = buildControlsItems(commandPaletteContext, derived);
```
