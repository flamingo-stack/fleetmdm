Utility module for the Command Palette feature that defines shared types, scoring constants, and matching/highlighting algorithms used to rank and display search results.

## Key Components

### Interfaces
- **`ICommandItem`** — A palette entry with label, group, path, optional sub-items, and action callbacks
- **`ICommandSubItem`** — A nested item under a parent `ICommandItem`
- **`ICommandPaletteContext`** — Full context object passed to all group builders, carrying team state, feature flags, permissions, and action callbacks
- **`IBestMatchEntry`** — A scored result pairing an item (and optional sub-item) with its numeric score
- **`IHighlightSegment`** — A text segment tagged `matched: true/false` for rendering emphasis

### Constants
- **`GROUPS`** — Ordered tuple of palette group names: `Pages`, `Controls`, `Software`, `Settings`, `MDM`, `Automations`, `Commands`
- **`SCORE_*`** — Tiered scoring constants (`SCORE_LABEL_EXACT=100` down to `SCORE_KEYWORD_WORD_PREFIX=30`) controlling match ranking priority

### Functions
- **`scoreMatch`** — Scores a single text against a query using exact, prefix, word-prefix, and substring tiers
- **`scoreItemForBestMatch`** — Runs a two-pass (full-query + multi-token) score over an item's label and keywords
- **`computeBestMatch`** — Filters and ranks all items against a query, returning sorted `IBestMatchEntry[]`
- **`highlightMatches`** — Returns `IHighlightSegment[]` marking which portions of a display string matched the query

## Usage Example

```typescript
import {
  computeBestMatch,
  highlightMatches,
  ICommandPaletteContext,
} from "./helpers";

// Score all items against a search query
const results = computeBestMatch(allItems, "os settings");
// results[0].score === SCORE_LABEL_WORD_PREFIX (80) for "OS settings"

// Highlight matched text for display
const segments = highlightMatches("Organization settings", "org");
// [{ text: "Org", matched: true }, { text: "anization settings", matched: false }]
```
