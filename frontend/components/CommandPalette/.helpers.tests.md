Test suite for the CommandPalette `helpers.ts` module, validating item generation, permission filtering, team context chips, MDM state toggles, and scoring/matching utilities.

## Key Components

### Tested Exports from `./helpers`
- **`buildPaletteItems(context)`** – Generates the full list of `ICommandItem` entries based on the current user context and permissions
- **`GROUPS`** – Ordered array of palette group names
- **`scoreMatch` / `computeBestMatch`** – Fuzzy scoring functions for ranking items against a search query
- **`highlightMatches`** – Produces annotated text for bolding matched characters
- **`buildFleetSwitchUrl`** – Constructs URLs that include team-switch parameters
- **`pathSupportsAllFleets` / `pathSupportsUnassigned`** – Guards for routes compatible with global/unassigned team contexts
- **Score constants** – `SCORE_KEYWORD_EXACT`, `SCORE_KEYWORD_PREFIX`, `SCORE_KEYWORD_WORD_PREFIX`, `SCORE_LABEL_EXACT`, `SCORE_LABEL_PREFIX`, `SCORE_LABEL_SUBSTRING`, `SCORE_LABEL_WORD_PREFIX`

### Test Fixtures
- **`BASE_CONTEXT`** – A fully-permissioned `ICommandPaletteContext` used as a baseline, overridden per test case

## Usage Example

```typescript
// Typical pattern: spread BASE_CONTEXT and override specific flags
const items = buildPaletteItems({
  ...BASE_CONTEXT,
  hasTeamSelected: true,
  currentTeam: { id: 1, name: "Engineering" },
});

const ids = items.map((i) => i.id);
expect(ids).toContain("dashboard");
```

## Test Coverage Highlights

| Scenario | Key Assertion |
|----------|--------------|
| Global admin + team selected | All major pages present |
| All Fleets context | Controls items hidden |
| Observer (`canWrite: false`) | `toggle-dark-mode` and `sign-out` still present |
| Non-global admin | Settings entries excluded |
| Packs visibility | Only appears when `search === "packs"` |
| Team chip rendering | `teamName` omitted when destination matches current context |
| MDM not configured | "Turn on" variants shown; "Edit" variants hidden |
| MDM configured | "Edit" variants shown; "Turn on" hidden |
| Policy automations | Single flat entry with `manage_automations=1` deep-link; no `subItems` |
| All Fleets keywords | `calendar` and `conditional access` excluded from policy automation keywords |
