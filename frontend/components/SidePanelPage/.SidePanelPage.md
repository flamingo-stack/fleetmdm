A layout wrapper component that applies consistent styling to the side panel region of the application.

## Key Components

- **`SidePanelPage`** *(default export)* — A functional component that wraps side panel content in a `div` with the `side-panel-page` base class, optionally merged with a custom `className`.
- **`ISidePanelContentProps`** — Interface defining the component's props: a required `children` node and an optional `className` string.

## Usage Example

```typescript
import SidePanelPage from "components/SidePanelPage";

const MyPanel = () => (
  <SidePanelPage className="my-custom-panel">
    <p>Side panel content goes here.</p>
  </SidePanelPage>
);
```

> **Note:** `children` accepts a single `ReactChild`, so wrap multiple elements in a fragment or container if needed.
