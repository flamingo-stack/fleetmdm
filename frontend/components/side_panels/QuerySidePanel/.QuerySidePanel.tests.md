Test suite for the `QuerySidePanel` component, validating rendering of osquery table metadata including table selection, platform compatibility, column listings, tooltips, examples, notes, and source links.

## Key Components

| Test Case | Description |
|-----------|-------------|
| Table selection | Verifies the correct table name (`users`) appears in the React Select value container |
| Platform compatibility | Checks all four platforms (macOS, Windows, Linux, ChromeOS) render in the compatibility section |
| Column rendering | Confirms all 13 columns render, including the 2 marked as hidden |
| Hidden column tooltip | Validates the "Not returned in SELECT *" tooltip appears on hover |
| Platform-specific column tooltip | Validates the "only available on chrome" tooltip on the `email` column |
| Example rendering | Confirms the example query header and "Example" label are present |
| Notes rendering | Verifies custom notes text renders under a "Notes" header |
| Source link | Confirms a `_blank` anchor pointing to `https://www.fleetdm.com/tables/users` renders |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { renderWithSetup } from "test/test-utils";
import createMockOsqueryTable from "__mocks__/osqueryTableMock";
import QuerySidePanel from "./QuerySidePanel";

// Basic render with mock table data
render(
  <QuerySidePanel
    selectedOsqueryTable={createMockOsqueryTable()}
    onOsqueryTableSelect={() => noop}
    onClose={noop}
  />
);

// With user interactions (hover for tooltips)
const { user } = renderWithSetup(
  <QuerySidePanel
    selectedOsqueryTable={createMockOsqueryTable()}
    onOsqueryTableSelect={() => noop}
    onClose={noop}
  />
);
await user.hover(screen.getByText("type"));
```

## Notes

- Uses `renderWithSetup` from `test/test-utils` for tests requiring user interaction events (hover)
- The `createMockOsqueryTable` mock accepts optional overrides (e.g., `{ notes: "..." }`) for targeted test scenarios
- Source file: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
