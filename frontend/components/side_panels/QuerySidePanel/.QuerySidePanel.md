A side panel component for browsing and exploring osquery tables within the Fleet query editor, displaying table metadata including columns, platforms, examples, and notes.

## Key Components

- **`QuerySidePanel`** — Main exported component rendering the full table reference panel
- **`renderTableSelect`** — Internal helper building a searchable dropdown of all available osquery table names
- **`IQuerySidePanel`** — Props interface defining `selectedOsqueryTable`, `onOsqueryTableSelect`, and `onClose` callbacks
- **Sub-components used**: `QueryTableColumns`, `QueryTablePlatforms`, `QueryTableExample`, `QueryTableNotes`, `EventedTableTag`, `FleetMarkdown`, `DropdownWrapper`, `CustomLink`

## Usage Example

```typescript
import QuerySidePanel from "components/QuerySidePanel";
import { IOsQueryTable } from "interfaces/osquery_table";

const selectedTable: IOsQueryTable = {
  name: "users",
  description: "Local user accounts.",
  platforms: ["darwin", "linux"],
  columns: [...],
  evented: false,
};

<QuerySidePanel
  selectedOsqueryTable={selectedTable}
  onOsqueryTableSelect={(tableName) => console.log("Selected:", tableName)}
  onClose={() => setPanelOpen(false)}
/>
```

## Notes

- Automatically displays an `EventedTableTag` when the selected table has `evented: true`
- Shows a **"Requires MDM"** badge specifically for the `managed_policies` table
- Renders optional `examples` and `notes` sections only when present on the table definition
- Links out to `https://www.fleetdm.com/tables/{name}` for the canonical upstream table reference
- Keyboard accessible close button supports `Enter` and `Space` key events
