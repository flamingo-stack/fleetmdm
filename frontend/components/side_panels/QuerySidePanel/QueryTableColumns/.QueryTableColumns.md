Renders an ordered list of osquery table columns, displaying required columns first (alphabetically), followed by non-required columns (alphabetically).

## Key Components

- **`QueryTableColumns`** – Main React component that accepts a `columns` prop and renders sorted `ColumnListItem` entries within a styled list
- **`orderColumns`** – Sorts columns by placing required entries before non-required ones, with each group sorted alphabetically
- **`sortAlphabetically`** – Comparator utility used by `orderColumns` to sort `IQueryTableColumn` objects by name
- **`IQueryTableColumnsProps`** – Props interface requiring a `columns: IQueryTableColumn[]` array

## Usage Example

```typescript
import QueryTableColumns from "./QueryTableColumns";
import { IQueryTableColumn } from "interfaces/osquery_table";

const columns: IQueryTableColumn[] = [
  { name: "pid", type: "integer", description: "Process ID", required: false },
  { name: "path", type: "text", description: "Binary path", required: true },
];

<QueryTableColumns columns={columns} />
// Renders "path" (required) before "pid" (non-required)
```

## Notes

- Consumes `QueryContext` to retrieve `selectedOsqueryTable.name`, which is passed down to each `ColumnListItem`
- Sorting is non-destructive — the original `columns` array is not mutated
