Renders a single osquery table column as a list item with its name, type, and a tooltip containing the column's description and relevant footnotes (required, user context, hidden, platform restrictions).

## Key Components

**`ColumnListItem`** — Default export. A React component that displays a column name (wrapped in a tooltip) and its formatted type. Appends an asterisk (`*`) to required columns.

**`renderTooltip`** — Builds the tooltip content as a React node, composing:
- Column description
- Required footnote
- User context footnote (links to FleetDM guide with UTM params)
- Hidden column footnote
- Platform availability footnote

**`hasFootnotes`** — Determines whether a column has any footnote indicators to apply additional styling.

**`createTypeDisplayText`** — Formats a `ColumnType` value by replacing underscores with spaces and uppercasing (e.g., `"big_int"` → `"BIG INT"`).

## Usage Example

```typescript
import ColumnListItem from "./ColumnListItem";

const MyColumnList = () => (
  <ul>
    <ColumnListItem
      column={{
        name: "uid",
        type: "big_int",
        description: "User ID",
        required: true,
        requires_user_context: false,
        hidden: false,
        platforms: ["linux", "macOS"],
      }}
      selectedTableName="users"
    />
  </ul>
);
```

## Notes

- Tooltip content is rendered as a React node via `TooltipWrapper`.
- Platform footnotes handle 1–3 platforms with natural language joining; 4+ fall back to comma-separated.
- UTM parameters on the user context footnote link include `utm_table` referencing the selected table name.
