Renders a labeled "Example" section that displays query table example content as formatted Markdown using the `FleetMarkdown` component.

## Key Components

- **`QueryTableExample`** — Default export; a React functional component that wraps a Markdown string in a styled container with an "Example" heading.
- **`IQueryTableExampleProps`** — Interface defining the component's props:
  - `example: string` — The Markdown string to render.
- **`baseClass`** — CSS class name (`"query-table-example"`) applied to the root `<div>`.

## Usage Example

```typescript
import QueryTableExample from "components/QueryTableExample";

const markdownExample = `
| column_name | type   |
|-------------|--------|
| hostname    | string |
| pid         | int    |
`;

<QueryTableExample example={markdownExample} />
```
