A React component that renders a clickable "EVENTED TABLE" tag linking to the FleetDM evented tables documentation, with UTM tracking parameters appended to the URL.

## Key Components

- **`EventedTableTag`** — Default export; a functional component that renders an anchor tag with a calendar-check icon and "EVENTED TABLE" label
- **`IEventedTableTagProps`** — Interface requiring a `selectedTableName` string prop used to build UTM tracking parameters
- **`buildQueryStringFromParams`** — Utility used to append `utm_source` and `utm_table` query parameters to the documentation URL

## Usage Example

```typescript
import EventedTableTag from "components/EventedTableTag";

// Renders a tag linking to FleetDM docs for the "file_events" evented table
<EventedTableTag selectedTableName="file_events" />

// Generated link:
// https://fleetdm.com/guides/osquery-evented-tables-overview
//   ?utm_source=fleet-ui&utm_table=table-file_events
```

## Notes

- Opens the documentation link in a new browser tab via `target="__blank"`
- The UTM parameters (`utm_source=fleet-ui`, `utm_table=table-{selectedTableName}`) enable tracking of which table triggered the documentation visit
- Styling is scoped under the `evented-table-tag` base CSS class
