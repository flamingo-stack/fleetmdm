Renders a sorted, icon-labeled list of platforms compatible with a given osquery table schema, filtering out unsupported platforms (e.g., `freebsd`).

## Key Components

- **`PlatformListItem`** — Internal component that renders a single platform entry with its icon and display name.
- **`QueryTablePlatforms`** — Primary exported component that accepts a `platforms` array, filters out `freebsd`, sorts by a defined order (`darwin → windows → linux → chrome`), and renders the compatibility list.
- **`PLATFORM_ORDER`** — Constant array controlling display sort order.

## Usage Example

```typescript
import QueryTablePlatforms from "components/QueryTablePlatforms";
import { TableSchemaPlatform } from "interfaces/osquery_table";

const platforms: TableSchemaPlatform[] = ["linux", "darwin", "windows"];

<QueryTablePlatforms platforms={platforms} />;
```

Renders:

```text
Compatible with
• 🍎 macOS
• 🪟 Windows
• 🐧 Linux
```

> **Note:** The `freebsd` type is temporarily accepted via `IPlatformsWithFreebsd` but filtered out at render time. This is flagged for removal once `freebsd` is fully removed from the table schema.
