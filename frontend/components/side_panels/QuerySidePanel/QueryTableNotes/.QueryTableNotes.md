Renders a styled "Notes" section for a query table, displaying markdown-formatted note content using the `FleetMarkdown` component.

## Key Components

- **`QueryTableNotes`** – Default export. A functional component that wraps a notes string in a labeled section with markdown rendering.
- **`IQueryTableNotesProps`** – Interface requiring a `notes` string prop.
- **`FleetMarkdown`** – Used internally to render the notes content as formatted markdown.

## Usage Example

```typescript
import QueryTableNotes from "components/QueryTableNotes";

<QueryTableNotes notes="This query returns **active sessions** only.\n\nSee [docs](https://fleetdm.com) for details." />
```

Renders a `<div class="query-table-notes">` containing an `<h3>Notes</h3>` header and the markdown-rendered notes content.
