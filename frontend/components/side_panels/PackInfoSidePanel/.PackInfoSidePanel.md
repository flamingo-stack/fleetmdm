Renders a static informational side panel explaining osquery query packs, their run modes, and where to find query results.

## Key Components

- **`PackInfoSidePanel`** — Default export; a stateless React component that displays educational content about query packs including descriptions of Differential and Snapshot report modes, log file locations, and a link to osquery's log aggregation documentation.
- **`DifferentialIcon`** — Icon asset representing the differential query mode.
- **`SnapshotIcon`** — Icon asset representing the snapshot query mode.
- **`CustomLink`** — Renders an external link to the [osquery log aggregation docs](https://osquery.readthedocs.io/en/stable/deployment/log-aggregation/).

## Usage Example

```javascript
import PackInfoSidePanel from "components/PackInfoSidePanel";

const PacksPage = () => (
  <div className="packs-layout">
    <main>{/* Pack list or form */}</main>
    <aside>
      <PackInfoSidePanel />
    </aside>
  </div>
);
```

## Notes

- The component accepts **no props** — all content is static.
- The `baseClass` pattern (`"pack-info-side-panel"`) is used for BEM-style CSS scoping across child elements.
- Log file paths (`/path/to/status/logs`, `/path/to/result/logs`) appear to be placeholder values that should be configured to reflect the actual deployment environment.
