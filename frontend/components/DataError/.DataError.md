A reusable React error state component that renders a standardized error UI with optional description text, an issue-filing link, and support for multiple visual variants.

## Key Components

### `DataError` (default export)

A JSX component with three rendering modes controlled by props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `description` | `string` | `"Refresh the page or log in again."` | Subtext shown below the header |
| `excludeIssueLink` | `boolean` | `false` | Hides the "file an issue" link |
| `verticalPaddingSize` | `Padding` | — | Controls vertical spacing (`"pad-large"` for cards, `"pad-xxxlarge"` for pages) |
| `useNew` | `boolean` | `false` | Renders the updated design with a graphic asset |
| `singleCustomLine` | `boolean` | `false` | Collapses error into a single icon + description line |
| `selfCenter` | `boolean` | `false` | Centers the component within its parent |
| `children` | `ReactNode` | — | Overrides the default description/link content |
| `className` | `string` | — | Additional CSS class |

**Render modes (evaluated in priority order):**
1. **`singleCustomLine`** — Inline icon + description on one line
2. **`useNew`** — Full-width graphic + refreshed layout
3. **Default** — Classic icon + header + description layout

## Usage Example

```typescript
// Default usage (card-level)
<DataError verticalPaddingSize="pad-large" />

// Page-level with no issue link
<DataError
  verticalPaddingSize="pad-xxxlarge"
  excludeIssueLink
  description="Unable to load device data."
/>

// New design with custom children
<DataError useNew selfCenter>
  <p>Contact your administrator.</p>
</DataError>

// Compact single-line variant
<DataError singleCustomLine description="Query failed." />
```
