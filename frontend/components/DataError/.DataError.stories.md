Storybook stories file for the `DataError` component, showcasing three display variants used for rendering data error messages in the UI.

## Key Components

| Export | Description |
|---|---|
| `Basic` | Default `DataError` rendering with no additional props |
| `WithChildren` | Renders the component with custom JSX passed as children |
| `SingleCustomLine` | Renders a compact single-line error with a custom description string |

## Usage Example

```typescript
// Import and use stories in Storybook or tests
import { Basic, WithChildren, SingleCustomLine } from "./DataError.stories";

// SingleCustomLine story args
const args = {
  singleCustomLine: true,
  description: "We can't retrieve data from Apple right now. Please try again later.",
};

// WithChildren story args
const childArgs = {
  children: <p>this is custom JSX</p>,
};
```

## Notes

- Stories are registered under `Components/Error Messages/Data error` in the Storybook hierarchy.
- The `WithChildren` story demonstrates how custom JSX content can be injected into the error component.
- The `SingleCustomLine` story is useful for inline or compact error display contexts.

For the source component, see [`DataError`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/DataError/DataError.tsx).
