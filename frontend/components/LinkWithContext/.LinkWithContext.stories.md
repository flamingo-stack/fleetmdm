Storybook stories file for the `LinkWithContext` component, providing visual documentation and interactive playground configurations.

## Key Components

- **`meta`** — Storybook metadata defining the component title, component reference, and default args including `className`, `children`, `to`, `withParams`, and `currentQueryParams`
- **`Basic`** — A default story rendering `LinkWithContext` with pre-configured query parameter forwarding (`apples`, `bananas`)

## Usage Example

```typescript
// Extend with additional stories for different parameter types
export const WithHashParams: Story = {
  args: {
    children: "Link with hash context",
    to: "/dashboard",
    withParams: {
      type: "hash",
      names: ["section"],
    },
    currentQueryParams: {
      section: "overview",
    },
  },
};
```

## Notes

- Default args simulate a URL context where query params `apples=1` and `bananas=2` are preserved across navigation
- The `withParams.type: "query"` configuration instructs `LinkWithContext` to forward specified query parameters to the destination route
- Stories are registered under **Components/LinkWithContext** in the Storybook sidebar
