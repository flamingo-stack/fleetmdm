A React component that wraps React Router's `Link` to preserve selected query parameters when navigating between routes.

## Key Components

- **`LinkWithContext`** — Default export; renders a `<Link>` with forwarded query params, or a `<span>` when disabled
- **`ILinkWithContextProps`** — Interface defining component props:
  - `currentQueryParams` — The active query params to pull from
  - `withParams` — Specifies which params to carry forward (`type: "query"` + `names` array)
  - `disabled` — Renders a non-navigable `<span>` instead of a link

## Usage Example

```typescript
import LinkWithContext from "components/LinkWithContext";

// Preserve `team_id` and `order_key` when linking to /hosts
<LinkWithContext
  to="/hosts"
  currentQueryParams={{ team_id: "3", order_key: "hostname", status: "online" }}
  withParams={{ type: "query", names: ["team_id", "order_key"] }}
  className="my-link"
>
  View Hosts
</LinkWithContext>
// Renders: <a href="/hosts?team_id=3&order_key=hostname">View Hosts</a>

// Disabled state renders a non-clickable span
<LinkWithContext disabled {...props}>
  View Hosts
</LinkWithContext>
// Renders: <span class="link-with-context my-link">View Hosts</span>
```

## Notes

- Uses `lodash.pick` to extract only the specified param names from `currentQueryParams`
- Query string is omitted from the URL entirely when no matching params are found
