Renders the target selection UI for queries and live policies, allowing users to search and select individual hosts, labels, teams, and platforms as execution targets.

## Key Components

### Props (`ISelectTargetsProps`)
- `selectedTargets` / `targetedHosts` / `targetedLabels` / `targetedTeams` — current selection state passed in from parent
- `setSelectedTargets`, `setTargetedHosts`, `setTargetedLabels`, `setTargetedTeams`, `setTargetsTotalCount` — state setters for updating selections
- `goToQueryEditor` / `goToRunQuery` — navigation callbacks
- `isLivePolicy`, `isObserverCanRunQuery`, `queryTeamId` — permission/context flags

### Internal Helpers
- `parseLabels(list)` — splits label summary into `allHosts`, `platforms`, and `other` buckets
- `getTruncatedEntityCount(list, maxLength)` — finds the index where cumulative name length exceeds `SECTION_CHARACTER_LIMIT` (600)
- `shouldExpandList(targetedList, truncatedList)` — detects if a pre-selected entity is hidden behind the "show more" truncation
- `expandListsOnInitialLoad()` — auto-expands teams/labels lists on first render if a hidden item is already selected

### Data Fetching (react-query)
- `teams` — loaded via `teamsAPI.loadAll()`, enabled only for premium tier
- `labelsSummary` — loaded via `labelsAPI.summary()`
- `searchResults` — debounced host search via `targetsAPI.search()`, keyed on query text and current selections
- `counts` — live target count via `targetsAPI.count()`, updates `targetsTotalCount` on success

### Event Handlers
- `handleButtonSelect` — toggles label/team chips; enforces "All Hosts" mutual exclusivity
- `handleRowSelect` / `handleRowRemove` — adds/removes individual hosts from the host table
- `onClickRun` — commits final count and navigates to query run step

## Usage Example

```typescript
<SelectTargets
  baseClass="query-page"
  queryId={42}
  selectedTargets={selectedTargets}
  targetedHosts={targetedHosts}
  targetedLabels={targetedLabels}
  targetedTeams={targetedTeams}
  goToQueryEditor={() => setStep("editor")}
  goToRunQuery={() => setStep("run")}
  setSelectedTargets={setSelectedTargets}
  setTargetedHosts={setTargetedHosts}
  setTargetedLabels={setTargetedLabels}
  setTargetedTeams={setTargetedTeams}
  setTargetsTotalCount={setTargetsTotalCount}
  isLivePolicy={false}
/>
```
