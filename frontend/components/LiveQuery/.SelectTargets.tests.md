Integration tests for the `SelectTargets` component, specifically covering team button enable/disable behavior based on user roles, query permissions, and live policy context.

## Key Components

### Test Fixtures
- **`MOCK_LABELS`** — Stub label data (builtin labels: "All Hosts", "macOS") served via MSW
- **`MOCK_TEAMS`** — Stub team data ("Team Alpha", "Team Beta") served via MSW
- **`defaultProps`** — Baseline props passed to `SelectTargets` in every test case
- **`getTeamButton`** — Helper querying a team button by visible text

### Test Suites

| Suite | User Type | Scenarios Covered |
|---|---|---|
| `plain observer` | Team-scoped observer | Live policies, `observer_can_run` false/true, per-team scoping |
| `observer+` | Team-scoped observer_plus | Always enabled regardless of policy/query flags |
| `mixed roles` | Admin on team 1, observer on team 2 | Selective disabling per role per team |
| `global observer` | Global observer role | All teams, Unassigned, global `observer_can_run` without `team_id` |
| `helper text visibility` | — | UI feedback when some teams are disabled (truncated) |

## Usage Example

```typescript
// Run a single suite
it("enables only the query's team when observer_can_run is true", async () => {
  const render = createCustomRenderer({
    withBackendMock: true,
    context: {
      app: {
        currentUser: plainObserverOnBothTeams,
        isPremiumTier: true,
        isOnGlobalTeam: false,
      },
    },
  });

  render(
    <SelectTargets
      {...defaultProps}
      isObserverCanRunQuery
      queryTeamId={1}
    />
  );

  await waitFor(() => {
    expect(getTeamButton("Team Alpha")).toBeEnabled();
    expect(getTeamButton("Team Beta")).toBeDisabled();
  });
});
```

MSW handlers (`labelSummariesHandler`, `teamsHandler`) are registered in `beforeEach` via `mockServer.use(...)` to intercept `/labels/summary` and `/fleets` API calls.
