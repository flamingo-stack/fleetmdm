A selectable chip button component used for targeting labels or teams, rendering a check or plus icon based on selection state with display name resolution for built-in platform labels.

## Key Components

- **`ITargetChipSelectorProps`** – Props interface accepting an `entity` (label or team), `isSelected` boolean, `onClick` handler, and optional `disabled` flag
- **`isBuiltInLabel`** – Type guard that narrows an entity to a built-in `ISelectLabel` by checking `label_type === "builtin"`
- **`displayText`** – Internal helper that resolves the chip's display name, mapping built-in label API names through `LABEL_DISPLAY_MAP` with a fallback to `entity.name`
- **`TargetChipSelector`** – Default export; renders a `<button>` with a dynamic `check`/`plus` icon and resolved label text

## Usage Example

```typescript
import TargetChipSelector from "components/TargetChipSelector";
import { ISelectLabel } from "interfaces/target";

const myLabel: ISelectLabel = {
  name: "macOS",
  label_type: "builtin",
};

<TargetChipSelector
  entity={myLabel}
  isSelected={false}
  onClick={(entity) => (e) => {
    console.log("Selected:", entity.name);
  }}
  disabled={false}
/>
```

## Notes

- Built-in platform labels (e.g. `macOS`, `Windows`) are remapped via `LABEL_DISPLAY_MAP` to human-friendly names before rendering
- The `onClick` prop follows a curried pattern: `(entity) => MouseEventHandler`, allowing the entity to be captured in the handler closure
- The `data-selected` attribute enables CSS-driven styling for selected vs. unselected states
