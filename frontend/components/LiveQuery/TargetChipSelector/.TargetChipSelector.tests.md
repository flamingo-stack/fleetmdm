Unit tests for the `TargetChipSelector` React component, verifying rendering, selection state, icon display, click handling, and data attributes for label and team entities.

## Key Components

- **`TargetChipSelector`** — The component under test; renders a selectable chip for a label or team entity
- **`ISelectLabel`** / **`ISelectTeam`** — Target entity interfaces used as mock props
- **`mockLabel`** / **`mockTeam`** — Fixture objects representing a regular label and a team

## Test Coverage

| Test Case | Description |
|-----------|-------------|
| Label display text | Renders `entity.name` for `ISelectLabel` |
| Team display text | Renders `entity.name` for `ISelectTeam` |
| Selected icon | Shows `check` icon when `isSelected={true}` |
| Unselected icon | Shows `plus` icon when `isSelected={false}` |
| Click handler | Calls `onClick` with the correct entity and event |
| `data-selected` (true) | Button attribute is `"true"` when selected |
| `data-selected` (false) | Button attribute is `"false"` when not selected |

## Usage Example

```typescript
// Rendering the component in tests
render(
  <TargetChipSelector
    entity={mockLabel}
    isSelected={false}
    onClick={(value) => (event) => handleClick(value, event)}
  />
);

// Asserting selection state
expect(screen.getByRole("button")).toHaveAttribute("data-selected", "false");

// Asserting icon visibility
expect(screen.getByLabelText("plus")).toBeInTheDocument();
```
