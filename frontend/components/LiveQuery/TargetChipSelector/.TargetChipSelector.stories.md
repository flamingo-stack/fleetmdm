Storybook stories for the `TargetChipSelector` component, providing interactive visual examples of label and team chip selection states.

## Key Components

- **`LabelExample`** — Story rendering a regular label chip in an unselected state
- **`TeamExample`** — Story rendering a team chip in a selected state
- **`BuiltInLabelExample`** — Story rendering a built-in label chip (e.g., "MS Windows") in an unselected state
- **Mock Data** — `mockLabel` and `mockTeam` fixtures implementing `ISelectLabel` and `ISelectTeam` interfaces

## Storybook Args

| Arg | Type | Description |
|---|---|---|
| `entity` | `ISelectLabel \| ISelectTeam` | The label or team entity to display |
| `isSelected` | `boolean` | Whether the chip is currently selected |
| `onClick` | `(value) => (event) => void` | Curried click handler |

## Usage Example

```typescript
import TargetChipSelector from "./TargetChipSelector";
import { ISelectLabel } from "interfaces/target";

const label: ISelectLabel = {
  id: 1,
  name: "Example Label",
  label_type: "regular",
  description: "A test label",
};

<TargetChipSelector
  entity={label}
  isSelected={false}
  onClick={(value) => (event) => {
    event.preventDefault();
    console.log("Clicked:", value);
  }}
/>
```
