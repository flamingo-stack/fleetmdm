A navigation dropdown component that renders a user avatar as the menu trigger, providing access to account settings, admin controls, documentation, and sign-out functionality.

## Key Components

### `UserMenu` (default export)
The main component rendering a `react-select-5` dropdown styled as a top-navigation user menu.

**Props (`IUserMenuProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `onLogout` | `() => void` | Sign-out handler |
| `onUserMenuItemClick` | `(path: string) => void` | Internal navigation handler |
| `isAnyTeamAdmin` | `boolean \| undefined` | Controls Settings menu item visibility |
| `isGlobalAdmin` | `boolean \| undefined` | Controls Users/Settings menu item visibility |
| `currentUser` | `IUser` | Used for avatar and admin team resolution |
| `currentTeam` | `ITeamSummary \| undefined` | Used to route to the correct team settings page |

### `CustomDropdownIndicator`
Replaces the default react-select chevron with a Fleet-styled `Icon` component.

### `CustomOption`
Wraps react-select's `Option` to suppress auto-focus on the first item unless keyboard navigation is active.

### `getOptionBackgroundColor`
Returns a highlight color on focus, `transparent` otherwise.

## Key Behaviors

- **Keyboard vs. mouse focus detection** — listens for `Tab` / `mousedown` events to toggle `isKeyboardFocus`, enabling `:focus-visible`-style styling without CSS pseudo-class support in react-select.
- **Dynamic menu items** — Settings and Users items are conditionally prepended based on `isGlobalAdmin` / `isAnyTeamAdmin`.
- **Team-admin routing** — When a non-global admin opens Settings, the component resolves the correct team to navigate to and flashes a warning if the current team is out of scope.

## Usage Example

```typescript
<UserMenu
  onLogout={handleLogout}
  onUserMenuItemClick={(path) => router.push(path)}
  isAnyTeamAdmin={currentUser.teams.some((t) => t.role === "admin")}
  isGlobalAdmin={currentUser.global_role === "admin"}
  currentUser={currentUser}
  currentTeam={currentTeam}
/>
```
