React component test suite for the `SiteTopNav` navigation component, verifying that the correct nav items and user menu options are rendered based on user role (admin, maintainer, observer) and tier (free vs. premium).

## Key Components

### Test Cases

| Test | Tier | Role | Expected Nav Items |
|------|------|------|--------------------|
| Free global admin | Free | Admin | Hosts, Controls, Software, Reports, Policies + Settings, Users menu items |
| Free global maintainer | Free | Maintainer | Hosts, Controls, Software, Reports, Policies (no Settings/Users) |
| Free global observer | Free | Observer | Hosts, Software, Reports, Policies (no Controls/Settings/Users) |
| Premium global admin | Premium | Admin | All nav items + Settings, Users menu items |
| Premium global maintainer | Premium | Maintainer | All nav items (no Settings/Users) |
| Premium global observer | Premium | Observer | Hosts, Software, Reports, Policies (no Controls/Settings/Users) |
| Premium team admin | Premium | Team Admin | All nav items + Settings (no Users) |
| Premium team maintainer | Premium | Team Maintainer | All nav items (no Settings/Users) |
| Premium team observer | Premium | Team Observer | Hosts, Software, Reports, Policies |

### Shared Fixtures
- **`urlLocation`** — stub route object pointing to `queries/manage`
- **`createCustomRenderer`** — injects app context (tier/role flags) into the render
- **`createMockUser` / `createMockConfig` / `createMockTeam`** — factory functions for test data

## Usage Example

```typescript
// Pattern used across all test cases
const render = createCustomRenderer({
  context: {
    app: {
      isPremiumTier: true,
      isGlobalAdmin: true,
    },
  },
});

const { user } = render(
  <SiteTopNav
    config={createMockConfig()}
    currentUser={createMockUser()}
    location={urlLocation}
    onLogoutUser={noop}
    onUserMenuItemClick={noop}
  />
);

// Open user menu, then assert visible items
await user.click(screen.getByTestId("user-avatar"));
expect(screen.getByRole("menuitem", { name: /settings/i })).toBeInTheDocument();
expect(screen.queryByText(/users/i)).not.toBeInTheDocument();
```
