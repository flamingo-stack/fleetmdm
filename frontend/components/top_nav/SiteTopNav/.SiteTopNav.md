Top-level navigation bar component for the Fleet MDM web application, rendering role-aware nav items, org branding, GitOps mode indicator, and a user menu.

## Key Components

- **`SiteTopNav`** — Main exported component. Reads user roles and team context from `AppContext`, resolves active nav items, and handles team ID query param propagation across page transitions.
- **`GitOpsModeIndicator`** — Internal component that displays a read-only GitOps mode badge with a tooltip. Renders as a clickable link to admin settings when the viewer is a global admin.
- **`renderNavItem`** — Internal render function handling three nav item variants: the org logo link, an active-page link (resets filters except team ID), and a standard link (with or without `LinkWithContext` for query param forwarding).
- **`REGEX_DETAIL_PAGES` / `REGEX_GLOBAL_PAGES`** — Route pattern maps used to detect whether the current path is a detail page (e.g., `/hosts/42`) or a global settings page, which triggers team ID injection from context rather than the URL.
- **`getNavItems`** — External utility (from `./navItems`) that filters the nav item list based on user role flags.

## Usage Example

```typescript
import SiteTopNav from "components/SiteTopNav";

<SiteTopNav
  config={appConfig}
  currentUser={currentUser}
  location={{ pathname: location.pathname, query: location.query }}
  onLogoutUser={handleLogout}
  onUserMenuItemClick={handleUserMenuClick}
/>
```

## Notes

- Dark/light mode is tracked via a `fleet-theme-change` custom DOM event, swapping the org logo URL accordingly.
- `fleet_id` query param is stripped when navigating to the "All Teams" view (`API_ALL_TEAMS_ID`), preserving clean URLs.
