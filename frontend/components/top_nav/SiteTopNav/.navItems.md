Defines and exports a function that generates the primary navigation items for the Fleet MDM application sidebar, filtering items based on the current user's role and permissions.

## Key Components

### `INavItem` Interface
Describes the shape of a single navigation item with the following properties:
- `name` — Display label
- `icon` / `iconName` — Optional icon identifiers
- `location` — Object containing a `regex` for active-state matching and a `pathname` for routing
- `exclude` — When `true`, hides the item from the nav
- `alwaysToPathname` — When `true`, always navigates to the root `pathname` regardless of the current child route (e.g. clicking **Software** always goes to `/software/inventory/`)
- `withParams` — Preserves specified query params (e.g. `fleet_id`) across navigation

### Default Export Function
Accepts a `user` object and role booleans, returns a filtered `INavItem[]`.

| Role Flag | Effect |
|---|---|
| `isNoAccess` | Returns only the logo/home item |
| `isGlobalAdmin` / `isAnyTeamAdmin` | Controls nav item shown |
| `isGlobalMaintainer` / `isAnyTeamMaintainer` | Controls nav item shown |
| `isGlobalTechnician` / `isAnyTeamTechnician` | Controls nav item shown |

## Usage Example

```typescript
import navItems from "navigation/navItems";

const items = navItems(
  currentUser,
  true,   // isGlobalAdmin
  false,  // isAnyTeamAdmin
  false,  // isAnyTeamMaintainer
  false,  // isGlobalMaintainer
  false,  // isNoAccess
  false,  // isGlobalTechnician
  false   // isAnyTeamTechnician
);

items.forEach((item) => {
  console.log(item.name, item.location.pathname);
});
// "Home"     /dashboard
// "Hosts"    /hosts/manage
// "Controls" /controls
// "Software" /software/inventory
// "Reports"  /reports/manage
// "Policies" /policies/manage
```

> **Note:** The `Controls` nav item is hidden unless the user holds at least one of the admin, maintainer, or technician roles (global or team-scoped).
