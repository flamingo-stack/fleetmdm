Test suite for the `LastUpdatedText` component, validating timestamp display, fallback text, and tooltip hover behavior.

## Key Components

- **`renders updated text`** — Verifies that a valid ISO timestamp renders as a human-readable relative string (e.g., `"Updated 2 days ago"`)
- **`renders never if missing timestamp`** — Confirms the component falls back to `"Updated never"` when `lastUpdatedAt` is omitted
- **`renders tooltip on hover`** — Asserts that hovering the text triggers a tooltip containing contextual retrieval messaging (e.g., `"to retrieve software"`)

## Usage Example

```typescript
// Render with a valid timestamp
render(
  <LastUpdatedText whatToRetrieve="software" lastUpdatedAt={twoDaysAgo} />
);

// Render without a timestamp (fallback state)
render(<LastUpdatedText whatToRetrieve="software" />);

// Simulate hover to test tooltip
const { user } = renderWithSetup(
  <LastUpdatedText whatToRetrieve="software" />
);
await user.hover(screen.getByText("Updated never"));
await waitFor(() => {
  expect(screen.getByText(/to retrieve software/i)).toBeInTheDocument();
});
```

## Dependencies

- [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) — `render`, `screen`, `waitFor`
- `renderWithSetup` from `test/test-utils` — extends standard render with a configured `userEvent` instance for interaction testing
