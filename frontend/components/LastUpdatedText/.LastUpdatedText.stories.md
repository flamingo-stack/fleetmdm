Storybook stories file for the `LastUpdatedText` component, providing visual development and testing stories with various prop configurations.

## Key Components

- **`meta`** — Storybook metadata configuring the component under `Components/LastUpdatedText` with a default `whatToRetrieve` arg of `"apples"`
- **`Basic`** — Default story using only the inherited `whatToRetrieve` arg, no timestamp provided
- **`WithLastUpdatedAt`** — Story demonstrating the component with a specific ISO 8601 timestamp (`lastUpdatedAt`)

## Usage Example

```typescript
// Render the Basic story (no timestamp)
export const Basic: Story = {};

// Render with a last-updated timestamp
export const WithLastUpdatedAt: Story = {
  args: {
    lastUpdatedAt: "2021-01-01T00:00:00Z",
  },
};
```

## Notes

- The default `whatToRetrieve` prop is set to `"apples"` at the meta level, inherited by all stories unless overridden.
- The `WithLastUpdatedAt` story exercises the timestamp display path of the component.
