A React component that displays a human-readable "last updated" timestamp with an explanatory tooltip, formatting relative time strings using `date-fns`.

## Key Components

- **`LastUpdatedText`** — Default export. Renders an abbreviated relative timestamp (e.g., "Updated 5m ago") wrapped in a `TooltipWrapper`.
- **`ILastUpdatedTextWithCustomTooltip`** — Prop variant for providing a custom `React.ReactNode` as tooltip content.
- **`ILastUpdatedTextWithWhatToRetrieve`** — Prop variant for generating a standard Fleet tooltip message using a `whatToRetrieve` string (mutually exclusive with `customTooltipText`).

### Props (discriminated union)

| Prop | Type | Description |
|---|---|---|
| `lastUpdatedAt` | `string \| null` | ISO timestamp; defaults to `"never"` if absent or zero-value |
| `whatToRetrieve` | `string` | Used in the default tooltip: *"Fleet periodically queries all hosts to retrieve {whatToRetrieve}."* |
| `customTooltipText` | `React.ReactNode` | Overrides the default tooltip content entirely |

## Usage Example

```typescript
// Standard usage with whatToRetrieve
<LastUpdatedText
  lastUpdatedAt="2024-06-01T12:00:00Z"
  whatToRetrieve="software inventory"
/>
// Renders: "Updated 3 days ago" with default Fleet tooltip

// Custom tooltip content
<LastUpdatedText
  lastUpdatedAt={policy.updatedAt}
  customTooltipText={<span>Manually triggered refresh</span>}
/>

// Never updated (null or zero-value date)
<LastUpdatedText
  lastUpdatedAt={null}
  whatToRetrieve="vulnerability data"
/>
// Renders: "Updated never"
```
