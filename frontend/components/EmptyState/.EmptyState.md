A reusable React component that renders an empty/loading state overlay with animated skeleton ghost UI behind centered content (header, info text, and action buttons).

## Key Components

### `EmptyState` (default export)
Main component accepting `IEmptyStateProps`. Renders a ghost table background with overlaid content.

### `GhostColumn`
Internal sub-component rendering a single skeleton column with optional header row and staggered-width data rows. Supports `twoLines` for secondary skeleton rows.

### `GhostForm`
Internal sub-component rendering skeleton form fields (label + input pairs) with a button skeleton.

### `IEmptyStateProps`
| Prop | Type | Description |
|---|---|---|
| `header` | `JSX.Element \| string` | Title text |
| `info` | `JSX.Element \| string` | Body description |
| `additionalInfo` | `JSX.Element \| string` | Secondary info |
| `primaryButton` | `JSX.Element` | Primary CTA |
| `secondaryButton` | `JSX.Element` | Secondary CTA |
| `width` | `"default" \| "small"` | 3-column vs 2-column ghost layout |
| `variant` | `"list" \| "header-list" \| "form"` | Single-column list or form ghost layout |
| `className` | `string` | Additional CSS class |

## Usage Example

```typescript
import EmptyState from "./EmptyState";

// Standard table empty state
<EmptyState
  header="No hosts found"
  info="Try adjusting your filters or adding a new host."
  primaryButton={<Button onClick={handleAdd}>Add Host</Button>}
/>

// Modal-width list variant
<EmptyState
  width="small"
  variant="list"
  header="No items"
  info="Nothing to display yet."
/>

// Form loading skeleton
<EmptyState
  variant="form"
  header="Loading settings..."
/>
```
