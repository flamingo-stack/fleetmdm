Storybook stories for the `EmptyState` component, demonstrating all supported props, layout variants, and button configurations.

## Key Components

| Export | Description |
|---|---|
| `Default` | Basic empty state with header, info text, and a primary button |
| `WithAdditionalInfo` | Includes an extra `additionalInfo` line below the main info text |
| `WithTwoButtons` | Shows both `primaryButton` and `secondaryButton` side-by-side |
| `Small` | Compact layout using `width="small"` |
| `MinimalContent` | Header-only, no info or buttons |
| `InfoOnly` | Info text only, no header or buttons |
| `List` / `ListWithButton` | `variant="list"` layout, used inside list views |
| `HeaderList` / `HeaderListWithButton` | `variant="header-list"` layout, used in page headers |
| `Form` / `FormWithLongInfo` | `variant="form"` layout, used inside form sections |

## Usage Example

```typescript
import EmptyState from "components/EmptyState";
import Button from "components/buttons/Button";

// Default layout
<EmptyState
  header="No reports"
  info="Create a report to get started."
  primaryButton={<Button>Create report</Button>}
/>

// Compact list variant with two buttons
<EmptyState
  variant="list"
  width="small"
  header="No policies"
  info="Start monitoring compliance by creating your first policy."
  primaryButton={<Button>Create policy</Button>}
  secondaryButton={<Button variant="inverse">Import from library</Button>}
/>
```

## Controls

The Storybook `argTypes` expose two interactive controls:

- **`width`** — `"default"` | `"small"`
- **`variant`** — `undefined` | `"list"` | `"header-list"` | `"form"`
