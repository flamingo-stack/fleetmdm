A reusable React component that renders styled tab label text with optional count badges and a configuration check indicator for use with react-tabs.

## Key Components

### `TabText`
The default export — a presentational component that wraps tab label content with unified styling.

**Props (`ITabTextProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | The tab label text |
| `className` | `string` | Optional additional CSS class |
| `count` | `number` | Optional count badge value (only renders if `> 0`) |
| `countVariant` | `"alert" \| "pending"` | Controls the badge color/style |
| `showCheck` | `boolean` | When `true`, renders a green check icon indicating configured state |

## Usage Example

```typescript
import TabText from "components/TabText";

// Basic tab label
<TabText>Policies</TabText>

// Tab with an alert count badge
<TabText count={5} countVariant="alert">
  Failing Policies
</TabText>

// Tab with a pending count badge
<TabText count={12} countVariant="pending">
  Pending Actions
</TabText>

// Tab indicating a configured state
<TabText showCheck>
  MDM Settings
</TabText>
```

## Notes

- Count values are formatted with [`toLocaleString()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/toLocaleString) for locale-aware number display (e.g., `1,000`).
- The `data-text` attribute on the inner text `<div>` mirrors the child content, commonly used for CSS bold-width reservation tricks to prevent layout shift on font-weight changes.
