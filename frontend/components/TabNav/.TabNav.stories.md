Storybook stories for the `TabNav` component, demonstrating its default and secondary visual variants with interactive tab navigation.

## Key Components

- **`Default`** — Primary `TabNav` story showcasing standard tab styling with five tabs including a disabled tab, a tab with a count badge, and a tab with an alert-variant count badge.
- **`Secondary`** — Alternate story rendering `TabNav` with the `secondary` prop enabled, applying secondary styling to the same tab configuration.

Both stories use `react-tabs` primitives (`Tabs`, `TabList`, `Tab`, `TabPanel`) and the `TabText` component for tab label rendering.

## Usage Example

```typescript
// Default (primary) TabNav
<TabNav>
  <Tabs onSelect={setSelectedTabIndex} selectedIndex={selectedTabIndex}>
    <TabList>
      <Tab><TabText>Basic tab</TabText></Tab>
      <Tab disabled><TabText>Disabled tab</TabText></Tab>
      <Tab><TabText count={3}>Tab with count</TabText></Tab>
      <Tab>
        <TabText count={20} countVariant="alert">
          Tab with error count
        </TabText>
      </Tab>
    </TabList>
    <TabPanel><div>Content for Tab 1</div></TabPanel>
    <TabPanel><div>Content for Tab 3 (disabled)</div></TabPanel>
    <TabPanel><div>Content for Tab 4</div></TabPanel>
    <TabPanel><div>Content for Tab 5</div></TabPanel>
  </Tabs>
</TabNav>

// Secondary TabNav variant
<TabNav secondary>
  <Tabs onSelect={setSelectedTabIndex} selectedIndex={selectedTabIndex}>
    {/* same tab structure */}
  </Tabs>
</TabNav>
```

View the live stories in Storybook under **Components → TabNav**.
