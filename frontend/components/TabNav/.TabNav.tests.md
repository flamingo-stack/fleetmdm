Test suite for the `TabNav` component, verifying tab rendering and panel switching behavior using React Testing Library.

## Key Components

- **`renders tabs and panels correctly`** — Confirms that all tab labels render in the DOM and that only the first panel's content is visible by default
- **`switches tabs and displays the correct panel content`** — Simulates a click on the second tab and asserts the correct panel becomes visible while the previous one is hidden

## Usage Example

```typescript
import { render, screen, fireEvent } from "@testing-library/react";
import { Tab, Tabs, TabList, TabPanel } from "react-tabs";
import TabText from "components/TabText";
import TabNav from "./TabNav";

// Render TabNav with react-tabs primitives
render(
  <TabNav>
    <Tabs>
      <TabList>
        <Tab><TabText>Tab 1</TabText></Tab>
        <Tab><TabText>Tab 2</TabText></Tab>
      </TabList>
      <TabPanel><div>Content for Tab 1</div></TabPanel>
      <TabPanel><div>Content for Tab 2</div></TabPanel>
    </Tabs>
  </TabNav>
);

// Assert default state
expect(screen.getByText("Tab 1")).toBeInTheDocument();
expect(screen.queryByText("Content for Tab 2")).not.toBeInTheDocument();

// Simulate tab switch
fireEvent.click(screen.getByText("Tab 2"));
expect(screen.getByText("Content for Tab 2")).toBeInTheDocument();
```

## Notes

- Relies on `react-tabs` for tab state management; `TabNav` acts as a wrapper providing styling or layout context
- Panel visibility follows `react-tabs` default behavior: only the active panel is mounted in the DOM
