A lightweight wrapper component that provides unified tab navigation styling by consolidating base and optional modifier CSS classes.

## Key Components

### `ITabNavProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | — | Tab navigation content |
| `className` | `string` | `undefined` | Additional CSS class names |
| `secondary` | `boolean` | `false` | Applies `tab-nav--secondary` modifier class |

### `TabNav`
A functional component that renders a `<div>` with composed class names using `classnames`. Applies the `tab-nav` base class, any additional `className`, and conditionally appends `tab-nav--secondary` when `secondary` is `true`.

## Usage Example

```typescript
import TabNav from "./TabNav";

// Primary tab navigation
<TabNav>
  <Tab>Overview</Tab>
  <Tab>Settings</Tab>
</TabNav>

// Secondary variant with custom class
<TabNav secondary className="custom-nav">
  <Tab>Details</Tab>
  <Tab>History</Tab>
</TabNav>
```

> **Note:** This component is designed to override loaded React Tabs default styles, ensuring consistent tab styling across the application.
