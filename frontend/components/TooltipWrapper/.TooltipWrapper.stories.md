Storybook stories file for the `TooltipWrapper` component, defining interactive documentation and visual test cases with configurable position controls.

## Key Components

- **`meta`** – Storybook metadata configuration registering the component under `Components/TooltipWrapper` with a radio control for all 12 tooltip position variants
- **`Default`** – Baseline story rendering a tooltip with sample content and a margin decorator to ensure visibility in the Storybook canvas

## Usage Example

```typescript
// Run stories locally via Storybook
// npm run storybook

// Reuse story args in tests
import { Default } from "./TooltipWrapper.stories";

render(<TooltipWrapper {...Default.args} />);
```

## Supported Position Values

```text
top | top-start | top-end
right | right-start | right-end
bottom | bottom-start | bottom-end
left | left-start | left-end
```

## Notes

- Stories import `../../index.scss` to apply global Fleet MDM styles in isolation
- The `decorators` array wraps the story in a `div` with vertical margin so the tooltip is not clipped at the viewport edge
- Source lives at [`frontend/components/TooltipWrapper/TooltipWrapper.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/TooltipWrapper/TooltipWrapper.stories.tsx)
