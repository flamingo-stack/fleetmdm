A reusable React wrapper component that attaches a configurable tooltip to any child element using `react-tooltip-5`, with support for delay timing, positioning, mobile interactions, and overflow-safe rendering.

## Key Components

### `ITooltipWrapper` Interface
Defines all configurable props:
- **`tipContent`** – The tooltip's rendered content (required)
- **`position`** – Tooltip placement (default: `"bottom-start"`)
- **`delayShow`** / **`delayHide`** / **`delayShowHide`** – Hover delay controls (boolean uses 250ms default, number sets explicit ms)
- **`disableTooltip`** – Dynamically suppresses tooltip rendering
- **`fixedPositionStrategy`** – Uses `position: fixed` to escape `overflow: hidden` containers
- **`isMobileView`** – Switches interaction model to click-based (tap to open/close)
- **`showArrow`** / **`underline`** / **`clickable`** – Visual and behavior toggles

### `TooltipWrapper` Component
Wraps children in a `<span>` + inner `<div>` with a `data-tooltip-id` anchor, then conditionally renders a `ReactTooltip5` instance. A unique ID (via `lodash.uniqueId`) links the anchor to its tooltip, preventing collisions when multiple instances are on the same page.

## Usage Example

```typescript
import TooltipWrapper from "components/TooltipWrapper";

// Basic usage
<TooltipWrapper tipContent="This is a tooltip">
  <span>Hover me</span>
</TooltipWrapper>

// Mobile-friendly, fixed positioning, custom delay
<TooltipWrapper
  tipContent={<strong>More info</strong>}
  position="top"
  delayShowHide={300}
  fixedPositionStrategy
  isMobileView={isMobile}
  disableTooltip={!hasPermission}
>
  <InfoIcon />
</TooltipWrapper>
```
