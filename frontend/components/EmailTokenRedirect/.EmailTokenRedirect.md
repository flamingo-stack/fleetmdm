Handles email change confirmation by consuming a token from the URL, calling the confirmation API, and redirecting the user to the appropriate route based on success or failure.

## Key Components

- **`EmailTokenRedirect`** — Renderless React component that performs side-effect-only logic (returns `null`)
- **`confirmEmailChange`** — Async function called via `useDeepEffect` that validates the token against the API
- **`useDeepEffect`** — Custom hook used to trigger the confirmation when `currentUser` and `token` are available

## Behavior

- On **success**: redirects to `PATHS.ACCOUNT` and shows a success flash notification
- On **failure**: redirects to `PATHS.LOGIN` and logs the error to the console
- Depends on both `currentUser` (from `AppContext`) and `token` (from route params) being present before firing

## Usage Example

```typescript
// Registered as a route in the router configuration
<Route
  path={PATHS.EMAIL_CHANGE + "/:token"}
  component={EmailTokenRedirect}
/>
```

```typescript
// Props interface
interface IEmailTokenRedirectProps {
  router: InjectedRouter; // React Router v3
  params: Params;         // Contains the `token` URL param
}
```

> **Note:** This component renders nothing to the DOM. It exists solely to handle the redirect logic triggered by an email confirmation link.
