Storybook stories file for the `FleetMarkdown` component, providing visual development and testing scenarios with sample Markdown content.

## Key Components

- **`TestMarkdown`** — A sample Markdown string covering headings (H1–H4), bold, italic, links, lists, blockquotes, and inline code
- **`meta`** — Storybook metadata registering the component under `Components/FleetMarkdown` with default `markdown` args
- **`Basic`** — A baseline story rendering the component with the full `TestMarkdown` fixture

## Usage Example

```typescript
import { Basic } from "./FleetMarkdown.stories";

// Renders FleetMarkdown with the default TestMarkdown fixture
<Basic />
```

To add additional stories:

```typescript
export const CustomContent: Story = {
  args: {
    markdown: "## Custom\n\nHello **world**",
  },
};
```

## Notes

- Located in the `FleetMarkdown` component directory; see the component itself at [`FleetMarkdown.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/FleetMarkdown/FleetMarkdown.tsx)
- Stories are registered under the `Components/FleetMarkdown` Storybook path
- The `Basic` story uses no overrides, relying entirely on the shared `args.markdown` default defined in `meta`
