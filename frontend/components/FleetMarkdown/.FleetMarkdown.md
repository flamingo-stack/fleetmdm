A reusable React component that renders Markdown content with Fleet-specific styling and behavior, using `ReactMarkdown` with GFM support and custom renderers for links, code blocks, and inline code.

## Key Components

### `FleetMarkdown`
The default export. Accepts markdown strings and renders them with customized component overrides:

| Prop | Type | Description |
|------|------|-------------|
| `markdown` | `string` | The markdown content to render |
| `className` | `string?` | Optional additional CSS class |
| `name` | `string?` | Passed to the underlying `SQLEditor` instance |

### Custom Renderers

- **`a` (links)** — Replaced with `CustomLink`, always opens in a new tab.
- **`pre` (fenced code blocks)** — Replaced with Fleet's `SQLEditor` (Ace-based), configured as read-only with no gutter, no indent-on-wrap, and focus styling removed.
- **`code` (inline code)** — Passed through as a standard `<code>` element.

### Plugins

- [`remark-gfm`](https://github.com/remarkjs/remark-gfm) — Enables GitHub Flavored Markdown features (bare URLs, strikethrough, tables, task lists).

## Usage Example

```typescript
import FleetMarkdown from "components/FleetMarkdown";

const MyPage = () => (
  <FleetMarkdown
    markdown={`
## Query Info

Run this query to check disk usage:

\`\`\`sql
SELECT * FROM disk_info;
\`\`\`

Visit [Fleet docs](https://fleetdm.com/docs) for more.
    `}
    className="my-custom-class"
    name="disk-info-query"
  />
);
```
