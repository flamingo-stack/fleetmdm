Renders the `BackButton` component and verifies it correctly displays both the provided text label and the chevron-left icon.

## Key Components

- **`describe("BackButton - component")`** — Test suite for the `BackButton` component
- **`renders text and icon`** — Asserts that the component renders the `text` prop and the `chevron-left-icon` test ID

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import BackButton from "./BackButton";

render(<BackButton text="Back to software" />);

expect(screen.getByText("Back to software")).toBeInTheDocument();
expect(screen.getByTestId("chevron-left-icon")).toBeInTheDocument();
```

## Notes

- Uses `@testing-library/react` for rendering and querying the DOM
- The icon is located via `data-testid="chevron-left-icon"` — ensure the `BackButton` implementation sets this attribute on the icon element
- Source: [`BackButton.tests.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/BackButton.tests.tsx)
