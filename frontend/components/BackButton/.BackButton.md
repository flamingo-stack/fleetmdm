A reusable navigation button component that navigates either to a specified path or the previous browser history entry.

## Key Components

### `IBackButtonProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | `"Back"` | Button label text |
| `path` | `string` | — | Target route path; falls back to `browserHistory.goBack()` if omitted |
| `className` | `string` | — | Additional CSS classes |

### `BackButton`
Default export. Renders an inverse-styled `Button` with a left chevron icon. Calls `browserHistory.push(path)` when `path` is provided, otherwise calls `browserHistory.goBack()`.

## Usage Example

```typescript
// Navigate to a specific path
<BackButton path="/hosts" text="Back to Hosts" />

// Navigate to the previous page (default behavior)
<BackButton />

// With custom class and text
<BackButton text="Return" className="my-custom-class" />
```
