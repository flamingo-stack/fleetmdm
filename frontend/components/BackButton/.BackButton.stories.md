Storybook stories file for the `BackButton` component, providing interactive UI documentation and visual testing via Storybook.

## Key Components

- **`meta`** — Storybook metadata configuration defining the component title (`Components/BackButton`), the component under test, and default args (`text: "Back"`).
- **`Basic`** — A default story rendering `BackButton` with the base args applied, serving as the baseline visual snapshot.

## Usage Example

```typescript
// Extend with additional stories as needed
export const CustomLabel: Story = {
  args: {
    text: "Go Back",
  },
};
```

To run Storybook and view this story locally:

```bash
npm run storybook
```

Navigate to **Components → BackButton** in the Storybook sidebar to interact with the `Basic` story.

## Notes

- Stories live alongside the component at [`app/.../BackButton.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/app).
- Default `text` prop is `"Back"` — override via `args` in individual stories.
- Follows the `StoryObj` pattern (Storybook v7+ CSF3 format).
