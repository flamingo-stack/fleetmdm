Storybook stories for the `ModalFooter` component, demonstrating its layout variants with primary action buttons, secondary icon buttons, and scroll shadow behavior.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Default` | `Story` | Full layout with primary buttons (dropdown + close) and secondary icon buttons (download + delete) |
| `WithTopScrolling` | `Story` | Same as `Default` but with `isTopScrolling: true` to show the top shadow/border |
| `WithoutSecondaryButtons` | `Story` | Primary buttons only, no secondary button slot |

## Usage Example

```typescript
import ModalFooter from "./ModalFooter";
import Button from "components/buttons/Button";

// Basic usage matching the Default story
<ModalFooter
  primaryButtons={
    <Button onClick={() => handleClose()}>Close</Button>
  }
  secondaryButtons={
    <Button variant="icon" onClick={() => handleDownload()}>
      <Icon name="download" />
    </Button>
  }
  isTopScrolling={false}
/>
```

## Props Reference

| Prop | Description |
|---|---|
| `primaryButtons` | Right-aligned actions (e.g., confirm/cancel, dropdowns) |
| `secondaryButtons` | Left-aligned supplementary icon buttons |
| `isTopScrolling` | When `true`, applies a visual separator (shadow/border) above the footer to indicate scrollable content above |
