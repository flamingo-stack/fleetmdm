A reusable React component that renders a standardized modal footer with support for primary and secondary button groups, and an optional top border to indicate scrollable modal content.

## Key Components

- **`ModalFooter`** — Default export; functional component rendering a structured footer layout
- **`IModalFooterProps`** — TypeScript interface defining the component's props:
  - `primaryButtons` *(required)* — Main action buttons (e.g., confirm/submit)
  - `secondaryButtons` *(optional)* — Secondary actions (e.g., cancel/back)
  - `className` *(optional)* — Additional CSS class for the wrapper
  - `isTopScrolling` *(optional, default: `false`)* — Adds a top border (`ui-fleet-black-10`) when modal content is scrollable

## Usage Example

```typescript
import ModalFooter from "components/ModalFooter";

<ModalFooter
  isTopScrolling={isScrolling}
  primaryButtons={
    <Button onClick={handleConfirm}>Confirm</Button>
  }
  secondaryButtons={
    <Button variant="text-link" onClick={handleCancel}>
      Cancel
    </Button>
  }
/>
```

## Notes

- The `isTopScrolling` prop dynamically applies a `1px solid` top border using the `COLORS["ui-fleet-black-10"]` design token, visually signaling to users that content above is scrollable.
- Button layout uses separate wrapper `div`s for primary and secondary groups, enabling independent CSS targeting via `modal-footer__primary-buttons-wrapper` and `modal-footer__secondary-buttons-wrapper`.
