Defines typography constants for font sizes and weights, converting pixel values to `rem` units for consistent scaling across the UI.

## Key Components

- **`FONT_SIZES`** — Named size scale from `xxx-small` (10px) to `large` (24px), all converted to `rem` via the `pxToRem` helper
- **`FONT_WEIGHTS`** — Two weight levels: `regular` (400) and `bold` (600)

## Usage Example

```typescript
import { FONT_SIZES, FONT_WEIGHTS } from "./fonts";

const styles = {
  fontSize: FONT_SIZES["x-small"],   // "0.8125rem"
  fontWeight: FONT_WEIGHTS.bold,     // 600
};
```

## Size Reference

| Token | px | rem |
|---|---|---|
| `xxx-small` | 10px | 0.625rem |
| `xx-small` | 12px | 0.75rem |
| `x-small` | 13px | 0.8125rem |
| `small` | 16px | 1rem |
| `medium` | 20px | 1.25rem |
| `large` | 24px | 1.5rem |
