Defines and exports icon size constants and types used across the Fleet MDM UI for consistent icon sizing.

## Key Components

- **`ICON_SIZES`** — Primary icon size map with pixel values for six named sizes (`small` through `extra-large`), using a base-16 scale.
- **`ICON_SIZES_BASE14`** — Alternate icon size map scaled to a base-14 grid, providing four sizes with fractional values.
- **`SOFTWARE_ICON_SIZES`** — Icon size map for software-related icons, ranging from `xsmall` (20px) to `xlarge` (96px).
- **`IconSizes`** — TypeScript union type derived from the keys of `ICON_SIZES`.
- **`SoftwareIconSizes`** — Explicit union type for software icon size keys.

## Usage Example

```typescript
import {
  ICON_SIZES,
  IconSizes,
  SOFTWARE_ICON_SIZES,
  SoftwareIconSizes,
} from "./icon_sizes";

// Use a named size constant
const iconSize: string = ICON_SIZES["large"]; // "24"

// Type-safe size prop
function renderIcon(size: IconSizes) {
  return `<Icon width="${ICON_SIZES[size]}" height="${ICON_SIZES[size]}" />`;
}

renderIcon("medium"); // width="16" height="16"

// Software icon sizing
const softwareSize: string = SOFTWARE_ICON_SIZES["xlarge"]; // "96"
```
