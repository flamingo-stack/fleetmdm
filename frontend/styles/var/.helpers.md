Utility function for converting pixel values to rem units, assuming a base font size of 16px.

## Key Components

- **`pxToRem(px: number): string`** — Default export. Accepts a pixel value and returns a rem string (e.g., `16` → `"1rem"`).

## Usage Example

```typescript
import pxToRem from './helpers';

const fontSize = pxToRem(24);  // "1.5rem"
const spacing = pxToRem(8);   // "0.5rem"
const base = pxToRem(16);     // "1rem"
```
