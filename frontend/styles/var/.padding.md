Design token file that defines the standardized padding scale for the Flamingo design system, converting pixel values to `rem` units via a helper utility.

## Key Components

- **`PADDING`** — Object map of named padding tokens to their `rem` values (or `"auto"`), ranging from `2px` to `80px`
- **`Padding`** — TypeScript union type derived from the keys of `PADDING`, enabling type-safe padding references throughout the codebase

## Token Scale

| Token | Value | Notes |
|---|---|---|
| `pad-auto` | `auto` | |
| `pad-xxsmall` | `0.125rem` | 2px |
| `pad-xsmall` | `0.25rem` | 4px |
| `pad-small` | `0.5rem` | 8px |
| `pad-icon` | `0.875rem` | 14px |
| `pad-medium` | `1rem` | 16px |
| `pad-large` | `1.5rem` | 24px — vertical main page component gap |
| `pad-xlarge` | `2rem` | 32px — vertical page margins |
| `pad-xxlarge` | `2.5rem` | 40px |
| `pad-xxxlarge` | `5rem` | 80px |

## Usage Example

```typescript
import { PADDING, Padding } from "./padding";

// Access a token value directly
const pageMargin = PADDING["pad-xlarge"]; // "2rem"

// Type-safe padding parameter
function applyPadding(token: Padding) {
  return PADDING[token];
}

applyPadding("pad-large");  // ✅ valid
applyPadding("pad-custom"); // ❌ TypeScript error
```
