Custom TypeScript ambient declarations for Fleet's module system, enabling type-safe imports of static assets and global feature flag definitions.

## Key Components

| Declaration | Type | Description |
|---|---|---|
| `*.png` | Module | String path for PNG image imports |
| `*.svg` | Module | String path for SVG image imports |
| `*.gif` | Module | String path for GIF image imports |
| `*.pdf` | Module | String path for PDF file imports |
| `*.mp4` | Module | String path for MP4 video imports |
| `featureFlags` | Global `const` | Key-value map for runtime feature flag access |

## Usage Example

```typescript
// Static asset imports — resolved to string paths by the bundler
import logo from "./assets/logo.png";
import icon from "./assets/icon.svg";
import animation from "./assets/loading.gif";
import manual from "./docs/manual.pdf";
import demo from "./media/demo.mp4";

// Feature flags — globally available, no import needed
if (featureFlags["newDashboard"]) {
  renderNewDashboard();
}
```

## Notes

- Asset module declarations allow bundlers (e.g., Webpack) to resolve static files as string URLs without TypeScript errors.
- `featureFlags` is declared as a global `const` with an index signature, making it accessible throughout the app without explicit imports.
- The `type` in the `featureFlags` value type appears to be a placeholder — consider replacing with `boolean` or a union type for stricter safety.
