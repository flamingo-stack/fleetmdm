TypeScript declaration file that extends `react-table`'s module types to merge all plugin-specific interfaces into the core table types, enabling full type safety when using multiple `react-table` plugins together.

## Key Components

Module augmentation for `react-table` that extends the following interfaces:

| Interface | Plugins Merged |
|---|---|
| `TableOptions` | Expanded, Filters, GlobalFilters, GroupBy, Pagination, ResizeColumns, RowSelect, RowState, SortBy |
| `Hooks` | Expanded, GroupBy, RowSelect, SortBy |
| `TableInstance` | ColumnOrder, Expanded, Filters, GlobalFilters, GroupBy, Pagination, RowSelect, RowState, SortBy |
| `TableState` | ColumnOrder, Expanded, Filters, GlobalFilters, GroupBy, Pagination, ResizeColumns, RowSelect, RowState, SortBy |
| `ColumnInterface` | Filters, GlobalFilters, GroupBy, ResizeColumns, SortBy |
| `ColumnInstance` | Filters, GroupBy, ResizeColumns, SortBy |
| `Cell` | GroupBy, RowState |
| `Row` | Expanded, GroupBy, RowSelect, RowState |

## Usage Example

This file requires no direct import — placing it in your project automatically applies the augmentations globally.

```typescript
// No import needed; types are merged at compile time
import { useTable, useSortBy, usePagination, useFilters } from "react-table";

function MyTable<D extends Record<string, unknown>>({ data, columns }) {
  const {
    // UseSortByInstanceProps methods are now typed
    toggleSortBy,
    // UsePaginationInstanceProps methods are now typed
    nextPage,
    previousPage,
    // UseFiltersInstanceProps methods are now typed
    setFilter,
  } = useTable<D>({ columns, data }, useFilters, useSortBy, usePagination);
}
```

## Notes

- `TableOptions` intentionally extends `Record<string, any>` to allow arbitrary plugin options, matching the loose nature of the underlying JavaScript library.
- To restrict options to only used plugins, replace `Record<string, any>` with a stricter union type matching your plugin set.
- Source: [`react-table-config.d.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/react-table-config.d.ts)
