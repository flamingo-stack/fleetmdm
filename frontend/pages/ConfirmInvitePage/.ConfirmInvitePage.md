Renders the invite confirmation page, allowing new users to complete registration by validating an invite token and submitting their account details.

## Key Components

- **`ConfirmInvitePage`** — Main page component that handles the full invite confirmation flow
- **`useQuery("invite", ...)`** — Fetches and validates the invite token from the URL params via `inviteAPI.verify`
- **`onSubmit`** — Async handler that calls `usersAPI.create` with form data, then redirects to login on success
- **`renderContent`** — Conditionally renders a `Spinner`, an error message, or the `ConfirmInviteForm` based on invite validation state

## Usage Example

```typescript
// Mounted via React Router at the invite confirmation route
<Route
  path={paths.CONFIRM_INVITE}
  component={ConfirmInvitePage}
/>
```

```typescript
// Form submission triggers user creation and redirects to login
const dataForAPI: ICreateUserWithInvitationFormData = {
  email: validInvite?.email || "",
  invite_token,
  name: formData.name,
  password: formData.password,
  password_confirmation: formData.password_confirmation,
};
await usersAPI.create(dataForAPI);
router.push(paths.LOGIN);
```

## Behavior

| State | Rendered Output |
|---|---|
| Authenticated user | Redirects to `/dashboard` |
| Verifying invite | `<Spinner />` |
| Invalid/expired token | Error message |
| Valid invite | Pre-filled `ConfirmInviteForm` |
