Handles the reset password flow for both token-based (unauthenticated) and logged-in user forced password reset scenarios, redirecting appropriately based on auth state and user role.

## Key Components

- **`ResetPasswordPage`** — Main page component accepting `location` (query token) and `router` props
- **`continueWithLoggedInUser`** — Calls `performRequiredPasswordReset` for logged-in users requiring a forced reset, then refreshes app config and redirects to dashboard
- **`onSubmit`** — Branches between token-based reset (`usersAPI.resetPassword`) and logged-in forced reset based on `currentUser` presence
- **Auth guards (useEffect)** — Redirects to `/login` if no `currentUser` and no token; redirects to `/no-access` if user has no global role and no team memberships

## Usage Example

```typescript
// Rendered by the router at the reset-password path
// Token-based flow: /reset-password?token=abc123
// Forced reset flow: user lands here after login when reset is required

<ResetPasswordPage
  location={{ query: { token: "abc123" } }}
  router={injectedRouter}
/>
```

## Redirect Logic

```text
No currentUser + no token  →  /login
User with no role/teams    →  /no-access
Token-based reset success  →  /login
Forced reset success       →  /dashboard
```

## Dependencies

| Import | Purpose |
|---|---|
| `usersAPI.resetPassword` | Token-based password reset |
| `usersAPI.performRequiredPasswordReset` | Forced reset for logged-in users |
| `configAPI.loadAll` + `setConfig` | Refreshes app config post-reset |
| `formatErrorResponse` | Normalizes API errors for form display |
