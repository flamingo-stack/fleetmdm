Unit tests for the `generateSoftwareOptionHelpText` helper, verifying platform/extension label and version subtitle generation across all software title types.

## Key Components

- **`generateSoftwareOptionHelpText`** — the function under test, imported from `./helpers`
- **Mock factories** — `createMockSoftwareTitle`, `createMockSoftwarePackage`, `createMockAppStoreApp` from `__mocks__/softwareMock`

## Test Coverage

| Scenario | Expected Output |
|---|---|
| Windows `.exe` package with version | `"Windows (.exe) • 8.9.6.4"` |
| macOS `.pkg` package with version | `"macOS (.pkg) • 1.2.3"` |
| App Store (VPP) app with version | `"macOS (App Store) • 5.0.0"` |
| VPP app without version | `"macOS (App Store)"` |
| Package with empty version string | `"Windows (.exe)"` |
| Unknown source with version only | `"1.2.3"` (no leading separator) |
| No package and no platform | `""` (empty string) |

## Usage Example

```typescript
import { generateSoftwareOptionHelpText } from "./helpers";
import { createMockSoftwareTitle, createMockSoftwarePackage } from "__mocks__/softwareMock";

const title = createMockSoftwareTitle({
  source: "apps",
  app_store_app: null,
  software_package: createMockSoftwarePackage({
    name: "Fleet.pkg",
    version: "2.0.0",
  }),
});

generateSoftwareOptionHelpText(title); // → "macOS (.pkg) • 2.0.0"
```
