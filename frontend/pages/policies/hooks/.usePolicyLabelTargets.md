Manages policy label targeting state, providing controlled include/exclude label selections and building the API payload expected by the Fleet policy endpoints.

## Key Components

### `usePolicyLabelTargets(args?)`
The default export hook that encapsulates all label-targeting state for a policy form. Accepts optional seed arrays (`includeAny`, `includeAll`, `excludeAny`, `excludeAll`) to hydrate state from an existing policy and returns an `IUsePolicyLabelTargets` object.

### `buildPolicyLabelsPayload(args)`
Internal helper that maps UI state (target type, include/exclude mode + selections) to the snake_case arrays (`labels_include_any`, `labels_include_all`, `labels_exclude_any`, `labels_exclude_all`) the policy API expects. Inactive scopes are sent as empty arrays to clear them on the backend.

### `derivePolicyTargetState(args)`
Derives initial controlled-component state from a policy's stored label arrays, resolving `targetType` to `"All hosts"` when all arrays are empty (create mode) or `"Custom"` when any labels are present.

### `IUsePolicyLabelTargets` (exported interface)
Shape of the hook's return value, exposing `selectorProps` (ready to spread onto `TargetLabelSelector`), `selectedTargetType`, `hasCustomLabels`, and `getLabelsPayload`.

## Usage Example

```typescript
import usePolicyLabelTargets from "hooks/usePolicyLabelTargets";
import TargetLabelSelector from "components/TargetLabelSelector";

const PolicyForm = ({ policy }) => {
  const { selectorProps, hasCustomLabels, getLabelsPayload } =
    usePolicyLabelTargets({
      includeAny: policy.labels_include_any,
      includeAll: policy.labels_include_all,
      excludeAny: policy.labels_exclude_any,
      excludeAll: policy.labels_exclude_all,
    });

  const handleSave = () => {
    const payload = {
      name: policy.name,
      query: policy.query,
      ...getLabelsPayload(), // merges label arrays into save payload
    };
    // submit payload to API
  };

  return <TargetLabelSelector {...selectorProps} />;
};
```

> **Note:** Label fetching is gated on `isPremiumTier && !!currentTeam` from `AppContext`; the selector remains functional but empty for free-tier or global contexts.
