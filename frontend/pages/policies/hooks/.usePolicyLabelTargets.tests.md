Test suite for the `usePolicyLabelTargets` hook, verifying label fetching, target type selection, payload construction, and error/loading state handling across all include/exclude label scope combinations.

## Key Components

| Component | Purpose |
|-----------|---------|
| `premiumWrapper` | Builds a React Query + `AppContext` provider with premium tier and a mock team |
| `buildWrapper` | Generic wrapper factory accepting partial `IAppContext` overrides |
| `labelSummariesHandler` | MSW handler intercepting `GET /api/latest/fleet/labels/summary` |
| `STORED_INCLUDE_ANY / ALL` | Referentially stable seed arrays simulating `PolicyContext` data |
| `STORED_EXCLUDE_ANY / ALL` | Referentially stable seed arrays for exclude label scenarios |

## Test Coverage

```text
usePolicyLabelTargets
 ├── defaults to All hosts and empty payload with no initial labels
 ├── fetches and exposes team labels via selectorProps
 ├── skips label fetch when no team is selected
 ├── seeds Custom + include-any from stored policy labels
 ├── seeds Custom + include-all from stored policy labels
 ├── seeds Custom + exclude-any from stored policy labels
 ├── seeds Custom + exclude-all from stored policy labels
 ├── builds include-any payload on user selection
 ├── clears payload when switching back to All hosts
 ├── migrates include selection when mode switches to All
 ├── migrates exclude selection when mode switches to All
 ├── removes a label from payload on deselect
 ├── builds a combined include + exclude payload
 ├── reports loading state during label fetch
 └── surfaces error state on failed labels request (403)
```

## Usage Example

```typescript
// Standard hook render with premium context
const { result } = renderHook(() => usePolicyLabelTargets(), {
  wrapper: premiumWrapper(),
});

// Simulate user switching to Custom targeting and selecting a label
act(() => result.current.selectorProps.onSelectTargetType("Custom"));
act(() =>
  result.current.selectorProps.includeConfig.onSelectLabel({
    name: "Fun",
    value: true,
  })
);

expect(result.current.getLabelsPayload()).toMatchObject({
  labels_include_any: ["Fun"],
  labels_include_all: [],
  labels_exclude_any: [],
  labels_exclude_all: [],
});
```

## Key Patterns

- **MSW per-test overrides** — the error test replaces the default handler with a `403` response using `mockServer.use(...)` inline, exercising the hook's `isErrorLabels` state without retries
- **Referentially stable seed data** — label arrays are module-level constants to avoid re-render identity issues, mirroring real `PolicyContext` behavior
- **`act` + `waitFor` interplay** — synchronous state mutations use `act`; async API resolution uses `waitFor`, keeping test determinism intact
