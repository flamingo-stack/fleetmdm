Custom React hook that orchestrates saving a single policy's automation settings — both per-policy fields (software, scripts, calendar events, etc.) and webhook/ticket membership — via parallel API calls with React Query.

## Key Components

### `IPolicyAutomationUpdate`
A `Pick` type containing the per-policy automation fields settable from the automations modal:
- `software_title_id`, `script_id`, `calendar_events_enabled`, `conditional_access_enabled`, `continuous_automations_enabled`

### `IUpdatePolicyAutomationsVars`
Mutation input shape:
- `policyUpdate?` — per-policy automation field changes
- `webhookOrTicketUpdate?` — `{ enabled: boolean }` controlling this policy's membership in the global/team failing-policies webhook list

### `useUpdatePolicyAutomations` (default export)
Returns a `useMutation` result. Internally:
- **`saveWebhookOrTicketMembership`** — merges/removes the policy ID from `webhook_settings.failing_policies_webhook.policy_ids`, then calls either `configAPI.update` (global) or `teamsAPI.update` (team-scoped) and updates the React Query cache.
- **Mutation function** — fans out up to two parallel requests (`teamPoliciesAPI.update` and `saveWebhookOrTicketMembership`) via `Promise.all`.
- **`onError`** — invalidates the relevant cache key (`config` or `teams/{id}`) before forwarding to the caller's handler.

## Usage Example

```typescript
const { mutate: updateAutomations, isLoading } = useUpdatePolicyAutomations({
  policy,
  teamIdForApi: 42,
  isGlobalPolicy: false,
  automationsConfig: teamConfig,
  onSuccess: () => refetchPolicy(),
  onError: () => renderFlash("error", "Failed to save automations."),
});

// Save only per-policy fields
updateAutomations({
  policyUpdate: { script_id: 7, calendar_events_enabled: true },
});

// Save only webhook membership
updateAutomations({
  webhookOrTicketUpdate: { enabled: true },
});

// Save both simultaneously
updateAutomations({
  policyUpdate: { software_title_id: 3 },
  webhookOrTicketUpdate: { enabled: false },
});
```

> **Note:** A team-scoped policy requires `teamIdForApi` to be defined — the hook throws synchronously during render if it is missing.
