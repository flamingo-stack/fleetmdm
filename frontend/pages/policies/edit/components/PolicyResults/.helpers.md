Utility helper for aggregating policy host response results into yes/no pass/fail counts.

## Key Components

- **`getYesNoCounts(hostResponses)`** — Reduces an array of `IPolicyHostResponse` objects into a `{ yes, no }` count object. A host response is counted as `yes` if it contains query results (`query_results?.length` is truthy), otherwise `no`.

## Usage Example

```typescript
import { getYesNoCounts } from "./helpers";
import { IPolicyHostResponse } from "interfaces/host";

const responses: IPolicyHostResponse[] = [
  { query_results: [{ column: "value" }] }, // yes
  { query_results: [] },                     // no
  { query_results: null },                   // no
];

const counts = getYesNoCounts(responses);
// => { yes: 1, no: 2 }
```

## Notes

- Hosts with a non-empty `query_results` array are treated as passing (`yes`).
- Hosts with an empty array, `null`, or `undefined` `query_results` are treated as failing (`no`).
- Returns a plain object `{ yes: number, no: number }` suitable for display in policy compliance summaries.
