Displays live policy query results in a tabbed interface, showing host pass/fail responses and query errors with CSV export capabilities.

## Key Components

- **`PolicyResults`** — Main component that renders the results UI for a running or completed policy query
- **`renderResultsTable()`** — Conditionally renders awaiting state, empty state, or the results table with pass/fail percentages
- **`renderErrorsTable()`** — Renders the errors tab with error count and export action
- **`renderPassFailPcts()`** — Calculates and displays yes/no host percentages with tooltips
- **`renderTableButtons()`** — Shared CTA buttons for "Show query" and "Export" actions
- **`onExportResults()` / `onExportErrorsResults()`** — Generates and downloads CSV files for results or errors via `FileSaver`

## Props

| Prop | Type | Description |
|---|---|---|
| `campaign` | `ICampaign` | Live query campaign data including host responses and error counts |
| `isQueryFinished` | `boolean` | Whether the policy run has completed |
| `policyName` | `string?` | Used as CSV filename prefix |
| `onRunQuery` | `fn` | Re-run query handler |
| `onStopQuery` | `fn` | Stop query handler |
| `setSelectedTargets` | `fn` | Clears selected targets on done |
| `goToQueryEditor` | `fn` | Navigates back to editor |
| `targetsTotalCount` | `number` | Total hosts targeted |

## Usage Example

```typescript
<PolicyResults
  campaign={activeCampaign}
  isQueryFinished={isFinished}
  policyName="Antivirus Enabled"
  onRunQuery={handleRunQuery}
  onStopQuery={handleStopQuery}
  setSelectedTargets={setSelectedTargets}
  goToQueryEditor={goToQueryEditor}
  targetsTotalCount={42}
/>
```
