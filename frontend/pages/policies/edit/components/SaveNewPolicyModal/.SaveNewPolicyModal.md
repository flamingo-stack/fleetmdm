Modal component for saving a new Fleet policy, handling form validation, platform selection, label targeting, AI autofill, and post-create automation configuration.

## Key Components

### `ISaveNewPolicyModalProps`
Interface defining all required/optional props including:
- `onCreatePolicy` — callback fired with form data and an optional `saveAutomations` closure
- `automationsConfig` / `globalConfig` — configs for webhook/ticket automation patching
- `platformSelector` — injected platform selector hook handle
- `isGlobalPolicy` / `policyTeamId` — determine automation routing (global vs. team)
- AI autofill callbacks: `onClickAutofillDescription`, `onClickAutofillResolution`

### `validatePolicyName(name)`
Pure validation helper returning `{ valid, errors }` — enforces a non-empty policy name.

### `SaveNewPolicyModal` (default export)
Main modal component orchestrating:
- **Form state** via `PolicyContext` (`lastEditedQueryName`, description, resolution, critical flag)
- **Platform targeting** via the injected `platformSelector`
- **Label targeting** via `usePolicyLabelTargets()` (premium tier only)
- **Automation deferral** — since the create API ignores automation fields, a `saveAutomations` async closure is built and passed to `onCreatePolicy`, which PATCHs webhook/ticket settings and team policy updates after creation
- **AI autofill buttons** for description and resolution with tooltip guards when AI features are disabled

## Usage Example

```typescript
<SaveNewPolicyModal
  baseClass="policy-form"
  queryValue={currentSQL}
  onCreatePolicy={handleCreate}
  setIsSaveNewPolicyModalOpen={setModalOpen}
  backendValidators={apiErrors}
  platformSelector={platformSelectorHook}
  isUpdatingPolicy={false}
  isGlobalPolicy={false}
  policyTeamId={42}
  automationsConfig={teamConfig}
  globalConfig={appConfig}
  fleetName="Engineering Fleet"
  router={router}
  isFetchingAutofillDescription={false}
  isFetchingAutofillResolution={false}
  onClickAutofillDescription={handleAutofillDescription}
  onClickAutofillResolution={handleAutofillResolution}
/>
```
