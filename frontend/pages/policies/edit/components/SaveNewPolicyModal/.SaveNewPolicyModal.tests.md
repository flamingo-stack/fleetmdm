Test suite for the `SaveNewPolicyModal` component, validating label targeting behavior across free and premium tier contexts when creating new Fleet policies.

## Key Components

- **`labelSummariesHandler`** — MSW handler mocking the `/api/latest/fleet/labels/summary` endpoint with two test labels (`Fun`, `Fresh`)
- **`defaultProps`** — Baseline prop configuration shared across all test cases, including mock platform selector, callbacks, and config objects
- **`describe("SaveNewPolicyModal")`** — Top-level suite with nested premium-tier block covering all label targeting scenarios

## Test Coverage

| Test | Description |
|------|-------------|
| Free tier | Target selector is hidden (`All hosts` radio absent) |
| Premium — default | `All hosts` radio is present and checked by default |
| Premium — Custom mode | Save button disabled with no labels; enabled after selecting one |
| Premium — include any | `labels_include_any` payload sent with selected label names |
| Premium — exclude any | `labels_exclude_any` payload sent after switching to Exclude tab |
| Premium — include all | `labels_include_all` sent when "All" match mode selected on Include tab |
| Premium — exclude all | `labels_exclude_all` sent when "All" match mode selected on Exclude tab |
| Premium — both tabs | Both include and exclude payloads sent when both tabs have selections |
| Premium — All hosts save | `labels_include_any` is empty `[]` when saving in All hosts mode |

## Usage Example

```typescript
// Running a single test block
// Install MSW handler, render with PolicyProvider wrapper, then assert payload shape
mockServer.use(labelSummariesHandler);

render(
  <PolicyProvider>
    <SaveNewPolicyModal {...defaultProps} onCreatePolicy={onCreatePolicy} />
  </PolicyProvider>
);

await waitFor(() => {
  expect(screen.getByLabelText("All hosts")).toBeInTheDocument();
});

await userEvent.click(screen.getByLabelText("Custom"));
// ... select labels, click Save, assert onCreatePolicy payload
```
