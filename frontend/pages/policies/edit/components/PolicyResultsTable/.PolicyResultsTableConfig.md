Defines the table configuration for displaying policy compliance results, including column headers and data formatting for host policy pass/fail status.

## Key Components

### `generateTableHeaders(): IDataColumn[]`
Returns the column definitions for the policy results table:
- **Host** — Displays the host's `display_name` with case-insensitive sorting
- **Status** — Renders a pass/fail icon (`success`/`error`) based on the presence of `query_results`

### `generateDataSet(policyHostsList): IPolicyHostResponse[]`
Memoized function that sorts the list of policy host responses alphabetically by `display_name` (case-insensitive ascending).

### Interfaces
- **`IHeaderProps`** — Extends `ColumnInstance` with `IDataColumn` for typed header rendering
- **`ICellProps`** — Provides `cell.value` (string) and `row.original` (`IPolicyHostResponse`) for cell rendering
- **`IDataColumn`** — Column shape with `Header`, `Cell`, optional `title`, `accessor`, `disableSortBy`, and `sortType`

## Usage Example

```typescript
import {
  generateTableHeaders,
  generateDataSet,
} from "./PolicyResultsTableConfig";

const columns = generateTableHeaders();
const data = generateDataSet(policyHostsList);

// Pass into a TableContainer component
<TableContainer
  columns={columns}
  data={data}
/>
```

## Notes
- The **Status** column uses `sortType: "hasLength"` to sort by whether `query_results` is non-empty
- `generateDataSet` is memoized via lodash to avoid redundant sorting on re-renders
- `react/prop-types` ESLint rule is disabled due to a known false-positive in `react-table` Header/Cell definitions
