Renders a read-only table displaying policy execution errors from a live query campaign, wrapping `TableContainer` with pre-configured headers and error data.

## Key Components

- **`PolicyErrorsTable`** — Main functional component that accepts a list of `ICampaignError` objects and renders them in a sortable, non-paginated table
- **`IPolicyErrorsTableProps`** — Props interface:
  - `errorsList: ICampaignError[]` — Array of campaign errors to display
  - `isLoading: boolean` — Controls loading state of the table
  - `resultsTitle?: string` — Optional label for the results count (defaults to `"policies"`)
- **`generateTableHeaders()`** — Imported helper that defines column configuration
- **`generateDataSet(errorsList)`** — Imported helper that transforms raw error objects into table rows

## Usage Example

```typescript
import PolicyErrorsTable from "components/PolicyErrorsTable";
import { ICampaignError } from "interfaces/campaign";

const errors: ICampaignError[] = [
  { host_display_name: "mac-01", osquery_version: "5.9.1", error: "Permission denied" },
];

<PolicyErrorsTable
  errorsList={errors}
  isLoading={false}
  resultsTitle="errors"
/>
```

## Notes

- Sorting defaults to `name` ascending; manual sort mode is enabled (`manualSortBy`)
- Pagination and row count display are both disabled
- Renders an `EmptyState` with `"No hosts are online"` when the error list is empty
- The `baseClass` (`policy-results-table`) is shared with `PolicyResultsTable` — a known TODO exists to differentiate their styles
