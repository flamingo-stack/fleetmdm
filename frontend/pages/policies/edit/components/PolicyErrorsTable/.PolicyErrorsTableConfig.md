Configures table headers and dataset generation for displaying policy run errors, mapping `ICampaignError` data into columns for host name, osquery version, and error message.

## Key Components

- **`generateTableHeaders()`** — Returns an array of `IDataColumn` definitions for three columns: `Host`, `Osquery version`, and `Error`. All columns use `TextCell` for rendering and have sorting disabled.
- **`generateDataSet()`** — Memoized function that accepts an array of `ICampaignError` objects and returns them sorted case-insensitively by `host_display_name` in ascending order.

## Usage Example

```typescript
import {
  generateTableHeaders,
  generateDataSet,
} from "./PolicyErrorsTableConfig";

const columns = generateTableHeaders();
const rows = generateDataSet(campaignErrors);

<TableContainer
  columns={columns}
  data={rows}
/>
```

## Notes

- `generateDataSet` is wrapped with `lodash.memoize`, caching results based on the input reference to avoid redundant sorts on re-renders.
- `react/prop-types` ESLint rule is disabled at the file level due to false positives in table column component definitions.
- Column definitions follow the [react-table](https://react-table.tanstack.com/docs/api/useTable#cell-properties) API (`accessor`, `Cell`, `Header`).
