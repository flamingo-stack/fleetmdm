Test suite for the `PolicyForm` component, covering rendering behavior, validation logic, and save/run action guards across free and premium tier configurations.

## Key Components

- **`labelSummariesHandler`** — MSW request handler that intercepts `GET /api/latest/fleet/labels/summary` and returns mock label data for premium tier tests.
- **`defaultProps`** — Shared prop baseline used across test cases to reduce repetition.
- **Test suite (`describe("PolicyForm - component")`)** — Groups all test cases with shared setup via `beforeEach` for the premium tier sub-suite.

## Test Cases

| Test | Description |
|------|-------------|
| Free tier: no target selector | Asserts the "All hosts" target selector is absent when `isPremiumTier: false` |
| Premium: disabled Save on missing name | Verifies the Save button is disabled when `lastEditedQueryName` is empty |
| Premium: empty query body guard | Regression for [#38348](https://github.com/flamingo-stack/fleetmdm/issues) — `onUpdate` must not be called when query body is empty, even before the 500ms debounced SQL validator fires |
| Premium: save with SQL syntax error | Regression for [#38348](https://github.com/flamingo-stack/fleetmdm/issues) — a syntactically invalid but non-empty query must still allow saving |
| Premium: disabled Save/Run on missing platforms | Validates that missing platform selection disables both buttons with a tooltip |

## Usage Example

```typescript
// Run all PolicyForm tests
npx jest PolicyForm.tests.tsx

// Run a specific test by name
npx jest PolicyForm.tests.tsx -t "does not call onUpdate when Save is clicked with an empty query body"
```

## Notes

- Uses `msw` via `mockServer.use(labelSummariesHandler)` to mock the labels API in premium tier tests.
- The debounced SQL validator (500ms) is a key timing concern — tests explicitly account for whether the debounce has fired using `waitFor` or intentional early clicks.
- All render calls use `createCustomRenderer` with injected `app` and `policy` context to simulate different user roles and tier configurations.
