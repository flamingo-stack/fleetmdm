Renders and manages the policy creation/editing form in Fleet MDM, handling SQL query editing, platform selection, label targeting, automations, and permission-based routing for both new and existing policies.

## Key Components

### `PolicyForm`
The primary exported component that renders the full policy form UI including:
- **SQL editor** — powered by `SQLEditor` with live osquery token linking and debounced SQL validation
- **Platform selector** — filtered by policy SQL compatibility via `usePlatformCompatibility`
- **Label targeting** — via `TargetLabelSelector` and `usePolicyLabelTargets` hook
- **Automations fields** — rendered by `PolicyAutomationsFields` with ref-based handle
- **Permission-based routing** — redirects observers/technicians from edit to details view
- **AI autofill** — description and resolution autofill with loading states

### Key Utilities

| Name | Purpose |
|---|---|
| `validateQuerySQL` | Validates SQL query string; returns `{ valid, errors }` |
| `debounceSQL` | 500ms debounced SQL validation on editor changes |
| `onChangePolicySql` | Updates query body in `PolicyContext` and resets AI autofill state |
| `onAddPatchAutomation` | Calls `teamPoliciesAPI.update` to attach a patch software automation |

### Notable Hooks Used
- `usePlatformCompatibility` — derives compatible platforms from SQL body
- `usePlatformSelector` — manages platform checkbox selection state
- `usePolicyLabelTargets` — manages include/exclude label selector state
- `useUpdatePolicyAutomations` — mutation hook for saving policy automations

## Usage Example

```typescript
<PolicyForm
  router={router}
  teamIdForApi={42}
  policyIdForEdit={null}
  showOpenSchemaActionText={true}
  storedPolicy={undefined}
  isStoredPolicyLoading={false}
  isTeamObserver={false}
  isUpdatingPolicy={false}
  onCreatePolicy={(formData, saveAutomations) => handleCreate(formData)}
  onOsqueryTableSelect={(tableName) => openSchemaSidebar(tableName)}
  goToSelectTargets={() => navigateToTargets()}
  onUpdate={async (formData) => handleUpdate(formData)}
  onOpenSchemaSidebar={() => setSidebarOpen(true)}
  renderLiveQueryWarning={() => <LiveQueryWarning />}
  backendValidators={{}}
  isFetchingAutofillDescription={false}
  isFetchingAutofillResolution={false}
  onClickAutofillDescription={async () => triggerDescriptionAutofill()}
  onClickAutofillResolution={async () => triggerResolutionAutofill()}
  resetAiAutofillData={() => clearAutofillState()}
/>
```

## Notes

- `PolicyContext` is the source of truth for mutable policy fields (name, SQL, platform, etc.); `storedPolicy` prop is used only for immutable metadata.
- `onUpdate` returns a `Promise` so automations can be sequenced after the core policy patch completes.
- GitOps mode disables platform selection and other mutation controls via `gitOpsModeEnabled`.
