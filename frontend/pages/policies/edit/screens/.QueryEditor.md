React component that manages the policy query editor, handling both creation and updating of Fleet MDM policies with AI-powered autofill support for descriptions and resolutions.

## Key Components

### `QueryEditor` (default export)
Main functional component that orchestrates policy form interactions. Consumes `AppContext`, `PolicyContext`, and `NotificationContext` to coordinate state and user feedback.

**Key handlers:**

| Handler | Description |
|---|---|
| `onCreatePolicy` | Debounced policy creation; routes to policy details on success |
| `onUpdatePolicy` | Diffs form data against stored state, skips immutable fields for patch policies |
| `onClickAutofillDescription` | Fetches or reuses AI-generated policy description via `autofillAPI` |
| `onClickAutofillResolution` | Fetches or reuses AI-generated policy resolution via `autofillAPI` |

### `IQueryEditorProps`
TypeScript interface defining required props including router, policy identifiers, loading/observer flags, and callback handlers.

## Usage Example

```typescript
<QueryEditor
  router={router}
  baseClass="policy-editor"
  policyIdForEdit={42}
  storedPolicy={policy}
  storedPolicyError={null}
  showOpenSchemaActionText={true}
  isStoredPolicyLoading={false}
  isTeamObserver={false}
  createPolicy={handleCreatePolicy}
  onOsqueryTableSelect={(table) => console.log(table)}
  goToSelectTargets={() => router.push(PATHS.SELECT_TARGETS)}
  onOpenSchemaSidebar={() => setSchemaOpen(true)}
  renderLiveQueryWarning={() => <LiveQueryWarning />}
  teamIdForApi={3}
/>
```

## Notes

- AI autofill data (`policyAutofillData`) is cached per editing session; calling either autofill handler a second time reuses the cached response rather than making a second API call.
- For **patch** policies, `query` and `platform` fields are stripped before the update request, as the backend rejects them.
- Back navigation resolves to either `filteredPoliciesPath` (from context) or a constructed `MANAGE_POLICIES` path, avoiding a race condition by using a function rather than a constant.
