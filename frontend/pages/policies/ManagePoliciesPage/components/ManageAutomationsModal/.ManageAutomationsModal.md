A modal component for managing policy automations, allowing users to configure webhook/ticket automations and view platform coverage for a specific Fleet MDM policy.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ManageAutomationsModal` | `React.FC` (default export) | Modal form for viewing and updating policy automations |
| `IManageAutomationsModalProps` | Interface | Props contract for the modal component |

### Props

| Prop | Type | Description |
|------|------|-------------|
| `policy` | `IPolicyStats` | Policy to manage automations for |
| `fleetName` | `string` | Display name of the fleet |
| `isGlobalPolicy` | `boolean` | Whether the policy applies globally |
| `teamIdForApi` | `number \| undefined` | `undefined` = all fleets, `0` = unassigned, positive = specific team |
| `automationsConfig` | `IConfig \| ITeamConfig \| undefined` | Current automation configuration |
| `globalConfig` | `IConfig \| undefined` | Global Fleet configuration |
| `refetchPolicies` | `() => void` | Callback to refresh policy list after save |
| `onExit` | `() => void` | Callback to close the modal |

### Internal Behavior

- Uses `useUpdatePolicyAutomations` hook to persist changes via API
- Delegates form state and payload construction to `PolicyAutomationsFields` via an imperative ref handle (`IPolicyAutomationsFieldsHandle`)
- Skips save if payload is invalid or unchanged (`isDirty` check)
- Renders platform icons in a fixed display order: macOS → Windows → Linux → ChromeOS

## Usage Example

```typescript
import ManageAutomationsModal from "./ManageAutomationsModal";

<ManageAutomationsModal
  policy={selectedPolicy}
  fleetName="Acme Corp"
  isGlobalPolicy={false}
  teamIdForApi={42}
  automationsConfig={teamConfig}
  globalConfig={globalConfig}
  refetchPolicies={() => refetch()}
  onExit={() => setShowModal(false)}
/>
```

> **Note:** The modal is content-disabled during save to prevent duplicate submissions. Flash notifications are shown on success or error via `NotificationContext`.
