Confirmation modal component that prompts users to confirm deletion of one or more policies, warning that associated automations (e.g., automatic software install or script run) will also be disabled.

## Key Components

### `DeletePoliciesModal`
Default export. A controlled modal component wrapping `Modal` and `Button` to present a delete confirmation UI.

**Props (`IDeletePoliciesModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `isUpdatingPolicies` | `boolean` | Shared loading state from parent; drives the delete button's loading spinner |
| `onCancel` | `() => void` | Callback fired on cancel button click or modal exit |
| `onSubmit` | `() => void` | Callback fired on delete confirmation or Enter key press |

## Usage Example

```typescript
import DeletePoliciesModal from "components/DeletePoliciesModal";

const PoliciesPage = () => {
  const [showModal, setShowModal] = useState(false);
  const [isUpdating, setIsUpdating] = useState(false);

  const handleDelete = async () => {
    setIsUpdating(true);
    await deleteSelectedPolicies();
    setIsUpdating(false);
    setShowModal(false);
  };

  return (
    <>
      {showModal && (
        <DeletePoliciesModal
          isUpdatingPolicies={isUpdating}
          onCancel={() => setShowModal(false)}
          onSubmit={handleDelete}
        />
      )}
    </>
  );
};
```

## Notes

- Supports keyboard confirmation via `onEnter` (Enter key triggers `onSubmit`).
- The delete `Button` uses `variant="alert"` with a loading state; cancel uses `variant="inverse-alert"`.
- `isUpdatingPolicies` reflects broader parent state — not exclusively scoped to delete operations.
