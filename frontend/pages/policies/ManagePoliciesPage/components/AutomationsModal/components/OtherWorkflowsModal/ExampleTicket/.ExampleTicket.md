Renders a preview screenshot of a policy automation ticket for either Jira or Zendesk integrations, selecting between standard and premium tier images based on the current app context.

## Key Components

- **`ExampleTicket`** – Default export; a React functional component that displays a ticket preview image inside a `Card`
- **`IExampleTicketProps`** – Props interface accepting an optional `integrationType` (`"jira"` or `"zendesk"`)
- **`AppContext`** – Consumed via `useContext` to determine if the current tier is premium, which controls which screenshot variant is shown

## Usage Example

```typescript
import ExampleTicket from "./ExampleTicket";

// Jira preview (auto-selects premium image if isPremiumTier is true)
<ExampleTicket integrationType="jira" />

// Zendesk preview
<ExampleTicket integrationType="zendesk" />
```

## Image Variants

| Integration | Free Tier | Premium Tier |
|-------------|-----------|--------------|
| Jira | `jira-policy-automation-preview-400x419@2x.png` | `jira-policy-automation-preview-premium-400x316@2x.png` |
| Zendesk | `zendesk-policy-automation-preview-400x515@2x.png` | `zendesk-policy-automation-preview-premium-400x483@2x.png` |

> If `integrationType` is undefined or not `"jira"`, the component defaults to rendering the Zendesk screenshot.
