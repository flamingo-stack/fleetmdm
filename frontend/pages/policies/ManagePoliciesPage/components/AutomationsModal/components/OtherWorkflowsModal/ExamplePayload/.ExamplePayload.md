Renders a syntax-highlighted JSON preview of a Fleet policy webhook payload, adapting the output based on the user's tier (free vs. paid).

## Key Components

- **`IHostPreview`** – Interface defining host data shape (`id`, `display_name`, `url`) used within the payload preview.
- **`IExamplePayload`** – Interface for the full webhook payload structure, combining a `timestamp`, `IPolicyWebhookPreviewPayload`, and an array of `IHostPreview` hosts.
- **`ExamplePayload`** – Default exported functional component that:
  - Reads `isFreeTier` from `AppContext` to conditionally strip the `critical` field.
  - Constructs a static example JSON payload and renders it via `syntaxHighlight`.

## Usage Example

```typescript
import ExamplePayload from "components/ExamplePayload";

// Renders a read-only, syntax-highlighted webhook payload preview
const WebhookConfigPage = () => (
  <div>
    <h2>Example Webhook Payload</h2>
    <ExamplePayload />
  </div>
);
```

## Behavior Notes

- The `critical` field is removed from the policy object when `isFreeTier` is `true`, reflecting feature availability differences between Fleet tiers.
- The payload is rendered using [`dangerouslySetInnerHTML`](https://react.dev/reference/react-dom/components/common#dangerously-setting-the-inner-html) with output from `syntaxHighlight`, which handles HTML escaping and colorization — ensure `syntaxHighlight` sanitizes its output appropriately.
- The displayed endpoint (`POST https://server.com/example`) is a static placeholder for illustration purposes.
