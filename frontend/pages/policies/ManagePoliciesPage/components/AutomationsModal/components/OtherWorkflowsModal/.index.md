Re-exports the `OtherWorkflowsModal` component and its associated `IOtherWorkflowsModalSubmit` type from the module's main implementation file.

## Key Components

- **`default`** — The `OtherWorkflowsModal` React component (re-exported as default)
- **`IOtherWorkflowsModalSubmit`** — TypeScript interface describing the submit payload for the modal

## Usage Example

```typescript
import OtherWorkflowsModal from "./OtherWorkflowsModal";
import type { IOtherWorkflowsModalSubmit } from "./OtherWorkflowsModal";
```

Or via the barrel export:

```typescript
import OtherWorkflowsModal, {
  type IOtherWorkflowsModalSubmit,
} from "./path/to/OtherWorkflowsModal";
```
