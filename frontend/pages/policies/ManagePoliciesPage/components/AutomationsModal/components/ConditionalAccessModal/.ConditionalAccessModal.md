A modal form component for configuring conditional access automation in Fleet MDM, allowing administrators to enable or disable SSO blocking for end users failing policies.

## Key Components

### Interfaces

- **`IConditionalAccessModalData`** — Form output shape: `{ enabled: boolean }`
- **`IConditionalAccessModalProps`** — Component props:
  - `configured` — Whether a conditional access provider is connected
  - `enabled` — Current enabled state
  - `gitOpsModeEnabled` — Disables the slider when GitOps mode is active
  - `providerText` — Display name of the identity provider (e.g., "Microsoft Entra ID")

### Imperative Handle (`IAutomationFormHandle`)

Exposes three methods via `ref`:

| Method | Behavior |
|---|---|
| `getFormData()` | Returns `{ enabled }` if configured, otherwise `null` |
| `validate()` | Always returns `true` |
| `isDirty()` | Returns `true` when configured and the toggle state has changed |

### Conditional Rendering

- **Not configured** — Renders an `InfoBanner` with a link to the Conditional Access settings page (clickable for global admins; plain bold text for non-admins)
- **Configured** — Renders a `Slider` toggle to enable/disable the automation

## Usage Example

```typescript
const modalRef = useRef<IAutomationFormHandle<IConditionalAccessModalData>>(null);

<ConditionalAccessModal
  ref={modalRef}
  configured={true}
  enabled={false}
  gitOpsModeEnabled={false}
  providerText="Microsoft Entra ID"
/>

// On save:
const data = modalRef.current?.getFormData(); // { enabled: true }
const dirty = modalRef.current?.isDirty();    // true if toggled
```
