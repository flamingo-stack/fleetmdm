Barrel export file that re-exports the `ConditionalAccessModal` component and its associated TypeScript type from the module's implementation file.

## Key Components

- **`default`** — The `ConditionalAccessModal` component (default export)
- **`IConditionalAccessModalData`** — TypeScript interface defining the data shape required by the modal

## Usage Example

```typescript
import ConditionalAccessModal, {
  type IConditionalAccessModalData,
} from "./ConditionalAccessModal";
```
