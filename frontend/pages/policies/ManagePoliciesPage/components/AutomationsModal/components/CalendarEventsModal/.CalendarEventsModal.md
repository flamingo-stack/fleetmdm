A form component for configuring calendar event automations that schedule maintenance windows for end users failing policies, with support for enabling/disabling the feature and setting a resolution webhook URL.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CalendarEventsModal` | `React.ForwardRefExoticComponent` | Main form component exposing an imperative handle via `ref` |
| `ICalendarEventsModalData` | `interface` | Form data shape: `{ enabled: boolean, url: string }` |
| `IAutomationFormHandle` | `interface` (imported) | Generic ref handle with `getFormData`, `validate`, and `isDirty` methods |

**Ref handle methods (via `useImperativeHandle`):**

| Method | Behavior |
|--------|----------|
| `getFormData()` | Returns `ICalendarEventsModalData` if configured, otherwise `null` |
| `validate()` | Validates webhook URL when feature is enabled; returns `true` if valid |
| `isDirty()` | Returns `true` if `enabled` or `url` has changed from initial props |

## Props

| Prop | Type | Description |
|------|------|-------------|
| `configured` | `boolean` | Whether Google Calendar integration is connected |
| `enabled` | `boolean` | Initial enabled state |
| `url` | `string` | Initial webhook URL |
| `gitOpsModeEnabled` | `boolean?` | Disables form fields when GitOps mode is active |

## Usage Example

```typescript
import { useRef } from "react";
import CalendarEventsModal from "./CalendarEventsModal";
import { IAutomationFormHandle } from "../../types";
import { ICalendarEventsModalData } from "./CalendarEventsModal";

const ref = useRef<IAutomationFormHandle<ICalendarEventsModalData>>(null);

const handleSave = () => {
  if (ref.current?.validate()) {
    const data = ref.current.getFormData();
    // submit data to API
  }
};

<CalendarEventsModal
  ref={ref}
  configured={true}
  enabled={false}
  url=""
  gitOpsModeEnabled={false}
/>
```

> **Note:** When `configured` is `false`, the component renders an `InfoBanner` prompting admins to connect Fleet to Google Workspace via **Settings > Integrations > Calendars** before calendar automations can be used.
