A modal component that renders a preview of the calendar event end users receive when their device fails a Fleet policy, showing either a generic or policy-specific maintenance notification.

## Key Components

- **`CalendarEventPreviewModal`** — Default export; a React functional component rendering a `Modal` with a simulated calendar event card
- **`ICalendarEventPreviewModalProps`** — Interface accepting `onCancel` callback and an optional `policy` (`IFormPolicy`)
- **`showGenericPreview`** — Derived boolean; `true` when the policy lacks `description` or `resolution`, falling back to generic Fleet self-remediation instructions
- **`orgName`** — Pulled from `AppContext` (`config.org_info.org_name`) and injected into the preview body copy

## Behavior

| Condition | Preview Content |
|---|---|
| `policy` has `description` + `resolution` | Policy name shown in header; description → **Why it matters**; resolution → **Maintenance required** |
| Missing `description` or `resolution` | Generic org-level copy with step-by-step Fleet self-remediation instructions |

## Usage Example

```typescript
import CalendarEventPreviewModal from "./CalendarEventPreviewModal";

<CalendarEventPreviewModal
  onCancel={() => setShowPreview(false)}
  policy={{
    name: "macOS encryption enabled",
    description: "Full-disk encryption protects company data.",
    resolution: "Enable FileVault in System Settings > Privacy & Security.",
    // ...other IFormPolicy fields
  }}
/>
```

Omit `policy` (or pass one missing `description`/`resolution`) to render the generic preview that displays Fleet-icon-based self-service instructions linking to `TRANSPARENCY_LINK`.
