Modal component for configuring automated script execution when hosts fail Fleet policies, with per-policy script selection via a paginated list and dropdown interface.

## Key Components

### `getTrulyDirtyItems`
Exported utility that filters a list of `IFormPolicy` items to only those with actual changes (enabled/disabled toggled, or selected script swapped), preventing unnecessary API calls on submit.

### `PolicyRunScriptModal`
Main modal component accepting:
- `onExit` — close handler
- `onSubmit` — receives only the truly-changed `IFormPolicy[]`
- `isUpdating` — disables content during save
- `teamId` — scopes script fetching to the correct Fleet team

Fetches available scripts for the team via `scriptsAPI.getScripts` and renders one of three states: `DataError`, `Spinner`, or the paginated policy list with per-policy script dropdowns.

### `PoliciesPaginatedList` integration
Each policy row conditionally renders a searchable `DropdownWrapper` (script selector) when `runScriptEnabled` is toggled on. Save is blocked if any enabled policy has no script selected.

## Usage Example

```typescript
<PolicyRunScriptModal
  teamId={42}
  isUpdating={isSaving}
  onExit={() => setShowModal(false)}
  onSubmit={(changedPolicies) => {
    // changedPolicies contains only truly modified entries
    await updatePolicyScripts(changedPolicies);
  }}
/>
```

```typescript
// Standalone utility usage
import { getTrulyDirtyItems } from "./PolicyRunScriptModal";

const changed = getTrulyDirtyItems(allPolicies);
// Returns only policies where script was added, removed, or swapped
```
