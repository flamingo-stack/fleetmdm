Unit tests for the `getTrulyDirtyItems` utility from `PolicyRunScriptModal`, verifying that only policies with actual script automation changes are identified as dirty.

## Key Components

- **`getTrulyDirtyItems`** (imported from `PolicyRunScriptModal`) — The function under test; filters a list of form policies to return only those where script enablement or the selected script has genuinely changed.
- **`createMockPolicyForScriptAutomation`** — Local test factory that builds a mock `IFormPolicy` with configurable overrides, defaulting to a disabled, unassigned script state.

## Test Cases

The single test covers four mutation scenarios within one assertion:

| Policy ID | Scenario | Expected |
|-----------|----------|----------|
| `1` | Enabled, same script — no change | Filtered out |
| `2` | Was disabled, now enabled with a script | Included |
| `3` | Was enabled, now disabled | Included |
| `4` | Enabled, but script changed | Included |

## Usage Example

```typescript
import { getTrulyDirtyItems } from "./PolicyRunScriptModal";

const changedPolicies = getTrulyDirtyItems(dirtyFormPolicies);
// Returns only policies where run_script enablement or scriptIdToRun differs
// from the originally persisted run_script value.
```
