A paginated list component for displaying and managing Fleet MDM policies within modal contexts, supporting both global and team-scoped policy queries with selection, automation configuration, and GitOps mode awareness.

## Key Components

### `IFormPolicy`
Extends `IPolicy` with virtual properties for tracking automation state:
- `installSoftwareEnabled` / `swIdToInstall` / `swNameToInstall` — software installation automation fields
- `runScriptEnabled` / `scriptIdToRun` / `scriptNameToRun` — script execution automation fields

### `IPoliciesPaginatedListProps`
Key props:
| Prop | Description |
|---|---|
| `teamId` | Determines whether global or team-scoped APIs are called |
| `isSelected` | String key or predicate function for selection state |
| `onToggleItem` | Callback when a row is clicked/toggled |
| `disableSave` | Function returning `boolean \| string`; string value is shown as tooltip |
| `renderPlatform` | When `true`, appends platform icons via `PlatformCell` to each row |
| `getPolicyDisabled` | Predicate to disable individual policy rows |

### Imperative Handle
Exposes `getDirtyItems()` via `forwardRef` + `useImperativeHandle`, allowing parent components to retrieve only changed policies on submit.

## Usage Example

```typescript
const ref = useRef<IPaginatedListHandle<IFormPolicy>>(null);

<PoliciesPaginatedList
  ref={ref}
  teamId={currentTeamId}
  isSelected={(policy) => selectedIds.includes(policy.id)}
  onToggleItem={(policy) => ({ ...policy, installSoftwareEnabled: !policy.installSoftwareEnabled })}
  onSubmit={(changedPolicies) => handleSave(changedPolicies)}
  onCancel={() => setModalOpen(false)}
  isUpdating={isSaving}
  renderPlatform
  disableSave={(changed) => changed.length === 0 && "No changes to save"}
  helpText={<span>Select policies to configure automations.</span>}
/>
```

> **GitOps mode:** When `gitops_mode_enabled` is `true` in `AppContext`, the list and Save button are automatically disabled via `GitOpsModeTooltipWrapper`.
