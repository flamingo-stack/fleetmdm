Integration test suite for the `PoliciesPaginatedList` component, verifying policy listing, user interactions, form submission, and GitOps mode behavior using MSW mock handlers.

## Key Components

| Element | Description |
|---|---|
| `globalPolicies` | Mock dataset of 3 global (team-agnostic) policies |
| `teamPolicies` | Mock dataset of 2 team-specific policies |
| MSW handlers | Intercepts `/policies`, `/policies/count`, `/fleets/2/policies`, and `/fleets/2/policies/count` endpoints |
| `describe` block | Groups 6 test cases covering render, interaction, and access control |

## Test Cases

| Test | Behavior Verified |
|---|---|
| All-teams teamId | Renders global policies (3 checkboxes) |
| Specific teamId | Renders team policies (2 checkboxes) |
| Footer rendering | `helpText` content appears in DOM |
| Save action | `onSubmit` called with toggled items and correct IDs/names |
| Cancel action | `onCancel` called once on button press |
| `disableSave` prop | Save button disabled when no changes or >1 item selected |
| GitOps mode | All checkboxes disabled when `gitops_mode_enabled: true` |

## Usage Example

```typescript
import PoliciesPaginatedList from "./PoliciesPaginatedList";

<PoliciesPaginatedList
  teamId={APP_CONTEXT_ALL_TEAMS_ID}  // or a numeric team ID
  isSelected={(item) => selectedIds.includes(item.id)}
  onToggleItem={(item) => item}
  onCancel={() => setOpen(false)}
  onSubmit={(changedItems) => handleSave(changedItems)}
  helpText={<span>Select policies to apply</span>}
  isUpdating={false}
  disableSave={(changed) => changed.length === 0 && "No changes made"}
/>
```

## Notes

- Uses `createCustomRenderer` with `withBackendMock: true` to wire MSW into the React render tree
- `onToggleItem` transforms each toggled policy; the test verifies the transformed name is forwarded to `onSubmit`
- Tooltip-based `disableSave` hover assertions are skipped due to known CI flakiness (marked with `TODO`)
