Renders a table column header displaying a pass/fail policy status using an icon-based status indicator.

## Key Components

- **`PassingColumnHeader`** — Default export. A React component that maps a boolean `isPassing` prop to the appropriate status indicator parameters and renders a `StatusIndicatorWithIcon`.
- **`IPassingColumnHeaderProps`** — Interface defining the single `isPassing: boolean` prop.

## Usage Example

```typescript
import PassingColumnHeader from "components/policies/PassingColumnHeader";

// Render a "passing" status header
<PassingColumnHeader isPassing={true} />

// Render a "failing" status header
<PassingColumnHeader isPassing={false} />
```

## Dependencies

| Dependency | Role |
|---|---|
| `POLICY_STATUS_TO_INDICATOR_PARAMS` | Maps `"pass"` / `"fail"` keys to `[indicatorStatus, displayText]` tuples |
| `StatusIndicatorWithIcon` | Renders the resolved status and label as an icon-accompanied indicator |
