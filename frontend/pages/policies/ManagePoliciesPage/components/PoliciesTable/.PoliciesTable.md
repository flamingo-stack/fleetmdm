Renders the policies management table with search, sort, pagination, and bulk-delete capabilities, adapting its empty state and selection behavior based on team context, premium tier, and Primo mode settings.

## Key Components

### `PoliciesTable` (default export)
A React functional component that wraps `TableContainer` to display a list of `IPolicyStats` entries with full query management.

### `isLastPage(count, pageSize, page)`
A local utility that determines whether the current page is the last one, used to disable the "next page" control until the API supports `meta.has_next_results`.

### `IPoliciesTableProps`
Interface defining all props including:
- `policiesList` — array of policy stats to render
- `currentTeam` / `isPremiumTier` — control team-scoped and premium UI behavior
- `otherAutomationType` / `onOpenManageAutomationsModal` — optional automation column support
- `canAddOrDeletePolicies` / `hasPoliciesToDelete` — permission guards for bulk actions
- `searchQuery`, `sortHeader`, `sortDirection`, `page`, `count` — controlled table state

## Usage Example

```typescript
<PoliciesTable
  policiesList={policies}
  isLoading={isLoading}
  onDeletePoliciesClick={(ids) => handleDelete(ids)}
  onAddPolicyClick={() => setShowAddModal(true)}
  canAddOrDeletePolicies={isAdmin}
  hasPoliciesToDelete={selectedCount > 0}
  currentTeam={selectedTeam}
  currentAutomatedPolicies={automatedPolicyIds}
  isPremiumTier={isPremium}
  renderPoliciesCount={() => <span>{count} policies</span>}
  onQueryChange={handleQueryChange}
  searchQuery={searchQuery}
  page={page}
  count={totalCount}
/>
```

## Key Behaviors

| Condition | Effect |
|---|---|
| `searchQuery` or `isFiltered` | Shows "No matching policies" empty state, hides Add button |
| `isPremiumTier && !enable_primo` | Uses fleet-scoped empty state headers |
| Viewing team policies (non-Primo) with no team-owned rows | Hides selection checkboxes |
| `isTrulyEmpty` | Disables the search input |
