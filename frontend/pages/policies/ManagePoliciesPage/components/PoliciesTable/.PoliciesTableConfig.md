Renders the policies table column configuration for the Fleet MDM policies management view, defining column headers, cell renderers, and automation display logic.

## Key Components

### `generateTableHeaders`
The primary export — builds the array of `IDataColumn` definitions based on runtime options:
- `selectedTeamId` — controls "Inherited" badge visibility and host-filter links
- `hasPermissionAndPoliciesToDelete` — gates the selection checkbox column
- `otherAutomationType` — passed through to `AutomationsCell`
- `onOpenManageAutomationsModal` — determines if automation cells are editable
- `isPremiumTier` / `isPrimoMode` — controls premium-only UI (e.g., Critical badge)

### `AutomationsCell`
Renders the automations column cell with three states:
- **Empty** — shows `DEFAULT_EMPTY_CELL_VALUE` with an "Add automation" aria label
- **Single automation** — icon + truncated name with tooltip
- **Multiple automations** — count badge with tooltip listing all names

Switches between read-only (`<span>`) and editable (`EditableAutomationsCell`) based on whether `onOpenManageAutomationsModal` is provided.

### `EditableAutomationsCell`
Accessible wrapper (`role="button"`, keyboard support) that adds a pencil icon and triggers the automations modal on click or `Enter`/`Space`.

### `AUTOMATION_ICON_RENDERERS`
A map of automation type → icon renderer for `software`, `script`, `calendar`, `conditional_access`, and `other`.

### `getPolicyRefreshTime` / `getTooltip`
Converts milliseconds to a human-readable refresh interval; used in the "has not run yet" tooltip for Pass/Fail cells.

## Usage Example

```typescript
const columns = generateTableHeaders(
  {
    selectedTeamId: 3,
    hasPermissionAndPoliciesToDelete: true,
    otherAutomationType: "webhook",
    onOpenManageAutomationsModal: (policy) => openModal(policy),
  },
  true,  // isPremiumTier
  false  // isPrimoMode
);

<TableContainer columns={columns} data={policyStats} />
```
