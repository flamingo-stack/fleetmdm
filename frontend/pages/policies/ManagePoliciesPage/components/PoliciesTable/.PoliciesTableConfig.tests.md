Unit tests for the `nextPolicyUpdateMs` function exported from `PoliciesTableConfig`, verifying the calculation of milliseconds until the next policy update under various timing conditions.

## Key Components

- **`nextPolicyUpdateMs`** — The function under test, imported from `PoliciesTableConfig`. Calculates the delay (in milliseconds) before the next policy update should occur based on current time, scheduled intervals, and host count state.

## Test Cases

| Scenario | Description |
|---|---|
| All zero inputs | Returns `0` immediately |
| Only next update set | Returns the next update value directly |
| Next host count update | Returns the base interval (`10`) |
| Recent policy + host update | Short-circuits to base interval |
| Old policy + host update | Returns base interval regardless of policy age |
| Subsequent host count update | Offsets by host count interval (`210`) |
| Far future host count update | Aligns to next interval boundary (`1010`) |

## Usage Example

```typescript
import { nextPolicyUpdateMs } from "./PoliciesTableConfig";

// Determine how long to wait before the next policy refresh
const delayMs = nextPolicyUpdateMs(
  new Date(),       // lastUpdated: when the policy was last evaluated
  10,               // nextUpdateMs: base polling interval
  200,              // hostCountIntervalMs: interval between host count refreshes
  20                // currentHostCount: number of hosts currently tracked
);

setTimeout(refreshPolicies, delayMs);
```
