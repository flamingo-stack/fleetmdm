Manages the policy list page for Fleet MDM, handling display, filtering, sorting, and automation management of global and team-specific policies.

## Key Components

### Exports
- `ManagePolicyPage` — Default page component rendering the policies table with full CRUD and automation controls
- `DEFAULT_SORT_DIRECTION` — `"asc"`
- `DEFAULT_PAGE_SIZE` — `20`
- `DEFAULT_SORT_COLUMN` — `"name"`

### Core Functionality
- **Policy Queries** — Fetches global and team policies with pagination, search, sort, and automation-type filtering via `react-query`
- **Team Switching** — Uses `useTeamIdParam` to sync team context with URL params and API calls
- **Automation Filtering** — Supports filtering by automation type (`software`, `scripts`, `calendar`, `conditional_access`, `other`) with scope differences between global and team contexts
- **URL Sync** — Keeps table state (search, sort, page, filter) in sync with query params via `location.query`
- **Config Fetching** — Loads both global config and per-team config to determine active automations settings

### Modals
- `DeletePoliciesModal` — Bulk delete confirmation
- `AutomationsModal` — Per-policy automation view
- `ManageAutomationsModal` — Global/team automation settings editor

## Usage Example

```typescript
// Rendered by the router — no direct instantiation needed
import ManagePoliciesPage from "pages/policies/ManagePoliciesPage";

// Route definition (react-router)
<Route path={PATHS.MANAGE_POLICIES} component={ManagePoliciesPage} />

// URL params consumed by the page
// /policies?fleet_id=2&query=disk&order_key=name&order_direction=asc&page=0&automation_type=calendar
```

## Key Behaviors

| Behavior | Detail |
|---|---|
| Permission guard | Add/delete requires `isGlobalAdmin`, `isGlobalMaintainer`, `isTeamAdmin`, or `isTeamMaintainer` |
| Automation settings | Edit restricted to `isGlobalAdmin` or `isTeamAdmin` |
| Primo mode | Reads `partnerships.enable_primo` from global config |
| Stale time | Policy queries use a 5-second stale window to reduce redundant fetches |
