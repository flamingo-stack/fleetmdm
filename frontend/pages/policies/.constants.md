Defines default policy constants and a comprehensive library of pre-built security compliance policies used throughout the Fleet MDM policy management interface.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `POLICY_TARGET_EMPTY_STATE_DESCRIPTION` | `string` | UI placeholder text shown when no policy target label is selected |
| `DEFAULT_POLICY` | `object` | A single mock policy object used for testing/defaults |
| `DEFAULT_POLICIES` | `IPolicyNew[]` | Array of 21+ pre-built security compliance policy templates |

### Policy Coverage in `DEFAULT_POLICIES`

Policies span three platforms (`linux`, `darwin`, `windows`) and cover:

- **Antivirus** — ClamAV (Linux), XProtect/MRT (macOS), Windows Defender (Windows)
- **Disk Encryption** — LUKS (Linux), FileVault (macOS), BitLocker (Windows)
- **Access Controls** — Screen lock, auto-login, password length, Gatekeeper
- **System Integrity** — SIP, firewall, MDM enrollment, secure keyboard entry
- **Software Updates** — Automatic check, download, install, and OS update policies (macOS)

## Usage Example

```typescript
import { DEFAULT_POLICIES, DEFAULT_POLICY } from "./constants";

// Seed a policy form with a default template
const newPolicy = DEFAULT_POLICIES.find(p => p.platform === "darwin");

// Use the mock policy in tests
expect(policyCard.name).toBe(DEFAULT_POLICY.name);

// Filter MDM-required policies before displaying to non-MDM users
const nonMdmPolicies = DEFAULT_POLICIES.filter(p => !p.mdm_required);
```

## Notes

- ESLint and Prettier are intentionally disabled for the `DEFAULT_POLICIES` array to preserve backslash characters in raw SQL query strings.
- Policies flagged with `mdm_required: true` are only applicable to MDM-managed devices.
