Custom React Query hook for fetching paginated scripts data from the Fleet MDM API, scoped to a specific fleet.

## Key Components

- **`useScripts`** – Default export. A wrapper around `useQuery` that fetches scripts for a given `fleetId`, with a fixed page size of 1000 and a 30-second stale time.
- **`IUseScriptsArgs`** – Interface defining hook arguments: `fleetId` (number) and `enabled` (boolean) for conditional fetching.
- **`SCRIPTS_PAGE_SIZE`** – Internal constant set to `1000`, controlling the maximum scripts returned per request.

## Usage Example

```typescript
import useScripts from "hooks/useScripts";

const MyComponent = ({ fleetId }: { fleetId: number }) => {
  const { data, isLoading, error } = useScripts({
    fleetId,
    enabled: true,
  });

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return <ScriptsList scripts={data?.scripts ?? []} />;
};
```

## Notes

- The `enabled` flag allows conditional fetching — pass `false` to defer the query until dependencies are ready.
- The `scope` key is stripped from the query key before passing to the API via `omit(key, "scope")`, as it is used only for React Query cache identification.
- `staleTime: 30_000` means cached data is considered fresh for 30 seconds, reducing redundant API calls during navigation.
