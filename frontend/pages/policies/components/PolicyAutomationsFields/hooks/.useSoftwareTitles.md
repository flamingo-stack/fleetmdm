Fetches a paginated list of software titles from the Fleet MDM API using `react-query`, scoped to a specific fleet and filtered to titles available for installation across macOS, Windows, and Linux.

## Key Components

- **`useSoftwareTitles`** — Custom React Query hook that retrieves up to 1,000 software titles ordered by host count descending.
- **`SOFTWARE_PAGE_SIZE`** — Constant set to `1000`, defining the maximum number of titles fetched per request.
- **`IUseSoftwareTitlesArgs`** — Input interface requiring `fleetId` (team identifier) and `enabled` (query toggle).

## Query Configuration

| Option | Value |
|---|---|
| `perPage` | `1000` |
| `orderKey` | `hosts_count` |
| `orderDirection` | `desc` |
| `platform` | `darwin,windows,linux` |
| `availableForInstall` | `true` |
| `staleTime` | `30,000ms` |

## Usage Example

```typescript
import useSoftwareTitles from "hooks/useSoftwareTitles";

const MyComponent = ({ fleetId }: { fleetId: number }) => {
  const { data, isLoading, isError } = useSoftwareTitles({
    fleetId,
    enabled: true,
  });

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return <SoftwareList titles={data?.software_titles} />;
};
```

## Notes

- The `scope` key is stripped from the query key before being passed to `softwareAPI.getSoftwareTitles` via `omit`.
- Pass `enabled: false` to defer or conditionally skip the query (e.g., when a required `fleetId` is not yet available).
