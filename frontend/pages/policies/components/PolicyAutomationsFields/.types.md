Defines the `IAutomationCheckboxRow` interface and supporting types used to render individual automation toggle rows in the Fleet MDM automation settings UI.

## Key Components

### Types

- **`IAutomationRowKey`** — Union type restricting automation identifiers to one of five valid keys: `ticket_webhook`, `install_software`, `run_script`, `calendar_event`, or `conditional_access`.

### Interfaces

- **`IAutomationCheckboxRow`** — Describes the shape of a single automation row, including:
  - `key` — Identifies the automation type via `IAutomationRowKey`
  - `label` / `tooltip` — Display text and optional tooltip node
  - `checked` / `onToggle` — Controlled checkbox state and change handler
  - `isDisabled` — Greys the row and disables the checkbox when the feature is not enabled for the fleet; also shows a "Not enabled" hint
  - `isLocked` — Disables the checkbox silently (no hint shown) when the user's role lacks permission to manage the automation
  - `picker` — Optional React node for rendering an inline picker (e.g., a policy or script selector)

## Usage Example

```typescript
const row: IAutomationCheckboxRow = {
  key: "run_script",
  label: "Run script",
  checked: false,
  isDisabled: false,
  isLocked: true, // user lacks permission; checkbox disabled silently
  onToggle: (next) => console.log("toggled:", next),
  picker: <ScriptPicker />,
};
```
