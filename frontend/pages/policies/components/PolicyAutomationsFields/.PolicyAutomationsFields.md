Renders the automation configuration form fields for a Fleet policy, exposing a `getAutomationsPayload()` handle so the parent can validate and collect changes on submit without owning local state.

## Key Components

### Exports

| Name | Type | Description |
|---|---|---|
| `PolicyAutomationsFields` | `React.ForwardRefExoticComponent` | Main form component, exposes an imperative handle via `ref` |
| `IPolicyAutomationsFieldsHandle` | Interface | Ref handle shape — provides `getAutomationsPayload()` |
| `IPolicyAutomationsPayload` | Interface | Return type of `getAutomationsPayload()`, includes `isValid`, `isDirty`, and optional update objects |

### Internal Hooks Used

- **`useSoftwareTitles`** — fetches installable software titles scoped to a fleet
- **`useScripts`** — fetches runnable scripts scoped to a fleet

### Automation Rows Rendered

| Row | Global Policy | Fleet Policy |
|---|---|---|
| Ticket / Webhook | ✅ | ✅ |
| Install software | ❌ | ✅ |
| Run script | ❌ | ✅ |
| Calendar events | ❌ | ✅ (if enabled) |
| Conditional access | ❌ | ✅ (if enabled) |
| Continuous retry | ❌ | ✅ |

## Usage Example

```typescript
import { useRef } from "react";
import PolicyAutomationsFields, {
  IPolicyAutomationsFieldsHandle,
} from "./PolicyAutomationsFields";

function PolicyAutomationsModal({ policy, config }) {
  const automationsRef = useRef<IPolicyAutomationsFieldsHandle>(null);

  const handleSave = () => {
    const payload = automationsRef.current?.getAutomationsPayload();
    if (!payload?.isValid) return; // errors surface inside the component

    if (payload.isDirty) {
      if (payload.policyUpdate) savePolicyUpdate(payload.policyUpdate);
      if (payload.webhookOrTicketUpdate) saveWebhookUpdate(payload.webhookOrTicketUpdate);
    }
  };

  return (
    <>
      <PolicyAutomationsFields
        ref={automationsRef}
        policy={policy}
        isGlobalPolicy={false}
        teamIdForApi={42}
        automationsConfig={config}
        globalConfig={globalConfig}
        fleetName="Engineering"
      />
      <button onClick={handleSave}>Save</button>
    </>
  );
}
```
