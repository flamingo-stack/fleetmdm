Read-only React component that renders a structured summary of all automations configured on a Fleet policy, including software installs, scripts, calendar events, conditional access, and webhook/ticket automations.

## Key Components

### `PolicyAutomationsList`
The default export — a functional component accepting:
- `storedPolicy: IPolicy` — the policy object containing automation config fields
- `currentAutomatedPolicies: number[]` — IDs of policies with active webhook/ticket automations
- `otherAutomationType?: OtherAutomationType` — disambiguates webhook vs. ticket label

### `IAutomationDisplayRow`
Internal interface modeling each rendered row with fields for display name, icon resolution, type classification, sort priority, and an optional deep-link.

### `OTHER_AUTOMATION_NAMES`
Lookup map translating `OtherAutomationType` values (`"webhook"` | `"ticket"`) to human-readable labels.

### Automation Types Rendered (in sort order)
| Order | Type | Trigger field |
|---|---|---|
| 0 | Software install | `install_software` |
| 1 | Script | `run_script` |
| 2 | Calendar / maintenance window | `calendar_events_enabled` |
| 3 | Conditional access (block SSO) | `conditional_access_enabled` |
| 4 | Webhook or ticket | `currentAutomatedPolicies` |

## Usage Example

```typescript
import PolicyAutomationsList from "components/PolicyAutomationsList";

<PolicyAutomationsList
  storedPolicy={policy}
  currentAutomatedPolicies={automatedPolicyIds}
  otherAutomationType="webhook"
/>
```

The component renders an `"Automations"` header, one row per configured automation (or a `"No automations"` empty state), and a footer describing when automations trigger — varying based on `continuous_automations_enabled`.
