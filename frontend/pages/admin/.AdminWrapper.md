Layout wrapper for the Fleet admin settings area, rendering a tabbed navigation header and routing between settings sub-pages based on user tier and sandbox mode.

## Key Components

### Interfaces

- **`ISettingSubNavItem`** — Defines a nav tab entry with `name`, `pathname`, and optional `exclude` flag
- **`ISettingsWrapperProp`** — Component props: `children`, `location.pathname`, and an injected `router`

### Core Logic

- **`settingsSubNav`** — Static array of nav items; tabs are conditionally excluded based on `isSandboxMode` and `isPremiumTier` from `AppContext`
- **`filteredSettingsSubNav`** — Excludes nav items where `exclude: true` before rendering
- **`navigateToNav(i)`** — Pushes the selected tab's route to the router on tab selection
- **`getTabIndex(path)`** — Finds the active tab index via `startsWith` matching, keeping parent tabs highlighted for nested routes
- **`classNames`** — Applies `sandbox-mode` CSS class when sandbox mode is active to support sticky layout adjustments

## Usage Example

```typescript
// Rendered automatically by the router; wraps admin sub-page content
<AdminWrapper location={location} router={router}>
  <OrganizationSettingsPage />
</AdminWrapper>
```

## Tab Visibility Rules

| Tab | Condition |
|---|---|
| Organization Settings | Hidden in sandbox mode |
| Integrations | Always visible |
| Users | Hidden in sandbox mode |
| Fleets | Visible on premium tier only |

## Notes

- Uses `react-tabs` for accessible tab rendering; tab labels use a `data-text` attribute with a hidden pseudo-element to prevent layout shift on bold active state
