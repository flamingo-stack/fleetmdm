A modal dialog component for renaming an existing fleet, handling form state, validation errors, and submission.

## Key Components

### `RenameFleetModal` (default export)
A controlled form modal that accepts a current fleet name, displays an editable input field, and delegates submission to the parent via callback.

**Props (`IRenameFleetModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `onCancel` | `() => void` | Closes the modal without saving |
| `onSubmit` | `(formData: IFleetFormData) => void` | Called with trimmed fleet name on save |
| `defaultName` | `string` | Pre-populates the input with the current fleet name |
| `backendValidators` | `{ [key: string]: string }` | Server-side validation errors (e.g., duplicate name) |
| `isUpdatingFleets` | `boolean` | Shows loading state on the Save button during API call |

## Behaviour Notes

- Input errors are cleared immediately on any keystroke via `onInputChange`
- `backendValidators` are synced to local error state via `useEffect`, so API errors surface after submission
- Fleet name is trimmed on both blur and submit; Save is disabled when the trimmed value is empty

## Usage Example

```typescript
<RenameFleetModal
  defaultName="Production Fleet"
  backendValidators={serverErrors}
  isUpdatingFleets={isLoading}
  onCancel={() => setShowModal(false)}
  onSubmit={async ({ name }) => {
    await renameFleet(fleetId, name);
    setShowModal(false);
  }}
/>
```
