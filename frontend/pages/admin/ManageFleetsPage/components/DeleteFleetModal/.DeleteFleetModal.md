A confirmation modal component for deleting a fleet, displaying the fleet name and warning users about access implications before confirming the destructive action.

## Key Components

### `IDeleteFleetModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Display name of the fleet to be deleted |
| `isUpdatingFleets` | `boolean` | Controls loading state on the Delete button |
| `onSubmit` | `() => void` | Callback fired on delete confirmation |
| `onCancel` | `() => void` | Callback fired on cancel or modal exit |

### `DeleteFleetModal`
Default export. Renders a `Modal` with a warning message and two action buttons — **Delete** (alert variant, with loading state) and **Cancel** (inverse-alert variant). Supports keyboard submission via `onEnter`.

## Usage Example

```typescript
import DeleteFleetModal from "components/DeleteFleetModal";

<DeleteFleetModal
  name="Production Fleet"
  isUpdatingFleets={isDeletingFleet}
  onSubmit={handleDeleteFleet}
  onCancel={() => setShowDeleteModal(false)}
/>
```

> **Note:** Users assigned exclusively to the deleted fleet will lose login access. Ensure this warning is surfaced clearly before triggering `onSubmit`.
