Modal component for creating a new fleet (team), providing a form with a name input field, validation error display, and submit/cancel actions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CreateFleetModal` | `React.FC` | Default export; renders the fleet creation modal |
| `ICreateFleetModalProps` | `interface` | Props contract for the modal component |

### Props (`ICreateFleetModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Callback fired when the modal is dismissed |
| `onSubmit` | `(formData: IFleetFormData) => void` | Callback fired on valid form submission |
| `backendValidators` | `{ [key: string]: string }` | Server-side validation errors (e.g., duplicate name) |
| `isUpdatingFleets` | `boolean` | Drives loading state on the submit button |

## Key Behaviors

- **Error sync** — `useEffect` keeps local error state in sync with `backendValidators` whenever the server returns a new validation error.
- **Input clearing** — Any keystroke clears existing errors via `onInputChange`, preventing stale error messages.
- **Submit guard** — The **Create** button is disabled when the trimmed fleet name is empty.
- **Name trimming** — Whitespace is stripped on both blur and submit.

## Usage Example

```typescript
import CreateFleetModal from "components/modals/CreateFleetModal";

<CreateFleetModal
  onCancel={() => setShowModal(false)}
  onSubmit={(formData) => handleCreateFleet(formData)}
  backendValidators={apiErrors}
  isUpdatingFleets={isLoading}
/>
```
