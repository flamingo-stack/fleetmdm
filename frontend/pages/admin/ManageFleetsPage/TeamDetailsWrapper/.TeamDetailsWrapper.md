Wrapper component that manages the team details page layout, navigation, and modal state for team management operations including enroll secrets, host management, and team CRUD actions.

## Key Components

### Props
- `children` – Sub-page content rendered within the wrapper
- `location` – Current route location including `fleet_id` query param
- `router` – Injected router for programmatic navigation

### Sub-navigation
Three tabs defined in `teamDetailsSubNav`:
- **Users** → `PATHS.FLEET_DETAILS_USERS`
- **Agent options** → `PATHS.FLEET_DETAILS_OPTIONS`
- **Settings** → `PATHS.FLEET_DETAILS_SETTINGS`

### Modal State Managed
| Modal | Toggle Function |
|---|---|
| Add Hosts | `toggleAddHostsModal` |
| Manage Enroll Secrets | `toggleManageEnrollSecretsModal` |
| Delete Secret | `toggleDeleteSecretModal` |
| Secret Editor | `toggleSecretEditorModal` |
| Delete Fleet | `toggleDeleteFleetModal` |
| Rename Fleet | `toggleRenameFleetModal` |

### Key Operations
- `onSaveSecret` – Creates or edits a team enroll secret
- `onDeleteSecret` – Removes a team enroll secret
- `onDeleteSubmit` – Deletes the entire team, redirects to `PATHS.ADMIN_FLEETS`
- `onEditSubmit` – Renames a team with backend validation (duplicate name, reserved names)

### Data Fetching
- **Teams** – `teamsAPI.loadAll()` (sorted case-insensitively)
- **Team secrets** – `enrollSecretsAPI.getTeamEnrollSecrets(teamIdForApi)`
- **Current user** – `usersAPI.me()` (refetched after team rename)

## Usage Example

```typescript
// Used as a route wrapper in React Router
<TeamDetailsWrapper router={router} location={location}>
  <TeamUsersPage />
</TeamDetailsWrapper>
```
