Test suite for the `TeamHostExpiryToggle` React component, verifying rendering behavior across different combinations of global and team-level host expiry settings.

## Key Components

- **`TeamHostExpiryToggle` (imported)** — The component under test, which controls host expiry settings at the team level
- **Three test cases** covering the primary rendering scenarios:
  - Global expiry disabled (no window set)
  - Global expiry enabled, team expiry disabled
  - Global expiry enabled, team expiry enabled

## Props Tested

| Prop | Type | Description |
|---|---|---|
| `globalHostExpiryEnabled` | `boolean` | Whether global host expiry is active |
| `globalHostExpiryWindow` | `number \| undefined` | Global expiry window in days |
| `teamExpiryEnabled` | `boolean` | Whether team-level expiry is toggled on |
| `setTeamExpiryEnabled` | `jest.fn()` | Callback for toggling team expiry |

## Usage Example

```typescript
// Run the test suite
// npx jest TeamHostExpiryToggle.tests.tsx

// Example: Assert global banner is hidden when global expiry is off
render(
  <TeamHostExpiryToggle
    globalHostExpiryEnabled={false}
    globalHostExpiryWindow={undefined}
    teamExpiryEnabled={false}
    setTeamExpiryEnabled={jest.fn()}
  />
);
expect(screen.queryByText(/Host expiry is globally enabled/)).toBeNull();

// Example: Assert custom window option appears when global is on, team is off
render(
  <TeamHostExpiryToggle
    globalHostExpiryEnabled
    globalHostExpiryWindow={2}
    teamExpiryEnabled={false}
    setTeamExpiryEnabled={jest.fn()}
  />
);
expect(screen.getByText(/Add custom expiry window/)).toBeInTheDocument();
```

## Key Assertions

- `"Enable host expiry"` label is always present regardless of state
- `"Host expiry is globally enabled"` banner only appears when `globalHostExpiryEnabled` is `true`
- `"Add custom expiry window"` option is shown only when global is enabled **and** team expiry is disabled
