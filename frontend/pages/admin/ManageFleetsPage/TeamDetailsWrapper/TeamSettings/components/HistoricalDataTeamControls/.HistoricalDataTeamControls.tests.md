Test suite for the `HistoricalDataTeamControls` component, verifying rendering, checkbox state reflection, global-lock behavior, and `onChange` callback interactions.

## Key Components

- **`renderControls`** — Helper that wraps `renderWithSetup` with sensible defaults, accepts partial prop overrides, and exposes a mocked `onChange` handler alongside testing utilities.
- **Test Suite (`describe`)** — Seven `it` blocks covering:
  - Section heading and checkbox presence
  - Team-level stored values reflected in checked state
  - Individual checkbox locking when the corresponding global setting is disabled
  - Checked + disabled state coexistence
  - `onChange` called on enabled checkbox click
  - `onChange` not called when checkbox is locked

## Usage Example

```typescript
// Render with defaults (all enabled, all unchecked)
const { onChange } = renderControls();

// Render with a team value pre-set
renderControls({ disableHostsActive: true });

// Render with a global lock applied
renderControls({ globalHostsActiveDisabled: true });

// Assert onChange payload shape
expect(onChange).toHaveBeenCalledWith(
  expect.objectContaining({ name: "disableHostsActive", value: true })
);
```

## Notes

- Global disable flags (`globalHostsActiveDisabled`, `globalVulnerabilitiesDisabled`) independently lock their respective checkboxes without affecting each other.
- A locked checkbox retains its stored `disableHostsActive` / `disableVulnerabilities` value (checked + disabled simultaneously).
- Uses `@testing-library/user-event` (via `renderWithSetup`) to simulate realistic click interactions.
