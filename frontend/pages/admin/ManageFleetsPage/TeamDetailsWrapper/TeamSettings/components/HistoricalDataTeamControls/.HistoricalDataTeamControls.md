Renders team-level controls for configuring historical data retention settings related to host activity and vulnerability exposure reporting.

## Key Components

### `IHistoricalDataTeamControlsProps`
| Prop | Type | Description |
|---|---|---|
| `disableHostsActive` | `boolean` | Current state of the hosts online reporting toggle |
| `disableVulnerabilities` | `boolean` | Current state of the vulnerability exposure reporting toggle |
| `globalHostsActiveDisabled` | `boolean` | Whether host activity reporting is disabled at the global level |
| `globalVulnerabilitiesDisabled` | `boolean` | Whether vulnerability reporting is disabled at the global level |
| `onChange` | `(parsed: IInputFieldParseTarget) => void` | Callback fired when either checkbox changes |

### `HistoricalDataTeamControls`
Default export. Renders two checkboxes under an "Activity & data retention" section header, each wrapped in `GitOpsModeTooltipWrapper` to handle GitOps-enforced disabling. Tooltips adapt contextually — showing `"Disabled globally"` when the parent-level setting overrides, or a descriptive message when the control is active.

## Usage Example

```typescript
import HistoricalDataTeamControls from "./HistoricalDataTeamControls";

<HistoricalDataTeamControls
  disableHostsActive={teamSettings.disableHostsActive}
  disableVulnerabilities={teamSettings.disableVulnerabilities}
  globalHostsActiveDisabled={globalConfig.disableHostsActive}
  globalVulnerabilitiesDisabled={globalConfig.disableVulnerabilities}
  onChange={({ name, value }) => {
    updateTeamSettings({ [name]: value });
  }}
/>
```

> **Note:** When `globalHostsActiveDisabled` or `globalVulnerabilitiesDisabled` is `true`, the corresponding checkbox is disabled regardless of GitOps mode, and the tooltip reflects the global override rather than the field description.
