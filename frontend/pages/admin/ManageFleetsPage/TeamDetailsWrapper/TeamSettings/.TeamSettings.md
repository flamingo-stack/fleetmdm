This React component manages team-specific settings in a Fleet MDM admin interface, handling host expiry, host status webhooks, and historical data collection configuration for a given team.

## Key Components

### `TeamSettings` (default export)
Main page component that renders and manages a team settings form, including:
- **Host expiry toggle** — team-level override of global host expiry settings
- **Host status webhook** — URL, host percentage threshold, and monitoring window configuration
- **Historical data controls** — enable/disable `uptime` and `vulnerabilities` data collection per team

### `validateTeamSettingsFormData`
Pure validation function that checks host expiry window bounds and webhook destination URL validity, returning a `Record<string, string>` of field errors.

### `ITeamSettingsFormData`
TypeScript type defining the shape of the form state, covering all configurable fields.

## Usage Example

```typescript
// Used as a subnav page routed by Fleet's team admin navigation
import TeamSettings from "pages/admin/teams/TeamSettings";

// Rendered by the router with location and router props
<TeamSettings location={location} router={router} />
```

Key behaviors:
- Requires a valid `teamIdForApi` from `useTeamIdParam`; redirects otherwise
- Loads both global app config and team-specific config in parallel via `react-query`
- Shows `ConfirmDataCollectionDisableModal` before saving if any historical dataset is being disabled
- Calls `teamsAPI.update()` on submit and flashes success/error notifications via `NotificationContext`
