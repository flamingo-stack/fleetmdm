A React page component for managing osquery agent options for a specific Fleet team, allowing administrators to view and update agent configuration via a YAML editor.

## Key Components

- **`AgentOptionsPage`** — Main page component accepting `ITeamSubnavProps` (`location`, `router`) for team-based routing
- **`useTeamIdParam`** — Hook resolving the current team ID from URL params, restricted to team admin role only
- **`validateForm`** — Inline YAML validation triggered on every form change via `useEffect`
- **`onFormSubmit`** — Submits updated agent options to `osqueryOptionsAPI.updateTeam`, parsing YAML or falling back to `EMPTY_AGENT_OPTIONS`
- **`handleAgentOptionsChange`** — Updates form state when the YAML editor value changes

## Key Behaviors

- Fetches team details on mount using `react-query`, populating the YAML editor with current `agent_options`
- GitOps mode awareness: disables the editor and save button when `gitops_mode_enabled` is `true` via `GitOpsModeTooltipWrapper`
- Displays inline error messages for unsupported keys or invalid value types, with a hint to use `fleetctl apply --force`
- Shows a `Spinner` while team options are loading

## Usage Example

```typescript
// Rendered as a sub-page within the team settings subnav
import AgentOptionsPage from "pages/ManageControlsPage/AgentOptionsPage";

<AgentOptionsPage
  location={location}
  router={router}
/>
```

> **Access Control:** Only users with the `admin` team role can access this page. Maintainers, observers, and technicians are redirected by `useTeamIdParam`.
