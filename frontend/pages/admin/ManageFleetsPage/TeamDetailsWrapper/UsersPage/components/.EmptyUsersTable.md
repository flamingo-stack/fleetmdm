Renders an empty state UI for the users table, displaying contextual messaging and conditional action buttons based on search state and user role.

## Key Components

### `IEmptyUsersTableProps`
Interface defining props for the empty state component:
- `className` – CSS class prefix for scoped styling
- `searchString` – Current search input; drives which empty state message is shown
- `isGlobalAdmin` / `isTeamAdmin` – Role flags controlling button visibility
- `toggleAddUserModal` / `toggleCreateMemberModal` – Callbacks for opening the appropriate user creation modal
- `disabled` – Optional flag to disable action buttons (e.g. GitOps mode)

### `CreateUserButton`
Internal component that renders a role-aware action button:
- Returns `null` if the user has neither global nor team admin privileges
- Renders **"Add user"** for global admins (`toggleAddUserModal`)
- Renders **"Create user"** for team admins (`toggleCreateMemberModal`)

### `EmptyMembersTable` (default export)
Main component with two display states:
- **Search active** – Shows a "no match" message when `searchString` is non-empty
- **No users** – Shows a "no users on this fleet" message with a link to global users and the `CreateUserButton` wrapped in `GitOpsModeTooltipWrapper` to handle GitOps-mode disabling

## Usage Example

```typescript
<EmptyMembersTable
  className="users-table"
  searchString={searchQuery}
  isGlobalAdmin={currentUser.isGlobalAdmin}
  isTeamAdmin={currentUser.isTeamAdmin}
  toggleAddUserModal={() => setShowAddUserModal(true)}
  toggleCreateMemberModal={() => setShowCreateMemberModal(true)}
/>
```
