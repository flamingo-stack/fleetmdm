A confirmation modal component for removing a user from a team, displaying a warning message and action buttons.

## Key Components

**`RemoveUserModal`** — Default export. A functional React component that renders a modal dialog with:
- A confirmation message identifying the user and team by name
- A warning that the user loses access if unassigned from all fleets
- A destructive **Remove** button with loading state support
- A **Cancel** button to dismiss without action

**`IDeleteTeamModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|---|---|---|
| `userName` | `string` | Display name of the user to remove |
| `teamName` | `string` | Display name of the target team |
| `isUpdatingUsers` | `boolean` | Triggers loading spinner on the Remove button |
| `onSubmit` | `() => void` | Callback fired on confirmation (also bound to `Enter` key) |
| `onCancel` | `() => void` | Callback fired on cancellation (also bound to `Escape` key) |

## Usage Example

```typescript
import RemoveUserModal from "components/RemoveUserModal";

<RemoveUserModal
  userName="Jane Doe"
  teamName="Engineering"
  isUpdatingUsers={isLoading}
  onSubmit={handleRemoveUser}
  onCancel={() => setShowModal(false)}
/>
```

> **Note:** The `Enter` key triggers `onSubmit` and `Escape`/close triggers `onCancel` via the underlying `Modal` component's `onEnter`/`onExit` bindings.
