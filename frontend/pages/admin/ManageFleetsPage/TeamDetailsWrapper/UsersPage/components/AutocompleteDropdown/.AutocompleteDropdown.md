Async autocomplete dropdown component for searching and selecting users to add to a team, built on `react-select` v1's `Async` component with debounced server-side filtering.

## Key Components

### `AutocompleteDropdown`
The default export. Renders a multi-select async dropdown that fetches user options from a server endpoint as the user types.

### `generateOptionLabel(user, team)`
Builds a human-readable label for each user option, appending contextual status:
- `"Global user"` — if the user belongs to the global team
- `"Already has access to <TeamName>"` — if the user is already a team member
- Plain name otherwise

### `getOptions`
A debounced (300ms, trailing) fetch handler that calls the `resourceUrl` with a `query` param and maps the response to `IDropdownOption[]`. Uses callbacks instead of promises due to a known `react-select` v1 `Async` compatibility issue.

### `IAutocompleteDropdownProps`

| Prop | Type | Description |
|---|---|---|
| `id` | `string` | Element ID |
| `team` | `ITeam` | Target team context |
| `resourceUrl` | `string` | API base path (prefixed with `/api`) |
| `disabledOptions` | `number[]` | User IDs to disable in the list |
| `onChange` | `OnChangeHandler` | Selection change callback |
| `value` | `Option[]` | Current selected values |
| `disabled` | `boolean?` | Disables the entire control |

## Usage Example

```typescript
<AutocompleteDropdown
  id="add-users"
  team={currentTeam}
  placeholder="Search users..."
  resourceUrl="/v1/users"
  value={selectedUsers}
  disabledOptions={existingMemberIds}
  onChange={(selected) => setSelectedUsers(selected)}
/>
```

> **Note:** Client-side filtering is intentionally bypassed (`filterOptions` returns all options unmodified) since filtering is handled server-side via the query parameter.
