A modal dialog component for adding existing users to a Fleet team, featuring an autocomplete search dropdown and an option to create new users.

## Key Components

- **`AddUsersModal`** — Default export. Renders a modal with a user search field and submit/cancel controls.
- **`IAddUsersModal`** — Props interface defining `team`, `disabledUsers`, `onCancel`, `onSubmit`, and `onCreateNewTeamUser`.
- **`AutocompleteDropdown`** — Fetches users from the `USERS` endpoint and renders a searchable dropdown, excluding already-added users via `disabledOptions`.
- **`onFormSubmit`** — Maps selected dropdown options to `INewTeamUser` objects (defaulting role to `"observer"`) before calling `onSubmit`.

## Usage Example

```typescript
import AddUsersModal from "./AddUsersModal";

<AddUsersModal
  team={currentTeam}
  disabledUsers={existingTeamUserIds}
  onCancel={() => setShowModal(false)}
  onSubmit={(formData) => {
    teamsAPI.addUsers(currentTeam.id, formData);
    setShowModal(false);
  }}
  onCreateNewTeamUser={() => setShowCreateUserModal(true)}
/>
```

## Behavior Notes

- The **Add users** button is disabled until at least one user is selected.
- All newly added users are assigned the `"observer"` role by default.
- Users already on the team should be passed via `disabledUsers` (array of user IDs) to prevent duplicate additions.
- The "Create a user" link delegates to the parent via `onCreateNewTeamUser`, keeping user creation flow outside this component.
