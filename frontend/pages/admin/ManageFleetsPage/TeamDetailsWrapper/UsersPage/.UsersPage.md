Renders the team users management page for a specific team, providing functionality to view, add, create, edit, and remove team members with role-based access control.

## Key Components

### Main Component
- **`UsersPage`** — Page component accepting `ITeamSubnavProps` (location, router) that manages the full team users workflow

### State Management
- Modal visibility states: `showAddUserModal`, `showRemoveUserModal`, `showEditUserModal`, `showCreateUserModal`
- `userEditing` — tracks the currently selected user for edit/remove operations
- `searchString` — controls user list filtering
- `addUserErrors` / `editUserErrors` — form-level validation error state

### Data Fetching (react-query)
- **`teamUsers`** — fetches team members via `usersAPI.loadAll`, keyed on `[users, teamIdForApi, searchString]`, transforms output with `generateDataSet`
- **`teams`** — fetches all teams via `teamsAPI.loadAll` to resolve `currentTeamDetails`

### Action Handlers
| Handler | Description |
|---|---|
| `onAddUserSubmit` | Adds existing users to the current team |
| `onCreateUserSubmit` | Creates a new user via invite or direct creation |
| `onEditUserSubmit` | Updates user attributes; redirects if self-demotion detected |
| `onRemoveUserSubmit` | Removes a user from the team; redirects if self-removal |
| `onActionSelection` | Routes table row actions (`edit`, `remove`) to appropriate modal |

### Access Control
Uses `useTeamIdParam` with `permittedAccessByTeamRole` — only `admin` role has access. Reads `isGlobalAdmin`, `isPremiumTier`, `smtpConfigured`, `sesConfigured`, and `canUseSso` from `AppContext`.

## Usage Example

```typescript
// Rendered as a subnav page within the team admin section
import UsersPage from "pages/admin/TeamManagementPage/TeamMemberDetailsPage/UsersPage";

<UsersPage
  location={reactRouterLocation}
  router={reactRouterObject}
/>
```

## Notes

- Self-removal or self-demotion from admin role triggers a redirect to `PATHS.ROOT`
- Column configuration and data transformation are handled externally via [`UsersPageTableConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/pages/admin/TeamManagementPage/TeamMemberDetailsPage/UsersPage/UsersPageTableConfig.ts)
- Invite flow vs. direct creation is determined by `NewUserType.AdminInvited`
