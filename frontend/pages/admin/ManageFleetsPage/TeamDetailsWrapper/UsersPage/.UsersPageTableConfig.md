Defines the table column configuration and data transformation utilities for the Users page table within a team management context.

## Key Components

### Exports

- **`renderApiUserIndicator`** — Renders a `PillBadge` tooltip component identifying API-only users created via `fleetctl`.
- **`generateColumnConfigs`** — Builds the column definitions array for the users table, including Name, Role, Email, and Actions columns with permission-aware action controls.
- **`generateDataSet`** — Entry point for transforming raw `IUser[]` into `ITeamUsersTableData[]` for table consumption.
- **`ITeamUsersTableData`** — Exported interface describing the shape of each row in the users table.

### Internal Utilities

- **`generateRole`** — Resolves a user's role for a specific team from their `teams` array.
- **`enhanceUsersData`** — Maps `IUser` objects to `ITeamUsersTableData`, merging role resolution and dropdown action options.
- **`generateActionDropdownOptions`** — Returns static Edit/Remove dropdown options.

## Usage Example

```typescript
import {
  generateColumnConfigs,
  generateDataSet,
} from "./UsersPageTableConfig";

// Build table columns with action handler and current user context
const columns = generateColumnConfigs(
  (action, user) => {
    if (action === "edit") handleEditUser(user);
    if (action === "remove") handleRemoveUser(user);
  },
  currentUser
);

// Transform API users into table-ready rows for a specific team
const tableData = generateDataSet(teamId, users);
```

## Notes

- The **Actions** column respects team-admin authorization: a team admin can only manage users across all teams they administer (`permissions.isAdminForAllUserTeams`). Users outside their admin scope display a disabled dropdown with an explanatory tooltip.
- The **Role** column renders special tooltips for `GitOps` and `Observer+` roles to explain their access restrictions.
