React page component for managing fleets (teams) in the Fleet MDM admin interface, providing CRUD operations for creating, renaming, and deleting fleet groups with support for GitOps/Primo mode restrictions.

## Key Components

- **`ManageFleetsPage`** — Main page component rendering a fleet management table with action controls
- **`toggleCreateFleetModal`** / **`toggleDeleteFleetModal`** / **`toggleRenameFleetModal`** — Modal visibility toggle callbacks
- **`onCreateSubmit`** — Handles fleet creation via `teamsAPI.create()` with backend validation error mapping
- **`onDeleteSubmit`** — Handles fleet deletion, clearing `currentTeam` if the deleted fleet was active
- **`onRenameSubmit`** — Handles fleet rename with reserved-name validation (`"All fleets"`, `"Unassigned"`)
- **`onActionSelection`** — Routes table row actions (`rename`, `delete`) to the appropriate modal
- **`isCreateFleetDisabled`** — Guards creation when Primo mode or GitOps mode is active
- **`tableHeaders`** / **`tableData`** — Memoized table configuration generated from `FleetTableConfig`

## Usage Example

```typescript
// Rendered by the router; receives router and location as props
import ManageFleetsPage from "./ManageFleetsPage";

// Route definition (react-router v3/v4 style used in Fleet)
<Route
  path="/settings/fleets"
  component={ManageFleetsPage}
/>

// Deep-link to auto-open the Create Fleet modal:
// /settings/fleets?create_fleet=1
// The modal opens only if Primo/GitOps mode is not active.
```

## Notes

- Requires `AppContext` (for `config`, `currentTeam`, setters) and `NotificationContext` (for `renderFlash`) to be provided by parent providers.
- Fleet data is fetched via `react-query` (`["teams"]` key) and refetched after every mutation alongside the current user (`["me"]`).
