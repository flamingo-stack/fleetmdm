Renders and configures the Fleet management table by defining column headers, action dropdowns, and data transformation utilities for displaying fleet (team) data in a tabular format.

## Key Components

| Export | Type | Description |
|---|---|---|
| `generateTableHeaders` | Function | Builds column definitions (Name, Hosts, Users, Actions) for the fleet table, wiring up action selection handlers |
| `generateDataSet` | Function | Transforms raw `IFleet[]` API data into enriched `IFleetTableData[]` rows ready for table rendering |
| `generateActionDropdownOptions` | Function (internal) | Returns static dropdown options (`Rename`, `Delete`) for each fleet row's actions menu |
| `enhanceFleetData` | Function (internal) | Maps each `IFleet` object to `IFleetTableData`, attaching action options to each row |

### Column Definitions

| Column | Accessor | Renderer |
|---|---|---|
| Name | `name` | `LinkCell` → navigates to fleet details via `PATHS.FLEET_DETAILS_USERS` |
| Hosts | `host_count` | `TextCell` |
| Users | `user_count` | `TextCell` |
| Actions | `actions` | `ActionsDropdown` wrapped in `GitOpsModeTooltipWrapper` |

## Usage Example

```typescript
import {
  generateTableHeaders,
  generateDataSet,
} from "./FleetTableConfig";

// In a table container component:
const tableHeaders = generateTableHeaders((action, fleet) => {
  if (action === "delete") handleDeleteFleet(fleet);
  if (action === "rename") handleRenameFleet(fleet);
});

const tableData = generateDataSet(fleets); // fleets: IFleet[]

<TableContainer
  columns={tableHeaders}
  data={tableData}
/>
```

> **Note:** Actions are disabled automatically when GitOps mode is active via the `GitOpsModeTooltipWrapper` component. The `Rename` and `Delete` options are currently static; permission-based filtering (e.g., by current user ID) is flagged as a future enhancement.
