Test suite for the `AdminWrapper` component, verifying that the correct navigation items are rendered based on tier (`isPremiumTier`) and mode (`isSandboxMode`) context flags.

## Key Components

- **`describe("AdminWrapper - component")`** — Top-level test suite grouping all navigation rendering scenarios
- **Test cases** — Seven `it` blocks covering:
  - Free tier (global admin & maintainer) — expects `Organization Settings`, `Integrations`, `Users`; no `Fleets`
  - Premium tier (global admin, global maintainer, team admin, team maintainer) — expects all four nav items including `Fleets`
  - Sandbox mode — expects only `Integrations` and `Fleets`; hides `Organization Settings` and `Users`
