A modal component that displays a preview of the host status webhook payload sent to a configured destination URL.

## Key Components

### `getHostStatusPreview(teamScope?: boolean)`
Helper function that generates a sample webhook payload object containing:
- `unseen_hosts`, `total_hosts`, `days_unseen` — numeric mock values
- `team_id` — included only when `teamScope` is `true`

### `IHostStatusWebhookPreviewModal`
```typescript
interface IHostStatusWebhookPreviewModal {
  isTeamScope?: boolean; // Includes team_id in preview payload when true
  toggleModal: () => void; // Callback to open/close the modal
}
```

### `HostStatusWebhookPreviewModal`
Default export. Renders a `Modal` with a syntax-highlighted JSON preview of the webhook request body, generated via `syntaxHighlight()` from `utilities/helpers`.

## Usage Example

```typescript
import HostStatusWebhookPreviewModal from "components/HostStatusWebhookPreviewModal";

const MyComponent = () => {
  const [showPreview, setShowPreview] = useState(false);

  return (
    <>
      <Button onClick={() => setShowPreview(true)}>Preview Webhook</Button>
      {showPreview && (
        <HostStatusWebhookPreviewModal
          isTeamScope={true}
          toggleModal={() => setShowPreview(false)}
        />
      )}
    </>
  );
};
```

## Notes

- When `isTeamScope` is `false` (default), `team_id` is omitted from the preview payload, matching global-scope webhook behavior.
- The payload is rendered using `dangerouslySetInnerHTML` with `syntaxHighlight()` for formatted JSON display.
