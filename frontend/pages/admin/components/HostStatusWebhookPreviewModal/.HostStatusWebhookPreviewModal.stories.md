Storybook stories file for the `HostStatusWebhookPreviewModal` component, providing visual development and testing stories for the modal that previews host status webhook configurations.

## Key Components

- **`meta`** – Storybook metadata configuration registering the component under `Components/HostStatusWebhookPreviewModal` with default args (`isTeamScope: false`)
- **`Basic`** – Default story rendering the modal with global (non-team) scope settings

## Usage Example

```typescript
// Viewing in Storybook
// Run storybook and navigate to: Components > HostStatusWebhookPreviewModal > Basic

// To add additional stories with different prop variants:
export const TeamScope: Story = {
  args: {
    isTeamScope: true,
  },
};
```

## Notes

- The `isTeamScope` prop controls whether the preview reflects team-level or global webhook scope
- See the component source at [`HostStatusWebhookPreviewModal.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/HostStatusWebhookPreviewModal/HostStatusWebhookPreviewModal.tsx) for full prop definitions
