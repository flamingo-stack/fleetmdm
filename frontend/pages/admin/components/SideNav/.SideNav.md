A generic sidebar navigation component that renders a vertical nav list alongside a content card, used primarily in admin settings pages.

## Key Components

### Interfaces

- **`ISideNavItem<T>`** – Describes a navigation item with `title`, `urlSection`, `path`, the associated `Card` component, and an optional `exclude` flag
- **`ISideNavProps<T>`** – Props for `SideNav`, including the nav items array, the active item identifier, the currently rendered card, and an optional CSS class

### Component

- **`SideNav<T>`** – Generic functional component (defaults `T` to `IAppConfigFormProps`) that renders a `<nav>` list of `SideNavItem` links alongside a card content area

## Usage Example

```typescript
import SideNav, { ISideNavItem } from "components/SideNav";
import MySettingsCard from "pages/settings/MySettingsCard";

const navItems: ISideNavItem<MyCardProps>[] = [
  {
    title: "General",
    urlSection: "general",
    path: "/settings/general",
    Card: MySettingsCard,
  },
];

<SideNav
  navItems={navItems}
  activeItem="general"
  CurrentCard={<MySettingsCard formData={formData} />}
  className="my-settings-nav"
/>;
```

## Notes

- Active state is determined by comparing each item's `urlSection` against the `activeItem` prop
- The `Card` property on `ISideNavItem` is defined but not rendered by `SideNav` itself — the caller is responsible for instantiating and passing the correct card via `CurrentCard`
