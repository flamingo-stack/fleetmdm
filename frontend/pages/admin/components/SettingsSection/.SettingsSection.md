A reusable layout component that wraps settings page sections with a consistent header and styling structure.

## Key Components

- **`SettingsSection`** — Default export. Renders a `<section>` element with a `SectionHeader` and slotted children content.
- **`ISettingsSectionProps`** — Interface defining the component's props:
  - `title` *(required)* — Section heading text.
  - `subTitle` *(optional)* — Secondary description node; when provided, renders with grey styling and vertical alignment.
  - `children` *(required)* — Section body content.
  - `className` *(optional)* — Additional CSS class merged via `classnames`.
  - `id` *(optional)* — HTML `id` for anchor linking or accessibility.

## Usage Example

```typescript
import SettingsSection from "components/SettingsSection";

const MySettingsPage = () => (
  <SettingsSection
    title="Organization Info"
    subTitle={<span>Update your organization details below.</span>}
    id="org-info"
  >
    <input type="text" placeholder="Organization name" />
  </SettingsSection>
);
```

> **Note:** When `subTitle` is provided, the subtitle is automatically rendered in grey with vertical left-alignment. These styles are currently not configurable by the caller — if use cases evolve, the underlying `SectionHeader` props may need to be exposed.
