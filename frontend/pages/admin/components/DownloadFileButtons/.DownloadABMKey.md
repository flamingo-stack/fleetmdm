Renders a button component that downloads an Apple Business Manager (ABM) public key file, handling the async download request, error notifications, and request state tracking.

## Key Components

### `IDownloadABMKeyProps`
Props interface for the component:
- `baseClass` — BEM base class prefix for CSS scoping
- `onSuccess?` — optional callback fired after a successful download
- `onError?` — optional callback fired with the error on failure

### `useDownloadABMKey` (hook)
Internal hook managing download logic:
- Calls `mdmAppleBusinessManagerApi.downloadPublicKey()` and saves the result as `fleet-mdm-apple-bm-public-key.pem` via `downloadBase64ToFile`
- Tracks request state (`undefined` | `"loading"` | `"success"` | `"error"`)
- Renders a flash error notification via `NotificationContext` on failure

### `DownloadABMKey` (component)
Exported default component rendering an inverse-styled `Button` with a download icon and label, wired to the hook's `handleDownload` handler.

## Usage Example

```typescript
import DownloadABMKey from "components/DownloadABMKey";

<DownloadABMKey
  baseClass="abm-setup"
  onSuccess={() => console.log("Key downloaded successfully")}
  onError={(e) => console.error("Download failed", e)}
/>
```

The downloaded file is saved as `fleet-mdm-apple-bm-public-key.pem` and decoded from the base64-encoded `public_key` field returned by the API.
