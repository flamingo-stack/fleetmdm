Provides utility types and helper functions for common UI and file operations.

## Key Components

- **`RequestState`** – Union type representing the lifecycle states of an async request: `"loading"`, `"error"`, `"success"`, or `undefined`.
- **`downloadBase64ToFile`** – Triggers a browser file download from a Base64-encoded string.

## Usage Example

```typescript
import { RequestState, downloadBase64ToFile } from "./helpers";

// Track async request state
let state: RequestState = "loading";

// After receiving a Base64-encoded file from an API
const handleDownload = (base64Data: string) => {
  downloadBase64ToFile(base64Data, "report.pdf");
};
```

> **Note:** `downloadBase64ToFile` relies on the browser DOM (`document.createElement`) and is not suitable for server-side (Node.js) environments.
