React component and hook for requesting and downloading an Apple MDM Certificate Signing Request (CSR) file from the Fleet MDM Apple API.

## Key Components

### `IDownloadCSRProps`
Interface defining props for the `DownloadCSR` component:
- `baseClass` — CSS class prefix for BEM-style styling
- `onSuccess?` — Optional callback invoked after a successful download
- `onError?` — Optional callback invoked with the error on failure

### `useDownloadCSR` (hook)
Internal custom hook managing CSR download state and logic:
- Tracks `downloadState` as a `RequestState` (`undefined | "loading" | "success" | "error"`)
- `handleDownload` — async handler that calls `mdmAppleApi.requestCSR()`, converts the base64 CSR to a file download, and updates state accordingly

### `downloadCSRFile` (helper)
Wraps `downloadBase64ToFile` to save the API response as `fleet-mdm-apple.csr`.

### `DownloadCSR` (component)
Exported default component rendering a button with a download icon. Delegates all state logic to `useDownloadCSR`.

## Usage Example

```typescript
import DownloadCSR from "components/DownloadCSR";

<DownloadCSR
  baseClass="mdm-setup"
  onSuccess={() => console.log("CSR downloaded successfully")}
  onError={(e) => console.error("CSR download failed", e)}
/>
```

## Notes

- The component uses `variant="inverse"` on the `Button`, rendering an outlined/secondary style.
- The downloaded file is always named `fleet-mdm-apple.csr`.
- State management is memoized via `useMemo` and `useCallback` to prevent unnecessary re-renders.
- See [`helpers.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/helpers.ts) for `RequestState` type and `downloadBase64ToFile` utility.
