A reusable React navigation list item component that renders a single side navigation link with active state styling and tooltip support for truncated text.

## Key Components

### `ISideNavItemProps`
| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Display text for the navigation item |
| `path` | `string` | Route path the link navigates to |
| `isActive` | `boolean` | Toggles the `side-nav-item--active` CSS modifier |

### `SideNavItem`
Default export. Renders an `<li>` element containing a React Router `<Link>` wrapping a `TooltipTruncatedText` component. When the title overflows its container, a right-positioned tooltip displays the full text.

**CSS classes applied:**
- `side-nav-item` — always present
- `side-nav-item--active` — conditionally applied when `isActive` is `true`

## Usage Example

```typescript
import SideNavItem from "components/SideNavItem";

const navItems = [
  { title: "Dashboard", path: "/dashboard" },
  { title: "Device Management", path: "/devices" },
];

const SideNav = ({ currentPath }: { currentPath: string }) => (
  <ul>
    {navItems.map(({ title, path }) => (
      <SideNavItem
        key={path}
        title={title}
        path={path}
        isActive={currentPath === path}
      />
    ))}
  </ul>
);
```
