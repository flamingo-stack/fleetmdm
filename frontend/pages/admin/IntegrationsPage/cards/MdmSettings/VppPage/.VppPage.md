The `VppPage.tsx` file renders the Volume Purchasing Program (VPP) management page, allowing admins to add, renew, delete, and assign teams to Apple VPP tokens within the MDM integrations settings.

## Key Components

- **`VppPage`** — Main page component that fetches VPP tokens via `react-query` and orchestrates modal visibility and token selection state
- **`AddVppMessage`** — Empty state component rendered when no VPP tokens exist, prompting the user to add one
- **Modal integrations** — Conditionally renders `AddVppModal`, `RenewVppModal`, `DeleteVppModal`, and `EditTeamsVppModal` based on user actions
- **`VppTable`** — Displays the list of active VPP tokens with action handlers for edit, renew, and delete

## Key Logic

- Redirects to a premium feature message if not on the premium tier
- Prompts Apple MDM enablement if `config.mdm.enabled_and_configured` is `false`
- Uses a `useRef` (`selectedToken`) to track the token targeted by a modal action without triggering re-renders
- Refetches token data after any add, renew, delete, or team-edit operation

## Usage Example

```typescript
// Rendered via the app router; receives an InjectedRouter prop
import VppPage from "pages/admin/integrations/mdm/VppPage";

<VppPage router={router} />
```
