Modal component for renewing an Apple Volume Purchasing Program (VPP) token, handling file selection, upload, and API submission with success/error notifications.

## Key Components

- **`RenewVppModal`** — Default export. A modal dialog that accepts a `.vpptoken` file and submits it to the Fleet MDM API to renew an existing VPP integration.
- **`IRenewVppModalProps`** — Interface defining the component's props:
  - `tokenId` — ID of the VPP token to renew
  - `onCancel` — Callback fired when the user dismisses or an error occurs
  - `onRenewedToken` — Callback fired on successful renewal
- **`onRenewToken`** — Memoized async handler that calls `mdmAppleAPI.renewVppToken`, flashes a success or error notification, and triggers the appropriate callback.
- **`onSelectFile`** — Handler that captures the first file from a `FileList` and stores it in local state.

## Usage Example

```typescript
import RenewVppModal from "pages/MDMApple/RenewVppModal";

<RenewVppModal
  tokenId={42}
  onCancel={() => setShowRenewModal(false)}
  onRenewedToken={() => {
    setShowRenewModal(false);
    refetchVppTokens();
  }}
/>
```

## Behavior Notes

- The **Renew token** button is disabled until a `.vpptoken` file is selected.
- While the API call is in flight, `isRenewing` disables all modal content and shows a loading state on the submit button.
- On error, `getErrorMessage` extracts a human-readable string from the caught exception before flashing it and closing the modal via `onCancel`.
- Links to `https://fleetdm.com/learn-more-about/renew-vpp` for step-by-step renewal guidance.
