Defines the table column configuration and data utilities for the MDM VPP (Volume Purchase Program) token management table.

## Key Components

### Constants
- **`DEFAULT_ACTION_OPTIONS`** — Base dropdown actions: `editTeams`, `renew`, and `delete`
- **`RENEW_DATE_CELL_STATUS_CONFIG`** — Tooltip content for warning (< 30 days) and error (expired) token states

### Functions
- **`generateActions(gitopsModeEnabled, repoURL)`** — Returns action dropdown options, disabling `editTeams` with a GitOps mode tooltip when GitOps is active
- **`generateTableConfig(actionSelectHandler, gitopsModeEnabled, repoURL)`** — Builds the `react-table` column definitions for: Organization Name, Organization Unit, Country, Renew Date, Fleets, and Actions
- **`generateTableData(data)`** — Pass-through that returns the raw `IMdmVppToken[]` array as table rows

### Column Definitions
| Accessor | Header | Sortable |
|---|---|---|
| `org_name` | Organization name | ✅ |
| `location` | Organization unit | ❌ |
| `country_code` | Country | ❌ |
| `renew_date` | Renew date | ❌ |
| `teams` | Fleets | ❌ |
| `id` | _(Actions)_ | ❌ |

## Usage Example

```typescript
import {
  generateTableConfig,
  generateTableData,
} from "./VppTableConfig";

const columns = generateTableConfig(
  (action, token) => {
    if (action === "delete") handleDelete(token);
    if (action === "renew") handleRenew(token);
    if (action === "editTeams") handleEditTeams(token);
  },
  isGitOpsModeEnabled,
  "https://github.com/org/repo"
);

const tableData = generateTableData(vppTokens);
```
