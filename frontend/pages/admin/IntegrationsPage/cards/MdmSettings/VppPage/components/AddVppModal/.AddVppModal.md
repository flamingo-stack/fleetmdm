A modal component for uploading Apple Volume Purchase Program (VPP) token files to enable app distribution via MDM.

## Key Components

- **`AddVppModal`** — Default export; a modal dialog that handles VPP token file selection and upload
- **`IAddVppModalProps`** — Interface defining `onCancel` and `onAdded` callbacks
- **`onSelectFile`** — Memoized handler that captures the selected `.vpptoken` file from a `FileList`
- **`uploadVppToken`** — Memoized async function that uploads the token via `mdmAppleAPI.uploadVppToken`, triggers flash notifications, and calls the appropriate callback on success or failure

## Usage Example

```typescript
import AddVppModal from "./AddVppModal";

const ParentComponent = () => {
  const [showModal, setShowModal] = useState(false);

  const handleAdded = () => {
    setShowModal(false);
    // refresh VPP token list
  };

  return (
    <>
      {showModal && (
        <AddVppModal
          onCancel={() => setShowModal(false)}
          onAdded={handleAdded}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Accepts only `.vpptoken` files via the `FileUploader` component
- Displays an uploading state (`isUploading`) that disables the submit button and shows a loading indicator
- On success: renders a success flash and calls `onAdded()`
- On failure: renders an error flash via `getErrorMessage(e)` and calls `onCancel()`
- Links to `fleetdm.com/learn-more-about/add-vpp` for setup guidance
