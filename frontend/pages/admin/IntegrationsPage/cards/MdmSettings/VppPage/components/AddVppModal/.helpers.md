Utility helper for generating user-facing error messages when adding a VPP (Volume Purchase Program) connection fails.

## Key Components

- **`getErrorMessage(err)`** — Primary export. Parses an unknown error and returns an appropriate React node or string message based on the error reason:
  - **Duplicate entry** → Renders a JSX message identifying the conflicting organization unit by name
  - **Invalid token** → Returns the raw reason string from the error
  - **Default** → Returns `"Couldn't add. Please try again."`

- **`generateDuplicateMessage(msg)`** — Internal helper that extracts the organization name from a duplicate entry error string (via single-quote parsing) and renders a formatted JSX element.

- **`DEFAULT_ERROR_MESSAGE`** — Fallback string constant used when no specific error condition is matched.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await addVppConnection(token);
} catch (err) {
  const errorMessage = getErrorMessage(err);
  // Returns JSX for duplicate org, string for invalid token,
  // or default fallback message
  renderToast(errorMessage);
}
```

## Notes

- Depends on [`getErrorReason`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/errors.ts) from the shared error interface utilities to extract structured reason strings from raw errors.
- The duplicate message uses HTML entities (`&apos;`) for apostrophe safety in JSX.
- Return type is `string | JSX.Element`, so consumers should support React node rendering.
