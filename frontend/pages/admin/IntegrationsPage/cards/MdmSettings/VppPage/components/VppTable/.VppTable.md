Renders a table of Apple VPP (Volume Purchase Program) tokens with action support for editing, renewing, and deleting tokens, with GitOps mode awareness.

## Key Components

- **`VppTable`** – Main component that wraps `TableContainer` to display a list of `IMdmVppToken` entries
- **`IVppTableProps`** – Props interface defining the token array and three action callbacks
- **`onSelectAction`** – Internal dispatcher that routes string-based action names (`"editTeams"`, `"renew"`, `"delete"`) to the appropriate callback
- **`generateTableConfig`** – Imported from `VppTableConfig` to produce column definitions, receiving GitOps context for conditional rendering

## GitOps Context

The component reads GitOps state directly from `AppContext` rather than relying on a standard GitOps wrapper, since this table renders inside a nested dropdown. It passes `gitops_mode_enabled` and `repository_url` into the table config to control action availability.

## Usage Example

```typescript
import VppTable from "components/VppTable";

<VppTable
  vppTokens={tokens}
  onEditTokenTeam={(token) => openEditModal(token)}
  onRenewToken={(token) => openRenewModal(token)}
  onDeleteToken={(token) => openDeleteModal(token)}
/>
```

## Notes

- Table renders with `defaultSortHeader="org_name"`, no pagination, and no table header
- Empty state renders a blank fragment (`<></>`) — callers should handle empty token arrays upstream if a visible empty state is needed
