A table cell component that displays team assignments for MDM tokens, handling null, empty, single, and multiple team states with tooltip support for multi-team scenarios.

## Key Components

### `TeamsCell` (default export)
The main React component accepting `ITeamsCellProps` and rendering team data contextually:
- **No teams (`null`)** → renders `---` placeholder
- **Empty array** → renders `"All fleets"`
- **Single team** → renders the team's display name directly
- **Multiple teams** → renders `"{n} fleets"` (italic) wrapped in a `TooltipWrapper`

### `generateCell(teams)`
Internal helper that produces a `TextCell` element based on team count. Italicizes text when multiple teams are present.

### `condenseTeams(teams)`
Internal helper that builds a tooltip-friendly list by slicing the last `NUM_TEAMS_IN_TOOLTIP` (3) teams, reversing them for display order, and appending a `"+N more"` label when the total exceeds the limit.

## Usage Example

```typescript
import TeamsCell from "components/TableContainer/DataTable/TeamsCell";

// In a table column definition
{
  Header: "Teams",
  accessor: "teams",
  Cell: ({ cell: { value } }) => <TeamsCell teams={value} />,
}

// Example team data
<TeamsCell teams={null} />                          // → "---"
<TeamsCell teams={[]} />                            // → "All fleets"
<TeamsCell teams={[{ id: 1, name: "Engineering" }]} /> // → "Engineering"
<TeamsCell teams={[team1, team2, team3, team4]} />  // → "4 fleets" + tooltip
```

## Notes
- Tooltip shows up to 3 team names plus a `"+N more"` overflow label
- Uses [`TooltipWrapper`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/TooltipWrapper) with `position="top"` and arrow enabled
- Team display names are resolved via `getTeamDisplayName` from the `interfaces/team` module
