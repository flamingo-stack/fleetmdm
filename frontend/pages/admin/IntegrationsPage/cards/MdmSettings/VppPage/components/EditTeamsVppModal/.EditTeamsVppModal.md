Modal component for editing the fleet assignments of a VPP (Volume Purchase Program) token, allowing administrators to assign tokens to specific fleets or all fleets with conflict validation.

## Key Components

### Exported Utility Functions

- **`selectedValueFromToken(token)`** — Converts a `IMdmVppToken` to a comma-separated string of team IDs; returns `""` for unassigned, `APP_CONTEXT_ALL_TEAMS_ID` string for all-teams tokens.
- **`teamIdsFromSelectedValue(selectedValue)`** — Parses the comma-separated string back to an array of numeric IDs for the API; returns `null` for empty, `[]` for all-teams.
- **`updateSelectedValue(prev, next)`** — Merges multi-select state, enforcing mutual exclusivity between "All fleets" and individual fleet selections.
- **`getOptions(availableTeams, tokens, currentToken, pendingTeamIds)`** — Builds dropdown options, filtering out teams already assigned to other tokens and handling all-teams conflict logic across three cases.

### Component

- **`EditTeamsVppModal`** — Modal form with a multi-select `Dropdown` for fleet assignment. Disables the dropdown (with tooltip explanation) when another token is already assigned to all fleets. Calls `mdmAppleAPI.editVppTeams` on save.

## Usage Example

```typescript
<EditTeamsVppModal
  currentToken={selectedVppToken}
  tokens={allVppTokens}
  onCancel={() => setShowModal(false)}
  onSuccess={() => {
    setShowModal(false);
    refetchTokens();
  }}
/>
```

## Behavior Notes

- A token assigned to **all fleets** (`teams: []`) blocks other tokens from selecting any fleet unless that token is reassigned first.
- Individual fleet options are hidden from the dropdown if already claimed by another token, unless they are part of the current pending selection.
- Save triggers `mdmAppleAPI.editVppTeams` and flashes success/error via `NotificationContext`.
