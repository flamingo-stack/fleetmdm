A confirmation modal component for deleting a VPP (Volume Purchase Program) token, handling the async deletion flow with loading state and user notifications.

## Key Components

### `DeleteVppModal`
Default export. A modal dialog that confirms and executes VPP token deletion via the MDM Apple API.

**Props (`IDeleteVppModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `orgName` | `string` | Organization name displayed in the confirmation message |
| `tokenId` | `number` | ID of the VPP token to delete |
| `onCancel` | `() => void` | Callback invoked on cancel or deletion failure |
| `onDeletedToken` | `() => void` | Callback invoked after successful deletion |

### Internal Behavior
- Tracks `isDeleting` state to disable UI and show a loading spinner during the API call
- Calls `mdmAppleAPI.deleteVppToken(tokenId)` on confirm
- Renders success/error flash notifications via `NotificationContext`

## Usage Example

```typescript
import DeleteVppModal from "components/DeleteVppModal";

<DeleteVppModal
  orgName="Acme Corp"
  tokenId={42}
  onCancel={() => setShowModal(false)}
  onDeletedToken={() => {
    setShowModal(false);
    refreshTokenList();
  }}
/>
```

## Notes
- Content is disabled (non-interactive) while deletion is in progress via `isContentDisabled`
- On failure, the modal closes and an error flash is shown; the token is **not** deleted
- Apps are **not** uninstalled from hosts upon token deletion, but auto-install policies are removed
