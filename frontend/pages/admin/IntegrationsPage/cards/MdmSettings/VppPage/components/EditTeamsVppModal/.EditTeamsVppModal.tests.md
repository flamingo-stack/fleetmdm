Unit tests for the `EditTeamsVppModal` utility functions, covering VPP token team assignment logic including option filtering, selection state management, and pending edit scenarios.

## Key Components

### Test Fixtures

| Fixture | Description |
|---|---|
| `allTeamsToken` | Token with `teams: []` (assigned to all teams) |
| `unassignedToken` | Token with `teams: null` (not yet assigned) |
| `noTeamToken` | Token assigned to `team_id: 0` ("No Team") |
| `piratesAndNinjasToken` | Token assigned to two specific teams |
| `legacyEmptyCountryToken` | Token with `country_code: ""` (pre-backfill legacy token) |

### Functions Under Test

- **`getOptions`** — Computes available team options for a token, excluding teams claimed by other tokens and enforcing "all teams" mutual exclusivity
- **`updateSelectedValue`** — Handles multi-select state transitions, ensuring "all teams" selection is mutually exclusive with individual team selections
- **`selectedValueFromToken`** — Derives a comma-separated selection string from a token's current `teams` array
- **`teamIdsFromSelectedValue`** — Parses a selection string back to a numeric team ID array (returns `null` for unassigned, `[]` for all-teams)

## Usage Example

```typescript
// Derive current selection from a token
const selected = selectedValueFromToken(piratesAndNinjasToken);
// → "2,1"

// Build available options for the edit modal
const options = getOptions(availableTeams, allTokens, piratesAndNinjasToken, ["2", "1"]);
// → excludes teams already claimed by other tokens

// Handle user toggling "all teams" in the multiselect
const next = updateSelectedValue("2", "2,-1");
// → "-1" (all-teams collapses other selections)

// Convert selection back to team IDs for the API payload
const ids = teamIdsFromSelectedValue("2,1");
// → [2, 1]
```
