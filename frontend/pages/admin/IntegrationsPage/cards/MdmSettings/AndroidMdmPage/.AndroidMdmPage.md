Page component for managing Android Enterprise MDM configuration in the Fleet admin interface, handling both enabling and disabling Android MDM via Google Enterprise enrollment.

## Key Components

### `AndroidMdmPage` (default export)
Root page component that conditionally renders either the turn-on or turn-off flow based on `isAndroidMdmEnabledAndConfigured` from `AppContext`. Also manages the `TurnOffAndroidMdmModal` visibility state.

### `TurnOnAndroidMdm`
Handles the Android Enterprise enrollment flow:
- Fetches a Google signup URL via `mdmAndroidAPI.getSignupUrl()`
- Opens the enrollment portal in a centered popup window (885×600)
- Listens for completion via Server-Sent Events (SSE) using `mdmAndroidAPI.startSSE()`
- On SSE success, optimistically patches the in-memory `IConfig` via React Query's `setQueryData` and `AppContext.setConfig` to immediately reflect `android_enabled_and_configured: true` without a network round-trip
- Redirects to `PATHS.ADMIN_INTEGRATIONS_MDM` on success

### `TurnOffAndroidMdm`
Fetches and displays the current Android Enterprise ID from `mdmAndroidAPI.getAndroidEnterprise()`, with a button to trigger the turn-off modal.

## Usage Example

```typescript
// Rendered by the router — receives router from react-router
import AndroidMdmPage from "./AndroidMdmPage";

// Route definition (example)
<Route
  path={PATHS.ADMIN_INTEGRATIONS_MDM_ANDROID}
  component={(props) => <AndroidMdmPage router={props.router} />}
/>
```

```typescript
// SSE + optimistic cache update pattern used internally
const prevConfig = queryClient.getQueryData<IConfig>(["config"]);
if (prevConfig) {
  const patched: IConfig = {
    ...prevConfig,
    mdm: { ...prevConfig.mdm, android_enabled_and_configured: true },
  };
  setConfig(patched);
  queryClient.setQueryData(["config"], patched);
}
```

## Notes

- The SSE abort controller lifecycle is tied to the `setupSse` state flag via `useEffect`; aborting when the Google signup popup is closed is a known open TODO
- Error handling distinguishes between "android enterprise already exists" and generic API failures, showing a support link in the former case
