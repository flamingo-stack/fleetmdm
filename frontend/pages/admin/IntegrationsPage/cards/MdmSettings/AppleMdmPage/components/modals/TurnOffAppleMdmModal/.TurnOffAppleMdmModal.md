A confirmation modal component that prompts administrators to confirm disabling Apple MDM, warning them about the consequences of turning off MDM.

## Key Components

### `TurnOffAppleMdmModal`
Default export. A modal dialog that renders a warning message and two action buttons for confirming or cancelling the MDM deactivation.

**Props (`ITurnOffAppleMdmModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `onConfirm` | `() => void` | Callback invoked when the user confirms turning off MDM |
| `onCancel` | `() => void` | Callback invoked when the user cancels the action |

**Internal State:**
- `isDeleting` — Tracks the in-progress state after confirmation is clicked, disabling both buttons and showing a loading indicator on the confirm button to prevent duplicate submissions.

## Usage Example

```typescript
import TurnOffAppleMdmModal from "./TurnOffAppleMdmModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  const handleConfirm = async () => {
    await disableAppleMdm();
    setShowModal(false);
  };

  return (
    <>
      <Button onClick={() => setShowModal(true)}>Turn off Apple MDM</Button>
      {showModal && (
        <TurnOffAppleMdmModal
          onConfirm={handleConfirm}
          onCancel={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

> **Note:** After turning off MDM, re-enabling it requires uploading a new APNs certificate, and all end users must manually toggle MDM off and back on. Display this modal only when the user has explicitly chosen to disable Apple MDM.
