React component that renders the Apple Push Notification service (APNs) certificate setup UI, guiding users through downloading a CSR and uploading a `.pem` certificate to enable Apple MDM.

## Key Components

### Props (`IApplePushCertSetupProps`)
| Prop | Type | Description |
|------|------|-------------|
| `baseClass` | `string` | BEM base class prefix for scoped styling |
| `onSetupSuccess` | `() => void` | Callback invoked after successful certificate upload |

### Internal Handlers

- **`onFileUpload`** — Validates file selection, calls `mdmAppleApi.uploadApplePushCertificate`, triggers success flash and `onSetupSuccess`, or displays contextual error messages (private key missing vs. general failure)
- **`onDownloadError`** — Handles CSR download failures with specific messaging for APNS permission errors and missing private key errors

### Rendered Elements

- Instructional text with a link to `fleetdm.com/learn-more-about/turn-on-apple-mdm`
- `DownloadCSR` button for obtaining the certificate signing request
- `FileUploader` accepting `.pem` files with loading state feedback

## Usage Example

```typescript
import ApplePushCertSetup from "./ApplePushCertSetup";

const MDMSetupPage = () => {
  const handleSetupSuccess = () => {
    // Refresh MDM status or navigate away
    refetchMDMConfig();
  };

  return (
    <ApplePushCertSetup
      baseClass="mdm-setup"
      onSetupSuccess={handleSetupSuccess}
    />
  );
};
```

## Error Handling

| Condition | User Message |
|-----------|-------------|
| Missing private key (upload) | Flash error with link to private key docs |
| Missing private key (download) | Flash error with link to private key docs |
| APNS permission error | Flash error with API-returned message |
| General failure | Generic retry prompt |
