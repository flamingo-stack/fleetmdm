Displays Apple Push Notification (APN) certificate information for MDM configuration, along with action buttons to renew the certificate or turn off MDM.

## Key Components

- **`ApplePushCertInfo`** — Default export. A presentational React component that renders APN certificate details and action controls.
- **`IApplePushCertInfoProps`** — Props interface defining:
  - `baseClass` — CSS class prefix for BEM-style styling
  - `appleAPNInfo` — APN certificate data (`IMdmApple`), including `common_name` and `renew_date`
  - `orgName` — Organization name to display
  - `serverUrl` — MDM server URL
  - `onClickRenew` — Callback triggered by the "Renew certificate" button
  - `onClickTurnOff` — Callback triggered by the "Turn off MDM" button

## Usage Example

```typescript
import ApplePushCertInfo from "./ApplePushCertInfo";

<ApplePushCertInfo
  baseClass="mdm-settings"
  appleAPNInfo={{
    common_name: "com.apple.mgmt.example",
    renew_date: "2025-06-01T00:00:00Z",
  }}
  orgName="Acme Corp"
  serverUrl="https://mdm.example.com"
  onClickRenew={() => console.log("Renew triggered")}
  onClickTurnOff={() => console.log("Turn off triggered")}
/>
```

## Notes

- Uses `readableDate()` from `utilities/helpers` to format the certificate renewal date into a human-readable string.
- Renders a definition list (`<dl>`) for structured certificate metadata display.
- Fully controlled — no internal state; all actions are delegated to parent via callbacks.
