Manages the Apple MDM (Mobile Device Management) configuration page, handling APNs certificate setup, renewal, and MDM deactivation workflows.

## Key Components

### `AppleMdmPage`
The primary page component that orchestrates the Apple Push Notification service (APNs) certificate lifecycle. Renders conditionally based on API state:
- **`ApplePushCertSetup`** — shown when APNs is not yet configured (API returns 404)
- **`ApplePushCertInfo`** — shown when APNs is active, displaying certificate details
- **`RenewCertModal`** — modal for renewing an existing APNs certificate
- **`TurnOffAppleMdmModal`** — confirmation modal before disabling Apple MDM

### Key Handlers

| Handler | Description |
|---|---|
| `turnOffMdm` | Deletes APNs certificate, invalidates config cache, redirects to MDM integrations |
| `onRenewCert` | Refetches APNs info after successful certificate renewal |
| `onSetupSuccess` | Redirects to MDM integrations page after initial setup |

### UI State Logic

| State | Condition |
|---|---|
| Spinner | `isLoading \|\| isUpdating \|\| isRefetching` |
| Error | Missing config or non-404 API error |
| Content | Neither spinner nor error |

## Usage Example

```typescript
// Rendered via React Router — no manual instantiation needed
import AppleMdmPage from "./AppleMdmPage";

// Route definition (example)
<Route
  path={PATHS.ADMIN_INTEGRATIONS_MDM_APPLE}
  component={AppleMdmPage}
/>
```

The component queries `mdmAppleAPI.getAppleAPNInfo()` on mount (only when MDM is enabled), using a 5-second stale time. A 404 response signals unconfigured APNs and triggers the setup flow rather than an error state.
