A confirmation modal component for deleting an Apple Business Manager (ABM) token, which disables automatic MDM enrollment for hosts in the associated organization.

## Key Components

**`DeleteAbmModal`** — Default export. A modal dialog that prompts the user to confirm deletion of an ABM token via the `mdmAbmAPI.deleteToken` call.

**`IDeleteAbmModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|---|---|---|
| `tokenOrgName` | `string` | Organization name displayed in the confirmation message |
| `tokenId` | `number` | ID of the ABM token to delete |
| `onCancel` | `() => void` | Callback invoked on cancellation or API error |
| `onDeletedToken` | `() => void` | Callback invoked after successful deletion |

**State & Hooks:**
- `isDeleting` — Boolean state that disables UI controls and shows a loading indicator during the async delete operation
- `onDeleteToken` — `useCallback`-memoized handler that calls the delete API, flashes a success/error notification, then invokes the appropriate callback

## Usage Example

```typescript
import DeleteAbmModal from "components/DeleteAbmModal";

<DeleteAbmModal
  tokenOrgName="Acme Corp"
  tokenId={42}
  onCancel={() => setShowDeleteModal(false)}
  onDeletedToken={() => {
    setShowDeleteModal(false);
    refreshTokenList();
  }}
/>
```

## Notes

- On success, renders a `"success"` flash notification via `NotificationContext`
- On failure, renders an `"error"` flash and calls `onCancel` (modal closes without refreshing)
- The modal content and action buttons are disabled (`isContentDisabled`) while the delete request is in flight
