Unit tests for the `EditTeamsAbmModal` component's utility functions, validating `getOptions` and `getSelectedTeamIds` helper logic.

## Key Components

- **`getOptions`** — Transforms available teams into dropdown option objects, filtering out the "All fleets" entry
- **`getSelectedTeamIds`** — Maps selected team name strings (by platform) to their corresponding numeric fleet IDs, using `0` for "Unassigned"

## Test Coverage

| Test | Description |
|------|-------------|
| `getOptions` excludes all teams | Asserts "All fleets" (`APP_CONTEXT_ALL_TEAMS_SUMMARY`) is omitted from returned options |
| `getSelectedTeamIds` returns selected team ids | Verifies correct ID resolution per platform (`ios`, `ipados`, `macos`, `byod`) including the unassigned (`0`) fallback |

## Usage Example

```typescript
import { getOptions, getSelectedTeamIds } from "./EditTeamsAbmModal";

const availableTeams = [
  APP_CONTEXT_ALL_TEAMS_SUMMARY,
  APP_CONTEXT_NO_TEAM_SUMMARY,
  { name: "Team 1", id: 1 },
];

// Returns [{value: "No team", label: "No team"}, {value: "Team 1", label: "Team 1"}]
const options = getOptions(availableTeams);

// Returns { ios_fleet_id: 1, ipados_fleet_id: 0, macos_fleet_id: 0, byod_fleet_id: 0 }
const ids = getSelectedTeamIds(
  { ios_team: "Team 1", ipados_team: "Unassigned", macos_team: "Unassigned", byod_team: "Unassigned" },
  availableTeams
);
```
