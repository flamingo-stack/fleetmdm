Utility helper for generating user-facing error messages when adding an Apple Business Manager (ABM) connection.

## Key Components

- **`DEFAULT_ERROR_MESSAGE`** — Fallback error string shown when no specific error reason is matched.
- **`generateDuplicateMessage(msg)`** — Private helper that parses the error reason string to extract the organization name and returns a formatted JSX element indicating a duplicate ABM connection.
- **`getErrorMessage(err)`** — Primary export that inspects an unknown error using `getErrorReason`, matches against known failure conditions (`"Duplicate entry"`, `"Invalid token"`), and returns an appropriate error message (either JSX or a plain string).

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await addAbmConnection(token);
} catch (err) {
  const message = getErrorMessage(err);
  // message may be a string or JSX element
  renderErrorToast(message);
}
```

## Error Handling Logic

| Condition | Response |
|---|---|
| Reason includes `"Duplicate entry"` | JSX with extracted org name |
| Reason includes `"Invalid token"` | Raw reason string from error |
| Any other error | `"Couldn't add. Please try again."` |
