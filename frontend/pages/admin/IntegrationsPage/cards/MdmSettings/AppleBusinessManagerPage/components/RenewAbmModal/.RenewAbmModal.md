A modal component for renewing an Apple Business Manager (ABM) token by uploading a new `.p7m` token file.

## Key Components

- **`RenewAbmModal`** — Default export; renders a `Modal` with a file uploader and submit button for ABM token renewal
- **`IRenewAbmModalProps`** — Interface defining required props:
  - `tokenId` — ID of the ABM token to renew
  - `onCancel` — Callback fired on modal dismissal or upload error
  - `onRenewedToken` — Callback fired on successful token renewal
- **`onSelectFile`** — Memoized handler that captures the selected `.p7m` file from the `FileUploader`
- **`onRenewToken`** — Memoized async handler that calls `mdmAppleBmAPI.renewToken`, flashes success/error notifications, and invokes the appropriate callback

## Usage Example

```typescript
import RenewAbmModal from "pages/MDMSettings/RenewAbmModal";

<RenewAbmModal
  tokenId={42}
  onCancel={() => setShowRenewModal(false)}
  onRenewedToken={() => {
    setShowRenewModal(false);
    refetchTokens();
  }}
/>
```

## Behavior Notes

- Accepts only `.p7m` files via the `FileUploader`
- Disables the submit button and shows a loading state while the upload is in progress (`isUploading`)
- On success: flashes `"Renewed successfully."` and calls `onRenewedToken`
- On failure: flashes the error from `getErrorMessage(e)` and calls `onCancel`
- Includes a `CustomLink` to `fleetdm.com/learn-more-about/renew-abm` for step-by-step guidance
