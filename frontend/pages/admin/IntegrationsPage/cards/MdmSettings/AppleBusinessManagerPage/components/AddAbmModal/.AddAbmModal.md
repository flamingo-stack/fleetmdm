Modal component for adding an Apple Business Manager (ABM) token to Fleet MDM by uploading a `.p7m` token file.

## Key Components

- **`AddAbmModal`** — Default export; renders a modal dialog that guides users through uploading an ABM token file
- **`IAddAbmModalProps`** — Props interface with `onCancel` and `onAdded` callbacks
- **`onSelectFile`** — Memoized handler that captures the selected `.p7m` file from a `FileList`
- **`uploadAbmToken`** — Memoized async function that calls `mdmAbmAPI.uploadToken`, flashes success/error notifications, and triggers the appropriate callback

## Usage Example

```typescript
import AddAbmModal from "pages/admin/components/AddAbmModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      {showModal && (
        <AddAbmModal
          onCancel={() => setShowModal(false)}
          onAdded={() => {
            setShowModal(false);
            refetchAbmTokens();
          }}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Accepts only `.p7m` files via `FileUploader`
- The **Add AB** button is disabled until a file is selected or while uploading
- On success, flashes `"Added successfully."` and calls `onAdded`
- On failure, uses `getErrorMessage` to extract an error string, flashes it, and calls `onCancel`
- Includes a `DownloadABMKey` button alongside the submit action for downloading the public key required by Apple Business Manager
