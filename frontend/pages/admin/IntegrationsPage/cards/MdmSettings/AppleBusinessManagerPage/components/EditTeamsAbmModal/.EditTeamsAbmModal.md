Modal component for editing fleet team assignments on an Apple Business Manager (ABM) token, allowing users to map macOS, iOS, iPadOS, and BYOD fleets to specific teams.

## Key Components

### Exported Functions

- **`getOptions(availableTeams)`** — Filters available teams (excluding "All fleets") and returns dropdown-compatible `{ value, label }` options.
- **`getSelectedTeamIds(selectedTeamNames, availableTeams)`** — Maps selected team names to their numeric IDs using the shape expected by `mdmAbmAPI.editTeams`. Returns `undefined` for any team name not found in `availableTeams`.

### Component: `EditTeamsAbmModal`

A modal form with four platform-specific fleet dropdowns (macOS, iOS, iPadOS, BYOD). On save, resolves team names to IDs and calls `mdmAbmAPI.editTeams`, then fires `onSuccess` or falls back to `onCancel` on error.

### Types

- **`SelectedTeamNames`** — Internal state shape keyed by platform (`ios_team`, `ipados_team`, `macos_team`, `byod_team`).
- **`SelectedTeamIds`** — API-facing shape derived from `mdmAbmAPI.editTeams` parameters.

## Usage Example

```typescript
import EditTeamsAbmModal, {
  getOptions,
  getSelectedTeamIds,
} from "./EditTeamsAbmModal";

// Render the modal
<EditTeamsAbmModal
  token={abmToken}           // IMdmAbToken
  onCancel={() => setShowModal(false)}
  onSuccess={() => {
    setShowModal(false);
    refetchTokens();
  }}
/>

// Standalone helpers
const options = getOptions(availableTeams);
// [{ value: "Engineering", label: "Engineering" }, ...]

const teamIds = getSelectedTeamIds(
  { ios_team: "Engineering", ipados_team: "Engineering", macos_team: "IT", byod_team: "HR" },
  availableTeams
);
// { ios_fleet_id: 2, ipados_fleet_id: 2, macos_fleet_id: 1, byod_fleet_id: 3 }
```

## Notes

- "All fleets" is excluded from dropdown options in both `getOptions` and the internal `useMemo`.
- The form disables all inputs during save (`isContentDisabled={isSaving}`).
- Flash notifications are rendered via `NotificationContext` on both success and error.
