Utility helper for generating user-facing error messages during session renewal operations.

## Key Components

- **`getErrorMessage(err)`** — Inspects an unknown error object and returns an appropriate error message string. If the error contains an "Invalid token" reason, that specific reason is returned; otherwise, falls back to a generic renewal failure message.
- **`DEFAULT_ERROR_MESSAGE`** — Fallback string: `"Couldn't renew. Please try again."`.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await renewSession();
} catch (err) {
  const message = getErrorMessage(err);
  console.error(message);
  // "Invalid token: ..." or "Couldn't renew. Please try again."
}
```
