Renders an organization name table cell with a conditional warning indicator and tooltip when ABM (Apple Business Manager) terms have expired.

## Key Components

- **`IOrgNameCellProps`** — Interface defining component props:
  - `orgName: string` — The organization name to display
  - `termsExpired: boolean` — Flag indicating whether ABM terms have expired
- **`OrgNameCell`** — Default export; a functional component that wraps a `TextCell`, conditionally rendering a `TooltipWrapper` with a warning icon when terms are expired

## Usage Example

```typescript
// Standard display — no warning
<OrgNameCell orgName="Acme Corp" termsExpired={false} />

// With expired terms — shows warning icon and tooltip
<OrgNameCell orgName="Acme Corp" termsExpired={true} />
```

## Behavior

When `termsExpired` is `true`, the cell renders:
- The org name as a `<span>`
- A `warning` icon beside it
- A `TooltipWrapper` on hover (positioned `top`, with arrow, no underline) displaying:
  > The ABM terms have changed. To accept terms, go to ABM.

When `termsExpired` is `false`, only the plain `orgName` string is passed to `TextCell`.
