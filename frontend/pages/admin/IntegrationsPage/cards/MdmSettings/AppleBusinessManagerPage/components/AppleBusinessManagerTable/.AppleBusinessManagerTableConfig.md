Defines the column configuration and data transformation for the Apple Business Manager (ABM) token management table, including columns for organization name, renewal date, platform-specific fleet assignments, and row actions.

## Key Components

- **`generateTableConfig`** — Returns an array of `react-table` column definitions for the ABM token table. Accepts an action handler, a GitOps mode flag, and an optional repo URL.
- **`generateTableData`** — Passthrough function that returns the raw `IMdmAbToken[]` array for use as table row data.
- **`generateActions`** — Builds the actions dropdown options (`editTeams`, `renew`, `delete`), disabling `editTeams` with a GitOps tooltip when GitOps mode is active.
- **`RENEW_DATE_CELL_STATUS_CONFIG`** — Tooltip configuration for the `RenewDateCell`, covering warning (< 30 days) and error (expired) states.

### Columns

| Column | Accessor | Notes |
|---|---|---|
| Organization name | `org_name` | Renders `OrgNameCell` with terms-expired state |
| Renew date | `renew_date` | Renders `RenewDateCell` with warning/error status |
| macOS fleet | `macos_fleet` | Tooltip explains auto-assignment behavior |
| iOS fleet | `ios_fleet` | Tooltip explains auto-assignment behavior |
| iPadOS fleet | `ipados_fleet` | Tooltip explains auto-assignment behavior |
| BYOD fleet | `byod_fleet` | Tooltip explains Managed Apple Account enrollment |
| Actions | `id` | `ActionsDropdown` with GitOps-aware options |

## Usage Example

```typescript
import {
  generateTableConfig,
  generateTableData,
} from "./AppleBusinessManagerTableConfig";

const columns = generateTableConfig(
  (action, token) => {
    if (action === "delete") handleDelete(token);
    if (action === "renew") handleRenew(token);
    if (action === "editTeams") handleEditTeams(token);
  },
  isGitOpsModeEnabled,
  "https://github.com/flamingo-stack/fleetmdm"
);

const tableData = generateTableData(abmTokens);

// Pass to TableContainer
<TableContainer columns={columns} data={tableData} />;
```
