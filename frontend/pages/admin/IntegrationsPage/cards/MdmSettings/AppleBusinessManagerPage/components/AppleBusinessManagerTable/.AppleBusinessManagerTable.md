Renders a searchable table of Apple Business Manager (ABM) tokens, supporting actions to edit team assignments, renew, or delete tokens.

## Key Components

- **`AppleBusinessManagerTable`** — Default export; a React component that wraps `TableContainer` with ABM-specific configuration.
- **`IAppleBusinessManagerTableProps`** — Props interface defining the token list and action callbacks.
- **`onSelectAction`** — Internal dispatcher routing table row actions (`editTeams`, `renew`, `delete`) to the appropriate callback.
- **`generateTableConfig`** — Imported helper that builds column definitions, respecting GitOps mode state.
- **`useGitOpsMode`** — Hook providing `gitOpsModeEnabled` and `repoURL` for read-only enforcement in GitOps environments.

## Usage Example

```typescript
import AppleBusinessManagerTable from "./AppleBusinessManagerTable";

<AppleBusinessManagerTable
  abTokens={abmTokens}
  onEditTokenTeam={(token) => openEditModal(token)}
  onRenewToken={(token) => openRenewModal(token)}
  onDeleteToken={(token) => openDeleteModal(token)}
/>
```

## Behavior Notes

- **Client-side search** filters tokens by `org_name` (case-insensitive) without a separate API call.
- **GitOps mode**: When enabled, table actions may be restricted; `repoURL` is passed to the column config for contextual linking.
- Pagination is disabled; all filtered tokens render in a single view.
- Sorted by `org_name` by default.
