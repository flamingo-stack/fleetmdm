The main page component for managing Apple Business Manager (ABM) token integrations within the MDM admin settings, handling token listing, addition, renewal, deletion, and team assignment.

## Key Components

### `AddAbmMessage`
Internal component rendering an empty state prompt when no ABM tokens exist, with a CTA button to add the first token.

### `AppleBusinessManagerPage`
The primary page component that:
- Fetches ABM tokens via `react-query` using `mdmAbmAPI.getTokens()`
- Updates global ABM expiry state (`setABMExpiry`) on successful token fetch
- Conditionally renders based on premium tier status, MDM configuration state, and token availability
- Manages four modal workflows: Add, Renew, Delete, and Edit Teams

**Modal state management:**
| State | Modal |
|---|---|
| `showAddAbmModal` | `AddAbmModal` |
| `showRenewModal` | `RenewAbmModal` |
| `showDeleteModal` | `DeleteAbmModal` |
| `showEditTeamsModal` | `EditTeamsAbmModal` |

Selected token context is tracked via `selectedToken` ref shared across all modal handlers.

## Usage Example

```typescript
// Rendered by the router — receives an InjectedRouter prop
import AppleBusinessManagerPage from "./AppleBusinessManagerPage";

<AppleBusinessManagerPage router={router} />
```

**Content rendering priority:**
```text
1. Non-premium tier  → <PremiumFeatureMessage />
2. MDM not enabled   → Turn on MDM empty state
3. Loading           → <Spinner />
4. Fetch error       → <DataError />
5. No tokens         → <AddAbmMessage />
6. Tokens exist      → <AppleBusinessManagerTable />
```
