Header component for the Entra Tenants list view, rendering the section title and an "Add" button with GitOps mode awareness.

## Key Components

- **`EntraTenantsListHeader`** — Default export. Renders a header bar containing a "Tenants" label and an "Add" button that triggers the provided callback.
- **`IEntraTenantsListHeaderProps`** — Interface requiring `onClickAddTenant: () => void` as a callback for the add button.
- **`GitOpsModeTooltipWrapper`** — Wraps the add button to disable it and show a tooltip when GitOps mode is active.

## Usage Example

```typescript
import EntraTenantsListHeader from "components/EntraTenantsListHeader";

const MyPage = () => {
  const handleAddTenant = () => {
    // open add tenant modal
  };

  return (
    <EntraTenantsListHeader onClickAddTenant={handleAddTenant} />
  );
};
```

## Behavior Notes

- The "Add" button is automatically **disabled** when GitOps mode is enabled, with a tooltip explaining why (handled by `GitOpsModeTooltipWrapper`).
- Uses `variant="inverse"` styling with a `plus` icon prefix.
- BEM-style class names are scoped under `entra-tenants-list-header`.
