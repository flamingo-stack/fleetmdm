A React component that renders a single Microsoft Entra tenant entry in a list, displaying the tenant ID with a delete action button wrapped in GitOps mode protection.

## Key Components

- **`EntraTenantsListItem`** — Default export; a functional component that composes `ListItem`, `GitOpsModeTooltipWrapper`, `Button`, and `Icon` to display a deletable Entra tenant row
- **`IEntraTenantsListItemProps`** — Props interface defining:
  - `tenantId: string` — The Microsoft Entra tenant ID to display as the list item title
  - `onClickDelete: () => void` — Callback invoked when the delete (trash) button is clicked

## Usage Example

```typescript
import EntraTenantsListItem from "components/EntraTenantsListItem";

const EntraTenantsList = ({ tenants, onDeleteTenant }) => (
  <>
    {tenants.map((tenant) => (
      <EntraTenantsListItem
        key={tenant.id}
        tenantId={tenant.id}
        onClickDelete={() => onDeleteTenant(tenant.id)}
      />
    ))}
  </>
);
```

## Behavior Notes

- The delete button is wrapped in `GitOpsModeTooltipWrapper`, which automatically disables the button and shows a tooltip when the application is in GitOps mode, preventing manual tenant deletion
- The delete button uses `variant="icon"` rendering only the trash icon with an accessible `ariaLabel` that includes the tenant ID for screen reader clarity
