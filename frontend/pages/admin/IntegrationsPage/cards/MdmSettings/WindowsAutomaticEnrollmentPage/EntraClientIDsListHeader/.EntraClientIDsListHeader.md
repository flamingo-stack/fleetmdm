Header component for the Entra Client IDs list section, rendering a "Client IDs" label alongside an "Add" button wrapped in GitOps mode awareness.

## Key Components

- **`EntraClientIDsListHeader`** — Default export; a presentational component that displays the section title and an add-client-ID action button
- **`IEntraClientIDsListHeaderProps`** — Interface defining the single required prop:
  - `onClickAddClientId: () => void` — Callback triggered when the "Add" button is clicked
- **`GitOpsModeTooltipWrapper`** — Wraps the add button to disable it (with a tooltip) when GitOps mode is active
- **`Button`** — Renders the "Add" action using the `inverse` variant with a `plus` icon

## Usage Example

```typescript
import EntraClientIDsListHeader from "components/EntraClientIDsListHeader";

const handleAddClientId = () => {
  // Open modal or navigate to add client ID form
};

<EntraClientIDsListHeader onClickAddClientId={handleAddClientId} />;
```

## Notes

- The component is purely presentational — it delegates all state and navigation logic to the parent via `onClickAddClientId`
- The "Add" button is automatically disabled when GitOps mode is enabled, preventing manual configuration changes that would conflict with GitOps-managed state
- Styled via the `entra-client-ids-list-header` BEM base class
