A list item component for displaying a Microsoft Entra client ID with a delete action, wrapped with GitOps mode protection.

## Key Components

- **`EntraClientIDsListItem`** — Default export. Renders a single Entra client ID entry in a list with a trash icon delete button.
- **`IEntraClientIDsListItemProps`** — Props interface accepting `clientId` (string) and `onClickDelete` (callback).
- **`GitOpsModeTooltipWrapper`** — Disables the delete button when GitOps mode is active, preventing manual configuration changes.

## Usage Example

```typescript
import EntraClientIDsListItem from "components/EntraClientIDsListItem";

<EntraClientIDsListItem
  clientId="a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  onClickDelete={() => handleDelete("a1b2c3d4-e5f6-7890-abcd-ef1234567890")}
/>
```

## Behavior Notes

- The delete button is rendered as an icon-only `Button` (variant `"icon"`) with an accessible `ariaLabel` identifying the specific client ID being deleted.
- When GitOps mode is enabled, `GitOpsModeTooltipWrapper` sets `disableChildren` to `true`, disabling the delete button and displaying a tooltip explaining why the action is unavailable.
- The tooltip is positioned to the `left` of the button.
