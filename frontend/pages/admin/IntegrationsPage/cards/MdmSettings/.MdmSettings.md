Top-level MDM Settings page component that orchestrates data fetching and renders all MDM-related configuration sections for the Fleet admin settings UI.

## Key Components

### `MdmSettings` (default export)
The root component for the MDM settings page. Manages three parallel API queries and distributes results to child section components.

**Props (`IMdmSettingsProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `router` | `InjectedRouter` | React Router instance passed to child sections for navigation |
| `appConfig` | `IConfig` (optional) | Global app configuration, used to derive MDM enabled states |
| `isPremiumTier` | `boolean` | Gates premium-only sections (VPP, EULA, End User Migration) |

### Data Queries
| Query | Key | Condition | Notes |
|-------|-----|-----------|-------|
| APNS Info | `appleAPNInfo` | MDM enabled | Drives overall page loading/error state |
| VPP Tokens | `vppInfo` | MDM enabled + premium | 404 treated as "no token uploaded" |
| EULA Metadata | `eula-metadata` | MDM enabled + premium | 404 treated as "no EULA uploaded" |

### Rendered Sections
- **`MdmSettingsSection`** — Always rendered; owns global loading/error display
- **`AppleBusinessManagerSection`** — Shown when data is ready; indicates VPP status
- **`MicrosoftEntraSection`** — Windows MDM / Entra tenant configuration
- **`EulaSection`** — Premium + Apple BM enabled only
- **`EndUserMigrationSection`** — Premium + Apple BM enabled only

## Usage Example

```typescript
import MdmSettings from "./MdmSettings";

<MdmSettings
  router={router}
  appConfig={appConfig}
  isPremiumTier={true}
/>
```

## Error Handling Logic

- 404 from APNS → treated as a real error (blocks render)
- 404 from VPP / EULA → treated as "not yet configured" (non-blocking)
- Any non-404 error from VPP or EULA → `hasError = true`, blocks child section render
