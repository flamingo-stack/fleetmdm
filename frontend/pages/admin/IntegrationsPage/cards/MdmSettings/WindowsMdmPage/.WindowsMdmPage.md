Page component for configuring Windows MDM (Mobile Device Management) settings in the Fleet admin integrations panel.

## Key Components

### `useSetWindowsMdm` (custom hook)
Handles the async update of Windows MDM configuration via `configAPI.updateMDMConfig`. On success, updates global app config, shows a success flash, and navigates back to the MDM integrations page. On failure, renders an error flash with a parsed error message.

**Parameters:**
- `enableMdm` — whether Windows MDM is enabled
- `enableAutoMigration` — whether automatic MDM migration is enabled
- `enrollmentType` — `"automatic"`, `"manual"`, or `null`
- `router` — injected router for post-save navigation

### `WindowsMdmPage` (default export)
Main page component managing three pieces of local state:

| State | Type | Description |
|---|---|---|
| `mdmOn` | `boolean` | Toggles Windows MDM on/off |
| `autoMigration` | `boolean` | Auto-migrate hosts from another MDM (premium only) |
| `enrollmentType` | `"automatic" \| "manual" \| null` | Enrollment UX mode (premium only) |

## Usage Example

```typescript
// Rendered via react-router. Router is injected automatically.
import WindowsMdmPage from "./WindowsMdmPage";

<WindowsMdmPage router={router} />
```

## Behavior Notes

- **GitOps mode**: The MDM slider and auto-migration checkbox are disabled when `gitops_mode_enabled` is true; the Save button is wrapped in `GitOpsModeTooltipWrapper`.
- **Premium tier**: Enrollment type radio buttons (`Automatic` / `Manual`) and the auto-migration checkbox are only rendered for premium accounts.
- **State coupling**: Toggling MDM off resets `enrollmentType` to `null` and disables auto-migration. Selecting `manual` enrollment clears auto-migration.
- **Manual enrollment** requires linking Fleet to Microsoft Entra via `PATHS.ADMIN_INTEGRATIONS_AUTOMATIC_ENROLLMENT_WINDOWS`.
