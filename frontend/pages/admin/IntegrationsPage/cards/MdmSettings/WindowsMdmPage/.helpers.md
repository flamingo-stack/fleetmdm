Utility module for generating user-facing error messages related to Windows MDM configuration operations.

## Key Components

### `getErrorMessage(err: unknown): string | JSX.Element`
Maps raw API errors to descriptive, actionable error messages for Windows MDM enable/disable flows. Handles two specific named error conditions and falls back to a default message.

| Error Name | Response |
|---|---|
| `mdm.windows_enabled_and_configured` | JSX with a `CustomLink` pointing to the Fleet Windows MDM setup guide |
| `mdm.windows_migration_enabled` | Raw reason string extracted from the error |
| *(default)* | `"Unable to update Windows MDM. Please try again."` |

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await updateWindowsMDM(enabled);
} catch (err) {
  const message = getErrorMessage(err);
  // Render message in a flash/toast notification
  showFlashMessage(message);
}
```

## Notes

- Depends on [`getErrorReason`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/errors.ts) to extract structured error names from API responses.
- Returns a React element (JSX) when the `mdm.windows_enabled_and_configured` error is encountered, so the caller must support rendering React nodes — not just plain strings.
- The Fleet guide link targets the certificate/key generation step directly: `windows-mdm-setup#step-1-generate-your-certificate-and-key`.
