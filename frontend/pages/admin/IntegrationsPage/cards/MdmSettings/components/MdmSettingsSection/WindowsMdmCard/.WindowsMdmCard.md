Renders a settings card for Windows MDM enrollment, toggling between "turn on" and "edit" states based on the current MDM configuration.

## Key Components

- **`TurnOnWindowsMdmCard`** — Displays a prompt with a "Turn on" button when Windows MDM is not yet configured.
- **`TurnOffWindowsMdmCard`** — Displays a success state with an "Edit" button when Windows MDM is active (servers excluded).
- **`WindowsMdmCard`** *(default export)* — Reads `config.mdm.windows_enabled_and_configured` from `AppContext` and conditionally renders one of the two sub-cards.

## Usage Example

```typescript
import WindowsMdmCard from "./WindowsMdmCard";

<WindowsMdmCard
  turnOnWindowsMdm={() => setShowTurnOnModal(true)}
  editWindowsMdm={() => setShowEditModal(true)}
/>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `turnOnWindowsMdm` | `() => void` | Callback fired when the "Turn on" button is clicked |
| `editWindowsMdm` | `() => void` | Callback fired when the "Edit" button is clicked |

## Behavior

The component is stateless beyond its context read. It derives the display state solely from `AppContext.config.mdm.windows_enabled_and_configured`, defaulting to `false` if the value is absent. No local state or side effects are managed within the component itself.
