Renders the MDM (Mobile Device Management) settings section in the admin integrations page, displaying platform-specific MDM configuration cards for Apple, Windows, and Android with loading and error states.

## Key Components

- **`MdmSettingsSection`** – Main default export component that wraps MDM platform cards in a `SettingsSection` layout
- **`navigateToAppleMdm`** / **`navigateToWindowsMdm`** / **`navigateToAndroidMdm`** – Navigation handlers that route to platform-specific MDM admin pages
- **`renderContent`** – Conditional renderer that returns a `Spinner`, `DataError`, or the three MDM platform cards based on loading/error state
- **`IMdmSectionProps`** – Interface defining props: `isLoading`, `isError`, `appleAPNSError`, `router`, and optional `appleAPNSInfo`

## Usage Example

```typescript
import MdmSettingsSection from "./MdmSettingsSection";

<MdmSettingsSection
  isLoading={false}
  isError={false}
  appleAPNSError={null}
  router={router}
  appleAPNSInfo={appleAPNSData}
/>
```

## Behavior

| State | Rendered Output |
|---|---|
| `isLoading: true` | `<Spinner />` |
| `isError: true` | `<DataError />` |
| Default | `AppleMdmCard`, `WindowsMdmCard`, `AndroidMdmCard` |
