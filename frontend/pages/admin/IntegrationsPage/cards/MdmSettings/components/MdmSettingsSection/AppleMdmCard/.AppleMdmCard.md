Renders the Apple MDM configuration card in the MDM Settings page, conditionally displaying either an activation prompt or a configured-state summary based on APNS setup status.

## Key Components

- **`TurnOnAppleMdmCard`** — Displays a prompt card with a "Turn on" button when Apple MDM is not yet configured.
- **`SeeDetailsAppleMdmCard`** — Displays a success card with an "Edit" button when Apple MDM (APNS) is already configured.
- **`AppleMdmCard`** _(default export)_ — Orchestrator component that selects between the two sub-cards based on `appleAPNSInfo` and `errorData` props. Returns `<DataError />` for unexpected API errors, ignoring expected 404/400 responses that indicate MDM is simply not yet enabled.

## Usage Example

```typescript
<AppleMdmCard
  appleAPNSInfo={apnsData}       // undefined = not configured
  errorData={apnsError}          // AxiosError | null
  turnOnAppleMdm={handleTurnOn}  // opens Turn On MDM flow
  viewDetails={handleViewDetails} // opens Edit/Details modal
/>
```

## Error Handling Logic

| Condition | Rendered Output |
|---|---|
| Non-404/400 API error | `<DataError />` |
| `appleAPNSInfo` is `undefined` | `<TurnOnAppleMdmCard />` |
| `appleAPNSInfo` is populated | `<SeeDetailsAppleMdmCard />` |

> **Note:** 404 and 400 responses are treated as "MDM not configured" rather than errors, so they are intentionally suppressed and fall through to the normal card rendering logic.
