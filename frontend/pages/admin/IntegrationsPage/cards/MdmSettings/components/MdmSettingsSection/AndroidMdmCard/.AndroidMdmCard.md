Renders a settings card for Android MDM enrollment status, toggling between "turn on" and "turn off/edit" states based on the current MDM configuration from app context.

## Key Components

- **`TurnOnAndroidMdmCard`** — Displays a prompt with a "Turn on" button when Android MDM is not yet configured
- **`TurnOffAndroidMdmCard`** — Displays a success state with an "Edit" button when Android MDM is active
- **`AndroidMdmCard`** (default export) — Orchestrates which card variant to render based on `isAndroidMdmEnabledAndConfigured` from `AppContext`; returns `null` while the value is undefined (loading)

## Usage Example

```typescript
<AndroidMdmCard
  turnOffAndroidMdm={handleTurnOnAndroid}
  editAndroidMdm={handleEditAndroid}
/>
```

> **Note:** The `turnOffAndroidMdm` prop is passed as `onClickTurnOn` to `TurnOnAndroidMdmCard` — the prop name is inverted from its intent. When integrating, `turnOffAndroidMdm` should point to the handler that initiates the Android MDM setup/turn-on flow, while `editAndroidMdm` handles editing an already-enabled configuration.

## Dependencies

| Dependency | Purpose |
|---|---|
| `AppContext` | Reads `isAndroidMdmEnabledAndConfigured` to determine render state |
| `SectionCard` | Layout wrapper providing header, icon, and CTA slot |
| `Button` / `Icon` | UI primitives for action controls |
