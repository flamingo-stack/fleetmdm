Renders the Microsoft Entra settings section within the admin integrations page, gating Windows automatic enrollment configuration behind a premium tier check.

## Key Components

- **`MicrosoftEntraSection`** — Default export. A settings section component that conditionally renders either a `PremiumFeatureMessage` or the `WindowsAutomaticEnrollmentCard` based on the user's tier.
- **`IMicrosoftEntraSectionProps`** — Interface defining the component's props:
  - `router` — Injected router for programmatic navigation.
  - `windowsMdmEnabled` — Whether Windows MDM is currently enabled.
  - `tenantAdded` — Whether a Microsoft Entra tenant has been configured.
  - `isPremiumTier` — Gates access to enrollment configuration.
- **`navigateToWindowsEnrollment`** — Internal handler that pushes to `PATHS.ADMIN_INTEGRATIONS_AUTOMATIC_ENROLLMENT_WINDOWS`.

## Usage Example

```typescript
import MicrosoftEntraSection from "./MicrosoftEntraSection";

<MicrosoftEntraSection
  router={router}
  windowsMdmEnabled={true}
  tenantAdded={false}
  isPremiumTier={true}
/>
```

When `isPremiumTier` is `false`, a `PremiumFeatureMessage` is shown in place of the enrollment card. When `true`, `WindowsAutomaticEnrollmentCard` is rendered with the current MDM and tenant state, and clicking "View Details" navigates the user to the Windows automatic enrollment admin page.
