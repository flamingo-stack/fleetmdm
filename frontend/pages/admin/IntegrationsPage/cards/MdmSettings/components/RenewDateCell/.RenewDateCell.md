A table cell component that displays a renewal/expiration date with a color-coded status indicator, automatically reflecting whether the date is current, expiring soon (within 30 days), or already expired.

## Key Components

### `RenewDateCell`
The default export — a React component that wraps `StatusIndicator` and applies date-based status logic.

| Status | Condition |
|--------|-----------|
| `success` | Date is valid and not expiring soon |
| `warning` | Expires within 30 days |
| `error` | Date has already expired |

### `IRenewDateCellStatusConfig`
An exported type that maps `warning` and `error` indicator states to a `tooltipText` node, allowing callers to customize tooltip content per status.

### Props (`IRenewDateCellProps`)

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | ISO date string to evaluate and display |
| `statusConfig` | `IRenewDateCellStatusConfig` (optional) | Custom tooltip text per non-success status |
| `className` | `string` (optional) | Additional CSS classes |

## Usage Example

```typescript
import RenewDateCell, {
  IRenewDateCellStatusConfig,
} from "components/RenewDateCell";

const statusConfig: IRenewDateCellStatusConfig = {
  warning: { tooltipText: "License expires soon. Renew to avoid disruption." },
  error: { tooltipText: "License has expired. Renew immediately." },
};

<RenewDateCell
  value="2025-01-15T00:00:00Z"
  statusConfig={statusConfig}
/>
```

> The component always applies the `w250` width utility class to align consistently with other text cells in its parent table. If the status is `success`, no tooltip is rendered regardless of `statusConfig`.
