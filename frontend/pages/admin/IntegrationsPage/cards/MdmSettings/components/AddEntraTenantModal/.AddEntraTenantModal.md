A React modal component for adding a Microsoft Entra (Azure AD) tenant ID to the Fleet MDM Windows Entra integration configuration.

## Key Components

- **`AddEntraTenantModal`** — Main modal component that renders a form for submitting a new Entra tenant ID
- **`IAddTenantFormData`** — Interface defining the form data shape (`tenantId?: string`)
- **`IAddEntraTenantModalProps`** — Interface defining component props (`onExit` callback)
- **`onChangeTenantID`** — Handler that updates form state and triggers real-time validation on input change
- **`onAddTenant`** — Async submit handler that validates input, checks for duplicate tenant IDs in existing config, and calls `configAPI.update()` to persist the new tenant

## Key Behaviors

- **Duplicate detection** — Checks `config.mdm.windows_entra_tenant_ids` before submitting to prevent adding an already-registered tenant
- **Optimistic UI** — Disables modal content and shows a loading state on the submit button during the API call
- **Flash notifications** — Uses `NotificationContext` to surface success/error messages after submission
- **Real-time validation** — Delegates to `validateFormData` from `./helpers` on every keystroke; the Add button is disabled while the form is invalid

## Usage Example

```typescript
import AddEntraTenantModal from "./AddEntraTenantModal";

const ParentComponent = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowModal(true)}>Add Entra Tenant</Button>
      {showModal && (
        <AddEntraTenantModal onExit={() => setShowModal(false)} />
      )}
    </>
  );
};
```
