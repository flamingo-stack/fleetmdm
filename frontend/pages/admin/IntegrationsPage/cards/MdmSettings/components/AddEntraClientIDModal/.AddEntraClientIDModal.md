Modal component for adding a Microsoft Entra (Azure AD) client ID to the Fleet MDM Windows Entra configuration. Validates the input, checks for duplicates, and persists the new client ID via the config API.

## Key Components

- **`AddEntraClientIdModal`** — Main modal component that renders an input field for a GUID-format client ID, handles real-time validation, duplicate detection, and submission to the Fleet config API.
- **`IAddClientIdFormData`** — Interface defining the form data shape (`clientId?: string`).
- **`IAddEntraClientIdModalProps`** — Props interface requiring an `onExit` callback.
- **`validateFormData`** (imported from `./helpers`) — Validates the client ID format and returns an `IAddClientIdFormValidation` object.

## Key Behaviors

- Normalizes the client ID to lowercase and trims whitespace before validation and submission.
- Guards against duplicate client IDs already present in `config.mdm.windows_entra_client_ids`.
- Appends the new client ID to the existing list and calls `configAPI.update`, then updates global app config via `setConfig`.
- Disables the **Add** button when form validation fails and shows a loading state during submission.

## Usage Example

```typescript
import AddEntraClientIdModal from "./AddEntraClientIdModal";

// Render the modal and pass a close handler
const [showModal, setShowModal] = useState(false);

{showModal && (
  <AddEntraClientIdModal
    onExit={() => setShowModal(false)}
  />
)}
```

> **Note:** This component requires `NotificationContext` and `AppContext` providers to be present in the React tree for flash notifications and global config access.
