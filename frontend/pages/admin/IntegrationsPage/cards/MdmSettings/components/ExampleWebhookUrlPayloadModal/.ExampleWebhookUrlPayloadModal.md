Renders a modal dialog displaying an example webhook URL payload with syntax-highlighted JSON, helping users understand the structure of POST requests sent to their configured webhook endpoint.

## Key Components

- **`ExampleWebhookUrlPayloadModal`** — Default export; a modal component showing a sample webhook request with a static example payload
- **`IExampleWebhookUrlPayloadModalProps`** — Interface requiring an `onCancel` callback to close/dismiss the modal
- **`EXAMPLE_PAYLOAD`** — Static example object containing `timestamp`, and `host` fields (`id`, `uuid`, `hardware_serial`)
- **`syntaxHighlight`** — Utility used to render the JSON payload with syntax highlighting via `dangerouslySetInnerHTML`

## Usage Example

```typescript
import ExampleWebhookUrlPayloadModal from "components/ExampleWebhookUrlPayloadModal";

const MyComponent = () => {
  const [showModal, setShowModal] = React.useState(false);

  return (
    <>
      <button onClick={() => setShowModal(true)}>
        View Example Payload
      </button>
      {showModal && (
        <ExampleWebhookUrlPayloadModal
          onCancel={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- The example payload is hardcoded and static — it is not fetched from an API
- The example POST URL (`https://organization.com/send-request-here`) is a placeholder for illustrative purposes only
- `dangerouslySetInnerHTML` is intentionally used here for syntax highlighting of a static, trusted payload — not user-generated content
