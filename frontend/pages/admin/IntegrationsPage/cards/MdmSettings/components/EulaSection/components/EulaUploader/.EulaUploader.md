A React component that handles uploading End User License Agreement (EULA) PDF files for macOS MDM enrollment, validating file type and providing user feedback via flash notifications.

## Key Components

- **`EulaUploader`** — Default export; a form component that wraps `FileUploader` to handle EULA PDF uploads via the MDM API
- **`IEulaUploaderProps`** — Interface requiring an `onUpload` callback invoked after a successful upload
- **`onUploadFile`** — Async handler that validates the selected file is a `.pdf`, calls `mdmAPI.uploadEULA`, and renders success/error flash messages

## Usage Example

```typescript
import EulaUploader from "components/EulaUploader";

const MacOSSetupSettings = () => {
  const handleEulaUpload = () => {
    // Refresh EULA state after successful upload
    refetchEulaMetadata();
  };

  return (
    <EulaUploader onUpload={handleEulaUpload} />
  );
};
```

## Behavior Notes

- Only `.pdf` files are accepted; non-PDF selections immediately show an error flash and abort
- Uses `UPLOAD_ERROR_MESSAGES` and `getErrorMessage` from local `helpers` for consistent API error formatting
- `isLoading` state is passed to `FileUploader` to disable interaction during upload
- Renders a `CustomLink` pointing to the Fleet documentation page for end user license agreements
- Marked `gitopsCompatible` on the underlying `FileUploader`
