Provides error message utilities for EULA file upload operations, mapping API error reasons to user-friendly messages.

## Key Components

### `UPLOAD_ERROR_MESSAGES`
A map of named error types, each with:
- `condition`: A predicate function that matches against an API error reason string
- `message`: The user-facing error string to display

| Key | Condition | Message |
|---|---|---|
| `wrongType` | Reason includes `"invalid file type"` | File must be a PDF |
| `default` | Always false (`noop`) | Generic retry prompt |

### `getErrorMessage(err)`
Accepts an `AxiosResponse<IApiError>` and returns the appropriate user-facing error string by matching the first API error reason against known `UPLOAD_ERROR_MESSAGES` conditions. Falls back to the `default` message if no condition matches.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await uploadEula(file);
} catch (err) {
  const message = getErrorMessage(err);
  // e.g. "Couldn't upload EULA. The file must be a PDF (.pdf)."
  renderErrorToast(message);
}
```
