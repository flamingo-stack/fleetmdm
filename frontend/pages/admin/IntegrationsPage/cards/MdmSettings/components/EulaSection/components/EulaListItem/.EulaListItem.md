Renders a single EULA (End User License Agreement) list entry with options to view or delete the uploaded PDF file.

## Key Components

- **`EulaListItem`** — Default export. A React component that displays EULA metadata and action controls.
- **`IEulaListItemProps`** — Props interface accepting `eulaData` (`IEulaMetadataResponse`) and an `onDelete` callback.
- **`onOpenEula`** — Opens the EULA PDF in a new browser tab via the MDM EULA API endpoint.

## Usage Example

```typescript
import EulaListItem from "components/EulaListItem";

<EulaListItem
  eulaData={{
    token: "abc123",
    name: "Corporate EULA.pdf",
    created_at: "2024-01-15T10:00:00Z",
  }}
  onDelete={() => handleEulaDelete()}
/>
```

## Behavior

- Displays a PDF graphic icon alongside the EULA file name and a relative upload timestamp (e.g., *"Uploaded 3 days ago"*) via `date-fns` `formatDistanceToNow`.
- **View action** — Opens the EULA PDF at `/api/mdm/eula/:token` in a new tab.
- **Delete action** — Triggers the `onDelete` callback, wrapped in `GitOpsModeTooltipWrapper` to automatically disable and annotate the button when GitOps mode is active.
