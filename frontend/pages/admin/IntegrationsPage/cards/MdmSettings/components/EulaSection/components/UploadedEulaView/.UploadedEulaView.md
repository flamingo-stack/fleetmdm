Displays a view for a previously uploaded End User License Agreement (EULA), showing metadata and providing a delete action for macOS MDM setup experience configuration.

## Key Components

- **`UploadedEulaView`** – Default export; renders a description, a learn-more link, and a list entry for the uploaded EULA file
- **`IUploadedEulaViewProps`** – Props interface requiring `eulaMetadata` (`IEulaMetadataResponse`) and an `onDelete` callback
- **`UploadList`** – Generic list component used to render the EULA entry
- **`EulaListItem`** – Renders individual EULA metadata with a delete control

## Usage Example

```typescript
import UploadedEulaView from "./UploadedEulaView";
import { IEulaMetadataResponse } from "services/entities/mdm";

const eulaMetadata: IEulaMetadataResponse = {
  name: "eula.pdf",
  token: "abc123",
  created_at: "2024-01-01T00:00:00Z",
};

const handleDelete = () => {
  console.log("EULA deleted");
};

<UploadedEulaView
  eulaMetadata={eulaMetadata}
  onDelete={handleDelete}
/>;
```

## Notes

- Rendered only when a EULA has already been uploaded; pair with an upload form component for the empty state
- The "Learn more" link opens Fleet's setup experience documentation in a new tab
