Manages the End User License Agreement (EULA) settings section, handling display, upload, and deletion of EULA documents in the MDM admin settings.

## Key Components

- **`EulaSection`** — Main component that conditionally renders either an uploader or the uploaded EULA view based on upload state
- **`IEulaSectionProps`** — Interface defining required props for EULA state and callback handlers
- **`onDeleteEula`** — Async handler that calls the MDM API to delete the EULA by token, displays a flash notification, and triggers parent callbacks
- **`showDeleteEulaModal`** — Local state controlling visibility of the delete confirmation modal

### Child Components Used
- `EulaUploader` — Shown when no EULA is uploaded
- `UploadedEulaView` — Shown when a EULA exists, with delete trigger
- `DeleteEulaModal` — Confirmation modal for deletion

## Usage Example

```typescript
import EulaSection from "./EulaSection";

<EulaSection
  eulaMetadata={eulaMetadata}       // IEulaMetadataResponse | undefined
  isEulaUploaded={true}             // boolean flag
  onUpload={() => refetchEula()}    // called after successful upload
  onDelete={() => refetchEula()}    // called after successful deletion
/>
```

## Behavior Notes

- Deletion requires `eulaMetadata` to be defined (guards against missing token)
- Flash notifications are shown for both success and error states via `NotificationContext`
- The delete modal is controlled locally; parent is notified only via the `onDelete` callback after the operation completes (success or failure)
