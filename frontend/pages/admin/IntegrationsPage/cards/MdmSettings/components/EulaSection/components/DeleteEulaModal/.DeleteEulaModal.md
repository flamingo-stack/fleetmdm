A confirmation modal component for deleting an End User License Agreement (EULA) from macOS automatic enrollment configuration.

## Key Components

- **`DeleteEulaModal`** — Default export. A modal dialog that warns users about the impact of EULA deletion and provides confirm/cancel actions.
- **`IDeleteEulaModalProps`** — Interface defining the component's required props:
  - `onDelete: () => void` — Callback invoked when the user confirms deletion (via button click or Enter key).
  - `onCancel: () => void` — Callback invoked when the user cancels (via button click or modal exit).

## Usage Example

```typescript
import DeleteEulaModal from "components/DeleteEulaModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  const handleDelete = async () => {
    await deleteEula();
    setShowModal(false);
  };

  return (
    <>
      {showModal && (
        <DeleteEulaModal
          onDelete={handleDelete}
          onCancel={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Pressing **Enter** triggers `onDelete` via the modal's `onEnter` handler.
- Clicking the modal's exit control or **Cancel** triggers `onCancel`.
- The **Delete** button uses the `alert` variant (destructive styling); **Cancel** uses `inverse-alert`.
- No loading or async state is managed internally — callers are responsible for handling async deletion logic.
