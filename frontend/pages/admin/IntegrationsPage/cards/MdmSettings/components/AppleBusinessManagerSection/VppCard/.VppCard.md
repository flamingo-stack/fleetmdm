Renders a settings section card for Apple Volume Purchasing Program (VPP) configuration, displaying one of three states based on MDM and VPP enablement status.

## Key Components

### `VppCard`
Default export. A conditional display component that renders different `SectionCard` variants:

| State | Condition | Rendered Card |
|---|---|---|
| `AppleMdmDisabledCard` | `isAppleMdmOn === false` | Prompt to enable Apple MDM first |
| `VppOnCard` | `isAppleMdmOn && isVppOn` | Success state with Edit button |
| `VppOffCard` | `isAppleMdmOn && !isVppOn` | Prompt to connect VPP with "Add VPP" button |

### `IVppCardProps`

| Prop | Type | Description |
|---|---|---|
| `isAppleMdmOn` | `boolean` | Whether Apple MDM is currently enabled |
| `isVppOn` | `boolean` | Whether a VPP connection is active |
| `viewDetails` | `() => void` | Callback triggered by both Edit and Add VPP buttons |

## Usage Example

```typescript
import VppCard from "./VppCard";

<VppCard
  isAppleMdmOn={true}
  isVppOn={false}
  viewDetails={() => navigate("/settings/vpp")}
/>
```
