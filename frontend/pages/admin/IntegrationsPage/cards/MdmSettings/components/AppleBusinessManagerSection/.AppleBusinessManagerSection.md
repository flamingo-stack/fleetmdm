Renders the Apple Business Manager settings section within the admin integrations page, displaying enrollment and VPP configuration cards or a premium upgrade prompt based on tier.

## Key Components

- **`AppleBusinessManagerSection`** — Main exported component that wraps `AppleAutomaticEnrollmentCard` and `VppCard` inside a `SettingsSection`
- **`navigateToAppleAutomaticEnrollment`** — Routes to `PATHS.ADMIN_INTEGRATIONS_APPLE_BUSINESS_MANAGER`
- **`navigateToVppSetup`** — Routes to `PATHS.ADMIN_INTEGRATIONS_VPP_SETUP`
- **`AppContext`** — Supplies `config.mdm` state to determine enabled/configured status of Apple MDM and ABM

## Props

| Prop | Type | Description |
|---|---|---|
| `router` | `InjectedRouter` | Router instance for programmatic navigation |
| `isPremiumTier` | `boolean` | Gates content behind a `PremiumFeatureMessage` if `false` |
| `isVppOn` | `boolean` | Indicates whether Volume Purchase Program is active |

## Usage Example

```typescript
import AppleBusinessManagerSection from "./AppleBusinessManagerSection";

<AppleBusinessManagerSection
  router={router}
  isPremiumTier={isPremiumTier}
  isVppOn={isVppOn}
/>
```

## Behavior

- If `isPremiumTier` is `false`, renders `<PremiumFeatureMessage />` instead of the cards
- `AppleAutomaticEnrollmentCard` receives MDM enabled/configured status from `AppContext`
- `VppCard` receives both MDM and VPP status flags
