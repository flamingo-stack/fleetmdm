Test suite for the `VppCard` component, verifying its conditional rendering behavior based on VPP and Apple MDM enabled states.

## Key Components

- **`VppCard` component** — The component under test, accepting `viewDetails`, `isVppOn`, and `isAppleMdmOn` props
- **Three test cases** covering the primary UI states:
  - Apple MDM disabled → MDM-off warning message
  - Apple MDM enabled, VPP disabled → "Add VPP" button
  - Apple MDM enabled, VPP enabled → "Edit" button

## Usage Example

```typescript
// Run the test suite
npx jest VppCard.tests.tsx

// Component states under test
<VppCard viewDetails={noop} isVppOn={false} isAppleMdmOn={false} />
// → Shows: "To enable Volume Purchasing Program (VPP), first turn on Apple (macOS, iOS, iPadOS) MDM."

<VppCard viewDetails={noop} isVppOn={false} isAppleMdmOn />
// → Renders: "Add VPP" button

<VppCard viewDetails={noop} isVppOn isAppleMdmOn />
// → Renders: "Edit" button
```

## Test Coverage

| Scenario | `isAppleMdmOn` | `isVppOn` | Expected Output |
|---|---|---|---|
| MDM off | `false` | `false` | Warning message |
| MDM on, VPP off | `true` | `false` | "Add VPP" button |
| MDM on, VPP on | `true` | `true` | "Edit" button |

## Notes

- Uses `@testing-library/react` for DOM queries (`findByText`, `findByRole`)
- `viewDetails` is stubbed with `lodash/noop` since navigation callbacks are not tested here
- All assertions are async (`await findBy*`) to handle any deferred rendering
