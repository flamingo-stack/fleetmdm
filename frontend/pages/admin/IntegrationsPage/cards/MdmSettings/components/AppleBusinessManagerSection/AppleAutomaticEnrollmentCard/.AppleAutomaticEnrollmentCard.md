Renders a status card for Apple Automatic Device Enrollment (ADE/ABM) configuration, displaying one of three states based on whether Apple MDM is enabled and ABM is configured.

## Key Components

### `AppleAutomaticEnrollmentCardProps`
| Prop | Type | Description |
|---|---|---|
| `isAppleMdmOn` | `boolean` | Whether Apple MDM is currently enabled |
| `viewDetails` | `() => void` | Callback triggered by "Edit" or "Add ABM" buttons |
| `configured` | `boolean` (optional) | Whether ABM has been configured |

### Rendered States
| Condition | Card Shown |
|---|---|
| `isAppleMdmOn === false` | **Disabled** — prompts user to enable Apple MDM first |
| `isAppleMdmOn && !configured` | **Not Configured** — shows "Add ABM" CTA button |
| `isAppleMdmOn && configured` | **Configured** — shows success icon with "Edit" button |

## Usage Example

```typescript
import AppleAutomaticEnrollmentCard from "./AppleAutomaticEnrollmentCard";

// MDM off — shows prerequisite message
<AppleAutomaticEnrollmentCard
  isAppleMdmOn={false}
  viewDetails={() => router.push("/mdm/apple")}
/>

// MDM on, ABM not yet configured
<AppleAutomaticEnrollmentCard
  isAppleMdmOn={true}
  configured={false}
  viewDetails={() => openAbmSetupModal()}
/>

// MDM on, ABM configured
<AppleAutomaticEnrollmentCard
  isAppleMdmOn={true}
  configured={true}
  viewDetails={() => openAbmEditModal()}
/>
```
