Renders the End User Migration Workflow settings section, allowing admins to configure macOS MDM migration behavior including mode selection, webhook URL, and enable/disable toggling.

## Key Components

- **`EndUserMigrationSection`** — Default export. Main settings section component gated behind premium tier and Apple Business Manager configuration checks.
- **`IEndUserMigrationFormData`** — Interface defining form state: `isEnabled`, `mode` (`"voluntary" | "forced"`), and `webhookUrl`.
- **`validateWebhookUrl`** — Validates webhook URL using `validator/lib/isURL`, requiring `http`/`https` protocols.
- **`formClasses`** — Dynamically disables form fields when migration is disabled or GitOps mode is active.

## Conditional Rendering

| State | Rendered Output |
|---|---|
| Non-premium tier | `PremiumFeatureMessage` |
| Apple BM not configured | `EmptyState` with Connect button |
| Fully configured | Full migration settings form |

## Key Behaviors

- **Voluntary mode** — End user sees migration window when selecting "Migrate to Fleet" from Fleet Desktop menu, or every 15–20 minutes if unenrolled.
- **Forced mode** — Migration window appears every 15–20 minutes regardless.
- **Webhook URL** — Validated on change and on submit; server-side errors on `macos_migration.webhook_url` are surfaced inline.
- **GitOps mode** — All form controls are disabled when `gitops_mode_enabled` is `true`.

## Usage Example

```typescript
import EndUserMigrationSection from "./EndUserMigrationSection";

// Used within an admin settings page layout
const MDMSettingsPage = ({ router }) => (
  <EndUserMigrationSection router={router} />
);
```
