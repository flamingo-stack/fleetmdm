Test suite for the `EndUserMigrationSection` component, validating UI behavior for macOS MDM end-user migration settings including toggle interactions, GitOps mode restrictions, and tier/connection state rendering.

## Key Components

- **`createTestMockData`** — Helper that builds mock app context with configurable `IConfig` overrides and premium tier flag
- **`describe("EndUserMigrationSection")`** — Four test cases covering the component's conditional UI states

## Test Cases

| Test | Description |
|------|-------------|
| Toggle slider enables/disables form fields | Verifies radio buttons and webhook URL input are disabled when the migration toggle is off, and enabled after clicking |
| GitOps mode disables all form elements | Confirms that when `gitops_mode_enabled: true`, the slider and all form fields remain disabled and unclickable |
| Unconfigured Apple Business Manager | Checks that a "Connect" button and prompt render when `apple_bm_enabled_and_configured: false` |
| Non-premium tier | Asserts the premium feature upsell message is shown when `isPremiumTier` is `false` |
