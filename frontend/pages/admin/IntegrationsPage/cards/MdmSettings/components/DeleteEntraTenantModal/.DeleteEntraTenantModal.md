Modal component for removing a Windows Entra tenant ID from the MDM configuration, disabling both Autopilot and manual enrollment for that tenant.

## Key Components

- **`DeleteEntraTenantModal`** — Default export. Renders a confirmation modal that filters the target `tenantId` out of `windows_entra_tenant_ids` and persists the update via `configAPI`.
- **`IDeleteEntraTenantModalProps`** — Props interface requiring `tenantId` (the ID to remove) and `onExit` (close/dismiss callback).
- **`onDeleteToken`** — Async handler that reads the current tenant list from `AppContext`, removes the target ID, calls `configAPI.update`, updates global config state, and flashes a success or error notification.

## Usage Example

```typescript
import DeleteEntraTenantModal from "./DeleteEntraTenantModal";

const [showDeleteModal, setShowDeleteModal] = useState(false);
const [selectedTenantId, setSelectedTenantId] = useState("");

{showDeleteModal && (
  <DeleteEntraTenantModal
    tenantId={selectedTenantId}
    onExit={() => setShowDeleteModal(false)}
  />
)}
```

## Behavior Notes

- **Optimistic filtering** — the updated list is derived client-side by filtering `config.mdm.windows_entra_tenant_ids` before the API call; no separate fetch is required.
- **Loading state** — `isDeleting` disables modal content and shows a spinner on the Delete button during the async operation.
- **Flash notifications** — uses `NotificationContext` to surface success (`"Tenant deleted successfully."`) and error (`"Couldn't delete tenant. Please try again."`) messages.
- `onExit` is called automatically on success; on error the modal stays open to allow retry.
