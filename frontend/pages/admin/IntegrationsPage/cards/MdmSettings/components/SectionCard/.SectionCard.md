A reusable UI component that renders a styled grey card with an optional icon, header, content area, and call-to-action element.

## Key Components

**`ISectionCardProps`** — Interface defining the component's props:
- `children` *(required)* — Main content rendered inside the card
- `header` *(optional)* — Section heading displayed as an `<h3>`
- `iconName` *(optional)* — Icon identifier from the shared `IconNames` type
- `cta` *(optional)* — Call-to-action JSX element rendered at the bottom of the card
- `className` *(optional)* — Additional CSS class names merged via `classnames`

**`SectionCard`** — Default export; a functional component composing `Card`, `Icon`, and structured layout `div`s under the `section-card` BEM base class.

## Usage Example

```typescript
import SectionCard from "components/SectionCard";
import Button from "components/buttons/Button";

// Basic usage with header and icon
<SectionCard header="Disk Encryption" iconName="lock">
  <p>Enable disk encryption to protect data at rest.</p>
</SectionCard>

// With a call-to-action element
<SectionCard
  header="MDM Enrollment"
  iconName="smartphone"
  cta={<Button onClick={handleEnroll}>Enroll devices</Button>}
  className="custom-section"
>
  <p>Enroll your devices to manage them through Fleet.</p>
</SectionCard>
```

## Notes

- Always renders with `color="grey"` via the underlying `Card` component — this is not configurable.
- The icon and header are conditionally rendered; the card is valid with `children` alone.
- BEM class structure: `section-card`, `section-card__content-wrapper`, `section-card__content`, `section-card__cta`.
