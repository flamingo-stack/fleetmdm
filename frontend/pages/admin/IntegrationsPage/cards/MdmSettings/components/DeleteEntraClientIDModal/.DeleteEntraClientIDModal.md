Modal component for confirming and executing the deletion of a Microsoft Entra client ID from the MDM configuration, preventing Windows hosts from enrolling via that application.

## Key Components

- **`DeleteEntraClientIdModal`** — Default export; a confirmation modal that removes a specified Entra client ID from `config.mdm.windows_entra_client_ids` via the config API
- **`IDeleteEntraClientIdModalProps`** — Props interface requiring `clientId` (string to remove) and `onExit` (close callback)
- **`onDeleteClientId`** — Async handler that filters the target ID from the current list, PATCHes the config, updates global app context, and flashes a success or error notification

## Usage Example

```typescript
import DeleteEntraClientIdModal from "./DeleteEntraClientIDModal";

const ManageEntraIds = () => {
  const [selectedClientId, setSelectedClientId] = useState<string | null>(null);

  return (
    <>
      {selectedClientId && (
        <DeleteEntraClientIdModal
          clientId={selectedClientId}
          onExit={() => setSelectedClientId(null)}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Reads existing `windows_entra_client_ids` from `AppContext`, filters out the target ID, and persists the result via `configAPI.update`
- Disables modal content and shows a loading state on the **Delete** button during the API call
- Only the targeted client ID is removed; all other tenant and client IDs remain unaffected
- On success, updates global config via `setConfig` and calls `onExit` to close the modal
- On failure, displays an error flash without closing the modal
