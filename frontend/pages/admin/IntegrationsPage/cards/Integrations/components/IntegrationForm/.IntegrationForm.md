A React form component for creating and editing Jira and Zendesk ticket integrations, handling field validation, connection testing state, and GitOps mode restrictions.

## Key Components

### `IntegrationForm` (default export)
The main form component that renders conditionally based on `testingConnection` state — showing a spinner during connection tests or a full form for data entry.

**Props (`IIntegrationFormProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Cancels the form action |
| `onSubmit` | `(data, destination) => void` | Submits the assembled integration array |
| `integrationEditing` | `IIntegrationTableData?` | Populated when editing an existing integration |
| `integrations` | `IZendeskJiraIntegrations` | Existing Jira and Zendesk integrations |
| `integrationEditingType` | `IIntegrationType?` | Sets the active destination (`"jira"` or `"zendesk"`) |
| `testingConnection` | `boolean?` | Renders spinner instead of form when `true` |
| `gitOpsModeEnabled` | `boolean?` | Disables all form fields when GitOps mode is active |

### Internal Logic

- **`validateForm`** — Validates the URL field on blur, enforcing HTTPS protocol
- **`createSubmitData`** — Assembles the full integration array for submission, either splicing in edits or appending new entries for both Jira and Zendesk

## Usage Example

```typescript
<IntegrationForm
  onCancel={() => setShowModal(false)}
  onSubmit={(data, destination) => handleSave(data, destination)}
  integrations={{ jira: existingJiraList, zendesk: existingZendeskList }}
  integrationEditingType="jira"
  integrationEditingUrl="https://mycompany.atlassian.net"
  integrationEditingUsername="admin@mycompany.com"
  integrationEditingProjectKey="OPS"
  testingConnection={isTesting}
  gitOpsModeEnabled={false}
/>
```
