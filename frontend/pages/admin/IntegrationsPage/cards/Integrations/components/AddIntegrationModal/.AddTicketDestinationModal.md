Modal component for adding a new ticket destination integration (Jira or Zendesk) within the Fleet MDM admin settings.

## Key Components

- **`AddTicketDestinationModal`** — Default export. Renders a modal with a destination selector dropdown and an integration configuration form.
- **`destinationOptions`** — Static array defining available ticket destinations (`jira`, `zendesk`).
- **`IAddTicketDestinationModalProps`** — Interface defining required props: `onCancel`, `onSubmit`, `integrations`, and `testingConnection`.

### Dependencies
- **`DropdownWrapper`** — Renders the ticket destination selector; disabled when GitOps mode is active.
- **`IntegrationForm`** — Handles credential/configuration input for the selected destination.
- **`PageDescription` + `CustomLink`** — Displays a link to suggest new destinations (hidden during connection testing).
- **`AppContext`** — Consumed to check if `gitops_mode_enabled` restricts editing.

## Usage Example

```typescript
import AddTicketDestinationModal from "./AddTicketDestinationModal";

<AddTicketDestinationModal
  onCancel={() => setShowModal(false)}
  onSubmit={(integrationData, destination) => {
    handleIntegrationSave(integrationData, destination);
  }}
  integrations={existingIntegrations}
  testingConnection={isTestingConnection}
/>
```

## Behavior Notes

- Defaults to `"jira"` as the selected destination on mount.
- The destination dropdown and suggestion link are hidden while `testingConnection` is `true`.
- GitOps mode (`gitops_mode_enabled`) disables the destination dropdown to prevent manual edits.
