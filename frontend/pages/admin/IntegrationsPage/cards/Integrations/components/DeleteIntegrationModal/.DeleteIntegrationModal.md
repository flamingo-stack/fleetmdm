A confirmation modal component for deleting an integration, displaying the integration's URL and project key before permanently removing it and disabling associated automations.

## Key Components

**`DeleteIntegrationModal`** — Default export. A modal dialog that prompts the user to confirm deletion of a specific integration.

**`IDeleteIntegrationModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|------|------|-------------|
| `url` | `string` | The integration's URL |
| `projectKey` | `string` | The associated project key |
| `onSubmit` | `() => void` | Callback executed on delete confirmation |
| `onCancel` | `() => void` | Callback executed on cancellation |
| `isUpdatingIntegration` | `boolean` | Controls the loading state of the delete button |

## Usage Example

```typescript
import DeleteIntegrationModal from "components/DeleteIntegrationModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);
  const [isUpdating, setIsUpdating] = useState(false);

  const handleDelete = async () => {
    setIsUpdating(true);
    await deleteIntegration();
    setIsUpdating(false);
    setShowModal(false);
  };

  return showModal ? (
    <DeleteIntegrationModal
      url="https://jira.example.com"
      projectKey="ENG"
      onSubmit={handleDelete}
      onCancel={() => setShowModal(false)}
      isUpdatingIntegration={isUpdating}
    />
  ) : null;
};
```

## Behavior Notes

- Renders a `Delete` button (variant: `alert`) with a loading spinner when `isUpdatingIntegration` is `true`
- Supports keyboard confirmation via `onEnter` (Enter key triggers `onSubmit`)
- Warns users that automations using this integration will be disabled upon deletion
