Configures the integrations management table for Jira and Zendesk integrations, defining column structure, data transformation, and action handlers for the admin settings view.

## Key Components

- **`generateTableHeaders(actionSelectHandler)`** — Builds the three-column table definition (type icon, name, actions dropdown) with a callback for row-level action handling.
- **`generateActionDropdownOptions()`** — Returns the available row actions; currently provides a single `"Delete"` option.
- **`enhanceJiraData(jiraIntegrations)`** — Maps raw `IJiraIntegration` records into `IIntegrationTableData` rows, composing a display name from `url` and `project_key`.
- **`enhanceZendeskData(zendeskIntegrations)`** — Maps raw `IZendeskIntegration` records into `IIntegrationTableData` rows, composing a display name from `url` and `group_id`.
- **`combineDataSets(jiraIntegrations, zendeskIntegrations)`** — Merges both enhanced datasets into a single array and assigns a sequential `tableIndex` to each row.
- **`IIntegrationTableData`** — Exported interface extending `IIntegrationCompleteData` with `actions` (dropdown options) and `name` (display string).

## Usage Example

```typescript
import {
  generateTableHeaders,
  combineDataSets,
  IIntegrationTableData,
} from "./IntegrationsTableConfig";

const handleActionSelect = (
  action: string,
  integration: IIntegrationTableData
) => {
  if (action === "delete") {
    deleteIntegration(integration);
  }
};

const columns = generateTableHeaders(handleActionSelect);

const tableData = combineDataSets(jiraIntegrations, zendeskIntegrations);

// Pass columns and tableData to your TableContainer component
<TableContainer columns={columns} data={tableData} />;
```
