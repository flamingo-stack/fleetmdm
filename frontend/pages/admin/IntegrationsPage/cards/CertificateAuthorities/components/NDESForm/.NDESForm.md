A reusable React form component for configuring Network Device Enrollment Service (NDES) integration, collecting SCEP URL, Admin URL, username, and password credentials.

## Key Components

### Interfaces

- **`INDESFormData`** — Shape of the form's data payload: `scepURL`, `adminURL`, `username`, `password`
- **`INDESFormProps`** — Component props including form state, callbacks, and submission control

### Component: `NDESForm`

Renders a controlled form with four `InputField` components and validates input on every change via `validateFormData`. The submit button is disabled until the form is valid, not submitting, and has unsaved changes (`isDirty`). A `TooltipWrapper` surfaces a prompt when required fields are incomplete.

**Props:**

| Prop | Type | Description |
|---|---|---|
| `formData` | `INDESFormData` | Current form field values |
| `submitBtnText` | `string` | Label for the submit button |
| `isSubmitting` | `boolean` | Shows loading state on submit button |
| `isDirty` | `boolean` | Enables submit when form has changes (default: `true`) |
| `onChange` | `(update) => void` | Called on any field change |
| `onSubmit` | `() => void` | Called on valid form submission |
| `onCancel` | `() => void` | Called when the Cancel button is clicked |

## Usage Example

```typescript
import NDESForm, { INDESFormData } from "./NDESForm";

const [formData, setFormData] = useState<INDESFormData>({
  scepURL: "",
  adminURL: "",
  username: "",
  password: "",
});

<NDESForm
  formData={formData}
  submitBtnText="Save"
  isSubmitting={false}
  isDirty={true}
  onChange={({ name, value }) =>
    setFormData((prev) => ({ ...prev, [name]: value }))
  }
  onSubmit={() => console.log("Submitted", formData)}
  onCancel={() => console.log("Cancelled")}
/>
```
