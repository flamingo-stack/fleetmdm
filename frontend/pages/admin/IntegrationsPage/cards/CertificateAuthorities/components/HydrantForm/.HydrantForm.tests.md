Test suite for the `HydrantForm` component, validating submit button states and form validation behavior across multiple scenarios.

## Key Components

- **`createTestFormData`** – Factory helper that generates default `IHydrantFormData` with optional overrides for isolated test setup
- **`HydrantForm` test suite** – Five test cases covering rendering and interactivity of the form

## Test Cases

| Test | Description |
|------|-------------|
| Custom button text | Verifies the submit button renders with the provided `submitBtnText` |
| Form validation gating | Confirms submit is enabled with valid data and disabled when a required field (Name) is cleared |
| `isSubmitting` state | Ensures submit is disabled while a submission is in progress |
| `isDirty={false}` | Validates submit is disabled when the form has no unsaved changes |
| `isDirty={true}` | Validates submit is enabled when the form has unsaved changes |

## Usage Example

```typescript
// Pattern used across tests
const formData = createTestFormData({ name: "Override Name" });

render(
  <HydrantForm
    formData={formData}
    isSubmitting={false}
    submitBtnText="Submit"
    isDirty
    onChange={noop}
    onSubmit={noop}
    onCancel={noop}
  />
);

expect(screen.getByRole("button", { name: "Submit" })).toBeEnabled();
```
