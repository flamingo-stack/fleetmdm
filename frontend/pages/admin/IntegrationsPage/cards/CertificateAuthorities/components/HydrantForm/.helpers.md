Validation helpers for the Hydrant Certificate Authority form, providing form validation configuration generation and form data validation logic.

## Key Components

### Interfaces & Types

- **`IHydrantFormValidation`** — Validation result shape containing per-field `isValid` flags and optional error messages
- **`IFormValidations`** — Record mapping each form field key to an ordered array of validation rules
- **`IValidation`** — Individual validation rule with a name, predicate function, and optional error message

### Exported Functions

- **`generateFormValidations(certAuthorities, isEditing)`** — Builds the field-level validation configuration for the Hydrant CA form. Validates:
  - `name` — required, alphanumeric/underscore characters only, unique among existing Hydrant CAs (skipped when editing)
  - `url` — required, must be a valid URL
  - `clientId` — required
  - `clientSecret` — required

- **`validateFormData(formData, validationConfig)`** — Runs all validations against provided form data. Returns an `IHydrantFormValidation` result; sets `isValid: false` on the top-level result and the failing field if any rule fails. Validations are evaluated in declaration order (first failure wins).

## Usage Example

```typescript
import {
  generateFormValidations,
  validateFormData,
} from "./helpers";

const validations = generateFormValidations(existingCertAuthorities, false);

const result = validateFormData(
  {
    name: "my_hydrant_ca",
    url: "https://hydrant.example.com",
    clientId: "client-123",
    clientSecret: "secret-abc",
  },
  validations
);

if (!result.isValid) {
  console.error("URL error:", result.url?.message);
}
```

> **Note:** Validation order within each field determines which error message is shown — the first failing rule wins.
