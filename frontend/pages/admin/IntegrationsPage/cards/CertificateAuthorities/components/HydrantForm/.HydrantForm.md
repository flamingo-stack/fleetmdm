A React form component for configuring HydrantID certificate authority integrations, handling input validation, change tracking, and submission.

## Key Components

### Interfaces
- **`IHydrantFormData`** — Shape of the form's data: `name`, `url`, `clientId`, `clientSecret`
- **`IHydrantFormProps`** — Component props including `certAuthorities`, `formData`, submit state flags, and event handlers

### Component: `HydrantForm`
Renders a controlled form with four input fields and submit/cancel actions. Validation runs on every input change via `validateFormData` and `generateFormValidations` (from `./helpers`). The submit button is disabled when validation fails, a submission is in progress, or the form is unchanged (`!isDirty`). A tooltip is shown over the submit button when the form is invalid.

## Usage Example

```typescript
const [formData, setFormData] = useState<IHydrantFormData>({
  name: "",
  url: "",
  clientId: "",
  clientSecret: "",
});

const handleChange = ({ name, value }: { name: string; value: string }) => {
  setFormData((prev) => ({ ...prev, [name]: value }));
};

<HydrantForm
  certAuthorities={certAuthorities}
  formData={formData}
  submitBtnText="Save"
  isSubmitting={false}
  isEditing={false}
  isDirty={true}
  onChange={handleChange}
  onSubmit={handleSave}
  onCancel={handleCancel}
/>
```

## Notes

- The `name` field enforces a restricted character set and maps to a Fleet config profile variable suffix (e.g. `$FLEET_VAR_HYDRANT_DATA_WIFI_CERTIFICATE`)
- Validation is generated dynamically based on `certAuthorities` and `isEditing` to support both create and edit flows
