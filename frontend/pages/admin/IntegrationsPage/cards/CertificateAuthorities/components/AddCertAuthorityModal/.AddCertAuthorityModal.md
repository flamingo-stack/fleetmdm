Modal component for adding a new Certificate Authority (CA) integration, supporting multiple CA types via a type-selector dropdown and dynamically rendered form.

## Key Components

- **`AddCertAuthorityModal`** — Main modal component that orchestrates CA type selection and form submission
- **`ICertFormData`** — Union type covering all supported CA form data shapes: `IDigicertFormData`, `IHydrantFormData`, `INDESFormData`, `ICustomSCEPFormData`, `ISmallstepFormData`, `ICustomESTFormData`
- **`onChangeDropdown`** — Switches the active CA type, controlling which form is rendered
- **`onChangeForm`** — Generic field change handler that routes updates to the correct CA-specific form state
- **`onAddCertAuthority`** — Async submit handler that builds the API payload via `generateAddCertAuthorityData` and calls `certificatesAPI.addCertificateAuthority`
- **`renderForm`** — Renders the appropriate CA-specific sub-form (`DigicertForm`, `HydrantForm`, `NDESForm`, `CustomSCEPForm`, `SmallstepForm`, `CustomESTForm`) based on the selected type

## Supported CA Types

| Type | Form Component |
|---|---|
| `digicert` | `DigicertForm` |
| `hydrant` | `HydrantForm` |
| `ndes_scep_proxy` | `NDESForm` |
| `custom_scep_proxy` | `CustomSCEPForm` |
| `smallstep` | `SmallstepForm` |
| `custom_est_proxy` | `CustomESTForm` |

## Usage Example

```typescript
import AddCertAuthorityModal from "./AddCertAuthorityModal";

<AddCertAuthorityModal
  certAuthorities={existingCAs}
  onExit={() => setShowModal(false)}
/>
```

The dropdown automatically disables `ndes_scep_proxy` if one already exists in `certAuthorities`. On successful submission, a flash notification is shown and `onExit` is called to close the modal.
