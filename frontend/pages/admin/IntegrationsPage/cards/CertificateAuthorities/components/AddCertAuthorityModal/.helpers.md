Utility helpers for the Add Certificate Authority modal flow, providing dropdown option generation, API request body construction, and error message mapping for all supported CA types.

## Key Components

### `generateDropdownOptions(hasNDESCert: boolean)`
Returns the list of CA dropdown options, conditionally disabling the NDES option with a tooltip when one already exists.

### `generateAddCertAuthorityData(certAuthorityType, formData)`
Maps a selected `ICertificateAuthorityType` and its typed form data to the `IAddCertAuthorityFormData` shape expected by the API. Handles all six CA types:

| CA Type | Form Interface |
|---|---|
| `ndes_scep_proxy` | `INDESFormData` |
| `digicert` | `IDigicertFormData` |
| `custom_scep_proxy` | `ICustomSCEPFormData` |
| `hydrant` | `IHydrantFormData` |
| `smallstep` | `ISmallstepFormData` |
| `custom_est_proxy` | `ICustomESTFormData` |

### `getDisplayErrMessage(err: unknown)`
Parses an API error reason string and returns a user-friendly `string | JSX.Element`. The PRIVATE_KEY_NOT_CONFIGURED case renders an inline `CustomLink` to Fleet documentation.

### `getErrorMessage(err: unknown)`
Wraps `getDisplayErrMessage` in a full sentence: `"Couldn't add certificate authority. {reason}"`.

## Usage Example

```typescript
import {
  generateDropdownOptions,
  generateAddCertAuthorityData,
  getErrorMessage,
} from "./helpers";

// Build dropdown — disable NDES if already configured
const options = generateDropdownOptions(hasNDESCert);

// Build API payload from form submission
const payload = generateAddCertAuthorityData("digicert", formData);

// Handle API error
try {
  await addCertAuthority(payload);
} catch (err) {
  const message = getErrorMessage(err); // JSX.Element
}
```
