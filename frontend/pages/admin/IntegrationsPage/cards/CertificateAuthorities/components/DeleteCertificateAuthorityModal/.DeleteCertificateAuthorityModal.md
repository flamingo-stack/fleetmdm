A confirmation modal component for deleting a certificate authority (CA) in Fleet MDM, handling the async delete operation with loading state and error/success notifications.

## Key Components

- **`DeleteCertificateAuthorityModal`** — Default export; a modal dialog that prompts the user to confirm deletion of a certificate authority
- **`IDeleteCertificateAuthorityModalProps`** — Interface defining the component's props:
  - `certAuthority: ICertificateAuthorityPartial` — The CA to be deleted (must include `id` and `name`)
  - `onExit: () => void` — Callback invoked on successful deletion or cancellation
- **`onDeleteCertAuthority`** — Async handler that calls `certificatesAPI.deleteCertificateAuthority`, flashes a success or error notification, and calls `onExit` on success. Handles `409` conflict errors by surfacing the API's reason message.

## Usage Example

```typescript
import DeleteCertificateAuthorityModal from "components/DeleteCertificateAuthorityModal";

const ParentComponent = () => {
  const [showModal, setShowModal] = useState(false);
  const selectedCA = { id: 42, name: "My Root CA" };

  return (
    <>
      {showModal && (
        <DeleteCertificateAuthorityModal
          certAuthority={selectedCA}
          onExit={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Displays the CA name in the confirmation message to prevent accidental deletion
- Disables and shows a loading spinner on the **Delete** button while the request is in flight
- On `409` conflict responses, surfaces the API-provided reason; falls back to a generic error message for all other failures
- Does **not** remove certificates from existing hosts — only removes the CA record from Fleet
