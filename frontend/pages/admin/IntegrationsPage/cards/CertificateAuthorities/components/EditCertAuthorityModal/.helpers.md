Utility helpers for the Edit Certificate Authority modal, providing form data initialization, change detection, and API payload construction across all supported CA types.

## Key Components

### `generateDefaultFormData(certAuthority)`
Maps an existing `ICertificateAuthority` entity to its corresponding form data shape (`ICertFormData`). Supports all CA types: `ndes_scep_proxy`, `digicert`, `hydrant`, `smallstep`, `custom_scep_proxy`, and `custom_est_proxy`.

### `generateEditCertAuthorityData(certAuthority, formData)`
Builds the `IEditCertAuthorityFormData` API payload by diffing current form values against the original CA data using `deepDifference`. For `custom_est_proxy`, ensures credentials are always included when the URL changes.

### `updateFormData(certAuthority, prevFormData, update)`
Handles field-level change logic, automatically clearing sensitive fields (passwords, tokens, secrets) when dependent fields are modified — but only if those fields still hold the API's unchanged-password sentinel value (`UNCHANGED_PASSWORD_API_RESPONSE`).

### `getErrorMessage(err)`
Returns a JSX error message element for display when editing a certificate authority fails.

## Usage Example

```typescript
// Populate form with existing CA data
const defaultData = generateDefaultFormData(certAuthority);

// React to a field change, clearing stale secrets as needed
const updated = updateFormData(certAuthority, currentFormData, {
  name: "url",
  value: "https://new-scep.example.com",
});

// Build minimal API diff payload before submitting
const editPayload = generateEditCertAuthorityData(certAuthority, updated);
await editCertAuthority(certAuthority.id, editPayload);
```
