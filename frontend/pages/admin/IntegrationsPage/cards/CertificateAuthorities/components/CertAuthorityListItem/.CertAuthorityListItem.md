Renders a single certificate authority entry in a list, displaying the certificate's name, description, and action buttons for editing and deleting.

## Key Components

- **`CertAuthorityListItem`** — Main export; wraps `ListItem` with certificate data and action handlers
- **`Actions`** — Internal component rendering edit (pencil) and delete (trash) icon buttons, each wrapped in `GitOpsModeTooltipWrapper` to disable interactions in GitOps mode
- **`ICertAuthorityListItemProps`** — Props interface accepting a `cert` object, `onClickEdit`, and `onClickDelete` callbacks
- **`IActionsProps`** — Props interface for the internal `Actions` component

## Usage Example

```typescript
import CertAuthorityListItem from "components/CertAuthorityListItem";

<CertAuthorityListItem
  cert={{
    name: "My Root CA",
    description: "Internal root certificate authority",
  }}
  onClickEdit={() => handleEdit(cert.id)}
  onClickDelete={() => handleDelete(cert.id)}
/>
```

## Notes

- Edit and delete buttons are automatically disabled in GitOps mode via `GitOpsModeTooltipWrapper`
- The `graphic` prop renders a `file-certificate` icon alongside the list entry
- Relies on `ICertAuthorityListData` from [`CertificateAuthorityList`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/CertificateAuthorityList/CertificateAuthorityList.tsx) for the certificate data shape
