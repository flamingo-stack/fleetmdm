A React form component for creating and editing custom EST (Enrollment over Secure Transport) certificate authority configurations.

## Key Components

### `ICustomESTFormData`
Interface defining the form's data shape:
- `name` — identifier (letters, numbers, underscores)
- `url` — EST endpoint URL
- `username` / `password` — authentication credentials

### `ICustomESTFormProps`
Props interface supporting:
- `formData` — current field values
- `certAuthorities` — existing CAs used for uniqueness validation
- `isEditing` — toggles edit vs. create validation rules
- `isDirty` — controls submit button availability
- `onChange` / `onSubmit` / `onCancel` — event handlers

### `CustomESTForm`
The default export. Renders four `InputField` components with inline validation errors and a submit/cancel button pair. Submit is disabled until all validations pass and the form is dirty.

**Validation** is derived via `generateFormValidations` and `validateFormData` (from `./helpers`), both memoized to avoid unnecessary recomputation on every render.
