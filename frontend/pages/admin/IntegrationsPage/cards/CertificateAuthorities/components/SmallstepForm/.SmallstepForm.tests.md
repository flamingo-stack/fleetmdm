Test suite for the `SmallstepForm` component, validating submit button state management based on form validity, submission status, and dirty state.

## Key Components

- **`createTestFormData`** — Factory helper that generates valid `ISmallstepFormData` with sensible defaults, accepting partial overrides for targeted test scenarios.
- **`SmallstepForm` test suite** — Six test cases covering rendering and submit button enable/disable logic.

## Test Cases

| Test | Description |
|------|-------------|
| Custom button text | Verifies `submitBtnText` prop renders correctly |
| Valid form enables submit | Submit enabled when all required fields are populated |
| Invalid form disables submit | Submit disabled when `name` is empty string |
| `isSubmitting` disables submit | Submit disabled while a submission is in progress |
| `isDirty={false}` disables submit | Submit disabled when form has no unsaved changes |
| `isDirty={true}` enables submit | Submit enabled when form has unsaved changes |

## Usage Example

```typescript
// Minimal render for SmallstepForm in tests
render(
  <SmallstepForm
    formData={createTestFormData({ name: "" })} // invalid
    isSubmitting={false}
    submitBtnText="Save"
    isDirty
    onChange={noop}
    onSubmit={noop}
    onCancel={noop}
  />
);

expect(screen.getByRole("button", { name: "Save" })).toBeDisabled();
```
