A React form component for configuring Smallstep SCEP (Simple Certificate Enrollment Protocol) certificate authority integration, handling credential input with validation and submission controls.

## Key Components

### `ISmallstepFormData`
Interface defining the form's data shape:
- `name` — Certificate authority identifier (used as Fleet variable suffix)
- `scepURL` — Smallstep SCEP endpoint URL
- `challengeURL` — Smallstep SCEP Challenge URL
- `username` — Challenge Basic Authentication Username
- `password` — Challenge Basic Authentication Password

### `ISmallstepFormProps`
Component props interface supporting:
- `certAuthorities` — Existing CAs for uniqueness validation
- `isEditing` — Toggles edit vs. create validation rules
- `isDirty` — Controls submit button availability when no changes detected
- `onChange` / `onSubmit` / `onCancel` — Event handlers

### `SmallstepForm`
Main form component using `useMemo` to derive validation config and results on each render cycle, preventing unnecessary recomputation when unrelated state changes.

## Usage Example

```typescript
import SmallstepForm, { ISmallstepFormData } from "./SmallstepForm";

const [formData, setFormData] = useState<ISmallstepFormData>({
  name: "",
  scepURL: "",
  challengeURL: "",
  username: "",
  password: "",
});

<SmallstepForm
  certAuthorities={existingCAs}
  formData={formData}
  submitBtnText="Save"
  isSubmitting={false}
  isEditing={false}
  isDirty={isDirty}
  onChange={({ name, value }) =>
    setFormData((prev) => ({ ...prev, [name]: value }))
  }
  onSubmit={handleSubmit}
  onCancel={handleCancel}
/>
```

The submit button is disabled and displays a tooltip (`"Complete all required fields to save."`) when validation fails, preventing incomplete form submission.
