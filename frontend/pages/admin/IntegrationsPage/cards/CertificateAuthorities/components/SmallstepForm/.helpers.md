Validation helpers for the Smallstep SCEP CA integration form, providing field-level validation rules and form data validation logic.

## Key Components

### Interfaces

- **`ISmallstepFormValidation`** — Shape of the validation result object, containing an overall `isValid` flag and per-field validity states with optional error messages.

### Functions

- **`generateFormValidations(smallstepIntegrations, isEditing)`** — Builds the `FORM_VALIDATIONS` config object containing validation rules for all form fields (`name`, `scepURL`, `challengeURL`, `username`, `password`). Accepts the existing integrations list to enforce name uniqueness, and an `isEditing` flag to skip the uniqueness check on edit.
- **`validateFormData(formData, validationConfig)`** — Runs all validation rules against the provided form data. Returns an `ISmallstepFormValidation` result with per-field pass/fail state and error messages.

### Validation Rules by Field

| Field | Rules |
|---|---|
| `name` | Required, alphanumeric + underscores only, unique across existing integrations |
| `scepURL` | Required, valid URL format |
| `challengeURL` | Required, valid URL format |
| `username` | Required |
| `password` | Required |

## Usage Example

```typescript
import {
  generateFormValidations,
  validateFormData,
} from "./helpers";

const validationConfig = generateFormValidations(
  existingIntegrations,
  false // isEditing
);

const result = validateFormData(formData, validationConfig);

if (!result.isValid) {
  console.error(result.name?.message);      // e.g. "Name is already used by another custom SCEP CA."
  console.error(result.scepURL?.message);   // e.g. "Must be a valid URL."
}
```
