Validation helpers for the Custom SCEP CA form, providing form field validation logic and error message resolution for the `name`, `scepURL`, and `challenge` fields.

## Key Components

- **`ICustomSCEPFormValidation`** — Interface describing the validation result shape, with per-field `isValid` flags and optional error messages.
- **`generateFormValidations`** — Factory that builds the `FORM_VALIDATIONS` config object. Accepts existing certificate authorities and an `isEditing` flag to apply context-aware rules (e.g., skipping uniqueness checks on edit).
- **`validateFormData`** — Iterates the validation config against provided form data, returning a populated `ICustomSCEPFormValidation` result.
- **`PRINTABLE_STRING_REGEX`** — Restricts challenge passwords to ASN.1 PrintableString characters, matching server-side enforcement in `certificate_authorities.go`.

### Validation Rules per Field

| Field | Rules |
|---|---|
| `name` | Required; alphanumeric + underscores only; unique among existing custom SCEP CAs |
| `scepURL` | Required; must pass `valid_url` check |
| `challenge` | Required; must match PrintableString charset (bypassed for unchanged/masked values) |

## Usage Example

```typescript
import {
  generateFormValidations,
  validateFormData,
} from "./helpers";

const validationConfig = generateFormValidations(existingCertAuthorities, false);

const result = validateFormData(
  { name: "my_ca", scepURL: "https://scep.example.com", challenge: "abc123" },
  validationConfig
);

if (!result.isValid) {
  console.error(result.name?.message);      // e.g. "Name is already used by another custom SCEP CA."
  console.error(result.scepURL?.message);   // e.g. "Must be a valid URL."
  console.error(result.challenge?.message); // e.g. "Invalid characters. ..."
}
```
