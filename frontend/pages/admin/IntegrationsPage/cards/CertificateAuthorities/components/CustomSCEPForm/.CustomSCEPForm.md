Form component for configuring a custom SCEP (Simple Certificate Enrollment Protocol) certificate authority, handling input validation and submission for SCEP server integration.

## Key Components

**`ICustomSCEPFormData`** — Exported interface defining the form's data shape:
- `name` — Identifier used as a suffix for Fleet configuration profile variables
- `scepURL` — SCEP server endpoint URL
- `challenge` — Password for SCEP server authentication (rendered as a password field)

**`ICustomSCEPFormProps`** — Component props interface supporting controlled form behavior with optional editing and dirty-state tracking.

**`CustomSCEPForm`** — Default export; a controlled React form component that:
- Derives field-level validations via `generateFormValidations` (memoized against `certAuthorities` and `isEditing`)
- Tracks per-field validation state with `useState`, re-validated on every input change
- Disables the submit button when the form is invalid, currently submitting, or unchanged (`!isDirty`)
- Wraps the submit button in a `TooltipWrapper` that surfaces a hint when validation fails

## Usage Example

```typescript
import CustomSCEPForm, { ICustomSCEPFormData } from "./CustomSCEPForm";

const [formData, setFormData] = useState<ICustomSCEPFormData>({
  name: "",
  scepURL: "",
  challenge: "",
});

<CustomSCEPForm
  certAuthorities={existingCAs}
  formData={formData}
  submitBtnText="Save"
  isSubmitting={false}
  isEditing={false}
  isDirty={true}
  onChange={({ name, value }) =>
    setFormData((prev) => ({ ...prev, [name]: value }))
  }
  onSubmit={() => console.log("Submitted", formData)}
  onCancel={() => console.log("Cancelled")}
/>
```

## Notes

- The `name` field enforces a specific character set (letters, numbers, underscores) to ensure compatibility with Fleet's `$FLEET_VAR_CUSTOM_SCEP_CHALLENGE_<NAME>` variable convention.
- Validation logic is externalized to `./helpers` (`generateFormValidations`, `validateFormData`) for testability.
