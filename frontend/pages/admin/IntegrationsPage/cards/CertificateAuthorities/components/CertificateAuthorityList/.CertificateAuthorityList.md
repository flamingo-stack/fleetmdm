Renders a managed list of certificate authorities (CAs) using a reusable `UploadList` layout, with support for adding, editing, and deleting CA entries.

## Key Components

- **`ICertAuthorityListData`** — Extended type combining `ICertificateAuthorityPartial` with a `description` field for display purposes.
- **`generateListData`** — Pure function that maps raw CA data to `ICertAuthorityListData` by appending a human-readable description via `CA_LABEL_BY_TYPE`.
- **`CertificateAuthorityList`** — Default export. Composes `UploadList` with `CertAuthorityListHeader` and `CertAuthorityListItem` to render the full CA list UI.

## Props

| Prop | Type | Description |
|---|---|---|
| `certAuthorities` | `ICertificateAuthorityPartial[]` | Array of CA records to display |
| `onAddCertAuthority` | `() => void` | Callback to trigger the add CA flow |
| `onClickEdit` | `(cert) => void` | Callback fired when a CA's edit action is selected |
| `onClickDelete` | `(cert) => void` | Callback fired when a CA's delete action is selected |

## Usage Example

```typescript
import CertificateAuthorityList, {
  generateListData,
} from "./CertificateAuthorityList";

<CertificateAuthorityList
  certAuthorities={certAuthorities}
  onAddCertAuthority={() => setShowAddModal(true)}
  onClickEdit={(cert) => setEditTarget(cert)}
  onClickDelete={(cert) => setDeleteTarget(cert)}
/>

// Standalone data transformation
const listData = generateListData(certAuthorities);
// listData[0].description === "DigiCert" (resolved via CA_LABEL_BY_TYPE)
```

> List data is memoized via `useMemo`, so `generateListData` only re-runs when `certAuthorities` changes.
