Header component for the Certificate Authority list section, rendering the section title and an "Add CA" action button with GitOps mode awareness.

## Key Components

- **`CertAuthorityListHeader`** — Default export. A presentational component that displays the "Certificate authority (CA)" label alongside an "Add CA" button.
- **`ICertAuthorityListHeaderProps`** — Props interface with a single `onClickAddCertAuthority` callback, invoked when the user clicks the add button.
- **`GitOpsModeTooltipWrapper`** — Wraps the add button to automatically disable it and show a tooltip when GitOps mode is active.

## Usage Example

```typescript
import CertAuthorityListHeader from "components/CertAuthorityListHeader";

const CertAuthorityPage = () => {
  const handleAddCA = () => {
    // Open modal or navigate to add CA form
  };

  return (
    <div>
      <CertAuthorityListHeader onClickAddCertAuthority={handleAddCA} />
      {/* CA list items below */}
    </div>
  );
};
```

## Notes

- The button is automatically disabled when GitOps mode is enabled via `GitOpsModeTooltipWrapper`, preventing manual CA management in GitOps-controlled environments.
- The `iconStroke` prop on `Button` enables stroke styling on the `plus` icon for visual consistency.
- BEM-style CSS classes are scoped under `cert-authority-list-header`.
