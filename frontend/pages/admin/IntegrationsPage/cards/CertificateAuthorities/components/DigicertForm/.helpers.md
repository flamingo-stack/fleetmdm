Form validation helpers for the DigiCert Certificate Authority configuration form, providing validation rule generation and form data validation utilities.

## Key Components

### Interfaces

- **`IDigicertFormValidation`** — Validation result shape containing a top-level `isValid` flag and per-field validation state (with optional error messages) for: `name`, `url`, `apiToken`, `profileId`, `commonName`, and `certificateSeatId`.

### Exported Functions

- **`generateFormValidations(certAuthorities, isEditing)`** — Builds the full validation rule set (`IFormValidations`) for the DigiCert form. Rules include:
  - `name`: required, alphanumeric/underscore-only characters, and uniqueness among existing DigiCert CAs (skipped when editing)
  - `url`: required and valid URL format
  - `apiToken`, `profileId`, `commonName`, `certificateSeatId`: required (non-empty)

- **`validateFormData(formData, validationConfig)`** — Runs form data against a given validation config. Returns an `IDigicertFormValidation` object; sets `isValid: false` on the first failing rule per field and attaches the corresponding error message.

## Usage Example

```typescript
import {
  generateFormValidations,
  validateFormData,
} from "./helpers";

const validations = generateFormValidations(existingCertAuthorities, false);

const result = validateFormData(formData, validations);

if (!result.isValid) {
  if (!result.name?.isValid) {
    console.error(result.name?.message);
    // e.g. "Name is already used by another DigiCert CA."
  }
  if (!result.url?.isValid) {
    console.error(result.url?.message);
    // e.g. "Must be a valid URL."
  }
}
```

## Notes

- Error messages can be static strings or dynamic functions `(formData) => string`, resolved at validation time via the internal `getErrorMessage` helper.
