Test suite for the `DigicertForm` component, validating submit button behavior, form validation state, and dirty/submitting prop interactions.

## Key Components

- **`createTestFormData`** — Factory helper that generates a complete `IDigicertFormData` object with sensible defaults, accepting partial overrides for targeted test scenarios.
- **`DigicertForm` test suite** — Five test cases covering:
  - Custom submit button text rendering
  - Form validation enabling/disabling submission
  - Disabled state when `isSubmitting` is `true`
  - Disabled state when `isDirty` is `false`
  - Enabled state when `isDirty` is `true`

## Usage Example

```typescript
// Run specific tests in this suite
// From project root:
// npx jest DigicertForm.tests.tsx

// Example: extending test data factory for edge cases
const testData = createTestFormData({
  name: "",           // triggers validation failure → submit disabled
  apiToken: "custom-token",
});
```

## Test Behaviors

| Scenario | Expected Submit State |
|---|---|
| Valid form data | Enabled |
| Name field cleared | Disabled |
| `isSubmitting={true}` | Disabled |
| `isDirty={false}` | Disabled |
| `isDirty={true}` | Enabled |

## Dependencies

- [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) — DOM rendering and queries
- `renderWithSetup` from `test/test-utils` — Provides `user` event simulation for interaction-based tests
- [`lodash/noop`](https://lodash.com/docs/#noop) — Stub for required `onChange`, `onSubmit`, and `onCancel` callbacks
