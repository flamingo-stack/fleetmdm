A React form component for configuring DigiCert ONE certificate authority integrations, handling input validation and submission for certificate profile settings.

## Key Components

### `IDigicertFormData`
Interface defining the form's data shape:
- `name` — Integration name (used as Fleet config profile variable suffix)
- `url` — DigiCert ONE instance URL
- `apiToken` — DigiCert ONE API token (password field)
- `profileId` — Certificate profile GUID
- `commonName` — Certificate CN for delivered certificates
- `userPrincipalName` — Optional UPN for Subject Alternative Name (SAN)
- `certificateSeatId` — DigiCert seat ID assignment

### `IDigicertFormProps`
Props interface controlling form behavior, including `isEditing`, `isDirty`, and callbacks for `onChange`, `onSubmit`, and `onCancel`.

### `DigicertForm` (default export)
The form component. Validates all fields on each input change using `validateFormData` and `generateFormValidations` helpers, disabling the submit button until the form is valid and dirty.

import DigicertForm, { IDigicertFormData } from "./DigicertForm";

const [formData, setFormData] = useState<IDigicertFormData>({
  name: "",
  url: "",
  apiToken: "",
  profileId: "",
  commonName: "$FLEET_VAR_HOST_HARDWARE_SERIAL",
  userPrincipalName: "",
  certificateSeatId: "",
});

## Notes

- Submit is disabled when `!formValidation.isValid`, `isSubmitting`, or `!isDirty`
- A tooltip (`"Complete all required fields to save."`) surfaces when the form is invalid
- Validations are regenerated via `useMemo` when `certAuthorities` or `isEditing` changes
