Maps each `ICertificateAuthorityType` enum value to its corresponding human-readable display label for use in UI components.

## Key Components

- **`CA_LABEL_BY_TYPE`** — A `Record` mapping every `ICertificateAuthorityType` to a descriptive label string. Supported CA types include:
  - `custom_est_proxy` — Custom Enrollment Over Secure Transport (EST)
  - `custom_scep_proxy` — Custom Simple Certificate Enrollment Protocol (SCEP)
  - `digicert` — DigiCert
  - `hydrant` — Hydrant Enrollment Over Secure Transport (EST)
  - `ndes_scep_proxy` — Dynamic SCEP (Okta CA / Microsoft NDES)
  - `smallstep` — Smallstep

## Usage Example

```typescript
import CA_LABEL_BY_TYPE from "./helpers";

const caType: ICertificateAuthorityType = "digicert";
const displayLabel = CA_LABEL_BY_TYPE[caType];
// → "DigiCert"

// Render in a dropdown or list
const options = Object.entries(CA_LABEL_BY_TYPE).map(([value, label]) => ({
  value,
  label,
}));
```

## Notes

- The `Record<ICertificateAuthorityType, string>` type ensures exhaustive coverage — adding a new CA type to `ICertificateAuthorityType` will produce a compile-time error until a label is added here.
