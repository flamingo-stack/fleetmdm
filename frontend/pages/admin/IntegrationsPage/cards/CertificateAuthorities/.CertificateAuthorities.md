Settings page component for managing Certificate Authorities (CAs), supporting add, edit, and delete operations with premium tier gating.

## Key Components

- **`CertificateAuthorities`** — Main page component rendered under the admin settings section
- **`useQuery("certAuthorities")`** — Fetches the list of CAs via `certificatesAPI.getCertificateAuthoritiesList()`
- **Modal state management** — Controls visibility of `AddCertAuthorityModal`, `EditCertAuthorityModal`, and `DeleteCertificateAuthorityModal`
- **`renderContent()`** — Conditionally renders premium gate, spinner, error, empty state, or the CA list

## Key Behaviors

| State | Rendered Output |
|---|---|
| Non-premium tier | `PremiumFeatureMessage` |
| Loading | `Spinner` |
| Error | `DataError` |
| No CAs | `EmptyState` with "Add certificate authority" button |
| CAs exist | `CertificateAuthorityList` with edit/delete actions |

## Usage Example

```typescript
// Rendered as part of the admin settings routing.
// No props required — all data is fetched internally.

import CertificateAuthorities from "./CertificateAuthorities";

const AdminSettingsPage = () => (
  <CertificateAuthorities />
);
```

## Event Flow

```text
Add:    onAddCertAuthority → modal → onAddedNewCertAuthority → refetch
Edit:   onEditCertAuthority(cert) → modal → onEditedCertAuthority → refetch
Delete: onDeleteCertAuthority(cert) → modal → onDeletedCertAuthority → refetch
```
