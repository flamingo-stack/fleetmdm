Renders the Identity Provider (IdP) settings section, displaying SCIM connection status — including success, error, or unconfigured states — based on the latest IdP request details fetched from the API.

## Key Components

### Sub-components

| Component | Purpose |
|---|---|
| `AddEndUserInfoCard` | Empty state shown when no IdP is connected; links to setup documentation |
| `ReceivedEndUserInfoCard` | Success state showing when IdP info was last received, with a relative timestamp tooltip |
| `FailedEndUserInfoCard` | Error state showing failure details via tooltip and a troubleshooting link |

### Main Export

**`IdentityProviderSection`** — Orchestrates the section by:
- Gating content behind `isPremiumTier` from `AppContext`
- Fetching SCIM details via `idpAPI.getSCIMDetails()` using `react-query`
- Rendering the appropriate card based on `last_request` status (`null`, `"success"`, or `"error"`)

## Usage Example

```typescript
// Rendered as part of the MDM/admin settings page
import IdentityProviderSection from "./IdentityProviderSection";

const IntegrationsSettingsPage = () => (
  <div>
    <IdentityProviderSection />
  </div>
);
```

## Rendering Logic

```text
isPremiumTier = false  →  <PremiumFeatureMessage />
isLoading              →  <Spinner />
isError                →  <DataError />
last_request = null    →  <AddEndUserInfoCard />
status = "success"     →  <ReceivedEndUserInfoCard receivedAt={...} />
status = "error"       →  <FailedEndUserInfoCard receivedAt={...} details={...} />
```
