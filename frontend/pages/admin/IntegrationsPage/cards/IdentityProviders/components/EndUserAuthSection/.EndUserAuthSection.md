Renders the End User Authentication configuration section for MDM settings, allowing admins to configure SAML/IdP integration for device enrollment authentication.

## Key Components

### `EndUserAuthSection`
The primary exported component that renders a form for configuring Identity Provider (IdP) settings used in MDM end user authentication.

**Props (`IEndUserAuthSectionProps`):**
| Prop | Type | Description |
|---|---|---|
| `formData` | `IFormDataIdp` | Current IdP form field values |
| `setFormData` | `Dispatch<SetStateAction<IFormDataIdp>>` | Form state updater |
| `originalFormData` | `MutableRefObject<IFormDataIdp>` | Ref tracking last-saved form state for dirty detection |
| `setDirty` | `(dirty: boolean) => void` | Notifies parent of unsaved changes |
| `onSubmit` | `() => void` | Callback to notify parent after a successful save |

### Form Fields
- **Identity Provider Name** — Human-readable IdP label
- **Entity ID** — URI identifying Fleet to the IdP (e.g., Okta Audience Restriction)
- **Metadata URL** — Takes precedence over raw Metadata when both are provided
- **Metadata** — Raw XML fallback for IdP metadata

### Validation & Save Logic
- Validates on blur and on input change using `validateFormDataIdp`
- Trims whitespace before submission via `trimFormDataIdp`
- Enables Save only when all required fields are populated and no errors exist, or when the form is fully cleared
- Calls `configAPI.update` directly (bypasses the common config handler) and flashes success/error notifications

## Usage Example

```typescript
<EndUserAuthSection
  formData={idpFormData}
  setFormData={setIdpFormData}
  originalFormData={originalIdpFormData}
  setDirty={setIsDirty}
  onSubmit={handleConfigRefresh}
/>
```

> **Note:** Renders a `PremiumFeatureMessage` for non-premium tiers. The form inputs are disabled when GitOps mode is active.
