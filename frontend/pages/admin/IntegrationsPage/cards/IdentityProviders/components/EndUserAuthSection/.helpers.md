Utility helpers for managing and validating Identity Provider (IdP) SAML configuration form data, including field validation, error messaging, and form state checks.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IFormDataIdp` | Interface | Shape of the IdP form with `idp_name`, `entity_id`, `metadata_url`, and `metadata` fields |
| `IFormErrorsIdp` | Type | Partial record mapping `IFormDataIdp` keys to error message strings |
| `newFormDataIdp` | Function | Creates a trimmed `IFormDataIdp` object from an optional `IEndUserAuthentication` config |
| `isEmptyFormData` | Function | Returns `true` if all IdP form fields are empty |
| `isMissingAnyRequiredField` | Function | Returns `true` if any required field (`idp_name`, `entity_id`, or metadata) is absent |
| `trimFormDataIdp` | Function | Returns a new `IFormDataIdp` with all string fields trimmed |
| `validateFormDataIdp` | Function | Runs all field validators and returns `IFormErrorsIdp` or `null` if no errors |

## Usage Example

```typescript
import {
  newFormDataIdp,
  trimFormDataIdp,
  validateFormDataIdp,
  isMissingAnyRequiredField,
} from "./helpers";

// Initialize form from existing config
const formData = newFormDataIdp(existingConfig);

// Trim before submission
const trimmed = trimFormDataIdp(formData);

// Guard against incomplete submissions
if (isMissingAnyRequiredField(trimmed)) {
  console.warn("Required IdP fields are missing.");
}

// Validate and collect field-level errors
const errors = validateFormDataIdp(trimmed);
if (errors) {
  // e.g. { metadata_url: "Metadata URL is not a valid URL." }
  console.error("Form validation failed:", errors);
}
```

## Validation Rules

- **`idp_name`** — must be non-empty
- **`entity_id`** — must be non-empty
- **`metadata_url`** — must be a valid URL starting with `http://` or `https://` (when provided)
- **`metadata`** — either `metadata` or `metadata_url` must be present; both fields share a cross-dependency check
