React page component that renders the Identity Providers settings section within a scoped CSS class wrapper.

## Key Components

- **`IdentityProviders`** — Default export; a functional component that wraps `IdentityProviderSection` inside a `div` with the `identity-providers` CSS class.
- **`IdentityProviderSection`** — Child component (from `./components/IdentityProviderSection`) containing the actual identity provider configuration UI.

## Usage Example

```typescript
import IdentityProviders from "./IdentityProviders";

// Render within a settings route or page layout
const SettingsPage = () => (
  <IdentityProviders />
);
```
