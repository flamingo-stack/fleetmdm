Renders the Google Calendar integration settings form within the Fleet admin panel, allowing administrators to configure a Google service account (API key JSON and primary domain) for calendar-based policy scheduling.

## Key Components

- **`Calendars`** — Main functional component accepting `IAppConfigFormProps`; gated behind a premium tier check
- **`isObfuscatedApiKey`** — Utility that detects whether the stored API key JSON has been masked by the backend (`"********"` values)
- **`validateForm`** — Validates that API key JSON and domain are either both set or both empty, and that the JSON is parseable
- **`onInputChange`** — Controlled input handler with inline validation on each keystroke
- **`onFormSubmit`** — Submits the integration update via `configAPI.update`, handles the masked-password passthrough case, and invalidates the React Query `"config"` cache on success

## Usage Example

```typescript
// Rendered inside the Integrations settings page
import Calendars from "pages/admin/IntegrationsPage/cards/Calendars/Calendars";

<Calendars appConfig={appConfig} />
```

The component reads from `appConfig.integrations.google_calendar[0]` on mount and writes back via `PATCH /api/latest/fleet/config`. If the existing API key is obfuscated (all fields equal `UNCHANGED_PASSWORD_API_RESPONSE`), the masked sentinel is displayed as help text and the unchanged value is excluded from the PATCH payload, preserving the backend secret.
