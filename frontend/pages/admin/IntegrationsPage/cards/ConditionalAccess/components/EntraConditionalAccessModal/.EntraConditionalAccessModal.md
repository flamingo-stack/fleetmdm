A modal component for configuring Microsoft Entra conditional access integration by collecting and validating a Microsoft Entra Tenant ID, then triggering the Microsoft authentication flow.

## Key Components

- **`EntraConditionalAccessModal`** — Default export; a controlled form modal wrapping `Modal`, `InputField`, and `Button` components
- **`validate(formData)`** — Validates that the `microsoft_entra_tenant_id` field is non-empty; returns an `IFormErrors` map
- **`IEntraConditionalAccessModalProps`** — Props interface exposing `onCancel` and `onSuccess` callbacks
- **`onSubmit`** — Async handler that calls `conditionalAccessAPI.triggerMicrosoftConditionalAccess`, opens the returned Microsoft auth URL in a new tab, and invokes `onSuccess`
- **`onInputChange` / `onInputBlur`** — Handlers for live field updates and blur-time validation respectively

## Usage Example

```typescript
import EntraConditionalAccessModal from "components/EntraConditionalAccessModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      {showModal && (
        <EntraConditionalAccessModal
          onCancel={() => setShowModal(false)}
          onSuccess={() => {
            setShowModal(false);
            // Show success banner or refresh integration state
          }}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- Validation runs on blur and on submit; the **Save** button is disabled while `formErrors` is non-empty
- On success, `window.open(msAuthURL)` opens the Microsoft OAuth consent screen in a new tab before closing the modal
- On API failure, a flash error notification is rendered via `NotificationContext`
- Links to the Entra conditional access setup guide via `LEARN_MORE_ABOUT_BASE_LINK/entra-conditional-access`
