Integration test suite for the `ConditionalAccess` React component, covering unconfigured, in-progress, and fully configured states for both Microsoft Entra and Okta conditional access providers.

## Key Components

- **`triggerConditionalAccessHandler`** — MSW handler mocking the `POST /conditional-access/microsoft` endpoint, returning a mock Microsoft authentication URL.
- **`updateConfigHandler`** — MSW handler mocking `PATCH /config`, returning a config with Okta fields populated.
- **`createEmptyConditionalAccessConfig`** — Helper factory producing a `mockConfig` with all conditional access fields blank.
- **Test suites:**
  - `Not configured` — Validates rendering of both provider cards, modal open/close behavior, Entra auth flow initiation, and Okta form submission with file upload.
  - `Confirming configured` — Validates spinner display when Entra tenant ID exists but connection is not yet confirmed.
  - `Configured` — Validates connected state UI (tooltips showing tenant/IDP ID, Delete button presence) for Entra, Okta, and both simultaneously.

## Usage Example

```typescript
// Run all ConditionalAccess tests
// From repo root:
// npx jest ConditionalAccess.tests.tsx

// Example: adding a new test case
it("Shows error when Entra modal submission fails", async () => {
  mockServer.use(
    http.post(baseUrl("/conditional-access/microsoft"), () => {
      return HttpResponse.error();
    })
  );

  const render = createCustomRenderer({
    withBackendMock: true,
    context: { app: { isPremiumTier: true, config: createEmptyConditionalAccessConfig() } },
  });

  const { user } = render(<ConditionalAccess />);
  const connectButtons = screen.getAllByText("Connect");
  await user.click(connectButtons[1]);

  const input = screen.getByRole("textbox");
  await user.type(input, "tenant-id");
  await user.click(screen.getByRole("button", { name: "Save" }));

  await waitFor(() => {
    expect(screen.getByText(/error/i)).toBeInTheDocument();
  });
});
```
