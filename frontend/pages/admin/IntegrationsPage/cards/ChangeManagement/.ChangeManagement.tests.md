Integration test suite for the `ChangeManagement` component, verifying GitOps configuration UI behavior including checkbox state, URL field interactions, form validation, and API submission.

## Key Components

- **`createGetConfigHandler`** — MSW handler factory that intercepts `GET /config` and returns a mock config with optional GitOps overrides
- **`createPatchConfigHandler`** — MSW handler factory that intercepts `PATCH /config`, captures the request body via a Jest spy, and echoes back a merged config response
- **Test suites:**
  - `GitOps mode checkbox` — verifies checkbox reflects `gitops_mode_enabled` from the API
  - `GitOps URL field` — verifies URL population, enabled/disabled state based on GitOps mode
  - `Form validation` — verifies error message when saving with GitOps enabled but no URL provided
  - `Exception checkboxes` — verifies `labels`, `software`, and `secrets` exception toggles reflect API state
  - `Form submission` — verifies correct payload shape is sent to `PATCH /config` after user interaction

## Usage Example

```typescript
// Running the tests
// From the repo root:
// npx jest ChangeManagement.tests.tsx

// Example: adding a new submission test
it("sends updated gitops_mode_enabled to API", async () => {
  const patchSpy = jest.fn();
  mockServer.use(
    createGetConfigHandler({
      gitops: {
        gitops_mode_enabled: false,
        repository_url: "",
        exceptions: { labels: false, software: false, secrets: false },
      },
    }),
    createPatchConfigHandler(patchSpy)
  );

  const { user } = render(<ChangeManagement />);

  const checkbox = await screen.findByRole("checkbox", { name: "gitOpsModeEnabled" });
  await user.click(checkbox);
  await user.click(screen.getByRole("button", { name: /save/i }));

  await waitFor(() => {
    expect(patchSpy).toHaveBeenCalledWith(
      expect.objectContaining({
        gitops: expect.objectContaining({ gitops_mode_enabled: true }),
      })
    );
  });
});
```

The suite uses `createCustomRenderer` with `isPremiumTier: true` context and MSW via `mockServer.use(...)` scoped per test, with `jest.clearAllMocks()` in `beforeEach` to prevent state leakage between cases.
