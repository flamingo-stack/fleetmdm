React form component for configuring the global host status webhook in Fleet MDM admin settings. Allows administrators to enable webhook alerts when a configured percentage of hosts go offline for a specified number of days.

## Key Components

### Interfaces
- **`IGlobalHostStatusWebhookFormData`** — Form state shape: enable toggle, destination URL, host percentage threshold, and time window
- **`IGlobalHostStatusWebhookFormErrors`** — Validation error state for the destination URL field

### Core Logic
- **`onInputChange`** — Generic field change handler using `IInputFieldParseTarget`; clears errors on change
- **`validateForm`** — Validates destination URL presence and format when webhook is enabled; runs on mount and `enableHostStatusWebhook` toggle via `useEffect`
- **`onFormSubmit`** — Formats form state into the Fleet API `webhook_settings` payload structure and calls `handleSubmit`
- **`percentageHostsOptions` / `windowOptions`** — `useMemo`-computed dropdown options from constants; intentionally computed once on mount

### UI Elements
- **`Checkbox`** — Enable/disable the webhook
- **`InputField`** — Destination URL with validation
- **`Dropdown`** — Host percentage and day window selectors (shown only when webhook is enabled)
- **`HostStatusWebhookPreviewModal`** — Preview the outgoing webhook payload
- **`GitOpsModeTooltipWrapper`** — Disables the save button when GitOps mode is active

## Usage Example

```typescript
import GlobalHostStatusWebhook from "./GlobalHostStatusWebhook";

<GlobalHostStatusWebhook
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isUpdatingSettings={isLoading}
/>
```
