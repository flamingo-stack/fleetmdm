Defines and exports the navigation item configuration for the Admin Integrations settings sidebar, returning an ordered list of `ISideNavItem` entries that map each integration category to its route path and card component.

## Key Components

- **`getIntegrationSettingsNavItems()`** — Factory function that returns the full list of integration settings nav items, each containing:
  - `title` — Display label shown in the side nav
  - `urlSection` — URL segment identifier
  - `path` — Route constant from `PATHS`
  - `Card` — The React component rendered when the item is active

### Nav Items Registered

| Title | URL Section | Card Component |
|---|---|---|
| Ticket destinations | `ticket-destinations` | `TicketDestinations` |
| MDM | `mdm` | `MdmSettings` |
| Calendars | `calendars` | `Calendars` |
| Change management | `change-management` | `ChangeManagement` |
| Single sign-on (SSO) | `sso` | `Sso` |
| Certificate authorities | `certificate-authorities` | `CertificateAuthorities` |
| Identity provider (IdP) | `identity-provider` | `IdentityProviders` |
| Host status webhook | `host-status-webhook` | `GlobalHostStatusWebhook` |
| Conditional access | `conditional-access` | `ConditionalAccess` |

## Usage Example

```typescript
import getIntegrationSettingsNavItems from "./IntegrationNavItems";
import SideNav from "../components/SideNav/SideNav";

const IntegrationsPage = () => {
  const navItems = getIntegrationSettingsNavItems();

  return <SideNav navItems={navItems} />;
};
```
