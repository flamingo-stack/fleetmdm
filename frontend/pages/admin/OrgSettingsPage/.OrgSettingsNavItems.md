Defines and exports the ordered list of side navigation items for the Organization Settings admin section, mapping each settings category to its route path and corresponding card component.

## Key Components

- **`ORG_SETTINGS_NAV_ITEMS`** — Array of `ISideNavItem<IAppConfigFormProps>` objects, each describing a settings section with:
  - `title` — Display label in the side nav
  - `urlSection` — URL segment identifier
  - `path` — Route path from `PATHS` constants
  - `Card` — React component rendered for that settings section

### Registered Nav Items

| Title | URL Section | Card Component |
|---|---|---|
| Organization info | `organization` | `Info` |
| Fleet web address | `webaddress` | `WebAddress` |
| SMTP options | `smtp` | `Smtp` |
| Agent options | `agents` | `Agents` |
| Usage statistics | `statistics` | `Statistics` |
| Fleet Desktop | `fleet-desktop` | `FleetDesktop` |
| Advanced options | `advanced` | `Advanced` |

## Usage Example

```typescript
import ORG_SETTINGS_NAV_ITEMS from "./OrgSettingsNavItems";
import SideNav from "../components/SideNav/SideNav";

const OrgSettingsPage = () => (
  <SideNav
    navItems={ORG_SETTINGS_NAV_ITEMS}
    activeSection="organization"
  />
);
```

> **Note:** The `isPremium` flag on the `FleetDesktop` item is currently commented out, meaning it is accessible regardless of license tier.
