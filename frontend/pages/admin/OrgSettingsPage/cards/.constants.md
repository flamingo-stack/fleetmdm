Defines shared constants, types, and interfaces for the Fleet MDM app configuration settings forms.

## Key Components

- **`DEFAULT_TRANSPARENCY_URL`** — Default URL pointing to the Fleet transparency page
- **`DeepPartial<T>`** — Recursive utility type that makes all properties of a type optionally partial, including nested objects
- **`IAppConfigFormProps`** — Interface defining common props shared across app configuration form subsections, including config data, premium tier status, submit handler, and router access
- **`authMethodOptions`** — Dropdown options for SMTP authentication methods (`Plain`, `Cram MD5`, `Login`)
- **`authTypeOptions`** — Dropdown options for SMTP authentication types (`Username and password`, `None`)

## Usage Example

```typescript
import {
  DEFAULT_TRANSPARENCY_URL,
  DeepPartial,
  IAppConfigFormProps,
  authMethodOptions,
  authTypeOptions,
} from "./constants";

// Using DeepPartial for partial config updates
const formUpdates: DeepPartial<IConfig> = {
  smtp_settings: {
    authentication_method: "authmethod_plain",
  },
};

// Using IAppConfigFormProps to type a config subsection component
const SmtpForm = ({
  appConfig,
  isPremiumTier,
  handleSubmit,
  router,
}: IAppConfigFormProps) => {
  return (
    <Dropdown
      options={authMethodOptions}
      defaultValue={appConfig.smtp_settings?.authentication_method}
    />
  );
};
```

## Notes

- `DeepPartial<T>` is particularly useful for form submissions where only a subset of nested config fields are updated at once
- Auth option arrays follow a consistent `{ label, value }` shape compatible with Fleet's `Dropdown` component
