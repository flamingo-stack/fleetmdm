A React settings form component for configuring Fleet Desktop options, rendered exclusively for premium tier users. Manages transparency URL and alternative browser host configuration with inline validation.

## Key Components

- **`IFleetDesktopFormData`** — Form state interface holding `transparencyURL` and `alternativeBrowserHost` fields
- **`IFleetDesktopFormErrors`** — Validation error state interface with optional error strings per field
- **`FleetDesktop`** — Default export; a controlled form component accepting `IAppConfigFormProps` that renders a settings section for Fleet Desktop configuration
- **`validateForm`** — Validates the transparency URL (must be a valid `http`/`https` URL) and browser host (must be a valid hostname or IP, with optional port)
- **`onInputChange`** — Handles field updates and clears per-field errors on change
- **`onFormSubmit`** — Transforms local form state into the API payload shape (`fleet_desktop.transparency_url`, `fleet_desktop.alternative_browser_host`) before calling `handleSubmit`

## Usage Example

```typescript
<FleetDesktop
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isPremiumTier={true}
  isUpdatingSettings={false}
/>
```

## Behavior Notes

- Returns an empty fragment (`<></>`) when `isPremiumTier` is `false` — the entire section is hidden for free-tier instances
- All inputs are disabled when GitOps mode is enabled (`appConfig.gitops.gitops_mode_enabled`)
- The Save button is disabled while form errors exist or while a settings update is in progress
- Transparency URL defaults to `DEFAULT_TRANSPARENCY_URL` from shared constants if not configured
