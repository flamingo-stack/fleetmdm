Renders the **Advanced** app configuration form, managing state for host lifecycle, activity retention, feature flags, server authentication, and MDM settings with inline validation and a confirmation modal when disabling historical data collection.

## Key Components

### Interfaces
- **`IAdvancedConfigFormData`** — Shape of all controlled form fields (SSO URL, MDM URL, SMTP domain, expiry windows, feature toggles, etc.)
- **`IAdvancedConfigFormErrors`** — Subset of fields that support inline validation errors
- **`IAdvancedSectionProps`** — Props contract shared by each child section component

### Internal Utilities
- **`validateFormData`** — Pure function validating URL fields (`ssoUserURL`, `mdmAppleServerURL`, `domain`) and `hostExpiryWindow`; returns a `Record<string, string>` of errors
- **`AdvancedInputChangeFn`** — Type alias for the shared `onInputChange` handler signature

### `Advanced` Component
- Initialises form state from `appConfig` via `useState`
- **`onInputChange`** — Updates form state; re-validates only previously-errored fields to avoid premature errors
- **`onInputBlur`** — Full re-validation on field blur
- **`datasetsBeingDisabled`** (`useMemo`) — Computes which historical datasets (`uptime`, `vulnerabilities`) are being turned off so the confirmation modal can surface them
- **`performSave`** — Assembles the API payload and calls the parent `handleSubmit`; keeps the confirm modal open on error
- **`onFormSubmit`** — Guards submission with full validation and routes through the confirm modal when datasets are being disabled

### Child Sections
`HostLifecycleSection`, `ActivityDataRetentionSection`, `FeaturesSection`, `ServerAuthenticationSection`

## Usage Example

```typescript
import Advanced from "./Advanced";

<Advanced
  appConfig={appConfig}
  handleSubmit={async (payload) => {
    await updateAppConfig(payload);
    return true;
  }}
  isUpdatingSettings={isSubmitting}
/>
```
