Renders the **Features** settings section in the admin Advanced settings page, providing toggle checkboxes for Live Reports, Script Execution, and Generative AI features.

## Key Components

- **`FeaturesSection`** — Default export. A React functional component that renders three GitOps-aware feature toggles.
- **`GitOpsModeTooltipWrapper`** — Wraps each checkbox to disable controls and display a tooltip when GitOps mode is active.
- **`Checkbox`** — Form field component used for each feature toggle, with inline tooltip content describing behavior and defaults.
- **`IAdvancedSectionProps`** — Interface providing `formData` (containing `disableLiveQuery`, `disableScripts`, `disableAIFeatures`) and `onInputChange` handler.

## Usage Example

```typescript
import FeaturesSection from "./FeaturesSection";

<FeaturesSection
  formData={{
    disableLiveQuery: false,
    disableScripts: false,
    disableAIFeatures: false,
  }}
  onInputChange={({ name, value }) => {
    // Update form state
    setFormData((prev) => ({ ...prev, [name]: value }));
  }}
/>
```

## Toggle Behaviors

| Feature | Field | Default | Notes |
|---|---|---|---|
| Live Reports | `disableLiveQuery` | On | Disables ad hoc UI/fleetctl queries |
| Script Execution | `disableScripts` | On | Blocks run scripts; install/lock/wipe still available |
| Generative AI | `disableAIFeatures` | On | Only policy SQL sent to LLM; not used for training |
