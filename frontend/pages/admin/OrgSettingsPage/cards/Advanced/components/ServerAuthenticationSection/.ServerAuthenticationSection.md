Renders the "Server & authentication" settings section within the Fleet admin advanced configuration page, providing form controls for SSO, MDM, SMTP, and SSL/TLS options.

## Key Components

- **`ServerAuthenticationSection`** — Default export; a functional React component that accepts `IAdvancedSectionProps` and renders grouped server/authentication fields
- **Fields rendered:**
  - `ssoUserURL` — SSO login URL override (wrapped in `GitOpsModeTooltipWrapper`)
  - `mdmAppleServerURL` — Apple MDM server URL override (conditionally shown when MDM is enabled and configured)
  - `domain` — HELO domain for SMTP
  - `verifySSLCerts` — Checkbox to enable/disable SSL certificate verification
  - `enableStartTLS` — Checkbox to enable STARTTLS detection for SMTP

## Usage Example

```typescript
import ServerAuthenticationSection from "./ServerAuthenticationSection";

<ServerAuthenticationSection
  formData={{
    ssoUserURL: "https://fleet.example.com/sso",
    mdmAppleServerURL: "",
    domain: "",
    verifySSLCerts: true,
    enableStartTLS: true,
  }}
  formErrors={{}}
  onInputChange={handleChange}
  onInputBlur={handleBlur}
  appConfig={appConfig}
/>
```

## Notes

- `mdmAppleServerURL` is only rendered when `appConfig.mdm.enabled_and_configured` is `true`
- SSO and Apple MDM URL fields are wrapped in [`GitOpsModeTooltipWrapper`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/GitOpsModeTooltipWrapper) to disable editing when GitOps mode is active
- Tooltips on checkboxes document default values and caveats directly in the UI
