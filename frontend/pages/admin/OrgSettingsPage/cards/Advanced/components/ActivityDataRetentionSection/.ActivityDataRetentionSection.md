A React settings section component for configuring activity and data retention policies in the Fleet MDM admin advanced settings panel.

## Key Components

- **`ActivityDataRetentionSection`** — Default export. Renders a `SettingsSection` containing multiple `Checkbox` and `Dropdown` controls for managing data lifecycle settings.
- **`IAdvancedSectionProps`** — Inherited prop interface providing `onInputChange` handler and `formData` object.
- **Controls rendered:**
  - **Delete activities** — Toggles automatic audit log cleanup.
  - **Max activity age** — Dropdown (conditional on `deleteActivities`) for setting log expiry window in days.
  - **Preserve host activities on re-enrollment** — Retains host activities after wipe/re-enrollment (Apple ADE hosts).
  - **Store report results** — Inverted toggle controlling `disableQueryReports`.
  - **Hosts online historical reporting** — Inverted toggle controlling `disableHostsActive`.
  - **Vulnerability exposure historical reporting** — Premium-tier only; inverted toggle for `disableVulnerabilities`.

All controls are wrapped in `GitOpsModeTooltipWrapper` to disable inputs and surface tooltips when GitOps mode is active.

## Usage Example

```typescript
import ActivityDataRetentionSection from "./ActivityDataRetentionSection";

<ActivityDataRetentionSection
  formData={{
    disableQueryReports: false,
    deleteActivities: true,
    activityExpiryWindow: 30,
    preserveHostActivitiesOnReenrollment: false,
    disableHostsActive: false,
    disableVulnerabilities: false,
  }}
  onInputChange={({ name, value }) => {
    setFormData((prev) => ({ ...prev, [name]: value }));
  }}
/>
```

> **Note:** The `activityExpiryWindowOptions` memo intentionally excludes `activityExpiryWindow` from its dependency array — custom dropdown values are preserved across user-driven frequency changes.
