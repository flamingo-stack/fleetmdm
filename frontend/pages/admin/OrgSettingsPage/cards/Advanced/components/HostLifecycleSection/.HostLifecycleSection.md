Renders the **Host Lifecycle** settings section in the Fleet admin Advanced settings page, providing controls for host expiry and hardware attestation configuration.

## Key Components

- **`HostLifecycleSection`** — Default export. A React functional component that renders host lifecycle settings wrapped in `SettingsSection`.
- **`enableHostExpiry` checkbox** — Toggles automatic cleanup of hosts that haven't communicated with Fleet within a configurable window.
- **`hostExpiryWindow` input** — Conditionally rendered numeric input (visible only when `enableHostExpiry` is `true`) specifying the inactivity threshold in days.
- **`requireHardwareAttestation` checkbox** — Premium-tier-only option requiring macOS Apple Silicon DEP-enrolled hosts to use ACME with Managed Device Attestation.
- **`GitOpsModeTooltipWrapper`** — Wraps each control to disable interaction and show a tooltip when GitOps mode is active.

## Props (`IAdvancedSectionProps`)

| Prop | Type | Default | Description |
|---|---|---|---|
| `isPremiumTier` | `boolean` | `false` | Shows hardware attestation option when `true` |
| `onInputChange` | `function` | — | Change handler for all form fields |
| `formData` | `object` | — | Current values for `enableHostExpiry`, `hostExpiryWindow`, `requireHardwareAttestation` |
| `formErrors` | `object` | `{}` | Validation errors keyed by field name |

## Usage Example

```typescript
import HostLifecycleSection from "./HostLifecycleSection";

<HostLifecycleSection
  isPremiumTier={true}
  formData={{
    enableHostExpiry: true,
    hostExpiryWindow: 30,
    requireHardwareAttestation: false,
  }}
  formErrors={{ hostExpiryWindow: "Must be greater than 0" }}
  onInputChange={handleInputChange}
/>
```
