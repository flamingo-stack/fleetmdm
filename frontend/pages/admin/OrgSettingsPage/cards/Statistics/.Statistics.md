A React settings form component that manages Fleet's usage statistics (analytics/telemetry) configuration, allowing administrators to enable or disable anonymous usage data collection.

## Key Components

- **`Statistics`** — Default export; a form component consuming `IAppConfigFormProps` that renders a checkbox toggle for enabling/disabling usage telemetry
- **`IStatisticsFormData`** — Local interface defining the form state shape (`enableUsageStatistics: boolean`)
- **`telemetryAlwaysEnabled`** — Derived boolean that locks the checkbox to `true` for Fleet Premium customers when `allow_disable_telemetry` is `false`
- **`onFormSubmit`** — Transforms UI form state into the `server_settings` API payload shape before delegating to `handleSubmit`

## Usage Example

```typescript
// Used within the Fleet admin app config settings page
import Statistics from "./Statistics";

<Statistics
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isPremiumTier={true}
  isUpdatingSettings={false}
/>
```

## Behavior Notes

- **Premium tier lock**: When `isPremiumTier` is `true` and `allow_disable_telemetry` is `false`, the checkbox is forced to `true` and both the checkbox and Save button are disabled.
- **GitOps mode**: The Save button is wrapped in `GitOpsModeTooltipWrapper`, automatically disabling it when GitOps mode is active.
- **API mapping**: The UI field `enableUsageStatistics` maps to `server_settings.enable_analytics` in the submitted payload. Other `server_settings` fields (`deferred_save_host`, `query_reports_disabled`, `scripts_disabled`) are passed through unchanged from `appConfig`.
