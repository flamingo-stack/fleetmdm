React settings form component for configuring Fleet agent options (fleetd) via a YAML editor in the admin app config section.

## Key Components

### Interfaces
- **`IAgentOptionsFormData`** — Form state shape holding the `agentOptions` YAML string
- **`IAgentOptionsFormErrors`** — Error state shape for `agent_options` field validation

### Component
- **`Agents`** — Default export; renders the agent options settings section with a YAML editor, real-time validation, and submit handling

### Internal Logic
- **`handleAgentOptionsChange`** — Updates `formData` state when the YAML editor value changes
- **`validateForm`** — Runs YAML validation on the current `agentOptions` value and populates `formErrors`; triggered via `useEffect` on every change
- **`onFormSubmit`** — Parses the YAML string via `yaml.load` before calling `handleSubmit`; falls back to `EMPTY_AGENT_OPTIONS` when the field is empty

## Usage Example

```typescript
import Agents from "pages/admin/AppSettingsPage/cards/Agents";

<Agents
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isPremiumTier={true}
  isUpdatingSettings={false}
/>
```

## Behavior Notes

- **GitOps mode** — When `appConfig.gitops.gitops_mode_enabled` is `true`, the YAML editor and Save button are disabled via `GitOpsModeTooltipWrapper`
- **Premium tier** — Shows an `InfoBanner` directing users to the Fleets page for per-fleet agent option overrides; free tier shows a link to Fleet docs instead
- **Validation** — YAML is validated on every keystroke; the Save button is disabled while any validation errors exist
- **Submit payload** — Submits parsed YAML as `agent_options` (object), not the raw string
