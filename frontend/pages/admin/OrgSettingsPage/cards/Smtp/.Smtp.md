Renders the SMTP configuration form within the Fleet admin settings panel, handling both standard SMTP setup and SES-configured email backend detection.

## Key Components

- **`ISmtpConfigFormData`** — Interface defining all SMTP form fields (server, port, auth type, credentials, SSL/TLS toggle)
- **`ISmtpConfigFormErrors`** — Interface for field-level validation error messages
- **`validateFormData`** — Pure validation function enforcing required fields and email format when SMTP is enabled
- **`Smtp`** — Default export; main form component consuming `IAppConfigFormProps`
- **`renderSmtpSection`** — Conditionally renders username/password/auth-method fields based on `smtpAuthenticationType`
- **`renderSesEnabled`** — Renders a read-only card when SES is already configured as the email backend
- **`renderSmtpForm`** — Renders the full SMTP form with GitOps mode disabling and save-button tooltip

## Behavior Notes

- Errors are surfaced on blur or submit, but only **updated** (not newly introduced) on each keystroke via `onInputChange`
- When `gitops_mode_enabled` is `true`, the form is visually disabled via `GitOpsModeTooltipWrapper`
- If `appConfig.email.backend === "ses"`, the form is replaced with the SES notice card
- The Save button tooltip indicates a test email will be sent on save

## Usage Example

```typescript
<Smtp
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isUpdatingSettings={isLoading}
/>
```
