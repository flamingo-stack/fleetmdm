Renders and tests the `Smtp` settings component, specifically verifying tooltip behavior on the SSL/TLS checkbox label.

## Key Components

- **`describe("Smtp")`** — Test suite for the `Smtp` settings form component
- **`mockHandleSubmit`** — Jest mock resolving `true`, simulating a successful form submission handler
- **`renderWithSetup`** — Custom test utility that wraps the component with necessary providers and returns a `user` event object
- **`createMockConfig`** — Factory that generates a mock Fleet app config for prop injection

## Tests

### `renders the STARTTLS guidance on hover of the SSL/TLS checkbox label`

Verifies that hovering over the "Use SSL/TLS to connect (recommended)" label displays a tooltip containing STARTTLS guidance text (`/STARTTLS must first be disabled in/i`).

## Usage Example

```typescript
import { renderWithSetup, createMockRouter } from "test/test-utils";
import createMockConfig from "__mocks__/configMock";
import Smtp from "./Smtp";

const { user } = renderWithSetup(
  <Smtp
    appConfig={createMockConfig()}
    handleSubmit={jest.fn().mockResolvedValue(true)}
    isUpdatingSettings={false}
    router={createMockRouter()}
  />
);

// Hover over the SSL/TLS label to trigger tooltip
await user.hover(screen.getByText("Use SSL/TLS to connect (recommended)"));
```
