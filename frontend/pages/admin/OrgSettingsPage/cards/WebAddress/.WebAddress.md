A React settings form component for configuring the Fleet server's web address URL within the admin app configuration panel.

## Key Components

- **`validateFormData`** — Pure validation function that checks the server URL is present and matches `http`/`https` protocols (localhost allowed), returning an error map
- **`WebAddress`** — Default-exported React component rendering the Fleet web address settings form with controlled input, inline validation, and GitOps mode awareness

### Form Behavior
- **On change**: Re-validates only fields that already have errors (prevents premature error display)
- **On blur**: Full validation run to surface new errors
- **On submit**: Full validation gate before calling `handleSubmit` with `server_settings.server_url` payload

## Usage Example

```typescript
import WebAddress from "./WebAddress";

<WebAddress
  appConfig={appConfig}
  handleSubmit={(formData) => updateAppConfig(formData)}
  isUpdatingSettings={isLoading}
/>
```

The component submits data shaped as:

```typescript
{
  server_settings: {
    server_url: "https://fleet.example.com"
  }
}
```

## Notes

- The URL input is **disabled** when `gitops_mode_enabled` is `true`; the Save button is wrapped in `GitOpsModeTooltipWrapper` to surface a tooltip explaining why it is disabled
- Validation uses the shared `validUrl` validator with `allowLocalHost: true`, matching Fleet's development use cases
- Error message for invalid URLs is sourced from the shared `INVALID_SERVER_URL_MESSAGE` utility constant
