Organization settings page component that manages Fleet MDM configuration, handling form submissions, navigation between settings sections, and tier-based access control.

## Key Components

- **`OrgSettingsPage`** — Main page component rendering a side-navigation layout with settings cards
- **`onFormSubmit`** — Async handler that diffs form updates against current config, submits only changed fields to the API, and surfaces SMTP/agent option-specific error messages
- **`navItems`** — Filtered navigation list; excludes `fleet-desktop` section for non-premium tiers
- **`currentFormSection`** — Resolved active nav item derived from the URL `section` param, falling back to the first nav item
- **`SideNav`** — Renders the sidebar and injects the active settings card, or a `Spinner` while config loads
- **`baseClass`** — Exported CSS class prefix (`"org-settings"`) for BEM-style styling

## Usage Example

```typescript
// Rendered by the router — receives params and router as props
import OrgSettingsPage from "./OrgSettingsPage";

// Route definition (react-router v3)
<Route
  path={paths.ADMIN_SETTINGS}
  component={OrgSettingsPage}
/>

// URL-driven section selection:
// /admin/settings/org-info       → Org Info card
// /admin/settings/fleet-desktop  → Fleet Desktop card (premium only)
```

## Behavior Notes

- Redirects to `/admin/integrations` when `isSandboxMode` is active
- Returns a `403` page error if a free-tier user navigates directly to `fleet-desktop`
- Agent options are always sent in full on submit (not diffed) to prevent partial overrides
- Config is refetched and synced to `AppContext` on every successful save
