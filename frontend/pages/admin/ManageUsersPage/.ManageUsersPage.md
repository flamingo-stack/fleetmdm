Renders the Manage Users page, composing a description and user management table for controlling Fleet access and permissions.

## Key Components

- **`ManageUsersPage`** — Default export. Top-level page component that accepts a `router` prop and renders the page layout with `PageDescription` and `UsersTable`.
- **`IUserManagementProps`** — Interface defining the `router` prop (React Router v3 `InjectedRouter`).
- **`UsersTable`** — Child component responsible for listing and managing users, receives the `router` for navigation.
- **`PageDescription`** — Displays a static description of the page's purpose.

## Usage Example

```typescript
import ManageUsersPage from "./ManageUsersPage";
import { InjectedRouter } from "react-router";

// Typically rendered by the router when the /users route is matched
<ManageUsersPage router={router as InjectedRouter} />
```

## Notes

- The `baseClass` constant (`"manage-users"`) is used for BEM-style CSS scoping on the wrapper `<div>`.
- This component is intentionally thin — all user data fetching and table logic is delegated to [`UsersTable`](https://github.com/flamingo-stack/fleetmdm/blob/main/src/pages/admin/UserManagementPage/components/UsersTable).
