Admin page component for creating new Fleet users, supporting both direct creation and email invitation flows.

## Key Components

- **`CreateUserPage`** — Main page component that renders a user creation form within the admin panel
- **`handleSubmit`** — Handles two creation paths based on `NewUserType`:
  - `AdminInvited` — Sends an email invitation via `invitesAPI.create()`
  - Direct creation — Creates the user immediately via `usersAPI.createUserWithoutInvitation()`
- **Teams query** — Loads available teams via `react-query` (only when `isPremiumTier` is enabled)
- **Form error handling** — Maps API error messages (duplicate email, password policy, password length) to field-level `formErrors` state

## Usage Example

```typescript
// Rendered by the router at PATHS.ADMIN_USERS_NEW
import CreateUserPage from "pages/admin/UserManagementPage/CreateUserPage";

// Router injects the `router` prop automatically
<Route
  path={PATHS.ADMIN_USERS_NEW}
  component={CreateUserPage}
/>
```

The component reads `isPremiumTier`, `currentUser`, and `config` from `AppContext` to conditionally load teams and configure SSO/SMTP/SES options passed down to `UserForm`.

## Error Handling

| API Error Reason | Field | Message |
|---|---|---|
| `already exists` / `Duplicate` | `email` | A user with this email address already exists |
| `required criteria` | `password` | Password must meet the criteria below |
| `password too long` | `password` | Password is over the character limit |
