A React form section component that renders API access controls, allowing users to choose between granting access to all API endpoints or selecting specific ones.

## Key Components

- **`ApiAccessType` (enum)** — Defines the two access modes: `AllEndpoints` and `SpecificEndpoints`
- **`IApiAccessSectionProps` (interface)** — Props contract for the component:
  - `isSpecificEndpoints` — Controls which radio option is selected
  - `onAccessTypeChange` — Callback fired when the access type radio changes
  - `selectedEndpoints` — Currently selected `IApiEndpointRef` items
  - `onEndpointSelectionChange` — Callback fired when endpoint selection changes
  - `error` — Optional validation error message
- **`ApiAccessSection` (default export)** — Main component rendering radio buttons and conditionally a `ApiEndpointSelectorTable` with a tooltip-wrapped label

## Usage Example

```typescript
import ApiAccessSection from "./ApiAccessSection";
import { IApiEndpointRef } from "interfaces/api_endpoint";

const [isSpecific, setIsSpecific] = useState(false);
const [selectedEndpoints, setSelectedEndpoints] = useState<IApiEndpointRef[]>([]);

<ApiAccessSection
  isSpecificEndpoints={isSpecific}
  onAccessTypeChange={setIsSpecific}
  selectedEndpoints={selectedEndpoints}
  onEndpointSelectionChange={setSelectedEndpoints}
  error="Please select at least one endpoint."
/>
```

When `isSpecificEndpoints` is `true`, a `ApiEndpointSelectorTable` appears beneath the radios along with a tooltip clarifying that selecting specific endpoints restricts access but does not elevate role-based permissions.
