A confirmation modal component that prompts an administrator to require a password reset for a Fleet user, warning that all active API tokens will be revoked.

## Key Components

- **`IResetPasswordModal`** — Interface defining two required callback props:
  - `onResetConfirm` — Called when the admin confirms the password reset action
  - `onResetCancel` — Called when the admin cancels or dismisses the modal
- **`ResetPasswordModal`** — Default export; a functional component rendering a `Modal` with a confirmation message and two action buttons (Confirm / Cancel)

## Usage Example

```typescript
import ResetPasswordModal from "components/ResetPasswordModal";

const UserManagementPage = () => {
  const [showResetModal, setShowResetModal] = React.useState(false);

  const handleResetConfirm = () => {
    // Trigger API call to require password reset
    setShowResetModal(false);
  };

  const handleResetCancel = () => {
    setShowResetModal(false);
  };

  return (
    <>
      {showResetModal && (
        <ResetPasswordModal
          onResetConfirm={handleResetConfirm}
          onResetCancel={handleResetCancel}
        />
      )}
    </>
  );
};
```

## Notes

- Keyboard-accessible: the `Modal`'s `onEnter` prop maps to `onResetConfirm`, allowing confirmation via the Enter key
- The modal body clearly communicates the side effect of token revocation before the admin commits to the action
