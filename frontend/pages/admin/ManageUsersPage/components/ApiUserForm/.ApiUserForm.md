Form component for creating and editing API-only users, handling name, role/team assignment, and API endpoint access configuration with inline validation.

## Key Components

- **`IApiUserFormData`** — Exported interface describing form submission payload (`name`, `global_role`, `fleets`, `api_endpoints`)
- **`IApiUserFormProps`** — Props interface accepting submit/cancel callbacks, available teams, optional default data, and tier flags
- **`UserTeamType`** — Enum distinguishing global user (`GLOBAL_USER`) vs. team-scoped (`ASSIGN_TEAMS`) permission modes
- **`ApiUserForm`** — Default export; stateful form component managing name, role, fleet selection, and API endpoint scoping

### Internal Handlers

| Handler | Purpose |
|---|---|
| `handleSubmit` | Validates, assembles, and submits form data; sends `null` for `api_endpoints` when "All" access is selected on premium tier |
| `handleIsGlobalUserChange` | Toggles between global and fleet-scoped permission modes |
| `handleAccessTypeChange` | Switches between all-endpoint and specific-endpoint API access |
| `getErrors` | Returns a map of field-level validation errors before submission |

## Usage Example

```typescript
import ApiUserForm, { IApiUserFormData } from "./ApiUserForm";

const handleSubmit = (data: IApiUserFormData) => {
  console.log("Submitting API user:", data);
};

<ApiUserForm
  availableTeams={teams}
  isPremiumTier={true}
  isSubmitting={false}
  onCancel={() => setIsOpen(false)}
  onSubmit={handleSubmit}
  defaultData={{
    name: "ci-bot",
    global_role: "gitops",
    fleets: [],
    api_endpoints: null,
  }}
/>
```

> **Note:** `api_endpoints` is intentionally omitted from the payload on free-tier submissions to avoid overwriting values set by a premium instance.
