Integration tests for the `UserForm` component covering edge cases around form validation, conditional rendering based on configuration flags, and authentication method display.

## Key Components

- **`defaultProps`** – Shared prop baseline (new user, premium tier, SMTP/SES configured, SSO disabled) reused across all test cases
- **`renderWithSetup`** – Custom test utility that returns a `user` event instance for simulating interactions
- **`createMockRouter`** – Utility that provides a mock router instance required by the form

## Test Cases

| Test | Description |
|------|-------------|
| `displays error messages for invalid inputs` | Submitting an empty form shows validation errors for name, email, and password |
| `renders SSO option when canUseSso is true` | SSO radio appears only when `canUseSso` prop is enabled |
| `disables invite user option when SMTP and SES are not configured` | The "Invite user" radio is disabled when both mail providers are off |
| `does not render premium sections when isPremiumTier is false` | Hides team assignment, global user, and 2FA fields; core fields remain visible |
| `does not render password and 2FA sections when SSO is selected` | Selecting SSO hides the password input and 2FA section |
| `displays disabled SSO option when SSO globally disabled but previously enabled` | SSO radio is disabled but visible; submitting still triggers password validation |

## Usage Example

```typescript
// Run this specific test file
npx jest UserForm.tests.tsx

// Run with coverage
npx jest UserForm.tests.tsx --coverage
```

> **Note:** Happy path flows (successful user creation/editing) are covered by end-to-end tests. These integration tests target conditional rendering and validation edge cases only.
