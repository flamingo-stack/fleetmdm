Renders a form for creating or editing Fleet users, handling user type selection, role assignment, SSO/MFA configuration, team membership, and form validation.

## Key Components

**Enums**
- `NewUserType` — Distinguishes between admin-invited (`AdminInvited`) and admin-created (`AdminCreated`) users
- `UserTeamType` — Differentiates global users from team-assigned users

**Interfaces**
- `IUserFormData` — Shape of the form submission payload, including email, name, password, SSO/MFA flags, global role, and team assignments
- `IUserFormProps` — All props accepted by the `UserForm` component

**Internal Helpers**
- `validate()` — Pure validation function; enforces presence, email format, and conditional password requirements based on SSO state and user type
- `addSubmitData()` — Assembles the final API payload, adjusting `password`/`new_password` fields and stripping irrelevant fields based on edit vs. create context

**Key Handlers**
- `onInputChange` / `onInputBlur` — Live and blur-triggered validation
- `onSsoChange` — Clears password errors when SSO is enabled
- `onIsGlobalUserChange` / `onGlobalUserRoleChange` — Manage global role state
- `onSelectedTeamChange` / `onTeamRoleChange` — Manage team assignments
- `onFormSubmit` — Final validation gate before calling `onSubmit`

## Usage Example

```typescript
import UserForm, { NewUserType, IUserFormData } from "./UserForm";

<UserForm
  availableTeams={teams}
  isPremiumTier={true}
  canUseSso={org.ssoEnabled}
  isSsoEnabled={user.ssoEnabled}
  isNewUser={true}
  defaultGlobalRole="observer"
  defaultTeams={[]}
  ancestorErrors={{}}
  onCancel={() => setShowModal(false)}
  onSubmit={(formData: IUserFormData) => {
    createUser(formData);
  }}
/>
```
