A React component that provides a searchable, dropdown-based selector for Fleet REST API endpoints, displaying selected endpoints in a removable table below the search input.

## Key Components

### `ApiEndpointSelectorTable`
The default export. Renders a search input, a dropdown results table, and a selected endpoints table.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `selectedEndpoints` | `IApiEndpointRef[]` | Currently selected API endpoints |
| `onSelectionChange` | `(endpoints: IApiEndpointRef[]) => void` | Callback fired when selection changes |

### `NameCell`
Internal cell renderer that displays an endpoint's display name alongside a `Deprecated` pill badge when applicable.

### `normalizePath(s: string)`
Utility that normalizes path parameter names (e.g., `:id`, `:host_id` → `:_`) so search queries match regardless of parameter naming conventions.

### `generateSelectedTableHeaders(handleRemove)`
Factory that produces column configs for the selected-endpoints table, appending a remove button column to the base headers.

## Usage Example

```typescript
import ApiEndpointSelectorTable from "components/ApiEndpointSelectorTable";
import { IApiEndpointRef } from "interfaces/api_endpoint";

const MyForm = () => {
  const [selected, setSelected] = useState<IApiEndpointRef[]>([]);

  return (
    <ApiEndpointSelectorTable
      selectedEndpoints={selected}
      onSelectionChange={setSelected}
    />
  );
};
```

## Behaviour Notes

- Fetches all endpoints once via `react-query` (`api_endpoints` key); results are cached and not refetched on window focus.
- The search dropdown closes on outside click or `Escape` keypress.
- Already-selected endpoints are excluded from search results.
- Searching matches against `display_name`, normalized `path`, and `method`.
- Experimental endpoints are intentionally unsupported and excluded from results.
