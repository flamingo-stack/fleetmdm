A confirmation modal component that prompts an administrator to reset all active sessions and API tokens for a specific user.

## Key Components

- **`ResetSessionsModal`** — Default export; a functional React component rendering a `Modal` with confirm/cancel actions
- **`IResetSessionsModal`** — Interface defining the two required callback props:
  - `onResetConfirm` — Invoked when the user confirms the session reset
  - `onResetCancel` — Invoked when the user cancels or closes the modal

## Usage Example

```typescript
import ResetSessionsModal from "components/ResetSessionsModal";

<ResetSessionsModal
  onResetConfirm={() => handleResetSessions(userId)}
  onResetCancel={() => setShowResetModal(false)}
/>
```

## Behavior Notes

- Displays a warning that the target user will be logged out and all active Fleet API tokens revoked
- Supports keyboard-driven confirmation via the `Modal`'s `onEnter` prop wired to `onResetConfirm`
- Closing the modal via the exit control triggers `onResetCancel`
- Styled under the BEM base class `reset-sessions-modal`
