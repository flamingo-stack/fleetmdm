Unit tests for the `SelectedTeamsForm` component, verifying checkbox rendering state and team selection change propagation to the parent.

## Key Components

- **Test suite**: `SelectedTeamsForm - component` — two test cases covering rendering and interaction behavior
- **`userTeamStub`** — reusable team fixture providing a base team object (`"Test Team"`)
- **`renderWithSetup`** — custom test utility that provides a `user` event object for simulating user interactions
- **`onFormChange`** — callback prop verified via `jest.fn()` to assert correct team arrays are passed up on checkbox changes

## Test Cases

**Renders checkboxes with correct checked state**
Mounts the form with one current team and one unjoined team, then asserts the current team's checkbox is checked and the other is not.

**Propagates selection changes to parent**
Simulates clicking an unchecked team checkbox and verifies `onFormChange` is called with the full updated selection. Then unchecks it and verifies the callback returns to the original selection.
