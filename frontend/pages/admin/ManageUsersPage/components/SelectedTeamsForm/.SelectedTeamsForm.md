A React form component for selecting and configuring team memberships with role assignments for user management workflows.

## Key Components

### Interfaces
- **`ITeamCheckboxListItem`** — Extends `ITeam` with an `isChecked` boolean to track selection state within the form
- **`ISelectedTeamsFormProps`** — Props for `availableTeams`, `usersCurrentTeams`, `onFormChange` callback, optional `isApiOnly` flag, and `onMenuOpen` handler

### Helper Functions
- **`generateFormListItems`** — Maps all available teams against the user's current teams, defaulting unassigned teams to the `"observer"` role with `isChecked: false`
- **`generateSelectedTeamData`** — Filters the internal form list to return only checked teams as clean `ITeam` objects for parent consumption
- **`updateFormState`** — Mutates a team item's `isChecked` or `role` field based on whether the incoming value is a boolean (checkbox) or dropdown selection

### Custom Hook
- **`useSelectedTeamState`** — Encapsulates form list state and exposes `updateSelectedTeams`, which updates internal state and propagates only selected teams upward via the `formChange` callback

### Component
- **`SelectedTeamsForm`** — Renders a `<ul>` of team rows, each with a `Checkbox` for selection and a `DropdownWrapper` (role selector) that appears only when the team is checked

## Usage Example

```typescript
<SelectedTeamsForm
  availableTeams={allTeams}
  usersCurrentTeams={user.teams}
  onFormChange={(selectedTeams: ITeam[]) => {
    // Only receives checked teams with their assigned roles
    setUserTeams(selectedTeams);
  }}
  isApiOnly={user.api_only}
  onMenuOpen={() => setDropdownOpen(true)}
/>
```

> **Note:** Role dropdown options are filtered via `roleOptions({ isPremiumTier: true, isApiOnly })` — unchecked team rows still allow dropdown interaction locally, but those changes are not surfaced to the parent until the team is selected.
