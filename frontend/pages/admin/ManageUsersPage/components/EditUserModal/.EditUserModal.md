A modal component that wraps `UserForm` inside a `Modal` dialog for editing existing user accounts, including role, team assignments, SSO/MFA settings, and email configuration.

## Key Components

### `EditUserModal` (default export)
A functional React component that renders an "Edit user" modal dialog.

### `IEditUserModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Closes the modal without saving |
| `onSubmit` | `(formData: IUserFormData) => void` | Submits the edited user form data |
| `defaultName` | `string?` | Pre-filled display name |
| `defaultEmail` | `string?` | Pre-filled email address |
| `defaultGlobalRole` | `UserRole \| null` | User's current global role |
| `defaultTeamRole` | `UserRole?` | User's current team-scoped role |
| `defaultTeams` | `ITeam[]?` | Teams the user currently belongs to |
| `availableTeams` | `ITeam[]` | All teams available for assignment |
| `currentTeam` | `ITeam?` | The team context in which the modal is opened |
| `isPremiumTier` | `boolean` | Enables premium-tier features in the form |
| `smtpConfigured` / `sesConfigured` | `boolean` | Email provider availability |
| `canUseSso` | `boolean` | Whether SSO is enabled org-wide |
| `isSsoEnabled` | `boolean?` | Whether SSO is enabled for this user |
| `isMfaEnabled` | `boolean?` | Whether MFA is enabled for this user |
| `isApiOnly` | `boolean?` | Marks the user as API-only |
| `editUserErrors` | `IUserFormErrors` | Validation/server errors passed into the form |
| `isModifiedByGlobalAdmin` | `boolean?` | Unlocks admin-only fields |
| `isInvitePending` | `boolean?` | Indicates the user has a pending invite |
| `isUpdatingUsers` | `boolean` | Disables form submission while saving |

## Usage Example

```typescript
<EditUserModal
  onCancel={() => setShowEditModal(false)}
  onSubmit={(formData) => handleEditUser(userId, formData)}
  defaultName="Jane Doe"
  defaultEmail="jane@example.com"
  defaultGlobalRole="admin"
  availableTeams={teams}
  isPremiumTier={true}
  smtpConfigured={true}
  sesConfigured={false}
  canUseSso={true}
  isSsoEnabled={false}
  isMfaEnabled={true}
  editUserErrors={editErrors}
  isUpdatingUsers={isSubmitting}
/>
```
