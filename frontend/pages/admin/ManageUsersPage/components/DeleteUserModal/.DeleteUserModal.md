A confirmation modal component for permanently deleting a user from Fleet, displaying a warning and action buttons.

## Key Components

### `IDeleteUserModal` Interface
| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Display name of the user to be deleted |
| `onDelete` | `() => void` | Callback triggered on delete confirmation |
| `onCancel` | `() => void` | Callback triggered on cancellation |
| `isUpdatingUsers` | `boolean` | Controls loading state on the Delete button |

### `DeleteUserModal` Component
A modal dialog that warns the user the action is irreversible and provides **Delete** (alert variant with loading state) and **Cancel** (inverse-alert variant) buttons.

## Usage Example

```typescript
import DeleteUserModal from "components/DeleteUserModal";

const UserManagement = () => {
  const [showDeleteModal, setShowDeleteModal] = React.useState(false);
  const [isUpdating, setIsUpdating] = React.useState(false);

  const handleDelete = async () => {
    setIsUpdating(true);
    await deleteUser(userId);
    setIsUpdating(false);
    setShowDeleteModal(false);
  };

  return (
    <>
      {showDeleteModal && (
        <DeleteUserModal
          name="Jane Doe"
          onDelete={handleDelete}
          onCancel={() => setShowDeleteModal(false)}
          isUpdatingUsers={isUpdating}
        />
      )}
    </>
  );
};
```

## Notes
- The `Enter` key triggers `onDelete` via the `Modal`'s `onEnter` prop, matching the confirm button behavior.
- The Delete button renders a loading spinner when `isUpdatingUsers` is `true`, preventing duplicate submissions.
