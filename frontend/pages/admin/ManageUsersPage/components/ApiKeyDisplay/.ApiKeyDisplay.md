Displays a newly generated API key for a user, with a masked input field and a one-time visibility warning banner.

## Key Components

- **`ApiKeyDisplay`** — Default export. A presentational React component that renders the new user's name, a hidden/copyable API key field, a yellow warning banner, and a "Done" button to dismiss the view.
- **`IApiKeyDisplayProps`** — Interface defining the component's props:
  - `newUserName: string` — The display name of the newly created user.
  - `apiKey: string` — The API key to display (shown once).
  - `onDone: () => void` — Callback invoked when the user clicks "Done".

## Usage Example

```typescript
import ApiKeyDisplay from "components/ApiKeyDisplay/ApiKeyDisplay";

const CreateUserFlow = () => {
  const [showKey, setShowKey] = React.useState(true);

  if (!showKey) return null;

  return (
    <ApiKeyDisplay
      newUserName="jane.doe@example.com"
      apiKey="fleet_abc123xyz"
      onDone={() => setShowKey(false)}
    />
  );
};
```

> **⚠️ One-time display:** The component renders a `yellow` `InfoBanner` reminding users to copy the API key immediately — it cannot be retrieved again after dismissal.

## Notes

- Uses `InputFieldHiddenContent` to mask the key value while allowing the user to reveal or copy it.
- Stateless and fully controlled via props — key storage and visibility management are the responsibility of the parent component.
