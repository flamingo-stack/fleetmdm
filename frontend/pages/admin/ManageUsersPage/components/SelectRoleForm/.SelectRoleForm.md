A React form component that renders a role selection dropdown for assigning a `UserRole` to a team member, updating the parent teams array on selection change.

## Key Components

- **`ISelectRoleFormProps`** — Props interface defining the team context, default role, change handler, and optional API-only/menu-open callbacks.
- **`generateSelectedTeamData`** — Pure helper that merges an updated team role into the full teams array by matching on team `id`.
- **`SelectRoleForm`** — Default export; reads `isPremiumTier` from `AppContext` to gate available role options, maintains local `selectedRole` state, and delegates rendering to `DropdownWrapper`.

## Usage Example

```typescript
import SelectRoleForm from "components/SelectRoleForm";
import { ITeam } from "interfaces/team";

const MyComponent = () => {
  const [teams, setTeams] = useState<ITeam[]>(allTeams);

  return (
    <SelectRoleForm
      defaultTeamRole="observer"
      currentTeam={teams[0]}
      teams={teams}
      onFormChange={(updatedTeams) => setTeams(updatedTeams)}
      isApiOnly={false}
      onMenuOpen={() => console.log("Dropdown opened")}
    />
  );
};
```

## Notes

- Available role options are derived from [`roleOptions`](https://github.com/flamingo-stack/fleetmdm/blob/main/helpers/userManagementHelpers.ts), which filters options based on `isPremiumTier` and `isApiOnly` flags.
- The component is controlled via local state (`selectedRole`) but propagates changes upward through `onFormChange`, keeping the parent teams array as the source of truth for persisted role assignments.
- Role value is lowercased for the dropdown option value while preserving the original casing for the label.
