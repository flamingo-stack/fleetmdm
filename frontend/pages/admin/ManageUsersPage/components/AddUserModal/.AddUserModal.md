A modal component that wraps `UserForm` to provide a standardized dialog for creating new users within the Fleet MDM interface.

## Key Components

### `IAddUserModalProps`
Props interface defining the modal's configuration:

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Callback fired when the modal is dismissed |
| `onSubmit` | `(formData: IUserFormData) => void` | Callback fired on successful form submission |
| `isPremiumTier` | `boolean` | Controls premium feature visibility |
| `smtpConfigured` | `boolean` | Enables email invite options when SMTP is set up |
| `sesConfigured` | `boolean` | Enables email invite options when SES is set up |
| `canUseSso` | `boolean` | Reflects organization-level SSO enablement |
| `addUserErrors` | `IUserFormErrors` | Validation errors passed down to the form |
| `isModifiedByGlobalAdmin` | `boolean` | Adjusts role/team options for global admin context |
| `currentTeam` | `ITeam` | Scopes the form to a specific team when provided |

### `AddUserModal` (default export)
A functional component rendering a large-width `Modal` titled **"Add user"**, pre-configured with `isNewUser` to distinguish creation from editing behavior.

## Usage Example

```typescript
<AddUserModal
  onCancel={() => setShowAddUserModal(false)}
  onSubmit={handleAddUser}
  availableTeams={teams}
  currentTeam={selectedTeam}
  defaultGlobalRole="observer"
  isPremiumTier={isPremiumTier}
  smtpConfigured={smtpConfigured}
  sesConfigured={sesConfigured}
  canUseSso={canUseSso}
  isModifiedByGlobalAdmin={currentUser?.global_role === "admin"}
  isUpdatingUsers={isUpdatingUsers}
  addUserErrors={userErrors}
/>
```

> **Note:** `availableTeams` falls back to an empty array if undefined, preventing runtime errors when no teams exist.
