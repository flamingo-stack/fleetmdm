Configuration module for the Users management table, defining column headers, row data shape, and helper functions that transform raw user and invite API responses into a unified table-ready format.

## Key Components

### Exported Interface

- **`IUserTableData`** — Unified row shape for both active users and pending invites, including prefixed `id` (e.g., `"user-3"`, `"invite-1"`) for react-table keys and numeric `apiId` for API calls.

### Exported Functions

- **`generateTableHeaders(actionSelectHandler, isPremiumTier)`** — Builds the column definitions array. Conditionally inserts a **Fleets** column at index 2 for premium-tier deployments. Renders role-specific tooltips for `GitOps` and `Observer+` roles, and suppresses email/password-reset actions for API-only users.
- **`combineDataSets(users, invites, currentUserId)`** — Merges enhanced user and invite arrays into a single `IUserTableData[]` for the table.

### Internal Helpers

| Function | Purpose |
|---|---|
| `enhanceUserData` | Maps `IUser[]` → `IUserTableData[]`, resolving role, team, status, and action options |
| `enhanceInviteData` | Maps `IInvite[]` → `IUserTableData[]` with invite-specific action constraints |
| `generateStatus` | Returns `"Active"`, `"Invite pending"`, or `"No access"` based on role/team assignment |
| `generateActionDropdownOptions` | Filters available actions (Edit, Password Reset, Reset Sessions, Delete) based on current user, SSO, and API-only flags |

## Usage Example

```typescript
import {
  generateTableHeaders,
  combineDataSets,
  IUserTableData,
} from "./UsersTableConfig";

// Build columns — adds "Fleets" column on premium tier
const columns = generateTableHeaders(
  (action, user: IUserTableData) => handleUserAction(action, user),
  isPremiumTier
);

// Merge users + pending invites into table rows
const tableData = combineDataSets(users, invites, currentUser.id);
```
