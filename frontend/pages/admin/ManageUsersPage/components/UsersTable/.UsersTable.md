Renders the admin users management table, combining Fleet users and pending invites into a unified, searchable list with row-level actions for editing, deleting, resetting passwords, and resetting sessions.

## Key Components

| Export / Symbol | Description |
|---|---|
| `UsersTable` | Default export — the primary table component for `/admin/users` |
| `ADD_USER_OPTIONS` | Dropdown config offering "Regular user" and "API-only user" creation paths |
| `EmptyUsersTable` | Fallback UI rendered when no users match the current search criteria |

**State managed internally:**
- `showDeleteUserModal`, `showResetPasswordModal`, `showResetSessionsModal` — modal visibility flags
- `userEditing` — tracks which `IUserTableData` row triggered an action
- `querySearchText` — bound to the table search input, drives API refetches

**Data sources (via `react-query`):**
- `usersAPI.loadAll` — fetches active Fleet users
- `invitesAPI.loadAll` — fetches pending invites

Both queries are keyed on `querySearchText` and merged via `combineDataSets` from `UsersTableConfig`.

## Usage Example

```typescript
import UsersTable from "pages/admin/UserManagementPage/components/UsersTable";
import { InjectedRouter } from "react-router";

// Rendered inside an admin route component
const UserManagementPage = ({ router }: { router: InjectedRouter }) => {
  return (
    <div>
      <h1>Users</h1>
      <UsersTable router={router} />
    </div>
  );
};
```

**Action routing:**

| Action value | Behaviour |
|---|---|
| `"edit"` | Navigates to `PATHS.ADMIN_USERS_EDIT`, appending `?type=invite` for pending invites |
| `"delete"` | Opens `DeleteUserModal`; calls `invitesAPI.destroy` or `usersAPI.destroy` based on row type |
| `"passwordReset"` | Opens `ResetPasswordModal`; calls `usersAPI.requirePasswordReset` |
| `"resetSessions"` | Opens `ResetSessionsModal`; removes auth token and redirects if acting on the current user |
| `"editMyAccount"` | Navigates to `PATHS.ACCOUNT` |

## Notes

- Requires `AppContext` (`currentUser`, `isPremiumTier`) and `NotificationContext` (`renderFlash`) to be present in the tree.
- `isPremiumTier` is forwarded to `generateTableHeaders` to conditionally show premium-only columns.
- Resetting sessions for the **current user** removes the auth token and redirects to `PATHS.ROOT` after 500 ms.
