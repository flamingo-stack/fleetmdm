Admin page component for editing existing users and pending invites, supporting both human users and API-only user types with role and team management.

## Key Components

### `EditUserPage`
The default exported React component that handles the full edit flow for users and invites.

**Props (`IEditUserPageProps`):**
- `router` — `InjectedRouter` for programmatic navigation
- `params.user_id` — ID of the user or invite to edit
- `location.query.type` — Set to `"invite"` when editing a pending invite

**Key behaviors:**
- Detects entity type (user vs. invite) via `location.query.type`
- Conditionally fetches user, invite, and team data using `react-query`
- Renders `ApiUserForm` for `api_only` users, `UserForm` for all others (including invites)
- Only loads teams data on premium tier instances

### `handleHumanUserSubmit`
Handles form submission for regular users and invites. Sends only changed fields to the API, handles email confirmation messaging, and maps API errors (duplicate email, password policy) to inline form errors.

### `handleApiUserSubmit`
Handles form submission for API-only users, including fleet role mapping and endpoint permissions via `usersAPI.updateApiOnlyUser`.

## Usage Example

```typescript
// Rendered via router at /admin/users/:user_id/edit
// ?type=invite triggers invite editing mode

<EditUserPage
  router={router}
  params={{ user_id: "42" }}
  location={{ query: { type: "invite" } }} // omit for regular user
/>
```
