Unit tests for the `userManagementHelpers` module, specifically validating the `generateUpdateData` function's diff logic between existing user data and updated form submissions.

## Key Components

- **`generateUpdatedData` test suite** — Verifies that `generateUpdateData` returns only the fields that differ between the current user state and new form data, omitting unchanged values.

## Usage Example

```typescript
// What the tested helper does under the hood:
const updatedData = userManagementHelpers.generateUpdateData(
  createMockUser({ role: "Observer", global_role: null }),
  formData
);

// Returns only changed fields:
// { email: "newemail@test.com", global_role: "admin", teams: [...] }
// Fields like `name` and `sso_enabled` are omitted if unchanged
```

## Test Coverage

| Scenario | Expected Behavior |
|---|---|
| Email differs from mock user | Included in result |
| `global_role` differs (`null` → `"admin"`) | Included in result |
| Teams array provided | Included in result |
| Unchanged fields (`name`, `sso_enabled`) | Omitted from result |
