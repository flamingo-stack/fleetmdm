Utility module providing helper functions for user management operations, including form data diffing for PATCH updates and dynamic role option generation based on tier and user type.

## Key Components

### `generateUpdateData(currentUserData, formData)`
Compares an existing user/invite against form submission data and returns only the changed fields. Designed for efficient PATCH requests by omitting unchanged attributes.

**Updatable fields:** `global_role`, `teams`, `name`, `email`, `sso_enabled`, `mfa_enabled`

### `roleOptions({ isPremiumTier, isApiOnly })`
Returns a `CustomOptionType[]` array of role dropdown options, conditionally including premium and API-only roles:

| Role | Tier |
|---|---|
| Observer | All tiers |
| Observer+ | Premium only |
| Technician | Premium only |
| GitOps | Premium + API-only |
| Maintainer | All tiers |
| Admin | All tiers |

### `IRoleOptionsParams`
```typescript
interface IRoleOptionsParams {
  isPremiumTier?: boolean;
  isApiOnly?: boolean;
}
```

## Usage Example

```typescript
import userManagementHelpers, { roleOptions } from "./userManagementHelpers";

// Generate only changed fields for a PATCH request
const updatePayload = userManagementHelpers.generateUpdateData(
  currentUser,   // IUser | IInvite
  formData       // IUserFormData
);
// updatePayload only contains fields that differ from currentUser

// Populate a role dropdown for a premium API-only user
const options = roleOptions({ isPremiumTier: true, isApiOnly: true });
// Returns: Observer, Observer+, Technician, GitOps, Maintainer, Admin
```
