A React component that renders a custom 404 "Not Found" error page with themed background imagery, navigation back to the dashboard, and support action buttons.

## Key Components

- **`Fleet404`** — Default-exported functional component rendering the full 404 error page UI
- **`isDarkMode()`** — Utility used to conditionally switch between light and dark background SVGs
- **`fleetLogoText`** — SVG logo linked to the dashboard via `PATHS.DASHBOARD`
- **`backgroundImg` / `backgroundImgDark`** — Theme-aware 404 illustration assets
- **`SUPPORT_LINK`** — Constant resolving to the Fleet Slack support URL
- **`Button`** — Shared button component used for the Slack and GitHub issue CTAs

## Usage Example

```typescript
import Fleet404 from "components/Fleet404";

// Typically registered as a catch-all route in the router
<Route path="*" element={<Fleet404 />} />
```

## Rendered Structure

```text
┌──────────────────────────────────────┐
│ [Fleet Logo] → Dashboard             │  ← <header>
│                                      │
│        [404 SVG Illustration]        │
│                                      │
│  404: Oops, sorry we can't find...   │  ← <main>
│  The page you are looking for...     │
│                                      │
│  [Slack: Get help] [GitHub: Issue]   │
└──────────────────────────────────────┘
```

The background illustration automatically switches between `404.svg` and `404-dark.svg` based on the user's active theme, detected at render time via `isDarkMode()`.
