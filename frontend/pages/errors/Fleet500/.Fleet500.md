A React component that renders a styled 500 Internal Server Error page with support links and dark mode support.

## Key Components

- **`Fleet500`** — Default export; a functional React component that displays a full-page error UI with:
  - A header linking back to the dashboard with the Fleet logo
  - A theme-aware background illustration (light/dark mode via `isDarkMode()`)
  - A Slack support button linking to `SUPPORT_LINK`
  - A GitHub issue creation button linking to the FleetDM bug report template

## Usage Example

```typescript
import Fleet500 from "components/Fleet500";

// Render directly within a route for 500 error handling
const App = () => (
  <Routes>
    <Route path="/500" element={<Fleet500 />} />
  </Routes>
);
```

## Notes

- Uses `isDarkMode()` from `utilities/theme` to conditionally swap the background SVG between light (`500.svg`) and dark (`500-dark.svg`) variants.
- The GitHub issue link pre-populates labels (`bug`, `:reproduce`) and uses the `bug-report.md` template from the upstream `fleetdm/fleet` repository.
- The `SUPPORT_LINK` constant (from `utilities/constants`) controls the Slack support URL.
- All external links use `target="_blank"` with `rel="noopener noreferrer"` for security.
- Styled via BEM-style class names under the `fleet-500` base class.
