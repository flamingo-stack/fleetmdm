React component that renders a 403 Access Denied error page with Fleet branding, dark mode support, and a link back to the dashboard.

## Key Components

- **`Fleet403`** — Default export; a functional React component displaying an access denied message with the Fleet logo header and themed background image.
- **`isDarkMode()`** — Utility used to conditionally swap between light and dark 403 background SVGs.
- **`PATHS.DASHBOARD`** — Router path used for the Fleet logo's home link.

## Usage Example

```typescript
import Fleet403 from "components/Fleet403";

// Render in a route guard or error boundary
const ProtectedRoute = ({ hasAccess }: { hasAccess: boolean }) => {
  if (!hasAccess) return <Fleet403 />;
  return <Outlet />;
};
```

## Notes

- Applies the `fleet-403` CSS base class for scoped styling.
- Automatically adapts to dark mode via `isDarkMode()`, serving `403-dark.svg` or `403.svg` accordingly.
- The Fleet logo in the header links back to `PATHS.DASHBOARD` for easy navigation recovery.
