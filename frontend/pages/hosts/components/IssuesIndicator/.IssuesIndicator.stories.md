Storybook stories file for the `IssuesIndicator` component, defining default metadata and a basic story with sample issue counts.

## Key Components

- **`meta`** — Storybook metadata object configuring the component title (`Components/IssuesIndicator`), the target component, and shared default args including `totalIssuesCount`, `criticalVulnerabilitiesCount`, and `failingPoliciesCount`
- **`Basic`** — A baseline story that renders `IssuesIndicator` with the default args (5 total issues, 3 critical vulnerabilities, 2 failing policies)

## Usage Example

```typescript
// Extend the Basic story with custom args
export const HighSeverity: Story = {
  args: {
    totalIssuesCount: 10,
    criticalVulnerabilitiesCount: 8,
    failingPoliciesCount: 2,
  },
};

// Render with no issues
export const NoIssues: Story = {
  args: {
    totalIssuesCount: 0,
    criticalVulnerabilitiesCount: 0,
    failingPoliciesCount: 0,
  },
};
```

## Notes

- Stories are located at [`frontend/.../IssuesIndicator.stories.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/IssuesIndicator/IssuesIndicator.stories.tsx)
- Default args apply to all stories unless overridden at the story level
- Add new stories by exporting additional `StoryObj<typeof IssuesIndicator>` objects with custom `args`
