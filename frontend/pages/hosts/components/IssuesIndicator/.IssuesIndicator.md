Displays a tooltip-enhanced issues indicator icon showing the total count of host issues, with a breakdown of critical vulnerabilities and failing policies on hover.

## Key Components

### `IIssuesIndicatorProps`
| Prop | Type | Description |
|------|------|-------------|
| `totalIssuesCount` | `number` | Aggregate count displayed next to the icon |
| `failingPoliciesCount` | `number` | Failing policy count shown in tooltip |
| `criticalVulnerabilitiesCount` | `number` | Critical CVE count shown in tooltip (Premium only) |
| `tooltipPosition` | `PlacesType` | Tooltip placement; defaults to `"top"` |
| `rowId` | `string \| number` | Appends a scoped BEM modifier class for row-level targeting |

### `IssuesIndicator`
Default export. Renders an `error-outline` icon alongside the total count, wrapped in a `TooltipWrapper` that surfaces a breakdown of critical vulnerabilities and/or failing policies.

## Usage Example

```typescript
import IssuesIndicator from "components/IssuesIndicator";

// Basic usage in a host table row
<IssuesIndicator
  totalIssuesCount={5}
  failingPoliciesCount={3}
  criticalVulnerabilitiesCount={2}
  tooltipPosition="bottom"
  rowId={host.id}
/>

// Policy failures only (no premium critical CVEs)
<IssuesIndicator
  totalIssuesCount={2}
  failingPoliciesCount={2}
  rowId="host-42"
/>
```

> **Note:** `criticalVulnerabilitiesCount` is a Premium-only feature. If omitted, the tooltip will only display the failing policies line. Both lines are conditionally rendered — the `<br />` separator only appears when both counts are present.
