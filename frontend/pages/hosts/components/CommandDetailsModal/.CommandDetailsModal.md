Renders a modal dialog that fetches and displays detailed results for a single MDM command, including status icon, request payload, and host response.

## Key Components

### Exports
- **`CommandResultsModal`** *(default)* — Main modal component that queries command results via `react-query` and renders them with loading, error, and success states.
- **`GetIconName`** — Maps an MDM command status string (`"Acknowledged"`, `"Error"`, `"Pending"`, `"NotNow"`, `"CommandFormatError"`) to an `IconNames` value for use with `IconStatusMessage`.

### Internal Helpers
- **`getStatusMessage`** — Returns a descriptive React node with host name, command type, and relative timestamp based on command status.
- **`defaultModalContentBody`** — Renders the default `IconStatusMessage` status block; used when no custom `contentBody` prop is provided.
- **`ModalContent`** — Internal display component that handles loading/error states and renders the status body alongside optional request payload and host response `InputField` text areas.

### Props (`ICommandResultsModalProps`)
| Prop | Type | Description |
|---|---|---|
| `command` | `{ host_uuid?, command_uuid }` | Identifies the target command; omitting `host_uuid` uses the host-agnostic endpoint |
| `contentBody` | `(baseClass, result) => ReactNode` | Optional override for the status content area |
| `title` | `string` | Modal title (defaults to `"MDM command details"`) |
| `onDone` | `() => void` | Callback for modal close/exit |

## Usage Example

```typescript
import CommandResultsModal from "components/CommandDetailsModal";

<CommandResultsModal
  command={{
    host_uuid: "abc-123",
    command_uuid: "cmd-xyz-456",
  }}
  onDone={() => setShowModal(false)}
/>

// With a custom status body
<CommandResultsModal
  command={{ command_uuid: "cmd-xyz-456" }}
  title="Custom Command Details"
  contentBody={(baseClass, result) => (
    <p className={`${baseClass}__custom`}>Status: {result.status}</p>
  )}
  onDone={() => setShowModal(false)}
/>
```

> **Note:** Base64-encoded `payload` and `result` fields returned by the API are decoded via `atob()` before rendering.
