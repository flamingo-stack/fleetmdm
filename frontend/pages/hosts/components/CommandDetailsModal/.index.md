Barrel export file that re-exports the default component and named utility from the `CommandDetailsModal` module.

## Key Components

| Export | Type | Description |
|---|---|---|
| `default` | Component | The `CommandDetailsModal` component |
| `GetIconName` | Function | Utility for resolving icon names within command details |

## Usage Example

```typescript
import CommandDetailsModal, { GetIconName } from "./CommandDetailsModal";

// Use the modal component
<CommandDetailsModal command={selectedCommand} onClose={handleClose} />

// Use the icon utility independently
const icon = GetIconName(command.platform);
```
