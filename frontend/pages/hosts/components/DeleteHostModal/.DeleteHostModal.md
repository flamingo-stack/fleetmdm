A confirmation modal component for deleting one or more hosts from Fleet, displaying contextual warnings and associated data removal notices.

## Key Components

### `IDeleteHostModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `onSubmit` | `() => void` | Callback fired on delete confirmation |
| `onCancel` | `() => void` | Callback fired on cancellation |
| `isAllMatchingHostsSelected` | `boolean?` | Manage hosts page: all filter-matched hosts selected |
| `selectedHostIds` | `number[]?` | Manage hosts page: IDs of selected hosts |
| `hostsCount` | `number?` | Manage hosts page: total matching host count |
| `hostName` | `string?` | Host details page: name of the single host |
| `isUpdating` | `boolean` | Shows loading state on the Delete button |

### `hostText()`
Internal helper that resolves the display label — either a pluralized count (with `+` suffix when total is unknown) for bulk deletions, or the individual `hostName`.

### `hasManyHosts`
Flags bulk deletions of 500+ hosts to render an additional latency warning paragraph.

## Usage Example

```typescript
// Manage Hosts page — bulk delete
<DeleteHostModal
  onSubmit={handleBulkDelete}
  onCancel={() => setShowModal(false)}
  isAllMatchingHostsSelected={true}
  selectedHostIds={[1, 2, 3]}
  hostsCount={620}
  isUpdating={isDeletingHosts}
/>

// Host Details page — single host
<DeleteHostModal
  onSubmit={handleDelete}
  onCancel={() => setShowModal(false)}
  hostName="macbook-pro-123"
  isUpdating={isDeletingHost}
/>
```

> **Note:** The modal always warns that desktop/mobile agents may cause deleted hosts to re-appear, linking to the Fleet uninstall guide at `LEARN_MORE_ABOUT_BASE_LINK/uninstall-fleetd`.
