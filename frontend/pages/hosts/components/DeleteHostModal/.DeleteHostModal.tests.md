Test suite for the `DeleteHostModal` component, verifying correct rendering of host counts, host names, and conditional warning messages based on selection state.

## Key Components

- **`DeleteHostModal` test suite** — Four test cases covering the modal's display logic under different prop combinations.

## Test Cases

| Test | Props | Expected Output |
|---|---|---|
| Multiple selected hosts | `selectedHostIds=[1,2,3]` | `"3 hosts"` visible |
| Single host by name | `hostName="Host1"` | `"Host1"` visible |
| All matching hosts selected | `isAllMatchingHostsSelected`, `hostsCount=50` | `"50 hosts"` visible |
| Large batch (≥500) + all matching | `isAllMatchingHostsSelected`, `hostsCount=500` | `"500 hosts"` + warning message visible |

## Usage Example

```typescript
// Running the test suite
// Ensure DeleteHostModal renders correct host counts

render(
  <DeleteHostModal
    selectedHostIds={[1, 2, 3]}
    hostsCount={500}
    isAllMatchingHostsSelected
    onSubmit={noop}
    onCancel={noop}
    isUpdating={false}
  />
);

// Verifies both the count label and the large-volume warning
expect(screen.getByText("500 hosts")).toBeVisible();
expect(
  screen.getByText(
    "When deleting a large volume of hosts, it may take some time for this change to be reflected in the UI."
  )
).toBeVisible();
```

## Notes

- Uses `@testing-library/react` for DOM-based assertions
- `noop` from `lodash` is used as a no-op placeholder for `onSubmit` and `onCancel` callbacks
- The large-volume warning threshold is **500 hosts** and only appears when `isAllMatchingHostsSelected` is `true`
