Test suite for the `TransferHostModal` component, validating rendering behavior, team filtering logic, form submission, and cancellation interactions.

## Key Components

### `setup()` Helper
A factory function that renders `TransferHostModal` with sensible defaults and returns `{ user, onSubmit, onCancel }` for test interaction. Accepts partial prop overrides via spread.

### Test Fixtures
- `teams`: Two mock `ITeam` objects (`Team Alpha` id=1, `Team Beta` id=2) used across all test cases.

### Test Cases

| Test | Description |
|---|---|
| Single host label | Verifies `"Transfer host to:"` label renders |
| Multiple hosts label | Verifies `"Transfer selected hosts to:"` when `multipleHosts=true` |
| Global admin link | `"Create a fleet"` link visible only for `isGlobalAdmin=true` |
| Transfer button disabled | Button is disabled until a team is selected |
| Current team filtered | Host's current team (`hostsTeamId`) is excluded from dropdown |
| No-team host filtering | `"Unassigned"` option hidden when host already has no team (`hostsTeamId=0`) |
| Submit with team | Enables Transfer button after selection; calls `onSubmit` once |
| Submit with no-team | Selecting `"Unassigned"` enables Transfer and calls `onSubmit` |
| Cancel | Clicking Cancel calls `onCancel` once |

## Usage Example

```typescript
// Run all tests
npx jest TransferHostModal.tests.tsx

// Run a specific test by name
npx jest --testNamePattern="filters out current host team"
```
