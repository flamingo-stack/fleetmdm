A modal dialog component for transferring one or more hosts to a different Fleet team, including an "Unassigned" option.

## Key Components

- **`TransferHostModal`** – Default export; renders a modal with a searchable team dropdown and Transfer/Cancel action buttons.
- **`ITransferHostModal`** – Props interface defining teams list, submission/cancellation handlers, loading state, and optional multi-host/current-team context.
- **`createTeamDropdownOptions()`** – Builds dropdown options, filtering out the host's current team and conditionally prepending the "Unassigned" option (unavailable if the host is already unassigned).
- **`onChangeSelectTeam()`** – Handles dropdown selection, mapping the string dropdown value back to a typed `ITeam` or the no-team sentinel object.
- **`NO_TEAM_OPTION`** – Constant representing the "Unassigned" transfer target with value `"no-team"`.

## Usage Example

```typescript
import TransferHostModal from "components/TransferHostModal";

<TransferHostModal
  isGlobalAdmin={true}
  teams={availableTeams}
  hostsTeamId={currentTeamId}
  multipleHosts={selectedHostIds.length > 1}
  isUpdating={isTransferring}
  onSubmit={(team) => handleTransfer(selectedHostIds, team)}
  onCancel={() => setShowModal(false)}
/>
```

**Behavior notes:**
- The dropdown excludes the host's current team to prevent no-op transfers.
- The **Transfer** button is disabled until a team is selected.
- Global admins see a "Create a fleet" link pointing to `PATHS.ADMIN_FLEETS` when their target fleet is missing.
- Passes the raw `ITeam` object (or `{ id: "no-team" }`) to `onSubmit`; callers should handle the no-team sentinel to unassign the host.
