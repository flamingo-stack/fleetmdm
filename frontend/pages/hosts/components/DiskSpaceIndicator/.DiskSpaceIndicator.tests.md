Test suite for the `DiskSpaceIndicator` component, validating rendering states, color-coded thresholds, sentinel value handling, and tooltip behavior across platforms.

## Key Components

- **`describe("Disk space Indicator")`** — Top-level test suite covering all indicator states
- **Color constants** — `errStyle`, `warningStyle`, `okayStyle` derived from `COLORS` design tokens for threshold assertions
- **Test cases:**
  - Sentinel value `-1` renders "Not supported" text
  - Distinguishes zero storage (disk full → "No data available") from unsupported (`-1` → "Not supported")
  - Any negative value other than `-1` is treated as unsupported
  - Warning (yellow) tooltip for `<32 GB` on `darwin`/`windows`
  - Error (red) tooltip for `<16 GB` on `darwin`/`windows`
  - OK (green) tooltip for `≥33 GB` on `darwin`/`windows`
  - Linux-specific tooltip showing system disk and all-partitions breakdown

## Usage Example

```typescript
// Running the tests
npx jest DiskSpaceIndicator.tests.tsx

// Example assertion pattern used in suite
const { user } = renderWithSetup(
  <DiskSpaceIndicator
    gigsDiskSpaceAvailable={5}
    percentDiskSpaceAvailable={2}
    platform="windows"
    tooltipPosition="bottom"
  />
);

const section = screen.getByTestId("section-0");
expect(section).toHaveStyle(`background-color: ${COLORS["ui-error"]}`);

await user.hover(section);
await waitFor(() => {
  expect(
    screen.getByText("Not enough disk space available to install most small operating systems updates.")
  ).toBeInTheDocument();
});
```

## Threshold Reference

| Available Disk | Color  | Platform        | Tooltip Message                        |
|---------------|--------|-----------------|----------------------------------------|
| `< 16 GB`     | Red    | darwin/windows  | Not enough space for small OS updates  |
| `< 32 GB`     | Yellow | darwin/windows  | Not enough space for large OS updates  |
| `≥ 32 GB`     | Green  | darwin/windows  | Enough space for OS updates            |
| `= -1`        | —      | any             | "Not supported"                        |
| `= 0`         | —      | any             | "No data available"                    |
