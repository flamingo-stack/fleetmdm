Storybook stories file for the `DiskSpaceIndicator` component, providing interactive visual documentation and development sandbox for the component.

## Key Components

- **`meta`** — Storybook metadata configuration registering the component under `Components/DiskSpaceIndicator` with default args
- **`Basic`** — A baseline story rendering the component with default props (100 GB available, 75% free, `darwin` platform)

## Usage Example

```typescript
// Extend with custom stories for other scenarios
import { StoryObj } from "@storybook/react";
import DiskSpaceIndicator from "./DiskSpaceIndicator";

export const LowDiskSpace: StoryObj<typeof DiskSpaceIndicator> = {
  args: {
    gigsDiskSpaceAvailable: 5,
    percentDiskSpaceAvailable: 3,
    platform: "darwin",
  },
};

export const WindowsPlatform: StoryObj<typeof DiskSpaceIndicator> = {
  args: {
    gigsDiskSpaceAvailable: 50,
    percentDiskSpaceAvailable: 40,
    platform: "windows",
  },
};
```

## Props (Default Args)

| Prop | Default | Description |
|---|---|---|
| `gigsDiskSpaceAvailable` | `100` | Available disk space in gigabytes |
| `percentDiskSpaceAvailable` | `75` | Percentage of disk space remaining |
| `platform` | `"darwin"` | Target OS platform |
