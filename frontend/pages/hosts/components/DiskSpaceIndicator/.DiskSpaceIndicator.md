Renders a visual disk space indicator combining a color-coded progress bar with contextual tooltip messaging, adapting its display logic based on the host platform (macOS, Windows, or Linux-like).

## Key Components

### `IDiskSpaceIndicatorProps`
| Prop | Type | Description |
|------|------|-------------|
| `gigsDiskSpaceAvailable` | `number \| "---"` | Free disk space in GB; `-1` signals unsupported, `"---"` signals no data |
| `percentDiskSpaceAvailable` | `number` | Percentage of free disk space (0–100) used to size the progress bar |
| `gigsTotalDiskSpace` | `number` (optional) | Total system disk size in GB (used in Linux tooltip) |
| `gigsAllDiskSpace` | `number` (optional) | Combined size across all partitions (used in Linux tooltip) |
| `platform` | `string` | Host platform identifier (e.g., `"darwin"`, `"windows"`, `"linux"`) |
| `tooltipPosition` | `PlacesType` | Tooltip placement; defaults to `"top"` |

### Color Thresholds (macOS / Windows only)
| Available Space | Color |
|----------------|-------|
| `< 16 GB` | `ui-error` (red) |
| `< 32 GB` | `ui-warning` (yellow) |
| `≥ 32 GB` | `status-success` (green) |

Linux-like platforms always render green regardless of available space.

## Usage Example

```typescript
<DiskSpaceIndicator
  gigsDiskSpaceAvailable={24}
  percentDiskSpaceAvailable={45}
  gigsTotalDiskSpace={256}
  platform="darwin"
  tooltipPosition="bottom"
/>
```

**Edge case handling:**
- `gigsDiskSpaceAvailable === -1` → renders `<NotSupported />`
- `gigsDiskSpaceAvailable === 0 || "---"` → renders `"No data available"`
- Linux hosts receive a tooltip showing system disk and partition totals instead of the threshold-based warning messages used for macOS/Windows.
