A modal component that displays script details including content, download, delete, and run actions for Fleet MDM scripts.

## Key Components

- **`ScriptDetailsModal`** – Default export; a modal that renders script content with contextual action buttons based on user role and view context
- **`IScriptDetailsModalProps`** – Interface defining props including script selection, content loading states, and action callbacks
- **`PartialOrFullHostScript`** – Union type supporting both partial (`script_id`, `name`) and full `IHostScript` objects
- **`renderContent()`** – Renders a spinner, error state, or the script `Textarea` with optional help text
- **`renderFooter()`** – Renders download/delete icon buttons and primary actions (close, "More actions" dropdown)
- **`onClickDownload()`** – Downloads script content as a dated file using `FileSaver`
- **`onSelectMoreActions()`** – Handles dropdown actions: `showRunDetails` and `run`

## Usage Example

```typescript
<ScriptDetailsModal
  onCancel={() => setModalOpen(false)}
  onDelete={handleDelete}
  selectedScriptId={42}
  selectedScriptDetails={{ script_id: 42, name: "restart-agent.sh" }}
  selectedScriptContent="#!/bin/bash\necho hello"
  showHostScriptActions
  runScriptHelpText
  onClickRun={(script) => handleRun(script)}
  onClickRunDetails={(execId) => openRunDetails(execId)}
  teamIdForApi={3}
/>
```

## Notes

- Script content is fetched via `react-query` (`scriptAPI.downloadScript`) only when `selectedScriptContent` is not provided and a valid `scriptId` is resolved
- Scroll detection (`isTopScrolling`) drives `ModalFooter` shadow behavior
- Delete button is wrapped in `GitOpsModeTooltipWrapper` to disable it in GitOps mode
- `suppressSecondaryActions` hides download/delete buttons; `customPrimaryButtons` overrides the default close/actions footer
