Provides utility functions for resolving and displaying host enrollment status values within the Fleet MDM host management interface.

## Key Components

- **`getHostStatusTooltipText(status)`** — Returns a human-readable tooltip string based on a host's current status. Handles three cases: `"online"`, pending enrollment (empty cell value), and offline.
- **`getHostStatus(status, mdmEnrollmentStatus?)`** — Resolves the effective display status of a host. Returns the default empty cell value when MDM enrollment is `"Pending"`, otherwise falls back to the raw status or the empty cell default.

## Usage Example

```typescript
import { getHostStatus, getHostStatusTooltipText } from "./helpers";

const status = getHostStatus("online", "Pending");
// Returns: DEFAULT_EMPTY_CELL_VALUE (enrollment not yet complete)

const status2 = getHostStatus("offline");
// Returns: "offline"

const tooltip = getHostStatusTooltipText("online");
// Returns: "Online hosts will respond to a live report."

const pendingTooltip = getHostStatusTooltipText(DEFAULT_EMPTY_CELL_VALUE);
// Returns: "Device is pending enrollment in Apple Business and status is not yet available."
```

## Notes

- MDM `"Pending"` enrollment overrides any reported status, reflecting that the device has not yet completed Apple Business Manager enrollment.
- Both functions depend on `DEFAULT_EMPTY_CELL_VALUE` from `utilities/constants` as a sentinel value for unknown or unavailable states.
