Provides helper functions and configuration logic for determining which host action menu options (Transfer, Lock, Wipe, etc.) are available based on host platform, MDM enrollment state, and user role permissions.

## Key Components

### `IHostActionConfigOptions`
Configuration interface containing all contextual flags needed to evaluate action availability:
- Role flags: `isGlobalAdmin`, `isTeamMaintainer`, `isTeamTechnician`, etc.
- MDM state: `isEnrolledInMdm`, `isConnectedToFleetMdm`, `hostMdmDeviceStatus`, `hostMdmEnrollmentStatus`
- Feature flags: `isPremiumTier`, `isPrimoMode`, `hostScriptsEnabled`

### Permission Gate Functions

| Function | Description |
|---|---|
| `canTransferTeam` | Premium + global admin/maintainer/technician only, no Primo mode |
| `canTurnOffMdm` | macOS (Mac MDM) or Android BYO; blocked during pending Android actions |
| `canQueryHost` | Excludes iOS, iPadOS, and Android (mobile platforms) |
| `canLockHost` | Premium; platform-specific MDM enrollment checks; status must be `unlocked` |
| `canWipeHost` | Premium (Android COBO exempt); blocks account-driven iOS/iPadOS enrollment |
| `canUnlock` | Premium; macOS allows `unlocking` state; Windows/Linux/Apple only |
| `canDeleteHost` | Admin or maintainer roles only |
| `canShowDiskEncryption` | Premium; requires stored key; Apple needs Fleet MDM connection |
| `canShowRecoveryLockPassword` | Premium; macOS arm64 only; respects existing password availability |
| `canShowManagedAccount` | Premium; macOS ADE only; admin/maintainer roles |
| `canClearPasscode` | Premium; admin/maintainer; Android blocked during pending actions |

## Usage Example

```typescript
const options = generateHostActionOptions({
  hostPlatform: "darwin",
  hostCpuType: "arm64",
  isPremiumTier: true,
  isGlobalAdmin: true,
  isEnrolledInMdm: true,
  isConnectedToFleetMdm: true,
  isMacMdmEnabledAndConfigured: true,
  hostMdmDeviceStatus: "unlocked",
  hostMdmEnrollmentStatus: "On (automatic)",
  doesStoreEncryptionKey: true,
  isRecoveryLockPasswordEnabled: true,
  // ...other flags
});
```
