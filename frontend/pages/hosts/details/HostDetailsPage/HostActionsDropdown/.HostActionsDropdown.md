Renders a context-aware actions dropdown for a host detail view, computing available actions based on the current user's permissions, host state, and MDM enrollment status.

## Key Components

- **`IHostActionsDropdownProps`** — Interface defining all required and optional props including host metadata, MDM state, permission-relevant fields, and the `onSelect` callback
- **`HostActionsDropdown`** — Default export; a React functional component that:
  - Reads global app context (`AppContext`) for tier, role flags, and MDM configuration
  - Derives team-scoped permission flags via `permissions` utilities
  - Delegates option generation to `generateHostActionOptions` from `./helpers`
  - Renders `ActionsDropdown` with `"brand-button"` styling, or returns `null` if no options are available or the current user is not set

## Usage Example

```typescript
import HostActionsDropdown from "pages/hosts/details/HostActionsDropdown";

<HostActionsDropdown
  hostTeamId={42}
  hostStatus="online"
  hostMdmEnrollmentStatus="On (automatic)"
  hostMdmDeviceStatus="unlocked"
  isConnectedToFleetMdm={true}
  doesStoreEncryptionKey={true}
  hostPlatform="darwin"
  hostCpuType="arm64"
  hostScriptsEnabled={true}
  onSelect={(action) => handleHostAction(action)}
/>
```

## Notes

- Returns `null` in two cases: no authenticated `currentUser` in context, or `generateHostActionOptions` produces an empty list (e.g., observer-only role with no permitted actions)
- MDM-related options (lock, wipe, encryption key retrieval) are gated on platform, enrollment status, MDM configuration, and premium tier
