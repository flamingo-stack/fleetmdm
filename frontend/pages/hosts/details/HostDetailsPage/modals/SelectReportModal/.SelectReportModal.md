Modal component for selecting and running saved reports on a specific host, with support for filtering, permission-based access control, and navigation to report creation or editing flows.

## Key Components

### `SelectReportModal`

The default export. A modal dialog that fetches all schedulable queries (reports) scoped to a host's team and renders them as a selectable list.

**Props (`ISelectReportModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Callback to close the modal |
| `isOnlyObserver` | `boolean?` | Whether the current user is observer-only |
| `hostId` | `number` | ID of the host to run the report against |
| `hostTeamId` | `number \| null` | Team ID of the host (used for permission checks) |
| `router` | `InjectedRouter` | React Router v3 instance for navigation |
| `currentTeamId` | `number \| undefined` | Currently selected team context |

### Internal Logic

- **Permission handling** — distinguishes between global observer, observer-plus, and host-team-specific observer-plus to determine if the user can create new reports or only run `observer_can_run` reports.
- **Data fetching** — uses `react-query` to load reports via `queryAPI.loadAll`, scoped to the host's team or all teams (`API_ALL_TEAMS_ID`).
- **Filtering** — client-side case-insensitive name filter via `InputFieldWithIcon`.
- **Navigation** — pushes to `PATHS.NEW_REPORT` (custom) or `PATHS.EDIT_REPORT(id)` (saved) with `host_id` and `fleet_id` query params.

## Usage Example

```typescript
<SelectReportModal
  onCancel={() => setShowModal(false)}
  isOnlyObserver={false}
  hostId={42}
  hostTeamId={7}
  router={router}
  currentTeamId={7}
/>
```

## Rendered States

| State | UI |
|-------|----|
| Reports available | Filterable list of report buttons |
| No saved reports | `EmptyState` with optional "Create a report" link |
| Filter returns no matches | `EmptyState` with search hint |
| Fetch error | `<DataError />` component |
