A confirmation modal component that allows administrators to remotely lock a managed host, with platform-specific messaging and an end-user experience preview for iOS/iPadOS devices.

## Key Components

### `LockModal` (default export)
The primary modal component that handles host locking across all supported platforms (macOS, iOS, iPadOS, Android).

**Props (`ILockModalProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `id` | `number` | Host identifier used for the lock API call |
| `platform` | `string` | Host platform (`darwin`, `ios`, `ipados`, `android`) |
| `hostName` | `string` | Display name shown in the confirmation checkbox |
| `onSuccess` | `() => void` | Callback fired after a successful lock request |
| `onClose` | `() => void` | Callback fired when the modal is dismissed |

### `IosOrIpadLockPreview`
An internal sub-component that renders a visual card previewing the end-user lock screen experience for iPhone and iPad hosts. Displays a device image and a note about Organization name branding.

### `renderDescription()`
An internal function that returns platform-specific descriptive copy:
- **iOS/iPadOS** — Apple Lost Mode details and Wi-Fi disconnect warning
- **Android** — Lock screen PIN/password requirement note
- **macOS (`darwin`)** — Six-digit unlock PIN generation notice
- **Other** — Generic return-to-organization message

## Usage Example

```typescript
<LockModal
  id={host.id}
  platform={host.platform}
  hostName={host.display_name}
  onSuccess={() => {
    setShowLockModal(false);
    refetchHost();
  }}
  onClose={() => setShowLockModal(false)}
/>
```

The **Lock** button remains disabled until the user checks the confirmation checkbox. On submission, it calls `hostAPI.lockHost(id)` and surfaces a success or error flash notification via `NotificationContext`.
