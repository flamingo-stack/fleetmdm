A modal dialog component that displays bootstrap package installation failure details to the user.

## Key Components

- **`BootstrapPackageModal`** — Default export. A presentational modal that surfaces the name of a failed bootstrap package and its associated error details.
- **`IBootstrapPackageModalProps`** — Interface defining the component's props:
  - `packageName` — The name of the package that failed to install.
  - `details` — The error message or failure details string.
  - `onClose` — Callback invoked when the modal is dismissed (via button click, `Enter` key, or exit gesture).

## Usage Example

```typescript
import BootstrapPackageModal from "components/BootstrapPackageModal";

const MyPage = () => {
  const [showModal, setShowModal] = React.useState(true);

  return (
    <>
      {showModal && (
        <BootstrapPackageModal
          packageName="com.example.bootstrapconfig"
          details="Exit code 1: Permission denied while writing to /Library/Preferences"
          onClose={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- The component is purely presentational with no internal state.
- Both `onEnter` and `onExit` on the underlying `Modal` are wired to `onClose`, so keyboard (`Enter`) and escape/exit interactions close the modal consistently.
- CSS scoping uses the `bootstrap-package-modal` base class with BEM-style child selectors (`__package-name`, `__details`).
