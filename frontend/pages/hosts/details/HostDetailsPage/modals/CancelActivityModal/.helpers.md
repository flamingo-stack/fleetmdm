Utility module for mapping API error responses to user-friendly messages when canceling host activities.

## Key Components

- **`getErrorMessage(err: unknown): string`** — Maps HTTP error status codes to descriptive error messages for activity cancellation failures:
  - `404` → Activity already happened message
  - `400` → Lock/wipe cancellation restriction message
  - Default → Generic cancellation failure message

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await cancelActivity(activityId);
} catch (err) {
  const message = getErrorMessage(err);
  renderFlash("error", message);
}
```

## Error Messages

| Status | Message |
|--------|---------|
| `404` | Activity already happened; cannot cancel |
| `400` | Lock/wipe cannot be canceled if about to run |
| Default | Generic retry prompt |

> **Note:** The `400` message specifically guards against users losing host access by preventing cancellation of imminent lock/wipe operations.
