A modal component that allows users to cancel a pending host activity, displaying a preview of the activity and handling the cancellation API call with success/error notifications.

## Key Components

### `CancelActivityModal`
The default export — a React functional component that renders a confirmation modal for canceling an upcoming host activity.

**Props (`ICancelActivityModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `hostId` | `number` | The ID of the host owning the activity |
| `activity` | `IHostUpcomingActivity` | The upcoming activity to cancel |
| `onCancelActivity` | `(activity) => void` | Called after cancel attempt (success or failure) |
| `onSuccessCancel` | `(activity) => void` | Called only on successful cancellation |
| `onExit` | `() => void` | Called to close the modal |

### `onAttemptyCancel` (internal handler)
Calls `activitiesAPI.cancelHostActivity`, flashes a success or error notification, then invokes `onCancelActivity` and `onExit` regardless of outcome.

## Usage Example

```typescript
<CancelActivityModal
  hostId={42}
  activity={pendingActivity}
  onCancelActivity={(activity) => console.log("Cancel attempted", activity)}
  onSuccessCancel={(activity) => refetchActivities()}
  onExit={() => setShowCancelModal(false)}
/>
```

## Notes

- Uses `upcomingActivityComponentMap` to dynamically render the correct activity preview component based on `activity.type`, giving users context on what they are canceling.
- Warns users that in-progress activities **will still complete** on the host — only Fleet result reporting is suppressed.
- The cancel button enters a loading state during the API call via `isCanceling`, and both modal content and the button are disabled to prevent duplicate submissions.
