A confirmation modal component for initiating a remote wipe on a managed host, with platform-specific messaging and a required checkbox confirmation before the action can proceed.

## Key Components

- **`WipeModal`** — Default export; a React functional component that renders a modal dialog for wiping a host
- **`IWipeModalProps`** — Interface defining the component's props:
  - `id` — Host ID used to call the wipe API
  - `hostName` — Displayed in the confirmation checkbox label
  - `hostPlatform` — Used to detect Android hosts via `isAndroid()`
  - `isWindowsHost` / `isLinuxHost` — Control platform-specific UI copy
  - `onSuccess` / `onClose` — Callbacks for post-wipe success and modal dismissal
- **`onWipe`** — Async handler that calls `hostAPI.wipeHost(id)`, renders a flash notification on success or error, then closes the modal

## Usage Example

```typescript
import WipeModal from "components/WipeModal";

<WipeModal
  id={host.id}
  hostName={host.display_name}
  hostPlatform={host.platform}
  isWindowsHost={host.platform === "windows"}
  isLinuxHost={host.platform === "linux"}
  onSuccess={() => refetchHost()}
  onClose={() => setShowWipeModal(false)}
/>
```

## Behavior Notes

- The **Wipe** button is disabled until the user checks the `"I wish to wipe {hostName}"` checkbox
- Platform-specific copy is shown:
  - **Windows**: warns that a USB reinstall is required
  - **Linux**: shows an OS reinstall warning and links to `fleetdm.com/learn-more-about/linux-wipe`
  - **Android**: uses a "sent request" flash message variant
- Uses `NotificationContext` to surface success/error flash messages after the API call
