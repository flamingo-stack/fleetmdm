Test suite for the `RunScriptModal` component, covering empty states, table rendering, and error/loading conditions across different user roles and tier configurations.

## Key Components

- **`baseProps`** — Shared default props used across all test cases, providing a consistent starting point with empty script lists and no-op callbacks.
- **`describe("empty state")`** — Six role/tier-aware tests verifying the "Add a script" link visibility and `fleet_id` query parameter behavior.
- **`describe("table state")`** — Verifies the script table renders when scripts are present, replacing the empty state.
- **`describe("error and loading states")`** — Confirms the `DataError` component renders when `isError` is `true`.

## Coverage Highlights

| Scenario | Behavior Verified |
|---|---|
| Premium admin, host on team | Link shown with `fleet_id=<hostTeamId>` |
| Premium admin, unassigned host (`hostTeamId=null`) | Link shown with `fleet_id=0` |
| Free tier admin | Link shown without `fleet_id` |
| Global technician | Link hidden; guidance text shown |
| Team maintainer on host's team | Link shown |
| Team technician on host's team | Link hidden; guidance text shown |
| Scripts exist | Table rendered; empty state absent |
| `isError=true` | "Something's gone wrong" error rendered |

## Usage Example

```typescript
// Run all tests
npx jest RunScriptModal.tests.tsx

// Run a specific describe block
npx jest RunScriptModal.tests.tsx -t "empty state"
```
