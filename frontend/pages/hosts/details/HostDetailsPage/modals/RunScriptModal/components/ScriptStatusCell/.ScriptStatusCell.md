React table cell component that displays the execution status of a script run, rendering a status icon with tooltip based on the script's last execution result.

## Key Components

- **`STATUS_DISPLAY_CONFIG`** — A record mapping each `IScriptExecutionStatus` (`ran`, `pending`, `error`) to its display text, icon status, and tooltip factory function.
- **`ScriptStatusCell`** — Default export; a React component that accepts a `lastExecution` prop and renders either an empty `TextCell` (when `null`) or a `StatusIndicatorWithIcon` with a humanized timestamp tooltip.

## Usage Example

```typescript
import ScriptStatusCell from "components/ScriptStatusCell/ScriptStatusCell";

const lastExecution = {
  status: "ran",
  executed_at: "2024-06-01T12:00:00Z",
};

<ScriptStatusCell lastExecution={lastExecution} />
// Renders: ✅ "Ran" — tooltip: "Script ran and exited with exit code 0 (3 days ago)."

<ScriptStatusCell lastExecution={null} />
// Renders: empty cell
```

## Status Mapping

| Status    | Icon        | Tooltip                                              |
|-----------|-------------|------------------------------------------------------|
| `ran`     | `success`   | Exited with code 0, includes elapsed time            |
| `pending` | `pendingPartial` | Running or waiting for host to come online      |
| `error`   | `error`     | Exited with non-zero code, includes elapsed time     |

Elapsed time is computed via `date-fns` [`formatDistanceToNow`](https://date-fns.org/docs/formatDistanceToNow) with second-level precision.
