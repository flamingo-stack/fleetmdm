A modal component for running scripts on a host device, displaying a paginated table of available scripts with actions to run, view details, and navigate to script management.

## Key Components

- **`RunScriptModal`** – Main modal component (memoized) rendering host scripts in a table with contextual empty and error states
- **`IRunScriptModalProps`** – Interface defining all required props including pagination state, script response data, and action callbacks
- **`EmptyComponent`** – Minimal fragment used as the `TableContainer` empty state placeholder
- **`generateTableColumnConfigs`** – Imported utility that builds column definitions based on user permissions and script state
- **`onSelectAction`** – Memoized callback dispatching `showRunDetails` and `run` table row actions
- **`canAddScript`** – Permission gate (global/team admin or maintainer) controlling visibility of the "Add a script" link

## Usage Example

```typescript
<RunScriptModal
  currentUser={currentUser}
  hostTeamId={42}
  onClose={() => setShowModal(false)}
  page={page}
  setPage={setPage}
  hostScriptResponse={hostScriptResponse}
  isFetchingHostScripts={isFetching}
  isLoadingHostScripts={isLoading}
  isError={isError}
  onClickViewScript={(script) => openScriptDetails(script)}
  onClickRunDetails={(executionId) => openRunDetails(executionId)}
  onClickRun={(script) => runScript(script)}
  isRunningScript={isRunning}
  isHidden={false}
/>
```

## States

| Condition | Rendered Output |
|---|---|
| Loading | `<Spinner />` |
| Error | `<DataError />` |
| No scripts (admin) | Empty state with "Add a script" link to Controls > Scripts |
| No scripts (non-admin) | Empty state prompting user to contact admin |
| Scripts available | Paginated `<TableContainer>` with 10 items per page |
