Defines the table column configuration and action dropdown logic for the host scripts table, mapping script data to interactive Name, Status, and Actions columns.

## Key Components

- **`generateActionDropdownOptions`** — Builds the actions dropdown items (`Run`, `Show run details`) based on the current user's role/permissions and the script's last execution status. Disables "Run" if the script is pending.
- **`generateTableColumnConfigs`** — Returns the full column definition array (Name, Status, Actions) for the scripts table, wiring up click handlers and rendering `ScriptStatusCell`, `ActionsDropdown`, and truncated name buttons.
- **`IRowProps` / `ICellProps` / `IStatusCellProps` / `IActionsDropdownProps`** — Local cell prop interfaces typed against `IHostScript` and `ILastExecution`.

## Usage Example

```typescript
import {
  generateTableColumnConfigs,
  generateActionDropdownOptions,
} from "./ScriptsTableConfig";

// Generate dropdown options for a given script row
const options = generateActionDropdownOptions(currentUser, teamId, hostScript);

// Generate column configs for the table
const columns = generateTableColumnConfigs(
  currentUser,
  hostTeamId,
  scriptsDisabled,
  (script) => openScriptDetails(script),   // onClickViewScript
  (action, script) => handleAction(action, script) // onSelectAction
);
```

> **Note:** The "Run" action is gated behind a broad permission check covering admins, maintainers, observers, and technicians at both global and team scope. The `scriptsDisabled` flag replaces the `ActionsDropdown` with a static tooltip-wrapped span to avoid `react-select` styling constraints.
