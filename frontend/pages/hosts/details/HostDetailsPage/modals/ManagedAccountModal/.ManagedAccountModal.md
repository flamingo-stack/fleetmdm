A modal component for viewing and rotating a managed local account password on a specific host, displayed within the Fleet MDM interface.

## Key Components

**`ManagedAccountModal`** — Default export. Renders a modal that:
- Fetches the managed account password via `hostAPI.getManagedAccountPassword` using `react-query` (cache disabled to avoid retaining sensitive data)
- Displays the username (`_fleetadmin`) and a hidden password field via `InputFieldHiddenContent`
- Shows a pending-rotation banner when a rotation is in-flight or already requested
- Shows an auto-rotation schedule banner when `auto_rotate_at` is set
- Allows admins/maintainers (`canRotatePassword`) to trigger a password rotation via `hostAPI.rotateManagedLocalAccountPassword`

**Props (`IManagedAccountModalProps`)**

| Prop | Type | Description |
|---|---|---|
| `hostId` | `number` | ID of the target host |
| `canRotatePassword` | `boolean` | Controls visibility of the rotate button (Admin/Maintainer only) |
| `onCancel` | `() => void` | Called when the modal is closed |
| `onRotate` | `() => void` | Called after a successful rotation to trigger parent refetch |

## Usage Example

```typescript
<ManagedAccountModal
  hostId={42}
  canRotatePassword={currentUser.role === "admin"}
  onCancel={() => setShowModal(false)}
  onRotate={() => {
    refetchHostDetails();
    refetchActivities();
  }}
/>
```

## Notes

- Password data is intentionally not cached (`cacheTime: 0`) to avoid persisting sensitive values in memory
- Rotation is fire-and-forget on the host side; a pending banner is shown until the host acknowledges
