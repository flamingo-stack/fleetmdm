Test suite for the `ManagedAccountModal` component, verifying rendering, banner display logic, and password rotation behavior based on API responses.

## Key Components

- **`mockPasswordResponse`** — Base fixture providing a mock `getManagedAccountPassword` API response with `host_id`, `username`, `password`, and `updated_at`.
- **`hostAPI` mock** — Mocks `getManagedAccountPassword` and `rotateManagedLocalAccountPassword` via `jest.mock`.
- **`createCustomRenderer`** — Custom test renderer with `withBackendMock: true` for simulating backend interactions.

## Test Coverage

| Scenario | Assertion |
|---|---|
| Initial render | Username `_fleetadmin` and "Username" label are visible |
| `auto_rotate_at` present | Auto-rotate banner is shown |
| `auto_rotate_at` absent | Auto-rotate banner is not rendered |
| `canRotatePassword={false}` | "Rotate password" button is hidden |
| `canRotatePassword={true}` | "Rotate password" button is visible |
| Successful rotation | `rotateManagedLocalAccountPassword(7)` called; `onRotate` callback invoked |
| `pending_rotation: true` in response | Pending-rotation banner shown; auto-rotate banner suppressed |
| Rotation replaces auto-rotate banner | After clicking rotate, pending-rotation banner replaces auto-rotate banner |
| Rotation API error | `onRotate` is **not** called on failure |

## Usage Example

```typescript
// Run the test suite
npx jest ManagedAccountModal.tests.tsx

// Key mock pattern used across tests
(hostAPI.getManagedAccountPassword as jest.Mock).mockResolvedValue({
  ...mockPasswordResponse,
  managed_account_password: {
    ...mockPasswordResponse.managed_account_password,
    auto_rotate_at: "2026-04-30T14:35:00Z",
  },
});
```
