A modal component for clearing the passcode on a managed host, with platform-aware messaging for Android BYO, Android corporate, and other MDM-enrolled devices.

## Key Components

### `ClearPasscodeModal`
The default export. A confirmation modal that requires the user to check a confirmation checkbox before submitting a passcode clear request via the host API.

**Props (`IClearPasscodeModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `id` | `number` | Host ID used for the API call |
| `hostName` | `string` | Displayed in the confirmation checkbox label |
| `hostPlatform` | `string` | Determines Android-specific messaging |
| `hostMdmEnrollmentStatus` | `MdmEnrollmentStatus \| null` | Detects Android BYO (`"On (personal)"`) |
| `onExit` | `() => void` | Called on cancel or after the API call completes |
| `onSuccess` | `() => void` | Optional callback on successful passcode clear |

### Internal Behaviour
- **`renderBody()`** — Returns platform-specific warning text:
  - Android BYO → work profile passcode only
  - Android corporate → full device passcode
  - All others → generic physical-access warning
- Uses `isClearingPasscode` state to show a loading indicator on the submit button.
- Uses `confirmChecked` state to gate the submit button (disabled until checked).

## Usage Example

```typescript
<ClearPasscodeModal
  id={host.id}
  hostName={host.display_name}
  hostPlatform={host.platform}
  hostMdmEnrollmentStatus={host.mdm.enrollment_status}
  onExit={() => setShowClearPasscodeModal(false)}
  onSuccess={() => refetchHostDetails()}
/>
```
