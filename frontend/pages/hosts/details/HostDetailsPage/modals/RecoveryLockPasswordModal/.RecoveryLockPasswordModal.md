Modal component for displaying and managing a host's Recovery Lock password, supporting password rotation and auto-rotate notifications.

## Key Components

### `RecoveryLockPasswordModal`
Main exported component that renders a modal dialog with the following behavior:
- Fetches the host's recovery lock password via `hostAPI.getRecoveryLockPassword` using `react-query` (with `cacheTime: 0` to prevent caching sensitive data)
- Displays the password using `InputFieldHiddenContent` for secure rendering
- Shows an `InfoBanner` warning when automatic password rotation is scheduled
- Optionally renders a **Rotate password** button based on the `canRotatePassword` prop

### Props (`IRecoveryLockPasswordModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `hostId` | `number` | ID of the target host |
| `canRotatePassword` | `boolean` | Controls visibility of the rotate password button |
| `onCancel` | `() => void` | Callback for modal close/cancel actions |

### Internal Handlers

- **`onRotatePassword`** — Calls `hostAPI.rotateRecoveryLockPassword`, renders a success/error flash notification, and closes the modal. Handles the "already in progress" edge case with a specific error message.
- **`renderRotateButton`** — Conditionally renders the rotate button based on `canRotatePassword`.

## Usage Example

```typescript
<RecoveryLockPasswordModal
  hostId={42}
  canRotatePassword={currentUser.isAdmin}
  onCancel={() => setShowModal(false)}
/>
```
