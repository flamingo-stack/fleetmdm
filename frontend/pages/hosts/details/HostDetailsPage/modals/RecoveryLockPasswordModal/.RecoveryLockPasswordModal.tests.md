Test suite for the `RecoveryLockPasswordModal` component, verifying conditional rendering of the password rotation button based on the `canRotatePassword` prop.

## Key Components

- **`mockPasswordResponse`** — Fixture object simulating the API response from `hostAPI.getRecoveryLockPassword`
- **`hides the rotate button when canRotatePassword is false`** — Asserts the "Rotate password" button is absent and "Close" is visible
- **`shows the rotate button when canRotatePassword is true`** — Asserts the "Rotate password" button renders when rotation is permitted

## Usage Example

```typescript
// Run tests
npx jest RecoveryLockPasswordModal.tests.tsx

// Example component usage under test
<RecoveryLockPasswordModal
  hostId={7}
  canRotatePassword={false}
  onCancel={jest.fn()}
/>
```

## Notes

- Uses `createCustomRenderer` with `withBackendMock: true` to simulate backend interactions
- `hostAPI.getRecoveryLockPassword` is mocked via `jest.mock` and reset before each test with `jest.resetAllMocks()`
- Tests use `waitFor` to handle async API resolution before asserting UI state
