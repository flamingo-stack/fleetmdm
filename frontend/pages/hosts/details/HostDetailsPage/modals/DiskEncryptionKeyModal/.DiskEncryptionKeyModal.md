Modal component that fetches and displays a host's disk encryption key, supporting both macOS (FileVault recovery key) and Windows (BitLocker unlock key) platforms.

## Key Components

- **`IDiskEncryptionKeyModal`** — Props interface accepting `platform` (`HostPlatform`), `hostId` (`number`), and `onCancel` callback
- **`DiskEncryptionKeyModal`** — Default export; React component rendering a `Modal` with the fetched encryption key
- **`useQuery`** — Fetches the encryption key via `hostAPI.getEncryptionKey(hostId)`, selecting `encryption_key.key` from the response; retries and refetches are disabled
- **`recoveryText`** — Platform-conditional hint: login guidance for `darwin`, drive unlock guidance for all other platforms
- **`InputFieldHiddenContent`** — Displays the encryption key with masked/hidden content UI
- **`DataError`** — Rendered in place of the key when the API call fails, showing the error reason

## Usage Example

```typescript
import DiskEncryptionKeyModal from "components/DiskEncryptionKeyModal";

const HostDetails = () => {
  const [showKeyModal, setShowKeyModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowKeyModal(true)}>
        View Disk Encryption Key
      </Button>
      {showKeyModal && (
        <DiskEncryptionKeyModal
          platform="darwin"
          hostId={42}
          onCancel={() => setShowKeyModal(false)}
        />
      )}
    </>
  );
};
```
