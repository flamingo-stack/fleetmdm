Modal component for unlocking managed hosts, with platform-specific behavior for macOS (displays a 6-digit PIN), iOS/iPadOS (disables Lost Mode), and other platforms (confirmation prompt with unlock action).

## Key Components

### `IUnlockModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `id` | `number` | Host identifier |
| `platform` | `string` | Host platform (`darwin`, `ipados`, `iphone`, etc.) |
| `hostName` | `string` | Display name of the host |
| `onSuccess` | `() => void` | Callback fired after successful unlock |
| `onClose` | `() => void` | Callback to close the modal |

### `UnlockModal`
Default export. Renders a `Modal` with platform-aware content and action buttons:

- **macOS (`darwin`)** — Fetches the unlock PIN via `hostAPI.unlockHost` on mount using `react-query`, then displays the 6-digit PIN. Only shows a **Close** button.
- **iPad/iPhone** — Displays a Lost Mode disable notice with **Unlock** and **Cancel** buttons.
- **Other platforms** — Shows a confirmation prompt with **Unlock** and **Cancel** buttons, calling `hostAPI.unlockHost` on confirm.

## Usage Example

```typescript
import UnlockModal from "pages/hosts/details/components/UnlockModal";

<UnlockModal
  id={42}
  platform="darwin"
  hostName="MacBook-Pro-12"
  onSuccess={() => refetchHostData()}
  onClose={() => setShowUnlockModal(false)}
/>
```

## Notes

- macOS PIN fetch is triggered **on modal open** (`enabled: platform === "darwin"`), not on button click.
- `renderFlash` from `NotificationContext` surfaces success/error toast notifications after unlock attempts.
- The unlock action for non-macOS platforms is async; the **Unlock** button shows a loading spinner via `isLoading` during the request.
