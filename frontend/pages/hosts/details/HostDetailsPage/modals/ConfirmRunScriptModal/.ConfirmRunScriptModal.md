A confirmation modal component that prompts the user to confirm execution of a script on a specific host before proceeding.

## Key Components

### `IConfirmRunScriptModal` Interface

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Called when the Cancel button is clicked |
| `onClose` | `() => void` | Called when the modal is dismissed/closed |
| `onConfirmRunScript` | `() => void` | Called when the Run button is confirmed |
| `scriptName` | `string` (optional) | Name of the script to display; falls back to `"The script"` |
| `hostName` | `string` | Target host name displayed in the confirmation message |
| `isRunningScript` | `boolean` | Disables controls and shows loading state while script executes |
| `isHidden` | `boolean` | Controls modal visibility |

### `ConfirmRunScriptModal` Component

Default export. Renders a `Modal` with a brief confirmation message and two action buttons: **Run** and **Cancel**.

## Usage Example

```typescript
import ConfirmRunScriptModal from "components/ConfirmRunScriptModal";

<ConfirmRunScriptModal
  scriptName="deploy-agent.sh"
  hostName="mac-workstation-01"
  isRunningScript={isLoading}
  isHidden={!showModal}
  onConfirmRunScript={handleRunScript}
  onCancel={() => setShowModal(false)}
  onClose={() => setShowModal(false)}
/>
```

> The `Run` button enters a loading state via `isLoading` while `isRunningScript` is `true`, preventing duplicate submissions. If `scriptName` is omitted, the message defaults to `"The script will run on <hostName>"`.
