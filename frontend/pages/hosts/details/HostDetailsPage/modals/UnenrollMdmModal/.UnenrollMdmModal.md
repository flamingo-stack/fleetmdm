Modal component for unenrolling a host from MDM management, with platform-aware messaging and re-enrollment instructions for iOS/iPadOS, Android, and desktop platforms.

## Key Components

- **`UnenrollMdmModal`** — Default export. Renders a confirmation modal that triggers the MDM unenrollment API call and displays contextual descriptions and re-enrollment guidance based on host platform and enrollment status.
- **`submitUnenrollMdm`** — Async handler that calls `mdmAPI.unenrollHostFromMdm` with a 5-second timeout, flashes a success or error notification, and closes the modal.
- **`generateDescription`** — Returns platform-specific body copy (iOS/iPadOS, Android, or desktop/macOS).
- **`generateIosOrIpadosDescription`** — Returns re-enrollment instructions specific to BYOD manual, BYOD account-driven user, or automatic (ABM) enrollment status.
- **`renderModalContent`** — Renders a `DataError` fallback on error state, or the description and action buttons (`Unenroll`/`Turn off` + `Cancel`).

## Props (`IUnenrollMdmModalProps`)

| Prop | Type | Description |
|---|---|---|
| `hostId` | `number` | ID passed to the unenroll API call |
| `hostPlatform` | `string` | Determines platform-specific UI text |
| `hostName` | `string` | Displayed in flash notifications |
| `enrollmentStatus` | `MdmEnrollmentStatus \| null` | Drives iOS/iPadOS re-enrollment copy |
| `onClose` | `() => void` | Called on cancel or successful unenroll |

## Usage Example

```typescript
<UnenrollMdmModal
  hostId={42}
  hostPlatform="ipados"
  hostName="Jane's iPad"
  enrollmentStatus="On (automatic)"
  onClose={() => setShowModal(false)}
/>
```
