Renders contextual warning banners on the host details page based on MDM enrollment status, disk encryption state, and platform-specific conditions.

## Key Components

### `IHostBannersBaseProps`
Props interface defining the inputs needed to determine which banner (if any) to display:

| Prop | Type | Description |
|---|---|---|
| `macDiskEncryptionStatus` | `DiskEncryptionStatus \| null \| undefined` | Current macOS disk encryption status |
| `mdmEnrollmentStatus` | `MdmEnrollmentStatus \| null` | Host's MDM enrollment state |
| `connectedToFleetMdm` | `boolean` | Whether host is connected to Fleet's MDM |
| `diskEncryptionOSSetting` | `IOSSettings["disk_encryption"]` | Team-level disk encryption policy |
| `diskIsEncrypted` | `boolean` | Whether the host disk is currently encrypted |
| `diskEncryptionKeyAvailable` | `boolean` | Whether Fleet has an escrowed encryption key |
| `lastMdmEnrolledAt` | `string` | ISO timestamp of last MDM enrollment |

### `HostDetailsBanners` (default export)
Component that evaluates host state and returns the appropriate `InfoBanner` or `null`. Banner priority order:

1. **Turn on MDM** — macOS host, MDM unenrolled, Fleet MDM configured
2. **Mac disk encryption action required** — macOS, Fleet MDM connected, status is `action_required`, enrollment is >1 hour old
3. **Linux disk not encrypted** — Linux host under disk encryption policy with disk unencrypted
4. **Linux/Windows key escrow pending** — Disk encrypted but no key available in Fleet
5. **Windows action required** — Windows host with `action_required` disk encryption status

## Usage Example

```typescript
<HostDetailsBanners
  mdmEnrollmentStatus="On (automatic)"
  hostPlatform="darwin"
  connectedToFleetMdm={true}
  macDiskEncryptionStatus="action_required"
  lastMdmEnrolledAt="2024-01-01T10:00:00Z"
  diskEncryptionOSSetting={{ status: "applied", detail: "" }}
  diskIsEncrypted={false}
  diskEncryptionKeyAvailable={false}
/>
```

> **Note:** The component suppresses the disk encryption `action_required` banner for hosts enrolled within the last hour, allowing time for the host to report its current encryption status to Fleet.
