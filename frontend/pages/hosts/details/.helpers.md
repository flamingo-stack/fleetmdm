Shared utility functions for host details and device pages, providing helpers to generate synthetic MDM profile settings and resolve device status UI states from API data.

## Key Components

| Export | Type | Description |
|---|---|---|
| `generateWinDiskEncryptionSetting` | Function | Builds a synthetic `IHostMdmProfile` for Windows disk encryption (absent from API profiles array) |
| `generateLinuxDiskEncryptionSetting` | Function | Builds a synthetic `IHostMdmProfile` for Linux disk encryption (absent from API profiles array) |
| `generateRecoveryLockPasswordSetting` | Function | Builds a synthetic `IHostMdmProfile` for the Darwin Recovery Lock password setting |
| `REC_LOCK_SYNTHETIC_PROFILE_UUID` | Constant | Sentinel UUID (`"rec_lock_dummy"`) identifying the synthetic recovery lock profile |
| `HostMdmDeviceStatusUIState` | Type | Union of UI-layer device states: `unlocked`, `locked`, `unlocking`, `locking`, `wiped`, `wiping`, `clearing_passcode`, `locating` |
| `getHostDeviceStatusUIState` | Function | Maps raw API `deviceStatus` + `pendingAction` values to a single `HostMdmDeviceStatusUIState` |
| `isDeviceStatusUpdating` | Function | Returns `true` when a device status indicates an in-progress transition |

## Usage Example

```typescript
import {
  generateWinDiskEncryptionSetting,
  generateLinuxDiskEncryptionSetting,
  getHostDeviceStatusUIState,
  isDeviceStatusUpdating,
} from "./helpers";

// Synthesize a Windows disk encryption profile for display
const winProfile = generateWinDiskEncryptionSetting("failed", "Encryption error");
// { name: "Disk encryption", status: "failed", detail: "Encryption error. Fleet will retry automatically.", ... }

// Synthesize a Linux disk encryption profile
const linuxProfile = generateLinuxDiskEncryptionSetting("verified", "");

// Resolve the UI state from raw API values
const uiState = getHostDeviceStatusUIState("locked", "location");
// "locating"

// Check if the device is mid-transition
if (isDeviceStatusUpdating(uiState)) {
  showSpinner();
}
```
