A React component that renders an empty state UI for the reports section, displaying context-aware messaging based on whether a search is active.

## Key Components

- **`EmptyReports`** — Default export; a functional component that accepts an `isSearching` boolean prop and renders an icon with a heading and subheading to indicate no reports are available.
- **`IEmptyReportsProps`** — Interface defining the component's props.

## Usage Example

```typescript
import EmptyReports from "components/EmptyReports";

// When no reports exist for the host
<EmptyReports isSearching={false} />

// When a search returns no results
<EmptyReports isSearching={true} />
```

## Behavior

| `isSearching` | Heading displayed |
|---|---|
| `false` | "No reports for this host" |
| `true` | "No reports match the current search criteria" |

The component always renders a search icon and the static subheading: *"Expecting to see reports? Check back later."*
