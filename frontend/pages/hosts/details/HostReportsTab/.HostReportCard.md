A React card component that displays a host-specific report summary, including data results, status banners, and contextual action controls.

## Key Components

### `HostReportCard` (default export)
The primary component rendering a Fleet report for a single host. Accepts:
- `report: IHostReport` — the report data to display
- `hostName: string` — display name of the host
- `onShowDetails(report)` — callback to open full report details
- `onViewAllHosts(report)` — callback to navigate to the all-hosts report view

### `ReportBanner` (internal)
A styled informational banner built on `InfoBanner`, used internally to communicate report status states (awaiting results, no data, clipped results, non-stored results).

### Status Logic
Four mutually exclusive states are derived from the report:
- **Awaiting results** — `last_fetched` is null
- **Does not store results** — `store_results` is false
- **No data** — `first_result` is null
- **Has additional results** — `n_host_results > 1`

## Usage Example

```typescript
import HostReportCard from "components/HostReportCard";
import { IHostReport } from "services/entities/host_reports";

const MyPage = () => {
  const handleShowDetails = (report: IHostReport) => {
    // open details modal
  };

  const handleViewAllHosts = (report: IHostReport) => {
    // navigate to all-hosts report view
  };

  return (
    <HostReportCard
      report={hostReport}
      hostName="acme-macbook-pro"
      onShowDetails={handleShowDetails}
      onViewAllHosts={handleViewAllHosts}
    />
  );
};
```

The actions dropdown dynamically includes **"Show details"** only when results have been fetched, and always includes **"View report for all hosts"**. Data cells are rendered as a grid of `DataSet` components, each with truncation tooltips via `TooltipTruncatedText`.
