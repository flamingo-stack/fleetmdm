Renders the Reports tab on a host detail page, displaying a paginated, searchable, and sortable list of scheduled reports associated with a specific host.

## Key Components

### `HostReportsTab` (default export)
Main functional component that manages report listing with the following capabilities:

- **Data fetching** — Uses `react-query` to call `hostReportsAPI.list()`, keyed on host ID, page, sort, search query, and the "don't store results" toggle
- **URL-driven state** — Search query, sort order, and toggle state are persisted in the URL via `router.replace()` / `location.query`, making the view bookmarkable and shareable
- **Sorting** — Four options (newest/oldest results, name A–Z/Z–A) mapped to `order_key` / `order_direction` API params via `getSortParams()`
- **"Don't store results" toggle** — `Slider` control that includes/excludes reports not configured to persist data; automatically forced on when `saveReportsDisabledInConfig` is `true`
- **Empty states** — Distinguishes between truly empty (no reports at all), search-filtered empty, and MDM-pending (`showReportsEmptyState`) scenarios
- **Pagination** — Client-controlled page index with previous/next navigation using API-returned `meta.has_next_results` / `meta.has_previous_results`
- **Navigation** — `onShowDetails` routes to `HOST_REPORT_RESULTS`, `onViewAllHosts` routes to `REPORT_DETAILS`

### Constants
- `PAGE_SIZE = 50` — Fixed page size for API requests
- `SORT_OPTIONS` — Dropdown options array consumed by `DropdownWrapper`
- `DEFAULT_SORT_OPTION = "newest_results"`

## Usage Example

```typescript
<HostReportsTab
  hostId={42}
  hostName="macbook-pro-alice"
  router={router}
  location={location}
  saveReportsDisabledInConfig={false}
  showReportsEmptyState={false}
  canScheduleReport={true}
  onScheduleReport={() => setShowScheduleModal(true)}
/>
```
