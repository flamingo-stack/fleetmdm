Displays installed software version details for a host, including version number, type, vulnerabilities, installed paths, and signature information. Renders one card per installed version with optional label support.

## Key Components

- **`InventoryVersions`** *(default export)* — Container component that iterates over `hostSoftware.installed_versions` and renders an `InventoryVersion` card for each entry. Falls back to a minimal type-only card when no versions are present.
- **`InventoryVersion`** — Internal card component displaying metadata for a single software version: version string, type, bundle identifier, last-opened timestamp, CVE vulnerabilities, and per-path hash/signature info.
- **`generateVulnerabilitiesValue`** — Helper that formats a CVE list, showing the first 3 inline and summarizing the remainder as `+N more`.

## Props

| Prop | Type | Description |
|---|---|---|
| `hostSoftware` | `IHostSoftware` | Full software record including installed versions, source, and identifiers |
| `showLabel` | `boolean` | Whether to render the "Current version(s):" label (default: `true`) |

## Usage Example

```typescript
import InventoryVersions from "components/InventoryVersions";

<InventoryVersions
  hostSoftware={hostSoftwareRecord}
  showLabel={true}
/>
```

## Notes

- The **Last opened** label on Linux platforms is wrapped in a `TooltipWrapper` explaining the broader access semantics (process-level, not just user-level).
- Vulnerabilities beyond the first 3 are collapsed into a `+N more` suffix rather than a separate UI element.
- Signature information (`hash_sha256`) is matched to installed paths by the `installed_path` field on each `signatureInformation` entry.
