Generates dynamic column configurations for the Host Query Results (HQR) table by introspecting row data to determine column types and applying appropriate rendering, filtering, and sorting behavior.

## Key Components

### `generateColumnConfigs(rows: IWebSocketData[]): IHQRTTableColumn[]`
The default export. Accepts an array of `IWebSocketData` rows and returns a `react-table` column definition array. Column names are derived at runtime from the row data via `getUniqueColsAreNumTypeFromRows`.

**Column behavior per field:**
- **`last_fetched`** — Header renders as `"Last fetched"` (sentence case); cell value is transformed via `humanHostLastSeen` for human-readable display while retaining chronological sort order.
- **All other columns** — Cell values longer than 300 characters are truncated using `internallyTruncateText`; shorter values render as-is.
- **Filtering** — Uses `DefaultColumnFilter` with `filterType: "text"` (filter is hidden for `last_fetched` internally by that component).
- **Sorting** — Enabled with `sortType: "caseInsensitive"` for all columns.

### Type Aliases
| Type | Description |
|---|---|
| `IHQRTTableColumn` | `Column<IWebSocketData>` — typed column definition |
| `ITableHeaderProps` | `IHeaderProps<IWebSocketData>` — typed header props |
| `ITableStringCellProps` | `CellProps<IWebSocketData, string \| unknown>` — typed cell props |

## Usage Example

```typescript
import generateColumnConfigs from "./HQRTableConfig";

// Inside a component consuming react-table
const columns = generateColumnConfigs(queryResultRows);

// Pass to TableContainer or useTable
<TableContainer columns={columns} data={queryResultRows} />
```
