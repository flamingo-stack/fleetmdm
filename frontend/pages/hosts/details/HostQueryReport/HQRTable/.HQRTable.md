A React component that renders a Host Query Report (HQR) table, displaying scheduled query results for a specific host with support for CSV export, performance impact indicators, and multiple empty states.

## Key Components

### `HQRTable` (default export)
The main table component accepting `IHQRTable` props:

| Prop | Type | Description |
|------|------|-------------|
| `queryId` | `number` | Unique identifier for the query |
| `queryName` | `string` | Display name of the query |
| `queryDescription` | `string` | Description shown in the table header |
| `queryStats` | `ISchedulableQueryStats` | Stats used to calculate performance impact |
| `hostName` | `string` | Name of the target host |
| `rows` | `Record<string, string>[]` | Query result rows |
| `reportClipped` | `boolean` | Whether the report has been paused/clipped |
| `lastFetched` | `string \| null` | Timestamp of last data fetch |
| `onShowQuery` | `() => void` | Callback to display the raw query |
| `isLoading` | `boolean` | Controls loading spinner display |

### `PerformanceImpact` (internal)
Renders a tooltip-wrapped performance indicator derived from `ISchedulableQueryStats`, normalizing execution time metrics per execution count.

## Usage Example

```typescript
import HQRTable from "components/HQRTable";

<HQRTable
  queryId={42}
  queryName="Running Processes"
  queryDescription="Lists all active processes"
  queryStats={queryStats}
  hostName="macbook-pro-1"
  rows={queryResults}
  lastFetched="2024-01-15T10:30:00Z"
  reportClipped={false}
  isLoading={false}
  onShowQuery={() => setShowQueryModal(true)}
/>
```

## Key Behaviors

- Renders a **loading spinner** while `isLoading` is true
- Shows **empty states** for three conditions: report clipped, results still collecting (`lastFetched` is null), or no data returned
- **CSV export** generates a filename scoped to query name and host name when both are available, falling back to `"Host-Specific Report"`
- Column configs are **dynamically generated** from the shape of incoming `rows` via `generateColumnConfigs`
