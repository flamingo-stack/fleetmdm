Test suite for the `HQRTable` component, validating rendering behavior across four distinct data states: results present, never collected, report clipped, and no results found.

## Key Components

| Test Case | Condition | Expected Output |
|---|---|---|
| Results present | `rows` populated, `lastFetched` set | Result count, "Last fetched", row data |
| Never collected | `rows: []`, `lastFetched: null` | "Collecting results..." |
| Report clipped | `rows: []`, `reportClipped: true` | "Report clipped" |
| Nothing to report | `rows: []`, `reportClipped: false`, `lastFetched` set | "Nothing to report" |

## Usage Example

```typescript
// Running the test suite
import { render, screen } from "@testing-library/react";
import HQRTable, { IHQRTable } from "./HQRTable";

// Example: testing the populated results state
const tableProps: IHQRTable = {
  queryId: 1,
  queryName: "testQuery0",
  queryDescription: "testDescription0",
  hostName: "testHost0",
  rows: [{ build_distro: "10.14", version: "5.11.0" /* ... */ }],
  reportClipped: false,
  lastFetched: "2021-09-01T00:00:00Z",
  onShowQuery: jest.fn(),
  isLoading: false,
};

render(<HQRTable {...tableProps} />);
expect(screen.getByText("1 result")).toBeInTheDocument();
expect(screen.getByText("Last fetched")).toBeInTheDocument();
```

## Notes

- All four empty states are mutually exclusive and driven by the combination of `rows`, `reportClipped`, and `lastFetched` props.
- Row data validation iterates all column keys and values to confirm complete table rendering.
