Modal component that guides macOS users through the MDM (Mobile Device Management) enrollment process, displaying version-appropriate instructions based on the host's OS version.

## Key Components

### `AutoEnrollMdmModal`
The default export — a React functional component that renders a `Modal` with step-by-step MDM enrollment instructions.

**Props (`IAutoEnrollMdmModalProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `host` | `IDUPDetails["host"]` | Host metadata containing `platform` and `os_version` |
| `onCancel` | `() => void` | Callback fired on modal close or Enter key |

### OS Version Branching Logic
- **Pre-Sonoma (macOS < 14):** Shows notification center–based enrollment flow
- **Sonoma and later (macOS 14+):** Shows System Settings sidebar–based flow
- **macOS 26+:** Updates the CTA label to `"Enroll in Device Management"` instead of `"Enroll in Remote Management"`

Both flows include a fallback `sudo profiles renew -type enrollment` terminal command rendered via a copyable, read-only `InputField`.

## Usage Example

```typescript
import AutoEnrollMdmModal from "./AutoEnrollMdmModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      {showModal && (
        <AutoEnrollMdmModal
          host={{ platform: "darwin", os_version: "macOS 14.5" }}
          onCancel={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- Only renders version-branched content for `darwin` (macOS) platform; other platforms fall through to the pre-Sonoma body by default.
