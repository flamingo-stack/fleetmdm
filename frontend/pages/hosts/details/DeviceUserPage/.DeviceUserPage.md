Renders the device user self-service portal page, providing end users with a view of their enrolled device's health, software, policies, and certificates, along with MDM enrollment and disk encryption management capabilities.

## Key Components

### Page Component
- **`DeviceUserPage`** — Primary page component that orchestrates device data fetching, tab navigation, and modal state management for the self-service device portal

### Data Queries
- **`deviceUserAPI.loadHostDetails`** — Fetches core device details (`dupDetails`) including host vitals, platform, and refetch status
- **`deviceUserAPI.loadHostDetailsExtension`** — Loads macOS admin (`macadmins`) extension data
- **`deviceUserAPI.getDeviceCertificates`** — Fetches paginated, sortable certificate list for the device

### State Management
- Modal states for: `BitLockerPIN`, `InfoModal`, `AutoEnrollMdm`, `OSSettings`, `BootstrapPackage`, `CreateLinuxKey`, `BypassModal`, `CertificateDetails`, `PolicyDetails`, `InventoryVersions`
- Refetch polling states (`refetchStartTime`, `showRefetchSpinner`) with a 3-minute timeout window
- Dark mode detection via `fleet-theme-change` custom event listener

### Tab Navigation
- `PREMIUM_TAB_PATHS` — Self-service, details, software, and policies tabs
- `FREE_TAB_PATHS` — Details and software tabs only

### Helper Utilities
- **`isRefetching`** — Determines if a host is actively refetching based on `refetch_requested` or `refetch_critical_queries_until`
- **`resetHostRefetchStates`** — Clears spinner and timer to prevent stale timeouts

## Usage Example

```typescript
// Route configuration (react-router)
<Route
  path={PATHS.DEVICE_USER_DETAILS}
  component={DeviceUserPage}
/>

// The component is accessed via device auth token in the URL:
// /device/:device_auth_token

// Refetch polling behavior for online hosts:
// - Polls every REFETCH_HOST_DETAILS_POLLING_INTERVAL ms
// - Times out after 180,000ms (3 minutes)
// - iOS/iPadOS and recently enrolled hosts skip offline error
```

## Key Constants

| Constant | Value | Purpose |
|---|---|---|
| `DEFAULT_CERTIFICATES_PAGE_SIZE` | `10` | Certificates per page |
| `DEFAULT_CERTIFICATES_PAGE` | `0` | Initial certificate page |
| Refetch timeout | `180000ms` | Max polling window before reset |
