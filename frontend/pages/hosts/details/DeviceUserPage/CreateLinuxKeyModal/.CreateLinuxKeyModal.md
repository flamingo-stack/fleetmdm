A React modal component that guides users through the Linux disk encryption key creation process, displaying step-by-step instructions for entering a disk encryption passphrase.

## Key Components

### `ICreateLinuxKeyModal` Interface
| Prop | Type | Description |
|------|------|-------------|
| `isTriggeringCreateLinuxKey` | `boolean` | Controls the modal's loading state while key creation is in progress |
| `onExit` | `() => void` | Callback fired on modal close, backdrop click, or Enter key press |

### `CreateLinuxKeyModal` Component
A stateless modal that renders an ordered list of instructions for Linux disk encryption key creation, including:
- Waiting for the **Enter disk encryption passphrase** pop-up
- Entering the device passphrase
- Guidance on when the **Disk Encryption** banner clears
- Escalation instructions if the process fails

## Usage Example

```typescript
import CreateLinuxKeyModal from "components/mdm/CreateLinuxKeyModal";

const MyDevicePage = () => {
  const [showModal, setShowModal] = useState(false);
  const [isTriggering, setIsTriggering] = useState(false);

  return (
    <>
      {showModal && (
        <CreateLinuxKeyModal
          isTriggeringCreateLinuxKey={isTriggering}
          onExit={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- The modal shows a loading spinner via `isLoading` when `isTriggeringCreateLinuxKey` is `true`
- `onExit` is wired to both `onExit` and `onEnter` on the `Modal`, allowing keyboard (`Enter`) dismissal
