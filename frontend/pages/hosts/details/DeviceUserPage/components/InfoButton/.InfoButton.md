A reusable button component that renders an "Info" label paired with a small info icon, styled with the `inverse` variant.

## Key Components

- **`InfoButton`** — Default export. Accepts a single `onClick` handler and renders a `Button` with an embedded `Icon`.
- **`IInfoButton`** — Interface defining the component's props (`onClick: () => void`).

## Usage Example

```typescript
import InfoButton from "components/buttons/InfoButton";

const MyComponent = () => (
  <InfoButton onClick={() => console.log("Info clicked")} />
);
```
