Renders conditional informational banners for device users based on MDM enrollment status, disk encryption state, and platform type.

## Key Components

### `DeviceUserBannersProps`
Extends `IHostBannersBaseProps` with:
- `mdmEnabledAndConfigured` — whether MDM is active on the Fleet server
- `diskEncryptionActionRequired` — macOS-specific encryption action (`rotate_key`, etc.)
- `mdmManualEnrolmentUrl` — optional URL overriding the default MDM enrollment button
- `onClickCreatePIN` — handler for Windows BitLocker PIN creation
- `onClickTurnOnMdm` — handler for triggering MDM enrollment
- `onTriggerEscrowLinuxKey` — handler for Linux disk encryption key escrow

### `DeviceUserBanners` (default export)
Stateless component that evaluates banner priority and renders at most one `InfoBanner` at a time. Banner resolution order:

1. **Turn on MDM** (macOS, MDM unenrolled) — links to manual enrolment URL or triggers modal
2. **Mac disk encryption key reset** — shown when `rotate_key` is required and enrollment is not brand-new (>1 hour)
3. **Linux disk not encrypted** — links to Fleet's encryption guide
4. **Linux key not escrowed** — prompts user to create an escrow key
5. **Windows BitLocker PIN required** — prompts PIN creation

Returns `null` when no banner conditions are met.

## Usage Example

```typescript
<DeviceUserBanners
  hostPlatform="darwin"
  hostOsVersion="14.0"
  mdmEnrollmentStatus="Off"
  mdmEnabledAndConfigured={true}
  connectedToFleetMdm={false}
  macDiskEncryptionStatus={null}
  diskEncryptionActionRequired={null}
  diskEncryptionOSSetting={null}
  diskIsEncrypted={false}
  diskEncryptionKeyAvailable={false}
  lastMdmEnrolledAt={null}
  onClickCreatePIN={() => {}}
  onClickTurnOnMdm={() => openMdmModal()}
  onTriggerEscrowLinuxKey={() => {}}
/>
```
