React component test suite validating conditional banner rendering in the `DeviceUserBanners` component across different host platforms, MDM enrollment states, and disk encryption scenarios.

## Key Components

### Test Suite: `Device User Banners`

Covers six distinct rendering scenarios for the `DeviceUserBanners` component:

| Test Case | Platform | Expected Behavior |
|---|---|---|
| Turn on MDM banner | `darwin` | Renders MDM off warning |
| Reset disk encryption key (non-Linux) | `darwin` | Renders rotate key banner |
| Create Linux disk encryption key | `ubuntu` | Renders escrow key banner |
| Create Linux disk encryption key (Fedora) | `rhel` | Renders escrow key banner |
| Create BitLocker PIN | `windows` | Renders PIN creation banner |
| No banner (verifying state) | `darwin` | Renders no banners |
| No banner (MDM not configured) | `darwin` | Renders no banners |

## Usage Example

```typescript
// Run all tests
npx jest DeviceUserBanners.tests.tsx

// Run a specific test
npx jest DeviceUserBanners.tests.tsx -t "renders the turn on mdm banner correctly"
```

```typescript
// Example prop shape exercised by the tests
<DeviceUserBanners
  hostPlatform="ubuntu"
  mdmEnrollmentStatus="On (automatic)"
  mdmEnabledAndConfigured
  connectedToFleetMdm
  macDiskEncryptionStatus={null}
  diskEncryptionActionRequired={null}
  diskEncryptionOSSetting={{ status: "action_required", detail: "" }}
  diskIsEncrypted
  diskEncryptionKeyAvailable={false}
  onTriggerEscrowLinuxKey={noop}
  onClickCreatePIN={noop}
  onClickTurnOnMdm={noop}
/>
```
