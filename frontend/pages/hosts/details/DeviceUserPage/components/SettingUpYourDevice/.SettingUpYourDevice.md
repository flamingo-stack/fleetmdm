Renders the device setup status card shown to end-users during MDM enrollment, displaying progress, completion, or software installation failure states with expandable error details.

## Key Components

- **`SettingUpYourDevice`** – Default export. Stateful React component that derives its title and message from three possible states:
  - **Failure** – A required software package failed to install (`requireAllSoftware` + `getFailedSoftwareInstall`)
  - **In progress** – Setup steps remain (`hasRemainingSetupSteps`)
  - **Complete** – All steps finished successfully
- **`ISettingUpYourDevice`** – Props interface with `setupSteps`, `toggleInfoModal`, `requireAllSoftware`, and `platform`
- **`showError`** – Local boolean state controlling visibility of the collapsible error `Textarea`

### Child Components Used
| Component | Role |
|---|---|
| `SetupStatusTable` | Renders per-step status rows (hidden on failure) |
| `RevealButton` | Toggles expandable error detail section |
| `Textarea` (code variant) | Displays raw software install error output |
| `InfoButton` | Opens info modal; hidden on failure or macOS (`darwin`) |
| `TooltipWrapper` | Wraps "Restart your device" with power-button instructions |

## Usage Example

```typescript
<SettingUpYourDevice
  setupSteps={setupSteps}
  toggleInfoModal={() => setShowInfoModal(true)}
  requireAllSoftware={true}
  platform="darwin"
/>
```
