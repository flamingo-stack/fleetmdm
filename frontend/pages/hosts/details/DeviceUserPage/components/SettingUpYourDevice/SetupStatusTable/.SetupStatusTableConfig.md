Generates column configuration for the setup status table, defining "Process" and "Status" columns that render appropriate cell components based on setup step type (`software_install`, `script_run`, or `software_script_run`).

## Key Components

- **`generateColumnConfigs()`** — Default export. Returns a `react-table` column config array with two columns:
  - **Process column** — Renders [`SetupSoftwareProcessCell`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/TableContainer/DataTable/SetupSoftwareProcessCell) or [`SetupScriptProcessCell`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/TableContainer/DataTable/SetupScriptProcessCell) depending on the step type.
  - **Status column** — Renders [`SetupSoftwareStatusCell`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/TableContainer/DataTable/SetupSoftwareStatusCell) or [`SetupScriptStatusCell`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/TableContainer/DataTable/SetupScriptStatusCell), defaulting to `"pending"` if status is absent.

## Type Reference

| Type | Description |
|---|---|
| `ISetupStatusTableConfig` | Alias for `Column<ISetupStep>` from `react-table` |
| `ITableCellProps` | Alias for `CellProps<ISetupStep>` |

## Usage Example

```typescript
import generateColumnConfigs from "./SetupStatusTableConfig";
import TableContainer from "components/TableContainer";

const SetupStatusTable = ({ steps }: { steps: ISetupStep[] }) => {
  const columns = generateColumnConfigs();

  return (
    <TableContainer
      columns={columns}
      data={steps}
      // ...other table props
    />
  );
};
```

## Step Type Rendering

| `type` value | Process Cell | Status Cell |
|---|---|---|
| `software_install` | `SetupSoftwareProcessCell` | `SetupSoftwareStatusCell` |
| `script_run` | `SetupScriptProcessCell` | `SetupScriptStatusCell` |
| `software_script_run` | `SetupScriptProcessCell` | `SetupScriptStatusCell` |
| *(other)* | `null` | `null` |
