Renders a sorted table of device setup status steps, displaying software installs, software script runs, and script runs in a defined order.

## Key Components

- **`SetupStatusTable`** — Main React component that accepts an array of `ISetupStep` objects and renders them in a `TableContainer`
- **`ISetupStatusTableProps`** — Props interface requiring a `statuses: ISetupStep[]` array
- **`generateColumnConfigs`** — Imported helper that defines the table column structure (from `SetupStatusTableConfig`)
- **Sort order** — Steps are sorted by type: `software_install` → `software_script_run` → `script_run`

## Usage Example

```typescript
import SetupStatusTable from "components/SetupStatusTable";
import { ISetupStep } from "interfaces/setup";

const steps: ISetupStep[] = [
  { type: "script_run", /* ...other fields */ },
  { type: "software_install", /* ...other fields */ },
  { type: "software_script_run", /* ...other fields */ },
];

// Renders sorted: software_install, software_script_run, script_run
<SetupStatusTable statuses={steps} />
```

## Notes

- Pagination is disabled; all steps render in a single page (`pageSize` equals `statuses.length`)
- The empty state (`"No setup steps to complete"`) is defined but functionally unreachable — the component assumes `statuses` is always populated
- Column configuration is externalized to [`SetupStatusTableConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/SetupStatusTable/SetupStatusTableConfig.tsx) for separation of concerns
