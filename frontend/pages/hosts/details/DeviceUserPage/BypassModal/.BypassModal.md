A modal dialog component that allows users to bypass policy enforcement and log in with Okta once, deferring policy resolution to a later time.

## Key Components

### `IBypassModal` Interface
| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Callback triggered when the modal is dismissed |
| `onResolveLater` | `() => void` | Callback triggered when the user confirms deferring policy resolution |
| `isLoading` | `boolean` | Controls the loading state and disabled state of the confirm button |

### `BypassModal` Component
A functional component rendering a `Modal` with an explanatory message and a single "Resolve later" action button. The modal informs users that bypassing grants a one-time Okta login, and that policies marked "Action required" must be resolved to restore future access.

## Usage Example

```typescript
import BypassModal from "components/BypassModal";

const MyComponent = () => {
  const [showBypass, setShowBypass] = React.useState(false);
  const [isLoading, setIsLoading] = React.useState(false);

  const handleResolveLater = async () => {
    setIsLoading(true);
    await bypassPolicyCheck();
    setIsLoading(false);
  };

  return showBypass ? (
    <BypassModal
      onCancel={() => setShowBypass(false)}
      onResolveLater={handleResolveLater}
      isLoading={isLoading}
    />
  ) : null;
};
```

> **Note:** This component is intended for policy enforcement flows where users have unresolved "Action required" policies. Bypassing only grants a **single** login session — subsequent logins require full policy compliance.
