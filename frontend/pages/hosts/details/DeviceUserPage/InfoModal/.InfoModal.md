A modal component that displays a "Welcome to Fleet" informational dialog, explaining Fleet's device security policy purpose to end users and providing a transparency link about organizational data visibility.

## Key Components

### `IInfoModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Callback fired when the user dismisses the modal |
| `transparencyURL` | `string` (optional) | Custom URL for the transparency link; falls back to `TRANSPARENCY_LINK` constant |

### `InfoModal`
Default export. A stateless functional component rendering a `Modal` with:
- A brief explanation of Fleet's purpose
- A `CustomLink` pointing to the transparency URL (opens in new tab)
- An **OK** button that triggers `onCancel`

## Usage Example

```typescript
import InfoModal from "components/InfoModal";

const DevicePage = () => {
  const [showInfo, setShowInfo] = React.useState(true);

  return (
    <>
      {showInfo && (
        <InfoModal
          onCancel={() => setShowInfo(false)}
          transparencyURL="https://example.com/transparency"
        />
      )}
    </>
  );
};
```

## Notes

- If `transparencyURL` is not provided, the component falls back to the `TRANSPARENCY_LINK` constant from `utilities/constants`.
- The modal's CSS scope is controlled by the `device-user-info` base class.
