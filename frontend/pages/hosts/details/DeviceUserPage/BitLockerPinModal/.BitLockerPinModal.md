A modal dialog that displays step-by-step instructions for creating a BitLocker PIN on Windows devices, presented to end users via the "My device" self-service page.

## Key Components

- **`BitLockerPinModal`** — Default export; a functional React component rendering a `Modal` with a numbered instruction list and a close button.
- **`IBitLockerPinModalProps`** — Interface defining the component's single prop:
  - `onCancel: () => void` — Callback fired when the user closes or dismisses the modal (mapped to both `onExit` and `onEnter` on the underlying `Modal`).

## Usage Example

```typescript
import BitLockerPinModal from "components/BitLockerPinModal";

const MyDevicePage = () => {
  const [showPinModal, setShowPinModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowPinModal(true)}>Create PIN</Button>
      {showPinModal && (
        <BitLockerPinModal onCancel={() => setShowPinModal(false)} />
      )}
    </>
  );
};
```

## Notes

- The modal is display-only — it contains no form inputs or async operations. All interactivity is handled by the parent via the `onCancel` callback.
- Instructions guide the user through the native Windows **Manage BitLocker** UI, ending with a prompt to use the **Refetch** action on their device page to confirm the PIN was set.
