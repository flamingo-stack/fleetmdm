Test suite for the `DeviceUserPage` component, verifying conditional rendering of UI sections and setup experience workflows based on device type, platform, license tier, and MDM configuration.

## Key Components

- **`setupTest`** — Helper that configures mock server handlers, renders `DeviceUserPage`, and returns the `user` interaction object for reuse across setup experience tests
- **Mock matchers** — Named regex constants (`REGULAR_DUP_MATCHER`, `SETTING_UP_YOUR_DEVICE_MATCHER`, `CONFIG_COMPLETE_MATCHER`, `SETUP_FAILED_MATCHER`) scoping assertion targets
- **`beforeAll` / `matchMedia` stub** — Polyfills `window.matchMedia` required by the `useIsMobileWidth` hook

## Test Coverage

| Suite | Scenarios |
|---|---|
| Top-level | Software tab hidden when no software; Certificates card hidden when no certs or non-Apple platform; User card hidden on non-Apple/Android |
| Setup experience | Free tier skips setup checks; Premium renders "Setting up your device" when steps exist; Empty steps show normal DUP; `setup_only=1` forces setup view; `require_all_software_macos` + macOS triggers failure page |

## Usage Example

```typescript
// Run all tests
npx jest DeviceUserPage.tests.tsx

// Run a specific describe block
npx jest DeviceUserPage.tests.tsx -t "Setup experience software installation"
```

The `setupTest` helper pattern used in this file:

```typescript
const user = await setupTest(
  { host },                              // IDUPDetails overrides
  { setup_experience_results: { ... } }, // setup experience overrides
  { query: { setup_only: "1" } }         // location overrides
);
```
