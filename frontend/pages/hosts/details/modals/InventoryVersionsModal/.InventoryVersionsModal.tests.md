Test suite for the `InventoryVersionsModal` component, verifying rendering of software details including version metadata, file paths, hashes, vulnerabilities, and "last opened" timestamps across various data states.

## Key Components

- **`SoftwareDetailsModal` describe block** — Groups all test cases for `InventoryVersionsModal`
- **`createMockHostSoftware`** — Factory helper used to generate typed mock `hostSoftware` props with configurable `installed_versions`
- **Fake timer setup** — `jest.useFakeTimers()` pins system time to `2022-05-08T10:00:00Z` for deterministic relative timestamp assertions (e.g., `"4 months ago"`)

## Test Cases

| Test | Scenario |
|---|---|
| Full details render | Verifies version, type, bundle ID, last opened, path, hash, CVE, and Close button |
| Missing `signature_information` | Confirms `Hash:` row is hidden |
| No installed versions | Only software type is shown; version and path are absent |
| Multiple paths and hashes | Each path is paired with its corresponding SHA-256 hash |
| `last_opened_at` is empty string | Renders `"Never"` |
| `last_opened_at` is `undefined` | "Last opened" field is omitted entirely |
| `last_opened_at` is a valid date | Renders a relative time string; never `"Never"` or `"Not supported"` |

## Usage Example

```typescript
// Running the test suite
// From the repository root:
// npx jest InventoryVersionsModal.tests.tsx

import { createMockHostSoftware } from "__mocks__/hostMock";
import InventoryVersionsModal from "./InventoryVersionsModal";

const mockSoftware = createMockHostSoftware({
  installed_versions: [
    {
      version: "1.0.0",
      last_opened_at: "2022-01-01T12:00:00Z",
      vulnerabilities: ["CVE-2020-0001"],
      installed_paths: ["/Applications/mock.app"],
      bundle_identifier: "com.mock.software",
      signature_information: [
        {
          installed_path: "/Applications/mock.app",
          team_identifier: "TEAMID",
          hash_sha256: "abc123",
        },
      ],
    },
  ],
});
```
