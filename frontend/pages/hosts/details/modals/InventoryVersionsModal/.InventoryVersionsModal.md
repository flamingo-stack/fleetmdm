A modal component that displays version information for a specific software item found in a host's software inventory.

## Key Components

- **`InventoryVersionsModal`** – Default export. A React functional component that wraps `InventoryVersions` in a scrollable modal dialog.
- **`IInventoryVersionsModal`** – Props interface requiring:
  - `hostSoftware: IHostSoftware` – The host software entry whose versions are displayed.
  - `onExit: () => void` – Callback invoked when the modal is dismissed.
- **Scroll detection** – Uses a `ref` and `resize` event listener to detect whether the modal content overflows, passing `isTopScrolling` to `ModalFooter` to trigger a visual scroll indicator.

## Usage Example

```typescript
import InventoryVersionsModal from "./InventoryVersionsModal";

const ParentComponent = ({ selectedSoftware, onClose }) => (
  <>
    {selectedSoftware && (
      <InventoryVersionsModal
        hostSoftware={selectedSoftware}
        onExit={onClose}
      />
    )}
  </>
);
```

## Behavior Notes

- The modal title is derived from `getDisplayedSoftwareName`, which resolves between `name` and `display_name` on the software entry.
- The modal uses `width="large"` to accommodate version tables.
- Scroll state is recalculated on every `window` resize to keep the footer shadow in sync.
- The footer contains a single **Close** button that fires `onExit`.
