A modal component that displays geolocation information for a host device, with platform-aware messaging for iOS/iPadOS devices and MDM lock state handling.

## Key Components

### Exports
- **`LocationModal`** (default) — Modal component rendering host location data with conditional UI based on device type and MDM status
- **`getCityCountryLocation`** — Utility that formats an `IGeoLocation` object into a `"City, CountryISO"` string

### Internal Helpers
- **`getLocationMessage`** — Returns contextual JSX messaging based on iOS/iPadOS status and MDM device state (`unlocked`, `locking`, `locating`, or default)
- **`buildGoogleMapsLinkFromGeo`** — Builds a Google Maps URL from coordinates (preferred) or city/country fallback

### Props (`ILocationModal`)
| Prop | Type | Description |
|---|---|---|
| `hostGeolocation` | `IGeoLocation` (optional) | Raw geolocation data for the host |
| `onExit` | `() => void` | Callback to close the modal |
| `onClickLock` | `() => void` | Callback to trigger MDM lock |
| `iosOrIpadosDetails` | `IIosOrIpadosDetails` (optional) | Platform and MDM status context |
| `detailsUpdatedAt` | `string` (optional) | Timestamp for last location update |

## Usage Example

```typescript
<LocationModal
  hostGeolocation={{
    city_name: "San Francisco",
    country_iso: "US",
    geometry: { coordinates: [37.7749, -122.4194] },
  }}
  onExit={() => setShowLocationModal(false)}
  onClickLock={() => handleLockDevice(hostId)}
  iosOrIpadosDetails={{
    isIosOrIpadosHost: true,
    hostMdmDeviceStatus: "unlocked",
  }}
  detailsUpdatedAt="2024-01-15T10:30:00Z"
/>
```

> **Note:** For unlocked iOS/iPadOS hosts, the modal renders a **Lock** action button instead of the standard **Close** button, as Apple requires Lost Mode to be active before location data is accessible.
