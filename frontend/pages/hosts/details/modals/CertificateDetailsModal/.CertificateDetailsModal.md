A React modal component that displays detailed information about a host certificate, organized into labeled sections.

## Key Components

**`CertificateDetailsModal`** — Default export. Renders a `Modal` containing structured certificate data across up to six collapsible sections, each shown only when relevant data is present:

| Section | Fields Displayed |
|---|---|
| Subject name | Country/region, organization, org unit, common name |
| Issuer name | Country/region, organization, org unit, common name |
| Validity period | Not valid before/after (formatted as `Month Day Year`) |
| Key info | Algorithm, key size, key usage, serial (hex + decimal) |
| Basic constraints | Certificate authority (always shown) |
| Signature | Signing algorithm |

**Props (`ICertificateDetailsModalProps`):**

| Prop | Type | Description |
|---|---|---|
| `certificate` | `IHostCertificate` | Certificate data object to display |
| `onExit` | `() => void` | Callback fired on modal close or button click |

**Serial number conversion** — Attempts to parse the hex serial as a `BigInt` and display a decimal equivalent, mirroring Keychain and OpenSSL display behavior. Only shown if the value is less than `2^63`; conversion errors are silently swallowed.

## Usage Example

```typescript
import CertificateDetailsModal from "./CertificateDetailsModal";

<CertificateDetailsModal
  certificate={selectedCertificate}
  onExit={() => setShowModal(false)}
/>
```

> Each `DataSet` field uses `TooltipTruncatedText` to handle long values gracefully with overflow tooltips.
