Renders a table displaying OS settings (MDM profiles) for a host, with support for resending profiles, resending certificate requests, and rotating recovery lock passwords.

## Key Components

- **`IOSSettingsTableProps`** — Interface defining the component's props:
  - `canResendProfiles` — Controls visibility of resend actions
  - `canRotateRecoveryLockPassword` — Toggles recovery lock password rotation action (defaults to `false`)
  - `tableData` — Array of `IHostMdmProfileWithAddedStatus` profile records
  - `resendRequest` — Async handler to resend a profile by UUID
  - `resendCertificateRequest` — Optional async handler to resend a certificate by template ID
  - `rotateRecoveryLockPassword` — Optional async handler for lock password rotation
  - `onProfileResent` — Callback triggered after a profile is successfully resent

- **`OSSettingsTable`** — Default export; functional component that wraps `TableContainer` with memoized column configuration

- **`tableConfig`** — Memoized via `useMemo` to prevent tooltip flickering during host data refetches; generated by `generateTableHeaders` from `OSSettingsTableConfig`

## Usage Example

```typescript
import OSSettingsTable from "./OSSettingsTable";

<OSSettingsTable
  canResendProfiles={true}
  canRotateRecoveryLockPassword={isAdmin}
  tableData={hostMdmProfiles}
  resendRequest={async (profileUUID) => {
    await api.resendProfile(hostId, profileUUID);
  }}
  resendCertificateRequest={async (templateId) => {
    await api.resendCertificate(hostId, templateId);
  }}
  rotateRecoveryLockPassword={async () => {
    await api.rotateRecoveryLock(hostId);
  }}
  onProfileResent={() => refetchHostData()}
/>
```
