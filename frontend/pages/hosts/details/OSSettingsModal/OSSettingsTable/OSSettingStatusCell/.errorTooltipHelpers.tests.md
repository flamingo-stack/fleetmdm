Tests for the `generateErrorTooltip` helper, verifying tooltip rendering logic for MDM profile error states across platforms and error types.

## Key Components

- **`renderTooltip`** — Local helper that wraps `generateErrorTooltip` output in a `div` and renders it via `@testing-library/react` for DOM assertions.
- **`generateErrorTooltip`** — The function under test, imported from `./errorTooltipHelpers`.
- **`createMockHostMdmProfile`** — Mock factory from `__mocks__/hostMock` used to construct typed MDM profile fixtures.

## Test Coverage

| Scenario | Expected Behavior |
|---|---|
| Non-failed profile status | Returns `null` |
| Failed profile with empty `detail` | Returns `null` |
| Windows profile with structured error string | Renders bold key labels and value text for each error segment |
| IdP email error | Renders an `<a>` "Learn more" link |
| Custom SCEP certificate error (`$FLEET_VAR_CUSTOM_SCEP_URL_*`) | Renders navigation hint and action text |
| DigiCert 410 (deleted profile ID) | Renders cert name, "Profile GUID" label, and settings path |
| DigiCert 400 (deleted/suspended profile) | Renders cert name, "Profile GUID" label, and settings path |
| DigiCert invalid API token | Renders CA name, "API token" label, and settings path |
| Unrecognized Darwin error | Returns the raw `detail` string |

## Usage Example

```typescript
// Running the test suite
// From repo root:
npx jest errorTooltipHelpers.tests.tsx

// Pattern used inside each test:
const tooltip = generateErrorTooltip(
  createMockHostMdmProfile({ status: "failed", detail: "some error" })
);
render(<div>{tooltip}</div>);
expect(screen.getByText(/some error/)).toBeInTheDocument();
```
