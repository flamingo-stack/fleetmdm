Unit tests for the `OSSettingStatusCell` React component, verifying correct status text, tooltip content, and Android certificate profile UI behavior across various operation types and statuses.

## Key Components

- **`OSSettingStatusCell`** — The component under test, renders an MDM profile's status label and tooltip
- **`createCustomRenderer`** — Test utility that provides a `user` event object for simulating interactions (e.g., hover)
- **`createMockHostMdmProfile`** — Factory for generating mock MDM host profile objects
- **`FLEET_ANDROID_CERTIFICATE_TEMPLATE_PROFILE_ID`** — Constant identifying Android certificate profiles, used to trigger Android-specific UI paths
- **`ProfileOperationType`** — Union type (`"install"` | `"remove"`) controlling which status labels are displayed

## Test Coverage

| Scenario | Expected UI |
|---|---|
| `verifying` / `install` (generic) | Displays "Verifying" with matching tooltip |
| `pending` / `install` (Android cert) | Displays "Enforcing" + command tooltip |
| `delivering` / `install` (Android cert) | Displays "Enforcing" + command tooltip |
| `delivered` / `install` (Android cert) | Displays "Enforcing" + command tooltip |
| `delivering` / `remove` (Android cert) | Displays "Removing enforcement" + command tooltip |
| `delivered` / `remove` (Android cert) | Displays "Removing enforcement" + command tooltip |
| `pending` + profile `detail` field | Shows custom detail message in tooltip |
