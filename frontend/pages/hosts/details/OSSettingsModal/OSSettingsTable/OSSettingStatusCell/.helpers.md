Display configuration helpers for MDM profile and disk encryption status rendering, mapping operation types and statuses to UI display options (status text, icons, and tooltips).

## Key Components

### `isDiskEncryptionProfile(profileName)`
Checks whether a given profile name matches the Fleet FileVault profile display name constant.

### `ProfileDisplayOption`
Type representing a UI display entry containing `statusText`, `iconName`, and an optional `tooltip` function or string.

### `ProfileStatus`
Derived type from `OsSettingsTableStatusValue`, excluding Android certificate-specific statuses.

### `PROFILE_DISPLAY_CONFIG`
Primary configuration object mapping `install`/`remove` operation types across all profile statuses (`verified`, `verifying`, `pending`, `action_required`, `failed`) to their respective display options, with disk-encryption-aware tooltip logic.

### `WINDOWS_DISK_ENCRYPTION_DISPLAY_CONFIG`
Platform-specific display config for Windows BitLocker encryption statuses, including a BitLocker PIN `action_required` state.

### `LINUX_DISK_ENCRYPTION_DISPLAY_CONFIG`
Simplified display config for Linux disk encryption, covering only `verified`, `failed`, and `action_required` statuses.

### `RECOVERY_LOCK_PASSWORD_DISPLAY_CONFIG`
Display config for macOS Recovery Lock password statuses: `verified`, `pending`, `removing_enforcement`, and `failed`.

## Usage Example

```typescript
import {
  isDiskEncryptionProfile,
  PROFILE_DISPLAY_CONFIG,
  WINDOWS_DISK_ENCRYPTION_DISPLAY_CONFIG,
} from "./helpers";

// Check if a profile is the FileVault profile
const isFileVault = isDiskEncryptionProfile("FileVault 2"); // false
const isFileVaultCorrect = isDiskEncryptionProfile("Disk encryption"); // true (if matches constant)

// Retrieve display options for an install operation in "pending" status
const displayOption = PROFILE_DISPLAY_CONFIG.install.pending;
console.log(displayOption?.statusText); // "Enforcing"
console.log(displayOption?.iconName);   // "pending-outline"

// Resolve tooltip with context
const tooltip = typeof displayOption?.tooltip === "function"
  ? displayOption.tooltip({ isDiskEncryptionProfile: true })
  : displayOption?.tooltip;

// Windows BitLocker action_required display
const winDisplay = WINDOWS_DISK_ENCRYPTION_DISPLAY_CONFIG.action_required;
console.log(winDisplay?.statusText); // "Action required"
```
