Utility module for generating formatted error tooltips displayed in the OS Settings MDM profile status table's error column.

## Key Components

### `generateErrorTooltip(profile)`
Primary export. Accepts an `IHostMdmProfileWithAddedStatus` profile and returns a formatted `React.ReactNode` tooltip. Returns `null` if the profile status is not `"failed"` or has no detail. Dispatches to platform/error-specific formatters in priority order.

### `formatDetailIdpEmailError(detail)`
Matches errors containing `"There is no IdP email for this host."` and returns a JSX element with a "Learn more" link pointing to Fleet's IdP email documentation.

### `formatDetailCertificateError(detail)`
Handles DigiCert-related certificate profile errors via regex matching. Covers three cases:
- Invalid API token
- Deleted/suspended Profile GUID
- Missing `$FLEET_VAR_HOST_END_USER_EMAIL_IDP` fleet variable

Each case directs users to **Settings > Integrations > Certificates**.

### `formatAndroidProfileNotAppliedError(detail)`
Matches Android-specific profile application errors and appends a "Learn more" link to Fleet's Android profile errors documentation.

### `formatDetailWindowsProfile(detail)`
Parses Windows profile errors formatted as `"key1: value1, key2: value2"` into bold-keyed JSX spans. Special-cases BitLocker errors, rendering them as plain strings.

## Usage Example

```typescript
import generateErrorTooltip from "./errorTooltipHelpers";

// Inside a table cell renderer
const tooltipContent = generateErrorTooltip(profile);

if (tooltipContent) {
  return <TooltipWrapper tipContent={tooltipContent}>{statusLabel}</TooltipWrapper>;
}
```
