Renders tooltip content by accepting either a static string or a dynamic function that receives contextual props and returns a string or JSX element.

## Key Components

- **`TooltipContent`** — Default export component that evaluates `innerContent` and renders the result as a React fragment
- **`TooltipInnerContentOption`** — Union type accepting either a `string` or `TooltipInnerContentFunc`
- **`TooltipInnerContentFunc`** — Function type receiving `TooltipInnerContentProps` and returning `string | JSX.Element`
- **`TooltipInnerContentProps`** — Record of `string | number | boolean` values passed as context to dynamic tooltip functions

## Usage Example

```typescript
import TooltipContent, {
  TooltipInnerContentFunc,
} from "./TooltipContent";

// Static string tooltip
<TooltipContent
  innerContent="Hello, world!"
  innerProps={{}}
/>

// Dynamic function tooltip
const dynamicTooltip: TooltipInnerContentFunc = ({ name, count }) =>
  `${name} has ${count} items`;

<TooltipContent
  innerContent={dynamicTooltip}
  innerProps={{ name: "Fleet", count: 42 }}
/>
```

## Notes

- The component uses a React fragment (`<>...</>`) as its wrapper, keeping the DOM clean
- `innerProps` is always passed to function-based tooltips, even if the function ignores them
- Static strings are rendered directly without processing
