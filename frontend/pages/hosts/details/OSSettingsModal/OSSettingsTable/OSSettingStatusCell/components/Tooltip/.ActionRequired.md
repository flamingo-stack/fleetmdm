Renders tooltip inner content for "Action Required" MDM profile states, displaying context-aware instructions based on whether the viewer is the device user or an administrator.

## Key Components

**`TooltipInnerContentActionRequired`** — Default export. Accepts two props:

| Prop | Type | Description |
|------|------|-------------|
| `isDeviceUser` | `boolean` | Switches message between end-user and admin perspectives |
| `profileName` | `string` | Optional profile name rendered in bold within the instruction text |

## Usage Example

```typescript
// Device user view (e.g., on "My device" page)
<TooltipInnerContentActionRequired
  isDeviceUser={true}
  profileName="FileVault"
/>
// → "Follow the FileVault instructions on your My device page."

// Admin/technician view
<TooltipInnerContentActionRequired
  isDeviceUser={false}
  profileName="FileVault"
/>
// → "Ask the end user to follow the FileVault instructions on their My device page."

// Without a profile name
<TooltipInnerContentActionRequired
  isDeviceUser={false}
  profileName=""
/>
// → "Ask the end user to follow the instructions on their My device page."
```

## Notes

- When `profileName` is provided, it is wrapped in `<b>` for emphasis.
- The component produces no wrapping element — it returns a React Fragment, making it suitable for direct injection into a tooltip container.
