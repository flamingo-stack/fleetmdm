Configures the OS Settings table structure and data generation for MDM profile management across multiple host platforms (Windows, macOS/Darwin, Linux, iOS, iPadOS, Android).

## Key Components

### Types

- **`IHostMdmProfileWithAddedStatus`** — Extends `IHostMdmProfile`, replacing the `status` field with the broader `OsSettingsTableStatusValue` union type
- **`OsSettingsTableStatusValue`** — Union of `MdmDDMProfileStatus`, `INonDDMProfileStatus`, and `HostAndroidCertStatus`
- **`INonDDMProfileStatus`** — Extends `MdmProfileStatus` with an `"action_required"` variant for non-DDM profiles

### Exports

- **`generateTableConfig`** — Builds the three-column table definition (`Name`, `Status`, `Actions`), wiring up resend/rotate capabilities per profile type
- **`generateTableData`** — Routes MDM host data to the correct row-builder based on platform

### Internal Row Builders

| Function | Platform | Notes |
|---|---|---|
| `makeWindowsRows` | `windows` | Appends synthetic disk encryption row if status present |
| `makeLinuxRows` | `ubuntu`, `rhel` | Same pattern as Windows, uses Linux encryption status |
| `makeDarwinRows` | `darwin` | Handles FileVault `action_required` override and recovery lock password row |

## Usage Example

```typescript
// Generate column config for the table
const columns = generateTableConfig(
  canResendProfiles,
  resendRequest,
  onProfileResent,
  resendCertificateRequest,
  canRotateRecoveryLockPassword,
  rotateRecoveryLockPassword
);

// Generate row data based on host platform
const tableData = generateTableData(hostMDMData, host.platform);

// Render with react-table
<TableContainer columns={columns} data={tableData ?? []} />
```

The `Actions` column conditionally enables resend for Apple `.mobileconfig`, Windows, and Android certificate profiles, and rotate for recovery lock password rows identified by `REC_LOCK_SYNTHETIC_PROFILE_UUID`.
