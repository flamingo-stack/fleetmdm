A React table cell component that renders an OS settings profile name with optional user-scope indicator for MDM (Mobile Device Management) profile tables.

## Key Components

- **`OSSettingsNameCell`** — Default export. Renders a truncated profile name with tooltip, and conditionally displays a user icon with a tooltip showing the associated managed account when the profile scope is `"user"`.
- **`IOSSettingsNameCellProps`** — Props interface:
  - `profileName: string` — The MDM profile name to display.
  - `scope: ProfileScope | null` — Profile scope; shows user icon only when `"user"`.
  - `managedAccount: string | null` — Local user account name shown in the scope tooltip.

## Usage Example

```typescript
import OSSettingsNameCell from "components/TableContainer/DataTable/OSSettingsNameCell";

// Inside a table column definition
{
  Header: "Name",
  accessor: "name",
  Cell: ({ row }) => (
    <OSSettingsNameCell
      profileName={row.original.name}
      scope={row.original.scope}         // "user" | "system" | null
      managedAccount={row.original.managedAccount} // e.g. "jsmith"
    />
  ),
}
```

When `scope` is `"user"`, a user icon appears beside the profile name. Hovering it reveals a tooltip identifying the targeted local account:

```text
Scoped to local user account:
jsmith
```

For `scope` values other than `"user"` (e.g. `"system"` or `null`), only the truncated profile name is rendered.
