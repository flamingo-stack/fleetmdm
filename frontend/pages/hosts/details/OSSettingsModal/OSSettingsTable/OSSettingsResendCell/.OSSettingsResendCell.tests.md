Test suite for the `OSSettingsResendCell` component, verifying the conditional rendering of "Resend" and "Rotate" action buttons based on MDM profile status and permission flags.

## Key Components

- **`OSSettingsResendCell`** — The component under test; renders action buttons in an OS settings table cell
- **`createMockHostMdmProfile`** — Mock factory used to simulate MDM profile data with configurable `status` and `profile_uuid`
- **`REC_LOCK_SYNTHETIC_PROFILE_UUID`** — Constant identifying the Recovery Lock synthetic profile, used to trigger "Rotate" button logic

## Test Cases

| Scenario | Expected Output |
|---|---|
| `canResendProfiles=true` + `status: "failed"` | Renders **Resend** button |
| `canResendProfiles=true` + `status: "verified"` | Renders **Resend** button |
| `canRotateRecoveryLockPassword=true` + Recovery Lock UUID + `status: "verified"` | Renders **Rotate** button |
| `canRotateRecoveryLockPassword=true` + Recovery Lock UUID + `status: "failed"` | Renders **Rotate** button |
| `canRotateRecoveryLockPassword=false` + Recovery Lock UUID | Does **not** render Rotate button |
| `canRotateRecoveryLockPassword=true` + `status: "pending"` | Does **not** render Rotate button |

## Usage Example

```typescript
// Rendering the component with resend capability
render(
  <OSSettingsResendCell
    canResendProfiles
    canRotateRecoveryLockPassword={false}
    profile={createMockHostMdmProfile({ status: "failed" })}
    resendRequest={() => Promise.resolve()}
    rotateRecoveryLockPassword={() => Promise.resolve()}
  />
);

// Rendering with rotate capability for a Recovery Lock profile
render(
  <OSSettingsResendCell
    canResendProfiles={false}
    canRotateRecoveryLockPassword
    profile={createMockHostMdmProfile({
      profile_uuid: REC_LOCK_SYNTHETIC_PROFILE_UUID,
      status: "verified",
    })}
    resendRequest={() => Promise.resolve()}
    rotateRecoveryLockPassword={() => Promise.resolve()}
  />
);
```

## Notes

- The **Rotate** button is suppressed when `status` is `"pending"`, regardless of `canRotateRecoveryLockPassword`
- Both `resendRequest` and `rotateRecoveryLockPassword` are always required props, even when their respective actions are disabled
