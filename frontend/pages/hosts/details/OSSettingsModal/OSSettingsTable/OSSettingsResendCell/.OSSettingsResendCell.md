Renders an action cell within the OS Settings table that provides "Resend" and/or "Rotate" buttons for MDM profiles, handling async state, error notifications, and special-casing for Android certificates and Recovery Lock profiles.

## Key Components

- **`ResendButton`** — Displays a small refresh-icon button that shows "Resend" or "Resending..." based on in-flight state; disabled during the request.
- **`RotateButton`** — Displays a small refresh-icon button that shows "Rotate" or "Rotating..." based on in-flight state; disabled during the request.
- **`OSSettingsResendCell`** *(default export)* — Orchestrates visibility logic and async handlers for both buttons based on profile status and permissions.

### Visibility Rules
| Button | Condition |
|--------|-----------|
| Resend | `canResendProfiles` is `true`, profile status is `"failed"` or `"verified"`, and profile UUID is not the Recovery Lock synthetic profile |
| Rotate | `canRotateRecoveryLockPassword` is `true` and profile status is `"failed"` or `"verified"` |

## Usage Example

```typescript
<OSSettingsResendCell
  canResendProfiles={true}
  canRotateRecoveryLockPassword={false}
  profile={profile}
  resendRequest={async (profileUUID) => {
    await sendResendProfileRequest(hostId, profileUUID);
  }}
  resendCertificateRequest={async (certificateTemplateId) => {
    await sendResendCertificateRequest(hostId, certificateTemplateId);
  }}
  rotateRecoveryLockPassword={async () => {
    await rotateHostRecoveryLock(hostId);
  }}
  onProfileResent={() => refetchHostProfiles()}
/>
```
