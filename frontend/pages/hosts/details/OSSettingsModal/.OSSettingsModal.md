Modal component that displays OS settings (MDM profiles, certificates) for a host in a tabular format, with optional actions for resending profiles and rotating recovery lock passwords.

## Key Components

### `IOSSettingsModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `platform` | `string` | Host OS platform |
| `hostMDMData` | `IHostMdmData` | MDM profile/settings data for the host |
| `canResendProfiles` | `boolean` | Enables resend action on profile rows (default: `false`) |
| `canRotateRecoveryLockPassword` | `boolean` | Enables rotate action on recovery lock row (default: `false`) |
| `resendRequest` | `(profileUUID: string) => Promise<void>` | Callback to resend a specific profile |
| `resendCertificateRequest` | `(certificateTemplateId: number) => Promise<void>` | Callback to resend a certificate |
| `rotateRecoveryLockPassword` | `() => Promise<void>` | Callback to rotate recovery lock password |
| `onProfileResent` | `() => void` | Fires after a profile is successfully resent |
| `onClose` | `() => void` | Modal dismiss handler |

### `OSSettingsModal`
Memoizes table data via `generateTableData(hostMDMData, platform)` to avoid unnecessary recalculations, then renders `OSSettingsTable` inside a `Modal` wrapper with a Close button.

## Usage Example

```typescript
<OSSettingsModal
  platform="darwin"
  hostMDMData={host.mdm}
  canResendProfiles={currentUser.canManageHosts}
  canRotateRecoveryLockPassword={isHostOnline}
  resendRequest={(profileUUID) => resendHostProfile(host.id, profileUUID)}
  resendCertificateRequest={(templateId) =>
    resendCertificate(host.id, templateId)
  }
  rotateRecoveryLockPassword={() => rotatePassword(host.id)}
  onProfileResent={() => refetchHostData()}
  onClose={() => setShowOSSettingsModal(false)}
/>
```

> **Note:** The caller is responsible for ensuring `hostMDMData` is defined and the platform is MDM-supported. If either condition is unmet, an empty modal renders rather than throwing — per [Fleet's "make it obvious when stuff breaks" philosophy](https://fleetdm.com/handbook/company/why-this-way#why-make-it-obvious-when-stuff-breaks).
