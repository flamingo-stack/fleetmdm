Renders a card displaying local user accounts for a host, supporting search, pagination, and a disabled state when user collection is turned off.

## Key Components

- **`LocalUserAccounts`** — Default export. A React component that wraps a `TableContainer` inside a `Card` layout to display host local user accounts.
- **`ILocalUserAccountsProps`** — Interface defining the component's props.
- **`renderUsersCount`** — Memoized callback rendering a `TableCount` badge showing the number of users in `usersState`.
- **`generateTableHeaders`** — Imported utility that produces column configs for the users table.

## Props

| Prop | Type | Description |
|---|---|---|
| `users` | `IHostUser[]` | Raw user data from the host |
| `usersState` | `{ username: string }[]` | Filtered/searched user state |
| `isLoading` | `boolean` | Controls table loading indicator |
| `onUsersTableSearchChange` | `(queryData: ITableQueryData) => void` | Search/query change handler |
| `hostUsersEnabled` | `boolean?` | Hides table and shows disabled state if `false` |
| `className` | `string?` | Additional CSS class |

## Usage Example

```typescript
import LocalUserAccounts from "./LocalUserAccounts";

<LocalUserAccounts
  users={hostUsers}
  usersState={filteredUsers}
  isLoading={isFetchingUsers}
  onUsersTableSearchChange={(queryData) => handleSearch(queryData)}
  hostUsersEnabled={host.features?.enableHostUsers}
/>
```

## Behavior Notes

- When `hostUsersEnabled` is `false`, renders a disabled state with a link to Fleet's [enable user collection docs](https://fleetdm.com/learn-more-about/enable-user-collection).
- When `users` is empty, renders a "No users detected" empty state.
- Table footer is hidden when the result count is below `DEFAULT_PAGE_SIZE`.
