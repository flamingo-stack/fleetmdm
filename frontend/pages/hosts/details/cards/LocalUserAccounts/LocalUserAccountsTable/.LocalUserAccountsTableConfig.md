Generates and returns the column configuration array for the Local User Accounts data table, defining headers and cell renderers for username and shell fields.

## Key Components

- **`generateTableHeaders()`** — Factory function that returns an `IDataColumn[]` array with two column definitions:
  - `username` — Sortable column (case-insensitive) with a standard `HeaderCell` and `TextCell` renderer.
  - `shell` — Non-sortable column with a `TooltipWrapper` header explaining the field, and a `TextCell` renderer.
- **`IDataColumn`** — Interface describing the shape of each column config object, compatible with `react-table`.
- **`IHeaderProps` / `ICellProps`** — Prop interfaces typed for `react-table`'s column header and cell callback signatures.

## Usage Example

```typescript
import generateTableHeaders from "./LocalUserAccountsTableConfig";
import TableContainer from "components/TableContainer";

const LocalUserAccountsTable = ({ users }) => {
  const tableHeaders = generateTableHeaders();

  return (
    <TableContainer
      columns={tableHeaders}
      data={users}
      defaultSortHeader="username"
    />
  );
};
```

> **Note:** Cell props are injected by `react-table` at render time. See the [react-table `useTable` cell properties docs](https://react-table.tanstack.com/docs/api/useTable#cell-properties) for the full prop shape.
