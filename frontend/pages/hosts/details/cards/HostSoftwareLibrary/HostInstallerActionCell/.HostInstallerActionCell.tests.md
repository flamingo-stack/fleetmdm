Test suite for the `HostInstallerActionCell` component and `getActionButtonState` helper, validating button states, tooltips, and rendering logic for host software installation actions.

## Key Components

### `getActionButtonState` Tests
Covers the helper function that computes install/uninstall button enabled/disabled states and tooltip messages based on:
- `hostScriptsEnabled` — disables both buttons with tooltips when `false`
- `status` — disables both buttons during `pending_install` / `pending_uninstall`
- `appStoreApp` — disables uninstall; requires MDM enrollment for install
- `hostMDMEnrolled` — gates VPP/App Store app installations
- `isMyDevicePage` — bypasses script/MDM checks entirely
- `installedVersionsDetected` — controls `moreDisabled` flag

### `HostInstallerActionCell` Component Tests
Validates rendered output for install/uninstall buttons including:
- Button text (`Install` vs `Reinstall`) and icon (`install-icon` vs `refresh-icon`)
- Button visibility (uninstall hidden for App Store apps or when no `softwarePackage`)
- Disabled state when scripts are off
- Dynamic re-render when `status` transitions (e.g., `pending_install` → `installed`)
- Tooltip display on hover for MDM-disabled install button

## Usage Example

```typescript
// Verify button state logic directly
import { getActionButtonState } from "./HostInstallerActionCell";

const state = getActionButtonState({
  hostScriptsEnabled: true,
  status: null,
  appStoreApp: null,
  softwareId: 1,
  softwarePackage: mockSoftwarePackage,
  hostMDMEnrolled: true,
  installedVersionsDetected: true,
});
// { installDisabled: false, uninstallDisabled: false, moreDisabled: false }

// Render component in tests
render(
  <HostInstallerActionCell
    software={{ ...defaultSoftware, ui_status: "installed" }}
    onClickInstallAction={noop}
    onClickUninstallAction={noop}
    baseClass="test"
    hostScriptsEnabled
    hostMDMEnrolled
  />
);
```
