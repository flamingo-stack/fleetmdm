Renders install/uninstall action controls for the Host Details > Software Library card, handling button state, pending transitions, and conditional dropdown menus based on software type and host configuration.

## Key Components

### Exports

- **`HostInstallerActionCell`** — Main component rendering install and secondary action controls (uninstall button, "How to open" button, or a combined "More" dropdown) for a given software entry.
- **`HostInstallerActionButton`** — Reusable button primitive wrapping `Button` + `TooltipWrapper` + `Icon`; also used in Fleet Desktop Self-service with different disabled logic.
- **`getActionButtonState`** — Pure function computing `installDisabled`, `uninstallDisabled`, `moreDisabled`, and tooltip content based on host scripts, MDM enrollment, software type, and current install/uninstall status.

### Key Interfaces

| Interface | Purpose |
|---|---|
| `IHostInstallerActionCellProps` | Props for the cell (software, click handlers, host flags) |
| `IGetActionButtonStateProps` | Inputs to `getActionButtonState` |
| `IActionButtonState` | Return shape of `getActionButtonState` |

## Usage Example

```typescript
import {
  HostInstallerActionCell,
  getActionButtonState,
} from "./HostInstallerActionCell";

// Inside a table cell renderer:
<HostInstallerActionCell
  software={hostSoftwareRow}
  baseClass="host-software"
  hostScriptsEnabled={host.scripts_enabled}
  hostMDMEnrolled={host.mdm?.enrollment_status === "On (automatic)"}
  onClickInstallAction={(id, isScriptPackage) =>
    openInstallModal(id, isScriptPackage)
  }
  onClickUninstallAction={() => openUninstallModal()}
  onClickOpenInstructionsAction={() => openInstructionsModal()}
/>
```

## Behavior Notes

- **Pending lock**: clicking install/uninstall sets local `isInstallUninstallPendingLocal` to `true` immediately, disabling all actions before the API responds.
- **Button text/icon**: updated only when status leaves a pending state (preserves "Retry" text during in-flight requests).
- **Secondary action rendering logic**: shows a "More" dropdown when both uninstall and "How to open" are available; falls back to individual buttons otherwise.
- **`isMyDevicePage`**: skips script/MDM restriction tooltips since the Self-service UI already hides ineligible entries upstream.
