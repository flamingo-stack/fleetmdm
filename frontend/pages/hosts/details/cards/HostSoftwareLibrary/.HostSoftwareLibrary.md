React component that manages the host software library view, handling software installation, uninstallation, polling for pending operations, and displaying relevant modals for install/uninstall details.

## Key Components

### Interfaces & Types
- **`ITableSoftware`** — Extended `ISoftware` type with `vulnerabilities` as a string array for client-side filtering
- **`IHostSoftwareLibraryProps`** — Component props including host metadata, routing, query params, and callback handlers

### Functions
- **`parseHostSoftwareLibraryQueryParams`** — Parses and normalizes URL query parameters (page, query, sort, self-service, team) into a structured query object

### State Management
- Multiple modal states for install/uninstall detail views (`selectedHostSWInstallDetails`, `selectedHostSWIpaInstallDetails`, `selectedVPPInstallDetails`, etc.)
- `hostSoftwareLibraryRes` — Cached API response state
- `pendingSoftwareSetRef` — Ref tracking pending install/uninstall IDs for polling
- `pollingTimeoutIdRef` — Ref managing polling timeout cleanup

### Data Fetching
- Primary `useQuery` hook fetching host software via `hostAPI.getHostSoftware`
- Secondary polling query (`pending_installs`) that rechecks every 5 seconds while installs/uninstalls are pending

### Key Behaviors
- Automatically polls when pending installs/uninstalls are detected, stopping when host goes offline
- Triggers `refetchHostDetails` when a pending operation completes
- Refetches software data when parent host-details polling resolves

## Usage Example

```typescript
<HostSoftwareLibrary
  id={host.id}
  platform={host.platform}
  hostDisplayName={host.display_name}
  softwareUpdatedAt={host.software_updated_at}
  router={router}
  queryParams={parseHostSoftwareLibraryQueryParams(location.query)}
  pathname={location.pathname}
  hostTeamId={host.team_id ?? 0}
  hostName={host.hostname}
  onShowInventoryVersions={handleShowInventoryVersions}
  isSoftwareEnabled={isSoftwareEnabled}
  isHostOnline={host.status === "online"}
  refetchHostDetails={refetchHostDetails}
  isHostDetailsPolling={isPolling}
/>
```
