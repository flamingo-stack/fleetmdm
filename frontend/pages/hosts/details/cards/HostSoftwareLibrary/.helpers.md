Helper utilities for the Host Software Library feature, providing dropdown filter options, install/uninstall error message formatting, and accessors for last install/uninstall metadata.

## Key Components

### Types & Constants

- **`IHostSWLibraryDropdownFilterVal`** — Union type `"available" | "selfService"` for the filter dropdown.
- **`DROPDOWN_OPTIONS`** — Configuration array for the software filter dropdown, including labels, values, and help text (with JSX for the self-service entry).

### Error Message Helpers

- **`getInstallErrorMessage(e: unknown)`** — Maps raw API errors to user-friendly install failure messages. Handles specific cases: missing `fleetd`, macOS-only packages, expired VPP tokens, unresolvable Fleet variables, and passthrough messages for MDM/license errors.
- **`getUninstallErrorMessage(e: unknown)`** — Maps raw API errors to user-friendly uninstall failure messages. Handles script errors, missing uninstall scripts, and normalized API error strings.

### Data Accessors

- **`getLastInstall(software)`** — Returns the most recent install record from either `software_package` or `app_store_app`, or `null` if absent.
- **`getLastUninstall(software)`** — Returns the most recent uninstall record from `software_package`, or `null` if absent.

## Usage Example

```typescript
import {
  getInstallErrorMessage,
  getUninstallErrorMessage,
  getLastInstall,
  DROPDOWN_OPTIONS,
} from "./helpers";

// Render error from a failed install API call
try {
  await installSoftware(hostId, softwareId);
} catch (e) {
  const message = getInstallErrorMessage(e);
  // e.g. "Couldn't install. VPP token expired. Go to Settings > ..."
  showToast(message);
}

// Get last install timestamp
const lastInstall = getLastInstall(hostSoftware);
if (lastInstall) {
  console.log(lastInstall.installed_at);
}
```
