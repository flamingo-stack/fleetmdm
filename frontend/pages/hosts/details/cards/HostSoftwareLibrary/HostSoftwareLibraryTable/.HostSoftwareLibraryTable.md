Renders the software library table for a specific host, handling pagination, sorting, searching, and filtering of installed or available software with platform-aware rendering.

## Key Components

### `HostSoftwareLibraryTable` (default export)
The primary React component that wraps `TableContainer` with host-software-specific logic.

**Props (`IHostSoftwareLibraryTableProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `tableConfig` | `any` | Column configuration passed to `TableContainer` |
| `data` | `IGetHostSoftwareResponse \| IGetDeviceSoftwareResponse` | Raw API response |
| `enhancedData` | `IHostSoftwareWithUiStatus[]` | UI-enriched software rows |
| `platform` | `HostPlatform` | Host OS platform (affects rendering) |
| `selfService` | `boolean` | Toggles self-service filter mode |
| `canAddSoftware` | `boolean` | Controls visibility of the "Add software" action |
| `onAddSoftware` | `() => void` | Callback for the add software button |

### Internal Helpers

- **`determineQueryParamChange`** — Identifies which query parameter changed to correctly reset pagination.
- **`generateNewQueryParams`** — Builds the updated URL query params object from table query state.
- **`onQueryChange`** — Handles table state changes and pushes updated routes via `router.replace`.
- **`handleCustomFilterDropdownChange`** — Responds to the self-service/available dropdown and updates the route.
- **`renderCustomControls`** — Renders the `DropdownWrapper` filter above the table.

## Usage Example

```typescript
<HostSoftwareLibraryTable
  tableConfig={softwareTableConfig}
  data={hostSoftwareResponse}
  enhancedData={enrichedSoftwareRows}
  platform="darwin"
  isLoading={isLoading}
  router={router}
  sortHeader="name"
  sortDirection="asc"
  searchQuery=""
  page={0}
  pagePath="/hosts/42/software"
  selfService={false}
  teamId={1}
  canAddSoftware
  onAddSoftware={() => setShowAddSoftwareModal(true)}
/>
```

> **Android note:** If `platform` resolves as Android via `isAndroid()`, the component short-circuits and renders an `EmptyState` informing users that installers are unsupported, with a support link.
