Defines and exports the table column configuration for the host software library table, generating column headers and cell renderers for name, status, installed version, library version, and actions.

## Key Components

### `generateHostSWLibraryTableHeaders(options)`
Primary export that constructs the `react-table` column definitions array. Accepts an `IHostSWLibraryTableHeaders` options object and returns an `ISoftwareTableConfig[]` array.

**Columns generated:**
| Column | Description |
|---|---|
| `Name` | Sortable; renders `SoftwareNameCell` with self-service, policy count, and platform badges |
| `Status` | Non-sortable; renders `InstallStatusCell` with detail modal callbacks |
| `Installed version` | Non-sortable; renders `VersionCell` from installed versions |
| `Library version` | Non-sortable; renders `VersionCell` or `AndroidLatestVersionWithTooltip` for Play Store apps |
| `Actions` | Renders `HostInstallerActionCell`; **removed** when `userHasSWWritePermission` is `false` |

### Key Types
- `IHostSWLibraryTableHeaders` — options interface with permission flags, router, callbacks, and host metadata
- `ISoftwareTableConfig` — alias for `Column<IHostSoftwareWithUiStatus>`

## Usage Example

```typescript
import { generateHostSWLibraryTableHeaders } from "./HostSoftwareLibraryTableConfig";

const columns = generateHostSWLibraryTableHeaders({
  userHasSWWritePermission: true,
  hostScriptsEnabled: true,
  router,
  teamId: 42,
  hostMDMEnrolled: true,
  baseClass: "host-sw-library",
  onShowInventoryVersions: handleShowVersions,
  onShowUpdateDetails: handleUpdateDetails,
  onSetSelectedHostSWInstallDetails: handleInstallDetails,
  onSetSelectedHostSWIpaInstallDetails: handleIpaDetails,
  onSetSelectedHostSWScriptDetails: handleScriptDetails,
  onSetSelectedHostSWUninstallDetails: handleUninstallDetails,
  onSetSelectedVPPInstallDetails: handleVPPDetails,
  onClickInstallAction: handleInstall,
  onClickUninstallAction: handleUninstall,
  isHostOnline: true,
  hostName: "macbook-pro-01",
});
```

> **Note:** The `Actions` column is conditionally removed at runtime — it is appended last in the array and popped when `userHasSWWritePermission` is `false`.
