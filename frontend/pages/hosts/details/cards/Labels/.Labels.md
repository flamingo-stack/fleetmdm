Renders a card displaying the custom labels associated with a host, filtering out built-in labels and presenting each as a clickable pill button with truncated tooltip text.

## Key Components

- **`Labels`** — Default export; a React functional component that accepts label data and renders them inside a styled `Card` with a `CardHeader`.
- **`ILabelsProps`** — Interface defining the component's props:
  - `labels: ILabel[]` — Array of label objects to display.
  - `onLabelClick: (label: ILabel) => void` — Callback fired when a label pill is clicked.
  - `className?: string` — Optional additional CSS class.
- **Built-in label filtering** — Labels with `label_type === "builtin"` are excluded from rendering.
- **Empty state** — Displays a fallback message when no custom labels are associated with the host.

## Usage Example

```typescript
import Labels from "pages/hosts/HostDetails/Cards/Labels";
import { ILabel } from "interfaces/label";

const hostLabels: ILabel[] = [
  { id: 1, name: "Production", label_type: "regular", /* ... */ },
  { id: 2, name: "macOS", label_type: "builtin", /* ... */ }, // filtered out
];

const handleLabelClick = (label: ILabel) => {
  console.log("Navigating to label:", label.name);
};

<Labels
  labels={hostLabels}
  onLabelClick={handleLabelClick}
  className="my-custom-class"
/>
```
