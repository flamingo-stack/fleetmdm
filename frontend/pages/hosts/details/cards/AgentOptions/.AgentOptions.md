Renders a card displaying osquery agent configuration options (Config TLS refresh, Logger TLS period, Distributed interval) for a host detail view, with special handling for ChromeOS devices.

## Key Components

- **`AgentOptions`** — Default export. A React functional component that accepts osquery configuration data and renders it as a styled card.
- **`IAgentOptionsProps`** — Interface defining component props:
  - `osqueryData` — Raw osquery config object containing TLS/interval values
  - `wrapFleetHelper` — Formatter function that applies a helper (e.g. `secondsToHms`) with fallback handling
  - `isChromeOS` — Toggles ChromeOS-specific static values and tooltip
  - `className` — Optional additional CSS class
- **`CHROMEOS_AGENT_OPTIONS`** — Static fallback values shown for ChromeOS hosts where Fleet agent options are unsupported.

## Usage Example

```typescript
import AgentOptions from "components/AgentOptions";
import { secondsToHms } from "utilities/helpers";

const wrapFleetHelper = (helperFn, value) =>
  value ? helperFn(value) : "Unavailable";

<AgentOptions
  osqueryData={{
    config_tls_refresh: 3600,
    logger_tls_period: 60,
    distributed_interval: 30,
  }}
  wrapFleetHelper={wrapFleetHelper}
  isChromeOS={false}
/>

// ChromeOS variant — renders static "Not supported" values with tooltip
<AgentOptions
  osqueryData={{}}
  wrapFleetHelper={wrapFleetHelper}
  isChromeOS
/>
```

## Notes

- ChromeOS hosts display hardcoded values (`"Not supported"`, `"Not supported"`, `"10 secs"`) and a tooltip explaining that Fleet agent options are ignored on Chromebooks.
- Time values are converted from seconds to a human-readable format via `secondsToHms`.
