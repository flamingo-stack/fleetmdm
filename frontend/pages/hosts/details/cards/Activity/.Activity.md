A tabbed card component that displays host activity history, splitting between **Past** and **Upcoming** activity feeds with optional MDM command views.

## Key Components

- **`Activity`** — Primary export. Renders a `Card` with a two-tab layout (Past / Upcoming) using `react-tabs`.
- **`UpcomingTooltip`** — Internal helper component displaying an ordered-execution tooltip for the Upcoming tab header.
- **`IActivityProps`** — Interface defining all props, including tab state, pagination handlers, cancel/details callbacks, and MDM command toggles.

### Tab Panels

| Tab | Default View | MDM Commands View |
|---|---|---|
| Past | `PastActivityFeed` | `CommandFeed` (completed commands) |
| Upcoming | `UpcomingActivityFeed` | `CommandFeed` (pending commands) |

The MDM commands view is toggled via `MDMCommandsToggle` when `showMDMCommandsToggle` is `true`.

## Usage Example

```typescript
<Activity
  activeTab="past"
  showMDMCommandsToggle={true}
  showMDMCommands={false}
  activities={pastActivitiesResponse}
  commands={commandsResponse}
  isLoading={false}
  upcomingCount={3}
  canCancelActivities={true}
  isUpcomingDisabled={false}
  onChangeTab={(index, last, event) => handleTabChange(index)}
  onNextPage={() => fetchNextPage()}
  onPreviousPage={() => fetchPreviousPage()}
  onShowDetails={handleShowDetails}
  onShowCommandDetails={handleShowCommandDetails}
  onCancel={handleCancelActivity}
  onShowMDMCommands={handleShowMDMCommands}
  onHideMDMCommands={handleHideMDMCommands}
/>
```

> **Note:** The Upcoming tab can be disabled via `isUpcomingDisabled`, which renders a tooltip explaining platform support limitations (macOS, Windows, Linux, iOS, iPadOS only).
