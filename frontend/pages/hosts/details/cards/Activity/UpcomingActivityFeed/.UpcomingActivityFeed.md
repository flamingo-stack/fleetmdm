Renders a paginated feed of pending host activities, displaying queued actions (scripts, software installs, lock, wipe) with optional cancel controls and empty/error states.

## Key Components

- **`UpcomingActivityFeed`** — Default export. Stateless component that maps each upcoming activity to its corresponding component via `upcomingActivityComponentMap`, then wraps the list with a `Pagination` control.
- **`IUpcomingActivityFeedProps`** — Props interface defining:
  - `activities` — Response payload containing the activity list and pagination metadata
  - `canCancelActivities` — Toggles visibility of cancel buttons per item
  - `onShowDetails` — Callback to open an activity detail view
  - `onCancel` — Callback fired with the specific `IHostUpcomingActivity` to cancel
  - `onNextPage` / `onPreviousPage` — Pagination callbacks

## Behavior

| State | Rendered Output |
|---|---|
| `isError === true` | `<DataError>` with large padding |
| `activities` is undefined | `null` (loading state) |
| Empty activity list | `<EmptyFeed>` with tier-aware message |
| Activities present | Paginated list of activity components |

The empty state message is tier-aware: Premium tier users see a broader message covering scripts, software, lock, and wipe; free-tier users see only script runs.

## Usage Example

```typescript
<UpcomingActivityFeed
  activities={upcomingActivitiesResponse}
  isError={isError}
  canCancelActivities={currentUser?.global_role === "admin"}
  onShowDetails={(activity, details) => setSelectedActivity({ activity, details })}
  onCancel={(activity) => handleCancelActivity(activity.uuid)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
/>
```
