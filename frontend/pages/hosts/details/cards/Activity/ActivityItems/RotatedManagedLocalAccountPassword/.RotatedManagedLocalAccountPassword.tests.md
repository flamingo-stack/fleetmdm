Test suite for the `RotatedManagedLocalAccountPasswordActivityItem` component, verifying rendering behavior for managed local account password rotation activity items in the Fleet MDM host activity feed.

## Key Components

- **`RotatedManagedLocalAccountPasswordActivityItem`** — The component under test, rendered with mock past activity data
- **`createMockHostPastActivity`** — Mock factory used to generate test activity objects with configurable `actor_full_name` and `type`
- **`ActivityType.RotatedManagedLocalAccountPassword`** — The specific activity type being validated

## Test Cases

| Test | Description |
|------|-------------|
| User-triggered rotation | Verifies actor name and rotation message render for a named user |
| Fleet-initiated rotation | Verifies the same content renders when `actor_full_name` is `"Fleet"` (auto-rotation) |
| No cancel icon | Asserts `close-icon` is absent from the DOM |
| No details icon | Asserts `info-outline-icon` is absent from the DOM |

## Usage Example

```typescript
// Typical render pattern used across all test cases
render(
  <RotatedManagedLocalAccountPasswordActivityItem
    activity={createMockHostPastActivity({
      actor_full_name: "Test User",
      type: ActivityType.RotatedManagedLocalAccountPassword,
    })}
    tab="past"
  />
);

// Assert activity message is visible
expect(
  screen.getByText(/triggered rotation of the managed local account password/i)
).toBeVisible();
```
