Renders an activity feed item indicating that a managed local account password rotation was triggered for a host.

## Key Components

- **`RotatedManagedLocalAccountPasswordActivityItem`** — Default export. A React functional component that displays an activity entry showing which actor triggered a managed local account password rotation on the host.

## Usage Example

```typescript
import RotatedManagedLocalAccountPasswordActivityItem from "./RotatedManagedLocalAccountPassword";

<RotatedManagedLocalAccountPasswordActivityItem activity={activityData} />
```

## Notes

- Wraps the [`ActivityItem`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/ActivityItem) base component with `hideCancel` and `hideShowDetails` flags, suppressing cancel and detail expansion controls.
- Accepts `IHostActivityItemComponentProps`, expecting an `activity` object that includes `actor_full_name` for display.
