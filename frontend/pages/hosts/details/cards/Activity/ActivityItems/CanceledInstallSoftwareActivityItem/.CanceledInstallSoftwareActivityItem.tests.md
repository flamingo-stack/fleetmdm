Test suite for the `CanceledInstallSoftwareActivityItem` component, verifying correct rendering of canceled software installation activity items in the host activity feed.

## Key Components

- **`describe("CanceledInstallSoftwareActivityItem")`** — Groups three test cases covering content rendering and absence of interactive UI elements
- **`mockActivity`** — Shared mock built with `createMockHostPastActivity` using `ActivityType.CanceledInstallSoftware` and a `software_title` detail of `"test.app"`

## Test Cases

| Test | Assertion |
|---|---|
| Renders activity content | Verifies actor name, "canceled", software title, and "install on this host" text are visible |
| No cancel icon | Confirms `close-icon` test ID is absent from the DOM |
| No show details icon | Confirms `info-outline-icon` test ID is absent from the DOM |

## Usage Example

```typescript
// Running the tests
// All three cases share a single mock activity:
const mockActivity = createMockHostPastActivity({
  type: ActivityType.CanceledInstallSoftware,
  details: { software_title: "test.app" },
});

// The component is rendered in "past" tab context for each assertion
render(
  <CanceledInstallSoftwareActivityItem tab="past" activity={mockActivity} />
);
```

## Notes

- The component is expected to display informational text only — no interactive cancel (`close-icon`) or details (`info-outline-icon`) controls should be present for past canceled installs
- Tests use `@testing-library/react` with `screen` queries; visibility is asserted with `toBeVisible()` and DOM absence with `not.toBeInTheDocument()`
