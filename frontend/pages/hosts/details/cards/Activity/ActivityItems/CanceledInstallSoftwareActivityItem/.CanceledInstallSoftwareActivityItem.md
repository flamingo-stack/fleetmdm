Renders a host activity feed entry for a canceled software installation event, displaying the actor name, software title, and whether the cancellation occurred during the setup experience.

## Key Components

- **`CanceledInstallSoftwareActivityItem`** — Default export. A React functional component that wraps `ActivityItem` to display a formatted message for canceled software install activities.
- **`getDisplayedSoftwareName`** — Helper used to resolve the software's display name from `software_title` or `software_display_name` activity details.
- **`IHostActivityItemComponentProps`** — TypeScript interface defining the required `activity` prop shape.

## Usage Example

```typescript
import CanceledInstallSoftwareActivityItem from "./CanceledInstallSoftwareActivityItem";

<CanceledInstallSoftwareActivityItem activity={activityItem} />
```

The rendered output produces a message in the form:

```text
<ActorName> canceled <SoftwareName> install on this host [during setup experience].
```

The `hideCancel` and `hideShowDetails` props are passed to `ActivityItem`, suppressing the cancel action and details toggle in the UI for this read-only activity type.

## Notes

- The `fromSetupExperience` flag is read from `activity.details?.from_setup_experience` and appends " during setup experience" to the message when `true`.
