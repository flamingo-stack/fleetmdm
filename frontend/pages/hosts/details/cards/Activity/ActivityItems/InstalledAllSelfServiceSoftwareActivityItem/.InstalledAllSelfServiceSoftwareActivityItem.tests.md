Test suite for the `InstalledAllSelfServiceSoftwareActivityItem` component, validating rendering behavior for the self-service software bulk-install activity item across different activity states.

## Key Components

- **`InstalledAllSelfServiceSoftwareActivityItem`** — The component under test, rendered within a host past activity context
- **`createMockHostPastActivity`** — Mock factory used to construct `ActivityType.InstalledAllSelfServiceSoftware` activity fixtures
- **`ActivityType.InstalledAllSelfServiceSoftware`** — Enum value identifying the activity type being tested

## Test Cases

| Test | Description |
|------|-------------|
| Un-scoped roll-up | Verifies "End user" label appears and actor name is suppressed |
| Null category name | Confirms `null` category behaves identically to un-scoped |
| Category-scoped roll-up | Checks category name, "Install all" label, and scoped message render correctly |
| No action icons | Asserts cancel and info icons are absent from the activity item |

## Usage Example

```typescript
// Rendering a category-scoped activity item in tests
render(
  <InstalledAllSelfServiceSoftwareActivityItem
    activity={createMockHostPastActivity({
      type: ActivityType.InstalledAllSelfServiceSoftware,
      details: { self_service_category_name: "Productivity" },
    })}
    tab="past"
  />
);

expect(screen.getByText("Productivity")).toBeVisible();
expect(screen.getByText(/in the self-service/i)).toBeVisible();
```

## Notes

- The component always substitutes **"End user"** for the actor's full name, regardless of `actor_full_name`
- Un-scoped and `null` category renders use a generic message; named categories surface the category label inline
- No cancel or details icons are rendered for this activity type
