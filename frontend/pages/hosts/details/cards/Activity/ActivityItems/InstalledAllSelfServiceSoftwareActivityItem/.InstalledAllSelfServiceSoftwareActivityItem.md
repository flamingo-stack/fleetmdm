Renders an activity feed item for when an end user triggers the "Install all" action in the self-service software portal, optionally scoped to a specific category.

## Key Components

- **`InstalledAllSelfServiceSoftwareActivityItem`** — Default export. A functional component that wraps `ActivityItem` to display a self-service bulk-install event. Hides cancel and show-details controls since the actor is always treated as "End user" regardless of who initiated the action.

## Props

| Prop | Type | Description |
|------|------|-------------|
| `activity` | `IHostActivityItemComponentProps["activity"]` | Activity record; uses `details.self_service_category_name` to determine display text |

## Rendering Logic

- If `activity.details.self_service_category_name` is present → displays: **End user** selected the **Install all** option in the self-service **{categoryName}** category.
- If no category name → displays: **End user** installed all the software in self-service.

## Usage Example

```typescript
import InstalledAllSelfServiceSoftwareActivityItem from "./InstalledAllSelfServiceSoftwareActivityItem";

<InstalledAllSelfServiceSoftwareActivityItem
  activity={{
    details: {
      self_service_category_name: "Security Tools",
    },
    // ...other activity fields
  }}
/>
```

> **Note:** `hideCancel` and `hideShowDetails` are always set on the inner `ActivityItem` because self-service bulk installs are end-user initiated — no specific actor identity is surfaced in the UI.
