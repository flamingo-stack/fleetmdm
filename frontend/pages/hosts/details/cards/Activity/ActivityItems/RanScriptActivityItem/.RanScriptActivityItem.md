Renders an activity item describing a script execution event on a host, adapting the displayed message based on whether the activity is past, pending, or Fleet-initiated.

## Key Components

- **`RanScriptActivityItem`** — Default export. A functional component that wraps `ActivityItem` and composes a human-readable message for script run events.
- **`ranScriptPrefix`** — Dynamically computed string (`"ran"`, `"told Fleet to run"`, or `"will run"`) based on the `tab` prop and `activity.fleet_initiated` flag.
- **`formatScriptNameForActivityItem`** — Utility used to format the script name for display.

## Props

Accepts `IHostActivityItemComponentPropsWithShowDetails`, which includes:

| Prop | Description |
|---|---|
| `tab` | `"past"` or another value indicating activity timeline position |
| `activity` | Activity data including actor, script name, and setup experience flag |
| `onShowDetails` | Callback to show activity details |
| `onCancel` | Callback to cancel the activity |
| `isSoloActivity` | Whether this is the only activity displayed |
| `hideCancel` | Whether to hide the cancel control |

## Usage Example

```typescript
<RanScriptActivityItem
  tab="past"
  activity={{
    actor_full_name: "Jane Doe",
    fleet_initiated: false,
    details: {
      script_name: "install_software.sh",
      from_setup_experience: false,
    },
  }}
  onShowDetails={handleShowDetails}
  onCancel={handleCancel}
  isSoloActivity={false}
  hideCancel={false}
/>
```

**Rendered output examples:**

```text
"Jane Doe ran install_software.sh on this host."
"Fleet will run setup_script.sh on this host during setup experience."
"Jane Doe told Fleet to run cleanup.sh on this host."
```
