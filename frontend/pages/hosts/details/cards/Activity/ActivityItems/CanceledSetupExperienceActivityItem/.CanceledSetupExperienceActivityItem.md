Renders an activity feed item describing a canceled setup experience event, displayed when software installation failure causes Fleet to abort host setup and prompt the user to restart.

## Key Components

- **`CanceledSetupExperienceActivityItem`** — Default export. A functional component that wraps `ActivityItem` to display a human-readable message about a canceled setup experience, including the actor name and the software title that failed to install.
- **`IHostActivityItemComponentProps`** — Interface from `ActivityConfig` defining the required `activity` prop shape.
- **`baseClass`** — CSS class identifier (`"canceled-setup-experience-activity-item"`) applied to the root `ActivityItem` for styling.

## Usage Example

```typescript
import CanceledSetupExperienceActivityItem from "./CanceledSetupExperienceActivityItem";

<CanceledSetupExperienceActivityItem
  activity={{
    actor_full_name: "Jane Smith",
    details: {
      software_title: "Microsoft Office",
    },
    // ...other IActivity fields
  }}
/>
```

Renders as:

```text
Jane Smith canceled setup experience on this host because Microsoft Office failed to install. End user was asked to restart.
```

If `actor_full_name` is absent, the actor label falls back to `"Fleet"`. The `hideCancel` and `hideShowDetails` props suppress action controls that are not applicable for this activity type.
