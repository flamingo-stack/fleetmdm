Test suite for the `UnlockHostActivityItem` component, validating rendering behavior for host unlock activity feed items across different platform types and UI states.

## Key Components

- **`UnlockHostActivityItem`** — Component under test, imported from `./UnlockedHostActivityItem`
- **`createMockHostPastActivity`** — Mock factory used to generate activity data fixtures
- **Test suite (`describe`)** — Four test cases covering platform-specific content and icon visibility

## Test Cases

| Test | Description |
|------|-------------|
| Darwin hosts | Verifies actor name and PIN-specific unlock message are visible |
| Non-darwin hosts | Verifies actor name and generic "unlocked this host" message are visible |
| No cancel icon | Confirms `close-icon` is absent from the DOM |
| No details icon | Confirms `info-outline-icon` is absent from the DOM |

## Usage Example

```typescript
// Renders correctly for macOS (darwin) hosts
render(
  <UnlockHostActivityItem
    activity={createMockHostPastActivity({
      actor_full_name: "Test User",
      details: { host_platform: "darwin" },
    })}
    tab="past"
  />
);

// Renders correctly for non-darwin (Windows/Linux) hosts
render(
  <UnlockHostActivityItem
    activity={createMockHostPastActivity({ actor_full_name: "Test User" })}
    tab="past"
  />
);
```

## Notes

- Darwin hosts display a PIN-specific message: `"viewed the six-digit unlock PIN for this host."`
- Non-darwin hosts display a generic message matching `/unlocked this host/i`
- The component intentionally omits both the cancel (`close-icon`) and show-details (`info-outline-icon`) icons in `past` tab context
