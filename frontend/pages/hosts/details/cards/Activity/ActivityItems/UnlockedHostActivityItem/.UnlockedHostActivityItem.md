Renders an activity feed item for host unlock events, displaying either a generic "unlocked this host" message or a macOS-specific "viewed the six-digit unlock PIN" message based on the host platform.

## Key Components

- **`UnlockedHostActivityItem`** — Default export. A functional component that wraps `ActivityItem` and conditionally renders a description based on `activity.details?.host_platform`.

## Usage Example

```typescript
import UnlockedHostActivityItem from "./UnlockedHostActivityItem";

<UnlockedHostActivityItem activity={activity} />
```

## Behavior

| Platform | Displayed Message |
|---|---|
| `darwin` (macOS) | `viewed the six-digit unlock PIN for this host.` |
| All others | `unlocked this host.` |

The `ActivityItem` wrapper is rendered with `hideCancel` and `hideShowDetails` to suppress interactive controls not relevant to this read-only event type.
