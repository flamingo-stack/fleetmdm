Renders an activity feed item describing a canceled script execution on a host, displaying the actor's name and the script that was canceled.

## Key Components

- **`CanceledRunScriptActivityItem`** — Default export. A functional React component that wraps `ActivityItem` to display a canceled script run event, with the cancel and show-details controls hidden.
- **`formatScriptNameForActivityItem`** — Utility used to format the `script_name` from `activity.details` for human-readable display.
- **`IHostActivityItemComponentProps`** — TypeScript interface defining the expected `activity` prop shape.

## Usage Example

```typescript
import CanceledRunScriptActivityItem from "./CanceledRunScriptActivityItem";

<CanceledRunScriptActivityItem
  activity={{
    actor_full_name: "Jane Smith",
    details: {
      script_name: "install_agent.sh",
    },
    // ...other activity fields
  }}
/>
// Renders: "Jane Smith canceled script 'install_agent.sh' on this host."
```

## Behavior Notes

- **`hideCancel`** and **`hideShowDetails`** are passed to `ActivityItem`, suppressing interactive controls since the event is already in a terminal (canceled) state.
- The component is purely presentational — no local state or side effects.
