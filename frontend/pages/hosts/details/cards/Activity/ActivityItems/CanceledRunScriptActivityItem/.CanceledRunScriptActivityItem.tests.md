Test suite for the `CanceledRunScriptActivityItem` component, verifying rendering behavior for canceled script run activities in the host activity feed.

## Key Components

- **`describe("CanceledRunScriptActivityItem")`** — Top-level test suite grouping all assertions for the component
- **`createMockHostPastActivity`** — Factory used to generate a mock activity with type `ActivityType.CanceledRunScript` and a `script_name` detail
- **Three test cases:**
  - Verifies the activity content (user name, "canceled" text, script name) renders visibly
  - Confirms the cancel (close) icon is **not** present
  - Confirms the show-details (info-outline) icon is **not** present

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { createMockHostPastActivity } from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";
import CanceledRunScriptActivityItem from "./CanceledRunScriptActivityItem";

const mockActivity = createMockHostPastActivity({
  type: ActivityType.CanceledRunScript,
  details: { script_name: "test.sh" },
});

render(
  <CanceledRunScriptActivityItem tab="past" activity={mockActivity} />
);

// Expected visible elements
screen.getByText("Test User");       // Actor who canceled
screen.getByText(/canceled/i);       // Action label
screen.getByText(/test.sh/i);        // Script name

// Expected absent elements
screen.queryByTestId("close-icon");        // null
screen.queryByTestId("info-outline-icon"); // null
```

## Notes

- The component is a **read-only past activity item** — interactive controls (cancel and info icons) are intentionally absent for already-canceled entries.
- Tests follow the [Testing Library](https://testing-library.com/) pattern using `getByText` for visibility assertions and `queryByTestId` for absence checks.
