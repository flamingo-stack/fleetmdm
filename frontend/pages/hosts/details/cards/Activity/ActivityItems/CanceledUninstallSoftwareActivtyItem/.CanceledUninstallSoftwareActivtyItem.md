Renders an activity feed item representing a canceled software uninstallation action on a host, displaying the actor's name and the affected software.

## Key Components

- **`CanceledUninstallSoftwareActivtyItem`** — Default export; a React functional component that wraps `ActivityItem` with cancel/details UI hidden, tailored for the "canceled uninstall software" activity type.
- **`baseClass`** — BEM-style CSS class identifier (`canceled-uninstall-software-activty-item`) applied to the root element.
- **`getDisplayedSoftwareName`** — Utility imported from the SoftwarePage helpers to resolve a human-readable software name from `software_title` and `software_display_name` activity details.

## Usage Example

```typescript
import CanceledUninstallSoftwareActivtyItem from "./CanceledUninstallSoftwareActivtyItem";

const activity = {
  actor_full_name: "Jane Doe",
  details: {
    software_title: "Zoom",
    software_display_name: "Zoom Video Communications",
  },
  // ...other IActivity fields
};

<CanceledUninstallSoftwareActivtyItem activity={activity} />;
```

Renders as:

```text
Jane Doe canceled Zoom Video Communications uninstall on this host.
```

## Notes

- `hideCancel` and `hideShowDetails` props are explicitly set on `ActivityItem`, suppressing those controls since a canceled action requires no further interaction.
- Relies on `IHostActivityItemComponentProps` for type safety, ensuring consistent prop shape across all host activity item components.
