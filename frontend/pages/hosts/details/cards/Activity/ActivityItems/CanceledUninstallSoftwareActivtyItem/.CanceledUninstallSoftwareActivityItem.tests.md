Unit tests for the `CanceledUninstallSoftwareActivityItem` component, verifying correct rendering of canceled software uninstall activity entries in the host activity feed.

## Key Components

- **`describe("CanceledUninstallSoftwareActivityItem")`** — Test suite covering rendering behavior of the activity item component
- **`mockActivity`** — Shared mock fixture using `createMockHostPastActivity` with `ActivityType.CanceledUninstallSoftware` and a `software_title` detail
- **Three test cases:**
  - `renders the activity content` — Asserts user name, "canceled", software title, and "uninstall on this host" text are visible
  - `does not render the cancel icon` — Confirms no `close-icon` test ID is present
  - `does not render the show details icon` — Confirms no `info-outline-icon` test ID is present

## Usage Example

```typescript
// Running this test file
// From repo root:
// npx jest CanceledUninstallSoftwareActivityItem.tests.tsx

// Mock setup pattern used in tests
import { createMockHostPastActivity } from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";

const mockActivity = createMockHostPastActivity({
  type: ActivityType.CanceledUninstallSoftware,
  details: { software_title: "test.sh" },
});
```

## Notes

- All three tests render the component with `tab="past"`, reflecting its use in the historical activity tab
- The absence of `close-icon` and `info-outline-icon` confirms that canceled uninstall activities are display-only — no interactive controls are shown
