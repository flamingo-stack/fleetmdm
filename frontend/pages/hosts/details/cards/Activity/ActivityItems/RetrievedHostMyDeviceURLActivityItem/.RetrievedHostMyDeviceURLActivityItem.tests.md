Test suite for the `RetrievedHostMyDeviceURLActivityItem` component, verifying its rendering behavior within the host activity feed.

## Key Components

- **`RetrievedHostMyDeviceURLActivityItem`** — The component under test, rendered with a mocked past activity and `tab="past"` prop
- **`createMockHostPastActivity`** — Factory utility from `__mocks__/activityMock` used to generate test activity data

## Test Cases

| Test | Assertion |
|------|-----------|
| Renders activity content | Actor name and "retrieved the My device URL" text are visible |
| No cancel icon | `close-icon` test ID is absent from the DOM |
| No show details icon | `info-outline-icon` test ID is absent from the DOM |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { createMockHostPastActivity } from "__mocks__/activityMock";
import RetrievedHostMyDeviceURLActivityItem from "./RetrievedHostMyDeviceURLActivityItem";

render(
  <RetrievedHostMyDeviceURLActivityItem
    activity={createMockHostPastActivity({ actor_full_name: "Test User" })}
    tab="past"
  />
);

expect(screen.getByText("Test User")).toBeVisible();
expect(screen.getByText(/retrieved the My device URL/i)).toBeVisible();
```

## Notes

The suite confirms this activity item is a **display-only** component — it shows the actor name and action text, but intentionally omits interactive controls (cancel, details) that other activity item types may expose.
