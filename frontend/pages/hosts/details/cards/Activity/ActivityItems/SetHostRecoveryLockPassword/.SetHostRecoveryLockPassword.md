Renders an activity feed item describing when a Recovery Lock password was set for a host, displaying the actor's name and a static message.

## Key Components

- **`SetHostRecoveryLockPasswordActivityItem`** — Default export. A functional component that wraps `ActivityItem` to display a "set a Recovery Lock password" event. Cancel and show-details controls are hidden via `hideCancel` and `hideShowDetails`.

## Usage Example

```typescript
import SetHostRecoveryLockPasswordActivityItem from "./SetHostRecoveryLockPassword";

<SetHostRecoveryLockPasswordActivityItem activity={activity} />
```

> This component is registered in the activity feed configuration and rendered automatically when a `set_host_recovery_lock_password` activity type is encountered. It is not typically used in isolation.
