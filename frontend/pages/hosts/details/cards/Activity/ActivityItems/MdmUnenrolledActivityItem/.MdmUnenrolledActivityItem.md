Renders an activity feed item describing an MDM unenrollment event, displaying platform-appropriate messaging based on whether the host is a mobile device (Android/iPadOS/iOS) or a non-mobile platform.

## Key Components

- **`MdmUnenrolledActivityItem`** — Default export; React functional component that accepts `IHostActivityItemComponentProps` and renders an `ActivityItem` with contextual unenrollment messaging.
- **Platform branching** — Uses `isAndroid` and `isIPadOrIPhone` helpers to differentiate between mobile ("unenroll") and desktop ("turn off MDM") language.
- **Actor-aware messaging** — Conditionally renders the initiating user's full name (`actor_full_name`) when present, otherwise falls back to a passive-voice description.

## Usage Example

```typescript
import MdmUnenrolledActivityItem from "./MdmUnenrolledActivityItem";

// Rendered by the activity feed when activity.type === "mdm_unenrolled"
<MdmUnenrolledActivityItem
  activity={{
    actor_full_name: "Jane Doe",
    details: { platform: "darwin" },
    // ...other IActivity fields
  }}
/>
```

## Message Variants

| Platform | With actor | Without actor |
|---|---|---|
| Android / iPadOS / iOS | **Jane Doe** told Fleet to unenroll this host. | This host is unenrolled from Fleet. |
| All other platforms | **Jane Doe** told Fleet to turn off mobile device management (MDM) for this host. | Mobile device management (MDM) was turned off for this host. |

> **Note:** The `ActivityItem` wrapper is rendered with `hideCancel` and `hideShowDetails` — no cancel or detail expansion controls are shown for this activity type.
