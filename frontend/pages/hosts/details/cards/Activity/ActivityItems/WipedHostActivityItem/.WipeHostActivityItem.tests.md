Test suite for the `WipeHostActivityItem` component, verifying its rendering behavior in the "past" activity tab context.

## Key Components

- **`WipeHostActivityItem`** — The component under test, imported from `WipedHostActivityItem`
- **`createMockHostPastActivity`** — Mock factory used to generate test activity data with customizable fields

## Test Cases

| Test | Description |
|---|---|
| Renders activity content | Verifies actor name and "wiped this host" text are visible |
| No cancel icon | Asserts the `close-icon` element is absent from the DOM |
| No show details icon | Asserts the `info-outline-icon` element is absent from the DOM |

## Usage Example

```typescript
// Run the full test suite
npx jest WipeHostActivityItem.tests.tsx

// Example of the mock used in tests
const activity = createMockHostPastActivity({ actor_full_name: "Test User" });

render(
  <WipeHostActivityItem
    activity={activity}
    tab="past"
  />
);
```

## Notes

- All tests use the `"past"` tab prop, meaning only past-activity rendering is covered here
- The absence of `close-icon` and `info-outline-icon` confirms this activity item is **display-only** with no interactive controls (no cancel or detail-expansion actions)
