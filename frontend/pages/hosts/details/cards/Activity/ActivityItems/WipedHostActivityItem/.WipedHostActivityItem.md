Renders a read-only activity feed entry indicating that a host was wiped, displaying the actor's full name with no cancel or detail actions.

## Key Components

- **`WipedHostActivityItem`** – Default export. A functional React component that wraps `ActivityItem` to display a "wiped host" event in the activity timeline.

## Usage Example

```typescript
import WipedHostActivityItem from "./WipedHostActivityItem";

<WipedHostActivityItem activity={activity} />
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `activity` | `IHostActivityItemComponentProps["activity"]` | Activity record containing `actor_full_name` and related metadata |

## Behavior

- `hideCancel` and `hideShowDetails` are hardcoded to `true`, making this a display-only item with no interactive controls.
- Renders the message: **`actor_full_name`** wiped this host.
