Renders a host activity item indicating that a wipe operation has failed, displaying a static failure message within the shared `ActivityItem` wrapper.

## Key Components

- **`FailedWipeActivityItem`** — Default export. A functional React component that accepts `IHostActivityItemComponentProps` and renders an `ActivityItem` with cancel and show-details controls hidden.

## Usage Example

```typescript
import FailedWipeActivityItem from "./FailedWipeActivityItem";

<FailedWipeActivityItem activity={activityRecord} />
```

## Notes

- The `hideCancel` and `hideShowDetails` props suppress interactive controls, as a failed wipe requires no further inline action.
- Styled via the BEM base class `failed-wipe-activity-item`.
- Defined in [`FailedWipeActivityItem.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/ActivityItem/FailedWipeActivityItem.tsx).
