Renders a host activity item indicating that a Fleet enrollment profile renewal has failed, displaying a descriptive message within the shared `ActivityItem` wrapper.

## Key Components

- **`FailedEnrollmentProfileRenewalActivityItem`** — Default export. A functional React component that wraps `ActivityItem` to display a failure message for enrollment profile renewal events on a specific host.
- **`IHostActivityItemComponentPropsWithShowDetails`** — Interface providing `activity`, `onShowDetails`, and `isSoloActivity` props.
- **`baseClass`** — CSS class prefix (`failed-enrollment-profile-renewal-activity-item`) applied to the root `ActivityItem` element.

## Usage Example

```typescript
import FailedEnrollmentProfileRenewalActivityItem from "./FailedEnrollmentProfileRenewalActivityItem";

<FailedEnrollmentProfileRenewalActivityItem
  activity={activityData}
  onShowDetails={handleShowDetails}
  isSoloActivity={false}
/>
```

## Notes

- The `hideCancel` prop is hardcoded to `true`, preventing a cancel action from being rendered for this activity type.
- The component is purely presentational; interaction logic is delegated to the parent via `onShowDetails`.
