Renders a read-only activity feed entry for certificate resend events on a host, displaying the actor's name and the certificate name involved.

## Key Components

- **`ResentCertificateActivityItem`** — Default-exported React component that wraps `ActivityItem` to display a "resent certificate" host activity. Cancel and show-details controls are hidden via `hideCancel` and `hideShowDetails` props.
- **`IHostActivityItemComponentProps`** — Interface from `ActivityConfig` that types the `activity` prop, providing `actor_full_name` and `details.certificate_name`.

## Usage Example

```typescript
import ResentCertificateActivityItem from "./ResentCertificateActivityItem";

// Consumed via the host activity feed registry
<ResentCertificateActivityItem
  activity={{
    actor_full_name: "Jane Doe",
    details: {
      certificate_name: "com.example.wifi.cert",
    },
    // ...other IHostActivityItemComponentProps fields
  }}
/>
```

**Rendered output (prose):**
```text
Jane Doe resent com.example.wifi.cert certificate on this host.
```

## Notes

- The component is intentionally minimal — all layout and timestamp rendering is delegated to the shared `ActivityItem` wrapper.
- `hideCancel` and `hideShowDetails` are hardcoded, making this a display-only item with no interactive controls.
