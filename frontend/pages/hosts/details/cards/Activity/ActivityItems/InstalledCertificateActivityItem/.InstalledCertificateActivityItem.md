Renders a host activity item for certificate installation events, displaying either a success or failure message based on the activity's status.

## Key Components

- **`InstalledCertificateActivityItem`** — Default export. A functional component that wraps `ActivityItem` to display certificate installation activity, conditionally showing a "Show Details" control only on failed installs.
- **`isFailed`** — Derived boolean flag checking if `activity.details?.status === "failed_install"` to control message copy and detail visibility.

## Usage Example

```typescript
import InstalledCertificateActivityItem from "./InstalledCertificateActivityItem";

<InstalledCertificateActivityItem
  activity={{
    details: {
      status: "failed_install",
      certificate_name: "MyCorpCA.pem",
    },
    // ...other IActivity fields
  }}
  onShowDetails={(activity) => console.log("Show details", activity)}
/>
```

## Behavior

| `status`          | Message rendered                                           | "Show Details" shown |
|-------------------|------------------------------------------------------------|----------------------|
| `"failed_install"`| Fleet **failed to install** certificate `<name>` on this host. | ✅ Yes              |
| Any other value   | Fleet **installed** certificate `<name>` on this host.     | ❌ No               |

- `hideCancel` is always set — cancellation is not supported for this activity type.
- `onShowDetails` is forwarded to `ActivityItem` but is only surfaced in the UI on failure, allowing technicians to inspect failure details via the details panel.
