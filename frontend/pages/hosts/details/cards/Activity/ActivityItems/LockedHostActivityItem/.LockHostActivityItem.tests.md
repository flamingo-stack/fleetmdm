Test suite for the `LockHostActivityItem` component, verifying rendering behavior for locked host activity entries in the past activity tab.

## Key Components

- **`describe("LockHostActivityItem")`** — Test suite covering three behavioral assertions for the activity item component
- **`createMockHostPastActivity`** — Mock factory imported from `__mocks__/activityMock` used to generate test activity data
- **`LockHostActivityItem`** — Component under test, imported from `./LockedHostActivityItem`

## Tests

| Test | Assertion |
|------|-----------|
| Renders activity content | Actor name and "locked this host" text are visible |
| No cancel icon | `close-icon` test ID is absent from the DOM |
| No show details icon | `info-outline-icon` test ID is absent from the DOM |


## Notes

- Uses `@testing-library/react` for DOM rendering and assertions
- The `tab="past"` prop is passed in all tests, scoping behavior to the past activity view
- Absence of `close-icon` and `info-outline-icon` confirms that interactive controls (cancel, details) are intentionally hidden for past lock activities
