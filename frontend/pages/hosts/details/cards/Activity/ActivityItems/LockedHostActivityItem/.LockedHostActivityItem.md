Renders an activity feed item indicating that a host was locked, displaying the actor's name and a static locked message.

## Key Components

- **`LockedHostActivityItem`** – Default export. A React functional component that wraps the shared `ActivityItem` component to display a "locked host" event in an activity feed.
- **`baseClass`** – CSS class prefix (`"locked-host-activity-item"`) applied to the root `ActivityItem` for scoped styling.

## Usage Example

```typescript
import LockedHostActivityItem from "./LockedHostActivityItem";

<LockedHostActivityItem activity={activity} />
```

## Notes

- The `hideCancel` and `hideShowDetails` props are passed to `ActivityItem`, suppressing the cancel and show-details controls since locked host events are informational only.
- Accepts `IHostActivityItemComponentProps`, which provides the `activity` object containing `actor_full_name` and other event metadata.
- The rendered message follows the pattern: **`<actor name>`** locked this host.
