Renders an activity feed entry indicating that a user cleared the passcode on a host, wrapping the `ActivityItem` component with preset display options.

## Key Components

- **`ClearedPasscodeActivityItem`** – Default export; a functional React component that displays a formatted activity log entry for passcode-clearing events
- **`baseClass`** – CSS class identifier (`"cleared-passcode-activity-item"`) applied to the root `ActivityItem`
- **`IHostActivityItemComponentProps`** – Imported interface that types the `activity` prop, providing actor and event metadata

## Usage Example

```typescript
import ClearedPasscodeActivityItem from "./ClearedPasscodeActivityItem";

<ClearedPasscodeActivityItem activity={activity} />
```

The component renders a message in the format:

> **John Doe** cleared the passcode on this host.

Cancel and "show details" controls are suppressed via `hideCancel` and `hideShowDetails` props passed to `ActivityItem`.

## Notes

- This component is part of a host activity feed system and is registered via `ActivityConfig`
- It has no internal state or side effects — purely presentational
