Test suite for the `CreatedManagedLocalAccountActivityItem` component, verifying its rendering behavior for the `CreatedManagedLocalAccount` activity type.

## Key Components

- **`describe` block** — Groups three tests scoped to `CreatedManagedLocalAccountActivityItem`
- **`createMockHostPastActivity`** — Factory helper from `__mocks__/activityMock` used to generate fixture data with `ActivityType.CreatedManagedLocalAccount`
- **Test cases:**
  - `renders the activity content` — Asserts the actor name and description text are visible
  - `does not render the cancel icon` — Confirms no `close-icon` element is present
  - `does not render the show details icon` — Confirms no `info-outline-icon` element is present

## Usage Example

```typescript
// Running the tests
// jest or vitest will pick this file up automatically

render(
  <CreatedManagedLocalAccountActivityItem
    activity={createMockHostPastActivity({
      actor_full_name: "Fleet",
      type: ActivityType.CreatedManagedLocalAccount,
    })}
    tab="past"
  />
);

// Assertions
expect(screen.getByText("Fleet")).toBeVisible();
expect(
  screen.getByText(/created a managed local account for this host/i)
).toBeVisible();
expect(screen.queryByTestId("close-icon")).not.toBeInTheDocument();
expect(screen.queryByTestId("info-outline-icon")).not.toBeInTheDocument();
```

## Notes

- All three tests share the same render setup; the component is intentionally read-only with no interactive icons (`close-icon`, `info-outline-icon`) for past activity entries.
