Renders a read-only activity feed entry indicating that Fleet created a managed local account for a host.

## Key Components

- **`CreatedManagedLocalAccountActivityItem`** – Default export; a functional React component that wraps `ActivityItem` with a fixed message and suppresses cancel/details controls.

## Usage Example

```typescript
import CreatedManagedLocalAccountActivityItem from "./CreatedManagedLocalAccountActivityItem";

<CreatedManagedLocalAccountActivityItem activity={activityRecord} />
```

## Props

| Prop | Type | Description |
|---|---|---|
| `activity` | `IHostActivityItemComponentProps["activity"]` | Activity record passed through to the underlying `ActivityItem` |

## Notes

- `hideCancel` and `hideShowDetails` are hardcoded, so this item is always display-only with no interactive controls.
- Conforms to the `IHostActivityItemComponentProps` interface defined in `ActivityConfig`, making it compatible with the host activity feed renderer.
