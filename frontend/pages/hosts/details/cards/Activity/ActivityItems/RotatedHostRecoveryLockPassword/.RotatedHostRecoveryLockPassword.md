Renders an activity feed item for the "rotated host recovery lock password" event, displaying the actor's name and a descriptive message.

## Key Components

- **`RotatedHostRecoveryLockPasswordActivityItem`** — Default export. A functional component that wraps `ActivityItem` to display a recovery lock password rotation event, with the cancel and show-details controls hidden.

## Usage Example

```typescript
import RotatedHostRecoveryLockPasswordActivityItem from "./RotatedHostRecoveryLockPassword";

<RotatedHostRecoveryLockPasswordActivityItem activity={activityData} />
```

## Notes

- Accepts `IHostActivityItemComponentProps` which provides the `activity` object containing `actor_full_name` and related metadata.
- `hideCancel` and `hideShowDetails` are passed to `ActivityItem` to suppress interactive controls not relevant for this read-only event.
