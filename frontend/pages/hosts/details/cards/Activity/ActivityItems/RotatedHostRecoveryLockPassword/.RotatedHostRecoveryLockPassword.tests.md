Tests for the `RotatedHostRecoveryLockPasswordActivityItem` component, verifying rendered content and absent UI elements for the `RotatedHostRecoveryLockPassword` activity type.

## Key Components

- **`RotatedHostRecoveryLockPasswordActivityItem`** — The component under test, rendering activity feed entries for Recovery Lock password rotation events
- **`createMockHostPastActivity`** — Mock factory from `activityMock` used to generate test activity data
- **`ActivityType.RotatedHostRecoveryLockPassword`** — Enum value identifying this activity type

## Test Cases

| Test | Description |
|------|-------------|
| User-triggered rotation | Verifies actor name and rotation message render for a named user |
| Fleet-initiated rotation | Verifies the same content renders when `actor_full_name` is `"Fleet"` (auto-rotation) |
| No cancel icon | Asserts `close-icon` is absent from the rendered output |
| No details icon | Asserts `info-outline-icon` is absent from the rendered output |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { createMockHostPastActivity } from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";
import RotatedHostRecoveryLockPasswordActivityItem from "./RotatedHostRecoveryLockPassword";

render(
  <RotatedHostRecoveryLockPasswordActivityItem
    activity={createMockHostPastActivity({
      actor_full_name: "Test User",
      type: ActivityType.RotatedHostRecoveryLockPassword,
    })}
    tab="past"
  />
);

expect(screen.getByText("Test User")).toBeVisible();
expect(
  screen.getByText(/triggered rotation of the Recovery Lock password/i)
).toBeVisible();
```
