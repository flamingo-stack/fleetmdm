Unit tests for the `ReadHostDiskEncryptionKeyActivityItem` component, verifying it correctly renders activity content and omits cancel/details icons.

## Key Components

- **`ReadHostDiskEncryptionKeyActivityItem`** — The component under test, rendered as a past activity item for disk encryption key read events
- **`createMockHostPastActivity`** — Mock factory used to generate test activity data with a configurable `actor_full_name`

## Test Cases

| Test | Assertion |
|---|---|
| Renders activity content | Actor name and "viewed the disk encryption key" text are visible |
| No cancel icon | `close-icon` test ID is absent from the DOM |
| No show details icon | `info-outline-icon` test ID is absent from the DOM |

## Usage Example

```typescript
// Running the test suite
import { render, screen } from "@testing-library/react";
import { createMockHostPastActivity } from "__mocks__/activityMock";
import ReadHostDiskEncryptionKeyActivityItem from "./ReadHostDiskEncryptionKey";

render(
  <ReadHostDiskEncryptionKeyActivityItem
    activity={createMockHostPastActivity({ actor_full_name: "Test User" })}
    tab="past"
  />
);

// Verifies actor name and action text are rendered
expect(screen.getByText("Test User")).toBeVisible();
expect(screen.getByText(/viewed the disk encryption key/i)).toBeVisible();
```

## Notes

- All three tests use the `"past"` tab prop, confirming this activity is only expected in the historical activity view
- The absence of `close-icon` and `info-outline-icon` confirms this activity item is non-interactive (no cancellation or detail expansion)
