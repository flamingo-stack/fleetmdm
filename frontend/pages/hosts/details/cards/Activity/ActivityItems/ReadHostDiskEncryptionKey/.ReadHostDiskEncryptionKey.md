Renders an activity feed item indicating that a user viewed a host's disk encryption key.

## Key Components

- **`ReadHostDiskEncryptionKeyActivityItem`** — Default export. A React functional component that displays a read-only activity entry showing the actor's name and the action performed.
- **`baseClass`** — CSS class (`locked-host-activity-item`) applied to the wrapping `ActivityItem`.

## Usage Example

```typescript
import ReadHostDiskEncryptionKeyActivityItem from "./ReadHostDiskEncryptionKey";

<ReadHostDiskEncryptionKeyActivityItem activity={activity} />
```

The component delegates layout and structure to `ActivityItem`, with `hideCancel` and `hideShowDetails` set to suppress interactive controls. The rendered message follows the pattern:

```text
<actor_full_name> viewed the disk encryption key for this host.
```

## Notes

- Accepts a single `activity` prop typed as `IHostActivityItemComponentProps`.
- No user interaction is exposed — the entry is purely informational.
