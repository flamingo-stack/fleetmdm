Test suite for the `ViewedManagedLocalAccountActivityItem` component, verifying its rendering behavior for the `ViewedManagedLocalAccount` activity type in the host past activity feed.

## Key Components

- **`describe("ViewedManagedLocalAccountActivityItem")`** — Top-level test suite grouping three behavioral assertions
- **`createMockHostPastActivity`** — Mock factory used to generate test activity data with `actor_full_name` and `ActivityType.ViewedManagedLocalAccount`
- **Three test cases:**
  - `renders the activity content` — Asserts the actor name and descriptive text are visible
  - `does not render the cancel icon` — Confirms no `close-icon` test ID is present
  - `does not render the show details icon` — Confirms no `info-outline-icon` test ID is present

## Usage Example

```typescript
// Run this test file with Jest
// Located alongside the component it tests

import { createMockHostPastActivity } from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";

// Mock shape used across all tests
const mockActivity = createMockHostPastActivity({
  actor_full_name: "Test User",
  type: ActivityType.ViewedManagedLocalAccount,
});

// Component is rendered with the "past" tab prop
<ViewedManagedLocalAccountActivityItem
  activity={mockActivity}
  tab="past"
/>
```

## Notes

- All three tests share the same render setup — consider a `beforeEach` refactor if cases expand
- The absence of `close-icon` and `info-outline-icon` confirms this activity type is **read-only** with no interactive controls
