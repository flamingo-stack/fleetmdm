Renders a read-only activity feed entry indicating that a user viewed the managed local account on a host.

## Key Components

- **`ViewedManagedLocalAccountActivityItem`** – Default export. A React functional component that displays an activity item with the actor's full name and a static description message. Cancellation and detail controls are hidden via `hideCancel` and `hideShowDetails` props passed to `ActivityItem`.
- **`IHostActivityItemComponentProps`** – Interface imported from `ActivityConfig` that types the `activity` prop.

## Usage Example

```typescript
import ViewedManagedLocalAccountActivityItem from "./ViewedManagedLocalAccountActivityItem";

<ViewedManagedLocalAccountActivityItem activity={activityRecord} />
```

The rendered output will display:

```text
[Actor Full Name] viewed the managed local account on this host.
```
