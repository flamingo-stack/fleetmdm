Renders an activity feed item indicating that a user viewed the Recovery Lock password for a specific host.

## Key Components

- **`ViewedHostRecoveryLockPasswordActivityItem`** — Default export. A functional React component that displays an actor's name and a fixed message describing the Recovery Lock password view event.

## Usage Example

```typescript
import ViewedHostRecoveryLockPasswordActivityItem from "./ViewedHostRecoveryLockPassword";

<ViewedHostRecoveryLockPasswordActivityItem activity={activity} />
```

## Notes

- Wraps the shared `ActivityItem` component with `hideCancel` and `hideShowDetails` flags, suppressing cancel and detail controls.
- Expects an `activity` prop conforming to `IHostActivityItemComponentProps`, which provides `actor_full_name` and related activity metadata.
