Renders a host activity item indicating that Fleet failed to rotate the managed local account password for a given host.

## Key Components

- **`FailedToRotateManagedLocalAccountPasswordActivityItem`** — Default export. A React functional component that displays a read-only activity entry with a fixed failure message. Hides the cancel and show-details controls via `hideCancel` and `hideShowDetails` props passed to `ActivityItem`.

## Usage Example

```typescript
import FailedToRotateManagedLocalAccountPasswordActivityItem from "./FailedToRotateManagedLocalAccountPassword";

<FailedToRotateManagedLocalAccountPasswordActivityItem activity={activity} />
```

## Notes

- Accepts `IHostActivityItemComponentProps`, which provides the `activity` object describing the event context.
- The message is static: **Fleet** failed to rotate the managed local account password for this host.
- No interactive controls are exposed (`hideCancel` and `hideShowDetails` are both set).
