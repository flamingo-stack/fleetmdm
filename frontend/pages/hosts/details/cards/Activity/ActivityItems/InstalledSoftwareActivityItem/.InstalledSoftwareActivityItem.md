Renders a host activity item for software installation and uninstallation events, handling self-service, fleet-initiated, and setup experience scenarios with appropriate messaging.

## Key Components

- **`InstalledSoftwareActivityItem`** — Default export. A React component that displays a formatted activity message for install/uninstall actions on a host.
- **`getInstallUninstallStatusPredicate`** — Generates active-voice verb phrases (e.g., "installed", "failed to uninstall") based on status and package source type.
- **`getInstallUninstallStatusPredicatePassive`** — Generates passive-voice verb phrases for self-service activities (e.g., "was installed").
- **`SCRIPT_PACKAGE_SOURCES`** — Constant used to determine if the software source uses a script-based installation method, which affects the predicate wording.

## Rendering Logic

| Scenario | Output Format |
|---|---|
| Self-service | `<title> was installed on this host (self-service).` |
| Fleet-initiated (pending) | `Fleet will install <title> on this host.` |
| Actor-initiated | `<actorName> installed <title> on this host.` |
| Setup experience | Appends `" during setup experience"` before the period |

## Usage Example

```typescript
<InstalledSoftwareActivityItem
  tab="past"
  activity={{
    actor_full_name: "Jane Doe",
    fleet_initiated: false,
    details: {
      software_title: "Slack",
      status: "installed",
      source: "apps",
      self_service: false,
      from_setup_experience: false,
    },
  }}
  onShowDetails={handleShowDetails}
  onCancel={handleCancel}
  hideCancel={false}
  isSoloActivity={false}
/>
// Renders: "Jane Doe installed Slack on this host."
```
