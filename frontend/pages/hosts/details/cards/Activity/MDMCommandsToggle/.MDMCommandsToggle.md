A toggle slider component for showing/hiding MDM (Mobile Device Management) commands, optionally displaying a count of available commands.

## Key Components

- **`MDMCommandsToggle`** — Default export. A wrapper around the `Slider` component that renders a labeled toggle for MDM commands visibility.
- **`IMDMCommandsToggleProps`** — Interface defining the component's props:
  - `showMDMCommands` — Controls the current toggle state
  - `commandCount` — Optional number appended to the label (e.g. `Show MDM commands (5)`)
  - `className` — Optional additional CSS class
  - `onToggleMDMCommands` — Callback fired when the toggle changes

## Usage Example

```typescript
import MDMCommandsToggle from "components/MDMCommandsToggle";

const DeviceDetails = () => {
  const [showCommands, setShowCommands] = React.useState(false);

  return (
    <MDMCommandsToggle
      showMDMCommands={showCommands}
      commandCount={12}
      onToggleMDMCommands={() => setShowCommands((prev) => !prev)}
    />
  );
};
```

When `commandCount` is provided, the label renders as `Show MDM commands (12)`; otherwise it renders as `Show MDM commands`. Both the active and inactive states of the underlying `Slider` display the same label text.
