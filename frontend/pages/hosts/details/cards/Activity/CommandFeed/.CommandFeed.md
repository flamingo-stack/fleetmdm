Renders a paginated list of MDM commands, displaying either a populated feed of `CommandItem` components or an empty state when no commands are available.

## Key Components

- **`CommandFeed`** — Default export. Accepts a commands response object and renders the appropriate UI based on result availability.
- **`ICommandFeedProps`** — Interface defining required props:
  - `commands` — `IGetCommandsResponse` containing `results` and `meta` (pagination flags)
  - `emptyDescription` — Message shown when no commands exist
  - `onShowDetails` — Handler passed to each `CommandItem` for detail view navigation
  - `onNextPage` / `onPreviousPage` — Pagination callbacks

## Key Behaviors

- Renders `EmptyFeed` with a "No MDM commands" title when `results` is `null` or empty
- Maps over `results` to render a `CommandItem` per command, keyed by `command_uuid + host_uuid`
- Passes `meta.has_previous_results` and `meta.has_next_results` to `Pagination` to control button states and visibility

## Usage Example

```typescript
<CommandFeed
  commands={commandsResponse}
  emptyDescription="No commands have been run on this host."
  onShowDetails={(command) => handleShowDetails(command)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
/>
```
