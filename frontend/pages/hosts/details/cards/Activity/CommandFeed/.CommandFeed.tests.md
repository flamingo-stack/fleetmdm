Brief description of the file's purpose: Test suite for the `CommandFeed` component, validating empty state rendering and pagination visibility based on MDM command response data.

## Key Components

- **`createMockGetCommandsResponse`** — Mock factory imported from `__mocks__/commandMock` used to generate typed command response fixtures
- **`CommandFeed`** — The component under test, rendered via `@testing-library/react`
- **`defaultProps`** — Shared prop baseline including `emptyDescription` and pagination/detail callback stubs

## Test Cases

| Test | Scenario |
|---|---|
| `results: null` | Renders empty state with heading and description |
| `results: []` | Renders empty state for empty array |
| `has_next_results: false, has_previous_results: false` | Hides pagination buttons |
| `has_next_results: true, has_previous_results: true` | Shows "Previous" and "Next" buttons |

## Usage Example

```typescript
// Running the tests
// From the project root:
// npx jest CommandFeed.tests.tsx

// Example of what the mock factory produces:
const commands = createMockGetCommandsResponse({
  results: null, // triggers empty state
  meta: {
    has_next_results: false,
    has_previous_results: false,
  },
});

render(<CommandFeed commands={commands} onShowDetails={jest.fn()} />);
expect(screen.getByText("No MDM commands")).toBeInTheDocument();
```
