A lightweight wrapper component that renders an empty state UI for feed/list views using the shared `EmptyState` component.

## Key Components

- **`IEmptyFeedProps`** — Interface defining the component's props:
  - `title` *(required)* — Heading text displayed in the empty state
  - `message` *(required)* — Descriptive info text shown below the title
  - `className` *(optional)* — Additional CSS class for custom styling

- **`EmptyFeed`** — Functional component that delegates to `EmptyState` with the `"list"` variant preset

## Usage Example

```typescript
import EmptyFeed from "components/EmptyFeed";

const ActivityFeed = ({ items }) => {
  if (!items.length) {
    return (
      <EmptyFeed
        title="No activity yet"
        message="Activity will appear here once devices start reporting."
        className="activity-feed__empty"
      />
    );
  }

  return <>{/* render items */}</>;
};
```

## Notes

- Always renders `EmptyState` with `variant="list"`, making it suitable specifically for list/feed contexts
- For non-list empty states, use `EmptyState` directly with a different variant
