Renders a paginated feed of completed host activities, displaying past actions (scripts, software, lock, wipe) with tier-aware empty states and graceful handling of unregistered activity types.

## Key Components

- **`PastActivityFeed`** – Default export; the primary component consuming `IHostPastActivitiesResponse` to render a list of past activity items
- **`IPastActivityFeedProps`** – Props interface defining feed data, error state, detail handler, and pagination callbacks
- **`pastActivityComponentMap`** – Registry lookup used to dynamically resolve the correct activity item component per `activity.type`
- **`EmptyFeed`** – Rendered when the activity list is null or empty, with messaging conditional on `isPremiumTier`
- **`Pagination`** – Controls next/previous page navigation using `meta.has_next_results` / `meta.has_previous_results`

## Usage Example

```typescript
import PastActivityFeed from "./PastActivityFeed";

<PastActivityFeed
  activities={pastActivitiesResponse}
  isError={isLoadingError}
  onShowDetails={(activity, details) => openDetailsModal(activity, details)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
/>
```

## Behavior Notes

- Returns `null` while `activities` is undefined (loading state)
- Renders `<DataError />` on fetch failure
- Logs a `console.warn` (without crashing) when an activity type has no registered component in `pastActivityComponentMap`
- Empty-state messaging differs between Premium and Free tiers via `AppContext`
