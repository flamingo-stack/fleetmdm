Renders a paginated list of pending MDM commands, displaying an empty state when no commands are queued.

## Key Components

- **`UpcomingCommandFeed`** — Main component that conditionally renders either an `EmptyFeed` placeholder or a scrollable list of `CommandItem` entries with pagination controls
- **`IUpcomingCommandFeedProps`** — Interface defining required props:
  - `commands` — `IGetCommandsResponse` containing `results` (command array) and `meta` (pagination state)
  - `onShowDetails` — Handler to surface command detail view
  - `onNextPage` / `onPreviousPage` — Pagination callbacks

## Usage Example

```typescript
import UpcomingCommandFeed from "./UpcomingCommandFeed";

<UpcomingCommandFeed
  commands={commandsResponse}
  onShowDetails={(command) => setSelectedCommand(command)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
/>
```

## Behavior Notes

- Returns `EmptyFeed` with a "No MDM commands" message when `results` is `null` or empty
- Each `CommandItem` is keyed by `command_uuid + host_uuid` to handle the same command targeting multiple hosts
- `Pagination` is hidden entirely when there are no adjacent pages, and individual prev/next buttons are disabled based on `meta.has_previous_results` / `meta.has_next_results`
