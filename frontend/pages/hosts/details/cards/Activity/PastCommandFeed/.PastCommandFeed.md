Renders a paginated list of past MDM commands, displaying an empty state when no commands exist or a scrollable feed of `CommandItem` entries with pagination controls.

## Key Components

- **`PastCommandFeed`** — Default export. Accepts a command response payload and page navigation handlers, conditionally rendering either an empty state or a list of commands with pagination.
- **`IPastCommandFeedProps`** — Props interface defining:
  - `commands` — `IGetCommandsResponse` containing `results` and `meta` (pagination flags)
  - `onShowDetails` — Handler passed to each `CommandItem` for viewing command details
  - `onNextPage` / `onPreviousPage` — Callbacks for pagination navigation
- **`EmptyFeed`** — Rendered when `results` is `null` or empty, with a "No MDM commands" message
- **`CommandItem`** — Rendered per command, keyed by a composite of `command_uuid` and `host_uuid`
- **`Pagination`** — Controls visibility and disabled state via `meta.has_previous_results` and `meta.has_next_results`

## Usage Example

```typescript
import PastCommandFeed from "./PastCommandFeed";

<PastCommandFeed
  commands={commandsResponse}
  onShowDetails={(command) => setSelectedCommand(command)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
/>
```
