Renders a single MDM command entry in a feed list, displaying the command's type, target device name, execution status, and a clickable detail trigger.

## Key Components

- **`ShowCommandDetailsHandler`** — Exported type alias for the callback invoked when a user clicks to view full command details; receives an `ICommand` object.
- **`ICommandItemProps`** — Internal interface defining `command: ICommand` and `onShowDetails: ShowCommandDetailsHandler` props.
- **`getStatusText(command)`** — Pure helper that maps `command_status` and `status` fields to a human-readable string (`"is pending"`, `"failed"`, `"was acknowledged"`, `"is deferred"`), with special handling for the `"NotNow"` MDM status.
- **`CommandItem`** — Default export; a functional React component that composes activity text and delegates rendering to `FeedListItem`.

## Usage Example

```typescript
import CommandItem, { ShowCommandDetailsHandler } from "./CommandItem";
import { ICommand } from "interfaces/command";

const handleShowDetails: ShowCommandDetailsHandler = (cmd: ICommand) => {
  console.log("Show details for:", cmd.request_type);
};

<CommandItem
  command={someCommand}
  onShowDetails={handleShowDetails}
/>
```

## Notes

- When `status` is `"NotNow"`, the status text reads `"is deferred"` and appends `" Fleet will try again."` to inform the user the command will be retried automatically.
- If the command includes a `name` (device name), the activity text includes it in bold; otherwise the message omits the device reference.
- Click events call `stopPropagation()` before invoking `onShowDetails` to prevent unintended event bubbling in the feed list.
