Test suite for the `HostSummary` component, validating rendering behavior across host summary data scenarios including issues, team assignment, platform-specific layouts, maintenance windows, and bootstrap package indicators.

## Key Components

| Test Suite | Description |
|---|---|
| `Issues data` | Verifies the Issues header is omitted when no issues exist |
| `Fleet data` | Validates team name display and "Unassigned" fallback for `---` team values |
| `iOS and iPadOS data` | Confirms only Fleet data renders for `ios` and `ipados` platforms |
| `Maintenance window data` | Checks formatted timezone-aware start time rendering |
| `Bootstrap package data` | Ensures the bootstrap package indicator appears when a status is present |

## Usage Example

```typescript
// Run the full test suite
npx jest HostSummary.tests.tsx

// Example: testing team name display
const summaryData = createMockHostSummary({ team_name: "Engineering" });
render(<HostSummary summaryData={summaryData} isPremiumTier />);
expect(screen.getByText("Fleet").nextElementSibling).toHaveTextContent("Engineering");

// Example: testing bootstrap package status
const bootstrapPackageData = { status: "installed" as BootstrapPackageStatus };
render(
  <HostSummary
    summaryData={summaryData}
    bootstrapPackageData={bootstrapPackageData}
    toggleBootstrapPackageModal={jest.fn()}
  />
);
expect(screen.getByText("Bootstrap package")).toBeInTheDocument();
```

## Notes

- Uses `createCustomRenderer` with a premium-tier global admin context for most tests
- Mock data is generated via `createMockHostSummary` and `createMockUser` from `__mocks__/`
