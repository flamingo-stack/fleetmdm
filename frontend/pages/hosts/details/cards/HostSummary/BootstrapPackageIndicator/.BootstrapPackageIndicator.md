Renders a status indicator for an MDM bootstrap package, displaying an icon, status label, and tooltip based on the current installation state.

## Key Components

- **`STATUS_DISPLAY_OPTIONS`** — Static map of `installed`, `pending`, and `failed` statuses to their respective icon name, display text, and tooltip content.
- **`IBootstrapPackageIndicatorProps`** — Interface requiring a `BootstrapPackageStatus` and an optional `onClick` callback.
- **`BootstrapPackageIndicator`** — Default export; composes `Icon`, `TooltipWrapper`, and conditionally a clickable `Button` (for `failed` status) or plain text (for other statuses).

## Usage Example

```typescript
import BootstrapPackageIndicator from "components/BootstrapPackageIndicator";
import { BootstrapPackageStatus } from "interfaces/mdm";

// Show a "Failed" indicator with a clickable button
<BootstrapPackageIndicator
  status={BootstrapPackageStatus.FAILED}
  onClick={() => console.log("View errors")}
/>

// Show an "Installed" indicator (no button, tooltip only)
<BootstrapPackageIndicator
  status={BootstrapPackageStatus.INSTALLED}
/>
```

## Behavior Notes

- **`installed` / `pending`** — Renders the status as plain tooltip-wrapped text alongside an icon.
- **`failed`** — Renders the status as an `inverse` variant `Button` inside the tooltip, enabling the `onClick` handler so users can navigate to error details.
