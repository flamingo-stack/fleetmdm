Renders a status indicator for a host's OS settings (MDM profiles), displaying an icon and clickable label that reflects the aggregate profile status across `Failed`, `Pending`, `Verifying`, and `Verified` states.

## Key Components

- **`OSSettingsIndicator`** – Main component accepting an array of `IHostMdmProfile` objects and an optional `onClick` handler. Displays an icon paired with a link-style button showing the computed status.
- **`getHostProfilesStatusForDisplay`** – Derives a single display status from all profiles using priority order: `Failed` > `Pending` > `Verifying` > `Verified`. Defaults to `Failed` if no condition matches.
- **`countHostProfilesByStatus`** – Reduces a profile array into counts per status bucket, mapping raw MDM statuses (e.g. `action_required`, `delivering`) into the four display categories.
- **`STATUS_DISPLAY_OPTIONS`** – Maps each `MdmProfileStatusForDisplay` value to its corresponding icon name (`success`, `success-outline`, `pending-outline`, `error`).

## Usage Example

```typescript
import OSSettingsIndicator from "components/OSSettingsIndicator";
import { IHostMdmProfile } from "interfaces/mdm";

const profiles: IHostMdmProfile[] = [
  { status: "verified", /* ...other fields */ },
  { status: "failed",   /* ...other fields */ },
];

<OSSettingsIndicator
  profiles={profiles}
  onClick={() => console.log("View OS settings details")}
/>
// Renders: [error icon] Failed  (link button)
```

> **Priority rule:** `Failed` always wins when any profile has that status, following Fleet's principle of making failures obvious. An empty `profiles` array renders `"Unavailable"` as a fallback.
