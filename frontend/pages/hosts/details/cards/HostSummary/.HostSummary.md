A React card component that displays a summarized overview of a host's key status information, including MDM settings, OS settings, issues, bootstrap packages, and maintenance windows.

## Key Components

### `HostSummary` (default export)
The main functional component rendering a `Card` with conditional `DataSet` entries based on host platform, tier, and MDM state.

**Props (`IHostSummaryProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `summaryData` | `any` | Core host data (status, platform, MDM, issues, team, etc.) |
| `bootstrapPackageData` | `IBootstrapPackageData` | Bootstrap package status and details |
| `isPremiumTier` | `boolean` | Controls team name and maintenance window visibility |
| `toggleOSSettingsModal` | `() => void` | Opens the OS settings modal |
| `toggleBootstrapPackageModal` | `() => void` | Opens the bootstrap package modal |
| `hostSettings` | `IHostMdmProfile[]` | MDM profile list, mutated internally to inject platform-specific disk encryption/recovery lock entries |
| `osSettings` | `IOSSettings` | Disk encryption and recovery lock password state |
| `className` | `string` | Additional CSS class |

### Internal Renderers
- **`renderIssues`** — Renders failing policies and vulnerability counts via `IssuesIndicator`
- **`renderHostTeam`** — Displays team name or "Unassigned"
- **`renderMaintenanceWindow`** — Formats and displays the next maintenance window with timezone-aware tooltip

### Platform-Specific Settings Injection
Before rendering, the component conditionally appends synthetic `IHostMdmProfile` entries to `hostSettings` for:
- **Windows** disk encryption status
- **Linux** disk encryption status (on supported platforms)
- **macOS** recovery lock password status (when enrolled in MDM)

## Usage Example

```typescript
<HostSummary
  summaryData={host}
  bootstrapPackageData={{ status: "installed", details: "Installed successfully" }}
  isPremiumTier={true}
  toggleOSSettingsModal={() => setOSSettingsOpen(true)}
  toggleBootstrapPackageModal={() => setBootstrapOpen(true)}
  hostSettings={host.mdm?.profiles ?? []}
  osSettings={host.os_settings}
/>
```
