Renders a host's vital statistics card for Fleet MDM, displaying key device metadata such as OS version, disk encryption status, agent version, location, MDM enrollment, and hardware details in an alphabetically sorted layout.

## Key Components

### Props (`IVitalsProps`)
- `vitalsData` — Raw host data object containing platform, OS, disk, battery, and agent fields
- `munki` — Optional Munki package manager data
- `mdm` — Optional MDM enrollment and status data
- `osVersionRequirement` — Apple device update requirements
- `toggleLocationModal` — Optional handler; presence makes the Location row interactive
- `toggleMDMStatusModal` — Optional handler; presence makes the MDM status row interactive

### Key Internals
- `renderVitalsAlphabetically()` — Builds and sorts an array of `VitalForSort` entries, conditionally including rows based on platform, MDM state, and data availability
- `getHostDiskEncryptionTooltipMessage()` — Returns platform-specific disk encryption tooltip copy for macOS, Windows, Linux, and Chrome OS
- `DISK_ENCRYPTION_MESSAGES` — Static map of per-platform encryption status strings

## Usage Example

```typescript
<Vitals
  vitalsData={host}
  mdm={host.mdm}
  munki={host.munki}
  osVersionRequirement={appleDeviceUpdates}
  toggleLocationModal={() => setShowLocationModal(true)}
  toggleMDMStatusModal={() => setShowMDMStatusModal(true)}
/>
```

## Notes

- BYOD (Account-Driven User Enrollment) hosts display an **Enrollment ID** instead of a serial number
- iOS/iPadOS and Android hosts skip agent, last restarted, and memory rows
- ADE-enrolled iDevices show a "Show location" button even without geolocation data
- Disk encryption support is gated by `platformSupportsDiskEncryption()` and respects per-distro Linux behavior (Arch, Manjaro, RHEL, Ubuntu report `unknown` instead of `off`)
