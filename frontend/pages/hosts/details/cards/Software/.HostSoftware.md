Renders the host or device software card, including data fetching, filter state management, and table rendering for both the host details page and the "My Device" page.

## Key Components

### `HostSoftware` (default component)
Main React component that orchestrates software listing for a host or device. Handles two distinct data sources:
- **Host software** — fetched via `hostAPI.getHostSoftware` (used on the Host Details page)
- **Device software** — fetched via `deviceAPI.getDeviceSoftware` (used on the My Device page, which is token-authenticated with no app session)

### `parseHostSoftwareQueryParams`
Utility function that normalizes raw URL query parameters into typed, structured params consumed by the component and API calls. Handles pagination, sorting, search, vulnerability filters, category, team, and the macOS `/Applications` tri-state filter.

### `ITableSoftware`
Extended interface derived from `ISoftware` that flattens `vulnerabilities` into a `string[]` of CVE identifiers for client-side search.

### `IHostSoftwareProps`
Full props interface for `HostSoftware`, including platform, routing, query params, premium tier flag, and MDM enrollment status.

## Usage Example

```typescript
import HostSoftware, { parseHostSoftwareQueryParams } from "./HostSoftware";

const queryParams = parseHostSoftwareQueryParams({
  page: "0",
  query: "chrome",
  order_key: "name",
  order_direction: "asc",
  vulnerable: "true",
});

<HostSoftware
  id={hostId}
  platform="darwin"
  router={router}
  queryParams={queryParams}
  pathname={location.pathname}
  hostTeamId={3}
  onShowInventoryVersions={(software) => console.log(software)}
  isSoftwareEnabled
  isPremiumTier
/>
```

## Notes

- The `macosApplications` filter defaults to `true` on macOS hosts (showing only top-level `/Applications`) unless explicitly overridden via URL params.
- `isPremiumTier` must be passed explicitly on the My Device page since it has no app context/session.
- Vulnerability filter changes are compared against current query params before triggering a route replace, preventing unnecessary navigation.
