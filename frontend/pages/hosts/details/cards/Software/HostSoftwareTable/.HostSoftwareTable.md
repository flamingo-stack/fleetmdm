Renders a paginated, searchable software table for a specific host or device, handling query-param-driven routing, vulnerability filters, and a macOS `/Applications` toggle.

## Key Components

### `HostSoftwareTable` (default export)
Main table component that wraps `TableContainer` with host-specific controls and routing logic.

**Props:**
| Prop | Type | Description |
|---|---|---|
| `tableConfig` | `any` | Column configuration passed to `TableContainer` |
| `data` | `IGetHostSoftwareResponse \| IGetDeviceSoftwareResponse` | Software list and pagination metadata |
| `platform` | `HostPlatform` | Host OS platform, controls filter visibility |
| `vulnFilters` | `ISoftwareVulnFiltersParams` | Active vulnerability filter state |
| `macosApplicationsFilter` | `boolean \| undefined` | macOS-only `/Applications` scope toggle |
| `isMyDevicePage` | `boolean` | Enables row-click navigation for the "My Device" view |
| `onShowInventoryVersions` | `(software: IHostSoftware) => void` | Callback when a software row is clicked |
| `onAddFiltersClick` | `() => void` | Opens the vulnerability filter panel |

### `EmptyComponent`
Memoized empty-state renderer. Shows `VulnsNotSupported` when vulnerability filters are active on an unsupported platform; otherwise shows `EmptySoftwareTable`.

## Usage Example

```typescript
<HostSoftwareTable
  tableConfig={softwareTableConfig}
  data={hostSoftwareData}
  platform="darwin"
  isLoading={isFetching}
  router={router}
  sortHeader="name"
  sortDirection="asc"
  searchQuery={query}
  page={pageIndex}
  pagePath={`/hosts/${hostId}/software`}
  vulnFilters={vulnFilters}
  teamId={teamId}
  macosApplicationsFilter={false}
  onAddFiltersClick={() => setShowFilterModal(true)}
  onShowInventoryVersions={(software) => setSelectedSoftware(software)}
/>
```

## Routing Behavior

All filter, sort, search, and pagination changes update the URL via `router.replace()` using `getNextLocationPath`. Page index resets to `0` on any change except pagination. The macOS applications dropdown and vulnerability filter button are injected as custom controls, with CSS used to reorder them visually relative to the search input.
