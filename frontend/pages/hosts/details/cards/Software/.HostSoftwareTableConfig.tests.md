Test suite for the `generateSoftwareTableHeaders` function, specifically validating the rendering behavior of the "Last opened" column cell across different data states.

## Key Components

- **`generateSoftwareTableHeaders`** — The function under test, imported from `HostSoftwareTableConfig`. Generates column header configurations for the host software table.
- **`lastOpenedColumn`** — The specific column extracted by `id === "Last opened"` from the generated headers.
- **`Cell`** — The React component rendered by the "Last opened" column, tested for three distinct value states.

## Test Coverage

| Scenario | Input Value | Expected Output |
|---|---|---|
| Valid date string | `"2023-01-01T00:00:00Z"` | Relative time (not "Never" or "Not supported") |
| Empty string | `""` | `"Never"` |
| Undefined | `undefined` | `"Not supported"` |

## Usage Example

```typescript
// Generating headers to find the "Last opened" column
const headers = generateSoftwareTableHeaders({
  router: mockRouter,
  teamId: 1,
  onShowInventoryVersions: noop,
  platform: "windows",
});

const lastOpenedColumn = headers.find((h) => h.id === "Last opened");

// Rendering the Cell component in tests
render(
  <Cell cell={{ value: "2023-01-01T00:00:00Z" }} row={{ original: {} }} />
);
```

## Notes

- The test guards against a missing column or non-function accessor by throwing an explicit `Error`, ensuring test failures are clear rather than silent.
- Valid date values are rendered via `HumanTimeDiffWithDateTip`, which produces relative strings (e.g., `"2 years ago"`). Tests assert absence of fallback strings rather than an exact relative time, making them date-independent.
