Provides UI status computation, version comparison, and query parameter utilities for the Host Software detail view in Fleet MDM.

## Key Components

### `getHostSoftwareFilterFromQueryParams(queryParams)`
Converts the `available_for_install` query parameter string to a filter label (`"installableSoftware"` or `"allSoftware"`).

### `compareVersions(v1, v2)`
Compares two software version strings, returning `-1`, `0`, or `1`. Handles SemVer, pre-release tags (`alpha`, `beta`, `rc`), build metadata, edition suffixes (`.CE`), and distribution channel tags (`-latest`).

**Internal helpers:**
- `stripBuildMetadata(version)` — removes parenthesized build suffixes, `+build` SemVer metadata, `.CE` edition markers, `-latest` tags, and leading `Build ` prefixes.
- `splitVersion(version)` — normalizes delimiters and splits a version string into typed numeric/string segments.
- `comparePreRelease(a, b)` — orders pre-release identifiers using `PRE_RELEASE_ORDER`.

### `getUiStatus(software, isHostOnline, hostSoftwareUpdatedAt?, recentlyUpdatedIds?)`
Determines the display status (`IHostSoftwareUiStatus`) for a host software entry. Evaluates (in priority order):
1. Script package states (`running_script`, `pending_script`, `ran_script`, etc.)
2. Failed install/uninstall (with optional update-available detection)
3. Pending install/update or uninstall
4. Recently uninstalled
5. Update available / recently updated
6. Recently installed
7. Installed or uninstalled fallback

## Usage Example

```typescript
import { compareVersions, getUiStatus } from "./helpers";

// Version comparison
compareVersions("1.2.3", "1.2.4");  // -1
compareVersions("2.0.0-rc", "2.0.0"); // -1
compareVersions("8.0 (build 6300)", "8.1"); // -1

// Resolve UI status for a host software row
const uiStatus = getUiStatus(
  hostSoftware,
  /* isHostOnline */ true,
  /* hostSoftwareUpdatedAt */ "2024-06-01T00:00:00Z",
  /* recentlyUpdatedIds */ new Set([42])
);
// e.g. "recently_updated", "installing", "update_available"
```
