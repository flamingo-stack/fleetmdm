Defines and exports the column configuration for the host software inventory table, mapping `IHostSoftware` data to sortable, platform-aware React Table columns.

## Key Components

### `generateSoftwareTableHeaders(props)`

The primary export. Accepts router, team ID, platform, and a version-drill-down callback, and returns an array of `Column<IHostSoftware>` definitions for use with `react-table`.

**Columns generated:**

| Column | Sortable | Notes |
|---|---|---|
| **Name** | ✅ | Routes to software title details; shows installer/self-service/policy badges |
| **Installed version** | ❌ | Renders `VersionCell` from `installed_versions` |
| **Type** | ❌ | Formats source via `formatSoftwareType`; truncates with tooltip |
| **Last opened** | ❌ | Platform-aware tooltip; resolves most recent date across all versions; shows `Never` or `Not supported` when applicable |
| **Vulnerabilities** | ❌ | Disabled for iPad/iPhone sources; aggregates CVEs via `getVulnerabilities` |
| **File path** | ❌ | Disabled for iPad/iPhone sources; opens version modal on multiple paths |
| **Hash** | ❌ | Disabled for iPad/iPhone sources; opens version modal on multiple hashes |

### `ISoftwareTableHeadersProps`

Interface for `generateSoftwareTableHeaders` parameters:

```typescript
interface ISoftwareTableHeadersProps {
  router: InjectedRouter;
  teamId: number;
  onShowInventoryVersions: (software: IHostSoftware) => void;
  platform: HostPlatform;
}
```

## Usage Example

```typescript
import { generateSoftwareTableHeaders } from "./HostSoftwareTableConfig";

const columns = generateSoftwareTableHeaders({
  router,
  teamId: 42,
  platform: "darwin",
  onShowInventoryVersions: (software) => setSelectedSoftware(software),
});

// Pass columns to your TableContainer
<TableContainer columns={columns} data={hostSoftware} />;
```
