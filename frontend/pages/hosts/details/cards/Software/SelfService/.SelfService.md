Renders the Self Service software tab on the Fleet device user page, allowing end-users to browse, install, update, and uninstall organization-approved applications from their device.

## Key Components

### Component

- **`SoftwareSelfService`** — Main component that fetches device software, tracks install/uninstall state, manages polling, and renders the self-service UI with cards and modals.

### Exports

- **`parseSelfServiceQueryParams`** — Parses and normalizes URL query params (`page`, `query`, `order_key`, `order_direction`, `category_id`) into typed config values.
- **`SELF_SERVICE_SUBHEADER`** — Static subtitle string displayed on the self-service page.
- **`ISoftwareSelfServiceProps`** — TypeScript interface for the component's props.

### Internal Utilities

- **`getInstallerName`** — Resolves a display-friendly installer name from macOS `.app` paths or falls back to `software.name`.
- **`DEFAULT_SELF_SERVICE_CONFIG`** — Defines default API and UI pagination/sort/filter parameters (all 9999-item pages; client-side filtering only).

### Key State & Refs

| Ref/State | Purpose |
|---|---|
| `userActionIdsRef` | Tracks IDs where the user initiated an action |
| `pendingSoftwareIdsRef` | Tracks pending install/uninstall IDs for polling |
| `recentlyUpdatedSoftwareIds` | Set of IDs showing the "recently updated" badge |
| `recentlyUpdatedTimeouts` | Timeout handles for 2-minute badge expiry |

## Usage Example

```typescript
import SoftwareSelfService, {
  parseSelfServiceQueryParams,
} from "./SelfService";

const queryParams = parseSelfServiceQueryParams({
  query: "zoom",
  order_key: "name",
  order_direction: "asc",
  category_id: "3",
});

<SoftwareSelfService
  contactUrl="https://support.example.com"
  deviceToken="abc123token"
  isSoftwareEnabled={true}
  pathname="/device/self-service"
  queryParams={queryParams}
  router={router}
  refetchHostDetails={refetch}
  isHostDetailsPolling={false}
  hostDisplayName="My MacBook"
  mdmEnrollmentStatus="On (manual)"
/>
```
