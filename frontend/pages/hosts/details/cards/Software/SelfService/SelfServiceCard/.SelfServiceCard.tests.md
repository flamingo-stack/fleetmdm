Unit test suite for the `SelfServiceCard` React component, verifying rendering states, user interactions, category filtering behavior, and install-all functionality.

## Key Components

### Test Helpers
- **`createMockTableConfig()`** — Generates a mock table column configuration with Name, Status, and Actions columns
- **`createTestProps()`** — Factory function that returns a complete `ISelfServiceCardProps` object with sensible defaults, accepting partial overrides
- **`DEFAULT_QUERY_PARAMS`** — Baseline `SelfServiceQueryParams` object used across tests

### Test Suites
The `describe("SelfServiceCard")` block covers:

| Test | Description |
|------|-------------|
| Loading state | Spinner renders when `isLoading: true` |
| Error state | Error message renders when `isError: true` |
| Empty state | Empty state copy renders when `isEmpty: true` |
| Header/subheader | Card title and description always render |
| Contact link | Link renders with correct `href` and `target="_blank"` when `contactUrl` is set |
| No contact link | Link is absent when `contactUrl` is empty |
| Category dropdown | Hidden when categories list is empty |
| Stale `category_id` (empty list) | Auto-cleared from URL via `router.push` |
| Stale `category_id` (deleted category) | Auto-cleared when ID not found in loaded list |
| Search field | Renders with placeholder and reflects `query` param |
| Category selection | `router.push` called with correct `category_id` |
| Install-all enabled | Button enabled when uninstalled items exist |
| Install-all count | Shows uninstalled count when category is selected |
| Install-all disabled | Button disabled when any item is in-progress |
| Install-all POST | Calls `install_all` endpoint and fires `onInstallAllSuccess` |

## Usage Example

```typescript
// Running a specific test with custom props
const props = createTestProps({
  isLoading: true,
  queryParams: { ...DEFAULT_QUERY_PARAMS, category_id: 1 },
});
const render = createCustomRenderer({ withBackendMock: true });
render(<SelfServiceCard {...props} />);
expect(await screen.findByTestId("spinner")).toBeInTheDocument();
```
