A modal component that displays platform-specific instructions for opening installed software, supporting macOS (`apps`) and Windows (`programs`) source types.

## Key Components

- **`getOpenSoftwareInstructions`** — Helper function that returns platform-appropriate instructions as a `ReactNode` based on the `softwareSource` value (`"apps"` for macOS Finder/Spotlight, `"programs"` for Windows Start Menu)
- **`OpenSoftwareModal`** — Default export; renders a `Modal` with the generated instructions and a close button via `ModalFooter`
- **`ISoftwareInstructionsModalProps`** — Interface defining the component's props:
  - `softwareName: string` — Display name of the software
  - `softwareSource: string` — Platform source identifier (`"apps"` or `"programs"`)
  - `onExit: () => void` — Callback invoked when the modal is dismissed

## Usage Example

```typescript
import OpenSoftwareModal from "components/OpenSoftwareModal";

// macOS example
<OpenSoftwareModal
  softwareName="Slack"
  softwareSource="apps"
  onExit={() => setShowModal(false)}
/>

// Windows example
<OpenSoftwareModal
  softwareName="Slack"
  softwareSource="programs"
  onExit={() => setShowModal(false)}
/>
```

> **Note:** If `softwareSource` is neither `"apps"` nor `"programs"`, the modal renders with no instruction content (empty fragment). Consider extending `getOpenSoftwareInstructions` for additional platforms as needed.
