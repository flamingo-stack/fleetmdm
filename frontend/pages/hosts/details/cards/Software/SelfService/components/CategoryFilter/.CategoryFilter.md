A React dropdown filter component for selecting self-service software categories, featuring a custom searchable menu built on top of `react-select-5` with a Fleet-branded button trigger.

## Key Components

- **`CategoryFilter`** — Main exported component that renders a custom button-triggered dropdown for filtering by category
- **`CustomMenuList`** — Internal component overriding `react-select`'s default menu list to inject a sticky search input with keyboard navigation forwarding
- **`ICategoryFilterProps`** — Props interface defining `categories`, `selectedCategoryId`, `onChange`, and `isDisabled`
- **`ALL_CATEGORIES_VALUE`** — Exported constant (`-1`) representing the "All" pseudo-category option

## Key Behaviors

- The visible trigger is a Fleet `<Button>` component; `react-select`'s native control is hidden but kept in the DOM to preserve keyboard event handling
- Navigation keys (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`) typed into the search input are forwarded via `dispatchEvent` to `react-select`'s hidden input
- Clicking outside the wrapper closes the menu (mirrors the `ActionsDropdown` pattern)
- Options are filtered client-side against `searchQuery` using case-insensitive substring matching

## Usage Example

```typescript
import CategoryFilter, { ALL_CATEGORIES_VALUE } from "./CategoryFilter";

const MyPage = () => {
  const [selectedCategoryId, setSelectedCategoryId] = useState<number | undefined>(undefined);

  return (
    <CategoryFilter
      categories={[
        { id: 1, name: "Security" },
        { id: 2, name: "Productivity" },
      ]}
      selectedCategoryId={selectedCategoryId}
      onChange={(newId) => setSelectedCategoryId(newId)}
    />
  );
};
```
