Unit tests for the `SelfServiceFilters` component, verifying search field rendering, category filter visibility, and optional slot injection behavior.

## Key Components

| Test Case | Description |
|---|---|
| `renders the search field` | Confirms the search input is present via placeholder text |
| `hides CategoryFilter when empty` | Asserts no dropdown trigger button when `categories` is `[]` |
| `renders CategoryFilter when present` | Confirms dropdown trigger appears when at least one category is provided |
| `renders install-all slot when provided` | Validates optional `installAllSlot` prop renders its content |
| `does not render slot when omitted` | Confirms no slot content leaks in when prop is absent |

## Usage Example

```typescript
import { createCustomRenderer } from "test/test-utils";
import { createMockSelfServiceCategory } from "test/handlers/self-service-categories-handlers";
import SelfServiceFilters from "./SelfServiceFilters";

const render = createCustomRenderer();

// Minimal render — search only
render(
  <SelfServiceFilters
    query=""
    categoryId={undefined}
    categories={[]}
    onSearchQueryChange={jest.fn()}
    onCategoryChange={jest.fn()}
  />
);

// With categories and an install-all action slot
render(
  <SelfServiceFilters
    query=""
    categoryId={1}
    categories={[createMockSelfServiceCategory({ id: 1, name: "🌎 Browsers" })]}
    onSearchQueryChange={jest.fn()}
    onCategoryChange={jest.fn()}
    installAllSlot={<button type="button">Install All</button>}
  />
);
```

## Notes

- Uses `createCustomRenderer` from the shared test utilities to wrap renders with required providers.
- `createMockSelfServiceCategory` generates typed category fixtures for deterministic test data.
- The `CategoryFilter` trigger is identified by its `aria-expanded` attribute — tests rely on ARIA role queries for accessible assertions.
