Renders the self-service software table with context-aware empty states for search, category filter, and fallback conditions.

## Key Components

### `SelfServiceTable` (default export)
A presentational component wrapping `TableContainer` to display self-service software items with client-side filtering, pagination, and sort handling.

**Props (`SelfServiceTableProps`):**

| Prop | Type | Description |
|---|---|---|
| `baseClass` | `string` | BEM base class prefix for scoped styling |
| `contactUrl` | `string` | URL linked in the "Reach out to IT" empty state |
| `queryParams` | `object` | Current sort, pagination, search, and category state |
| `enhancedSoftware` | `IDeviceSoftwareWithUiStatus[]` | Software rows with UI status augmentation |
| `selfServiceData` | `IGetDeviceSoftwareResponse` | Raw API response used for pagination metadata |
| `tableConfig` | `any` | Column definitions passed to `TableContainer` |
| `isFetching` | `boolean` | Loading state for the table |
| `onSortChange` | `(query: ITableQueryData) => void` | Sort/query change handler |
| `onClientSidePaginationChange` | `(page: number) => void` | Client-side page change handler |

### `renderEmptyState()`
Returns one of three `EmptyState` variants based on active filters:
1. **Search active** — "No items match your search" with a contact IT link
2. **Category only** — "No items in this category"
3. **Fallback** — Generic criteria mismatch message

## Usage Example

```typescript

  baseClass="self-service"
  contactUrl="https://it.example.com/contact"
  queryParams={{
    query: "zoom",
    order_key: "name",

    page: 0,
    per_page: 20,
  }}
  enhancedSoftware={software}
  selfServiceData={apiResponse}
```
