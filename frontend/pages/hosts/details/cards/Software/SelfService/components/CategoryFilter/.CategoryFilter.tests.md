Test suite for the `CategoryFilter` component, validating rendering, menu interaction, search filtering, option selection, and disabled state behaviors.

## Key Components

- **`CATEGORIES`** — Static fixture array of two mock self-service categories used across all test cases.
- **`getMenu()`** — Helper that queries the open dropdown menu by its CSS class (`.self-service-category-filter__menu`), working around react-select-5's lack of `role="listbox"`.
- **`openMenu()`** — Async helper that clicks the trigger button and waits for the search input to appear.

## Test Cases

| Test | Description |
|---|---|
| Default label | Shows `"All"` when no `selectedCategoryId` is provided |
| Selected label | Shows the matching category name when an ID is provided |
| Menu contents | Opens to display all options including `"All"` |
| Search filtering | Filters options by query string; hides non-matching entries |
| No-match message | Displays `"No categories match this search."` when search excludes everything |
| Select category | Calls `onChange` with the numeric category ID |
| Select "All" | Calls `onChange` with `undefined` |
| Disabled state | Disables the trigger button when `isDisabled` is `true` |

## Usage Example

```typescript
import { render } from "@testing-library/react";
import CategoryFilter from "./CategoryFilter";

render(
  <CategoryFilter
    categories={[{ id: 1, name: "🌎 Browsers" }]}
    selectedCategoryId={1}
    onChange={(id) => console.log(id)} // number | undefined
    isDisabled={false}
  />
);
```
