Test suite for the `TileActionStatus` component, verifying that the correct UI elements (spinners, action buttons, error indicators) are rendered for each possible software installation/management status.

## Key Components

- **`makeSoftware(ui_status)`** — Helper factory that creates a mock `IDeviceSoftwareWithUiStatus` object with a given `ui_status` string, using `createMockHostSoftware` as the base.
- **`TileActionStatus`** — The component under test, accepting `software` and `onActionClick` props.

## Status Coverage

| Status Group | Statuses Tested | Expected UI |
|---|---|---|
| Installing | `installing`, `pending_install` | Spinner + "Installing..." label |
| Updating | `updating`, `pending_update` | Spinner + "Updating..." label |
| Running Script | `running_script`, `pending_script` | Spinner + "Running..." label |
| Uninstalling | `uninstalling`, `pending_uninstall` | Spinner + "Uninstalling..." label |
| Install | `uninstalled`, `recently_uninstalled`, unknown | "Install" button |
| Update | `update_available`, `failed_uninstall_update_available` | "Update" button |
| Reinstall | `installed`, `recently_installed`, `recently_updated`, `failed_uninstall` | "Reinstall" button |
| Run/Rerun | `never_ran_script`, `ran_script` | "Run" / "Rerun" button |
| Failed/Retry | `failed_install`, `failed_install_update_available`, `failed_script` | "Retry" button + error icon/text |

## Usage Example

```typescript
// Pattern used throughout the test suite
const makeSoftware = (ui_status: string) =>
  ({
    ...createMockHostSoftware(),
    ui_status,
  } as IDeviceSoftwareWithUiStatus);

render(
  <TileActionStatus
    software={makeSoftware("installing")}
    onActionClick={jest.fn()}
  />
);

expect(screen.getByText(/Installing.../i)).toBeInTheDocument();
expect(screen.getByTestId("spinner")).toBeInTheDocument();
```

## Notes

- Button click callbacks are verified via `fireEvent.click` (see the `uninstalled` status test).
- Unknown/unrecognized statuses fall back to rendering the **Install** button.
