A React button component that triggers bulk installation of all uninstalled self-service software items within a selected category, with confirmation modal and error handling.

## Key Components

### `InstallAllInCategoryButton`
The default export — a controlled button component that:
- Displays the count of uninstalled items alongside an install icon
- Disables itself when installations are in-progress or all items are already installed
- Opens a confirmation modal (`InstallAllInCategoryModal`) before executing the bulk install
- Calls `deviceUserAPI.installAllSelfServiceSoftwareInCategory` on confirmation
- Surfaces errors via `NotificationContext` flash messages

### `IInstallAllInCategoryButtonProps`
Exported interface defining component props:

| Prop | Type | Description |
|---|---|---|
| `uninstalledCount` | `number` | Count of items not yet installed (excludes in-flight statuses) |
| `hasInProgressInCategory` | `boolean` | Disables the button if any install is in-progress |
| `deviceToken` | `string` | Token identifying the device |
| `categoryId` | `number \| undefined` | Category to install; omitting installs all entitled software |
| `onSuccess` | `() => void` | Callback invoked after successful bulk install |

## Usage Example

```typescript
<InstallAllInCategoryButton
  uninstalledCount={5}
  hasInProgressInCategory={false}
  deviceToken="abc123token"
  categoryId={42}
  onSuccess={() => refetchSoftwareList()}
/>
```

Passing `categoryId={undefined}` (when the user selects "All") instructs the backend to install every uninstalled item the device user is entitled to.
