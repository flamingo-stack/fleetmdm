Test suite for the `OpenSoftwareModal` component, verifying platform-specific software opening instructions and modal interaction behavior.

## Key Components

- **`renders macOS instructions`** — Asserts that when `softwareSource` is `"apps"`, the modal displays macOS-specific guidance (Finder > Applications, double-click)
- **`renders Windows instructions`** — Asserts that when `softwareSource` is `"programs"`, the modal displays Windows-specific guidance (Start Menu, click)
- **`renders nothing when softwareSource is unknown`** — Verifies that unsupported sources (e.g., `"chrome_extensions"`) produce no visible instructions
- **`calls onExit when Close button is clicked`** — Confirms the `onExit` callback fires on Close button interaction using `renderWithSetup` for user-event simulation

## Usage Example

```typescript
// Run the full test suite
// From the repository root:
// npx jest OpenSoftwareModal.tests.tsx

// Example: Testing the Close button interaction
const onExitMock = jest.fn();
const { user } = renderWithSetup(
  <OpenSoftwareModal
    softwareSource="apps"
    softwareName="Slack"
    onExit={onExitMock}
  />
);

await user.click(screen.getByRole("button", { name: /Close/i }));
expect(onExitMock).toHaveBeenCalled();
```

## Notes

- Uses `@testing-library/react` for rendering and querying
- Uses `renderWithSetup` from `test/test-utils` for user-event interaction tests
- `softwareSource` drives conditional rendering: `"apps"` → macOS path, `"programs"` → Windows path, anything else → empty
