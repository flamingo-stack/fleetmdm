A confirmation modal component that prompts users to install all apps within a category, displaying the count of apps to be installed and preventing re-installation of already-installed apps.

## Key Components

### `IInstallAllInCategoryModalProps`
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `count` | `number` | ✅ | Number of new apps to be installed |
| `isSubmitting` | `boolean` | ❌ | Disables controls and shows loading state during submission |
| `onConfirm` | `() => void` | ✅ | Callback fired when the user clicks "Install all" |
| `onExit` | `() => void` | ✅ | Callback fired when the user cancels or closes the modal |

### `InstallAllInCategoryModal`
Default export. A controlled modal with two actions — confirm installation or cancel — that gracefully handles singular/plural app count messaging.

## Usage Example

```typescript
import InstallAllInCategoryModal from "components/InstallAllInCategoryModal";

const MyComponent = () => {
  const [isOpen, setIsOpen] = React.useState(false);
  const [isSubmitting, setIsSubmitting] = React.useState(false);

  const handleConfirm = async () => {
    setIsSubmitting(true);
    await installAllAppsInCategory();
    setIsSubmitting(false);
    setIsOpen(false);
  };

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Install all</button>
      {isOpen && (
        <InstallAllInCategoryModal
          count={5}
          isSubmitting={isSubmitting}
          onConfirm={handleConfirm}
          onExit={() => setIsOpen(false)}
        />
      )}
    </>
  );
};
```

## Behaviour Notes
- The message automatically pluralizes — `"1 new app"` vs `"5 new apps"`.
- While submitting, the modal content is disabled (`isContentDisabled`) and the confirm button shows a loading spinner.
- Already-installed apps are explicitly excluded from reinstallation per the modal's messaging.
