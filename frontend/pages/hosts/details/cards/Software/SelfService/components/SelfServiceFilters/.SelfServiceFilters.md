Renders the filter bar for the Software Self-Service page, combining an optional category filter, an optional "Install All" action slot, and a search field into a single responsive header row.

## Key Components

- **`SelfServiceFilters`** — Default export. A presentational component that composes category-based filtering, a configurable action slot, and text search.
- **`SelfServiceFiltersProps`** — Interface defining the component's props:
  - `query` — Current search string.
  - `categoryId` — Currently selected category ID (optional).
  - `categories` — Array of `ISelfServiceCategory` items; controls whether the `CategoryFilter` is rendered.
  - `onSearchQueryChange` — Callback fired when the search input changes.
  - `onCategoryChange` — Callback fired when the selected category changes.
  - `installAllSlot` — Optional `ReactNode` injected into a dedicated wrapper (e.g., an "Install All" button).
- **Layout modifier** — Applies the `--with-categories` BEM modifier to trigger a two-row SCSS layout only when categories are present.

## Usage Example

```typescript
import SelfServiceFilters from "./SelfServiceFilters";

<SelfServiceFilters
  query={searchQuery}
  categoryId={selectedCategoryId}
  categories={availableCategories}
  onSearchQueryChange={(value) => setSearchQuery(value)}
  onCategoryChange={(id) => setSelectedCategoryId(id)}
  installAllSlot={<InstallAllButton onClick={handleInstallAll} />}
/>
```

## Notes

- The `CategoryFilter` and `installAllSlot` sections are conditionally rendered — the component gracefully collapses to a search-only bar when no categories exist and no slot is provided.
