Modal component that displays software update details for a host, showing installation status, version information, and update/cancel actions.

## Key Components

### `StatusMessage` (internal)
Renders a contextual status icon and message based on:
- `pending_install` — shows a pending indicator with Fleet's auto-update message
- Device user view — simplified "Update to version X" prompt
- Admin view — full "new version available" message with host name

### `SoftwareUpdateModal` (default export)
Main modal component that orchestrates:
- Status messaging via `StatusMessage`
- Installed version display via `InventoryVersions` (hidden when `pending_install`)
- Footer actions: **Update** + **Cancel** buttons, or a single **Close** button when install is already pending

## Props (`ISoftwareUpdateModalProps`)

| Prop | Type | Description |
|---|---|---|
| `hostDisplayName` | `string` | Display name of the target host |
| `software` | `IHostSoftware` | Software object with status, versions, and package info |
| `onExit` | `() => void` | Callback to close the modal |
| `onUpdate` | `(id: number) => void` | Callback to trigger the update (uses install API) |
| `isDeviceUser` | `boolean` | Toggles simplified device-user messaging |

## Usage Example

```typescript
<SoftwareUpdateModal
  hostDisplayName="Johns MacBook Pro"
  software={hostSoftware}
  isDeviceUser={false}
  onExit={() => setShowModal(false)}
  onUpdate={(id) => installSoftware(id)}
/>
```

> **Note:** The update action reuses the software install API endpoint. Calling `onUpdate` also triggers `onExit` automatically.
