Renders the self-service software catalog as a grid of installable tiles, handling loading, empty search, and empty category states.

## Key Components

- **`SelfServiceTiles`** — Default export. Accepts a list of enhanced software items and renders each as a `Card` tile with icon, name, version, and an action button via `TileActionStatus`.
- **`SelfServiceTilesProps`** — Interface defining the component's props, including software data, contact URL, install callback, and display state flags.

## Usage Example

```typescript
<SelfServiceTiles
  enhancedSoftware={softwareList}
  contactUrl="https://it.example.com/contact"
  onClickInstallAction={(softwareId, isSoftwarePackage) => {
    handleInstall(softwareId, isSoftwarePackage);
  }}
  isEmptySearch={searchQuery.length > 0 && results.length === 0}
  isEmptyCategory={selectedCategory !== null && categoryResults.length === 0}
  isFetching={isLoading}
/>
```

## Rendering Logic

| State | Output |
|---|---|
| `isFetching` | `<Spinner />` |
| `isEmptySearch` | Empty state with "Reach out to IT" contact link |
| `isEmptyCategory` | Empty state with "No items in this category" |
| Default | Grid of `Card` tiles |

Each tile displays a `SoftwareIcon`, a `TooltipTruncatedText` name (resolved via `getDisplayedSoftwareName`), the package or App Store version, and a `TileActionStatus` button. The install callback passes `isSoftwarePackage` based on whether the software's `source` appears in `SCRIPT_PACKAGE_SOURCES`.
