Header component for the Self-Service section that displays a title, description, and optional IT contact link.

## Key Components

**`SelfServiceHeader`** — Default export. A presentational component wrapping `CardHeader` with self-service–specific copy and an optional contact link rendered via `CustomLink`.

### Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `contactUrl` | `string` | ✅ | URL for the "reach out to IT" link. If falsy, the contact sentence is omitted. |
| `variant` | `"mobile-header" \| "preview"` | ❌ | Controls rendering mode. `"mobile-header"` is forwarded to `CardHeader`; `"preview"` disables keyboard navigation on the contact link. |

## Usage Example

```typescript
// Standard usage with a contact URL
<SelfServiceHeader contactUrl="https://support.example.com" />

// Mobile header variant
<SelfServiceHeader
  contactUrl="https://support.example.com"
  variant="mobile-header"
/>

// Preview mode (e.g., in a non-interactive preview pane)
<SelfServiceHeader
  contactUrl="https://support.example.com"
  variant="preview"
/>

// No contact link rendered
<SelfServiceHeader contactUrl="" />
```

## Behavior Notes

- `variant="mobile-header"` is passed through to `CardHeader`; `"preview"` is intentionally **not** forwarded — it only suppresses keyboard navigation on the contact link.
- The contact link opens in a new tab (`newTab` prop on `CustomLink`).
