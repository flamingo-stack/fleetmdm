Displays a paginated card of available software updates for a device, with responsive page sizing and bulk update support.

## Key Components

**`UpdatesCard`** — Default export. React component that renders a card listing device software items that need updates, filtered by `ui_status` values such as `update_available`, `updating`, `recently_updated`, and failure states.

**`getUpdatesPageSize(width)`** — Pure utility that returns the number of update items per page based on viewport width breakpoints (`4` at ≥1400px, `3` at ≥880px, `2` otherwise).

**`IUpdatesCardProps`** — Component prop interface:

| Prop | Type | Description |
|---|---|---|
| `enhancedSoftware` | `IDeviceSoftwareWithUiStatus[]` | Full software list with UI status metadata |
| `isLoading` | `boolean` | Shows `<Spinner />` when true |
| `isError` | `boolean` | Shows `<DeviceUserError />` when true |
| `onClickUpdateAll` | `() => void` | Triggered by "Update all" button |
| `onClickUpdateAction` | `(id: number) => void` | Per-item update action handler |
| `onClickFailedUpdateStatus` | `(software: IDeviceSoftware) => void` | Opens installer details for failed updates |

## Usage Example

```typescript
<UpdatesCard
  enhancedSoftware={softwareWithStatus}
  isLoading={isFetching}
  isError={hasError}
  onClickUpdateAll={handleUpdateAll}
  onClickUpdateAction={(id) => handleUpdate(id)}
  onClickFailedUpdateStatus={(software) => openFailedModal(software)}
/>
```

## Behavior Notes

- Returns `null` if no matching update items exist on the current page.
- The "Update all" button is **disabled** when all items are in `updating` or `recently_updated` state.
- Pagination adjusts automatically on window resize, clamping the current page to a valid range without debouncing (resize events only hit 2 breakpoints with no API side effects).
- Pagination controls are hidden when only one page exists.
