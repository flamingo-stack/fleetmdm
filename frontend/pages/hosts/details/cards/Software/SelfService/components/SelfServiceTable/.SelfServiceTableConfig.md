Defines the column configuration and data transformation for the Self-Service software table displayed on the device user ("My Device") page.

## Key Components

- **`generateSoftwareTableData`** — Identity transform that accepts an array of `IDeviceSoftwareWithUiStatus` and returns it unchanged; serves as a normalization hook for future data shaping.
- **`generateSoftwareTableHeaders`** — Factory function that returns three `react-table` column definitions:
  - **Name** — Renders `SoftwareNameCell` with `isSelfService` and `pageContext="deviceUser"` flags.
  - **Install status** — Renders `InstallStatusCell` using `ui_status` accessor with custom `installStatusSortType`; wires all detail-modal callbacks.
  - **Actions** — Renders `HostInstallerActionCell` with install, uninstall, and open-instructions callbacks; sort is disabled.
- **`ISelfServiceTableHeaders`** — Interface describing the eight callback props required by `generateSoftwareTableHeaders`.

## Usage Example

```typescript
import {
  generateSoftwareTableHeaders,
  generateSoftwareTableData,
} from "./SelfServiceTableConfig";

const columns = generateSoftwareTableHeaders({
  onShowUpdateDetails: (sw) => openUpdateModal(sw),
  onShowInstallDetails: (sw) => openInstallModal(sw),
  onShowIpaInstallDetails: (sw) => openIpaModal(sw),
  onShowScriptDetails: (sw) => openScriptModal(sw),
  onShowVPPInstallDetails: (sw) => openVPPModal(sw),
  onShowUninstallDetails: (details) => openUninstallModal(details),
  onClickInstallAction: (id, isScript) => triggerInstall(id, isScript),
  onClickUninstallAction: (sw) => triggerUninstall(sw),
  onClickOpenInstructionsAction: (sw) => openInstructions(sw),
});

const rows = generateSoftwareTableData(deviceSoftwareList);
```
