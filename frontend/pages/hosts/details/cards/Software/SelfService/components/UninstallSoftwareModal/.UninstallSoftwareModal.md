A confirmation modal component that prompts device users to confirm uninstallation of self-service software, handling the API call and user feedback.

## Key Components

### `IUninstallSoftwareModalProps`
| Prop | Type | Description |
|---|---|---|
| `softwareId` | `number` | ID of the software to uninstall |
| `softwareName` | `string?` | Display name of the software (defaults to `"software"`) |
| `token` | `string` | Device user authentication token |
| `onExit` | `() => void` | Callback to close the modal |
| `onSuccess` | `() => void` | Callback invoked on successful uninstall |

### `UninstallSoftwareModal`
The default export. Renders a `Modal` with a confirmation message and two actions: **Uninstall** (alert variant) and **Cancel** (inverse-alert variant). During the async uninstall operation, the modal content and button are disabled/loading. On API failure, a toast error is shown via `NotificationContext`.

## Usage Example

```typescript
import UninstallSoftwareModal from "components/UninstallSoftwareModal";

<UninstallSoftwareModal
  softwareId={42}
  softwareName="Slack"
  token={deviceToken}
  onExit={() => setShowModal(false)}
  onSuccess={() => {
    setShowModal(false);
    refreshSoftwareList();
  }}
/>
```

## Behavior Notes

- Calls `deviceUserAPI.uninstallSelfServiceSoftware(token, softwareId)` on confirm
- `onExit` is always called after the attempt (success or failure)
- `onSuccess` is only called before `onExit` when the API call succeeds
- Error feedback is scoped to a flash notification; no inline error state
