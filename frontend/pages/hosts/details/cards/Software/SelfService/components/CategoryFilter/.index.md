Re-exports from the `CategoryFilter` module, providing a centralized entry point for the category filtering component and its associated constants.

## Key Components

- **`default`** — The default export from `CategoryFilter` (the `CategoryFilter` component itself)
- **`ALL_CATEGORIES_VALUE`** — A named constant representing the "all categories" selection state

## Usage Example

```typescript
import CategoryFilter, { ALL_CATEGORIES_VALUE } from "./index";

// Use the component
<CategoryFilter
  selectedCategory={ALL_CATEGORIES_VALUE}
  onChange={(category) => handleCategoryChange(category)}
/>

// Or reference the constant directly for comparisons
const isAllSelected = selectedCategory === ALL_CATEGORIES_VALUE;
```

## Notes

This barrel file follows standard module re-export patterns, allowing consumers to import from the directory rather than the specific file path. See [`CategoryFilter.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/CategoryFilter.ts) for full implementation details.
