Test suite for the `UpdateSoftwareItem` React component, validating rendering and interaction behavior across all possible software update UI states.

## Key Components

- **`describe` block** — Groups all tests under `"Self-service - UpdateSoftwareItem component"`
- **`createCustomRenderer`** — Custom test renderer with backend mock support
- **`createMockDeviceSoftware`** — Factory for mock `IDeviceSoftwareWithUiStatus` data

## Test Coverage

| UI State | Assertion |
|---|---|
| `update_available` | Renders name, version, and software icon |
| `update_available` (installed) | Shows enabled `Update` button, no status indicators |
| `updating` | Shows spinner + "Updating..." text, hides `Update` button |
| `failed_install_update_available` | Shows `Failed` button with tooltip on hover |
| `recently_updated` | Shows `Updated` text + success icon, hides `Update` button |
| Callback — update | `onClickUpdateAction` called with `software.id` on click |
| Callback — failed | `onShowInstallerDetails` called on `Failed` button click |

## Usage Example

```typescript
import { createCustomRenderer } from "test/test-utils";
import { createMockDeviceSoftware } from "__mocks__/deviceUserMock";
import UpdateSoftwareItem from "./UpdateSoftwareItem";

const render = createCustomRenderer({ withBackendMock: true });

const software = {
  ...createMockDeviceSoftware({ status: "installed" }),
  ui_status: "update_available" as const,
};

render(
  <UpdateSoftwareItem
    software={software}
    onClickUpdateAction={(id) => console.log("Update:", id)}
    onShowInstallerDetails={() => {}}
  />
);
```
