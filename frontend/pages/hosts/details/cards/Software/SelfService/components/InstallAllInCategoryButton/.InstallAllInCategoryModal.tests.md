Test suite for the `InstallAllInCategoryModal` component, verifying rendering, pluralization logic, user interactions, and submitting state behavior.

## Key Components

| Test Case | Description |
|---|---|
| Title & confirm button rendering | Asserts both the modal heading and confirm button display "Install all" (2 occurrences) |
| Pluralization (`count > 1`) | Verifies "5 new apps will be installed" copy for counts greater than 1 |
| Singular (`count = 1`) | Verifies "1 new app will be installed" copy for a count of 1 |
| `onConfirm` callback | Confirms the callback fires once when the confirm button is clicked |
| `onExit` callback | Confirms the callback fires once when Cancel is clicked |
| Submitting state | Asserts the Cancel button is disabled when `isSubmitting` is `true` |

## Usage Example

```typescript
// Run the full suite
jest --testPathPattern="InstallAllInCategoryModal.tests"

// Minimal render for local exploration
import { render, screen } from "@testing-library/react";
import InstallAllInCategoryModal from "./InstallAllInCategoryModal";

render(
  <InstallAllInCategoryModal
    count={3}
    onConfirm={() => console.log("confirmed")}
    onExit={() => console.log("exited")}
  />
);
```

## Props Under Test

| Prop | Type | Purpose |
|---|---|---|
| `count` | `number` | Number of apps to install; drives singular/plural copy |
| `onConfirm` | `() => void` | Called when the user confirms the bulk install |
| `onExit` | `() => void` | Called when the user cancels |
| `isSubmitting` | `boolean` | Disables the Cancel button during an in-flight request |
