Test suite for the `UninstallSoftwareModal` component, verifying rendering behavior for both named and unnamed software uninstall confirmation dialogs.

## Key Components

- **`describe("UninstallSoftwareModal")`** — Test suite containing two rendering assertions for the modal component
- **`renders the generic uninstall message with software name`** — Verifies the modal displays a software-specific warning message (e.g., referencing "Slack") along with **Uninstall** and **Cancel** action buttons
- **`renders the generic uninstall message with default software name`** — Verifies the modal renders a generic uninstall warning when no `softwareName` prop is provided

## Usage Example

```typescript
// Rendering with a specific software name
render(
  <UninstallSoftwareModal
    softwareId={1}
    softwareName="Slack"
    token="abc"
    onExit={noop}
    onSuccess={noop}
  />
);

// Rendering without a software name (uses default fallback)
render(
  <UninstallSoftwareModal
    softwareId={1}
    token="abc"
    onExit={noop}
    onSuccess={noop}
  />
);
```

## Props Exercised

| Prop | Type | Notes |
|---|---|---|
| `softwareId` | `number` | Required identifier for the software |
| `softwareName` | `string` | Optional; triggers named warning message |
| `token` | `string` | Auth/session token |
| `onExit` | `() => void` | Callback on modal close/cancel |
| `onSuccess` | `() => void` | Callback on successful uninstall |
