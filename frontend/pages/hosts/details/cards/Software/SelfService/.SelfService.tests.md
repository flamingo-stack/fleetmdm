Tests the `SelfService` React component, verifying correct rendering of self-service software items across various install/uninstall states and MDM enrollment scenarios.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `getMoreDropdown` | Helper function | Locates the "More" actions combobox by scanning all combobox roles and matching parent text |
| `TEST_PROPS` | Constant | Default `ISoftwareSelfServiceProps` fixture used across all test cases |
| `SelfService` test suite | `describe` block | Integration tests covering all software status states and UI interactions |

## Usage Example

```typescript
// Run all SelfService tests
npx jest SelfService.tests.tsx

// Run a specific test by name
npx jest SelfService.tests.tsx -t "renders installed status"
```

## Test Coverage

| Test Case | Status Scenario | Expected UI |
|-----------|----------------|-------------|
| List rendering | Multiple items | Renders all software names |
| `installed` + `installed_versions` | Installed | "Installed" badge, **Reinstall** button, **More** dropdown enabled |
| `null` status + `installed_versions` | Installed | Same as above |
| `failed_install`, no versions | Failed | "Failed" badge, **Retry** button, no **More** dropdown |
| `failed_uninstall` + versions | Installed | **More** dropdown with **Retry uninstall** option |
| `null` status, no versions | No status | **Install** button, no **More** dropdown |
| `pending_install`, no versions | Installing | "Installing..." badge, **Install** button disabled |
| `pending_uninstall` + versions | Uninstalling | "Uninstalling..." badge, **Reinstall** disabled, **More** disabled |
| BYOD mobile view | `On (personal)` MDM | Shows software list, no "not supported" message |
| Post-update stale inventory | `installed` → `pending_install` → `installed` | Maintains "Updated" state, **Update** button does not reappear |
