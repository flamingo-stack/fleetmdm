Utility helpers for the self-service software catalog, providing category filtering and install-eligibility logic for device software items.

## Key Components

### Constants

- **`IN_PROGRESS_UI_STATUSES`** — Set of UI statuses indicating an installation/uninstall is server-acknowledged but not yet complete.
- **`INSTALLED_OR_IN_FLIGHT_UI_STATUSES`** — Superset of `IN_PROGRESS_UI_STATUSES`; all statuses that disqualify an item from a bulk "Install All" operation.
- **`CATEGORIES_ITEMS`** *(deprecated)* — Static fallback category list for `SoftwareOptionsSelector`. Prefer the dynamic `/software/self_service_categories` endpoint.

### Interfaces

- **`ICategory`** — Describes a UI category item with a client-side `id`, display `label`, and API-facing `value`.

### Functions

| Function | Description |
|---|---|
| `filterSoftwareByCustomCategory` | Client-side category filter. Returns all items when `categoryId` is `undefined` ("All"), an empty array for unknown/stale category IDs, or items whose `software_package` or `app_store_app` categories match the selected category name. |
| `countUninstalledForInstallAll` | Returns the count of software items eligible for bulk install (i.e., not already installed or in-flight). |
| `hasInProgressInstallAllItems` | Returns `true` if any item is currently in a pending/in-progress state, used to disable the "Install All" button. |

## Usage Example

```typescript
import {
  filterSoftwareByCustomCategory,
  countUninstalledForInstallAll,
  hasInProgressInstallAllItems,
} from "./helpers";

// Filter software to a specific category
const filtered = filterSoftwareByCustomCategory(allSoftware, categories, 3);

// Determine how many items would be queued by "Install All"
const eligibleCount = countUninstalledForInstallAll(filtered);

// Disable "Install All" while any install is still in-progress
const isInstallAllDisabled = hasInProgressInstallAllItems(filtered);
```
