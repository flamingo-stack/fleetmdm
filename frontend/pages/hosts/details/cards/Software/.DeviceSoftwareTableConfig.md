Defines the column configuration and data helpers for the device software table, used to display installed software on a host device with columns for name, version, type, and vulnerabilities.

## Key Components

- **`generateSoftwareTableData`** — Pass-through function that returns the raw `IHostSoftware[]` array for table consumption.
- **`generateSoftwareTableHeaders`** — Builds and returns the `react-table` column definitions array with four columns:
  - **Name** — Sortable; renders `SoftwareNameCell` with icon, display name, and source in `"deviceUser"` context.
  - **Installed version** — Uses a function accessor on `installed_versions`; renders `VersionCell`.
  - **Type** — Formats the software source type via `formatSoftwareType`; renders `TooltipTruncatedTextCell`.
  - **Vulnerabilities** — Extracts CVEs via `getVulnerabilities`; renders `VulnerabilitiesCell`.

## Usage Example

```typescript
import {
  generateSoftwareTableHeaders,
  generateSoftwareTableData,
} from "./DeviceSoftwareTableConfig";

const columns = generateSoftwareTableHeaders();
const data = generateSoftwareTableData(hostSoftwareList);

// Pass to a TableContainer or react-table instance
<TableContainer
  columns={columns}
  data={data}
  defaultSortHeader="name"
/>
```

## Notes

- The **Name** and **Vulnerabilities** columns share `installed_versions` data; the `id` field disambiguates them since `react-table` does not support duplicate string accessors.
- Global filter is disabled on the **Type** column; sorting is disabled on all columns except **Name**.
