Test suite for the `InstallStatusCell` React component, verifying rendering and tooltip behavior across all software installation/uninstallation lifecycle statuses.

## Key Components

- **`InstallStatusCell`** — The component under test; renders a status cell (icon + label) for host software with optional interactive tooltips and clickable buttons
- **`createMockHostSoftware` / `createMockHostSoftwarePackage` / `createMockHostAppStoreApp`** — Mock factories from `__mocks__/hostMock` used to construct test fixtures
- **`renderWithSetup`** — Custom test utility wrapping `@testing-library/react` with user-event setup

## Test Cases Covered

| Status | Scenario |
|---|---|
| `installed` | Shows success icon + clickable button, no tooltip |
| `installed` (not via Fleet) | Still renders button even without `last_install` |
| `installing` (online host) | Shows spinner, non-clickable, tooltip with Fleet message |
| `ran_script` | Script-only package shows "Ran" button, no tooltip |
| `pending_install` (offline) | Shows pending icon + tooltip about upcoming install |
| `running_script` (online) | Script running spinner with Fleet tooltip |
| `pending_script` (offline) | "Run (pending)" button with Fleet tooltip |
| `uninstalling` (online) | Spinner, non-clickable, uninstall tooltip |
| `pending_uninstall` (offline) | "Uninstall (pending)" button with Fleet tooltip |
| `failed_install` | Error icon + clickable button + failure tooltip |
| `failed_script` | Script-only failure rendering |

## Usage Example

```typescript
// Running the tests
jest.mock("lodash", () => ({
  ...jest.requireActual("lodash"),
  uniqueId: jest.fn(() => "test-tooltip-id"), // stable IDs for tooltips
}));

const { user } = renderWithSetup(
  <InstallStatusCell
    software={{
      ...createMockHostSoftware({ status: "installed", software_package: pkg }),
      ui_status: "installed",
    }}
    onShowInstallDetails={noop}
    onShowUninstallDetails={noop}
    // ...other handlers
  />
);

await user.hover(screen.getByText("Installed"));
expect(screen.queryByRole("button", { name: /installed/i })).toBeInTheDocument();
```
