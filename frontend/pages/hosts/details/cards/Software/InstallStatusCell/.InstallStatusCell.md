Renders the install/uninstall status cell for host software entries in a table, displaying icons, status text, tooltips, and action buttons based on the software's current installation state.

## Key Components

### Types & Interfaces
- **`IStatusDisplayConfig`** — Defines shape for status display entries: optional icon name/color, display text (static or function), and tooltip renderer
- **`InstallOrCommandUuid`** — Union type for identifying installs via `install_uuid` or commands via `command_uuid`
- **`IInstallStatusCellProps`** — Props for the main cell component including software data, modal callbacks, and host context flags

### Constants
- **`INSTALL_STATUS_DISPLAY_OPTIONS`** — Record mapping all `IHostSoftwareUiStatus` values (excluding `uninstalled`, `recently_uninstalled`, `never_ran_script`) to their `IStatusDisplayConfig`; covers install, uninstall, update, and script execution states
- **`RECENT_SUCCESS_ACTION_MESSAGE`** — Helper producing the "Fleet successfully {action} software and is fetching latest software inventory." message

### Helper Functions
- **`resolveDisplayText`** — Resolves display text string or function given `isSelfService` and `isHostOnline` context
- **`getEmptyCellTooltip`** — Returns appropriate tooltip content for software with no current install status, branching on Apple App Store, Android Play Store, or generic package types
- **`getSoftwarePackageName`** — Extracts display name or package name from host software

### Component
- **`InstallStatusCell`** — Main React component rendering the status cell; delegates to modal handlers for install/uninstall/update/script/VPP details

## Usage Example

```typescript
<InstallStatusCell
  software={hostSoftwareWithUiStatus}
  onShowInstallDetails={(s) => openInstallModal(s)}
  onShowUninstallDetails={(details) => openUninstallModal(details)}
  onShowUpdateDetails={(s) => openUpdateModal(s)}
  onShowIpaInstallDetails={(s) => openIpaModal(s)}
  onShowScriptDetails={(s) => openScriptModal(s)}
  onShowVPPInstallDetails={(s) => openVPPModal(s)}
  isSelfService={false}
  isHostOnline={true}
/>
```
