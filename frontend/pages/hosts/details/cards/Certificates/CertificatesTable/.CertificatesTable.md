Renders a paginated, sortable table of host certificates with optional help text and row-click selection support.

## Key Components

**`ICertificatesTableProps`**
Props interface defining the table's data, pagination state, sort state, and event handlers:
- `data` — `IGetHostCertificatesResponse` containing the certificate list, count, and pagination metadata
- `showHelpText` — toggles an informational paragraph with a link to Fleet's certificate query docs
- `page` / `pageSize` — current pagination state
- `sortHeader` / `sortDirection` — current sort state
- `onSelectCertificate` — callback fired when a certificate row is clicked
- `onNextPage` / `onPreviousPage` / `onSortChange` — pagination and sort event handlers

**`CertificatesTable`**
Functional component that composes `TableContainer` with certificate-specific column configuration generated by `generateTableConfig()`. Pagination and sort changes are handled via a memoized `onQueryChange` callback that diffs the incoming query state against the current page and sort values.

## Usage Example

```typescript
<CertificatesTable
  data={certificatesResponse}
  showHelpText={isPartialData}
  page={currentPage}
  pageSize={20}
  sortHeader="not_valid_after"
  sortDirection="asc"
  onSelectCertificate={(cert) => openCertificateModal(cert)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
  onSortChange={({ order_key, order_direction }) =>
    setSortOptions({ order_key, order_direction })
  }
/>
```

## Notes

- Row selection is single-row only (`disableMultiRowSelect`).
- Next-page navigation is disabled when `data.meta.has_next_results` is `false`.
- Sort is handled server-side (`manualSortBy`); the component does not sort data locally.
