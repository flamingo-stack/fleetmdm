Defines and exports the column configuration for the host certificates table, mapping `IHostCertificate` data fields to sortable, formatted table columns with expiration status indicators.

## Key Components

- **`generateTableConfig`** — Factory function returning an array of `react-table` column definitions for the certificates table. Exported as default.

### Columns Configured

| Column | Accessor | Sortable | Notes |
|---|---|---|---|
| Name | `common_name` | ✅ | Truncated with tooltip |
| Issuer | `issuer.common_name` | ❌ | Truncated with tooltip |
| Keychain | `source` | ❌ | `"system"` → "System"; otherwise shows username via tooltip |
| Issued | `not_valid_before` | ❌ | Formatted as `Month Day, Year` |
| Expires | `not_valid_after` | ✅ | Color-coded: error (expired), warning (≤30 days), success |
| View Details | — | ❌ | Row-hover action link, no navigation |

## Usage Example

```typescript
import generateTableConfig from "./CertificatesTableConfig";

const columns = generateTableConfig();

<TableContainer
  columns={columns}
  data={hostCertificates}
/>
```

## Expiration Status Logic

```typescript
if (hasExpired(not_valid_after))               → "error"   // red
else if (willExpireWithinXDays(value, 30))     → "warning" // yellow
else                                           → "success" // green
```

## Dependencies

- [`react-table`](https://react-table.tanstack.com/) — Column type definitions
- `hasExpired` / `willExpireWithinXDays` — Expiration utility helpers from `utilities/helpers`
- `monthDayYearFormat` — Date formatter from `utilities/date_format`
- `StatusIndicator`, `TooltipTruncatedTextCell`, `ViewAllHostsLink` — Shared UI components
