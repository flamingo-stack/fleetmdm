A card component that displays host SSL/TLS certificates in a paginated, sortable table with error state handling for both admin and device-user contexts.

## Key Components

**`ICertificatesProps`** — Interface defining the component's props:
- `data` — Certificate response payload from the host certificates API
- `hostPlatform` — Platform type used to conditionally show macOS (`darwin`) help text
- `page`, `pageSize`, `sortHeader`, `sortDirection` — Pagination and sort state
- `isError` — Triggers error UI rendering
- `isMyDevicePage` — Switches between admin (`DataError`) and end-user (`DeviceUserError`) error displays
- `onSelectCertificate`, `onNextPage`, `onPreviousPage`, `onSortChange` — Event handlers

**`CertificatesCard`** — Default export; wraps `CertificatesTable` inside a styled `Card` with a `CardHeader`.

**`renderContent()`** — Internal render function that returns either an error component or the `CertificatesTable` based on `isError`.

## Usage Example

```typescript
<CertificatesCard
  data={hostCertificatesResponse}
  hostPlatform="darwin"
  page={0}
  pageSize={20}
  sortHeader="not_valid_after"
  sortDirection="asc"
  isError={false}
  isMyDevicePage={false}
  onSelectCertificate={(cert) => handleCertificateSelect(cert)}
  onNextPage={() => setPage((p) => p + 1)}
  onPreviousPage={() => setPage((p) => p - 1)}
  onSortChange={({ order_key, order_direction }) =>
    handleSortChange({ order_key, order_direction })
  }
/>
```

> **Note:** When `isMyDevicePage` is `true` and an error occurs, `DeviceUserError` is rendered instead of the generic `DataError`, providing a friendlier message for non-admin users. Help text within the table is only shown on macOS (`darwin`) hosts in the admin view.
