Utility helpers for deriving display values and tooltip content from `IHostEndUser` data, used to populate end user identity fields (IdP username, full name, groups, Chrome profiles, and custom emails) in host detail views.

## Key Components

| Export | Description |
|---|---|
| `generateUsernameValues` | Extracts all `idp_username` strings from the end users array |
| `generateFullNameValues` | Returns the first end user's `idp_full_name` if IdP info is present |
| `generateGroupsValues` | Returns the first end user's `idp_groups`, sorted alphabetically |
| `generateChromeProfilesValues` | Filters `other_emails` for `google_chrome_profiles` source entries |
| `generateOtherEmailsValues` | Filters `other_emails` for `custom` source entries |
| `generateFullNameTipContent` | Returns JSX tooltip guiding IdP setup or describing the field source |
| `generateGroupsTipContent` | Returns JSX tooltip prompting IdP connection if `idp_info_updated_at` is null |

## Usage Example

```typescript
import {
  generateUsernameValues,
  generateGroupsValues,
  generateFullNameTipContent,
} from "./helpers";

const endUsers: IHostEndUser[] = [
  {
    idp_username: "jdoe@example.com",
    idp_full_name: "Jane Doe",
    idp_groups: ["Engineering", "Admins"],
    idp_info_updated_at: "2024-01-01T00:00:00Z",
    other_emails: [],
  },
];

generateUsernameValues(endUsers);
// => ["jdoe@example.com"]

generateGroupsValues(endUsers);
// => ["Admins", "Engineering"]

generateFullNameTipContent(endUsers);
// => <>'This is the "givenName + familyName" from your IdP.'</>
```

## Notes

- All generators return an empty array `[]` when `endUsers` is empty or required fields are `undefined`/`null`.
- Full name and groups generators operate only on the **first** element (`endUsers[0]`), as IdP info is scoped to a single primary user.
- Tip content generators return `null` when no tooltip is needed, making them safe for conditional rendering.
