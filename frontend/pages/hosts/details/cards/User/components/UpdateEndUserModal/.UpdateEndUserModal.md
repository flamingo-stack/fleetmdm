A modal component for adding or editing an end user's IdP (Identity Provider) username associated with a host, with premium tier gating.

## Key Components

- **`UpdateEndUserModal`** — Default export. Renders a modal dialog with a form for managing a host's IdP username.
- **`IUpdateEndUserModalProps`** — Interface defining the component's props:
  - `isPremiumTier` — Gates the feature; shows `PremiumFeatureMessage` if `false`
  - `endUsers` — Array of `IHostEndUser` (at most 1 entry)
  - `onUpdate(username)` — Callback invoked with the new/updated username on save
  - `isUpdating` — Optional loading state for the save button
  - `onExit` — Callback to close the modal
- **`generateUsernameValues`** — Helper used to extract the display username from the `endUsers` array
- **`isEditing`** — Derived boolean; `true` when an existing username is present, toggling the modal title between `"Edit user"` and `"Add user"`

## Usage Example

```typescript
import UpdateEndUserModal from "components/UpdateEndUserModal";

<UpdateEndUserModal
  isPremiumTier={true}
  endUsers={[{ username: "jane.doe@example.com", email: "jane.doe@example.com" }]}
  onUpdate={(username) => handleUsernameUpdate(username)}
  isUpdating={isSaving}
  onExit={() => setShowModal(false)}
/>
```

## Behavior Notes

- When `isPremiumTier` is `false`, the form is replaced by a `PremiumFeatureMessage` component.
- The **Save** button is disabled when no username has been entered (add mode) or while an update is in progress.
- The `InputField` renders with `autofocus` and accepts an email-style placeholder (`user@example.com`).
