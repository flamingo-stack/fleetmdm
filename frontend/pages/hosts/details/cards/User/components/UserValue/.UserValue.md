Renders user values in a table cell with smart truncation detection and tooltip support for single and multiple values.

## Key Components

- **`UserValue`** – Default export. A display component that adapts its rendering based on the number of values provided.
- **`IUserValueProps`** – Interface requiring a `values: string[]` prop.
- **`useCheckTruncatedElement`** – Hook used to detect whether the primary value span is visually truncated, conditionally enabling tooltip display.
- **`TooltipWrapper`** – Wraps displayed values to show full content on hover when truncated, or lists overflow items via a `+ N more` trigger.

## Behavior

| Case | Rendered Output |
|------|----------------|
| `values.length === 0` | Displays `DEFAULT_EMPTY_CELL_VALUE` (e.g., `—`) |
| `values.length === 1` | Displays the value with a tooltip only if truncated |
| `values.length > 1` | Displays first value + `+ N more` with a tooltip listing remaining values |

## Usage Example

```typescript
import UserValue from "components/UserValue";

// Empty state
<UserValue values={[]} />

// Single value with truncation-aware tooltip
<UserValue values={["john.doe@example.com"]} />

// Multiple values with overflow tooltip
<UserValue values={["john.doe@example.com", "admin", "superuser"]} />
// Renders: "john.doe@example.com + 2 more"
```
