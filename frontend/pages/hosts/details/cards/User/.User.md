A React card component that displays host end user information sourced from an Identity Provider (IdP), including username, full name, groups, department, Chrome profiles, and additional emails.

## Key Components

### `IUserProps` Interface

| Prop | Type | Description |
|------|------|-------------|
| `endUsers` | `IHostEndUser[]` | Array of end users (at most 1 in practice) |
| `canWriteEndUser` | `boolean` | Shows Edit/Add user button when `true` |
| `canViewMyDeviceLink` | `boolean` | Shows "My device" link button when `true` |
| `disableFullNameTooltip` | `boolean` | Suppresses tooltip on Full Name field |
| `disableGroupsTooltip` | `boolean` | Suppresses tooltip on Groups field |
| `onClickUpdateUser` | `function` | Handler for Edit/Add user button |
| `onClickMyDevice` | `function` | Handler for My device button |

### Helper Functions (from `./helpers`)

- `generateUsernameValues` — formats IdP username display values
- `generateFullNameValues` / `generateFullNameTipContent` — full name data and tooltip
- `generateGroupsValues` / `generateGroupsTipContent` — groups data and tooltip
- `generateChromeProfilesValues` — Chrome profile entries (conditionally rendered)
- `generateOtherEmailsValues` — custom emails via human-device mapping API (conditionally rendered)

## Usage Example

```typescript
import User from "./User";

<User
  endUsers={host.end_users}
  canWriteEndUser={currentUser.canWriteEndUser}
  canViewMyDeviceLink={true}
  onClickUpdateUser={(e) => openUpdateUserModal()}
  onClickMyDevice={(e) => navigateToMyDevice()}
/>
```

## Notes

- Chrome profiles and Other emails sections render **conditionally** — only when values are present.
- The write button dynamically toggles between **"Add user"** (`plus` icon) and **"Edit user"** (`pencil` icon) based on whether a username is already set.
