Defines the column configuration for the Munki Issues data table, specifying headers, accessors, sort behavior, and cell renderers for displaying Munki-reported host issues.

## Key Components

- **`munkiIssuesTableHeaders`** — Array of `IDataColumn` objects configuring three table columns:
  - **Issue** — Truncated text cell with tooltip header explaining Munki run context; case-insensitive sortable via `name` accessor.
  - **Type** — Plain text cell displaying capitalized issue type; sorting disabled.
  - **Time** — Relative timestamp cell (e.g., "3 days ago") using `date-fns` and abbreviated time units; sortable via `created_at` accessor.

- **`IDataColumn`** — Interface describing the full column shape including `Header`, `Cell`, `accessor`, sort/filter options, and react-table filter integration.

- **`IStringCellProps`** / **`ICellProps`** — Typed props interfaces for cell and row data, typed against `IMunkiIssue`.

## Usage Example

```typescript
import munkiIssuesTableHeaders from "./MunkiIssuesTableConfig";
import TableContainer from "components/TableContainer";

const MunkiIssuesTable = ({ issues }: { issues: IMunkiIssue[] }) => (
  <TableContainer
    columns={munkiIssuesTableHeaders}
    data={issues}
    defaultSortHeader="name"
    defaultSortDirection="asc"
  />
);
```

## Notes

- Tooltip headers on **Issue** and **Time** columns provide contextual guidance to users.
- Time values are formatted using [`date-fns` `formatDistanceToNowStrict`](https://date-fns.org/docs/formatDistanceToNowStrict) then passed through `abbreviateTimeUnits` to shorten labels (e.g., `"minutes"` → `"min"`).
