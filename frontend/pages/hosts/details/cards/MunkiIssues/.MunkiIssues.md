Renders a card displaying a sortable table of Munki issues for a host, with an empty state when no issues are reported.

## Key Components

- **`MunkiIssuesTable`** — Default export. A React component that wraps a `TableContainer` inside a `Card` layout to display Munki-reported issues.
- **`IMunkiIssuesTableProps`** — Props interface with:
  - `isLoading: boolean` — Controls loading state of the table.
  - `munkiIssues?: IMunkiIssue[]` — Array of Munki issue records to display.
  - `deviceType?: string` — Optional CSS class applied to the table wrapper div.
- **`munkiIssuesTableHeaders`** — Column configuration imported from `MunkiIssuesTableConfig`, defining the table structure.

## Usage Example

```typescript
import MunkiIssuesTable from "./MunkiIssues";
import { IMunkiIssue } from "interfaces/host";

const issues: IMunkiIssue[] = [
  { name: "missing_package", type: "error", created_at: "2024-01-01" },
];

<MunkiIssuesTable
  isLoading={false}
  munkiIssues={issues}
  deviceType="mac"
/>
```

When `munkiIssues` is empty or undefined, the table renders an `EmptyState` component with the message: *"The last time Munki ran on this host, no issues were reported."*

The table defaults to ascending sort by `name` and uses client-side pagination.
