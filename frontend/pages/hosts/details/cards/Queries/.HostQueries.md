Renders the "Reports" card on a host detail page, displaying scheduled query statistics in a paginated table or an appropriate empty state based on host platform.

## Key Components

- **`HostQueries`** — Main export. Renders a `Card` containing a reports table or empty state, with an optional "Add report" button for authorized users.
- **`EmptyHostQueries`** — Internal component that displays platform-aware empty states; unsupported platforms (Chrome, iOS, iPadOS, Android) show a support link, while supported platforms prompt users to add a report.
- **`IHostQueriesProps`** — Props interface for the main component.
- **`IHostQueriesRowProps`** — Extends `react-table`'s `Row` with typed `original` fields for navigation logic.
- **`onSelectSingleRow`** — Navigates to the host query report results page when a row is clicked, guarded by `should_link_to_hqr` and `queryReportsDisabled` flags.

## Usage Example

```typescript
import HostQueries from "./HostQueries";

<HostQueries
  hostId={42}
  schedule={queryStatsArray}
  hostPlatform="darwin"
  queryReportsDisabled={false}
  router={injectedRouter}
  canAddQuery={true}
  onClickAddQuery={() => setShowAddQueryModal(true)}
/>
```

## Behavior Notes

- Platforms `chrome`, `ios`, `ipados`, and `android` always render the unsupported empty state regardless of `schedule` data.
- The table is paginated client-side at **4 rows per page**; pagination controls are hidden when total rows ≤ 4.
- Row click navigation is suppressed when `queryReportsDisabled` is `true` or the row's `should_link_to_hqr` flag is falsy.
- Column configs and table data are memoized to avoid unnecessary re-renders.
