Renders a table cell displaying when a query report was last updated, with conditional states for no-report, pending, and timestamped results — optionally including a "View data" navigation button.

## Key Components

- **`IReportUpdatedCell`** — Interface defining cell props:
  - `last_fetched` — ISO timestamp of the last report fetch
  - `interval` — Query schedule interval; drives conditional rendering logic
  - `discard_data` / `automations_enabled` — Flags indicating results are streamed to a log destination (no cached report)
  - `should_link_to_hqr` — Controls visibility of the "View data" navigation button
  - `hostId` / `queryId` — Required for constructing the Host Query Report (HQR) route

- **`renderCellValue()`** — Internal function returning one of three states:
  1. **"No report"** — Query discards data with automations enabled; shows tooltip explaining log destination behavior
  2. **Pending (`—`)** — Scheduled query has not yet returned results; shows "collecting" tooltip
  3. **Timestamp** — Renders relative time via `HumanTimeDiffWithFleetLaunchCutoff`

- **`onClick()`** — Navigates to `PATHS.HOST_REPORT_RESULTS(hostId, queryId)` via `browserHistory`

## Usage Example

```typescript
<ReportUpdatedCell
  last_fetched="2024-11-01T12:00:00Z"
  interval={3600}
  discard_data={false}
  automations_enabled={false}
  should_link_to_hqr={true}
  hostId={42}
  queryId={7}
/>
```
