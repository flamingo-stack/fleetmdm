Configures the column definitions and data transformation utilities for the Host Queries table, displaying query statistics per host with optional report-update tracking.

## Key Components

- **`generateColumnConfigs(hostId, queryReportsDisabled?)`** — Returns an array of column definitions for the table. Always includes a `Name` column; conditionally appends a `Last updated` column (with tooltip) when query reports are globally enabled.
- **`generateDataSet(query_stats)`** — Entry point for preparing table rows; delegates to `enhanceScheduleData` or returns an empty array if no data is provided.
- **`enhanceScheduleData(query_stats)`** — Maps raw `IQueryStats` records into `IHostQueriesTableData` rows, computing `should_link_to_hqr` to determine whether a query row should link to the Host Query Report.

### Interfaces

| Interface | Purpose |
|---|---|
| `IHostQueriesTableData` | Extends `IQueryStats` with `should_link_to_hqr` and `id` |
| `IDataColumn` | Column shape consumed by react-table |
| `ICellProps` / `IPerformanceImpactCell` | Typed cell prop variants for different value shapes |

## Usage Example

```typescript
import {
  generateColumnConfigs,
  generateDataSet,
} from "./HostQueriesTableConfig";

// Build column definitions (query reports enabled)
const columns = generateColumnConfigs(hostId, false);

// Transform raw API data into table rows
const rows = generateDataSet(queryStats);

// Pass to your TableContainer
<TableContainer
  columns={columns}
  data={rows}
/>
```

> **Note:** The `should_link_to_hqr` flag is `true` when `last_fetched` is present **or** when the query has an interval and data is not discarded. This drives link rendering inside [`ReportUpdatedCell`](https://github.com/flamingo-stack/fleetmdm/blob/main/pages/hosts/details/cards/Queries/ReportUpdatedCell.tsx).
