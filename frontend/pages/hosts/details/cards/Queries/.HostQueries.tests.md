Unit tests for the `HostQueries` card component, verifying rendering behavior across different host platforms and query schedule states.

## Key Components

- **`HostQueries card` describe block** — Three test cases covering the core rendering scenarios for the `HostQueries` component.

### Test Cases

| Test | Scenario | Assertions |
|------|----------|------------|
| Supported platform with queries | `darwin` platform + populated schedule | Table rows, "Add report" button visible |
| Unsupported platform (`chrome`) | `chrome` platform + empty schedule | Unsupported message shown, "Add report" hidden |
| Supported platform, no reports | `darwin` platform + empty schedule | Empty state message, "Add report" button visible |

## Usage Example

```typescript
// Run tests with:
// npx jest HostQueries.tests.tsx

// Key props exercised in tests:
<HostQueries
  hostId={1}
  schedule={schedule}         // QueryStats[] — empty or populated
  hostPlatform="darwin"       // "darwin" | "chrome" | other
  router={createMockRouter()}
  canAddQuery={true}          // controls "Add report" button visibility
  onClickAddQuery={noop}
/>
```

## Dependencies

- [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) — `render` and `screen` queries
- `createMockRouter` — test utility from [`test/test-utils`](https://github.com/flamingo-stack/fleetmdm/blob/main/test/test-utils)
- `createMockQueryStats` — factory from [`__mocks__/queryMock`](https://github.com/flamingo-stack/fleetmdm/blob/main/src/__mocks__/queryMock)
