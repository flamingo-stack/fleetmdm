Renders the host policies card for a given device, displaying a table of policy compliance results with platform-specific handling and conditional access banners.

## Key Components

| Export/Symbol | Type | Description |
|---|---|---|
| `Policies` (default export) | React component | Main component rendering the host policies table or platform-specific empty states |
| `IPoliciesProps` | Interface | Props contract for the `Policies` component |
| `IHostPoliciesRowProps` | Interface | Extends `react-table` `Row` with a typed `original` field for `IHostPolicy` |
| `renderBanner` | Internal function | Conditionally renders either a `PolicyFailingCount` or a conditional-access-bypassed `InfoBanner` |
| `renderHostPolicies` | Internal function | Renders the policies table or an unsupported-platform `EmptyState` for iOS, iPadOS, and Android |

## Usage Example

```typescript
import Policies from "./HostPolicies";

<Policies
  policies={hostPolicies}
  isLoading={isLoadingPolicies}
  hostPlatform="darwin"
  currentTeamId={42}
  togglePolicyDetailsModal={(policy) => openModal(policy)}
  closePolicyDetailsModal={() => closeModal()}
  conditionalAccessEnabled={true}
  conditionalAccessBypassed={false}
  canManagePolicies={true}
  onManagePolicies={() => navigateToPolicies()}
/>
```

## Platform Handling

- **iOS / iPadOS / Android** — renders an `EmptyState` with a link to the Fleet support channel instead of the table.
- **All other platforms** — renders a `TableContainer` with sortable policy rows; clicking a row opens the policy details modal.
- **Conditional access bypassed** — replaces the `PolicyFailingCount` banner with an Okta-specific `InfoBanner` guiding the user through resolution steps.
- **Device user mode** (`deviceUser`) — strips the "view all hosts" column from the table headers and adjusts empty-state copy to reference "your device".
