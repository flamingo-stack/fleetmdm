Defines table column configuration and data transformation utilities for displaying host-level policy compliance results in a sortable, status-aware table.

## Key Components

- **`PolicyStatus`** — Union type: `"pass" | "fail" | "actionRequired"`, where `actionRequired` indicates a failed policy with conditional access enabled
- **`IEnhancedHostPolicy`** — Extends `IHostPolicy` with a computed `status` field of type `PolicyStatus | null`
- **`getPolicyStatus(policy, conditionalAccessEnabled)`** — Derives a `PolicyStatus` from a policy's raw response string, accounting for conditional access enforcement
- **`generatePolicyTableHeaders(currentTeamId?)`** — Returns the column definitions array for the host policies table (Name, Status, and a filtered-hosts link column)
- **`generatePolicyDataSet(policies, conditionalAccessEnabled)`** — Maps raw `IHostPolicy[]` into `IEnhancedHostPolicy[]` by injecting computed `status` values

## Usage Example

```typescript
import {
  generatePolicyTableHeaders,
  generatePolicyDataSet,
} from "./HostPoliciesTableConfig";

// Transform raw API data into table-ready rows
const tableData = generatePolicyDataSet(hostPolicies, isConditionalAccessEnabled);

// Generate column definitions (scoped to a team if provided)
const columns = generatePolicyTableHeaders(currentTeamId);

// Pass both to your table component
<TableContainer
  columns={columns}
  data={tableData}
/>
```

## Notes

- The `Status` column uses a custom `"hostPolicyStatus"` sort type — ensure this is registered with your `react-table` instance
- `actionRequired` is only surfaced when both the policy-level `conditional_access_enabled` flag and the fleet-wide `conditionalAccessEnabled` setting are `true`
- The link column renders a `ViewAllHostsLink` only when a `response` value exists, filtering hosts by `policy_id` and pass/fail response
