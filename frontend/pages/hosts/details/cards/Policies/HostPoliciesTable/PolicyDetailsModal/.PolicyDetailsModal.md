Renders a modal dialog displaying the details of a host policy, including its description and resolution instructions, with optional conditional access controls.

## Key Components

- **`PolicyDetailsModal`** — Default export. A React functional component that wraps the shared `Modal` component to present policy metadata.
- **`IPolicyDetailsProps`** — Interface defining the component's props:
  - `policy: IHostPolicy | null` — The policy object to display.
  - `onCancel: () => void` — Callback fired on modal close or `Enter` key.
  - `onResolveLater?: () => void` — Optional callback shown when a policy has conditional access enabled and a failing response.
  - `isDeviceUser?: boolean` — Adjusts the empty-state message to direct end users to their IT admin (defaults to `false`).
- **`ClickableUrls`** — Renders the resolution text with auto-linked URLs.

## Usage Example

```typescript
import PolicyDetailsModal from "components/PolicyDetailsModal";

<PolicyDetailsModal
  policy={selectedPolicy}
  onCancel={() => setShowModal(false)}
  onResolveLater={() => handleResolveLater()}
  isDeviceUser={true}
/>
```

## Behavior Notes

- If the policy has neither a `description` nor a `resolution`, an empty-state message is shown. When `isDeviceUser` is `true`, the message appends `"Please contact your IT admin."`
- The **Resolve later** button appears only when all three conditions are met: `policy.conditional_access_enabled`, `policy.response === "fail"`, and `onResolveLater` is provided.
