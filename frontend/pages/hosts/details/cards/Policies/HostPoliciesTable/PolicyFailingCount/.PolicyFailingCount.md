Renders a dismissible warning banner displaying the count of failing host policies, with conditional messaging for devices where login access is being blocked by policy enforcement.

## Key Components

### `PolicyFailingCount`
A React component that computes failing policy counts from a list of `IHostPolicy` objects and renders an `InfoBanner` with an `IconStatusMessage`. Returns `null` when no policies are failing.

**Props (`IPolicyFailingCountProps`):**

| Prop | Type | Description |
|---|---|---|
| `policyList` | `IHostPolicy[]` | List of host policies to evaluate |
| `deviceUser` | `boolean` (optional) | Tailors messaging with a "Refetch" prompt when viewed by the device's user |
| `conditionalAccessEnabled` | `boolean` (optional) | Switches messaging to a "blocking login" variant when active |

**Internal Logic:**
- `failCount` — total policies where `response === "fail"`
- `blockingCount` — subset of failed policies where `conditional_access_enabled` is also `true`
- Displays the "blocking login" message only when `conditionalAccessEnabled` is `true` **and** `blockingCount > 0`; otherwise falls back to the standard failing-count message

## Usage Example

```typescript
import PolicyFailingCount from "components/PolicyFailingCount";

<PolicyFailingCount
  policyList={hostPolicies}
  deviceUser={true}
  conditionalAccessEnabled={true}
/>
```
