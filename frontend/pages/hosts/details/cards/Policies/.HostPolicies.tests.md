Tests for the `HostPolicies` React component, verifying rendering behavior across permission levels, platform types, policy counts, and modal lifecycle management.

## Key Components

- **`createMockHostPolicy`** — Factory function that returns a complete `IHostPolicy` fixture with sensible defaults, accepting optional overrides for targeted test scenarios.
- **`baseProps`** — Shared baseline props object used across all test cases to reduce boilerplate.
- **`renderWithContext`** — Helper wrapping `createCustomRenderer` to mount `HostPolicies` with merged base and per-test props.
- **`Wrapper`** — Inline stateful component used in the modal lifecycle test to simulate parent-owned modal state (mirrors `HostDetailsPage` / `DeviceUserPage` ownership).

## Test Coverage

| Scenario | Assertion |
|---|---|
| Empty state with manage permission | Shows `"0 policies"`, empty state copy, and "Manage policies" button |
| Empty state without manage permission | Hides "Manage policies" button and manage clause |
| Device user mode | Renders `"your device"` copy instead of `"this host"` |
| Policies present | Displays correct count badge (`"3 policies"`) |
| iOS / Android hosts | Shows unsupported platform message; hides normal empty state |
| Modal closed on unmount | `PolicyDetailsModal` is dismissed when `HostPolicies` unmounts |

## Usage Example

```typescript
// Run all tests
npx jest HostPolicies.tests.tsx

// Adding a new scenario — extend baseProps with overrides
renderWithContext({
  policies: [createMockHostPolicy({ response: "fail", critical: true })],
  canManagePolicies: true,
});

expect(screen.getByText("1 policies")).toBeInTheDocument();
```
