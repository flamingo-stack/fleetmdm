Renders the header section for a host detail page, displaying the host's display name, MDM device status tag, last-fetched timestamp, refetch button, and an actions dropdown.

## Key Components

### `RefetchButton`
Internal sub-component that renders a refresh button with contextual tooltip support. Switches between a spinner label and "Refetch" text based on `isFetching` state.

**Props:**
| Prop | Type | Description |
|---|---|---|
| `isDisabled` | `boolean` | Disables the button |
| `isFetching` | `boolean` | Shows fetching state/label |
| `tooltip` | `React.ReactNode` | Optional tooltip content |
| `onRefetchHost` | `function` | Click handler |

### `HostHeader` (default export)
Main header component orchestrating display name, device status, last-fetched time, and action controls.

**Props:**
| Prop | Type | Description |
|---|---|---|
| `summaryData` | `any` | Host data including `platform`, `status`, `display_name`, `detail_updated_at` |
| `showRefetchSpinner` | `boolean` | Triggers fetching state on refetch button |
| `onRefetchHost` | `function` | Refetch click handler |
| `renderActionsDropdown` | `function` | Renders the actions dropdown |
| `deviceUser` | `boolean` | Switches to device-user view |
| `deviceUserHeader` | `string` | Override title in device-user mode (defaults to `"My device"`) |
| `hostMdmDeviceStatus` | `HostMdmDeviceStatusUIState` | Controls refetch button disable logic and status tag |
| `hostMdmEnrollmentStatus` | `MdmEnrollmentStatus \| null` | Used for iOS/iPadOS-specific refetch logic |

## Usage Example

```typescript
<HostHeader
  summaryData={host}
  showRefetchSpinner={isFetching}
  onRefetchHost={handleRefetch}
  renderActionsDropdown={() => <ActionsDropdown host={host} />}
  hostMdmDeviceStatus={mdmDeviceStatus}
  hostMdmEnrollmentStatus={host.mdm.enrollment_status}
/>
```

## Refetch Button Logic

- **Android:** Refetch button is hidden entirely.
- **iOS/iPadOS:** Disabled state is determined solely by `hostMdmDeviceStatus` and `hostMdmEnrollmentStatus`.
- **Other platforms:** Disabled when the host is offline or when `hostMdmDeviceStatus` is locked/wiped.
