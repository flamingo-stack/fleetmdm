Renders the main host management page for the Fleet MDM interface, providing a comprehensive table view of enrolled devices with filtering, sorting, bulk actions, and modal-driven workflows for host enrollment, label management, and script execution.

## Key Components

### `ManageHostsPage`
The primary page component that orchestrates:

- **Multi-source data fetching** via `react-query` for hosts, labels, teams, policies, OS versions, enroll secrets, and script batch summaries
- **URL-driven state** — sort order, pagination, search query, and all filter parameters are persisted in the query string
- **Team scoping** via `useTeamIdParam` hook, with automatic removal of incompatible query params on team change
- **Modal management** for 8+ modals: Add Hosts, Enroll Secrets, Transfer Host, Delete Host, Delete Label, Edit Columns, Run Script Batch, and Secret Editor

### Configuration Utilities (imported)
| Import | Purpose |
|---|---|
| `generateVisibleTableColumns` | Builds column set from hidden-columns preference |
| `generateAvailableTableHeaders` | Full available column list for column editor |
| `defaultHiddenColumns` | Initial hidden column set |
| `MANAGE_HOSTS_PAGE_FILTER_KEYS` | Canonical list of URL filter params |

## Usage Example

```typescript
// Rendered via React Router — not instantiated directly.
// Route definition (simplified):
<Route path={PATHS.MANAGE_HOSTS} component={ManageHostsPage} />

// Deep-link examples that trigger modal open on load:
// ?add_hosts=1            → opens Add Hosts modal (admins/maintainers only)
// ?manage_enroll_secrets=1 → opens Enroll Secrets modal

// URL filter params consumed by the page:
// ?policy_id=3&policy_response=passing
// ?software_title_id=42&software_status=installed
// ?script_batch_execution_id=<uuid>&script_batch_execution_status=ran
```
