Provides lightweight validation utility functions for filtering and data format checks used across the Fleet MDM frontend.

## Key Components

| Function | Signature | Description |
|---|---|---|
| `isAcceptableStatus` | `(filter: string) => boolean` | Checks if a string matches a valid host status value |
| `isValidPolicyResponse` | `(filter: string) => boolean` | Validates a policy response as either `"pass"` or `"fail"` |
| `isValidPemCertificate` | `(cert: string) => boolean` | Performs simplified PEM certificate chain validation using `-----BEGIN` / `-----END` header checks |

## Usage Example

```typescript
import {
  isAcceptableStatus,
  isValidPolicyResponse,
  isValidPemCertificate,
} from "./helpers";

// Host status filter validation
isAcceptableStatus("online");  // true
isAcceptableStatus("active");  // false

// Policy response validation
isValidPolicyResponse("pass"); // true
isValidPolicyResponse("skip"); // false

// PEM certificate validation (simplified)
const pemCert = `-----BEGIN CERTIFICATE-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...
-----END CERTIFICATE-----`;
isValidPemCertificate(pemCert); // true
isValidPemCertificate("not-a-cert"); // false
```

## Notes

- **Accepted host statuses:** `"new"`, `"online"`, `"offline"`, `"missing"`, `"pending"`
- **PEM validation** is intentionally minimal — it only checks for the presence of `-----BEGIN` and `-----END` markers per [RFC 7468](https://datatracker.ietf.org/doc/html/rfc7468#section-2). For stricter validation, consider a dedicated PEM parsing library.
