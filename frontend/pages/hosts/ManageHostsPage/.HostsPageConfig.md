Defines configuration constants and types for the Manage Hosts page, including URL filter keys, sort defaults, and host status/OS settings filter options.

## Key Components

- **`MANAGE_HOSTS_PAGE_FILTER_KEYS`** — Exhaustive `as const` tuple of all valid URL query parameter keys used to filter the hosts list.
- **`MANAGE_HOSTS_PAGE_LABEL_INCOMPATIBLE_QUERY_PARAMS`** — Subset of filter keys that must be stripped from the URL when a non-status label is selected.
- **`ManageHostsPageQueryParams`** — TypeScript `Record` type mapping all filter keys plus pagination/sort params to string values; intended as the typed `location.query` shape for the page.
- **`LABEL_SLUG_PREFIX`** — Constant prefix (`"labels/"`) for label-based route slugs.
- **`DEFAULT_SORT_HEADER`**, **`DEFAULT_SORT_DIRECTION`**, **`DEFAULT_PAGE_SIZE`**, **`DEFAULT_PAGE_INDEX`** — Default pagination and sort configuration values.
- **`hostSelectStatuses(isPremiumTier)`** — Returns the list of host status filter options, conditionally appending the `"pending"` status for premium-tier Fleet instances.
- **`OS_SETTINGS_FILTER_OPTIONS`** — Static filter options (`verified`, `verifying`, `pending`, `failed`) for the OS settings filter dropdown.

## Usage Example

```typescript
import {
  MANAGE_HOSTS_PAGE_FILTER_KEYS,
  MANAGE_HOSTS_PAGE_LABEL_INCOMPATIBLE_QUERY_PARAMS,
  DEFAULT_SORT_HEADER,
  DEFAULT_SORT_DIRECTION,
  DEFAULT_PAGE_SIZE,
  DEFAULT_PAGE_INDEX,
  hostSelectStatuses,
  OS_SETTINGS_FILTER_OPTIONS,
} from "./HostsPageConfig";

// Strip label-incompatible params when a non-status label is selected
const cleanedQuery = omit(query, MANAGE_HOSTS_PAGE_LABEL_INCOMPATIBLE_QUERY_PARAMS);

// Build status filter list based on tier
const statusOptions = hostSelectStatuses(isPremiumTier);

// Apply defaults for pagination/sort
const params = {
  order_key: DEFAULT_SORT_HEADER,   // "display_name"
  order_direction: DEFAULT_SORT_DIRECTION, // "asc"
  page: DEFAULT_PAGE_INDEX,         // 0
  per_page: DEFAULT_PAGE_SIZE,      // 50
};
```
