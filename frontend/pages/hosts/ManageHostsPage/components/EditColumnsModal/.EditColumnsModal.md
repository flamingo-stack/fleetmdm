A modal dialog component that allows users to toggle the visibility of table columns via checkboxes.

## Key Components

### `useCheckboxListStateManagement` (hook)
Internal custom hook that manages checkbox state for the column list. Initializes each column's checked state based on whether its `id` appears in the `hiddenColumns` array, and exposes an `updateColumnItems` function to toggle individual columns.

### `getHiddenColumns` (utility)
Pure function that filters the column items array and returns an array of `id` strings for any column where `isChecked` is `false`.

### `EditColumnsModal` (default export)
The main React component. Renders a `Modal` containing a checkbox list for each column (excluding those with `disableHidden: true`), plus **Save** and **Cancel** action buttons.

**Props:**

| Prop | Type | Description |
|---|---|---|
| `columns` | `Array<Object>` | All available columns with `id`, `title`, and `disableHidden` |
| `hiddenColumns` | `Array<string>` | Column IDs currently hidden |
| `onSaveColumns` | `Function` | Called with updated hidden column IDs on save |
| `onCancelColumns` | `Function` | Called when the modal is dismissed |

## Usage Example

```javascript
import EditColumnsModal from "components/EditColumnsModal";

<EditColumnsModal
  columns={[
    { id: "hostname", title: "Hostname", disableHidden: true },
    { id: "status",   title: "Status",   disableHidden: false },
    { id: "os",       title: "OS",        disableHidden: false },
  ]}
  hiddenColumns={["os"]}
  onSaveColumns={(newHiddenColumns) => updateTablePrefs(newHiddenColumns)}
  onCancelColumns={() => setShowModal(false)}
/>
```

When the user clicks **Save**, `onSaveColumns` receives the updated array of hidden column IDs (e.g. `["os"]`). Columns with `disableHidden: true` are always visible and excluded from the checkbox list.
