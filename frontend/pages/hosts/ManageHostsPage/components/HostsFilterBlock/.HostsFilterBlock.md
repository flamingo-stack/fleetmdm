Renders the filtering section of the Manage Hosts page, displaying context-aware filter pills and dropdowns based on active query parameters such as OS, MDM status, software, policies, and labels.

## Key Components

### `HostsFilterBlock` (default export)
The main component that conditionally renders filter pills and dropdowns based on the active filter state passed via `params`.

### `IHostsFilterBlockProps`
The component's prop interface, defining:
- **`params`** — All active filter values (policy, MDM, software, OS, disk encryption, script batch, etc.)
- **`selectedLabel`** — Currently selected host label
- **`handleClearFilter`** / **`handleClearRouteParam`** — Callbacks to remove filter params
- **`onChange*` handlers** — Callbacks for each filterable dimension (MDM, OS settings, bootstrap package, etc.)
- **`onClickEditLabel`** / **`onClickDeleteLabel`** — Label management actions

### Internal render helpers
| Function | Renders |
|---|---|
| `renderLabelFilterPill` | Label pill with optional edit/delete buttons (respects GitOps mode and observer role) |
| `renderOSFilterBlock` | OS version pill resolved from `osVersionId` or `osName`+`osVersion` |
| `renderVulnerabilityFilterBlock` | CVE vulnerability pill |
| `renderPoliciesFilterBlock` | Policy dropdown + pill |
| `renderMacSettingsStatusFilterBlock` | Apple settings dropdown + pill |
| `renderSoftwareFilterBlock` | Software title/version pill |
| `renderMDMSolutionFilterBlock` | MDM server pill |
| `renderMDMEnrollmentFilterBlock` | MDM enrollment status pill |

## Usage Example

```typescript
<HostsFilterBlock
  params={{
    policyId: 5,
    policyResponse: "passing",
    policy: { name: "Firewall Enabled" },
    softwareDetails: null,
    mdmSolutionDetails: null,
    munkiIssueDetails: null,
    scriptBatchRanAt: null,
    scriptBatchScriptName: null,
    depProfileError: "false",
  }}
  selectedLabel={undefined}
  isOnlyObserver={false}
  handleClearRouteParam={() => {}}
  handleClearFilter={(params) => removeQueryParams(params)}
  onChangePoliciesFilter={(response) => setPolicyResponse(response)}
  onChangeOsSettingsFilter={(status) => setOsSettingsStatus(status)}
  onChangeDiskEncryptionStatusFilter={(status) => setDiskEncryption(status)}
  onChangeBootstrapPackageStatusFilter={(status) => setBootstrap(status)}
  onChangeMacSettingsFilter={(status) => setMacSettings(status)}
  onChangeSoftwareInstallStatusFilter={(status) => setSoftwareStatus(status)}
  onChangeConfigProfileStatusFilter={(status) => setConfigProfile(status)}
  onChangeScriptBatchStatusFilter={(status) => setScriptBatch(status)}
  onClickEditLabel={(e) => openEditLabelModal(e)}
  onClickDeleteLabel={() => openDeleteLabelModal()}
/>
```

## Notes
- Returns an empty fragment while `isLoading` is `true`
- Label edit/delete buttons are gated by GitOps mode, observer role, and label ownership
- `host_vitals` labels suppress the edit button per a known limitation
