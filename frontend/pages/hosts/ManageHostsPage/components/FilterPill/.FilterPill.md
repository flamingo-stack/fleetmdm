A UI pill component for displaying active filters with an optional icon, tooltip support for truncated or described content, and a clear/dismiss button.

## Key Components

### `IFilterPillProps`
| Prop | Type | Description |
|------|------|-------------|
| `label` | `string` | Display text for the active filter |
| `onClear` | `() => void` | Callback fired when the dismiss button is clicked |
| `icon` | `IconNames` | Optional icon rendered before the label |
| `tooltipDescription` | `string \| ReactNode` | Custom tooltip content; falls back to truncated label text if omitted |
| `className` | `string` | Additional CSS class names |

### Truncation Behavior
Uses `useCheckTruncatedElement` to detect when the label text overflows its container. If no `tooltipDescription` is provided and the text is truncated, the tooltip automatically displays the full label — mirroring `TooltipTruncatedText` behavior.

## Usage Example

```typescript
import FilterPill from "components/FilterPill";

// Basic usage with clear handler
<FilterPill
  label="macOS"
  onClear={() => handleClearFilter("platform")}
/>

// With icon and custom tooltip description
<FilterPill
  label="Low disk space"
  icon="warning"
  tooltipDescription="Hosts with less than 10GB available"
  onClear={() => handleClearFilter("disk")}
  className="my-custom-class"
/>
```

> The pill renders with `role="status"` and an `aria-label` of `"hosts filtered by {label}"` for accessibility. The close button uses `variant="icon"` to render without default button chrome.
