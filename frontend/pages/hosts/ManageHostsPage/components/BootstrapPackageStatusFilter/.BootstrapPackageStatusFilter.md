A React dropdown filter component for filtering hosts by their MDM bootstrap package installation status.

## Key Components

- **`BootstrapPackageStatusFilter`** — Default export; renders a `Dropdown` populated with the three possible bootstrap package statuses
- **`BOOTSTRAP_PACKAGE_STATUS`** — Static dropdown options array mapping `BootstrapPackageStatus` enum values (`INSTALLED`, `PENDING`, `FAILED`) to display labels
- **`IBootstrapPackageStatusFilterProps`** — Props interface requiring the current status value and an `onChange` handler

## Usage Example

```typescript
import BootstrapPackageStatusFilter from "components/BootstrapPackageStatusFilter";
import { BootstrapPackageStatus } from "interfaces/mdm";

const [status, setStatus] = useState<BootstrapPackageStatus>(
  BootstrapPackageStatus.INSTALLED
);

<BootstrapPackageStatusFilter
  bootstrapPackageStatus={status}
  onChange={(newStatus) => setStatus(newStatus)}
/>
```

## Notes

- The `Dropdown` import uses a `@ts-ignore` comment, indicating the underlying component lacks TypeScript typings
- The component is non-searchable (`searchable={false}`), presenting a simple select-style UI
- BEM-style class naming (`bootstrap-package-status-filter`) is applied to both the wrapper `div` and the inner dropdown for targeted styling
