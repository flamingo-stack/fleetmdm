A confirmation modal component for deleting a label, with conditional premium-tier warnings about configuration profiles and policies.

## Key Components

**`DeleteLabelModal`** — Default export. Renders a `Modal` with a delete confirmation message, conditional warnings for premium users, and Delete/Cancel action buttons.

**`IDeleteLabelModalProps`** — Interface defining the component's props:
- `onSubmit: () => void` — Callback fired when the user confirms deletion
- `onCancel: () => void` — Callback fired when the user cancels or exits the modal
- `isUpdatingLabel: boolean` — Controls the loading state on the Delete button

**Context dependency:** Reads `isPremiumTier` from `AppContext` to conditionally render warnings about configuration profiles and policies affected by label deletion.

## Usage Example

```typescript
import DeleteLabelModal from "components/DeleteLabelModal";

<DeleteLabelModal
  onSubmit={handleDeleteLabel}
  onCancel={() => setShowDeleteModal(false)}
  isUpdatingLabel={isLoading}
/>
```

## Behavior Notes

- Supports keyboard interaction via `onEnter` (submit) and `onExit` (cancel) on the underlying `Modal`
- Premium-tier users see two additional warnings:
  - Labels targeted by a configuration profile cannot be deleted until the profile is removed first
  - Policies and reports targeting the label will continue running but may affect different hosts
- The Delete button enters a loading state while `isUpdatingLabel` is `true`, preventing duplicate submissions
