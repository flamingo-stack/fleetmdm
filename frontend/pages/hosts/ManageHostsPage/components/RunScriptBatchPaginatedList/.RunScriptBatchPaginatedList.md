Paginated list component for browsing and running scripts in a batch run workflow, supporting page-by-page script fetching with run/run-again actions per row.

## Key Components

### Exports
- **`RunScriptBatchPaginatedList`** — Default export. React component that renders a paginated list of scripts with per-row run controls.
- **`IPaginatedListScript`** — Extended `IScript` interface with an optional `hasRun` boolean to track whether a script has already been triggered in the current session.
- **`SCRIPT_BATCH_PAGE_SIZE`** — Constant (`6`) controlling how many scripts are fetched and displayed per page.

### Internal Behaviour
- **`useQuery`** — Fetches one page of scripts at a time via `scriptAPI.getScripts`, keyed by team ID, page number, and tier.
- **`onRunScript`** — Calls the parent handler then flips `hasRun: true` on the local row state via the `PaginatedList` `onChange` callback.
- **`renderScriptRow`** — Renders the script name and a toggle button showing "Run script" (first run) or "Run again" (subsequent runs) with matching icons.

### Props (`IRunScriptBatchPaginatedList`)
| Prop | Type | Description |
|---|---|---|
| `onRunScript` | `(script) => void` | Called when a script run is triggered |
| `isUpdating` | `boolean` | Disables the list during an in-progress action |
| `teamId` | `number` | Scopes the script query to a team |
| `isFreeTier` | `boolean?` | Adjusts query criteria for free-tier accounts |
| `scriptCount` | `number` | Total script count for pagination controls |
| `setScriptForDetails` | `(script) => void` | Opens detail view on row click |

## Usage Example

```typescript
<RunScriptBatchPaginatedList
  onRunScript={(script) => handleRun(script)}
  isUpdating={isRunning}
  teamId={42}
  isFreeTier={false}
  scriptCount={totalScripts}
  setScriptForDetails={(script) => setDetailScript(script)}
/>
```
