Integration tests for the `RunScriptBatchPaginatedList` component, verifying script listing, run action callbacks, and script detail selection behavior against a mocked backend.

## Key Components

- **`waitForLoadingToFinish`** — Helper that waits for the `.loading-overlay` element to disappear before making assertions
- **`team1ScriptOverrides`** — Mock script fixtures scoped to team ID `1`, used across all test cases
- **`team1ScriptsHandler`** — MSW request handler that returns the mock scripts for team `1`
- **Test suite** — Three `it` blocks covering the core interactive behaviors of `RunScriptBatchPaginatedList`

## Test Cases

| Test | Description |
|------|-------------|
| Lists a team's scripts | Renders the component and asserts the correct number of list items with matching names |
| `onRunScript` callback | Clicks the run button on the first script and asserts the callback receives the correct script by ID |
| `setScriptForDetails` callback | Clicks a script name and asserts the details handler is called with the correct script by ID |

## Usage Example

```typescript
// Running a single test case in isolation
it("Calls `onRunScript` with the appropriate script", async () => {
  mockServer.use(team1ScriptsHandler);
  const onRunScript = jest.fn();
  const { container } = render(
    <RunScriptBatchPaginatedList
      onRunScript={onRunScript}
      isUpdating={false}
      teamId={1}
      scriptCount={2}
      setScriptForDetails={jest.fn()}
    />
  );
  await waitForLoadingToFinish(container);
  // Interact and assert...
});
```

> **Note:** Tests validate callbacks by script `id` rather than full object equality, so changes to `fetchPage` transformation logic won't break these tests unnecessarily.
