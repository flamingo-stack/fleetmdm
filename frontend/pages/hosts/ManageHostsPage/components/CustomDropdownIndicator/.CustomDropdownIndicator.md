Custom dropdown indicator component for a `react-select-5` select input, rendering a chevron icon that changes color based on focus and open menu states.

## Key Components

- **`CustomDropdownIndicator`** — A custom `react-select-5` `DropdownIndicator` component that replaces the default dropdown arrow with a `chevron-down` icon. Accepts `DropdownIndicatorProps` typed to `ILabel | IEmptyOption` options within `IGroupOption` groups.
- **Color logic** — Dynamically sets the icon color to `"core-fleet-black"` when the select is focused or its menu is open, otherwise defaults to `"ui-fleet-black-75"`. Hover state styling is handled externally via SCSS in `LabelFilterSelect`.

## Usage Example

This component is intended to be passed as a custom component override to a `react-select-5` `Select` instance, typically inside `LabelFilterSelect`:

```typescript
import Select from "react-select-5";
import CustomDropdownIndicator from "./CustomDropdownIndicator";

<Select
  options={groupedOptions}
  components={{ DropdownIndicator: CustomDropdownIndicator }}
/>
```

## Notes

- Hover color transitions are **not** handled in this component — they rely on SCSS rules in the parent `LabelFilterSelect` component, since `react-select-5` does not expose hover state via props.
- The `baseClass` CSS class `"custom-dropdown-indicator"` is applied to both the wrapper and the icon (as `custom-dropdown-indicator__icon`) for BEM-style SCSS targeting.
