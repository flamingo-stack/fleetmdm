A custom React Select v5 dropdown indicator component that replaces the default indicator with a filter icon.

## Key Components

- **`CustomDropdownIndicator`** — Default export. A wrapper around `react-select-5`'s `DropdownIndicator` component that renders a `filter-alt` icon in place of the standard chevron/caret indicator.

## Usage Example

```typescript
import CustomDropdownIndicator from "components/CustomValueContainer";
import Select from "react-select-5";

<Select
  components={{ DropdownIndicator: CustomDropdownIndicator }}
  options={options}
/>
```

## Notes

- Applies the `custom-dropdown-indicator` BEM base class for styling hooks; hover state styling is handled externally in `LabelFilterSelect.scss` rather than inline.
- The `props` argument uses a loose `ValueContainerProps | any` type signature — the component receives the full react-select props object nested under a `props` key.
