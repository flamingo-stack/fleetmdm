A React filter component that renders a dropdown for filtering hosts or results by policy response status (Pass/Fail).

## Key Components

### Interface: `IPoliciesFilterProps`
- `policyResponse: PolicyResponse` — The currently selected filter value (`PASSING` or `FAILING`)
- `onChange: (selectedFilter: PolicyResponse) => void` — Callback invoked when the user selects a new filter option

### Constant: `POLICY_RESPONSE_OPTIONS`
Dropdown option definitions mapping `PolicyResponse.PASSING` → `"Pass"` and `PolicyResponse.FAILING` → `"Fail"`.

### Component: `PoliciesFilter` (default export)
Wraps the shared `Dropdown` component with a non-searchable, icon-adorned select using the `"filter-alt"` icon.

## Usage Example

```typescript
import PoliciesFilter from "components/PoliciesFilter";
import { PolicyResponse } from "utilities/constants";

const MyPage = () => {
  const [policyResponse, setPolicyResponse] = React.useState<PolicyResponse>(
    PolicyResponse.PASSING
  );

  return (
    <PoliciesFilter
      policyResponse={policyResponse}
      onChange={(selected) => setPolicyResponse(selected)}
    />
  );
};
```

## Notes
- Relies on the `PolicyResponse` enum from `utilities/constants` for type-safe filter values.
- The underlying `Dropdown` component is imported with `@ts-ignore` due to missing type definitions.
- `searchable={false}` keeps the dropdown simple — no text-based filtering of options.
