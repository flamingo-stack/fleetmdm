Custom group heading component for React Select that renders differently based on group type — platform groups display a simple title, while label groups include a search input and optional "Add label" button.

## Key Components

### `CustomLabelGroupHeading`

A React Select custom `GroupHeading` component accepting `GroupHeadingProps` typed to `ILabel | IEmptyOption` within an `IGroupOption` group. Behavior branches on `data.type`:

- **`"platform"` type** — Renders a minimal header with only the group title.
- **Other types (label groups)** — Renders a full header with:
  - Group title
  - Optional "Add label" `Button` (shown when `canAddNewLabels` is `true`)
  - A search `<input>` for filtering labels by name, using a `useRef` to manage focus
  - Click propagation stopped on the input to prevent the parent dropdown from intercepting events

### Custom `selectProps` consumed

| Prop | Description |
|---|---|
| `labelQuery` | Controlled value for the search input |
| `canAddNewLabels` | Toggles the add-label button |
| `onAddLabel` | Handler for the add-label button click |
| `onChangeLabelQuery` | Handler for search input `onChange` |
| `onClickLabelSearchInput` | Handler for search input `onClick` |
| `onBlurLabelSearchInput` | Handler for search input `onBlur` |

## Usage Example

```typescript
import CustomLabelGroupHeading from "./CustomLabelGroupHeading";
import ReactSelect from "react-select-5";

<ReactSelect
  components={{ GroupHeading: CustomLabelGroupHeading }}
  labelQuery={query}
  canAddNewLabels={true}
  onAddLabel={() => openAddLabelModal()}
  onChangeLabelQuery={(e) => setQuery(e.target.value)}
  onClickLabelSearchInput={(e) => handleInputFocus(e)}
  onBlurLabelSearchInput={() => handleBlur()}
  options={groupedOptions}
/>
```

> **Note:** The extra props (`labelQuery`, `canAddNewLabels`, etc.) must be passed directly on the `ReactSelect` component — they are accessed via `selectProps` inside the custom heading. These are non-standard React Select props and should be declared via module augmentation if TypeScript strict checking is enabled.
