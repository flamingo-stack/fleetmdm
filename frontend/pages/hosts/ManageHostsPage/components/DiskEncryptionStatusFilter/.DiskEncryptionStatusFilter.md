A React filter component that renders a dropdown for filtering hosts by their disk encryption status in the Fleet MDM interface.

## Key Components

- **`DISK_ENCRYPTION_STATUS_OPTIONS`** – Static array of `IDropdownOption` items representing the six possible disk encryption states: `verified`, `verifying`, `action_required`, `enforcing`, `failed`, and `removing_enforcement`
- **`IDiskEncryptionStatusFilterProps`** – Component props interface accepting the current `DiskEncryptionStatus` value and an `onChange` callback
- **`DiskEncryptionStatusFilter`** – Default export; a controlled dropdown component that surfaces disk encryption status options for host filtering

## Usage Example

```typescript
import DiskEncryptionStatusFilter from "components/DiskEncryptionStatusFilter";
import { DiskEncryptionStatus } from "interfaces/mdm";

const HostsTable = () => {
  const [encryptionStatus, setEncryptionStatus] =
    useState<DiskEncryptionStatus>("verified");

  return (
    <DiskEncryptionStatusFilter
      diskEncryptionStatus={encryptionStatus}
      onChange={(newStatus) => setEncryptionStatus(newStatus)}
    />
  );
};
```

## Notes

- Non-searchable dropdown; user selects from a fixed list only
- Wraps the internal `Dropdown` field component (TypeScript-ignored due to missing types)
- The `onChange` handler receives a typed `DiskEncryptionStatus` value directly, making it straightforward to wire into parent filter state or query params
