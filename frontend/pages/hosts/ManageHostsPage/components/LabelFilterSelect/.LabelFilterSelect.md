A React Select dropdown component for filtering devices by platform or label, with support for custom label searching, platform icons, and a controlled menu state.

## Key Components

- **`LabelFilterSelect`** – Main exported component wrapping `react-select-5` with custom behavior for label/platform filtering
- **`formatOptionLabel`** – Renders individual dropdown options with platform icons and correct display names
- **`LoadingMenu`** – Custom menu component that renders a spinner while labels are being fetched
- **`ValueContainer`** – Custom value container that prepends a filter icon when a value is selected
- **Extended `react-select-5` Props** – Module augmentation adding `labelQuery`, `canAddNewLabels`, `onAddLabel`, and related label search handlers to react-select's `Props` interface

## Props

| Prop | Type | Description |
|------|------|-------------|
| `labels` | `ILabel[]` | Available labels to display in the dropdown |
| `selectedLabel` | `ILabel \| null` | Currently selected label |
| `canAddNewLabels` | `boolean` | Whether the "Add label" action is shown |
| `onChange` | `(label: ILabel) => void` | Called when a label is selected |
| `onAddLabel` | `() => void` | Called when user triggers label creation |
| `isLoading` | `boolean` | Shows spinner menu when `true` |
| `isDisabled` | `boolean` | Disables the entire select |

## Usage Example

```typescript
import LabelFilterSelect from "components/LabelFilterSelect";

<LabelFilterSelect
  labels={allLabels}
  selectedLabel={currentLabel}
  canAddNewLabels={isAdmin}
  onChange={(label) => setCurrentLabel(label)}
  onAddLabel={() => router.push("/labels/new")}
  isLoading={labelsLoading}
/>
```

> **Note:** The component uses a controlled `menuIsOpen` state and a `ref`-tracked focus flag (`isLabelSearchInputFocusedRef`) to coordinate focus between the react-select dropdown and an internal label search input rendered inside `CustomLabelGroupHeading`.
