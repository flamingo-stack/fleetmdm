Utility functions for building grouped dropdown options for label-based host filtering in the Fleet MDM UI.

## Key Components

### Interfaces

- **`IEmptyOption`** — Represents a disabled placeholder option shown when no labels are available.
- **`IGroupOption`** — Describes a grouped dropdown section with a `type` (`"platform"` or `"custom"`), a display `label`, and its `options` array.

### Functions

- **`createOptionGroup`** *(internal)* — Factory that constructs a single `IGroupOption` object from a type, label string, and options array.
- **`createCustomLabelOptions`** *(internal)* — Filters custom labels by a case-insensitive search query. Falls back to `NO_LABELS_OPTION` when no custom labels exist, or `EMPTY_OPTION` when the query returns no matches.
- **`createDropdownOptions`** *(exported)* — Main entry point. Accepts the full label list and a search query, then returns two grouped option sets: built-in platform labels (excluding `"All Hosts"` and filtered Linux variants) and custom labels.

## Usage Example

```typescript
import { createDropdownOptions } from "./helpers";
import { ILabel } from "interfaces/label";

const labels: ILabel[] = await fetchLabels();
const searchQuery = "mac";

const dropdownOptions = createDropdownOptions(labels, searchQuery);
// Returns:
// [
//   { type: "platform", label: "Platforms", options: [...builtInLabels] },
//   { type: "custom",   label: "Labels",    options: [...filteredCustomLabels] }
// ]
```

## Notes

- Built-in platform labels exclude `"All Hosts"` (handled by the host status dropdown) and any entries listed in `FILTERED_LINUX`.
- Custom label filtering is case-insensitive via `.toLowerCase()` comparison.
