Defines shared constant values used for label-related dropdown options and Linux distribution filtering within the Fleet MDM UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NO_LABELS_OPTION` | `object` | Disabled dropdown option shown when no custom labels exist |
| `EMPTY_OPTION` | `object` | Disabled dropdown option shown when no labels match a search |
| `FILTERED_LINUX` | `string[]` | List of Linux distro display names used for filtering purposes |

## Usage Example

```typescript
import {
  NO_LABELS_OPTION,
  EMPTY_OPTION,
  FILTERED_LINUX,
} from "./constants";

// Use in a label selector dropdown
const options = customLabels.length > 0 ? customLabels : [NO_LABELS_OPTION];

// Display fallback when search returns no results
const filteredOptions = searchResults.length > 0 ? searchResults : [EMPTY_OPTION];

// Filter out specific Linux distributions
const isFilteredDistro = FILTERED_LINUX.includes(platform.displayName);
```

## Notes

- Both `NO_LABELS_OPTION` and `EMPTY_OPTION` set `isDisabled: true`, preventing user selection — they serve as informational placeholders only.
- `FILTERED_LINUX` covers the three most common enterprise Linux variants (`Red Hat Linux`, `CentOS Linux`, `Ubuntu Linux`), typically used to group or exclude these distributions in platform-specific UI logic.
