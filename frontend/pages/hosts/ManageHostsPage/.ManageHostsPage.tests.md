Integration tests for `ManageHostsPage`, covering empty states, filtered states, populated states, and CSV export column substitution behavior.

## Key Components

| Export / Identifier | Purpose |
|---|---|
| `describe("ManageHostsPage")` | Top-level test suite for the Manage Hosts page |
| `setupHandlers()` | Registers MSW request handlers for config, labels, hosts, host count, enroll secrets, and current user |
| `createMockProps()` | Builds router/location props for `ManageHostsPage`, with optional overrides |
| `getHostsHandler()` | MSW handler for `GET /hosts` |
| `getHostsCountHandler()` | MSW handler for `GET /hosts/count` |

### Test Cases

| Test | Behavior Verified |
|---|---|
| Truly empty state | Shows "No hosts" copy, disables Export/Edit Columns/Search controls, keeps "Add hosts" visible |
| Filtered empty state (search query) | Shows "No hosts match your filters" copy, controls remain **enabled** |
| Filtered empty state (query params) | Same as above but triggered via `low_disk_space` param |
| Populated state | Shows host count, all controls **enabled** |
| CSV export column substitution | Confirms the display-only `agent` column is replaced by `orbit_version` + `osquery_version`; `selection` is also excluded |

## Usage Example

```typescript
// Run all tests
npx jest ManageHostsPage.tests.tsx

// Run a single test by name
npx jest ManageHostsPage.tests.tsx -t "renders truly empty state"
```
