Defines and exports the column configuration array for the host management table, specifying rendering logic, sorting behavior, and cell components for each host attribute column.

## Key Components

### Types
- **`IHostTableColumnConfig`** — Extends `Column<IHost>` with optional `disableHidden` and `title` fields used by `EditColumnsModal`
- **`IHostTableHeaderProps`**, **`IHostTableStringCellProps`**, **`IHostTableNumberCellProps`** — Typed wrappers for React Table cell/header prop interfaces
- **`ISelectionCellProps`**, **`IIssuesCellProps`**, **`IDeviceUserCellProps`** — Specialized cell prop types for selection, issues, and device user columns

### Helper Functions
- **`condenseDeviceUsers(users)`** — Truncates device user email lists to 3–4 entries, appending `+N more` when the list exceeds 4
- **`lastSeenTime(status, seenTime, platform?)`** — Returns a human-readable last-seen string; returns `"Not supported"` for mobile platforms

### Main Export
- **`allHostTableHeaders(teamId?)`** — Returns the full column definition array. Accepts an optional `teamId` for constructing host detail links via `PATHS.HOST_DETAILS`.

### Columns Defined
`selection`, `display_name`, `team_name`, `os_version`, `hardware_model`, `device_mapping`, `uuid`, `hardware_serial`, `detail_updated_at`, `gigs_disk_space_available`, `cpu_type`, `memory`, `primary_mac`, `status` (partial in snippet)

## Usage Example

```typescript
import { allHostTableHeaders } from "./HostTableConfig";

// Without team context
const columns = allHostTableHeaders();

// With team-scoped host detail links
const teamColumns = allHostTableHeaders(42);

// Pass to React Table
const tableInstance = useTable(
  { columns: teamColumns, data: hosts },
  useSortBy,
  useRowSelect
);
```

## Notes

- The `selection` and `display_name` columns set `disableHidden: true`, preventing them from being toggled off in `EditColumnsModal`
- Platform-specific cells (Android, iOS/iPadOS, Chrome) render `NotSupported` where a feature is unavailable
- `os_version` wraps Arch Linux rolling release versions with `TooltipWrapperArchLinuxRolling`
