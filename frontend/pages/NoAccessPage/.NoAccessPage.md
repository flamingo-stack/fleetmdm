Renders the "Access denied" page shown when an authenticated user has no global or team role assigned in Fleet.

## Key Components

- **`NoAccessPage`** – Default export. Functional React component that displays an access denied message with a contact link and a back-to-login button.
- **`INoAccessPageProps`** – Interface defining the component's props:
  - `router` – `InjectedRouter` used to navigate back to the login page.
  - `orgContactUrl` – Optional override URL for the administrator contact link; falls back to `CONTACT_FLEET_LINK`.
- **Enter key handler** – A `useEffect` hook registers a `keydown` listener so pressing `Enter` or `NumpadEnter` triggers the back-to-login navigation, then cleans up on unmount.

## Usage Example

```typescript
import NoAccessPage from "pages/NoAccessPage/NoAccessPage";

// Rendered by the router when a user has no assigned role
const RouteHandler = ({ router }) => (
  <NoAccessPage
    router={router}
    orgContactUrl="https://example.com/contact-support"
  />
);
```

## Behavior Notes

- Wraps content in `AuthenticationFormWrapper` with an `"Access denied"` header and `AuthenticationNav` as the header CTA.
- The contact link falls back to the global `CONTACT_FLEET_LINK` constant when `orgContactUrl` is not provided.
- Navigates to `PATHS.LOGIN` on both button click and `Enter` / `NumpadEnter` keypress.
