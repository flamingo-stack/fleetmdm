A registration wizard breadcrumb navigation component that renders three step indicators ("Set up user", "Organization details", "Set Fleet URL") with active and complete state styling.

## Key Components

### `IBreadcrumbs` Interface
| Prop | Type | Description |
|------|------|-------------|
| `onSetPage` | `(page: number) => void` | Callback to navigate to a specific page |
| `currentPage` | `number` | The currently active page (1–3) |
| `pageProgress` | `number` | The furthest page the user has reached; controls which steps are clickable |

### `Breadcrumbs` Component
Renders three unstyled `Button` elements as step indicators. Each button receives dynamic CSS classes based on the following states:

- **`--active`** — applied when `currentPage` matches the step number
- **`--complete`** — applied when `pageProgress` has advanced past the step
- **`tabIndex`** — steps 2 and 3 are keyboard-unreachable (`tabIndex={-1}`) until the user has progressed to that step

## Usage Example

```typescript
import Breadcrumbs from "components/Breadcrumbs";

const RegistrationWizard = () => {
  const [currentPage, setCurrentPage] = React.useState(1);
  const [pageProgress, setPageProgress] = React.useState(1);

  const handleSetPage = (page: number) => {
    if (page <= pageProgress) {
      setCurrentPage(page);
    }
  };

  return (
    <>
      <Breadcrumbs
        onSetPage={handleSetPage}
        currentPage={currentPage}
        pageProgress={pageProgress}
      />
      {/* Page content here */}
    </>
  );
};
```

## Notes

- Navigation to steps 2 and 3 is restricted until `pageProgress` reaches those steps, preventing users from skipping ahead.
