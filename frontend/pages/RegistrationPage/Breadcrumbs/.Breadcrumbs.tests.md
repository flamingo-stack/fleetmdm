Unit tests for the `Breadcrumbs` component used in the `RegistrationPage`, verifying render count and active state logic based on the `currentPage` prop.

## Key Components

- **`renders 3 Button components`** — Asserts the component always renders exactly three navigation buttons.
- **`renders page 1 Button as active when the current page prop is 1`** — Verifies that when `currentPage={1}`, only the first button receives the `registration-breadcrumbs__page--active` CSS class.

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { noop } from "lodash";
import Breadcrumbs from "pages/RegistrationPage/Breadcrumbs";

// Render with page 1 active
render(<Breadcrumbs onSetPage={noop} pageProgress={1} currentPage={1} />);

// Expect 3 step buttons
expect(screen.getAllByRole("button").length).toEqual(3);

// Verify active class is applied only to the current page button
const page1Btn = container.querySelector("button.registration-breadcrumbs__page--1");
expect(page1Btn?.className).toContain("registration-breadcrumbs__page--active");
```

## Props Under Test

| Prop | Type | Description |
|------|------|-------------|
| `onSetPage` | `function` | Callback when a breadcrumb step is clicked |
| `pageProgress` | `number` | Highest page the user has reached |
| `currentPage` | `number` | Currently active page (1–3) |

## Notes

- Tests use `@testing-library/react` for DOM queries and `noop` from lodash as a no-op callback placeholder.
- Active state is determined via the `registration-breadcrumbs__page--active` BEM modifier class.
