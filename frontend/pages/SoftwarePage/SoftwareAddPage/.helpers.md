Utility helpers for the "Add Software" feature, providing shared error message constants and formatting functions for API error responses.

## Key Components

### Constants
- **`ADD_SOFTWARE_ERROR_PREFIX`** – Base error prefix string: `"Couldn't add."`
- **`DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE`** – Generic fallback error message
- **`REQUEST_TIMEOUT_ERROR_MESSAGE`** – Timeout-specific error message with server/load balancer guidance

### Functions

- **`ensurePeriod(str)`** – Normalizes a string to end with a period. No-ops on empty strings or strings already ending with `.`
- **`formatAlreadyAvailableInstallMessage(msg)`** – Parses raw API error messages to produce a formatted React element highlighting the conflicting package and fleet names. Handles two message patterns:
  - `"<package> already has an installer available for the <fleet> fleet."`
  - `"SoftwareInstaller|In-house app "<package>" already exists with fleet "<fleet>"."`
  
  Returns `null` if neither pattern matches.

## Usage Example

```typescript
import {
  DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE,
  REQUEST_TIMEOUT_ERROR_MESSAGE,
  ensurePeriod,
  formatAlreadyAvailableInstallMessage,
} from "./helpers";

// Normalize error text
ensurePeriod("Something went wrong"); // → "Something went wrong."
ensurePeriod("Already handled.");     // → "Already handled."

// Format a known API conflict message into a React element
const element = formatAlreadyAvailableInstallMessage(
  "Couldn't add software. osquery already has an installer available for the Workstations fleet."
);
// Renders: "Couldn't add. <b>osquery</b> already has an installer available for the <b>Workstations</b> fleet."

// Use fallback for unknown errors
const fallback = formatAlreadyAvailableInstallMessage("Unknown error");
// → null (caller should fall back to DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE)
```
