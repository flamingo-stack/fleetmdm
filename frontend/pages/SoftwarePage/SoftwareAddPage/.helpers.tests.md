Unit tests for the `helpers` module, validating the `ensurePeriod` and `formatAlreadyAvailableInstallMessage` utility functions used in software installation error handling.

## Key Components

### `ensurePeriod` Tests
Validates string punctuation normalization:
- Appends a period to strings lacking one
- Preserves strings already ending with a period
- Handles edge cases: empty strings, single-period strings

### `formatAlreadyAvailableInstallMessage` Tests
Validates React fragment generation for duplicate software installer errors:
- Parses messages matching the `ADD_SOFTWARE_ERROR_PREFIX` pattern (e.g., *"Couldn't add. MyApp already has an installer available for the Marketing fleet."*)
- Parses the alternate `SoftwareInstaller "X" already exists with fleet "Y"` format
- Returns `null` for non-matching or empty input strings
- Verifies correct app name and fleet name extraction across different inputs

## Usage Example

```typescript
import {
  ensurePeriod,
  formatAlreadyAvailableInstallMessage,
  ADD_SOFTWARE_ERROR_PREFIX,
} from "./helpers";

// Ensure a message ends with a period
ensurePeriod("Something went wrong"); // → "Something went wrong."

// Format a known duplicate installer error into a React fragment
const msg = `${ADD_SOFTWARE_ERROR_PREFIX} MyApp already has an installer available for the Marketing fleet.`;
const node = formatAlreadyAvailableInstallMessage(msg);
// Returns a React fragment with structured error text, or null if unrecognized
```

## Notes

- Tests use `@testing-library/react`'s `render` to assert on rendered `textContent`, ensuring React fragments produce correct visible output.
- `formatAlreadyAvailableInstallMessage` supports two distinct error message patterns via regex matching.
