Renders the Fleet Maintained Apps tab within the Software Add page, fetching and displaying a paginated, filterable list of Fleet-maintained applications for a given team.

## Key Components

- **`SoftwareFleetMaintained`** — Default export. React component that orchestrates data fetching and conditional rendering for the fleet-maintained apps view.
- **`IQueryKey`** — Interface extending `ISoftwareFleetMaintainedAppsQueryParams` with a `scope` discriminator for React Query cache keys.
- **`ISoftwareFleetMaintainedProps`** — Props interface requiring `currentTeamId`, `router`, and `location`.
- **`FleetMaintainedAppsTable`** — Child component receiving fetched data and pagination/filter state.
- **Platform mapping** — Translates UI platform values (`"macos"` → `"darwin"`) before passing to the API.

## Key Behaviors

| Concern | Detail |
|---|---|
| Premium gate | Renders `PremiumFeatureMessage` for non-premium tiers |
| Pagination | Server-side, 100 apps per page; macOS + Windows entries merged per row |
| Stale time | 30 seconds (`DATA_STALE_TIME`) with `keepPreviousData: true` |
| Platform filter | Maps `"macos"` → `"darwin"`, `"windows"` → `"windows"` for the API |
| Status filter | Maps `status === "available"` to `available: true` query param |

## Usage Example

```typescript
import SoftwareFleetMaintained from "./SoftwareFleetMaintained";

<SoftwareFleetMaintained
  currentTeamId={3}
  router={router}
  location={location} // location.query may include: page, query, order_key,
                      // order_direction, platform, status
/>
```
