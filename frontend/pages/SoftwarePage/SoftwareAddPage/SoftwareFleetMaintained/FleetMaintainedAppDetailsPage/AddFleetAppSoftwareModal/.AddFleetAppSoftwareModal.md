A loading modal component displayed while a Fleet app software upload is in progress, preventing user dismissal during the operation.

## Key Components

- **`AddFleetAppSoftwareModal`** — Default export. A non-dismissible modal that renders a spinner and status message while software is being uploaded to Fleet.

## Usage Example

```typescript
import AddFleetAppSoftwareModal from "./AddFleetAppSoftwareModal";

const MyComponent = () => {
  const [isUploading, setIsUploading] = useState(false);

  return (
    <>
      {isUploading && <AddFleetAppSoftwareModal />}
    </>
  );
};
```

## Notes

- The modal is **non-closable** (`disableClosingModal` + `onExit={noop}`), ensuring the upload process cannot be interrupted by the user.
- Uses a `Spinner` component to indicate background activity.
- Styled under the BEM base class `add-fleet-app-software-modal`.
