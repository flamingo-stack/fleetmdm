Renders unit tests for the `FleetAppDetailsModal` component, verifying modal title, app detail field rendering, and conditional display of optional URL and slug fields.

## Key Components

- **`renders modal with correct title`** – Asserts the modal header displays "Software details"
- **`displays correct app details`** – Verifies all detail fields (Name, Platform, Version, slug, URL) render with correct values; uses `getAllByText` for URL due to tooltip duplicate rendering
- **`does not render URL or slug field when respective props are not provided`** – Confirms URL and slug fields are omitted when props are `undefined`

## Usage Example

```typescript
// Default props used across test cases
const defaultProps = {
  name: "Test App",
  platform: "darwin",   // Rendered as "macOS" in the modal
  version: "1.0.0",
  url: "https://example.com/app",
  slug: "test-app/darwin",
  onCancel: noop,
};

// Rendering with createCustomRenderer
const render = createCustomRenderer();
render(<FleetAppDetailsModal {...defaultProps} />);

// Optional fields: omit url/slug to hide those rows
render(<FleetAppDetailsModal {...defaultProps} url={undefined} slug={undefined} />);
```

> **Note:** The URL assertion uses `getAllByText(...).length > 0` rather than `toBeInTheDocument()` because the tooltip component duplicates the URL text in the DOM.
