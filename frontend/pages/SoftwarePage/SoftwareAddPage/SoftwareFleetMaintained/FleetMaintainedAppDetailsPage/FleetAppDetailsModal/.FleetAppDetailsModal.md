Modal component that displays detailed metadata for a Fleet-maintained app, including name, version, platform, slug (with clipboard copy), and download URL.

## Key Components

### `FleetAppDetailsModal`
Default export. A modal dialog rendering software package details with the following props:

| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | App display name |
| `platform` | `string` | Platform key mapped via `PLATFORM_DISPLAY_NAMES` |
| `version` | `string` | Version string; `"latest"` renders a tooltip variant |
| `slug` | `string?` | GitOps slug with one-click copy-to-clipboard |
| `url` | `string?` | Download URL displayed with truncation tooltip |
| `onCancel` | `() => void` | Close/dismiss handler |

### Notable Behaviors
- **Slug copy**: Calls `stringToClipboard`, shows `"Copied!"` / `"Copy failed"` feedback, auto-clears after 1 second
- **Version tooltip**: When `version === "latest"`, wraps the label in a `TooltipWrapper` prompting the user to preview via the URL
- **Conditional fields**: `slug` and `url` sections render only when those props are provided

## Usage Example

```typescript
import FleetAppDetailsModal from "./FleetAppDetailsModal";

<FleetAppDetailsModal
  name="Slack"
  platform="darwin"
  version="latest"
  slug="slack"
  url="https://example.com/slack.pkg"
  onCancel={() => setShowModal(false)}
/>
```
