Provides form validation logic for the Fleet Maintained App details form, defining validation rules and generating validation state objects for pre-install query and custom label target fields.

## Key Components

- **`FORM_VALIDATION_CONFIG`** — Static configuration mapping each form field to its validation rules:
  - `preInstallQuery`: Validates optional SQL query using `validateQuery`; empty strings pass validation
  - `customTarget`: Requires at least one label target selected when target type is not `"All hosts"`

- **`getErrorMessage`** — Resolves a validation message that is either a static string or a dynamic function evaluated against current form data

- **`generateFormValidation`** — Main export; iterates over all configured field validations, returns an `IFormValidation` object with per-field validity state and error messages

## Usage Example

```typescript
import { generateFormValidation } from "./helpers";

const formData: IFleetMaintainedAppFormData = {
  preInstallQuery: "SELECT 1 FROM osquery_info WHERE build_platform = 'darwin';",
  targetType: "Custom",
  labelTargets: { macOS: true, Windows: false },
};

const validation = generateFormValidation(formData);

if (!validation.isValid) {
  console.log(validation.preInstallQuery?.message); // e.g. "Invalid query"
  console.log(validation.customTarget?.message);
}
```
