Form component for adding Fleet-maintained app software with deployment configuration options and submit validation.

## Key Components

### Exports

- **`FleetAppDetailsForm`** *(default)* — Form component that renders a software deployment slider and action buttons (Add software / Cancel) for Fleet-maintained app installation
- **`softwareAlreadyAddedTipContent`** — Helper that generates tooltip JSX content with a link to existing software when a duplicate is detected
- **`IFleetMaintainedAppFormData`** — Interface defining the full form state including install scripts, target configuration, self-service, and categories
- **`IFormValidation`** — Interface for form validation state, covering `preInstallQuery` and `customTarget` validity

### Internal Behavior

- Initializes form state from `defaultInstallScript`, `defaultPostInstallScript`, and `defaultUninstallScript` props
- Submit is disabled when `softwareTitleId` is present (software already added) or when GitOps mode disables children
- Automatic install is toggled via `SoftwareDeploySlider`

## Usage Example

```typescript
import FleetAppDetailsForm, {
  IFleetMaintainedAppFormData,
} from "./FleetAppDetailsForm";

<FleetAppDetailsForm
  defaultInstallScript="sudo installer -pkg $INSTALLER_PATH -target /"
  defaultPostInstallScript=""
  defaultUninstallScript="sudo rm -rf /Applications/MyApp.app"
  teamId="42"
  softwareTitleId={undefined} // undefined = not yet added
  categories={[{ id: 1, name: "Productivity" }]}
  onCancel={() => console.log("cancelled")}
  onSubmit={(data: IFleetMaintainedAppFormData) => console.log(data)}
/>
```
