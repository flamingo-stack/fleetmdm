Defines two filter components for the Fleet Managed Apps (FMA) interface: a platform dropdown filter and a status toggle filter.

## Key Components

### Exports

| Export | Type | Description |
|--------|------|-------------|
| `FmaPlatformValue` | Type | Union: `"all" \| "macos" \| "windows"` |
| `FmaStatusValue` | Type | Union: `"all" \| "available"` |
| `FmaPlatformFilter` | Component | Dropdown to filter apps by platform |
| `FmaStatusFilter` | Component | Slider toggle to filter by availability status |

### `FmaPlatformFilter`

Renders a `DropdownWrapper` with three options — All platforms, macOS, Windows — using the `table-filter` variant and a filter icon.

### `FmaStatusFilter`

Renders a `Slider` toggle that switches between `"all"` and `"available"`, labelled **Hide added apps** in both states.

## Usage Example

```typescript
import {
  FmaPlatformFilter,
  FmaStatusFilter,
  FmaPlatformValue,
  FmaStatusValue,
} from "components/FmaFilters";

const [platform, setPlatform] = useState<FmaPlatformValue>("all");
const [status, setStatus]     = useState<FmaStatusValue>("all");

<FmaPlatformFilter
  value={platform}
  onChange={setPlatform}
  className="my-platform-filter"
/>

<FmaStatusFilter
  value={status}
  onChange={setStatus}
  className="my-status-filter"
/>
```

## Notes

- Platform options are memoized via `useMemo` to prevent unnecessary re-renders.
- `FmaStatusFilter` derives its enabled state from `value === "available"` and toggles between the two `FmaStatusValue` states on each click.
- Both components accept an optional `className` prop for layout customization.
