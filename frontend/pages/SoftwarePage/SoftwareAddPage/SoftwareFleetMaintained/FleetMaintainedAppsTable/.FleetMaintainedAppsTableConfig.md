Defines the table column configuration for the Fleet Maintained Apps table, mapping software name and platform-specific installer actions to their respective columns.

## Key Components

### `generateTableConfig(router, teamId)`
Returns an array of `react-table` column definitions for the Fleet Maintained Apps table.

**Parameters:**
- `router: InjectedRouter` — Router instance passed to action cells for navigation
- `teamId: number` — Team context passed to installer action cells

**Columns:**
| Column | Accessor | Sortable | Cell Component |
|--------|----------|----------|----------------|
| Name | `name` | ✅ (case-insensitive) | `SoftwareNameCell` |
| macOS | `macos` | ❌ | `InstallerActionCell` |
| Windows | `windows` | ❌ | `InstallerActionCell` |

### Type Aliases
- `IFleetMaintainedAppsTableConfig` — Column type scoped to `ICombinedFMA`
- `ITableStringCellProps` — String cell props scoped to `ICombinedFMA`
- `ITableHeaderProps` — Header props scoped to `ICombinedFMA`

## Usage Example

```typescript
import { generateTableConfig } from "./FleetMaintainedAppsTableConfig";

const columns = generateTableConfig(router, teamId);

// Pass to TableContainer
<TableContainer
  columns={columns}
  data={fleetMaintainedApps}
/>
```
