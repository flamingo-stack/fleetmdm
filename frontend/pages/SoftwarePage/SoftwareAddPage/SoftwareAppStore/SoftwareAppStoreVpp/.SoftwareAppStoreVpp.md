React component that manages the VPP (Volume Purchasing Program) App Store software addition flow, handling VPP token validation, app listing, and software installation for a given team.

## Key Components

### Exported Component
- **`SoftwareAppStoreVpp`** — Main component orchestrating the VPP app store UI, data fetching, and form submission

### Internal UI Components
- **`EnableVppMessage`** — Shown when no VPP token exists; prompts global admins to enable VPP
- **`AddTeamToVppMessage`** — Shown when a VPP token exists but the current team isn't associated with it
- **`NoVppAppsMessage`** — Shown when the team has VPP access but no available apps to add

### Key Behaviors
- Fetches VPP token status, available VPP apps, and custom labels in parallel via `react-query`
- Guards behind `isPremiumTier` — non-premium users see a `PremiumFeatureMessage`
- On successful app submission, invalidates relevant query caches and navigates to the new software title's detail page
- Supports an optional end-user experience preview modal (`CategoriesEndUserExperienceModal`) triggered from the form

## Usage Example

```typescript
import SoftwareAppStoreVpp from "./SoftwareAppStoreVpp";

// Rendered within a route that provides currentTeamId and router
<SoftwareAppStoreVpp
  currentTeamId={42}
  router={router}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `currentTeamId` | `number` | ID of the team to scope VPP data and app installation |
| `router` | `InjectedRouter` | React Router instance used for programmatic navigation |
