Utility helpers for the VPP (Volume Purchase Program) software addition flow, providing token availability checks and user-facing error message formatting.

## Key Components

### `teamHasVPPToken`
Checks whether a given team has access to a VPP token — either one explicitly assigned to the team or one available to "All teams" (indicated by an empty `teams` array).

### `getErrorMessage`
Parses an unknown error and returns a formatted string or `ReactElement` for display. Handles three cases:
- Software already available for install (generic)
- VPP app already available in the fleet
- Any other API error reason, falling back to a default message

## Usage Example

```typescript
import { teamHasVPPToken, getErrorMessage } from "./helpers";

// Check if current team can use VPP
const canInstallVPP = teamHasVPPToken(42, vppTokens);

// Format an error from a failed add-software API call
try {
  await addVPPSoftware(payload);
} catch (e) {
  const message = getErrorMessage(e);
  // message is ready to render — may be a string or ReactElement
  renderErrorBanner(message);
}
```

## Notes

- A VPP token with `teams.length === 0` is treated as available to **all teams**.
- Error messages are prefixed with `ADD_SOFTWARE_ERROR_PREFIX` (defined in the parent `helpers` module) for consistent UI copy.
- `getErrorMessage` returns either a plain `string` or a `ReactElement`, so consumers should support both render paths.
