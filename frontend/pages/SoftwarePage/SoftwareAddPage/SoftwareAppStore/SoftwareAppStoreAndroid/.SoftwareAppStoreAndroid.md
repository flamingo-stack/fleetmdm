React component for adding Android apps from the app store to a team's software library in Fleet MDM.

## Key Components

### Components
- **`SoftwareAppStoreAndroid`** — Main component that handles the full flow of adding an Android app store app to a team
- **`EnableAndroidMdmMessage`** — Internal helper component rendering an empty state prompt when Android MDM is not yet configured

### Key Behaviors
- **Premium gate** — Renders `PremiumFeatureMessage` if the instance is not on a premium tier
- **MDM gate** — Renders `EnableAndroidMdmMessage` if Android MDM is not enabled/configured; global admins see an "Enable Android MDM" CTA, other users see a contact-admin message
- **`onAddSoftware`** — Calls `softwareAPI.addAppStoreApp`, flashes success/error, and navigates to the new software title's detail page on success
- **`onEnableAndroidMdm`** — Navigates to `PATHS.ADMIN_INTEGRATIONS_MDM_ANDROID`
- **`goBackToSoftwareLibrary`** — Navigates back to the software library with `fleet_id` query param

## Props

| Prop | Type | Description |
|------|------|-------------|
| `currentTeamId` | `number` | Active team ID, used for API calls and URL params |
| `router` | `InjectedRouter` | React Router instance for imperative navigation |

## Usage Example

```typescript
import SoftwareAppStoreAndroid from "./SoftwareAppStoreAndroid";

<SoftwareAppStoreAndroid
  currentTeamId={42}
  router={router}
/>
```
