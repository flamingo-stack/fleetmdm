Utility module for formatting error messages when adding software (e.g., Play Store apps, VPP apps) to a fleet, normalizing various API error responses into user-friendly strings or React elements.

## Key Components

### `getErrorMessage(e: unknown): string | ReactElement`
Parses an unknown error and returns a human-readable message with contextual handling for:
- **Play Store ID errors** — returns the raw reason directly
- **"Already available" errors** — delegates to `formatAlreadyAvailableInstallMessage`; falls back to a VPP-specific message if the software is a `VPPApp`
- **Generic errors** — prefixes the reason with `ADD_SOFTWARE_ERROR_PREFIX` and ensures it ends with a period
- **Unknown/empty errors** — returns `DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE`

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await addSoftware(payload);
} catch (e) {
  const message = getErrorMessage(e);
  // message is a string or ReactElement ready to display in the UI
  showErrorToast(message);
}
```

## Dependencies

| Import | Purpose |
|--------|---------|
| `getErrorReason` | Extracts a string reason from an unknown error |
| `ADD_SOFTWARE_ERROR_PREFIX` | Standard error prefix for add-software failures |
| `DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE` | Fallback message when no reason is available |
| `ensurePeriod` | Ensures the error string ends with a `.` |
| `formatAlreadyAvailableInstallMessage` | Formats messages for duplicate software installs |
