Utility helpers for the VPP (Volume Purchase Program) software addition flow, providing token availability checks and error message formatting for MDM VPP operations.

## Key Components

### `teamHasVPPToken`
Checks whether a given team has an available VPP token — either one explicitly assigned to the team or one configured for "All teams" (indicated by an empty `teams` array).

### `getErrorMessage`
Formats API/error responses into user-facing strings or React elements for the "Add Software" flow. Handles three cases:
- **Already available** — delegates to `formatAlreadyAvailableInstallMessage` or returns a VPP-specific duplicate message
- **Known reason** — prefixes the reason with `ADD_SOFTWARE_ERROR_PREFIX`
- **Unknown error** — falls back to `DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE`

## Usage Example

```typescript
import { teamHasVPPToken, getErrorMessage } from "./helpers";

// Check VPP token availability for a team
const canInstallVPP = teamHasVPPToken(42, vppTokens);
if (!canInstallVPP) {
  console.warn("No VPP token available for this team.");
}

// Format an error from a failed "Add Software" request
try {
  await addVPPSoftware(payload);
} catch (e) {
  const message = getErrorMessage(e);
  // message is a string or ReactElement ready for display
  setErrorBanner(message);
}
```
