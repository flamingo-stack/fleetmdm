Renders the software app store UI for adding applications to a Fleet team, providing a platform selector that conditionally displays either the Apple VPP or Android app store content.

## Key Components

- **`SoftwareAppStore`** – Default export. Top-level component that orchestrates platform selection and delegates rendering to the appropriate store sub-component.
- **`ISoftwareAppStoreProps`** – Interface defining required props: `currentTeamId`, `router`, and `location` (with `fleet_id` and `platform` query params).
- **`platformOptions`** – Static dropdown options for `"apple"` (macOS, iOS, iPadOS) and `"android"`.
- **`renderDropdown`** – Renders a `DropdownWrapper` for switching between platforms.
- **`renderContent`** – Conditionally renders `SoftwareAppStoreVpp` (Apple) or `SoftwareAppStoreAndroid` based on the current platform.
- **`onDestinationChange`** – Handles platform selection by pushing a new route with updated `fleet_id` and `platform` query params.

## Usage Example

```typescript
import SoftwareAppStore from "./SoftwareAppStore";

<SoftwareAppStore
  currentTeamId={42}
  router={router}
  location={{
    pathname: "/software/add/app-store",
    query: {
      fleet_id: "42",
      platform: "android",
    },
  }}
/>
```

## Notes

- Defaults to `"apple"` if no `platform` query param is present.
- Platform changes update the URL via `router.push`, keeping state in the query string for shareability and browser history support.
- Sub-components (`SoftwareAppStoreVpp`, `SoftwareAppStoreAndroid`) receive only `currentTeamId` and `router` — platform routing is fully handled at this level.
