Renders the page for adding a custom software package to a Fleet team, handling file upload progress, label fetching, GitOps mode awareness, and end-user experience preview.

## Key Components

### Component: `SoftwareCustomPackage`

**Props (`ISoftwarePackageProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `currentTeamId` | `number` | Active Fleet team ID |
| `router` | `InjectedRouter` | Router instance for navigation |
| `isSidePanelOpen` | `boolean` | Whether the schema side panel is open |
| `setSidePanelOpen` | `(isOpen: boolean) => void` | Toggles the side panel |

**Internal state:**
- `uploadProgress` — numeric 0–1 progress value passed to `FileProgressModal`
- `uploadDetails` — file metadata shown during upload; also gates the `beforeunload` warning
- `showPreviewEndUserExperience` — toggles `CategoriesEndUserExperienceModal`
- `isIpadOrIphoneSoftwareSource` — passed to the preview modal to adjust iOS-specific copy

**Key behaviors:**
- **Premium gate** — renders `PremiumFeatureMessage` when `isPremiumTier` is `false`
- **Label fetching** — queries `labelsAPI.summary` filtered to custom labels; shows `Spinner` or `DataError` during load/error states
- **Upload guard** — attaches a `beforeunload` listener while a file upload is in progress to prevent accidental navigation
- **GitOps banner** — displays an `InfoBanner` with SHA-256 hash instructions when GitOps mode is active
- **Post-submit navigation** — redirects to the new software title's detail page with optional `gitops_yaml` query param

## Usage Example

```typescript
<SoftwareCustomPackage
  currentTeamId={42}
  router={router}
  isSidePanelOpen={false}
  setSidePanelOpen={(isOpen) => setIsSidePanelOpen(isOpen)}
/>
```
