Provides the `getErrorMessage` helper for the Add Software flow, mapping API error responses to user-facing messages with optional inline links.

## Key Components

### `getErrorMessage(err: unknown): string | JSX.Element`
Processes an unknown error and returns an appropriate message string or React element based on the error type:

| Condition | Output |
|---|---|
| HTTP 504/408 timeout | `REQUEST_TIMEOUT_ERROR_MESSAGE` |
| Reason includes `"already"` | Formatted "already available" install message |
| Reason includes `"Secret variable"` | Secret variable error message via `generateSecretErrMsg` |
| Reason includes `"Unable to extract necessary metadata"` | Inline JSX with a "Learn more" link |
| Reason includes `"not a valid .tar.gz archive"` | Inline JSX with a "Learn more" link |
| Reason starts with `"Couldn't add."` | Reason string with ensured trailing period |
| Any other reason | `ADD_SOFTWARE_ERROR_PREFIX` + reason |
| No reason | `DEFAULT_ADD_SOFTWARE_ERROR_MESSAGE` |

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await addSoftware(payload);
} catch (err) {
  const message = getErrorMessage(err);
  // message may be a string or a JSX element with a CustomLink
  showFlashMessage(message);
}
```

## Notes

- Returns JSX elements (with `<CustomLink />`) for metadata extraction and `.tar.gz` errors, so consumers must support rendering React nodes.
- Delegates secret variable errors to `generateSecretErrMsg` from the `SoftwarePage` helpers.
