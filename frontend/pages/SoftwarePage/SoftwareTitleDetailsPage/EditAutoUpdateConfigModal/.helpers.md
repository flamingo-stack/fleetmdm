Validation helpers for the Software Auto Update Config modal form, providing type definitions, validation rules, and a form data validator.

## Key Components

### Interfaces
- **`ISoftwareAutoUpdateConfigInputValidation`** — Per-field validation result (`isValid`, optional `message`)
- **`ISoftwareAutoUpdateConfigFormValidation`** — Aggregate form validation state covering `autoUpdateStartTime`, `autoUpdateEndTime`, `targets`, and `windowLength`

### Internal Helpers
- **`validateTimeFormat(time)`** — Checks that a string matches `HH:MM` (24-hour) and contains valid hour/minute values
- **`validateWindowLength(formData, validations)`** — Ensures the update window is at least 60 minutes; skips if either time field is empty or already invalid

### Constants
- **`FORM_VALIDATIONS`** — Rule registry mapping each form field to an ordered list of named validations (`required`, `valid`, `minimum_length`, `custom_labels_selected`)

### Exports
- **`validateFormData(formData, isSaving?)`** — Runs all applicable rules against `formData` and returns an `ISoftwareAutoUpdateConfigFormValidation` object. Skips `required` checks when `isSaving` is `false`; skips all time/window validations when `autoUpdateEnabled` is `false`

## Usage Example

```typescript
import { validateFormData } from "./helpers";

const formData = {
  autoUpdateEnabled: true,
  autoUpdateStartTime: "02:00",
  autoUpdateEndTime: "03:30",
  targetType: "Custom",
  labelTargets: { "label-1": true },
};

// Validate on field change (skips required checks)
const liveValidation = validateFormData(formData);

// Validate on save (enforces required checks)
const saveValidation = validateFormData(formData, true);

if (!saveValidation.isValid) {
  console.error(saveValidation.autoUpdateStartTime?.message);
}
```
