Page component for the `software/titles/:id` route that displays detailed information about a specific software title, including its summary and installer configuration.

## Key Components

- **`SoftwareTitleDetailsPage`** — Main page component that fetches and renders software title details
- **`SoftwareSummaryCard`** — Displays general software metadata and version info
- **`SoftwareInstallerCard`** — Displays installer/package configuration; rendered only when a software package or App Store app is available and the user has appropriate team permissions
- **`TeamsHeader`** — Team switcher shown for premium tier users (excluding Primo partnership config)
- **`DetailsNoHosts`** — Fallback UI shown on fetch errors

## Key Behaviors

- Fetches software title via `softwareAPI.getSoftwareTitle` using the `id` route param
- Suppresses error boundary for 403/404 responses, surfacing a friendly "not detected" message instead
- On installer deletion, invalidates `software-titles` and `software-library` query caches; redirects to the software library if no versions remain
- Supports GitOps mode: automatically opens the "View YAML" modal when `?gitops_yaml=true` is present in the URL
- The installer card is hidden when viewing "All Teams" (`APP_CONTEXT_ALL_TEAMS_ID`) or when no package/App Store app is attached

## Usage Example

```typescript
// Rendered automatically by the router at /software/titles/:id
// Route params and location are injected by react-router

import SoftwareTitleDetailsPage from "pages/SoftwareTitleDetailsPage/SoftwareTitleDetailsPage";

// In router config:
<Route
  path={paths.SOFTWARE_TITLE_DETAILS}
  component={SoftwareTitleDetailsPage}
/>

// Deep-link to open GitOps YAML modal on load:
// /software/titles/42?gitops_yaml=true
```
