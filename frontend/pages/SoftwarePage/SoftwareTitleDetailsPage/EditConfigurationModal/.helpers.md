Utility helpers for the managed configuration editor, providing error message generation, input validation, and platform display logic.

## Key Components

### Exported Functions

- **`getErrorMessage(err, isApplePlatform)`** — Parses API errors into user-friendly messages, handling Android-specific key restrictions, unsupported `$FLEET_VAR_` variables, and missing `$FLEET_SECRET_` secrets.
- **`isErrorWithMessage(error)`** — Type guard that narrows an unknown error to `ErrorWithMessage` (has a `.message` string property).
- **`validateJson(value)`** — Validates a JSON string; returns an error message string or `null` if valid.
- **`validateXml(value)`** — Validates an XML plist string, accepting `<dict>` or `<plist><dict>` structures; returns an error message string or `null` if valid.
- **`getPlatformLabel(platform)`** — Maps platform identifiers (`"ios"`, `"ipados"`, `"android"`) to display labels.

### Internal Helpers

- **`isProfileOnlyVariable(varNameWithoutPrefix)`** — Checks if a `$FLEET_VAR_` variable is valid in configuration profiles but unsupported in managed configuration (e.g., SCEP, DigiCert, Smallstep variables).
- **`generateUnsupportedVariableErrMsg(errMsg)`** — Produces a targeted error for unsupported `$FLEET_VAR_` variables.
- **`generateMissingSecretErrMsg(errMsg)`** — Produces a targeted error listing one or more missing `$FLEET_SECRET_` variables.

## Usage Example

```typescript
import {
  getErrorMessage,
  validateJson,
  validateXml,
  getPlatformLabel,
} from "./helpers";

// Error message from an API response
const msg = getErrorMessage(apiError, /* isApplePlatform */ true);

// Validate JSON input before submission
const jsonError = validateJson('{ "key": "value" }'); // null = valid

// Validate XML plist input
const xmlError = validateXml("<dict><key>Foo</key><string>Bar</string></dict>");

// Display label for a platform identifier
const label = getPlatformLabel("ipados"); // "iPadOS"
```
