A React modal component that prompts users to confirm adding a patch policy for a specific software title on a team, then calls the Fleet API to create it.

## Key Components

- **`AddPatchPolicyModal`** — Default export; a confirmation modal wrapping the `teamPoliciesAPI.create` call with `type: "patch"`.
- **`IAddPatchPolicyModal`** — Props interface defining `softwareId`, `teamId`, `onExit`, and `onSuccess` callbacks.
- **`onAddPatchPolicy`** — Memoized async handler that submits the policy creation request, flashes success/error notifications, and invokes the appropriate callback.
- **`GitOpsModeTooltipWrapper`** — Wraps the confirm button to disable it when GitOps mode is active.

## Usage Example

```typescript
import AddPatchPolicyModal from "components/AddPatchPolicyModal";

<AddPatchPolicyModal
  softwareId={42}
  teamId={7}
  onExit={() => setShowModal(false)}
  onSuccess={() => refetchPolicies()}
/>
```

## Error Handling

| Scenario | Flash Message |
|---|---|
| Policy already exists for this software | `"Couldn't add patch policy. Specified 'patch_software_title_id' already has a policy with 'type' set to 'patch'."` |
| Any other API error | `"Couldn't add patch policy. Please try again."` |

## Notes

- The created policy is **read-only** by default; enforcement must be configured separately from the policy's own page.
- The **Add** button shows a loading spinner during submission and is disabled when GitOps mode is enabled.
