Provides a utility for extracting and normalizing installer card display data from a software title, supporting both software packages and App Store apps.

## Key Components

### `InstallerCardInfo` (interface)
Normalized shape for rendering an installer card in the UI, containing:
- `softwareTitleName` / `softwareDisplayName` — raw and display-formatted title names
- `softwareInstaller` — the underlying `ISoftwarePackage` or `IAppStoreApp` object
- `name`, `version`, `source`, `iconUrl` — display metadata
- `addedTimestamp` — upload/creation time, resolved per installer type
- `status` — aggregated `installed`, `pending`, and `failed` counts
- `isSelfService`, `isScriptPackage` — behavioral flags
- `autoUpdateEnabled`, `autoUpdateStartTime`, `autoUpdateEndTime` — auto-update configuration

### `getInstallerCardInfo(softwareTitle)`
Maps an `ISoftwareTitleDetails` object to an `InstallerCardInfo`, handling the branching logic between package-based and App Store installers.

## Usage Example

```typescript
import { getInstallerCardInfo } from "./helpers";

const cardInfo = getInstallerCardInfo(softwareTitle);

console.log(cardInfo.softwareDisplayName); // e.g. "Slack"
console.log(cardInfo.status);              // { installed: 10, pending: 2, failed: 1 }
console.log(cardInfo.isScriptPackage);     // true | false
console.log(cardInfo.autoUpdateEnabled);   // true | false
```

Key normalization details:
- `version` resolves to `installerData.version` for packages or `installerData.latest_version` for App Store apps, falling back to `null`
- `addedTimestamp` uses `uploaded_at` for packages and `created_at` for App Store apps
- `status` is passed through `aggregateInstallStatusCounts()` for packages; used directly for App Store apps
