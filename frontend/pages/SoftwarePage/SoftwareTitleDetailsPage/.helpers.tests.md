Unit tests for the `getInstallerCardInfo` helper function used in the `SoftwareTitleDetailsPage`, verifying correct card info extraction for both software packages and App Store apps.

## Key Components

### Test Suite: `getPackageCardInfo`

- **Software package test** — Validates that `getInstallerCardInfo` returns the correct card info when a `software_package` is present and no `display_name` is set. Confirms package-specific behavior such as using the package filename (`TestPackage.pkg`) as the display name, aggregating pending counts (`pending_install + pending_uninstall = 8`), and aggregating failed counts (`failed_install + failed_uninstall = 3`).
- **App Store app test** — Validates that `getInstallerCardInfo` returns the correct card info when an `app_store_app` is present with a custom `display_name`. Confirms app-specific behavior such as using the software title name (`Test Software`) as `name` and passing through pre-aggregated `status` counts directly.

## Usage Example

```typescript
import { getInstallerCardInfo } from "./helpers";

const cardInfo = getInstallerCardInfo(softwareTitle);
// Returns:
// {
//   softwareInstaller: softwareTitle.software_package | softwareTitle.app_store_app,
//   name: string,            // package filename OR software title name
//   softwareDisplayName: string,
//   displayName: string | undefined,
//   iconUrl: string,
//   version: string,
//   addedTimestamp: string,
//   softwareTitleName: string,
//   source: string,
//   status: { installed, pending, failed },
//   isScriptPackage: boolean,
//   isSelfService: boolean,
// }
```

## Key Behaviors Verified

| Scenario | `name` field | `status.pending` source |
|---|---|---|
| Software package | Package filename | `pending_install + pending_uninstall` |
| App Store app | Software title name | Passed through directly |
