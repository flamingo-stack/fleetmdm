Test suite for the `SoftwareSummaryCard` component, verifying correct rendering of software metadata and conditional display of action dropdown options based on software type and platform.

## Key Components

- **`SoftwareSummaryCard`** — The component under test, rendered with mocked software title data and router
- **`mockSoftwareIcon`** — Jest mock for the `SoftwareIcon` component to intercept icon URL calls without triggering real API requests
- **`getDropdownOptions`** — Shared helper that opens the "Actions" dropdown and returns all visible option labels
- **`createCustomRenderer`** — Sets up a renderer with Premium tier and Global Admin context for permission-gated tests

## Test Coverage

| Scenario | Expected Dropdown Options |
|---|---|
| Standard macOS package | Edit appearance, Edit software |
| iOS/iPadOS App Store app | Edit appearance, Edit software, Edit configuration, Schedule auto updates |
| Android App Store app | Edit appearance, Edit configuration |
| Android web app | Edit appearance only |
| iOS/iPadOS in-house `.ipa` | Edit appearance, Edit software, Edit configuration |
| macOS in-house `.pkg` | Edit appearance, Edit software |
| macOS VPP app | Edit appearance, Edit software |

```typescript
// Extend with a new platform scenario using the shared helper:
it("displays correct options for my new platform", async () => {
  const { user } = render(
    <SoftwareSummaryCard
      softwareTitle={createMockSoftwareTitle({ source: "my_platform" })}
      softwareId={1}
      teamId={1}
      router={router}
      refetchSoftwareTitle={jest.fn()}
      onToggleViewYaml={jest.fn()}
    />
  );
  const options = await getDropdownOptions(user);
  expect(options).toContain("Edit appearance");
});
```
