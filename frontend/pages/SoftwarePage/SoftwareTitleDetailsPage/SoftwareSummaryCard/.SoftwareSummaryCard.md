The top-level summary card for the `software/titles/:id` detail page, rendering software metadata, a versions table, and conditionally gating edit/configuration modals based on installer type and user permissions.

## Key Components

- **`SoftwareSummaryCard`** — Default export. Composes `SoftwareDetailsSummary` and `TitleVersionsTable` inside a `Card`, then conditionally mounts five action modals.
- **`useSoftwareInstaller`** — Hook that derives installer metadata (`installerType`, `isIosOrIpadosApp`, `isFleetMaintainedApp`, `canManageSoftware`, etc.) from the software title. When it returns `null`, the component renders a read-only view.
- **Modal gates** — Five modals are each controlled by a local boolean state flag and require both a valid `teamId` and an active `softwareInstallerOnTeam`:
  - `EditIconModal` — appearance/icon editing
  - `EditSoftwareModal` — package/installer editing (blocked for Android Play Store apps)
  - `AddPatchPolicyModal` — only for Fleet-maintained apps
  - `EditConfigurationModal` — Android Play Store (non-web) or iOS/iPadOS apps
  - `EditAutoUpdateConfigModal` — iOS/iPadOS App Store apps only
- **`showVersionsTable`** — Derived flag; hides the versions table for script-based packages (`tgz_packages`, `sh_packages`, `ps1_packages`) and titles with zero host installs.

## Usage Example

```typescript
<SoftwareSummaryCard
  softwareTitle={softwareTitleDetails}
  softwareId={42}
  teamId={1}
  isAvailableForInstall={true}
  isLoading={false}
  router={router}
  refetchSoftwareTitle={() => refetch()}
  onToggleViewYaml={() => setShowYaml(prev => !prev)}
/>
```

## Notes

- **"All Teams" context**: passing `teamId={undefined}` suppresses all installer modals (`softwareInstallerOnTeam` becomes `false`).
- Passing `teamId={0}` is valid (represents the "No team" team); modals will still render.
- `iconUploadedAt` is a local cache-busting timestamp passed down to both the summary and `EditIconModal` to force icon refresh after an upload.
