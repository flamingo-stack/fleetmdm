Test suite for the `TitleVersionsTable` component, verifying rendering of software version rows, footer metadata, and empty state behavior.

## Key Components

- **`TitleVersionsTable` (under test)** — Component that renders a table of software title versions with links, vulnerability counts, host counts, and a "View all hosts" action per row.
- **`createMockRouter`** — Test utility that provides a mock Next.js router instance.
- **`ISoftwareTitleVersion`** — Interface representing a software version entry (id, version string, vulnerabilities array).

## Test Cases

| Test | Description |
|------|-------------|
| `renders version names as links and footer info` | Asserts 4 columns × 7 rows = 28 cells, version labels are visible, version count summary shows "7 versions", and an "updated" timestamp footer is rendered. |
| `renders empty state if no versions detected` | Asserts no table cells, no "0 versions" label, presence of the "updated" footer, and an explicit "no versions detected" empty state message. |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { createMockRouter } from "test/test-utils";
import TitleVersionsTable from "./TitleVersionsTable";

const mockRouter = createMockRouter();

render(
  <TitleVersionsTable
    router={mockRouter}
    data={[{ id: 1, version: "1.0.0", vulnerabilities: [] }]}
    isLoading={false}
    teamIdForApi={1}
    isIPadOSOrIOSApp={false}
    countsUpdatedAt="2024-01-01T00:00:00Z"
  />
);

expect(screen.getByText(/1.0.0/i)).toBeInTheDocument();
```
