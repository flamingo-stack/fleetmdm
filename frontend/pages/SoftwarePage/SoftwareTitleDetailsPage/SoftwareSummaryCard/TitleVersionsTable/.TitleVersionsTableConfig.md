Generates the column configuration for the software title versions table, defining how version, vulnerabilities, host count, and navigation link columns are rendered.

## Key Components

- **`generateSoftwareTitleVersionsTableConfig`** — Default export. Factory function that returns a `react-table` column definitions array based on team and platform context.
- **`ISoftwareTitleVersionsTableConfigProps`** — Config input interface accepting an optional `teamId` and `isIPadOSOrIOSApp` flag.
- **Cell type aliases** — `IVersionCellProps`, `IVulnCellProps`, `IHostCountCellProps`, `IViewAllHostsLinkProps` provide typed cell prop interfaces for each column.

### Columns

| Column | Accessor | Notes |
|---|---|---|
| Version | `version` | Links to `SOFTWARE_VERSION_DETAILS` route; renders empty `TextCell` if no value |
| Vulnerabilities | `vulnerabilities` | Shows `"Not supported"` for iPadOS/iOS apps; otherwise renders `VulnerabilitiesCell` |
| Hosts | `hosts_count` | Plain text count |
| *(empty)* | `linkToFilteredHosts` | Renders `ViewAllHostsLink` filtered by `software_version_id` and `fleet_id` |

## Usage Example

```typescript
import generateSoftwareTitleVersionsTableConfig from "./TitleVersionsTableConfig";

const columns = generateSoftwareTitleVersionsTableConfig({
  teamId: 42,
  isIPadOSOrIOSApp: false,
});

// Pass to TableContainer or react-table's useTable
<TableContainer columns={columns} data={softwareTitleVersions} />
```

## Notes

- All columns have `disableSortBy: true`; sorting is not supported in this table.
- The `vulnerabilities` accessor uses version-row data due to a `react-table` limitation preventing accessor reuse — see inline comment.
- Team scoping is applied via `fleet_id` query param on both the version details link and the "View All Hosts" link.
