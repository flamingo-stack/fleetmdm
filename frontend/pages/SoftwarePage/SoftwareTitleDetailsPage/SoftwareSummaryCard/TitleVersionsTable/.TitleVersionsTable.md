Renders the Versions section table for a software title detail page (`software/titles/:id`), displaying version-specific data with host counts, vulnerability info, and navigation to version detail pages.

## Key Components

- **`TitleVersionsTable`** *(default export)* — Main table component wrapping `TableContainer` with version rows, client-side pagination, and row-click navigation to `SOFTWARE_VERSION_DETAILS`
- **`TitleVersionsLastUpdatedInfo`** *(named export)* — Renders a `LastUpdatedText` tooltip indicating when software data (versions, vulnerabilities, host counts) was last refreshed
- **`NoVersionsDetected`** — Internal empty state component; conditionally adjusts messaging based on whether the software is available for install (currently unused as the table is hidden when no software exists)
- **`handleRowSelect`** — Navigates to the version detail route with an optional `fleet_id` (team) query param on row click
- **`softwareTableHeaders`** — Memoized column config generated by `generateSoftwareTitleVersionsTableConfig`, varying by team ID and iPadOS/iOS context

## Usage Example

```typescript
import TitleVersionsTable from "./TitleVersionsTable";

<TitleVersionsTable
  router={router}
  data={softwareTitleVersions}
  isLoading={isFetching}
  teamIdForApi={currentTeamId}
  isIPadOSOrIOSApp={false}
  isAvailableForInstall={true}
  countsUpdatedAt="2024-06-01T12:00:00Z"
/>
```

## Notes

- Default sort is `hosts_count` descending with a page size of 10
- Footer is hidden when total versions fit within a single page (`data.length <= 10`)
- The `isIPadOSOrIOSApp` flag adjusts column configuration for mobile OS contexts
