A modal component that displays generated YAML configuration for a software package, allowing users to view and copy the filename and YAML contents for GitOps-managed deployments.

## Key Components

- **`ViewYamlModal`** — Default export. A React modal that renders the YAML representation of a software package with copy-enabled fields.
- **`IViewYamlModalProps`** — Interface defining modal props including `softwareTitleName`, `softwarePackage`, `onExit`, and optional `iconUrl`, `displayName`, and `isScriptPackage`.
- **`createPackageYaml`** — Helper imported from `./helpers` that generates the YAML string from package metadata.
- **`hyphenateString`** — Utility used to convert the software title into a hyphenated filename (e.g., `my-software.package.yml`).

## Behavior Notes

- Reads `config.gitops.repository_url` from `AppContext`; if present, renders a link prompting the user to manage the package in YAML via their GitOps repository.
- The filename field is read-only with copy support, derived from the hyphenated software title.
- The YAML editor includes help text linking to `LEARN_MORE_ABOUT_BASE_LINK/yaml-packages` for advanced options documentation.

## Usage Example

```typescript
<ViewYamlModal
  softwareTitleName="Google Chrome"
  iconUrl="https://example.com/chrome-icon.png"
  displayName="Chrome Browser"
  softwarePackage={{
    name: "googlechrome",
    version: "120.0.0",
    url: "https://dl.google.com/chrome/install.pkg",
    hash_sha256: "abc123...",
  }}
  onExit={() => setShowModal(false)}
  isScriptPackage={false}
/>
```
