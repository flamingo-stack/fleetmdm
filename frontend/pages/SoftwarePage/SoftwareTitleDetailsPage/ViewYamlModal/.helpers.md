Generates a YAML configuration string for Fleet MDM software packages, conditionally including fields for URL, hash, scripts, and icons based on the provided parameters.

## Key Components

### `createPackageYaml(params: CreatePackageYamlParams): string`
The default export. Builds a YAML string for a software package entry, supporting both standard packages (`.pkg`, `.exe`, `.msi`, etc.) and script-only packages (`.sh`, `.ps1`). Script packages omit install/uninstall/query fields since the file itself serves as the install script.

### `CreatePackageYamlParams`
Interface defining all configurable fields:
- **Required:** `softwareTitle`, `packageName`, `version`, `iconUrl`
- **Optional:** `url`, `sha256`, `preInstallQuery`, `installScript`, `postInstallScript`, `uninstallScript`, `displayName`
- **Flag:** `isScriptPackage` (default `false`) — suppresses script/query YAML fields

## Usage Example

```typescript
import createPackageYaml from "./helpers";

const yaml = createPackageYaml({
  softwareTitle: "My App",
  packageName: "my-app",
  version: "1.0.0",
  url: "https://example.com/my-app.pkg",
  sha256: "abc123def456",
  installScript: "install.sh",
  iconUrl: "https://example.com/icon.png",
});

// Output:
// # My App (my-app) version 1.0.0
// - url: https://example.com/my-app.pkg
//   hash_sha256: abc123def456
//   install_script:
//     path: ../scripts/install-my-app.sh
//   icon:
//     path: ./icons/my-app-icon.png
```

Script paths use a hyphenated form of `softwareTitle` (via `hyphenateString`), so `"My App"` becomes `my-app` in all generated paths.
