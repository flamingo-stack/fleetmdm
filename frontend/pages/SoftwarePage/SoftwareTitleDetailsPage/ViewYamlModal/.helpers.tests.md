Test suite for the `createPackageYaml` helper function, validating YAML generation for software packages with various field combinations and package types.

## Key Components

- **`createPackageYaml`** — The function under test, imported from `./helpers`, which generates YAML configuration strings for software packages
- **`createMockSoftwarePackage`** — Mock factory imported from `__mocks__/softwareMock` providing consistent test fixture data

## Test Cases

| Test | Description |
|------|-------------|
| All fields present | Generates complete YAML with `url`, `hash_sha256`, scripts, and query paths |
| Optional fields omitted | Produces comment-only output when optional fields are `undefined` |
| Partial scripts/queries | Includes only the provided subset of script/query fields |
| File path hyphenation | Verifies `softwareTitle` is correctly kebab-cased in generated file paths |
| Null/empty SHA256 | Omits `hash_sha256` when value is `null` or empty string |
| Script packages | Strips `install_script`, `post_install_script`, `uninstall_script`, and `pre_install_query` when `isScriptPackage: true` |
| Icon URL and display name | Includes `display_name` and `icon.path` fields when provided |

## Usage Example

```typescript
import createPackageYaml from "./helpers";

const yaml = createPackageYaml({
  softwareTitle: "Falcon Sensor",
  packageName: "falcon-sensor-1.0.0.pkg",
  version: "1.0.0",
  url: "https://example.com/package.pkg",
  sha256: "abcd1234",
  installScript: "#!/bin/bash\ninstall",
  postInstallScript: undefined,
  uninstallScript: undefined,
  preInstallQuery: undefined,
  iconUrl: null,
  displayName: "Falcon Sensor",
  isScriptPackage: false,
});
```
