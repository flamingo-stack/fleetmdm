A confirmation modal component that prompts users to acknowledge the consequences of saving software installer configuration changes before proceeding.

## Key Components

### `IConfirmSaveChangesModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `onSaveChanges` | `() => void` | Callback invoked when the user confirms the save action |
| `onClose` | `() => void` | Callback invoked when the modal is dismissed or cancelled |
| `installerType` | `InstallerType` | Determines which warning message is displayed (`"package"` vs other types) |
| `softwareInstallerName` | `string` (optional) | Installer name displayed inline in the warning text |
| `isLoading` | `boolean` | Shows a loading state on the Save button during async operations |

### `ConfirmSaveChangesModal`
Default export. Renders a `Modal` with context-sensitive warning text and Save/Cancel actions.

**Warning text behavior:**
- `"package"` installer type — warns that pending installs/uninstalls will be cancelled, in-progress operations won't report results to Fleet, and the action is irreversible.
- All other installer types — warns only that pending installs will still complete when targets change.

## Usage Example

```typescript
import ConfirmSaveChangesModal from "components/ConfirmSaveChangesModal";

<ConfirmSaveChangesModal
  installerType="package"
  softwareInstallerName="Google Chrome.pkg"
  onSaveChanges={handleSave}
  onClose={() => setShowModal(false)}
  isLoading={isSaving}
/>
```
