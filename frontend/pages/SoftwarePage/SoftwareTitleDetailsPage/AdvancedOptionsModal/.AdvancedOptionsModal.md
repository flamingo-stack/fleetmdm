Read-only modal component that displays software installation advanced options (install script, pre-install query, and post-install script) in a non-editable view.

## Key Components

- **`AdvancedOptionsModal`** — Default export. A modal presenting advanced software installation settings in read-only editors.
- **`IAdvancedOptionsModalProps`** — Props interface defining the modal's inputs:
  - `installScript` *(required)* — Shell/PowerShell script Fleet runs to install software.
  - `preInstallQuery` *(optional)* — SQL query that must return results before installation proceeds.
  - `postInstallScript` *(optional)* — Script executed after installation completes.
  - `onExit` *(required)* — Callback invoked when the modal is dismissed.

## Usage Example

```typescript
import AdvancedOptionsModal from "components/software/AdvancedOptionsModal";

const MyComponent = () => {
  const [showModal, setShowModal] = React.useState(false);

  return (
    <>
      {showModal && (
        <AdvancedOptionsModal
          installScript="sudo installer -pkg /tmp/software.pkg -target /"
          preInstallQuery="SELECT 1 FROM os_version WHERE major >= 12;"
          postInstallScript="echo 'Installation complete'"
          onExit={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Notes

- All fields are strictly **read-only**; users must delete and re-add software to modify options.
- `preInstallQuery` and `postInstallScript` sections render conditionally — only when values are provided.
- The pre-install query links to [fleetdm.com/tables](https://fleetdm.com/tables) for osquery table reference.
