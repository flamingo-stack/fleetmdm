Generates table column configuration for displaying software installer policies, rendering each policy as a clickable link with associated type badges.

## Key Components

- **`generateInstallerPoliciesTableConfig`** – Factory function that returns a React Table column definition array for the installer policies table
- **`IInstallerPoliciesTableConfig`** – Config interface accepting an optional `teamId` to scope policy detail navigation
- **`ICellProps`** – Internal interface typing row/cell/column data from `ISoftwareInstallPolicyUI`

### Columns Produced

| Accessor | Header | Cell Renderer |
|---|---|---|
| `name` | `Name` (sortable) | `LinkCell` → policy detail page + `SoftwareInstallPolicyBadges` suffix |

## Usage Example

```typescript
import generateInstallerPoliciesTableConfig from "./InstallerPoliciesTableConfig";

// Without team scope (global context)
const columns = generateInstallerPoliciesTableConfig({});

// Scoped to a specific team
const teamColumns = generateInstallerPoliciesTableConfig({ teamId: 42 });

// Pass to a TableContainer
<TableContainer
  columns={teamColumns}
  data={installerPolicies}
/>
```

The `name` cell links to `PATHS.POLICY_DETAILS(id)` with a `fleet_id` query param when `teamId` is provided, and appends a `SoftwareInstallPolicyBadges` component to display the policy type (e.g., install/uninstall).
