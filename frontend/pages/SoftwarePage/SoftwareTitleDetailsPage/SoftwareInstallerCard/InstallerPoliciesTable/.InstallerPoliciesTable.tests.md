Test suite for the `InstallerPoliciesTable` component, verifying rendering of policy names as links, footer counts, and badge tooltips for `patch` and `dynamic` policy types.

## Key Components

- **`describe("InstallerPoliciesTable")`** — Top-level test suite using two mock `ISoftwareInstallPolicyUI` entries: one `dynamic` type ("No Gatekeeper") and one `patch` type ("Outdated Gatekeeper").
- **`it("renders policy names as links and footer info")`** — Asserts each policy renders as an `<a class="link-cell">` inside a table cell, and that a count summary ("2 policies") is displayed.
- **`it("renders the badges for patch and dynamic policies")`** — Uses `renderWithSetup` for user-event support, then hovers over badge elements to verify tooltip text for `patch` and `dynamic` (refresh icon) indicators.

## Notes

- Uses `renderWithSetup` from `test/test-utils` to include `@testing-library/user-event` for hover interactions.
- The `dynamic` policy type is identified by a `data-testid="refresh-icon"` element; the `patch` type is identified by visible text `/patch/i`.
- The nested `waitFor` calls are intentional for async tooltip rendering, though they may be candidates for simplification.
