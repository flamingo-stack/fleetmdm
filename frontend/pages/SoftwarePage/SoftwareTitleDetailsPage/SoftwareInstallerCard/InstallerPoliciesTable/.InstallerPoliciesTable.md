Renders a read-only table displaying the policies associated with a software installer, wrapping `TableContainer` with installer-specific column configuration and policy count display.

## Key Components

- **`InstallerPoliciesTable`** — Default export. Accepts `className`, `teamId`, `isLoading`, and `policies` props to render a paginated-disabled, single-select table of `ISoftwareInstallPolicyUI` entries.
- **`baseClass`** — Named export (`"installer-policies-table"`) used as the BEM root class for styling.
- **`generateInstallerPoliciesTableConfig`** — Imported helper that produces column definitions, receiving `teamId` to build team-scoped links or filters.
- **`TableCount`** — Renders a live policy count label above the table, memoized via `useCallback` on `policies.length`.

## Usage Example

```typescript
import InstallerPoliciesTable from "./InstallerPoliciesTable";
import { ISoftwareInstallPolicyUI } from "interfaces/software";

const policies: ISoftwareInstallPolicyUI[] = [
  { id: 1, name: "Require FileVault", platform: "darwin" },
  { id: 2, name: "Ensure Gatekeeper", platform: "darwin" },
];

<InstallerPoliciesTable
  teamId={42}
  isLoading={false}
  policies={policies}
  className="my-custom-class"
/>;
```

## Notes

- Pagination, multi-row selection, and the table footer are all disabled — the table is intended for compact, inline display.
- Passes an empty fragment (`<></>`) as `emptyComponent`, so no empty-state UI is rendered when `policies` is `null` or empty.
