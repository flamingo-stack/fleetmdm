Renders the installer details card on the Software Title Details page (`software/titles/:id`), displaying package metadata, status tables, associated policies, and action buttons for download/delete operations.

## Key Components

### `SoftwareActionButtons`
Exported sub-component that renders icon-based action buttons (download, delete) for a software installer. Dynamically adjusts available options based on:
- `installerType` — `"app-store"`, Android Play Store, or standard package
- `gitOpsModeEnabled` — disables delete for FMA/VPP apps with a YAML repo link tooltip
- `isTechnician` — hides delete action for technician roles

### `SoftwareInstallerCard` (default export)
Main card component composing:
- **`InstallerDetailsWidget`** — name, version, timestamp, SHA256, FMA version status
- **Tags** — "Self-service" and "Auto updates" with tooltips
- **`InstallerStatusTable`** — per-device installation status
- **`InstallerPoliciesTable`** — merged automatic install + patch policies
- **`DeleteSoftwareModal`** — confirmation modal for removal
- **`ViewYamlModal`** — GitOps YAML viewer (custom packages only)

## Usage Example

```typescript
<SoftwareInstallerCard
  softwareId={42}
  teamId={1}
  softwareTitle={softwareTitleDetails}
  isLoading={isLoading}
  showViewYamlModal={showYaml}
  onToggleViewYaml={() => setShowYaml((v) => !v)}
  onDelete={() => refetchSoftwareTitle()}
/>
```

## Notes

- Relies on `useSoftwareInstaller` hook to derive all installer metadata; throws if called with a `softwareTitle` lacking an installer.
- Download flow fetches a short-lived token via `softwareAPI.getSoftwarePackageToken`, then constructs a tokenized URL — no additional auth required at download time.
- Action visibility is gated on admin/maintainer/technician roles from `AppContext`.
