Defines action options and download utilities for software management UI components.

## Key Components

- **`ISoftwareOption`** – Type defining a dropdown/action menu option with value, disabled state, icon name, and optional tooltip content.
- **`SOFTWARE_PACKAGE_ACTION_OPTIONS`** – Action options (download + delete) for software packages.
- **`APP_STORE_APP_ACTION_OPTIONS`** – Action options (delete only) for App Store apps.
- **`ANDROID_PLAY_STORE_APP_ACTION_OPTIONS`** – Action options (delete only) for Android Play Store apps.
- **`downloadFile`** – Utility that triggers a browser file download by programmatically clicking a temporary anchor element.

## Usage Example

```typescript
import {
  SOFTWARE_PACKAGE_ACTION_OPTIONS,
  APP_STORE_APP_ACTION_OPTIONS,
  downloadFile,
} from "./helpers";

// Render action menu options for a software package
SOFTWARE_PACKAGE_ACTION_OPTIONS.forEach(({ value, iconName, disabled }) => {
  console.log(`Action: ${value}, Icon: ${iconName}, Disabled: ${disabled}`);
});

// Trigger a file download
downloadFile("https://example.com/package.pkg", "my-package.pkg");
```
