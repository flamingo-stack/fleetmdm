Test suite for the `InstallerDetailsWidget` React component, verifying rendering behavior across different installer types, version display logic, and UI element presence.

## Key Components

### Test Setup
- **`beforeAll`/`afterAll`**: Freezes system time to `2024-05-08T10:00:00Z` using `jest.useFakeTimers()` to enable deterministic relative timestamp assertions (e.g., "2 days ago")
- **`defaultProps`**: Baseline props object using `package` installer type with a fixed `addedTimestamp`

### Test Cases

| Test | Description |
|------|-------------|
| Package icon rendering | Verifies `file-pkg-graphic` test ID appears for `package` type; `software-icon` absent |
| Software name | Confirms display name renders |
| Version + relative time | Checks version string and "2 days ago" relative timestamp |
| Script package (no version) | Suppresses "Version (unknown)" label for script packages |
| Non-script, no version | Shows "Version (unknown)" for standard packages missing version |
| Missing timestamp | Omits relative time display when `addedTimestamp` is undefined |
| Custom className | Verifies CSS class composition on root element |
| Source labels | Validates "custom package", "Fleet-maintained" (FMA), "App Store (VPP)", "Google Play Store", and "Web app" labels per installer type |
| Google Play version | Confirms "latest" renders for Android Play Store entries |
| SHA256 hash | Shows truncated hash (`abcdef1…`) and a copy button |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import InstallerDetailsWidget from "./InstallerDetailsWidget";

render(
  <InstallerDetailsWidget
    softwareName="My App"
    installerType="package"
    addedTimestamp="2024-05-06T10:00:00Z"
    version="v2.0.0"
    isFma={false}
    isScriptPackage={false}
    androidPlayStoreId={undefined}
    sha256="abcdef1234567890..."
  />
);

expect(screen.getByText("My App")).toBeInTheDocument();
expect(screen.getByText(/abcdef1…/)).toBeInTheDocument();
```
