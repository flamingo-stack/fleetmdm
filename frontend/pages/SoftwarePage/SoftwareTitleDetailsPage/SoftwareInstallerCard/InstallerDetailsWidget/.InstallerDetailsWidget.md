Renders a details widget for a software installer, displaying its icon, name, type label, version, timestamp, and SHA-256 hash with copy functionality.

## Key Components

- **`InstallerDetailsWidget`** — Main exported component; composes icon, name, and metadata details for a given installer
- **`InstallerName`** — Internal sub-component that renders the software name with a tooltip when the text is truncated
- **`renderInstallerDisplayText`** — Helper that resolves the human-readable installer type label (e.g., `"Fleet-maintained"`, `"Custom package"`, `"Google Play Store"`, `"App Store (VPP)"`)
- **`renderDetails`** — Internal render function composing version info, timestamp, and SHA-256 with clipboard copy support

## Props (`IInstallerDetailsWidgetProps`)

| Prop | Type | Description |
|---|---|---|
| `softwareName` | `string` | Display name of the software |
| `installerType` | `InstallerType` | Type of installer (`"package"` or `"app-store"`) |
| `isFma` | `boolean` | Whether this is a Fleet-maintained app |
| `isScriptPackage` | `boolean` | Suppresses version display for script packages |
| `sha256` | `string \| null` | SHA-256 hash; renders truncated value with copy button |
| `addedTimestamp` | `string` | ISO timestamp shown as relative time with full tooltip |
| `androidPlayStoreId` | `string` | Triggers Play Store icon and Android version display |
| `customDetails` | `string` | Overrides all detail rendering with custom text |

## Usage Example

```typescript
<InstallerDetailsWidget
  softwareName="Slack"
  installerType="package"
  isFma={true}
  isLatestFmaVersion={true}
  isScriptPackage={false}
  version="4.35.126"
  sha256="a1b2c3d4e5f6..."
  addedTimestamp="2024-06-01T12:00:00Z"
/>
```
