Renders a read-only status table for a software installer or app store application, displaying install counts with contextual help text based on the software type.

## Key Components

**`InstallerStatusTable`** — Default exported React component that wraps `TableContainer` to display a single-row status summary.

**`IInstallerStatusTableProps`** — Component props interface:
| Prop | Type | Description |
|---|---|---|
| `softwareId` | `number` | ID of the software title |
| `teamId` | `number` (optional) | Scopes status to a specific team |
| `status` | `ISoftwarePackageStatus \| ISoftwareAppStoreAppStatus` | Status data row |
| `isLoading` | `boolean` | Shows loading state |
| `isScriptPackage` | `boolean` | Suppresses help text for script-type packages |
| `isAndroidPlayStoreApp` | `boolean` | Renders Android-specific setup experience help text |

**`renderTableHelpText`** — Internal renderer that conditionally returns tooltip-enhanced help text describing what triggered the installs (policy automations, setup experience, or manual).

**`generateSoftwareTitleDetailsTableConfig`** — Imported column config builder that resolves column definitions based on software context.

## Usage Example

```typescript
import InstallerStatusTable from "./InstallerStatusTable";

<InstallerStatusTable
  softwareId={42}
  teamId={7}
  status={softwarePackageStatus}
  isLoading={false}
  isScriptPackage={false}
  isAndroidPlayStoreApp={false}
/>
```
