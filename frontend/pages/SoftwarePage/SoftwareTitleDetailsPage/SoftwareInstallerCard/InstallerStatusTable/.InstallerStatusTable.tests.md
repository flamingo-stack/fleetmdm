Test suite for the `InstallerStatusTable` component, verifying rendering of status counts, column headers, host links, and tooltip behavior across different software package types (standard installer, script package, and Android Play Store app).

## Key Components

- **`describe("InstallerStatusTable")`** — Main test suite using `createCustomRenderer` for component rendering
- **Column/link rendering test** — Validates cell values and correct pluralization (`"1 host"` vs `"0/3 hosts"`)
- **Header title test** — Checks that `isScriptPackage` prop switches headers from `Installed/Pending/Failed` to `Ran/Pending/Failed`
- **Pending tooltip test** — Confirms different tooltip text for Android Play Store vs. standard packages
- **Installed tooltip test** — Verifies the installed tooltip is hidden (`null`) for Android Play Store apps
- **Failed tooltip test** — Validates distinct failure messages for Android vs. non-Android packages

## Usage Example

```typescript
// Render the component under test with various prop combinations
render(
  <InstallerStatusTable
    softwareId={123}
    teamId={5}
    status={{ installed: 0, pending: 1, failed: 3 }}
    isScriptPackage={false}
    isAndroidPlayStoreApp={false}
  />
);

// Assert host count links
const cells = screen.getAllByRole("cell");
expect(cells[1].querySelector("a.link-cell")).toHaveTextContent("1 host");

// Assert column headers for script packages
rerender(<InstallerStatusTable ... isScriptPackage />);
expect(screen.getAllByRole("columnheader")[0]).toHaveTextContent("Ran");
```
