Generates table column configuration for displaying software installation/script execution status counts across hosts, with tooltips and links to filtered host views.

## Key Components

### Types

- **`SoftwareInstallDisplayStatus`** — `"installed" | "pending" | "failed"`
- **`SoftwareScriptDisplayStatus`** — `"ran_script" | "pending_script" | "failed_script"`
- **`ISoftwareTitleDetailsTableConfigProps`** — Config options including `softwareId`, `teamId`, `baseClass`, `isScriptPackage`, and `isAndroidPlayStoreApp`

### Constants

- **`STATUS_DISPLAY_OPTIONS`** — Map of all six statuses to their display name, icon, and context-aware tooltip content. Tooltips vary based on `isAndroidPlayStoreApp` for install statuses.

### Exports

- **`generateSoftwareTitleDetailsTableConfig`** — Default export. Returns three column definitions (`installed`, `pending`, `failed`) for use with `TableContainer`. Each column renders a tooltip-wrapped icon header and a `LinkCell` pointing to `/manage/hosts` filtered by `software_title_id`, `software_status`, and `fleet_id`.

## Usage Example

```typescript
import generateSoftwareTitleDetailsTableConfig from "./InstallerStatusTableConfig";

const columns = generateSoftwareTitleDetailsTableConfig({
  softwareId: 42,
  teamId: 1,
  baseClass: "software-title-details",
  isScriptPackage: false,
  isAndroidPlayStoreApp: false,
});

// Pass to TableContainer
<TableContainer columns={columns} data={versionData} />;
```

## Behavior Notes

- When `isScriptPackage` is `true`, the first column switches from **Installed** → **Ran** (using `ran_script` display options).
- When `isAndroidPlayStoreApp` is `true`, tooltip copy adjusts to reflect Play Store semantics (e.g., "configuration will be applied" instead of "Fleet is installing").
- All columns have `disableSortBy: true`; host counts link directly to a pre-filtered host management view.
