Renders a modal dialog for editing an existing software package or VPP app within the Fleet MDM software library, handling form state, upload progress, GitOps mode compatibility, and save-confirmation flows.

## Key Components

- **`EditSoftwareModal`** — Main default export component that orchestrates the edit workflow
- **`IEditPackageFormData`** — Exported type alias for `IPackageFormData` without the `installType` field (not applicable on edit)
- **`IEditSoftwareModalProps`** — Interface defining required props: `softwareId`, `teamId`, `softwareInstaller`, installer metadata, and callbacks
- **`onEditPackage`** — Async handler that calls `softwareAPI.editSoftwarePackage`, tracks upload progress, and invalidates React Query caches
- **`onEditVpp`** — Async handler that calls `softwareAPI.editAppStoreApp` for VPP/App Store apps
- **`onClickSavePackage` / `onClickSaveVpp`** — Pre-save handlers that use `deepDifference` to detect changes; skip the confirm modal when only `selfService` changed
- **`renderForm`** — Conditionally renders `PackageForm` or `SoftwareVppForm` based on `installerType`

## Usage Example

```typescript
import EditSoftwareModal from "./EditSoftwareModal";

<EditSoftwareModal
  softwareId={42}
  teamId={1}
  softwareInstaller={softwarePackage}
  installerType="package"
  name="Microsoft Teams"
  displayName="Microsoft Teams"
  refetchSoftwareTitle={() => refetch()}
  onExit={() => setShowEditModal(false)}
  openViewYamlModal={() => setShowYaml(true)}
  isFleetMaintainedApp={false}
/>
```

## Notable Behaviors

- **GitOps mode**: When `gitOpsModeEnabled` and `isFleetMaintainedApp`, the form renders disabled and opens the YAML modal instead of flashing a success message after save
- **File progress modal**: Shown only after 3 seconds of active upload to prevent flashing on quick uploads; blocks page navigation via `beforeunload`
- **CSS hiding pattern**: The edit modal is hidden via CSS class (not unmounted) when child modals (`ConfirmSaveChangesModal`, `CategoriesEndUserExperienceModal`) are open, preserving form state
- **Query invalidation**: Invalidates both `software-titles` and `software-library` scopes after a successful edit
