Brief utility module for the software editing flow that maps API/network errors to user-facing messages.

## Key Components

### `getErrorMessage(err, software)`

Exported function that inspects an error and a software item (`ISoftwarePackage | IAppStoreApp`) and returns a human-readable string or JSX element suitable for display in the UI.

| Condition | Message Returned |
|---|---|
| HTTP 504 / 408 timeout | Timeout guidance message |
| Reason includes `"selected package is"` | Bolded software name + raw reason |
| Reason includes `"Secret variable"` | Reworded secret-error message from `generateSecretErrMsg` |
| Reason includes `"some or all of the categories"` | Category-not-found message with bolded software name |
| All other errors | Raw reason string or `DEFAULT_ERROR_MESSAGE` |

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await editSoftware(payload);
} catch (err) {
  const message = getErrorMessage(err, {
    name: "my-app",
    display_name: "My App",
    // ...other ISoftwarePackage fields
  });

  // `message` is either a string or a JSX element
  showToast({ content: message, variant: "error" });
}
```

## Dependencies

- [`axios`](https://axios-http.com) — `isAxiosError` for HTTP status detection
- `interfaces/errors` — `getErrorReason` to extract a readable reason string
- `interfaces/software` — `ISoftwarePackage`, `IAppStoreApp` types
- `pages/SoftwarePage/helpers` — `generateSecretErrMsg`, `getDisplayedSoftwareName`
