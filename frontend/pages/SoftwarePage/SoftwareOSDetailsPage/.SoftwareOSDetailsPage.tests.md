Unit tests for the `SoftwareOSDetailsPage` component cards (`SummaryCard`, `VulnerabilitiesCard`, `KernelsCard`), validating rendering behavior across various OS platforms and data states.

## Key Components

| Test Suite | Component Tested | Coverage |
|---|---|---|
| `SummaryCard` | OS name, host count, updated timestamp | Basic render |
| `VulnerabilitiesCard` | Vulnerability table, unsupported platform empty state | macOS + iPadOS |
| `KernelsCard` | Kernels table with data, empty state | Linux |

## Usage Example

```typescript
// Run all tests in this file
npx jest SoftwareOSDetailsPage.tests.tsx

// Run a specific suite
npx jest --testNamePattern="KernelsCard"
```

### Test Patterns

```typescript
// Mocking OS version data
createMockOSVersion({ hosts_count: 123 })
createMockLinuxOSVersion({ kernels: [] })

// Mocking router
const mockRouter = createMockRouter();

// Asserting unsupported platform empty state
expect(
  screen.getByText(/Vulnerabilities are not supported for this type of host/i)
).toBeInTheDocument();
```

## Test Scenarios

- **`SummaryCard`** — asserts OS name (`Mac OS X`), host count (`123`), and relative timestamp (`Updated 2 days ago`)
- **`VulnerabilitiesCard`** — confirms vulnerability rows render for supported platforms; verifies `iPadOS` triggers a "not supported" empty state
- **`KernelsCard`** — validates kernel version strings, vulnerability counts (`14 vulnerabilities`), and the `No kernels detected` empty state when `kernels: []`
