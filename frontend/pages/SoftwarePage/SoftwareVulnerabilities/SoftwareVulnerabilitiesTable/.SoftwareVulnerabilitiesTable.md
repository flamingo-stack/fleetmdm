Renders the paginated, searchable vulnerabilities table on the **Software > Vulnerabilities** tab, handling query-param-driven routing, exploited-filter toggling, and row-level navigation to CVE detail pages.

## Key Components

| Export/Symbol | Description |
|---|---|
| `SoftwareVulnerabilitiesTable` (default) | Main table component wrapping `TableContainer` with vulnerability-specific config |
| `ISoftwareVulnerabilitiesTableProps` | Props interface defining routing, pagination, filter, and data inputs |
| `IRowProps` | Extended `Row` type carrying the `cve` string for row-select navigation |
| `determineQueryParamChange` | Detects which query param changed to selectively reset page index |
| `generateNewQueryParams` | Builds the next URL query params object from current table state |
| `onQueryChange` | Central handler that maps table events to router `replace` calls |
| `renderExploitedVulnerabilitiesDropdown` | Renders the exploited-only filter dropdown (premium-gated) |

## Usage Example

```typescript
<SoftwareVulnerabilitiesTable
  router={router}
  isSoftwareEnabled={true}
  data={vulnerabilitiesResponse}
  query="CVE-2024"
  perPage={20}
  orderDirection="desc"
  orderKey="cvss_score"
  showExploitedVulnerabilitiesOnly={false}
  currentPage={0}
  teamId={3}
  isLoading={false}
/>
```

## Behaviour Notes

- **Incomplete quote guard** — `onQueryChange` bails early when the search string contains an unclosed quote, preventing partial-query API calls.
- **Page reset logic** — any parameter change other than `pageIndex` resets `page` to `0` in the new route.
- **Premium gating** — the exploited-vulnerabilities dropdown options are conditionally restricted via `isPremiumTier` from `AppContext`.
- **Row navigation** — clicking a row pushes to `PATHS.SOFTWARE_VULNERABILITY_DETAILS(cveName)` with the active `fleet_id` (team) preserved as a query param.
