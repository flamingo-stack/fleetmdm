Provides utility functions for the vulnerabilities feature, including dropdown option generation for vulnerability filtering and CVE format validation.

## Key Components

### `getExploitedVulnerabilitiesDropdownOptions(isPremiumTier?)`
Returns an array of dropdown options for filtering vulnerabilities. The "Exploited vulnerabilities" option is gated behind Fleet Premium — when `isPremiumTier` is `false`, it renders as disabled with a tooltip indicating the tier requirement.

### `isValidCVEFormat(query)`
Validates whether a given string matches the standard CVE identifier format (`CVE-YYYY-NNNN+`), case-insensitively. Returns `false` early for strings shorter than 9 characters.

## Usage Example

```typescript
import {
  getExploitedVulnerabilitiesDropdownOptions,
  isValidCVEFormat,
} from "./helpers";

// Generate dropdown options for a premium user
const options = getExploitedVulnerabilitiesDropdownOptions(true);
// options[1].isDisabled === false (exploited option enabled)

// Generate dropdown options for a free-tier user
const freeOptions = getExploitedVulnerabilitiesDropdownOptions(false);
// freeOptions[1].isDisabled === true
// freeOptions[1].tooltipContent === "Available in Fleet Premium."

// Validate CVE format
isValidCVEFormat("CVE-2024-12345"); // true
isValidCVEFormat("CVE-2024-1234");  // true
isValidCVEFormat("cve-2021-44228"); // true (case-insensitive)
isValidCVEFormat("CVE-24-123");     // false (short year)
isValidCVEFormat("invalid");        // false
```

## Notes

- The minimum length check (`< 9`) in `isValidCVEFormat` serves as a fast-path guard before the regex is evaluated (`CVE-0000` is 8 characters, the shortest plausible CVE-like string).
