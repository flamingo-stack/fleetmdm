Defines the column configuration for the vulnerabilities data table, generating sortable, filterable headers with custom cell renderers for CVE details, severity, exploit probability, and host counts.

## Key Components

- **`generateTableHeaders`** — Primary export. Returns an array of `IDataColumn` definitions used to configure a React table for vulnerability data.
- **`IDataColumn`** — Interface describing a table column with `Header`, `Cell`, `accessor`, and optional sort/visibility flags.
- **`IVulnerabilitiesTableConfigOptions`** — Options to conditionally include name, icon, or vulnerability columns.

### Columns Generated

| Accessor | Description |
|---|---|
| `cve` | Vulnerability ID; renders as a link to the CVE detail page when `includeIcon` is set |
| `cvss_score` | CVSS v3 severity score with tooltip |
| `epss_probability` | 30-day exploit probability via EPSS (FIRST.org) |
| `cve_published` | NVD publish date rendered as a human-readable time diff |
| `created_at` | Date the vulnerability was first detected on a host |
| `hosts_count` | Number of affected hosts |
| `linkToFilteredHosts` | "View all hosts" link filtered by CVE |

> **Tier filtering:** When `isPremiumTier` is `false`, the `epss_probability`, `cve_published`, and `cvss_score` columns are removed from the returned config.

## Usage Example

```typescript
import generateTableHeaders from "./VulnerabilitiesTableConfig";

const columns = generateTableHeaders(
  isPremiumTier,   // boolean — controls premium column visibility
  router,          // InjectedRouter — used for CVE detail page navigation
  { includeIcon: true }, // render CVE as a clickable link
  teamId           // number — scopes host links to a specific team
);

// Pass to a TableContainer or DataTable component
<TableContainer columns={columns} data={vulnerabilities} />
```
