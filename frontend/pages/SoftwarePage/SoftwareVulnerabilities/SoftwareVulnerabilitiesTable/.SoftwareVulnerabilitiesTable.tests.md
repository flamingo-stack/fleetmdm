Test suite for the `SoftwareVulnerabilitiesTable` component, verifying rendering behavior across various states including disabled inventory, empty states, CVE search results, and premium vs. free tier column visibility.

## Key Components

- **`describe("Software Vulnerabilities table")`** — Top-level test suite containing 8 test cases
- **`createCustomRenderer`** — Utility that injects app context (user role, tier) into rendered components
- **`createMockVulnerabilitiesResponse`** — Mock factory for vulnerability API response payloads
- **`createMockUser`** — Mock factory for authenticated user objects

## Test Cases

| Test | Scenario |
|------|----------|
| Software inventory disabled | Shows "Software inventory disabled" banner, no table columns |
| No vulnerabilities detected | Shows empty state with `emptyStateReason="no-vulns-detected"` |
| Exploited filter with no results | Shows generic "No items match" empty state |
| Invalid CVE query | Shows CVE format hint with `emptyStateReason="invalid-cve"` |
| Known CVE, no hosts affected | Shows known-but-undetected message |
| Unknown CVE | Shows "This is not a known CVE" message |
| Premium tier columns | Renders Severity, Probability of exploit, Published columns |
| Free tier restrictions | Hides premium columns; disables "Exploited vulnerabilities" dropdown with upgrade tooltip |

## Usage Example

```typescript
// Running the test suite
npx jest SoftwareVulnerabilitiesTable.tests.tsx

// Key render pattern used throughout
const render = createCustomRenderer({
  context: {
    app: {
      isPremiumTier: true,
      isGlobalAdmin: true,
      currentUser: createMockUser(),
    },
  },
});

render(
  <SoftwareVulnerabilitiesTable
    router={mockRouter}
    isSoftwareEnabled
    data={createMockVulnerabilitiesResponse()}
    query="CVE-2018-16463"
    perPage={20}
    orderDirection="asc"
    orderKey="hosts_count"
    showExploitedVulnerabilitiesOnly={false}
    currentPage={0}
    isLoading={false}
  />
);
```
