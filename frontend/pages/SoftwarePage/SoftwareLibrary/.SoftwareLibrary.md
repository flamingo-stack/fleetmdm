Renders the **Software Library** tab, fetching and displaying fleet-managed software titles available for installation via `react-query` and delegating rendering to `SoftwareLibraryTable`.

## Key Components

- **`SoftwareLibrary`** *(default export)* — React component that:
  - Fetches software titles from `softwareAPI.getSoftwareTitles` with a 30-second stale time
  - Scopes the query to `availableForInstall: true` and optionally `selfService: true`
  - Guards fetching with a `teamId` check and pathname validation against `PATHS.SOFTWARE_LIBRARY`
  - Shows `<Spinner />` while loading and `<TableDataError />` on failure
  - Passes resolved data and all pagination/filter props to `SoftwareLibraryTable`

- **`ISoftwareLibraryProps`** — Props interface covering router, pagination (`currentPage`, `perPage`), sorting (`orderKey`, `orderDirection`), filtering (`query`, `selfServiceOnly`), feature flag (`isSoftwareEnabled`), and optional `teamId`

## Usage Example

```typescript
import SoftwareLibrary from "./SoftwareLibrary";

<SoftwareLibrary
  router={router}
  isSoftwareEnabled={true}
  query=""
  perPage={20}
  orderDirection="asc"
  orderKey="name"
  selfServiceOnly={false}
  currentPage={0}
  teamId={42}
/>
```

## Notes

- The query is **disabled** until `teamId` is defined and the current pathname matches `PATHS.SOFTWARE_LIBRARY`, preventing stale fetches when navigating away.
- `keepPreviousData: true` ensures the table retains its last dataset during page/filter transitions, avoiding layout flicker.
