Renders the paginated, searchable table for the Software Library tab, displaying software titles with support for self-service filtering, sort/search query sync via URL params, and role-based add-software actions.

## Key Components

### `SoftwareLibraryTable` (default export)
Main component accepting the following props:

| Prop | Type | Description |
|------|------|-------------|
| `router` | `InjectedRouter` | React Router instance for navigation |
| `data` | `ISoftwareTitlesResponse` | Paginated software titles response |
| `isSoftwareEnabled` | `boolean` | Disables table controls when `false` |
| `query` | `string` | Current search query string |
| `perPage` | `number` | Page size |
| `orderDirection` | `"asc" \| "desc"` | Current sort direction |
| `orderKey` | `string` | Current sort column key |
| `selfServiceOnly` | `boolean` | Whether self-service filter is active |
| `currentPage` | `number` | Active page index |
| `teamId` | `number?` | Optional team scope |
| `isLoading` | `boolean` | Loading state for the table |

### Internal Helpers

- **`determineQueryParamChange`** — Identifies which query parameter changed from the previous table state.
- **`generateNewQueryParams`** — Builds the next URL query param object, resetting page to `0` on non-pagination changes.
- **`onQueryChange`** — Syncs table state to URL via `router.replace`.
- **`handleSelfServiceToggle`** — Toggles the `self_service` URL param.
- **`handleRowSelect`** — Navigates to the software title detail page on row click.
- **`renderCustomControls`** — Renders the Categories button and Self-service slider.
- **`renderSoftwareCount`** — Renders item count and last-updated timestamp.

## Usage Example

```typescript
import SoftwareLibraryTable from "./SoftwareLibraryTable";

<SoftwareLibraryTable
  router={router}
  data={softwareTitlesResponse}
  isSoftwareEnabled={true}
  query="chrome"
  perPage={20}
  orderDirection="asc"
  orderKey="name"
  selfServiceOnly={false}
  currentPage={0}
  teamId={3}
  isLoading={false}
/>
```

## Empty States

| Condition | Displayed Component |
|-----------|-------------------|
| Software disabled | `<EmptySoftwareTable isSoftwareDisabled />` |
| Active search/filter with no results | "No items match the current search criteria" |
| No software, user can add | "No software available" + **Add software** button |
| No software, read-only user | "Software added to this fleet's library will appear here" |

## Notes

- Table state (search, sort, page, self-service) is fully URL-driven via query params (`query`, `order_key`, `order_direction`, `page`, `self_service`, `fleet_id`).
- The **Add software** button is only rendered for `GlobalAdmin`, `GlobalMaintainer`, `TeamAdmin`, or `TeamMaintainer` roles (via `AppContext`).
- Column configuration is generated by [`SoftwareLibraryTableConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/pages/SoftwarePage/components/tables/SoftwareLibraryTable/SoftwareLibraryTableConfig.ts).
