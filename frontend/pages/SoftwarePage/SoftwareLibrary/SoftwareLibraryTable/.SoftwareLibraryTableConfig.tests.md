Test suite for the `SoftwareLibraryTableConfig` table header generator, verifying column structure, naming conventions, and sort behavior for the software library table view.

## Key Components

- **`generateTableHeaders`** — The function under test; accepts a router and team ID, returns column configuration objects
- **`createMockRouter`** — Test utility that provides a mock Next.js router instance

## Test Coverage

| Test | Assertion |
|------|-----------|
| Column headers | Verifies exact ordered list of column names/accessors |
| "Installed version" label | Confirms label is `"Installed version"`, not generic `"Version"` |
| Library version column | Confirms `library_version` column exists by `id` |
| No Vulnerabilities column | Confirms `"Vulnerabilities"` column is absent |
| Sort disabled | Confirms `disableSortBy: true` on `"Installed version"`, `"Library version"`, and `"Type"` |

## Usage Example

```typescript
import generateTableHeaders from "./SoftwareLibraryTableConfig";
import { createMockRouter } from "test/test-utils";

const router = createMockRouter();

// Generate headers for team ID 1
const headers = generateTableHeaders(router, 1);

// Expected column order:
// ["name", "Installed version", "Library version", "Type", "hosts_count", ""]
```
