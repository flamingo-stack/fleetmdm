Defines and exports the `generateTableHeaders` function that produces the react-table column configuration for the Software Library table, rendering name, version, type, host count, and navigation columns for `ISoftwareTitle` rows.

## Key Components

### Helper Functions

- **`getSoftwareNameCellData(softwareTitle, teamId?)`** — Derives display data for the name cell: detail page path, installer presence, self-service flag, install type (`"manual"` | `"automatic"`), icon URL, and automatic install policy count.
- **`getLibraryVersion(softwareTitle)`** — Returns the installer package version or App Store app's latest version, falling back to `null`.

### Main Export

- **`generateTableHeaders(router, teamId?)`** — Builds and returns the column definitions array (`ISoftwareTitlesTableConfig[]`) consumed by the Software Library react-table instance.

### Column Definitions

| Column | Accessor / ID | Sortable | Notes |
|---|---|---|---|
| Name | `name` | ✅ | Uses `SoftwareNameCell`; handles iOS/iPadOS and Android Play Store apps |
| Installed version | `versions` | ❌ | Uses `VersionCell` |
| Library version | `library_version` | ❌ | Installer/App Store version via `getLibraryVersion` |
| Type | `source` | ❌ | Formatted with `formatSoftwareType` |
| Hosts | `hosts_count` | ✅ | Tooltip: "Hosts with any version installed" |
| *(View all hosts)* | `view-all-hosts` | ❌ | Hidden for unsupported sources (`NO_VERSION_OR_HOST_DATA_SOURCES`) |

## Usage Example

```typescript
import generateTableHeaders from "./SoftwareLibraryTableConfig";

const columns = generateTableHeaders(router, teamId);

<TableContainer
  columns={columns}
  data={softwareTitles}
/>
```
