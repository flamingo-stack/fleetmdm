Modal component for editing an existing self-service category name, with validation and duplicate name error handling.

## Key Components

- **`EditCategoryModal`** — Default export. Renders a modal form allowing users to rename a self-service category.
- **`IEditCategoryModalProps`** — Interface defining required props: `category`, `onExit`, and `onSuccess` callbacks.
- **`NAME_MAX_LENGTH`** — Constant (`255`) enforcing the maximum allowed category name length.

### Form Validation Logic
- Submit is disabled if the trimmed name is empty, exceeds 255 characters, is unchanged from the original, or a request is in flight.
- A `409` conflict response surfaces a user-friendly duplicate name error inline on the input field.

## Usage Example

```typescript
import EditCategoryModal from "components/EditCategoryModal";

<EditCategoryModal
  category={{ id: 1, name: "Productivity" }}
  onExit={() => setShowModal(false)}
  onSuccess={() => {
    setShowModal(false);
    refetchCategories();
  }}
/>
```

## API Interaction

Calls `selfServiceCategoriesAPI.updateCategory(category.id, { name })` on submit. On success, invokes `onSuccess`. On failure:

| HTTP Status | Error Message |
|-------------|---------------|
| `409` | "A self-service category with this name already exists in this fleet." |
| Other | "Couldn't update self-service category." |
