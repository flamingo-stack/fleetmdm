Integration test suite for the `SelfServiceCategoriesPage` component, verifying rendering, permissions, CRUD operations, and error handling across different user roles and API response scenarios.

## Key Components

- **`premiumAdminContext`** – Shared context fixture for a Fleet Premium global admin user with a mock team
- **`getOpenModal()`** – Helper that polls for the modal container element using the `.modal__modal_container` CSS selector (used because the modal title renders as a `<span>`, not a heading)
- **MSW Handlers** – Per-test mock server overrides from `test/handlers/self-service-categories-handlers`:
  - `emptySelfServiceCategoriesHandler`
  - `listSelfServiceCategoriesHandler`
  - `addSelfServiceCategoryHandler` / `addSelfServiceCategoryConflictHandler` / `addSelfServiceCategoryErrorHandler`
  - `editSelfServiceCategoryHandler` / `editSelfServiceCategoryConflictHandler` / `editSelfServiceCategoryErrorHandler`
  - `deleteSelfServiceCategoryHandler` / `deleteSelfServiceCategoryErrorHandler`

## Test Coverage

| Scenario | Assertion |
|---|---|
| Fleet Free tier | Premium gate shown; team dropdown hidden |
| Empty state (admin) | Empty copy + "Add category" button visible |
| Empty state (observer) | Observer-specific copy; no "Add category" button |
| Populated list | Category names rendered |
| Observer on populated list | Edit/Delete/Add buttons hidden |
| Successful add | Flash success message fired |
| Duplicate name (add) | Inline 409 error in modal; no flash |
| Generic add error | Inline error in modal; no flash |
| Duplicate name (edit) | Inline 409 error in modal; no flash |
| Generic edit error | Inline error in modal; no flash |
| Delete failure | Flash error; Delete button re-enabled |
| Cancel Add modal | Modal closes |

## Usage Example

```typescript
// Run the full suite
jest --testPathPattern="SelfServiceCategoriesPage.tests"

// Override MSW handlers per test
mockServer.use(listSelfServiceCategoriesHandler([{ id: 1, name: "🌎 Browsers" }]));
```
