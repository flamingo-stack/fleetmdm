A modal component for creating new self-service categories within a fleet, handling input validation, duplicate name detection, and submission state.

## Key Components

- **`AddCategoryModal`** — Default export. A controlled form modal that accepts a category name, validates it, and calls `selfServiceCategoriesAPI.addCategory` on submit.
- **`IAddCategoryModalProps`** — Props interface with:
  - `fleetId: number` — Target fleet for the new category
  - `onExit: () => void` — Callback to close the modal
  - `onSuccess: () => void` — Callback invoked after successful creation
- **Validation** — Name must be non-empty and ≤ 255 characters; 409 conflict responses surface an inline duplicate-name error.

## Usage Example

```typescript
import AddCategoryModal from "components/AddCategoryModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <button onClick={() => setShowModal(true)}>Add Category</button>
      {showModal && (
        <AddCategoryModal
          fleetId={42}
          onExit={() => setShowModal(false)}
          onSuccess={() => {
            setShowModal(false);
            refetchCategories();
          }}
        />
      )}
    </>
  );
};
```

## Error Handling

| Scenario | Behavior |
|---|---|
| Empty or whitespace-only name | Submit button disabled |
| Name exceeds 255 characters | Submit button disabled |
| HTTP 409 Conflict | Inline error: duplicate name in fleet |
| Other API errors | Inline generic error message |
