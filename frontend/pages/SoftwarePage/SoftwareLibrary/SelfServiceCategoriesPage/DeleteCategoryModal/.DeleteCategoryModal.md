A confirmation modal component for deleting a self-service category, handling the async delete operation with loading state and error notifications.

## Key Components

- **`DeleteCategoryModal`** — Default export. A modal dialog that prompts the user to confirm deletion of a self-service category.
- **`IDeleteCategoryModalProps`** — Props interface with:
  - `category: ISelfServiceCategory` — The category to be deleted
  - `onExit: () => void` — Callback to close/dismiss the modal
  - `onSuccess: () => void` — Callback invoked after a successful deletion

## Usage Example

```typescript
import DeleteCategoryModal from "components/DeleteCategoryModal";

<DeleteCategoryModal
  category={selectedCategory}
  onExit={() => setShowDeleteModal(false)}
  onSuccess={() => {
    setShowDeleteModal(false);
    refreshCategories();
  }}
/>
```

## Behavior

- Calls `selfServiceCategoriesAPI.deleteCategory(category.id)` on confirmation
- Sets `isDeleting` to `true` during the API call, disabling both buttons and showing a loading spinner on the Delete button
- On failure, renders an error flash notification via `NotificationContext` and re-enables the UI
- Warns users that the category will be removed from all associated software before confirming
