Test suite for the `SoftwareOSTable` component, verifying rendering behavior for disabled software inventory and empty OS data states.

## Key Components

- **`describe("Software operating systems table")`** — Test suite grouping two rendering scenarios for the OS table
- **`createMockRouter`** — Utility that provides a mock Next.js-style router for component context
- **`createMockOSVersionsResponse`** — Mock factory generating a `OSVersionsResponse` shape with configurable `count` and `os_versions`

## Test Cases

| Test | Condition | Expected Output |
|------|-----------|-----------------|
| Disabled state | `isSoftwareEnabled={false}` | Renders `"Software inventory disabled"` banner |
| Empty state | `isSoftwareEnabled={true}`, empty `os_versions` | Renders `"No operating systems detected"`, `"0 items"`, `"All platforms"`; omits `"Search"` and `"Updated"` |

## Usage Example

```typescript
// Running the tests
// From repo root:
// npx jest SoftwareOSTable.tests.tsx

render(
  <SoftwareOSTable
    router={mockRouter}
    isSoftwareEnabled={false}
    data={createMockOSVersionsResponse({ count: 0, os_versions: [] })}
    perPage={20}
    orderDirection="asc"
    orderKey="hosts_count"
    currentPage={0}
    teamId={1}
    isLoading={false}
  />
);

expect(screen.getByText("Software inventory disabled")).toBeInTheDocument();
```
