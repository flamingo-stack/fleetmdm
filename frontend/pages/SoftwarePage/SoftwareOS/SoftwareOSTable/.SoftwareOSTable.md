Renders the OS versions table on the Software > OS tab, handling platform filtering, pagination, sorting, and row navigation to OS version detail pages.

## Key Components

- **`SoftwareOSTable`** — Default export. Main table component that wraps `TableContainer` with OS-specific configuration.
- **`PLATFORM_FILTER_OPTIONS`** — Static array defining available platform filter options (All, macOS, Windows, Linux, ChromeOS, iOS, iPadOS, Android).
- **`determineQueryParamChange`** — Detects which query parameter changed to enable selective page index resets.
- **`generateNewQueryParams`** — Builds the next URL query params, resetting to page 0 on non-page changes.
- **`onQueryChange`** — Handles table sort/page changes and updates the route via `router.replace`.
- **`handleRowSelect`** — Navigates to the OS version detail page (`SOFTWARE_OS_DETAILS`) on row click.
- **`renderPlatformDropdown`** — Renders the platform filter `DropdownWrapper` control injected into the table header.
- **`renderSoftwareCount`** — Renders item count and last-updated timestamp above the table.

## Usage Example

```typescript
import SoftwareOSTable from "pages/SoftwarePage/SoftwareOSTables/SoftwareOSTable";

<SoftwareOSTable
  router={router}
  isSoftwareEnabled={true}
  data={osVersionsResponse}
  perPage={20}
  orderDirection="asc"
  orderKey="name"
  currentPage={0}
  teamId={1}
  isLoading={false}
  platform="darwin"
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `router` | `InjectedRouter` | React Router instance for navigation |
| `isSoftwareEnabled` | `boolean` | Disables controls when software inventory is off |
| `data` | `IOSVersionsResponse` | OS versions payload from the API |
| `perPage` | `number` | Rows per page |
| `orderDirection` | `"asc" \| "desc"` | Current sort direction |
| `orderKey` | `string` | Current sort column key |
| `currentPage` | `number` | Active page index |
| `teamId` | `number?` | Scopes data to a specific Fleet team |
| `isLoading` | `boolean` | Shows loading state in the table |
| `platform` | `SelectedPlatform` | Active platform filter; defaults to `"all"` |
