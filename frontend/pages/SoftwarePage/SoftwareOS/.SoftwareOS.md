Renders the OS tab within the Software section by fetching and displaying operating system version data with pagination, sorting, and platform filtering support.

## Key Components

- **`SoftwareOS`** — Default export. React component that manages OS version data fetching and delegates rendering to `SoftwareOSTable`.
- **`ISoftwareOSProps`** — Interface defining required props: router, pagination controls (`perPage`, `currentPage`), sorting (`orderDirection`, `orderKey`), `platform`, optional `teamId`, and `isSoftwareEnabled` flag.
- **`useQuery`** — Fetches OS version data via `getOSVersions`, scoped under `"software-os"` with 30-second stale time and `keepPreviousData` enabled for smooth pagination.

## Usage Example

```typescript
import SoftwareOS from "./SoftwareOS";

<SoftwareOS
  router={router}
  isSoftwareEnabled={true}
  perPage={20}
  orderDirection="asc"
  orderKey="name"
  currentPage={0}
  teamId={1}
  platform="darwin"
/>
```

## Behavior Notes

- Shows `<Spinner />` while the initial data load is in progress (`isLoading`).
- Shows `<TableDataError />` if the query fails.
- Passes `isFetching` (not `isLoading`) to `SoftwareOSTable` so in-progress pagination/sort refetches reflect as table-level loading rather than a full-page spinner.
- When `platform` is `"all"`, it is normalized to `undefined` before being sent as a query parameter.
- Caps vulnerability display at `max_vulnerabilities: 3` per OS entry.
