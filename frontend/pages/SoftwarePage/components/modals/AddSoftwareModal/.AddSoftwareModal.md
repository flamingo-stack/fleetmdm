A modal component that handles software addition restrictions, displaying contextual messages based on tier and team selection state.

## Key Components

- **`AddSoftwareModal`** — Primary exported modal component that renders one of two gating messages depending on the `isFreeTier` flag
- **`AllTeamsMessage`** — Internal sub-component displayed when "All teams" is selected, prompting the user to select a specific team before adding software
- **`IAddSoftwareModalProps`** — Interface accepting `onExit` callback and optional `isFreeTier` boolean
- **`IAllTeamsMessageProps`** — Interface for the internal `AllTeamsMessage` sub-component

## Behavior

| Condition | Rendered Content |
|---|---|
| `isFreeTier === true` | `PremiumFeatureMessage` + Close button |
| `isFreeTier` is `false`/`undefined` | "All teams" selection warning + Close button |

## Usage Example

```typescript
import AddSoftwareModal from "components/AddSoftwareModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);
  const isFreeTier = !currentUser?.isPremium;

  return (
    <>
      {showModal && (
        <AddSoftwareModal
          onExit={() => setShowModal(false)}
          isFreeTier={isFreeTier}
        />
      )}
    </>
  );
};
```

## Notes

- The component does not render a form for actually adding software — it exclusively handles the two restricted/gating states
- Actual software addition logic should be implemented in a parent or sibling component once the user has a valid team context and a premium tier
