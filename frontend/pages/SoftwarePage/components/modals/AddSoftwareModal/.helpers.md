Utility file for generating user-facing error messages during upload operations.

## Key Components

- **`getErrorMessage(err: unknown): string`** — Extracts a readable error message from an unknown error value. Returns the raw string if the input is already a string, falls back to `getErrorReason`, and defaults to a generic upload failure message if no reason is found.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await uploadFile(file);
} catch (err) {
  const message = getErrorMessage(err);
  console.error(message); // "Couldn't add. Please try again."
}
```

## Notes

- Depends on [`getErrorReason`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/errors.ts) from the shared `interfaces/errors` module.
- The default fallback message is `"Couldn't add. Please try again."` defined via `UPLOAD_ERROR_MESSAGES`.
