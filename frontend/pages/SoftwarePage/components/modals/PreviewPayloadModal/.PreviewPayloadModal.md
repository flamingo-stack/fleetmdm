A modal component that displays an example webhook payload for Fleet's software vulnerability automations, with tier-aware field visibility.

## Key Components

### Interfaces
- **`IPreviewPayloadModalProps`** — Accepts an `onCancel` callback to close the modal
- **`IHostsAffected`** — Shape of host objects within the payload (`id`, `display_name`, `url`, `software_installed_paths`)
- **`IWebhookPayload`** — Extends `ISoftwareVulnerability` with an optional `hosts_affected` array
- **`IJsonPayload`** — Top-level payload structure with `timestamp` and `vulnerability` fields

### Component: `PreviewPayloadModal`
Renders a syntax-highlighted JSON preview of a vulnerability webhook payload. Reads `isFreeTier` from `AppContext` and strips premium-only fields (`epss_probability`, `cvss_score`, `cisa_known_exploit`, `cve_published`) when on the free tier.

## Usage Example

```typescript
import PreviewPayloadModal from "components/PreviewPayloadModal";

const MyComponent = () => {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowModal(true)}>Preview Payload</Button>
      {showModal && (
        <PreviewPayloadModal onCancel={() => setShowModal(false)} />
      )}
    </>
  );
};
```

## Notes

- Uses `syntaxHighlight` utility to render formatted JSON via `dangerouslySetInnerHTML`
- Free tier users see a reduced payload — premium vulnerability intel fields are removed at render time
- Links to `fleetdm.com/docs/using-fleet/automations` for automation documentation
