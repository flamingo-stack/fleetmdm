Renders a preview modal showing the end-user self-service experience for software installers, including category visibility and install status, as it would appear to device users.

## Key Components

### `CategoriesEndUserExperienceModal` (default export)
The main modal component. Fetches self-service categories scoped to a team and renders a `SelfServicePreview` with a software icon and a sample software table.

**Props:**

| Prop | Type | Description |
|---|---|---|
| `onCancel` | `() => void` | Callback to close the modal |
| `teamId` | `number` | Scopes the categories API query |
| `isIosOrIpadosApp` | `boolean` | Adjusts preview for iOS/iPadOS apps |
| `name` | `string` | Software name (defaults to `"Software name"`) |
| `displayName` | `string` | Display name shown in UI |
| `iconUrl` | `string \| null` | Software icon URL |
| `source` | `string` | Software source type |
| `mobileVersion` | `string` | Version label for mobile apps |

### `BasicSoftwareTable` (named export)
Renders a read-only `TableContainer` with 3 rows: the current software (never installed) plus up to 2 example apps (installed), simulating the self-service software list.

**Props:** `name`, `displayName`, `source`, `iconUrl`, `previewIcon`

### `getData()`
Builds the table row data, filtering `EXAMPLE_SOFTWARE_ROWS` (`Adobe Acrobat Reader`, `Box Drive`) to avoid duplicating the current software entry.

### Cell Components
- **`InstalledCell`** — Renders a green success icon with "Installed" label
- **`NeverInstalledCell`** — Renders the default empty cell value

## Usage Example

```typescript
<CategoriesEndUserExperienceModal
  onCancel={() => setShowModal(false)}
  teamId={currentTeamId}
  name="Slack"
  displayName="Slack"
  iconUrl="https://example.com/slack-icon.png"
  source="apps"
  isIosOrIpadosApp={false}
/>
```

> **Note:** This modal is currently only shown from the edit software UI. Users can set categories only when editing an existing installer, not when adding a new one.
