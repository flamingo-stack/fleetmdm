Test suite for the `SoftwareFiltersModal` component, validating rendering, field state toggling, CVSS score validation, form submission, and severity dropdown behavior.

## Key Components

- **`renderModal`** — Helper that renders `SoftwareFiltersModal` with default vulnerability filter props via RTL's `render`.
- **`vulnFiltersDefault`** — Shared fixture with all filters disabled and CVSS scores unset.
- **Test suites** — Five `it` blocks covering the full interactive lifecycle of the modal.

## Test Coverage

| Test Case | Description |
|---|---|
| Renders modal fields | Verifies title, toggles, score inputs, exploit checkbox, and action buttons are present |
| Disabled state | Confirms dropdown, min/max inputs, and exploit checkbox are disabled when `vulnerable` is `false` |
| Enabled state | Toggling the switch enables all dependent fields |
| Validation errors | Out-of-range scores (>10, <0, >1 decimal), non-numeric input, and min > max trigger error messages and disable Apply |
| Form submission | Valid inputs call `onSubmit` with correctly typed numeric CVSS values and boolean flags |
| Severity dropdown reset | Clearing both score inputs resets the dropdown to "Any severity" |

## Usage Example

```typescript
// Run the test suite
import { renderWithSetup } from "test/test-utils";

const { user } = renderWithSetup(
  <SoftwareFiltersModal
    onExit={noop}
    onSubmit={onSubmitSpy}
    vulnFilters={{ vulnerable: false, exploit: false, minCvssScore: undefined, maxCvssScore: undefined }}
    isPremiumTier
  />
);

// Toggle vulnerability filter on
await user.click(screen.getByRole("switch"));

// Enter CVSS range and submit
await user.type(screen.getByLabelText(/Min score/i), "3");
await user.type(screen.getByLabelText(/Max score/i), "8.5");
await user.click(screen.getByRole("button", { name: /Apply/i }));
// onSubmitSpy called with { vulnerable: true, exploit: false, minCvssScore: 3, maxCvssScore: 8.5 }
```
