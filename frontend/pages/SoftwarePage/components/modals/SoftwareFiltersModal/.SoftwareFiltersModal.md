A modal dialog component for filtering software inventory by vulnerability-related criteria, including CVSS severity scores and known exploit status.

## Key Components

**Props (`ISoftwareFiltersModalProps`)**
- `onExit` — callback to close the modal
- `onSubmit` — callback receiving the applied `ISoftwareVulnFiltersParams`
- `vulnFilters` — current filter state used to pre-populate form fields
- `isPremiumTier` — gates severity/exploit filters behind a premium feature flag

**Internal State**
- `vulnSoftwareFilterEnabled` — toggles the vulnerable software slider
- `severity` — selected severity dropdown option (any / named range / custom)
- `formData` — unified `{ minScore, maxScore }` string state for CVSS inputs
- `hasKnownExploit` — checkbox state for known-exploit filter

**Validation (`validate`)**
- Enforces CVSS scores between `0`–`10` in `0.1` increments
- Disables the Apply button when `minScore > maxScore`, displaying a tooltip error

**`onChangeSeverity`** — syncs the CVSS range inputs when a preset severity option is selected; preserves free-form input for the "Custom" option.

**`onScoreChange`** — updates form state on manual CVSS input, resets to "Any severity" when both fields are cleared, and auto-matches a preset option when values align.

## Usage Example

```typescript
<SoftwareFiltersModal
  onExit={() => setShowFilters(false)}
  onSubmit={(filters) => updateQueryParams(filters)}
  vulnFilters={{
    vulnerable: true,
    minCvssScore: 7.0,
    maxCvssScore: 10.0,
    exploit: false,
  }}
  isPremiumTier={true}
/>
```

**Notes:**
- Severity and exploit filters render only for `isPremiumTier` users
- Setting CVSS range to `0–10` clears the score params on submit (treated as "any")
- The Apply button is tooltip-wrapped to surface validation errors inline
