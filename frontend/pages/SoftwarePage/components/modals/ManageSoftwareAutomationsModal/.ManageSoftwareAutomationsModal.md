Modal component for managing software vulnerability automation settings, supporting webhook URLs and Jira/Zendesk ticket integrations with enable/disable controls.

## Key Components

### Types & Interfaces

- **`ISoftwareAutomations`** — Form data shape containing `webhook_settings` and `integrations` (Jira/Zendesk arrays)
- **`IManageSoftwareAutomationsModalProps`** — Props including router, submit handler, preview modal toggles, and `softwareConfig`
- **`isGlobalSWConfig`** — Type guard distinguishing `IConfig` from `ITeamConfig` by checking for the `"vulnerabilities"` key

### Core Logic

- **`validateWebhookURL`** — Validates destination URL presence and format; returns `{ valid, errors }`
- **`readyForSubmission`** — Builds the final `ISoftwareAutomations` payload based on the enabled automation type (disabled / webhook / integration), toggling the correct flags across Jira and Zendesk arrays
- **`createIntegrationDropdownOptions`** — Maps indexed integrations to `{ value, label }` options for the dropdown

### State

| State | Purpose |
|---|---|
| `softwareAutomationsEnabled` | Master toggle for all vulnerability automations |
| `integrationEnabled` | Switches between webhook mode and ticket integration mode |
| `selectedIntegration` | Currently active Jira or Zendesk integration |
| `destinationUrl` / `errors` | Webhook URL field value and validation errors |
| `allIntegrationsIndexed` | Merged Jira + Zendesk list with `dropdownIndex` for dropdown mapping |

## Usage Example

```typescript
<ManageAutomationsModal
  router={router}
  onCancel={() => setShowModal(false)}
  onCreateWebhookSubmit={(formData) => handleSave(formData)}
  togglePreviewPayloadModal={togglePreviewPayloadModal}
  togglePreviewTicketModal={togglePreviewTicketModal}
  showPreviewPayloadModal={showPreviewPayloadModal}
  showPreviewTicketModal={showPreviewTicketModal}
  softwareConfig={teamConfig ?? globalConfig}
/>
```

> **GitOps mode:** When `gitOpsModeEnabled` is `true`, save controls are wrapped in `GitOpsModeTooltipWrapper` and disabled. Recent vulnerability max age is read from `softwareConfig` (team) or the global `AppContext` config and converted from nanoseconds to days for display.
