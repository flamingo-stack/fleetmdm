A modal component that displays a preview screenshot of an automatically generated ticket (Jira or Zendesk) for vulnerability software automations, with tier-aware image selection.

## Key Components

- **`PreviewTicketModal`** — Default export; renders a `Modal` with a static ticket screenshot and a link to Fleet automation docs
- **`IPreviewTicketModalProps`** — Interface defining:
  - `onCancel: () => void` — Callback for closing the modal
  - `integrationType: IIntegrationType` — Determines which integration screenshot to display (`"jira"` or `"zendesk"`)
- **Tier-aware images** — Selects between standard and premium preview assets based on `isPremiumTier` from `AppContext`

## Usage Example

```typescript
import PreviewTicketModal from "./PreviewTicketModal";

<PreviewTicketModal
  integrationType="jira"
  onCancel={() => setShowPreview(false)}
/>
```

## Notes

- Uses `AppContext` to detect premium tier and swap preview images accordingly
- Four static image assets are bundled: Jira/Zendesk × standard/premium
- Links to `https://fleetdm.com/docs/using-fleet/automations` for further reading
- Responds to both `onExit` (click/escape) and `onEnter` (Enter key) with the same `onCancel` handler
