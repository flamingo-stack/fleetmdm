Renders a table cell displaying software version information, handling empty, single, and multiple version states with appropriate tooltip behavior.

## Key Components

- **`IVersionCellProps<T>`** — Generic interface requiring a `versions` array of objects with a `version: string` field (or `null`)
- **`VersionCell`** — Generic React component with three rendering branches:
  - **Empty/null** — Renders a grey `TextCell` with the default empty cell placeholder
  - **Single version** — Renders a `TooltipTruncatedTextCell` to handle overflow gracefully
  - **Multiple versions** — Renders an italic `TextCell` showing `"N versions"` with a tooltip listing all versions joined by commas

## Usage Example

```typescript
interface ISoftwareVersion {
  version: string;
  id: number;
}

// Empty state
<VersionCell<ISoftwareVersion> versions={null} />

// Single version
<VersionCell<ISoftwareVersion> versions={[{ version: "1.2.3", id: 1 }]} />

// Multiple versions — shows "3 versions" with tooltip
<VersionCell<ISoftwareVersion>
  versions={[
    { version: "1.2.3", id: 1 },
    { version: "1.2.4", id: 2 },
    { version: "1.3.0", id: 3 },
  ]}
/>
```

## Notes

- The generic constraint `T extends { version: string }` allows the component to accept richer version objects without sacrificing type safety.
