A table cell component that displays software vulnerability counts with an interactive tooltip listing individual CVEs.

## Key Components

- **`VulnerabilitiesCell`** — Main exported component; renders a `TextCell` wrapped in a `TooltipWrapper` when multiple vulnerabilities exist
- **`generateCell`** — Renders the cell text: `"---"` for no vulnerabilities, the CVE identifier for a single hit, or `"N vulnerabilities"` for multiple
- **`generateTooltip`** — Builds a `<ul>` list of up to `NUM_VULNERABILITIES_IN_TOOLTIP` (3) CVEs, appending a `"+N more"` item when the total exceeds that limit
- **`condenseVulnerabilities`** — Slices, reverses, and optionally appends an overflow label to keep the tooltip concise
- **`getName`** — Normalizes a vulnerability entry (either a raw `string` or an `ISoftwareVulnerability`) to its CVE string

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `vulnerabilities` | `ISoftwareVulnerability[] \| string[] \| null` | — | List of vulnerabilities to display |
| `vulnerabilitiesCount` | `number?` | `vulnerabilities.length` | Override total count (e.g. from paginated API) |
| `tooltipPosition` | `PlacesType` | `"top"` | Tooltip placement via `react-tooltip-5` |

## Usage Example

```typescript
import VulnerabilitiesCell from "components/TableContainer/DataTable/VulnerabilitiesCell";

// No vulnerabilities
<VulnerabilitiesCell vulnerabilities={null} />

// Single CVE — renders plain text, no tooltip
<VulnerabilitiesCell vulnerabilities={[{ cve: "CVE-2024-1234" }]} />

// Multiple CVEs — renders "3 vulnerabilities" with tooltip listing them
<VulnerabilitiesCell
  vulnerabilities={[
    { cve: "CVE-2024-0001" },
    { cve: "CVE-2024-0002" },
    { cve: "CVE-2024-0003" },
  ]}
  vulnerabilitiesCount={10}
  tooltipPosition="bottom"
/>
```

> When `vulnerabilitiesCount` exceeds the local array length (e.g. server-side pagination), the tooltip appends `"+N more"` to reflect the true total while only listing the available entries.
