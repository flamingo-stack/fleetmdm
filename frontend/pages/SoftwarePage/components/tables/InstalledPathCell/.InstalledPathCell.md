A React table cell component that renders installed file paths for software versions, handling three display states based on the number of unique paths found.

## Key Components

- **`InstalledPathCell`** — Default export. Accepts installed version data and a callback, then renders one of three UI states:
  - **Empty state** — Grey `TextCell` with a default placeholder when `installedVersion` is `null` or no paths exist
  - **Single path** — `TooltipTruncatedTextCell` displaying the lone path with truncation and tooltip support
  - **Multiple paths** — A link `Button` showing the count (e.g., `"3 paths"`) that triggers the `onClickMultiplePaths` callback

## Props

| Prop | Type | Description |
|------|------|-------------|
| `installedVersion` | `ISoftwareInstallVersion[] \| null` | Array of software install version objects, each containing optional `installed_paths` |
| `onClickMultiplePaths` | `() => void` | Callback fired when the user clicks the multi-path count button |

## Usage Example

```typescript
import InstalledPathCell from "components/TableContainer/DataTable/InstalledPathCell";

<InstalledPathCell
  installedVersion={[
    { installed_paths: ["/usr/local/bin/app"] },
    { installed_paths: ["/opt/homebrew/bin/app", "/usr/local/bin/app"] },
  ]}
  onClickMultiplePaths={() => setShowPathsModal(true)}
/>
```

## Path Deduplication Logic

Paths are collected via `flatMap` across all version entries and deduplicated using a `Set`, ensuring the count and display reflect only **unique** install paths regardless of how many version records reference the same location.
