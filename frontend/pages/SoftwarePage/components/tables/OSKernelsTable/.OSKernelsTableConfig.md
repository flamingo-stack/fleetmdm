Generates the column configuration for the OS Kernels table, defining headers and cell renderers for version, vulnerabilities, host count, and host navigation columns.

## Key Components

- **`generateTableConfig`** – Default export. Accepts `teamId`, `osName`, and `osVersion` props and returns a `react-table` column definition array.
- **Column definitions:**
  - `version` – Renders a `LinkCell` navigating to the software version details page (via `PATHS.SOFTWARE_VERSION_DETAILS`), or an empty `TextCell` if no value exists.
  - `vulnerabilities` – Renders a `VulnerabilitiesCell` with the CVE list for the kernel version.
  - `hosts_count` – Renders a `TextCell` with a tooltip header noting that Linux hosts may have multiple kernels and containers have none.
  - `linkToFilteredHosts` – Renders a `ViewAllHostsLink` passing `software_version_id`, `fleet_id`, `os_name`, and `os_version` as query params to filter the hosts view.

## Usage Example

```typescript
import generateTableConfig from "./OSKernelsTableConfig";

const columns = generateTableConfig({
  teamId: 42,
  osName: "Ubuntu",
  osVersion: "22.04",
});

// Pass to a TableContainer or react-table instance
<TableContainer
  columns={columns}
  data={kernelRows}
/>
```

## Notes

- All columns have `disableSortBy: true`; sorting is not supported in this table.
- The `version` link appends `fleet_id` as a query parameter via `getPathWithQueryParams`.
- The `linkToFilteredHosts` column renders no header, appearing as a row-level action link on hover (`rowHover`).
