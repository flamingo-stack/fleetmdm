Renders the OS kernels table for Linux operating systems within the `software/os/:id` detail view, displaying kernel versions and their associated host counts with CVE-based row navigation.

## Key Components

### `OSKernelsTable` (default export)
Main table component that wraps `TableContainer` with kernel-specific configuration.

**Props (`ISoftwareVulnerabilitiesTableProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `osName` | `string` | Operating system name passed to table config |
| `osVersion` | `string` | OS version passed to table config |
| `data` | `IOperatingSystemKernels[]` | Kernel records to display |
| `isLoading` | `boolean` | Loading state for the table |
| `router` | `InjectedRouter` | Router instance for CVE navigation |
| `teamIdForApi` | `number` (optional) | Team ID for scoped API requests |
| `className` | `string` (optional) | Additional CSS class |

### `NoKernelsDetected`
Internal empty state component rendered when no kernel data is available, with a GitHub issue link for unexpected cases.

### `handleRowSelect`
Navigates to the software vulnerability details page (`PATHS.SOFTWARE_VULNERABILITY_DETAILS`) when a row with a `cve` field is clicked, appending `fleet_id` as a query parameter.

## Usage Example

```typescript
import OSKernelsTable from "./OSKernelsTable";

<OSKernelsTable
  osName="Ubuntu"
  osVersion="22.04"
  data={kernelsData}
  isLoading={isFetching}
  router={router}
  teamIdForApi={3}
/>
```

## Notes

- Client-side pagination (20 rows/page) and filtering are enabled.
- Row selection is disabled when `cve` is absent on the row.
- Table header is hidden when `data` is empty.
