Defines and exports the column configuration for the Software Vulnerabilities data table, mapping CVE data fields to sortable, tooltip-enhanced header and cell renderers.

## Key Components

### `generateTableConfig(isPremiumTier, router, teamId)`

Factory function returning an array of `IDataColumn` column definitions. Filters out premium-only columns (`epss_probability`, `cve_published`, `cvss_score`) when `isPremiumTier` is `false`.

### Column Definitions

| Accessor | Title | Premium Only | Notes |
|---|---|---|---|
| `cve` | Vulnerability | No | Links to `/software/vulnerabilities/:cve` with optional `fleet_id` query param |
| `cvss_score` | Severity | Yes | Formats score via `formatSeverity`; CVSS v3.x base score tooltip |
| `epss_probability` | Probability of Exploit | Yes | Renders `ProbabilityOfExploit` component with EPSS + CISA known exploit data |
| `cve_published` | Published | Yes | NVD publish date via `HumanTimeDiffWithDateTip` |
| `created_at` | Detected | No | Date vulnerability first appeared on a host |
| `linkToFilteredHosts` | _(empty)_ | No | Renders `ViewAllHostsLink` filtered by CVE and team |

### Interfaces

- **`IHeaderProps`** — Props for sortable header cells (`title`, `isSortedDesc`)
- **`ICellProps`** — Props for row cells with access to `cell.value` and `row.original` (`ISoftwareVulnerability`)
- **`IDataColumn`** — Full column shape including optional `disableSortBy`, `sortType`, `disableHidden`

## Usage Example

```typescript
import generateTableConfig from "./SoftwareVulnerabilitiesTableConfig";

const columns = generateTableConfig(
  isPremiumTier,
  router,
  teamId // optional; appended as fleet_id query param
);

// Pass to TableContainer
<TableContainer columns={columns} data={vulnerabilities} />
```
