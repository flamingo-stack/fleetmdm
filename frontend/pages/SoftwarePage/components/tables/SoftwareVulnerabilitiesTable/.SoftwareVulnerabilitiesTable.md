Renders a paginated table of software vulnerabilities for a given software version or OS, with row-click navigation to CVE detail pages.

## Key Components

| Export | Type | Description |
|---|---|---|
| `SoftwareVulnerabilitiesTable` | Default export | Main table component displaying CVE vulnerability data |
| `VulnsNotSupported` | Named export | Empty state shown when the host platform doesn't support vulnerability scanning |
| `NoVulnsDetected` | Internal component | Empty state shown when no CVEs are found for the software item |

## Usage Example

```typescript
import SoftwareVulnerabilitiesTable, {
  VulnsNotSupported,
} from "./SoftwareVulnerabilitiesTable";

// Render the vulnerabilities table
<SoftwareVulnerabilitiesTable
  data={vulnerabilities}
  itemName="software version"
  isLoading={isLoading}
  router={router}
  teamIdForApi={currentTeamId}
/>

// Render unsupported platform state
<VulnsNotSupported platformText="Linux" />
```

## Key Behaviors

- **Row navigation**: Clicking a row routes to `PATHS.SOFTWARE_VULNERABILITY_DETAILS(cveName)` with an optional `fleet_id` query param derived from `teamIdForApi`.
- **Sort defaults**: Premium tier sorts by `updated_at` descending; free tier sorts by `cve`.
- **Column config**: Table headers are memoized via `generateTableConfig`, which receives `isPremiumTier`, `router`, and `teamIdForApi` — premium tier exposes additional columns.
- **Pagination**: Client-side, fixed at 20 rows per page.
- **Empty states**: Table header is hidden (`disableTableHeader`) when `data.length === 0`.
