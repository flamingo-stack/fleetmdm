A table cell component for displaying SHA-256 hash values associated with installed software versions, supporting copy-to-clipboard, truncated display, and multi-hash navigation.

## Key Components

- **`HashCell`** — Default export; renders one of three states based on the number of unique SHA-256 hashes found across all `signature_information` entries in the installed versions
- **`renderHash`** — Internal helper that displays a truncated hash (first 7 chars + ellipsis) alongside a copy icon button with a transient "Copied!" / "Copy failed" overlay message
- **`onCopySha256`** — Curried click handler that writes the full hash to the clipboard and clears the status message after 1 second
- **`IHashCellProps`** — Props interface accepting `installedVersion` (`ISoftwareInstallVersion[] | null`) and `onClickMultipleHashes` callback

## Render States

| Condition | Output |
|---|---|
| `null` or 0 unique hashes | `TextCell` with default empty value (`—`) |
| Exactly 1 unique hash | Truncated hash with copy button |
| 2+ unique hashes | Link button showing `"{n} hashes"` |

## Usage Example

```typescript
import HashCell from "components/TableContainer/DataTable/HashCell";

<HashCell
  installedVersion={software.installed_versions}
  onClickMultipleHashes={(software) => {
    setSelectedSoftware(software);
    setShowHashModal(true);
  }}
/>
```
