Utility helpers for validating and processing VPP (Volume Purchase Program) software form data in the `SoftwareVppForm` component.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `getUniqueAppId` | Function | Generates a unique identifier for a VPP app by combining `app_store_id` and `platform` |
| `generateFormValidation` | Function | Runs all configured validations against form data and returns an `IFormValidation` result object |
| `FORM_VALIDATION_CONFIG` | Internal constant | Declares validation rules per form field; currently validates `customTarget` requires at least one label when not targeting "All hosts" |

## Usage Example

```typescript
import { getUniqueAppId, generateFormValidation } from "./helpers";

// Generate a stable unique key for a VPP app
const appId = getUniqueAppId({ app_store_id: "123456789", platform: "ios" });
// → "123456789_ios"

// Validate form data before submission
const formData: ISoftwareVppFormData = {
  targetType: "Custom",
  labelTargets: { "label-1": true, "label-2": false },
};

const validation = generateFormValidation(formData);

if (!validation.isValid) {
  console.log("Custom target validation failed:", validation.customTarget);
  // → { isValid: false }
}
```

## Validation Rules

| Field | Rule |
|-------|------|
| `customTarget` | When `targetType` is not `"All hosts"`, at least one entry in `labelTargets` must be `true` |
