Form component for adding or editing VPP (Volume Purchase Program) Apple App Store apps within Fleet's software management workflow.

## Key Components

### Exported Component
- **`SoftwareVppForm`** — Main form component supporting two modes: adding a new VPP app (renders a selectable app list) and editing an existing VPP app (renders configuration options for the selected app)

### Internal Components
- **`VppAppList`** — Renders a scrollable list of available VPP apps
- **`VppAppListItem`** — Individual app row with radio selection, icon, name, and platform label

### Exported Types
- **`ISoftwareVppFormData`** — Form state shape including `selfService`, `automaticInstall`, `targetType`, `customTarget`, `labelTargets`, `selectedApp`, and `categories`
- **`IFormValidation`** — Validation state with `isValid` flag and optional `customTarget` validation

## Usage Example

```typescript
<SoftwareVppForm
  labels={labels}
  vppApps={availableApps}
  onSubmit={(formData) => handleAddVppApp(formData)}
  onCancel={() => setShowForm(false)}
  onClickPreviewEndUserExperience={(isIosOrIpadosApp) =>
    openPreviewModal(isIosOrIpadosApp)
  }
  teamId={currentTeam?.id}
/>

// Edit mode — pass softwareVppForEdit to pre-populate form
<SoftwareVppForm
  labels={labels}
  softwareVppForEdit={existingApp}
  onSubmit={(formData) => handleSaveVppApp(formData)}
  onCancel={() => setShowForm(false)}
  onClickPreviewEndUserExperience={(isIosOrIpadosApp) =>
    openPreviewModal(isIosOrIpadosApp)
  }
  teamId={currentTeam?.id}
/>
```

## Notes
- iOS/iPadOS apps automatically disable `selfService` and `automaticInstall` toggles, as those features are unsupported on mobile platforms
- Submit is disabled until a VPP app is selected (add mode) or form validation passes (edit mode)
- GitOps mode disables form inputs via `GitOpsModeTooltipWrapper`
