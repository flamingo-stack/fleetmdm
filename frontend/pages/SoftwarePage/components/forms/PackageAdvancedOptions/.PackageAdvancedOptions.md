Renders the collapsible "Advanced options" section of the package form, providing package-type-aware install, post-install, and uninstall script fields with contextual help text and tooltips.

## Key Components

### Helper Functions
- **`getSupportedScriptTypeText(pkgType)`** — Returns shell/PowerShell support disclaimer based on OS type
- **`getInstallScriptTooltip(pkgType)`** — Returns required-field tooltip for `.exe`, `.tar.gz`, and Windows `.zip` packages
- **`getInstallHelpText(pkgType)`** — Returns JSX help text with `$INSTALLER_PATH` guidance and learn-more links
- **`getUninstallScriptTooltip(pkgType)`** — Mirror of install tooltip logic for the uninstall script field
- **`getUninstallHelpText(pkgType)`** — Returns JSX help text with `$PACKAGE_ID`/`$UPGRADE_CODE` population details per package type

### Constants
- **`PKG_TYPE_TO_ID_TEXT`** — Maps each `PackageType` to the human-readable identifier name used in uninstall help text (e.g., `msi → "product code"`)

### Component
- **`PackageAdvancedOptions`** — Wraps `AdvancedOptionsFields` in a `RevealButton` accordion; auto-expands and disables the toggle for `.exe`, `.zip`, and `.tar.gz` packages where scripts are required

## Usage Example

```typescript
<PackageAdvancedOptions
  errors={{ preInstallQuery: undefined }}
  selectedPackage={formData.software}
  installScript={installScript}
  preInstallQuery={preInstallQuery}
  postInstallScript={postInstallScript}
  uninstallScript={uninstallScript}
  showSchemaButton
  onClickShowSchema={handleShowSchema}
  onChangePreInstallQuery={setPreInstallQuery}
  onChangeInstallScript={setInstallScript}
  onChangePostInstallScript={setPostInstallScript}
  onChangeUninstallScript={setUninstallScript}
  gitOpsModeEnabled={isGitOpsMode}
/>
```

## Notes

- The accordion is **force-expanded and non-collapsible** for `.exe`, `.zip`, and `.tar.gz` package types since scripts are mandatory for those formats
- When no package is selected, the reveal button is disabled with a tooltip prompting file selection
- `gitopsCompatible` is currently reserved for Fleet-maintained app (FMA) editing only
