Renders a set of advanced software installation configuration fields, including pre-install query, install script, post-install script, and uninstall script editors. Memoized to prevent unnecessary re-renders of the heavy editor components.

## Key Components

**`AdvancedOptionsFields`** — Default export (memoized React component)

| Prop | Type | Description |
|------|------|-------------|
| `showSchemaButton` | `boolean` | Toggles the "Schema" button on the pre-install query field |
| `installScriptTooltip` | `string?` | Tooltip for the install script label |
| `installScriptHelpText` | `ReactNode` | Help text rendered below the install script editor |
| `postInstallScriptHelpText` | `ReactNode` | Help text rendered below the post-install script editor |
| `uninstallScriptTooltip` | `string?` | Tooltip for the uninstall script label |
| `uninstallScriptHelpText` | `ReactNode` | Help text rendered below the uninstall script editor |
| `errors` | `object` | Validation errors for `preInstallQuery` and `postInstallScript` |
| `gitopsCompatible` | `boolean` | Whether the software item supports GitOps |
| `gitOpsModeEnabled` | `boolean` | Whether GitOps mode is active; combined with `gitopsCompatible` to make all fields read-only |
| `onClickShowSchema` | `() => void` | Callback when the Schema button is clicked |

**Field disable logic** — All editors become `readOnly` when both `gitopsCompatible` and `gitOpsModeEnabled` are `true`.

## Usage Example

```typescript
<AdvancedOptionsFields
  showSchemaButton={true}
  installScriptHelpText={<span>Default install script for .pkg packages.</span>}
  postInstallScriptHelpText={<span>Runs after installation completes.</span>}
  uninstallScriptHelpText={<span>Runs on software removal.</span>}
  errors={{ preInstallQuery: "Invalid SQL" }}
  preInstallQuery="SELECT * FROM osquery_info WHERE start_time > 1"
  installScript="#!/bin/bash\ninstaller -pkg $PACKAGE_PATH -target /"
  postInstallScript=""
  uninstallScript=""
  gitopsCompatible={true}
  gitOpsModeEnabled={false}
  onClickShowSchema={() => setShowSchema(true)}
  onChangePreInstallQuery={(val) => setPreInstallQuery(val)}
  onChangeInstallScript={(val) => setInstallScript(val)}
  onChangePostInstallScript={(val) => setPostInstallScript(val)}
  onChangeUninstallScript={(val) => setUninstallScript(val)}
/>
```
