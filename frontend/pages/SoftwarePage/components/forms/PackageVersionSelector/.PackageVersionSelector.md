A React component that renders a version selector dropdown for software packages, with tooltip guidance and GitOps-aware disabled state handling.

## Key Components

### `PackageVersionSelector`
The default export. A controlled dropdown component that:
- Returns `null` when no version options are available
- Disables all non-selected versions (temporary restriction while version selection via UI is unsupported)
- Wraps the dropdown in a `TooltipWrapper` when multiple versions exist and GitOps mode is inactive, providing contextual guidance on rollback/update limitations
- Disables the entire dropdown in GitOps mode

### `disableAllUIOptions` (internal)
A helper that marks all version options as disabled except the currently selected one, enforcing the current limitation that version changes must go through GitOps.

### `IPackageVersionSelectorProps`
| Prop | Type | Description |
|------|------|-------------|
| `versionOptions` | `CustomOptionType[]` | Available versions to display |
| `selectedVersion` | `string` | Currently selected version value |
| `onSelectVersion` | `(version: string) => void` | Callback when a version is chosen |
| `isGitOpsMode` | `boolean` | Disables the dropdown when GitOps is active |
| `className` | `string?` | Optional additional CSS class |

## Usage Example

```typescript
import PackageVersionSelector from "components/PackageVersionSelector";

const versionOptions = [
  { label: "1.2.0 (latest)", value: "1.2.0" },
  { label: "1.1.0", value: "1.1.0" },
];

<PackageVersionSelector
  versionOptions={versionOptions}
  selectedVersion="1.2.0"
  onSelectVersion={(version) => console.log("Selected:", version)}
  isGitOpsMode={false}
/>
```

> **Note:** All non-selected versions are currently disabled in the UI. Version switching is only supported via GitOps. See [`PackageVersionSelector.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/PackageVersionSelector.tsx) for the temporary `disableAllUIOptions` override.
