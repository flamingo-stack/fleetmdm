Test suite for the `PackageVersionSelector` component, verifying rendering behavior, dropdown option states, and tooltip content across various version selection and GitOps mode scenarios.

## Key Components

- **`PackageVersionSelector`** — The component under test, which renders a version picker UI for software packages
- **`renderWithSetup`** — Custom test utility that provides a `user` event object for simulating interactions
- **Test scenarios covered:**
  - Null render when no version options exist
  - Plain label display with a single version option
  - Dropdown rendering with multiple versions
  - Option disabled states (only the selected option remains enabled)
  - Rollback tooltip (shown when latest is selected, not in GitOps mode)
  - No tooltip in GitOps mode
  - Update-to-latest tooltip (shown when a non-latest version is selected)

## Usage Example

```typescript
// Render with multiple versions and simulate dropdown interaction
const { user } = renderWithSetup(
  <PackageVersionSelector
    selectedVersion="2.0.0"
    versionOptions={[
      { value: "2.0.0", label: "Latest (2.0.0)" },
      { value: "1.0.0", label: "1.0.0" },
    ]}
    onSelectVersion={noop}
  />
);

// Open the dropdown
await user.click(screen.getByRole("combobox"));

// Assert non-selected options are disabled
const oldOption = screen
  .getAllByTestId("dropdown-option")
  .find((el) => el.textContent === "1.0.0")
  ?.closest(".react-select__option");

expect(oldOption).toHaveAttribute("aria-disabled", "true");
```

## Notes

- The component suppresses its own tooltip when `isGitOpsMode` is `true` — the parent component is expected to handle GitOps-related messaging in that case
- Tooltip text differentiates between rollback (latest selected) and update-to-latest (older version selected) workflows
