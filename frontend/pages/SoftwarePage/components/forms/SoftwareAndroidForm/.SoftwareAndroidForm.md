A React form component for adding Android applications to the Fleet MDM software catalog via Google Play Store application IDs.

## Key Components

### Interfaces

- **`ISoftwareAndroidFormData`** — Form state shape including `applicationID`, `selfService`, `automaticInstall`, `targetType`, `customTarget`, `labelTargets`, `categories`, and `platform: "android"`
- **`IFormValidation`** — Simple validation state with an `isValid` boolean
- **`ISoftwareAndroidFormProps`** — Component props including optional `softwareAndroidForEdit`, `onSubmit`, `isLoading`, and `onCancel`

### Behavior

- Initializes form state from an existing `IAppStoreApp` (edit mode) or empty defaults (add mode)
- Submit is disabled until a valid `applicationID` is entered
- Displays a yellow `InfoBanner` warning when the entered application ID matches an Android web app pattern, noting Chrome is required
- Respects GitOps mode via `useGitOpsMode`, disabling inputs and wrapping the submit button with `GitOpsModeTooltipWrapper`
- Edit mode (`softwareAndroidForEdit`) renders `null` for form content — edit functionality is not yet implemented (noted as 4.77 limitation)

## Usage Example

```typescript
import SoftwareAndroidForm, {
  ISoftwareAndroidFormData,
} from "./SoftwareAndroidForm";

const handleSubmit = (formData: ISoftwareAndroidFormData) => {
  console.log("Application ID:", formData.applicationID);
  // e.g. "com.android.chrome"
};

<SoftwareAndroidForm
  onSubmit={handleSubmit}
  onCancel={() => setShowForm(false)}
  isLoading={false}
/>;
```
