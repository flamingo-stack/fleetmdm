A React component that renders software installation options (self-service toggle and category assignment) for the Fleet MDM software management forms, supporting VPP, package, Fleet-maintained, and Android app types.

## Key Components

### `SoftwareOptionsSelector` (default export)
The main component that renders a self-service toggle slider and conditionally displays a `CategoriesSelector` when editing software with self-service enabled.

**Props:**
- `formData` — union of form data types (`IFleetMaintainedAppFormData | ISoftwareVppFormData | IPackageFormData | ISoftwareAndroidFormData`)
- `onToggleSelfService` — callback to toggle the self-service slider
- `onSelectCategory` — callback for category checkbox changes
- `onClickPreviewEndUserExperience` — opens a preview modal/panel
- `teamId?` — when provided, fetches categories dynamically from the API
- `isIpaPackage?` — disables self-service selection for IPA packages
- `isEditingSoftware?` — gates category selector visibility
- `disableOptions?` — disables all controls (default: `false`)

### `CategoriesSelector` (internal)
Renders a list of checkboxes for assigning software to self-service categories. Fetches categories dynamically via `selfServiceCategoriesAPI.getCategories` when `teamId` is provided; falls back to the hardcoded `CATEGORIES_ITEMS` list otherwise. Handles loading, error, and empty states.

### `AndroidOptionsDescription` (named export)
A static description paragraph for Android apps, noting Play Store installation behavior and linking to the Setup experience page.

## Usage Example

```typescript
<SoftwareOptionsSelector
  formData={formData}
  platform="darwin"
  isEditingSoftware
  teamId={42}
  onToggleSelfService={() => setFormData((prev) => ({
    ...prev,
    selfService: !prev.selfService,
  }))}
  onSelectCategory={({ name, value }) => handleCategoryChange(name, value)}
  onClickPreviewEndUserExperience={() => setShowPreview(true)}
/>
```
