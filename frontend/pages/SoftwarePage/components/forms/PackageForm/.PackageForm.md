Shared form component used in both `AddPackageModal.tsx` and `EditSoftwareModal.tsx` for managing software package uploads and configuration in Fleet MDM.

## Key Components

### Exported Types
- **`IPackageFormData`** — Form state shape including file, version, install/uninstall scripts, targeting, self-service, automatic install, and categories
- **`IPackageFormValidation`** — Validation state for each form field
- **`baseClass`** — BEM base CSS class (`"package-form"`)

### Main Component: `PackageForm`
A controlled form component with the following key props:

| Prop | Purpose |
|------|---------|
| `labels` | Available label targets for deployment scoping |
| `isEditingSoftware` | Switches between add/edit modes (affects script defaults) |
| `isFleetMaintainedApp` | Adjusts UI for Fleet-maintained packages |
| `gitopsCompatible` | Disables fields when GitOps mode is active |
| `defaultSoftware` | Pre-populates form for edit mode |
| `teamId` | Used for dynamic category fetching |
| `onSubmit` | Callback receiving final `IPackageFormData` |

### Internal Helpers
- **`getDefaultVersion`** — Resolves version dropdown default, preferring previously selected value
- **`getGraphicName`** — Maps file extension to icon name
- **`renderSoftwareDeployWarningBanner`** — Warning InfoBanner for auto-install risks
- **`renderFileTypeMessage`** — Displays accepted file type hints with tooltips

## Usage Example

```typescript
<PackageForm
  labels={labelsList}
  isEditingSoftware={false}
  gitopsCompatible
  defaultSelfService={false}
  defaultCategories={[]}
  teamId={1}
  onCancel={() => setShowModal(false)}
  onSubmit={(data: IPackageFormData) => handleAddPackage(data)}
  onClickPreviewEndUserExperience={(isIos) => openPreview(isIos)}
/>
```

## Notes
- Accepted file types: `.pkg`, `.msi`, `.exe`, `.deb`, `.rpm`, `.tar.gz`, `.sh`, `.ps1`, `.ipa`
- Default install/uninstall scripts are auto-populated on file selection (add mode only)
- Fields are disabled when GitOps mode is enabled and `gitopsCompatible` is `true`
