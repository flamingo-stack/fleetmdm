Form validation helpers for the `PackageForm` component, providing field-level validation logic, tooltip content generation, and version sorting utilities.

## Key Components

### `FORM_VALIDATION_CONFIG`
Internal configuration object mapping each form field to its validation rules. Covers:
- **`software`** — Required field (must not be null)
- **`preInstallQuery`** — Always valid for submission; computes SQL error messages as warnings only
- **`installScript`** — Required when package type is `.exe`, `.zip`, or `.tar.gz`
- **`uninstallScript`** — Same requirements as `installScript`
- **`customTarget`** — Requires at least one label target selected when not targeting "All hosts"

### `generateFormValidation(formData)`
Iterates the validation config and returns an `IPackageFormValidation` object with per-field `isValid` flags and error messages. The `preInstallQuery` field is special-cased: it never blocks form submission but still computes and surfaces SQL validation messages.

### `createTooltipContent(formValidation, repoURL?, disabledFieldsForGitOps?)`
Builds a React tooltip element from all invalid fields with messages. Returns `null` if all fields are valid. When GitOps mode is active and a `repoURL` is provided, returns the GitOps-specific tip content instead.

### `sortByVersionLatestFirst(items)`
Generic utility that sorts any array of objects with an optional `version` string field in descending order (latest first), using the shared `compareVersions` utility.

## Usage Example

```typescript
import { generateFormValidation, createTooltipContent } from "./helpers";

const formData: IPackageFormData = {
  software: { name: "app.exe", type: "exe" },
  installScript: "install.bat",
  uninstallScript: "",
  preInstallQuery: "",
  targetType: "All hosts",
  labelTargets: {},
};

const validation = generateFormValidation(formData);
// validation.uninstallScript => { isValid: false, message: "Uninstall script is required for .exe packages." }

const tooltip = createTooltipContent(validation);
// Returns a React fragment listing all validation error messages
```
