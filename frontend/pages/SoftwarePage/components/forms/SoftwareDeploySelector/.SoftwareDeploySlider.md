A toggle slider component that controls automatic software deployment, displaying a "Deploy" label with a tooltip explaining the auto-install behavior for hosts missing the software.

## Key Components

- **`SoftwareDeploySlider`** – Default export; a wrapper around the base `Slider` component configured for software deployment toggling
- **`ISoftwareDeploySliderProps`** – Interface defining component props:
  - `deploySoftware: boolean` – Current toggle state
  - `onToggleDeploySoftware: () => void` – Callback fired on toggle
  - `className?: string` – Optional additional CSS class

## Usage Example

```typescript
import SoftwareDeploySlider from "components/software/SoftwareDeploySlider";

const MyForm = () => {
  const [deploy, setDeploy] = useState(false);

  return (
    <SoftwareDeploySlider
      deploySoftware={deploy}
      onToggleDeploySoftware={() => setDeploy((prev) => !prev)}
      className="my-custom-class"
    />
  );
};
```

## Notes

- The tooltip text is fixed: `"Automatically install only on hosts missing this software."`
- Both active and inactive states display the same label text: `"Deploy"`
- Styling is managed via `classnames`, merging the base class `software-deploy-slider__container` with any optional `className` passed in
