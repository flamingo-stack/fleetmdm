Test suite for the `SoftwareDeploySlider` component, verifying that the deploy software toggle correctly invokes its callback when clicked.

## Key Components

- **`defaultProps`** — Baseline props with `deploySoftware: false` and a mocked `onToggleDeploySoftware` handler
- **`getSwitchByLabelText`** — Helper that locates a `button[role="switch"]` within a `.fleet-slider__wrapper` by its label text
- **`SoftwareOptionsSelector` describe block** — Contains the test suite for `SoftwareDeploySlider`

## Usage Example

```typescript
// Renders the component and simulates toggling the "Deploy" switch
const onToggleDeploySoftware = jest.fn();
render(
  <SoftwareDeploySlider
    deploySoftware={false}
    onToggleDeploySoftware={onToggleDeploySoftware}
  />
);

const deploySoftwareSwitch = getSwitchByLabelText("Deploy");
fireEvent.click(deploySoftwareSwitch);

expect(onToggleDeploySoftware).toHaveBeenCalledTimes(1);
```

## Test Coverage

| Test | Assertion |
|------|-----------|
| Toggle "Deploy" slider | `onToggleDeploySoftware` called exactly once with no arguments |

## Notes

- The `getSwitchByLabelText` helper traverses the DOM upward via `.closest(".fleet-slider__wrapper")` to find the associated `<button role="switch">`, accommodating the Fleet slider component structure
- The test verifies the callback is called with no arguments (`toHaveBeenCalledWith()`)
