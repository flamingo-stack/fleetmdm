Renders the top-section summary panel for software title, version, and OS detail pages, displaying the icon, display name, metadata (type, versions, host count), and an optional Actions dropdown for managing software.

## Key Components

### Exports

- **`SoftwareDetailsSummary`** *(default)* — Main React component rendering the summary header
- **`buildActionOptions`** — Pure function that constructs the Actions dropdown options based on permissions and GitOps mode state
- **Action constants** — `ACTION_EDIT_APPEARANCE`, `ACTION_EDIT_SOFTWARE`, `ACTION_EDIT_CONFIGURATION`, `ACTION_PATCH`, `ACTION_EDIT_AUTO_UPDATE_CONFIGURATION`

### Interfaces

- **`ISoftwareDetailsSummaryProps`** — Component props including display metadata, permission flags, and action callbacks
- **`BuildActionOptionsArgs`** — Arguments for `buildActionOptions`, encoding permission flags and GitOps context

### Notable Behaviors

- Conditionally renders a `SoftwareIcon` or `OSIcon` based on `isOperatingSystem`
- Supports live icon preview via `iconPreviewUrl` (validated with `isSafeImagePreviewUrl`)
- Suppresses host count for `tgz_packages`, `sh_packages`, and `ps1_packages` sources
- Wraps Arch Linux rolling-release names with a `TooltipWrapperArchLinuxRolling` suffix indicator
- Disables relevant Actions dropdown items when GitOps mode is active, linking to the repo URL in the tooltip

## Usage Example

```typescript
<SoftwareDetailsSummary
  displayName="Slack"
  name="slack"
  type="Package (dmg)"
  hostCount={42}
  countsUpdatedAt="2024-01-15T10:00:00Z"
  queryParams={{ software_title_id: "123" }}
  source="brew"
  versions={3}
  iconUrl="https://example.com/slack.png"
  canManageSoftware={true}
  onClickEditAppearance={() => setShowEditAppearanceModal(true)}
  onClickEditSoftware={() => setShowEditSoftwareModal(true)}
  onClickAddPatchPolicy={() => setShowPatchModal(true)}
/>
```
