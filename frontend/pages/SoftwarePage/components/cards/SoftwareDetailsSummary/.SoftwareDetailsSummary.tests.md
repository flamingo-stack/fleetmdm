Unit tests for the `buildActionOptions` function exported from `SoftwareDetailsSummary`, validating the construction of dropdown action options based on user permissions, GitOps mode, and software source.

## Key Components

### `buildActionOptions` (tested function)
Builds a list of action menu options for a software details view. Tests cover all exported action constants:

| Constant | Label |
|---|---|
| `ACTION_EDIT_APPEARANCE` | Edit appearance |
| `ACTION_EDIT_SOFTWARE` | Edit software |
| `ACTION_EDIT_CONFIGURATION` | Edit configuration |
| `ACTION_PATCH` | Patch |
| `ACTION_EDIT_AUTO_UPDATE_CONFIGURATION` | Schedule auto updates |

## Test Cases

| Scenario | Expected Behavior |
|---|---|
| No permissions | Returns only `Edit appearance` |
| `canEditSoftware: true` | Adds enabled `Edit software` option |
| `canEditConfiguration: true` | Adds enabled `Edit configuration` option |
| `gitOpsModeEnabled: true` + `source: "vpp_apps"` | Disables appearance, configuration, and software options with tooltip |
| `canAddPatchPolicy: true`, no existing policy | Adds enabled `Patch` option |
| `canAddPatchPolicy: true` + `hasExistingPatchPolicy: true` | Adds disabled `Patch` with `"Patch policy is already added."` tooltip |
| `canConfigureAutoUpdate: true` | Adds `Schedule auto updates` option |

## Usage Example

```typescript
import { buildActionOptions } from "./SoftwareDetailsSummary";

const options = buildActionOptions({
  gitOpsModeEnabled: false,
  repoURL: undefined,
  source: "vpp_apps",
  canEditSoftware: true,
  canEditConfiguration: true,
  canAddPatchPolicy: true,
  canConfigureAutoUpdate: false,
  hasExistingPatchPolicy: false,
});
// Returns action options array with Edit appearance, Edit software,
// Edit configuration, and Patch — all enabled
```
