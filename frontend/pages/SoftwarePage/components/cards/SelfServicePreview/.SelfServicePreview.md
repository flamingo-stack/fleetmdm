Renders a preview of the Fleet self-service UI, supporting both a mobile screenshot overlay (iOS/iPadOS) and an interactive HTML/CSS desktop preview with dynamic app name and icon.

## Key Components

- **`ISelfServicePreviewProps`** — Interface defining preview configuration including `isIosOrIpadosApp`, `contactUrl`, `name`, `displayName`, `versionLabel`, `hasCategories`, `renderIcon`, and optional `renderTable`
- **Mobile branch** — Screenshot-based preview using `PreviewSelfServiceMobileIcon` with a dynamic icon/name/version overlay via `TooltipTruncatedText`
- **Desktop branch** — HTML/CSS preview card embedding `SelfServiceHeader`, an optional static "All" category dropdown, a disabled `SearchField`, and a pluggable `renderTable` slot

## Usage Example

```typescript
import SelfServicePreview from "./SelfServicePreview";
import SoftwareIcon from "components/SoftwareIcon";

<SelfServicePreview
  isIosOrIpadosApp={false}
  contactUrl="https://support.example.com"
  name="Slack"
  displayName="Slack"
  versionLabel="4.35.126"
  hasCategories={true}
  renderIcon={() => <SoftwareIcon name="Slack" />}
  renderTable={() => <BasicSoftwareTable />}
/>
```

## Notes

- Used by `CategoriesEndUserExperienceModal` and `Edit Appearance Modal` under Software title pages
- The desktop preview renders a `disabled-overlay` div to prevent interaction with the simulated UI
- When `hasCategories` is `true`, a static `"All"` dropdown is shown to mirror the real `CategoryFilter` component
- `renderTable` is optional; omitting it renders the preview without a software list
