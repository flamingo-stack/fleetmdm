A simple presentational component that displays a placeholder card when no hosts are associated with a given detail view.

## Key Components

- **`IDetailsNoHosts`** — Interface defining the component's props: `header` (string) and `details` (string)
- **`DetailsNoHosts`** — Default export; renders a styled `Card` with an `xxlarge` border radius containing a heading and descriptive paragraph

## Usage Example

```typescript
import DetailsNoHosts from "components/DetailsNoHosts";

<DetailsNoHosts
  header="No hosts targeted"
  details="Add hosts to this policy to start collecting results."
/>
```
