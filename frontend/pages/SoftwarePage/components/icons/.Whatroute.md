A React SVG component that renders the WhatRoute logo/icon as an inline SVG embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Whatroute`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG with an embedded PNG via a base64 `<image>` element.

## Usage Example

```typescript
import Whatroute from "./Whatroute";

// Basic usage
<Whatroute />

// With custom size and className
<Whatroute width={64} height={64} className="icon" />

// With accessibility attributes
<Whatroute aria-label="WhatRoute" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via spread (`{...props}`), making the component fully customizable.
- The icon image is self-contained — no external assets or network requests are required.
- Default dimensions are `32×32` but can be overridden via props.
