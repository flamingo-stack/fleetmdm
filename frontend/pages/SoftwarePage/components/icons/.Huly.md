React SVG icon component that renders the Huly logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Huly`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import Huly from "./Huly";

// Basic usage
<Huly />

// With custom size and className
<Huly width={64} height={64} className="icon" />

// With style overrides
<Huly style={{ opacity: 0.8 }} aria-label="Huly logo" />
```

## Notes

- Default dimensions are `32×32` pixels; override via `width`/`height` props.
- The PNG data is inlined as a base64 `data:image/png` string — no external image assets required.
