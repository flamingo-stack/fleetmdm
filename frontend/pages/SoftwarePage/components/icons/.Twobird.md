A React SVG component that renders the Twobird logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Twobird`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Twobird from "./Twobird";

// Basic usage
<Twobird />

// With custom size and className
<Twobird width={64} height={64} className="logo-icon" />

// With style overrides
<Twobird style={{ display: "block", margin: "0 auto" }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The visual asset is a **base64-encoded PNG** baked directly into the component — no external image files or network requests required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
