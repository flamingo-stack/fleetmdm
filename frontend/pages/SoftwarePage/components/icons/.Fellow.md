React SVG icon component that renders the Fellow integration logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Fellow`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Fellow logo as an embedded PNG image.

## Usage Example

```typescript
import Fellow from "./Fellow";

// Basic usage
<Fellow />

// With custom dimensions or className
<Fellow width={64} height={64} className="integration-icon" />

// With accessibility attributes
<Fellow aria-label="Fellow" role="img" />
```

## Notes

- The logo image is embedded as a base64 PNG, requiring no external asset dependencies.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
