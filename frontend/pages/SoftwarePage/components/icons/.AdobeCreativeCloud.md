React SVG wrapper component that renders the Adobe Creative Cloud application icon as an inline PNG image encoded in base64, embedded within an SVG element.

## Key Components

- **`AdobeCreativeCloud`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element. Internally renders a 32×32 pixel PNG via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import AdobeCreativeCloud from "./AdobeCreativeCloud";

// Basic usage
<AdobeCreativeCloud />

// With custom dimensions and className
<AdobeCreativeCloud width={64} height={64} className="app-icon" />

// With accessibility attributes
<AdobeCreativeCloud
  role="img"
  aria-label="Adobe Creative Cloud"
  width={32}
  height={32}
/>
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
