React SVG icon component that renders the Mattermost logo as an inline PNG embedded in an SVG element.

## Key Components

- **`Mattermost`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Mattermost logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Mattermost from "./Mattermost";

// Basic usage
<Mattermost />

// With custom dimensions and className
<Mattermost width={48} height={48} className="icon" />

// With accessibility attributes
<Mattermost aria-label="Mattermost" role="img" />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- The logo is embedded as a base64 PNG — no external image requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
