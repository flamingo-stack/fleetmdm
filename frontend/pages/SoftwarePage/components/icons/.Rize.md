A React SVG component that renders the Rize brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Rize`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Rize from "./Rize";

// Basic usage
<Rize />

// With custom dimensions or className
<Rize width={64} height={64} className="icon" />

// With inline styles
<Rize style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The image content is a self-contained base64 PNG — no external asset dependencies.
- Fully compatible with standard SVG accessibility and styling patterns (e.g., `aria-label`, `className`, `style`).
