React SVG icon component that renders the Keka logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Keka`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Keka brand logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Keka from "./Keka";

// Basic usage
<Keka />

// With custom dimensions and className
<Keka width={64} height={64} className="icon" />

// With accessibility attributes
<Keka aria-label="Keka" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The logo image is self-contained — no external asset fetching required.
