React SVG component that renders the Droplr logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Droplr`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing the Droplr brand logo as an inline base64 PNG `<image>`.

## Usage Example

```typescript
import Droplr from "./Droplr";

// Basic usage
<Droplr />

// With custom dimensions or className
<Droplr width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Droplr aria-label="Droplr" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The logo image is fully self-contained — no external network requests are made at runtime.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
