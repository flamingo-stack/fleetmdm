A React SVG component that renders the KeeWeb password manager logo as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Keeweb`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the KeeWeb logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Keeweb from "./Keeweb";

// Basic usage
<Keeweb />

// With custom size and className
<Keeweb width={64} height={64} className="app-icon" />

// With accessibility attributes
<Keeweb aria-label="KeeWeb" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- The icon is self-contained — no external image URLs are needed at runtime.
- Default render size is **32×32 px**; override with `width`/`height` props.
