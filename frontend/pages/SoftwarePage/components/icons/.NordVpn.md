React SVG icon component that renders the NordVPN logo as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`NordVpn`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the NordVPN brand icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import NordVpn from "./NordVpn";

// Basic usage
const App = () => <NordVpn />;

// With custom dimensions and className
const App = () => (
  <NordVpn
    width={64}
    height={64}
    className="vendor-icon"
    aria-label="NordVPN"
  />
);

// With inline styles
const App = () => (
  <NordVpn style={{ opacity: 0.8 }} />
);
```

## Notes

- The icon image is self-contained via a base64-encoded PNG payload — no external network request or separate asset file required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via the spread operator.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
