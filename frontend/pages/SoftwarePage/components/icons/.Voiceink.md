A React SVG component that renders the Voiceink brand logo as an inline SVG element with an embedded base64-encoded PNG image (32×32px).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Voiceink` | `React.FC<SVGProps<SVGSVGElement>>` | Default exported SVG icon component accepting standard SVG props |

## Usage Example

```typescript
import Voiceink from './Voiceink';

// Basic usage
<Voiceink />

// With custom dimensions
<Voiceink width={64} height={64} />

// With className or style overrides
<Voiceink className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- Renders a fixed `32×32` SVG wrapper by default; override via `width`/`height` props.
- The icon image is embedded as a base64-encoded PNG (512×512 source resolution), avoiding any external asset requests.
- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/node_modules/@types/react/index.d.ts) attributes, making it composable with icon libraries or design systems.
