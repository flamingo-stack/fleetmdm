A React SVG icon component that renders the Airtame brand logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Airtame`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering an `<svg>` wrapper with an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Airtame from "./Airtame";

// Basic usage
<Airtame />

// With custom dimensions or className
<Airtame width={64} height={64} className="icon" />

// With accessibility attributes
<Airtame aria-label="Airtame" role="img" />
```

## Notes

- Dimensions default to `32×32` but can be overridden via props.
- The icon image is self-contained as a base64 PNG — no external asset dependencies.
