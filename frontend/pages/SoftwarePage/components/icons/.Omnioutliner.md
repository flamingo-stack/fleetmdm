React SVG icon component that renders the OmniOutliner application icon as a 32×32 SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Omnioutliner`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with the OmniOutliner app icon as an embedded PNG via a base64 `href`.

## Usage Example

```typescript
import Omnioutliner from "./Omnioutliner";

// Basic usage
<Omnioutliner />

// With custom dimensions or className
<Omnioutliner width={64} height={64} className="app-icon" />

// With accessibility attributes
<Omnioutliner aria-label="OmniOutliner" role="img" />
```

## Notes

- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- The icon is self-contained — no external image dependencies.
- Default render size is `32×32` pixels; override via `width`/`height` props.
