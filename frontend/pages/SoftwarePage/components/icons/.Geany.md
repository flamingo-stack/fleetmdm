A React SVG component that renders the Geany IDE application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Geany`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the Geany logo as an SVG wrapper around an embedded PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import Geany from "./Geany";

// Basic usage
<Geany />

// With custom dimensions and className
<Geany width={64} height={64} className="app-icon" />

// With accessibility attributes
<Geany aria-label="Geany IDE" role="img" />
```

## Notes

- The component delegates sizing and styling through `SVGProps`, making it composable with standard SVG attributes (`width`, `height`, `style`, `className`, etc.).
- The icon is self-contained — no external image assets or network requests required.
- Default render size is **32×32px**, matching a standard toolbar/favicon footprint.
