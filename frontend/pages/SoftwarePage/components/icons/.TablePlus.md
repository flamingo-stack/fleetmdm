React SVG icon component that renders the TablePlus application logo as a Base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`TablePlus`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the TablePlus app icon via a Base64 PNG `<image>` element.

## Usage Example

```typescript
import TablePlus from "./TablePlus";

// Basic usage
<TablePlus />

// With custom dimensions or className
<TablePlus width={24} height={24} className="icon" />

// With aria label for accessibility
<TablePlus aria-label="TablePlus" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The PNG data is fully self-contained — no external image requests are made at runtime.
