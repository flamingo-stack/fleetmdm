A React SVG component that renders the SigmaOS browser application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Sigmaos`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Sigmaos from "./Sigmaos";

// Basic usage
<Sigmaos />

// With custom size and className
<Sigmaos width={64} height={64} className="app-icon" />

// With accessibility attributes
<Sigmaos aria-label="SigmaOS" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG (512×512 source resolution, rendered at 32×32 by default).
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via prop spreading.
- No external asset dependencies — the image is self-contained in the component bundle.
