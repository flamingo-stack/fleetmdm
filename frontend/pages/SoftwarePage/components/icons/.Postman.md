A React SVG icon component that renders the Postman logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Postman`** — Default export. A functional React component that renders a 32×32 SVG containing the Postman logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Postman from "./Postman";

// Basic usage
<Postman />

// With custom size and className
<Postman width={64} height={64} className="icon" />

// With style overrides
<Postman style={{ opacity: 0.8 }} aria-label="Postman" />
```

All standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the underlying `<svg>` element. The default rendered size is **32×32px**.

## Notes

- The logo image is self-contained as a base64 data URI — no external asset requests are made.
