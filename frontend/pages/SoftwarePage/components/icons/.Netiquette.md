A React SVG component that renders the Netiquette icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Netiquette`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Netiquette from "./Netiquette";

// Basic usage
<Netiquette />

// With custom dimensions or className
<Netiquette width={64} height={64} className="icon" />

// With inline styles
<Netiquette style={{ opacity: 0.8 }} aria-label="Netiquette" />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via props.
- The image content is embedded as a **base64 PNG** (512×512 source resolution), meaning no external asset request is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
