A React SVG component that renders a Terminal application icon as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Terminal`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 terminal icon.

## Usage Example

```typescript
import Terminal from "./Terminal";

// Basic usage
<Terminal />

// With custom dimensions or className
<Terminal width={64} height={64} className="icon" />

// With accessibility attributes
<Terminal aria-label="Terminal" role="img" />
```

## Notes

- Icon dimensions default to **32×32px** but can be overridden via props.
- The image is embedded as a **base64 PNG** inside an `<image>` element, so no external asset dependency is required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
