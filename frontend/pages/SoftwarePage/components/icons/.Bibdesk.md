A React SVG component that renders the BibDesk application icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Bibdesk`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded base64 PNG icon via an `<image>` tag.

## Usage Example

```typescript
import Bibdesk from "./Bibdesk";

// Basic usage
<Bibdesk />

// With custom dimensions or className
<Bibdesk width={64} height={64} className="app-icon" />

// With accessibility attributes
<Bibdesk aria-label="BibDesk" role="img" />
```

## Notes

- The icon image is self-contained — no external image file is required at runtime.
- All SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
