React SVG component that renders the Royal TSX application icon as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`RoyalTsx`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import RoyalTsx from "./RoyalTsx";

// Basic usage
<RoyalTsx />

// With custom dimensions or className
<RoyalTsx width={64} height={64} className="app-icon" />

// With aria label for accessibility
<RoyalTsx aria-label="Royal TSX" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required at runtime.
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) via prop spreading.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- Part of the Flamingo asset/icon library. See the full icon set at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
