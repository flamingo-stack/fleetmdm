A React SVG icon component that renders the Google Earth Pro application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`GoogleEarthPro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Google Earth Pro icon as an embedded base64 PNG image.

## Usage Example

```typescript
import GoogleEarthPro from './GoogleEarthPro';

// Basic usage
<GoogleEarthPro />

// With custom dimensions
<GoogleEarthPro width={64} height={64} />

// With additional SVG props
<GoogleEarthPro className="app-icon" aria-label="Google Earth Pro" />
```

## Notes

- The icon is a **32×32px** SVG by default; dimensions can be overridden via props.
- The PNG image data is embedded as a base64 `data:image/png` URI, so no external asset request is made.
- Accepts all standard React `SVGProps<SVGSVGElement>` (e.g., `className`, `style`, `onClick`, `aria-*`).
