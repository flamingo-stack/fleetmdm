A React SVG icon component that renders the Syncovery logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Syncovery`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element. Renders a 32×32 SVG wrapper with an embedded base64 PNG via an `<image>` tag.

## Usage Example

```typescript
import Syncovery from "./Syncovery";

// Basic usage
<Syncovery />

// With custom size and className
<Syncovery width={64} height={64} className="icon" />

// With inline styles
<Syncovery style={{ opacity: 0.8 }} />
```

## Notes

- The component renders a fixed 32×32 SVG by default, but dimensions can be overridden via props.
- The logo image is self-contained as a base64-encoded PNG — no external asset dependencies.
- Fully compatible with standard SVG prop patterns used across icon libraries (e.g., `aria-label`, `role`, `fill`).
