React SVG icon component that renders the Geekbench application logo as an inline PNG image encoded in base64, sized at 32×32 pixels.

## Key Components

- **`Geekbench`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 SVG wrapper around an embedded base64-encoded PNG image of the Geekbench logo.

## Usage Example

```typescript
import Geekbench from "./Geekbench";

// Basic usage
<Geekbench />

// With custom size or className
<Geekbench width={64} height={64} className="app-icon" />

// With accessibility attributes
<Geekbench aria-label="Geekbench" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via `{...props}`.
- The icon image is fully self-contained — no external network requests are made at runtime.
- Default rendered size is **32×32px**; the internal PNG asset is **512×512px**, so the component scales cleanly to larger sizes.
- This component follows the same pattern used across other app icon components in this repository.
