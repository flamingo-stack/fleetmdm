A React SVG component that renders the Mimecast logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Mimecast`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Mimecast brand icon at 32×32px.

## Usage Example

```typescript
import Mimecast from "./Mimecast";

// Basic usage
<Mimecast />

// With custom dimensions or className
<Mimecast width={64} height={64} className="icon" />

// With accessibility attributes
<Mimecast aria-label="Mimecast" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG, so no external asset file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
