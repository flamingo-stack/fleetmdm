React SVG component that renders the Affinity Designer application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AffinityDesigner` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component for Affinity Designer |

## Usage Example

```typescript
import AffinityDesigner from './AffinityDesigner';

// Basic usage
<AffinityDesigner />

// With custom dimensions
<AffinityDesigner width={64} height={64} />

// With additional SVG props
<AffinityDesigner
  className="app-icon"
  style={{ borderRadius: '8px' }}
  aria-label="Affinity Designer"
/>
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props
- The icon is embedded as a base64-encoded PNG inside an SVG `<image>` element — no external asset requests required
- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react-spring.dev/docs/components/svg) for full composability
- Source: [`AffinityDesigner.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/AffinityDesigner.tsx)
