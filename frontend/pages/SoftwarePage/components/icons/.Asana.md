React SVG icon component that renders the Asana logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Asana`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Asana brand icon.

## Usage Example

```typescript
import Asana from "./Asana";

// Basic usage
<Asana />

// With custom dimensions or className
<Asana width={64} height={64} className="icon" />

// With accessibility attributes
<Asana aria-label="Asana" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained as a base64 PNG — no external asset requests.
- All `SVGProps` (e.g., `style`, `className`, `onClick`) are forwarded directly to the `<svg>` element.
