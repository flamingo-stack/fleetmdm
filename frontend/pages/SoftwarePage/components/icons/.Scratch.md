A React SVG component that renders the Scratch programming language logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Scratch`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Scratch logo as an inline base64 PNG `<image>`.

## Usage Example

```typescript
import Scratch from "./Scratch";

// Basic usage
<Scratch />

// With custom dimensions and styling
<Scratch width={64} height={64} className="icon" />

// With click handler and accessibility
<Scratch
  aria-label="Scratch"
  role="img"
  onClick={() => console.log("clicked")}
/>
```

## Notes

- The logo image is self-contained via base64 encoding — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is `32×32` pixels; override with `width`/`height` props as needed.
