React SVG icon component that renders the Android Studio logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`AndroidStudio`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing a base64 PNG `<image>` element.

## Usage Example

```typescript
import AndroidStudio from "./AndroidStudio";

// Basic usage
<AndroidStudio />

// With custom size and class
<AndroidStudio width={64} height={64} className="icon" />

// With accessibility attributes
<AndroidStudio aria-label="Android Studio" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained as an inline base64 PNG — no external image requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread (`{...props}`).
