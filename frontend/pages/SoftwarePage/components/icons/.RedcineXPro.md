A React SVG component that renders the REDCINE-X PRO application icon as a 32×32 inline SVG element containing a base64-encoded PNG image.

## Key Components

- **`RedcineXPro`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG with an embedded PNG icon via a `data:image/png;base64` href.

## Usage Example

```typescript
import RedcineXPro from "./RedcineXPro";

// Basic usage
<RedcineXPro />

// With custom size and className
<RedcineXPro width={64} height={64} className="app-icon" />

// With accessibility attributes
<RedcineXPro aria-label="REDCINE-X PRO" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full prop customization (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The default rendered size is `32×32` pixels; override via `width`/`height` props.
- The icon image is self-contained — no external asset dependency at runtime.
