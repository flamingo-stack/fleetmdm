SVG icon component rendering the Android OS logo, used for platform identification in device management interfaces.

## Key Components

- **`AndroidOS`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 Android robot head icon in a `#515774` fill on a `#F9FAFC` background.

## Usage Example

```typescript
import AndroidOS from "@/components/icons/AndroidOS";

// Basic usage
<AndroidOS />

// Custom dimensions
<AndroidOS width={24} height={24} />

// With custom class or style
<AndroidOS className="platform-icon" aria-label="Android OS" />
```

## Notes

- All `SVGProps` are spread onto the root `<svg>` element, enabling full customization (size, `className`, `style`, `aria-*`, etc.).
- The icon uses `fill="none"` at the root level; fill colors are applied per path.
- Intended for use in device/OS platform listings within the [FleetMDM](https://github.com/flamingo-stack/fleetmdm) UI, such as device tables or filter labels.
