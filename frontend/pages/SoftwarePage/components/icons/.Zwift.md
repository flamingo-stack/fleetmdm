A React SVG component that renders the Zwift brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Zwift`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` wrapper containing an `<image>` element with an inline base64 PNG.

## Usage Example

```typescript
import Zwift from "./Zwift";

// Basic usage
<Zwift />

// With custom size and className
<Zwift width={64} height={64} className="icon" />

// With accessibility attributes
<Zwift aria-label="Zwift" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via `width`/`height` props.
- The PNG is embedded as a base64 `data:image/png` URI — no external image request is made.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via spread.
