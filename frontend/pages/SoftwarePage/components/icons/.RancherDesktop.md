A React SVG icon component that renders the Rancher Desktop logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`RancherDesktop`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing the Rancher Desktop logo as an embedded PNG via base64 data URI.

## Usage Example

```typescript
import RancherDesktop from "./RancherDesktop";

// Basic usage
<RancherDesktop />

// With custom size and className
<RancherDesktop width={64} height={64} className="icon" />

// With accessible label
<RancherDesktop aria-label="Rancher Desktop" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element.
- The logo image is self-contained — no external network requests are made.
