A React SVG component that renders the Autopsy icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Autopsy`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Autopsy from "./Autopsy";

// Basic usage
<Autopsy />

// With custom dimensions and className
<Autopsy width={64} height={64} className="my-icon" />

// With ARIA label for accessibility
<Autopsy aria-label="Autopsy" role="img" />
```

## Notes

- The icon image is embedded as a base64 PNG — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
