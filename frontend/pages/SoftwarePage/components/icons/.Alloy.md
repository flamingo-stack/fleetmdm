A React SVG component that renders the Alloy brand icon as a 32×32 inline SVG using a base64-encoded PNG image.

## Key Components

- **`Alloy`** — Default export. A functional React component that wraps a base64-encoded PNG inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` for full prop forwarding (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Alloy from "./Alloy";

// Basic usage
<Alloy />

// With custom size and className
<Alloy width={64} height={64} className="icon" />

// With event handler
<Alloy onClick={() => console.log("clicked")} />
```

## Notes

- Dimensions default to `32×32` but can be overridden via props.
- The icon is self-contained — no external image fetch required; the PNG is embedded as a base64 `data:` URI inside the `<image>` element.
- Accepts all standard SVG element props via `SVGProps<SVGSVGElement>` spread.
