SVG icon component that renders the Antigravity IDE logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`AntigravityIde`** — A React functional component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing a base64-encoded PNG image of the Antigravity IDE logo.

## Usage Example

```typescript
import AntigravityIde from "./AntigravityIde";

// Basic usage
<AntigravityIde />

// With custom dimensions or class
<AntigravityIde width={64} height={64} className="icon" />

// With inline styles
<AntigravityIde style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The image is embedded as a base64-encoded PNG — no external asset file is required.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element.
