Storybook story file for the `SoftwareIcon` component, enabling interactive exploration of all available software icons mapped by name or source.

## Key Components

- **`IconWrapper`** — Thin wrapper that calls `getMatchedSoftwareIcon` with `name`/`source` props and renders the resolved icon component
- **`meta`** — Storybook metadata registering the story under `Components/Icon/SoftwareIcon` with a `select` control populated from both `SOFTWARE_NAME_TO_ICON_MAP` and `SOFTWARE_SOURCE_TO_ICON_MAP`
- **`Default`** — Single story with a custom `render` function that parses the dropdown selection (e.g. `"homebrew (source)"`) back into the correct `name` or `source` prop

## Usage Example

```typescript
// Viewing in Storybook:
// 1. Open the "Components/Icon/SoftwareIcon" story
// 2. Use the "selection" dropdown in the Controls panel
// 3. Pick an entry like "google-chrome (name)" or "homebrew (source)"
//    — the story parses the suffix to route the value to the correct prop

// Underlying helper used by the wrapper:
import { getMatchedSoftwareIcon } from ".";

const Icon = getMatchedSoftwareIcon({ name: "google-chrome", source: "" });
// → returns the Chrome SVG icon component

const FallbackIcon = getMatchedSoftwareIcon({ name: "", source: "homebrew" });
// → returns the Homebrew SVG icon component
```

## Notes

- The `selection` control format (`"value (type)"`) is a workaround for the mutual exclusivity of `name` and `source` — Storybook controls don't natively support union types, so both maps are merged into a single labelled dropdown.
- Source lives at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Icon.stories.tsx)
