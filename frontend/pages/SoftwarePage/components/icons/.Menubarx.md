A React SVG component that renders a 32×32 Menubar icon using an embedded base64-encoded PNG image as its source.

## Key Components

- **`Menubarx`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, forwarding all props to the root `<svg>` element.
- **Embedded image** — A base64-encoded PNG (512×512 source, rendered at 32×32) embedded directly via an `<image>` element's `href` attribute, eliminating external asset dependencies.

## Usage Example

```typescript
import Menubarx from "./Menubarx";

// Basic usage
<Menubarx />

// With custom dimensions or className
<Menubarx width={64} height={64} className="icon" />

// With accessibility attributes
<Menubarx aria-label="Menu bar" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are supported via spread.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
- The icon is self-contained — no external image files or network requests required.
