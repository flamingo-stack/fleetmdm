A React SVG component that renders the Darkmodebuddy icon as an embedded PNG image (32×32) using a base64-encoded data URI.

## Key Components

- **`Darkmodebuddy`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).
- The icon is a 32×32 SVG wrapper containing an `<image>` element with a base64-encoded PNG embedded directly in the source — no external asset dependency.

## Usage Example

```typescript
import Darkmodebuddy from "./Darkmodebuddy";

// Basic usage
<Darkmodebuddy />

// With custom size and class
<Darkmodebuddy width={48} height={48} className="icon" />

// With click handler
<Darkmodebuddy onClick={() => toggleDarkMode()} style={{ cursor: "pointer" }} />
```

## Notes

- The default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The embedded PNG is self-contained — no network requests or missing asset risk.
