A React SVG component that renders a 32×32 "CommandTabPlus" icon by embedding a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`CommandTabPlus`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import CommandTabPlus from "./CommandTabPlus";

// Basic usage
<CommandTabPlus />

// With custom dimensions and className
<CommandTabPlus width={64} height={64} className="my-icon" />

// With accessibility attributes
<CommandTabPlus aria-label="Command Tab Plus" role="img" />
```

## Notes

- The icon is **32×32px** by default but can be overridden via props.
- The visual is stored as an embedded base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` element — no external file dependencies.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are supported via spread.
