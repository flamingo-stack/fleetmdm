React SVG icon component that renders the Yaak application logo as a 32×32 PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Yaak` | React Functional Component | SVG wrapper component accepting standard SVG props |

**Props:** Accepts all standard `SVGProps<SVGSVGElement>` — spread onto the root `<svg>` element, allowing consumers to override `width`, `height`, `className`, `style`, etc.

## Usage Example

```typescript
import { Yaak } from "./icons/Yaak";

// Default 32x32 icon
<Yaak />

// Custom size
<Yaak width={64} height={64} />

// With class and style overrides
<Yaak className="app-icon" style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions: **32×32 pixels**
- The PNG asset is inlined as a base64 data URI — no external image dependency required
- The component is purely presentational with no internal state or side effects
- Source: [`Yaak.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Yaak.tsx)
