A React SVG icon component that renders the Microsoft AutoUpdate application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`MicrosoftAutoUpdate`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Microsoft AutoUpdate icon as an embedded PNG.

## Usage Example

```typescript
import MicrosoftAutoUpdate from "./MicrosoftAutoUpdate";

// Basic usage
<MicrosoftAutoUpdate />

// With custom dimensions or className
<MicrosoftAutoUpdate width={64} height={64} className="app-icon" />

// With accessibility attributes
<MicrosoftAutoUpdate aria-label="Microsoft AutoUpdate" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` are forwarded to the root `<svg>` element, enabling full styling and attribute control.
- The icon image is self-contained as a base64-encoded PNG — no external assets or network requests required.
