A React SVG icon component that renders the SSH Config Editor icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`SshConfigEditor`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a base64-encoded PNG icon for SSH Config Editor.

## Usage Example

```typescript
import SshConfigEditor from "./SshConfigEditor";

// Basic usage
<SshConfigEditor />

// With custom size and className
<SshConfigEditor width={64} height={64} className="icon" />

// With accessibility attributes
<SshConfigEditor aria-label="SSH Config Editor" role="img" />
```

## Notes

- The component renders at **32×32px** by default but accepts any `SVGProps` overrides (e.g., `width`, `height`, `className`, `style`).
- The icon image is embedded as a **base64 PNG data URI** (`href` on an `<image>` element), meaning no external asset is needed at runtime.
- The source file is located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/SshConfigEditor.tsx).
