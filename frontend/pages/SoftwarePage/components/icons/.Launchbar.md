A React SVG component that renders the Launchbar application icon as a 32×32 SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Launchbar`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 `<svg>` with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { Launchbar } from "./Launchbar";

// Basic usage
<Launchbar />

// With custom dimensions or className
<Launchbar width={64} height={64} className="icon" />

// With accessibility attributes
<Launchbar aria-label="Launchbar" role="img" />
```

## Notes

- The icon image is self-contained — no external assets are required at runtime.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is `32×32` pixels; override via props as needed.
