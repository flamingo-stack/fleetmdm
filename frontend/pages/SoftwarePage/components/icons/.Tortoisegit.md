React SVG icon component that renders the TortoiseGit logo as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`Tortoisegit`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the TortoiseGit logo as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Tortoisegit from "./Tortoisegit";

// Basic usage
<Tortoisegit />

// With custom dimensions and className
<Tortoisegit width={64} height={64} className="icon" />

// With accessibility attributes
<Tortoisegit aria-label="TortoiseGit" role="img" />
```

## Notes

- All standard SVG props (`width`, `height`, `className`, `style`, `onClick`, etc.) are forwarded to the root `<svg>` element via spread.
- Default render size is **32×32 pixels**.
- The logo is self-contained — no external image requests are made.
