A React SVG icon component that renders the Masscode application logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`Masscode`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an inline base64-encoded PNG of the Masscode logo.

## Usage Example

```typescript
import Masscode from "./Masscode";

// Basic usage
<Masscode />

// With custom dimensions and className
<Masscode width={64} height={64} className="app-icon" />

// With style overrides
<Masscode style={{ opacity: 0.8 }} aria-label="Masscode" />
```

## Notes

- The icon renders at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The PNG image data is fully self-contained as a base64 data URI — no external assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
