A React SVG icon component that renders the Idagio logo as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Idagio`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a fixed 32×32 SVG containing the Idagio brand icon as an embedded PNG.

## Usage Example

```typescript
import Idagio from "./Idagio";

// Basic usage
<Idagio />

// With custom styling
<Idagio className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (via SVG props)
<Idagio width={64} height={64} />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 string — no external asset requests are made.
