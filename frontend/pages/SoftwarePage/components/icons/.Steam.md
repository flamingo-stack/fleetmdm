SVG React component that renders the Steam logo as an inline PNG image encoded in base64, sized at 32×32 pixels.

## Key Components

- **`Steam`** — Default export; a React functional component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.
- Renders a 32×32 `<svg>` containing an `<image>` element with the Steam logo embedded as a base64-encoded PNG `href`.

## Usage Example

```typescript
import Steam from "./Steam";

// Basic usage
<Steam />

// With custom size via SVG props
<Steam width={64} height={64} />

// With className or style
<Steam className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The logo is fully self-contained — no external network requests are made.
- All `SVGProps<SVGSVGElement>` are forwarded, enabling control over `width`, `height`, `className`, `style`, `aria-*`, and other standard SVG attributes.
- Default rendered size is **32×32 px**.
