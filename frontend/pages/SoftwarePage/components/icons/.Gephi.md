A React SVG component that renders the Gephi logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Gephi`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Gephi graph visualization tool logo at 32×32 pixels via an inline `<image>` element with a base64-encoded PNG `href`.

## Usage Example

```typescript
import { Gephi } from "./Gephi";

// Basic usage
<Gephi />

// With custom dimensions or className
<Gephi width={64} height={64} className="icon" />

// With aria label for accessibility
<Gephi aria-label="Gephi" role="img" />
```

## Notes

- The PNG data is fully self-contained — no external image requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the `{...props}` spread.
- Default size is `32×32` but can be overridden via `width`/`height` props.
