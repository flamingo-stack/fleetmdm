A React SVG component that renders the ActivityWatch application icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Activitywatch`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` element with an embedded base64 PNG image (32×32px).

## Usage Example

```typescript
import Activitywatch from "./Activitywatch";

// Basic usage
<Activitywatch />

// With custom dimensions or className
<Activitywatch width={64} height={64} className="icon" />

// With aria label for accessibility
<Activitywatch aria-label="ActivityWatch" role="img" />
```

## Notes

- The icon is hardcoded at 32×32 pixels by default but can be overridden via props.
- The image data is a base64-encoded PNG embedded directly in the SVG `<image>` element — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
