A React SVG component that renders the Unclutter icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Unclutter`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Unclutter from "./Unclutter";

// Basic usage
<Unclutter />

// With custom dimensions and className
<Unclutter width={64} height={64} className="icon" />

// With accessibility attributes
<Unclutter aria-label="Unclutter" role="img" />
```

## Notes

- The icon is rendered at a native size of **32×32 pixels** but can be overridden via `width`/`height` props.
- The embedded PNG was originally a **512×512** image (per EXIF metadata) downscaled to 32×32 in the SVG viewport.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded via the spread `{...props}`.
