React SVG icon component that renders the Prisma logo as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Prisma`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Prisma logo via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Prisma from "./Prisma";

// Basic usage
<Prisma />

// With custom dimensions or className
<Prisma width={64} height={64} className="my-icon" />

// With style overrides
<Prisma style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32** pixels but can be overridden via `width`/`height` props.
- The logo image is self-contained as a base64 PNG — no external asset fetching required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread.
- Useful as a technology badge or integration indicator in UI contexts referencing [Prisma ORM](https://www.prisma.io/).
