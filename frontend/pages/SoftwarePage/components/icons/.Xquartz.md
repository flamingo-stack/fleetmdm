React SVG icon component that renders the XQuartz application icon as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Xquartz` | React functional component | SVG wrapper component accepting standard SVG props |

## Usage Example

```typescript
import { Xquartz } from "./Xquartz";

// Basic usage
<Xquartz />

// With custom dimensions and class
<Xquartz width={64} height={64} className="icon" />

// With accessibility attributes
<Xquartz aria-label="XQuartz" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`)
- Default rendered size is **32×32** pixels
- The icon graphic is embedded as a base64-encoded PNG (`data:image/png;base64,...`) inside an SVG `<image>` element — no external assets required
- Source: [`Xquartz.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Xquartz.tsx)
