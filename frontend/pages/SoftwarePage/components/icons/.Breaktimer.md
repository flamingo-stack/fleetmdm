React SVG wrapper component that renders the Breaktimer application icon as an inline SVG containing an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Breaktimer`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element with an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import Breaktimer from "./Breaktimer";

// Basic usage
<Breaktimer />

// With custom dimensions or className
<Breaktimer width={64} height={64} className="app-icon" />

// With accessibility attributes
<Breaktimer aria-label="Breaktimer app" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external asset fetches are required at runtime.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
