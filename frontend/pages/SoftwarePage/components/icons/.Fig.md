A React SVG component that renders the Fig (formerly Fig.io) terminal autocomplete tool logo as a 32×32 pixel inline PNG image embedded via a base64 data URI.

## Key Components

- **`Fig`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing callers to override width, height, className, style, and other SVG attributes.

## Usage Example

```typescript
import Fig from "./Fig";

// Basic usage
<Fig />

// With custom size and className
<Fig width={64} height={64} className="tool-icon" />

// With inline style
<Fig style={{ opacity: 0.8 }} />
```

## Notes

- The image is a fixed 32×32 PNG encoded as a base64 data URI — no external network request is made at render time.
- All `SVGProps` are spread onto the root `<svg>` element, so consumers can override dimensions or attach event handlers without wrapping the component.
