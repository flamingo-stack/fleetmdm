Renders operating system icons app-wide, supporting both named OS icons (resolved via `getMatchedOsIcon`) and custom image URLs, with configurable sizing.

## Key Components

- **`OSIcon`** — Default export. A React component that displays an OS-specific icon based on an OS name or a custom image URL.
- **`IOSIconProps`** — Interface defining component props:
  - `name` — OS/distribution name (e.g., `'arch'`, `'ubuntu'`, `'windows'`, `'darwin'`, `'ios'`)
  - `size` — Icon size from `SoftwareIconSizes`; defaults to `"small"`
  - `url` — Optional image URL; takes precedence over `name`-based icon resolution

## Usage Example

```typescript
// Render a named OS icon
<OSIcon name="ubuntu" size="medium" />

// Render a custom image URL as an OS icon
<OSIcon url="https://example.com/custom-os.png" size="large" />

// Fallback to default (small) size with OS name
<OSIcon name="darwin" />
```

## Notes

- When `url` is provided, an `<img>` element is rendered inside a wrapper `<div>`, and `name` is ignored.
- When only `name` is provided, the component calls `getMatchedOsIcon` to resolve the appropriate SVG icon component.
- Icon dimensions are driven by `SOFTWARE_ICON_SIZES[size]`, applied to both `width` and `height` with a fixed `viewBox` of `0 0 32 32`.
- CSS class names follow the `os-icon` BEM-style pattern (e.g., `os-icon__medium`).
