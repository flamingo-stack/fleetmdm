Unit tests for the `OSIcon` component, verifying rendering behavior for both URL-based image icons and matched SVG OS icons across different size configurations.

## Key Components

- **`MockSvgIcon`** — A lightweight SVG stub used to isolate `OSIcon` rendering from the real `getMatchedOsIcon` implementation
- **`jest.mock("..")`** — Mocks the parent index module's `getMatchedOsIcon` to return `MockSvgIcon` by default
- **Test suite: `OSIcon`** — Four test cases covering the component's core rendering paths

## Test Cases

| Test | Description |
|------|-------------|
| URL-provided rendering | Asserts an `<img>` is rendered with the correct `src` and size class (`os-icon__os-img-large`) |
| Matched SVG rendering | Confirms `getMatchedOsIcon` is called with the OS name and the SVG receives correct `width`/`height` from `SOFTWARE_ICON_SIZES` plus expected CSS classes |
| Default size fallback | Validates `size` defaults to `"small"` when omitted |
| Missing name fallback | Ensures `getMatchedOsIcon` is called with `{ name: "" }` when no `name` prop is passed |
