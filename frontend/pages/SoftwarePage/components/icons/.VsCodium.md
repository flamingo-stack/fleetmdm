SVG icon component that renders the VSCodium logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`VsCodium`** — A React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains a base64-encoded PNG of the VSCodium logo via an `<image>` element.

## Usage Example

```typescript
import VsCodium from "./VsCodium";

// Basic usage
<VsCodium />

// With custom size and className
<VsCodium width={64} height={64} className="icon" />

// With inline styles
<VsCodium style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The logo is self-contained as a base64-encoded PNG — no external asset dependency.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
