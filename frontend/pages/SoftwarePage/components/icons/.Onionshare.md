React SVG component that renders the Onionshare application icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Onionshare`** — Default export; a functional React component wrapping an `<svg>` element with an embedded `<image>` tag sourcing a base64-encoded PNG.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing callers to override `width`, `height`, `className`, `style`, and other SVG attributes.

## Usage Example

```typescript
import Onionshare from "./Onionshare";

// Basic usage
<Onionshare />

// With custom size and class
<Onionshare width={64} height={64} className="app-icon" />

// With inline style
<Onionshare style={{ opacity: 0.8 }} />
```

## Notes

- The icon renders at **32×32px** by default.
- The image data is fully self-contained (base64 PNG), so no external asset requests are made.
