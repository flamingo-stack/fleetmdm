A React SVG component that renders the Raycast application logo as an inline SVG with a base64-encoded PNG image embedded within it.

## Key Components

- **`Raycast`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Raycast logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Raycast from "./Raycast";

// Basic usage
<Raycast />

// With custom dimensions and className
<Raycast width={64} height={64} className="icon" />

// With style overrides
<Raycast style={{ opacity: 0.8 }} aria-label="Raycast" />
```

## Notes

- The component renders at **32×32 pixels** by default but accepts any `SVGProps` to override dimensions or add attributes such as `className`, `style`, or `aria-*`.
- The logo image is encoded as a **base64 PNG** inside an SVG `<image>` element, meaning no external network request is required — the icon is fully self-contained.
- Useful as part of an icon library or integration listing within the [Flamingo / OpenFrame](https://github.com/flamingo-stack/fleetmdm) platform UI for representing Raycast-based MDM integrations or tool connections.
