React SVG icon component for the Tunnelblick VPN application, rendering a 32×32 pixel PNG image encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`Tunnelblick`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing an embedded base64-encoded PNG icon.

## Usage Example

```typescript
import Tunnelblick from "./Tunnelblick";

// Basic usage
<Tunnelblick />

// With custom dimensions or className
<Tunnelblick width={64} height={64} className="app-icon" />

// With accessibility attributes
<Tunnelblick aria-label="Tunnelblick VPN" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`).
- The icon image is self-contained via a base64-encoded PNG `href` — no external asset files required.
- Default rendered size is `32×32` pixels.
