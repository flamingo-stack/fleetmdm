A React SVG component that renders the Teleport Connect logo as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`TeleportConnect`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper with an embedded PNG via a `data:image/png;base64` `href` on an `<image>` element.

## Usage Example

```typescript
import TeleportConnect from "./TeleportConnect";

// Basic usage
<TeleportConnect />

// With custom dimensions and className
<TeleportConnect width={64} height={64} className="my-icon" />

// With style overrides
<TeleportConnect style={{ opacity: 0.8 }} aria-label="Teleport Connect" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`), but the internal `<image>` dimensions remain fixed at 32×32.
- The PNG image data is fully self-contained — no external network request is made at render time.
- Defined in [`TeleportConnect.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/TeleportConnect.tsx) in the `flamingo-stack/fleetmdm` repository.
