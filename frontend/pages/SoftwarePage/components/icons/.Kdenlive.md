A React component that renders the Kdenlive video editor application icon as an SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Kdenlive`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Kdenlive logo icon.

## Usage Example

```typescript
import Kdenlive from "./Kdenlive";

// Basic usage
<Kdenlive />

// With custom dimensions and className
<Kdenlive width={64} height={64} className="app-icon" />

// With style overrides
<Kdenlive style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered as an `<svg>` wrapper containing an `<image>` element with a base64-encoded PNG, rather than native SVG paths.
- Default size is **32×32** pixels but can be overridden via `width` and `height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
