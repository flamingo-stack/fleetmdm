React SVG component that renders a sloth emoji/icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Sloth`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a 512×512 PNG image scaled down via base64 encoding.

## Usage Example

```typescript
import Sloth from "./Sloth";

// Basic usage
<Sloth />

// With custom dimensions or className
<Sloth width={64} height={64} className="icon" />

// With accessibility attributes
<Sloth aria-label="Sloth icon" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, color overrides, event handlers, etc.).
- The inner image is a base64-encoded PNG at native 512×512px rendered within a 32×32 SVG viewport — standard practice for shipping pixel-art or raster icons in icon libraries.
- No external dependencies beyond React.
