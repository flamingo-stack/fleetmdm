A React SVG icon component that renders the Microsoft Edge browser logo with gradient fills.

## Key Components

- **`Edge`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Edge browser icon using multiple layered SVG paths with linear and radial gradients.
- **Unique ID generation** — Uses `lodash.uniqueId` to generate collision-safe IDs for the clip path and six gradient definitions (`fillPathA`–`fillPathF`), preventing conflicts when multiple instances are rendered on the same page.

## Usage Example

```typescript
import Edge from "./Edge";

// Basic usage
<Edge />

// With custom dimensions
<Edge width={24} height={24} />

// With additional SVG props
<Edge className="browser-icon" aria-label="Microsoft Edge" />
```

## Notes

- The icon uses a combination of one `linearGradient`, one `radialGradient` for the bottom arc, one `linearGradient` + `radialGradient` for the left arc, and two `radialGradient`s for the top sweep — matching the official Edge brand color progression (blues through cyan to green).
- All gradient/clip IDs are scoped per instance via `uniqueId`, making the component safe for repeated use in the same DOM.
