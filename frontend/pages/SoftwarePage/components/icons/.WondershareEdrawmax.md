A React SVG component that renders the Wondershare EdrawMax application icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`WondershareEdrawmax`** — Default-exported React functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`)
- Renders a `32×32` `<svg>` wrapper containing an `<image>` element with an embedded base64 PNG of the EdrawMax logo

## Usage Example

```typescript
import WondershareEdrawmax from "./WondershareEdrawmax";

// Basic usage
<WondershareEdrawmax />

// With custom sizing and className
<WondershareEdrawmax
  width={64}
  height={64}
  className="app-icon"
/>

// With click handler
<WondershareEdrawmax
  onClick={() => console.log("EdrawMax icon clicked")}
  style={{ cursor: "pointer" }}
/>
```

## Notes

- The icon is self-contained — no external image dependencies at runtime
- Props spread directly onto the `<svg>` element, so `width`/`height` overrides are supported
- Consistent with other icon components in the codebase; swap `WondershareEdrawmax` for any peer icon component following the same `SVGProps` pattern
