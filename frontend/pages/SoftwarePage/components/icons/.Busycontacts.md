A React SVG wrapper component that renders the BusyContacts app icon as a 32×32 inline PNG image encoded in base64.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Busycontacts` | `React.FC` | Default SVG component wrapping a base64-encoded BusyContacts icon |

**Props:** Accepts all standard `SVGProps<SVGSVGElement>` — spread directly onto the root `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Busycontacts from "./Busycontacts";

// Basic usage
<Busycontacts />

// With custom dimensions and class
<Busycontacts width={64} height={64} className="app-icon" />

// With click handler
<Busycontacts onClick={() => console.log("BusyContacts clicked")} />
```

## Notes

- Default rendered size is **32×32 pixels**
- The icon is embedded as a base64 PNG `<image>` inside an `<svg>` wrapper — no external asset fetch required
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
