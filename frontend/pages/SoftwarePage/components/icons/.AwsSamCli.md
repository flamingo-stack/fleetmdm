React SVG icon component that renders the AWS SAM CLI logo as a 32×32 PNG embedded via a base64-encoded `<image>` element.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AwsSamCli` | React component | SVG wrapper rendering the AWS SAM CLI icon at 32×32px |

## Usage Example

```typescript
import { AwsSamCli } from "./AwsSamCli";

// Default usage
<AwsSamCli />

// With custom dimensions and className
<AwsSamCli width={64} height={64} className="icon" />

// With accessibility attributes
<AwsSamCli aria-label="AWS SAM CLI" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`)
- Default size is **32×32px**
- The icon image is self-contained — no external asset requests
