SVG icon component that renders the Spokenly brand logo as an inline PNG image encoded in base64, wrapped in an SVG container.

## Key Components

- **`Spokenly`** — Default export; a React functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG of the Spokenly logo via an `<image>` element.

## Usage Example

```typescript
import Spokenly from "./Spokenly";

// Basic usage
<Spokenly />

// With custom dimensions and className
<Spokenly width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Spokenly aria-label="Spokenly logo" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image data is self-contained (base64 PNG), requiring no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
