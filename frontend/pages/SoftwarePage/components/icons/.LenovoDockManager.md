A React SVG component that renders the Lenovo Dock Manager application icon as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`LenovoDockManager`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Lenovo Dock Manager icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import LenovoDockManager from "./LenovoDockManager";

// Basic usage
<LenovoDockManager />

// With custom dimensions or className
<LenovoDockManager width={64} height={64} className="app-icon" />

// With accessibility attributes
<LenovoDockManager aria-label="Lenovo Dock Manager" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The PNG image data is fully self-contained — no external image requests are made at runtime.
