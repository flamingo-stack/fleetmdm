React SVG icon component that renders the Visual C++ Redistributable x64 application icon as an inline base64-encoded PNG image.

## Key Components

- **`VcRedistX64`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper containing the VC++ Redistributable x64 icon as an embedded PNG.

## Usage Example

```typescript
import VcRedistX64 from "./VcRedistX64";

// Basic usage
<VcRedistX64 />

// With custom dimensions or className
<VcRedistX64 width={64} height={64} className="app-icon" />

// With accessibility attributes
<VcRedistX64 aria-label="Visual C++ Redistributable x64" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon data is fully self-contained (no external image requests).
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
