SVG icon component that renders the WebStorm IDE logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`WebStorm`** — Default export. A React functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the WebStorm logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import WebStorm from './WebStorm';

// Basic usage
<WebStorm />

// With custom size and className
<WebStorm width={64} height={64} className="icon" />

// With accessibility attributes
<WebStorm aria-label="WebStorm" role="img" />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The logo image is self-contained as a base64-encoded PNG — no external assets required.
- Fully compatible with standard SVG styling (e.g., `style`, `className`).
