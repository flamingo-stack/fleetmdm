SVG icon component that renders the Sequel Ace database application logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`SequelAce`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing the Sequel Ace logo as an embedded base64 PNG.

## Usage Example

```typescript
import SequelAce from "./SequelAce";

// Basic usage
<SequelAce />

// With custom dimensions and className
<SequelAce width={64} height={64} className="app-icon" />

// With accessibility attributes
<SequelAce aria-label="Sequel Ace" role="img" />
```

## Notes

- Fixed base dimensions of `32×32` pixels; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread.
- The icon is self-contained — no external image requests at runtime.
