A React SVG component that renders a TextExpander application icon as an inline base64-encoded PNG image (32×32 pixels).

## Key Components

- **`TextExpander`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import TextExpander from "./TextExpander";

// Basic usage
<TextExpander />

// With custom dimensions and styling
<TextExpander width={64} height={64} className="app-icon" />

// With click handler
<TextExpander onClick={() => console.log("TextExpander selected")} />
```

## Notes

- The icon image is embedded as a base64 PNG, requiring no external assets or network requests.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- Fully compatible with any standard SVG prop (e.g., `className`, `style`, `aria-label`).
