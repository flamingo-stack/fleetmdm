A React SVG component that renders the Snowflake SnowSQL icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`SnowflakeSnowsql`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG of the Snowflake SnowSQL logo.

## Usage Example

```typescript
import SnowflakeSnowsql from "./SnowflakeSnowsql";

// Basic usage
<SnowflakeSnowsql />

// With custom dimensions and class
<SnowflakeSnowsql width={64} height={64} className="icon" />

// With accessibility attributes
<SnowflakeSnowsql aria-label="Snowflake SnowSQL" role="img" />
```

## Notes

- The component forwards all `SVGProps` to the underlying `<svg>` element, allowing full customization of attributes such as `width`, `height`, `className`, `style`, and `aria-*` props.
- The icon image is self-contained as a base64-encoded PNG — no external asset dependencies.
- Default rendered size is **32×32 pixels**.
