A React component that renders the Plex media server logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Plex`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Plex from "./Plex";

// Basic usage
<Plex />

// With custom size and className
<Plex width={64} height={64} className="logo-icon" />

// With style overrides
<Plex style={{ opacity: 0.8 }} aria-label="Plex" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The PNG logo data is embedded as a base64 string inside an SVG `<image>` element — no external image requests are made.
