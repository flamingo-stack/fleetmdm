A React SVG component that renders the Calibrite Profiler application icon as a 32×32 inline PNG image embedded via base64 encoding.

## Key Components

- **`CalibriteProfiler`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG wrapper around an embedded PNG icon.

## Usage Example

```typescript
import CalibriteProfiler from "./CalibriteProfiler";

// Basic usage
<CalibriteProfiler />

// With custom styling
<CalibriteProfiler className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions via SVG props
<CalibriteProfiler width={64} height={64} />
```

## Notes

- The icon image is embedded as a base64-encoded PNG, making it self-contained with no external asset dependencies.
- All [`SVGProps`](https://react.dev/reference/react-dom/components/svg) are forwarded to the root `<svg>` element, allowing consumers to override `width`, `height`, `className`, `style`, and other standard SVG attributes.
