A React SVG component that renders the Spotify brand logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`Spotify`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Spotify logo within an `<svg>` wrapper.

## Usage Example

```typescript
import Spotify from "./Spotify";

// Basic usage
<Spotify />

// With custom size and className
<Spotify width={64} height={64} className="logo-icon" />

// With onClick handler
<Spotify onClick={() => console.log("Spotify clicked")} />
```

## Notes

- The logo image is self-contained via a base64-encoded PNG — no external asset dependencies.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- Supports all standard SVG props (e.g., `className`, `style`, `aria-*`) through prop spreading.
