A React SVG component that renders the Amethyst icon as an inline PNG image embedded via a base64 data URI within an SVG wrapper.

## Key Components

- **`Amethyst`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a 512×512 PNG icon via base64 encoding.

## Usage Example

```typescript
import Amethyst from "./Amethyst";

// Basic usage
<Amethyst />

// With custom dimensions and className
<Amethyst width={64} height={64} className="icon" />

// With accessibility attributes
<Amethyst aria-label="Amethyst" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full prop customization (e.g., `className`, `style`, `onClick`, `aria-*`).
- The default rendered size is `32×32` pixels; the embedded PNG source is `512×512`, providing sharp rendering at higher resolutions or when scaled up.
- The image data is self-contained — no external asset fetch is required at runtime.
