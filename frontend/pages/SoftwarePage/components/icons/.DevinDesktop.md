SVG icon component that renders the Devin Desktop application logo as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`DevinDesktop`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import DevinDesktop from "@/components/icons/DevinDesktop";

// Basic usage
<DevinDesktop />

// With custom sizing and styling
<DevinDesktop width={64} height={64} className="icon" />

// With accessibility attributes
<DevinDesktop aria-label="Devin Desktop" role="img" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon image is embedded as a **base64-encoded PNG** inside an `<image>` element, meaning no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
