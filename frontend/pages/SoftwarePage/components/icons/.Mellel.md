A React SVG component that renders the Mellel application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Mellel`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Mellel logo as an `<svg>` element containing an `<image>` tag with an embedded base64 PNG.

## Usage Example

```typescript
import Mellel from "./Mellel";

// Basic usage
<Mellel />

// With custom dimensions or className
<Mellel width={64} height={64} className="app-icon" />

// With style overrides
<Mellel style={{ opacity: 0.8 }} aria-label="Mellel" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The PNG data is embedded as a base64 `data:image/png` URI, so no external image asset is required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element.
