React SVG icon component that renders the Shotcut video editor logo as a 32×32 inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Shotcut`** — Default export. A functional React component wrapping an `<svg>` element that renders the Shotcut application icon via an embedded base64 PNG `<image>` tag.

## Usage Example

```typescript
import Shotcut from "@/components/icons/Shotcut";

// Basic usage
<Shotcut />

// With custom dimensions or className
<Shotcut width={64} height={64} className="icon" />

// With accessibility attributes
<Shotcut aria-label="Shotcut" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons/Shotcut.tsx) props, allowing full customization (e.g., `className`, `style`, `aria-*`, `width`, `height`).
- The icon is self-contained — no external image URLs or icon font dependencies.
- Default size is `32×32` pixels; override via `width`/`height` props.
