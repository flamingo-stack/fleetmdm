A React SVG icon component that renders the Zulip logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Zulip`** — Default export. A functional React component that wraps a base64-encoded Zulip logo PNG inside an SVG element, accepting all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import Zulip from "./Zulip";

// Basic usage
<Zulip />

// With custom dimensions and className
<Zulip width={64} height={64} className="icon" />

// With accessibility attributes
<Zulip aria-label="Zulip" role="img" />
```

## Notes

- Rendered at **32×32px** by default; override via `width`/`height` props.
- The logo is self-contained — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
