A React SVG icon component that renders the Via brand logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Via`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Via logo as an embedded PNG.

## Usage Example

```typescript
import Via from "./Via";

// Basic usage
<Via />

// With custom dimensions or className
<Via width={64} height={64} className="icon" />

// With accessibility attributes
<Via aria-label="Via" role="img" />
```

## Notes

- The logo image is embedded as a base64-encoded PNG (512×512 source, scaled to 32×32), so no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Part of the icon set in [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm).
