A React SVG component that renders a 4K Slideshow Maker application icon as a 32×32 inline SVG with an embedded PNG image encoded as a base64 data URI.

## Key Components

- **`FourKSlideshowMaker`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG icon

## Usage Example

```typescript
import FourKSlideshowMaker from "./FourKSlideshowMaker";

// Basic usage
<FourKSlideshowMaker />

// With custom dimensions or className
<FourKSlideshowMaker width={64} height={64} className="app-icon" />

// With accessibility attributes
<FourKSlideshowMaker aria-label="4K Slideshow Maker" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread to the root `<svg>` element
- The icon image is fully self-contained — no external asset dependencies
- Default rendered size is **32×32 pixels**; override via `width`/`height` props
- The embedded PNG is 512×512 source resolution, downscaled to 32×32 for display
