Renders a 32×32 SVG icon containing an embedded base64-encoded PNG image, used as a glyph/logo asset in the Flamingo Fleet MDM UI.

## Key Components

- **`Glyphs`** — Default export. A functional React component that renders an SVG wrapper with a fixed `32x32` viewport, embedding a base64 PNG via an `<image>` element. Accepts all standard `SVGProps<SVGSVGElement>` for customization.

## Usage Example

```typescript
import Glyphs from "./Glyphs";

// Basic usage
<Glyphs />

// With custom dimensions or className
<Glyphs width={64} height={64} className="my-icon" />

// With accessibility attributes
<Glyphs aria-label="Flamingo Fleet MDM" role="img" />
```

## Notes

- The embedded image is a 512×512 PNG downscaled to `32x32` via the SVG viewport.
- All SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread, making this composable with icon libraries or styled components.
