SVG icon component that renders the Groove OmniDialer application logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`GrooveOmniDialer`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG logo via a base64 data URI.

## Usage Example

```typescript
import GrooveOmniDialer from "./GrooveOmniDialer";

// Basic usage
<GrooveOmniDialer />

// With custom dimensions or className
<GrooveOmniDialer width={64} height={64} className="app-icon" />

// With style overrides
<GrooveOmniDialer style={{ borderRadius: 4 }} />
```

## Notes

- Accepts all standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) via prop spreading.
- Default rendered size is **32×32 pixels**.
- The PNG image is fully self-contained — no external image assets are required.
- Suitable for use in navigation bars, integration tiles, or app-switcher UIs where the Groove OmniDialer integration is referenced.
