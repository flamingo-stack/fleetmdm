A React SVG component that renders the RapidWeaver application icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Rapidweaver`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG image via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import Rapidweaver from './Rapidweaver';

// Basic usage
<Rapidweaver />

// With custom dimensions or className
<Rapidweaver width={64} height={64} className="app-icon" />

// With style overrides
<Rapidweaver style={{ opacity: 0.8 }} aria-label="RapidWeaver" />
```

## Notes

- The icon image is fully self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via prop spreading.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
