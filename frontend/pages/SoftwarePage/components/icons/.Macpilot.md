A React SVG component that renders the Macpilot application icon as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Macpilot`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded base64 PNG icon via an `<image>` element.

## Usage Example

```typescript
import Macpilot from './Macpilot';

// Basic usage
<Macpilot />

// With custom dimensions and className
<Macpilot width={64} height={64} className="app-icon" />

// With accessibility attributes
<Macpilot aria-label="Macpilot" role="img" />
```

## Notes

- The icon is a **32×32px** SVG wrapping a base64-encoded PNG asset, making it fully self-contained with no external image dependencies.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`) are forwarded via spread to the root `<svg>` element.
- The source file is located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — search for `Macpilot.tsx` in the repository for the full path.
