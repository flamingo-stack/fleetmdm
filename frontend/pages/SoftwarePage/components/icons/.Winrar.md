A React SVG component that renders the WinRAR application icon as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Winrar`** — A functional React component accepting standard `SVGProps<SVGSVGElement>`. Renders an SVG wrapper containing an embedded base64 PNG of the WinRAR logo at 32×32px. All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.

## Usage Example

```typescript
import { Winrar } from "./Winrar";

// Basic usage
<Winrar />

// With custom size and class
<Winrar width={64} height={64} className="app-icon" />

// With click handler
<Winrar onClick={() => console.log("WinRAR icon clicked")} />
```

## Notes

- The icon image is fully self-contained — no external asset requests at runtime.
- Default dimensions are `32×32`; override via `width`/`height` props.
