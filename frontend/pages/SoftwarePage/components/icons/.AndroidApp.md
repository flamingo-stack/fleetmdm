SVG icon component rendering an Android app logo with a dark slate background and white Android robot path illustration.

## Key Components

- **`AndroidApp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG icon with a rounded `#515774` background and white Android figure path.

## Usage Example

```typescript
import AndroidApp from "./AndroidApp";

// Basic usage
<AndroidApp />

// With custom dimensions
<AndroidApp width={24} height={24} />

// With additional SVG props
<AndroidApp className="icon" aria-label="Android App" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread (`{...props}`).
- Default rendered size is **32×32px** with `rx="4"` corner rounding.
- No internal state or side effects — purely presentational.
