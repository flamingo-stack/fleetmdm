A React SVG component that renders the Screenflick application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Screenflick`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Screenflick app icon as an inline base64 PNG.

## Usage Example

```typescript
import { Screenflick } from './Screenflick';

// Basic usage
<Screenflick />

// With custom dimensions and className
<Screenflick width={64} height={64} className="app-icon" />

// With style overrides
<Screenflick style={{ opacity: 0.8 }} aria-label="Screenflick" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG (`data:image/png;base64,...`) directly within the SVG `<image>` element — no external asset fetch required.
- Default render size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via spread.
