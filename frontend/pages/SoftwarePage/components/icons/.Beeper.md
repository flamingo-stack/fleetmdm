A React SVG component that renders the Beeper logo/icon as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`Beeper`** — Default export; a functional React component that wraps a 32×32 base64-encoded PNG inside an SVG element, accepting all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import { Beeper } from "./Beeper";

// Basic usage
<Beeper />

// With custom size and className
<Beeper width={64} height={64} className="icon" />

// With style override
<Beeper style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The image data is embedded as a base64 PNG, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
