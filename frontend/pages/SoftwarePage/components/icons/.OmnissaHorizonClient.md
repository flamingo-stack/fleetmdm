A React SVG component that renders the Omnissa Horizon Client application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`OmnissaHorizonClient`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 PNG icon via an embedded base64 data URI inside an `<svg>` element.

## Usage Example

```typescript
import OmnissaHorizonClient from "./OmnissaHorizonClient";

// Basic usage
<OmnissaHorizonClient />

// With custom dimensions and styling
<OmnissaHorizonClient
  width={64}
  height={64}
  className="app-icon"
  aria-label="Omnissa Horizon Client"
/>
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external assets or network requests are required.
