A React SVG icon component that renders the MindManager application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`MindManager`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 MindManager brand icon with an embedded base64 PNG image.

## Usage Example

```typescript
import MindManager from './MindManager';

// Basic usage
<MindManager />

// With custom size and className
<MindManager width={64} height={64} className="app-icon" />

// With accessibility attributes
<MindManager aria-label="MindManager" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels**, overridable via `width`/`height` props.
- The icon image is embedded as a base64 PNG, requiring no external asset files.
- Supports all standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`).
