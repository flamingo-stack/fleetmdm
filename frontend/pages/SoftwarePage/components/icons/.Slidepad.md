A React SVG component that renders the Slidepad integration icon as a 32×32 embedded PNG image within an SVG wrapper.

## Key Components

- **`Slidepad`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Slidepad logo as a base64-encoded PNG image.

## Usage Example

```typescript
import Slidepad from './Slidepad';

// Basic usage
<Slidepad />

// With custom dimensions and className
<Slidepad width={64} height={64} className="icon" />

// With accessible title via aria attributes
<Slidepad aria-label="Slidepad integration" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG (`data:image/png;base64,...`), making it self-contained with no external image dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is `32×32` pixels; override with `width` and `height` props as needed.
