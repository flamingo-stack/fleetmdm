React SVG component that renders the Xmplify logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Xmplify`** — Default export; a functional React component that wraps an inline `<svg>` element containing a base64-encoded PNG of the Xmplify logo
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>` via spread, allowing callers to override width, height, className, style, and other SVG attributes

## Usage Example

```typescript
import Xmplify from "./Xmplify";

// Basic usage
<Xmplify />

// With custom dimensions and className
<Xmplify width={64} height={64} className="my-icon" />

// With inline style override
<Xmplify style={{ opacity: 0.8 }} />
```

## Notes

- Default render size is `32×32` pixels
- The image is self-contained — no external asset fetch required
- Follows the same pattern as other SVG icon components in this repository (see [`/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm))
