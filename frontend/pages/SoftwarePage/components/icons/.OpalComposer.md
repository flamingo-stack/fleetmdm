A React SVG component that renders the OpalComposer icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`OpalComposer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a `<image>` element with a base64-encoded `href`.

## Usage Example

```typescript
import OpalComposer from "./OpalComposer";

// Basic usage
<OpalComposer />

// With custom dimensions or className
<OpalComposer width={64} height={64} className="icon" />

// With accessibility attributes
<OpalComposer aria-label="OpalComposer" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via the spread `{...props}`.
- The icon image is self-contained — no external image assets or network requests are required.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
