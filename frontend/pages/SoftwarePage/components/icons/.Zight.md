A React SVG component that renders the Zight application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Zight`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Zight logo as an embedded PNG.

## Usage Example

```typescript
import Zight from "./Zight";

// Basic usage
<Zight />

// With custom dimensions or className
<Zight width={64} height={64} className="icon" />

// With accessibility attributes
<Zight aria-label="Zight" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The PNG image data is embedded as a base64 `data:` URI — no external asset requests are made.
- Accepts the full `SVGProps<SVGSVGElement>` interface, enabling use of any standard SVG attribute (`style`, `className`, `onClick`, etc.).
