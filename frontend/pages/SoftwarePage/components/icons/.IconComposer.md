A React SVG icon component for the Composer application, rendering a 32×32 PNG image embedded as a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`IconComposer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG icon image.

## Usage Example

```typescript
import IconComposer from "./IconComposer";

// Basic usage
<IconComposer />

// With custom dimensions or className
<IconComposer width={64} height={64} className="my-icon" />

// With accessibility attributes
<IconComposer aria-label="Composer" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32 pixels**.
