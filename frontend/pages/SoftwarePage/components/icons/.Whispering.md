A React SVG component that renders a "Whispering" icon using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Whispering`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full prop forwarding (e.g., `className`, `style`, `onClick`).
- **Embedded image** — The icon is rendered as a 32×32 `<image>` element with a base64-encoded PNG `href`, meaning no external asset requests are required.

## Usage Example

```typescript
import Whispering from "./Whispering";

// Basic usage
<Whispering />

// With custom sizing and className
<Whispering width={64} height={64} className="icon-whispering" />

// With event handler
<Whispering onClick={() => console.log("clicked")} />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The base64 PNG data is embedded directly in the component, making it fully self-contained with no runtime asset dependencies.
- All standard SVG props are forwarded, enabling accessibility attributes (`aria-label`, `role`) and styling overrides.
