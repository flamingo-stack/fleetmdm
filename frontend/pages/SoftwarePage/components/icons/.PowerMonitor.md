React SVG icon component that renders a **Power Monitor** icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`PowerMonitor`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import PowerMonitor from "./PowerMonitor";

// Basic usage
<PowerMonitor />

// With custom dimensions and className
<PowerMonitor width={64} height={64} className="icon" />

// With accessibility attributes
<PowerMonitor
  aria-label="Power Monitor"
  role="img"
  style={{ display: "block" }}
/>
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external image assets are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
