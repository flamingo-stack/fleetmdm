React SVG wrapper component that renders the Affinity Photo application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AffinityPhoto` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapping the Affinity Photo icon as an embedded PNG |

## Usage Example

```typescript
import AffinityPhoto from "./AffinityPhoto";

// Basic usage
<AffinityPhoto />

// With custom dimensions via SVG props
<AffinityPhoto width={64} height={64} className="app-icon" />

// With accessibility attributes
<AffinityPhoto aria-label="Affinity Photo" role="img" />
```

## Notes

- The icon image is self-contained — no external asset requests are made at runtime.
- All standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32 px**; override with `width`/`height` props as needed.
