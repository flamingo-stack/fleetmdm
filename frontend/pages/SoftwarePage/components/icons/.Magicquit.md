React SVG icon component that renders the Magicquit application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Magicquit`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Magicquit app icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import Magicquit from './Magicquit';

// Basic usage
<Magicquit />

// With custom dimensions or className
<Magicquit width={64} height={64} className="app-icon" />

// With accessibility attributes
<Magicquit aria-label="Magicquit" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained — no external image fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
