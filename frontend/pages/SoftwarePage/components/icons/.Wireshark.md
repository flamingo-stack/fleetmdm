A React SVG icon component that renders the Wireshark network protocol analyzer logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`Wireshark`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Wireshark from "./Wireshark";

// Basic usage
<Wireshark />

// With custom size and class
<Wireshark width={64} height={64} className="icon" />

// With click handler
<Wireshark onClick={() => console.log("Wireshark clicked")} />
```

## Notes

- Renders at **32×32px** by default.
- The icon is embedded as a base64-encoded PNG via an `<image>` tag inside the SVG — no external asset dependency required.
- All standard SVG props are forwarded via spread (`{...props}`), enabling size overrides, accessibility attributes (`aria-label`), and event handlers.
