A React SVG component that renders the Abstract icon as an inline SVG using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Abstract`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarding them to the root `<svg>` element.

## Usage Example

```typescript
import Abstract from "./Abstract";

// Basic usage
<Abstract />

// With custom size and class
<Abstract width={64} height={64} className="icon" />

// With accessibility attributes
<Abstract aria-label="Abstract icon" role="img" />
```

## Notes

- The icon is fixed at 32×32 by default but can be overridden via `width`/`height` props.
- The image data is self-contained as a base64 PNG — no external asset requests.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are supported via spread.
