A React SVG icon component that renders a 32×32 "Hides" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Hides`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Hides from "./Hides";

// Basic usage
<Hides />

// With custom size and className
<Hides width={64} height={64} className="icon" />

// With click handler
<Hides onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external asset dependencies at runtime.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
