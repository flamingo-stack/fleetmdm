React SVG wrapper component that renders the "Shifty" icon as a 32×32 PNG embedded inline via a base64-encoded data URI.

## Key Components

- **`Shifty`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 `<svg>` element with an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import Shifty from "./Shifty";

// Basic usage
<Shifty />

// With custom className or style
<Shifty className="icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Shifty aria-label="Shifty icon" role="img" />
```

## Notes

- The PNG asset is inlined as a base64 data URI, so no external image request is made.
- The component is sized at **32×32px** by default; width/height can be overridden via props.
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) through prop spreading.
