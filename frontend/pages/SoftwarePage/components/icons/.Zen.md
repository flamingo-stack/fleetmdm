React SVG icon component that renders the Zen browser logo as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`Zen`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an inline base64-encoded PNG image of the Zen browser icon.

## Usage Example

```typescript
import Zen from "./Zen";

// Basic usage
<Zen />

// With custom dimensions and className
<Zen width={64} height={64} className="icon" />

// With accessibility attributes
<Zen aria-label="Zen browser" role="img" />
```

## Notes

- Default size is `32×32` pixels; override via `width`/`height` props.
- The icon is self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
