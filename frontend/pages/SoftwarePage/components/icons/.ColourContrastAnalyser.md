React SVG icon component that renders the Colour Contrast Analyser application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`ColourContrastAnalyser`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a fixed 32×32 SVG containing the tool's icon as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import ColourContrastAnalyser from "./ColourContrastAnalyser";

// Basic usage
<ColourContrastAnalyser />

// With custom dimensions or className
<ColourContrastAnalyser width={64} height={64} className="icon" />

// As part of a tool listing
<img aria-label="Colour Contrast Analyser" />
<ColourContrastAnalyser aria-hidden="true" />
```

## Notes

- All props are forwarded to the underlying `<svg>` element via spread (`{...props}`), allowing overrides for `className`, `style`, `aria-*`, `width`, `height`, etc.
- The icon image is fully self-contained — no external image requests are made at runtime.
- The embedded PNG is 512×512px (as declared in its EXIF/XMP metadata), downscaled to 32×32 by the SVG viewport by default.
