A React component that renders the Sonos brand logo as an SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Sonos`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Sonos logo as an inline base64 PNG.

## Usage Example

```typescript
import Sonos from "./Sonos";

// Basic usage
<Sonos />

// With custom dimensions or className
<Sonos width={64} height={64} className="brand-logo" />

// With accessibility attributes
<Sonos aria-label="Sonos" role="img" />
```

## Notes

- Default size is **32×32 pixels**, overridable via `width`/`height` props.
- The logo image is self-contained as a base64 PNG — no external asset dependencies.
- Fully compatible with standard SVG prop forwarding (e.g., `style`, `className`, `onClick`).
