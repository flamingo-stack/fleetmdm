A React SVG component that renders the Antinote brand icon as an inline SVG embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Antinote`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing callers to override or extend any SVG attribute (e.g., `className`, `style`, `width`, `height`).

## Usage Example

```typescript
import Antinote from "./Antinote";

// Basic usage
<Antinote />

// With custom dimensions and class
<Antinote width={64} height={64} className="brand-icon" />

// With inline style override
<Antinote style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is embedded as a base64 PNG (`data:image/png;base64,...`) within an SVG `<image>` element — no external asset fetch required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props are forwarded via spread (`{...props}`), making it fully composable within icon systems or design token libraries.
