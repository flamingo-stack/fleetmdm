React SVG component that renders the Sonobus application icon as an inline PNG image embedded via base64 encoding within an SVG wrapper.

## Key Components

- **`Sonobus`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG icon.

## Usage Example

```typescript
import Sonobus from "./Sonobus";

// Basic usage
<Sonobus />

// With custom dimensions or className
<Sonobus width={64} height={64} className="app-icon" />

// With accessibility attributes
<Sonobus aria-label="Sonobus" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The PNG image data is embedded as a base64 `data:image/png` URI inside an SVG `<image>` element — no external asset fetch required.
