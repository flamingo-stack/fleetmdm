A React SVG component that renders the letter "R" as an inline PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`R`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import R from "./R";

// Basic usage
<R />

// With custom dimensions or className
<R width={64} height={64} className="icon" />

// With style overrides
<R style={{ opacity: 0.8 }} aria-label="R icon" />
```

## Notes

- The component spreads all `SVGProps` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`).
- The image content is a self-contained base64 PNG — no external asset dependencies.
- Default rendered size is **32×32 pixels**.
