React SVG icon component that renders a Lunar logo using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Lunar`** — Default export. A functional React component wrapping an `<svg>` element with a single `<image>` child that renders a base64-encoded PNG. Accepts and spreads all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Lunar from "./Lunar";

// Basic usage
<Lunar />

// With custom dimensions or className
<Lunar width={64} height={64} className="icon" />

// With style override
<Lunar style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32px**; override via `width`/`height` props.
- The PNG image data is fully self-contained (base64 inline) — no external asset dependency.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element.
