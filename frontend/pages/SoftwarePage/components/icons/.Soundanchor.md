A React SVG component that renders the Soundanchor brand icon as an inline SVG element embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Soundanchor`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Soundanchor from "./Soundanchor";

// Basic usage
<Soundanchor />

// With custom dimensions and className
<Soundanchor width={64} height={64} className="brand-icon" />

// With style overrides
<Soundanchor style={{ opacity: 0.8 }} aria-label="Soundanchor" />
```

## Notes

- The icon renders at **32×32px** by default but accepts any `SVGProps` override.
- The image is embedded as a **base64-encoded PNG** inside an `<image>` element — no external asset fetch required.
- The source PNG is encoded at 512×512px internally and scaled to the SVG viewport.
