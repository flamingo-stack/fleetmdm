A React component that renders the Hyper terminal application logo as an SVG icon with an embedded base64-encoded PNG image.

## Key Components

- **`Hyper`** — Default export; a functional React component that renders a 32×32 SVG containing the Hyper terminal logo as an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import Hyper from "./Hyper";

// Basic usage
<Hyper />

// With custom dimensions and className
<Hyper width={64} height={64} className="icon" />

// With style overrides
<Hyper style={{ opacity: 0.8 }} aria-label="Hyper terminal" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/common) props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `onClick`).
- Default rendered size is **32×32 pixels**.
- The logo image is self-contained via a base64-encoded PNG — no external asset dependencies.
