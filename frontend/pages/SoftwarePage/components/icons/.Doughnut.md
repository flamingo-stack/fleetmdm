A React SVG component that renders a doughnut emoji icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Doughnut`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import { Doughnut } from "./Doughnut";

// Basic usage
<Doughnut />

// With custom size and className
<Doughnut width={64} height={64} className="icon" />

// With inline style
<Doughnut style={{ opacity: 0.8 }} />
```

## Notes

- The icon renders at 32×32px by default but can be overridden via props.
- The image data is self-contained as a base64-encoded PNG — no external asset dependencies.
- All standard SVG attributes (`className`, `style`, `onClick`, `aria-*`, etc.) are supported through prop spreading.
