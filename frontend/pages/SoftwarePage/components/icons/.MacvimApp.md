A React SVG component that renders the MacVim application icon as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`MacvimApp`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG element with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import MacvimApp from "./MacvimApp";

// Basic usage
<MacvimApp />

// With custom dimensions or className
<MacvimApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<MacvimApp aria-label="MacVim" role="img" />
```

## Notes

- The icon image data is fully self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Rendered dimensions default to `32×32` but can be overridden via props.
