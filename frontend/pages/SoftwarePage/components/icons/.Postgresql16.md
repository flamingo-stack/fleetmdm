React SVG icon component that renders a PostgreSQL 16 logo as a base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`Postgresql16`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 PostgreSQL logo icon via an embedded base64 PNG.

## Usage Example

```typescript
import Postgresql16 from "./Postgresql16";

// Basic usage
<Postgresql16 />

// With custom size and className
<Postgresql16 width={64} height={64} className="db-icon" />

// With accessibility attributes
<Postgresql16 aria-label="PostgreSQL 16" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The icon image is embedded as a base64 PNG (`data:image/png;base64,...`), so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Postgresql16.tsx) — typically used in database connection UIs or service selection screens within the OpenFrame platform.
