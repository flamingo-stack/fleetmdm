A React SVG icon component that renders the TradingView logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Tradingview`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing the TradingView brand logo.

## Usage Example

```typescript
import Tradingview from "./Tradingview";

// Basic usage
<Tradingview />

// With custom dimensions and className
<Tradingview width={64} height={64} className="icon" />

// With inline styles
<Tradingview style={{ opacity: 0.8 }} />
```

## Notes

- The logo image is embedded as a base64-encoded PNG, requiring no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
