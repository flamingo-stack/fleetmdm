React SVG component that renders the Smultron application icon as an inline PNG image embedded via base64 encoding within an SVG wrapper.

## Key Components

- **`Smultron`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element that contains a base64-encoded PNG of the Smultron icon.

## Usage Example

```typescript
import Smultron from "./Smultron";

// Basic usage
<Smultron />

// With custom dimensions or className
<Smultron width={64} height={64} className="app-icon" />

// With accessibility attributes
<Smultron aria-label="Smultron" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default but can be overridden via props.
- The PNG image data is entirely self-contained (base64-encoded), requiring no external image assets or network requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
