SVG icon component rendering the Apple logo on a dark background (`#515774`), used to represent Apple/macOS app targets in the Fleet MDM UI.

## Key Components

- **`AppleApp`** — Default export. A functional React component that renders a 32×32 SVG Apple logo icon, accepting all standard `SVGProps<SVGSVGElement>` props for customization (e.g., `width`, `height`, `className`, `style`).

## Usage Example

```typescript
import AppleApp from "components/icons/AppleApp";

// Basic usage
<AppleApp />

// With custom dimensions
<AppleApp width={24} height={24} />

// With className for styling
<AppleApp className="platform-icon" aria-label="Apple App" />
```

## Notes

- The icon is fixed at a **32×32 viewBox** by default but can be overridden via props.
- The background fill (`#515774`) is part of the SVG itself — use `fill="transparent"` or override via CSS if a transparent background is needed.
- Located in the Fleet MDM icon library at [`frontend/components/icons/AppleApp.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/icons/AppleApp.tsx).
