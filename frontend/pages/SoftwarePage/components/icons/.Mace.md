A React SVG component that renders the Mace icon as an inline SVG element with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Mace`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a base64-encoded PNG of the Mace icon.

## Usage Example

```typescript
import Mace from "./Mace";

// Basic usage
<Mace />

// With custom dimensions and className
<Mace width={64} height={64} className="icon" />

// With style overrides
<Mace style={{ opacity: 0.8 }} aria-label="Mace icon" />
```

## Notes

- The icon image is embedded directly as a base64 PNG (`data:image/png;base64,...`), so no external image assets are required.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- Default render size is **32×32** pixels.
