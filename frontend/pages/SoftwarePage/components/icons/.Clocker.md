A React SVG component that renders the Clocker app icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Clocker` | `React.FC<SVGProps<SVGSVGElement>>` | Default export rendering a 32×32 SVG icon with an embedded PNG image |

## Usage Example

```typescript
import Clocker from "./Clocker";

// Basic usage
<Clocker />

// With custom dimensions or className
<Clocker width={64} height={64} className="icon" />

// With accessibility attributes
<Clocker aria-label="Clocker" role="img" />
```

## Notes

- The component accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element.
- The default rendered size is **32×32px**; the embedded PNG is a **512×512px** high-resolution asset downscaled via the SVG viewport.
- The icon is self-contained — no external image requests are made at runtime.
