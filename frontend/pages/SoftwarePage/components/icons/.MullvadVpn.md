A React SVG component that renders the Mullvad VPN logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`MullvadVpn`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 Mullvad VPN icon with an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import MullvadVpn from "./MullvadVpn";

// Basic usage
<MullvadVpn />

// With custom dimensions or className
<MullvadVpn width={64} height={64} className="vpn-icon" />

// With style overrides
<MullvadVpn style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The icon is self-contained — no external image assets required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
