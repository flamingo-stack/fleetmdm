A React SVG component that renders a 32×32 "Blip" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Blip`** — Default export. A functional React component that wraps a base64-encoded PNG inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Blip from "./Blip";

// Basic usage
<Blip />

// With custom size and className
<Blip width={64} height={64} className="my-icon" />

// With inline style override
<Blip style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image source is a **self-contained base64 PNG** — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded directly to the `<svg>` element via the spread `{...props}` pattern.
