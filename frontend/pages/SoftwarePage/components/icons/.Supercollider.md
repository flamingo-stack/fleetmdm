A React SVG icon component that renders the SuperCollider logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Supercollider`** — Default export. A functional React component that renders a 32×32 SVG containing the SuperCollider logo as an embedded PNG via a base64-encoded `data:image/png` `href` attribute.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, aria-label, etc.).

## Usage Example

```typescript
import Supercollider from "./Supercollider";

// Basic usage
<Supercollider />

// With custom size and class
<Supercollider width={64} height={64} className="icon" />

// With accessibility
<Supercollider aria-label="SuperCollider" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The image is self-contained — no external asset files are required.
- Part of the icon library in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository, likely found under an icons or assets directory.
