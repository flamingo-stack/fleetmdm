React SVG icon component that renders the Clop application logo as a 32×32 PNG image embedded inline via a base64 data URI.

## Key Components

- **`Clop`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the outer `<svg>` element for full customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Clop from "./Clop";

// Basic usage
<Clop />

// With custom size and class
<Clop width={64} height={64} className="icon" />

// With click handler
<Clop onClick={() => console.log("clicked")} />
```

## Notes

- The icon is rendered at **32×32px** by default.
- The inner `<image>` element contains a **base64-encoded PNG** rather than native SVG paths, meaning it will not scale crisply beyond the original resolution.
- All SVG props are forwarded, so size, accessibility attributes (`aria-label`, `role`), and event handlers can be passed directly.
