A React SVG icon component that renders the Camunda Modeler logo as a base64-encoded PNG image embedded within an SVG element.

## Key Components

- **`CamundaModeler`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Camunda Modeler icon as an embedded PNG.

## Usage Example

```typescript
import CamundaModeler from "./CamundaModeler";

// Basic usage
<CamundaModeler />

// With custom dimensions and className
<CamundaModeler width={64} height={64} className="icon" />

// With inline styles
<CamundaModeler style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via `width`/`height` props.
- The icon is self-contained — no external image files or network requests required.
- Accepts all standard SVG element props (e.g., `className`, `style`, `onClick`) via prop spreading.
