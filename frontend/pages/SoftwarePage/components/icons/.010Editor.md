SVG icon component for the "010 Editor" application, rendering a 32×32 pixel PNG image encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`ZeroOneZeroEditor`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a base64-encoded PNG of the 010 Editor application icon.

## Usage Example

```typescript
import ZeroOneZeroEditor from "./010Editor";

// Basic usage
<ZeroOneZeroEditor />

// With custom dimensions or className
<ZeroOneZeroEditor width={64} height={64} className="app-icon" />

// With accessibility attributes
<ZeroOneZeroEditor aria-label="010 Editor" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, class, style, event handlers, etc.).
- The icon image is self-contained via a base64 `data:image/png` URI — no external asset fetch required.
- Default dimensions are `32×32` pixels; override via `width`/`height` props.
