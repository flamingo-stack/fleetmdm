A React SVG component that renders a 32×32 "Bartender" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Bartender`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders the icon as an `<svg>` element with an embedded PNG via a base64 `<image>` tag.

## Usage Example

```typescript
import Bartender from "./Bartender";

// Basic usage
<Bartender />

// With custom sizing or className
<Bartender width={64} height={64} className="icon" />

// With accessibility attributes
<Bartender aria-label="Bartender" role="img" />
```

## Notes

- The component is fully controlled via `SVGProps`, allowing consumers to override `width`, `height`, `className`, `style`, and any other standard SVG attributes.
- The icon is self-contained — no external image assets are required at runtime.
- Default dimensions are `32×32` pixels; the embedded PNG source is `512×512` pixels.
