A React SVG component that renders the VLC media player application icon as an inline PNG image (base64-encoded, 128×128px) embedded within an SVG wrapper.

## Key Components

- **`Vlc`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Vlc from './Vlc';

// Basic usage
<Vlc />

// With custom dimensions and className
<Vlc width={64} height={64} className="app-icon" />

// With onClick handler
<Vlc onClick={() => openWithVlc(file)} style={{ cursor: 'pointer' }} />
```

## Notes

- The icon renders at **32×32px** by default but accepts any valid SVG sizing props.
- The image data is fully self-contained (base64 PNG), requiring no external assets or network requests.
- Suitable for use in file-type indicators, application launchers, or media player UI components within the [FleetMDM](https://github.com/flamingo-stack/fleetmdm) interface.
