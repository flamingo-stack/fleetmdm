React SVG component that renders the Hazel operating system icon as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Hazel`** — Default export. A functional React component that wraps a base64-encoded PNG in an SVG `<image>` element, forwarding all standard `SVGProps<SVGSVGElement>` to the root `<svg>` tag.

## Usage Example

```typescript
import Hazel from "./Hazel";

// Basic usage
<Hazel />

// With custom props
<Hazel className="os-icon" style={{ opacity: 0.8 }} />

// As part of an OS selector list
const osIcons = [<Hazel key="hazel" aria-label="Hazel" />];
```

## Notes

- The component renders at a fixed **32×32 px** by default; override via `width`/`height` props.
- The PNG is inlined as a base64 data URI, so no external asset request is made at runtime.
- Intended for use in Fleet MDM device/OS identification UIs where the Hazel macOS version icon is needed alongside other platform icons.
