A React SVG component that renders the Extradock application icon as a 32×32 PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Extradock`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 SVG wrapper around an embedded PNG icon.

## Usage Example

```typescript
import Extradock from "./Extradock";

// Basic usage
<Extradock />

// With custom dimensions or className
<Extradock width={64} height={64} className="app-icon" />

// With accessibility attributes
<Extradock aria-label="Extradock" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via `{...props}`.
- The icon image is self-contained — no external image assets or network requests are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
