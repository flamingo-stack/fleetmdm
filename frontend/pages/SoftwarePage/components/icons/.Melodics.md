A React SVG component that renders the Melodics brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Melodics`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full SVG attribute customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Melodics from './Melodics';

// Basic usage
<Melodics />

// With custom size and class
<Melodics width={64} height={64} className="icon" />

// With click handler
<Melodics onClick={() => console.log('clicked')} />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default, with the actual graphic embedded as a base64 PNG `<image>` element.
- All standard SVG props are forwarded via spread (`{...props}`), so `width`/`height` overrides apply to the outer `<svg>` but not the inner `<image>` element — scale via CSS `transform` or wrapper styles if resizing is needed.
