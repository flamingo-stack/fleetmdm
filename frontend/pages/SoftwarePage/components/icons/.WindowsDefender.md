A React SVG icon component that renders the Windows Defender logo as an inline SVG element.

## Key Components

- **`WindowsDefender`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Windows Defender shield icon in blue (`#0177D7`) on a white background.

## Usage Example

```typescript
import WindowsDefender from "./WindowsDefender";

// Basic usage
<WindowsDefender />

// With custom dimensions and className
<WindowsDefender width={24} height={24} className="icon" />

// With inline styles
<WindowsDefender style={{ display: "block" }} aria-label="Windows Defender" />
```

## Notes

- No intrinsic `width`/`height` attributes are set on the SVG — size is controlled entirely via props.
- Accepts all standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) via spread.
