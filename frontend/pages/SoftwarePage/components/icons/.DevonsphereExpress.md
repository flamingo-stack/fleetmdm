React SVG component that renders the DevonsphereExpress icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`DevonsphereExpress`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import DevonsphereExpress from "./DevonsphereExpress";

// Basic usage
<DevonsphereExpress />

// With custom dimensions or className
<DevonsphereExpress width={64} height={64} className="icon" />

// With accessibility attributes
<DevonsphereExpress aria-label="DevonsphereExpress" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override via `width`/`height` props.
