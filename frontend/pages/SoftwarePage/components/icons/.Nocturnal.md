React SVG component that renders the Nocturnal icon as an inline PNG image embedded via a base64 data URI within an SVG wrapper.

## Key Components

- **`Nocturnal`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG element containing an embedded 512×512 PNG image scaled to fit.

## Usage Example

```typescript
import Nocturnal from "./Nocturnal";

// Basic usage
<Nocturnal />

// With custom dimensions or className
<Nocturnal width={64} height={64} className="icon" />

// With accessibility attributes
<Nocturnal aria-label="Nocturnal icon" role="img" />
```

## Notes

- The icon image is self-contained — no external asset dependencies at runtime.
- All `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element.
- The embedded PNG has EXIF metadata indicating a 512×512 source image, downscaled to 32×32 via SVG `width`/`height` attributes.
