React SVG icon component that renders the Dash logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Dash`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64 PNG of the Dash logo.

## Usage Example

```typescript
import Dash from "./Dash";

// Basic usage
<Dash />

// With custom dimensions or className
<Dash width={64} height={64} className="icon" />

// With accessibility attributes
<Dash aria-label="Dash" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, style, className, event handlers, etc.).
- The icon is self-contained — no external image assets are required.
- Default dimensions are `32×32` pixels.
