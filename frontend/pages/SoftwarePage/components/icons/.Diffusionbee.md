A React SVG component that renders the DiffusionBee application icon as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Diffusionbee`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element with the DiffusionBee logo embedded as a base64 PNG `<image>`.

## Usage Example

```typescript
import Diffusionbee from "./Diffusionbee";

// Basic usage
<Diffusionbee />

// With custom dimensions and class
<Diffusionbee width={64} height={64} className="app-icon" />

// With accessibility attributes
<Diffusionbee aria-label="DiffusionBee" role="img" />
```

## Notes

- The icon is self-contained — no external image assets or network requests required.
- All standard SVG props (`className`, `style`, `width`, `height`, `onClick`, etc.) are forwarded via spread.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
