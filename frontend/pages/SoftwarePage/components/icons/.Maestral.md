A React SVG component that renders the Maestral application icon as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Maestral`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Maestral app icon as an embedded PNG.

## Usage Example

```typescript
import Maestral from "./Maestral";

// Basic usage
<Maestral />

// With custom dimensions or className
<Maestral width={64} height={64} className="app-icon" />

// With style overrides
<Maestral style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is self-contained — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded directly to the `<svg>` element via spread.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
