A React SVG component that renders the Internet Explorer browser icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Iexplorer`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders an `<svg>` element containing the IE logo as an inline base64 PNG image.

## Usage Example

```typescript
import Iexplorer from "./Iexplorer";

// Basic usage
<Iexplorer />

// With custom styling
<Iexplorer className="browser-icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32x32)
<Iexplorer width={64} height={64} />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via props.
- The PNG image data is embedded directly as a base64 string, requiring no external asset files.
- Accepts all standard SVG element props (e.g., `className`, `style`, `onClick`, `aria-label`).
