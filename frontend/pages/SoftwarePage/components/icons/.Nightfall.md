A React SVG component that renders the Nightfall icon as a 32×32 SVG element embedding a base64-encoded PNG image.

## Key Components

- **`Nightfall`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { Nightfall } from "./Nightfall";

// Basic usage
<Nightfall />

// With custom dimensions or class
<Nightfall width={64} height={64} className="icon" />

// With inline style
<Nightfall style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via spread (`{...props}`), making it fully composable.
- The icon image is self-contained — no external asset dependencies at runtime.
- Default rendered size is `32×32` px; override with `width`/`height` props as needed.
