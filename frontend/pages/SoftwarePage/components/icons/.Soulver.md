A React SVG component that renders the Soulver app icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Soulver`** — Default export. A functional React component that wraps a base64-encoded PNG of the Soulver logo inside an `<svg>` element using an `<image>` tag.

## Usage Example

```typescript
import Soulver from "./Soulver";

// Basic usage
<Soulver />

// With custom props (className, style, onClick, etc.)
<Soulver className="app-icon" width={64} height={64} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The icon image is fully self-contained — no external asset files are required.
- Default rendered size is **32×32 pixels**; the embedded PNG is originally 512×512.
