A React SVG component that renders the Enpass password manager logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Enpass`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around a base64-encoded PNG of the Enpass logo.

## Usage Example

```typescript
import Enpass from "./Enpass";

// Basic usage
<Enpass />

// With custom dimensions or className
<Enpass width={64} height={64} className="icon" />

// With accessibility attributes
<Enpass aria-label="Enpass" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The image data is self-contained (base64 PNG), requiring no external assets or network requests.
- Fully compatible with any React project using standard SVG prop forwarding.
