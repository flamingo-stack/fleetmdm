React SVG icon component that renders the Sourcetree logo using an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Sourcetree`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Sourcetree logo as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import Sourcetree from "./Sourcetree";

// Basic usage
<Sourcetree />

// With custom size via SVG props
<Sourcetree width={64} height={64} />

// With className or style
<Sourcetree className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The component is **32×32 pixels** by default, matching the embedded image dimensions.
- All SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded directly to the root `<svg>` element via spread.
- The logo image is fully self-contained as a base64 PNG — no external network request is required at runtime.
- Resizing via `width`/`height` props will scale the SVG viewport, but the inner `<image>` element remains fixed at 32×32 internally; for crisp scaling consider overriding both the SVG and image dimensions.
