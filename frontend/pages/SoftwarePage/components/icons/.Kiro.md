React SVG icon component that renders the Kiro logo as a 32×32 PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Kiro`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Kiro logo as an inline base64 PNG image.

## Usage Example

```typescript
import Kiro from "./Kiro";

// Basic usage
<Kiro />

// With custom dimensions or className
<Kiro width={64} height={64} className="icon" />

// With accessibility attributes
<Kiro aria-label="Kiro logo" role="img" />
```

## Notes

- The logo image is embedded as a base64-encoded PNG (512×512 source), so no external image asset is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**.
