React SVG icon component that renders the LastPass brand logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`LastPass`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded LastPass logo PNG via an `<image>` element.

## Usage Example

```typescript
import LastPass from "./LastPass";

// Basic usage
<LastPass />

// With custom dimensions and className
<LastPass width={64} height={64} className="brand-icon" />

// With accessibility attributes
<LastPass aria-label="LastPass" role="img" />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- The logo image is fully self-contained — no external network requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element.
