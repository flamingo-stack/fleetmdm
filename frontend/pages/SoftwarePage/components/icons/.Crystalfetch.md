React SVG component that renders the Crystalfetch application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Crystalfetch`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG wrapper containing a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Crystalfetch from "./Crystalfetch";

// Basic usage
<Crystalfetch />

// With custom size or class
<Crystalfetch width={64} height={64} className="app-icon" />

// With inline styles
<Crystalfetch style={{ borderRadius: "4px" }} />
```

## Notes

- The icon image is fully self-contained — no external network requests are made at runtime.
- The underlying PNG is 512×512 (as noted in the embedded EXIF metadata) but is rendered at 32×32 by default. Override `width`/`height` props to scale up without losing quality.
- All standard SVG props (`className`, `style`, `aria-*`, event handlers, etc.) are forwarded to the root `<svg>` element.
