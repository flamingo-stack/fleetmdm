Renders a software icon with a priority chain: custom API blob → direct image URL → matched SVG fallback based on software name/source.

## Key Components

**Props (`ISoftwareIconProps`)**
- `name` – Software name for SVG fallback matching
- `source` – Software source for SVG fallback matching
- `size` – Icon dimensions (`SoftwareIconSizes`, defaults to `"small"` / 24×24px)
- `url` – Direct image URL or `/api/` path for custom icon fetching
- `uploadedAt` – Timestamp used as a query key to refetch stale custom icons

**Icon resolution priority**
1. API blob — if `url` starts with `/api/`, fetches via `softwareAPI.getSoftwareIconFromApiUrl` and converts to an object URL
2. Direct URL — used as-is (e.g. VPP image URLs)
3. SVG fallback — `getMatchedSoftwareIcon({ name, source })` when no URL is set or the image fails to load (e.g. 429 rate limit)

## Usage Example

```typescript
// Small icon using automatic SVG fallback
<SoftwareIcon name="Google Chrome" source="apps" />

// Custom icon served from Fleet API
<SoftwareIcon
  url="/api/v1/fleet/software/123/icon"
  uploadedAt="2024-06-01T12:00:00Z"
  size="medium"
/>

// Direct image URL (e.g. VPP)
<SoftwareIcon
  url="https://is1-ssl.mzstatic.com/image/thumb/..."
  name="Slack"
  size="large"
/>
```
