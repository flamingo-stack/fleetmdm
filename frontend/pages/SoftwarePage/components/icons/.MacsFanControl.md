A React SVG component that renders the Macs Fan Control application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`MacsFanControl`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Macs Fan Control app icon as an embedded PNG via base64 data URI.

## Usage Example

```typescript
import MacsFanControl from "./MacsFanControl";

// Basic usage
<MacsFanControl />

// With custom dimensions or className
<MacsFanControl width={64} height={64} className="app-icon" />

// With style overrides
<MacsFanControl style={{ opacity: 0.8 }} />
```

## Notes

- The icon is a **32×32** SVG wrapper containing a base64-encoded PNG (originally 512×512 per EXIF metadata).
- All standard `SVGProps` are forwarded to the root `<svg>` element, allowing full styling and attribute overrides.
- No external image dependencies — the icon is fully self-contained in the bundle.
