A React SVG icon component that renders a "Sidenotes" icon as a 32×32 SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Sidenotes`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as an inline SVG wrapper around a base64 PNG image asset.

## Usage Example

```typescript
import Sidenotes from "./Sidenotes";

// Basic usage
<Sidenotes />

// With custom className or style
<Sidenotes className="icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Sidenotes aria-label="Sidenotes" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default; dimensions can be overridden via props.
- The PNG asset is embedded as a base64 `data:image/png` URI inside an SVG `<image>` element — no external file dependency.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
