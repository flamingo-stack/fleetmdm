A React SVG icon component that renders the SABnzbd application logo as a 32×32 inline PNG image embedded via base64 within an SVG element.

## Key Components

- **`Sabnzbd`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Sabnzbd from "./Sabnzbd";

// Basic usage
<Sabnzbd />

// With custom dimensions or className
<Sabnzbd width={64} height={64} className="icon" />

// With style overrides
<Sabnzbd style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at 32×32 pixels by default but accepts any `SVGProps` overrides.
- The image is embedded as a base64-encoded PNG (`data:image/png;base64,...`), so no external image assets are required.
