A React SVG component that renders a 32×32 color icon using an embedded base64-encoded PNG image.

## Key Components

- **`Stillcolor`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Stillcolor from './Stillcolor';

// Basic usage
<Stillcolor />

// With custom dimensions or className
<Stillcolor width={64} height={64} className="my-icon" />

// With accessibility attributes
<Stillcolor aria-label="Stillcolor icon" role="img" />
```

## Notes

- All standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external asset dependencies at runtime.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
