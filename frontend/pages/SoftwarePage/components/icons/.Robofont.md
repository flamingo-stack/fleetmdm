A React SVG component that renders the Robofont icon as an inline PNG image embedded via a base64 data URI within an SVG wrapper.

## Key Components

- **`Robofont`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing a base64-encoded PNG image of the Robofont logo.

## Usage Example

```typescript
import Robofont from "./Robofont";

// Basic usage
<Robofont />

// With custom dimensions and className
<Robofont width={64} height={64} className="icon" />

// With accessible title via aria attributes
<Robofont aria-label="Robofont" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The image is fully self-contained — no external asset requests at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
