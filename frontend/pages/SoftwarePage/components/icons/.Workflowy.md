React SVG component that renders the Workflowy logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Workflowy`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the wrapping `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Workflowy from "./Workflowy";

// Basic usage
<Workflowy />

// With custom size and class
<Workflowy width={64} height={64} className="icon" />

// With click handler
<Workflowy onClick={() => console.log("clicked")} />
```

## Notes

- The icon image is embedded as a **base64 PNG** via an `<image>` element inside the SVG, so no external asset files or network requests are required.
- Default dimensions are **32×32 pixels** but can be overridden via props.
- Part of the icon set in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository.
