SVG icon component that renders the Apparency application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Apparency`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import Apparency from "./Apparency";

// Basic usage
<Apparency />

// With custom dimensions or className
<Apparency width={64} height={64} className="icon" />

// With accessibility attributes
<Apparency aria-label="Apparency" role="img" />
```

## Notes

- The component spreads all `SVGProps` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `className`, `style`, `onClick`).
- The icon image is statically embedded as a base64 PNG data URI, meaning no external network request is required at runtime.
- Default rendered size is **32×32 pixels**.
