A React SVG component that renders the Elgato Camera Hub device icon as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`ElgatoCameraHub`** — Default-exported functional React component that accepts standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG icon for the Elgato Camera Hub device.

## Usage Example

```typescript
import ElgatoCameraHub from './ElgatoCameraHub';

// Basic usage
<ElgatoCameraHub />

// With custom size and styling
<ElgatoCameraHub
  width={64}
  height={64}
  className="device-icon"
  style={{ opacity: 0.8 }}
/>

// With ARIA attributes for accessibility
<ElgatoCameraHub
  aria-label="Elgato Camera Hub"
  role="img"
/>
```

## Notes

- The icon is rendered at **32×32 pixels** by default (overridable via props).
- The PNG image data is inlined as a **base64-encoded `data:` URI**, so no external image asset is required at runtime.
- The component forwards all `SVGProps<SVGSVGElement>` to the root `<svg>` element, making it fully composable with standard SVG attributes.
