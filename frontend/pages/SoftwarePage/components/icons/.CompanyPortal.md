SVG icon component that renders a Company Portal logo as an inline PNG image embedded via base64 data URI.

## Key Components

- **`CompanyPortal`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a 32×32 SVG containing an embedded PNG image via base64 `href`.

## Usage Example

```typescript
import CompanyPortal from "./CompanyPortal";

// Basic usage
<CompanyPortal />

// With custom dimensions or className
<CompanyPortal width={64} height={64} className="icon" />

// With aria label for accessibility
<CompanyPortal aria-label="Company Portal" role="img" />
```

## Notes

- The icon is **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The PNG image is fully self-contained — no external assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
