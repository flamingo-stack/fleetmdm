React SVG icon component that renders the Telegram logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Telegram`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) that renders a 32×32 Telegram brand icon using an inline base64 PNG image.

## Usage Example

```typescript
import Telegram from './Telegram';

// Basic usage
<Telegram />

// With custom dimensions and className
<Telegram width={64} height={64} className="icon" />

// With click handler
<Telegram onClick={() => window.open('https://t.me/yourchannel')} style={{ cursor: 'pointer' }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is embedded as a base64-encoded PNG inside an `<image>` element — no external asset fetch required.
- All standard `SVGSVGElement` props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded via spread.
