A React SVG component that renders a "Boop" icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Boop`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering an SVG wrapper around an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Boop from "./Boop";

// Basic usage
<Boop />

// With custom dimensions or class
<Boop width={64} height={64} className="icon" />

// With onClick handler
<Boop onClick={() => console.log("booped!")} />
```

## Notes

- The image is hardcoded at `width={32}` and `height={32}` internally, but the outer `<svg>` accepts any `SVGProps` overrides.
- The embedded base64 PNG avoids external image dependencies, making the component fully self-contained.
- The source file is located at [`Boop.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Boop.tsx).
