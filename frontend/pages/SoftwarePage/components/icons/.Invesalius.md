A React SVG component that renders the InVesalius application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Invesalius`** — Default-exported functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG wrapper around an embedded PNG logo via a `<image>` element with a `data:image/png;base64` href.

## Usage Example

```typescript
import Invesalius from "./Invesalius";

// Basic usage
<Invesalius />

// With custom className or style overrides
<Invesalius className="app-icon" style={{ opacity: 0.8 }} />

// With explicit size override
<Invesalius width={64} height={64} />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full prop passthrough (e.g., `onClick`, `aria-label`, `className`).
- The icon is self-contained — no external image assets or network requests are required.
- Default render size is **32×32 px**; the embedded PNG was originally encoded at **256×256 px**, so scaling up via props will not degrade visual quality.
