A React SVG component that renders the Adlock application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Adlock`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon.

## Usage Example

```typescript
import Adlock from './Adlock';

// Basic usage
<Adlock />

// With custom dimensions or className
<Adlock width={64} height={64} className="app-icon" />

// With accessibility attributes
<Adlock aria-label="Adlock" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via prop spreading.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
