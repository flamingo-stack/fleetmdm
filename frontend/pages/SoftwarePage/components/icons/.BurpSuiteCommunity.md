A React SVG icon component that renders the Burp Suite Community Edition logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`BurpSuiteCommunity`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Burp Suite Community logo as an inline base64 PNG image.

## Usage Example

```typescript
import BurpSuiteCommunity from "./BurpSuiteCommunity";

// Basic usage
<BurpSuiteCommunity />

// With custom dimensions and className
<BurpSuiteCommunity width={64} height={64} className="icon" />

// With inline styles
<BurpSuiteCommunity style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- Accepts all standard SVG props (e.g., `className`, `style`, `aria-label`) via prop spreading.
- The logo is self-contained — no external image dependencies.
