A React SVG icon component that renders the Runjs application logo as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`Runjs`** — Default export. A functional React component that renders a 32×32 SVG containing the Runjs logo as an inline base64-encoded PNG image.

## Usage Example

```typescript
import Runjs from "./Runjs";

// Basic usage
<Runjs />

// With custom dimensions or className
<Runjs width={64} height={64} className="app-icon" />

// With accessibility attributes
<Runjs aria-label="Runjs" role="img" />
```

Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `width`, `height`), which are spread onto the root `<svg>` element. Default size is 32×32px.
