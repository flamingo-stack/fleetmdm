A React SVG icon component that renders the Logseq logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Logseq`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Logseq brand icon.

## Usage Example

```typescript
import Logseq from "./Logseq";

// Basic usage
<Logseq />

// With custom size and class
<Logseq width={64} height={64} className="icon" />

// With inline styles
<Logseq style={{ opacity: 0.8 }} />
```

## Notes

- Dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The icon image is self-contained as a base64 PNG — no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element.
