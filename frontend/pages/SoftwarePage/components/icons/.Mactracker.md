A React SVG component that renders the Mactracker application icon as an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Mactracker`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG image via a `data:image/png;base64` `href` attribute.

## Usage Example

```typescript
import Mactracker from "./Mactracker";

// Basic usage
<Mactracker />

// With custom dimensions or className
<Mactracker width={64} height={64} className="app-icon" />

// With accessibility attributes
<Mactracker aria-label="Mactracker" role="img" />
```

## Notes

- The icon image is fully self-contained — no external image file is required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via prop spreading.
- Default render size is **32×32px**; override via `width`/`height` props.
