A React SVG component that renders the Ultimaker Cura 3D printing software logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`UltimakerCura`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image data URI.

## Usage Example

```typescript
import UltimakerCura from './UltimakerCura';

// Basic usage
<UltimakerCura />

// With custom dimensions or className
<UltimakerCura width={64} height={64} className="app-icon" />

// With accessibility attributes
<UltimakerCura aria-label="Ultimaker Cura" role="img" />
```

## Notes

- The icon image is inlined as a base64 PNG, so no external image file is required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
