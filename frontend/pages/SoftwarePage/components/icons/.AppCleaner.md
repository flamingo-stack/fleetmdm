React SVG icon component that renders the AppCleaner application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`AppCleaner`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon via a base64 data URI.

## Usage Example

```typescript
import AppCleaner from "./AppCleaner";

// Basic usage
<AppCleaner />

// With custom dimensions and className
<AppCleaner width={64} height={64} className="app-icon" />

// With style overrides
<AppCleaner style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The PNG image data is embedded as a base64 data URI, making this component self-contained with no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
