A React SVG component that renders the Gpodder podcast manager application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Gpodder`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the Gpodder logo via an `<image>` element with an inline base64 PNG data URI.

## Usage Example

```typescript
import Gpodder from "./Gpodder";

// Basic usage
<Gpodder />

// With custom dimensions or className
<Gpodder width={64} height={64} className="app-icon" />

// With accessibility attributes
<Gpodder aria-label="Gpodder" role="img" />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG is fully self-contained as a base64 data URI — no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
