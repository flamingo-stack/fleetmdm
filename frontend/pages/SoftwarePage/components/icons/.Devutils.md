React SVG icon component that renders the Devutils application logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Devutils`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Devutils app icon as an inline base64 PNG.

## Usage Example

```typescript
import { Devutils } from "./Devutils";

// Basic usage
<Devutils />

// With custom dimensions and styling
<Devutils width={64} height={64} className="app-icon" />

// With aria attributes for accessibility
<Devutils aria-label="Devutils" role="img" />
```

## Notes

- The icon is a **32×32px** SVG by default but can be resized via `width`/`height` props.
- The image data is embedded as a base64 PNG (originally 512×512px per EXIF metadata), making this component self-contained with no external image dependencies.
- All standard `SVGProps` are forwarded to the root `<svg>` element, enabling full customization of attributes such as `className`, `style`, `onClick`, etc.
