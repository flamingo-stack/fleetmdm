React SVG icon component that renders the NoSQL Workbench application logo as a 32×32 PNG embedded within an SVG element.

## Key Components

- **`NosqlWorkbench`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the NoSQL Workbench logo as a base64-encoded PNG `<image>`.

## Usage Example

```typescript
import NosqlWorkbench from "./NosqlWorkbench";

// Basic usage
<NosqlWorkbench />

// With custom size and className
<NosqlWorkbench width={64} height={64} className="icon" />

// With aria label for accessibility
<NosqlWorkbench aria-label="NoSQL Workbench" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the root `<svg>` element via spread.
- The image data is a self-contained base64 PNG — no external network requests are made at render time.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
