React SVG icon component that renders the XCreds application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`XCreds`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the XCreds logo as an embedded PNG image.

## Usage Example

```typescript
import XCreds from "./XCreds";

// Basic usage
<XCreds />

// With custom dimensions and className
<XCreds width={64} height={64} className="icon" />

// With accessibility attributes
<XCreds aria-label="XCreds" role="img" />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo is self-contained — no external image dependencies.
- Supports all standard SVG props (e.g., `className`, `style`, `onClick`) via prop spreading.
