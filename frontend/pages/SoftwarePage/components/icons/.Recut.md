A React SVG component that renders the Recut logo/icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Recut`** — Default export; a functional React component that wraps a base64-encoded PNG within an `<svg>` element. Accepts all standard `SVGProps<SVGSVGElement>` props for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Recut from "./Recut";

// Basic usage
<Recut />

// With custom size and class
<Recut width={64} height={64} className="icon" />

// With click handler
<Recut onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The component renders a fixed 32×32 SVG by default; dimensions can be overridden via props.
- The icon image is embedded as a base64 PNG (512×512 source resolution), making this component self-contained with no external asset dependencies.
