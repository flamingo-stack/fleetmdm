A React SVG component that renders the pgAdmin 4 logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `PgAdmin4` | `React.FC<SVGProps<SVGSVGElement>>` | SVG wrapper component rendering the pgAdmin 4 logo at 32×32px |

## Usage Example

```typescript
import { PgAdmin4 } from './PgAdmin4';

// Basic usage
<PgAdmin4 />

// With custom dimensions and class
<PgAdmin4 width={64} height={64} className="tool-icon" />

// With accessibility attributes
<PgAdmin4 aria-label="pgAdmin 4" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`)
- Default dimensions: `32×32`
- The icon image is embedded as a base64 PNG — no external asset dependency
- Commonly used as a service/tool icon within the [Flamingo OpenFrame](https://www.flamingo.run/openframe) integration UI
