A React SVG icon component that renders the RustDesk logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`RustDesk`** — Default export. A functional React component that accepts standard SVG props and renders a 32×32 RustDesk logo icon.

## Usage Example

```typescript
import RustDesk from "./RustDesk";

// Basic usage
<RustDesk />

// With custom dimensions or className
<RustDesk width={64} height={64} className="icon" />

// With style overrides
<RustDesk style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/RustDesk.tsx) via prop spreading, enabling full customization of the outer `<svg>` element.
- The icon image is embedded as a base64 PNG, so no external asset files are required.
- Default rendered size is **32×32 pixels**.
