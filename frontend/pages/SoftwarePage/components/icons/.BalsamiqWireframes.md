SVG icon component that renders the Balsamiq Wireframes logo as a 32×32 PNG embedded within an SVG element.

## Key Components

- **`BalsamiqWireframes`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering the Balsamiq Wireframes brand icon via a base64-encoded PNG embedded in an `<image>` element.

## Usage Example

```typescript
import BalsamiqWireframes from './BalsamiqWireframes';

// Basic usage
<BalsamiqWireframes />

// With custom dimensions and className
<BalsamiqWireframes width={64} height={64} className="tool-icon" />

// With accessibility attributes
<BalsamiqWireframes aria-label="Balsamiq Wireframes" role="img" />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The PNG image data is fully inlined as a base64 string — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
