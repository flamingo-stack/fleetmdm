A React SVG component that renders the Vimcal brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Vimcal`** — Default exported functional component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing an embedded base64 PNG image of the Vimcal logo.

## Usage Example

```typescript
import Vimcal from "./Vimcal";

// Basic usage
<Vimcal />

// With custom className or style
<Vimcal className="app-icon" style={{ opacity: 0.8 }} />

// With custom dimensions via SVG props
<Vimcal width={64} height={64} />
```

## Notes

- The icon is self-contained — no external image assets or network requests are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via prop spreading.
- The embedded PNG was originally a 512×512 image, downscaled to 32×32 for display.
