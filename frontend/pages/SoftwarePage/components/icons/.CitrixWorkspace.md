A React SVG component that renders the Citrix Workspace application icon as an inline PNG image encoded in base64, embedded within an SVG wrapper.

## Key Components

- **`CitrixWorkspace`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Citrix Workspace logo.

## Usage Example

```typescript
import CitrixWorkspace from "./CitrixWorkspace";

// Basic usage
<CitrixWorkspace />

// With custom dimensions or className
<CitrixWorkspace width={64} height={64} className="app-icon" />

// With inline style
<CitrixWorkspace style={{ opacity: 0.8 }} />
```

## Notes

- The icon is **32×32 pixels** by default but can be overridden via `width`/`height` props.
- All standard SVG props (`className`, `style`, `aria-label`, `onClick`, etc.) are forwarded to the root `<svg>` element.
- The image data is self-contained (base64-encoded PNG) — no external network requests are made at render time.
- Intended for use in application/software icon lists, device management UIs, or integration catalogs within the [Flamingo/FleetMDM platform](https://github.com/flamingo-stack/fleetmdm).
