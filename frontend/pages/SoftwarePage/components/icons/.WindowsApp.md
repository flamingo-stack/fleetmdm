A React SVG component that renders a Windows application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`WindowsApp`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import WindowsApp from "./WindowsApp";

// Basic usage
<WindowsApp />

// With custom dimensions or styling
<WindowsApp width={64} height={64} className="app-icon" />

// With click handler
<WindowsApp onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon graphic is a base64-encoded PNG embedded directly in the component — no external asset file or network request required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- Fully compatible with standard SVG prop patterns (e.g., `aria-label`, `role`, `style`, `className`).
