React SVG wrapper component that renders the ProtonMail Bridge application icon as an inline PNG image (32×32) embedded via base64 data URI within an SVG element.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ProtonMailBridge` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component for ProtonMail Bridge |

## Usage Example

```typescript
import ProtonMailBridge from './ProtonMailBridge';

// Basic usage
<ProtonMailBridge />

// With custom dimensions or className
<ProtonMailBridge width={64} height={64} className="app-icon" />

// With accessibility attributes
<ProtonMailBridge aria-label="ProtonMail Bridge" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/common) props for full customization
- Default render size is **32×32 pixels**
- The icon is self-contained — no external image requests at runtime
- Part of the Fleet MDM application icon library at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
