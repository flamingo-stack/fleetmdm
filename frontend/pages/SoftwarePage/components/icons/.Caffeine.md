React SVG icon component that renders the Caffeine icon as a 32×32 PNG embedded inline via a base64-encoded data URI.

## Key Components

- **`Caffeine`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Caffeine from "./Caffeine";

// Basic usage
<Caffeine />

// With custom size and className
<Caffeine width={64} height={64} className="icon" />

// With onClick handler
<Caffeine onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is rendered at **32×32** by default but can be overridden via `width`/`height` props.
- The image content is a **base64-encoded PNG** embedded directly in the SVG via an `<image>` element — no external asset fetch required.
- All standard SVG attributes (`className`, `style`, `aria-*`, event handlers, etc.) are supported via prop spreading.
