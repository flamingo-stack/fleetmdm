React SVG icon component that renders the AWS CLI logo as an inline PNG image encoded in base64 format.

## Key Components

- **`AwsCli`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the AWS CLI logo as a base64-encoded PNG via an `<image>` element.

## Usage Example

```typescript
import AwsCli from "./AwsCli";

// Basic usage
<AwsCli />

// With custom dimensions or className
<AwsCli width={64} height={64} className="icon" />

// With accessibility attributes
<AwsCli aria-label="AWS CLI" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The icon graphic is self-contained — no external network requests are made.
