A React SVG component that renders the Spitfire Audio brand logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SpitfireAudio`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image via a base64 `href` data URI.

## Usage Example

```typescript
import SpitfireAudio from "./SpitfireAudio";

// Basic usage
<SpitfireAudio />

// With custom dimensions or className
<SpitfireAudio width={64} height={64} className="brand-logo" />

// With accessibility attributes
<SpitfireAudio aria-label="Spitfire Audio" role="img" />
```

## Notes

- The component is fully self-contained — no external image assets or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32px**; override via `width`/`height` props.
