React SVG component that renders the Sqlectron database client logo as an inline PNG image embedded via base64 within an SVG wrapper.

## Key Components

- **`Sqlectron`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that contains the Sqlectron logo as an embedded base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Sqlectron from "./Sqlectron";

// Basic usage
<Sqlectron />

// With custom sizing and className
<Sqlectron width={48} height={48} className="app-icon" />

// With inline styles
<Sqlectron style={{ opacity: 0.8 }} />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, making it fully customizable via standard SVG attributes (e.g., `width`, `height`, `className`, `style`).
- The logo image is embedded as a base64 PNG, so no external asset fetching is required.
- Default dimensions are `32×32` pixels.
