React SVG icon component that renders the Photostickies macOS application icon as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`Photostickies`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing an embedded base64 PNG icon.

## Usage Example

```typescript
import Photostickies from "./Photostickies";

// Basic usage
<Photostickies />

// With custom dimensions or className
<Photostickies width={64} height={64} className="app-icon" />

// With click handler
<Photostickies onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via prop spreading.
- The icon is embedded as a base64-encoded PNG (`data:image/png;base64,...`), so no external asset files are required.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
