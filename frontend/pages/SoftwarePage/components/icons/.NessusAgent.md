React SVG icon component that renders the Nessus Agent logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`NessusAgent`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Nessus Agent brand icon as an embedded base64 PNG.

## Usage Example

```typescript
import NessusAgent from "./NessusAgent";

// Basic usage
<NessusAgent />

// With custom size and className
<NessusAgent width={64} height={64} className="icon" />

// With accessibility attributes
<NessusAgent aria-label="Nessus Agent" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels** but can be overridden via `width`/`height` props.
- The icon is self-contained — no external image assets or network requests required.
- Fully compatible with standard SVG styling (e.g., `style`, `className`, `fill`).
