React SVG component that renders the Bitwig Studio application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`BitwigStudio`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Bitwig Studio logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import BitwigStudio from "./BitwigStudio";

// Basic usage
<BitwigStudio />

// With custom dimensions or className
<BitwigStudio width={64} height={64} className="app-icon" />

// With accessibility attributes
<BitwigStudio aria-label="Bitwig Studio" role="img" />
```

## Notes

- The icon image is fully self-contained — no external assets or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32 pixels**; this can be overridden via `width`/`height` props.
