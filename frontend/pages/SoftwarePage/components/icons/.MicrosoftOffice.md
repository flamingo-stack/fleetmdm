SVG icon component that renders the Microsoft Office logo as a base64-encoded PNG image embedded within an SVG element.

## Key Components

- **`MicrosoftOffice`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import MicrosoftOffice from "./MicrosoftOffice";

// Basic usage
<MicrosoftOffice />

// With custom dimensions or className
<MicrosoftOffice width={64} height={64} className="icon" />

// With accessibility attributes
<MicrosoftOffice aria-label="Microsoft Office" role="img" />
```

## Notes

- The component is a **32×32 px** icon by default; dimensions can be overridden via props.
- The PNG data is fully self-contained (no external network requests at render time).
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded directly to the `<svg>` element.
