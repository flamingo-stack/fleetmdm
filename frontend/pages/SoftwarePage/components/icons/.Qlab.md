React SVG component that renders the QLab application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Qlab`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG image of the QLab logo.

## Usage Example

```typescript
import Qlab from "./Qlab";

// Basic usage
<Qlab />

// With custom dimensions or className
<Qlab width={64} height={64} className="app-icon" />

// With accessibility attributes
<Qlab aria-label="QLab" role="img" />
```

## Notes

- The component spreads all passed `SVGProps` onto the root `<svg>` element, making it fully customizable (size, class, style, event handlers, etc.).
- The icon image is a 32×32 PNG embedded as a base64 data URI — no external image fetch required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
