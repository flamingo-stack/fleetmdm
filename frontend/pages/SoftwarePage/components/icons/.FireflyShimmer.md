A React SVG component that renders the Firefly Shimmer logo/icon as an inline base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`FireflyShimmer`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import FireflyShimmer from "./FireflyShimmer";

// Basic usage
<FireflyShimmer />

// With custom dimensions and className
<FireflyShimmer width={64} height={64} className="logo-icon" />

// With style overrides
<FireflyShimmer style={{ opacity: 0.8 }} aria-label="Firefly Shimmer" />
```

> **Note:** The component accepts all standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-label`) which are spread onto the root `<svg>` element. The internal image dimensions are fixed at 32×32 — to scale the icon, override `width` and `height` via props.
