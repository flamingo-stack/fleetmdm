A React SVG icon component that renders the Openboard logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Openboard`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Openboard logo as an embedded PNG via a `data:image/png;base64` `href`.

## Usage Example

```typescript
import Openboard from "./Openboard";

// Basic usage
<Openboard />

// With custom dimensions or class
<Openboard width={64} height={64} className="icon" />

// With accessibility attributes
<Openboard aria-label="Openboard" role="img" />
```

## Notes

- The component spreads `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable via standard SVG attributes (`className`, `style`, `onClick`, etc.).
- Default size is **32×32px**; the embedded PNG is 512×512px and scales down via the SVG `width`/`height` attributes.
- No external asset dependencies — the image is fully self-contained as a base64 data URI.
