A React SVG component that renders the Front.fm logo as an inline Base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Front`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded Base64 PNG image.

## Usage Example

```typescript
import Front from "./Front";

// Basic usage
<Front />

// With custom dimensions or className
<Front width={64} height={64} className="icon" />

// With accessibility attributes
<Front aria-label="Front logo" role="img" />
```

## Notes

- The image data is embedded as a Base64 PNG, so no external asset requests are made.
- Default dimensions are `32×32` pixels but can be overridden via props.
- All standard SVG props (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element.
