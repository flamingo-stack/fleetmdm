A React SVG component that renders the Fantastical app icon as an inline base64-encoded PNG image (32×32px).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Fantastical` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapping a base64 PNG of the Fantastical calendar app icon |

## Usage Example

```typescript
import Fantastical from "./Fantastical";

// Basic usage
<Fantastical />

// With custom dimensions or className
<Fantastical width={64} height={64} className="app-icon" />

// With style overrides
<Fantastical style={{ borderRadius: 8 }} aria-label="Fantastical" />
```

## Notes

- All standard [`SVGProps`](https://react.dev/reference/react-dom/components/common) are forwarded to the root `<svg>` element, allowing full customization of size, accessibility attributes, and styles.
- The icon image is embedded as a base64 PNG — no external asset fetch is required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
