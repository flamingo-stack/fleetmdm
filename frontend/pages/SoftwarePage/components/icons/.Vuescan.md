React SVG component that renders the Vuescan application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Vuescan`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded PNG icon for the [Vuescan](https://www.hamrick.com/) scanning application.

## Usage Example

```typescript
import Vuescan from "./Vuescan";

// Basic usage
<Vuescan />

// With custom dimensions or className
<Vuescan width={64} height={64} className="app-icon" />

// With accessibility attributes
<Vuescan aria-label="Vuescan" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via `width`/`height` props.
- The PNG image data is fully inlined as a base64 `data:image/png` URI — no external asset requests are made.
- All standard `SVGProps` (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
