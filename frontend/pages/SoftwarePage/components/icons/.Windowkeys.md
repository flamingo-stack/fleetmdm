A React SVG component that renders a Windows keyboard keys icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Windowkeys`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG image via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Windowkeys from './Windowkeys';

// Basic usage
<Windowkeys />

// With custom dimensions or className
<Windowkeys width={64} height={64} className="icon" />

// With accessibility attributes
<Windowkeys aria-label="Windows keys" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon is self-contained — no external assets or stylesheets required.
- The embedded PNG is 512×512px (per EXIF metadata in the base64 payload) but rendered at 32×32 by default via SVG `width`/`height`.
- Resizing via `width`/`height` props scales the SVG container; the inner `<image>` is hardcoded to 32×32 and does not auto-scale with the container.
