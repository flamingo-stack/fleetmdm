React SVG component that renders the Linearmouse application icon as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Linearmouse`** — Default export. A functional React component that wraps a 32×32 SVG element containing a base64-encoded PNG `<image>` of the Linearmouse app icon.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Linearmouse from "./Linearmouse";

// Basic usage
export default function App() {
  return <Linearmouse />;
}

// With custom props
export default function App() {
  return (
    <Linearmouse
      className="app-icon"
      style={{ borderRadius: 6 }}
      aria-label="Linearmouse"
    />
  );
}
```

## Notes

- The icon is rendered at a fixed internal size of **32×32 pixels** but can be scaled via CSS `width`/`height` props.
- The PNG data is embedded inline — no external image request is made.
- Intended for use as a software icon in device management or application inventory UIs within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) project.
