A React SVG icon component that renders the Epic Games logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`EpicGames`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import EpicGames from './EpicGames';

// Basic usage
<EpicGames />

// With custom dimensions or className
<EpicGames width={64} height={64} className="icon" />

// With accessibility attributes
<EpicGames aria-label="Epic Games" role="img" />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The logo is embedded as a base64 PNG — no external image assets required.
- Accepts all standard SVG props (`className`, `style`, `onClick`, etc.) via `SVGProps<SVGSVGElement>`.
