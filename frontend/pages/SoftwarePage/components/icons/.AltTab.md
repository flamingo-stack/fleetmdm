A React SVG component that renders the AltTab keyboard shortcut icon (Alt+Tab) as an embedded PNG image within an SVG wrapper.

## Key Components

- **`AltTab`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element containing a base64-encoded PNG image of the AltTab icon.

## Usage Example

```typescript
import AltTab from "./AltTab";

// Basic usage
<AltTab />

// With custom dimensions and styling
<AltTab width={64} height={64} className="icon" />

// With event handlers
<AltTab onClick={() => console.log("AltTab clicked")} />
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread props.
- The icon image is embedded as a base64 PNG `<image>` element, so no external asset file is required.
- Default render size is **32×32 pixels**.
