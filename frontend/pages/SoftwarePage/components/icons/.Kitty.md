A React SVG component that renders an inline base64-encoded PNG image of a cat ("Kitty") within a 32×32 SVG container.

## Key Components

- **`Kitty`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Kitty from "./Kitty";

// Basic usage
<Kitty />

// With custom dimensions or className
<Kitty width={64} height={64} className="kitty-icon" />

// With accessibility attributes
<Kitty aria-label="Kitty icon" role="img" />
```

## Notes

- The image data is embedded as a base64-encoded PNG, so no external asset file is required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Kitty.tsx).
