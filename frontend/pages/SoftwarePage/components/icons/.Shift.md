A React SVG component that renders a 32×32 "Shift" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Shift`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering an `<svg>` element with an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Shift from './Shift';

// Basic usage
<Shift />

// With custom dimensions and className
<Shift width={64} height={64} className="icon" />

// With accessibility attributes
<Shift aria-label="Shift key" role="img" />
```

## Notes

- The component accepts all standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) via spread, but the internal `<image>` element is hardcoded to `32×32`. Override the outer `<svg>` dimensions for scaling.
- The icon is self-contained — no external image assets or icon libraries are required.
