A React SVG icon component that renders the LocalSend application logo as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`Localsend`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the LocalSend logo as a base64-encoded PNG image inside an SVG element.

## Usage Example

```typescript
import Localsend from "./Localsend";

// Basic usage
<Localsend />

// With custom sizing or className
<Localsend width={64} height={64} className="icon" />

// With style overrides
<Localsend style={{ opacity: 0.8 }} />
```

## Notes

- The icon renders at **32×32px** by default but accepts any `SVGProps` override (e.g., `width`, `height`, `className`, `style`).
- The logo image is a **base64-encoded PNG** embedded directly into the SVG, meaning no external asset requests are made.
