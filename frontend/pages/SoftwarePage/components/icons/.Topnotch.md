A React SVG component that renders the Topnotch brand logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`Topnotch`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image.

## Usage Example

```typescript
import Topnotch from "./Topnotch";

// Basic usage
<Topnotch />

// With custom dimensions or className
<Topnotch width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Topnotch aria-label="Topnotch logo" role="img" />
```

## Notes

- The PNG image data is inlined as a base64 string, so no external image file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override by passing `width` and `height` props.
