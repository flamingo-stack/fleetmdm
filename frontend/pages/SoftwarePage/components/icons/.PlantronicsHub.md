React SVG icon component that renders the Plantronics Hub application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`PlantronicsHub`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Plantronics Hub logo as an inline base64 PNG image.

## Usage Example

```typescript
import PlantronicsHub from "./PlantronicsHub";

// Basic usage
<PlantronicsHub />

// With custom dimensions and className
<PlantronicsHub width={64} height={64} className="app-icon" />

// With inline styles
<PlantronicsHub style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; overridable via `width`/`height` props.
- The logo is embedded as a base64 PNG, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
