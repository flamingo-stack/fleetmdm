React SVG icon component that renders the Squash application icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Squash`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element containing a base64-encoded PNG image of the Squash icon.

## Usage Example

```typescript
import Squash from './Squash';

// Basic usage
<Squash />

// With custom dimensions and className
<Squash width={64} height={64} className="icon" />

// With accessibility attributes
<Squash aria-label="Squash" role="img" />
```

## Notes

- The icon image is embedded directly as a base64-encoded PNG, making it self-contained with no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
