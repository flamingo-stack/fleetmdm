React SVG icon component that renders the BlueJ logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Bluej`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the BlueJ logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Bluej from "./Bluej";

// Basic usage
<Bluej />

// With custom dimensions or className
<Bluej width={64} height={64} className="icon" />

// With aria label for accessibility
<Bluej aria-label="BlueJ" role="img" />
```

## Notes

- The image data is fully self-contained — no external image files or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
