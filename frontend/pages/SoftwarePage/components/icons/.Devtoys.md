A React component that renders the DevToys application icon as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`Devtoys`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG element embedding the DevToys icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Devtoys from "./Devtoys";

// Basic usage
<Devtoys />

// With custom dimensions via SVG props
<Devtoys width={64} height={64} className="app-icon" />

// With accessibility attributes
<Devtoys aria-label="DevToys" role="img" />
```

## Notes

- The icon is embedded as a base64-encoded PNG (512×512 source image downscaled to 32×32 via SVG), making it fully self-contained with no external image dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- Intended for use as an app/tool icon in navigation menus, toolbars, or integration listings within the [Flamingo/OpenFrame](https://www.flamingo.run/openframe) platform UI.
