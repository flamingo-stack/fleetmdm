React SVG component that renders the ClickUp logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`ClickUp`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the ClickUp brand logo as an embedded base64 PNG.

## Usage Example

```typescript
import ClickUp from './ClickUp';

// Basic usage
<ClickUp />

// With custom dimensions and className
<ClickUp width={64} height={64} className="brand-logo" />

// With style overrides
<ClickUp style={{ opacity: 0.8 }} aria-label="ClickUp" />
```

## Notes

- The logo is embedded as a base64-encoded PNG inside an `<image>` element, so no external image assets are required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` attributes (`className`, `style`, `aria-*`, etc.) are forwarded to the root `<svg>` element via spread.
