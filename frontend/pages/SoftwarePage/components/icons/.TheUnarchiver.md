A React SVG component that renders The Unarchiver application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`TheUnarchiver`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a `<image>` element with a `data:image/png;base64` href.

## Usage Example

```typescript
import TheUnarchiver from "./TheUnarchiver";

// Basic usage
<TheUnarchiver />

// With custom dimensions and className
<TheUnarchiver width={64} height={64} className="app-icon" />

// With accessibility attributes
<TheUnarchiver
  role="img"
  aria-label="The Unarchiver"
  style={{ borderRadius: 8 }}
/>
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are spread onto the root `<svg>` element, making it fully customizable.
- The icon image is self-contained — no external assets required.
- Default rendered size is **32×32px**.
