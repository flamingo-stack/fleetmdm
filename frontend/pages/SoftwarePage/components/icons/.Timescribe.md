A React SVG component that renders the Timescribe brand logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Timescribe`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG logo via a `data:image/png;base64` href.

## Usage Example

```typescript
import Timescribe from "./Timescribe";

// Basic usage
<Timescribe />

// With custom size override
<Timescribe width={64} height={64} />

// With className for styling
<Timescribe className="logo-icon" aria-label="Timescribe" />

// With inline style
<Timescribe style={{ opacity: 0.8 }} />
```

## Notes

- All props are spread onto the root `<svg>` element, so standard SVG/HTML attributes (`className`, `style`, `onClick`, `aria-*`, etc.) work as expected.
- The image is self-contained — no external asset fetch is required at runtime.
- Default dimensions are `32×32`; override via `width`/`height` props.
- The embedded PNG is a 512×512 source image scaled down to 32×32 display size.
