A React SVG component that renders a 32×32 FileJuicer application icon using an embedded base64-encoded PNG image.

## Key Components

- **`FileJuicer`** — Default export. A functional React component that wraps a base64-encoded PNG icon inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import FileJuicer from "./FileJuicer";

// Basic usage
<FileJuicer />

// With custom size and className
<FileJuicer width={64} height={64} className="my-icon" />

// With click handler
<FileJuicer onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is a **32×32 SVG** wrapping a **512×512 PNG** (downscaled via the `<image>` element) — the base64 payload embeds full-resolution artwork.
- All [`SVGProps`](https://github.com/flamingo-stack/fleetmdm/blob/main/node_modules/@types/react/index.d.ts) are spread onto the root `<svg>`, allowing `width`, `height`, `className`, `style`, `onClick`, and other SVG attributes to be overridden at the call site.
- No external image dependencies — the icon is fully self-contained and safe to use in offline or restricted environments.
