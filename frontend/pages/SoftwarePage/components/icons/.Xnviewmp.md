React SVG component that renders the XnViewMP application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Xnviewmp`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64 PNG of the XnViewMP logo.

## Usage Example

```typescript
import Xnviewmp from "./Xnviewmp";

// Basic usage
<Xnviewmp />

// With custom dimensions or className
<Xnviewmp width={64} height={64} className="app-icon" />

// With accessibility attributes
<Xnviewmp aria-label="XnViewMP" role="img" />
```

## Notes

- The icon is self-contained — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread.
- The embedded PNG was originally 512×512 and is scaled down to 32×32 at render time.
