A React SVG component that renders the Axure RP logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`AxureRp`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering an `<svg>` wrapper with an embedded `<image>` containing the Axure RP logo as a base64 PNG.

## Usage Example

```typescript
import AxureRp from "./AxureRp";

// Basic usage
<AxureRp />

// With custom dimensions and className
<AxureRp width={64} height={64} className="tool-icon" />

// With aria label for accessibility
<AxureRp aria-label="Axure RP" role="img" />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The icon image is self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
