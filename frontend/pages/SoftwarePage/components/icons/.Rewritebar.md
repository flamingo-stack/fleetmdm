A React SVG component that renders a "Rewritebar" icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Rewritebar`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering an SVG wrapper with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Rewritebar from "./Rewritebar";

// Basic usage
<Rewritebar />

// With custom className or style
<Rewritebar className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32×32)
<Rewritebar width={64} height={64} />
```

## Notes

- The icon is always rendered at 32×32px by default but accepts any `SVGProps` override.
- The image content is a self-contained base64 PNG — no external assets or network requests required.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — search for `Rewritebar.tsx` in the icons or assets directory.
