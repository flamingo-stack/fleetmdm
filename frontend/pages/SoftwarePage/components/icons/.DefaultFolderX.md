A React SVG component that renders a 32×32 "DefaultFolderX" icon using an embedded Base64-encoded PNG image.

## Key Components

- **`DefaultFolderX`** — A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a Base64-encoded PNG of a folder-with-X icon.

## Usage Example

```typescript
import DefaultFolderX from './DefaultFolderX';

// Basic usage
<DefaultFolderX />

// With custom dimensions or className
<DefaultFolderX width={64} height={64} className="icon" />

// With an onClick handler
<DefaultFolderX onClick={() => handleFolderRemove()} style={{ cursor: 'pointer' }} />
```

## Notes

- The icon image is fully self-contained — no external asset dependencies.
- All `SVGProps<SVGSVGElement>` are forwarded via spread (`{...props}`), allowing consumers to override `width`, `height`, `className`, `style`, `aria-*`, and other SVG attributes.
- Default rendered size is **32×32 pixels**; the embedded PNG source is **512×512** (sRGB color space per EXIF metadata).
