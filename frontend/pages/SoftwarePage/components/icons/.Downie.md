React SVG component that renders the Downie application icon as an inline PNG image (32×32) embedded via a base64-encoded data URI.

## Key Components

- **`Downie`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full prop passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Downie from "./Downie";

// Basic usage
<Downie />

// With custom dimensions and className
<Downie width={64} height={64} className="app-icon" />

// With event handler
<Downie onClick={() => console.log("Downie clicked")} />
```

## Notes

- The icon is rendered as a 32×32 SVG containing an `<image>` element with the PNG data embedded as a base64 string, ensuring no external asset requests.
- All SVG props are forwarded via `{...props}`, making the component fully customizable without modifying the source.
