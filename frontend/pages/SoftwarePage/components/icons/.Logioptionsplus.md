A React SVG component that renders the Logi Options+ application icon as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`Logioptionsplus`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Logi Options+ icon via a base64-encoded PNG embedded in an SVG `<image>` element.

## Usage Example

```typescript
import Logioptionsplus from "./Logioptionsplus";

// Basic usage
<Logioptionsplus />

// With custom dimensions or className
<Logioptionsplus width={64} height={64} className="app-icon" />

// With accessibility attributes
<Logioptionsplus aria-label="Logi Options+" role="img" />
```

## Notes

- Renders at 32×32 pixels by default; override via `width`/`height` props.
- The icon is self-contained — no external image requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
