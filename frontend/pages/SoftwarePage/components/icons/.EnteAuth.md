A React SVG component that renders the EnteAuth application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`EnteAuth`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the EnteAuth logo as an embedded PNG.

## Usage Example

```typescript
import EnteAuth from "./EnteAuth";

// Basic usage
<EnteAuth />

// With custom dimensions or className
<EnteAuth width={64} height={64} className="app-icon" />

// With accessibility attributes
<EnteAuth aria-label="EnteAuth" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG image data is embedded as a **base64 data URI**, so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
