React SVG icon component that renders the Filebeat logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`Filebeat`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Filebeat icon using a base64-encoded PNG image element.

## Usage Example

```typescript
import Filebeat from './Filebeat';

// Basic usage
<Filebeat />

// With custom dimensions or className
<Filebeat width={48} height={48} className="icon" />

// With accessibility attributes
<Filebeat aria-label="Filebeat" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The image data is fully self-contained as a base64-encoded PNG — no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
