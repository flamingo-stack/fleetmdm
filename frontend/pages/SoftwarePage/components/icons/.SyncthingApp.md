A React SVG component that renders the Syncthing application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`SyncthingApp`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders an SVG wrapper containing the Syncthing app icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import SyncthingApp from "./SyncthingApp";

// Basic usage
<SyncthingApp />

// With custom props (className, style, onClick, etc.)
<SyncthingApp className="app-icon" style={{ opacity: 0.8 }} />

// With explicit size override
<SyncthingApp width={64} height={64} />
```

## Notes

- The icon renders at **32×32px** by default, matching the embedded PNG dimensions.
- The base64 PNG is inlined directly, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, event handlers) are forwarded via spread (`{...props}`).
- This component follows the same pattern used across the Fleet MDM icon set for third-party application icons.
