A React SVG component that renders the Clipbook icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Clipbook`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a PNG icon via a base64 data URI.

## Usage Example

```typescript
import { Clipbook } from "./Clipbook";

// Basic usage
<Clipbook />

// With custom dimensions and className
<Clipbook width={64} height={64} className="icon" />

// With style overrides
<Clipbook style={{ opacity: 0.8 }} aria-label="Clipbook" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full prop customization (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The icon is hardcoded as a base64 PNG (`512×512` source image, downscaled to `32×32` display). No external asset loading is required.
