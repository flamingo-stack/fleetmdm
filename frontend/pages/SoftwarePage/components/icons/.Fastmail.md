React SVG component that renders the Fastmail email service logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Fastmail`** — Default export; a functional React component that wraps an `<svg>` element containing a base64-encoded PNG of the Fastmail logo.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>`, allowing callers to override or extend any SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Fastmail from "./Fastmail";

// Basic usage
<Fastmail />

// With custom dimensions and class
<Fastmail width={64} height={64} className="email-icon" />

// With click handler
<Fastmail onClick={() => console.log("Fastmail clicked")} />
```

## Notes

- Default rendered size is **32×32 pixels**.
- The logo is embedded as a base64 PNG inside an SVG `<image>` tag, so no external assets or network requests are required.
- This component follows the same pattern used across the icon library in this repository — see other icon files at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/) for reference.
