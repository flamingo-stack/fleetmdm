A React SVG component that renders the Elephas logo as an inline SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Elephas`** — Default export. A functional React component that wraps a 32×32 SVG element containing the Elephas logo as a base64-encoded PNG `<image>` tag.

## Usage Example

```typescript
import Elephas from "./Elephas";

// Basic usage
<Elephas />

// With custom dimensions or className
<Elephas width={64} height={64} className="my-icon" />

// With style overrides
<Elephas style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The image is embedded as a base64-encoded PNG, so no external asset is required.
- Default rendered size is **32×32 pixels**.
