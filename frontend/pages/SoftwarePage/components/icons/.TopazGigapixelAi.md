A React SVG icon component that renders the Topaz Gigapixel AI brand logo as an inline base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`TopazGigapixelAi`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Topaz Gigapixel AI logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import TopazGigapixelAi from "./TopazGigapixelAi";

// Basic usage
<TopazGigapixelAi />

// With custom dimensions and className
<TopazGigapixelAi width={64} height={64} className="icon" />

// With accessibility attributes
<TopazGigapixelAi aria-label="Topaz Gigapixel AI" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The logo is self-contained — no external image requests are made at runtime.
- Fully compatible with standard SVG styling (e.g., `style`, `className`, `fill`).
