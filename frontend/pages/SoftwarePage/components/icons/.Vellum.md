A React SVG icon component that renders the Vellum logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Vellum`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element with an embedded PNG via a base64 `<image>` href.

## Usage Example

```typescript
import Vellum from "./Vellum";

// Basic usage
<Vellum />

// With custom size and className
<Vellum width={64} height={64} className="icon" />

// With accessibility attributes
<Vellum aria-label="Vellum" role="img" />
```

## Notes

- The logo is self-contained — no external image requests are made at runtime.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread to the root `<svg>` element.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
