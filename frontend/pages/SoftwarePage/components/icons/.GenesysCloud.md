React SVG icon component that renders the Genesys Cloud logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GenesysCloud` | `React.FC` | Default export; accepts all standard `SVGProps<SVGSVGElement>` props |

## Usage Example

```typescript
import GenesysCloud from "./GenesysCloud";

// Basic usage
<GenesysCloud />

// With custom dimensions and className
<GenesysCloud width={64} height={64} className="icon" />

// With inline styles
<GenesysCloud style={{ opacity: 0.8 }} />
```

## Notes

- Fixed default size of **32×32px**; override via `width`/`height` props.
- The logo image is self-contained — no external asset fetch required.
- All `SVGProps<SVGSVGElement>` are spread onto the `<svg>` element, enabling `className`, `style`, `aria-*`, and event handlers.
