A React SVG icon component that renders the Mockoon logo as a 32×32 inline base64-encoded PNG image.

## Key Components

- **`Mockoon`** — Default export. A functional React component that renders an `<svg>` wrapper containing the Mockoon logo as an embedded base64 PNG. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Mockoon from "./Mockoon";

// Basic usage
<Mockoon />

// With custom props
<Mockoon className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Mockoon width={64} height={64} />
```

## Notes

- The icon defaults to **32×32 pixels** but dimensions can be overridden via props.
- The image is embedded as a **base64 PNG** within an SVG `<image>` element — no external asset requests are made at runtime.
- Fully compatible with standard SVG prop customization (e.g., `className`, `style`, `aria-*`, `onClick`).
