React SVG icon component that renders the CoconutBattery application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Coconutbattery`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the CoconutBattery app icon via a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Coconutbattery from "./Coconutbattery";

// Basic usage
<Coconutbattery />

// With custom dimensions or className
<Coconutbattery width={64} height={64} className="app-icon" />

// With inline styles
<Coconutbattery style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The icon image is self-contained — no external asset dependencies at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
