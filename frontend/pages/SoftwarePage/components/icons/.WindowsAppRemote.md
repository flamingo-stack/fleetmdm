A React SVG icon component rendering the Windows logo on a blue (`#0078D4`) background, styled for use as a "Windows App Remote" icon.

## Key Components

- **`WindowsAppRemote`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props for full SVG customization (e.g., `width`, `height`, `className`, `style`).

## Usage Example

```typescript
import WindowsAppRemote from "./WindowsAppRemote";

// Basic usage
<WindowsAppRemote width={32} height={32} />

// With custom size and class
<WindowsAppRemote width={64} height={64} className="icon" />
```
