A React SVG icon component that renders the Weasis medical imaging viewer logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Weasis`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the wrapping `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Weasis from "./Weasis";

// Basic usage
<Weasis />

// With custom size and styling
<Weasis width={64} height={64} className="icon" />

// With click handler
<Weasis onClick={() => console.log("Weasis clicked")} />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via `width`/`height` props.
- The image is self-contained — no external assets or network requests are required.
