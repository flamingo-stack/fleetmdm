A React SVG icon component that renders the FSMonitor logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Fsmonitor`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG wrapping an embedded PNG icon.

## Usage Example

```typescript
import Fsmonitor from "./Fsmonitor";

// Basic usage
<Fsmonitor />

// With custom dimensions or className
<Fsmonitor width={64} height={64} className="icon" />

// With accessibility attributes
<Fsmonitor aria-label="FSMonitor" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is hardcoded as a base64-encoded PNG — no external image fetch required.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
