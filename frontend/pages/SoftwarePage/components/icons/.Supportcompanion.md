React SVG component that renders the SupportCompanion application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Supportcompanion`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Supportcompanion from "./Supportcompanion";

// Basic usage
<Supportcompanion />

// With custom size or className
<Supportcompanion width={64} height={64} className="icon" />

// With accessibility attributes
<Supportcompanion aria-label="SupportCompanion" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element.
- The icon image is self-contained — no external asset references required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
