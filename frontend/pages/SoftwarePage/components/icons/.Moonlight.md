A React SVG component that renders a 32×32 "Moonlight" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Moonlight`** — Default export; a functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing an inline PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import Moonlight from "./Moonlight";

// Basic usage
<Moonlight />

// With custom dimensions or className
<Moonlight width={64} height={64} className="icon" />

// With accessibility attributes
<Moonlight aria-label="Moonlight" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external assets or network requests required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
