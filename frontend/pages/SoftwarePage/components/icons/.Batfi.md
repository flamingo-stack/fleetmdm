A React SVG icon component that renders the Batfi application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Batfi`** — Default export. A functional React component that wraps a 32×32 `<svg>` element embedding the Batfi logo as a base64-encoded PNG via an `<image>` tag.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of SVG attributes (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Batfi from "./Batfi";

// Basic usage
<Batfi />

// With custom dimensions and className
<Batfi width={64} height={64} className="icon" />

// With event handler
<Batfi onClick={() => console.log("Batfi clicked")} />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG — no external image assets are required.
- Spread props (`{...props}`) are applied directly to the root `<svg>` element, making this compatible with icon libraries or design systems expecting standard SVG prop interfaces.
