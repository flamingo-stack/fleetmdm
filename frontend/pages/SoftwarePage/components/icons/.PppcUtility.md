React SVG component that renders the PPPC Utility application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`PppcUtility`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded PNG icon for the PPPC Utility macOS application.

## Usage Example

```typescript
import PppcUtility from "./PppcUtility";

// Basic usage
<PppcUtility />

// With custom dimensions or class
<PppcUtility width={64} height={64} className="app-icon" />

// With style overrides
<PppcUtility style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained — no external asset or network request required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Default render size is **32×32px**; override via `width`/`height` props.
- Relates to Fleet MDM's [Privacy Preferences Policy Control (PPPC)](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/icons/PppcUtility.tsx) feature, which manages macOS TCC/privacy permission profiles.
