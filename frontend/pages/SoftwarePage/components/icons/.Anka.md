A React SVG component that renders the Anka brand icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Anka`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Anka from "./Anka";

// Basic usage
<Anka />

// With custom size and className
<Anka width={64} height={64} className="icon" />

// With accessibility attributes
<Anka aria-label="Anka" role="img" />
```

## Notes

- The icon image is fully self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
