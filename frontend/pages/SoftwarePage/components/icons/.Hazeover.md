A React SVG component that renders the Hazeover application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Hazeover`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Hazeover app icon as an embedded PNG.

## Usage Example

```typescript
import Hazeover from "./Hazeover";

// Basic usage
<Hazeover />

// With custom dimensions or className
<Hazeover width={64} height={64} className="app-icon" />

// With accessibility attributes
<Hazeover aria-label="Hazeover" role="img" />
```

## Notes

- The icon is embedded as a base64-encoded PNG (`data:image/png;base64,...`) inside an `<image>` SVG element, making it self-contained with no external asset dependencies.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props are forwarded to the root `<svg>` element via spread (`{...props}`).
- Typically used within Fleet MDM's software/application icon set. See the full icon library at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
