A React SVG icon component that renders the Windows Notepad application icon (`notepad.exe`) as a 32×32 inline PNG embedded via a base64-encoded data URI.

## Key Components

- **`Notepadexe`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 `<svg>` containing an `<image>` element with the icon's base64-encoded PNG source.

## Usage Example

```typescript
import Notepadexe from "./Notepadexe";

// Basic usage
<Notepadexe />

// With custom dimensions and class
<Notepadexe width={64} height={64} className="app-icon" />

// With accessibility attributes
<Notepadexe aria-label="Notepad" role="img" />
```

## Notes

- The icon data is fully self-contained — no external image assets or network requests are required.
- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32px**; override via `width`/`height` props as needed.
