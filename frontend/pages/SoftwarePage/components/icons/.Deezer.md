A React SVG component that renders the Deezer logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Deezer`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override attributes like `className`, `style`, `width`, `height`, etc.

## Usage Example

```typescript
import Deezer from "./Deezer";

// Basic usage
<Deezer />

// With custom size and className
<Deezer width={64} height={64} className="logo-icon" />

// With inline styles
<Deezer style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**
- The logo image is embedded as a **base64 PNG** within an SVG `<image>` element, meaning no external asset requests are made
- All additional props are spread onto the root `<svg>` element via `SVGProps<SVGSVGElement>`, providing full flexibility for styling and accessibility attributes (e.g., `aria-label`, `role`)
