A React SVG component that renders the Cardhop application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Cardhop`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Cardhop app icon as an embedded base64-encoded PNG.

## Usage Example

```typescript
import Cardhop from "./Cardhop";

// Basic usage
<Cardhop />

// With custom dimensions and className
<Cardhop width={64} height={64} className="app-icon" />

// With style overrides
<Cardhop style={{ borderRadius: 8 }} aria-label="Cardhop" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via `width`/`height` props.
- The PNG image is embedded as a base64 data URI, meaning no external image fetch is required — the icon is fully self-contained.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
