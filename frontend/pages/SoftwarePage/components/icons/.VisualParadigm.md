A React SVG component that renders the Visual Paradigm logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`VisualParadigm`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Visual Paradigm logo as an embedded PNG via base64 data URI.

## Usage Example

```typescript
import VisualParadigm from "./VisualParadigm";

// Basic usage
<VisualParadigm />

// With custom dimensions or className
<VisualParadigm width={64} height={64} className="logo-icon" />

// With style overrides
<VisualParadigm style={{ opacity: 0.8 }} aria-label="Visual Paradigm" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The PNG image data is embedded as a base64 data URI, so no external asset request is made.
- The component is part of the brand/integration icon set in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository.
