A React SVG component that renders the Fleet MDM "Commander" icon as a 32×32 SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Commander`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, forwarded to the root `<svg>` element.
- The icon is rendered via an `<image>` element with a base64 PNG `href`, making it self-contained with no external asset dependencies.

## Usage Example

```typescript
import Commander from "./Commander";

// Basic usage
<Commander />

// With custom size and className
<Commander width={64} height={64} className="icon" />

// With accessibility attributes
<Commander aria-label="Commander" role="img" />
```

## Notes

- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
- The embedded PNG is `512×512` pixels (per EXIF metadata in the base64 payload), scaled down by the SVG viewport.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
