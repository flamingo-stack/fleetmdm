A React SVG component that renders the macOS Reminders app menubar icon as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`RemindersMenubar`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Reminders menubar icon.

## Usage Example

```typescript
import RemindersMenubar from "./RemindersMenubar";

// Basic usage
<RemindersMenubar />

// With custom dimensions or className
<RemindersMenubar width={16} height={16} className="menubar-icon" />

// With inline styles
<RemindersMenubar style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained — no external asset dependencies.
- Accepts all native SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) via prop spreading.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
