A React SVG icon component that renders the ChromeOS logo as an inline SVG element.

## Key Components

- **`ChromeOS`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 ChromeOS icon.

## Usage Example

```typescript
import ChromeOS from "@/components/icons/ChromeOS";

// Basic usage
<ChromeOS />

// Custom dimensions and className
<ChromeOS width={24} height={24} className="platform-icon" />

// With inline styles
<ChromeOS style={{ opacity: 0.8 }} aria-label="ChromeOS" />
```

## Notes

- The icon uses a fixed `32×32` viewBox with a light background (`#F9FAFC`) and a slate-colored logo path (`#515774`).
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-label`) are forwarded via spread, making it flexible for sizing and accessibility needs.
- No external dependencies beyond React — safe to use in any React/Next.js project in the [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) repository.
