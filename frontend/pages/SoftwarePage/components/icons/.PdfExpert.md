React SVG component that renders the PDF Expert application icon as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`PdfExpert`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64 PNG of the PDF Expert app icon.

## Usage Example

```typescript
import PdfExpert from "./PdfExpert";

// Basic usage
<PdfExpert />

// With custom dimensions or className
<PdfExpert width={64} height={64} className="app-icon" />

// With inline styles
<PdfExpert style={{ borderRadius: 4 }} />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread (`{...props}`), making this fully composable.
- The icon image is self-contained — no external image assets or network requests are required.
- Default render size is **32×32 pixels**; override via `width`/`height` props as needed.
