A React SVG icon component that renders the WisprFlow application logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`WisprFlow`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import WisprFlow from "./WisprFlow";

// Basic usage
<WisprFlow />

// With custom dimensions or className
<WisprFlow width={64} height={64} className="app-icon" />

// With style overrides
<WisprFlow style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32** by default but dimensions can be overridden via props.
- The image data is a self-contained base64 PNG — no external asset dependencies.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — search the repo for its import path to identify placement within the icon library.
