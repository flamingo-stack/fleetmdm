A React SVG icon component that renders the Wrike for Mac application logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`WrikeForMac`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a fixed 32×32 SVG containing the Wrike for Mac icon as an embedded PNG data URI.

## Usage Example

```typescript
import WrikeForMac from "./WrikeForMac";

// Basic usage
<WrikeForMac />

// With custom props
<WrikeForMac className="icon" style={{ opacity: 0.8 }} />
```
