A React SVG icon component that renders the Amazon Workspaces logo as a 32×32 inline PNG image embedded via base64 encoding.

## Key Components

- **`AmazonWorkspaces`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the outer `<svg>` element for full customization support.

## Usage Example

```typescript
import AmazonWorkspaces from "./AmazonWorkspaces";

// Basic usage
<AmazonWorkspaces />

// With custom dimensions and class
<AmazonWorkspaces width={64} height={64} className="icon" />

// With inline styles
<AmazonWorkspaces style={{ opacity: 0.8 }} />
```

## Notes

- Fixed default size: **32×32 pixels**
- The logo is embedded as a **base64-encoded PNG** inside an SVG `<image>` element — no external asset requests at runtime.
- Accepts any `SVGProps<SVGSVGElement>` (e.g., `width`, `height`, `className`, `style`, `aria-label`) passed directly to the root `<svg>`.
- Overriding `width`/`height` via props will resize the SVG container but not the inner image; for scaled rendering, pair with CSS (`width: 100%; height: auto;`).
