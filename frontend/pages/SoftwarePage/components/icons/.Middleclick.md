A React SVG component that renders a middle-click mouse icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Middleclick`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG image via a base64 `href` data URI.

## Usage Example

```typescript
import Middleclick from "./Middleclick";

// Basic usage
<Middleclick />

// With custom sizing or className
<Middleclick width={64} height={64} className="icon" />

// With accessibility attributes
<Middleclick aria-label="Middle click" role="img" />
```

## Notes

- The icon image is fully self-contained — no external assets or network requests required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread, making the component flexible for use in toolbars, tooltips, or keyboard shortcut guides.
