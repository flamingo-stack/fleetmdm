SVG icon component that renders the PhpStorm IDE logo as an inline base64-encoded PNG image.

## Key Components

- **`PhpStorm`** — Default export. A React functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the PhpStorm logo as an embedded base64 PNG image.

## Usage Example

```typescript
import PhpStorm from "./PhpStorm";

// Basic usage
<PhpStorm />

// With custom dimensions and className
<PhpStorm width={64} height={64} className="icon" />

// With inline styles
<PhpStorm style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**, overridable via `width`/`height` props.
- The logo is embedded as a base64 PNG `<image>` element within the SVG — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
