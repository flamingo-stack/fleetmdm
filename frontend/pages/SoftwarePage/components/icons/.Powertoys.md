React SVG icon component that renders the Microsoft PowerToys application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Powertoys`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the PowerToys icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Powertoys from "./Powertoys";

// Basic usage
<Powertoys />

// With custom dimensions and className
<Powertoys width={64} height={64} className="app-icon" />

// With accessibility attributes
<Powertoys aria-label="PowerToys" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The image data is embedded as a **base64 PNG**, meaning no external network request is needed.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
