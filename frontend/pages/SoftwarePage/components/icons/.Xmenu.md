SVG icon component that renders a 32×32 PNG image (base64-encoded) of an X/hamburger menu icon using an inline SVG wrapper.

## Key Components

- **`Xmenu`** — Default export. A React functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a fixed 32×32 SVG element embedding a base64-encoded PNG icon via an `<image>` tag.

## Usage Example

```typescript
import Xmenu from "./Xmenu";

// Basic usage
<Xmenu />

// With custom className or style overrides
<Xmenu className="icon" style={{ opacity: 0.8 }} />

// With onClick handler
<Xmenu onClick={() => setMenuOpen(prev => !prev)} />
```

## Notes

- The PNG image is embedded directly as a base64 `data:image/png` URI — no external asset file is required.
- The SVG wrapper accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via the spread `{...props}`, making it flexible for accessibility and styling overrides.
- Width and height are defaulted to `32` but can be overridden via props.
