A React SVG component that renders the Pale Moon browser logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`PaleMoon`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Pale Moon browser icon as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import PaleMoon from "./PaleMoon";

// Basic usage
<PaleMoon />

// With custom dimensions or className
<PaleMoon width={64} height={64} className="browser-icon" />

// With inline styles
<PaleMoon style={{ opacity: 0.8 }} />
```

## Notes

- The icon is self-contained — no external image assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
