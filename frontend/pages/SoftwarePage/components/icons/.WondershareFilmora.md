React SVG component that renders the Wondershare Filmora application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `WondershareFilmora` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component for Wondershare Filmora |

## Usage Example

```typescript
import WondershareFilmora from "./WondershareFilmora";

// Basic usage
<WondershareFilmora />

// With custom dimensions
<WondershareFilmora width={64} height={64} />

// With additional SVG props
<WondershareFilmora className="app-icon" aria-label="Wondershare Filmora" />
```

## Notes

- Renders a fixed 32×32 SVG by default; dimensions are overridable via `width`/`height` props
- The icon image is embedded as a base64-encoded PNG — no external asset requests
- Accepts all standard `SVGProps<SVGSVGElement>` for full styling and accessibility flexibility
- Intended for use in software/application icon lists, such as managed device application catalogs in [FleetMDM](https://github.com/flamingo-stack/fleetmdm)
