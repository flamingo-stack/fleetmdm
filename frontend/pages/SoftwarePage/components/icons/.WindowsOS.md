SVG icon component that renders the Windows OS logo for use in Fleet MDM's device management interface.

## Key Components

- **`WindowsOS`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute customization (className, width, height, style, etc.).

## Usage Example

```typescript
import WindowsOS from "components/icons/WindowsOS";

// Basic usage
<WindowsOS />

// With custom dimensions and styling
<WindowsOS width={24} height={24} className="os-icon" />

// Inline style override
<WindowsOS style={{ width: 16, height: 16 }} />
```

## Notes

- Renders a 32×32 viewBox by default with a light background (`#F9FAFC`) and a slate-blue Windows logo (`#515774`).
- Spread props pattern allows full override of any SVG attribute without wrapper elements.
- Pairs with sibling OS icon components (macOS, Linux, etc.) for consistent platform identification across device tables and filters.
