React SVG icon component that renders the OpenRCT2 logo as an inline PNG image embedded within an SVG wrapper.

## Key Components

- **`Openrct2`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG of the OpenRCT2 logo.

## Usage Example

```typescript
import Openrct2 from "./Openrct2";

// Basic usage
<Openrct2 />

// With custom dimensions and class
<Openrct2 width={64} height={64} className="app-icon" />

// With inline styles
<Openrct2 style={{ opacity: 0.8 }} aria-label="OpenRCT2" />
```

## Notes

- The component is a thin wrapper — all props are spread onto the underlying `<svg>` element, making it fully customizable via standard SVG attributes.
- The embedded image is a 512×512 PNG (downscaled to 32×32 by default) stored as a base64 data URI, so no external image assets are required.
