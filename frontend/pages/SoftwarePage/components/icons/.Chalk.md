A React SVG component that renders the Chalk logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Chalk`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around a base64-encoded PNG of the Chalk logo.

## Usage Example

```typescript
import Chalk from "./Chalk";

// Basic usage
<Chalk />

// With custom size and className
<Chalk width={64} height={64} className="icon" />

// With style overrides
<Chalk style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- The default rendered size is **32×32 pixels**; pass `width`/`height` props to override.
- The image data is a self-contained base64 PNG — no external asset fetch required.
