A React SVG component that renders the BoltAI application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Boltai`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the BoltAI logo as an inline base64 PNG image.

## Usage Example

```typescript
import Boltai from "./Boltai";

// Basic usage
<Boltai />

// With custom dimensions or className
<Boltai width={64} height={64} className="app-icon" />

// As part of a button or nav item
<button>
  <Boltai aria-label="BoltAI" />
  Open BoltAI
</button>
```

## Notes

- The component passes all SVG props through via spread (`{...props}`), allowing full customization of SVG attributes such as `width`, `height`, `className`, and `style`.
- The icon is embedded as a base64-encoded PNG (`data:image/png;base64,...`) inside an `<image>` element, meaning no external asset fetch is required at runtime.
- Default rendered size is **32×32 pixels**; override via props as needed.
