React SVG icon component that renders the Dropbox logo as an inline base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Dropbox`** — Default export. A functional React component that accepts all standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 Dropbox brand icon.

## Usage Example

```typescript
import Dropbox from "./Dropbox";

// Basic usage
<Dropbox />

// With custom dimensions and className
<Dropbox width={64} height={64} className="icon" />

// With onClick handler
<Dropbox onClick={() => console.log("Dropbox clicked")} />
```

## Notes

- Renders at **32×32 pixels** by default; dimensions can be overridden via props.
- The icon image is embedded as a **base64 PNG** inside an `<image>` SVG element — no external image requests are made.
- Accepts all native `SVGSVGElement` props (e.g., `className`, `style`, `onClick`, `aria-*`) via spread.
