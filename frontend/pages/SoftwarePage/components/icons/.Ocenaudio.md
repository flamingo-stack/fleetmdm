A React SVG component that renders the Ocenaudio application icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Ocenaudio`** — Default export. A functional React component that wraps a base64-encoded PNG icon inside an `<svg>` element, forwarding all standard `SVGProps` to the root `<svg>` tag.

## Usage Example

```typescript
import Ocenaudio from "./Ocenaudio";

// Basic usage
<Ocenaudio />

// With custom dimensions or className
<Ocenaudio width={64} height={64} className="app-icon" />

// With style overrides
<Ocenaudio style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) — `className`, `style`, `onClick`, `aria-*`, etc.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- The icon image is fully self-contained (no external network requests) as it uses an inline base64-encoded PNG.
- Likely part of a shared icon library within the Fleet MDM UI. See related assets at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/).
