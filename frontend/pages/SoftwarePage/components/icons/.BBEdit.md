React SVG component that renders the BBEdit application icon as a 32×32 PNG image embedded as a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`BBEdit`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full prop customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import BBEdit from "./BBEdit";

// Basic usage
<BBEdit />

// With custom size and class
<BBEdit width={64} height={64} className="app-icon" />

// With click handler
<BBEdit onClick={() => console.log("BBEdit clicked")} />
```

## Notes

- The icon is rendered as a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` `href`. This avoids external file dependencies but increases bundle size.
- All standard SVG props are forwarded, making it composable with icon libraries or styled-components.
