A React functional component that renders the Megasync application icon as an SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Megasync`** — Default export. A React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Megasync logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Megasync from './Megasync';

// Basic usage
<Megasync />

// With custom dimensions and className
<Megasync width={64} height={64} className="app-icon" />

// With accessibility attributes
<Megasync aria-label="Megasync" role="img" />
```

## Notes

- The icon defaults to **32×32 pixels** but accepts any valid SVG props for customization (e.g., `width`, `height`, `style`, `className`).
- The PNG image data is fully self-contained via a base64 `data:image/png` URI — no external asset requests are made at runtime.
- Follows the standard Flamingo icon component pattern used across the icon library.
