A React SVG component that renders the Jump Desktop application icon as a 32×32 SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`JumpDesktop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering the Jump Desktop logo via an inline base64 PNG `<image>` element within an SVG wrapper.

## Usage Example

```typescript
import JumpDesktop from "./JumpDesktop";

// Basic usage
<JumpDesktop />

// With custom dimensions or className
<JumpDesktop width={64} height={64} className="app-icon" />

// With accessibility attributes
<JumpDesktop aria-label="Jump Desktop" role="img" />
```

## Notes

- The icon is **self-contained** — no external image files or network requests are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**; the embedded PNG source is **512×512**, so the icon scales cleanly to larger sizes if `width`/`height` props are overridden.
