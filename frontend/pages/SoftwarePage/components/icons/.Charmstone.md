A React SVG component that renders the Charmstone logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Charmstone`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Charmstone from './Charmstone';

// Basic usage
<Charmstone />

// With custom dimensions or className
<Charmstone width={64} height={64} className="icon" />

// With style overrides
<Charmstone style={{ opacity: 0.8 }} />
```

## Notes

- The PNG image data is inlined as a base64 data URI, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread.
- The component is stateless and has no side effects, making it safe to use in any rendering context.
