A React SVG component that renders the Easydict application icon as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`Easydict`** — Default export. A functional React component that wraps a 32×32 SVG element containing the Easydict app icon as an embedded base64 PNG image.

## Usage Example

```typescript
import Easydict from "./Easydict";

// Basic usage
<Easydict />

// With custom SVG props (className, style, onClick, etc.)
<Easydict
  width={64}
  height={64}
  className="app-icon"
  style={{ borderRadius: 8 }}
/>
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) — any valid SVG attribute can be passed as a prop.
- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The icon is self-contained — no external image requests are made at runtime.
