A React SVG icon component that renders the Sublime Text logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`SublimeText`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass custom `className`, `style`, `onClick`, and other SVG attributes.

## Usage Example

```typescript
import SublimeText from './SublimeText';

// Basic usage
<SublimeText />

// With custom dimensions and styling
<SublimeText width={64} height={64} className="icon" />

// With click handler
<SublimeText onClick={() => console.log('clicked')} style={{ cursor: 'pointer' }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The logo image is embedded as a **base64-encoded PNG** inside an SVG `<image>` element — no external asset fetch required.
- Part of an icon component library at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/SublimeText.tsx).
