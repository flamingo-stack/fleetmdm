React SVG icon component that renders a "Local" icon as a 32×32 PNG embedded via a base64-encoded data URI.

## Key Components

- **`Local`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (className, style, onClick, aria-*, etc.).

## Usage Example

```typescript
import Local from "./Local";

// Basic usage
<Local />

// With custom sizing and styling
<Local width={24} height={24} className="icon-local" />

// With event handler
<Local onClick={() => console.log("clicked")} aria-label="Local environment" />
```

## Notes

- The icon image is a 32×32 pixel PNG embedded as a base64 data URI inside an `<image>` element — no external asset file is required.
- The SVG wrapper accepts all standard SVG props, making it composable with icon libraries or design systems.
- Default rendered size is **32×32 pixels**.
