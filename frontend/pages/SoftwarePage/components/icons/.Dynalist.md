A React SVG icon component that renders the Dynalist logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Dynalist`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Dynalist brand icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Dynalist from './Dynalist';

// Basic usage
<Dynalist />

// With custom size or className
<Dynalist width={64} height={64} className="icon" />

// With accessibility attributes
<Dynalist aria-label="Dynalist" role="img" />
```

## Notes

- The icon image is self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
