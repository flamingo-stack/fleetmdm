React SVG component that renders the Krita application icon as a 32×32 inline SVG using a base64-encoded PNG image.

## Key Components

- **`Krita`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Krita from './Krita';

// Basic usage
<Krita />

// With custom dimensions and className
<Krita width={64} height={64} className="app-icon" />

// With inline styles
<Krita style={{ borderRadius: '8px' }} />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default but accepts any `SVGProps` overrides (e.g., `width`, `height`, `className`, `style`).
- The image data is embedded as a base64-encoded PNG `<image>` element, so no external asset fetch is required.
- Compatible with any React project — no additional dependencies beyond `react`.
