A React SVG icon component that renders the Intellidock application logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Intellidock`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a `<image>` element using a base64 data URI.

## Usage Example

```typescript
import Intellidock from "./Intellidock";

// Basic usage
<Intellidock />

// With custom dimensions and className
<Intellidock width={64} height={64} className="app-icon" />

// With accessibility attributes
<Intellidock aria-label="Intellidock" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon is self-contained — no external image assets are required at runtime.
- Default render size is `32×32`; override via `width`/`height` props.
