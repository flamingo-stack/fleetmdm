A React SVG component that renders the Swish payment logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Swish`** — Default export; a functional React component that wraps a base64-encoded PNG of the Swish logo inside an SVG element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Swish from "./Swish";

// Basic usage
<Swish />

// With custom dimensions and className
<Swish width={64} height={64} className="payment-icon" />

// With accessibility attributes
<Swish aria-label="Pay with Swish" role="img" />
```

## Notes

- The icon renders at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG is embedded as a **base64 data URI**, so no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
