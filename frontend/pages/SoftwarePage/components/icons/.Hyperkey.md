A React SVG component that renders a Hyperkey icon using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Hyperkey`** — Default export. A functional React component that wraps a 32×32 SVG element containing a base64-encoded PNG image of the Hyperkey icon.
- Accepts all standard `SVGProps<SVGSVGElement>` props, enabling full customization (e.g., `className`, `style`, `onClick`, `aria-*`).

## Usage Example

```typescript
import Hyperkey from "./Hyperkey";

// Basic usage
<Hyperkey />

// With custom size and class
<Hyperkey width={64} height={64} className="icon" />

// With accessibility attributes
<Hyperkey aria-label="Hyperkey" role="img" />
```

## Notes

- The icon is rendered as an inline `<image>` inside an SVG, using a base64 PNG data URI — no external image requests are made.
- The native SVG dimensions are 32×32; override with `width`/`height` props as needed.
- Part of the Flamingo/FleetMDM icon set. See the full component tree at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
