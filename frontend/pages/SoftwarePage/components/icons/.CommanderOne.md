A React SVG component that renders the CommanderOne application icon as an inline PNG image embedded via base64 encoding within an SVG wrapper.

## Key Components

- **`CommanderOne`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the CommanderOne app icon as an embedded base64 PNG.

## Usage Example

```typescript
import CommanderOne from "./CommanderOne";

// Basic usage
<CommanderOne />

// With custom dimensions and className
<CommanderOne width={64} height={64} className="app-icon" />

// With inline styles
<CommanderOne style={{ borderRadius: "8px" }} />
```

## Notes

- The icon renders at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 `data:image/png` URI — no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
- Part of the Fleet MDM integration icon set within the Flamingo platform.
