A React SVG component that renders the "DFU Blaster Pro" icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`DfuBlasterPro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute customization (className, style, width, height, etc.)
- Renders a 32×32 SVG containing a base64-encoded PNG `<image>` element
- All SVG props are spread onto the root `<svg>` element, allowing override of default dimensions

## Usage Example

```typescript
import DfuBlasterPro from "./DfuBlasterPro";

// Basic usage
<DfuBlasterPro />

// With custom size and class
<DfuBlasterPro width={64} height={64} className="icon" />

// With inline style
<DfuBlasterPro style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**
- The icon image is fully self-contained (no external image requests) via an inline base64 PNG
- Extend or override any SVG attribute via standard `SVGProps` — useful for accessibility (`aria-label`, `role`) or event handlers
