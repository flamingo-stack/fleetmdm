A React SVG component that renders the eM Client email application logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Emclient`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG logo via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Emclient from "./Emclient";

// Basic usage
<Emclient />

// With custom sizing or className
<Emclient width={64} height={64} className="app-icon" />

// With accessibility attributes
<Emclient aria-label="eM Client" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are spread onto the root `<svg>` element, allowing full customization at the call site.
- The icon renders at **32×32px** by default. The internal PNG is sourced from a base64 data URI (originally a 512×512 image downscaled to 32×32 at display time).
- This component is part of the Flamingo/FleetMDM icon set. See related icon components in the repository:

https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons
