React SVG icon component that renders the Amazon DCV (Desktop Cloud Visualization) logo as a scalable vector graphic.

## Key Components

- **`AmazonDCV`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, enabling full customization of size, className, style, and other SVG attributes.

## Usage Example

```typescript
import AmazonDCV from "./AmazonDCV";

// Basic usage
<AmazonDCV />

// With custom dimensions and className
<AmazonDCV width={32} height={32} className="icon" />

// With inline styles
<AmazonDCV width={24} height={24} style={{ color: "gray" }} />
```

## Notes

- The component renders a multi-path SVG using hardcoded fill colors (`#FEFEFE`, `#259ED5`, `#BBE1F2`), representing the official Amazon DCV brand palette.
- No external dependencies beyond React.
- Fully compatible with standard SVG prop overrides (e.g., `width`, `height`, `className`, `aria-label`).
