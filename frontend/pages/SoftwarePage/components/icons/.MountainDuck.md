A React SVG component that renders the Mountain Duck application icon as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`MountainDuck`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

The component renders a 32×32 `<svg>` containing a single `<image>` element whose `href` attribute holds the full Mountain Duck logo as a base64-encoded PNG, eliminating any external asset dependency.

## Usage Example

```typescript
import MountainDuck from "./MountainDuck";

// Basic usage
<MountainDuck />

// With custom size and class
<MountainDuck width={64} height={64} className="app-icon" />

// With accessibility attributes
<MountainDuck aria-label="Mountain Duck" role="img" />
```

## Notes

- The icon is fully self-contained — no network request or file import is required for the image to render.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are supported via prop spreading.
- Default dimensions are `32×32` pixels but can be overridden via `width` / `height` props.
