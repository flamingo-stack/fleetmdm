React SVG icon component that renders the RsyncUI application logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Rsyncui`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the RsyncUI app icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Rsyncui from "./Rsyncui";

// Basic usage
<Rsyncui />

// With custom dimensions or className
<Rsyncui width={64} height={64} className="app-icon" />

// With style overrides
<Rsyncui style={{ opacity: 0.8 }} aria-label="RsyncUI" />
```

## Notes

- The icon is self-contained — no external image file dependencies.
- Inherits all SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) via spread.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props.
- The embedded PNG is 512×512 and scaled down via the SVG viewport.
