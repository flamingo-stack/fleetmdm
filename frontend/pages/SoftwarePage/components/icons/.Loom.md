A React SVG component that renders the Loom brand logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Loom`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Loom logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Loom from "./Loom";

// Basic usage
<Loom />

// With custom dimensions or className
<Loom width={64} height={64} className="brand-icon" />

// With aria label for accessibility
<Loom aria-label="Loom" role="img" />
```

## Notes

- The logo image is self-contained — no external network requests are made; the PNG is inlined as a base64 data URI.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- This component follows the same pattern as other brand icon components in the repository. See related icons at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/).
