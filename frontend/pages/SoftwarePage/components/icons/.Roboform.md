A React SVG component that renders the Roboform brand logo as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Roboform`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a `data:image/png;base64` href.

## Usage Example

```typescript
import Roboform from "./Roboform";

// Basic usage
<Roboform />

// With custom dimensions or className
<Roboform width={64} height={64} className="icon" />

// With accessibility attributes
<Roboform aria-label="Roboform" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread (`{...props}`), overriding defaults where applicable.
- The 32×32 default dimensions match a typical toolbar/icon size; the embedded PNG is 512×512 (per EXIF metadata), so it will scale crisply if rendered larger.
