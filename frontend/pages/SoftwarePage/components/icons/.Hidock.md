A React SVG component that renders the Hidock application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Hidock`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a base64-encoded PNG icon via an `<image>` element.

## Usage Example

```typescript
import Hidock from './Hidock';

// Basic usage
<Hidock />

// With custom dimensions or className
<Hidock width={64} height={64} className="app-icon" />

// With accessibility attributes
<Hidock aria-label="Hidock" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default but accepts any `SVGProps` override (e.g., `width`, `height`, `className`, `style`).
- The image content is a **base64-encoded PNG** embedded directly in the component — no external asset requests are made.
- The underlying PNG metadata indicates a **512×512** source image (downscaled to 32×32 via the SVG `image` element).
