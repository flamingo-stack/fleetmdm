A React SVG component that renders the Hammerspoon application icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Hammerspoon`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Hammerspoon from "./Hammerspoon";

// Basic usage
<Hammerspoon />

// With custom size and class
<Hammerspoon width={64} height={64} className="app-icon" />

// With accessibility attributes
<Hammerspoon aria-label="Hammerspoon" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external asset or network request required.
- Default dimensions are `32×32`; override via `width`/`height` props.
