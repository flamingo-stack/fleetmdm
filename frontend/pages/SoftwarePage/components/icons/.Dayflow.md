A React SVG component that renders the Dayflow brand icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Dayflow`** — Default exported functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element with an embedded base64 PNG image

## Usage Example

```typescript
import Dayflow from './Dayflow';

// Basic usage
<Dayflow />

// With custom dimensions via SVG props
<Dayflow width={64} height={64} />

// With className or style
<Dayflow className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is embedded as a base64-encoded PNG (no external asset dependency)
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread
- The component is stateless and has no side effects — safe for SSR
