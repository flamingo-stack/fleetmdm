A React SVG component that renders the OnlySwitch brand logo as an inline SVG element containing a base64-encoded PNG image (32×32 pixels).

## Key Components

- **`OnlySwitch`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import OnlySwitch from "./OnlySwitch";

// Basic usage
<OnlySwitch />

// With custom dimensions or className
<OnlySwitch width={64} height={64} className="brand-logo" />

// With accessibility attributes
<OnlySwitch aria-label="OnlySwitch logo" role="img" />
```

## Notes

- The embedded PNG is a 512×512 source image downscaled to 32×32 via the SVG `width`/`height` attributes.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making it fully composable.
- No external asset dependencies — the image data is fully self-contained in the component.
