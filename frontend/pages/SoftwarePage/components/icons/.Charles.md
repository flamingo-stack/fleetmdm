React SVG wrapper component that renders the Charles proxy tool logo as an inline PNG image encoded in Base64 format.

## Key Components

- **`Charles`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing an embedded Base64-encoded PNG of the Charles proxy logo.

## Usage Example

```typescript
import Charles from "./Charles";

// Basic usage
<Charles />

// With custom dimensions or className
<Charles width={64} height={64} className="tool-icon" />

// With style overrides
<Charles style={{ opacity: 0.8 }} />
```

## Notes

- The component passes all SVG props through (`{...props}`), allowing consumers to override `width`, `height`, `className`, `style`, and other SVG attributes.
- The image data is self-contained — no external asset requests are made at runtime.
- Default render size is **32×32 pixels**.
