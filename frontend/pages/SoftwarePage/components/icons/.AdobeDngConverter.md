A React SVG component that renders the Adobe DNG Converter application icon as an embedded PNG image (32×32 pixels) using a base64-encoded data URI.

## Key Components

- **`AdobeDngConverter`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>`, which renders a 32×32 `<svg>` containing an `<image>` element with the icon data embedded as a base64 PNG.

## Usage Example

```typescript
import AdobeDngConverter from "./AdobeDngConverter";

// Basic usage
<AdobeDngConverter />

// With custom size and className
<AdobeDngConverter width={64} height={64} className="app-icon" />

// With accessibility attributes
<AdobeDngConverter
  role="img"
  aria-label="Adobe DNG Converter"
  style={{ display: "block" }}
/>
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via the spread `{...props}`.
- The icon is fully self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
