A React SVG component that renders a **PhoenixSlides** icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`PhoenixSlides`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element via spread.

## Usage Example

```typescript
import PhoenixSlides from "./PhoenixSlides";

// Basic usage
<PhoenixSlides />

// With custom dimensions and styling
<PhoenixSlides
  width={64}
  height={64}
  className="icon"
  style={{ opacity: 0.8 }}
/>

// With an accessible label
<PhoenixSlides aria-label="Phoenix Slides" role="img" />
```

## Notes

- Default dimensions are **32×32px**, overridable via `width`/`height` props.
- The PNG image data is embedded as a base64 `data:image/png` string inside an SVG `<image>` element — no external asset required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
