A React SVG wrapper component that renders a 32×32 "Tiles" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Tiles`** — A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing an inline base64 PNG image asset.

## Usage Example

```typescript
import { Tiles } from "./Tiles";

// Basic usage
<Tiles />

// With custom dimensions and class
<Tiles width={64} height={64} className="icon" />

// With style overrides
<Tiles style={{ opacity: 0.8 }} aria-label="Tiles icon" />
```

## Notes

- The icon image is self-contained — no external image files or network requests are required.
- All standard SVG attributes (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread props.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
