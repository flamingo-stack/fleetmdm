A React SVG component that renders the Cherry Studio application icon as a 32×32 inline SVG element containing an embedded base64-encoded PNG image.

## Key Components

- **`CherryStudio`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import CherryStudio from "./CherryStudio";

// Basic usage
<CherryStudio />

// With custom sizing or className
<CherryStudio width={64} height={64} className="app-icon" />

// With style overrides
<CherryStudio style={{ borderRadius: 8 }} />
```

## Notes

- The icon is self-contained — no external image assets are required; the PNG data is embedded as a base64 `data:image/png` string inside an SVG `<image>` element.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- Fully compatible with standard React SVG prop patterns (e.g., `aria-label`, `role`, `onClick`).
