A React SVG component that renders the TeXshop application icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Texshop`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element containing the TeXshop icon as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Texshop from "./Texshop";

// Basic usage
<Texshop />

// With custom dimensions or className
<Texshop width={64} height={64} className="app-icon" />

// With accessibility attributes
<Texshop aria-label="TeXshop" role="img" />
```

## Notes

- The icon image is self-contained — no external assets or network requests are required.
- All props are forwarded to the root `<svg>` element, enabling full SVG attribute customization (e.g., `style`, `className`, `onClick`).
