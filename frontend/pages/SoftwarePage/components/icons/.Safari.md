A React SVG component that renders the Safari browser logo with unique gradient IDs to prevent conflicts when multiple instances are rendered on the same page.

## Key Components

- **`Safari`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props
- **Unique gradient IDs** — Three IDs generated per instance using `lodash.uniqueId` to avoid SVG gradient collisions:
  - `linearGradientAId` — linear gradient for the outer circle fill
  - `radialGradientBId` — radial gradient for the inner circle fill
  - `linearGradientCId` — linear gradient (referenced elsewhere in the full SVG)

## Usage Example

```typescript
import Safari from "./Safari";

// Basic usage
<Safari width={32} height={32} />

// With custom dimensions and className
<Safari width={64} height={64} className="browser-icon" />

// Inherits all SVGProps — style, onClick, aria-label, etc.
<Safari
  width={24}
  height={24}
  aria-label="Safari browser"
  style={{ display: "block" }}
/>
```

## Notes

- The component renders a **32×32** SVG by default (based on the `viewBox`-equivalent path coordinates)
- `uniqueId` from lodash ensures safe reuse — rendering `<Safari />` multiple times on the same page will not cause gradient ID collisions
- All props are forwarded directly to the root `<svg>` element, so standard SVG/HTML attributes (e.g., `className`, `style`, `onClick`) work as expected
