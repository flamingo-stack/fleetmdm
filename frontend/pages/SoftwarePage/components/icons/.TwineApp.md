React SVG icon component that renders the Twine application logo as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TwineApp` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG containing the Twine app icon as an embedded PNG |

## Usage Example

```typescript
import TwineApp from "./TwineApp";

// Basic usage
<TwineApp />

// With custom dimensions or className
<TwineApp width={64} height={64} className="app-icon" />

// With inline styles
<TwineApp style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32px** by default; accepts all standard `SVGProps` for overrides
- The icon is embedded as a **base64 PNG `<image>`** inside the SVG, so no external asset requests are made
- Fully compatible with React's SVG prop system — pass `className`, `style`, `aria-label`, event handlers, etc.
