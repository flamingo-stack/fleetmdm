A React SVG component that renders the Webex logo as a base64-encoded PNG image embedded within an SVG element.

## Key Components

- **`Webex`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Webex brand logo as an inline base64 PNG.

## Usage Example

```typescript
import Webex from "./Webex";

// Basic usage
<Webex />

// With custom dimensions or className
<Webex width={64} height={64} className="icon" />

// With accessibility attributes
<Webex aria-label="Webex" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The logo image is entirely self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
