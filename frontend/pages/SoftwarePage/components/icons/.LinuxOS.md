SVG icon component representing the Linux operating system, used for platform identification in device management interfaces.

## Key Components

- **`LinuxOS`** — Default export. A functional React component that renders a Linux OS icon as an inline SVG, accepting all standard `SVGProps<SVGSVGElement>` attributes.

## Usage Example

```typescript
import LinuxOS from "components/icons/LinuxOS";

// Basic usage
<LinuxOS />

// With custom dimensions and className
<LinuxOS width={24} height={24} className="platform-icon" />

// With custom styling
<LinuxOS style={{ opacity: 0.8 }} aria-label="Linux OS" />
```

## Notes

- Renders at a default `32×32` viewport
- Accepts all native SVG props (e.g., `width`, `height`, `className`, `style`, `aria-*`) via prop spreading
- Icon uses a light background (`#F9FAFC`) with a slate-gray Tux-style figure (`#515774`)
- Typically used alongside sibling OS icons (macOS, Windows) for fleet device platform display in the [FleetMDM UI](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/icons/LinuxOS.tsx)
