A React SVG component that renders the InputSourcePro application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`InputSourcePro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the InputSourcePro app icon as an inline base64 PNG.

## Usage Example

```typescript
import InputSourcePro from "./InputSourcePro";

// Basic usage
<InputSourcePro />

// With custom dimensions or className
<InputSourcePro width={64} height={64} className="app-icon" />

// With accessibility attributes
<InputSourcePro aria-label="InputSourcePro" role="img" />
```

## Notes

- The icon is a **32×32** SVG with a base64-encoded PNG embedded via an `<image>` element.
- All standard `SVGProps` (e.g., `className`, `style`, `width`, `height`, `onClick`) are forwarded to the root `<svg>` element via spread props.
- Overriding `width`/`height` props will resize the SVG container but not the inner image; pass matching values if scaling is needed.
