A React SVG component that renders the "Is There Net?" service logo as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`Istherenet`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Istherenet logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Istherenet from "./Istherenet";

// Basic usage
<Istherenet />

// With custom dimensions and className
<Istherenet width={64} height={64} className="service-icon" />

// With accessibility attributes
<Istherenet aria-label="Istherenet" role="img" />
```

## Notes

- The component renders at **32×32px** by default but can be overridden via props.
- The PNG image data is embedded as a base64 string, so no external asset request is made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Typically used as a service/integration icon within the Flamingo OpenFrame platform's tool catalog.
