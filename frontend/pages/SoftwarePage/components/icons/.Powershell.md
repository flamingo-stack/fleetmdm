React SVG icon component that renders a PowerShell logo as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`Powershell`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the PowerShell logo as an embedded base64-encoded PNG.

## Usage Example

```typescript
import { Powershell } from "./Powershell";

// Basic usage
<Powershell />

// With custom dimensions and className
<Powershell width={24} height={24} className="icon" />

// With accessibility attributes
<Powershell aria-label="PowerShell" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The logo image is self-contained as an inline base64 PNG — no external asset requests required.
