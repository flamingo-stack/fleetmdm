A React SVG component that renders a 32×32 "Processing" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Processing`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Processing from "./Processing";

// Basic usage
<Processing />

// With custom styles
<Processing className="spin-animation" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32×32)
<Processing width={64} height={64} />
```

## Notes

- The icon dimensions default to **32×32 pixels**.
- The visual is delivered as a base64 PNG embedded in an `<image>` element — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via the spread operator.
