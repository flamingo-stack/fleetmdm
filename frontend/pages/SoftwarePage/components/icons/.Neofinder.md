A React SVG component that renders a Neofinder icon as an inline SVG using a base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Neofinder`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element. Renders a 32×32 SVG containing an embedded base64 PNG image.

## Usage Example

```typescript
import Neofinder from "./Neofinder";

// Basic usage
<Neofinder />

// With custom dimensions or className
<Neofinder width={64} height={64} className="app-icon" />

// With accessibility attributes
<Neofinder aria-label="Neofinder" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG, so no external image file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
