SVG icon component that renders a "Secretive" app icon as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`Secretive`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Secretive from "./Secretive";

// Basic usage
<Secretive />

// With custom className or style overrides
<Secretive className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Secretive width={64} height={64} />
```

## Notes

- The component defaults to `32×32` pixels but accepts any valid `SVGProps` to override dimensions, add `className`, `style`, `aria-*` attributes, etc.
- The icon image is fully self-contained — no external asset requests are made at runtime.
- Likely represents the [Secretive](https://github.com/maxgoedjen/secretive) macOS app (a hardware-backed SSH key store), used as an asset within the FleetMDM integration UI.
