React SVG icon component that renders the Free Download Manager application logo as an inline PNG image embedded within an SVG wrapper.

## Key Components

- **`FreeDownloadManager`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing a base64-encoded PNG of the Free Download Manager icon via an `<image>` element.

## Usage Example

```typescript
import FreeDownloadManager from "./FreeDownloadManager";

// Basic usage
<FreeDownloadManager />

// With custom dimensions or className
<FreeDownloadManager width={64} height={64} className="app-icon" />

// With inline styles
<FreeDownloadManager style={{ borderRadius: 4 }} />
```

## Notes

- The icon is rendered at **32×32px** by default; dimensions can be overridden via props.
- The PNG image data is fully self-contained as a base64 string — no external asset requests are made.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
