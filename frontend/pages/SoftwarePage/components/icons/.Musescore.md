A React SVG icon component that renders the MuseScore logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Musescore`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element containing the MuseScore brand icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Musescore from "./Musescore";

// Basic usage
<Musescore />

// With custom dimensions and className
<Musescore width={64} height={64} className="icon" />

// With accessibility attributes
<Musescore aria-label="MuseScore" role="img" />
```

## Notes

- The icon is **32×32px** by default but can be overridden via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The image is self-contained — no external network requests are made at runtime.
