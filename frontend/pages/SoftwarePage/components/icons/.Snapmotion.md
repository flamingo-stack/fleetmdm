A React SVG component that renders the Snapmotion brand icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Snapmotion`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG wrapper around an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import Snapmotion from "./Snapmotion";

// Basic usage
<Snapmotion />

// With custom dimensions or className
<Snapmotion width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Snapmotion aria-label="Snapmotion" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the `SVGProps<SVGSVGElement>` spread.
- The icon is self-contained — no external image dependencies at runtime.
- Default rendered size is `32×32` pixels; override with `width`/`height` props as needed.
