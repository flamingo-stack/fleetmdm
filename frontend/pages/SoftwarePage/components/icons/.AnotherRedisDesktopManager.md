SVG icon component for the Another Redis Desktop Manager application logo, rendering a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`AnotherRedisDesktopManager`** — Default-exported React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the application's icon as an embedded base64 PNG.

## Usage Example

```typescript
import AnotherRedisDesktopManager from "./AnotherRedisDesktopManager";

// Basic usage
<AnotherRedisDesktopManager />

// With custom dimensions and styling
<AnotherRedisDesktopManager
  width={64}
  height={64}
  className="app-icon"
  aria-label="Another Redis Desktop Manager"
/>
```

## Notes

- Default render size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is entirely self-contained as a base64 PNG — no external asset dependencies.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
