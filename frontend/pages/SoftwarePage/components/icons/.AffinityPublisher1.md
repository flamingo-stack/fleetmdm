React SVG component that renders the Affinity Publisher 1 application icon as an inline PNG image embedded via base64 within an SVG wrapper.

## Key Components

- **`AffinityPublisher1`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG of the Affinity Publisher 1 logo.

## Usage Example

```typescript
import AffinityPublisher1 from "./AffinityPublisher1";

// Basic usage
<AffinityPublisher1 />

// With custom dimensions or className
<AffinityPublisher1 width={64} height={64} className="app-icon" />

// With accessibility attributes
<AffinityPublisher1 aria-label="Affinity Publisher 1" role="img" />
```

## Notes

- The component is fully typed via `SVGProps<SVGSVGElement>`, so all standard SVG attributes (e.g., `className`, `style`, `onClick`, `aria-*`) are supported through prop spreading.
- The icon image is self-contained — no external asset files are required at runtime.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
- Likely part of a broader icon library within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository, alongside icons for other applications.
