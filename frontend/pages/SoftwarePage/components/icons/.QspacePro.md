A React SVG component that renders the QspacePro brand icon as a 32×32 inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`QspacePro`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG via a `<image>` tag using a base64 `href`.

## Usage Example

```typescript
import QspacePro from './QspacePro';

// Basic usage
<QspacePro />

// With custom dimensions or styling
<QspacePro width={64} height={64} className="icon" />

// As an inline icon with aria label
<QspacePro aria-label="QspacePro" role="img" />
```

## Notes

- The PNG image data is inlined as a base64 string, so no external image assets are required.
- The component forwards all `SVGProps` to the root `<svg>` element, allowing full customization (size, className, style, event handlers, etc.).
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
