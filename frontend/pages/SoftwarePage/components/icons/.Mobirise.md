A React SVG component that renders the Mobirise logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Mobirise`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Mobirise brand logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Mobirise from "./Mobirise";

// Basic usage
<Mobirise />

// With custom dimensions and className
<Mobirise width={64} height={64} className="logo-icon" />

// With style overrides
<Mobirise style={{ opacity: 0.8 }} aria-label="Mobirise" />
```

## Notes

- The logo image is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element via prop spreading.
