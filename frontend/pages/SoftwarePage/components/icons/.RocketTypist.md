A React SVG wrapper component that renders the RocketTypist icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`RocketTypist`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded directly to the root `<svg>` element.

## Usage Example

```typescript
import RocketTypist from "./RocketTypist";

// Basic usage
<RocketTypist />

// With custom dimensions or className
<RocketTypist width={64} height={64} className="icon" />

// With accessibility attributes
<RocketTypist aria-label="RocketTypist" role="img" />
```

## Notes

- The icon is self-contained — no external image assets required; the PNG is embedded as a base64 `data:` URI inside an `<image>` element.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are supported via prop spreading.
