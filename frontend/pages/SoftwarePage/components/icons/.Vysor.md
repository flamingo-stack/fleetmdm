A React SVG icon component that renders the Vysor logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Vysor`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the Vysor brand icon via an embedded PNG data URI inside an `<svg>` element.

## Usage Example

```typescript
import Vysor from "./Vysor";

// Basic usage
<Vysor />

// With custom dimensions or className
<Vysor width={64} height={64} className="icon" />

// With accessibility attributes
<Vysor aria-label="Vysor" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32px** but can be overridden via `width`/`height` props.
- The image content is a base64-encoded PNG embedded directly in the component — no external image assets are required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
- Typically used as part of an icon library for third-party integrations within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) platform.
