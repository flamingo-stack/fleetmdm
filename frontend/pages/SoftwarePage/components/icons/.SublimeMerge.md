A React component that renders the Sublime Merge application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SublimeMerge`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import SublimeMerge from "./SublimeMerge";

// Basic usage
<SublimeMerge />

// With custom dimensions or className
<SublimeMerge width={64} height={64} className="icon" />

// With inline styles
<SublimeMerge style={{ opacity: 0.8 }} />
```

## Notes

- The icon is self-contained — no external image assets are required; the PNG is embedded as a base64 data URI.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via prop spreading.
- Default rendered size is **32×32 pixels**.
