SVG icon component that renders the Opera browser logo as a base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`Opera`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 Opera browser icon via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Opera from "./Opera";

// Basic usage
<Opera />

// With custom dimensions or className
<Opera width={24} height={24} className="browser-icon" />

// With accessibility attributes
<Opera aria-label="Opera browser" role="img" />
```

## Notes

- Renders at **32×32px** by default; override with `width`/`height` props.
- The icon image is **self-contained** — no external asset requests; the PNG data is inlined as a base64 `data:image/png` URI.
- All standard `SVGProps<SVGSVGElement>` are forwarded to the root `<svg>` element, enabling full styling and attribute control.
