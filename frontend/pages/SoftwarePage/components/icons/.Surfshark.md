A React component that renders the Surfshark VPN brand logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Surfshark`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Surfshark logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Surfshark from "./Surfshark";

// Basic usage
<Surfshark />

// Custom size via width/height props
<Surfshark width={64} height={64} />

// With className or style
<Surfshark className="brand-logo" style={{ opacity: 0.8 }} />
```

## Notes

- Fixed default dimensions: **32×32px**
- The logo image is entirely self-contained as a base64 PNG — no external network requests.
- Accepts all standard SVG props (`className`, `style`, `aria-label`, `onClick`, etc.) via spread.
