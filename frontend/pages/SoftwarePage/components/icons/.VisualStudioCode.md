A React SVG icon component that renders the Visual Studio Code logo as an inline scalable vector graphic.

## Key Components

- **`VisualStudioCode`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full customization of size, className, style, and other SVG attributes.
- **`clipPathId`** — A dynamically generated unique ID (via `lodash.uniqueId`) applied to the SVG `<clipPath>` definition, preventing ID collisions when the icon is rendered multiple times on the same page.

## Usage Example

```typescript
import VisualStudioCode from "./VisualStudioCode";

// Basic usage
<VisualStudioCode width={32} height={32} />

// With custom class and size
<VisualStudioCode
  className="app-icon"
  width={24}
  height={24}
  aria-label="Visual Studio Code"
/>
```

## Notes

- The component renders at a native `32×32` viewport but scales freely via `width`/`height` props.
- All `SVGProps` are spread onto the root `<svg>` element, making it compatible with standard icon patterns (sizing utilities, accessibility attributes, event handlers).
- No external assets or stylesheets are required — the logo is fully self-contained using hardcoded fill colors from the VS Code brand palette (`#2489CA`, `#1070B3`, `#0877B9`, `#3C99D4`).
