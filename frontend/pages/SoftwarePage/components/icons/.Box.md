SVG icon component for the Box logo, rendered as a React component with a blue background and white Box wordmark path.

## Key Components

- **`Box`** — Default export. A functional React component that renders the Box.com brand logo as an inline SVG. Accepts all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Box from "@/components/icons/Box";

// Basic usage
<Box width={32} height={32} />

// With custom dimensions and className
<Box width={24} height={24} className="icon-box" aria-label="Box" />
```

## Notes

- Viewbox defaults to `32x32`
- Fill colors are hardcoded (`#0061D5` background, `#fff` foreground); override via `fill` prop or CSS if needed
- Source: [`Box.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Box.tsx)
