A React SVG icon component that renders the Prism logo as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Prism`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a base64 `<image>` element.

## Usage Example

```typescript
import Prism from "./Prism";

// Basic usage
<Prism />

// With custom dimensions or className
<Prism width={64} height={64} className="icon" />

// With accessibility attributes
<Prism aria-label="Prism logo" role="img" />
```

## Notes

- The icon is self-contained — no external image URLs or additional assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The embedded PNG is 512×512 px (per EXIF metadata), downscaled to 32×32 by the SVG viewport.
