A React SVG component that renders the Netspot brand icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Netspot`** — Default export. A functional React component that wraps a base64-encoded PNG logo inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Netspot from "./Netspot";

// Basic usage
<Netspot />

// With custom dimensions or className
<Netspot width={64} height={64} className="icon" />

// With accessibility attributes
<Netspot aria-label="Netspot" role="img" />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via props.
- The image is self-contained — no external asset file is required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element.
