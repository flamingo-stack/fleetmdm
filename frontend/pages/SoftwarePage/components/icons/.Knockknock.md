A React SVG icon component that renders a "Knockknock" icon using an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Knockknock`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG image.

## Usage Example

```typescript
import Knockknock from "./Knockknock";

// Basic usage
<Knockknock />

// With custom dimensions and className
<Knockknock width={64} height={64} className="icon" />

// With accessibility attributes
<Knockknock aria-label="Knockknock icon" role="img" />
```

## Notes

- The icon renders at a default size of **32×32** pixels but accepts any valid SVG props for customization.
- The image data is fully self-contained as a base64-encoded PNG — no external image assets required.
- All standard SVG props (e.g., `style`, `className`, `onClick`, `width`, `height`) are forwarded via the spread `{...props}` pattern.
