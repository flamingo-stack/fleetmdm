React SVG component that renders the Keycastr application icon as an inline PNG image encoded in base64, wrapped in an SVG container.

## Key Components

- **`Keycastr`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element with an embedded base64-encoded PNG image of the Keycastr logo.

## Usage Example

```typescript
import Keycastr from "./Keycastr";

// Basic usage
<Keycastr />

// With custom dimensions and className
<Keycastr width={64} height={64} className="app-icon" />

// With inline styles
<Keycastr style={{ borderRadius: 4 }} />
```

## Notes

- The component spreads all `SVGProps` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `aria-label`).
- The icon image is embedded as a base64-encoded PNG via an `<image>` element, so no external asset request is made at runtime.
- Default rendered size is **32×32 pixels**.
