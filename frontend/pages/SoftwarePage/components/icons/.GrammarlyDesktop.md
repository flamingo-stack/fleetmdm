React SVG icon component that renders the Grammarly Desktop application logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`GrammarlyDesktop`** — Default exported functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a base64-encoded Grammarly Desktop icon.

## Usage Example

```typescript
import GrammarlyDesktop from "./GrammarlyDesktop";

// Basic usage
<GrammarlyDesktop />

// With custom dimensions and className
<GrammarlyDesktop width={64} height={64} className="app-icon" />

// With accessibility attributes
<GrammarlyDesktop aria-label="Grammarly Desktop" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via props.
- The PNG image data is embedded as a base64 string inside an SVG `<image>` element, so no external image assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
