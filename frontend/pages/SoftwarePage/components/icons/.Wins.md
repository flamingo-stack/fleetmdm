A React SVG icon component that renders a "Wins" trophy/award icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Wins`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG image.

## Usage Example

```typescript
import Wins from './Wins';

// Basic usage
<Wins />

// With custom dimensions or className
<Wins width={64} height={64} className="icon-wins" />

// With click handler
<Wins onClick={() => console.log('wins icon clicked')} />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via props.
- The image data is embedded as a base64-encoded PNG, so no external asset loading is required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
