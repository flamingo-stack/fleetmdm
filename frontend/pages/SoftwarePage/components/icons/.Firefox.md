React SVG wrapper component that renders the Firefox browser logo as a 32×32 pixel PNG embedded via a base64-encoded `<image>` element inside an SVG container.

## Key Components

- **`Firefox`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the outer `<svg>` element.

## Usage Example

```typescript
import Firefox from "./Firefox";

// Basic usage
<Firefox />

// With custom size and className
<Firefox width={64} height={64} className="browser-icon" />

// With click handler
<Firefox onClick={() => console.log("Firefox clicked")} />
```

## Notes

- The icon is a fixed 32×32 base64-encoded PNG rendered inside an SVG shell, so resizing via `width`/`height` props scales the SVG container but not the inner image.
- All standard SVG props (`className`, `style`, `aria-*`, event handlers, etc.) are supported via spread.
