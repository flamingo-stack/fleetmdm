React SVG component that renders the Handbrake application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`HandbrakeApp`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Handbrake app icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import HandbrakeApp from "./HandbrakeApp";

// Basic usage
<HandbrakeApp />

// With custom dimensions or className
<HandbrakeApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<HandbrakeApp aria-label="Handbrake" role="img" />
```

## Notes

- The icon is self-contained — no external image files or network requests are required.
- All `SVGProps` are spread onto the root `<svg>` element, enabling full customization (size, style, event handlers, etc.).
- Default rendered size is **32×32px**; the embedded PNG source is **512×512px**, so scaling up maintains quality.
