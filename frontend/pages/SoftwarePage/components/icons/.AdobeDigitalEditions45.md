A React SVG component that renders the Adobe Digital Editions 4.5 application icon as a 32×32 PNG image embedded via base64 encoding.

## Key Components

- **`AdobeDigitalEditions45`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full SVG attribute customization (e.g., `className`, `style`, `aria-*`).

## Usage Example

```typescript
import AdobeDigitalEditions45 from "./AdobeDigitalEditions45";

// Basic usage
<AdobeDigitalEditions45 />

// With custom dimensions and accessibility label
<AdobeDigitalEditions45
  width={64}
  height={64}
  aria-label="Adobe Digital Editions 4.5"
  role="img"
/>

// With custom styling
<AdobeDigitalEditions45 className="app-icon" style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32** pixels; override via `width`/`height` props.
- The icon image is self-contained as a base64-encoded PNG inside an SVG `<image>` element — no external assets or network requests required.
