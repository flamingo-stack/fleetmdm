SVG icon component that renders the Keyboard Maestro application logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`KeyboardMaestro`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Keyboard Maestro icon as an embedded PNG image.

## Usage Example

```typescript
import KeyboardMaestro from "./KeyboardMaestro";

// Basic usage
<KeyboardMaestro />

// With custom dimensions or className
<KeyboardMaestro width={64} height={64} className="icon" />
```

## Notes

- The icon is a static asset; no dynamic rendering logic is involved.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread.
- The embedded PNG is 512×512 source resolution, downscaled to 32×32 display size.
