A React SVG component that renders the Audiveris logo as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Audiveris`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Audiveris from "./Audiveris";

// Basic usage
<Audiveris />

// With custom size and style
<Audiveris width={64} height={64} className="logo-icon" />

// With event handler
<Audiveris onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The logo image is self-contained via a base64-encoded PNG `href` — no external assets or network requests required.
- Default dimensions are `32×32` pixels but can be overridden via props.
