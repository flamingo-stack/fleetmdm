React SVG component that renders the LogiTune application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`LogiTune`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props. Renders a 32×32 SVG containing an embedded PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import LogiTune from "./LogiTune";

// Basic usage
<LogiTune />

// With custom dimensions or className
<LogiTune width={64} height={64} className="app-icon" />

// With accessibility attributes
<LogiTune aria-label="LogiTune" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required at runtime.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via the spread `{...props}`, making the component flexible for use in icon systems or UI toolkits.
- Default render size is **32×32px**; the embedded PNG source is 1024×1024px (per embedded EXIF metadata), so the icon scales well at larger sizes.
