A React SVG component that renders the GOG Galaxy logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`GogGalaxy`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).
- The icon image is embedded as a base64-encoded PNG within an SVG `<image>` element, requiring no external asset files.

## Usage Example

```typescript
import GogGalaxy from "./GogGalaxy";

// Basic usage
<GogGalaxy />

// With custom size and className
<GogGalaxy width={64} height={64} className="app-icon" />

// With style overrides
<GogGalaxy style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- The PNG image data is self-contained (base64), so no additional assets or CDN dependencies are needed.
- Compatible with any React project using standard SVG rendering.
