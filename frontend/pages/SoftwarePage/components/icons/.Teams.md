SVG icon component rendering the Microsoft Teams logo with gradient fills and layered transparency effects.

## Key Components

- **`Teams`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 Microsoft Teams logo SVG.
- **`linearGradientId`** — A `lodash` `uniqueId`-generated ID scoped to each instance, preventing `<linearGradient>` `id` collisions when multiple `Teams` icons are rendered on the same page.

## Usage Example

```typescript
import Teams from "./Teams";

// Basic usage
<Teams />

// With custom dimensions and className
<Teams width={24} height={24} className="teams-icon" />

// Inline style override
<Teams style={{ display: "block", margin: "0 auto" }} />
```

## Notes

- All standard SVG props (`width`, `height`, `className`, `style`, `aria-label`, etc.) are forwarded via spread (`{...props}`).
- The component does **not** set a default `width`/`height` — size must be controlled externally or via CSS.
- The gradient uses three color stops (`#5A62C3` → `#4D55BD` → `#3940AB`) to replicate the Teams brand blue.
