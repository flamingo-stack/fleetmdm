React SVG icon component that renders a PostgreSQL 15 logo as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Postgresql15`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 `<svg>` containing the PostgreSQL elephant logo as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Postgresql15 from './Postgresql15';

// Basic usage
<Postgresql15 />

// With custom dimensions and class
<Postgresql15 width={64} height={64} className="db-icon" />

// With accessibility attributes
<Postgresql15 aria-label="PostgreSQL 15" role="img" />
```

## Notes

- The logo is embedded as a base64 `data:image/png` URI directly in the SVG, so no external asset requests are made at runtime.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread (`{...props}`), making the component fully composable.
- Default rendered size is **32×32** but can be overridden by passing `width`/`height` props.
