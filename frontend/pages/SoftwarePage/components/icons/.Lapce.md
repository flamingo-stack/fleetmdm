A React SVG component that renders the Lapce editor icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Lapce`** — Default export. A functional React component that renders an SVG wrapper containing the Lapce logo as an inline base64 PNG image.

## Usage Example

```typescript
import Lapce from "./Lapce";

// Basic usage
const App = () => <Lapce />;

// With custom dimensions or styling
const App = () => (
  <Lapce
    width={64}
    height={64}
    className="editor-icon"
    aria-label="Lapce editor"
  />
);
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The icon image is fully self-contained via a base64-encoded PNG — no external image assets required.
- Default render size is **32×32px**.
