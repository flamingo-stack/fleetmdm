A React SVG component that renders the Fastscripts app icon as an inline base64-encoded PNG image (32×32px).

## Key Components

- **`Fastscripts`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG icon via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Fastscripts from "./Fastscripts";

// Basic usage
<Fastscripts />

// With custom size or className
<Fastscripts width={64} height={64} className="app-icon" />

// With accessibility attributes
<Fastscripts aria-label="Fastscripts" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread, making the component fully customizable.
- The icon is self-contained — no external image assets or network requests required.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
