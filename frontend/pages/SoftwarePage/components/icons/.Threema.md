A React component that renders the Threema messaging app icon as an SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Threema`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Threema from "./Threema";

// Basic usage
<Threema />

// With custom dimensions or className
<Threema width={64} height={64} className="icon" />

// With style overrides
<Threema style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered via an `<image>` tag inside SVG, embedding the Threema logo as a base64 PNG (`32×32` native resolution).
- All SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are spread onto the outer `<svg>` element, making the component flexible for layout and accessibility needs.
