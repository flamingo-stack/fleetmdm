React SVG icon component that renders the Mac Mouse Fix application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`MacMouseFix`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import MacMouseFix from "./MacMouseFix";

// Basic usage
<MacMouseFix />

// With custom dimensions or className
<MacMouseFix width={64} height={64} className="app-icon" />

// With accessibility attributes
<MacMouseFix aria-label="Mac Mouse Fix" role="img" />
```

## Notes

- The PNG image data is fully self-contained — no external asset fetches required.
- All props are forwarded to the root `<svg>` element, enabling style, className, event handlers, and ARIA attributes.
- Default rendered size is **32×32px**; override via `width`/`height` props.
