SVG icon component that renders the Notion logo as a React component using an embedded base64-encoded PNG image.

## Key Components

- **`Notion`** — Default export. A functional React component that accepts all standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 Notion logo icon via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Notion from "./Notion";

// Basic usage
<Notion />

// With custom size and className
<Notion width={64} height={64} className="icon" />

// With accessibility attributes
<Notion aria-label="Notion" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The logo image is fully self-contained as a base64-encoded PNG — no external asset dependencies.
- Defined at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — search the repo for the exact file path.
