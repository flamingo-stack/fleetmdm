A React SVG component that renders the OneSwitch brand logo as an inline SVG element containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`OneSwitch`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 `<svg>` with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { OneSwitch } from "./OneSwitch";

// Basic usage
<OneSwitch />

// With custom dimensions or className
<OneSwitch width={64} height={64} className="vendor-icon" />

// With accessible title via aria attributes
<OneSwitch aria-label="OneSwitch" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread to the root `<svg>` element.
- The icon dimensions default to `32×32`; override with `width`/`height` props.
- The PNG data is fully self-contained — no external image fetch is required at runtime.
