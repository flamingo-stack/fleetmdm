React SVG component that renders the Amazon Corretto 25 logo as a 32×32 PNG image embedded via a base64-encoded data URI.

## Key Components

- **`AmazonCorretto25`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, which allows consumers to pass any valid SVG attribute (e.g., `className`, `style`, `onClick`).
- **Embedded PNG** — The logo is inlined as a base64 data URI within an `<image>` element, eliminating any external asset dependency.

## Usage Example

```typescript
import AmazonCorretto25 from "./AmazonCorretto25";

// Basic usage
<AmazonCorretto25 />

// With custom size and class
<AmazonCorretto25 width={64} height={64} className="my-icon" />

// With click handler
<AmazonCorretto25 onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- No external assets or network requests — safe for offline/airgapped environments.
- Part of the icon library in [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
