A React SVG component that renders the Thorium browser logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Thorium`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Thorium browser icon as an embedded PNG image.

## Usage Example

```typescript
import Thorium from "./Thorium";

// Basic usage
<Thorium />

// With custom dimensions or className
<Thorium width={64} height={64} className="browser-icon" />

// With style overrides
<Thorium style={{ opacity: 0.8 }} />
```

## Notes

- The icon is a **32×32** SVG by default; dimensions can be overridden via props.
- The image data is embedded as a base64-encoded PNG, so no external asset requests are made at runtime.
- All standard `SVGProps<SVGSVGElement>` attributes (`className`, `style`, `aria-*`, `onClick`, etc.) are forwarded to the root `<svg>` element.
