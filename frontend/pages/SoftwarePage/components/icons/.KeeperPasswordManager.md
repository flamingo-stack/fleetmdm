SVG icon component for the Keeper Password Manager brand logo, rendered as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`KeeperPasswordManager`** — Default export. A React functional component that renders a 32×32 SVG icon using an embedded base64 PNG image of the Keeper Password Manager logo.

## Usage Example

```typescript
import KeeperPasswordManager from "./KeeperPasswordManager";

// Basic usage
<KeeperPasswordManager />

// With custom dimensions or styling
<KeeperPasswordManager width={64} height={64} className="icon" />

// With accessibility attributes
<KeeperPasswordManager aria-label="Keeper Password Manager" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/common) props, enabling full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`).
- Default dimensions are `32×32` pixels.
- The icon image is self-contained via a base64-encoded PNG — no external asset dependencies.
