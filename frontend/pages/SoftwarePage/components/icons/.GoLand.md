React SVG component that renders the GoLand IDE logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`GoLand`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the GoLand logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import GoLand from "./GoLand";

// Basic usage
<GoLand />

// With custom dimensions or className
<GoLand width={64} height={64} className="icon" />

// With aria label for accessibility
<GoLand aria-label="GoLand IDE" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props are forwarded via spread (`{...props}`), allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-*`).
- The logo is embedded as a base64 PNG rather than pure SVG paths, so it will not inherit CSS `fill`/`color` overrides.
- Default dimensions are `32×32` pixels; override with `width` and `height` props as needed.
