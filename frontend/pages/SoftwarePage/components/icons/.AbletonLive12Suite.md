React SVG icon component that renders the Ableton Live 12 Suite application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`AbletonLive12Suite`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Ableton Live 12 Suite icon via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import AbletonLive12Suite from "./AbletonLive12Suite";

// Basic usage
<AbletonLive12Suite />

// With custom size and className
<AbletonLive12Suite width={64} height={64} className="app-icon" />

// With accessibility attributes
<AbletonLive12Suite
  aria-label="Ableton Live 12 Suite"
  role="img"
/>
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread.
