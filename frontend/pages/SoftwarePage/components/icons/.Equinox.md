React SVG icon component that renders the Equinox logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Equinox`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG logo via an `<image>` element.

## Usage Example

```typescript
import Equinox from "./Equinox";

// Basic usage
<Equinox />

// With custom dimensions or className
<Equinox width={64} height={64} className="my-icon" />

// With style overrides
<Equinox style={{ opacity: 0.8 }} />
```

## Notes

- The component renders at **32×32px** by default but can be overridden via `width`/`height` props.
- The icon image is a **512×512 PNG** embedded as a base64 data URI, scaled down to the SVG viewport.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
