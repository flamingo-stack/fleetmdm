A React SVG icon component that renders a 32×32 "Forecast" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Forecast`** — Default export; a functional React component that wraps an `<svg>` element containing an inlined PNG via a base64 `data:image/png` URI.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass `className`, `style`, `onClick`, and other SVG attributes.

## Usage Example

```typescript
import Forecast from "./Forecast";

// Basic usage
<Forecast />

// With custom dimensions and className
<Forecast width={64} height={64} className="icon-forecast" />

// With event handler
<Forecast onClick={() => console.log("Forecast icon clicked")} />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The image data is fully self-contained (no external asset fetches at runtime).
