React SVG component that renders the SoundSiphon application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SoundSiphon`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG wrapper around an embedded PNG icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import SoundSiphon from "./SoundSiphon";

// Basic usage
<SoundSiphon />

// With custom dimensions or className
<SoundSiphon width={64} height={64} className="app-icon" />

// With accessibility attributes
<SoundSiphon aria-label="SoundSiphon" role="img" />
```

## Notes

- The icon image is self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
