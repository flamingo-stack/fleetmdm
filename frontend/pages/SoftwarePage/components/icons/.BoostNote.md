A React SVG component that renders the BoostNote application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`BoostNote`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image of the BoostNote logo.

## Usage Example

```typescript
import BoostNote from "./BoostNote";

// Basic usage
<BoostNote />

// With custom dimensions or className
<BoostNote width={64} height={64} className="icon" />

// With accessibility attributes
<BoostNote aria-label="BoostNote" role="img" />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG `href` on the inner `<image>` element — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}` pattern.
- Default rendered size is `32×32` pixels; override with `width`/`height` props as needed.
