React SVG icon component that renders the OpenVPN Connect application logo as a 32×32 PNG embedded within an SVG wrapper.

## Key Components

- **`OpenvpnConnect`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).
- The icon uses an inline base64-encoded PNG via an SVG `<image>` element, rendered at 32×32 pixels.

## Usage Example

```typescript
import OpenvpnConnect from "./OpenvpnConnect";

// Basic usage
<OpenvpnConnect />

// With custom size and class
<OpenvpnConnect width={64} height={64} className="app-icon" />

// With click handler
<OpenvpnConnect onClick={() => console.log("OpenVPN Connect clicked")} />
```

## Notes

- All props are spread onto the root `<svg>` element, so standard SVG/HTML attributes like `aria-label`, `role`, and event handlers work as expected.
- The icon is self-contained — no external image assets or network requests required.
- Default dimensions are `32×32`; override with `width`/`height` props as needed.
