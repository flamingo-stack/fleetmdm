A React SVG component that renders the Duet icon as a 32×32 inline SVG wrapping a base64-encoded PNG image.

## Key Components

- **`Duet`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Duet from "./Duet";

// Basic usage
<Duet />

// With custom dimensions or className
<Duet width={64} height={64} className="icon" />

// With style overrides
<Duet style={{ opacity: 0.8 }} aria-label="Duet" />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default, overridable via props.
- The visual content is a base64-encoded PNG embedded via an `<image>` tag — no external assets required.
- Fully compatible with standard SVG accessibility and styling patterns (`aria-*`, `className`, `style`, etc.).
