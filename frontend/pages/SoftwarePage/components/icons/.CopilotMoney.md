A React SVG component that renders the Copilot Money app icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`CopilotMoney`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element containing a base64-encoded PNG of the Copilot Money logo.

## Usage Example

```typescript
import CopilotMoney from "./CopilotMoney";

// Basic usage
<CopilotMoney />

// With custom dimensions or className
<CopilotMoney width={64} height={64} className="app-icon" />

// With accessibility attributes
<CopilotMoney aria-label="Copilot Money" role="img" />
```

## Notes

- The icon image is self-contained — no external image assets or network requests required at runtime.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via the spread `{...props}`.
- The embedded PNG is 512×512 px source resolution, downscaled to 32×32 by the SVG viewport — pass larger `width`/`height` values if a higher-resolution render is needed.
