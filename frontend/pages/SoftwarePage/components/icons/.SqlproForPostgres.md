A React SVG component that renders the SQLPro for Postgres application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`SqlproForPostgres`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the SQLPro for Postgres icon via an embedded PNG data URI.

## Usage Example

```typescript
import SqlproForPostgres from "./SqlproForPostgres";

// Basic usage
<SqlproForPostgres />

// With custom dimensions and className
<SqlproForPostgres width={64} height={64} className="app-icon" />

// With accessibility attributes
<SqlproForPostgres
  role="img"
  aria-label="SQLPro for Postgres"
  style={{ borderRadius: 4 }}
/>
```

## Notes

- The icon image is fully self-contained — no external asset requests are made at runtime.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via the spread `{...props}` pattern.
