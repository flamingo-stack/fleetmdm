A React SVG icon component that renders the StandardNotes application logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`StandardNotes`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import StandardNotes from "./StandardNotes";

// Basic usage
<StandardNotes />

// With custom dimensions or className
<StandardNotes width={64} height={64} className="icon" />

// With accessibility attributes
<StandardNotes aria-label="StandardNotes" role="img" />
```

## Notes

- The icon is fixed at a base size of `32×32` but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 `data:image/png` URI — no external asset fetch required.
