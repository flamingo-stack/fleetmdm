React SVG icon component that renders a UTM (Unified Threat Management) icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Utm`** — Default export. A functional React component that wraps a 32×32 SVG element containing an embedded PNG via a base64 `href` on an `<image>` tag.
- **`SVGProps<SVGSVGElement>`** — All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Utm from "./Utm";

// Basic usage
<Utm />

// With custom size override
<Utm width={64} height={64} />

// With className or style
<Utm className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is self-contained — no external asset requests at runtime.
- Overriding `width`/`height` via props scales the SVG container but not the internal `<image>` element (fixed at 32×32).
