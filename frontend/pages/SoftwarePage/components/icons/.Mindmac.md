A React SVG component that renders the Mindmac application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Mindmac`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG wrapper around an inline base64 PNG image.

## Usage Example

```typescript
import Mindmac from "./Mindmac";

// Basic usage
<Mindmac />

// With custom dimensions or className
<Mindmac width={64} height={64} className="app-icon" />

// With accessibility attributes
<Mindmac aria-label="Mindmac" role="img" />
```

## Notes

- The icon image is fully self-contained — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Part of the FleetMDM icon set. See related icon components at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
