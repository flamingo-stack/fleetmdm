React SVG component that renders the Elgato Wave Link application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`ElgatoWaveLink`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Elgato Wave Link icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import ElgatoWaveLink from "./ElgatoWaveLink";

// Basic usage
<ElgatoWaveLink />

// With custom dimensions or className
<ElgatoWaveLink width={64} height={64} className="app-icon" />
```

## Notes

- Default size is **32×32px**; override via `width`/`height` props.
- The icon is fully self-contained — no external image assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
