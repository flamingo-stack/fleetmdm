A React SVG icon component that renders the Numi logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Numi`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG wrapper around the embedded Numi logo image.

## Usage Example

```typescript
import Numi from "./Numi";

// Basic usage
<Numi />

// With custom className or style
<Numi className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions via props
<Numi width={64} height={64} />
```

## Notes

- The logo image is embedded as a base64 PNG (`data:image/png;base64,...`), so no external image file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread (`{...props}`).
