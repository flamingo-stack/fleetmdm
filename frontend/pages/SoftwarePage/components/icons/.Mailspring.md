React SVG icon component that renders the Mailspring email client logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Mailspring`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing the Mailspring logo as an embedded base64 PNG.

## Usage Example

```typescript
import Mailspring from "./Mailspring";

// Basic usage
<Mailspring />

// With custom dimensions or className
<Mailspring width={64} height={64} className="app-icon" />

// With accessibility attributes
<Mailspring aria-label="Mailspring" role="img" />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo is embedded as a **base64-encoded PNG** inside an `<image>` element, making the component self-contained with no external asset dependency.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via prop spreading.
