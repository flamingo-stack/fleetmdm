SVG icon component that renders the "Privileges" icon as a base64-encoded PNG embedded in an SVG wrapper.

## Key Components

- **`Privileges`** — Default export; a React functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a base64-encoded `<image>` element.

## Usage Example

```typescript
import Privileges from "./Privileges";

// Basic usage
<Privileges />

// With custom sizing and className
<Privileges width={24} height={24} className="icon-privileges" />

// With accessibility attributes
<Privileges aria-label="Privileges" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image data is self-contained (base64 PNG), requiring no external asset references.
- Fully compatible with any project using React and standard SVG prop forwarding.
