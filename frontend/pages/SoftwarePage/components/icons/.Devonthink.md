A React SVG component that renders the DEVONthink application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Devonthink`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the DEVONthink app icon as a base64-embedded PNG.

## Usage Example

```typescript
import Devonthink from "./Devonthink";

// Basic usage
<Devonthink />

// With custom sizing or className
<Devonthink width={64} height={64} className="app-icon" />

// With style overrides
<Devonthink style={{ opacity: 0.8 }} aria-label="DEVONthink" />
```

## Notes

- The icon image is self-contained — no external image assets or network requests required.
- All `SVGProps<SVGSVGElement>` props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
