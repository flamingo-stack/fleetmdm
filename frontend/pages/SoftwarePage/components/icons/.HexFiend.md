A React SVG icon component that renders the HexFiend application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`HexFiend`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the HexFiend app icon as a 32×32 SVG element with an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import HexFiend from './HexFiend';

// Basic usage
const MyComponent = () => (
  <HexFiend />
);

// With custom size and className
const CustomIcon = () => (
  <HexFiend
    width={64}
    height={64}
    className="app-icon"
    aria-label="HexFiend"
  />
);
```

## Notes

- The component uses a base64-encoded PNG embedded directly in the SVG via an `<image>` element, making it self-contained with no external asset dependencies.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element.
