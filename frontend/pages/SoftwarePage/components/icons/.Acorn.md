A React SVG icon component that renders an Acorn image as a 32×32 SVG element with an embedded base64-encoded PNG.

## Key Components

- **`Acorn`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Acorn from "./Acorn";

// Basic usage
<Acorn />

// With custom size and class
<Acorn width={64} height={64} className="icon" />

// With event handler
<Acorn onClick={() => console.log("clicked")} />
```

## Notes

- The icon is a fixed 32×32 PNG image embedded as a base64 data URI inside an `<image>` element.
- Overriding `width`/`height` via props resizes the SVG viewport but not the internal image element (which is hardcoded to 32×32).
