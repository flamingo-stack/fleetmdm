A React SVG component that renders the Nextcloud logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Nextcloud`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Nextcloud brand icon.

## Usage Example

```typescript
import Nextcloud from "./Nextcloud";

// Basic usage
<Nextcloud />

// With custom dimensions or className
<Nextcloud width={64} height={64} className="icon" />

// With accessibility attributes
<Nextcloud aria-label="Nextcloud" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image data is embedded as a base64 PNG — no external network requests or asset imports required.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via prop spreading.
