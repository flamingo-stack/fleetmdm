SVG icon component that renders the RStudio logo as a Base64-encoded PNG embedded within an SVG element at 32×32 pixels.

## Key Components

- **`Rstudio`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full customization of the underlying `<svg>` element (e.g., `className`, `style`, `aria-*`).

## Usage Example

```typescript
import Rstudio from "./Rstudio";

// Basic usage
<Rstudio />

// With custom size and styling
<Rstudio width={64} height={64} className="icon" />

// With accessibility attributes
<Rstudio aria-label="RStudio" role="img" />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The icon image is embedded as a Base64 PNG inside an `<image>` element — no external asset fetch required.
