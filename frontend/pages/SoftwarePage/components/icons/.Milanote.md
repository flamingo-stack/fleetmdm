A React SVG component that renders the Milanote logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Milanote`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarding them to the root `<svg>` element.

## Usage Example

```typescript
import Milanote from "./Milanote";

// Basic usage
<Milanote />

// With custom dimensions or className
<Milanote width={64} height={64} className="icon" />

// With inline styles
<Milanote style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered at 32×32 by default but accepts any valid SVG props for overriding dimensions, styles, or event handlers.
- The logo image is inlined as a base64 PNG, so no external assets or network requests are required.
