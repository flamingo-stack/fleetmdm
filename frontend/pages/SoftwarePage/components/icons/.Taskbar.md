A React SVG icon component that renders a Taskbar icon using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Taskbar`** — A functional React component that wraps a 32×32 SVG element containing an inline base64 PNG image, accepting all standard SVG props via `SVGProps<SVGSVGElement>`.

## Usage Example

```typescript
import { Taskbar } from './Taskbar';

// Basic usage
<Taskbar />

// With custom dimensions or class
<Taskbar width={64} height={64} className="icon" />

// With onClick handler
<Taskbar onClick={() => console.log('clicked')} />
```

## Notes

- The icon image is embedded as a base64-encoded PNG, so no external asset loading is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded to the root `<svg>` element.
- Default render size is **32×32** pixels; override via `width`/`height` props.
