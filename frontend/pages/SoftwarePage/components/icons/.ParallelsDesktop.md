SVG icon component that renders the Parallels Desktop logo as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`ParallelsDesktop`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Parallels Desktop logo as an inline base64 PNG.

## Usage Example

```typescript
import ParallelsDesktop from "./ParallelsDesktop";

// Basic usage
<ParallelsDesktop />

// With custom dimensions and className
<ParallelsDesktop width={64} height={64} className="icon" />

// With accessibility attributes
<ParallelsDesktop aria-label="Parallels Desktop" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image data is embedded as a **base64 PNG**, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
