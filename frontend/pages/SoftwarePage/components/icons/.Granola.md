A React SVG component that renders the Granola application logo as a 32×32 pixel icon with an embedded base64-encoded PNG image.

## Key Components

- **`Granola`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering an `<svg>` element with an embedded PNG via a base64 `data:` URI.

## Usage Example

```typescript
import Granola from "./Granola";

// Basic usage
<Granola />

// With custom dimensions or className
<Granola width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Granola aria-label="Granola" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via `width`/`height` props.
- The PNG image data is fully self-contained — no external image assets or network requests required.
- Passes through all standard SVG props (e.g., `className`, `style`, `onClick`) via spread.
