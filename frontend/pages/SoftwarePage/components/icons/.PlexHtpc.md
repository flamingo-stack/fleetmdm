A React SVG component that renders the Plex HTPC application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`PlexHtpc`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Plex HTPC logo via an inline base64 PNG within an SVG wrapper.

## Usage Example

```typescript
import PlexHtpc from "./PlexHtpc";

// Basic usage
<PlexHtpc />

// With custom props
<PlexHtpc className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32×32)
<PlexHtpc width={64} height={64} />
```

## Notes

- The icon is fixed at 32×32 by default but can be overridden via `width`/`height` props.
- The image data is self-contained (no external asset dependencies).
