React SVG icon component that renders the Proxifier application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Proxifier`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Proxifier logo as an embedded PNG image.

## Usage Example

```typescript
import Proxifier from "./Proxifier";

// Basic usage
<Proxifier />

// With custom size and className
<Proxifier width={64} height={64} className="app-icon" />

// With accessibility attributes
<Proxifier aria-label="Proxifier" role="img" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The image data is inlined as a base64 PNG, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
