React SVG component that renders the YouTube Music logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`YtMusic`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the YouTube Music brand icon as an embedded PNG via a `data:image/png;base64` `href`.

## Usage Example

```typescript
import YtMusic from "./YtMusic";

// Basic usage
<YtMusic />

// With custom size and className
<YtMusic width={64} height={64} className="icon" />

// With accessibility attributes
<YtMusic aria-label="YouTube Music" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- All `SVGProps` are spread onto the root `<svg>` element, allowing full control over styling, event handlers, and ARIA attributes.
- The PNG image data is self-contained — no external network request is made.
