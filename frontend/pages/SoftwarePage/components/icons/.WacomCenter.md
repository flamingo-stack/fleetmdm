A React component that renders the Wacom Center application icon as an SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`WacomCenter`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Wacom Center icon as an inline base64 PNG.

## Usage Example

```typescript
import WacomCenter from "./WacomCenter";

// Basic usage
<WacomCenter />

// With custom dimensions and className
<WacomCenter width={64} height={64} className="app-icon" />

// With accessibility attributes
<WacomCenter aria-label="Wacom Center" role="img" />
```

## Notes

- The icon image is fully self-contained via a base64-encoded PNG `href` on an SVG `<image>` element — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is `32×32`px but can be overridden via `width`/`height` props.
