A React SVG component that renders the NAPS2 (Not Another PDF Scanner) application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Naps2`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 `<svg>` element containing an embedded PNG via a base64 `href` on an `<image>` tag.

## Usage Example

```typescript
import Naps2 from "./Naps2";

// Basic usage
<Naps2 />

// With custom size or class
<Naps2 width={64} height={64} className="app-icon" />

// With accessibility attributes
<Naps2 aria-label="NAPS2 Scanner" role="img" />
```

## Notes

- The icon image is entirely self-contained — no external asset fetches required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
