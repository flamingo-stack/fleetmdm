A React SVG component that renders the Amadeus Pro application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`AmadeusPro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Amadeus Pro icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import AmadeusPro from './AmadeusPro';

// Basic usage
<AmadeusPro />

// With custom dimensions or className
<AmadeusPro width={64} height={64} className="app-icon" />

// With accessibility attributes
<AmadeusPro aria-label="Amadeus Pro" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required at runtime.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- Default rendered size is **32×32px**; override via `width`/`height` props.
