A React SVG component that renders the Azul Zulu 25 JRE (Java Runtime Environment) icon as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`AzulZulu25Jre`** — Default export; a functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) and rendering the Azul Zulu 25 JRE logo.

## Usage Example

```typescript
import AzulZulu25Jre from "./AzulZulu25Jre";

// Basic usage
<AzulZulu25Jre />

// With custom dimensions or className
<AzulZulu25Jre width={64} height={64} className="icon" />
```

## Notes

- The icon defaults to `32×32` pixels but accepts any valid `SVGProps` for overrides.
- The image data is self-contained (base64 PNG), requiring no external asset fetching.
