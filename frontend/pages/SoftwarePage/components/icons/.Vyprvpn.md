A React SVG icon component that renders the VyprVPN logo as a 32×32 inline PNG embedded via base64 data URI.

## Key Components

- **`Vyprvpn`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Vyprvpn from "./Vyprvpn";

// Basic usage
<Vyprvpn />

// With custom dimensions or className
<Vyprvpn width={64} height={64} className="icon" />

// With style overrides
<Vyprvpn style={{ opacity: 0.8 }} aria-label="VyprVPN" />
```

## Notes

- Fixed default size of `32×32` pixels; override via `width`/`height` props.
- The logo image is embedded as a base64 PNG — no external asset fetch required.
- All `SVGProps` (e.g., `className`, `style`, `aria-*`) are passed through to the `<svg>` element.
