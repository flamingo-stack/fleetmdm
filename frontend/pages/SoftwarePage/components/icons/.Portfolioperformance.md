A React SVG component that renders a **Portfolio Performance** icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Portfolioperformance`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- **Embedded image** — The icon graphic is stored as a base64 PNG data URI inside an SVG `<image>` tag, making the component fully self-contained with no external asset dependencies.

## Usage Example

```typescript
import Portfolioperformance from "./Portfolioperformance";

// Basic usage
<Portfolioperformance />

// With custom size and className
<Portfolioperformance width={64} height={64} className="icon" />

// With accessibility attributes
<Portfolioperformance
  aria-label="Portfolio Performance"
  role="img"
  style={{ display: "block" }}
/>
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` attributes (e.g., `className`, `style`, `onClick`, `aria-*`) are passed through via spread (`{...props}`).
- No runtime dependencies beyond React.
