A React SVG component that renders the IINA media player application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Iina`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing the IINA app icon as a base64-encoded PNG via an `<image>` element.

## Usage Example

```typescript
import Iina from "./Iina";

// Basic usage
<Iina />

// With custom dimensions and className
<Iina width={64} height={64} className="app-icon" />

// With accessibility attributes
<Iina aria-label="IINA Media Player" role="img" />
```

## Notes

- The icon data is fully self-contained — no external image assets are required.
- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default size is **32×32px**; override with `width`/`height` props as needed.
