SVG React component that renders the Vernier Spectral Analysis application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`VernierSpectralAnalysis`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import VernierSpectralAnalysis from "./VernierSpectralAnalysis";

// Basic usage
<VernierSpectralAnalysis />

// With custom size and className
<VernierSpectralAnalysis width={64} height={64} className="icon" />

// With ARIA label for accessibility
<VernierSpectralAnalysis aria-label="Vernier Spectral Analysis" role="img" />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, making it fully customizable (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The icon image is self-contained as a base64 PNG — no external asset files required.
- Default render size is **32×32 pixels**; the embedded PNG source resolution is 512×512 (sRGB color space per EXIF metadata).
