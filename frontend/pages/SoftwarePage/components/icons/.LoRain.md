A React SVG component that renders a "light rain" weather icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`LoRain`** — Default export. A functional React component that wraps a 32×32 `<svg>` element containing a single `<image>` tag with a base64-encoded PNG of a low-rain weather icon.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the underlying `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import LoRain from "./LoRain";

// Basic usage
<LoRain />

// With custom size and class
<LoRain width={64} height={64} className="weather-icon" />

// With inline style
<LoRain style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is entirely self-contained via a base64 PNG data URI — no external assets or network requests required.
- The component does not manage any internal state and is safe for use in server-side rendering (SSR) environments.
- Default rendered size is **32×32px**; override via `width`/`height` props.
