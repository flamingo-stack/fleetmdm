A React SVG component that renders the Fleet MDM "Display Link Manager" icon as an inline SVG containing a base64-encoded PNG image (32×32px).

## Key Components

- **`DisplayLinkManager`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import DisplayLinkManager from "./DisplayLinkManager";

// Basic usage
<DisplayLinkManager />

// With custom size and className
<DisplayLinkManager width={64} height={64} className="icon" />

// With accessibility attributes
<DisplayLinkManager aria-label="Display Link Manager" role="img" />
```

## Notes

- The component renders at **32×32px** by default but can be overridden via props.
- The visual content is a base64-encoded PNG embedded via an `<image>` element — no external asset requests are needed.
- Spread props (`{...props}`) allow full customization of the SVG (e.g., `style`, `className`, `onClick`, `aria-*`).
