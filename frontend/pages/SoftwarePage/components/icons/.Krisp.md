A React SVG component that renders the Krisp logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Krisp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64 PNG image of the Krisp brand logo.

## Usage Example

```typescript
import Krisp from "./Krisp";

// Basic usage
<Krisp />

// With custom dimensions or className
<Krisp width={64} height={64} className="logo-icon" />

// With style overrides
<Krisp style={{ opacity: 0.8 }} aria-label="Krisp logo" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external network requests are made at render time.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
