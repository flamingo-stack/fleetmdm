A React SVG component that renders the Far2L application icon as an inline PNG image (32×32px) embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Far2L`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Far2L from "./Far2L";

// Basic usage
<Far2L />

// With custom size and className
<Far2L width={64} height={64} className="app-icon" />

// With click handler
<Far2L onClick={() => console.log("Far2L icon clicked")} />
```

## Notes

- The icon renders at **32×32px** by default (overridable via props).
- The image data is fully self-contained — no external asset loading required.
- All standard SVG props (e.g., `aria-label`, `role`, `style`) are forwarded to the root element, making it accessible and composable.
