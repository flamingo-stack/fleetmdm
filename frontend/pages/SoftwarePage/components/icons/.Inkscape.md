A React SVG component that renders the Inkscape application icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Inkscape`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Inkscape logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Inkscape from "./Inkscape";

// Basic usage
<Inkscape />

// With custom dimensions and className
<Inkscape width={64} height={64} className="app-icon" />

// With style overrides
<Inkscape style={{ opacity: 0.8 }} aria-label="Inkscape" />
```

## Notes

- All props are forwarded directly to the underlying `<svg>` element, enabling full customization (size, class, style, accessibility attributes, event handlers).
- The icon image is self-contained — no external assets or network requests are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
