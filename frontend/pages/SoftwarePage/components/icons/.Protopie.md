A React SVG component that renders the Protopie logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`Protopie`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Protopie brand icon as an embedded base64 PNG.

## Usage Example

```typescript
import Protopie from "./Protopie";

// Basic usage
<Protopie />

// With custom dimensions or className
<Protopie width={64} height={64} className="icon" />

// With accessibility attributes
<Protopie aria-label="Protopie" role="img" />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded via spread (`{...props}`).
- The icon image is self-contained — no external asset fetch required.
