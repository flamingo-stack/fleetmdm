React SVG icon component that renders the CotEditor application logo as an inline base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`CotEditor`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the CotEditor app icon as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import CotEditor from "./CotEditor";

// Basic usage
<CotEditor />

// With custom dimensions or className
<CotEditor width={64} height={64} className="app-icon" />

// With accessibility attributes
<CotEditor aria-label="CotEditor" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- The icon is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props.
