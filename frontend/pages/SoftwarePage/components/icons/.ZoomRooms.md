React SVG icon component that renders the Zoom Rooms logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`ZoomRooms`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Zoom Rooms logo as an embedded PNG image.

## Usage Example

```typescript
import ZoomRooms from "./ZoomRooms";

// Basic usage
<ZoomRooms />

// With custom dimensions or className
<ZoomRooms width={64} height={64} className="icon" />

// With style overrides
<ZoomRooms style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image source is a **base64-encoded PNG** embedded directly in the SVG, requiring no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element via spread.
