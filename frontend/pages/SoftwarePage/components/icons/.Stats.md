A React SVG component that renders a "Stats" icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Stats`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element. The icon is rendered via an `<image>` element with an inline base64 PNG data URI.

## Usage Example

```typescript
import Stats from "./Stats";

// Basic usage
<Stats />

// With custom dimensions or className
<Stats width={48} height={48} className="icon-stats" />

// With accessibility attributes
<Stats aria-label="Statistics" role="img" />
```

## Notes

- The component is a pure presentational icon with no internal state or logic.
- The image content is fully self-contained — no external asset fetch is required.
- Props are spread onto the `<svg>` element, enabling full customization (size, color overrides, event handlers, etc.) at the call site.
