A React SVG component that renders the Termius application icon as an inline SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Termius`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG wrapping the Termius brand icon as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Termius from "./Termius";

// Basic usage
<Termius />

// With custom size and class
<Termius width={64} height={64} className="icon" />

// With accessibility attributes
<Termius aria-label="Termius" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The icon image is self-contained — no external network requests are made at render time.
- Default dimensions are `32×32` pixels; override via `width`/`height` props.
