SVG icon component that renders the PlistEdit Pro application icon as a 32×32 pixel image embedded as a base64-encoded PNG within an SVG wrapper.

## Key Components

- **`PlisteditPro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering the PlistEdit Pro app icon at 32×32px.

## Usage Example

```typescript
import PlisteditPro from "./PlisteditPro";

// Basic usage
<PlisteditPro />

// With custom dimensions or className
<PlisteditPro width={64} height={64} className="app-icon" />

// With accessibility attributes
<PlisteditPro aria-label="PlistEdit Pro" role="img" />
```

## Notes

- The icon image is embedded as a base64 PNG inside an SVG `<image>` element, so no external asset fetch is required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default dimensions are `width={32}` and `height={32}`, matching typical toolbar/list icon sizes; these can be overridden via props.
