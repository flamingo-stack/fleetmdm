A React SVG component that renders a 32×32 icon embedding a base64-encoded PNG image (`JordanbairdIce`) as an inline SVG element.

## Key Components

- **`JordanbairdIce`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import JordanbairdIce from "./JordanbairdIce";

// Basic usage
<JordanbairdIce />

// With custom dimensions or className
<JordanbairdIce width={64} height={64} className="my-icon" />
```

## Notes

- The component renders a fixed 32×32 SVG by default; dimensions can be overridden via props.
- The image content is a base64-encoded PNG embedded directly in the SVG via an `<image>` element — no external asset dependencies.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are supported and passed through.
