A React SVG component that renders the Jellyfin media server logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Jellyfin`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains the Jellyfin logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Jellyfin from "./Jellyfin";

// Basic usage
<Jellyfin />

// With custom size and className
<Jellyfin width={64} height={64} className="icon" />

// With accessibility attributes
<Jellyfin aria-label="Jellyfin" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The logo is self-contained — no external image dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
