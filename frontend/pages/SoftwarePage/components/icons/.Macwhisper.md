A React SVG component that renders the Macwhisper application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Macwhisper`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering the Macwhisper icon at 32×32px with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Macwhisper from "./Macwhisper";

// Basic usage
<Macwhisper />

// With custom dimensions or className
<Macwhisper width={64} height={64} className="app-icon" />

// With accessibility attributes
<Macwhisper aria-label="Macwhisper" role="img" />
```

## Notes

- The icon is fully self-contained — no external image files required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread (`{...props}`), making it flexible for layout and accessibility needs.
