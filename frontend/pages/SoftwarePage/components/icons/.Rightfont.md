A React SVG component that renders the Rightfont application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Rightfont`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Rightfont from './Rightfont';

// Basic usage
<Rightfont />

// With custom dimensions or className
<Rightfont width={64} height={64} className="app-icon" />

// With accessibility attributes
<Rightfont aria-label="Rightfont" role="img" />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, supporting standard attributes such as `width`, `height`, `className`, `style`, and `aria-*`.
- The icon is a 32×32 PNG embedded as a base64 data URI; overriding `width`/`height` via props scales the SVG container but not the internal `<image>` element.
