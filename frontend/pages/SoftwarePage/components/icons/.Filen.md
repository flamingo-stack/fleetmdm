A React SVG component that renders the Filen brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Filen`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded Filen logo PNG.

## Usage Example

```typescript
import Filen from "./Filen";

// Basic usage
<Filen />

// With custom dimensions or className
<Filen width={64} height={64} className="icon" />

// With accessibility attributes
<Filen aria-label="Filen" role="img" />
```

## Notes

- The icon image is self-contained — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the `...props` spread.
