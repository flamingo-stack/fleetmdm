A React SVG component that renders the Affinity Publisher application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AffinityPublisher` | `React.FC<SVGProps<SVGSVGElement>>` | SVG wrapper component rendering the Affinity Publisher icon |

## Usage Example

```typescript
import AffinityPublisher from './AffinityPublisher';

// Basic usage
<AffinityPublisher />

// With custom dimensions
<AffinityPublisher width={64} height={64} />

// With additional SVG props
<AffinityPublisher className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The component accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `aria-*` attributes).
- The icon is rendered at **32×32px** by default via an embedded `<image>` element using a base64-encoded PNG data URI — no external asset requests are made.
- Part of the Flamingo/OpenFrame icon library. See the full icon set at [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm).
