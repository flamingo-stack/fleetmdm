A React SVG component that renders the Franz application icon as an inline SVG embedding a base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Franz`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG with an embedded base64 PNG of the Franz logo.

## Usage Example

```typescript
import Franz from "./Franz";

// Basic usage
<Franz />

// With custom dimensions or className
<Franz width={64} height={64} className="app-icon" />

// With accessibility attributes
<Franz aria-label="Franz" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread (`{...props}`), defaulting to `32×32`.
- The icon image is fully self-contained as a base64 data URI — no external asset fetches required.
