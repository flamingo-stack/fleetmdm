React SVG icon component that renders the Microsoft Edge browser logo as an inline PNG image embedded via base64 data URI.

## Key Components

- **`MicrosoftEdge`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing the Edge logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import MicrosoftEdge from './MicrosoftEdge';

// Basic usage
<MicrosoftEdge />

// With custom dimensions or className
<MicrosoftEdge width={24} height={24} className="browser-icon" />

// With accessibility attributes
<MicrosoftEdge aria-label="Microsoft Edge" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The logo is embedded as a **base64-encoded PNG** inside an SVG `<image>` tag, meaning no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
