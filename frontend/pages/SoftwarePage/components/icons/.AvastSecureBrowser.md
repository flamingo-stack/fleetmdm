A React SVG component that renders the Avast Secure Browser application icon as a 32×32 pixel image, embedding the icon as a base64-encoded PNG within an SVG wrapper.

## Key Components

- **`AvastSecureBrowser`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG with an embedded base64 PNG image of the Avast Secure Browser icon.

## Usage Example

```typescript
import AvastSecureBrowser from "./AvastSecureBrowser";

// Basic usage
<AvastSecureBrowser />

// With custom dimensions or className
<AvastSecureBrowser width={64} height={64} className="app-icon" />

// With accessibility attributes
<AvastSecureBrowser aria-label="Avast Secure Browser" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`).
- The icon image is self-contained via a base64-encoded PNG, requiring no external image assets.
- Part of the Fleet MDM application icon set, likely used to identify managed devices or software inventory entries for Avast Secure Browser.
