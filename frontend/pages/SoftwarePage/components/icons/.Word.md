A React SVG icon component that renders a Microsoft Word logo with gradient fills. Uses `lodash.uniqueId` to generate unique gradient IDs, preventing conflicts when multiple instances are rendered on the same page.

## Key Components

- **`Word`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, forwarded directly to the root `<svg>` element.
- **Gradient IDs** — Five unique linear gradient IDs (`gradAId`–`gradEId`) generated per instance via `uniqueId()`, scoping gradients to avoid SVG `<defs>` collisions.

## Usage Example

```typescript
import Word from "./Word";

// Basic usage
<Word width={32} height={32} />

// With custom size and class
<Word width={24} height={24} className="icon-word" />

// Inherits all SVGProps
<Word aria-label="Microsoft Word" role="img" style={{ display: "block" }} />
```

## Notes

- The SVG is designed for a **32×32** viewport but scales freely via `width`/`height` props.
- Gradient colors use the Microsoft Word blue palette (`#223E74` → `#338ACD`).
- No `viewBox` is set in the component — pass one via props if needed for responsive scaling:

```typescript
<Word viewBox="0 0 32 32" width="100%" height="100%" />
```
