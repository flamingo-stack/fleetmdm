A React SVG icon component that renders a Santa Claus icon on a red background within a 32×32 viewport.

## Key Components

- **`Santa`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute customization (e.g., `width`, `height`, `className`, `style`).
- **`clipPathId`** — A unique ID generated via Lodash `uniqueId` to prevent `clipPath` collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import Santa from "./Santa";

// Basic usage
<Santa width={32} height={32} />

// With custom sizing and className
<Santa width={64} height={64} className="santa-icon" />

// Inline style override
<Santa style={{ width: "2rem", height: "2rem" }} />
```

## Notes

- The icon is a fixed 32×32 SVG composition with a solid red (`#DC2626`) background and a white (`#FAFAFA`) Santa silhouette rendered using complex path data.
- The unique `clipPath` ID ensures safe reuse of the component across multiple renders without DOM ID conflicts.
- All standard SVG props are forwarded via the spread `{...props}`, making it compatible with icon systems or UI libraries that pass SVG attributes externally.
