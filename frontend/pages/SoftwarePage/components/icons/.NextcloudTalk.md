React SVG icon component that renders the Nextcloud Talk logo as a 32×32 PNG embedded inline via a base64-encoded `<image>` element.

## Key Components

- **`NextcloudTalk`** — Default-exported functional component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the outer `<svg>` element.

## Usage Example

```typescript
import NextcloudTalk from "./NextcloudTalk";

// Basic usage
<NextcloudTalk />

// With custom dimensions and className
<NextcloudTalk width={64} height={64} className="icon" />

// With accessibility attributes
<NextcloudTalk aria-label="Nextcloud Talk" role="img" />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via `width`/`height` props.
- The logo is stored as a **base64-encoded PNG** inside an SVG `<image>` tag — no external asset fetch required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are supported via spread.
