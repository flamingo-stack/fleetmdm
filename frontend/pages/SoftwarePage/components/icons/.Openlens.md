A React SVG icon component that renders the OpenLens logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Openlens`** — Default export. A functional React component that renders a 32×32 SVG element containing the OpenLens logo as an embedded PNG image.

## Usage Example

```typescript
import Openlens from "./Openlens";

// Basic usage
<Openlens />

// With custom dimensions or className
<Openlens width={64} height={64} className="my-icon" />

// With accessibility attributes
<Openlens aria-label="OpenLens" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`).
- Default render size is **32×32px**; override via `width`/`height` props.
- The logo is embedded as a base64 PNG — no external image requests required.
