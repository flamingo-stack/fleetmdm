SVG icon component that renders the Cloudflare logo as a React component, accepting standard SVG props for customization.

## Key Components

- **`Cloudflare`** — Default export. A functional React component wrapping an SVG with two paths representing the Cloudflare flame logo in brand colors (`#F38020` orange and `#FAAE40` yellow) on a white background.

## Usage Example

```typescript
import Cloudflare from "./Cloudflare";

// Basic usage
<Cloudflare width={32} height={32} />

// Custom size and class
<Cloudflare width={24} height={24} className="icon" />

// Override fill color
<Cloudflare style={{ fill: "currentColor" }} />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/Cloudflare.tsx) — `width`, `height`, `className`, `style`, `aria-label`, etc.
- Default viewBox is `32×32`.
- No internal state or side effects; safe for SSR and static rendering.
