React SVG icon component that renders the OpenAudible logo as an inline PNG embedded within an SVG wrapper.

## Key Components

- **`Openaudible`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the OpenAudible logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Openaudible from "./Openaudible";

// Basic usage
<Openaudible />

// With custom dimensions or className
<Openaudible width={64} height={64} className="icon" />

// With accessibility attributes
<Openaudible aria-label="OpenAudible" role="img" />
```

## Notes

- The logo image is embedded as a base64-encoded PNG (512×512 source, scaled to 32×32), so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
