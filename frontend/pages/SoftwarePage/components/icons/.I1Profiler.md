A React SVG icon component that renders the i1Profiler application logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`I1Profiler`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the i1Profiler icon as an inline base64 PNG.

## Usage Example

```typescript
import I1Profiler from "./I1Profiler";

// Basic usage
<I1Profiler />

// With custom dimensions and class
<I1Profiler width={64} height={64} className="icon" />

// With inline styles
<I1Profiler style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32px**; override via `width`/`height` props.
- The PNG image data is embedded as a base64 `href` on an `<image>` element — no external asset required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, event handlers) are forwarded via `{...props}`.
