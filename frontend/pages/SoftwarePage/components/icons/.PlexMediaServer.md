A React SVG component that renders the Plex Media Server icon as a 32×32 inline SVG using a base64-encoded PNG image.

## Key Components

- **`PlexMediaServer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing the Plex Media Server logo as an embedded PNG.

## Usage Example

```typescript
import PlexMediaServer from "./PlexMediaServer";

// Basic usage
<PlexMediaServer />

// With custom dimensions and className
<PlexMediaServer width={64} height={64} className="icon" />

// With accessibility attributes
<PlexMediaServer aria-label="Plex Media Server" role="img" />
```

## Notes

- The icon image is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
