A React SVG icon component that renders the Podman Desktop logo as a 32×32 SVG element using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `PodmanDesktop` | `React.FC<SVGProps<SVGSVGElement>>` | SVG wrapper component rendering the Podman Desktop icon via embedded base64 PNG |

## Usage Example

```typescript
import PodmanDesktop from "./PodmanDesktop";

// Basic usage
<PodmanDesktop />

// With custom dimensions and className
<PodmanDesktop width={64} height={64} className="icon" />

// With style overrides
<PodmanDesktop style={{ opacity: 0.8 }} aria-label="Podman Desktop" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-label`).
- The icon image is self-contained via a base64-encoded PNG — no external asset dependencies or network requests required.
- Default rendered size is **32×32 pixels**.
