A React SVG wrapper component that renders the Pixelsnap application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Pixelsnap`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Pixelsnap logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Pixelsnap from "./Pixelsnap";

// Basic usage
<Pixelsnap />

// With custom size and class
<Pixelsnap width={64} height={64} className="app-icon" />

// With accessibility attributes
<Pixelsnap aria-label="Pixelsnap" role="img" />
```

## Notes

- The icon dimensions default to **32×32 pixels** but can be overridden via `width`/`height` props.
- The PNG image data is fully self-contained (base64-encoded), so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
