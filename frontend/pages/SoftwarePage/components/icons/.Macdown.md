A React SVG component that renders the Macdown application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Macdown`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Macdown app icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import Macdown from "./Macdown";

// Basic usage
<Macdown />

// With custom dimensions or className
<Macdown width={64} height={64} className="app-icon" />

// With style overrides
<Macdown style={{ opacity: 0.8 }} />
```

## Notes

- The icon is hardcoded as a base64-encoded PNG (`data:image/png;base64,...`) embedded inside the SVG, so no external image assets are required.
- Default size is **32×32 pixels**; this can be overridden via `width`/`height` props.
- All standard SVG element props (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element via spread.
