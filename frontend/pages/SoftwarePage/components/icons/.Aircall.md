React SVG icon component that renders the Aircall logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Aircall`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Aircall brand logo as an embedded base64 PNG.

## Usage Example

```typescript
import Aircall from "./Aircall";

// Basic usage
<Aircall />

// With custom dimensions and className
<Aircall width={64} height={64} className="integration-icon" />

// With style overrides
<Aircall style={{ opacity: 0.8 }} aria-label="Aircall" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The logo image is embedded as a base64 PNG — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element.
- Part of the integration icon set in [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm).
