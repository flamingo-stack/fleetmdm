React SVG icon component that renders an iPadOS platform icon in two size variants for use in OS identification tables and UI elements.

## Key Components

- **`iPadOS`** (default export) — A React functional component accepting standard `SVGProps<SVGSVGElement>`. Renders different SVG artwork based on the `width` prop:
  - **`width="24"`** — Compact variant with a thicker outline and smaller Apple logo, intended for OS table rows
  - **Default (32px)** — Standard variant with a thinner outline and larger Apple logo for general UI use

Both variants render a tablet outline with the Apple logo path on a `#F9FAFC` background, using `#515774` as the icon stroke/fill color.

## Usage Example

```typescript
import iPadOS from "./iPadOS";

// Standard size (32px canvas)
<iPadOS width="32" height="32" />

// Compact table variant (24px triggers thicker outline)
<iPadOS width="24" height="24" />

// With additional SVG props
<iPadOS width="32" height="32" className="os-icon" aria-label="iPadOS" />
```

## Notes

- The `width === "24"` check is a string comparison against the prop value — pass `"24"` as a string to trigger the compact variant
- SVG paths are hardcoded; no external assets or icon libraries are required
- Follows the same pattern as other OS icon components in this codebase (e.g., `macOS.tsx`, `iOS.tsx`)
