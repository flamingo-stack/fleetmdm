A React SVG icon component that renders the "Open in Terminal" application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Openinterminal`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element that contains an embedded PNG image (512×512 source, downscaled to 32×32) encoded as a base64 data URI.

## Usage Example

```typescript
import Openinterminal from "./Openinterminal";

// Basic usage
<Openinterminal />

// With custom dimensions and styling
<Openinterminal
  width={24}
  height={24}
  className="icon"
  style={{ cursor: "pointer" }}
/>

// As a clickable icon button
<button onClick={handleOpenTerminal}>
  <Openinterminal aria-label="Open in Terminal" />
</button>
```

## Notes

- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via prop spreading.
- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The PNG source is embedded directly as a base64 data URI — no external asset file or network request required.
- Source file: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Openinterminal.tsx)
