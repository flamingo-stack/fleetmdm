React SVG icon component that renders the Bitwarden logo as an inline base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`Bitwarden`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Bitwarden brand icon via an embedded base64 PNG.

## Usage Example

```typescript
import Bitwarden from "./Bitwarden";

// Basic usage
<Bitwarden />

// With custom dimensions or className
<Bitwarden width={24} height={24} className="icon" />

// With accessibility attributes
<Bitwarden aria-label="Bitwarden" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained — no external image assets required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
