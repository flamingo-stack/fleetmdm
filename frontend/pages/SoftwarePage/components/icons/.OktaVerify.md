A React SVG component that renders the Okta Verify application icon as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`OktaVerify`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Okta Verify logo as an embedded PNG.

## Usage Example

```typescript
import OktaVerify from "./OktaVerify";

// Basic usage
<OktaVerify />

// With custom dimensions or className
<OktaVerify width={64} height={64} className="app-icon" />

// With accessibility attributes
<OktaVerify aria-label="Okta Verify" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG image data is fully self-contained (base64-encoded), requiring no external image assets or network requests.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
