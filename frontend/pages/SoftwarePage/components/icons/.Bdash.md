A React SVG component that renders the Bdash logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Bdash`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Bdash logo as an embedded PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import Bdash from "./Bdash";

// Basic usage
<Bdash />

// With custom dimensions or className
<Bdash width={64} height={64} className="icon" />

// With inline styles
<Bdash style={{ opacity: 0.8 }} />
```

## Notes

- The component passes all standard SVG props (`className`, `style`, `onClick`, etc.) through to the root `<svg>` element via spread (`{...props}`).
- The logo is self-contained — no external image URL is required at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
