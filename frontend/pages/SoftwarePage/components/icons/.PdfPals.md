A React SVG component that renders the PdfPals logo as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`PdfPals`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG logo via an `<image>` element.

## Usage Example

```typescript
import PdfPals from "./PdfPals";

// Basic usage
<PdfPals />

// With custom size or className
<PdfPals width={64} height={64} className="my-icon" />

// With accessibility attributes
<PdfPals aria-label="PdfPals" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component fully customizable.
- The default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
- The embedded PNG is a 512×512 source image downscaled to 32×32 via the SVG viewport — pass larger `width`/`height` values for sharper rendering at bigger sizes.
