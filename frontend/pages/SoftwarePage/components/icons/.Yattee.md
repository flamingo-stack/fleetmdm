React SVG icon component that renders the Yattee app logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Yattee`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Yattee logo via an `<image>` element with an inline base64 PNG source.

## Usage Example

```typescript
import Yattee from "./Yattee";

// Basic usage
<Yattee />

// With custom dimensions or className
<Yattee width={64} height={64} className="icon" />

// With accessibility attributes
<Yattee aria-label="Yattee" role="img" />
```

## Notes

- The logo image data is entirely self-contained — no external asset requests are made.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
