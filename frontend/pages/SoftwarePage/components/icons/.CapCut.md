A React SVG icon component that renders the CapCut logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`CapCut`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the CapCut brand icon as an embedded PNG via base64 data URI.

## Usage Example

```typescript
import CapCut from "./CapCut";

// Basic usage
<CapCut />

// With custom dimensions and className
<CapCut width={64} height={64} className="icon" />

// With accessibility attributes
<CapCut aria-label="CapCut" role="img" />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- All standard SVG props (`className`, `style`, `onClick`, etc.) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external asset dependencies.
