A React SVG icon component that renders the PuTTY application logo as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`Putty`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` element containing a base64-encoded PNG image of the PuTTY logo.

## Usage Example

```typescript
import Putty from './Putty';

// Basic usage
<Putty />

// With custom size and className
<Putty width={64} height={64} className="icon" />

// With style overrides
<Putty style={{ opacity: 0.8 }} aria-label="PuTTY" />
```

## Notes

- Fixed internal dimensions of 32×32 pixels; override via `width`/`height` props.
- The image data is entirely self-contained (base64 PNG), requiring no external assets.
- Supports all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`).
