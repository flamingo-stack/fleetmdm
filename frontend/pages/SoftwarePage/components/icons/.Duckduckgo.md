A React SVG component that renders the DuckDuckGo browser/search engine logo as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Duckduckgo`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, aria-label, etc.)

## Usage Example

```typescript
import Duckduckgo from './Duckduckgo';

// Basic usage
<Duckduckgo />

// With custom dimensions and className
<Duckduckgo width={64} height={64} className="browser-icon" />

// With accessibility label
<Duckduckgo aria-label="DuckDuckGo" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props
- The logo is embedded as a **base64 PNG** inside an SVG `<image>` tag — no external network requests required
- Part of the browser/search engine icon set in the Flamingo MDM UI; see related icons in the same directory at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/)
