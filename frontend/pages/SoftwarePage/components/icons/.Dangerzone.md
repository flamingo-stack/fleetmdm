A React SVG icon component that renders a "Dangerzone" icon as a 32×32 PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Dangerzone`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, forwarding all props to the root `<svg>` element.

## Usage Example

```typescript
import Dangerzone from "./Dangerzone";

// Basic usage
<Dangerzone />

// With custom size and className
<Dangerzone width={64} height={64} className="icon" />

// With style overrides
<Dangerzone style={{ opacity: 0.8 }} aria-label="Danger Zone" />
```

## Notes

- The icon is a **32×32** SVG by default but can be resized via `width`/`height` props.
- The inner image is a static base64-encoded PNG; scaling beyond 32×32 may result in pixelation.
- All `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are passed through to the root `<svg>` element.
