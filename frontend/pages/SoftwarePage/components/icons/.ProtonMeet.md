SVG icon component that renders the ProtonMeet logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`ProtonMeet`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the ProtonMeet logo as an embedded base64 PNG image.

## Usage Example

```typescript
import ProtonMeet from "./ProtonMeet";

// Basic usage
<ProtonMeet />

// With custom dimensions or className
<ProtonMeet width={64} height={64} className="icon" />

// With accessibility attributes
<ProtonMeet aria-label="ProtonMeet" role="img" />
```

## Notes

- The icon renders at **32×32px** by default but accepts any `SVGProps` overrides.
- The logo image is self-contained as a base64-encoded PNG — no external asset requests.
- The underlying PNG was authored at **512×512px** (per embedded EXIF metadata), downscaled to 32×32 in the SVG viewport.
