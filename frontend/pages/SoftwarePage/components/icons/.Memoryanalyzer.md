SVG icon component that renders a Memory Analyzer application icon as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Memoryanalyzer`** — A React functional component that renders a 32×32 SVG element containing an embedded PNG image (base64-encoded) of the Memory Analyzer icon.

## Props

Accepts all standard `SVGProps<SVGSVGElement>` from React, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-*` attributes).

## Usage Example

```typescript
import { Memoryanalyzer } from "./Memoryanalyzer";

// Basic usage
<Memoryanalyzer />

// With custom size and class
<Memoryanalyzer width={64} height={64} className="icon" />

// With click handler
<Memoryanalyzer onClick={() => openMemoryAnalyzer()} style={{ cursor: "pointer" }} />
```

## Notes

- Default dimensions are **32×32 pixels**.
- The icon image is fully self-contained — no external image assets required.
- Exported as a named export; use the component name `Memoryanalyzer` when importing.
