A React SVG component that renders the Google Chrome app icon with proper gradient fills and unique clip path IDs to avoid conflicts when rendered multiple times on the same page.

## Key Components

- **`ChromeApp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Chrome logo with three gradient arcs and a central blue circle.
- **Unique ID generation** — Uses `lodash.uniqueId` to generate unique IDs for `clipPath` and `linearGradient` `defs`, preventing SVG `id` collisions when multiple instances are mounted simultaneously.

## Usage Example

```typescript
import ChromeApp from "./ChromeApp";

// Basic usage
<ChromeApp />

// With custom dimensions and className
<ChromeApp width={48} height={48} className="app-icon" />

// Inside a list of app icons
{apps.map((app) => (
  <div key={app.id}>
    <ChromeApp width={32} height={32} />
    <span>{app.name}</span>
  </div>
))}
```

## Notes

- The component defaults to a 32×32 viewBox (matching the background `path`).
- Gradient colors match the official Chrome brand palette: red (`#D93025`→`#EA4335`), yellow (`#FCC934`→`#FBBC04`), and green (`#1E8E3E`→`#34A853`), with a blue (`#1A73E8`) center circle.
- All `SVGProps` are spread onto the root `<svg>` element, so `width`, `height`, `className`, `style`, and `aria-*` attributes are fully supported.
