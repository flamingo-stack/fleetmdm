A React SVG component that renders the ProtonDrive application icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`ProtonDrive`** — Default export. A functional React component that wraps a base64-encoded PNG of the ProtonDrive logo inside an `<svg>` element, accepting and forwarding all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import ProtonDrive from "./ProtonDrive";

// Basic usage
<ProtonDrive />

// With custom dimensions or className
<ProtonDrive width={64} height={64} className="app-icon" />

// With accessibility attributes
<ProtonDrive aria-label="ProtonDrive" role="img" />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via props.
- The PNG image data is embedded as a base64 `data:image/png` URI, making this component self-contained with no external asset dependencies.
- All `SVGProps<SVGSVGElement>` (e.g., `className`, `style`, `onClick`, `aria-*`) are spread onto the root `<svg>` element, making it fully composable.
