A React SVG component that renders the Goodsync brand icon as a 32×32 inline SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Goodsync`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing the Goodsync logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Goodsync from "./Goodsync";

// Basic usage
<Goodsync />

// With custom dimensions and className
<Goodsync width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Goodsync aria-label="Goodsync" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded to the root `<svg>` element via spread.
- The logo image is self-contained — no external network requests are made at render time.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
