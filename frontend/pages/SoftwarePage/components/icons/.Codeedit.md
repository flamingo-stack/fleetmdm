A React SVG component that renders a "Code Edit" icon as an inline SVG element embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Codeedit`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`)
- The SVG wrapper is fixed at `width={32}` and `height={32}`, rendering the icon via an embedded `<image>` element with a base64-encoded PNG data URI

## Usage Example

```typescript
import Codeedit from "./Codeedit";

// Basic usage
<Codeedit />

// With custom className and click handler
<Codeedit className="icon-code-edit" onClick={() => console.log("clicked")} />

// Overriding size via props
<Codeedit width={48} height={48} />
```

## Notes

- The icon image is fully self-contained — no external asset dependencies at runtime
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, making it straightforward to control accessibility attributes (`aria-label`, `role`), dimensions, and event handlers
