A React SVG component that renders the DbVisualizer logo as an inline SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Dbvisualizer`** — Default export. A functional React component that renders an `<svg>` element (32×32) with an embedded base64 PNG of the DbVisualizer logo. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Dbvisualizer from "./Dbvisualizer";

// Basic usage
<Dbvisualizer />

// With custom size and className
<Dbvisualizer width={64} height={64} className="tool-icon" />

// With accessibility attributes
<Dbvisualizer aria-label="DbVisualizer" role="img" />
```

## Notes

- The image data is fully self-contained — no external asset fetches required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default dimensions are `32×32`; override via `width`/`height` props.
