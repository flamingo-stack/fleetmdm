SVG icon component for iOS devices, rendering an Apple logo inside a mobile phone outline. Supports two size variants: a compact version with thicker stroke for OS tables (width `"24"`), and a standard version for default display.

## Key Components

- **`iOS`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props.
- **Size branching** — When `props.width === "24"`, renders a scaled-up, thicker-outlined variant using `scale(1.5)` and `strokeWidth="1.5"`. Otherwise renders the default variant using `scale(0.75)`.
- **Visual elements** — Both variants share the same structure: a white/light background fill (`#F9FAFC`), a rounded-rect phone outline, an Apple logo path, and a home button cap, all stroked and filled in `#515774`.

## Usage Example

```typescript
import iOS from "./iOS";

// Default size variant
<iOS width="32" height="32" />

// OS table compact variant (thicker outline, smaller Apple logo)
<iOS width="24" height="24" />

// With additional SVG props
<iOS width="32" height="32" className="platform-icon" aria-label="iOS" />
```

## Notes

- The `width="24"` check is a string comparison, so numeric props (e.g., `width={24}`) will **not** trigger the compact variant — pass width as a string literal.
- The `32×32` viewport is fixed in both variants; only the internal scaling changes.
