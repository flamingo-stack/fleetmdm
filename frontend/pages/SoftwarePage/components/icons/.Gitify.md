A React SVG component that renders the Gitify application icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Gitify`** — Default export. A functional React component that wraps a base64-encoded PNG logo inside an `<svg>` element. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import { Gitify } from './Gitify';

// Basic usage
<Gitify />

// With custom dimensions or className
<Gitify width={64} height={64} className="app-icon" />

// With style overrides
<Gitify style={{ opacity: 0.8 }} aria-label="Gitify logo" />
```

## Notes

- The icon is rendered at a default size of **32×32px** but can be overridden via `width`/`height` props.
- The image source is a **base64-encoded PNG** embedded directly in the SVG — no external image request is made.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, making this fully composable with standard SVG attributes.
