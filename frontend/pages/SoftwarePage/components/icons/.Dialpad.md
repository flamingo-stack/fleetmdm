A React SVG icon component that renders a Dialpad icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Dialpad`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element. The icon is rendered as an `<image>` element with a base64-encoded PNG `href`, making it self-contained with no external asset dependencies.

## Usage Example

```typescript
import Dialpad from "./Dialpad";

// Basic usage
<Dialpad />

// With custom size and className
<Dialpad width={24} height={24} className="icon" />

// With color override (note: base64 PNG does not respond to CSS fill/stroke)
<Dialpad style={{ opacity: 0.8 }} />
```

## Notes

- The icon is **32×32px** by default but can be overridden via `width`/`height` props.
- Because the icon uses an embedded **PNG image** (not SVG paths), CSS properties like `fill` and `stroke` will **not** affect the icon's appearance.
- The component is fully typed via `SVGProps<SVGSVGElement>` from React, supporting all standard SVG attributes.
