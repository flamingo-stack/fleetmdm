React SVG wrapper component that renders a 32×32 "Principle" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Principle`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an inlined PNG icon via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Principle from "./Principle";

// Basic usage
<Principle />

// With custom dimensions or className
<Principle width={64} height={64} className="icon" />

// With accessibility attributes
<Principle aria-label="Principle icon" role="img" />
```

## Notes

- The PNG data is fully inlined as a base64 string, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component fully composable.
