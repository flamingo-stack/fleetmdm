React SVG icon component that renders the Tor Browser logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`TorBrowser`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`. Renders a 32×32 SVG containing an `<image>` element with the Tor Browser icon embedded as a base64 PNG data URI.

## Usage Example

```typescript
import TorBrowser from "./TorBrowser";

// Basic usage
<TorBrowser />

// With custom dimensions or className
<TorBrowser width={24} height={24} className="icon" />

// With accessibility attributes
<TorBrowser aria-label="Tor Browser" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Fixed intrinsic size is **32×32 pixels**; override via `width`/`height` props as needed.
