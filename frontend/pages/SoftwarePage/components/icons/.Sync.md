React SVG icon component that renders a 32×32 "Sync" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Sync`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Sync from "./Sync";

// Basic usage
<Sync />

// With custom styles and event handlers
<Sync
  className="spin-icon"
  width={24}
  height={24}
  onClick={() => handleSync()}
  style={{ cursor: "pointer" }}
/>
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via spread to the root `<svg>` element.
- The icon image is entirely self-contained — no external image assets or network requests are needed.
- Default render size is **32×32px**; override with `width`/`height` props.
