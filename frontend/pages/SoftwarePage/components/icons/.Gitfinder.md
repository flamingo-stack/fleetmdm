A React SVG icon component that renders the Gitfinder logo as a 32×32 PNG embedded via a base64-encoded `<image>` element within an SVG wrapper.

## Key Components

- **`Gitfinder`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the outer `<svg>` element.

## Usage Example

```typescript
import Gitfinder from "./Gitfinder";

// Basic usage
<Gitfinder />

// With custom dimensions or className
<Gitfinder width={64} height={64} className="icon" />

// With accessibility attributes
<Gitfinder aria-label="Gitfinder" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via `width`/`height` props.
- The image data is a self-contained base64 PNG — no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are supported via prop spreading.
