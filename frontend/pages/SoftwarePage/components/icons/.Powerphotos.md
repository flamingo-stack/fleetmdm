A React SVG component that renders the PowerPhotos macOS app icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Powerphotos`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG element containing the PowerPhotos app icon as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Powerphotos from "./Powerphotos";

// Basic usage
<Powerphotos />

// With custom dimensions or className
<Powerphotos width={64} height={64} className="app-icon" />

// With accessibility attributes
<Powerphotos aria-label="PowerPhotos" role="img" />
```

## Notes

- The icon image is self-contained — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- The embedded PNG is 512×512 source resolution, downscaled to 32×32 in the SVG viewport.
