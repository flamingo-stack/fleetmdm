A React SVG icon component that renders the Slack logo as an inline scalable vector graphic.

## Key Components

- **`Slack`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the four-colored Slack hash mark logo using `fillRule="evenodd"` path geometry.
- **`clipPathId`** — A `lodash.uniqueId`-generated ID ensuring each rendered instance has a unique `clipPath` reference, preventing conflicts when the icon appears multiple times on the same page.

## Usage Example

```typescript
import Slack from "@/components/icons/Slack";

// Basic usage
<Slack width={32} height={32} />

// Custom size with className
<Slack width={24} height={24} className="mr-2" />

// Pass any SVGProps
<Slack aria-label="Slack" role="img" style={{ display: "block" }} />
```

## Notes

- The component renders a fixed white background rectangle (`32×32`) and a `22×22` clipped icon centered within it via a `translate(5 5)` transform.
- The four Slack brand colors used are: `#36C5F0` (blue), `#2EB67D` (green), `#ECB22E` (yellow), `#E01E5A` (red).
- All SVG props are spread onto the root `<svg>` element, allowing full customization of dimensions, accessibility attributes, and styles.
