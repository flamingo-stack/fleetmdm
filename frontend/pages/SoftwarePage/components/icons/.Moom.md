A React SVG component that renders the Moom application icon as an inline SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Moom`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import Moom from "./Moom";

// Basic usage
<Moom />

// With custom dimensions or className
<Moom width={64} height={64} className="app-icon" />

// With accessibility attributes
<Moom aria-label="Moom" role="img" />
```

## Notes

- The icon image is self-contained — no external asset files are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element.
- Default rendered size is **32×32px**; override via `width`/`height` props.
