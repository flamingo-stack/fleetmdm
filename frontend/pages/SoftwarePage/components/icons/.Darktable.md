React SVG component that renders the Darktable application icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Darktable`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element that embeds the Darktable logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Darktable from "./Darktable";

// Basic usage
<Darktable />

// With custom dimensions or className
<Darktable width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Darktable aria-label="Darktable" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via the spread `{...props}`, making the component fully customizable.
- The icon is self-contained — no external image assets are required at runtime.
