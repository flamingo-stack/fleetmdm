A React SVG icon component that renders the Kiro CLI logo as a 32×32 inline PNG embedded via base64 data URI.

## Key Components

- **`KiroCli`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing consumers to pass any SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import KiroCli from "./KiroCli";

// Basic usage
<KiroCli />

// With custom size and className
<KiroCli width={64} height={64} className="icon" />

// With onClick handler
<KiroCli onClick={() => console.log("clicked")} />
```

## Notes

- The icon is fixed at 32×32 SVG viewport by default but can be overridden via props.
- The PNG image is embedded as a base64 data URI, so no external asset requests are made.
