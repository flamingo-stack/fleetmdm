React SVG icon component that renders the XCA (Certificate Authority) logo as a 32×32 PNG embedded within an SVG wrapper.

## Key Components

- **`Xca`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- Renders a fixed 32×32 SVG containing an `<image>` element with a base64-encoded PNG of the XCA logo.

## Usage Example

```typescript
import Xca from "./Xca";

// Basic usage
<Xca />

// With custom className or style
<Xca className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Xca width={64} height={64} />
```

## Notes

- The icon is self-contained — no external image assets required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are passed through via spread.
- Default dimensions are `32×32` pixels but can be overridden via props.
