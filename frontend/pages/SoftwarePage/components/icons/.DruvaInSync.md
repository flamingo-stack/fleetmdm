SVG React component that renders the Druva InSync logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`DruvaInSync`** — A React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Druva InSync logo via an `<image>` element.

## Usage Example

```typescript
import DruvaInSync from "./DruvaInSync";

// Basic usage
<DruvaInSync />

// With custom dimensions or className
<DruvaInSync width={64} height={64} className="icon" />

// With style overrides
<DruvaInSync style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
- The logo image is self-contained as a base64 PNG — no external asset dependencies.
