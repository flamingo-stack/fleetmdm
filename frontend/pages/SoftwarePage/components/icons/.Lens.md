A React SVG component that renders a 32×32 Lens icon using an embedded base64-encoded PNG image.

## Key Components

- **`Lens`** — Default export. A functional React component wrapping an `<svg>` element that renders a Lens icon via an inline base64 PNG `<image>` tag.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Lens from "./Lens";

// Basic usage
<Lens />

// With custom size and class
<Lens width={64} height={64} className="icon-lens" />

// With event handler
<Lens onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- Default dimensions are **32×32 pixels**.
- The icon image is self-contained via a base64-encoded PNG, requiring no external assets.
- SVG props are spread onto the root `<svg>` element, enabling full style and attribute overrides.
