A React SVG component that renders the Syncmate brand icon as a 32×32 inline SVG, embedding a base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Syncmate` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component accepting standard SVG props |

## Usage Example

```typescript
import Syncmate from "./Syncmate";

// Basic usage
<Syncmate />

// With custom dimensions
<Syncmate width={64} height={64} />

// With className or style overrides
<Syncmate className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-label`) via spread.
- The icon is rendered as an `<image>` element inside the SVG, using an embedded base64 PNG — no external network requests required.
- Default dimensions are `32×32` pixels; override via `width`/`height` props.
