React SVG icon component that renders the OBS (Open Broadcaster Software) logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Obs`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the OBS logo as a base64-embedded PNG `<image>` element.

## Usage Example

```typescript
import Obs from './Obs';

// Basic usage
<Obs />

// With custom size and className
<Obs width={64} height={64} className="icon" />

// With accessibility attributes
<Obs aria-label="OBS Studio" role="img" />
```

## Notes

- The component renders at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The logo image is entirely **self-contained** — no external image requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
