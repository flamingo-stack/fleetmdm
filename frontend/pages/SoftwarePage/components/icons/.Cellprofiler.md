A React SVG icon component that renders the CellProfiler logo as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Cellprofiler`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the CellProfiler logo embedded as a base64 PNG within an `<svg>` element.

## Usage Example

```typescript
import Cellprofiler from "./Cellprofiler";

// Basic usage
<Cellprofiler />

// With custom dimensions or className
<Cellprofiler width={64} height={64} className="tool-icon" />

// With style overrides
<Cellprofiler style={{ opacity: 0.8 }} aria-label="CellProfiler" />
```

## Notes

- The component is a thin wrapper — the actual image data is a base64-encoded PNG embedded directly in the SVG `<image>` element, so no external asset files are required.
- All props are forwarded to the root `<svg>` element, enabling full customization (size, accessibility attributes, event handlers, etc.).
- Default rendered size is **32×32px**; override via `width`/`height` props.
