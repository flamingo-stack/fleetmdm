A React SVG component that renders the Jami logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Jami`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG wrapper containing the Jami logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Jami from './Jami';

// Basic usage
<Jami />

// With custom size and className
<Jami width={64} height={64} className="icon" />

// With accessibility attributes
<Jami aria-label="Jami" role="img" />
```

## Notes

- The logo image is inlined as a base64-encoded PNG, so no external asset file is required.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, event handlers) are forwarded to the root `<svg>` element via spread.
