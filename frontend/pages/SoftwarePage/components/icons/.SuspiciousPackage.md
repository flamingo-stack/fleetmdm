React SVG icon component that renders a "Suspicious Package" icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SuspiciousPackage`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper with an embedded base64 PNG `<image>` element

## Usage Example

```typescript
import SuspiciousPackage from "./SuspiciousPackage";

// Basic usage
<SuspiciousPackage />

// With custom dimensions or className
<SuspiciousPackage width={64} height={64} className="icon" />

// With style overrides
<SuspiciousPackage style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via spread to the root `<svg>` element
- The icon image is fully self-contained — no external asset dependencies
- Default render size is `32×32` pixels; override via `width`/`height` props
