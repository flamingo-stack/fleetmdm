A React SVG icon component that renders the Alacritty terminal emulator logo as an inline base64-encoded PNG image.

## Key Components

- **`Alacritty`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Alacritty icon as an embedded PNG.

## Usage Example

```typescript
import Alacritty from './Alacritty';

// Basic usage
<Alacritty />

// With custom dimensions or className
<Alacritty width={64} height={64} className="icon" />

// With accessibility attributes
<Alacritty aria-label="Alacritty terminal" role="img" />
```

## Notes

- The icon is a fixed 32×32 base64-encoded PNG wrapped in an `<svg>` element.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
