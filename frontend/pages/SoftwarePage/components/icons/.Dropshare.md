A React SVG component that renders the Dropshare application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Dropshare`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Dropshare app icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import { Dropshare } from "./Dropshare";

// Basic usage
<Dropshare />

// With custom dimensions or className
<Dropshare width={64} height={64} className="app-icon" />

// With accessibility attributes
<Dropshare aria-label="Dropshare" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required; the PNG data is embedded directly in the component as a base64 string.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The embedded image carries EXIF metadata indicating a source resolution of **512×512 pixels**.
