A React SVG component that renders the Kaleidoscope logo/icon as an inline SVG wrapping a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Kaleidoscope`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG image

## Usage Example

```typescript
import Kaleidoscope from './Kaleidoscope';

// Basic usage
<Kaleidoscope />

// With custom dimensions and className
<Kaleidoscope width={64} height={64} className="icon" />

// With accessibility attributes
<Kaleidoscope aria-label="Kaleidoscope" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element
- The image is self-contained — no external asset dependencies
- Default rendered size is **32×32px**; override with `width`/`height` props
