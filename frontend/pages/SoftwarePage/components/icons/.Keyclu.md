A React SVG component that renders the Keyclu application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Keyclu`** — Default export. A functional React component that renders a 32×32 SVG element containing the Keyclu app icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Keyclu from "./Keyclu";

// Basic usage
<Keyclu />

// With custom dimensions or className
<Keyclu width={64} height={64} className="app-icon" />

// With accessibility attributes
<Keyclu aria-label="Keyclu" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/path/to/Keyclu.tsx) props, forwarded directly to the root `<svg>` element.
- Default render size is **32×32px**; override via `width`/`height` props.
- The icon image is self-contained — no external network requests are made.
