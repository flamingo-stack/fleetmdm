A React SVG component that renders the EagleFiler application icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Eaglefiler`** — Default-exported functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the EagleFiler app icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Eaglefiler from "./Eaglefiler";

// Basic usage
<Eaglefiler />

// With custom size and className
<Eaglefiler width={64} height={64} className="app-icon" />

// With accessibility attributes
<Eaglefiler aria-label="EagleFiler" role="img" />
```

## Notes

- The icon image is self-contained via a base64 data URI — no external asset fetch required.
- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`), with `width={32}` and `height={32}` as defaults that can be overridden.
