React SVG wrapper component that renders the Focusrite Control 2 application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`FocusriteControl2`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Focusrite Control 2 icon via a base64 PNG `<image>` element.

## Usage Example

```typescript
import FocusriteControl2 from "./FocusriteControl2";

// Basic usage
<FocusriteControl2 />

// With custom dimensions or class
<FocusriteControl2 width={64} height={64} className="app-icon" />

// With click handler
<FocusriteControl2 onClick={() => openApp("focusrite-control-2")} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via spread to the root `<svg>` element.
- The icon graphic is self-contained — no external image assets are required at runtime.
- Default render size is **32×32px**; override via `width`/`height` props.
