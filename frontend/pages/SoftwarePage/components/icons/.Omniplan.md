A React SVG component that renders the OmniPlan application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Omniplan`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the OmniPlan logo as an SVG wrapper around an embedded PNG via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Omniplan from './Omniplan';

// Basic usage
<Omniplan />

// With custom className or style
<Omniplan className="app-icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32×32)
<Omniplan width={64} height={64} />
```

## Notes

- The icon defaults to `32×32` pixels but dimensions can be overridden via props.
- The image data is a self-contained base64 PNG (originally 512×512), so no external asset requests are made.
- All standard SVG props (e.g., `aria-label`, `role`, `onClick`) are forwarded to the root `<svg>` element.
