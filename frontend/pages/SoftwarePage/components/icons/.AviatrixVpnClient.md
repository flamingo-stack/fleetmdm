A React SVG icon component that renders the Aviatrix VPN Client logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`AviatrixVpnClient`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Aviatrix VPN Client brand icon.

## Usage Example

```typescript
import AviatrixVpnClient from "./AviatrixVpnClient";

// Basic usage
<AviatrixVpnClient />

// With custom dimensions and className
<AviatrixVpnClient width={64} height={64} className="icon" />

// With accessibility attributes
<AviatrixVpnClient aria-label="Aviatrix VPN Client" role="img" />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG `href` — no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
