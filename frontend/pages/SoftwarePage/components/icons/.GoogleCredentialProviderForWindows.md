Renders a 32×32 SVG icon for the Google Credential Provider for Windows, embedding the image as a base64-encoded PNG.

## Key Components

- **`GoogleCredentialProviderForWindows`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import GoogleCredentialProviderForWindows from "./GoogleCredentialProviderForWindows";

// Basic usage
<GoogleCredentialProviderForWindows />

// With custom size and class
<GoogleCredentialProviderForWindows width={64} height={64} className="icon" />

// With click handler
<GoogleCredentialProviderForWindows onClick={() => console.log("clicked")} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The PNG image data is self-contained as a base64 `href` on an `<image>` element — no external asset required.
