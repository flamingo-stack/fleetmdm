React SVG component that renders the Jitsi Meet logo as an inline PNG image encoded in base64, displayed at 32×32 pixels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `JitsiMeet` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG containing the Jitsi Meet brand icon as an embedded base64 PNG |

## Usage Example

```typescript
import JitsiMeet from "./JitsiMeet";

// Basic usage
<JitsiMeet />

// With custom dimensions and className
<JitsiMeet width={64} height={64} className="icon" />

// With aria label for accessibility
<JitsiMeet aria-label="Jitsi Meet" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) props, allowing full customization of the SVG element.
- The icon image is embedded as a base64-encoded PNG via an `<image>` element — no external asset request is made at runtime.
- Default render size is **32×32 px**; override with `width`/`height` props as needed.
