A React SVG component that renders the Piphero brand icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Piphero`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the wrapping `<svg>` element (e.g., `className`, `style`, `onClick`).

The component renders a fixed 32×32 `<svg>` containing an `<image>` element with the Piphero logo inlined as a base64 PNG, eliminating any external asset dependency.

## Usage Example

```typescript
import Piphero from "./Piphero";

// Basic usage
<Piphero />

// With custom sizing and styling
<Piphero width={64} height={64} className="icon" />

// With event handler
<Piphero onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The PNG payload is embedded as a base64 data URI — no network request or asset bundler configuration is required.
