A React SVG component that renders a 32×32 "Latest" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Latest`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element that displays a PNG icon via a base64-encoded `<image>` tag.

## Usage Example

```typescript
import { Latest } from "./Latest";

// Basic usage
<Latest />

// With custom styling
<Latest className="icon" style={{ opacity: 0.8 }} />

// With size override
<Latest width={64} height={64} />
```

## Notes

- The icon image is embedded as a base64 PNG (`data:image/png;base64,...`), so no external asset file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The underlying PNG is 512×512 but rendered at 32×32 by default; scaling via `width`/`height` props is supported.
