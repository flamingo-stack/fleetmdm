React SVG icon component that renders the Flux application logo as a 32×32 PNG embedded as a base64-encoded `<image>` element within an SVG wrapper.

## Key Components

- **`FluxApp`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Flux app logo as an embedded base64 PNG.

## Usage Example

```typescript
import FluxApp from "./FluxApp";

// Basic usage
<FluxApp />

// With custom dimensions and className
<FluxApp width={64} height={64} className="app-icon" />

// With style overrides
<FluxApp style={{ opacity: 0.8 }} aria-label="Flux" />
```

## Notes

- The icon is a **self-contained** component — no external image assets are required at runtime.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, allowing full customization of dimensions, accessibility attributes, and event handlers.
- The embedded PNG is encoded at 512×512 px (per EXIF metadata) and downscaled to 32×32 via the SVG `width`/`height` attributes.
