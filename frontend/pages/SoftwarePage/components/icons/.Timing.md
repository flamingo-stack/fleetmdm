A React SVG component that renders a 32×32 "Timing" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Timing`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Timing from "./Timing";

// Basic usage
<Timing />

// Custom size and color overrides
<Timing width={64} height={64} style={{ opacity: 0.8 }} />

// With className for CSS targeting
<Timing className="timing-icon" aria-label="Timing" />
```

## Notes

- The icon content is a static base64-encoded PNG embedded inside an SVG `<image>` tag — no external assets required.
- Default dimensions are `32×32` pixels but can be overridden via props.
- Located at [`https://github.com/flamingo-stack/fleetmdm/blob/main/Timing.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Timing.tsx).
