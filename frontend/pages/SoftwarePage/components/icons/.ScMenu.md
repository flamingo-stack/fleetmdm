A React SVG component that renders the Shortcut (Sc) menu icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`ScMenu`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import ScMenu from "./ScMenu";

// Basic usage
<ScMenu />

// With custom size and className
<ScMenu width={24} height={24} className="icon" />

// With click handler
<ScMenu onClick={() => openMenu()} style={{ cursor: "pointer" }} />
```

## Notes

- The icon image is embedded as a base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` tag — no external asset dependencies.
- Default dimensions are **32×32px**; override via `width`/`height` props.
