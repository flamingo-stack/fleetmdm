A React SVG icon component that renders the WorksheetCrafter application icon as an inline SVG element, embedding a 32×32 PNG image via base64 encoding.

## Key Components

- **`WorksheetCrafter`** — Default export; a functional React component that wraps a base64-encoded PNG inside an `<svg>` element. Accepts all standard SVG props via `SVGProps<SVGSVGElement>`.

## Usage Example

```typescript
import WorksheetCrafter from "./WorksheetCrafter";

// Basic usage
<WorksheetCrafter />

// With custom dimensions or className
<WorksheetCrafter width={64} height={64} className="icon" />

// With accessibility attributes
<WorksheetCrafter aria-label="WorksheetCrafter" role="img" />
```

## Notes

- The component is fully self-contained — no external image assets are required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, enabling full customization (e.g., `style`, `className`, `onClick`).
- The embedded PNG is a 512×512 source image scaled down to 32×32 via the SVG `<image>` element.
