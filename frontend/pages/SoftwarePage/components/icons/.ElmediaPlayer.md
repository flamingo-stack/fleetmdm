React SVG component that renders the Elmedia Player application icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`ElmediaPlayer`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element that embeds the Elmedia Player icon as a base64-encoded PNG via an `<image>` tag.

## Usage Example

```typescript
import ElmediaPlayer from "./ElmediaPlayer";

// Basic usage
<ElmediaPlayer />

// With custom dimensions and className
<ElmediaPlayer width={64} height={64} className="app-icon" />

// With style overrides
<ElmediaPlayer style={{ opacity: 0.8 }} />
```

## Notes

- The icon data is fully self-contained — no external image assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded to the root `<svg>` element via spread, making the component easily customizable.
- Default rendered size is **32×32 pixels**; the embedded PNG is 512×512 internally (per EXIF metadata), so scaling up via props will remain crisp.
