A React SVG icon component rendering the Adobe Acrobat Reader logo with a red background and white "A" symbol.

## Key Components

- **`AcrobatReader`** — Default export. A functional React component that renders a 32×32 SVG icon for Adobe Acrobat Reader, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import AcrobatReader from "./AcrobatReader";

// Basic usage
<AcrobatReader />

// With custom dimensions and className
<AcrobatReader width={48} height={48} className="icon" />

// With inline styles
<AcrobatReader style={{ borderRadius: 4 }} />
```

## Notes

- Accepts all native SVG props (`width`, `height`, `className`, `style`, `onClick`, etc.) via spread.
- Default viewport is `32x32`; override with `width`/`height` props as needed.
