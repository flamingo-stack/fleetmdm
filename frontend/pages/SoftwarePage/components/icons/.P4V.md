React SVG component that renders the P4V (Perforce Visual Client) application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`P4V`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 PNG icon embedded as a base64 data URI inside an `<svg>` element.

## Usage Example

```typescript
import P4V from "./P4V";

// Basic usage
<P4V />

// With custom dimensions and className
<P4V width={64} height={64} className="icon" />

// With accessibility attributes
<P4V aria-label="P4V" role="img" />
```

## Notes

- All props are forwarded directly to the underlying `<svg>` element via spread (`{...props}`), enabling full customization of attributes such as `width`, `height`, `className`, `style`, and `aria-*`.
- The icon image is self-contained (no external network requests) as the PNG is embedded as a base64 data URI.
- The internal `<image>` element has a fixed size of 32×32 pixels; scaling the outer `<svg>` via props will stretch the rendered output.
