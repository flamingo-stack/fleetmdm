A React SVG component that renders a 32×32 Biscuit icon using an embedded base64-encoded PNG image.

## Key Components

- **`Biscuit`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Biscuit from "./Biscuit";

// Basic usage
<Biscuit />

// With custom dimensions or className
<Biscuit width={64} height={64} className="icon" />

// With accessibility attributes
<Biscuit aria-label="Biscuit" role="img" />
```

> **Note:** The icon image is embedded as a base64 PNG, so no external asset file is required. The default rendered size is 32×32 pixels.
