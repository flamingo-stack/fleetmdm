React SVG icon component that renders the Splashtop Business logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`SplashtopBusiness`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Splashtop Business application icon as an embedded PNG image.

## Usage Example

```typescript
import SplashtopBusiness from "./SplashtopBusiness";

// Basic usage
<SplashtopBusiness />

// With custom dimensions or className
<SplashtopBusiness width={64} height={64} className="app-icon" />

// With accessibility attributes
<SplashtopBusiness aria-label="Splashtop Business" role="img" />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via props.
- The PNG image data is inlined as a base64 `data:` URI — no external image fetch required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
- Typically used in application/integration icon sets within the [FleetMDM integration UI](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/icons/SplashtopBusiness.tsx).
