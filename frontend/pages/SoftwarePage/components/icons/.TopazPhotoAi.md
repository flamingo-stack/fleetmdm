A React SVG icon component that renders the Topaz Photo AI application logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`TopazPhotoAi`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import TopazPhotoAi from "@/components/icons/TopazPhotoAi";

// Basic usage
<TopazPhotoAi />

// With custom className or style
<TopazPhotoAi className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32x32)
<TopazPhotoAi width={64} height={64} />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 data URI — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
