A React SVG component that renders the PureVPN brand icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Purevpn`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG with the PureVPN logo embedded as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Purevpn from "./Purevpn";

// Basic usage
<Purevpn />

// With custom className or style
<Purevpn className="icon" style={{ opacity: 0.8 }} />

// With accessible title via aria attributes
<Purevpn aria-label="PureVPN" role="img" />
```

## Notes

- The icon is self-contained — no external network requests are made; the PNG is embedded as a base64 data URI.
- Width and height default to `32` but can be overridden via props.
- Intended for use within the [Flamingo/FleetMDM](https://github.com/flamingo-stack/fleetmdm) integration icon set, likely representing a PureVPN software title or enrollment context.
