A React SVG component that renders the Netron icon as a 32×32 SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Netron`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Netron logo as an embedded base64 PNG.

## Usage Example

```typescript
import Netron from "./Netron";

// Basic usage
<Netron />

// With custom className or style
<Netron className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32x32)
<Netron width={64} height={64} />
```

## Notes

- The icon image is fully self-contained — no external assets or network requests required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element via the spread `{...props}`.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
