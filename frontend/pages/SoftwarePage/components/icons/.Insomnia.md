A React SVG component that renders the Insomnia logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Insomnia`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Insomnia API client logo as an embedded PNG.

## Usage Example

```typescript
import Insomnia from "./Insomnia";

// Basic usage
<Insomnia />

// With custom dimensions or className
<Insomnia width={64} height={64} className="my-icon" />

// With aria attributes for accessibility
<Insomnia aria-label="Insomnia" role="img" />
```

## Notes

- The image data is a hardcoded base64 PNG, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default dimensions are **32×32** pixels but can be overridden via props.
