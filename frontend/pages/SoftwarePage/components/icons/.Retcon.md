A React SVG component that renders the Retcon logo as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`Retcon`** — Default export; a functional React component wrapping an `<svg>` element that embeds a 32×32 base64-encoded PNG of the Retcon logo via an `<image>` tag.

## Usage Example

```typescript
import Retcon from "./Retcon";

// Basic usage
<Retcon />

// With custom dimensions and className
<Retcon width={64} height={64} className="my-icon" />

// With style overrides (supports all SVGProps)
<Retcon style={{ opacity: 0.8 }} aria-label="Retcon logo" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/Retcon.tsx) via prop spreading, allowing full customization of the SVG element (dimensions, class, style, event handlers, etc.).
- The embedded image is a 32×32 PNG (512×512 source resolution per EXIF metadata) encoded as a base64 data URI, making the component self-contained with no external asset dependencies.
- Default render size is **32×32 pixels**.
