SVG icon component rendering the Microsoft Excel logo with a dynamically generated gradient ID to prevent conflicts when multiple instances are rendered on the same page.

## Key Components

- **`Excel`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded directly to the underlying `<svg>` element.
- **`gradientId`** — A unique ID generated via `lodash.uniqueId` to scope the `linearGradient` definition, preventing CSS/SVG gradient ID collisions on multi-instance renders.

## Usage Example

```typescript
import Excel from "@/components/icons/Excel";

// Basic usage
<Excel width={32} height={32} />

// With custom sizing and className
<Excel
  width={24}
  height={24}
  className="mr-2"
  aria-label="Excel file"
/>
```

## Notes

- The component renders a 32×32 viewBox by default; override with `width`/`height` props.
- All spreadsheet-related green shades (`#185C37`, `#21A366`, `#107C41`, `#33C481`) match the official Microsoft Excel brand palette.
- The `linearGradient` uses `gradientUnits="userSpaceOnUse"` with three color stops to replicate Excel's icon gradient faithfully.
