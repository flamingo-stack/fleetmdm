React SVG component that renders the SF Symbols logo as an inline SVG containing a base64-encoded PNG image.

## Key Components

- **`SfSymbols`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import SfSymbols from "./SfSymbols";

// Basic usage
<SfSymbols />

// With custom dimensions and className
<SfSymbols width={64} height={64} className="my-icon" />

// With style overrides
<SfSymbols style={{ opacity: 0.8 }} aria-label="SF Symbols logo" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, style, event handlers, accessibility attributes, etc.).
- The image data is statically inlined as a base64 PNG — no external asset loading required.
- Default rendered size is **32×32 pixels**.
