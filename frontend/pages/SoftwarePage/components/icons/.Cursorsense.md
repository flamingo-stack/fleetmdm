A React SVG component that renders the Cursorsense logo as an inline SVG element containing a base64-encoded PNG image.

## Key Components

- **`Cursorsense`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG logo via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Cursorsense from "./Cursorsense";

// Basic usage
<Cursorsense />

// With custom dimensions or className
<Cursorsense width={64} height={64} className="logo-icon" />

// With style overrides
<Cursorsense style={{ opacity: 0.8 }} aria-label="Cursorsense" />
```

## Notes

- The image is self-contained — no external asset requests are made at runtime.
- The component accepts any `SVGProps<SVGSVGElement>` prop (e.g., `className`, `style`, `onClick`, `aria-*`), which are spread onto the root `<svg>` element.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
