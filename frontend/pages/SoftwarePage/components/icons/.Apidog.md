React SVG component that renders the Apidog logo as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Apidog`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Apidog from "./Apidog";

// Basic usage
<Apidog />

// With custom dimensions or className
<Apidog width={64} height={64} className="icon" />

// With accessibility attributes
<Apidog aria-label="Apidog" role="img" />
```

## Notes

- The logo is embedded as a base64 PNG `<image>` element inside the SVG, making it self-contained with no external asset dependency.
- Default size is `32×32` pixels but can be overridden via `width`/`height` props.
- All standard SVG props (e.g., `style`, `className`, `aria-*`) are supported through prop spreading.
