A React SVG component that renders a 32×32 rectangle icon using an embedded base64-encoded PNG image.

## Key Components

- **`Rectangle`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import Rectangle from "./Rectangle";

// Basic usage
<Rectangle />

// With custom dimensions and styling
<Rectangle width={64} height={64} className="my-icon" />

// With custom fill or style overrides
<Rectangle style={{ opacity: 0.8 }} aria-label="Rectangle icon" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels**.
- The visual is a static base64-encoded PNG embedded via an `<image>` tag inside the SVG — it cannot be styled with CSS `fill` or `stroke` properties.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
