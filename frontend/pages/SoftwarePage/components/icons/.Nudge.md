A React SVG component that renders the Nudge application icon as an inline base64-encoded PNG image.

## Key Components

- **`Nudge`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG containing an embedded PNG icon for the Nudge macOS application.

## Usage Example

```typescript
import Nudge from "./Nudge";

// Basic usage
<Nudge />

// With custom dimensions or className
<Nudge width={64} height={64} className="app-icon" />

// With accessibility attributes
<Nudge aria-label="Nudge" role="img" />
```

## Notes

- The PNG image data is embedded directly as a base64 `data:image/png` URI, requiring no external image assets.
- All standard `SVGProps` are spread onto the root `<svg>` element, allowing full customization of size, style, and accessibility attributes.
- Typically used in MDM UI contexts to represent the [Nudge](https://github.com/macadmins/nudge) macOS update nudge tool within the Fleet MDM interface at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
