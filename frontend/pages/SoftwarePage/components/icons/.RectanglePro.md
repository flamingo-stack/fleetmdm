A React SVG component that renders a 32×32 "RectanglePro" icon by embedding a base64-encoded PNG image inside an SVG element.

## Key Components

- **`RectanglePro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 SVG that displays an embedded PNG via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import RectanglePro from "./RectanglePro";

// Basic usage
<RectanglePro />

// With custom class or style
<RectanglePro className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides defaults via props spread)
<RectanglePro width={64} height={64} />
```

## Notes

- The component forwards all `SVGProps<SVGSVGElement>` to the root `<svg>` element, enabling full customization (e.g., `className`, `style`, `aria-*`, event handlers).
- The icon image is self-contained as a base64 PNG — no external asset dependencies.
- Default rendered size is **32×32 pixels**.
