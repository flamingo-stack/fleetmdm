A React SVG component that renders the Cyberduck application icon as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Cyberduck`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Cyberduck from "./Cyberduck";

// Basic usage
<Cyberduck />

// With custom dimensions or className
<Cyberduck width={64} height={64} className="app-icon" />

// With accessibility attributes
<Cyberduck aria-label="Cyberduck" role="img" />
```

## Notes

- The icon is rendered as a fixed 32×32 `<svg>` container with an embedded `<image>` element referencing a base64-encoded PNG data URI.
- Accepts all standard SVG props (`className`, `style`, `width`, `height`, `onClick`, etc.) via prop spreading.
- No external assets or network requests are required — the image data is fully self-contained.
