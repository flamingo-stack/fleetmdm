React SVG component that renders the OrbStack logo as an inline PNG image embedded via base64 data URI.

## Key Components

- **`OrbStack`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing the OrbStack brand icon as an embedded base64-encoded PNG.

## Usage Example

```typescript
import OrbStack from "./OrbStack";

// Basic usage
<OrbStack />

// With custom dimensions or className
<OrbStack width={64} height={64} className="my-icon" />

// With aria label for accessibility
<OrbStack aria-label="OrbStack" role="img" />
```

## Notes

- The icon is **self-contained** — no external image files or network requests required.
- The embedded image is a 128×128 PNG scaled to 32×32 via the SVG viewport.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
