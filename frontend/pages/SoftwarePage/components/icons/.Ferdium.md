A React SVG icon component that renders the Ferdium logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Ferdium`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Ferdium logo as an embedded PNG.

## Usage Example

```typescript
import Ferdium from "./Ferdium";

// Basic usage
<Ferdium />

// With custom dimensions or className
<Ferdium width={64} height={64} className="icon" />

// With style overrides
<Ferdium style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- The logo image is embedded as a base64 PNG — no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
