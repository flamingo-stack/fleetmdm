A React SVG wrapper component that renders the Iconjar application icon as an embedded PNG image (32×32px) encoded as a base64 data URI within an SVG element.

## Key Components

- **`Iconjar`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` for full prop forwarding (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Iconjar from "./Iconjar";

// Basic usage
<Iconjar />

// With custom dimensions and class
<Iconjar width={64} height={64} className="icon" />

// With click handler
<Iconjar onClick={() => console.log("clicked")} />
```

## Notes

- The icon is a **32×32** SVG containing a base64-encoded PNG, preserving crisp rendering without external file dependencies.
- All standard SVG props are forwarded via the spread `{...props}`, enabling full styling and event flexibility.
