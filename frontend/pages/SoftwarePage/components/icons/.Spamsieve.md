A React functional component that renders the SpamSieve application icon as an SVG element containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Spamsieve`** — Default export; a stateless React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.
- **Embedded image** — A 512×512 source PNG encoded as a base64 data URI, rendered inside the SVG via an `<image>` element scaled to 32×32.

## Usage Example

```typescript
import Spamsieve from "./Spamsieve";

// Basic usage
<Spamsieve />

// With custom dimensions and className
<Spamsieve width={64} height={64} className="app-icon" />

// With accessibility attributes
<Spamsieve aria-label="SpamSieve" role="img" />
```

## Notes

- Props follow the standard React SVG interface (`SVGProps<SVGSVGElement>`), so any valid SVG attribute (`width`, `height`, `className`, `style`, `aria-*`, etc.) can be passed.
- The default rendered size is **32×32 px**; override via `width`/`height` props.
- The icon image is self-contained — no external assets or network requests are required.
