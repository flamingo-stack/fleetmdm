A React SVG icon component that renders the Windsurf logo as a 32×32 pixel image, embedding the logo as a base64-encoded PNG within an SVG wrapper.

## Key Components

- **`Windsurf`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override width, height, className, style, and other SVG attributes.

## Usage Example

```typescript
import Windsurf from "./Windsurf";

// Basic usage
<Windsurf />

// With custom size and className
<Windsurf width={64} height={64} className="icon" />

// With inline style
<Windsurf style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The logo image is self-contained as a base64 PNG — no external asset dependencies.
