A React SVG component that renders the **Keepingyouawake** application icon as an embedded PNG image (32×32 pixels) encoded inline as a base64 data URI.

## Key Components

- **`Keepingyouawake`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Keepingyouawake from "./Keepingyouawake";

// Basic usage
<Keepingyouawake />

// With custom className or style
<Keepingyouawake className="app-icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Keepingyouawake width={64} height={64} />
```

## Notes

- The icon defaults to **32×32px** but dimensions can be overridden via props.
- The image is self-contained — no external asset file is required; the PNG is inlined as a base64 `data:image/png` URI within an SVG `<image>` element.
- Likely used in the Fleet MDM UI to represent the [Keepingyouawake](https://github.com/newmarcel/KeepingYouAwake) macOS utility as a managed application icon.
