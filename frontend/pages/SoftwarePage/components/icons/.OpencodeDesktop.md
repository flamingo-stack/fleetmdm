A React SVG component that renders the Opencode Desktop application icon as an inline SVG containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`OpencodeDesktop`** — Default-exported React functional component that renders an `<svg>` element wrapping an `<image>` tag with a base64-encoded PNG as its `href`. Accepts all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import OpencodeDesktop from "./OpencodeDesktop";

// Basic usage
<OpencodeDesktop />

// With custom size and className
<OpencodeDesktop width={64} height={64} className="icon" />

// With inline styles
<OpencodeDesktop style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32px**; override via `width`/`height` props.
- The icon image is self-contained — no external asset requests are made.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>`, enabling `aria-*`, `role`, `onClick`, and other standard SVG attributes.
