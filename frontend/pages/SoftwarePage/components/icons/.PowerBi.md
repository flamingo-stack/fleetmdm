A React SVG component that renders the Power BI logo as an inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`PowerBi`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Power BI brand icon as an embedded base64 PNG.

## Usage Example

```typescript
import PowerBi from './PowerBi';

// Basic usage
<PowerBi />

// With custom size and className
<PowerBi width={48} height={48} className="icon" />

// With aria label for accessibility
<PowerBi aria-label="Power BI" role="img" />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- The icon image is self-contained — no external asset dependencies at runtime.
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`) via prop spreading.
