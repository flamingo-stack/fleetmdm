A React SVG component that renders the VNC Viewer application icon as an inline base64-encoded PNG image.

## Key Components

- **`VncViewer`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 VNC Viewer logo embedded as a base64 PNG within an `<svg>` element.

## Usage Example

```typescript
import VncViewer from "./VncViewer";

// Basic usage
<VncViewer />

// With custom dimensions and className
<VncViewer width={64} height={64} className="app-icon" />

// With accessibility attributes
<VncViewer aria-label="VNC Viewer" role="img" />
```

## Notes

- The icon image is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The inner `<image>` element is fixed at 32×32px; scaling should be applied via the outer SVG props.
