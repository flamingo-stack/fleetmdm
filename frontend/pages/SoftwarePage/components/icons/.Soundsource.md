A React SVG component that renders the SoundSource application icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Soundsource`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a 32×32 SVG wrapping a base64 PNG icon.

## Usage Example

```typescript
import Soundsource from "./Soundsource";

// Basic usage
<Soundsource />

// With custom dimensions or className
<Soundsource width={64} height={64} className="app-icon" />

// With accessibility attributes
<Soundsource aria-label="SoundSource" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making this component fully customizable.
- The icon is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
