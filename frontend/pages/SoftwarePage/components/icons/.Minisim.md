A React SVG component that renders the Minisim icon as a 32×32 inline SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Minisim`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64 PNG image asset.

## Usage Example

```typescript
import Minisim from "./Minisim";

// Basic usage
<Minisim />

// With custom dimensions or className
<Minisim width={64} height={64} className="icon" />

// With inline styles
<Minisim style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external asset requests are made at runtime.
- Default dimensions are `32×32` pixels but can be overridden via props.
