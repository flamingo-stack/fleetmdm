A React SVG component that renders the Lunatask logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Lunatask`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG logo via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import Lunatask from "./Lunatask";

// Basic usage
<Lunatask />

// With custom size and className
<Lunatask width={64} height={64} className="logo-icon" />

// With ARIA label for accessibility
<Lunatask aria-label="Lunatask" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread, making it fully composable.
- The rendered dimensions default to `32×32` but can be overridden via `width`/`height` props.
