React SVG icon component that renders the ProtonMail logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`ProtonMail`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`. Renders a 32×32 SVG element containing an embedded base64 PNG of the ProtonMail logo.

## Usage Example

```typescript
import ProtonMail from "./ProtonMail";

// Basic usage
<ProtonMail />

// With custom className or style overrides
<ProtonMail className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<ProtonMail width={64} height={64} />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
- The logo is embedded as a base64 PNG `<image>` — no external network request required.
