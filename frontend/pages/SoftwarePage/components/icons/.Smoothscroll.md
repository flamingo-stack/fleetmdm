A React SVG component that renders the Smoothscroll brand icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Smoothscroll`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing an embedded PNG logo.

## Usage Example

```typescript
import Smoothscroll from "./Smoothscroll";

// Basic usage
<Smoothscroll />

// With custom dimensions and className
<Smoothscroll width={64} height={64} className="icon" />

// With onClick handler
<Smoothscroll onClick={() => console.log("clicked")} />
```

## Notes

- The icon is rendered at **32×32 pixels** by default but can be overridden via props.
- The image source is a **self-contained base64 PNG** — no external network requests are made.
- Accepts all standard `SVGProps<SVGSVGElement>` attributes (e.g., `className`, `style`, `onClick`, `aria-*`).
