React SVG component that renders the Lasso application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`LassoApp`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded 512×512 PNG (downscaled via the SVG viewport).

## Usage Example

```typescript
import LassoApp from "./LassoApp";

// Basic usage
<LassoApp />

// With custom dimensions or className
<LassoApp width={64} height={64} className="app-icon" />

// As an image with accessible label
<LassoApp aria-label="Lasso application" role="img" />
```

## Notes

- The PNG asset is embedded directly as a base64 `data:image/png` URI — no external file dependency required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}` pattern.
