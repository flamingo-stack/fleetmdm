A React SVG icon component that renders the Twingate logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Twingate`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Twingate brand logo as an embedded PNG.

## Usage Example

```typescript
import Twingate from "@/components/icons/Twingate";

// Basic usage
<Twingate />

// With custom dimensions and className
<Twingate width={24} height={24} className="icon" />

// With accessibility attributes
<Twingate aria-label="Twingate" role="img" />
```

## Notes

- Default rendered size is **32×32** pixels, overridable via `width`/`height` props.
- The logo is embedded as a base64 PNG via an `<image>` element — no external network request is made.
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) via prop spreading.
