React SVG icon component that renders the Minstaller application icon as a 32×32 PNG embedded via base64 within an SVG wrapper.

## Key Components

- **`Minstaller`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64-encoded PNG image.

## Usage Example

```typescript
import Minstaller from "./Minstaller";

// Basic usage
<Minstaller />

// With custom dimensions or className
<Minstaller width={64} height={64} className="icon" />

// With accessibility attributes
<Minstaller aria-label="Minstaller" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external image dependencies.
- Default rendered size is **32×32px**; override via `width`/`height` props.
