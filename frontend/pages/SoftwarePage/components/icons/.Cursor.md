A React SVG component that renders a cursor icon as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Cursor`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 cursor icon via an embedded base64 PNG image.

## Usage Example

```typescript
import Cursor from './Cursor';

// Basic usage
<Cursor />

// With custom size and styling
<Cursor width={64} height={64} className="cursor-icon" />

// With event handlers
<Cursor onClick={() => console.log('clicked')} style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) via spread.
- The icon image is self-contained as a base64-encoded PNG — no external assets or network requests required.
- Default rendered size is **32×32px**.
