React SVG icon component that renders the Debookee application logo as a 32×32 pixel image using a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`Debookee`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper containing an embedded base64 PNG icon.

## Usage Example

```typescript
import Debookee from "./Debookee";

// Basic usage
<Debookee />

// With custom dimensions or className
<Debookee width={64} height={64} className="app-icon" />

// With accessibility attributes
<Debookee aria-label="Debookee" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external asset fetches required.
- Default render size is **32×32px**; override with `width`/`height` props.
