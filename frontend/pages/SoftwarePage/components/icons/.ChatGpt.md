SVG icon component that renders the ChatGPT logo as an inline base64-encoded PNG image embedded within an SVG element.

## Key Components

- **`ChatGpt`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the ChatGPT logo via a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import ChatGpt from './ChatGpt';

// Basic usage
<ChatGpt />

// With custom dimensions or className
<ChatGpt width={24} height={24} className="icon" />

// With accessibility attributes
<ChatGpt aria-label="ChatGPT" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via spread to the root `<svg>` element.
- The default render size is **32×32 pixels**; override with `width`/`height` props as needed.
- The image data is self-contained — no external network request is made at render time.
