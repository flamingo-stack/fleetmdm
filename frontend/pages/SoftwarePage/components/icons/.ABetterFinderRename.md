A React SVG component that renders the "A Better Finder Rename" application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`ABetterFinderRename`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the app icon as an embedded PNG image.

## Usage Example

```typescript
import ABetterFinderRename from "./ABetterFinderRename";

// Basic usage
<ABetterFinderRename />

// With custom dimensions or className
<ABetterFinderRename width={64} height={64} className="app-icon" />

// With accessibility attributes
<ABetterFinderRename aria-label="A Better Finder Rename" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via `width` and `height` props.
- The PNG image data is fully self-contained as a base64-encoded data URI — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
