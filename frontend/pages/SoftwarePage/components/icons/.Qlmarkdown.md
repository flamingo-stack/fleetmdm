A React SVG icon component that renders the QLMarkdown application icon as a 32×32 embedded PNG image within an SVG wrapper.

## Key Components

- **`Qlmarkdown`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a base64-encoded PNG of the QLMarkdown app icon.

## Usage Example

```typescript
import Qlmarkdown from "./Qlmarkdown";

// Basic usage
<Qlmarkdown />

// With custom dimensions or className
<Qlmarkdown width={64} height={64} className="app-icon" />

// With accessibility attributes
<Qlmarkdown aria-label="QLMarkdown" role="img" />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG data URI — no external asset requests.
- All props are forwarded to the root `<svg>` element, enabling full SVG attribute customization (e.g., `className`, `style`, `onClick`).
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
