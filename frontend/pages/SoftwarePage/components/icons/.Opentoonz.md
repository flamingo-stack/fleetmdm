A React component that renders the Opentoonz application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Opentoonz`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Opentoonz logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Opentoonz from "./Opentoonz";

// Basic usage
<Opentoonz />

// With custom dimensions or class
<Opentoonz width={64} height={64} className="app-icon" />

// With accessibility attributes
<Opentoonz aria-label="Opentoonz" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external image assets or network requests are required.
- Default rendered size is **32×32px**; the embedded PNG source is **512×512px**, so scaling up via props retains quality.
