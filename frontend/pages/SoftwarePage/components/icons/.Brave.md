A React SVG icon component that renders the Brave browser logo as a scalable vector graphic with gradient fills.

## Key Components

- **`Brave`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `width`, `height`, `className`, `style`).
- **`clipPathId` / `fillPathId`** — Unique IDs generated via `lodash.uniqueId` to prevent conflicts when multiple instances are rendered on the same page.

## Usage Example

```typescript
import Brave from "./Brave";

// Basic usage
<Brave width={32} height={32} />

// With custom sizing and className
<Brave width={24} height={24} className="browser-icon" />

// Inline style override
<Brave style={{ width: "2rem", height: "2rem" }} />
```

## Notes

- Default canvas is **32×32px** (set via the inner `<rect>`); override via `width`/`height` props.
- The logo uses two **linear gradients** (orange-to-red: `#FF5500` → `#FF2000` and `#FF452A` → `#FF2000`) applied via a shared `fillPathId`, plus a `clipPath` for masking.
- Unique ID generation ensures safe use in **server-side rendering** or pages with **multiple icon instances** without DOM ID collisions.
