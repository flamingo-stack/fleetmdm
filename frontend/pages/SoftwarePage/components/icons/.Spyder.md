A React SVG icon component that renders the Spyder IDE logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Spyder`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded Spyder IDE logo.

## Usage Example

```typescript
import Spyder from './Spyder';

// Basic usage
<Spyder />

// With custom dimensions and className
<Spyder width={64} height={64} className="icon" />

// With accessibility attributes
<Spyder aria-label="Spyder IDE" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external asset files are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
