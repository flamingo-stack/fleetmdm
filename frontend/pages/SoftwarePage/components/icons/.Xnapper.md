React SVG wrapper component that renders the Xnapper app icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Xnapper`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 `<svg>` element with an embedded base64 PNG via an `<image>` tag.

## Usage Example

```typescript
import Xnapper from "./Xnapper";

// Basic usage
<Xnapper />

// With custom className or style
<Xnapper className="app-icon" style={{ opacity: 0.8 }} />

// With aria label for accessibility
<Xnapper aria-label="Xnapper" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Width and height default to `32` but can be overridden through props.
