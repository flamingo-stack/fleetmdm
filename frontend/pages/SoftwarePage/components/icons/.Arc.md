React SVG icon component that renders the Arc browser logo as an inline PNG embedded via a base64-encoded `<image>` element within an SVG wrapper.

## Key Components

- **`Arc`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Arc browser logo as a base64-encoded PNG image.

## Usage Example

```typescript
import Arc from './Arc';

// Basic usage
<Arc />

// With custom size and className
<Arc width={64} height={64} className="icon" />

// With inline styles
<Arc style={{ opacity: 0.8 }} />
```

## Notes

- The logo is rendered at a fixed **32×32** default size but can be overridden via `width`/`height` props.
- The image data is fully self-contained — no external network request is made.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element via spread.
