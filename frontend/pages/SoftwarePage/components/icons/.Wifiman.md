A React SVG component that renders the WifiMan application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Wifiman`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the WifiMan logo as an inline SVG with an embedded PNG `<image>` element.

## Usage Example

```typescript
import Wifiman from "./Wifiman";

// Basic usage
<Wifiman />

// With custom dimensions or className
<Wifiman width={64} height={64} className="app-icon" />

// With accessibility attributes
<Wifiman aria-label="WifiMan" role="img" />
```

## Notes

- The icon is rendered at a native size of **32×32px** but can be overridden via `width`/`height` props.
- The PNG data is inlined as a base64 `data:image/png` URI, meaning no external image file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
