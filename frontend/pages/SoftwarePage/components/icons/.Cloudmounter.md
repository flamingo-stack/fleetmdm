A React SVG component that renders the Cloudmounter application icon as an inline PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Cloudmounter`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing the Cloudmounter app icon as an embedded PNG.

## Usage Example

```typescript
import Cloudmounter from "./Cloudmounter";

// Basic usage
<Cloudmounter />

// With custom dimensions or className
<Cloudmounter width={64} height={64} className="app-icon" />

// With accessibility attributes
<Cloudmounter aria-label="Cloudmounter" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32** pixels but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 `data:image/png` URI, so no external image asset is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
