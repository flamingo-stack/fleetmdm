A React SVG component that renders the Boom3D application icon as a 32×32 inline SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Boom3D`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG icon image.

## Usage Example

```typescript
import Boom3D from "./Boom3D";

// Basic usage
<Boom3D />

// With custom dimensions or className
<Boom3D width={64} height={64} className="app-icon" />

// With accessibility attributes
<Boom3D aria-label="Boom3D" role="img" />
```

## Notes

- The icon image is embedded as a base64 PNG (`data:image/png;base64,...`) within an SVG `<image>` element — no external network request is made at runtime.
- The source PNG is 512×512 pixels (per embedded EXIF metadata) downscaled to 32×32 for display.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Located in the Flamingo Stack fleet MDM icon set: [`Boom3D.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Boom3D.tsx)
