A React SVG component that renders the MacJournal application icon as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Macjournal`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import Macjournal from "./Macjournal";

// Basic usage
<Macjournal />

// With custom dimensions or className
<Macjournal width={64} height={64} className="app-icon" />

// With accessibility attributes
<Macjournal aria-label="MacJournal" role="img" />
```

## Notes

- The icon image is fully self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
