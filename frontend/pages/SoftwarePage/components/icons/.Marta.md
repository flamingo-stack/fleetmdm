A React SVG component that renders the "Marta" icon as an inline SVG element embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Marta`** — Default export. A functional React component wrapping an `<svg>` element that renders a 32×32 base64-encoded PNG via an `<image>` tag.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, aria attributes, event handlers, etc.).

## Usage Example

```typescript
import Marta from "./Marta";

// Basic usage
<Marta />

// With custom size and class
<Marta width={64} height={64} className="my-icon" />

// With accessibility attributes
<Marta aria-label="Marta icon" role="img" />
```

## Notes

- The embedded PNG is a 512×512 image downscaled to 32×32 via SVG attributes.
- No external asset dependencies — the image data is fully self-contained in the component.
- Drop-in compatible with any icon system that consumes `SVGProps`.
