A React SVG component that renders the Tabtab logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Tabtab`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG wrapper around a base64 PNG `<image>` element.

## Usage Example

```typescript
import Tabtab from "./Tabtab";

// Basic usage
<Tabtab />

// With custom className or style
<Tabtab className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Tabtab width={64} height={64} />
```

## Notes

- The icon is embedded as a base64-encoded PNG (512×512 source), downscaled to 32×32 via the SVG viewport — no external asset requests at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded via spread (`{...props}`).
