SVG icon component that renders the GoToMeeting logo as an inline PNG image embedded in an SVG wrapper.

## Key Components

- **`GoToMeeting`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the GoToMeeting brand logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import GoToMeeting from "./GoToMeeting";

// Basic usage
<GoToMeeting />

// With custom dimensions or className
<GoToMeeting width={64} height={64} className="icon" />

// With accessibility attributes
<GoToMeeting aria-label="GoToMeeting" role="img" />
```

## Notes

- The icon defaults to `32×32` pixels but can be overridden via `width`/`height` props.
- The logo image is fully self-contained as a base64 PNG — no external asset requests at runtime.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
