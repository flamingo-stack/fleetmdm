SVG icon component that renders the Aptakube logo as an inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Aptakube`** — Default export. A React functional component that renders a 32×32 SVG element containing a base64-encoded PNG of the Aptakube logo. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Aptakube from "./Aptakube";

// Basic usage
<Aptakube />

// With custom styling
<Aptakube className="icon" style={{ opacity: 0.8 }} />

// With size override
<Aptakube width={64} height={64} />
```

## Notes

- The default rendered size is **32×32 pixels**, matching both the outer `<svg>` and the inner `<image>` element.
- The logo image is fully self-contained — no external asset fetch is required at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded via spread.
