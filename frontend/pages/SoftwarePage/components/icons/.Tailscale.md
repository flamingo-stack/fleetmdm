React SVG component that renders the Tailscale brand icon as a 32×32 inline image embedded via a base64-encoded PNG data URI.

## Key Components

- **`Tailscale`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a `<svg>` wrapper containing the Tailscale logo as an embedded PNG.

## Usage Example

```typescript
import Tailscale from "./Tailscale";

// Basic usage
<Tailscale />

// With custom className or style overrides
<Tailscale className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions (overrides default 32×32)
<Tailscale width={64} height={64} />
```

## Notes

- Default size is **32×32px**, controlled by the `width` and `height` props on the outer `<svg>` element.
- The icon is self-contained — no external image files or network requests are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element via spread.
