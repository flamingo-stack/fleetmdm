A React SVG component that renders the Superwhisper app icon as a 32×32 embedded PNG image within an SVG wrapper.

## Key Components

- **`Superwhisper`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Superwhisper logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Superwhisper from "./Superwhisper";

// Basic usage
<Superwhisper />

// With custom dimensions or className
<Superwhisper width={64} height={64} className="app-icon" />

// With ARIA label for accessibility
<Superwhisper aria-label="Superwhisper" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32px**; the embedded PNG source is **512×512px**, so the component scales cleanly to larger sizes.
