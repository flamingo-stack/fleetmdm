A React SVG component that renders the Google Drive icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`GoogleDrive`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Google Drive icon.

## Usage Example

```typescript
import GoogleDrive from './GoogleDrive';

// Basic usage
<GoogleDrive />

// With custom size or className
<GoogleDrive width={64} height={64} className="icon" />

// With style overrides
<GoogleDrive style={{ opacity: 0.8 }} />
```

## Notes

- The icon is embedded as a base64 PNG (`data:image/png;base64,...`) inside an `<image>` element, making it self-contained with no external asset dependencies.
- Default dimensions are **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
