SVG icon component that renders the Superhuman email client logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Superhuman`** — Default export. A React functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Superhuman logo as an inline base64 PNG image.

## Usage Example

```typescript
import Superhuman from "./Superhuman";

// Basic usage
<Superhuman />

// With custom dimensions or className
<Superhuman width={64} height={64} className="icon" />

// With accessibility attributes
<Superhuman aria-label="Superhuman" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The logo image is embedded as a **base64-encoded PNG** (`data:image/png;base64,...`), meaning no external network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
