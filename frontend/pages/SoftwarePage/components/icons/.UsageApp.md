A React SVG component that renders the "Usage" app icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`UsageApp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import UsageApp from "./UsageApp";

// Basic usage
<UsageApp />

// With custom dimensions or className
<UsageApp width={64} height={64} className="app-icon" />

// With onClick handler
<UsageApp onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via props.
- The PNG image data is embedded as a base64 `data:image/png` URI, so no external image assets are required.
