React SVG icon component that renders the AirDroid brand logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Airdroid` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component for the AirDroid brand logo |

## Usage Example

```typescript
import Airdroid from './Airdroid';

// Basic usage
<Airdroid />

// With custom dimensions
<Airdroid width={64} height={64} />

// With additional SVG props
<Airdroid className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32px**
- Accepts all standard [`SVGProps<SVGSVGElement>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/svg) props for customization
- The icon is self-contained — no external image dependencies; the PNG is embedded as a base64 `data:image/png` URI inside an SVG `<image>` element
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Airdroid.tsx)
