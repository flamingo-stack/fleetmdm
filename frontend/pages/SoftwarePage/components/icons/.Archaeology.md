React SVG icon component that renders an Archaeology emoji/icon as an inline PNG image encoded in base64 format.

## Key Components

- **`Archaeology`** — Default export; a functional React component that wraps a base64-encoded PNG inside an `<svg>` element
- **SVGProps** — Accepts all standard SVG element props (e.g., `className`, `style`, `onClick`, `aria-*`) via TypeScript's `SVGProps<SVGSVGElement>` spread

## Usage Example

```typescript
import Archaeology from "./Archaeology";

// Basic usage
<Archaeology />

// With custom dimensions or styling
<Archaeology width={64} height={64} className="my-icon" />

// With event handler
<Archaeology onClick={() => console.log("clicked")} aria-label="Archaeology icon" />
```

## Notes

- Default rendered size is **32×32 pixels**
- The image data is a self-contained base64 PNG — no external asset loading required
- The component lives at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) and follows the project's standard SVG icon pattern
