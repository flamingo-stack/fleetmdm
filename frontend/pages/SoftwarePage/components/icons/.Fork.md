React SVG icon component that renders a Fork icon using an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Fork`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG element containing an inline base64 PNG image of a fork icon.

## Usage Example

```typescript
import Fork from "./Fork";

// Basic usage
<Fork />

// With custom dimensions and styling
<Fork width={24} height={24} className="icon" />

// With click handler
<Fork onClick={() => console.log("fork clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The image data is embedded as a **base64 PNG**, so no external assets are required.
- Accepts all standard [`SVGProps`](https://react.dev/reference/react-dom/components/svg) for full flexibility (e.g., `className`, `style`, `aria-*`, event handlers).
