A React SVG component that renders the Home Assistant logo as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`HomeAssistant`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering the Home Assistant brand icon via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import HomeAssistant from "./HomeAssistant";

// Basic usage
<HomeAssistant />

// With custom dimensions or styling
<HomeAssistant width={64} height={64} className="icon" />

// With an aria-label for accessibility
<HomeAssistant aria-label="Home Assistant" role="img" />
```

## Notes

- The icon is fixed at 32×32px by default but can be overridden via props.
- The image data is fully self-contained (no external network requests).
- Accepts all standard SVG element props (e.g., `className`, `style`, `onClick`).
