SVG icon component that renders the Advanced Renamer application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`AdvancedRenamer`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`)

## Usage Example

```typescript
import AdvancedRenamer from "./AdvancedRenamer";

// Basic usage
<AdvancedRenamer />

// With custom dimensions and className
<AdvancedRenamer width={64} height={64} className="app-icon" />

// With click handler
<AdvancedRenamer onClick={() => console.log("clicked")} />
```

## Notes

- Renders at **32×32px** by default
- The icon image is a **512×512 PNG** embedded as a base64 data URI, downscaled via SVG `<image>` to 32×32
- All standard SVG props are spread onto the root `<svg>` element, making size and style fully customizable at the call site
