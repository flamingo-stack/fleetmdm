React SVG icon component that renders the Onlyoffice logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Onlyoffice` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component for the Onlyoffice brand logo |

## Usage Example

```typescript
import Onlyoffice from "./Onlyoffice";

// Basic usage
<Onlyoffice />

// With custom dimensions or className
<Onlyoffice width={64} height={64} className="my-icon" />

// With accessibility attributes
<Onlyoffice aria-label="Onlyoffice" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, enabling full customization (size, color overrides, event handlers, etc.)
- The logo is rendered as a `<image>` element with a base64 PNG `href`, so CSS `fill`/`stroke` overrides will **not** affect its appearance
- Default dimensions: `32×32` pixels
