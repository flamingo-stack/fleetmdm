A React SVG component that renders the Airy brand/integration logo as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Airy`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Airy logo as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Airy from "./Airy";

// Basic usage
<Airy />

// With custom dimensions or className
<Airy width={64} height={64} className="integration-logo" />

// With accessibility attributes
<Airy aria-label="Airy" role="img" />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, allowing full customization (e.g., `className`, `style`, `onClick`, `aria-*`).
- The logo image is self-contained — no external image assets or network requests are required at runtime.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
