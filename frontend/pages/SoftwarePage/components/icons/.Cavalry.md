React SVG icon component that renders the Cavalry logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Cavalry`** — Default export. A functional React component that wraps an `<svg>` element containing a base64-encoded PNG image of the Cavalry logo at 32×32 pixels.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-label`).

## Usage Example

```typescript
import Cavalry from "./Cavalry";

// Basic usage
<Cavalry />

// With custom size and class
<Cavalry width={64} height={64} className="icon" />

// With accessibility label
<Cavalry aria-label="Cavalry logo" role="img" />
```

## Notes

- The image content is statically embedded as a base64 PNG, so no external asset requests are made.
- Default dimensions are `32×32` pixels but can be overridden via `width` and `height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
