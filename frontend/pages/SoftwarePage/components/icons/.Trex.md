A React SVG wrapper component that renders a T-Rex dinosaur icon as an embedded PNG image (32×32 pixels) encoded in base64.

## Key Components

- **`Trex`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded base64-encoded PNG of a T-Rex dinosaur icon.

## Usage Example

```typescript
import Trex from "./Trex";

// Basic usage
<Trex />

// With custom dimensions and className
<Trex width={64} height={64} className="icon" />

// With accessibility attributes
<Trex aria-label="T-Rex dinosaur" role="img" />
```

## Notes

- The image data is fully self-contained via a base64-encoded PNG — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
