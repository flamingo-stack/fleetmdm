React SVG icon component that renders the Evernote brand logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Evernote`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props
- Renders a 32×32 SVG containing an embedded base64 PNG of the Evernote logo
- Props are spread onto the root `<svg>` element, enabling className, style, onClick, aria-*, and other SVG attributes

## Usage Example

```typescript
import Evernote from "./Evernote";

// Basic usage
<Evernote />

// With custom dimensions and styling
<Evernote
  width={48}
  height={48}
  className="icon"
  aria-label="Evernote"
/>

// With click handler
<Evernote onClick={() => window.open("https://evernote.com")} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props
- The logo image is self-contained (base64-encoded PNG) — no external asset fetch required
- Part of the icon set in the Flamingo/FleetMDM integration UI
