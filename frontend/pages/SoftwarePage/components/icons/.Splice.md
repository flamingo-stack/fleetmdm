A React SVG icon component that renders the Splice brand logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Splice`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Splice logo as an embedded PNG.

## Usage Example

```typescript
import Splice from "./Splice";

// Basic usage
<Splice />

// With custom dimensions and className
<Splice width={64} height={64} className="icon" />

// With inline styles
<Splice style={{ opacity: 0.8 }} />
```

## Notes

- Rendered at a default size of **32×32 pixels**; override via `width`/`height` props.
- The logo image is embedded as a base64-encoded PNG — no external asset requests required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
