React SVG icon component that renders the XnConvert application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Xnconvert`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the XnConvert app icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Xnconvert from "./Xnconvert";

// Basic usage
<Xnconvert />

// With custom dimensions or className
<Xnconvert width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Xnconvert aria-label="XnConvert" role="img" />
```

## Notes

- The icon is a **32×32** pixel asset embedded directly as a base64 PNG — no external image requests required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread to the root `<svg>` element.
