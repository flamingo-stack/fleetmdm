React SVG component that renders the Elgato Stream Deck brand logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`ElgatoStreamDeck`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element with an embedded base64 PNG via an `<image>` tag.

## Usage Example

```typescript
import ElgatoStreamDeck from "./ElgatoStreamDeck";

// Basic usage
<ElgatoStreamDeck />

// With custom dimensions and className
<ElgatoStreamDeck width={64} height={64} className="device-icon" />

// With inline styles
<ElgatoStreamDeck style={{ opacity: 0.8 }} aria-label="Elgato Stream Deck" />
```

## Notes

- The icon is self-contained — no external image assets are required.
- All standard SVG props (`width`, `height`, `className`, `style`, `onClick`, etc.) are forwarded to the root `<svg>` element.
- Default rendered size is **32×32px**; override via `width`/`height` props.
