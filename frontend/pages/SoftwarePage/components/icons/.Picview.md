A React SVG component that renders a 32×32 "Picview" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Picview`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around a base64-encoded PNG icon.

## Usage Example

```typescript
import Picview from "./Picview";

// Basic usage
<Picview />

// With custom dimensions or className
<Picview width={64} height={64} className="my-icon" />

// With accessibility attributes
<Picview aria-label="Pic view" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `width`, `height`) are spread onto the root `<svg>` element, making it fully customizable.
- The icon image is inlined as a base64 PNG (512×512 source, scaled to 32×32), so no external asset requests are made.
