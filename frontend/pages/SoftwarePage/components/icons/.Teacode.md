A React SVG component that renders the Teacode application icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Teacode`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Teacode from './Teacode';

// Basic usage
<Teacode />

// With custom dimensions or className
<Teacode width={64} height={64} className="icon" />

// With accessibility attributes
<Teacode aria-label="Teacode" role="img" />
```

## Notes

- The icon is rendered via an embedded `<image>` element with a base64-encoded PNG data URI, making it self-contained with no external image dependencies.
- Default rendered size is **32×32px**; override with `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
