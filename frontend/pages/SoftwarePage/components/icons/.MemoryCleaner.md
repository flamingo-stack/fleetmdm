A React SVG component that renders a Memory Cleaner icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`MemoryCleaner`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props
- Renders a 32×32 SVG element containing a `<image>` tag with an embedded base64-encoded PNG (512×512 source, downscaled to 32×32)
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread

## Usage Example

```typescript
import MemoryCleaner from "./MemoryCleaner";

// Basic usage
<MemoryCleaner />

// With custom dimensions and styling
<MemoryCleaner width={64} height={64} className="icon" style={{ opacity: 0.8 }} />

// With click handler
<MemoryCleaner onClick={() => console.log("clicked")} />
```

## Notes

- The component is designed as a static icon; no internal state or side effects
- The base64 PNG carries embedded EXIF metadata indicating a 512×512 sRGB source image
