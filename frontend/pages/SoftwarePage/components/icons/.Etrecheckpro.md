React SVG component that renders the EtreCheckPro application icon as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Etrecheckpro`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a 32×32 SVG wrapper containing an embedded PNG icon via a base64 data URI.

## Usage Example

```typescript
import Etrecheckpro from "./Etrecheckpro";

// Basic usage
<Etrecheckpro />

// With custom dimensions or className
<Etrecheckpro width={64} height={64} className="app-icon" />

// With accessibility attributes
<Etrecheckpro aria-label="EtreCheckPro" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the `<svg>` element via spread.
- The icon image is embedded as a base64 PNG — no external asset dependency at runtime.
- Default rendered size is `32×32`; override by passing `width`/`height` props.
