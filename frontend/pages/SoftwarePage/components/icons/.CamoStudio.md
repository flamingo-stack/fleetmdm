A React SVG component that renders the Camo Studio application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`CamoStudio`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a 512×512 PNG icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import CamoStudio from "./CamoStudio";

// Basic usage
<CamoStudio />

// With custom dimensions or className
<CamoStudio width={64} height={64} className="app-icon" />

// With style overrides
<CamoStudio style={{ borderRadius: 8 }} />
```

## Notes

- The component passes all `SVGProps` through to the root `<svg>` element, supporting standard SVG attributes (`width`, `height`, `className`, `style`, `onClick`, etc.).
- The icon image is embedded as a base64-encoded PNG (no external network request required), making this component fully self-contained.
- Default rendered size is **32×32px**; the embedded image source is **512×512px**, so scaling up via props retains visual quality.
- Typically used in UI contexts where the Camo Studio integration is represented — such as device lists, app selectors, or software inventory views within the [FleetMDM interface](https://github.com/flamingo-stack/fleetmdm).
