React SVG icon component that renders the PDFsam Basic application logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`PdfsamBasic`** — A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper containing a base64-encoded PNG of the PDFsam Basic logo.

## Usage Example

```typescript
import { PdfsamBasic } from "./PdfsamBasic";

// Basic usage
<PdfsamBasic />

// With custom dimensions
<PdfsamBasic width={64} height={64} />

// With additional SVG props
<PdfsamBasic className="app-icon" aria-label="PDFsam Basic" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes.
- The icon image is embedded as a base64 PNG (originally 512×512), downscaled to 32×32 at render time.
- Default dimensions are `width={32}` and `height={32}` but can be overridden via props.
