A React SVG component that renders the TickTick app icon as a 32×32 inline PNG image embedded as a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Ticktick`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full customization of SVG attributes (e.g., `className`, `style`, `aria-*`).

## Usage Example

```typescript
import Ticktick from "./Ticktick";

// Basic usage
<Ticktick />

// With custom size and class
<Ticktick width={64} height={64} className="app-icon" />

// With accessibility label
<Ticktick aria-label="TickTick" role="img" />
```

## Notes

- The icon is rendered as a 32×32 SVG by default using an embedded PNG (base64 data URI), so no external image assets are required.
- All standard SVG props are forwarded via spread (`{...props}`), making it easy to override dimensions, add styles, or attach event handlers.
- Since the image is base64-embedded, this component adds payload weight — consider lazy loading or sprite sheets in icon-heavy UIs.
