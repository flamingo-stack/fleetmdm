`Zed.tsx` is a React SVG icon component that renders the Zed editor logo as a 32×32 pixel image using an embedded base64-encoded PNG. It accepts standard SVG props for customization and forwards them to the root `<svg>` element.

## Key Components

- **`Zed`** — Default export; a functional React component that renders a 32×32 `<svg>` containing an `<image>` element with an inline base64 PNG of the Zed editor icon.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>`, allowing consumers to override width, height, className, style, aria attributes, and other SVG attributes.

## Usage Example

```typescript
import Zed from "./Zed";

// Basic usage
<Zed />

// Custom size and className
<Zed width={64} height={64} className="icon-zed" />

// With aria label for accessibility
<Zed aria-label="Zed Editor" role="img" />
```

## Notes

- The PNG asset is embedded as a base64 data URI, so no external image file is required — the component is fully self-contained.
- Default dimensions are `32×32` pixels but can be overridden via props.
- This pattern is common in icon libraries where each editor/tool integration is represented as a standalone component (e.g., alongside `VSCode.tsx`, `Cursor.tsx`).
