A React SVG component that renders the Fing brand icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Fing`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` wrapper containing an embedded PNG image.

## Usage Example

```typescript
import Fing from "./Fing";

// Basic usage
<Fing />

// With custom dimensions or className
<Fing width={64} height={64} className="icon" />

// With style overrides
<Fing style={{ opacity: 0.8 }} aria-label="Fing" />
```

## Notes

- The icon is fixed at a natural size of **32×32 pixels** but can be overridden via props.
- The image is self-contained (no external network requests) thanks to the base64-encoded PNG `href`.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
