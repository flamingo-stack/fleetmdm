A React SVG component that renders the OkJSON application icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`OkJson`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that contains an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import OkJson from "./OkJson";

// Basic usage
<OkJson />

// With custom size or className
<OkJson width={64} height={64} className="app-icon" />

// With accessibility attributes
<OkJson aria-label="OkJSON" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external asset fetch is required.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
