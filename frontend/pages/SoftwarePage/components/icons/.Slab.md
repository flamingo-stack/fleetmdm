A React component that renders the Slab logo as an SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Slab`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import Slab from "./Slab";

// Basic usage
<Slab />

// With custom dimensions and className
<Slab width={64} height={64} className="logo-icon" />

// With style overrides
<Slab style={{ opacity: 0.8 }} aria-label="Slab logo" />
```

> **Note:** The SVG contains an inline base64-encoded PNG image. The default rendered size is 32×32px, but width/height props can override this. The underlying image data is 512×512px, so scaling up will remain crisp.
