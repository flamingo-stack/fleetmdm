A React SVG component that renders a 32×32 Deskpad icon using an embedded base64-encoded PNG image.

## Key Components

- **`Deskpad`** — A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing an inline base64 PNG icon.

## Usage Example

```typescript
import { Deskpad } from "./Deskpad";

// Basic usage
<Deskpad />

// With custom dimensions or styling
<Deskpad width={64} height={64} className="icon" />

// With color or style overrides (note: color overrides won't affect the embedded PNG)
<Deskpad style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained as a base64 data URI — no external image assets are required.
- Since the icon is a rasterized PNG embedded inside the SVG, SVG-specific styling (e.g., `fill`, `stroke`) will not affect the icon's appearance. Use `opacity` or CSS transforms for visual adjustments.
- The component spreads all `SVGProps` onto the root `<svg>` element, making it compatible with standard SVG attribute overrides such as `width`, `height`, `className`, `style`, and `aria-*` attributes.
