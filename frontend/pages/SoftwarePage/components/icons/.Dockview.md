A React SVG component that renders the Dockview logo as an inline SVG element using a base64-encoded PNG image.

## Key Components

- **`Dockview`** — Default export. A functional React component wrapping a 32×32 SVG element that embeds the Dockview logo via a base64-encoded PNG `<image>` tag.

## Usage Example

```typescript
import Dockview from "./Dockview";

// Basic usage
const MyComponent = () => (
  <div>
    <Dockview />
  </div>
);

// With custom SVG props (e.g., size, className, style)
const CustomDockview = () => (
  <Dockview
    width={64}
    height={64}
    className="icon"
    style={{ opacity: 0.8 }}
  />
);
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of size, class, style, and other SVG attributes via prop spreading.
- The logo image is self-contained as a base64-encoded PNG — no external asset dependencies required.
- Default rendered size is **32×32 pixels**.
