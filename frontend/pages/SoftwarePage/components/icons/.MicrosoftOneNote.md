React SVG component that renders the Microsoft OneNote application icon as an inline PNG image embedded via base64 data URI.

## Key Components

- **`MicrosoftOneNote`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains an embedded base64-encoded PNG of the OneNote logo.

## Usage Example

```typescript
import MicrosoftOneNote from "./MicrosoftOneNote";

// Basic usage
<MicrosoftOneNote />

// With custom dimensions or className
<MicrosoftOneNote width={64} height={64} className="app-icon" />

// With accessibility attributes
<MicrosoftOneNote aria-label="Microsoft OneNote" role="img" />
```

## Notes

- The icon is statically embedded as a base64 PNG inside an `<image>` SVG element — no external network request is made.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
