A React SVG component that renders the KNIME logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Knime`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the KNIME brand icon via an inline `<image>` element with a base64-encoded PNG data URI at 32×32 pixels.

## Usage Example

```typescript
import Knime from './Knime';

// Basic usage
<Knime />

// With custom dimensions or className
<Knime width={64} height={64} className="icon" />

// With accessibility attributes
<Knime aria-label="KNIME" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props are spread onto the root `<svg>` element, enabling full customization (sizing, styling, event handlers, ARIA attributes).
- The icon content is a self-contained base64 PNG — no external assets or network requests required.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
