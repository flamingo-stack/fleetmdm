React SVG wrapper component that renders the Actual (Fleet MDM) logo as an inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Actual`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG logo via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Actual from "./Actual";

// Basic usage
<Actual />

// With custom dimensions and className
<Actual width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Actual aria-label="Actual logo" role="img" />
```

## Notes

- The component spreads all passed `SVGProps` onto the root `<svg>` element, making it fully customizable (size, color, event handlers, etc.).
- The default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The PNG image data is embedded inline — no external asset fetch required, making it suitable for offline or SSR environments.
