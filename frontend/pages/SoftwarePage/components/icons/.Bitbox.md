React SVG component that renders the Bitbox cryptocurrency wallet logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`Bitbox`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Bitbox logo as an embedded PNG.

## Usage Example

```typescript
import Bitbox from "./Bitbox";

// Basic usage
<Bitbox />

// With custom dimensions
<Bitbox width={64} height={64} />

// With additional SVG props
<Bitbox className="wallet-icon" aria-label="Bitbox wallet" />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG embedded directly in the SVG `<image>` element — no external assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
