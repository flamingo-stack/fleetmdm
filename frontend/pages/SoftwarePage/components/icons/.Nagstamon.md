A React SVG component that renders the Nagstamon logo as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Nagstamon`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG of the Nagstamon logo.

## Usage Example

```typescript
import Nagstamon from "./Nagstamon";

// Basic usage
<Nagstamon />

// With custom dimensions or className
<Nagstamon width={64} height={64} className="app-icon" />

// With accessibility attributes
<Nagstamon aria-label="Nagstamon" role="img" />
```

## Notes

- The icon is sourced from [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Nagstamon.tsx) and uses an embedded base64 PNG, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component fully composable.
- Default render size is **32×32px**; override via `width`/`height` props as needed.
