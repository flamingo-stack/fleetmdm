A React SVG component that renders a 32×32 "Middle" icon by embedding a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Middle`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing an inlined PNG via a base64 data URI.

## Usage Example

```typescript
import { Middle } from "./Middle";

// Basic usage
<Middle />

// With custom dimensions or styling
<Middle width={64} height={64} className="icon" />

// With event handlers or accessibility attributes
<Middle
  aria-label="Middle icon"
  onClick={() => console.log("clicked")}
  style={{ cursor: "pointer" }}
/>
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the `<svg>` element via spread (`{...props}`).
- The image is fully self-contained — no external assets are required at runtime.
- Default dimensions are `32×32` pixels but can be overridden via props.
