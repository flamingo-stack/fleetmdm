A React SVG icon component that renders the NordLayer brand logo as a 32×32 PNG embedded within an SVG wrapper.

## Key Components

- **`Nordlayer`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override or extend SVG attributes (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Nordlayer from "./Nordlayer";

// Basic usage
<Nordlayer />

// With custom size and class
<Nordlayer width={64} height={64} className="icon" />

// With click handler
<Nordlayer onClick={() => console.log("NordLayer clicked")} />
```

## Notes

- The logo image is inlined as a Base64-encoded PNG (`data:image/png;base64,...`), meaning no external asset request is needed at runtime.
- Default dimensions are **32×32 pixels**; these can be overridden via `width`/`height` props.
