A React component that renders the NounProject logo as an SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`NounProject`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the NounProject logo as an inline base64 PNG.

## Usage Example

```typescript
import NounProject from "./NounProject";

// Basic usage
<NounProject />

// With custom dimensions and className
<NounProject width={64} height={64} className="logo-icon" />

// With style overrides
<NounProject style={{ opacity: 0.8 }} aria-label="NounProject logo" />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The logo image is embedded as a base64 PNG — no external asset requests required.
- Accepts all standard SVG props (e.g., `className`, `style`, `aria-*`) via prop spreading.
