A React SVG component that renders a 32×32 "Session" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Session`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization support.

## Usage Example

```typescript
import Session from "./Session";

// Basic usage
<Session />

// With custom size and className
<Session width={64} height={64} className="icon-session" />

// With accessibility attributes
<Session aria-label="Session" role="img" />
```

## Notes

- The icon renders at **32×32px** by default (matches the embedded PNG dimensions).
- The image data is a self-contained base64 PNG, so no external assets are required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the `<svg>` element.
