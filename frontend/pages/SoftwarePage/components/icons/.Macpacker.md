A React SVG component that renders the Macpacker application icon as a 32×32 inline PNG embedded via base64 within an SVG element.

## Key Components

- **`Macpacker`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64-encoded PNG image.

## Usage Example

```typescript
import Macpacker from "./Macpacker";

// Basic usage
<Macpacker />

// With custom dimensions or className
<Macpacker width={64} height={64} className="icon" />

// With accessibility attributes
<Macpacker aria-label="Macpacker" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external image assets are required.
- Default render size is **32×32px**; override via `width`/`height` props.
