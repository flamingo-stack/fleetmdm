A React SVG icon component that renders the Falcon (CrowdStrike Falcon) brand logo as an inline SVG element.

## Key Components

- **`Falcon`** — Default export. A functional React component that renders a red-background SVG icon with the Falcon logo path, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Falcon from "./Falcon";

// Basic usage
<Falcon width={32} height={32} />

// With custom class or style
<Falcon className="icon" style={{ borderRadius: 4 }} />

// As part of an integration badge
<Falcon width={24} height={24} aria-label="CrowdStrike Falcon" />
```

## Notes

- Default canvas is **32×32px** (set via `<rect>`); override with `width`/`height` props.
- The background fill is `#D31C12` (CrowdStrike red) — baked into the SVG markup, not themeable via CSS.
- Spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, so `className`, `style`, `aria-*`, `role`, etc. are fully supported.
- No external dependencies beyond React.
