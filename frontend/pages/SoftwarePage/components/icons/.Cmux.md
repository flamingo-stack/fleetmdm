A React SVG component that renders the Cmux logo as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Cmux`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Cmux from "./Cmux";

// Basic usage
<Cmux />

// With custom sizing and class
<Cmux width={64} height={64} className="icon" />

// With click handler
<Cmux onClick={() => console.log("clicked")} />
```

## Notes

- The image is embedded as a 512×512 PNG encoded in base64 and rendered at 32×32 via an SVG `<image>` element.
- All standard SVG props are forwarded via spread (`{...props}`), making the component fully customizable.
