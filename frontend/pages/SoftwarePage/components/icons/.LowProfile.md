A React SVG component that renders a "Low Profile" icon as an inline SVG element containing an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`LowProfile`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import LowProfile from "./LowProfile";

// Basic usage
<LowProfile />

// With custom size and className
<LowProfile width={64} height={64} className="icon" />

// With aria label for accessibility
<LowProfile aria-label="Low Profile" role="img" />
```

## Notes

- The component spreads all `SVGProps` onto the root `<svg>` element, making it fully customizable (size, color, style, event handlers, etc.).
- The icon image is self-contained via a base64 data URI — no external assets or network requests are required.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
