A React component that renders the Itsycal application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Itsycal`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Itsycal from "./Itsycal";

// Basic usage
<Itsycal />

// With custom dimensions or className
<Itsycal width={64} height={64} className="app-icon" />

// With accessibility attributes
<Itsycal aria-label="Itsycal" role="img" />
```

## Notes

- The icon image is self-contained — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are supported via prop spreading.
