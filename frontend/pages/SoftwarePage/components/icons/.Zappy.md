React SVG component that renders the Zappy mascot/icon as a 32×32 pixel image embedded via a base64-encoded PNG.

## Key Components

- **`Zappy`** — Default export; a functional React component that wraps an `<svg>` element containing a base64-encoded PNG rendered via an `<image>` tag.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override `width`, `height`, `className`, `style`, and other SVG attributes.

## Usage Example

```typescript
import Zappy from "./Zappy";

// Basic usage
<Zappy />

// With custom size and class
<Zappy width={64} height={64} className="mascot-icon" />

// With inline style override
<Zappy style={{ opacity: 0.8 }} />
```

## Notes

- The PNG asset is fully self-contained via a base64 data URI — no external image file or network request is needed.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- The source image is a **512×512** PNG (per embedded EXIF metadata), downscaled to 32×32 at render time by the SVG viewport.
