A React SVG component that renders the Aldente app icon as an inline SVG using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Aldente`** — Default exported functional component that wraps a base64-encoded PNG inside an `<svg>` element, forwarding all standard `SVGProps` to the root `<svg>` tag.

## Usage Example

```typescript
import Aldente from "./Aldente";

// Basic usage
<Aldente />

// With custom dimensions or className
<Aldente width={64} height={64} className="app-icon" />

// With accessibility attributes
<Aldente aria-label="Aldente" role="img" />
```

## Notes

- The icon is **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG image data is embedded directly as a base64 `href` on an `<image>` element, so no external asset fetch is required.
- All standard [`SVGProps`](https://react.dev/reference/react-dom/components/svg) (e.g., `className`, `style`, `onClick`) are spread onto the root `<svg>` element.
