A React SVG component that renders a 32×32 Pika icon using an embedded base64-encoded PNG image.

## Key Components

- **`Pika`** — Default export. A functional React component that wraps an SVG element containing an inline base64 PNG image, forwarding all standard `SVGProps` to the root `<svg>` element.

## Usage Example

```typescript
import Pika from "./Pika";

// Basic usage
<Pika />

// With custom size and class
<Pika width={64} height={64} className="icon" />

// With style override
<Pika style={{ opacity: 0.8 }} />
```

## Notes

- The icon is **32×32px** by default but can be overridden via `width`/`height` props.
- The image source is a **self-contained base64 PNG**, so no external image assets or network requests are required.
- All standard [`SVGProps`](https://github.com/flamingo-stack/fleetmdm/blob/main/node_modules/@types/react/index.d.ts) (e.g., `className`, `style`, `onClick`) are spread onto the root `<svg>` element.
- Located at [`Pika.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Pika.tsx) in the repository.
