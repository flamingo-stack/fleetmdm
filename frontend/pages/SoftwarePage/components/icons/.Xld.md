React SVG component that renders a 32×32 pixel icon by embedding a base64-encoded PNG image inline within an SVG wrapper.

## Key Components

- **`Xld`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Xld from "./Xld";

// Basic usage
<Xld />

// With custom props
<Xld className="icon" style={{ opacity: 0.8 }} aria-label="Xld icon" />

// With size override
<Xld width={64} height={64} />
```

## Notes

- The component is **32×32px** by default but accepts any valid SVG props including `width`, `height`, `className`, `style`, and accessibility attributes.
- The icon image is embedded as a **base64-encoded PNG** via an `<image>` element, meaning no external asset requests are made.
- Prop spreading (`{...props}`) on the `<svg>` element allows full customization at the call site.
