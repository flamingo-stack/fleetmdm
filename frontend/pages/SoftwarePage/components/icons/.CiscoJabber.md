React SVG component that renders the Cisco Jabber application icon as an inline PNG image encoded in base64.

## Key Components

- **`CiscoJabber`** — Default export; a functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing the Cisco Jabber logo as an embedded base64 PNG image.

## Usage Example

```typescript
import CiscoJabber from "./CiscoJabber";

// Basic usage
<CiscoJabber />

// With custom dimensions and className
<CiscoJabber width={64} height={64} className="app-icon" />

// With accessibility attributes
<CiscoJabber aria-label="Cisco Jabber" role="img" />
```

## Notes

- The icon is hardcoded at 32×32 pixels by default but can be overridden via `width`/`height` props.
- The PNG image data is embedded as a base64-encoded `data:image/png` URI within an SVG `<image>` element, requiring no external asset fetching.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
