A React SVG component that renders the Swifty icon as a 32×32 inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Swifty`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { Swifty } from "./Swifty";

// Basic usage
<Swifty />

// With custom size or className
<Swifty width={64} height={64} className="my-icon" />

// With accessibility attributes
<Swifty aria-label="Swifty" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>`, making it fully customizable (size, class, style, ARIA attributes, etc.).
- The icon image is self-contained — no external asset requests are made at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
