A React SVG component that renders a custom "shortcuts" icon using an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Customshortcuts`** — Default export; a functional React component wrapping an SVG element that displays a 32×32 PNG icon via a base64 `data:image/png` URI embedded in an `<image>` tag.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Customshortcuts from "./Customshortcuts";

// Basic usage
<Customshortcuts />

// With custom size and class
<Customshortcuts width={64} height={64} className="icon-shortcuts" />

// With click handler
<Customshortcuts onClick={() => console.log("shortcuts clicked")} />
```

## Notes

- The icon is self-contained — no external image assets are required.
- The embedded PNG carries EXIF metadata indicating a source resolution of 512×512px, downscaled to 32×32 for display.
