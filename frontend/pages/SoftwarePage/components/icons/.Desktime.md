A React SVG component that renders the Desktime logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Desktime`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG wrapper around an embedded PNG icon.

## Usage Example

```typescript
import Desktime from "./Desktime";

// Basic usage
<Desktime />

// With custom dimensions or className
<Desktime width={64} height={64} className="my-icon" />

// With accessibility attributes
<Desktime aria-label="Desktime" role="img" />
```

## Notes

- The icon image is inlined as a base64 PNG (`data:image/png;base64,...`), so no external asset file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
