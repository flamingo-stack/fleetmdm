A React SVG component that renders the Drawbot icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`Drawbot`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing a base64-encoded PNG of the Drawbot icon.

## Usage Example

```typescript
import Drawbot from "./Drawbot";

// Basic usage
<Drawbot />

// With custom dimensions or className
<Drawbot width={64} height={64} className="icon" />

// With accessibility attributes
<Drawbot aria-label="Drawbot" role="img" />
```

## Notes

- The component renders at **32×32 pixels** by default but accepts any valid SVG props to override dimensions or add styling.
- The icon image is embedded as a **base64-encoded PNG** inside an `<image>` tag, so no external assets are required.
- All props are spread directly onto the root `<svg>` element, enabling full customization via `SVGProps`.
