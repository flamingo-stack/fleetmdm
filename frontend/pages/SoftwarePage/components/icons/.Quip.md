SVG icon component that renders the Quip logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Quip`** — Default export; a React functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Quip logo as an embedded PNG image.

## Usage Example

```typescript
import Quip from "./Quip";

// Basic usage
<Quip />

// With custom dimensions and className
<Quip width={64} height={64} className="icon" />

// With accessibility attributes
<Quip aria-label="Quip" role="img" />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo image is self-contained as a base64-encoded PNG — no external network requests or additional assets required.
- Fully compatible with standard SVG prop passthrough (e.g., `style`, `className`, `onClick`, `aria-*`).
