React SVG icon component for the Audacity application, rendering a 32×32 PNG logo embedded as a base64-encoded inline image within an SVG wrapper.

## Key Components

- **`Audacity`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a fixed 32×32 SVG containing the Audacity app icon as an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Audacity from "./Audacity";

// Basic usage
<Audacity />

// With custom className or style overrides
<Audacity className="app-icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Audacity aria-label="Audacity" role="img" />
```

## Notes

- The icon is self-contained — no external image assets or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Width and height default to `32`, but can be overridden via props: `<Audacity width={64} height={64} />`.
