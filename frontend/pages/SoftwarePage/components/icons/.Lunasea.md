A React SVG component that renders the Lunasea application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Lunasea`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Lunasea logo via an inline base64 PNG data URI within an SVG wrapper.

## Usage Example

```typescript
import Lunasea from "./Lunasea";

// Basic usage
<Lunasea />

// With custom class or style
<Lunasea className="app-icon" style={{ opacity: 0.8 }} />

// With custom dimensions via SVG props
<Lunasea width={64} height={64} />
```

## Notes

- Default rendered size is **32×32px**.
- The icon image is self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
