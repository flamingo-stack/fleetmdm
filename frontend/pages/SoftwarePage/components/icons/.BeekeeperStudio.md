A React SVG icon component that renders the Beekeeper Studio logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`BeekeeperStudio`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass `className`, `style`, `onClick`, and other SVG attributes.

## Usage Example

```typescript
import BeekeeperStudio from "@/components/icons/BeekeeperStudio";

// Basic usage
<BeekeeperStudio />

// With custom sizing and className
<BeekeeperStudio width={48} height={48} className="icon-beekeeper" />

// With onClick handler
<BeekeeperStudio onClick={() => openBeekeeperStudio()} style={{ cursor: "pointer" }} />
```

## Notes

- Default render size is **32×32 pixels**; override via `width`/`height` props.
- The PNG image is embedded as a base64 data URI — no external asset fetch required.
