A React SVG component that renders the Mozilla Thunderbird application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Thunderbird`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element containing the Thunderbird logo as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Thunderbird from './Thunderbird';

// Basic usage
<Thunderbird />

// With custom dimensions or className
<Thunderbird width={64} height={64} className="app-icon" />

// With click handler or aria attributes
<Thunderbird
  aria-label="Mozilla Thunderbird"
  onClick={() => console.log('Thunderbird clicked')}
/>
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- The icon is self-contained — no external image assets or network requests are required at runtime.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
- Typically used in UI elements that display installed application or email client icons, such as software catalogs or MDM asset inventories within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) platform.
