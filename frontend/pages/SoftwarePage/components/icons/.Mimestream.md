A React SVG component that renders the Mimestream app icon as a 32×32 PNG image embedded inline via a base64-encoded data URI.

## Key Components

- **`Mimestream`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` with an embedded base64 PNG icon image.

## Usage Example

```typescript
import Mimestream from "./Mimestream";

// Basic usage
<Mimestream />

// With custom dimensions or className
<Mimestream width={64} height={64} className="app-icon" />

// With accessibility attributes
<Mimestream aria-label="Mimestream" role="img" />
```

## Notes

- The icon image is self-contained — no external network requests are made at runtime.
- Props are spread onto the root `<svg>` element, allowing full customization of dimensions, styles, and ARIA attributes.
- Default rendered size is **32×32px**; override via `width` and `height` props.
