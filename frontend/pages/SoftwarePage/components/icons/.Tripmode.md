A React SVG component that renders the Tripmode application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Tripmode`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Tripmode app icon as an inline PNG via a base64 data URI.

## Usage Example

```typescript
import Tripmode from "./Tripmode";

// Basic usage
<Tripmode />

// With custom dimensions or className
<Tripmode width={64} height={64} className="app-icon" />

// With style overrides
<Tripmode style={{ opacity: 0.8 }} aria-label="Tripmode" />
```

## Notes

- The icon is a **32×32** SVG container housing a base64-encoded PNG (originally 512×512 pixels per embedded EXIF metadata).
- All standard `SVGProps` are spread onto the root `<svg>` element, allowing full customization of dimensions, accessibility attributes, and styling.
- The embedded image approach ensures the icon is fully self-contained with no external network dependencies.
