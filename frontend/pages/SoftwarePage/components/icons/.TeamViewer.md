React SVG icon component that renders the TeamViewer logo with blue gradient styling.

## Key Components

- **`TeamViewer`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering the TeamViewer brand icon using two linear gradients and a clip path.
- **Dynamic IDs** — Uses `lodash.uniqueId` to generate unique IDs for `linearGradient` and `clipPath` SVG `<defs>` elements, preventing ID collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import TeamViewer from "components/icons/TeamViewer";

// Basic usage
<TeamViewer />

// With custom dimensions and className
<TeamViewer width={32} height={32} className="integration-icon" />

// Inline with a label
<span>
  <TeamViewer width={16} height={16} />
  TeamViewer Integration
</span>
```

## Notes

- Renders at a native `32×32` viewBox; use `width`/`height` props to scale.
- Gradient colors transition from `#096FD2` to `#0E8EE9` (TeamViewer brand blue).
- All `SVGProps` are forwarded via spread (`{...props}`), so `className`, `style`, `aria-*`, and event handlers are fully supported.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
