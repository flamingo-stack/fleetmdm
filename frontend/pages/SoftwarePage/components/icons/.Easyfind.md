A React SVG wrapper component that renders the Easyfind logo as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Easyfind`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG logo via an `<image>` element.

## Usage Example

```typescript
import Easyfind from "./Easyfind";

// Basic usage
<Easyfind />

// With custom dimensions and className
<Easyfind width={64} height={64} className="logo-icon" />

// With style overrides
<Easyfind style={{ opacity: 0.8 }} aria-label="Easyfind logo" />
```

## Notes

- The component accepts all `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The logo image is self-contained via a base64-encoded PNG — no external asset dependencies.
- Default render size is **32×32px**.
