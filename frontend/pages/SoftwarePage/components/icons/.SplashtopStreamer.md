React SVG icon component that renders the Splashtop Streamer application logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`SplashtopStreamer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import SplashtopStreamer from "./SplashtopStreamer";

// Basic usage
<SplashtopStreamer />

// With custom dimensions and className
<SplashtopStreamer width={64} height={64} className="app-icon" />

// With accessible title via aria attributes
<SplashtopStreamer aria-label="Splashtop Streamer" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default render size is **32×32 pixels**; override with `width`/`height` props.
- The icon image is self-contained — no external network requests at runtime.
