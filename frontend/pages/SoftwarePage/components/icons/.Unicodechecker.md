A React SVG component that renders a 32×32 Unicodechecker icon using an embedded base64-encoded PNG image.

## Key Components

- **`Unicodechecker`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full SVG attribute customization (e.g., `className`, `style`, `onClick`).
- The icon is rendered as an `<image>` element inside an SVG wrapper, embedding a 32×32 PNG as a base64 data URI (originally 512×512 px, per EXIF metadata).

## Usage Example

```typescript
import Unicodechecker from "./Unicodechecker";

// Basic usage
const App = () => (
  <Unicodechecker />
);

// With custom sizing and styling
const App = () => (
  <Unicodechecker
    width={64}
    height={64}
    className="icon-unicodechecker"
    style={{ cursor: "pointer" }}
    onClick={() => console.log("Unicodechecker clicked")}
  />
);
```

## Notes

- The component defaults to `32×32` pixels but can be overridden via `width`/`height` props.
- All standard SVG props are forwarded via the spread `{...props}` pattern.
- The icon asset is self-contained — no external image files or imports are required.
