React SVG component that renders the Jabra Direct brand icon as a 32×32 inline PNG embedded via a base64-encoded `<image>` element.

## Key Components

- **`JabraDirect`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import JabraDirect from "./JabraDirect";

// Basic usage
<JabraDirect />

// With custom size and className
<JabraDirect width={64} height={64} className="icon" />

// With accessibility attributes
<JabraDirect aria-label="Jabra Direct" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The image data is a self-contained base64 PNG, requiring no external asset fetches.
- Useful in MSP/device-management UI contexts (e.g., listing supported headset vendors in [OpenFrame](https://www.flamingo.run/openframe)).
