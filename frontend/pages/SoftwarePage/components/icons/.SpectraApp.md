A React SVG component that renders the Spectra application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`SpectraApp`** — Default export. A functional React component that wraps an inline `<svg>` element containing the Spectra app icon as a base64 `<image>` element.

## Usage Example

```typescript
import SpectraApp from "./SpectraApp";

// Basic usage
<SpectraApp />

// With custom SVG props (e.g., className, style, aria-label)
<SpectraApp
  className="app-icon"
  aria-label="Spectra application"
  style={{ opacity: 0.8 }}
/>
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the outer `<svg>` element (e.g., `width`, `height`, `className`, `style`).
- The icon is rendered at a default size of 32×32px. Override via the `width`/`height` props if a different size is needed.
- The PNG asset is embedded directly as a base64 data URI — no external image file or network request required.
