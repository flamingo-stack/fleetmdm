SVG icon component that renders the Elgato Control Center application logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`ElgatoControlCenter`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute forwarding (e.g., `className`, `style`, `onClick`).
- Renders a 32×32 SVG shell containing an `<image>` element with a base64-encoded PNG of the Elgato Control Center icon.

## Usage Example

```typescript
import ElgatoControlCenter from "./ElgatoControlCenter";

// Basic usage
<ElgatoControlCenter />

// With custom size and class
<ElgatoControlCenter width={64} height={64} className="app-icon" />

// With click handler
<ElgatoControlCenter onClick={() => console.log("clicked")} />
```

## Notes

- Default dimensions are **32×32 pixels**; override with `width`/`height` props.
- The icon data is fully self-contained (no external image requests).
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — find the file via the repo browser for exact path context.
