React SVG icon component that renders the GitHub Desktop application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`GitHubDesktop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the GitHub Desktop icon as an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import GitHubDesktop from "./GitHubDesktop";

// Basic usage
<GitHubDesktop />

// With custom class or style overrides
<GitHubDesktop className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<GitHubDesktop width={64} height={64} />
```

## Notes

- Default rendered size is **32×32 pixels**; can be overridden via `width`/`height` props.
- The icon image is embedded as a base64 PNG — no external asset fetch required.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
