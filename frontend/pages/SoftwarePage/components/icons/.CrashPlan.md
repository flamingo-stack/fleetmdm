A React SVG component that renders the CrashPlan logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`CrashPlan`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing the CrashPlan brand icon as an inline base64 PNG.

## Usage Example

```typescript
import CrashPlan from "./CrashPlan";

// Basic usage
<CrashPlan />

// With custom dimensions or className
<CrashPlan width={64} height={64} className="icon" />

// With accessibility attributes
<CrashPlan aria-label="CrashPlan" role="img" />
```

## Notes

- The icon is sourced from [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons/CrashPlan.tsx) and is typically used to represent CrashPlan backup software within the Fleet MDM software inventory or integration UI.
- The base64 PNG is embedded directly, so no external image assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread props.
