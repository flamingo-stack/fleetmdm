React SVG wrapper component that renders the Lightburn application icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Lightburn` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders the Lightburn logo as an SVG containing an embedded PNG |

## Usage Example

```typescript
import Lightburn from './Lightburn';

// Basic usage
<Lightburn />

// With custom dimensions or styling via SVGProps
<Lightburn width={64} height={64} className="icon" />

// With style overrides
<Lightburn style={{ opacity: 0.8 }} aria-label="Lightburn" />
```

## Notes

- The icon is a **32×32** SVG wrapper around a base64-encoded PNG (`data:image/png;base64,...`).
- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `width`, `height`, event handlers) via spread.
- No external image dependencies — the PNG data is fully self-contained in the component.
