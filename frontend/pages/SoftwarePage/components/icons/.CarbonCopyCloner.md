React SVG icon component that renders the Carbon Copy Cloner application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`CarbonCopyCloner`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Carbon Copy Cloner app icon as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import CarbonCopyCloner from "./CarbonCopyCloner";

// Basic usage
<CarbonCopyCloner />

// With custom dimensions or className
<CarbonCopyCloner width={64} height={64} className="app-icon" />

// With inline styles
<CarbonCopyCloner style={{ opacity: 0.8 }} />
```

## Notes

- The icon defaults to **32×32 pixels** but can be overridden via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
- The image data is self-contained (base64-encoded PNG), so no external asset loading is required.
- Intended for use in device/software inventory UIs within the [Flamingo Fleet MDM platform](https://github.com/flamingo-stack/fleetmdm), where macOS backup software icons are displayed alongside managed device records.
