A React SVG component that renders the UaConnect icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`UaConnect`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import UaConnect from "./UaConnect";

// Basic usage
<UaConnect />

// With custom dimensions via SVG props
<UaConnect width={64} height={64} />

// With className or style
<UaConnect className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- All standard `SVGProps<SVGSVGElement>` (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread props.
- The icon image is fully self-contained — no external image assets are required.
- Default render size is **32×32px**; override by passing `width` and `height` props.
