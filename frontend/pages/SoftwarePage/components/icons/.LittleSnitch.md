A React SVG component that renders the Little Snitch application icon as an inline PNG image (32×32px) encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`LittleSnitch`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import LittleSnitch from "./LittleSnitch";

// Basic usage
<LittleSnitch />

// With custom dimensions or className
<LittleSnitch width={64} height={64} className="app-icon" />

// With inline style
<LittleSnitch style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via props.
- The image is self-contained — no external asset files are required.
- Accepts all standard SVG props (e.g., `className`, `style`, `aria-label`) via spread.
