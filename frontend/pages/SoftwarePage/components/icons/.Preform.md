A React SVG component that renders a Preform icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Preform`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Preform from "./Preform";

// Basic usage
<Preform />

// With custom size and className
<Preform width={64} height={64} className="icon" />

// With style overrides
<Preform style={{ opacity: 0.8 }} aria-label="Preform icon" />
```

## Notes

- The icon is a **32×32 SVG** wrapping a base64-encoded PNG `<image>` element — the visual is raster-based, not vector-based.
- All SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via the spread operator, making it flexible for layout and styling.
