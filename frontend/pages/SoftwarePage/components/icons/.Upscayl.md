A React SVG icon component that renders the Upscayl logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`Upscayl`** — Default export. A functional React component that renders an `<svg>` element containing the Upscayl brand icon at 32×32px. Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Upscayl from "./Upscayl";

// Basic usage
<Upscayl />

// With custom size and class
<Upscayl width={64} height={64} className="icon" />

// With click handler
<Upscayl onClick={() => console.log("clicked")} />
```

## Notes

- The icon image is embedded as a base64 PNG data URI, so no external assets or network requests are required.
- The component forwards all `SVGProps` to the root `<svg>` element, making it fully composable with standard SVG attributes.
