A React SVG component that renders a 32×32 "Lookaway" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Lookaway`** — Default export; a functional React component that wraps an SVG element containing an inline base64 PNG `<image>` tag. Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `aria-*` attributes).

## Usage Example

```typescript
import Lookaway from "./Lookaway";

// Basic usage
<Lookaway />

// With custom dimensions and styling
<Lookaway width={64} height={64} className="icon" />

// With accessibility attributes
<Lookaway aria-label="Look away icon" role="img" />
```

## Notes

- The icon is fixed at a native resolution of **32×32 px** (overridable via props).
- The image data is a **512×512 px** PNG embedded as a base64 data URI, so no external asset requests are made.
- Useful in MDM or device management UI contexts (e.g., screen privacy indicators) within the [Flamingo/FleetMDM](https://github.com/flamingo-stack/fleetmdm) platform.
