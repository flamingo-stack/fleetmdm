A React SVG icon component that renders the NVIDIA GeForce Now logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`NvidiaGeforceNow`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass any native SVG attributes (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import NvidiaGeforceNow from "./NvidiaGeforceNow";

// Basic usage
<NvidiaGeforceNow />

// With custom size and className
<NvidiaGeforceNow width={64} height={64} className="icon" />

// With click handler
<NvidiaGeforceNow onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The image data is self-contained as a base64 PNG — no external assets or network requests required.
