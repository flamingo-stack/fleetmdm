A React SVG component that renders the Reflector icon as an inline SVG element containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Reflector`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Reflector from "./Reflector";

// Basic usage
<Reflector />

// With custom size and class
<Reflector width={64} height={64} className="icon-reflector" />

// With click handler
<Reflector onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is rendered at a default size of **32×32** pixels via a `<image>` element embedding a base64 PNG.
- Overriding `width`/`height` via props resizes the SVG container but not the internal image element.
