React SVG component that renders the GIMP (GNU Image Manipulation Program) application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Gimp`** — Default export; a functional React component that wraps an `<svg>` element containing a 32×32 base64-encoded PNG of the GIMP logo
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.)

## Usage Example

```typescript
import Gimp from "./Gimp";

// Basic usage
<Gimp />

// With custom size and className
<Gimp width={64} height={64} className="app-icon" />

// With click handler
<Gimp onClick={() => console.log("GIMP icon clicked")} />
```

## Notes

- Default rendered size is **32×32 pixels**
- The icon image is embedded as a base64 PNG inside an SVG `<image>` tag — no external asset requests are made
- Fully compatible with standard SVG prop overrides via spread (`{...props}`)
