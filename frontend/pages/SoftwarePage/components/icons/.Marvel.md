A React SVG component that renders the Marvel logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Marvel`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Marvel from "./Marvel";

// Basic usage
<Marvel />

// With custom dimensions or className
<Marvel width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Marvel aria-label="Marvel" role="img" />
```

## Notes

- The SVG wrapper is fixed at `32×32` by default but can be overridden via props.
- The actual image is an embedded base64 PNG (not a vector path), so scaling beyond the source resolution may result in quality loss.
- No external assets or network requests are required — the image is fully self-contained.
