React SVG wrapper component that renders a 32×32 PNG icon (`NameMangler`) as an inline Base64-encoded image embedded within an SVG element.

## Key Components

- **`NameMangler`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- **Embedded image** — A 512×512 PNG asset encoded as a Base64 data URI, rendered via an SVG `<image>` tag scaled to 32×32.

## Usage Example

```typescript
import NameMangler from "./NameMangler";

// Basic usage
<NameMangler />

// With custom sizing or className
<NameMangler width={64} height={64} className="icon" />

// With accessibility attributes
<NameMangler aria-label="Name Mangler" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are spread onto the root `<svg>` element, making the component fully composable.
- The 32×32 default dimensions can be overridden via props.
- The icon source lives entirely in this file — no external asset files or imports required.
