React SVG icon component that renders the iMazing Profile Editor application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`IMazingProfileEditor`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import IMazingProfileEditor from "./IMazingProfileEditor";

// Basic usage
<IMazingProfileEditor />

// With custom dimensions or className
<IMazingProfileEditor width={64} height={64} className="app-icon" />

// With accessibility attributes
<IMazingProfileEditor aria-label="iMazing Profile Editor" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread, making the component fully composable.
- The icon is self-contained — no external image assets or network requests are required at runtime.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
