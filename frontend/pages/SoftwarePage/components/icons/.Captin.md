A React SVG component that renders the Captin logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Captin`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Captin logo as an embedded PNG.

## Usage Example

```typescript
import Captin from "./Captin";

// Basic usage
<Captin />

// With custom size or className
<Captin width={64} height={64} className="logo-icon" />

// With style overrides
<Captin style={{ opacity: 0.8 }} />
```

## Notes

- The image is embedded as a base64-encoded PNG (`data:image/png;base64,...`), meaning no external asset request is made at runtime.
- Default dimensions are **32×32px**, overridable via standard SVG props.
