A React SVG component that renders a 32×32 Pacifist icon using an embedded base64-encoded PNG image.

## Key Components

- **`Pacifist`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the wrapping `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Pacifist from "./Pacifist";

// Basic usage
<Pacifist />

// With custom size and class
<Pacifist width={64} height={64} className="icon" />

// With click handler
<Pacifist onClick={() => console.log("clicked")} />
```

## Notes

- The icon is rendered as a 32×32 SVG wrapper containing an `<image>` element with a base64-encoded PNG payload.
- Accepts all `SVGProps<SVGSVGElement>` via spread, enabling full prop passthrough for accessibility attributes (`aria-label`, `role`), styling, and event handlers.
