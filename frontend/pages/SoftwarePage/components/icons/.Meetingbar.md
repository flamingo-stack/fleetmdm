A React SVG component that renders the MeetingBar application icon as an inline base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Meetingbar`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which renders a 32×32 SVG wrapper containing an embedded base64 PNG of the MeetingBar app icon.

## Usage Example

```typescript
import Meetingbar from "./Meetingbar";

// Basic usage
<Meetingbar />

// With custom dimensions or className
<Meetingbar width={64} height={64} className="app-icon" />

// With inline styles
<Meetingbar style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via the spread `{...props}`.
- The icon image is self-contained — no external image assets or network requests are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
