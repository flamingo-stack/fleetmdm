A React SVG component that renders a 32×32 "SimpleComic" icon using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SimpleComic` | `React.FC<SVGProps<SVGSVGElement>>` | SVG wrapper component with an inline base64 PNG image |

## Usage Example

```typescript
import { SimpleComic } from './SimpleComic';

// Basic usage
<SimpleComic />

// With custom dimensions and styling
<SimpleComic width={64} height={64} className="icon" style={{ opacity: 0.8 }} />

// With event handlers
<SimpleComic onClick={() => console.log('clicked')} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (spread via `{...props}`)
- Default dimensions: `32×32`
- Image source is a self-contained base64-encoded PNG (512×512 original, downscaled to 32×32 in the SVG)
- No external dependencies beyond React
