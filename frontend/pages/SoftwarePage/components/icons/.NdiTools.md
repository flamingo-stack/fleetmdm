A React SVG icon component that renders the NDI Tools logo as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`NdiTools`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing consumers to pass any SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import NdiTools from "./NdiTools";

// Basic usage
<NdiTools />

// With custom dimensions and className
<NdiTools width={64} height={64} className="icon" />

// With click handler
<NdiTools onClick={() => console.log("NDI Tools clicked")} />
```

## Notes

- The icon is fixed at a 32×32 base resolution; overriding `width`/`height` via props scales the SVG container but the inner `<image>` element remains at 32×32 px.
- The PNG is embedded as a base64 data URI, so no external image assets are required.
