A React SVG component that renders the Kap application icon as an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Kap`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import Kap from "./Kap";

// Basic usage
<Kap />

// With custom size and className
<Kap width={64} height={64} className="app-icon" />

// With inline style
<Kap style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered as a 32×32 SVG containing a base64-encoded PNG `<image>` element — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread, making this composable with icon libraries or UI toolkits.
