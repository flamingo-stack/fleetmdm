A React SVG component that renders the 7-Zip application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`SevenZip`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 7-Zip icon via an embedded base64 PNG.

## Usage Example

```typescript
import SevenZip from "./7Zip";

// Basic usage
<SevenZip />

// With custom dimensions or class
<SevenZip width={64} height={64} className="app-icon" />

// With additional SVG props
<SevenZip style={{ opacity: 0.8 }} aria-label="7-Zip" />
```

## Notes

- Renders at **32×32px** by default; override with `width`/`height` props.
- The icon is self-contained — no external image assets required.
- Accepts all standard `SVGProps<SVGSVGElement>` (e.g., `className`, `style`, `onClick`).
- Part of the application icon set in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository.
