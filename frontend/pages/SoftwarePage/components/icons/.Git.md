A React SVG icon component that renders the Git logo as a 32×32 inline PNG embedded via base64 data URI.

## Key Components

- **`Git`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the outer `<svg>` element.

## Usage Example

```typescript
import Git from "./Git";

// Basic usage
<Git />

// With custom size and className
<Git width={24} height={24} className="icon" />

// With style overrides
<Git style={{ opacity: 0.8 }} aria-label="Git" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The Git logo image is embedded as a **base64-encoded PNG** within an `<image>` element — no external asset required.
