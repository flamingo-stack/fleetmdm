SVG icon component for the RapidAPI logo, rendering a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`RapidApi`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing the RapidAPI brand logo as an embedded base64 PNG image.

## Usage Example

```typescript
import RapidApi from "./RapidApi";

// Basic usage
<RapidApi />

// With custom dimensions and className
<RapidApi width={48} height={48} className="icon" />

// With style overrides
<RapidApi style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
- The logo image is self-contained as a base64 PNG — no external network requests required.
