A React SVG component that renders the "Buzz" icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Buzz`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded base64 PNG via an `<image>` tag.

## Usage Example

```typescript
import Buzz from "./Buzz";

// Basic usage
const App = () => <Buzz />;

// With custom dimensions and className
const App = () => (
  <Buzz
    width={64}
    height={64}
    className="my-icon"
    aria-label="Buzz"
  />
);

// With inline styles
const App = () => (
  <Buzz style={{ opacity: 0.8 }} />
);
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable via standard SVG attributes.
- The icon image is self-contained — no external asset loading required.
- Default rendered size is `32×32` pixels but can be overridden via `width`/`height` props.
