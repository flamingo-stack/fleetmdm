A React SVG component that renders the Elgato Game Capture HD device icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`ElgatoGameCaptureHd`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import ElgatoGameCaptureHd from "./ElgatoGameCaptureHd";

// Basic usage
<ElgatoGameCaptureHd />

// With custom size and class
<ElgatoGameCaptureHd width={64} height={64} className="device-icon" />

// With click handler
<ElgatoGameCaptureHd onClick={() => console.log("selected")} />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is a **base64-encoded PNG** embedded directly in the SVG — no external asset requests at runtime.
- This pattern is consistent with other device icon components in the Fleet MDM asset library.
