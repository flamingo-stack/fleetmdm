A React SVG component that renders the Marked app icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`MarkedApp`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import MarkedApp from "./MarkedApp";

// Basic usage
<MarkedApp />

// With custom dimensions or className
<MarkedApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<MarkedApp aria-label="Marked application" role="img" />
```

## Notes

- The icon image is fully self-contained — no external file dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
