React SVG icon component that renders the Appium Inspector logo as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`AppiumInspector`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full prop customization (className, style, onClick, aria-*, etc.).

## Usage Example

```typescript
import AppiumInspector from "./AppiumInspector";

// Basic usage
<AppiumInspector />

// With custom size and className
<AppiumInspector width={64} height={64} className="icon" />

// With accessibility attributes
<AppiumInspector aria-label="Appium Inspector" role="img" />
```

## Notes

- The icon is **32×32 px** by default but can be overridden via `width`/`height` props.
- The PNG is embedded as a base64 data URI inside an SVG `<image>` element — no external asset request is made.
