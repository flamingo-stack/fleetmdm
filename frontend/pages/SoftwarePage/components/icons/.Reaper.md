A React SVG component that renders a 32×32 "Reaper" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Reaper`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- The icon is rendered via an `<image>` element with a hardcoded base64 PNG `href` (512×512 source, scaled to 32×32).

## Usage Example

```typescript
import Reaper from "./Reaper";

// Basic usage
<Reaper />

// With custom size and class
<Reaper width={64} height={64} className="my-icon" />

// With style overrides
<Reaper style={{ opacity: 0.8 }} aria-label="Reaper" />
```

## Notes

- All `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are passed through via spread to the `<svg>` element.
- The default rendered size is **32×32 pixels**; override with `width`/`height` props.
- The PNG source is embedded inline — no external asset fetch required.
