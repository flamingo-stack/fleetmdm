A React SVG component that renders the Hive application icon as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`HiveApp`** — Default export. A functional React component that wraps a 32×32 base64-encoded PNG of the Hive app logo inside an `<svg>` element using an `<image>` tag.

## Usage Example

```typescript
import HiveApp from "./HiveApp";

// Basic usage
<HiveApp />

// With custom dimensions or className
<HiveApp width={64} height={64} className="app-icon" />

// With style overrides
<HiveApp style={{ borderRadius: "8px" }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The icon is self-contained — no external image files or network requests are needed.
- Default rendered size is **32×32 pixels**; override via props as needed.
