A React SVG component that renders the Loopback logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Loopback`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering the Loopback brand icon at 32×32 pixels with a base64-encoded PNG embedded via an `<image>` element.

## Usage Example

```typescript
import Loopback from "./Loopback";

// Basic usage
<Loopback />

// With custom dimensions and className
<Loopback width={64} height={64} className="icon" />

// With accessibility attributes
<Loopback aria-label="Loopback" role="img" />
```

## Notes

- Accepts all standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) via spread, allowing flexible customization.
- The icon image is self-contained as a base64 PNG — no external asset requests are needed.
- Default rendered size is **32×32px**; override via `width`/`height` props.
