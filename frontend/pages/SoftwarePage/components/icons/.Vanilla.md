A React SVG component that renders the Vanilla (JavaScript) technology icon as an inline base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Vanilla`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendered as a 32×32 SVG wrapper containing an embedded PNG image via base64 data URI.

## Usage Example

```typescript
import Vanilla from "./Vanilla";

// Basic usage
<Vanilla />

// With custom dimensions or className
<Vanilla width={64} height={64} className="tech-icon" />

// With accessibility attributes
<Vanilla aria-label="Vanilla JavaScript" role="img" />
```

## Notes

- The icon image is embedded as a base64 PNG data URI, so no external asset requests are made.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Default render size is **32×32px**; override via `width`/`height` props.
