A React SVG component that renders the Weektodo app icon as a 32×32 inline image, embedding the logo as a base64-encoded PNG data URI.

## Key Components

- **`Weektodo`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element to allow customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Weektodo from "./Weektodo";

// Basic usage
<Weektodo />

// With custom sizing or styling
<Weektodo width={64} height={64} className="icon" />

// With click handler
<Weektodo onClick={() => console.log("Weektodo clicked")} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The icon is self-contained — no external image dependencies at runtime.
- Located at: [`https://github.com/flamingo-stack/fleetmdm/blob/main/Weektodo.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Weektodo.tsx)
