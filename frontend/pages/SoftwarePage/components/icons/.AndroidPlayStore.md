SVG icon component that renders the Android Play Store logo using four colored path elements (red, yellow, blue, green) within a clipped viewport.

## Key Components

- **`AndroidPlayStore`** – Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full prop forwarding (e.g., `className`, `width`, `height`, `style`).
- **`clipPathId`** – A `lodash.uniqueId`-generated ID ensuring clip path references remain unique when multiple instances are rendered on the same page.

## Usage Example

```typescript
import AndroidPlayStore from "./AndroidPlayStore";

// Basic usage
<AndroidPlayStore />

// With custom dimensions and class
<AndroidPlayStore width={24} height={24} className="icon" />

// Inline style override
<AndroidPlayStore style={{ width: "2rem", height: "2rem" }} />
```

## Notes

- Default canvas is `32×32` with a light gray (`#e2e4ea`) background fill.
- The visible icon area is clipped to a `25.6×25.6` inner region via `<clipPath>`.
- No internal color theming — stroke/fill colors are hardcoded to match Play Store brand colors.
- Safe for multi-instance rendering due to unique clip path ID generation via `uniqueId`.
