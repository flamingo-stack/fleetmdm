A React SVG component that renders the Tuple logo as an inline SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Tuple`** — Default export. A functional React component that wraps a base64-encoded PNG of the Tuple logo inside an `<svg>` element, accepting all standard SVG props for customization.

## Usage Example

```typescript
import Tuple from "./Tuple";

// Basic usage
<Tuple />

// With custom size and className
<Tuple width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Tuple aria-label="Tuple" role="img" />
```

## Notes

- The component accepts all `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`), which are spread onto the root `<svg>` element.
- The default rendered size is **32×32px**; the embedded image is a 512×512 PNG downscaled via the `width`/`height` attributes.
- No external image assets are required — the logo is fully self-contained as a base64 data URI.
