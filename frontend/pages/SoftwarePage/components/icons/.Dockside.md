A React SVG component that renders the Dockside brand icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Dockside`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` href.

## Usage Example

```typescript
import Dockside from "./Dockside";

// Basic usage
<Dockside />

// With custom className or style
<Dockside className="icon" style={{ opacity: 0.8 }} />

// With aria label for accessibility
<Dockside aria-label="Dockside" role="img" />
```

## Notes

- The PNG image data is inlined as a base64 string — no external asset fetch required.
- All `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The fixed `width={32}` and `height={32}` defaults can be overridden by passing `width` and `height` props.
