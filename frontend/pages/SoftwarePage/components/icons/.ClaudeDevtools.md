React SVG icon component that renders the Claude Devtools logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`ClaudeDevtools`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Claude Devtools icon as an embedded base64 PNG image.

## Usage Example

```typescript
import ClaudeDevtools from "./ClaudeDevtools";

// Basic usage
<ClaudeDevtools />

// With custom dimensions and className
<ClaudeDevtools width={64} height={64} className="icon" />

// With style overrides
<ClaudeDevtools style={{ opacity: 0.8 }} aria-label="Claude Devtools" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external asset dependencies.
