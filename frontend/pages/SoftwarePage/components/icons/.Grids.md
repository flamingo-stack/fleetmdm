A React SVG component that renders a 32×32 Grids icon using an embedded base64-encoded PNG image.

## Key Components

- **`Grids`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an inline base64 PNG image asset.

## Usage Example

```typescript
import Grids from './Grids';

// Basic usage
<Grids />

// With custom dimensions or className
<Grids width={64} height={64} className="icon" />

// With accessibility attributes
<Grids aria-label="Grids icon" role="img" />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via props.
- The image is self-contained — no external asset files are required since the PNG is embedded as a base64 data URI.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
