A React SVG component that renders the ExifCleaner application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Exifcleaner`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the ExifCleaner logo as an embedded PNG.

## Usage Example

```typescript
import Exifcleaner from "./Exifcleaner";

// Basic usage
<Exifcleaner />

// With custom sizing or className
<Exifcleaner width={64} height={64} className="app-icon" />

// With style overrides
<Exifcleaner style={{ borderRadius: "8px" }} />
```

## Notes

- The icon is rendered at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The image data is embedded as a **base64 PNG** directly in the SVG, requiring no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via prop spreading.
