A React SVG icon component that renders the VirtualBox logo as a 32×32 inline image using an embedded base64-encoded PNG.

## Key Components

- **`VirtualBox`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the VirtualBox logo via an `<image>` element with an inline base64 PNG data URI.

## Usage Example

```typescript
import VirtualBox from "./VirtualBox";

// Basic usage
<VirtualBox />

// With custom dimensions or className
<VirtualBox width={64} height={64} className="icon" />

// With accessibility attributes
<VirtualBox aria-label="VirtualBox" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The logo image is fully self-contained as a base64 PNG — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
