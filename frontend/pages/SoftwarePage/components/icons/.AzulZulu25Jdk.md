A React SVG icon component that renders the Azul Zulu 25 JDK logo as a 32×32 inline image using an embedded base64-encoded PNG.

## Key Components

- **`AzulZulu25Jdk`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 SVG wrapper around a base64-encoded PNG of the Azul Zulu 25 JDK icon.

## Usage Example

```typescript
import AzulZulu25Jdk from "./AzulZulu25Jdk";

// Basic usage
<AzulZulu25Jdk />

// With custom props
<AzulZulu25Jdk className="icon" aria-label="Azul Zulu 25 JDK" />

// With custom dimensions (overrides default 32x32)
<AzulZulu25Jdk width={64} height={64} />
```

## Notes

- The icon image is embedded as a base64 PNG, so no external asset dependencies are required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via spread.
