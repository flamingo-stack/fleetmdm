A React SVG component that renders the ActiveDock application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Activedock`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the ActiveDock icon as an embedded PNG via a `data:image/png;base64` URI.

## Usage Example

```typescript
import Activedock from './Activedock';

// Basic usage
<Activedock />

// With custom size and className
<Activedock width={64} height={64} className="app-icon" />

// With style overrides
<Activedock style={{ opacity: 0.8 }} aria-label="ActiveDock" />
```

## Notes

- The icon is a 512×512 PNG (per embedded EXIF metadata) downscaled to 32×32 via the SVG viewport.
- All `SVGProps<SVGSVGElement>` attributes (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded directly to the root `<svg>` element.
- No external dependencies beyond React.
