A React SVG component that renders the Codex app icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CodexApp` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component with a base64-embedded PNG |

## Usage Example

```typescript
import CodexApp from './CodexApp';

// Basic usage
<CodexApp />

// With custom dimensions and className
<CodexApp width={64} height={64} className="app-icon" />

// With inline styles
<CodexApp style={{ borderRadius: '8px' }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`)
- Default rendered size is **32×32px**; the embedded PNG is natively **512×512px** for high-DPI display
- The icon is self-contained — no external image dependencies or network requests
