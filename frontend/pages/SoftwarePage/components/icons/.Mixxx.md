A React SVG component that renders the Mixxx logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Mixxx`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG element with the Mixxx logo embedded as a base64 PNG `<image>`.

## Usage Example

```typescript
import Mixxx from "./Mixxx";

// Basic usage
<Mixxx />

// With custom class or style
<Mixxx className="app-icon" style={{ opacity: 0.8 }} />

// With aria label for accessibility
<Mixxx aria-label="Mixxx" role="img" />
```

## Notes

- The icon dimensions are fixed at `32×32` by default but can be overridden via props.
- The PNG data is inlined as a base64 `href` on an SVG `<image>` element, so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread.
