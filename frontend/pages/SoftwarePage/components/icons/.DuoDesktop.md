A React SVG icon component that renders the Duo Desktop application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`DuoDesktop`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing the Duo Desktop logo as an embedded PNG via base64 data URI.

## Usage Example

```typescript
import DuoDesktop from "./DuoDesktop";

// Basic usage
<DuoDesktop />

// With custom dimensions or className
<DuoDesktop width={64} height={64} className="icon" />

// With inline styles
<DuoDesktop style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The logo image is self-contained — no external assets or network requests are required.
