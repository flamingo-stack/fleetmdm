A React SVG component that renders the Clockify Desktop application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`ClockifyDesktop`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Clockify Desktop icon as an embedded PNG.

## Usage Example

```typescript
import ClockifyDesktop from "./ClockifyDesktop";

// Basic usage
<ClockifyDesktop />

// With custom dimensions
<ClockifyDesktop width={64} height={64} />

// With additional SVG props
<ClockifyDesktop className="app-icon" aria-label="Clockify Desktop" />
```

## Notes

- The icon is self-contained — no external image files or network requests are required at runtime.
- The component is fully typed via `SVGProps<SVGSVGElement>`, so all standard SVG attributes (`className`, `style`, `onClick`, `aria-*`, etc.) are supported.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
