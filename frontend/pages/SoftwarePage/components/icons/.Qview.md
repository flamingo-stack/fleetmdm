A React SVG component that renders the Qview logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Qview`** — Default export. A functional React component that renders a 32×32 SVG element containing the Qview logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Qview from "./Qview";

// Basic usage
<Qview />

// With custom dimensions or className
<Qview width={64} height={64} className="my-icon" />

// With accessibility attributes
<Qview aria-label="Qview" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The default rendered size is **32×32 pixels**.
- The logo image is self-contained as a base64-encoded PNG — no external asset dependencies.
