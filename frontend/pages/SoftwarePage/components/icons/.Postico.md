React SVG icon component that renders the Postico database client application icon as a 32×32 inline PNG image embedded via base64 within an SVG wrapper.

## Key Components

- **`Postico`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Postico app icon as an embedded base64-encoded PNG.

## Usage Example

```typescript
import Postico from "./Postico";

// Basic usage
<Postico />

// With custom dimensions and className
<Postico width={64} height={64} className="app-icon" />

// With style overrides
<Postico style={{ opacity: 0.8 }} aria-label="Postico" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props are forwarded directly to the root `<svg>` element, enabling full customization (size, className, style, aria attributes, etc.).
- The icon image is self-contained — no external asset fetch is required at runtime.
- Default dimensions are `32×32` pixels; override via `width`/`height` props as needed.
