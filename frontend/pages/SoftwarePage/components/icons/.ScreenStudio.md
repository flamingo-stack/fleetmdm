A React SVG component that renders the Screen Studio application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`ScreenStudio`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG icon.

## Usage Example

```typescript
import ScreenStudio from "./ScreenStudio";

// Basic usage
<ScreenStudio />

// With custom dimensions or className
<ScreenStudio width={64} height={64} className="app-icon" />

// With aria label for accessibility
<ScreenStudio aria-label="Screen Studio" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via spread to the root `<svg>` element.
- The icon image is embedded as a base64 PNG, so no external asset file is required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
