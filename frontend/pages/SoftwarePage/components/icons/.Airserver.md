A React component that renders the AirServer application icon as an SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Airserver`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Airserver from "./Airserver";

// Basic usage
<Airserver />

// With custom dimensions or className
<Airserver width={64} height={64} className="app-icon" />

// With style overrides
<Airserver style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default; `width` and `height` props can override this via spread.
- The PNG image data is embedded inline as a base64 `data:image/png` URI — no external asset fetch required.
