React SVG component that renders the Calibre application icon as a 32×32 PNG embedded via a base64-encoded data URI.

## Key Components

- **`Calibre`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the wrapping `<svg>` element.

## Usage Example

```typescript
import Calibre from "./Calibre";

// Basic usage
<Calibre />

// With custom dimensions or className
<Calibre width={64} height={64} className="icon" />

// With aria label for accessibility
<Calibre aria-label="Calibre" role="img" />
```

## Notes

- The icon is statically embedded as a base64 PNG inside an SVG `<image>` element — no external asset fetch required.
- Default size is **32×32 pixels**; override via `width`/`height` props.
- Fully compatible with any React project using standard SVG prop conventions.
