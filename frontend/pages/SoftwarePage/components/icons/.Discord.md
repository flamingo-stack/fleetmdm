React SVG icon component that renders the Discord logo as an embedded base64 PNG image within an SVG wrapper.

## Key Components

- **`Discord`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props
- Renders a 32×32 SVG containing a `<image>` element with the Discord logo encoded as an inline base64 PNG
- All SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element

## Usage Example

```typescript
import Discord from "./Discord";

// Basic usage
<Discord />

// With custom size and class
<Discord width={24} height={24} className="icon" />

// With click handler
<Discord onClick={() => window.open("https://discord.com")} />
```

## Notes

- The logo is fully self-contained — no external image requests are made at runtime
- Default dimensions are **32×32 pixels**; override via `width`/`height` props
- Suitable for use in nav bars, social link lists, or anywhere a Discord brand icon is needed
