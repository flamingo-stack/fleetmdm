A React SVG icon component that renders the DBeaver Enterprise Edition logo as a Base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`DBeaverEe`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the DBeaver EE icon as an inline Base64 PNG image.

## Usage Example

```typescript
import DBeaverEe from "./DBeaverEe";

// Basic usage
<DBeaverEe />

// With custom dimensions or className
<DBeaverEe width={64} height={64} className="icon" />

// With accessibility attributes
<DBeaverEe aria-label="DBeaver Enterprise Edition" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The icon image is self-contained as a Base64-encoded PNG — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
