A React SVG component that renders the BetterZip application icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Betterzip`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Betterzip from "./Betterzip";

// Basic usage
<Betterzip />

// With custom dimensions or className
<Betterzip width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Betterzip aria-label="BetterZip" role="img" />
```

## Notes

- The icon is self-contained — no external image requests are made at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are supported via prop spreading.
