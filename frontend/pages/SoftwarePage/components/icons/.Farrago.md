A React SVG component that renders the Farrago logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Farrago`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Farrago logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Farrago from "./Farrago";

// Basic usage
<Farrago />

// With custom dimensions and className
<Farrago width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Farrago aria-label="Farrago logo" role="img" />
```

## Notes

- The logo image is fully self-contained — no external assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
