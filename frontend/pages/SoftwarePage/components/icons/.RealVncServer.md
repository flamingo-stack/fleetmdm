A React SVG icon component that renders the RealVNC Server application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`RealVncServer`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the RealVNC Server icon as an embedded PNG image.

## Usage Example

```typescript
import RealVncServer from "./RealVncServer";

// Basic usage
<RealVncServer />

// With custom size and className
<RealVncServer width={64} height={64} className="icon" />

// With accessibility attributes
<RealVncServer aria-label="RealVNC Server" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained — no external asset dependencies.
