A React SVG component that renders the Draw.io (diagrams.net) application logo as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Drawio`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 `<svg>` containing a base64-encoded PNG `<image>`.

## Usage Example

```typescript
import Drawio from "./DrawIo";

// Basic usage
<Drawio />

// With custom dimensions and className
<Drawio width={64} height={64} className="app-icon" />

// With inline style
<Drawio style={{ opacity: 0.8 }} />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The logo image is self-contained as a base64 PNG — no external assets or network requests required.
- Default render size is `32×32` pixels; override via the `width`/`height` props.
