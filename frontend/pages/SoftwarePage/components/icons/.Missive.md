A React SVG component that renders the Missive logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Missive`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing the Missive brand logo as an embedded PNG image.

## Usage Example

```typescript
import Missive from "./Missive";

// Basic usage
<Missive />

// With custom dimensions and className
<Missive width={64} height={64} className="my-icon" />

// With style overrides
<Missive style={{ opacity: 0.8 }} />
```

## Notes

- The logo image is embedded as a base64-encoded PNG (512×512 source), scaled to 32×32 by default.
- All standard `SVGProps` are forwarded to the root `<svg>` element, enabling full customization of size, accessibility attributes, and event handlers.
