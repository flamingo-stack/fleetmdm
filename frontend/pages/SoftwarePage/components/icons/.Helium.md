A React SVG component that renders a 32×32 Helium icon using an embedded base64-encoded PNG image.

## Key Components

- **`Helium`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper containing an inline base64 PNG image.

## Usage Example

```typescript
import Helium from "./Helium";

// Basic usage
<Helium />

// With custom dimensions or className
<Helium width={64} height={64} className="my-icon" />

// With accessibility attributes
<Helium aria-label="Helium" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon graphic is self-contained — no external image assets are required at runtime.
