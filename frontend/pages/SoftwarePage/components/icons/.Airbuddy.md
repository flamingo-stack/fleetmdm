A React SVG component that renders the Airbuddy application icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Airbuddy`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.)

## Usage Example

```typescript
import Airbuddy from "./Airbuddy";

// Basic usage
<Airbuddy />

// With custom size and class
<Airbuddy width={64} height={64} className="app-icon" />

// With click handler
<Airbuddy onClick={() => console.log("Airbuddy clicked")} />
```

## Notes

- The icon is self-contained — no external image files are required.
- Default dimensions are **32×32px**; override via `width`/`height` props.
- The embedded PNG was originally rendered at 512×512 (per EXIF metadata) and downscaled for display.
