React SVG component that renders the CleanShot X application icon as an inline PNG image encoded in Base64, embedded within an SVG wrapper.

## Key Components

- **`CleanShotX`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the CleanShot X app icon as a Base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import CleanShotX from "./CleanShotX";

// Basic usage
<CleanShotX />

// With custom dimensions or className
<CleanShotX width={64} height={64} className="app-icon" />

// With accessibility attributes
<CleanShotX aria-label="CleanShot X" role="img" />
```

## Notes

- The icon is self-contained — no external image files or network requests are required.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`), but `width` and `height` default to `32`.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
