A React SVG component that renders the Popchar application icon as a 32×32 pixel embedded PNG image within an SVG wrapper.

## Key Components

- **`Popchar`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a base64-encoded PNG icon.

## Usage Example

```typescript
import Popchar from "./Popchar";

// Basic usage
<Popchar />

// With custom dimensions or className
<Popchar width={64} height={64} className="app-icon" />

// With accessibility attributes
<Popchar aria-label="Popchar" role="img" />
```

## Notes

- The icon image is inlined as a base64-encoded PNG (`data:image/png;base64,...`), meaning no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is `32×32` but can be overridden via `width` and `height` props.
