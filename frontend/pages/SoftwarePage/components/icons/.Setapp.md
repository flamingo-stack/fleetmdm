A React SVG component that renders the Setapp application icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Setapp`** — Default export. A functional React component that wraps a base64-encoded PNG of the Setapp logo inside an `<svg>` element. Accepts all standard `SVGProps<SVGSVGElement>` props for full customization (e.g., `className`, `style`, `aria-*`).

## Usage Example

```typescript
import Setapp from "./Setapp";

// Basic usage
<Setapp />

// With custom size and class
<Setapp width={64} height={64} className="app-icon" />

// With accessibility attributes
<Setapp aria-label="Setapp" role="img" />
```

## Notes

- The icon is rendered at **32×32px** by default.
- The image data is embedded as a base64 PNG directly in the SVG `<image>` element, meaning no external asset requests are made.
- Fully compatible with standard SVG prop overrides via `SVGProps<SVGSVGElement>`, allowing size, color filter, and layout customization at the call site.
