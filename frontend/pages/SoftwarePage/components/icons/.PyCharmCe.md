React SVG icon component that renders the PyCharm Community Edition logo as an inline SVG using a base64-encoded PNG image.

## Key Components

- **`PyCharmCe`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG of the PyCharm CE logo.

## Usage Example

```typescript
import PyCharmCe from "./PyCharmCe";

// Basic usage
<PyCharmCe />

// With custom size and className
<PyCharmCe width={64} height={64} className="icon" />

// With accessibility attributes
<PyCharmCe aria-label="PyCharm Community Edition" role="img" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via props.
- The image data is self-contained (base64 PNG), requiring no external assets or network requests.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element.
