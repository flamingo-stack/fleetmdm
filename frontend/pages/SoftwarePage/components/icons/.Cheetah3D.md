A React SVG component that renders the Cheetah3D application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Cheetah3D`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Cheetah3D from "./Cheetah3D";

// Basic usage
<Cheetah3D />

// With custom size and className
<Cheetah3D width={64} height={64} className="app-icon" />

// With accessibility attributes
<Cheetah3D aria-label="Cheetah3D" role="img" />
```

## Notes

- The icon is a fixed 32×32 SVG by default but can be overridden via `width`/`height` props.
- The image data is embedded as a base64 PNG inside an SVG `<image>` element, so no external asset requests are made.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root element.
