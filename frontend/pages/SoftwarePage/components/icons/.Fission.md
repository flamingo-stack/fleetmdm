A React SVG component that renders the Fission logo/icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Fission`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Fission from './Fission';

// Basic usage
<Fission />

// With custom sizing or className
<Fission width={64} height={64} className="my-icon" />

// With accessibility attributes
<Fission aria-label="Fission" role="img" />
```

## Notes

- The component spreads all passed `SVGProps` onto the root `<svg>` element, making it fully customizable (size, color, style, event handlers, etc.).
- The icon image is self-contained — no external assets or network requests required.
- Default dimensions are `32×32`; override via `width`/`height` props.
