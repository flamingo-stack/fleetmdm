A React SVG component that renders a 32×32 Bezel icon using an embedded base64-encoded PNG image.

## Key Components

- **`Bezel`** — Default export. A functional React component that wraps a base64-encoded PNG inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Bezel from './Bezel';

// Basic usage
<Bezel />

// With custom dimensions or className
<Bezel width={64} height={64} className="icon" />

// With style overrides
<Bezel style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image is self-contained as a base64 PNG — no external asset dependencies.
- Supports all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
