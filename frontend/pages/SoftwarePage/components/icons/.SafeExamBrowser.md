A React SVG component that renders the Safe Exam Browser application icon as an inline SVG containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SafeExamBrowser`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 `<svg>` with an `<image>` element containing the icon as a base64 PNG data URI.

## Usage Example

```typescript
import SafeExamBrowser from "./SafeExamBrowser";

// Basic usage
<SafeExamBrowser />

// With custom sizing and styling
<SafeExamBrowser
  width={64}
  height={64}
  className="app-icon"
  aria-label="Safe Exam Browser"
/>
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via prop spreading.
- The icon is self-contained — no external image URL or asset import is required.
- Default render size is **32×32 px**; override via `width`/`height` props as needed.
