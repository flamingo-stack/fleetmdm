React SVG component that renders the Snagit application icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Snagit`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing a base64-encoded Snagit logo PNG via an `<image>` element.

## Usage Example

```typescript
import Snagit from "./Snagit";

// Basic usage
<Snagit />

// With custom dimensions or className
<Snagit width={64} height={64} className="app-icon" />

// With style overrides
<Snagit style={{ opacity: 0.8 }} aria-label="Snagit" />
```

## Notes

- The icon is self-contained — no external image files or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
