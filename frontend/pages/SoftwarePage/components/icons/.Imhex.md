A React SVG component that renders the ImHex icon as an embedded base64-encoded PNG image within an SVG container.

## Key Components

- **`Imhex`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the ImHex application icon as a base64 PNG.

## Usage Example

```typescript
import { Imhex } from './Imhex';

// Basic usage
<Imhex />

// With custom dimensions and className
<Imhex width={64} height={64} className="tool-icon" />

// With style overrides
<Imhex style={{ opacity: 0.8 }} aria-label="ImHex icon" />
```

## Notes

- The icon is a 32×32 SVG wrapper around a base64-encoded PNG (original resolution 512×512 per embedded EXIF metadata).
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread to the root `<svg>` element.
