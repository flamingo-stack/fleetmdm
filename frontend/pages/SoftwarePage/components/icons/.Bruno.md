A React SVG icon component that renders the Bruno API client logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Bruno`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which renders an `<svg>` wrapper containing a `<image>` element with the Bruno logo encoded as a base64 PNG.

## Usage Example

```typescript
import Bruno from "./Bruno";

// Basic usage
<Bruno />

// With custom size or className
<Bruno width={64} height={64} className="icon" />

// With accessibility attributes
<Bruno aria-label="Bruno" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` props onto the root `<svg>` element, allowing full customization of attributes like `width`, `height`, `className`, and `style`.
- The default dimensions are **32×32 pixels**. Override via props as needed.
- The logo image is self-contained (no external network requests) due to base64 encoding.
