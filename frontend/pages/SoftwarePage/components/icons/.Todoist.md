React SVG component that renders the Todoist brand logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Todoist`** — Default export; a functional React component wrapping an `<svg>` element that displays the Todoist icon via an embedded base64 PNG `<image>` tag. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Todoist from "./Todoist";

// Basic usage
<Todoist />

// Custom size and className
<Todoist width={64} height={64} className="my-icon" />

// With inline style
<Todoist style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The image data is fully self-contained (base64 PNG), so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded via spread, making it accessible and flexible.
