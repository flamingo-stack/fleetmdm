A React SVG component that renders the Morgen app icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Morgen`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Morgen logo as an embedded PNG image.

## Usage Example

```typescript
import Morgen from "./Morgen";

// Basic usage
<Morgen />

// With custom dimensions or className
<Morgen width={64} height={64} className="icon" />

// With style overrides
<Morgen style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at 32×32 pixels by default but can be overridden via props.
- The image data is self-contained as a base64 PNG — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
