A React SVG component that renders the Akiflow logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Akiflow`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing callers to pass any valid SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Akiflow from "./Akiflow";

// Basic usage
<Akiflow />

// With custom dimensions and class
<Akiflow width={64} height={64} className="icon" />

// With click handler
<Akiflow onClick={() => console.log("clicked")} />
```

## Notes

- The logo image is embedded as a base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` element, so no external file dependency is required.
- Default render size is **32×32px**; override via `width`/`height` props.
- Fully typed via `SVGProps<SVGSVGElement>` from React's type definitions.
