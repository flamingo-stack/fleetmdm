Renders a PagerDuty (Pd) logo as a React SVG component with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Pd`** — Default export. A functional React component that renders an SVG wrapper containing the PagerDuty logo as an inline base64 PNG image.

## Usage Example

```typescript
import Pd from "./Pd";

// Basic usage
<Pd />

// With custom dimensions or className
<Pd width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Pd aria-label="PagerDuty" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/common) props, allowing full customization (e.g., `className`, `style`, `onClick`).
- Default rendered size is **32×32px**.
- The image data is self-contained (base64 PNG), requiring no external asset files or network requests.
