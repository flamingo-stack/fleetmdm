React SVG wrapper component that renders the MxPowerGadget application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`MxPowerGadget`** — A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing a base64-encoded PNG icon for the [MxPowerGadget](https://www.intel.com/content/www/us/en/developer/articles/tool/power-gadget.html) macOS power monitoring utility.

## Usage Example

```typescript
import MxPowerGadget from "./MxPowerGadget";

// Basic usage
<MxPowerGadget />

// With custom dimensions or class
<MxPowerGadget width={64} height={64} className="app-icon" />

// With accessibility attributes
<MxPowerGadget aria-label="MxPowerGadget" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of size, class, style, and accessibility attributes.
- The icon is rendered via an `<image>` element with a base64-encoded PNG (512×512 source, displayed at 32×32), so no external image assets are required.
- Likely used within Fleet MDM's software catalog or asset inventory UI to visually identify the MxPowerGadget application on managed macOS devices.
