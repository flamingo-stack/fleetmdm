SVG icon component that renders the PyCharm IDE logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`PyCharm`** — Default exported React functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute customization (className, style, width, height, etc.)
- Renders a 32×32 SVG containing an `<image>` element with an inline base64-encoded PNG of the PyCharm logo

## Usage Example

```typescript
import PyCharm from "./PyCharm";

// Basic usage
<PyCharm />

// With custom size and className
<PyCharm width={48} height={48} className="icon" />

// With inline styles
<PyCharm style={{ marginRight: 8 }} />
```

## Notes

- Default dimensions are **32×32 pixels** but can be overridden via props
- The logo is self-contained — no external image assets or network requests required
