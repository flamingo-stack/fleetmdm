A React SVG component that renders the "Captain" icon as an inline SVG embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Captain`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- **Embedded image** — A 256×256 PNG encoded as a base64 `data:image/png` URI, rendered via an SVG `<image>` element scaled to 32×32.

## Usage Example

```typescript
import Captain from "./Captain";

// Basic usage
<Captain />

// With custom size and className
<Captain width={64} height={64} className="icon" />

// With style overrides
<Captain style={{ opacity: 0.8 }} aria-label="Captain icon" />
```

## Notes

- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>`, so `width`, `height`, `className`, `style`, `aria-*`, and event handlers are all supported.
- The visual content is a self-contained base64 PNG — no external asset requests are made.
- Default rendered size is **32×32px**; override via `width`/`height` props.
