A React SVG component that renders the Pastebot application icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Pastebot`** — Default export. A functional React component that wraps a 32×32 `<svg>` element containing an `<image>` tag with a base64-encoded PNG. Accepts and forwards all standard `SVGProps<SVGSVGElement>` props.

## Usage Example

```typescript
import Pastebot from "./Pastebot";

// Basic usage
<Pastebot />

// With custom dimensions or className
<Pastebot width={64} height={64} className="icon" />

// With accessibility attributes
<Pastebot aria-label="Pastebot" role="img" />
```

## Notes

- The icon image is fully self-contained via a base64 data URI — no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props.
