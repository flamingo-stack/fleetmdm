React SVG component that renders the Dell Command Update application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`DellCommandUpdate`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Dell Command Update logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import DellCommandUpdate from "./DellCommandUpdate";

// Basic usage
<DellCommandUpdate />

// With custom dimensions or className
<DellCommandUpdate width={64} height={64} className="app-icon" />

// With accessibility attributes
<DellCommandUpdate aria-label="Dell Command Update" role="img" />
```

## Notes

- The icon is self-contained — no external image files or network requests are needed.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via the spread `{...props}`.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props.
- Typically used within Fleet MDM's software catalog or device management UI to identify Dell Command Update as a managed application.
