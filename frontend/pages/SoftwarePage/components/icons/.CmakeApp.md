React SVG component that renders the CMake application icon as an embedded 32×32 PNG image using a base64-encoded data URI.

## Key Components

- **`CmakeApp`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the CMake logo as an inline SVG containing a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import CmakeApp from "./CmakeApp";

// Basic usage
<CmakeApp />

// With custom dimensions or className
<CmakeApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<CmakeApp aria-label="CMake" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The PNG image data is fully inlined as a base64 string, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via the spread `{...props}` pattern.
