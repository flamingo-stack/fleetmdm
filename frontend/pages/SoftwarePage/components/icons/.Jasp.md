A React SVG icon component that renders the JASP (Just Another Statistics Program) logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Jasp` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders the JASP logo SVG icon |

## Usage Example

```typescript
import Jasp from './Jasp';

// Basic usage
<Jasp />

// With custom dimensions and styling
<Jasp width={64} height={64} className="icon" />

// With accessibility attributes
<Jasp aria-label="JASP" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of size, class, style, and ARIA attributes.
- The icon defaults to **32×32px** but can be overridden via `width`/`height` props.
- The logo image is embedded as a **base64 PNG** inside an `<image>` element — no external network request is made.
- Part of the icon set in [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Jasp.tsx).
