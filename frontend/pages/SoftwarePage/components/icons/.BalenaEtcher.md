SVG icon component that renders the Balena Etcher logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`BalenaEtcher`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Balena Etcher logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import BalenaEtcher from "./BalenaEtcher";

// Basic usage
<BalenaEtcher />

// With custom dimensions or className
<BalenaEtcher width={64} height={64} className="my-icon" />

// With style overrides
<BalenaEtcher style={{ opacity: 0.8 }} aria-label="Balena Etcher" />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- The PNG bitmap is fully self-contained (no external network requests).
- All standard `SVGProps` (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via spread.
- Defined using a React arrow function with TypeScript generic typing — no `forwardRef` is used, so `ref` forwarding is not supported.
