A React SVG component that renders the **Jiggler** icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Jiggler`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Jiggler from "./Jiggler";

// Basic usage
<Jiggler />

// With custom dimensions or className
<Jiggler width={64} height={64} className="icon" />

// With aria attributes for accessibility
<Jiggler aria-label="Jiggler icon" role="img" />
```

## Notes

- The PNG image data is fully self-contained via base64 encoding — no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via `{...props}`.
- The component is defined as a `const` arrow function — ensure the consuming module handles the default export pattern (no `export default` shown, but typical for icon component conventions in this codebase).
