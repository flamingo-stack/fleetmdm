SVG React component that renders the Origami Studio application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `OrigamiStudio` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG wrapper component for the Origami Studio icon |

## Usage Example

```typescript
import OrigamiStudio from "./OrigamiStudio";

// Basic usage
<OrigamiStudio />

// With custom dimensions or className
<OrigamiStudio width={64} height={64} className="app-icon" />

// With style overrides
<OrigamiStudio style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, enabling full styling and accessibility overrides.
- The icon image is self-contained as a base64-encoded PNG — no external asset files or network requests required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
