React SVG component that renders the OneDrive brand logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`OneDrive`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the OneDrive icon as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import OneDrive from "./OneDrive";

// Basic usage
<OneDrive />

// With custom dimensions and className
<OneDrive width={64} height={64} className="icon" />

// With accessible title via aria attributes
<OneDrive aria-label="OneDrive" role="img" />
```

## Notes

- The icon is **self-contained** — no external image requests; the PNG is fully inlined as a base64 data URI.
- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
