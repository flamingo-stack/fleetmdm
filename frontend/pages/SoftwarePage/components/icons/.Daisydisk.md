A React SVG component that renders the DaisyDisk application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Daisydisk`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the DaisyDisk app icon as an embedded base64 PNG image.

## Usage Example

```typescript
import Daisydisk from "./Daisydisk";

// Basic usage
<Daisydisk />

// With custom dimensions or className
<Daisydisk width={64} height={64} className="app-icon" />

// With style overrides
<Daisydisk style={{ opacity: 0.8 }} />
```

## Notes

- The icon is self-contained — no external image assets or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
