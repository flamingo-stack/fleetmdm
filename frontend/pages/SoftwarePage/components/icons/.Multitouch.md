A React SVG component that renders a 32×32 multitouch icon using an embedded base64-encoded PNG image.

## Key Components

- **`Multitouch`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a fixed-size SVG wrapper around an inline PNG icon.

## Usage Example

```typescript
import Multitouch from "./Multitouch";

// Basic usage
<Multitouch />

// With custom styling
<Multitouch className="icon" style={{ opacity: 0.8 }} />

// With ARIA label for accessibility
<Multitouch aria-label="Multitouch gesture" role="img" />
```

## Notes

- The icon dimensions are fixed at `32×32` pixels via the SVG `width`/`height` attributes, though these can be overridden via props.
- The image data is a base64-encoded PNG embedded directly in the component — no external asset files are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
