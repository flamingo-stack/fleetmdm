A React SVG component that renders the Paletro app icon as an inline SVG element containing an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Paletro`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG icon.

## Usage Example

```typescript
import Paletro from "./Paletro";

// Basic usage
<Paletro />

// With custom size or className
<Paletro width={64} height={64} className="app-icon" />

// With accessibility attributes
<Paletro aria-label="Paletro" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, class, style, ARIA attributes, etc.).
- The icon image is embedded as a base64 PNG via an `<image>` element, so no external asset loading is required.
- Default dimensions are `width={32}` and `height={32}` but can be overridden via props.
