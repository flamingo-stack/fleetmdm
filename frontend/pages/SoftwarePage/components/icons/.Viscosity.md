SVG icon component for the Viscosity VPN application. Renders a 32×32 PNG asset (embedded as a base64 data URI) wrapped in an SVG container with full React SVG prop forwarding.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Viscosity` | `React.FC<SVGProps<SVGSVGElement>>` | Default export — renders the Viscosity app icon as a 32×32 SVG with an embedded PNG image |

## Usage Example

```typescript
import Viscosity from "./Viscosity";

// Basic usage
<Viscosity />

// With custom dimensions or class
<Viscosity width={64} height={64} className="app-icon" />

// With accessibility attributes
<Viscosity aria-label="Viscosity VPN" role="img" />
```

## Notes

- The component accepts all standard `SVGProps<SVGSVGElement>` props, enabling full customization (e.g., `className`, `style`, `onClick`, `aria-*`).
- The icon image is self-contained — no external asset dependencies at runtime.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Viscosity.tsx)
