A React SVG component that renders a "blurscreen" icon as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Blurscreen`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG image of a blurscreen icon.

## Usage Example

```typescript
import Blurscreen from "./Blurscreen";

// Basic usage
<Blurscreen />

// With custom dimensions and className
<Blurscreen width={64} height={64} className="icon" />

// With inline styles
<Blurscreen style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is self-contained as a base64 PNG — no external asset files are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
