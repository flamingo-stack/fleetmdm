A React SVG component that renders the OpenMTP application icon as an inline 32×32 PNG image embedded via base64 data URI.

## Key Components

- **`Openmtp`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper containing the OpenMTP logo as an embedded base64 PNG.

## Usage Example

```typescript
import Openmtp from "./Openmtp";

// Basic usage
<Openmtp />

// With custom sizing or className
<Openmtp width={64} height={64} className="app-icon" />

// With style overrides
<Openmtp style={{ opacity: 0.8 }} aria-label="OpenMTP" />
```

## Notes

- The icon image is self-contained — no external image fetch required at runtime.
- All `SVGSVGElement` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default render size is **32×32px**; the embedded PNG source is **512×512px**, so the component scales cleanly at larger sizes.
