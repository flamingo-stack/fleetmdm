React SVG component that renders the Superkey icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`Superkey`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG image of the Superkey icon.

## Usage Example

```typescript
import Superkey from "./Superkey";

// Basic usage
<Superkey />

// With custom dimensions or className
<Superkey width={64} height={64} className="icon" />

// With accessible title via aria attributes
<Superkey aria-label="Superkey" role="img" />
```

## Notes

- The icon is hardcoded as a base64-encoded PNG (`data:image/png;base64,...`) embedded inside an `<image>` element, rendered at 32×32 pixels by default.
- All SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
