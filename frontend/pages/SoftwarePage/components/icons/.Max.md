React SVG icon component that renders a "Max" icon using an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Max`** — Default export functional component accepting all standard `SVGProps<SVGSVGElement>` props, renders a 32×32 SVG containing an inline base64 PNG image

## Usage Example

```typescript
import Max from './Max';

// Basic usage
<Max />

// With custom dimensions and className
<Max width={64} height={64} className="icon" />

// With accessibility attributes
<Max aria-label="Max icon" role="img" />

// With style overrides
<Max style={{ opacity: 0.8 }} />
```

## Notes

- Fixed default dimensions of **32×32 pixels**, overridable via props
- The icon image is embedded as a base64-encoded PNG (`data:image/png;base64,...`), making it self-contained with no external asset dependencies
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) via spread
