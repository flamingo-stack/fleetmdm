SVG icon component that renders the Retrobatch application logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Retrobatch`** — Default exported React functional component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG containing an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Retrobatch from "./Retrobatch";

// Basic usage
<Retrobatch />

// With custom sizing or className
<Retrobatch width={64} height={64} className="app-icon" />

// With inline style
<Retrobatch style={{ borderRadius: 4 }} />
```

## Notes

- The icon image is self-contained — no external asset fetches required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element.
- The source file is located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Retrobatch.tsx).
