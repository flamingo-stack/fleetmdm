SVG icon component that renders a 32×32 PNG image (base64-encoded) of the "RocketmanChoicesPackager" logo for use in React applications.

## Key Components

- **`RocketmanChoicesPackager`** — A React functional component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG wrapper containing a base64-encoded PNG image asset.

## Usage Example

```typescript
import { RocketmanChoicesPackager } from "./RocketmanChoicesPackager";

// Basic usage
<RocketmanChoicesPackager />

// With custom dimensions or className
<RocketmanChoicesPackager width={64} height={64} className="my-icon" />

// With style override
<RocketmanChoicesPackager style={{ opacity: 0.8 }} />
```

## Notes

- The component passes all `SVGProps<SVGSVGElement>` through to the root `<svg>` element, making it fully customizable (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The PNG image is embedded as a base64 `data:image/png` string inside an `<image>` element, so no external asset file is required at runtime.
- Default rendered size is **32×32 pixels**; override via props as needed.
