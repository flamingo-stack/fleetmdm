A React component that renders the Smartsheet brand icon as an SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Smartsheet`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image of the Smartsheet logo.

## Usage Example

```typescript
import Smartsheet from "./Smartsheet";

// Basic usage
<Smartsheet />

// With custom dimensions and className
<Smartsheet width={64} height={64} className="icon" />

// With inline styles
<Smartsheet style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG — no external image requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via prop spreading.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
