A React SVG component that renders the Anytype application icon as a 32×32 inline PNG image embedded via a base64 data URI.

## Key Components

- **`Anytype`** — Default export. A functional React component that wraps a base64-encoded PNG logo inside an `<svg>` element, forwarding all standard `SVGProps` to the root `<svg>` node.

## Usage Example

```typescript
import Anytype from "./Anytype";

// Basic usage
<Anytype />

// With custom size or className
<Anytype width={64} height={64} className="icon" />

// With accessibility attributes
<Anytype aria-label="Anytype" role="img" />
```

## Notes

- The icon is a **32×32** SVG shell containing a fixed PNG image; scaling via `width`/`height` props resizes the SVG viewport but not the raster image quality.
- All [`SVGProps`](https://react.dev/reference/react-dom/components/svg) (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The image data is self-contained — no external network request is made at render time.
