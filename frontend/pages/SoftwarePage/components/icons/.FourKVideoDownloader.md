A React SVG component that renders an embedded 32×32 PNG icon for a "4K Video Downloader" application using a base64-encoded image embedded within an SVG wrapper.

## Key Components

- **`FourKVideoDownloader`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an inline base64 PNG image asset.

## Usage Example

```typescript
import FourKVideoDownloader from "./FourKVideoDownloader";

// Basic usage
<FourKVideoDownloader />

// With custom dimensions and className
<FourKVideoDownloader
  width={64}
  height={64}
  className="app-icon"
  aria-label="4K Video Downloader"
/>

// With inline styles
<FourKVideoDownloader style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is fully self-contained as a base64-encoded PNG — no external asset files or network requests are required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
