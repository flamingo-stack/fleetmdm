React SVG icon component that renders the BetterTouchTool application icon as a 32×32 embedded PNG image within an SVG wrapper.

## Key Components

- **`Bettertouchtool`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the BetterTouchTool app icon.

## Usage Example

```typescript
import Bettertouchtool from "./Bettertouchtool";

// Basic usage
<Bettertouchtool />

// With custom dimensions or className
<Bettertouchtool width={64} height={64} className="app-icon" />

// With inline styles
<Bettertouchtool style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered via an SVG `<image>` element with an embedded base64 PNG (`data:image/png;base64,...`), so no external asset requests are made.
- Default size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
