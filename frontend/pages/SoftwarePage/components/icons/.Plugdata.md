A React SVG icon component that renders the Plugdata application logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`Plugdata`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass any native SVG attributes (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Plugdata from "./Plugdata";

// Basic usage
<Plugdata />

// With custom size and className
<Plugdata width={64} height={64} className="icon" />

// With event handler
<Plugdata onClick={() => console.log("clicked")} />
```

## Notes

- Fixed internal dimensions of `32×32`, though `width`/`height` props can override the rendered size via SVG scaling.
- The logo is embedded as a base64 PNG `<image>` element, so no external image assets are required.
