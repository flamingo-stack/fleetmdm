SVG icon component that renders the iTerm2 terminal application logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`ITerm`** — Default export. A React functional component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 iTerm2 icon using an embedded base64 PNG image.

## Usage Example

```typescript
import ITerm from "./ITerm";

// Basic usage
<ITerm />

// With custom dimensions and className
<ITerm width={64} height={64} className="app-icon" />

// With accessibility attributes
<ITerm aria-label="iTerm2 terminal" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The icon image is hardcoded as a base64 PNG at 32×32 pixels; scaling via `width`/`height` props resizes the SVG container but the internal `<image>` element remains at its original dimensions.
