A React SVG component that renders the Scrivener application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Scrivener`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded base64 PNG of the Scrivener logo.

## Usage Example

```typescript
import Scrivener from "./Scrivener";

// Basic usage
<Scrivener />

// With custom sizing and className
<Scrivener width={64} height={64} className="app-icon" />

// With accessibility attributes
<Scrivener aria-label="Scrivener" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external asset fetches required.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
