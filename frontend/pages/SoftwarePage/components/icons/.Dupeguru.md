A React SVG component that renders the Dupeguru application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Dupeguru`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Dupeguru from "./Dupeguru";

// Basic usage
<Dupeguru />

// With custom dimensions or className
<Dupeguru width={64} height={64} className="app-icon" />

// With accessibility attributes
<Dupeguru aria-label="Dupeguru" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via the spread `{...props}`.
- The icon is self-contained — no external image assets are required at runtime.
- The fixed internal `width={32}` and `height={32}` on the `<image>` element are the native resolution; override display size via the outer `SVGProps`.
