React SVG icon component that renders the SQL Server Management Studio (SSMS) application logo as an inline PNG image encoded in base64 within an SVG wrapper.

## Key Components

- **`SqlServerManagementStudio`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the SSMS icon as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import SqlServerManagementStudio from "./SqlServerManagementStudio";

// Basic usage
<SqlServerManagementStudio />

// With custom dimensions and className
<SqlServerManagementStudio
  width={64}
  height={64}
  className="icon-ssms"
/>

// With accessibility attributes
<SqlServerManagementStudio
  role="img"
  aria-label="SQL Server Management Studio"
/>
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained (no external asset dependency) via a base64-encoded PNG embedded in the `href` attribute of the SVG `<image>` element.
- All standard SVG props are forwarded via spread (`{...props}`), making it composable with styling systems (Tailwind, CSS-in-JS, etc.).
