A React SVG component that renders a Piezo icon as a 32×32 SVG element embedding a base64-encoded PNG image.

## Key Components

- **`Piezo`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 `<svg>` containing an embedded PNG via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import Piezo from './Piezo';

// Basic usage
<Piezo />

// With custom dimensions or styling
<Piezo width={64} height={64} className="icon" />

// With event handlers
<Piezo onClick={() => console.log('clicked')} aria-label="Piezo sensor icon" />
```

## Notes

- The PNG image is inlined as a base64 data URI, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component fully composable.
- Default dimensions are `32×32` but can be overridden via props.
