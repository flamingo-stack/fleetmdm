A React SVG icon component that renders the Godspeed logo as a 32×32 inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Godspeed`** — Default export. A functional React component that wraps a base64 PNG of the Godspeed logo inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Godspeed from "./Godspeed";

// Basic usage
<Godspeed />

// With custom size and className
<Godspeed width={64} height={64} className="icon" />

// With click handler
<Godspeed onClick={() => console.log("clicked")} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props.
- The icon image is self-contained — no external asset requests are made at runtime.
- Follows the same prop interface pattern used across other SVG icon components in this repository.
