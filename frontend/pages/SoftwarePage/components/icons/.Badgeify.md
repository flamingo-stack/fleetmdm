A React SVG component that renders the Badgeify logo as an inline SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Badgeify`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Badgeify logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Badgeify from "./Badgeify";

// Basic usage
<Badgeify />

// With custom dimensions or className
<Badgeify width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Badgeify aria-label="Badgeify logo" role="img" />
```

## Notes

- The component is fully customizable via standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The logo image is self-contained — no external assets or network requests are required.
- Default rendered size is **32×32px**; the embedded PNG is encoded at **512×512px** for high-DPI clarity when scaled up.
