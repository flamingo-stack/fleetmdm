A React SVG component that renders the Yubico Authenticator application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`YubicoAuthenticator`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Yubico Authenticator logo as an inline SVG containing a base64-encoded PNG image.

## Usage Example

```typescript
import YubicoAuthenticator from "./YubicoAuthenticator";

// Basic usage
<YubicoAuthenticator />

// With custom dimensions or className
<YubicoAuthenticator width={64} height={64} className="app-icon" />

// With accessibility attributes
<YubicoAuthenticator aria-label="Yubico Authenticator" role="img" />
```

## Notes

- The component renders at **32×32px** by default but accepts `width`/`height` overrides via props.
- The PNG image is **self-contained** via base64 encoding — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
