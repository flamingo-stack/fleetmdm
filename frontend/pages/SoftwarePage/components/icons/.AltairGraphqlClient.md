React SVG icon component that renders the Altair GraphQL Client logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`AltairGraphqlClient`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Altair GraphQL Client logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import AltairGraphqlClient from "./AltairGraphqlClient";

// Basic usage
<AltairGraphqlClient />

// With custom dimensions or className
<AltairGraphqlClient width={64} height={64} className="icon" />

// With accessible title via aria attributes
<AltairGraphqlClient aria-label="Altair GraphQL Client" role="img" />
```

## Notes

- Props are spread directly onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `className`, `style`, `onClick`, `aria-*`).
- The icon is self-contained — no external image dependencies; the PNG data is inlined as a base64 data URI.
- Default rendered size is **32×32px**; override via `width`/`height` props.
