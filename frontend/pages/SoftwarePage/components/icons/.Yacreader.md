A React SVG icon component that renders the YACReader logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Yacreader`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to customize attributes such as `className`, `style`, `onClick`, etc.

## Usage Example

```typescript
import Yacreader from "./Yacreader";

// Basic usage
<Yacreader />

// With custom size and class
<Yacreader width={64} height={64} className="icon" />

// With click handler
<Yacreader onClick={() => console.log("clicked")} />
```

## Notes

- The logo is inlined as a base64 PNG inside an `<image>` element, so no external asset files are required.
- Default dimensions are `32×32`; override via `width`/`height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
