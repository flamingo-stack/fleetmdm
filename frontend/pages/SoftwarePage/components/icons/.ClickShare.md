A React SVG component that renders the ClickShare logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`ClickShare`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the ClickShare brand logo as an embedded PNG.

## Usage Example

```typescript
import ClickShare from "./ClickShare";

// Basic usage
<ClickShare />

// With custom dimensions or className
<ClickShare width={64} height={64} className="vendor-logo" />

// With accessibility attributes
<ClickShare aria-label="ClickShare" role="img" />
```

## Notes

- The image is a **32×32px** SVG by default; dimensions can be overridden via props.
- The logo is embedded as a **base64 PNG data URI** inside an `<image>` element, meaning no external asset request is made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
