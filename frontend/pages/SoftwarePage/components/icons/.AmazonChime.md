React SVG icon component that renders the Amazon Chime logo as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`AmazonChime`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Amazon Chime logo.

## Usage Example

```typescript
import AmazonChime from './AmazonChime';

// Basic usage
<AmazonChime />

// With custom dimensions and className
<AmazonChime width={64} height={64} className="icon" />

// With accessibility attributes
<AmazonChime aria-label="Amazon Chime" role="img" />
```

## Notes

- The logo image is embedded as a base64-encoded PNG inside an SVG `<image>` element, meaning no external assets are required.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32 pixels**.
