React SVG icon component that renders the Applite application logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Applite` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG containing a base64-encoded PNG of the Applite logo |

## Usage Example

```typescript
import Applite from './Applite';

// Basic usage
<Applite />

// With custom dimensions via SVG props
<Applite width={64} height={64} />

// With additional SVG attributes
<Applite className="app-icon" aria-label="Applite" />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via `width`/`height` props
- The PNG is embedded as a base64 data URI — no external image request is made
- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`)
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Applite.tsx)
