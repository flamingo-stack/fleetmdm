A React SVG component that renders the Fontbase application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Fontbase`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing the Fontbase logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Fontbase from "./Fontbase";

// Basic usage
<Fontbase />

// With custom size and className
<Fontbase width={64} height={64} className="app-icon" />

// With accessibility attributes
<Fontbase aria-label="Fontbase" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The PNG image data is embedded directly as a base64 `data:image/png` URI, eliminating any external asset dependency.
- Accepts all standard SVG element props (e.g., `className`, `style`, `onClick`, `aria-*`) via spread.
- Intended for use as an integration icon, likely within the [OpenFrame](https://www.flamingo.run/openframe) tool/app icon registry.
