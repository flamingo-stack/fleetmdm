A React SVG component that renders the FreeFileSync application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Freefilesync`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the FreeFileSync logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import { Freefilesync } from "./Freefilesync";

// Basic usage
<Freefilesync />

// With custom dimensions and class
<Freefilesync width={64} height={64} className="app-icon" />

// With accessibility attributes
<Freefilesync
  aria-label="FreeFileSync"
  role="img"
  style={{ verticalAlign: "middle" }}
/>
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- The icon image is self-contained — no external image assets or network requests are required.
- Default render size is **32×32px**; override with `width`/`height` props as needed.
