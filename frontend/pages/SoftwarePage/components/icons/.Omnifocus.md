React SVG component that renders the OmniFocus application icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Omnifocus`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering the OmniFocus icon via an embedded base64 PNG within an `<svg>` element.

## Usage Example

```typescript
import Omnifocus from "./Omnifocus";

// Basic usage
<Omnifocus />

// With custom dimensions or className
<Omnifocus width={64} height={64} className="app-icon" />

// With accessibility attributes
<Omnifocus aria-label="OmniFocus" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- The icon image is self-contained — no external asset fetch required.
