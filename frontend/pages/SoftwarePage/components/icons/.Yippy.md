React SVG component that renders the Yippy icon (32×32) using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Yippy` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component with embedded PNG via base64 `href` |

## Usage Example

```typescript
import Yippy from "./Yippy";

// Basic usage
<Yippy />

// With custom size/className
<Yippy width={64} height={64} className="icon" />

// With style overrides
<Yippy style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (spread via `{...props}`)
- Default dimensions: `32×32`
- Image source is a self-contained base64 PNG — no external asset dependency
- Suitable for use in environments where importing image files directly is not available (e.g., design system packages)
