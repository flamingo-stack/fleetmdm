React SVG component that renders the Zeplin logo as an inline SVG image with embedded base64-encoded PNG data.

## Key Components

- **`Zeplin`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Zeplin brand icon as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Zeplin from "./Zeplin";

// Basic usage
<Zeplin />

// With custom size and className
<Zeplin width={64} height={64} className="icon" />

// With aria label for accessibility
<Zeplin aria-label="Zeplin" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 `data:image/png` URI, so no external asset requests are made.
- All `SVGProps<SVGSVGElement>` are forwarded to the root `<svg>` element, enabling full styling and event handler support.
