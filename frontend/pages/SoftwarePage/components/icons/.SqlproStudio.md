A React SVG component that renders the SQLPro Studio application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SqlproStudio`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering the SQLPro Studio logo via an `<image>` element with an embedded base64 PNG.

## Usage Example

```typescript
import SqlproStudio from "./SqlproStudio";

// Basic usage
<SqlproStudio />

// With custom dimensions or className
<SqlproStudio width={64} height={64} className="app-icon" />

// With accessibility attributes
<SqlproStudio aria-label="SQLPro Studio" role="img" />
```

## Notes

- The icon is **self-contained** — no external image files or network requests required; the PNG is inlined as a base64 data URI.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via `SVGProps<SVGSVGElement>`.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
