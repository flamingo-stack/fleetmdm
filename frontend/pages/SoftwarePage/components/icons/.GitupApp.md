A React SVG component that renders the GitUp application icon as an inline SVG using an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`GitupApp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with the GitUp app icon embedded as a base64 PNG `<image>` element.

## Usage Example

```typescript
import GitupApp from "./GitupApp";

// Basic usage
<GitupApp />

// With custom dimensions and className
<GitupApp width={64} height={64} className="app-icon" />

// With style overrides
<GitupApp style={{ borderRadius: "8px" }} />
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread props.
- The icon image is fully self-contained — no external asset requests are made at runtime.
- Default render size is **32×32px**; the embedded PNG source is **512×512px**, so the component scales well at larger sizes.
