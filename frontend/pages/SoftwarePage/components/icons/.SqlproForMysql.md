React SVG component that renders the SQLPro for MySQL application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`SqlproForMysql`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64 PNG `<image>` element

## Usage Example

```typescript
import SqlproForMysql from "./SqlproForMysql";

// Basic usage
<SqlproForMysql />

// With custom dimensions or className
<SqlproForMysql width={64} height={64} className="app-icon" />

// With accessibility attributes
<SqlproForMysql aria-label="SQLPro for MySQL" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element
- The icon image data is fully self-contained — no external assets or network requests are required
- Default render size is **32×32px**; the embedded PNG is encoded at **512×512px**, so the icon scales cleanly to larger sizes
