A React SVG component that renders the Digikam application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Digikam`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Digikam from "./Digikam";

// Basic usage
<Digikam />

// With custom sizing or className
<Digikam width={64} height={64} className="app-icon" />

// With accessibility attributes
<Digikam aria-label="Digikam" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded via spread (`{...props}`), overriding the defaults of `32×32`.
- The icon image is self-contained — no external network requests or asset imports required.
