A React SVG icon component that renders the "Sensei" icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Sensei`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded base64 PNG image.

## Usage Example

```typescript
import Sensei from "./Sensei";

// Basic usage
<Sensei />

// With custom dimensions and class
<Sensei width={64} height={64} className="icon" />

// With aria label for accessibility
<Sensei aria-label="Sensei icon" role="img" />
```

## Notes

- The image data is embedded directly as a base64-encoded PNG, making this component self-contained with no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via the spread `{...props}`.
- Default rendered size is `32×32` pixels; override with `width` and `height` props as needed.
