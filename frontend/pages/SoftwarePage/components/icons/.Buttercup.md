A React SVG component that renders the Buttercup icon as an embedded PNG image (32×32px) encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`Buttercup`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Buttercup from "./Buttercup";

// Basic usage
<Buttercup />

// With custom dimensions or className
<Buttercup width={64} height={64} className="icon" />

// With accessibility attributes
<Buttercup aria-label="Buttercup icon" role="img" />
```

## Notes

- The icon is **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is self-contained — no external assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
