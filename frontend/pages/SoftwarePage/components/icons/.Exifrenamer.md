React SVG icon component that renders the Exifrenamer application logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Exifrenamer`** — Default export; a functional React component wrapping an `<svg>` element that embeds the Exifrenamer app icon via a base64-encoded PNG `<image>` tag.

## Usage Example

```typescript
import Exifrenamer from "./Exifrenamer";

// Basic usage
<Exifrenamer />

// With custom size and className
<Exifrenamer width={64} height={64} className="app-icon" />

// With style overrides
<Exifrenamer style={{ opacity: 0.8 }} aria-label="Exifrenamer" />
```

All standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the `<svg>` element via spread.

## Notes

- Default rendered size is **32×32 px**; override with `width`/`height` props.
- The icon is fully self-contained — no external image requests at runtime.
