React SVG component that renders a VirtualBuddy avatar icon (32×32px) using an embedded base64-encoded PNG image.

## Key Components

- **`VirtualBuddy`** — A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around a base64-encoded PNG avatar image.

## Usage Example

```typescript
import VirtualBuddy from "./VirtualBuddy";

// Basic usage
<VirtualBuddy />

// With custom dimensions or className
<VirtualBuddy width={64} height={64} className="avatar-icon" />

// With style overrides
<VirtualBuddy style={{ borderRadius: "50%" }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via `{...props}`.
- The image is self-contained — no external asset dependencies.
- Default rendered size is **32×32px**; override via `width`/`height` props.
