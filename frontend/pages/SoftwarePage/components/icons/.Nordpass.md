A React SVG component that renders the NordPass password manager logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Nordpass`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Nordpass from "./Nordpass";

// Basic usage
<Nordpass />

// With custom dimensions and styling
<Nordpass width={64} height={64} className="icon" />

// With click handler
<Nordpass onClick={() => console.log("NordPass selected")} />
```

## Notes

- The icon is fixed at 32×32 by default but can be overridden via `width`/`height` props.
- The logo is embedded as a base64 PNG `<image>` within an SVG wrapper — no external asset dependencies.
- Part of the Flamingo/OpenFrame integration icon set, likely used to represent NordPass in the MSP tool stack or password manager integrations.
