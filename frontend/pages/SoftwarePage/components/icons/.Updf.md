A React SVG component that renders the UPDF application icon as a 32×32 inline SVG element, embedding the icon image as a base64-encoded PNG data URI.

## Key Components

- **`Updf`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the UPDF brand icon via an embedded base64 PNG.

## Usage Example

```typescript
import Updf from './Updf';

// Basic usage
<Updf />

// With custom dimensions or className
<Updf width={64} height={64} className="app-icon" />

// With ARIA label for accessibility
<Updf aria-label="UPDF" role="img" />
```

## Notes

- The icon image is self-contained (no external network requests); the PNG is inlined as a base64 data URI within the SVG `<image>` element.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread, making the component flexible for layout and accessibility needs.
- Default render size is **32×32 pixels**; override with `width`/`height` props as needed.
