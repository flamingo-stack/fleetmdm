A React SVG icon component that renders the Node.js logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Nodejs`** — Default export. A functional React component that accepts all standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 Node.js logo icon.

## Usage Example

```typescript
import Nodejs from "./Nodejs";

// Basic usage
<Nodejs />

// With custom size or className
<Nodejs width={64} height={64} className="icon" />

// With style overrides
<Nodejs style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo is embedded as a **base64 PNG** inside an `<image>` tag, meaning no external asset requests are required.
- All standard `SVGSVGElement` props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
