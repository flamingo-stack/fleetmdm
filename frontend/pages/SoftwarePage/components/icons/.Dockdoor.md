A React SVG component that renders the Dockdoor application icon as a 32×32 inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Dockdoor`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, forwarding all props to the root `<svg>` element for full customization (className, style, onClick, etc.)

## Usage Example

```typescript
import Dockdoor from "./Dockdoor";

// Basic usage
<Dockdoor />

// Custom size and className
<Dockdoor width={64} height={64} className="app-icon" />

// With click handler
<Dockdoor onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- Default dimensions are **32×32** pixels; override via `width`/`height` props.
- The icon image is self-contained (base64-encoded PNG) — no external asset requests.
- Useful as a visual identifier for the [Dockdoor](https://dockdoor.net) macOS app integration within the Fleet MDM UI.
