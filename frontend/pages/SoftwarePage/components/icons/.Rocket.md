A React SVG component that renders a 32×32 Rocket emoji icon using an embedded base64-encoded PNG image.

## Key Components

- **`Rocket`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Rocket from "./Rocket";

// Basic usage
<Rocket />

// With custom size and className
<Rocket width={64} height={64} className="my-icon" />

// With inline style
<Rocket style={{ opacity: 0.8 }} />
```

## Notes

- The icon is a **32×32** SVG wrapper around a base64-encoded PNG, rendered via an `<image>` element.
- All standard SVG props (`className`, `style`, `width`, `height`, `aria-*`, etc.) are forwarded to the root `<svg>` element, enabling full customization.
- The embedded PNG is self-contained — no external image assets are required.
