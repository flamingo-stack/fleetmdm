React SVG component that renders the StarUML application icon as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Staruml`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing callers to override width, height, className, style, and other SVG attributes.

## Usage Example

```typescript
import Staruml from "./Staruml";

// Basic usage
<Staruml />

// With custom size and className
<Staruml width={64} height={64} className="icon" />

// With inline style
<Staruml style={{ opacity: 0.8 }} />
```

## Notes

- The icon is rendered as an `<image>` element inside an SVG, using a base64-encoded PNG data URI — no external file dependency required.
- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- Part of the icon asset library in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository.
