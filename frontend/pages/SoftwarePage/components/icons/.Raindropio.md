A React component that renders the Raindrop.io brand icon as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Raindropio`** — Default export; a functional React component wrapping an `<svg>` element that renders a 32×32 Raindrop.io logo via an embedded base64 PNG `<image>` tag.

Accepts all standard `SVGProps<SVGSVGElement>` props, allowing callers to override or extend attributes such as `className`, `style`, `width`, `height`, and event handlers.

## Usage Example

```typescript
import Raindropio from "./Raindropio";

// Basic usage
<Raindropio />

// With custom size and class
<Raindropio width={64} height={64} className="icon" />

// With inline style override
<Raindropio style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained — no external image assets or network requests are required at runtime.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The component is located at [`Raindropio.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Raindropio.tsx) in the repository.
