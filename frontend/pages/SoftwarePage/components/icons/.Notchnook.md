A React SVG component that renders the Notchnook brand/app icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Notchnook`** — Default exported functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Notchnook from "./Notchnook";

// Basic usage
<Notchnook />

// With custom size override
<Notchnook width={64} height={64} />

// With className or style
<Notchnook className="app-icon" style={{ borderRadius: 8 }} />
```

## Notes

- The icon image is fully self-contained — no external network requests are made at runtime.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, allowing consumers to override `width`, `height`, `className`, `style`, `aria-label`, and other standard SVG attributes.
