A React SVG icon component that renders the PopSQL logo as a 32×32 inline PNG embedded via a base64-encoded `data:image/png` URI.

## Key Components

- **`Popsql`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Popsql from "./icons/Popsql";

// Basic usage
<Popsql />

// With custom size and class
<Popsql width={64} height={64} className="icon" />

// With click handler
<Popsql onClick={() => console.log("PopSQL clicked")} />
```

## Notes

- The logo image is embedded as a base64 PNG, so no external asset requests are made.
- Default dimensions are `32×32` pixels; override via `width`/`height` props.
