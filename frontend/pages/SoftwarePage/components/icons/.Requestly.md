A React SVG component that renders the Requestly logo as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Requestly`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full customization of the underlying `<svg>` element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Requestly from "./Requestly";

// Basic usage
<Requestly />

// With custom size and class
<Requestly width={64} height={64} className="integration-icon" />

// With style override
<Requestly style={{ opacity: 0.8 }} />
```

## Notes

- The logo is embedded as a base64 PNG inside an `<image>` tag, so no external image assets are required.
- Default dimensions are **32×32px** but can be overridden via `width`/`height` props.
- Extends `SVGProps<SVGSVGElement>`, making it compatible with any standard SVG attribute or event handler.
