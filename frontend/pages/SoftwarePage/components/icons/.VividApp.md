React SVG component that renders the Vivid app icon as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `VividApp` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapping a base64 PNG image |

## Usage Example

```typescript
import VividApp from "./VividApp";

// Basic usage
<VividApp />

// With custom dimensions and className
<VividApp width={64} height={64} className="app-icon" />

// With aria label for accessibility
<VividApp aria-label="Vivid App" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react-spring.dev/docs) props, allowing size, style, and event overrides at the call site.
- The icon is fully self-contained — no external image requests are made.
- Default render size is **32×32px**; the embedded PNG is 512×512px, so the icon scales cleanly up to that resolution.
