A React SVG component that renders the Tableau Prep application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`TableauPrep`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are forwarded to the root `<svg>` element.

## Usage Example

```typescript
import TableauPrep from "./TableauPrep";

// Basic usage
<TableauPrep />

// With custom dimensions or className
<TableauPrep width={64} height={64} className="icon" />

// With accessibility attributes
<TableauPrep aria-label="Tableau Prep" role="img" />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 string — no external asset requests are made.
- All `SVGProps` (e.g., `style`, `className`, `onClick`) are passed through to the `<svg>` element.
