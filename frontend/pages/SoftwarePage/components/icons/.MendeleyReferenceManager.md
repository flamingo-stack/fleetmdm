SVG icon component that renders the Mendeley Reference Manager logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`MendeleyReferenceManager`** — Default export. A React functional component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing the Mendeley logo as an embedded PNG image.

## Usage Example

```typescript
import MendeleyReferenceManager from "./MendeleyReferenceManager";

// Basic usage
<MendeleyReferenceManager />

// With custom size and className
<MendeleyReferenceManager width={64} height={64} className="icon" />

// With accessibility attributes
<MendeleyReferenceManager aria-label="Mendeley Reference Manager" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The PNG logo is inlined as a base64 `data:image/png` URI — no external asset fetch required.
- All standard `SVGProps<SVGSVGElement>` attributes (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
