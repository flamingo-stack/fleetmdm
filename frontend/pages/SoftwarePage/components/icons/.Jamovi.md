A React component that renders the Jamovi application icon as an SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Jamovi`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Jamovi logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Jamovi from './Jamovi';

// Basic usage
<Jamovi />

// With custom dimensions or className
<Jamovi width={64} height={64} className="app-icon" />

// With accessibility attributes
<Jamovi aria-label="Jamovi" role="img" />
```

## Notes

- The icon image is self-contained — no external image requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
