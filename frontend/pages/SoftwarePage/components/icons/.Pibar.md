A React SVG component that renders a 32×32 Pibar icon using an embedded base64-encoded PNG image.

## Key Components

- **`Pibar`** — Default export; a functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG wrapper containing a base64-encoded PNG image.

## Usage Example

```typescript
import { Pibar } from './Pibar';

// Basic usage
<Pibar />

// With custom dimensions or className
<Pibar width={64} height={64} className="my-icon" />

// With accessibility attributes
<Pibar aria-label="Pibar icon" role="img" />
```

## Notes

- The icon image is inlined as a base64 PNG, so no external asset files are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread props.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
