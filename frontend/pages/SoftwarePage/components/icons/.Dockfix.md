A React SVG component that renders the Dockfix application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Dockfix`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Dockfix logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Dockfix from "./Dockfix";

// Basic usage
<Dockfix />

// With custom dimensions or className
<Dockfix width={64} height={64} className="app-icon" />

// With accessibility attributes
<Dockfix aria-label="Dockfix" role="img" />
```

## Notes

- The icon is hardcoded at **32×32 pixels** by default but can be overridden via props.
- The image is self-contained (no external image requests) thanks to the embedded base64 PNG.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
