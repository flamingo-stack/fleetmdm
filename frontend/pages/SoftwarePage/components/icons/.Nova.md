React SVG icon component that renders the Nova logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Nova`** — Default export. A functional React component wrapping an `<svg>` element with an embedded `<image>` tag that renders a base64 PNG. Accepts all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import Nova from "./Nova";

// Basic usage
<Nova />

// With custom size and className
<Nova width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Nova aria-label="Nova logo" role="img" />
```

## Notes

- The component is 32×32px by default but can be overridden via `width`/`height` props.
- The PNG data is fully inlined — no external image file is required.
- All `SVGProps` (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
