A React SVG component that renders the Steermouse application icon as an inline base64-encoded PNG image.

## Key Components

- **`Steermouse`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG element containing the Steermouse icon as an embedded base64 PNG.

## Usage Example

```typescript
import Steermouse from "./Steermouse";

// Basic usage
<Steermouse />

// With custom dimensions or className
<Steermouse width={64} height={64} className="app-icon" />

// With style overrides
<Steermouse style={{ opacity: 0.8 }} />
```

## Notes

- The icon is **32×32 pixels** by default but can be overridden via props.
- The image data is embedded as a **base64 PNG** within the SVG `<image>` element, meaning no external asset fetch is required.
- All standard `SVGProps<SVGSVGElement>` are forwarded to the root `<svg>` element, enabling full customization (e.g., `className`, `style`, `aria-*`, event handlers).
- Typically used in MDM or device management UI contexts to represent the [Steermouse](https://www.steermouse.com/) macOS mouse driver application within Fleet MDM's software catalog.
