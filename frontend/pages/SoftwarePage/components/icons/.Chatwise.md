A React SVG component that renders the Chatwise logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Chatwise`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Chatwise logo as an embedded PNG.

## Usage Example

```typescript
import Chatwise from "./Chatwise";

// Basic usage
<Chatwise />

// With custom dimensions or className
<Chatwise width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Chatwise aria-label="Chatwise" role="img" />
```

## Notes

- The logo is embedded as a base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` element, making it self-contained with no external image dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
