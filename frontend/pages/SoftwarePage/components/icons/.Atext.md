A React SVG icon component that renders the "Atext" icon as an inline SVG wrapping a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Atext`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `width`, `height`).

The SVG renders a 32×32 container with an embedded base64 PNG image asset. All standard SVG props are forwarded via spread (`{...props}`), allowing full customization at the call site.

## Usage Example

```typescript
import Atext from "./Atext";

// Basic usage
<Atext />

// With custom size and style
<Atext width={64} height={64} className="icon" />

// With click handler
<Atext onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The component is **prop-passthrough friendly** — any valid `SVGProps` attribute overrides or extends the defaults.
- The embedded image is a self-contained base64 PNG, so no external asset file is required.
- Default rendered size is **32×32 px**; override via `width`/`height` props.
