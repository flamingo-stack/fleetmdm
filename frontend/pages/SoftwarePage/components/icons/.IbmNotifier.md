A React SVG component that renders the IBM Notifier application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`IbmNotifier`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the IBM Notifier icon as an embedded PNG.

## Usage Example

```typescript
import IbmNotifier from "./IbmNotifier";

// Basic usage
<IbmNotifier />

// With custom dimensions and className
<IbmNotifier width={64} height={64} className="app-icon" />

// With style overrides
<IbmNotifier style={{ opacity: 0.8 }} />
```

## Notes

- Default render size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element via spread.
