SVG icon component for the Egnyte brand logo, rendered as a base64-encoded PNG embedded within an SVG wrapper at 32×32 pixels.

## Key Components

- **`Egnyte`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Egnyte logo.

## Usage Example

```typescript
import Egnyte from "./Egnyte";

// Basic usage
<Egnyte />

// With custom dimensions or className
<Egnyte width={64} height={64} className="icon" />

// With inline styles
<Egnyte style={{ opacity: 0.8 }} />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The logo image is inlined as a base64 PNG, so no external assets are required.
- Default render size is **32×32px**.
