React SVG icon component that renders the Stretchly application logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Stretchly`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Stretchly logo as an embedded PNG via a `data:image/png;base64` URI.

## Usage Example

```typescript
import Stretchly from "./Stretchly";

// Basic usage
<Stretchly />

// With custom size and class
<Stretchly width={64} height={64} className="app-icon" />

// With accessibility attributes
<Stretchly aria-label="Stretchly" role="img" />
```

## Notes

- The PNG image is 512×512 pixels, downscaled to 32×32 by the SVG viewport.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
