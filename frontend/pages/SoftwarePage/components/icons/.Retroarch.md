A React SVG component that renders the RetroArch logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Retroarch`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the RetroArch icon via an `<image>` element with a base64-encoded PNG `href`.

## Usage Example

```typescript
import Retroarch from "./Retroarch";

// Basic usage
<Retroarch />

// With custom size and className
<Retroarch width={64} height={64} className="app-icon" />

// With accessibility attributes
<Retroarch aria-label="RetroArch" role="img" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via `width`/`height` props.
- The image data is a **base64-encoded PNG** embedded directly in the SVG — no external image request is made.
- Accepts and spreads all standard [`SVGProps`](https://react-typescript-cheatsheet.netlify.app/docs/basic/getting-started/basic_type_example/#svg) onto the root `<svg>` element, enabling full customization (style, className, onClick, aria-*, etc.).
