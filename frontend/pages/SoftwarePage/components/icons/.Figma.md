A React SVG icon component that renders the Figma logo with its characteristic five-colored sections.

## Key Components

- **`Figma`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Figma logo as an inline SVG with a unique `clipPath` ID to avoid collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import Figma from "./Figma";

// Basic usage
<Figma width={32} height={32} />

// With custom dimensions and className
<Figma width={24} height={24} className="icon" aria-label="Figma" />
```

## Notes

- Uses `lodash.uniqueId` to generate a unique `clipPath` ID per instance, preventing SVG `defs` conflicts when the icon is rendered multiple times.
- The logo segments map to Figma's official brand colors: green (`#0ACF83`), purple (`#A259FF`), red (`#F24E1E`), orange-red (`#FF7262`), and blue (`#1ABCFE`).
- All `SVGProps` are spread onto the root `<svg>` element, making size, style, className, and ARIA attributes fully customizable by the consumer.
- Base canvas is a 32×32 dark background (`#333`).
