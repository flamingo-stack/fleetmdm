SVG icon component that renders the Angry IP Scanner application logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`AngryIpScanner`** — Default export; a React functional component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 SVG containing the Angry IP Scanner icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import AngryIpScanner from "./AngryIpScanner";

// Basic usage
<AngryIpScanner />

// With custom dimensions or className
<AngryIpScanner width={64} height={64} className="tool-icon" />

// With inline styles
<AngryIpScanner style={{ opacity: 0.8 }} />
```

## Notes

- Default render size is **32×32 pixels**; override via `width`/`height` props.
- The icon data is self-contained (base64-encoded PNG), so no external image assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via prop spreading.
- Likely part of a broader icon library for MSP tooling integrations within the [Flamingo/OpenFrame platform](https://github.com/flamingo-stack/fleetmdm).
