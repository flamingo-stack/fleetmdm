React SVG icon component that renders the Affinity application logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Affinity`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 SVG containing the Affinity logo as an embedded PNG image.

## Usage Example

```typescript
import Affinity from "./Affinity";

// Basic usage
<Affinity />

// With custom dimensions or className
<Affinity width={64} height={64} className="icon" />

// With inline styles
<Affinity style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo image is self-contained as a base64-encoded PNG — no external asset dependencies.
- Accepts all standard `SVGProps<SVGSVGElement>` attributes (e.g., `className`, `style`, `onClick`).
