A React SVG icon component that renders the Pritunl logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Pritunl`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Pritunl logo.

## Usage Example

```typescript
import Pritunl from "@/components/icons/Pritunl";

// Basic usage
<Pritunl />

// With custom dimensions or className
<Pritunl width={64} height={64} className="icon" />

// With inline styles
<Pritunl style={{ opacity: 0.8 }} />
```

## Notes

- Fixed default size of **32×32 pixels**; override via `width`/`height` props.
- The logo image is embedded as a **base64 PNG** — no external asset dependency.
- Accepts all native SVG props (e.g., `className`, `style`, `aria-*`) via prop spreading.
