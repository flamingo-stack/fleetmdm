React SVG icon component that renders the JetBrains Rider IDE logo as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Rider` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapper containing the Rider logo as an embedded PNG |

## Usage Example

```typescript
import Rider from "./Rider";

// Basic usage
<Rider />

// With custom dimensions
<Rider width={64} height={64} />

// With className or style props
<Rider className="icon" style={{ marginRight: 8 }} />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) props (e.g., `className`, `style`, `onClick`, `width`, `height`).
- The image is self-contained — no external asset files or network requests are required.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
