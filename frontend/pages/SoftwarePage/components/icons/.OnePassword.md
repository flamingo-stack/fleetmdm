A React SVG icon component that renders the 1Password logo as a scalable vector graphic.

## Key Components

- **`OnePassword`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 1Password brand icon with layered paths for the characteristic circular badge and key symbol.

## Usage Example

```typescript
import OnePassword from "./OnePassword";

// Basic usage
<OnePassword />

// With custom dimensions
<OnePassword width={24} height={24} />

// With className for styling
<OnePassword className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- Renders a fixed-aspect 32×32 SVG by default; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
- No external dependencies beyond React — purely inline SVG paths.
