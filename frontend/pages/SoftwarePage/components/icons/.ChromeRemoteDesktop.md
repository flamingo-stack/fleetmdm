A React SVG component that renders the Chrome Remote Desktop application icon as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`ChromeRemoteDesktop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import ChromeRemoteDesktop from "./ChromeRemoteDesktop";

// Basic usage
<ChromeRemoteDesktop />

// With custom size and className
<ChromeRemoteDesktop width={64} height={64} className="icon" />

// With accessibility attributes
<ChromeRemoteDesktop aria-label="Chrome Remote Desktop" role="img" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon image is fully self-contained — no external image assets or network requests required.
