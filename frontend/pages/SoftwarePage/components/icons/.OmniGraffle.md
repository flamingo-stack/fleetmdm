React SVG icon component that renders the OmniGraffle application logo as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`OmniGraffle`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the OmniGraffle app icon.

## Usage Example

```typescript
import OmniGraffle from "./OmniGraffle";

// Basic usage
<OmniGraffle />

// With custom dimensions and className
<OmniGraffle width={64} height={64} className="app-icon" />

// With accessibility attributes
<OmniGraffle
  width={32}
  height={32}
  role="img"
  aria-label="OmniGraffle"
/>
```

## Notes

- The component renders at **32×32px** by default but accepts any valid SVG props for customization.
- The icon image is embedded as a **base64 PNG** inside an `<image>` element, so no external asset files are required.
- Part of an icon library pattern; see other icon components in the same directory at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/).
