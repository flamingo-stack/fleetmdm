A React SVG component that renders the Tidal logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Tidal`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Tidal from "./Tidal";

// Basic usage
<Tidal />

// With custom dimensions and className
<Tidal width={64} height={64} className="logo-icon" />

// With style overrides
<Tidal style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at a base size of `32×32` but can be overridden via props.
- The image data is self-contained (base64 PNG), so no external assets are required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are supported via prop spreading.
