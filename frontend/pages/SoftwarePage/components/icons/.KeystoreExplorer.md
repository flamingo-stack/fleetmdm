A React SVG component that renders the Keystore Explorer application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`KeystoreExplorer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `aria-*` attributes).
- **Embedded PNG** — The icon graphic is inlined as a base64-encoded PNG within an SVG `<image>` element, eliminating any external asset dependency.

## Usage Example

```typescript
import KeystoreExplorer from "./KeystoreExplorer";

// Basic usage
<KeystoreExplorer />

// With custom size and class
<KeystoreExplorer width={64} height={64} className="app-icon" />

// With accessibility label
<KeystoreExplorer aria-label="Keystore Explorer" role="img" />
```

## Notes

- The component defaults to `32×32` pixels but accepts any valid `SVGProps` overrides.
- The base64 PNG is encoded at 512×512 source resolution and scaled down to 32×32 via the SVG viewport — no external image files required.
- Sourced from [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/KeystoreExplorer.tsx).
