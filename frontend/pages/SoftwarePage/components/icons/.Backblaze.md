React SVG wrapper component that renders the Backblaze logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Backblaze`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override width, height, className, style, and other SVG attributes.

## Usage Example

```typescript
import Backblaze from "./Backblaze";

// Basic usage
<Backblaze />

// With custom size and className
<Backblaze width={64} height={64} className="provider-icon" />

// With inline style
<Backblaze style={{ opacity: 0.8 }} />
```

## Notes

- The component embeds the logo as a base64 PNG via an `<image>` element, so no external asset request is made at runtime.
- Default dimensions are **32×32px**; override via `width`/`height` props.
- Fully typed via `SVGProps<SVGSVGElement>` from React — no custom prop interface needed.
