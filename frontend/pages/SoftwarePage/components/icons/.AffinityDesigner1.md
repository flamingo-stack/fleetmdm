React SVG component that renders the Affinity Designer 1 application icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AffinityDesigner1` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG icon component for Affinity Designer 1 |

## Usage Example

```typescript
import AffinityDesigner1 from './AffinityDesigner1';

// Basic usage
<AffinityDesigner1 />

// With custom dimensions and className
<AffinityDesigner1 width={64} height={64} className="app-icon" />

// With inline styles
<AffinityDesigner1 style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props
- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/AffinityDesigner1.tsx) props for full customization
- The icon is self-contained — no external image assets required; the PNG is embedded as a base64 `data:image/png` URI inside an `<image>` element
- Part of a broader application icon component library in the repository
