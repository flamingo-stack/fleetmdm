React SVG component that renders the 4K YouTube to MP3 application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`FourKYoutubeToMp3`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import FourKYoutubeToMp3 from "./FourKYoutubeToMp3";

// Basic usage
<FourKYoutubeToMp3 />

// With custom dimensions or className
<FourKYoutubeToMp3 width={64} height={64} className="app-icon" />
```

## Notes

- The component spreads all `SVGProps` onto the root `<svg>` element, allowing full prop customization (size, style, aria attributes, etc.).
- The icon image is self-contained — no external asset dependency at runtime.
- Default rendered size is **32×32 pixels**; the embedded PNG source is 512×512 (EXIF metadata).
