A React SVG component that renders the Taskade brand icon as a 32×32 SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Taskade`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering the Taskade logo as a 32×32 SVG with an embedded PNG via a `data:image/png;base64` `href`.

## Usage Example

```typescript
import Taskade from "./Taskade";

// Basic usage
<Taskade />

// With custom dimensions or className
<Taskade width={64} height={64} className="my-icon" />

// With accessibility attributes
<Taskade aria-label="Taskade" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `className`, `style`, `aria-*`).
- The icon image is fully self-contained — no external asset fetch required.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
