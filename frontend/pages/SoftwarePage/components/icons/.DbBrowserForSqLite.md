A React SVG icon component that renders the DB Browser for SQLite application logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`DbBrowserForSqLite`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) and rendering the DB Browser for SQLite icon.

## Usage Example

```typescript
import DbBrowserForSqLite from "./DbBrowserForSqLite";

// Basic usage
<DbBrowserForSqLite />

// With custom dimensions or className
<DbBrowserForSqLite width={64} height={64} className="icon" />

// With accessibility attributes
<DbBrowserForSqLite aria-label="DB Browser for SQLite" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The PNG data is inlined as a base64 string — no external image assets required.
- All standard `SVGProps` are forwarded to the root `<svg>` element, enabling full style and attribute customization.
