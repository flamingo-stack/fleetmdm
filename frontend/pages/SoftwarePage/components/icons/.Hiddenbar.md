A React SVG component that renders the Hiddenbar macOS menu bar utility app icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Hiddenbar`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing an embedded PNG icon via a base64 `data:` URI.

## Usage Example

```typescript
import Hiddenbar from "./Hiddenbar";

// Basic usage
<Hiddenbar />

// With custom dimensions or className
<Hiddenbar width={64} height={64} className="app-icon" />

// With accessibility attributes
<Hiddenbar aria-label="Hiddenbar" role="img" />
```

> **Note:** All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded directly to the underlying `<svg>` element via props spreading.
