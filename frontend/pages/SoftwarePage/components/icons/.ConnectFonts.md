SVG icon component that renders a Connect Fonts logo/icon as a React component, embedding a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`ConnectFonts`** — Default export. A functional React component that renders a 32×32 SVG containing an embedded base64 PNG image, accepting all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import ConnectFonts from "./ConnectFonts";

// Basic usage
<ConnectFonts />

// With custom dimensions or className
<ConnectFonts width={64} height={64} className="my-icon" />

// With style overrides
<ConnectFonts style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard SVG props (e.g., `className`, `style`, `width`, `height`, `onClick`) via `SVGProps<SVGSVGElement>`.
- The icon defaults to **32×32 pixels** but can be overridden via props.
- The image data is self-contained as a base64 PNG — no external asset dependencies.
