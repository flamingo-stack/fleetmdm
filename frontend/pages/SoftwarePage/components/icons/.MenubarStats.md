SVG icon component that renders a 32×32 menubar statistics icon using an embedded base64-encoded PNG image.

## Key Components

- **`MenubarStats`** — Default export. A React functional component that wraps a native `<svg>` element containing a base64 PNG `<image>` tag. Accepts all standard `SVGProps<SVGSVGElement>` props for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import MenubarStats from "./MenubarStats";

// Basic usage
<MenubarStats />

// With custom dimensions or class
<MenubarStats width={24} height={24} className="icon-stats" />

// With click handler
<MenubarStats onClick={() => console.log("stats clicked")} />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via props.
- The PNG image data is fully self-contained (base64-encoded inline), so no external asset fetch is required.
- Designed for use in macOS-style menubar or toolbar UI contexts within the Fleet MDM dashboard.
