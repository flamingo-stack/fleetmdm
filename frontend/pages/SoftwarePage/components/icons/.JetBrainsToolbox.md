React SVG component that renders the JetBrains Toolbox application icon as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`JetBrainsToolbox`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props. Renders a 32×32 SVG element containing an `<image>` tag with the icon data embedded as a base64 PNG `data:` URI.

## Usage Example

```typescript
import JetBrainsToolbox from "./JetBrainsToolbox";

// Basic usage
<JetBrainsToolbox />

// With custom dimensions or className
<JetBrainsToolbox width={64} height={64} className="icon" />

// With accessibility attributes
<JetBrainsToolbox aria-label="JetBrains Toolbox" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is fully self-contained — no external image requests are made.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded via spread to the root `<svg>` element.
