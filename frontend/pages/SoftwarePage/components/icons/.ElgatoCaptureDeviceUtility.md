React SVG component that renders the Elgato Capture Device Utility application icon as an inline PNG embedded within an SVG wrapper.

## Key Components

- **`ElgatoCaptureDeviceUtility`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Elgato Capture Device Utility icon.

## Usage Example

```typescript
import ElgatoCaptureDeviceUtility from "./ElgatoCaptureDeviceUtility";

// Basic usage
<ElgatoCaptureDeviceUtility />

// With custom dimensions or className
<ElgatoCaptureDeviceUtility width={64} height={64} className="app-icon" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG (`data:image/png;base64,...`) inside an SVG `<image>` element, ensuring no external asset requests.
- All standard SVG props (e.g., `width`, `height`, `style`, `className`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32 pixels**; override via props as needed.
- Part of the FleetMDM application icon set. Source:
  [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/icons/ElgatoCaptureDeviceUtility.tsx)
