React SVG icon component that renders the IntelliJ IDEA CE (Community Edition) logo as an inline PNG embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`IntelliJIdeaCe`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the IntelliJ IDEA CE icon as an embedded PNG image.

## Usage Example

```typescript
import IntelliJIdeaCe from "./IntelliJIdeaCe";

// Basic usage
<IntelliJIdeaCe />

// With custom dimensions and className
<IntelliJIdeaCe width={64} height={64} className="icon" />

// With accessibility attributes
<IntelliJIdeaCe aria-label="IntelliJ IDEA CE" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained — no external asset fetching required.
- Spreads all `SVGProps` onto the root `<svg>` element, making it fully composable with standard SVG attributes (e.g., `className`, `style`, `onClick`).
