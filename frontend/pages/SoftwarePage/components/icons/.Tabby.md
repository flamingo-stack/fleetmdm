React SVG component that renders the Tabby logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Tabby`** — Default export; a React functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Tabby logo.

## Usage Example

```typescript
import Tabby from "./Tabby";

// Basic usage
<Tabby />

// With custom dimensions or className
<Tabby width={64} height={64} className="logo-icon" />

// With style overrides
<Tabby style={{ display: "block", margin: "0 auto" }} />
```

## Notes

- The image data is fully self-contained — no external image files or network requests are required.
- Supports all standard SVG props (`className`, `style`, `aria-*`, `onClick`, etc.) via prop spreading.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
