A React SVG component that renders the Cork icon as an inline SVG embedding a base64-encoded PNG image (32×32px).

## Key Components

- **`Cork`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Cork from './Cork';

// Basic usage
<Cork />

// With custom dimensions or className
<Cork width={64} height={64} className="icon" />

// With accessibility attributes
<Cork aria-label="Cork icon" role="img" />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default; dimensions can be overridden via props.
- The image data is fully self-contained — no external image assets are required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
