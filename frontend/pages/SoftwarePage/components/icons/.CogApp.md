A React SVG component that renders a 32×32 pixel Cog application icon using an embedded base64-encoded PNG image.

## Key Components

- **`CogApp`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering an SVG wrapper around an inline base64 PNG image asset.

## Usage Example

```typescript
import CogApp from "./CogApp";

// Basic usage
<CogApp />

// With custom dimensions or className
<CogApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<CogApp aria-label="Cog Application" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via props.
- The image data is entirely self-contained as a base64 PNG, requiring no external asset loading.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
