A React SVG icon component that renders the Wealthfolio application logo as a 32×32 pixel image, embedding the logo as a base64-encoded PNG within an SVG wrapper.

## Key Components

- **`Wealthfolio`** — Default export. A functional React component that renders a 32×32 SVG containing an embedded base64 PNG of the Wealthfolio logo. Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Wealthfolio from "./Wealthfolio";

// Basic usage
<Wealthfolio />

// With custom size and class
<Wealthfolio width={64} height={64} className="app-icon" />

// With click handler
<Wealthfolio onClick={() => console.log("clicked")} />
```

## Notes

- The logo image is self-contained — no external image assets are required.
- Default dimensions are 32×32px but can be overridden via `width`/`height` props.
