React SVG icon component that renders the Zettlr application logo as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Zettlr`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG of the Zettlr logo via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Zettlr from "./Zettlr";

// Basic usage
<Zettlr />

// With custom sizing and class
<Zettlr width={64} height={64} className="app-icon" />

// With accessibility attributes
<Zettlr aria-label="Zettlr" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, making it fully customizable (size, class, style, aria attributes, etc.).
- The logo image is self-contained via an inline base64 PNG — no external asset or network request required.
- Default dimensions are `32×32`; override with `width` and `height` props as needed.
