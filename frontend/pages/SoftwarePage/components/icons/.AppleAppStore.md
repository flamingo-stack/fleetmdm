SVG icon component for the Apple App Store logo, rendered as a 32×32 gradient badge with a white App Store symbol.

## Key Components

- **`AppleAppStore`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute passthrough (e.g., `width`, `height`, `className`, `style`).
- **`uniqueId`** — Generates unique IDs for the `linearGradient` and `clipPath` `<defs>` elements, preventing ID collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import AppleAppStore from "components/icons/AppleAppStore";

// Basic usage
<AppleAppStore />

// Custom size and class
<AppleAppStore width={24} height={24} className="app-store-icon" />

// Inline style override
<AppleAppStore style={{ display: "block", margin: "0 auto" }} />
```

## Notes

- Default rendered size is **32×32** (defined by the internal `clipPath` bounds).
- The badge background uses a **linear gradient** from `#18bffb` (top) to `#2072f3` (bottom) with a rounded-rectangle mask.
- No explicit `width`/`height` props are set internally — consumers should provide dimensions via props or CSS to avoid the SVG defaulting to browser intrinsic sizing.
