React SVG component that renders the Garmin Express application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`GarminExpress`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element that embeds a base64-encoded PNG icon via an `<image>` tag.

## Usage Example

```typescript
import GarminExpress from "./GarminExpress";

// Basic usage
<GarminExpress />

// With custom dimensions or className
<GarminExpress width={64} height={64} className="app-icon" />

// With style overrides
<GarminExpress style={{ opacity: 0.8 }} />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- The embedded PNG was originally 512×512 pixels (per EXIF metadata) and is downscaled to 32×32 for display.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- This component follows the same pattern used throughout the icon library in this repository. See other icon components at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/) for reference.
