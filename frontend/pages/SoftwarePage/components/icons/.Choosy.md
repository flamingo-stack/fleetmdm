React SVG wrapper component that renders the Choosy application icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Choosy`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Choosy app icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Choosy from "./Choosy";

// Basic usage
<Choosy />

// With custom dimensions or className
<Choosy width={64} height={64} className="app-icon" />

// With style overrides
<Choosy style={{ opacity: 0.8 }} />
```

## Notes

- The icon is a 32×32 SVG wrapping a 512×512 source PNG (downscaled via SVG dimensions).
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
- No external image dependencies — the PNG is fully embedded as a `data:image/png;base64` URI, making it portable and network-independent.
