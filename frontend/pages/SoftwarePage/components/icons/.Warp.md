React SVG icon component that renders the Warp terminal application logo as an inline PNG image embedded in base64 format within an SVG element.

## Key Components

- **`Warp`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Warp logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Warp from './Warp';

// Basic usage
<Warp />

// With custom dimensions and className
<Warp width={64} height={64} className="icon" />

// With accessibility attributes
<Warp aria-label="Warp terminal" role="img" />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via props.
- The logo image is embedded as a base64-encoded PNG, meaning no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
