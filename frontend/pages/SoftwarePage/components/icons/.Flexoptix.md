A React SVG component that renders the Flexoptix brand icon as a 32×32 inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`Flexoptix`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Flexoptix from "./Flexoptix";

// Basic usage
<Flexoptix />

// With custom size and className
<Flexoptix width={64} height={64} className="icon" />

// With style overrides
<Flexoptix style={{ opacity: 0.8 }} aria-label="Flexoptix" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon image is self-contained — no external assets or network requests required.
- Compatible with any React project; no additional dependencies beyond React itself.
