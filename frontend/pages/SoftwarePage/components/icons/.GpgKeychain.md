A React SVG component that renders the GPG Keychain icon as an inline SVG element containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`GpgKeychain`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, forwarding all props to the root `<svg>` element
- Renders a 32×32 `<svg>` with an embedded `<image>` using a base64-encoded PNG `href`

## Usage Example

```typescript
import GpgKeychain from "./GpgKeychain";

// Basic usage
<GpgKeychain />

// With custom size and className
<GpgKeychain width={64} height={64} className="icon" />

// With accessibility attributes
<GpgKeychain aria-label="GPG Keychain" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are supported via prop spreading
- The base64 PNG is embedded inline — no external asset fetch required
- Default rendered size is **32×32px**; override via `width`/`height` props
