React SVG component that renders the Shottr app icon as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Shottr`** — Default export. A functional React component that wraps a 32×32 SVG element containing a base64-encoded PNG of the Shottr screenshot tool icon.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>`, allowing consumers to pass any valid SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Shottr from "./Shottr";

// Basic usage
<Shottr />

// With custom size and class
<Shottr width={64} height={64} className="app-icon" />

// With click handler
<Shottr onClick={() => console.log("Shottr icon clicked")} />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via props.
- The image data is self-contained as a base64 PNG, so no external image assets are required.
- This component is part of the Flamingo/OpenFrame icon library, likely used to represent [Shottr](https://shottr.cc) integration within the MSP tool stack.
