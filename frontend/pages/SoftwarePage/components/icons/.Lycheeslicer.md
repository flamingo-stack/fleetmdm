React SVG icon component that renders the Lychee Slicer application logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Lycheeslicer`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a base64-encoded PNG logo via an `<image>` element.

## Usage Example

```typescript
import Lycheeslicer from "./Lycheeslicer";

// Basic usage
<Lycheeslicer />

// With custom dimensions or className
<Lycheeslicer width={64} height={64} className="icon" />

// With accessibility attributes
<Lycheeslicer aria-label="Lychee Slicer" role="img" />
```

## Notes

- The component renders at **32×32px** by default but accepts any `SVGProps` for overrides.
- The PNG image is **512×512** source resolution (per embedded EXIF metadata), downscaled to the SVG viewport.
- Because the image is base64-inlined, no external asset request is made at runtime.
