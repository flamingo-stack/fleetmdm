React SVG component that renders the OmniDiskSweeper application icon as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Omnidisksweeper`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a fixed 32×32 `<svg>` element containing a base64-encoded PNG `<image>`.

## Usage Example

```typescript
import Omnidisksweeper from "./Omnidisksweeper";

// Basic usage
<Omnidisksweeper />

// With custom props
<Omnidisksweeper className="app-icon" aria-label="OmniDiskSweeper" />
```

## Notes

- The icon image is fully self-contained — no external assets or network requests required.
- All `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Width and height default to `32` but can be overridden via props.
