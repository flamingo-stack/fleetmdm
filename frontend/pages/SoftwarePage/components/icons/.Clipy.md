A React SVG component that renders the Clipy application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Clipy`** — Default export; a functional React component that wraps a base64-encoded 32×32 PNG icon inside an `<svg>` element. Accepts all standard `SVGProps<SVGSVGElement>` props for customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Clipy from "./Clipy";

// Basic usage
<Clipy />

// With custom dimensions or class
<Clipy width={64} height={64} className="app-icon" />

// With click handler
<Clipy onClick={() => console.log("Clipy clicked")} />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- The embedded PNG metadata indicates an original resolution of 512×512 pixels, downscaled to 32×32 in the SVG viewport.
- Props are spread directly onto the `<svg>` element, making the component fully composable with standard SVG attributes.
