A React SVG component that renders the YubiKey Manager application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`YubiKeyManager`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 YubiKey Manager icon via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import YubiKeyManager from "./YubikeyManager";

// Basic usage
<YubiKeyManager />

// With custom dimensions and className
<YubiKeyManager width={64} height={64} className="app-icon" />

// With accessibility attributes
<YubiKeyManager
  role="img"
  aria-label="YubiKey Manager"
  width={32}
  height={32}
/>
```

## Notes

- The icon image is self-contained — no external image assets or network requests are required.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded directly to the `<svg>` element via spread.
- The inner `<image>` is fixed at 32×32 pixels; scaling should be applied via the outer SVG props.
