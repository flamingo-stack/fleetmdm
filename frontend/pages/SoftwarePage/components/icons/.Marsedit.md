A React SVG component that renders the MarsEdit application icon as a 32×32 embedded PNG image via a base64-encoded data URI.

## Key Components

- **`Marsedit`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element containing the MarsEdit app icon as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Marsedit from "./Marsedit";

// Basic usage
<Marsedit />

// With custom dimensions or className
<Marsedit width={64} height={64} className="app-icon" />

// With accessibility attributes
<Marsedit aria-label="MarsEdit" role="img" />
```

## Notes

- The icon image is fully self-contained — no external image files or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
