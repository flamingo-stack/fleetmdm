SVG icon component for the TexLive Utility application, rendering a 32×32 PNG-embedded icon as a React SVG element.

## Key Components

- **`TexLiveUtility`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG image of the TexLive Utility icon.

## Usage Example

```typescript
import TexLiveUtility from "./TexLiveUtility";

// Basic usage
const App = () => <TexLiveUtility />;

// With custom dimensions or className
const App = () => (
  <TexLiveUtility
    width={64}
    height={64}
    className="icon"
    style={{ opacity: 0.8 }}
  />
);
```

## Notes

- The icon image is embedded as a base64-encoded PNG within the SVG `<image>` element, so no external asset loading is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
