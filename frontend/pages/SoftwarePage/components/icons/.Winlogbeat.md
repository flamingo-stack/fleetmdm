A React SVG icon component that renders the Winlogbeat logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Winlogbeat`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Winlogbeat icon.

## Usage Example

```typescript
import Winlogbeat from "./Winlogbeat";

// Basic usage
<Winlogbeat />

// With custom dimensions or className
<Winlogbeat width={64} height={64} className="icon" />

// With accessibility attributes
<Winlogbeat aria-label="Winlogbeat" role="img" />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The icon is embedded as a base64 PNG — no external image requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
