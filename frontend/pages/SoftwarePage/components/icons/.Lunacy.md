A React SVG component that renders the Lunacy application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Lunacy`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Lunacy logo as an embedded base64 PNG.

## Usage Example

```typescript
import { Lunacy } from "./Lunacy";

// Basic usage
<Lunacy />

// With custom dimensions or className
<Lunacy width={64} height={64} className="app-icon" />

// With accessibility attributes
<Lunacy aria-label="Lunacy" role="img" />
```

## Notes

- The icon is rendered at **32×32 pixels** by default but can be overridden via props.
- The PNG image data is embedded directly as a base64 `href` on an SVG `<image>` element — no external asset fetch required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
