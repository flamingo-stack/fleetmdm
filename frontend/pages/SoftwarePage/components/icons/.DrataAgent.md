React SVG component that renders the Drata Agent logo as an inline PNG image embedded via base64 encoding within an SVG wrapper.

## Key Components

- **`DrataAgent`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains an embedded 512×512 PNG (downscaled) of the Drata Agent icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import DrataAgent from "./DrataAgent";

// Basic usage
<DrataAgent />

// With custom dimensions or className
<DrataAgent width={64} height={64} className="icon" />

// As part of an integration tile
<div className="integration-card">
  <DrataAgent aria-label="Drata Agent" />
  <span>Drata Agent</span>
</div>
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`).
- The icon is self-contained — no external image fetch required; the PNG is inlined as base64.
- Default render size is `32×32` px; override via `width`/`height` props.
