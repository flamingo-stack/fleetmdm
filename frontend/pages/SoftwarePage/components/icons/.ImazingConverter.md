A React SVG component that renders the iMazing Converter application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`ImazingConverter`** — Default-exported React functional component that renders a 32×32 SVG element containing an embedded PNG icon via a base64 `href` on an `<image>` element
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.)

## Usage Example

```typescript
import ImazingConverter from "./ImazingConverter";

// Basic usage
<ImazingConverter />

// With custom size and className
<ImazingConverter width={64} height={64} className="icon" />

// With click handler
<ImazingConverter onClick={() => console.log("clicked")} />
```

## Notes

- The icon is self-contained — no external image assets required at runtime
- The embedded PNG was originally 512×512 pixels (per EXIF metadata) and is downscaled to 32×32 via SVG attributes
- Extend or override dimensions via the `width`/`height` props passed through `SVGProps`
