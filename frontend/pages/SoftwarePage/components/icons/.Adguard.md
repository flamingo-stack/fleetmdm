A React SVG component that renders the Adguard brand logo as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Adguard`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64 PNG of the Adguard logo.

## Usage Example

```typescript
import Adguard from "./Adguard";

// Basic usage
<Adguard />

// With custom dimensions and className
<Adguard width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Adguard aria-label="Adguard" role="img" />
```

## Notes

- The logo image is self-contained — no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded directly to the `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props.
