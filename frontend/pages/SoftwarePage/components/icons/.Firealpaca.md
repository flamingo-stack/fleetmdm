A React SVG component that renders the FireAlpaca application icon as an inline PNG image encoded in base64, embedded within an SVG wrapper.

## Key Components

- **`Firealpaca`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the FireAlpaca logo.

## Usage Example

```typescript
import Firealpaca from "./Firealpaca";

// Basic usage
<Firealpaca />

// With custom dimensions or className
<Firealpaca width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Firealpaca aria-label="FireAlpaca" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained — no external network request is made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
