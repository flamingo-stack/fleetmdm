A React SVG component that renders the BlueWallet cryptocurrency wallet logo as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Bluewallet`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Bluewallet from "./Bluewallet";

// Basic usage
<Bluewallet />

// With custom dimensions
<Bluewallet width={64} height={64} />

// With className or style overrides
<Bluewallet className="wallet-icon" style={{ opacity: 0.8 }} />
```

## Notes

- The logo is rendered via an embedded base64 PNG (`<image>` element), so no external asset fetch is required.
- Default size is `32×32` px; override with `width`/`height` props.
- Fully typed via `SVGProps<SVGSVGElement>` — all standard SVG attributes (e.g., `aria-label`, `className`, `onClick`) are supported.
