A React SVG component that renders a 32×32 "Transfer" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Transfer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- Renders a 32×32 SVG shell containing an `<image>` element with a base64-encoded PNG as its `href`.

## Usage Example

```typescript
import Transfer from "./Transfer";

// Basic usage
<Transfer />

// With custom size or className
<Transfer width={24} height={24} className="icon-transfer" />

// With ARIA attributes for accessibility
<Transfer aria-label="Transfer" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
- The icon's visual content is a static PNG bitmap; scaling beyond 32×32 may result in blurring since the image is raster-based rather than vector-native.
