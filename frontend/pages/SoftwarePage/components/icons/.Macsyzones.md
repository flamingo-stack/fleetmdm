A React SVG icon component that renders the Macsyzones brand logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Macsyzones`** — Default export. A functional React component that wraps a base64-encoded PNG inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for full customization.

## Usage Example

```typescript
import Macsyzones from "./Macsyzones";

// Basic usage
<Macsyzones />

// With custom size and className
<Macsyzones width={64} height={64} className="icon" />

// With custom style
<Macsyzones style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32px**; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, enabling `className`, `style`, `aria-*`, and event handlers.
- The image data is embedded as a base64 PNG — no external asset fetch required.
