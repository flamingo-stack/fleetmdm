A React SVG icon component that renders the BeaverNotes application logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`BeaverNotes`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image.

## Usage Example

```typescript
import BeaverNotes from "./BeaverNotes";

// Basic usage
<BeaverNotes />

// With custom dimensions or className
<BeaverNotes width={64} height={64} className="app-icon" />

// With accessibility attributes
<BeaverNotes aria-label="BeaverNotes" role="img" />
```

## Notes

- The icon image is self-contained — no external image assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is `32×32`px; override via `width`/`height` props.
