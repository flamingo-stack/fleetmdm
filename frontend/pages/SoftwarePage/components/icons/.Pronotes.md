React SVG icon component that renders the Pronotes application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Pronotes`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Pronotes app icon as an embedded PNG.

## Usage Example

```typescript
import Pronotes from "./Pronotes";

// Basic usage
<Pronotes />

// With custom dimensions or className
<Pronotes width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Pronotes aria-label="Pronotes" role="img" />
```

## Notes

- The icon is a 32×32 SVG with a base64-encoded PNG embedded via an `<image>` element (original PNG is 512×512 pixels).
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
- No external dependencies beyond React — the image data is fully self-contained.
