A React SVG component that renders a 32×32 "Hot" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Hot`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Hot from "./Hot";

// Basic usage
<Hot />

// With custom sizing or className
<Hot width={64} height={64} className="icon-hot" />

// With accessibility attributes
<Hot aria-label="Hot item" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded via spread (`{...props}`).
- The icon is self-contained — no external image assets required.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
