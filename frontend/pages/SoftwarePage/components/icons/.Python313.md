A React SVG component that renders the Python 3.13 logo as an inline SVG image using a base64-encoded PNG data URI at 32×32 pixels.

## Key Components

- **`SvgPython313`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering an `<svg>` element containing a base64-embedded PNG of the Python 3.13 logo.

## Usage Example

```typescript
import SvgPython313 from "./Python313";

// Basic usage
<SvgPython313 />

// With custom dimensions and class
<SvgPython313 width={64} height={64} className="icon" />

// With accessibility attributes
<SvgPython313 aria-label="Python 3.13" role="img" />
```

## Notes

- Renders at **32×32px** by default; override with `width`/`height` props.
- The logo is embedded as a **base64 PNG** inside an SVG `<image>` tag — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread.
- Typically used in UI elements such as technology badges, version selectors, or language icons within the Fleet MDM interface.
