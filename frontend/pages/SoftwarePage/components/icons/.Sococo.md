A React component that renders the Sococo logo as an SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Sococo`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Sococo from "./Sococo";

// Basic usage
<Sococo />

// With custom size and style
<Sococo width={64} height={64} style={{ opacity: 0.8 }} />

// With className for Tailwind/CSS
<Sococo className="text-gray-500 hover:text-gray-900" />
```

## Notes

- The logo is self-contained via a base64-encoded PNG embedded as an `<image>` element — no external asset dependency.
- Default rendered size is **32×32px**; override via `width`/`height` props.
