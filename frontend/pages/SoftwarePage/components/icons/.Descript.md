React SVG component that renders the Descript application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Descript`** — Default export. A functional React component wrapping an `<svg>` element that renders the Descript logo via an `<image>` tag with an inline base64 PNG data URI.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override or extend SVG attributes (e.g., `className`, `style`, `aria-label`).

## Usage Example

```typescript
import Descript from "./Descript";

// Basic usage
<Descript />

// With custom size and class
<Descript width={64} height={64} className="app-icon" />

// With accessibility label
<Descript aria-label="Descript" role="img" />
```

## Notes

- Default dimensions are `32×32` pixels; override via `width`/`height` props.
- The icon image is fully self-contained — no external network requests are made.
