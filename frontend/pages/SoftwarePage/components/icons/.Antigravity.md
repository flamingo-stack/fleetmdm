SVG icon component that renders the Antigravity logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Antigravity`** — Default export React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing a base64-encoded PNG image

## Usage Example

```typescript
import Antigravity from "./Antigravity";

// Basic usage
<Antigravity />

// With custom dimensions or className
<Antigravity width={64} height={64} className="icon" />

// With style overrides
<Antigravity style={{ opacity: 0.8 }} />
```

## Notes

- Dimensions default to `32×32` pixels but can be overridden via props
- The image data is fully self-contained — no external asset requests at runtime
- All standard SVG props (e.g. `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element via spread
