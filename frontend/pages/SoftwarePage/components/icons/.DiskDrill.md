A React SVG component that renders the Disk Drill application icon as an inline base64-encoded PNG image at a fixed 32×32 pixel size.

## Key Components

- **`DiskDrill`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

The component renders a 32×32 `<svg>` containing an `<image>` element with the Disk Drill app icon embedded as a base64-encoded PNG (originally 512×512 px per EXIF metadata).

## Usage Example

```typescript
import DiskDrill from "./DiskDrill";

// Basic usage
const App = () => (
  <DiskDrill />
);

// With custom size and className
const CustomIcon = () => (
  <DiskDrill
    width={64}
    height={64}
    className="app-icon"
    style={{ borderRadius: 8 }}
  />
);
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- Props are forwarded to the `<svg>` element; the inner `<image>` dimensions are fixed at 32×32 and are not affected by prop overrides on the outer element.
- This component is part of the application icon set in the Flamingo/FleetMDM UI. See the full icon library at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
