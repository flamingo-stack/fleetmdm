React SVG wrapper component that renders the Linear logo as an inline PNG image embedded via a base64-encoded data URI within an SVG element.

## Key Components

- **`Linear`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Linear brand logo as an embedded PNG image

## Usage Example

```typescript
import Linear from "./Linear";

// Basic usage
<Linear />

// With custom dimensions and className
<Linear width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Linear aria-label="Linear" role="img" />
```

## Notes

- The logo is hardcoded at **32×32px** by default but can be overridden via `width`/`height` props
- The PNG is inlined as a base64 data URI — no external network request required
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded via spread (`{...props}`)
