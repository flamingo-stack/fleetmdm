A React SVG component that renders a 4K Video to MP3 converter icon as an embedded PNG image (512×512px) within an SVG wrapper.

## Key Components

- **`FourKVideoToMp3`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG icon

## Usage Example

```typescript
import FourKVideoToMp3 from './FourKVideoToMp3';

// Basic usage
<FourKVideoToMp3 />

// With custom dimensions and styling
<FourKVideoToMp3
  width={64}
  height={64}
  className="icon"
  style={{ opacity: 0.8 }}
/>

// With click handler
<FourKVideoToMp3
  onClick={() => handleConvert()}
  aria-label="Convert 4K video to MP3"
/>
```

## Notes

- The icon image is fully self-contained via a base64-encoded PNG embedded in the `href` attribute — no external image assets required
- Default rendered size is `32×32` pixels; override via `width`/`height` props
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element
