A React SVG component that renders the AWS VPN Client service icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`AwsVpnClient`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, allowing full SVG attribute customization (className, style, width, height, etc.)
- Renders a 32×32 `<svg>` containing an `<image>` element with a base64-encoded PNG of the AWS VPN Client logo

## Usage Example

```typescript
import AwsVpnClient from "./AwsVpnClient";

// Basic usage
<AwsVpnClient />

// Custom dimensions
<AwsVpnClient width={64} height={64} />

// With className and style
<AwsVpnClient className="service-icon" style={{ opacity: 0.8 }} />
```

## Notes

- The icon dimensions default to 32×32px but can be overridden via props
- The PNG data is fully self-contained — no external image requests
- Part of an AWS service icon set; see related icons in the same directory at [`https://github.com/flamingo-stack/fleetmdm/blob/main/`](https://github.com/flamingo-stack/fleetmdm/blob/main/)
