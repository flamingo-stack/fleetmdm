SVG icon component that renders the Microsoft 365 Copilot logo as an inline base64-encoded PNG image.

## Key Components

- **`Microsoft365Copilot`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing the Microsoft 365 Copilot icon as an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Microsoft365Copilot from "./Microsoft365Copilot";

// Basic usage
<Microsoft365Copilot />

// With custom size or className
<Microsoft365Copilot width={64} height={64} className="icon" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon image is self-contained (no external network requests) — the PNG is inlined as a base64 data URI inside an SVG `<image>` element.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element via spread.
