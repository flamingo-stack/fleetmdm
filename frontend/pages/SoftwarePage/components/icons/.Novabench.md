A React SVG icon component that renders the Novabench application logo as a 32×32 pixel image with an embedded base64-encoded PNG.

## Key Components

- **`Novabench`** — Default export. A functional React component that renders an SVG wrapper containing the Novabench logo as an inline base64 PNG image.

## Usage Example

```typescript
import Novabench from "./Novabench";

// Basic usage
<Novabench />

// With custom dimensions or class
<Novabench width={64} height={64} className="app-icon" />

// With accessibility attributes
<Novabench aria-label="Novabench" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The logo is embedded as a base64 PNG (`data:image/png;base64,...`) inside an `<image>` element, so no external image file is required.
- Default rendered size is **32×32px**.
