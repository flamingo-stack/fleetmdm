A React SVG component that renders the App Fair icon as a 32×32 inline SVG containing an embedded base64-encoded PNG image.

## Key Components

- **`AppFair`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import AppFair from "./AppFair";

// Basic usage
<AppFair />

// With custom dimensions or className
<AppFair width={64} height={64} className="icon" />

// With accessibility attributes
<AppFair aria-label="App Fair" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is self-contained — no external image assets or network requests are required.
- Default rendered size is **32×32px**; the embedded PNG is encoded at **512×512px** for sharpness at higher resolutions if `width`/`height` props are overridden.
