React SVG component that renders the Microsoft Power Automate logo as an inline PNG image (base64-encoded) wrapped in an SVG element.

## Key Components

- **`PowerAutomate`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Power Automate icon as an embedded base64 PNG.

## Usage Example

```typescript
import PowerAutomate from "./PowerAutomate";

// Basic usage
<PowerAutomate />

// With custom dimensions or class
<PowerAutomate width={24} height={24} className="icon" />

// With inline styles or aria attributes
<PowerAutomate
  aria-label="Power Automate"
  style={{ verticalAlign: "middle" }}
/>
```

## Notes

- The icon is self-contained — no external image assets or network requests required.
- Inherits all `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) for full flexibility.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props.
