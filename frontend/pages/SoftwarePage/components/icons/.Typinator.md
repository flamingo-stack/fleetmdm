A React SVG component that renders the Typinator application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Typinator`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper containing the Typinator logo as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Typinator from "./Typinator";

// Basic usage
<Typinator />

// With custom size or className
<Typinator width={64} height={64} className="app-icon" />

// With accessibility attributes
<Typinator aria-label="Typinator" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32px**; the embedded PNG is **512×512px**, so upscaling via `width`/`height` props will remain sharp.
