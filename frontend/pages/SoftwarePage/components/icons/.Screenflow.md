A React SVG component that renders the Screenflow application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Screenflow`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Screenflow logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Screenflow from "./Screenflow";

// Basic usage
<Screenflow />

// With custom dimensions or className
<Screenflow width={64} height={64} className="icon" />

// With inline styles
<Screenflow style={{ opacity: 0.8 }} />
```

## Notes

- The component forwards all `SVGProps` to the underlying `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The icon image is a 512×512 PNG embedded as a base64 data URI, downscaled to 32×32 by default via SVG dimensions.
- No external asset dependencies; the icon is fully self-contained.
