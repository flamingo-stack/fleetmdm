React SVG icon component that renders the KeePassXC logo as an inline PNG image encoded in base64, wrapped in an SVG container.

## Key Components

- **`KeePassXc`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG with an embedded base64-encoded PNG of the KeePassXC application icon.

## Usage Example

```typescript
import KeePassXc from "./KeePassXc";

// Basic usage
<KeePassXc />

// With custom dimensions and className
<KeePassXc width={64} height={64} className="icon" />

// With accessibility attributes
<KeePassXc aria-label="KeePassXC" role="img" />
```

## Notes

- Defaults to `32×32` pixels; override via `width`/`height` props.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>`, enabling full styling and event handler support.
- The icon is self-contained — no external image assets or network requests required.
