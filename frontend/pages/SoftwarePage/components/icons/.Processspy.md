A React SVG component that renders the Processspy application icon as an embedded PNG image (32×32px) encoded in base64.

## Key Components

- **`Processspy`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image via a base64 `href` data URI.

## Usage Example

```typescript
import Processspy from "./Processspy";

// Basic usage
<Processspy />

// With custom dimensions or className
<Processspy width={64} height={64} className="app-icon" />

// With accessibility attributes
<Processspy aria-label="Processspy" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread props.
- The icon image is self-contained — no external image assets are required at runtime.
- Default render size is **32×32px**; the embedded PNG source is **512×512px**, so the component scales cleanly to larger sizes.
