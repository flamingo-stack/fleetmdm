React SVG component that renders the Nitro PDF Pro application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`NitroPdfPro`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around a base64-encoded PNG of the Nitro PDF Pro logo.

## Usage Example

```typescript
import NitroPdfPro from './NitroPdfPro';

// Basic usage
<NitroPdfPro />

// With custom dimensions and className
<NitroPdfPro width={64} height={64} className="app-icon" />

// With accessibility attributes
<NitroPdfPro aria-label="Nitro PDF Pro" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded via spread (`{...props}`), with `width` and `height` defaulting to `32`.
- The icon image is self-contained — no external image assets or network requests are required.
