A React SVG icon component that renders the AnyDesk logo as an inline base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`AnyDesk`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the AnyDesk brand logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import AnyDesk from "./AnyDesk";

// Basic usage
<AnyDesk />

// With custom dimensions and className
<AnyDesk width={64} height={64} className="icon" />

// With style overrides
<AnyDesk style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element.
- The logo image is self-contained — no external asset dependencies at runtime.
