A React SVG icon component that renders a "Mist" icon (32×32) using an embedded base64-encoded PNG image.

## Key Components

- **`Mist`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Mist from "./Mist";

// Basic usage
<Mist />

// With custom dimensions and class
<Mist width={64} height={64} className="icon-mist" />

// With accessibility attributes
<Mist aria-label="Mist" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
- The icon image is self-contained as a base64 PNG — no external asset loading required.
