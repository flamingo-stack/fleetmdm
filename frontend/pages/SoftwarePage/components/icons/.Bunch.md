A React SVG component that renders the **Bunch** icon (32×32) using an embedded base64-encoded PNG image.

## Key Components

- **`Bunch`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an inlined PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { Bunch } from "./Bunch";

// Basic usage
<Bunch />

// With custom dimensions and className
<Bunch width={64} height={64} className="icon" />

// With accessibility attributes
<Bunch aria-label="Bunch icon" role="img" />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The image data is self-contained (base64 PNG), so no external asset files are required.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
