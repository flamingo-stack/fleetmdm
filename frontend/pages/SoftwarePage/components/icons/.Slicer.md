A React SVG component that renders the Slicer application icon as an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Slicer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an inline PNG image via a `data:image/png;base64` href.

## Usage Example

```typescript
import Slicer from "./Slicer";

// Basic usage
<Slicer />

// With custom dimensions or className
<Slicer width={64} height={64} className="icon" />

// With style overrides
<Slicer style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external asset dependencies.
- Default render size is **32×32 pixels**.
