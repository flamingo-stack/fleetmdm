A React SVG component that renders the 4kstogram logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`FourKStogram`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper with an embedded base64 PNG image.

## Usage Example

```typescript
import FourKStogram from "./FourKStogram";

// Basic usage
<FourKStogram />

// With custom dimensions or class
<FourKStogram width={64} height={64} className="icon" />

// With style override
<FourKStogram style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded via spread to the root `<svg>` element.
- The image data is self-contained as a base64-encoded PNG — no external asset fetch required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
