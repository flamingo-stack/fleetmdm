A React SVG icon component that renders the macOS logo as an inline SVG element.

## Key Components

- **`MacOS`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 macOS Apple icon in a two-tone style (`#F9FAFC` background, `#515774` logo fill).

## Usage Example

```typescript
import MacOS from "./MacOS";

// Basic usage
<MacOS />

// With custom dimensions and className
<MacOS width={24} height={24} className="platform-icon" />

// With custom styling
<MacOS style={{ opacity: 0.8 }} aria-label="macOS" />
```

## Notes

- The SVG dimensions default to **32×32** via the background path (`M0 0h32v32H0z`).
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-label`) are forwarded via spread (`{...props}`), making it fully customizable.
- No hardcoded `width`/`height` attributes on the `<svg>` element itself, so sizing is controlled entirely through props or CSS.
