React SVG icon component that renders the Unity Hub logo as an embedded PNG image within an SVG wrapper.

## Key Components

- **`UnityHub`** — Default export; a functional React component wrapping an `<svg>` element that embeds a 32×32 Unity Hub logo as a base64-encoded PNG via an `<image>` tag.

## Usage Example

```typescript
import UnityHub from "./UnityHub";

// Basic usage
<UnityHub />

// With custom dimensions or className
<UnityHub width={64} height={64} className="icon" />

// With aria label for accessibility
<UnityHub aria-label="Unity Hub" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, enabling style, className, event handlers, and dimension overrides.
- The logo is self-contained via an inline base64 PNG — no external image assets required.
- Default rendered size is **32×32px**; override with `width`/`height` props.
