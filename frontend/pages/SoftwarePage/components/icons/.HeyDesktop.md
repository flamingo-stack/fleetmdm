React SVG component that renders the Hey Desktop application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`HeyDesktop`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a PNG image via a base64-encoded `data:image/png` URI.

## Usage Example

```typescript
import HeyDesktop from "./HeyDesktop";

// Basic usage
<HeyDesktop />

// With custom className or style
<HeyDesktop className="app-icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<HeyDesktop aria-label="Hey Desktop" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon is self-contained — no external image assets are required at runtime.
- Fixed dimensions: **32×32px**. Override via CSS or the `width`/`height` props if needed, though the embedded raster image is sized at 512×512px (as indicated by EXIF metadata), so scaling up may reduce quality.
