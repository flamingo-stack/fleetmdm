A React component that renders the ExpressVPN logo as an SVG element containing an embedded base64-encoded PNG image.

## Key Components

- **`ExpressVpn`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with the ExpressVPN brand icon embedded as a base64 PNG `<image>`.

## Usage Example

```typescript
import ExpressVpn from "./ExpressVpn";

// Basic usage
<ExpressVpn />

// With custom dimensions and className
<ExpressVpn width={64} height={64} className="icon" />

// With inline styles
<ExpressVpn style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
- The icon image is fully self-contained — no external network requests are made.
