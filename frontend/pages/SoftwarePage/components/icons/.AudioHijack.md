A React SVG component that renders the Audio Hijack application icon as an inline PNG image embedded via base64 encoding within an SVG wrapper.

## Key Components

- **`AudioHijack`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains the Audio Hijack app icon as an embedded base64 PNG.

## Usage Example

```typescript
import AudioHijack from "./AudioHijack";

// Basic usage
<AudioHijack />

// With custom dimensions or className
<AudioHijack width={64} height={64} className="app-icon" />

// With aria label for accessibility
<AudioHijack aria-label="Audio Hijack" role="img" />
```

## Notes

- The icon is delivered as a base64-encoded PNG embedded inside an `<image>` element, meaning no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32 pixels**; override with `width` and `height` props as needed.
