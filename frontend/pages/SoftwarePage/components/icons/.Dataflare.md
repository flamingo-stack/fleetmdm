A React SVG icon component that renders the Dataflare logo as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Dataflare`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element that embeds the Dataflare logo as an inline base64 PNG `<image>`.

## Usage Example

```typescript
import Dataflare from './Dataflare';

// Basic usage
<Dataflare />

// With custom dimensions or className
<Dataflare width={64} height={64} className="icon" />

// With accessibility attributes
<Dataflare aria-label="Dataflare" role="img" />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread.
- The logo image is self-contained — no external network requests are made.
