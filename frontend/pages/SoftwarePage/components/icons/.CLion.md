A React SVG component that renders the CLion IDE logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`CLion`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 CLion logo icon.

## Usage Example

```typescript
import CLion from "./CLion";

// Basic usage
<CLion />

// With custom size or className
<CLion width={64} height={64} className="icon" />

// With accessibility attributes
<CLion aria-label="CLion IDE" role="img" />
```

## Notes

- The icon is fixed at a default size of 32×32 pixels but can be overridden via `width`/`height` props.
- The logo image is embedded as a base64 PNG inside an `<image>` element — no external asset requests are made.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
