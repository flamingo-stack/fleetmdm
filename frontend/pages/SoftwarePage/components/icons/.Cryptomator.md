React SVG component that renders the Cryptomator application icon as an inline PNG image encoded in base64, sized at 32×32 pixels.

## Key Components

- **`Cryptomator`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full prop forwarding (e.g., `className`, `style`, `onClick`).
- **Inline `<image>`** — Renders a base64-encoded PNG asset directly within the SVG, avoiding any external file dependency.

## Usage Example

```typescript
import Cryptomator from "./Cryptomator";

// Basic usage
<Cryptomator />

// With custom size and class
<Cryptomator width={64} height={64} className="app-icon" />

// With click handler
<Cryptomator onClick={() => console.log("Cryptomator selected")} />
```

## Notes

- Default dimensions are **32×32px**; override via `width`/`height` props.
- The icon asset is fully self-contained — no network requests or external image files required.
- Compatible with any React project using standard SVG rendering.
