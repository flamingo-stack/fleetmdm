A React SVG icon component that renders a memory/RAM icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Memory`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) and rendering a 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import Memory from './Memory';

// Basic usage
<Memory />

// With custom dimensions and className
<Memory width={64} height={64} className="icon-memory" />

// With accessibility attributes
<Memory aria-label="Memory" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default; dimensions can be overridden via props.
- The actual image is a **512×512 PNG** embedded as a base64 `data:image/png` URI, so no external image assets are required.
- All standard `SVGSVGElement` props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
