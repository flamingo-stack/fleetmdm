React SVG component that renders the Amazon Corretto 26 logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`AmazonCorretto26`** — Default-exported React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 `<svg>` with an embedded PNG logo via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import AmazonCorretto26 from "./AmazonCorretto26";

// Basic usage
<AmazonCorretto26 />

// With custom dimensions or className
<AmazonCorretto26 width={64} height={64} className="icon" />

// Inside a software inventory table
<td>
  <AmazonCorretto26 aria-label="Amazon Corretto 26" />
  Amazon Corretto 26
</td>
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded via spread (`{...props}`).
- The logo image is self-contained — no external network requests are made at render time.
- Default rendered size is **32×32 px**; override via `width`/`height` props.
