React SVG icon component that renders the Gather logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Gather`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Gather logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Gather from "./Gather";

// Basic usage
<Gather />

// With custom dimensions or className
<Gather width={64} height={64} className="icon" />

// With ARIA attributes for accessibility
<Gather aria-label="Gather" role="img" />
```

## Notes

- Fixed default size: **32×32 pixels** (overridable via `width`/`height` props).
- The PNG image data is fully inlined as a base64 URI — no external network request is made.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- Part of the icon set in the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) repository.
