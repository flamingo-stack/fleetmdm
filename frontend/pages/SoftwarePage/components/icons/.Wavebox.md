A React SVG component that renders the Wavebox application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Wavebox`** — Default export; a functional React component that wraps a base64-encoded PNG inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import Wavebox from "./Wavebox";

// Basic usage
<Wavebox />

// With custom dimensions or className
<Wavebox width={64} height={64} className="app-icon" />

// With accessibility attributes
<Wavebox aria-label="Wavebox" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is self-contained (base64 PNG inline), requiring no external asset requests.
- All standard SVG props (`className`, `style`, `onClick`, etc.) are passed through via spread.
