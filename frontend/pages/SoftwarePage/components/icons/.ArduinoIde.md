SVG icon component that renders the Arduino IDE application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`ArduinoIde`** — Default exported React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Arduino IDE logo as an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import ArduinoIde from "./ArduinoIde";

// Basic usage
<ArduinoIde />

// With custom dimensions or className
<ArduinoIde width={64} height={64} className="app-icon" />

// With accessibility attributes
<ArduinoIde aria-label="Arduino IDE" role="img" />
```

## Notes

- The component passes all `SVGProps` through to the root `<svg>` element, enabling full customization (size, style, className, event handlers, etc.).
- The logo is self-contained via base64 encoding — no external image assets or network requests required.
- Default render size is **32×32 pixels**.
