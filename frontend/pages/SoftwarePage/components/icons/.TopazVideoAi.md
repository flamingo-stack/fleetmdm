A React SVG icon component that renders the Topaz Video AI logo as a 32×32 inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`TopazVideoAi`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import TopazVideoAi from "./TopazVideoAi";

// Basic usage
<TopazVideoAi />

// With custom dimensions or className
<TopazVideoAi width={64} height={64} className="icon" />

// With inline styles
<TopazVideoAi style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32px**; override via `width`/`height` props.
- The PNG image data is fully self-contained (base64-encoded), requiring no external assets or network requests.
