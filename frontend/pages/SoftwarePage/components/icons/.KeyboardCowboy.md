A React SVG component that renders a 32×32 "Keyboard Cowboy" icon using an embedded base64-encoded PNG image.

## Key Components

- **`KeyboardCowboy`** — Default exported functional component that renders an SVG wrapper containing a base64-encoded PNG image at 32×32 pixels
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`)

## Usage Example

```typescript
import KeyboardCowboy from "./KeyboardCowboy";

// Basic usage
<KeyboardCowboy />

// With custom size or class
<KeyboardCowboy width={64} height={64} className="icon" />

// With event handler
<KeyboardCowboy onClick={() => console.log("clicked")} />
```

## Notes

- The icon image is inlined as a base64 PNG, so no external image assets are required
- Default dimensions are `32x32`; override via `width`/`height` props
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/KeyboardCowboy.tsx)
