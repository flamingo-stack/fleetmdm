React SVG icon component that renders the Proxyman application logo as an inline PNG image encoded in base64 within an SVG wrapper.

## Key Components

- **`Proxyman`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Proxyman logo as an embedded base64-encoded PNG.

## Usage Example

```typescript
import Proxyman from "./Proxyman";

// Basic usage
<Proxyman />

// With custom dimensions or className
<Proxyman width={64} height={64} className="app-icon" />

// With accessibility attributes
<Proxyman aria-label="Proxyman" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`).
- The default rendered size is **32×32 pixels**.
- The logo image data is self-contained (base64-encoded PNG via a `<image href="data:image/png;base64,…" />` element), requiring no external asset imports or network requests.
- Typically used as a vendor/tool icon within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) UI to represent the Proxyman network debugging proxy tool.
