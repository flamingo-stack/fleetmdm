A React SVG component that renders the Cursr logo/icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Cursr`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, which allows full customization of the SVG element (e.g., `className`, `style`, `onClick`).

The component renders an `<svg>` wrapper at 32×32 pixels containing an `<image>` element that displays a base64-encoded PNG. All SVG props are forwarded via spread (`{...props}`).

## Usage Example

```typescript
import Cursr from "./Cursr";

// Basic usage
<Cursr />

// With custom size and class
<Cursr width={64} height={64} className="icon" />

// With click handler
<Cursr onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The PNG is embedded inline as a base64 data URI — no external image file or network request required.
- Default dimensions are **32×32 px** but can be overridden via props.
- Suitable for use as a brand icon or logo in navigation bars, buttons, or toolbars.
