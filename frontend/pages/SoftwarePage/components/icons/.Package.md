A React SVG icon component that renders a 3D-style package/box icon with brown and orange tones, sized at 32×32 pixels.

## Key Components

- **`Package`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `width`, `height`, `style`).
- **`clipPathId`** — A `uniqueId`-generated ID (via lodash) ensuring no `clipPath` ID collisions when multiple instances are rendered on the same page.

## Usage Example

```typescript
import Package from "./Package";

// Basic usage
<Package />

// With custom dimensions and class
<Package width={24} height={24} className="icon-package" />

// With inline style
<Package style={{ color: "#FF9701" }} width={48} height={48} />
```

## Notes

- The component uses a `clipPath` clipping region scoped to an 18×20 area within the 32×32 canvas.
- The icon is rendered with `fill="none"` as a base, with all colors defined inline across the SVG paths.
- The `uniqueId` call ensures safe reuse across multiple instances without conflicting `id` attributes in the DOM.
