A React SVG component that renders a dot icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Dot`** — Default export; a functional React component wrapping an `<svg>` element with a single `<image>` child that renders a 32×32 PNG via an inline base64 `href`. Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Dot from "./Dot";

// Basic usage
<Dot />

// With custom dimensions via viewBox override
<Dot width={16} height={16} />

// With className for styling
<Dot className="status-indicator" style={{ opacity: 0.8 }} />
```

## Notes

- The icon is self-contained — no external image assets are required.
- Because the PNG is base64-encoded directly in the source, bundle size will increase proportionally; consider an SVG path or external sprite if bundle size is a concern.
- The underlying PNG is 512×512px (per EXIF metadata), downscaled to 32×32 at render time.
