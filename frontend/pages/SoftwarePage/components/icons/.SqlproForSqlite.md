React SVG component that renders the SQLPro for SQLite application icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`SqlproForSqlite`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing a base64-encoded PNG of the SQLPro for SQLite application icon.

## Usage Example

```typescript
import SqlproForSqlite from "./SqlproForSqlite";

// Basic usage
<SqlproForSqlite />

// With custom dimensions or className
<SqlproForSqlite width={64} height={64} className="app-icon" />

// With accessibility attributes
<SqlproForSqlite aria-label="SQLPro for SQLite" role="img" />
```

## Notes

- The icon image is fully self-contained via a base64-encoded PNG data URI — no external image assets are required.
- Default rendered size is **32×32 pixels**; this can be overridden via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- Sourced from [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/SqlproForSqlite.tsx).
