React SVG component that renders the ProtonVPN logo as an inline image using a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`ProtonVpn`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded base64 PNG of the ProtonVPN logo.

## Usage Example

```typescript
import ProtonVpn from "./ProtonVpn";

// Basic usage
<ProtonVpn />

// With custom dimensions or className
<ProtonVpn width={64} height={64} className="vpn-icon" />

// With accessibility attributes
<ProtonVpn aria-label="ProtonVPN" role="img" />
```

## Notes

- The component defaults to `32×32` pixels but accepts any `SVGProps` overrides.
- The logo image is fully self-contained — no external asset requests at runtime.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — search the repo for `ProtonVpn.tsx` to find its exact path.
