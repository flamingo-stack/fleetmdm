A React SVG component that renders a "Radio Silence" icon as a 32×32 SVG element containing an embedded base64-encoded PNG image.

## Key Components

- **`RadioSilence`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props, allowing callers to override attributes such as `className`, `style`, `width`, `height`, and event handlers.

## Usage Example

```typescript
import RadioSilence from "./RadioSilence";

// Basic usage
<RadioSilence />

// With custom size and className
<RadioSilence width={64} height={64} className="icon" />

// With inline styles
<RadioSilence style={{ opacity: 0.5 }} />
```

## Notes

- The icon image is inlined as a base64-encoded PNG (512×512 source), rendered via an SVG `<image>` element at 32×32 display size.
- No external asset dependencies — fully self-contained.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — find the file at `https://github.com/flamingo-stack/fleetmdm/blob/main/` (append the actual path within the repo).
