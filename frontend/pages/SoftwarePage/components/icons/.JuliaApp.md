A React SVG component that renders the Julia programming language application icon as a 32×32 pixel image.

## Key Components

- **`JuliaApp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering an embedded base64-encoded PNG of the Julia app logo inside an SVG wrapper.

## Usage Example

```typescript
import JuliaApp from "./JuliaApp";

// Basic usage
<JuliaApp />

// With custom size or className
<JuliaApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<JuliaApp aria-label="Julia application" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32px** but can be overridden via `width`/`height` props.
- The image data is fully self-contained as a base64-encoded PNG — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
