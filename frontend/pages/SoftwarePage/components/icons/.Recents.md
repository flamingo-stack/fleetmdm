A React SVG component that renders a 32×32 "Recents" icon using an embedded base64-encoded PNG image, allowing it to be used as a standard SVG element throughout the UI.

## Key Components

- **`Recents`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper with an embedded PNG icon via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Recents from "./Recents";

// Basic usage
<Recents />

// With custom dimensions or className
<Recents width={24} height={24} className="icon-recents" />

// With accessibility attributes
<Recents aria-label="Recent items" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element via spread.
- The icon image is self-contained — no external assets or network requests are required.
- Default rendered size is `32×32` pixels; override with `width`/`height` props as needed.
