A React SVG component that renders a 32×32 Viz icon using an embedded base64-encoded PNG image.

## Key Components

- **`Viz`** — Default export; a functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`)
- Renders a fixed 32×32 `<svg>` wrapper containing an `<image>` element with an inline base64 PNG data URI

## Usage Example

```typescript
import Viz from "./Viz";

// Basic usage
<Viz />

// With custom className or style
<Viz className="my-icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Viz aria-label="Viz icon" role="img" />
```

## Notes

- All standard `SVGProps<SVGSVGElement>` props are forwarded to the root `<svg>` element (e.g., `className`, `style`, `onClick`, `aria-*`)
- The icon dimensions are fixed at 32×32 pixels by default; override via `width`/`height` props or CSS
- The PNG payload is self-contained — no external asset requests
