SVG icon component that renders the Obsidian logo as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Obsidian`** — Default export; a React functional component that accepts standard `SVGProps<SVGSVGElement>` and renders an `<svg>` element containing the Obsidian app icon as an embedded base64 PNG.

## Usage Example

```typescript
import Obsidian from "./Obsidian";

// Basic usage
<Obsidian />

// With custom className or style
<Obsidian className="icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Obsidian width={64} height={64} />
```

## Notes

- Default render size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded via spread.
- The icon image is self-contained — no external network requests are made.
