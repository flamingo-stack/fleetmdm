A React SVG component that renders the Rive logo as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Rive`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG wrapper around an embedded PNG image of the Rive logo.

## Usage Example

```typescript
import Rive from "./Rive";

// Basic usage
<Rive />

// With custom className or style
<Rive className="logo-icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Rive width={64} height={64} />
```

## Notes

- The image data is embedded as a base64-encoded PNG, so no external asset loading is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
