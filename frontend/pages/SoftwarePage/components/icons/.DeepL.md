React SVG component that renders the DeepL logo as an inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`DeepL`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper containing a base64-encoded PNG of the DeepL brand logo.

## Usage Example

```typescript
import DeepL from "./DeepL";

// Basic usage
<DeepL />

// With custom dimensions or className
<DeepL width={64} height={64} className="brand-icon" />

// With aria attributes for accessibility
<DeepL aria-label="DeepL logo" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via `{...props}`.
- The image content is a static base64 PNG; no external network request is made at runtime.
- Default rendered size is **32×32 pixels**.
