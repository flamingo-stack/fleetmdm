A React SVG component that renders the Klokki app icon as a 32×32 inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Klokki`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute/style customization.

## Usage Example

```typescript
import Klokki from "./Klokki";

// Basic usage
<Klokki />

// With custom size and className
<Klokki width={64} height={64} className="app-icon" />

// With style overrides
<Klokki style={{ opacity: 0.8 }} aria-label="Klokki" />
```

## Notes

- The icon is a **512×512 source PNG** downscaled to `32×32` display size via the SVG `width`/`height` props.
- All props are spread onto the root `<svg>` element, enabling overrides for `width`, `height`, `className`, `style`, `aria-*`, and other SVG attributes.
- The image data is self-contained — no external asset fetch required.
