React SVG component that renders the Binance cryptocurrency exchange logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`Binance`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Binance logo within an SVG wrapper.

## Usage Example

```typescript
import Binance from './Binance';

// Basic usage
<Binance />

// With custom dimensions or className
<Binance width={64} height={64} className="crypto-icon" />

// With inline styles
<Binance style={{ opacity: 0.8 }} />
```

## Notes

- The logo is embedded as a base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` element, making it self-contained with no external asset dependencies.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
