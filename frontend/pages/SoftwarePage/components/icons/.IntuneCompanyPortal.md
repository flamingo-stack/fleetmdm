SVG icon component that renders the Microsoft Intune Company Portal logo as a scalable vector graphic with dynamically generated unique IDs to prevent conflicts when multiple instances are rendered on the same page.

## Key Components

- **`IntuneCompanyPortal`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, allowing full customization of size, className, style, and other SVG attributes.
- **Unique ID generation** — Uses `lodash.uniqueId` to generate unique IDs for `clipPath`, `mask`, and `linearGradient` elements, preventing DOM ID collisions when the icon is rendered multiple times.
- **Linear gradients** — Two `linearGradient` definitions (`fillPathCId`, `fillPathDId`) render the avatar circle and silhouette with a cyan-to-blue gradient (`#4EE3FE` → `#21A6E5`).
- **Masked background grid** — A luminance mask (`maskBId`) segments the background into a colored tile grid using Microsoft's Intune blue palette (`#134583`, `#0862B2`, `#0B87DA`, `#31BCEF`).

## Usage Example

```typescript
import IntuneCompanyPortal from "./IntuneCompanyPortal";

// Default render (inherits parent size)
<IntuneCompanyPortal />

// Fixed size with custom class
<IntuneCompanyPortal width={32} height={32} className="app-icon" />

// Multiple instances — no ID collisions
<IntuneCompanyPortal width={16} height={16} />
<IntuneCompanyPortal width={24} height={24} />
```

## Notes

- The component has no intrinsic size; always pass explicit `width` and `height` props or control dimensions via CSS.
