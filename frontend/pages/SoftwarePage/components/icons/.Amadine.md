A React SVG component that renders the Amadine application icon as an inline base64-encoded PNG image (32×32 pixels).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Amadine` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapper containing the Amadine app icon as an embedded PNG |

## Usage Example

```typescript
import Amadine from "./Amadine";

// Basic usage
<Amadine />

// With custom dimensions or className
<Amadine width={64} height={64} className="app-icon" />

// With style overrides
<Amadine style={{ borderRadius: 8 }} />
```

All standard [`SVGProps`](https://react.dev/reference/react-dom/components/svg) are forwarded to the root `<svg>` element, allowing full customization of size, accessibility attributes, and styles.

## Notes

- The icon image is embedded as a base64-encoded PNG (`data:image/png;base64,...`), so **no external asset request** is made at runtime.
- Default rendered size is **32×32 px**; override via `width`/`height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
