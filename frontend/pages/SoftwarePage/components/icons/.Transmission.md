A React SVG component that renders the Fleet MDM "Transmission" icon as a 32×32 PNG embedded inline via a base64-encoded `data:image/png` URI within an `<image>` element.

## Key Components

- **`Transmission`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG wrapper around an embedded PNG image.

## Usage Example

```typescript
import Transmission from "./Transmission";

// Basic usage
<Transmission />

// With custom className or style
<Transmission className="icon" style={{ opacity: 0.8 }} />

// Scaled via width/height override
<Transmission width={64} height={64} />
```

## Notes

- The icon image is self-contained — no external asset fetch required; the PNG data is baked into the component as a base64 string.
- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>` element, enabling full prop passthrough (e.g., `aria-label`, `role`, `onClick`, `className`).
