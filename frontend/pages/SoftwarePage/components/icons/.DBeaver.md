A React SVG icon component that renders the DBeaver database tool logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`DBeaver`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the DBeaver logo as an embedded PNG.

## Usage Example

```typescript
import DBeaver from "./DBeaver";

// Basic usage
<DBeaver />

// With custom dimensions or className
<DBeaver width={64} height={64} className="icon" />

// With style overrides
<DBeaver style={{ opacity: 0.8 }} />
```

## Notes

- The logo is embedded as a base64 PNG inside an SVG `<image>` element, so no external assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via spread to the root `<svg>` element.
- Default dimensions are `32×32`; override with `width`/`height` props as needed.
