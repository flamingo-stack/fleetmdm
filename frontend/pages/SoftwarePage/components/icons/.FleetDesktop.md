A React SVG component that renders the Fleet Desktop application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`FleetDesktop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Fleet Desktop logo as an embedded PNG.

## Usage Example

```typescript
import FleetDesktop from "./FleetDesktop";

// Basic usage
<FleetDesktop />

// With custom dimensions or className
<FleetDesktop width={64} height={64} className="app-icon" />

// With accessibility attributes
<FleetDesktop aria-label="Fleet Desktop" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
