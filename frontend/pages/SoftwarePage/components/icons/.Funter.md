A React SVG component that renders the Funter icon as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Funter`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import { Funter } from "./Funter";

// Basic usage
<Funter />

// With custom size and class
<Funter width={64} height={64} className="my-icon" />

// With style override
<Funter style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained — no external asset fetching required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override via `width`/`height` props.
