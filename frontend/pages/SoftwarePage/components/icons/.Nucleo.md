A React SVG component that renders the Nucleo icon as an embedded PNG image within an SVG wrapper.

## Key Components

- **`Nucleo`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a base64-encoded PNG via an `<image>` element.

## Usage Example

```typescript
import Nucleo from "./Nucleo";

// Basic usage
<Nucleo />

// With custom dimensions or className
<Nucleo width={64} height={64} className="icon" />

// With style overrides
<Nucleo style={{ opacity: 0.8 }} aria-label="Nucleo icon" />
```

## Notes

- The icon dimensions default to **32×32 pixels** but can be overridden via props.
- The image data is a self-contained base64 PNG, requiring no external assets or network requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
