A React SVG icon component that renders the Reqable logo as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Reqable`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Reqable brand icon at 32×32 pixels.

## Usage Example

```typescript
import Reqable from "./Reqable";

// Basic usage
<Reqable />

// With custom dimensions and className
<Reqable width={64} height={64} className="icon" />

// With accessibility attributes
<Reqable aria-label="Reqable" role="img" />
```

## Notes

- Props are spread onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The icon image is embedded as a base64 PNG — no external asset dependency.
