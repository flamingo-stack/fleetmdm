A React SVG icon component that renders the Bleunlock icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Bleunlock`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import Bleunlock from "./Bleunlock";

// Basic usage
<Bleunlock />

// With custom dimensions and className
<Bleunlock width={64} height={64} className="icon" />

// With style overrides
<Bleunlock style={{ opacity: 0.8 }} aria-label="Bleunlock icon" />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, allowing full customization of attributes such as `width`, `height`, `className`, `style`, and `aria-*`.
- The icon image is self-contained via a base64-encoded PNG — no external assets or network requests required.
- Default rendered size is **32×32px**.
