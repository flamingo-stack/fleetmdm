A React SVG component that renders the Super Productivity app icon as a 32×32 inline PNG embedded via base64 data URI.

## Key Components

- **`SuperProductivity`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper containing the icon as an embedded base64 PNG image.

## Usage Example

```typescript
import SuperProductivity from "./SuperProductivity";

// Basic usage
<SuperProductivity />

// With custom dimensions or className
<SuperProductivity width={64} height={64} className="app-icon" />

// With accessibility attributes
<SuperProductivity aria-label="Super Productivity" role="img" />
```

## Notes

- All `SVGProps` are spread onto the root `<svg>` element, enabling style, className, event handlers, and ARIA attributes.
- The icon image is a 512×512 source PNG encoded as a base64 data URI, downscaled to 32×32 by the SVG viewport.
- No external assets or network requests are required — the icon is fully self-contained.
