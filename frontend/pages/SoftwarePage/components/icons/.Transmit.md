React SVG icon component that renders the Transmit application logo as an inline PNG embedded within an SVG element.

## Key Components

- **`Transmit`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds a Base64-encoded PNG of the Transmit app icon.

## Usage Example

```typescript
import Transmit from "./Transmit";

// Basic usage
<Transmit />

// With custom dimensions or className
<Transmit width={64} height={64} className="app-icon" />

// With accessibility attributes
<Transmit aria-label="Transmit" role="img" />
```

## Notes

- The icon is a fixed **32×32px** SVG by default but accepts any valid SVG props for overrides.
- The image data is fully self-contained as a Base64 PNG — no external network requests required.
- Follows the same pattern as other icon components in this repository.
