SVG icon component for the Canva brand logo, rendered as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Canva`** — Default export; a React functional component that renders the Canva logo as a 32×32 SVG element
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.)
- Uses an embedded base64 PNG via an `<image>` tag rather than native SVG paths

## Usage Example

```typescript
import Canva from "./Canva";

// Basic usage
<Canva />

// With custom size and class
<Canva width={64} height={64} className="icon" />

// With click handler
<Canva onClick={() => console.log("Canva clicked")} />
```

## Notes

- Default dimensions are **32×32px**; override with `width`/`height` props
- The logo image is self-contained (no external network requests)
- Follows the same pattern as other brand icon components in the [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) icon library
