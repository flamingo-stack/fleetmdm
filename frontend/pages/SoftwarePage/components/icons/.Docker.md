React SVG component that renders the Docker logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Docker`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 Docker logo icon.

## Usage Example

```typescript
import Docker from "./Docker";

// Basic usage
<Docker />

// With custom dimensions and className
<Docker width={64} height={64} className="icon" />

// With style overrides
<Docker style={{ display: "block", margin: "auto" }} />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default; dimensions can be overridden via props.
- The image data is embedded as a base64 PNG, so no external asset dependencies are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
