React SVG icon component that renders the Remote Desktop Manager application icon as an inline PNG image embedded within an SVG wrapper.

## Key Components

- **`RemoteDesktopManager`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Remote Desktop Manager icon.

## Usage Example

```typescript
import RemoteDesktopManager from "./RemoteDesktopManager";

// Basic usage
<RemoteDesktopManager />

// With custom dimensions and className
<RemoteDesktopManager width={64} height={64} className="app-icon" />

// With accessibility attributes
<RemoteDesktopManager aria-label="Remote Desktop Manager" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default but can be resized via `width`/`height` props.
- The PNG image data is embedded as a **base64 data URI**, so no external assets are required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
