SVG icon component for the Microsoft .NET Runtime, rendered as a 32×32 PNG embedded via base64 data URI.

## Key Components

- **`MicrosoftDotnetRuntime`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders an `<svg>` element containing the .NET Runtime icon as an embedded base64 PNG image.

## Usage Example

```typescript
import MicrosoftDotnetRuntime from "./MicrosoftDotnetRuntime";

// Basic usage
<MicrosoftDotnetRuntime />

// With custom size and className
<MicrosoftDotnetRuntime width={64} height={64} className="icon" />

// With inline styles
<MicrosoftDotnetRuntime style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon asset is self-contained — no external image files or network requests required.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
