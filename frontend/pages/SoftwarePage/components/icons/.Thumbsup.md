A React SVG component that renders a thumbs-up emoji as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Thumbsup`** — Default export; a functional React component that wraps a 32×32 SVG element containing an embedded PNG image via a base64 `data:image/png` URI.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Thumbsup from "./Thumbsup";

// Basic usage
<Thumbsup />

// With custom size and class
<Thumbsup width={64} height={64} className="my-icon" />

// With click handler
<Thumbsup onClick={() => console.log("Thumbs up!")} />
```

## Notes

- The image data is fully self-contained — no external asset requests are made at runtime.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The component spreads all additional SVG props onto the root `<svg>` element, making it composable and style-friendly.
