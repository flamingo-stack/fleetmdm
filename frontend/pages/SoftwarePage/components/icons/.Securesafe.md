A React SVG icon component that renders the Securesafe brand logo as an inline PNG image embedded within an SVG wrapper.

## Key Components

- **`Securesafe`** — Default export. A functional React component that accepts all standard SVG element props via `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing the Securesafe logo as a base64-encoded PNG.

## Usage Example

```typescript
import Securesafe from "./Securesafe";

// Basic usage
<Securesafe />

// With custom dimensions or className
<Securesafe width={64} height={64} className="icon" />

// With inline styles
<Securesafe style={{ opacity: 0.8 }} />
```

## Notes

- Renders at **32×32 pixels** by default; dimensions can be overridden via props.
- The logo image is embedded as a **base64-encoded PNG** inside an SVG `<image>` element, meaning no external network request is required.
- Fully compatible with standard SVG prop overrides (e.g., `className`, `style`, `aria-label`).
