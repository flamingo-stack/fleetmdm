A React SVG component that renders the Firefly Iota desktop icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`FireflyIotaDesktop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute customization.

## Usage Example

```typescript
import FireflyIotaDesktop from "./FireflyIotaDesktop";

// Basic usage
<FireflyIotaDesktop />

// With custom props
<FireflyIotaDesktop className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- Fixed at **32×32px** by default; override via `width`/`height` props if needed.
- The PNG asset is inlined as a base64 `data:image/png` URI — no external image file dependency.
