SVG icon component that renders the DataGrip logo as an inline PNG image embedded via base64 within an SVG wrapper.

## Key Components

- **`DataGrip`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the DataGrip logo as an embedded base64 PNG image.

## Usage Example

```typescript
import DataGrip from './DataGrip';

// Basic usage
<DataGrip />

// With custom dimensions and className
<DataGrip width={64} height={64} className="icon" />

// With accessibility attributes
<DataGrip aria-label="DataGrip" role="img" />
```

## Notes

- Default size is **32×32** pixels; override via `width`/`height` props.
- The PNG image data is fully inlined as a base64 string — no external asset requests.
- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`) via spread.
