A React SVG component that renders a Dictionaries icon as a 32×32 SVG element embedding a base64-encoded PNG image.

## Key Components

- **`Dictionaries`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG with an embedded PNG via a base64-encoded `<image>` element.

## Usage Example

```typescript
import Dictionaries from "./Dictionaries";

// Basic usage
<Dictionaries />

// With custom dimensions or className
<Dictionaries width={64} height={64} className="icon" />

// With accessibility attributes
<Dictionaries aria-label="Dictionaries" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- The icon image is self-contained as a base64 PNG — no external asset dependencies.
