A React SVG component that renders the LuLu avatar/icon as an inline SVG element with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`LuLu`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image via a base64 `data:` URI.

## Usage Example

```typescript
import LuLu from "./LuLu";

// Basic usage
<LuLu />

// With custom dimensions or className
<LuLu width={64} height={64} className="avatar-icon" />

// With aria label for accessibility
<LuLu aria-label="LuLu avatar" role="img" />
```

## Notes

- The PNG image data is fully self-contained — no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default render size is **32×32px**; override with `width`/`height` props.
