React SVG wrapper component that renders the GitHub Copilot for Xcode application icon as a 32×32 PNG embedded inline via a base64-encoded `<image>` element.

## Key Components

- **`GithubCopilotForXcode`** — Default-exported functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).
- **Inline asset** — The icon is self-contained; no external image file or network request is required at runtime.

## Usage Example

```typescript
import GithubCopilotForXcode from "./GithubCopilotForXcode";

// Basic usage
<GithubCopilotForXcode />

// With custom size and class
<GithubCopilotForXcode width={64} height={64} className="icon" />

// Inside a button
<button aria-label="GitHub Copilot for Xcode">
  <GithubCopilotForXcode style={{ verticalAlign: "middle" }} />
</button>
```

## Notes

- Default dimensions are **32×32 px**; override via `width`/`height` props.
- The base64 PNG is a 512×512 source image downscaled by the SVG viewport — passing larger `width`/`height` values will not reduce quality.
