React SVG icon component that renders the SelfControl macOS application icon as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Selfcontrol`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the SelfControl app icon as an inlined PNG via a `data:image/png;base64` href.

## Usage Example

```typescript
import Selfcontrol from "./Selfcontrol";

// Basic usage
<Selfcontrol />

// With custom size or className
<Selfcontrol width={64} height={64} className="app-icon" />

// With accessibility attributes
<Selfcontrol aria-label="SelfControl" role="img" />
```

## Notes

- The icon is statically embedded as a base64 PNG — no external image requests are made.
- Default dimensions are `32×32` pixels but can be overridden via props.
- Fully compatible with any context accepting standard SVG props (e.g., styling, event handlers).
