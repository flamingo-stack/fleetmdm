A React SVG icon component that renders the Cinc logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Cinc`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the Cinc logo via an inline base64 PNG within an SVG wrapper.

## Usage Example

```typescript
import Cinc from "./Cinc";

// Basic usage
<Cinc />

// With custom dimensions or className
<Cinc width={64} height={64} className="icon" />

// With accessibility attributes
<Cinc aria-label="Cinc" role="img" />
```

## Notes

- The component spreads `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `className`, `style`, `aria-*`).
- The logo image is self-contained via a base64 data URI — no external asset files are required.
- Default rendered size is **32×32px**.
