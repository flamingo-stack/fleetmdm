A React SVG component that renders the Popclip application icon as a 32×32 SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Popclip`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a fixed 32×32 SVG containing the Popclip icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import Popclip from "./Popclip";

// Basic usage
<Popclip />

// With custom sizing and className
<Popclip width={64} height={64} className="app-icon" />

// With accessibility attributes
<Popclip aria-label="Popclip" role="img" />
```

## Notes

- The icon image data is self-contained — no external asset files are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
