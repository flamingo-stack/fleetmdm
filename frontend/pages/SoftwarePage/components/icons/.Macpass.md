A React SVG component that renders the MacPass application icon as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Macpass`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 `<svg>` element containing the MacPass app icon as an embedded PNG via a base64 `data:` URI.

## Usage Example

```typescript
import Macpass from "./Macpass";

// Basic usage
<Macpass />

// With custom dimensions and className
<Macpass width={64} height={64} className="app-icon" />

// With accessibility attributes
<Macpass aria-label="MacPass" role="img" />
```

## Notes

- The icon image is fully self-contained — no external image files or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via prop spreading.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
- The embedded PNG source is 512×512, so the icon scales cleanly to larger sizes without quality loss.
