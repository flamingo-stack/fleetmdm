A React SVG icon component that renders the MongoDB Compass logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`MongoDbCompass`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the MongoDB Compass icon as an embedded PNG.

## Usage Example

```typescript
import MongoDbCompass from './MongoDbCompass';

// Basic usage
<MongoDbCompass />

// With custom size and className
<MongoDbCompass width={64} height={64} className="icon" />

// With style overrides
<MongoDbCompass style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32** pixels, overridable via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external asset dependencies.
