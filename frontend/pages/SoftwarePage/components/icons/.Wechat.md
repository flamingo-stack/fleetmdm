SVG icon component that renders the WeChat logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Wechat`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the WeChat brand icon via an inline `<image>` element with a base64-encoded PNG `href`.

## Usage Example

```typescript
import Wechat from './Wechat';

// Basic usage
<Wechat />

// With custom dimensions or className
<Wechat width={64} height={64} className="icon" />

// With accessibility attributes
<Wechat aria-label="WeChat" role="img" />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is embedded as a base64 PNG, so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
