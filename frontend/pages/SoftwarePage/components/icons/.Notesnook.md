A React SVG component that renders the Notesnook application icon as a 32×32 inline PNG image embedded via base64 encoding.

## Key Components

- **`Notesnook`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded base64-encoded PNG icon.

## Usage Example

```typescript
import Notesnook from "./Notesnook";

// Basic usage
<Notesnook />

// With custom size or className
<Notesnook width={64} height={64} className="icon" />

// With accessibility attributes
<Notesnook aria-label="Notesnook" role="img" />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via props.
- The PNG image data is fully self-contained (base64-encoded), requiring no external asset requests.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
