React SVG component that renders the Surge brand logo as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Surge`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG containing a base64-encoded PNG of the Surge logo via an `<image>` element.

## Usage Example

```typescript
import Surge from './Surge';

// Basic usage
<Surge />

// With custom dimensions and className
<Surge width={64} height={64} className="logo-icon" />

// With accessibility attributes
<Surge aria-label="Surge" role="img" />
```

## Notes

- Props are spread onto the root `<svg>` element, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The logo image is self-contained as a base64 PNG — no external assets or network requests required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
