A React SVG component that renders the SwiftBar application icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Swiftbar`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering the SwiftBar logo via an embedded base64 PNG within an `<svg>` element.

## Usage Example

```typescript
import Swiftbar from "./Swiftbar";

// Basic usage
<Swiftbar />

// With custom dimensions or className
<Swiftbar width={64} height={64} className="app-icon" />

// With accessibility attributes
<Swiftbar aria-label="SwiftBar" role="img" />
```

## Notes

- The icon is self-contained — no external image assets required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
