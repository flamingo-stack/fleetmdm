A React SVG component that renders the Alcove brand icon as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Alcove`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG image via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Alcove from "./Alcove";

// Basic usage
<Alcove />

// With custom dimensions or className
<Alcove width={64} height={64} className="icon" />

// With accessibility attributes
<Alcove aria-label="Alcove" role="img" />
```

## Notes

- The PNG data is fully self-contained via base64 encoding — no external image fetch required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component flexible for use in toolbars, navigation, or icon libraries.
- The source image metadata indicates an original resolution of 512×512 pixels, downscaled to 32×32 in the rendered SVG.
