A React SVG component that renders the MySQL Workbench logo as an inline PNG image (32×32px) encoded in base64.

## Key Components

- **`MySqlWorkbench`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper containing a base64-encoded PNG of the MySQL Workbench icon.

## Usage Example

```typescript
import MySqlWorkbench from "./MySqlWorkbench";

// Basic usage
<MySqlWorkbench />

// With custom dimensions or className
<MySqlWorkbench width={64} height={64} className="my-icon" />

// With accessible label
<MySqlWorkbench aria-label="MySQL Workbench" role="img" />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, allowing full customization (size, style, className, event handlers, etc.).
- The icon image is self-contained via a base64 data URI — no external asset fetch required.
- Default rendered size is **32×32px**.
