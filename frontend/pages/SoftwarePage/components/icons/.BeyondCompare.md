React SVG wrapper component that renders the Beyond Compare application icon as an inline PNG image embedded via base64 data URI within an SVG container.

## Key Components

- **`BeyondCompare`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 PNG icon of the Beyond Compare diff tool inside an `<svg>` element.

## Usage Example

```typescript
import BeyondCompare from "./BeyondCompare";

// Basic usage
<BeyondCompare />

// With custom dimensions and className
<BeyondCompare width={64} height={64} className="app-icon" />

// With accessibility attributes
<BeyondCompare
  role="img"
  aria-label="Beyond Compare"
  width={32}
  height={32}
/>
```

## Notes

- All standard SVG props (`width`, `height`, `className`, `style`, `onClick`, etc.) are forwarded directly to the root `<svg>` element via spread.
- The icon image is self-contained — no external asset or network request required.
- Default rendered size is **32×32 px** (defined on the inner `<image>` element); override via props if needed.
