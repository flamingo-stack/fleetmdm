React SVG component that renders a 32×32 MarkText logo/icon using an embedded base64-encoded PNG image.

## Key Components

- **`MarkText`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` and renders a fixed 32×32 SVG containing an inline base64 PNG image

## Usage Example

```typescript
import MarkText from "./MarkText";

// Basic usage
<MarkText />

// With custom className or style
<MarkText className="logo-icon" style={{ opacity: 0.8 }} />

// With custom dimensions via SVG props
<MarkText width={64} height={64} />
```

## Notes

- The icon image is self-contained — no external image assets required
- All `SVGProps<SVGSVGElement>` are forwarded (e.g., `className`, `style`, `onClick`, `aria-*`)
- Default rendered size is `32×32` pixels; override via `width`/`height` props
