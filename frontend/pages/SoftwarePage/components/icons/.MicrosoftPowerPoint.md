React SVG component that renders the Microsoft PowerPoint application icon as a 32×32 inline PNG image encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`MicrosoftPowerPoint`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering the PowerPoint logo as a fixed 32×32 SVG.

## Usage Example

```typescript
import MicrosoftPowerPoint from "./MicrosoftPowerPoint";

// Basic usage
<MicrosoftPowerPoint />

// With custom dimensions or className
<MicrosoftPowerPoint width={64} height={64} className="app-icon" />

// With accessibility attributes
<MicrosoftPowerPoint aria-label="Microsoft PowerPoint" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG inside an SVG `<image>` element — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread, making the component fully customizable without modification.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
