React SVG icon component that renders the WinSCP application logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Winscp`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the WinSCP logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Winscp from './Winscp';

// Basic usage
<Winscp />

// With custom dimensions and className
<Winscp width={64} height={64} className="icon" />

// With accessibility attributes
<Winscp aria-label="WinSCP" role="img" />
```

## Notes

- Fixed default dimensions of **32×32 pixels**; override via `width`/`height` props.
- The PNG image data is fully self-contained — no external image assets required.
- All `SVGProps` (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element via spread.
