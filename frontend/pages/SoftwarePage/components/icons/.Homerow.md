React SVG icon component that renders the Homerow app logo as an inline PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Homerow`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the Homerow logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Homerow from "./Homerow";

// Basic usage
<Homerow />

// With custom dimensions or className
<Homerow width={64} height={64} className="icon" />

// With accessibility attributes
<Homerow aria-label="Homerow" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` props onto the root `<svg>` element, allowing full customization (size, style, className, event handlers, etc.).
- The logo image is self-contained — no external image assets are required at runtime.
- Default rendered size is **32×32 pixels**; the embedded PNG source is **512×512 pixels**, so the component scales cleanly to larger sizes.
