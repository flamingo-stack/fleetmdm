React SVG component that renders the Gemini AI logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Gemini`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Gemini from "./Gemini";

// Basic usage
<Gemini />

// With custom size and className
<Gemini width={64} height={64} className="icon" />

// With accessibility attributes
<Gemini aria-label="Gemini AI" role="img" />
```

## Notes

- The logo image is fully self-contained via a base64-encoded PNG — no external asset dependencies.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- Supports all standard SVG props (e.g., `className`, `style`, `onClick`) through prop spreading.
