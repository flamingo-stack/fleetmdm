A React SVG component that renders the Framer logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Framer` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG wrapping a base64 PNG of the Framer logo |

## Usage Example

```typescript
import Framer from './Framer';

// Basic usage
<Framer />

// With custom dimensions or className
<Framer width={64} height={64} className="icon" />

// With accessibility attributes
<Framer aria-label="Framer" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (size, color overrides, event handlers, etc.)
- The icon image is self-contained via a base64-encoded PNG — no external asset requests at runtime
- Default size is `32×32` pixels; override with `width`/`height` props as needed
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Framer.tsx)
