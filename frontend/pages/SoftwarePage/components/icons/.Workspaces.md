A React SVG component that renders the Workspaces icon as an inline SVG element embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Workspaces`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element.

## Usage Example

```typescript
import Workspaces from "./Workspaces";

// Basic usage
<Workspaces />

// With custom dimensions and className
<Workspaces width={64} height={64} className="icon" />

// With accessibility attributes
<Workspaces aria-label="Workspaces" role="img" />
```

## Notes

- The image content is a 32×32 PNG embedded as a base64 `data:` URI via an SVG `<image>` element.
- All valid `SVGProps<SVGSVGElement>` attributes (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` tag.
