A React SVG icon component that renders the BambuStudio logo as a 32×32 inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`BambuStudio`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import BambuStudio from "./BambuStudio";

// Basic usage
<BambuStudio />

// With custom size and className
<BambuStudio width={64} height={64} className="icon" />

// With inline style
<BambuStudio style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via `width`/`height` props.
- The PNG image data is embedded as a base64 string, so no external asset requests are made.
