A React SVG component that renders a 32×32 Syntax Highlight icon using an embedded base64-encoded PNG image.

## Key Components

- **`SyntaxHighlight`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering an `<svg>` wrapper with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import SyntaxHighlight from "./SyntaxHighlight";

// Basic usage
<SyntaxHighlight />

// With custom size and class
<SyntaxHighlight width={64} height={64} className="icon" />

// With accessibility attributes
<SyntaxHighlight aria-label="Syntax Highlight" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props are spread onto the root `<svg>` element, allowing full customization of dimensions, styling, and accessibility attributes.
- The icon is hardcoded as a 32×32 base64 PNG; scaling beyond native size may result in visual degradation.
