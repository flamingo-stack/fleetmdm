React SVG component that renders the HP Easy Admin application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`HpEasyAdmin`** — Default-exported functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG icon via a `<image>` element with a base64 `href` data URI.

## Usage Example

```typescript
import HpEasyAdmin from "./HpEasyAdmin";

// Basic usage
<HpEasyAdmin />

// With custom dimensions and className
<HpEasyAdmin width={64} height={64} className="app-icon" />

// With accessibility attributes
<HpEasyAdmin aria-label="HP Easy Admin" role="img" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external network requests are made.
- Default render size is **32×32px**; the embedded PNG is encoded at **512×512px** for high-DPI display contexts.
