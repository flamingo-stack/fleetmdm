A React SVG component that renders a Platypus icon as an embedded PNG image within an SVG wrapper at 32×32 pixels.

## Key Components

- **`Platypus`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG image of a platypus icon.

## Usage Example

```typescript
import { Platypus } from "./Platypus";

// Basic usage
<Platypus />

// With custom dimensions and className
<Platypus width={64} height={64} className="my-icon" />

// With style overrides
<Platypus style={{ opacity: 0.8 }} aria-label="Platypus icon" />
```

## Notes

- The component passes all SVG props through to the root `<svg>` element, enabling full customization of dimensions, styles, and accessibility attributes.
- The icon image is self-contained as a base64-encoded PNG — no external asset dependencies.
- Default render size is **32×32px**; override via `width` / `height` props.
