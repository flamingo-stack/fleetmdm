A React SVG component that renders the RemoteBuddy icon as a 32×32 PNG embedded inline via a base64-encoded data URI.

## Key Components

- **`RemoteBuddy`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG image asset.

## Usage Example

```typescript
import RemoteBuddy from "./RemoteBuddy";

// Basic usage
<RemoteBuddy />

// With custom size and className
<RemoteBuddy width={64} height={64} className="icon" />

// With style overrides
<RemoteBuddy style={{ opacity: 0.8 }} />
```

## Notes

- The icon asset is self-contained — no external image files or network requests required.
- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default dimensions are **32×32px**; override via `width`/`height` props.
