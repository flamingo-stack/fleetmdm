React SVG component that renders the Godot Engine logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Godot`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Godot logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import Godot from "./Godot";

// Basic usage
<Godot />

// With custom size and className
<Godot width={64} height={64} className="my-icon" />

// With style overrides
<Godot style={{ opacity: 0.8 }} aria-label="Godot Engine" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded directly to the root `<svg>` element via spread (`{...props}`).
- The logo is self-contained — no external image assets or network requests are required.
- Default rendered size is `32×32` pixels; override by passing `width` and `height` props.
