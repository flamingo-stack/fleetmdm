A React SVG wrapper component that renders the BomeNetwork cryptocurrency/blockchain network logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`BomeNetwork`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders an SVG element containing the BomeNetwork logo as an embedded base64 PNG image.

## Usage Example

```typescript
import BomeNetwork from './BomeNetwork';

// Basic usage
<BomeNetwork />

// With custom dimensions and className
<BomeNetwork width={64} height={64} className="icon" />

// With style overrides
<BomeNetwork style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image data is embedded as a **base64 PNG**, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Part of an icon library pattern — likely alongside other cryptocurrency/network logo components in the same directory.
