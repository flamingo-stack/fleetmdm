A React SVG component that renders a Crossover device/platform icon as an inline SVG containing an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Crossover`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props
- Renders a 32×32 SVG wrapper with an embedded base64 PNG via an `<image>` element
- All SVG attributes (e.g., `className`, `style`, `onClick`) can be passed through via props spreading

## Usage Example

```typescript
import Crossover from "./Crossover";

// Basic usage
<Crossover />

// With custom dimensions and styling
<Crossover width={64} height={64} className="device-icon" />

// With event handler
<Crossover onClick={() => console.log("Crossover selected")} />
```

## Notes

- The PNG image is baked in as a base64 data URI — no external asset file is required
- Default rendered size is **32×32 px**; override via `width`/`height` props
- Part of the device-type icon set used in the Fleet MDM UI to identify Crossover device platforms
