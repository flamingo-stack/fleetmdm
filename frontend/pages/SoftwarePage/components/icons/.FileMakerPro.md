A React SVG component that renders the FileMaker Pro application icon as an inline PNG image embedded via base64 encoding.

## Key Components

- **`FileMakerPro`** — Default export. A functional React component that renders a 32×32 SVG element containing the FileMaker Pro logo as an embedded base64-encoded PNG image.

## Usage Example

```typescript
import FileMakerPro from "./FileMakerPro";

// Basic usage
<FileMakerPro />

// With custom dimensions or class
<FileMakerPro width={64} height={64} className="app-icon" />

// With style overrides
<FileMakerPro style={{ opacity: 0.8 }} />
```

All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via prop spreading.
