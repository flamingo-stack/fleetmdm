React SVG icon component that renders the DataSpell IDE logo as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Dataspell`** — A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the DataSpell logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Dataspell from './icons/Dataspell';

// Basic usage
<Dataspell />

// With custom dimensions and className
<Dataspell width={64} height={64} className="icon" />

// With inline styles
<Dataspell style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The logo is self-contained — no external image dependencies at runtime.
