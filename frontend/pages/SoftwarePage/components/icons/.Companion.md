A React SVG component that renders the Companion icon as a 32×32 pixel image with an embedded base64-encoded PNG.

## Key Components

- **`Companion`** — Default export. A functional React component that renders an `<svg>` element containing a base64-encoded PNG image representing the Companion icon.

## Usage Example

```typescript
import Companion from "./Companion";

// Basic usage
<Companion />

// With custom sizing or className
<Companion width={64} height={64} className="my-icon" />

// With accessibility attributes
<Companion aria-label="Companion" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/src/components/icons/Companion.tsx) props, allowing full customization of SVG attributes (e.g., `className`, `style`, `onClick`).
- Default dimensions are `32×32`; override via `width`/`height` props.
- The icon image is self-contained — no external asset dependencies.
