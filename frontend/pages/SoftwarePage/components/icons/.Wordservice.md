React SVG component that renders a Microsoft Word service icon as an inline SVG with an embedded base64-encoded PNG image.

## Key Components

- **`Wordservice`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper around an embedded PNG icon via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Wordservice from "./Wordservice";

// Basic usage
<Wordservice />

// With custom dimensions or className
<Wordservice width={64} height={64} className="service-icon" />

// With accessibility attributes
<Wordservice aria-label="Microsoft Word" role="img" />
```

## Notes

- The icon is self-contained — no external image requests are made at runtime.
- All standard SVG props (e.g., `onClick`, `style`, `className`) are forwarded via `{...props}`.
- The base icon is rendered at **32×32px** by default; override via `width`/`height` props as needed.
- The embedded PNG is 512×512px (per EXIF metadata), scaled down to 32×32 for display.
