A React SVG icon component that renders the Ollama logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Ollama`** — Default export. A functional React component that renders a 32×32 SVG containing the Ollama logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Ollama from './Ollama';

// Basic usage
<Ollama />

// With custom size and className
<Ollama width={64} height={64} className="icon" />

// With style overrides
<Ollama style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`), which are spread onto the root `<svg>` element.
- Default dimensions are `32×32` pixels.
- The logo image is embedded as a base64-encoded PNG, so no external asset loading is required.
