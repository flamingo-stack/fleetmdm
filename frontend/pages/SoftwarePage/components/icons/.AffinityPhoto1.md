React SVG component that renders the Affinity Photo 1 application icon as a 32×32 embedded PNG image.

## Key Components

- **`AffinityPhoto1`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering an `<svg>` wrapper with an embedded base64-encoded PNG of the Affinity Photo 1 icon.

## Usage Example

```typescript
import AffinityPhoto1 from "./AffinityPhoto1";

// Basic usage
<AffinityPhoto1 />

// With custom dimensions and className
<AffinityPhoto1 width={64} height={64} className="app-icon" />

// With accessibility attributes
<AffinityPhoto1 aria-label="Affinity Photo 1" role="img" />
```

## Notes

- The icon is hardcoded at **32×32 pixels** by default but can be overridden via `width`/`height` props.
- The PNG image data is embedded as a **base64 data URI**, so no external image file is required.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
