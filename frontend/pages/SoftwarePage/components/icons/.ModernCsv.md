SVG React component that renders a CSV file type icon using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`ModernCsv`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper with an embedded PNG via a `<image>` element using a base64 `href`.

## Usage Example

```typescript
import ModernCsv from "./ModernCsv";

// Basic usage
<ModernCsv />

// With custom size and className
<ModernCsv width={64} height={64} className="file-icon" />

// With accessibility attributes
<ModernCsv aria-label="CSV file" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded to the root `<svg>` element via spread props.
- The icon image is self-contained — no external assets or network requests are required.
- Default render size is **32×32px**; override via `width`/`height` props.
