A React SVG icon component that renders the Sharefile logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Sharefile`** — Default export. A functional React component that renders a 32×32 SVG element containing the Sharefile brand icon as an embedded PNG (base64).

## Usage Example

```typescript
import Sharefile from "./Sharefile";

// Basic usage
<Sharefile />

// With custom dimensions and styling
<Sharefile width={64} height={64} className="icon" />

// With accessibility attributes
<Sharefile aria-label="Sharefile" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/common) props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-*`).
- The icon image is embedded as a base64 PNG, so no external asset files are required.
- Default rendered size is **32×32 pixels**.
