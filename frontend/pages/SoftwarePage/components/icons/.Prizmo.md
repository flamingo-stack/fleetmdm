A React SVG component that renders the Prizmo brand icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Prizmo`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64 PNG image of the Prizmo logo.

## Usage Example

```typescript
import { Prizmo } from "./Prizmo";

// Basic usage
<Prizmo />

// With custom dimensions
<Prizmo width={64} height={64} />

// With className or style overrides
<Prizmo className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is fully self-contained — no external asset files or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded via spread to the root `<svg>` element.
- Default size is `32×32`; override with `width`/`height` props as needed.
