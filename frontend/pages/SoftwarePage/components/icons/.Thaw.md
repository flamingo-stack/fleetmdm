A React SVG component that renders a "Thaw" icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Thaw`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG icon

## Usage Example

```typescript
import { Thaw } from './Thaw';

// Basic usage
<Thaw />

// With custom dimensions and styling
<Thaw width={64} height={64} className="icon" />

// With click handler
<Thaw onClick={() => handleThaw()} style={{ cursor: 'pointer' }} />
```

## Notes

- The component accepts all standard SVG props (`className`, `style`, `onClick`, etc.) via spread
- The icon is a 32×32 PNG (originally 512×512, downscaled) embedded as a base64 data URI — no external asset fetch required
- Useful for bundlers that cannot handle static image imports in certain SSR or sandboxed environments
