React SVG component that renders a 32×32 "Fluid" icon by embedding a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Fluid`** — Default export; a functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a fixed 32×32 SVG containing an embedded PNG via a base64 `data:image/png` URI.

## Usage Example

```typescript
import { Fluid } from "./Fluid";

// Basic usage
<Fluid />

// With custom className or style
<Fluid className="icon" style={{ opacity: 0.8 }} />

// With ARIA attributes for accessibility
<Fluid aria-label="Fluid icon" role="img" />
```

## Notes

- The component spreads `...props` onto the `<svg>` element, allowing full customization of SVG attributes (e.g., `className`, `style`, `onClick`, `aria-*`).
- The icon dimensions are fixed at `32×32` pixels by default; override via `width`/`height` props if needed.
- The embedded image is a 512×512 PNG downscaled to 32×32 within the SVG, so scaling up may reduce visual fidelity.
