A React SVG component that renders the AirParrot application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Airparrot`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element that embeds the AirParrot app icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Airparrot from "./Airparrot";

// Basic usage
<Airparrot />

// With custom dimensions or className
<Airparrot width={64} height={64} className="app-icon" />

// With click handler
<Airparrot onClick={() => console.log("AirParrot clicked")} />
```

## Notes

- The icon is self-contained — no external image file required; the PNG data is embedded directly as a base64 data URI.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Default render size is **32×32 pixels**.
