A React SVG component that renders the NetNewsWire application icon as a 32×32 inline PNG embedded within an SVG wrapper.

## Key Components

- **`Netnewswire`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering the NetNewsWire logo as a base64-encoded PNG image inside an `<svg>` element.

## Usage Example

```typescript
import Netnewswire from "./Netnewswire";

// Basic usage
<Netnewswire />

// With custom dimensions or className
<Netnewswire width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Netnewswire aria-label="NetNewsWire" role="img" />
```

## Notes

- The icon is statically embedded as a base64 PNG — no external network requests are made.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
