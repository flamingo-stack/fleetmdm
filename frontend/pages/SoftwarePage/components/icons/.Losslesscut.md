A React SVG component that renders the LosslessCut application icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

- **`Losslesscut`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the LosslessCut logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Losslesscut from "./Losslesscut";

// Basic usage
<Losslesscut />

// With custom dimensions or className
<Losslesscut width={64} height={64} className="app-icon" />

// With aria label for accessibility
<Losslesscut aria-label="LosslessCut" role="img" />
```

## Notes

- The icon PNG is embedded directly as a base64 data URI, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `width`, `height`) are forwarded to the root `<svg>` element via spread.
