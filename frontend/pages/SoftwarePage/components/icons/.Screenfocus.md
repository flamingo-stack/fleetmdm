A React SVG component that renders the Screenfocus application icon as a 32×32 inline SVG embedding a base64-encoded PNG image.

## Key Components

- **`Screenfocus`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Screenfocus icon via an embedded base64 PNG inside an `<svg>` element.

## Usage Example

```typescript
import Screenfocus from "./Screenfocus";

// Basic usage
<Screenfocus />

// With custom dimensions or className
<Screenfocus width={64} height={64} className="icon" />

// With style overrides
<Screenfocus style={{ opacity: 0.8 }} aria-label="Screenfocus" />
```

## Notes

- The icon is fixed at **32×32** by default but can be overridden via props.
- The image data is embedded as a base64-encoded PNG, so no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
