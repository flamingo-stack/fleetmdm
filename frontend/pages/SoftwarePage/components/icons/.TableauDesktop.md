React SVG icon component that renders the Tableau Desktop application logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`TableauDesktop`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a fixed 32×32 SVG wrapper containing an inline base64 PNG of the Tableau Desktop icon.

## Usage Example

```typescript
import TableauDesktop from "./TableauDesktop";

// Basic usage
<TableauDesktop />

// With custom className or style
<TableauDesktop className="icon" style={{ opacity: 0.8 }} />

// With ARIA label for accessibility
<TableauDesktop aria-label="Tableau Desktop" role="img" />
```

## Notes

- The icon dimensions are fixed at **32×32px** by default but can be overridden via `width`/`height` props passed through `SVGProps`.
- The image is self-contained — no external assets or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
