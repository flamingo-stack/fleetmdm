A React component that renders the Mural logo as an SVG element with an embedded base64-encoded PNG image.

## Key Components

- **`Mural`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Mural logo as an embedded PNG.

## Usage Example

```typescript
import Mural from "@/components/icons/Mural";

// Basic usage
<Mural />

// With custom dimensions and className
<Mural width={64} height={64} className="logo-icon" />

// With style overrides
<Mural style={{ opacity: 0.8 }} aria-label="Mural" />
```

## Notes

- The logo image is self-contained via a base64-encoded PNG (`data:image/png;base64,...`), requiring no external assets.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**.
