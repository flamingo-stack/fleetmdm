React SVG icon component that renders the Stellarium application logo as a 32×32 inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Stellarium`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that contains an embedded PNG image via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import Stellarium from './Stellarium';

// Basic usage
<Stellarium />

// With custom dimensions or className
<Stellarium width={64} height={64} className="app-icon" />

// With accessibility attributes
<Stellarium aria-label="Stellarium" role="img" />
```

## Notes

- The icon image is self-contained — no external network requests are made; the PNG is inlined as a base64 data URI.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
