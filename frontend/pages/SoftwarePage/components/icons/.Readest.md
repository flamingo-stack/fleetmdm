A React SVG component that renders the Readest application icon as an inline SVG containing an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Readest` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component for the Readest integration |

## Usage Example

```typescript
import Readest from "./Readest";

// Basic usage
<Readest />

// With custom dimensions or className
<Readest width={64} height={64} className="icon" />

// With style overrides
<Readest style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of SVG attributes (e.g., `width`, `height`, `className`, `style`, `onClick`).
- The icon is self-contained — the PNG pixel data is embedded as a base64 `data:image/png` URI inside an SVG `<image>` element, requiring no external asset files.
- Default rendered size is **32×32 pixels**; the source PNG is 512×512 (downscaled via SVG).
