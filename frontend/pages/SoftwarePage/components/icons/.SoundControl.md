SVG icon component that renders a sound control icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`SoundControl`** — Default export. A React functional component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing an embedded PNG image via a base64 data URI.

## Usage Example

```typescript
import SoundControl from "./SoundControl";

// Basic usage
<SoundControl />

// With custom sizing and className
<SoundControl width={64} height={64} className="icon" />

// With event handlers
<SoundControl onClick={() => toggleMute()} style={{ cursor: "pointer" }} />
```

## Notes

- Renders at **32×32px** by default; override via `width`/`height` props.
- The icon image is a **512×512 PNG** embedded as a base64 data URI and scaled down to the SVG viewport — no external asset fetch required.
- All standard `SVGProps` (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element.
- Suitable for use in media player controls, audio toggle buttons, or volume UI within the Flamingo/OpenFrame interface.
