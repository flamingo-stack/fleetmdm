A React SVG component that renders the DYMO Connect application icon as an inline SVG wrapping a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`DymoConnect`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the DYMO Connect logo as a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import DymoConnect from "./DymoConnect";

// Basic usage
<DymoConnect />

// With custom size and class
<DymoConnect width={64} height={64} className="app-icon" />

// With click handler
<DymoConnect onClick={() => handleConnect()} style={{ cursor: "pointer" }} />
```

## Notes

- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- The icon is self-contained — no external image assets are required.
- Default dimensions are `32×32`; override via `width`/`height` props.
- Typically used in integration lists, connection status badges, or device management UIs where DYMO label printer connectivity is surfaced.
