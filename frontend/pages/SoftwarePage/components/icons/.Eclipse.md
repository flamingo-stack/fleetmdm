A React SVG component that renders the Eclipse IDE logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Eclipse`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Eclipse logo icon.

## Usage Example

```typescript
import Eclipse from "./Eclipse";

// Basic usage
<Eclipse />

// With custom dimensions and className
<Eclipse width={64} height={64} className="icon" />

// With style overrides
<Eclipse style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32** by default but dimensions can be overridden via props.
- The image data is a self-contained base64 PNG — no external assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
