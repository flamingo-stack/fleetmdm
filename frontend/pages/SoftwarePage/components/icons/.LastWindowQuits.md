A React SVG component that renders a 32×32 "Last Window Quits" icon using an embedded base64-encoded PNG image.

## Key Components

- **`LastWindowQuits`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- The icon is rendered via an `<image>` element with a hardcoded base64 PNG `href`, sized at 32×32 pixels.

## Usage Example

```typescript
import LastWindowQuits from "./LastWindowQuits";

// Basic usage
<LastWindowQuits />

// With custom size or className
<LastWindowQuits width={64} height={64} className="my-icon" />

// With accessibility attributes
<LastWindowQuits aria-label="Last Window Quits" role="img" />
```

## Notes

- All SVG props (e.g., `width`, `height`, `className`, `style`, `onClick`) are spread onto the root `<svg>` element, though the internal `<image>` dimensions remain fixed at 32×32.
- The embedded PNG data is self-contained — no external assets are required.
