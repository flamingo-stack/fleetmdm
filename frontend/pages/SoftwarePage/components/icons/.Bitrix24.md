A React SVG icon component that renders the Bitrix24 logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Bitrix24`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` wrapper containing an `<image>` element with a base64-encoded PNG logo.

## Usage Example

```typescript
import Bitrix24 from "./Bitrix24";

// Basic usage
<Bitrix24 />

// With custom dimensions or className
<Bitrix24 width={64} height={64} className="integration-icon" />

// With onClick handler
<Bitrix24 onClick={() => console.log("Bitrix24 selected")} />
```

## Notes

- Accepts all standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) via `SVGProps<SVGSVGElement>`.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The logo is self-contained — no external image assets or network requests required.
- Part of the integration icon set in the Flamingo/OpenFrame platform.
