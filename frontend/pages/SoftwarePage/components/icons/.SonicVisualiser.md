A React SVG component that renders the Sonic Visualiser application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`SonicVisualiser`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import SonicVisualiser from "./SonicVisualiser";

// Basic usage
<SonicVisualiser />

// With custom dimensions or className
<SonicVisualiser width={64} height={64} className="app-icon" />

// With accessibility attributes
<SonicVisualiser role="img" aria-label="Sonic Visualiser" />
```

## Notes

- The icon is self-contained — no external image assets are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**.
