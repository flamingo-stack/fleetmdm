A React SVG icon component that renders the RubyMine IDE logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`RubyMine`** — Default export. A functional React component that renders a 32×32 SVG element containing the RubyMine logo as an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import RubyMine from "./RubyMine";

// Basic usage
<RubyMine />

// With custom dimensions or className
<RubyMine width={64} height={64} className="icon" />

// With accessibility attributes
<RubyMine aria-label="RubyMine IDE" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The icon image is self-contained — no external assets or network requests are required.
- Default render size is **32×32 pixels**.
