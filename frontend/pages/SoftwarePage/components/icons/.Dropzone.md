A React SVG component that renders the Dropzone logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Dropzone`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a 32×32 SVG with the Dropzone brand icon embedded as a base64 PNG.

## Usage Example

```typescript
import Dropzone from "./Dropzone";

// Basic usage
<Dropzone />

// With custom dimensions and className
<Dropzone width={64} height={64} className="icon" />

// With style overrides
<Dropzone style={{ opacity: 0.8 }} aria-label="Dropzone" />
```

## Notes

- All standard SVG props (e.g., `width`, `height`, `className`, `style`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon is a 32×32 PNG (originally 512×512) embedded as a base64 data URI — no external asset fetch required.
