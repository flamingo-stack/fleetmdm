SVG icon component that renders the Proton Pass logo as a 32×32 image using an embedded base64-encoded PNG.

## Key Components

- **`ProtonPass`** — Default exported React functional component that renders an SVG wrapper containing an embedded PNG image of the Proton Pass logo
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (e.g., `className`, `style`, `onClick`)

## Usage Example

```typescript
import ProtonPass from "./ProtonPass";

// Basic usage
<ProtonPass />

// With custom sizing or className
<ProtonPass width={64} height={64} className="icon" />

// With click handler
<ProtonPass onClick={() => console.log("Proton Pass clicked")} />
```

## Notes

- Default dimensions are **32×32** pixels
- The PNG image data is inlined as a base64 `data:image/png` URI within the SVG `<image>` element, so no external asset request is made
