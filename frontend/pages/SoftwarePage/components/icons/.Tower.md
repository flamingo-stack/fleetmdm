A React SVG component that renders a Tower icon as an inline Base64-encoded PNG image (32×32).

## Key Components

- **`Tower`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a `<image>` element with a Base64 `href`.

## Usage Example

```typescript
import Tower from "./Tower";

// Basic usage
<Tower />

// With custom dimensions and className
<Tower width={64} height={64} className="icon" />

// With aria attributes for accessibility
<Tower aria-label="Tower" role="img" />
```

## Notes

- The image data is fully self-contained (no external network requests).
- All `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The internal `<image>` is fixed at 32×32; scaling beyond that may reduce fidelity since the source is a raster PNG.
