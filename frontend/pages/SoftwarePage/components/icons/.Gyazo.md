React SVG component that renders the Gyazo logo as an inline SVG image using a base64-encoded PNG data URI at 32×32 pixels.

## Key Components

- **`Gyazo`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG element containing the Gyazo brand logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Gyazo from "./Gyazo";

// Basic usage
<Gyazo />

// With custom dimensions or class
<Gyazo width={64} height={64} className="brand-icon" />

// With accessibility attributes
<Gyazo aria-label="Gyazo" role="img" />
```

## Notes

- The logo is embedded as a base64 PNG `data:` URI within an SVG `<image>` element, meaning no external network request is made to render the icon.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- Default render size is `32×32` but can be overridden via `width`/`height` props.
