A React SVG component that renders the Electrum cryptocurrency wallet logo as a 32×32 icon using an embedded base64 PNG image.

## Key Components

- **`Electrum`** — Default export; a functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) that renders a 32×32 SVG wrapper containing the Electrum logo as an embedded PNG via a base64-encoded `href`.

## Usage Example

```typescript
import Electrum from "./Electrum";

// Basic usage
<Electrum />

// With custom dimensions and className
<Electrum width={64} height={64} className="icon" />

// With accessibility attributes
<Electrum aria-label="Electrum wallet" role="img" />
```

## Notes

- The logo image is entirely self-contained — no external network requests are made at render time.
- Width and height default to `32` but can be overridden via props.
- All standard `SVGProps<SVGSVGElement>` attributes (e.g., `className`, `style`, `onClick`) are spread onto the root `<svg>` element.
