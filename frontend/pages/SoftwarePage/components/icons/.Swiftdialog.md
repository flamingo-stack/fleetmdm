React SVG icon component that renders the SwiftDialog application logo as an inline PNG image embedded within an SVG wrapper.

## Key Components

- **`Swiftdialog`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the SwiftDialog app icon as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Swiftdialog from "./Swiftdialog";

// Basic usage
<Swiftdialog />

// With custom dimensions or className
<Swiftdialog width={64} height={64} className="app-icon" />

// Inside a button or nav item
<button>
  <Swiftdialog aria-label="SwiftDialog" />
  Open Dialog
</button>
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component fully composable.
- The icon is self-contained — no external image assets or network requests are required at runtime.
- Default render size is **32×32 pixels**; override via `width`/`height` props.
