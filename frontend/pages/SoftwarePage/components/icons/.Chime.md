A React SVG icon component that renders the Chime logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Chime`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered as an `<svg>` wrapper containing an `<image>` element with the Chime logo encoded as a base64 PNG.

## Usage Example

```typescript
import Chime from './Chime';

// Basic usage
<Chime />

// With custom size and className
<Chime width={64} height={64} className="my-icon" />

// With accessibility attributes
<Chime aria-label="Chime" role="img" />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The logo image is self-contained (no external network requests) as a base64-encoded PNG.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
