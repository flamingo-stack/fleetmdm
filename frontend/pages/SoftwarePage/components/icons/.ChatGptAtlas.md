React SVG icon component that renders the ChatGPT Atlas logo as an inline PNG image encoded in base64, embedded within an SVG wrapper.

## Key Components

- **`ChatGptAtlas`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered at 32×32 pixels with an embedded base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import ChatGptAtlas from "./ChatGptAtlas";

// Basic usage
<ChatGptAtlas />

// With custom dimensions and className
<ChatGptAtlas width={64} height={64} className="icon" />

// With accessibility attributes
<ChatGptAtlas aria-label="ChatGPT Atlas" role="img" />
```

## Notes

- The icon is **self-contained** — no external image dependencies or network requests.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- Default size is **32×32px**; override with `width`/`height` props.
