React SVG icon component that renders the RustRover IDE logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`RustRover`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the RustRover logo as an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import RustRover from "./RustRover";

// Basic usage
<RustRover />

// With custom dimensions and className
<RustRover width={64} height={64} className="ide-icon" />

// With style overrides
<RustRover style={{ opacity: 0.8 }} aria-label="RustRover IDE" />
```

## Notes

- Renders at **32×32px** by default; dimensions can be overridden via props.
- The logo image is embedded as a **base64 PNG** data URI — no external network requests required.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- Stateless and side-effect free; safe for SSR environments.
