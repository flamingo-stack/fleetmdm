A React SVG component that renders the Markedit logo as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Markedit`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props and rendering the Markedit icon via an embedded base64 PNG.

## Usage Example

```typescript
import Markedit from "./Markedit";

// Basic usage
<Markedit />

// With custom dimensions or className
<Markedit width={64} height={64} className="my-icon" />

// With accessibility attributes
<Markedit aria-label="Markedit" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- The icon is fixed as a 32×32 PNG embedded via a `data:image/png;base64` URI inside an SVG `<image>` element. Overriding `width`/`height` via props changes the SVG viewport but not the internal image element dimensions.
