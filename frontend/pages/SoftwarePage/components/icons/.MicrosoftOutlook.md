React SVG component that renders the Microsoft Outlook brand icon as an inline PNG image (base64-encoded) within an SVG wrapper.

## Key Components

- **`MicrosoftOutlook`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Outlook logo via an `<image>` element.

## Usage Example

```typescript
import MicrosoftOutlook from "./MicrosoftOutlook";

// Basic usage
<MicrosoftOutlook />

// With custom dimensions or className
<MicrosoftOutlook width={64} height={64} className="icon" />

// With inline styles
<MicrosoftOutlook style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is self-contained — no external network request is made at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
