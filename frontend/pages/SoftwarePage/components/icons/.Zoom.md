Renders the Zoom brand logo as an SVG React component with a blue linear gradient background and the Zoom "Z-o-o-m" wordmark in light grey.

## Key Components

- **`Zoom`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded directly to the underlying `<svg>` element.
- **`linearGradientId`** — A `lodash.uniqueId`-generated ID scoped to each render instance, preventing gradient `id` collisions when multiple `Zoom` icons appear on the same page.

## Usage Example

```typescript
import Zoom from "./Zoom";

// Basic usage
<Zoom width={32} height={32} />

// Custom size with accessibility label
<Zoom
  width={48}
  height={48}
  role="img"
  aria-label="Zoom"
/>

// Inline with className
<Zoom width={24} height={24} className="integration-icon" />
```

## Notes

- The component renders at a **32×32** viewport by default; override via `width`/`height` props.
- The gradient runs diagonally from `#3A8FEA` (top-right) to `#0042BC` (bottom-left), matching Zoom's brand palette.
- Safe for **multi-instance** use — each render generates a unique gradient `id` via `uniqueId`, avoiding SVG `<defs>` conflicts in the DOM.
