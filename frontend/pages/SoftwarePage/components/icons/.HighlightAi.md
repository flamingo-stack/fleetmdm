A React SVG component that renders the Highlight AI brand logo as an inline SVG element using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`HighlightAi`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import HighlightAi from "./HighlightAi";

// Basic usage
<HighlightAi />

// With custom size and className
<HighlightAi width={64} height={64} className="icon" />

// With click handler
<HighlightAi onClick={() => console.log("clicked")} />
```

## Notes

- The image is self-contained via a base64-encoded PNG — no external asset fetch required.
- Default dimensions are `32×32`; override via `width`/`height` props.
