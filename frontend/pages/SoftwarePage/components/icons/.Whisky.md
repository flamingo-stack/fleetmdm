A React SVG component that renders a whisky emoji/icon as an inline SVG element using an embedded base64-encoded PNG image.

## Key Components

- **`Whisky`** — Default export; a functional React component that renders a 32×32 SVG containing a base64-encoded PNG of a whisky icon
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-*`)

## Usage Example

```typescript
import Whisky from "./Whisky";

// Basic usage
<Whisky />

// With custom size and class
<Whisky width={64} height={64} className="icon" />

// With event handler
<Whisky onClick={() => console.log("clicked")} aria-label="Whisky icon" />
```

## Notes

- The icon is rendered at **32×32px** by default but can be overridden via props
- The image data is a **base64-encoded PNG** embedded directly in the SVG, so no external asset fetching is required
- This component follows the same pattern as other icon components in the codebase and can be used interchangeably with other SVG icon components
