A React SVG icon component rendering a 3D box/package illustration with orange and yellow tones, representing an "Extension" concept.

## Key Components

- **`Extension`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 package/box icon with a clip path.
- **`clipPathId`** — A `uniqueId`-generated ID (via lodash) ensuring multiple instances of the icon on the same page don't share conflicting `clipPath` references.

## Usage Example

```typescript
import Extension from "./Extension";

// Basic usage
<Extension />

// With custom dimensions and className
<Extension width={24} height={24} className="icon-extension" />

// With inline style
<Extension style={{ color: "currentColor" }} width={16} height={16} />
```

## Notes

- The component forwards all `SVGProps` to the root `<svg>` element, making it fully customizable (size, className, style, aria attributes, etc.).
- The icon uses a fixed internal color palette (amber `#F1C40F`, orange `#E67E22`, dark orange `#F39C12`, dark brown stroke `#693202`) and does **not** respond to `currentColor` or CSS color overrides.
