A React SVG component that renders the LingonX icon as a 32×32 inline SVG, embedding a PNG image via a base64-encoded data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `LingonX` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component with a base64-embedded PNG |

## Usage Example

```typescript
import LingonX from "./LingonX";

// Basic usage
<LingonX />

// With custom size and className
<LingonX width={64} height={64} className="icon" />

// With accessibility attributes
<LingonX aria-label="LingonX icon" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `onClick`)
- Default render size is **32×32 pixels**; the embedded PNG source is **512×512 pixels**, so the component scales cleanly
- The icon is self-contained — no external image fetch required; the full PNG is embedded as a base64 data URI inside the `<image>` element
- Spread props (`{...props}`) are applied to the root `<svg>` element, allowing full customization at the call site
