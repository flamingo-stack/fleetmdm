React SVG icon component that renders the GitKraken logo as an inline PNG embedded via a base64-encoded `<image>` element within an SVG wrapper.

## Key Components

- **`GitKraken`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the GitKraken brand icon as a base64-encoded PNG image.

## Usage Example

```typescript
import GitKraken from "./GitKraken";

// Basic usage
<GitKraken />

// With custom dimensions and class
<GitKraken width={64} height={64} className="icon" />

// With style overrides
<GitKraken style={{ opacity: 0.8 }} />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The PNG data is inlined as a base64 `data:image/png` URI — no external asset fetch required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element via spread.
- Suitable for use in icon libraries, navigation bars, or integration badges within the [flamingo-stack/fleetmdm](https://github.com/flamingo-stack/fleetmdm) UI.
