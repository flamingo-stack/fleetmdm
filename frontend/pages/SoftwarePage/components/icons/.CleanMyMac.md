A React SVG component that renders the CleanMyMac application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`CleanMyMac`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.
- **Embedded image** — The icon is rendered via an `<image>` tag with a base64-encoded PNG `href`, producing a 32×32 pixel graphic without any external asset dependencies.

## Usage Example

```typescript
import CleanMyMac from "./CleanMyMac";

// Basic usage
<CleanMyMac />

// With custom dimensions or class
<CleanMyMac width={64} height={64} className="app-icon" />

// With accessibility attributes
<CleanMyMac aria-label="CleanMyMac" role="img" />
```

## Notes

- All `SVGProps<SVGSVGElement>` are spread onto the root `<svg>`, allowing full customisation (e.g. `className`, `style`, `onClick`, ARIA attributes).
- Default dimensions are **32×32 px**; override with `width`/`height` props.
- The icon is fully self-contained — no external image files or CDN dependencies.
