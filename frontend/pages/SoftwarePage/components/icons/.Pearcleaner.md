React SVG icon component that renders the Pearcleaner application logo as a 32×32 PNG embedded via base64 within an SVG element.

## Key Components

- **`Pearcleaner`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Pearcleaner from "./Pearcleaner";

// Basic usage
<Pearcleaner />

// With custom size and class
<Pearcleaner width={64} height={64} className="app-icon" />

// With inline style override
<Pearcleaner style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are `32×32` pixels; override via `width`/`height` props.
- The icon image is self-contained — no external asset fetch required.
- Follows the same prop interface as all other SVG icon components in this codebase.
