React SVG icon component that renders the GDevelop logo as a 32×32 PNG image embedded via a base64 data URI.

## Key Components

- **`Gdevelop`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 `<svg>` element that contains a base64-encoded PNG of the GDevelop logo via an `<image>` tag.

## Usage Example

```typescript
import Gdevelop from "./Gdevelop";

// Basic usage
<Gdevelop />

// With custom dimensions or className
<Gdevelop width={64} height={64} className="icon" />

// With accessibility attributes
<Gdevelop aria-label="GDevelop" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The icon image is fully self-contained — no external network request is made.
- Default rendered size is **32×32 px**; override with `width`/`height` props as needed.
