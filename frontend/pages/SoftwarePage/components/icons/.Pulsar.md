A React SVG icon component that renders the Pulsar logo as an inline SVG element with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Pulsar`** — Default export. A functional React component that renders an `<svg>` wrapper (32×32) containing the Pulsar logo as a base64-encoded PNG via an `<image>` element.
- **`SVGProps<SVGSVGElement>`** — Accepts all standard SVG props, allowing callers to override `width`, `height`, `className`, `style`, and other SVG attributes.

## Usage Example

```typescript
import Pulsar from "./Pulsar";

// Basic usage
<Pulsar />

// Custom size and class
<Pulsar width={64} height={64} className="my-icon" />

// With inline style
<Pulsar style={{ opacity: 0.8 }} />
```

## Notes

- The logo image is fully self-contained — no external image file or network request required.
- Default dimensions are `32×32` px but can be overridden via props.
