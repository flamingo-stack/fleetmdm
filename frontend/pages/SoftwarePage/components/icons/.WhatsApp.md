SVG icon component that renders the WhatsApp logo with its characteristic green background and white chat bubble design.

## Key Components

- **`WhatsApp`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 WhatsApp icon.

## Usage Example

```typescript
import WhatsApp from "@/components/icons/WhatsApp";

// Basic usage
<WhatsApp />

// Custom size
<WhatsApp width={24} height={24} />

// With className
<WhatsApp className="icon" aria-label="WhatsApp" />
```

## Notes

- Dimensions default to the internal `viewBox` of `32×32`; override via `width`/`height` props.
- Colors are hardcoded (`#1BD741` green background, `#fff` paths) and not overridable via `fill` prop due to inline `fill` attributes on child elements.
- Spread of `SVGProps` allows passing `className`, `style`, `aria-*`, and other standard SVG attributes.
