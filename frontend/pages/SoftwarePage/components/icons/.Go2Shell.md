SVG icon component that renders the Go2Shell macOS application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Go2Shell`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Go2Shell app icon as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Go2Shell from "./Go2Shell";

// Basic usage
<Go2Shell />

// With custom dimensions or className
<Go2Shell width={64} height={64} className="app-icon" />

// With accessibility attributes
<Go2Shell aria-label="Go2Shell" role="img" />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`).
- Default rendered size is **32×32 pixels**; override with `width`/`height` props.
- The embedded PNG is 512×512 internally (per EXIF metadata), downscaled to 32×32 by the SVG viewport.
