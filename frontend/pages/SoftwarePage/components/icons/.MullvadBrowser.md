A React SVG component that renders the Mullvad Browser application icon as an inline SVG embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`MullvadBrowser`** — Default exported functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG with an embedded base64 PNG via an `<image>` element.

## Usage Example

```typescript
import MullvadBrowser from "./MullvadBrowser";

// Basic usage
<MullvadBrowser />

// With custom size or className
<MullvadBrowser width={64} height={64} className="app-icon" />

// With accessibility attributes
<MullvadBrowser aria-label="Mullvad Browser" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon graphic is self-contained — no external image fetch is required.
- Default dimensions are `32×32`; override via `width`/`height` props.
