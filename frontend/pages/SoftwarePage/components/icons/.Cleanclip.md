A React SVG component that renders the Cleanclip application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Cleanclip`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing a base64-encoded PNG of the Cleanclip app icon.

## Usage Example

```typescript
import Cleanclip from "./Cleanclip";

// Basic usage
<Cleanclip />

// With custom dimensions or className
<Cleanclip width={64} height={64} className="app-icon" />

// With accessibility attributes
<Cleanclip aria-label="Cleanclip" role="img" />
```

## Notes

- The icon image data is fully self-contained as a base64 PNG — no external image assets required.
- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
