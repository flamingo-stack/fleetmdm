React SVG component that renders the Museeks music player application icon as an inline SVG with an embedded base64-encoded PNG image (32×32px).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Museeks` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component for the Museeks music player |

## Usage Example

```typescript
import Museeks from "./Museeks";

// Basic usage
<Museeks />

// With custom dimensions
<Museeks width={64} height={64} />

// With className or style overrides
<Museeks className="app-icon" style={{ opacity: 0.8 }} />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the outer `<svg>` element
- The icon itself is a fixed 32×32 PNG (512×512 source, downscaled) embedded as a base64 data URI inside an `<image>` element — visual output is not affected by SVG styling applied to child elements
- Spread props (`{...props}`) are applied to the `<svg>` wrapper, so `width`/`height` overrides work as expected
