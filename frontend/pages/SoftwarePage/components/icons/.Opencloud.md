A React SVG icon component that renders the Opencloud logo as a 32×32 pixel image embedded via a base64-encoded PNG data URI.

## Key Components

- **`Opencloud`** — Default export. A functional React component that renders an SVG wrapper containing an embedded PNG image of the Opencloud logo.

## Usage Example

```typescript
import Opencloud from "./Opencloud";

// Basic usage
<Opencloud />

// With custom dimensions or className
<Opencloud width={64} height={64} className="icon" />

// With accessibility attributes
<Opencloud aria-label="Opencloud" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://github.com/flamingo-stack/fleetmdm/blob/main/path/to/Opencloud.tsx) props, enabling full customization (e.g., `width`, `height`, `className`, `style`).
- The icon is fixed at 32×32 by default; override via props if needed.
- The PNG payload is inlined as a base64 data URI — no external asset dependency.
