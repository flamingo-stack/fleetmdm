SVG icon component for the 8x8 Work application, rendering a 32×32 pixel PNG logo embedded as a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`EightXEightWork`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute pass-through (className, style, onClick, aria-*, etc.)
- **Embedded asset** — The 8x8 Work logo is inlined as a base64 PNG (`data:image/png;base64,...`) inside an SVG `<image>` element, eliminating external asset dependencies
- **Fixed dimensions** — Renders at 32×32px by default; can be overridden via props

## Usage Example

```typescript
import EightXEightWork from "./8X8Work";

// Basic usage
<EightXEightWork />

// With custom size and class
<EightXEightWork width={64} height={64} className="integration-icon" />

// With accessibility attributes
<EightXEightWork
  aria-label="8x8 Work"
  role="img"
  style={{ display: "block" }}
/>
```

## Notes

- The component is typically used in integration listings, app selectors, or connector catalogues within the [FleetMDM](https://github.com/flamingo-stack/fleetmdm) UI
- Because the PNG is base64-inlined, no separate image file or CDN request is needed — the icon renders immediately without network dependency
- Pass any valid `SVGProps` to control rendering; `width` and `height` default to `32` but are overridable
