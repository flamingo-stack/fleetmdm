React SVG icon component that renders the DBeaver Ultimate logo as a base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`DBeaverUltimate`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the DBeaver Ultimate icon as an embedded base64 PNG.

## Usage Example

```typescript
import DBeaverUltimate from "./DBeaverUltimate";

// Basic usage
<DBeaverUltimate />

// With custom dimensions and className
<DBeaverUltimate width={64} height={64} className="icon" />

// With inline styles
<DBeaverUltimate style={{ opacity: 0.8 }} />
```

## Notes

- Default rendered size is **32×32** pixels; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external network requests are made.
