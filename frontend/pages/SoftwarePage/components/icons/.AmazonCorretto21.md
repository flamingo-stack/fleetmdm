React SVG icon component that renders the Amazon Corretto 21 logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AmazonCorretto21` | `React.FC<SVGProps<SVGSVGElement>>` | Default SVG wrapper component accepting standard SVG props |

## Usage Example

```typescript
import AmazonCorretto21 from './AmazonCorretto21';

// Basic usage
<AmazonCorretto21 />

// With custom dimensions or className
<AmazonCorretto21 width={64} height={64} className="icon" />

// With style overrides
<AmazonCorretto21 style={{ opacity: 0.8 }} aria-label="Amazon Corretto 21" />
```

## Notes

- Renders a fixed 32×32 SVG element by default; override via `width`/`height` props.
- The logo image is embedded as a base64-encoded PNG `<image>` element — no external asset fetch required.
- All standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element.
