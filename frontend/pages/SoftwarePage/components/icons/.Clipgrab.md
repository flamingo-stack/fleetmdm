A React SVG component that renders the ClipGrab application icon as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`Clipgrab`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the ClipGrab app icon as an embedded PNG image

## Usage Example

```typescript
import Clipgrab from "./Clipgrab";

// Basic usage
<Clipgrab />

// With custom size or className
<Clipgrab width={64} height={64} className="app-icon" />

// With accessibility attributes
<Clipgrab aria-label="ClipGrab" role="img" />
```

## Notes

- The icon is rendered at a default size of **32×32 pixels** but can be overridden via `width`/`height` props
- The PNG image data is embedded as a base64 `data:image/png` string — no external asset fetch required
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread
