React SVG icon component that renders the Shapr3D application logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Shapr3D`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing a base64-encoded PNG of the Shapr3D logo.

## Usage Example

```typescript
import Shapr3D from "./Shapr3D";

// Basic usage
<Shapr3D />

// With custom dimensions and class
<Shapr3D width={64} height={64} className="app-icon" />

// With style override
<Shapr3D style={{ opacity: 0.8 }} aria-label="Shapr3D" />
```

## Notes

- Default size is **32×32px**; override via `width`/`height` props.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element.
- The image is self-contained — no external network request is made at render time.
