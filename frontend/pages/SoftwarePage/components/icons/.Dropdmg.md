A React SVG component that renders the DropDMG application icon as an embedded base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Dropdmg`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the DropDMG icon as an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import Dropdmg from "./Dropdmg";

// Basic usage
<Dropdmg />

// With custom dimensions or className
<Dropdmg width={64} height={64} className="app-icon" />

// With accessibility attributes
<Dropdmg aria-label="DropDMG" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default; dimensions can be overridden via props.
- The image data is a **base64-encoded PNG** (originally 512×512px per EXIF metadata), embedded directly — no external asset dependency.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- Intended for use in Fleet MDM UI contexts where DropDMG appears as a managed application icon.
