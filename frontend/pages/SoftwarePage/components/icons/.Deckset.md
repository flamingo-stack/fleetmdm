A React SVG component that renders the Deckset application icon as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Deckset`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper with an embedded base64 PNG icon via an `<image>` element.

## Usage Example

```typescript
import Deckset from "./Deckset";

// Basic usage
<Deckset />

// With custom dimensions or className
<Deckset width={64} height={64} className="app-icon" />

// With accessibility attributes
<Deckset aria-label="Deckset" role="img" />
```

## Notes

- The icon image is self-contained — no external network requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via the spread `{...props}`.
