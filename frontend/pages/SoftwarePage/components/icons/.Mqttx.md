A React SVG icon component that renders the MQTTX logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Mqttx`** — Default export. A functional React component that renders a 32×32 SVG containing the MQTTX application icon as an embedded base64 PNG.

## Usage Example

```typescript
import Mqttx from "./Mqttx";

// Basic usage
<Mqttx />

// With custom size and className
<Mqttx width={64} height={64} className="icon" />

// With ARIA label for accessibility
<Mqttx aria-label="MQTTX" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`, `aria-*`).
- Default dimensions are **32×32** pixels. Override via `width`/`height` props.
- The icon image is self-contained — no external assets or network requests required.
