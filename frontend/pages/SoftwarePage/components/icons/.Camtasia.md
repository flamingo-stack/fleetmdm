React SVG icon component that renders the Camtasia logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`Camtasia`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` for full SVG attribute passthrough (e.g., `className`, `style`, `onClick`).
- Renders a 32×32 SVG containing an `<image>` element with the Camtasia logo as an inline base64 PNG data URI.

## Usage Example

```typescript
import Camtasia from "./Camtasia";

// Basic usage
<Camtasia />

// With custom size and class
<Camtasia width={64} height={64} className="icon" />

// With event handler
<Camtasia onClick={() => console.log("clicked")} />
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- The logo is self-contained — no external image dependencies.
- Follows the same SVG icon pattern used across the icon library in this repository.
