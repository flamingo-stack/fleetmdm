A React SVG component that renders the SQLPro for MSSQL application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`SqlproForMssql`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering the SQLPro for MSSQL icon at 32×32 pixels.

## Usage Example

```typescript
import SqlproForMssql from "./SqlproForMssql";

// Basic usage
<SqlproForMssql />

// With custom size and className
<SqlproForMssql width={64} height={64} className="app-icon" />

// With accessibility attributes
<SqlproForMssql aria-label="SQLPro for MSSQL" role="img" />
```

## Notes

- The icon image is embedded as a base64-encoded PNG inside an SVG `<image>` element, making it fully self-contained with no external asset dependencies.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
