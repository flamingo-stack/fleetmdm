A React SVG component that renders a 32×32 Monitor Control icon by embedding a base64-encoded PNG image within an `<svg>` element.

## Key Components

- **`Monitorcontrol`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import Monitorcontrol from "./Monitorcontrol";

// Basic usage
<Monitorcontrol />

// With custom dimensions or className
<Monitorcontrol width={64} height={64} className="icon" />

// With accessibility attributes
<Monitorcontrol aria-label="Monitor Control" role="img" />
```

## Notes

- The icon is rendered as a fixed 32×32 SVG by default; width/height can be overridden via props.
- The image content is a base64-encoded PNG embedded directly in the component, requiring no external asset files.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are supported via prop spreading.
