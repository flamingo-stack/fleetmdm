React SVG icon component that renders a PCoIP Client application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Pcoipclient`** — Default export. A functional React component that wraps a base64 PNG inside an `<svg>` element, accepting all standard SVG props via `SVGProps<SVGSVGElement>`.

## Usage Example

```typescript
import Pcoipclient from "./Pcoipclient";

// Basic usage
<Pcoipclient />

// With custom props
<Pcoipclient className="icon" aria-label="PCoIP Client" style={{ opacity: 0.8 }} />
```

## Notes

- The icon is fixed at **32×32px** by default but can be overridden via `width`/`height` props.
- The image is self-contained — no external asset files are required.
- Located at: [`https://github.com/flamingo-stack/fleetmdm/blob/main/Pcoipclient.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/Pcoipclient.tsx)
