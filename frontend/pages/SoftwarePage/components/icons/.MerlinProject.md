A React SVG component that renders the Merlin Project logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`MerlinProject`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around an embedded PNG via a `<image>` element with a base64 `href`.

## Usage Example

```typescript
import MerlinProject from "./MerlinProject";

// Basic usage
<MerlinProject />

// With custom props (size, class, style, etc.)
<MerlinProject width={64} height={64} className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The image data is fully self-contained (base64-encoded PNG), requiring no external asset fetches.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
