React SVG component that renders the Shortcat application icon as an inline PNG image embedded via a base64-encoded data URI within an SVG wrapper.

## Key Components

- **`Shortcat`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props and rendering a 32×32 SVG containing a base64-encoded PNG icon.

## Usage Example

```typescript
import Shortcat from "./Shortcat";

// Basic usage
<Shortcat />

// With custom dimensions or className
<Shortcat width={64} height={64} className="app-icon" />

// With style overrides
<Shortcat style={{ opacity: 0.8 }} />
```

## Notes

- The component renders at **32×32 pixels** by default but accepts all standard SVG props for customization.
- The icon image is embedded as a **base64 PNG data URI**, meaning no external asset request is made at runtime.
- All `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-label`) are spread onto the root `<svg>` element.
