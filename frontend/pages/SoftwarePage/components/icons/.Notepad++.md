SVG icon component that renders the Notepad++ application logo as an inline PNG image embedded in an SVG wrapper.

## Key Components

- **`Notepad`** — Default export. A React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Notepad++ logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Notepad from "./Notepad++";

// Basic usage
<Notepad />

// With custom size or className
<Notepad width={64} height={64} className="app-icon" />

// With accessibility attributes
<Notepad aria-label="Notepad++" role="img" />
```

## Notes

- The icon is **32×32 pixels** by default but can be overridden via `width`/`height` props inherited from `SVGProps`.
- The PNG data is embedded as a base64 `data:image/png` URI, so no external image file is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via the spread `{...props}`.
