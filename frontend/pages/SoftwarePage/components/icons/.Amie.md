React SVG icon component that renders the Amie app logo as an inline PNG image (32×32) embedded via a base64 data URI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Amie` | `React.FC<SVGProps<SVGSVGElement>>` | Default export; renders a 32×32 SVG containing the Amie logo as a base64-encoded PNG `<image>` element |

## Usage Example

```typescript
import Amie from './Amie';

// Basic usage
<Amie />

// With custom dimensions or className
<Amie width={64} height={64} className="icon" />

// With accessibility attributes
<Amie aria-label="Amie" role="img" />
```

## Notes

- Accepts all standard [`SVGProps<SVGSVGElement>`](https://react.dev/reference/react-dom/components/svg) props (e.g., `className`, `style`, `onClick`, `aria-*`).
- The logo image is embedded as a base64 PNG data URI — no external network request is made.
- Default rendered size is **32×32 px**; override via `width`/`height` props.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/Amie.tsx)
