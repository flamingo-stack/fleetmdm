A React SVG icon component that renders the Hubstaff logo as a 32×32 inline PNG image embedded via a base64 data URI.

## Key Components

- **`Hubstaff`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Hubstaff brand logo as an embedded PNG.

## Usage Example

```typescript
import Hubstaff from "./Hubstaff";

// Basic usage
<Hubstaff />

// With custom dimensions or className
<Hubstaff width={64} height={64} className="integration-icon" />

// With accessibility attributes
<Hubstaff aria-label="Hubstaff" role="img" />
```

## Notes

- The logo image is self-contained — no external network request is made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32 pixels**; override with `width`/`height` props as needed.
