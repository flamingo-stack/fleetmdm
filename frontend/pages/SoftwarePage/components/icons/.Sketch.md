React SVG wrapper component that renders the Sketch application logo as an inline base64-encoded PNG image within an SVG element.

## Key Components

- **`Sketch`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Sketch logo as an embedded base64 PNG `<image>`.

## Usage Example

```typescript
import Sketch from "./Sketch";

// Basic usage
<Sketch />

// With custom dimensions and className
<Sketch width={64} height={64} className="icon" />

// With click handler and accessibility attributes
<Sketch
  aria-label="Sketch"
  role="img"
  onClick={() => console.log("clicked")}
/>
```

## Notes

- The image data is statically embedded as a base64-encoded PNG — no external asset fetch required.
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element via spread.
