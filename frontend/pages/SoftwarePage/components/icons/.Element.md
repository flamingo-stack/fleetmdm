A React SVG component that renders a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Element`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a fixed-size `32×32` SVG with an inline base64 PNG `<image>` element.

## Usage Example

```typescript
import Element from "./Element";

// Basic usage
<Element />

// With custom className or style overrides
<Element className="my-icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Element aria-label="Element icon" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- The image data is fully self-contained — no external asset requests are made.
- Default dimensions are `width={32}` and `height={32}`; these can be overridden via props.
