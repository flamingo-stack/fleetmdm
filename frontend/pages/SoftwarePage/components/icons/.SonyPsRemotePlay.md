A React SVG component that renders the Sony PS Remote Play application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`SonyPsRemotePlay`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, forwarded to the wrapping `<svg>` element.

## Usage Example

```typescript
import SonyPsRemotePlay from "./SonyPsRemotePlay";

// Basic usage
<SonyPsRemotePlay />

// With custom dimensions and class
<SonyPsRemotePlay width={64} height={64} className="app-icon" />

// With accessibility label
<SonyPsRemotePlay aria-label="Sony PS Remote Play" role="img" />
```

## Notes

- The icon renders as a fixed 32×32 SVG by default; dimensions can be overridden via props.
- The PNG image data is embedded as a base64 `data:image/png` URI, so no external asset fetch is required.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are supported via prop spreading.
