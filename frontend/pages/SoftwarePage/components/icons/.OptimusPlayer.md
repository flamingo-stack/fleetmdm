A React SVG component that renders the Optimus Player icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`OptimusPlayer`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendered as a 32×32 SVG wrapping a base64 PNG via an `<image>` element.

## Usage Example

```typescript
import OptimusPlayer from "./OptimusPlayer";

// Basic usage
<OptimusPlayer />

// With custom dimensions or className
<OptimusPlayer width={64} height={64} className="icon" />

// With style overrides
<OptimusPlayer style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon image is fully self-contained — no external asset dependencies at runtime.
- Default rendered size is **32×32 px**; the embedded PNG is 512×512 px, so scaling up via props will not degrade quality significantly.
