React SVG icon component that renders the Zotero logo as an inline PNG image embedded via base64 data URI within an SVG container.

## Key Components

- **`Zotero`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Zotero logo as a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Zotero from "./Zotero";

// Basic usage
<Zotero />

// With custom size via SVG props
<Zotero width={64} height={64} />

// With className or style
<Zotero className="icon" style={{ opacity: 0.8 }} />
```

## Notes

- The component is 32×32 pixels by default but can be resized via `width`/`height` props.
- The logo image is entirely self-contained — no external network requests are made.
- All standard SVG attributes (`aria-label`, `role`, `onClick`, etc.) are forwarded via prop spreading.
