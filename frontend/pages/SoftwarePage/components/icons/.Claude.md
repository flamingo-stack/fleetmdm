React SVG icon component that renders the Claude AI logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Claude`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendered at 32×32 pixels with an embedded base64 PNG image.

## Usage Example

```typescript
import Claude from "./Claude";

// Basic usage
<Claude />

// With custom size and className
<Claude width={64} height={64} className="my-icon" />

// With style overrides
<Claude style={{ opacity: 0.8 }} aria-label="Claude AI" />
```

## Notes

- The PNG data is inlined as a base64 `href` on an `<image>` element, so no external asset fetch is needed.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via the spread `{...props}`.
- Default dimensions are `32×32`; override with `width`/`height` props as needed.
