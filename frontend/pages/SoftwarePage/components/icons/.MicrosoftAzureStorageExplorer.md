A React SVG icon component that renders the Microsoft Azure Storage Explorer logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`MicrosoftAzureStorageExplorer`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization support.

## Usage Example

```typescript
import MicrosoftAzureStorageExplorer from "./MicrosoftAzureStorageExplorer";

// Basic usage
<MicrosoftAzureStorageExplorer />

// With custom size and className
<MicrosoftAzureStorageExplorer width={64} height={64} className="icon" />

// With style overrides
<MicrosoftAzureStorageExplorer style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
- The icon image is self-contained via a base64-encoded PNG — no external asset dependencies.
- Fully compatible with standard SVG prop APIs (e.g., `aria-label`, `role`, `style`, `className`).
