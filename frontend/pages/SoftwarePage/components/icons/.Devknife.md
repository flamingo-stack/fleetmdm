A React SVG icon component that renders the Devknife logo as an inline SVG element embedding a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Devknife`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Devknife from "./Devknife";

// Basic usage
<Devknife />

// With custom sizing and className
<Devknife width={64} height={64} className="icon" />

// With click handler
<Devknife onClick={() => console.log("clicked")} />
```

## Notes

- The image is embedded as a base64-encoded PNG, so no external assets are required.
- Default dimensions are `32×32` pixels but can be overridden via `width`/`height` props.
