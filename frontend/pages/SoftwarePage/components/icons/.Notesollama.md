A React SVG icon component that renders the Ollama logo as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Notesollama`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a fixed 32×32 SVG wrapper around an embedded Ollama PNG icon.

## Usage Example

```typescript
import Notesollama from "./Notesollama";

// Basic usage
<Notesollama />

// With custom className or style props
<Notesollama className="icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Notesollama aria-label="Ollama" role="img" />
```

## Notes

- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is statically embedded as a base64 PNG — no external asset fetch required.
- Fixed dimensions of `32×32`; override via `width`/`height` props if needed.
