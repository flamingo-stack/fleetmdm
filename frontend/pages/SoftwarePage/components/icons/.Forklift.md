A React SVG component that renders a 32×32 forklift icon using an embedded base64-encoded PNG image.

## Key Components

- **`Forklift`** — Default exported functional component that accepts all standard `SVGProps<SVGSVGElement>` props, allowing full SVG attribute customization (e.g., `className`, `style`, `onClick`).

The component renders an `<svg>` wrapper with a fixed `32×32` viewport containing an `<image>` element with an inlined base64 PNG, ensuring the icon is self-contained with no external asset dependencies.

## Usage Example

```typescript
import Forklift from "./Forklift";

// Basic usage
<Forklift />

// With custom styling
<Forklift className="icon" style={{ opacity: 0.8 }} />

// With click handler and custom size override
<Forklift onClick={() => console.log("clicked")} width={64} height={64} />
```

## Notes

- The icon dimensions default to `32×32` pixels but can be overridden via props.
- The PNG is embedded as a base64 data URI, so no external file or network request is needed at runtime.
- All standard SVG props are forwarded via the spread `{...props}` pattern, making this compatible with icon libraries and design systems.
