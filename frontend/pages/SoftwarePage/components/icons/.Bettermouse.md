A React SVG component that renders a 32×32 Bettermouse icon using an embedded base64-encoded PNG image.

## Key Components

- **`Bettermouse`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded directly to the root `<svg>` element.
- **Embedded image** — Renders a 32×32 PNG (originally 512×512) inline via a base64 `data:image/png` URI, avoiding any external asset dependency.

## Usage Example

```typescript
import Bettermouse from "./Bettermouse";

// Basic usage
<Bettermouse />

// With custom dimensions or className
<Bettermouse width={64} height={64} className="icon" />

// With accessibility attributes
<Bettermouse aria-label="Bettermouse" role="img" />
```

## Notes

- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are supported via spread.
- The default rendered size is **32×32 pixels**; override with `width`/`height` props.
- No external image assets are required — the PNG is fully self-contained in the component.
