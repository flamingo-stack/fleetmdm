A React SVG component that renders the Amazon Corretto 24 logo as a 32×32 pixel icon using an embedded base64-encoded PNG image.

## Key Components

- **`AmazonCorretto24`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64-encoded PNG of the Amazon Corretto logo.

## Usage Example

```typescript
import AmazonCorretto24 from "./AmazonCorretto24";

// Basic usage
<AmazonCorretto24 />

// With custom dimensions or className
<AmazonCorretto24 width={64} height={64} className="icon" />

// With accessibility attributes
<AmazonCorretto24 aria-label="Amazon Corretto 24" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, enabling full customization (e.g., `className`, `style`, `onClick`).
- The logo image is embedded as a base64 PNG, so no external asset files or network requests are required.
- Default rendered size is `32×32` pixels but can be overridden via props.
