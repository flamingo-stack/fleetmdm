A React SVG icon component that renders the Microsoft Remote Help application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`MicrosoftRemoteHelp`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG containing the Microsoft Remote Help icon as an embedded PNG via a base64 data URI.

## Usage Example

```typescript
import MicrosoftRemoteHelp from "./MicrosoftRemoteHelp";

// Basic usage
<MicrosoftRemoteHelp />

// With custom size and className
<MicrosoftRemoteHelp width={64} height={64} className="icon" />

// With style overrides
<MicrosoftRemoteHelp style={{ opacity: 0.8 }} />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- All standard SVG props (e.g., `className`, `style`, `aria-label`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external network requests are made at render time.
