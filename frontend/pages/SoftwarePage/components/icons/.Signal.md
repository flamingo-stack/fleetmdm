A React SVG component that renders the Signal app logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Signal`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Signal messenger logo as an embedded base64 PNG.

## Usage Example

```typescript
import Signal from "./Signal";

// Basic usage
<Signal />

// With custom dimensions and className
<Signal width={64} height={64} className="icon" />

// With accessibility attributes
<Signal aria-label="Signal" role="img" />
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full prop customization (e.g., `width`, `height`, `className`, `style`, `aria-*`).
- The logo image is embedded as a base64-encoded PNG via an `<image>` element — no external network request is made.
- Default rendered size is **32×32 pixels**.
