SVG icon component that renders a background music icon as a React component, embedding a base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`BackgroundMusic`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded PNG icon.

## Usage Example

```typescript
import BackgroundMusic from "./BackgroundMusic";

// Basic usage
<BackgroundMusic />

// With custom size and styling
<BackgroundMusic
  width={64}
  height={64}
  className="icon"
  style={{ opacity: 0.8 }}
/>

// With click handler
<BackgroundMusic onClick={() => toggleMusic()} />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon image is embedded as a **base64-encoded PNG** (originally 512×512), so no external asset loading is required.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-label`, `onClick`) are forwarded to the root `<svg>` element.
