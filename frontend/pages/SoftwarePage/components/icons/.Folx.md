A React SVG component that renders the Folx icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Folx`** — Default export. A functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a 32×32 SVG containing an embedded PNG icon via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import Folx from './Folx';

// Basic usage
<Folx />

// With custom dimensions or class
<Folx width={64} height={64} className="my-icon" />

// With accessibility attributes
<Folx aria-label="Folx" role="img" />
```

## Notes

- The icon is fixed at **32×32** pixels by default but can be overridden via `SVGProps`.
- The PNG image data is inlined as a base64 string, so no external asset request is made.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element.
