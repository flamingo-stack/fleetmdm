A React SVG component that renders a Comet icon using an embedded base64-encoded PNG image.

## Key Components

- **`Comet`** — Default export; a functional React component that renders a 32×32 SVG element containing an inline base64 PNG image of a comet icon
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`)

## Usage Example

```typescript
import Comet from "./Comet";

// Basic usage
<Comet />

// With custom size and class
<Comet width={64} height={64} className="icon-comet" />

// With event handler
<Comet onClick={() => console.log("comet clicked")} />
```

## Notes

- Default dimensions are `32×32` pixels but can be overridden via props
- The icon image is fully self-contained via a base64-encoded PNG `href` — no external image assets required
- Built with standard React SVG conventions; compatible with any React project
