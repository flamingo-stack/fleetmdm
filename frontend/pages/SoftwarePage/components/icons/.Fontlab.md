React SVG wrapper component that renders the Fontlab application icon as a 32×32 inline PNG image embedded via base64 data URI.

## Key Components

- **`Fontlab`** — Default export. A functional React component that accepts standard SVG props (`SVGProps<SVGSVGElement>`) and renders a 32×32 `<svg>` element containing a base64-encoded PNG of the Fontlab logo.

## Usage Example

```typescript
import Fontlab from './Fontlab';

// Basic usage
<Fontlab />

// With custom dimensions and className
<Fontlab width={64} height={64} className="app-icon" />

// With accessibility attributes
<Fontlab aria-label="Fontlab" role="img" />
```

## Notes

- The icon image is embedded as a base64 PNG data URI, so no external asset fetch is required.
- Default rendered size is `32×32` pixels; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
