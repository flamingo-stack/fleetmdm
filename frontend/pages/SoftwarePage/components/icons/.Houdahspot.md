React SVG wrapper component that renders the HoudahSpot application icon as an inline SVG containing a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Houdahspot`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Houdahspot from "./Houdahspot";

// Basic usage
<Houdahspot />

// With custom size and class
<Houdahspot width={64} height={64} className="app-icon" />

// With click handler
<Houdahspot onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon image is self-contained via a base64-encoded PNG `href` on an `<image>` element — no external asset requests.
- Default rendered size is **32×32px**; override with `width`/`height` props.
