SVG icon component that renders the IntelliJ IDEA logo as a base64-encoded PNG embedded within an SVG element.

## Key Components

- **`IntelliJIdea`** – Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG wrapper containing the IntelliJ IDEA logo as an embedded PNG image via a base64 `data:image/png` URI.

## Usage Example

```typescript
import IntelliJIdea from "./IntelliJIdea";

// Basic usage
const MyComponent = () => (
  <div>
    <IntelliJIdea />
  </div>
);

// With custom size and className
const CustomIcon = () => (
  <IntelliJIdea
    width={64}
    height={64}
    className="editor-icon"
    aria-label="IntelliJ IDEA"
  />
);
```

## Notes

- Default dimensions are **32×32 pixels**; override via `width`/`height` props.
- All standard `SVGProps` (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The icon image is self-contained — no external network requests are made.
