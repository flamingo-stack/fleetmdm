A React SVG wrapper component that renders a 32×32 PNG icon (Sanesidebuttons) as an inline SVG image using an embedded base64-encoded PNG data URI.

## Key Components

- **`Sanesidebuttons`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element. The icon is rendered via a single `<image>` element with a hardcoded base64 PNG payload at 32×32 pixels.

## Usage Example

```typescript
import Sanesidebuttons from "./Sanesidebuttons";

// Basic usage
<Sanesidebuttons />

// With custom dimensions or className
<Sanesidebuttons width={64} height={64} className="my-icon" />

// With accessibility attributes
<Sanesidebuttons aria-label="Sanesidebuttons icon" role="img" />
```

## Notes

- The PNG data is fully self-contained — no external image assets are required.
- Because the image is base64-encoded and embedded at build time, this component adds to bundle size. For performance-sensitive applications, consider referencing an external image file instead.
- Accepts any valid `SVGProps<SVGSVGElement>` (e.g., `className`, `style`, `onClick`, `aria-*`), making it easy to integrate into design systems or icon libraries.
