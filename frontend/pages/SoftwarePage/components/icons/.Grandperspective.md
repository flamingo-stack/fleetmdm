A React SVG component that renders the GrandPerspective application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

- **`Grandperspective`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element containing a base64-encoded PNG icon via an `<image>` tag.

## Usage Example

```typescript
import Grandperspective from "./Grandperspective";

// Basic usage
<Grandperspective />

// With custom dimensions or className
<Grandperspective width={64} height={64} className="app-icon" />

// With accessibility attributes
<Grandperspective aria-label="GrandPerspective" role="img" />
```

## Notes

- The icon data is fully self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; override with `width`/`height` props as needed.
