A React SVG component that renders a wave emoji icon as an inline SVG wrapping a base64-encoded PNG image.

## Key Components

- **`Wave`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing an embedded base64 PNG wave emoji image.

## Usage Example

```typescript
import Wave from "./Wave";

// Basic usage
<Wave />

// With custom dimensions or className
<Wave width={64} height={64} className="wave-icon" />

// With style overrides
<Wave style={{ opacity: 0.8 }} aria-label="Wave emoji" />
```

## Notes

- The image data is self-contained (no external asset dependency) — the PNG is embedded directly as a base64 `data:image/png` URI within the SVG `<image>` element.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread (`{...props}`).
- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
