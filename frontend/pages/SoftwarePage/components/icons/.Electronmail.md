A React SVG icon component that renders the Electronmail application logo as a 32×32 inline PNG image embedded via a base64 data URI.

## Key Components

- **`Electronmail`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG containing the Electronmail icon as an embedded PNG.

## Usage Example

```typescript
import Electronmail from "./Electronmail";

// Basic usage
<Electronmail />

// With custom class or style
<Electronmail className="icon" style={{ opacity: 0.8 }} />

// With aria label for accessibility
<Electronmail aria-label="Electronmail" role="img" />
```

## Notes

- The icon dimensions are fixed at `32×32` pixels by default but can be overridden via `width`/`height` props.
- The PNG image is embedded directly as a base64 data URI — no external asset request is made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
