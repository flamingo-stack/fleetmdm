A React SVG component that renders the macOS (MOS) operating system icon as a 32×32 inline PNG image embedded via a base64-encoded data URI.

## Key Components

- **`Mos`** — Default export; a functional React component that accepts standard `SVGProps<SVGSVGElement>` and renders a fixed-size 32×32 SVG containing an embedded PNG image.

## Usage Example

```typescript
import Mos from "./Mos";

// Basic usage
<Mos />

// With custom dimensions or className
<Mos width={64} height={64} className="os-icon" />

// With accessibility attributes
<Mos aria-label="macOS" role="img" />
```

## Notes

- The icon image is self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default rendered size is **32×32px**; the embedded image is sourced from a 512×512 PNG (per embedded EXIF metadata), so it scales cleanly to larger sizes if overridden via props.
