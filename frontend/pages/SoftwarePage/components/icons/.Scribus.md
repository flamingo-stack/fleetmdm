A React SVG component that renders the Scribus desktop publishing application logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Scribus`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders the Scribus logo at 32×32 pixels via an embedded base64 PNG `<image>` element.

## Usage Example

```typescript
import Scribus from "./Scribus";

// Basic usage
<Scribus />

// With custom size or className
<Scribus width={64} height={64} className="app-icon" />

// With style overrides
<Scribus style={{ opacity: 0.8 }} />
```

## Notes

- The icon image is self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element via spread.
- Default dimensions are `32×32`; override with `width`/`height` props as needed.
