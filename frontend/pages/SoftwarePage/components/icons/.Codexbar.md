A React SVG wrapper component that renders the Codexbar logo as a 32×32 inline SVG containing a base64-encoded PNG image.

## Key Components

- **`Codexbar`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG element with an embedded PNG via a base64-encoded `href` on an `<image>` element.

## Usage Example

```typescript
import Codexbar from "./Codexbar";

// Basic usage
<Codexbar />

// With custom className or style
<Codexbar className="logo-icon" style={{ opacity: 0.8 }} />

// With ARIA attributes for accessibility
<Codexbar aria-label="Codexbar logo" role="img" />
```

## Notes

- The component forwards all `SVGProps<SVGSVGElement>` to the root `<svg>` element, allowing full customization (e.g., `className`, `style`, `aria-*`, event handlers).
- The image dimensions are fixed at `32×32` pixels; override via `width`/`height` props if a different size is needed.
- The PNG is embedded inline as a base64 data URI — no external asset fetch is required.
