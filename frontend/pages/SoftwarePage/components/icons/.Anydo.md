React SVG component that renders the Any.do brand logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`Anydo`** — Default export. A functional React component that wraps an `<svg>` element containing an `<image>` tag with a base64-encoded PNG of the Any.do logo.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>`, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Anydo from "./Anydo";

// Basic usage
<Anydo />

// With custom size and class
<Anydo width={64} height={64} className="brand-icon" />

// With click handler
<Anydo onClick={() => console.log("Any.do icon clicked")} />
```

## Notes

- Default dimensions are `32×32` pixels.
- The logo image is self-contained via base64 encoding — no external asset dependency.
- Because props are spread onto the `<svg>` element, `width` and `height` overrides will not change the inner `<image>` dimensions; for proper scaling, apply a CSS `transform` or adjust the inner `width`/`height` attributes directly.
