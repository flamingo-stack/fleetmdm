React SVG icon component that renders the DbGate database GUI tool logo as an inline SVG using an embedded base64-encoded PNG image.

## Key Components

- **`Dbgate`** — Default export. A functional React component that renders a 32×32 SVG element containing the DbGate logo as an embedded base64 PNG image.
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Dbgate from "./Dbgate";

// Basic usage
<Dbgate />

// With custom size and className
<Dbgate width={64} height={64} className="tool-icon" />

// With click handler
<Dbgate onClick={() => console.log("DbGate selected")} />
```

## Notes

- The logo image is embedded as a base64 PNG, so no external asset files are required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- Part of the Flamingo/OpenFrame icon set for MSP tool integrations.
