A React SVG component that renders a 32×32 PostgreSQL application icon using an embedded base64-encoded PNG image.

## Key Components

- **`PostgresApp`** — Default export. A functional React component wrapping an `<svg>` element that renders the PostgreSQL app icon via an embedded base64 PNG `<image>` tag.
- **Props** — Accepts all standard `SVGProps<SVGSVGElement>`, allowing full customization of the SVG element (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import PostgresApp from "./PostgresApp";

// Basic usage
<PostgresApp />

// With custom size and class
<PostgresApp width={64} height={64} className="icon" />

// With click handler
<PostgresApp onClick={() => console.log("PostgreSQL selected")} />
```

## Notes

- The icon is self-contained — no external image assets are required at runtime.
- Default dimensions are `32×32` pixels but can be overridden via props.
- The embedded PNG carries EXIF metadata indicating a source resolution of 512×512 pixels.
