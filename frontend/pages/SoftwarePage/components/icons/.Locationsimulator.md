A React SVG component that renders a Location Simulator icon as a 32×32 SVG element, embedding a PNG image via a base64-encoded data URI.

## Key Components

- **`Locationsimulator`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full customization (className, style, onClick, etc.).
- **Embedded PNG** — The icon image is inlined as a base64 data URI within an SVG `<image>` tag, requiring no external asset files.

## Usage Example

```typescript
import Locationsimulator from "./Locationsimulator";

// Basic usage
<Locationsimulator />

// With custom size and className
<Locationsimulator width={64} height={64} className="icon" />

// With click handler
<Locationsimulator onClick={() => console.log("clicked")} />
```

## Notes

- Default rendered size is **32×32 pixels**; override via `width`/`height` props.
- The base64 PNG payload is a 512×512 source image downscaled to 32×32 by the SVG viewport — no runtime fetches required.
