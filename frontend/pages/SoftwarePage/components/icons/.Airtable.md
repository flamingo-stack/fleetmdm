A React SVG component that renders the Airtable brand logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Airtable`** — Default export. A functional React component that renders a 32×32 SVG containing the Airtable logo as an embedded base64 PNG image.

## Usage Example

```typescript
import Airtable from "./Airtable";

// Basic usage
<Airtable />

// With custom dimensions and className
<Airtable width={64} height={64} className="integration-logo" />

// With ARIA label for accessibility
<Airtable aria-label="Airtable" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `width`, `height`, `className`, `style`, `aria-*`) via spread.
- Default rendered size is **32×32 pixels**.
- The logo image is self-contained as a base64-encoded PNG — no external image dependencies or network requests required.
