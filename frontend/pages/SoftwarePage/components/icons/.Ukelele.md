A React SVG component that renders a 32×32 ukulele icon using an embedded base64-encoded PNG image.

## Key Components

- **`Ukelele`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a fixed 32×32 SVG wrapper around an embedded PNG raster image.

## Usage Example

```typescript
import Ukelele from "./Ukelele";

// Basic usage
<Ukelele />

// With custom className or style
<Ukelele className="icon" style={{ opacity: 0.8 }} />

// With aria attributes for accessibility
<Ukelele aria-label="Ukulele" role="img" />
```

## Notes

- The icon is raster-based (base64 PNG), not vector, so it does not scale crisply beyond 32×32.
- All SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded directly to the `<svg>` element via spread.
