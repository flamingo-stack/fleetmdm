A React SVG component that renders a 32×32 "Loop" icon using an embedded base64-encoded PNG image.

## Key Components

- **`Loop`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, which are spread onto the root `<svg>` element for full customization (className, style, onClick, etc.).

## Usage Example

```typescript
import Loop from "./Loop";

// Basic usage
<Loop />

// With custom size and color overrides
<Loop width={64} height={64} className="loop-icon" />

// With event handler
<Loop onClick={() => console.log("clicked")} style={{ cursor: "pointer" }} />
```

## Notes

- The icon is a 32×32 SVG wrapper containing an `<image>` element with an inline base64-encoded PNG, sourced from [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
- Because the visual is a rasterized PNG embed, scaling beyond 32×32 may result in blurring. For sharp rendering at larger sizes, consider replacing with a vector path.
- All standard `SVGProps` are forwarded, making this compatible with any SVG attribute or React event handler.
