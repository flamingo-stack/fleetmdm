A React SVG component that renders the Coderunner application icon as an inline SVG with an embedded base64-encoded PNG image (32×32 pixels).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Coderunner` | `React.FC<SVGProps<SVGSVGElement>>` | Default-exported SVG icon component for the Coderunner app |

## Usage Example

```typescript
import Coderunner from './Coderunner';

// Basic usage
<Coderunner />

// With custom dimensions and class
<Coderunner width={64} height={64} className="icon" />

// With accessibility attributes
<Coderunner aria-label="Coderunner" role="img" />
```

## Notes

- Renders a 32×32 SVG containing an embedded PNG via a base64 `data:image/png` `href` on an `<image>` element
- Accepts all standard `SVGProps<SVGSVGElement>` props, allowing full customization (size, class, style, event handlers, etc.)
- The icon asset is self-contained — no external image requests are made at runtime
