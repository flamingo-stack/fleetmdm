React SVG icon component that renders a PostgreSQL logo at 32×32px using an embedded base64-encoded PNG image.

## Key Components

- **`Postgresql18`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, allowing consumers to override `className`, `style`, `onClick`, and other SVG attributes.

## Usage Example

```typescript
import Postgresql18 from "./Postgresql18";

// Basic usage
<Postgresql18 />

// With custom size and class
<Postgresql18 width={64} height={64} className="icon" />

// With click handler
<Postgresql18 onClick={() => console.log("clicked")} />
```

## Notes

- The icon renders a fixed 32×32 PNG asset inlined as a base64 `data:image/png` inside an `<image>` element — no external network request required.
- Width/height default to `32`; override via props if a different display size is needed (the underlying bitmap remains 32×32, so scale up cautiously).
