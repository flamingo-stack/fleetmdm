A React SVG component that renders the TrezorSuite application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`TrezorSuite`** — Default export. A functional React component that wraps a base64 PNG logo inside an `<svg>` element, accepting all standard `SVGProps<SVGSVGElement>` props for customization.

## Usage Example

```typescript
import TrezorSuite from "./TrezorSuite";

// Basic usage
<TrezorSuite />

// With custom props
<TrezorSuite className="icon" style={{ opacity: 0.8 }} />

// With custom dimensions (overrides default 32×32)
<TrezorSuite width={64} height={64} />
```

## Notes

- The icon dimensions default to `32×32` but can be overridden via `width`/`height` props.
- The PNG data is inlined as a base64 string — no external asset loading required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`) are forwarded to the root `<svg>` element.
