A React SVG component that renders the Maccy application icon as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Maccy`** — A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Maccy clipboard manager icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import { Maccy } from "./Maccy";

// Basic usage
<Maccy />

// With custom dimensions or className
<Maccy width={64} height={64} className="app-icon" />

// With accessibility attributes
<Maccy aria-label="Maccy" role="img" />
```

## Notes

- The icon is **self-contained** — no external image assets are required at runtime; the PNG data is embedded directly as a base64 `href` on the inner `<image>` element.
- Inherits all SVG prop overrides (e.g., `width`, `height`, `style`, `className`) via `{...props}` spread.
- Default rendered size is **32×32 pixels**.
- Intended for use as an application/integration icon representing [Maccy](https://maccy.app), a macOS clipboard manager, within the Flamingo/OpenFrame tooling context.
