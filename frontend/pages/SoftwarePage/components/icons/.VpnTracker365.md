A React SVG component that renders the VPN Tracker 365 application icon as an inline SVG with an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`VpnTracker365`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG element with an embedded PNG via a base64 data URI `<image>` tag.

## Usage Example

```typescript
import VpnTracker365 from "./VpnTracker365";

// Basic usage
<VpnTracker365 />

// With custom dimensions and className
<VpnTracker365 width={64} height={64} className="app-icon" />

// With style overrides
<VpnTracker365 style={{ borderRadius: 8 }} />
```

## Notes

- The icon image is fully self-contained — no external asset files or network requests are required.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-label`) are forwarded directly to the root `<svg>` element via the spread `{...props}`.
- Default rendered size is **32×32px**; override via `width`/`height` props as needed.
