SVG icon component that renders the Blender application logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Blender`** — Default export. A React functional component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG that embeds the Blender logo as a base64 PNG `<image>` element.

## Usage Example

```typescript
import Blender from "./Blender";

// Basic usage
<Blender />

// With custom dimensions or className
<Blender width={64} height={64} className="app-icon" />

// With accessibility attributes
<Blender aria-label="Blender" role="img" />
```

## Notes

- The icon is fixed at **32×32 pixels** by default but can be overridden via props.
- The image data is fully self-contained (base64-encoded PNG), requiring no external asset files or network requests.
- Accepts all standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) via spread.
- Suitable for use in tool/integration lists, app pickers, or any UI referencing Blender as a managed application within the [FleetMDM integration layer](https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons/Blender.tsx).
