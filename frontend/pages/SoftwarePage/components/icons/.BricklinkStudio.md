SVG icon component that renders the BricklinkStudio logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`BricklinkStudio`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG element with an embedded base64 PNG image of the BricklinkStudio application icon.

## Usage Example

```typescript
import BricklinkStudio from "./BricklinkStudio";

// Basic usage
<BricklinkStudio />

// With custom dimensions or className
<BricklinkStudio width={64} height={64} className="app-icon" />

// Inside a button or link
<button>
  <BricklinkStudio aria-label="Open BricklinkStudio" />
  Launch Studio
</button>
```

## Notes

- The icon image is self-contained — no external image assets are required at runtime.
- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread, making it easy to compose or style.
- The fixed intrinsic size is 32×32; override via `width`/`height` props as needed.
