React SVG icon component that renders the Typora application logo as an inline SVG using an embedded base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Typora`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` and rendering a 32×32 SVG wrapper around a base64-encoded PNG `<image>` element.

## Usage Example

```typescript
import Typora from './Typora';

// Basic usage
<Typora />

// With custom dimensions or className
<Typora width={64} height={64} className="app-icon" />

// With ARIA label for accessibility
<Typora aria-label="Typora" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread (`{...props}`), making the component flexible for layout and accessibility needs.
- The icon image is self-contained — no external asset requests are made at runtime.
- Default rendered size is **32×32 px**; override via `width`/`height` props.
