A React SVG component that renders a 32×32 Typeface logo icon using an embedded base64-encoded PNG image.

## Key Components

- **`Typeface`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, which are spread onto the root `<svg>` element for full customization.

## Usage Example

```typescript
import Typeface from "./Typeface";

// Basic usage
<Typeface />

// With custom dimensions and className
<Typeface width={64} height={64} className="my-icon" />

// With accessibility attributes
<Typeface aria-label="Typeface logo" role="img" />
```

## Notes

- The icon renders at 32×32 pixels by default but can be resized via `width`/`height` props.
- The image data is fully self-contained as a base64-encoded PNG — no external asset requests.
- All standard SVG props (e.g., `style`, `className`, `onClick`) are forwarded to the root `<svg>` element.
