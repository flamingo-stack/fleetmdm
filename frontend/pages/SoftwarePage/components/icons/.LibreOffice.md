A React SVG icon component that renders the LibreOffice logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`LibreOffice`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`), rendering a 32×32 LibreOffice logo icon.

## Usage Example

```typescript
import LibreOffice from './LibreOffice';

// Basic usage
<LibreOffice />

// With custom size and className
<LibreOffice width={64} height={64} className="icon" />

// With style overrides
<LibreOffice style={{ opacity: 0.8 }} />
```

## Notes

- Defaults to `32×32` pixels but accepts any valid `SVGProps` to override dimensions or add attributes.
- The logo image is embedded as a base64 PNG — no external asset loading required.
- Compatible with any React project using standard JSX/TSX.
