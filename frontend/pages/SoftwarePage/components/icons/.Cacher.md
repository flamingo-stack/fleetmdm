React SVG component that renders the Cacher logo as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Cacher`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that contains a base64-encoded PNG of the Cacher logo.

## Usage Example

```typescript
import Cacher from "./Cacher";

// Basic usage
<Cacher />

// With custom dimensions or className
<Cacher width={64} height={64} className="icon" />

// With inline styles
<Cacher style={{ opacity: 0.8 }} />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded to the root `<svg>` element.
- The default size is **32×32 pixels**; override via `width`/`height` props.
- The image is self-contained — no external network requests are made.
