React SVG component that renders the PostgreSQL 17 logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Postgresql17`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props
- Renders a 32×32 SVG containing an embedded base64 PNG of the PostgreSQL 17 logo
- All SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element

## Usage Example

```typescript
import Postgresql17 from "./Postgresql17";

// Basic usage
<Postgresql17 />

// Custom size
<Postgresql17 width={64} height={64} />

// With className or style
<Postgresql17 className="icon" style={{ opacity: 0.8 }} />
```
