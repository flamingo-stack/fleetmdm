React SVG component that renders the Capto application icon as an inline PNG image embedded via base64 data URI within an SVG wrapper.

## Key Components

- **`Capto`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds a 512×512 PNG icon via a base64-encoded `<image>` element.

## Usage Example

```typescript
import Capto from './Capto';

// Basic usage
<Capto />

// With custom dimensions or className
<Capto width={64} height={64} className="icon" />

// With accessibility attributes
<Capto aria-label="Capto" role="img" />
```

## Notes

- All standard SVG props (e.g., `className`, `style`, `onClick`, `aria-*`) are forwarded via spread to the root `<svg>` element.
- The icon is self-contained — no external image assets are required at runtime.
- Default render size is **32×32** pixels; override with `width`/`height` props as needed.
