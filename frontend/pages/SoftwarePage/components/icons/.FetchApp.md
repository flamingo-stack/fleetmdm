SVG icon component that renders the Fetch app logo as an inline base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`FetchApp`** — Default export; a React functional component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Fetch app icon as a base64 PNG `<image>` element.

## Usage Example

```typescript
import FetchApp from "./FetchApp";

// Basic usage
<FetchApp />

// With custom dimensions or className
<FetchApp width={64} height={64} className="app-icon" />

// With accessibility attributes
<FetchApp aria-label="Fetch App" role="img" />
```

## Notes

- The icon is a **32×32** SVG by default but accepts any `SVGProps` overrides (e.g., `width`, `height`, `className`, `style`).
- The image data is a self-contained base64 PNG — no external asset requests at runtime.
