A React SVG component that renders the Joplin application icon as a base64-encoded PNG embedded within an SVG wrapper.

## Key Components

- **`Joplin`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Joplin logo as an embedded PNG image.

## Usage Example

```typescript
import Joplin from "./Joplin";

// Basic usage
<Joplin />

// With custom dimensions or className
<Joplin width={64} height={64} className="icon" />

// With accessibility attributes
<Joplin aria-label="Joplin" role="img" />
```

## Notes

- The icon renders at **32×32px** by default but can be overridden via `width`/`height` props.
- The PNG image data is inlined as a base64 `data:image/png` URI — no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded via the spread `{...props}` pattern.
