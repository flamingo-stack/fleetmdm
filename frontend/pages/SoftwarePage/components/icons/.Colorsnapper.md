React SVG wrapper component that renders the Colorsnapper app icon as a 32×32 PNG image embedded via a base64-encoded data URI within an SVG element.

## Key Components

- **`Colorsnapper`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, allowing consumers to pass any valid SVG attribute (e.g., `className`, `style`, `onClick`).

## Usage Example

```typescript
import Colorsnapper from "./Colorsnapper";

// Basic usage
<Colorsnapper />

// With custom dimensions or class
<Colorsnapper width={64} height={64} className="app-icon" />

// With click handler
<Colorsnapper onClick={() => console.log("Colorsnapper clicked")} />
```

## Notes

- The icon is self-contained — no external image requests are made at runtime.
- Default size is `32×32` pixels; override via `width`/`height` props.
- Located at [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) — check the repo for exact file path within the icon or asset library.
