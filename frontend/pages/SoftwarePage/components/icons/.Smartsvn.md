React SVG icon component that renders the SmartSVN logo as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Smartsvn`** — Default export. A functional React component accepting standard SVG props (`SVGProps<SVGSVGElement>`) and rendering a fixed 32×32 SVG wrapper around an embedded PNG image via a `data:image/png;base64` href.

## Usage Example

```typescript
import Smartsvn from "./Smartsvn";

// Basic usage
const App = () => <Smartsvn />;

// With custom props
const App = () => (
  <Smartsvn
    className="icon"
    style={{ opacity: 0.8 }}
    aria-label="SmartSVN"
  />
);
```

## Notes

- The component spreads all `SVGProps<SVGSVGElement>` onto the root `<svg>` element, allowing full customization of attributes like `className`, `style`, `aria-*`, and event handlers.
- Width and height are hardcoded to `32`, but can be overridden via props.
- The image data is self-contained — no external asset files are required.
