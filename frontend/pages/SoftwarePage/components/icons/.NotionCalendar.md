A React SVG component that renders the Notion Calendar app icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`NotionCalendar`** — Default export. A functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element.

## Usage Example

```typescript
import NotionCalendar from "./NotionCalendar";

// Basic usage
<NotionCalendar />

// With custom dimensions or className
<NotionCalendar width={64} height={64} className="icon" />

// With accessibility attributes
<NotionCalendar aria-label="Notion Calendar" role="img" />
```

## Notes

- The icon is self-contained — no external image assets or network requests required.
- Default rendered size is **32×32px**; override via `width`/`height` props.
- Accepts any `SVGProps<SVGSVGElement>` for full flexibility (e.g., `style`, `className`, `onClick`).
