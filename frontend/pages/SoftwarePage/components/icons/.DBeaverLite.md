A React SVG icon component that renders the DBeaver Lite logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`DBeaverLite`** — Default export. A functional React component that accepts all standard SVG props via `SVGProps<SVGSVGElement>` and renders a 32×32 DBeaver Lite icon.

## Usage Example

```typescript
import DBeaverLite from "./DBeaverLite";

// Basic usage
<DBeaverLite />

// With custom dimensions or className
<DBeaverLite width={64} height={64} className="icon" />

// With accessibility attributes
<DBeaverLite aria-label="DBeaver Lite" role="img" />
```

## Notes

- Default size is **32×32 pixels**; override via `width`/`height` props.
- The icon image is embedded as a base64 PNG — no external asset dependency.
- All [`SVGProps`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/icons/DBeaverLite.tsx) are spread onto the root `<svg>` element, making it fully composable with standard SVG attributes.
