React SVG icon component that renders a Python 3.14 logo as a base64-encoded PNG image embedded within an SVG wrapper.

## Key Components

- **`SvgPython314`** — Default named export; a functional React component accepting standard `SVGProps<SVGSVGElement>` props spread onto a 32×32 SVG element containing an embedded PNG via base64 `data:image/png` href.

## Usage Example

```typescript
import SvgPython314 from "./Python314";

// Basic usage
<SvgPython314 />

// With custom dimensions and class
<SvgPython314 width={64} height={64} className="icon" />

// With accessibility attributes
<SvgPython314 aria-label="Python 3.14" role="img" />
```

## Notes

- The component is 32×32px by default but can be overridden via `width`/`height` props.
- The image data is a self-contained PNG embedded as base64, so no external asset fetching occurs.
- All standard SVG props (`className`, `style`, `onClick`, etc.) are forwarded to the root `<svg>` element.
