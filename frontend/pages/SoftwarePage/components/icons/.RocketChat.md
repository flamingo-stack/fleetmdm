A React SVG component that renders the Rocket.Chat logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`RocketChat`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, which forwards all props to the underlying `<svg>` element.

## Usage Example

```typescript
import RocketChat from "./RocketChat";

// Basic usage
<RocketChat />

// With custom dimensions and className
<RocketChat width={64} height={64} className="icon" />

// With accessibility attributes
<RocketChat
  aria-label="Rocket.Chat"
  role="img"
  style={{ verticalAlign: "middle" }}
/>
```

## Notes

- The icon is rendered at **32×32px** by default; override via `width`/`height` props.
- The PNG image data is inlined as a base64 `href` on an SVG `<image>` element — no external asset request is made.
- All standard `SVGProps` (e.g., `className`, `style`, `aria-*`) are passed through via spread.
