A React SVG component that renders the Miro logo as an inline Base64-encoded PNG image wrapped in an SVG element.

## Key Components

- **`Miro`** — Default export. A functional React component accepting standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 Miro brand icon via an embedded Base64 PNG `<image>` element.

## Usage Example

```typescript
import Miro from "./Miro";

// Basic usage
<Miro />

// With custom size and className
<Miro width={64} height={64} className="icon" />

// With style overrides
<Miro style={{ opacity: 0.8 }} aria-label="Miro" />
```

## Notes

- Default dimensions are **32×32** pixels but can be overridden via `width`/`height` props.
- The icon is self-contained — no external image assets or network requests required.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded to the root `<svg>` element.
