A React SVG component that renders the Webcatalog application icon as a 32×32 pixel image using an embedded base64-encoded PNG.

## Key Components

- **`Webcatalog`** — Default export. A functional React component that accepts all standard `SVGProps<SVGSVGElement>` props and renders a 32×32 SVG containing the Webcatalog logo as an inline base64 PNG image.

## Usage Example

```typescript
import Webcatalog from "./Webcatalog";

// Basic usage
<Webcatalog />

// With custom className or style
<Webcatalog className="app-icon" style={{ opacity: 0.8 }} />

// With explicit dimensions override
<Webcatalog width={64} height={64} />
```

## Notes

- The icon image is self-contained — no external image assets or network requests required.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are forwarded to the root `<svg>` element.
- Default rendered size is **32×32px**; the embedded PNG source is **512×512px**, so the component scales cleanly at larger sizes.
