A React SVG component that renders the Redis Pro logo as a 32×32 icon using an embedded base64-encoded PNG image.

## Key Components

- **`RedisPro`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG wrapper around a base64 PNG of the Redis Pro logo.

## Usage Example

```typescript
import RedisPro from "./RedisPro";

// Basic usage
<RedisPro />

// With custom size or className
<RedisPro width={64} height={64} className="my-icon" />

// With accessibility attributes
<RedisPro aria-label="Redis Pro" role="img" />
```

## Notes

- The icon size defaults to `32×32` pixels but can be overridden via `width`/`height` props.
- The PNG is inlined as a base64 `data:image/png` URI, so no external asset requests are made.
- All standard SVG props (e.g., `className`, `style`, `onClick`) are forwarded to the root `<svg>` element.
