SVG React component that renders the BetterDisplay application icon as an inline base64-encoded PNG image.

## Key Components

- **`BetterDisplay`** — Default export; a functional React component accepting standard `SVGProps<SVGSVGElement>`, rendering a 32×32 SVG that embeds the BetterDisplay app icon via a base64 PNG `<image>` element.

## Usage Example

```typescript
import BetterDisplay from "./BetterDisplay";

// Basic usage
<BetterDisplay />

// With custom dimensions or className
<BetterDisplay width={64} height={64} className="app-icon" />
```

## Notes

- The icon is self-contained — no external image assets or network requests required.
- All `SVGProps` (e.g., `width`, `height`, `className`, `style`, `onClick`) are forwarded to the root `<svg>` element via spread, making it fully composable.
- Default rendered size is **32×32px**.
