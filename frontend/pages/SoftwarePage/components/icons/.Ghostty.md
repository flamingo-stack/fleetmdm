React SVG component that renders the Ghostty terminal emulator icon as an inline PNG image (32×32) encoded as a base64 data URI within an SVG wrapper.

## Key Components

- **`Ghostty`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, rendering a 32×32 SVG containing the Ghostty terminal icon as an embedded base64 PNG.

## Usage Example

```typescript
import Ghostty from "./Ghostty";

// Basic usage
<Ghostty />

// With custom size and className
<Ghostty width={64} height={64} className="icon" />

// With onClick handler
<Ghostty onClick={() => console.log("Ghostty icon clicked")} />
```

## Notes

- The icon image is self-contained — no external asset requests are made at runtime.
- All standard SVG props (e.g., `className`, `style`, `aria-*`, `onClick`) are forwarded via spread to the root `<svg>` element.
- Default dimensions are `32×32` but can be overridden via `width`/`height` props.
