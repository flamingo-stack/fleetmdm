A React SVG icon component that renders the OpenRefine logo as an inline base64-encoded PNG image within an SVG wrapper.

## Key Components

- **`Openrefine`** — Default export; a functional React component that renders a 32×32 SVG containing the OpenRefine logo as an embedded PNG via a base64 `href` on an `<image>` element.

## Usage Example

```typescript
import Openrefine from "./Openrefine";

// Basic usage
<Openrefine />

// With custom dimensions and styling
<Openrefine width={64} height={64} className="icon" />

// With ARIA label for accessibility
<Openrefine aria-label="OpenRefine" role="img" />
```

## Notes

- Accepts all standard `SVGProps<SVGSVGElement>` props (e.g., `className`, `style`, `onClick`, `aria-*`), which are spread onto the root `<svg>` element.
- Default size is **32×32 pixels**; override via `width`/`height` props.
- The logo image is fully self-contained — no external network requests or file dependencies.
