A React SVG component that renders the Sirimote icon as an inline SVG using a base64-encoded PNG image at 32×32 pixels.

## Key Components

- **`Sirimote`** — Default export; a functional React component accepting all standard `SVGProps<SVGSVGElement>` props, forwarded to the root `<svg>` element via spread.

## Usage Example

```typescript
import Sirimote from "./Sirimote";

// Basic usage
<Sirimote />

// With custom size and className
<Sirimote width={64} height={64} className="icon" />

// With style overrides
<Sirimote style={{ opacity: 0.8 }} aria-label="Sirimote icon" />
```

## Notes

- The image is embedded as a base64 PNG, so no external asset file is required.
- Default dimensions are **32×32px**; override via `width`/`height` props.
- All standard SVG props (`className`, `style`, `onClick`, `aria-*`, etc.) are supported through the spread pattern.
