Generates the column configuration array for the Software Versions data table, defining headers, accessors, sort behavior, and cell renderers for each column.

## Key Components

- **`generateTableHeaders(router, teamId?)`** — Default export. Accepts an `InjectedRouter` and optional `teamId`, returns an array of `Column<ISoftwareVersion>` configs for use with `react-table`.

### Columns Defined

| Column | Accessor | Sortable | Notes |
|---|---|---|---|
| Name | `name` | ✅ | Links to `SOFTWARE_VERSION_DETAILS` route with optional `fleet_id` |
| Version | `version` | ❌ | Plain text display |
| Type | `source` | ❌ | Formatted via `formatSoftwareType` |
| Vulnerabilities | `vulnerabilities` | ❌ | Shows "Not supported" for `ios_apps`/`ipados_apps` |
| Hosts | `hosts_count` | ✅ | Numeric count |
| *(View All Hosts)* | `view-all-hosts` | ❌ | Row-hover link filtered by `software_version_id` and `fleet_id` |

## Usage Example

```typescript
import generateTableHeaders from "./SoftwareVersionsTableConfig";

const columns = generateTableHeaders(router, teamId);

<TableContainer
  columns={columns}
  data={softwareVersions}
  // ...
/>
```

## Notes

- `iconUrl` is intentionally omitted from `SoftwareNameCell` — it does not exist on `ISoftwareVersion`.
- The `fleet_id` param on the "View All Hosts" link is noted as a TODO in source.
