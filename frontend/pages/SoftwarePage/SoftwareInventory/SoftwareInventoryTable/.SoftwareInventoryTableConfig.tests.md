Test suite for `generateTableHeaders` from `SoftwareInventoryTableConfig`, validating the column structure, header names, and sorting behavior of the software inventory table.

## Key Components

- **`generateTableHeaders`** — The function under test; accepts a router and a team ID, returns an array of column configuration objects.
- **`createMockRouter`** — Test utility that provides a mock Next.js router instance required by the table config.

## Test Coverage

| Test | Description |
|------|-------------|
| Column headers | Asserts the exact ordered set of column keys/names |
| Version column | Confirms the column is labeled `"Version"` (not `"Installed version"`) |
| No Library version | Ensures the `"Library version"` column is absent |
| Vulnerabilities column | Confirms the `"Vulnerabilities"` column is present |
| Sorting disabled | Verifies `disableSortBy: true` on `Version`, `Type`, and `Vulnerabilities` |

## Usage Example

```typescript
// Running the test suite
// jest SoftwareInventoryTableConfig.tests.tsx

// Calling the function under test directly
import generateTableHeaders from "./SoftwareInventoryTableConfig";
import { createMockRouter } from "test/test-utils";

const router = createMockRouter();
const teamId = 1;
const headers = generateTableHeaders(router, teamId);

// Expected column order:
// ["name", "Version", "Type", "Vulnerabilities", "hosts_count", ""]
```
