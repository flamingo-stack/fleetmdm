Renders the software inventory table for the Fleet MDM software page, supporting both "titles" and "versions" views with filtering, sorting, pagination, and row navigation.

## Key Components

### `SoftwareTable` (default export)
The primary React component accepting these props:

| Prop | Type | Description |
|------|------|-------------|
| `router` | `InjectedRouter` | React Router instance for navigation |
| `data` | `ISoftwareTitlesResponse \| ISoftwareVersionsResponse` | API response data |
| `showVersions` | `boolean` | Toggles between titles and versions view |
| `vulnFilters` | `ISoftwareVulnFiltersParams` | Active vulnerability filter state |
| `isSoftwareEnabled` | `boolean` | Whether software inventory is enabled |
| `installableSoftwareExists` | `boolean` | Controls empty state messaging |
| `onAddFiltersClick` | `() => void` | Opens the vulnerability filter modal |

### Internal Helpers
- **`isSoftwareTitles`** — Type guard differentiating `ISoftwareTitlesResponse` from `ISoftwareVersionsResponse`
- **`determineQueryParamChange`** — Detects which table query param changed to conditionally reset pagination
- **`generateNewQueryParams`** — Builds the full URL query parameter object on table state changes
- **`handleShowVersionsToggle`** — Navigates between `SOFTWARE_INVENTORY` and `SOFTWARE_VERSIONS` paths
- **`handleRowSelect`** — Routes to `SOFTWARE_TITLE_DETAILS` or `SOFTWARE_VERSION_DETAILS` on row click

## Usage Example

```typescript
<SoftwareTable
  router={router}
  data={softwareTitlesResponse}
  showVersions={false}
  installableSoftwareExists={true}
  isSoftwareEnabled={true}
  query={query}
  perPage={20}
  orderDirection="asc"
  orderKey="name"
  vulnFilters={{ vulnerable: true }}
  currentPage={0}
  teamId={1}
  isLoading={false}
  onAddFiltersClick={() => setShowFilterModal(true)}
/>
```

The table dynamically selects its column config via `generateInventoryTableConfig` (titles) or `generateVersionsTableConfig` (versions), and disables controls entirely when software inventory is disabled or the table is genuinely empty (no data, query, or active filters).
