Defines and exports the column configuration for the Software Inventory table, mapping `ISoftwareTitle` data to react-table column definitions with custom cell renderers.

## Key Components

### `getSoftwareNameCellData(softwareTitle, teamId?)`
Internal helper that derives all props needed by `SoftwareNameCell` from a software title row — including the detail page path, installer presence, self-service flag, install type (`"manual"` | `"automatic"`), icon URL, and automatic install policy count.

### `generateTableHeaders(router, teamId?)`
Default export. Returns the ordered array of react-table `Column<ISoftwareTitle>` definitions:

| Column | Accessor | Sortable | Notes |
|---|---|---|---|
| Name | `name` | ✅ | Renders `SoftwareNameCell` with badges |
| Version | `versions` | ❌ | Renders `VersionCell` |
| Type | `source` | ❌ | Formats via `formatSoftwareType` |
| Vulnerabilities | *(derived)* | ❌ | Aggregated from `versions`; shows "Not supported" for iOS/iPadOS and `.tgz` packages |
| Hosts | `hosts_count` | ✅ | Raw count |
| *(link)* | `view-all-hosts` | ❌ | `ViewAllHostsLink`; hidden for unsupported sources |

## Usage Example

```typescript
import generateTableHeaders from "./SoftwareInventoryTableConfig";

// Inside a React component
const tableColumns = generateTableHeaders(router, teamId);

return (
  <TableContainer
    columns={tableColumns}
    data={softwareTitles}
    // ...
  />
);
```

## Notes
- The `vulnerabilities` column intentionally uses a separate accessor from `versions` to work around react-table's restriction on reusing accessors.
- The "View All Hosts" link is suppressed for sources listed in `NO_VERSION_OR_HOST_DATA_SOURCES`.
- When `teamId` is `undefined` (All Teams view), the installer badge is hidden.
