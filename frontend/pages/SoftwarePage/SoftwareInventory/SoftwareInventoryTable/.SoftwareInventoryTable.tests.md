Test suite for the `SoftwareInventoryTable` component, validating rendering behavior across disabled, empty, filtered, and version-toggled states.

## Key Components

- **`describe("Software inventory table")`** — Top-level test suite covering four distinct UI states
- **`createCustomRenderer`** — Sets up a render context with a global admin user
- **`createMockSoftwareTitlesResponse` / `createMockSoftwareVersionsResponse`** — Factory helpers providing typed mock API responses
- **`createMockRouter`** — Provides a mock Next.js-compatible router instance

## Test Cases

| Test | Condition | Key Assertion |
|------|-----------|---------------|
| Disabled state | `isSoftwareEnabled={false}` | Shows "Software inventory disabled"; hides filters |
| Empty state | `count: 0`, no query/filters | Shows "No software detected"; search and filters are **disabled** |
| Versions toggle with empty data | `showVersions={true}`, empty data | Controls remain **enabled** so users can toggle back |
| Active vuln filter, no results | `vulnerable: true`, empty data | Shows "No items match" empty-search state; displays "1 filter" badge |

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import SoftwareInventoryTable from "./SoftwareInventoryTable";
import { createMockSoftwareTitlesResponse } from "__mocks__/softwareMock";

render(
  <SoftwareInventoryTable
    isSoftwareEnabled
    showVersions={false}
    data={createMockSoftwareTitlesResponse({ software_titles: [] })}
    query=""
    perPage={20}
    orderDirection="asc"
    orderKey="hosts_count"
    vulnFilters={{ vulnerable: false, exploit: false }}
    currentPage={0}
    isLoading={false}
    onAddFiltersClick={() => {}}
  />
);

expect(screen.getByText("No software detected")).toBeInTheDocument();
```

## Notes

- When `showVersions` is active and returns no data, controls intentionally stay **enabled** — the titles view may still have installable software.
- The search input placeholder `"Search by name or vulnerability (CVE)"` is used as a stable selector across multiple tests.
