Test suite for the `getVulnerabilities` helper function, validating deduplication, null-safety, and edge-case behavior across software version vulnerability data.

## Key Components

- **`getVulnerabilities` import** — Function under test, sourced from `./helpers`
- **`versions` fixture** — Sample dataset of four software versions with varying vulnerability states (duplicates, nulls, and valid CVE lists)
- **`describe("getVulnerabilities")`** — Test suite covering two primary scenarios

## Test Cases

| Test | Description |
|------|-------------|
| Unique vulnerability list | Verifies deduplication across versions, presence of all expected CVEs, and absence of fabricated entries |
| Empty input | Confirms a graceful `[]` return when no versions are provided |

## Usage Example

```typescript
import { getVulnerabilities } from "./helpers";

const versions = [
  {
    id: 531270,
    version: "131.0.6778.86",
    vulnerabilities: ["CVE-2024-12053", "CVE-2025-0444"],
  },
  {
    id: 538184,
    version: "132.0.6834.160",
    vulnerabilities: ["CVE-2025-0444", "CVE-2025-0445"], // duplicate CVE
  },
  {
    id: 572993,
    version: "139.0.7258.127",
    vulnerabilities: null, // null entries are ignored
  },
];

const result = getVulnerabilities(versions);
// ["CVE-2024-12053", "CVE-2025-0444", "CVE-2025-0445"] — no duplicates, nulls skipped
```

## Key Behaviors Tested

- **Deduplication** — `CVE-2025-0444` appears in two versions but only once in output
- **Null safety** — Versions with `vulnerabilities: null` are silently skipped
- **Empty input** — Returns `[]` without error
