Utility helpers for managing software vulnerability filters, CVSS severity ranges, and related UI state in the Fleet MDM software inventory views.

## Key Components

### Constants
- **`SEVERITY_DROPDOWN_OPTIONS`** — Array of predefined CVSS severity band options (Any, Critical, High, Medium, Low, Custom), each with `minSeverity`/`maxSeverity` bounds and display metadata
- **`ANY_SEVERITY_OPTION`** / **`CUSTOM_SEVERITY_OPTION`** — Standalone exports for the boundary severity options

### Types
- **`ISoftwareVulnFilters`** — Query-param-style filter shape (snake_case keys, e.g. `min_cvss_score`)
- **`ISoftwareVulnFiltersParams`** — Camelcase filter shape used internally (e.g. `minCvssScore`)

### Functions
| Function | Description |
|---|---|
| `getSoftwareVulnFiltersFromQueryParams` | Parses raw URL query params into typed vulnerability filter values |
| `buildSoftwareVulnFiltersQueryParams` | Serializes internal filter state back to URL query params; returns `{}` if `vulnerable` is falsy |
| `findOptionBySeverityRange` | Resolves a `SEVERITY_DROPDOWN_OPTIONS` entry from a min/max CVSS pair, falling back to a dynamic custom option |
| `getVulnFilterRenderDetails` | Computes UI state: active filter count, button label text, and tooltip content |
| `getVulnerabilities` | Deduplicates CVE strings across an array of software version objects |

## Usage Example

```typescript
// Parse filters from the current URL
const filters = getSoftwareVulnFiltersFromQueryParams(queryParams);
// { vulnerable: true, exploit: false, minCvssScore: 7, maxCvssScore: 10 }

// Build query params to push back to the URL
const params = buildSoftwareVulnFiltersQueryParams(filters);
// { vulnerable: true, min_cvss_score: "7", max_cvss_score: "10" }

// Resolve the matching severity dropdown option
const option = findOptionBySeverityRange(7.0, 10);
// { label: "High severity", value: "high", ... }

// Get button label and tooltip for the filter badge
const { buttonText, tooltipText, filterCount } = getVulnFilterRenderDetails(filters);
// buttonText: "2 filters", filterCount: 2

// Collect unique CVEs across software versions
const cves = getVulnerabilities(softwareVersions);
// ["CVE-2024-1234", "CVE-2023-5678"]
```
