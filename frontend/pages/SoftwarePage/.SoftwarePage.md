Serves as the top-level layout and routing container for the Software section, managing tab navigation, team context, automation modals, and query parameter state for all software sub-pages (Inventory, OS, Vulnerabilities, Library).

## Key Components

### Exports
- **`SoftwarePage`** – Main page component wrapping all software sub-routes
- **`softwareSubNav`** – Free-tier tab navigation config (Inventory, OS, Vulnerabilities)
- **`premiumSoftwareSubNav`** – Premium-tier tabs, extends `softwareSubNav` with Library
- **`getTabIndex`** – Resolves active tab index from the current pathname

### Internal State & Hooks
- **`useTeamIdParam`** – Manages team selection and URL sync; removes `self_service` param when switching to All Teams
- **`useQuery` (softwareConfig)** – Fetches global or team-scoped config to drive automation settings
- **Modal toggles** – `showManageAutomationsModal`, `showAddSoftwareModal`, `showSoftwareFiltersModal`, `showPreviewPayloadModal`, `showPreviewTicketModal`

### Key Behaviors
- **Deep-link automation modal** – Opens `ManageAutomationsModal` when `?manage_automations=1` is present in the URL (global admin + All Teams only), then strips the param
- **Library tab guard** – Redirects to Inventory if user is on free tier or has All Teams selected
- **`onApplyVulnFilters`** – Rebuilds query params from vulnerability filter modal and updates the URL via `router.replace`
- **`onAddSoftware`** – Routes to team-scoped add flow or shows the global `AddSoftwareModal`

## Usage Example

```typescript
// Route config (simplified)
<Route path={PATHS.SOFTWARE} component={SoftwarePage}>
  <Route path={PATHS.SOFTWARE_INVENTORY} component={SoftwareInventoryPage} />
  <Route path={PATHS.SOFTWARE_OS} component={SoftwareOSPage} />
  <Route path={PATHS.SOFTWARE_VULNERABILITIES} component={SoftwareVulnerabilitiesPage} />
  <Route path={PATHS.SOFTWARE_LIBRARY} component={SoftwareLibraryPage} />
</Route>

// Deep-link to open automations modal from command palette
router.push(`${PATHS.SOFTWARE}?manage_automations=1`);
```
