Unit test file for `SoftwarePage` tab configuration logic, validating navigation arrays and active tab index resolution for both free and premium tiers.

## Key Components

- **`softwareSubNav`** — Free-tier navigation array containing Inventory, OS, and Vulnerabilities tabs
- **`premiumSoftwareSubNav`** — Premium-tier navigation array extending the free tier with an additional Library tab
- **`getTabIndex`** — Utility function that resolves the active tab index from a given pathname against a nav array

## Test Coverage

| Suite | What's tested |
|---|---|
| `softwareSubNav` (free tier) | Tab names, absence of Library tab, correct `PATHS.SOFTWARE_INVENTORY` pathname |
| `premiumSoftwareSubNav` (premium tier) | Tab names including Library, correct `PATHS.SOFTWARE_LIBRARY` pathname |
| `getTabIndex` | Index resolution for all known paths, alias path (`SOFTWARE_VERSIONS` → index 0), and `-1` fallback for unknown paths |

## Usage Example

```typescript
import { getTabIndex, premiumSoftwareSubNav } from "./SoftwarePage";
import PATHS from "router/paths";

// Resolve which tab should be active for the current route
const activeIndex = getTabIndex(PATHS.SOFTWARE_OS, premiumSoftwareSubNav);
// → 1

// Unknown paths return -1 (no active tab)
const noMatch = getTabIndex("/software/unknown", premiumSoftwareSubNav);
// → -1
```

## Notes

- `SOFTWARE_VERSIONS` is treated as an alias for the Inventory tab (index `0`), meaning version detail routes keep the Inventory tab active
- The Library tab is **premium-only** — it appears in `premiumSoftwareSubNav` but not `softwareSubNav`
