Detail page component for displaying information about a specific software version, accessed at the `software/versions/:id` route. Renders a summary card and vulnerabilities table for the selected version, with team-scoped filtering support.

## Key Components

- **`SoftwareVersionDetailsPage`** — Main page component. Fetches software version details and host count, then renders a summary and vulnerability table.
- **`getVulnUnsupportedSourceText`** — Helper that maps a software source string to a `DisplayPlatform` label (`"Android"`, `"iOS"`, `"iPadOS"`) when vulnerability scanning is unsupported.
- **`renderVulnTable`** — Conditionally renders either a `VulnsNotSupported` notice or a `SoftwareVulnerabilitiesTable` based on the software source.
- **`renderContent`** — Orchestrates the full page layout: loading spinner, error state (`DetailsNoHosts`), or the summary + vulnerabilities cards.

### Data Fetching

| Query | Source | Key Data |
|---|---|---|
| Software version | `softwareAPI.getSoftwareVersion` | Name, version, source, vulnerabilities |
| Host count | `hostsCountAPI.load` | Numeric count scoped to `versionId` |

403/404 errors are silently ignored; other errors are forwarded to the error boundary.

## Usage Example

```typescript
// Rendered automatically via React Router at:
// /software/versions/:id
// Optional query params: ?fleet_id=<teamId>

// Route definition (example)
<Route
  path="/software/versions/:id"
  component={SoftwareVersionDetailsPage}
/>
```

```typescript
// Team context is managed via useTeamIdParam;
// the component reads currentTeamId from the URL and

const { currentTeamId, teamIdForApi, handleTeamChange } = useTeamIdParam({
  location,
  router,

});
```
