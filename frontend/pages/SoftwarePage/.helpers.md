Utility helpers for the Fleet software management UI, providing shared logic for software installers, label targeting, policy merging, and display formatting across software-related components.

## Key Components

### Error Handling
- **`generateSecretErrMsg(err)`** — Transforms raw API errors for secret/variable fields into user-friendly messages, handling install script, post-install script, uninstall script, and profile contexts.

### Install & Target Helpers
- **`getInstallType(softwarePackage)`** — Returns `"automatic"` or `"manual"` based on the presence of `automatic_install_policies`.
- **`getTargetType(softwareInstaller)`** — Returns `"All hosts"` or `"Custom"` based on label configuration.
- **`getCustomTarget(softwareInstaller)`** — Resolves the active label targeting mode: `labelsIncludeAny`, `labelsIncludeAll`, or `labelsExcludeAny`.
- **`generateSelectedLabels(softwareInstaller)`** — Produces a `Record<string, boolean>` map of selected label names for form state initialization.

### UI Content Generators
- **`generateHelpText(automaticInstall, customTarget)`** — Returns contextual JSX help text for label targeting fields.
- **`CUSTOM_TARGET_OPTIONS`** — Static dropdown options array for label targeting mode selection.
- **`getSelfServiceTooltip(isIosOrIpadosApp, isAndroidPlayStoreApp)`** — Returns platform-specific JSX tooltip for the self-service toggle.
- **`getAutoUpdatesTooltip(startTime, endTime)`** — Returns JSX tooltip describing the auto-update window.

### Display Helpers
- **`getDisplayedSoftwareName(name, display_name)`** — Resolves the best display name, preferring `display_name`, then normalizing known titles via `WELL_KNOWN_SOFTWARE_TITLES` (e.g., `microsoft.companyportal` → `"Company Portal"`).
- **`getAutomaticInstallPoliciesCount(softwareTitle)`** — Returns the count of automatic install policies for a title.
- **`isSafeImagePreviewUrl(url)`** — Validates that a URL is safe for image preview (`blob:`, `data:image/png`, `https:`, `http:`).
- **`isAndroidWebApp(androidPlayStoreId)`** — Detects Google enterprise web apps by Play Store ID prefix.

### Policy Merging
- **`mergePolicies({ automaticInstallPolicies, patchPolicy })`** — Merges dynamic (automatic) and patch policies by ID into a unified `ISoftwareInstallPolicyUI[]` array, using a `Set` to track combined policy types.

## Usage Example

```typescript
import {
  getDisplayedSoftwareName,
  mergePolicies,
  getTargetType,
  generateSelectedLabels,
} from "./helpers";

// Resolve display name
const label = getDisplayedSoftwareName("microsoft.companyportal", null);
// → "Company Portal"

// Determine host targeting
const targetType = getTargetType(softwarePackage);
// → "All hosts" | "Custom"

// Build label selection map for form state
const selectedLabels = generateSelectedLabels(softwarePackage);
// → { "macOS": true, "Engineering": true }

// Merge automatic install + patch policies
const policies = mergePolicies({
  automaticInstallPolicies: softwarePackage.automatic_install_policies,
  patchPolicy: softwarePackage.patch_policy,
});
// → ISoftwareInstallPolicyUI[] with type Set(["dynamic", "patch"])
```
