A React page component that handles the preview mode login flow, automatically authenticating users with demo credentials and redirecting them to the dashboard upon mount.

## Key Components

### `LoginPreviewPage`
The default export. A functional React component that:
- **Auto-submits** preview credentials (`admin@example.com` / `preview1337#`) via `useEffect` when `isPreviewMode` is active
- **Authenticates** against `sessionsAPI.login`, persists the auth token via `authToken.save`, and updates global `AppContext` state (`currentUser`, `availableTeams`, `currentTeam`)
- **Redirects** to the dashboard on successful login using the injected `router`

### Interfaces

| Interface | Purpose |
|---|---|
| `ILoginPreviewPageProps` | Expects a v3 `InjectedRouter` instance |
| `ILoginData` | Shape of login form data (`email`, `password`) |

### `onSubmit(formData: ILoginData)`
Async handler that calls the sessions API, saves the token with an optional expiry, updates app context, and pushes to `DASHBOARD`. Errors are caught and logged silently.

## Usage Example

```typescript
// Rendered by the router — no manual instantiation needed
import LoginPreviewPage from "pages/LoginPreviewPage";

// In your route config:
<Route path="/login/preview" component={LoginPreviewPage} />
```

The component renders a brief "Taking you to the Fleet UI..." message during the redirect transition. The `LoginForm` is included in the render tree but is functionally bypassed in preview mode since `onSubmit` fires automatically on mount.
