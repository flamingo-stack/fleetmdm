Utility helper for extracting user-facing error messages during password update operations, falling back to a default message when no specific reason is found.

## Key Components

- **`getErrorMessage(e: unknown): string`** — Parses an unknown error object using `getErrorReason`, checking for the `"Cannot reuse old password"` condition. Returns the specific reason if matched, otherwise returns the default fallback message.

- **`DEFAULT_ERROR_MESSAGE`** — Internal constant: `"Could not update. Please try again."` used as a fallback when no actionable error reason is detected.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await updatePassword({ oldPassword, newPassword });
} catch (e) {
  const message = getErrorMessage(e);
  // Returns "Cannot reuse old password" if that reason is present,
  // otherwise returns "Could not update. Please try again."
  setErrorMessage(message);
}
```
