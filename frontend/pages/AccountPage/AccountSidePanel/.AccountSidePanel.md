A side panel component for the user account page that displays profile information, theme preferences, role/team details, and account actions.

## Key Components

### `AccountSidePanel`
Main exported component that renders the account sidebar with the following sections:

- **Avatar & Gravatar link** — displays the current user's avatar with a link to update it via Gravatar
- **Theme picker** — radio group for switching between `system`, `light`, and `dark` themes, synced with the `fleet-theme-change` custom event
- **DataSets** — displays Fleets (premium only), Role, License expiration (premium only), and Password management
- **API token button** — triggers the parent-provided `onGetApiToken` callback
- **Version info** — fetches and displays Fleet and Go runtime versions via `versionAPI`
- **Privacy policy link**

### Props (`IAccountSidePanelProps`)

| Prop | Type | Description |
|------|------|-------------|
| `currentUser` | `IUser` | The authenticated user object |
| `onChangePassword` | `() => void` | Callback to open the change password flow |
| `onGetApiToken` | `() => void` | Callback to open the API token modal |

## Usage Example

```typescript
<AccountSidePanel
  currentUser={currentUser}
  onChangePassword={() => setShowPasswordModal(true)}
  onGetApiToken={() => setShowApiTokenModal(true)}
/>
```

## Notes

- Theme state is initialized from `getThemeMode()` and kept in sync via a `fleet-theme-change` window event listener, ensuring consistency when the theme is toggled from other surfaces (e.g., command palette or OS media query changes)
- The **Change password** button is disabled when `ssoEnabled` is `true`
- Fleet/team fields are conditionally rendered based on `isPremiumTier` from `AppContext`
