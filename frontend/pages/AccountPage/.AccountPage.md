Renders the user account management page, allowing the current user to update their profile settings, change their email/password, and retrieve their API token.

## Key Components

| Export / Symbol | Type | Description |
|---|---|---|
| `AccountPage` | Default export (React component) | Main page component; orchestrates the settings form and modal dialogs |
| `renderEmailModal` | Internal function | Confirmation modal triggered when a user changes their email address |
| `renderPasswordModal` | Internal function | Modal wrapping `ChangePasswordForm` for password updates |
| `renderApiTokenModal` | Internal function | Modal displaying the current session API token with expiry warning |
| `handleSubmit` | Async handler | Diffs form data against `currentUser`, then calls `usersAPI.update` |
| `handleSubmitPasswordForm` | Async handler | Calls `usersAPI.changePassword` and surfaces success/error flash messages |

## Usage Example

```typescript
import AccountPage from "pages/AccountPage/AccountPage";
import { InjectedRouter } from "react-router";

// Rendered automatically by the Fleet router; requires AppContext and
// NotificationContext providers to be present in the component tree.
const App = ({ router }: { router: InjectedRouter }) => (
  <AppContextProvider>
    <NotificationContextProvider>
      <AccountPage router={router} />
    </NotificationContextProvider>
  </AppContextProvider>
);
```

**Key behaviors:**
- If `formData` email differs from `currentUser.email` and no password is supplied, the email-change confirmation modal is shown before submitting.
- On a successful email update, a pending-email banner is displayed and the SMTP sender address (when configured) is included in the flash message.
- The API token modal warns that session tokens expire and links to the Fleet docs for creating a permanent API-only user.
