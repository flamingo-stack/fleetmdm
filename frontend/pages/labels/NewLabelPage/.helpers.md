Form validation helpers for the New Label page, providing field-level validation logic for label name, description, query, and host vitals criteria.

## Key Components

- **`INewLabelFormValidation`** — Interface describing the validation result shape, with per-field `isValid` flags and optional error messages.
- **`FORM_VALIDATIONS`** — Internal record mapping each form field key to an array of named validation rules with predicates and messages.
- **`validateNewLabelFormData`** — Main exported function that runs all validations against form data and returns a structured `INewLabelFormValidation` result.

### Validation Rules

| Field | Rule | Constraint |
|---|---|---|
| `name` | `required` | Must not be blank |
| `name` | `notTooLong` | Max 255 characters |
| `description` | `notTooLong` | Max 255 characters (optional field) |
| `labelQuery` | `requiredForDynamic` | Required when `type === "dynamic"` |
| `vitalValue` | `requiredForHostVitals` | Required when `type === "host_vitals"` |

## Usage Example

```typescript
import { validateNewLabelFormData } from "./helpers";

const formData = {
  name: "My Label",
  description: "Devices running macOS",
  type: "dynamic",
  labelQuery: "SELECT 1 FROM os_version WHERE platform = 'darwin'",
  vitalValue: "",
};

const validation = validateNewLabelFormData(formData);

if (!validation.isValid) {
  console.error(validation.labelQuery?.message);
  // e.g. "Query text must be present"
}

if (validation.name?.isValid) {
  // Proceed with valid name
}
```
