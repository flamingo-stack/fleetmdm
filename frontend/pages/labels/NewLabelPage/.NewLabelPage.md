React page component for creating new Fleet labels, supporting dynamic (SQL query), manual (host selection), and host vitals label types with form validation, debounced search, and side panel integration.

## Key Components

### `INewLabelFormData`
Interface defining the complete form state shape, covering all three label membership types:
- **dynamic** — `labelQuery`, `platform`
- **host_vitals** — `vital`, `vitalValue`
- **manual** — `targetedHosts`

### `NewLabelPage`
Main page component handling:
- **Form state management** — tracks `formData`, `formErrors`, and `isUpdating`
- **Label type switching** — `onTypeChange` revalidates existing errors on type change
- **Debounced host search** — 500ms debounce via `useDebouncedCallback` for manual label target lookup
- **SQL query validation** — debounced `validateQuery` call on editor change
- **Submit handler** — `onSubmit` calls `labelsAPI.create`, handles 409/422 error codes with specific messages
- **Side panel** — `useToggleSidePanel` controls the `QuerySidePanel` for osquery table reference

### Supporting Utilities
| Import | Role |
|---|---|
| `validateNewLabelFormData` | Per-field and full-form validation |
| `targetsAPI.search` | Host search for manual labels (excludes already-targeted hosts) |
| `idpAPI.getSCIMDetails` | Determines if IdP is configured for host vitals labels |
| `generateTableHeaders` | Table config for manual host target display |

## Usage Example

```typescript
// Rendered via router at /labels/new
<NewLabelPage router={router} location={location} />

// Form data structure consumed by labelsAPI.create:
const formData: INewLabelFormData = {
  name: "macOS 13+",
  description: "Hosts running macOS 13 or later",
  type: "dynamic",
  labelQuery: "SELECT 1 FROM os_version WHERE major >= 13;",
  platform: "darwin",
  vital: "end_user_idp_group",
  vitalValue: "",
  targetedHosts: [],
};
```
