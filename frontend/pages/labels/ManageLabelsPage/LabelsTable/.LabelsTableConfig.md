Configuration module for the Labels data table, defining column headers, action dropdown options, and dataset generation for displaying and managing Fleet labels.

## Key Components

### `hasEditPermission(currentUser, label)`
Evaluates whether the current user has permission to edit or delete a label. Returns `true` for global admins, maintainers, technicians, the label's author (if team-scoped), or users with team-level admin/maintainer/technician roles matching the label's team.

### `generateActionDropdownOptions(currentUser, label, labelsGitOpsManaged, repoURL?)`
Builds the context-sensitive actions dropdown for each label row. Always includes **"View all hosts"**; conditionally appends **"Edit"** (excluded for `host_vitals` labels) and **"Delete"** (disabled with a GitOps tooltip when GitOps-managed) based on the user's permissions.

### `generateTableHeaders(currentUser, onClickAction, labelsGitOpsManaged?, repoURL?)`
Returns the full column definition array for the labels table with four columns:
- **Name** — sortable, truncated with tooltip
- **Description** — truncated with tooltip
- **Type** — maps `label_membership_type` to display copy
- **Actions** — per-row `ActionsDropdown` wired to `onClickAction`

### `generateDataSet(labels)`
Filters the raw labels array, excluding built-in (`builtin`) labels from the table view.
