Renders a paginated, sortable table of Fleet MDM labels with support for GitOps-managed label display and per-row action callbacks.

## Key Components

- **`LabelsTable`** – Memoized React component that composes `TableContainer` with label-specific column configs and dataset.
- **`ILabelsTable`** – Props interface defining labels array, action handler, current user context, and optional GitOps/repo settings.
- **`generateTableHeaders`** – Imported utility that builds column definitions based on user permissions, action handler, and GitOps state.
- **`generateDataSet`** – Imported utility that transforms `ILabel[]` into the row data format expected by `TableContainer`.

## Usage Example

```typescript
import LabelsTable from "pages/labels/components/LabelsTable";

<LabelsTable
  labels={labelsData}
  currentUser={currentUser}
  onClickAction={(action, label) => {
    if (action === "edit") handleEditLabel(label);
    if (action === "delete") handleDeleteLabel(label);
  }}
  labelsGitOpsManaged={true}
  repoURL="https://github.com/flamingo-stack/fleetmdm"
/>
```

## Behavior Notes

- Defaults to ascending sort by `name`.
- Client-side pagination is enabled via `isClientSidePagination`.
- Displays a `TableCount` badge when rows exist; renders an `EmptyState` ("No labels") when the dataset is empty.
- `labelsGitOpsManaged` and `repoURL` are forwarded to `generateTableHeaders` to conditionally render GitOps-aware column controls (e.g., disabling edit/delete actions for repo-managed labels).
