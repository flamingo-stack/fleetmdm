A form field component for selecting or displaying an OS platform (macOS, Windows, Ubuntu, CentOS) in both editable and read-only modes.

## Key Components

- **`PlatformField`** — Default export. Renders either a `DropdownWrapper` (edit mode) or a static `FormField` (read-only mode) depending on the `isEditing` prop.
- **`PLATFORM_STRINGS`** — Internal map translating platform keys (e.g., `darwin`) to display labels (e.g., `macOS`).
- **`platformOptions`** — Predefined dropdown options including an "All platforms" catch-all with an empty string value.
- **`IPlatformFieldProps`** — Interface defining the component's props.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `platform` | `string` | — | Current platform value (e.g., `"darwin"`, `"windows"`) |
| `isEditing` | `boolean` | `false` | Toggles between dropdown and read-only display |
| `onChange` | `(platform: string) => void` | `noop` | Callback fired when the dropdown selection changes |

## Usage Example

```typescript
import PlatformField from "components/forms/fields/PlatformField";

// Editable dropdown
<PlatformField
  platform="darwin"
  isEditing={false}
  onChange={(newPlatform) => console.log(newPlatform)}
/>

// Read-only display (shows "macOS")
<PlatformField
  platform="darwin"
  isEditing={true}
/>

// "All platforms" state (empty string value)
<PlatformField
  platform=""
  isEditing={false}
  onChange={(val) => setPlatform(val)}
/>
```
