A React form component for creating or editing Fleet MDM labels, handling name/description input with real-time validation and immutable field messaging.

## Key Components

### Interfaces

- **`ILabelFormData`** — Shape of the form's output data (`name`, `description`)
- **`ILabelFormProps`** — Component props including default values, immutable field config, and callbacks

### Helpers

- **`generateDescriptionHelpText(immutableFields)`** — Generates grammatically correct help text listing immutable fields (handles 0, 1, 2, and Oxford-comma 3+ item cases)

### State & Handlers

| Handler | Behavior |
|---|---|
| `onFormChange` | Updates state on input change; only **clears** existing errors if field becomes valid (never sets new errors mid-type) |
| `onInputBlur` | Runs full validation when a field loses focus, surfacing all errors |
| `onSubmitForm` | Triggers full validation on submit; calls `onSave` with data and validity flag |

## Usage Example

```typescript
import LabelForm, { ILabelFormData } from "components/forms/LabelForm";

const handleSave = (formData: ILabelFormData, isValid: boolean) => {
  if (!isValid) return;
  console.log("Saving label:", formData);
};

<LabelForm
  defaultName="macOS devices"
  defaultDescription="All macOS endpoints"
  teamName="Engineering"
  immutableFields={["query", "platform"]}
  isUpdatingLabel={false}
  onSave={handleSave}
  onCancel={() => console.log("Cancelled")}
/>
```

## Notes

- Errors are shown **on blur** and on **submit**, but cleared immediately as the user corrects a field (no premature error-on-type UX)
- The Save button is disabled when the form is invalid or when GitOps mode is active (via `GitOpsModeTooltipWrapper`)
- `additionalFields` accepts any `ReactNode` for extending the form with custom fields
