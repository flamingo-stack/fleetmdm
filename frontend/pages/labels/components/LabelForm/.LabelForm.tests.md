Test suite for the `LabelForm` component, validating form behavior including field validation, data submission, additional field rendering, and immutable field help text display.

## Key Components

- **`renderWithSetup`** — Custom test utility providing a `user` event object for simulating interactions
- **`LabelForm`** — Component under test, accepting `onSave`, `onCancel`, `teamName`, `immutableFields`, and `additionalFields` props

## Test Cases

| Test | Description |
|------|-------------|
| Name validation | Ensures the name field is required and shows/clears the error message appropriately |
| Additional fields | Verifies `additionalFields` prop renders arbitrary form elements |
| Form submission | Confirms `onSave` is called with correct `{ name, description }` payload and a `true` flag on valid submit |
| No immutable fields | Confirms help text is absent when `immutableFields` is empty |
| Single immutable field | Checks singular help text (e.g., `"Label fleets are immutable..."`) |
| Two immutable fields | Checks Oxford-style join (`"queries and platforms"`) in help text |
| Three immutable fields | Checks Oxford comma join (`"fleets, queries, and platforms"`) in help text |

## Usage Example

```typescript
// Render LabelForm in a test with user interaction
const { user } = renderWithSetup(
  <LabelForm
    onSave={jest.fn()}
    onCancel={jest.fn()}
    teamName="Example Fleet"
    immutableFields={["fleets", "queries"]}
  />
);

await user.type(screen.getByLabelText("Name"), "My Label");
await user.click(screen.getByRole("button", { name: "Save" }));
```
