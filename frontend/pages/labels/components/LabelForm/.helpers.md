Provides form validation logic for the Label form, defining validation rules and returning structured field-level error results.

## Key Components

- **`ILabelFormValidation`** — Interface describing the validation result shape, with optional per-field `isValid` and `message` properties.
- **`FORM_VALIDATIONS`** — Static map of validation rules per form field:
  - `name`: required, max 255 characters
  - `description`: max 255 characters (optional field)
- **`validateLabelFormData`** — Main exported function that runs all validations against the provided form data and returns an `ILabelFormValidation` result.

## Usage Example

```typescript
import { validateLabelFormData } from "./helpers";

const formData = {
  name: "My Label",
  description: "A short description",
};

const validation = validateLabelFormData(formData);

if (!validation.isValid) {
  if (!validation.name?.isValid) {
    console.error(validation.name?.message); // e.g. "Label name must be present"
  }
  if (!validation.description?.isValid) {
    console.error(validation.description?.message);
  }
}
```

## Notes

- Character limits (`MAX_LABEL_NAME_LENGTH`, `MAX_LABEL_DESCRIPTION_LENGTH`) are both set to **255**, matching the database column constraints.
- Validation messages can be static strings or dynamic functions receiving `formData`.
- The switch statements use an exhaustive check (`never`) to catch unhandled field keys at compile time, ensuring safety when new fields are added.
