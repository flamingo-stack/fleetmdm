Form component for creating and editing dynamic (query-based) labels in Fleet MDM, combining SQL query input with platform selection and label metadata fields.

## Key Components

### Interfaces

- **`IDynamicLabelFormData`** — Shape of the submitted form data: `name`, `description`, `query`, and `platform`
- **`IDynamicLabelFormProps`** — Component props including defaults, edit mode flags, sidebar controls, and save/cancel callbacks

### Internal State

| State | Type | Purpose |
|---|---|---|
| `query` | `string` | Current SQL query string |
| `platform` | `string` | Selected target platform |
| `queryError` | `string \| null` | Debounced SQL validation error |

### Key Behaviors

- **Debounced SQL validation** — Uses `useDebouncedCallback` (500ms) to validate the query via `validateQuery` as the user types, surfacing errors without blocking input
- **Composed save flow** — `onSaveForm` validates SQL and delegates name/description validation to the child `LabelForm`, only calling `onSave` when both pass
- **Osquery table links** — Hooks into the Ace editor's `linkClick` event to trigger `onOsqueryTableSelect` when a user clicks an `osquery-token` in the editor
- **Conditional schema button** — Renders a sidebar toggle button only when `showOpenSidebarButton` is `true`
- **Immutable fields** — When `teamName` is set, locks `fleets`, `queries`, and `platforms` fields; otherwise locks only `queries` and `platforms`

## Usage Example

```typescript
<DynamicLabelForm
  defaultName="Linux servers"
  defaultQuery="SELECT * FROM os_version WHERE platform = 'linux';"
  defaultPlatform="linux"
  teamName={null}
  isEditing={false}
  showOpenSidebarButton
  onOpenSidebar={() => setSidebarOpen(true)}
  onOsqueryTableSelect={(table) => console.log("Selected:", table)}
  onSave={(formData) => dispatch(saveLabel(formData))}
  onCancel={() => router.push("/labels")}
/>
```
