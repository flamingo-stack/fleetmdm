A read-only form field component that displays a Fleet (team) name label within a styled form field wrapper.

## Key Components

- **`ITeamNameFieldProps`** — Interface defining the component's props:
  - `name: string` — The Fleet/team name to display
- **`TeamNameField`** — Default export; renders a `FormField` with the label `"Fleet"` and displays the provided `name` as static text

## Usage Example

```typescript
import TeamNameField from "components/forms/fields/TeamNameField";

const MyForm = () => (
  <TeamNameField name="Engineering Team" />
);
```

## Notes

- The field is **read-only** — it renders `name` inside a `<p>` tag rather than an `<input>`, making it purely display-oriented
- The underlying `FormField` uses the fixed field name `"fleet_name"` and label `"Fleet"` regardless of props passed
- Useful for displaying the associated team/fleet context within a form without allowing user edits
