Generates the column configuration for the label host target input table, defining headers for host display name, hostname, and serial number with an optional row-removal action.

## Key Components

- **`ITargestInputHostTableConfig`** — Type alias for `Column<IHost>`, representing a single column definition for the host table.
- **`generateTableHeaders(handleRowRemove?)`** — Factory function that returns an array of react-table column configs. Accepts an optional `handleRowRemove` callback; when provided, appends a delete column rendering a close-filled icon button that triggers row removal.

## Usage Example

```typescript
import { generateTableHeaders } from "./LabelHostTargetTableConfig";

// Without delete column
const readOnlyColumns = generateTableHeaders();

// With delete column
const editableColumns = generateTableHeaders((row) => {
  console.log("Removing host:", row.original.id);
});
```

## Column Definitions

| Column | Accessor | Description |
|---|---|---|
| Host | `display_name` | Human-readable host name |
| Hostname | `hostname` | Machine hostname |
| Serial number | `hardware_serial` | Device hardware serial |
| *(delete)* | — | Conditionally rendered close button |

## Notes

- The delete column includes `disableHidden: true`, preventing it from being toggled off in column visibility controls.
