A React form component for creating manual labels by searching for and selecting specific hosts, extending the base `LabelForm` with host-targeting functionality.

## Key Components

### Interfaces

- **`IManualLabelFormData`** — Form submission payload containing `name`, `description`, and `targetedHosts` (`IHost[]`)
- **`IManualLabelFormProps`** — Component props including optional defaults, `teamName`, `onSave`, and `onCancel` callbacks

### Constants

- **`LABEL_TARGET_HOSTS_INPUT_LABEL`** — Exported label string for the host search input (`"Select hosts"`)
- **`DEBOUNCE_DELAY`** — Search debounce interval (500ms)

### Core Behavior

- **Debounced host search** — Uses `useDebouncedCallback` to delay API calls by 500ms as the user types
- **`useQuery` (targets API)** — Fetches matching hosts via `targetsAPI.search`, automatically excluding already-selected host IDs
- **Host selection state** — Manages `targetedHosts` array; supports adding via `onHostSelect` and removing via `onHostRemove`
- **`generateTableHeaders`** — Builds table configs for both search results and selected hosts views

## Usage Example

```typescript
import ManualLabelForm, {
  IManualLabelFormData,
} from "components/ManualLabelForm";

<ManualLabelForm
  defaultName="My Label"
  defaultDescription="Hosts in building A"
  defaultTargetedHosts={[]}
  teamName="Engineering"
  onSave={(formData: IManualLabelFormData) => {
    console.log(formData.name, formData.targetedHosts);
  }}
  onCancel={() => setShowForm(false)}
/>
```
