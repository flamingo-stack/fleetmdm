Test suite for the `ManualLabelForm` component, verifying rendering behavior and form submission with valid data.

## Key Components

- **`ManualLabelForm`** — The component under test, imported alongside the `LABEL_TARGET_HOSTS_INPUT_LABEL` constant
- **`createCustomRenderer`** — Test utility that sets up a custom renderer with optional backend mock support
- **`createMockHost`** — Factory function that generates mock host data for use in test scenarios

## Test Cases

| Test | Description |
|------|-------------|
| Renders Select Hosts input | Asserts the host selection input is present using the exported label constant |
| Submits valid form data | Simulates user input and verifies `onSave` is called with the correct payload |

## Usage Example

```typescript
import { createCustomRenderer } from "test/test-utils";
import createMockHost from "__mocks__/hostMock";
import ManualLabelForm from "./ManualLabelForm";

const render = createCustomRenderer({ withBackendMock: true });

// Render with pre-populated hosts
const { user } = render(
  <ManualLabelForm
    onSave={(data) => console.log(data)}
    onCancel={() => {}}
    defaultTargetedHosts={[createMockHost()]}
    teamName={null}
  />
);

// Simulate form interaction
await user.type(screen.getByLabelText("Name"), "My Label");
await user.click(screen.getByRole("button", { name: "Save" }));
// onSave receives: { name, description, targetedHosts }
```

## Notes

- Uses `withBackendMock: true` to support async API interactions during tests
- The `onSave` callback receives a structured payload: `{ name, description, targetedHosts }`
