Parses API error responses for label deletion operations and returns human-readable error messages based on the HTTP status code and error reason.

## Key Components

### `getDeleteLabelErrorMessages(error: unknown): string`

The sole export of this module. Accepts an unknown error object and maps it to a user-friendly message using the following logic:

- **Status `422` + `"built-in"` reason** → Informs the user that built-in labels cannot be modified or deleted.
- **Status `422` + `"configuration profile"` reason** → Prompts the user to remove the targeting profile before deleting.
- **Status `422` + any other reason** → Indicates the label is used as a software custom target.
- **Any other error** → Returns a generic fallback deletion failure message.

## Usage Example

```typescript
import getDeleteLabelErrorMessages from "./helpers";

try {
  await deleteLabel(labelId);
} catch (error) {
  const message = getDeleteLabelErrorMessages(error);
  renderErrorToast(message);
}
```
