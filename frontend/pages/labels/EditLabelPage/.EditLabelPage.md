Renders the edit label page, allowing users to update dynamic or manual labels by fetching the label's current data and conditionally rendering the appropriate form based on label membership type.

## Key Components

- **`EditLabelPage`** — Default export. Main page component that orchestrates label fetching, permission checking, and form rendering.
- **`onUpdateLabel`** — Submits label update to the API, invalidates related React Query caches on success, and surfaces contextual error messages for `409`/`422` status codes.
- **`onCancelEdit`** — Navigates the user back to the previous route.
- **`renderContent`** — Conditionally renders a `Spinner`, `DataError`, `DynamicLabelForm`, or `ManualLabelForm` based on loading state, error state, and label type.

## Key Behaviors

- Redirects to `MANAGE_LABELS` if the label is of type `host_vitals` (not editable) or if the current user lacks edit permission.
- Fetches hosts in the label only when `label_membership_type === "manual"` (query is disabled otherwise).
- Built-in labels render a non-editable `DataError` message instead of a form.

## Usage Example

This page is route-mounted and receives params automatically via the router:

```typescript
// router/paths.ts (example route registration)
<Route
  path={PATHS.EDIT_LABEL}
  component={EditLabelPage}
/>
```

```typescript
// Navigating to the edit page programmatically
router.push(PATHS.EDIT_LABEL_BY_ID(labelId));
```

The component reads `routeParams.label_id`, parses it to an integer, and manages all data fetching and form state internally. No props beyond router-injected values are required.
