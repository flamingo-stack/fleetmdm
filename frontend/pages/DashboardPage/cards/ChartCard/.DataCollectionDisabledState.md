Renders an empty state UI when a data collection feature is disabled, prompting users to enable it or directing admins to the appropriate settings page.

## Key Components

- **`DataCollectionDisabledState`** — Default export. A React functional component that displays a disabled-state message with a contextual call-to-action based on the user's role and team scope.
- **`IDataCollectionDisabledStateProps`** — Interface defining component props:
  - `datasetLabel` (`string`) — Human-readable name of the disabled dataset shown in the message.
  - `currentTeamId` (`number`, optional) — If provided, scopes the message and settings navigation to a specific team/fleet.
- **`canAccessSettings`** — Derived boolean controlling whether the "Turn on" button renders. Global admins always have access; team admins only when a `currentTeamId` is present.

## Usage Example

```typescript
import DataCollectionDisabledState from "components/DataCollectionDisabledState";

// Global scope (no team) — only global admins see the button
<DataCollectionDisabledState
  datasetLabel="Software inventory"
/>

// Team-scoped — global and team admins see the button;
// clicking navigates to that team's fleet settings
<DataCollectionDisabledState
  datasetLabel="Vulnerability data"
  currentTeamId={42}
/>
```

When `canAccessSettings` is `true`, a **"Turn on"** button navigates to:
- `paths.FLEET_DETAILS_SETTINGS(currentTeamId)` — for team-scoped views
- `paths.ADMIN_ORGANIZATION_ADVANCED` — for global scope

Non-admin users see a plain message: *"Ask an admin to turn on [datasetLabel]..."* with no button rendered.
