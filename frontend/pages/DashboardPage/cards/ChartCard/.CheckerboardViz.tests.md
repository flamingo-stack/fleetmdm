Test suite for the `CheckerboardViz` React component, validating cell rendering, color level classification, relative/fixed scale behavior, and data trimming logic using mocked browser APIs.

## Key Components

- **`generateData(numDays, percentage)`** — Helper that produces `IFormattedDataPoint[]` arrays with 12 two-hour slots per day for use across test cases.
- **`MockResizeObserver`** — Stub replacing `global.ResizeObserver` to simulate a non-zero container width (`600px`) in jsdom, enabling layout-dependent rendering.
- **`beforeAll` / `afterAll` hooks** — Install and restore `MockResizeObserver` and `Element.prototype.getBoundingClientRect` overrides.

## Test Cases

| Test | What it verifies |
|------|-----------------|
| Correct cell count (3 days) | `3 days × 12 slots = 36 rect` elements rendered |
| Level-0 class for 0% | All cells get `--level-0` when data is zero |
| Color level classes by percentage | Percentages 10–90 map to `--level-1` through `--level-5` |
| `relativeScale` color ramp | Fixed scale collapses low values; `relativeScale` spreads them across all five levels |
| Zero excluded from relative min | `0%` cells stay `--level-0` and don't compress the ramp's lower bound |
| Single distinct value on relative scale | When `min === max`, all non-zero cells render at `--level-5` instead of collapsing |
| Leading-day trimming | Extra leading day is dropped; grid shows exactly `selectedDays` columns |

## Usage Example

```typescript
import { renderWithSetup } from "test/test-utils";
import CheckerboardViz from "./CheckerboardViz";

const data = generateData(14); // 14 days × 12 slots

renderWithSetup(
  <CheckerboardViz
    data={data}
    selectedDays={14}
    relativeScale // optional: stretch color ramp to dataset min/max
  />
);
```
