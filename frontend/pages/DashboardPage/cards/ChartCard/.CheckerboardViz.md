Renders a 2D checkerboard-style heatmap grid visualizing host activity data across days and time slots, with responsive scaling, horizontal scroll, hover tooltips, and support for both fixed-percentage and relative color ramps.

## Key Components

### Component

- **`CheckerboardViz`** — Main React component accepting activity data, time window selection, theme, and optional tooltip formatter; renders an SVG cell grid with y-axis labels, x-axis date markers, and a floating tooltip on cell hover.

### Interfaces

- **`ICellData`** — Internal cell descriptor holding grid position (`dayIndex`, `hourRow`), display values (`value`, `percentage`, `total`), and human-readable labels (`dayLabel`, `hourLabel`).
- **`ICheckerboardVizProps`** — Component prop contract: `data`, `selectedDays`, `theme`, `tooltipFormatter`, `relativeScale`.

### Key Constants

| Constant | Value | Purpose |
|---|---|---|
| `CELL_W` | `16.75` | Base cell width in px |
| `CELL_H` | `19` | Base cell height in px |
| `WIDE_THRESHOLD` | `700` | Container width triggering 1.5× scale-up |
| `Y_AXIS_WIDTH` | `40` | Left margin reserved for y-axis labels |

### Internal Helpers

- **`formatHourLabel(hourVal)`** — Converts a 0–23 integer to a 12-hour AM/PM string (e.g., `6` → `"6am"`, `18` → `"6pm"`).
- **`getColorLevel(cell)`** — Returns a 0–5 color intensity level; operates in fixed-percentage mode (0/20/40/60/80%) or relative min-max mode when `relativeScale` is `true`.

## Usage Example

```typescript
import CheckerboardViz from "components/CheckerboardViz";
import { IFormattedDataPoint } from "interfaces/charts";

const activityData: IFormattedDataPoint[] = [
  { timestamp: "2024-06-01T06:00:00Z", value: 42, total: 100, percentage: 42 },
  { timestamp: "2024-06-01T12:00:00Z", value: 78, total: 100, percentage: 78 },
  // ...
];

// 7-day grid with green theme and relative color scaling
<CheckerboardViz
  data={activityData}
  selectedDays={7}
  theme="green"
  relativeScale={true}
  tooltipFormatter={(cell) => `${cell.value} hosts at ${cell.hourLabel}`}
/>
```
