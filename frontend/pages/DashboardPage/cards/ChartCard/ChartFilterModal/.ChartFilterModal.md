A modal component for configuring chart data filters, allowing users to filter by labels, platforms, and individual hosts (via exclude or include modes) with debounced search and infinite scroll.

## Key Components

### `IChartFilterState`
Exported interface representing the filter state shape:
- `labelIDs` — selected label IDs
- `platforms` — selected platform strings (e.g., `"darwin"`, `"windows"`)
- `hostFilterMode` — `"none"` | `"include"` | `"exclude"`
- `selectedHosts` — array of individually selected `IHost` objects

### `ChartFilterModal`
Default export. Renders a `Modal` with three filter sections:
- **Labels dropdown** — multi-select, searchable, sourced from `labelsAPI.summary()` (builtin labels excluded)
- **Platforms dropdown** — multi-select from static `PLATFORM_OPTIONS` (macOS, Windows, Linux, ChromeOS)
- **Host tabs** — tabbed UI switching between "Exclude hosts" and "Specific hosts" modes, each rendering a debounced search field with infinite-scroll host list and pill-style selected host badges

Key internal behaviors:
- Debounced search (300 ms) via `useDebouncedCallback`
- Infinite scroll implemented by incrementing `pageCount`, fetching `pageCount * PAGE_SIZE` hosts per request with `keepPreviousData`
- Shared `listRef` avoided across tabs by only rendering the active tab's host list

## Usage Example

```typescript
import ChartFilterModal, { IChartFilterState } from "./ChartFilterModal";

const defaultFilters: IChartFilterState = {
  labelIDs: [],
  platforms: [],
  hostFilterMode: "none",
  selectedHosts: [],
};

<ChartFilterModal
  filters={defaultFilters}
  currentTeamId={42}
  onApply={(filters) => console.log("Applied filters:", filters)}
  onCancel={() => setModalOpen(false)}
/>
```
