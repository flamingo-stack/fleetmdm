A reusable Recharts line chart component for visualizing time-series percentage data (e.g., host compliance rates) with dynamic X-axis formatting based on the selected time range.

## Key Components

- **`LineChartViz`** — Default export. Renders a responsive `LineChart` with a styled tooltip, percentage Y-axis, and adaptive X-axis tick formatting.
- **`ILineChartVizProps`** — Props interface accepting `data: IFormattedDataPoint[]` and `selectedDays: number`.
- **`formatXAxis`** — Memoized callback that formats ISO timestamps as `ha` (e.g., `3pm`) for 1-day views or `MMM d` (e.g., `Jun 4`) for multi-day views.
- **`renderTooltip`** — Custom Recharts tooltip displaying the data point's label and formatted value (percentage + host count).
- **`LINE_STROKE`** — Uses the `--core-vibrant-blue` CSS design token so the chart line inherits the active theme color.

## Usage Example

```typescript
import LineChartViz from "components/LineChartViz";
import { IFormattedDataPoint } from "interfaces/charts";

const data: IFormattedDataPoint[] = [
  {
    timestamp: "2024-06-01T00:00:00Z",
    label: "Jun 1",
    percentage: 82,
    value: 1640,
  },
  {
    timestamp: "2024-06-02T00:00:00Z",
    label: "Jun 2",
    percentage: 87,
    value: 1740,
  },
];

const MyChart = () => (
  <LineChartViz data={data} selectedDays={7} />
);
```

> **Note:** The component auto-throttles X-axis tick density to a maximum of ~8 labels via `tickInterval = Math.max(1, Math.floor(data.length / 8))`, preventing label crowding on large datasets.
