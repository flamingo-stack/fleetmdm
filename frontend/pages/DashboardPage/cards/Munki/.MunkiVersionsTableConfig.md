Defines the column configuration for the Munki versions table, specifying headers and cell renderers for displaying Munki version distribution across hosts.

## Key Components

- **`munkiVersionsTableHeaders`** — Array of column definitions for use with `react-table`, exported as the default export
- **`ICellProps`** — Interface typing cell and row props passed by `react-table`'s `useTable` hook
- **Columns defined:**
  - `version` — Displays the Munki version string
  - `hosts_count` — Displays the number of hosts running that version

## Usage Example

```typescript
import munkiVersionsTableHeaders from "./MunkiVersionsTableConfig";
import TableContainer from "components/TableContainer";

const MunkiVersionsTable = ({ munkiData }) => (
  <TableContainer
    columns={munkiVersionsTableHeaders}
    data={munkiData}
  />
);
```

## Notes

- Both columns have `disableSortBy: true` — sorting is not supported
- Cells render via the shared `TextCell` component for consistent text display
- Row data is typed against `IMacadminsResponse` from the host interfaces
