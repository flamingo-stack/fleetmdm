Generates the column configuration for the Munki Issues data table, defining headers, accessors, and cell renderers for displaying aggregated Munki issue data across hosts.

## Key Components

- **`generateMunkiIssuesTableHeaders(teamId?)`** — Factory function that returns an array of `IDataColumn` definitions for the Munki Issues table. Accepts an optional `teamId` to scope the "View All Hosts" links.
- **`ICellProps`** — Typed interface for react-table cell props, bound to `IMunkiIssuesAggregate` row data.
- **`IHeaderProps`** — Typed interface for react-table header props, supporting sort direction state.
- **`IDataColumn`** — Column definition shape consumed by the shared `TableContainer`.

### Columns Defined

| Accessor | Title | Sortable | Notes |
|---|---|---|---|
| `name` | Issue | ❌ | Tooltip on hover via `TooltipTruncatedTextCell`; header has tooltip explaining Munki run context |
| `type` | Type | ❌ | Capitalizes value via lodash `capitalize` |
| `hosts_count` | Hosts | ✅ | Supports sort direction indicator |
| `linkToFilteredHosts` | *(empty)* | ❌ | Renders `ViewAllHostsLink` filtered by `munki_issue_id` and optional `fleet_id` |

## Usage Example

```typescript
import generateMunkiIssuesTableHeaders from "./MunkiIssuesTableConfig";

// Without team scoping
const columns = generateMunkiIssuesTableHeaders();

// Scoped to a specific team
const teamColumns = generateMunkiIssuesTableHeaders(42);

// Pass to TableContainer
<TableContainer
  columns={teamColumns}
  data={munkiIssues}
/>
```
