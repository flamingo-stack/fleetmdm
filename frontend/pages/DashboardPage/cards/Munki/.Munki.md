A React card component that displays Munki MDM data in a tabbed interface, showing both Munki issues and Munki versions aggregated across macOS hosts.

## Key Components

- **`Munki`** — Default export. A functional component rendering a two-tab card for the home dashboard.
  - **Issues tab** — Displays `IMunkiIssuesAggregate[]` data with dynamically generated column headers (team-aware via `selectedTeamId`).
  - **Versions tab** — Displays `IMunkiVersionsAggregate[]` data with static column headers from `MunkiVersionsTableConfig`.
- **`IMunkiCardProps`** — Props interface defining:
  - `errorMacAdmins` — Error state from the MacAdmins API call.
  - `isMacAdminsFetching` — Loading state; triggers a `Spinner` overlay and opacity fade.
  - `munkiIssuesData` / `munkiVersionsData` — Aggregated table data.
  - `selectedTeamId` — Optional team filter passed to issues table header generator.

## Behavior Notes

- Renders a `Spinner` while fetching; content fades in via inline `opacity` style.
- Displays `TableDataError` in either tab if `errorMacAdmins` is set.
- Empty states differ by tab: issues show a "no issues" message; versions prompt users to deploy `fleetd`.
- Table is client-side paginated with a page size of 8, sorted descending by `hosts_count`.

## Usage Example

```typescript
import Munki from "./Munki";

<Munki
  errorMacAdmins={null}
  isMacAdminsFetching={false}
  munkiIssuesData={issuesAggregateArray}
  munkiVersionsData={versionsAggregateArray}
  selectedTeamId={42}
/>
```
