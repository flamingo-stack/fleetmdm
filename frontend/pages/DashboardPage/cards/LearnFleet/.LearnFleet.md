A React component that renders a brief introduction to Fleet's features with a link to the official Fleet documentation.

## Key Components

- **`LearnFleet`** – Functional component that displays a short descriptive paragraph and an external link directing users to Fleet's "Learn how to use Fleet" documentation page.
- **`CustomLink`** – Reusable link component used to render the external documentation URL, opening in a new tab.

## Usage Example

```typescript
import LearnFleet from "components/LearnFleet";

const Dashboard = () => (
  <div>
    <LearnFleet />
  </div>
);
```

## Notes

- Applies the BEM-style base class `learn-fleet` for styling, with `learn-fleet__action-button` scoped to the link element.
- The documentation link targets `https://fleetdm.com/docs/using-fleet/learn-how-to-use-fleet` and always opens in a new tab (`newTab` prop).
