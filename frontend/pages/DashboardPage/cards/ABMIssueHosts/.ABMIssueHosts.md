Renders a card displaying the count of hosts with Apple Business Manager (ABM) profile assignment issues, linking to a filtered host management view.

## Key Components

- **`IABMIssueHostsProps`** — Interface defining props: `abmIssueCount` (number of affected hosts), optional `selectedPlatformLabelId` (filters by platform label), and optional `currentTeamId` (scopes results to a team).
- **`abmIssueTooltip`** — Exported helper that returns a `<span>` describing the ABM issue context for use in the card's tooltip.
- **`ABMIssueHosts`** — Default export; builds a URL to `MANAGE_HOSTS` (or `MANAGE_HOSTS_LABEL` if a platform label is selected) with `dep_profile_error=true` and `fleet_id` query params, then renders a `HostCountCard`.

## Usage Example

```typescript
import ABMIssueHosts from "./ABMIssueHosts";

<ABMIssueHosts
  abmIssueCount={12}
  selectedPlatformLabelId={3}
  currentTeamId={1}
/>
```

The rendered card links to:

```text
/hosts/manage/labels/3?dep_profile_error=true&fleet_id=1
```

## Notes

- When `selectedPlatformLabelId` is omitted, the link targets the global `/hosts/manage` route.
- When `currentTeamId` is omitted, the `fleet_id` query param is excluded from the URL.
- The tooltip is exported separately (`abmIssueTooltip`) so it can be reused outside the card if needed.
