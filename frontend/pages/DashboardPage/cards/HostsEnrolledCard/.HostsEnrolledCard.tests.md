Test suite for the `HostsEnrolledCard` component, validating the `formatPercent` utility and the component's rendering behavior within a jsdom environment that lacks real browser layout capabilities.

## Key Components

- **`MockResizeObserver`** — Stubs the browser `ResizeObserver` API, injecting fixed dimensions (`600×250`) so Recharts' `ResponsiveContainer` can render its SVG in jsdom.
- **`formatPercent` tests** — Unit tests for the exported utility covering three edge cases: normal rounding, sub-`0.1%` nonzero shares, and true zero counts.
- **`HostsEnrolledCard` render test** — Integration-style render test asserting the card title and all seven platform labels (`macOS`, `Windows`, `Linux`, `ChromeOS`, `iOS`, `iPadOS`, `Android`) appear in the DOM.

## Usage Example

```typescript
// Run the full test suite
// npx jest HostsEnrolledCard.tests.tsx

// formatPercent edge cases tested:
expect(formatPercent(21925, 99.16)).toBe("99.2%");  // normal rounding
expect(formatPercent(5, 0.02)).toBe("<0.1%");        // nonzero below threshold
expect(formatPercent(0, 0)).toBe("0.0%");            // true zero

// Component render assertion pattern used in the suite:
render(
  <HostsEnrolledCard
    counts={counts}
    totalHostCount={22070}
    router={noopRouter}
  />
);
expect(screen.getByText("Hosts enrolled")).toBeInTheDocument();
```

## Notes

- `getBoundingClientRect` is monkey-patched in `beforeAll` and restored in `afterAll` to avoid test pollution.
- The `noopRouter` satisfies the `InjectedRouter` prop type without requiring a full React Router context.
