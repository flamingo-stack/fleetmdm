Barrel export file that re-exports the `HostsEnrolledCard` component and its associated `IHostPlatformCounts` type from the local module.

## Key Components

- **`HostsEnrolledCard`** — Default export of the card component displaying enrolled host counts.
- **`IHostPlatformCounts`** — TypeScript interface describing platform-specific host count data.

## Usage Example

```typescript
import { HostsEnrolledCard } from "./HostsEnrolledCard";
import type { IHostPlatformCounts } from "./HostsEnrolledCard";

const counts: IHostPlatformCounts = {
  darwin: 42,
  windows: 18,
  linux: 7,
};

<HostsEnrolledCard platformCounts={counts} />;
```
