A dashboard card component that renders a horizontal bar chart of enrolled host counts broken down by platform (macOS, Windows, Linux, ChromeOS, iOS, iPadOS, Android) using Recharts.

## Key Components

- **`HostsEnrolledCard`** — Main component rendering the responsive bar chart. Clicking a bar or Y-axis label navigates to the filtered hosts list for that platform.
- **`HostsEnrolledTooltip`** — Custom Recharts tooltip displaying platform name, host count, and percentage of fleet.
- **`ClickableYAxisTick`** — Custom Y-axis tick that renders as a clickable label when a matching built-in label exists for the platform.
- **`formatPercent`** — Formats a platform's fleet share; returns `"<0.1%"` for nonzero counts that round to zero.
- **`IHostPlatformCounts`** — Interface defining per-platform host count fields.

## Usage Example

```typescript
import HostsEnrolledCard from "./HostsEnrolledCard";

<HostsEnrolledCard
  counts={{
    darwin: 1200,
    windows: 800,
    linux: 300,
    chrome: 50,
    ios: 120,
    ipados: 40,
    android: 90,
  }}
  totalHostCount={2700}
  builtInLabels={builtInLabels}
  currentTeamId={1}
  router={router}
/>
```

## Notes

- Chart height adapts between two breakpoints (`CHART_HEIGHT_NARROW = 190`, `CHART_HEIGHT_WIDE = 242`) using a `ResizeObserver` mirroring the adjacent `CheckerboardViz` layout.
- Bar and hover colors use CSS custom properties (`--core-fleet-green`, `--core-fleet-green-over`) to respect the design system theme.
- Bars with zero hosts are rendered non-clickable; navigation is suppressed when no matching built-in label ID is found.
