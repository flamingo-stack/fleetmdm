Test suite for the `GlobalActivityItem` component, verifying that activity feed items render correctly across all supported `ActivityType` variants with proper avatar, actor name, timestamp, and contextual message display.

## Key Components

- **`GlobalActivityItem`** — The component under test, rendered with `activity` and `isPremiumTier` props
- **`createMockActivity`** — Factory for generating typed `IActivity` test fixtures
- **`createMockQuery`** / **`createMockTeamSummary`** — Supporting mock factories for nested `details` payloads
- **`ActivityType`** — Enum driving the conditional rendering logic exercised by each test case

## Usage Example

```typescript
import { render, screen } from "@testing-library/react";
import { createMockActivity } from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";
import GlobalActivityItem from ".";

// Render a specific activity type and assert its message
const activity = createMockActivity({
  type: ActivityType.LiveQuery,
  details: { targets_count: 10 },
});

render(<GlobalActivityItem activity={activity} isPremiumTier />);

expect(screen.getByText("ran a live report on 10 hosts.")).toBeInTheDocument();
```

## Test Coverage Highlights

| Scenario | Assertion |
|---|---|
| Avatar, actor name, relative timestamp | Image alt, text presence |
| Default activity (no specific message) | Generic "created pack." copy |
| `LiveQuery` with/without host count and performance stats | Dynamic message assembly |
| `AppliedSpecSavedQuery` single vs. multiple queries | Singular/plural copy |
| `AppliedSpecTeam` single vs. multiple teams | Team name inline link |
| `UserLoggedIn` / `UserFailedLogin` with/without IP | IP address interpolation |
| `UserCreated` via JIT SSO provisioning | Self-activation message |
| `EditedAgentOptions` global vs. team-scoped | Conditional team name |
