Paginated activity feed component for the Fleet MDM dashboard that displays global activities with filtering, sorting, and detail modal support.

## Key Components

### `ActivityFeed` (default export)
Main component accepting:
- `setShowActivityFeedTitle` — controls parent title visibility
- `setRefetchActivities` — exposes refetch callback to parent
- `isPremiumTier` — gates premium features
- `router` — for programmatic navigation (e.g., script batch details)

### `generateDateFilter(dateFilter)`
Pure utility that converts a named date range (`"today"`, `"yesterday"`, `"7d"`, `"30d"`, `"3m"`, `"12m"`, `"all"`) into `{ startDate, endDate }` ISO strings for the API query.

### Detail Modals
| Modal | Activity Type |
|---|---|
| `SoftwareInstallDetailsModal` | Package installs |
| `SoftwareScriptDetailsModal` | Script-based package installs |
| `SoftwareIpaInstallDetailsModal` | IPA command installs |
| `SoftwareUninstallDetailsModal` | Uninstalls |
| `VppInstallDetailsModal` | Apple VPP / Android installs |
| `RunScriptDetailsModal` | `RanScript` |
| `ShowQueryModal` | `LiveQuery` |
| `ActivityAutomationDetailsModal` | Automation enable/edit |
| `AppStoreDetailsModal` | App Store add/edit/delete |
| `SoftwareDetailsModal` | Library software add/edit/delete |
| `FailedEnrollmentProfileModal` | Failed enrollment profile renewal |

## Usage Example

```typescript
<ActivityFeed
  setShowActivityFeedTitle={(show) => setTitleVisible(show)}
  setRefetchActivities={(refetch) => { refetchRef.current = refetch; }}
  isPremiumTier={currentUser.isPremiumTier}
  router={router}
/>
```

## Notes

- Uses `react-query` with `keepPreviousData: true` and a 5 s `staleTime` to avoid flash-of-empty on pagination.
- Page size is fixed at **8** (`DEFAULT_PAGE_SIZE`).
- Opacity drops to `0.4` during fetch to indicate loading without unmounting the list.
- Script batch activity types (`RanScriptBatch`, `CanceledScriptBatch`) navigate directly to the batch details route instead of opening a modal.
