Renders a table cell displaying the host count for a script batch execution, with a linked count that filters hosts by batch status and an optional cancel button for pending batches.

## Key Components

- **`IScriptBatchHostCountCellProps`** — Props interface defining:
  - `batchExecutionId` — Unique identifier for the batch execution
  - `status` — Execution status (e.g., `"pending"`)
  - `count` — Number of hosts in this status group
  - `onClickCancel` — Callback fired when the cancel button is clicked
  - `teamId` *(optional)* — Fleet team ID for scoped host filtering

- **`ScriptBatchHostCountCell`** — Default export; builds a filtered host management URL using `buildQueryStringFromParams` and conditionally renders a cancel button only when `status === "pending"` and `count > 0`.

## Usage Example

```typescript
<ScriptBatchHostCountCell
  batchExecutionId="abc-123"
  status="pending"
  count={42}
  onClickCancel={() => console.log("Cancelling batch...")}
  teamId={7}
/>
```

The linked count navigates to:

```text
/hosts/manage?script_batch_execution_status=pending&script_batch_execution_id=abc-123&fleet_id=7
```

The cancel button is suppressed when:
- `status` is not `"pending"`, or
- `count` is `0`
