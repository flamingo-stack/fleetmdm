A searchable dropdown component for filtering activity log entries by activity type, built on top of `react-select-5` with custom menu, search, and value container components.

## Key Components

- **`ActivityTypeDropdown`** — Main exported component that renders a styled select dropdown with an embedded search input for filtering activity types.
- **`CustomMenuList`** — Overrides the default react-select menu list to inject a text search input above the options list.
- **`CustomValueContainer`** — Overrides the value container to prepend a filter icon alongside the selected value.
- **`TYPE_FILTER_OPTIONS`** — Sorted array of all `ActivityType` values mapped to human-readable labels, with an "All types" option prepended.
- **`generateOptions(searchQuery)`** — Filters `TYPE_FILTER_OPTIONS` based on a case-insensitive substring match against the search query.

## Usage Example

```typescript
import ActivityTypeDropdown from "components/ActivityTypeDropdown";

const ActivityLog = () => {
  const [selectedType, setSelectedType] = React.useState("");

  const handleSelect = (value: string) => {
    // Empty string means "All types"
    setSelectedType(value);
    fetchActivities({ type: value || undefined });
  };

  return (
    <ActivityTypeDropdown
      value={selectedType}
      onSelect={handleSelect}
      className="activity-log__type-filter"
    />
  );
};
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `value` | `string` | Currently selected `ActivityType` value, or `""` for "All types" |
| `onSelect` | `(value: string) => void` | Called with the selected type value; empty string signals "All types" |
| `className` | `string` (optional) | Additional CSS class appended to the root element |

## Notes

- Keyboard handling supports `Escape` to close and `Tab` to blur/dismiss the menu.
- Focus tracking via `isSearchInputFocusedRef` prevents the menu from closing when clicking the embedded search input.
- The component extends react-select's `Props` interface via module augmentation to thread custom search props through `selectProps`.
