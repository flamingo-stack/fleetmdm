Renders the filter controls for the activity feed, providing search, activity type, date range, and sort direction filtering capabilities.

## Key Components

- **`ActivityFeedFilters`** – Main exported React component that renders a search field and three dropdown filters
- **`DATE_FILTER_OPTIONS`** – Predefined date range options (All time, Today, Yesterday, Last 7/30 days, Last 3/12 months)
- **`TYPE_FILTER_OPTIONS`** – Dynamically generated from the `ActivityType` enum, alphabetically sorted, with an "All types" option prepended
- **`SORT_OPTIONS`** – Newest/oldest sort direction options
- **`ActivityFeedFiltersProps`** – Interface defining controlled filter state and setters, including `setPageIndex` to reset pagination on any filter change

## Usage Example

```typescript
<ActivityFeedFilters
  searchQuery={searchQuery}
  setSearchQuery={setSearchQuery}
  typeFilter={typeFilter}
  setTypeFilter={setTypeFilter}
  dateFilter={dateFilter}
  setDateFilter={setDateFilter}
  createdAtDirection={createdAtDirection}
  setCreatedAtDirection={setCreatedAtDirection}
  setPageIndex={setPageIndex}
/>
```

All filter changes automatically reset `pageIndex` to `0` to prevent stale pagination. The type filter accepts an array but currently surfaces only a single selection (`typeFilter[0]`), passed through `ActivityTypeDropdown`. The date and sort dropdowns guard against `null` values and no-op on unchanged sort direction.
