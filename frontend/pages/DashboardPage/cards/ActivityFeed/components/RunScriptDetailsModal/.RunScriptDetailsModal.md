Modal component that displays the execution details and output of a run script action, fetching results via the scripts API and rendering status messages based on exit codes.

## Key Components

### Sub-components
- **`ScriptContent`** — Renders the script source in a read-only code textarea (shown for ad-hoc scripts only)
- **`StatusMessage`** — Resolves the correct status display based on `exitCode` and `hostTimeout`:
  - `null` + no timeout → `StatusMessageRunning`
  - `null` + timeout → `StatusMessageError`
  - `-2` → Scripts disabled error
  - `-1` → Timeout with configurable seconds tooltip
  - `0` → `StatusMessageSuccess`
  - any other → `StatusMessageFailed` with exit code
- **`ScriptOutput`** — Renders recorded output with a tooltip noting the 10,000-character limit

### Main Export
- **`RunScriptDetailsModal`** — Modal wrapper that:
  - Fetches script result via `scriptsAPI.getScriptResult(scriptExecutionId)` using `react-query`
  - Manages scroll-shadow state for the modal footer via a `ResizeObserver`-style `resize` listener
  - Handles loading, error, and data states in `renderContent()`
  - Supports `isHidden` prop to suppress rendering without unmounting

## Usage Example

```typescript
import RunScriptDetailsModal from "components/RunScriptDetailsModal";

<RunScriptDetailsModal
  scriptExecutionId="abc-123-execution-id"
  onCancel={() => setShowModal(false)}
  isHidden={false}
/>
```

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `scriptExecutionId` | `string` | ✅ | Execution ID used to fetch script results |
| `onCancel` | `() => void` | ✅ | Callback fired on close button click or Enter key |
| `isHidden` | `boolean` | ❌ | Hides the modal without unmounting (default: `false`) |
