A modal component that displays details for software added via Apple App Store (VPP) or Android Google Play Store, used within activity detail views.

## Key Components

- **`AppStoreDetailsModal`** — Default export. Renders a read-only details modal showing app metadata pulled from `IActivityDetails`.
- **`IAppStoreDetailsModalProps`** — Props interface accepting `details: IActivityDetails` and an `onCancel` callback.

### Displayed Fields

| Field | Notes |
|---|---|
| **Name** | Resolved via `getDisplayedSoftwareName` |
| **App Store ID / Google Play ID** | Label switches based on `isAndroid(details.platform)` |
| **Self-Service** | Boolean rendered as `"Yes"` / `"No"` |
| **Target** | Uses shared `TargetTitle` / `TargetValue` components driven by `labels_include_any` / `labels_exclude_any` |

## Usage Example

```typescript
import AppStoreDetailsModal from "./AppStoreDetailsModal";

<AppStoreDetailsModal
  details={activityDetails}
  onCancel={() => setShowModal(false)}
/>
```

## Notes

- The App Store ID label dynamically switches to **"Google Play ID"** when `details.platform` resolves to Android via `isAndroid()`.
- `TargetTitle` and `TargetValue` are shared components imported from `LibrarySoftwareDetailsModal`, keeping label/inclusion logic consistent across software detail modals.
- Both `onExit` and `onEnter` on the underlying `Modal` are wired to `onCancel`, so pressing **Enter** or the close button both dismiss the modal.
