Modal component for displaying read-only details of a library software item from activity logs, including name, package, self-service status, and label targeting information.

## Key Components

### `LibrarySoftwareDetailsModal` (default export)
Main modal component rendering software activity details. Accepts `details: IActivityDetails` and `onCancel: () => void`.

### `TargetTitle` (named export)
Renders the target field label with an optional suffix — `" (include any)"` or `" (exclude any)"` — based on which label prop is provided. Shared with the global activity VPP details modal.

### `TargetValue` (named export)
Renders the target field value:
- No labels → `"All hosts"`
- Single label → label name
- Multiple labels → count with a tooltip listing all label names

Shared with the global activity VPP details modal.

## Usage Example

```typescript
import LibrarySoftwareDetailsModal, {
  TargetTitle,
  TargetValue,
} from "./LibrarySoftwareDetailsModal";

// Full modal usage
<LibrarySoftwareDetailsModal
  details={activityDetails}
  onCancel={() => setShowModal(false)}
/>

// Standalone target components (e.g. reuse in VPP modal)
<TargetTitle labelIncludeAny={[{ name: "macOS devices" }]} />
// renders: "Target (include any)"

<TargetValue labelExcludeAny={[{ name: "Kiosk hosts" }, { name: "Test hosts" }]} />
// renders: "2 labels" with tooltip listing both names
```
