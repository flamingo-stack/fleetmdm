A read-only modal component that displays the webhook URL configured for activity automation, showing where Fleet sends JSON payloads when new activities are generated.

## Key Components

- **`ActivityAutomationDetailsModal`** — Default export; renders a `Modal` containing a read-only `Textarea` (code variant) displaying the webhook URL from the provided `IActivityDetails`.
- **`IActivityAutomationDetailsModalProps`** — Props interface requiring:
  - `details: IActivityDetails` — Activity details object containing the `webhook_url` to display.
  - `onCancel: () => void` — Callback fired on modal close (via button click, exit, or Enter key).

## Usage Example

```typescript
import ActivityAutomationDetailsModal from "components/ActivityAutomationDetailsModal";

<ActivityAutomationDetailsModal
  details={{ webhook_url: "https://example.com/fleet-webhook" }}
  onCancel={() => setShowModal(false)}
/>
```

## Notes

- The modal is purely informational — no editable fields or form submission.
- The `Textarea` uses `variant="code"` to render the URL in a monospace/code style.
- Both `onExit` and `onEnter` on the `Modal` are wired to `onCancel`, so pressing Enter or dismissing the modal both trigger the same close handler.
