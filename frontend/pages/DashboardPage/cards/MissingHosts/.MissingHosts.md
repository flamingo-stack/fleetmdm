Renders a host count card displaying the number of missing hosts (offline for 30+ days), with a link to the filtered Manage Hosts view.

## Key Components

- **`MissingHosts`** – Default export. A presentational component that computes a filtered URL for missing hosts and renders a `HostCountCard`.
- **`IMissingHostsProps`** – Interface defining the component's props:
  - `missingCount` – Number of missing hosts to display.
  - `selectedPlatformLabelId` *(optional)* – Scopes the link to a specific platform label.
  - `currentTeamId` *(optional)* – Scopes the link to a specific Fleet team.

## Usage Example

```typescript
import MissingHosts from "components/MissingHosts";

<MissingHosts
  missingCount={12}
  selectedPlatformLabelId={3}
  currentTeamId={1}
/>
```

The component builds a `path` such as `/hosts/manage/labels/3?status=missing&fleet_id=1` and passes it to `HostCountCard`, which renders an icon, count, title, and tooltip linking to the filtered host list.

## Notes

- Hosts are considered "missing" after **30 days** offline; this definition is surfaced via the card's tooltip.
- When `selectedPlatformLabelId` is provided, the link targets `PATHS.MANAGE_HOSTS_LABEL`; otherwise it falls back to `PATHS.MANAGE_HOSTS`.
- Styling is scoped under the `hosts-missing` CSS base class.
