A React dashboard card component that displays the connection status and security policy compliance of the first enrolled host (ID: 1), designed for onboarding new Fleet users.

## Key Components

### Props (`IWelcomeHostCardProps`)
| Prop | Type | Description |
|------|------|-------------|
| `totalsHostsCount` | `number` | Total number of enrolled hosts |
| `toggleAddHostsModal` | `(show: boolean) => void` | Callback to open the Add Hosts modal |

### Render States
The component renders one of several conditional UI states:

| State | Trigger | Output |
|-------|---------|--------|
| Loading | `isLoadingHost` | Spinner |
| No host found | `loadingHostError` | Prompt to add a device |
| Host offline | `status === "offline"` | Error message + Slack help link |
| No policies | `isPoliciesEmpty` | Error message + Slack help link |
| Host online | `status === "online"` | Policy list + refetch button |

### Key Internal Behaviors
- **`onRefetchHost`** — Triggers a host vitals refetch via `hostAPI.refetch()`, polling every second for up to 60 seconds
- **`handlePolicyModal`** — Opens a detail modal for a specific policy by ID
- Displays up to 3 policies inline; links to full policy list if more exist

## Usage Example

```typescript
import WelcomeHost from "components/WelcomeHost";

<WelcomeHost
  totalsHostsCount={hostSummary.totals_hosts_count}
  toggleAddHostsModal={setShowAddHostsModal}
/>
```

## Notes
- Hard-coded to fetch host with `HOST_ID = 1` — intended for single-device onboarding flows
- Refetch polling mirrors the logic in `HostDetailsPage` (60-second timeout, online-status guard)
