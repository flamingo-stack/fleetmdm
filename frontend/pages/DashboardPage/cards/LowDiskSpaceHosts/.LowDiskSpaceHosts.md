Renders a dashboard card displaying the count of hosts with low available disk space, linking to a filtered host management view.

## Key Components

### `LowDiskSpaceHosts` (default export)
A React functional component that wraps `HostCountCard` to display hosts falling below a configurable disk space threshold.

**Props (`ILowDiskSpaceHostsProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `lowDiskSpaceGb` | `number` | Disk space threshold in GB |
| `lowDiskSpaceCount` | `number` | Number of hosts below the threshold |
| `selectedPlatformLabelId` | `number?` | Optional label ID for platform-filtered host routing |
| `currentTeamId` | `number?` | Optional team ID for scoping results |
| `notSupported` | `boolean` | Disables the card for unsupported platforms (e.g., Chromebooks); defaults to `false` |

## Behavior Notes

- When `selectedPlatformLabelId` is provided, routes to `MANAGE_HOSTS_LABEL`; otherwise routes to `MANAGE_HOSTS`
- Query params `low_disk_space` and `fleet_id` are appended to the path via `getPathWithQueryParams`
- **Known limitation:** The backend cannot simultaneously filter by both low disk space and label — the label filter only affects routing, not the disk space filter
- Displays a platform-specific tooltip when `notSupported` is `true` (Chromebook disclaimer)

## Usage Example

```typescript
<LowDiskSpaceHosts
  lowDiskSpaceGb={32}
  lowDiskSpaceCount={7}
  selectedPlatformLabelId={3}
  currentTeamId={1}
  notSupported={false}
/>
```
