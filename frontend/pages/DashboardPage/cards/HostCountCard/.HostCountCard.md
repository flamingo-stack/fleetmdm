A reusable card component that displays a host count metric with an icon, numeric count, and title, optionally supporting tooltip annotations and navigation links.

## Key Components

**Interface: `IHostCountCard`**

| Prop | Type | Description |
|------|------|-------------|
| `count` | `number` | Numeric host count to display |
| `title` | `string` | Card label/description |
| `iconName` | `IconNames` | Icon identifier to render |
| `path` | `string` | Navigation path (disabled when `notSupported`) |
| `tooltip` | `JSX.Element \| string` | Optional tooltip content wrapping the title |
| `notSupported` | `boolean` | Renders "Not supported" state instead of count |
| `className` | `string` | Additional CSS class override |
| `iconPosition` | `"top" \| "left"` | Controls icon layout relative to count/description |

**Internal Renderers**

- `renderIcon()` — Renders a large card icon
- `renderCount()` — Displays formatted count via `internationalNumberFormat` or a "Not supported" fallback
- `renderDescription()` — Renders the title, wrapped in `TooltipWrapper` if a tooltip is provided
- `renderCard()` — Composes layout based on `iconPosition`

## Usage Example

```typescript
<HostCountCard
  count={1042}
  title="macOS Hosts"
  iconName="darwin"
  path="/hosts?os=macos"
  tooltip="Total enrolled macOS devices"
  iconPosition="left"
/>

// Unsupported platform state
<HostCountCard
  count={0}
  title="ChromeOS Hosts"
  iconName="chrome"
  path="/hosts?os=chromeos"
  notSupported
/>
```

## Notes

- When `notSupported` is `true`, the card's navigation path is disabled and the count is replaced with a "Not supported" message.
- Count values are formatted using `internationalNumberFormat` for locale-aware display (e.g., `1,042`).
- CSS class names are auto-generated from the `title` prop via `kebabCase` for scoped styling.
