Unit tests for the `HostCountCard` component, verifying rendering behavior for title, count, icon, and tooltip interactions.

## Key Components

| Test Case | Description |
|-----------|-------------|
| Render title, count, and icon | Validates core display elements render correctly when all props are provided |
| Icon omission | Confirms no icon renders when `tooltip` prop is absent |
| Tooltip on hover | Verifies tooltip text appears on title hover using `userEvent` |

## Usage Example

```typescript
// Rendering HostCountCard in tests
render(
  <HostCountCard
    count={200}
    title="Windows hosts"
    iconName="windows"
    tooltip="Hosts on any Windows device"
    path={paths.MANAGE_HOSTS_LABEL(10)}
  />
);

// Testing tooltip visibility on hover
const { user } = renderWithSetup(<HostCountCard {...props} />);
await user.hover(screen.getByText("Windows hosts"));
await waitFor(() => {
  expect(screen.getByText("Hosts on any Windows device")).toBeInTheDocument();
});
```

## Notes

- Uses both `render` (from `@testing-library/react`) and `renderWithSetup` (from `test/test-utils`) — the latter provides a configured `user` event instance for interaction testing.
- React Router `<Link />` path behavior is **not tested** here; a wrapping `<Router />` would be required to validate navigation.
- Source: [`HostCountCard.tests.tsx`](https://github.com/flamingo-stack/fleetmdm/blob/main/HostCountCard.tests.tsx)
