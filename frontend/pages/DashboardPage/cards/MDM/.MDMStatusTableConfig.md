Defines table column configuration and data transformation utilities for the MDM enrollment status summary table displayed on the MDM dashboard card.

## Key Components

### `generateStatusTableHeaders(teamId?)`
Returns an array of `react-table` column definitions with three columns:
- **Status** – Renders a plain `TextCell` or a `TooltipWrapper` based on whether a tooltip exists in `MDM_STATUS_TOOLTIP`. Displays the human-readable name from `MDM_ENROLLMENT_STATUS_UI_MAP`.
- **Hosts** – Renders the numeric host count via `TextCell`.
- **View All Hosts** (unlabeled) – Renders a `ViewAllHostsLink` that navigates to the host list filtered by `mdm_enrollment_status`, optional `fleet_id` (team), and platform label.

### `generateStatusDataSet(statusData, selectedPlatformLabelId?)`
Public entry point that returns an enhanced copy of the status data array. Returns `[]` if `statusData` is `null`.

### `enhanceStatusData(statusData, selectedPlatformLabelId?)` *(internal)*
Maps over status rows and injects `selectedPlatformLabelId` into each record so downstream cells can pass it to `ViewAllHostsLink`.

## Usage Example

```typescript
import {
  generateStatusTableHeaders,
  generateStatusDataSet,
} from "./MDMStatusTableConfig";

const columns = generateStatusTableHeaders(teamId);
const data = generateStatusDataSet(rawStatusData, selectedPlatformLabelId);

// Pass to a TableContainer or react-table instance
<TableContainer columns={columns} data={data} />
```
