A React dashboard card component that displays MDM (Mobile Device Management) enrollment data in a tabbed interface, showing both MDM solutions and enrollment status across managed hosts.

## Key Components

### Exports
- **`Mdm`** (default) — Main card component rendering two tabs: Solutions and Status
- **`IMdmSolutionTableData`** — Type alias for MDM solution table rows (`name` + `hosts_count`)

### Internal Utilities
- **`reduceSolutionsToObj`** — Merges duplicate MDM solution entries (including unnamed/`"Unknown"`) by summing `hosts_count`
- **`EmptyMdmStatus`** — Empty state with a link to Fleet's agent (`fleetd`) docs
- **`EmptyMdmSolutions`** — Empty state shown when no MDM solutions are detected

### Props (`IMdmCardProps`)
| Prop | Type | Description |
|------|------|-------------|
| `isFetching` | `boolean` | Shows spinner and hides content while loading |
| `error` | `Error \| null` | Renders `DataError` in place of table on failure |
| `mdmStatusData` | `IMdmStatusCardData[]` | Data for the Status tab |
| `mdmSolutions` | `IMdmSummaryMdmSolution[] \| null` | Raw solutions list, de-duplicated internally |
| `selectedPlatformLabelId` | `number?` | Filters status data by platform |
| `selectedTeamId` | `number?` | Filters solution headers by team |
| `onClickMdmSolution` | `(solution) => void` | Row click handler for the Solutions table |

## Usage Example

```typescript
<Mdm
  isFetching={isLoading}
  error={fetchError}
  mdmStatusData={statusData}
  mdmSolutions={solutions}
  selectedPlatformLabelId={3}
  selectedTeamId={1}
  onClickMdmSolution={(solution) => {
    router.push(`/hosts?mdm_solution=${solution.name}`);
  }}
/>
```
