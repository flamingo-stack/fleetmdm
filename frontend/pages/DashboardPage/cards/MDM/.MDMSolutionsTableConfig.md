Configures the table headers and data set for the MDM Solutions table, mapping solution records to displayable rows with name and host count columns.

## Key Components

- **`generateSolutionsTableHeaders()`** — Returns the column definitions array for the MDM solutions table, defining two non-sortable columns: `Name` (rendered as a `LinkCell`) and `Hosts` (rendered as a `TextCell`).
- **`generateSolutionsDataSet()`** — Transforms an array of `IMdmSolutionTableData` records, normalizing the `displayName` field by falling back to `"Unknown"` when `name` is absent.
- **`IMDMSolutionWithPlatformId`** — Extended interface combining `IMdmSolution` with an optional `selectedPlatformLabelId` for platform-filtered views.
- **`ICellProps` / `IHeaderProps` / `IDataColumn`** — Local TypeScript interfaces typed against `react-table` cell and header prop shapes.

## Usage Example

```typescript
import {
  generateSolutionsTableHeaders,
  generateSolutionsDataSet,
} from "./MDMSolutionsTableConfig";

// Build column definitions for react-table
const columns = generateSolutionsTableHeaders();

// Normalize raw solution data before passing to the table
const rawSolutions = [
  { id: 1, name: "Jamf Pro", hosts_count: 42 },
  { id: 2, name: null, hosts_count: 7 },
];

const tableData = generateSolutionsDataSet(rawSolutions);
// tableData[1].displayName === "Unknown"
```

## Notes

- The `LinkCell` in the `Name` column uses a `noop` click handler — link navigation is expected to be handled upstream or extended by a parent component.
