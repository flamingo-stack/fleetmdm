Generates and exports the column configuration array for the software inventory table, defining headers, accessors, and cell renderers for Name, Version, Hosts, and Actions columns.

## Key Components

- **`generateTableHeaders(teamId?: number): IDataColumn[]`** — Factory function that returns a column definitions array for `react-table`. Accepts an optional `teamId` to scope the "View All Hosts" link query params.
- **`ICellProps`** — Typing for `react-table` cell props, referencing `ISoftware` as the row's original data shape.
- **`IHeaderProps`** — Typing for column header props including sort direction.
- **`IDataColumn`** — Interface describing each column definition (title, Header, accessor, Cell renderer, sort/visibility flags).

## Column Definitions

| Column | Accessor | Renderer |
|---|---|---|
| Name | `name` | `TooltipTruncatedTextCell` |
| Version | `version` | `TooltipTruncatedTextCell` |
| Hosts | `hosts_count` | `TextCell` |
| Actions | `id` | `ViewAllHostsLink` |

All columns have `disableSortBy: true`.

## Usage Example

```typescript
import generateTableHeaders from "./SoftwareTableConfig";

// Without team scoping
const columns = generateTableHeaders();

// With team scoping — filters "View All Hosts" link to a specific team
const teamColumns = generateTableHeaders(42);

// Pass to a TableContainer or react-table instance
<TableContainer
  columns={generateTableHeaders(currentTeamId)}
  data={softwareList}
/>
```
