A tabbed dashboard card component that displays software inventory for hosts, supporting both "All" and "Vulnerable" software views with pagination, sorting, and row-level navigation.

## Key Components

### `ISoftwareCardProps`
Props interface for the `Software` component:
- `errorSoftware` – Error state from the software fetch
- `isSoftwareFetching` – Loading state toggle
- `isSoftwareEnabled` – Feature flag guard for software data display
- `software` – The fetched `ISoftwareResponse` data
- `navTabIndex` / `onTabChange` – Controlled tab state
- `onQueryChange` – Callback for pagination/sort/filter changes
- `router` – Injected router for programmatic navigation
- `softwarePageIndex` / `teamId` – Pagination and team scoping

### Constants
| Constant | Value |
|---|---|
| `SOFTWARE_DEFAULT_SORT_DIRECTION` | `"desc"` |
| `SOFTWARE_DEFAULT_SORT_HEADER` | `"hosts_count"` |
| `SOFTWARE_DEFAULT_PAGE_SIZE` | `8` |

### `Software` Component
Renders a two-tab layout ("All" / "Vulnerable") using `react-tabs`, each backed by a `TableContainer`. Row clicks navigate to the host management page filtered by `software_id` and `fleet_id`.

## Usage Example

```typescript
<Software
  errorSoftware={null}
  isSoftwareFetching={false}
  isSoftwareEnabled={true}
  software={softwareData}
  teamId={3}
  navTabIndex={0}
  onTabChange={(index) => setTabIndex(index)}
  onQueryChange={(queryData) => fetchSoftware(queryData)}
  router={router}
  softwarePageIndex={0}
/>
```

## Behavior Notes

- While fetching, a `<Spinner />` overlays the table and content is rendered with `opacity: 0` to prevent layout shift
- Errors surface via `<DataError />` only after fetching completes
- The "Vulnerable" tab passes `vulnFilters={{ vulnerable: true }}` to `EmptySoftwareTable` for context-aware empty states
- Table headers are memoized per `teamId` via `generateTableHeaders`
