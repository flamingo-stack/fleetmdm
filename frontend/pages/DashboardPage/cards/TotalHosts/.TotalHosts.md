Renders a summary card displaying the total number of enrolled hosts, linking to a filtered manage-hosts view based on the selected platform label and team.

## Key Components

- **`TotalHosts`** — Default export. A React functional component that computes the correct manage-hosts URL and renders a `HostCountCard`.
- **`ITotalHostsProps`** — Props interface:
  - `totalCount?: number` — Total host count to display.
  - `selectedPlatformLabelId?: number` — When provided, scopes the link to a specific platform label.
  - `currentTeamId?: number` — Filters the link by Fleet team ID.

## Usage Example

```typescript
import TotalHosts from "components/TotalHosts";

<TotalHosts
  totalCount={342}
  selectedPlatformLabelId={5}
  currentTeamId={2}
/>
```

## Notes

- When `selectedPlatformLabelId` is set, the card links to `MANAGE_HOSTS_LABEL(id)`; otherwise it falls back to `MANAGE_HOSTS`.
- `currentTeamId` is appended as a `fleet_id` query parameter via `getPathWithQueryParams`.
- Delegates all rendering to [`HostCountCard`](https://github.com/flamingo-stack/fleetmdm/blob/main/components/HostCountCard) with `iconName="total-hosts"` and `iconPosition="left"`.
- Displays `0` when `totalCount` is `undefined`.
