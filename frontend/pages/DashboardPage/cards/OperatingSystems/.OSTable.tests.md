Brief description: Unit tests for the `OSTable` component used on the Fleet Dashboard, verifying that OS version data renders correctly in the table.

## Key Components

- **`Dashboard OS table` test suite** — Wraps all tests for the `OSTable` component
- **`renders data normally when present`** — Validates that OS version rows (version numbers, host counts) render correctly given valid `osVersions` prop data

## Usage Example

```typescript
// Run this specific test file
npx jest OSTable.tests.tsx

// Or run all dashboard-related tests
npx jest --testPathPattern="Dashboard"
```

## Test Coverage

The test renders `OSTable` with two Windows OS version entries:

| Field | Entry 1 | Entry 2 |
|---|---|---|
| Version | `1.2.3` | `4.5.6` |
| Hosts | `234` | `567` |
| Vulnerabilities | None | 1 CVE (`CVE-2022-2601`) |

**Assertions:**

- Column headers `Version` and `Hosts` are present in the DOM
- Both OS version strings (`1.2.3`, `4.5.6`) render correctly
- Both host counts (`234`, `567`) render correctly

## Notes

- Uses `@testing-library/react` for rendering and DOM queries
- `currentTeamId` is passed as `undefined` (no team filter)
- `isLoading` is set to `false` to ensure data is rendered, not a loading skeleton
- The second OS entry includes a vulnerability object to confirm the component handles mixed data (with and without CVEs) without errors
