Defines the column configuration for the Operating System table used in dashboard OS views and the Software OS tab, generating sortable/filterable column headers for OS name, version, vulnerabilities, and host counts.

## Key Components

### Types
- **`IOSTableConfigOptions`** — Options to conditionally include columns: `includeName`, `includeVulnerabilities`, `includeIcon`
- **`INameCellProps`, `IVersionCellProps`, `IVulnCellProps`, `IHostCountCellProps`** — Typed cell props for each column

### Functions
- **`generateDefaultTableHeaders(teamId?, router?, configOptions?)`** — Builds the full set of 5 columns: Name, Version, Vulnerabilities, Hosts, and View All Hosts link
- **`generateTableHeaders(teamId?, router?, configOptions?)`** *(default export)* — Wraps `generateDefaultTableHeaders` and filters out columns based on `configOptions`

### Column Behaviors
- **Name** — Renders plain text or a linked `LinkCell` with an `OSIcon` prefix, depending on `includeIcon`
- **Version** — Detects rolling Arch Linux versions and renders a special `TooltipWrapperArchLinuxRolling` component
- **Vulnerabilities** — Shows "Not supported" tooltip for unsupported platforms (non-macOS/Windows/Linux), otherwise renders `VulnerabilitiesCell`
- **Hosts** — Sortable count column
- **View All Hosts** — Renders a `ViewAllHostsLink` filtered by `os_version_id` and `teamId`

## Usage Example

```typescript
import generateTableHeaders from "./OSTableConfig";

// Dashboard OS table (no name column, no icon, no vulns)
const dashboardColumns = generateTableHeaders(teamId, router, {
  includeName: false,
  includeVulnerabilities: false,
  includeIcon: false,
});

// Software OS tab (full table with icon and vulnerabilities)
const softwareOSColumns = generateTableHeaders(teamId, router, {
  includeName: true,
  includeVulnerabilities: true,
  includeIcon: true,
});
```
