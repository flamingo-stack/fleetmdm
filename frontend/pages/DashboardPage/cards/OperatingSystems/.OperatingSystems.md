A React component that fetches and displays operating system version data for a selected platform and team, rendering an OS table with loading/error states and dynamic title/description updates.

## Key Components

### `IOperatingSystemsCardProps`
Props interface for the component:
- `currentTeamId` — filters OS data by team
- `selectedPlatform` — the active platform filter (`PlatformValueOptions`)
- `showTitle` / `setShowTitle` — controls title visibility during loading
- `showDescription` — toggles description text under the title (defaults to `true`)
- `setTitleDetail` / `setTitleDescription` — optional callbacks to inject content into a parent card header

### `OperatingSystems` (default export)
Main component that:
- Fetches OS version data via `react-query` using `getOSVersions`, scoped by platform and team
- Skips the query for unsupported platforms via `OS_VERSIONS_API_SUPPORTED_PLATFORMS`
- Renders a platform-aware description (special-cased for `chrome`, with vendor/EOL links for others)
- Displays a `LastUpdatedText` detail when `counts_updated_at` is available
- Shows a `Spinner` during loading and fades content via inline opacity
- Delegates to `OSTable` for the actual data table, or shows `DataError` on 5xx responses

## Usage Example

```typescript
import OperatingSystems from "./OperatingSystems";

<OperatingSystems
  currentTeamId={1}
  selectedPlatform="darwin"
  showTitle={showTitle}
  showDescription={true}
  setShowTitle={setShowTitle}
  setTitleDetail={setTitleDetail}
  setTitleDescription={setTitleDescription}
/>
```

## Notes
- Query is disabled when `selectedPlatform` is not in `OS_VERSIONS_API_SUPPORTED_PLATFORMS`
- `keepPreviousData: true` prevents table flicker when switching filters
- Title/description state is cleared while loading and repopulated once data arrives
