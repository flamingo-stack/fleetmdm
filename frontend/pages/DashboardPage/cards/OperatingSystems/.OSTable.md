A reusable table component for displaying operating system versions, with built-in empty state handling and pagination logic based on result count.

## Key Components

- **`OSTable`** – Main component that renders a paginated table of OS versions for a selected platform
- **`EmptyOS`** – Internal helper that renders a platform-specific empty state message when no OS versions are detected
- **`IOSTableProps`** – Interface defining the component's props
- **`generateTableHeaders`** – Imported utility from `OSTableConfig` that produces column configurations

### Constants

| Constant | Value | Purpose |
|---|---|---|
| `DEFAULT_SORT_HEADER` | `"hosts_count"` | Default sort column |
| `DEFAULT_SORT_DIRECTION` | `"desc"` | Default sort order |
| `PAGE_SIZE` | `8` | Rows per page; also controls pagination visibility |

## Usage Example

```typescript
import OSTable from "components/OSTable";

<OSTable
  currentTeamId={42}
  osVersions={osVersionData}
  selectedPlatform="darwin"
  isLoading={false}
/>
```

## Behavior Notes

- **Pagination** is enabled client-side only when `osVersions.length > 8`; otherwise pagination controls are hidden
- **Empty state** message dynamically includes the platform display name (e.g., `"No macOS operating systems detected"`)
- Column configs are memoized on `currentTeamId` to avoid unnecessary recalculations
- The table refreshes every hour on the server side, as noted in the empty state info text
