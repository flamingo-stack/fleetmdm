Defines shared constants for the Fleet dashboard's platform selection feature.

## Key Components

- **`PLATFORM_DROPDOWN_OPTIONS`** — A `const` tuple of platform dropdown entries, each containing a `label`, `value`, and corresponding router `path`. Covers all supported platforms: All, macOS, Windows, Linux, ChromeOS, iOS, iPadOS, and Android.
- **`PLATFORM_NAME_TO_LABEL_NAME`** — A `const` mapping from platform value identifiers (e.g. `"darwin"`) to their human-readable built-in label names (e.g. `"macOS"`).
- **`LOW_DISK_SPACE_GB`** — A numeric constant (`32`) representing the default low disk space threshold in gigabytes. This is a premium feature with a valid range of 1–100 GB.

## Usage Example

```typescript
import {
  PLATFORM_DROPDOWN_OPTIONS,
  PLATFORM_NAME_TO_LABEL_NAME,
  LOW_DISK_SPACE_GB,
} from "./helpers";

// Render platform dropdown
const options = PLATFORM_DROPDOWN_OPTIONS.map((opt) => ({
  label: opt.label,
  value: opt.value,
}));

// Resolve built-in label for a selected platform
const platformValue = "darwin";
const builtInLabel = PLATFORM_NAME_TO_LABEL_NAME[platformValue];
// → "macOS"

// Check disk space alert threshold
if (device.availableDiskGb < LOW_DISK_SPACE_GB) {
  console.warn(`Low disk space: ${device.availableDiskGb}GB`);
}
```
