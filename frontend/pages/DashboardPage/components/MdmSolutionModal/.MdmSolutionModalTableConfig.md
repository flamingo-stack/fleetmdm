Defines table configuration for displaying MDM solutions, providing column headers and data transformation utilities for the MDM solutions table in Fleet's dashboard.

## Key Components

### `generateSolutionsTableHeaders(teamId?: number): IDataColumn[]`
Returns column definitions for the MDM solutions table with two columns:
- **Server URL** — Displays the MDM server URL with a tooltip explaining its purpose; sorting disabled.
- **Hosts** — Shows host count with an inline `ViewAllHostsLink` that filters by `mdm_id`, optional `fleet_id` (team), and platform label.

### `generateSolutionsDataSet(solutions, selectedPlatformLabelId?): IMdmSolution[]`
Transforms raw `IMdmSolution[]` by injecting `selectedPlatformLabelId` into each record, making platform context available to cell renderers. Returns an empty array when `solutions` is `null`.

### `IMDMSolutionWithPlatformId`
Extends `IMdmSolution` with an optional `selectedPlatformLabelId` field used to scope "View All Hosts" links to a specific platform.

## Usage Example

```typescript
import {
  generateSolutionsTableHeaders,
  generateSolutionsDataSet,
} from "./MdmSolutionModalTableConfig";

const teamId = 42;
const platformLabelId = 7;

// Build columns (pass teamId to scope host links to a team)
const columns = generateSolutionsTableHeaders(teamId);

// Transform API response before passing to the table
const rows = generateSolutionsDataSet(apiResponse.solutions, platformLabelId);

// Pass to your table component
<TableContainer columns={columns} data={rows} />;
```

## Notes
- Cell props follow the [react-table v7 API](https://react-table.tanstack.com/docs/api/useTable#cell-properties).
- Both columns have `disableSortBy: true`; sorting must be handled externally if needed.
