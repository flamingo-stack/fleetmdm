Unit test for the `MdmSolutionModal` component, verifying that MDM solution data (server URL and host count) renders correctly in the modal's table.

## Key Components

- **`describe("MdmSolutionModal table")`** — Test suite scoping all assertions for the modal's table rendering
- **`it("Renders table data normally")`** — Single test case validating that `server_url` and `hosts_count` from an `IMdmSolution` object appear in the DOM

## Usage Example

```typescript
const mdmSolutions: IMdmSolution[] = [
  {
    id: 1,
    name: "test solution",
    server_url: "a.b.c",
    hosts_count: 123,
  },
];

render(
  <MdmSolutionModal mdmSolutions={mdmSolutions} onCancel={() => null} />
);

expect(screen.getByText("a.b.c")).toBeInTheDocument();
expect(screen.getByText(123)).toBeInTheDocument();
```

## Notes

- Uses `@testing-library/react` for rendering and DOM querying
- The `onCancel` prop is stubbed with a no-op (`() => null`) since cancellation behavior is not under test
- Relies on the `IMdmSolution` interface from [`interfaces/mdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/mdm.ts) for type safety on test data
