A modal component that displays a table of MDM (Mobile Device Management) solution details for a selected MDM solution, filtered by platform label and team.

## Key Components

- **`MdmSolutionModal`** — Default export. Renders a `Modal` containing a sortable, paginated-disabled `TableContainer` of MDM solution data.
- **`IMdmSolutionModalProps`** — Props interface accepting:
  - `mdmSolutions: IMdmSolution[]` — Array of MDM solution objects to display
  - `selectedPlatformLabelId?: number` — Optional platform filter
  - `selectedTeamId?: number` — Optional team context for column generation
  - `onCancel: () => void` — Callback for closing the modal
- **`generateSolutionsTableHeaders`** — Imported utility that builds column configs based on team context
- **`generateSolutionsDataSet`** — Imported utility that transforms raw `IMdmSolution[]` into table-ready rows filtered by platform label

## Usage Example

```typescript
import MdmSolutionModal from "pages/DashboardPage/cards/Mdm/MdmSolutionModal";

<MdmSolutionModal
  mdmSolutions={[
    { name: "Jamf Pro", hosts_count: 42 },
    { name: "Jamf Pro", hosts_count: 10 },
  ]}
  selectedPlatformLabelId={3}
  selectedTeamId={1}
  onCancel={() => setShowModal(false)}
/>
```

## Notes

- The modal title defaults to `"Unknown MDM solution"` if `mdmSolutions[0].name` is falsy.
- The table is sorted descending by `hosts_count` by default.
- Pagination, count display, and table header are all disabled — the component is display-only.
- Both `onExit` and `onEnter` on the modal trigger `onCancel`, supporting keyboard (Enter/Escape) dismissal.
