A modal component for configuring activity feed webhook automations, allowing users to enable/disable and set a destination URL for Fleet activity notifications.

## Key Components

### Interfaces

- **`IAFAMFormData`** — Form data shape with `enabled: boolean` and `url: string`
- **`IActivityFeedAutomationsModal`** — Component props including `automationSettings`, `onSubmit`, `onExit`, and `isUpdating`

### Internal State

| State | Type | Purpose |
|---|---|---|
| `formData` | `IAFAMFormData` | Tracks enabled toggle and destination URL |
| `formErrors` | `Record<string, string \| null>` | Tracks URL validation errors |
| `showExamplePayload` | `boolean` | Controls example payload visibility |

### Key Behaviors

- **URL validation** — Validates `http`/`https` protocols via `validURL` only when the webhook is enabled
- **GitOps mode** — Disables form controls via `useGitOpsMode` hook when GitOps mode is active
- **Auto-clear on disable** — Clears URL errors and resets state when the webhook is toggled off
- **Example payload** — Reveals a syntax-highlighted JSON POST payload preview with a link to Fleet audit log docs

## Usage Example

```typescript
import ActivityFeedAutomationsModal, {
  IAFAMFormData,
} from "components/ActivityFeedAutomationsModal";

<ActivityFeedAutomationsModal
  automationSettings={{
    enable_activities_webhook: false,
    destination_url: "",
  }}
  onSubmit={(formData: IAFAMFormData) => {
    // persist webhook settings
    saveWebhookSettings(formData);
  }}
  onExit={() => setModalVisible(false)}
  isUpdating={isSaving}
/>
```
