A dashboard card component that renders a titled, bordered card with optional description, action buttons, and dynamic child communication via injected props.

## Key Components

### `IInfoCardProps`
Configuration interface accepting:
- `title` – card heading text
- `titleDetail` – supplemental detail rendered beneath the title
- `description` – optional body text below the title group
- `action` – polymorphic action descriptor supporting `"link"`, `"button"`, or `"automations"` types
- `total_host_count` – optional numeric badge displayed alongside the title
- `showTitle` – toggles visibility of the entire title section (default: `true`)
- `children` – card body content; receives injected state setters

### `useInfoCard`
A render function (named with `use` prefix but returns JSX directly) that:
- Manages internal state for `titleDetail`, `description`, and `actionLink`, allowing child components to update them via cloned props (`setTitleDetail`, `setTitleDescription`, `setActionURL`)
- Renders the appropriate action control (`AutomationsButton`, a plain `Button`, or a navigation `Button` with an arrow icon) based on the `action.type`
- Wraps everything in a `Card` with `xlarge` padding and `large` border radius

## Usage Example

```typescript
import useInfoCard from "components/InfoCard";

const MyDashboardSection = () => {
  return useInfoCard({
    title: "Software",
    titleDetail: <span>Last updated 2h ago</span>,
    description: "Installed software across your fleet.",
    total_host_count: 42,
    action: {
      type: "link",
      to: "/software",
      text: "View all",
    },
    children: <SoftwareTable />,
  });
};
```

> **Note:** Child components can dynamically update the card's `titleDetail`, `description`, and action URL by calling the injected `setTitleDetail`, `setTitleDescription`, and `setActionURL` props passed down via `React.cloneElement`.
