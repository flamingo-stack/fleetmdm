Renders a grid of per-platform host count cards for the Fleet dashboard, conditionally displaying or hiding each platform card based on host counts and the currently selected platform filter.

## Key Components

### `IPlatformHostCountsProps`
Props interface accepting:
- `currentTeamId` — optional team scope for filtering host paths
- Per-platform counts: `macCount`, `windowsCount`, `linuxCount`, `chromeCount`, `iosCount`, `ipadosCount`, `androidCount`
- `builtInLabels` — built-in label metadata used to resolve label IDs for navigation paths
- `selectedPlatform` — optional `PlatformValueOptions` value to show only a single platform card
- `totalHostCount` — used to determine whether zero-count cards should be hidden

### `hidePlatformCard(platformCount)`
Returns `true` when a platform has 0 hosts but other platforms do have hosts, suppressing the card from rendering.

### `getBuiltinLabelId(platformName)`
Memoized callback that looks up a built-in label ID by platform name using `PLATFORM_NAME_TO_LABEL_NAME` mapping.

### `renderCounts(teamId?)`
Switch-based dispatcher: renders a single platform card when `selectedPlatform` is set, or all platform cards in the default all-platforms view.

## Usage Example

```typescript
<PlatformHostCounts
  currentTeamId={3}
  macCount={120}
  windowsCount={85}
  linuxCount={40}
  chromeCount={10}
  iosCount={5}
  ipadosCount={2}
  androidCount={0}
  builtInLabels={hostSummary.builtin_labels}
  selectedPlatform="darwin"
  totalHostCount={262}
/>
```

Each rendered `HostCountCard` links to `PATHS.MANAGE_HOSTS_LABEL(labelId)` with an optional `fleet_id` query param scoped to the current team. When `selectedPlatform` is undefined, all non-zero platform cards are rendered together.
