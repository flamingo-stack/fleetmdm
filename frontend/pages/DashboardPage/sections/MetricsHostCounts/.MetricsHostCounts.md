A React component that renders a collection of host metric count cards on the Fleet MDM dashboard, conditionally displaying host status indicators based on platform selection and subscription tier.

## Key Components

### `MetricsHostCounts`
The default export — a functional component that composes four metric cards:

| Card | Render Condition |
|---|---|
| `TotalHosts` | Only when `selectedPlatform === "all"` |
| `MissingHosts` | Premium tier only; hidden for iOS, iPadOS, Android |
| `LowDiskSpaceHosts` | Premium tier only; hidden for iOS, iPadOS, Android; disabled for Chrome |
| `ABMIssueHosts` | Only when `abmIssueCount > 0` (non-zero Apple Business Manager issues) |

### `IPlatformHostCountsProps`

| Prop | Type | Description |
|---|---|---|
| `currentTeamId` | `number \| undefined` | Active team scope |
| `selectedPlatform` | `PlatformValueOptions` | Current platform filter |
| `totalHostCount` | `number` | Total enrolled host count |
| `isPremiumTier` | `boolean` | Controls premium-only card visibility |
| `missingCount` | `number` | Hosts not checking in |
| `lowDiskSpaceCount` | `number` | Hosts below `LOW_DISK_SPACE_GB` threshold |
| `abmIssueCount` | `number` | Hosts with ABM enrollment issues |
| `selectedPlatformLabelId` | `number` | Label ID for filtered navigation links |

## Usage Example

```typescript
import MetricsHostCounts from "./MetricsHostCounts";

<MetricsHostCounts
  currentTeamId={1}
  selectedPlatform="all"
  totalHostCount={342}
  isPremiumTier={true}
  missingCount={5}
  lowDiskSpaceCount={12}
  abmIssueCount={3}
  selectedPlatformLabelId={undefined}
/>
```

> **Note:** `ABMIssueHosts` renders only for Apple platforms where `abmIssueCount > 0`. Pass `0` (or leave undefined) on non-Apple platform views to suppress it.
