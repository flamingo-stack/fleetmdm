This is the main dashboard page component for the Fleet MDM application, orchestrating data fetching, state management, and rendering of multiple dashboard cards including host summaries, software inventory, MDM status, activity feeds, and operating system metrics.

## Key Components

### `DashboardPage`
The primary exported React component that renders the full MSP dashboard UI. Accepts:
- `router` — `InjectedRouter` for navigation
- `location` — Route location object including query params (`fleet_id`, `manage_automations`)

### Key State & Hooks
| Hook / State | Purpose |
|---|---|
| `useTeamIdParam` | Resolves current team context from route |
| `useContext(AppContext)` | Global admin/tier/role flags |
| `selectedPlatform` | Active platform filter (`all`, `darwin`, `windows`, etc.) |
| `softwarePageIndex` / `softwareNavTabIndex` | Pagination and tab state for the Software card |
| `showMdmSolutionModal` / `showAddHostsModal` | Modal visibility toggles |

### Data Queries (React Query)
| Query Key | Source |
|---|---|
| `config` | `configAPI.loadAll()` |
| `host summary` | `hostSummaryAPI.getSummary()` with platform/team filters |
| `host summary totals` | Unfiltered platform counts for chart card |
| `teams` | `teamsAPI.loadAll()` (premium only) |
| `global secrets` / `team secrets` | Enroll secret APIs |
| `software` | `softwareAPI` with pagination |

### Rendered Cards
`MetricsHostCounts`, `ActivityFeed`, `Software`, `LearnFleet`, `WelcomeHost`, `Mdm`, `Munki`, `OperatingSystems`, `ChartCard`, `HostsEnrolledCard`

## Usage Example

```typescript
// Rendered by the Fleet router — not instantiated directly.
// Route: /dashboard or /dashboard/:platform

import DashboardPage from "pages/DashboardPage/DashboardPage";

// Router configuration (simplified):
<Route path={paths.DASHBOARD} component={DashboardPage} />

// Deep-link to open Activity Feed Automations modal (global admin only):
router.push(`${paths.DASHBOARD}?manage_automations=1`);
```
