Handles the Apple MDM SSO (Single Sign-On) login flow, supporting multiple enrollment initiators including DEP, account-driven enrollment, and setup experience workflows.

## Key Components

- **`DEPSSOLoginPage`** – Default export. A React page component that initiates the MDM Apple SSO flow via `mdmAPI.initiateMDMAppleSSO`, then redirects the user to the returned SSO URL. Handles three initiator modes:
  - `setup_experience` – Renders an explicit "Sign in" prompt requiring user interaction before triggering SSO.
  - `account_driven_enroll` / `account_driven_enroll:<token>` – Auto-triggers SSO based on pathname matching.
  - `mdm_sso` – Default fallback; auto-triggers SSO immediately on mount.

- **Initiator resolution** – Determines the `initiator` value from `query.initiator`, pathname (`/mdm/apple/account_driven_enroll/sso`), or defaults to `"mdm_sso"`.

- **`deviceinfo` persistence** – Stores `query.deviceinfo` in `localStorage` for downstream use during enrollment.

## Usage Example

```typescript
// Rendered by React Router at MDM SSO routes, e.g.:
// /mdm/apple/sso
// /mdm/apple/account_driven_enroll/sso/:token

// Query params consumed:
// ?initiator=setup_experience&deviceinfo=<encoded>

<Route path="/mdm/apple/sso" component={DEPSSOLoginPage} />
<Route path="/mdm/apple/account_driven_enroll/sso/:token" component={DEPSSOLoginPage} />
```

## Error & Loading States

| State | Rendered Output |
|---|---|
| SSO in progress | `<Spinner />` |
| SSO fetch error | `<SSOError />` |
| `setup_experience` | Authentication form with sign-in button |
