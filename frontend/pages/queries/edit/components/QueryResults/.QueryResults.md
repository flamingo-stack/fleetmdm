Renders the live query results interface, displaying real-time query output and errors in a tabbed layout with export and filtering capabilities.

## Key Components

### `QueryResults` (default export)
Main component that manages the full results view for a running or completed live query.

**Props (`IQueryResultsProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `campaign` | `ICampaign` | Active campaign containing results, errors, and host counts |
| `isQueryFinished` | `boolean` | Whether the query has completed execution |
| `isQueryClipped` | `boolean` | Whether results were truncated due to target size |
| `queryName` | `string` | Optional name used for CSV export filenames |
| `onRunQuery` | `() => void` | Callback to re-run the query |
| `onStopQuery` | `MouseEventHandler` | Callback to stop the running query |
| `setSelectedTargets` | `(value: ITarget[]) => void` | Resets target selection on done |
| `goToQueryEditor` | `() => void` | Navigates back to the query editor |
| `targetsTotalCount` | `number` | Total number of hosts targeted |

**Internal state:**
- `navTabIndex` — controls active Results/Errors tab
- `filteredResults` / `filteredErrors` — rows used for CSV export
- `resultsColumnConfigs` / `errorColumnConfigs` — dynamically generated from row data
- `queryResultsForTableRender` — debounced (1 s, max 2 s) copy of `queryResults` to reduce render thrashing

## Usage Example

```typescript
<QueryResults
  campaign={activeCampaign}
  isQueryFinished={queryStatus === "finished"}
  isQueryClipped={activeCampaign.isClipped}
  queryName="Installed Software"
  onRunQuery={handleRunQuery}
  onStopQuery={handleStopQuery}
  setSelectedTargets={setTargets}
  goToQueryEditor={navigateToEditor}
  targetsTotalCount={250}
/>
```
