A React component that renders a "Store data" checkbox option for controlling whether query results are persisted in Fleet, with contextual help text and disabled-state handling based on global report settings.

## Key Components

### `IDiscardDataOptionProps`
| Prop | Type | Description |
|------|------|-------------|
| `queryReportsDisabled` | `boolean` | Whether report results are globally disabled in Fleet |
| `selectedLoggingType` | `QueryLoggingOption` | Current logging type selection for the query |
| `discardData` | `boolean` | Current discard data state |
| `setDiscardData` | `(value: boolean) => void` | Callback to update discard data state |

### Behavior
- **Disabled state**: When `queryReportsDisabled` is `true`, the checkbox is disabled and shows a tooltip explaining the global setting, with an "Edit anyway" escape hatch to override locally via `forceEditDiscardData`
- **Differential logging**: Displays an `InfoBanner` warning when `selectedLoggingType` is `differential` or `differential_ignore_removals`, indicating the Store data setting is ignored
- **Help text**: Dynamically renders context-aware help text depending on the disabled state

## Usage Example

```typescript
import DiscardDataOption from "components/DiscardDataOption";

const QueryForm = () => {
  const [discardData, setDiscardData] = useState(false);

  return (
    <DiscardDataOption
      queryReportsDisabled={false}
      selectedLoggingType="snapshot"
      discardData={discardData}
      setDiscardData={setDiscardData}
    />
  );
};
```
