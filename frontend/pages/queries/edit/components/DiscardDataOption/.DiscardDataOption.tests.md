Unit tests for the `DiscardDataOption` React component, verifying rendering behavior across different `queryReportsDisabled` states and logging type selections.

## Key Components

- **`DiscardDataOption` component** — The component under test, rendered via `@testing-library/react`
- **Test suite** — Five test cases covering the primary UI states of the component

## Test Cases

| Test | Description |
|------|-------------|
| Normal help text | Verifies "Store data" label and standard description render when `queryReportsDisabled={false}` |
| Disabled help text | Verifies "This setting is ignored" text appears when `queryReportsDisabled={true}` |
| "Edit anyway" interaction | Confirms clicking "Edit anyway" restores normal help text from the disabled state |
| Differential logging banner | Checks info banner renders for `selectedLoggingType="differential"` |
| Differential (ignore removals) banner | Checks info banner renders for `selectedLoggingType="differential_ignore_removals"` |

## Usage Example

```typescript
// Running the tests
// From the repo root:
// npx jest DiscardDataOption.tests.tsx

// Component props exercised in tests:
<DiscardDataOption
  queryReportsDisabled={false}
  selectedLoggingType="snapshot"
  discardData={false}
  setDiscardData={jest.fn()}
/>
```

## Notes

- Uses `fireEvent.click` to simulate user interaction with the "Edit anyway" control
- The `discardData` / `setDiscardData` pair follows a controlled input pattern, with `setDiscardData` mocked via `jest.fn()`
