Test suite for the `EditQueryForm` component, verifying form validation states, UI behavior, and conditional rendering based on user permissions and configuration settings.

## Key Components

- **`labelSummariesHandler`** — MSW request handler mocking the `/api/latest/fleet/labels/summary` endpoint
- **`createCustomRenderer`** — Utility for rendering components with mocked context (app config, query state, user roles)
- **`mockQuery` / `mockRouter` / `mockLocation`** — Shared test fixtures used across all test cases

## Test Cases

| Test | Description |
|------|-------------|
| `disables save button for missing query name` | Asserts the Save button is disabled when `lastEditedQueryName` is empty |
| `disables live query button for globally disabled live queries` | Verifies the "Live report" button is disabled and shows a tooltip when `live_query_disabled: true` |
| `shows automations warning icon when query frequency is set to 0` | Confirms a warning icon appears on the automations slider when interval is `Never` (0) |
| `should not show the target selector in the free tier` | Ensures the target selector is hidden for non-premium (`isPremiumTier: false`) users |

## Usage Example

```typescript
// Run all tests in this suite
npx jest EditQueryForm.tests.tsx

// Run a specific test by name
npx jest EditQueryForm.tests.tsx -t "disables save button"
```

## Dependencies

- [`@testing-library/react`](https://testing-library.com/docs/react-testing-library/intro/) for rendering and querying
- [`msw`](https://mswjs.io/) for API mocking via `mockServer`
- [`@testing-library/user-event`](https://testing-library.com/docs/user-event/intro/) for simulating hover/click interactions
- Internal mock factories: `createMockQuery`, `createMockUser`, `createMockConfig`
