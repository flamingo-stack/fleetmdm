React form component for editing and creating Fleet osquery queries, handling SQL editing, scheduling configuration, platform targeting, and save/update workflows.

## Key Components

### Props (`IEditQueryFormProps`)
- `router` / `location` — Navigation context for routing after save actions
- `storedQuery` — Immutable persisted query metadata (author, timestamps)
- `queryIdForEdit` — `null` for new queries; numeric ID for existing ones
- `isQuerySaving` / `isQueryUpdating` — Loading state flags for save operations
- `onSubmitNewQuery` / `onUpdate` — Callbacks for create vs. update flows
- `backendValidators` — Server-side validation errors keyed by field name
- `showConfirmSaveChangesModal` / `setShowConfirmSaveChangesModal` — Modal state lifted to parent

### Internal State & Hooks
- **`QueryContext`** — Provides all mutable query fields (`lastEditedQueryBody`, `lastEditedQueryFrequency`, etc.) and their setters
- **`AppContext`** — Role/tier checks (`isPremiumTier`, `isGlobalAdmin`, `isOnlyObserver`, `gitOpsModeEnabled`)
- **`usePlatformSelector`** — Multi-platform checkbox selector with `getSelectedPlatforms()`
- **`usePlatformCompatibility`** — Detects SQL-compatible platforms via `setCompatiblePlatforms`
- **`useDebouncedCallback`** — Debounces SQL validation (500ms) to avoid excessive re-renders

### Key Helper Functions
- **`validateQuerySQL(query)`** — Runs client-side SQL validation; returns `{ valid, errors }`
- **`getLabelsForScope(...)`** — Resolves `labels_include_any` / `labels_include_all` arrays based on the selected target type and premium tier status

## Usage Example

```typescript
<EditQueryForm
  router={router}
  location={location}
  queryIdForEdit={42}
  storedQuery={storedQuery}
  isStoredQueryLoading={false}
  isQuerySaving={false}
  isQueryUpdating={false}
  onSubmitNewQuery={handleCreate}
  onUpdate={handleUpdate}
  onOsqueryTableSelect={(table) => openSchemaSidebar(table)}
  onOpenSchemaSidebar={openSchemaSidebar}
  renderLiveQueryWarning={() => <LiveQueryWarning />}
  backendValidators={{}}
  showOpenSchemaActionText={true}
  showConfirmSaveChangesModal={false}
  setShowConfirmSaveChangesModal={setModal}
/>
```
