A React modal component for saving a new Fleet query/report, handling form state for name, description, scheduling interval, automations, platform targeting, and advanced logging options.

## Key Components

### `ISaveNewQueryModalProps`
Interface defining the modal's props:
- `queryValue` — the raw SQL query string from the query editor
- `apiTeamIdForQuery` — optional team scope; omit for global queries
- `saveQuery` — callback receiving `ICreateQueryFormData` on submit
- `platformSelector` — injected platform selection hook (`IPlatformSelector`)
- `backendValidators` — server-side field errors
- `existingQuery` — pre-populates interval, logging, and version defaults

### `validateQueryName(name)`
Pure validator that returns `{ valid, errors }`. Enforces that the report name is non-empty.

### `SaveNewQueryModal` (default export)
Stateful modal form managing:
- **Basic fields** — name, description, frequency (interval), observer-can-run checkbox
- **Automations slider** — toggles log destination forwarding with a warning tooltip when interval is `0`
- **Platform selector** — delegated to the injected `platformSelector.render()`
- **Label targeting** (Premium) — `DropdownTargetLabelSelector` with `labelsIncludeAny` / `labelsIncludeAll` scopes fetched via `react-query`
- **Advanced options** — minimum osquery version, logging type, discard-data toggle (collapsed by default)

## Usage Example

```typescript
<SaveNewQueryModal
  queryValue="SELECT * FROM osquery_info;"
  apiTeamIdForQuery={42}
  isLoading={isSaving}
  saveQuery={(formData) => handleSave(formData)}
  toggleSaveNewQueryModal={() => setShowModal(false)}
  backendValidators={serverErrors}
  platformSelector={platformSelector}
  queryReportsDisabled={false}
/>
```

## Notes

- Label fetching is gated on `isPremiumTier && !!currentTeam` to avoid premature API calls during context hydration.
- The **Save** button is disabled when "Custom" targeting is selected but no labels are checked (`canSave` guard).
