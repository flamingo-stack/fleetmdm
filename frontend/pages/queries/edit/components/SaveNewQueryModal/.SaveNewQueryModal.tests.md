Test suite for the `SaveNewQueryModal` component, validating rendering behavior, form interactions, platform selection, and premium-tier label targeting functionality.

## Key Components

- **`SaveNewQueryModal`** — The component under test; a modal for saving a new Fleet query with fields for name, description, interval, and advanced options
- **`labelSummariesHandler`** — MSW request handler that mocks the `/api/latest/fleet/labels/summary` endpoint with sample label data
- **`defaultProps`** — Shared baseline props including a mock query, platform selector, and callback stubs
- **`createCustomRenderer`** — Test utility that wraps components with app context (user, config, tier)

## Test Coverage

| Test Case | Description |
|-----------|-------------|
| Initial render & editing | Verifies all form fields are present and accepts user input |
| Advanced options toggle | Confirms `Minimum osquery version` and `Logging` fields appear/hide on click |
| Empty name validation | Asserts error message when saving without a query name |
| Free tier — no target selector | Confirms `All hosts` target option is absent for non-premium users |
| No platforms selected | Validates the Save button is disabled when `isAnyPlatformSelected` is `false` |
| Platform submission | Ensures `platform` is serialized as `"linux,macos"` on save |
| Premium — target selector | Verifies `All hosts` and `Custom` radio options appear and `All hosts` is pre-selected |
| Premium — custom target gate | Save button is disabled until at least one label is checked |
| Premium — label submission | Confirms `labels_include_any` contains selected label names on save |
| Premium — all-hosts clears labels | Confirms `labels_include_any` is `[]` when saving in `All hosts` mode |

## Usage Example

```typescript
// Run only the premium-tier tests
npx jest SaveNewQueryModal.tests.tsx --testNamePattern="premium tier"

// Run all tests
npx jest SaveNewQueryModal.tests.tsx
```
