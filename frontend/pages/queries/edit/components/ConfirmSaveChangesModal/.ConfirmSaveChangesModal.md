A confirmation modal dialog that warns users before saving changes to a report, particularly when those changes will delete previous results.

## Key Components

### `IConfirmSaveChangesModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `isUpdating` | `boolean` | Shows a loading state on the Save button during the update operation |
| `onSaveChanges` | `(evt: React.MouseEvent<HTMLButtonElement>) => void` | Callback triggered when the user confirms the save action |
| `onClose` | `() => void` | Callback triggered when the modal is dismissed or cancelled |
| `showChangedSQLCopy` | `boolean` (optional) | When `true`, displays SQL-specific warning text; defaults to `false` |

### `ConfirmSaveChangesModal`
The default export — a React functional component rendering a `Modal` with a contextual warning message and two action buttons (Save / Cancel).

**Warning text variants:**
- **SQL change**: *"Changing this report's SQL will delete its previous results..."*
- **General change**: *"The changes you are making to this report will delete its previous results."*

## Usage Example

```typescript
import ConfirmSaveChangesModal from "components/ConfirmSaveChangesModal";

const MyReportEditor = () => {
  const [showModal, setShowModal] = useState(false);
  const [isUpdating, setIsUpdating] = useState(false);

  const handleSave = (evt: React.MouseEvent<HTMLButtonElement>) => {
    setIsUpdating(true);
    // perform save logic...
  };

  return (
    <>
      {showModal && (
        <ConfirmSaveChangesModal
          isUpdating={isUpdating}
          onSaveChanges={handleSave}
          onClose={() => setShowModal(false)}
          showChangedSQLCopy={true}
        />
      )}
    </>
  );
};
```
