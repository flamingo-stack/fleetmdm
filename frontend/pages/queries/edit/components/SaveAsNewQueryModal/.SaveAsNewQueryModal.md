A modal component that allows users to duplicate an existing query/report under a new name and optionally assign it to a different team.

## Key Components

### Interfaces
- **`ISaveAsNewQueryModal`** — Props: `router`, `location`, `initialQueryData` (prefills form), optional `hostId`, and `onExit` callback
- **`ISANQFormData`** — Internal form state holding `queryName` (string) and `team` (partial `ITeamSummary`)
- **`ISANQFormErrors`** — Validation error map for `queryName` and `team` fields

### Core Logic
- **`validateFormData`** — Validates that `queryName` is non-empty; returns an error map
- **`handleSave`** — Submits form via `queryAPI.create()`, then navigates to the new report's detail page. Handles duplicate-name and invalid-platform errors with contextual flash messages
- **`onTeamChange`** — Resolves a `teamId` to a full team object from `userTeams`
- **`onInputChange`** — Updates form state and re-runs validation only for fields that previously had errors (avoids premature validation)

### UI
- Renders a `Modal` with an `InputField` for the query name (pre-populated as `"Copy of <original name>"`)
- Shows a `TeamsDropdown` only for premium-tier users with more than one accessible team
- Save button is disabled while saving or when validation errors exist

## Usage Example

```typescript
<SaveAsNewQueryModal
  router={router}
  location={location}
  initialQueryData={{
    name: "Weekly Vulnerability Scan",
    query: "SELECT * FROM vulnerabilities;",
    fleet_id: 2,
    // ...other ICreateQueryFormData fields
  }}
  hostId={42}
  onExit={() => setShowModal(false)}
/>
```

On save, the user is redirected to `PATHS.REPORT_DETAILS(newQuery.id)` with `fleet_id` and `host_id` as query parameters.
