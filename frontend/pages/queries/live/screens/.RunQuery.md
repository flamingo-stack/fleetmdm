Manages the lifecycle of a live distributed query campaign, handling WebSocket connections to stream real-time results from Fleet's query execution engine.

## Key Components

### Props (`IRunQueryProps`)
| Prop | Type | Description |
|------|------|-------------|
| `storedQuery` | `IQuery \| undefined` | The saved query definition |
| `selectedTargets` | `ITarget[]` | Hosts/groups targeted by the query |
| `queryId` | `number \| null` | ID of the stored query |
| `setSelectedTargets` | `(value: ITarget[]) => void` | Callback to update targets |
| `goToQueryEditor` | `() => void` | Navigation callback to the editor |
| `targetsTotalCount` | `number` | Total number of targeted hosts |

### Core Functions
- **`connectAndRunLiveQuery`** — Opens a SockJS WebSocket to `/v1/fleet/results`, authenticates, selects the campaign, and streams incoming row/error data into `campaignState`
- **`onRunQuery`** — Debounced handler that calls `queryAPI.run()` to create a campaign, then initiates the WebSocket connection
- **`onStopQuery`** — Stops the query by calling `teardownDistributedQuery()`
- **`teardownDistributedQuery`** — Clears the polling interval, resets running state, and closes the socket
- **`removeSocket`** — Closes and nullifies the global WebSocket reference

### Constants
- `CAMPAIGN_LIMIT` (`250000`) — Maximum combined result+error rows before auto-stopping
- `RESPONSE_COUNT_ZERO` — Initial response counter shape

## Usage Example

```typescript
<RunQuery
  storedQuery={currentQuery}
  selectedTargets={selectedTargets}
  queryId={42}
  setSelectedTargets={setSelectedTargets}
  goToQueryEditor={() => router.push("/queries/42/edit")}
  targetsTotalCount={150}
/>
```

The component auto-runs the query on mount via `useEffect(() => { onRunQuery(); }, [])` and delegates all result rendering to [`QueryResults`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/pages/queries/edit/components/QueryResults/index.tsx). If the edited SQL differs from the stored query, the campaign is treated as a new (unsaved) query by passing `queryId: null` to the API.
