Test suite for the `QueriesTable` component, validating rendering behavior across different user roles, tier configurations, team scopes, and query states.

## Key Components

- **`testRawGlobalQueries`** — Fixture array of two global `ISchedulableQuery` objects (no `team_id`)
- **`testRawTeamQueries`** — Fixture array of two team-scoped `ISchedulableQuery` objects (`team_id: 1`)
- **`renderAsPremiumGlobalAdmin`** — Shared custom renderer with premium tier + global admin context
- **Test suites** — Eight `it` blocks covering empty states, Primo mode, inherited queries, search, and badge rendering

## Test Coverage

| Scenario | Assertion |
|---|---|
| Free tier, no queries | Shows "No reports yet", search disabled |
| Premium, all teams, no queries | Shows "No reports apply to all fleets" |
| Premium, specific team, no queries | Shows "No reports for this fleet" |
| Primo mode (all fleets) | Shows generic "No reports yet", suppresses fleet-specific text |
| Primo mode (specific team) | Shows generic "No reports yet", suppresses team-specific text |
| Team view with global + team queries | Renders both sets with "Inherited" badge and "Interval" column |
| Search with no matches | Shows "No matching reports" |
| `observer_can_run` query | Renders badge and tooltip on hover |
