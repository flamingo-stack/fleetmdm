Renders a paginated, searchable, and filterable table of Fleet report queries, supporting platform filtering, row selection, sorting, and deletion actions.

## Key Components

### `QueriesTable` (default export)
The primary React component that wraps `TableContainer` with query-specific logic.

**Props (`IQueriesTableProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `queries` | `IEnhancedQuery[] \| null` | Query data to display |
| `totalQueriesCount` | `number \| undefined` | Total count for pagination display |
| `hasNextResults` | `boolean` | Controls next-page navigation |
| `curTeamScopeQueriesPresent` | `boolean` | Enables multi-row selection and delete |
| `onDeleteQueryClick` | `(ids: number[]) => void` | Bulk delete handler |
| `queryParams` | `object` | URL-driven filter/sort/pagination state |
| `currentTeamId` | `number \| undefined` | Active team context |
| `isPremiumTier` | `boolean \| undefined` | Gates fleet-scoped empty state messaging |

### Internal Behaviors
- **`onQueryChange`** — Syncs table sort, search, and pagination state to the URL via `router.push` / `router.replace`, using `isFirstNavigation` ref to avoid history pollution on initial load.
- **`handlePlatformFilterDropdownChange`** — Updates the `platform` URL param and resets pagination.
- **`handleRowSelect`** — Navigates to `PATHS.REPORT_DETAILS` with the selected query's ID and active team.
- **`renderPlatformDropdown`** — Renders the `DropdownWrapper` platform filter control injected into `TableContainer`.

### Constants
- `PLATFORM_FILTER_OPTIONS` — Dropdown options: All platforms, macOS (`darwin`), Windows, Linux.
- `DEFAULT_SORT_HEADER` — `"name"`, `DEFAULT_SORT_DIRECTION` — `"asc"`.

## Usage Example

```typescript
<QueriesTable
  queries={queries}
  totalQueriesCount={total}
  hasNextResults={hasMore}
  curTeamScopeQueriesPresent={!!queries?.length}
  isLoading={isLoading}
  onDeleteQueryClick={(ids) => handleDelete(ids)}
  onAddReportClick={() => openAddReportModal()}
  canAddReport={isAdmin}
  router={router}
  queryParams={queryParams}
  currentTeamId={currentTeamId}
  isPremiumTier={isPremiumTier}
/>
```

> **Note:** URL params are the source of truth for filter/sort state. The component initializes from `queryParams` and pushes updates back to the router on change.
