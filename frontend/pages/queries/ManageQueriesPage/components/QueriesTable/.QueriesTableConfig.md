Defines and exports the `generateColumnConfigs` function that builds the column configuration array for the queries/reports table, conditionally including a selection column based on user permissions.

## Key Components

### `generateColumnConfigs(options)`
The default export. Accepts a config object and returns an `IDataColumn[]` array for use with React Table.

| Option | Type | Description |
|---|---|---|
| `currentUser` | `IUser` | Used to evaluate role-based permissions |
| `currentTeamId` | `number \| undefined` | Scopes column behavior to a team or all-teams view |
| `omitSelectionColumn` | `boolean` | When `true`, skips prepending the checkbox column (default: `false`) |

### Column Definitions

| Column | Accessor | Notes |
|---|---|---|
| **Selection** | — | Prepended only for admins/maintainers; uses `GitOpsModeTooltipWrapper`; inherited queries are non-selectable |
| **Name** | `name` | `LinkCell` to report details; shows observer-can-run icon and "Inherited" pill badge when applicable |
| **Platform** | `platform` | Parses comma-separated platform string; empty when query has no interval |
| **Interval** | `interval` | Formats seconds via `secondsToDhms`; shows tooltip when unscheduled |
| **Performance impact** | `performance` | Renders `PerformanceImpactCell` with tooltip header |
| **Automations** | `automations_enabled` | Renders `QueryAutomationsStatusIndicator` |
| **Last modified** | `updated_at` | Renders `HumanTimeDiffWithDateTip` |

## Usage Example

```typescript
import generateColumnConfigs from "./QueriesTableConfig";

const columns = generateColumnConfigs({
  currentUser,
  currentTeamId: 3,
  omitSelectionColumn: false,
});

// Pass to TableContainer
<TableContainer
  columns={columns}
  data={queries}
/>
```
