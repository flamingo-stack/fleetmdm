A confirmation modal component for deleting selected query/report records, providing Delete and Cancel actions with a loading state.

## Key Components

- **`DeleteQueryModal`** — Default export; a functional React component that renders a `Modal` with confirmation messaging and action buttons.
- **`IDeleteQueryModalProps`** — Interface defining the component's props:
  - `isUpdatingQueries` — Boolean flag that triggers a loading spinner on the Delete button during async operations.
  - `onCancel` — Callback invoked when the user cancels (via button click or modal exit).
  - `onSubmit` — Callback invoked when the user confirms deletion (via button click or Enter key).

## Usage Example

```typescript
import DeleteQueryModal from "components/DeleteQueryModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);
  const [isDeleting, setIsDeleting] = useState(false);

  const handleDelete = async () => {
    setIsDeleting(true);
    await deleteSelectedQueries();
    setIsDeleting(false);
    setShowModal(false);
  };

  return (
    <>
      {showModal && (
        <DeleteQueryModal
          isUpdatingQueries={isDeleting}
          onCancel={() => setShowModal(false)}
          onSubmit={handleDelete}
        />
      )}
    </>
  );
};
```

## Notes

- Supports keyboard confirmation via the `onEnter` prop passed to `Modal`, allowing users to press Enter to confirm deletion.
- The Delete button uses the `alert` variant (destructive styling) and displays a loading indicator while `isUpdatingQueries` is `true`.
