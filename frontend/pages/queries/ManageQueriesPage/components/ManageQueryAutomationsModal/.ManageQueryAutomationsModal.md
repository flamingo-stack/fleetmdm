A modal component for managing query report automations, allowing users to select which queries send data to a configured log destination.

## Key Components

- **`ManageQueryAutomationsModal`** — Main modal component that fetches team-scoped queries, renders checkboxes for enabling/disabling automations, and submits changes
- **`IQueryAutomationsSubmitData`** — Exported interface containing `newAutomatedQueryIds` and `previousAutomatedQueryIds` arrays for diffing automation state changes
- **`IManageQueryAutomationsModalProps`** — Props interface defining required callbacks (`onSubmit`, `onCancel`), state flags, log destination config, and optional team scoping
- **`ICheckedQuery`** — Internal interface tracking per-query checkbox state alongside `id`, `name`, and `interval`

### Internal Behavior
- Fetches queries via `react-query` with `mergeInherited: false` to exclude inherited global queries
- Sorts queries alphabetically client-side
- Syncs `queryItems` checkbox state from async fetch results via `useEffect`
- Listens for `Enter`/`NumpadEnter` keyboard events to trigger form submission
- Respects GitOps mode by disabling checkboxes and the save button via `GitOpsModeTooltipWrapper`

## Usage Example

```typescript
<ManageQueryAutomationsModal
  isUpdatingAutomations={isLoading}
  onSubmit={({ newAutomatedQueryIds, previousAutomatedQueryIds }) => {
    // diff arrays to determine which queries to enable/disable
    handleSave(newAutomatedQueryIds, previousAutomatedQueryIds);
  }}
  onCancel={() => setShowModal(false)}
  isShowingPreviewDataModal={showPreview}
  togglePreviewDataModal={() => setShowPreview((prev) => !prev)}
  teamId={currentTeam?.id}
  logDestination="filesystem"
  filesystemDestination="/var/log/fleet"
/>
```
