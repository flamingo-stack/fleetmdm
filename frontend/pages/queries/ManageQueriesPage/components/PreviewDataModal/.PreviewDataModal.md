A modal component that displays a sample JSON payload preview for scheduled query log output, helping users understand the data format sent to their configured log destination.

## Key Components

- **`PreviewDataModal`** — Default export; a React functional component that renders a modal with a syntax-highlighted JSON example
- **`IPreviewDataModalProps`** — Interface requiring a single `onCancel` callback prop
- **`syntaxHighlight`** — Utility imported from `utilities/helpers` used to render colorized JSON inside a `<pre>` block via `dangerouslySetInnerHTML`
- **`TooltipWrapper`** — Wraps the descriptive paragraph to clarify that the `snapshot` key contains query-specific results

## Usage Example

```typescript
import PreviewDataModal from "components/PreviewDataModal";

const ScheduledQueryForm = () => {
  const [showPreview, setShowPreview] = React.useState(false);

  return (
    <>
      <button onClick={() => setShowPreview(true)}>Preview Data</button>
      {showPreview && (
        <PreviewDataModal onCancel={() => setShowPreview(false)} />
      )}
    </>
  );
};
```

## Notes

- The displayed JSON is a static example payload (not live data) illustrating the structure of a snapshot-type osquery result
- Used in both global and team scheduled query creation/editing flows
- The `snapshot` field tooltip clarifies that real query results replace the placeholder values
