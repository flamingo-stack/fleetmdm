React component that displays a status indicator for query automations, showing whether automations are active, paused, or disabled based on configuration state.

## Key Components

### `IQueryAutomationsStatusIndicator`
Props interface with two fields:
- `automationsEnabled` — boolean flag controlling whether automations are active
- `interval` — numeric interval value; `0` triggers the paused state

### `QueryAutomationsStatusIndicator`
Functional component that derives one of three statuses and renders a `StatusIndicator`:

| Condition | Status |
|---|---|
| `automationsEnabled && interval > 0` | `"on"` |
| `automationsEnabled && interval === 0` | `"paused"` |
| `!automationsEnabled` | `"off"` |

A tooltip is injected only in the `"paused"` state, prompting users to set an interval to resume automations.

## Usage Example

```typescript
import QueryAutomationsStatusIndicator from "components/QueryAutomationsStatusIndicator";

// Automations active
<QueryAutomationsStatusIndicator automationsEnabled={true} interval={3600} />

// Automations paused (enabled but no interval set)
<QueryAutomationsStatusIndicator automationsEnabled={true} interval={0} />

// Automations disabled
<QueryAutomationsStatusIndicator automationsEnabled={false} interval={3600} />
```

## Notes

- Delegates all rendering to the shared `StatusIndicator` component using `customIndicatorType="query-automations"`.
- Tooltip messaging only appears in the `"paused"` state; `"on"` and `"off"` states render with no tooltip.
