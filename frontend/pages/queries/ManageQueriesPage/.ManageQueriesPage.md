Renders the main Reports/Queries management page, providing a full-featured interface for listing, filtering, deleting, and automating Fleet queries across teams.

## Key Components

- **`ManageQueriesPage`** — Primary page component that orchestrates query listing, team filtering, deletion, and automation management
- **`enhanceQuery`** — Exported utility that transforms a raw `ISchedulableQuery` into an `IEnhancedQuery` by appending performance impact description and targeted platforms array
- **`getTargetedPlatforms`** — Internal helper that parses a comma-separated platform string into a filtered array of `QueryablePlatform` values

### Child Components & Modals
- `QueriesTable` — Paginated, sortable table with server-side filtering via URL params
- `DeleteQueryModal` — Confirms single or bulk query deletion
- `ManageQueryAutomationsModal` — Enables/disables per-query log automations
- `PreviewDataModal` — Preview automation data (cosmetically overlays the automations modal)

### State & Data Flow
- Query data is fetched via `react-query` using team ID, pagination, search, sort, and platform filter from URL params
- Table state changes are propagated back to the API by pushing updated params to the router URL
- Supports deep-linking to the automations modal via `?manage_automations=1` query param (gated on role and data availability)

## Usage Example

```typescript
// Rendered by the router at PATHS.MANAGE_QUERIES
<ManageQueriesPage
  router={router}
  location={{
    pathname: "/reports",
    query: {
      platform: "darwin",
      page: "0",
      order_key: "name",
      order_direction: "asc",
    },
    search: "?platform=darwin",
  }}
/>

// Standalone utility usage
import { enhanceQuery } from "./ManageQueriesPage";

const enhanced = enhanceQuery(rawQuery);
// enhanced.performance => "Minimal" | "Considerable" | "Excessive" | "Undetermined"
// enhanced.targetedPlatforms => ["darwin", "windows"]
```
