Provides configuration constants and types for the Query Details page, including filter keys, query parameter types, and default sort settings.

## Key Components

- **`QUERY_DETAILS_PAGE_FILTER_KEYS`** – Readonly tuple of supported filter keys (`"model"`, `"vendor"`) for the Query Details page.
- **`QueryDetailsPageQueryParams`** – Type alias representing the expected URL query parameters, combining sort fields (`order_key`, `order_direction`) with the defined filter keys.
- **`DEFAULT_SORT_HEADER`** – Default column used for sorting results (`"host_name"`).
- **`DEFAULT_SORT_DIRECTION`** – Default sort direction (`"asc"`).

## Usage Example

```typescript
import {
  QUERY_DETAILS_PAGE_FILTER_KEYS,
  QueryDetailsPageQueryParams,
  DEFAULT_SORT_HEADER,
  DEFAULT_SORT_DIRECTION,
} from "./QueryDetailsPageConfig";

// Type-safe query params for the Query Details page
const queryParams: QueryDetailsPageQueryParams = {
  order_key: DEFAULT_SORT_HEADER,
  order_direction: DEFAULT_SORT_DIRECTION,
  model: "MacBook Pro",
  vendor: "Apple",
};

// Iterate over supported filter keys
QUERY_DETAILS_PAGE_FILTER_KEYS.forEach((key) => {
  console.log(`Filter key: ${key}, value: ${queryParams[key]}`);
});
```

## Notes

- `QUERY_DETAILS_PAGE_FILTER_KEYS` is declared `as const` to ensure literal type inference across filter-related logic.
- `QueryDetailsPageQueryParams` is intended to replace ad-hoc `location.query` prop typing on the Query Details page (pending refactor).
