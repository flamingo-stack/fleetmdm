React component that renders contextual empty-state messaging for query report pages when no results are available, handling multiple scenarios such as caching disabled, no schedule interval, and results still collecting.

## Key Components

**`INoResultsProps`** — Interface defining required/optional props:

| Prop | Type | Description |
|---|---|---|
| `queryId` | `number` | Used to build live report links |
| `queryInterval` | `number?` | Schedule interval in seconds |
| `queryUpdatedAt` | `string?` | Timestamp of last update |
| `disabledCaching` | `boolean` | Whether caching is disabled for this query |
| `disabledCachingGlobally` | `boolean` | Org-level caching disabled flag |
| `discardDataEnabled` | `boolean` | Whether "Discard data" is set on the query |
| `loggingSnapshot` | `boolean` | Whether logging mode is Snapshot |
| `canLiveQuery` | `boolean?` | Permission to run live queries |
| `canEditQuery` | `boolean?` | Permission to edit the query |

**`secondsCheckbackTime()`** — Calculates remaining seconds until a cached result is expected, based on `queryInterval` and time since last update.

**`getNoResultsInfo()`** — Returns `[header, details]` tuple for the `EmptyState` component, prioritized as:
1. Caching disabled (with tooltip explaining why)
2. No schedule interval (suggests adding one or running live)
3. Default: no data yet (suggests live report to troubleshoot)

## Usage Example

```typescript
<NoResults
  queryId={42}
  queryInterval={3600}
  queryUpdatedAt="2024-01-15T10:00:00Z"
  disabledCaching={false}
  disabledCachingGlobally={false}
  discardDataEnabled={false}
  loggingSnapshot={true}
  canLiveQuery={true}
  canEditQuery={false}
/>
```
