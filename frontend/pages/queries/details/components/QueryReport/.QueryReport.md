Renders a paginated, filterable table of query report results with CSV export functionality for a given Fleet MDM query.

## Key Components

- **`QueryReport`** – Default export; main component that displays flattened query results in a `TableContainer` with client-side filtering, pagination, and multi-column filter support
- **`flattenResults`** – Utility function that merges host metadata (`host_id`, `host_display_name`, `last_fetched`) with per-query variable columns into a flat row object
- **`renderTableButtons`** – Renders the "Export results" button that triggers CSV download via `FileSaver`
- **`renderResultsCount`** – Renders a result count; wraps in a `TooltipWrapper` with clipping explanation when `isClipped` is `true`
- **`onExportQueryResults`** – Generates and saves a CSV file named after the current query using `generateCSVQueryResults`

## Props

| Prop | Type | Description |
|---|---|---|
| `queryReport` | `IQueryReport` | Report data including results and query ID |
| `queryId` | `number` | Used for live report routing |
| `isClipped` | `boolean` | Indicates report data has been sampled/truncated |
| `canLiveQuery` | `boolean` | Shows live report link in empty state when `true` |

## Usage Example

```typescript
import QueryReport from "./QueryReport";

<QueryReport
  queryReport={queryReportData}
  queryId={42}
  isClipped={false}
  canLiveQuery={true}
/>
```

## Notes

- Column configs are memoized via `useMemo` and generated by `generateReportColumnConfigsFromResults`
- Empty states (no results) are handled upstream in `QueryDetailsPage.tsx`; this component renders its own inline empty state only within the table
- Filtered row state (`filteredResults`) is synced via `setExportRows` to ensure CSV exports reflect active filter state
