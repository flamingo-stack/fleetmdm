Generates dynamic `react-table` column configurations for the Query Report results table, mapping WebSocket query result data into typed, sortable, and filterable column definitions.

## Key Components

### `generateReportColumnConfigsFromResults` *(default export)*
Builds an array of `Column<IWebSocketData>` configs from live query results. For each detected column:
- Renders a `HeaderCell` with special-cased label for `last_fetched`
- Renders a `LinkCell` to `HOST_REPORT_RESULTS` for the host display name column
- Formats `last_fetched` values using `humanHostLastSeen`
- Truncates cell values exceeding 300 characters via `internallyTruncateText`
- Assigns `alphanumeric` or `caseInsensitive` sort type based on column data type
- Attaches `DefaultColumnFilter` to each column

### `_unshiftHostname` *(internal)*
Reorders column headers so the host display name appears first. Also strips the legacy `host_hostname` column (kept for backward compatibility until the v5 API response is updated).

## Usage Example

```typescript
import generateReportColumnConfigsFromResults from "./QueryReportTableConfig";

// Inside a component receiving live query results
const columns = generateReportColumnConfigsFromResults(
  queryResults, // IWebSocketData[]
  queryId       // number | null
);

// Pass to TableContainer or react-table's useTable
<TableContainer
  columns={columns}
  data={queryResults}
/>
```

## Notes

- `host_id` is intentionally excluded from rendered columns — it is used only to construct the host report link path via `PATHS.HOST_REPORT_RESULTS(hostID, queryId)`
- If `queryId` is `null`, the host name renders as plain text instead of a link
- The `_unshiftHostname` helper handles both `host_display_name` (current) and `host_hostname` (deprecated pre-v5) API fields
