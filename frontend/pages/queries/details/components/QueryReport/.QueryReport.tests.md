Test suite for the `QueryReport` component, validating rendering behavior for query result data including normal display, cell truncation, and clipped report tooltip interactions.

## Key Components

- **Normal cell rendering** — Verifies that cell values under 300 characters are displayed without truncation indicators
- **Truncated cell rendering** — Confirms that long cell values (>300 chars) are visually truncated with `...` and a `(truncated)` label
- **Clipped report tooltip** — Tests that hovering the result count triggers a tooltip explaining that Fleet has retained only a sample of early results

## Usage Example

```typescript
// Run the test suite
// pnpm test QueryReport.tests.tsx

// Example of what's being tested - rendering with clipped results
import { renderWithSetup } from "test/test-utils";

const { user } = renderWithSetup(
  <QueryReport
    queryId={1}
    isClipped={true}
    queryReport={{
      query_id: 1,
      results: [
        {
          host_id: 1,
          host_name: "host1",
          last_fetched: "2021-01-01",
          columns: { col1: "value1", col2: "value2" },
        },
      ],
      report_clipped: true,
    }}
  />
);

// Hover to trigger the clipped report tooltip
await user.hover(screen.getByText(/\d+ result/));
```

## Test Cases

| Scenario | Assertion |
|---|---|
| Cell value ≤ 300 chars | Value renders; no `...` or `(truncated)` shown |
| Cell value > 300 chars | `...` and `(truncated)` present alongside normal values |
| Report clipped (`isClipped: true`) | Tooltip appears on hover with sample retention message |
