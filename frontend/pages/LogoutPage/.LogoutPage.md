Handles user logout by destroying the session, removing the auth token, and redirecting to the appropriate destination based on sandbox mode.

## Key Components

- **`LogoutPage`** — Renderless React component that executes logout logic on mount via `useEffect`
- **`ILogoutPageProps`** — Interface requiring an `InjectedRouter` instance for fallback navigation

## Behavior

1. Calls `sessionsAPI.destroy()` to invalidate the server-side session
2. Removes the local auth token via `authToken.remove()`
3. Redirects after 500ms:
   - **Sandbox mode** → `https://www.fleetdm.com/logout`
   - **Standard mode** → `PATHS.ROOT`
4. On failure, navigates back and displays an error flash notification

## Usage Example

```typescript
// Rendered by the router at the /logout path
import LogoutPage from "pages/LogoutPage";

// Route definition
<Route path={PATHS.LOGOUT} component={LogoutPage} />
```

## Notes

- Returns `null` — no UI is rendered; this is a purely side-effect-driven component
- The 500ms delay allows any cleanup or animations to complete before redirect
- Sandbox mode redirect defers to the FleetDM marketing site for post-logout handling
