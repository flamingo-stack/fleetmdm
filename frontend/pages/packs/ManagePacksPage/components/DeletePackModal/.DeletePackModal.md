A confirmation modal component for deleting one or more query packs, providing Delete and Cancel actions with a loading state.

## Key Components

- **`DeletePackModal`** — Default export. Renders a `Modal` with a confirmation message and two action buttons.
- **`IDeletePackModalProps`** — Interface defining the component's props:
  - `onCancel` — Callback fired when the user dismisses or cancels the modal.
  - `onSubmit` — Callback fired when the user confirms deletion (also triggered on `Enter` key).
  - `isUpdatingPack` — Boolean that toggles the loading spinner on the Delete button during the async operation.

## Usage Example

```typescript
import DeletePackModal from "components/DeletePackModal";

<DeletePackModal
  onCancel={() => setShowDeleteModal(false)}
  onSubmit={handleDeletePacks}
  isUpdatingPack={isDeletingPacks}
/>
```

## Notes

- Supports keyboard confirmation via `onEnter` (pressing `Enter` triggers `onSubmit`).
- The Delete button uses the `alert` variant (destructive styling) and displays a loading indicator while `isUpdatingPack` is `true`.
- Cancel uses the `inverse-alert` variant for a non-destructive visual treatment.
