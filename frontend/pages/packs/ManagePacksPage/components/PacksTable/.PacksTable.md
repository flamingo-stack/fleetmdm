Renders a searchable, filterable table of osquery query packs with bulk selection actions for enabling, disabling, and deleting packs.

## Key Components

- **`PacksTable`** — Main component that wraps `TableContainer` with pack-specific configuration
- **`filteredPacks`** — Local state derived from the `packs` prop, filtered client-side by `searchString`
- **`onQueryChange`** — Callback that updates the search string from `TableContainer`'s query data
- **`emptyState()`** — Returns context-aware empty state props (no packs vs. no search results)
- **`secondarySelectActions`** — Enable/Disable bulk actions shown when rows are selected
- **`renderPackCount`** — Memoized renderer for the pack count badge above the table

## Props

| Prop | Type | Description |
|------|------|-------------|
| `onDeletePackClick` | `(ids: number[]) => void` | Called with selected pack IDs for deletion |
| `onEnablePackClick` | `(ids: number[]) => void` | Called with selected pack IDs to enable |
| `onDisablePackClick` | `(ids: number[]) => void` | Called with selected pack IDs to disable |
| `onCreatePackClick` | `MouseEventHandler` | Triggered by the "Create new pack" button in the empty state |
| `packs` | `IPack[]` | Optional array of pack objects to display |
| `isLoading` | `boolean` | Shows loading state in the table |

## Usage Example

```typescript
<PacksTable
  packs={packs}
  isLoading={isLoadingPacks}
  onCreatePackClick={handleCreatePackClick}
  onDeletePackClick={handleDeletePackClick}
  onEnablePackClick={handleEnablePackClick}
  onDisablePackClick={handleDisablePackClick}
/>
```

## Notes

- Filtering is purely client-side via `Array.filter` on `pack.name`
- Column headers and row data are generated via `generateTableHeaders` and `generateDataSet` from [`PacksTableConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/pages/packs/PacksPage/components/PacksTable/PacksTableConfig.tsx)
- Pagination is disabled; all packs are shown in a single list
