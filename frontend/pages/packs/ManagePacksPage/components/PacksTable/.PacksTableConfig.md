Defines the table configuration for the Packs list view, providing column definitions and data transformation utilities for rendering packs in a sortable, selectable table.

## Key Components

### `generateTableHeaders(): IDataColumn[]`
Returns an array of column definitions for the packs table, including:
- **Selection** — Checkbox column for row selection (select all / individual row)
- **Name** — Sortable link column navigating to `PATHS.EDIT_PACK(id)`
- **Reports** — Displays `query_count` for each pack
- **Hosts** — Displays `total_hosts_count`
- **Last Modified** — Formats `updated_at` as `MM/dd/yy` using `date-fns`
- **Status** — Non-sortable column rendering a `StatusIndicator` (`enabled` / `disabled`)

### `enhancePackData(packs: IPack[] | undefined): IPackTableData[]`
Maps raw `IPack` objects to flat `IPackTableData` objects, deriving `status` from the `disabled` boolean flag.

### `generateDataSet(packs: IPack[] | undefined): IPackTableData[]`
Thin wrapper around `enhancePackData` that returns the transformed dataset ready for table consumption.

## Usage Example

```typescript
import { generateTableHeaders, generateDataSet } from "./PacksTableConfig";

const columns = generateTableHeaders();
const tableData = generateDataSet(packs);

// Pass to TableContainer or react-table instance
<TableContainer
  columns={columns}
  data={tableData}
/>
```

## Notes

- Column definitions follow the [react-table v7 API](https://react-table.tanstack.com/docs/api/useTable#cell-properties)
- `IPack.disabled` is coerced to a human-readable `"enabled"` / `"disabled"` string for `StatusIndicator`
- The selection column sets `disableHidden: true` to prevent it from being toggled off
