Manages the Fleet MDM query packs list page, providing CRUD operations (create, delete, enable/disable) for osquery packs with real-time data fetching and user notifications.

## Key Components

### `ManagePacksPage` (default export)
Main page component that orchestrates pack management. Consumes `AppContext` for observer role gating and `NotificationContext` for success/error flash messages.

**State:**
- `selectedPackIds` — IDs of packs selected for bulk operations
- `showDeletePackModal` — controls delete confirmation modal visibility
- `isUpdatingPack` — tracks in-flight delete requests

**Data Fetching:**
- Uses `react-query` with key `"packs"` to call `packsAPI.loadAll()`
- `refetchOnWindowFocus` disabled; auto-selects `data.packs` from response

### `renderTable` (helper)
Pure render function that returns either a `<TableDataError />` on API failure or a `<PacksTable />` with action callbacks injected.

### Key Handlers

| Handler | Behavior |
|---|---|
| `onCreatePackClick` | Navigates to `PATHS.NEW_PACK` |
| `onDeletePackClick` | Opens delete modal, sets selected IDs |
| `onDeletePackSubmit` | Parallel-deletes all selected packs via `Promise.all`, then refetches |
| `onEnablePackClick` / `onDisablePackClick` | Calls `packsAPI.update(id, { disabled })` in parallel for all selected packs |

## Usage Example

```typescript
// Rendered by the router — receives router prop from react-router v3
import ManagePacksPage from "./ManagePacksPage";

<ManagePacksPage router={router} />
```

**Observer role gating:** The "Create new pack" button is hidden when `isOnlyObserver` is `true` or no packs exist yet.
