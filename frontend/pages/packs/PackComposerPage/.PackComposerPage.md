Page component for creating new osquery packs, handling form submission, target selection, and navigation upon successful pack creation.

## Key Components

- **`PackComposerPage`** — Main page component that orchestrates pack creation flow
- **`onFetchTargets`** — Callback that tracks the count of selected targets from the API response
- **`handleSubmit`** — Async handler that calls `packsAPI.create()`, navigates to the new pack on success, and surfaces flash notifications for duplicate name errors or general failures

## Usage Example

```typescript
// Rendered via the router; receives router as a prop
import PackComposerPage from "pages/packs/PackComposerPage";

<Route
  path={PATHS.NEW_PACK}
  component={PackComposerPage}
/>
```

## Context Dependencies

| Context | Value Used |
|---|---|
| `AppContext` | `isPremiumTier` — passed to `NewPackForm` to conditionally render premium features |
| `NotificationContext` | `renderFlash` — displays success/error toast notifications |

## Error Handling

| Condition | Message |
|---|---|
| Duplicate pack name | `"Pack names must be unique."` |
| Generic failure | `"Unable to create pack."` |
| Success | Redirects to `PATHS.PACK(packID)` with a success flash |
