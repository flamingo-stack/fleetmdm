Modal component for creating and editing scheduled queries within osquery packs, handling form state for query selection, frequency, logging type, platform, osquery version, and shard configuration.

## Key Components

### `PackQueryEditorModal` (default export)
The primary React component rendered as a `Modal`. Accepts the following props:

| Prop | Type | Description |
|---|---|---|
| `allQueries` | `IQuery[]` | Available queries for the dropdown |
| `onCancel` | `() => void` | Handler for modal dismissal |
| `onPackQueryFormSubmit` | `(formData, editQuery) => void` | Submission callback |
| `editQuery` | `IScheduledQuery` (optional) | Pre-populated data when editing |
| `packId` | `number` | Target pack identifier |
| `isUpdatingPack` | `boolean` | Controls loading state on submit button |

### `generateLoggingType`
Utility function that derives a logging type string (`"snapshot"`, `"differential"`, or `"differential_ignore_removals"`) from an existing `IScheduledQuery`.

### `IFormData`
Internal interface defining the shape of submitted form data, including `interval`, `shard`, `snapshot`, `removed`, `platform`, `version`, and `pack_id`.

## Usage Example

```typescript
<PackQueryEditorModal
  allQueries={queries}
  packId={42}
  isUpdatingPack={false}
  editQuery={scheduledQuery} // omit for "add" mode
  onCancel={() => setShowModal(false)}
  onPackQueryFormSubmit={(formData, editQuery) => {
    editQuery
      ? updateScheduledQuery(formData)
      : createScheduledQuery(formData);
  }}
/>
```

**Validation:** Frequency must be a positive integer not exceeding `604,800` seconds (7 days). The submit button is disabled until a query is selected (create mode) or an `editQuery` is provided (edit mode).
