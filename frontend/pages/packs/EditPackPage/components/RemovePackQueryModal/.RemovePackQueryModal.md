A confirmation modal component for removing one or more scheduled queries from a Fleet pack.

## Key Components

**Props (`IRemovePackQueryModalProps`)**

| Prop | Type | Description |
|------|------|-------------|
| `onCancel` | `() => void` | Closes the modal without action |
| `onSubmit` | `() => void` | Confirms removal of selected queries |
| `selectedQuery` | `IScheduledQuery?` | Single query selected for removal |
| `selectedQueryIds` | `number[]` | IDs of multiple selected queries |
| `isUpdatingPack` | `boolean` | Shows loading state on the Remove button |

**Behavior**

- Displays `"query"` (singular) when a single query is selected (`selectedQuery` is defined or `selectedQueryIds.length === 1`), otherwise displays `"queries"` (plural)
- Supports keyboard confirmation via `onEnter` on the modal
- Remove button renders a loading spinner while `isUpdatingPack` is `true`

## Usage Example

```typescript
import RemovePackQueryModal from "components/RemovePackQueryModal";

<RemovePackQueryModal
  onCancel={() => setShowModal(false)}
  onSubmit={handleRemoveQueries}
  selectedQueryIds={[42, 99]}
  isUpdatingPack={isLoading}
/>
```
