Page component for editing an existing Fleet query pack, handling pack metadata updates, scheduled query management (add/edit/remove), and target configuration.

## Key Components

### `EditPacksPage` (default export)
Main page component that orchestrates all pack editing functionality through three coordinated data queries and modal workflows.

**Props:**
- `router` — React Router v3 injected router for navigation
- `params.id` — Pack ID from URL parameters

**Data Queries (react-query):**
- `queries` — Loads all schedulable queries for the query editor modal
- `storedPack` — Loads pack metadata (name, description, targets)
- `storedPackQueries` — Loads scheduled queries associated with the pack

**State Management:**
- `showPackQueryEditorModal` / `showRemovePackQueryModal` — Modal visibility toggles
- `selectedPackQuery` — Currently selected query for edit/remove operations
- `selectedPackQueryIds` — Multi-select query IDs for bulk removal
- `isUpdatingPack` — Loading state for async operations
- `targetsCount` — Live target count from targets API

**Key Handlers:**
- `handlePackFormSubmit` — Diffs form data against stored pack, submits only changed fields via `deepDifference`
- `onPackQueryEditorSubmit` — Creates or updates a scheduled query depending on whether `editQuery` is provided
- `onRemovePackQuerySubmit` — Bulk removes selected scheduled queries via `Promise.all`

**Child Components:**
- `EditPackForm` — Main form for pack name, description, targets, and query table
- `PackQueryEditorModal` — Add/edit scheduled query modal
- `RemovePackQueryModal` — Confirmation modal for query removal

## Usage Example

```typescript
// Rendered via React Router — no direct instantiation required
// Route definition (react-router v3):
<Route path="/packs/:id/edit" component={EditPacksPage} />

// The component self-navigates on save/cancel:

```
