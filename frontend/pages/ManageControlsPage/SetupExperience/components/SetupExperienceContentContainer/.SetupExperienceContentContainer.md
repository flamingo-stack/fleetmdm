A simple layout wrapper component that provides consistent styling for setup experience content sections by applying a base CSS class and supporting optional className composition.

## Key Components

- **`SetupExperienceContentContainer`** – Default export. A presentational wrapper `div` that merges the `setup-experience-content-container` base class with any additional `className` passed via props.
- **`ISetupExperienceContentContainerProps`** – Interface defining `children` (required `React.ReactNode`) and optional `className` string.

## Usage Example

```typescript
import SetupExperienceContentContainer from "./SetupExperienceContentContainer";

const MySetupStep = () => (
  <SetupExperienceContentContainer className="my-custom-step">
    <h1>Welcome to Setup</h1>
    <p>Follow the steps below to get started.</p>
  </SetupExperienceContentContainer>
);
```

The rendered output will have both `setup-experience-content-container` and `my-custom-step` applied to the `div`, allowing page-level or step-level style overrides without losing the base layout styles.
