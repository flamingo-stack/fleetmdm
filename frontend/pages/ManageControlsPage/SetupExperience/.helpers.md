Retrieves the macOS manual agent install MDM setting for either a global or team-specific configuration context.

## Key Components

- **`getManualAgentInstallSetting`** *(default export)* — Returns the `macos_manual_agent_install` boolean from MDM setup experience settings, scoped to the global config when `currentTeamId` matches `API_NO_TEAM_ID`, or to the team config otherwise.

## Usage Example

```typescript
import getManualAgentInstallSetting from "./helpers";

// Global (no team) context
const isManualInstall = getManualAgentInstallSetting(
  API_NO_TEAM_ID,
  globalConfig,
  undefined
);

// Team-specific context
const isTeamManualInstall = getManualAgentInstallSetting(
  42,
  globalConfig,
  teamConfig
);

console.log(isManualInstall);     // true | false
console.log(isTeamManualInstall); // true | false
```

## Notes

- Returns `false` as a safe default when the config value is absent or undefined.
- Team config is ignored when `currentTeamId === API_NO_TEAM_ID`; global config is ignored otherwise.
