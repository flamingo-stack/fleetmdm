Renders the Setup Experience settings page, providing section-based navigation for configuring end-user setup workflows. Displays a premium feature gate for non-premium tiers.

## Key Components

- **`SetupExperience`** – Main page component that handles section routing, platform parameter validation, and rendering the active configuration card within a `SideNav` layout
- **`ISetupExperienceProps`** – Interface defining required props: `params`, `location`, `router`, and `teamIdForApi`
- **`SETUP_EXPERIENCE_NAV_ITEMS`** – External nav config used to resolve the active section and populate the sidebar
- **`PremiumFeatureMessage`** – Rendered in place of the full UI when `isPremiumTier` is `false`

## Usage Example

```typescript
import SetupExperience from "pages/setup-experience/SetupExperience";

<SetupExperience
  params={{ section: "install-software", platform: "darwin" }}
  location={{ search: "?team_id=1" }}
  router={injectedRouter}
  teamIdForApi={1}
/>
```

## Behavior Notes

- Defaults to the first item in `SETUP_EXPERIENCE_NAV_ITEMS` if no matching `section` param is found
- Redirects (via `router.replace`) to strip the `platform` URL param when the active section is not `install-software`, as other sections do not support platform filtering
- Passes `teamIdForApi` as `key` to force card remount on team change
- Query string is preserved and appended to all nav item paths
