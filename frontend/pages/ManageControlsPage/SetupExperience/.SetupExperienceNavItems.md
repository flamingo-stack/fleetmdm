Defines the ordered navigation items for the Setup Experience section in the Fleet MDM Controls interface, mapping each setup step to its corresponding route path and card component.

## Key Components

- **`ISetupExperienceCardProps`** — Shared props interface injected into each setup card, providing `currentTeamId`, `router`, and optional `urlPlatformParam`.
- **`SETUP_EXPERIENCE_NAV_ITEMS`** — Ordered array of `ISideNavItem` entries representing the five sequential setup steps:
  1. **Users** → `PATHS.CONTROLS_USERS`
  2. **Bootstrap package** → `PATHS.CONTROLS_BOOTSTRAP_PACKAGE`
  3. **Install software** → `PATHS.CONTROLS_INSTALL_SOFTWARE("macos")`
  4. **Run script** → `PATHS.CONTROLS_RUN_SCRIPT`
  5. **Setup Assistant** → `PATHS.CONTROLS_SETUP_ASSISTANT`

## Usage Example

```typescript
import SETUP_EXPERIENCE_NAV_ITEMS, {
  ISetupExperienceCardProps,
} from "./SetupExperienceNavItems";
import SideNav from "pages/admin/components/SideNav/SideNav";

const SetupExperience = ({ currentTeamId, router }: ISetupExperienceCardProps) => {
  return (
    <SideNav
      navItems={SETUP_EXPERIENCE_NAV_ITEMS}
      activeSection="users"
      navItemProps={{ currentTeamId, router }}
    />
  );
};
```

Each item's `urlSection` drives the active state in the `SideNav`, and the `Card` component is rendered when that section is selected. The `path` field defaults Install Software to `"macos"` as the initial platform, though `urlPlatformParam` allows runtime platform switching.
