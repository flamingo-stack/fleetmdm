Renders the view for a successfully uploaded MDM bootstrap package, displaying the package table, an informational message with a documentation link, and the uploaded package list item with a delete action.

## Key Components

- **`UploadedPackageView`** – Default export. Composes `BootstrapPackageTable`, `BootstrapPackageTable`, and `UploadList` to display the current bootstrap package and deletion controls.
- **`IUploadedPackageViewProps`** – Interface defining required props:
  - `bootstrapPackage` – Metadata for the uploaded package (`IBootstrapPackageMetadata`)
  - `currentTeamId` – ID of the team the package belongs to
  - `onDelete` – Callback triggered when the package is deleted

## Usage Example

```typescript
import UploadedPackageView from "./UploadedPackageView";

<UploadedPackageView
  bootstrapPackage={bootstrapPackageMetadata}
  currentTeamId={3}
  onDelete={() => refetchBootstrapPackage()}
/>
```

## Notes

- The informational paragraph links out to the FleetDM bootstrap package documentation via `CustomLink` with `newTab`.
- The package list is rendered via `UploadList` using `BootstrapPackageListItem` as the item component, forwarding the `onDelete` handler.
- Deleting the package is required before a new one can be uploaded — this view is only shown when a package already exists.
