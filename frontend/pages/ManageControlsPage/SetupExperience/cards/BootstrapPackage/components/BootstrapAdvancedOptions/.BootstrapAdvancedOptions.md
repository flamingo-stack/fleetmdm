Collapsible advanced options panel for macOS MDM bootstrap configuration, allowing users to toggle manual fleetd agent installation and persist the setting via the MDM API.

## Key Components

### `IBootstrapAdvancedOptionsProps`
| Prop | Type | Description |
|------|------|-------------|
| `currentTeamId` | `number` | Fleet team ID used when saving setup experience settings |
| `disableInstallManually` | `boolean` | Disables the manual install checkbox (e.g., no bootstrap package uploaded) |
| `selectManualAgentInstall` | `boolean` | Current checkbox state (controlled) |
| `onChange` | `(value: boolean) => void` | Callback to update parent state on checkbox change |

### `BootstrapAdvancedOptions` (default export)
Renders a `RevealButton`-gated accordion containing:
- **`Checkbox`** — toggles `macos_manual_agent_install`; wrapped in `TooltipWrapper` explaining custom fleetd deployment constraints
- **`GitOpsModeTooltipWrapper`** — disables controls when GitOps mode is active
- **`onSubmit`** — calls `mdmAPI.updateSetupExperienceSettings` and flashes success/error notifications

## Usage Example

```typescript
import BootstrapAdvancedOptions from "components/BootstrapAdvancedOptions";

const [manualInstall, setManualInstall] = useState(false);

<BootstrapAdvancedOptions
  currentTeamId={42}
  disableInstallManually={!bootstrapPackageUploaded}
  selectManualAgentInstall={manualInstall}
  onChange={(val) => setManualInstall(val)}
/>
```

> **Note:** The manual agent install option should only be enabled after uploading a bootstrap package. When active, Fleet skips automatic fleetd installation — ensure **Install software** and **Run script** setup steps are not in use.
