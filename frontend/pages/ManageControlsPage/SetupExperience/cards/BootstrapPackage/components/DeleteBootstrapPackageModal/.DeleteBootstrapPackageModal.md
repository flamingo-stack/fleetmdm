A confirmation modal component for deleting a bootstrap package in macOS MDM management, warning users about the consequences of deletion before proceeding.

## Key Components

- **`DeleteBootstrapPackageModal`** – Default export. Renders a modal dialog with a deletion warning and two action buttons.
- **`DeleteBootstrapPackageModalProps`** – Interface defining two required callbacks:
  - `onCancel` – Invoked when the user dismisses the modal.
  - `onDelete` – Invoked when the user confirms deletion (triggered by button click or Enter key).

## Usage Example

```typescript
import DeleteBootstrapPackageModal from "./DeleteBootstrapPackageModal";

<DeleteBootstrapPackageModal
  onCancel={() => setShowModal(false)}
  onDelete={() => {
    handleDeleteBootstrapPackage();
    setShowModal(false);
  }}
/>
```

## Behavior Notes

- The modal supports **keyboard confirmation** via `onEnter`, mapping the Enter key to `onDelete`.
- Displays two warnings:
  1. The package will **not** be uninstalled from existing macOS hosts; in-progress installs/uninstalls will complete.
  2. Manual fleetd agent installation will be disabled; the agent will revert to automatic installation during macOS enrollment.
- Uses `variant="alert"` for the destructive Delete button and `variant="inverse-alert"` for Cancel, following the fleet UI pattern for dangerous actions.
