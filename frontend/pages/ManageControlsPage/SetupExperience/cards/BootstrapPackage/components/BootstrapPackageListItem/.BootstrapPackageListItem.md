Renders a single MDM bootstrap package list entry with download and delete actions.

## Key Components

- **`DownloadPackageButton`** — Internal form-based component that triggers a native browser download for the bootstrap package using a hidden token input and a GET form submission, avoiding custom download handling in the Fleet UI.
- **`BootstrapPackageListItem`** — Main export. Displays package metadata (name, upload time) alongside download and delete action buttons.
- **`GitOpsModeTooltipWrapper`** — Wraps the delete button to disable it and show a tooltip when GitOps mode is active.

## Usage Example

```typescript
import BootstrapPackageListItem from "components/BootstrapPackageListItem";
import { IBootstrapPackageMetadata } from "interfaces/mdm";

const handleDelete = (pkg: IBootstrapPackageMetadata) => {
  console.log("Deleting package:", pkg.name);
};

<BootstrapPackageListItem
  bootstrapPackage={{
    name: "setup.pkg",
    created_at: "2024-01-15T10:30:00Z",
    token: "abc123token",
  }}
  onDelete={handleDelete}
/>;
```

## Notes

- Download is implemented via a native browser `<form>` GET submission to `MDM_BOOTSTRAP_PACKAGE` endpoint, with the package token passed as a hidden field.
- The delete button is automatically disabled in GitOps mode via `GitOpsModeTooltipWrapper`.
- Upload time is rendered as a relative duration using `date-fns` `formatDistanceToNow`.
