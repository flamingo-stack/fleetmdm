Renders a table displaying MDM bootstrap package aggregate status for a given team, fetching data via `react-query` and handling loading, error, and empty states.

## Key Components

- **`BootstrapPackageTable`** – Default export. Accepts a `currentTeamId` prop, queries the MDM API for bootstrap package aggregate data, and renders a `TableContainer` with pre-configured columns.
- **`IBootstrapPackageTableProps`** – Interface requiring `currentTeamId: number`.
- **`COLUMN_CONFIGS` / `generateTableData`** – Imported from `BootstrapPackageTableConfig` to define column structure and transform API response into table rows.

## Behavior

| State | Output |
|---|---|
| Loading | `TableContainer` with loading indicator |
| Error | `<DataError />` component |
| Empty / no data | `<EmptyState />` with guidance message |
| Success | Paginated table sorted by `hosts` ascending |

## Usage Example

```typescript
import BootstrapPackageTable from "./BootstrapPackageTable";

// Render within a team-scoped MDM management view
const MDMPage = ({ teamId }: { teamId: number }) => (
  <BootstrapPackageTable currentTeamId={teamId} />
);
```

## Notes

- Query key `["bootstrap-package-summary", currentTeamId]` ensures per-team cache isolation.
- `retry: false` and `refetchOnWindowFocus: false` prevent aggressive re-fetching.
- Table header, pagination, count, and footer are all hidden — display is intentionally minimal.
