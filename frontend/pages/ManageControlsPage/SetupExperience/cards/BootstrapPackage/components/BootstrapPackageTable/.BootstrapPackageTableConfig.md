Defines column configurations and data transformation utilities for the Bootstrap Package status table in the MDM section of the Fleet UI.

## Key Components

### `COLUMN_CONFIGS`
Exported array of `IColumnConfig` objects defining three table columns:
- **Status** – Renders a `StatusIndicatorWithIcon` with optional tooltip based on bootstrap package install state
- **Hosts** – Sortable numeric column showing aggregate host count via `TextCell`
- **Link** – Hidden-title column rendering a `ViewAllHostsLink` that filters hosts by `macos_bootstrap_package` status and `fleet_id` (team ID)

### `STATUS_CELL_VALUES`
Internal lookup map from `IBootstrapPackageAggregate` keys (`installed`, `pending`, `failed`) to display metadata including `displayName`, `statusName` (indicator variant), `BootstrapPackageStatus` enum value, and tooltip text.

### `generateTableData(data?, currentTeamId?)`
Transforms an `IBootstrapPackageAggregate` object into row data consumable by the table. Returns an empty array if `data` is undefined.

## Usage Example

```typescript
import {
  COLUMN_CONFIGS,
  generateTableData,
} from "./BootstrapPackageTableConfig";

const aggregate: IBootstrapPackageAggregate = {
  installed: 42,
  pending: 7,
  failed: 3,
};

// Generate rows for the table
const tableData = generateTableData(aggregate, currentTeamId);
// [
//   { status: { displayName: "Installed", ... }, hosts: 42, teamId: 1 },
//   { status: { displayName: "Pending",   ... }, hosts: 7,  teamId: 1 },
//   { status: { displayName: "Failed",    ... }, hosts: 3,  teamId: 1 },
// ]

// Pass to your TableContainer
<TableContainer
  columns={COLUMN_CONFIGS}
  data={tableData}
/>
```

## Notes

- `ViewAllHostsLink` receives `macos_bootstrap_package` and `fleet_id` as query params, enabling drill-down navigation from aggregate counts to filtered host lists.
