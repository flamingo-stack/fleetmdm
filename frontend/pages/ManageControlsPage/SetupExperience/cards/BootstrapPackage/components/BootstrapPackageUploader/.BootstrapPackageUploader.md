Renders a file upload UI component for uploading macOS bootstrap packages (`.pkg` files) to a specific MDM team, handling validation, API submission, and user notifications.

## Key Components

- **`BootstrapPackageUploader`** – Default export. A React functional component that wraps `FileUploader` with bootstrap package-specific upload logic.
- **`IBootstrapPackageUploaderProps`** – Props interface requiring `currentTeamId` (number) and `onUpload` callback (invoked on successful upload).
- **`onUploadFile`** – Internal async handler that validates file presence and `.pkg` extension, calls `mdmAPI.uploadBootstrapPackage`, and dispatches flash notifications for success or error states.

## Usage Example

```typescript
import BootstrapPackageUploader from "components/BootstrapPackageUploader";

<BootstrapPackageUploader
  currentTeamId={3}
  onUpload={() => refetchTeamData()}
/>
```

## Behavior Notes

- **File type guard:** Rejects any file whose name does not include `.pkg`, immediately showing an error flash using `UPLOAD_ERROR_MESSAGES.wrongType.message`.
- **Loading state:** Sets `showLoading` to `true` during the upload and resets it in the `finally` block regardless of outcome.
- **Error handling:** Casts caught errors to `AxiosResponse<IApiError>` and passes them through `getErrorMessage` (from `./helpers`) to produce user-facing error messages.
- **Notifications:** Uses `NotificationContext` (`renderFlash`) for both success and error feedback.
