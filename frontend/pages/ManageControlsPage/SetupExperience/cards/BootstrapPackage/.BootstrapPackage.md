Renders the Bootstrap Package section of the macOS Setup Experience settings, managing upload, display, deletion, and advanced configuration of a bootstrap package for MDM-enrolled hosts.

## Key Components

- **`BootstrapPackage`** — Default export. Main page component accepting `currentTeamId` and `router` via `ISetupExperienceCardProps`.
- **Data Queries**
  - `bootstrapMetadata` — Fetches existing bootstrap package metadata; 404 response indicates no package uploaded.
  - `macSoftwareTitles` — Loads macOS setup experience software titles (up to 3000) to compute install count.
  - `script` — Fetches setup experience script to determine if one is active.
  - `globalConfig` / team config — Checks MDM enabled state and manual agent install setting.
- **`onUpload`** — Refetches bootstrap metadata after a successful upload.
- **`onDelete`** — Deletes the bootstrap package, resets manual agent install setting, flashes success/error, and refetches relevant config.
- **`renderBootstrapView`** — Conditionally renders `PackageUploader` or `UploadedPackageView`, plus `BootstrapAdvancedOptions`.
- **`renderContent`** — Shows a `Spinner` while loading, an `EmptyState` prompt if MDM is not configured, or the bootstrap view.

## Usage Example

```typescript
import BootstrapPackage from "./BootstrapPackage";

// Used as a setup experience card within the MDM settings flow
<BootstrapPackage
  currentTeamId={selectedTeamId}
  router={router}
/>
```

## Notes

- The component treats an HTTP 404 from the metadata endpoint as "no package uploaded" rather than an error condition.
- The **manual agent install** advanced option is disabled when no package is uploaded, when setup experience software is selected, or when a setup experience script is active — ensuring mutually exclusive configurations.
- MDM + Apple BM must both be enabled (`enabled_and_configured` + `apple_bm_enabled_and_configured`); otherwise an `EmptyState` with a "Turn on" CTA is shown.
