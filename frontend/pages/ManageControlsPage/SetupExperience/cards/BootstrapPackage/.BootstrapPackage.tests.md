Integration tests for the `BootstrapPackage` React component, validating rendering behavior across MDM configuration states, package upload status, and advanced options availability.

## Key Components

- **`setupDefaultBackendMocks()`** — Helper that wires up MSW handlers for a baseline backend state: MDM config enabled, no run script, no install software, and a pre-uploaded bootstrap package (`foo-package.pkg`) with summary stats (installed: 1, pending: 2, failed: 3).
- **`BootstrapPackage`** — The component under test, rendered with `createCustomRenderer` and a mock router.

## Test Cases

| Scenario | Assertion |
|---|---|
| MDM not configured | Shows "Turn on MDM and automatic enrollment" + page description |
| MDM configured, ABM not | Shows "Turn on MDM and automatic enrollment" |
| Bootstrap package uploaded | Renders status table and package name |
| No bootstrap package | Renders uploader UI with "Package (.pkg)" and "Upload" button |
| No package uploaded → Advanced options | `fleetd` checkbox and Save button are disabled |
| Install software already added → Advanced options | `fleetd` checkbox and Save button are disabled |
| Run script already added → Advanced options | `fleetd` checkbox and Save button are disabled |

## Usage Example

```typescript
// Run all tests in this suite
// From repo root:
// npx jest BootstrapPackage.tests.tsx

// Override a specific mock within a test:
mockServer.use(errorNoBootstrapPackageMetadataHandler);

render(<BootstrapPackage router={createMockRouter()} currentTeamId={0} />);
await screen.findByText(/Upload a bootstrap package/gi);
```
