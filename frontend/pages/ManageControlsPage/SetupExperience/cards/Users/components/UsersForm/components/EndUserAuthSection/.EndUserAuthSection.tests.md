Test suite for the `EndUserAuthSection` React component, verifying rendering behavior, conditional visibility, user interactions, and disabled states for end-user authentication and lock-user-info controls.

## Key Components

- **`describe("EndUserAuthSection")`** — Top-level suite covering all component behaviors
- **`defaultProps`** — Baseline prop configuration with IdP configured, Mac MDM enabled, and auth disabled
- **`render`** — Custom renderer with backend mock via `createCustomRenderer`
- **Nested `describe("disabled states")`** — Focused group testing checkbox `aria-disabled` states under various IdP/MDM configurations

## Test Coverage

| Scenario | What's Verified |
|---|---|
| Initial render | "Require IdP authentication" checkbox is present |
| Help text | IdP link text renders alongside auth description |
| Conditional visibility | "Lock end user info" hidden when auth unchecked; shown when checked |
| Checkbox toggle | `onEndUserAuthChange(true)` and `onLockEndUserInfoChange(true)` called on click |
| IdP not configured | Auth checkbox is `aria-disabled="true"`; callback not invoked |
| Mac MDM not configured | Lock end user info checkbox is `aria-disabled="true"` |
| Both configured | Both checkboxes are `aria-disabled="false"` |

## Usage Example

```typescript
// Running the test suite
import { render, screen } from "@testing-library/react";
import EndUserAuthSection from "./EndUserAuthSection";

// Minimal prop shape exercised by the tests
const props = {
  endUserAuthEnabled: false,
  lockEndUserInfo: false,
  onEndUserAuthChange: jest.fn(),
  onLockEndUserInfoChange: jest.fn(),
  isIdPConfigured: true,
  isMacMdmEnabledAndConfigured: true,
  gitOpsModeEnabled: false,
};

render(<EndUserAuthSection {...props} />);
expect(screen.getByText("Require IdP authentication")).toBeInTheDocument();
```
