Test suite for the `UsersForm` component, verifying IdP authentication toggling behavior, "Lock end user info" checkbox state management, and save payload construction based on Apple MDM configuration status.

## Key Components

- **`defaultProps`** — Baseline props shared across tests (`currentTeamId`, `defaultIsEndUserAuthEnabled`, `defaultLockEndUserInfo`, `defaultEnableManagedLocalAccount`, `isIdPConfigured`)
- **`render`** — Base renderer with backend mock, no MDM context override
- **`renderWithMdmEnabled`** — Renderer with `isMacMdmEnabledAndConfigured: true`
- **`renderWithMdmDisabled`** — Renderer with `isMacMdmEnabledAndConfigured: false`
- **`save payload` describe block** — Spies on `mdmAPI.updateSetupExperienceSettings` to assert correct API payloads

## Test Coverage

| Test | Description |
|------|-------------|
| EUA toggle reveals lock field | "Lock end user info" is hidden until "Require IdP authentication" is checked |
| Auto-check with MDM enabled | Enabling EUA auto-checks "Lock end user info" when Apple MDM is configured |
| No auto-check with MDM disabled | EUA toggle does not auto-check "Lock end user info" when Apple MDM is off |
| Preserve backend value | Toggling EUA off then on preserves a previously saved `lock_end_user_info: true` |
| No "Advanced options" button | Confirms that section is absent from the form |
| Single Save button | Asserts exactly one Save button renders |
| Payload without Apple MDM | Omits `lock_end_user_info` and `enable_managed_local_account` when MDM is off |
| Payload with Apple MDM | Includes all Apple-only fields including `end_user_local_account_type` |

## Usage Example

```typescript
// Run the full suite
jest --testPathPattern="UsersForm.tests.tsx"

// Key assertion pattern used throughout
const { user } = renderWithMdmEnabled(<UsersForm {...defaultProps} />);
await user.click(
  screen.getByRole("checkbox", { name: "Require IdP authentication" })
);
expect(
  screen.getByRole("checkbox", { name: "Lock end user info" })
).toBeChecked();
```
