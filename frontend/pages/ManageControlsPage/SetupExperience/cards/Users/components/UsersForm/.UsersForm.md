A React form component for managing MDM user settings, including end-user authentication and managed local account configuration for macOS devices.

## Key Components

### `IUsersFormData`
Form state interface tracking:
- `endUserAuthEnabled` — whether end-user authentication (IdP) is active
- `lockEndUserInfo` — whether end-user info is locked after setup
- `enableManagedLocalAccount` — whether a managed local account is provisioned
- `localAccountType` — the local account type (`EndUserLocalAccountType`)

### `IUsersFormProps`
Props consumed by `UsersForm`:
- `currentTeamId` — Fleet team ID for scoping the API call
- `defaultIs*` / `default*` — server-derived initial values, re-synced on team switch via `useEffect`
- `isIdPConfigured` — controls availability of end-user auth options

### `UsersForm` (default export)
Controlled form component that:
- Syncs local state from props on team change
- Conditionally includes Apple-MDM-only fields (`lockEndUserInfo`, managed local account) when `isMacMdmEnabledAndConfigured`
- Submits via `mdmAPI.updateSetupExperienceSettings`
- Wraps the Save button in `GitOpsModeTooltipWrapper` to disable edits when GitOps mode is active

## Usage Example

```typescript
<UsersForm
  currentTeamId={teamId}
  defaultIsEndUserAuthEnabled={settings.endUserAuthEnabled}
  defaultLockEndUserInfo={settings.lockEndUserInfo}
  defaultEnableManagedLocalAccount={settings.enableManagedLocalAccount}
  defaultLocalAccountType={EndUserLocalAccountType.ADMIN}
  isIdPConfigured={!!idpConfig}
/>
```

## Notes

- Apple MDM-only fields are omitted from the API payload when `isMacMdmEnabledAndConfigured` is `false`
- `lockEndUserInfo` is auto-synced to match `endUserAuthEnabled` when Apple MDM is configured, but left untouched otherwise
