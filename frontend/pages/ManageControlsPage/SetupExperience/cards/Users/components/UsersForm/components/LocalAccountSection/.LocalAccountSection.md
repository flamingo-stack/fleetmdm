Renders the "Local accounts" settings section within the MDM Users Form, allowing administrators to configure end-user local account types and managed local admin account creation for macOS hosts.

## Key Components

- **`LocalAccountSection`** — Default export. A React component that renders radio buttons for selecting the end-user account role (`Admin`, `Standard`, `Skip`) and a checkbox to enable a hidden Fleet-managed local admin account (`_fleetadmin`). Disabled when Apple MDM is not configured or GitOps mode is active.
- **`effectiveEnableManagedLocalAccount`** — Named export. A utility function that derives whether the managed local account should be enabled, forcing it `true` for `Standard` and `None` account types (since at least one admin must exist on the host).

### Props (`ILocalAccountSectionProps`)

| Prop | Type | Description |
|---|---|---|
| `formData` | `IUsersFormData` | Current form state |
| `onLocalAccountTypeChange` | `(value: EndUserLocalAccountType) => void` | Callback for radio selection changes |
| `onEnableManagedLocalAccountChange` | `(value: boolean) => void` | Callback for checkbox toggle |
| `isMacMdmEnabledAndConfigured` | `boolean` | Gates all controls; shows tooltip link to Apple MDM setup when `false` |

## Usage Example

```typescript
import LocalAccountSection, {
  effectiveEnableManagedLocalAccount,
} from "./LocalAccountSection";

<LocalAccountSection
  formData={formData}
  onLocalAccountTypeChange={(type) =>
    setFormData({ ...formData, localAccountType: type })
  }
  onEnableManagedLocalAccountChange={(enabled) =>
    setFormData({ ...formData, enableManagedLocalAccount: enabled })
  }
  isMacMdmEnabledAndConfigured={isMacMdmEnabledAndConfigured}
/>

// Derive effective checkbox state before submitting:
const payload = {
  enableManagedLocalAccount: effectiveEnableManagedLocalAccount(formData),
};
```
