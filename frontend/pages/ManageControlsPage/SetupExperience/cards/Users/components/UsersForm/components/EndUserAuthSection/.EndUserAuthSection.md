A React settings section component that renders end user authentication controls for MDM enrollment, including IdP authentication requirement and end user info locking options.

## Key Components

### `EndUserAuthSection` (default export)
A functional component that displays two conditionally enabled checkboxes within a `SettingsSection`:

- **Require IdP authentication** — Enables mandatory IdP login during host setup. Disabled when no IdP is configured or GitOps mode is active. Shows a tooltip with a link to the IdP settings page when IdP is not configured.
- **Lock end user info** *(conditional)* — Visible only when `endUserAuthEnabled` is `true`. Prevents macOS users from editing Account Name and Full Name during Setup Assistant. Requires both IdP and Apple MDM to be configured.

### `IEndUserAuthSectionProps`
| Prop | Type | Description |
|---|---|---|
| `endUserAuthEnabled` | `boolean` | Current state of IdP auth toggle |
| `lockEndUserInfo` | `boolean` | Current state of lock info toggle |
| `onEndUserAuthChange` | `(value: boolean) => void` | Handler for auth toggle changes |
| `onLockEndUserInfoChange` | `(value: boolean) => void` | Handler for lock info toggle changes |
| `isIdPConfigured` | `boolean` | Whether an IdP has been configured |
| `isMacMdmEnabledAndConfigured` | `boolean` | Whether Apple MDM is active |
| `gitOpsModeEnabled` | `boolean` | Disables all controls when GitOps mode is on |

## Usage Example

```typescript
<EndUserAuthSection
  endUserAuthEnabled={settings.endUserAuth}
  lockEndUserInfo={settings.lockEndUserInfo}
  onEndUserAuthChange={(val) => handleChange("endUserAuth", val)}
  onLockEndUserInfoChange={(val) => handleChange("lockEndUserInfo", val)}
  isIdPConfigured={!!integrations.sso}
  isMacMdmEnabledAndConfigured={mdm.appleEnabled}
  gitOpsModeEnabled={config.gitOpsMode}
/>
```
