Renders and behavior tests for the `LocalAccountSection` component, validating rendering, checkbox/radio states, and disabled conditions tied to MDM and GitOps configuration.

## Key Components

- **`describe("LocalAccountSection")`** — Top-level suite covering rendering, active states, and disabled states
- **`defaultProps`** — Baseline props with `endUserAuthEnabled: false`, `enableManagedLocalAccount: false`, and `localAccountType: ADMIN`
- **`createCustomRenderer`** — Custom test renderer with optional backend mock and app context overrides
- **Active states suite** — Verifies checkbox checked/unchecked behavior and callback invocation on user interaction
- **Disabled states suite** — Covers three disable scenarios: Apple MDM not configured, GitOps mode enabled, and non-Admin account types forcing managed local account on

## Usage Example

```typescript
// Run all tests for LocalAccountSection
import { createCustomRenderer } from "test/test-utils";
import LocalAccountSection from "./LocalAccountSection";

const render = createCustomRenderer({ withBackendMock: true });

render(
  <LocalAccountSection
    formData={{
      endUserAuthEnabled: false,
      lockEndUserInfo: false,
      enableManagedLocalAccount: true,
      localAccountType: EndUserLocalAccountType.ADMIN,
    }}
    onLocalAccountTypeChange={jest.fn()}
    onEnableManagedLocalAccountChange={jest.fn()}
    isMacMdmEnabledAndConfigured={true}
  />
);

// Assert checkbox is checked
expect(
  screen.getByRole("checkbox", { name: "Create hidden admin" })
).toBeChecked();
```

## Test Coverage Summary

| Scenario | Expected Behavior |
|---|---|
| MDM not configured | All controls `aria-disabled`, tooltip references Apple MDM |
| GitOps mode enabled | All controls `aria-disabled`, tooltip references GitOps |
| Account type `STANDARD` or `NONE` | Checkbox forced checked and disabled |
| Account type `ADMIN` | Checkbox interactive, fires `onEnableManagedLocalAccountChange` |
