Renders the Setup Assistant section of the MDM Setup Experience, managing Apple automatic enrollment profiles and advanced MDM configuration options for a given team or global context.

## Key Components

- **`SetupAssistant`** — Main page component accepting `currentTeamId` and `router` via `ISetupExperienceCardProps`
- **`SetupAssistantProfileUploader`** — Handles uploading a new Apple enrollment profile
- **`SetupAssistantProfileCard`** — Displays an existing enrollment profile with optional delete action
- **`DeleteAutoEnrollmentProfile`** — Modal for confirming profile deletion
- **`AdvancedOptionsForm`** — Form for configuring the `apple_enable_release_device_manually` MDM setting
- **`SetupExperienceContentContainer`** — Layout wrapper for the setup experience card content

## Data Flow

| Query Key | Source | Purpose |
|---|---|---|
| `["config"]` | `configAPI.loadAll()` | Global MDM config + release device setting |
| `["team"]` | `teamsAPI.load(id)` | Team-level MDM config |
| `["enrollment_profile"]` | `mdmAPI.getSetupEnrollmentProfile()` | Active team/global enrollment profile |
| `["default_enrollment_profile"]` | `mdmAPI.getDefaultSetupEnrollmentProfile()` | Fallback default profile (fetched only on 404) |

## Usage Example

```typescript
// Used as a card within the Setup Experience navigation flow
import SetupAssistant from "./SetupAssistant";

<SetupAssistant
  currentTeamId={selectedTeamId} // or API_NO_TEAM_ID for global
  router={router}
/>
```

## Rendering Logic

1. Shows a `<Spinner />` while any query is loading
2. Renders an `<EmptyState />` prompt if MDM or Apple Business Manager is not configured, with a link to `/admin/integrations/mdm`
3. If no team enrollment profile exists (404), displays the default profile card (if available) and the uploader
4. If a team enrollment profile exists, shows the profile card with a delete action
5. Always renders `AdvancedOptionsForm` when MDM is configured, keyed to the current release device setting
