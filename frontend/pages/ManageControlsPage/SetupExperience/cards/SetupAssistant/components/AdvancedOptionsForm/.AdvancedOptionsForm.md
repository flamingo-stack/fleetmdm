A collapsible form component for configuring advanced MDM options, specifically the "Release device manually" setting for a given team.

## Key Components

- **`AdvancedOptionsForm`** — Default export. Renders a toggleable accordion form that allows administrators to configure whether devices are released manually during MDM enrollment.
- **`IAdvancedOptionsFormProps`** — Interface defining the component's props:
  - `currentTeamId: number` — The ID of the team whose setting is being updated.
  - `defaultReleaseDevice: boolean` — Initial value for the release device checkbox.

## Internal State

| State | Type | Purpose |
|---|---|---|
| `showAdvancedOptions` | `boolean` | Controls accordion visibility |
| `releaseDevice` | `boolean` | Tracks the checkbox value |

## Usage Example

```typescript
import AdvancedOptionsForm from "components/AdvancedOptionsForm";

<AdvancedOptionsForm
  currentTeamId={42}
  defaultReleaseDevice={false}
/>
```

## Behavior

- The accordion is collapsed by default; clicking "Advanced options" via `RevealButton` toggles visibility.
- On form submission, calls `mdmAPI.updateReleaseDeviceSetting(currentTeamId, releaseDevice)`.
- Displays a success or error flash notification via `NotificationContext` based on the API response.
- The "Release device manually" checkbox includes a tooltip clarifying that enabling it transfers responsibility for sending the `DeviceConfigured` MDM command to the administrator.
