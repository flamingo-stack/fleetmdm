Renders a file uploader component for uploading MDM Setup Assistant enrollment profiles (`.json`) to a specific team, handling upload state, success notifications, and contextual error messaging.

## Key Components

- **`SetupAssistantProfileUploader`** — Default export. Functional React component that wraps `FileUploader` with MDM-specific upload logic.
- **`ISetupAssistantProfileUploaderProps`** — Props interface requiring `currentTeamId` (number) and `onUpload` callback.
- **`onUploadFile`** — Async handler that calls `mdmAPI.uploadSetupEnrollmentProfile`, flashes success/error notifications, and conditionally renders a "Learn more" link when the error message includes `"Couldn't add"`.

## Usage Example

```typescript
import SetupAssistantProfileUploader from "./SetupAssistantProfileUploader";

<SetupAssistantProfileUploader
  currentTeamId={42}
  onUpload={() => refetchTeamProfiles()}
/>
```

## Behavior Notes

- Accepts only `.json` files via the `FileUploader` component.
- On a `"Couldn't add"` API error, appends a `CustomLink` pointing to `https://fleetdm.com/learn-more-about/dep-profile` inside the flash message.
- Loading state (`showLoading`) is set on upload start and cleared in the `finally` block regardless of outcome.
- Error shape is cast as `AxiosResponse<IApiError>` and passed through the local `getErrorMessage` helper.
