Utility module for formatting upload error messages in a user-friendly way.

## Key Components

- **`getErrorMessage(err)`** — Accepts an unknown error value and returns a human-readable string. Returns the raw string if `err` is already a string, falls back to `getErrorReason`, or uses the default upload error message.
- **`UPLOAD_ERROR_MESSAGES`** — Internal constant defining fallback error message copy.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await uploadFile(file);
} catch (err) {
  const message = getErrorMessage(err);
  console.error(message); // "Couldn't add. Please try again."
}
```
