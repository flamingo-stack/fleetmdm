Renders a card UI for displaying an Apple MDM Setup Assistant enrollment profile, supporting both default and custom profile variants with download and delete actions.

## Key Components

- **`SetupAssistantProfileCard`** — Main component accepting either a default or custom Apple Setup Enrollment profile via discriminated union props
- **`IDefaultProfileProps`** — Props variant for the built-in default profile (no delete action)
- **`ICustomProfileProps`** — Props variant for user-uploaded profiles, includes `onDelete` callback
- **`onDownload`** — Handler that serializes `enrollment_profile` to JSON and triggers a file download via `FileSaver`, using an ISO date-prefixed filename

## Usage Example

```typescript
// Default profile (no delete action)
<SetupAssistantProfileCard
  profile={defaultProfileResponse}
  defaultProfile={true}
/>

// Custom uploaded profile (with delete action)
<SetupAssistantProfileCard
  profile={customProfileResponse}
  defaultProfile={false}
  onDelete={() => handleDeleteProfile()}
/>
```

## Behavior Notes

- **Default profile**: Displays "Default profile" label with a static description; no delete button
- **Custom profile**: Displays the profile `name` and relative upload time via `uploadedFromNow`; renders a trash icon button wired to `onDelete`
- **Download**: Both variants expose a download icon button; the filename is `YYYY-MM-DD_default-automatic-enrollment.json` for default profiles or `YYYY-MM-DD_<profile.name>` for custom ones
- CSS modifier `setup-assistant-profile-card--default-profile` is conditionally applied for default profile styling
