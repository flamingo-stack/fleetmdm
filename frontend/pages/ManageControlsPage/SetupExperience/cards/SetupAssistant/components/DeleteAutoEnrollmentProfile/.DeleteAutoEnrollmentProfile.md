A confirmation modal component for deleting an MDM automatic enrollment profile for a specified team, with success/error flash notifications.

## Key Components

- **`DeleteAutoEnrollProfile`** — Default export; renders a modal dialog with confirm/cancel actions
- **`DeleteAutoEnrollProfileProps`** — Interface defining required props:
  - `currentTeamId: number` — ID of the team whose profile will be deleted
  - `onCancel: () => void` — Callback invoked when the user cancels
  - `onDelete: () => void` — Callback invoked after deletion completes (success or failure)
- **`handleDelete`** — Async handler that calls `mdmAPI.deleteSetupEnrollmentProfile`, flashes a success or error notification, then calls `onDelete`

## Usage Example

```typescript
import DeleteAutoEnrollProfile from "./DeleteAutoEnrollmentProfile";

<DeleteAutoEnrollProfile
  currentTeamId={42}
  onCancel={() => setShowModal(false)}
  onDelete={() => {
    setShowModal(false);
    refetchProfiles();
  }}
/>
```

## Behavior Notes

- Calls `mdmAPI.deleteSetupEnrollmentProfile(currentTeamId)` on confirm
- On **success**: flashes `"Successfully deleted."` and calls `onDelete()`
- On **failure**: flashes `"Couldn't delete. Please try again."` and still calls `onDelete()`
- Informs the user that deleting the profile causes new macOS hosts to fall back to default setup enrollment settings
