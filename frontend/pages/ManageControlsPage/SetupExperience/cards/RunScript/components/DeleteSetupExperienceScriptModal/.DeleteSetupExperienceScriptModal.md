A confirmation modal component for deleting a setup experience script associated with a Fleet MDM team.

## Key Components

- **`DeleteSetupExperienceScriptModal`** — Default export. Renders a modal with a delete confirmation flow, including loading state management and flash notifications on success or failure.
- **`IDeleteSetupExperienceScriptModalProps`** — Props interface defining:
  - `currentTeamId` — The team whose setup script will be deleted
  - `scriptName` — Display name of the script shown in the warning message
  - `onExit` — Callback to close/dismiss the modal
  - `onDeleted` — Callback invoked after the delete attempt (success or failure)

## Usage Example

```typescript
<DeleteSetupExperienceScriptModal
  currentTeamId={42}
  scriptName="onboarding.sh"
  onExit={() => setShowDeleteModal(false)}
  onDeleted={() => {
    setShowDeleteModal(false);
    refreshScriptData();
  }}
/>
```

## Behavior Notes

- Calls `mdmAPI.deleteSetupExperienceScript(currentTeamId)` on confirmation.
- Disables modal content during the async delete to prevent duplicate submissions.
- Renders a flash success message on completion, or an error message if the API call fails.
- Warns the user that any **pending** script executions will be cancelled, but scripts already running on a host will complete without reporting results to Fleet.
