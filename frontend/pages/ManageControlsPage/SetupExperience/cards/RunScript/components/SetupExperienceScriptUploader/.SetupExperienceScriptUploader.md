A React component that renders a file uploader for shell scripts used during the macOS MDM setup experience, handling upload state and error notifications.

## Key Components

- **`SetupExperienceScriptUploader`** – Default export. Wraps `FileUploader` to accept `.sh` files and upload them via `mdmAPI.uploadSetupExperienceScript`.
- **`ISetupExperienceScriptUploaderProps`** – Props interface defining:
  - `currentTeamId` – Team scope for the script upload.
  - `hasManualAgentInstall` – Disables the uploader when Fleet's agent is manually installed via bootstrap package.
  - `onUpload` – Callback fired on successful upload.
  - `className` – Optional CSS class override.

## Key Behaviors

- Displays a loading state during upload via `showLoading` state.
- On success, triggers a flash notification (`"Successfully uploaded."`) and calls `onUpload()`.
- On failure, extracts a human-readable reason via `getErrorReason` and flashes an error.
- When `hasManualAgentInstall` is `true`, the upload button is **disabled** with a tooltip explaining users should use the bootstrap package instead.

## Usage Example

```typescript
<SetupExperienceScriptUploader
  currentTeamId={42}
  hasManualAgentInstall={false}
  onUpload={() => refetchSetupExperience()}
  className="my-custom-class"
/>
```
