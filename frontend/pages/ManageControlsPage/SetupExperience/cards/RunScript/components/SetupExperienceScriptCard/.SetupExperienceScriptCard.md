Renders a card UI component displaying a setup experience script with its name, upload timestamp, and action buttons for downloading or deleting the script.

## Key Components

- **`SetupExperienceScriptCard`** — Default export. A React functional component that accepts a `script` object and an `onDelete` callback.
- **`ISetupExperienceScriptCardProps`** — Interface defining the component's props:
  - `script: IGetSetupExperienceScriptResponse` — Script metadata including `name`, `created_at`, and `team_id`
  - `onDelete: () => void` — Callback triggered when the delete button is clicked
- **`onDownload`** — Async handler that fetches the script binary via `mdmAPI.downloadSetupExperienceScript`, constructs a dated filename, and saves it using `FileSaver`. Displays an error flash notification on failure.

## Usage Example

```typescript
import SetupExperienceScriptCard from "components/SetupExperienceScriptCard";

const MyPage = () => {
  const script = {
    name: "setup.sh",
    created_at: "2024-01-15T10:00:00Z",
    team_id: 1,
  };

  const handleDelete = () => {
    console.log("Script deleted");
  };

  return (
    <SetupExperienceScriptCard
      script={script}
      onDelete={handleDelete}
    />
  );
};
```

## Notes

- Uses `API_NO_TEAM_ID` as a fallback when `script.team_id` is `null` or `undefined`.
- Downloaded filename format: `YYYY-M-D_<script_name>` (e.g., `2024-0-15_setup.sh`).
- Leverages `NotificationContext` to surface download errors as flash messages.
