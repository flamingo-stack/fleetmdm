Manages the "Run Script" section of the Fleet MDM Setup Experience configuration, allowing administrators to upload, view, and delete scripts that run on macOS hosts during automatic enrollment.

## Key Components

- **`RunScript`** – Main React component that orchestrates script management within the Setup Experience flow
- **`useQuery` (script)** – Fetches the current setup experience script via `mdmAPI.getSetupExperienceScript`
- **`useQuery` (globalConfig/teamConfig)** – Loads MDM configuration to gate feature availability and check manual agent install settings
- **`renderContent()`** – Conditionally renders a spinner, error state, MDM-not-configured empty state, script uploader, or the existing script card
- **`SetupExperienceScriptUploader`** – Shown when no script exists; handles file upload
- **`SetupExperienceScriptCard`** – Displays the current script with a delete trigger
- **`DeleteSetupExperienceScriptModal`** – Confirmation modal for script deletion

## Usage Example

```typescript
// Used as a routed card within the Setup Experience navigation
import RunScript from "./RunScript";

<RunScript
  currentTeamId={selectedTeamId}
  router={router}
/>
```

## Behavior Notes

- Requires MDM to be enabled **and** Apple Business Manager configured; otherwise renders an "Additional configuration required" empty state with a redirect to MDM settings
- On upload or delete, the script query is refetched and the cache entry is cleared to ensure UI consistency
- `retry: false` is set on the script query so 404 responses (no script uploaded yet) gracefully render the uploader instead of retrying
