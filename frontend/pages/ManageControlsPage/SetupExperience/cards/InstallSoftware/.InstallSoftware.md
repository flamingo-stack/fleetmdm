A React component that manages software installation configuration for Fleet's Setup Experience feature, providing a tabbed interface for configuring software installation across multiple device platforms (macOS, Windows, Linux, iOS, iPadOS, and Android).

## Key Components

### `InstallSoftware` (default export)
The main container component that renders a platform-tabbed layout for setup experience software configuration.

**Props** (`ISetupExperienceCardProps`):
- `currentTeamId` — Active team context (uses `API_NO_TEAM_ID` for global)
- `router` — React Router instance for navigation
- `urlPlatformParam` — Current platform slug from URL (validated via `isSetupExperiencePlatform`)

### `PLATFORM_BY_INDEX`
Exported constant array mapping tab index positions to `SetupExperiencePlatform` values: `["macos", "windows", "linux", "ios", "ipados", "android"]`

### `renderTabContent(platform)`
Internal renderer that returns one of three states per platform tab:
- `<Spinner />` — while loading
- `<DataError />` — on fetch failure
- `<EmptyState />` — when MDM is not enabled (Apple MDM + ABM required for Apple/iOS/iPadOS, Android MDM for Android)
- `<InstallSoftwareForm />` — fully configured state

## Data Fetching

| Query Key | Source | Purpose |
|-----------|--------|---------|
| `install-software` | `mdmAPI.getSetupExperienceSoftware` | Fetches up to 3,000 software titles for the selected platform |
| `config` | `configAPI.loadAll` | Loads global MDM configuration |
| `team` | `teamsAPI.load` | Loads team-specific MDM config (skipped for no-team context) |

## Usage Example

```typescript
// Rendered by the Setup Experience router with platform param
<InstallSoftware
  currentTeamId={42}
  router={router}
  urlPlatformParam="macos"
/>
```
