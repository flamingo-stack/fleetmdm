Generates the react-table column configuration for the "Install Software" table used in the Fleet MDM setup experience flow, supporting macOS, Linux, Android, and iOS platforms.

## Key Components

- **`generateTableConfig`** – Main export. Returns an array of `Column<ISoftwareTitle>` definitions given a target platform, a selection callback, and an optional agent-install blocking flag.
- **`getSetupExperienceLinuxPackageCopy`** – Internal helper that maps a `SoftwareSource` value (`rpm_packages`, `deb_packages`, `tgz_packages`) to its short package-type suffix (`rpm`, `deb`, `tar`).

### Columns Produced

| Column | Notes |
|---|---|
| `selection` | Checkbox wrapped in `GitOpsModeTooltipWrapper`; disabled when GitOps mode is active or `manualAgentInstallBlockingSoftware` is `true` |
| `Name` | Renders `SoftwareNameCell` with icon, display name, and source |
| `Version` | Android: fetches latest via `AndroidLatestVersionWithTooltip`; Linux: appends package type suffix (e.g., `1.2.3 (.rpm)`); others: raw version string |

## Usage Example

```typescript
import generateTableConfig from "./InstallSoftwareTableConfig";

const handleSelectSoftware = (selected: boolean, id: number) => {
  console.log(`Software ${id} ${selected ? "selected" : "deselected"}`);
};

// macOS setup experience table
const macOSColumns = generateTableConfig("darwin", handleSelectSoftware);

// Linux with agent install blocked
const linuxColumns = generateTableConfig(
  "linux",
  handleSelectSoftware,
  true // manualAgentInstallBlockingSoftware
);
```
