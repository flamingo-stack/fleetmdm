Renders a paginated, searchable table for selecting software to install during the setup experience, with platform-specific help text and pre-selected rows based on existing install configurations.

## Key Components

- **`InstallSoftwareTable`** — Default export. Main component wrapping `TableContainer` with selection persistence, client-side pagination/filtering, and dynamic help text.
- **`generateHelpText(platform)`** — Returns platform-aware contextual help text for `windows`, `linux`, or macOS (default).
- **`generateSelectedRows(softwareTitles)`** — Derives initial row selection state from `software_package.install_during_setup` or `app_store_app.install_during_setup` flags on each title.

## Props

| Prop | Type | Description |
|------|------|-------------|
| `softwareTitles` | `ISoftwareTitle[]` | List of software items to display |
| `onChangeSoftwareSelect` | `(select: boolean, id: number) => void` | Callback fired on row selection change |
| `platform` | `SetupExperiencePlatform` | Controls help text and table column config |
| `renderCustomCount` | `() => JSX.Element` | Optional custom row count renderer |
| `manualAgentInstallBlockingSoftware` | `boolean` | Passed to table config; defaults to `false` |

## Usage Example

```typescript
<InstallSoftwareTable
  softwareTitles={softwareTitles}
  platform="macOS"
  onChangeSoftwareSelect={(selected, id) => {
    handleSoftwareToggle(selected, id);
  }}
  renderCustomCount={() => <span>{softwareTitles.length} items</span>}
  manualAgentInstallBlockingSoftware={false}
/>
```

## Notes

- Row selection state is **persisted across pagination** via `persistSelectedRows`.
- Row IDs are derived from `software.id` (cast to `string`) to match `DataTable`'s `getRowId` implementation.
- Table config is memoized on `platform`, `onChangeSoftwareSelect`, and `manualAgentInstallBlockingSoftware` to avoid unnecessary re-renders.
