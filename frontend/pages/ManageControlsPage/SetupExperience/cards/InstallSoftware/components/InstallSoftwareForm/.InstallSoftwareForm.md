Form component for managing software installation during the MDM setup experience, allowing users to select which software titles should be installed on devices during enrollment and configure failure behavior options per platform.

## Key Components

### `InstallSoftwareForm`
The primary exported component that renders a form with:
- **`InstallSoftwareTable`** — Displays selectable software titles for setup installation
- **`requireAllSoftware` checkboxes** — Platform-specific "Cancel setup if software fails" options (macOS and Windows only)
- **`GitOpsModeTooltipWrapper`** — Disables controls when GitOps mode is active
- **Save button** — Submits software selection and requirement settings via `mdmAPI`

### Helper Functions

| Function | Description |
|---|---|
| `initializeSelectedSoftwareIds` | Seeds initial checkbox state from `install_during_setup` flags on software titles |
| `getAddSoftwareUrl` | Builds a platform-aware route to the Add Software page with team query params |

### Key State

| State | Purpose |
|---|---|
| `selectedSoftwareIds` | Tracks currently selected software IDs |
| `requireAllSoftwareMacOS` / `requireAllSoftwareWindows` | Tracks the "cancel on failure" checkbox per platform |
| `touchedRequireAll` | Detects if the require-all checkbox was changed since last save (avoids race with parent refetch) |
| `isSoftwareSelectionDirty` | Prevents unnecessary API calls when selection is unchanged |

## Usage Example

```typescript
<InstallSoftwareForm
  currentTeamId={42}
  hasManualAgentInstall={false}
  softwareTitles={softwareTitles}
  platform="macos"
  savedRequireAllSoftwareMacOS={true}
  isWindowsMdmEnabled={false}
  router={router}
  refetchSoftwareTitles={() => refetch()}
/>
```

On save, the form independently calls `mdmAPI.updateSetupExperienceSoftware` and `mdmAPI.updateRequireAllSoftwareMacOS/Windows`, batching any errors into a multi-flash notification rather than failing silently.
