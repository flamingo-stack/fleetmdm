Test suite for the `InstallSoftwareForm` component, validating rendering behavior, platform-specific UI logic, and API interactions for the MDM setup experience software installation form.

## Key Components

- **`render`** — Custom renderer with backend mock support via `createCustomRenderer`
- **`InstallSoftwareForm`** — Component under test; accepts props including `softwareTitles`, `platform`, `currentTeamId`, `hasManualAgentInstall`, and saved-state flags

## Test Coverage

| Scenario | Description |
|---|---|
| Empty state | Renders "No software available" message and "Add software" button when `softwareTitles` is `null` |
| No selection | Displays "0 software items installed during setup" when titles exist but none are selected |
| macOS selection | Shows correct count, tooltip with alphabetical install order note |
| Android selection | Shows correct count, tooltip with "Software order will vary" message |
| macOS cancel checkbox | Renders checked "Cancel setup if software fails" checkbox for macOS |
| Windows cancel checkbox | Renders checked checkbox for Windows when `savedRequireAllSoftwareWindows` is set |
| Windows API call | Verifies `mdmAPI.updateRequireAllSoftwareWindows` is called with correct team ID on Save |
| Windows MDM disabled | Checkbox is `aria-disabled` when `isWindowsMdmEnabled={false}` |
| macOS manual agent | Save button is disabled when `hasManualAgentInstall` is `true` |
| Non-macOS manual agent | Save button remains enabled for all `SETUP_EXPERIENCE_PLATFORMS` except macOS |

## Usage Example

```typescript
import { createMockSoftwarePackage, createMockSoftwareTitle } from "__mocks__/softwareMock";

// Render with pre-selected software for setup
render(
  <InstallSoftwareForm
    savedRequireAllSoftwareMacOS={false}
    currentTeamId={1}
    softwareTitles={[
      createMockSoftwareTitle({
        software_package: createMockSoftwarePackage({ install_during_setup: true }),
      }),
    ]}
    hasManualAgentInstall={false}
    platform="macos"
    router={createMockRouter()}
    refetchSoftwareTitles={noop}
  />
);
```
