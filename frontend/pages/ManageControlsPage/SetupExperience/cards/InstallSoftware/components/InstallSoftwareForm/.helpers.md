Utility helpers for evaluating software title collections during macOS Setup Experience flows.

## Key Components

- **`hasNoSoftwareUploaded`** — Returns `true` if the provided `ISoftwareTitle` array is nullish or empty.
- **`getInstallSoftwareDuringSetupCount`** — Counts how many software titles (either package or App Store app) are flagged with `install_during_setup`.

## Usage Example

```typescript
import {
  hasNoSoftwareUploaded,
  getInstallSoftwareDuringSetupCount,
} from "./helpers";

const titles: ISoftwareTitle[] = [
  { software_package: { install_during_setup: true }, app_store_app: null },
  { software_package: null, app_store_app: { install_during_setup: false } },
];

hasNoSoftwareUploaded(titles);                   // false
hasNoSoftwareUploaded([]);                        // true
getInstallSoftwareDuringSetupCount(titles);       // 1
getInstallSoftwareDuringSetupCount(undefined);    // 0
```
