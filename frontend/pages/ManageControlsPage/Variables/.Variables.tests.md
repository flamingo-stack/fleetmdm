Test suite for the `Variables` component, validating rendering behavior, user interactions, and API integration for the custom variables management UI in Fleet MDM's Controls section.

## Key Components

- **`emptyVariablesHandler`** – MSW handler mocking an empty `/custom_variables` GET response
- **`variablesHandler` / `addVariableHandler` / `deleteVariableHandler`** – MSW handlers simulating full CRUD operations on custom variables
- **`getAddVariableUI`** – Helper that waits for and returns the add-variable form elements (name input, value input, save button)
- **`renderInGOM`** – Custom renderer with GitOps Mode (GOM) enabled context for testing read-only/disabled states

## Test Coverage

| Suite | Scenarios Covered |
|---|---|
| Empty state | Add CTA visible for admins; read-only message for non-editors |
| Non-empty state | Variables list renders correctly |
| GitOps mode | Add button disabled; delete still functional |
| Adding a variable | Valid submission, missing name, missing value, invalid name format, name too long |

## Usage Example

```typescript
// Run the full test suite
npx jest Variables.tests.tsx

// Run a specific describe block
npx jest Variables.tests.tsx -t "adding a new variable"
```

The tests use `msw` for API mocking via `mockServer`, `@testing-library/react` for rendering/assertions, and `createCustomRenderer` / `createMockRouter` from the project's test utilities.
