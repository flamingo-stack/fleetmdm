A modal dialog component for creating custom Fleet secret variables, handling form input, validation, and API submission.

## Key Components

- **`AddCustomVariableModal`** — Main React component rendering the modal form
- **`AddCustomVariableModalProps`** — Props interface with `onCancel` and `onSave` callbacks
- **`IAddCustomVariableFormData`** — Exported interface defining `name` and `value` fields
- **`onInputChange`** — Handles field updates; auto-uppercases and trims the variable name
- **`onClickSave`** — Validates form, calls `variablesAPI.addVariable`, and handles 409 conflict errors

## Key Behaviors

- Variable names are automatically trimmed and uppercased on input
- Form validation runs on every keystroke via `validateFormData` from `./helpers`
- The Save button is disabled while validation fails or a save is in progress
- On success, renders a flash notification and calls `onSave()`
- On a 409 conflict, shows a specific "already exists" error message
- Variables are accessible in scripts/profiles as `$FLEET_SECRET_{NAME}`

## Usage Example

```typescript
import AddCustomVariableModal from "./AddCustomVariableModal";

const MyPage = () => {
  const [showModal, setShowModal] = useState(false);

  const handleSave = () => {
    setShowModal(false);
    // Refresh variable list
  };

  return (
    <>
      {showModal && (
        <AddCustomVariableModal
          onCancel={() => setShowModal(false)}
          onSave={handleSave}
        />
      )}
    </>
  );
};
```
