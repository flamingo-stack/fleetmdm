Manages the Variables page UI, which lists, adds, and deletes custom Fleet secret variables available for use in scripts and configuration profiles.

## Key Components

- **`Variables`** — Main page component rendering the variables list, header actions, and modals
- **`VARIABLES_PAGE_SIZE`** — Exported constant (`20`) controlling pagination page size
- **`renderVariableRow`** — Renders each variable as a `ListItem` with copy-to-clipboard and delete actions
- **`renderContent`** — Conditionally renders a loading spinner, empty state, or paginated list
- **`onCopyVariableName`** — Copies the `$FLEET_SECRET_<NAME>` token to clipboard with a timed feedback message
- **`getTokenFromVariableName`** — Transforms a variable name into its `$FLEET_SECRET_<NAME>` token format
- **Deep-link support** — Reads `?add_variable=1` from the URL to auto-open the Add modal (admin/maintainer only), then strips the param

## Usage Example

```typescript
// Rendered by the Fleet router; receives router and location as props
import Variables from "./Variables";

<Variables
  router={router}
  location={{
    pathname: "/settings/variables",
    query: { add_variable: "1" }, // opens Add modal on load
  }}
/>
```

```typescript
// Token format produced by getTokenFromVariableName:
// Input:  "my_secret"
// Output: "$FLEET_SECRET_MY_SECRET"
```

## Permissions

| Role | View | Add | Delete |
|------|------|-----|--------|
| Global Admin | ✅ | ✅ | ✅ |
| Global Maintainer | ✅ | ✅ | ✅ |
| Other | ✅ | ❌ | ❌ |

Add/delete actions are further guarded by `GitOpsModeTooltipWrapper` to disable them when GitOps mode is active.
