A reusable heading component for upload list sections, displaying an entity name and an optional "add" button wrapped with GitOps mode awareness.

## Key Components

- **`UploadListHeading`** — Default export. Renders a section heading with an entity label and a conditionally rendered add/create button.
- **`IUploadListHeadingProps`** — Props interface:
  - `entityName` — Display label shown as the heading text.
  - `createEntityText` — Button label text for the add action.
  - `onClickAdd` *(optional)* — Callback fired when the add button is clicked; omitting it hides the button entirely.
- **`GitOpsModeTooltipWrapper`** — Wraps the add button to disable it and show a tooltip when GitOps mode is active.

## Usage Example

```typescript
import UploadListHeading from "components/UploadListHeading";

<UploadListHeading
  entityName="Scripts"
  createEntityText="Add script"
  onClickAdd={() => setShowAddModal(true)}
/>

// Read-only heading (no add button rendered)
<UploadListHeading
  entityName="Certificates"
  createEntityText="Add certificate"
/>
```

## Notes

- The add button uses the `brand-inverse-icon` variant and renders a `plus` icon in `core-fleet-green`.
- When `onClickAdd` is not provided, the actions area is omitted from the DOM entirely.
- GitOps mode disables the button automatically via `disableChildren` — no additional handling is needed by consumers.
