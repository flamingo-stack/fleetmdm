The `ManageControlsPage` component serves as the layout and navigation shell for the Controls section of the Fleet MDM admin interface, managing tab-based sub-navigation and team context.

## Key Components

- **`controlsSubNav`** — Static array defining the five sub-nav tabs: OS updates, OS settings, Setup experience, Scripts, and Variables.
- **`permittedControlsSubNav`** — Memoized filtered nav based on user role: technicians see only "OS settings" and "Scripts"; non-admins see all tabs except "OS updates".
- **`getTabIndex`** — Utility that resolves the active tab index by matching the current pathname prefix against nav items.
- **`navigateToNav`** — Callback that handles tab switching, stripping pagination/sort query params (`page`, `order_key`, `order_direction`, `status`) on navigation.
- **`renderHeaderContent`** — Conditionally renders a `TeamsDropdown`, a single team name `<h1>`, or a plain "Controls" `<h1>` based on tier and team membership.
- **`useTeamIdParam`** — Hook wiring team selection to URL params, restricting access to admin, maintainer, and technician roles only.

## Usage Example

```typescript
// Rendered via React Router — children are the routed sub-page components
<ManageControlsPage
  location={location}
  router={router}
>
  <OSUpdatesPage />
</ManageControlsPage>
```

Child components receive three injected props via `React.cloneElement`:

```typescript
// Injected into children automatically:
{
  teamIdForApi: number | undefined,   // resolved team ID for API calls
  currentPage: number,                // parsed from ?page= query param
  queryParams: OSUpdatesQueryParams,  // parsed from location.query
}
```
