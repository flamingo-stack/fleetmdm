Defines and exports a custom React hook that builds the side navigation items for the Scripts section, conditionally including the "Batch Progress" tab based on the current user's role.

## Key Components

- **`useScriptNavItems`** – Custom hook that returns a memoized array of `ISideNavItem` entries for the Scripts side navigation. Accepts an optional `teamId` and reads role flags from `AppContext`.
- **`IScriptsCommonProps`** – Shared prop interface (`router`, `location`, `teamId`) used across Scripts card components.
- **`IScriptsCardProps`** – Union type of all possible card prop interfaces (`IScriptLibraryProps | IScriptBatchProgressProps`), kept as a union for easy future extension.

### Navigation Items

| Title | URL Section | Visibility |
|---|---|---|
| Library | `library` | All roles |
| Batch progress | `progress` | Admins/Maintainers only (hidden from team/global technicians) |

## Usage Example

```typescript
import useScriptNavItems from "./ScriptsNavItems";

const Scripts = ({ teamId }: { teamId: number }) => {
  const navItems = useScriptNavItems(teamId);

  return (
    <SideNav
      items={navItems}
      // ...other props
    />
  );
};
```

## Notes

- Uses `useMemo` to avoid rebuilding the nav item array on every render; only recomputes when `teamId`, `isTeamTechnician`, or `isGlobalTechnician` changes.
- The `fleet_id` query parameter defaults to `0` when `teamId` is `undefined`.
- The `IScriptsCardProps` union type and `IScriptsCommonProps` interface are intentionally separated to accommodate future per-card prop divergence without structural changes.
