Test suite for the `ScriptBatchProgress` component, verifying tab navigation, empty states, and script list rendering across `started`, `scheduled`, and `finished` batch script statuses.

## Key Components

- **`waitForLoadingToFinish`** — Helper that waits for the loading spinner (`.script-batch-progress__loading`) to disappear before asserting
- **`emptyTeamBatchSummariesHandler`** — MSW handler returning an empty `batch_executions` list for `/scripts/batch`
- **`teamBatchSummariesHandler`** — MSW handler returning mock data per `status` query param (`started`, `scheduled`, `finished`)
- **`getTestLocation`** — Builds a `ScriptsLocation` object with the given `ScriptBatchStatus`
- **`EMPTY_STATE_TEXT`** — Map of expected empty-state copy per status tab
- **`testTabURLNavAndEmpty`** — Shared helper that renders the component, asserts all three tabs are present with correct selection state, and verifies the empty-state message

## Usage Example

```typescript
// Run a specific test case manually
it("Renders the 'started' tab with appropriate scripts list", async () => {
  mockServer.use(teamBatchSummariesHandler);

  const render = createCustomRenderer({ withBackendMock: true });
  const { container } = render(
    <ScriptBatchProgress
      router={createMockRouter()}
      teamId={1}
      location={getTestLocation("started")}
    />
  );

  await waitForLoadingToFinish(container);

  await waitFor(() => {
    expect(screen.getByText("Test Script 1")).toBeInTheDocument();
    // (ran + errored) / targeted
    expect(screen.getByText(/65\s+\/\s+100/m)).toBeInTheDocument();
  });
});
```

## Test Coverage

| Test | Status Verified |
|------|----------------|
| Empty state via URL nav | `started`, `scheduled`, `finished` |
| Script list with `started` data | Script name, relative start time, host progress |

| Script list with `finished` data | Completed/Canceled states, host counts for two scripts |
