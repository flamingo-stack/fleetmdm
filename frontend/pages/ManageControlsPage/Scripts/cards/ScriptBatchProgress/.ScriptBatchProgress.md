A React component that displays batch script execution progress across a fleet of hosts, organized into tabbed views by status (Started, Scheduled, Finished).

## Key Components

- **`ScriptBatchProgress`** — Main component rendering a tabbed UI for monitoring batch script execution state
- **`STATUS_BY_INDEX`** — Ordered array mapping tab indices to `ScriptBatchStatus` values (`started`, `scheduled`, `finished`)
- **`EMPTY_STATE_DETAILS`** — Per-status empty state messages with learn-more links
- **`renderRow`** — Renders a list item with script name, host count, and a segmented `ProgressBar` showing ran vs. errored hosts
- **`renderTabContent`** — Handles loading spinner, empty state, and paginated list rendering per tab
- **`handleTabChange`** — Updates the URL `status` query param and resets pagination on tab switch

## Usage Example

```typescript
// Used as a route-level component within the Controls > Scripts section
<ScriptBatchProgress
  location={location}  // React Router location with `?status=` query param
  router={router}      // React Router history object
  teamId={currentTeamId}
/>
```

## Behavior Notes

- **URL-driven tab state**: Active tab is determined by `?status=` in the URL; invalid values redirect to `started` via `useEffect`
- **Paginated results**: Uses `PaginatedList` with a default page size of 10, keyed by `{ fleet_id, status, page, per_page }`
- **Row click navigation**: Clicking a batch row navigates to `CONTROLS_SCRIPTS_BATCH_DETAILS` with `?status=ran` pre-set to avoid triggering downstream redirect effects
- **Progress visualization**: Non-scheduled rows show a two-section `ProgressBar` — green for successful runs, red for errors — alongside raw host counts
