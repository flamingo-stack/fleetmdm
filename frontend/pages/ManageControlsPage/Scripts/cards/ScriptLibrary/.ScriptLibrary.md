Renders the paginated script library page for Fleet MDM's Controls section, allowing admins to view, upload, edit, and delete scripts while respecting team/technician permissions and GitOps mode.

## Key Components

### `ScriptLibrary` (default export)
Main page component that manages the full script library lifecycle.

**Props** (`IScriptLibraryProps` / `IScriptsCommonProps`):
- `router` — React Router instance for navigation and query param manipulation
- `teamId` — Current team ID used to scope script queries
- `location` — Current route location, including query params (`page`, `add_script`)

**Internal state & behavior:**
- Fetches paginated scripts via `scriptAPI.getScripts` using `react-query` (10 per page)
- Tracks `selectedScript` via `useRef` for delete/edit modal targets
- Reads `?add_script=1` query param on mount to auto-open the upload modal (non-technicians only), then cleans the param from the URL
- Renders a disabled-scripts warning banner when `config.server_settings.scripts_disabled` is `true`
- Technicians (`isGlobalTechnician` | `isTeamTechnician`) have read-only access — upload/add controls are hidden

## Usage Example

```typescript
// Rendered by the router — not typically instantiated directly
<ScriptLibrary
  router={router}
  teamId={42}
  location={location}
/>

// Deep-link to open the upload modal automatically:
// /controls/scripts/library?fleet_id=42&add_script=1
```

## Key Behaviors

| Scenario | Result |
|---|---|
| `scripts_disabled = true` | Yellow `InfoBanner` shown above list |
| No scripts, page 0, admin | `EmptyState` with "Upload" button (GitOps-aware) |
| No scripts, page 0, technician | `EmptyState` with no action button |
| Script selected | Opens `EditScriptModal` or `DeleteScriptModal` |
| Upload submitted / script deleted | `refetchScripts()` called to refresh list |
