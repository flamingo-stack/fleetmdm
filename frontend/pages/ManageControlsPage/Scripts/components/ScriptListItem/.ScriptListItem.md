A reusable list item component for displaying individual scripts in the Fleet MDM scripts management UI, showing script metadata, platform info, and action controls.

## Key Components

### `ScriptListItem` (default export)
The main component rendering a single script entry using the `ListItem` layout. Handles edit, download, and delete actions with GitOps mode awareness.

### `ScriptListItemDetails`
Internal sub-component displaying the script's target platform and relative upload time.

### `getFileRenderDetails(fileName)`
Utility that maps file extensions to graphic icons and platform labels:

| Extension | Graphic | Platform |
|-----------|---------|----------|
| `.py` | `file-py` | macOS & Linux |
| `.sh` | `file-sh` | macOS & Linux |
| `.ps1` | `file-ps1` | Windows |
| other | `file-script` | null |

### `onDownload(script, renderFlash)`
Async handler that fetches script content via `scriptAPI.downloadScript`, names the file with a `yyyy-MM-dd` prefix, and triggers a browser download via `FileSaver`.

## Props

| Prop | Type | Description |
|------|------|-------------|
| `script` | `IScript` | Script data object |
| `onDelete` | `(script: IScript) => void` | Delete callback |
| `onClickScript` | `(script: IScript) => void` | Row click callback |
| `onEdit` | `(script: IScript) => void` | Edit callback |
| `isTechnician` | `boolean?` | Hides action buttons when `true` |

## Usage Example

```typescript
<ScriptListItem
  script={script}
  onDelete={(s) => openDeleteModal(s)}
  onClickScript={(s) => openScriptDetailModal(s)}
  onEdit={(s) => openEditModal(s)}
  isTechnician={currentUser.role === "technician"}
/>
```
