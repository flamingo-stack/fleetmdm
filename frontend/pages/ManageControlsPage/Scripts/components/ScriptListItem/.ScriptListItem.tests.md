Unit tests for the `ScriptListItem` React component, verifying rendering, user interactions, accessibility labels, and GitOps mode behavior.

## Key Components

- **`MAC_SCRIPT` / `WINDOWS_SCRIPT`** — Fixture `IScript` objects used across test cases to represent `.sh` and `.ps1` scripts respectively
- **`scriptAPI` mock** — Mocked `downloadScript` service to isolate API calls during tests
- **Main `describe` block** — Covers core rendering and interaction behavior
- **Nested `describe("with GitOps mode enabled")`** — Tests disabled edit/delete actions and available download when GitOps mode is active

## Test Coverage

| Scenario | Assertion |
|---|---|
| Platform label for `.sh` script | Renders "macOS & Linux" |
| Platform label for `.ps1` script | Renders "Windows" |
| Accessibility button labels | Edit/Download/Delete buttons include script name |
| Script name click | Calls `onClickScript` with the script object |
| Click elsewhere in item | Calls `onClickScript`, not `onEdit`/`onDelete` |
| Delete button click | Calls `onDelete` only |
| Edit button click | Calls `onEdit` only |
| GitOps: pencil/trash disabled | No callbacks fired |
| GitOps: download button | Calls `scriptAPI.downloadScript` with script ID |
