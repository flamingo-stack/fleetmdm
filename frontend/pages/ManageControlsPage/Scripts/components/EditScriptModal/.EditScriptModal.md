Modal component for editing existing Fleet scripts, supporting `.sh`, `.ps1`, and `.py` file types with syntax highlighting, GitOps mode awareness, and a confirmation step when changes would cancel pending script runs.

## Key Components

- **`EditScriptModal`** — Primary export. Fetches the current script content via `scriptAPI.downloadScript`, renders a syntax-aware `Editor`, and handles save logic including validation and optimistic confirmation gating.
- **`WarningModal`** — Internal sub-modal that surfaces when saving would cancel pending script runs. Requires explicit user confirmation before committing the update.
- **`validate`** — Pure validation function that rejects empty or whitespace-only script content.

## Usage Example

```typescript
import EditScriptModal from "components/EditScriptModal";

<EditScriptModal
  scriptId={42}
  scriptName="remediate.sh"
  onExit={() => setShowEditModal(false)}
/>
```

## Key Behaviors

- **Syntax mode detection** — Editor mode is derived from the script filename extension: `.ps1` → `powershell`, `.py` → `python`, default → `sh`.
- **Change detection** — If the edited content differs from the fetched original, a `WarningModal` intercepts the save flow before calling `scriptAPI.updateScript`.
- **GitOps mode** — When `gitOpsModeEnabled` is `true`, the editor is set to `readOnly` and the Save button is disabled via `GitOpsModeTooltipWrapper`.
- **Role-based UI** — The `ModalFooter` with Save/Cancel actions is only rendered for users with `canRunScripts` permissions (admins and maintainers).
