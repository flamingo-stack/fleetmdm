A modal component for uploading scripts to a Fleet MDM team, handling file selection, upload submission, and contextual guidance based on script type.

## Key Components

- **`ScriptUploadModal`** — Default export. A controlled modal that wraps `ScriptUploader` and manages upload state.
- **`IScriptUploadModal`** — Interface defining required props: `onExit`, `onSubmit`, and `currentTeamId`.
- **`onUploadFile`** — Async handler that calls `scriptAPI.uploadScript`, triggers success/error flash notifications, and manages loading state.
- **`additionalInfo`** — Derived string shown below the uploader for `.sh` files (shebang interpreter info) and `.py` files (Python shebang requirement).

## Usage Example

```typescript
import ScriptUploadModal from "pages/ManageControlsPage/Scripts/components/ScriptUploadModal";

<ScriptUploadModal
  currentTeamId={42}
  onExit={() => setShowModal(false)}
  onSubmit={() => {
    setShowModal(false);
    refetchScripts();
  }}
/>
```

## Behavior Notes

- **File selection** is delegated to `ScriptUploader` via the `forModal` prop.
- **Shell scripts** (`.sh`): displays a note about interpreter selection via shebang (e.g., `#!/bin/bash`).
- **Python scripts** (`.py`): displays a note requiring a python shebang (e.g., `#!/usr/bin/env python3`).
- **Submit button** is disabled until a file is selected or while upload is in progress.
- Flash notifications are rendered via `NotificationContext` on both success and error paths.
