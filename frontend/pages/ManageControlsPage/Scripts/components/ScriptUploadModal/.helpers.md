Parses and formats API error messages for script upload failures into user-friendly strings.

## Key Components

### `getErrorMessage(err: unknown): string`
Transforms raw API errors into human-readable messages for the script add flow. Handles two specific error cases before falling back to the generic API message or a default string.

| Condition | Returned Message |
|---|---|
| Unsupported file type | `"Couldn't add. The file should be a .sh, .py, or .ps1 file."` |
| Secret variable error | Result of `generateSecretErrMsg(err)` |
| Other API error | Raw API error reason |
| No error reason | `"Couldn't add. Please try again."` |

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await addScript(payload);
} catch (err) {
  const message = getErrorMessage(err);
  renderFlash("error", message);
}
```

## Dependencies

- [`getErrorReason`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/errors.ts) — extracts the error reason string from an API error object
- [`generateSecretErrMsg`](https://github.com/flamingo-stack/fleetmdm/blob/main/pages/SoftwarePage/helpers.ts) — builds a formatted message when secret variable errors are returned
