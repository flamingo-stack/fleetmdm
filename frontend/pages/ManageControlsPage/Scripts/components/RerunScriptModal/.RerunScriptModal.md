A confirmation modal component that prompts users before rerunning a script across macOS hosts, with context-aware messaging based on tier and team assignment.

## Key Components

- **`RerunScriptModal`** — Default export. Renders a Modal with a confirmation message and Rerun/Cancel action buttons.
- **`generateMessageSuffix`** — Helper that appends context-sensitive text to the confirmation message:
  - Free tier: no suffix
  - Premium + team assigned: `" assigned to this fleet"`
  - Premium + no team: `" that are unassigned"`
- **`IRerunScriptModalProps`** — Interface defining required props: `scriptName`, `scriptId`, `onCancel`, and `onRerun`.

## Usage Example

```typescript
<RerunScriptModal
  scriptName="install-updates.sh"
  scriptId={42}
  onCancel={() => setShowModal(false)}
  onRerun={(id) => handleRerun(id)}
/>
```

The modal reads `isPremiumTier` and `currentTeam` from `AppContext` to tailor its message. Pressing **Rerun** or hitting Enter invokes `onRerun(scriptId)`; pressing **Cancel** or exiting the modal calls `onCancel`.

> **Note:** This script targets **all macOS hosts** matching the current tier/team scope. As stated in the modal copy, it may cause the script to run more than once on some hosts.
