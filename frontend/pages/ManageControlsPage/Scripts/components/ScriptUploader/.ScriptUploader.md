A React component that renders a file upload interface for script files, supporting `.sh`, `.py`, and `.ps1` formats with dynamic icon rendering based on the selected file's extension.

## Key Components

### `IScriptPackageUploaderProps`
| Prop | Type | Description |
|------|------|-------------|
| `onFileSelected` | `(file: File) => void` | Callback triggered when a file is selected |
| `selectedFile` | `File \| null` | Currently selected file |
| `forModal` | `boolean` | Adjusts button style/label when rendered inside a modal |
| `onButtonClick` | `() => void` | Callback triggered on button click |

### `ScriptPackageUploader`
The default export. Wraps the shared `FileUploader` component with script-specific configuration:

- **Dynamic graphic icons** — Resolves to `file-ps1`, `file-py`, or `file-sh` based on the selected file's extension. Displays all three icons when no file is selected.
- **Accepted formats** — Restricted to `.sh`, `.py`, and `.ps1` via the `accept` attribute.
- **Modal-aware UI** — Switches button type to `brand-inverse-icon` and label to `"Choose file"` when `forModal` is `true`.

## Usage Example

```typescript
import ScriptPackageUploader from "./ScriptUploader";

// Standalone usage
<ScriptPackageUploader
  onFileSelected={(file) => console.log("Selected:", file.name)}
  selectedFile={selectedFile}
/>

// Inside a modal
```
