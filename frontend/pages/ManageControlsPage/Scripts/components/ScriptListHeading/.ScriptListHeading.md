A heading component for the scripts list section that renders a "Scripts" title and an optional "Add script" button with GitOps mode awareness.

## Key Components

- **`ScriptListHeading`** — Default export. Renders the section heading with an optional action button.
- **`IScriptListHeading`** — Props interface with an optional `onClickAddScript` callback.
- **`GitOpsModeTooltipWrapper`** — Wraps the add button to disable it and show a tooltip when GitOps mode is active.

## Usage Example

```typescript
// With add script action
<ScriptListHeading onClickAddScript={() => setShowAddScriptModal(true)} />

// Read-only / no action (e.g. non-admin view)
<ScriptListHeading />
```

## Behavior Notes

- The "Add script" button only renders when `onClickAddScript` is provided.
- When GitOps mode is enabled, `GitOpsModeTooltipWrapper` disables the button and surfaces a tooltip explaining why — no additional prop handling required in the parent.
- Styling is scoped via the `script-list-heading` BEM base class.
