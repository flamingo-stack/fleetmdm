Confirmation modal component for canceling a batch script execution in Fleet MDM.

## Key Components

### `ICancelScriptBatchModal` Interface

| Prop | Type | Description |
|------|------|-------------|
| `onExit` | `() => void` | Callback to close/dismiss the modal |
| `onSubmit` | `() => void` | Callback to confirm script batch cancellation |
| `scriptName` | `string` (optional) | Display name of the script being canceled |
| `isCanceling` | `boolean` | Loading state for the confirm button during cancellation |

### `CancelScriptBatchModal`

Default export. Renders a `Modal` with a warning message and two action buttons — **Cancel script** (alert/destructive) and **Back** (inverse-alert). If `scriptName` is provided, it is displayed in bold within the body copy; otherwise falls back to `"this batch"`.

## Usage Example

```typescript
import CancelScriptBatchModal from "components/CancelScriptBatchModal";

<CancelScriptBatchModal
  scriptName="install_agent.sh"
  isCanceling={isCancelingBatch}
  onSubmit={handleCancelBatch}
  onExit={() => setShowCancelModal(false)}
/>
```

## Behavior Notes

- Pressing **Enter** triggers `onSubmit` (via `Modal`'s `onEnter` prop)
- The **Cancel script** button is disabled and shows a loading spinner while `isCanceling` is `true`
- Already-running script executions will complete on the host, but results are suppressed in Fleet
- The action is irreversible; the modal explicitly warns users
