Page component that displays detailed execution results for a script batch run, showing host-level status breakdowns across tabbed views (Ran, Errored, Pending, Incompatible, Canceled).

## Key Components

- **`ScriptBatchDetailsPage`** — Main page component rendered at the script batch details route, accepting `router`, `routeParams`, and `location` props via React Router
- **`EMPTY_STATE_DETAILS`** — Record mapping each `ScriptBatchHostStatus` to a descriptive empty-state message
- **`HOSTS_STATUS_BY_INDEX`** — Ordered array mapping tab index positions to `ScriptBatchHostStatus` values
- **`getEmptyState`** — Helper that renders an `EmptyState` component for a given host status tab with no results

### State & Data Fetching
- Uses `react-query` to fetch `IScriptBatchSummaryV2` via `scriptsAPI.getRunScriptBatchSummaryV2`
- Manages modals for: cancel batch (`CancelScriptBatchModal`), script source viewer (`ScriptDetailsModal`), and per-host execution details (`RunScriptDetailsModal`)
- Syncs tab selection and pagination to URL query params (`status`, `page`, `order_key`, `order_direction`)

### Key Behaviors
- Redirects to the first tab if `status` query param is not a valid `ScriptBatchHostStatus`
- Shows a tooltip on host count when actual loaded records differ from summary count (indicating removed hosts)
- Cancel action hidden when batch `status === "finished"`

## Usage Example

```typescript
// Rendered by React Router at the batch details path
<Route
  path={paths.CONTROLS_SCRIPTS_BATCH_DETAILS(":batch_execution_id")}
  component={ScriptBatchDetailsPage}
/>
```

```typescript
// URL shape consumed by this page
// /controls/scripts/batch/:batch_execution_id?status=errored&page=0&order_key=display_name&order_direction=asc
```
