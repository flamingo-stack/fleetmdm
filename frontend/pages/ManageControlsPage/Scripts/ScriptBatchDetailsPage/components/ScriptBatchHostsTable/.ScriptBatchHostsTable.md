Displays a paginated, sortable table of hosts associated with a script batch execution, fetching results via React Query and supporting row-click navigation to either a host detail page or a script execution result modal.

## Key Components

### `ScriptBatchHostsTable` (default export)
Main component rendering the host results table for a given `batchExecutionId`.

**Props (`IScriptBatchHostsTableProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `batchExecutionId` | `string` | ID of the batch execution to fetch results for |
| `selectedHostStatus` | `ScriptBatchHostStatus` | Current status filter applied to the host list |
| `page` | `number` | Current page index for pagination |
| `orderDirection` | `OrderDirection` | Sort direction (`asc`/`desc`) |
| `orderKey` | `ScriptBatchHostsOrderKey` | Column key used for sorting |
| `setHostScriptExecutionIdForModal` | `(id: string) => void` | Opens the script result modal for an executed host |
| `router` | `InjectedRouter` | React Router instance for navigation |
| `onDataLoaded` | `(recordCount: number) => void` | Optional callback fired with the total record count after data loads |

### Exported Constants

| Constant | Value |
|----------|-------|
| `DEFAULT_SORT_DIRECTION` | `"asc"` |
| `DEFAULT_PAGE_SIZE` | `20` |
| `DEFAULT_SORT_COLUMN` | `"display_name"` |

## Key Behaviors

- **Row click**: If the host status is in `SCRIPT_BATCH_HOST_EXECUTED_STATUSES`, opens the execution result modal; otherwise navigates to the host detail page.
- **Query change**: Uses `router.replace` (not `push`) to update sort/pagination URL params, keeping browser history clean. Resets to page `0` when sort column or direction changes.
- **Error state**: Renders `<DataError>` if the API call fails.
- **Empty state**: Delegated to the parent component via a no-op `emptyComponent`.

## Usage Example

```typescript
<ScriptBatchHostsTable
  batchExecutionId="batch-abc-123"
  selectedHostStatus="ran"
  page={0}
  orderDirection="asc"
  orderKey="display_name"
  setHostScriptExecutionIdForModal={(id) => setModalExecutionId(id)}
  router={router}
  onDataLoaded={(count) => setTotalHosts(count)}
/>
```
