Generates column configurations for the Script Batch Hosts table, dynamically adjusting displayed columns based on whether hosts have executed or not-yet-executed script statuses.

## Key Components

- **`generateColumnConfigs(hostStatus)`** — Default export. Accepts a `ScriptBatchHostStatus` and returns an array of `react-table` column definitions, conditionally including execution-specific columns.
- **`ScriptOutputCell`** — Internal cell renderer displaying a truncated script output preview with a "View script details" hover link.
- **Base column** — `display_name`: renders a linked host name via `LinkCell` pointing to `PATHS.HOST_DETAILS`; shows a "View host details" hover link for not-yet-executed statuses.
- **Executed-only columns** — Appended when `hostStatus` is in `SCRIPT_BATCH_HOST_EXECUTED_STATUSES`:
  - `script_executed_at`: sortable time column using `HumanTimeDiffWithDateTip`.
  - `script_output_preview`: non-sortable column rendering `ScriptOutputCell`.

## Usage Example

```typescript
import generateColumnConfigs from "./ScriptBatchHostsTableConfig";
import { ScriptBatchHostStatus } from "interfaces/script";

// For hosts that have already run the script
const executedColumns = generateColumnConfigs(ScriptBatchHostStatus.ran);

// For hosts pending execution
const pendingColumns = generateColumnConfigs(ScriptBatchHostStatus.pending);

// Pass to a TableContainer
<TableContainer
  columns={executedColumns}
  data={scriptBatchHostResults}
/>
```
