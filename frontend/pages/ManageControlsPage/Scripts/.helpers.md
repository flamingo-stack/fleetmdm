Utility helpers for the script batch run UI, providing display constants and a status-aware timestamp renderer for batch script execution summaries.

## Key Components

### Constants

- **`SCRIPT_UPLOADER_EMPTY_STATE_TEXT`** — JSX fragment for the script uploader empty state, listing supported file types (`.sh`, `.py`, `.ps1`).
- **`SCRIPT_UPLOADER_TEXT`** — Plain string equivalent of the uploader hint text, suitable for non-JSX contexts (e.g., `aria-label`, tooltips).

### Functions

- **`getWhen(summary: IScriptBatchSummaryV2)`** — Returns a JSX element displaying a human-readable relative timestamp and icon for a batch run, based on its current `status`. Returns `null` if the status/timestamp combination is inconsistent.

| Status | Icon | Label |
|---|---|---|
| `started` | `pending-outline` | "Started X ago" |
| `scheduled` | `clock` | "Will start in X" |
| `finished` | `success` or `close-filled` | "Completed X ago" / "Canceled X ago" |

Logs a `console.warn` for each inconsistent state (e.g., a `started` run with no past `started_at`).

## Usage Example

```typescript
import { getWhen } from "./helpers";

const TimeDisplay = ({ summary }: { summary: IScriptBatchSummaryV2 }) => {
  const whenElement = getWhen(summary);

  if (!whenElement) {
    return null; // inconsistent or unrecognized status
  }

  return <div className="batch-run-time">{whenElement}</div>;
};
```
