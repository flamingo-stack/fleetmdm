Renders the OS Settings page for MDM profile management, providing a side-navigated interface for configuring OS settings per team with aggregate profile status tracking.

## Key Components

- **`OSSettings`** – Main page component that orchestrates team-aware MDM profile settings navigation
- **`ProfileStatusAggregate`** – Displays a summary of MDM profile deployment statuses for the current team
- **`SideNav`** – Renders the settings sub-navigation with the active section's card
- **`getOSSettingsNavItems`** – Filters nav items based on whether the current user is a technician
- **`mdmAPI.getProfilesStatusSummary`** – Fetches aggregate profile status data via `react-query`

## Key Behaviors

- **Team ID normalization** – Coerces `undefined` or `-1` team IDs to `0` (`API_NO_TEAM_ID`) for the "No team" case
- **Role-based nav filtering** – Restricts nav items for technician roles (team or global)
- **Invalid section redirect** – Automatically redirects to the default section if the URL `section` param is not found in the filtered nav list
- **Query string preservation** – Appends the original query string to all nav item paths and redirects

## Usage Example

```typescript
// Rendered via React Router — props injected by the router
<OSSettings
  params={{ section: "custom-settings" }}
  router={injectedRouter}
  currentPage={1}
  location={{ search: "?team_id=3" }}
/>
```

## Props

| Prop | Type | Description |
|---|---|---|
| `params` | `Params` | React Router params, expects `section` |
| `router` | `InjectedRouter` | Used for programmatic redirects |
| `currentPage` | `number` | Current pagination page passed to the active card |
| `location.search` | `string` | Query string preserved across navigation |
