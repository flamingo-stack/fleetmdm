Defines and exports the navigation item configuration for the OS Settings section of the Controls page, mapping each settings category to its route and card component.

## Key Components

### `IOSSettingsCommonProps`
Shared prop interface inherited by all OS Settings card components, providing:
- `currentTeamId` — active team context
- `router` — injected router for navigation
- `onMutation` — callback triggered when a setting is changed (e.g., profile uploaded, encryption toggled)

### `getOSSettingsNavItems(isTechnician: boolean)`
Factory function returning a filtered array of `ISideNavItem` entries for the OS Settings side navigation. Excludes **Certificates** and **Passwords** items when the current user is a technician role.

| Item | URL Section | Card Component |
|---|---|---|
| Disk encryption | `disk-encryption` | `DiskEncryption` |
| Configuration profiles | `configuration-profiles` | `ConfigurationProfiles` |
| Certificates | `certificates` | `Certificates` |
| Passwords | `passwords` | `Passwords` |

> Observers and Observer+ roles have no access to the Controls page entirely; the `isTechnician` flag only applies within the page itself.

## Usage Example

```typescript
import getOSSettingsNavItems from "./OSSettingsNavItems";

const navItems = getOSSettingsNavItems(isTechnician);

// Pass to SideNav component
<SideNav
  items={navItems}
  currentTeamId={currentTeamId}
  router={router}
  onMutation={refetchData}
/>
```
