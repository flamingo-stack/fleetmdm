Renders a read-only table displaying the deployment status of a configuration profile across hosts, using memoized column configs and static table data derived from the profile status response.

## Key Components

- **`ConfigProfileStatusTable`** — Default export. A functional component that wraps `TableContainer` to display per-status host counts for a given config profile.
- **`IConfigProfileStatusTableProps`** — Interface defining the component's props:
  - `teamId` — The team context for filtering/linking.
  - `uuid` — The config profile's unique identifier.
  - `profileStatus` — Response payload of type `IGetConfigProfileStatusResponse` containing host status data.
  - `onClickResend` — Callback triggered when a user initiates a resend action, receiving the host count and status string.
- **`generateTableConfig`** — Imported utility that builds memoized column definitions, including resend action handlers.
- **`generateTableData`** — Imported utility that transforms `profileStatus` into table row data.

## Usage Example

```typescript
import ConfigProfileStatusTable from "components/ConfigProfileStatusTable";

<ConfigProfileStatusTable
  teamId={42}
  uuid="abc123-profile-uuid"
  profileStatus={profileStatusResponse}
  onClickResend={(hostCount, status) => {
    console.log(`Resending to ${hostCount} hosts with status: ${status}`);
  }}
/>
```

## Notes

- Column configs are memoized via `useMemo`, recomputing only when `profileStatus`, `teamId`, `uuid`, or `onClickResend` changes.
- Pagination, sorting controls, table header, footer, and count display are all disabled — this is intentionally a compact, static summary table.
- The empty state (`"No host status available"`) is noted as unreachable in practice but is included for `TableContainer` API consistency.
