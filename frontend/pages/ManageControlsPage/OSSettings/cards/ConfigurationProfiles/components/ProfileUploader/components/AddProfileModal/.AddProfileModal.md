Modal component for uploading MDM configuration profiles with support for targeting hosts via labels (premium tier only).

## Key Components

### `FileChooser`
Internal component that renders a file upload UI accepting `.mobileconfig`, `.json`, and `.xml` profile formats. Marked as legacy — should be replaced with the newer `FileUploader` component.

### `FileDetails`
Internal component that displays a preview of the selected file (name and extension) after selection.

### `AddProfileModal` (default export)
The primary modal component that orchestrates the full profile upload flow including file selection, label targeting, and API submission.

**Props:**

| Prop | Type | Description |
|------|------|-------------|
| `currentTeamId` | `number` | ID of the currently selected team |
| `isPremiumTier` | `boolean` | Enables label targeting UI when `true` |
| `onUpload` | `() => void` | Callback fired after successful upload |
| `setShowModal` | `Dispatch<SetStateAction<boolean>>` | Controls modal visibility |

## Key Behaviors

- Fetches custom labels via `labelsAPI.summary()` (only when `isPremiumTier` is `true`)
- Parses the selected file using the shared `parseFile` helper to extract name/extension metadata
- Generates a `labelKey` via `generateCustomTargetLabelKey` combining target type, include/exclude label selections, and include mode (`any`/`all`)
- Submits the profile via `mdmAPI.uploadProfile()`
- "Add profile" button is disabled until a file is selected; also requires at least one label when target type is `"Custom"`

## Usage Example

```typescript
<AddProfileModal
  currentTeamId={42}
  isPremiumTier={true}
  onUpload={() => refetchProfiles()}
  setShowModal={setShowAddProfileModal}
/>
```
