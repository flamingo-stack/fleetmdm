Renders a file configuration profile graphic with optional title and message text, used to visually represent MDM configuration profiles in the Fleet UI.

## Key Components

- **`ProfileGraphic`** – Default export; a presentational React component that wraps the `file-configuration-profile` graphic asset with optional contextual text.
- **`IProfileGraphicProps`** – Interface defining the component's props:
  - `baseClass` – BEM-style base class string for scoped CSS namespacing
  - `title` – Optional `ReactNode` displayed above the message
  - `message` – Optional `ReactNode` displayed below the graphic

## Usage Example

```typescript
import ProfileGraphic from "components/ProfileGraphic";

// Basic usage with a status message
<ProfileGraphic
  baseClass="profile-details"
  title="Configuration Profile"
  message="Profile is pending installation on this host."
/>

// Minimal usage without optional props
<ProfileGraphic baseClass="mdm-section" />
```

## Notes

- Delegates rendering of the actual SVG/image asset to the shared `Graphic` component using the `"file-configuration-profile"` name key.
- Both `title` and `message` are conditionally rendered — neither appears in the DOM if not provided.
- Follows BEM naming: the component appends `__profile-graphic`, `__graphic`, `__profile-graphic--title`, and `__profile-graphic--message` to the provided `baseClass`.
