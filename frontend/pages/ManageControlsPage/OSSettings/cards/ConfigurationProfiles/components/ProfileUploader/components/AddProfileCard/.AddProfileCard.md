A presentational card component that prompts users to upload a configuration profile, with GitOps mode awareness to conditionally disable the action button.

## Key Components

- **`AddProfileCard`** — Default export. A styled `Card` component displaying a profile graphic with upload instructions and an "Add profile" button.
- **`IAddProfileCardProps`** — Interface requiring a `setShowModal` state dispatcher to trigger the upload modal.
- **`GitOpsModeTooltipWrapper`** — Wraps the button to disable it and show a tooltip when GitOps mode is active.
- **`ProfileGraphic`** — Displays an icon with a title and platform-specific format message (`.mobileconfig`/`.json` for Apple platforms, `.json` for Android, `.xml` for Windows).

## Usage Example

```typescript
import AddProfileCard from "components/AddProfileCard";

const ProfilesPage = () => {
  const [showModal, setShowModal] = React.useState(false);

  return (
    <>
      <AddProfileCard setShowModal={setShowModal} />
      {showModal && <UploadProfileModal onClose={() => setShowModal(false)} />}
    </>
  );
};
```

## Notes

- The card is purely presentational — it owns no local state and delegates modal control entirely to the parent via `setShowModal`.
- GitOps mode disables the "Add profile" button automatically; no additional wiring is needed by the consumer.
- Supported profile formats are surfaced inline: `.mobileconfig` and `.json` (macOS/iOS/iPadOS), `.json` (Android), `.xml` (Windows).
