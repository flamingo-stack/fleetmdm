Utility module for parsing configuration profile files and generating user-friendly error messages when uploading MDM configuration profiles fails.

## Key Components

### `IParseFileResult`
Interface describing the result of parsing a configuration profile file, containing `name`, `platform`, and `ext` fields.

### `parseFile(file: File): Promise<IParseFileResult>`
Parses a configuration profile file to determine its target platform based on file extension:
- `.xml` → Windows
- `.mobileconfig` → macOS, iOS, iPadOS
- `.json` → Android or macOS (DDM)
- Any other extension → throws an error

### `DEFAULT_ERROR_MESSAGE`
Fallback error string: `"Couldn't add configuration profile. Please try again."`

### `getErrorMessage(err: AxiosResponse<IApiError>): string | JSX.Element`
Maps API error reasons to user-friendly messages or JSX elements with contextual links. Handles cases including:
- Invalid/empty JSON profiles
- DDM declaration key naming violations
- Restricted settings (BitLocker, FileVault, Windows Update)
- Unsupported Fleet variables
- SCEP certificate authority configuration errors
- Signed configuration profiles
- Generic "Learn more" link extraction from API messages

## Usage Example

```typescript
import { parseFile, getErrorMessage } from "./helpers";

// Parse an uploaded file
const file = new File(["..."], "enrollment.mobileconfig");
const result = await parseFile(file);
// result: { name: "enrollment", platform: "macOS, iOS, iPadOS", ext: "mobileconfig" }

// Handle API errors on upload failure
try {
  await uploadProfile(file);
} catch (err) {
  const message = getErrorMessage(err.response);
  showFlashMessage(message); // may be a string or JSX with a CustomLink
}
```
