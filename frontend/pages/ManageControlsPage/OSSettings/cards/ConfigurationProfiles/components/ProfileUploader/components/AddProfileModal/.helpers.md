Generates a label key object for custom target configurations in Fleet MDM's label-based targeting system.

## Key Components

- **`generateCustomTargetLabelKey`** *(default export)* — Transforms include/exclude label selections into a structured key object used for API payloads or query parameters.
- **`IGenerateCustomTargetLabelKeyArgs`** — Interface defining the function's input shape, containing `targetType`, `includeMode`, `includeLabels`, and `excludeLabels`.

## Behavior

- Returns an empty object `{}` if `targetType` is not `"Custom"`.
- Maps `includeMode` to either `labelsIncludeAll` or `labelsIncludeAny` key depending on whether all or any labels must match.
- Always maps exclusions to the `labelsExcludeAny` key.
- Omits keys entirely when the corresponding label list is empty.

## Usage Example

```typescript
import generateCustomTargetLabelKey from "./helpers";

const labelKey = generateCustomTargetLabelKey({
  targetType: "Custom",
  includeMode: "all",
  includeLabels: { "macOS": true, "Linux": false },
  excludeLabels: { "Servers": true },
});

// Result:
// {
//   labelsIncludeAll: ["macOS"],
//   labelsExcludeAny: ["Servers"],
// }
```
