Unit tests for the `generateCustomTargetLabelKey` helper function, validating label key generation logic for custom target configurations.

## Key Components

- **`generateCustomTargetLabelKey`** — The function under test (imported from `./helpers`), which maps target label selections into a structured key object used for filtering hosts.

## Test Cases

| Scenario | Expected Output |
|---|---|
| Target type is not `"Custom"` | `{}` (empty object) |
| Include mode `"any"` with selected labels | `{ labelsIncludeAny: [...] }` |
| Include mode `"all"` with selected labels | `{ labelsIncludeAll: [...] }` |
| Exclude labels selected | `{ labelsExcludeAny: [...] }` |
| Both include and exclude labels selected | Both keys present |
| Labels present but all `false` | `{}` (omits empty selections) |

## Usage Example

```typescript
generateCustomTargetLabelKey({
  targetType: "Custom",
  includeMode: "all",
  includeLabels: { foo: true },
  excludeLabels: { bar: true },
});
// → { labelsIncludeAll: ["foo"], labelsExcludeAny: ["bar"] }
```

## Notes

- Only labels with a value of `true` are included in the output arrays — `false` values are filtered out.
- Returns an empty object `{}` for any non-`"Custom"` target type, regardless of other inputs.
- The output keys (`labelsIncludeAny`, `labelsIncludeAll`, `labelsExcludeAny`) are mutually exclusive per include direction but can coexist with exclude keys.
