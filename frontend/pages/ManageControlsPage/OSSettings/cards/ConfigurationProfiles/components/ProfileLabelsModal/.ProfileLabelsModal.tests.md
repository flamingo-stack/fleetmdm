Test suite for the `ProfileLabelsModal` component, validating rendering behavior across label assignment modes (`include_any`, `include_all`, `exclude_any`), null profile handling, and broken label warnings.

## Key Components

- **`baseProfile`** — Shared `IMdmProfile` fixture used across tests to avoid repetition
- **`render`** — Custom renderer created via `createCustomRenderer()` for consistent test setup
- **`ProfileLabelsModal`** — The component under test, accepting a `profile` and `setModalData` prop

## Test Cases

| Test | Description |
|------|-------------|
| Profile name in description | Verifies the profile name renders in modal content |
| Null profile | Confirms the modal renders nothing when `profile` is `null` |
| `labels_include_any` | Checks "Include any" section and label names appear |
| `labels_include_all` | Checks "Include all" section renders |
| `labels_exclude_any` | Checks "Exclude any" section renders and include section is absent |
| Both include + exclude | Both sections render simultaneously with correct labels |
| Broken label warning | Warning and "Label deleted" text appear when a label has `broken: true` |
| No broken labels | "Label deleted" text is absent when no labels are broken |

## Usage Example

```typescript
// Running the test suite
import { screen } from "@testing-library/react";

render(
  <ProfileLabelsModal
    profile={{
      ...baseProfile,
      labels_include_any: [{ name: "Label A", broken: true }],
    }}
    setModalData={noop as any}
  />
);

// Verify broken label warning is shown
expect(screen.getByText("Label deleted")).toBeInTheDocument();
```
