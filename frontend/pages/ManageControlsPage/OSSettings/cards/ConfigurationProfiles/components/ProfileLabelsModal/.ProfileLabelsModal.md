Modal component that displays the label-based targeting rules for an MDM configuration profile, showing which host labels are included or excluded and warning when any labels have been deleted.

## Key Components

- **`ProfileLabelsModal`** – Main exported component; renders a modal for a given `IMdmProfile`, displaying its include/exclude label groups.
- **`BrokenLabelWarning`** – Internal banner shown when one or more labels in the profile have been deleted, using `InfoBanner` with a tooltip explanation.
- **`LabelsList`** – Internal scrollable list that renders each `IProfileLabel` as a badge, with a warning icon if the label is broken.

### Props (`IProfileLabelsModalProps`)

| Prop | Type | Description |
|---|---|---|
| `profile` | `IMdmProfile \| null` | The MDM profile whose labels to display; renders `null` if not set. |
| `setModalData` | `React.Dispatch<...>` | Setter to close the modal by clearing the profile state. |

## Usage Example

```typescript
import ProfileLabelsModal from "components/ProfileLabelsModal";
import { IMdmProfile } from "interfaces/mdm";

const [selectedProfile, setSelectedProfile] = useState<IMdmProfile | null>(null);

// Open the modal by setting a profile
<Button onClick={() => setSelectedProfile(profile)}>
  View labels
</Button>

<ProfileLabelsModal
  profile={selectedProfile}
  setModalData={setSelectedProfile}
/>
```

The component handles three label targeting strategies from `IMdmProfile`: `labels_include_all`, `labels_include_any`, and `labels_exclude_any`. It prefers `labels_include_all` over `labels_include_any` when both are present, and renders `null` if no label arrays are populated.
