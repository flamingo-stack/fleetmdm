A confirmation modal component for deleting MDM configuration profiles, displaying a contextual warning message and delete/cancel actions.

## Key Components

### `DeleteProfileModal`
The primary exported React component that renders a modal dialog prompting the user to confirm deletion of a configuration profile.

**Props (`DeleteProfileModalProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `profileName` | `string` | Display name of the profile being deleted |
| `profileId` | `string` | Unique identifier passed to the `onDelete` callback |
| `onCancel` | `() => void` | Handler for dismissing the modal |
| `onDelete` | `(profileId: string) => void` | Handler invoked with the profile ID on confirmation |
| `isDeleting` | `boolean` | Shows a loading spinner on the Delete button during async deletion |

### `generateMessageSuffix`
Internal helper that customizes the warning message based on tier and team context:
- **Free tier:** no suffix appended
- **Premium, team context:** appends `"assigned to this fleet"`
- **Premium, no team (unassigned):** appends `"that are unassigned"`

## Usage Example

```typescript
<DeleteProfileModal
  profileName="macOS Security Baseline"
  profileId="profile-abc-123"
  onCancel={() => setShowDeleteModal(false)}
  onDelete={(id) => handleDeleteProfile(id)}
  isDeleting={isDeletingProfile}
/>
```

## Notes
- Supports keyboard confirmation via `onEnter` (Enter key triggers delete).
- Reads `isPremiumTier` and `currentTeam` from [`AppContext`](https://github.com/flamingo-stack/fleetmdm/blob/main/context/app.tsx) to tailor the warning message for multi-team Premium deployments.
