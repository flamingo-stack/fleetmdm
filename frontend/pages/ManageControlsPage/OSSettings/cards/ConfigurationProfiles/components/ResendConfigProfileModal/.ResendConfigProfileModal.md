Modal component for confirming and triggering a batch resend of a configuration profile to all affected hosts.

## Key Components

- **`ResendConfigProfileModal`** — Default export. A confirmation modal that calls `configProfilesAPI.batchResendConfigProfile` with the profile UUID, displays success/error flash notifications, and blocks re-submission while the request is in-flight.
- **`IResendConfigProfileModalProps`** — Props interface:
  - `name` — Display name of the configuration profile.
  - `uuid` — Unique identifier used to target the batch resend API call.
  - `count` — Number of hosts that will receive the profile (used for pluralized display text).
  - `onExit` — Callback invoked on success or when the user cancels.

## Usage Example

```typescript
import ResendConfigProfileModal from "./ResendConfigProfileModal";

const MyPage = () => {
  const [showModal, setShowModal] = React.useState(false);

  return (
    <>
      {showModal && (
        <ResendConfigProfileModal
          name="CIS Benchmark"
          uuid="abc-123-def-456"
          count={42}
          onExit={() => setShowModal(false)}
        />
      )}
    </>
  );
};
```

## Behavior Notes

- The **Resend** button shows a loading state (`isLoading`) and is disabled while the API call is pending, preventing duplicate submissions.
- On success, a flash notification references the profile `name` inline and `onExit` is called automatically.
- On failure, a generic error flash is shown and the modal remains open for retry.
