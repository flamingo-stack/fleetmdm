Renders a single MDM configuration profile entry in a list, displaying profile metadata and providing action buttons for info, label filtering, download, and deletion.

## Key Components

- **`ProfileListItem`** — Main exported component displaying a profile row with name, platform, upload date, label count, and action controls
- **`ProfileDetails`** — Internal sub-component rendering the platform name and relative upload timestamp
- **`LabelCount`** — Internal sub-component showing the number of associated labels with a filter icon
- **`createProfileExtension`** — Helper that returns the correct file extension (`json`, `mobileconfig`, or `xml`) based on profile type/platform
- **`createFileContent`** — Async helper that fetches and formats profile content for download via `mdmAPI.downloadProfile`

## Key Behaviors

- **Platform display**: Maps `windows`, `android`, `linux`, and Apple platforms (with optional DDM declaration suffix) to human-readable strings
- **Download**: Generates a date-prefixed filename and triggers a browser file save using `file-saver`
- **Label warnings**: Shows a warning icon if any associated label is `broken`
- **Technician mode**: Hides the delete button when `isTechnician` is `true`
- **GitOps mode**: Wraps the delete button in `GitOpsModeTooltipWrapper` to disable it when GitOps mode is active

## Usage Example

```typescript
<ProfileListItem
  isPremium={true}
  profile={mdmProfile}
  onClickInfo={(profile) => openInfoModal(profile)}
  onClickDelete={(profile) => handleDelete(profile)}
  setProfileLabelsModalData={setLabelsModal}
  isTechnician={false}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `isPremium` | `boolean` | Enables label display and filter button |
| `profile` | `IMdmProfile` | The MDM profile data object |
| `onClickInfo` | `(profile: IMdmProfile) => void` | Info button handler |
| `onClickDelete` | `(profile: IMdmProfile) => void` | Delete button handler |
| `setProfileLabelsModalData` | `Dispatch` | Opens the labels modal |
| `isTechnician` | `boolean?` | Hides delete action when `true` |
