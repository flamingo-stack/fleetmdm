Test suite for the `ConfigProfileStatusModal` component, verifying correct host count rendering per deployment status and conditional display of the resend action on hover.

## Key Components

- **`defaultConfigProfileStatusHandler`** – MSW mock handler providing stubbed API responses for profile status data
- **`createCustomRenderer`** – Custom render utility with backend mock support (`withBackendMock: true`)
- **`ConfigProfileStatusModal`** – Component under test, accepting `name`, `uuid`, `teamId`, `onClickResend`, and `onExit` props

## Test Cases

### `renders the correct number of hosts for each status`
Mounts the modal with a mocked profile UUID (`123-abc`) and asserts each status row in the table displays the expected host count:

| Status | Expected Count |
|---|---|
| Verified | `---` |
| Verifying | `1` |
| Pending | `2` |
| Failed | `3` |

### `shows the resend button for a failed row on hover`
Simulates a hover interaction on the `Failed` row and asserts the `Resend` button becomes visible.

## Usage Example

```typescript
import { defaultConfigProfileStatusHandler } from "test/handlers/config-profiles";
import mockServer from "test/mock-server";

mockServer.use(defaultConfigProfileStatusHandler);

render(
  <ConfigProfileStatusModal
    name="My Profile"
    uuid="abc-123"
    teamId={1}
    onClickResend={() => console.log("resend clicked")}
    onExit={() => console.log("modal closed")}
  />
);
```
