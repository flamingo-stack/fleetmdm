A modal component that fetches and displays the deployment status of a configuration profile, showing a breakdown table of host statuses with an option to resend the profile.

## Key Components

### `ConfigProfileStatusModal`
The default export — a React modal that:
- Fetches profile status data via `configProfileAPI.getConfigProfileStatus(uuid)` using `react-query`
- Renders a loading spinner, error state, or `ConfigProfileStatusTable` based on query state
- Passes `onClickResend` with a host count to the parent for resend actions

### Props (`IConfigProfileStatusModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Profile name shown as modal title |
| `uuid` | `string` | Unique profile identifier used for the API call and query key |
| `teamId` | `number` | Team scope for filtering host status |
| `onClickResend` | `(hostCount: number) => void` | Callback triggered when resending the profile |
| `onExit` | `() => void` | Callback to close the modal |

## Usage Example

```typescript
<ConfigProfileStatusModal
  name="CIS Benchmark - macOS"
  uuid="abc-123-def-456"
  teamId={7}
  onClickResend={(hostCount) => {
    console.log(`Resending to ${hostCount} hosts`);
  }}
  onExit={() => setShowStatusModal(false)}
/>
```

## Notes

- Query key is `["config-profile-status", uuid]` — cache is scoped per profile UUID
- Uses `DEFAULT_USE_QUERY_OPTIONS` for consistent query behavior across the app
