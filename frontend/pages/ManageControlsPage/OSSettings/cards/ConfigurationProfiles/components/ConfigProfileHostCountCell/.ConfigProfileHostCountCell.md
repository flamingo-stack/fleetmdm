A React table cell component that displays the host count for a configuration profile status, with an optional "Resend" button for failed non-DDM profiles.

## Key Components

### `ConfigProfileHostCountCell`
Default export. Renders a count value as either a linked number (navigating to filtered hosts) or an empty cell placeholder, alongside a conditional resend action button.

### `IConfigProfileHostCountCellProps`
| Prop | Type | Description |
|------|------|-------------|
| `teamId` | `number` | Fleet team ID used in the host filter query |
| `uuid` | `string` | Profile UUID; a `"d"` prefix indicates a DDM profile |
| `status` | `string` | Profile status (e.g., `"failed"`) |
| `count` | `number` | Number of hosts matching this profile/status |
| `onClickResend` | `() => void` | Callback triggered when the Resend button is clicked |

### Internal Helpers
- **`renderCount()`** — Returns `DEFAULT_EMPTY_CELL_VALUE` when count is `0`, otherwise a `CustomLink` to the filtered hosts page.
- **`renderResendButton()`** — Returns a resend `Button` only when `count > 0`, the profile is not a DDM profile (uuid does not start with `"d"`), and `status === "failed"`.

## Usage Example

```typescript
<ConfigProfileHostCountCell
  teamId={3}
  uuid="a1b2c3d4-profile-uuid"
  status="failed"
  count={12}
  onClickResend={() => handleResend(profileUuid)}
/>
```

## Notes

- DDM profiles (uuid prefixed with `"d"`) never show the Resend button, regardless of status or count.
- The generated host link filters by `fleet_id`, `profile_uuid`, and `profile_status` via query string.
