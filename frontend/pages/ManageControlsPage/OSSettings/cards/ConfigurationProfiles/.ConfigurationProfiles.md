Manages the display, upload, deletion, and status tracking of MDM configuration profiles within the Fleet Controls settings page, supporting paginated browsing and label-based filtering.

## Key Components

- **`ConfigurationProfiles`** — Main component that renders the configuration profiles list with full CRUD-adjacent operations (upload, delete, view status, resend)
- **`PROFILES_PER_PAGE`** — Constant controlling pagination (10 profiles per page)
- **`IConfigurationProfilesProps`** — Extends `IOSSettingsCommonProps` with an optional `currentPage` prop

### Modal States Managed
| Modal | Trigger |
|---|---|
| `AddProfileModal` | Upload a new configuration profile |
| `DeleteProfileModal` | Confirm profile deletion |
| `ProfileLabelsModal` | View include/exclude label assignments (Premium) |
| `ConfigProfileStatusModal` | View per-profile host deployment status |
| `ResendConfigProfileModal` | Re-push profile to failed/pending hosts |

## Usage Example

```typescript
import ConfigurationProfiles from "./ConfigurationProfiles";

<ConfigurationProfiles
  currentTeamId={1}
  router={router}
  currentPage={0}
  onMutation={() => refetchParentData()}
/>
```

## Behavior Notes

- Renders an **MDM-disabled** empty state with a "Turn on" CTA when MDM is not configured
- Technicians (global or team) see a read-only view — upload/add actions are hidden
- Pagination uses URL query params (`?fleet_id=<id>&page=<n>`) via `router.push`
- Profile data is fetched via `react-query` using `mdmAPI.getProfiles`, keyed by `team_id`, `page`, and `per_page`
- `ProfileLabelsModal` only renders for Premium tier users when the selected profile has label assignments
