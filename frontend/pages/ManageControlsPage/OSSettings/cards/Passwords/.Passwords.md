Renders the Passwords settings panel within OS Settings, allowing admins to enable or disable the macOS Recovery Lock password for a specific team or globally (no-team context).

## Key Components

- **`Passwords`** — Default export. React functional component accepting `IOSSettingsCommonProps` (`currentTeamId`, `router`, `onMutation`).
- **`RECOVERY_LOCK_TOOLTIP_CONTENT`** — JSX constant providing tooltip text and a learn-more link for the Recovery Lock feature.
- **`onUpdateRecoveryLockPassword`** — Async handler that persists the toggle state via `configAPI.update` (no-team) or `teamsAPI.updateConfig` (team-scoped), then calls `onMutation` on success.

### Rendering Logic

| Condition | Rendered Output |
|---|---|
| Non-premium tier | `PremiumFeatureMessage` |
| Premium + MDM status unknown | `Spinner` |
| Premium + MDM disabled | `EmptyState` with "Turn on" MDM button |
| Premium + MDM enabled + loading | `Spinner` |
| Premium + MDM enabled + technician role | Nothing (form hidden) |
| Premium + MDM enabled + admin | Recovery Lock checkbox form |

## Usage Example

```typescript
import Passwords from "./Passwords";

// Used inside OS Settings routing — receives props from IOSSettingsCommonProps
<Passwords
  currentTeamId={selectedTeamId}   // API_NO_TEAM_ID for global config
  router={reactRouterInstance}
  onMutation={() => refetchSettings()}
/>
```

The checkbox is disabled when GitOps mode is active (via `GitOpsModeTooltipWrapper`) or when the form state is not yet ready. State is seeded from team config via `react-query` or from global `AppContext` config when `currentTeamId === API_NO_TEAM_ID`.
