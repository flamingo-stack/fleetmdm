Manages the disk encryption settings page for Fleet MDM, allowing administrators to enable/disable disk encryption enforcement and configure BitLocker PIN requirements across macOS, Windows, and Linux hosts.

## Key Components

- **`DiskEncryption`** — Main page component that renders disk encryption controls for a given team or global config
- **`onUpdateDiskEncryption`** — Async handler that persists encryption settings via `diskEncryptionAPI` and refreshes app config
- **`onToggleDiskEncryption`** / **`onToggleRequireBitLockerPIN`** — Checkbox state handlers for enabling encryption and BitLocker PIN
- **`getTipContent`** — Returns platform-specific tooltip content explaining MDM prerequisites for `macOS`, `windows`, and `linux`
- **`DiskEncryptionTable`** — Sub-component rendered when encryption is active, displaying per-host encryption status
- **`GitOpsModeTooltipWrapper`** — Wraps the Save button to disable it when GitOps mode is active

## Usage Example

```typescript
import DiskEncryption from "./DiskEncryption";

// Rendered inside the OS Settings page for a specific team
<DiskEncryption
  currentTeamId={3}           // 0 for global (no-team) config
  onMutation={() => refetch()} // called after successful save
  router={router}
/>
```

## Behavior Notes

- **Premium-gated**: Renders a `PremiumFeatureMessage` for non-premium tiers
- **Role-based rendering**: Technicians (`isTeamTechnician` / `isGlobalTechnician`) see a read-only aggregate table; admins see the editable form
- **Team vs. global config**: When `currentTeamId === 0`, settings are read from and written back to global app config via `configAPI`
- **Error handling**: Detects the `"Missing required private key"` error and surfaces a contextual link to Fleet's private key documentation
