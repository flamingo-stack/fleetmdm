Renders a table displaying disk encryption status summaries, fetching data via the disk encryption API and navigating to filtered host views on row selection.

## Key Components

- **`DiskEncryptionTable`** – Main functional component that displays disk encryption status data in a paginated-free, clickable table.
- **`IDiskEncryptionTableProps`** – Props interface accepting an optional `currentTeamId` and a required `router` instance.
- **`IDiskEncryptionRowProps`** – Extends `react-table`'s `Row` with typed `original` fields (`id`, `status`, `teamId`).
- **`useQuery`** – Fetches disk encryption summary data keyed by `["disk-encryption-summary", currentTeamId]` with no retry or window-focus refetch.
- **`onSelectSingleRow`** – Navigates to `PATHS.MANAGE_HOSTS` with `DISK_ENCRYPTION` and `fleet_id` query params derived from the selected row.
- **`generateTableHeaders` / `generateTableData`** – Imported from `DiskEncryptionTableConfig` to construct column configs and row data.

## Usage Example

```typescript
import DiskEncryptionTable from "components/DiskEncryptionTable";
import { useRouter } from "react-router";

const MyPage = () => {
  const router = useRouter();

  return (
    <DiskEncryptionTable
      currentTeamId={42}
      router={router}
    />
  );
};
```

## Behavior Notes

- Renders `<DataError />` if the API call fails.
- Returns `null` while data is loading (no loading spinner).
- Clicking any row redirects to the host management page filtered by that row's encryption status and team.
- Displays an `<EmptyState />` when no status data is returned by the API.
