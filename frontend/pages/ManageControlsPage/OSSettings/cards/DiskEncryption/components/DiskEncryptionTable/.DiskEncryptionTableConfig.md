Defines the column configuration and data transformation logic for the disk encryption summary table, mapping MDM encryption statuses to display-ready row data with status indicators and per-platform host counts.

## Key Components

- **`IStatusCellValue`** – Interface describing a status cell's display name, indicator variant, underlying enum value, and optional tooltip content.
- **`generateTableHeaders()`** – Returns the static column definitions: Status (with `StatusIndicatorWithIcon`), macOS hosts, Windows hosts, Linux hosts, and a "view all hosts" link column.
- **`STATUS_CELL_VALUES`** – Record mapping each `DiskEncryptionStatus` enum value (`verified`, `verifying`, `action_required`, `enforcing`, `failed`, `removing_enforcement`) to its corresponding `IStatusCellValue` display configuration, including tooltip copy.
- **`STATUS_ORDER`** – Constant tuple enforcing a fixed row ordering in the rendered table.
- **`generateTableData()`** – Transforms an `IDiskEncryptionSummaryResponse` API payload into table rows ordered by `STATUS_ORDER`, attaching the resolved `IStatusCellValue` and per-platform counts.

## Usage Example

```typescript
import {
  generateTableHeaders,
  generateTableData,
} from "./DiskEncryptionTableConfig";

// Build column definitions
const columns = generateTableHeaders();

// Transform API response into table rows
const rows = generateTableData(diskEncryptionSummaryResponse, currentTeamId);

// Pass to your table component
<TableContainer
  columns={columns}
  data={rows}
/>
```

## Notes

- All columns set `disableSortBy: true` — the table is display-only with a fixed row order.
- The `action_required` tooltip renders JSX (bold inline elements) rather than a plain string.
- The `linkToFilteredHosts` column renders `ViewAllHostsLink` with `noLink` to support row-hover state only; actual navigation is handled upstream.
