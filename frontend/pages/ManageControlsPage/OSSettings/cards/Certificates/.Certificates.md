Manages the Certificates section of the OS Settings Controls page, handling listing, adding, and deleting certificates for Android MDM deployments with pagination support.

## Key Components

- **`Certificates`** — Main React component that renders the certificate management UI
- **`ICertificatesProps`** — Extends `IOSSettingsCommonProps` with an optional `currentPage` prop
- **`renderContent()`** — Internal function that conditionally renders based on premium tier status, Android MDM configuration, loading/error states, and certificate list presence
- **`useQuery`** — Fetches paginated certificates via `certAPI.getCerts`, scoped by team ID and page number (10 per page)
- **Pagination** — URL-driven pagination using `router.push` with `fleet_id` and `page` query params
- **`AddCertModal`** / **`DeleteCertModal`** — Modals for certificate CRUD operations, triggered by local state
- **`AddCertCard`** — Empty state card shown when no certificates exist
- **`GitOpsModeTooltipWrapper`** — Wraps the delete button to disable it in GitOps mode

## Usage Example

```typescript
import Certificates from "./Certificates";

// Within a route/page component
<Certificates
  currentTeamId={selectedTeamId}
  router={router}
  currentPage={Number(queryParams.page) || 0}
  onMutation={() => refetchParentData()}
/>
```

## Behavior Notes

- Renders `<PremiumFeatureMessage />` for non-premium tiers
- Requires Android MDM to be enabled; otherwise shows a prompt to navigate to MDM settings
- Certificate list displays name, CA name, and relative creation time (e.g., "Added 3 days ago")
- Pagination only renders when there are multiple pages of results
