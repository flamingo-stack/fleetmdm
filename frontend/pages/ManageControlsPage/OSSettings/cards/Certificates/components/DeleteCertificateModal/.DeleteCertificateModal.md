A confirmation modal component for deleting a certificate from Fleet, handling the async delete operation with loading states and success/error flash notifications.

## Key Components

- **`DeleteCertificateModal`** — Default export. Renders a modal dialog prompting the user to confirm deletion of a certificate.
- **`IDeleteCertModalProps`** — Interface defining required props:
  - `cert: ICertificate` — The certificate to delete (uses `name` for display, `id` for API call)
  - `onSuccess: () => void` — Callback invoked after a successful deletion
  - `onExit: () => void` — Callback invoked to close the modal (on cancel or after success)

## Usage Example

```typescript
import DeleteCertificateModal from "components/DeleteCertificateModal";

<DeleteCertificateModal
  cert={selectedCert}
  onSuccess={() => refetchCertificates()}
  onExit={() => setShowDeleteModal(false)}
/>
```

## Behavior

1. Displays the certificate `name` in the confirmation message.
2. On **Delete** click, calls `certAPI.deleteCert(id)` and sets a loading state on the button.
3. On success: renders a success flash, calls `onSuccess()`, then `onExit()`.
4. On failure: renders an error flash and re-enables the button.
5. **Cancel** dismisses the modal immediately via `onExit()`.
