Test suite for the `AddCertificateModal` component, verifying form validation, API submission behavior, error handling, and UI state management for adding MDM certificates.

## Key Components

- **`renderModal`** — Helper that mounts `AddCertModal` with a backend mock and waits for the form to be interactive
- **`selectScepCa`** — Helper that opens the CA dropdown and selects the mocked `TEST_SCEP_CA` option
- **`getCAsHandler`** — MSW handler mocking `GET /certificate_authorities` with a single custom SCEP CA
- **`addCertHandler`** — MSW handler mocking `POST /certificates`, capturing every call body into `addCertCalls` for assertion
- **`addCertCalls`** — Shared array accumulating POST request bodies across test cases

## Test Coverage

| Scenario | Assertion |
|---|---|
| SAN field renders | Field and placeholder are present |
| All required fields empty | Three inline errors shown, no API call |
| Only subject name empty | Exactly one error shown |
| Invalid name characters | Inline error on keystroke (no submit) |
| Name exceeds 255 chars | Inline error on paste |
| Submit without SAN | Success callback fired; `subject_alternative_name` absent from body |
| Submit with SAN | Success callback fired; SAN value present in body |
| 422 server error on SAN | Error surfaced inline; cleared on edit |
| Add button disabled in-flight | Button disabled while POST is pending, re-enabled on response |
| Cancel button | `onExit` callback called once |

## Usage Example

```typescript
// Run the full suite
npx jest AddCertificateModal.tests.tsx

// Inspect a specific case
it("submits successfully with SAN", async () => {
  const { user } = await renderModal();
  await user.type(screen.getByPlaceholderText(NAME_PLACEHOLDER), "My Cert");
  await user.type(screen.getByPlaceholderText(SUBJECT_NAME_PLACEHOLDER), "/CN=test");
  await user.type(screen.getByPlaceholderText(SAN_PLACEHOLDER), "DNS=host.example.com");
  await selectScepCa(user);
  await user.click(screen.getByRole("button", { name: /Add/i }));
  await waitFor(() => expect(mockOnSuccess).toHaveBeenCalledTimes(1));
});
```
