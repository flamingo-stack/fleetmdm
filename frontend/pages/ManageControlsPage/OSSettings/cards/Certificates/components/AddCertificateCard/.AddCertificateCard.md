A presentational card component that prompts users to add a certificate for corporate network connectivity, featuring a GitOps-mode-aware action button.

## Key Components

- **`AddCertCard`** – Default export. A card UI component that displays an "Add certificate" prompt with a button to trigger a modal. Wraps the action button in `GitOpsModeTooltipWrapper` to disable interaction when GitOps mode is active.
- **`IAddCertCardProps`** – Interface requiring a `setShowModal` state dispatcher to control modal visibility.

## Usage Example

```typescript
import AddCertCard from "components/AddCertificateCard";

const CertificatesPage = () => {
  const [showModal, setShowModal] = React.useState(false);

  return (
    <>
      <AddCertCard setShowModal={setShowModal} />
      {showModal && <AddCertificateModal onClose={() => setShowModal(false)} />}
    </>
  );
};
```

## Notes

- The "Add" button is automatically disabled when GitOps mode is enabled, with a tooltip surfaced via `GitOpsModeTooltipWrapper`.
- Styling is scoped under the `add-cert-card` BEM base class.
- The component is purely presentational — modal rendering and certificate logic are handled by the parent.
