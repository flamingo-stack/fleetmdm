Displays an aggregate summary of MDM profile statuses across hosts, rendering clickable status cards that link to filtered host views.

## Key Components

### `ProfileStatusCount`
Internal component that renders a single status indicator with host count, using `StatusIndicatorWithIcon` in vertical layout with tooltip support.

**Props:**
- `statusIcon` — `IndicatorStatus` icon variant
- `title` — display label for the status
- `hostCount` — number of hosts in this status
- `tooltipText` — JSX tooltip content

### `ProfileStatusAggregate` (default export)
Parent component that maps over `AGGREGATE_STATUS_DISPLAY_OPTIONS` to render a card per profile status. Handles loading, error, and empty states.

**Props:**
- `isLoading` — shows a `Spinner` while data is fetching
- `isError` — renders a `DataError` fallback on failure
- `teamId` — used to scope host filter links via `fleet_id`
- `aggregateProfileStatusData` — `ProfileStatusSummaryResponse` containing counts per status key

Each card links to `MANAGE_HOSTS` with `OS_SETTINGS` and `fleet_id` query params pre-applied, enabling one-click navigation to the filtered host list.

## Usage Example

```typescript
import ProfileStatusAggregate from "./ProfileStatusAggregate";

<ProfileStatusAggregate
  isLoading={isFetching}
  isError={isError}
  teamId={currentTeamId}
  aggregateProfileStatusData={profileStatusSummary}
/>
```

## Notes
- Status display options (labels, icons, tooltip text) are driven by `AGGREGATE_STATUS_DISPLAY_OPTIONS` — extend that file to add or modify status entries without touching this component.
