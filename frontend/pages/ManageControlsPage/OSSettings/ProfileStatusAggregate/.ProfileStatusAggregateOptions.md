Defines the display configuration for MDM profile status aggregate options, mapping each `MdmProfileStatus` value to its corresponding label, icon, and tooltip text for UI rendering.

## Key Components

- **`IAggregateDisplayOption`** — Interface defining the shape of each status display option, containing:
  - `value`: The `MdmProfileStatus` enum value
  - `text`: Human-readable label
  - `iconName`: `IndicatorStatus` icon variant
  - `tooltipText`: JSX tooltip content

- **`AGGREGATE_STATUS_DISPLAY_OPTIONS`** — Array of four display configurations for statuses:
  - `verified` — Hosts with all OS settings confirmed by Fleet
  - `verifying` — Hosts that acknowledged MDM commands; Fleet is confirming
  - `pending` — Hosts scheduled to apply the latest OS settings
  - `failed` — Hosts that encountered errors applying OS settings

## Usage Example

```typescript
import AGGREGATE_STATUS_DISPLAY_OPTIONS from "./ProfileStatusAggregateOptions";

const MyStatusList = () => (
  <ul>
    {AGGREGATE_STATUS_DISPLAY_OPTIONS.map(({ value, text, iconName, tooltipText }) => (
      <li key={value}>
        <StatusIndicatorWithIcon status={iconName} value={text} tooltip={{ tooltipText }} />
      </li>
    ))}
  </ul>
);
```
