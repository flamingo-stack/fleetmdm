Utility helper for extracting and formatting error messages from OS update API responses.

## Key Components

### `getErrorMessage(err: AxiosResponse<IApiError>): string`

Parses an Axios error response and returns a human-readable error message. If the API error reason contains a specific OS update settings failure message, the original reason is returned verbatim; otherwise, a generic fallback message is returned.

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await updateOsSettings(payload);
} catch (err) {
  const message = getErrorMessage(err);
  console.error(message);
  // → "Couldn't update os updates settings" (if API-specific)
  // → "Couldn't update. Please try again."  (fallback)
}
```

## Notes

- Relies on `IApiError` from [`interfaces/errors`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/errors.ts) for response shape (`data.errors[0].reason`).
- Case-insensitive matching is applied via `.toLowerCase()` before the check, but the **original casing** of the reason is preserved in the returned string.
- Designed specifically for the OS update settings flow; expand the conditional logic to handle additional API-specific error cases.
