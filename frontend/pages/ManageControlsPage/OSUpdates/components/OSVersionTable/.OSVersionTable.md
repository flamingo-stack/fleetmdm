Renders a paginated, sortable table of operating system versions within the Fleet MDM OS Updates controls section, syncing sort and pagination state to URL query parameters via router replacement.

## Key Components

- **`OSVersionTable`** – Default export; the main component that wraps `TableContainer` with OS version data and routing logic
- **`determineQueryParamChange`** – Identifies which query parameter (sort direction, sort header, or page index) changed between renders to enable selective page reset
- **`generateNewQueryParams`** – Constructs the next URL query parameter object, resetting `page` to `0` when any non-pagination param changes
- **`onQueryChange`** – Callback passed to `TableContainer`; skips navigation on initial render (when no param has changed), otherwise pushes a new route via `router.replace`
- **`generateTableHeaders`** – Imported config function that builds column definitions scoped to the current team

## Usage Example

```typescript
import OSVersionTable from "./OSVersionTable";
import { parseOSUpdatesCurrentVersionsQueryParams } from "../CurrentVersionSection/CurrentVersionSection";

const queryParams = parseOSUpdatesCurrentVersionsQueryParams(location.query);

<OSVersionTable
  router={router}
  osVersionData={osVersions}
  currentTeamId={currentTeamId}
  isLoading={isLoading}
  queryParams={queryParams}
  hasNextPage={hasNextPage}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `router` | `InjectedRouter` | React Router instance for URL navigation |
| `osVersionData` | `IOperatingSystemVersion[]` | Array of OS version records to display |
| `currentTeamId` | `number` | Active team ID; passed to column config and query params |
| `isLoading` | `boolean` | Toggles loading state on the table |
| `queryParams` | Parsed query params | Controls default sort, direction, and page |
| `hasNextPage` | `boolean` | Disables next-page navigation and hides footer when `false` |
