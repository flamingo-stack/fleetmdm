Defines and exports the table column configuration for the OS version table in the Fleet MDM dashboard.

## Key Components

### `generateTableHeaders(teamId: number)`
Returns an array of column definitions for `react-table`, configuring four columns:

| Column | Description |
|--------|-------------|
| **OS type** | Renders platform icon and OS name via `OSTypeCell` |
| **Version** | Plain text display of the OS version string |
| **Hosts** | Sortable host count using `TextCell` with a `HeaderCell` sort indicator |
| **Link** | Row-level `ViewAllHostsLink` filtered by `os_name`, `os_version`, and `fleet_id` |

## Usage Example

```typescript
import { generateTableHeaders } from "./OSVersionTableConfig";

const teamId = 42;
const columns = generateTableHeaders(teamId);

// Pass to TableContainer or react-table instance
<TableContainer
  columns={columns}
  data={osVersions}
/>
```

## Notes

- `teamId` is injected into the `ViewAllHostsLink` query params as `fleet_id`, scoping host links to the correct team context.
- Sorting is disabled on all columns except **Hosts** (`hosts_count`).
- The link column has no header label — it renders only on row hover (`rowHover` prop).
