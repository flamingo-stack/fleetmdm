Renders a platform-specific preview panel showing the end user experience for OS update requirements, combining a descriptive text block with a screenshot for macOS, Windows, iOS, and iPadOS.

## Key Components

- **`EndUserOSRequirementPreview`** — Default export. Root component that composes the description and screenshot sub-components for the given platform.
- **`OSRequirementDescription`** — Internal component that renders platform-specific explanatory text and a "Learn more" link. Returns an empty fragment for unsupported platforms.
- **`OSRequirementImage`** — Internal component that selects and renders the correct screenshot asset based on the platform prop.
- **`IEndUserOSRequirementPreviewProps`** — Interface requiring a single `platform` prop typed as `OSUpdatesSupportedPlatform` (`"darwin" | "windows" | "ios" | "ipados"`).

## Usage Example

```typescript
import EndUserOSRequirementPreview from "./EndUserOSRequirementPreview";

// Render the macOS update end-user experience preview
<EndUserOSRequirementPreview platform="darwin" />

// Render the Windows update end-user experience preview
<EndUserOSRequirementPreview platform="windows" />
```

## Notes

- Supported platforms: `"darwin"` (macOS DDM nudge), `"windows"` (deferrable restart flow), `"ios"`, and `"ipados"` (header only, no description body).
- There is a known rendering issue (marked `FIXME`) where on slow connections the screenshot may load after the text, potentially causing a visual mismatch when switching between platforms.
