Renders the OS update target configuration section, determining which platform-specific form(s) to display based on MDM enrollment status and extracting default values from app or team config.

## Key Components

### Helper Functions

| Function | Purpose |
|---|---|
| `getDefaultUpdateNewHosts` | Resolves the `update_new_hosts` flag for a given Apple platform (`darwin`, `ios`, `ipados`) |
| `getDefaultOSVersion` | Resolves the minimum OS version string for a given Apple platform |
| `getDefaultDeadline` | Resolves the update deadline string for a given Apple platform |
| `getDefaultWindowsDeadlineDays` | Resolves Windows update deadline days from app or team config |
| `getDefaultWindowsGracePeriodDays` | Resolves Windows grace period days from app or team config |

All helpers select between `appConfig.mdm` and `teamConfig.mdm` based on whether `currentTeamId` equals `API_NO_TEAM_ID`.

### Component: `TargetSection`

Renders either a standalone `WindowsTargetForm` (when only Windows MDM is enabled) or a `PlatformTabs` component (for multi-platform or Apple/Android scenarios). Shows a `Spinner` while config data is loading.

### Interface: `ITargetSectionProps`

| Prop | Type | Description |
|---|---|---|
| `appConfig` | `IConfig` | Global Fleet app configuration |
| `currentTeamId` | `number` | Active team ID (`API_NO_TEAM_ID` for no-team context) |
| `isFetching` | `boolean` | Loading state; renders spinner when `true` |
| `selectedPlatform` | `OSUpdatesTargetPlatform` | Currently active platform tab |
| `teamConfig` | `ITeamConfig` (optional) | Team-specific MDM configuration |
| `onSelectPlatform` | `function` | Callback when platform tab changes |
| `refetchAppConfig` | `function` | Triggers app config reload after save |
| `refetchTeamConfig` | `function` | Triggers team config reload after save |

## Usage Example

```typescript
<TargetSection
  appConfig={appConfig}
  currentTeamId={currentTeamId}
  isFetching={isFetchingConfig}
  selectedPlatform={selectedPlatform}
  teamConfig={teamConfig}
  onSelectPlatform={(platform) => setSelectedPlatform(platform)}
  refetchAppConfig={refetchAppConfig}
  refetchTeamConfig={refetchTeamConfig}
/>
```
