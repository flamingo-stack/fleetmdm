A React functional component that renders an empty state UI for the OS Versions report when no operating system versions have been detected.

## Key Components

- **`OSVersionsEmptyState`** — Default export; a stateless component that wraps the shared `EmptyState` component with OS-specific messaging.

## Usage Example

```typescript
import OSVersionsEmptyState from "components/OSVersionsEmptyState";

const OSVersionsTable = ({ data }) => {
  if (!data.length) {
    return <OSVersionsEmptyState />;
  }
  return <Table data={data} />;
};
```

## Notes

- Accepts no props; messaging is hardcoded.
- Informs users that the report refreshes hourly to avoid performance impact on managed devices.
- Delegates all visual rendering to the shared `EmptyState` component.
