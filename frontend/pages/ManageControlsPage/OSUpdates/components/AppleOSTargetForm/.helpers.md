Utility helper for parsing and formatting API error messages returned from OS update settings API calls.

## Key Components

### `getErrorMessage(err)`

Accepts an `AxiosResponse<IApiError>` and returns a user-facing error message (either a React JSX element or a plain string) based on the error reason returned by the API.

| API Reason Match | Returned Message |
|---|---|
| `"version isn't supported by apple"` | JSX with bolded **Minimum version** context |
| `"deadline isn't a valid date"` | JSX with bolded **Deadline** context |
| `"couldn't update os updates settings"` | Raw `originalReason` string from API |
| *(fallback)* | `"Couldn't update. Please try again."` |

## Usage Example

```typescript
import { getErrorMessage } from "./helpers";

try {
  await updateOSSettings(payload);
} catch (err) {
  const message = getErrorMessage(err);
  // Render `message` in a toast or error banner
  renderErrorToast(message);
}
```

## Notes

- Error reason matching is **case-insensitive** (via `.toLowerCase()`).
- Returns JSX for actionable errors where bolding specific field names improves clarity for end users.
- Falls back to a generic message for any unrecognized API error.
