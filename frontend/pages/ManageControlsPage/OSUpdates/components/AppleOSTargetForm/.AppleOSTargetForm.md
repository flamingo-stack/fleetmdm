A React form component for configuring Apple OS update targets (macOS, iOS, iPadOS) within Fleet MDM, handling minimum version and deadline settings per team or globally.

## Key Components

- **`AppleOSTargetForm`** — Main form component that renders minimum version and deadline inputs, submits MDM update configuration to either the global app config or a specific team config
- **`validateForm`** — Validates that minimum version (semver-like) and deadline (YYYY-MM-DD) are both present or both empty, returning field-level error messages
- **`createAppleOSUpdatesData`** — Builds the MDM config payload, mapping `ApplePlatform` values (`darwin`, `ios`, `ipados`) to their respective API config field names; includes `update_new_hosts` for macOS only
- **`APPLE_PLATFORMS_TO_CONFIG_FIELDS`** — Maps platform identifiers to MDM config keys (`darwin` → `macos_updates`, etc.)

## Usage Example

```typescript
<AppleOSTargetForm
  currentTeamId={42}
  applePlatform="darwin"
  defaultMinOsVersion="14.0"
  defaultDeadline="2024-07-01"
  defaultUpdateNewHosts={false}
  refetchAppConfig={refetchAppConfig}
  refetchTeamConfig={refetchTeamConfig}
/>
```

## Behavior Notes

- When `currentTeamId` equals `APP_CONTEXT_NO_TEAM_ID`, updates are saved to the global app config via `configAPI.update`; otherwise they target the specific team via `teamsAPI.update`
- Both fields may be cleared simultaneously (empty state is valid); having only one populated triggers validation errors on the other
- The **"Update new hosts to latest"** checkbox (`update_new_hosts`) is rendered only for `darwin` (macOS)
- GitOps mode disables all inputs and the save button via `GitOpsModeTooltipWrapper`
