A tabbed UI component for configuring OS update policies across multiple device platforms (macOS, Windows, iOS, iPadOS, and optionally Android) within the Fleet MDM OS Updates settings.

## Key Components

- **`PlatformTabs`** — Default export. Renders a `react-tabs` tab interface where each tab corresponds to a supported OS platform, conditionally showing Windows and Android tabs based on MDM enrollment status.
- **`IPlatformTabsProps`** — Interface defining props including default version/deadline values per platform, MDM feature flags, and callbacks for platform selection and config refetching.
- **`platformByIndex`** — Dynamically built array mapping tab indices to `OSUpdatesTargetPlatform` values, accounting for enabled MDM features.
- **Configuration status checks** — Boolean flags (`isMacOSConfigured`, `isWindowsConfigured`, etc.) that display a checkmark on tabs where a minimum version or deadline has been set.

## Usage Example

```typescript
<PlatformTabs
  currentTeamId={42}
  defaultMacOSVersion="14.0"
  defaultMacOSDeadline="2024-12-31"
  defaultMacOSUpdateNewHosts={true}
  defaultIOSVersion="17.0"
  defaultIOSDeadline="2024-12-31"
  defaultIPadOSVersion="17.0"
  defaultIPadOSDeadline="2024-12-31"
  defaultWindowsDeadlineDays="7"
  defaultWindowsGracePeriodDays="3"
  selectedPlatform="darwin"
  onSelectPlatform={(platform) => setSelectedPlatform(platform)}
  refetchAppConfig={refetchAppConfig}
  refetchTeamConfig={refetchTeamConfig}
  isWindowsMdmEnabled={true}
  isAndroidMdmEnabled={false}
/>
```
