A React table cell component that displays an OS platform icon alongside a truncated, tooltip-enabled version name for OS update entries.

## Key Components

- **`OSTypeCell`** – Default export. Renders a platform icon and version name within a styled container.
- **`IOSTypeCellProps`** – Interface defining the component's props:
  - `platform: OSUpdatesSupportedPlatform` – The OS platform identifier (e.g., `darwin`, `windows`) used to resolve the correct icon.
  - `versionName: string` – The OS version label displayed with truncation and tooltip support.

## Usage Example

```typescript
import OSTypeCell from "./OSTypeCell";

<OSTypeCell
  platform="darwin"
  versionName="macOS Sonoma 14.5"
/>
```

## Notes

- Uses the [`Icon`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/Icon) component to render a platform-specific icon based on the `platform` prop.
- Uses [`TooltipTruncatedText`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/TooltipTruncatedText) to gracefully handle long version name strings — truncating overflow text and showing the full value in a tooltip on hover.
- `OSUpdatesSupportedPlatform` is imported from the parent `OSUpdates` feature module, constraining `platform` to valid OS types.
