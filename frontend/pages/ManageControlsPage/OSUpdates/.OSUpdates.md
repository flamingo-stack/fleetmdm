Renders the OS Updates settings page within Fleet MDM's Controls section, managing platform-specific software update enforcement for macOS, Windows, and iOS devices across global and team configurations.

## Key Components

- **`OSUpdates`** — Main page component that orchestrates config fetching, access control, and platform selection
- **`getDefaultSelectedPlatform`** — Derives the initial platform tab (`darwin` or `windows`) based on MDM enrollment state
- **`OSUpdatesSupportedPlatform`** — Union type: `ApplePlatform | "windows"`
- **`OSUpdatesTargetPlatform`** — Extends supported platforms with `"android"` for "coming soon" messaging
- **`CurrentVersionSection`** — Displays current OS version data with query param support
- **`TargetSection`** — UI for configuring the target OS version per platform

## Usage Example

```typescript
// Rendered by a parent route component
<OSUpdates
  router={router}
  teamIdForApi={currentTeamId}
  queryParams={parseOSUpdatesCurrentVersionsQueryParams(location.query)}
/>
```

## Access & Rendering Logic

```text
Not premium tier     → <PremiumFeatureMessage />
Loading configs      → <Spinner />
Not global/team admin → redirect to OS Settings
MDM not configured   → <EmptyState /> with "Turn on" CTA
Default state        → Renders CurrentVersionSection + TargetSection
```

## Data Fetching

| Query | Source | Condition |
|---|---|---|
| App config | `configAPI.loadAll()` | Disabled (pre-fetched in `App.tsx`) |
| Team config | `teamsAPI.load(teamIdForApi)` | Only when `teamIdForApi` is truthy |
