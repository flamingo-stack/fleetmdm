Utility module for generating CSV files from live query results, policy results, and policy errors in the Fleet MDM interface.

## Key Components

- **`generateCSVFilename(descriptor)`** – Creates a timestamped CSV filename in the format `<descriptor> (MM-dd-yy hh-mm-ss).csv`.
- **`generateCSVQueryResults(rows, filename, tableHeaders, omitHostDisplayName?)`** – Converts `react-table` row data into a CSV `File` object. Reorders columns to place `host_display_name` first unless `omitHostDisplayName` is set.
- **`generateCSVPolicyResults(rows, filename)`** – Converts policy result rows (`host`, `status`) into a CSV `File` object.
- **`generateCSVPolicyErrors(rows, filename)`** – Converts `ICampaignError` rows into a CSV `File` object.
- **`reorderCSVFields(tableHeaders)`** *(internal)* – Ensures `host_display_name` is the first column in the CSV output.

## Usage Example

```typescript
import csvExport from "path/to/index";

// Generate a timestamped filename
const filename = csvExport.generateCSVFilename("Query Results");
// → "Query Results (01-15-25 03-45-22).csv"

// Export live query results to CSV
const csvFile = csvExport.generateCSVQueryResults(
  tableRows,       // Row[] from react-table
  filename,
  tableHeaders     // Column<T>[] or string[]
);

// Export policy results
const policyCSV = csvExport.generateCSVPolicyResults(
  [{ host: "device-01", status: "pass" }],
  csvExport.generateCSVFilename("Policy Results")
);

// Trigger browser download
const url = URL.createObjectURL(csvFile);
```

## Notes

- All functions return a browser `File` object (`text/csv` MIME type), suitable for direct download via `URL.createObjectURL`.
- Relies on [`convertToCSV`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/convert_to_csv) for serialization and [`date-fns`](https://date-fns.org/) for timestamp formatting.
