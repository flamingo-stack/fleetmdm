Utility functions for parsing and enriching host/target entity data with computed CPU information and target type metadata.

## Key Components

### `parseEntityFunc(host: IHost)`
Exported function that enriches a host object with a formatted `cpu_type` string (e.g., `"4 x 2.4 GHz"`) derived from the host's `cpu_brand`, `cpu_physical_cores` fields. Falls back to `"Unknown"` for unparseable CPU brand strings. Appends `target_type: "hosts"` to the returned object.

### `appendTargetTypeToTargets(targets, targetType)` *(default export)*
Maps over an array of targets and appends a `target_type` field. When `targetType` is `"hosts"`, delegates to `parseEntityFunc` for full CPU parsing; otherwise, performs a simple spread with the given `targetType`.

## Usage Example

```typescript
import appendTargetTypeToTargets, { parseEntityFunc } from "./index";

// Enrich a single host
const enrichedHost = parseEntityFunc({
  cpu_brand: "Intel Core i7 @ 2.6GHz",
  cpu_physical_cores: 4,
  // ...other IHost fields
});
// enrichedHost.cpu_type => "4 x 2.6 GHz"
// enrichedHost.target_type => "hosts"

// Enrich a list of mixed targets
const targets = appendTargetTypeToTargets(rawTargets, "hosts");
// Each target gets cpu_type + target_type: "hosts"

const labelTargets = appendTargetTypeToTargets(rawLabels, "labels");
// Each target gets target_type: "labels" (no CPU parsing)
```

## Notes

- CPU clock speed parsing splits on `"@ "` or `"@"` and truncates to one decimal place via `Math.floor`.
- If `cpu_brand` doesn't contain a parseable clock speed, a console warning is logged and `cpu_type` is set to `null` (omitted from display).
