Central constants file for the Fleet MDM frontend application, exporting shared configuration values, dropdown options, platform mappings, UI constants, and default state objects used across the application.

## Key Components

| Export | Type | Description |
|---|---|---|
| `BASE_URL` | `string` | API base URL derived from `window.location.origin` |
| `PolicyResponse` | `enum` | `PASSING` / `FAILING` policy response states |
| `DEFAULT_QUERY` | `ISchedulableQuery` | Default schedulable query shape |
| `DEFAULT_CAMPAIGN` | `ICampaign` | Default live query campaign state |
| `DEFAULT_CAMPAIGN_STATE` | `object` | Full UI state for live query campaign |
| `PLATFORM_DISPLAY_NAMES` | `Record<string, DisplayPlatform>` | Maps API platform keys to display strings |
| `PLATFORM_LABEL_DISPLAY_NAMES` | `Record<PlatformLabelNameFromAPI, string>` | Maps API label names to human-readable display names |
| `PLATFORM_LABEL_DISPLAY_TYPES` | `Record<PlatformLabelNameFromAPI, string>` | Maps labels to `"all"` or `"platform"` type |
| `PLATFORM_TYPE_ICONS` | `object` | Maps platform labels to icon identifiers |
| `MDM_STATUS_TOOLTIP` | `Record<MdmEnrollmentStatus, ReactNode>` | Tooltip content for each MDM enrollment status |
| `FREQUENCY_DROPDOWN_OPTIONS` | `IDropdownOption[]` | Query schedule frequency options (0s to 604800s) |
| `MIN_OSQUERY_VERSION_OPTIONS` | `IDropdownOption[]` | Supported minimum osquery version filter options |
| `SCHEDULE_PLATFORM_DROPDOWN_OPTIONS` | `readonly` array | Platform filter options for scheduled queries |
| `isPlatformLabelNameFromAPI` | `function` | Type guard for `PlatformLabelNameFromAPI` |
| `hasPlatformTypeIcon` | `function` | Type guard checking if a string has a platform icon |
| `MAX_OSQUERY_SCHEDULED_QUERY_INTERVAL` | `number` | Max interval (604800s = 1 week) |
| `DEFAULT_EMPTY_CELL_VALUE` | `string` | `"---"` placeholder for empty table cells |

## Usage Example

```typescript
import {
  BASE_URL,
  FREQUENCY_DROPDOWN_OPTIONS,
  PLATFORM_DISPLAY_NAMES,
  DEFAULT_QUERY,
  isPlatformLabelNameFromAPI,
  PolicyResponse,
} from "utilities/constants";

// API calls
const response = await fetch(`${BASE_URL}/v1/fleet/hosts`);

// Dropdown rendering
const options = FREQUENCY_DROPDOWN_OPTIONS;
// [{ value: 0, label: "Never" }, { value: 300, label: "Every 5 minutes" }, ...]

// Platform display mapping
const displayName = PLATFORM_DISPLAY_NAMES["darwin"]; // "macOS"

// Type guard usage
if (isPlatformLabelNameFromAPI(labelName)) {
  // labelName is narrowed to PlatformLabelNameFromAPI
}

// Policy response check
if (response === PolicyResponse.FAILING) {
  // handle failing policy
}

// Clone default query for a new query form
const newQuery = { ...DEFAULT_QUERY, name: "My Query" };
```
