Provides utilities for base64-encoding scripts to bypass WAF (Web Application Firewall) rules that may block requests containing shell or PowerShell script patterns.

## Key Components

- **`SCRIPTS_ENCODED_HEADER`** — HTTP header name (`X-Fleet-Scripts-Encoded`) used to signal that script payloads in a request are base64-encoded.
- **`encodeScriptBase64`** — Encodes a script string to base64 using `TextEncoder` for correct UTF-8/unicode handling. Passes through `undefined` and empty strings unchanged.

## Usage Example

```typescript
import { SCRIPTS_ENCODED_HEADER, encodeScriptBase64 } from "./scripts_encoding";

const script = "#!/bin/bash\necho 'Hello, World!'";
const encoded = encodeScriptBase64(script);

fetch("/api/run-script", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    [SCRIPTS_ENCODED_HEADER]: "true",
  },
  body: JSON.stringify({ script: encoded }),
});

// Edge cases — passed through without modification
encodeScriptBase64(undefined); // → undefined
encodeScriptBase64("");        // → ""
```

## Notes

- Uses `TextEncoder` + `btoa` instead of `btoa` alone to correctly handle multi-byte unicode characters in script content.
- The `undefined`/empty passthrough behavior allows callers to forward optional script fields without conditional checks.
