Utility module for resolving file extensions to platform display names and extracting file metadata for package management workflows.

## Key Components

### Constants

- **`FILE_EXTENSIONS_TO_PLATFORM_DISPLAY_NAME`** — Maps file extensions (e.g., `pkg`, `msi`, `deb`) to human-readable platform names (`macOS`, `Windows`, `Linux`, `iOS/iPadOS`, `macOS & Linux`).

### Functions

- **`getExtensionFromFileName(fileName)`** — Extracts the file extension, handling compound extensions (e.g., `tar.gz`) and aliased extensions (e.g., `tgz` → `tar.gz`). Returns a `PackageType` or `undefined`.
- **`getPlatformDisplayName(file)`** — Returns the platform display name for a given `File`. For `.ipa` files, wraps the result in a `TooltipWrapper` noting dual-platform support.
- **`getFileDetails(file)`** — Returns an `IFileDetails` object containing the file's `name` and platform `description`.

### Interfaces

- **`IFileDetails`** — Shape `{ name: string; description?: React.ReactNode }` representing resolved file metadata.

## Usage Example

```typescript
import {
  getExtensionFromFileName,
  getFileDetails,
  FILE_EXTENSIONS_TO_PLATFORM_DISPLAY_NAME,
} from "./fileUtils";

// Resolve extension (handles compound & aliased types)
const ext = getExtensionFromFileName("installer.tar.gz"); // "tar.gz"
const aliased = getExtensionFromFileName("archive.tgz");  // "tar.gz"

// Get platform label from extension
const platform = FILE_EXTENSIONS_TO_PLATFORM_DISPLAY_NAME["deb"]; // "Linux"

// Get full file details (e.g., for display in a table row)
const inputFile: File = new File([""], "agent.pkg");
const details = getFileDetails(inputFile);
// { name: "agent.pkg", description: "macOS" }
```
