Provides constants, types, and async validation logic for organization logo file uploads, including size limits, accepted formats, and magic-byte content sniffing.

## Key Components

| Export | Type | Description |
|---|---|---|
| `ORG_LOGO_ACCEPT` | `string` | File input `accept` attribute value for allowed extensions |
| `ORG_LOGO_MAX_SIZE_BYTES` | `number` | Maximum file size (100 KB) |
| `ORG_LOGO_HELP_TEXT` | `string` | UI helper text for logo upload guidance |
| `ORG_LOGO_ALLOWED_TYPES` | `readonly string[]` | Allowed image formats: `png`, `jpeg`, `webp`, `svg` |
| `ImageFileType` | `type` | Union type derived from `ORG_LOGO_ALLOWED_TYPES` |
| `IOrgLogoValidationResult` | `interface` | Validation result shape with `valid` flag and optional `error` string |
| `validateOrgLogoFile` | `async function` | Validates a `File` by size and magic-byte content sniffing |

### Internal Helpers

- **`detectImageType(bytes)`** — Reads raw `Uint8Array` bytes to identify PNG, JPEG, WebP, or SVG by their binary signatures, ignoring the browser-reported MIME type (which is extension-based and untrustworthy).
- **SVG detection** — Strips BOM, XML declarations, comments, and DOCTYPE before matching `<svg` at the root, preventing false positives from HTML files containing inline SVGs.

## Usage Example

```typescript
import { validateOrgLogoFile } from "./orgLogoFile";

const handleLogoUpload = async (file: File) => {
  const result = await validateOrgLogoFile(file);

  if (!result.valid) {
    console.error(result.error);
    // e.g. "Logo must be a PNG, JPEG, WEBP, or SVG file."
    // e.g. "Logo must be 100 KB or less."
    return;
  }

  // Safe to proceed with upload
  await uploadLogo(file);
};
```

> **Note:** Validation sniffs the first 1024 bytes of the file content rather than trusting `file.type`, so a WebP saved with a `.png` extension is correctly rejected.
