Test suite for the `fileUtils` module, validating extension extraction, file detail resolution, and platform display name mapping for macOS, Windows, and Linux file types.

## Key Components

| Test Suite | Function Under Test | Coverage |
|---|---|---|
| `getExtensionFromFileName` | Extension parsing | Simple, compound (`.tar.gz`), aliases (`.tgz`), no extension |
| `getFileDetails` | File metadata resolution | Platform description mapping per extension |
| `getPlatformDisplayName` | Platform label lookup | Extension-to-OS mapping, unknown/empty inputs |

## Usage Example

```typescript
// Functions tested (from ./fileUtils)
import {
  getExtensionFromFileName,
  getFileDetails,
  getPlatformDisplayName,
} from "./fileUtils";

// Extension parsing
getExtensionFromFileName("setup.tar.gz"); // → "tar.gz"
getExtensionFromFileName("setup.tgz");    // → "tar.gz" (alias resolved)
getExtensionFromFileName("no_extension"); // → undefined

// File detail resolution
const file = new File([""], "installer.pkg");
getFileDetails(file);
// → { name: "installer.pkg", description: "macOS" }

// Platform display name
getPlatformDisplayName(new File([""], "app.exe")); // → "Windows"
getPlatformDisplayName(new File([""], "app.deb")); // → "Linux"
getPlatformDisplayName(new File([""], "app.pkg")); // → "macOS"
```

## Edge Cases Covered

- **Compound extensions** — `.tar.gz`, `.tar.xz`, `.tar.bz2`, `.tar.zst`
- **Alias normalization** — `.tgz` → `tar.gz`, `.txz` → `tar.xz`, `.tzst` → `tar.zst`
- **Empty filenames** — returns `undefined` platform, empty `name`
- **No extension** — returns `undefined` for both platform and description
- **Multiple dots** — `my.file.name.pkg` correctly resolves to `macOS`
- **Unknown extensions** — returns `undefined` without throwing
