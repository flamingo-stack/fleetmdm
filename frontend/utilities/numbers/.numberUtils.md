Provides a type guard utility for validating numeric values with optional range constraints.

## Key Components

- **`isValidNumber(value, min?, max?)`** — Type guard that returns `true` if `value` is a non-`NaN` number and, when provided, falls within the inclusive `[min, max]` range.

## Usage Example

```typescript
import numberUtils from "./numberUtils";

// Basic type check
numberUtils.isValidNumber(42);        // true
numberUtils.isValidNumber("42");      // false
numberUtils.isValidNumber(NaN);       // false

// Range validation
numberUtils.isValidNumber(5, 1, 10);  // true
numberUtils.isValidNumber(0, 1, 10);  // false

// Type narrowing in practice
const raw: unknown = getUserInput();
if (numberUtils.isValidNumber(raw, 0, 100)) {
  // `raw` is narrowed to `number` here
  setProgress(raw);
}
```
