Test suite for the `isValidNumber` utility from `utilities/numbers`, verifying type checking, NaN handling, and optional min/max boundary enforcement.

## Key Components

- **`isValidNumber`** — The function under test; validates that a value is a finite number (not `NaN`, not a non-number type) and optionally falls within a specified range.

## Test Coverage

| Scenario | Cases Covered |
|---|---|
| Valid numbers | `0`, positive, negative, floats |
| Invalid types | `string`, `null`, `undefined`, `{}`, `[]`, `boolean` |
| NaN | `NaN` returns `false` |
| Min boundary | exclusive below, inclusive at min |
| Max boundary | exclusive above, inclusive at max |
| Min + Max range | inclusive boundaries, exclusive outside |

## Usage Example

```typescript
import numberUtils from "utilities/numbers";

const { isValidNumber } = numberUtils;

// Basic type check
isValidNumber(42);         // true
isValidNumber("42");       // false
isValidNumber(NaN);        // false

// With min constraint
isValidNumber(5, 6);       // false — below min

// With max constraint
isValidNumber(5, undefined, 4); // false — above max

// With both min and max
isValidNumber(5, 0, 10);   // true
isValidNumber(11, 0, 10);  // false
```
