Utility module providing string manipulation and formatting helpers for Fleet MDM UI, including capitalization, pluralization, casing enforcement, and query parsing.

## Key Components

| Export | Description |
|--------|-------------|
| `capitalize` | Capitalizes the first letter of each word in a string |
| `capitalizeRole` | Capitalizes `UserRole` values with special handling for `observer_plus` and `gitops` |
| `STYLIZATIONS_AND_ACRONYMS` | Allowlist of preserved terms (e.g., `macOS`, `MDM`, `API`) for casing rules |
| `enforceFleetSentenceCasing` | Applies Fleet's sentence-case style guide, preserving known stylizations |
| `pluralize` | Returns a pluralized or singular word form based on a count |
| `strToBool` | Parses a string to a boolean via `JSON.parse` |
| `stripQuotes` | Removes surrounding single or double quotes from a string |
| `isIncompleteQuoteQuery` | Detects strings that open a quote without closing it |
| `hyphenateString` | Lowercases and hyphenates whitespace for use in file names |
| `matchLoosePrefixToKey` | Loosely matches a string prefix to a dictionary key (longest-first) |

## Usage Example

```typescript
import stringUtils, {
  enforceFleetSentenceCasing,
  pluralize,
  matchLoosePrefixToKey,
} from "utilities/stringUtils";

// Capitalize words
stringUtils.capitalize("fleet device management"); // "Fleet Device Management"

// Fleet sentence casing (preserves stylizations)
enforceFleetSentenceCasing("Configure MDM settings for macOS"); 
// "Configure MDM settings for macOS"

// Pluralization with custom suffixes
pluralize(1, "hero", "es", "");  // "hero"
pluralize(2, "hero", "es", "");  // "heroes"
pluralize(2, "dragon");          // "dragons"

// Prefix dictionary matching (longest key wins)
const dict = { archaeology: 1, arc: 2 };
matchLoosePrefixToKey(dict, "archaeology dig"); // "archaeology"
matchLoosePrefixToKey(dict, "arc");             // "arc"

// Strip surrounding quotes
stringUtils.stripQuotes('"hello"'); // "hello"

// Detect incomplete quote queries
stringUtils.isIncompleteQuoteQuery('"unclosed'); // true
```

> **Note:** `enforceFleetSentenceCasing` does not recognize arbitrary proper nouns — only terms listed in `STYLIZATIONS_AND_ACRONYMS` are preserved. See the [Fleet content style guide](https://fleetdm.com/handbook/marketing/content-style-guide#sentence-case) for context.
