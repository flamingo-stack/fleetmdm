Test suite for the `stringUtils` module, validating string manipulation utilities used across the Fleet MDM frontend.

## Key Components

| Utility | Description |
|---|---|
| `enforceFleetSentenceCasing` | Normalizes strings to sentence case while preserving reserved words (e.g., `macOS`, `MySQL`) |
| `pluralize` | Returns singular or plural form of a word based on count, with optional custom suffixes |
| `strToBool` | Converts string `"true"`/`"false"` to booleans; returns `false` for falsy inputs |
| `stripQuotes` | Removes matching surrounding single or double quotes from a string |
| `isIncompleteQuoteQuery` | Detects strings that open with a quote but lack a closing match |
| `hyphenateString` | Converts strings to lowercase, hyphen-separated slugs |
| `matchLoosePrefixToKey` | Case-insensitive prefix lookup against a map, preferring the longest matching key |

## Usage Example

```typescript
import {
  enforceFleetSentenceCasing,
  pluralize,
  strToBool,
  stripQuotes,
  isIncompleteQuoteQuery,
  hyphenateString,
  matchLoosePrefixToKey,
} from "./stringUtils";

enforceFleetSentenceCasing("All Hosts");           // "All hosts"
enforceFleetSentenceCasing("fleet uses MySQL");    // "Fleet uses MySQL"

pluralize(1, "hero", "es", "");  // "hero"
pluralize(2, "hero", "es", "");  // "heroes"

strToBool("true");   // true
strToBool(null);     // false

stripQuotes('"Hello"');          // "Hello"
isIncompleteQuoteQuery('"open'); // true

hyphenateString("My Cool App");  // "my-cool-app"

const APP_MAP = { arc: "Arc", "visual studio code": "VisualStudioCode" };
matchLoosePrefixToKey(APP_MAP, "Visual Studio Code - Insiders"); // "visual studio code"
matchLoosePrefixToKey(APP_MAP, "Archive");                       // undefined
```

## Notes

- `matchLoosePrefixToKey` matches on whole-word boundaries — `"Codex"` will not match a key `"code"`.
- `enforceFleetSentenceCasing` maintains a Fleet-specific allowlist of casing exceptions (e.g., `osquery`, `macOS`).
