Test suite for the `debounce` utility, verifying that rapid successive calls to a debounced function execute only once.

## Key Components

- **`debounce` (default import)** — The debounce utility under test, imported from `./index`.
- **`prevents double-clicks` test** — Asserts that invoking a debounced function twice in quick succession results in only a single execution.

## Usage Example

```typescript
import debounce from "./index";

let count = 0;
const increment = () => { count += 1; };

const debouncedIncrement = debounce(increment);

debouncedIncrement(); // executes
debouncedIncrement(); // suppressed

console.log(count); // 1
```

## Notes

- The test focuses on **synchronous double-click prevention** — the two calls happen back-to-back with no delay, so only the first invocation should run.
- No timer mocking (e.g., `jest.useFakeTimers`) is used, meaning the debounce implementation relies on call-count or leading-edge logic rather than a time-based delay for this test case.
- Extend coverage with async/timer-based tests using `jest.useFakeTimers()` to validate trailing-edge behavior across varying wait intervals.
