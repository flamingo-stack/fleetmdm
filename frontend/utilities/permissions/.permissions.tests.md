Tests for the `permissions.isAdminForAllUserTeams` function, verifying authorization logic that determines whether one user has admin rights over all teams a target user belongs to.

## Key Components

- **`permissions.isAdminForAllUserTeams(currentUser, targetUser)`** — The function under test; returns a boolean indicating if the current user has admin authority over every team the target user is a member of.
- **`createMockUser`** — Factory helper used to construct user fixtures with configurable `global_role` and `teams` arrays.

## Test Cases

| Scenario | Expected |
|---|---|
| No current user (`null`) | `false` |
| Global admin targeting any user | `true` |
| Team admin — target only in administered teams | `true` |
| Team admin — target also in non-administered teams | `false` |
| Team admin of all target's teams | `true` |
| Team admin of one team, observer of another (target in both) | `false` |
| Team admin — target has a global role | `false` |
| Team admin — target has no teams | `false` |

## Usage Example

```typescript
import permissions from "./permissions";
import createMockUser from "__mocks__/userMock";

const currentUser = createMockUser({
  global_role: null,
  teams: [{ id: 1, name: "Team 1", role: "admin" }],
});

const targetUser = createMockUser({
  global_role: null,
  teams: [{ id: 1, name: "Team 1", role: "observer" }],
});

// true — currentUser admins all of targetUser's teams
permissions.isAdminForAllUserTeams(currentUser, targetUser);
```
