Role and permission utility functions for evaluating user access levels and system configuration state across global and team-scoped contexts.

## Key Components

### Config Checks
| Function | Description |
|---|---|
| `isSandboxMode(config)` | Returns `true` if sandbox mode is enabled |
| `isFreeTier(config)` | Returns `true` if license tier is `"free"` |
| `isPremiumTier(config)` | Returns `true` if license tier is `"premium"` |
| `isMacMdmEnabledAndConfigured(config)` | Returns `true` if macOS MDM is enabled and configured |
| `isWindowsMdmEnabledAndConfigured(config)` | Returns `true` if Windows MDM is enabled and configured |
| `isAndroidMdmEnabledAndConfigured(config)` | Returns `true` if Android MDM is enabled and configured |

### Global Role Checks
| Function | Description |
|---|---|
| `isGlobalAdmin(user)` | User has `admin` global role |
| `isGlobalMaintainer(user)` | User has `maintainer` global role |
| `isGlobalObserver(user)` | User has `observer` or `observer_plus` global role |
| `isGlobalObserverPlus(user)` | User has `observer_plus` global role |
| `isGlobalTechnician(user)` | User has `technician` global role |
| `isOnGlobalTeam(user)` | User has any non-null global role |

### Team-Scoped Role Checks
| Function | Description |
|---|---|
| `isTeamAdmin(user, teamId)` | User is `admin` on the specified team |
| `isTeamMaintainer(user, teamId)` | User is `maintainer` on the specified team |
| `isTeamObserver(user, teamId)` | User is `observer` or `observer_plus` on the specified team |
| `isTeamObserverPlus(user, teamId)` | User is `observer_plus` on the specified team |
| `isTeamTechnician(user, teamId)` | User is `technician` on the specified team |
| `isAdminForAllUserTeams(user, otherUser)` | User can manage `otherUser` across all their teams |

### Aggregate Role Checks
| Function | Description |
|---|---|
| `isAnyTeamAdmin(user)` | User is `admin` on at least one team |
| `isAnyTeamMaintainer(user)` | User is `maintainer` on at least one team |
| `isAnyTeamMaintainerOrTeamAdmin(user)` | User is `maintainer` or `admin` on at least one team |
| `isAnyTeamTechnician(user)` | User is `technician` on at least one team |
| `isOnlyObserver(user)` | User has no maintainer/admin roles anywhere |
| `isObserverPlus(user, teamId)` | User is `observer_plus` globally or on the specified team |
| `isNoAccess(user)` | User has no global role and belongs to no teams |

## Usage Example

```typescript
import permissions from "utilities/permissions";

// Config-level checks
if (permissions.isPremiumTier(config)) {
  // enable premium features
}

if (permissions.isMacMdmEnabledAndConfigured(config)) {
  // show macOS MDM controls
}

// Global role checks
if (permissions.isGlobalAdmin(currentUser)) {
  // show admin controls
}

// Team-scoped role checks
const teamId = 42;
if (permissions.isTeamMaintainer(currentUser, teamId)) {
  // allow policy edits for this team
}

// Cross-user admin validation (mirrors backend authorization)
if (permissions.isAdminForAllUserTeams(currentUser, targetUser)) {
  // allow editing targetUser's profile
}

// Aggregate checks (no specific team required)
if (permissions.isOnlyObserver(currentUser)) {
  // hide write actions across the UI
}
```
