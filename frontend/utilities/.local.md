A thin wrapper around the browser's `localStorage` API that namespaces all keys with a `FLEET::` prefix to avoid collisions with other applications.

## Key Components

- **`local.getItem(itemName)`** – Retrieves a value from `localStorage` using the namespaced key `FLEET::<itemName>`. Returns `string | null`.
- **`local.setItem(itemName, value)`** – Stores a string value under the namespaced key `FLEET::<itemName>`.
- **`local.removeItem(itemName)`** – Deletes the entry for the given namespaced key.
- **`local.clear()`** – Clears **all** entries in `localStorage` (not just `FLEET::` keys).

## Usage Example

```typescript
import local from "utilities/local";

// Store a value
local.setItem("authToken", "abc123");

// Retrieve a value (returns null if not found)
const token = local.getItem("authToken"); // "abc123"

// Remove a specific item
local.removeItem("authToken");

// Clear all localStorage entries
local.clear();
```

> **Note:** `local.clear()` removes all `localStorage` entries regardless of prefix, not just `FLEET::` keys. Use with caution in shared environments.
