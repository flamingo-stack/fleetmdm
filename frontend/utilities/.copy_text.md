Provides clipboard copy utility with helper constants for user-facing success and error feedback messages.

## Key Components

- **`stringToClipboard(string)`** — Writes the provided string to the system clipboard using the browser's `navigator.clipboard.writeText` API; returns the resulting `Promise`
- **`COPY_TEXT_SUCCESS`** — Standard success message: `"Text copied to clipboard"`
- **`COPY_TEXT_ERROR`** — Standard error message: `"Text not copied. Please copy manually."`

## Usage Example

```typescript
import {
  stringToClipboard,
  COPY_TEXT_SUCCESS,
  COPY_TEXT_ERROR,
} from "./copy_text";

async function handleCopy(value: string) {
  try {
    await stringToClipboard(value);
    console.log(COPY_TEXT_SUCCESS);
  } catch {
    console.error(COPY_TEXT_ERROR);
  }
}
```

> **Note:** `navigator.clipboard` requires a secure context (HTTPS or `localhost`) and user permission. The `@ts-nocheck` flag is present due to untyped global access and may need revisiting.
