Maps platform name strings to their corresponding icon filenames, returning a dark-themed 20x20 retina icon asset name or `false` if unrecognized.

## Key Components

- **`platformIconClass(platform?)`** — Takes an optional platform string and returns the matching icon filename string, or `false` for empty/unrecognized input. Matching is case-insensitive.

**Supported platforms and aliases:**

| Platform | Aliases |
|---|---|
| macOS | `macos`, `mac os x`, `mac osx`, `mac os`, `darwin`, `apple` |
| CentOS | `centos`, `centos linux` |
| Ubuntu | `ubuntu`, `ubuntu linux` |
| Linux | `linux` |
| Windows | `windows`, `ms windows` |

## Usage Example

```typescript
import { platformIconClass } from "./platform_icon_class";

// Recognized platforms
platformIconClass("macOS");       // "icon-apple-dark-20x20@2x.png"
platformIconClass("Darwin");      // "icon-apple-dark-20x20@2x.png"
platformIconClass("Windows");     // "icon-windows-dark-20x20@2x.png"
platformIconClass("Ubuntu Linux") // "icon-ubuntu-dark-20x20@2x.png"

// Unrecognized or empty
platformIconClass("android");     // false
platformIconClass();              // false
platformIconClass("");            // false
```

The return value is intended for use as an image source filename within an `<img>` tag or similar component to display a platform-specific icon in the Fleet MDM UI.
