Recursively compares two objects and returns the properties from the first object that differ from the second, handling nested objects and arrays.

## Key Components

- **`deepDifference(obj1, obj2)`** — Default export. Traverses `obj1` and returns a new object containing only the keys whose values differ from `obj2`. Handles three cases:
  - **Arrays** — Uses `differenceWith(isEqual)` to find elements in `obj1`'s array not present in `obj2`'s array; treats an empty array replacing a non-empty one as a meaningful difference.
  - **Nested objects** — Recurses into both values to produce a nested diff.
  - **Primitives** — Includes the value directly if `isEqual` reports a mismatch.

## Usage Example

```typescript
import deepDifference from "./index";

const original = {
  name: "Alice",
  roles: ["admin", "editor"],
  settings: { theme: "dark", lang: "en" },
};

const updated = {
  name: "Alice",
  roles: ["admin"],
  settings: { theme: "light", lang: "en" },
};

deepDifference(updated, original);
// → { roles: ["admin"], settings: { theme: "light" } }
```

> **Note:** The function only surfaces differences from `obj1`'s perspective — keys present in `obj2` but absent from `obj1` are not included in the result.
