Test suite for the `deepDifference` utility, validating deep comparison behavior across flat objects, nested objects, mixed nesting levels, and array comparisons.

## Key Components

| Test Case | Description |
|---|---|
| Flat objects | Detects changed primitive values between un-nested objects |
| Nested objects | Recursively identifies differing keys within nested structures |
| Mixed nesting | Handles comparisons between nested and non-nested objects |
| Empty arrays | Correctly returns empty arrays when compared against non-empty arrays |

## Usage Example

```typescript
import deepDifference from "utilities/deep_difference";

// Flat objects
const a = { id: 1, name: "Joe" };
const b = { id: 1, name: "Jane" };
deepDifference(a, b); // { name: "Joe" }

// Nested objects
const obj1 = { profile: { last_name: "Smith" }, post_ids: [1, 2, 3] };
const obj2 = { profile: { last_name: "Smyth" }, post_ids: [1, 3] };
deepDifference(obj1, obj2);
// { profile: { last_name: "Smith" }, post_ids: [2] }

// Mixed nesting
const nested = { profile: { id: 1, first_name: "Joe" } };
const flat   = { profile: "my profile" };
deepDifference(nested, flat); // returns nested (entire object differs)

// Empty array vs non-empty
const p = { label_ids: [] };
const q = { label_ids: [1, 2] };
deepDifference(p, q); // { label_ids: [] }
```

## Notes

- The function is **directional** — `deepDifference(a, b)` returns values from `a` that differ from `b`, not a symmetric diff.
- Array diffing returns elements present in the first array but absent in the second.
- When object nesting types mismatch (one nested, one primitive), the entire value from the first argument is returned.
