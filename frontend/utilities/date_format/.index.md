Provides date formatting utilities for displaying human-readable date strings, including relative time ("ago") and various formatted date representations.

## Key Components

| Export | Description |
|--------|-------------|
| `uploadedFromNow` | Returns `"Uploaded X ago"` string from a date string |
| `addedFromNow` | Returns `"Added X ago"` string from a date string |
| `dateAgo` | Returns `"X ago"` string from a date string or `Date` object |
| `monthDayYearFormat` | Returns `"January 01, 2024"` format, UTC-normalized |
| `monthDayTimeFormat` | Returns `"Mar 20, 1:35 PM"` format, returns empty string if invalid |

## Usage Example

```typescript
import {
  uploadedFromNow,
  addedFromNow,
  dateAgo,
  monthDayYearFormat,
  monthDayTimeFormat,
} from "./index";

// Relative time strings
uploadedFromNow("2024-01-15T10:00:00Z"); // "Uploaded 3 months ago"
addedFromNow("2024-01-15T10:00:00Z");    // "Added 3 months ago"
dateAgo(new Date("2024-01-15"));         // "3 months ago"

// Formatted date strings
monthDayYearFormat("2024-01-01T00:00:00Z"); // "January 1, 2024"
monthDayTimeFormat("2024-03-20T13:35:00Z"); // "Mar 20, 1:35 PM"
monthDayTimeFormat("not-a-date");           // ""
```

> **Note:** `uploadedFromNow`, `addedFromNow`, and `dateAgo` intentionally throw on malformed dates (fail-loudly behavior). Use `monthDayTimeFormat` when graceful fallback to an empty string is preferred.
