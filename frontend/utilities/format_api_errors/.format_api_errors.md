Transforms API error responses into a key-value map, converting an array of error objects into a structured dictionary keyed by error name.

## Key Components

- **Default export** — A function that accepts a raw API error object and returns a normalized error map or `undefined` if no response errors exist.

## Usage Example

```typescript
import formatApiErrors from "./format_api_errors";

try {
  await apiCall();
} catch (error) {
  const errors = formatApiErrors(error);
  // errors => { email: "is already taken", password: "is too short" }

  if (errors?.email) {
    console.error("Email error:", errors.email);
  }
}
```

## Input / Output

**Input:** An error object with the shape:
```typescript
{
  response: {
    errors: [
      { name: "email", reason: "is already taken" },
      { name: "password", reason: "is too short" }
    ]
  }
}
```

**Output:** A flat dictionary:
```typescript
{ email: "is already taken", password: "is too short" }
```

Returns `undefined` if `error.response` or `error.response.errors` is absent.
