SQL parsing and platform compatibility analysis utilities for osquery SQL queries, providing table extraction, platform filtering, and SQL keyword/function/type reference lists.

## Key Components

### Exports

- **`parseSqlTables(sqlString, includeVirtualTables?)`** — Parses a SQL string using `node-sql-parser` and returns an array of referenced osquery table names. Filters out virtual tables (CTEs/subselects) and function tables (e.g., `json_each`) by default.
- **`checkTable(sqlString, includeVirtualTables?)`** — Safe wrapper around `parseSqlTables` returning `{ tables, error }` instead of throwing.
- **`checkPlatformCompatibility(sqlString, includeVirtualTables?)`** — Determines which `QueryablePlatform` values are compatible with all tables referenced in the query via platform intersection. Returns `{ platforms, error }`.
- **`sqlKeyWords`** — Array of reserved SQL keywords for syntax highlighting or autocomplete.
- **`sqlBuiltinFunctions`** — Array of common SQL built-in functions (note: `last` intentionally excluded to avoid collision with the osquery `last` table).
- **`sqlDataTypes`** — Array of common SQL data types.

### Internal Helpers

- **`platformsByTableDictionary`** — A pre-built lookup mapping each osquery table name (including MacAdmins extension tables) to its supported platforms.
- **`_isNode` / `_visit`** — AST traversal utilities using a visitor pattern to walk the parsed SQL tree.
- **`filterCompatiblePlatforms`** — Intersects platform lists across all referenced tables to determine mutual compatibility; returns all platforms if no tables are referenced.

## Usage Example

```typescript
import { checkTable, checkPlatformCompatibility } from "utilities/sql_tools";

// Extract referenced tables
const { tables, error } = checkTable(
  "SELECT * FROM users JOIN processes ON users.pid = processes.pid"
);
// tables => ["users", "processes"]

// Check which platforms support all referenced tables
const { platforms, error: platErr } = checkPlatformCompatibility(
  "SELECT * FROM kernel_extensions"
);
// platforms => ["darwin"] (macOS-only table)

// Query with no tables is compatible with all platforms
const { platforms: all } = checkPlatformCompatibility("SELECT 1");
// platforms => ["darwin", "windows", "linux", ...]
```
