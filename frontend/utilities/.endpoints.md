Centralized registry of all Fleet API endpoint URL strings and generator functions, versioned under the `latest` API version.

## Key Components

- **`API_VERSION`** – Internal constant (`"latest"`) prepended to every URL path.
- **Static endpoints** – Plain string exports for stable, parameterless routes (e.g., `CONFIG`, `LOGIN`, `HOSTS`, `MDM_APPLE`).
- **Dynamic endpoint factories** – Arrow functions that accept typed parameters (`id`, `token`, `uuid`, etc.) and return interpolated URL strings. Examples include:
  - `HOST_PAST_ACTIVITIES(id)` / `HOST_UPCOMING_ACTIVITIES(id)` / `HOST_CANCEL_ACTIVITY(hostId, uuid)`
  - `DEVICE_SOFTWARE(token)`, `DEVICE_SOFTWARE_INSTALL(token, softwareTitleId)`
  - `MDM_APPLE_ENROLLMENT_PROFILE(token, ref?, deviceinfo?)` – builds a URL with `URLSearchParams` for optional query parameters
  - `HOST_LOCK(id)`, `HOST_UNLOCK(id)`, `HOST_WIPE(id)`

### Endpoint Groups

| Group | Examples |
|---|---|
| Activities | `ACTIVITIES`, `HOST_PAST_ACTIVITIES`, `HOST_UPCOMING_ACTIVITIES` |
| Device (self-service) | `DEVICE_SOFTWARE`, `DEVICE_SOFTWARE_INSTALL`, `DEVICE_CERTIFICATES` |
| Hosts | `HOSTS`, `HOST_SUMMARY`, `HOST_SOFTWARE`, `HOST_MDM` |
| MDM / Apple | `MDM_APPLE`, `MDM_BOOTSTRAP_PACKAGE`, `MDM_EULA`, `MDM_SETUP` |
| MDM / Android | `MDM_ANDROID_ENTERPRISE`, `MDM_ANDROID_SSE_URL` |
| Conditional Access | `CONDITIONAL_ACCESS_MICROSOFT`, `CONDITIONAL_ACCESS_IDP_SIGNING_CERT` |
| Labels | `LABELS`, `LABEL(id)`, `LABEL_HOSTS(id)` |
| OS Versions | `OS_VERSIONS`, `OS_VERSION(id)` |
| Auth | `LOGIN`, `LOGOUT`, `FORGOT_PASSWORD`, `RESET_PASSWORD` |

## Usage Example

```typescript
import endpoints from "endpoints";

// Static endpoint
const configUrl = endpoints.CONFIG;
// → "/latest/fleet/config"

// Dynamic endpoint — host activities
const pastActivities = endpoints.HOST_PAST_ACTIVITIES(42);
// → "/latest/fleet/hosts/42/activities"

// Dynamic endpoint — device software install
const installUrl = endpoints.DEVICE_SOFTWARE_INSTALL("device-token-xyz", 7);
// → "/latest/fleet/device/device-token-xyz/software/install/7"

// Dynamic endpoint — MDM enrollment profile with optional params
const enrollUrl = endpoints.MDM_APPLE_ENROLLMENT_PROFILE("tok123", "ref456");
// → "/api/mdm/apple/enroll?token=tok123&enrollment_reference=ref456"
```

> **Note:** `MDM_ANDROID_SSE_URL` uses a `/api/` prefix rather than the standard `/${API_VERSION}/` path, and `SETUP` is hardcoded to `/v1/setup` pending an upstream update.
