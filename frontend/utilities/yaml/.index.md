Utility module for handling YAML operations related to Fleet agent options, including error message formatting and YAML serialization.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `constructErrorString` | Function | Formats a YAML error object into a human-readable string |
| `agentOptionsToYaml` | Function | Serializes agent options to YAML, with empty `overrides` key suppression |

## Usage Example

```typescript
import { constructErrorString, agentOptionsToYaml } from "./index";

// Format a YAML parse error
const errorMsg = constructErrorString({
  name: "YAMLException",
  reason: "unexpected token",
  line: "5",
});
// → "YAMLException: unexpected token at line 5"

// Convert agent options to YAML string
const yaml = agentOptionsToYaml({
  config: { logging: { debug: true } },
  overrides: {}, // Empty — will be stripped from output
});
// → "config:\n  logging:\n    debug: true\n"

// Handles null/undefined input gracefully
const defaultYaml = agentOptionsToYaml(null);
// → "config: {}\n"
```

## Notes

- `agentOptionsToYaml` defaults to `{ config: {} }` when called with a falsy value.
- The `overrides` key is automatically removed from serialization when it is absent or empty, keeping the YAML output clean.
- Relies on [`js-yaml`](https://github.com/nodeca/js-yaml) for serialization via `yaml.dump`.
