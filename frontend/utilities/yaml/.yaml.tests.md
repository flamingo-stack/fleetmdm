Test suite for the `agentOptionsToYaml` utility, validating YAML serialization behavior for agent options including conditional rendering of `command_line_flags` and `overrides` keys.

## Key Components

- **`agentOptionsToYaml`** (imported from `utilities/yaml`) — The function under test; converts agent options objects to YAML strings.

## Test Cases

| Scenario | Expected Behavior |
|---|---|
| `command_line_flags` absent | Key omitted from output |
| Agent options are `null` | Key omitted from output |
| `command_line_flags: {}` | Renders as `command_line_flags: {}` |
| `command_line_flags: null` | Renders as `command_line_flags: null` |
| `command_line_flags: { verbose: true }` | Renders as nested YAML block |
| `overrides: {}` (empty) | Key omitted from output |

## Usage Example

```typescript
import { agentOptionsToYaml } from "utilities/yaml";

// Returns YAML without command_line_flags key
agentOptionsToYaml({ config: {} });

// Renders flags as a nested YAML block
agentOptionsToYaml({
  config: {},
  command_line_flags: { verbose: true },
});
// Output:
// config: {}
// command_line_flags:
//   verbose: true
```

## Notes

- The suite enforces that `command_line_flags` is **present** when explicitly set (even to `null` or `{}`), distinguishing between "unset" and "explicitly empty."
- Empty `overrides` objects are treated as absent, keeping output clean.
