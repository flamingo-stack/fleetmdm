Provides a utility for retrieving default installation scripts based on software package file extensions, mapping common package formats to their corresponding install scripts.

## Key Components

- **`getDefaultInstallScript(fileName: string): string`** — Default export. Accepts a file name, extracts its extension, and returns the appropriate pre-bundled install script string. Returns an empty string for formats that handle their own installation (`exe`, `zip`, `tar.gz`, `sh`, `ps1`, `ipa`), and throws for unrecognized extensions.

**Supported script-backed formats:**

| Extension | Script |
|-----------|--------|
| `pkg` | `install_pkg.sh` (macOS) |
| `msi` | `install_msi.ps1` (Windows) |
| `deb` | `install_deb.sh` (Debian/Ubuntu) |
| `rpm` | `install_rpm.sh` (RHEL/Fedora) |

## Usage Example

```typescript
import getDefaultInstallScript from "./software_install_scripts";

const script = getDefaultInstallScript("AcmeTool-1.0.0.pkg");
// Returns the contents of install_pkg.sh as a string

const emptyScript = getDefaultInstallScript("setup.exe");
// Returns "" — exe handles its own installation

try {
  getDefaultInstallScript("tool.dmg");
} catch (e) {
  console.error(e.message); // "unsupported file extension: dmg"
}
```

## Notes

- Script files (`install_pkg.sh`, `install_msi.ps1`, etc.) are bundled at build time via `@ts-ignore` imports — ensure your bundler is configured to handle `.sh` and `.ps1` files as raw text.
- Extension parsing is delegated to [`getExtensionFromFileName`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/utilities/file/fileUtils.ts).
