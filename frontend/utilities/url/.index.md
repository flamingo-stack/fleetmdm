Query parameter utility module for building, filtering, and reconciling host-related URL query strings, including logic for mutually exclusive/inclusive filter combinations.

## Key Components

### Types
- **`QueryValues`** / **`QueryParams`** — Base types for URL query parameter values and records
- **`IMutuallyInclusiveHostParams`** — Params that can coexist (e.g., `label` + `teamId` + `macSettingsStatus`)
- **`IMutuallyExclusiveHostParams`** — Full set of host filter params where only one filter group is active at a time

### Exported Functions

| Function | Description |
|---|---|
| `buildQueryStringFromParams` | Converts a params object to a URL query string, omitting null/undefined/empty values |
| `getPathWithQueryParams` | Appends a query string to an endpoint path |
| `parseQueryValueToNumberOrUndefined` | Safely parses a query value to a number with optional range validation |
| `reconcileSoftwareParams` | Resolves which software filter params to send based on specificity priority |
| `reconcileMutuallyInclusiveHostParams` | Builds params that must appear together (e.g., `fleet_id` always accompanies settings filters) |
| `reconcileMutuallyExclusiveHostParams` | Selects only one active filter group from the full exclusive params set |
| `getStatusParam` | Extracts a host status filter from selected label strings |
| `getLabelParam` | Extracts a label ID from selected label strings using the `labels/` prefix |
| `convertParamsToSnakeCase` | Converts camelCase param keys to snake_case for API compatibility |

## Usage Example

```typescript
import {
  buildQueryStringFromParams,
  getPathWithQueryParams,
  reconcileMutuallyExclusiveHostParams,
} from "utilities/url";

// Build a query string, omitting empty values
const qs = buildQueryStringFromParams({ teamId: 1, status: "online", label: undefined });
// → "teamId=1&status=online"

// Append params to an endpoint
const path = getPathWithQueryParams("/api/hosts", { teamId: 2, osName: "Ubuntu" });
// → "/api/hosts?teamId=2&osName=Ubuntu"

// Resolve mutually exclusive host filter params
const params = reconcileMutuallyExclusiveHostParams({
  policyId: 42,
  policyResponse: "passing",
});
// → { policy_id: 42, policy_response: "passing" }
```
