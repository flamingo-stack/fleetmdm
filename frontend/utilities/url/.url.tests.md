Unit test suite for URL utility functions, validating query string construction, path building, and mutually inclusive host parameter reconciliation.

## Key Components

### `buildQueryStringFromParams`
Converts a params object into a URL query string, filtering out `undefined`, `null`, and empty string values.

### `getPathWithQueryParams`
Appends a filtered query string to an endpoint path, returning the bare path when all params are filtered out.

### `reconcileMutuallyInclusiveHostParams`
Reconciles `macSettingsStatus` and `teamId` into their API equivalents (`apple_settings`, `fleet_id`), enforcing mutual inclusion rules and label-based exclusion logic.

## Usage Example

```typescript
import {
  buildQueryStringFromParams,
  getPathWithQueryParams,
  reconcileMutuallyInclusiveHostParams,
} from ".";

// Build a query string, nulls/undefined/empty strings are filtered
buildQueryStringFromParams({ query: "test", page: 1, order: undefined });
// => "query=test&page=1"

// Append filtered params to a path
getPathWithQueryParams("/hosts/manage", { software_id: 25, team_id: null });
// => "/hosts/manage?software_id=25"

// Reconcile host params — macSettingsStatus requires a teamId (defaults to 0)
reconcileMutuallyInclusiveHostParams({ macSettingsStatus: "pending" });
// => { apple_settings: "pending", fleet_id: 0 }

// Label presence excludes apple_settings and osSettings
reconcileMutuallyInclusiveHostParams({
  teamId: 1,
  label: "labels/7",
  macSettingsStatus: "pending",
});
// => { fleet_id: 1 }
```

## Key Behaviors Tested

| Scenario | Behavior |
|---|---|
| Null / undefined / empty string params | Filtered from query string |
| No params or all filtered | Returns bare endpoint path |
| `macSettingsStatus` without `teamId` | Defaults `fleet_id` to `0` |
| `teamId` without `macSettingsStatus` | Omits `apple_settings` |
| `label` present | Excludes `macSettingsStatus` and `osSettings`, retains `teamId` |
