Exports sorted and filtered collections of osquery tables and columns derived from the Fleet schema JSON, providing utilities for table/column lookup and query editor autocomplete.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `osqueryTables` | `IOsQueryTable[]` | All tables sorted alphabetically by name |
| `osqueryTablesAvailable` | `IOsQueryTable[]` | Tables with `hidden: false` only |
| `osqueryTableNames` | `string[]` | Flat list of visible table names |
| `osqueryTableColumnNames` | `string[]` | Flat list of all column names from visible tables |
| `osqueryTableColumns` | `OsQueryColumn[]` | Flat list of all columns from visible tables |
| `selectedTableColumns` | `(selectedTables: string[]) => OsQueryColumn[]` | Columns filtered by a set of selected table names |

## Usage Example

```typescript
import {
  osqueryTablesAvailable,
  osqueryTableNames,
  selectedTableColumns,
} from "utilities/osquery_tables";

// Get all non-hidden table names for autocomplete suggestions
const tableNames = osqueryTableNames;
// ["chrome_extensions", "disk_encryption", "processes", ...]

// Get columns for specific tables in a query editor context
const columns = selectedTableColumns(["processes", "users"]);
// Returns all columns from the "processes" and "users" tables only

// Access full table metadata for visible tables
const tables = osqueryTablesAvailable;
tables.forEach((table) => console.log(table.name, table.description));
```

## Notes

- Data is sourced from [`osquery_fleet_schema.json`](https://github.com/flamingo-stack/fleetmdm/blob/main/schema/osquery_fleet_schema.json) and cast to `IOsQueryTable[]`
- Tables/columns with `hidden: true` are excluded from all `Available`, `Names`, and `Columns` exports
- `selectedTableColumns` additionally filters by an explicit list of table names, returning an empty set for tables not in `selectedTables`
