A utility module providing formatting, transformation, and helper functions used across the Fleet MDM frontend application.

## Key Components

- **`addGravatarUrlToResource`** – Generates Gravatar URLs (light/dark) for a resource using MD5-hashed email, with localStorage-based fallback
- **`removeOSPrefix`** – Strips Apple OS prefixes (`macOS`, `iOS`, `iPadOS`) from version strings
- **`compareVersions`** – Semantic version comparator returning `-1`, `0`, or `1`
- **`formatSelectedTargetsForApi` / `formatPackTargetsForApi`** – Transforms selected UI targets (hosts, labels, teams) into API-ready payloads
- **`formatScheduledQueryForServer/Client`** – Bidirectional transform for pack/global/team scheduled queries, normalising platform, logging type, shard, and interval fields
- **`formatSeverity`** – Converts a CVSS float score into a labelled string (`Low`, `Medium`, `High`, `Critical`)
- **`formatFloatAsPercentage`** – Formats a decimal as a localised percentage string
- **`formatScriptNameForActivityItem`** – Returns a React element or fallback string for script activity display
- **`generateRole`** – Derives a display role (`UserRole`) from a user's teams and global role
- **`formatPackForClient`** / **`formatTeamForClient`** – Normalises pack and team objects for UI consumption

## Usage Example

```typescript
import {
  addGravatarUrlToResource,
  formatSeverity,
  compareVersions,
  formatSelectedTargetsForApi,
} from "utilities/helpers";

// Gravatar enrichment
const user = addGravatarUrlToResource({ email: "user@example.com", name: "Alice" });
console.log(user.gravatar_url); // https://www.gravatar.com/avatar/<hash>?d=...

// Severity label
console.log(formatSeverity(7.5)); // "High (7.5)"

// Version comparison
console.log(compareVersions("1.10.0", "1.9.0")); // 1

// Target formatting for API
const apiTargets = formatSelectedTargetsForApi(selectedTargets);
// { hosts: [1, 2], labels: [3], teams: [] }
```
