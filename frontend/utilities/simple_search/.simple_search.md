Case-insensitive search utility that filters a dictionary of items by matching a query string against each item's `name` property.

## Key Components

- **`IDictionary`** — Interface representing a key-value object where values can be any type.
- **`simpleSearch`** — Default export function that filters dictionary entries whose `name` field contains the search query (case-insensitive). Items without a `name` property are excluded from results.

## Usage Example

```typescript
import simpleSearch from "./simple_search";

const devices = {
  device1: { name: "MacBook Pro", os: "macOS" },
  device2: { name: "Windows Laptop", os: "Windows" },
  device3: { os: "Linux" }, // no name — excluded
};

const results = simpleSearch("mac", devices);
// Returns: [{ name: "MacBook Pro", os: "macOS" }]

const emptyResults = simpleSearch("android", devices);
// Returns: []
```

## Notes

- The search query defaults to an empty string, returning all named items if no query is provided.
- Matching is performed using lodash [`filter`](https://lodash.com/docs/#filter) and [`includes`](https://lodash.com/docs/#includes).
- Returns an array of matched values (not the original dictionary structure).
