Brief validation message constant used to communicate invalid Fleet server URL input to users.

## Key Components

- **`INVALID_SERVER_URL_MESSAGE`** — A string constant containing the error message displayed when a Fleet server URL fails validation (must be `https` or `http`).

## Usage Example

```typescript
import INVALID_SERVER_URL_MESSAGE from "./error_messages";

if (!isValidUrl(serverUrl)) {
  setError(INVALID_SERVER_URL_MESSAGE);
}
```
