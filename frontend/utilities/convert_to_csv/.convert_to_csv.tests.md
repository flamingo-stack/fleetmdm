Test suite for the `convertToCSV` utility, validating CSV generation from arrays of objects with support for custom table headers and edge cases involving embedded quotes, commas, and JSON values.

## Key Components

- **`convertToCSV`** — The utility under test, imported from `utilities/convert_to_csv`
- **`objArray`** — Basic fixture: simple flat objects with `first_name` / `last_name` keys
- **`objArray2`** — Edge-case fixture: includes a JSON-valued field, an ISO timestamp, and a key containing embedded `"` and `,` characters
- **`tableHeaders`** — Column descriptor array used to control output column order and selection

## Test Cases

| Test | Description |
|---|---|
| Basic conversion | Flat object array → properly quoted CSV rows |
| Headers + edge cases | Validates quoting of JSON field values, ISO timestamps, and keys containing `","` |

## Usage Example

```typescript
import convertToCSV from "utilities/convert_to_csv";

// Basic usage — headers inferred from object keys
convertToCSV({ objArray });
// → '"first_name","last_name"\n"Mike","Stone"\n"Paul","Simon"'

// With explicit table headers (controls column order/selection)
convertToCSV({ objArray: objArray2, tableHeaders });
// → '"host_display_name","last_fetched","uid","json_result","edge"",""case"...'
```

## Edge Cases Covered

- **JSON field values** — Serialized objects have internal `"` doubled (`""`) per RFC 4180
- **Keys with `","` in name** — The key `'edge","case'` is escaped as `"edge"",""case"` in the header row
- **ISO timestamps** — Passed through as-is within quoted cells
