Converts an array of objects to a CSV-formatted string, with support for custom field ordering and proper escaping of special characters.

## Key Components

- **`ConvertToCSV`** — Interface defining input options: `objArray` (data rows), optional `fieldSortFunc` (column ordering), and optional `tableHeaders` (explicit column definitions)
- **`formatFieldForCSV(value)`** — Formats individual cell values: stringifies objects, preserves leading zeros via Excel-safe quoting (`"=""value"""`), escapes internal double quotes, and wraps all values in quotes
- **`convertToCSV({ objArray, fieldSortFunc, tableHeaders })`** — Main export; derives fields from `tableHeaders` or the first object's keys, applies sort function, filters reserved columns, and joins rows with newlines
- **`defaultFieldSortFunc`** — Identity function used as the default `fieldSortFunc` (no reordering)

## Usage Example

```typescript
import convertToCSV from "./index";

const data = [
  { id: "001", name: 'Alice "A"', score: 98 },
  { id: "042", name: "Bob", score: 75 },
];

// Basic usage — fields inferred from object keys
const csv = convertToCSV({ objArray: data });

// With explicit headers and custom sort order
const csv = convertToCSV({
  objArray: data,
  tableHeaders: [{ id: "name" }, { id: "score" }, { id: "id" }],
  fieldSortFunc: (fields) => [...fields].sort(),
});

console.log(csv);
// "id","name","score"
// "001","Alice ""A""",98
// "042","Bob",75
```

> **Note:** The `"Host"` field is unconditionally filtered from output pending a post-v5 API review. Values with leading zeros (e.g. `"042"`) are wrapped in Excel-safe format to prevent zero-stripping.
