Returns the appropriate default uninstall script string for a given software package filename, based on its file extension.

## Key Components

- **`getDefaultUninstallScript(fileName: string): string`** — Main exported function that maps a package file extension to its corresponding uninstall script. Imports pre-built shell/PowerShell scripts for supported formats and returns them as strings.

**Supported extensions and their scripts:**

| Extension | Script |
|---|---|
| `.pkg` | `uninstall_pkg.sh` (macOS) |
| `.msi` | `uninstall_msi_with_upgrade_code.ps1` (Windows) |
| `.deb` | `uninstall_deb.sh` (Debian/Ubuntu) |
| `.rpm` | `uninstall_rpm.sh` (RHEL/Fedora) |
| `.exe`, `.tar.gz`, `.sh`, `.ps1`, `.ipa` | Returns `""` (no default script) |

Throws an `Error` for any unrecognized extension.

## Usage Example

```typescript
import getDefaultUninstallScript from "./software_uninstall_scripts";

// Get uninstall script for a macOS package
const script = getDefaultUninstallScript("MyApp-1.0.pkg");
// Returns the contents of uninstall_pkg.sh

// Get uninstall script for a Windows installer
const winScript = getDefaultUninstallScript("MyApp.msi");
// Returns the contents of uninstall_msi_with_upgrade_code.ps1

// Extensions with no default script return an empty string
const exeScript = getDefaultUninstallScript("MyApp.exe");
// Returns ""

// Unsupported extension throws an error
getDefaultUninstallScript("MyApp.dmg");
// throws Error: unsupported file extension: dmg
```
