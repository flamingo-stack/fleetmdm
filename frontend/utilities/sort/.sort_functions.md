Utility module providing comparator functions for sorting arrays, designed for use with `Array.prototype.sort()`.

## Key Components

| Function | Description |
|---|---|
| `booleanAsc` | Sorts boolean-like values ascending (`false`/falsy before `true`/truthy) |
| `caseInsensitiveAsc` | Sorts strings alphabetically, ignoring case differences |
| `dateStringsAsc` | Sorts date strings (e.g., `"2021-02-21"`) ascending; non-parsable values sort first |
| `hasLength` | Sorts arrays by presence of items (empty arrays sort before non-empty) |
| `hostPolicyStatus` | Sorts by host policy status using precedence order: `actionRequired` → `fail` → `pass` |

## Usage Example

```typescript
import sortFunctions from "./sort_functions";

// Sort strings case-insensitively
const names = ["Zebra", "apple", "Mango"];
names.sort(sortFunctions.caseInsensitiveAsc);
// → ["apple", "Mango", "Zebra"]

// Sort date strings ascending
const dates = ["2021-03-01", "invalid", "2021-01-15"];
dates.sort(sortFunctions.dateStringsAsc);
// → ["invalid", "2021-01-15", "2021-03-01"]

// Sort host policy statuses by severity
const statuses = ["pass", "actionRequired", "fail"];
statuses.sort(sortFunctions.hostPolicyStatus);
// → ["actionRequired", "fail", "pass"]
```

## Notes

- All functions follow the standard comparator contract: return `-1`, `0`, or `1`.
- `dateStringsAsc` uses `Date.parse()` internally; unparsable strings return `NaN` and are sorted to the front.
- `hostPolicyStatus` uses a fixed precedence array (`POLICY_STATUS_PRECEDENCE`) to rank statuses, where unlisted values receive an index of `-1` and sort first.
