Provides reusable test stub data for `IUser` and `ITeam` interfaces, used across unit and component tests to avoid repetitive mock object definitions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `teamStub` | `ITeam` | Base team mock with id, name, description, and counts |
| `userTeamStub` | `ITeam` | Extends `teamStub` with an `observer` role |
| `userStub` | `IUser` | Full user mock referencing `userTeamStub` for both `teams` and `fleets` |

## Usage Example

```typescript
import { userStub, teamStub, userTeamStub } from "test/stubs";

describe("UserProfile", () => {
  it("renders user name", () => {
    render(<UserProfile user={userStub} />);
    expect(screen.getByText("Gnar Mike")).toBeInTheDocument();
  });

  it("renders team info", () => {
    render(<TeamCard team={teamStub} />);
    expect(screen.getByText("Test Team")).toBeInTheDocument();
  });
});
```

## Notes

- `userTeamStub` spreads `teamStub` and adds a `role: "observer"` — useful for testing role-based UI logic.
- `userStub.teams` and `userStub.fleets` both reference `userTeamStub`, reflecting Fleet MDM's dual-association model.
- The default export includes only `userStub` for convenience; named exports are preferred for granular test setup.
