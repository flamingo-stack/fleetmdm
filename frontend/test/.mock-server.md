Sets up a Mock Service Worker (MSW) node server instance pre-configured with default request handlers for use in test environments.

## Key Components

- **`mockServer`** — An MSW server instance created via `setupServer`, initialized with all handlers from `default-handlers`.

## Usage Example

```typescript
import mockServer from "./mock-server";

beforeAll(() => mockServer.listen());
afterEach(() => mockServer.resetHandlers());
afterAll(() => mockServer.close());
```

## Notes

- Built on [MSW](https://mswjs.io/) (`msw/node`) for API mocking in Node.js (Jest/Vitest) environments.
- Default handlers are centralized in [`default-handlers.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/default-handlers.ts) — add shared mocks there to apply them globally across all test suites.
- Individual tests can override handlers temporarily using `mockServer.use(...)` without affecting other tests, as `resetHandlers()` restores defaults after each test.
