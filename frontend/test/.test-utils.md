Shared testing utilities for React component tests, providing custom renderers with context providers, mock factories for routing, and date helpers.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `renderWithAppContext` | Function | Renders a component wrapped in a configurable `AppContext` provider |
| `createCustomRenderer` | Function | Factory that builds a reusable render function with optional context providers and backend mock (`QueryClientProvider`) |
| `renderWithSetup` | Function | Convenience wrapper around `@testing-library/react` `render` that adds `userEvent.setup()` |
| `createMockRouter` | Function | Creates a jest-mocked `InjectedRouter` with optional overrides |
| `createMockLocation` | Function | Creates a mock `history` `Location` object with optional overrides |
| `createMockLocationExperimental` | Function | Creates a mock `IRouterLocation` (internal interface) with optional overrides |
| `baseUrl` | Function | Prefixes a path with `/api/latest/fleet` |
| `getPastDate` / `getFutureDate` | Functions | Generate ISO date strings relative to today |
| `waitForLoadingToFinish` | Function | Async helper that waits until `.loading-overlay` is removed from the DOM |

## Usage Example

```typescript
// Using createCustomRenderer with app context and backend mock
const render = createCustomRenderer({
  withBackendMock: true,
  context: {
    app: { currentUser: mockUser },
    notification: { renderFlash: jest.fn() },
  },
});

it("renders the component", async () => {
  const { getByText, user } = render(<MyComponent />);
  await user.click(getByText("Submit"));
  expect(getByText("Success")).toBeInTheDocument();
});

// Using createMockRouter
const router = createMockRouter({ push: jest.fn() });
render(<MyComponent router={router} />);
expect(router.push).toHaveBeenCalledWith("/dashboard");

// Date helpers
const createdAt = getPastDate(7);  // 7 days ago ISO string
const expiresAt = getFutureDate(30); // 30 days from now ISO string
```
