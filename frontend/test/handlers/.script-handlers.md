Provides an MSW (Mock Service Worker) request handler for mocking the Fleet team scripts API endpoint in tests.

## Key Components

- **`getTeamScriptsHandler`** — Factory function that creates an MSW GET handler for `/scripts?fleet_id={teamId}`, returning a mocked list of scripts built from the provided partial overrides.

## Usage Example

```typescript
import { server } from "test/server";
import getTeamScriptsHandler from "handlers/script-handlers";

server.use(
  getTeamScriptsHandler(1, [
    { name: "install-agent.sh" },
    { name: "restart-service.sh", script_content: "#!/bin/bash\n..." },
  ])
);
```

## Notes

- Wraps [`createMockScript`](https://github.com/flamingo-stack/fleetmdm/blob/main/src/__mocks__/scriptMock.ts) to hydrate each partial override into a full `IScript` object.
- The comment `// not supported for all teams` suggests this handler may only be applicable in contexts where the target team has scripting enabled.
