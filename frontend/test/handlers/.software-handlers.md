MSW (Mock Service Worker) request handlers for software installation and MDM command API endpoints, used in test environments to simulate Fleet server responses.

## Key Components

| Export | Endpoint | Description |
|---|---|---|
| `getDefaultSoftwareInstallHandler` | `GET /software/install/:uuid/results` | Successful install with full script outputs |
| `getSoftwareInstallHandlerNoOutputs` | `GET /software/install/:uuid/results` | Successful install with empty outputs |
| `getSoftwareInstallHandlerOnlyInstallOutput` | `GET /software/install/:uuid/results` | Successful install with only install output |
| `getSoftwareInstallResultHandler` | `GET /software/install/:uuid/results` | Alias for default successful install result |
| `getSoftwareInstallResultHandlerPremiumRequired` | `GET /software/install/:uuid/results` | Simulates a 402 Fleet Premium license error |
| `getSoftwareInstallHandlerWithPreInstall` | `GET /software/install/:uuid/results` | Install with pre-install, install, and post-install outputs |
| `getSoftwareInstallHandlerOnlyPreInstallOutput` | `GET /software/install/:uuid/results` | Failed install with only pre-install query output |
| `getMdmCommandResultHandler` | `GET /commands/results` | MDM command results for IPA packages; maps `command_uuid` to `NotNow` or `Acknowledged` status |

## Usage Example

```typescript
import { setupServer } from "msw/node";
import {
  getDefaultSoftwareInstallHandler,
  getMdmCommandResultHandler,
  getSoftwareInstallResultHandlerPremiumRequired,
} from "handlers/software-handlers";

// Set up server with desired mock handlers
const server = setupServer(
  getDefaultSoftwareInstallHandler,
  getMdmCommandResultHandler
);

beforeAll(() => server.listen());
afterEach(() => server.resetHandlers());
afterAll(() => server.close());

// Override a handler for a specific test
it("shows premium upsell on 402", () => {
  server.use(getSoftwareInstallResultHandlerPremiumRequired);
  // ... render and assert
});
```
