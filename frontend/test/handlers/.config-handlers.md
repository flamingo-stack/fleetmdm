MSW request handler factory for mocking Fleet config API responses in tests.

## Key Components

- **`createGetConfigHandler`** — Factory function that creates an MSW `GET /config` handler, optionally merging partial `IConfig` overrides into the mock config response.

## Usage Example

```typescript
import { createGetConfigHandler } from "test/handlers/config-handlers";

// Default mock config
const handler = createGetConfigHandler();

// With overrides
const handler = createGetConfigHandler({
  org_info: { org_name: "Test Org" },
  features: { enable_software_inventory: true },
});

// Use in test server setup
server.use(handler);
```

## Notes

- Relies on `createMockConfig` from `__mocks__/configMock` as the base fixture.
- Uses [`msw`](https://mswjs.io/) `http` and `HttpResponse` for request interception.
- `baseUrl` resolves the full URL from the test environment base URL.
