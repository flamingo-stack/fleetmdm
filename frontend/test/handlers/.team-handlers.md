Mock Service Worker (MSW) handler factory for intercepting GET requests to the team/fleet API endpoint in tests.

## Key Components

- **`createGetTeamHandler`** — Factory function that returns an MSW `http.get` handler for the `/fleets/:id` endpoint, accepting optional `IConfig` partial overrides to customize the mocked response payload via `createMockConfig`.

## Usage Example

```typescript
import { createGetTeamHandler } from "path/to/team-handlers";

// Default mock response
const handler = createGetTeamHandler();

// With custom config overrides
const handlerWithOverrides = createGetTeamHandler({
  tier: "premium",
  sandbox_enabled: true,
});

// Register with MSW server in tests
server.use(handlerWithOverrides);
```

## Notes

- Relies on `createMockConfig` from `__mocks__/configMock` to build the response body, keeping test data consistent.
- The `teamUrl` targets `/fleets/:id`, matching dynamic fleet/team detail routes.
- Designed to be composed into MSW `server.use(...)` calls within Jest or Vitest test suites.
