MSW (Mock Service Worker) request handlers for Fleet MDM label-related API endpoints, used in testing to intercept and mock HTTP responses for label data.

## Key Components

- **`getLabelHandler`** — Creates an MSW GET handler for `/labels/:id` that returns a mocked `ILabel` object, accepting partial overrides to customize the label response.
- **`getLabelHostsHandler`** — Creates an MSW GET handler for `/labels/:id/hosts` that returns a mocked hosts response, accepting an optional array of partial `IHost` objects.

## Usage Example

```typescript
import { getLabelHandler, getLabelHostsHandler } from "test/handlers/label-handlers";

const server = setupServer(
  getLabelHandler({ name: "macOS Devices", label_type: "platform" }),
  getLabelHostsHandler([{ hostname: "mac-01", platform: "darwin" }])
);

beforeAll(() => server.listen());
afterEach(() => server.resetHandlers());
afterAll(() => server.close());
```
