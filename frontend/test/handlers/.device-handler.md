MSW (Mock Service Worker) request handlers for device-related API endpoints used in test environments.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `defaultDeviceHandler` | `http.get` | Returns a default mock device response for `/device/:token` |
| `customDeviceHandler` | Factory function | Creates a GET handler with optional `IDUPDetails` overrides |
| `defaultMacAdminsHandler` | `http.get` | Returns mock Mac admins data for `/device/:token/macadmins` |
| `customDeviceSoftwareHandler` | Factory function | Creates a GET handler with optional software response overrides |
| `defaultDeviceCertificatesHandler` | `http.get` | Returns a single mock certificate for `/device/:token/certificates` |
| `deviceSetupExperienceHandler` | Factory function | Creates a POST handler for `/device/:token/setup_experience/status` |
| `emptySetupExperienceHandler` | `http.post` | Pre-configured handler returning empty software and scripts |
| `getDeviceVppCommandResultHandler` | `http.get` | Returns MDM command results mapped by UUID to a known status |

## Usage Example

```typescript
import { renderWithSetup } from "test/test-utils";
import {
  defaultDeviceHandler,
  customDeviceHandler,
  customDeviceSoftwareHandler,
  emptySetupExperienceHandler,
} from "handlers/device-handler";

// Use default handler in a test server setup
const server = setupServer(defaultDeviceHandler);

// Override specific device fields
const handler = customDeviceHandler({
  self_service: true,
  global_config: {
    mdm: { enabled_and_configured: true, require_all_software_macos: false },
    features: {
      enable_software_inventory: true,
      enable_conditional_access: false,
      enable_conditional_access_bypass: false,
    },
  },
});

// Combine multiple handlers
const server = setupServer(
  handler,
  customDeviceSoftwareHandler({ software: [] }),
  emptySetupExperienceHandler
);
```

The `getDeviceVppCommandResultHandler` maps specific UUIDs (`notnow-uuid`, `acknowledged-uuid`, `uuid-failed`) to MDM command statuses, falling back to `"Acknowledged"` for unrecognized UUIDs.
