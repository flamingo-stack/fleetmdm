MSW (Mock Service Worker) request handlers for the self-service software categories API endpoints, used in tests to mock CRUD operations and error scenarios.

## Key Components

### Factory Function
- **`createMockSelfServiceCategory`** — Creates a mock `ISelfServiceCategory` object with sensible defaults, accepting optional overrides.

### GET Handlers
- **`listSelfServiceCategoriesHandler`** — Returns a configurable list of categories (`GET /software/self_service_categories`); defaults to 5 emoji-named categories.
- **`listDeviceSelfServiceCategoriesHandler`** — Device-token-scoped variant (`GET /device/:token/software/self_service_categories`); fleet is derived from the token server-side.
- **`emptySelfServiceCategoriesHandler`** / **`emptyDeviceSelfServiceCategoriesHandler`** — Return empty category arrays.
- **`listSelfServiceCategoriesErrorHandler`** — Simulates a 500 error on list.

### POST Handlers
- **`addSelfServiceCategoryHandler`** — Echoes back the created category with id `99`.
- **`addSelfServiceCategoryConflictHandler`** — Simulates a 409 duplicate-name conflict.
- **`addSelfServiceCategoryErrorHandler`** — Simulates a 500 error on create.

### PATCH Handlers
- **`editSelfServiceCategoryHandler`** — Echoes back the updated category using the URL `:id` param.
- **`editSelfServiceCategoryConflictHandler`** — Simulates a 409 duplicate-name conflict.
- **`editSelfServiceCategoryErrorHandler`** — Simulates a 500 error on update.

### DELETE Handlers
- **`deleteSelfServiceCategoryHandler`** — Returns 204 No Content.
- **`deleteSelfServiceCategoryErrorHandler`** — Simulates a 500 error on delete.

## Usage Example

```typescript
import { render } from "test/test-utils";
import {
  listSelfServiceCategoriesHandler,
  addSelfServiceCategoryConflictHandler,
  createMockSelfServiceCategory,
} from "mocks/handlers/self-service-categories-handlers";

// In a test with a custom server
server.use(
  listSelfServiceCategoriesHandler([
    { id: 10, name: "🎨 Design Tools" },
  ]),
  addSelfServiceCategoryConflictHandler
);

// Create a one-off mock object
const mockCategory = createMockSelfServiceCategory({ id: 42, name: "🔧 Utilities" });
```
