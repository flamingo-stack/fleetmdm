Configures and exports the default MSW (Mock Service Worker) request handlers used across frontend tests to mock Fleet API responses.

## Key Components

- **`baseUrl(path)`** — Utility function that prefixes a path with `/api/latest/fleet`, providing a consistent base URL for Fleet API endpoint construction.
- **`handlers`** — Array of default MSW handlers covering devices, Mac admins, activity, and self-service categories. Exported as the module default.

## Usage Example

```typescript
import handlers, { baseUrl } from "./default-handlers";
import { setupServer } from "msw/node";

// Set up the mock server with default handlers
const mockServer = setupServer(...handlers);

// Override a specific handler in an individual test
mockServer.use(
  rest.get(baseUrl("/devices"), (req, res, ctx) => {
    return res(ctx.json({ devices: [] }));
  })
);

// Construct a Fleet API URL
const endpoint = baseUrl("/hosts"); // → "/api/latest/fleet/hosts"
```

## Notes

> **Anti-pattern notice:** Adding new handlers to this file is discouraged. Prefer using `mockServer.use()` within individual test files for clarity on which handlers are active per test. See [MSW `.use()` docs](https://mswjs.io/docs/api/setup-worker/use/) for details.
