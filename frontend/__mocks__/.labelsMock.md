Provides mock factory functions for `ILabel` and `IGetLabelResponse` objects, used in tests to generate realistic label data with sensible defaults.

## Key Components

- **`DEFAULT_LABEL_MOCK`** — Base label fixture with pre-filled fields including `id`, `name`, `query`, `platform`, `label_type`, `label_membership_type`, and `criteria`.
- **`createMockLabel(overrides?)`** — Factory that merges `DEFAULT_LABEL_MOCK` with any partial `ILabel` overrides.
- **`createMockGetLabelResponse(overrides?)`** — Factory that merges `DEFAULT_GET_LABEL_RESPONSE_MOCK` with any partial `IGetLabelResponse` overrides.

## Usage Example

```typescript
import { createMockLabel, createMockGetLabelResponse } from "__mocks__/labelsMock";

// Default label
const label = createMockLabel();

// Override specific fields
const customLabel = createMockLabel({
  name: "Windows devices",
  platform: "windows",
  label_membership_type: "manual",
});

// Mock full API response
const labelResponse = createMockGetLabelResponse({
  label: customLabel,
});
```
