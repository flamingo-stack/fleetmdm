Provides factory functions for creating mock `ISchedulableQuery` and `IQueryStats` objects for use in tests, with sensible defaults and support for partial overrides.

## Key Components

- **`DEFAULT_QUERY_MOCK`** — Base mock object conforming to `ISchedulableQuery` with preset values for all required fields
- **`DEFAULT_QUERY_STATS_MOCK`** — Base mock object conforming to `IQueryStats` with preset performance and execution statistics
- **`createMockQuery`** *(default export)* — Factory function that merges provided overrides into `DEFAULT_QUERY_MOCK`
- **`createMockQueryStats`** — Factory function that merges provided overrides into `DEFAULT_QUERY_STATS_MOCK`

## Usage Example

```typescript
import createMockQuery, { createMockQueryStats } from "__mocks__/queryMock";

// Create a default query mock
const query = createMockQuery();

// Override specific fields
const teamQuery = createMockQuery({
  team_id: 42,
  name: "Team-Specific Query",
  automations_enabled: true,
});

// Create a default query stats mock
const stats = createMockQueryStats();

// Override specific stats fields
const activeStats = createMockQueryStats({
  executions: 500,
  last_executed: "2025-06-01T12:00:00Z",
  average_memory: 256,
});
```
