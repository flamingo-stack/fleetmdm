Provides mock data factories for Fleet MDM configuration objects used in tests and Storybook stories, covering the full `IConfig`, `ILicense`, and `IMdmConfig` interfaces.

## Key Components

- **`DEFAULT_CONFIG_MDM_MOCK`** – Internal baseline object implementing `IMdmConfig` with sensible test defaults (Apple BM enabled, Windows MDM configured, empty update deadlines, etc.)
- **`createMockMdmConfig(overrides?)`** – Factory function that merges partial `IMdmConfig` overrides onto the default MDM config
- **`DEFAULT_LICENSE_MOCK`** – Exported constant implementing `ILicense` representing a free-tier managed cloud license
- **`DEFAULT_CONFIG_MOCK`** – Internal full `IConfig` object covering org info, SMTP, SSO, webhooks, logging, vulnerabilities, MDM, and GitOps settings
- **`createMockConfig(overrides?)`** – Default export factory that merges partial `IConfig` overrides onto the default config

## Usage Example

```typescript
import createMockConfig, {
  createMockMdmConfig,
  DEFAULT_LICENSE_MOCK,
} from "__mocks__/configMock";

// Basic config with all defaults
const config = createMockConfig();

// Override specific top-level fields
const premiumConfig = createMockConfig({
  license: { ...DEFAULT_LICENSE_MOCK, tier: "premium" },
  server_settings: { server_url: "https://fleet.example.com" },
});

// Override specific MDM fields
const mdmConfig = createMockMdmConfig({
  enable_disk_encryption: true,
  windows_require_bitlocker_pin: true,
});

// Compose into a full config
const configWithMdm = createMockConfig({ mdm: mdmConfig });
```
