Provides mock data factories for operating system version objects used in tests, supporting both macOS and Linux variants with realistic default values including kernel and vulnerability data.

## Key Components

- **`createMockOSVersion`** — Creates a mock `IOperatingSystemVersion` for macOS (`darwin`), defaulting to Mac OS X 10.15.7 with a sample CPE and software vulnerability.
- **`createMockOSVersionsResponse`** — Creates a mock `IOSVersionsResponse` wrapping a single macOS version entry with pagination metadata.
- **`createMockLinuxOSVersion`** — Creates a mock `IOperatingSystemVersion` for Ubuntu 24.04.1 LTS with three kernel entries (including kernel-level CVE lists with intentional repeats to stress-test deduplication logic) and one OS-level vulnerability.
- **`createMockLinuxOSVersionsResponse`** — Creates a mock `IOSVersionsResponse` wrapping a single Linux version entry with pagination metadata.

All factories accept an optional `Partial<T>` overrides argument for targeted customization in individual test cases.

## Usage Example

```typescript
import {
  createMockOSVersion,
  createMockOSVersionsResponse,
  createMockLinuxOSVersion,
  createMockLinuxOSVersionsResponse,
} from "__mocks__/operatingSystemsMock";

// Default macOS version
const macOS = createMockOSVersion();

// Override specific fields
const customMacOS = createMockOSVersion({ hosts_count: 42, version: "14.0" });

// Full API response shape for macOS
const macOSResponse = createMockOSVersionsResponse({ count: 5 });

// Linux version with realistic kernel + CVE data
const linux = createMockLinuxOSVersion();

// Full API response shape for Linux
const linuxResponse = createMockLinuxOSVersionsResponse();
```

## Notes

- Linux mock kernels include intentionally repeated CVEs across kernel versions to support testing of vulnerability deduplication logic.
- Vulnerability data uses real CVE identifiers and NVID detail links for realistic test scenarios.
