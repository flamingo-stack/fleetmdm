Provides factory functions for creating mock software-related data objects used in tests, covering software titles, versions, packages, vulnerabilities, OS versions, app store apps, Fleet-maintained apps, and install results.

## Key Components

| Export | Returns | Description |
|--------|---------|-------------|
| `createMockSoftware` | `ISoftware` | Basic software entry with host count, version, and bundle identifier |
| `createMockSoftwareTitle` | `ISoftwareTitle` | Software title with version list and package reference |
| `createMockSoftwareTitleDetails` | `ISoftwareTitleDetails` | Detailed title info including counts and timestamps |
| `createMockSoftwareTitleVersion` | `ISoftwareTitleVersion` | Single version entry with CVE vulnerability |
| `createMockSoftwareVersion` | `ISoftwareVersion` | Full version record including CPE and vulnerability data |
| `createMockSoftwareVersionsResponse` | `ISoftwareVersionsResponse` | Paginated versions API response |
| `createMockSoftwareTitlesResponse` | `ISoftwareTitlesResponse` | Paginated titles API response |
| `createMockSoftwareVulnerability` | `ISoftwareVulnerability` | CVE entry with CVSS, EPSS, and CISA fields |
| `createMockSoftwarePackage` | `ISoftwarePackage` | macOS `.pkg` with install/uninstall scripts |
| `createMockSoftwarePackageIos` | `ISoftwarePackage` | iOS `.ipa` package with MDM configuration payload |
| `createMockAppStoreApp` | `IAppStoreApp` | macOS App Store app with install status counts |
| `createMockAppStoreAppAndroid` | `IAppStoreApp` | Android App Store app with work profile configuration |
| `createMockAppStoreAppIos` | `IAppStoreApp` | iOS App Store app with SSO MDM configuration |
| `createMockFleetMaintainedApp` | `IFleetMaintainedApp` | Minimal Fleet-maintained app entry |
| `createMockFleetMaintainedAppDetails` | `IFleetMaintainedAppDetails` | Full Fleet-maintained app with install scripts and slug |
| `createMockSoftwareInstallResult` | `ISoftwareInstallResult` | Software install result with status and script outputs |
| `createMockOSVersion` | `IOperatingSystemVersion` | macOS version entry with host count |
| `createMockOSVersionsResponse` | `IOSVersionsResponse` | Paginated OS versions API response |
| `createMockSoftwareTitleResponse` | `ISoftwareTitleResponse` | Single title API response wrapper |
| `createMockSoftwareVersionResponse` | `ISoftwareVersionResponse` | Single version API response wrapper |
| `createMockSetupExperienceSoftware` | `IGetSetupExperienceSoftwareResponse` | MDM setup experience software list response |

## Usage Example

```typescript
import {
  createMockSoftwareTitle,
  createMockSoftwarePackage,
  createMockSoftwareVulnerability,
} from "__mocks__/softwareMock";

// Use defaults directly
const title = createMockSoftwareTitle();

// Override specific fields
const appStoreTitle = createMockSoftwareTitle({
  app_store_app: createMockAppStoreApp({ platform: "darwin" }),
  software_package: null,
});

// Build a package with a custom install script
const pkg = createMockSoftwarePackage({
  name: "MyTool-2.0.pkg",
  version: "2.0.0",
  install_script: "sudo installer -pkg /tmp/MyTool.pkg -target /",
});

// Compose a high-severity vulnerability
const vuln = createMockSoftwareVulnerability({
  cve: "CVE-2024-9999",
  cvss_score: 9.8,
  cisa_known_exploit: true,
});
```

All factory functions accept an optional `Partial<T>` overrides argument, merging with sensible defaults so tests can declare only the fields relevant to the scenario under test.
