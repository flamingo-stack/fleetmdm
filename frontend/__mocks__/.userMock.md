Provides a factory function for generating mock `IUser` objects in tests, with sensible defaults that can be selectively overridden.

## Key Components

- **`DEFAULT_USER_MOCK`** – A base `IUser` object with preset test values (admin role, SSO disabled, no teams or fleets).
- **`createMockUser(overrides?)`** – Factory function that merges any partial `IUser` overrides onto the default mock and returns a complete `IUser`.

## Usage Example

```typescript
import createMockUser from "tests/mocks/userMock";

// Use default mock user
const defaultUser = createMockUser();

// Override specific fields
const ssoUser = createMockUser({ sso_enabled: true, role: "maintainer" });

// Override team membership
const teamUser = createMockUser({ teams: [{ id: 1, name: "Engineering" }] });
```

## Notes

- All overrides are shallow-merged, so nested objects (e.g., `teams`) should be passed in full if customized.
- The default user is an **admin** with `api_only: false`, `force_password_reset: false`, and empty `teams`/`fleets` arrays — suitable for most auth-related test scenarios.
