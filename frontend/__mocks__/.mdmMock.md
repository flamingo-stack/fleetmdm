Provides factory functions for creating mock MDM (Mobile Device Management) data objects used in tests, with sensible defaults that can be selectively overridden.

## Key Components

| Export | Return Type | Description |
|--------|-------------|-------------|
| `createMockMdmSolution` | `IMdmSolution` | Mock MDM solution with id, name, server URL, and host count |
| `createMockMdmSummaryMdmSolution` | `IMdmSummaryMdmSolution` | Mock MDM summary solution for host summary views |
| `createMockMdmProfile` | `IMdmProfile` | Mock MDM profile with darwin platform defaults and checksum |
| `createMockHostMdmData` | `IHostMdmData` | Mock host MDM data including enrollment status, OS settings, disk encryption, and device state |

## Usage Example

```typescript
import {
  createMockMdmSolution,
  createMockMdmProfile,
  createMockHostMdmData,
} from "__mocks__/mdmMock";

// Use defaults
const solution = createMockMdmSolution();

// Override specific fields
const enrolledHost = createMockHostMdmData({
  enrollment_status: "On (manual)",
  device_status: "locked",
  profiles: [createMockMdmProfile({ name: "Custom Policy" })],
});

// Override profile platform
const windowsProfile = createMockMdmProfile({ platform: "windows" });
```
