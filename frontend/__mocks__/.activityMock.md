Factory functions for generating mock `IActivity` and `IHostPastActivity` objects in tests, with sensible defaults and full override support.

## Key Components

- **`DEFAULT_ACTIVITY_MOCK`** — Base mock with pre-filled fields: timestamps, actor info, and `ActivityType.EditedAgentOptions` as the default type.
- **`DEFAULT_HOST_PAST_ACTIVITY_MOCK`** — Extends the base mock with `ActivityType.LockedHost` and an empty `details` object, matching the `IHostPastActivity` shape.
- **`createMockActivity(overrides?)`** — Factory that returns a full `IActivity` object, merging any provided partial overrides.
- **`createMockHostPastActivity(overrides?)`** — Factory that returns a full `IHostPastActivity` object with host-specific defaults, merging any provided overrides.

## Usage Example

```typescript
import {
  createMockActivity,
  createMockHostPastActivity,
} from "__mocks__/activityMock";
import { ActivityType } from "interfaces/activity";

// Use default mock
const activity = createMockActivity();

// Override specific fields
const customActivity = createMockActivity({
  type: ActivityType.LiveQuery,
  actor_full_name: "Jane Doe",
  actor_email: "jane@example.com",
});

// Host past activity with overrides
const hostActivity = createMockHostPastActivity({
  id: 42,
  details: { host_id: 7 },
});
```
