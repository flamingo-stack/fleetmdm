Provides factory functions for generating typed mock data used in tests related to Fleet scripts, host scripts, and batch script execution results.

## Key Components

| Export | Return Type | Description |
|--------|-------------|-------------|
| `createMockScript` | `IScript` | Creates a mock script entity |
| `createMockScriptResult` | `IScriptResultResponse` | Creates a mock script execution result |
| `createMockHostScript` | `IHostScript` | Creates a mock host-script association with last execution details |
| `createMockBatchScriptSummary` | `IScriptBatchSummaryV2` | Creates a mock batch script run summary with status counts |
| `createMockScriptBatchHostResults` | `IScriptBatchHostResultsResponse` | Creates a paginated mock response of per-host batch results, optionally filtered by status |

Each factory merges sensible defaults with an optional `Partial<T>` overrides argument, keeping test setup concise.

## Usage Example

```typescript
import {
  createMockScript,
  createMockScriptResult,
  createMockHostScript,
  createMockBatchScriptSummary,
  createMockScriptBatchHostResults,
} from "__mocks__/scriptMock";

// Override only the fields relevant to your test
const script = createMockScript({ team_id: 42, name: "deploy.sh" });

const result = createMockScriptResult({ exit_code: 1, host_timeout: true });

const hostScript = createMockHostScript({
  last_execution: {
    execution_id: "abc-456",
    executed_at: "2024-03-01T12:00:00.000Z",
    status: "errored",
  },
});

const batchSummary = createMockBatchScriptSummary({ status: "running" });

// Returns two hosts both with "errored" status
const batchHostResults = createMockScriptBatchHostResults("errored");
```
