Provides factory functions for generating mock pagination and list-entity response objects used in tests.

## Key Components

- **`createMockPaginationResponse`** — Returns a `ListEntitiesResponsePaginationCommon` mock with `has_next_results` and `has_previous_results` defaulting to `false`. Accepts optional partial overrides.
- **`createMockListEntitiesResponseCommon`** — Returns a `ListEntitiesResponseCommon` mock with a default `count` of `1` and a default pagination `meta`. Accepts optional partial overrides.

## Usage Example

```typescript
import {
  createMockPaginationResponse,
  createMockListEntitiesResponseCommon,
} from "__mocks__/commonMock";

// Default pagination response
const pagination = createMockPaginationResponse();
// { has_next_results: false, has_previous_results: false }

// Pagination with overrides
const nextPage = createMockPaginationResponse({ has_next_results: true });
// { has_next_results: true, has_previous_results: false }

// Default list entities response
const listResponse = createMockListEntitiesResponseCommon();
// { meta: { has_next_results: false, ... }, count: 1 }

// With overrides
const customListResponse = createMockListEntitiesResponseCommon({ count: 42 });
// { meta: { has_next_results: false, ... }, count: 42 }
```
