Provides factory functions for generating mock MDM setup experience API responses in tests, with sensible defaults that can be partially overridden.

## Key Components

| Export | Return Type | Description |
|--------|-------------|-------------|
| `createMockSetupExperienceScriptResponse` | `IGetSetupExperienceScriptResponse` | Mock setup experience script metadata |
| `createMockSetupExperienceSoftwareResponse` | `IGetSetupExperienceSoftwareResponse` | Mock paginated software titles list |
| `createMockBootstrapPackageMetadataResponse` | `IGetBootstrapPackageMetadataResponse` | Mock bootstrap package metadata |
| `createMockBootstrapPackageSummaryResponse` | `IGetBootstrapPackageSummaryResponse` | Mock bootstrap package installation summary counts |

## Usage Example

```typescript
import {
  createMockSetupExperienceScriptResponse,
  createMockSetupExperienceSoftwareResponse,
  createMockBootstrapPackageMetadataResponse,
  createMockBootstrapPackageSummaryResponse,
} from "__mocks__/setupExperienceMock";

// Use defaults
const script = createMockSetupExperienceScriptResponse();

// Override specific fields
const teamScript = createMockSetupExperienceScriptResponse({ team_id: 42 });

const software = createMockSetupExperienceSoftwareResponse({ count: 5 });

const packageMeta = createMockBootstrapPackageMetadataResponse({
  name: "custom-package.pkg",
  sha256: "abc123",
});

const summary = createMockBootstrapPackageSummaryResponse({
  installed: 10,
  pending: 0,
  failed: 1,
});
```

## Default Values

- **Script:** `id: 1`, no team, named `"Test Script.sh"`
- **Software:** 1 software title, no pagination neighbors
- **Bootstrap package:** `team_id: 0`, placeholder SHA-256 and token
- **Bootstrap summary:** `installed: 1`, `pending: 2`, `failed: 3`
