Utility for creating mock `AxiosError` objects in tests, providing a default error structure with optional property overrides.

## Key Components

- **`DEFAULT_AXIOS_ERROR_MOCK`** — A base mock object satisfying the `AxiosError` interface with sensible defaults (`isAxiosError: true`, generic `name` and `message`).
- **`createMockAxiosError`** — Factory function that merges the default mock with any provided overrides, returning a typed `AxiosError`.

## Usage Example

```typescript
import createMockAxiosError from "./axiosError";

// Use default mock
const defaultError = createMockAxiosError();

// Override specific fields
const notFoundError = createMockAxiosError({
  message: "Request failed with status code 404",
  response: {
    status: 404,
    data: { error: "Not found" },
  } as any,
});

// In a Jest test
jest.spyOn(apiService, "getUser").mockRejectedValue(
  createMockAxiosError({ message: "Network Error" })
);
```

## Notes

- Intended for use in unit/integration tests only — not for production code.
- The `overrides` parameter accepts any subset of `AxiosError` properties, enabling precise error scenario simulation without boilerplate.
