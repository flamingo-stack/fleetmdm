Provides factory functions and default mock data for `IHost` and related interfaces, used in unit and integration tests throughout the Fleet frontend.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `createMockHost` | Factory (default) | Creates a full `IHost` mock object with sensible defaults |
| `createMockHostMdmProfile` | Factory | Creates an `IHostMdmProfile` mock with `verified` status |
| `createMockHostGeolocation` | Factory | Creates an `IGeoLocation` mock defaulting to Minneapolis, US |
| `createMockHostResponse` | Object | Single-host API response shape |
| `createMockHostsResponse` | Factory | Multi-host API response, accepts an array of partial overrides |
| `createMockIosHostResponse` | Object | Pre-configured iOS device host response |
| `createMockHostSummary` | Factory | Returns only `HOST_SUMMARY_DATA` fields, normalized |
| `createMockHostSoftware` | Factory | Creates an `IHostSoftware` mock with a software package attached |
| `createMockHostSoftwarePackage` | Factory | Creates an `IHostSoftwarePackage` mock |
| `createMockHostAppStoreApp` | Factory | Creates an `IHostAppStoreApp` mock |
| `createMockGetHostSoftwareResponse` | Factory | Creates a paginated `IGetHostSoftwareResponse` mock |
| `createMockHostEndUser` | Factory | Creates an `IHostEndUser` mock with IDP and group data |
| `DEFAULT_HOST_HOSTNAME` | Constant | Default hostname string `"9b20fc72a247"` |
| `DEFAULT_INSTALLED_VERSION` | Constant | Reusable installed software version with CVE and path data |
| `DEFAULT_HOST_END_USER_MOCK` | Constant | Exported base end-user mock for direct use in tests |

## Usage Example

```typescript
import createMockHost, {
  createMockHostSoftware,
  createMockHostMdmProfile,
  createMockHostEndUser,
  createMockGetHostSoftwareResponse,
} from "__mocks__/hostMock";

// Basic host with overrides
const onlineHost = createMockHost({ status: "online", team_id: 3 });

// Host with MDM enrolled and a verified profile
const mdmHost = createMockHost({
  mdm: {
    ...onlineHost.mdm,
    enrollment_status: "On (automatic)",
    server_url: "https://mdm.example.com",
  },
});
const profile = createMockHostMdmProfile({ status: "failed" });

// Software response with two entries
const softwareResponse = createMockGetHostSoftwareResponse({
  count: 2,
  software: [
    createMockHostSoftware({ name: "Firefox.app" }),
    createMockHostSoftware({ name: "Chrome.app", status: "pending" }),
  ],
});

// End user mock with custom IDP group
const endUser = createMockHostEndUser({ idp_groups: ["Admins"] });
```
