Factory function for creating mock `IOsQueryTable` objects in tests, merging `DEFAULT_OSQUERY_TABLE` defaults with optional overrides.

## Key Components

- **`createMockOsqueryTable(overrides?)`** — Returns a complete `IOsQueryTable` object by spreading `DEFAULT_OSQUERY_TABLE` with any provided partial overrides.

## Usage Example

```typescript
import createMockOsqueryTable from "utilities/mocks/osqueryTableMock";

// Use defaults
const defaultTable = createMockOsqueryTable();

// Override specific fields
const customTable = createMockOsqueryTable({
  name: "users",
  description: "Local user accounts",
});
```

## Notes

- Depends on `DEFAULT_OSQUERY_TABLE` from [`interfaces/osquery_table`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/osquery_table.ts) for baseline values.
- Designed for use in unit/integration tests to avoid manually constructing full `IOsQueryTable` objects.
