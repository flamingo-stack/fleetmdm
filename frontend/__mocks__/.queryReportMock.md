Provides a factory function and default fixture for `IQueryReport` test data, simulating query results across multiple hosts with varying USB device columns.

## Key Components

- **`DEFAULT_QUERY_REPORT_MOCK`** — A static `IQueryReport` fixture containing 33 result rows spread across 8 hosts (`foo`, `bar`, `zoo`, `car`, `choo`, `moo`, `apple man`, and a long-named test host), each with `host_id`, `host_name`, `last_fetched`, and a `columns` map of USB device metadata (`model`, `vendor`, `model_id`).
- **`createMockQueryReport`** — Default export factory that shallow-merges optional overrides into the default fixture, enabling targeted customization in tests.

## Usage Example

```typescript
import createMockQueryReport from "mocks/queryReportMock";

// Use default fixture as-is
const defaultReport = createMockQueryReport();

// Override top-level fields for a specific test case
const clippedReport = createMockQueryReport({
  query_id: 99,
  report_clipped: true,
});

// Override results entirely
const emptyReport = createMockQueryReport({ results: [] });
```

> **Note:** Overrides are shallow-merged, so passing a partial `results` array replaces the entire `results` field rather than appending to it.
