Provides a mock factory for `IGetSCIMDetailsResponse`, used in tests to simulate IdP SCIM detail API responses with sensible defaults.

## Key Components

- **`DEFAULT_GET_SCIM_DETAILS_MOCK`** — Base mock object representing a successful SCIM request, including a timestamp, `"success"` status, and a descriptive message.
- **`createMockGetSCIMDetailsResponse(overrides?)`** — Factory function that merges the default mock with any provided partial overrides, returning a fully typed `IGetSCIMDetailsResponse`.

## Usage Example

```typescript
import { createMockGetSCIMDetailsResponse } from "__mocks__/idpMock";

// Use defaults
const defaultMock = createMockGetSCIMDetailsResponse();

// Override specific fields
const failedMock = createMockGetSCIMDetailsResponse({
  last_request: {
    requested_at: "2025-02-01T10:00:00Z",
    status: "error",
    details: "Failed to retrieve user information",
  },
});
```

## Notes

- Depends on `IGetSCIMDetailsResponse` from [`services/entities/idp`](https://github.com/flamingo-stack/fleetmdm/blob/main/services/entities/idp.ts).
- Follows the standard mock factory pattern used across the test suite — pass `overrides` only for fields relevant to each test case, keeping tests minimal and focused.
