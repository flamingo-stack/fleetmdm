Provides factory functions and default mock data for certificate-related entities used in tests and Storybook stories.

## Key Components

### Mock Factories

| Function | Return Type | Description |
|----------|-------------|-------------|
| `createMockHostCertificate` | `IHostCertificate` | Creates a mock host certificate with RSA-2048 defaults |
| `createMockGetHostCertificatesResponse` | `IGetHostCertificatesResponse` | Creates a mock paginated host certificates API response |
| `createMockCertificateAuthorityPartial` | `ICertificateAuthorityPartial` | Creates a mock partial CA record (DigiCert type) |
| `createMockAndroidCert` | `ICertificate` | Creates a mock Android certificate entity |

### Default Values

- **Host certificate**: SHA-256/RSA-2048 signed cert for "Test Biz" / "Test Inc.", system source
- **Certificates response**: Single certificate, no pagination (`has_next_results: false`)
- **CA partial**: DigiCert CA named "Test CA"
- **Android cert**: Linked to CA id `1`, created `2021-08-19`

## Usage Example

```typescript
import {
  createMockHostCertificate,
  createMockGetHostCertificatesResponse,
  createMockCertificateAuthorityPartial,
  createMockAndroidCert,
} from "__mocks__/certificatesMock";

// Use defaults as-is
const cert = createMockHostCertificate();

// Override specific fields for targeted test scenarios
const expiredCert = createMockHostCertificate({
  not_valid_after: "2020-01-01T00:00:00Z",
  common_name: "Expired Cert",
});

const paginatedResponse = createMockGetHostCertificatesResponse({
  meta: { has_next_results: true, has_previous_results: false },
  count: 42,
});

const customCA = createMockCertificateAuthorityPartial({ type: "ndes" });

const androidCert = createMockAndroidCert({ name: "Custom Android Cert" });
```

All factories accept an optional `Partial<T>` overrides argument, shallow-merged over the defaults via spread.
