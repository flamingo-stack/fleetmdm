Provides a factory function for generating mock Fleet license objects in tests, with sensible defaults and support for per-test overrides.

## Key Components

- **`DEFAULT_LICENSE_MOCK`** — Base license object with a `"premium"` tier, 100-device count, expiration set to `2050-01-01`, and telemetry/managed cloud disabled.
- **`License`** — Type inferred directly from `DEFAULT_LICENSE_MOCK`.
- **`createMockLicense(overrides?)`** — Factory function that merges optional partial overrides onto the default license and returns a complete `License` object.

## Usage Example

```typescript
import createMockLicense from "./licenseMock";

// Default premium license
const license = createMockLicense();

// Override specific fields
const expiredLicense = createMockLicense({
  tier: "free",
  expiration: "2020-01-01T00:00:00Z",
  device_count: 10,
});

// With managed cloud enabled
const cloudLicense = createMockLicense({ managed_cloud: true });
```
