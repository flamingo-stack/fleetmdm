Provides a factory function for generating mock `IMacadminsResponse` data used in tests, with sensible defaults for MDM enrollment and Munki version fields.

## Key Components

- **`DEFAULT_MAC_ADMINS_MOCK`** — Default mock payload including a Kandji MDM enrollment (manual, with server URL) and Munki version `1.2.3` with no issues.
- **`createMockMacAdmins`** — Factory function that merges optional overrides into the default mock, returning a complete `IMacadminsResponse` object.

## Usage Example

```typescript
import createMockMacAdmins from "tests/mocks/macAdminsMock";

// Use defaults
const defaultMock = createMockMacAdmins();

// Override specific fields
const customMock = createMockMacAdmins({
  macadmins: {
    mobile_device_management: {
      enrollment_status: "Off",
      server_url: "https://custom-mdm.example.com",
      name: "Custom MDM",
      id: 42,
    },
    munki: { version: "5.0.0" },
    munki_issues: [{ id: 1, name: "issue", type: "error" }],
  },
});
```

## Notes

- Overrides are applied at the top level of `IMacadminsResponse` via shallow spread — for nested changes, pass a complete `macadmins` object.
