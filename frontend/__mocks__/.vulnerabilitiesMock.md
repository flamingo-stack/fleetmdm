Mock data factory for vulnerability-related API responses, providing realistic test fixtures for `IVulnerability`, `IVulnerabilityResponse`, and `IVulnerabilitiesResponse` shapes used in Fleet MDM testing.

## Key Components

- **`DEFAULT_VULNERABILITY`** — Base `IVulnerability` object seeded with CVE-2022-30190, including Fleet Premium fields (`cvss_score`, `epss_probability`, `cisa_known_exploit`, etc.)
- **`DEFAULT_VULNERABILITY_DETAILS`** — Full `IVulnerabilityResponse` combining the base vulnerability with mock `os_versions` and `software` arrays
- **`DEFAULT_VULNERABILITIES_RESPONSE`** — Paginated list response containing 7 varied CVE entries with distinct scores, probabilities, and host counts
- **`createMockVulnerability`** — Factory that merges caller-supplied overrides into the default vulnerability shape
- **`createMockVulnerabilityResponse`** — Factory for single-vulnerability detail responses with OS and software context
- **`createMockVulnerabilitiesResponse`** — Factory for paginated list responses, useful for testing filtering, sorting, and pagination UI states

## Usage Example

```typescript
import {
  createMockVulnerability,
  createMockVulnerabilityResponse,
  createMockVulnerabilitiesResponse,
} from "__mocks__/vulnerabilitiesMock";

// Single vulnerability with overrides
const criticalVuln = createMockVulnerability({
  cve: "CVE-2024-99999",
  cvss_score: 9.8,
  cisa_known_exploit: true,
  hosts_count: 500,
});

// Detail view response (includes software + OS versions)
const detailResponse = createMockVulnerabilityResponse({
  vulnerability: criticalVuln,
});

// Paginated list response
const listResponse = createMockVulnerabilitiesResponse({
  count: 1,
  vulnerabilities: [criticalVuln],
});
```
