Provides factory functions for creating mock `ITeam` and `ITeamSummary` objects in tests, with sensible defaults and support for partial overrides.

## Key Components

- **`DEFAULT_MOCK_TEAM_SUMMARY`** — Base mock data for `ITeamSummary` (`id: 1`, `name: "Team 1"`)
- **`DEFAUT_TEAM_MOCK`** — Base mock data for `ITeam`, extended from the summary defaults
- **`createMockTeamSummary(overrides?)`** — Named export; returns an `ITeamSummary` merged with any provided overrides
- **`createMockTeam(overrides?)`** — Default export; returns an `ITeam` merged with any provided overrides

## Usage Example

```typescript
import createMockTeam, { createMockTeamSummary } from "mocks/teamMock";

// Use defaults
const team = createMockTeam();
// { id: 1, name: "Team 1" }

// Override specific fields
const customTeam = createMockTeam({ id: 42, name: "Engineering" });
// { id: 42, name: "Engineering" }

// Create a team summary
const summary = createMockTeamSummary({ name: "Security" });
// { id: 1, name: "Security" }
```
