Provides mock factory functions for Apple MDM-related data structures used in tests, including MDM Apple configuration, VPP token info, and VPP app records.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `createMockMdmApple` | Factory function | Creates a mock `IMdmApple` object with optional overrides |
| `createMockVppInfo` | Factory function | Creates a mock `IGetVppInfoResponse` object with optional overrides |
| `createMockVppApp` | Factory function | Creates a mock `IVppApp` object with optional overrides |

## Default Mock Values

- **MDM Apple** — `common_name: "APSP:12345"`, `serial_number: "12345"`, `renew_date: "2023-03-24"`
- **VPP Info** — `org_name: "test org"`, `location: "test location"`, `renew_date: "2024-09-19"`
- **VPP App** — `name: "Test App"`, `bundle_identifier: "com.test.app"`, `platform: "darwin"`

## Usage Example

```typescript
import {
  createMockMdmApple,
  createMockVppInfo,
  createMockVppApp,
} from "__mocks__/appleMdm";

// Use defaults
const mdmApple = createMockMdmApple();

// Override specific fields
const customVppInfo = createMockVppInfo({ org_name: "Acme Corp" });

// Partially override a VPP app
const paidApp = createMockVppApp({ name: "Pro App", added: true });
```
