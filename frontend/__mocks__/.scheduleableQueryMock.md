Provides a mock factory for `ISchedulableQuery` objects, used in frontend development and testing for schedulable query features.

## Key Components

- **`DEFAULT_SCHEDULABLE_QUERY_MOCK`** — A fully populated `ISchedulableQuery` object with realistic default values, including execution stats, platform targets, and scheduling metadata.
- **`createMockSchedulableQuery(overrides?)`** — Factory function that merges the default mock with any provided partial overrides, returning a complete `ISchedulableQuery`.

## Usage Example

```typescript
import createMockSchedulableQuery from "tests/mocks/scheduleableQueryMock";

// Use defaults
const query = createMockSchedulableQuery();

// Override specific fields
const customQuery = createMockSchedulableQuery({
  name: "Custom Query",
  interval: 86400, // Every 24 hours
  platform: "darwin",
  automations_enabled: false,
});
```

## Default Mock Values

| Field | Value |
|---|---|
| `id` | `1` |
| `name` | `"Test Query"` |
| `query` | `"SELECT * FROM users"` |
| `interval` | `43200` (12 hours) |
| `platform` | `"darwin,windows,linux"` |
| `automations_enabled` | `true` |
| `logging` | `"snapshot"` |
| `total_executions` | `5746` |
