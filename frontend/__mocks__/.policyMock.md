Provides mock data factories for `IPolicyStats` objects used in tests and Storybook stories.

## Key Components

- **`DEFAULT_POLICY_MOCK`** — A baseline `IPolicyStats` object representing a Linux ClamAV antivirus health policy, with realistic field values including host counts, timestamps, and software install metadata.
- **`createMockPolicy`** *(default export)* — Factory function that returns a complete `IPolicyStats` object, optionally deep-merged with caller-supplied overrides.
- **`createMockPoliciesResponse`** — Returns a `{ policies: IPolicyStats[] }` response object pre-populated with three cross-platform policies (macOS Gatekeeper, Windows BitLocker, and a cross-platform test policy). If overrides are provided, an additional policy built via `createMockPolicy` is appended.

## Usage Example

```typescript
import createMockPolicy, { createMockPoliciesResponse } from "tests/mocks/policyMock";

// Single policy with defaults
const policy = createMockPolicy();

// Single policy with field overrides
const criticalPolicy = createMockPolicy({
  critical: true,
  failing_host_count: 42,
  platform: "darwin",
});

// Multi-policy response (used to mock API list endpoints)
const response = createMockPoliciesResponse();
// response.policies → array of 3 policies

// Append a custom policy to the response
const responseWithExtra = createMockPoliciesResponse({
  name: "Custom Policy",
  team_id: 5,
});
// response.policies → array of 4 policies
```

## Notes

- All mock data uses `type: "dynamic"` and pre-set `next_update_ms: 3600000`.
- The `install_software` field is only present on `DEFAULT_POLICY_MOCK`; override as needed when testing software-remediation flows.
