Entry point for the Fleet MDM React application. Initializes polyfills, applies the user theme, and mounts the React component tree to the DOM.

## Key Components

- **`createRoot`** — React 18 concurrent mode renderer used to mount the app
- **`core-js/stable` / `regenerator-runtime/runtime`** — Babel polyfills for cross-browser compatibility
- **`./public-path`** — Configures the Webpack public path at runtime
- **`routes`** — Top-level router component imported from `./router`
- **`initTheme`** — Reads and applies the persisted user theme before first render to prevent flash

## Usage Example

This file is the Webpack entry point and is not imported directly. It runs automatically when the browser loads the bundled assets:

```javascript
// webpack.config.js (conceptual reference)
module.exports = {
  entry: "./index.jsx",
  // ...
};
```

At runtime the file:

1. Calls `initTheme()` to apply light/dark theme from storage
2. Locates the `#app` DOM node
3. Creates a React 18 root and renders the router

```javascript
// Equivalent runtime behavior
initTheme();
const root = createRoot(document.getElementById("app"));
root.render(routes);
```

The `typeof window !== "undefined"` guard ensures this side-effectful code is skipped in any server-side or test environments where `window` is unavailable.
