The primary authenticated layout wrapper for the Fleet MDM application, rendering the top navigation, flash notifications, command palette, and unsupported screen size overlay around page content.

## Key Components

- **`CoreLayout`** — Default export. A React layout component that composes the authenticated shell UI, consuming three contexts:
  - `AppContext` — `config` and `currentUser`
  - `NotificationContext` — `notification` and `hideFlash`
  - `TableContext` — `setResetSelectedRows`

- **`ICoreLayoutProps`** — Interface defining `children`, `router` (React Router v3 `InjectedRouter`), and `location` (pathname, search, hash, query).

- **Table row reset side effect** — A `useDeepEffect` hook watches `notification` and triggers a double-`setTimeout` pattern to reset table checkbox selections on successful actions, mitigating race conditions during table reloads.

- **`coreWrapperClassnames`** — Conditionally applies `low-width-supported` class when the current route does not require the unsupported screen size overlay.

## Usage Example

```typescript
// Typically registered as a route wrapper in the router config
import CoreLayout from "layouts/CoreLayout";

<Route component={CoreLayout}>
  <Route path="/hosts" component={ManageHostsPage} />
  <Route path="/software" component={SoftwarePage} />
</Route>
```

```typescript
// The layout renders this structure:
// <div.app-wrap>
//   <CommandPalette />
//   <UnsupportedScreenSize />   ← conditional
//   <nav.site-nav-container>
//     <SiteTopNav />
//   </nav>
//   <div.core-wrapper>
//     <FlashMessage />
//     {children}
//   </div>
// </div>
```

## Notes

- Returns `null` if `currentUser` or `config` is not yet available (pre-auth or loading state).
- Logout navigates to `paths.LOGOUT` via the injected router.
