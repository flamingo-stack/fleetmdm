A layout wrapper component for gated/authenticated views that provides flash notification support via the `NotificationContext`.

## Key Components

- **`GatedLayout`** — Default export. Wraps page content in a `.gated-layout` container and renders a full-width `FlashMessage` banner driven by the global `NotificationContext`.
- **`IGatedLayoutProps`** — Interface requiring a single `children: React.ReactNode` prop.

## Usage Example

```typescript
import GatedLayout from "components/GatedLayout";

const ProtectedPage = () => (
  <GatedLayout>
    <h1>Dashboard</h1>
    <p>Only visible to authenticated users.</p>
  </GatedLayout>
);
```

Notifications are managed externally through `NotificationContext` — no additional props are needed to display flash messages.
