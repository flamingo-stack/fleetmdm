Determines whether the unsupported screen overlay should be displayed based on the current route path, returning `false` for routes that support low-width screens.

## Key Components

- **`deviceSelfServiceRegex`** – Matches device self-service routes (`/device/<id>/self-service`)
- **`deviceIOSIPadOSRegex`** – Matches base device routes (`/device/<id>`), intended for iOS/iPadOS low-width support
- **`lowWidthSupportedPathsRegex`** – Array of route patterns exempt from the unsupported screen overlay
- **`shouldShowUnsupportedScreen`** – Default export; returns `true` if the given path should display the unsupported screen overlay, `false` if the path is low-width compatible

## Usage Example

```typescript
import shouldShowUnsupportedScreen from "./helpers";

const pathname = "/device/abc123/self-service";

if (shouldShowUnsupportedScreen(pathname)) {
  // Render unsupported screen overlay
} else {
  // Render normal content (low-width supported path)
}
```

## Notes

- Uses `url_prefix` from the router module to ensure regexes respect any configured base path
- To add new low-width-supported routes, append additional regex patterns to `lowWidthSupportedPathsRegex`
