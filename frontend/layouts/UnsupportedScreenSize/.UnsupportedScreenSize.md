A simple React component that renders a fallback UI when the user's screen or browser window is too small to support the application interface.

## Key Components

- **`UnsupportedScreenSize`** — Default exported functional component that displays an image and instructional message prompting the user to resize their browser or switch to a larger device.
- **`smallScreenImage`** — A 2x resolution PNG asset (`160x80`) used as a visual indicator for the unsupported screen state.
- **`baseClass`** — BEM-style CSS class namespace (`unsupported-screen-size`) applied to the root `div` and child text container.

## Usage Example

```typescript
import UnsupportedScreenSize from "components/UnsupportedScreenSize";

const App = () => {
  const isScreenTooSmall = useWindowWidth() < 768;

  if (isScreenTooSmall) {
    return <UnsupportedScreenSize />;
  }

  return <MainLayout />;
};
```

## Notes

- The component is purely presentational with no props or internal state.
- Styling is expected to be handled externally via the `unsupported-screen-size` CSS class and its `__text` modifier.
- The image includes an `alt` attribute for accessibility compliance.
