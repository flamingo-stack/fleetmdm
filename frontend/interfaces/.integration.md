Defines TypeScript types and interfaces for third-party ticketing and calendar integrations (Jira, Zendesk, Google Calendar) used across global and team-level MDM configurations.

## Key Components

| Export | Description |
|---|---|
| `IIntegrationType` | Union type limiting integration types to `"jira"` or `"zendesk"` |
| `IJiraIntegration` | Jira-specific config: URL, username, API token, project key, and optional policy/vuln triggers |
| `IZendeskIntegration` | Zendesk-specific config: URL, email, API token, group ID, and optional policy/vuln triggers |
| `IIntegration` | Merged/normalized integration shape used internally, with UI metadata (`tableIndex`, `dropdownIndex`) |
| `IIntegrationFormData` | Form field values for creating/editing an integration (camelCase) |
| `IIntegrationTableData` | Extends `IIntegrationFormData` with display metadata for table rows |
| `IIntegrationFormErrors` | Validation error state keyed to each form field |
| `IGlobalCalendarIntegration` | Google Calendar integration config using a domain and service account JSON key |
| `IZendeskJiraIntegrations` | Coupled container for Zendesk and Jira arrays (both must be present together) |
| `IGlobalIntegrations` | Global-level integrations including optional Google Calendar and conditional access flag |
| `ITeamIntegrations` | Team-level integrations with per-team calendar settings and conditional access flag |

## Usage Example

```typescript
import {
  IGlobalIntegrations,
  IIntegrationFormData,
  IIntegrationType,
} from "interfaces/integration";

// Constructing form data for a new Jira integration
const formData: IIntegrationFormData = {
  url: "https://myorg.atlassian.net",
  username: "admin@myorg.com",
  apiToken: "my-secret-token",
  projectKey: "OPS",
  enableSoftwareVulnerabilities: true,
};

// Reading global integrations from API response
const integrations: IGlobalIntegrations = {
  jira: [{ url: "https://myorg.atlassian.net", username: "admin@myorg.com", api_token: "token", project_key: "OPS" }],
  zendesk: [],
  google_calendar: [{ domain: "myorg.com", api_key_json: { type: "service_account" } }],
  conditional_access_enabled: false,
};

const type: IIntegrationType = "jira";
```

> **Note:** `IZendeskJiraIntegrations` treats Jira and Zendesk as a coupled pair — if one is provided, both fields must be present. `google_calendar` is independent and will not nullify the ticketing integrations if omitted.
