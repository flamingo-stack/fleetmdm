Defines TypeScript interfaces, types, and legacy PropTypes for Fleet MDM policy objects, covering policy data shapes for API responses, form submissions, host-level status, and aggregate statistics.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `default` | `PropTypes.shape` | Legacy PropTypes validator for policy objects used on host interfaces |
| `IPolicy` | Interface | Core policy data structure including automation, label filtering, and conditional access fields |
| `IPolicyStats` | Interface | Extends `IPolicy` with host pass/fail counts, webhook state, and update metadata |
| `IHostPolicy` | Interface | Extends `IPolicy` with per-host `response` status (`pass`, `fail`, or empty) |
| `IPolicyFormData` | Interface | Form submission shape for creating or updating policies, including script and label selectors |
| `IPolicySoftwareToInstall` | Interface | Software installation payload linked to a policy automation |
| `IPolicyNew` | Interface | Minimal shape for creating a new policy |
| `OtherAutomationType` | Type | Union: `"webhook"` or `"ticket"` |
| `PolicyStatusResponse` | Type | Union: `"pass"`, `"fail"`, or `""` |

## Usage Example

```typescript
import type {
  IPolicy,
  IPolicyStats,
  IHostPolicy,
  IPolicyFormData,
  PolicyStatusResponse,
} from "interfaces/policy";

// Checking a host-level policy response
const hostPolicy: IHostPolicy = {
  ...policy,
  response: "fail" as PolicyStatusResponse,
};

// Submitting a policy form with label filters and script automation
const formData: IPolicyFormData = {
  name: "Require FileVault",
  query: "SELECT 1 FROM filevault_status WHERE status = 'FileVault is On';",
  platform: "darwin",
  critical: true,
  script_id: 42,
  labels_include_all: ["macOS Managed Devices"],
  calendar_events_enabled: false,
  conditional_access_enabled: true,
};

// Aggregate stats from the manage policies page
const stats: IPolicyStats = {
  ...policy,
  passing_host_count: 120,
  failing_host_count: 8,
  has_run: true,
  next_update_ms: 3600000,
  webhook: "",
  host_count_updated_at: "2024-01-15T10:00:00Z",
};
```
