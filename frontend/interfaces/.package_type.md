Defines and exports package type constants, union types, and type-guard functions for all supported software package formats across Windows, Unix/macOS, iOS/iPadOS, and script-only deployment targets.

## Key Components

### Constants
- **`packageTypes`** — Combined readonly tuple of all supported package extensions (`pkg`, `deb`, `rpm`, `dmg`, `zip`, `tar.gz`, `msi`, `exe`, `sh`, `ps1`, `ipa`)

### Types
| Type | Values |
|------|--------|
| `WindowsPackageType` | `msi`, `exe`, `zip` |
| `UnixPackageType` | `pkg`, `deb`, `rpm`, `dmg`, `zip`, `tar.gz` |
| `FleetMaintainedPackageType` | `dmg`, `zip` |
| `ScriptOnlyPackageType` | `sh`, `ps1` |
| `IosIpadosPackageType` | `ipa` |
| `PackageType` | Union of all above types |

### Type Guards
- **`isWindowsPackageType(s)`** — Narrows `any` to `WindowsPackageType`
- **`isUnixPackageType(s)`** — Narrows `any` to `UnixPackageType`
- **`isFleetMaintainedPackageType(s)`** — Narrows `any` to `FleetMaintainedPackageType`
- **`isIosIpadosPackageType(s)`** — Narrows `any` to `IosIpadosPackageType`
- **`isPackageType(s)`** — Narrows `any` to the full `PackageType` union

## Usage Example

```typescript
import {
  isWindowsPackageType,
  isPackageType,
  PackageType,
} from "./package_type";

const ext = getFileExtension(uploadedFile); // e.g. "msi"

if (isWindowsPackageType(ext)) {
  // ext is narrowed to WindowsPackageType
  handleWindowsInstaller(ext);
} else if (isPackageType(ext)) {
  // ext is narrowed to the full PackageType union
  handleGenericPackage(ext);
} else {
  throw new Error(`Unsupported package type: ${ext}`);
}
```
