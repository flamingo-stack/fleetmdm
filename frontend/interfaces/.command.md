Defines TypeScript types and interfaces for MDM (Mobile Device Management) command representations, bridging the original MDM protocol status values with Fleet's internal status model.

## Key Components

- **`CommandStatus`** — Union type representing the original MDM protocol command statuses: `"Pending"`, `"Acknowledged"`, `"Error"`, `"NotNow"`
- **`FleetCommandStatus`** — Union type representing Fleet's normalized command statuses: `"ran"`, `"pending"`, `"failed"`
- **`ICommand`** — Interface for a command record as displayed in Fleet, including host/command identifiers, dual status fields, timestamps, and an optional profile name
- **`ICommandResult`** — Interface for the raw MDM command result returned by the Fleet API, including Base64-encoded `payload` (request) and `result` (response), and optional `results_metadata` for command-specific data (e.g., VPP install metadata)

## Usage Example

```typescript
import { ICommand, ICommandResult, CommandStatus, FleetCommandStatus } from "./command";

const command: ICommand = {
  host_uuid: "abc-123",
  command_uuid: "cmd-456",
  status: "Acknowledged",       // Original MDM protocol status
  command_status: "ran",        // Fleet-normalized status
  updated_at: "2024-01-15T10:00:00Z",
  request_type: "InstallProfile",
  hostname: "macbook-pro-01",
  name: "WiFi Configuration",   // macOS profile name, if applicable
};

const result: ICommandResult = {
  host_uuid: "abc-123",
  command_uuid: "cmd-456",
  status: "Acknowledged",
  updated_at: "2024-01-15T10:00:00Z",
  request_type: "InstallProfile",
  hostname: "macbook-pro-01",
  payload: "PD94bWwgdm...",  // Base64-encoded MDM request
  result: "PD94bWwgdm...",   // Base64-encoded MDM response
  name: "WiFi Configuration",
  results_metadata: { software_installed: true, vpp_verify_timeout_seconds: 60 },
};
```

## Notes

- `ICommandResult.status` is typed as `string` (not `CommandStatus`) to accommodate both Apple MDM string values and Windows HTTP status codes (e.g., `200`, `400`)
- The `name` field on both interfaces is `null` for non-profile commands and populated for macOS profile install/remove operations
