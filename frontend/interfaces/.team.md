Defines TypeScript interfaces, types, and utility constants for Fleet team entities, including team structure, MDM configuration, automation settings, and user/secret management shapes.

## Key Components

### Interfaces & Types

| Export | Description |
|--------|-------------|
| `ITeamSummary` | Minimal team shape: `id`, `name`, optional `description` and `host_count` |
| `ITeam` | Full team entity extending `ITeamSummary` with MDM config, agent options, secrets, and host expiry settings |
| `ITeamWebhookSettings` | Subset of `IWebhookSettings` for vulnerabilities, failing policies, and host status webhooks |
| `ITeamAutomationsConfig` | Combines `ITeamWebhookSettings` with `ITeamIntegrations` |
| `ITeamConfig` | Full team config: `ITeam & ITeamAutomationsConfig` |
| `INewTeamUser` / `INewTeamUsersFormData` | Shapes for adding users to a team via API |
| `IRemoveTeamUserFormData` | Shape for removing users from a team |
| `INewTeamSecretFormData` / `IRemoveTeamSecretFormData` | Shapes for managing enroll secrets on a team |

### Constants

| Constant | Value | Purpose |
|----------|-------|---------|
| `API_ALL_TEAMS_ID` | `undefined` | Sentinel for "all teams" in API calls |
| `APP_CONTEXT_ALL_TEAMS_ID` | `-1` | UI context ID representing all teams |
| `APP_CONTEXT_ALL_TEAMS_SUMMARY` | `{ id: -1, name: "All fleets" }` | Summary object for the all-teams context |
| `API_NO_TEAM_ID` / `APP_CONTEXT_NO_TEAM_ID` | `0` | Sentinel for unassigned/no-team |
| `APP_CONTEXT_NO_TEAM_SUMMARY` | `{ id: 0, name: "Unassigned" }` | Summary object for the no-team context |

### Utility Functions

- **`isAnyTeamSelected(currentTeamId?)`** — Returns `true` if a specific team (not "no team") is selected.
- **`getTeamDisplayName(team)`** — Returns `"Unassigned"` for team ID `0`, otherwise the team's name.
- **`getFleetDisplayName(fleet)`** — Same resolution logic applied to `ITokenFleet` entities.

## Usage Example

```typescript
import {
  ITeam,
  ITeamSummary,
  isAnyTeamSelected,
  getTeamDisplayName,
  APP_CONTEXT_NO_TEAM_SUMMARY,
  APP_CONTEXT_ALL_TEAMS_SUMMARY,
} from "interfaces/team";

// Check if a specific team is selected
const teamId = 3;
if (isAnyTeamSelected(teamId)) {
  console.log("A specific team is active");
}

// Resolve display names from token data
const displayName = getTeamDisplayName({ team_id: 0, name: "Engineering" });
// => "Unassigned"

const activeTeamName = getTeamDisplayName({ team_id: 5, name: "Engineering" });
// => "Engineering"

// Use sentinel summaries in dropdowns
const options: ITeamSummary[] = [
  APP_CONTEXT_ALL_TEAMS_SUMMARY, // { id: -1, name: "All fleets" }
  APP_CONTEXT_NO_TEAM_SUMMARY,   // { id: 0,  name: "Unassigned" }
];
```
