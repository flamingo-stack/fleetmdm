Defines TypeScript interfaces and utilities for operating system data within the Fleet MDM platform, covering OS versions, kernel tracking, vulnerability associations, and display formatting.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IOperatingSystemKernels` | Interface | Kernel metadata including software version ID, version string, vulnerability list, and host count |
| `IOperatingSystemVersion` | Interface | Full OS version record with platform, CPEs, vulnerabilities, and associated kernels |
| `IVulnerabilityOSVersion` | Type | Variant of `IOperatingSystemVersion` omitting `vulnerabilities`, adding `resolved_in_version` for vulnerability context views |
| `OS_VENDOR_BY_PLATFORM` | Constant | Maps platform keys (`darwin`, `windows`) to vendor display names |
| `OS_END_OF_LIFE_LINK_BY_PLATFORM` | Constant | Maps platform keys to end-of-life reference URLs |
| `formatOperatingSystemDisplayName` | Function | Normalizes OS display names (e.g. strips "Microsoft" prefix from Windows names) |

## Usage Example

```typescript
import {
  IOperatingSystemVersion,
  OS_VENDOR_BY_PLATFORM,
  OS_END_OF_LIFE_LINK_BY_PLATFORM,
  formatOperatingSystemDisplayName,
} from "./operating_system";

const osVersion: IOperatingSystemVersion = {
  os_version_id: 42,
  name: "Microsoft Windows 11 22H2",
  name_only: "Windows 11",
  version: "22H2",
  platform: "windows",
  hosts_count: 120,
  vulnerabilities: [],
  kernels: [],
};

// Normalize display name: "Windows 11 22H2"
const displayName = formatOperatingSystemDisplayName(osVersion.name);

// Look up vendor and EOL link for the platform
const vendor = OS_VENDOR_BY_PLATFORM[osVersion.platform]; // "Microsoft"
const eolLink = OS_END_OF_LIFE_LINK_BY_PLATFORM[osVersion.platform];
// "https://endoflife.date/windows"
```
