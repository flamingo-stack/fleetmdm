Defines PropTypes validation and TypeScript interfaces for Fleet MDM target entities (hosts, labels, and teams) used across query, policy, and pack targeting workflows.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `default` | `PropTypes` | Combined PropTypes validator accepting host, label, or team shapes |
| `ITarget` | Union type | `IHost \| ILabel \| ITeam` |
| `ITargets` | Interface | Grouped arrays of hosts, labels, and teams |
| `ITargetsAPIResponse` | Interface | API response shape including target counts and status breakdowns |
| `ISelectHost` / `ISelectLabel` / `ISelectTeam` | Interfaces | Extended target types with `target_type`, `display_text`, and UI-specific fields for select inputs |
| `ISelectTargetsEntity` | Union type | Combined select entity type for target picker components |
| `ISelectedTargetsForApi` | Interface | ID arrays (numbers) for submitting targets to the API |
| `ISelectedTargetsByType` | Interface | Full entity arrays grouped by type for internal state |
| `IPackTargets` | Interface | Pack-specific target ID arrays supporting both `number` and `string` IDs |
| `DEFAULT_TARGETS` | Constant | Empty `ITarget[]` default value |
| `DEFAULT_TARGETS_BY_TYPE` | Constant | Empty grouped targets default value |

## Usage Example

```typescript
import { ISelectedTargetsForApi, DEFAULT_TARGETS_BY_TYPE } from "interfaces/target";

// Initialize local targeting state
const [selectedTargets, setSelectedTargets] = useState(DEFAULT_TARGETS_BY_TYPE);

// Transform selected entities into API payload
const targetsForApi: ISelectedTargetsForApi = {
  hosts: selectedTargets.hosts.map((h) => h.id),
  labels: selectedTargets.labels.map((l) => l.id),
  teams: selectedTargets.teams.map((t) => t.id),
};
```
