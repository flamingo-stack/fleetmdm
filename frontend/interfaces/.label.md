Defines PropTypes validation shape and TypeScript interfaces for Fleet MDM label entities, covering label types, membership types, and host vitals criteria structures.

## Key Components

### PropTypes Export (default)
Runtime prop validation shape for label objects used in React components.

### Type Aliases
- **`LabelType`** — `"regular" | "builtin"`
- **`LabelMembershipType`** — `"dynamic" | "manual" | "host_vitals"`
- **`LabelMembershipTypeToDisplayCopy`** — Record mapping `LabelMembershipType` values to display strings
- **`LabelHostVitalsCriterion`** — Supported vitals criteria keys (`"end_user_idp_group"` | `"end_user_idp_department"`)
- **`LabelHostVitalsCriteria`** — Recursive tree type supporting leaf, `and`, and `or` criterion nodes

### Interfaces
- **`ILabelSummary`** — Minimal label shape (`id`, `name`, `description`, `label_type`)
- **`ILabel`** — Full label entity extending `ILabelSummary`; includes membership type, dynamic query/platform fields, host vitals criteria, and manual host IDs
- **`ILabelSoftwareTitle`**, **`ILabelQuery`**, **`ILabelPolicy`** — Slim reference shapes for cross-entity associations
- **`ILabelSpecResponse`** — API response envelope for label spec endpoints (maps to `fleet/server/fleet/labels.go > LabelSpec`)

## Usage Example

```typescript
import type {
  ILabel,
  ILabelSummary,
  LabelMembershipType,
  LabelMembershipTypeToDisplayCopy,
  LabelHostVitalsCriteria,
} from "interfaces/label";

// Render membership type as human-readable copy
const displayType = (type: LabelMembershipType): string =>
  LabelMembershipTypeToDisplayCopy[type];

// Type-narrow a host vitals criteria tree
function isLeafCriterion(
  c: LabelHostVitalsCriteria
): c is { vital: string; value: string } {
  return "vital" in c;
}

// Work with a full label object
const label: ILabel = fetchedLabel;
if (label.label_membership_type === "host_vitals" && label.criteria) {
  console.log(isLeafCriterion(label.criteria));
}
```

- `count` and `hosts_count` appear to be duplicates — tracked in [issue #1618](https://github.com/flamingo-stack/fleetmdm/issues/1618)
- `host_count` is only returned for built-in labels, not custom labels
- `team_name` is available on individual label endpoints but not list endpoints
