Defines shared PropTypes validator and TypeScript interfaces for form field components used across the Fleet MDM UI.

## Key Components

- **Default Export** — PropTypes shape validator enforcing `error`, `name`, `onChange`, and `value` (array | bool | number | string) on any form field component.
- **`IFormField<T>`** — Generic interface describing the standard props contract for all form fields.
- **`IInputFieldParseTarget<T>`** — Describes the `{ name, value }` object shape emitted by `InputField` when `parseTarget` is enabled.
- **`InputFieldOnChange<T>`** — Union type representing both `onChange` signatures: plain value or parsed target object.

## Usage Example

```typescript
import formFieldInterface, { IFormField, InputFieldOnChange } from "components/forms/form_field";

// Typed form field component props
interface MyFieldProps extends IFormField<string> {
  label: string;
}

// Handler that works with both onChange signatures
const handleChange: InputFieldOnChange<string> = (valueOrEvent) => {
  if (typeof valueOrEvent === "object" && "name" in valueOrEvent) {
    // parseTarget mode: { name, value }
    console.log(valueOrEvent.name, valueOrEvent.value);
  } else {
    // default mode: raw value
    console.log(valueOrEvent);
  }
};

// PropTypes usage in a legacy component
MyLegacyComponent.propTypes = {
  field: formFieldInterface,
};
```

## Notes

- The generic `T` on `IFormField` defaults to `any[] | boolean | number | string`, matching the PropTypes definition.
- `InputFieldOnChange` is a union rather than an overload, so callers should narrow the argument type when `parseTarget` behavior is needed.
