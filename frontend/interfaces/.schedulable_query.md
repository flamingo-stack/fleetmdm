Defines TypeScript interfaces and types for schedulable queries in the Fleet MDM platform, covering query data shapes, API request/response contracts, form fields, and performance impact indicators.

## Key Components

- **`ISchedulableQuery`** – Core query entity with scheduling config (`interval`, `platform`, `automations_enabled`), authorship, stats, and label targeting fields
- **`IEnhancedQuery`** – Extends `ISchedulableQuery` with computed `performance` and `targetedPlatforms` fields for UI display
- **`ISchedulableQueryStats`** – Performance percentile metrics (`user_time_p50/p95`, `system_time_p50/p95`, `total_executions`)
- **`PerformanceImpactIndicatorValue`** – Const enum of performance ratings: `Minimal`, `Considerable`, `Excessive`, `Undetermined`, `Denylisted`
- **`isPerformanceImpactIndicator`** – Type guard for validating `PerformanceImpactIndicator` values
- **API shapes** – `IGetQueryResponse`, `IListQueriesResponse`, `ICreateQueryFormData`, `IEditQueryFormData`, `IDeleteQueryFormData`, `IDeleteQueriesFormData`, `IDeleteQueriesResponse`
- **`IQueryKeyQueriesLoadAll`** – Query key shape for list queries with pagination, filtering, and platform targeting
- **`IEditQueryFormFields`** – Form field wrappers for the query editor UI
- **`QueryLoggingOption`** – Union type: `"snapshot"` | `"differential"` | `"differential_ignore_removals"`

## Usage Example

```typescript
import {
  ISchedulableQuery,
  ICreateQueryFormData,
  PerformanceImpactIndicatorValue,
  isPerformanceImpactIndicator,
  QueryLoggingOption,
} from "interfaces/schedulable_query";

// Create a new query payload
const newQuery: ICreateQueryFormData = {
  name: "Running Processes",
  query: "SELECT * FROM processes;",
  interval: 3600,
  platform: "darwin,linux",
  logging: "snapshot" as QueryLoggingOption,
  automations_enabled: true,
};

// Check performance impact
const impact = PerformanceImpactIndicatorValue.MINIMAL;
if (isPerformanceImpactIndicator(impact)) {
  console.log(`Performance: ${impact}`);
}
```
