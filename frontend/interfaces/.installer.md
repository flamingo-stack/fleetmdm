Defines types and lookup maps for Fleet agent installer formats across supported platforms.

## Key Components

- **`IInstallerType`** — Union type for installer package formats: `"pkg"`, `"msi"`, `"rpm"`, `"deb"`
- **`IInstallerPlatform`** — Union type for supported OS platforms: `"Windows"`, `"macOS"`, `"Linux (RPM)"`, `"Linux (deb)"`
- **`INSTALLER_TYPE_BY_PLATFORM`** — Record mapping each platform to its corresponding installer type
- **`INSTALLER_PLATFORM_BY_TYPE`** — Reverse lookup record mapping each installer type back to its platform

## Usage Example

```typescript
import {
  INSTALLER_TYPE_BY_PLATFORM,
  INSTALLER_PLATFORM_BY_TYPE,
  IInstallerPlatform,
  IInstallerType,
} from "./installer";

// Get installer type for a given platform
const platform: IInstallerPlatform = "macOS";
const installerType = INSTALLER_TYPE_BY_PLATFORM[platform]; // "pkg"

// Reverse lookup: get platform from installer type
const type: IInstallerType = "msi";
const resolvedPlatform = INSTALLER_PLATFORM_BY_TYPE[type]; // "Windows"
```
