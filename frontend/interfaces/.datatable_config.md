Defines reusable TypeScript types for building data tables with `react-table`, providing typed wrappers for columns, cells, and headers.

## Key Components

| Export | Description |
|--------|-------------|
| `IDataColumn` | Extended `Column` type with additional metadata fields (`title`, `disableHidden`, `disableSortBy`, `filterValue`, etc.) |
| `IColumnConfig<T>` | Generic wrapper around `react-table`'s `Column<T>` for typed column configurations |
| `IStringCellProps<T>` | Typed cell props wrapper for string cell values |
| `INumberCellProps<T>` | Typed cell props wrapper for number cell values |
| `IBoolCellProps<T>` | Typed cell props wrapper for boolean cell values |
| `IHeaderProps<T>` | Typed wrapper around `react-table`'s `HeaderProps<T>` |
| `IWebSocketData` | Loose `Record<string, unknown>` type for unstructured WebSocket payloads |

## Usage Example

```typescript
import {
  IColumnConfig,
  IStringCellProps,
  INumberCellProps,
  IDataColumn,
} from "./datatable_config";

interface IHost {
  name: string;
  id: number;
}

// Define typed column configurations for a host table
type IHostColumnConfig = IColumnConfig<IHost>;

const nameColumn: IHostColumnConfig = {
  Header: "Name",
  accessor: "name",
  Cell: ({ cell: { value } }: IStringCellProps<IHost>) => (
    <span>{value}</span>
  ),
};

const idColumn: IHostColumnConfig = {
  Header: "ID",
  accessor: "id",
  Cell: ({ cell: { value } }: INumberCellProps<IHost>) => (
    <span>{value}</span>
  ),
};

// Use IDataColumn for legacy or untyped table definitions
const legacyColumn: IDataColumn = {
  Header: "Status",
  accessor: "status",
  title: "Host Status",
  disableSortBy: true,
};
```

## Notes

- `IColumnConfig<T>` is the preferred type for new tables; use `IDataColumn` when additional metadata fields are needed.
- `IWebSocketData` intentionally uses a loose type (`Record<string, unknown>`) since WebSocket payloads are not guaranteed to have a consistent shape.
