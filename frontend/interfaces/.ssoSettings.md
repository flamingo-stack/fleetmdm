Defines PropTypes validation shape and TypeScript interface for SSO (Single Sign-On) configuration settings used across the Fleet MDM application.

## Key Components

- **Default Export** – A `PropTypes.shape` validator for SSO settings, used in React component prop validation
- **`ISSOSettings`** – TypeScript interface defining the SSO settings contract

### `ISSOSettings` Interface

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `idp_image_url` | `string` | No | URL for the Identity Provider logo/image |
| `idp_name` | `string` | No | Display name of the Identity Provider |
| `sso_enabled` | `boolean` | **Yes** | Whether SSO authentication is enabled |

## Usage Example

```typescript
import ssoSettingsPropTypes, { ISSOSettings } from "./ssoSettings";

// TypeScript interface usage
const settings: ISSOSettings = {
  idp_name: "Okta",
  idp_image_url: "https://example.com/okta-logo.png",
  sso_enabled: true,
};

// PropTypes usage in a React component
MyComponent.propTypes = {
  ssoSettings: ssoSettingsPropTypes,
};
```
