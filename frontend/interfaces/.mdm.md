Defines TypeScript interfaces, types, and utility functions for MDM (Mobile Device Management) integration, covering enrollment status, profiles, disk encryption, Apple/VPP tokens, and bootstrap packages.

## Key Components

### Interfaces
- **`IMdmApple`** / **`IMdmAppleBm`** — Apple MDM certificate and Business Manager configuration
- **`IMdmAbToken`** / **`IMdmVppToken`** — Apple Business and Volume Purchase Program token structures, including per-platform fleet assignments
- **`IMdmProfile`** / **`IHostMdmProfile`** — MDM configuration profiles with label targeting and per-host profile status
- **`IMdmSummaryResponse`** / **`IMdmAggregateStatus`** — Enrollment count aggregates returned from the API
- **`IBootstrapPackageMetadata`** / **`IBootstrapPackageAggregate`** — macOS bootstrap package info and deployment status counts

### Types & Enums
- **`MdmEnrollmentStatus`** — Raw API enrollment values (`"On (manual)"`, `"On (automatic)"`, `"Off"`, etc.)
- **`MdmEnrollmentFilterValue`** — Query string filter values for enrollment status
- **`DiskEncryptionStatus`** / **`WindowsDiskEncryptionStatus`** / **`LinuxDiskEncryptionStatus`** — Platform-scoped disk encryption states
- **`BootstrapPackageStatus`** / **`EndUserLocalAccountType`** — Enums for package deployment and local account type
- **`ProfilePlatform`** — Supported MDM profile platforms: `darwin`, `windows`, `ios`, `ipados`, `linux`, `android`

### Constants & Maps
- **`MDM_ENROLLMENT_STATUS_UI_MAP`** — Maps raw API enrollment statuses to display names and filter values (e.g., `"On (automatic)"` → `"On (company-owned)"`)
- **`FLEET_FILEVAULT_PROFILE_DISPLAY_NAME`**, **`FLEET_RECOVERY_LOCK_PASSWORD_DISPLAY_NAME`**, **`FLEET_ANDROID_CERTIFICATE_TEMPLATE_PROFILE_ID`** — Display name constants

### Utility Functions
- **`getMdmServerUrl`** — Constructs the MDM server URL from server settings
- **`isEnrolledInMdm`** — Type guard for active enrollment status
- **`isWindowsDiskEncryptionStatus`** / **`isLinuxDiskEncryptionStatus`** — Platform-specific disk encryption type guards
- **`isBYODManualEnrollment`**, **`isBYODAccountDrivenUserEnrollment`**, **`isAutomaticDeviceEnrollment`** — Enrollment mode checks
- **`isAndroidBYO`** / **`isAndroidCOBO`** — Android-specific enrollment mode checks

## Usage Example

```typescript
import {
  MdmEnrollmentStatus,
  MDM_ENROLLMENT_STATUS_UI_MAP,
  isEnrolledInMdm,
  isAutomaticDeviceEnrollment,
  isWindowsDiskEncryptionStatus,
} from "./mdm";

// Resolve display name and filter value for a raw API status
const apiStatus: MdmEnrollmentStatus = "On (automatic)";
const { displayName, filterValue } = MDM_ENROLLMENT_STATUS_UI_MAP[apiStatus];
// displayName → "On (company-owned)", filterValue → "automatic"

// Type guard: check if host is actively enrolled
if (isEnrolledInMdm(apiStatus)) {
  console.log("Host is enrolled");
}

// Check for ADE/DEP enrollment
if (isAutomaticDeviceEnrollment(apiStatus)) {
  console.log("Host enrolled via Automated Device Enrollment");
}

// Narrow disk encryption status to Windows-specific values
const encStatus = "enforcing";
if (isWindowsDiskEncryptionStatus(encStatus)) {
  // encStatus is now typed as WindowsDiskEncryptionStatus
  console.log("Windows encryption in progress");
}
```
