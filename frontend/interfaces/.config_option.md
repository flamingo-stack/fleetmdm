Defines and exports a reusable PropTypes shape for validating configuration option objects passed as props in React components.

## Key Components

- **Default Export** — A `PropTypes.shape` validator describing the structure of a single configuration option with the following fields:

| Field | Type | Required |
|-------|------|----------|
| `id` | `number` | No |
| `name` | `string` | **Yes** |
| `value` | `string \| number \| bool` | No |
| `read_only` | `bool` | No |
| `type` | `string` | No |

## Usage Example

```javascript
import PropTypes from "prop-types";
import configOptionInterface from "./config_option";

const MyComponent = ({ option }) => (
  <div>{option.name}: {option.value}</div>
);

MyComponent.propTypes = {
  option: configOptionInterface.isRequired,
};
```
