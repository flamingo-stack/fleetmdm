Defines TypeScript interfaces and PropTypes for live query campaign data, modeling the real-time state of Fleet's websocket-driven query execution including host results, error tracking, and campaign metrics.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `default` | PropTypes shape | Runtime prop validation for campaign UI host counts and identifiers |
| `ICampaign` | Interface | Core campaign object combining server-reported totals, UI-constructed result arrays, and websocket status |
| `ICampaignError` | Interface | Per-host error record with display name, osquery version, and error message |
| `IUIHostCounts` | Interface | UI-tracked aggregate counts (total, successful, failed) built from streaming websocket messages |
| `IServerHostCounts` | Interface | Server-reported host counts distinguishing results vs. no-results hosts |
| `IHostWithQueryResults` | Interface | Extends `IHost` with an array of query result rows |
| `ICampaignState` | Interface | Legacy component state wrapper for a running campaign (flagged for review) |
| `QueryResults` | Type alias | `Record<string, unknown>[]` — rows returned from an osquery execution |

## Usage Example

```typescript
import { ICampaign, ICampaignError, IUIHostCounts } from "interfaces/campaign";

// Initializing a fresh campaign state
const uiHostCounts: IUIHostCounts = {
  total: 0,
  successful: 0,
  failed: 0,
};

// Handling an incoming "result"-type websocket message
function handleCampaignError(
  campaign: ICampaign,
  error: ICampaignError
): ICampaign {
  return {
    ...campaign,
    errors: [...campaign.errors, error],
    uiHostCounts: {
      ...campaign.uiHostCounts,
      total: campaign.uiHostCounts.total + 1,
      failed: campaign.uiHostCounts.failed + 1,
    },
  };
}
```

> **Note:** `ICampaign` intentionally uses broad typing on `Metrics` and `query_results` because upstream websocket payloads are untyped. `uiHostCounts.successful` excludes ChromeOS hosts with partial results. `ICampaignState` is marked for legacy review — prefer `ICampaign` directly in new code.
