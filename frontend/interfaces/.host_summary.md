Defines TypeScript interfaces for host summary data returned by the Fleet MDM API, including platform breakdowns and host status counts.

## Key Components

- **`IHostSummaryPlatforms`** — Represents per-platform host counts with `platform` (string) and `hosts_count` (number).
- **`IHostSummary`** — Aggregated host summary including:
  - `totals_hosts_count` / `all_linux_count` — Total and Linux-specific host counts
  - `online_count` / `offline_count` / `new_count` — Host connectivity status counts
  - `missing_30_days_count` / `low_disk_space_count` / `dep_assign_error_count` — Optional premium-only metrics
  - `mia_count` — Deprecated field (scheduled for removal in Fleet 5.0)
  - `platforms` — Array of `IHostSummaryPlatforms` or `null`
  - `builtin_labels` — Array of `ILabelSummary` from the label module

## Usage Example

```typescript
import { IHostSummary, IHostSummaryPlatforms } from "./host_summary";

const summary: IHostSummary = {
  totals_hosts_count: 120,
  all_linux_count: 45,
  online_count: 98,
  offline_count: 22,
  mia_count: 0,
  new_count: 5,
  missing_30_days_count: 3,   // premium
  low_disk_space_count: 7,    // premium
  platforms: [
    { platform: "darwin", hosts_count: 60 },
    { platform: "linux",  hosts_count: 45 },
    { platform: "windows", hosts_count: 15 },
  ],
  builtin_labels: [],
};
```

## Notes

- `missing_30_days_count`, `low_disk_space_count`, and `dep_assign_error_count` are optional and only available on premium Fleet tiers.
- `mia_count` is deprecated and will be removed in Fleet 5.0; prefer `missing_30_days_count` going forward.
