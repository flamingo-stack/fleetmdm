Unit test suite for the `formatSoftwareType` utility function, validating display string formatting across all supported software source types, browser extensions, and IDE extensions.

## Key Components

- **`formatSoftwareType` tests** — Covers the full range of software source type formatting, organized into five `describe` blocks:
  - **Basic source types** — Verifies static mappings for OS-native package formats (macOS apps, Windows programs, deb/RPM/npm/Python/Homebrew/Chocolatey/pkg packages, Go binaries)
  - **Browser extensions** — Tests `chrome_extensions` with various `extension_for` values (Chrome, Edge, Brave, Opera, Chromium), plus Firefox add-ons, Safari, and IE
  - **IDE extensions** — Tests `vscode_extensions` with VSCode, VSCode Insiders, VSCodium, Cursor, Trae, Windsurf variants, plus JetBrains/IntelliJ IDEA
  - **Unknown `extension_for` values** — Asserts that unrecognized values fall back to `startCase` formatting (e.g., `"unknown_browser"` → `"Unknown Browser"`)
  - **Edge cases** — Validates graceful handling of unknown source types (`"Unknown"`), empty strings, `undefined`, and `null` for `extension_for`

- **`SoftwareExtensionFor`** — Imported type used to cast unknown extension strings in edge-case tests

## Usage Example

```typescript
// Verifying the formatter against expected display strings
import { formatSoftwareType } from "./software";

formatSoftwareType({ source: "deb_packages" });
// → "Package (deb)"

formatSoftwareType({ source: "chrome_extensions", extension_for: "brave" });
// → "Browser plugin (Brave)"

formatSoftwareType({ source: "vscode_extensions", extension_for: "cursor" });
// → "IDE extension (Cursor)"

formatSoftwareType({ source: "chrome_extensions", extension_for: undefined });
// → "Browser plugin"

formatSoftwareType({ source: "unknown_source" as any });
// → "Unknown"
```
