Defines TypeScript interfaces for secret/configuration variables managed within the Fleet MDM platform.

## Key Components

- **`IVariable`** — Represents a stored variable entity returned from the API, including metadata fields (`id`, `created_at`, `updated_at`) and its `name`.
- **`IVariableFormData`** — Represents the payload used when creating or updating a variable, containing only the `name` and `value` fields (value is intentionally omitted from `IVariable` to avoid exposing secrets in list responses).

## Usage Example

```typescript
import { IVariable, IVariableFormData } from "./variables";

// Displaying a variable from an API response
const variable: IVariable = {
  id: 1,
  name: "API_TOKEN",
  created_at: "2024-01-15T10:00:00Z",
  updated_at: "2024-01-15T10:00:00Z",
};

// Submitting a new variable via form
const formData: IVariableFormData = {
  name: "API_TOKEN",
  value: "super-secret-value",
};

await createVariable(formData);
```

## Notes

- `IVariable` intentionally excludes `value` — this follows a security best practice where secret values are write-only and never returned in API list/get responses.
- `IVariableFormData` is used for both **create** and **update** operations.
