Defines TypeScript interfaces for Fleet API query parameters used when fetching paginated and sorted lists.

## Key Components

- **`IListOptions`** – Full interface representing all list query params: `page`, `per_page`, `order_key`, and `order_direction`
- **`IListSort`** – Utility type picking only the sort-related fields (`order_key`, `order_direction`) from `IListOptions`
- **`IListPagination`** – Utility type picking only the pagination fields (`page`, `per_page`) from `IListOptions`

## Usage Example

```typescript
import { IListOptions, IListSort, IListPagination } from "./list_options";

// Full list options
const listOptions: IListOptions = {
  page: 0,
  per_page: 20,
  order_key: "name",
  order_direction: "asc",
};

// Sort-only params
const sortOptions: IListSort = {
  order_key: "created_at",
  order_direction: "desc",
};

// Pagination-only params
const paginationOptions: IListPagination = {
  page: 2,
  per_page: 50,
};
```
