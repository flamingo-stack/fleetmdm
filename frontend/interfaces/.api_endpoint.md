Defines TypeScript interfaces and utilities for representing Fleet API endpoints, used to identify and display HTTP route metadata.

## Key Components

- **`IApiEndpointRef`** — Minimal interface containing `method` and `path` to uniquely reference an endpoint
- **`IApiEndpoint`** — Extends `IApiEndpointRef` with `display_name` and `deprecated` flag for richer endpoint metadata
- **`endpointKey(ep)`** — Utility function that generates a unique string key from an endpoint reference (e.g., `"GET /api/v1/hosts"`)

## Usage Example

```typescript
import { IApiEndpoint, IApiEndpointRef, endpointKey } from "./api_endpoint";

const endpoint: IApiEndpoint = {
  method: "GET",
  path: "/api/v1/hosts",
  display_name: "List Hosts",
  deprecated: false,
};

// Generate a unique key for map lookups or comparisons
const key = endpointKey(endpoint); // "GET /api/v1/hosts"

// Use the minimal ref interface when full metadata isn't needed
const ref: IApiEndpointRef = { method: "POST", path: "/api/v1/labels" };
console.log(endpointKey(ref)); // "POST /api/v1/labels"
```

## Notes

- `endpointKey` is the recommended way to uniquely identify endpoints since the interfaces have no `id` field
- The separation between `IApiEndpointRef` and `IApiEndpoint` allows passing lightweight references where full metadata is unnecessary
