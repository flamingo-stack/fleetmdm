Legacy PropTypes shape and TypeScript interfaces for scheduled queries within Fleet pack management.

## Key Components

### Default Export
- **PropTypes shape** — Runtime validation shape for scheduled query objects, used to maintain backward compatibility with legacy pack support.

### Interfaces

| Interface | Description |
|---|---|
| `IPackQueryFormData` | Form data shape for creating/editing a query within a pack |
| `IScheduledQuery` | Full scheduled query object returned from the API |
| `IEditScheduledQuery` | Extends `IScheduledQuery` with a `type` discriminator (`global_scheduled_query` \| `team_scheduled_query`) |
| `ILoadAllGlobalScheduledQueriesResponse` | API response shape for fetching global scheduled queries |
| `IStoredScheduledQueriesResponse` | API response shape for fetching pack-scoped scheduled queries |
| `IUpdateScheduledQuery` | Payload shape for updating a scheduled query |
| `IUpdateTeamScheduledQuery` | Extends `IUpdateScheduledQuery` with a required `team_id` for team-scoped updates |

## Usage Example

```typescript
import { IScheduledQuery, IUpdateTeamScheduledQuery } from "interfaces/scheduled_query";

// Typed scheduled query object
const query: IScheduledQuery = {
  id: 1,
  pack_id: 42,
  name: "system_info",
  query_id: 7,
  query_name: "Get System Info",
  query: "SELECT * FROM system_info;",
  interval: 3600,
  snapshot: false,
  removed: true,
  created_at: "2024-01-01T00:00:00Z",
  updated_at: "2024-06-01T00:00:00Z",
  stats: { /* ISchedulableQueryStats */ } as any,
};

// Team-scoped update payload
const update: IUpdateTeamScheduledQuery = {
  logging_type: "snapshot",
  interval: 7200,
  team_id: 3,
};
```

## Notes

- This file is marked as **legacy** — interfaces exist to maintain compatibility with Fleet's pack-based scheduling system.
- `ISchedulableQueryStats` is imported from [`interfaces/schedulable_query`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/schedulable_query.ts).
