Defines the PropTypes validator and TypeScript types for the application's notification/alert system.

## Key Components

- **Default Export** — PropTypes shape validator for notification objects, used for runtime prop validation in React components
- **`IAlertType`** — Union type defining the three supported alert styles: `"success"`, `"error"`, and `"warning-filled"`
- **`INotification`** — Interface describing the full notification object structure

### `INotification` Interface Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `alertType` | `IAlertType \| null` | ✅ | Visual style of the alert |
| `isVisible` | `boolean` | ✅ | Controls alert visibility |
| `message` | `JSX.Element \| string \| null` | ✅ | Alert content (supports rich JSX) |
| `persistOnPageChange` | `boolean` | ❌ | Keeps alert visible across navigation |
| `id` | `string` | ❌ | Unique identifier for the notification |

## Usage Example

```typescript
import { INotification, IAlertType } from "./notification";

const successNotification: INotification = {
  alertType: "success",
  isVisible: true,
  message: "Settings saved successfully.",
  persistOnPageChange: false,
  id: "save-success-01",
};

const errorNotification: INotification = {
  alertType: "error",
  isVisible: true,
  message: <span>An <strong>unexpected error</strong> occurred.</span>,
};
```
