Extends the default React Router 3 location type with additional browser location properties not included out of the box.

## Key Components

- **`IRouterLocation`** — Interface augmenting React Router 3's location object with standard browser `window.location`-style fields.

| Property | Type | Description |
|---|---|---|
| `pathname` | `string` | URL path segment |
| `host` | `string` | `hostname:port` combined value |
| `hostname` | `string` | Domain name without port |
| `port` | `string` | Port number as string |
| `protocol` | `string` | URL scheme (e.g. `https:`) |
| `[key: string]` | `any` | Index signature for additional router properties |

## Usage Example

```typescript
import { IRouterLocation } from "./routing";

function handleRouteChange(location: IRouterLocation) {
  const isSecure = location.protocol === "https:";
  const baseUrl = `${location.protocol}//${location.host}`;
  console.log(`Navigated to: ${baseUrl}${location.pathname}`);
}
```

> **Note:** The index signature `[key: string]: any` allows consuming code to access any additional properties React Router 3 attaches to the location object without TypeScript errors, while still providing type safety for the explicitly declared fields.
