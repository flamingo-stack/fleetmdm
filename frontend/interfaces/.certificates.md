TypeScript interfaces and type guards for certificate management, covering host certificate data structures and multiple certificate authority (CA) integration types.

## Key Components

### Interfaces
- **`IHostCertificate`** — Full certificate data for a host, including validity dates, key info, subject/issuer details, and source metadata.
- **`ICertificateAuthorityPartial`** — Lightweight CA representation (`id`, `name`, `type`) returned by some CA endpoints.
- **`ICertificatesNDES`** — NDES SCEP Proxy CA config.
- **`ICertificatesDigicert`** — DigiCert CA config with profile and seat fields.
- **`ICertificatesHydrant`** — Hydrant CA config with OAuth client credentials.
- **`ICertificatesCustomSCEP`** — Custom SCEP Proxy CA config.
- **`ICertificatesSmallstep`** — Smallstep CA config with challenge URL and basic auth.
- **`ICertificatesCustomEST`** — Custom EST Proxy CA config.

### Types
- **`ICertificateAuthorityType`** — Union of all supported CA type strings.
- **`ICertificateAuthority`** — Union of all CA config interfaces.

### Constants
- **`CERTIFICATES_DEFAULT_SORT`** — Default list sort: `common_name` ascending.

### Type Guards
- `isNDESCertAuthority`, `isDigicertCertAuthority`, `isHydrantCertAuthority`, `isCustomSCEPCertAuthority`, `isSmallstepCertAuthority`, `isCustomESTCertAuthority` — Narrow an `ICertificateAuthority` to its specific type by checking for discriminating fields.

### Test Utilities
- **`createMockCertificateAuthorities()`** — Returns a mock list of all six `ICertificateAuthorityPartial` entries for use in tests.

## Usage Example

```typescript
import {
  ICertificateAuthority,
  isDigicertCertAuthority,
  isSmallstepCertAuthority,
} from "./certificates";

function getCALabel(ca: ICertificateAuthority): string {
  if (isDigicertCertAuthority(ca)) {
    return `DigiCert — Profile: ${ca.profile_id}`;
  }
  if (isSmallstepCertAuthority(ca)) {
    return `Smallstep — Challenge: ${ca.challenge_url}`;
  }
  return "Unknown CA";
}
```
