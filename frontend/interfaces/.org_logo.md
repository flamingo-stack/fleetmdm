Defines TypeScript types for organization logo display mode configuration.

## Key Components

- **`IOrgLogoMode`** — Union type representing valid logo mode values: `"light"`, `"dark"`, or `"all"` (display in all contexts).
- **`IOrgLogoStorableMode`** — Derived type excluding `"all"` from `IOrgLogoMode`, representing only the modes that can be persisted/stored (`"light"` or `"dark"`).

## Usage Example

```typescript
import type { IOrgLogoMode, IOrgLogoStorableMode } from "./org_logo";

// Use IOrgLogoMode when accepting any mode (including "all")
function applyLogoMode(mode: IOrgLogoMode) {
  if (mode === "all") {
    // show logo in both light and dark contexts
  }
}

// Use IOrgLogoStorableMode when saving to storage (excludes "all")
function saveLogo(mode: IOrgLogoStorableMode, url: string) {
  // mode is strictly "light" | "dark"
  db.save({ mode, url });
}
```
