Defines the PropTypes shape and TypeScript interfaces for Fleet host entities, covering hardware inventory, MDM state, software, policies, and device management data structures.

## Key Components

### Default Export
- **`PropTypes.shape`** — Runtime prop validation shape for host objects used in React components

### Type Aliases
- **`HostStatus`** — `"online" | "offline" | "new" | "missing"`
- **`HostMdmDeviceStatus`** — `"unlocked" | "locked" | "wiped"`
- **`HostMdmPendingAction`** — MDM actions: `"unlock"`, `"lock"`, `"wipe"`, `"clear_passcode"`, `"location"`
- **`MacDiskEncryptionActionRequired`** — `"log_out" | "rotate_key"`
- **`RecoveryLockPasswordStatus`** — `"verified" | "verifying" | "pending" | "failed"`
- **`HostAndroidCertStatus`** — Certificate lifecycle states

### Core Interfaces
- **`IHost`** — Full host record with hardware specs, OS info, MDM state, policies, software, and user mappings
- **`IHostDevice`** — Extends `IHost` with `dep_assigned_to_fleet` for the `/devices` endpoint
- **`IHostMdmData`** — MDM enrollment, encryption keys, profiles, OS settings, and pending actions
- **`IOSSettings`** — Cross-platform OS-level MDM settings (disk encryption, recovery lock, managed accounts, certificates)
- **`IDUPDetails`** — Device User Page payload including license, org branding, and global config
- **`IHostIssues`** — Aggregated issue counts (vulnerabilities, failing policies)
- **`IHostEndUser`** — IdP-linked end user data attached to a host
- **`IMacadminsResponse`** — Munki and legacy MDM data from macadmins endpoint
- **`IHostEncrpytionKeyResponse`** / **`IHostRecoveryLockPasswordResponse`** / **`IHostManagedAccountPasswordResponse`** — Credential retrieval responses

## Usage Example

```typescript
import { IHost, HostStatus, IHostMdmData } from "interfaces/host";

function getHostSummary(host: IHost): string {
  const status: HostStatus = host.status;
  const mdm: IHostMdmData = host.mdm;

  return `${host.display_name} [${status}] — MDM: ${mdm.enrollment_status ?? "none"}`;
}

// Narrowing MDM device status
function isHostLocked(host: IHost): boolean {
  return host.mdm.device_status === "locked";
}
```
