Defines TypeScript interfaces, types, and utility functions for Fleet MDM script management, including platform support checks and batch execution status handling.

## Key Components

### Interfaces
- **`IScript`** — Core script entity with id, team association, name, and timestamps
- **`IHostScript`** — Script as associated with a host, including last execution metadata
- **`ILastExecution`** — Execution record with id, timestamp, and status

### Types
- **`IScriptExecutionStatus`** — `"ran" | "pending" | "error"`
- **`ScriptBatchStatus`** — `"started" | "scheduled" | "finished"`
- **`ScriptBatchHostStatus`** — Combined type from executed (`"ran"`, `"errored"`) and not-executed (`"pending"`, `"incompatible"`, `"canceled"`) status arrays
- **`ScriptContent`** — Alias for `string`

### Utility Functions
- **`isScriptSupportedPlatform(hostPlatform)`** — Returns `true` for darwin, windows, and Linux platforms; excludes Chrome OS, iOS, iPadOS, and Android
- **`addTeamIdCriteria(pred, teamId, isFreeTier?)`** — Conditionally appends `fleet_id` to a query predicate based on tier
- **`isValidScriptBatchStatus(status)`** — Type guard for `ScriptBatchStatus`
- **`isValidScriptBatchHostStatus(status)`** — Type guard for `ScriptBatchHostStatus`

## Usage Example

```typescript
import {
  isScriptSupportedPlatform,
  isValidScriptBatchStatus,
  addTeamIdCriteria,
} from "./script";

// Check if a host can run scripts
if (isScriptSupportedPlatform("darwin")) {
  console.log("Scripts supported");
}

// Type-safe batch status check
const status = "finished";
if (isValidScriptBatchStatus(status)) {
  // status is narrowed to ScriptBatchStatus
  console.log(status);
}

// Build a team-scoped query predicate
const query = addTeamIdCriteria({ name: "deploy.sh" }, 42, false);
// → { name: "deploy.sh", fleet_id: 42 }
```
