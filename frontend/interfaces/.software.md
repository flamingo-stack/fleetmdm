This file defines TypeScript interfaces, types, and constants for the software inventory domain in the Fleet MDM frontend, including software packages, app store apps, vulnerabilities, and source type mappings.

## Key Components

### Interfaces
- **`ISoftware`** — Legacy software record (name, version, source, vulnerabilities, hosts count)
- **`ISoftwareTitle`** / **`ISoftwareTitleDetails`** — Current software title with package/app store metadata
- **`ISoftwareVersion`** — Versioned software record with CVE data
- **`ISoftwarePackage`** — Custom or Fleet-maintained installable package (scripts, labels, policies)
- **`IAppStoreApp`** — VPP/Google Play app store entry
- **`ISoftwareVulnerability`** — CVE record with CVSS/EPSS scores and exploit data
- **`ISoftwareInstallPolicy`** / **`ISoftwareInstallPolicyUI`** — Auto-install policy shapes (API vs. UI)

### Types & Enums
- **`SoftwareSource`** — Union of all valid software source keys (e.g., `deb_packages`, `apps`, `programs`)
- **`InstallerType`** — `"package"` | `"app-store"`
- **`SoftwareCategory`** — Allowed categories matching backend `allowedCategories`
- **`SoftwareInstallPolicyType`** — `"dynamic"` | `"patch"`

### Constants
- **`SOURCE_TYPE_CONVERSION`** — Maps raw source keys to human-readable display strings
- **`INSTALLABLE_SOURCE_PLATFORM_CONVERSION`** — Maps source keys to platform targets (`"darwin"`, `"linux"`, `"windows"`, etc.)
- **`SCRIPT_PACKAGE_SOURCES`** — Sources for script-only packages (`sh_packages`, `ps1_packages`)

### Type Guards
- **`isSoftwarePackage`** — Narrows `ISoftwarePackage | IAppStoreApp` to `ISoftwarePackage`

## Usage Example

```typescript
import {
  ISoftwareTitle,
  ISoftwarePackage,
  IAppStoreApp,
  isSoftwarePackage,
  SOURCE_TYPE_CONVERSION,
  SoftwareSource,
} from "interfaces/software";

// Narrow installer type at runtime
function renderInstaller(installer: ISoftwarePackage | IAppStoreApp) {
  if (isSoftwarePackage(installer)) {
    console.log("Install script:", installer.install_script);
  } else {
    console.log("App Store ID:", installer.app_store_id);
  }
}

// Look up human-readable source label
const source: SoftwareSource = "deb_packages";
const label = SOURCE_TYPE_CONVERSION[source]; // "Package (deb)"
```
