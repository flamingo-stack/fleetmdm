Utility module for parsing and extracting error information from Fleet API responses and Axios errors.

## Key Components

### Interfaces
- **`IFleetApiError`** — Shape of a single Fleet API error (`name` + `reason` fields)
- **`IApiError`** — Shape of a full Fleet API error response (`message`, `errors[]`, optional `uuid`)

### Exported Functions

| Function | Description |
|---|---|
| `getErrorReason(payload, filter?)` | Extracts the `reason` string from any error payload shape; supports optional name/reason filtering |
| `hasStatusKey(value)` | Type guard checking if a value has a numeric `status` property |
| `ignoreAxiosError(err, ignoreStatuses)` | Returns `true` if an `AxiosError`'s status code is in the provided ignore list |
| `expandErrorReasonRequired(err)` | Finds a `"required"` reason error and returns `"<fieldName> required"`, falling back to `getErrorReason` |

## Usage Example

```typescript
import { getErrorReason, ignoreAxiosError, expandErrorReasonRequired } from "./errors";

// Extract reason from any error shape
try {
  await apiCall();
} catch (err) {
  // Returns first error's reason, or empty string
  const reason = getErrorReason(err);

  // Filter by error name
  const nameReason = getErrorReason(err, { nameEquals: "email" });

  // Filter by partial reason string
  const partialReason = getErrorReason(err, { reasonIncludes: "duplicate" });
}

// Suppress 404s from error handling
catch (err) {
  if (ignoreAxiosError(err, [404])) return;
}

// Expand required field errors into readable messages
const message = expandErrorReasonRequired(err);
// e.g. "email required"
```

## Notes

- `getErrorReason` handles multiple payload shapes: raw `AxiosError`, `{ response: { data: { errors[] } } }`, `{ data: { errors[] } }`, and `{ errors[] }`
- `IFilterFleetError` is a discriminated union — only `nameEquals` **or** `reasonIncludes` can be specified, not both
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm)
