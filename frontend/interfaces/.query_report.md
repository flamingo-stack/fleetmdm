Defines TypeScript interfaces for the query report feature, representing structured results returned from host query executions.

## Key Components

- **`IQueryReportResultRow`** — Represents a single row in a query report result, containing the host identifier, hostname, fetch timestamp, and a dynamic `columns` map of column name/value pairs.
- **`IQueryReport`** — Top-level query report structure containing the query ID, an array of result rows, and a flag indicating whether the report was truncated.

## Usage Example

```typescript
import { IQueryReport, IQueryReportResultRow } from "./query_report";

const row: IQueryReportResultRow = {
  host_id: 42,
  host_name: "macbook-pro-alice",
  last_fetched: "2024-01-15T10:30:00Z",
  columns: { os_version: "14.2", cpu_brand: "Apple M2" },
};

const report: IQueryReport = {
  query_id: 7,
  results: [row],
  report_clipped: false,
};

if (report.report_clipped) {
  console.warn("Report exceeded size limit and was truncated.");
}
```

## Notes

- The `columns` field on `IQueryReportResultRow` is typed as `any` to accommodate arbitrary osquery column schemas that vary per query.
- `report_clipped: true` signals the result set was cut off server-side; consumers should surface a warning to users.
