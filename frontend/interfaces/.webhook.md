Defines PropTypes shape and TypeScript interfaces for Fleet MDM webhook configurations, covering host status, failing policies, software vulnerabilities, and activity event webhooks.

## Key Components

- **Default export** — PropTypes shape for failing policies webhook validation
- **`IWebhookHostStatus`** — Interface for host status monitoring webhooks
- **`IWebhookFailingPolicies`** — Interface for policy failure notification webhooks
- **`IWebhookSoftwareVulnerabilities`** — Interface for software vulnerability alert webhooks
- **`IWebhookActivities`** — Interface for activity event webhooks (required fields)
- **`IWebhook`** — Union type combining all webhook configuration interfaces

## Usage Example

```typescript
import webhookPropType, {
  IWebhook,
  IWebhookFailingPolicies,
  IWebhookHostStatus,
} from "./webhook";

// Type-safe webhook configuration
const failingPoliciesConfig: IWebhookFailingPolicies = {
  destination_url: "https://hooks.example.com/policies",
  policy_ids: [1, 2, 3],
  enable_failing_policies_webhook: true,
  host_batch_size: 100,
};

const hostStatusConfig: IWebhookHostStatus = {
  enable_host_status_webhook: true,
  destination_url: "https://hooks.example.com/host-status",
  host_percentage: 20,
  days_count: 14,
};

// Union type usage
function processWebhook(webhook: IWebhook) {
  if ("enable_host_status_webhook" in webhook) {
    // handle host status webhook
  }
}

// PropTypes usage in a React component
MyComponent.propTypes = {
  webhook: webhookPropType,
};
```

## Notes

- `IWebhookActivities` has required (non-optional) fields unlike the other interfaces
- `IWebhook` union type allows flexible handling of any webhook variant
