Defines the TypeScript interface for props used by the `EmptyState` UI component, which renders placeholder content when no data is available.

## Key Components

### `IEmptyStateProps`
An interface describing the optional props for the `EmptyState` component:

| Prop | Type | Description |
|------|------|-------------|
| `header` | `JSX.Element \| string` | Title or heading displayed in the empty state |
| `info` | `JSX.Element \| string` | Primary descriptive text or element |
| `additionalInfo` | `JSX.Element \| string` | Secondary/supplemental information |
| `className` | `string` | Custom CSS class for styling overrides |
| `primaryButton` | `JSX.Element` | Main call-to-action button |
| `secondaryButton` | `JSX.Element` | Optional secondary action button |

## Usage Example

```typescript
import { IEmptyStateProps } from "./empty_state";

const emptyStateProps: IEmptyStateProps = {
  header: "No devices found",
  info: "There are no devices enrolled yet.",
  additionalInfo: "Contact your administrator for help.",
  className: "custom-empty-state",
  primaryButton: <Button onClick={handleAdd}>Add Device</Button>,
  secondaryButton: <Button onClick={handleDismiss}>Dismiss</Button>,
};

<EmptyState {...emptyStateProps} />
```

## Notes

- All props are optional (`?`), allowing the component to render with partial or no content.
- Both `JSX.Element` and `string` are accepted for content props, providing flexibility for plain text or rich React elements.
