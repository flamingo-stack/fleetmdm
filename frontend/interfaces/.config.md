Defines TypeScript interfaces and utility functions representing the Fleet MDM global configuration structure, providing a flattened type-safe model of the `fleet/config` API response.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IConfig` | Interface | Root configuration object covering org info, server settings, MDM, webhooks, integrations, and logging |
| `IMdmConfig` | Interface | Full MDM configuration including Apple, Windows, Android, and end-user authentication settings |
| `ILicense` | Interface | License tier, device count, expiration, and cloud management flags |
| `IConfigFeatures` | Interface | Feature flags for host users, software inventory, and conditional access |
| `ILoggingConfig` | Interface | Logging destination and plugin configuration |
| `IDeviceGlobalConfig` | Interface | Per-device config subset (note: may reflect team config when device is team-assigned) |
| `IAutomationsConfig` | Type alias | Subset of `IConfig` scoped to webhook and integration settings |
| `LogDestination` | Union type | Supported log output destinations (filesystem, firehose, kinesis, etc.) |
| `IGitOpsModeConfig` | Interface | GitOps mode enablement, repository URL, and exception flags |
| `isOktaConditionalAccessConfigured` | Function | Returns `true` when all four Okta conditional access fields are present |
| `isEntraConditionalAccessConfigured` | Function | Returns `true` when Microsoft Entra connection is configured |
| `isConditionalAccessConfigured` | Function | Returns `true` when either Okta or Entra conditional access is configured |

## Usage Example

```typescript
import {
  IConfig,
  isConditionalAccessConfigured,
  isOktaConditionalAccessConfigured,
} from "interfaces/config";

function renderConditionalAccessBadge(config: IConfig | null) {
  if (isConditionalAccessConfigured(config)) {
    const provider = isOktaConditionalAccessConfigured(config)
      ? "Okta"
      : "Microsoft Entra";
    return `Conditional access enabled via ${provider}`;
  }
  return "No conditional access configured";
}

// Access MDM and license details
function checkMdmStatus(config: IConfig) {
  const { mdm, license } = config;
  console.log("MDM enabled:", mdm.enabled_and_configured);
  console.log("License tier:", license.tier);
  console.log("Disk encryption:", mdm.enable_disk_encryption);
}
```

> **Note:** `apple_bm_terms_expired` on `IMdmConfig` is deprecated — use `needsAbmTermsRenewal` from `AppContext` instead. See [PR #21043](https://github.com/fleetdm/fleet/pull/21043).
