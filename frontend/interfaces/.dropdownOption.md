Defines the PropTypes validator and TypeScript interface for dropdown option objects used throughout the UI component library.

## Key Components

- **Default export** — `PropTypes.shape` validator for runtime prop validation of dropdown options
- **`TooltipContent`** — Type alias for `ReactNode`, used for tooltip content within dropdown options
- **`IDropdownOption`** — TypeScript interface describing the full shape of a dropdown option, including optional display and behavior fields:
  - `label` — Display text or JSX element
  - `value` — String or numeric identifier
  - `disabled` — Prevents selection when `true`
  - `helpText` — Supplementary content rendered alongside the option
  - `premiumOnly` — Flags the option as restricted to premium users
  - `tooltipContent` — Content rendered in a tooltip on hover
  - `onClick` — Optional click handler

## Usage Example

```typescript
import { IDropdownOption } from "path/to/dropdownOption";

const options: IDropdownOption[] = [
  {
    label: "All Hosts",
    value: "all",
  },
  {
    label: "Windows Only",
    value: "windows",
    helpText: "Filters to Windows devices",
    tooltipContent: <span>Requires Windows agent</span>,
  },
  {
    label: "Premium Feature",
    value: "premium",
    premiumOnly: true,
    disabled: true,
  },
];
```
