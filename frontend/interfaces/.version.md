Defines the PropTypes shape and TypeScript interface for Fleet version metadata returned from the build/version API endpoint.

## Key Components

- **Default Export** — A `PropTypes.shape` validator describing the structure of a version response object, suitable for runtime prop validation in React components.
- **`IVersionResponse`** — TypeScript interface representing the version response payload with the following fields:

| Field | Type | Description |
|---|---|---|
| `version` | `string` | Fleet release version |
| `branch` | `string` | Git branch name |
| `revision` | `string` | Git commit revision hash |
| `go_version` | `string` | Go compiler version used at build time |
| `build_date` | `string` | Timestamp of the build |
| `build_user` | `string` | User who triggered the build |

## Usage Example

```typescript
import versionInterface, { IVersionResponse } from "./version";

// TypeScript usage
const displayVersion = (v: IVersionResponse): string => {
  return `Fleet ${v.version} (${v.branch}@${v.revision})`;
};

// PropTypes usage in a React component
import PropTypes from "prop-types";

MyComponent.propTypes = {
  versionInfo: versionInterface,
};
```
