Defines a PropTypes shape validator for Fleet license objects, used to validate license-related props across components.

## Key Components

- **Default Export** — A `PropTypes.shape` validator describing the structure of a Fleet license object with the following fields:
  - `allowed_hosts` — Accepts a string or number representing the host limit
  - `expiry` — A string representing the license expiration date
  - `hosts` — A number representing the current host count

## Usage Example

```javascript
import licensePropType from "path/to/license";

MyComponent.propTypes = {
  license: licensePropType,
};
```
