Defines TypeScript interfaces for aggregated macOS admin data, including Munki version distribution, Munki issues, and MDM enrollment statistics.

## Key Components

- **`IMunkiVersionsAggregate`** – Represents a Munki version entry with its associated host count.
- **`IMunkiIssuesAggregate`** – Describes a Munki issue (error or warning) affecting a set of hosts, identified by `id` and `name`.
- **`IMacadminAggregate`** – Top-level aggregate response shape containing Munki versions, Munki issues, MDM enrollment status, and MDM solutions, along with a `counts_updated_at` timestamp.

## Usage Example

```typescript
import {
  IMacadminAggregate,
  IMunkiVersionsAggregate,
  IMunkiIssuesAggregate,
} from "./macadmins";

const data: IMacadminAggregate = {
  macadmins: {
    counts_updated_at: "2024-01-15T10:30:00Z",
    munki_versions: [
      { version: "6.3.0", hosts_count: 42 },
    ],
    munki_issues: [
      { id: 1, name: "Could not install package", type: "error", hosts_count: 5 },
      { id: 2, name: "Deprecated catalog", type: "warning", hosts_count: 12 },
    ],
    mobile_device_management_enrollment_status: {
      enrolled_manual_hosts_count: 10,
      enrolled_automated_hosts_count: 30,
      unenrolled_hosts_count: 2,
    },
    mobile_device_management_solution: null,
  },
};
```

## Notes

- Depends on [`IMdmAggregateStatus` and `IMdmSolution`](https://github.com/flamingo-stack/fleetmdm/blob/main/mdm.ts) from the `mdm` module.
- `mobile_device_management_solution` is nullable, reflecting hosts where no MDM solution is detected.
- `type` on `IMunkiIssuesAggregate` is a string literal union (`"error" | "warning"`) for type-safe issue classification.
