Defines shared TypeScript types, interfaces, and utilities for Fleet MDM chart components, including dataset configuration, tooltip formatting, and historical data collection settings.

## Key Components

### Types & Interfaces
- **`ChartType`** — Union type for chart rendering modes: `"line"` or `"checkerboard"`
- **`ChartTheme`** — Union type for chart color themes: `"green"` or `"red"`
- **`IDataSet`** — Describes a chart dataset with its name, label, default chart type, optional description, tooltip formatter, theme, and relative scale flag
- **`IFormattedDataPoint`** — Represents a single chart data point with timestamp, label, value, percentage, and optional total
- **`TooltipFormatter`** — Function type that receives `value`, `total`, and `percentage` and returns a formatted `string` or `ReactNode`
- **`IHistoricalDataSettings`** — Boolean flags controlling collection for `uptime` and `vulnerabilities` datasets

### Constants
- **`HISTORICAL_DATA_CONFIG_KEYS`** — Readonly tuple of valid historical data config keys (`"uptime"`, `"vulnerabilities"`)
- **`DATASET_CONFIG_KEY`** — Maps internal API dataset names (e.g., `"cve"`) to their `features.historical_data` config keys
- **`DATASET_LABEL`** — Maps config keys to human-readable labels for display

### Functions
- **`isHistoricalDataEnabled`** — Applies a global-AND-fleet precedence rule; returns `true` only if both global and fleet settings enable the given config key (missing settings default to `true`)

## Usage Example

```typescript
import {
  isHistoricalDataEnabled,
  DATASET_CONFIG_KEY,
  IHistoricalDataSettings,
} from "./charts";

const globalSettings: IHistoricalDataSettings = {
  uptime: true,
  vulnerabilities: false,
};

const fleetSettings: IHistoricalDataSettings = {
  uptime: true,
  vulnerabilities: true,
};

// Returns false — global has vulnerabilities disabled
const canShowVulns = isHistoricalDataEnabled(
  globalSettings,
  fleetSettings,
  "vulnerabilities"
);

// Map an API dataset name to its config key
const configKey = DATASET_CONFIG_KEY["cve"]; // "vulnerabilities"
```
