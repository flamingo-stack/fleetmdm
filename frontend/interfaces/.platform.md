Defines platform constants, types, and utility functions for all supported device operating systems across the Fleet MDM platform.

## Key Components

### Constants
- **`PLATFORM_DISPLAY_NAMES`** — Single source of truth mapping platform keys (`darwin`, `windows`, `linux`, `chrome`, `ios`, `ipados`, `android`) to human-readable display names
- **`QUERYABLE_PLATFORMS`** / **`NON_QUERYABLE_PLATFORMS`** — Separates platforms that support osquery (`darwin`, `windows`, `linux`, `chrome`) from mobile-only platforms
- **`SCHEDULED_QUERYABLE_PLATFORMS`** — Subset of queryable platforms supporting scheduled queries (excludes Chrome)
- **`HOST_LINUX_PLATFORMS`** — Exhaustive list of Linux distros recognized by the Fleet server
- **`MACADMINS_EXTENSION_TABLES`** — Maps MacAdmins osquery extension table names to their supported platforms
- **`DISK_ENCRYPTION_SUPPORTED_PLATFORMS`** / **`SETUP_EXPERIENCE_PLATFORMS`** / **`VULN_SUPPORTED_PLATFORMS`** — Feature-specific platform groupings

### Type Guards
- **`isLinuxLike`**, **`isAppleDevice`**, **`isWindows`**, **`isMacOS`**, **`isChrome`**, **`isAndroid`**, **`isIPadOrIPhone`**, **`isMobilePlatform`** — Runtime platform checks
- **`isQueryablePlatform`**, **`isScheduledQueryablePlatform`**, **`isSetupExperiencePlatform`**, **`isVulnUnsupportedPlatform`** — Feature-capability checks
- **`platformSupportsDiskEncryption`**, **`isDiskEncryptionSupportedLinuxPlatform`**, **`isOsSettingsDisplayPlatform`** — Feature support checks with special Fedora/`rhel` handling

### Types
`Platform`, `DisplayPlatform`, `QueryablePlatform`, `ScheduledQueryablePlatform`, `HostPlatform`, `SelectedPlatform`, `CommaSeparatedPlatformString`, `SetupExperiencePlatform`, `DiskEncryptionSupportedPlatform`

## Usage Example

```typescript
import {
  isQueryablePlatform,
  platformSupportsDiskEncryption,
  isMobilePlatform,
  PLATFORM_DISPLAY_NAMES,
  type HostPlatform,
} from "./platform";

const hostPlatform: HostPlatform = "ubuntu";

// Display name lookup
const label = PLATFORM_DISPLAY_NAMES["darwin"]; // "macOS"

// Feature gating
if (isQueryablePlatform(hostPlatform)) {
  // Run osquery on this host
}

if (platformSupportsDiskEncryption(hostPlatform)) {
  // Show disk encryption status
}

// Fedora requires os_version check
const fedoraHost: HostPlatform = "rhel";
platformSupportsDiskEncryption(fedoraHost, "Fedora 39"); // true
platformSupportsDiskEncryption(fedoraHost, "Red Hat 8");  // false

if (isMobilePlatform(hostPlatform)) {
  // iOS, iPadOS, or Android — limited feature set
}
```
