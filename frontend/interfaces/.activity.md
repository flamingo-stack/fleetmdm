Defines the complete activity type system for Fleet MDM, including the `ActivityType` enum, host-scoped activity type subsets, and the core `IActivity` interface with its associated details types.

## Key Components

- **`ActivityType`** — Exhaustive enum of all auditable events in the system (200+ values), covering packs, policies, queries, MDM enrollment, software, scripts, profiles, certificates, and more
- **`IHostPastActivityType`** — Union type restricting `ActivityType` to events shown in a host's activity history (script runs, installs, lock/wipe, certificate events, etc.)
- **`IHostUpcomingActivityType`** — Union type restricting `ActivityType` to pending/queued host actions (script runs, software installs/uninstalls, lock/unlock)
- **`IActivity`** — Core activity record interface with actor metadata, timestamp, type, and optional details payload
- **`IHostPastActivity`** — Variant of `IActivity` for host history; requires `details` and narrows `type` to `IHostPastActivityType`
- **`IHostUpcomingActivity`** — Variant of `IActivity` for queued host actions; replaces `id` with `uuid` and narrows `type` to `IHostUpcomingActivityType`
- **`IActivityDetails`** — Open-ended details bag typed with optional fields for all activity-specific metadata (software names, profile names, policy IDs, etc.)

## Usage Example

```typescript
import { IActivity, ActivityType, IHostPastActivity } from "./activity";

// Type-guard for host-relevant activities
function isHostInstallEvent(activity: IActivity): boolean {
  return (
    activity.type === ActivityType.InstalledSoftware ||
    activity.type === ActivityType.InstalledAppStoreApp
  );
}

// Narrowed host past activity
const hostActivity: IHostPastActivity = {
  created_at: "2024-01-15T10:00:00Z",
  id: 42,
  actor_full_name: "Jane Admin",
  actor_id: 7,
  actor_gravatar: "https://gravatar.com/...",
  actor_api_only: false,
  type: ActivityType.InstalledSoftware,
  fleet_initiated: false,
  details: { software_title: "Slack", software_package: "slack.pkg" },
};
```
