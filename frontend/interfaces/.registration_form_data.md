Defines the shape and TypeScript interface for user registration form data used during Fleet onboarding setup.

## Key Components

- **Default export** — PropTypes shape validator for runtime prop validation of registration form fields
- **`IRegistrationFormData`** — TypeScript interface defining the strongly-typed structure for registration form submissions

### `IRegistrationFormData` Fields

| Field | Type | Required |
|---|---|---|
| `name` | `string` | ✅ |
| `password` | `string` | ✅ |
| `password_confirmation` | `string` | ✅ |
| `email` | `string` | ✅ |
| `org_name` | `string` | ✅ |
| `org_web_url` | `string` | ✅ |
| `org_logo_file` | `File \| null` | ❌ |
| `fleet_web_address` | `string` | ✅ |
| `server_url` | `string` | ✅ |

## Usage Example

```typescript
import { IRegistrationFormData } from "./registration_form_data";

const formData: IRegistrationFormData = {
  name: "Jane Admin",
  password: "securepassword123",
  password_confirmation: "securepassword123",
  email: "jane@example.com",
  org_name: "Acme Corp",
  org_web_url: "https://acme.com",
  org_logo_file: null,
  fleet_web_address: "https://fleet.acme.com",
  server_url: "https://fleet.acme.com",
};
```

> **Note:** `server_url` is present in the TypeScript interface but absent from the PropTypes validator — consider keeping both in sync if runtime validation is required.
