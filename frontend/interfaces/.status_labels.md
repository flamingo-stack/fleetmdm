Defines the TypeScript interface and PropTypes shape for host status label counts used across the Fleet MDM dashboard.

## Key Components

- **`IStatusLabels`** — TypeScript interface describing the structure of host status counts:
  - `loading_counts` — boolean indicating if counts are being fetched
  - `new_count` — number of newly enrolled hosts
  - `online_count` — number of online hosts
  - `offline_count` — number of offline hosts
  - `mia_count` — ⚠️ **Deprecated**: scheduled for removal in Fleet 5.0

- **Default export** — A `PropTypes.shape` validator mirroring the `IStatusLabels` interface for runtime prop validation in React components.

## Usage Example

```typescript
import statusLabelsPropTypes, { IStatusLabels } from "./status_labels";

// Typed component props
interface Props {
  statusLabels: IStatusLabels;
}

const HostSummary = ({ statusLabels }: Props) => {
  const { loading_counts, online_count, offline_count, new_count } = statusLabels;

  if (loading_counts) return <Spinner />;

  return <div>{online_count} online · {offline_count} offline · {new_count} new</div>;
};

// PropTypes validation (class components)
HostSummary.propTypes = {
  statusLabels: statusLabelsPropTypes.isRequired,
};
```

## Notes

- `mia_count` is deprecated and should not be used in new code; it will be removed in Fleet 5.0.
