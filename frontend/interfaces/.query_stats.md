Defines PropTypes validation shape and TypeScript interface for query execution statistics associated with scheduled queries and packs.

## Key Components

- **Default Export** — PropTypes shape validator for runtime prop validation of query stats objects, including legacy `ILegacySchedulableQueryStats` for the `stats` field
- **`IQueryStats`** — TypeScript interface describing a fully-typed query stats object, extending fields from the PropTypes shape with additional properties like `discard_data`, `automations_enabled`, and `last_fetched`

## Usage Example

```typescript
import QueryStatsPropTypes, { IQueryStats } from "./query_stats";

// Runtime prop validation
MyComponent.propTypes = {
  queryStat: QueryStatsPropTypes,
};

// Static typing
const processQueryStats = (stat: IQueryStats): void => {
  console.log(stat.query_name);         // string
  console.log(stat.average_memory);     // number
  console.log(stat.automations_enabled); // boolean
  console.log(stat.last_fetched);       // string | null
  console.log(stat.stats);             // ISchedulableQueryStats | undefined
};
```

## Notes

- `wall_time` and `output_size` are optional (`?`) in `IQueryStats` but required in the PropTypes shape — consumers should handle potential `undefined` values
- `stats` references `ISchedulableQueryStats` (current) in the interface vs. `ILegacySchedulableQueryStats` in the PropTypes shape, reflecting a schema migration
- `last_fetched` accepts `null` to represent queries that have never been fetched
