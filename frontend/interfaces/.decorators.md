Defines and exports a PropTypes shape validator for a **decorator** object used in Fleet MDM configuration.

## Key Components

- **Default Export** — A `PropTypes.shape` validator describing the structure of a decorator entity with the following fields:

| Field | Type | Description |
|-------|------|-------------|
| `id` | `number` | Unique identifier for the decorator |
| `type` | `string` | Decorator type (e.g., `load`, `always`, `interval`) |
| `interval` | `number` | Execution interval (used with interval-type decorators) |
| `query` | `string` | The SQL query the decorator runs |
| `built_in` | `bool` | Whether the decorator is a Fleet built-in |
| `updated_at` | `string` | ISO timestamp of the last update |

## Usage Example

```javascript
import decoratorInterface from "interfaces/decorators";

const MyComponent = ({ decorator }) => {
  // use decorator fields
};

MyComponent.propTypes = {
  decorator: decoratorInterface,
};
```
