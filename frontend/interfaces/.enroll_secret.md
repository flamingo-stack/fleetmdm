Defines PropTypes shape and TypeScript interfaces for Fleet MDM enroll secret entities used in device enrollment.

## Key Components

- **Default Export** — PropTypes shape validator for enroll secret objects, used for runtime prop validation in React components
- **`IEnrollSecret`** — Interface representing a single enroll secret with:
  - `secret` *(required)* — The secret string used for device enrollment
  - `created_at` *(optional)* — ISO timestamp of when the secret was created
  - `team_id` *(optional)* — Associated team identifier for team-scoped enrollment
- **`IEnrollSecretsResponse`** — Interface representing the API response containing an array of `IEnrollSecret` objects

## Usage Example

```typescript
import { IEnrollSecret, IEnrollSecretsResponse } from "./enroll_secret";

// Typing an API response
const response: IEnrollSecretsResponse = {
  secrets: [
    {
      secret: "abc123xyz",
      created_at: "2024-01-15T10:30:00Z",
      team_id: 42,
    },
  ],
};

// Accessing a single secret
const enrollSecret: IEnrollSecret = response.secrets[0];
console.log(enrollSecret.secret); // "abc123xyz"
```

## Notes

- `team_id` being optional allows this type to represent both global and team-scoped enroll secrets
- The PropTypes export enables legacy or mixed JS/TS component compatibility alongside the TypeScript interfaces
