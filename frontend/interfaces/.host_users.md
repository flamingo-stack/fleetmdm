Defines the PropTypes shape and TypeScript interface for host user objects returned from the Fleet MDM API.

## Key Components

- **Default export** — A `PropTypes.shape` validator describing the runtime shape of a host user object
- **`IHostUser`** — TypeScript interface representing a user account associated with a managed host

### `IHostUser` Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `number` | Unique record identifier |
| `uid` | `number` | OS-level user ID (UID) |
| `username` | `string` | Login username |
| `type` | `string` | Account type (e.g., `local`, `remote`) |
| `groupname` | `string` | Primary group name for the user |

## Usage Example

```typescript
import hostUserInterface, { IHostUser } from "./host_users";

// Type-safe usage
const user: IHostUser = {
  id: 42,
  uid: 1001,
  username: "jdoe",
  type: "local",
  groupname: "staff",
};

// PropTypes validation in a React component
MyComponent.propTypes = {
  hostUser: hostUserInterface,
};
```
