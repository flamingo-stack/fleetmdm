Defines TypeScript interfaces for self-service category data structures used in the Fleet MDM self-service portal.

## Key Components

- **`ISelfServiceCategory`** – Represents a full self-service category record returned from the API, including metadata fields (`id`, `fleet_id`, `created_at`, `updated_at`).
- **`ICreateSelfServiceCategoryFormData`** – Payload shape for creating a new self-service category, requiring `fleet_id` and `name`.
- **`IEditSelfServiceCategoryFormData`** – Payload shape for updating an existing category, accepting only `name`.

## Usage Example

```typescript
import {
  ISelfServiceCategory,
  ICreateSelfServiceCategoryFormData,
  IEditSelfServiceCategoryFormData,
} from "./self_service_category";

// Typed API response
const category: ISelfServiceCategory = {
  id: 1,
  name: "Security Tools",
  fleet_id: 42,
  created_at: "2024-01-15T10:00:00Z",
  updated_at: "2024-06-01T08:30:00Z",
};

// Create form payload
const createPayload: ICreateSelfServiceCategoryFormData = {
  fleet_id: 42,
  name: "Productivity Apps",
};

// Edit form payload
const editPayload: IEditSelfServiceCategoryFormData = {
  name: "Updated Category Name",
};
```
