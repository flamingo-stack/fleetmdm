Defines TypeScript interfaces for Fleet MDM query management, covering stored query responses, query metadata, and editable query form fields.

## Key Components

- **`IStoredQueryResponse`** – API response wrapper containing a single `ISchedulableQuery` object
- **`IQuery`** – Full query entity with metadata (timestamps, author info, observer permissions, associated packs, and optional stats)
- **`IEditQueryFormFields`** – Form field structure for the query editor UI, mapping `description`, `name`, `query`, and `observer_can_run` to `IFormField`

## Usage Example

```typescript
import { IQuery, IEditQueryFormFields, IStoredQueryResponse } from "./query";

// Typing an API response
const response: IStoredQueryResponse = await fetchQuery(queryId);

// Accessing query metadata
const query: IQuery = {
  id: 1,
  name: "List running processes",
  query: "SELECT * FROM processes;",
  description: "Returns all running processes",
  saved: true,
  author_id: 42,
  author_name: "Jane Doe",
  author_email: "jane@example.com",
  observer_can_run: false,
  packs: [],
  created_at: "2024-01-01T00:00:00Z",
  updated_at: "2024-01-02T00:00:00Z",
};

// Typing edit form fields
const formFields: IEditQueryFormFields = {
  name: { value: "List running processes", error: "" },
  description: { value: "Returns all running processes", error: "" },
  query: { value: "SELECT * FROM processes;", error: "" },
  observer_can_run: { value: false, error: "" },
};
```
