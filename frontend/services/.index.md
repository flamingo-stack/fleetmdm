Axios-based HTTP client utilities for making authenticated API requests, providing variants with progress tracking, custom headers, and upload/download monitoring.

## Key Components

| Export | Description |
|---|---|
| `sendRequest` | Base authenticated HTTP request function with positional parameters |
| `sendRequestWithProgress` | Object-parameter variant supporting `onDownloadProgress`, `onUploadProgress`, and `AbortSignal` |
| `sendRequestWithHeaders` | Extends `sendRequest` with support for merging custom headers (e.g., WAF bypass via base64-encoded scripts) |
| `sendRequestWithProgressAndHeaders` | Full-featured variant combining progress tracking and custom headers |

All functions:
- Automatically prepend `window.origin + URL_PREFIX + /api` to the provided path
- Attach a Bearer token from `authToken.get()` to every request
- Parse and normalize Axios errors unless `skipParseError` is set
- Return raw `AxiosResponse` when `returnRaw` is `true`, otherwise return `response.data`

## Usage Example

```typescript
import sendRequest, {
  sendRequestWithProgress,
  sendRequestWithHeaders,
} from "utilities/send_request";

// Basic GET
const data = await sendRequest("GET", "/v1/hosts");

// POST with custom timeout
const result = await sendRequest("POST", "/v1/queries", { query: "SELECT 1" }, "json", 5000);

// File upload with progress tracking
await sendRequestWithProgress({
  method: "POST",
  path: "/v1/software/package",
  data: formData,
  responseType: "json",
  onUploadProgress: (event) => {
    console.log(`Uploaded: ${event.loaded} / ${event.total}`);
  },
  signal: abortController.signal,
});

// Request with custom headers for WAF bypass
await sendRequestWithHeaders("POST", "/v1/scripts", encodedPayload, {
  "X-Fleet-Base64-Encoded": "true",
});
```
