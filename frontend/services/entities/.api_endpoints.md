Provides a service module for fetching all REST API endpoint configurations from the Fleet backend, returning a typed list of `IApiEndpoint` objects.

## Key Components

- **`IListApiEndpointsResponse`** — Interface describing the raw API response shape, containing an `api_endpoints` array.
- **`loadAll()`** — Async function that issues a `GET` request to `REST_API_ENDPOINTS` and returns the unwrapped `IApiEndpoint[]` array.

## Usage Example

```typescript
import apiEndpointsAPI from "services/entities/api_endpoints";

const fetchEndpoints = async () => {
  const endpoints = await apiEndpointsAPI.loadAll();
  console.log(endpoints); // IApiEndpoint[]
};
```

## Notes

- Delegates HTTP transport to the shared `sendRequest` service.
- The endpoint path is resolved via the `endpoints` utility (`utilities/endpoints`), keeping URL definitions centralised.
- See [`IApiEndpoint`](https://github.com/flamingo-stack/fleetmdm/blob/main/interfaces/api_endpoint.ts) for the full shape of individual endpoint objects.
