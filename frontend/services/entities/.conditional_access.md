Service module for managing Microsoft Conditional Access and Identity Provider (IdP) integrations, exposing API calls to trigger, confirm, delete, and retrieve CA-related resources.

## Key Components

**Types**

- `TriggerMSConditionalStatusResponse` — Response shape containing `microsoft_authentication_url` for initiating the Microsoft OAuth flow.
- `ConfirmMSConditionalAccessResponse` — Response shape with `configuration_completed` flag and `setup_error` string.

**`conditionalAccessService` (default export)**

| Method | HTTP | Description |
|---|---|---|
| `triggerMicrosoftConditionalAccess(msTenantId)` | `POST` | Initiates the Microsoft Conditional Access setup for a given tenant ID. |
| `confirmMicrosoftConditionalAccess()` | `POST` | Confirms and finalizes the Conditional Access configuration. |
| `deleteMicrosoftConditionalAccess()` | `DELETE` | Removes the existing Microsoft Conditional Access configuration. |
| `getIdpAppleProfile()` | `GET` | Fetches the IdP Apple profile as a plain-text string. |
| `getIdpSigningCert()` | `GET` | Downloads the IdP signing certificate as a `Blob`. |

## Usage Example

```typescript
import conditionalAccessService from "services/conditional_access";

// Trigger Microsoft Conditional Access setup
const { microsoft_authentication_url } =
  await conditionalAccessService.triggerMicrosoftConditionalAccess("my-tenant-id");
window.location.href = microsoft_authentication_url;

// Confirm setup after OAuth redirect
const { configuration_completed, setup_error } =
  await conditionalAccessService.confirmMicrosoftConditionalAccess();
if (!configuration_completed) {
  console.error("Setup failed:", setup_error);
}

// Download the IdP signing certificate
const certBlob = await conditionalAccessService.getIdpSigningCert();
const url = URL.createObjectURL(certBlob);
```
