Provides API service methods for checking the operational status of Fleet's result store and live query subsystems.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `result_store` | Function | Sends a GET request to check result store status |
| `live_query` | Function | Sends a GET request to check live query service status |

## Usage Example

```typescript
import statusService from "services/entities/status";

// Check result store health
const resultStoreStatus = await statusService.result_store();

// Check live query service health
const liveQueryStatus = await statusService.live_query();
```

## Endpoints Used

Both methods resolve their target URLs from the shared `endpoints` utility:

- `STATUS_RESULT_STORE` — result store health endpoint
- `STATUS_LIVE_QUERY` — live query health endpoint

> Requests are dispatched via the shared `sendRequest` utility from `services`, which handles authentication headers and response parsing consistently across the app.
