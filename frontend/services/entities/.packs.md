Service module for managing Fleet MDM query pack API operations, providing CRUD methods and label/query association management for packs.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `addLabel` | Function | Associates a label with a pack via `POST` |
| `addQuery` | Function | Associates a query with a pack via `POST` |
| `create` | Function | Creates a new pack with name, description, and targets |
| `destroy` | Function | Deletes a pack by ID via `DELETE` |
| `load` | Function | Fetches a single pack by ID via `GET` |
| `loadAll` | Function | Fetches all packs via `GET` |
| `update` | Function | Partially updates a pack via `PATCH`, separating targets from other fields |

### Interfaces

- **`ICreateProps`** — `{ name, description, targets: ISelectTargetsEntity[] }`
- **`IUpdatePack`** — Imported from `interfaces/pack`; used for partial pack updates

## Usage Example

```typescript
import packsService from "services/entities/packs";

// Create a new pack
await packsService.create({
  name: "Weekly Audit",
  description: "Runs weekly audit queries",
  targets: selectedTargets,
});

// Add a query to a pack
await packsService.addQuery(packID, queryID);

// Update an existing pack
await packsService.update(packId, {
  name: "Updated Pack",
  targets: newTargets,
});

// Load all packs
const allPacks = await packsService.loadAll();

// Delete a pack
await packsService.destroy(packID);
```

## Notes

- Target formatting is handled by `formatPackTargetsForApi` before sending to the API
- On `update`, the `targets` field is stripped via `lodash.omit` before merging formatted targets, preventing raw target objects from being sent directly
