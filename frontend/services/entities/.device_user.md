API service module for device user (DUP) operations, providing methods to interact with Fleet MDM device-scoped endpoints using a device authentication token.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `IDeviceSoftwareQueryKey` | Query key for device software list requests |
| `IGetDeviceSoftwareResponse` | Paginated software list response |
| `IGetDeviceCertificatesResponse` | Paginated certificates response |
| `IGetVppInstallCommandResultsResponse` | VPP command result response |
| `IGetSetupExperienceStatusesResponse` | Setup experience status (software + scripts steps) |
| `ILoadHostDetailsExtension` | Union type limiting extensions to `"macadmins"` |

### Service Methods

| Method | HTTP | Description |
|---|---|---|
| `loadHostDetails` | `GET` | Fetch device details, optionally excluding software |
| `loadHostDetailsExtension` | `GET` | Fetch extension data (e.g. macadmins) |
| `refetch` | `POST` | Trigger a device data refetch |
| `getDeviceSoftware` | `GET` | Paginated software list for a device |
| `installSelfServiceSoftware` | `POST` | Install a specific self-service software title |
| `installAllSelfServiceSoftwareInCategory` | `POST` | Install all uninstalled titles in a category |
| `uninstallSelfServiceSoftware` | `POST` | Uninstall a self-service software title |
| `getSoftwareInstallResult` | `GET` | Get install result by UUID |
| `getSoftwareUninstallResult` | `GET` | Get uninstall result by script execution ID |
| `getVppCommandResult` | `GET` | Get VPP MDM command result by UUID |
| `getDeviceCertificates` | `GET` | Paginated certificate list for a device |
| `getSetupExperienceStatuses` | `POST` | Get setup experience step statuses |
| `resendProfile` | `POST` | Resend an MDM configuration profile |
| `getMdmManualEnrollUrl` | `GET` | Retrieve MDM manual enrollment profile URL |
| `bypassConditionalAccess` | `POST` | Bypass conditional access for a device |

## Usage Example

```typescript
import deviceUserAPI from "services/entities/device_user";

// Load device details excluding software inventory
const details = await deviceUserAPI.loadHostDetails({
  token: "abc123devicetoken",
  exclude_software: true,
});

// Install a self-service software title
await deviceUserAPI.installSelfServiceSoftware("abc123devicetoken", 42);

// Install all items in a category (omit categoryId for all categories)
await deviceUserAPI.installAllSelfServiceSoftwareInCategory(
  "abc123devicetoken",
  7 // or undefined for all
);

// Retrieve paginated device certificates
const certs = await deviceUserAPI.getDeviceCertificates({
  token: "abc123devicetoken",
  page: 0,
  per_page: 20,
});
```
