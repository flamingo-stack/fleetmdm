Provides a simple API service module for fetching the current Fleet version from the server.

## Key Components

- **`load()`** — Sends a `GET` request to the `VERSION` endpoint and returns the server's version information.

## Usage Example

```typescript
import versionService from "services/version";

const fetchVersion = async () => {
  const version = await versionService.load();
  console.log(version);
};
```

## Notes

- Delegates HTTP communication to the shared `sendRequest` utility from `services`.
- The `VERSION` endpoint URL is resolved via the centralized `utilities/endpoints` map, keeping base URLs consistent across the application.
