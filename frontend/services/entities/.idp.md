Provides API methods for Identity Provider (IDP) operations, specifically for retrieving SCIM (System for Cross-domain Identity Management) provisioning details from the Fleet MDM backend.

## Key Components

### Interfaces

- **`IGetSCIMDetailsResponse`** — Response shape for SCIM details, containing a nullable `last_request` object with:
  - `requested_at` — ISO timestamp of the last SCIM request
  - `status` — Status string of the last request
  - `details` — Additional detail string about the last request

### Exported Methods

- **`getSCIMDetails()`** — Sends a `GET` request to the `SCIM_DETAILS` endpoint and returns a promise resolving to `IGetSCIMDetailsResponse`

## Usage Example

```typescript
import idpAPI from "services/entities/idp";

const fetchSCIMDetails = async () => {
  const response = await idpAPI.getSCIMDetails();

  if (response.last_request) {
    console.log("Last SCIM request at:", response.last_request.requested_at);
    console.log("Status:", response.last_request.status);
    console.log("Details:", response.last_request.details);
  } else {
    console.log("No SCIM requests have been made yet.");
  }
};
```

## Notes

- Returns `null` for `last_request` when no SCIM provisioning requests have been recorded
- Relies on the shared `sendRequest` service and the `SCIM_DETAILS` endpoint defined in [`utilities/endpoints`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/endpoints.ts)
