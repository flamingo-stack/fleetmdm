Defines the API service layer for managing global (non-team-scoped) policies in Fleet MDM, providing CRUD operations and paginated query support.

## Key Components

### Types & Interfaces

- **`GlobalPoliciesAutomationType`** — Subset of `AutomationType` excluding `"software"`, `"scripts"`, `"conditional_access"`, and `"calendar"`.
- **`IGlobalPoliciesApiQueryParams`** — Query parameters for paginated policy list requests (`page`, `perPage`, `orderKey`, `orderDirection`, `query`, `automationType`).
- **`IPoliciesQueryKey`** — React Query key shape for global policies list queries.
- **`IPoliciesCountQueryKey`** — React Query key shape for policy count queries.

### API Methods

| Method | HTTP | Description |
|---|---|---|
| `create(data)` | `POST` | Creates a new global policy |
| `destroy(ids)` | `POST` | Bulk-deletes policies by ID array |
| `update(id, data)` | `PATCH` | Updates an existing policy by ID |
| `load(id)` | `GET` | Fetches a single policy by ID |
| `loadAll()` | `GET` | Fetches all policies (no pagination) |
| `loadAllNew(params)` | `GET` | Fetches paginated/filtered policies |
| `getCount(params)` | `GET` | Returns total policy count with optional filters |

## Usage Example

```typescript
import globalPoliciesAPI from "services/entities/global_policies";

// Create a policy
await globalPoliciesAPI.create({ name: "Firewall Enabled", query: "SELECT 1 FROM firewall WHERE..." });

// Fetch paginated policies filtered by automation type
const response = await globalPoliciesAPI.loadAllNew({
  page: 0,
  perPage: 20,
  orderKey: "name",
  orderDirection: "asc",
  automationType: "failing_policy_webhook",
});

// Get policy count
const { count } = await globalPoliciesAPI.getCount({ query: "firewall" });

// Delete multiple policies
await globalPoliciesAPI.destroy([1, 2, 3]);
```
