Shared TypeScript interfaces and types for paginated list API responses and query parameters used across the Fleet MDM codebase.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ListEntitiesResponsePaginationCommon` | Interface | Pagination metadata flags for next/previous page availability |
| `ListEntitiesResponseCommon` | Interface | Base response shape for paginated entity lists, including `meta` and total `count` |
| `OrderDirection` | Type | Union type constraining sort direction to `"asc"` or `"desc"` |
| `PaginationParams` | Interface | Query parameters for requesting a specific page of results |

## Usage Example

```typescript
import type {
  ListEntitiesResponseCommon,
  OrderDirection,
  PaginationParams,
} from "./common";

interface ListDevicesResponse extends ListEntitiesResponseCommon {
  devices: Device[];
}

async function fetchDevices(
  params: PaginationParams,
  order: OrderDirection = "asc"
): Promise<ListDevicesResponse> {
  const { page, per_page } = params;
  const res = await api.get<ListDevicesResponse>(`/devices`, {
    params: { page, per_page, order },
  });
  return res.data;
}

// Check pagination state
const { meta, count, devices } = await fetchDevices({ page: 1, per_page: 25 });
if (meta.has_next_results) {
  // fetch next page
}
```
