Unit tests for the `listNamesFromSelectedLabels` utility function from the `labels` module, verifying correct filtering of selected label names from a boolean dictionary.

## Key Components

- **`listNamesFromSelectedLabels` tests** — Three test cases covering the core behavior of the labels utility:
  - Returns only keys with `true` values from a mixed dictionary
  - Returns an empty array when all values are `false`
  - Returns an empty array for an empty input object

## Usage Example

```typescript
import { listNamesFromSelectedLabels } from "./labels";

// Returns ["foo", "baz"] — only keys with true values
listNamesFromSelectedLabels({ foo: true, bar: false, baz: true });

// Returns [] — no selected labels
listNamesFromSelectedLabels({ foo: false, bar: false });

// Returns [] — empty input
listNamesFromSelectedLabels({});
```
