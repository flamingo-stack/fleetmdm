Service module for managing scheduled queries (pack queries) via REST API, providing CRUD operations for scheduling queries within query packs.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `create` | Function | Creates a new scheduled query within a pack |
| `destroy` | Function | Deletes a scheduled query by ID |
| `loadAll` | Function | Retrieves all scheduled queries for a given pack |
| `update` | Function | Updates an existing scheduled query's attributes |

## Usage Example

```typescript
import scheduledQueriesAPI from "services/entities/scheduled_queries";

// Create a scheduled query in a pack
await scheduledQueriesAPI.create({
  pack_id: 12,
  query_id: 5,
  interval: 3600,
  platform: "darwin",
});

// Load all scheduled queries for a pack
const queries = await scheduledQueriesAPI.loadAll(12);

// Update a scheduled query
await scheduledQueriesAPI.update(existingScheduledQuery, {
  interval: 7200,
  snapshot: true,
});

// Delete a scheduled query
await scheduledQueriesAPI.destroy(99);
```

## Notes

- **`create`** — POSTs to `SCHEDULE_QUERY` with raw form data.
- **`destroy`** — DELETEs to `SCHEDULE_QUERY/{id}`.
- **`loadAll`** — GETs from `SCHEDULED_QUERIES(packId)`, a pack-scoped endpoint.
- **`update`** — PATCHes to `SCHEDULE_QUERY/{id}`; attributes are pre-formatted via `helpers.formatScheduledQueryForServer` before transmission.
