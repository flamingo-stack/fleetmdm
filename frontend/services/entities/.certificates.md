Provides API service methods for managing certificate authorities (CAs) and certificates, including CRUD operations and certificate requests against Fleet MDM endpoints.

## Key Components

### Exported Types

| Type | Description |
|---|---|
| `IAddCertAuthorityFormData` | Union type for creating a CA — supports DigiCert, NDES, Custom SCEP, Hydrant, Smallstep, and Custom EST |
| `IEditCertAuthorityFormData` | Partial variant of `IAddCertAuthorityFormData` for patch updates |
| `ICertificate` | Shape of a certificate record returned by the API |
| `IGetCertsResponse` | Paginated response containing `certificates` and `meta` |
| `IAddCert` | Input parameters for creating a new certificate |
| `IQueryKeyGetCerts` | React Query key shape for the `getCerts` query |

### Service Methods

| Method | HTTP | Description |
|---|---|---|
| `getCertificateAuthoritiesList` | `GET` | Fetches all CA summaries |
| `getCertificateAuthority(id)` | `GET` | Fetches full details for a single CA |
| `addCertificateAuthority(data)` | `POST` | Creates a new CA |
| `editCertificateAuthority(id, data)` | `PATCH` | Updates an existing CA |
| `deleteCertificateAuthority(id)` | `DELETE` | Removes a CA |
| `requestCertificate(id)` | `GET` | Requests a certificate from a CA |
| `getCerts(params)` | `GET` | Paginated list of certificates, optionally filtered by `fleet_id` |
| `addCert(params)` | `POST` | Creates a certificate, mapping app-level "all teams" to the API sentinel |
| `deleteCert(id)` | `DELETE` | Removes a certificate by ID |

## Usage Example

```typescript
import certificatesAPI from "services/entities/certificates";

// List all certificate authorities
const { certificate_authorities } = await certificatesAPI.getCertificateAuthoritiesList();

// Add a DigiCert CA
await certificatesAPI.addCertificateAuthority({
  digicert: { url: "https://example.digicert.com", api_token: "token", profile_id: "profile123" },
});

// Fetch paginated certificates for a team
const { certificates, meta } = await certificatesAPI.getCerts({
  fleet_id: 42,
  page: 0,
  per_page: 20,
});

// Create a certificate
await certificatesAPI.addCert({
  name: "My Cert",
  certAuthorityId: 1,
  subjectName: "CN=device.example.com",
  subjectAlternativeName: "device.example.com",
  teamId: 42,
});
```

## Notes

- `subject_alternative_name` is omitted from `addCert` payloads when empty, so the server treats it as absent.
- When `teamId` equals `APP_CONTEXT_ALL_TEAMS_ID`, it is converted to the API-level `API_ALL_TEAMS_ID` sentinel before submission.
