Provides an API service function for generating AI-powered policy autofill suggestions (description and resolution) from a SQL query string.

## Key Components

- **`IAutofillPolicy`** – Type definition representing an autofilled policy with `description` and `resolution` string fields.
- **`getPolicyInterpretationFromSQL`** – Sends a `POST` request to the `AUTOFILL_POLICY` endpoint with a SQL string, returning a promise that resolves to an `IAutofillPolicy` object.

## Usage Example

```typescript
import autofillService, { IAutofillPolicy } from "services/autofill";

const sql = "SELECT * FROM hosts WHERE platform = 'darwin'";

const policy: IAutofillPolicy = await autofillService.getPolicyInterpretationFromSQL(sql);

console.log(policy.description); // AI-generated policy description
console.log(policy.resolution);  // AI-generated remediation steps
```
