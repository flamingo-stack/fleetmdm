Service module for Apple MDM API operations, providing functions to manage Apple Push Notification certificates, VPP (Volume Purchase Program) tokens, and App Store app assignments.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `IGetVppInfoResponse` | VPP organization info including name, renewal date, and location |
| `IVppApp` | App Store app metadata including bundle ID, icon, version, and platform |
| `IGetVppAppsResponse` | Wrapper for array of `IVppApp` |
| `IGetVppTokensResponse` | Wrapper for array of `IMdmVppToken` |
| `IUploadVppTokenResponse` / `IRenewVppTokenResponse` | Response shape for token upload/renew operations |

### Exported Methods

| Method | HTTP | Description |
|---|---|---|
| `getAppleAPNInfo` | `GET` | Fetch current APNs push certificate info |
| `uploadApplePushCertificate` | `POST` | Upload a new APNs `.pem` certificate |
| `deleteApplePushCertificate` | `DELETE` | Remove the APNs certificate |
| `requestCSR` | `GET` | Request a Certificate Signing Request |
| `getVppTokens` | `GET` | List all VPP tokens |
| `uploadVppToken` | `POST` | Upload a new VPP token file |
| `renewVppToken` | `PATCH` | Renew an existing VPP token by ID |
| `deleteVppToken` | `DELETE` | Remove a VPP token by ID |
| `disableVpp` | `DELETE` | Disable VPP entirely |
| `getVppApps` | `GET` | Fetch App Store apps available to a team |
| `editVppTeams` | `PATCH` | Assign or update teams associated with a VPP token |

## Usage Example

```typescript
import mdmAppleService from "services/mdm_apple";

// Upload an APNs push certificate
const certFile = new File([certData], "certificate.pem");
await mdmAppleService.uploadApplePushCertificate(certFile);

// Upload a VPP token and assign it to teams
const tokenFile = new File([tokenData], "vpp_token.vpptoken");
const { vpp_token } = await mdmAppleService.uploadVppToken(tokenFile);

await mdmAppleService.editVppTeams({
  tokenId: vpp_token.id,
  teamIds: [1, 2, 3],
});

// Fetch App Store apps available to team ID 42
const { app_store_apps } = await mdmAppleService.getVppApps(42);
```
