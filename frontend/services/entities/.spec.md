Provides API service methods for retrieving and applying global enroll secret specifications in FleetMDM.

## Key Components

- **`IEnrollSecretSpec`** — Interface defining the shape of an enroll secret specification payload, containing a `spec` object with an array of `IEnrollSecret` entries.
- **`getEnrollSecretSpec()`** — Sends a `GET` request to the `GLOBAL_ENROLL_SECRETS` endpoint to retrieve the current enroll secret spec.
- **`applyEnrollSecretSpec(spec)`** — Sends a `POST` request to the `GLOBAL_ENROLL_SECRETS` endpoint to apply a new enroll secret spec.

## Usage Example

```typescript
import enrollSecretService from "services/enroll_secret/spec";

// Fetch current enroll secret spec
const secretSpec = await enrollSecretService.getEnrollSecretSpec();

// Apply a new enroll secret spec
await enrollSecretService.applyEnrollSecretSpec({
  spec: {
    secrets: [
      { secret: "my-enroll-secret-value" },
    ],
  },
});
```

## Notes

- Both methods target the same `GLOBAL_ENROLL_SECRETS` endpoint defined in `utilities/endpoints`.
- The `applyEnrollSecretSpec` method sends the full `IEnrollSecretSpec` object as the request body.
