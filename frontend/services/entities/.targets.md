API service module for managing Fleet MDM targets, providing methods to search, count, and load hosts/labels/teams for query targeting.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ITargetsSearchParams` | Parameters for host search (query string, excluded host IDs, optional report ID) |
| `ITargetsSearchResponse` | Returns an array of matching `IHost` objects |
| `ITargetsCountParams` | Parameters for counting selected targets |
| `ITargetsCountResponse` | Returns `targets_count`, `targets_online`, and `targets_offline` totals |

### Exported Methods

| Method | Description |
|---|---|
| `loadAll(props)` | Loads all targets (hosts, labels, teams) via `POST /targets` |
| `search(params)` | Searches hosts by query string via `POST /hosts/search`; rejects if `query` or `excluded_host_ids` are missing |
| `count(params)` | Returns target counts via `POST /targets/count`; rejects if no selected targets |
| `DEPRECATED_loadAll(...)` | Legacy loader that appends type metadata to targets; pending removal once `SelectTargetsDropdown` is replaced |

## Usage Example

```typescript
import targetsAPI from "services/entities/targets";

// Search for hosts
const results = await targetsAPI.search({
  query: "macbook",
  excluded_host_ids: [1, 2, 3],
  report_id: null,
});

// Count selected targets
const counts = await targetsAPI.count({
  selected: { hosts: [4], labels: [], teams: [] },
});
console.log(counts.targets_count, counts.targets_online);

// Load all targets for a query
const all = await targetsAPI.loadAll({
  query: "production",
  queryId: 42,
  selected: { hosts: [], labels: ["linux"], teams: [] },
});
```

## Notes

- `search` and `count` include guard clauses that return a rejected `Promise` on missing required parameters rather than throwing synchronously.
- `DEPRECATED_loadAll` appends `target_type` metadata using `appendTargetTypeToTargets` and will be removed once [`SelectTargetsDropdown`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/forms/fields/SelectTargetsDropdown) is fully replaced by [`TargetsInput`](https://github.com/flamingo-stack/fleetmdm/blob/main/frontend/components/TargetsInput).
