API service module for managing Fleet team operations, providing typed wrappers around the Fleet REST API endpoints for team CRUD, user management, host transfer, and enrollment secret operations.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ILoadTeamResponse` | Response shape for single team fetch |
| `ILoadTeamsResponse` | Response shape for listing all teams |
| `ITeamFormData` | Payload for team creation |
| `IUpdateTeamFormData` | Full update payload including MDM, webhooks, integrations, host expiry, and features |

### Exported Methods

| Method | HTTP | Description |
|---|---|---|
| `create(formData)` | `POST` | Creates a new team |
| `destroy(teamId)` | `DELETE` | Deletes a team by ID |
| `load(teamId)` | `GET` | Fetches a single team config |
| `loadAll(params)` | `GET` | Lists all teams with optional filter |
| `update(formData, teamId)` | `PATCH` | Updates specific team fields |
| `updateConfig(data, teamId)` | `PATCH` | Updates arbitrary team config fields |
| `addUsers(teamId, newUsers)` | `PATCH` | Adds users to a team |
| `removeUsers(teamId, removeUsers)` | `DELETE` | Removes users from a team |
| `transferHosts(teamId, hostIds)` | `POST` | Transfers hosts to a team |
| `getEnrollSecrets(teamId)` | `GET` | Retrieves team enrollment secrets |
| `modifyEnrollSecrets(teamId, secrets)` | `PATCH` | Updates team enrollment secrets |

## Usage Example

```typescript
import teamsAPI from "services/entities/teams";

// Create a team
const newTeam = await teamsAPI.create({ name: "Engineering" });

// Load a specific team
const { team } = await teamsAPI.load(42);

// Update team MDM settings
await teamsAPI.update(
  {
    mdm: {
      macos_updates: {
        minimum_version: "14.0",
        deadline: "2024-12-01",
      },
    },
    host_expiry_settings: {
      host_expiry_enabled: true,
      host_expiry_window: 30,
    },
  },
  42
);

// Transfer hosts to a team
await teamsAPI.transferHosts(42, [101, 102, 103]);

// Manage enrollment secrets
await teamsAPI.modifyEnrollSecrets(42, [{ secret: "abc123", created_at: "" }]);
```

## Notes

- `load()` and `addUsers()`/`removeUsers()` validate the `teamId` against `API_NO_TEAM_ID` before sending requests, rejecting with an error for invalid IDs.
- The `update()` method filters integration properties (Jira, Zendesk) using `lodash.pick` to ensure only permitted fields are sent to the API.
- `modifyEnrollSecrets()` strips all secret fields except `"secret"` before submission.
