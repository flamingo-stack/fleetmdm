Provides API service functions for querying operating system version data from the Fleet MDM backend, including list and detail endpoints with filtering and pagination support.

## Key Components

### Constants

- **`OS_VERSIONS_API_SUPPORTED_PLATFORMS`** — Array of platform strings (`darwin`, `windows`, `chrome`, `ios`, `ipados`, `android`) supported by the OS versions API.

### Interfaces

| Interface | Description |
|---|---|
| `IGetOSVersionsQueryParams` | Query parameters for listing OS versions (platform, teamId, pagination, etc.) |
| `IGetOSVersionsQueryKey` | Extends query params with a `scope` string for React Query cache keys |
| `IOSVersionsResponse` | Response shape for the OS versions list endpoint |
| `IGetOsVersionOptions` | Options for fetching a single OS version by ID |
| `IGetOsVersionQueryKey` | Extends options with `scope: "osVersionDetails"` for React Query |
| `IOSVersionResponse` | Response shape for a single OS version detail endpoint |

### Functions

- **`getOSVersions(params)`** — Fetches a paginated list of OS versions with optional filtering by platform, team, name, version, and vulnerability count.
- **`getOSVersion(options)`** — Fetches details for a single OS version by `os_version_id`, optionally scoped to a team.

## Usage Example

```typescript
import osVersionsAPI from "services/operating_systems";

// Fetch paginated OS versions for macOS
const response = await osVersionsAPI.getOSVersions({
  platform: "darwin",
  teamId: 3,
  page: 0,
  per_page: 20,
  max_vulnerabilities: 5,
});

// Fetch a single OS version detail
const detail = await osVersionsAPI.getOSVersion({
  os_version_id: 42,
  teamId: 3,
});
```
