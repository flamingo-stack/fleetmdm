Service module providing API methods for Mobile Device Management (MDM) operations, including profile management, bootstrap packages, EULA handling, Apple SSO enrollment, and setup experience configuration.

## Key Components

### Exported Types & Interfaces

| Type | Description |
|---|---|
| `IEulaMetadataResponse` | EULA file metadata (name, token, created_at) |
| `ProfileStatusSummaryResponse` | Record mapping `MdmProfileStatus` to counts |
| `IMdmProfilesResponse` | Paginated profiles list with navigation metadata |
| `IUploadProfileApiParams` | Parameters for profile upload including label filtering |
| `IGetProfilesApiParams` | Pagination and team filter params for profile listing |
| `IAppleSetupEnrollmentProfileResponse` | Apple enrollment profile with team and upload details |
| `IGetSetupExperienceScriptResponse` | Setup experience script metadata |
| `IGetSetupExperienceSoftwareResponse` | Software titles for setup experience flow |

### Helper

- **`isDDMProfile`** — Determines if a profile is a DDM (Declarative Device Management) profile by checking if `profile_uuid` starts with `"d"`.

### `mdmService` Methods

| Method | HTTP | Description |
|---|---|---|
| `unenrollHostFromMdm` | DELETE | Removes a host from MDM enrollment |
| `requestCSR` | GET | Requests a Certificate Signing Request |
| `getProfiles` | GET | Fetches paginated MDM profiles |
| `uploadProfile` | POST | Uploads a profile with optional label scoping |
| `downloadProfile` | GET | Downloads a profile as media |
| `deleteProfile` | DELETE | Removes a profile by ID |
| `getProfilesStatusSummary` | GET | Gets profile status counts per team |
| `initiateMDMAppleSSO` | POST | Starts Apple MDM SSO flow |
| `getBootstrapPackageMetadata` | GET | Fetches bootstrap package metadata |
| `uploadBootstrapPackage` | POST | Uploads a bootstrap package |
| `deleteBootstrapPackage` | DELETE | Removes a bootstrap package |
| `getBootstrapPackageAggregate` | GET | Gets bootstrap package install summary |
| `getEULAMetadata` | GET | Retrieves EULA file metadata |
| `uploadEULA` | POST | Uploads a EULA file |
| `deleteEULA` | DELETE | Removes EULA by token |
| `downloadEULA` | GET | Downloads EULA by token |
| `updateSetupExperienceSettings` | PATCH | Updates setup experience configuration |
| `updateReleaseDeviceSetting` | PATCH | Toggles manual device release |
| `getSetupEnrollmentProfile` | GET | Fetches Apple setup enrollment profile |
| `uploadSetupEnrollmentProfile` | POST | Parses and uploads JSON enrollment profile |
| `deleteSetupEnrollmentProfile` | DELETE | Removes Apple enrollment profile |
| `downloadManualEnrollmentProfile` | GET | Downloads enrollment profile as blob |
| `getSetupExperienceSoftware` | GET | Lists software for setup experience |
| `updateSetupExperienceSoftware` | PUT | Sets software titles for setup experience |
| `getSetupExperienceScript` | GET | Fetches setup experience script metadata |
| `downloadSetupExperienceScript` | GET | Downloads setup experience script |
| `uploadSetupExperienceScript` | POST | Uploads a setup experience script |

## Usage Example

```typescript
import mdmService from "services/mdm";

// Upload an MDM profile scoped to specific labels
await mdmService.uploadProfile({
  file: profileFile,
  teamId: 42,
  labelsIncludeAll: ["macOS", "Production"],
  labelsExcludeAny: ["Legacy"],
});

// Fetch paginated profiles
const { profiles, meta } = await mdmService.getProfiles({
  page: 0,
  per_page: 20,
  fleet_id: 42,
});

// Check if a profile uses Declarative Device Management
const isDDM = isDDMProfile(profiles[0]); // true if uuid starts with "d"

// Initiate Apple SSO enrollment
const ssoResponse = await mdmService.initiateMDMAppleSSO({
  deviceinfo: "<encoded-device-info>",
  initiator: "orbit",
  host_uuid: "abc-123",
});
```
