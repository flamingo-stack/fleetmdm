Provides CRUD operations and search functionality for managing user invitations in the Fleet MDM platform.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ISortOption` | Defines sort configuration with `id` and `desc` (descending) fields |
| `IInviteSearchOptions` | Options for filtering/paginating invite listings (`page`, `perPage`, `globalFilter`, `sortBy`) |
| `IValidateInviteResponse` | Response shape returned from invite token verification |

### Exported Methods

| Method | HTTP | Description |
|---|---|---|
| `create(formData)` | `POST` | Creates a new invite and appends a Gravatar URL to the returned resource |
| `update(inviteId, formData)` | `PATCH` | Updates an existing invite by ID |
| `destroy(inviteId)` | `DELETE` | Deletes an invite by ID |
| `verify(token)` | `GET` | Validates an invite token and returns the associated `IInvite` |
| `loadAll(options)` | `GET` | Fetches all invites with optional global search filter; appends Gravatar URLs to each result |

## Usage Example

```typescript
import invitesAPI from "services/entities/invites";

// Create a new invite
const newInvite = await invitesAPI.create({
  email: "user@example.com",
  global_role: "observer",
});

// Verify an invite token
const { invite } = await invitesAPI.verify("abc123token");

// Load all invites with a search filter
const invites = await invitesAPI.loadAll({ globalFilter: "example.com" });

// Update an existing invite
await invitesAPI.update(42, { global_role: "admin" });

// Delete an invite
await invitesAPI.destroy(42);
```

## Notes

- Gravatar URLs are automatically appended to invite objects on `create` and `loadAll` via `helpers.addGravatarUrlToResource`.
- The `verify` endpoint delegates to a dynamic endpoint builder (`endpoints.INVITE_VERIFY(token)`).
- Search queries in `loadAll` are serialized into query strings via `buildQueryStringFromParams`.
