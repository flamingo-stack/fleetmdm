Service module for managing Apple Business Manager (ABM) MDM token operations, including fetching ABM info, uploading/renewing tokens, and managing team assignments.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `IAppleBusinessTokenFormData` | Form data shape for token file upload |
| `IGetAppleBMInfoResponse` | Apple BM info response (Apple ID, org name, renew date, etc.) |
| `IGetAbTokensResponse` | Paginated list of ABM tokens |
| `IAbTokenResponse` | Single ABM token response wrapper |

### Exported Methods

| Method | HTTP | Description |
|--------|------|-------------|
| `getAppleBMInfo()` | `GET` | Fetches Apple Business Manager info |
| `loadKeys()` | `POST` | Generates and base64-decodes public/private keypair |
| `downloadPublicKey()` | `GET` | Downloads the ABM public key |
| `uploadToken(token)` | `POST` | Uploads a new ABM `.p7m` token file |
| `renewToken(id, token)` | `PATCH` | Renews an existing ABM token by ID |
| `deleteToken(id)` | `DELETE` | Removes an ABM token by ID |
| `getTokens()` | `GET` | Lists all ABM tokens |
| `editTeams(params)` | `PATCH` | Assigns iOS/iPadOS/macOS/BYOD fleet teams to a token |

## Usage Example

```typescript
import appleBmService from "services/entities/mdm_apple_bm";

// Fetch Apple BM org info
const bmInfo = await appleBmService.getAppleBMInfo();
console.log(bmInfo.org_name, bmInfo.renew_date);

// Upload a new ABM token
const tokenFile: File = event.target.files[0];
const newToken = await appleBmService.uploadToken(tokenFile);

// Assign fleet teams to a token
await appleBmService.editTeams({
  tokenId: newToken.id,
  teams: {
    ios_fleet_id: 1,
    ipados_fleet_id: 2,
    macos_fleet_id: 3,
    byod_fleet_id: 4,
  },
});

// Generate and decode enrollment keypair
const { decodedPublic, decodedPrivate } = await appleBmService.loadKeys();
```

> **Note:** `loadKeys()` decodes the server-returned base64 keys using `window.atob` and rejects the promise if decoding fails or keys are missing.
