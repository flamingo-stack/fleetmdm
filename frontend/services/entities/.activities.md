Service module for fetching and managing Fleet activity data, including global activities and host-specific past/upcoming activities.

## Key Components

### Response Interfaces

- **`IActivitiesResponse`** — Paginated global activity list with `has_next_results` / `has_previous_results` meta flags
- **`IHostPastActivitiesResponse`** — Paginated past activity list scoped to a specific host
- **`IHostUpcomingActivitiesResponse`** — Paginated upcoming activity list with an additional `count` field

### Default Parameters

| Constant | Value |
|---|---|
| `DEFAULT_PAGE` | `0` |
| `DEFAULT_PAGE_SIZE` | `8` |
| `ORDER_KEY` | `"created_at"` |
| `ORDER_DIRECTION` | `"desc"` |

### Exported Methods

- **`loadNext`** — Fetches global activities with filtering support (search query, date range, activity type, sort direction)
- **`getHostPastActivities`** — Retrieves paginated past activities for a host by ID
- **`getHostUpcomingActivities`** — Retrieves paginated upcoming activities for a host by ID
- **`cancelHostActivity`** — Cancels a pending host activity via `DELETE` using host ID and activity UUID

## Usage Example

```typescript
import activitiesAPI from "services/activities";

// Load global activities with filters
const response = await activitiesAPI.loadNext(
  0,
  8,
  "script",
  "desc",
  "2024-01-01",
  "2024-12-31",
  ["ran_script"]
);

// Fetch past activities for a host
const pastActivities = await activitiesAPI.getHostPastActivities(42, 0, 8);

// Fetch upcoming activities for a host
const upcoming = await activitiesAPI.getHostUpcomingActivities(42);

// Cancel a pending activity
await activitiesAPI.cancelHostActivity(42, "uuid-1234-abcd");
```
