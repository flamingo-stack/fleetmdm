Service module for managing Fleet MDM labels via API — handles CRUD operations, label filtering, and response type definitions for both dynamic and manual label types.

## Key Components

### Response Interfaces
- `ILabelsResponse` — Array of full `ILabel` objects
- `ILabelsSummaryResponse` — Array of lightweight `ILabelSummary` objects
- `ICreateLabelResponse` / `IUpdateLabelResponse` / `IGetLabelResponse` — Single label response wrapper

### Utility Exports
- `getCustomLabels<T>()` — Filters labels to `"regular"` type and sorts them case-insensitively (locale-aware alphabetical order)
- `listNamesFromSelectedLabels()` — Extracts selected label names from a `Record<string, boolean>` selection map

### API Methods (default export)
| Method | HTTP | Description |
|---|---|---|
| `create(formData)` | `POST` | Creates manual, dynamic, or host-vitals label |
| `destroy(label)` | `DELETE` | Deletes label by ID |
| `loadAll(teamID?)` | `GET` | Loads all labels with host counts; supports team/global scoping |
| `summary(teamID?, treatAllTeamsAsGlobalOnly?)` | `GET` | Loads lightweight label summaries |
| `update(labelId, formData)` | `PATCH` | Updates dynamic or manual label |
| `specByName(labelName)` | `GET` | Fetches label spec by name |
| `getLabel(labelId)` | `GET` | Fetches a single label |
| `getHostsInLabel(labelId)` | `GET` | Fetches hosts belonging to a label |

## Usage Example

```typescript
import labelsService, { getCustomLabels, listNamesFromSelectedLabels } from "services/entities/labels";

// Load all labels scoped to a team
const { labels } = await labelsService.loadAll(teamID);

// Filter and sort custom (user-created) labels
const customLabels = getCustomLabels(labels);

// Get selected label names from a checkbox map
const selected = listNamesFromSelectedLabels({ "macOS": true, "Windows": false });
// => ["macOS"]

// Create a manual label
await labelsService.create({
  type: "manual",
  name: "My Servers",
  description: "Manually targeted hosts",
  targetedHosts: [{ id: 1 }, { id: 2 }],
});

// Delete a label
await labelsService.destroy(label);
```
