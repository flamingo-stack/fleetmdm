Provides an API service for fetching host query report (HQR) data, mapping to the Fleet MDM host query report endpoint.

## Key Components

- **`IHQRResult`** — Interface representing a single query result row, with a `columns` map of column names to string values.
- **`IGetHQRResponse`** — Interface representing the full API response, including host metadata, fetch timestamp, clipping status, and result rows.
- **`load(hostId, queryId)`** — Sends a `GET` request to retrieve the query report for a specific host and query ID pair.

## Usage Example

```typescript
import hostQueryReport from "services/host_query_report";

const report = await hostQueryReport.load(42, 7);

console.log(report.host_name);       // e.g. "my-macbook.local"
console.log(report.report_clipped);  // true if results were truncated
console.log(report.results);         // IHQRResult[]
```

## Notes

- `last_fetched` may be `null` if the query has never been executed on the host.
- `report_clipped` indicates the result set was truncated server-side; consumers should surface this to the user.
- The underlying endpoint is resolved via `endpoints.HOST_QUERY_REPORT(hostId, queryId)`.
