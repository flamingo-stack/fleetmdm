Provides API service methods for managing Android MDM (Mobile Device Management) enrollment and enterprise connectivity within the Fleet MDM platform.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `getSignupUrl` | Function | Fetches the Android Enterprise signup URL for initiating enrollment |
| `getAndroidEnterprise` | Function | Retrieves current Android Enterprise enrollment status |
| `turnOffAndroidMdm` | Function | Disables Android MDM by deleting the enterprise registration |
| `startSSE` | Function | Opens a Server-Sent Events stream to detect successful Android Enterprise connection |

### Interfaces

- **`IGetAndroidSignupUrlResponse`** — Shape of the signup URL response (`android_enterprise_signup_url: string`)
- **`IGetAndroidEnterpriseResponse`** — Shape of the enterprise status response (`android_enterprise_id: boolean`)

## Usage Example

```typescript
import mdmAndroid from "services/mdm_android";

// Get the signup URL to redirect an admin for enrollment
const { android_enterprise_signup_url } = await mdmAndroid.getSignupUrl();

// Monitor connection completion via SSE
const controller = new AbortController();
try {
  await mdmAndroid.startSSE(controller.signal);
  console.log("Android Enterprise connected successfully");
} catch (err) {
  console.error("SSE failed:", err);
}

// Disable Android MDM
await mdmAndroid.turnOffAndroidMdm();
```

## Notes

- `startSSE` uses the [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) instead of the native `EventSource` API because `EventSource` does not support custom headers — required here for Bearer token authentication.
- The SSE stream buffers chunks across network frames to reliably detect split success/error signals.
- `AbortError` is silently swallowed in `startSSE` to support clean unmount cancellation.
