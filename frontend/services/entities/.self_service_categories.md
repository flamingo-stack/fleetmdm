API service module for managing self-service categories, providing CRUD operations and device-token-scoped access for fleet-aware category retrieval.

## Key Components

### Response Interfaces
- **`ISelfServiceCategoriesResponse`** — Wraps an array of `ISelfServiceCategory` objects returned by list endpoints.
- **`ISelfServiceCategoryResponse`** — Wraps a single `ISelfServiceCategory` object returned by create/update endpoints.

### Service Methods

| Method | HTTP | Description |
|---|---|---|
| `getCategories(fleetId)` | `GET` | Fetches all categories for a given fleet, scoped by `fleet_id` query param. |
| `getDeviceCategories(deviceToken)` | `GET` | Fetches categories for the fleet derived from a device token (end-user scoped). |
| `addCategory(formData)` | `POST` | Creates a new self-service category. |
| `updateCategory(id, formData)` | `PATCH` | Updates an existing category by ID. |
| `deleteCategory(id)` | `DELETE` | Removes a category by ID. |

## Usage Example

```typescript
import selfServiceCategoriesAPI from "services/entities/self_service_categories";

// Admin: fetch all categories for a fleet
const { self_service_categories } = await selfServiceCategoriesAPI.getCategories(42);

// End-user: fetch categories scoped to device's fleet
const { self_service_categories } = await selfServiceCategoriesAPI.getDeviceCategories("device-token-xyz");

// Create a new category
const { self_service_category } = await selfServiceCategoriesAPI.addCategory({
  name: "Security Tools",
  description: "Security-related self-service apps",
});

// Update an existing category
await selfServiceCategoriesAPI.updateCategory(7, { name: "Updated Name" });

// Delete a category
await selfServiceCategoriesAPI.deleteCategory(7);
```

> **Note:** `getDeviceCategories` uses a separate endpoint (`DEVICE_SELF_SERVICE_CATEGORIES`) where the backend resolves the fleet from the device token, ensuring end users only see categories relevant to their own fleet rather than the global set.
