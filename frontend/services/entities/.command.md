Provides API service methods for retrieving MDM commands and their execution results, supporting both fleet-wide and host-specific command result queries.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `IGetCommandsApiParams` | Query parameters for listing commands, including pagination, sorting, filtering by host, request type, and status |
| `IGetCommandsResponse` | Paginated response containing a list of `ICommand` objects and pagination metadata |
| `IGetCommandResultsResponse` | Response containing an array of `ICommandResult` objects |
| `IGetCommandResultsParams` | Parameters requiring a `command_uuid` to fetch results |
| `IGetHostCommandResultsParams` | Extends `IGetCommandResultsParams` with a `host_identifier` for host-scoped queries |
| `IGetHostCommandResultsQueryKey` | React Query key shape for host command result queries, adding a `scope` discriminator |

### API Methods

| Method | Description |
|---|---|
| `getCommands(requestParams)` | Fetches a paginated list of MDM commands with optional filtering and sorting |
| `getCommandResults(command_uuid)` | Retrieves execution results for a specific command across all hosts |
| `getHostCommandResults({ host_identifier, command_uuid })` | Retrieves execution results for a specific command scoped to a single host |

## Usage Example

```typescript
import commandAPI from "services/entities/command";

// Fetch filtered commands list
const commands = await commandAPI.getCommands({
  page: 0,
  per_page: 20,
  order_key: "updated_at",
  order_direction: "desc",
  command_status: "Acknowledged",
});

// Fetch results for a specific command
const results = await commandAPI.getCommandResults("abc-uuid-123");

// Fetch results scoped to a specific host
const hostResults = await commandAPI.getHostCommandResults({
  command_uuid: "abc-uuid-123",
  host_identifier: "device-hostname.local",
});
```
