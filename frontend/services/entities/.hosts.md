Provides the API service layer for host management operations in Fleet MDM, including loading, filtering, exporting, and performing bulk actions on managed hosts.

## Key Components

### Interfaces & Types
- **`ILoadHostsOptions`** — Query options for fetching host lists (pagination, filters, MDM status, software, OS, labels, etc.)
- **`IExportHostsOptions`** — Options for exporting host data to CSV, mirrors `ILoadHostsOptions` with export-specific fields
- **`IActionByFilter`** — Filter parameters for bulk operations (delete, transfer) scoped by team, policy, software, OS, and MDM state
- **`ILoadHostsResponse`** — API response shape for host list queries
- **`IDepAssignmentHostResponse`** — DEP profile assignment details per host
- **`IGetHostSoftwareResponse`** — Paginated software inventory for a host
- **`IGetHostCertificatesResponse`** — Paginated TLS certificates for a host
- **`IUnlockHostResponse`** — Unlock PIN response for macOS hosts
- **`HOSTS_QUERY_PARAMS`** — Canonical filter parameter name constants (`os_settings`, `software_status`, `script_batch_execution_status`, etc.)

### Helper Functions (internal)
- **`getLabel`** — Extracts the `labels/` prefixed label from selected filters
- **`getHostEndpoint`** — Returns `HOSTS` or `LABEL_HOSTS(id)` based on active label selection
- **`getSortParams`** — Maps `ISortOption[]` to API `order_key`/`order_direction` params
- **`createMdmParams`** — Builds MDM query string, handling the `"all"` platform special case

### API Methods (default export)
- **`destroy(host)`** — `DELETE /hosts/:id`
- **`destroyBulk(hostIds)`** — `POST /hosts/delete` with ID array
- **`destroyByFilter(filters)`** — `POST /hosts/delete` with full filter object for bulk deletion
- **`exportHosts(options)`** — Builds and sends export request with all active filters applied

## Usage Example

```typescript
import hostsAPI, { ILoadHostsOptions } from "services/hosts";

// Delete a single host
await hostsAPI.destroy(host);

// Bulk delete by ID
await hostsAPI.destroyBulk([101, 102, 103]);

// Delete hosts matching filters
await hostsAPI.destroyByFilter({
  teamId: 2,
  query: "macbook",
  status: "online",
  softwareStatus: "vulnerable",
  diskEncryptionStatus: "failed",
});

// Export hosts with visible columns
await hostsAPI.exportHosts({
  sortBy: [{ key: "hostname", direction: "asc" }],
  teamId: 2,
  status: "online",
  visibleColumns: "hostname,platform,status",
});
```
