API service module for managing custom variables in Fleet MDM, providing CRUD operations for variable resources via HTTP requests.

## Key Components

### Interfaces

- **`IListVariablesApiParams`** — Pagination parameters (`page`, `per_page`) for listing variables
- **`IListVariablesResponse`** — Response shape containing `custom_variables`, pagination `meta`, and total `count`

### Methods

| Method | HTTP | Description |
|---|---|---|
| `getVariables(params)` | `GET` | Fetches a paginated list of custom variables |
| `addVariable(variable)` | `POST` | Creates a new custom variable |
| `deleteVariable(variableId)` | `DELETE` | Removes a variable by ID |

## Usage Example

```typescript
import variablesAPI from "services/entities/variables";

// Fetch paginated variables
const response = await variablesAPI.getVariables({ page: 0, per_page: 20 });
console.log(response.custom_variables); // IVariable[]
console.log(response.meta.has_next_results); // boolean

// Create a new variable
await variablesAPI.addVariable({ name: "API_KEY", value: "abc123" });

// Delete a variable by ID
await variablesAPI.deleteVariable(42);
```

## Notes

- Built on the shared `sendRequest` utility from `services`, inheriting standard error handling and auth headers
- Query strings are constructed via `buildQueryStringFromParams`, omitting undefined values automatically
