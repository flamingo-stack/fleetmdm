Provides CRUD operations for managing Fleet MDM enroll secrets at both the global and team levels, acting as a service layer that delegates to the `specAPI` and `teamsAPI` clients.

## Key Components

| Method | Description |
|--------|-------------|
| `getGlobalEnrollSecrets` | Fetches the global enroll secret spec, returning the `secrets` array |
| `modifyGlobalEnrollSecrets` | Applies an updated global enroll secret spec |
| `getTeamEnrollSecrets` | Fetches enroll secrets for a specific team, rejecting invalid or no-team IDs |
| `modifyTeamEnrollSecrets` | Updates enroll secrets for a specific team, rejecting invalid or no-team IDs |

## Usage Example

```typescript
import enrollSecretAPI from "services/entities/enroll_secret";

// Global secrets
const globalSecrets = await enrollSecretAPI.getGlobalEnrollSecrets();

await enrollSecretAPI.modifyGlobalEnrollSecrets([
  { secret: "abc123", created_at: "2024-01-01T00:00:00Z" },
]);

// Team secrets (teamId must be > API_NO_TEAM_ID)
const teamSecrets = await enrollSecretAPI.getTeamEnrollSecrets(42);

await enrollSecretAPI.modifyTeamEnrollSecrets(42, [
  { secret: "xyz789", created_at: "2024-01-01T00:00:00Z" },
]);

// Invalid team ID — rejects with an Error
enrollSecretAPI.getTeamEnrollSecrets(0).catch((err) => {
  console.error(err.message); // "Invalid team id: 0 must be greater than ..."
});
```

## Notes

- Team-scoped methods guard against `teamId` values of `undefined`, `0`, or anything `≤ API_NO_TEAM_ID`, rejecting early with a descriptive `Error`.
- Global secret operations route through `specAPI` (spec-based apply/get), while team operations route through `teamsAPI` (REST endpoints).
