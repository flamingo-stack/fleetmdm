Provides API service methods for uploading and deleting organization logo assets, supporting configurable display modes.

## Key Components

- **`upload(file, mode)`** — Sends a `PUT` request with the logo file as `multipart/form-data` to the logo endpoint, scoped by the specified `IOrgLogoMode`.
- **`delete(mode)`** — Sends a `DELETE` request to remove the organization logo for the given mode.
- **`IOrgLogoMode`** — Imported interface that defines valid logo display modes (defaults to `"all"`).

## Usage Example

```typescript
import logoService from "services/logo";

// Upload a new organization logo
const file = new File([blob], "logo.png", { type: "image/png" });
await logoService.upload(file, "light");

// Delete the organization logo for all modes
await logoService.delete();

// Delete logo for a specific mode
await logoService.delete("dark");
```

## Notes

- Both methods default `mode` to `"all"` if not specified.
- The `upload` method constructs a `FormData` payload with the file appended under the `"logo"` key.
- Query parameters (e.g., `?mode=light`) are appended to the endpoint path via `getPathWithQueryParams`.
- Relies on the shared `sendRequest` utility from `services` for HTTP transport.
