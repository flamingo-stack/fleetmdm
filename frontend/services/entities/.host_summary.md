Provides a service function to fetch a summarized overview of hosts from the Fleet MDM API, supporting optional filtering by team, platform, and disk space.

## Key Components

- **`ISummaryProps`** — Interface defining optional query parameters:
  - `teamId` — Filter by Fleet team ID
  - `platform` — Filter by OS platform
  - `lowDiskSpace` — Filter hosts with low disk space (threshold in GB)
- **`getSummary`** — Sends a `GET` request to the `HOST_SUMMARY` endpoint with the provided filters serialized as query string parameters

## Usage Example

```typescript
import hostSummaryService from "services/entities/host_summary";

const summary = await hostSummaryService.getSummary({
  teamId: 3,
  platform: "darwin",
  lowDiskSpace: 10,
});
```

## Notes

- Query parameters are built via `buildQueryStringFromParams`, which omits `undefined` values automatically
- The endpoint path is resolved from the centralized `endpoints` utility, keeping URL management consistent across the codebase
