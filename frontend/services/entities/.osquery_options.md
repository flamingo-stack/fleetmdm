Provides API service methods for retrieving and updating osquery/agent options at both the global and team levels.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `loadAll` | Function | Fetches all global osquery options via `GET /osquery_options` |
| `update` | Function | Posts agent options to a given endpoint (generic, caller-supplied path) |
| `updateTeam` | Function | Posts agent options scoped to a specific team, with team ID validation |

## Usage Example

```typescript
import osqueryOptionsService from "services/osquery_options";

// Load global osquery options
const options = await osqueryOptionsService.loadAll();

// Update agent options for a specific team
await osqueryOptionsService.updateTeam(42, {
  config: {
    options: {
      logger_snapshot_event_type: true,
    },
  },
});

// Update agent options using a custom endpoint
await osqueryOptionsService.update(
  { options: { distributed_interval: 30 } },
  "/api/v1/fleet/config"
);
```

## Notes

- `updateTeam` rejects with an `Error` if `teamId` is falsy or `<= API_NO_TEAM_ID`, preventing accidental global-scope overwrites via a team-scoped call.
- `update` is intentionally generic — the caller is responsible for providing the correct endpoint string (e.g., team-specific or global config paths).
- Relies on [`endpoints`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/endpoints.ts) for URL resolution and [`sendRequest`](https://github.com/flamingo-stack/fleetmdm/blob/main/services/index.ts) for HTTP transport.
