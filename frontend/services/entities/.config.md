Configuration service module that provides API methods for loading and updating Fleet application configuration, certificates, enrollment secrets, MDM settings, and sandbox expiry data.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `loadAll` | `() => Promise<IConfig>` | Fetches the full application configuration |
| `loadCertificate` | `() => Promise<string>` | Fetches and base64-decodes the certificate chain |
| `loadEnrollSecret` | `() => Promise<any>` | Fetches the global enrollment secret |
| `update` | `(formData, skipParseError?) => Promise<any>` | Updates app config via PATCH request |
| `updateMDMConfig` | `(mdm, skipParseError?) => Promise<any>` | Updates MDM-specific config via PATCH request |
| `loadSandboxExpiry` | `() => Promise<string \| undefined>` | Fetches sandbox instance expiry timestamp from external endpoint |

## Usage Example

```typescript
import configAPI from "services/config";

// Load full app configuration
const config = await configAPI.loadAll();

// Load and decode the TLS certificate chain
const certificate = await configAPI.loadCertificate();

// Update general app config, handling raw AxiosError on failure
await configAPI.update({ org_info: { org_name: "Acme" } }, true);

// Update MDM-specific settings
await configAPI.updateMDMConfig(
  { apple_bm_default_team: "Engineering" },
  true
);

// Load sandbox expiry (uses axios directly against external endpoint)
const expiry = await configAPI.loadSandboxExpiry();
```

## Notes

- `loadCertificate` decodes the response's `certificate_chain` field using `window.atob` and rejects the promise if decoding fails or the result is empty.
- `update` and `updateMDMConfig` accept an optional `skipParseError` flag — when `true`, callers must handle raw `AxiosError` rejection themselves.
- `loadSandboxExpiry` deviates from the standard `sendRequest` pattern, using `axios` directly against `https://sandbox.fleetdm.com/expires` with the subdomain extracted from `window.location.host` as the instance ID.
