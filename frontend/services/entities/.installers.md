Provides API service methods for checking the existence of Fleet MDM installers by sending HEAD requests to the download installer endpoint.

## Key Components

- **`ICheckInstallerExistenceApiParams`** – Interface defining the parameters required to check installer existence:
  - `enrollSecret` – Enrollment secret (URL-encoded in the request)
  - `includeDesktop` – Boolean flag to include the Fleet Desktop component
  - `installerType` – Installer type (e.g., `pkg`, `msi`, `deb`, `rpm`) from `IInstallerType`
- **`checkInstallerExistence`** – Sends a `HEAD` request to verify an installer exists without downloading it, returning a `Promise<BlobPart>`

## Usage Example

```typescript
import installersAPI from "services/installers";

const checkInstaller = async () => {
  try {
    await installersAPI.checkInstallerExistence({
      enrollSecret: "my-enroll-secret",
      includeDesktop: true,
      installerType: "pkg",
    });
    console.log("Installer exists");
  } catch (error) {
    console.error("Installer not found", error);
  }
};
```

## Notes

- Uses a `HEAD` HTTP method, so no response body is returned — only the status code is used to determine existence
- The `enrollSecret` is passed through `encodeURIComponent` to safely handle special characters in the URL
- Endpoint is constructed using the `DOWNLOAD_INSTALLER` constant from [`utilities/endpoints`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/endpoints.ts)
