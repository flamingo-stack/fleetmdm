Service module for interacting with MDM configuration profile API endpoints, providing methods to retrieve profile details, check deployment status, and resend failed profiles.

## Key Components

### Types & Interfaces

- **`IGetConfigProfileResponse`** — Alias for `IMdmProfile`; represents a single MDM config profile.
- **`IGetConfigProfileStatusResponse`** — Breakdown of profile deployment counts across four states: `verified`, `verifying`, `failed`, and `pending`.

### Methods

| Method | HTTP | Description |
|---|---|---|
| `getConfigProfile(uuid)` | `GET` | Fetches a single config profile by UUID. |
| `getConfigProfileStatus(uuid)` | `GET` | Returns host-level deployment status counts for a profile. |
| `batchResendConfigProfile(uuid)` | `POST` | Re-sends a profile to all hosts where it is in a `failed` state. |

## Usage Example

```typescript
import configProfilesAPI from "services/config_profiles";

// Fetch profile details
const profile = await configProfilesAPI.getConfigProfile("abc-123");

// Check deployment status
const status = await configProfilesAPI.getConfigProfileStatus("abc-123");
console.log(`Failed: ${status.failed}, Pending: ${status.pending}`);

// Retry failed deployments
await configProfilesAPI.batchResendConfigProfile("abc-123");
```

## Notes

- `batchResendConfigProfile` hardcodes `profile_status: "failed"` in its filter body — it only targets hosts that failed to receive the profile.
- All methods delegate to `sendRequest` using endpoint constructors from `utilities/endpoints`.
