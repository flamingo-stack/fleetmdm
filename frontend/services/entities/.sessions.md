Handles authentication session management, including standard email/password login, MFA completion, logout, and SSO initialization/settings retrieval.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `ILoginProps` | Email and password credentials for standard login |
| `ICreateSessionProps` | Token payload for completing MFA |
| `ISSOSettingsResponse` | Wraps `ISSOSettings` returned from the SSO endpoint |
| `ILoginResponse` | Full login response including user, available teams/fleets, and session token |

### Exported Methods

| Method | HTTP | Description |
|--------|------|-------------|
| `login` | `POST` | Authenticates with email/password; throws raw `202` response for MFA flows |
| `finishMFA` | `POST` | Completes MFA by exchanging a token for a full session |
| `destroy` | `POST` | Logs out the current session |
| `initializeSSO` | `POST` | Initiates SSO flow with a relay URL |
| `ssoSettings` | `GET` | Fetches current SSO configuration settings |

> All methods that return a user object automatically enrich it with a Gravatar URL via `helpers.addGravatarUrlToResource`.

## Usage Example

```typescript
import sessionAPI from "services/sessions";

// Standard login
const response = await sessionAPI.login({ email: "user@example.com", password: "secret" });
console.log(response.user, response.token);

// Handle MFA (202 status throws)
try {
  await sessionAPI.login({ email, password });
} catch (rawResponse) {
  if (rawResponse.status === 202) {
    const session = await sessionAPI.finishMFA({ token: mfaToken });
  }
}

// SSO
await sessionAPI.initializeSSO("https://example.com/relay");
const { settings } = await sessionAPI.ssoSettings();

// Logout
await sessionAPI.destroy();
```
