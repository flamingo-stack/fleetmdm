Provides CRUD service methods for managing global scheduled queries in FleetMDM, wrapping HTTP requests to the `GLOBAL_SCHEDULE` API endpoint.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `create` | Function | Creates a new global scheduled query from `IPackQueryFormData` |
| `destroy` | Function | Deletes a scheduled query by numeric ID |
| `loadAll` | Function | Fetches all global scheduled queries |
| `update` | Function | Patches an existing scheduled query with updated attributes |

## Usage Example

```typescript
import globalScheduledQueriesAPI from "services/global_scheduled_queries";

// Create a new scheduled query
await globalScheduledQueriesAPI.create({
  interval: 3600,
  logging_type: "snapshot",
  platform: "darwin",
  query_id: 42,
  shard: 100,
  version: "4.0.0",
});

// Load all scheduled queries
const allQueries = await globalScheduledQueriesAPI.loadAll();

// Update an existing query
await globalScheduledQueriesAPI.update(existingQuery, updatedFormData);

// Delete a scheduled query
await globalScheduledQueriesAPI.destroy({ id: 7 });
```

## Notes

- `logging_type` is mapped internally: `"differential"` sets `removed: true`; `"snapshot"` sets `snapshot: true`
- `update` delegates parameter formatting to `helpers.formatScheduledQueryForServer`
- All numeric fields (`interval`, `shard`, `report_id`) are explicitly cast with `Number()` on `create`
