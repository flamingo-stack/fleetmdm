Provides API service methods for managing Fleet queries, including CRUD operations, bulk deletion, paginated listing, and live query execution.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ILoadQueriesParams` | Pagination, filtering, and sorting parameters for listing queries |
| `IQueryKeyLoadQueries` | Extends `ILoadQueriesParams` with a `scope` discriminator for React Query |
| `IQueriesResponse` | Paginated response shape including queries array, count, and pagination meta |
| `ICreateQueryResponse` | Response shape for query creation |

### Exported Methods

| Method | HTTP | Description |
|---|---|---|
| `create` | `POST` | Creates a new query; trims the name field |
| `destroy` | `DELETE` | Deletes a single query by ID |
| `bulkDestroy` | `POST` | Deletes multiple queries by ID array |
| `load` | `GET` | Fetches a single query by ID |
| `loadAll` | `GET` | Lists queries with filtering, sorting, and pagination; maps `darwin` → `macos` and `fleet_id` → `team_id` |
| `run` | `POST` | Executes a live query against selected targets; returns the campaign object |
| `update` | `PATCH` | Updates an existing query; trims the name field |

## Usage Example

```typescript
import queryAPI from "services/queries";

// Create a query
const { query } = await queryAPI.create({
  name: "Active Processes",
  query: "SELECT * FROM processes;",
  description: "Lists all running processes",
});

// List queries with filters
const { queries, count } = await queryAPI.loadAll({
  teamId: 1,
  page: 0,
  perPage: 20,
  orderKey: "name",
  orderDirection: "asc",
  targetedPlatform: "darwin",
});

// Run a live query
const campaign = await queryAPI.run({
  query: "SELECT * FROM os_version;",
  queryId: query.id,
  selected: { hosts: [42], labels: [], teams: [] },
});

// Bulk delete
await queryAPI.bulkDestroy([1, 2, 3]);
```

> **Platform note:** `targetedPlatform: "darwin"` is automatically converted to `"macos"` before the API request to match the Fleet API and database convention.
