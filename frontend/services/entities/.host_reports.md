Provides API service functions and TypeScript interfaces for listing and paginating host reports associated with a specific host in the Fleet MDM system.

## Key Components

### Interfaces

- **`IHostReport`** — Represents a single host report with fields for ID, name, description, fetch timestamps, result counts, clipping status, and storage preferences.
- **`IListHostReportsResponse`** — Paginated response wrapper containing an array of `IHostReport` items, total count, and pagination metadata (`has_previous_results`, `has_next_results`).
- **`IListHostReportsParams`** — Optional query parameters for filtering and paginating the reports list, including `page`, `per_page`, `order_key`, `order_direction`, `query`, and `include_reports_dont_store_results`.

### Exports

- **`list(hostId, params?)`** — Fetches a paginated list of reports for a given host. Builds a query string from the provided params and dispatches a `GET` request to the `HOST_REPORTS` endpoint.

## Usage Example

```typescript
import hostReportsService from "services/entities/host_reports";

// Fetch page 1 of reports for host ID 42, ordered by name
const response = await hostReportsService.list(42, {
  page: 0,
  per_page: 20,
  order_key: "name",
  order_direction: "asc",
  include_reports_dont_store_results: true,
});

console.log(response.reports);       // IHostReport[]
console.log(response.count);         // total report count
console.log(response.meta);          // pagination flags
```

## Notes

- Only defined parameters are appended to the query string — `undefined` values are safely omitted.
- The `query` field is destructured separately to keep naming consistent with the API's search parameter convention.
