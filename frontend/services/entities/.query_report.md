Handles API requests for loading query reports, supporting sort options and optional team filtering via query parameters.

## Key Components

### Interfaces

- **`ISortOption`** — Defines a sort option with `key` (field name) and `direction` (e.g., `"asc"` / `"desc"`).
- **`ILoadQueryReportOptions`** — Parameters for loading a query report: `id`, `sortBy` array, and optional `teamId`.
- **`ILoadQueryReportQueryParams`** — Internal shape of the query string params sent to the API.

### Functions

- **`getSortParams(sortOptions?)`** — Extracts the first sort option into `order_key` and `order_direction` params; returns empty object if none provided.
- **`load({ id, sortBy, teamId })`** — Builds the full request URL using the query report endpoint, appends sort and team params, then fires a `GET` request.

## Usage Example

```typescript
import queryReportService from "services/entities/query_report";

const report = await queryReportService.load({
  id: 42,
  sortBy: [{ key: "host_display_name", direction: "asc" }],
  teamId: 7,
});
```

This will send a `GET` request to:

```text
/api/v1/fleet/queries/42/report?order_key=host_display_name&order_direction=asc&fleet_id=7
```

If `teamId` is `0` or omitted, the `fleet_id` param is excluded from the request.

## Notes

- Only the **first** entry in `sortBy` is used; multi-column sorting is not supported.
