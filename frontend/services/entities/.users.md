Service module providing API methods for all user-related operations in the Fleet MDM application, including authentication, user management, and password operations.

## Key Components

### Exported Interfaces

| Interface | Description |
|---|---|
| `ISortOption` | Sort configuration with `id` and `desc` (descending) flag |
| `IGetMeResponse` | Response shape for the current user endpoint, including `user`, `available_teams`, and `settings` |

### Internal Interfaces

- **`IUserSearchOptions`** — Pagination, filtering, and sorting options for user list queries
- **`IForgotPassword`** — Email payload for password reset initiation
- **`IUpdatePassword`** — Old/new password pair for authenticated password changes
- **`IRequirePasswordReset`** — Flag to force a password reset on next login

### API Methods

| Method | HTTP | Description |
|---|---|---|
| `me()` | `GET` | Fetches the current authenticated user with UI settings |
| `loadAll()` | `GET` | Lists all users with optional filter and team scope |
| `getUserById()` | `GET` | Fetches a single user by ID |
| `create()` | `POST` | Creates a user via invitation flow |
| `createUserWithoutInvitation()` | `POST` | Admin-creates a user without invitation |
| `createApiOnlyUser()` | `POST` | Creates an API-only user with optional role/team scope |
| `updateApiOnlyUser()` | `PATCH` | Updates an API-only user's attributes |
| `update()` | `PATCH` | Updates a standard user's profile data |
| `updateAdmin()` | `POST` | Toggles admin status for a user |
| `destroy()` | `DELETE` | Deletes a user by ID |
| `deleteSessions()` | `DELETE` | Invalidates all sessions for a user |
| `enable()` | `POST` | Enables or disables a user account |
| `forgotPassword()` | `POST` | Initiates a password reset email |
| `resetPassword()` | `POST` | Completes a password reset using a token |
| `changePassword()` | `POST` | Changes password for authenticated user |
| `requirePasswordReset()` | `POST` | Forces password reset on next login |
| `performRequiredPasswordReset()` | `POST` | Completes a required password reset |
| `confirmEmailChange()` | `GET` | Confirms an email change via token |
| `setup()` | `POST` | Submits initial instance registration data |

## Usage Example

```typescript
import usersAPI from "services/users";

// Fetch the current authenticated user
const { user, available_teams, settings } = await usersAPI.me();

// Load all users scoped to a team
const users = await usersAPI.loadAll({ teamId: 3, globalFilter: "alice" });

// Create an API-only user with a global role
const { user, token } = await usersAPI.createApiOnlyUser({
  name: "ci-bot",
  global_role: "observer",
});

// Force a password reset for a specific user
await usersAPI.requirePasswordReset(userId, { require: true });
```

> **Note:** All methods that return a user object automatically enrich the response with a Gravatar URL via `helpers.addGravatarUrlToResource`.
