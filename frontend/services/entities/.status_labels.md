Provides a service interface for retrieving status label counts from the Fleet MDM API.

## Key Components

- **`getCounts`** — Sends a `GET` request to the `STATUS_LABEL_COUNTS` endpoint and returns the response containing counts for all status labels.

## Usage Example

```typescript
import statusLabels from "services/status_labels";

const fetchStatusCounts = async () => {
  const counts = await statusLabels.getCounts();
  console.log(counts);
};
```

## Notes

- Relies on `sendRequest` from the shared `services` module for HTTP communication.
- The endpoint `STATUS_LABEL_COUNTS` is resolved from the centralized `utilities/endpoints` config.
- Source: [`services/status_labels.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/services/status_labels.ts)
