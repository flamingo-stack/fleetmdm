Provides a service module for fetching MacAdmins aggregate data from the Fleet API, supporting optional team-scoped queries.

## Key Components

- **`loadAll(teamId?)`** — Sends a `GET` request to the MacAdmins endpoint. Accepts an optional `teamId` to scope results to a specific fleet/team via query string parameter (`fleet_id`).

## Usage Example

```typescript
import macAdminsService from "services/entities/macadmins";

// Fetch MacAdmins data for all teams
const allData = await macAdminsService.loadAll();

// Fetch MacAdmins data scoped to a specific team
const teamData = await macAdminsService.loadAll(42);
```

## Notes

- Uses the `MACADMINS` endpoint constant from `utilities/endpoints`.
- Query string construction is handled by `buildQueryStringFromParams`, which maps `teamId` to the `fleet_id` parameter.
- Returns the raw promise from `sendRequest`, allowing callers to handle resolution and errors.
