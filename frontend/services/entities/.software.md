API service module for managing software operations in Fleet MDM, including fetching software titles/versions, managing packages, VPP apps, Android apps, and Fleet-maintained applications.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ISoftwareApiParams` | Query parameters for software list endpoints (pagination, filtering, sorting) |
| `ISoftwareTitlesResponse` | Paginated response for software titles |
| `ISoftwareVersionsResponse` | Paginated response for software versions |
| `ISoftwareTitlesQueryKey` / `ISoftwareVersionsQueryKey` | React Query cache key shapes |
| `IAddAppStoreAppFormData` | Payload for adding VPP/Android App Store apps |
| `IEditAppStoreAppFormData` | Payload for editing App Store apps |
| `ISoftwareFleetMaintainedAppsQueryParams` | Query params for Fleet-maintained app listing |

### Internal Helpers

| Function | Description |
|---|---|
| `handleAndroidForm` | Builds and sends POST request for adding an Android app |
| `handleVppAppForm` | Builds and sends POST request for adding a VPP app |
| `handleEditPackageForm` | Populates `FormData` for editing a software package, including Base64-encoded scripts |
| `handleDisplayNameForm` | Appends display name to a `FormData` instance |
| `handleDisplayNameAppStoreAppForm` | Sets `display_name` on an App Store edit payload |
| `handleConfigurationAppStoreAppForm` | Sets MDM `configuration` on an App Store edit payload |
| `handleAutoUpdateConfigAppStoreAppForm` | Sets auto-update window and label targeting on an App Store edit payload |
| `handleEditAppStoreAppForm` | Merges self-service, categories, and label targeting into an App Store edit payload |

## Usage Example

```typescript
// Fetch paginated software titles for a team
const params: ISoftwareApiParams = {
  page: 0,
  perPage: 20,
  teamId: 42,
  vulnerable: true,
};

// Query key for React Query
const queryKey: ISoftwareTitlesQueryKey = {
  scope: "software-titles",
  ...params,
};

// Add a VPP app
await handleVppAppForm(teamId, {
  selectedApp: { app_store_id: "123456789", platform: "ios" },
  selfService: true,
  automaticInstall: false,
  targetType: "All hosts",
});
```

## Notes

- Script fields (`install_script`, `pre_install_query`, etc.) are **Base64-encoded** via `encodeScriptBase64` to bypass WAF rules.
- Label targeting supports three modes: `labelsIncludeAny`, `labelsIncludeAll`, and `labelsExcludeAny`.
- Default sort is `name` ascending (`ORDER_KEY = "name"`, `ORDER_DIRECTION = "asc"`).
