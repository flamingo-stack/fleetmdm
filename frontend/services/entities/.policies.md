Provides a service module for loading global fleet policies by ID from the Fleet API.

## Key Components

- **`load(id: number)`** — Fetches a single stored policy by its numeric ID via a `GET` request to the `GLOBAL_POLICIES` endpoint, returning a `Promise<IStoredPolicyResponse>`.

## Usage Example

```typescript
import policiesService from "services/entities/policies";

const fetchPolicy = async (policyId: number) => {
  const policy = await policiesService.load(policyId);
  console.log(policy);
};
```
