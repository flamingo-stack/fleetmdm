Provides a service function to fetch the total count of hosts from the Fleet API, applying a rich set of optional filters (labels, policies, MDM status, software, OS, vulnerabilities, etc.).

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `ISortOption` | Defines a sort key and direction |
| `IHostsCountResponse` | API response shape containing a single `count: number` |
| `IHostsCountQueryKey` | Extends load options with a `scope` discriminator for query caching |
| `IHostCountLoadOptions` | Full set of optional filter parameters passed to the count endpoint |

### Default Export — `load(options)`

Accepts an `IHostCountLoadOptions` object (or `undefined`) and returns a `Promise<IHostsCountResponse>`. Internally it:

1. Extracts and normalises all filter options from the input.
2. Calls `reconcileMutuallyInclusiveHostParams` for params that must coexist (e.g. `teamId` + `macSettingsStatus`).
3. Calls `reconcileMutuallyExclusiveHostParams` to strip conflicting filters (e.g. `label` vs `policyId`).
4. Builds the query string via `buildQueryStringFromParams` and issues a `GET` request to the `HOSTS_COUNT` endpoint.

## Usage Example

```typescript
import hostCountService from "services/entities/host_count";

const fetchCount = async () => {
  const response = await hostCountService.load({
    teamId: 3,
    status: "online",
    softwareTitleId: 42,
    osSettings: "failed",
  });

  console.log(`Matching host count: ${response.count}`);
};
```

> **Note:** Mutually exclusive filters (e.g. `policyId` and `label`) are automatically reconciled — only one will be forwarded to the API per request. See `reconcileMutuallyExclusiveHostParams` in [`utilities/url`](https://github.com/flamingo-stack/fleetmdm/blob/main/utilities/url) for reconciliation logic.
