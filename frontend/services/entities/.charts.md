Provides a typed API client for fetching time-series chart data from Fleet MDM metric endpoints, with support for filtering by labels, platforms, and host IDs.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `IChartDataPoint` | Single time-series data point with `timestamp` and `value` |
| `IChartFilters` | Filter options for labels, platforms, and host inclusion/exclusion |
| `IChartResponse` | Full API response including metric metadata and data points |
| `IChartApiParams` | Serializable query parameters for chart API requests |
| `IChartQueryKey` | React Query cache key shape scoped to `"chart"` |

### Methods

- **`getChartData(metric, params)`** — Sends a `GET` request to the chart data endpoint for a given metric, appending optional query parameters as a query string.

## Usage Example

```typescript
import chartsAPI from "services/entities/charts";

// Fetch MDM enrollment data for the last 30 days
const response = await chartsAPI.getChartData("mdm_enrolled", {
  days: 30,
  resolution: 1,
  platforms: "macos,windows",
  label_ids: "1,2,3",
  exclude_host_ids: "99",
});

// response conforms to IChartResponse
console.log(response.data); // IChartDataPoint[]
```

## Notes

- Query parameters are serialized via `buildQueryStringFromParams` — array-type filters (`label_ids`, `platforms`, etc.) must be pre-serialized as comma-delimited strings in `IChartApiParams`.
- The endpoint path is resolved via `endpoints.CHART_DATA(metric)`, making the metric name a path segment.
- See the full source at [`services/entities/charts.ts`](https://github.com/flamingo-stack/fleetmdm/blob/main/services/entities/charts.ts).
