Service module for Fleet MDM script management, providing typed API methods and interfaces for CRUD operations on scripts, script execution, and batch script runs across hosts.

## Key Components

### Type Exports

| Type | Description |
|------|-------------|
| `IScriptResponse` | Single script from `GET /script/:id` |
| `IScriptsResponse` | Paginated script list from `GET /scripts` |
| `IScriptResultResponse` | Execution result including `exit_code`, `output`, and `host_timeout` |
| `IHostScriptsResponse` | Scripts associated with a specific host |
| `IScriptRunFormData` / `IScriptRunResponse` | Async single-host script run request/response |
| `IRunScriptBatchFormData` | Union type — target hosts either by `host_ids` or `filters` (mutually exclusive) |
| `IScriptBatchSummaryV1` / `IScriptBatchSummaryV2` | Batch summary shapes for deprecated and current endpoints |
| `IScriptBatchHostResult` | Per-host result within a batch execution |

### API Methods

| Method | HTTP | Endpoint |
|--------|------|----------|
| `getScripts` | `GET` | `/scripts` |
| `getScript` | `GET` | `/script/:id` |
| `uploadScript` | `POST` | `/scripts` (multipart) |
| `updateScript` | `PATCH` | `/script/:id` (multipart) |
| `downloadScript` | `GET` | `/script/:id?alt=media` |
| `deleteScript` | `DELETE` | `/script/:id` |
| `getScriptResult` | `GET` | `/scripts/results/:executionId` |
| `runScript` | `POST` | `/scripts/run` |
| `runScriptBatch` | `POST` | `/scripts/run/batch` |
| `cancelScriptBatch` | `POST` | `/scripts/run/batch/:id/cancel` |
| `getRunScriptBatchSummaryV1` | `GET` | Deprecated V1 summary |
| `getRunScriptBatchSummaryV2` | `GET` | Current V2 summary |
| `getRunScriptBatchSummaries` | `GET` | Paginated batch list |
| `getScriptBatchHostResults` | `GET` | Per-host results for a batch |
| `getHostScripts` | `GET` | `/hosts/:id/scripts` |

## Usage Example

```typescript
import scriptsAPI from "services/entities/scripts";

// Run a script on a single host
const { execution_id } = await scriptsAPI.runScript({
  host_id: 42,
  script_id: 7,
});

// Poll for result
const result = await scriptsAPI.getScriptResult(execution_id);
console.log(result.exit_code, result.output);

// Run a script batch by filters
const { batch_execution_id } = await scriptsAPI.runScriptBatch({
  script_id: 7,
  filters: { team_id: 1, status: "online" },
  not_before: "2025-01-01T00:00:00Z",
});

// Fetch per-host results
const hosts = await scriptsAPI.getScriptBatchHostResults({
  batch_execution_id,
  status: "ran",
  page: 0,
  per_page: 20,
  order_key: "display_name",
  order_direction: "asc",
});
```

> **Note:** `IRunScriptBatchFormData` uses a discriminated union — `host_ids` and `filters` are mutually exclusive. `order_key: "script_executed_at"` is remapped to `"updated_at"` when sent to the server.
