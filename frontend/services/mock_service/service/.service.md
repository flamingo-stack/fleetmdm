Implements the core request-routing logic for the FleetMDM mock API service, matching incoming requests to configured response handlers based on method, path, and query string parts.

## Key Components

- **`sleep(ms)`** — Promise-based delay utility used to simulate network latency configured via `DELAY`.
- **`splitRouteAndQueryString(path)`** — Strips the base endpoint prefix and splits a URL path into its route and query string segments.
- **`getParts(pathString)`** — Decomposes a full path string into individual route and query parts for comparison.
- **`isPartMatch(partToMatch, configPart, wildcards)`** — Compares a single request part against a config part, treating any configured wildcard tokens as catch-all matchers.
- **`matchPathToResponse(method, requestPath)`** — Filters the pre-built `partsByPathByMethod` lookup to find all config entries whose parts align with the incoming request.
- **`sendRequest(method, requestPath, data)`** *(default export)* — Orchestrates the full mock request lifecycle: resolves the matching handler (function or static object), applies the simulated delay, and resolves or rejects the Promise accordingly.

## Usage Example

```typescript
import sendRequest from "./service";

// Simulates a GET request to a mocked endpoint
const response = await sendRequest("GET", "/api/v1/hosts?page=1");

// Simulates a POST with a request body
const created = await sendRequest("POST", "/api/v1/devices", {
  hostname: "macbook-pro-01",
  platform: "darwin",
});
```
