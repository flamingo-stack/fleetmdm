Mock response fixtures for host-related API endpoints used in testing and development environments.

## Key Components

| Export | Description |
|--------|-------------|
| `ALL_HOSTS` | Array of all hosts using the base `HOST_ID` fixture |
| `HOSTS_TEAM_ID` | Hosts filtered by a specific team ID (`2`, team `n00bz`) |
| `HOSTS_TEAM_1337` | Hosts filtered by team ID `1337` (team `h4x0r`) |
| `HOST_ID` | Base host fixture with full host detail shape (ID `1337`) |
| `HOST_1337` | Extended host fixture with team assignment spread over `HOST_ID` |
| `DEVICE_MAPPING` | Device mapping response stub with `host_id` and null mapping |
| `MACADMINS` | macOS admins response stub with null payload |

## Usage Example

```typescript
// Copy this file to ../mocks/responses.ts before editing
// Import mock responses in your test or MSW handler

import responses from "../mocks/responses";

// Use a specific fixture in a test
const host = responses.HOST_ID.host;
console.log(host.hostname); // "myf1337d3v1c3"
console.log(host.status);   // "online"

// Use as a mock API response body
server.use(
  rest.get("/api/v1/fleet/hosts/:id", (_req, res, ctx) => {
    return res(ctx.json(responses.HOST_ID));
  })
);
```
