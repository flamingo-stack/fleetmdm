Test suite for the `sortAvailableTeams` utility from `app.ts`, verifying team list ordering and filtering behavior based on user role.

## Key Components

- **`sortAvailableTeams`** — The function under test, imported from `./app`
- **`createMockUser`** — Mock factory used to simulate global and non-global users

## Test Cases

| Scenario | Description |
|---|---|
| Global user | "Unassigned" is placed last; "All fleets" appears first |
| Non-global user | "All fleets" and "Unassigned" are excluded entirely |
| Alphabetical sort | Named teams are sorted case-insensitively |

## Usage Example

```typescript
// Global user sees all teams with special ordering
const teams = [
  { id: 0, name: "Unassigned" },
  { id: -1, name: "All fleets" },
  { id: 1, name: "Alpha" },
];

const globalResult = sortAvailableTeams(teams, createMockUser());
// → ["All fleets", "Alpha", "Unassigned"]

// Non-global user sees only named teams, alphabetically
const teamResult = sortAvailableTeams(teams, createMockUser({ global_role: null }));
// → ["Alpha"]
```
