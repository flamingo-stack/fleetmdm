Global React context provider for the Fleet MDM application, managing authentication state, team context, permissions, and configuration throughout the component tree.

## Key Components

### `AppContext`
The React context object consumed by child components via `useContext(AppContext)`.

### `initialState`
Default state object exported for testing and context initialization, with all permission flags set to `undefined`/`false` and setters as no-ops.

### `AppContext` Provider (`App`)
The root provider component that wraps the app, exposing state and dispatch-bound action callbacks.

### `ACTIONS` (enum)
Internal action types for the reducer: `SET_CURRENT_USER`, `SET_CURRENT_TEAM`, `SET_CONFIG`, `SET_AVAILABLE_TEAMS`, and expiry/path-filter actions.

### `setPermissions` (internal helper)
Recomputes all role/permission flags (e.g., `isGlobalAdmin`, `isTeamMaintainer`) whenever `currentUser`, `config`, or `currentTeam` changes.

### `sortAvailableTeams`
Exported utility that sorts teams alphabetically, injecting "All teams" at the top and "No team" at the bottom for global team members.

## Usage Example

```typescript
// Consume context in a child component
import { useContext } from "react";
import { AppContext } from "context/app";

const MyComponent = () => {
  const {
    currentUser,
    isGlobalAdmin,
    currentTeam,
    setCurrentTeam,
    config,
  } = useContext(AppContext);

  return (
    <div>
      {isGlobalAdmin && <AdminPanel />}
      <TeamSelector
        teams={availableTeams}
        onSelect={setCurrentTeam}
      />
    </div>
  );
};
```

## State Shape Highlights

| Field | Description |
|-------|-------------|
| `currentUser` | Authenticated `IUser` or `null` |
| `currentTeam` | Active `ITeamSummary` scope |
| `config` | Fleet server `IConfig` |
| `isGlobalAdmin` / `isTeamAdmin` | Computed permission flags |
| `filteredHostsPath` | Persisted hosts filter URL |
| `isAppleBmExpired` / `willAppleBmExpire` | ABM/APNs/VPP certificate expiry state |
