React context provider managing table row selection state, exposing a `resetSelectedRows` flag and its setter to descendant components.

## Key Components

- **`TableContext`** — React context with `InitialStateType` shape; consume via `useContext(TableContext)` in any child component
- **`TableProvider`** — Wraps children with `TableContext.Provider`; uses `useReducer` + `useMemo` to manage and memoize state
- **`resetSelectedRows`** — Boolean flag signaling that selected rows should be cleared
- **`setResetSelectedRows(update: boolean)`** — Dispatches `RESET_SELECTED_ROWS` to toggle the flag

## Usage Example

```typescript
// Wrap your table component tree
import TableProvider, { TableContext } from "./table";

function App() {
  return (
    <TableProvider>
      <MyTable />
    </TableProvider>
  );
}

// Consume in a child component
import { useContext } from "react";
import { TableContext } from "./table";

function MyTable() {
  const { resetSelectedRows, setResetSelectedRows } = useContext(TableContext);

  useEffect(() => {
    if (resetSelectedRows) {
      clearSelection();
      setResetSelectedRows(false);
    }
  }, [resetSelectedRows]);

  return <table>{/* ... */}</table>;
}
```

## Notes

- `useMemo` dependency is scoped to `state.resetSelectedRows`, preventing unnecessary re-renders
- Default `setResetSelectedRows` in `initialState` is a no-op (`() => null`); only functional when consumed inside a `TableProvider`
