Provides a React context and provider for managing flash/toast notifications across the application, supporting both single and multiple simultaneous notifications.

## Key Components

- **`NotificationContext`** — React context exposing notification state and control functions; consumed via `useContext(NotificationContext)`
- **`NotificationProvider`** — Wraps the app (or a subtree) to supply notification state via `useReducer`
- **`INotificationContext`** — Exported type describing the full context shape
- **`renderFlash`** — Dispatches a single notification with an alert type (`"success"`, `"error"`, `"warning-filled"`, or `null`), a message, and optional `persistOnPageChange` flag
- **`renderMultiFlash`** — Dispatches multiple notifications at once via `MultiFlashOptions`
- **`hideFlash`** — Dismisses a notification by `id` (array) or clears all (single)

Both `renderFlash` and `renderMultiFlash` use `setTimeout` to defer dispatch to the next event loop tick, preventing conflicts with React Router v3's asynchronous navigation.

## Usage Example

```typescript
import React, { useContext } from "react";
import NotificationProvider, {
  NotificationContext,
} from "context/notification";

// Wrap your app
const App = () => (
  <NotificationProvider>
    <MyRoutes />
  </NotificationProvider>
);

// Consume in any child component
const SaveButton = () => {
  const { renderFlash, hideFlash } = useContext(NotificationContext);

  const handleSave = async () => {
    try {
      await saveData();
      renderFlash("success", "Changes saved successfully.");
    } catch {
      renderFlash("error", "Failed to save. Please try again.", {
        persistOnPageChange: true,
      });
    }
  };

  return <button onClick={handleSave}>Save</button>;
};
```
