React context provider managing global query editor state, including the last-edited query's metadata, osquery table selection, and query targets.

## Key Components

### Exports
- **`QueryContext`** — React context object; consume via `useContext(QueryContext)` in child components
- **`QueryProvider`** — Context provider component; wraps query-related pages/components
- **`IQueryContext`** — TypeScript type alias for the full context shape (`InitialStateType`)

### State Fields
| Field | Type | Description |
|---|---|---|
| `selectedOsqueryTable` | `IOsQueryTable` | Currently selected osquery table (defaults to `users`) |
| `lastEditedQuery*` | various | Tracks in-progress query: id, name, description, body, frequency, platforms, logging type, etc. |
| `editingExistingQuery` | `boolean` | Whether the user is editing a saved query vs. creating new |
| `selectedQueryTargets` | `ITarget[]` | Flat target list (legacy format, used by policies/live query) |
| `selectedQueryTargetsByType` | `ISelectedTargetsByType` | Targets grouped by type (modern format) |

### Actions (reducer)
- `SET_SELECTED_OSQUERY_TABLE` — Looks up table by name from `osqueryTables`
- `SET_LAST_EDITED_QUERY_INFO` — Partial update; only overrides fields explicitly provided
- `SET_SELECTED_QUERY_TARGETS` — Updates flat target array
- `SET_SELECTED_QUERY_TARGETS_BY_TYPE` — Updates typed target map

## Usage Example

```typescript
import React, { useContext } from "react";
import { QueryContext } from "context/query";

// Wrap your component tree
const App = () => (
  <QueryProvider>
    <QueryEditor />
  </QueryProvider>
);

// Consume context in a child component
const QueryEditor = () => {
  const {
    lastEditedQueryBody,
    setLastEditedQueryBody,
    setSelectedOsqueryTable,
  } = useContext(QueryContext);

  return (
    <textarea
      value={lastEditedQueryBody}
      onChange={(e) => setLastEditedQueryBody(e.target.value)}
    />
  );
};
```
