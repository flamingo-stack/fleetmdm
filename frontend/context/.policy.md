React context provider managing global state for policy creation and editing, including query metadata, team assignment, label filters, and osquery table selection.

## Key Components

- **`PolicyContext`** — React context exposing `IPolicyContext` state and setter functions to consumers
- **`PolicyProvider`** — Provider component wrapping children with policy state via `useReducer`
- **`IPolicyContext`** — Exported type representing the full context shape
- **`reducer`** — Handles three actions: `SET_LAST_EDITED_QUERY_INFO`, `SET_POLICY_TEAM_ID`, `SET_SELECTED_OSQUERY_TABLE`

### State Fields

| Field | Type | Description |
|---|---|---|
| `lastEditedQueryId` | `number \| null` | ID of the policy being edited |
| `lastEditedQueryName/Description/Body/Resolution` | `string` | Core policy text fields |
| `lastEditedQueryCritical` | `boolean` | Marks policy as critical |
| `lastEditedQueryPlatform` | `CommaSeparatedPlatformString \| null` | Target platforms |
| `lastEditedQueryLabels*` | `ILabelPolicy[]` | Include/exclude label filters (any/all) |
| `defaultPolicy` | `boolean` | Whether this is a default policy |
| `policyTeamId` | `number` | Team scope for the policy |
| `selectedOsqueryTable` | `IOsQueryTable` | Active osquery table (defaults to `users`) |

## Usage Example

```typescript
import { PolicyContext, PolicyProvider } from "context/policy";

// Wrap your component tree
const App = () => (
  <PolicyProvider>
    <PolicyEditor />
  </PolicyProvider>
);

// Consume context in a child component
import { useContext } from "react";

const PolicyEditor = () => {
  const {
    lastEditedQueryName,
    setLastEditedQueryName,
    selectedOsqueryTable,
    setSelectedOsqueryTable,
    policyTeamId,
  } = useContext(PolicyContext);

  return (
    <input
      value={lastEditedQueryName}
      onChange={(e) => setLastEditedQueryName(e.target.value)}
    />
  );
};
```

> **Note:** All setter callbacks are memoized with `useCallback` and the context value is memoized with `useMemo` to prevent unnecessary re-renders. The selected osquery table defaults to the `users` table on initialization.
