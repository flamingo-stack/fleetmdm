Sets the Webpack public path for asset loading by prepending the application's URL prefix to the `/assets/` directory path.

## Key Components

- **`__webpack_public_path__`** — Webpack's global runtime variable that controls the base URL used for dynamically loaded chunks and static assets.
- **`URL_PREFIX`** — Imported from `router/url_prefix`; provides the application's base URL prefix (e.g., for sub-path deployments).

## Usage Example

```javascript
// Imported early in the app entry point to ensure assets resolve correctly
import "public-path";

// Resulting public path (if URL_PREFIX = "/fleet"):
// "/fleet/assets/"
```

## Notes

- This file should be imported **before** any other module that triggers dynamic imports or asset loading.
- The `eslint-disable` comment suppresses `camelcase` and `no-undef` warnings, as `__webpack_public_path__` is a non-standard Webpack global.
- Enables correct asset resolution when the app is served from a sub-path rather than the domain root.
