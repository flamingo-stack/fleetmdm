Exports an ordered array of path-to-title mappings used to set browser document titles across static application routes.

## Key Components

- **Default export** — Array of `{ path, title }` objects pairing route paths (from `PATHS`) with formatted page titles using the `DOCUMENT_TITLE_SUFFIX` constant.

## Notes

- **Order is significant** — The array is consumed via `Array.find()`, so more specific subpaths must appear before their parent paths to ensure correct matches.
- **Dynamic titles excluded** — Host, software, query, and policy detail pages construct their own titles dynamically within their respective `*DetailsPage.tsx` components.

## Covered Routes

| Path | Title |
|---|---|
| `PATHS.DASHBOARD` | `Dashboard \| {suffix}` |
| `PATHS.MANAGE_HOSTS` | `Hosts \| {suffix}` |
| `PATHS.CONTROLS` | `Controls \| {suffix}` |
| `PATHS.SOFTWARE` | `Software \| {suffix}` |
| `PATHS.MANAGE_REPORTS` | `Reports \| {suffix}` |
| `PATHS.NEW_REPORT` | `New report \| {suffix}` |
| `PATHS.MANAGE_POLICIES` | `Policies \| {suffix}` |
| `PATHS.NEW_POLICY` | `New policy \| {suffix}` |
| `PATHS.ADMIN_SETTINGS` | `Settings \| {suffix}` |
| `PATHS.ACCOUNT` | `Settings \| My account \| {suffix}` |

## Usage Example

```typescript
import pageTitles from "utilities/page_titles";
import PATHS from "router/paths";

const match = pageTitles.find((entry) =>
  location.pathname.startsWith(entry.path)
);

if (match) {
  document.title = match.title;
}
```
