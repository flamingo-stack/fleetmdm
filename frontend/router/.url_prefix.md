Encapsulates access to the global `window.urlPrefix` value, providing a single module that all other modules should import instead of accessing the global directly.

## Key Components

- **`window.urlPrefix`** — Extended `Window` interface declaration adding the `urlPrefix` string property
- **Default export** — Resolves to `window.urlPrefix` if defined, or falls back to an empty string `""`

## Usage Example

```typescript
import urlPrefix from "./url_prefix";

const apiUrl = `${urlPrefix}/api/v1/fleet/hosts`;
fetch(apiUrl);
```

## Notes

- Follows the single-responsibility pattern: only this module reads `window.urlPrefix`; all other modules consume the exported value
- The `declare global` block extends the TypeScript `Window` interface to avoid type errors when accessing `window.urlPrefix`
- Safe fallback (`|| ""`) prevents runtime errors when `urlPrefix` is not set on the window object
