Serves as the root routing configuration for the Fleet MDM frontend application, defining the complete URL hierarchy, authentication guards, and query client setup.

## Key Components

- **`AppWrapper`** — Top-level React wrapper that composes `AppProvider`, `RoutingProvider`, `QueryClientProvider`, and `App` to bootstrap application-wide context
- **`CustomQueryClientProvider`** — Compatibility shim that extends `react-query`'s `QueryClientProvider` to accept explicit `children` prop for React 18
- **`queryClient`** — Singleton `QueryClient` instance shared across the application
- **`routes`** — `react-router` v3 route tree mapping every application URL to its page component

## Route Guard Components

| Guard | Purpose |
|---|---|
| `UnauthenticatedRoutes` | Public-only routes (login, registration, SSO) |
| `AuthenticatedRoutes` | Requires any authenticated user |
| `AuthGlobalAdminRoutes` | Requires global admin role |
| `AuthAnyAdminRoutes` | Requires any admin (team or global) |
| `AuthAnyMaintainerAnyAdminRoutes` | Requires maintainer or admin role |
| `PremiumRoutes` | Restricts to premium Fleet license |
| `ExcludeInSandboxRoutes` | Hides routes in sandbox environments |

## Usage Example

```typescript
import routes from "router/index";
import { render } from "react-dom";

render(routes, document.getElementById("root"));
```

## Route Structure

```text
/                        → AppWrapper
├── (unauthenticated)
│   ├── /login           → LoginPage
│   ├── /setup           → RegistrationPage
│   └── /mdm/sso         → MDMAppleSSOPage
└── (authenticated)
    ├── /dashboard       → DashboardPage
    ├── /settings        → Admin pages (role-gated)
    ├── /hosts           → ManageHostsPage / HostDetailsPage
    ├── /software        → SoftwarePage subtree
    ├── /controls        → ManageControlsPage subtree
    ├── /queries         → ManageQueriesPage / LiveQueryPage
    └── /policies        → ManagePoliciesPage / PolicyDetailsPage
```
