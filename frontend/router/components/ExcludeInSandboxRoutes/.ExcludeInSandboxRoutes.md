A React route guard component that blocks access to certain routes when the application is running in sandbox mode, triggering a 403 error page instead.

## Key Components

- **`ExcludeInSandboxRoutes`** — Default export. A wrapper component that checks `isSandboxMode` from `AppContext` and either renders its children or triggers a 403 error via `react-error-boundary`.
- **`IExcludeInSandboxRoutesProps`** — Interface requiring a single `children: JSX.Element` prop.

## Usage Example

```typescript
import ExcludeInSandboxRoutes from "components/ExcludeInSandboxRoutes";

// Wrap any route that should be inaccessible in sandbox mode
<ExcludeInSandboxRoutes>
  <AdminSettingsPage />
</ExcludeInSandboxRoutes>
```

When `isSandboxMode` is `true`, the component calls `handlePageError({ status: 403 })` and returns `null`, preventing the child route from rendering. In non-sandbox environments, children are rendered normally via a React fragment.

## Notes

- Relies on `AppContext` for the `isSandboxMode` flag — ensure the app is wrapped with the appropriate context provider.
- Error handling is delegated to the nearest `ErrorBoundary` from `react-error-boundary`, so a boundary must exist in the component tree.
