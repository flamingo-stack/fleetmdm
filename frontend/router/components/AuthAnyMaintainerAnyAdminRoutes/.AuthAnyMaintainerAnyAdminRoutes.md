Route guard component that restricts access to users with any maintainer or admin role (global or team-level), triggering a 403 error for unauthorized users.

## Key Components

- **`AuthAnyMaintainerAnyAdminRoutes`** — Default export; a React wrapper component that validates role-based access before rendering child routes.
- **`IAuthAnyMaintainerAnyAdminRoutesProps`** — Interface defining the `children` prop (a single `JSX.Element`).
- **Role checks** — Reads `isGlobalAdmin`, `isGlobalMaintainer`, `isAnyTeamAdmin`, and `isAnyTeamMaintainer` from `AppContext`.
- **`useErrorHandler`** — Invokes the `react-error-boundary` error handler with a `403` status when none of the required roles are present.

## Usage Example

```typescript
import AuthAnyMaintainerAnyAdminRoutes from "components/AuthAnyMaintainerAnyAdminRoutes";

const AppRouter = () => (
  <Route
    path="/manage-hosts"
    element={
      <AuthAnyMaintainerAnyAdminRoutes>
        <ManageHostsPage />
      </AuthAnyMaintainerAnyAdminRoutes>
    }
  />
);
```

## Access Logic

| Condition | Result |
|---|---|
| `currentUser` is `null` | Renders nothing (loading state) |
| None of the four role flags are `true` | Calls `handlePageError({ status: 403 })`, renders nothing |
| Any role flag is `true` | Renders `children` |
