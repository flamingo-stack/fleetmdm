Route guard component that restricts access to children based on whether the current user holds any maintainer, admin, or technician role — globally or on any team. Unauthorized users receive a 403 error via the error boundary.

## Key Components

- **`AuthAnyMaintainerAdminTechnicianRoutes`** — Default export; a React component that wraps protected routes and enforces role-based access control.
- **`IAuthAnyMaintainerAdminTechnicianRoutesProps`** — Props interface requiring a single `children: JSX.Element`.
- **`AppContext`** — Provides current user and role flags (`isGlobalAdmin`, `isGlobalMaintainer`, `isGlobalTechnician`, `isAnyTeamAdmin`, `isAnyTeamMaintainer`, `isAnyTeamTechnician`).
- **`useErrorHandler`** — Triggers a 403 page error when the user lacks all required roles.

## Access Logic

| Condition | Result |
|---|---|
| `currentUser` is `null` | Returns `null` (unauthenticated) |
| User holds at least one qualifying role | Renders `children` |
| User holds no qualifying role | Fires `handlePageError({ status: 403 })` |

## Usage Example

```typescript
import AuthAnyMaintainerAdminTechnicianRoutes from "components/AuthAnyMaintainerAdminTechnicianRoutes";

<AuthAnyMaintainerAdminTechnicianRoutes>
  <ProtectedPage />
</AuthAnyMaintainerAdminTechnicianRoutes>
```

Wrap any route element that should be accessible only to admins, maintainers, or technicians (at the global or team level). Place this guard in your route definitions alongside other `Auth*` guards for consistent access control.
