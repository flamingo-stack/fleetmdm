A React component that guards unauthenticated routes by redirecting sandbox environment users to the FleetDM login page.

## Key Components

- **`UnauthenticatedRoutes`** — A wrapper component that checks the current hostname and redirects users on `.sandbox.fleetdm.com` to `https://www.fleetdm.com/try-fleet/login`. For all other environments, it renders its `children` unchanged.
- **`IAppProps`** — Interface requiring a single `children` prop of type `JSX.Element`.

## Usage Example

```typescript
import { UnauthenticatedRoutes } from "./UnauthenticatedRoutes";

const App = () => (
  <UnauthenticatedRoutes>
    <LoginPage />
  </UnauthenticatedRoutes>
);
```

## Behavior

| Environment | Outcome |
|---|---|
| `*.sandbox.fleetdm.com` | Redirects to FleetDM login page |
| All other hostnames | Renders `children` as-is |

## Notes

- The redirect is triggered via `window.location.href`, causing a full browser navigation.
- No loading state or conditional rendering is returned during the redirect — the component still returns the `children` wrapper, though the browser will navigate away immediately.
- This is intended for use at the router level to prevent sandbox users from accessing self-hosted login flows.
