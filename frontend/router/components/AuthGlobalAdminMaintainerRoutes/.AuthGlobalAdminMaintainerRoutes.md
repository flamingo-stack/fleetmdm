Route guard component that restricts access to routes requiring either global admin or global maintainer privileges, triggering a 403 error for unauthorized users.

## Key Components

- **`AuthGlobalAdminMaintainerRoutes`** — Default export; a React component that wraps protected route children and enforces role-based access control
- **`IAuthGlobalAdminMaintainerRoutesProps`** — Interface defining the `children` prop (`JSX.Element`)
- **`AppContext`** — Consumed via `useContext` to access `currentUser`, `isGlobalAdmin`, and `isGlobalMaintainer`
- **`useErrorHandler`** — From `react-error-boundary`; triggers a 403 page error for users lacking the required role

## Behavior

| Condition | Result |
|---|---|
| No `currentUser` | Renders `null` (unauthenticated) |
| Not global admin **and** not global maintainer | Calls `handlePageError({ status: 403 })`, renders `null` |
| Is global admin **or** global maintainer | Renders `children` |

## Usage Example

```typescript
import AuthGlobalAdminMaintainerRoutes from "components/AuthGlobalAdminMaintainerRoutes";

const AppRoutes = () => (
  <Route
    path="/policies"
    element={
      <AuthGlobalAdminMaintainerRoutes>
        <PoliciesPage />
      </AuthGlobalAdminMaintainerRoutes>
    }
  />
);
```
