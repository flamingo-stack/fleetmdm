Guards route access by verifying the current user exists and the application is on a premium tier, triggering a 403 error boundary if either condition fails.

## Key Components

- **`PremiumRoutes`** — Default-exported route guard component that wraps protected children
- **`IAuthenticatedAdminRoutesProps`** — Interface defining the `children: JSX.Element` prop
- **`AppContext`** — Consumed for `currentUser` and `isPremiumTier` state
- **`useErrorHandler`** — From `react-error-boundary`; used to dispatch a 403 on premium tier violations

## Usage Example

```typescript
import PremiumRoutes from "components/PremiumRoutes";

const App = () => (
  <PremiumRoutes>
    <PremiumFeaturePage />
  </PremiumRoutes>
);
```

**Guard logic:**

| Condition | Result |
|---|---|
| `currentUser` is falsy | Renders `null` silently |
| `isPremiumTier` is false | Triggers 403 error boundary, renders `null` |
| Both conditions pass | Renders `children` |

## Notes

- Relies on `AppContext` being available in the component tree; ensure `AppContext.Provider` wraps this component
- The 403 error is handled upstream by `react-error-boundary` — pair with an `<ErrorBoundary>` ancestor that handles `status: 403` responses
- Does not perform redirects; error display is delegated entirely to the error boundary
