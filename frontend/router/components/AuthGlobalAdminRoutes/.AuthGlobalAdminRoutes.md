Route guard component that restricts access to global admin users, triggering a 403 error for unauthorized users.

## Key Components

- **`AuthenticatedGlobalAdminRoutes`** — Default export; a React wrapper component that checks global admin privileges before rendering child routes
- **`IAuthenticatedAdminRoutesProps`** — Interface defining the `children` prop (`JSX.Element`)
- **`AppContext`** — Consumed via `useContext` to read `currentUser` and `isGlobalAdmin` state
- **`useErrorHandler`** — From `react-error-boundary`; used to surface a `403` error when a non-admin user attempts access

## Behavior

| Condition | Result |
|---|---|
| `currentUser` is falsy | Returns `null` (silent no-op) |
| `isGlobalAdmin` is `false` | Triggers `handlePageError({ status: 403 })` and returns `null` |
| User is a global admin | Renders `children` |

## Usage Example

```typescript
import AuthenticatedGlobalAdminRoutes from "components/AuthGlobalAdminRoutes";

const AdminSettingsRoute = () => (
  <AuthenticatedGlobalAdminRoutes>
    <AdminSettingsPage />
  </AuthenticatedGlobalAdminRoutes>
);
```

Wrap any route element that should be restricted to global admins. Non-admin authenticated users will hit the error boundary with a 403 status, while unauthenticated users are silently blocked until auth resolves.
