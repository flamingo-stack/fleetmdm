Route guard component that restricts access to users who are either global admins or team admins, triggering a 403 error for unauthorized users.

## Key Components

- **`AuthAnyAdminRoutes`** — Default export; a React wrapper component that validates admin privileges before rendering child routes
- **`IAuthAnyAdminRoutesProps`** — Interface defining the `children` prop of type `JSX.Element`
- **`AppContext`** — Consumed via `useContext` to access `currentUser`, `isGlobalAdmin`, and `isAnyTeamAdmin`
- **`useErrorHandler`** — From `react-error-boundary`; triggers a 403 page error for unauthorized access attempts

## Access Logic

```text
No currentUser  → render null (unauthenticated)
Not global admin AND not any team admin → 403 error
Otherwise → render children
```

## Usage Example

```typescript
import AuthAnyAdminRoutes from "components/AuthAnyAdminRoutes";

// Wrap protected routes that require any admin role
<AuthAnyAdminRoutes>
  <AdminSettingsPage />
</AuthAnyAdminRoutes>
```

Any authenticated user who lacks both global admin and team admin roles will have the error boundary trigger a 403 response, preventing access to the wrapped content.
