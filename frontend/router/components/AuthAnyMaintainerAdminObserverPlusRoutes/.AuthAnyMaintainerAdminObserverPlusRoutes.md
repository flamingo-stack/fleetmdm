Route guard component that restricts access to users with maintainer, admin, or observer-plus roles, triggering a 403 error for unauthorized users.

## Key Components

- **`AuthAnyMaintainerAdminObserverPlusRoutes`** — Default export; a React component that wraps protected routes and enforces role-based access control
- **`IAuthAnyMaintainerAdminObserverPlusRoutesProps`** — Interface requiring a `children: JSX.Element` prop
- **`isAnyMaintainerAdminObserverPlus`** — Boolean flag consumed from `AppContext` that determines access eligibility
- **`handlePageError`** — Invoked with `{ status: 403 }` via `react-error-boundary` when the user lacks the required role

## Usage Example

```typescript
import AuthAnyMaintainerAdminObserverPlusRoutes from "components/auth/AuthAnyMaintainerAdminObserverPlusRoutes";

<Route
  path="/some/protected/path"
  element={
    <AuthAnyMaintainerAdminObserverPlusRoutes>
      <ProtectedPage />
    </AuthAnyMaintainerAdminObserverPlusRoutes>
  }
/>
```

## Behavior

| Condition | Result |
|---|---|
| `currentUser` is null | Renders `null` (unauthenticated) |
| `isAnyMaintainerAdminObserverPlus` is false | Triggers 403 error boundary |
| User has required role | Renders `children` |
