A React custom hook that manages the open/closed state of a side panel, providing toggle and direct set functionality.

## Key Components

**`IUseToggleSidePanelHook`** — Interface describing the hook's return value:
- `isSidePanelOpen: boolean` — current visibility state
- `toggleSidePanel: () => void` — flips the current state
- `setSidePanelOpen: (isOpen: boolean) => void` — sets state explicitly

**`useToggleSidePanel(initialIsOpened)`** — The hook itself, accepts an initial boolean to seed the open/closed state.

## Usage Example

```typescript
import useToggleSidePanel from "./useToggleSidePanel";

const MyComponent = () => {
  const { isSidePanelOpen, toggleSidePanel, setSidePanelOpen } =
    useToggleSidePanel(false);

  return (
    <>
      <button onClick={toggleSidePanel}>
        {isSidePanelOpen ? "Close" : "Open"} Panel
      </button>
      <button onClick={() => setSidePanelOpen(false)}>
        Force Close
      </button>
      {isSidePanelOpen && <SidePanel />}
    </>
  );
};
```

## Notes

- `toggleSidePanel` is memoized with `useCallback`, depending on `isSidePanelOpen` — it will always reflect the latest state without stale closure issues.
- `setSidePanelOpen` is also memoized and stable across renders, making it safe to pass as a prop without triggering unnecessary re-renders.
- Initialize with `true` to render the panel open by default.
