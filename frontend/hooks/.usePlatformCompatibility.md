React hook that manages SQL query platform compatibility checking, providing debounced analysis, state management, and a ready-to-render compatibility indicator component.

## Key Components

- **`IPlatformCompatibility`** — Interface defining the hook's return shape with `getCompatiblePlatforms`, `setCompatiblePlatforms`, and `render` methods
- **`usePlatformCompatibility`** — Main hook encapsulating compatibility state, debounced SQL analysis, and UI rendering
- **`debounceCompatiblePlatforms`** — 300ms debounced callback (leading + trailing) that triggers `checkPlatformCompatibility` on SQL input changes
- **`getCompatiblePlatforms`** — Memoized selector filtering `QUERYABLE_PLATFORMS` against current compatible platforms state
- **`render`** — Memoized render function returning a `<PlatformCompatibility>` component with current state

## Usage Example

```typescript
import usePlatformCompatibility from "hooks/usePlatformCompatibility";

const QueryEditor = () => {
  const {
    getCompatiblePlatforms,
    setCompatiblePlatforms,
    render: renderCompatibility,
  } = usePlatformCompatibility();

  const handleSqlChange = (sql: string) => {
    setCompatiblePlatforms(sql); // debounced — safe to call on every keystroke
  };

  const platforms = getCompatiblePlatforms(); // ["darwin", "windows", ...]

  return (
    <div>
      <textarea onChange={(e) => handleSqlChange(e.target.value)} />
      {renderCompatibility()} {/* Renders <PlatformCompatibility /> */}
    </div>
  );
};
```

## Notes

- `setCompatiblePlatforms` is debounced at 300ms with both leading and trailing edges, making it safe to bind directly to rapid input events without excessive computation.
- Returns `[]` (empty array) rather than `null` when no platforms match, keeping consumers from needing null guards on `getCompatiblePlatforms()`.
