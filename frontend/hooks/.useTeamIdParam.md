Manages team ID state derived from URL query parameters (`fleet_id`) for Fleet MDM pages, synchronizing React Context team state with routing and handling team selection validation, defaults, and URL rebuilding on team changes.

## Key Components

### Exported Hook

- **`useTeamIdParam`** — Primary hook that reads `fleet_id` from the URL, validates it against available teams, redirects to defaults when invalid, and returns the current team context along with a `handleTeamChange` callback.

### Exported Utilities

- **`preferredOrLowestIdFleet`** — Selects a "Workstations" fleet by name (with or without emoji prefix) or falls back to the fleet with the lowest ID.
- **`IConfigOverrideParamsOnTeamChange`** — Type defining per-param override functions that strip or replace query params when the team changes.

### Internal Helpers

| Function | Purpose |
|---|---|
| `rebuildQueryStringWithTeamId` | Rewrites the URL query string on team change: resets `page=0`, migrates legacy `team_id=` to `fleet_id=`, applies `overrideParamsOnTeamChange` rules |
| `getDefaultTeam` | Picks the default team for a user based on role, Primo mode, and page inclusion flags |
| `getTeamIdForApi` | Maps React Context team IDs (`APP_CONTEXT_*`) to API-facing IDs (`API_*`) |
| `isValidTeamId` | Validates a parsed team ID against available teams and page flags |
| `shouldRedirectToDefaultTeam` | Returns `true` when the URL's `fleet_id` is absent, malformed, or inaccessible |
| `filterUserTeamsByRole` | Filters a non-global user's teams by `permittedAccessByTeamRole` |

## Usage Example

```typescript
const { currentTeamId, currentTeamName, handleTeamChange } = useTeamIdParam({
  location,
  router,
  includeAllTeams: true,
  includeNoTeam: false,
  permittedAccessByTeamRole: { admin: true, maintainer: true },
  overrideParamsOnTeamChange: {
    // Strip "vulnerability_id" param whenever team changes
    vulnerability_id: (newTeamId) => newTeamId !== undefined,
  },
});
```

## Notes

- **Primo mode** (`config.partnerships.enable_primo`) inverts team-selection priority: "No team" takes precedence over "All teams".
- The hook automatically redirects users to their default team when they land on a page with an invalid or inaccessible `fleet_id`.
- Legacy `team_id=` query params are silently rewritten to `fleet_id=` for backward compatibility.
