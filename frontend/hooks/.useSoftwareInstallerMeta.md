Extracts and normalizes software installer metadata from `ISoftwareTitleDetails` for use across the Fleet MDM software management UI.

## Key Components

### `SoftwareInstallerMeta`
Interface describing the normalized installer metadata returned by the hook, including:
- `installerType` — `"package"` or `"app-store"`
- `isAndroidPlayStoreApp` / `isAndroidPlayStoreWebApp` — Android-specific flags
- `isFleetMaintainedApp` / `isLatestFmaVersion` — Fleet-maintained app (FMA) status
- `isCustomPackage` — `true` for non-FMA packages
- `isIosOrIpadosApp` — iOS/iPadOS VPP app flag
- `sha256`, `androidPlayStoreId`, `patchPolicy` — installer-specific metadata
- `automaticInstallPolicies` — policies for automatic installation
- `gitOpsModeEnabled`, `repoURL` — GitOps context
- `canManageSoftware` — derived from user role (admin/maintainer)

### `UseSoftwareInstallerResult`
Return type combining `cardInfo` (`InstallerCardInfo`) and the full `meta` object.

### `useSoftwareInstaller(softwareTitle)`
The primary hook. Returns `undefined` if the title has no associated installer. Internally uses `useMemo` to avoid recomputation across renders.

## Usage Example

```typescript
import { useSoftwareInstaller } from "hooks/useSoftwareInstallerMeta";

const MyComponent = ({ softwareTitle }: { softwareTitle: ISoftwareTitleDetails }) => {
  const result = useSoftwareInstaller(softwareTitle);

  if (!result) return null;

  const { cardInfo, meta } = result;

  return (
    <div>
      {meta.isFleetMaintainedApp && !meta.isLatestFmaVersion && (
        <Banner>A newer Fleet-maintained version is available.</Banner>
      )}
      {meta.isAndroidPlayStoreApp && <AndroidBadge storeId={meta.androidPlayStoreId} />}
      {meta.canManageSoftware && <ManageButton disabled={meta.gitOpsModeEnabled} />}
    </div>
  );
};
```

## Notes

- FMA version staleness is determined by comparing the installed version against all known `fleet_maintained_versions` using `compareVersions`, requiring `>= 0` for every entry.
- `canManageSoftware` is `true` for global/team admins and maintainers only.
