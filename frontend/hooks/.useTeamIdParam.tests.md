Test suite for the `preferredOrLowestIdFleet` utility from `useTeamIdParam`, verifying fleet selection logic including preferred name matching and lowest-ID fallback behavior.

## Key Components

- **`preferredOrLowestIdFleet`** (imported from `./useTeamIdParam`) — The function under test; selects a fleet by preferred name or falls back to the lowest ID.

## Test Cases

| Scenario | Expected Behavior |
|---|---|
| `"Workstations"` fleet present | Returns the matching fleet |
| `"💻 Workstations"` (emoji variant) present | Returns the emoji-named fleet |
| Both plain and emoji variants exist | Returns first match (plain wins) |
| Name matches case-insensitively (`"WORKSTATIONS"`) | Returns the case-variant fleet |
| No `"Workstations"` fleet exists | Returns fleet with the lowest `id` |
| Empty array input | Returns `undefined` |

## Usage Example

```typescript
import { preferredOrLowestIdFleet } from "./useTeamIdParam";

const fleets = [
  { id: 10, name: "Servers" },
  { id: 2, name: "Workstations" },
  { id: 7, name: "Mobile" },
];

// Returns { id: 2, name: "Workstations" }
const defaultFleet = preferredOrLowestIdFleet(fleets);

// Falls back to lowest ID when no "Workstations" fleet exists
const fallback = preferredOrLowestIdFleet([
  { id: 10, name: "Servers" },
  { id: 3, name: "Mobile" },
]); // Returns { id: 3, name: "Mobile" }
```
