A React Query hook for fetching and transforming Fleet MDM target data, including hosts, labels, and teams with online percentage calculations.

## Key Components

### Interfaces

- **`ITargetsLabels`** — Categorized label groups: `allHostsLabels`, `platformLabels`, `otherLabels`, `teams`, and `labelCount`
- **`ITargetsQueryResponse`** — Extends `ITargetsLabels` with `targetsTotalCount`, `targetsOnlinePercent`, and `relatedHosts`
- **`ITargetsQueryKey`** — Query key shape containing `scope`, `query`, `queryId`, `selected`, and `includeLabels`

### Functions

- **`getTargets(queryKey)`** — Internal async function that calls `targetsAPI.loadAll`, optionally categorizes labels into "All Hosts", platform (`macOS`, `MS Windows`, `All Linux`), and custom (`regular` type) groups, and computes the online percentage
- **`useQueryTargets(targetsQueryKey, options)`** — Exported hook wrapping `useQuery` with `refetchOnWindowFocus: false` and `refetchOnMount: "always"`

## Usage Example

```typescript
import { useQueryTargets, ITargetsQueryKey } from "./useQueryTargets";

const queryKey: ITargetsQueryKey[] = [
  {
    scope: "targets",
    query: "macbook",
    queryId: null,
    selected: { hosts: [], labels: [], teams: [] },
    includeLabels: true,
  },
];

const { data, isLoading } = useQueryTargets(queryKey, {
  onSuccess: (data) => {
    console.log("Total targets:", data.targetsTotalCount);
    console.log("Online %:", data.targetsOnlinePercent);
    console.log("Platform labels:", data.platformLabels);
  },
  staleTime: 3000,
});
```
