Provides a React hook for determining whether GitOps mode is effectively enabled, optionally scoped to a specific entity that may have per-entity exceptions configured.

## Key Components

- **`useGitOpsMode(entity?)`** — Default export hook that reads GitOps configuration from `AppContext` and resolves the effective enabled state, factoring in entity-level exceptions
- **`UseGitOpsModeResult`** — Return type containing:
  - `gitOpsModeEnabled: boolean` — `true` only when GitOps mode is globally enabled *and* the given entity is not excepted
  - `repoURL?: string` — The configured repository URL from GitOps settings
- **`IGitOpsExceptions`** — Interface (from `interfaces/config`) whose keys are valid `entity` arguments

## Usage Example

```typescript
// Global GitOps status (e.g. nav indicator) — no entity argument
const { gitOpsModeEnabled, repoURL } = useGitOpsMode();

// Scoped to a specific entity (e.g. "policies"), respects exceptions
const { gitOpsModeEnabled } = useGitOpsMode("policies");

if (gitOpsModeEnabled) {
  // Disable editing UI, show read-only GitOps banner
}
```

## Behavior Notes

- Calling without an argument returns the **global** GitOps mode status with no exception logic applied
- Calling with an `entity` key returns `gitOpsModeEnabled: false` if that entity appears in `config.gitops.exceptions`, even when global GitOps mode is on
- Safe to call when `config` is `undefined` — all optional chaining returns `false`/`undefined` gracefully
