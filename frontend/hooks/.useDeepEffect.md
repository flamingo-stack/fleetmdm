A custom React hook that extends `useEffect` with deep equality checking for dependencies, using Lodash's `isEqual` to detect changes within nested objects and arrays.

## Key Components

- **`useDeepEffect(fn, deps)`** — Drop-in replacement for `useEffect` that performs deep comparison of dependency values instead of shallow reference checks
- **`isFirst` ref** — Ensures the effect runs on the initial render regardless of dependency state
- **`prevDeps` ref** — Stores the previous dependency array for comparison on subsequent renders

## Usage Example

```typescript
import { useDeepEffect } from "./useDeepEffect";

const MyComponent = ({ filters }: { filters: { status: string; tags: string[] } }) => {
  useDeepEffect(() => {
    // Runs only when filters content changes, not just its reference
    fetchData(filters);
  }, [filters]);

  return <div>...</div>;
};
```

## When to Use

Use `useDeepEffect` over standard `useEffect` when dependencies are objects or arrays that may be recreated on each render with the same content but different references — a common cause of infinite re-render loops.

```typescript
// Standard useEffect — triggers on every render if `config` is recreated
useEffect(() => { ... }, [config]);

// useDeepEffect — only triggers when config values actually change
useDeepEffect(() => { ... }, [config]);
```

## Notes

- Adds a small overhead per render due to deep comparison; prefer standard `useEffect` for primitive dependencies
