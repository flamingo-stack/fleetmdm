A React hook that detects whether a DOM element's text content is horizontally truncated (i.e., overflowing with CSS `text-overflow: ellipsis`), updating reactively on resize.

## Key Components

- **`useCheckTruncatedElement<T extends HTMLElement>(ref)`** — Accepts a React ref to any HTML element and returns a boolean indicating truncation state.
- **`isTruncated`** — State value (`boolean`) that is `true` when `scrollWidth > clientWidth`.
- **`updateIsTruncated`** — Internal helper that compares scroll and client widths to determine overflow.
- **`ResizeObserver`** — Used inside `useLayoutEffect` to reactively re-evaluate truncation whenever the element is resized.

## Usage Example

```typescript
import { useRef } from "react";
import { useCheckTruncatedElement } from "./useCheckTruncatedElement";

const TruncatedLabel = ({ text }: { text: string }) => {
  const ref = useRef<HTMLSpanElement>(null);
  const isTruncated = useCheckTruncatedElement(ref);

  return (
    <span
      ref={ref}
      style={{ overflow: "hidden", textOverflow: "ellipsis", whiteSpace: "nowrap" }}
      title={isTruncated ? text : undefined}
    >
      {text}
    </span>
  );
};
```

> **Note:** The element must have `overflow: hidden` and a constrained width for truncation to be detected correctly. The hook cleans up the `ResizeObserver` on unmount to prevent memory leaks.
