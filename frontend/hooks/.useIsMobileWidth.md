A React hook that detects whether the current viewport width is below the mobile breakpoint (768px) using the `window.matchMedia` API.

## Key Components

- **`MOBILE_BREAKPOINT`** — Constant set to `768`; the hook triggers when viewport is `≤ 767px`.
- **`useIsMobileWidth()`** — Custom hook returning a boolean that updates reactively on window resize. Includes a fallback to the deprecated `addListener`/`removeListener` API for older Safari compatibility.

## Usage Example

```typescript
import useIsMobileWidth from "./useIsMobileWidth";

const NavBar = () => {
  const isMobile = useIsMobileWidth();

  return (
    <nav>
      {isMobile ? <HamburgerMenu /> : <DesktopNav />}
    </nav>
  );
};
```

## Notes

- Initializes state synchronously from `query.matches` on mount, preventing a flash of incorrect layout.
- Properly cleans up the media query listener on unmount to avoid memory leaks.
- Safe for SSR frameworks — `window` is only accessed inside `useEffect`, which runs client-side only.
