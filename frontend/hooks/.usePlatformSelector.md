A custom React hook that manages platform selection state (macOS, Windows, Linux, ChromeOS) for policies and queries, providing controlled checkbox state and a rendered `PlatformSelector` component.

## Key Components

### `IPlatformSelector` Interface
| Member | Type | Description |
|--------|------|-------------|
| `setSelectedPlatforms` | `(platforms: string[]) => void` | Sets checked state for a given list of platform keys |
| `getSelectedPlatforms` | `() => QueryablePlatform[]` | Returns array of currently selected platform keys |
| `isAnyPlatformSelected` | `boolean` | `true` if at least one platform checkbox is checked |
| `render` | `() => JSX.Element` | Renders the `PlatformSelector` component with current state |
| `disabled` | `boolean?` | Optional — disables all checkboxes |
| `installSoftware` | `IPolicySoftwareToInstall?` | Optional — software install context passed to selector |
| `currentTeamId` | `number?` | Optional — scopes selector to a specific team |

### `usePlatformSelector` Hook
Accepts a comma-separated platform string (e.g., `"darwin,windows"`), a CSS base class, a disabled flag, an optional software install object, and an optional team ID. Initializes checkbox state from `platformContext` on mount and whenever it changes — defaulting to **all platforms selected** when the context is an empty string.

## Usage Example

```typescript
const platformSelector = usePlatformSelector(
  policy.platforms,   // e.g. "darwin,linux"
  "policy-form",
  false,
  policy.installSoftware,
  currentTeamId
);

// Read selected platforms
const platforms = platformSelector.getSelectedPlatforms();
// => ["darwin", "linux"]

// Programmatically update selection
platformSelector.setSelectedPlatforms(["windows"]);

// Check if anything is selected before saving
if (!platformSelector.isAnyPlatformSelected) {
  showError("Select at least one platform.");
}

// Render the checkbox UI
return <div>{platformSelector.render()}</div>;
```
