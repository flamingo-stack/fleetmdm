Manages checkbox state for a list of policies, initializing each item's checked status based on whether it appears in a set of automated policy IDs.

## Key Components

- **`ICheckedPolicy`** — Interface extending a policy with an `isChecked` boolean flag
- **`useCheckboxListStateManagement`** — Custom hook accepting all available policies and a list of currently automated policy IDs, returning stateful checkbox items and a toggle updater

## Usage Example

```typescript
const { policyItems, updatePolicyItems } = useCheckboxListStateManagement(
  allPolicies,
  automatedPolicies
);

// Render checkboxes
policyItems.map(({ id, name, isChecked }) => (
  <Checkbox
    key={id}
    label={name}
    checked={isChecked}
    onChange={() => updatePolicyItems(id)}
  />
));
```

## Parameters

| Parameter | Type | Description |
|---|---|---|
| `allPolicies` | `IPolicy[]` | Full list of available policies |
| `automatedPolicies` | `number[] \| undefined` | IDs of policies already marked as automated |

## Returns

| Value | Type | Description |
|---|---|---|
| `policyItems` | `ICheckedPolicy[]` | Policies with their current checked state |
| `updatePolicyItems` | `(policyId: number) => void` | Toggles the `isChecked` flag for a given policy ID |
