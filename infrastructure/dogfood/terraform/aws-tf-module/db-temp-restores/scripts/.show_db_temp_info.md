Reads Terraform outputs from a `db-temp` module and prints a human-friendly summary of Aurora/MySQL cluster details and developer credentials.

## Key Components

| Component | Description |
|---|---|
| `run_terraform_output(directory)` | Executes `terraform output -json` in the given directory and returns the parsed dict; exits with a clear error on failure |
| `summarize_databases(databases)` | Formats per-customer cluster endpoints, engine version, database name, and instance roles into a readable string |
| `summarize_developer_passwords(dev_passwords)` | Formats per-customer developer usernames and plaintext passwords into a readable string |
| `main()` | CLI entry point; resolves Terraform directories, fetches outputs, and falls back to the `mysql_dev_access` module for credentials if not exposed at the root |

## Usage Example

```bash
# Run against the default Terraform root (two levels up from this script)
python3 show_db_temp_info.py

# Specify an explicit Terraform directory and module override
python3 show_db_temp_info.py \
  --tf-dir /infra/db-temp \
  --module-dir /infra/db-temp/mysql_dev_access
```

```text
=== Databases ===
Customer: acme
  Cluster endpoint: acme.cluster-abc123.us-east-1.rds.amazonaws.com
  Reader endpoint:  acme.cluster-ro-abc123.us-east-1.rds.amazonaws.com
  Engine version:   8.0.mysql_aurora.3.04.0
  Database name:    fleet
  Instances:
    - acme-instance-1 (writer) @ acme-1.abc123.us-east-1.rds.amazonaws.com [db.r6g.large]

=== Developer Credentials ===
Customer: acme
  - dev_user: s3cr3tP@ssw0rd
```

## Notes

- Requires `terraform` on `$PATH` and an initialized state in the target directory.
- Credentials fall back to `mysql_dev_access/` module outputs when not exported at the root level.
