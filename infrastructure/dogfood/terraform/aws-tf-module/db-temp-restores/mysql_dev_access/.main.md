Terraform module that provisions MySQL developer accounts on an RDS instance, generating random passwords and granting privileges across fixed VPN subnets via idempotent SQL execution.

## Key Components

| Component | Type | Description |
|---|---|---|
| `endpoint` | Variable | DB host:port (e.g. `cluster-xyz.us-east-1.rds.amazonaws.com:3306`) |
| `admin_username` / `admin_password` | Variables | Admin credentials used to execute SQL |
| `developers` | Variable | List of MySQL usernames to create and grant |
| `database_name` | Variable | Target database (defaults to `fleet`) |
| `vpn_host_patterns` | Local | Three VPN subnets (`10.255.1-3.%`) as MySQL host wildcards |
| `random_password.dev_pw` | Resource | 24-char random password per developer |
| `dev_pw_escaped` | Local | SQL-safe password strings (escapes `\` and `'`) |
| `sql` | Local | Rendered idempotent SQL — `CREATE USER IF NOT EXISTS`, `ALTER USER`, `GRANT rds_superuser_role`, `GRANT ALL PRIVILEGES`, `FLUSH PRIVILEGES` |
| `null_resource.apply_sql` | Resource | Runs SQL via `mysql` CLI; triggers on endpoint, developer list, password, or SQL changes |
| `developer_passwords` | Output | Sensitive map of `developer → password` |

## Usage Example

```bash
# terraform.tfvars
endpoint       = "cluster-xyz.us-east-1.rds.amazonaws.com:3306"
admin_username = "admin"
admin_password = "s3cr3t"
database_name  = "fleet"
developers     = ["alice", "bob", "carol"]
```

```bash
terraform init
terraform apply
```

Each developer receives three MySQL accounts (one per VPN subnet), e.g. `alice@10.255.1.%`, `alice@10.255.2.%`, `alice@10.255.3.%`, all with the same generated password and full privileges on the target database.

> **Prerequisite:** The `mysql` client binary must be available in `$PATH` on the Terraform runner.
