Terraform configuration for building osquery Docker images from source and pushing them to an AWS ECR repository.

## Key Components

### Variables

| Variable | Type | Description |
|---|---|---|
| `osquery_version` | `string` | osquery version to build and push |
| `osquery_tags` | `list(string)` | Image tags to build and push |
| `ecr_repo` | `string` | Target ECR repository URL |

### Resources

- **`local_file.osquery_patch`** — Renders a patch file from `osquery-docker.patch.tmpl` using the specified osquery version
- **`null_resource.build_osquery`** — Clones (or updates) the osquery GitHub repo, applies the patch, and runs `./build.sh` via `local-exec`; re-triggers on version or tag changes
- **`docker_tag.osquery`** — Tags each built image for the target ECR repository (one per entry in `osquery_tags`)
- **`docker_registry_image.osquery`** — Pushes each tagged image to ECR; `keep_remotely = true` prevents remote deletion on destroy

### Outputs

- **`ecr_images`** — Map of tag → full ECR image URI (e.g., `{ "5.12.0" => "123456.dkr.ecr.us-east-1.amazonaws.com/osquery:5.12.0" }`)

## Usage Example

```bash
terraform init

terraform apply \
  -var="osquery_version=5.12.0" \
  -var='osquery_tags=["5.12.0","latest"]' \
  -var="ecr_repo=123456789.dkr.ecr.us-east-1.amazonaws.com/osquery"
```

## Notes

- Requires Docker and Git installed locally; the build runs on the machine executing Terraform
- The patch template (`osquery-docker.patch.tmpl`) must exist alongside this file
- AWS credentials and ECR login must be configured before `apply`
