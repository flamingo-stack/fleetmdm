Defines the input variable for authenticating with the SigNoz OpenTelemetry (OTEL) collector used in the FleetMDM infrastructure.

## Key Components

| Variable | Type | Sensitive | Description |
|---|---|---|---|
| `otel_bearer_token` | `string` | ✅ Yes | Bearer token for SigNoz OTLP collector authentication |

## Usage Example

Declare the value in a `terraform.tfvars` file or pass via CLI:

```bash
# terraform.tfvars
otel_bearer_token = "your-signoz-bearer-token"
```

```bash
# Or pass via CLI flag
terraform apply -var="otel_bearer_token=your-signoz-bearer-token"
```

Reference in other Terraform resources:

```text
var.otel_bearer_token
```

> ⚠️ **Security Note:** This variable is marked `sensitive = true`, meaning Terraform will redact its value from plan/apply output and state diffs. Never commit raw token values to source control — use a secrets manager or CI/CD environment variables instead.
