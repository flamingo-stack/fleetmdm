Terraform configuration that provisions a complete SigNoz observability stack on AWS EKS for the FleetMDM dogfood environment, including cluster infrastructure, storage, load balancing, and Helm-based application deployment.

## Key Components

| Resource/Module | Purpose |
|---|---|
| `module.eks` | EKS cluster (`signoz`, k8s 1.31) using shared dogfood VPC |
| `module.acm` | ACM certificate for `signoz.dogfood.fleetdm.com` and OTLP subdomain |
| `module.ebs_csi_irsa_role` | IRSA role for EBS CSI driver (gp3 persistent storage) |
| `module.load_balancer_controller_irsa_role` | IRSA role for AWS Load Balancer Controller |
| `aws_eks_addon.ebs_csi` | EBS CSI driver addon with service account role |
| `kubernetes_storage_class_v1.gp3` | Default gp3 encrypted storage class |
| `helm_release.aws_load_balancer_controller` | ALB controller deployed via Helm into `kube-system` |
| `helm_release.signoz` | SigNoz chart deployed to `signoz` namespace with ALB ingress |
| `data.terraform_remote_state.dogfood` | Reads shared VPC outputs (subnets, VPC ID) from remote state |

**Backend:** S3 (`fleet-terraform-state20220408141538466600000002`) with DynamoDB locking and KMS encryption, assuming the `terraform-dogfood` IAM role.

**Access control:** Three explicit EKS access entries (admin, github-actions, SSO) with `AmazonEKSClusterAdminPolicy`; cluster creator admin permissions disabled to prevent role drift.

## Usage Example

```bash
# Initialize and select workspace
terraform init
terraform workspace select dogfood

# Plan and apply
terraform plan -out=signoz.tfplan
terraform apply signoz.tfplan
```

**Key local values:**

```text
signoz_domain  = signoz.dogfood.fleetdm.com
otlp_domain    = otlp.signoz.dogfood.fleetdm.com
cluster_name   = signoz
ALB scheme     = internal (private subnets only)
```

> **Note:** The EKS addon `before_compute=true` pattern is required for `vpc-cni`, `kube-proxy`, and `coredns` to avoid a circular dependency where nodes remain `NotReady` waiting for CNI. A 60-second `time_sleep` ensures the EBS CSI driver is active before the gp3 storage class is created.
