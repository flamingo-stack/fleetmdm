Terraform configuration that provisions AWS Backup resources for Aurora RDS clusters and S3 buckets, including IAM roles, KMS encryption keys, backup vaults, plans, and cross-region replication to `us-west-2`.

## Key Components

### IAM Resources
- **`aws_backup_assume_role`** — Trust policy allowing `backup.amazonaws.com` to assume the backup role
- **`aws_backup_policy`** — Inline policy granting backup operations across DynamoDB, RDS, S3, KMS, CloudWatch, and EventBridge
- **`aws_restore_policy`** — Inline policy granting restore operations for DynamoDB, RDS, and S3
- **`aws_iam_role.aws_backup`** — IAM role (`aws_backup_role`) combining both inline policies

### Aurora Backup Resources
- **`aws_kms_key.aws_backup_aurora_source/destination`** — Customer-managed KMS keys for source and replica regions
- **`aws_backup_vault.aws_backup_aurora_source/destination`** — Encrypted vaults in primary and replica (`us-west-2`) regions
- **`aws_backup_plan.snapshot_backup_plan`** — Daily backup at 05:00 UTC with a 7-day retention and cross-region copy action
- **`aws_backup_selection.snapshot_selection`** — Targets Aurora clusters tagged with `backup = true` in `us-east-2`

### S3 Backup Resources
- **`aws_kms_key.aws_backup_s3_source/destination`** — Dedicated KMS keys for S3 backups
- **`aws_backup_vault.aws_backup_s3_source/destination`** — Encrypted S3 backup vaults (note: destination vault definition is truncated in the file)

## Usage Example

```bash
# Initialize and apply the backup configuration
terraform init
terraform plan -out=backup.tfplan
terraform apply backup.tfplan
```

```hcl
# Aurora clusters must be tagged to be included in backups
tags = {
  backup = "true"
}
```

> **Note:** The file ends mid-resource (`aws_backup_vault.aws_backup_s3_destination`). Ensure the `kms_key_arn` assignment and closing braces are present before applying.
