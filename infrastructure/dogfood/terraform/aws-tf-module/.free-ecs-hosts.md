Terraform configuration that provisions Linux osquery host containers on AWS ECS Fargate, simulating a fleet of diverse Linux endpoints enrolled in FleetDM for the free tier environment.

## Key Components

| Resource | Purpose |
|---|---|
| `local.osquery_hosts` | Map of 10 osquery image tags (Ubuntu, Debian, CentOS variants) to simulated hostnames |
| `aws_iam_role.osquery` | ECS task execution role for osquery containers |
| `aws_iam_policy.osquery` | Grants ECR pull, KMS, and Secrets Manager access |
| `aws_ecr_repository.osquery` | Immutable, KMS-encrypted container registry with push scanning |
| `aws_kms_key.osquery` | KMS key with 10-day deletion window and automatic rotation |
| `aws_secretsmanager_secret.osquery_enroll` | Stores the FleetDM osquery enrollment secret |
| `module.osquery_docker` | Builds and pushes osquery images to ECR |
| `aws_ecs_task_definition.osquery` | Per-host Fargate task (256 CPU / 512 MB) with osquery TLS flags |
| `aws_ecs_service.osquery` | One service per host, wired into the free-tier ECS cluster |

## Usage Example

```bash
# Set osquery version and apply to spin up all simulated hosts
terraform apply -target=module.osquery_docker
terraform apply
```

Each ECS service runs a single osquery container that enrolls to `free.fleetdm.com` via TLS, using a stable `random_uuid` as the host identifier so identity persists across task restarts. The `FAKE_HOSTNAME` environment variable (e.g. `Skys-laptop`) overrides the container hostname reported to Fleet.

```text
osquery_version = "5.12.2"

Hosts spawned (1 Fargate task each):
  5.12.2-ubuntu24.04  →  Atmosphere-database
  5.12.2-ubuntu22.04  →  Skys-laptop
  5.12.2-centos7      →  Zephyrs-Laptop
  ... (10 total)
```

## Notes

- `deployment_minimum_healthy_percent = 0` ensures a clean replace when the static `--specified_identifier` UUID must stay consistent
- File carving and distributed queries are enabled via TLS endpoints on `/api/osquery/carve/*` and `/api/osquery/distributed/*`
