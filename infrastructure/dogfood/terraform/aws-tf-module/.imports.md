Terraform import block that brings an existing AWS CloudWatch log group (created outside of Terraform state) under management for the cron monitoring Lambda function.

## Key Components

- **Import Block** — Maps the existing CloudWatch log group to the Terraform resource address `module.monitoring.aws_cloudwatch_log_group.cron_monitoring_lambda[0]`
- **Resource ID** — Constructed dynamically using the `local.customer` local value to match the naming convention `/aws/lambda/<customer>_cron_monitoring`

## Usage Example

Run a targeted plan to preview the import before applying:

```bash
terraform plan -generate-config-out=generated.tf
terraform apply
```

The log group must already exist in AWS with the exact name `/aws/lambda/<customer>_cron_monitoring`. The `local.customer` value controls the interpolated segment of the resource ID, so ensure it matches the deployed environment before running `terraform apply`.

## Notes

- The `[0]` index indicates the resource is conditionally created (likely guarded by a `count` or `for_each` in the monitoring module)
- This import block only needs to be present once — after a successful `apply`, it can be safely removed from the configuration
