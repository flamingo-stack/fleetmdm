Terraform configuration for the FleetMDM "free" tier dogfood environment, defining infrastructure resources and ECS service settings for `free.fleetdm.com`.

## Key Components

**Locals**
- `customer_free` — Namespacing identifier derived from the base `local.customer` value
- `extra_environment_variables_free` — Fleet server environment variables including logging, MySQL TLS, and vulnerability database settings
- `sidecars_free` — Alpine-based sidecar container definition that retrieves and mounts the RDS TLS CA certificate before the main Fleet container starts

**Modules**
- `free` — Core Fleet deployment via `fleetdm/fleet-terraform//byo-vpc`; wires VPC, RDS (Aurora MySQL 8.0), Redis 7.1, ECS cluster, ALB, autoscaling (2–5 tasks), IAM roles, TLS volume mounts, and SES environment variables
- `acm-free` — ACM certificate provisioned and validated for `free.fleetdm.com`
- `ses-free` — SES addon for outbound email from `free.fleetdm.com` with a `mail.` custom MAIL FROM domain
- `migrations_free` — Runs Fleet database migrations as an ECS task before service startup; depends on `geolite2`

**Resources**
- `aws_route53_zone.free` — Hosted zone for `free.fleetdm.com`
- `aws_route53_record.free` — A-record aliased to the ALB DNS name

## Usage Example

```bash
# Initialize and apply only the free tier resources
terraform init
terraform apply -target=module.free -target=module.acm-free \
  -target=module.ses-free -target=module.migrations_free
```

## Notes

- RDS requires secure transport (`require_secure_transport = ON`); the sidecar fetches the CA cert via thumbprint lookup before the Fleet task starts
- Elastic APM variables are present but commented out; uncomment and supply `var.elastic_url` / `var.elastic_token` to enable tracing
- VPN CIDR blocks (`10.255.x.0/24`) restrict direct RDS access; database subnet access is limited to private subnets
