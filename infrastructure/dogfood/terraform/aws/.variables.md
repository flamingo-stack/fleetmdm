Terraform variable definitions for the FleetDM dogfood deployment, declaring all configurable inputs and a local name constant used across the infrastructure modules.

## Key Components

**Local**
- `name` — Fixed identifier `"fleetdm"` used internally across resources.

**Networking & Region**
- `region` — AWS region (default: `us-east-2`)
- `vpc_azs` / `redis_azs` — Availability zones for VPC and Redis (default: `us-east-2a/b/c`)
- `domain_fleetdm` — Public domain for the Fleet service (default: `dogfood.fleetdm.com`)
- `extra_security_group_cidrs` — Additional CIDR blocks (e.g. VPN) allowed to reach Redis/MySQL; validated as proper CIDRs

**Fleet Application**
- `fleet_image` — Container image to deploy (default: `fleetdm/fleet:v4.86.2`)
- `fleet_backend_cpu` / `fleet_backend_mem` — ECS task CPU units (256) and memory in MB (512)
- `fleet_min_capacity` / `fleet_max_capacity` — Auto-scaling bounds (1–5 containers)
- `cpu_tracking_target_value` / `memory_tracking_target_value` — Target tracking thresholds (60% CPU, 80% memory)
- `fleet_license` — Fleet Premium license key (empty by default)

**Database & Storage**
- `database_user` / `database_name` — RDS credentials and schema name
- `rds_backup_retention_period` — Snapshot retention in days (default: 30)
- `rds_initial_snapshot` — Optional snapshot ID to restore from
- `osquery_results_s3_bucket` / `osquery_status_s3_bucket` — S3 buckets for osquery archival

**Migration Task**
- `cpu_migrate` / `mem_migrate` — Resources for the one-off DB migration ECS task (1024 CPU, 2048 MB)

**Logging & Features**
- `logging_debug` / `logging_json` — Debug mode toggle and JSON logging flag
- `async_host_processing` — Enable asynchronous host data processing
- `software_inventory` — Toggle software inventory collection
- `cloudwatch_log_retention` — CloudWatch log retention in days (default: 1)

## Usage Example

Override defaults in a `terraform.tfvars` file:

```hcl
region                       = "us-west-2"
fleet_image                  = "fleetdm/fleet:v4.87.0"
fleet_min_capacity           = 2
fleet_max_capacity           = 10
fleet_license                = "your-premium-license-key"
rds_backup_retention_period  = 7
cloudwatch_log_retention     = 14
extra_security_group_cidrs   = ["10.10.0.0/16"]
```

Or pass inline:

```bash
terraform apply \
  -var="fleet_image=fleetdm/fleet:v4.87.0" \
  -var="region=us-west-2"
```
