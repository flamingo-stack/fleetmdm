Terraform input variable definitions for deploying FleetDM on Google Cloud Platform, covering infrastructure configuration for compute, database, networking, and Fleet application settings.

## Key Components

| Variable | Default | Description |
|---|---|---|
| `region` | `us-central1` | GCP region for all resources |
| `project_id` | *(required)* | GCP project ID |
| `prefix` | `fleet` | Resource name prefix |
| `db_zone` | `us-central1-c` | Cloud SQL availability zone |
| `db_tier` | `db-custom-1-3840` | Cloud SQL machine tier |
| `db_version` | `MYSQL_8_0` | MySQL 8.0 engine |
| `db_user` / `db_name` | `default` / `fleet` | Database credentials |
| `fleet_cpu` | `1000m` | Fleet container CPU request |
| `fleet_memory` | `1024Mi` | Fleet container memory request |
| `image` | `fleetdm/fleet:v4.86.2` | Fleet container image |
| `dns_zone` / `dns_name` | `""` | Optional Cloud DNS configuration |
| `vpc_subnet` | `10.10.10.0/28` | VPC subnet CIDR |
| `redis_mem` | `1` | Redis memory (GB) |
| `serverless_connector_*` | `2–3 × f1-micro` | VPC Serverless Connector scaling |
| `software_installers_bucket_name` | `fleet-software-installers` | GCS bucket for software installers |
| `license_key` | `""` | Fleet premium license key |
| `debug_logging` | `false` | Enable Fleet debug logging |

## Usage Example

Create a `terraform.tfvars` file to override defaults:

```hcl
project_id = "my-gcp-project"
region     = "us-central1"
prefix     = "prod-fleet"

db_tier    = "db-custom-2-7680"
redis_mem  = 2

fleet_cpu    = "2000m"
fleet_memory = "2048Mi"
image        = "fleetdm/fleet:v4.86.2"

dns_zone = "my-dns-zone"
dns_name = "fleet.example.com"

license_key   = "your-fleet-license-key"
debug_logging = "false"

software_installers_bucket_name = "my-fleet-installers"
```

Then apply:

```bash
terraform init
terraform plan -var-file="terraform.tfvars"
terraform apply -var-file="terraform.tfvars"
```

> **Note:** `project_id` is the only required variable with no default. All other variables use sensible defaults suitable for a small single-node Fleet deployment. See the full infrastructure definition at [`https://github.com/flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm).
