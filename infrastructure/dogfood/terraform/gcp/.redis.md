Terraform resource definition for a Google Cloud Memorystore Redis instance configured with high-availability and private network access.

## Key Components

- **`google_redis_instance.cache`** — Provisions a Redis instance with the following settings:
  - `tier = "STANDARD_HA"` — High-availability replication tier
  - `memory_size_gb` — Configurable via `var.redis_mem`
  - `authorized_network` — Scoped to the VPC network from `module.vpc`
  - `connect_mode = "PRIVATE_SERVICE_ACCESS"` — Uses VPC peering for private connectivity
  - `depends_on` — Waits for `module.private-service-access.peering_completed` before provisioning

## Usage Example

```bash
# Apply with default variables
terraform apply -var="prefix=flamingo" -var="redis_mem=4"
```

```text
# Expected resource naming pattern
${var.prefix}-redis  →  flamingo-redis
```

## Dependencies

| Dependency | Purpose |
|---|---|
| `module.vpc` | Supplies the authorized VPC network name |
| `module.private-service-access` | Ensures VPC peering is complete before Redis is created |

## Related Variables

| Variable | Description |
|---|---|
| `var.prefix` | Name prefix applied to the Redis instance and display name |
| `var.redis_mem` | Memory size in GB allocated to the Redis instance |
