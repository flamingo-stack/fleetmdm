Terraform configuration that provisions a Google Cloud SQL MySQL instance for the Fleet MDM database, including a randomly generated user password and a dedicated database with UTF-8 encoding.

## Key Components

- **`random_password.fleet-db-user-pw`** — Generates a 12-character random password for the Fleet database user
- **`module.fleet-mysql`** — Deploys a Cloud SQL MySQL instance using the `GoogleCloudPlatform/sql-db/google//modules/mysql` module (v9.0.0) with the following configuration:
  - **Additional user** — Creates a built-in SQL user using `var.db_user` and the generated password
  - **IP configuration** — Disables public IPv4, routes all traffic through a private VPC network (`module.vpc.network_self_link`), and requires no authorized networks (all connections mediated by Cloud SQL)
  - **Additional database** — Creates a database named `var.db_name` with `utf8mb4` charset and `utf8mb4_unicode_ci` collation
  - **Ordering dependency** — Waits on `module.private-service-access.peering_completed` to ensure VPC peering is established before provisioning

## Key Variables

| Variable | Purpose |
|---|---|
| `var.prefix` | Name prefix for the instance |
| `var.project_id` | GCP project |
| `var.db_user` | Database username |
| `var.db_name` | Database name |
| `var.db_version` | MySQL version |
| `var.region` / `var.db_zone` | Deployment location |
| `var.db_tier` | Cloud SQL machine tier |

## Usage Example

```bash
# Provision the MySQL instance as part of the full Terraform stack
terraform apply -var="prefix=flamingo" -var="project_id=my-gcp-project"
```

> **Note:** `deletion_protection` is set to `false`. For production deployments, consider setting this to `true` to prevent accidental database deletion.
