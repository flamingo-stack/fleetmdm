Terraform root configuration that declares required Google Cloud providers and configures them with project and region settings.

## Key Components

| Element | Description |
|---|---|
| `terraform` block | Declares `hashicorp/google` (v4.51.0) and `hashicorp/google-beta` as required providers |
| `provider "google"` | Configures the stable Google provider using `var.project_id` and `var.region` |
| `provider "google-beta"` | Configures the beta Google provider with the same project and region variables |

## Usage Example

Initialize and apply with required variables:

```bash
terraform init

terraform apply \
  -var="project_id=my-gcp-project" \
  -var="region=us-central1"
```

Or define a `terraform.tfvars` file:

```text
project_id = "my-gcp-project"
region     = "us-central1"
```

Then run:

```bash
terraform apply
```

> **Note:** The `var.project_id` and `var.region` variables must be declared in a `variables.tf` file within the same module. Both the stable and beta Google providers share the same project/region configuration, allowing use of GA and preview GCP features side by side.
