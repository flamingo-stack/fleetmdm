Enables required Google Cloud APIs for the project using Terraform, specifically VPC Access and Secret Manager services.

## Key Components

| Resource | Service Enabled |
|---|---|
| `google_project_service.vpcaccess-api` | `vpcaccess.googleapis.com` — enables Serverless VPC Access |
| `google_project_service.secretmanager` | `secretmanager.googleapis.com` — enables Secret Manager (via `google-beta` provider) |

## Usage Example

```bash
# Initialize and apply to enable APIs in your GCP project
terraform init
terraform apply -var="project_id=my-gcp-project"
```

Both resources reference `var.project_id`, which must be defined in your `variables.tf`. The Secret Manager resource explicitly uses the `google-beta` provider, so ensure it is declared in your provider configuration.

## Notes

- API enablement may take a few minutes to propagate in GCP.
- Destroying this resource will **disable** the APIs — use `prevent_destroy` if this is a concern in production.
