Terraform configuration that provisions a Google Cloud HTTPS load balancer with DNS management and SSL termination for a serverless backend.

## Key Components

| Resource / Module | Purpose |
|---|---|
| `google_dns_managed_zone.default` | Creates a Cloud DNS managed zone with DNSSEC enabled |
| `google_dns_record_set.default` | Adds an `A` record pointing the domain to the load balancer's external IP |
| `module.lb-http` | Deploys a Google Cloud HTTP(S) load balancer via the `serverless_negs` module with managed SSL |

## Usage Example

```bash
# Initialize and apply the load balancer configuration
terraform init
terraform apply \
  -var="project_id=my-gcp-project" \
  -var="prefix=flamingo" \
  -var="dns_zone=flamingo.run." \
  -var="dns_name=app.flamingo.run."
```

## Required Variables

| Variable | Description |
|---|---|
| `var.project_id` | GCP project ID |
| `var.prefix` | Name prefix for all resources |
| `var.dns_zone` | DNS zone name (e.g. `flamingo.run.`) |
| `var.dns_name` | Fully qualified DNS record name |

## Notes

- SSL is enforced with automatic HTTPS redirect (`https_redirect = true`)
- Uses a Google-managed SSL certificate tied to the `dns_name` domain
- Backend is a serverless NEG (`google_compute_region_network_endpoint_group.neg`) — that resource must be defined separately
- CDN is disabled; request/response logging is enabled at 100% sample rate
- IAP (Identity-Aware Proxy) is configured but disabled by default
