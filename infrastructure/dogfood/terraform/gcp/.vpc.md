Terraform configuration that provisions the Google Cloud VPC infrastructure required for FleetMDM's serverless deployment, including the network, VPC connector, private service access, and Cloud NAT.

## Key Components

| Resource | Description |
|---|---|
| `module.vpc` | Creates a GCP VPC network with a single subnet scoped to the configured region |
| `module.serverless-connector` | Provisions a Serverless VPC Access connector (beta) for Cloud Run/Functions connectivity |
| `module.private-service-access` | Establishes private service access for Cloud SQL peering over the VPC |
| `module.cloud_router` | Deploys a Cloud Router with NAT (`fleet-vpc-nat`) for outbound internet access from private instances |

## Locals

- `subnet_name` — Interpolated as `{prefix}-serverless-subnet`
- `vpc_connector_name` — Interpolated as `{prefix}-serverless-con`

## Usage Example

This module is driven by input variables defined elsewhere in the Terraform project. A representative `terraform.tfvars` might look like:

```hcl
prefix                                 = "flamingo"
project_id                             = "my-gcp-project"
region                                 = "us-central1"
vpc_subnet                             = "10.10.0.0/28"
serverless_connector_instance_type     = "e2-micro"
serverless_connector_min_instances     = 2
serverless_connector_max_instances     = 10
```

Apply with:

```bash
terraform init
terraform plan -var-file="terraform.tfvars"
terraform apply -var-file="terraform.tfvars"
```

## Dependencies

- [`terraform-google-modules/network/google`](https://registry.terraform.io/modules/terraform-google-modules/network/google) `~> 4.1.0`
- [`GoogleCloudPlatform/sql-db/google`](https://registry.terraform.io/modules/GoogleCloudPlatform/sql-db/google) `9.0.0`
- [`terraform-google-modules/cloud-router/google`](https://registry.terraform.io/modules/terraform-google-modules/cloud-router/google) `~> 6.0`
- `google_project_service.vpcaccess-api` must be enabled before the serverless connector is created
