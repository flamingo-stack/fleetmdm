Terraform configuration that provisions a private, KMS-encrypted S3 bucket for storing software installers, along with the IAM policy and role attachment needed for Fleet MDM to access it.

## Key Components

| Resource | Description |
|---|---|
| `aws_s3_bucket.software_installers` | Workspace-prefixed S3 bucket with `force_destroy = true` |
| `aws_s3_bucket_server_side_encryption_configuration` | Enforces AES-256 encryption via a dedicated KMS key |
| `aws_s3_bucket_public_access_block` | Blocks all public ACLs, policies, and bucket access |
| `aws_kms_key.software_installers` | Customer-managed KMS key with automatic key rotation enabled |
| `aws_kms_alias.software_installers` | Human-readable alias: `alias/<workspace>-software-installers` |
| `aws_iam_policy_document.software_installers` | IAM policy granting S3 CRUD + multipart upload permissions; supports dynamic KMS policy statements via `local.software_installers_kms_policy` |
| `aws_iam_role_policy_attachment.software_installers` | Attaches the S3 policy to `aws_iam_role.main` |

## Usage Example

The bucket and permissions are created automatically during `terraform apply`. The workspace name controls the bucket prefix and KMS alias:

```bash
# Deploy to a named workspace
terraform workspace new staging
terraform apply
# Creates: bucket prefix "staging-...", alias "alias/staging-software-installers"
```

To supply custom KMS policy statements (e.g., cross-account access), define `local.software_installers_kms_policy` in your locals:

```text
locals {
  software_installers_kms_policy = [
    {
      sid     = "AllowCrossAccount"
      actions = ["kms:Decrypt", "kms:GenerateDataKey"]
      resources = ["*"]
      principals = [{ type = "AWS", identifiers = ["arn:aws:iam::123456789:root"] }]
      conditions = []
    }
  ]
}
```

## Notes

- `force_destroy = true` allows Terraform to delete non-empty buckets on `terraform destroy` — use with caution in production.
- Several `tfsec` warnings (customer-managed key, versioning, bucket logging) are suppressed with expiry annotations pending future remediation.
