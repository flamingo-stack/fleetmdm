Terraform configuration for AWS Kinesis Firehose delivery streams that archive osquery results and status logs to S3 during load testing, with KMS encryption, public access blocking, and 1-day object expiration.

## Key Components

| Resource | Description |
|---|---|
| `aws_s3_bucket.osquery-results` | S3 bucket for osquery query result log archives |
| `aws_s3_bucket.osquery-status` | S3 bucket for osquery status log archives |
| `aws_s3_bucket_server_side_encryption_configuration` | KMS encryption for both buckets |
| `aws_s3_bucket_lifecycle_configuration` | Auto-expires objects after 1 day for both buckets |
| `aws_s3_bucket_public_access_block` | Blocks all public access on both buckets |
| `aws_iam_policy.firehose-results / firehose-status` | IAM policies granting Firehose S3 write permissions |
| `aws_iam_role.firehose-results / firehose-status` | IAM roles with Firehose service assume-role trust |
| `aws_kinesis_firehose_delivery_stream.osquery_results` | Firehose stream delivering results logs to S3 |
| `aws_kinesis_firehose_delivery_stream.osquery_status` | Firehose stream delivering status logs to S3 |

## Usage Example

```bash
# Deploy firehose resources as part of the loadtest environment
terraform init
terraform apply -target=aws_kinesis_firehose_delivery_stream.osquery_results \
                -target=aws_kinesis_firehose_delivery_stream.osquery_status
```

Both Firehose streams use the `extended_s3` destination type. IAM roles are scoped to allow only the minimum S3 actions needed (`PutObject`, `ListBucket`, `AbortMultipartUpload`). The 1-day lifecycle expiration and `force_destroy = true` flag indicate this is a short-lived dev/load-test environment. Security scan suppressions (`tfsec`, `checkov`) are applied intentionally for dev use.
