Defines AWS security group rules for ECS backend containers, controlling inbound traffic from the Application Load Balancer (ALB) and allowing unrestricted outbound traffic.

## Key Components

| Resource | Name | Purpose |
|---|---|---|
| `aws_security_group` | `backend` | Security group attached to ECS backend tasks, scoped to the shared VPC |
| `aws_security_group_rule` | `backend-ingress` | Allows inbound TCP traffic on port `8080` from the ALB security group only |
| `aws_security_group_rule` | `backend-egress` | Allows all outbound traffic (`0.0.0.0/0`) from backend containers |

## Traffic Flow

```text
[ALB Security Group]
        |
        | TCP :8080 (ingress)
        ▼
[Backend Security Group]
        |
        | All ports, all protocols (egress)
        ▼
  [0.0.0.0/0]
```

## Usage Example

This file is consumed automatically by Terraform as part of the ECS stack. Ensure the shared state outputs `vpc.vpc_id` and `alb_security_group.id` are available:

```bash
# Initialize and apply alongside other ECS modules
terraform init
terraform plan
terraform apply
```

## Notes

- Ingress is **restricted** to traffic sourced from the ALB security group — no direct public access to backends.
- Egress uses `cidr_blocks = ["0.0.0.0/0"]` with a `tfsec:ignore` annotation to suppress the public egress warning — review if egress restriction is required in your environment.
- The `local.prefix` local variable drives naming/descriptions; ensure it is defined in your `locals.tf`.
