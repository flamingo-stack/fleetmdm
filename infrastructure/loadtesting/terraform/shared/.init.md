Terraform initialization file that configures the AWS provider, required provider versions, and remote S3 backend for the Fleet load testing shared infrastructure.

## Key Components

- **AWS Provider** — Targets `us-east-2` with default tags for `environment`, `terraform`, and `state`
- **Required Providers** — Pins `hashicorp/aws >= 5.68.0`, `kreuzwerker/docker ~> 2.16.0`, and `metio/git 2025.10.10`
- **S3 Backend** — Stores Terraform state in `fleet-terraform-state20220408141538466600000002` with KMS encryption, DynamoDB locking, and IAM role assumption for the `loadtesting` account
- **`aws_caller_identity` data source** — Retrieves the current AWS account identity at plan/apply time
- **`git_repository` data source** — Reads the local git repository metadata four levels up from the module directory
- **`random_pet` resource** — Generates a single-word random pet name for unique resource naming

## Usage Example

```bash
# Initialize with the configured S3 backend
terraform init

# Select or create a workspace (workspace_key_prefix = "loadtesting")
terraform workspace new loadtesting-dev

# Plan against the load testing account
terraform plan
```

> **Note:** The S3 backend `key` and `workspace_key_prefix` should be updated to match the target account alias and unique deployment key when reusing this configuration in a different environment.
