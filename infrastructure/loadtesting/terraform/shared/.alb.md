Terraform configuration for the FleetDM load testing environment's Application Load Balancer (ALB) infrastructure, including S3 log buckets, Athena query resources, ALB listeners, and associated security groups.

## Key Components

| Resource | Name | Purpose |
|---|---|---|
| `module.s3_bucket_for_logs` | `fleet-loadtesting-alb-logs` | Encrypted S3 bucket storing ALB access logs with 365-day lifecycle |
| `module.athena-s3-bucket` | `fleet-loadtesting-alb-logs-athena` | S3 bucket for Athena query results against ALB logs |
| `aws_athena_database.logs` | `fleet_loadtesting_alb_logs` | Athena database for querying ALB log data |
| `aws_athena_workgroup.logs` | `fleet-loadtesting-logs` | Athena workgroup with SSE_S3 output encryption |
| `aws_alb.main` | `fleetdm` | Public-facing ALB with access logging and 905s idle timeout |
| `aws_alb_listener.https-fleetdm` | HTTPS:443 | TLS 1.3 listener with TLS13-1-2-2021-06 policy; returns 404 default |
| `aws_alb_listener.http` | HTTP:80 | Redirects all HTTP traffic to HTTPS (301) |
| `aws_security_group.lb` | Load balancer SG | Controls inbound/outbound traffic for the ALB |

**Security group rules:**

| Rule | Ports | Source |
|---|---|---|
| `lb-ingress` | 443/tcp | `0.0.0.0/0` |
| `lb-http-ingress` | 80/tcp | `0.0.0.0/0` |
| `lb-es` | 9200/tcp | `10.0.0.0/8` |
| `lb-es-apm` | 8200/tcp | `10.0.0.0/8` + NAT IPs |
| `lb-kibana` | 5601/tcp | `10.0.0.0/8` |
| `lb-egress` | all | `0.0.0.0/0` |

## Usage Example

```bash
# Initialize and apply this module within the load testing Terraform workspace
terraform init
terraform plan -target=module.s3_bucket_for_logs \
               -target=aws_alb.main \
               -target=aws_alb_listener.https-fleetdm
terraform apply
```

S3 log buckets enforce AES-256 server-side encryption, block all public access, and transition objects to `ONEZONE_IA` after 90 days with full expiration at 365 days.
