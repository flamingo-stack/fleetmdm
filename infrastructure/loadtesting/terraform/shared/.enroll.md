Terraform resource definition that creates an AWS Secrets Manager secret for storing Fleet MDM enrollment credentials, encrypted with a dedicated KMS key.

## Key Components

- **`aws_secretsmanager_secret.enroll_secret`** — Secrets Manager secret scoped to the load test environment, with a dynamic path incorporating a random pet name for uniqueness.

## Resource Details

| Attribute | Value |
|---|---|
| Name path | `/fleet/loadtest/enroll/<random_pet_id>` |
| Encryption | `aws_kms_key.main` (customer-managed KMS key) |

## Dependencies

- **`random_pet.main`** — Provides a unique suffix for the secret name, preventing collisions across deployments.
- **`aws_kms_key.main`** — Customer-managed KMS key used to encrypt the secret at rest.

## Usage Example

```bash
# Apply this resource as part of the load test stack
terraform apply -target=aws_secretsmanager_secret.enroll_secret
```

After creation, populate the secret value separately (e.g., with the Fleet enroll secret) using the AWS CLI:

```bash
aws secretsmanager put-secret-value \
  --secret-id "/fleet/loadtest/enroll/<random_pet_id>" \
  --secret-string '{"enroll_secret":"<value>"}'
```

> **Note:** The secret name is dynamic. Use `terraform output` or the AWS console to retrieve the full ARN after `terraform apply`.
