Terraform configuration for provisioning the Elastic Stack (Elasticsearch, Kibana, and APM Server) infrastructure on AWS, used for Fleet load testing observability.

## Key Components

| Resource | Description |
|---|---|
| `aws_security_group.elasticsearch` | VPC security group restricting ingress to RFC-1918 `10.0.0.0/8` on ports 9200, 8200, 5601, and 22 |
| `aws_autoscaling_group.elasticstack` | Single-instance ASG (`m6a.4xlarge`) deploying the Elastic Stack via Ansible at launch |
| `aws_launch_template.elasticstack` | EC2 launch template using Amazon Linux 2, IMDSv2, a 150 GB EBS data volume, and a user-data bootstrap script |
| `aws_iam_role.elasticstack` | EC2 instance role granting Secrets Manager access (SSH keys), CloudWatch agent permissions, and ECS task execution policy |
| ALB listeners & target groups | HTTPS listeners (TLS 1.3 policy) forwarding to Elasticsearch (:9200), Elastic APM (:8200), and Kibana (:5601) |

## Usage Example

```bash
# Initialize and apply this module from the load testing terraform directory
terraform init
terraform apply -target=aws_autoscaling_group.elasticstack
```

The ASG propagates Ansible tags at launch to configure the node automatically:

```text
ansible_repository    → https://github.com/fleetdm/fleet.git
ansible_playbook_file → elasticsearch.yml
ansible_branch        → <current git branch>
```

Health checks:
- Elasticsearch: `GET /_cat/health`
- Kibana: `GET /api/status`
- APM Server: no health check path configured (TCP)

## Notes

- Outbound traffic is unrestricted (`0.0.0.0/0`) with a `tfsec` suppression comment.
- The ASG delete timeout is set to 15 minutes to allow graceful Elastic Stack shutdown.
