Terraform outputs file that exposes key infrastructure resource references from the FleetMDM AWS deployment for use by other Terraform modules or external consumers.

## Key Components

| Output | Resource | Description |
|--------|----------|-------------|
| `alb_security_group` | `aws_security_group.lb` | Security group attached to the Application Load Balancer |
| `alb` | `aws_alb.main` | Main Application Load Balancer resource |
| `alb-listener` | `aws_alb_listener.https-fleetdm` | HTTPS listener configured for FleetDM |
| `vpc` | `module.vpc` | Full VPC module output |
| `ecr` | `aws_ecr_repository.prometheus-to-cloudwatch` | ECR repository for the Prometheus-to-CloudWatch sidecar |
| `ecr-kms` | `aws_kms_key.main` | KMS key used for ECR encryption |
| `enroll_secret` | `aws_secretsmanager_secret.enroll_secret` | Secrets Manager secret containing the Fleet device enrollment secret |

## Usage Example

Reference these outputs from a parent or consuming Terraform module:

```bash
# View all outputs after applying
terraform output

# Reference a specific output in a consuming module
module.fleetmdm.alb.dns_name
module.fleetmdm.vpc.vpc_id
module.fleetmdm.enroll_secret.arn
```

```text
# Example cross-module reference in another .tf file
module "fleetmdm" {
  source = "../fleetmdm"
}

resource "aws_route53_record" "fleet" {
  alias {
    name = module.fleetmdm.alb.dns_name
  }
}
```
