Terraform module configuration that provisions a shared AWS VPC for the FleetMDM infrastructure, including subnet tiers, NAT gateway, and EKS-compatible networking tags.

## Key Components

- **VPC CIDR**: `10.12.0.0/16` across three `us-east-2` availability zones
- **Subnet Tiers**:
  - Private: `10.12.1–3.0/24` — workloads and EKS nodes
  - Public: `10.12.11–13.0/24` — internet-facing load balancers
  - Database: `10.12.21–23.0/24` — RDS instances (with subnet group and route table)
  - ElastiCache: `10.12.31–33.0/24` — Redis/Memcached (with subnet group and route table)
- **NAT Gateway**: Single shared NAT gateway (`single_nat_gateway = true`); no per-AZ NAT or VPN gateway
- **DNS**: Hostnames enabled via `enable_dns_hostnames = true`
- **EKS Subnet Tags**:
  - Public subnets tagged `kubernetes.io/role/elb` for external load balancers
  - Private subnets tagged `kubernetes.io/role/internal-elb` for internal load balancers
  - Cluster-specific EKS tags are applied by downstream EKS/SigNoz modules, not here

## Usage Example

This module is consumed automatically by Terraform. No direct invocation is needed, but the VPC outputs (subnet IDs, VPC ID) are referenced by other modules:

```bash
# Initialize and apply the VPC configuration
terraform init
terraform plan -target=module.vpc
terraform apply -target=module.vpc
```

```bash
# Retrieve VPC outputs for use in dependent modules
terraform output -module=module.vpc vpc_id
terraform output -module=module.vpc private_subnets
```

## Notes

- The `shared = "true"` tag indicates this VPC is shared across multiple services (EKS clusters, RDS, ElastiCache).
