Terraform configuration defining the AWS ECS infrastructure for the Fleet MDM backend service, including cluster setup, task definitions, auto-scaling policies, and secrets management.

## Key Components

| Resource | Description |
|---|---|
| `aws_ecs_cluster.fleet` | ECS cluster with Container Insights enabled |
| `aws_ecs_service.fleet` | Fargate service wired to two ALB target groups (internal + main) on port 8080 |
| `aws_ecs_task_definition.backend` | Main Fleet task: `fleet` container + `prometheus-exporter` sidecar (1024 CPU, 4096 MB) |
| `aws_ecs_task_definition.migration` | One-off migration task running `fleet prepare db` (1024 CPU, 2048 MB) |
| `aws_appautoscaling_*` | Target-tracking auto-scaling on CPU (90%) and memory (80%) thresholds |
| `aws_cloudwatch_log_group.backend` | CloudWatch log group with 1-day retention for all containers |
| `aws_secretsmanager_secret.fleet_server_private_key` | Auto-generated 32-character private key stored in Secrets Manager |

## Key Configuration Details

- **Networking**: Fargate tasks run in private VPC subnets using `awsvpc` mode
- **Secrets injected**: MySQL password, license key, server private key (via Secrets Manager ARNs)
- **Environment**: MySQL (primary + read replica via Aurora), Redis (ElastiCache), S3 software installers bucket
- **Observability**: Prometheus metrics scraped from `localhost:8080/metrics` and pushed to CloudWatch namespace `fleet-loadtest`
- **Extensibility**: Environment variables and secrets are `concat`-merged with `local.additional_env_vars` and `local.secrets`

## Usage Example

```bash
# Deploy the ECS stack
terraform workspace select <env>
terraform apply -target=aws_ecs_service.fleet

# Trigger a one-off database migration
aws ecs run-task \
  --cluster <prefix>-backend \
  --task-definition <prefix>-migrate \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={subnets=[<subnet-id>],securityGroups=[<sg-id>]}"
```
