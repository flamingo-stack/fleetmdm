Defines the input variables for the Terraform AWS provider configuration, currently exposing the target AWS region as a configurable parameter.

## Key Components

| Variable | Type | Default | Description |
|---|---|---|---|
| `aws_region` | `string` | `us-east-2` | AWS region where resources will be provisioned |

## Usage Example

Override the default region at plan/apply time:

```bash
terraform apply -var="aws_region=us-west-2"
```

Or via a `.tfvars` file:

```text
aws_region = "us-west-2"
```

Reference the variable in other Terraform files:

```text
provider "aws" {
  region = var.aws_region
}
```

> **Note:** The default region is `us-east-2` (Ohio). Ensure the target region supports all required AWS services before overriding this value.
