Terraform configuration that deploys a Percona Monitoring and Management (PMM) server on AWS ECS Fargate for load testing environments, wiring it into a shared VPC, internal ALB, and RDS MySQL instance.

## Key Components

| Resource | Purpose |
|---|---|
| `aws_ecs_task_definition.pmm` | Fargate task running `percona/pmm-server:2` with startup script to configure admin password and add RDS MySQL monitoring |
| `aws_ecs_service.pmm` | Single-replica Fargate service attached to internal ALB target group |
| `aws_iam_role.pmm_execution` | ECS execution role with permissions for CloudWatch Logs and Secrets Manager |
| `aws_secretsmanager_secret.pmm_admin_password` | Auto-generated 24-char admin password stored in Secrets Manager |
| `aws_security_group.pmm` | Restricts inbound HTTPS (443) to the internal ALB security group only |
| `aws_lb_target_group.pmm` | HTTPS target group with `/v1/readyz` health check |
| `aws_lb_listener_rule.pmm` | Routes `pmm-<workspace>.loadtest.fleetdm.com` to the PMM target group |
| `aws_route53_record.pmm` | DNS alias record pointing to the internal ALB |
| `data.terraform_remote_state.shared` | Reads shared VPC outputs |
| `data.terraform_remote_state.infra` | Reads ECS cluster, IAM roles, RDS endpoint, and ALB details from workspace-scoped infra state |

## Usage Example

```bash
# Initialize and select a workspace
terraform init
terraform workspace select <workspace-name>

# Plan and apply
terraform plan -var="aws_region=us-east-2"
terraform apply -var="aws_region=us-east-2"

# PMM dashboard is available at:
# https://pmm-<workspace>.loadtest.fleetdm.com
```

## Notes

- **State backend**: S3 bucket `fleet-terraform-state20220408141538466600000002` with DynamoDB locking; assumes IAM role `arn:aws:iam::353365949058:role/terraform-loadtesting`.
- **Ephemeral design**: `recovery_window_in_days = 0` on the Secrets Manager secret allows immediate deletion, suited for short-lived load test environments.
- **RDS integration**: PMM automatically registers the Fleet RDS MySQL cluster on startup using `pmm-admin add mysql` with credentials pulled from Secrets Manager.
- Requires Terraform `>= 1.5` and AWS provider `>= 5.68.0`.
