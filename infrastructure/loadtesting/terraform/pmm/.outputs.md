Terraform output definitions for the PMM (Percona Monitoring and Management) deployment, exposing the UI access URL and admin password secret reference.

## Key Components

| Output | Description |
|--------|-------------|
| `pmm_url` | Workspace-scoped HTTPS URL for accessing the PMM UI (internal/VPN only) |
| `pmm_admin_password_secret` | AWS Secrets Manager secret name storing the PMM admin password |

## Usage Example

```bash
# View all outputs after apply
terraform output

# Retrieve the PMM URL for the current workspace
terraform output pmm_url

# Fetch the admin password using the secret name output
aws secretsmanager get-secret-value \
  --secret-id $(terraform output -raw pmm_admin_password_secret)
```

> **Note:** The `pmm_url` is dynamically scoped to the active Terraform workspace (e.g., `pmm-staging.loadtest.fleetdm.com`), so ensure the correct workspace is selected before referencing this output.
