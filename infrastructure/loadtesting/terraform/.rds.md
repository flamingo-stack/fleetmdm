Terraform configuration for provisioning an Aurora MySQL RDS cluster on AWS, including secure password generation, AWS Secrets Manager integration, and cluster parameter tuning for a Fleet MDM deployment.

## Key Components

| Resource | Description |
|---|---|
| `random_password.database_password` | Generates a 16-character alphanumeric master DB password |
| `random_pet.db_secret_postfix` | Generates a unique suffix to avoid Secrets Manager name collisions across workspace reuse |
| `aws_secretsmanager_secret.database_password_secret` | KMS-encrypted secret stored at `/fleet/database/password/master-2-<suffix>` with zero-day recovery window |
| `aws_secretsmanager_secret_version.database_password_secret_version` | Binds the generated password to the secret |
| `module.aurora_mysql` | Aurora MySQL 8.0 cluster (`aurora-mysql` engine, version `8.0.mysql_aurora.3.08.2`) with two instances |

## Cluster Configuration Highlights

- **IAM DB authentication** enabled; storage encrypted at rest
- **Performance Insights** enabled with slow query log exports to CloudWatch
- **Custom parameter group** (`aurora-mysql8.0`) with `innodb_print_all_deadlocks = 1` for deadlock observability
- **Networking**: placed in dedicated database subnets, security group allows traffic from private subnets and VPN CIDR blocks
- **Snapshot restore**: bootstrapped from a named snapshot ARN for pre-seeded data
- Enhanced monitoring at 60-second intervals via a dedicated IAM role

## Usage Example

```bash
# Deploy the RDS cluster within the target Terraform workspace
terraform init
terraform apply -target=module.aurora_mysql
```

```bash
# Retrieve the generated master password from Secrets Manager
aws secretsmanager get-secret-value \
  --secret-id "/fleet/database/password/master-2-<pet-id>" \
  --query SecretString \
  --output text
```

## Notes

- `skip_final_snapshot = true` and `recovery_window_in_days = 0` are intentional for workspace flexibility — review before using in production.
- The `tfsec:ignore` annotations suppress findings for performance insights encryption and storage encryption (both managed separately via `storage_encrypted = true` and `kms_key_id`).
