Terraform input variable definitions for configuring load test container deployments on ECS, controlling container count, resource sizing, and osquery-perf runtime flags.

## Key Components

| Variable | Type | Default | Description |
|---|---|---|---|
| `git_tag_branch` | `string` | *(required)* | Git tag or branch used to build loadtest container images |
| `loadtest_containers` | `number` | `1` | Number of loadtest containers to deploy |
| `extra_flags` | `list(string)` | `["--orbit_prob", "0.0"]` | Extra CLI flags passed to `osquery-perf` containers |
| `task_size` | `object` | `cpu=4096, memory=8192` | ECS task CPU and memory allocation (in ECS units) |

## Usage Example

```hcl
module "loadtest" {
  source = "./modules/loadtest"

  git_tag_branch      = "main"
  loadtest_containers = 5

  extra_flags = ["--orbit_prob", "0.5", "--host_count", "1000"]

  task_size = {
    cpu    = 2048
    memory = 4096
  }
}
```

## Notes

- `git_tag_branch` is the only required variable with no default; it must be explicitly provided in every deployment.
- `task_size` uses Terraform's `optional()` syntax, so individual fields (`cpu`, `memory`) can be omitted and will fall back to their defaults (`4096` and `8192` respectively).
- CPU and memory values follow AWS ECS unit conventions: `4096` CPU units = 4 vCPUs; `8192` MB = 8 GB RAM.
