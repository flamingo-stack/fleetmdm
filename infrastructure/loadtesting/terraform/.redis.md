Terraform configuration for provisioning an AWS ElastiCache Redis replication group with associated parameter group, security group, and network access rules.

## Key Components

| Resource | Description |
|---|---|
| `aws_elasticache_replication_group.default` | 3-node Redis 6.2 cluster across `us-east-2a/b/c` AZs with automatic failover |
| `aws_elasticache_parameter_group.default` | Custom `redis6.x` parameter group disabling pub/sub output buffer limits |
| `aws_security_group.redis` | Dedicated VPC security group for ElastiCache access |
| `aws_security_group_rule.ingress` | Allows TCP 6379 from private subnets and VPN CIDR blocks |
| `aws_security_group_rule.egress` | Unrestricted outbound traffic from the Redis security group |

## Configuration Notes

- **Port:** `6379` (standard Redis)
- **Engine version:** Redis `6.2`, parameter family `redis6.x`
- **Cluster size:** 3 cache clusters, instance type controlled by `var.redis_instance_type`
- **Failover:** Automatic failover enabled across 3 AZs
- **Encryption:** At-rest and in-transit encryption are **disabled** (suppressed via `tfsec:ignore` annotations)
- **Snapshots:** Retention limit set to `0` (no automatic snapshots)
- **Networking:** Subnet group and VPC ID sourced from remote state (`shared` workspace)

## Usage Example

```bash
# Apply with a specific instance type
terraform apply -var="redis_instance_type=cache.r6g.large"
```

```text
# Remote state outputs consumed
data.terraform_remote_state.shared.outputs.vpc.elasticache_subnet_group_name
data.terraform_remote_state.shared.outputs.vpc.private_subnets_cidr_blocks
data.terraform_remote_state.shared.outputs.vpc.vpc_id
```

> **Security note:** Encryption is intentionally disabled with `tfsec:ignore` suppressions. Review this before deploying to production environments handling sensitive data.
