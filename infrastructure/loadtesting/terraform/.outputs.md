Terraform outputs file that exposes key infrastructure values from the Fleet ECS deployment for use by other modules or CI/CD pipelines.

## Key Components

| Output | Description |
|--------|-------------|
| `private_subnets` | Private subnet ARNs sourced from shared remote state VPC |
| `fleet_migration_revision` | Current revision number of the Fleet ECS migration task definition |
| `fleet_migration_subnets` | JSON-encoded list of subnets used by the Fleet ECS service network configuration |
| `fleet_migration_security_groups` | JSON-encoded list of security groups attached to the Fleet ECS service |
| `fleet_ecs_cluster_arn` | ARN of the Fleet ECS cluster |
| `fleet_ecs_cluster_id` | ID of the Fleet ECS cluster |

## Usage Example

Reference these outputs from another Terraform module:

```hcl
data "terraform_remote_state" "fleet" {
  backend = "s3"
  config = {
    bucket = "my-tfstate-bucket"
    key    = "fleet/terraform.tfstate"
    region = "us-east-1"
  }
}

# Access Fleet ECS cluster ARN
locals {
  cluster_arn          = data.terraform_remote_state.fleet.outputs.fleet_ecs_cluster_arn
  migration_subnets    = jsondecode(data.terraform_remote_state.fleet.outputs.fleet_migration_subnets)
  migration_sec_groups = jsondecode(data.terraform_remote_state.fleet.outputs.fleet_migration_security_groups)
}
```

> **Note:** `fleet_migration_subnets` and `fleet_migration_security_groups` are JSON-encoded strings. Use `jsondecode()` when consuming them in downstream Terraform configurations.
