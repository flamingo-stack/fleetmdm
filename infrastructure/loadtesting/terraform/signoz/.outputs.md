Terraform outputs file for the EKS + SigNoz observability stack, exposing cluster connection details and OpenTelemetry collector endpoints for downstream consumption.

## Key Components

| Output | Description |
|---|---|
| `cluster_name` | EKS cluster name from the `eks` module |
| `cluster_endpoint` | API server endpoint for the EKS cluster |
| `cluster_certificate_authority_data` | CA certificate for authenticating against the cluster |
| `configure_kubectl` | Ready-to-run `aws eks update-kubeconfig` command |
| `get_signoz_ui_url` | `kubectl` command to retrieve the SigNoz UI LoadBalancer hostname on port `8080` |
| `get_otlp_endpoint` | `kubectl` command to retrieve the OTEL collector LoadBalancer hostname on port `4317` |
| `otel_collector_endpoint` | Programmatic `hostname:4317` string read directly from the `kubernetes_service` data source; falls back to `"LoadBalancer not ready yet"` |

The `data "kubernetes_service"` block fetches the `signoz-otel-collector` service from the `signoz` namespace after `helm_release.signoz` completes, enabling the `otel_collector_endpoint` output to resolve at plan time without manual `kubectl` calls.

## Usage Example

After `terraform apply`, retrieve outputs and configure your kubeconfig in one step:

```bash
# Configure kubectl
$(terraform output -raw configure_kubectl)

# Get the SigNoz UI URL
terraform output -raw get_signoz_ui_url | bash

# Get the OTLP collector endpoint for use in app config
OTLP=$(terraform output -raw otel_collector_endpoint)
echo "OTEL_EXPORTER_OTLP_ENDPOINT=http://$OTLP"
```

For programmatic use in other Terraform workspaces:

```hcl
data "terraform_remote_state" "eks" {
  backend = "s3"
  config  = { bucket = "my-tfstate"; key = "eks/terraform.tfstate" }
}

locals {
  otlp_endpoint = data.terraform_remote_state.eks.outputs.otel_collector_endpoint
}
```

> **Note:** `otel_collector_endpoint` may return `"LoadBalancer not ready yet"` immediately after apply if the AWS LoadBalancer controller has not yet assigned a hostname. Re-run `terraform refresh` once the service is provisioned.
