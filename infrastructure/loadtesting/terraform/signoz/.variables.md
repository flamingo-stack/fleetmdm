Defines Terraform input variables for AWS infrastructure configuration.

## Key Components

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `aws_region` | `string` | `us-east-2` | AWS region for resource deployment |

## Usage Example

Reference this variable in other Terraform files within the same module:

```plaintext
provider "aws" {
  region = var.aws_region
}
```

Override the default at plan/apply time:

```bash
terraform apply -var="aws_region=us-west-2"
```

Or via a `.tfvars` file:

```plaintext
aws_region = "eu-central-1"
```

## Notes

- The default region is `us-east-2` (Ohio). Override as needed for your deployment target.
- Defined in [`variables.tf`](https://github.com/flamingo-stack/fleetmdm/blob/main/variables.tf) — add additional infrastructure variables here to keep configuration centralized.
