Terraform root module that provisions a SigNoz observability stack on AWS EKS for load testing, including cluster setup, EBS storage, and Helm-based SigNoz deployment with pre-destroy cleanup logic.

## Key Components

| Resource / Block | Purpose |
|---|---|
| `backend "s3"` | Remote state stored in S3 with DynamoDB locking, scoped to the `loadtesting` workspace |
| `data.terraform_remote_state.shared_vpc` | Reads VPC ID and private subnets from a separately managed shared infrastructure state |
| `module.eks` | EKS cluster (`signoz-<workspace>`) on Kubernetes 1.31 using a single `m6i.8xlarge` managed node group |
| `module.ebs_csi_irsa_role` | IAM Role for Service Accounts (IRSA) granting the EBS CSI controller pod permission to manage EBS volumes |
| `aws_eks_addon.ebs_csi` | EBS CSI Driver addon attached after the IRSA role is ready to avoid circular OIDC dependency |
| `kubernetes_storage_class_v1.gp3` | Default `gp3` encrypted StorageClass provisioned via the EBS CSI driver |
| `helm_release.signoz` | SigNoz chart deployed with tuned ClickHouse (600 Gi, 12–24 Gi RAM) and OTEL Collector (3 replicas, 36 Gi RAM limit) resources |
| `null_resource.signoz_predestroy_cleanup` | Pre-destroy local-exec that removes the ClickHouse operator, strips CHI finalizers, deletes LoadBalancer services, and queues PVC deletion to prevent destroy hangs ([fleet#35405](https://github.com/fleetdm/fleet/issues/35405)) |

## Usage Example

```bash
# Initialise with workspace-scoped state
terraform init
terraform workspace new loadtest-1

# Plan and apply
terraform plan -var="aws_region=us-east-2"
terraform apply -var="aws_region=us-east-2"

# Destroy (pre-destroy cleanup runs automatically before helm_release teardown)
terraform destroy -var="aws_region=us-east-2"
```

## Notes

- EKS addons (`vpc-cni`, `kube-proxy`, `coredns`) are installed with `before_compute = true` to avoid a node-readiness deadlock during initial provisioning.
- The OTEL Collector service is configured as an **internal** AWS load balancer; the SigNoz UI service is public-facing.
- A 60-second `time_sleep` guards StorageClass creation against race conditions after the EBS CSI addon becomes active.
