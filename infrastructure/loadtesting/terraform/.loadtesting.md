Terraform configuration that provisions AWS ECS Fargate services and task definitions for load testing a Fleet MDM deployment using the `osquery-perf` simulator.

## Key Components

| Resource | Description |
|---|---|
| `locals.hosts_per_container` | Configures 500 simulated osquery hosts per container instance |
| `aws_ecs_service.loadtest` | Creates one Fargate service per `loadtest_containers` count, each running a single load test task |
| `aws_ecs_task_definition.loadtest` | Defines task specs: 512 CPU units, 1024 MB memory, `awsvpc` networking, and CloudWatch log routing |
| `aws_secretsmanager_secret_version.enroll_secret` | Retrieves the Fleet enrollment secret from AWS Secrets Manager via shared remote state |

### Container Command Flags

The `osquery-perf` binary is invoked with:

- `-enroll_secret` — Fleet enrollment secret from Secrets Manager
- `-host_count` — 500 hosts per container
- `-server_url` — Internal ALB DNS endpoint
- `--policy_pass_prob 0.5` — 50% policy pass rate simulation
- `--start_period 5m` — Staggered host enrollment start
- `--orbit_prob 0.0` — Disables Orbit agent simulation

## Usage Example

```bash
# Scale the number of load test containers via Terraform variable
terraform apply -var="loadtest_containers=10"
# Results in 10 ECS services × 500 hosts = 5,000 simulated osquery hosts
```

To enable **distributed mode** (coordinated host index offsets across containers), uncomment the two flagged lines in `container_definitions`:

```text
# "-total_host_count", tostring(var.loadtest_containers * local.hosts_per_container),
# "-host_index_offset", tostring(count.index * local.hosts_per_container),
```

## Notes

- Each task sets `ulimits.nofile` to `9999` to support high concurrent connection counts
- Containers run in private subnets behind the `backend` security group
- Logs stream to the shared CloudWatch log group under the `loadtest-{index}` prefix
- Source: [`loadtesting.tf`](https://github.com/flamingo-stack/fleetmdm/blob/main/loadtesting.tf)
