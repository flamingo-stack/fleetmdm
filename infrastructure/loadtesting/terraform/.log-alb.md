Terraform module configuration that provisions ALB (Application Load Balancer) access logging infrastructure with Athena query support enabled.

## Key Components

| Field | Value | Description |
|---|---|---|
| `source` | `fleetdm/fleet-terraform` | Fleet Terraform addon at `tf-mod-addon-logging-alb-v1.3.0` |
| `prefix` | `terraform.workspace` | Namespaces resources per Terraform workspace |
| `enable_athena` | `true` | Enables AWS Athena for querying ALB logs |

## Usage Example

```bash
# Initialize and apply from the repo root
terraform init
terraform workspace select <env>
terraform apply -target=module.logging_alb
```

The module is pinned to `tf-mod-addon-logging-alb-v1.3.0` via `?depth=1&ref=` to ensure reproducible deployments. Logs are stored in S3 and queryable via Athena, enabling SQL-based analysis of ALB access patterns.

> **Note:** `enable_athena = true` provisions additional AWS resources (Glue catalog, Athena workgroup). Ensure your AWS account has the necessary IAM permissions before applying.
