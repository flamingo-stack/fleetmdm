Terraform input variables for the FleetMDM ECS deployment, defining configurable parameters for Fleet containers, Aurora database, Elasticache (Redis/Valkey), and optional OpenTelemetry tracing.

## Key Components

| Variable | Type | Default | Description |
|---|---|---|---|
| `tag` | string | `v4.76.1` | Container image tag to deploy (matches branch name) |
| `fleet_task_count` | number | `5` | Max ECS container scale count (≥ 0) |
| `fleet_task_memory` | number | `4096` | Fleet container memory (MB) |
| `fleet_task_cpu` | number | `512` | Fleet container CPU units |
| `database_instance_size` | string | `db.t4g.medium` | Aurora instance class |
| `database_instance_count` | number | `2` | Aurora instance count (≥ 1) |
| `redis_instance_size` | string | `cache.t4g.micro` | Elasticache node instance class |
| `redis_instance_count` | number | `3` | Elasticache node count (≥ 1) |
| `redis_engine` | string | `redis` | Cache engine: `redis` or `valkey` |
| `redis_engine_version` | string | `7.1` | Cache engine version |
| `redis_parameter_group_family` | string | `redis7` | Parameter group family (must prefix-match engine) |
| `enable_otel` | bool | `false` | Enable OpenTelemetry/SigNoz tracing |

## Usage Example

Override defaults at plan/apply time using `-var` flags:

```bash
# Scale up Fleet containers with more memory
terraform apply \
  -var="tag=v4.80.0" \
  -var="fleet_task_count=10" \
  -var="fleet_task_memory=8192"

# Switch from Redis to Valkey
terraform apply \
  -var="redis_engine=valkey" \
  -var="redis_engine_version=8.0" \
  -var="redis_parameter_group_family=valkey8"

# Enable OpenTelemetry tracing
terraform apply -var="enable_otel=true"
```

## Validation Rules

- `fleet_task_count` must be `>= 0`
- `database_instance_count` must be `>= 1`
- `redis_instance_count` must be `>= 1`
- `redis_engine` must be `"redis"` or `"valkey"`
- `redis_parameter_group_family` must start with the value of `redis_engine` (e.g., `redis7` for `redis`, `valkey8` for `valkey`)

> To discover valid engine/family pairs: `aws elasticache describe-cache-engine-versions --engine <engine>`
