Terraform TLS resource definitions for generating cryptographic keys and certificates used by MDM (SCEP) and CloudFront infrastructure.

## Key Components

- **`tls_private_key.scep_key`** — RSA-4096 private key for the SCEP (Simple Certificate Enrollment Protocol) MDM CA
- **`tls_self_signed_cert.scep_cert`** — Self-signed root CA certificate tied to the SCEP key, valid for ~10 years (`87648` hours), with signing and encipherment capabilities enabled
- **`tls_private_key.cloudfront_key`** — RSA-2048 private key for CloudFront distribution signing

## Usage Example

These resources are referenced by downstream Terraform resources. For example, the SCEP cert PEM output is typically passed to Fleet MDM configuration:

```hcl
# Reference SCEP cert in Fleet MDM config
mdm_scep_cert = tls_self_signed_cert.scep_cert.cert_pem
mdm_scep_key  = tls_private_key.scep_key.private_key_pem

# Reference CloudFront key for signed URL/cookie configuration
cloudfront_private_key = tls_private_key.cloudfront_key.private_key_pem
```

## Notes

- The SCEP certificate is configured as a **CA certificate** (`is_ca_certificate = true`) with `cert_signing` and `crl_signing` uses, making it suitable as a Fleet MDM root authority
- Subject is set to `Fleet Root CA / Fleet. / US`
- The CloudFront key uses a smaller 2048-bit key, appropriate for CloudFront's key group requirements
- Private key material is sensitive — ensure Terraform state is stored securely (e.g., encrypted S3 backend)
