Terraform outputs file that exposes infrastructure resource attributes for the FleetMDM load testing environment, including ALB endpoints, ECS configuration, RDS cluster details, and networking information.

## Key Components

| Output | Sensitive | Description |
|---|---|---|
| `server_url` | No | Public HTTPS URL derived from Route53 FQDN |
| `internal_alb_dns_name` | No | Internal ALB DNS name |
| `internal_alb_listener_arn` | No | HTTP listener ARN for host-based routing rules |
| `internal_alb_https_listener_arn` | No | HTTPS listener ARN for host-based routing rules |
| `internal_alb_zone_id` | No | ALB hosted zone ID for Route53 alias records |
| `internal_alb_security_group_id` | No | Security group ID for the internal ALB |
| `ecs_cluster` | Yes | ECS cluster reference from `loadtest` module |
| `security_groups` | Yes | ECS task network security groups |
| `ecs_arn` | Yes | ECS task IAM role ARN |
| `ecs_execution_arn` | Yes | ECS execution IAM role ARN |
| `logging_config` | Yes | ECS logging configuration |
| `enroll_secret_arn` | Yes | Secrets Manager ARN for Fleet enrollment secret |
| `vpc_subnets` | Yes | Private subnets from shared `fleet-vpc` remote state |
| `rds_cluster_endpoint` | No | Aurora writer endpoint |
| `rds_cluster_reader_endpoint` | No | Aurora reader endpoint |
| `rds_cluster_master_username` | Yes | Aurora master username |
| `rds_cluster_database_name` | No | Aurora database name |
| `rds_security_group_id` | No | RDS cluster security group ID |

## Usage Example

Reference these outputs from another Terraform root module via remote state:

```hcl
data "terraform_remote_state" "loadtest" {
  backend = "s3"
  config = {
    bucket = "my-tfstate-bucket"
    key    = "loadtest/terraform.tfstate"
    region = "us-east-1"
  }
}

# Use non-sensitive outputs directly
locals {
  fleet_url     = data.terraform_remote_state.loadtest.outputs.server_url
  alb_zone_id   = data.terraform_remote_state.loadtest.outputs.internal_alb_zone_id
  rds_endpoint  = data.terraform_remote_state.loadtest.outputs.rds_cluster_endpoint
}
```

> Sensitive outputs (`ecs_arn`, `vpc_subnets`, `enroll_secret_arn`, etc.) are redacted in `terraform plan`/`apply` output but remain accessible via remote state or `terraform output -json`.
