Terraform configuration that provisions SCEP (Simple Certificate Enrollment Protocol) secrets for Fleet MDM's Apple MDM integration, storing certificate and key material in AWS Secrets Manager.

## Key Components

- **`random_password.challenge`** — Generates a 12-character alphanumeric challenge password used for SCEP authentication
- **`aws_secretsmanager_secret_version.scep`** — Writes a JSON-encoded secret bundle to the pre-existing SCEP secret managed by the `mdm` module, containing three Fleet MDM environment variables:
  - `FLEET_MDM_APPLE_SCEP_CERT_BYTES` — PEM-encoded SCEP certificate from `tls_self_signed_cert.scep_cert`
  - `FLEET_MDM_APPLE_SCEP_KEY_BYTES` — PEM-encoded private key from `tls_private_key.scep_key`
  - `FLEET_MDM_APPLE_SCEP_CHALLENGE` — The randomly generated challenge password

## Dependencies

This file depends on resources defined elsewhere in the Terraform configuration:

| Reference | Expected Source |
|---|---|
| `module.mdm.scep.id` | MDM module output |
| `tls_self_signed_cert.scep_cert` | TLS certificate resource |
| `tls_private_key.scep_key` | TLS key resource |

## Usage Example

```bash
# Apply only the SCEP secret resources
terraform apply -target=aws_secretsmanager_secret_version.scep

# View the generated challenge password (sensitive)
terraform output -raw scep_challenge
```

## Notes

- The challenge password excludes special characters (`special = false`) for compatibility with SCEP client implementations
- The secret version is stored as a JSON object, matching Fleet MDM's expected environment variable format
- Rotating SCEP credentials requires re-applying this configuration and redeploying Fleet MDM
