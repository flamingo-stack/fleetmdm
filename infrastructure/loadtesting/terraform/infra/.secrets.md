Retrieves two secrets from AWS Secrets Manager: a Fleet license key and an enrollment secret referenced from shared Terraform remote state.

## Key Components

- **`aws_secretsmanager_secret.license`** — Looks up the Fleet license secret by name (`/fleet/license`)
- **`aws_secretsmanager_secret_version.enroll_secret`** — Fetches the current version of the enrollment secret, with its ID sourced from the `shared` Terraform remote state output

## Usage Example

Reference these data sources in other Terraform resources:

```hcl
# Use the license secret ARN
resource "aws_ecs_task_definition" "fleet" {
  ...
  secrets = [
    {
      name      = "FLEET_LICENSE_KEY"
      valueFrom = data.aws_secretsmanager_secret.license.arn
    },
    {
      name      = "FLEET_ENROLL_SECRET"
      valueFrom = data.aws_secretsmanager_secret_version.enroll_secret.secret_id
    }
  ]
}
```

## Notes

- The license secret path (`/fleet/license`) must exist in AWS Secrets Manager before `terraform apply`
- The enroll secret ID is passed in via [remote state](https://github.com/flamingo-stack/fleetmdm/blob/main/terraform/shared), requiring the `shared` workspace to be applied first
- Only the secret metadata is fetched for the license; the full versioned value is retrieved for the enrollment secret
