Defines Terraform local values for the Fleet load-test deployment, centralizing naming conventions, container image references, observability configuration, MySQL TLS setup, and ECS sidecar definitions.

## Key Components

| Local | Purpose |
|---|---|
| `customer` / `prefix` | Workspace-scoped naming: `fleet-<workspace>` |
| `fleet_image` | Constructs the ECR image URI from repo URL, tag, and DockerHub digest |
| `otel_environment_variables` | OpenTelemetry env vars (enabled when `var.enable_otel = true`) |
| `elastic_apm_environment_variables` | Elastic APM env vars (enabled when `var.enable_otel = false`) |
| `extra_environment_variables` | Merged Fleet runtime config: logging, Redis, MySQL, SSO, CloudWatch, TLS |
| `extra_secrets` | Maps `FLEET_LICENSE_KEY` to its Secrets Manager ARN |
| `vpn_cidr_blocks` | VPN private subnet CIDRs for security group rules |
| `ca_cert_thumbprint` / `cert_path` | RDS TLS certificate identity and in-container path |
| `sidecars` | ECS sidecar definition for `rds-tls-ca-retriever` (Alpine-based init container) |

## Usage Example

```bash
# Select a workspace before applying
terraform workspace select loadtest

# The locals resolve to, e.g.:
# customer    = "fleet-loadtest"
# fleet_image = "123456789.dkr.ecr.us-east-2.amazonaws.com/fleet:v4.50.0-<digest>"
# cert_path   = "/tmp/rds-tls/us-east-2.pem"
```

The `sidecars` list is passed to the ECS task definition to run a short-lived Alpine container that downloads the RDS CA certificate into a shared volume mount before the Fleet container starts, enabling mutual TLS authentication to Aurora MySQL. Tracing backend (OpenTelemetry via SigNoz vs. Elastic APM) is toggled exclusively through `var.enable_otel`.
