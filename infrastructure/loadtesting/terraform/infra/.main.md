Terraform configuration that provisions a complete Fleet MDM load testing environment on AWS, wiring together networking, database, cache, ECS, and supporting add-on modules under the `loadtest.fleetdm.com` subdomain.

## Key Components

| Resource / Module | Purpose |
|---|---|
| `aws_route53_record.main` | Creates an A record aliasing the ALB for `<customer>.loadtest.fleetdm.com` |
| `module.loadtest` | Core Fleet deployment via `fleet-terraform//byo-vpc` — provisions VPC config, Aurora MySQL 8.0, ElastiCache Redis, ECS cluster, Fleet ECS service, and ALB |
| `module.ses` | SES email add-on with custom MAIL FROM domain |
| `module.migrations` | Runs Fleet DB migrations as an ECS task before service start |
| `module.vuln-processing` | External vulnerability scanning add-on running in the same ECS cluster |
| `module.mdm` | MDM add-on with Windows MDM enabled; Apple MDM disabled; SCEP secret configured |
| `module.osquery-carve` | S3-backed osquery file carving add-on |
| `module.logging_alb` | ALB access log shipping to S3 with Athena query support |
| `module.acm` | ACM certificate reference for the customer subdomain |

## Notable Configuration Details

- **Database**: Aurora MySQL 8.0 (`8.0.mysql_aurora.3.10.3`), restored from a named cluster snapshot, with `sort_buffer_size` tuned to 8 MB and TLS enforced via `require_secure_transport = ON`
- **Redis**: ElastiCache cluster spread across `us-east-2a/b/c` with pubsub output buffer limits disabled
- **Fleet ECS**: Fixed autoscaling (min = max = `var.fleet_task_count`), RDS TLS cert sidecar via volume/mount, private key secret, and software installer S3 bucket with KMS
- **ALB**: Deletion protection disabled (load test environment), 905-second idle timeout, HTTPS via wildcard ACM cert

## Usage Example

```bash
# Initialize and deploy to a specific workspace (sets local.customer)
terraform workspace new my-loadtest
terraform init
terraform apply \
  -var="database_instance_size=db.r6g.xlarge" \
  -var="fleet_task_count=3" \
  -var="redis_instance_size=cache.r6g.large"
```
