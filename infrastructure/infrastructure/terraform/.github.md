Configures AWS IAM resources to enable GitHub Actions OIDC-based authentication for the `fleetdm/confidential` repository, granting scoped access to Terraform remote state backend resources (S3, KMS, DynamoDB).

## Key Components

| Resource | Name | Purpose |
|---|---|---|
| `data.tls_certificate.github` | `github` | Fetches GitHub OIDC TLS thumbprint dynamically |
| `aws_iam_openid_connect_provider` | `github` | Registers GitHub Actions as an AWS OIDC identity provider |
| `data.aws_iam_policy_document` | `fleetdm_confidential_cloudflare_trust` | Trust policy restricting role assumption to `fleetdm/confidential` repo only |
| `aws_iam_role` | `fleetdm-confidential-cloudflare-terraform` | Assumable role for GitHub Actions CI/CD workflows |
| `data.aws_iam_policy_document` | `fleetdm_confidential_cloudflare_rw` | Permissions policy for S3 tfstate, KMS encryption, and DynamoDB state locking |
| `aws_iam_policy` | `fleetdm-confidential-cloudflare-terraform` | Attaches the backend access permissions |
| `aws_iam_role_policy_attachment` | `fleetdm_confidential_cloudflare_rw_attach` | Binds the policy to the role |

## Trust Policy Conditions

The IAM role enforces two OIDC claim conditions to prevent unauthorized assumption:

- **Audience (`aud`)** — must equal `sts.amazonaws.com`
- **Subject (`sub`)** — must match `repo:fleetdm/confidential:*`

## Permissions Granted

```text
S3:  GetObject, PutObject, DeleteObject  → cloudflare/terraform.tfstate only
S3:  ListBucket, GetBucketVersioning     → state bucket
KMS: Encrypt, Decrypt, DescribeKey,
     GenerateDataKey                     → backend KMS key
KMS: ListKeys                            → * (safe, read-only global)
DynamoDB: GetItem, PutItem, DeleteItem,
          DescribeTable                  → state lock table
```

## Usage Example

In a GitHub Actions workflow within the `fleetdm/confidential` repo:

```yaml
jobs:
  terraform:
    permissions:
      id-token: write
      contents: read
    steps:
      - uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: arn:aws:iam::<ACCOUNT_ID>:role/fleetdm-confidential-cloudflare-terraform
          aws-region: us-east-1
```
