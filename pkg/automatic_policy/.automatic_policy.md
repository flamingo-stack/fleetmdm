Generates trigger policies from software package metadata, producing the name, SQL query, description, and target platform needed to automatically install software on hosts that are missing it.

## Key Components

### Types

- **`PolicyData`** — Struct holding the generated policy fields: `Name`, `Query`, `Description`, and `Platform`.
- **`InstallerMetadata`** — Interface that metadata types must implement: `PolicyName()`, `PolicyDescription()`, `PolicyQuery()`, `PolicyPlatform()`.
- **`FMAInstallerMetadata`** — Metadata for Fleet-managed app (FMA) packages with a custom query.
- **`MacInstallerMetadata`** — Metadata for macOS apps, generating a bundle identifier query against the `apps` table.
- **`FullInstallerMetadata`** — Metadata for `pkg`, `msi`, `deb`, and `rpm` installers, generating platform-appropriate SQL queries.

### Function

- **`Generate(metadata InstallerMetadata) (*PolicyData, error)`** — Calls each method on the provided metadata and returns a fully populated `*PolicyData`.

### Sentinel Errors

| Error | Condition |
|---|---|
| `ErrExtensionNotSupported` | Extension is not `pkg`, `msi`, `deb`, or `rpm` |
| `ErrMissingBundleIdentifier` | `pkg` installer lacks a bundle identifier |
| `ErrMissingProductAndUpgradeCode` | `msi` installer lacks both product and upgrade codes |
| `ErrMissingTitle` | No title was extracted from the installer |

## Usage Example

```go
// Generate a policy for a macOS .pkg installer
metadata := automatic_policy.FullInstallerMetadata{
    Title:            "My App",
    Extension:        "pkg",
    BundleIdentifier: "com.example.myapp",
}

policy, err := automatic_policy.Generate(metadata)
if err != nil {
    log.Fatal(err)
}

fmt.Println(policy.Name)        // [Install software] My App (pkg)
fmt.Println(policy.Platform)    // darwin
fmt.Println(policy.Query)       // SELECT 1 FROM apps WHERE bundle_identifier = 'com.example.myapp';
```
