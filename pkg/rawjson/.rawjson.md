Provides utilities for combining two JSON objects at the root level by merging their top-level key-value pairs into a single JSON object.

## Key Components

### `CombineRoots(a, b json.RawMessage) (json.RawMessage, error)`
Merges two JSON objects into one by stripping the closing brace from `a` and the opening brace from `b`, joining them with a comma. Short-circuits if either input is an empty object (`{}`). Validates both inputs before processing.

### `validate(j json.RawMessage) error`
Internal helper that ensures the raw JSON:
- Is at least 2 bytes long
- Is wrapped in `{` and `}`
- Does not end with a trailing comma

## Usage Example

```go
package main

import (
    "encoding/json"
    "fmt"
    "github.com/flamingo-stack/fleetmdm/rawjson"
)

func main() {
    a := json.RawMessage(`{"name":"fleet","version":1}`)
    b := json.RawMessage(`{"env":"production","debug":false}`)

    combined, err := rawjson.CombineRoots(a, b)
    if err != nil {
        panic(err)
    }
    fmt.Println(string(combined))
    // Output: {"name":"fleet","version":1,"env":"production","debug":false}

    // Empty object short-circuit
    empty := json.RawMessage(`{}`)
    result, _ := rawjson.CombineRoots(empty, b)
    fmt.Println(string(result))
    // Output: {"env":"production","debug":false}
}
```

## Limitations

- Does **not** perform deep merging — duplicate top-level keys from both objects will both appear in the output, resulting in technically valid but ambiguous JSON
- Assumes inputs are well-formed JSON produced by Go's standard `encoding/json` library (no pretty-printed or manually crafted JSON with unusual whitespace near braces)
