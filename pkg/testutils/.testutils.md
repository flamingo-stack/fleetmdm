Provides shared test helpers for managing log output and environment variable state in Go tests.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TestLogWriter` | `struct` | Adapts `testing.TB` to `io.Writer` for compatibility with `go-kit/log` |
| `TestLogWriter.Write` | method | Writes log bytes to `t.Log()`, trimming the trailing newline added by `go-kit/log` |
| `SaveEnv` | function | Snapshots the current OS environment and restores it via `t.Cleanup` after the test completes |

## Usage Example

**`TestLogWriter`** — pass to any logger expecting an `io.Writer`:

```go
func TestMyService(t *testing.T) {
    logger := log.NewLogfmtLogger(&testutils.TestLogWriter{T: t})
    svc := NewService(logger)
    // log output appears only on test failure or with -v
}
```

**`SaveEnv`** — isolate environment mutations without affecting other tests:

```go
func TestEnvDependentBehavior(t *testing.T) {
    testutils.SaveEnv(t) // snapshot current env; restores automatically on test exit

    os.Setenv("FLEET_LICENSE_KEY", "test-key")
    // test code that reads the environment...
    // original environment is fully restored after the test
}
```

> ⚠️ `SaveEnv` calls `os.Clearenv()` during cleanup, which affects the **entire process environment**. Do not use it in tests marked with `t.Parallel()`.
