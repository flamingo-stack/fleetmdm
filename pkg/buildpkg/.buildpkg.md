Utilities for building Fleet components, specifically for creating macOS universal (fat) binaries from multiple architecture-specific Mach-O executables.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `MakeMacOSFatExecutable` | `func` | Combines multiple Mach-O binaries into a single macOS fat (universal) executable |
| `alignBits` | `const` | Alignment exponent (`14`) satisfying both amd64 (12-bit) and arm64 (14-bit) requirements |
| `align` | `const` | Computed alignment value (`1 << 14 = 16384` bytes) |
| `magicFat64` | `const` | Fat64 magic number (currently unused; fat64 output is blocked due to OS compatibility issues) |

## Usage Example

```go
err := buildpkg.MakeMacOSFatExecutable(
    "/tmp/fleet-universal",
    "/tmp/fleet-amd64",
    "/tmp/fleet-arm64",
)
if err != nil {
    log.Fatalf("failed to build fat binary: %v", err)
}
```

## Notes

- Input files must be valid 32-bit or 64-bit Mach-O binaries (`macho.Magic32` / `macho.Magic64`); non-Mach-O inputs return an error.
- The fat binary header is written in **big-endian** byte order regardless of the contained architectures (all currently supported macOS targets are little-endian).
- Fat64 output is explicitly blocked — if the last binary's offset or size would exceed `1 << 32`, the function returns an error, as fat64 binaries are not executable on macOS and are not producible by the native `lipo` tool.
- The output file is created with `0755` permissions.
- Adapted from [`randall77/makefat`](https://github.com/randall77/makefat/blob/master/makefat.go) (Unlicensed).
