Provides utilities for loading, validating, and encoding TLS certificates used throughout the Fleet MDM server and agent components.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `LoadPEM` | Function | Reads a PEM file and returns an `*x509.CertPool` |
| `ValidateConnection` | Function | Verifies a TLS connection to a Fleet server URL using a cert pool |
| `ValidateConnectionContext` | Function | Context-aware variant of `ValidateConnection` with timeout/deadline support |
| `ValidateClientAuthTLSConnection` | Function | Validates mutual TLS (mTLS) by dialing a server using a client certificate |
| `Certificate` | Struct | Holds a parsed `tls.Certificate` alongside its raw PEM bytes |
| `LoadClientCertificateFromFiles` | Function | Loads a client cert/key pair from file paths; returns `nil, nil` if files are absent |
| `LoadClientCertificate` | Function | Loads a client cert/key pair from PEM strings; returns `nil, nil` if both are empty |
| `EncodeCertPEM` | Function | Encodes an `*x509.Certificate` to PEM format |
| `EncodePrivateKeyPEM` | Function | Encodes an `*rsa.PrivateKey` to PKCS#1 PEM format |

## Usage Example

```go
// Load a CA cert pool from a PEM file
pool, err := certificate.LoadPEM("/etc/fleet/ca.pem")
if err != nil {
    log.Fatal(err)
}

// Validate that the Fleet server is reachable with the given CA
if err := certificate.ValidateConnection(pool, "https://fleet.example.com"); err != nil {
    log.Fatalf("TLS validation failed: %v", err)
}

// Load a client certificate for mTLS from files
cert, err := certificate.LoadClientCertificateFromFiles("/etc/fleet/client.crt", "/etc/fleet/client.key")
if err != nil {
    log.Fatal(err)
}
if cert != nil {
    // cert.Crt is ready for use in tls.Config
    tlsConfig := &tls.Config{Certificates: []tls.Certificate{cert.Crt}}
}

// Encode a generated certificate to PEM for storage
pemBytes := certificate.EncodeCertPEM(x509Cert)
os.WriteFile("/tmp/cert.pem", pemBytes, 0644)
```
