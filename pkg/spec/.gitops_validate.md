Provides utilities for validating GitOps configuration files by detecting unknown or misspelled JSON/YAML keys against expected struct field definitions using reflection and Levenshtein distance suggestions.

## Key Components

| Symbol | Description |
|---|---|
| `ValidKeysProvider` | Interface for types with custom JSON marshaling to declare their valid keys |
| `knownJSONKeys` | Extracts and caches valid JSON field names from a struct type via reflection |
| `collectFields` | Recursively walks struct fields (including embedded) to build the key map |
| `anyFieldTypes` | Registry mapping parent struct types to concrete type overrides for `any`-typed fields |
| `suggestKey` | Returns the closest known key name using Levenshtein distance (~40% edit distance threshold) |
| `validateUnknownKeys` | Entry point: dispatches to map/slice validators recursively |
| `validateRawKeys` | Convenience wrapper that unmarshals JSON then validates keys |
| `validateYAMLKeys` | Convenience wrapper that unmarshals YAML then validates keys |
| `filterWarnings` | Separates validation errors into hard errors vs. logged warnings by error type |

## Usage Example

```go
// Validate a raw JSON payload against a known GitOps struct type
raw := json.RawMessage(`{"controls": {"macos_updates": {"deadline": "2024-01-01"}}}`)
errs := validateRawKeys(raw, reflect.TypeFor[GitOpsConfig](), "fleet.yml", nil)
if len(errs) > 0 {
    for _, err := range errs {
        fmt.Println(err)
    }
}

// Validate a YAML file's keys against a struct type
yamlBytes, _ := os.ReadFile("controls.yml")
errs = validateYAMLKeys(yamlBytes, reflect.TypeFor[GitOpsControls](), "controls.yml", []string{"controls"})

// Custom type declares its own valid keys
type MyConfig struct{}
func (m *MyConfig) ValidKeys() []string {
    return []string{"api_key", "secret", "endpoint"}
}
```

## Notes

- Results from `knownJSONKeys` are cached per `reflect.Type` behind a mutex for concurrent safety.
- The `renameto` struct tag registers deprecated field name aliases alongside current names.
- `anyFieldTypes` bridges `any`/`interface{}`-typed fields (which lose type info at runtime) to their concrete GitOps types for deep validation.
