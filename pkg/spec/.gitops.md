Parses and validates Fleet GitOps YAML configuration files, providing structured types and error handling for managing org settings, controls, policies, labels, software, and MDM configurations in a GitOps workflow.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `GitOpsControls` | MDM controls config (macOS/iOS/Windows/Android settings, disk encryption, scripts) |
| `GitOpsOrgSettings` | Top-level `org_settings:` section embedding `fleet.AppConfig` with GitOps-only fields |
| `GitOpsMDM` | Extends `fleet.MDM` with GitOps-only fields (e.g., EULA) |
| `GitOpsPolicySpec` | Policy spec with run-script, install-software, and webhook automation fields |
| `LabelChangesSummary` | Tracks label additions, removals, updates, and cross-team movements |
| `LabelChange` / `LabelMovement` | Fine-grained label operation records |
| `SoftwarePackage` | Software installer spec with team-level override hydration |
| `Software` | Aggregates packages, App Store apps, and Fleet-maintained apps |
| `Label` | Extends `fleet.LabelSpec` with custom JSON unmarshaling to distinguish null vs. omitted `hosts` |

### Error Types

| Type | Description |
|------|-------------|
| `ParseTypeError` | Structured error for YAML type mismatches, with human-readable field paths |
| `ParseUnknownKeyError` | Error for unrecognized YAML keys, optionally suggesting the closest valid key |

### Functions

| Function | Description |
|----------|-------------|
| `YamlUnmarshal` | Converts YAML → JSON → struct, preserving structured error information |
| `MaybeParseTypeError` | Wraps `json.UnmarshalTypeError` into a `ParseTypeError` with file/path context |
| `NewLabelChangesSummary` | Builds a `LabelChangesSummary` from raw change and movement slices |

## Usage Example

```go
// Unmarshal a GitOps YAML file with structured error reporting
data, _ := os.ReadFile("gitops.yml")

var controls GitOpsControls
if err := YamlUnmarshal(data, &controls); err != nil {
    if typeErr := new(ParseTypeError); errors.As(err, &typeErr) {
        fmt.Println(typeErr.Error()) // e.g. Couldn't edit "gitops.yml" at "controls.macos_updates", expected type string but got number
    }
}

// Build a label changes summary
changes := []LabelChange{
    {Name: "linux-servers", Op: "+", TeamName: "infra"},
    {Name: "dev-macs", Op: "-", TeamName: "engineering"},
}
summary := NewLabelChangesSummary(changes, nil)
if summary.HasChanges() {
    fmt.Println("Labels added:", summary.LabelsToAdd)
    fmt.Println("Labels removed:", summary.LabelsToRemove)
}
```
