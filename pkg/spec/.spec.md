Parses concatenated YAML "Fleet spec" files into a typed `Group` struct, handling multi-document splitting, environment variable expansion, deprecated key rewriting, and secret handling modes.

## Key Components

### Types

- **`Group`** — Aggregates all parsed spec types: `Queries`, `Teams`, `Packs`, `Labels`, `Policies`, `Software`, `AppConfig`, `EnrollSecret`, `UsersRoles`, etc.
- **`Metadata`** — Holds the `kind`, `apiVersion`, and raw `spec` fields from a single YAML document section.
- **`secretHandling`** — Enum controlling `FLEET_SECRET_` variable behavior: `secretsReject`, `secretsIgnore`, or `secretsExpand`.
- **`GroupFromBytesOpts`** — Optional configuration for `GroupFromBytes`, currently supporting a logging callback.

### Functions

- **`GroupFromBytes(b []byte, opts ...GroupFromBytesOpts) (*Group, error)`** — Primary entry point; splits, unmarshals, and routes each YAML document by `kind` into the appropriate `Group` field. Logs deprecation warnings for renamed kinds and keys.
- **`SplitYaml(in string) []string`** — Splits a multi-document YAML string on `---` separators, trimming empty chunks.
- **`ExpandEnv(s string) (string, error)`** — Public wrapper for environment variable expansion using `secretsReject` mode (errors on `FLEET_SECRET_` vars).
- **`expandEnv(s string, secretMode secretHandling) (string, error)`** — Internal expander supporting backslash-escaped `$`, XML/JSON-aware value escaping, and configurable secret handling.
- **`SetEnvOverrides(overrides map[string]string)`** — Thread-safe override for environment variables used during expansion (useful for testing).
- **`rewriteNewToOldKeys(raw json.RawMessage, target any) (json.RawMessage, map[string]string, error)`** — Rewrites renamed field keys back to their legacy JSON tag names before unmarshaling.

## Usage Example

```go
import "github.com/fleetdm/fleet/v4/ee/fleetctl/spec"

data, err := os.ReadFile("fleet-specs.yml")
if err != nil {
    log.Fatal(err)
}

group, err := spec.GroupFromBytes(data, spec.GroupFromBytesOpts{
    LogFn: func(format string, args ...any) {
        fmt.Printf(format, args...)
    },
})
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Parsed %d queries, %d policies\n", len(group.Queries), len(group.Policies))
```
