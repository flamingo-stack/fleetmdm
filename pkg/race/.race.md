Detects whether the Go race detector is enabled at runtime, exposing the result as a package-level boolean.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Enabled` | `bool` | `true` if the binary was built with `-race`, `false` otherwise |

> The actual value of `Enabled` is set by the build-tag-conditional variable `enabled`, defined in companion files (`race_on.go` / `race_off.go`) that are conditionally compiled.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/race"

func main() {
    if race.Enabled {
        fmt.Println("Race detector is active — expect slower performance")
    }
}
```

## How It Works

The package relies on two build-constrained files (not shown here) that define `enabled`:

```go
// race_on.go  (compiled when -race is set)
//go:build race
var enabled = true

// race_off.go  (compiled otherwise)
//go:build !race
var enabled = false
```

This pattern avoids `runtime` or `reflect` hacks and adds zero overhead in production builds.

## Notes

- Check `race.Enabled` at startup to gate expensive diagnostic logging or test assertions.
- Never use this to skip correctness checks — treat race-detected paths as always-possible bugs.
