Generic JSON union types for handling polymorphic JSON values that can be either a primitive type or a complex object.

## Key Components

### `StringOr[T any]`
A generic struct representing a JSON value that is either a `string` or another type `T`.

| Field | Type | Description |
|-------|------|-------------|
| `String` | `string` | Holds the string value when `IsOther` is `false` |
| `Other` | `T` | Holds the alternative value when `IsOther` is `true` |
| `IsOther` | `bool` | Discriminator flag indicating which field is active |

- **`MarshalJSON`** — marshals `Other` if `IsOther` is set, otherwise marshals `String`
- **`UnmarshalJSON`** — detects a leading `"` to distinguish a JSON string from any other JSON value

### `BoolOr[T any]`
A generic struct representing a JSON value that is either a `bool` or another type `T`.

| Field | Type | Description |
|-------|------|-------------|
| `Bool` | `bool` | Holds the boolean value when `IsOther` is `false` |
| `Other` | `T` | Holds the alternative value when `IsOther` is `true` |
| `IsOther` | `bool` | Discriminator flag indicating which field is active |

- **`MarshalJSON`** — marshals `Other` if `IsOther` is set, otherwise marshals `Bool`
- **`UnmarshalJSON`** — matches literal `true`/`false` bytes to distinguish a JSON boolean from other values

## Usage Example

```go
// StringOr: handle a field that can be a string or []string
type Config struct {
    Tags optjson.StringOr[[]string] `json:"tags"`
}

// Unmarshaling a plain string
data := []byte(`{"tags": "linux"}`)
var cfg Config
json.Unmarshal(data, &cfg)
// cfg.Tags.IsOther == false, cfg.Tags.String == "linux"

// Unmarshaling an array
data = []byte(`{"tags": ["linux", "arm64"]}`)
json.Unmarshal(data, &cfg)
// cfg.Tags.IsOther == true, cfg.Tags.Other == []string{"linux", "arm64"}

// BoolOr: handle a field that can be a bool or an object
type Rule struct {
    Enabled optjson.BoolOr[map[string]string] `json:"enabled"`
}
```
