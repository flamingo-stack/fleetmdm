Package `optjson` provides generic types for representing optional JSON values, distinguishing between a key that was omitted, explicitly set to `null`, or set to a valid value.

## Key Components

| Type | Description |
|------|-------------|
| `String` | Optional `string` value |
| `Bool` | Optional `bool` value |
| `Int` | Optional `int` value |
| `Slice[T]` | Optional slice of any type |
| `Any[T]` | Optional value of any type (generic fallback) |

Each type carries three fields:

- **`Set`** — `true` if the JSON key was present in the payload
- **`Valid`** — `true` if the value was non-null
- **`Value`** — the underlying Go value

Constructor helpers (`SetString`, `SetBool`, `SetInt`, `SetSlice`) return a fully initialized value with both `Set` and `Valid` set to `true`.

All types implement `json.Marshaler` and `json.Unmarshaler`. Marshaling emits `null` when `Valid` is `false`; unmarshaling sets `Set` regardless of whether the value is `null`.

## Usage Example

```go
type Config struct {
    Name    optjson.String   `json:"name"`
    Enabled optjson.Bool     `json:"enabled"`
    Limit   optjson.Int      `json:"limit"`
    Tags    optjson.Slice[string] `json:"tags"`
}

data := []byte(`{"name": "fleet", "enabled": null}`)

var cfg Config
_ = json.Unmarshal(data, &cfg)

cfg.Name.Set   // true  — key was present
cfg.Name.Valid // true  — value was non-null
cfg.Name.Value // "fleet"

cfg.Enabled.Set   // true  — key was present
cfg.Enabled.Valid // false — value was null

cfg.Limit.Set   // false — key was omitted entirely

// Construct a value programmatically
s := optjson.SetString("example") // {Set: true, Valid: true, Value: "example"}
```
