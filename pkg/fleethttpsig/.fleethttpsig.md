Shared HTTP request signing and verification utilities for Fleet client-server communication, built on the `httpsig-go` library.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Verifier` | `func` | Creates an `*httpsig.Verifier` configured to validate signed HTTP requests from Fleet clients |
| `Signer` | `func` | Creates an `*httpsig.Signer` to sign outbound HTTP requests to a Fleet server |
| `requiredFields` | `var` | Signed fields: `@method`, `@authority`, `@path`, `@query`, `content-digest` |
| `requiredMetadata` | `var` | Required signature metadata: `key-id`, `created`, `nonce` |

**Supported algorithms:** `ECDSA_P256_SHA256` and `ECDSA_P384_SHA384`

> `@target-uri` is intentionally excluded from signed fields to avoid issues with HTTPS forwarding and proxy environments (HTTP vs HTTPS mismatches).

## Usage Example

```go
// --- Server-side: verify incoming requests ---
verifier, err := fleethttpsig.Verifier(myKeyFetcher)
if err != nil {
    log.Fatal(err)
}

// --- Client-side: sign outgoing requests ---
// Standard ECDSA key
signer, err := fleethttpsig.Signer("key-id-001", ecPrivateKey, httpsig.Algo_ECDSA_P256_SHA256)
if err != nil {
    log.Fatal(err)
}

// TPM or hardware-backed signer (non-*ecdsa.PrivateKey)
signer, err = fleethttpsig.Signer("tpm-key-001", tpmSigner, httpsig.Algo_ECDSA_P384_SHA384)
if err != nil {
    log.Fatal(err)
}
```

The `Signer` automatically detects whether the provided `crypto.Signer` is a standard `*ecdsa.PrivateKey` or a TPM/hardware-backed signer, routing the key material accordingly.
