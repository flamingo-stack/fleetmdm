Generates patch policy queries for software version compliance checks on macOS and Windows, wrapping "exists" queries with `NOT EXISTS` and `version_compare` predicates.

## Key Components

- **`PolicyData`** — struct holding policy metadata: name, platform, description, resolution, query, exists query, and target version.
- **`GenerateQueryForManifest(p PolicyData) (string, error)`** — builds a patch policy query from an app manifest's exists query, appending the appropriate `version_compare` suffix based on platform.
- **`GenerateFromInstaller(p PolicyData, installer *fleet.SoftwareInstaller) (*PolicyData, error)`** — constructs a full `PolicyData` from a `fleet.SoftwareInstaller`, falling back to default macOS/Windows query templates when no `PatchQuery` is set.
- **`parenthesizeWhereClause(existsQuery string) string`** — wraps `WHERE` conditions containing `OR` in parentheses to ensure correct SQL precedence when the `AND version_compare(...)` suffix is appended.
- **`versionCompareColumn(platform, existsQuery string) (string, error)`** — resolves the correct version column (`bundle_short_version`, `file_version`, or `version`) based on platform and table.

## Usage Example

```go
// From a manifest exists query
data := patch_policy.PolicyData{
    Platform:    "darwin",
    ExistsQuery: "SELECT 1 FROM apps WHERE bundle_identifier = 'com.example.app'",
    Version:     "3.2.1",
}
query, err := patch_policy.GenerateQueryForManifest(data)
// query: SELECT 1 WHERE NOT EXISTS (SELECT 1 FROM apps WHERE bundle_identifier = 'com.example.app' AND version_compare(bundle_short_version, '3.2.1') < 0);

// From a software installer
policy, err := patch_policy.GenerateFromInstaller(patch_policy.PolicyData{}, installer)
```
