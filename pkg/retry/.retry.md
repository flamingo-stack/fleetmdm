Provides a configurable retry loop with support for exponential backoff, attempt limits, and error-based outcome filtering.

## Key Components

### Types

- **`ErrorOutcome`** — Integer enum controlling how `Do` reacts to a returned error:
  - `ErrorOutcomeNormalRetry` — Continue retrying as usual.
  - `ErrorOutcomeResetAttempts` — Reset the attempt counter and backoff (retry indefinitely until a condition is met).
  - `ErrorOutcomeIgnore` — Swallow the error and return `nil`.
  - `ErrorOutcomeDoNotRetry` — Return the error immediately without further retries.

### Options

| Function | Description |
|---|---|
| `WithInterval(d)` | Wait duration between retries (default: `30s`) |
| `WithBackoffMultiplier(m)` | Multiplier applied to the interval each attempt |
| `WithMaxAttempts(a)` | Maximum attempts before giving up |
| `WithErrorFilter(f)` | Maps errors to `ErrorOutcome` values before backoff/limit logic |

### Functions

- **`Do(fn, opts...)`** — Executes `fn` repeatedly until it returns `nil`, the attempt limit is reached, or an error filter returns `ErrorOutcomeDoNotRetry`.

## Usage Example

```go
err := retry.Do(
    func() error {
        return callExternalService()
    },
    retry.WithInterval(2*time.Second),
    retry.WithBackoffMultiplier(2),
    retry.WithMaxAttempts(5),
    retry.WithErrorFilter(func(err error) retry.ErrorOutcome {
        if errors.Is(err, ErrPermanent) {
            return retry.ErrorOutcomeDoNotRetry
        }
        return retry.ErrorOutcomeNormalRetry
    }),
)
```

> **Default behavior:** Retries indefinitely every 30 seconds with no backoff until `fn` succeeds.
