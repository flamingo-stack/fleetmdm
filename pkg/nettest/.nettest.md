Provides utilities for running Go tests that require public network access, including serial test coordination via file locking and automatic retry logic for transient network errors.

## Key Components

| Export | Type | Description |
|---|---|---|
| `Run` | Function | Gates test execution behind the `NETWORK_TEST` env var; optionally serialises tests using a lock file (`TEST_LOCK_FILE_PATH`) |
| `Retryable` | Function | Classifies a network error as retriable by inspecting `net.Error` fields and common error substrings (timeouts, TLS handshake failures, unexpected EOF, connection resets, etc.) |
| `RunWithNetRetry` | Function | Wraps a function and retries it every 5 seconds when `Retryable` returns `true` |
| `lock` / `unlock` | Internal | File-system mutex using `O_EXCL` creation to serialise parallel test processes |

## Usage Example

```go
func TestFetchFromInternet(t *testing.T) {
    // Skip unless NETWORK_TEST=1; serialise if TEST_LOCK_FILE_PATH is set
    nettest.Run(t)

    err := nettest.RunWithNetRetry(t, func() error {
        resp, err := http.Get("https://example.com")
        if err != nil {
            return err
        }
        defer resp.Body.Close()
        return nil
    })
    require.NoError(t, err)
}
```

## Environment Variables

| Variable | Purpose |
|---|---|
| `NETWORK_TEST` | Must be set to any non-empty value (e.g. `1`) to enable network tests |
| `TEST_LOCK_FILE_PATH` | Path to a lock file used to prevent concurrent network tests on the same host |
