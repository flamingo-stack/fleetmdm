Utility package providing string splitting, trimming, and parsing helpers for comma-separated and delimited string inputs.

## Key Components

| Function | Signature | Description |
|---|---|---|
| `SplitAndTrim` | `(s, delimiter string, removeEmpty bool) []string` | Splits a string by a delimiter, trims whitespace from each part, and optionally removes empty entries |
| `ParseUintList` | `(s string) []uint` | Parses a comma-separated string of unsigned integers; silently skips invalid values and returns `nil` for empty input |
| `ParseStringList` | `(s string) []string` | Parses a comma-separated string into a trimmed, non-empty string slice; returns `nil` for empty input |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/pkg/str"
)

func main() {
    // Split and trim with empty removal
    parts := str.SplitAndTrim("foo , bar ,  , baz", ",", true)
    fmt.Println(parts) // [foo bar baz]

    // Parse a list of unsigned integers, bad values silently dropped
    ids := str.ParseUintList("1, 2, abc, 3")
    fmt.Println(ids) // [1 2 3]

    // Parse a comma-separated string list
    tags := str.ParseStringList("alpha, beta,  , gamma")
    fmt.Println(tags) // [alpha beta gamma]

    // Empty input returns nil
    fmt.Println(str.ParseUintList(""))    // <nil>
    fmt.Println(str.ParseStringList("")) // <nil>
}
```

> **Note:** `ParseUintList` silently skips unparseable tokens rather than returning an error, making it suitable for best-effort parsing of user-supplied or environment-provided configuration values.
