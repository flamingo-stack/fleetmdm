A test helper that simulates a Windows MDM client for integration testing of Fleet's Windows MDM enrollment and management protocols.

## Key Components

- **`TestWindowsMDMClient`** — Core struct representing a simulated Windows MDM device, tracking device/hardware IDs, enrollment type, session state, queued command responses, and JWT/credential state.
- **`NewTestMDMClientWindowsProgramatic`** / **`NewTestMDMClientWindowsAutomatic`** / **`NewTestMDMClientWindowsEmptyBinarySecurityToken`** — Constructors for different enrollment scenarios (programmatic, automatic, and error-case empty token).
- **`StartManagementSession`** — Initiates a SyncML management session by sending device info (`DevInfo`) and alert codes to the Fleet MDM endpoint.
- **`SendResponse`** — Sends queued command responses back to the server in a follow-up SyncML message, honoring the MS-MDM spec rule against sending header-only messages.
- **`AppendResponse`** — Queues a `SyncMLCmd` response to be sent on the next `SendResponse` call.
- **`doManagementReq`** — Internal method handling the full request/response cycle including re-key detection and MD5 challenge/response authentication (`isRekeyRequest`, `shouldAuth`, `getCredHDR`, `hashedCredentials`).

## Usage Example

```go
// Create a programmatic enrollment client
client := mdmtest.NewTestMDMClientWindowsProgramatic(
    "https://fleet.example.com",
    "orbit-node-key-abc123",
    mdmtest.TestWindowsMDMClientDebug(),
)

// Start a management session and receive server commands
cmds, err := client.StartManagementSession()
if err != nil {
    log.Fatal(err)
}

// Queue a result status for a received command
for cmdID, op := range cmds {
    client.AppendResponse(fleet.SyncMLCmd{
        XMLName: xml.Name{Local: fleet.CmdStatus},
        CmdID:   fleet.CmdID{Value: "10"},
        MsgRef:  ptr.String("1"),
        CmdRef:  ptr.String(cmdID),
        Cmd:     ptr.String(op.Verb),
        Data:    ptr.String("200"),
    })
}

// Send responses back to the server
_, err = client.SendResponse()
```
