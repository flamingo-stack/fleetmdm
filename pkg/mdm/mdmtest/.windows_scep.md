Provides test utilities for simulating Windows MDM SCEP (Simple Certificate Enrollment Protocol) exchanges, including CSP command extraction, certificate enrollment, and response handling for the `TestWindowsMDMClient`.

## Key Components

### Types

- **`SCEPCommand`** — Represents a parsed SCEP `CertificateInstall` CSP command, including enrollment URL, challenge, subject name, key length, and associated SyncML command IDs.
- **`SCEPResult`** — Emitted on the result channel when an async SCEP exchange completes, carrying the issued certificate or error.
- **`scepCSPPath`** — Internal struct holding the parsed `UniqueID` and field name from a SCEP LocURI.

### Methods on `TestWindowsMDMClient`

- **`ExtractSCEPCommands`** — Parses a SyncML commands map, groups SCEP CSP nodes by `UniqueID`, and returns `complete` CSPs (ready for enrollment) and `incomplete` CSPs (missing required fields).
- **`AppendSCEPInstallResponses`** — ACKs complete SCEP CSPs, launches SCEP exchanges concurrently, and returns handled CmdIDs plus a result channel.
- **`RunSCEP`** — Executes a single synchronous SCEP exchange against the server URL from a given `SCEPCommand`.

### Helper Functions

- **`scepInstallPath`** — Parses `./Device/Vendor/MSFT/ClientCertificateInstall/SCEP/<ID>/Install/<Field>` LocURIs.
- **`parseSCEPSubject`** — Converts a `CN=foo,OU=bar` subject string into a `pkix.Name`.
- **`missingSCEPFields`** — Returns a descriptive string of missing required CSP fields.
- **`newStatusCmd`** — Constructs a SyncML `<Status>` command for ACKing received commands.

## Usage Example

```go
// Extract and process SCEP commands from a SyncML message
complete, incomplete := client.ExtractSCEPCommands(cmds)
if len(incomplete) > 0 {
    t.Errorf("incomplete SCEP CSPs: %v", incomplete)
}

// Append ACKs and kick off async SCEP exchanges
handled, done, hasWork := client.AppendSCEPInstallResponses(ctx, cmds, msgID, logger)
if hasWork {
    for result := range done {
        if result.Err != nil {
            t.Errorf("SCEP failed for %s: %v", result.UniqueID, result.Err)
        }
    }
}

// Or drive a single exchange synchronously
cert, err := client.RunSCEP(ctx, scepCmd, logger)
```
