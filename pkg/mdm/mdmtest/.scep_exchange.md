Implements a reusable SCEP enrollment exchange for test MDM clients, handling the full CSR-to-certificate flow against a SCEP server for both Apple and Windows test paths.

## Key Components

### Types

- **`scepExchangeRequest`** — Input descriptor for a SCEP exchange, carrying the server URL, certificate subject, challenge password, and RSA key size (defaults to 2048).

### Functions

- **`performSCEPExchange`** — Executes the complete SCEP enrollment sequence: fetches the CA certificate, generates an RSA key pair, builds and submits a CSR wrapped in a `PKCSReq` message, then decrypts and returns the issued device certificate alongside its private key. TLS verification is intentionally skipped for test use.

- **`selfSignedSignerCert`** — Constructs a short-lived (24-hour) self-signed certificate over the provided RSA key, used as the SCEP envelope signer per [RFC 8894 §2.4](https://www.rfc-editor.org/rfc/rfc8894#section-2.4) for initial enrollment where no prior cert exists.

## Usage Example

```go
ctx := context.Background()
logger := slog.Default()

cert, privKey, err := performSCEPExchange(ctx, scepExchangeRequest{
    URL:       "http://mdm.example.local/scep",
    Challenge: "mysecret",
    Subject: pkix.Name{
        CommonName:   "TestDevice-001",
        Organization: []string{"Test Org"},
    },
    KeyBits: 2048,
}, logger)
if err != nil {
    log.Fatal(err)
}

// cert and privKey are now ready for MDM enrollment
_ = cert
_ = privKey
```

## Notes

- **Test-only**: TLS verification is skipped via `scepclient.Insecure()`; do not use in production.
- The signer certificate is intentionally ephemeral (24-hour validity) and self-signed, satisfying the RFC 8894 requirement for first-time enrollees that lack an existing certificate.
