Simulates a macOS MDM client for testing Apple MDM enrollment flows, including DEP, OTA, Desktop manual, direct, and Account Driven User Enrollment scenarios.

## Key Components

### Types
- **`TestAppleMDMClient`** — Core struct simulating a macOS device with fields for UUID, serial number, SCEP/ACME credentials, and enrollment configuration
- **`AppleEnrollInfo`** — Holds MDM enrollment metadata: SCEP challenge/URL, MDM URL, ACME URL, and raw profile bytes
- **`TestMDMAppleClientOption`** — Functional option type for configuring `TestAppleMDMClient`

### Constructors
| Function | Description |
|---|---|
| `NewTestMDMClientAppleDesktopManual` | Simulates Fleet Desktop manual enrollment |
| `NewTestMDMClientAppleDEP` | Simulates DEP (Device Enrollment Program) flow |
| `NewTestMDMClientAppleDEPFromDevice` | DEP flow with a specific serial number and model |
| `NewTestMDMClientAppleDirect` | Direct enrollment with pre-supplied `AppleEnrollInfo` |
| `NewTestMDMClientAppleOTA` | Simulates Over-The-Air (OTA) enrollment |
| `NewTestMDMClientAppleAccountDrivenUserEnrollment` | Simulates Account Driven User Enrollment (MDM-BYOD) |

### Option Functions
- `TestMDMAppleClientDebug()` — Enables request/response debug logging
- `WithEnrollmentProfileFromDEPUsingPost()` — Forces POST for DEP profile fetch
- `WithOTAIdpUUID(idpUUID)` — Associates an IdP account UUID for OTA SSO flows
- `WithACMECerts(cert, key)` — Supplies ACME CA certificate and key for hardware-attested enrollment
- `WithLegacyIDeviceEnrollRef(ref)` — Appends a legacy enroll reference to the MDM URL (for iOS/iPadOS SCEP renewal tests)
- `WithSkipParseEnrollProf(skip)` — Stores raw profile bytes without parsing

## Usage Example

```go
// Simulate a DEP-enrolled Mac
client := NewTestMDMClientAppleDEP(
    "https://fleet.example.com",
    "dep-token-abc",
    TestMDMAppleClientDebug(),
)

// Simulate an OTA-enrolled device with IdP
otaClient := NewTestMDMClientAppleOTA(
    "https://fleet.example.com",
    "enroll-secret-xyz",
    "MacBookPro16,1",
    WithOTAIdpUUID("idp-uuid-123"),
)

// Simulate Account Driven User Enrollment (BYOD)
byodClient := NewTestMDMClientAppleAccountDrivenUserEnrollment(
    "https://fleet.example.com",
    "MacBookPro16,1",
    "bearer-token-abc",
)
```
