Determines whether OTA (Over-The-Air) MDM enrollment requires Identity Provider (IdP) authentication before proceeding, based on the enroll secret and team configuration.

## Key Components

### `RequiresEnrollOTAAuthentication`

```text
func RequiresEnrollOTAAuthentication(
    ctx context.Context,
    ds fleet.AndroidDatastore,
    enrollSecret string,
    noTeamIdPEnabled bool,
) (bool, error)
```

Evaluates three scenarios to decide if IdP authentication is required:

1. **Invalid enroll secret** — checks if any team has IdP enabled for Setup Experience; returns `true` if at least one does (authentication enforced before profile installation fails)
2. **"No team" enrollment** — returns the value of `noTeamIdPEnabled`
3. **Team-specific enrollment** — returns the team's `MDM.MacOSSetup.EnableEndUserAuthentication` setting

> **Note:** Accepts `fleet.AndroidDatastore` so the function can be shared with the Android package until [fleet#31218](https://github.com/fleetdm/fleet/issues/31218) is resolved.

## Usage Example

```go
requiresAuth, err := mdm.RequiresEnrollOTAAuthentication(
    ctx,
    ds,
    enrollSecret,
    noTeamIdPEnabled,
)
if err != nil {
    return ctxerr.Wrap(ctx, err, "check OTA auth requirement")
}

if requiresAuth {
    // redirect to IdP for authentication before continuing enrollment
}
```
