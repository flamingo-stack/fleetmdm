Windows-specific implementation of the `secure` package that delegates directory creation and file operations directly to the standard `os` library.

## Key Components

| Function | Signature | Description |
|----------|-----------|-------------|
| `MkdirAll` | `(path string, perm os.FileMode) error` | Creates a directory tree using `os.MkdirAll` |
| `OpenFile` | `(name string, flag int, perm os.FileMode) (*os.File, error)` | Opens or creates a file using `os.OpenFile` |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/secure"

// Create a nested directory
err := secure.MkdirAll("C:\\fleet\\data\\logs", 0755)
if err != nil {
    log.Fatal(err)
}

// Open or create a file
f, err := secure.OpenFile("C:\\fleet\\data\\config.json", os.O_CREATE|os.O_WRONLY, 0644)
if err != nil {
    log.Fatal(err)
}
defer f.Close()
```

## Notes

- This file is **build-constrained** to Windows (`//go:build windows`), meaning it only compiles on Windows targets.
- On Windows, POSIX-style `os.FileMode` permission bits have limited effect; the delegation to `os.MkdirAll` and `os.OpenFile` is a pass-through without additional security hardening.
- Companion implementations for other platforms (e.g., Linux/macOS) likely apply stricter permission enforcement — see the [`secure` package](https://github.com/flamingo-stack/fleetmdm/blob/main/secure/) for platform-specific variants.
