Permission-aware file system utilities for Unix-like systems (non-Windows) that enforce strict directory and file mode validation before creating or opening paths.

## Key Components

| Function | Description |
|---|---|
| `isMorePermissive` | Compares two `os.FileMode` values; returns `true` if `newMode` grants broader group or world access than `currentMode` |
| `checkPermPath` | Recursively validates that an existing directory's permissions are not more permissive than the expected `perm`; mirrors `os.MkdirAll` path-walking logic |
| `checkPermFile` | Validates file permissions, attempting `chmod` to correct mismatches, then delegates to `checkPermPath` for the parent directory |
| `MkdirAll` | Drop-in replacement for `os.MkdirAll` that rejects paths where existing directories exceed the requested permission level |
| `OpenFile` | Drop-in replacement for `os.OpenFile` that validates/corrects file permissions before opening |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/secure"

// Create a directory tree, ensuring no existing component is
// more permissive than 0750.
if err := secure.MkdirAll("/var/lib/myapp/data", 0750); err != nil {
    log.Fatalf("insecure path: %v", err)
}

// Open (or create) a config file, enforcing 0640 on the file
// and its parent directory.
f, err := secure.OpenFile("/var/lib/myapp/config.json", os.O_RDWR|os.O_CREATE, 0640)
if err != nil {
    log.Fatalf("permission check failed: %v", err)
}
defer f.Close()
```

> **Note:** This file is excluded from Windows builds via the `//go:build !windows` constraint. Group (`070`) and world (`07`) permission bits are the only axes checked — owner bits are intentionally ignored in the permissiveness comparison.
