Extracts metadata from RPM package files, computing a SHA-256 hash and parsing package headers in a single streaming pass.

## Key Components

- **`ExtractRPMMetadata(r io.Reader) (*InstallerMetadata, error)`** — Reads an RPM stream, parses package headers using `cavaliergopher/rpm`, drains the remaining payload to ensure the full-file SHA-256 hash is correct, and returns an `InstallerMetadata` struct.

## Usage Example

```go
f, err := os.Open("package.rpm")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

meta, err := file.ExtractRPMMetadata(f)
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Name:    %s\n", meta.Name)
fmt.Printf("Version: %s\n", meta.Version)
fmt.Printf("SHA-256: %x\n", meta.SHASum)
```

## Notes

- Uses `io.TeeReader` to hash the stream while reading, avoiding a second pass over the file.
- The payload after the headers is discarded via `io.Copy(io.Discard, r)` solely to ensure the hash covers the entire file contents.
- `PackageIDs` is set to `[]string{pkg.Name()}`, matching the RPM package name.
