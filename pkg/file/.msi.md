Parses Windows Installer (`.msi`) files to extract software metadata by reading and decoding the internal MSI database tables stored in the Compound Document (OLE) format.

## Key Components

| Symbol | Description |
|---|---|
| `ExtractMSIMetadata` | Main entry point — reads an MSI file, computes its SHA-256 hash, and returns `InstallerMetadata` with name, version, product code, upgrade code, and checksum |
| `decodeStrings` | Decodes the `_StringPool` and `_StringData` streams into an indexed string table, handling oversized string entries |
| `decodePropertyTableColumns` | Parses the `_Columns` stream to locate and describe the `Property` table schema |
| `decodePropertyTable` | Reads the `Property` stream using the decoded schema to produce a `map[string]string` of key-value installer properties |
| `msiDecodeName` / `msiDecodeRune` | Decodes MSI-encoded stream names (encoded Unicode rune sequences used internally by the OLE compound document) |
| `msiColumn.Type()` | Extracts the column type from raw attribute bits |
| `msiType` constants | Typed constants for MSI column types: `msiLong`, `msiShort`, `msiBinary`, `msiString`, `msiStringLocalized` |

## Usage Example

```go
f, _ := os.Open("installer.msi")
tfr, _ := fleet.NewTempFileReader(f)

meta, err := file.ExtractMSIMetadata(tfr)
if err != nil {
    log.Fatal(err)
}

fmt.Println(meta.Name)        // e.g. "My Application"
fmt.Println(meta.Version)     // e.g. "1.2.3"
fmt.Println(meta.PackageIDs)  // e.g. ["{GUID}"]
fmt.Println(meta.UpgradeCode) // e.g. "{GUID}"
fmt.Printf("%x\n", meta.SHASum)
```

## Notes

- Reads four internal MSI streams: `_StringData`, `_StringPool`, `_Columns`, and `Property`
- Product name is decoded from Windows-1252 encoding via `charmap.Windows1252`
- Property keys extracted: `ProductName`, `ProductVersion`, `ProductCode`, `UpgradeCode`
- Reference: [MSI Property Reference](https://learn.microsoft.com/en-us/windows/win32/msi/property-reference#product-information-properties)
