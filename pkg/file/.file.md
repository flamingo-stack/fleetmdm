Provides utilities for installer metadata extraction, file operations, archive handling, and checksum computation used throughout the Fleet MDM agent and server.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ErrUnsupportedType` | `error` | Returned when magic bytes don't match a known installer format |
| `ErrInvalidTarball` | `error` | Returned when a `.tar.gz` archive fails validation |
| `InstallerMetadata` | `struct` | Holds name, version, bundle ID, SHA256, extension, package IDs, and upgrade code extracted from an installer |
| `ExtractInstallerMetadata` | `func` | Detects installer type via magic bytes and dispatches to the appropriate extractor |
| `typeFromBytes` | `func` | Internal magic-byte sniffer supporting `pkg`, `deb`, `rpm`, `msi`, `tar.gz`, `ipa`, and `exe` |
| `Copy` / `CopyWithPerms` | `func` | Secure file copy with explicit or inherited permissions |
| `Exists` | `func` | Reports whether a path exists and is a regular file |
| `Dos2UnixNewlines` | `func` | Converts `\r\n` line endings to `\n` |
| `ExtractFilenameFromURLPath` | `func` | Parses a URL path and returns a filename, appending a default extension if needed |
| `ExtractTarGz` | `func` | Extracts a `.tar.gz` archive with zip-slip and zip-bomb protections |
| `SHA256FromTempFileReader` | `func` | Computes a hex-encoded SHA-256 hash from a `TempFileReader` and rewinds it |

## Usage Example

```go
// Extract metadata from an uploaded installer
tfr, _ := fleet.NewTempFileReader(uploadedBytes)
meta, err := file.ExtractInstallerMetadata(tfr)
if errors.Is(err, file.ErrUnsupportedType) {
    log.Fatal("unsupported installer format")
}
fmt.Printf("Name: %s, Version: %s, Ext: %s\n", meta.Name, meta.Version, meta.Extension)

// Compute SHA-256 without consuming the reader
hash, err := file.SHA256FromTempFileReader(tfr)

// Extract a tar.gz archive with a 500 MB per-file limit
err = file.ExtractTarGz("/tmp/agent.tar.gz", "/opt/agent", 500<<20, logger)

// Copy a file preserving source permissions
err = file.CopyWithPerms("/src/binary", "/dst/binary")
```
