Provides macOS filename validation utilities by defining invalid characters and checking filenames for compliance.

## Key Components

- **`InvalidMacOSChars`** — A slice of runes representing characters that are forbidden in macOS filenames: `:`, `\`, `*`, `?`, `"`, `<`, `>`, `|`, and the null character (`0`).
- **`IsValidMacOSName(fileName string) bool`** — Returns `true` if the given filename is non-empty and contains none of the characters in `InvalidMacOSChars`.

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/pkg/file"
)

func main() {
    fmt.Println(file.IsValidMacOSName("report.pdf"))      // true
    fmt.Println(file.IsValidMacOSName("bad:name.txt"))    // false
    fmt.Println(file.IsValidMacOSName(""))                // false
}
```

> **Note:** The `InvalidMacOSChars` slice is exported so callers can reference or extend the character set for custom validation logic without duplicating the list.
