Parses and extracts metadata from macOS XAR (eXtensible ARchive) format `.pkg` files, including name, version, bundle identifier, and package IDs from embedded `Distribution` and `PackageInfo` XML files.

## Key Components

- **`ExtractXARMetadata`** — Primary entry point. Reads a XAR file, locates the `Distribution` or `PackageInfo` XML, and returns an `InstallerMetadata` struct with name, version, bundle identifier, package IDs, and SHA256 checksum.
- **`XARHasDistribution`** — Checks whether a XAR archive contains a `Distribution` file without fully parsing it.
- **`parseDistributionFile`** / **`parsePackageInfoFile`** — Unmarshal raw XML bytes into structured metadata.
- **`getDistributionInfo`** — Extracts name, bundle identifier, version, and package IDs from a parsed `distributionXML`. Handles edge cases like known bad names (`knownBadNames`), vendor-specific ID translations (`idTranslations`), and Microsoft AutoUpdate bundle ID filtering.
- **`readXARFileHeader`** — Decodes the 28-byte binary XAR header.
- **`decodeXARTOCData`** — Decompresses and XML-decodes the zlib-compressed Table of Contents from the XAR archive.
- **`readCompressedFile`** — Reads a file entry from the XAR heap, supporting `x-gzip` (zlib), `x-bzip2`, and uncompressed encodings.
- **Error sentinels** — `ErrInvalidType` and `ErrNotSigned` for structured error handling.

## Usage Example

```go
// Open a .pkg file and extract metadata
f, err := os.Open("MyApp.pkg")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

tfr, err := fleet.NewTempFileReader(f, tempDir)
if err != nil {
    log.Fatal(err)
}

meta, err := file.ExtractXARMetadata(tfr)
if err != nil {
    log.Fatal(err)
}

fmt.Println(meta.Name)             // e.g. "MyApp"
fmt.Println(meta.Version)          // e.g. "1.2.3"
fmt.Println(meta.BundleIdentifier) // e.g. "com.example.MyApp"
fmt.Printf("%x\n", meta.SHASum)   // SHA256 of the .pkg file
```
