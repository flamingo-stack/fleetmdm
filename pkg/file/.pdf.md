Validates that an `io.Reader` contains a PDF file by checking its magic bytes signature (`%PDF`, `0x25 0x50 0x44 0x46`).

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `pdfMagic` | `[]byte` | PDF [file signature](https://en.wikipedia.org/wiki/List_of_file_signatures) — `%PDF` (`0x25 0x50 0x44 0x46`) |
| `CheckPDF` | `func(io.Reader) error` | Reads the first 4 bytes and returns `ErrInvalidType` if they don't match the PDF magic bytes |

## Usage Example

```go
f, err := os.Open("document.pdf")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

if err := file.CheckPDF(f); err != nil {
    // returns ErrInvalidType if not a valid PDF
    log.Fatalf("not a valid PDF: %v", err)
}
```

## Error Handling

| Condition | Error Returned |
|-----------|----------------|
| File is shorter than 4 bytes (`io.EOF` / `io.ErrUnexpectedEOF`) | `ErrInvalidType` |
| Magic bytes don't match `%PDF` | `ErrInvalidType` |
| Underlying read failure | Wrapped `fmt.Errorf("reading magic bytes: %w", err)` |

## Notes

- Only the **first 4 bytes** of the reader are consumed, making it safe to use with an `io.MultiReader` or after resetting a buffer if the caller needs to re-read the full content.
- `ErrInvalidType` is a package-level sentinel error defined elsewhere in the `file` package.
