Parses Windows Portable Executable (`.exe`) files to extract installer metadata including product name, version, and SHA-256 hash.

## Key Components

### `ExtractPEMetadata(tfr *fleet.TempFileReader) (*InstallerMetadata, error)`
Main extraction function that:
1. Computes a SHA-256 hash of the binary
2. Parses the PE file using the `saferwall/pe` library (resource directory only — import/export/debug directories are omitted for performance)
3. Reads `ProductName`, `ProductVersion`, and `FileVersion` from version resources
4. Handles self-extracting archive wrappers (7-Zip, InstallAnywhere) by falling back to the wrapper's own metadata only when no other product name is found
5. Applies special-case name transformations via `applySpecialCases`

### `exeSpecialCases`
A map of product-name-keyed transform functions applied after standard extraction. Currently handles **Notion**, which appends the version to the product name (`Notion 3.11.1`) to match how the installer registers the app on the host.

### `applySpecialCases(meta *InstallerMetadata, resources []map[string]string) *InstallerMetadata`
Looks up the extracted product name in `exeSpecialCases` and applies the transform if one exists; otherwise returns metadata unchanged.

## Usage Example

```go
tfr, err := fleet.NewTempFileReader(exeBytes, tempDir)
if err != nil {
    log.Fatal(err)
}
defer tfr.Close()

meta, err := file.ExtractPEMetadata(tfr)
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Name:    %s\n", meta.Name)
fmt.Printf("Version: %s\n", meta.Version)
fmt.Printf("SHA256:  %x\n", meta.SHASum)
```

> **Note:** Adding support for a new app with non-standard install naming requires adding an entry to `exeSpecialCases`. See [fleet#20440](https://github.com/fleetdm/fleet/issues/20440#issuecomment-2260500661) for context.
