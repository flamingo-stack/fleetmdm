Provides embedded shell and PowerShell scripts for installing, removing, and uninstalling software packages across multiple formats (MSI, DEB, RPM, PKG, EXE), along with utilities for package identifier validation and fleetd detection.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `IsFleetdPkg` | `func` | Checks if any package ID has the `com.fleetdm.orbit` prefix |
| `GetInstallScript` | `func` | Returns the embedded install script for `msi`, `deb`, `rpm`, or `pkg` |
| `GetRemoveScript` | `func` | Returns the embedded remove script for `msi`, `deb`, `rpm`, `pkg`, or `exe` |
| `GetUninstallScript` | `func` | Returns the embedded uninstall script for `msi`, `deb`, `rpm`, or `pkg` |
| `ValidatePackageIdentifiers` | `func` | Validates that package IDs and upgrade codes contain no shell metacharacters |
| `PackageIDRegex` | `var` | Regex matching `$PACKAGE_ID` / `${PACKAGE_ID}` interpolation placeholders |
| `UpgradeCodeRegex` | `var` | Regex matching `$UPGRADE_CODE` / `${UPGRADE_CODE}` interpolation placeholders |
| `InstallPkgFleetdScript` | `var` | Exported embedded script for installing fleetd (orbit) PKG packages |
| `UninstallMsiWithUpgradeCodeScript` | `var` | Exported embedded script for MSI uninstall via upgrade code |

## Usage Example

```go
package main

import (
    "fmt"
    "pkg/file"
)

func main() {
    // Detect fleetd packages
    ids := []string{"com.fleetdm.orbit.desktop", "com.example.app"}
    if file.IsFleetdPkg(ids) {
        fmt.Println("fleetd package detected")
    }

    // Validate identifiers before interpolation
    if err := file.ValidatePackageIdentifiers(ids, ""); err != nil {
        fmt.Println("invalid identifier:", err)
    }

    // Retrieve install/remove/uninstall scripts by extension
    installScript  := file.GetInstallScript("deb")
    removeScript   := file.GetRemoveScript("msi")
    uninstallScript := file.GetUninstallScript("rpm")

    fmt.Println(installScript, removeScript, uninstallScript)
}
```

> **Note:** `ValidatePackageIdentifiers` rejects characters such as `'`, `"`, `` ` ``, `$`, `\`, `|`, `;`, `&`, `>`, `<`, `!`, and newlines to prevent shell injection when IDs are interpolated into scripts.
