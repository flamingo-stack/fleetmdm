Parses Debian `.deb` package files to extract installer metadata including package name, version, and SHA-256 checksum.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ExtractDebMetadata` | `func(io.Reader) (*InstallerMetadata, error)` | Entry point that reads a `.deb` archive, locates the `control.tar.*` member, and returns name, version, package IDs, and SHA-256 hash |
| `parseControl` | `func(io.Reader, string) (string, string, error)` | Internal helper that decompresses a `control.tar.*` stream (gz, bz2, xz, zst, or uncompressed), locates the `control` file within, and scans it for `Package` and `Version` fields |

**Supported compression formats** for `control.tar.*`: `.gz`, `.bz2`, `.xz`, `.zst`, and uncompressed.

## Usage Example

```go
package main

import (
    "fmt"
    "os"

    "github.com/flamingo-stack/fleetmdm/pkg/file"
)

func main() {
    f, err := os.Open("example.deb")
    if err != nil {
        panic(err)
    }
    defer f.Close()

    meta, err := file.ExtractDebMetadata(f)
    if err != nil {
        panic(err)
    }

    fmt.Printf("Name:    %s\n", meta.Name)
    fmt.Printf("Version: %s\n", meta.Version)
    fmt.Printf("SHA256:  %x\n", meta.SHASum)
}
```

> **Note:** The SHA-256 hash is computed over the **entire** `.deb` file regardless of whether a `control.tar.*` entry is found, ensuring a consistent checksum for all code paths.
