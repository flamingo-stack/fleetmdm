Validates a `.tar.gz` archive by decompressing and iterating through its tar entries, then returns minimal `InstallerMetadata` containing only the SHA-256 checksum.

## Key Components

- **`ValidateTarball(r io.Reader) (*InstallerMetadata, error)`** — Reads a gzip-compressed tar stream, validates structural integrity of both layers, computes a SHA-256 hash of the full content, and returns an `InstallerMetadata` with only `SHASum` populated. Name and version fields are left empty for the caller to resolve via fallback logic.

## Usage Example

```go
f, err := os.Open("package.tar.gz")
if err != nil {
    log.Fatal(err)
}
defer f.Close()

meta, err := file.ValidateTarball(f)
if err != nil {
    log.Fatalf("invalid tarball: %v", err)
}

fmt.Printf("SHA-256: %x\n", meta.SHASum)
// Caller is responsible for populating meta.Name and meta.Version
```

## Notes

- Uses `io.TeeReader` to hash bytes as they are read, avoiding a second pass over the stream.
- After the tar walk completes, any remaining buffered content is drained via `io.Copy(io.Discard, r)` to ensure the hash covers the full file.
- Returns `InstallerMetadata` with only `SHASum` set; name/version resolution is intentionally delegated to the caller.
