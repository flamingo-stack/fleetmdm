Extracts metadata from iOS IPA installer files by parsing the embedded `Info.plist` and computing a SHA-256 checksum.

## Key Components

### `ExtractIPAMetadata(tfr *fleet.TempFileReader) (*InstallerMetadata, error)`

The sole exported function. It:

1. Streams the IPA through a `sha256.Hash` to compute a checksum
2. Opens the IPA as a ZIP archive and scans for an `Info.plist` file
3. Unmarshals the plist to extract `CFBundleIdentifier`, `CFBundleName`, and `CFBundleShortVersionString`
4. Returns an `InstallerMetadata` struct populated with the extracted values, or an error if the bundle identifier is missing

**Returns `*InstallerMetadata` containing:**

| Field | Source |
|---|---|
| `BundleIdentifier` | `CFBundleIdentifier` |
| `Name` | `CFBundleName` |
| `Version` | `CFBundleShortVersionString` |
| `SHASum` | SHA-256 of the full IPA file |
| `PackageIDs` | `[]string{BundleIdentifier}` |

## Usage Example

```go
f, _ := os.Open("MyApp.ipa")
tfr, _ := fleet.NewTempFileReader(f, nil)

metadata, err := file.ExtractIPAMetadata(tfr)
if err != nil {
    log.Fatalf("failed to extract IPA metadata: %v", err)
}

fmt.Printf("Bundle ID: %s\n", metadata.BundleIdentifier)
fmt.Printf("Name:      %s\n", metadata.Name)
fmt.Printf("Version:   %s\n", metadata.Version)
fmt.Printf("SHA-256:   %x\n", metadata.SHASum)
```

## Notes

- The function calls `tfr.Rewind()` after hashing so the same reader can be repositioned for ZIP parsing via the file path (`tfr.Name()`)
- Returns an error if no `CFBundleIdentifier` is found, as it is required for Fleet's software inventory
