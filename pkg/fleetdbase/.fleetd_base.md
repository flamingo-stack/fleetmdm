Fetches and parses release metadata for the `fleetd` base installer from `downloads.fleetdm.com`, with support for a dev-mode URL override.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Metadata` | struct | JSON-mapped response containing download URLs and SHA256 checksums for MSI/PKG installers, the manifest plist URL, and the release version |
| `getBaseURL()` | func (internal) | Returns the base download URL, preferring `FLEET_DEV_DOWNLOAD_FLEETDM_URL` env var when set |
| `GetMetadata()` | func | Fetches `<baseURL>/stable/meta.json` and decodes it into a `*Metadata` struct |
| `GetPKGManifestURL()` | func | Returns the stable PKG manifest plist URL without making a network request |

## Usage Example

```go
meta, err := fleetdbase.GetMetadata()
if err != nil {
    log.Fatalf("failed to get fleetd metadata: %v", err)
}

fmt.Println("Version:   ", meta.Version)
fmt.Println("MSI URL:   ", meta.MSIURL)
fmt.Println("MSI SHA256:", meta.MSISha256)
fmt.Println("PKG URL:   ", meta.PKGURL)
fmt.Println("PKG SHA256:", meta.PKGSha256)

// Get the macOS PKG manifest URL directly (no HTTP call)
manifestURL := fleetdbase.GetPKGManifestURL()
fmt.Println("Manifest: ", manifestURL)
```

> **Dev override:** Set `FLEET_DEV_DOWNLOAD_FLEETDM_URL` to redirect all requests to a local or staging server without modifying code.
