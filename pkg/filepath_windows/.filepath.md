Windows path parsing utilities ported from the Go standard library (`path/filepath`) to enable validation of Windows-style paths from code running on Unix systems.

## Key Components

| Function | Description |
|---|---|
| `IsAbs(path string) bool` | Reports whether a Windows path is absolute (exported) |
| `volumeNameLen(path string) int` | Returns the length of the leading volume name (drive letter, UNC, device paths) |
| `isSlash(c uint8) bool` | Checks if a byte is a path separator (`\` or `/`) |
| `toUpper(c byte) byte` | ASCII uppercase conversion for case-insensitive comparisons |
| `pathHasPrefixFold(s, prefix string) bool` | Case-insensitive, separator-agnostic prefix matching |
| `uncLen(path string, prefixLen int) int` | Computes the volume prefix length for UNC paths |
| `cutPath(path string)` | Splits a path string at the first separator |

## Supported Path Formats

The package handles all major Windows path formats:

- **Drive-letter paths** — `C:\foo\bar`
- **UNC paths** — `\\host\share\path`
- **Local Device paths** — `\\.\device\path`
- **Root Local Device paths** — `\\?\C:\path` and `\??\C:\path`
- **DOS Device UNC paths** — `\\.\UNC\host\share`

## Usage Example

```go
import filepath_windows "github.com/flamingo-stack/fleetmdm/pkg/filepath_windows"

func validateWindowsPath(path string) {
    if filepath_windows.IsAbs(path) {
        fmt.Println("Path is absolute:", path)
    } else {
        fmt.Println("Path is relative:", path)
    }
}

// Examples:
// IsAbs(`C:\Users\foo`)     → true
// IsAbs(`\\server\share`)   → true
// IsAbs(`relative\path`)    → false
// IsAbs(`\no-drive-letter`) → false
```

> **Note:** This package is a verbatim copy of [`path/filepath/path_windows.go`](https://github.com/golang/go/blob/master/src/path/filepath/path_windows.go) from the Go standard library, vendored to support cross-platform Windows path validation without build constraints.
