Opens a URL in the default web browser on macOS by invoking the native `open` system command.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `browser` | `func(url string) error` | Executes the macOS `open` command to launch a URL in the default browser |

## Usage Example

```go
// Called internally by the open package when targeting darwin
err := browser("https://example.com")
if err != nil {
    log.Fatal("failed to open browser:", err)
}
```

## Notes

- This file is **build-constrained to macOS** (`darwin`) via its filename suffix (`_darwin.go`)
- Delegates directly to the macOS [`open`](https://ss64.com/osx/open.html) CLI utility — no external dependencies required
- Part of a platform-specific implementation pattern; sibling files (e.g. `open_windows.go`, `open_linux.go`) provide equivalent implementations for other operating systems
