Opens URLs in the default browser on Windows by invoking `cmd.exe /c start`, with special handling for shell metacharacters and console window visibility.

## Key Components

- **`unescapedAmpsRegex`** — Compiled regex that matches unescaped `&` characters (not preceded by `\` or `^`), used to prevent `cmd.exe` from interpreting `&` as a command separator.
- **`browser(url string) error`** — Escapes ampersands in the URL, then launches it via `cmd /c start` with `HideWindow: true` to suppress the brief console flash.

## Usage Example

```go
// Internal call within the open package (Windows build only)
err := browser("https://example.com/search?q=foo&bar=baz")
if err != nil {
    log.Fatalf("failed to open browser: %v", err)
}
```

The regex transforms `q=foo&bar=baz` → `q=foo^&bar=baz` before passing to `cmd.exe`, ensuring the URL is not split into multiple shell commands.

> **Build constraint:** This file is compiled only on Windows (`GOOS=windows`) as part of the `open` package's platform-specific browser-launching strategy alongside its Linux/macOS counterparts.
