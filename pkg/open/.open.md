Opens the system's default web browser to a specified URL, wrapping platform-specific browser launch logic.

## Key Components

- **`Browser(url string) error`** — Public function that delegates to a platform-specific `browser()` implementation, wrapping any error with context.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/open"

if err := open.Browser("https://example.com"); err != nil {
    log.Fatal(err)
}
```
