Provides HTTP download utilities with automatic retry logic and optional decompression support for `.gz`, `.bz2`, and `.xz` file formats.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Download` | func | Downloads a file from a URL and writes it atomically to a path |
| `DownloadAndExtract` | func | Downloads and decompresses a file; detects format from URL extension |
| `NotFound` | error | Sentinel error returned on HTTP 404; not retried |
| `backoffMaxElapsedTime` | const | Maximum retry window: 5 minutes using exponential backoff |

## Behavior

- **Atomic writes**: Content is written to a temp file in the target directory, then renamed to the final path — preventing partial writes on failure.
- **Retry logic**: Uses exponential backoff up to 5 minutes; logs each retry attempt to stdout.
- **404 short-circuit**: A `404 Not Found` response wraps `NotFound` as a `backoff.PermanentError`, stopping retries immediately.
- **Extraction**: `DownloadAndExtract` selects a decompressor based on the URL path suffix (`.gz` → gzip, `.bz2` → bzip2, `.xz` → xz); returns an error for unrecognized extensions.

## Usage Example

```go
import (
    "net/http"
    "net/url"

    "github.com/flamingo-stack/fleetmdm/pkg/download"
)

client := &http.Client{}

// Simple download
u, _ := url.Parse("https://example.com/agent.pkg")
if err := download.Download(client, u, "/tmp/agent.pkg"); err != nil {
    log.Fatal(err)
}

// Download and decompress a .gz file
u, _ = url.Parse("https://example.com/osqueryd.tar.gz")
if err := download.DownloadAndExtract(client, u, "/usr/local/bin/osqueryd"); err != nil {
    if errors.Is(err, download.NotFound) {
        log.Println("binary not found at URL")
    }
    log.Fatal(err)
}
```
