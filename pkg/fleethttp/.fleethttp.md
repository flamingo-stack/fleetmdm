Provides uniform creation and configuration of HTTP clients, transports, and related utilities used throughout Fleet, with built-in OpenTelemetry instrumentation.

## Key Components

### Client Options (`ClientOpt`)
| Option | Description |
|--------|-------------|
| `WithTimeout(t)` | Sets the HTTP client timeout |
| `WithTLSClientConfig(conf)` | Configures TLS for the client transport |
| `WithFollowRedir(follow)` | Enables or disables redirect following |
| `WithCookieJar(jar)` | Attaches a cookie jar for session management |

### Transport Options (`TransportOpt`)
| Option | Description |
|--------|-------------|
| `WithTLSConfig(conf)` | Sets TLS config on the transport |

### Core Functions
- **`NewClient(...ClientOpt)`** — Builds an `*http.Client` with OTel tracing via `otelhttp.NewTransport`
- **`NewTransport(...TransportOpt)`** — Clones `http.DefaultTransport` and applies overrides, preserving sane defaults
- **`NewGithubClient()`** — Returns an OAuth2-authenticated GitHub client when `NETWORK_TEST_GITHUB_TOKEN` is set
- **`HostnamesMatch(a, b string)`** — Parses two URL strings and compares their hostnames

### `SizeLimitTransport`
A custom `http.RoundTripper` that enforces a maximum response body size. Returns `ErrMaxSizeExceeded` if `Content-Length` exceeds the limit, or wraps the body in `http.MaxBytesReader` when no `Content-Length` is present.

## Usage Example

```go
// Basic client with timeout and TLS
client := fleethttp.NewClient(
    fleethttp.WithTimeout(30 * time.Second),
    fleethttp.WithTLSClientConfig(&tls.Config{InsecureSkipVerify: false}),
)

// Client that does not follow redirects
noRedirectClient := fleethttp.NewClient(
    fleethttp.WithFollowRedir(false),
)

// Size-limited transport (5 MB cap)
transport := fleethttp.NewSizeLimitTransport(5 * 1024 * 1024)
limitedClient := &http.Client{Transport: transport}

// GitHub client (uses OAuth2 if NETWORK_TEST_GITHUB_TOKEN is set)
ghClient := fleethttp.NewGithubClient()

// Hostname comparison
match, err := fleethttp.HostnamesMatch("https://fleet.example.com/api", "https://fleet.example.com/v1")
```

> All clients created via `NewClient` automatically include OpenTelemetry trace propagation through `otelhttp.NewTransport`.
