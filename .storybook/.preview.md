Storybook global preview configuration that sets up theme toggling, decorators, and default parameters for all stories in the Fleet MDM component library.

## Key Components

- **`globalTypes`** — Declares a `theme` global with a toolbar toggle (sun/moon icons) for switching between `light` and `dark` modes across all stories
- **`applyTheme(isDark)`** — Imperatively applies dark/light mode by toggling the `dark-mode` class on `document.body` and updating background/color styles using Fleet CSS custom properties (`--core-fleet-white`, `--core-fleet-black`), including `.docs-story` containers
- **`withTheme`** — A Storybook decorator that reads the active `theme` global from context and calls `applyTheme` via `useEffect` on every render/theme change
- **`decorators`** — Exports `[withTheme]` so the theme decorator is applied globally to every story
- **`parameters`** — Configures Storybook controls with regex matchers: `color` for fields ending in `background` or `color`, and `date` for fields ending in `Date`
- **`tags`** — Enables `autodocs` globally so all stories automatically generate documentation pages

## Usage Example

```javascript
// .storybook/preview.js is loaded automatically by Storybook.
// To consume the theme in a story:

export default {
  title: "Components/MyButton",
  component: MyButton,
};

export const Default = {
  args: { label: "Click me" },
};
// Switch between light/dark using the toolbar — withTheme applies the
// dark-mode class automatically via the globalTypes toolbar toggle.
```

## Notes

- The `dark-mode` CSS class must be defined in `frontend/index.scss` (imported at the top) for visual changes to take effect
- CSS variables (`--core-fleet-white`, `--core-fleet-black`) must be declared in the stylesheet; if they are undefined, the fallback is an empty string (browser default)
