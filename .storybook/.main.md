Storybook main configuration file that sets up the webpack build pipeline, story discovery patterns, addons, and TypeScript documentation generation for the Fleet MDM frontend component library.

## Key Components

- **`webpackFinal`** — Custom webpack configuration hook that:
  - Aliases `node-sql-parser` to the SQLite UMD build from `@sgress454/node-sql-parser`
  - Adds SCSS processing pipeline via `sass-loader` → `postcss-loader` → `css-loader` → `MiniCssExtractPlugin`
  - Registers bourbon mixins as Sass include paths with glob import support
  - Appends the `frontend/` directory to webpack module resolution
- **`stories`** — Glob patterns discovering stories from `frontend/components`, `SoftwarePage/components`, and `IntegrationsPage`
- **`addons`** — Registers links, essentials, accessibility (`addon-a11y`), design specs (`addon-designs`), and Babel compiler
- **`typescript`** — Configures `react-docgen-typescript` for prop extraction, filtering out `node_modules` parents and extracting enum literals


```typescript
// To add a new story glob, extend the stories array in main.ts:
stories: [
  "../frontend/components/**/*.stories.@(js|jsx|ts|tsx)",
  "../frontend/pages/YourNewPage/**/*.stories.@(js|jsx|ts|tsx)", // ← add here
],
```

## Notes

- SCSS compilation depends on `node-bourbon`, `node-sass-glob-importer`, and `mini-css-extract-plugin` being installed
- The `node-sql-parser` alias avoids browser-incompatible Node.js built-ins by pointing to the UMD/SQLite bundle
- TypeScript type checking is disabled (`check: false`) in Storybook builds for faster startup; rely on your main build for type errors
