Manages BitLocker COM/WMI operations on a single dedicated OS thread to prevent deadlocks with other COM callers sharing the global comshim singleton.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ErrWorkerClosed` | `error` | Sentinel error returned when operations are attempted on a closed worker |
| `COMWorker` | `struct` | Thread-safe worker that serializes all BitLocker COM calls onto one OS thread |
| `NewCOMWorker()` | `func` | Constructs and initializes a `COMWorker`, returning an error if COM initialization fails |
| `Close()` | `method` | Shuts down the worker goroutine gracefully; safe to call multiple times via `sync.Once` |
| `GetEncryptionStatus()` | `method` | Returns BitLocker encryption status for all logical volumes |
| `EncryptVolume()` | `method` | Encrypts a specified volume and returns the recovery key |
| `RotateRecoveryKey()` | `method` | Rotates the recovery key on an encrypted volume without decrypting the disk |

## Shutdown Design

Two channels manage safe shutdown, avoiding a panic from closing a channel another goroutine may still send on:

- `stop` — closed by `Close()` to signal the loop to exit
- `done` — closed by the loop goroutine after COM cleanup; `exec()` selects on this to return `ErrWorkerClosed` if it races with shutdown

## Usage Example

```go
worker, err := bitlocker.NewCOMWorker()
if err != nil {
    log.Fatalf("failed to initialize COM worker: %v", err)
}
defer worker.Close()

// Query encryption status across all volumes
statuses, err := worker.GetEncryptionStatus()
if err != nil {
    log.Printf("encryption status error: %v", err)
}

// Encrypt a volume and retrieve the recovery key
recoveryKey, err := worker.EncryptVolume("C:")
if err != nil {
    log.Printf("encrypt volume error: %v", err)
}

// Rotate the recovery key for escrow
newKey, err := worker.RotateRecoveryKey("C:")
if err != nil {
    log.Printf("rotate key error: %v", err)
}
```
