Provides Windows-specific BitLocker volume management via WMI/COM interfaces, implementing encryption, key protection, and status querying for the `bitlocker` package.

## Key Components

### Types & Constants
- **`EncryptionMethod`** — Enum for cipher algorithms (`AES128`, `AES256`, `XtsAES128`, `XtsAES256`, `HardwareEncryption`, etc.)
- **`EncryptionFlag`** — Bitfield flags controlling encrypt behavior (`EncryptDataOnly`, `EncryptDemandWipe`, `EncryptSynchronous`)
- **`DiscoveryVolumeType`** — Discovery volume format (`VolumeTypeNone`, `VolumeTypeDefault`, `VolumeTypeFAT32`)
- **`ForceEncryptionType`** — Software vs. hardware encryption selection
- **`KeyProtectorTypeNumericalPassword`** — WMI constant (`3`) for numerical password protector filtering

### `Volume` Struct
Holds a drive letter and WMI COM dispatch handles (`handle`, `wmiIntf`, `wmiSvc`).

### Methods on `Volume`
| Method | Description |
|---|---|
| `bitlockerClose()` | Releases all COM/OLE resources |
| `encrypt(method, flags)` | Starts volume encryption via WMI |
| `prepareVolume(volType, encType)` | Prepares a new BitLocker volume before adding protectors |
| `protectWithNumericalPassword()` | Adds a numerical password protector; returns the recovery key |
| `protectWithTPM(profile)` | Adds a TPM key protector with optional PCR profile |
| `deleteKeyProtectors()` | Removes all key protectors |
| `deleteKeyProtector(id)` | Removes a single key protector by ID |
| `getKeyProtectorIDs(type)` | Returns protector IDs filtered by type |
| `getBitlockerStatus()` | Returns conversion status, encryption percentage, and protection status |

### Helpers
- **`fveErrorCode(val)`** — Formats BitLocker error codes as `decimal (0xHEX)` matching Microsoft WMI docs
- **`encryptErrHandler(val)`** — Maps known FVE error codes to human-readable `EncryptionError` values

## Usage Example

```go
// Encrypt a volume with XTS-AES-256, data-only mode
err := vol.encrypt(XtsAES256, EncryptDataOnly)
if err != nil {
    log.Fatal().Err(err).Msg("encryption failed")
}

// Add a numerical recovery password protector
recoveryKey, err := vol.protectWithNumericalPassword()
if err != nil {
    log.Fatal().Err(err).Msg("failed to add recovery key")
}
fmt.Println("Recovery key:", recoveryKey)

// Add TPM protector (default PCR profile)
err = vol.protectWithTPM(nil)

// Query current encryption status
status, err := vol.getBitlockerStatus()

// Clean up COM resources when done
defer vol.bitlockerClose()
```
