Provides no-op stub implementations of the `COMWorker` BitLocker interface for non-Windows build targets, ensuring cross-platform compilation without Windows-specific COM dependencies.

## Key Components

| Symbol | Description |
|--------|-------------|
| `COMWorker` | Empty struct satisfying the BitLocker worker interface on non-Windows platforms |
| `NewCOMWorker()` | Returns a zero-value `COMWorker` with no error |
| `Close()` | No-op lifecycle cleanup method |
| `GetEncryptionStatus()` | Returns `nil, nil` — no volumes available on non-Windows |
| `EncryptVolume(string)` | No-op; returns empty string and no error |
| `RotateRecoveryKey(string)` | No-op; returns empty string and no error |

## Usage Example

This file is selected automatically by the Go build system via the `//go:build !windows` constraint. No manual wiring is required.

```go
// On Linux/macOS, NewCOMWorker returns a safe no-op worker.
worker, err := bitlocker.NewCOMWorker()
if err != nil {
    log.Fatal(err)
}
defer worker.Close()

// All operations succeed silently and return zero values.
statuses, _ := worker.GetEncryptionStatus() // nil
key, _      := worker.EncryptVolume("/dev/sda1") // ""
recovery, _ := worker.RotateRecoveryKey("/dev/sda1") // ""
```

## Notes

- The build tag `//go:build !windows` ensures this file is **excluded** on Windows, where the real COM-backed implementation is compiled instead.
- All methods satisfy the same interface as the Windows implementation, enabling platform-agnostic code paths without `runtime.GOOS` checks at call sites.
