Defines BitLocker encryption constants, error types, and status structures for interacting with the Windows `Win32_EncryptableVolume` WMI class.

## Key Components

### Constants

- **Conversion Status** (`ConversionStatusFullyDecrypted` through `ConversionStatusDecryptionPaused`) — Volume encryption/decryption state values mapped from the [Microsoft WMI docs](https://learn.microsoft.com/en-us/windows/win32/secprov/getconversionstatus-win32-encryptablevolume).
- **Error Codes** — `int32` representations of Win32 BitLocker error codes (delivered as `VT_I4` via COM VARIANT), covering invalid arguments, passphrase policy violations, protector conflicts, and more.

### Types

| Type | Description |
|------|-------------|
| `EncryptionError` | Wraps a BitLocker-specific `int32` error code with a human-readable message; implements the `error` interface |
| `EncryptionStatus` | Holds full conversion state: protection/conversion status, encryption percentage, flags, and wipe progress |
| `VolumeStatus` | Associates a drive letter (e.g., `"C:"`) with its `EncryptionStatus` |

## Usage Example

```go
status := &bitlocker.VolumeStatus{
    DriveVolume: "C:",
    Status: &bitlocker.EncryptionStatus{
        ProtectionStatus:     1,
        ConversionStatus:     bitlocker.ConversionStatusFullyEncrypted,
        EncryptionPercentage: "100%",
    },
}

if status.Status.ConversionStatus == bitlocker.ConversionStatusEncryptionInProgress {
    fmt.Printf("Encrypting %s: %s complete\n",
        status.DriveVolume,
        status.Status.EncryptionPercentage,
    )
}

// Handle a BitLocker-specific error
err := bitlocker.NewEncryptionError("passphrase not allowed by policy",
    bitlocker.ErrorCodePolicyPassphraseNotAllowed)
fmt.Println(err.Error()) // "passphrase not allowed by policy"
fmt.Println(err.Code())  // -2144272278
```
