Type-safe conversion utilities for transforming `ole.VARIANT` values returned by Windows COM/OLE calls into native Go types.

## Key Components

| Function | Return Type | Description |
|---|---|---|
| `ToIDispatchErr` | `*ole.IDispatch` | Converts variant to a COM dispatch interface |
| `ToStringSliceErr` | `[]string` | Converts variant array to a Go string slice |
| `ToInt64Err` | `int64` | Extracts a 64-bit integer |
| `ToInt32Err` | `int32` | Extracts a 32-bit integer |
| `ToUint32Err` | `uint32` | Extracts an unsigned 32-bit integer |
| `ToFloat64Err` | `float64` | Extracts a 64-bit float |
| `ToFloat32Err` | `float32` | Extracts a 32-bit float |
| `ToStringErr` | `string` | Extracts a string value |
| `ToBoolErr` | `bool` | Extracts a boolean value |
| `ToTimeErr` | `*time.Time` | Extracts a `time.Time` pointer |

All exported functions follow the same signature pattern: they accept `(*ole.VARIANT, error)` and propagate the input error, returning a zero value on `nil` variant data.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/oleconv"

// Typically used when calling COM object properties that return (VARIANT, error)
name, err := oleconv.ToStringErr(obj.GetProperty("Name"))
if err != nil {
    return fmt.Errorf("reading Name: %w", err)
}

installed, err := oleconv.ToBoolErr(obj.GetProperty("IsInstalled"))
if err != nil {
    return fmt.Errorf("reading IsInstalled: %w", err)
}

installDate, err := oleconv.ToTimeErr(obj.GetProperty("LastDeploymentChangeTime"))
if err != nil {
    return fmt.Errorf("reading date: %w", err)
}
```

> **Note:** This package is derived from [`ceshihao/windowsupdate`](https://github.com/ceshihao/windowsupdate/blob/master/oleconv.go), originally based on the Kolide launcher osquery tables. It is Windows-specific and requires the [`go-ole`](https://github.com/go-ole/go-ole) library.
