Go wrapper for the Windows Update API `ICategory` COM interface, converting OLE dispatch objects into typed Go structs for use in Windows Update table queries.

## Key Components

### `ICategory` struct
Maps to the [Windows Update API `ICategory` interface](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/nn-wuapi-icategory). Fields include:

| Field | Type | Description |
|-------|------|-------------|
| `CategoryID` | `string` | Unique category identifier |
| `Children` | `[]*ICategory` | Nested subcategories |
| `Description` | `string` | Human-readable description |
| `Image` | `*IImageInformation` | Associated image metadata |
| `Name` | `string` | Display name |
| `Order` | `int32` | Sort order |
| `Type` | `string` | Category type string |

> **Note:** `Parent` and `Updates` fields are defined but their OLE hydration is commented out, likely to avoid circular traversal or performance issues.

### `toICategory(categoryDisp *ole.IDispatch) (*ICategory, error)`
Converts a single OLE `IDispatch` pointer into a fully populated `*ICategory`, fetching each property via `oleutil.GetProperty`.

### `toICategories(categoriesDisp *ole.IDispatch) ([]*ICategory, error)`
Iterates over an OLE collection (using the `Count`/`Item` pattern) and returns a slice of `*ICategory`.

## Usage Example

```go
// Retrieve a categories collection dispatch from Windows Update API
categoriesDisp, err := oleconv.ToIDispatchErr(
    oleutil.GetProperty(updateDisp, "Categories"),
)
if err != nil {
    log.Fatal(err)
}

categories, err := toICategories(categoriesDisp)
if err != nil {
    log.Fatal(err)
}

for _, cat := range categories {
    fmt.Printf("Category: %s (%s)\n", cat.Name, cat.CategoryID)
}
```
