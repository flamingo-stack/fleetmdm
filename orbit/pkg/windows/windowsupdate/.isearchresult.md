Go wrapper for the Windows Update API `ISearchResult` COM interface, converting OLE dispatch objects into a typed Go struct.

## Key Components

### `ISearchResult` struct
Represents the result of a Windows Update search operation, mirroring the [`ISearchResult`](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-isearchresult) WUA interface with the following fields:

| Field | Type | Description |
|---|---|---|
| `disp` | `*ole.IDispatch` | Underlying COM dispatch pointer |
| `ResultCode` | `int32` | Operation result enum ([`OperationResultCode`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/ne-wuapi-operationresultcode)) |
| `RootCategories` | `[]*ICategory` | Top-level update categories |
| `Updates` | `[]*IUpdate` | Full update details from the result collection |
| `Warnings` | `[]*IUpdateException` | Non-fatal warnings from the search |

### `toISearchResult(searchResultDisp *ole.IDispatch) (*ISearchResult, error)`
Internal constructor that hydrates an `ISearchResult` from a raw OLE `IDispatch` pointer by extracting each property via `oleutil.GetProperty` and delegating collection conversion to `toICategories`, `toIUpdates`, and `toIUpdateExceptions`.

## Usage Example

```go
// Typically called internally after performing a Windows Update search
searchResultDisp, err := oleutil.CallMethod(searcher, "Search", query)
if err != nil {
    log.Fatal(err)
}

result, err := toISearchResult(searchResultDisp.ToIDispatch())
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Result code: %d\n", result.ResultCode)
for _, update := range result.Updates {
    fmt.Println(update.Title)
}
```

> **Note:** Based on [`kolide/launcher`](https://github.com/kolide/launcher) OLE/COM table patterns. This is a Windows-only component used within the [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm) orbit Windows update subsystem.
