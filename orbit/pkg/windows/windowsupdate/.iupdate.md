Go wrapper for the Windows Update Agent (WUA) `IUpdate` COM interface, mapping update properties from OLE dispatch objects into a typed Go struct for use in Fleet's osquery Windows update tables.

## Key Components

### `IUpdate` struct
A comprehensive Go representation of the [Windows `IUpdate` COM interface](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-iupdate), covering properties from `IUpdate` through `IUpdate5`. Includes metadata such as `Title`, `Description`, `KBArticleIDs`, `MsrcSeverity`, installation state flags (`IsInstalled`, `IsDownloaded`, `IsHidden`), and download sizing fields.

### Functions

| Function | Description |
|---|---|
| `toIUpdate` | Converts a single OLE `IDispatch` pointer into a populated `*IUpdate` |
| `toIUpdates` | Iterates an `IUpdateCollection` dispatch object and returns `[]*IUpdate` |
| `toIUpdatesIdentities` | Extracts only the `IUpdateIdentity` from each update in a collection (non-recursive) |

## Usage Example

```go
// Retrieve an IUpdateCollection dispatch pointer via WUA session, then convert:
updates, err := toIUpdates(updateCollectionDisp)
if err != nil {
    log.Fatal(err)
}

for _, u := range updates {
    fmt.Printf("Title: %s, Installed: %v, KB: %v\n",
        u.Title, u.IsInstalled, u.KBArticleIDs)
}

// To get only identities from bundled updates (avoids recursive full parse):
identities, err := toIUpdatesIdentities(bundledUpdatesDisp)
```

## Notes

- Based on [`kolide/launcher`](https://github.com/kolide/launcher) osquery table patterns.
- OLE property marshalling uses `oleconv` helpers (`ToBoolErr`, `ToInt32Err`, `ToStringErr`, etc.).
- Enum-typed fields (`AutoDownload`, `DeploymentAction`, `DownloadPriority`) store raw `int32` values; callers must map these against the WUA API enumerations.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/windows/windowsupdate/iupdate.go)
