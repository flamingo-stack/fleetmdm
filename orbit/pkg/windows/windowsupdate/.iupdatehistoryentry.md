Maps the Windows Update API `IUpdateHistoryEntry` COM interface to a Go struct, providing typed access to historical update records via OLE/COM dispatch.

## Key Components

### `IUpdateHistoryEntry` struct
A Go representation of the [Windows `IUpdateHistoryEntry` interface](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-iupdatehistoryentry), exposing fields such as:

| Field | Type | Description |
|---|---|---|
| `ClientApplicationID` | `string` | ID of the application that initiated the update |
| `Date` | `*time.Time` | Timestamp of the update operation |
| `HResult` | `int32` | COM result code from the operation |
| `Operation` | `int32` | Enum: install, uninstall, etc. |
| `ResultCode` | `int32` | Enum: success, failed, etc. |
| `UpdateIdentity` | `*IUpdateIdentity` | Nested identity (revision ID, update ID) |

### `toIUpdateHistoryEntry(disp *ole.IDispatch)`
Converts a single OLE dispatch pointer into a populated `*IUpdateHistoryEntry`, reading each property via `oleutil.GetProperty` and converting types using the `oleconv` helpers.

### `toIUpdateHistoryEntries(disp *ole.IDispatch)`
Iterates the COM collection by reading its `Count` property and calling `toIUpdateHistoryEntry` for each `Item`, returning `[]*IUpdateHistoryEntry`.

## Usage Example

```go
// Obtain the dispatch pointer from the Windows Update Agent API, then:
entries, err := toIUpdateHistoryEntries(historyCollectionDisp)
if err != nil {
    log.Fatalf("failed to read update history: %v", err)
}

for _, e := range entries {
    fmt.Printf("Title: %s | Date: %v | ResultCode: %d\n",
        e.Title, e.Date, e.ResultCode)
    if e.UpdateIdentity != nil {
        fmt.Printf("  UpdateID: %s Rev: %d\n",
            e.UpdateIdentity.UpdateID, e.UpdateIdentity.RevisionNumber)
    }
}
```

> **Platform note:** This file is Windows-only. It relies on `go-ole` for COM/OLE interop and is part of the `windowsupdate` package under [`orbit/pkg/windows`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/windows).
