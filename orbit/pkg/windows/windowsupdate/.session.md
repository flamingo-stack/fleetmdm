Wraps the Windows Update COM `IUpdateSession` interface, enabling search, download, and installation operations on Windows updates via OLE automation.

## Key Components

| Export | Type | Description |
|---|---|---|
| `IUpdateSession` | struct | Represents a Windows Update session with `ClientApplicationID` and `ReadOnly` properties |
| `NewUpdateSession()` | func | Creates a new `Microsoft.Update.Session` COM object and returns an `IUpdateSession` |
| `toIUpdateSession()` | func | Internal constructor that hydrates an `IUpdateSession` from an OLE `IDispatch` pointer |
| `GetLocal()` | method | Retrieves the `UserLocale` property (uint32) for the session |
| `SetLocal()` | method | Sets the `UserLocale` property on the session |
| `CreateUpdateSearcher()` | method | Returns an `IUpdateSearcher` for querying available updates |

## Usage Example

```go
// Create a new Windows Update session
session, err := windowsupdate.NewUpdateSession()
if err != nil {
    log.Fatalf("failed to create update session: %v", err)
}

// Optionally set the locale
if err := session.SetLocal(0x0409); err != nil {
    log.Fatalf("failed to set locale: %v", err)
}

// Create a searcher to query updates
searcher, err := session.CreateUpdateSearcher()
if err != nil {
    log.Fatalf("failed to create update searcher: %v", err)
}

// Use searcher to find updates...
_ = searcher
```

## Notes

- Based on [`kolide/launcher`](https://github.com/kolide/launcher/pkg/osquery/tables) OLE table patterns
- Wraps the Windows [`IUpdateSession`](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-iupdatesession) COM interface
- Depends on [`go-ole`](https://github.com/go-ole/go-ole) for OLE/COM interop and `oleconv` for safe type conversions
- **Windows only** — requires the Windows Update Agent API (`wuapi`)
