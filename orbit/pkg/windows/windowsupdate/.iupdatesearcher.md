Go wrapper for the Windows Update API's `IUpdateSearcher` COM interface, enabling programmatic searching and querying of Windows update history via OLE/COM dispatch.

## Key Components

### `IUpdateSearcher` Struct
Maps the [Windows `IUpdateSearcher` COM interface](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-iupdatesearcher) properties:

| Field | Type | Description |
|---|---|---|
| `CanAutomaticallyUpgradeService` | `bool` | Whether the service can auto-upgrade |
| `ClientApplicationID` | `string` | ID of the calling application |
| `IncludePotentiallySupersededUpdates` | `bool` | Include superseded updates in results |
| `Online` | `bool` | Whether search is performed online |
| `ServerSelection` | `int32` | Which server to search |
| `ServiceID` | `string` | GUID of the update service |

### Functions & Methods

- **`toIUpdateSearcher()`** — Constructs an `IUpdateSearcher` from an OLE `IDispatch` pointer, reading all properties via `oleutil`
- **`Search(criteria string)`** — Runs a synchronous update search using a [WQL-like criteria string](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nf-wuapi-iupdatesearcher-search); returns `*ISearchResult`
- **`QueryHistory(startIndex, count int32)`** — Retrieves a paginated slice of update history entries
- **`GetTotalHistoryCount()`** — Returns total number of update history events on the machine
- **`QueryHistoryAll()`** — Convenience method combining `GetTotalHistoryCount` and `QueryHistory` to fetch the complete update history

## Usage Example

```go
// Obtain an IDispatch pointer from the WUA COM object (omitted for brevity)
var updateSearcherDisp *ole.IDispatch

searcher, err := toIUpdateSearcher(updateSearcherDisp)
if err != nil {
    log.Fatal(err)
}

// Search for all pending updates
result, err := searcher.Search("IsInstalled=0 AND Type='Software'")
if err != nil {
    log.Fatal(err)
}

// Fetch complete update history
history, err := searcher.QueryHistoryAll()
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Total history entries: %d\n", len(history))
```
