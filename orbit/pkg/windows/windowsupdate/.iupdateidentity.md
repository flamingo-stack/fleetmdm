Wraps the Windows Update Agent `IUpdateIdentity` COM interface, providing Go access to a Windows update's unique identifier and revision number.

## Key Components

### `IUpdateIdentity`
A struct representing the [IUpdateIdentity](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-iupdateidentity) COM interface with the following fields:

| Field | Type | Description |
|---|---|---|
| `disp` | `*ole.IDispatch` | Underlying COM dispatch pointer |
| `RevisionNumber` | `int32` | Revision number of the update |
| `UpdateID` | `string` | GUID uniquely identifying the update |

### `toIUpdateIdentity(updateIdentityDisp *ole.IDispatch) (*IUpdateIdentity, error)`
Converts a raw `IDispatch` COM pointer into an `IUpdateIdentity` struct by querying the `RevisionNumber` and `UpdateID` properties via OLE automation.

## Usage Example

```go
// Typically called when iterating over an IUpdateCollection
dispatchPtr, _ := oleutil.GetProperty(updateDisp, "Identity")
identity, err := toIUpdateIdentity(dispatchPtr.ToIDispatch())
if err != nil {
    log.Fatalf("failed to get update identity: %v", err)
}

fmt.Printf("Update ID: %s (Revision: %d)\n", identity.UpdateID, identity.RevisionNumber)
```

## Notes

- Based on the [kolide/launcher](https://github.com/kolide/launcher) OLE/COM table pattern.
- Depends on [`go-ole`](https://github.com/go-ole/go-ole) for COM interop and the internal `oleconv` package for type-safe property conversion.
- Windows-only; part of the `windowsupdate` package under [`orbit/pkg/windows`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/windows).
