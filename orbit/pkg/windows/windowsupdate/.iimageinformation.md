Represents a localized image associated with a Windows Update entry or category, wrapping the COM `IImageInformation` interface via OLE dispatch.

## Key Components

- **`IImageInformation`** — Struct holding image metadata: `AltText`, `Height`, `Source`, and `Width`, backed by an underlying `*ole.IDispatch` pointer.
- **`toIImageInformation`** — Conversion helper that transforms an `*ole.IDispatch` reference into an `*IImageInformation` struct. Currently a stub returning `nil`.

## Usage Example

```go
// Intended internal usage once toIImageInformation is implemented:
imageDisp := getDispatchFromWindowsUpdate() // *ole.IDispatch
imageInfo, err := toIImageInformation(imageDisp)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Source: %s (%dx%d)\n", imageInfo.Source, imageInfo.Width, imageInfo.Height)
```

## Notes

- Based on [`kolide/launcher`](https://github.com/kolide/launcher) OLE/COM table patterns.
- Maps to the Windows API interface [`IImageInformation`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/nn-wuapi-iimageinformation).
- `toIImageInformation` is **not yet implemented** — returns `nil, nil` pending COM property extraction logic.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/tables/windowsupdate/iimageinformation.go)
