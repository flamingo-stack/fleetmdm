Provides a Go representation of the Windows Update API `IUpdateException` interface, mapping incomplete search result metadata from the Windows Update Agent (WUA) COM API via OLE dispatch.

## Key Components

| Component | Type | Description |
|---|---|---|
| `IUpdateException` | struct | Maps to the WUA [`IUpdateException`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/nn-wuapi-iupdateexception) COM interface, holding context, HRESULT, and message for a single update exception |
| `Context` | `int32` | Enum value from [`UpdateExceptionContext`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/ne-wuapi-updateexceptioncontext) indicating the scope of the exception |
| `HResult` | `int64` | Win32 HRESULT error code associated with the exception |
| `Message` | `string` | Human-readable description of the exception |
| `toIUpdateExceptions` | func | Converts an OLE `IDispatch` pointer to a slice of `IUpdateException` structs (stub — not yet implemented) |

## Usage Example

```go
// IUpdateException is populated from Windows Update Agent search results
exception := &IUpdateException{
    Context: 1,       // UpdateExceptionContext enum value
    HResult: 0x80240004,
    Message: "Access denied",
}

fmt.Printf("Update error [ctx=%d]: %s (HRESULT: 0x%X)\n",
    exception.Context,
    exception.Message,
    exception.HResult,
)
```

> **Note:** `toIUpdateExceptions` is currently a stub returning `nil, nil`. Full OLE dispatch parsing from `*ole.IDispatch` is not yet implemented. See the [source file](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/tables/windowsupdate/iupdateexception.go) for the current state.
