Provides the package declaration and documentation header for the `windowsupdate` package, which wraps the Windows Update Agent API using go-ole bindings.

## Key Components

- **Package `windowsupdate`** — Top-level package exposing a Go interface to the Windows Update Agent via COM/OLE automation.

## Upstream Attribution

This package derives from two upstream sources:

- [`ceshihao/windowsupdate`](https://github.com/ceshihao/windowsupdate)
- [`kolide/launcher` osquery tables](https://github.com/kolide/launcher/pkg/osquery/tables)

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/windowsupdate"

// Use the windowsupdate package to query or interact
// with the Windows Update Agent via go-ole bindings.
```

## Notes

- Windows-only package; intended for use on Windows hosts where the Windows Update Agent COM interface is available.
- See sibling files in the same package for the concrete API surface (session management, update queries, etc.).
