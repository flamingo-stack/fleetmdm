Converts a Windows Update API `IStringCollection` COM object (via OLE `IDispatch`) into a Go string slice.

## Key Components

### Functions

- **`iStringCollectionToStringArrayErr(disp *ole.IDispatch, err error) ([]string, error)`** — Accepts an OLE `IDispatch` pointer referencing a [`IStringCollection`](https://docs.microsoft.com/en-us/windows/win32/api/wuapi/nn-wuapi-istringcollection) and propagates any upstream error. Returns `nil, nil` for a nil dispatch, otherwise iterates items by index using the COM `Count` and `Item` properties.

## Usage Example

```go
// Retrieve a property returning an IStringCollection from a COM object
disp, err := oleutil.GetProperty(someDispatch, "Categories")

strings, err := iStringCollectionToStringArrayErr(disp.ToIDispatch(), err)
if err != nil {
    log.Fatal(err)
}

for _, s := range strings {
    fmt.Println(s)
}
```

## Notes

- Based on patterns from [`kolide/launcher`](https://github.com/kolide/launcher).
- Uses [`oleconv`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/windows/oleconv) helpers to safely convert OLE `VARIANT` values to typed Go primitives.
- Error from the caller is passed directly into the function, allowing idiomatic chained OLE calls without intermediate error checks.
