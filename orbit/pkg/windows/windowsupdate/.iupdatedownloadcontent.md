Defines the `IUpdateDownloadContent` struct and its collection parser for the Windows Update COM API, representing the download content metadata of a single update entry.

## Key Components

| Element | Description |
|---|---|
| `IUpdateDownloadContent` | Struct mapping to the Windows `IUpdateDownloadContent` COM interface, exposing the `DownloadUrl` field |
| `toIUpdateDownloadContents` | Helper function to convert an `ole.IDispatch` collection into a slice of `*IUpdateDownloadContent` (currently a stub) |

## Usage Example

```go
// Retrieve download content from an IDispatch pointer
contents, err := toIUpdateDownloadContents(dispatchPtr)
if err != nil {
    log.Fatal(err)
}

for _, content := range contents {
    fmt.Println(content.DownloadUrl)
}
```

## Notes

- Based on the [`kolide/launcher`](https://github.com/kolide/launcher) osquery tables pattern.
- Maps to the Microsoft Windows Update API interface [`IUpdateDownloadContent`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/nn-wuapi-iupdatedownloadcontent).
- `toIUpdateDownloadContents` is **not yet implemented** (`TODO`) and returns `nil, nil`.
- The `disp` field is intentionally unused (`//nolint:unused`) as the COM dispatch pointer is held for lifecycle management.
