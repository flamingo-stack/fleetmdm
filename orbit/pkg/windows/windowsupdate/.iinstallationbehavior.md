Wraps the Windows Update API `IInstallationBehavior` COM interface, representing installation and uninstallation behavior properties for a Windows update.

## Key Components

**`IInstallationBehavior` struct**
- `CanRequestUserInput` — whether the update can prompt the user during install/uninstall
- `Impact` — installation impact level (enum: [`InstallationImpact`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/ne-wuapi-installationimpact))
- `RebootBehavior` — reboot requirement behavior (enum: [`InstallationRebootBehavior`](https://docs.microsoft.com/zh-cn/windows/win32/api/wuapi/ne-wuapi-installationrebootbehavior))
- `RequiresNetworkConnectivity` — whether network is required during installation

**`toIInstallationBehavior()`** — converts a raw `*ole.IDispatch` COM pointer into an `*IInstallationBehavior` (currently a stub returning `nil`).

## Usage Example

```go
// Retrieve an IDispatch pointer for an update's installation behavior
// (typically obtained from iterating Windows Update COM objects)
var behaviorDisp *ole.IDispatch

behavior, err := toIInstallationBehavior(behaviorDisp)
if err != nil {
    log.Fatal(err)
}

if behavior != nil && behavior.CanRequestUserInput {
    fmt.Println("Update may prompt the user during installation")
}
```
