Implements an insecure TLS reverse proxy for testing osquery enrollment against a Fleet server in non-production environments. Uses a hardcoded self-signed certificate/key pair and skips TLS verification on the upstream connection.

## Key Components

- **`TLSProxy`** — Core struct holding the listener, HTTP server, and assigned port. Always initialize via `NewTLSProxy`.
- **`NewTLSProxy(targetURL string)`** — Creates a `TLSProxy` that forwards traffic to the given target URL. Binds to `localhost:0` (random available port) using the embedded self-signed cert.
- **`InsecureServeTLS()`** — Starts serving TLS connections. Blocks until the server stops.
- **`Close()`** — Gracefully shuts down the server with a 10-second timeout.
- **`ServerCert`** — Exported constant containing the embedded self-signed certificate (localhost). The corresponding private key `serverKey` is intentionally compromised by inclusion in source.
- **`newProxyHandler`** — Builds an `httputil.ReverseProxy` targeting the parsed URL, with `InsecureSkipVerify: true` on the upstream transport.
- **`joinURLPath` / `singleJoiningSlash`** — Internal URL path helpers copied from Go stdlib source.

## Usage Example

```go
package main

import (
    "log"

    "github.com/flamingo-stack/fleetmdm/pkg/certificate/insecure"
)

func main() {
    proxy, err := insecure.NewTLSProxy("https://fleet.example.com")
    if err != nil {
        log.Fatal(err)
    }
    defer proxy.Close()

    log.Printf("Insecure TLS proxy listening on localhost:%d", proxy.Port)

    // Run in a goroutine; blocks until server stops
    if err := proxy.InsecureServeTLS(); err != nil {
        log.Println(err)
    }
}
```

> **⚠️ Warning:** This package is explicitly **not suitable for production**. The certificate and private key are publicly known, and TLS verification of the upstream target is disabled.
