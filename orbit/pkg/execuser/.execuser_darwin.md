Provides the macOS-specific implementation of the `execuser` package, using the system `open` command to launch `.app` bundle processes as the current login user or a specified user via `sudo`.

## Key Components

### `run(path string, opts eopts) (lastLogs string, err error)`
Launches a macOS `.app` directory using `/usr/bin/open`. Validates that the path is a directory, constructs arguments for stderr redirection, environment variables, and program arguments, then executes the command. If `opts.user` is set, runs `open` via `sudo -u <user>`. Captures combined stdout/stderr via a `TransientWriter` and returns any captured output on error.

### `runWithOutput(path string, opts eopts) (output []byte, exitCode int, err error)`
Stub implementation — always returns `errors.New("not implemented")`. Reserved for future macOS output-capturing support.

## Usage Example

```go
// Launch a macOS .app bundle as the current user
logs, err := run("/Applications/MyApp.app", eopts{
    stderrPath: "/tmp/myapp.stderr",
    env: [][2]string{
        {"MY_ENV_VAR", "value"},
    },
    args: [][2]string{
        {"--config", "/etc/myapp.conf"},
    },
})
if err != nil {
    fmt.Printf("launch failed: %v\nLast logs: %s\n", err, logs)
}

// Launch as a specific user (requires sudo privileges)
logs, err = run("/Applications/MyApp.app", eopts{
    user: "jane",
})
```

> **Note:** Because macOS `open` spawns a detached process in user space, the child process cannot be cancelled via a `context.Context`. The `run` function returns once `open` itself exits, not when the launched application exits.
