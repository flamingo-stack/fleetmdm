Linux-specific implementation of the `execuser` package that executes commands as a login user via `sudo`, with automatic detection of GUI session type (X11/Wayland) and environment configuration.

## Key Components

### Core Execution Functions

| Function | Description |
|---|---|
| `baserun(path, opts)` | Builds an `exec.Cmd` using `sudo` (with optional `timeout` prefix), injecting display environment variables and `LD_LIBRARY_PATH` for Fleet Desktop |
| `run(path, opts)` | Starts a command in fire-and-forget mode; reaps the child via a background goroutine to prevent zombie accumulation |
| `runWithOutput(path, opts)` | Runs a command and captures stdout/stderr along with the exit code |

### Session & Display Detection

| Function | Description |
|---|---|
| `getConfigForCommand(user, path)` | Resolves `sudo` args and environment variables for a given user, including session type and display |
| `getDisplayVariableForSession(userID, type)` | Returns the correct `DISPLAY` or `WAYLAND_DISPLAY` value, defaulting gracefully on error |
| `getUserWaylandDisplay(uid)` | Scans `/run/user/<uid>/wayland-*` sockets to find the active Wayland display |
| `getUserX11Display(userID)` | Scans `/proc` for a process owned by the user that has `DISPLAY` set in its environment |

### Utility Functions

| Function | Description |
|---|---|
| `getUserID(user)` | Calls `id -u <user>` to resolve the numeric UID |
| `isOpenSUSELeap16Plus()` | Parses `/etc/os-release` to detect openSUSE Leap 16+ and suppress the `-i` (login shell) sudo flag |
| `readEnvFromProc(pid, envVar)` | Reads a single environment variable from `/proc/<pid>/environ` |
| `readEnvFromProcFile(path, envVar)` | Parses null-byte-delimited proc environ file for a specific key |

## Usage Example

```go
// Run Fleet Desktop as the logged-in user
lastLogs, err := run("/usr/local/bin/fleet-desktop", eopts{
    user:    "alice",
    timeout: 30 * time.Second,
    env:     [][2]string{{"FLEET_URL", "https://fleet.example.com"}},
    args:    [][2]string{{"--fleet-url", "https://fleet.example.com"}},
})
if err != nil {
    log.Fatal().Err(err).Msg("failed to start fleet-desktop")
}

// Capture output from a command run as another user
output, exitCode, err := runWithOutput("/usr/bin/some-tool", eopts{
    user: "alice",
})
```

> **Note:** `run` returns immediately after `cmd.Start()` and reaps the child process asynchronously. This prevents zombie process accumulation when Fleet Desktop is respawned in a tight loop by Orbit. See [issue #41796](https://github.com/flamingo-stack/fleetmdm/issues/41796) for context.
