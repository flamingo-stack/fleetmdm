A circular-buffer writer that retains only the most recent 4096 bytes of written data, discarding older content when the buffer is full.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `bufSize` | `const` | Fixed buffer capacity: `4096` bytes |
| `TransientWriter` | `struct` | Holds a fixed-size byte array and a length counter |
| `Write` | `method` | Implements `io.Writer`; overwrites oldest bytes when capacity is exceeded |
| `String` | `method` | Returns current buffer contents as a string |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/orbit/pkg/execuser"
)

func main() {
    var w execuser.TransientWriter

    fmt.Fprintf(&w, "first chunk of output\n")
    fmt.Fprintf(&w, "second chunk of output\n")

    // Always contains the most recent ≤4096 bytes
    fmt.Println(w.String())
}
```

## Write Behaviour

The three `switch` cases handle distinct overflow scenarios:

```text
Input >= bufSize  → copy only the last 4096 bytes of input (discard head)
Input causes wrap → shift buffer left to make room, append new bytes
Input fits        → append directly at current position
```

> **Note:** `Write` always returns `len(p), nil` regardless of truncation — callers should not rely on `n` to detect dropped bytes. Use `String()` after the process completes to inspect captured output.
