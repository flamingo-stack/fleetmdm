Runs privileged applications as the current login user, providing a platform-agnostic interface for privilege de-escalation from root/SYSTEM to the active user session.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `eopts` | struct | Internal configuration holding env vars, args, stderr path, timeout, and target user |
| `Option` | func type | Functional option pattern for configuring execution |
| `WithEnv` | func | Appends a `name=value` environment variable to the child process |
| `WithArg` | func | Appends a `name value` CLI argument pair to the child process |
| `WithTimeout` | func | Sets execution timeout (Linux only) |
| `WithUser` | func | Overrides the target user (macOS only) |
| `Run` | func | Starts the child process and returns immediately with last logs |
| `RunWithOutput` | func | Blocks until the child process exits, returning stdout, exit code, and error |

## Usage Example

```go
// Fire-and-forget: launch a GUI app as the logged-in user from a root daemon
lastLogs, err := execuser.Run(
    "/usr/local/bin/myapp",
    execuser.WithEnv("MY_ENV", "production"),
    execuser.WithArg("--config", "/etc/myapp/config.yaml"),
    execuser.WithTimeout(30*time.Second),
)
if err != nil {
    log.Fatalf("failed to run: %v (logs: %s)", err, lastLogs)
}

// Blocking: capture output from a privileged helper
output, exitCode, err := execuser.RunWithOutput(
    "/usr/local/bin/myhelper",
    execuser.WithArg("--query", "status"),
)
if err != nil || exitCode != 0 {
    log.Fatalf("helper failed (exit %d): %v\nOutput: %s", exitCode, err, output)
}
```

> **Platform notes:** `WithTimeout` is Linux-only. `WithUser` is macOS-only. The actual privilege drop is handled by platform-specific `run`/`runWithOutput` implementations not shown in this file.
