Provides a macOS-specific implementation for detecting the currently active GUI-logged-in user via the system configuration utility `scutil`.

## Key Components

- **`UserLoggedInViaGui() (*string, error)`** — Queries macOS's `State:/Users/ConsoleUser` key using `scutil` to identify the active GUI console user. Returns `nil, nil` if no valid user is found, `nil, error` on command failure, or a pointer to the username string on success.
- **`re`** — A compiled `regexp` that extracts `Name : <username>` entries from `scutil` output.

## Usage Example

```go
import "yourpackage/user"

func main() {
    username, err := user.UserLoggedInViaGui()
    if err != nil {
        log.Fatalf("failed to get GUI user: %v", err)
    }
    if username == nil {
        log.Println("no GUI user currently logged in")
        return
    }
    log.Printf("GUI user: %s", *username)
}
```

## Notes

- **Build constraint:** This file is compiled **only on Darwin (macOS)** (`//go:build darwin`).
- The function deliberately skips `_mbsetupuser`, the macOS Migration Assistant/Setup Assistant account, returning the first real user instead.
- Relies on `/bin/sh` and the `scutil` binary, both standard on macOS — no external dependencies required.
