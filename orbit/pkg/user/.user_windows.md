Provides a Windows-specific stub implementation of the `UserLoggedInViaGui` function, returning an empty string to satisfy the cross-platform interface.

## Key Components

- **`UserLoggedInViaGui() (*string, error)`** — Returns a pointer to an empty string and no error. On Windows, GUI session user detection is not required; this stub exists solely to satisfy the shared interface used on macOS and Linux.

## Usage Example

```go
user, err := user.UserLoggedInViaGui()
if err != nil {
    log.Fatal(err)
}
// On Windows, *user will always be ""
fmt.Println(*user)
```

## Notes

- Build-constrained to Windows via `//go:build windows`.
- The meaningful implementations of this function live in the macOS and Linux counterparts within the same package. See the full package at [`server/mdm/internal/user/`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/mdm/internal/user/).
- This pattern prevents Fleet Desktop launch errors on non-Windows platforms by ensuring a consistent function signature across all OS targets.
