Windows-specific stub implementation of the `CopyLenses` function for the `augeas` package. On Windows, Augeas lens installation is not supported, so this function returns empty values with no error.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `CopyLenses` | `func CopyLenses(installPath string) (string, error)` | No-op stub that returns `("", nil)` on Windows builds |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/augeas"

// On Windows, CopyLenses is a no-op and always succeeds
lensPath, err := augeas.CopyLenses("C:\\Program Files\\Fleet")
if err != nil {
    // Will never occur on Windows
    log.Fatal(err)
}
// lensPath will always be "" on Windows
```

## Notes

- This file is **build-constrained** to Windows via `//go:build windows` and `// +build windows` (legacy compatibility tag).
- A platform-specific counterpart likely exists for Linux/macOS that performs the actual lens copy operation.
- The no-op pattern allows cross-platform code to call `CopyLenses` without OS-specific branching at the call site.
