Provides Unix-only utilities for embedding and extracting Augeas lens files to the local filesystem at runtime using Go's `embed` package.

## Key Components

- **`lenses` (embed.FS)** — Embedded filesystem containing the bundled Augeas lens files from the `lenses/` directory at compile time.
- **`CopyLenses(installPath string) (string, error)`** — Extracts all embedded lens files into a `lenses/` subdirectory under the given `installPath`. Clears any existing directory before writing, then copies each lens file with permissions `0644`. Returns the full output path on success.

> **Build constraint:** This file is excluded on Windows (`//go:build !windows`).

## Usage Example

```go
package main

import (
    "fmt"
    "log"

    "github.com/flamingo-stack/fleetmdm/ee/fleetd_chrome/augeas"
)

func main() {
    lensPath, err := augeas.CopyLenses("/tmp/augeas")
    if err != nil {
        log.Fatalf("failed to copy lenses: %v", err)
    }
    fmt.Printf("Augeas lenses available at: %s\n", lensPath)
    // lensPath == "/tmp/augeas/lenses"
}
```

## Notes

- The output directory is **fully replaced** on each call (`os.RemoveAll` + `os.MkdirAll`), ensuring no stale lens files persist between deployments.
- Lens files are written with mode `0644`; the parent directory is created with mode `0755`.
- The `nolint:gosec` annotation suppresses the `G302` lint warning for the intentionally permissive file-creation flags.
