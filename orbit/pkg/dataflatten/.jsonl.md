Parses JSON Lines (JSONL) data from a file or `io.Reader`, decoding each newline-delimited JSON object and flattening the resulting collection into `[]Row`.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `JsonlFile` | `(file string, opts ...FlattenOpts) ([]Row, error)` | Opens a JSONL file by path and delegates to `Jsonl` |
| `Jsonl` | `(r io.Reader, opts ...FlattenOpts) ([]Row, error)` | Streams and decodes JSONL records, then flattens the accumulated objects |

## Usage Example

```go
// From a file path
rows, err := dataflatten.JsonlFile("/var/log/events.jsonl",
    dataflatten.WithQuery([]string{"name"}),
)

// From any io.Reader (e.g. HTTP response body)
rows, err := dataflatten.Jsonl(resp.Body)
if err != nil {
    log.Fatal(err)
}
for _, row := range rows {
    fmt.Println(row)
}
```

## Notes

- Based on [kolide/launcher](https://github.com/kolide/launcher/pkg/osquery/tables) osquery table helpers.
- Uses `json.NewDecoder` for streaming — memory-efficient for large JSONL files since objects are decoded one at a time before being passed to `Flatten`.
- Decoding stops cleanly at `io.EOF`; any other decoder error is wrapped and returned.
- All `FlattenOpts` (filtering, querying, etc.) are forwarded to the shared `Flatten` function.
