Parses delimiter-separated key-value text data into flattened rows, supporting both single-record and multi-record (duplicate key) splitting strategies.

## Key Components

- **`dataFunc`** — Function type signature for data parsers: `func([]byte, ...FlattenOpts) ([]Row, error)`
- **`recordSplittingStrategy`** — Enum controlling how records are grouped (`None`, `DuplicateKeys`)
- **`StringDelimitedFunc`** — Factory that returns the appropriate `dataFunc` based on the chosen splitting strategy
- **`singleRecordFunc`** — Treats the entire input as one record; each line is an independent key-value pair
- **`duplicateKeyFunc`** — Groups lines into records by detecting when a key repeats, then starts a new record

## Usage Example

```go
// Single-record: entire input is one record (e.g., "key: value" lines)
fn := StringDelimitedFunc(":", None)
rows, err := fn([]byte("hostname: myhost\nos: linux"), WithQuery("hostname"))

// Multi-record: group lines into records by duplicate key detection
fn := StringDelimitedFunc("=", DuplicateKeys)
rows, err := fn([]byte(`
name=alice
role=admin
name=bob
role=user
`))
// Produces two records: {name:alice, role:admin} and {name:bob, role:user}
```

## Record Splitting Strategies

| Strategy | Behaviour |
|---|---|
| `None` | All key-value pairs belong to a single record |
| `DuplicateKeys` | A repeated key signals the end of the current record and the start of a new one |

> **Note:** `DuplicateKeys` requires that records are contiguous in the input and that at least one field appears in every record before any sparse/optional fields.
