Parses INI configuration files and raw INI byte data into flattened row structures, handling boolean canonicalization for ini-style truthy/falsy string values.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `IniFile` | func | Parses an INI file from a filesystem path |
| `Ini` | func | Parses raw INI data from a `[]byte` slice |
| `flattenIni` | func (internal) | Core parser using `go-ini`; accepts either a file path or `[]byte` via `interface{}` |
| `iniToBool` | func (internal) | Canonicalizes ini boolean strings (`yes`, `ON`, `True`, etc.) to native Go `bool` |

## Usage Example

**From a file path:**

```go
rows, err := dataflatten.IniFile("/etc/myapp/config.ini",
    dataflatten.WithQuery("DEFAULT/timeout"),
)
if err != nil {
    log.Fatal(err)
}
```

**From raw bytes:**

```go
raw := []byte(`
[database]
enabled = yes
host    = localhost
port    = 5432
`)

rows, err := dataflatten.Ini(raw)
if err != nil {
    log.Fatal(err)
}

for _, row := range rows {
    fmt.Println(row)
}
```

## Notes

- TOML parsing is intentionally avoided — INI files lack quoted strings and contain irregular whitespace that breaks TOML parsers.
- Boolean detection covers the full set of truthy/falsy variants recognised by `go-ini` (e.g. `t`, `T`, `true`, `TRUE`, `YES`, `yes`, `y`, `ON`, `on` and their negatives). All other values remain as strings.
- Sections and keys are iterated manually rather than using `section.KeysHash()` to allow per-value boolean canonicalization before passing the result to `Flatten`.
