Provides tools to flatten complex nested data structures (arrays, maps, plists) into a simplified key-path/value row format, with optional filtering and rewriting via a query syntax.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Flattener` | struct | Core stateful object managing flattening state: query terms, accumulated rows, logging options |
| `Row` | type | Output unit — a path/value pair produced during traversal |
| `FlattenOpts` | type | Functional option type for configuring `Flattener` |
| `Flatten()` | func | Entry point — constructs a `Flattener`, applies options, and triggers recursion |
| `IncludeNulls()` | option | Include `nil` values in output instead of skipping them |
| `WithNestedPlist()` | option | Recursively expand embedded plist blobs found in values |
| `WithLogger()` | option | Attach a `zerolog.Logger` instance |
| `WithDebugLogging()` | option | Enable verbose debug-level log output |
| `WithQuery()` | option | Supply a query path (e.g. `["data", "users", "name=>A*"]`) for filtering/rewriting |
| `descend()` | method | Recursive workhorse — dispatches on `[]interface{}`, `map[string]interface{}`, `[]byte`, `string`, etc. |
| `handleStringLike()` | method | Converts leaf values to strings and appends matching `Row`s |
| `descendMaybePlist()` | method | Attempts to parse `[]byte` / `string` values as embedded plists before treating as plain strings |
| `queryMatchArrayElement()` | method | Matches array elements by index, map key presence, or `key=>value` pattern |
| `queryMatchString()` | method | Wildcard-aware string comparison (prefix/postfix `*`) |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/dataflatten"

data := map[string]interface{}{
    "users": []interface{}{
        map[string]interface{}{"id": "u1", "name": "Alice"},
        map[string]interface{}{"id": "u2", "name": "Bob"},
    },
}

// Return all users whose name starts with "A", rewriting the array
// keyed by "id"
rows, err := dataflatten.Flatten(
    data,
    dataflatten.WithQuery([]string{"users", "#id", "name=>A*"}),
)
if err != nil {
    log.Fatal(err)
}

for _, row := range rows {
    fmt.Println(row.StringPath("/"), "=", row.Value)
    // e.g. users/u1/name = Alice
}
```

### Query Syntax Reference

```text
*                    Wildcard — match anything at this level
data/users           Descend into nested keys
data/users/0         Select first array element by index
data/users/name=>A*  Filter array elements where name starts with "A"
data/users/#id       Rewrite array-of-maps as a map keyed by "id"
```
