Parses XML data into flattened rows, supporting both file-based and in-memory byte slice input. Based on the [kolide/launcher](https://github.com/kolide/launcher) osquery tables package.

## Key Components

| Function | Description |
|---|---|
| `XmlFile(file string, opts ...FlattenOpts)` | Opens and parses an XML file by path, returning flattened rows |
| `Xml(rawdata []byte, opts ...FlattenOpts)` | Parses raw XML bytes in memory, returning flattened rows |

Both functions use the [`mxj`](https://github.com/clbanning/mxj) library for XML-to-map conversion, then delegate to `Flatten()` for row extraction.

## Usage Example

```go
// Parse XML from a file
rows, err := dataflatten.XmlFile("/etc/config.xml", dataflatten.WithQuery("key"))
if err != nil {
    log.Fatal(err)
}

// Parse XML from raw bytes
data := []byte(`<config><key>value</key></config>`)
rows, err := dataflatten.Xml(data)
if err != nil {
    log.Fatal(err)
}

for _, row := range rows {
    fmt.Println(row)
}
```

## Notes

- Both functions accept variadic `FlattenOpts` for filtering and query control
- `XmlFile` wraps OS-level file errors directly; `Xml` wraps `mxj` parse errors with context
- Source: [`xml.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/xml.go)
