Parses and flattens JSON data (from raw bytes or a file) into a slice of `Row` values using the `dataflatten` package.

## Key Components

- **`JsonFile(file string, opts ...FlattenOpts) ([]Row, error)`** — Reads a JSON file from disk and delegates to `Json` for flattening.
- **`Json(rawdata []byte, opts ...FlattenOpts) ([]Row, error)`** — Unmarshals raw JSON bytes into a generic `interface{}` and passes the result to `Flatten`.

## Usage Example

```go
// Flatten a JSON file
rows, err := dataflatten.JsonFile("/etc/config.json")
if err != nil {
    log.Fatal(err)
}

// Flatten raw JSON bytes with options
data := []byte(`{"host": "localhost", "port": 8080}`)
rows, err := dataflatten.Json(data, dataflatten.WithQuery("host"))
if err != nil {
    log.Fatal(err)
}

for _, row := range rows {
    fmt.Println(row)
}
```

## Notes

- Based on [`github.com/kolide/launcher/pkg/osquery/tables`](https://github.com/kolide/launcher).
- Both functions accept variadic `FlattenOpts` for filtering or querying the flattened output.
- JSON unmarshalling errors are wrapped with context for easier debugging.
