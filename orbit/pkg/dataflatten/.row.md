Defines the `Row` record type used throughout the `dataflatten` package to represent a single flattened data entry as a path-value pair.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Row` | struct | Core record holding a hierarchical path (`[]string`) and a scalar `Value` string |
| `NewRow` | func | Constructor that deep-copies the path slice to avoid pointer aliasing bugs |
| `StringPath` | method | Joins the path segments into a single string using the provided separator |
| `ParentKey` | method | Splits the path into a parent prefix string and the final key segment |

## Usage Example

```go
// Construct a row representing a nested key, e.g. system.os.version = "14.0"
row := dataflatten.NewRow([]string{"system", "os", "version"}, "14.0")

// "system/os/version"
fullPath := row.StringPath("/")

// parent = "system/os", key = "version"
parent, key := row.ParentKey("/")
```

**`ParentKey` edge cases:**

```go
// Empty path → both values are empty strings
empty := dataflatten.NewRow([]string{}, "val")
parent, key := empty.ParentKey("/") // "", ""

// Single-element path → parent is empty, key is the sole element
single := dataflatten.NewRow([]string{"hostname"}, "myhost")
parent, key = single.ParentKey("/") // "", "hostname"
```

## Notes

- Based on [`github.com/kolide/launcher`](https://github.com/kolide/launcher) osquery table helpers.
- The explicit path copy in `NewRow` guards against slice mutation bugs that can occur when callers reuse or modify the original path slice across iterations.
- Source: [`dataflatten/row.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/dataflatten/row.go)
