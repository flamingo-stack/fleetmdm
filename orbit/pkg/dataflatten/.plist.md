Parses Apple Property List (plist) files and raw plist byte data into flattened row structures using the `dataflatten` package.

## Key Components

- **`PlistFile(file string, opts ...FlattenOpts) ([]Row, error)`** — Reads a plist file from disk by path, then delegates to `Plist` for parsing and flattening.
- **`Plist(rawdata []byte, opts ...FlattenOpts) ([]Row, error)`** — Unmarshals raw plist bytes using `howett.net/plist`, then passes the resulting data through `Flatten` to produce `[]Row`.

## Usage Example

```go
// Flatten a plist file from disk
rows, err := dataflatten.PlistFile("/Library/Preferences/com.apple.TimeMachine.plist")
if err != nil {
    log.Fatal(err)
}

// Flatten raw plist bytes with a query filter
rows, err := dataflatten.Plist(rawData, dataflatten.WithQuery("BackupAlias"))
if err != nil {
    log.Fatal(err)
}

for _, row := range rows {
    fmt.Println(row.Path, row.Value)
}
```

## Notes

- Based on [`kolide/launcher`](https://github.com/kolide/launcher/tree/main/pkg/osquery/tables) plist table implementation.
- Supports all plist formats handled by `howett.net/plist` (XML, binary, OpenStep, GNUStep).
- Accepts variadic `FlattenOpts` for filtering or transforming the flattened output (e.g., query selectors).
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/dataflatten/plist.go)
