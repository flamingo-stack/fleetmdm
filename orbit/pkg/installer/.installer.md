Orchestrates software installation on Fleet-managed hosts by coordinating installer downloads, pre-condition checks, script execution, and result reporting with retry logic and osquery integration.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Runner` | struct | Core orchestrator holding osquery client, orbit client, config, and execution state |
| `NewRunner` | func | Constructs a `Runner` with defaults for timeouts, retry options, and logging |
| `Runner.Run` | method | Entry point called by the orbit config loop; connects osquery and dispatches installations |
| `Runner.run` | method | Iterates pending installer IDs, calls `installSoftware`, and saves results with retry |
| `Runner.installSoftware` | method | Fetches installer details, evaluates pre-conditions, checks script enablement, and routes to single or retried install |
| `Runner.installWithRetry` | method | Wraps `attemptInstall` in a loop up to `MaxRetries+1` times, reporting intermediate failures |
| `Runner.preConditionCheck` | method | Runs an osquery SQL query to gate installation on a host state condition |
| `Runner.handleInstallerNotFound` | method | Silently retries 404 responses within a 5-minute window, then emits a synthetic failure payload |
| `Client` | interface | API surface required from `fleet.OrbitClient` (details, download, save result) |
| `QueryClient` | interface | Minimal osquery interface used for pre-condition queries |

## Usage Example

```go
runner := installer.NewRunner(
    orbitClient,
    "/var/osquery/osquery.em",
    func() bool { return true }, // scripts enabled
    "/opt/orbit",
)

// Called automatically by the orbit config loop
if err := runner.Run(orbitConfig); err != nil {
    log.Error().Err(err).Msg("software installer runner failed")
}
```
