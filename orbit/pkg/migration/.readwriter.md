Manages reading, writing, and monitoring of the MDM migration tracking file used by Fleet orbit to persist migration state across processes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ReadWriter` | struct | Core type holding the directory path and full file path for the migration file |
| `NewReadWriter` | constructor | Creates a `ReadWriter` given a directory path and filename |
| `FileWatcher` | interface | Read-only view exposing `GetMigrationType`, `FileExists`, and `DirExists` |
| `fileWatcher` | struct | Private `FileWatcher` implementation backed by a `ReadWriter` |
| `Dir` | func | Returns the platform-specific default cache directory (`~/Library/Caches/com.fleetdm.orbit`) |

### `ReadWriter` Methods

| Method | Description |
|--------|-------------|
| `SetMigrationFile(typ string)` | Writes the migration type to disk; creates parent directories as needed and sets world-readable permissions |
| `RemoveFile()` | Deletes the migration file; no-ops if the file does not exist |
| `GetMigrationType()` | Returns the migration type string from the file, or `""` if absent |
| `FileExists()` | Reports whether the migration file exists |
| `DirExists()` | Reports whether the migration directory exists |
| `NewFileWatcher()` | Returns a read-only `FileWatcher` backed by this `ReadWriter` |

## Usage Example

```go
dir, err := migration.Dir()
if err != nil {
    log.Fatal(err)
}

rw := migration.NewReadWriter(dir, "migration_type")

// Write migration type
if err := rw.SetMigrationFile("automatic"); err != nil {
    log.Fatal(err)
}

// Read it back via a FileWatcher (read-only interface)
watcher := rw.NewFileWatcher()
typ, err := watcher.GetMigrationType()
if err != nil {
    log.Fatal(err)
}
fmt.Println("Migration type:", typ) // "automatic"

// Clean up when migration completes
if err := rw.RemoveFile(); err != nil {
    log.Fatal(err)
}
```
