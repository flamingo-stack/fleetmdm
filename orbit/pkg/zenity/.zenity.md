Linux dialog interface using the `zenity` GTK dialog tool, implementing the `dialog.Dialog` interface for displaying GUI prompts to the active desktop user.

## Key Components

| Component | Description |
|-----------|-------------|
| `Zenity` struct | Wraps zenity command execution with an injectable `cmdWithOutput` function for testability |
| `New()` | Constructor returning a `*Zenity` instance wired to the real `execCmdWithOutput` |
| `ShowEntry()` | Displays a text-input dialog; returns user input or `ErrCanceled`, `ErrTimeout`, `ErrUnknown` |
| `ShowInfo()` | Displays an information dialog; returns `ErrTimeout` or `ErrUnknown` on failure |
| `execCmdWithOutput()` | Resolves the active GUI user and executes `zenity` via `execuser.RunWithOutput` |

## Usage Example

```go
z := zenity.New()

// Show a password prompt
input, err := z.ShowEntry(dialog.EntryOptions{
    Title:    "Authentication Required",
    Text:     "Enter your password:",
    HideText: true,
    TimeOut:  30 * time.Second,
})
if errors.Is(err, dialog.ErrCanceled) {
    log.Println("user canceled")
} else if errors.Is(err, dialog.ErrTimeout) {
    log.Println("dialog timed out")
} else if err != nil {
    log.Println("unexpected error:", err)
} else {
    log.Printf("received input: %s", input)
}

// Show an info dialog
err = z.ShowInfo(dialog.InfoOptions{
    Title:   "Update Complete",
    Text:    "Your device has been updated successfully.",
    TimeOut: 60 * time.Second,
})
```

**Exit code mapping:** zenity exit code `1` → `ErrCanceled`, `5` → `ErrTimeout`, anything else → `ErrUnknown`.

## Notes

- Requires an active GUI session; `execCmdWithOutput` will error if no desktop user is logged in via `user.UserLoggedInViaGui()`
- Trailing newlines are stripped from zenity output automatically
- `cmdWithOutput` is exported on the struct for easy mocking in unit tests
