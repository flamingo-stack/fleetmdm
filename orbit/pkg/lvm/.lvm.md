Provides LVM disk discovery utilities for identifying the physical partition hosting the root filesystem on Linux systems using LVM volumes.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `BlockDevice` | struct | Represents a block device parsed from `lsblk` JSON output, supporting nested children for device trees |
| `FindRootDisk` | func | Entry point — runs `lsblk --json` and returns the `/dev/<name>` path of the physical root partition |
| `rootDiskFromJson` | func | Parses `lsblk` JSON, locates the root partition, and traces up to its nearest `part`-type parent |
| `findRootPartition` | func | Recursively searches the device tree for the device mounted at `/` |
| `searchForRoot` | func | Handles both legacy `mountpoint` (single string) and modern `mountpoints` (array) fields |
| `findParentPartitionOfTypePart` | func | BFS traversal upward through the device tree to find the nearest ancestor of type `part` |

## Usage Example

```go
partition, err := lvm.FindRootDisk()
if err != nil {
    log.Fatalf("could not determine root disk: %v", err)
}
fmt.Println(partition) // e.g. /dev/sda2
```

## Notes

- Handles both older Ubuntu systems (single `mountpoint` string field) and modern kernels (`mountpoints` array) via `BlockDevice`.
- `FindRootDisk` requires `lsblk` to be available on the host — typically present on all standard Linux distributions.
- The parent-lookup uses BFS rather than simple recursion to correctly handle deep LVM stacks (e.g. `disk → part → lvm → dm`).
