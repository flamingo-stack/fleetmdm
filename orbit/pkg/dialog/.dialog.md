Defines the core `dialog` package interface and types for displaying UI dialogs to end users on managed hosts.

## Key Components

**Errors**
- `ErrCanceled` — user dismissed the dialog via cancel
- `ErrTimeout` — dialog closed automatically after timeout
- `ErrUnknown` — catch-all for unexpected errors

**Interface**
- `Dialog` — primary interface with two methods:
  - `ShowEntry(opts EntryOptions) ([]byte, error)` — prompts user for text input (e.g. passwords)
  - `ShowInfo(opts InfoOptions) error` — displays an informational message

**Option Types**
- `EntryOptions` — configures entry dialogs: `Title`, `Text`, `HideText`, `TimeOut`
- `InfoOptions` — configures info dialogs: `Title`, `Text`, `TimeOut`
- `ProgressOptions` — configures progress dialogs: `Title`, `Text` (no `TimeOut`)

## Usage Example

```go
var d dialog.Dialog // inject concrete implementation

// Prompt for a password
result, err := d.ShowEntry(dialog.EntryOptions{
    Title:    "Authentication Required",
    Text:     "Enter your password:",
    HideText: true,
    TimeOut:  30 * time.Second,
})
if errors.Is(err, dialog.ErrCanceled) {
    // user dismissed
}
if errors.Is(err, dialog.ErrTimeout) {
    // dialog expired
}

// Display a notification
err = d.ShowInfo(dialog.InfoOptions{
    Title:   "Update Complete",
    Text:    "Your device has been updated successfully.",
    TimeOut: 10 * time.Second,
})
```

Concrete implementations of `Dialog` are provided per platform (e.g. macOS, Windows) and injected at runtime. See the full source at [`ee/desktop/dialog/dialog.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/desktop/dialog/dialog.go).
