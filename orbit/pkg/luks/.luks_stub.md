Stub implementations of LUKS operations for non-Linux build targets, ensuring cross-platform compilation without Linux-specific dependencies.

## Key Components

- **`LuksRunner.Run`** – No-op implementation of the `Run` method; returns `nil` on all non-Linux platforms.
- **`GetLuksDump`** – No-op implementation that returns `nil, nil`; satisfies the interface on non-Linux platforms without performing any disk operations.

## Usage Example

```go
// No explicit usage required — the Go build system selects this file
// automatically on non-Linux targets (e.g., macOS, Windows).

//go:build !linux

runner := &LuksRunner{}
err := runner.Run(orbitConfig) // Returns nil; no-op on non-Linux

dump, err := GetLuksDump(ctx, "/dev/sda1") // Returns nil, nil on non-Linux
```

## Notes

- Controlled by the build constraint `//go:build !linux`, so this file is compiled only on non-Linux platforms.
- The corresponding Linux implementation lives alongside this file and is selected via the inverse build tag.
