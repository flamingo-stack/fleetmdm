Provides core LUKS2 encryption type detection and escrow data structures for the Fleet orbit agent's Linux disk encryption workflow.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `LuksDump` | Parsed representation of a `cryptsetup luksDump` JSON output, containing keyslots and tokens |
| `Keyslot` / `KDF` | Keyslot metadata, primarily holding the KDF salt |
| `Token` | LUKS2 token entry; only the `type` field is inspected |
| `LuksResponse` | Escrow payload sent to the Fleet server: passphrase, key slot, salt, and any error |
| `LuksRunner` | Orchestrates the escrow flow, holding a `KeyEscrower` and a dialog notifier |

### Constants

| Constant | Value | Purpose |
|----------|-------|---------|
| `EncryptionTypePassphrase` | `"passphrase"` | Default/fallback type |
| `EncryptionTypeTPM2` | `"tpm2"` | systemd-cryptenroll TPM2 token detected |
| `EncryptionTypeFIDO2` | `"fido2"` | systemd-cryptenroll FIDO2 token detected |
| `EncryptionTypeRecovery` | `"recovery"` | systemd-cryptenroll recovery token detected |

### Functions

- **`DetectEncryptionType(dump *LuksDump) string`** — Inspects a `LuksDump`'s tokens and returns the highest-priority encryption type. Priority: `tpm2 > fido2 > recovery > passphrase`.
- **`New(escrower KeyEscrower) *LuksRunner`** — Constructs a `LuksRunner` with the given escrow backend.
- **`extractJSON(input []byte) ([]byte, error)`** — Internal helper that extracts the first `{...}` JSON object from raw command output.

### Interfaces

- **`KeyEscrower`** — Implemented by callers to deliver a `LuksResponse` to the Fleet server.

## Usage Example

```go
dump := &luks.LuksDump{
    Tokens: map[string]luks.Token{
        "0": {Type: "systemd-tpm2"},
    },
}

encType := luks.DetectEncryptionType(dump)
// encType == "tpm2"

runner := luks.New(myEscrower)
```
