Stateful exponential backoff tracker for agent-to-server communication paths. Unlike blocking retry utilities, this package computes polling intervals so callers can integrate backoff into existing ticker-based loops without blocking.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Tracker` | struct | Per-path backoff state; safe for concurrent use |
| `New` | func | Creates a `Tracker` with a base interval and max backoff ceiling |
| `RecordSuccess` | method | Resets failure count and exits backoff state |
| `RecordFailure` | method | Increments consecutive failures and enters backoff state |
| `Interval` | method | Returns the next wait duration: `min(base * 2^n + jitter, maxBackoff)` |
| `InBackoff` | method | Reports whether at least one unresolved failure exists |
| `ConsecutiveFailures` | method | Returns the current failure count |
| `TimeSinceBackoffStarted` | method | Duration since backoff began, or `0` if not in backoff |
| `jitter` | func (internal) | Adds up to 10% random noise to prevent thundering-herd |

**Constants:** `maxShift = 20` caps the bit-shift exponent to prevent integer overflow; `minInterval = 1s` guarantees `Interval` never returns a value that would panic `time.Ticker`.

## Usage Example

```go
tracker := backoff.New(30*time.Second, 10*time.Minute)

ticker := time.NewTicker(tracker.Interval())
defer ticker.Stop()

for range ticker.C {
    if err := pingServer(); err != nil {
        tracker.RecordFailure()
    } else {
        tracker.RecordSuccess()
    }

    // Reset ticker to the new computed interval.
    ticker.Reset(tracker.Interval())

    if tracker.InBackoff() {
        log.Printf("in backoff: %d failures over %s",
            tracker.ConsecutiveFailures(),
            tracker.TimeSinceBackoffStarted())
    }
}
```

Each `Tracker` is independent — a healthy communication path cannot reset the backoff of a failing one.
