Unix-specific implementation of stderr redirection for capturing panic logs to a file using low-level file descriptor duplication.

## Key Components

- **`redirectStderr(f *os.File) (UndoFunction, error)`** — Redirects `os.Stderr` to the provided file using `unix.Dup`/`unix.Dup2`. Returns an `UndoFunction` closure that restores the original stderr file descriptor when called.

**Build Constraint:** Active on all platforms except `windows`, `solaris`, and `plan9`.

## Usage Example

```go
logFile, err := os.OpenFile("panic.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
if err != nil {
    log.Fatal(err)
}
defer logFile.Close()

undo, err := redirectStderr(logFile)
if err != nil {
    log.Fatal(err)
}
defer undo()

// Panics and stderr output now written to panic.log
```

## Notes

- Uses `unix.Dup` to preserve the original stderr fd before overwriting it, enabling clean restoration.
- The returned `UndoFunction` calls `unix.Dup2` to restore the saved fd, then closes the temporary duplicate with `unix.Close`.
