A simple test/demo program that demonstrates the `paniclog` package's ability to redirect stderr output (including panic messages) to a file instead of the console.

## Key Components

- **`main()`** — Entry point that exercises the `paniclog.RedirectStderr` functionality end-to-end

## Behavior

1. Creates a log file named `test.log`
2. Redirects stderr to that file using `paniclog.RedirectStderr`, which returns an undo function
3. Closes the file handle after redirection is established
4. If the `UNDO_PANICLOG` environment variable is set, calls `undo()` to restore stderr to its original destination
5. Triggers a `panic`, which will land in `test.log` (or back on the console if undone)

## Usage Example

```bash
# Run normally — panic output goes to test.log
go run main.go

# Run with undo — panic output goes back to console
UNDO_PANICLOG=1 go run main.go

# Inspect captured output
cat test.log
```

## Notes

- The `undo()` call is annotated with `//nolint:errcheck`, indicating the error return is intentionally ignored in this demo context
- This file serves as a functional smoke test for the `go-paniclog` package and is not intended for production use
