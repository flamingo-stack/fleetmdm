Fallback stub for unsupported operating systems that cannot redirect stderr to a file for panic log capture.

## Key Components

- **`redirectStderr(f *os.File) (UndoFunction, error)`** — Always returns `nil` and an error on platforms not explicitly supported by other build-tagged implementations.

## Build Constraints

This file is compiled only when the target OS is **none** of the following: `windows`, `darwin`, `dragonfly`, `freebsd`, `linux`, `nacl`, `netbsd`, `openbsd`. It serves as the catch-all fallback for exotic or future platforms.

## Usage Example

```go
undo, err := redirectStderr(logFile)
if err != nil {
    // On unsupported platforms, err will be:
    // "Can't redirect stderr to file"
    log.Printf("panic log redirect not supported: %v", err)
    return
}
defer undo()
```

## Notes

- This is part of the `paniclog` package's platform abstraction layer. Each supported OS has its own implementation file with an appropriate build tag, while this file ensures the package compiles cleanly on any unsupported platform.
