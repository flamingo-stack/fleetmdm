Redirects stderr output to a specified file, primarily to capture panic logs, and provides a mechanism to revert the redirection.

## Key Components

- **`UndoFunction`** — A function type (`func() error`) returned by `RedirectStderr` to restore stderr to its original destination.
- **`RedirectStderr(f *os.File)`** — Redirects stderr to the provided file, delegating to the platform-specific `redirectStderr` implementation. Returns an `UndoFunction` and any error encountered.

## Usage Example

```go
package main

import (
    "log"
    "os"

    "github.com/flamingo-stack/fleetmdm/orbit/pkg/paniclog"
)

func main() {
    f, err := os.OpenFile("panic.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
    if err != nil {
        log.Fatal(err)
    }
    defer f.Close()

    undo, err := paniclog.RedirectStderr(f)
    if err != nil {
        log.Fatal("failed to redirect stderr:", err)
    }
    defer undo()

    // Panics and stderr output are now written to panic.log
}
```

## Notes

- The actual redirection logic lives in a platform-specific `redirectStderr` function (not shown here), allowing OS-level differences (e.g., Windows vs. Unix) to be handled separately.
- Closing the file after calling `RedirectStderr` is safe; the OS-level redirect is established before the function returns.
- Any other stderr output (not just panics) will also be written to the target file while the redirect is active.
