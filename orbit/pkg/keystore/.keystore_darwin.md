Darwin-only keystore implementation (`darwin && cgo`) that stores, retrieves, and manages Fleet enrollment secrets in the macOS Keychain using the Security and CoreFoundation C frameworks via CGo.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `service` | `const` | Keychain service identifier: `com.fleetdm.fleetd.enroll.secret` |
| `serviceStringRef` | `C.CFStringRef` | Package-level CFString for the service name |
| `mu` | `sync.Mutex` | Guards all Keychain operations for thread safety |
| `Supported()` | `func` | Always returns `true` on Darwin builds |
| `Name()` | `func` | Returns `"default keychain"` |
| `AddSecret()` | `func` | Inserts a new generic password item via `SecItemAdd` |
| `UpdateSecret()` | `func` | Updates an existing item's data via `SecItemUpdate` |
| `GetSecret()` | `func` | Retrieves the secret via `SecItemCopyMatching`; returns `"", nil` if not found |
| `deleteSecret()` | `func` | Removes the item via `SecItemDelete`; unexported, used only by tests |
| `stringToCFString()` | `func` | Converts a Go `string` to a `CFStringRef` (UTF-8) |
| `releaseCFString()` | `func` | Releases memory held by a `CFStringRef` |

## Usage Example

```go
package main

import (
    "fmt"
    "log"

    "github.com/flamingo-stack/fleetmdm/orbit/pkg/keystore"
)

func main() {
    if !keystore.Supported() {
        log.Fatal("keystore not supported on this platform")
    }
    fmt.Println("Backend:", keystore.Name()) // "default keychain"

    // Store a new enrollment secret
    if err := keystore.AddSecret("my-fleet-enroll-secret"); err != nil {
        log.Fatal("add:", err)
    }

    // Retrieve it later (no user prompt needed for app-added items)
    secret, err := keystore.GetSecret()
    if err != nil {
        log.Fatal("get:", err)
    }
    fmt.Println("Secret:", secret)

    // Rotate the secret in place
    if err := keystore.UpdateSecret("new-fleet-enroll-secret"); err != nil {
        log.Fatal("update:", err)
    }
}
```

> **Notes:**
> - All Keychain calls are serialised through `mu` to prevent concurrent CGo races.
> - Secrets added by other applications or users may require explicit macOS authorization to read.
> - `deleteSecret` is unexported because CGo cannot be used directly in `_test.go` files; the function lives here and is called via a test helper.
