Windows-specific keystore implementation that stores and retrieves Fleet enrollment secrets using the Windows Credential Manager via the `wincred` library.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `service` | `var string` | Credential Manager target name (`com.fleetdm.fleetd.enroll.secret`); overridable in tests |
| `mu` | `var sync.Mutex` | Guards all Credential Manager operations |
| `Supported()` | `func bool` | Always returns `true` on Windows |
| `Name()` | `func string` | Returns `"Credential Manager"` |
| `AddSecret(secret string)` | `func error` | Writes (or overwrites) the enrollment secret |
| `UpdateSecret(secret string)` | `func error` | Alias for `AddSecret` |
| `GetSecret()` | `func (string, error)` | Reads the secret; returns `"", nil` if not found |

## Usage Example

```go
// Check platform support
if keystore.Supported() {
    fmt.Println("Backend:", keystore.Name()) // "Credential Manager"
}

// Store an enrollment secret
if err := keystore.AddSecret("my-fleet-enroll-token"); err != nil {
    log.Fatal(err)
}

// Retrieve it later
secret, err := keystore.GetSecret()
if err != nil {
    log.Fatal(err)
}
if secret == "" {
    log.Println("No secret stored yet")
}

// Update to a new secret
if err := keystore.UpdateSecret("new-fleet-enroll-token"); err != nil {
    log.Fatal(err)
}
```

## Notes

- **Build constraint:** Only compiled on `windows` (`//go:build windows`).
- **`ERROR_NOT_FOUND` handling:** `GetSecret` unwraps `syscall.Errno` to distinguish a missing credential (returns `"", nil`) from a genuine error.
- **Thread safety:** All read/write operations are protected by `mu` to prevent concurrent Credential Manager access.
- **Secret trimming:** `AddSecret` strips leading/trailing whitespace and rejects empty strings.
