Stub implementation of the `keystore` package for platforms where native keychain support is unavailable (non-Darwin/CGO and non-Windows builds).

## Key Components

| Function | Returns | Description |
|---|---|---|
| `Supported()` | `bool` | Always returns `false` — keystore is not available on this platform |
| `Name()` | `string` | Returns `"not implemented"` |
| `AddSecret(secret string)` | `error` | No-op stub; always returns an error |
| `UpdateSecret(secret string)` | `error` | No-op stub; always returns an error |
| `GetSecret()` | `(string, error)` | No-op stub; always returns an empty string and error |

## Build Constraints

This file is compiled only when **both** of the following are true:

- The target is **not** `darwin` with `cgo` enabled
- The target is **not** `windows`

```go
//go:build !(darwin && cgo) && !windows
```

On Darwin (with CGO) or Windows, platform-specific implementations replace this stub.

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/fleetmdm/keystore"
)

func main() {
    if !keystore.Supported() {
        fmt.Printf("Keystore backend (%s) unavailable on this platform\n", keystore.Name())
        return
    }

    if err := keystore.AddSecret("my-api-token"); err != nil {
        fmt.Println("Error:", err)
    }
}
```

> **Note:** All operations return `errors.New("not implemented")` on unsupported platforms. Always check `keystore.Supported()` before calling any keystore operation to avoid unhandled errors at runtime.
