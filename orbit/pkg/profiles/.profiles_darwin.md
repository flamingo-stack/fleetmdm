Darwin-only implementation for querying macOS device configuration profiles and MDM enrollment status using the `/usr/bin/profiles` command-line tool.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `GetFleetdConfig` | func | Reads and parses the Fleet agent configuration from a device-level profile using `mobileconfig.FleetdConfigPayloadIdentifier` |
| `GetCustomEnrollmentProfileEndUserEmail` | func | Extracts the end-user email from a custom Fleet enrollment profile |
| `getProfilePayloadContent[T]` | generic func | Generic helper that runs `profiles -C` and unmarshals plist output into a typed struct |
| `IsEnrolledInMDM` | func | Returns MDM enrollment status and server URL by parsing `profiles status -type enrollment` output |
| `ParseMDMEnrollmentStatus` | func | Reports whether the device was enrolled via DEP |
| `CheckAssignedEnrollmentProfile` | func | Validates that the assigned DEP enrollment profile's server hostname matches an expected URL |
| `execProfileCmd` | var (func) | Executes `/usr/bin/profiles -C -o stdout-xml`; overridable in tests |
| `getMDMInfoFromProfilesCmd` | var (func) | Executes `profiles status -type enrollment`; overridable in tests |
| `showEnrollmentProfileCmd` | var (func) | Executes `profiles show -type enrollment` via `launchctl asuser`; overridable in tests |

## Usage Example

```go
// Check if the device is enrolled in an MDM
enrolled, serverURL, err := profiles.IsEnrolledInMDM()
if err != nil {
    log.Fatal(err)
}
if enrolled {
    fmt.Println("Enrolled in MDM at:", serverURL)
}

// Read Fleet agent config from the installed profile
cfg, err := profiles.GetFleetdConfig()
if err != nil {
    log.Fatal(err)
}
fmt.Println("Fleet server URL:", cfg.FleetURL)

// Verify DEP profile is assigned to the expected server
err = profiles.CheckAssignedEnrollmentProfile("https://fleet.example.com")
if err != nil {
    log.Println("Profile mismatch:", err)
}
```

> **Note:** All three command executor variables (`execProfileCmd`, `getMDMInfoFromProfilesCmd`, `showEnrollmentProfileCmd`) are package-level `var` functions, making them straightforward to replace in unit tests without spawning real processes.
