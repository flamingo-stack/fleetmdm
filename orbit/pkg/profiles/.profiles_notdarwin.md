Provides stub implementations of macOS MDM profile functions for non-Darwin platforms, returning `ErrNotImplemented` for all operations.

## Key Components

| Function | Returns | Description |
|---|---|---|
| `GetFleetdConfig()` | `(*fleet.MDMAppleFleetdConfig, error)` | Stub for retrieving Fleet MDM Apple configuration |
| `IsEnrolledInMDM()` | `(bool, string, error)` | Stub for checking MDM enrollment status |
| `CheckAssignedEnrollmentProfile()` | `error` | Stub for validating an assigned enrollment profile URL |
| `GetCustomEnrollmentProfileEndUserEmail()` | `(string, error)` | Stub for retrieving the end-user email from a custom enrollment profile |

## Build Constraint

This file is compiled for all platforms **except** Darwin (`//go:build !darwin`). The Darwin-specific implementations live in the corresponding `profiles_darwin.go` file.

## Usage Example

```go
// On non-Darwin platforms, all calls return ErrNotImplemented
config, err := profiles.GetFleetdConfig()
if err != nil {
    // err == profiles.ErrNotImplemented on Linux/Windows
    log.Printf("MDM profiles not supported on this platform: %v", err)
}

enrolled, serverURL, err := profiles.IsEnrolledInMDM()
// enrolled == false, serverURL == "", err == profiles.ErrNotImplemented
```

## Notes

- All functions return zero values alongside `ErrNotImplemented`, allowing callers to handle unsupported platforms gracefully without panicking.
- This pattern enables cross-platform compilation while keeping MDM logic isolated to Darwin builds.
