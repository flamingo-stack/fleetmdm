Defines sentinel error values for the `profiles` package, used for consistent error handling across profile operations.

## Key Components

| Error | Description |
|-------|-------------|
| `ErrNotFound` | Returned when a requested profile does not exist |
| `ErrNotImplemented` | Returned when a profile operation is unsupported on the current platform |

## Usage Example

```go
profile, err := profiles.Get("com.example.config")
if errors.Is(err, profiles.ErrNotFound) {
    // handle missing profile
}
if errors.Is(err, profiles.ErrNotImplemented) {
    // handle unsupported platform
}
```

Use `errors.Is()` for comparison to correctly handle wrapped errors.
