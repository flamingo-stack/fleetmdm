Utility helpers for the `swiftdialog` package that determine the appropriate icon size for dialog windows based on image dimensions fetched from a URL.

## Key Components

### Constants

| Constant | Value | Description |
|---|---|---|
| `DefaultIconSize` | `80` | Icon size (px) for square or narrow-aspect images |
| `wideIconSize` | `200` | Icon size (px) for wide-aspect images |
| `wideAspectRatio` | `1.8` | Threshold ratio (9:5) used to classify an image as wide |

### Functions

- **`GetIconSize(url string) (uint, error)`** — Fetches an image from the given URL via an HTTP client (10s timeout) and returns either `DefaultIconSize` or `wideIconSize` based on its aspect ratio. The caller is responsible for ensuring the URL is trusted.
- **`decodeIconSize(b io.Reader) (uint, error)`** — Internal helper that decodes image config from a reader and applies the wide-aspect ratio check.

Blank imports of `image/gif`, `image/jpeg`, and `image/png` register decoders so `image.DecodeConfig` can handle all three formats.

## Usage Example

```go
size, err := swiftdialog.GetIconSize("https://example.com/icon.png")
if err != nil {
    log.Fatalf("failed to get icon size: %v", err)
}

// size == 200 for wide images (width >= 1.8 × height)
// size == 80  for square or narrow images
fmt.Printf("icon size: %dpx\n", size)
```

## Notes

- Only call `GetIconSize` with admin-controlled or known-safe URLs; the function explicitly skips the `gosec` URL-injection lint check via `//nolint:gosec`.
