Defines the complete configuration schema for swiftDialog macOS dialog windows, including all UI options, layout controls, and interactive element types.

## Key Components

### `SwiftDialogOptions`
The primary configuration struct serialized to JSON when launching a swiftDialog window. Covers:
- **Content** — `Title`, `Message`, `Icon`, `BannerImage`, `Video`, `WebContent`
- **Buttons** — `Button1Text/Action`, `Button2Text`, `InfoButtonText/Action`, `ButtonStyle`
- **Interactive elements** — `TextField`, `Checkbox`, `SelectItems`, `ListItem`
- **Layout** — `Width`, `Height`, `Position`, `PositionOffset`, `Background`
- **Behavior** — `Timer`, `Progress`, `Moveable`, `OnTop`, `Fullscreen`, `Resizable`

### Enum Types & Constants

| Type | Constants |
|---|---|
| `Style` | `StylePresentation`, `StyleMini`, `StyleCentered`, `StyleAlert`, `StyleCaution`, `StyleWarning` |
| `Alignment` | `AlignmentLeft`, `AlignmentCenter`, `AlignmentRight` |
| `Position` | `PositionTop`, `PositionCenter`, `PositionBottom` |
| `FullPosition` | `FullPositionTopLeft` … `FullPositionBottomRight` (9 positions) |
| `Status` | `StatusWait`, `StatusSuccess`, `StatusFail`, `StatusError`, `StatusPending`, `StatusProgress` |
| `Appearance` | `AppearanceDark`, `AppearanceLight` |

### Nested Structs

- **`Checkbox`** — label, checked state, disabled flag, optional icon, and `EnableButton1`
- **`TextField`** — supports confirmation, secure input, regex validation, file selection, and editor mode
- **`SelectItems`** — dropdown or radio button groups with default value and required flag
- **`ListItem`** — titled list entries with icon and `Status` indicator
- **`Image`** — image path/URL with caption
- **`CheckboxStyle`** — style (`default`, `checkbox`, `switch`) and size (`mini`, `small`, `regular`, `large`)

## Usage Example

```go
opts := swiftdialog.SwiftDialogOptions{
    Title:       "Software Update",
    Message:     "A new update is available. Install now?",
    Icon:        "/path/to/icon.png",
    IconSize:    128,
    Button1Text: "Install",
    Button2Text: "Later",
    Button2:     true,
    Style:       swiftdialog.StyleAlert,
    Timer:       60,
    ProgressText: "Waiting...",
    Appearance:  swiftdialog.AppearanceDark,
    ListItem: []swiftdialog.ListItem{
        {Title: "Downloading", Status: swiftdialog.StatusSuccess},
        {Title: "Installing",  Status: swiftdialog.StatusWait},
    },
}
```
