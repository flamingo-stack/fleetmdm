Core lifecycle management for the `swiftdialog` Go package — handles process creation, command dispatch, and teardown of macOS [swiftDialog](https://github.com/swiftDialog/swiftDialog) dialog windows.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `SwiftDialog` | struct | Main handle holding the process, command file, context, and output buffer |
| `SwiftDialogExit` | struct | Result returned by `Wait()` containing exit code and parsed JSON output |
| `ExitCode` | type | Typed integer constants for swiftDialog exit reasons (button clicks, timer, quit, etc.) |
| `Create()` | func | Allocates a `SwiftDialog` instance and creates the temp command file |
| `Start()` | func | Marshals options to JSON, launches the swiftDialog binary, and optionally runs `caffeinate` |
| `Wait()` | func | Blocks until the process exits, parses JSON output, cleans up, returns `SwiftDialogExit` |
| `Kill()` | func | Cancels context, waits for exit, and removes the temp command file |
| `sendCommand()` / `writeCommand()` | funcs | Write `key: value` commands to the command file (open-write-close cycle required by swiftDialog) |
| Update methods | funcs | High-level helpers for title, message, progress, list items, buttons, icon, and info box |

## Usage Example

```go
ctx := context.Background()

sd, err := swiftdialog.Create(ctx, "/usr/local/bin/dialog")
if err != nil {
    log.Fatal(err)
}

opts := &swiftdialog.SwiftDialogOptions{
    Title:   "Installing...",
    Message: "Please wait.",
}

if err := sd.Start(ctx, opts, true); err != nil {
    log.Fatal(err)
}

sd.UpdateProgress(50)
sd.UpdateProgressText("Halfway there")
sd.UpdateProgress(100)
sd.CompleteProgress()

result, err := sd.Wait()
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Exit code: %d, Output: %v\n", result.ExitCode, result.Output)
```

> **Note:** The command file is opened, written, and closed on every command because swiftDialog only detects changes on file close. A 500ms startup delay in `Start()` ensures the binary is ready before the first command is sent.
