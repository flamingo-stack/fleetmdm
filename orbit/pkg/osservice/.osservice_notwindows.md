Placeholder implementation of `SetupServiceManagement` for non-Windows operating systems that performs no operations.

## Key Components

- **`SetupServiceManagement(serviceName string, interruptCh chan struct{}, doneCh chan struct{})`** — No-op stub satisfying the cross-platform interface for service lifecycle management on Linux and macOS.

## Usage Example

```go
interruptCh := make(chan struct{})
doneCh := make(chan struct{})

// On non-Windows, this is a no-op
osservice.SetupServiceManagement("my-service", interruptCh, doneCh)
```

> **Note:** The actual service management logic lives in the Windows-specific counterpart. This file is selected at build time via the `!windows` build constraint, ensuring the package compiles cleanly on all platforms without branching in calling code.
