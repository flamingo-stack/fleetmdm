Provides cross-platform process management utilities and shared sentinel errors/constants for the `platform` package.

## Key Components

**Errors**
- `ErrProcessNotFound` — sentinel error for missing processes
- `ErrComChannelNotFound` — sentinel error for missing communication channels

**Constants**
- `UUIDSource` / `UUIDSourceInvalid`, `UUIDSourceWMI`, `UUIDSourceHardware` — typed constants identifying the source of a hardware UUID

**Types**
- `Process` — lightweight struct holding a process `Name` and `PID`

**Functions**
- `getProcessesByName(namePrefix string)` — internal helper; returns all running processes whose name starts with the given prefix
- `KillAllProcessByName(namePrefix string)` — kills every running process matching the prefix and returns the list of killed `Process` entries; returns `nil, nil` when no matching processes exist

## Usage Example

```go
// Kill all running instances of the Fleet agent
killed, err := platform.KillAllProcessByName("fleet")
if err != nil {
    log.Fatalf("failed to kill processes: %v", err)
}

for _, p := range killed {
    fmt.Printf("killed process %s (PID %d)\n", p.Name, p.PID)
}
```

## Notes

- `getProcessesByName` silently skips processes whose name cannot be retrieved (common for privileged system processes).
- `KillAllProcessByName` stops on the first kill failure and returns the error — partial kills are **not** rolled back.
