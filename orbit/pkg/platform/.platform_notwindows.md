POSIX/non-Windows platform-specific implementations of file permission management and process control utilities for the Fleet orbit agent.

## Key Components

| Function | Description |
|---|---|
| `ChmodRestrictFile` | Sets restrictive read permissions on a file using `constant.DefaultFileMode` |
| `ChmodExecutableDirectory` | Sets directory permissions using `constant.DefaultDirMode` |
| `ChmodExecutable` | Sets executable permissions using `constant.DefaultExecutableMode` |
| `SignalProcessBeforeTerminate` | Force-terminates the desktop app process by name (no pre-signal on POSIX) |
| `GetProcessesByName` | Returns all running processes matching a name prefix via `gopsutil` |
| `GetSMBiosUUID` | Stub — returns `UUIDSourceInvalid` and an error (not implemented on non-Windows) |
| `PreUpdateQuirks` | No-op on non-Windows platforms |
| `IsInvalidReparsePoint` | No-op on non-Windows; always returns `false` |
| `killProcessByName` | Internal helper that finds and kills a process by name |

## Usage Example

```go
// Restrict a sensitive file
if err := platform.ChmodRestrictFile("/etc/orbit/secret.key"); err != nil {
    log.Fatal(err)
}

// Make a binary executable
if err := platform.ChmodExecutable("/usr/local/bin/fleet-desktop"); err != nil {
    log.Fatal(err)
}

// Find a running process by name
procs, err := platform.GetProcessesByName("fleet-desktop")
if err != nil {
    if errors.Is(err, platform.ErrProcessNotFound) {
        log.Println("process not running")
    }
}

// Terminate the desktop process before an update
if err := platform.SignalProcessBeforeTerminate("fleet-desktop"); err != nil {
    log.Fatal(err)
}
```

## Notes

- Build-constrained to non-Windows targets via `//go:build !windows`.
- `GetProcessesByName` matches on name **prefix** and stops at the first match — only one process entry is appended despite iterating all system processes.
- `GetSMBiosUUID` and `IsInvalidReparsePoint` are intentional stubs; corresponding implementations live in the Windows-specific counterpart file.
