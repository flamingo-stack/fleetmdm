Windows-specific platform implementation for Fleet's orbit agent, providing Windows ACL permission management, process control via Win32 APIs, and SMBIOS/BIOS UUID retrieval.

## Key Components

| Function | Description |
|---|---|
| `ChmodRestrictFile` | Applies Windows ACLs to restrict file access to SYSTEM and Admin only |
| `ChmodExecutableDirectory` | Sets ACLs on a directory granting read+execute to Users, full control to SYSTEM/Admins |
| `ChmodExecutable` | Sets ACLs on an executable file (same permissions as directory) |
| `SignalProcessBeforeTerminate` | Signals a named kernel event then force-kills matching processes |
| `GetProcessesByName` | Enumerates running processes via `CreateToolhelp32Snapshot` and returns matches by name |
| `signalThroughNamedEvent` | Low-level helper that opens and pulses a `Global\comm-<id>` named event object |
| `hardwareGetSMBiosUUID` | Reads BIOS UUID from SMBIOS structures via `GetSystemFirmwareTable` (uses `go-smbios`) |
| `wmiGetSMBiosUUID` | Fallback UUID retrieval via `wmic csproduct get UUID` |
| `isValidUUID` | Validates a raw 16-byte SMBIOS UUID buffer (rejects all-0x00 and all-0xFF) |

**Constants:**
- `fullControl` (`2032127`) — Windows `FILE_ALL_ACCESS` mask
- `readAndExecute` (`131241`) — Windows read + execute mask

## Usage Example

```go
// Restrict a sensitive config file to SYSTEM/Admin only
if err := platform.ChmodRestrictFile("/path/to/secret.cfg"); err != nil {
    log.Fatal(err)
}

// Find and terminate a named process gracefully
err := platform.SignalProcessBeforeTerminate("fleet-desktop")
if errors.Is(err, platform.ErrComChannelNotFound) {
    // Named event not found; process may already be gone
}

// Look up running processes by name
procs, err := platform.GetProcessesByName("orbit")
if errors.Is(err, platform.ErrProcessNotFound) {
    fmt.Println("orbit is not running")
}
```

## Notes

- Uses `golang.org/x/sys/windows` for direct Win32 API calls (`OpenEvent`, `PulseEvent`, `CreateToolhelp32Snapshot`)
- SMBIOS UUID decoding respects the SMBIOS ≥2.6 little-endian field encoding spec ([DSP0134](https://www.dmtf.org/sites/default/files/standards/documents/DSP0134_3.1.1.pdf))
- Named events follow the `Global\comm-<channelId>` kernel object naming convention
