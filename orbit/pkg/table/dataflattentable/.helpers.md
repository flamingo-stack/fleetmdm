Utility helpers for converting `dataflatten.Row` results into osquery-compatible table structures within the `dataflattentable` package.

## Key Components

### `ToMap`
Converts a slice of `dataflatten.Row` values into `[]map[string]string` for direct consumption by osquery tables. Each result map includes:

| Key | Description |
|---|---|
| `fullkey` | Full slash-delimited path of the row |
| `parent` | Parent path component |
| `key` | Leaf key name |
| `value` | Row value |
| `query` | The flatten query string |

Any additional key-value pairs passed via `rowData` are merged into every result row.

### `Columns`
Returns the standard five dataflatten column definitions (`fullkey`, `parent`, `key`, `value`, `query`) plus any caller-supplied `table.ColumnDefinition` entries. Acts as syntactic sugar to avoid boilerplate when registering dataflatten-backed osquery tables.

## Usage Example

```go
// Define a table with standard flatten columns plus a custom one
cols := dataflattentable.Columns(
    table.TextColumn("device_id"),
)

// Convert flatten rows to osquery row maps
rows, _ := dataflatten.JSON(data, dataflatten.WithQuery("users"))
results := dataflattentable.ToMap(rows, "users", map[string]string{
    "device_id": "abc-123",
})

// results[0] will contain:
// { "fullkey": "users/0/name", "parent": "users/0", "key": "name",
//   "value": "alice", "query": "users", "device_id": "abc-123" }
```
