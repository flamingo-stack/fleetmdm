Provides osquery table plugin functionality for executing system binaries and flattening their output into queryable table rows.

## Key Components

- **`ExecTableOpt`** — Functional option type for configuring `Table` behavior.
- **`WithKVSeparator(separator string)`** — Option to override the default `":"` key-value delimiter used when parsing `KeyValueType` output.
- **`WithBinDirs(binDirs ...string)`** — Option to specify directories searched when resolving the binary path.
- **`TablePluginExec(...)`** — Constructs an osquery `table.Plugin` that runs a command and flattens its output using the specified `DataSourceType` (`PlistType`, `JsonType`, or `KeyValueType`).
- **`generateExec(...)`** — Query handler; executes the binary, iterates over query constraints, flattens output, and returns results as `[]map[string]string`.
- **`exec(ctx)`** — Internal helper that resolves the binary across `binDirs`, runs it with a 50-second timeout, and returns stdout bytes.

## Usage Example

```go
plugin := dataflattentable.TablePluginExec(
    logger,
    "system_brew_info",
    dataflattentable.JsonType,
    []string{"brew", "info", "--json=v2", "--installed"},
    dataflattentable.WithBinDirs("/usr/local/bin", "/opt/homebrew/bin"),
)

// Register with osquery server
server.RegisterPlugin(plugin)
```

## Notes

- Binary resolution tries each path in `binDirs` in order; falls back to the bare binary name when `binDirs` is empty.
- A missing binary (`os.ErrNotExist`) returns `nil, nil` — preventing table errors that would break osquery joins.
- Other exec failures are logged at `Info` level and also return `nil, nil` for the same reason.
- Based on [`kolide/launcher`](https://github.com/kolide/launcher/pkg/osquery/tables).
