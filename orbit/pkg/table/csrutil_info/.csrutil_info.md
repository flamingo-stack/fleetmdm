Darwin-only osquery table plugin that exposes macOS System Security Volume (SSV) / Authenticated Root status as a queryable column.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | `[]table.ColumnDefinition` | Declares the table schema — a single integer column `ssv_enabled` |
| `Generate()` | `([]map[string]string, error)` | osquery callback that executes at query time and returns the SSV status row |
| `getSSVEnabled()` | internal | Runs `csrutil authenticated-root status` and parses the output into `"1"` (enabled) or `"0"` (disabled) |
| `runCommand()` | internal | Executes an arbitrary binary with a 5-second context timeout; logs failures via `zerolog` |

## Schema

| Column | Type | Values |
|--------|------|--------|
| `ssv_enabled` | `INTEGER` | `1` = Authenticated Root enabled, `0` = disabled, `""` = command failed |

## Usage Example

Register the table with an osquery-go extension server:

```go
package main

import (
    "github.com/flamingo-stack/fleetmdm/path/to/csrutil_info"
    "github.com/osquery/osquery-go"
    "github.com/osquery/osquery-go/plugin/table"
)

func main() {
    server, _ := osquery.NewExtensionManagerServer("csrutil_info", socketPath)
    server.RegisterPlugin(table.NewPlugin(
        "csrutil_info",
        csrutil_info.Columns(),
        csrutil_info.Generate,
    ))
    server.Run()
}
```

Query from osquery:

```sql
SELECT ssv_enabled FROM csrutil_info;
```

> **macOS only** — the `darwin` build tag restricts compilation to macOS. The underlying command (`/usr/bin/csrutil`) requires macOS 11+ (Big Sur) for the `authenticated-root` subcommand.
