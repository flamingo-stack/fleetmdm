Linux-only osquery table plugin that reads dconf configuration values for a specified user by executing `dconf read` via `sudo`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | `func` | Defines the table schema with three columns: `username` (required), `key` (required), and `value` |
| `Generate()` | `func` | Query handler that executes `sudo -u <username> dconf read <key>` and returns the result |

## Usage Example

This plugin is registered as an osquery virtual table. Query it using osquery SQL:

```sql
SELECT value FROM dconf_read WHERE username = 'alice' AND key = '/org/gnome/desktop/interface/color-scheme';
```

Both `username` and `key` constraints using `=` are **required** — the table returns an error if either is omitted.

At runtime, `Generate` constructs and runs:

```bash
sudo -u alice /usr/bin/dconf read /org/gnome/desktop/interface/color-scheme
```

Registration example (Go):

```go
plugin := table.NewPlugin("dconf_read", dconf_read.Columns(), dconf_read.Generate)
```

## Notes

- **Linux only** — guarded by `//go:build linux` build tag
- Requires `sudo` configured to allow the osquery process to run `dconf` as arbitrary users without a password prompt
- Only `OperatorEquals` constraints are evaluated; range or `LIKE` queries on `username`/`key` are not supported
- stderr output is included in returned errors for easier debugging
