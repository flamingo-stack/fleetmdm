Darwin-only osquery table plugin that retrieves and encodes macOS application icons as base64 PNG strings using Objective-C/Cocoa bindings.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `AppIcons()` | `*table.Plugin` | Registers the `app_icons` osquery table with `path`, `icon`, and `hash` columns |
| `generateAppIcons()` | table generator | Query handler; requires a `WHERE path =` constraint, resizes icon to 128×128, returns base64 PNG |
| `getAppIcon()` | helper | Calls the CGO `Icon()` function, decodes the TIFF response, and computes a CRC-64 checksum |
| `Icon()` | CGO/ObjC | Cocoa function using `NSWorkspace` to fetch the app icon as a TIFF `CFDataRef` |
| `crcTable` | `*crc64.Table` | Pre-computed ECMA CRC-64 table for icon hashing |

## Usage Example

```go
// Register the plugin with an osquery-go extension
plugin := appicons.AppIcons()
server, err := osquery.NewExtensionManagerServer("app_icons", socket)
if err != nil {
    log.Fatal(err)
}
server.RegisterPlugin(plugin)
server.Run()
```

```sql
-- Query from osquery
SELECT path, icon, hash
FROM app_icons
WHERE path = '/Applications/Safari.app';
```

## Notes

- **Darwin only** — guarded by `//go:build darwin`; requires Cocoa framework linkage
- Icons are fetched at 128×128 via `NSWorkspace`, converted from TIFF → PNG, then base64-encoded
- The `hash` column is a CRC-64 (ECMA) hex digest of the raw TIFF bytes, useful for change detection
- Based on [`kolide/launcher`](https://github.com/kolide/launcher/tree/main/pkg/osquery/tables)
