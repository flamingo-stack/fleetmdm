Implements an osquery table plugin (`cryptoinfo`) that identifies and exposes cryptographic file metadata — such as certificate and key details — by reading files from specified paths and flattening the parsed output into queryable rows.

## Key Components

- **`Table`** — Struct holding a `zerolog.Logger` instance scoped to the `cryptoinfo` table.
- **`TablePlugin`** — Registers the osquery plugin with columns for `path`, `passphrase`, and flattened data fields. Returns a `*table.Plugin` ready for use.
- **`generate`** — Query handler that resolves glob paths, iterates over matched files, and applies optional passphrase and query constraints before returning flattened rows.
- **`flattenCryptoInfo`** — Helper that reads a file, passes its bytes through `cryptoinfo.Identify`, marshals the result to JSON, then feeds it into `dataflatten.Json` for row generation.

## Usage Example

```go
import (
    "github.com/fleetdm/fleet/v4/orbit/pkg/table/cryptoinfotable"
    "github.com/rs/zerolog"
    "os"
)

logger := zerolog.New(os.Stdout)
plugin := cryptoinfotable.TablePlugin(logger)

// Register with osquery-go
client.RegisterPlugin(plugin)
```

Once registered, query the table via osquery:

```sql
SELECT * FROM cryptoinfo WHERE path = '/etc/ssl/certs/%.pem';

SELECT * FROM cryptoinfo WHERE path = '/etc/ssl/private/server.key' AND passphrase = 'secret';
```

## Notes

- The `path` constraint is **required**; omitting it returns an error.
- SQL `%` wildcards are automatically converted to glob `*` patterns for filesystem matching.
- The `passphrase` constraint defaults to an empty string if not provided.
- Based on the [kolide/launcher](https://github.com/kolide/launcher) osquery tables pattern.
