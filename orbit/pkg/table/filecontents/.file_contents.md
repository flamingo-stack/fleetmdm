Implements an osquery virtual table plugin (`file_contents`) that exposes file system content as queryable SQL rows, supporting both exact path lookups and wildcard glob patterns.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Columns()` | Function | Returns the table schema with `path` and `contents` text columns |
| `Generate()` | Function | osquery entry point; parses query constraints and returns matching file rows |
| `processFile()` | Function | Reads one or more files from disk; translates SQL `LIKE` `%` wildcards to glob `*` patterns |
| `fileContents` | Struct | Internal DTO holding a file's `Path` and `Contents` |

## Usage Example

Register the table with an osquery extension server and query it via SQL:

```go
package main

import (
    "log"

    osquery "github.com/osquery/osquery-go"
    "github.com/osquery/osquery-go/plugin/table"

    filecontents "github.com/flamingo-stack/fleetmdm/path/to/filecontents"
)

func main() {
    server, err := osquery.NewExtensionManagerServer(
        "file_contents_ext",
        "/var/osquery/osquery.em",
    )
    if err != nil {
        log.Fatal(err)
    }

    server.RegisterPlugin(table.NewPlugin(
        "file_contents",
        filecontents.Columns(),
        filecontents.Generate,
    ))

    if err := server.Run(); err != nil {
        log.Fatal(err)
    }
}
```

Once registered, query the table via osquery:

```sql
-- Exact path lookup
SELECT path, contents FROM file_contents WHERE path = '/etc/hosts';

-- Wildcard glob (% maps to *)
SELECT path, contents FROM file_contents WHERE path LIKE '/etc/%.conf';
```

> **Note:** The `=` operator triggers a single exact file read, while `LIKE` translates `%` to `*` and uses `filepath.Glob` for multi-file expansion. Both operators can appear in the same query; the last matching constraint wins.
