Queries an SNTP/NTP server to retrieve the current timestamp and clock offset, exposed as an osquery virtual table.

## Key Components

- **`Columns()`** — Defines the table schema with three columns: `server` (text), `timestamp_ms` (bigint), and `clock_offset_ms` (bigint).
- **`GenerateFunc()`** — Executes an NTP query against a caller-specified server and returns the server time and clock offset in millisecond precision.

## Usage Example

```go
// Register the table with an osquery plugin server
plugin := table.NewPlugin("sntp_request", sntp_request.Columns(), sntp_request.GenerateFunc)
```

Query from osquery:

```sql
SELECT server, timestamp_ms, clock_offset_ms
FROM sntp_request
WHERE server = 'pool.ntp.org';
```

## Notes

- The `server` column **must** be provided as an equality constraint (`WHERE server = '...'`); omitting it returns an error.
- NTP queries time out after **30 seconds**.
- Clock offset reflects the difference between the local system clock and the NTP server, useful for detecting clock drift in managed endpoints.
