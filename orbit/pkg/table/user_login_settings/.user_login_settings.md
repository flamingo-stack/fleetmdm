macOS-only osquery table plugin that reports whether a password hint is configured for the current console user by querying the Directory Service command-line utility (`dscl`).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | `func` | Defines the table schema with a single `password_hint_enabled` integer column |
| `Generate()` | `func` | Executes `dscl` as the console user and returns `1` if a password hint exists, `0` otherwise |

## Usage Example

Register the table with an osquery-go extension server:

```go
plugin := table.NewPlugin("user_login_settings", user_login_settings.Columns(), user_login_settings.Generate)
server.RegisterPlugin(plugin)
```

Querying from osquery:

```sql
SELECT password_hint_enabled FROM user_login_settings;
-- Returns: 1 (hint set) or 0 (no hint)
```

## Implementation Notes

- **Darwin-only**: build tags restrict compilation to macOS (`//go:build darwin`)
- **Console user context**: runs `dscl . -list /Users hint` under the console user's UID/GID via `syscall.Credential` — prevents empty results that occur when the command runs as root
- **Timeout**: enforces a 5-second deadline on the `dscl` subprocess via `context.WithTimeout`
- **Detection logic**: any non-empty, non-whitespace output from `dscl` is treated as a hint being present (`"1"`); empty output returns `"0"`
