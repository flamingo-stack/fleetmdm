macOS `ioreg` osquery table plugin that wraps the `/usr/sbin/ioreg` command, parsing its complex nested plist output using the `dataflatten` library to expose IOKit registry data as queryable osquery rows.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Table` | struct | Holds the table name and zerolog logger |
| `TablePlugin` | func | Constructs and registers the osquery table plugin with column definitions |
| `generate` | method | Executes `ioreg` with constraint-derived arguments and returns flattened rows |
| `flattenOutput` | method | Parses raw plist bytes into `dataflatten.Row` slices using a query path |
| `allowedCharacters` | const | Alphanumeric allowlist applied to all user-supplied constraint values |

### Columns

Mirrors the `ioreg` CLI flags directly:

| Column | Type | `ioreg` Flag |
|--------|------|-------------|
| `c` | text | `-c` class name |
| `d` | integer | `-d` depth |
| `k` | text | `-k` key name |
| `n` | text | `-n` entry name |
| `p` | text | `-p` plane |
| `r` | integer (bool) | `-r` root entry |

## Usage Example

Query USB devices by class from osquery:

```sql
SELECT * FROM ioreg WHERE c = 'IOUSBDevice' AND query = 'IORegistryEntryChildren/*/IORegistryEntryName';
```

Or filter by key name:

```sql
SELECT * FROM ioreg WHERE k = 'UsbDeviceClass';
```

Register the plugin in Go:

```go
logger := zerolog.New(os.Stdout)
plugin := ioreg.TablePlugin(logger)
// pass plugin to osquery-go ExtensionManagerServer
```

## Notes

- **Darwin only** — build-tagged `//go:build darwin`.
- All constraint values are sanitized against `allowedCharacters` (alphanumeric) before being passed as shell arguments, preventing injection.
- The `-a` (archive/plist output) flag is always appended; other flags are conditionally added based on non-empty query constraints.
- `ioreg` execution has a **30-second timeout** enforced via `tablehelpers.Exec`.
