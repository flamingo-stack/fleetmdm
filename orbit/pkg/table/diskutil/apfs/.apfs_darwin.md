Darwin-only osquery table plugin that exposes APFS container, volume, and physical store metadata by parsing `diskutil apfs list -plist` output.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `CmdResult` | Top-level plist deserialization target holding a slice of `Container` |
| `Container` | APFS container metadata including UUID, capacity, fusion status, and nested stores/volumes |
| `PhysicalStore` | Disk-level physical store with device identifier, UUID, and size |
| `Volume` | APFS volume metadata including encryption, FileVault, lock state, roles, and capacity |

### Functions

| Function | Description |
|----------|-------------|
| `VolumesColumns()` | Returns the osquery column schema for the `apfs_volumes` table |
| `VolumesGenerate()` | osquery generate hook; runs `diskutil`, parses output, returns volume rows |
| `parseDiskutilVolumes()` | Unmarshals plist bytes and flattens containers × volumes into row maps |
| `PhysicalStoresColumns()` | Returns the osquery column schema for the `apfs_physical_stores` table |
| `PhysicalStoresGenerate()` | osquery generate hook; runs `diskutil`, parses output, returns physical store rows |
| `parseDiskutilPhysicalStores()` | Unmarshals plist bytes and flattens containers × physical stores into row maps |
| `convertBool()` | Converts a Go `bool` to `"1"` / `"0"` for osquery string map rows |

## Usage Example

```go
// Register both tables with an osquery plugin server
volumesPlugin := table.NewPlugin("apfs_volumes",
    apfs.VolumesColumns(),
    apfs.VolumesGenerate,
)

physicalStoresPlugin := table.NewPlugin("apfs_physical_stores",
    apfs.PhysicalStoresColumns(),
    apfs.PhysicalStoresGenerate,
)

// Query volumes directly (e.g. in tests)
rows, err := apfs.VolumesGenerate(ctx, table.QueryContext{})
if err != nil {
    log.Fatal(err)
}
for _, row := range rows {
    fmt.Println(row["name"], row["filevault"], row["capacity_in_use"])
}
```

> **Platform note:** This file is Darwin-only (`apfs_darwin.go`). Both generate functions invoke `/usr/sbin/diskutil` directly and will fail on non-macOS systems.
