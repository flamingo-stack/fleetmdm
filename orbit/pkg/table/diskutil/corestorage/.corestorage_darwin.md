macOS CoreStorage osquery table plugin that queries logical volume groups, families, and physical volumes by parsing `diskutil coreStorage` plist output.

## Key Components

### Data Types

| Type | Description |
|------|-------------|
| `ListCmdResult` | Root plist structure from `diskutil coreStorage list -plist` |
| `LogicalVolumeGroup` | Volume group containing families and physical volumes |
| `LogicalVolumeFamily` | Volume family (encryption context) within a group |
| `BasicVolume` | Minimal volume reference (UUID + role) |
| `VolumeGroupInfo` | Detailed info for a volume group (size, status, fusion drive, etc.) |
| `LogicalVolumeFamilyInfo` | Encryption status and security context for a volume family |
| `LogicalVolumeInfo` | Full logical volume details (name, size, conversion state, device ID) |
| `PhysicalVolumeInfo` | Physical disk backing a volume group |

### Exported Functions

- **`LogicalVolumesColumns()`** — Returns the osquery column schema for the `corestorage_logical_volumes` table (31 columns spanning VG, LVF, and LV properties)
- **`LogicalVolumesGenerate()`** — Query handler that runs `diskutil`, parses plist, and returns one row per logical volume
- **`LogicalVolumeFamiliesColumns()`** — Returns the column schema for the `corestorage_logical_volume_families` table (18 columns)
- **`LogicalVolumeFamiliesGenerate()`** — Query handler returning one row per volume family

### Internal Helpers

- **`parseDiskutilLogicalVolumes()`** — Unmarshals plist, iterates VG → LVF → LV hierarchy, calls `runDiskutilInfo` for each UUID
- **`parseDiskutilLogicalVolumeFamilies()`** — Same traversal stopping at the LVF level

## Usage Example

```go
// Register with osquery-go as an osquery table plugin
logicalVolumesTable := table.NewPlugin(
    "corestorage_logical_volumes",
    corestorage.LogicalVolumesColumns(),
    corestorage.LogicalVolumesGenerate,
)

logicalVolumeFamiliesTable := table.NewPlugin(
    "corestorage_logical_volume_families",
    corestorage.LogicalVolumeFamiliesColumns(),
    corestorage.LogicalVolumeFamiliesGenerate,
)
```
