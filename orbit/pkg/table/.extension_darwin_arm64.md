Registers ARM64-specific osquery table plugins for macOS (darwin/arm64) builds, appending platform-exclusive tables to the plugin list.

## Key Components

- **`appendTables(plugins []osquery.OsqueryPlugin) []osquery.OsqueryPlugin`** — Appends ARM64-only osquery plugins to the provided plugin slice and returns the extended list. Currently registers the `AppIcons` table from the `app-icons` package.

## Build Constraints

- **`//go:build darwin && arm64`** — This file is only compiled when targeting macOS on Apple Silicon (ARM64) hardware.

## Usage Example

```go
// Called internally during plugin registration; not invoked directly.
// The build system selects this file automatically for darwin/arm64 targets.
var plugins []osquery.OsqueryPlugin
plugins = appendTables(plugins)
// plugins now includes AppIcons() for ARM64 macOS
```

## Notes

- This file is part of a platform-specific build pattern — sibling files (e.g., `extension_darwin_amd64.go`, `extension_linux.go`) implement `appendTables` for other targets.
- To add new ARM64-only tables, import the package and append its plugin constructor inside `appendTables`.
