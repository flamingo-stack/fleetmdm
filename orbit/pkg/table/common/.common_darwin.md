Darwin-specific utility functions for console user identification and XML value extraction on macOS systems.

## Key Components

### `GetConsoleUidGid() (uid uint32, gid uint32, err error)`
Retrieves the UID and GID of the most recently logged-in console user by inspecting `/dev/console` file ownership. This is necessary because the Orbit process typically runs as root, so `os.CurrentUser()` would return root rather than the actual logged-in user.

### `GetValFromXMLWithTags(xml, parentTag, tag, tagValue, valType string) (string, error)`
Parses an XML string and extracts a sibling element's value by locating a parent node that contains a child element matching a specific tag/value pair, then returning the text content of a sibling element matching `valType`.

## Usage Example

```go
// Get the console user's UID and GID
uid, gid, err := common.GetConsoleUidGid()
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Console user UID: %d, GID: %d\n", uid, gid)

// Extract a value from XML using nested tags
xmlData := `
<root>
  <policyEntry>
    <key>maxFailedAttempts</key>
    <integer>5</integer>
  </policyEntry>
</root>`

val, err := common.GetValFromXMLWithTags(
    xmlData,
    "policyEntry",
    "key",
    "maxFailedAttempts",
    "integer",
)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Max failed attempts:", val) // Output: 5
```

## Notes

- Build-constrained to `darwin` only via `//go:build darwin`
- Depends on [`antchfx/xmlquery`](https://github.com/antchfx/xmlquery) for XPath-based XML traversal
- `GetConsoleUidGid` is particularly useful in MDM/endpoint management contexts where daemons run as root but need to act on behalf of the logged-in user
