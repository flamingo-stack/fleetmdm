Manages the osquery extension manager lifecycle, registering default and platform-specific table plugins for Fleet's orbit agent.

## Key Components

- **`Runner`** — Wraps the osquery `ExtensionManagerServer` with `Execute` and `Interrupt` methods compatible with `oklog/run`. Manages lifecycle, context cancellation, and thread-safe server access.
- **`Extension`** — Interface for custom osquery table plugins, requiring `Name()`, `Columns()`, and `GenerateFunc()`.
- **`NewRunner(socket, opts...)`** — Constructs a `Runner` bound to the given osquery socket path.
- **`OrbitDefaultTables(opts)`** — Returns the full set of built-in osquery plugins including MacAdmins tables (Puppet, Chrome profiles), Orbit tables (SNTP, Firefox preferences, crypto info, Go binaries), data format parsers (`parse_json`, `parse_jsonl`, `parse_xml`, `parse_ini`), and `mcp_listening_servers`.
- **`WithExtension(t)`** — Functional option to register additional `Extension` implementations on a `Runner`.
- **`waitExtensionSocket`** — Blocks until the osquery socket exists on disk and responds to a ping, working around [osquery-go#80](https://github.com/osquery/osquery-go/issues/80).

## Usage Example

```go
runner := table.NewRunner(
    "/var/osquery/osquery.em",
    table.WithExtension(myCustomTable),
)

// In an oklog/run group:
g.Add(runner.Execute, runner.Interrupt)
```

To register a custom table, implement the `Extension` interface:

```go
type MyTable struct{}

func (t *MyTable) Name() string { return "my_custom_table" }
func (t *MyTable) Columns() []table.ColumnDefinition { ... }
func (t *MyTable) GenerateFunc(ctx context.Context, qc table.QueryContext) ([]map[string]string, error) { ... }
```
