Implements an osquery virtual table plugin that exposes LUKS (Linux Unified Key Setup) salt values for encrypted block devices via the `cryptsetup_luks_salt` table.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TblName` | `const` | Table name constant: `"cryptsetup_luks_salt"` |
| `Columns()` | `func` | Returns column definitions: `device`, `key_slot`, `salt` |
| `Generate()` | `func` | osquery table generator; runs `luksDump` and returns per-keyslot rows |
| `getCriteria()` | `func` (internal) | Validates query context and extracts the required `device` constraint |

**Column schema:**

| Column | Required | Description |
|--------|----------|-------------|
| `device` | ✅ (WHERE clause) | Block device path (e.g. `/dev/sda1`) |
| `key_slot` | — | LUKS keyslot identifier |
| `salt` | — | KDF salt for the keyslot |

## Usage Example

Query from osquery (requires `device` in the WHERE clause with `=`):

```sql
SELECT device, key_slot, salt
FROM cryptsetup_luks_salt
WHERE device = '/dev/sda1';
```

Register the table in your osquery extension:

```go
plugin := table.NewPlugin(
    cryptsetup_luks_salt.TblName,
    cryptsetup_luks_salt.Columns(),
    cryptsetup_luks_salt.Generate,
)
```

**Constraints:**
- The `device` column is **required** in the `WHERE` clause; omitting it returns an error.
- Only the `=` operator is supported on `device`; range/LIKE queries are rejected.
- Internally delegates to [`luks.GetLuksDump`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/luks) to parse `cryptsetup luksDump` output.
