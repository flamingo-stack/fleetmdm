Provides a macOS-only osquery table plugin that reports the current FileVault encryption status by executing the `fdesetup` system utility.

## Key Components

- **`Table`** — Struct holding a scoped `zerolog.Logger` for the plugin instance.
- **`TablePlugin(logger zerolog.Logger) *table.Plugin`** — Constructs and registers the `filevault_status` osquery table with a single `status` text column.
- **`generate(...)`** — Query handler that shells out to `/usr/bin/fdesetup status`, parses the trimmed output, and returns it as a single-row result. Silently returns `nil` if `fdesetup` is not found on the system.

## Usage Example

```go
import (
    filevault_status "github.com/flamingo-stack/fleetmdm/orbit/pkg/table/filevault_status"
    "github.com/rs/zerolog"
)

logger := zerolog.New(os.Stderr).With().Timestamp().Logger()

plugin := filevault_status.TablePlugin(logger)

// Register with an osquery-go extension server
server.RegisterPlugin(plugin)
```

Once registered, query the table via osquery:

```sql
SELECT status FROM filevault_status;
```

**Example output:**

```text
FileVault is On.
```

## Notes

- **Darwin-only**: Build tags (`//go:build darwin`) restrict compilation to macOS.
- **`fdesetup` path**: Hardcoded to `/usr/bin/fdesetup`; returns no rows (not an error) if the binary is absent (`os.ErrNotExist`).
- **Source**: Adapted from [fleetdm/launcher](https://github.com/fleetdm/launcher/blob/main/pkg/osquery/tables/filevault).
