Implements an osquery table plugin that parses Firefox `user_pref` preference files (e.g., `prefs.js`) into queryable key-value rows using regex-based extraction and data flattening.

## Key Components

- **`Table`** — Struct holding the table name and a scoped `zerolog.Logger`.
- **`TablePlugin(logger)`** — Constructs and returns the osquery `*table.Plugin` with `path` and `query` columns.
- **`generate(ctx, queryContext)`** — Generates rows by reading one or more preference files, parsing each `user_pref(...)` line, and flattening the result.
- **`re`** — Compiled regex that extracts the preference key and value from lines matching `user_pref("key", value);`, stripping surrounding quotes and leaving JSON strings intact.

## Usage Example

```go
import (
    firefox "github.com/fleetdm/fleet/v4/orbit/pkg/table/firefox_preferences"
    "github.com/rs/zerolog"
)

logger := zerolog.New(os.Stderr)
plugin := firefox.TablePlugin(logger)
// Register with osquery-go runner
runner.RegisterPlugin(plugin)
```

Query from osquery:

```sql
SELECT key, value
FROM firefox_preferences
WHERE path = '/Users/alice/Library/Application Support/Firefox/Profiles/abc123.default/prefs.js'
  AND query = 'app.normandy/*';
```

## Notes

- Requires at least one `path` constraint; returns empty results otherwise.
- The `query` column supports `/`-delimited flatten queries (defaults to `*` for all keys).
- Escaped quotes inside JSON string values (e.g., `{\"key\":1}`) are unescaped before flattening.
- Based on [`kolide/launcher`](https://github.com/kolide/launcher/pkg/osquery/tables) table patterns.
- Source: [`flamingo-stack/fleetmdm`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/table/firefox_preferences/table.go)
