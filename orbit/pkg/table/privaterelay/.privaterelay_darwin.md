Provides an osquery table plugin for macOS that reports the Apple Private Relay (iCloud Private Relay) service status for the currently logged-in console user.

## Key Components

- **`Columns()`** — Defines the table schema with a single `status` integer column representing the `PrivacyProxyServiceStatus` value.
- **`Generate()`** — Queries the macOS `networkserviceproxy` defaults domain by shelling out to a `bash` pipeline (`defaults export` → `plutil` → `base64` → `grep`), running as the console user via `syscall.Credential` to avoid empty results when Fleet runs as root. Returns `"0"` (disabled) or `"1"` (enabled).

## Usage Example

```go
// Register the table with an osquery extension server
plugin := table.NewPlugin("private_relay", privaterelay.Columns(), privaterelay.Generate)
server.RegisterPlugin(plugin)
```

Querying via osquery:

```sql
SELECT status FROM private_relay;
-- status: 0 (disabled) or 1 (enabled)
```

> **Note:** This file is Darwin-only (`//go:build darwin`). The shell pipeline used to extract `PrivacyProxyServiceStatus` is acknowledged as potentially brittle and may need revisiting if Apple changes the underlying plist structure. A 5-second timeout is enforced on the subprocess.
