Darwin-only osquery table plugin that exposes `sudo -V` output as structured JSON through a single `json_result` column.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | `[]table.ColumnDefinition` | Returns the table schema with a single `json_result` text column |
| `Generate()` | `func` | Executes `/usr/bin/sudo -V`, parses output, and returns it as a JSON-encoded row |
| `parseSudoVOutput()` | `func` | Parses the raw `sudo -V` stdout into a structured `map[string]interface{}` |

## Parsing Logic

`parseSudoVOutput` handles three line formats from `sudo -V`:

- **Indented lines** — appended as `[]string` values under the current key
- **Key-only lines** (no colon) — stored with a `nil` value
- **`Key: value` lines** — stored as a plain string value

## Usage Example

```go
// Register the table with an osquery extension
plugin := table.NewPlugin("sudo_info", sudo_info.Columns(), sudo_info.Generate)
```

Query from osquery:

```sql
SELECT json_result FROM sudo_info;
```

Example `json_result` output:

```json
{
  "Sudo version": "1.9.13p3",
  "Configure options": ["--with-env-editor", "--disable-root-sudo"],
  "Sudoers policy plugin version": "1.9.13p3"
}
```

## Notes

- Build-constrained to **darwin** only via `//go:build darwin`
- Requires `/usr/bin/sudo` to be present and executable
- Source: [`sudo_info_darwin.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/sudo_info_darwin.go)
