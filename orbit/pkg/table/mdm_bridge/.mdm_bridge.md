Provides a Windows-only osquery table plugin that bridges Fleet's MDM management capabilities to the Windows MDM stack via native DLL calls, enabling MDM enrollment status checks and SyncML command execution.

## Key Components

### Exported Functions

- **`Columns()`** — Returns the osquery table schema with columns: `enrollment_status`, `enrolled_user`, `mdm_command_input`, `mdm_command_output`, `raw_mdm_command_output`
- **`Generate(ctx, queryContext)`** — osquery table generator; reads MDM enrollment state and optionally executes a SyncML command passed via the `mdm_command_input` WHERE clause constraint

### Core Internal Functions

| Function | Purpose |
|---|---|
| `getEnrollmentInfo()` | Calls `IsDeviceRegisteredWithManagement()` via `mdmregistration.dll` to return enrollment status and enrolled UPN |
| `executeMDMcommand(inputCMD)` | Validates and dispatches a SyncML command to `ApplyLocalManagementSyncML` in `mdmlocalmanagement.dll` |
| `isValidMDMcommand(inputCMD)` | Validates SyncML structure (XML, `<SyncBody>` wrapper, read-only verbs only) |
| `isReadOnlyCommandRequest(inputCmd)` | Ensures only `Get` verbs are present — write operations are blocked |
| `getCmdResponseData(outputCmd)` | Parses the SyncML XML response and extracts `<Results>` data |
| `localUTF16toString(ptr)` | Converts a Windows `LPWSTR` pointer to a Go string using `lstrlenW` + `RtlMoveMemory` |
| `IsValidXML(s)` | Returns true if the string is well-formed XML |
| `enableCmdExecution()` | Enables local MDM management command execution (truncated in source) |

### SyncML XML Types

`SyncMLMessage`, `SyncMLHeader`, `SyncMLBody`, `SyncMLCommand`, `SyncMLCommandItem`, `SyncMLCommandMeta` — struct hierarchy for encoding/decoding OMA-DM SyncML payloads.

### Windows Bindings

Lazily loaded via `windows.NewLazySystemDLL`:
- `mdmregistration.dll` → `IsDeviceRegisteredWithManagement`
- `mdmlocalmanagement.dll` → `ApplyLocalManagementSyncML`, `RegisterDeviceWithLocalManagement`
- `kernel32.dll` → `lstrlenW`, `RtlMoveMemory`

## Usage Example

This file is consumed as an osquery extension table. Query it via SQL:

```sql
-- Check enrollment status only
SELECT enrollment_status, enrolled_user FROM mdm_bridge;

-- Execute a read-only SyncML Get command
SELECT mdm_command_output, raw_mdm_command_output
FROM mdm_bridge
WHERE mdm_command_input = '<SyncBody><Get><CmdID>1</CmdID><Item><Target><LocURI>./DevDetail/SwV</LocURI></Target></Item></Get></SyncBody>';
```

> **Note:** Only `Get` verb SyncML commands are permitted. Write operations (`Add`, `Replace`, `Delete`) are rejected by `isReadOnlyCommandRequest`. Command execution is mutex-guarded and COM-initialized via `comshim`.
