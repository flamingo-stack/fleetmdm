Parses raw output from `cryptsetup status` into a structured key-value map, handling both the free-form first line and standard colon-delimited fields.

## Key Components

### `parseStatus(rawdata []byte) (map[string]interface{}, error)`
Entry point that scans all lines of `cryptsetup status` output. Delegates the first line to `parseFirstLine`, then splits remaining lines on `": "` into normalized keys (spaces replaced with underscores).

### `parseFirstLine(line string) (map[string]interface{}, error)`
Parses the first line using `firstLineRegexp`, which handles two output forms:

| Pattern | Example |
|---|---|
| Device not found | `Device sda1 not found` |
| Device status | `sda1 is active and is in use` |

Returns a map with keys:

| Key | Description |
|---|---|
| `short_name` / `display_name` | Device identifier |
| `status` | Device state (e.g., `active`, `not_found`) |
| `mounted` | Boolean string (`"true"` / `"false"`) |

### `firstLineRegexp`
Compiled regex matching both device-not-found and active/inactive device states from the first output line.

## Usage Example

```go
output, err := exec.Command("cryptsetup", "status", "sda1").Output()
if err != nil {
    log.Fatal(err)
}

data, err := parseStatus(output)
if err != nil {
    log.Fatal(err)
}

fmt.Println(data["status"])   // e.g., "active"
fmt.Println(data["mounted"])  // e.g., "true"
fmt.Println(data["type"])     // e.g., "LUKS2"
```
