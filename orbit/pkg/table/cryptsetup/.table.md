Implements an osquery table plugin (`cryptsetup_status`) that queries the status of LUKS/dm-crypt encrypted devices by executing the `cryptsetup status` command and flattening its output into queryable rows.

## Key Components

- **`TablePlugin(logger)`** — Registers the `cryptsetup_status` osquery table plugin with a `name` text column plus standard `dataflattentable` columns.
- **`Table.generate(ctx, queryContext)`** — Resolves the required `name` constraint, executes `cryptsetup --readonly status <name>` (15-second timeout), parses output, and returns flattened rows.
- **`Table.flattenOutput(dataQuery, status)`** — Wraps `dataflatten.Flatten` to convert the parsed status map into queryable `Row` slices using a `/`-delimited query path.
- **`cryptsetupPaths`** — Fallback binary search paths (`/usr/sbin/cryptsetup`, `/sbin/cryptsetup`).
- **`allowedNameCharacters`** — Allowlist used to sanitize the `name` constraint before shell execution.

## Usage Example

```go
// Register the plugin with an osquery extension server
plugin := cryptsetup.TablePlugin(logger)
server.RegisterPlugin(plugin)
```

```sql
-- Query the status of a LUKS device named "sda2_crypt"
SELECT * FROM cryptsetup_status WHERE name = 'sda2_crypt';

-- Query a specific field using the dataflattentable query syntax
SELECT * FROM cryptsetup_status WHERE name = 'sda2_crypt' AND query = 'type';
```

> **Note:** The `name` constraint is **required**; omitting it returns an error. Only characters in `[a-zA-Z0-9\-/_]` are permitted in the device name to prevent command injection.
