Darwin-only osquery extension table that queries macOS code signature information using the system `codesign` binary.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | `func` | Defines the table schema with `path`, `team_identifier`, and `cdhash_sha256` columns |
| `Generate()` | `func` | Query-time row generator; accepts `path` equality constraints and invokes `codesign --display` |
| `parseCodesignOutput()` | `func` | Parses raw `codesign` stderr/stdout output into `TeamIdentifier` and `CDHash` fields |
| `parsedInfo` | `struct` | Internal struct holding extracted `teamIdentifier` and `cdHash` values |

## Usage Example

Query from osquery SQL:

```sql
SELECT path, team_identifier, cdhash_sha256
FROM codesign
WHERE path = '/Applications/Safari.app';
```

Registering the table with an osquery plugin server:

```go
plugin := table.NewPlugin("codesign", codesign.Columns(), codesign.Generate)
server.RegisterPlugin(plugin)
```

## Notes

- **Darwin-only**: enforced via build tags (`//go:build darwin`).
- **Required constraint**: `path` must be provided with the `=` operator; other operators return an error.
- **Command invoked**: `/usr/bin/codesign --display --verbose=3 <path>` — reads metadata only, performs no signature verification.
- **Apple built-in apps**: `TeamIdentifier=not set` is normalized to an empty string `""`.
- **Unsigned apps**: `codesign` exits with an error; the row is still returned with empty `team_identifier` and `cdhash_sha256`. Errors are logged at `debug` level to avoid noise.
