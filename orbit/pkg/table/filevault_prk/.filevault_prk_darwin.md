Implements a macOS-only osquery table plugin that reads and exposes the FileVault Personal Recovery Key (PRK) from disk as a base64-encoded string.

## Key Components

- **`Columns()`** — Defines the table schema with a single `base64_encrypted` text column.
- **`Generate()`** — Reads `/var/db/FileVaultPRK.dat`, base64-encodes its binary contents, and returns it as a single-row result. Returns `nil, nil` (empty result) if the file does not exist.

## Usage Example

```go
// Register the table with an osquery-go extension server
server, err := osquery.NewExtensionManagerServer("filevault_prk", socketPath)
if err != nil {
    log.Fatal(err)
}

server.RegisterPlugin(table.NewPlugin(
    "filevault_prk",
    filevault_prk.Columns(),
    filevault_prk.Generate,
))

if err := server.Run(); err != nil {
    log.Fatal(err)
}
```

Query from osquery:

```sql
SELECT base64_encrypted FROM filevault_prk;
```

## Notes

- **Darwin only** — guarded by `//go:build darwin`; will not compile on other platforms.
- If `/var/db/FileVaultPRK.dat` is absent, `Generate` returns an empty result set rather than an error.
- Reading this file typically requires elevated privileges (`root`).
