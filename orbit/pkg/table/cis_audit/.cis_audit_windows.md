Windows-only osquery table plugin that exposes CIS (Center for Internet Security) audit benchmark values by querying native Windows security utilities (`secedit.exe`, `auditpol.exe`) and registry settings.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Columns()` | Function | Defines the osquery table schema: `item` (TEXT) and `value` (TEXT) columns |
| `Generate()` | Function | osquery table generator; accepts an `item` constraint and returns its CIS audit value |
| `CommandHandler` | Type | `func() (string, error)` — function signature for per-item audit handlers |
| `AuditItem` | Struct | Parsed output from `auditpol.exe` (subcategory, GUID, success/failure flags) |
| `SeceditData` | Struct | Parsed output from `secedit.exe` — covers system access, event audit, and privilege rights sections |
| `getSeceditData()` | Function | Runs `secedit.exe /export`, decodes the UTF-16 `.inf` output, and parses it with `gopkg.in/ini.v1` |
| `getPreProcessedFileContent()` | Function | Reads a file and converts Windows UTF-16 (with BOM handling) to UTF-8, normalizing line endings |
| `getSystem32Dir()` | Function | Returns the Windows System32 directory path via `golang.org/x/sys/windows` |
| `commandHandlers` | Variable | Map of CIS item identifiers → `CommandHandler` functions, initialized once via `sync.Once` |

## Usage Example

```go
// Queried automatically by osquery via the registered table plugin.
// To test the Generate function directly:
ctx := context.Background()
qc := table.QueryContext{
    Constraints: map[string]table.ConstraintList{
        "item": {
            Constraints: []table.Constraint{
                {
                    Operator:   table.OperatorEquals,
                    Expression: "MinimumPasswordLength",
                },
            },
        },
    },
}

rows, err := cisaudit.Generate(ctx, qc)
if err != nil {
    log.Fatal(err)
}
// rows[0]["item"]  => "MinimumPasswordLength"
// rows[0]["value"] => "14"
```

## Data Sources

```text
secedit.exe  → System Access, Event Audit, Privilege Rights
auditpol.exe → Advanced audit policy subcategories
Registry     → Additional CIS benchmark checks
```

> **Build constraint:** This file only compiles on Windows (`//go:build windows`). It depends on `golang.org/x/sys/windows` for system directory resolution and `golang.org/x/text` for UTF-16 decoding of `secedit.exe` output.
