Implements an osquery table plugin for querying macOS power management settings via the `pmset -g` command, parsing its output into structured JSON results.

## Key Components

- **`Columns()`** — Defines the table schema with two columns: `getting` (the `pmset -g` subcommand option) and `json_result` (parsed output as a JSON string).
- **`Generate()`** — Query-time handler that reads the `getting` constraint from the osquery context, executes `/usr/bin/pmset -g <getting>`, and returns the parsed result as JSON.
- **`parsePMSetOutput()`** — Parses raw `pmset` output into a nested `map[string]interface{}`, grouping key-value pairs under their section headers. Lines starting without a space are treated as section keys; indented lines are matched via a regex and stored as string pairs within the current section.
- **`linePattern`** — Compiled regex (`^(\w+)[\t\f\r ]+(\S[\S\t\f\r ]*)$`) used to extract key-value pairs from indented `pmset` output lines.

## Usage Example

```go
// Register the table with an osquery plugin server
plugin := table.NewPlugin("pmset", pmset.Columns(), pmset.Generate)
```

Query from osquery:

```sql
-- Get general power settings
SELECT json_result FROM pmset WHERE getting = '';

-- Get battery status
SELECT json_result FROM pmset WHERE getting = 'batt';

-- Get sleep assertions
SELECT json_result FROM pmset WHERE getting = 'assertions';
```

## Notes

- **Darwin only** — guarded by the `//go:build darwin` build constraint.
- Lines that do not match the expected `key  value` pattern are silently skipped with a debug log entry via `zerolog`.
