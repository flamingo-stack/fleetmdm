Linux-specific osquery table plugin registration for Fleet's orbit daemon, exposing security, container, disk, and system configuration data.

## Key Components

| Export | Description |
|--------|-------------|
| `PlatformTables(opts PluginOpts)` | Returns all Linux-specific osquery plugins registered at daemon startup |

### Registered Tables

| Table Name | Source | Description |
|------------|--------|-------------|
| `cryptsetup_status` | `cryptsetup` | LUKS/dm-crypt device encryption status |
| `cryptsetup_luks_salt` | `cryptsetup_luks_salt` | LUKS volume salt metadata |
| `falconctl_option` | `falconctl` | CrowdStrike Falcon agent configuration options |
| `falcon_kernel_check` | `falcon_kernel_check` | CrowdStrike kernel module compatibility |
| `crowdstrike_falcon` | `crowdstrike_falcon` | CrowdStrike Falcon sensor data (requires socket) |
| `nftables` | `dataflattentable` | Netfilter ruleset via `nft -jat list ruleset` |
| `lsblk` | `dataflattentable` | Block device info via `lsblk -n -O --json` |
| `dconf_read` | `dconf_read` | GNOME dconf configuration values |
| `containerd_containers` | `containerd` | Running containerd containers |
| `containerd_mounts` | `containerd` | containerd container mount points |
| `fleetd_pacman_packages` | `fleetd_pacman_packages` | Arch Linux pacman package inventory |

## Usage Example

```go
plugins, err := table.PlatformTables(table.PluginOpts{
    Socket: "/var/osquery/osquery.em",
})
if err != nil {
    log.Fatal().Err(err).Msg("failed to load Linux platform tables")
}

for _, plugin := range plugins {
    server.RegisterPlugin(plugin)
}
```

## Notes

- Build-constrained to `linux` only via `//go:build linux`
- `crowdstrike_falcon` requires `opts.Socket` to connect to the osquery extension socket
- `nftables` and `lsblk` use `dataflattentable` to parse JSON CLI output — binaries are searched in `/usr/bin` and `/usr/sbin`
- Source: [`extension_linux.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/table/extension_linux.go)
