An osquery table plugin for macOS that queries user-scoped configuration profiles by running `/usr/bin/profiles` and parsing the plist output.

## Key Components

- **`profilePayload`** — Struct mapping plist fields from `profiles` command output to profile metadata (identifier, display name, UUID, etc.)
- **`Columns()`** — Defines the osquery table schema, mirroring the [macadmins `macos_profiles`](https://github.com/macadmins/osquery-extension/blob/main/tables/macos_profiles/macos_profiles.go) extension with an added `username` column
- **`Generate()`** — osquery table handler; validates a required single `username = '<value>'` constraint, runs the profiles command, and returns results
- **`runProfilesCmd()`** — Executes `/usr/bin/profiles -L -U <username> -o stdout-xml` to fetch user-scoped profiles as XML plist
- **`unmarshalProfilesOutput()`** — Parses the plist XML into a `map[string][]profilePayload`
- **`generateResults()`** — Converts parsed payloads into osquery row maps, injecting the queried `username`

## Usage Example

Query from osquery (requires the extension registered):

```sql
SELECT identifier, display_name, verification_state, uuid
FROM macos_user_profiles
WHERE username = 'alice';
```

Registering the table with an osquery extension server:

```go
plugin := table.NewPlugin("macos_user_profiles",
    macos_user_profiles.Columns(),
    macos_user_profiles.Generate,
)
server.RegisterPlugin(plugin)
```

## Notes

- **Darwin only** — build tag restricts compilation to macOS (`//go:build darwin`)
- **`username` constraint is required** — must be a single equality constraint; missing or multiple constraints return an error
- Runs as the osquery process user; ensure sufficient privileges to call `profiles -L -U <username>`
