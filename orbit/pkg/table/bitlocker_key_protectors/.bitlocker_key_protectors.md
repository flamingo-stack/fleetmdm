Registers a Windows-only osquery table plugin (`bitlocker_key_protectors`) that queries BitLocker volume encryption key protector information via PowerShell.

## Key Components

- **`BitLockerVolume`** — Struct mapping PowerShell output fields (`MountPoint`, `KeyProtectorType`) for JSON deserialization.
- **`TablePlugin`** — Initializes and returns the osquery table plugin with columns `drive_letter` and `key_protector_type`.
- **`generate`** — Executes `Get-BitLockerVolume` via PowerShell and returns parsed rows.
- **`parseOutput`** — Deserializes PowerShell JSON output, handling both single-object and array responses.

## Usage Example

```go
import (
    bitlocker "github.com/flamingo-stack/fleetmdm/orbit/pkg/table/bitlocker_key_protectors"
    "github.com/rs/zerolog"
)

logger := zerolog.New(os.Stdout)
plugin := bitlocker.TablePlugin(logger)

// Register with osquery-go extension manager
server.RegisterPlugin(plugin)
```

Once registered, query via osquery:

```sql
SELECT drive_letter, key_protector_type
FROM bitlocker_key_protectors;
```

**Notes:**
- Windows-only (`//go:build windows`).
- PowerShell execution has a 30-second timeout.
- `key_protector_type` maps to the [BitLocker Key Protector Type enumeration](https://docs.microsoft.com/en-us/windows/win32/secprov/getprotectortype-win32-encryptablevolume) (e.g., `3` = TPM, `6` = Recovery Password).
