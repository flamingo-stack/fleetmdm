Implements the `containerd_containers` osquery virtual table for Linux, exposing containerd container metadata including state, image, PID, and runtime details.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ContainersColumns()` | `func` | Returns the schema for the `containerd_containers` table with 9 column definitions |
| `GenerateContainers()` | `func` | Query-time data generator; connects to the containerd socket, iterates all namespaces, and returns one row per container |

**Columns exposed:**

| Column | Type | Source |
|--------|------|--------|
| `namespace` | text | containerd namespace |
| `id` | text | Container ID |
| `image` | text | Image reference |
| `image_digest` | text | OCI digest (if available) |
| `state` | text | Task status or `"stopped"` |
| `created` | bigint | Unix timestamp |
| `runtime` | text | Runtime name (e.g., `io.containerd.runc.v2`) |
| `command` | text | Process args joined by space |
| `pid` | bigint | Task PID (if running) |

## Usage Example

```go
// Register the table with the osquery plugin server
plugin := table.NewPlugin(
    "containerd_containers",
    containerd.ContainersColumns(),
    containerd.GenerateContainers,
)
```

```sql
-- Query running containers across all namespaces
SELECT namespace, id, image, state, pid, command
FROM containerd_containers
WHERE state = 'running';
```

## Notes

- **Build constraint:** Linux only (`//go:build linux`)
- Connects to the containerd Unix socket at `/run/containerd/containerd.sock`
- Image digest, PID, and command are best-effort — missing values are returned as empty strings rather than causing row failure
- Stopped containers (no active task) report `state = "stopped"` and empty `pid`/`command`
