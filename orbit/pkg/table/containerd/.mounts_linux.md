Implements the `containerd_mounts` osquery virtual table for Linux, exposing mount point details for all containers across all containerd namespaces.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MountsColumns()` | `[]table.ColumnDefinition` | Defines the schema for the `containerd_mounts` table |
| `GenerateMounts()` | `func` | Query-time data generator; connects to the containerd socket, iterates namespaces and containers, and returns mount records |

### Table Schema

| Column | Type | Description |
|--------|------|-------------|
| `namespace` | text | containerd namespace |
| `container_id` | text | Container identifier |
| `type` | text | Mount type (e.g., `bind`, `proc`) |
| `source` | text | Mount source path |
| `destination` | text | Mount target path inside container |
| `options` | text | Comma-separated mount options |

## Usage Example

```go
// Register the table with the osquery extension
plugin := table.NewPlugin("containerd_mounts", containerd.MountsColumns(), containerd.GenerateMounts)
```

```sql
-- Query all mounts across containerd namespaces
SELECT namespace, container_id, type, source, destination, options
FROM containerd_mounts
WHERE namespace = 'k8s.io';
```

## Notes

- **Linux only** — build tag `//go:build linux` restricts compilation to Linux.
- Connects to the containerd Unix socket at `/run/containerd/containerd.sock`; the process must have read access.
- Containers with inaccessible specs are skipped with a warning log rather than failing the entire query.
