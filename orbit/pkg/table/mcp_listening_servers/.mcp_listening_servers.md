Implements an osquery virtual table (`mcp_listening_servers`) that discovers Model Context Protocol (MCP) servers running on the local machine by querying osquery for listening ports and probing each with MCP's JSON-RPC `initialize` handshake.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Columns()` | func | Returns the osquery table schema (pid, name, port, tools, prompts, resources, etc.) |
| `Generate()` | func | Public entry point – opens an osquery client and returns rows for every detected MCP server |
| `generateWithScanner()` | func | Internal helper that accepts an injected `mcpScanner` for unit-testable logic |
| `mcpScanner` | struct | Holds an `http.Client` and an osquery client factory; drives all network I/O |
| `checkMCPServer()` | method | Sends an MCP `initialize` JSON-RPC request to a candidate address/port and returns parsed server info or `nil` |
| `makeMCPRequest()` | method | Posts a JSON-RPC message, handles both plain JSON and SSE-wrapped responses, and extracts the `Mcp-Session-Id` header |
| `terminateSession()` | method | Sends `DELETE /mcp` with the session ID for clean teardown per the MCP spec |
| `mcpServerInfo` | struct | Aggregated result: protocol version, server metadata, capability flags, and tool/prompt/resource lists |
| `mcpResponse` / `mcpListResponse` | structs | JSON-RPC response shapes for `initialize` and list calls |

## Usage Example

```go
package main

import (
    "context"
    "fmt"

    mcp "github.com/fleetdm/fleet/v4/orbit/pkg/table/mcp_listening_servers"
    "github.com/osquery/osquery-go/plugin/table"
)

func main() {
    // Register with osquery
    plugin := table.NewPlugin(
        "mcp_listening_servers",
        mcp.Columns(),
        func(ctx context.Context, qc table.QueryContext) ([]map[string]string, error) {
            return mcp.Generate(ctx, qc, "/var/osquery/osquery.em")
        },
    )
    _ = plugin // pass to osquery.NewExtensionManagerServer(...)

    // Or call directly during development
    rows, err := mcp.Generate(context.Background(), table.QueryContext{}, "/var/osquery/osquery.em")
    if err != nil {
        panic(err)
    }
    for _, row := range rows {
        fmt.Printf("pid=%s  server=%s  port=%s  tools=%s\n",
            row["pid"], row["server_name"], row["port"], row["tools"])
    }
}
```
