Wraps `exec.CommandContext` with timeout enforcement, fallback binary resolution, and stderr handling for use in osquery table helpers.

## Key Components

### `Exec`
```text
func Exec(ctx context.Context, log zerolog.Logger, timeoutSeconds int, possibleBins []string, args []string, includeStderr bool) ([]byte, error)
```

The sole export. Executes a command with these behaviors:

- **Timeout** — wraps the context with `context.WithTimeout` using `timeoutSeconds`.
- **Binary fallback** — iterates `possibleBins` in order, skipping entries that are not found (`os.IsNotExist`), returning results from the first successful execution.
- **Stderr handling** — when `includeStderr` is `true`, stderr is merged into stdout; otherwise it is captured separately and included in the returned error on failure.
- **Debug logging** — logs the resolved command string at `DEBUG` level via `zerolog`.

## Usage Example

```go
import (
    "context"
    "os"

    "github.com/rs/zerolog"
    tablehelpers "github.com/flamingo-stack/fleetmdm/pkg/osquery/tables/tablehelpers"
)

log := zerolog.New(os.Stderr)

out, err := tablehelpers.Exec(
    context.Background(),
    log,
    10, // timeout in seconds
    []string{"/usr/local/bin/mytool", "/usr/bin/mytool"}, // fallback paths
    []string{"--json", "--verbose"},
    false, // keep stderr separate
)
if err != nil {
    // handle: binary not found or non-zero exit
}
// use out (stdout bytes)
```

## Notes

- Not intended for high-frequency calls — allocates fresh `bytes.Buffer` instances per invocation.
- Returns `os.ErrNotExist` (wrapped) if **none** of the provided binary paths resolve successfully.
- Source: adapted from [`fleetdm/launcher`](https://github.com/flamingo-stack/fleetmdm/blob/main/pkg/osquery/tables/tablehelpers/exec.go).
