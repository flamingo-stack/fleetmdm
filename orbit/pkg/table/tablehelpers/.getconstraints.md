Extracts and validates osquery column constraint values from a query context, with support for filtering by allowed characters, allowed values, and fallback defaults.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `constraintOptions` | struct | Internal config holding allowed characters, allowed values, defaults, and logger |
| `GetConstraintOpts` | func type | Functional option for configuring constraint extraction |
| `WithLogger` | option func | Sets a zerolog logger for diagnostic messages |
| `WithDefaults` | option func | Sets fallback values returned when no constraints are present |
| `WithAllowedCharacters` | option func | Restricts constraint expressions to a specific character set |
| `WithAllowedValues` | option func | Restricts constraint expressions to an explicit allowlist |
| `GetConstraints` | func | Main entry point — returns deduplicated, validated constraint strings for a column |
| `OnlyAllowedCharacters` | method | Validates that all rune in an expression are within the allowed character set |

## Usage Example

```go
import (
    "github.com/flamingo-stack/fleetmdm/pkg/tablehelpers"
    "github.com/osquery/osquery-go/plugin/table"
)

func MyTableGenerate(ctx context.Context, queryContext table.QueryContext) ([]map[string]string, error) {
    // Get "username" constraints, defaulting to "root", only allowing alphanumerics
    usernames := tablehelpers.GetConstraints(
        queryContext,
        "username",
        tablehelpers.WithDefaults("root"),
        tablehelpers.WithAllowedCharacters("abcdefghijklmnopqrstuvwxyz0123456789"),
        tablehelpers.WithLogger(logger),
    )

    // Get "platform" constraints limited to known values
    platforms := tablehelpers.GetConstraints(
        queryContext,
        "platform",
        tablehelpers.WithAllowedValues([]string{"darwin", "linux", "windows"}),
        tablehelpers.WithDefaults("darwin"),
    )

    for _, u := range usernames {
        // query data for each validated username
        _ = u
    }
}
```

> **Note:** `WithDefaults` only applies when **no** constraints are present on the column. If constraints exist but are all filtered out by validation rules, an empty slice is returned rather than the defaults.
