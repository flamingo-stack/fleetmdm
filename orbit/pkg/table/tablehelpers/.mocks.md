Provides a test utility for constructing mock `table.QueryContext` objects used in osquery table plugin unit tests.

## Key Components

- **`MockQueryContext`** — Converts a simple `map[string][]string` of column names to constraint expressions into a fully structured `table.QueryContext`, suitable for passing to osquery table query handlers in tests.

## Usage Example

```go
package myplugin_test

import (
    "testing"
    "github.com/flamingo-stack/fleetmdm/pkg/tablehelpers"
)

func TestMyTable(t *testing.T) {
    ctx := tablehelpers.MockQueryContext(map[string][]string{
        "uid":      {"1000"},
        "username": {"alice", "bob"},
    })

    rows, err := queryMyTable(ctx)
    if err != nil {
        t.Fatal(err)
    }
    // assert rows...
}
```

## Notes

- Based on the upstream pattern from [`kolide/launcher`](https://github.com/kolide/launcher/pkg/osquery/tables).
- Constraint `Operator` fields are left at their zero value; set them manually on the returned `QueryContext` if operator-specific logic needs to be tested.
- Source: [`tablehelpers/mocks.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/tablehelpers/mocks.go)
