Provides a no-op stub implementation of `PlatformTables` for operating systems other than Darwin, Windows, and Linux.

## Key Components

- **`PlatformTables(opts PluginOpts) ([]osquery.OsqueryPlugin, error)`** — Returns `nil, nil` on unsupported platforms, satisfying the interface contract without registering any platform-specific osquery plugins.

## Usage Example

```go
// No action needed — this stub is selected automatically by the Go build system
// when compiling for an unsupported OS (not darwin, windows, or linux).
plugins, err := table.PlatformTables(opts)
// plugins == nil, err == nil
```

## Notes

- Controlled by the build constraint `//go:build !darwin && !windows && !linux`, so it is only compiled on platforms outside the three primary targets.
- Maintained as a forward-compatibility shim in case osquery-go support is extended to additional operating systems in the future.
- Source: [`extension_stub.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/extension_stub.go)
