Implements an in-memory osquery table plugin (`fleetd_logs`) that captures and exposes fleetd's zerolog log entries for querying via SQL.

## Key Components

- **`TablePlugin()`** — Returns an osquery `table.Plugin` exposing columns: `time`, `level`, `payload`, `message`, and `error`.
- **`Logger`** — A package-level `logger` instance implementing `zerolog.LevelWriter`. Buffers up to `maxEntries` (10,000) log events in memory with a write mutex for concurrency safety.
- **`logger.Write` / `logger.WriteLevel`** — Accept raw JSON log bytes, parse them via `processLogEntry`, append to the in-memory ring buffer, and trim to `maxEntries`.
- **`processLogEntry()`** — Decodes one or more newline-delimited JSON log entries, extracts `level`, `time` (converting RFC3339 → SQLite UTC format), `message`, and `error`, and marshals remaining fields into a `payload` JSON string.
- **`Event`** — Struct holding a single parsed log entry with `Time`, `Level`, `Payload`, `Message`, and `Error` fields.
- **`generate()`** — osquery table generator that serializes all buffered `Event` entries into `[]map[string]string` rows.

## Usage Example

```go
// Register as a zerolog writer
log.Logger = zerolog.New(zerolog.MultiLevelWriter(os.Stderr, &fleetd_logs.Logger))

// Register the osquery table plugin
plugin := fleetd_logs.TablePlugin()
// pass plugin to osquery extension server

// Query via osquery
// SELECT time, level, message, error, payload FROM fleetd_logs WHERE level = 'error';
```

> **Note:** Timestamps are stored in SQLite-compatible UTC format (`2006-01-02 15:04:05.999999999`) so SQLite date functions work directly on the `time` column. The buffer automatically evicts the oldest entries once the 10,000-entry limit is exceeded.
