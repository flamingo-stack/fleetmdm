Implements an osquery extension table (`orbit_info`) that exposes runtime metadata about the Orbit agent, including version, enrollment status, update channels, uptime, and device auth token.

## Key Components

### `Extension` struct
Holds Orbit runtime state including the orbit client, update channel names, desktop version, token reader/writer, scripts-enabled callback, and agent start time.

### `New(...) *Extension`
Constructor that initializes the extension with all required runtime dependencies.

### `Name() string`
Returns the osquery table name: `"orbit_info"`.

### `Columns() []table.ColumnDefinition`
Defines the table schema with the following columns:

| Column | Type | Description |
|---|---|---|
| `version` | text | Orbit build version |
| `device_auth_token` | text | Current device auth token |
| `enrolled` | text | Enrollment status (bool as string) |
| `last_recorded_error` | text | Most recent client error |
| `orbit_channel` | text | Orbit update channel |
| `osqueryd_channel` | text | osqueryd update channel |
| `desktop_channel` | text | Desktop app update channel |
| `desktop_version` | text | Desktop app version |
| `uptime` | bigint | Seconds since agent start |
| `scripts_enabled` | integer | Script execution enabled (0/1) |
| `update_url` | text | Update server URL |

### `GenerateFunc(...) ([]map[string]string, error)`
Called by osquery at query time; reads live state from the orbit client and token reader to populate a single-row result.

## Usage Example

```go
ext := orbit_info.New(
    orbitClient,
    "stable",        // orbitChannel
    "stable",        // osquerydChannel
    "stable",        // desktopChannel
    "1.2.3",         // desktopVersion
    tokenReadWriter,
    time.Now(),
    func() bool { return true }, // scriptsEnabled
    "https://updates.example.com",
)

// Register with the osquery extension manager
runner.AddExtension(ext)
```

Query from osquery:

```sql
SELECT version, enrolled, uptime, scripts_enabled FROM orbit_info;
```
