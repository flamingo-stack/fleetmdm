Fixed-size circular buffer for Santa log entries, used to retain the most recent `n` log entries in chronological order without unbounded memory growth. Darwin-only (`//go:build darwin`).

## Key Components

| Symbol | Description |
|--------|-------------|
| `ringBuffer` | Struct holding the backing slice, start index, and current size |
| `newRingBuffer(n int)` | Allocates a new ring buffer with capacity `n` |
| `Add(e logEntry)` | Appends an entry, overwriting the oldest when full |
| `Len() int` | Returns the number of entries currently stored |
| `SliceChrono()` | Returns all entries as a slice ordered oldest → newest |

## Usage Example

```go
// Create a buffer that retains the last 100 log entries
rb := newRingBuffer(100)

rb.Add(logEntry{/* ... */})
rb.Add(logEntry{/* ... */})

fmt.Println(rb.Len()) // 2

// Retrieve entries in insertion order
entries := rb.SliceChrono()
for _, e := range entries {
    fmt.Println(e)
}
```

## Notes

- When the buffer is full, `Add` overwrites the oldest entry and advances `start`, maintaining O(1) write performance.
- `SliceChrono` always reconstructs a correctly ordered slice regardless of the internal wrap-around state.
- Passing `n = 0` to `newRingBuffer` produces a no-op buffer; `Add` returns immediately and `SliceChrono` returns an empty slice.
