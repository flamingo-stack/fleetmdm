Parses Santa security daemon log files on macOS to extract binary allow/deny decision entries, supporting both plain-text and gzip-compressed log archives.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `LogColumns()` | Function | Returns osquery table column definitions: `timestamp`, `application`, `reason`, `sha256` |
| `GenerateAllowed()` | Function | osquery table generator returning entries where `decision=ALLOW` |
| `GenerateDenied()` | Function | osquery table generator returning entries where `decision=DENY` |
| `generate()` | Function | Internal dispatcher calling `scrapeSantaLog` and mapping `logEntry` structs to osquery row maps |
| `extractValues()` | Function | Parses a single log line using a timestamp regex and `|`-delimited `key=value` segments |
| `scrapeStream()` | Function | Scans a `bufio.Scanner` line-by-line, filtering by decision type and writing matches into a ring buffer |
| `scrapeSantaLogFromBase()` | Function | Orchestrates reading compressed archives (oldest→newest) then the current log, populating a `ringBuffer` capped at `maxEntries` (10,000) |
| `logEntry` | Struct | Holds parsed fields: `Timestamp`, `Application`, `Reason`, `SHA256` |
| `santaDecisionType` | Enum | `decisionAllowed` / `decisionDenied` |
| `defaultLogPath` | Constant | `/var/db/santa/santa.log` |

## Usage Example

```go
// Register as osquery virtual tables
plugin := table.NewPlugin("santa_log_allowed", santa.LogColumns(), santa.GenerateAllowed)
plugin := table.NewPlugin("santa_log_denied",  santa.LogColumns(), santa.GenerateDenied)

// Query in osquery shell
// SELECT timestamp, application, reason, sha256 FROM santa_log_allowed;
// SELECT timestamp, application, sha256 FROM santa_log_denied LIMIT 100;
```

## Log Format Assumptions

- Lines contain a bracketed timestamp: `[2024-01-15T10:30:00Z]`
- Santa daemon prefix: `santad: `
- Pipe-delimited key-value pairs: `decision=ALLOW|path=/usr/bin/foo|sha256=abc123`
- Archives follow the naming pattern `santa.log.0.gz`, `santa.log.1.gz`, ... (higher index = older)

## Notes

- Darwin-only (`//go:build darwin`)
- Context cancellation is respected mid-scan via `ctx.Done()`
- Only the most recent `maxEntries` matching lines are retained via a ring buffer
- Source reference: [fleet-extensions/santa](https://github.com/allenhouchins/fleet-extensions/tree/main/santa)
