Implements an osquery table plugin that queries Santa daemon status on macOS by invoking `santactl status --json` and mapping the parsed JSON output to osquery-compatible rows.

## Key Components

- **`santaStatus`** — Struct mirroring the JSON schema returned by `santactl status --json`, covering daemon config, cache counts, rule type breakdowns, sync state, watch items, and metrics.
- **`StatusColumns()`** — Returns the 42-column osquery table schema definition used to register the `santa_status` table.
- **`GenerateStatus()`** — Table generator function; runs `santactl`, parses output, and returns a single-row result. On failure (daemon unreachable, FDA not granted, etc.), returns a degraded row with `daemon_reachable=0` and the extracted error message rather than zero rows.
- **`santactlError()`** — Extracts the most useful error string from a failed `santactl` invocation, preferring stderr over stdout over the raw Go error.
- **`boolToIntString()` / `floatToString()`** — Helpers converting Go booleans and floats to osquery string representations.
- **`execCommandContext`** — Package-level variable wrapping `exec.CommandContext`, allowing the command to be swapped out in tests.

## Usage Example

```go
// Register the table with an osquery extension server
server, _ := osquery.NewExtensionManagerServer("santa", socketPath)
server.RegisterPlugin(table.NewPlugin(
    "santa_status",
    santa.StatusColumns(),
    santa.GenerateStatus,
))
server.Run()
```

```sql
-- Query Santa daemon status from osquery
SELECT mode, sync_enabled, sync_server, daemon_reachable, error
FROM santa_status;
```

> **Note:** This file is Darwin-only (`//go:build darwin`) and requires Santa to be installed at `/usr/local/bin/santactl`. When the Santa daemon is unreachable, the table still returns one row with `daemon_reachable = 0` so operators have visibility into degraded states.
