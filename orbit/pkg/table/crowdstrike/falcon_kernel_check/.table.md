Implements an osquery table plugin that checks CrowdStrike Falcon sensor compatibility with the host kernel by executing the `falcon-kernel-check` utility and parsing its output.

## Key Components

- **`TablePlugin(logger)`** — Registers the `falcon_kernel_check` osquery table with three columns: `kernel`, `supported`, and `sensor_version`
- **`Table.generate()`** — Executes `/opt/CrowdStrike/falcon-kernel-check` (5-second timeout), captures output, and returns a single-row result
- **`parseStatus()`** — Parses the CLI output via regex into structured key/value data; maps `"is supported"` → `1` and `"is not supported"` → `0`
- **`kernelCheckRegexp`** — Compiled regex that extracts kernel version string, support status, and sensor version number from the tool's output

## Usage Example

Query via osquery to check whether the running kernel is supported by the installed Falcon sensor:

```go
// Register the plugin with an osquery extension
plugin := falcon_kernel_check.TablePlugin(logger)
```

```sql
-- osquery SQL
SELECT kernel, supported, sensor_version
FROM falcon_kernel_check;
```

Example output row:

| kernel | supported | sensor_version |
|---|---|---|
| `5.13.0-51-generic #58~20.04.1-Ubuntu SMP ...` | `1` | `14006` |

## Notes

- Requires the CrowdStrike agent to be installed at `/opt/CrowdStrike/falcon-kernel-check`
- The utility must be run with sufficient privileges (typically `sudo`)
- Returns a single row representing the current host kernel's support status
- Based on the [kolide/launcher](https://github.com/kolide/launcher) osquery table pattern; source lives at [`orbit/pkg/table/falcon_kernel_check/table.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/table/falcon_kernel_check/table.go)
