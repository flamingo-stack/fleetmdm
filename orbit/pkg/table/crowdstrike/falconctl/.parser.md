Parses the text output from `falconctl`'s option display into a structured key-value map, handling multiple inconsistent output formats produced by the CrowdStrike Falcon sensor CLI.

## Key Components

### `parseOptions(reader io.Reader) (any, error)`

Reads `falconctl` stdout line by line and returns a `map[string]interface{}` of parsed key-value pairs. Handles five distinct output formats:

| Format | Example | Result |
|--------|---------|--------|
| Quoted assignment | `cid="ac917ab..."` | `{"cid": "ac917ab..."}` |
| Unset flag | `aid is not set` | `{"aid": "is not set"}` |
| Tag sentinel | `Sensor grouping tags are not set` | `{"tags": "is not set"}` |
| Default annotation | `metadata-query=enable (unset default)` | `{"metadata-query": "enable"}` |
| Spaced assignment | `version = 6.38.13501.0` | `{"version": "6.38.13501.0"}` |

**Special handling:**
- `rfm-reason` produces two KV pairs on one line; the secondary `code=` key is remapped to `rfm-reason-code` to avoid collisions.
- Trailing commas and periods are stripped from each line before parsing.
- Unrecognised pair formats are collected and returned as a combined error alongside any successfully parsed results.

## Usage Example

```go
import "strings"

output := `cid="ac917ab123"
rfm-state is not set
rfm-reason=None, code=0x0
version = 6.38.13501.0`

result, err := parseOptions(strings.NewReader(output))
if err != nil {
    log.Printf("parse warnings: %v", err)
}

data := result.(map[string]interface{})
fmt.Println(data["cid"])             // ac917ab123
fmt.Println(data["rfm-reason"])      // None
fmt.Println(data["rfm-reason-code"]) // 0x0
fmt.Println(data["version"])         // 6.38.13501.0
```
