An osquery table plugin for macOS that exposes Transparency, Consent, and Control (TCC) database entries as queryable rows, covering both system-level and per-user privacy permission records.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Columns()` | Function | Defines the osquery table schema with columns for `source`, `uid`, and all TCC access fields |
| `Generate()` | Function | Main entry point called by osquery at query time; iterates users and system TCC databases |
| `getTCCAccessRows()` | Function | Shells out to `/usr/bin/sqlite3` to query a TCC.db at a given path |
| `parseTCCDbReadOutput()` | Function | Parses pipe-delimited sqlite3 stdout into a 2D string slice |
| `buildTableRows()` | Function | Converts parsed rows into osquery-compatible `map[string]string` records, tagging each with `uid` and `source` |
| `satisfiesConstraints()` | Function | Evaluates osquery `uid` column constraints (`=`, `<`, `>`, `<=`, `>=`) against a candidate UID string |
| `getUsersInfo()` | Function | Calls `dscl` to list all non-system macOS users and their UIDs |

## Usage Example

This file is used as an osquery extension table. Register it with an osquery plugin server:

```go
plugin := table.NewPlugin("tcc_access", tcc_access.Columns(), tcc_access.Generate)
server, err := osquery.NewExtensionManagerServer(
    "tcc_access_extension",
    socketPath,
    osquery.ServerPlugin(plugin),
)
```

Then query from osquery:

```sql
SELECT source, uid, service, client, auth_value
FROM tcc_access
WHERE uid = 501;
```

> **Note:** This plugin is Darwin-only (`//go:build darwin`) and requires Full Disk Access for the osquery process to read user-level `TCC.db` files under `/Users/<username>/Library/Application Support/com.apple.TCC/TCC.db`. The system-level database is queried with `uid = 0`.
