Darwin-only osquery table plugin that queries macOS Authorization Database entries using the `security authorizationdb read` command and returns results as JSON.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Columns()` | Function | Defines the table schema with `right_name` (required) and `json_result` columns |
| `Generate()` | Function | osquery table generator that reads an authorization right by name and returns its plist-parsed data as JSON |
| `parseAuthDBReadOutput()` | Function (internal) | Parses raw plist output from `security authorizationdb read` into a Go map |

## Usage Example

```go
// Register the plugin with an osquery extension server
plugin := table.NewPlugin("authdb", authdb.Columns(), authdb.Generate)
server.RegisterPlugin(plugin)
```

```sql
-- Query from osquery shell
SELECT right_name, json_result
FROM authdb
WHERE right_name = 'com.apple.System-Preferences';
```

**Example `json_result` output:**

```json
{
  "class": "user",
  "group": "admin",
  "timeout": 300,
  "version": 1
}
```

## Notes

- **Build constraint:** Darwin only (`//go:build darwin`)
- **`right_name` is required** — querying without an equality constraint returns an error
- The `security` binary at `/usr/bin/security` must be accessible at runtime
- Raw plist output is parsed via `howett.net/plist` before JSON serialization
