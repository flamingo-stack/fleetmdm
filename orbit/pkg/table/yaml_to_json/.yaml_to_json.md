Implements a custom osquery virtual table that converts YAML input to JSON output, enabling SQL-style YAML-to-JSON transformation within osquery queries.

## Key Components

- **`Columns()`** — Defines the table schema with two `TEXT` columns: `yaml` (input) and `json` (output).
- **`GenerateFunc()`** — Table generator that extracts the `yaml` equality constraint from the query context, converts the YAML string to JSON using `ghodss/yaml`, and returns the result row.

## Usage Example

```go
// Register the table with an osquery plugin server
yamlToJsonPlugin := table.NewPlugin("yaml_to_json", yaml_to_json.Columns(), yaml_to_json.GenerateFunc)
```

Once registered, query it from osquery:

```sql
SELECT json FROM yaml_to_json WHERE yaml = 'name: fleet\nversion: 1';
```

**Error conditions:**
- Returns an error if the `yaml` constraint is missing or empty — a `WHERE yaml = '...'` clause is required.
- Returns an error if the provided YAML is malformed and cannot be converted.

## Notes

- Only the `=` (equals) operator is supported on the `yaml` column; range or `LIKE` constraints are ignored.
- Uses [`github.com/ghodss/yaml`](https://github.com/ghodss/yaml) which converts YAML → JSON via an intermediate Go map, producing standard JSON output.
