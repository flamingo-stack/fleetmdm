An osquery table plugin that wraps macOS's `/usr/sbin/firmwarepasswd` binary to expose firmware password status as a queryable osquery table.

## Key Components

### Types & Constructor
- **`Table`** — holds a `zerolog.Logger` and an `OutputParser` for processing command output
- **`TablePlugin(logger)`** — registers the `firmwarepasswd` osquery plugin with three columns: `option_roms_allowed` (int), `password_enabled` (int), and `mode` (text)
- **`New(logger)`** — constructs a `Table` with pre-wired `Matcher` rules for each output line pattern

### Core Methods
- **`generate(ctx, queryContext)`** — runs `firmwarepasswd -check` and `firmwarepasswd -mode`, merges parsed results into a single row
- **`runFirmwarepasswd(ctx, subcommand, output)`** — executes the binary with a 1-second timeout in a temporary directory with `0755` permissions

### Value Parsers
- **`modeValue(in)`** — extracts and lowercases the mode string after the `:` delimiter
- **`passwordValue(in)`** — converts a boolean-like string to `"1"` or `"0"`
- **`optionRomValue(in)`** — maps `"allowed"` / `"not allowed"` to `"1"` / `"0"`
- **`discernValBool(in)`** — normalizes common boolean representations (`true/false`, `yes/no`, `1/0`, `y/n`, `t/f`)

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/osquery/tables/firmwarepasswd"

plugin := firmwarepasswd.TablePlugin(logger)
// Register with osquery-go server
server.RegisterPlugin(plugin)
```

Once registered, query via osquery:

```sql
SELECT option_roms_allowed, password_enabled, mode
FROM firmwarepasswd;
```

> **Note:** This table is macOS-only and requires the host binary at `/usr/sbin/firmwarepasswd`. The plugin runs with a 1-second execution timeout per subcommand. Results from `-check` and `-mode` are merged into a single row.
