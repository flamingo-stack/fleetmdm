Provides a build-constrained stub implementation of `appendTables` for Darwin (macOS) AMD64 platforms, returning the plugin slice unmodified.

## Key Components

- **`appendTables(plugins []osquery.OsqueryPlugin) []osquery.OsqueryPlugin`** — No-op stub that passes through the plugin slice unchanged. Active only when build tags `darwin` and `amd64` are both satisfied.

## Usage Example

```go
// Called internally during table plugin registration.
// On darwin/amd64, no additional platform-specific tables are appended.
plugins := appendTables(existingPlugins)
```

## Notes

- The `//go:build darwin && amd64` constraint ensures this stub is compiled exclusively for macOS on Intel architecture.
- ARM64 macOS (Apple Silicon) uses a separate implementation; see [`extension_darwin_arm64.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/extension_darwin_arm64.go) for that variant.
- To add AMD64-specific osquery table plugins, replace the pass-through return with plugin append logic here.
