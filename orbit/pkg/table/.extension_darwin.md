Darwin-only implementation of `PlatformTables` that registers all macOS-specific osquery extension table plugins for Fleet's orbit agent.

## Key Components

### `PlatformTables(opts PluginOpts) ([]osquery.OsqueryPlugin, error)`

The sole exported function. Returns a slice of osquery plugins split into two groups:

**Fleet-owned tables** (selected examples):

| Plugin Name | Description |
|---|---|
| `icloud_private_relay` | iCloud Private Relay status |
| `tcc_access` | Transparency, Consent & Control DB |
| `filevault_prk` | FileVault personal recovery key |
| `apfs_volumes` / `apfs_physical_stores` | APFS volume info |
| `corestorage_logical_volumes` | CoreStorage volume info |
| `firmware_eficheck_integrity_check` | EFI firmware integrity |
| `codesign` | Code signature verification |
| `santa_status/allowed/denied` | Santa security tool data |
| `executable_hashes` | Hash values for executables |
| `parse_plist` | Apple Property List file parser |

**Macadmins extension tables** (selected examples):

| Plugin Name | Description |
|---|---|
| `mdm` | MDM enrollment info |
| `macos_profiles` | Configuration profiles |
| `crowdstrike_falcon` | CrowdStrike agent status |
| `sofa_security_release_info` | SOFA security release data |
| `sofa_unpatched_cves` | Unpatched CVEs via SOFA |
| `macadmins_unified_log` | Renamed from `unified_log` to avoid collision with osquery core (v5.5.0+) |
| `macadmins_wifi_network` | Wi-Fi network details |

After assembling the slice, `appendTables(plugins)` is called to add any further platform-specific tables defined elsewhere.

## Usage Example

```go
plugins, err := table.PlatformTables(table.PluginOpts{
    Socket: "/var/osquery/osquery.em",
})
if err != nil {
    log.Fatal().Err(err).Msg("failed to load platform tables")
}

for _, p := range plugins {
    server.RegisterPlugin(p)
}
```

> **Note:** Several plugins (`crowdstrike_falcon`, `sofa_*`, `macadmins_wifi_network`) forward `opts.Socket` to their generate functions for IPC with the osquery socket.
