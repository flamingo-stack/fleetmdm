Detects Adobe plugins (CEP extensions, UXP extensions, and native plug-ins) on macOS and Windows by scanning well-known directories and parsing plugin manifests as an osquery extension table.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `TablePlugin` | func | Registers the `adobe_plugins` osquery extension table |
| `Columns` | func | Defines the table schema with 10 columns |
| `adobePluginsTable` | struct | Core table implementation holding the zerolog logger |
| `scanPath` | struct | Describes a directory target including type, host app, and user scope |
| `cepManifest` | struct | XML model for `CSXS/manifest.xml` (CEP extensions) |
| `uxpManifest` | struct | JSON model for `manifest.json` (UXP extensions) |
| `hostAppCodes` | map | Maps Adobe host app codes (e.g. `PHXS`, `PPRO`) to human-readable names |
| `readFileCapped` | func | Reads a file up to 1 MB to prevent memory exhaustion when running as root |
| `resolveHostApps` | func | Converts host application codes to deduplicated, human-readable names |

## Usage Example

```go
// Register the table with an osquery extension manager
plugin := adobe_plugins.TablePlugin(logger)
```

```sql
-- Standard scan: CEP and UXP extensions only
SELECT name, version, vendor, extension_type, host_application, user
FROM adobe_plugins;

-- Deep scan: additionally includes native plug-ins
SELECT path, name, version, extension_type, host_application
FROM adobe_plugins
WHERE scan_level = 'deep';
```

## Table Schema

| Column | Description |
|--------|-------------|
| `path` | Absolute path to the plugin directory or file |
| `name` | Plugin display name |
| `version` | Plugin version string |
| `vendor` | Publisher or author name |
| `bundle_id` | Plugin bundle identifier |
| `host_application` | Resolved Adobe app(s) (e.g. `Photoshop, Illustrator`) |
| `extension_type` | `CEP`, `UXP`, or `native` |
| `user` | Username for user-scoped installs; empty for system-wide |
| `platform` | `darwin` or `windows` |
| `scan_level` | `standard` (default) or `deep` |

## Notes

- Symlinks are skipped during directory traversal to prevent escaping scan boundaries.
- Manifest reads are capped at **1 MB** (`maxManifestSize`) since the process runs as root.
- Deduplication via a `seen` map prevents double-reporting plugins found in overlapping scan paths.
- Platform-specific scan paths are resolved at runtime via `getScanPaths` (defined in a separate platform file).
