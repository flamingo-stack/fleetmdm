Stub implementation of `getScanPaths` for unsupported platforms (non-Darwin, non-Windows) where Adobe Creative Cloud is not available.

## Key Components

- **`getScanPaths`** — Returns `nil, nil` on Linux and other unsupported platforms; satisfies the platform-specific interface without performing any filesystem scanning.

## Usage Example

```go
// This file is selected automatically by the Go build system
// when targeting non-darwin, non-windows platforms (e.g., Linux).
// No direct invocation is needed; the build tag handles selection.

paths, err := getScanPaths("/some/path", logger)
// paths == nil, err == nil on Linux
```

## Notes

- Controlled by the build constraint `//go:build !darwin && !windows`; paired with platform-specific implementations in sibling files.
- Adobe Creative Cloud has no Linux distribution, so no scan paths are defined.
- See the Darwin and Windows counterparts in [`adobe_plugins/`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/fleetd-chrome/adobe_plugins/) for real implementations.
