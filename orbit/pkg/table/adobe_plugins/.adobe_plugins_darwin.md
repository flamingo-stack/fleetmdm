Provides macOS-specific scan path resolution for Adobe CEP and UXP plugin extensions, supporting both system-wide and per-user plugin directories.

## Key Components

### `getScanPaths(level string, logger zerolog.Logger) ([]scanPath, error)`
Builds a list of `scanPath` structs targeting Adobe extension directories:
- **System-wide paths** (always included): `/Library/Application Support/Adobe/CEP/extensions` and `/Library/Application Support/Adobe/UXP/extensions`
- **Per-user paths** (always included): iterates local users via `listLocalUsers()` and appends user-scoped CEP/UXP paths under each home directory
- **Deep scan paths** (when `level == "deep"`): adds glob-style native plugin paths for Photoshop, Premiere Pro, After Effects, and Illustrator under `/Applications/`

### `listLocalUsers() ([]localUser, error)`
Enumerates local macOS users by reading `/Users`, filtering out hidden directories (prefixed with `.`) and the `Shared` directory.

### `localUser`
Simple struct holding a user's `name` and `homeDir`.

## Usage Example

```go
logger := zerolog.New(os.Stdout)

// Standard scan (CEP + UXP only)
paths, err := getScanPaths("standard", logger)

// Deep scan (includes native app plug-in folders)
paths, err := getScanPaths("deep", logger)

for _, p := range paths {
    fmt.Printf("Type: %s | Path: %s | User: %s | Host: %s\n",
        p.extensionType, p.basePath, p.user, p.hostApp)
}
```
