Windows-specific implementation for resolving Adobe plugin scan paths across system-wide and per-user locations.

## Key Components

### `getScanPaths(level string, logger zerolog.Logger) ([]scanPath, error)`
Builds a slice of `scanPath` structs covering all relevant Adobe extension directories on Windows:
- **System-wide CEP** – `C:\Program Files\Common Files\Adobe\CEP\extensions` (both 32/64-bit paths)
- **System-wide UXP** – `C:\Program Files\Common Files\Adobe\UXP\extensions`
- **Per-user CEP/UXP** – Roaming AppData paths for each local user discovered via `listLocalUsers()`
- **Deep scan** (`level == "deep"`) – Adds native plug-in directories for Photoshop, Premiere Pro, and After Effects using glob-style wildcard paths

### `localUser`
Internal struct holding a user's login `name` and resolved `homeDir`.

### `listLocalUsers() ([]localUser, error)`
Enumerates directories under `C:\Users`, skipping system entries (`Public`, `Default`, `All Users`) and dot-prefixed names.

## Usage Example

```go
logger := zerolog.New(os.Stdout)

// Standard scan (CEP + UXP only)
paths, err := getScanPaths("standard", logger)

// Deep scan (includes native Photoshop/Premiere/After Effects plug-ins)
paths, err := getScanPaths("deep", logger)

for _, p := range paths {
    fmt.Printf("type=%s host=%s user=%s path=%s\n",
        p.extensionType, p.hostApp, p.user, p.basePath)
}
```

> **Note:** Per-user path enumeration is best-effort — if `listLocalUsers()` fails, a warning is logged and scanning continues with system-wide paths only.
