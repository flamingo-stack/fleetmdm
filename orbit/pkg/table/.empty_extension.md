A lightweight osquery table extension that returns a single instructional message row when queried, useful for placeholder or informational tables.

## Key Components

- **`EmptyExtension`** — struct holding a table `name` and display `msg`
- **`NewEmptyExtension(name, msg string) Opt`** — constructor that wraps the extension via `WithExtension`, returning a table `Opt`
- **`Name() string`** — returns the registered osquery table name
- **`Columns() []table.ColumnDefinition`** — declares a single `TEXT` column named `"message"`
- **`GenerateFunc(...)`** — always returns one row containing the configured message string

## Usage Example

```go
opt := table.NewEmptyExtension(
    "fleet_enrollment_status",
    "This device is not yet enrolled. Please contact your IT administrator.",
)

// Pass the Opt into your table runner or plugin setup
runner := table.NewRunner(opt)
```

When queried via osquery:

```text
SELECT * FROM fleet_enrollment_status;

+------------------------------------------------------------+
| message                                                    |
+------------------------------------------------------------+
| This device is not yet enrolled. Please...                 |
+------------------------------------------------------------+
```

## Notes

- `GenerateFunc` ignores both the `context.Context` and `table.QueryContext` arguments — it always returns the static message.
- Intended for scenarios where a table must be registered but no real data is available (e.g., feature not yet configured, missing permissions, or onboarding guidance).
