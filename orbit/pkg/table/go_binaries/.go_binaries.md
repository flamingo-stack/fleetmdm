Implements an osquery table plugin that discovers and exposes metadata from Go binaries installed in user home directories.

## Key Components

- **`GoBinariesColumns()`** — Returns the schema for the `go_binaries` osquery table with six columns: `name`, `version`, `module_path`, `import_path`, `go_version`, and `installed_path`.
- **`generateForDirs(homeDirs []string)`** — Scans `<homeDir>/go/bin` for each provided home directory, collecting rows for all discovered Go binaries.
- **`readGoBinary(path string)`** — Reads embedded build metadata from a single Go binary using `debug/buildinfo`. Returns `nil` if the file is not a Go binary or is unreadable.

## Usage Example

```go
// Register the table with an osquery server
plugin := table.NewPlugin("go_binaries", go_binaries.GoBinariesColumns(), func(ctx context.Context, queryContext table.QueryContext) ([]map[string]string, error) {
    homeDirs := []string{"/home/alice", "/home/bob"}
    return go_binaries.generateForDirs(homeDirs), nil
})
```

**Example query output:**

```text
SELECT name, version, go_version, installed_path FROM go_binaries;

name         version  go_version  installed_path
-----------  -------  ----------  --------------------------
golangci-lint  v1.57.2  go1.22.1  /home/alice/go/bin/golangci-lint
air            v1.49.0  go1.21.5  /home/alice/go/bin/air
```

## Notes

- Directories that don't exist or cannot be read are silently skipped.
- Non-Go binaries (those lacking embedded build info) are excluded; failures are logged at `DEBUG` level via `zerolog`.
