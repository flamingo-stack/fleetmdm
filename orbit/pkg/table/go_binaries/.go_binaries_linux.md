Linux-specific implementation of the `go_binaries` osquery table plugin. It discovers Go binaries installed in real user home directories by parsing `/etc/passwd`.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `GenerateGoBinaries` | Function | osquery table query handler; returns rows for the `go_binaries` virtual table |
| `linuxHomeDirs` | Function | Opens `/etc/passwd` and delegates to `parsePasswdHomeDirs` |
| `parsePasswdHomeDirs` | Function | Parses passwd-formatted content, filtering out system/service accounts |

## Filtering Logic

`parsePasswdHomeDirs` skips entries that match any of the following:

- UID below `500` (system accounts)
- Empty, `/`, or `/dev/null` home directories
- Shells ending in `/nologin` or `/false`

Duplicate home directories are deduplicated via a `seen` map.

## Usage Example

```go
// Invoked automatically by the osquery plugin runtime at query time:
// SELECT * FROM go_binaries;

rows, err := GenerateGoBinaries(ctx, queryContext)
if err != nil {
    log.Fatal().Err(err).Send()
}

// Unit-test parsePasswdHomeDirs directly with synthetic input:
input := strings.NewReader(`root:x:0:0:root:/root:/bin/bash
alice:x:1000:1000:Alice:/home/alice:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
`)
dirs, err := parsePasswdHomeDirs(input)
// dirs == []string{"/home/alice"}
```

## Notes

- Build-constrained to Linux via `//go:build linux`; other platforms provide their own `GenerateGoBinaries` implementations
- The actual binary discovery is delegated to `generateForDirs` (defined in a shared, platform-agnostic file)
