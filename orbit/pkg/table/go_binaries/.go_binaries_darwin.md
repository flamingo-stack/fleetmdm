Provides the macOS-specific implementation of the `go_binaries` osquery virtual table, handling home directory discovery for Darwin systems.

## Key Components

- **`GenerateGoBinaries`** — Entry point called by the osquery table plugin at query time; retrieves macOS home directories and delegates to the shared `generateForDirs` function
- **`darwinHomeDirs`** — Scans `/Users` and returns valid user home directories, filtering out hidden entries (prefixed with `.`) and the system `Shared` directory

## Usage Example

```go
// Registered as an osquery table plugin
plugin := table.NewPlugin("go_binaries", go_binaries.GoBinariesColumns(), go_binaries.GenerateGoBinaries)
```

At query time, osquery calls `GenerateGoBinaries`, which:

1. Reads all entries under `/Users`
2. Filters system/hidden directories
3. Passes real user home dirs to `generateForDirs` for binary discovery

```go
// darwinHomeDirs filters /Users entries like:
// /Users/.localized  → skipped (hidden)
// /Users/Shared      → skipped (system)
// /Users/alice       → included
// /Users/bob         → included
```
