An osquery table plugin that exposes Arch Linux pacman package metadata by executing `pacman -Qi` and parsing its output into structured rows.

## Key Components

- **`TableName`** — Constant defining the osquery virtual table name: `fleetd_pacman_packages`.
- **`Columns()`** — Returns the table schema with 21 text columns covering package metadata (name, version, description, arch, dependencies, install date/reason, etc.).
- **`Generate()`** — osquery table handler that runs `pacman -Qi [name...]` at query time. Supports optional equality constraints on the `name` column to query specific packages; returns `nil` (not an error) if pacman is not installed.
- **`parsePacmanQiOutput()`** — Parses the `pacman -Qi` human-readable output, splitting on blank lines (one block per package) and mapping colon-delimited `Key: Value` pairs to column names. `None` values are normalized to empty strings.

## Usage Example

```go
// Register the table with an osquery extension server
server, err := osquery.NewExtensionManagerServer(
    "fleetd_pacman_packages",
    socketPath,
)
if err != nil {
    log.Fatal(err)
}

server.RegisterPlugin(table.NewPlugin(
    fleetd_pacman_packages.TableName,
    fleetd_pacman_packages.Columns(),
    fleetd_pacman_packages.Generate,
))

// Query all installed packages via osquery SQL:
// SELECT name, version, install_reason FROM fleetd_pacman_packages;

// Query a specific package using the name constraint (runs: pacman -Qi git):
// SELECT * FROM fleetd_pacman_packages WHERE name = 'git';
```

> **Platform note:** This plugin requires `/usr/bin/pacman` to be present (Arch Linux and derivatives). On systems without pacman, `Generate` returns an empty result set rather than an error.
