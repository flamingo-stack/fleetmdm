Parses X.509 certificates from raw bytes into a structured, human-readable format, handling string conversions and key usage bitfield enumeration.

## Key Components

### `certExtract` struct
A flat, serialization-friendly representation of an X.509 certificate, including parsed string forms of fields like `IssuerParsed`, `SubjectParsed`, `PublicKeyAlgorithm`, and `SignatureAlgorithm` alongside their raw counterparts.

### `parseCertificate(certBytes []byte) (interface{}, error)`
Entry point that wraps `x509.ParseCertificate` and delegates to `extractCert` for structured extraction.

### `extractCert(c *x509.Certificate) (interface{}, error)`
Maps fields from a `*x509.Certificate` into a `certExtract`, converting enums and big integers to strings (e.g. `SerialNumber`, `PublicKeyAlgorithm`).

### `keyUsageToStrings(k x509.KeyUsage) []string`
Iterates over the `keyUsageBits` map and returns all active key usage labels (e.g. `"Digital Signature"`, `"Key Encipherment"`) by testing each bit against the usage bitfield.

## Usage Example

```go
import "crypto/x509"

certBytes := getPEMBlock() // raw DER-encoded certificate bytes

result, err := parseCertificate(certBytes)
if err != nil {
    log.Fatal(err)
}

extract := result.(*certExtract)
fmt.Println(extract.SubjectParsed)      // "CN=example.com,O=Example Inc,C=US"
fmt.Println(extract.IssuerParsed)       // "CN=Let's Encrypt Authority X3,..."
fmt.Println(extract.SerialNumber)       // "123456789"
fmt.Println(extract.KeyUsageParsed)     // ["Digital Signature", "Key Encipherment"]
fmt.Println(extract.NotAfter)           // 2026-01-01 00:00:00 +0000 UTC
```

## Notes

- Based on [kolide/launcher](https://github.com/kolide/launcher/pkg/osquery/tables) osquery table patterns.
- `ExcludedDNSDomains`, `PermittedDNSDomains`, and name constraint fields are captured in `certExtract` but not currently populated in `extractCert` — reserved for future expansion.
- Source: [`parse_certificate.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/parse_certificate.go)
