Parses PKCS#12 (`.p12`) binary data and extracts certificate chain information, returning structured key and certificate metadata.

## Key Components

- **`tryP12(data []byte, password string) ([]*KeyInfo, error)`** — Decodes a PKCS#12 blob using [`go-pkcs12`](https://pkg.go.dev/software.sslmate.com/src/go-pkcs12), then builds a slice of `*KeyInfo` entries representing any private key, end-entity certificate, and CA certificates found in the chain.

## Usage Example

```go
import "os"

raw, err := os.ReadFile("client.p12")
if err != nil {
    log.Fatal(err)
}

keys, err := tryP12(raw, "secret")
if err != nil {
    log.Printf("not a valid P12 or wrong password: %v", err)
    return
}

for _, k := range keys {
    fmt.Printf("type=%s source=%s\n", k.Type, k.Source)
}
```

## Notes

| Condition | Result appended |
|---|---|
| `privateKey != nil` | `NewKey(kiP12)` — private key entry |
| `cert != nil` | `NewCertificate(kiP12).SetData(extractCert(cert))` — leaf cert |
| Each `caCerts` entry | `NewCaCertificate(kiP12).SetData(extractCert(c))` — CA cert |

- Based on the [Kolide Launcher](https://github.com/kolide/launcher) osquery tables implementation.
- Returns `nil, err` immediately on decode failure (wrong password, corrupt data, unsupported format).
- Source constant `kiP12` tags all results for downstream filtering by origin format.
