Defines the `KeyInfo` struct and supporting types for representing parsed cryptographic objects (certificates, CA certificates, and keys) with encoding metadata and structured JSON output.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `KeyInfo` | Core struct holding type, encoding, data, headers, and error for a crypto object |
| `kiType` | String alias for object classification (`CERTIFICATE`, `CA-CERTIFICATE`, `KEY`) |
| `kiEncoding` | String alias for encoding format (`PEM`, `DER`, `P12`) |
| `kiDataNames` | String alias controlling the JSON field name for the data payload |

### Constructors

| Function | Returns |
|----------|---------|
| `NewKey(encoding)` | `*KeyInfo` for a private/public key |
| `NewCertificate(encoding)` | `*KeyInfo` for a certificate |
| `NewCaCertificate(encoding)` | `*KeyInfo` for a CA certificate |
| `NewError(encoding, err)` | `*KeyInfo` representing a parse failure |

### Methods

- **`SetData(data, err)`** — Attaches parsed data or an error to the struct (chainable)
- **`SetHeaders(headers)`** — Attaches PEM header metadata (chainable)
- **`SetDataName(name)`** — Overrides the JSON key used for the data field (chainable)
- **`MarshalJSON()`** — Custom marshaller producing a consistent JSON envelope with `type`, `encoding`, and either the data payload or an `error` string

## Usage Example

```go
ki := cryptoinfo.NewCertificate(cryptoinfo.kiPEM).
    SetData(parsedCert, nil).
    SetHeaders(map[string]string{"Proc-Type": "4,ENCRYPTED"})

out, err := json.Marshal(ki)
if err != nil {
    log.Fatal(err)
}
// Output: {"type":"CERTIFICATE","encoding":"PEM","certificate":{...},"headers":{...}}
```

```go
// Wrap a parse error
ki := cryptoinfo.NewError(cryptoinfo.kiDER, fmt.Errorf("unexpected EOF"))
out, _ := json.Marshal(ki)
// Output: {"type":"","encoding":"DER","error":"unexpected EOF"}
```
