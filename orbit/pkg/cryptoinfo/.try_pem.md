Parses PEM-encoded byte slices into structured `KeyInfo` objects, iterating over all PEM blocks in the input and dispatching each to type-specific handlers.

## Key Components

- **`tryPem(pemBytes []byte, _password string) ([]*KeyInfo, error)`** — Entry point that loops over raw bytes using `pem.Decode`, collecting all decoded PEM blocks. Returns an error if no valid PEM blocks are found. The `_password` parameter is accepted for interface compatibility but unused.
- **`expandPem(block *pem.Block) *KeyInfo`** — Dispatches a decoded PEM block to the appropriate parser. Currently handles `CERTIFICATE` blocks via `parseCertificate`; returns a `KeyInfo` error record for any unrecognised block type.

## Usage Example

```go
pemData, err := os.ReadFile("/etc/ssl/cert.pem")
if err != nil {
    log.Fatal(err)
}

keys, err := tryPem(pemData, "")
if err != nil {
    log.Fatalf("failed to parse PEM: %v", err)
}

for _, k := range keys {
    fmt.Printf("Type: %s, Subject: %s\n", k.Type, k.Subject)
}
```

## Notes

- Based on [`kolide/launcher`](https://github.com/kolide/launcher/tree/main/pkg/osquery/tables) PEM parsing patterns.
- The loop breaks on the first undecodable remainder to avoid an infinite loop, which is the documented behaviour of `pem.Decode` when no PEM block is found.
- Only `CERTIFICATE` blocks produce structured output; all other block types (e.g. `PRIVATE KEY`, `RSA PRIVATE KEY`) result in an error-typed `KeyInfo` rather than a parse failure, allowing partial results to still be returned.
