Attempts to parse raw binary data as a DER-encoded X.509 certificate, returning a slice of `KeyInfo` structs on success.

## Key Components

- **`tryDer(data []byte, _password string) ([]*KeyInfo, error)`** — Entry point for DER parsing. Accepts raw bytes and an unused password parameter (for interface compatibility), delegates to `parseCertificate`, and wraps the result in a `KeyInfo` tagged with the `kiDER` format identifier.

## Usage Example

```go
data, err := os.ReadFile("certificate.der")
if err != nil {
    log.Fatal(err)
}

keys, err := tryDer(data, "")
if err != nil {
    log.Fatal(err)
}

for _, k := range keys {
    fmt.Println(k)
}
```

## Notes

- Based on [`github.com/kolide/launcher`](https://github.com/kolide/launcher) osquery tables implementation.
- The `_password` parameter is intentionally ignored — DER-encoded certificates are not encrypted, but the parameter exists to satisfy a common parser function signature used across multiple format handlers (PEM, PFX, etc.).
- Parsing is delegated to `parseCertificate`; errors from that function are propagated directly to the caller.
