Provides the main entry point for identifying cryptographic material (keys, certificates) from raw bytes by sequentially trying multiple format parsers.

## Key Components

- **`identifierSignature`** — Internal function type defining the contract for format-specific identifier functions (`func(data []byte, password string) ([]*KeyInfo, error)`).
- **`defaultIdentifiers`** — Ordered slice of identifier functions tried in sequence: `tryP12` → `tryDer` → `tryPem`.
- **`Identify`** — Public function that accepts raw bytes and an optional password, returning parsed `[]*KeyInfo` from the first successful format match.

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/pkg/cryptoinfo"

data, err := os.ReadFile("/path/to/certificate.p12")
if err != nil {
    log.Fatal(err)
}

keys, err := cryptoinfo.Identify(data, "optional-password")
if err != nil {
    log.Fatal(err)
}

if keys == nil {
    fmt.Println("No recognizable cryptographic material found")
    return
}

for _, k := range keys {
    fmt.Printf("Type: %s, Subject: %s\n", k.Type, k.Subject)
}
```

## Notes

- Returns `nil, nil` (not an error) when no supported format is recognized — callers should treat a `nil` result as "no parseable crypto material" rather than a failure.
- Format detection is attempted by content, not file extension. Future versions may support caller-specified ordering or extension-based hints.
- Integrates with the `dataflatten` subsystem and is intended as a long-term replacement for `pkg/keyidentifier`.
