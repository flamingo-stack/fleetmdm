Non-Windows implementation of script execution for the Fleet MDM agent's scripts package. It handles shebang detection to determine whether to run scripts via `/bin/sh` or directly, and captures combined output with an exit code.

## Key Components

- **`ExecCmd(ctx, scriptPath, env)`** — Executes a script file on non-Windows systems (Linux/macOS). Reads the script contents, validates the shebang line via `fleet.ValidateShebang`, and either invokes `/bin/sh` or executes the script directly (after `chmod 0700`). Sets a 1-second `WaitDelay` to ensure the subprocess is terminated on context cancellation. Returns combined stdout/stderr output, the process exit code (defaults to `-1` on failure to start), and any error.

## Usage Example

```go
ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()

output, exitCode, err := scripts.ExecCmd(ctx, "/tmp/my_script.sh", nil)
if err != nil {
    log.Printf("script error: %v", err)
}
fmt.Printf("exit=%d output=%s\n", exitCode, output)
```

## Notes

- Build-constrained to non-Windows targets (`//go:build !windows`).
- Uses `cmd.CombinedOutput()` so stdout and stderr are merged into a single byte slice.
- Exit code is only read from `ProcessState` when the context has not been cancelled, preventing misleading codes on timeout.
