Manages the lifecycle of an `osqueryd` process, providing a `Runner` type compatible with `oklog/run` for starting, monitoring, and interrupting osquery execution.

## Key Components

- **`Runner`** — Core struct wrapping an `osqueryd` process with context-aware lifecycle management and thread-safe cancellation.
- **`NewRunner(path string, options ...Option) (*Runner, error)`** — Constructs a new runner, validates the osqueryd binary path, applies functional options, and cleans up stale extension sockets.
- **`Execute() error`** — Starts osqueryd and blocks until exit. Supports single-query mode (blocking `cmd.Run()`) and daemon mode (supervised via `process.WaitOrKill`).
- **`Interrupt(err error)`** — Cancels the running context to signal osqueryd to stop; compatible with `oklog/run`.
- **`ExtensionSocketPath() string`** — Returns the platform-appropriate extension socket path (named pipe on Windows, Unix socket elsewhere).
- **`GetCommand() string`** — Returns the full osqueryd command string for logging (OpenFrame agent mode instrumentation).

### Functional Options

| Option | Description |
|---|---|
| `WithFlags(flags []string)` | Appends CLI flags to the osqueryd invocation |
| `WithEnv(env []string)` | Injects environment variables (`KEY=VAL` format) |
| `WithDataPath(dataPath, postfix string)` | Sets `--pidfile` and `--extensions_socket` paths |
| `WithShell()` | Adds `-S` flag and connects stdin for interactive shell |
| `SingleQuery()` | Runs a SQL statement and exits |
| `WithStderr(w io.Writer)` | Redirects stderr output |
| `WithStdout(w io.Writer)` | Redirects stdout output |
| `WithLogPath(path string)` | Sets `--logger_path` for osquery logs |

## Usage Example

```go
runner, err := osquery.NewRunner(
    "/usr/local/bin/osqueryd",
    osquery.WithDataPath("/var/orbit/data", ""),
    osquery.WithFlags([]string{"--config_path=/etc/osquery/osquery.conf"}),
    osquery.WithLogPath("/var/log/osquery"),
)
if err != nil {
    log.Fatal().Err(err).Msg("failed to create osquery runner")
}

// Use with oklog/run
g.Add(runner.Execute, runner.Interrupt)
```
