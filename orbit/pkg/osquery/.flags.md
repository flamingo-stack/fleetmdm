Generates the set of osquery command-line flags required for connecting an osquery agent to a Fleet server over TLS.

## Key Components

### `FleetFlags(osqueryVersion string, fleetURL *url.URL) []string`

Builds and returns a slice of osquery CLI flags configured for Fleet connectivity, including:

- **TLS/enrollment** — `--tls_hostname`, `--enroll_tls_endpoint`
- **Config** — `--config_plugin=tls`, `--config_tls_endpoint`, `--config_refresh=60`
- **Distributed queries** — `--distributed_plugin=tls`, read/write endpoints, `--distributed_tls_max_attempts=10`
- **Logging** — `--logger_plugin=tls,filesystem`, `--logger_tls_endpoint`
- **File carving** — `--disable_carver=false`, `--carver_disable_function=false`, begin/block endpoints, `--carver_block_size=8000000`
- **Version-gated flag** — `--tls_accept_gzip=true` appended only for osquery `>= 5.21.0`

All endpoint paths are joined with any URL prefix present in `fleetURL.Path` using `path.Join`.

## Usage Example

```go
import (
    "net/url"
    "github.com/flamingo-stack/fleetmdm/path/to/osquery"
)

fleetURL, _ := url.Parse("https://fleet.example.com/fleet")
flags := osquery.FleetFlags("5.21.0", fleetURL)
// flags includes "--tls_hostname=fleet.example.com",
//               "--tls_accept_gzip=true", etc.
```

## Notes

- `--config_refresh` defaults to `60` seconds; this overrides osquery's own default of `0` and can be further overridden via Fleet's served config.
- `--carver_disable_function` is independent of `--disable_carver` and governs SQL-level file carving (e.g. `SELECT carve(path) FROM processes`).
- GZip support (`--tls_accept_gzip=true`) requires osquery `5.21.0` or later; the flag is omitted for older versions to avoid startup errors.
