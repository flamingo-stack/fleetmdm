Defines Windows AMD64-specific default options for the Fleet Orbit updater, setting platform-appropriate paths and targets.

## Key Components

- **`defaultOptions`** – Pre-initialized `Options` struct with Windows-specific defaults:
  - `RootDirectory`: `C:\Program Files\Orbit`
  - `ServerURL`: `DefaultURL`
  - `RootKeys`: `defaultRootMetadata`
  - `LocalStore`: In-memory TUF store via `client.MemoryLocalStore()`
  - `InsecureTransport`: `false`
  - `Targets`: `WindowsTargets`

- **`init()`** – Overrides `DefaultOptions.RootDirectory` at startup using the `ProgramFiles` environment variable if set, ensuring compatibility with non-standard Windows installations.

## Usage Example

```go
// DefaultOptions is automatically populated for Windows AMD64 builds.
// The init() function adjusts the root directory at runtime:
//
// If %ProgramFiles% = "D:\Program Files", then:
//   DefaultOptions.RootDirectory => "D:\Program Files\Orbit"
//
// Use directly or copy and customize:
opts := update.DefaultOptions
opts.ServerURL = "https://my-fleet-server.example.com"
updater, err := update.NewUpdater(opts)
```

## Notes

- This file is build-constrained to `windows/amd64` via its filename suffix.
- The `ProgramFiles` environment variable fallback handles Windows systems where Program Files resides on a non-`C:` drive.
