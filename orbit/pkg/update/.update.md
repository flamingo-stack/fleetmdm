Manages TUF (The Update Framework)-based software updates for Fleet's orbit agent, handling secure binary downloads, version tracking, and directory initialization.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Updater` | struct | Core update manager with TUF client, retry logic, and mutex-protected state |
| `Options` | struct | Configuration for server URL, TLS settings, root keys, local store, and targets |
| `Targets` | type | `map[string]TargetInfo` tracking all managed update targets |
| `TargetInfo` | struct | Per-target metadata: platform, channel, file path, and optional exec validator |
| `NewUpdater` | func | Constructs and initializes an `Updater`, bootstrapping TUF trust from embedded root keys if no local metadata exists |
| `NewDisabled` | func | Returns a non-network `Updater` for local-only binary resolution |
| `SetTargetInfo` | func | Thread-safe update of a named target's `TargetInfo` |
| `RemoveTargetInfo` | func | Thread-safe removal of a target entry |
| `DefaultURL` | const | `https://updates.fleetdm.com` — Fleet's primary TUF server |
| `MetadataFileName` | const | `updates-metadata.json` — local TUF metadata file (introduced in orbit 1.38.0) |

## Usage Example

```go
store, _ := client.NewFileLocalStore("/var/lib/orbit/metadata")

updater, err := update.NewUpdater(update.Options{
    RootDirectory:  "/var/lib/orbit",
    ServerURL:      update.DefaultURL,
    RootKeys:       update.defaultRootMetadata,
    LocalStore:     store,
    Targets: update.Targets{
        "orbit": {
            Platform:             runtime.GOOS + "-" + runtime.GOARCH,
            Channel:              "stable",
            TargetFile:           "orbit",
            ExtractedExecSubPath: []string{"orbit"},
        },
    },
})
if err != nil {
    log.Fatal(err)
}

// Update a target's channel at runtime
updater.SetTargetInfo("orbit", update.TargetInfo{
    Channel:    "edge",
    TargetFile: "orbit",
})
```

> **Migration note:** Starting with orbit 1.38.0, metadata is stored in `updates-metadata.json` rather than `tuf-metadata.json`. Packages built with fleetctl 4.63.0+ include both files to support downgrades.
