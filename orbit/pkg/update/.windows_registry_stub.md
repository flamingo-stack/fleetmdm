Provides a no-op stub implementation of the Windows registry update function for non-Windows platforms using Go build constraints.

## Key Components

- **`updateUninstallFleetdRegistryVersion(newVersion string) error`** — Stub function that returns `nil` immediately; satisfies the interface on Linux, macOS, and other non-Windows platforms where registry operations are not applicable.

## Build Constraint

The `//go:build !windows` tag ensures this file is compiled only on non-Windows targets, while the real Windows implementation in a companion file handles actual registry writes.

## Usage Example

```go
// No direct invocation needed — the build system selects the correct
// implementation automatically based on the target OS.

// On Linux/macOS, calling this function is a safe no-op:
if err := updateUninstallFleetdRegistryVersion("1.2.3"); err != nil {
    log.Fatal(err) // never reached on non-Windows builds
}
```

## Notes

- Part of the `update` package within the [fleetmdm](https://github.com/flamingo-stack/fleetmdm) codebase.
- The real registry logic lives in the corresponding `windows_registry.go` (or similarly named) file compiled only when `GOOS=windows`.
- This pattern keeps cross-platform builds clean without `runtime.GOOS` checks scattered throughout business logic.
