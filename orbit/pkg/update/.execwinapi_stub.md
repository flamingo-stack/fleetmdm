Stub implementations for Windows MDM (Mobile Device Management) enrollment functions on non-Windows platforms, using a build constraint to ensure these no-op stubs are compiled only when the target OS is not Windows.

## Key Components

| Function | Description |
|---|---|
| `RunWindowsMDMEnrollment` | No-op stub for MDM enrollment |
| `RunWindowsMDMUnenrollment` | No-op stub for MDM unenrollment |
| `IsRunningOnWindowsServer` | Always returns `false, nil` on non-Windows |
| `TriggerWindowsMDMSync` | No-op stub for MDM sync trigger |

## Usage Example

These stubs are selected automatically by the Go build system on non-Windows targets. No explicit import or call changes are needed — the real Windows implementations in the companion file take over when `GOOS=windows`.

```go
// Cross-platform code can safely call these functions;
// on non-Windows builds the stubs are silently resolved.
if err := update.RunWindowsMDMEnrollment(args); err != nil {
    log.Fatal(err) // Never triggered on Linux/macOS
}

isServer, _ := update.IsRunningOnWindowsServer()
// isServer == false on all non-Windows platforms
```

## Notes

- Build constraint `//go:build !windows` ensures these stubs are excluded from Windows builds, where the real WinAPI implementations apply.
- All functions return zero values (`nil` errors, `false` booleans), making them safe no-ops for cross-platform compilation without conditional logic at the call site.
- Source: [`execwinapi_stub.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/update/execwinapi_stub.go)
