Defines the `OrbitConfigFetcher` interface for retrieving Orbit configuration from the Fleet server.

## Key Components

- **`OrbitConfigFetcher`** — Interface with a single method `GetConfig() (*fleet.OrbitConfig, error)` that returns the current Orbit configuration or an error.

## Usage Example

```go
type myFetcher struct{}

func (f *myFetcher) GetConfig() (*fleet.OrbitConfig, error) {
    // retrieve and return Orbit config
    return &fleet.OrbitConfig{}, nil
}

var fetcher OrbitConfigFetcher = &myFetcher{}
cfg, err := fetcher.GetConfig()
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Implementations of this interface are typically injected into update or agent components that need to react to server-side configuration changes.
- See [`fleet.OrbitConfig`](https://github.com/flamingo-stack/fleetmdm/blob/main/server/fleet) for the full configuration schema.
