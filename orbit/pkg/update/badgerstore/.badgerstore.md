A `client.LocalStore` implementation for the [go-tuf](https://github.com/theupdateframework/go-tuf) client that persists TUF metadata using [BadgerDB](https://github.com/dgraph-io/badger) as the backing key-value store.

## Key Components

| Symbol | Description |
|---|---|
| `badgerStore` | Internal struct wrapping a `*badger.DB` instance |
| `New(db *badger.DB)` | Constructor returning a `client.LocalStore` backed by Badger |
| `SetMeta(name, meta)` | Writes raw JSON metadata under a prefixed key |
| `GetMeta()` | Returns all stored metadata as a `map[string]json.RawMessage` by prefix-scanning |
| `DeleteMeta(name)` | Removes a single metadata entry by name |
| `Close()` | Closes the underlying Badger DB |
| `keyPrefix` | Constant `":tuf-metadata:"` namespacing all TUF keys within the DB |

## Usage Example

```go
import (
    badgerv2 "github.com/dgraph-io/badger/v2"
    "github.com/flamingo-stack/fleetmdm/path/to/badgerstore"
    "github.com/theupdateframework/go-tuf/client"
)

// Open (or create) a Badger database
db, err := badgerv2.Open(badgerv2.DefaultOptions("/tmp/tuf-db"))
if err != nil {
    log.Fatal(err)
}

// Create the TUF local store backed by Badger
store := badgerstore.New(db)
defer store.Close()

// Use with a go-tuf client
remote, _ := client.NewHTTPRemoteStore("https://tuf.example.com", nil, nil)
tufClient := client.NewClient(store, remote)

// Metadata is automatically persisted to BadgerDB via SetMeta/GetMeta
if err := tufClient.Init(trustedRootJSON); err != nil {
    log.Fatal(err)
}
```

All keys are namespaced with the `:tuf-metadata:` prefix, so the Badger instance can be safely shared with other subsystems without key collisions.
