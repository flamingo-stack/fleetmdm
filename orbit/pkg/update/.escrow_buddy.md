Manages the lifecycle of [Escrow Buddy](https://github.com/macadmins/escrow-buddy), an authorization plugin that rotates FileVault encryption keys on macOS without user interaction, driven by Fleet server notifications via `OrbitConfig`.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `EscrowBuddyRunner` | `struct` | Core runner that wraps the update `Runner`, enforces a run interval, and gates concurrent executions via a mutex |
| `NewEscrowBuddyRunner` | `func` | Constructor returning an `fleet.OrbitConfigReceiver` configured with a parent `Runner` and polling interval |
| `Run` | `method` | Main entry point called by the orbit config loop; enables or disables key rotation based on `cfg.Notifications.RotateDiskEncryptionKey` |
| `setTargetsAndHashes` | `method` | Registers `escrowBuddy` as a TUF target and caches its local hash; rolls back on failure |
| `setGenerateNewKeyTo` | `method` | Writes the `GenerateNewKey` preference via `defaults write` to enable or disable key generation |
| `setAuthDBSetup` | `method` | Runs `AuthDBSetup.sh` to re-register Escrow Buddy in the macOS authorization database (guards against OS updates resetting it) |

## Usage Example

```go
// Wrap an existing update Runner with Escrow Buddy support
ebRunner := update.NewEscrowBuddyRunner(updateRunner, 30*time.Minute)

// Receive an OrbitConfig from the Fleet server (e.g. inside an orbit config loop)
cfg := &fleet.OrbitConfig{
    Notifications: fleet.OrbitConfigNotifications{
        RotateDiskEncryptionKey: true,
    },
}

if err := ebRunner.Run(cfg); err != nil {
    log.Error().Err(err).Msg("Escrow Buddy runner failed")
}
```

> **Platform note:** This runner is macOS-only. It shells out to `/usr/bin/defaults` and `AuthDBSetup.sh` paths that do not exist on other platforms.
