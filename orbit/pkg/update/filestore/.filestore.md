A file-backed implementation of the `go-tuf` `client.LocalStore` interface that persists TUF (The Update Framework) metadata as JSON on disk.

## Key Components

| Symbol | Description |
|---|---|
| `fileStore` | Private struct holding the filename path and an in-memory metadata map |
| `metadataMap` | Type alias for `map[string]json.RawMessage` representing stored TUF metadata |
| `New(filename string)` | Constructor that initializes the store and reads existing data from disk |
| `SetMeta` | Writes a named metadata entry and flushes to disk |
| `GetMeta` | Returns all stored metadata entries |
| `DeleteMeta` | Removes a named metadata entry and flushes to disk |
| `readData` | Reads and deserializes JSON from the backing file; initializes empty map if file does not exist |
| `writeData` | Serializes metadata to JSON and syncs to the backing file using `secure.OpenFile` |

## Usage Example

```go
import "github.com/fleetdm/fleet/v4/orbit/pkg/update/filestore"

// Create or open an existing store
store, err := filestore.New("/var/lib/orbit/tuf-metadata.json")
if err != nil {
    log.Fatal(err)
}
defer store.Close()

// Store a metadata entry
raw := json.RawMessage(`{"version":1}`)
if err := store.SetMeta("root.json", raw); err != nil {
    log.Fatal(err)
}

// Retrieve all metadata
meta, err := store.GetMeta()
if err != nil {
    log.Fatal(err)
}

// Remove an entry
if err := store.DeleteMeta("timestamp.json"); err != nil {
    log.Fatal(err)
}
```

## Notes

- The store uses `secure.OpenFile` (rather than `os.OpenFile`) to enforce safe file permissions (`constant.DefaultFileMode`).
- Each mutating operation (`SetMeta`, `DeleteMeta`) immediately flushes and `fsync`s to disk, preventing metadata loss on crash.
- If the backing file does not exist, the store initializes with an empty map rather than returning an error.
