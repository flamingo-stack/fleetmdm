Executes external commands and captures combined stdout/stderr output into error messages for improved debugging context.

## Key Components

- **`runCmdCollectErr(exe string, args ...string) error`** — Runs an external executable with the provided arguments, collecting combined stdout/stderr. If the command fails and produces output, the output (truncated to 512 bytes) is appended to the returned error.

## Usage Example

```go
err := runCmdCollectErr("softwareupdate", "--install", "--all")
if err != nil {
    // err includes both the exit error and any captured output
    log.Printf("update failed: %v", err)
}
```

## Notes

- Output is capped at **512 bytes** to prevent excessively large error messages.
- The `var _ = runCmdCollectErr` blank assignment suppresses unused-symbol compilation errors on non-Darwin platforms where this helper may not be called.
