Wraps `os.File` to implement the go-tuf `Destination` interface by adding a `Delete` method that closes and removes the file.

## Key Components

- **`fileDestination`** — Struct embedding `*os.File`, extending it with cleanup functionality for use as a go-tuf download destination.
- **`Delete() error`** — Closes the file and removes it from disk via `os.Remove`, enabling rollback/cleanup of partially downloaded TUF artifacts.

## Usage Example

```go
f, err := os.CreateTemp("", "tuf-download-*")
if err != nil {
    return err
}
dst := &fileDestination{File: f}

// Pass dst to a go-tuf client as a Destination.
// On failure, clean up the temp file:
if err := dst.Delete(); err != nil {
    log.Printf("cleanup failed: %v", err)
}
```
