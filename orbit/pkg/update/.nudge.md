Manages the lifecycle of Nudge on macOS within Fleet's orbit update system — handling configuration sync, target registration, and interval-based launching of the Nudge app.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `NudgeConfigReceiver` | struct | Middleware that processes orbit config, writes Nudge config to disk, and launches Nudge on a configurable interval |
| `NudgeConfigFetcherOptions` | struct | Configuration options including `UpdateRunner`, `RootDir`, `Interval`, and an optional mock `runNudgeFn` for testing |
| `ApplyNudgeConfigReceiverMiddleware` | func | Constructor that wraps options into a `fleet.OrbitConfigReceiver` |
| `Run` | method | Entry point called on each config poll; gates Nudge setup/launch based on config presence |
| `setTargetsAndHashes` | method | Registers `nudge` as a TUF target and caches its local hash; rolls back on failure |
| `configure` | method | Marshals `fleet.NudgeConfig` to JSON and writes to `nudge-config.json` only if the file is missing, has wrong permissions, or its contents differ |
| `launch` | method | Launches the Nudge app as the logged-in user via `execuser.Run`, respecting the configured interval and suppressing re-launch after a persistent exit error |
| `nudgeLaunchErr` | struct | Records exit code, stderr detail, config file path, and timestamp when Nudge fails to start; prevents repeated launch attempts |

## Usage Example

```go
receiver := update.ApplyNudgeConfigReceiverMiddleware(update.NudgeConfigFetcherOptions{
    UpdateRunner: runner,
    RootDir:      "/opt/orbit",
    Interval:     30 * time.Minute,
})

// Called by the orbit config polling loop
if err := receiver.Run(orbitConfig); err != nil {
    log.Error().Err(err).Msg("nudge receiver error")
}
```

> **Note:** If Nudge exits with a non-zero code, `launchErr` is set and further launch attempts are suppressed for the lifetime of the process. A hash mismatch resets this guard and triggers a fresh target refresh.
