Manages periodic synchronization of osquery command-line flags and extensions from Fleet server to local disk, triggering Orbit restarts when changes are detected.

## Key Components

### Types

- **`FlagRunner`** — Reconciles Fleet-provided osquery flags with the local `osquery.flags` file and restarts Orbit on changes.
- **`FlagUpdateOptions`** — Configuration for `FlagRunner`; holds `RootDir` (orbit state directory).
- **`ExtensionRunner`** — Reconciles Fleet-provided extension configs with the local `extensions.load` file, updating TUF metadata as needed.
- **`ExtensionUpdateOptions`** — Configuration for `ExtensionRunner`; holds `RootDir`.

### Functions

| Function | Description |
|---|---|
| `NewFlagReceiver` | Constructs a `FlagRunner` with a restart callback and options. |
| `FlagRunner.Run` | Compares Fleet flags to disk; writes `osquery.flags` and triggers restart on diff. No-op when `config.Flags` is nil/empty. |
| `NewExtensionConfigUpdateRunner` | Constructs an `ExtensionRunner` with options, a TUF `Runner`, and a restart callback. |
| `ExtensionRunner.Run` | Syncs `extensions.load` from Fleet config; clears the file and restarts Orbit when extensions are removed. |
| `getFlagsFromJSON` | Converts a flat JSON object to `map[string]string` with `--` prefixed keys. |
| `writeFlagFile` | Serializes a `map[string]string` to `key=value` lines in `osquery.flags`. |
| `readFlagFile` | Parses `osquery.flags` from disk into `map[string]string`, skipping comments and blank lines. |

## Usage Example

```go
// Flag sync runner
runner := update.NewFlagReceiver(
    func(reason string) { log.Info().Str("reason", reason).Msg("restarting orbit") },
    update.FlagUpdateOptions{RootDir: "/var/lib/orbit"},
)
if err := runner.Run(orbitConfig); err != nil {
    log.Error().Err(err).Msg("flag update failed")
}

// Extension sync runner
extRunner := update.NewExtensionConfigUpdateRunner(
    update.ExtensionUpdateOptions{RootDir: "/var/lib/orbit"},
    tufRunner,
    func(reason string) { log.Info().Str("reason", reason).Msg("restarting orbit") },
)
if err := extRunner.Run(orbitConfig); err != nil {
    log.Error().Err(err).Msg("extension update failed")
}
```

> **Behavior note:** When `command_line_flags` is omitted from Fleet agent settings, `osquery.flags` is left untouched. An explicit empty object (`{}`) clears the file. Extension removal truncates `extensions.load` and triggers an Orbit restart to unload previously active extensions.
