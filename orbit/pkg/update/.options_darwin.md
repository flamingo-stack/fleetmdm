Defines the default macOS-specific configuration options for the Orbit update system, initializing the `defaultOptions` variable with Darwin platform values.

## Key Components

- **`defaultOptions`** (`Options`): Package-level variable containing the default update configuration for macOS (Darwin) builds, with the following fields:
  - `RootDirectory`: `/opt/orbit` — installation root path on macOS
  - `ServerURL`: `DefaultURL` — the default TUF update server endpoint
  - `RootKeys`: `defaultRootMetadata` — TUF root of trust metadata
  - `LocalStore`: `client.MemoryLocalStore()` — in-memory TUF metadata store
  - `InsecureTransport`: `false` — enforces secure HTTPS transport
  - `Targets`: `DarwinTargets` — macOS-specific update target definitions

## Usage Example

```go
// defaultOptions is used implicitly when initializing the updater on macOS.
// Override specific fields as needed before passing to the updater.
opts := defaultOptions
opts.ServerURL = "https://custom-update-server.example.com"

updater, err := update.New(opts)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- This file is build-constrained to Darwin (macOS) via its filename (`_darwin.go`), meaning it is only compiled on macOS targets.
- Counterpart files (e.g., `options_linux.go`, `options_windows.go`) provide equivalent defaults for other platforms.
- The TUF `MemoryLocalStore` means metadata is not persisted across restarts; suitable for ephemeral or first-run scenarios.
