Middleware component that conditionally enables swiftDialog as a TUF-managed update target based on MDM-related notification flags received in the Orbit configuration.

## Key Components

### `SwiftDialogDownloader`
A struct implementing `fleet.OrbitConfigReceiver` that wraps an `UpdateRunner` to manage swiftDialog installation and updates.

### `ApplySwiftDialogDownloaderMiddleware`
Constructor function that wraps a `Runner` in a `SwiftDialogDownloader` and returns it as an `OrbitConfigReceiver`.

### `Run(cfg *fleet.OrbitConfig) error`
Core logic method that evaluates Orbit config notifications to determine whether swiftDialog should be registered as an update target:

- **No-ops** when config is `nil`, `UpdateRunner` is `nil`, or none of `NeedsMDMMigration`, `RenewEnrollmentProfile`, or `RunSetupExperience` are active
- Registers `swiftDialog` as a TUF target and caches its local hash if not already tracked
- Triggers an immediate update via `UpdateAction()` when `RunSetupExperience` is set, to ensure swiftDialog is available before the setup experience begins
- Rolls back target registration if `StoreLocalHash` fails

## Usage Example

```go
runner, err := update.NewRunner(updaterOpts, runnerOpts)
if err != nil {
    log.Fatal().Err(err).Msg("failed to create update runner")
}

receiver := update.ApplySwiftDialogDownloaderMiddleware(runner)

// receiver.Run() is called by the Orbit config polling loop
cfg := &fleet.OrbitConfig{
    Notifications: fleet.OrbitConfigNotifications{
        RunSetupExperience: true,
    },
}
if err := receiver.Run(cfg); err != nil {
    log.Error().Err(err).Msg("swiftDialog middleware error")
}
```
