Defines default TUF (The Update Framework) target configurations for all supported platforms and components in the Fleet orbit update system.

## Key Components

### `DefaultOptions`

A package-level variable pointing to `defaultOptions` (defined elsewhere), used as the baseline configuration when constructing an update client.

### Platform Target Maps (`Targets`)

Pre-built `Targets` maps grouping orbit and osquery TUF targets by platform:

| Variable | Platform |
|---|---|
| `DarwinTargets` | macOS (`macos`, `macos-app`) |
| `LinuxTargets` | Linux x86-64 |
| `LinuxArm64Targets` | Linux ARM64 |
| `WindowsTargets` | Windows x86-64 |
| `WindowsArm64Targets` | Windows ARM64 (experimental osquery support) |

### Individual Component Targets (`TargetInfo`)

Standalone `TargetInfo` values for optional/auxiliary components:

| Variable | Component | Platform(s) |
|---|---|---|
| `DesktopMacOSTarget` | Fleet Desktop | macOS |
| `DesktopWindowsTarget` | Fleet Desktop | Windows x86-64 |
| `DesktopWindowsArm64Target` | Fleet Desktop | Windows ARM64 |
| `DesktopLinuxTarget` | Fleet Desktop | Linux (sets `LD_LIBRARY_PATH` on exec check) |
| `DesktopLinuxArm64Target` | Fleet Desktop | Linux ARM64 |
| `NudgeMacOSTarget` | Nudge | macOS |
| `SwiftDialogMacOSTarget` | Swift Dialog | macOS |
| `EscrowBuddyMacOSTarget` | Escrow Buddy | macOS (`.pkg`, no extracted exec) |

## Usage Example

```go
// Select targets for the current platform and build an update client
opts := update.DefaultOptions
opts.Targets = update.LinuxTargets

// Add Fleet Desktop to the target set
opts.Targets[constant.DesktopTUFTargetName] = update.DesktopLinuxTarget

client, err := update.NewUpdater(opts)
if err != nil {
    log.Fatal(err)
}
```

> **Note:** `DesktopLinuxTarget` includes a `CustomCheckExec` that runs the binary with `--help` and injects `LD_LIBRARY_PATH` to validate shared library resolution after a download. `DesktopLinuxArm64Target` performs the same check without the `LD_LIBRARY_PATH` override.
