Orchestrates periodic TUF-based update checks for orbit/osquery binaries, managing target hashes, symlink updates, and version comparisons within the `oklog/run` execution model.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Runner` | Core struct holding the `Updater`, options, cancellation channel, and cached local file hashes |
| `RunnerOptions` | Configuration for check interval, watched targets, and expired-signature startup behavior |
| `NewRunner` | Constructs a `Runner`, pre-caching local file hashes for all tracked targets as an optimization |
| `Execute` | Main loop — randomizes the initial tick, then polls on `CheckInterval`; returns on update or cancellation |
| `UpdateAction` | Fetches fresh TUF metadata, compares local hashes against repository hashes, and triggers updates |
| `updateTarget` | Calls `Updater.Get`, extracts the binary version, updates the orbit symlink, and patches the Windows registry when the version changes |
| `needsOrbitSymlinkUpdate` | Reads the existing orbit symlink and reports whether it points to the expected binary path |
| `StoreLocalHash` / `HasLocalHash` | Cache and query the SHA hash of a target's locally installed binary |
| `AddRunnerOptTarget` / `RemoveRunnerOptTarget` / `HasRunnerOptTarget` | Thread-safe management of the watched-target list |
| `compareVersion` | Semver comparison with structured logging; returns a signed integer for callers that need to act on upgrade/downgrade |
| `randomizeDuration` | Cryptographically random jitter (capped at 10 minutes) to spread initial update checks across a fleet |

## Usage Example

```go
updater, _ := update.NewUpdater(update.Options{...})

runner, err := update.NewRunner(updater, update.RunnerOptions{
    CheckInterval: 15 * time.Minute,
    Targets: []string{
        constant.OrbitTUFTargetName,
        constant.OsqueryTUFTargetName,
    },
})
if err != nil {
    log.Fatal(err)
}

// Compatible with oklog/run
var g run.Group
g.Add(runner.Execute, runner.Interrupt)
g.Run()
```
