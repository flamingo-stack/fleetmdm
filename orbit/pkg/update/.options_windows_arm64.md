Platform-specific default configuration for the update system targeting Windows ARM64 architecture, defining installation paths, server settings, and update targets.

## Key Components

- **`defaultOptions`** — Initializes the `Options` struct with Windows ARM64-specific defaults:
  - `RootDirectory`: `C:\Program Files\Orbit`
  - `ServerURL`: `DefaultURL`
  - `RootKeys`: `defaultRootMetadata`
  - `LocalStore`: in-memory TUF store via `client.MemoryLocalStore()`
  - `InsecureTransport`: `false`
  - `Targets`: `WindowsArm64Targets`

- **`init()`** — Overrides the root directory at startup using the `ProgramFiles` environment variable if set, ensuring compatibility with non-standard Windows installations.

## Usage Example

```go
// defaultOptions is used implicitly when no custom options are provided.
// The init() function adjusts RootDirectory at runtime:
//
// If %ProgramFiles% = "D:\Program Files"
// Then DefaultOptions.RootDirectory = "D:\Program Files\Orbit"

updater, err := update.NewUpdater(update.DefaultOptions)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- This file is build-constrained to `windows/arm64` via its filename suffix (`_windows_arm64.go`).
- The `ProgramFiles` env var check in `init()` handles environments where Windows is installed to a non-default drive or path.
- Counterpart files exist for other platforms (e.g., `options_linux_amd64.go`, `options_darwin_amd64.go`).
