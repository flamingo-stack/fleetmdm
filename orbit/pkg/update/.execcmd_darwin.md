Runs the macOS enrollment profile renewal command as the console user.

## Key Components

- **`runRenewEnrollmentProfile()`** — Executes `profiles renew -type enrollment` via `launchctl asuser` in the context of the current console user, collecting any errors through `runCmdCollectErr`.

## Usage Example

```go
if err := runRenewEnrollmentProfile(); err != nil {
    log.Errorf("failed to renew enrollment profile: %v", err)
}
```

## Notes

- Build-constrained to `darwin` only; not compiled on other platforms.
- Uses `stat -f "%u" /dev/console` to resolve the UID of the logged-in console user, ensuring `profiles renew` runs in the correct user session rather than as root.
- Delegates shell execution and error collection to `runCmdCollectErr`.
