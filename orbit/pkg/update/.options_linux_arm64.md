Defines default update configuration options for the Linux ARM64 platform, initializing the `defaultOptions` variable with platform-specific target binaries and standard update settings.

## Key Components

- **`defaultOptions`** (`Options`) — Package-level variable providing the default update configuration for Linux ARM64, including:
  - `RootDirectory`: `/opt/orbit`
  - `ServerURL`: `DefaultURL`
  - `RootKeys`: `defaultRootMetadata`
  - `LocalStore`: in-memory TUF local store via `client.MemoryLocalStore()`
  - `InsecureTransport`: `false`
  - `Targets`: `LinuxArm64Targets`

## Usage Example

```go
// defaultOptions is used automatically on Linux ARM64 builds.
// To customize, copy and modify:
opts := defaultOptions
opts.ServerURL = "https://my-custom-update-server.example.com"

updater, err := update.New(opts)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- This file is build-tag constrained to `linux/arm64` via its filename (`_linux_arm64.go`), ensuring it is only compiled for that platform.
- The `LocalStore` uses an in-memory store from [`go-tuf`](https://github.com/theupdateframework/go-tuf), meaning TUF metadata is not persisted across restarts.
- For other platform defaults, see the corresponding `options_<os>_<arch>.go` files in the [`update`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/update) package.
