Defines default `Options` for the Fleet orbit update system on Linux AMD64 platforms, configuring the TUF (The Update Framework) client with Linux-specific settings.

## Key Components

- **`defaultOptions`** — Package-level variable providing platform-specific defaults for the `Options` struct:
  - `RootDirectory`: `/opt/orbit`
  - `ServerURL`: `DefaultURL`
  - `RootKeys`: `defaultRootMetadata`
  - `LocalStore`: In-memory TUF local store via `client.MemoryLocalStore()`
  - `InsecureTransport`: `false` (TLS enforced)
  - `Targets`: `LinuxTargets`

## Usage Example

```go
// defaultOptions is consumed internally by the update package.
// To override specific fields, pass functional options:
updater, err := update.New(update.Options{
    RootDirectory: "/custom/orbit",
    ServerURL:     update.DefaultURL,
    Targets:       update.LinuxTargets,
})
```

## Notes

- This file is build-constrained to `linux/amd64` via its filename (`_linux_amd64`).
- Parallel files exist for other platforms (e.g., `options_darwin_amd64.go`, `options_windows_amd64.go`), each defining their own `defaultOptions` with platform-appropriate `Targets` and `RootDirectory`.
- See [`orbit/pkg/update/`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/pkg/update/) for the full update package context.
