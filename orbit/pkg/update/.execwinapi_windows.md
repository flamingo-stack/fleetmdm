Windows-only implementation of MDM enrollment, unenrollment, and sync trigger operations using direct Windows API calls via `mdmregistration.dll` and registry inspection.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `RunWindowsMDMEnrollment` | func | Exported entry point for enrolling a Windows host into MDM; skips server OS installs |
| `RunWindowsMDMUnenrollment` | func | Exported entry point for unenrolling a Windows host from MDM; skips server OS installs |
| `TriggerWindowsMDMSync` | func | Exported entry point that launches `deviceenroller.exe /o <GUID> /c` to trigger an on-demand OMA-DM session |
| `IsRunningOnWindowsServer` | func | Checks the `InstallationType` registry value to determine if the host is a Windows Server |
| `enrollHostToMDM` | func | Calls `RegisterDeviceWithManagement` via `mdmregistration.dll` with a UTF-16 encoded access token payload |
| `unenrollHostFromMDM` | func | Calls `UnregisterDeviceWithManagement` via `mdmregistration.dll` |
| `fleetMDMEnrollmentGUID` | func | Scans `HKLM\SOFTWARE\Microsoft\Enrollments` to find the Fleet MDM enrollment GUID |
| `improveWindowsAPIError` | func | Translates opaque Windows HRESULT/HTTP error codes into human-readable error messages |
| `generateWindowsMDMAccessTokenPayload` | func | Marshals orbit node key and enrollment type into a JSON access token payload |
| `windowsEnrollmentGUIDRe` | var | Regex that validates the GUID shape before passing it to `deviceenroller.exe` |
| `windowsMDMSyncTriggerTimeout` | const | 2-minute cap on the `deviceenroller` subprocess |

## Usage Example

```go
// Enroll a Windows device into Fleet MDM
err := RunWindowsMDMEnrollment(WindowsMDMEnrollmentArgs{
    DiscoveryURL: "https://fleet.example.com/api/mdm/microsoft/discovery",
    OrbitNodeKey: "abc123",
})
if err != nil && !errors.Is(err, errIsWindowsServer) {
    log.Fatal().Err(err).Msg("enrollment failed")
}

// Trigger an immediate OMA-DM sync session
if err := TriggerWindowsMDMSync(); err != nil {
    log.Warn().Err(err).Msg("MDM sync trigger failed (best-effort)")
}

// Unenroll when decommissioning
if err := RunWindowsMDMUnenrollment(args); err != nil {
    log.Error().Err(err).Msg("unenrollment failed")
}
```

> **Note:** All functions guard against accidental execution on Windows Server by reading `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\InstallationType`. The `unsafe` package is used exclusively for passing UTF-16 pointers to Windows API calls and is suppressed from `gosec` linting intentionally.
