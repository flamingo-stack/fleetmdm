Manages dynamic log-level adjustments for the Orbit agent by toggling the global zerolog level in response to server-pushed `OrbitConfig.DebugLogging` changes.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `DebugLogReceiver` | struct | Holds the startup debug flag; implements the config runner interface |
| `startedInDebug` | field | Floor flag — prevents the server from lowering the level below `debug` when Orbit launched with `--debug` or `ORBIT_DEBUG=1` |
| `NewDebugLogReceiver` | constructor | Returns a `*DebugLogReceiver` initialized with the agent's startup debug state |
| `Run` | method | Compares the current global zerolog level against the desired level derived from `OrbitConfig.DebugLogging` and applies a change when they differ |

## Behaviour

```text
startedInDebug=false, DebugLogging=nil/false  → zerolog.InfoLevel
startedInDebug=false, DebugLogging=true       → zerolog.DebugLevel
startedInDebug=true,  DebugLogging=any        → zerolog.DebugLevel (floor)
```

Level changes are logged at `Info` with `from` / `to` fields so the transition is always visible regardless of the new level.

## Usage Example

```go
// Instantiate once at agent startup.
receiver := update.NewDebugLogReceiver(startedInDebug)

// Called by the config runner loop whenever OrbitConfig is refreshed.
cfg := &fleet.OrbitConfig{DebugLogging: ptr.Bool(true)}
if err := receiver.Run(cfg); err != nil {
    log.Error().Err(err).Msg("debug log runner failed")
}
```
