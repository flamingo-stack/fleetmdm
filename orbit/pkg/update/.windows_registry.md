Windows-only utility for managing the Fleet agent (`fleetd`) uninstall entry in the Windows Registry, specifically updating the `DisplayVersion` value under `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`.

## Key Components

### Constants

| Constant | Value | Purpose |
|---|---|---|
| `REG_FLEETD_DISPLAY_NAME` | `"Fleet osquery"` | Display name used to identify the fleetd registry entry |
| `HKEY_LOCAL_MACHINE_PATH` | `Computer\HKEY_LOCAL_MACHINE` | Absolute registry root path |
| `REG_UNINSTALL_REL_PATH` | `SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` | Relative path to the uninstall registry directory |
| `REG_UNINSTALL_ABS_PATH` | Combined absolute path | Used in error messages for clarity |

### Functions

- **`updateUninstallFleetdRegistryVersion(newVersion string) error`** — Public entry point. Locates the fleetd registry key and sets its `DisplayVersion` string value to `newVersion`.
- **`findUninstallFleetdRegKeyRelPath() (string, error)`** — Iterates all subkeys under the `Uninstall` registry path, matching by `DisplayName == "Fleet osquery"`, and returns the relative key path including the GUID subkey.

## Usage Example

```go
// Called during a fleetd self-update to keep the Windows uninstaller metadata current
if err := updateUninstallFleetdRegistryVersion("1.23.0"); err != nil {
    log.Errorf("failed to update registry version: %v", err)
}
```

## Notes

- Build-constrained to **Windows only** (`//go:build windows`).
- Uses [`golang.org/x/sys/windows/registry`](https://pkg.go.dev/golang.org/x/sys/windows/registry) for registry access.
- Since fleetd does not store its own GUID, `findUninstallFleetdRegKeyRelPath` performs a linear scan of all uninstall entries — gracefully skipping keys without a `DisplayName`.
- All opened registry key handles are closed via `defer`.
