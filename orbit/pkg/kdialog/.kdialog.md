KDE dialog wrapper that implements Fleet's `dialog.Dialog` interface using the `kdialog` CLI tool to display GUI prompts (password entry and info messages) to the active KDE desktop user on Linux.

## Key Components

| Symbol | Description |
|--------|-------------|
| `KDialog` | Main struct wrapping `kdialog` execution with an injectable command runner |
| `New()` | Constructor returning a `*KDialog` with the default command executor |
| `ShowEntry()` | Displays a password input dialog; returns trimmed output or a typed error (`ErrCanceled`, `ErrTimeout`, `ErrUnknown`) |
| `ShowInfo()` | Displays a message box dialog; returns a typed error on failure |
| `execCmdWithOutput()` | Resolves the active GUI user, then runs `kdialog` as that user via `execuser.RunWithOutput` |

**Error mapping:**

| Exit code | Error |
|-----------|-------|
| `1` | `dialog.ErrCanceled` |
| `124` | `dialog.ErrTimeout` |
| other | `dialog.ErrUnknown` |

## Usage Example

```go
package main

import (
    "fmt"
    "time"

    "github.com/fleetdm/fleet/v4/orbit/pkg/dialog"
    "github.com/fleetdm/fleet/v4/orbit/pkg/kdialog"
)

func main() {
    kd := kdialog.New()

    // Prompt user for a password
    password, err := kd.ShowEntry(dialog.EntryOptions{
        Title:   "Fleet Authentication",
        Text:    "Enter your password:",
        TimeOut: 30 * time.Second,
    })
    if err != nil {
        switch err {
        case dialog.ErrCanceled:
            fmt.Println("User cancelled")
        case dialog.ErrTimeout:
            fmt.Println("Dialog timed out")
        default:
            fmt.Printf("Error: %v\n", err)
        }
        return
    }
    fmt.Printf("Received password of length %d\n", len(password))

    // Show an informational message
    _ = kd.ShowInfo(dialog.InfoOptions{
        Title:   "Success",
        Text:    "Authentication complete.",
        TimeOut: 10 * time.Second,
    })
}
```

> **Note:** This package is Linux/KDE-specific. `execCmdWithOutput` requires an active GUI session user; it will return an error if no GUI user is detected.
