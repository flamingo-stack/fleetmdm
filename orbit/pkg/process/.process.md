Provides process lifecycle management with graceful shutdown support, wrapping `os/exec.Cmd` with context-aware wait-or-kill semantics.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ExecCmd` | Interface | Abstracts `exec.Cmd` methods (`Start`, `Wait`, `OsProcess`) for testability |
| `OsProcess` | Interface | Abstracts `os.Process` methods (`Signal`, `Kill`) |
| `Process` | Struct | Wraps `ExecCmd` with extended lifecycle methods |
| `NewWithCmd` | Constructor | Creates a `Process` from a real `*exec.Cmd` |
| `WaitOrKill` | Method | Waits for process exit; sends interrupt on context cancellation, escalates to `SIGKILL` after `killDelay` |
| `stopSignal` | Function | Returns `os.Interrupt` on Unix or `os.Kill` on Windows |

## Usage Example

```go
cmd := exec.Command("my-service", "--flag")
if err := cmd.Start(); err != nil {
    log.Fatal(err)
}

proc := process.NewWithCmd(cmd)

ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()

// Wait up to 30s, then interrupt; kill after 5s if still running.
if err := proc.WaitOrKill(ctx, 5*time.Second); err != nil {
    log.Printf("process exited with error: %v", err)
}
```

## Shutdown Behavior

```text
ctx expires
    │
    ├─► Signal(os.Interrupt / os.Kill on Windows)
    │
    └─► [killDelay > 0] wait killDelay
            │
            └─► OsProcess.Kill()  ← hard kill if still running
```

## Notes

- `WaitOrKill` requires `Start()` to have been called before invocation; returns an error immediately if `OsProcess()` is `nil`.
- The interrupt/kill escalation logic is adapted from the [Go standard library test runner](https://github.com/golang/go/blob/8981092d71aee273d27b0e11cf932a34d4d365c1/src/cmd/go/script_test.go#L1131-L1190).
- `newWithMock` (unexported) accepts a custom `ExecCmd` for unit testing without spawning real processes.
