Provides a no-op stub implementation of `RotateDiskEncryptionKey` for non-Darwin (non-macOS) platforms using a build constraint.

## Key Components

- **`RotateDiskEncryptionKey(maxRetries int) error`** — Returns `nil` immediately; satisfies the cross-platform interface on Linux, Windows, and other non-macOS targets.

## Usage Example

```go
// Automatically selected by the Go toolchain on non-Darwin platforms.
// No configuration needed — the stub compiles in place of the real implementation.
err := useraction.RotateDiskEncryptionKey(3)
// err is always nil on non-Darwin platforms
```

## Notes

- The `//go:build !darwin` constraint ensures this file is compiled on all platforms **except** macOS.
- The real implementation lives in a Darwin-specific counterpart (e.g., `useraction_darwin.go`), which interacts with macOS disk encryption APIs.
- See the full package at [`ee/desktop/user/useraction/`](https://github.com/flamingo-stack/fleetmdm/blob/main/ee/desktop/user/useraction/useraction_notdarwin.go).
