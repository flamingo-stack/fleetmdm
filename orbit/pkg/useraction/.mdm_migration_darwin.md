Provides the macOS-specific implementation of the MDM migration user action flow using swiftDialog for interactive enrollment dialogs during device migration to Fleet MDM.

## Key Components

### Types & Interfaces

- **`baseDialog`** – Core dialog renderer that wraps swiftDialog binary execution, handles process lifecycle, interrupt signaling, and exit code parsing.
- **`dialog`** – Interface requiring `CanRun()`, `Exit()`, and `render()` methods.
- **`swiftDialogMDMMigrator`** – Full MDM migrator implementation composing `baseDialog`, migration state, frequency control, and unenrollment wait logic.
- **`readWriter`** – Interface abstracting read/write operations on the migration sentinel file.

### Exit Codes

| Constant | Value | Meaning |
|---|---|---|
| `primaryBtnExitCode` | `0` | User clicked primary button |
| `secondaryBtnExitCode` | `2` | User clicked secondary button |
| `timeoutExitCode` | `4` | Dialog timed out |
| `userQuitExitCode` | `10` | User quit the dialog |

### Key Functions

- **`NewMDMMigrator`** – Constructor; validates `showCh` buffer size and returns a configured `swiftDialogMDMMigrator`.
- **`isDarkMode()`** – Detects macOS dark mode via `defaults read -g AppleInterfaceStyle`.
- **`render()`** – Builds swiftDialog flags (icon, fonts, layout) and delegates to `baseDialog.render()`.
- **`renderLoadingSpinner()`** – Shows the unenrollment progress dialog with a disabled Start button.
- **`renderError()`** – Shows an error dialog, optionally with a "Contact IT" link.
- **`waitForUnenrollment()`** – Polls enrollment status for up to 90 seconds (5-second intervals) before returning an error.

### Templates

Three Go `text/template` variants drive dialog message content:
- `mdmMigrationTemplatePreSonoma` – Pre-Sonoma notification flow
- `mdmManualMigrationTemplate` – Manual enrollment flow
- `mdmADEMigrationTemplate` – ADE (DEP) enrollment flow

## Usage Example

```go
migrator := NewMDMMigrator(
    "/usr/local/bin/dialog",
    15*time.Minute,
    myHandler,
    myReadWriter,
    "https://fleet.example.com",
    make(chan struct{}, 1),
)

if migrator.CanRun() {
    migrator.ShowIfNeeded(ctx)
}
```

> **Note:** This file is Darwin-only (`//go:build darwin`). The sentinel file at `/private/var/db/ConfigurationProfiles/Settings/.cloudConfigProfileInstalled` is used to detect active DEP enrollment status without shelling out to `profiles`.
