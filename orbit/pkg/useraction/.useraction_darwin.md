macOS-specific implementation of disk encryption key rotation via user-facing AppleScript dialogs and FileVault CLI commands.

## Key Components

- **`RotateDiskEncryptionKey(maxRetries int) error`** — Public entry point that orchestrates the full key rotation flow: prompts for credentials, retries on invalid password, enforces a retry limit, and shows success/error dialogs.
- **`displayDialog(opts dialogOptions) (string, error)`** — Renders an AppleScript (JXA) dialog template and executes it via `osascript`, handling user cancellation (`errCanceled`), timeout (`errTimeout`), and JSON output parsing.
- **`askUserCredentials() (string, string, error)`** — Detects the current console user via `/usr/bin/stat` and prompts for their login password using a hidden-input dialog.
- **`rotateFileVaultKey(u, p string) error`** — Drives `fdesetup changerecovery -personal` via `expect`, piping credentials through environment variables (`FV_USER`, `FV_PASS`). Detects authentication failure from output text and returns `errInvalidPassword`.
- **`wrongPasswordMessage`, `errorMessage`, `showSuccessMsg`** — Helper dialogs for user feedback at each stage of the flow.
- **`dialogScript`** — A `text/template` template that generates JXA JavaScript passed to `osascript -l JavaScript -s s` for machine-readable JSON output.

## Usage Example

```go
// Attempt to rotate the FileVault key, retrying up to 3 times on wrong password
err := useraction.RotateDiskEncryptionKey(3)
if err != nil {
    log.Printf("Key rotation failed: %v", err)
}
```

## Notes

- Build-constrained to `darwin` only (`//go:build darwin`).
- All dialogs enforce a 30-second timeout (`defaultDialogTimeout`) to prevent indefinite blocking.
- Credentials are passed to `expect`/`fdesetup` via environment variables, not command-line args, to avoid shell exposure.
