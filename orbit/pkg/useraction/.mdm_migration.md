Defines the core interfaces for MDM migration functionality used by Fleet Desktop, including dialog display, migration state management, and remote action handling.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `MDMMigrator` | Primary interface a migration implementation must satisfy to integrate with Fleet Desktop |
| `MDMMigratorHandler` | Handles remote callbacks triggered by the migrator |
| `MDMOfflineWatcher` | Monitors and responds to offline state during migration |

### Types

| Type | Description |
|------|-------------|
| `MDMMigratorProps` | Props passed to the migrator for dialog rendering, analogous to UI framework props |

### `MDMMigrator` Methods

| Method | Description |
|--------|-------------|
| `CanRun()` | Checks runtime prerequisites (e.g., swiftDialog binary presence on macOS) |
| `SetProps()` | Updates migrator display properties |
| `Show()` | Displays the dialog if no other dialog is active |
| `ShowInterval()` | Displays the dialog on a defined interval if conditions are met |
| `Exit()` | Terminates any processes started by the migrator |
| `MigrationInProgress()` | Returns the in-progress migration type, if any |
| `MarkMigrationCompleted()` | Finalizes migration by removing the migration file |

## Usage Example

```go
// Implement MDMMigrator for a custom migration
type MyMigrator struct{}

func (m *MyMigrator) CanRun() bool { return true }
func (m *MyMigrator) SetProps(props useraction.MDMMigratorProps) { /* configure */ }
func (m *MyMigrator) Show() error { return nil }
func (m *MyMigrator) ShowInterval() error { return nil }
func (m *MyMigrator) Exit() {}
func (m *MyMigrator) MigrationInProgress() (string, error) { return "", nil }
func (m *MyMigrator) MarkMigrationCompleted() error { return nil }

// Configure and use
migrator := &MyMigrator{}
if migrator.CanRun() {
    migrator.SetProps(useraction.MDMMigratorProps{
        OrgInfo:     orgInfo,
        IsUnmanaged: false,
        DisableTakeover: true,
    })
    migrator.Show()
}
```
