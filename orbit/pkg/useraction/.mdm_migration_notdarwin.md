Provides no-op stub implementations of the MDM migration interfaces for non-Darwin (non-macOS) platforms, ensuring cross-platform compilation compatibility.

## Key Components

### Constructors

- **`NewMDMMigrator`** — Returns a `NoopMDMMigrator`, satisfying the `MDMMigrator` interface on non-Darwin platforms.
- **`StartMDMMigrationOfflineWatcher`** — Returns a `NoopOfflineWatcher`, satisfying the `MDMOfflineWatcher` interface on non-Darwin platforms.

### Types

- **`NoopMDMMigrator`** — No-op implementation of `MDMMigrator`. All methods are safe no-ops (`CanRun` returns `false`, errors return `nil`).
- **`NoopOfflineWatcher`** — No-op implementation of `MDMOfflineWatcher`. `ShowIfOffline` always returns `false`.

## Usage Example

This file is selected automatically by the Go build system on non-Darwin targets via the `//go:build !darwin` constraint. No manual instantiation is needed; call the same constructor as on Darwin:

```go
migrator := useraction.NewMDMMigrator(
    "/some/path",
    5*time.Minute,
    handler,
    mrw,
    "https://fleet.example.com",
    showCh,
)

// On non-Darwin platforms, CanRun() always returns false
if migrator.CanRun() {
    migrator.Show()
}
```

> **Note:** The real macOS implementation lives in the Darwin-specific counterpart file. This stub exists solely to satisfy the interface contract on Linux and Windows builds without introducing platform-specific compilation errors.
