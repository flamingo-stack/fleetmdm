Windows-specific constants and security identifiers for the `constant` package, providing default file permissions and well-known Windows Security Identifier (SID) values used for access control.

## Key Components

### Constants

| Name | Value | Description |
|---|---|---|
| `DefaultExecutableMode` | `0o700` | Default permission mode for created executable files (read-only on Windows) |

### Variables

| Name | SID String | Description |
|---|---|---|
| `SystemSID` | `S-1-5-18` | Local System account SID |
| `AdminSID` | `S-1-5-32-544` | Built-in Administrators group SID |
| `UserSID` | `S-1-5-32-545` | Built-in Users group SID |

### Functions

- **`mustSID(identifier string) *windows.SID`** — Converts a SID string (e.g. `"S-1-5-18"`) to a `*windows.SID`. Panics on failure, intended for package-level initialization only.

## Usage Example

```go
//go:build windows

package mypackage

import "github.com/flamingo-stack/fleetmdm/constant"

func applyPermissions(path string) error {
    // Use predefined SIDs for ACL assignment
    adminSID := constant.AdminSID
    systemSID := constant.SystemSID

    // Use DefaultExecutableMode when creating files
    err := os.Chmod(path, constant.DefaultExecutableMode)
    // ...
    _ = adminSID
    _ = systemSID
    return err
}
```

## Notes

- SID values mirror those used by [osquery's deployment tooling](https://github.com/osquery/osquery/blob/d2be385d71f401c85872f00d479df8f499164c5a/tools/deployment/chocolatey/tools/osquery_utils.ps1)
- `DefaultExecutableMode` (`0o700`) has no meaningful effect on Windows; `os.Chmod` is limited on that platform
- This file is build-tag guarded (`//go:build windows`) and only compiled on Windows targets
