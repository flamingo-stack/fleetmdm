Defines shared constants used across the fleetd/Orbit agent codebase, covering file system defaults, enrollment behavior, TLS credentials, TUF update targets, and MDM migration configuration.

## Key Components

| Constant Group | Examples | Purpose |
|---|---|---|
| **File Modes** | `DefaultDirMode`, `DefaultFileMode`, `DefaultWorldReadableFileMode`, `DefaultSystemdUnitMode` | Standard Unix permission bits for files and directories |
| **File Names** | `OrbitNodeKeyFileName`, `OsqueryEnrollSecretFileName`, `DesktopTokenFileName`, `HardwareUUIDFileName` | On-disk filenames for agent state and credentials |
| **TLS Credentials** | `FleetTLSClientCertificateFileName`, `UpdateTLSClientKeyFileName`, `FleetHTTPSignatureCertificateFileName` | Client cert/key filenames for Fleet and update server connections |
| **Enrollment** | `OrbitEnrollMaxRetries`, `OrbitEnrollBackoffMultiplier`, `OrbitEnrollRetrySleep` | Retry/backoff configuration for agent enrollment |
| **MDM Migration** | `MDMMigrationTypeManual`, `MDMMigrationTypeADE`, `MDMMigrationTypePreSonoma`, `MDMMigrationOfflineWatcherInterval` | Migration type identifiers and watcher timing |
| **TUF Targets** | `OrbitTUFTargetName`, `OsqueryTUFTargetName`, `DesktopTUFTargetName` | Component names as registered in the TUF update repository |
| **System Service** | `SystemServiceName`, `DesktopAppExecName` | OS service and process identifiers |

## Usage Example

```go
package main

import (
    "fmt"
    "os"

    "github.com/flamingo-stack/fleetmdm/orbit/pkg/constant"
)

func main() {
    // Create the orbit base directory with standard permissions
    if err := os.MkdirAll("/var/lib/orbit", constant.DefaultDirMode); err != nil {
        panic(err)
    }

    // Write the node key file with restricted permissions
    err := os.WriteFile(
        "/var/lib/orbit/"+constant.OrbitNodeKeyFileName,
        []byte("my-secret-key"),
        constant.DefaultFileMode,
    )
    if err != nil {
        panic(err)
    }

    fmt.Printf("Enrolling as service: %s\n", constant.SystemServiceName)
    fmt.Printf("Max retries: %d, backoff: %dx, sleep: %s\n",
        constant.OrbitEnrollMaxRetries,
        constant.OrbitEnrollBackoffMultiplier,
        constant.OrbitEnrollRetrySleep,
    )
}
```
