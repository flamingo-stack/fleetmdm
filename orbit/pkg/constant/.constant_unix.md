Defines Unix-specific constants for the `constant` package, providing platform-appropriate file permission values on non-Windows systems.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `DefaultExecutableMode` | `0o755` | Octal file permission mode for created executable files (`rwxr-xr-x`) |

## Usage Example

```go
import "github.com/flamingo-stack/fleetmdm/constant"

// Apply default executable permissions when creating a file
err := os.Chmod("/usr/local/bin/agent", constant.DefaultExecutableMode)
```

> **Note:** This file is excluded from Windows builds via the `//go:build !windows` build tag. A separate `constant_windows.go` file provides the Windows equivalent.
