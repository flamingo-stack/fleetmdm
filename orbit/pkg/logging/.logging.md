Provides conditional error logging utilities that suppress log output when a specified environment variable is set to `"1"`, useful for silencing expected errors in specific deployment environments.

## Key Components

| Function | Description |
|---|---|
| `LogErrIfEnvNotSet` | Logs at **info** level if `envVarName` is not set to `"1"` |
| `LogErrIfEnvNotSetDebug` | Logs at **debug** level if `envVarName` is not set to `"1"` |
| `LogErrIfEnvNotSetWithEvent` | Core implementation; accepts a custom `*zerolog.Event` for flexible log levels |

## Usage Example

```go
// Suppress info-level error when SUPPRESS_DB_ERR=1
logging.LogErrIfEnvNotSet("SUPPRESS_DB_ERR", err, "database connection failed")

// Suppress debug-level error when SUPPRESS_CACHE_ERR=1
logging.LogErrIfEnvNotSetDebug("SUPPRESS_CACHE_ERR", err, "cache miss on startup")

// Use a custom zerolog event (e.g., warn level)
logging.LogErrIfEnvNotSetWithEvent("SUPPRESS_WARN", err, "optional service unavailable", log.Warn())
```

Set the environment variable to `"1"` to silence the log:

```bash
export SUPPRESS_DB_ERR=1
```

## Notes

- Suppression is triggered **only** when the env var equals exactly `"1"`; any other value (including empty string) allows the log to emit.
- Built on [`zerolog`](https://github.com/rs/zerolog) — integrate with your existing `zerolog` setup without additional configuration.
