A thread-safe file-based token reader that caches token values and refreshes them only when the underlying file has changed or expired.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Reader` | struct | Core type holding the file path, cached token value, and file modification time |
| `Read()` | method | Returns the token, refreshing from disk only if the file has changed or cache is empty |
| `HasChanged()` | method | Compares the cached `mtime` against the file's current modification time |
| `HasExpired()` | method | Reports whether more than 1 hour has elapsed since the last file read |
| `GetCached()` | method | Returns the in-memory token value without hitting the filesystem |
| `GetMtime()` | method | Returns the last recorded file modification time |

All exported methods acquire `sync.Mutex` before accessing shared fields, making `Reader` safe for concurrent use.

## Usage Example

```go
r := &token.Reader{
    Path: "/etc/myapp/token",
}

// Read token from file (uses cache if file is unchanged)
value, err := r.Read()
if err != nil {
    log.Fatalf("failed to read token: %v", err)
}
fmt.Println("token:", value)

// Check expiry before making an authenticated request
if expired, remaining := r.HasExpired(); expired {
    log.Println("token has expired, refreshing...")
} else {
    log.Printf("token valid for another %s", remaining)
}
```

## Notes

- **Cache invalidation** is driven by file `mtime`, not a polling interval — the file is re-read only when `mtime` changes or the cache is empty.
- **Expiration** (`HasExpired`) is independent of `HasChanged`; a file may be unchanged but still considered expired after 1 hour.
- The internal `readFile` performs two syscalls (`ReadFile` + `Stat`) to ensure the stored `mtime` matches the content that was read.
