Defines Go text templates used to generate macOS installer artifacts for the Fleet orbit agent, including package metadata, distribution definition, post-install script, and launchd daemon configuration.

## Key Components

| Template | Purpose |
|---|---|
| `macosPackageInfoTemplate` | Generates `PackageInfo` XML for the flat `.pkg` format, specifying identifier, version, install location, and post-install script hook |
| `macosDistributionTemplate` | Generates a Distribution Definition XML (`.dist`) controlling the macOS installer GUI experience, choices, and supported architectures (`arm64`, `x86_64`) |
| `macosPostinstallTemplate` | Generates a `postinstall` bash script that creates symlinks for the orbit binary, handles in-band self-upgrades, and registers/starts the launchd daemon |
| `macosLaunchdTemplate` | Generates the `com.fleetdm.orbit.plist` launchd daemon plist, configuring environment variables (Fleet URL, channels, secrets, feature flags) and service behavior |

## Template Data Fields

The templates are rendered with a struct providing these notable fields:

| Field | Used In |
|---|---|
| `.Identifier`, `.Version` | `PackageInfo`, `Distribution` |
| `.OrbitChannel`, `.LegacyVarLibSymlink`, `.StartService` | `postinstall` |
| `.FleetURL`, `.EnrollSecret`, `.FleetCertificate` | `launchd plist` |
| `.OrbitChannel`, `.OsquerydChannel`, `.DesktopChannel` | `launchd plist` |
| `.Debug`, `.Insecure`, `.DisableUpdates`, `.Desktop` | `launchd plist` |
| `.EnableScripts`, `.UseSystemConfiguration`, `.DisableKeystore` | `launchd plist` |

## Usage Example

```go
// Render the launchd plist template
var buf bytes.Buffer
err := macosLaunchdTemplate.Execute(&buf, Options{
    FleetURL:        "https://fleet.example.com",
    OrbitChannel:    "stable",
    OsquerydChannel: "stable",
    UpdateURL:       "https://updates.example.com",
    OrbitUpdateInterval: "15m",
    EnrollSecret:    "abc123",
    Desktop:         true,
    DesktopChannel:  "stable",
})
```
