Defines Go `text/template` instances for generating Windows-specific packaging artifacts used during Fleet osquery MSI installer creation.

## Key Components

| Template | Description |
|---|---|
| `ManifestXMLTemplate` | Generates a Windows application manifest XML (`.manifest`) declaring assembly identity, version, processor architecture, and execution trust level (`asInvoker`). |
| `windowsWixTemplate` | Generates a WiX XML installer definition (`.wxs`) for the Fleet osquery Windows MSI, including directory structure, service installation, registry searches, custom actions, and upgrade logic. |
| `windowsOsqueryEventLogTemplate` | Generates a Windows Event Log instrumentation manifest for the osqueryd provider (`FleetDM`), mapping event symbols and channels. |

All templates use `missingkey=error` to fail fast on missing data fields.

## Template Variables

**`ManifestXMLTemplate`**

| Field | Description |
|---|---|
| `.Version` | Assembly version string |
| `.Arch` | Processor architecture (e.g., `amd64`) |

**`windowsWixTemplate`** (selected fields)

| Field | Description |
|---|---|
| `.FleetURL` | Fleet server URL injected as MSI property |
| `.OrbitChannel` / `.OsquerydChannel` / `.DesktopChannel` | Update channels for each component |
| `.EnableScripts` | Enables script execution in Orbit service |
| `.Desktop` | Enables Fleet Desktop |
| `.EnableEndUserEmailProperty` / `.EndUserEmail` | Optional end-user email for MDM enrollment |
| `.EnableEUATokenProperty` | Optional end-user authentication token property |
| `.NativePlatform` | Platform string used in file source paths |

## Usage Example

```go
import (
    "bytes"
    "text/template"
)

type ManifestData struct {
    Version string
    Arch    string
}

func renderManifest(version, arch string) (string, error) {
    data := ManifestData{Version: version, Arch: arch}
    var buf bytes.Buffer
    if err := ManifestXMLTemplate.Execute(&buf, data); err != nil {
        return "", err
    }
    return buf.String(), nil
}
```
