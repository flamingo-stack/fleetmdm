Provides tools for building Orbit installation packages, including configuration options, update initialization via TUF, and package artifact management.

## Key Components

### `Options` struct
Comprehensive configuration struct for package generation, covering:
- Fleet server connection (`FleetURL`, `EnrollSecret`, `FleetCertificate`)
- TLS client auth (`FleetTLSClientCertificate`, `FleetTLSClientKey`)
- Update channels (`OrbitChannel`, `OsquerydChannel`, `DesktopChannel`)
- macOS code signing and notarization (`SignIdentity`, `Notarize`, `MacOSDevIDCertificateContent`)
- Platform/architecture targeting (`Architecture`, `NativePlatform`)
- Feature flags (`Desktop`, `EnableScripts`, `DisableUpdates`, `DisableKeystore`)

### `UpdatesData` struct
Holds resolved paths and versions for the three Orbit components fetched from the TUF repository: Orbit, osqueryd, and Fleet Desktop.

### Key Functions

| Function | Description |
|---|---|
| `InitializeUpdates(updateOpt)` | Connects to TUF, fetches metadata and binaries for `orbit`, `osqueryd`, and optionally `desktop`. Returns populated `UpdatesData`. |
| `initializeTempDir()` | Creates a `0755`-permissioned temp directory for staging package artifacts. |
| `saveHashAndRemoveTarGz(path)` | Computes SHA-512 of a `.tar.gz` artifact, writes a `.sha512` sidecar, then removes the archive to avoid bundling duplicates. |

## Usage Example

```go
updateOpt := update.Options{
    RootDirectory: "/tmp/orbit-staging",
    ServerURL:     "https://tuf.fleetctl.com",
    Targets: update.DefaultTargets,
}

data, err := packaging.InitializeUpdates(updateOpt)
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Orbit %s at %s\n", data.OrbitVersion, data.OrbitPath)
fmt.Printf("osqueryd %s at %s\n", data.OsquerydVersion, data.OsquerydPath)
```

> **Note:** Functions in this package are **not safe for concurrent use**.
