Builds macOS `.pkg` installer packages for the Fleet orbit agent, supporting both native macOS tooling and cross-platform Linux builds with optional code signing and notarization.

## Key Components

- **`BuildPkg(opt Options) (string, error)`** — Main entry point that orchestrates the full `.pkg` build: initializes temp directories, fetches TUF update metadata, writes all configuration files, assembles the xar/BOM archive, optionally signs and notarizes, then copies the final package to the output path.
- **`writePackageInfo`** — Renders and writes the `PackageInfo` metadata XML into the flat package structure.
- **`writeScripts`** — Renders and writes the `postinstall` shell script (executable at `0o744`).
- **`writeLaunchd`** — Renders and writes the `com.fleetdm.orbit.plist` LaunchDaemon for macOS service management.
- **`writeDistribution`** — Renders and writes the `Distribution` XML metadata file.
- **`writeFleetServerCertificate` / `writeUpdateServerCertificate`** — Copies TLS server certificates (`fleet.pem`, `update.pem`) into the orbit root.
- **`writeFleetClientCertificate` / `writeUpdateClientCertificate`** — Copies mTLS client certificate and key pairs into the orbit root.
- **`xarBom`** — Assembles the xar archive with CPIO payloads and a Bill of Materials (BOM), supporting both macOS (`mkbom`/`lsbom`) and Linux (`bomutils`).
- **`bomRegexp`** — Regex used to parse and transform `lsbom` output to normalize ownership to root/admin.

## Usage Example

```go
pkg, err := packaging.BuildPkg(packaging.Options{
    FleetURL:        "https://fleet.example.com",
    EnrollSecret:    "my-secret",
    UpdateURL:       "https://tuf.example.com",
    OrbitChannel:    "stable",
    OsquerydChannel: "stable",
    StartService:    true,
    Desktop:         true,
    SignIdentity:    "Developer ID Installer: Acme Corp",
    Notarize:        false,
})
if err != nil {
    log.Fatal(err)
}
fmt.Println("Package written to:", pkg)
```

> **Note:** Cross-platform Linux builds require `bomutils`, `xar`, and `cpio` installed, with `Options.NativeTooling` set to `true`. macOS builds use native system tools (`mkbom`, `productbuild`, `productsign`).
