Wrapper package that executes the WiX toolchain (Heat, Candle, Light) for building Windows `.msi` installers, supporting three execution modes: Docker (default), native Windows, and local WiX binaries via Wine on macOS.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `Heat` | `func` | Runs `heat.exe` to generate WiX XML fragments from a directory |
| `Candle` | `func` | Runs `candle.exe` to compile `.wxs` source files into `.wixobj` objects |
| `Light` | `func` | Runs `light.exe` to link `.wixobj` files into the final `orbit.msi` |
| `darwinWineExecutable` | `func` | Detects Wine version on macOS and returns `wine` (≥v10) or `wine64` (<v10) |
| `imageName` | `const` | Docker image `fleetdm/wix:latest` used for containerised builds |
| `WineCmd` / `Wine64Cmd` | `const` | Wine executable names used to set `WINEDEBUG=-all` on Wine-based runs |

## Usage Example

```go
// Build path containing WiX source files
buildDir := "/tmp/orbit-msi-build"

// Step 1: Generate heat.wxs from the root directory
if err := wix.Heat(buildDir, false, ""); err != nil {
    log.Fatal(err)
}

// Step 2: Compile heat.wxs and main.wxs into .wixobj files
if err := wix.Candle(buildDir, false, "", "x64"); err != nil {
    log.Fatal(err)
}

// Step 3: Link .wixobj files into orbit.msi
if err := wix.Light(buildDir, false, ""); err != nil {
    log.Fatal(err)
}

// --- Alternative: local WiX dir on macOS via Wine ---
localWix := "/usr/local/wix"
if err := wix.Heat(buildDir, false, localWix); err != nil {
    log.Fatal(err)
}
```

**Execution mode selection** (per function):

| `native` | `localWixDir` | Mode |
|---|---|---|
| `false` | `""` | Docker (`fleetdm/wix:latest`) |
| `true` | `""` | Native Windows `heat`/`candle`/`light` on `$PATH` |
| `false` | `"/path/to/wix"` | Local `.exe` via Wine (macOS) or direct (Windows) |
