Builds a `.pkg.tar.zst` package (Arch Linux package format) by delegating to the NFPM build system using the default Arch Linux packager.

## Key Components

- **`BuildPkgTarZst(opt Options) (string, error)`** — Accepts packaging options and returns the output path of the generated `.pkg.tar.zst` file. Wraps `buildNFPM` with `arch.Default`. **Not safe for concurrent use.**

## Usage Example

```go
path, err := packaging.BuildPkgTarZst(packaging.Options{
    Name:    "myapp",
    Version: "1.0.0",
    // additional fields...
})
if err != nil {
    log.Fatal(err)
}
fmt.Println("Package built at:", path)
```

## Notes

- Delegates to [`buildNFPM`](https://github.com/flamingo-stack/fleetmdm/blob/main/pkg/packaging/nfpm.go) internally using [`arch.Default`](https://github.com/goreleaser/nfpm) as the packager target.
- Concurrent calls to this function are **not safe** — ensure external synchronization if building packages in parallel.
