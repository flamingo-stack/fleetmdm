Provides macOS package signing and notarization helpers using the `rcodesign` CLI tool, wrapping both operations with automatic retry logic.

## Key Components

- **`rSign(pkgPath, cert string) error`** — Signs a macOS package using a PEM certificate. Writes the certificate to a temporary file, invokes `rcodesign sign`, and retries up to 3 times on failure.
- **`rNotarizeStaple(pkg, apiKeyID, apiKeyIssuer, apiKeyContent string) error`** — Notarizes and staples a macOS package via Apple's notary service. Writes App Store Connect API keys to disk, invokes `rcodesign notarize --staple`, and retries up to 3 times.
- **`writeAPIKeys(issuer, id, content string) (string, error)`** — Writes the App Store Connect private key (`.p8`) to `~/.appstoreconnect/private_keys/AuthKey_<id>.p8`, the path expected by `rcodesign` and Apple's Transporter tool.

## Usage Example

```go
// Sign a .pkg file with a PEM certificate
err := rSign("/path/to/fleet.pkg", pemCertString)
if err != nil {
    log.Fatalf("signing failed: %v", err)
}

// Notarize and staple the signed package
err = rNotarizeStaple(
    "/path/to/fleet.pkg",
    "ABC123DEF4",            // App Store Connect Key ID
    "your-issuer-uuid",      // Issuer ID
    privateKeyP8Content,     // .p8 key file contents
)
if err != nil {
    log.Fatalf("notarization failed: %v", err)
}
```

> **Note:** `rcodesign` must be installed and available on `$PATH`. Both `rSign` and `rNotarizeStaple` clean up temporary credential files via `defer os.Remove(...)` regardless of outcome.
