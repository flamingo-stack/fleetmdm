Shared Linux packaging logic for building `.deb`, `.rpm`, and `.pkg` (Arch Linux) packages using the [nfpm](https://nfpm.goreleaser.com/) library. It handles directory scaffolding, update metadata initialization, file content assembly, and maintainer script generation for the Fleet orbit agent.

## Key Components

- **`buildNFPM(opt Options, pkger nfpm.Packager) (string, error)`** — Core function that orchestrates the full Linux package build pipeline: creates temp directories, fetches TUF update targets, writes configuration/script files, assembles file contents with symlinks, and produces the final package via the provided `nfpm.Packager`.

- **`writeSystemdUnit(opt Options, rootPath string) error`** — Writes the `orbit.service` systemd unit file to `usr/lib/systemd/system/`, configuring auto-restart, CPU quota (`20%`), and environment file loading.

- **`envTemplate`** — A `text/template` that renders `/etc/default/orbit`, conditionally emitting environment variables for Fleet URL, TLS certificates, enroll secret, update channels, desktop mode, and other orbit runtime flags.

- **`postInstallSafeRestart`** — A reusable shell snippet embedded in post-install scripts to safely restart orbit, delaying the restart by 60 seconds via `systemd-run` when an in-band self-upgrade is detected (avoids terminating orbit mid-script).

## Usage Example

```go
import "github.com/goreleaser/nfpm/v2/deb"

opt := packaging.Options{
    FleetURL:        "https://fleet.example.com",
    EnrollSecret:    "abc123",
    OrbitChannel:    "stable",
    OsquerydChannel: "stable",
    UpdateURL:       "https://tuf.fleetdm.com",
    Architecture:    packaging.ArchAmd64,
    Desktop:         true,
}

pkger := &deb.Deb{}
outPath, err := buildNFPM(opt, pkger)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Package written to:", outPath)
```

> **Note:** Architecture must be `ArchAmd64` or `ArchArm64`; any other value returns an error. RPM packages additionally receive a `posttrans` script, and Arch Linux packages receive `preupgrade`/`postupgrade` hooks.
