Handles macOS notarization and stapling for packaged artifacts using Apple's notarization service via the `gon` library.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Notarize` | `func(path, bundleIdentifier string) error` | Submits a `.zip`, `.dmg`, or `.pkg` to Apple's notarization service |
| `Staple` | `func(path string) error` | Staples the notarization ticket to a `.app`, `.pkg`, or `.dmg` |
| `NotarizeStaple` | `func(path, bundleIdentifier string) error` | Convenience wrapper that runs both `Notarize` then `Staple` |
| `statusHuman` | `struct` | Internal `notarize.Status` implementation that prints progress to stdout |

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `AC_USERNAME` | ✅ | Apple ID / Developer ID email |
| `AC_PASSWORD` | ✅ | App-specific password for the Apple ID |
| `AC_TEAM_ID` | ⚠️ Optional | Required for Apple Enterprise Developer accounts |

## Usage Example

```go
// Notarize and staple a DMG in one call
err := packaging.NotarizeStaple("/path/to/app.dmg", "com.example.myapp")
if err != nil {
    log.Fatal().Err(err).Msg("failed to notarize")
}

// Or run steps individually
if err := packaging.Notarize("/path/to/app.zip", "com.example.myapp"); err != nil {
    log.Fatal().Err(err).Msg("notarization failed")
}
if err := packaging.Staple("/path/to/app.dmg"); err != nil {
    log.Fatal().Err(err).Msg("stapling failed")
}
```

> **Note:** Notarization can take minutes to hours. Progress is printed to stdout via `statusHuman`, which is adapted from [`gon` v0.2.3](https://github.com/mitchellh/gon/blob/v0.2.3/cmd/gon/status_human.go) since it is not exported by that library.
