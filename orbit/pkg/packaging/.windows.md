Builds Windows MSI packages for the Fleet osquery agent by orchestrating WiX toolset compilation steps, file generation, and update metadata initialization.

## Key Components

- **`BuildMSI(opt Options) (string, error)`** — Main entry point. Creates a temp workspace, initializes TUF update metadata, writes all required files, invokes WiX pipeline (Heat → TransformHeat → Candle → Light), and outputs the `.msi` artifact.
- **`checkWine(wineChecked bool) error`** — Verifies Wine is installed on macOS when using local WiX binaries.
- **`checkDockerAvailable() error`** — Probes whether the Docker CLI and daemon are reachable; used to decide between the Docker and Wine+WiX fallback paths.
- **`writeWixFile`** — Renders `main.wxs` from the Windows WiX template.
- **`writeEventLogFile`** — Renders `osquery.man` (Windows Event Log manifest).
- **`writePowershellInstallerUtilsFile`** — Renders `installer_utils.ps1` for MSI install-time logic.
- **`writeManifestXML`** — Generates `manifest.xml` for Windows version-info embedding.
- **`createVersionInfo`** — Builds a `goversioninfo.VersionInfo` struct used to produce the `resource_windows.syso` metadata binary.

## Usage Example

```go
outFile, err := packaging.BuildMSI(packaging.Options{
    FleetURL:        "https://fleet.example.com",
    EnrollSecret:    "s3cr3t",
    OrbitChannel:    "stable",
    OsquerydChannel: "stable",
    UpdateURL:       "https://tuf.example.com",
    Architecture:    packaging.ArchAmd64,
    Desktop:         true,
})
if err != nil {
    log.Fatal(err)
}
fmt.Println("MSI written to:", outFile) // e.g. fleet-osquery.msi
```

## Notes

- Not safe for concurrent use (uses a shared temp directory per call).
- On **macOS**, defaults to a Docker-based WiX build. Falls back to Wine + auto-downloaded WiX 3.14 if Docker is unavailable (deprecated path).
- On **Windows**, grants read permissions via `icacls` to avoid Docker container permission errors.
- Orbit version gates control optional MSI properties: `END_USER_EMAIL` (≥ v1.28.0) and `EUA_TOKEN` (≥ v1.55.0).
