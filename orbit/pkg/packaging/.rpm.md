Thin wrapper around the `nfpm` library that produces a `.rpm` package from the provided build options.

## Key Components

- **`BuildRPM(opt Options) (string, error)`** — Delegates to `buildNFPM` using `rpm.Default` as the packager. Returns the output file path on success, or an error. **Not safe for concurrent use.**

## Usage Example

```go
path, err := packaging.BuildRPM(packaging.Options{
    Name:    "myapp",
    Version: "1.0.0",
    // ...additional fields
})
if err != nil {
    log.Fatal(err)
}
fmt.Println("RPM created at:", path)
```

## Notes

- Concurrency is not supported; call `BuildRPM` sequentially or guard with a mutex if used across goroutines.
- Relies on [`goreleaser/nfpm`](https://github.com/goreleaser/nfpm) under the hood — ensure RPM build dependencies (e.g. `rpmbuild`) are available in the environment.
- See [`buildNFPM`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/packaging/buildNFPM.go) for shared packaging logic and the `Options` struct definition.
