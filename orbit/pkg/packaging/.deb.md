Builds a Debian `.deb` package using the nfpm library.

## Key Components

- **`BuildDeb(opt Options) (string, error)`** — Accepts packaging `Options` and delegates to the shared `buildNFPM` helper with the nfpm Debian packager. Returns the output file path or an error. **Not safe for concurrent use.**

## Usage Example

```go
path, err := packaging.BuildDeb(packaging.Options{
    Name:    "myapp",
    Version: "1.0.0",
    // ...additional options
})
if err != nil {
    log.Fatal(err)
}
fmt.Println("Package written to:", path)
```

## Notes

- Relies on [`goreleaser/nfpm`](https://github.com/goreleaser/nfpm) under the hood via the shared `buildNFPM` function.
- Concurrent calls are **not** supported; serialize access if building multiple packages.
- See [`deb.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/tools/packaging/deb.go) for the full source.
