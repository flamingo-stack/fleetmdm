Entrypoint for the `fleetd_tables` osquery extension binary, which registers Fleet's custom osquery tables by connecting to an osquery extension socket and serving them via the Extension Manager Server.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `socket` | `flag.String` | Path to the osquery extensions UNIX domain socket (required) |
| `timeout` | `flag.Int` | Seconds to wait for autoloaded extensions (default: 3) |
| `interval` | `flag.Int` | Seconds between connectivity ping checks (default: 3) |
| `main()` | `func` | Parses flags, connects to osquery with retry logic, registers default and platform-specific plugins, and runs the extension server |

## Behavior

- Requires `-socket` flag; exits fatally if not provided.
- Attempts to connect to the osquery socket using a **backoff retry** strategy: up to 25 retries at 200ms intervals (~5 seconds total).
- Loads orbit default tables via `orbittable.OrbitDefaultTables` and platform-specific tables via `orbittable.PlatformTables`, then registers all plugins with the extension server.
- The `-verbose` flag is silently accepted to maintain compatibility when osqueryd passes it automatically.

## Usage Example

```bash
# Run the extension against an active osquery socket
fleetd_tables -socket /var/osquery/osquery.em -timeout 5 -interval 2
```

```go
// The core startup sequence in main():
server, _ := osquery.NewExtensionManagerServer(
    "com.fleetdm.fleetd_tables.osquery_extension.v1",
    *socket,
    serverTimeout,
    serverPingInterval,
)
plugins := orbittable.OrbitDefaultTables(opts)
platformTables, _ := orbittable.PlatformTables(opts)
plugins = append(plugins, platformTables...)
server.RegisterPlugin(plugins...)
server.Run()
```
