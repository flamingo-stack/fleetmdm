Implements the `shell` (aliased as `osqueryi`) CLI subcommand for Orbit, launching an interactive or single-query osqueryi session with TUF-managed binaries, extension registration, and certificate validation.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `shellCommand` | `*cli.Command` | CLI command definition for `orbit shell` / `orbit osqueryi` |
| `getCertPath` | `func` | Resolves and validates the TLS certificate PEM path |
| `getUpdater` | `func` | Returns a live or disabled `update.Updater` based on configuration |

## Flags

| Flag | Default | Env Var | Description |
|------|---------|---------|-------------|
| `--osqueryd-channel` | `stable` | `ORBIT_OSQUERYD_CHANNEL` | TUF channel for osqueryd binary |
| `--debug` | `false` | `ORBIT_DEBUG` | Enable debug-level logging |
| `--fleet-certificate` | — | `ORBIT_FLEET_CERTIFICATE` | Path to Fleet server certificate chain |

## Usage Example

```bash
# Interactive osqueryi shell
orbit shell --root-dir /var/lib/orbit --fleet-certificate /etc/fleet/cert.pem

# Single SQL query (non-interactive)
orbit shell --root-dir /var/lib/orbit -- "SELECT * FROM osquery_info;"

# Use a specific channel with debug logging
orbit shell --osqueryd-channel edge --debug

# Disable auto-updates (use locally cached binary)
orbit shell --disable-updates --root-dir /var/lib/orbit
```

## Behavior Notes

- **Isolated data path**: Uses `<root-dir>/shell/` to avoid RocksDB lock conflicts with the Orbit daemon's osqueryd instance.
- **Windows pipe collision**: Appends a UUID suffix to the extension socket path on Windows to prevent named pipe conflicts with the daemon.
- **Extension runner**: Registered only for interactive sessions; skipped for single-query mode (where osquery exits immediately) to avoid socket wait issues.
- **Signal handling**: Listens for `SIGINT`/`SIGKILL` via a `run.Group` context for clean shutdown.
