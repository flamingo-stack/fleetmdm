Unix-specific signal handling for the Fleet orbit agent, providing OS interrupt/termination signal routing and `SIGUSR1`-triggered pprof diagnostics collection.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `signalHandler` | `func` | Returns `run.Group`-compatible execute/interrupt pair for `SIGINT` and `SIGTERM` |
| `sigusrListener` | `func` | Blocking goroutine that captures `SIGUSR1` and triggers a profile dump |
| `dumpProf` | `func` | Collects all active pprof profiles and writes them to a timestamped `.tar.gz` archive |

## Usage Example

```go
// Wire up graceful shutdown (called from main run.Group setup)
execute, interrupt := signalHandler(ctx)
g.Add(execute, interrupt)

// Launch SIGUSR1 listener in background goroutine
go sigusrListener(rootDir) // e.g. rootDir = "/var/lib/orbit"
```

Sending `SIGUSR1` to the running process triggers a profile dump:

```bash
kill -SIGUSR1 $(pidof orbit)
```

Output is written to:

```text
<rootDir>/profiles/profiles-2024-06-01T12-30-00.tar.gz
```

The archive contains one `.pprof` file per registered profile (e.g., `goroutine.pprof`, `heap.pprof`, `cpu.pprof`).

## Notes

- Timestamps use `2006-01-02T15-04-05` (hyphens instead of colons) to remain compatible with NTFS/FAT filesystems.
- Profiles directory is created with `constant.DefaultDirMode` via [`secure.MkdirAll`](https://github.com/flamingo-stack/fleetmdm/blob/main/pkg/secure).
- This file is Unix-only (`//go:build unix`); a separate implementation handles Windows signal semantics.
