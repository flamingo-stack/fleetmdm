Provides Windows-compatible signal handling for the application's process lifecycle management.

## Key Components

- **`signalHandler(ctx context.Context)`** — Returns `execute` and `interrupt` functions that listen for `os.Interrupt` (Ctrl+C / SIGINT) using the `oklog/run` signal handler.
- **`sigusrListener(rootDir string)`** — No-op stub; exists for Windows compatibility where SIGUSR signals are unavailable.

## Usage Example

```go
ctx := context.Background()

execute, interrupt := signalHandler(ctx)

var g run.Group
g.Add(execute, interrupt)

if err := g.Run(); err != nil {
    log.Fatal(err)
}
```

> **Note:** On Windows, only `os.Interrupt` is supported. The `sigusrListener` function is intentionally empty — its Unix counterpart (typically in `signal_unix.go`) handles `SIGUSR1`/`SIGUSR2` for live config reloads or log rotation. This file ensures the build compiles cross-platform without conditional logic at the call site.
