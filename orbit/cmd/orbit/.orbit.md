Main entry point for the Orbit agent — a Fleet MDM client daemon that manages osquery lifecycle, auto-updates, enrollment, and platform-specific integrations on managed endpoints.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `main()` | func | Bootstraps the CLI application, registers subcommands (`version`, `shell`, `uuid`), and defines all runtime flags |
| `orbitAction()` | func | Primary daemon logic: initialises logging, TLS, enrollment, update runners, osquery process management, and the service group |
| `logError` | type | String constants used to pattern-match known subprocess error messages (LaunchServices, missing executable, missing domain) |

**CLI flags registered in `main()`:**

| Flag | Env var | Purpose |
|------|---------|---------|
| `--root-dir` | `ORBIT_ROOT_DIR` | State directory for Orbit |
| `--fleet-url` | `ORBIT_FLEET_URL` | Fleet server endpoint |
| `--enroll-secret` / `--enroll-secret-path` | `ORBIT_ENROLL_SECRET*` | Host enrollment credentials |
| `--fleet-managed-host-identity-certificate` | `ORBIT_FLEET_MANAGED_HOST_IDENTITY_CERTIFICATE` | TPM-backed request signing (EE) |
| `--openframe-mode` | `ORBIT_OPENFRAME_MODE` | OpenFrame integration mode |
| `--disable-updates` | `ORBIT_DISABLE_UPDATES` | Skip auto-update runner |

> **Note:** The `//go:debug x509negativeserial=1` directive re-enables parsing of certificates with negative serial numbers (required for Microsoft Company Portal Platform SSO certificates, which violate the RFC).

## Usage Example

```bash
# Run Orbit pointing at a Fleet server
orbit \
  --fleet-url=https://fleet.example.com \
  --enroll-secret=abc123 \
  --root-dir=/var/lib/orbit \
  --fleet-desktop \
  --debug

# OpenFrame mode with a custom osqueryd binary
ORBIT_OPENFRAME_MODE=true \
ORBIT_OPENFRAME_SECRET=secret \
ORBIT_OPENFRAME_OSQUERY_PATH=/usr/local/bin/osqueryd \
  orbit
```
