Entry point for a CLI tool that requests a certificate from a Fleet server's certificate authority using HTTP message signing backed by a secure hardware key (TPM/secure enclave).

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `Credentials` | struct | Holds the SCEP-issued X.509 certificate, its secure-hardware-backed private key handle, and the file path to the certificate on disk |
| `Credentials.Close()` | method | Releases the secure hardware device resources |
| `main()` | func | Parses CLI flags (`-rootdir`, `-fleeturl`, `-ca`, `-csr`, `-out`, `-debug`), reads the CSR, signs the request, and writes the returned certificate to disk |
| `requestCert()` | func | POSTs a signed HTTP request to `/api/v1/fleet/certificate_authorities/{id}/request_certificate` and returns the PEM certificate string |
| `getSigner()` | func | Loads credentials and constructs an `httpsig.Signer` using the device's ECC key (P-256 or P-384) and the certificate serial number as the key ID |
| `loadCredentials()` | func | Initialises the secure hardware device, loads the stored key, loads the SCEP certificate, and verifies that both public keys match |
| `loadSCEPClientCert()` | func | Reads and PEM-decodes the X.509 certificate from the fleetd root directory |

## Usage Example

```bash
# Request a certificate from a Fleet CA using the device's TPM-backed identity
fleet-cert-requester \
  -rootdir /var/lib/fleetd \
  -fleeturl https://fleet.example.com \
  -ca 1 \
  -csr /tmp/device.csr \
  -out /etc/fleetd/certificate.pem \
  -debug
```

```go
// Internal flow: sign an HTTP request with the secure-hardware-backed key
signer, err := getSigner(rootDir, logger)
if err != nil {
    log.Fatal(err)
}

cert, err := requestCert(signer, "https://fleet.example.com", 1, csrPEM)
if err != nil {
    log.Fatal(err)
}
fmt.Println(cert) // PEM-encoded certificate
```

> **Note:** The tool validates that the public key in the on-disk SCEP certificate matches the public key stored in secure hardware before signing any request. If no key is found on the device, it exits with a descriptive error rather than a raw hardware error.
