Windows-specific desktop tray implementation providing the system tray icon asset and Windows kernel event synchronization for IPC between the Fleet desktop agent and Orbit.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `iconDark` | `[]byte` | Embedded `.ico` file (`windows_app.ico`) used as the system tray icon on all Windows themes |
| `blockWaitForStopEvent` | `func(channelId string) error` | Polls for a named Windows kernel event object (`Global\comm-<channelId>`), then blocks indefinitely until Orbit signals it |
| `trayIconExists` | `func() bool` | Stub returning `true`; tray icon existence checking is not implemented on Windows |

## Usage Example

```go
// Wait for Orbit to signal the desktop agent to stop via a named kernel event.
// channelId is the shared communication channel identifier passed at startup.
err := blockWaitForStopEvent(channelId)
if err != nil {
    log.Fatal().Err(err).Msg("Stop event error")
}
// Proceed with graceful shutdown after Orbit signals the event.
```

## Notes

- The icon is loaded at compile time via `//go:embed windows_app.ico` and must be in `.ico` format; Windows GDI requires this format for system tray icons.
- `blockWaitForStopEvent` first spins in a 500 ms polling loop using `OpenEvent` until the named kernel object becomes available, then switches to a blocking `WaitForSingleObject(INFINITE)` call — avoiding busy-wait once the handle is acquired.
- The synchronization access right `EVENT_SYNCHRONIZE` (`0x00100000`) is the minimal permission required; the handle is always closed via `defer` to prevent kernel handle leaks.
- Theme-adaptive icon logic was intentionally removed (see [Fleet PR #16402](https://github.com/fleetdm/fleet/pull/16402)); a single colored icon is used for both light and dark Windows themes.
