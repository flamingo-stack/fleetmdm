Linux-specific implementation for the Fleet desktop tray icon, handling KDE Plasma detection, icon selection, and D-Bus tray icon visibility checks.

## Key Components

- **`iconDarkDefault`** / **`iconKDE`** — Embedded PNG assets for the default dark icon and KDE-specific icon, loaded at compile time via `//go:embed`.
- **`iconDark`** — Package-level icon resolved at startup by calling `getIcon()`.
- **`getIcon()`** — Selects the appropriate icon based on the active desktop environment (KDE vs. default).
- **`isKDE()`** — Detects whether the active GUI session is running KDE Plasma by looking up the logged-in GUI user and checking for a running `plasmashell` process via `pgrep`.
- **`blockWaitForStopEvent()`** — Stub satisfying a cross-platform interface; communication channel helpers are not implemented on Linux.
- **`trayIconExists()`** — Checks whether the systray icon is still visible by querying the D-Bus session bus for the expected `org.kde.StatusNotifierItem-<pid>-1` name.

## Usage Example

```go
// Icon selection happens automatically at package init.
// iconDark holds the correct PNG bytes for the current desktop environment.

// Check if the tray icon is currently registered on D-Bus:
if trayIconExists() {
    log.Info().Msg("Tray icon is active")
} else {
    log.Warn().Msg("Tray icon not found on D-Bus")
}

// isKDE can be called independently to branch desktop-specific behaviour:
if isKDE() {
    // Apply KDE-specific tray icon handling
}
```

## Notes

- KDE detection uses `pgrep` scoped to the GUI user's UID, avoiding false positives from other sessions.
- The D-Bus name convention `org.kde.StatusNotifierItem-<pid>-1` follows the [StatusNotifierItem specification](https://www.freedesktop.org/wiki/Specifications/StatusNotifierItem/).
- `blockWaitForStopEvent` is a no-op on Linux; see platform-specific counterparts for Windows/macOS implementations.
