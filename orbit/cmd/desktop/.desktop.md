Fleet Desktop application entry point that manages the system tray icon, device authentication token lifecycle, MDM migration, and server connectivity polling for the Fleet MDM desktop agent.

## Key Components

| Component | Description |
|-----------|-------------|
| `main()` | Application entry point; bootstraps logging, environment config, systray lifecycle, and polling goroutines |
| `setupRunners()` | Configures a `run.Group` with a Windows IPC shutdown watcher via `blockWaitForStopEvent` |
| `onReady` | Systray callback that initialises the menu manager, Fleet device client, token reader, MDM migrator (macOS), and all background goroutines |
| `checkToken()` | Exponential-backoff loop that calls `DesktopSummary` until the device auth token is accepted by Fleet, then signals readiness via a channel |
| `menuManager` | `menu.Manager` instance that drives systray state transitions: `SetConnecting`, `SetConnected`, `SetOffline` |
| `tokenReader` | `token.Reader` that watches the device identifier file for changes and refetches the token on modification |
| `pingTicker` | 10-second ticker; drives the connectivity check loop that updates the offline indicator and rate-limits `DesktopSummary` calls to every 5 minutes |
| `mdmMigrator` / `offlineWatcher` | macOS-only MDM migration and offline-state coordination via `swiftDialogCh` |
| `reportError` | Ships `FleetdError` telemetry to the Fleet server when the `CapabilityErrorReporting` capability is present |
| `version` | Compile-time version string injected via `-ldflags` |

## Usage Example

```bash
# Build with version metadata
go build -ldflags "-X main.version=1.2.3" ./orbit/cmd/desktop

# Required environment variables at runtime
export FLEET_DESKTOP_FLEET_URL="https://fleet.example.com"
export FLEET_DESKTOP_DEVICE_IDENTIFIER_PATH="/var/lib/orbit/identifier"

# Optional TLS / advanced config
export FLEET_DESKTOP_FLEET_ROOT_CA="/etc/fleet/ca.crt"
export FLEET_DESKTOP_FLEET_TLS_CLIENT_CERTIFICATE="/etc/fleet/client.crt"
export FLEET_DESKTOP_FLEET_TLS_CLIENT_KEY="/etc/fleet/client.key"
export FLEET_DESKTOP_ALTERNATIVE_BROWSER_HOST="fleet-browser.example.com"
export FLEET_DESKTOP_TUF_UPDATE_ROOT="/etc/fleet/tuf-root.json"
export FLEET_DESKTOP_INSECURE="1"          # skip TLS verification (dev only)

# Print version (used by Orbit's update.GetVersion)
./fleet-desktop --version

# Trigger permanent-error mode (displays an error dialog instead of normal tray)
export FLEET_DESKTOP_PERMANENT_ERROR="Device enrollment failed"
./fleet-desktop
```
