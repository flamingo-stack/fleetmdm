Manages the Fleet Desktop system tray menu state, handling menu item creation, visibility, and state transitions for connecting, connected, and offline scenarios.

## Key Components

### Interfaces

- **`Factory`** — Abstracts systray menu creation; provides `AddMenuItem` and `AddSeparator` methods for testable menu construction.
- **`Item`** — Wraps `systray.MenuItem` with method-based access (`SetTitle`, `Enable`, `Disable`, `Show`, `Hide`, `ClickedCh`) to support testing.

### Types

- **`Items`** — Holds all tray menu item references: `Version`, `MigrateMDM`, `MyDevice`, `HostOffline`, `SelfService`, and `Transparency`.
- **`Manager`** — Orchestrates menu state with thread-safe atomic booleans tracking MDM migrator and offline indicator visibility.

### Functions & Methods

| Symbol | Description |
|---|---|
| `isOpenSUSE()` | Detects OpenSUSE Linux by reading `/etc/os-release` to suppress emoji in system tray |
| `NewManager(version, factory)` | Initializes all menu items with default disabled/hidden states |
| `SetConnecting()` | Transitions menu to a connecting state; disables most items |
| `SetConnected(summary, isFreeTier)` | Enables device and transparency items; conditionally shows self-service and MDM migrator |
| `SetOffline()` | Hides all items and shows the offline warning |
| `UpdateFailingPolicies(count)` | Updates the "My device" label with policy failure count; uses text fallback on Windows/OpenSUSE |
| `SetMDMMigratorVisibility(show)` | Atomically toggles MDM migration item visibility |

## Usage Example

```go
manager := menu.NewManager("1.2.3", myFactory)

// On successful connection
manager.SetConnected(&fleet.DesktopSummary{SelfService: &selfServiceEnabled}, false)

// Update policy failure badge
failCount := uint(2)
manager.UpdateFailingPolicies(&failCount)

// Show MDM migration prompt
manager.SetMDMMigratorVisibility(true)

// On network loss
manager.SetOffline()
```
