Concrete adapter that bridges the `menu.Factory` interface to the real `fyne.io/systray` library, enabling the rest of the application to interact with native OS system tray menus through a consistent abstraction.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `SystrayFactory` | struct | Implements `Factory`; delegates `AddMenuItem` and `AddSeparator` calls directly to `fyne.io/systray` |
| `SystrayMenuItem` | struct | Thin wrapper around `*systray.MenuItem` that promotes the `ClickedCh` field to a method, satisfying the `Item` interface |
| `NewSystrayFactory()` | constructor | Returns a ready-to-use `*SystrayFactory` |

## Usage Example

```go
// Wire up the real systray backend at startup
factory := menu.NewSystrayFactory()

// Create menu items through the abstraction
quitItem := factory.AddMenuItem("Quit", "Exit the application")
factory.AddSeparator()
settingsItem := factory.AddMenuItem("Settings", "Open settings")

// Listen for clicks via the interface method
go func() {
    for range quitItem.ClickedCh() {
        // handle quit
    }
}()
```

> **Design note:** `SystrayMenuItem` exists solely because `systray.MenuItem` exposes `ClickedCh` as a **field**, not a method. The wrapper promotes it to a method so `SystrayMenuItem` satisfies the `Item` interface without changing call-site code. Swap `SystrayFactory` for a mock factory in tests to avoid spawning a real system tray process.
