## Usage Example

```go
// Watch a registry key for value/subkey changes asynchronously
event, _ := windows.CreateEvent(nil, 0, 0, nil)
defer windows.CloseHandle(event)

err := regNotifyChangeKeyValue(
    key,
    true,                    // watchSubtree
    windows.REG_NOTIFY_CHANGE_LAST_SET, // notifyFilter
    event,
    true,                    // asynchronous
)
if err != nil {
    log.Fatalf("registry watch failed: %v", err)
}

// Wait for change notification
windows.WaitForSingleObject(event, windows.INFINITE)
```
