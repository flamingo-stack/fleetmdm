Provides macOS-specific stub implementations for desktop tray icon and inter-process communication helpers, embedding the Fleet logo SVG for use as the dark tray icon.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `iconDark` | `[]byte` | Embedded `fleet-logo.svg` asset loaded at compile time via `//go:embed` |
| `blockWaitForStopEvent` | `func(string) error` | No-op stub; logs a debug message and returns `nil` — IPC stop-event blocking is not implemented on Darwin |
| `trayIconExists` | `func() bool` | No-op stub; logs a debug message and always returns `true` — tray icon presence checking is not implemented on Darwin |

## Usage Example

```go
// iconDark is available package-wide as a compiled-in byte slice:
fmt.Printf("SVG size: %d bytes\n", len(iconDark))

// blockWaitForStopEvent is called during shutdown coordination;
// on Darwin it is a no-op and always succeeds.
if err := blockWaitForStopEvent("some-channel"); err != nil {
    log.Fatal().Err(err).Msg("failed waiting for stop event")
}

// trayIconExists is used to check whether the system tray icon
// is already running; on Darwin it always reports true.
if trayIconExists() {
    fmt.Println("tray icon is present")
}
```

## Notes

- The file uses a Darwin build tag implicitly via the `_darwin` filename suffix, so these stubs are only compiled on macOS.
- Both `blockWaitForStopEvent` and `trayIconExists` are platform-specific shims; full implementations exist for other supported platforms (e.g., Windows).
- See the full source at [`orbit/cmd/orbit/desktop_darwin.go`](https://github.com/flamingo-stack/fleetmdm/blob/main/orbit/cmd/orbit/desktop_darwin.go).
